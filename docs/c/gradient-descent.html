梯度下降

Gradient Descent

也叫：GD　梯度下降法　最速下降　steepest descent　下山法　batch gradient descent

在交互版中打开（看它长在树上的哪里）

反复沿着损失函数下降最快的方向（负梯度方向）把参数挪一小步，直到损失不再明显下降。

先要会：导数、偏导与梯度 损失函数

有了损失函数，训练就是求最小值。线性回归这类简单问题可以解方程一步得到答案，但神经网络有几百万到上万亿个参数，损失是高度非线性的函数，没有解析解。我们能做的只有：站在当前位置，看看往哪边走损失下降，然后走一小步。

多元微积分告诉我们，函数在一点增长最快的方向就是梯度∇L(θ)（所有偏导组成的向量，见导数、偏导与梯度），所以下降最快的方向是负梯度。梯度下降的更新规则只有一行：

θ ← θ − η · ∇L(θ)

η叫学习率与学习率调度，决定每一步走多远。不断重复，参数就会沿着损失曲面往低处走。

步长的取舍：η太小，收敛极慢；η太大，会越过谷底甚至来回震荡、发散。对二次函数f(w) = a(w − c)²，每一步后与最优点的距离乘以(1 − 2aη)，只有0 < η < 1/a时才收敛。

它只保证找到局部的低处。对凸函数与凸优化函数，局部最小就是全局最小；神经网络的损失不是凸的，梯度下降找到的只是某个“够好的”点。为什么这样的点在实践中往往已经足够好，至今仍是研究课题，见损失曲面、局部极小与鞍点。

它出现在哪里：几乎所有深度学习训练都是梯度下降的变体。计算梯度靠反向传播；每步只用一小批数据估计梯度是随机梯度下降与小批量；在此基础上加动量、自适应步长就得到Adam等优化器。历史上随机梯度下降（1951年的随机逼近）与反向传播结合，才让训练多层网络成为可能。

例子

最小化f(w) = (w − 3)²，导数f'(w) = 2(w − 3)。从w = 0出发，η = 0.1：

  • 第1步：梯度 = −6，w = 0 − 0.1×(−6) = 0.6
  • 第2步：梯度 = −4.8，w = 0.6 + 0.48 = 1.08
  • 每步距离3的差都乘以0.8，第10步时w ≈ 2.68。

如果η = 1.0，w在0和6之间来回跳，永远不收敛；η = 1.1时每步差距乘以−1.2，越跳越远，发散。

容易误解的地方

  • 梯度只描述局部，“下降最快”只在无穷小的邻域里成立，所以步长不能太大。
  • 梯度为0的点不一定是最小值，也可能是鞍点或极大值。
  • 实际中很少用全部数据算精确梯度（太贵），用的几乎都是随机小批量版本。
