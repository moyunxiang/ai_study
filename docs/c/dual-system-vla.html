快慢双系统VLA

Dual-System VLA (System 1 / System 2)

也叫：System 1 System 2　双系统　快慢系统　分层VLA　Hierarchical VLA　大小脑　大脑小脑　Action Cascade　慢思考快执行

在交互版中打开（看它长在树上的哪里）

一个慢而聪明的视觉语言模型负责理解和规划，一个快而小的动作模型负责高频控制，两者分工协作。

大视觉语言模型推理一次要几百毫秒，而灵巧控制需要几十到上百赫兹。借用心理学“系统1/系统2”的说法，双系统VLA把两件事拆开：System 2是大VLM，低频地理解指令和场景、输出子任务或隐向量；System 1是小网络，高频地根据最新观测和System 2的输出生成连续动作。中文圈常叫“大脑+小脑”。

Figure Helix（低频的System 2加高频的System 1）、GR00T N1和GR00T N1.7（NVIDIA称Action Cascade）都采用这种结构；Hi Robot分层VLA把高层换成会对话的规划器；Gemini Robotics系列（Gemini Robotics 1.5、Gemini Robotics 2.5）用独立的具身推理模型加动作模型。另一派如π0用单个模型加“动作专家”，知识隔离VLA研究两部分如何训练才不互相破坏。
