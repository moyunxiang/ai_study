最大似然估计

Maximum Likelihood Estimation

也叫：似然　似然函数　likelihood　likelihood function　极大似然　极大似然估计　MLE　极大似然估计　似然函数　对数似然　log-likelihood　NLL

在交互版中打开（看它长在树上的哪里）

选择让已观察到的数据出现概率最大的那组参数。神经网络训练中最常用的交叉熵损失和均方误差，本质上都是最大似然。

先要会：随机变量与概率分布 导数、偏导与梯度

我们有一个带参数θ的概率模型和一批数据，怎么定参数？一个自然的原则是：好的参数应该让“真实发生了的事”看起来最不意外。最大似然估计就是把这个原则写成优化问题。

定义。设数据x_1, …, x_n独立同分布，模型给出概率p(x | θ)。似然函数是

L(θ) = Π_i p(x_i | θ)

连乘很多个小于1的数会下溢，也不好求导，所以实践中最大化对数似然：

θ* = argmax_θ Σ_i log p(x_i | θ)

等价地，最小化负对数似然（NLL）−Σ_i log p(x_i | θ)。这就是一个可以用梯度下降求解的损失函数。

和常见损失的关系。

  • 分类：模型输出类别分布，NLL就是交叉熵损失。
  • 回归：假设y ~ N(f(x), σ²)，NLL展开后只剩Σ (y_i − f(x_i))²加常数，即均方误差。
  • 语言模型：按链式法则把句子概率拆成逐词条件概率，NLL就是每个位置“下一个词”的交叉熵之和，见语言模型。

它出现在哪里。逻辑回归的训练目标就是最大似然；Baum-Welch算法和EM算法在含隐变量时迭代地最大化似然，见EM算法；神经概率语言模型用最大似然训练神经语言模型，GPT-3等大模型的预训练目标也只是在海量文本上做最大似然。最大似然的弱点是数据少时容易过拟合，加入先验就得到先验、后验与贝叶斯推断。

例子

抛硬币10次，7次正面。设正面概率为p，似然L(p) = p⁷(1−p)³。对数似然7 log p + 3 log(1−p)，求导令其为0：7/p − 3/(1−p) = 0，得p = 0.7。代入数值：L(0.7) ≈ 0.00222，L(0.5) = 0.5¹⁰ ≈ 0.00098，前者约是后者的2.3倍。可见最大似然估计就是“频率”。

容易误解的地方

  • 似然不是参数的概率：L(θ)对θ积分不等于1，不能说“p = 0.7的概率最大”。
  • 数据很少时最大似然很极端：抛3次全是正面，它会给出p = 1，即断言永远不会出现反面。
