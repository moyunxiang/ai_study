半监督学习与伪标签

Semi-Supervised Learning and Pseudo-Labels

也叫：pseudo-labeling　自训练　self-training　一致性正则

在交互版中打开（看它长在树上的哪里）

只有少量带标签数据、大量无标签数据时，让模型也从无标签数据中学习；最常用的手段是给无标签样本打“伪标签”并要求预测对扰动保持一致。

先要会：监督学习 数据增强

标注很贵：医学图像需要专家，语音转写要逐字听。无标签数据却几乎免费。半监督学习介于监督学习与无监督学习之间：训练集里有少量(x, y)和大量只有x的样本，目标仍是做好监督任务。

它能起作用依赖一个假设：数据的分布结构本身包含了关于标签的信息，比如同一类的样本聚在一起、类别之间的边界落在数据稀疏的地方。无标签数据帮助模型看清这些结构。

两个核心技巧：

  • 伪标签（自训练）：先用有标签数据训练一个模型，让它预测无标签样本，把置信度高的预测当作标签加入训练，再重复。
  • 一致性正则：同一个样本做不同的数据增强，模型的预测应该一致；这个约束不需要标签。

FixMatch（2020）把两者合在一起：对无标签图像做弱增强（翻转、平移）得到预测，若最大概率超过阈值（论文默认0.95）就当作伪标签；然后要求模型在同一图像的强增强版本上也预测出这个标签。

在AI里：Noisy Student自训练把自训练用到ImageNet规模，用有标签的ImageNet训练教师，给JFT数据集里上亿张无标签图片打伪标签，再训练更大、加了噪声的学生，循环几轮，达到88.4%的top-1准确率。语音识别里用大量无转写音频做伪标签也很常见。更广义地说，自监督学习预训练加少量标签微调，已经成为利用无标签数据的主流方式，与半监督的目标相同。

例子

三类分类，阈值0.95。无标签样本甲的弱增强预测是[0.97, 0.02, 0.01]，最大值超过阈值，伪标签为第1类；样本乙的预测[0.60, 0.30, 0.10]达不到阈值，本轮不用。

对样本甲的强增强版本，模型给第1类的概率只有0.70，交叉熵损失 = −ln 0.70 ≈ 0.36；如果也给到0.97，损失只有−ln 0.97 ≈ 0.03。训练就是把这个损失压下去。

容易误解的地方

  • 伪标签会自我强化错误：模型一开始错了，再拿错标签训练自己，错误会越来越牢固。高阈值、数据增强、教师与学生分开都是为了缓解这一点。
  • 无标签数据和有标签数据分布不同（例如混入了别的类别）时，半监督可能反而有害。
  • 对比论文时要看有标签样本的数量，每类4个和每类400个是完全不同的难度。
