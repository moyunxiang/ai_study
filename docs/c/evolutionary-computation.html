不用梯度，维护一群候选解，按得分挑选、变异、重组，一代代逼近更好的解；可优化参数、网络结构甚至程序。

当目标不可导、只能打分时，进化方法是最通用的退路。遗传算法确立了“种群+选择+交叉+变异”的框架；连续参数上，CMA-ES进化策略用自适应的高斯分布采样，成为黑箱优化的常用工具；NEAT神经进化把进化用于同时搜索神经网络的结构和权重，这就是神经进化。

深度学习时代，进化策略作为RL替代证明简单的进化策略可以大规模并行地训练RL策略，神经架构搜索NAS的一条主要路线是进化搜索网络结构，Lion则用程序搜索找到了新优化器。近两年最受关注的是“大模型当变异算子”：FunSearch、AlphaEvolve、ShinkaEvolve让LLM改写程序、由评估器挑选，达尔文哥德尔机DGM把这一套用于智能体自我改进。争论点在于：进化搜索的样本效率远低于梯度方法，它的优势只在无梯度、可大规模并行评估的场景。
