扩散模型的预测目标：ε、x₀与v

Diffusion Prediction Targets: ε, x₀ and v

也叫：预测目标　prediction target　ε预测　epsilon prediction　ε-prediction　噪声预测　noise prediction　x0预测　x₀预测　x0-prediction　v预测　v-prediction　速度预测　velocity prediction　模型参数化　model parameterization　预处理　preconditioning

扩散模型的去噪网络可以被训练成预测三种不同的东西：加进去的噪声ε、干净的原图x₀，或二者的组合v（流匹配里则是速度）。它们在数学上可以互相换算，但训练的稳定性和各噪声水平上的权重不同。

先要会：扩散：前向加噪与反向去噪 分数函数与分数匹配 噪声调度与采样步数

扩散：前向加噪与反向去噪的前向过程是x_t = α_t·x₀ + σ_t·ε（DDPM里α_t = √ᾱ_t、σ_t = √(1−ᾱ_t)）。去噪网络看到x_t和噪声水平t，要输出“某个东西”，采样器再据此算出更干净的x。这个“某个东西”有几种选法，论文里常以ε-prediction、x₀-prediction、v-prediction来区分。

ε预测。网络预测加进去的噪声：损失‖ε − ε_θ(x_t, t)‖²。DDPM用这种形式，并发现它与加权的去噪分数匹配等价：ε_θ与分数函数与分数匹配只差一个系数−1/σ_t。由ε的预测可以反推x̂₀ = (x_t − σ_t·ε̂) / α_t。缺点是在噪声极大时（α_t接近0）反推x₀要除以一个很小的数，误差被放大。

x₀预测。网络直接输出干净数据的估计。噪声很大时它最稳定（只需猜出一个平均的图像），但在噪声很小时，网络几乎只需原样输出输入，学到的细节信号很弱。

v预测。渐进蒸馏与v预测提出预测

v = α_t·ε − σ_t·x₀

当α_t² + σ_t² = 1时，v是x₀和ε在单位圆上的“旋转”组合，在所有噪声水平上目标的量级都适中。它在少步采样和蒸馏中更稳定，被不少文生图和视频模型采用。

速度预测（流匹配）。在可逆流与流匹配里的流匹配和整流Rectified Flow中，路径取x_t = (1 − t)·x₀ + t·ε，网络预测速度u = ε − x₀（方向取决于约定），沿着它积分ODE即可采样，Stable Diffusion 3采用了这种形式。

本质上是同一件事。给定x_t和t，任意两种目标都可以线性互换；真正不同的是：网络输出层的数值范围不同，以及换算后损失在不同t上的隐含权重不同。EDM设计空间把这一点系统化，用预处理系数让网络的输入、输出在各噪声水平上都保持单位方差，并单独设计损失权重，见噪声调度与采样步数。

例子

某一步α_t = 0.6、σ_t = 0.8（α² + σ² = 1），某个像素的真实值x₀ = 1.0、噪声ε = −0.5。则x_t = 0.6×1.0 + 0.8×(−0.5) = 0.2。三种目标分别为：ε = −0.5；x₀ = 1.0；v = 0.6×(−0.5) − 0.8×1.0 = −1.1。若网络完美预测出v=−1.1，可以换算回x₀ = α_t·x_t − σ_t·v = 0.12 + 0.88 = 1.0。

容易误解的地方

  • 换了预测目标却沿用原来的采样器公式，会得到完全错误的结果；采样器需要知道模型预测的是什么。
  • 不同目标对应的损失权重不同，“v预测效果更好”往往部分来自权重的变化，而不只是参数化本身。
