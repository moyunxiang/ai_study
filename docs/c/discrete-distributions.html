伯努利、二项、类别与多项分布

Bernoulli, Binomial, Categorical and Multinomial

也叫：伯努利分布　Bernoulli distribution　Bernoulli　二项分布　binomial distribution　binomial　类别分布　分类分布　categorical distribution　categorical　多项分布　multinomial distribution　multinomial　离散分布　discrete distribution　多项式分布　0-1分布　两点分布

最常用的几种离散分布：伯努利（一次是/否）、二项（n次是/否里成功几次）、类别（一次从K个选项里选一个）、多项（n次里每个选项各被选几次）。

先要会：随机变量与概率分布 期望与方差

分类器、语言模型、强化学习的离散动作，输出的都是一个离散分布。认识这几个最基本的分布，就能看懂大多数损失函数是从哪来的。

伯努利分布。一次只有两种结果的试验，成功概率为p：P(X = 1) = p，P(X = 0) = 1 − p。均值p，方差p(1 − p)。二分类模型用sigmoid输出p，它的负对数似然就是二元交叉熵与sigmoid输出。

二项分布。独立做n次伯努利试验，成功次数k的分布：

P(k) = C(n, k) · p^k · (1 − p)^(n−k)

均值np，方差np(1 − p)。评测里“模型在n道题上答对k道”就可以看成二项分布，用它估计准确率的误差范围，见置信区间、标准误与误差棒；pass@k指标的无偏估计也基于这类组合计数。

类别分布（categorical）。一次从K个选项里选一个，选第i个的概率是p_i，Σ p_i = 1。它是伯努利在K类上的推广。Softmax与logits输出的就是一个类别分布；语言模型每一步“从词表里选下一个token”就是从类别分布采样，交叉熵损失−log p_正确正是它的负对数似然（见交叉熵）。

多项分布（multinomial）。独立地从同一个类别分布抽n次，统计每类被抽中的次数(k₁, …, k_K)：

P(k₁, …, k_K) = n! / (k₁!…k_K!) · Π p_i^{k_i}

n-gram与平滑模型和朴素贝叶斯分类文本分类把一篇文档看成从词表上抽出的多项分布样本；LDA主题模型主题模型里每个主题是词表上的一个类别分布，而这些分布本身又从Beta分布、狄利克雷分布与共轭先验中的狄利克雷分布抽出。

关系一览：伯努利是n = 1的二项，类别是n = 1的多项；K = 2时类别分布退化为伯努利，多项分布退化为二项。

例子

一个模型对每道题答对的概率都是0.7，独立做10道题。恰好答对7道的概率是C(10, 7)·0.7⁷·0.3³ = 120 × 0.0824 × 0.027 ≈ 0.267。期望答对7道，标准差√(10 × 0.7 × 0.3) ≈ 1.45道——只有10道题时，准确率在55%到85%之间晃动都很正常。

容易误解的地方

  • PyTorch等框架里的multinomial函数实际做的是从类别分布中采样（返回下标），名字容易误导。
  • 二项分布假设每次试验独立且概率相同；基准里的题目难度差别很大时，用它估算的误差范围会偏离实际。
