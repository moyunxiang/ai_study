混合线性注意力架构

Hybrid Linear-Attention / SSM Architectures

也叫：混合架构　hybrid architecture　混合注意力　hybrid attention　线性注意力混合　Mamba-Transformer混合　hybrid Mamba　Gated DeltaNet混合　3:1混合　Lightning Attention

在交互版中打开（看它长在树上的哪里）

大部分层用开销随长度线性增长的线性注意力或状态空间层，只保留少量全注意力层，兼顾长上下文效率和精确回忆。

全注意力的计算随长度平方增长、KV缓存随长度线性增长，长上下文和智能体场景越来越吃不消；纯线性注意力或状态空间模型与线性RNN又在精确检索长距离细节上吃亏。折中办法是混合：Jamba混合架构最早在大模型上把Mamba状态空间模型层和注意力层按比例交替，MiniMax-01闪电注意力用闪电注意力（线性注意力）配少量softmax注意力做到百万上下文，Qwen3-Next混合注意力和Kimi Linear把Gated DeltaNet类层与全注意力按约3:1混合，Nemotron 3混合Mamba则是Mamba加注意力再加MoE。

当前讨论的焦点是混合比例、全注意力层放在哪里，以及线性层在长程推理和检索类任务上到底损失多少；与它竞争的是保留全注意力、只做稀疏化的路线（原生稀疏注意力NSA、DeepSeek-V3.2与DSA）。
