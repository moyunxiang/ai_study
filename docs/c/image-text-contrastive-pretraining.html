图文对比预训练

Contrastive Language-Image Pre-training

也叫：图文对比学习　CLIP式预训练　CLIP-style　图文对齐　Image-Text Contrastive　ITC　语言监督视觉预训练　零样本图像分类　视觉语言嵌入　Sigmoid对比损失

在交互版中打开（看它长在树上的哪里）

让配对的图片和文字在同一向量空间里靠近、不配对的远离，从而学到能零样本识别的视觉表示。

做法是同时训练图像编码器和文本编码器：一批N对图文，配对的N个组合作为正例、其余N²−N个作为负例，用对比学习损失拉近正例。训练好后，把类别名写成句子编码，就能不经微调直接分类（零样本与少样本）。医学领域的ConVIRT图文对比最早系统地这样做，CLIP用4亿网络图文对把它做大，ALIGN用更嘈杂的18亿对数据得到相近结论。

后续工作主要改三件事：损失函数（SigLIP把softmax换成逐对sigmoid，降低对大批量的依赖）、训练方式（LiT锁定图像微调冻结图像塔只训文本塔）、数据（OpenCLIP复现的可复现扩展、MetaCLIP数据配方公开数据配方、MetaCLIP 2全球多语扩到多语言）。这类编码器至今是绝大多数VLM的视觉入口，也是文生图模型的文本条件来源；争论在于对比学习学到的是“是什么”的语义，对位置、计数、空间关系不敏感（CLIP视觉盲区）。
