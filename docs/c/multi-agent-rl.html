多智能体强化学习

Multi-Agent Reinforcement Learning

也叫：MARL　multi-agent RL　Multi-Agent RL　多智能体RL　多智能体学习　multiagent learning　合作多智能体　cooperative MARL　竞争多智能体　马尔可夫博弈　Markov game　随机博弈　stochastic game　多智能体系统学习

在交互版中打开（看它长在树上的哪里）

多个会学习的智能体在同一环境里同时决策，彼此既是队友或对手，也是对方环境的一部分。

单智能体RL假设环境是固定的；多个智能体一起学时，每个人的策略都在变，对别人来说环境就不再平稳，团队奖励也说不清是谁的功劳。马尔可夫博弈给出了基本框架，独立Q学习多智能体则是最朴素的做法：各学各的、把别人当环境。

深度学习时代的主线是“集中训练、分散执行”：DIAL/RIAL学习通信让梯度跨智能体传递学会通信，COMA反事实策略梯度和MADDPG用看全局的评论家，VDN值分解网络、QMIX值分解做团队价值分解，MAPPO证明调好的PPO就是强基线，HATRPO/HAPPO、多智能体Transformer MAT给出有理论保证的顺序更新和序列建模写法。竞争与混合场景则靠自我对弈和种群训练，催生了AlphaStar、OpenAI Five、捉迷藏中的涌现工具使用。评测上有星际多智能体挑战SMAC、Hanabi挑战、Melting Pot社会泛化评测，JaxMARL把实验搬上GPU。

当前争论集中在：能否扩展到成百上千个智能体（平均场多智能体RL、Sable千智能体序列模型），能否和陌生伙伴乃至人类配合，以及从仿真走向真实多机系统（多机无人机竞速MARL）。用RL训练多个大语言模型智能体协作属于另一条线，见智能体分支。
