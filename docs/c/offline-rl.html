离线强化学习

Offline RL

也叫：离线RL　batch RL　批量强化学习　数据驱动RL　CQL　分布外动作

在交互版中打开（看它长在树上的哪里）

只用一份事先收集好的固定数据集学策略，训练过程中不再与环境交互。难点是数据没覆盖到的动作，其价值无法验证，容易被严重高估。

先要会：on-policy与off-policy 时序差分与自举 分布偏移 模仿学习与行为克隆

在医疗、自动驾驶、推荐系统里，让一个还没学好的策略去真实环境里试错代价太高，但历史日志却有大量现成数据。离线强化学习就是只用这样一份固定数据集D = {(s, a, r, s')}来学策略，目标仍是最大化回报，而且希望学出的策略比产生数据的策略更好——这是它和模仿学习与行为克隆的区别。

为什么不能直接用off-policy算法。Q-learning本来就能用别的策略的数据（见on-policy与off-policy），但它的目标r + γ·max_{a'} Q(s', a')要在所有动作里取最大。数据里没出现过的动作，Q值只是神经网络的随意外推，有些会被估得偏高；max恰好会挑出这些偏高的值，再通过时序差分与自举的自举一层层传播放大。在线训练时，智能体去试一下就会发现“这个动作其实不好”；离线时没有这个纠错机会。这叫外推误差，本质是策略与数据之间的分布偏移。

主要思路。

  • 约束策略：只在数据里出现过的动作附近选，如BCQ批量约束Q学习；TD3+BC极简离线RL在策略目标里直接加一项行为克隆损失。
  • 保守估计：离线强化学习CQL在训练Q时额外压低所有动作的Q值、抬高数据中动作的Q值，让没见过的动作不会被高估。
  • 不查询没见过的动作：隐式Q学习IQL只用数据里的动作做价值学习，用期望分位数（expectile）回归来近似“数据中较好动作”的价值。
  • 当作序列建模：Decision Transformer把轨迹写成“目标回报、状态、动作”的序列，用Transformer做条件模仿，推理时给一个高的目标回报。

D4RL离线RL基准提供了常用的离线RL基准数据集。大语言模型用已有偏好数据直接优化（如DPO）也常被看作离线方法。

例子

数据集中，状态s下只出现过动作“左”，它的平均回报约为3，网络学到Q(s, 左)=3。动作“右”从未出现，网络随机外推出Q(s, 右)=9。Q-learning的max会选“右”，把9当作s的价值往前传，而实际上没有任何证据支持这个数字。

CQL在损失里加入α·(log Σ_a exp Q(s, a) − Q(s, a_数据))。代入数值：log(e³ + e⁹) ≈ 9.002，减去数据动作的3，得到约6.0。最小化这一项会主要压低Q(s, 右)（它在log-sum-exp里占主导），同时抬高Q(s, 左)，从而把没见过的动作的高估去掉。

容易误解的地方

  • “离线”与“off-policy”不同：off-policy算法通常仍在持续收集新数据，离线RL完全不收集。
  • 离线RL的效果高度依赖数据质量和覆盖面；数据只有平庸行为时，能学到的上限有限。
  • 离线训练的评估本身也难：最终仍需要在环境中测试，或使用离策略评估方法，后者误差也不小。
