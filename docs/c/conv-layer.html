卷积层、池化与感受野

Convolution, Pooling and Receptive Field

也叫：CNN　卷积神经网络　convolutional neural network

在交互版中打开（看它长在树上的哪里）

用一个小卷积核在输入上滑动、每个位置共用同一组权重的层；配合池化逐层扩大感受野。这是处理图像等网格数据的标准结构。

先要会：卷积运算 多层感知机 图像作为张量

把一张32×32的彩色图片（3个通道，共3,072个数）直接交给多层感知机，第一层哪怕只输出同样大小的64通道特征图，也需要约2亿个权重。这不仅浪费，还忽略了图像的两个基本事实：局部性（判断一个像素属于边缘还是纹理，只需看它附近）和平移不变性（猫在左上角还是右下角都是猫）。

卷积层把这两点写进结构里（见归纳偏置）：

  • 每个输出只看输入的一小块（例如3×3邻域）。
  • 同一个卷积核（一组权重）在所有位置共享，滑过整张图。

对二维多通道输入，第k个输出通道在位置(i, j)的值是：

y_k[i, j] = b_k + Σ_c Σ_u Σ_v W_k[c, u, v] · x_c[i+u, j+v]

（深度学习框架里的“卷积”严格说是互相关，即不翻转卷积核，见卷积运算。）一个卷积核学到的是一种局部模式检测器，比如某个方向的边缘；输出通道数就是检测器的个数。输出尺寸由核大小k、填充p、步长s决定：H_out = ⌊(H + 2p − k) / s⌋ + 1。

池化。在每个小窗口（如2×2）里取最大值（最大池化）或平均值，把特征图缩小一半。它丢掉一点位置细节，换来对小平移的不敏感和更小的计算量。今天也常用步长为2的卷积代替池化。

感受野。一个输出单元在原始输入上能“看到”的区域。一层3×3卷积的感受野是3×3；叠两层变成5×5，叠三层是7×7；每次池化或步长2的下采样会让后续层的感受野增长更快。所以浅层检测边缘，深层能看到整个物体——这对应视觉皮层感受野在猫视觉皮层里发现的从简单到复杂的细胞层级。

它在哪里出现。Neocognitron最早提出这种结构，LeNet与卷积网络用反向传播训练它识别手写数字，AlexNet在GPU上把它做大并赢下ImageNet，VGG和ResNet把它推到几十到上百层。2020年后视觉的主力部分让位给Vision Transformer，但卷积仍广泛用于扩散模型的U-Net、语音和端侧模型。

例子

一维的例子。输入[1, 2, 3, 4, 5]，卷积核[1, 0, −1]，不填充、步长1：第一个输出是1×1 + 0×2 + (−1)×3 = −2，往右滑一格是2 − 4 = −2，再一格3 − 5 = −2，输出[−2, −2, −2]，长度5 − 3 + 1 = 3。这个核在算“左减右”，是一个最简单的边缘（变化）检测器。

参数量对比。输入32×32×3，用64个3×3卷积核：每个核有3×3×3 = 27个权重加1个偏置，共64×28 = 1,792个参数，与图片大小无关。若改用全连接层产生同样大小的32×32×64输出，需要3,072×65,536 ≈ 2.0亿个权重。

输出尺寸。32×32的输入，k = 3、p = 1、s = 1时输出仍是32×32；改成s = 2，输出⌊(32 + 2 − 3)/2⌋ + 1 = 16，即16×16。

容易误解的地方

  • 卷积本身是平移等变（输入平移，输出跟着平移），不是不变；不变性主要来自池化和最后的全局汇总（见不变性与等变性）。
  • 卷积层的参数少，但计算量不少：每个位置都要做一次乘加，高分辨率输入的计算量很大。
  • 感受野的理论大小不等于有效大小：实际起作用的通常集中在中心一小块。
