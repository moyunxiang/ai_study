强化学习方法的分类：基于价值、基于策略与有无模型

给强化学习算法定位的几条坐标轴：学不学环境模型（无模型/有模型）、学价值还是直接学策略（基于价值/基于策略/Actor-Critic），以及数据从哪来（同策略/离策略/离线）。

先要会：马尔可夫决策过程 策略与价值函数

读强化学习论文，常会看到“这是一个无模型、基于价值的离策略算法”这样的定位。算法名字成百上千，但大多可以用三条坐标轴放进同一张地图，先掌握坐标轴，再看具体算法就只需要记它在哪几处做了改动。

第一条轴：有没有环境模型。马尔可夫决策过程里的转移概率P(s'|s, a)和奖励R(s, a)对智能体通常是未知的。

  • 无模型（model-free）：不去估计P和R，直接从交互数据里学价值或策略。Q-learning、DQN、PPO都是。实现简单，但通常需要大量交互。
  • 有模型（model-based）：先学一个能预测“做了a之后会怎样”的模型，再用它规划或生成假数据，见基于模型的强化学习。Dyna：学习与规划合一和MuZero是代表；AlphaZero直接用已知的棋规当模型。数据效率高，但模型的误差会被利用。

第二条轴：学什么。

  • 基于价值（value-based）：学动作价值Q(s, a)，策略隐含在argmax_a Q(s, a)里。适合离散动作；连续动作时argmax本身就难求。
  • 基于策略（policy-based）：直接参数化π_θ(a|s)并做梯度上升，见策略梯度，REINFORCE策略梯度是最早的形式。天然支持连续动作和随机策略，但方差大。
  • Actor-Critic：两者都学，策略负责选动作，价值函数负责打分，见Actor-Critic与优势函数。今天的主流算法多属于这一类。

第三条轴：数据从哪来。用当前策略自己采的数据叫同策略，能复用别的策略的数据叫离策略，见on-policy与off-policy；完全不与环境交互、只用一份固定数据集的叫离线，见离线强化学习。

这三条轴是相互独立的，所以同一个名字可能在不同轴上各占一格。另外还有一些常用的标签：表格型与强化学习中的函数逼近，单智能体与多智能体，有无示范数据（见模仿学习与行为克隆）。

例子

几个常见算法的定位：

  • DQN：无模型、基于价值、离策略、在线交互。
  • PPO：无模型、Actor-Critic、同策略。
  • SAC：无模型、Actor-Critic、离策略。
  • 离线强化学习CQL：无模型、基于价值、离线。
  • MuZero：有模型（学一个隐空间模型）、在模型里做树搜索规划，同时学价值和策略。

容易误解的地方

  • “有模型”不等于“知道真实环境”：学到的模型可能很不准，规划时智能体会钻模型的空子。
  • 基于价值和基于策略并非互斥，Actor-Critic同时属于两边；分类是为了定位，不是硬性的阵营。
  • 有的论文把“model-based”只用来指学到的模型，把AlphaZero这类用规则模拟器的方法单称为“规划”或“搜索”，读时要看上下文。
