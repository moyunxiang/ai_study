潜空间

Latent Space

也叫：隐空间　潜在空间　latent representation　隐向量　latent code　潜变量空间

在交互版中打开（看它长在树上的哪里）

模型内部用来表示数据的低维向量空间。每个数据点对应其中一个点，空间里相近的点代表相似的数据，生成模型常在这里采样和编辑。

先要会：自编码器 隐变量模型 嵌入向量

一张512×512的彩色图有78万多个数，但“自然照片”只占这个巨大空间里极小的一部分，而且有大量冗余：相邻像素几乎一样，一只猫换个角度也还是猫。如果能找到一组少得多的坐标来描述图像——比如“什么物体、什么姿势、什么光照”——学习和生成都会容易很多。这组坐标所在的空间就叫潜空间（latent space），其中的向量叫潜变量或潜码z。“潜”指它不是直接观测到的，而是模型推断或学出来的，见隐变量模型。

怎么得到。最常见的是自编码器：编码器把x压成z，解码器再从z还原x，训练目标是还原误差小。z的维度远小于x，网络就被迫只保留最重要的信息。变分自编码器VAE再进一步，要求z的分布接近标准高斯，这样从高斯里随便采一个z，解码出来也是一张合理的图。GAN的生成器同样是从潜空间（输入噪声z）到图像的映射。

它为什么有用。

  • 生成更便宜：潜空间扩散LDM（Stable Diffusion）先把图压进潜空间，在那里做扩散，计算量降了几十倍。
  • 可以插值和编辑：两个潜码之间连线上的点通常对应“渐变”的图像；DCGAN发现潜向量能做加减（戴眼镜的男人−男人+女人≈戴眼镜的女人）；StyleGAN的潜空间里不同方向对应年龄、发型等属性。
  • 离散化后能当token：把连续潜码量化成码本编号，就能用语言模型的方法生成图像和音频，见向量量化与离散token。

潜空间与嵌入向量几乎是同一个东西的两种说法：embedding通常强调“把离散对象变成向量”，潜空间强调“生成模型内部的压缩表示”。

例子

Stable Diffusion的自编码器把512×512×3=786,432个数压成64×64×4=16,384个数，压缩48倍，扩散过程只在这1.6万个数上进行。

插值要注意几何：若潜码服从16,384维标准高斯，它们的长度几乎都在√16384=128附近。两个独立潜码的中点长度约为128/√2≈90.5，明显“偏短”，解码出来可能发灰发糊。所以高斯潜空间里常用球面插值（slerp），而不是直接取线性中点。

容易误解的地方

  • 潜空间的各个坐标轴一般没有可读的含义；“某一维控制笑容”是少数精心设计（如β-VAE、StyleGAN）才部分做到的。
  • 压缩越狠，生成越省，但细节（文字、小人脸）越容易丢，这是潜空间扩散生成小字容易出错的原因之一。
  • 潜空间离得近不一定代表语义相似，距离度量取决于模型训练时的目标。
