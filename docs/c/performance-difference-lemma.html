性能差异引理

Performance Difference Lemma

也叫：性能差异引理　performance difference lemma　PDL　策略性能差异　Kakade-Langford引理　policy performance difference

在交互版中打开（看它长在树上的哪里）

两个策略的回报之差，等于新策略在它自己会访问的状态上、按旧策略的优势函数打分的平均值（再除以1−γ）。它是信赖域、保守策略迭代和模仿学习理论的共同起点。

先要会：Actor-Critic与优势函数 状态访问分布与占用度量

想知道新策略π'比旧策略π好多少，最直接的办法是把两者都跑一遍。性能差异引理给了一个只用旧策略的价值信息就能写出的精确表达式，很多算法的推导都从这里开始。

内容。对任意两个策略π'和π，

J(π') − J(π) = (1 / (1 − γ)) · E_{s~d^{π'}} E_{a~π'(·|s)} [A^π(s, a)]

其中A^π = Q^π − V^π是旧策略的优势函数（见Actor-Critic与优势函数），d^{π'}是新策略的折扣状态访问分布（见状态访问分布与占用度量）。直观地说：沿着新策略走，每一步都问一下旧策略“这一步比你平时的选择好多少”，把这些好处按访问频率加起来就是总的提升。证明只需把J(π')沿新策略的轨迹展开，逐项加减V^π(s_t)，然后望远镜求和。它由Kakade和Langford在保守策略迭代CPI中提出。

为什么重要。

  • 若新策略在每个状态上都选优势非负的动作，回报一定不降，这就是策略评估、策略迭代与价值迭代中策略改进定理的推广。
  • 难点在于期望是在d^{π'}下取的，而我们手里只有旧策略π的数据。把d^{π'}换成d^π就得到信赖域与代理目标的代理目标；两者的差可以用新旧策略的距离来界定，于是有了保守策略迭代CPI的保守混合更新和TRPO的KL约束。
  • 在策略梯度的收敛理论（策略梯度的全局收敛理论）中，它用来把全局最优性归结为局部的优势条件。
  • 在模仿学习中，把π取为专家策略，引理把学习者与专家的差距写成学习者自己分布上的“专家优势”，AggreVaTe代价感知模仿等交互式模仿方法的分析即基于此，并解释了为什么行为克隆的误差会随时域累积（见复合误差）。

例子

γ=0.9。新策略π'访问的状态里，有一半状态它和旧策略选得一样（优势为0），另一半它选了一个优势为+0.2的动作。平均优势为0.1，于是J(π') − J(π) = 0.1 / (1 − 0.9) = 1.0。如果只用旧策略的状态分布来估计，而旧策略恰好很少去那些“改进了的”状态，就会低估这一提升，这就是代理目标的误差来源。

容易误解的地方

  • 引理是精确等式，不是近似；近似只发生在把d^{π'}换成d^π的那一步。
  • 用的是旧策略的优势、新策略的状态分布，两者顺序很容易记反。
