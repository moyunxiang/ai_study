模型容量与欠拟合

Model Capacity and Underfitting

也叫：模型容量　model capacity　容量　capacity　表达能力　expressivity　expressive power　假设空间　hypothesis space　hypothesis class　欠拟合　打散　shattering　有效容量　effective capacity　模型复杂度　model complexity

在交互版中打开（看它长在树上的哪里）

模型能拟合的函数有多丰富：容量太低连训练数据都拟合不好（欠拟合），太高则可能连噪声都记住（过拟合）。参数量只是粗略代理，VC维等是更严格的度量。

先要会：泛化与过拟合 偏差-方差权衡

用一条直线去拟合抛物线，怎么调都拟合不好；用一个100次多项式去拟合10个点，曲线会穿过每一个点却在点与点之间剧烈摆动。两者的区别在于模型的容量：它的假设空间里有多少种不同的函数可选。

容量与拟合。

  • 欠拟合：容量不足，训练误差和测试误差都高，模型根本表达不了数据中的规律。
  • 过拟合：容量过剩又缺乏约束，训练误差很低，测试误差却高，模型记住了训练集里的噪声（见泛化与过拟合）。
  • 经典观点认为测试误差随容量呈U形，最佳容量在中间，这对应偏差-方差权衡的权衡。

怎么衡量容量。

  • 参数量：最直观，但很粗糙。sin(ωx)只有一个参数，却能拟合任意多个点的符号。
  • VC维：模型能“打散”（对任意标签组合都能完美分开）的最多样本数。二维平面上的线性分类器VC维是3。VC维与一致收敛给出了“测试误差 ≤ 训练误差 + 与VC维/样本数有关的项”这类泛化界。
  • Rademacher复杂度：模型拟合随机标签的能力有多强，Rademacher复杂度给出依赖于数据分布的、更紧的界。
  • 有效容量：实际训练能触及的容量还受优化算法、训练步数和正则化限制。早停、正则化与权重衰减、Dropout都是在不改变结构的情况下降低有效容量。

深度学习带来的困惑。万能近似定理说明足够宽的网络能逼近任何函数；重新思考泛化发现标准CNN可以完美记住随机打乱的ImageNet标签，说明它们的容量足以死记硬背，可在真实标签上却泛化得很好。经典容量理论无法解释这一点。双下降和良性过拟合发现，容量越过“恰好能插值训练集”的临界点后，测试误差会再次下降，见过参数化与泛化之谜。今天通常认为，过参数化网络的泛化更多取决于优化算法的隐式偏好和数据的结构，而不只是容量大小。

在大模型里。容量常用参数量和计算量来描述，幂律与规模定律给出了在固定计算预算下参数量与数据量的最优配比；知识容量规模定律研究了模型每个参数大约能存储多少比特的知识。

例子

用多项式拟合10个带噪声的点：1次多项式训练误差0.8、测试误差0.9（欠拟合）；3次多项式训练0.10、测试0.12（合适）；9次多项式恰好穿过全部10个点，训练误差0，测试误差却升到5以上（过拟合）。（数字为示意）

容易误解的地方

  • 参数多不等于一定过拟合，参数少也不等于一定泛化好；要看训练与验证表现的差距。
  • 泛化界里的VC维对深度网络通常大到让界毫无意义，不能用它来预测实际的测试误差。
