文本分类

Text Classification

也叫：Text Categorization　文档分类　Document Classification　新闻分类　意图识别　Intent Classification　垃圾邮件过滤　Spam Filtering　短文本分类

在交互版中打开（看它长在树上的哪里）

给整段文本贴上类别标签，如新闻栏目、垃圾邮件与否、用户意图，是最常见的NLP应用。

传统做法是把文本表示成词袋或IDF与TF-IDF加权向量（向量空间模型），再接一个通用分类器。SVM文本分类说明文本特征维度高、稀疏、多数特征都有用，正适合SVM，这在2000年代是标准基线。

神经时代，TextCNN句子分类用一层卷积加预训练词向量做句子分类，字符级CNN文本分类直接在字符上做卷积，结构化自注意力句嵌入用自注意力汇总句子表示；同一时期，fastText式的词向量平均加线性分类器以极快的速度成为工业界常用方案。ULMFiT提出先预训练语言模型再微调，用很少标注就能分好类，随后BERT微调成为默认做法。如今很多分类任务直接用大模型零样本或少样本完成，但在高吞吐场景下小模型仍更经济。
