图像金字塔与多尺度处理

Image Pyramids and Multi-Scale Processing

也叫：图像金字塔　image pyramid　高斯金字塔　Gaussian pyramid　拉普拉斯金字塔　Laplacian pyramid　尺度空间　scale space　多尺度　multi-scale　多尺度测试　multi-scale testing　高斯差分　DoG　由粗到细　coarse-to-fine

把同一张图按不同分辨率做成一叠（每层通常缩小一半），在各层上分别处理，以便同一个算法能看到大大小小的物体。高斯金字塔、拉普拉斯金字塔、尺度空间，以及CNN里的特征金字塔都是这一思想。

先要会：卷积层、池化与感受野 图像作为张量

图像里的物体可大可小：远处的行人只有十几个像素，近处的可能占满半张图。一个固定大小的卷积核或检测窗口，只对某一个尺度最敏感。最直接的办法是把图像缩放成多个尺度分别处理，这叠不同分辨率的图像就叫图像金字塔。

高斯金字塔。每一层先用高斯核模糊（去掉高频，避免缩小时出现混叠），再隔行隔列采样，分辨率减半。底层是原图，越往上越小、越模糊。

拉普拉斯金字塔。每一层存“本层减去上一层放大回来的结果”，即这个尺度特有的细节。把所有层加回去可以无损重建原图，常用于图像融合、压缩和多尺度编辑，后来也影响了逐级由粗到细生成图像的方法。

尺度空间。用逐渐增大的高斯模糊构造一组连续尺度的图像，在其中寻找跨尺度稳定的结构。SIFT特征在相邻尺度的高斯差分（DoG）里找极值点，使关键点对缩放不变。

在深度学习里。

  • 输入金字塔：测试时把图像缩放成多个尺寸分别推理再合并（多尺度测试），简单但成倍增加计算。
  • 特征金字塔：CNN本身逐层降低分辨率（见步长、填充与特征图尺寸），天然形成一个特征层次：浅层分辨率高但语义弱，深层语义强但分辨率低。特征金字塔FPN通过自顶向下的路径和横向连接，把深层的语义传回各个分辨率，让每一层都既有语义又有分辨率，成为检测和分割的标准组件（见锚框与非极大值抑制）。
  • 空洞卷积的多尺度：DeepLabv3与ASPP的ASPP用不同空洞率的并行卷积在同一分辨率上获取多尺度上下文。
  • 生成模型中也有在多分辨率上逐级生成或去噪的做法，例如金字塔流匹配视频。

例子

一张1024×768的图像建5层高斯金字塔，各层尺寸依次为1024×768、512×384、256×192、128×96、64×48，总像素数约为原图的1 + 1/4 + 1/16 + … ≈ 1.33倍。一个固定大小为64×128的行人检测窗口在第0层能找到约128像素高的人，在第2层就能找到原图中约512像素高的人。

容易误解的地方

  • 缩小前不做低通滤波会产生混叠（细条纹变成假的粗条纹），这是自己实现金字塔时的常见错误。
  • 多尺度测试能提高指标，但计算成本成倍增加，比较方法时要注意对方是否使用了多尺度测试。
