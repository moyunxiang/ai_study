状态估计与贝叶斯滤波

State Estimation and Bayes Filters

也叫：贝叶斯滤波　Bayes filter　Bayesian filtering　状态估计　state estimation　递归状态估计　信念　belief　扩展卡尔曼滤波　EKF　extended Kalman filter　粒子滤波　particle filter　蒙特卡洛定位　Monte Carlo localization　MCL　传感器融合　sensor fusion　滤波发散

状态估计的通用框架：机器人维护一个关于“自己现在处于什么状态”的概率分布（信念），每来一个控制就按运动模型预测、每来一个观测就按观测模型修正。卡尔曼滤波和粒子滤波是它的两种主要实现。

先要会：条件概率与贝叶斯公式 高斯分布 马尔可夫性与马尔可夫链

机器人的传感器从不直接告诉它真实状态：轮速计会打滑，GPS有几米误差，相机有噪声且会被遮挡。控制和规划却需要知道“我现在在哪、速度多少”。状态估计要从一连串带噪声的控制输入u和观测z中，推断隐藏的状态x。这正是隐马尔可夫模型的思想在连续状态上的推广，也对应POMDP规划里的信念状态。

贝叶斯滤波的两步循环。信念bel(x_t) = p(x_t | z_{1:t}, u_{1:t})。

  • 预测：根据运动模型和上一时刻的信念，bel⁻(x_t) = ∫ p(x_t | x_{t−1}, u_t)·bel(x_{t−1}) dx_{t−1}。不确定性在这一步变大。
  • 更新：来了观测，用条件概率与贝叶斯公式修正，bel(x_t) ∝ p(z_t | x_t)·bel⁻(x_t)。不确定性在这一步变小。

这里假设了马尔可夫性：给定当前状态，过去的观测不再提供额外信息（见马尔可夫性与马尔可夫链）。

几种实现。

  • 卡尔曼滤波：运动和观测都是线性的、噪声是高斯分布时，信念始终是高斯分布，只需更新均值和协方差，有闭式解，见卡尔曼滤波。
  • 扩展卡尔曼滤波（EKF）：非线性模型在当前估计处做一阶泰勒展开线性化后套用卡尔曼公式，是导航和早期SLAM（随机地图EKF-SLAM）的主力。
  • 无迹卡尔曼滤波（UKF）：用一组精心选择的采样点穿过非线性函数来估计均值和协方差，通常比EKF更准，见无迹卡尔曼滤波UKF。
  • 粒子滤波：用大量带权重的样本（粒子）表示任意形状的分布：预测时按运动模型移动每个粒子，更新时按观测似然重新加权，再按权重重采样。能处理多峰的情形（例如“我可能在两条相似走廊中的任意一条”），代价是计算量随维数急剧增长，见蒙特卡洛采样和FastSLAM。

系统讲解见《概率机器人》。在学习型机器人里，循环网络或Transformer的隐状态常被看作一种学到的、隐式的滤波器。

例子

一维卡尔曼滤波：当前位置估计均值0、方差1。机器人指令前进1米，运动噪声方差0.5：预测为均值1、方差1.5。随后测距传感器读数1.4，观测噪声方差0.5：卡尔曼增益K = 1.5/(1.5 + 0.5) = 0.75，更新后均值1 + 0.75×(1.4 − 1) = 1.3，方差(1 − 0.75)×1.5 = 0.375，比预测和观测单独的方差都小。

容易误解的地方

  • 滤波器“过于自信”（协方差估计过小）时，会忽略后来的观测、越错越远，这叫滤波发散；调大过程噪声常能缓解。
  • 粒子数不够或重采样过于频繁时，粒子会坍缩到少数几个，失去多样性（粒子贫化）。
