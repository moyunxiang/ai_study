用世界模型评测策略

World Models as Policy Evaluators

也叫：World Model Evaluation　神经仿真评测　生成式仿真评测　Policy Evaluation in World Model　世界模型当评测器　Neural Simulator　Real-to-Sim评测

在交互版中打开（看它长在树上的哪里）

不在真机上一次次试，而是让策略在学到的视频世界模型里“跑”，用模型内的成功率预测真机表现。

真机评测一个机器人策略要摆场景、跑几十次、人工记分，非常慢。传统做法是在物理仿真器里评测，如SIMPLER仿真评测专门调教仿真去对齐真机结果。视频世界模型提供了另一条路：策略输出动作，世界模型生成执行后的画面，再判断成功与否。

1X世界模型较早提出用世界模型评测家用人形策略；Veo世界模型评测策略用Veo改造的世界模型评测Gemini Robotics策略；DreamDojo机器人世界模型在20个场景上报告模型内与真机成功率相关系数0.995；Runway Praxis-1所在的Runway称相关系数0.95；驾驶领域Waymo世界模型用于生成罕见场景做仿真。主要风险是世界模型对失败过于“宽容”——模型内成功率常高于真机，细微的接触失败被低估。
