残差强化学习

Residual Reinforcement Learning

也叫：残差强化学习　残差RL　residual RL　residual reinforcement learning　残差策略　residual policy　residual policy learning　动作修正　action correction　策略修正　基础策略加残差　base policy plus residual　残差控制　residual control

在交互版中打开（看它长在树上的哪里）

不从零学策略，而是在已有控制器或预训练策略上只学一个修正量：动作 = 基础动作 + 残差。基础策略给出合理起点，残差弥补接触、摩擦和模型误差，样本效率高得多。

先要会：策略与价值函数 模仿学习与行为克隆

机器人里经常已经有一个“差不多能用”的控制器：手工调好的PD控制器、基于模型的轨迹规划器、通过模仿学习得到的策略（见模仿学习与行为克隆）。它们在大多数情况下工作，但在精细接触、物体位置有误差、仿真与现实存在偏差时会失败。从零开始用强化学习又要大量试错，在真实机器人上代价很高。残差强化学习取两者之长。

做法。设基础策略为π_base(s)，学一个残差策略π_res(s)，执行的动作是

a = π_base(s) + π_res(s)

只训练π_res。残差网络通常初始化为输出接近0，所以训练开始时机器人的表现就等于基础策略，探索是在一个已经合理的动作附近进行（见探索与利用）。有时残差的输入还包括基础动作本身，或者把残差的幅度限制在一个小范围内，保证安全。

为什么有效。

  • 基础策略解决了任务的大部分结构（往哪里走、按什么顺序），强化学习只需处理剩下的小问题，奖励更容易获得（见信用分配）。
  • 残差可以补偿基础控制器所依据的模型与真实世界之间的差异，是缩小仿真到现实的差距差距的一种方式（与系统辨识互补）。
  • 不需要改动或重训基础策略，可以在不同机器人上复用同一个基础控制器。

常见场景。插孔、装配这类接触丰富的任务；在模仿学习得到的视觉运动策略或VLA与WAM的基本结构模型之上做少量真机强化学习微调（见VLA强化学习后训练）；足式机器人在模型预测控制器的输出上加学到的修正（见规划与模型预测控制）。

与相关方法的关系。它与神经网络中的残差连接思想一致：学习“与已有结果的差”通常比学习完整映射更容易；与预训练与微调相比，残差方法不改动基础参数，而是在输出端叠加修正。

例子

机械臂把销钉插进公差0.5毫米的孔。手工的位置控制器按标称孔位插入，因为孔位有±2毫米的感知误差，成功率约30%。在它上面训练一个残差策略，输入力传感器读数，输出每步±1毫米以内的位置修正，真机训练约2小时后成功率达到90%；从零训练同样的强化学习策略，同样时间内几乎学不会。（数字为示意）

容易误解的地方

  • 基础策略太差时，残差需要修正的幅度太大，等于从零学习，优势消失。
  • 残差和基础策略“各管一部分”，出现故障时难以判断是哪一部分的问题；残差幅度的限制设得太小又会束缚改进空间。
