PUCT：带先验的树搜索选择规则

PUCT: Prior-Guided Tree Search Selection

也叫：PUCT　PUCB　Predictor + UCT　带先验的UCT　c_puct　MCTS选择规则　AlphaZero搜索　访问次数策略　visit count policy　Dirichlet噪声　根节点噪声

在交互版中打开（看它长在树上的哪里）

AlphaGo系列在蒙特卡洛树搜索中选择分支的公式：在UCT的“平均价值+探索奖励”之上，用策略网络给出的先验概率加权探索项，让搜索优先尝试网络认为有希望的走法。

先要会：博弈树搜索：minimax与MCTS 上置信界与乐观原则 策略与价值函数

蒙特卡洛树搜索UCT的经典选择规则UCT在每个节点上对子节点用上置信界与乐观原则：Q + c·√(ln N / n)。它对所有未充分尝试的走法一视同仁。围棋每步有两百多种合法走法，平均地探索每一种代价太大，而AlphaGo已经有了一个能预测高手落子的策略网络。PUCT（Predictor + UCT）把这个预测作为先验，引导探索。

公式。在节点s处，选择

a* = argmax_a [ Q(s, a) + c_puct · P(s, a) · √(Σ_b N(s, b)) / (1 + N(s, a)) ]

  • Q(s, a)：已经模拟过的平均价值（利用）；
  • P(s, a)：策略网络给出的先验概率；
  • N(s, a)：这个分支被访问的次数；分子是父节点的总访问次数；
  • c_puct：平衡利用和探索的常数。

先验高、访问少的走法探索项大；随着N(s, a)增长，探索项按1/(1+N)衰减，最终由实际的Q决定。与UCB1相比，探索项随父节点访问数按平方根增长（而不是对数），并直接由先验加权。这类带先验的规则最早来自老虎机文献中的PUCB，AlphaGo用了它的一个变体，AlphaGo Zero和AlphaZero沿用并简化。

搜索结果怎样变成训练目标。搜索结束后，根节点各走法的访问次数N形成一个比原始策略更强的分布：π(a) ∝ N(s, a)^{1/τ}，τ是温度。策略网络被训练去拟合这个分布，价值网络去拟合对局结果，这就是“搜索作为策略改进算子”，见策略评估、策略迭代与价值迭代和专家迭代ExIt。

后续变化。MuZero在c_puct上加入随访问数缓慢增长的对数项，并在学到的模型里搜索；为了在很少模拟次数下也保证策略改进，后续工作用基于Gumbel采样的选择规则替代根节点的PUCT。为增加探索，自我对弈时还会在根节点的先验上混入Dirichlet噪声。

例子

某节点父访问数ΣN=100，c_puct=1.5。走法A：Q=0.55，P=0.10，N=40；走法B：Q=0.40，P=0.50，N=5。A的得分0.55 + 1.5×0.10×10/41 ≈ 0.55 + 0.037 = 0.587；B的得分0.40 + 1.5×0.50×10/6 = 0.40 + 1.25 = 1.65。尽管B目前平均价值较低，先验高且访问少，下一次模拟会选B。

容易误解的地方

  • PUCT的探索严重依赖先验：网络给某个好走法的概率接近0时，搜索可能很久都不去试它，这是AlphaGo类程序出现“盲点”的原因之一。
  • 不同论文的Q值初始化（未访问节点用0、父节点价值还是损失值）差别很大，对小模拟次数下的表现影响明显。
