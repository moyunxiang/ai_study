机器人数据规模化

Scaling Robot Data

也叫：Data Scaling　数据飞轮　Data Flywheel　数据金字塔　Data Pyramid　机器人大数据　数据采集工厂　robot data scaling law　具身数据规模律

在交互版中打开（看它长在树上的哪里）

机器人能否像语言模型一样“数据越多越聪明”：怎样把机器人训练数据从几千条扩到几十万小时，以及规模化是否真的有效。

语言模型靠互联网文本实现规模化，机器人没有现成的“互联网”。早期的规模化尝试是机械臂农场（机械臂农场抓取、QT-Opt）；Open X-Embodiment汇总了多家实验室的数据，DROID在野外大规模采集，AgiBot World与GO-1建立数据采集工厂。另一方向是降低每小时数据的成本：UMI手持夹爪采集用手持夹爪、EgoScale人类视频扩展用人类第一视角视频。

2025–2026年开始有公司声称观察到规模律：Generalist GEN-0称性能随物理交互数据规模提升，Generalist GEN-1用50万小时以上数据，GR00T N1.7称人类视频从1千小时到2万小时完成度翻倍。这些结论多为公司自报，TRI大行为模型评测等独立研究提醒需要严谨的统计评测才能下结论。
