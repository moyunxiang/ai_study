智能体记忆

Agent Memory

也叫：agent memory　记忆　长期记忆　long-term memory　记忆系统　memory system　记忆管理　情景记忆　episodic memory　个性化记忆　memory layer

在交互版中打开（看它长在树上的哪里）

上下文窗口装不下全部历史，智能体需要把重要信息存到外部、按需取回并定期整理，才能跨会话记住用户和经验。

生成式智能体给虚拟角色设计了记忆流、反思和检索，是智能体记忆的早期范例；MemGPT借用操作系统的分页思想，让模型自己在上下文和外部存储之间搬运信息。产品层面，ChatGPT记忆让助手跨对话记住用户偏好，2026年的“做梦”式记忆整理增加了离线整理记忆的过程；Mem0长期记忆提供可扩展的长期记忆层。智能体上下文工程ACE把记忆的对象从「用户事实」扩展到「做事经验」，不断改写一份操作手册。

它与检索增强的区别是记忆由智能体自己写入和维护。难点包括记什么、何时遗忘、记忆出错后如何纠正，以及隐私。
