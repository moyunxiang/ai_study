最大熵原理

Principle of Maximum Entropy

也叫：最大熵原理　最大熵　maximum entropy principle　MaxEnt　principle of maximum entropy　最大熵模型　maximum entropy model　对数线性模型　log-linear model　熵正则　entropy regularization　熵奖励　entropy bonus　最大熵强化学习　maximum entropy RL　Jaynes

在交互版中打开（看它长在树上的哪里）

在所有满足已知约束的分布里，选熵最大的那个：除了已知事实外不做任何多余假设。它推出了指数族形式，在NLP的最大熵模型和强化学习的最大熵目标里都出现。

先要会：信息量与熵 拉格朗日乘子、约束优化与对偶

只知道一个骰子的平均点数是4.5，该怎么给六个面分配概率？满足这个均值的分布有无穷多个。最大熵原理（Jaynes在1957年系统提出）说：选熵最大的那个，因为它在满足已知信息的前提下“最不确定”，没有偷偷加入我们并不掌握的信息。

数学形式。在约束E_p[f_k(x)] = c_k（k = 1…K）和Σ p(x) = 1下最大化H(p) = −Σ p(x) log p(x)。用拉格朗日乘子（见拉格朗日乘子、约束优化与对偶）求解，答案总是

p(x) ∝ exp(Σ_k λ_k f_k(x))

这正是指数族分布的形式。几个特例：

  • 没有任何约束（有限个取值）：均匀分布。
  • 只约束均值（取值非负）：指数分布。
  • 约束均值和方差：高斯分布。这也是高斯被当作“默认噪声假设”的一个理由。

反过来，对这种形式的模型做最大似然估计，等价于在“特征期望与数据一致”的约束下求最大熵分布，两者是同一个问题的对偶。

它出现在哪里。

  • NLP：最大熵模型把分类写成p(y | x) ∝ exp(Σ λ_k f_k(x, y))，特征可以随意设计、相互重叠，在深度学习之前是词性标注（最大熵词性标注器）、最大熵马尔可夫模型MEMM、条件随机场和统计机器翻译中对数线性翻译模型的基础。今天的softmax分类层在形式上就是同一个模型，特征换成了神经网络的输出（见Softmax与logits）。
  • 强化学习：最大熵逆强化学习在“与专家特征期望一致”的所有轨迹分布里取熵最大的，解决了逆强化学习中奖励的歧义；SAC把目标改成“回报 + α·策略熵”，鼓励在同样好的动作之间保持随机，提升探索和稳健性（见探索与利用）。
  • 语言模型的熵正则、标签平滑也带有“不要过度自信”的最大熵精神。

例子

骰子平均点数约束为4.5。最大熵解形如p(i) ∝ exp(λi)，求得λ ≈ 0.37，概率约为(0.054, 0.079, 0.114, 0.165, 0.240, 0.347)：越大的点数概率越高，但每个面都保留了一定概率，而不是只把概率放在4和5上。

容易误解的地方

  • 最大熵依赖于“取值空间”怎么划分和约束怎么选；同一个问题换一种参数化，得到的分布可能不同。
  • 它是一种选择分布的原则，不保证得到的分布就是真实分布；约束选得不对，结论也不对。
