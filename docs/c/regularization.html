正则化与权重衰减

Regularization and Weight Decay

也叫：L2正则　L1正则　岭回归　惩罚项　penalty

在交互版中打开（看它长在树上的哪里）

在训练中加入额外约束或偏好（如惩罚过大的权重），限制模型去“死记”训练数据，从而提升在新数据上的表现。权重衰减是最常见的一种。

先要会：损失函数 泛化与过拟合 范数与距离

参数足够多的模型能把训练数据背下来，包括其中的噪声，导致在新数据上表现差，这叫过拟合（见泛化与过拟合）。正则化泛指一切“不是为了降低训练损失、而是为了让模型在没见过的数据上更好”的手段。

L2正则与权重衰减：在损失上加一项权重的平方和：

L_total = L + (λ/2)·‖w‖²

求导后梯度多了一项λw，于是梯度下降的更新变成w ← (1 − ηλ)·w − η·g：每一步先把权重整体缩小一点，再按梯度更新，所以也叫权重衰减。它偏好小而分散的权重，函数更平滑，不容易对个别样本反应过度。线性回归加L2就是岭回归与L2正则。

L1正则：加λ·Σ|w_i|。它的梯度大小恒定，会把不重要的权重直接压到0，得到稀疏解，见Lasso与L1稀疏。

更广义的正则化：

  • Dropout：训练时随机关掉一部分神经元（Dropout）。
  • 数据增强：对图像做翻转、裁剪，相当于扩充数据。
  • 早停（early stopping）：验证集损失不再下降就停止训练。
  • 标签平滑（label smoothing）：不让模型对训练标签过度自信。

从贝叶斯角度看，L2正则等价于给权重加一个零均值的高斯分布先验，最小化正则化损失就是求先验、后验与贝叶斯推断估计。

Adam中的细节：对自适应学习率优化器，把λw加进梯度与直接衰减权重不再等价，AdamW把两者分开，今天训练大模型用的权重衰减一般指AdamW的这种形式。

例子

学习率η = 0.1，权重衰减系数λ = 0.01，每一步权重先乘以1 − 0.1×0.01 = 0.999。

如果某个权重得不到任何梯度支持（它对降低损失没用），1000步后它只剩原来的0.999¹⁰⁰⁰ ≈ 0.37倍，3000步后约0.05倍——没用的权重会被慢慢“蒸发”掉。

容易误解的地方

  • 正则化强度λ是超参数，要在验证集上调，不能在测试集上调。
  • 大语言模型预训练通常只过数据一遍左右，过拟合不是主要矛盾，但仍普遍使用权重衰减，它在这里的作用更多与优化稳定性有关，机制仍有讨论。
