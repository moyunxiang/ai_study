视觉SLAM

Visual SLAM

也叫：SLAM　同时定位与建图　Simultaneous Localization and Mapping　单目SLAM　monocular SLAM　视觉里程计　visual odometry　VO　深度SLAM　deep SLAM　稠密SLAM　dense SLAM

在交互版中打开（看它长在树上的哪里）

相机边移动边实时估计自己的位置，同时构建周围环境的三维地图，用于机器人、AR和自动驾驶。

SLAM要在线解决两个互相依赖的问题：知道地图才能定位，知道位置才能建图。MonoSLAM首次用单个相机实时做到这一点，基于扩展卡尔曼滤波；PTAM把跟踪与建图拆成两个并行线程，并用关键帧束调整代替滤波，这一结构沿用至今；ORB-SLAM整合ORB特征特征、回环检测和重定位，成为最常用的特征点法系统；KinectFusion则用深度相机做稠密实时重建。

深度学习时代，学习式方法进入SLAM：MegaSaM动态SfM所基于的深度SLAM用网络估计稠密对应，MASt3R-SLAM把前馈三维重建模型的点图预测作为SLAM前端，StreamVGGT流式4D、CUT3R持续状态重建等流式重建模型也在模糊SLAM与前馈重建的界限。

开放问题：动态场景、长时间运行的漂移与回环，以及学习式方法在资源受限设备上的实时性。
