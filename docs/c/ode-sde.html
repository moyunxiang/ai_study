常微分方程与随机微分方程

ODEs and SDEs

也叫：ODE　SDE　neural ODE　概率流ODE　扩散SDE　probability flow ODE　连续时间生成　数值求解器

在交互版中打开（看它长在树上的哪里）

常微分方程描述一个量如何随时间连续变化；随机微分方程在此基础上每一瞬间再加一点随机噪声。扩散模型和流模型的生成过程都可以写成这两类方程。

先要会：导数、偏导与梯度 泰勒展开 高斯分布 马尔可夫性与马尔可夫链

很多生成模型的思路是：从一团纯噪声出发，一点一点地把它“推”成一张图片。如果把每一步推得无限小，这个过程就变成了一条连续的轨迹，可以用微分方程描述。理解了这一点，扩散模型、流匹配以及各种快速采样器就有了统一的语言。

常微分方程（ODE）。

dx/dt = f(x, t)

给定起点x(0)，函数f规定了每一时刻x往哪个方向、以多快的速度移动（一个“速度场”），轨迹就完全确定了。大多数ODE没有解析解，要数值求解，最简单的是欧拉法：x_{t+h} = x_t + h·f(x_t, t)，本质上就是泰勒展开的一阶近似；步长h越小越准，但步数越多。

随机微分方程（SDE）。

dx = f(x, t) dt + g(t) dW

W是布朗运动：在很短的时间h内，它的增量服从均值为0、方差为h的高斯分布。对应的数值方法（欧拉–丸山法）是x_{t+h} = x_t + h·f(x_t, t) + g(t)·√h·ε，ε ~ N(0, 1)。每一步既有确定的漂移，又有随机抖动，所以同一个起点会走出不同的轨迹。离散化后，它就是一条马尔可夫性与马尔可夫链。

它出现在哪里。ResNet的残差更新x_{l+1} = x_l + F(x_l)恰好是步长为1的欧拉步，神经常微分方程据此把网络深度变成连续时间，用ODE求解器来做前向计算。Score SDE统一框架指出扩散模型的加噪过程是一个SDE，去噪生成是对应的逆向SDE，而且存在一个确定性的“概率流ODE”能得到相同的分布；DDIM的确定性采样就可以看作这个ODE的离散化。Flow Matching则直接学一个速度场，用ODE把噪声搬到数据上。采样步数的问题见噪声调度与采样步数。

例子

ODE：dx/dt = −x，x(0) = 1，精确解x(t) = e^{−t}，x(1) ≈ 0.368。用欧拉法、步长h = 0.5走两步：x = 1 → 1 − 0.5×1 = 0.5 → 0.5 − 0.5×0.5 = 0.25，误差较大；改用h = 0.1走10步，得到0.9¹⁰ ≈ 0.349，接近多了。SDE：dx = −x dt + dW，从x = 1出发，取h = 0.1，抽到ε = 0.5，则一步之后x = 1 − 0.1 + √0.1×0.5 ≈ 0.9 + 0.158 = 1.058；抽到别的ε就会得到别的结果。

容易误解的地方

  • “ODE采样是确定性的”指的是给定起始噪声后轨迹确定，整体仍是从随机噪声出发，生成结果依然多样。
  • 数值求解的步数和求解器的阶数决定速度与质量的权衡；减少扩散模型采样步数的很多工作，本质上是在换更好的ODE求解器。
