情感分析

Sentiment Analysis

也叫：情感分类　Sentiment Classification　观点挖掘　Opinion Mining　情绪分析　褒贬分析　倾向性分析　Polarity Classification　SST

在交互版中打开（看它长在树上的哪里）

判断一段文本表达的态度是正面、负面还是中性，常用于评论、舆情和用户反馈分析。

情感分析作为机器学习任务的起点是机器学习情感分类：用电影评论做实验，发现朴素贝叶斯、最大熵和SVM等通用分类器就能做得不错，但比普通话题分类难，因为否定、转折、反讽会改变整句的倾向。

神经时代，递归张量网络与情感树库发布了在句法树每个节点上标注情感的斯坦福情感树库，用递归网络按句法组合词义来处理否定；TextCNN句子分类用卷积网络加预训练词向量成为简单强基线；情感神经元发现只训练来预测评论下一个字符的语言模型里，有一个神经元几乎就是情感开关，这是无监督预训练能学到语义的早期证据。之后BERT类模型微调成为默认做法，研究转向细粒度（针对某个方面的情感）和跨领域、跨语言迁移。
