向量量化与离散token

Vector Quantization

也叫：VQ　码本　codebook　离散化　VQ-VAE　量化编码

在交互版中打开（看它长在树上的哪里）

准备一本有K个向量的“码本”，把每个连续向量替换成离它最近的码本向量，只记下编号。这样图像和音频就变成了一串离散token。

先要会：聚类 自编码器 范数与距离 潜空间

语言模型处理的是离散token，有成熟的训练和采样方法。如果图像、音频也能变成一串整数编号，就能直接拿自回归生成或掩码建模的办法来生成它们。向量量化（VQ）就是把连续向量变成离散编号的标准工具。它本是信号压缩里的老方法，思想和k-means聚类一样：用有限个中心点代表整个空间。

定义。码本是K个d维向量{e_1, …, e_K}。对编码器输出的向量z，取最近的那个：

k* = argmin_k ‖z − e_k‖，量化结果z_q = e_k*

只需存储编号k*，占log₂K个比特。距离见范数与距离。

怎么放进神经网络训练。VQ-VAE把它放在自编码器中间：编码器把图像变成一格一格的向量，每格量化成码本编号，解码器再从码本向量还原图像。问题是argmin不可导。解决办法是直通估计（straight-through）：前向用z_q，反向时把解码器传回来的梯度原样复制给z。损失为

L = 重建误差 + ‖sg[z] − e‖² + β‖z − sg[e]‖²

sg表示“这一项不传梯度”。第二项把码本向量拉向编码器输出，第三项（commitment损失，β常取0.25）让编码器别乱跑。

它出现在哪里。VQGAN加上对抗损失，让每个token代表更大的图像块；DALL·E把图像token和文本token拼在一起用Transformer生成。语音里神经音频编解码器、EnCodec用多级的残差向量量化，见声码器与音频编解码。码本学不好时会出现“码本坍塌”（大部分编号从不被用到），有限标量量化FSQ改成对每一维直接取整来绕开这个问题。

例子

码本有3个二维向量：e₁=(0,0)，e₂=(1,1)，e₃=(2,0)。编码器输出z=(1.2, 0.7)。到三者的平方距离分别是1.44+0.49=1.93、0.04+0.09=0.13、0.64+0.49=1.13，最近的是e₂，所以这一格记作token“2”，量化后的向量为(1,1)。

规模感：一张256×256的RGB图原始占256×256×3×8=1,572,864比特。若下采样16倍得到16×16=256个格子，码本大小1024（每个编号10比特），整张图只剩256个token、2560比特，约为原来的1/614。

容易误解的地方

  • 量化会丢信息，token化后的重建误差决定了生成质量的上限；码本越小、下采样越狠，细节损失越大。
  • 码本里很多向量可能从未被选中（码本坍塌），实际可用的词表比名义上的K小得多。
  • 直通估计只是近似梯度，不是真正的导数。
