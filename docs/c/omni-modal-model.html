全模态模型

Omni-Modal Model

也叫：Omni　Omni-modal　全模态大模型　Omni Model　端到端全模态　实时音视频交互　全双工　Full-Duplex　语音视频对话　Any-to-Any

在交互版中打开（看它长在树上的哪里）

一个模型同时听、看、读，并能用文字和语音实时回答，像和人视频通话一样交互。

GPT-4o全模态实时模型第一次把文本、图像和音频放进同一个模型端到端处理，语音回应延迟降到接近人类对话，此前的语音助手要串联识别、语言模型和合成三个系统。之前已有把多种模态对齐到同一空间的尝试（ImageBind、NExT-GPT任意模态、AnyGPT），但不支持实时交互。

开源社区随后跟进：VITA开源全模态做了早期的开源交互式全模态模型，MiniCPM-o 2.6全模态把实时音视频流交互放到手机级尺寸，Qwen2.5-Omni提出“思考者-说话者”分工结构，Qwen3-Omni和LongCat-Flash-Omni把规模推到大型混合专家模型。语音一侧的全双工对话（Moshi全双工语音对话）解决“边听边说、能被打断”的问题。当前难点是：加入语音和视频后如何不损失文本与视觉能力，以及流式输入下何时开口、如何记住长时间的音视频内容。
