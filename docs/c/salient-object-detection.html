显著性目标检测与抠图

Salient Object Detection and Matting

也叫：显著性目标检测　显著目标检测　显著性检测　salient object detection　SOD　saliency detection　视觉显著性　visual saliency　注视点预测　fixation prediction　显著性预测　saliency prediction　抠图　去背景　背景移除　background removal　U2-Net　U²-Net　BiRefNet　二分图像分割　dichotomous image segmentation　伪装目标检测　camouflaged object detection　图像抠图　image matting　S-measure　F-measure

在交互版中打开（看它长在树上的哪里）

找出图中最吸引注意的物体，输出与原图同大小的前景概率图。它不管物体类别，只回答“哪个是主体”，常用于一键抠图、去背景、构图裁剪，也作为其他任务的预处理。

先要会：分类、检测、分割 编码器-解码器

看一张照片时，人的目光会先落在某个“主角”上：草地上的一只狗、桌上的一杯咖啡。显著性检测试图让计算机预测这一点，有两个相关但不同的任务：

  • 注视点预测（视觉显著性）：预测人眼会看向图中哪些位置，输出一张模糊的热力图，用眼动仪数据评测。早期的Itti–Koch模型按颜色、亮度、方向的“中心—周边”对比计算显著图，是计算神经科学的经典模型。
  • 显著性目标检测（SOD）：把最显著的整个物体以清晰的边界分割出来，输出逐像素的前景概率图。日常说的“抠主体”就是它。

与其他分割任务的区别。语义分割要给每个像素一个类别（见分类、检测、分割），实例分割要分出每个物体并给类别；SOD是类别无关的二值分割，只回答“哪一部分是主体”。与之相近的有伪装目标检测（找出与背景融为一体的物体）、图像抠图（matting，还要估计头发丝等半透明区域的透明度），以及高分辨率二分图像分割。

方法演变。

  • 传统方法依赖手工先验：颜色对比度、“物体通常在图像中央”、“背景通常与图像边界相连”等。
  • 深度学习方法普遍采用编码器—解码器结构（见编码器-解码器和上采样与转置卷积）：用分类网络作编码器提取多尺度特征，解码器逐级上采样并融合浅层的边缘细节，形如全卷积网络FCN、U-Net；U²-Net把U形结构嵌套起来以兼顾全局语义与局部细节；BiRefNet等更新的方法针对高分辨率图像的精细边界。基于Transformer的骨干（见Vision Transformer）进一步改善了对“哪个物体是主体”的全局判断。
  • 通用分割模型Segment Anything能根据点或框提示分割任意物体，但需要提示；SOD模型则自动决定主体。

评测。常用F-measure（精确率与召回率的加权调和平均，见准确率、精确率、召回率与F1）、平均绝对误差MAE（概率图与真值掩码的逐像素平均差）、结构相似性度量S-measure和E-measure。

注意区分。可解释性里的“显著图”（梯度显著图、Grad-CAM与显著图）指的是“输入的哪些像素对模型预测影响最大”，与这里预测人类注意力或分割主体完全不同。

例子

一张商品照片：白色背景上一双运动鞋。SOD模型输出一张同尺寸的概率图，鞋子区域接近1、背景接近0。以0.5为阈值得到二值掩码，与人工标注比较：若预测正确的鞋子像素占预测前景的95%（精确率），覆盖了真实鞋子像素的90%（召回率），F-measure（β² = 0.3）约为0.94，逐像素MAE约为0.02。

容易误解的地方

  • “显著”本身有歧义：一张图里有两个人时，哪一个是主体，不同标注者可能意见不同，数据集通常只标一个答案。
  • 在复杂背景、多主体或主体很小时，模型容易把背景中的高对比区域误判为主体。
