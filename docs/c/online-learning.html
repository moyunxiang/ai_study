在线学习与遗憾

Online Learning and Regret

也叫：在线学习　online learning　在线凸优化　online convex optimization　OCO　遗憾　regret　无遗憾学习　no-regret learning　遗憾界　regret bound　在线梯度下降　online gradient descent　OGD　乘性权重　multiplicative weights　Hedge算法　专家建议　prediction with expert advice　FTRL　follow the regularized leader　流式学习　streaming learning

在交互版中打开（看它长在树上的哪里）

数据一条一条到来、每来一条就要先做预测再更新的学习设定。它不假设数据独立同分布，用“遗憾”衡量表现：和事后看来最好的固定策略相比，累计多亏了多少。

先要会：梯度下降 凸函数与凸优化

广告点击率预测每秒都有新数据涌入，推荐系统要跟上用户兴趣的变化，股票、博弈对手甚至可能故意与你作对。这类问题里没有固定的训练集，数据按顺序到来，模型必须边用边学。这就是在线学习。

协议。每一轮t：学习者选择一个决策w_t（例如一组权重）；环境揭示损失函数ℓ_t；学习者付出ℓ_t(w_t)，再据此更新。数据可以来自任意（甚至对抗性的）序列，不要求独立、条件独立与独立同分布。

遗憾（regret）。既然没有“真实分布”，就和事后最好的固定决策比：

Regret_T = Σ_t ℓ_t(w_t) − min_w Σ_t ℓ_t(w)

如果遗憾随T亚线性增长（如O(√T)），平均每轮的遗憾就趋于0，说明学习者长期来看不比事后诸葛亮差。

典型算法。

  • 在线梯度下降：每轮沿当前损失的梯度走一步w ← w − η_t∇ℓ_t(w_t)。对凸损失、步长按1/√t衰减时，遗憾为O(√T)。随机梯度下降可以看作它在i.i.d.数据上的特例，见随机梯度下降与小批量。
  • 专家加权（Hedge / 乘性权重）：有N个专家给建议，每轮按权重混合，犯错的专家权重乘以一个小于1的因子，遗憾O(√(T log N))。
  • FTRL：每轮选择使“历史累计损失 + 正则项”最小的决策，AdaGrad的逐坐标自适应步长就是在这一类框架下推导出来的；它的一个变体FTRL-Proximal曾被广泛用于工业界的点击率预测。
  • 感知机是最早的在线学习算法之一：分错一个样本就修正一次。

和其他领域的联系。

  • 老虎机是只能看到所选动作损失的在线学习，UCB1、对抗老虎机EXP3给出了遗憾界，Lai–Robbins遗憾下界给出了下界，见探索与利用。
  • 模仿学习：DAgger把模仿学习化归为无遗憾在线学习，从而解决了行为克隆的误差累积。
  • 博弈：自我对弈中双方都用无遗憾算法时，平均策略收敛到均衡，这是反事实遗憾最小化CFR和遗憾匹配求解扑克的理论基础，见博弈论基础与纳什均衡。
  • 持续学习、测试时适应关心的也是“数据按顺序到来”，但更关注遗忘旧知识的问题，见持续学习与灾难性遗忘。

例子

两个天气预报专家，连续4天：A说对、对、错、对，B说错、对、对、错。Hedge让每说错一次权重减半，初始权重都是1：第1天后A = 1、B = 0.5；第2天两人都对，不变；第3天A错，变为A = 0.5、B = 0.5；第4天B错，变为A = 0.5、B = 0.25。学习者每天按当时的权重混合两人的预测。事后看A最好（只错1次），Hedge的理论保证是：学习者的累计错误最多比A多出一个与log N和√T同阶的量。

容易误解的地方

  • “在线学习”在工程语境里也指“模型上线后持续用新数据更新”，和这里的理论框架相关但不完全相同。
  • 遗憾小只说明不比最好的固定决策差，如果环境在变化，最好的固定决策本身可能就很差，这时需要“动态遗憾”等更强的标准。
