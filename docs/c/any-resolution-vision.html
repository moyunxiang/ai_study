任意分辨率与原生分辨率

Any-Resolution / Native-Resolution Vision Encoding

也叫：AnyRes　动态分辨率　Dynamic Resolution　原生分辨率　Native Resolution　动态切块　Dynamic Tiling　高分辨率VLM　Patch n' Pack　2D-RoPE

在交互版中打开（看它长在树上的哪里）

不再把每张图缩放到固定的小尺寸，而是按原始大小和长宽比编码，图越大token越多，以便看清文档和小字。

早期VLM把图统一缩成224或336像素见方，文档、图表上的小字和细节因此丢失。两条路线解决这个问题。一是切块：把高分辨率图按长宽比切成若干块分别编码，再加一张缩略全图，代表是LLaVA-NeXT任意分辨率的AnyRes、InternVL 1.5的动态高分辨率和DeepSeek-VL2的动态切块。二是原生分辨率：编码器直接接受任意大小的图，NaViT任意分辨率提出把不同尺寸图像的块打包训练，Qwen2-VL与开源VLM用2D旋转位置编码实现，Pixtral 12B、VideoLLaMA 3、Kimi-VL也采用类似做法。

代价是视觉token数随分辨率快速增长，计算和延迟随之上升，于是有了视觉token压缩（FastV视觉token剪枝）和输出更少token的编码器（FastVLM高效编码）。另一个副作用是：既然模型能读高分辨率文字图，就可以把文本渲染成图来压缩上下文（DeepSeek-OCR光学压缩、Glyph视觉文本压缩）。
