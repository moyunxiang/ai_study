视觉分词器

Visual Tokenizer

也叫：图像分词器　Image Tokenizer　离散视觉token　视觉词表　VQ Tokenizer　统一视觉分词器　Unified Tokenizer　语义分词器　图像离散化

在交互版中打开（看它长在树上的哪里）

把一张图变成一串离散编号（像文字的词一样），让语言模型可以用同一种“下一个词预测”来读图和画图。

连续特征适合理解，但要让模型生成图像，最直接的办法是把图像也离散成token。VQ-VAE和VQGAN学一个码本，把每个图块映射成最近的码字编号，这是重建导向的分词器，细节保留好但语义弱。SEED视觉分词器让离散token对齐文本语义，便于LLM理解；Chameleon早期融合、Emu3纯下一词预测、AnyGPT把这类token和文字放进同一序列自回归训练。

核心矛盾是重建（像素细节）和语义（理解）难以兼得，理解与生成统一Janus因此干脆为理解和生成各用一套编码。UniTok统一分词器认为冲突来自码本容量太小，用多码本量化同时训重建和对比目标，MMaDA多模态扩散则把离散图像token用于扩散式统一模型。争论仍在继续：离散token是否会成为生成质量的瓶颈，连续特征加扩散头（Transfusion）是不是更好的路线。
