元强化学习

Meta-Reinforcement Learning

也叫：元强化学习　meta-RL　meta reinforcement learning　meta-reinforcement learning　学会强化学习　learning to reinforcement learn　快速适应　fast adaptation　贝叶斯自适应MDP　Bayes-adaptive MDP　BAMDP　任务推断　task inference　少样本强化学习　few-shot RL

在交互版中打开（看它长在树上的哪里）

在一大批相关任务上训练，目标不是学会某个任务，而是学会“怎样快速学会新任务”：遇到没见过的任务时，只需很少几次交互就能适应。

先要会：元学习 策略梯度 循环网络与隐状态

普通RL智能体换一个迷宫就要从头再试几百万次。人却能把在很多迷宫里积累的经验迁移过来：先探索一下，记住出口在哪，第二次直接走过去。元强化学习把这种“学会学习”作为训练目标，是元学习在决策问题上的版本。

问题设定。有一个任务分布p(T)，例如目标位置不同的导航任务、质量不同的机械臂、奖励不同的游戏关卡。训练分两层：

  • 内层（适应）：面对一个具体任务，用少量交互（几个回合）调整行为。
  • 外层（元训练）：在许多任务上优化“内层适应之后的表现”。

评估时给一个训练中没见过的任务，看几次交互之后能做多好。

三类方法。

  • 基于梯度：MAML元学习学一组初始参数，使得在新任务上做几步策略梯度就能大幅提升。
  • 基于记忆（黑箱）：RL²元强化学习和深度元强化学习让一个循环网络读入跨回合的历史(s, a, r, …)，在多个回合中保持隐状态不重置。外层用普通RL训练这个网络，内层的“学习算法”就隐含在隐状态的演化里，这正是上下文强化学习的起点。
  • 基于任务推断：把任务看作一个未知的隐变量，智能体一边行动一边推断它是哪个任务。PEARL离策略元RL用概率编码器推断任务表示并支持离策略训练；VariBAD贝叶斯自适应近似贝叶斯最优地平衡“为了弄清任务而探索”和“利用已知信息”，对应贝叶斯自适应MDP的思想。

规模化。AdA人类时间尺度适应在大量程序生成的任务上训练大型记忆模型，能在人类时间尺度内适应新任务；算法蒸馏与上下文RL把一个RL算法的整段学习过程蒸馏进序列模型。大语言模型在上下文里根据反馈改进答案，也被看作一种元学习出的能力。

例子

训练任务：二维平面上走到一个未知的目标点，目标位置每个任务随机。元训练后的RL²智能体在新任务的第1个回合里先绕圈搜索，碰到奖励后记住位置；第2、3个回合直接走过去，平均步数从约50步降到约10步。普通的单任务策略则只能学会走到训练时的某个平均位置。这里的步数是说明用的设定，不是某篇论文的实测值。

容易误解的地方

  • 元RL的泛化只在训练任务分布附近成立；新任务若超出分布（例如从导航换成抓取），通常不再能快速适应。
  • 黑箱方法的“内层学习”无法直接检查，它学到的往往是针对训练分布的搜索策略，而不是通用的RL算法。
