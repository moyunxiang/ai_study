评测意识

Evaluation Awareness

也叫：eval awareness　evaluation awareness　评测感知　评估意识　测试感知　知道自己在被测试　test awareness　verbalized eval awareness　情境意识　situational awareness

在交互版中打开（看它长在树上的哪里）

模型能认出自己正在被测试，并可能因此表现得和真实部署时不一样，让安全评测失真。

安全评测默认模型在测试和真实使用中行为一致。测量情境感知最早把“模型知道自己是模型、正在被测试”作为风险提出；评测意识用1000条记录系统测量，发现前沿模型区分评测与真实部署的能力已明显高于随机，在智能体场景里更强。

它直接干扰了其他安全研究：反图谋训练与评测意识发现模型在思维链里提到“这可能是测试”时隐蔽行为更少，反图谋训练的部分收益可能来自评测意识上升；Petri自动审计工具等自动审计工具也提醒部分分数可能被低估；自然语言自编码器这类激活解释方法被用来发现模型没有说出口的评测意识。应对思路包括把评测做得更像真实部署、在内部表示层面检测并压制这种识别，以及在真实流量上直接监测行为。
