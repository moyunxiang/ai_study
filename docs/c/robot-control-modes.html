位置、速度、力矩与力控制

Robot Control Modes: Position, Velocity, Torque, Force

也叫：位置控制　position control　速度控制　velocity control　力矩控制　torque control　扭矩控制　力控制　force control　混合位置力控制　hybrid position/force control　PD控制　PD controller　柔顺控制　compliance control　控制模式　control modes　关节位置目标　阻抗控制　impedance control　刚度控制　stiffness control

在交互版中打开（看它长在树上的哪里）

机器人关节或末端接受什么样的指令：位置控制给目标位置，速度控制给目标速度，力矩控制直接给电机力矩，力控制调节与环境的接触力；阻抗控制让机器人像弹簧一样“软硬可调”。

先要会：控制回路与控制频率 自由度、运动学与本体感知

同一个“把手移到那里”的意图，可以用完全不同的方式下达给机器人。选哪种控制模式，决定了机器人碰到东西时是硬顶、是退让，还是精确地施加一个力；也决定了学习型策略应该输出什么。

位置控制。指令是目标关节角q*（或末端目标位姿），底层控制器（通常是高频的PD或PID控制，见控制回路与控制频率）负责尽快跟上：τ = Kp·(q* − q) − Kd·q̇。工业机械臂默认使用这种模式，精度高、简单可靠，但增益很高时非常“硬”，碰到障碍会产生很大的力。

速度控制。指令是目标关节速度，适合遥操作和视觉伺服等需要连续调整的场景。

力矩控制。直接指定每个关节电机的力矩τ。要让机器人按期望运动，控制器必须知道机器人的动力学（质量、惯量、重力，见机器人动力学与运动方程）来计算所需力矩。好处是可以精确控制与环境的交互，而且对外界碰撞天然“柔顺”；腿足机器人和协作机械臂越来越多地支持这种模式。

力控制与混合控制。用末端的力/力矩传感器测量接触力，调节使其等于目标值，例如擦桌子时保持10牛的压力。混合位置/力控制在某些方向控位置（沿桌面移动）、在其他方向控力（垂直于桌面压住）。

阻抗控制。不直接控位置或力，而是规定二者之间的关系：让末端表现得像一个刚度为K、阻尼为D的弹簧-阻尼器，F = K·(x* − x) − D·ẋ。K大则硬、K小则软，接触时既不会硬顶也不会完全听任推动，见阻抗控制。在任务空间设计这类控制律的系统方法见操作空间控制OSC。

对机器人学习的意义。多数学习型策略以10到50Hz输出目标关节位置，交给1kHz左右的PD控制器跟踪，例如四足敏捷步态Sim2Real这类腿足工作；PD增益本身就隐含了一种阻抗，对仿真到现实的迁移影响很大（见仿真到现实的差距）。直接输出力矩的策略更灵活，但对仿真动力学的准确性要求更高。

例子

一个关节的PD位置控制：Kp=50牛·米/弧度，Kd=2牛·米·秒/弧度。目标角1.0弧度，当前0.8弧度、速度0.5弧度/秒，输出力矩τ = 50×0.2 − 2×0.5 = 9牛·米。若有人用手挡住关节使它停在0.8弧度，PD会持续输出10牛·米；把Kp调到5，挡住时只有1牛·米，关节就“软”了，代价是跟踪误差变大。

容易误解的地方

  • 论文里说策略输出“位置”时，实际行为高度依赖底层PD增益；复现时增益不同，同一个策略可能完全不能用。
  • 力矩控制的效果依赖于动力学模型和电机的力矩精度，很多廉价电机只能做位置控制。
