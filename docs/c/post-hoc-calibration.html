事后校准：Platt缩放、温度缩放与保序回归

Post-hoc Calibration: Platt, Temperature and Isotonic

模型训练好之后，在验证集上再学一个从“原始分数”到“可靠概率”的映射：Platt缩放拟合一条sigmoid，温度缩放只调一个温度，保序回归拟合任意单调的阶梯函数。

先要会：模型校准 逻辑回归

模型校准说明了什么是“概率可信”。很多模型输出的分数并不满足这一点：支持向量机输出的是到分类边界的距离，根本不是概率；朴素贝叶斯分类的概率往往被推向0或1；现代深度网络普遍过度自信（神经网络校准）。重新训练模型代价大，于是常用事后校准：模型不动，只在一份独立的验证集上学一个单调的映射g，把原始分数s变成p = g(s)。

Platt缩放。假设校准曲线是sigmoid形状：

p = σ(a·s + b)

用验证集上的标签最大化似然，学两个参数a和b，本质上是在一维分数上做一次逻辑回归。它最早用于把SVM的输出变成概率。

温度缩放。多分类神经网络的简化版：所有logits除以同一个温度T，p = softmax(z / T)，只学一个参数（见Softmax与logits）。它不改变哪一类得分最高，所以准确率不变，只修正置信度。参数少，不容易在小验证集上过拟合，是深度网络最常用的事后校准方法。

保序回归（isotonic regression）。不假设任何形状，只要求映射是单调不减的：在验证集上找一个阶梯函数g，使Σ(g(s_i) − y_i)²最小且g单调。经典解法是“相邻违序合并”（PAV）：从左到右扫描，遇到后面的平均值比前面小，就把它们合并成一段取平均。它比Platt灵活，能纠正任意形状的偏差，但需要更多验证数据，否则容易过拟合，而且输出是分段常数。

怎么选。验证数据少或偏差形状接近sigmoid时用Platt或温度缩放；数据多、偏差形状复杂时用保序回归。评估效果用可靠性图和ECE，同时看对数损失或Brier分数，后者同时奖励校准和区分能力（见二元交叉熵与sigmoid输出）。

相关方法。保形预测走的是另一条路：不修正概率，而是给出带覆盖率保证的预测集合。直方图分箱法（把分数分箱、每箱用实际正例比例作为概率）是保序回归的更粗糙版本。

例子

验证集上按分数排序的8个样本，标签为(0, 0, 1, 0, 1, 1, 0, 1)。保序回归从左到右：前两个为0、0；第3个1与第4个0违序，合并为0.5、0.5；接着1、1；第7个0与前面的1违序，合并第5到7个为2/3；最后一个为1。得到单调的(0, 0, 0.5, 0.5, 0.67, 0.67, 0.67, 1)。

容易误解的地方

  • 校准集必须独立于训练集；在训练集上校准，过拟合的模型看起来会特别“准”。
  • 分布发生变化后，原来学到的校准映射可能失效，需要用新分布的数据重新校准（见分布偏移）。
