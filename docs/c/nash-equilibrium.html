博弈论基础与纳什均衡

Game Theory and Nash Equilibrium

也叫：零和博弈　zero-sum game　极小极大定理

在交互版中打开（看它长在树上的哪里）

多方博弈中的一组策略，使得在其他人不变的前提下，任何一方单独改变自己的策略都得不到更多好处。

先要会：随机变量与概率分布 期望与方差

单个智能体优化的是固定的目标。但下棋、打扑克、GAN里的生成器与判别器、多个智能体抢资源时，你的最优选择取决于对方怎么做，对方的最优选择又取决于你。这时“最优”需要新的定义，博弈论就是研究它的数学。

基本要素：若干玩家，每人有一个策略集合，每种策略组合给每个玩家一个收益。纯策略是确定地选一个动作；混合策略是动作上的概率分布。

纳什均衡：策略组合(s₁*, …, s_n*)使得对每个玩家i，u_i(s_i*, s_−i*) ≥ u_i(s_i, s_−i*)对任意s_i成立。纳什均衡（1950）证明了：任何有限博弈，只要允许混合策略，至少存在一个纳什均衡。

两人零和博弈是特例：一方所得即另一方所失。《博弈论与经济行为》与极小极大中的极小极大定理说明此时“最大化自己的最坏情况”与“最小化对手的最好情况”数值相等，纳什均衡策略就是极小极大策略，打出它的一方在期望上不会输给任何对手。博弈树搜索：minimax与MCTS里的minimax就是在完全信息博弈中求这个值。

在AI里：

  • 扑克是不完全信息的零和博弈，反事实遗憾最小化CFR通过反复自我对弈、累积“后悔值”逼近纳什均衡，Libratus据此在一对一无限注德州扑克中击败职业选手。
  • 生成对抗网络GAN的训练目标是一个两人极小极大博弈，理论上的最优点是纳什均衡，实践中梯度下降常在均衡附近振荡，见对抗训练。
  • 自我对弈与PSRO博弈论元求解等方法维护一个策略池，求池内的元博弈均衡，AlphaStar的联赛训练沿用了这一思路。

例子

囚徒困境。双方都合作各得−1，都背叛各得−2，一方背叛一方合作时背叛者得0、合作者得−3。无论对方怎么做，背叛都比合作多1分，所以(背叛, 背叛)是唯一的纳什均衡，双方各得−2，比都合作的−1还差：均衡不等于整体最好。

石头剪刀布的均衡是三者各1/3。如果对手偏离成石头40%、布30%、剪刀30%，你出布的期望收益 = 0.4×1 + 0.3×0 + 0.3×(−1) = 0.1 > 0，可以剥削他。

容易误解的地方

  • 纳什均衡只保证“单方偏离无利可图”，不保证结果对所有人好，也不保证唯一。
  • 多人或一般和博弈中，打均衡策略不再保证不输；Pluribus多人扑克在六人扑克中用的方法在理论上就没有这种保证。
  • 求一般博弈的纳什均衡在计算上很难，实际算法求的多是近似均衡。
