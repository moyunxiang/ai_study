推测解码家族

Speculative Decoding Methods

也叫：投机解码　投机采样　推测采样　speculative sampling　draft-and-verify　草稿-验证　草稿模型　draft model　drafter　并行解码　多token预测　MTP　lossless acceleration　无损加速

在交互版中打开（看它长在树上的哪里）

先用便宜的办法一次猜出几个词，再让大模型一次前向并行验证，猜对的直接收下，输出分布与逐词生成完全一样。

大模型逐词生成时，每一步都要把全部权重从显存读一遍，GPU算力大多闲着。分块并行解码最早提出“先猜后验”：一次预测多个未来位置，再由模型并行核对。推测解码给出了带接受-拒绝规则的推测采样，证明输出分布可以与原模型完全一致，从此加速变成“怎么造一个又快又准的草稿器”。

路线大致有三条：独立的小草稿模型；挂在大模型上的轻量头，如Medusa多解码头的多头、EAGLE特征级推测解码和EAGLE-3推测解码读取目标模型特征的自回归草稿层；以及训练时就让模型多预测几个词的多token预测MTP。2026年的DFlash块扩散草稿进一步用块扩散模型一次前向出整块草稿。

当前争论集中在：批量越大、GPU越忙，推测解码的收益越小；每个目标模型都要单独训练草稿器；推理模型的长思维链是否更适合推测。
