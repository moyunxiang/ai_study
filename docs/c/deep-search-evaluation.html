考智能体能否在网上长时间、多步骤地搜索、交叉核对，找到难找但容易验证的信息。

GAIA较早要求智能体结合浏览和工具回答对人简单、对模型难的问题；SimpleQA事实性测短事实问答的准确率与幻觉。Deep Research类产品出现后，需要更难的考题：BrowseComp用1266道“先有答案再反向出题”的难找信息题，答案短、易核对；xbench长青评测推出面向中文互联网的DeepSearch评估集并持续更新；Humanity's Last Exam也常在允许搜索的设置下报告。

这类评测的难点在于：网页内容随时间变化，标准答案可能失效；题目一旦公开，答案也会出现在网上；而真实研究任务需要写长篇综合报告，短答案题只测到其中“找到信息”这一环。
