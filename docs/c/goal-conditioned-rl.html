目标条件强化学习

Goal-Conditioned Reinforcement Learning

也叫：GCRL　goal-conditioned RL　目标条件RL　通用值函数　UVFA　后见重标记　hindsight relabeling　自监督RL　self-supervised RL

在交互版中打开（看它长在树上的哪里）

让同一个策略接收“要达到哪个目标”作为输入，学会到达任意指定状态，常用事后改写目标来摆脱稀疏奖励。

很多任务的奖励只有“到达目标=1，否则=0”，极其稀疏。通用值函数近似UVFA提出把目标也作为价值函数的输入，一个网络覆盖所有目标；后见经验回放HER的关键技巧是事后重标记：没到达原目标的轨迹，就当作“到达了实际终点”这个目标的成功示范，失败经验也能用来学习。

对比RL（目标条件）把目标条件价值学习改写成对比学习，不需要手写奖励；1000层网络的自监督RL在这一自监督设定下把网络加深到1000层，被视为深度RL的规模化的代表证据。它也是机器人操作与导航里常用的问题形式。
