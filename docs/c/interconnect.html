互连：从芯片到机柜到集群

Interconnect: Chip, Rack, Cluster

也叫：互联　NVLink　InfiniBand　RDMA　网络拓扑　片间互连　scale-up　scale-out

在交互版中打开（看它长在树上的哪里）

芯片之间怎样传数据：封装内靠硅中介层，机柜内靠NVLink等专用链路，机柜之间靠InfiniBand或以太网；越往外带宽越低，集群设计就是按这几层安排通信。

先要会：分布式训练：数据并行与模型并行

一块GPU再快，训练前沿模型也要上万块一起工作，而它们每一步都要交换梯度或激活值（见分布式训练：数据并行与模型并行）。如果数据传得慢，GPU就只能停下来等。所以AI集群的性能一半在芯片，一半在“线”。互连可以按距离分成四层，每往外一层，带宽大约降一个数量级。

1. 封装内（毫米级）。计算芯片和HBM高带宽内存放在同一块硅中介层上，几千根微细导线并排连接，见CoWoS先进封装。Blackwell的B200由两颗计算芯片拼成，两者之间的芯片间链路带宽官方称达10TB/s，让软件把它当作一块GPU。

2. 机器内与机柜内（米级）。传统服务器用PCIe连接CPU和GPU，PCIe 5.0 x16单方向约64GB/s。NVIDIA的NVLink与NVSwitch是GPU之间的专用链路，H100每卡900GB/s（双向合计）；NVSwitch交换芯片让8块卡两两全速互通。Blackwell与整机柜液冷这一代更进一步，GB200 NVL72用铜缆背板把整个机柜的72块GPU连成一个NVLink域，每卡1.8TB/s、全柜130TB/s，官方称它可以“像一块巨大的GPU”一样工作。张量并行这种每层都要通信的切法只能在这一层做。开放标准的对应物是UALink开放互连。

3. 机柜之间（几十到几百米）。每块GPU配一张网卡，经多层交换机组成胖树网络。主流是InfiniBand（NVIDIA收购NVIDIA收购Mellanox得来）和针对AI改造的以太网，如RoCE：以太网上的RDMA、Spectrum-X AI以太网、Ultra Ethernet联盟。单卡网络带宽400–800Gb/s，也就是50–100GB/s，比NVLink低一个数量级。远距离链路要用光模块把电信号转成光，共封装光学交换机把光器件直接封装到交换芯片旁边以省电。

4. 数据中心之间（公里级）。超大训练开始跨楼甚至跨园区，带宽更低、延迟更高，需要DiLoCo低通信训练这类低通信训练算法。

它出现在哪里：Google的TPU v4与光路交换用光路交换机动态重连几千块芯片；华为的CloudMatrix 384超节点用大量光互连把384颗昇腾连成一个超节点，以弥补单芯片性能差距。

例子

传输14GB数据（7B模型的一份BF16梯度）需要多久：

  • NVLink 5（单方向约900GB/s）：约16毫秒
  • PCIe 5.0 x16（单方向约64GB/s）：约0.22秒
  • 400Gb/s网卡（50GB/s）：约0.28秒

相差十几倍。所以并行策略的通用规则是：通信最频繁的张量并行放在NVLink域内，通信较少的数据并行放在跨机柜网络上。

容易误解的地方

  • 网络带宽常用比特每秒（Gb/s），显存和NVLink常用字节每秒（GB/s），相差8倍，比较前要换算。
  • “双向合计”和“单方向”的数字也差2倍，厂商宣传通常给合计值。
  • 带宽不是唯一指标：all-reduce由大量小消息组成时，延迟和拥塞控制同样决定速度。
