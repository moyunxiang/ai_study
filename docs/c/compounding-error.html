复合误差

Compounding Error

也叫：复合误差　compounding error　compounding errors　误差累积　模型误差累积　error accumulation　误差滚雪球　模型rollout误差　model rollout error　漂移　drift

在交互版中打开（看它长在树上的哪里）

每一步只有很小的误差，但下一步的输入来自上一步有误差的输出，误差就会越滚越大。它是行为克隆、学到的环境模型做长时域rollout、自回归生成长序列时的共同难题。

先要会：模仿学习与行为克隆 基于模型的强化学习 分布偏移

监督学习里，一个样本预测错了不影响下一个样本。序列决策里不同：智能体（或模型）自己的输出会成为下一步的输入。一点小偏差把它带到训练时没见过的地方，在那里误差更大，偏差更大……这就是复合误差（compounding error）。

在行为克隆里。策略只在专家走过的状态上训练（见模仿学习与行为克隆）。设每一步在专家分布上犯错的概率为ε，一旦犯错就进入陌生状态、之后可能一直错下去，时域为T的任务里总代价最坏可达O(ε·T²)量级，而不是监督学习直觉中的O(ε·T)。这一分析来自Forward Training与SMILe的工作，本质是训练和测试的状态分布不一致，即协变量偏移（见分布偏移）。DAgger让专家在学习者自己走到的状态上补标签，把误差降回O(ε·T)；预测一整段动作而不是一步也能减少决策次数，见动作表示：离散token、连续动作与动作块。

在模型rollout里。学到的动力学模型ŝ' = f(s, a)一步误差很小，但在模型里连续模拟k步，每步的输入都是上一步的预测，误差逐步放大，模拟出的轨迹可能很快变得不符合物理。规划器还会主动寻找模型出错的地方（见交叉熵方法与随机射击）。对策：MBPO只从真实状态出发做很短的模型rollout；PETS概率集成模型用模型集成估计不确定性；在隐空间做多步预测训练，让模型直接学会多步准确，如TD-MPC。

在自回归生成里。语言模型的曝光偏差（见Teacher forcing与曝光偏差）、长视频生成随时间漂移、世界模型长时间想象后画面崩坏，都是同一个现象。

例子

行为克隆：T=100步的任务，每步出错概率ε=1%。按监督学习的直觉，预计约1次错误；但若一旦出错之后每步都错，第t步出错的期望代价约为1 − 0.99^t，累加100步约为37次错误，比1次多得多（最坏情形的上界是εT²=100）。

模型rollout：一步预测的相对误差1%，若每步误差按1.1倍放大，10步后约为1% × 1.1^10 ≈ 2.6%，50步后约为1.17 × 100% ≈ 117%，已经和真实轨迹无关。

容易误解的地方

  • 一步预测误差（验证集上的均方误差）小，不代表长时域rollout可用，评估模型要看多步误差。
  • 复合误差和分布偏移常被混用：后者是原因（输入分布变了），前者是在序列中的累积后果。
