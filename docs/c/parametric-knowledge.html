参数化知识与上下文知识

Parametric vs Contextual Knowledge

也叫：parametric knowledge　参数化知识　参数知识　contextual knowledge　上下文知识　closed-book QA　闭卷问答　open-book QA　开卷问答　开卷　闭卷　knowledge conflict　知识冲突　parametric memory　参数记忆　模型记忆　知识密集型任务　knowledge-intensive tasks

模型的知识有两个来源：训练时存进权重里的参数化知识，和推理时放进上下文的上下文知识。只靠前者答题叫闭卷，允许查资料叫开卷；两者冲突时模型听谁，是检索增强的核心问题之一。

先要会：语言模型 检索与向量数据库

问模型“《红楼梦》的作者是谁”，它不查任何资料就能答出曹雪芹，这个知识存在它的参数里，叫参数化知识（parametric knowledge）。如果在提示里附上一篇文章再提问，答案来自这篇文章，那是上下文知识（contextual knowledge）。区分这两种来源，是理解检索增强、幻觉和知识更新的基础。

闭卷与开卷。

  • 闭卷问答（closed-book QA）：只给问题，模型只能靠参数化知识回答。参数里能装多少知识用T5在问答数据上微调后闭卷作答，发现大模型能在不检索的情况下答对相当比例的开放域问题，而且模型越大越好。
  • 开卷问答（open-book QA）：先检索相关段落，再基于段落回答，即开放域问答的检索-阅读范式和检索增强生成RAG。

两种知识的特点。

  • 参数化知识：不需要额外资料，速度快；但会过时（见知识截止日期），对长尾事实记得不牢（见Zipf定律与Heaps定律），而且无法给出出处，记错时就产生幻觉。
  • 上下文知识：可随时更新、可溯源（见有据生成与引用）；但受上下文窗口限制，依赖检索质量，资料本身也可能错误或被投毒。

知识冲突。当上下文与参数记忆不一致时（例如给模型一篇“某国首都已迁到另一个城市”的文章），模型可能固执地沿用记忆，也可能盲从上下文。知识冲突：变色龙或树懒研究了这种行为，发现模型在上下文证据连贯、有说服力时容易接受与记忆相反的信息，但当上下文同时包含支持记忆的证据时，又倾向于偏向自己的记忆。理想的行为取决于场景：RAG通常希望模型以资料为准，而面对可能被篡改的网页则需要保持判断。

修改参数化知识。重新训练太贵，于是有了知识编辑：定位存储某条事实的参数（研究认为与Transformer的前馈层密切相关）并直接修改。

例子

问题：“珠穆朗玛峰有多高？”

  • 闭卷：模型凭记忆回答“8848米”，这是较早的测量值。
  • 开卷：检索到“2020年中尼两国联合宣布珠峰最新高程为8848.86米”的段落，模型回答8848.86米并标明出处。

冲突实验：在上下文中放一段虚构文字“最新测量显示珠峰高9100米”，有的模型会照着回答9100米（盲从上下文），有的坚持8848米（固守记忆）。

容易误解的地方

  • 闭卷答对不代表模型“理解”了这条知识，可能只是记住了训练数据中的原句；换一种问法就答错的情况很常见。
  • 开卷并不能完全消除幻觉，模型仍可能忽略资料或混入记忆中的内容。
