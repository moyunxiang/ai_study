早期的WebShop和GAIA把工具使用嵌在购物、问答任务里；BFCL函数调用榜专门考函数调用，主要检查单次调用的名字和参数是否正确；τ-bench和τ²-bench加入与模拟用户的多轮对话和业务规则，并用数据库最终状态判分。

模型上下文协议MCP成为工具接入标准后，评测转向真实服务器和长流程：Toolathlon工具十项全能接入32个软件、604个工具，每题用脚本检查环境状态；MCP-Atlas用36个真实MCP服务器、1000个不点名工具的任务，并按事实覆盖率判分、区分工具失败与认知失败。争论点在于：模拟环境可复现但不真实，真实服务器真实却会随时间变化；而智能体基准清单ABC指出，判分脚本本身的漏洞可能让分数偏差很大。
