时间步嵌入与条件注入

Timestep Embeddings and Conditioning

也叫：时间步嵌入　timestep embedding　time embedding　噪声水平嵌入　noise level embedding　条件注入　conditioning　adaLN　adaLN-Zero　AdaGN　自适应层归一化　adaptive layer norm　交叉注意力条件　cross-attention conditioning　文本条件

扩散模型的去噪网络必须知道“现在噪声有多大”和“要画什么”。噪声水平t先编码成向量（时间步嵌入），常通过对特征做缩放和平移（AdaGN、adaLN）注入网络；文本等条件则常通过交叉注意力注入。

先要会：位置编码 扩散：前向加噪与反向去噪 注意力机制

同一张模糊的输入，如果噪声水平很高，网络应该大刀阔斧地猜整体结构；噪声水平很低时，只该修补细节。所以去噪网络ε_θ(x_t, t, c)除了图像x_t，还有两个输入：噪声水平t和条件c（类别、文本、图像）。怎样把它们送进一个卷积网络或Transformer，是扩散模型架构的核心细节。

时间步嵌入。t是一个标量（如0到1000的整数，或连续的噪声水平σ）。直接作为一个数输入效果不好，通常像位置编码那样，用一组不同频率的正弦和余弦把它展开成几百维的向量，再经过一个小的多层感知机，得到嵌入向量e_t。

怎么注入。

  • 相加：DDPM把e_t经线性层投影后加到每个残差块的特征上。
  • 自适应归一化：用e_t（以及类别嵌入）预测每个通道的缩放γ和平移β，对归一化后的特征做γ·h + β。这与FiLM特征调制的特征调制是同一种思想。扩散超越GAN称之为AdaGN，Diffusion Transformer在Transformer中用adaLN，并把残差分支的门控系数初始化为0（adaLN-Zero），训练更稳定。

文本等复杂条件。一段文字编码后是一串token向量，一个缩放平移装不下这么多信息。潜空间扩散LDM在U-Net的各层加入交叉注意力：图像特征作为查询，文本token作为键和值（见注意力机制），每个空间位置都能“查阅”提示里的相关词。Stable Diffusion 3的MM-DiT则把文本token和图像token拼接在一起做联合自注意力。全局性的信息（例如池化后的文本向量、图像尺寸）仍常和时间步嵌入合并，走adaLN这条路。

为什么重要。条件注入方式决定了模型“听不听话”，也决定了能否在不改主干的情况下增加新的控制信号，例如额外的结构图或参考图像。

例子

嵌入维度为4时，t=500的正弦编码可以取频率(1, 1/100)：[sin(500), cos(500), sin(5), cos(5)] ≈ [−0.47, −0.88, −0.96, 0.28]。实际模型常用128到320维，经过MLP后映射到每个块所需的γ、β。若某通道得到γ=1.2、β=−0.1，归一化后的特征0.5就变成1.2×0.5 − 0.1 = 0.5，特征−1.0变成−1.3。

容易误解的地方

  • 噪声水平的编码要与训练时一致：用整数步t训练的模型，采样时传入连续的σ就会出错，这是换采样器时常见的错误。
  • 交叉注意力注入的是逐token的信息，adaLN注入的是全局信息，二者分工不同，不能简单互换。
