线性回归

Linear Regression

也叫：最小二乘　least squares　OLS　线性模型　linear model　回归分析

在交互版中打开（看它长在树上的哪里）

用输入特征的加权和加一个偏置来预测一个实数，并选择使预测值与真实值的平方误差之和最小的权重。它是最简单、能精确求解的监督学习模型。

先要会：向量、矩阵与张量 损失函数 导数、偏导与梯度

许多量之间大致是线性关系：房子面积越大、价格越高；广告投入越多、销量越高。线性回归假设

ŷ = w · x + b = w₁x₁ + w₂x₂ + … + w_d·x_d + b

并用训练数据确定权重w和偏置b。衡量好坏的损失函数是均方误差L = (1/N) Σ_i (ŷ_i − y_i)²。

有闭式解：把所有样本排成矩阵X（每行一个样本，末尾补一列1对应偏置），令损失对w的梯度为0，得到正规方程

w = (XᵀX)⁻¹ Xᵀ y

这是少数能一步算出最优解的模型。学到的每个权重w_j有直接的解释：其他特征不变时，x_j每增加1，预测值改变w_j，这也是它在统计学和经济学中被广泛使用的原因。数据量大时也可以用梯度下降迭代求解，结果相同，因为平方误差是凸函数，只有一个最低点。

为什么用平方误差：如果假设y = w·x + b + 噪声、噪声服从高斯分布，那么最小化平方误差恰好等价于最大似然估计。另外它可导、凸、有闭式解，数学上方便。

它在AI里的位置：线性回归是理解所有后续模型的起点。把输出过一个sigmoid就成了逻辑回归；把很多个线性函数叠加、中间插入非线性激活，就是多层感知机——神经网络每一层的核心计算仍然是Wx + b。ADALINE与LMS（1960）就是用梯度下降在线训练的线性模型；加上L2惩罚得到岭回归与L2正则，加上L1惩罚得到Lasso与L1稀疏。

例子

三个数据点(x, y)：(1, 2)、(2, 3)、(3, 5)。

x的均值2，y的均值10/3。斜率w = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)² = 3/2 = 1.5，截距b = 10/3 − 1.5×2 ≈ 0.333。

拟合直线ŷ = 1.5x + 0.333，三个预测值为1.833、3.333、4.833，残差（y − ŷ）为0.167、−0.333、0.167，均方误差约0.056。

容易误解的地方

  • “线性”指对参数线性，不一定对输入线性。把x²、log x当作新特征，模型仍然是线性回归，可以拟合曲线。
  • 特征之间高度相关时，XᵀX接近奇异，解会非常不稳定，这正是加L2正则（岭回归）的动机之一。
