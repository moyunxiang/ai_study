重参数化技巧

Reparameterization Trick

也叫：重参数技巧　pathwise gradient　路径梯度

在交互版中打开（看它长在树上的哪里）

把“从带参数的分布中采样”改写成“先采固定的噪声，再用参数做确定性变换”，比如z = μ + σ·ε。这样梯度就能穿过采样步骤传回参数，而且方差通常小得多。

先要会：高斯分布 链式法则 蒙特卡洛采样 变分推断与ELBO

训练VAE时要最大化变分推断与ELBO，其中有一项是E_{z~q_φ}[f(z)]：从编码器给出的分布N(μ, σ²)里采样z，再算解码器的损失。问题是，采样是一个随机操作，“抽到哪个z”对μ和σ的导数是什么？如果梯度在这里断掉，编码器就学不到东西。

技巧。把随机性从参数上剥离出去：

z = μ + σ · ε，ε ~ N(0, 1)

z的分布仍然是N(μ, σ²)（见高斯分布的线性变换性质），但现在随机性全在ε里，ε与参数无关；z是μ、σ的确定性函数。于是

∇_φ E_{z~q_φ}[f(z)] = E_ε[∇_φ f(μ + σε)]

右边可以用蒙特卡洛采样采几个ε来估计，梯度按普通的链式法则传过z = μ + σε即可，∂z/∂μ = 1，∂z/∂σ = ε。

另一条路及其缺点。不重参数化也能求梯度，用所谓“得分函数估计”（log-derivative技巧）：∇_φ E[f(z)] = E[f(z) ∇_φ log q_φ(z)]。它对任何分布都适用，强化学习中的REINFORCE策略梯度就是它，但它只利用了f的值、没用f的导数，方差往往大得多。

它出现在哪里。变分自编码器VAE和同期的随机反向传播DLGM都以重参数化为核心技巧，使得编码器和解码器可以用一次反向传播端到端训练。DDPM的前向加噪写成x_t = √ᾱ_t·x_0 + √(1 − ᾱ_t)·ε，也是同一种写法，网络被训练来预测这个ε，见扩散：前向加噪与反向去噪。离散变量不能直接这样做，常用Gumbel-Softmax等连续松弛来近似。

例子

f(z) = z²，z ~ N(μ, σ²)，μ = 1，σ = 0.5。精确值：E[z²] = μ² + σ²，所以∂/∂μ = 2μ = 2，∂/∂σ = 2σ = 1。重参数化时抽到ε = 0.8，则z = 1.4，单样本梯度：∂f/∂μ = 2z×1 = 2.8，∂f/∂σ = 2z×ε = 2.24；对多个ε取平均就会趋近于2和1。比较方差：对μ的梯度，重参数化估计的标准差为1；得分函数估计f(z)·(z−μ)/σ²的标准差约4.66，同样精度需要约22倍的样本。

容易误解的地方

  • 重参数化要求f对z可导，并且分布能写成“固定噪声的可导变换”，所以它不能直接用于离散变量，也不能用于不可导的奖励函数。
  • 它降低的是梯度估计的方差，不改变目标本身；结果好坏仍取决于ELBO与模型设计。
