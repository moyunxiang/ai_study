机器学习势函数

Machine Learning Interatomic Potentials

也叫：MLIP　MLFF　机器学习力场　神经网络势　通用原子模型　通用势函数　foundation potential

在交互版中打开（看它长在树上的哪里）

用神经网络拟合量子力学计算出的能量和力，以接近第一性原理的精度、低得多的成本模拟原子。

第一性原理（如DFT）精度高但很贵，限制了模拟规模。做法是在量子计算数据上训练神经网络，学出能量对原子位置的函数，力由求导得到，并通过等变设计保证物理对称性。从神经网络势函数、SchNet到NequIP等变势函数、MACE，再到覆盖周期表的M3GNet通用势函数、CHGNet、MACE-MP-0材料基础模型、MatterSim和UMA通用原子模型，趋势是从单一体系走向通用基础模型。争论在于通用模型对稀有结构、长时间动力学是否可靠。
