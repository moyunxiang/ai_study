约束MDP与安全强化学习

Constrained MDPs and Safe RL

也叫：安全强化学习　safe RL　safe reinforcement learning　约束MDP　constrained MDP　CMDP　约束强化学习　constrained RL　拉格朗日松弛　Lagrangian relaxation　PPO-Lagrangian　原始-对偶方法　primal-dual　代价函数　cost function　安全盾　shielding　安全探索　safe exploration　CPO　约束策略优化

安全强化学习最常用的形式化：在最大化回报的同时，要求某个“代价”的期望累计值不超过阈值（约束MDP）。常用拉格朗日乘子把约束变成可自动调节的惩罚，也可以在执行时用安全盾直接拦下危险动作。

先要会：马尔可夫决策过程 拉格朗日乘子、约束优化与对偶 奖励、回报与折扣

把“别撞人”“别超速”“能耗不超标”写进奖励里，最直接的做法是加一个负的惩罚项。但惩罚该多大？太小，智能体为了多拿奖励宁可违规；太大，它什么都不敢做。而且换个任务就要重调。更自然的说法是：在满足约束的前提下尽量做好。

约束MDP（CMDP）。在马尔可夫决策过程之外再加一个代价函数c(s, a)和阈值d：

max_π J_r(π) s.t. J_c(π) = E_π[Σ_t γ^t c(s_t, a_t)] ≤ d

代价可以是碰撞次数、危险区域停留时间、违规输出等。与普通MDP不同，CMDP的最优策略可能必须是随机的：例如在两个方案之间按比例混合，恰好把期望代价用到阈值。

拉格朗日方法。用拉格朗日乘子、约束优化与对偶把约束问题变成一个极小极大问题：

max_π min_{λ≥0} J_r(π) − λ·(J_c(π) − d)

实践中交替更新：策略按奖励r − λc用普通RL算法（如PPO）训练；乘子按λ ← max(0, λ + η·(J_c − d))更新——代价超标就加大惩罚，长期满足约束就放松。λ相当于一个被自动调好的惩罚系数，但训练过程中常出现振荡，约束在学习期间会被反复违反。

其他路线。

  • 信赖域式：在每次更新的信赖域内显式保证约束近似满足（见信赖域与代理目标），代表是约束策略优化CPO。
  • 安全盾（shielding）：Shielding安全盾在执行时用一个基于形式化规约的监视器检查智能体的动作，违反规约就替换成安全动作，训练和部署期间都能保证约束。
  • 安全探索：限制学习过程中的风险，而不只是最终策略，见AI安全的具体问题的讨论。
  • 风险而不是期望的约束见风险敏感强化学习与CVaR。

在大模型对齐中，Safe RLHF约束对齐把“有用”作为奖励、“有害”作为代价，用拉格朗日方法在两者间平衡。

例子

一个配送机器人：每次准时送达奖励+1，每次进入行人密集区代价+1，要求每个回合平均代价不超过0.1。若当前策略平均代价为0.3，λ=2、学习率η=0.5，则λ更新为2 + 0.5×(0.3 − 0.1) = 2.1，有效奖励变成r − 2.1·c，策略会更倾向于绕路。几轮后若代价降到0.05，λ又会逐渐减小。

容易误解的地方

  • 期望代价约束只约束平均值，平均0.1次碰撞可能是大多数回合零碰撞、少数回合多次碰撞，对安全关键场景这可能不够，见风险敏感强化学习与CVaR。
  • 拉格朗日方法通常只保证训练收敛时约束满足，训练过程中的违规并不受控；在真实系统上要配合仿真预训练或安全盾。
