多示例学习与弱监督

Multiple Instance Learning

也叫：多示例学习　多实例学习　multiple instance learning　multi-instance learning　MIL　注意力池化　attention pooling　attention-based MIL　ABMIL　整张切片　whole slide image　WSI　计算病理　computational pathology

标签不打在单个样本上，而打在一“包”样本上：包里只要有一个正例，整包就是正的；全是负例，整包才是负的。病理切片、远程监督关系抽取、弱标注视频都属于这种设定。

先要会：监督学习 二元交叉熵与sigmoid输出

一张病理切片有几万×几万像素，医生只给出“这张切片有癌”或“没有”的诊断，不会圈出每一个癌细胞。把切片切成上千个小图块后，我们只知道整体标签，不知道哪些图块是阳性。这种“标签只在集合层面已知”的问题叫多示例学习（MIL），是弱监督学习的一种（见半监督学习与伪标签）。

标准假设。每个训练样本是一个包B = {x₁, …, x_n}，带一个包标签Y。经典的MIL假设：

Y = 1　当且仅当　至少有一个示例y_i = 1

于是包的标签可以写成示例标签的最大值：Y = max_i y_i。

常见做法。

  • max池化：给每个示例打分，用最高分作为包的分数，再与包标签算损失。只有分数最高的示例得到梯度。
  • 平均池化：用所有示例分数的平均，适合“正例比例越高越可能为正”的情形，但违背了经典假设。
  • 注意力池化：学一组注意力权重，对示例的特征加权平均得到包的表示，再分类（见注意力机制）。权重本身还能指出模型认为哪些示例是关键，在病理学中用来定位可疑区域。这是今天计算病理学处理整张切片的主流做法。

它出现在哪里。

  • 远程监督关系抽取：知识库说“A的创始人是B”，于是包含A和B的所有句子都被标成“创始人”关系，但其中很多句子其实并不表达这个关系。多示例远程监督把同一实体对的句子看作一个包，只要求至少一句表达该关系（见信息抽取）。
  • 医学影像：整张切片或整个CT扫描只有诊断级标签。
  • 视频与音频：只知道“这段视频里有人摔倒”，不知道在第几秒，即弱监督的时序定位。
  • 图像分类与检测：只有图片级标签时训练检测器（弱监督目标检测），常把候选框当作示例。

和其他设定的区别。二分类、多分类与多标签里每个样本自己有标签；标签噪声与带噪学习里标签可能是错的；MIL里标签是对的，只是粒度更粗。

例子

三个包：包1 = {0.1, 0.2, 0.9}，标签为正；包2 = {0.3, 0.2}，标签为负；包3 = {0.6, 0.4, 0.1}，标签为正。用max池化，包分数分别为0.9、0.3、0.6，阈值0.5时全部分对。训练时只有0.9、0.3、0.6这三个示例收到梯度，模型逐渐学会“包里哪一个是罪魁祸首”。

容易误解的地方

  • max池化每个包只有一个示例得到梯度，训练效率低、容易不稳定；包很大时常改用注意力池化或top-k平均。
  • 包级准确率高不等于能找对正示例；定位能力需要另外有示例级标注才能评估。
