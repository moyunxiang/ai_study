拒绝采样

Rejection Sampling

也叫：拒绝采样　rejection sampling　接受-拒绝采样　acceptance-rejection sampling　accept-reject　提议分布　proposal distribution　拒绝采样微调　rejection sampling fine-tuning　RFT　RS微调　Best-of-N　best-of-n sampling　BoN

想从难采样的分布里抽样本，就先从容易采样的分布里抽，再按一定概率决定留下还是丢掉，留下的恰好服从目标分布。大模型的“拒绝采样微调”借用了这个名字。

先要会：随机变量与概率分布 蒙特卡洛采样

我们常常能算出一个分布的密度p(x)（甚至只知道它正比于某个函数），却没法直接从中抽样本。拒绝采样是最简单的通用解法，也是理解更复杂的蒙特卡洛采样方法的起点。

算法。找一个容易采样的提议分布q(x)和常数M，使处处有p(x) ≤ M·q(x)（M·q像一个罩子盖住p）。然后重复：

1. 从q抽一个x； 2. 从均匀分布U(0, 1)抽一个u； 3. 若u ≤ p(x) / (M·q(x))就接受x，否则丢掉重来。

接受下来的x恰好服从p。直观上，这等于在“罩子”下面均匀撒点，只保留落在p曲线下面的点。平均接受率是1/M，所以罩子越贴合，效率越高。

维度灾难。高维时很难找到贴合的q，M会随维度指数增长，接受率趋于0（见维度灾难）。所以高维分布通常改用重要性采样或MCMC（MCMC与朗之万动力学、Gibbs采样与马尔可夫随机场）。

它出现在哪里。

  • 推测解码和DeepMind推测采样：小模型先猜若干token，大模型按min(1, p(x)/q(x))的概率接受每个token，拒绝时从修正后的分布重采。这是一种精巧的拒绝采样，保证输出分布与大模型单独生成完全相同，但速度更快。
  • 大模型后训练里的拒绝采样微调（rejection sampling fine-tuning）：对每个问题采样多个回答，只保留被奖励模型或验证器判为好的，再拿去做监督微调。Llama 2、DeepSeek-R1、STaR自举推理、ReST强化自训练都用了这种流程；RSO统计拒绝采样进一步按统计意义上的拒绝采样来近似最优策略的分布。严格说，这里通常只是“筛选”，留下的样本并不精确服从某个目标分布。
  • 与之相关的Best-of-N：一次采N个回答，只输出奖励最高的一个，是推理时扩展计算量的最简单方法之一（见推理token与测试时计算）。

例子

目标分布p(x) = 2x（x在[0, 1]），提议分布q为U(0, 1)，取M = 2。抽到x = 0.3、u = 0.5：接受门槛是2×0.3/(2×1) = 0.3，u > 0.3，拒绝。抽到x = 0.8、u = 0.5：门槛0.8，接受。平均接受率1/M = 50%，接受的样本在靠近1的地方更密，正好服从p。

容易误解的地方

  • M取小了（罩子没盖住p）时，结果分布是错的，而且算法本身不会报错。
  • “拒绝采样微调”中的“拒绝”是按奖励好坏筛选，与上面那种保证精确分布的算法目的不同，读论文时要区分。
