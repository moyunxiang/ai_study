自注意力与多头注意力

Self-Attention and Multi-Head Attention

也叫：MHA　缩放点积注意力　scaled dot-product attention　自注意力机制

在交互版中打开（看它长在树上的哪里）

序列中的每个元素都用注意力去看同一序列里的所有元素，并据此更新自己的表示；多头注意力则并行做多组这样的计算。是Transformer的核心运算。

先要会：注意力机制 矩阵乘法与线性变换 Softmax与logits

在注意力机制里，查询来自解码器、键和值来自编码器，注意力只是连接两个RNN的桥梁。信息在序列内部的流动仍靠RNN一步步传递，既慢又难以跨越长距离。自注意力的想法是：让句子里的每个词直接去看句子里的所有其他词，一步就能交换信息。

单头自注意力。输入是n个token的向量，排成矩阵X（形状n×d）。用三个可学习的矩阵把X投影成查询、键、值（见矩阵乘法与线性变换）：

Q = X·W_Q，K = X·W_K，V = X·W_V（W_Q、W_K形状d×d_k，W_V形状d×d_v）

然后

Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V

Q·Kᵀ是n×n的分数矩阵，第i行第j列表示第i个token对第j个token的关注程度；Softmax与logits对每一行归一化；再乘V得到每个token的新表示（n×d_v）。除以√d_k是因为d_k维随机向量内积的方差约为d_k，数值太大会让softmax饱和、梯度接近0。

因果掩码。做语言模型时，第i个位置不能看到后面的词（否则训练时就“偷看答案”了）。做法是在softmax之前把分数矩阵的上三角（j > i）设为−∞，softmax后这些位置的权重为0。

多头注意力。一组Q、K、V只能表达一种“相关”的概念。多头注意力并行做h组，每组用自己的投影矩阵、维度d_k = d/h，各自算出n×d_k的结果后拼接回n×d，再乘一个输出矩阵W_O（d×d）。不同的头可以分别关注语法依赖、指代、相邻位置等不同关系。总计算量和单个d维的头差不多。

它在哪里出现。句内自注意力LSTMN和结构化自注意力句嵌入在RNN内部先试用了自注意力；Transformer（2017）完全只用它。之后BERT用不加掩码的双向版本，GPT-1用带因果掩码的版本。为了降低推理时的显存，多查询注意力MQA和分组查询注意力GQA让多个查询头共享键值头；FlashAttention不改变数学结果，只重排计算顺序来减少显存读写。注意力本身不知道词序，需要位置编码补上。

例子

3个token的计算。假设投影后（d_k = 2）：Q = [[1, 0], [0, 1], [1, 1]]，K = [[1, 0], [1, 1], [0, 1]]，V = [[1, 0], [0, 2], [3, 1]]（每个内层括号是一个token）。看第3个token：

1. 它的q = [1, 1]与三个k的内积是[1, 2, 1]，除以√2得[0.707, 1.414, 0.707]。 2. softmax得权重[0.248, 0.503, 0.248]：它最关注第2个token。 3. 输出 = 0.248×[1, 0] + 0.503×[0, 2] + 0.248×[3, 1] ≈ [0.99, 1.25]。

加上因果掩码后，第2个token只能看前两个：分数[0, 0.707]，权重[0.33, 0.67]，输出 = 0.33×[1, 0] + 0.67×[0, 2] = [0.33, 1.34]。第1个token只能看自己，输出就是v_1 = [1, 0]。

形状。原始Transformer中d = 512，h = 8，d_k = 64。长度n = 10的句子：X是10×512，每个头的Q、K、V是10×64，每个头的分数矩阵是10×10，8个头的输出拼回10×512。四个投影矩阵W_Q、W_K、W_V、W_O合计4×512×512 = 1,048,576个参数，与n无关。

容易误解的地方

  • 自注意力的计算量和显存随序列长度n平方增长（n×n的分数矩阵），长文本的主要成本就在这里。
  • 不加位置信息时，自注意力对输入顺序是“等变”的：打乱输入，输出也只是跟着打乱（见不变性与等变性）。它本身不知道哪个词在前。
  • 多头不是“8倍的计算量”：每个头的维度是d/h，总量与一个大头相当。
