神经元与激活函数

Neurons and Activation Functions

也叫：activation function　ReLU　sigmoid　tanh　GELU　人工神经元　非线性

在交互版中打开（看它长在树上的哪里）

神经网络的最小计算单元：对输入做加权求和、加上偏置，再经过一个非线性的激活函数。激活函数让网络能表示非线性关系。

先要会：向量、矩阵与张量 内积与余弦相似度 导数、偏导与梯度

神经网络的名字来自一个粗糙的类比：生物神经元接收很多输入信号，总和超过某个阈值就“放电”。1943年的M-P神经元把它写成了数学：输入加权求和，超过阈值输出1，否则输出0。

今天的人工神经元保留了这个结构，只是把阈值换成了光滑的函数：

y = f(w·x + b)

其中x是输入向量，w是同样长度的权重向量，b是偏置（一个标量），w·x + b是一次线性变换（见内积与余弦相似度），f是激活函数。w和b是要从数据里学出来的参数；f是事先选好的固定函数。

为什么一定要有非线性的f。如果f是恒等函数，一层神经元就是一个矩阵乘法，两层叠起来W2(W1x) = (W2W1)x仍是一个矩阵乘法——叠多少层都等价于一层线性模型，画不出弯曲的分类边界。非线性的f打破了这种坍缩，深度才有意义（见多层感知机）。

常见的激活函数：

  • 阶跃函数：f(z) = 1 if z > 0 else 0。感知机用它，但导数处处为0（或不存在），无法用梯度训练。
  • Sigmoid：σ(z) = 1 / (1 + e^(−z))，输出在(0, 1)之间，可读作概率。缺点是z很大或很小时导数接近0（“饱和”），深层网络中梯度会越传越小（见梯度消失与梯度爆炸）。
  • tanh：输出在(−1, 1)，以0为中心，早期RNN常用，同样会饱和。
  • ReLU：f(z) = max(0, z)。正半轴导数恒为1，不会饱和，计算也最便宜。2010年前后的ReLU让深层网络好训了很多，AlexNet就用它。
  • GELU / SiLU：ReLU的光滑版本，如SiLU(z) = z·σ(z)。今天的Transformer基本都用这一类（GELU），或者它们的门控版本（GLU变体与SwiGLU，见门控机制）。

它在哪里出现。几乎所有神经网络的每一层都是“线性变换 + 逐元素激活函数”。实践中不会单独写一个个神经元，而是把一层里的所有神经元合成矩阵运算f(Wx + b)，W的每一行就是一个神经元的权重。

例子

一个神经元有两个输入x = [1, 2]，权重w = [0.5, −1]，偏置b = 0.5。线性部分：z = 0.5×1 + (−1)×2 + 0.5 = −1。

换不同的激活函数，输出分别是：ReLU(−1) = 0；Sigmoid(−1) = 1/(1 + e) ≈ 0.269；tanh(−1) ≈ −0.762。

可以看到ReLU在负半轴把信号完全截断（该神经元“不激活”），而Sigmoid和tanh仍会输出一个非零值。训练时ReLU在z < 0处的导数为0，这个神经元这一次就不更新；Sigmoid在z = −1处的导数是σ(1−σ) ≈ 0.197，比它在z = 0处的最大值0.25稍小。

容易误解的地方

  • 人工神经元和生物神经元相似的只有“加权求和再阈值化”这一点，不要把神经网络当作大脑的模型。
  • 激活函数不是越复杂越好。它主要决定梯度能否顺利传播；换激活函数带来的差别通常远小于数据和规模带来的差别。
  • ReLU的神经元可能“死掉”：如果偏置被推到很负，对所有输入都输出0，梯度也恒为0，再也学不回来。
