命题逻辑、谓词逻辑与符号推理

Logic and Symbolic Reasoning

也叫：符号主义　symbolic AI　GOFAI　一阶逻辑　first-order logic　定理证明　规则推理

在交互版中打开（看它长在树上的哪里）

用符号表示事实和规则，再按形式化的推理规则机械地推出新结论。这是AI前三十年的主流路线，也是今天讨论“模型会不会推理”的参照系。

先要会：图、树与搜索

AI诞生时，研究者认为智能的核心是推理：知道“所有人都会死”和“苏格拉底是人”，就能推出“苏格拉底会死”。如果把知识写成精确的符号，把推理写成机械的规则，计算机就能像数学家一样推导。这条路线叫符号主义。

命题逻辑。基本单位是非真即假的命题，用连接词组合：非¬、与∧、或∨、蕴含→。例如P → Q表示“若P则Q”。最基本的推理规则是肯定前件：由P和P → Q推出Q。一个公式是否永真，可以列真值表检查，n个变量要列2ⁿ行。

谓词逻辑（一阶逻辑）。命题逻辑不能谈论“所有”和“存在”。一阶逻辑引入对象、谓词和量词：

∀x (Human(x) → Mortal(x))，Human(Socrates) ⊢ Mortal(Socrates)

∀读作“对所有”，∃读作“存在”，⊢表示“可以推出”。一阶逻辑表达力强得多，但代价是一般情形下无法保证在有限时间内判定一个命题能否被推出。

自动推理。归结（resolution）原理把推理统一成一条规则，Prolog语言就是建立在它之上的；专家系统则写下大量“如果……那么……”规则，用前向或后向链式推理得出结论。

它出现在哪里。M-P神经元把神经元看作逻辑门；逻辑理论家自动证明了《数学原理》中的定理；专家系统的商业化在80年代把规则推理商业化；Cyc常识知识库试图把常识全部写成逻辑断言。符号方法的瓶颈在于知识要人工编写、难以处理不确定性和噪声，这推动了概率方法和概率图模型的兴起；今天关于推理token与测试时计算的讨论，仍常以形式逻辑作为检验标准。

例子

命题逻辑：已知P =“下雨”，Q =“地湿”，规则P → Q，观察到P为真，推出Q为真。但观察到Q为真并不能推出P（地湿也可能是洒水车），这是常见的逻辑谬误“肯定后件”。规模感：有20个命题变量的公式，真值表有2²⁰ = 1048576行；有50个变量就超过10¹⁵行，必须用更聪明的算法（如SAT求解器）而不是穷举。

容易误解的地方

  • 逻辑里的“蕴含”P → Q在P为假时总是为真，这和日常语言里的“如果”不完全相同。
  • 符号主义没有消失：定理证明器、类型检查器、SAT求解器至今广泛使用，LLM做数学证明时也常借助Lean这样的形式化系统来验证。
