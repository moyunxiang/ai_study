能量模型与玻尔兹曼分布

Energy-Based Models

也叫：EBM　能量函数　energy function　Boltzmann distribution　配分函数　partition function

在交互版中打开（看它长在树上的哪里）

给每个可能的取值打一个“能量”分数，能量越低越可能出现，概率正比于exp(−能量)。定义模型很自由，但归一化常数通常算不出来，这让训练和采样都变难。

先要会：随机变量与概率分布 Softmax与logits 蒙特卡洛采样

要给图片定义一个概率分布，一个非常自由的做法是：只规定一个打分函数E(x)，让“像真实图片”的x得分低、不像的得分高，而不去管它们的概率加起来是否为1。这个想法来自统计物理：系统更常处于低能量状态。能量模型就是把这条物理规律搬到了机器学习里。

玻尔兹曼分布。

p(x) = exp(−E(x)/T) / Z，Z = Σ_x exp(−E(x)/T)

E(x)是能量，T是温度，Z是配分函数（归一化常数）。只看有限个离散状态时，这正是对−E/T做Softmax与logits。温度高时分布趋于平坦，温度低时集中在能量最低的状态上。

难点：配分函数。Z要对所有可能的x求和。784个二值像素的图片有2⁷⁸⁴种，根本无法求和。没有Z，就算不出精确的似然；对数似然的梯度里还含有一项“模型分布下的期望”，只能用Metropolis采样与MCMC等蒙特卡洛采样采样近似，而采样本身又慢又难以收敛。

绕开Z的思路。对比散度只跑几步MCMC就更新；噪声对比估计把问题改成区分数据和噪声；分数匹配不学p(x)本身，而学∇_x log p(x) = −∇_x E(x)，Z在求导时消失了，这直接通向分数函数与分数匹配和扩散模型。

它出现在哪里。Hopfield网络网络把记忆存成能量函数的局部极小值；玻尔兹曼机用玻尔兹曼分布定义带隐单元的随机网络，其简化版受限玻尔兹曼机是深度信念网络的积木；对比散度让这类模型变得可训练；基于能量的学习这篇教程把许多学习方法统一到能量框架下；分数匹配估计提出只学能量梯度的分数匹配，分数匹配生成模型把它用于图像生成，发展出了现代的分数模型与扩散模型。

例子

三个状态的能量为[0, 1, 2]，T = 1。各自的exp(−E)为[1, 0.368, 0.135]，Z ≈ 1.503，概率约为[0.665, 0.245, 0.090]，能量最低的最可能出现。T = 2时概率变为[0.506, 0.307, 0.186]，更平均；T = 0.5时变为[0.867, 0.117, 0.016]，几乎只选最低能量。只有3个状态时Z很好算；28×28的二值图片却有2⁷⁸⁴ ≈ 10²³⁶种状态。

容易误解的地方

  • 能量只有相对大小有意义：给所有状态的能量加同一个常数，分布不变。
  • softmax分类器也可以看成能量模型（能量是负的logit），区别在于分类只需在少数类别上归一化，而生成模型要在整个输入空间上归一化，后者才是难点。
