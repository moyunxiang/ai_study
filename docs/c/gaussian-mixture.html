高斯混合模型

Gaussian Mixture Model

也叫：高斯混合模型　混合高斯　混合高斯模型　GMM　Gaussian mixture model　Gaussian mixture　mixture of Gaussians　MoG　混合模型　mixture model　责任度　responsibility　软聚类　soft clustering　GMM-HMM　混合密度网络　mixture density network　MDN

用几个高斯分布按权重叠加来拟合复杂的数据分布：每个样本被看作先随机选一个分量、再从该高斯里抽出。它是最经典的隐变量模型，用EM算法训练。

先要会：高斯分布 隐变量模型 EM算法

单个高斯分布只有一个峰。可是人的身高混合了男女两个群体，语音的声学特征来自几十个音素，数据常常有多个峰。最直接的办法是把几个高斯加起来。

定义。K个分量的高斯混合模型（GMM）：

p(x) = Σ_k π_k · N(x | μ_k, Σ_k)

π_k是混合权重（非负、和为1），每个分量有自己的均值μ_k和协方差Σ_k（见协方差矩阵）。只要分量足够多，GMM可以任意精度地逼近任何光滑密度。

生成视角与隐变量。GMM描述了一个两步过程：先按π抽一个分量编号z，再从N(μ_z, Σ_z)中抽x。z看不见，是一个隐变量（见隐变量模型）。给定x，它属于第k个分量的后验概率叫责任度：

γ_k(x) = π_k N(x | μ_k, Σ_k) / Σ_j π_j N(x | μ_j, Σ_j)

训练：EM。对数似然里有“log套着求和”，不能直接求闭式解。EM算法交替两步：E步用当前参数算每个样本的责任度；M步把责任度当作软标签，按加权平均重新估计每个分量的π、μ、Σ。每一轮都保证似然不下降。如果把责任度硬化成0或1、并让所有协方差相同且趋于0，EM就退化成k-means聚类，所以GMM常被称为“软聚类”（见聚类）。

它出现在哪里。

  • 语音识别在深度学习之前的二十多年里用GMM建模每个HMM状态的声学特征分布（GMM-HMM），深度网络声学模型用神经网络替换了GMM这一部分；说话人确认的GMM-UBM说话人确认和i-vector说话人识别也建立在GMM上。
  • 图像分割的GrabCut框选抠图用两个GMM分别建模前景和背景颜色。
  • 混合密度网络让神经网络输出GMM的参数，用来预测有多种可能答案的连续量；一些连续token的自回归生成模型（如GIVT连续token生成）也让输出头给出高斯混合。

例子

一维数据来自两个群体：π = (0.6, 0.4)，μ = (160, 175)，σ = (6, 7)（单位cm）。身高168的人：两个分量的密度分别约0.027和0.035，乘上权重为0.6 × 0.027 ≈ 0.016与0.4 × 0.035 ≈ 0.014，属于第二个分量的责任度约0.014/(0.016 + 0.014) ≈ 0.46，几乎各占一半。身高185的人属于第二个分量的责任度则超过0.99。

容易误解的地方

  • 分量数K需要人选，常用BIC等信息准则或验证集似然来定。
  • 某个分量只覆盖一个样本时，其方差可以缩到0，似然趋于无穷；实际实现会给协方差加一个下限。
  • EM只收敛到局部最优，结果依赖初始化，通常用k-means的结果初始化并多次重启。
