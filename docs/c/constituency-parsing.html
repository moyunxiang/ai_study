成分句法分析

Constituency Parsing

也叫：constituency parsing　成分句法分析　成分句法　短语结构分析　phrase structure parsing　句法树　parse tree　syntax tree　constituency tree　PARSEVAL　成分分析　句法分析

在交互版中打开（看它长在树上的哪里）

把句子分析成一棵短语结构树：词组成短语，短语再组成更大的短语，直到整个句子。它回答“哪些词是一个整体、这个整体是什么类别”。

先要会：上下文无关文法 动态规划

要理解“我看见了拿望远镜的男人”，需要知道“拿望远镜的男人”是一个整体；而“我用望远镜看见了男人”里，“用望远镜”修饰的是“看见”。词序列一样的句子可以有不同的结构，结构不同意思就不同。成分句法分析（constituency parsing）把这种层次结构显式地画成一棵树。

输出是什么。一棵树：叶子是词，内部节点是短语类别（NP名词短语、VP动词短语、PP介词短语、S句子……），每个节点覆盖句子里连续的一段词，这段词叫一个成分。它与依存句法分析是两种互补的句法表示：成分树描述“短语怎么嵌套”，依存树描述“哪个词修饰哪个词”，两者可以互相转换。

核心难点：歧义。英文经典例子“I saw the man with the telescope”，介词短语可以挂在动词上，也可以挂在名词上。句子越长，合法树的数量增长得越快（大致按卡特兰数增长），必须有办法给每棵树打分，选出最可能的那棵。

方法的演变。

  • 文法+动态规划：用上下文无关文法描述合法结构，概率上下文无关文法PCFG给规则加概率，CKY句法分析算法用动态规划在O(n³)时间内找出概率最高的树。规则和概率从Penn Treebank这样的树库中统计得到。
  • 改进PCFG：纯PCFG忽略了词本身，Collins词汇化句法分析器和Charniak句法分析器把中心词信息加入规则（词汇化）；非词汇化句法分析和Berkeley句法分析器则通过细分非终结符类别，不用词汇化也达到很高精度。
  • 神经网络：句法分析即翻译把树写成括号序列，当作“翻译”来生成；跨度式神经成分分析和自注意力成分句法分析给每个片段打分再做CKY式解码，后者用自注意力编码器把英文树库上的F1推到95以上。

评测。常用PARSEVAL：把每个成分看作（类别, 起点, 终点）三元组，与标准树比较算精确率、召回率和F1。

今天显式句法树在大模型应用中用得少了，但在语言学研究、可解释性分析（“模型内部是否表示了句法？”）和一些低资源、高可靠的场景中仍有用。

例子

“她 吃 了 一碗 面”的成分树（括号写法）：

(S (NP 她) (VP (V 吃了) (NP (QP 一碗) (N 面))))

成分有：S覆盖全部5个词，NP覆盖“她”，VP覆盖“吃了一碗面”，NP覆盖“一碗面”。如果分析器把VP的范围错标成“吃了一碗”，就有一个成分错误：精确率和召回率各掉一点。

容易误解的地方

  • 成分树的形状依赖标注规范（树库怎么规定），不同树库的F1不能直接比。
  • 句法正确不等于语义理解正确；树只告诉你结构，不告诉你“谁对谁做了什么”，后者见语义角色标注。
