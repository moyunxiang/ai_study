驾驶世界模型

Driving World Models

也叫：Driving World Model　自动驾驶世界模型　生成式驾驶仿真　驾驶视频生成　4D占用预测　Occupancy World Model

在交互版中打开（看它长在树上的哪里）

学会预测“自车这样开之后，周围的路况和画面会怎样变化”的模型，用来生成训练数据、做闭环仿真和辅助规划。

自动驾驶最难的是长尾场景，真实路测很难攒够。驾驶世界模型从海量行车视频中学习交通动态：GAIA-1驾驶世界模型把驾驶视频当作token序列预测，DriveDreamer和Vista驾驶世界模型用扩散生成可控的驾驶视频，OccWorld占用世界模型在三维占用栅格上预测未来，GAIA-2支持多相机和更细的控制，Waymo世界模型用于生成罕见场景做仿真。

另一种用法是把世界建模当作训练信号：DriveVLA-W0世界模型增强让驾驶VLA同时预测未来画面，发现数据越多收益越大。争论是生成的画面看起来真实，不代表物理和其他车辆的行为合理，用它评测或训练规划器是否可靠仍待验证。
