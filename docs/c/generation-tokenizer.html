生成用分词器与重建-生成之困

Tokenizers for Generation and the Reconstruction–Generation Dilemma

也叫：视觉分词器　Visual Tokenizer　Image Tokenizer　VAE　潜空间自编码器　Latent Autoencoder　重建与生成的矛盾　Reconstruction-Generation Dilemma　生成友好潜空间　高压缩自编码器　Deep Compression Autoencoder　一维分词器　1D Tokenizer　LFQ　FSQ　VAE瓶颈

生成模型多在压缩后的潜空间里工作，而潜空间压得越好重建越清楚，却未必越好生成。

潜空间扩散LDM之后，几乎所有图像和视频生成都分两步：先用自编码器把图像压成潜变量或离散token（潜空间、向量量化与离散token），再在其上训练扩散或自回归模型。分词器因此成为质量与速度的上限。

离散分词器一线：VQ-VAE、VQGAN，后来MAGVIT-v2与LFQ分词器的LFQ与有限标量量化FSQ解决码本利用率；TiTok一维分词器把图像压成32个一维token。连续潜空间一线：深度压缩自编码器DC-AE把空间压缩比做到最高128倍而重建不明显变差，以加速高分辨率生成。

2025年的焦点是重建与生成之困：VA-VAE重建与生成之困发现提高潜空间维度能改善重建，但生成反而变差，于是让潜变量向视觉基础模型对齐；REPA-E端到端调VAE让VAE与扩散模型端到端一起调；表征自编码器RAE干脆用冻结的表征编码器（如DINOv2）当编码器。另一派则认为潜空间本身可以不要（见像素空间扩散）。
