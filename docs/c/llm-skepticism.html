大模型怀疑论

LLM Skepticism

也叫：LLM怀疑论　随机鹦鹉　Stochastic Parrots　LLM是死路　LLM dead end　大模型能否通向AGI　LLMs can't reason　大模型不会推理　世界模型派　自回归会失败　next-token prediction is not enough

在交互版中打开（看它长在树上的哪里）

认为只靠预测下一个词的大语言模型无法通向真正的智能：它们缺乏理解、世界模型、持续学习或真正的推理。

怀疑论有几条不同的论证。语言学和伦理角度，随机鹦鹉认为大模型只是按统计规律拼接文本、并不理解意义。认知科学角度，Marcus对深度学习的批判指出深度学习缺乏抽象、组合和因果推理能力。LeCun的LeCun的“蛋糕”比喻比喻认为自监督学习世界模型才是主体，他后来离开Meta创办以世界模型为目标的公司（LeCun离开Meta创办AMI）。

强化学习一派的论证来自Sutton：模仿人类文本学不到目标和经验，大模型是死路（Sutton：LLM是死路），应当回到从交互中学习（《经验时代》）。推理模型出现后，“思考的幻觉”之争声称它们在复杂谜题上会突然崩溃，引发大量反驳；规模撞墙与预训练终结论之争和ARC-AGI系列基准上的表现，也常被双方各自引为证据。支持者则认为这些批评一再被新模型的能力推翻。
