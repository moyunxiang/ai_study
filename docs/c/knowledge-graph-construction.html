知识图谱

Knowledge Graphs

也叫：KG　Knowledge Graph　知识库　Knowledge Base　KB　知识图谱构建　KG Construction　语义网　Semantic Web　知识图谱嵌入　KGE　链接数据　Linked Data

在交互版中打开（看它长在树上的哪里）

把世界上的实体和它们之间的关系存成一张巨大的图，供搜索、问答和推理直接查询。

知识图谱的前身是手工构建的常识库Cyc常识知识库和词汇网络WordNet。2007年前后，Freebase采用众包编辑，DBpedia和YAGO知识库从维基百科的信息框里自动抽取事实，规模达到数百万实体；2012年谷歌推出Google知识图谱，口号是“things, not strings”，让搜索结果直接给出实体卡片，“知识图谱”一词由此流行；同年的Wikidata成为后来最常用的开放知识库。

为了让机器学习模型使用图谱，TransE知识图谱嵌入把实体和关系都映射为向量，要求“头实体+关系≈尾实体”，开启了知识图谱嵌入方向。图谱也是基于Freebase的语义解析问答这类知识库问答的底座。大模型出现后，讨论转向两者如何结合：图谱提供可核查的事实，模型提供语言理解。
