知识编辑

Knowledge / Model Editing

也叫：model editing　模型编辑　知识编辑　事实编辑　locate-then-edit　定位后编辑　ROME　MEMIT　知识定位　参数化知识

在交互版中打开（看它长在树上的哪里）

不重新训练，直接改动模型里少量参数，让它记住一条新事实或忘掉一条错误事实。

语言模型把大量事实存在参数里：语言模型即知识库表明不微调就能用填空把知识问出来，参数里能装多少知识测量了闭卷问答能装多少知识。但事实会过时或出错，整体重训太贵。ROME知识定位与编辑用因果追踪定位到中间层MLP在“主语最后一个词”处存储事实关联，再对该层做秩一更新改写一条事实；MEMIT批量编辑把它推广到一次修改成千上万条。

后续研究发现编辑常常“改了表面、没改推理”：改完“A的首都是B”，模型在多跳问题里仍按旧知识回答；反转诅咒也说明模型学到的知识是有方向的。编辑的副作用、可扩展性以及与检索增强的取舍，至今仍是开放问题。
