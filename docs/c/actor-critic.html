Actor-Critic与优势函数

Actor–Critic and Advantage

也叫：AC　A2C　A3C　演员-评论家　GAE

在交互版中打开（看它长在树上的哪里）

同时训练两个部分：actor（策略）负责选动作，critic（价值函数）负责评判这个动作比平均好多少。用critic的评分代替完整回报，策略梯度的方差小得多。

先要会：策略梯度 时序差分与自举 策略与价值函数

策略梯度用整局的实际回报G来给动作打分，方差很大：一局赢了，里面的臭棋也被加强。时序差分与自举则提供了一个低方差但有偏的局部评分。Actor-Critic把两者结合起来。

两个角色。

  • Actor：策略网络π_θ(a|s)，按策略梯度更新。
  • Critic：价值网络V_w(s)，用TD方法学习，评价当前状态平均能拿多少回报。

优势函数。衡量某动作比该状态下的平均水平好多少：

A(s, a) = Q(s, a) − V(s)

正数说明这步比平均好，应该加强。不必单独学Q，一步TD误差就是优势的一个估计：A ≈ δ = r + γ·V(s') − V(s)。于是actor的更新变成θ ← θ + α·∇log π_θ(a|s)·δ，critic同时用δ更新自己。广义优势估计GAE把多步TD误差按λ加权平均，在偏差和方差之间调节。

历史与演变。Actor-Critic（ASE/ACE）用两个神经元式单元（ASE与ACE）解决倒立摆控制，是这一结构的起点。A3C用多个并行环境训练深度actor-critic。PPO在此基础上加了“裁剪”：新旧策略的概率比ρ = π_new(a|s)/π_old(a|s)，目标取min(ρ·A, clip(ρ, 1−ε, 1+ε)·A)，防止一次更新走太远；它成为RLHF的默认算法。SAC在目标里加上策略熵，鼓励探索。

去掉critic。大语言模型很大，再训一个同样大的critic很贵。GRPO对同一个问题采样一组回答，用组内奖励的均值和标准差做归一化来代替critic估计的V(s)，这是推理模型训练中的常见选择。

例子

critic估计V(s)=3，actor选了某动作，得到r=1，到达s'，V(s')=4，γ=0.9。优势估计δ = 1 + 0.9×4 − 3 = 1.6，大于0，actor提高这个动作的概率；若奖励是r=−1，δ = −1 + 3.6 − 3 = −0.4，就降低它。

PPO裁剪：ε=0.2，某动作优势A=2，新旧概率比ρ=1.5。未裁剪项1.5×2 = 3，裁剪项clip(1.5, 0.8, 1.2)×2 = 2.4，取较小的2.4。概率比超出1.2之后再增加也得不到更多收益，更新被“刹住”。

GRPO：同一问题采4个回答，奖励为(1, 0, 0, 1)，均值0.5，标准差0.5（按总体标准差算；有的实现用样本标准差，数值略有不同），优势依次为(+1, −1, −1, +1)。

容易误解的地方

  • critic不准时，优势估计就有偏，actor会被带偏；所以critic常需要比actor更多的更新或更大的学习率。
  • “优势”是相对量：所有动作都很好时，平均以下的仍然得负分。
  • PPO中的ε裁剪只在一个方向起作用：A>0时限制概率比过大，A<0时限制概率比过小。
