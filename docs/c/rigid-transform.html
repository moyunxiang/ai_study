位姿与齐次变换SE(3)

Poses and Homogeneous Transforms (SE(3))

也叫：位姿　pose　6D位姿　6-DoF pose　齐次变换　homogeneous transformation　齐次变换矩阵　刚体变换　rigid transformation　rigid-body transform　SE(3)　坐标变换　坐标系变换　coordinate frame　外参　手眼标定　hand-eye calibration　位姿图　pose graph　TF变换

位姿（pose）= 位置 + 朝向，即一个三维平移加一个三维旋转，共6个自由度。用4×4齐次变换矩阵表示时，坐标系之间的换算就变成矩阵连乘，所有这样的变换构成SE(3)。

先要会：三维旋转的表示：旋转矩阵、欧拉角与四元数 矩阵乘法与线性变换

机器人系统里同时存在很多坐标系：世界坐标系、机器人底座、每个关节、末端夹爪、相机、目标物体。相机看到杯子在“相机前方0.5米”，夹爪需要知道它在“底座坐标系下的哪里”。把一个坐标系下的量换到另一个坐标系，是机器人、SLAM和三维视觉里最基本也最容易出错的操作。

位姿。一个坐标系B相对另一个坐标系A的位姿，由旋转R（3×3，见三维旋转的表示：旋转矩阵、欧拉角与四元数）和平移t（3维）组成。点在B中的坐标p_B换到A中：

p_A = R·p_B + t

齐次变换矩阵。把它写成一个4×4矩阵，点用齐次坐标(x, y, z, 1)：

T_AB = [[R, t], [0 0 0, 1]]，p_A = T_AB · p_B

好处是复合变成矩阵乘法：T_AC = T_AB · T_BC。逆变换有闭式：T_BA = T_AB⁻¹ = [[Rᵀ, −Rᵀ·t], [0, 1]]。所有这样的矩阵构成一个群，记作SE(3)（特殊欧几里得群）。下标的写法T_AB（“B在A中”）能帮助检查乘法顺序：相邻下标要相同才能相乘。

它出现在哪里。

  • 正运动学：机械臂末端位姿就是各关节变换的连乘T_base_ee = T_01·T_12·…，见自由度、运动学与本体感知和DH参数。
  • 相机外参与手眼标定：相机模型与多视图几何里的[R | t]就是世界到相机的变换；手眼标定求的是相机与夹爪（或底座）之间固定的T。
  • SLAM与位姿图：每个时刻的相机位姿是图中的一个节点，相邻帧之间测得的相对变换是边，回环检测加入长程约束后整体优化，如ORB-SLAM、Cartographer实时回环激光SLAM，见SLAM的基本概念：里程计、后端优化与回环。
  • 机器人动作：很多策略输出末端执行器的目标位姿或位姿增量，见动作表示：离散token、连续动作与动作块。

优化时的注意点。SE(3)不是普通的向量空间，不能直接对矩阵元素做梯度下降或取平均；常在李代数（6维向量，3维平移+3维旋转向量）上做小增量更新，再映射回去。

例子

相机安装在底座上方，T_base_cam的平移为(0, 0, 1.0)米，旋转让相机朝下（绕x轴转180°）。相机看到杯子在相机坐标系下p_cam = (0.1, 0.2, 0.8)。绕x轴转180°把(x, y, z)变成(x, −y, −z)，于是p_base = (0.1, −0.2, −0.8) + (0, 0, 1.0) = (0.1, −0.2, 0.2)：杯子在底座前方0.1米、右侧0.2米、离桌面0.2米高（按所设的坐标轴方向）。

容易误解的地方

  • 最常见的错误是把T_AB和T_BA用反，或者左乘右乘顺序搞错；坚持用带下标的记号并检查相邻下标可以避免。
  • 不同库对“位姿”的定义方向（世界到相机还是相机到世界）不同，COLMAP、OpenCV、ROS之间转换时尤其要核对。
