表征坍塌与维度坍塌

Representation and Dimensional Collapse

也叫：表征坍塌　表示坍塌　表征崩溃　representation collapse　完全坍塌　complete collapse　维度坍塌　dimensional collapse　特征坍塌　feature collapse　坍塌解　trivial solution　平凡解　防坍塌　collapse prevention　停止梯度　stop-gradient　有效秩　effective rank

自监督学习的典型失败：只要求“同一样本的两个视角表示相近”，网络最省事的解是把所有输入都映射成同一个向量。维度坍塌是较轻的版本：表示只用到少数几个方向。

先要会：自监督学习 对比学习

自监督学习里有一类方法这样训练：对同一张图做两种随机增强（裁剪、调色，见数据增强），要求网络给出的两个表示尽量接近。问题是，如果网络对任何输入都输出同一个常数向量，“两个表示相同”这个目标就完美满足了，损失为0，但表示毫无用处。这叫完全坍塌。

维度坍塌。更隐蔽的情形是：表示没有缩成一个点，但只在高维空间的少数几个方向上变化，其余维度几乎不用。可以对一批表示的协方差矩阵做特征分解（见协方差矩阵和特征分解与奇异值分解）来诊断：如果只有少数几个特征值明显大于0，就是发生了维度坍塌。

各类方法怎么防坍塌。

  • 对比学习：除了拉近正样本，还要推开负样本（其他图片），常数解会让负样本也很近，损失很大，见对比学习、SimCLR、MoCo。
  • 不对称结构：BYOL和SimSiam没有负样本，靠在一支上加预测头、另一支停止梯度（或用参数的指数移动平均做目标网络）来避免坍塌；为什么这样就够了，曾引起不少理论讨论。
  • 正则化表示的统计量：Barlow Twins要求两支表示的互相关矩阵接近单位阵，VICReg显式要求每一维的方差不低于一个阈值并去掉维度之间的协方差。
  • 聚类与均衡：SwAV、DeepCluster要求样本被均匀地分到各个簇；DINO用中心化和锐化教师输出，避免所有样本落入同一类。
  • 预测式方法：I-JEPA、V-JEPA在表示空间里预测被遮挡部分，同样依赖EMA目标网络等设计来避免坍塌（见JEPA与LeCun的世界模型路线）。

名字相近、含义不同的“坍塌”。

  • 后验坍塌与KL退火：VAE的解码器太强，忽略了隐变量，见变分推断与ELBO。
  • 模式坍塌与模式覆盖：GAN只生成少数几种样本。
  • 神经坍缩：分类网络训练末期，同类样本的最后一层特征收缩到类均值，这是一种被观察到的几何现象，并不一定是坏事。
  • 模型坍缩：反复用模型生成的数据训练下一代模型，分布逐渐退化。

例子

一批256张图的表示是128维。健康的训练中，协方差矩阵的特征值从大到小缓慢衰减，前50个方向解释了约80%的方差；发生维度坍塌时，可能前3个方向就解释了99%，其余125维几乎是常数；完全坍塌时所有方差趋于0，表示的平均余弦相似度接近1。（数字为示意）

容易误解的地方

  • 训练损失很低不代表学得好：坍塌时损失往往正是最低的。要同时监控表示的方差、有效秩或线性探针准确率。
  • 增大批次、加长训练不一定能自动避免坍塌，防坍塌机制需要在方法设计中显式加入。
