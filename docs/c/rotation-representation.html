三维旋转的表示：旋转矩阵、欧拉角与四元数

3D Rotation Representations

三维旋转只有3个自由度，却有多种写法：旋转矩阵（9个数）、欧拉角（3个角）、轴角（一个轴乘一个角）、四元数（4个数）以及神经网络常用的6D表示。各有长处，也各有陷阱，例如欧拉角的万向锁。

先要会：矩阵乘法与线性变换 自由度、运动学与本体感知

机器人末端的朝向、相机的姿态、物体的6D位姿、人体关节的转动，都离不开三维旋转。旋转构成的集合记作SO(3)：它只有3个自由度，却不是一个“平坦”的空间（转360°回到原处），所以不存在一种既只用3个数、又处处连续无奇异的表示。

旋转矩阵。3×3矩阵R，满足RᵀR = I、det R = 1。直接作用于向量v' = R·v，多次旋转就是矩阵相乘，没有奇异点。缺点是9个数有6个约束，数值误差累积后会不再正交，需要重新正交化。

欧拉角。依次绕三个轴各转一个角，例如航空里的偏航-俯仰-滚转（yaw-pitch-roll）。直观、只有3个数，但：

  • 轴的顺序有十几种约定，不同软件之间常常不一致；
  • 万向锁（gimbal lock）：当中间那次旋转为±90°时，第一和第三个轴重合，丢失一个自由度，附近的微小转动需要角度剧烈跳变才能表示；
  • 角度在±180°处不连续。

轴角与旋转向量。任何旋转都等价于绕某个单位轴n转角度θ，写成3维向量θ·n。与李代数相对应，适合表示小的旋转增量。

四元数。单位四元数q = (cos(θ/2), sin(θ/2)·n)，4个数、1个约束（长度为1）。组合旋转用四元数乘法，没有万向锁，插值平滑（四元数上的球面插值，见潜空间插值与球面插值），在机器人、图形学和SLAM（如ORB-SLAM）里非常常用。注意q和−q表示同一个旋转（双重覆盖）。

神经网络该输出什么。直接回归欧拉角或四元数会因为不连续或双重覆盖而难以训练。一种常用做法是输出两个三维向量（6个数），用施密特正交化得到旋转矩阵的前两列，第三列由叉乘得到，这种6D表示是连续的，在姿态估计和机器人策略中被广泛采用（见动作表示：离散token、连续动作与动作块、姿态估计）。另一条路是让网络结构本身对旋转等变，例如SE(3)-Transformer，见不变性与等变性。

例子

绕z轴转90°：旋转矩阵为[[0, −1, 0], [1, 0, 0], [0, 0, 1]]，把x轴(1, 0, 0)转到(0, 1, 0)。对应轴角为(0, 0, π/2)，四元数为(cos45°, 0, 0, sin45°) ≈ (0.707, 0, 0, 0.707)。万向锁：按偏航-俯仰-滚转的顺序，当俯仰为90°时，偏航10°加滚转0°与偏航0°加滚转−10°（或+10°，取决于约定）得到的是同一个朝向，三个角只剩两个有效自由度。

容易误解的地方

  • 四元数的分量顺序有(w, x, y, z)和(x, y, z, w)两种约定，混用是常见的bug。
  • 两个旋转的“距离”不能直接用欧拉角之差衡量，应使用相对旋转的角度。
