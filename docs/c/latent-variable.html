隐变量模型

Latent Variable Models

也叫：潜变量　混合模型　mixture model　GMM　高斯混合模型

在交互版中打开（看它长在树上的哪里）

假设每条数据背后有一个看不见的变量z决定了它的大致样子，先抽z再由z生成x。这样复杂的数据分布可以由简单的部件组合出来。

先要会：随机变量与概率分布 条件概率与贝叶斯公式 高斯分布

直接写出“所有人脸图片”的概率分布几乎不可能。但我们可以设想：每张脸背后有一些没被记录下来的因素，比如年龄、朝向、光照、表情；先确定这些因素，再生成图片就容易得多。这些没被观察到、却决定数据样子的因素就是隐变量。

定义。隐变量模型把数据的分布写成

p(x) = Σ_z p(z) p(x | z)（z连续时把求和换成积分）

p(z)是隐变量的先验，通常很简单；p(x | z)描述给定隐变量后数据如何生成。即使两部分都很简单，混合起来的p(x)也可以非常复杂。

最简单的例子：高斯混合模型（GMM）。z表示“属于第几个簇”，p(z = k) = π_k，p(x | z = k) = N(μ_k, σ_k²)。看到一个数据点后，用条件概率与贝叶斯公式可以算出它来自各个簇的后验概率p(z | x)，这就是“软聚类”，见聚类。

两个核心难题。一是推断：给定x，求后验p(z | x)；二是学习：只有x、没有z时，如何估计参数。两者都要对z求和或积分，z维度一高就算不出来。针对离散、低维的z有EM算法；针对连续、高维的z，有变分推断和变分推断与ELBO。

它出现在哪里。GMM-UBM说话人确认用高斯混合建模语音特征；HMM统计语音识别中的隐藏状态序列是隐变量，见隐马尔可夫模型；LDA主题模型把每篇文档的主题分布当作隐变量；变分自编码器VAE用神经网络表示p(x | z)，把z当作图片的连续隐表示，这一思路直接通向潜空间。

例子

一维GMM：p(x) = 0.3·N(x; 0, 1) + 0.7·N(x; 4, 1)。在x = 1处，第一个分量的密度是0.242，第二个是0.0044，所以p(1) = 0.3×0.242 + 0.7×0.0044 ≈ 0.0726 + 0.0031 = 0.0757。来自第一个簇的后验概率是0.0726/0.0757 ≈ 0.959：虽然第一个簇的先验只有0.3，但x = 1离它近得多。

容易误解的地方

  • 隐变量不一定对应人能理解的概念；模型学到的z可能是各种因素的纠缠混合。
  • 隐变量模型存在“标签交换”问题：把簇1和簇2的参数互换，p(x)完全相同，所以单个簇的编号没有意义。
