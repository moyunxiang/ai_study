稳定性与李雅普诺夫函数

Stability and Lyapunov Functions

也叫：李雅普诺夫稳定性　Lyapunov stability　李雅普诺夫函数　Lyapunov function　李亚普诺夫　渐近稳定　asymptotic stability　稳定性分析　stability analysis　平衡点　equilibrium point　控制李雅普诺夫函数　control Lyapunov function　CLF　神经李雅普诺夫函数

判断一个系统受扰动后会不会回到平衡点的方法：如果能找到一个类似“能量”的函数，它在平衡点为0、别处为正，并且沿着系统的运动只降不升，系统就是稳定的。这个函数叫李雅普诺夫函数。

先要会：导数、偏导与梯度 控制回路与控制频率

设计一个控制器之后，第一个问题是：它稳定吗？倒立摆被轻轻推一下，是会自己回正，还是越晃越大最终倒下？对线性系统可以看特征值，但机器人、带神经网络策略的闭环系统都是非线性的，不可能对所有初始状态逐一仿真。李雅普诺夫方法给出了一种不需要解方程的判据。

稳定性的几种含义。对平衡点x*（例如倒立摆竖直静止）：

  • 稳定：初始偏离足够小，之后的轨迹就一直停留在附近；
  • 渐近稳定：不仅停在附近，而且最终回到x*；
  • 全局渐近稳定：从任何初始状态出发都回到x*。

李雅普诺夫函数。对系统ẋ = f(x)，若存在函数V(x)满足：

  • V(x*) = 0，且x ≠ x*时V(x) > 0（像一个以平衡点为底的碗）；
  • 沿系统轨迹的变化率V̇(x) = ∇V·f(x) ≤ 0（只下不上），

则x*稳定；若x ≠ x*时V̇ < 0严格成立，则渐近稳定。物理直觉：V像总能量，有摩擦的系统能量只减不增，最终停在能量最低处。困难在于找到这样的V，没有通用方法。

线性系统。ẋ = A·x渐近稳定，当且仅当A的所有特征值实部为负（见特征分解与奇异值分解），此时总能找到二次型的李雅普诺夫函数V = xᵀPx。LQR最优控制求出的最优反馈控制律自动保证闭环稳定，这正是它在控制中受欢迎的原因之一。

在学习与AI中。

  • 安全强化学习：用李雅普诺夫函数约束策略只在“能回到安全区域”的范围内探索，见李雅普诺夫安全RL和约束MDP与安全强化学习。
  • 神经李雅普诺夫函数：用神经网络表示V，并训练或验证它满足上述条件，为学到的控制器提供稳定性证书。
  • 博弈与优化动力学：分析学习算法（如多智能体梯度动态）是否收敛时也用同样的工具，DeepNash陆军棋的算法分析中就用到了李雅普诺夫函数。

例子

带阻尼的单摆，状态为角度q和角速度ω：q̇ = ω，ω̇ = −sin q − 0.5·ω。取能量V = ½ω² + (1 − cos q)：在q=0、ω=0处为0，附近为正。计算V̇ = ω·ω̇ + sin q·q̇ = ω·(−sin q − 0.5ω) + ω·sin q = −0.5ω²，始终不大于0，所以下垂的平衡点是稳定的（进一步分析可得渐近稳定：只要还在摆动，能量就在流失）。

容易误解的地方

  • 找不到李雅普诺夫函数不代表系统不稳定，只是这个判据用不上。
  • V̇ ≤ 0只保证稳定，不保证收敛到平衡点；要得到渐近稳定需要严格不等式或额外的论证（如LaSalle不变性原理）。
