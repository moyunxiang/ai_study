负面提示

Negative Prompts

也叫：负面提示　负面提示词　反向提示词　负向提示　negative prompt　negative prompting　负提示　引导尺度　CFG scale　cfg scale

在交互版中打开（看它长在树上的哪里）

文生图时额外给一段“不想要什么”的文字（如“模糊、多余的手指”）。实现上就是在无分类器引导里，用这段文字的预测替换掉空提示的预测，让采样方向远离它。

先要会：条件生成与引导 扩散：前向加噪与反向去噪

用户常遇到这样的情况：提示词写得再详细，生成的图仍然带水印、画面模糊、手指数目不对。直接在提示里写“不要模糊”往往无效，因为文本编码器对否定词理解很差，“不要模糊”的向量反而和“模糊”很接近。负面提示提供了另一个输入框，专门写不想要的内容。

它是怎么实现的。回顾条件生成与引导里的无分类器引导（无分类器引导CFG）：去噪网络对同一个x_t做两次预测，一次带提示c，一次带空提示∅，再外推：

ε̃ = ε(x_t, ∅) + w · (ε(x_t, c) − ε(x_t, ∅))

w是引导尺度（常取5到10）。这相当于从“无条件”的方向出发，朝“有条件”的方向多走w倍。负面提示只是把空提示换成负面文字c⁻：

ε̃ = ε(x_t, c⁻) + w · (ε(x_t, c) − ε(x_t, c⁻))

于是采样的推力变成了“从负面描述指向正面描述”，既靠近想要的，又远离不想要的。它不需要任何额外训练，也不增加计算量（本来就要算两次预测）。这一做法随Stable Diffusion开源的开源社区工具流行起来，后来被各大文生图界面普遍采用。

引导尺度的作用。w越大，图像越贴合提示（和越远离负面提示），但过大会导致颜色过饱和、细节生硬。一些改进方法在采样后期减小w，或对引导结果做重新缩放，见CFG-Zero*流匹配引导这类后续工作。

局限。负面提示的效果依赖文本编码器对那些词的理解，对“六根手指”这类精确的计数约束帮助有限；用蒸馏得到的少步模型（见少步采样与扩散蒸馏）常常不再做CFG，也就没有负面提示的入口，需要另外的设计。

例子

引导尺度w=7。某个像素位置上，带正面提示的预测为0.30，带负面提示“模糊、低质量”的预测为0.10，空提示的预测为0.20。普通CFG：0.20 + 7×(0.30 − 0.20) = 0.90；使用负面提示：0.10 + 7×(0.30 − 0.10) = 1.50，推力更大，方向是“离开模糊”。

容易误解的地方

  • 负面提示不是逻辑上的“排除”，它只是把采样方向往远离那段描述的地方推，并不保证结果里完全没有那些内容。
  • 负面提示写得过长或与正面提示冲突时，会显著改变整体风格，带来意外的副作用。
