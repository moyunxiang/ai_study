多模态幻觉

Multimodal Hallucination

也叫：物体幻觉　Object Hallucination　VLM幻觉　LVLM Hallucination　视觉幻觉　幻觉缓解　Hallucination Mitigation　多模态偏好对齐　对比解码

在交互版中打开（看它长在树上的哪里）

多模态模型说出图中并不存在的物体、属性或关系，这是VLM最常被诟病的可靠性问题。

幻觉在多模态模型里有具体表现：看到餐桌就说有叉子，因为训练数据里两者常一起出现。成因包括语言模型的先验过强、视觉编码器丢失细节（CLIP视觉盲区）、指令数据本身由文本模型编造。POPE物体幻觉用“图里有没有某物”的是/否问题量化物体幻觉，成为标准评测。

缓解办法分三类。训练阶段做偏好对齐：LLaVA-RLHF事实增强把RLHF搬到VLM，奖励模型额外参考图像描述等事实，之后也有大量多模态DPO直接偏好优化式工作。解码阶段免训练修正：VCD视觉对比解码比较原图和加噪图的输出，压低只靠语言先验也会说出的词。感知阶段增强：提高分辨率、主动搜索局部（V*引导视觉搜索）。争议在于：基准上幻觉率下降，往往伴随回答变短、变保守，真实场景中的长回答幻觉仍难评估。
