单细胞与虚拟细胞模型

Single-Cell Foundation Models

也叫：虚拟细胞　Virtual Cell　单细胞基础模型　scFM　细胞语言模型　single-cell LLM

在交互版中打开（看它长在树上的哪里）

在海量单细胞测序数据上预训练模型，用来预测细胞类型、扰动反应，目标是模拟细胞。

单细胞测序产生大量数据但任务零散。做法是把每个细胞的基因表达当序列，用Transformer预训练。Geneformer单细胞模型按基因表达排序做输入，scGPT用生成式预训练，C2S-Scale单细胞大模型把细胞写成文本交给大语言模型，Evo 2则在DNA层面建模。争论在于这些模型在扰动预测等任务上是否真优于简单基线。
