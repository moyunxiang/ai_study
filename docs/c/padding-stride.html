步长、填充与特征图尺寸

Stride, Padding and Feature-Map Size

也叫：步长　stride　填充　padding　零填充　zero padding　same padding　valid padding　特征图　feature map　特征图尺寸　输出尺寸公式　卷积输出大小　空洞率　dilation　下采样　downsampling

卷积和池化层输出的“特征图”有多大，由卷积核大小k、步长s、填充p（以及空洞率d）决定：输出边长 = ⌊(输入 + 2p − d·(k−1) − 1) / s⌋ + 1。读网络结构、写代码对齐形状都离不开这条公式。

先要会：卷积层、池化与感受野 图像作为张量

卷积层、池化与感受野讲了卷积核怎样在图像上滑动。实际搭网络时，最常出错的是形状：这一层输出多大？下一层的全连接要接多少个输入？几个超参数决定了答案。

特征图（feature map）。卷积层的输出是一个C × H × W的张量（见图像作为张量）：C个通道，每个通道是一张H×W的“图”，记录某个卷积核在各个位置的响应强度。浅层的特征图分辨率高、通道少，深层的分辨率低、通道多。

步长（stride，s）。卷积核每次移动几个像素。s=1时逐像素滑动，输出与输入差不多大；s=2时隔一个取一个，输出边长约减半，常用来代替池化做下采样。

填充（padding，p）。在输入四周补p圈0（或镜像值）。不填充时，每做一次k×k卷积，边长减少k−1，边缘像素也被“看”得更少。常见两种约定：

  • valid：不填充，p=0。
  • same：步长为1时，取p = (k − 1)/2，使输出与输入一样大，例如3×3卷积配p=1。

输出尺寸公式（每个空间维度分别计算）：

out = ⌊(in + 2p − d·(k − 1) − 1) / s⌋ + 1

d是空洞率（dilation），普通卷积d=1，此时化简为⌊(in + 2p − k)/s⌋ + 1。空洞卷积在核的元素之间插入空隙，等效核大小变为d·(k−1)+1，不增加参数就扩大了感受野，见DeepLab空洞卷积。池化层用同一个公式。

例子里的设计。AlexNet第一层用11×11、步长4的大卷积快速缩小分辨率；VGG全部使用3×3、步长1、填充1的卷积，空间尺寸只靠池化减半；ResNet用步长2的卷积下采样。转置卷积按相反方向放大尺寸，见上采样与转置卷积。

例子

输入224×224×3，第一层64个7×7卷积核、步长2、填充3：输出边长⌊(224 + 6 − 7)/2⌋ + 1 = 111 + 1 = 112，得到112×112×64的特征图。再接3×3、步长2、填充1的最大池化：⌊(112 + 2 − 3)/2⌋ + 1 = 56，得到56×56×64。这正是ResNet开头两层的形状。

容易误解的地方

  • 公式里的向下取整会悄悄丢掉边缘的行列：输入边长为奇数、步长为2时，最后一行可能没有被任何窗口覆盖。
  • 不同框架对same填充在步长大于1时的处理不同（不对称填充），模型在框架间转换时可能出现一个像素的错位。
