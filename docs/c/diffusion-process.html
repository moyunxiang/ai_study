扩散：前向加噪与反向去噪

Diffusion: Forward Noising and Reverse Denoising

也叫：扩散模型　diffusion model　DDPM　去噪扩散　denoising diffusion　加噪去噪

在交互版中打开（看它长在树上的哪里）

先把数据一步步加高斯噪声直到变成纯噪声（前向），再训练网络学会每一步去掉一点噪声（反向），生成时从纯噪声出发反复去噪得到新样本。

先要会：高斯分布 马尔可夫性与马尔可夫链 生成建模的目标 变分推断与ELBO

直接学“从噪声一步变出一张图”很难，GAN就因此训练不稳。扩散模型把这件难事拆成上千件小事：每一步只去掉一点点噪声。每个小步都是一个简单的回归问题，训练稳定，规模也容易做大。

前向过程（加噪，不需要学习）。从真实数据x₀出发，每一步按方差β_t混入一点高斯分布噪声：

x_t = √(1−β_t)·x_{t−1} + √β_t·ε，ε ~ N(0, I)

β_t很小（DDPM里从0.0001线性增加到0.02，共T=1000步）。这是一条马尔可夫性与马尔可夫链，走到底x_T几乎就是标准高斯噪声。由于高斯叠加高斯还是高斯，任意一步都能从x₀一步算出：

x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε，其中 ᾱ_t = Π_{s≤t}(1−β_s)

ᾱ_t表示还剩多少原信号，从接近1降到接近0。这个公式让训练不必真的一步步加噪。

反向过程（去噪，需要学习）。训练一个网络ε_θ(x_t, t)，输入加噪后的x_t和步数t，预测当初混进去的噪声ε。损失就是均方误差：

L = E‖ε − ε_θ(√ᾱ_t·x₀ + √(1−ᾱ_t)·ε, t)‖²

每个训练样本随机抽一个t、抽一个ε即可。这个简单损失可以从变分推断与ELBO推出来。生成时从纯噪声x_T出发，用预测的噪声算出稍微干净一点的x_{t−1}，再补上一点随机噪声，重复T次得到x₀。

它在哪里。思想最早来自扩散模型的起点，DDPM让它真正好用，潜空间扩散LDM搬到潜空间里做成了Stable Diffusion，今天的文生图、文生视频大多以此为基础。它与分数函数与分数匹配是一回事的两种说法：预测噪声等价于估计分数。步数怎么取、噪声怎么排见噪声调度与采样步数，文字怎么控制生成见条件生成与引导。

例子

一个像素值x_{t−1}=0.8，这一步β_t=0.02，抽到噪声ε=−0.5。前向一步：√0.98×0.8 + √0.02×(−0.5) = 0.792 − 0.071 ≈ 0.721。原值被缩小了一点，再叠上一点噪声。

用DDPM的线性调度一步跳到t=500：累乘得ᾱ₅₀₀≈0.0786，于是x₅₀₀ = √0.0786×0.8 + √0.9214×ε ≈ 0.280×0.8 + 0.960×ε。原信号只剩0.28倍，噪声占了大头。到t=1000时ᾱ≈0.00004，√ᾱ≈0.006，几乎只剩噪声。训练时网络看到x₅₀₀和t=500，要猜出ε是多少。

容易误解的地方

  • “扩散”只是借用物理里墨水在水中扩散的比喻，模型并不模拟物理过程。
  • 网络不是直接输出干净图像，而是常预测噪声ε（也有预测x₀或速度v的变体），三者可以互相换算。
  • 1000步不是必须的：训练用1000步，采样可以用DDIM等方法跳着走，只用几十步。
