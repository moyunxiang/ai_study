超节点与纵向扩展

Scale-Up Domain / SuperPod

也叫：超节点　SuperPod　Scale-up　纵向扩展　NVL72　机柜级系统　Rack-scale　整机柜　Scale-up网络　Scale-out　横向扩展　高带宽域　HBD

在交互版中打开（看它长在树上的哪里）

把几十到上千颗加速器用高带宽互连连成一个整体，让它们像一块巨大的GPU一样共享内存和通信。

大模型训练和推理需要的显存和算力远超单卡，张量并行、专家并行这类切分方式要求芯片之间频繁交换数据。服务器之间的普通网络（scale-out）带宽不够，于是出现了“纵向扩展”：在一个机柜甚至多个机柜内用专用互连把芯片连成高带宽域。

NVIDIA从NVLink与NVSwitch起步，到Blackwell与整机柜液冷的NVL72把72颗GPU连成一个NVLink域，路线图上的Rubin Ultra与Kyber路线图和Vera Rubin NVL72继续加大规模。谷歌TPU v4与光路交换用光路交换连起4096颗TPU。华为CloudMatrix 384超节点用384颗昇腾组成超节点，以数量弥补单卡性能差距。AMD的AMD Helios机柜与MI455X和开放标准UALink开放互连试图提供非NVIDIA的方案，NVIDIA则推出NVLink Fusion开放互连对第三方开放。

争论包括：超节点越大，功耗、散热和故障域越难管理；铜缆还是光互连；开放标准能否追上NVLink。
