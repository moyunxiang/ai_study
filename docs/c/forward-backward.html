前向算法与前向-后向算法

Forward and Forward–Backward Algorithms

也叫：forward algorithm　前向算法　backward algorithm　后向算法　forward-backward algorithm　前向-后向算法　前向后向算法　alpha-beta递推　HMM评估问题　配分函数计算

在交互版中打开（看它长在树上的哪里）

在HMM、CRF这类链式模型上用动态规划高效求和的算法：前向算法算出整条观测序列的概率，前向-后向算法进一步算出每个位置取每个隐状态的后验概率，是训练这些模型的核心步骤。

先要会：隐马尔可夫模型 动态规划

隐马尔可夫模型有三个基本问题：给定模型，一条观测序列出现的概率是多少（评估）？最可能的隐状态序列是什么（解码）？怎样从数据学出参数（学习）？解码由Viterbi算法算法解决；评估和学习靠的就是前向算法和前向-后向算法。

为什么需要它。观测序列的概率要对所有可能的隐状态路径求和：P(o) = Σ_路径 P(o, 路径)。N个隐状态、长度T的序列有N^T条路径，直接枚举不可行。但HMM有马尔可夫性与马尔可夫链结构，可以用动态规划把求和逐步拆开。

前向算法。定义α_t(j)为“看到前t个观测、且第t步处在状态j”的概率：

α_1(j) = π_j · b_j(o_1)

α_t(j) = [Σ_i α_(t−1)(i) · a_ij] · b_j(o_t)

P(o) = Σ_j α_T(j)

其中π是初始概率，a_ij是转移概率，b_j(o)是发射概率。复杂度从N^T降到N²·T。它和Viterbi几乎一样，只是把“取最大”换成了“求和”。

后向算法与后验。对称地定义β_t(i)为“第t步在状态i的条件下，看到后面所有观测”的概率，从后往前递推。两者相乘就得到每个位置的后验：

P(第t步在状态i | o) = α_t(i)·β_t(i) / P(o)

类似地可以求出相邻两步的状态对的后验。

用在哪里。

  • 训练HMM：Baum-Welch算法算法是EM算法在HMM上的特例：E步用前向-后向算出状态后验和转移后验的期望计数，M步按计数重新估计参数。这是统计语音识别（HMM统计语音识别）的训练基础，Rabiner的HMM教程是经典讲解。
  • 训练CRF：条件随机场的对数似然需要配分函数（所有标签序列打分之和），同样用前向算法计算；梯度中的期望由前向-后向算出。
  • CTC：CTC用同样的前向-后向递推，对所有可能的对齐路径求和（见输入输出不等长时的对齐）。

例子

两个隐状态：热H、冷C。初始概率π = (0.6, 0.4)。转移：H→H 0.7、H→C 0.3、C→H 0.4、C→C 0.6。观测“吃冰淇淋的个数”，第1天吃3个：b_H(3) = 0.4、b_C(3) = 0.1；第2天吃1个：b_H(1) = 0.2、b_C(1) = 0.5。

  • 第1天：α_1(H) = 0.6×0.4 = 0.24，α_1(C) = 0.4×0.1 = 0.04。
  • 第2天：α_2(H) = (0.24×0.7 + 0.04×0.4)×0.2 = 0.184×0.2 = 0.0368；α_2(C) = (0.24×0.3 + 0.04×0.6)×0.5 = 0.096×0.5 = 0.048。
  • P(“3, 1”) = 0.0368 + 0.048 = 0.0848。

枚举全部4条路径求和，结果完全一样；但序列长度为100时，枚举要2^100条路径，前向算法只需约400次乘加。

容易误解的地方

  • 连乘很多小于1的概率会下溢为0，实际实现要在对数空间计算（用log-sum-exp）或每步做归一化缩放。
  • 前向-后向给出的是每个位置最可能的状态，把它们拼起来不一定是一条合法或整体最优的路径；要整体最优的路径应该用Viterbi。
