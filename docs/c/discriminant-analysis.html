判别分析：LDA与QDA

Linear and Quadratic Discriminant Analysis

也叫：判别分析　discriminant analysis　线性判别分析　linear discriminant analysis　二次判别分析　quadratic discriminant analysis　QDA　高斯判别分析　Gaussian discriminant analysis　GDA　正则化判别分析　regularized discriminant analysis　Fisher判别　Fisher discriminant　LDA降维　有监督降维

生成式分类器：假设每类数据服从一个多元高斯，用贝叶斯公式算各类的后验概率。各类共享协方差时边界是直线（LDA），协方差各不相同时是二次曲线（QDA）。

先要会：高斯分布 条件概率与贝叶斯公式 协方差矩阵

逻辑回归直接学习“给定x时y是哪一类”，是判别模型。另一条路是先为每一类建模“这一类的数据长什么样”p(x | y)，再用条件概率与贝叶斯公式反推p(y | x) ∝ p(x | y)·p(y)，这是生成模型（见判别模型与生成模型）。高斯判别分析是其中最经典的一种。

模型。对每个类别k，假设x | y = k ~ N(μ_k, Σ_k)（见高斯分布），先验p(y = k) = π_k。参数直接从训练数据算：μ_k是第k类样本的均值，Σ_k是它们的协方差（见协方差矩阵），π_k是该类所占比例，这就是最大似然估计的解，不需要迭代优化。

线性判别分析（LDA）。假设所有类别共享同一个协方差矩阵Σ。两类的对数后验比中二次项相互抵消，只剩下x的线性函数：

log p(y=1|x)/p(y=0|x) = wᵀx + b，w = Σ⁻¹(μ₁ − μ₀)

所以决策边界是超平面。有意思的是，它的后验恰好是逻辑回归的形式：LDA与逻辑回归给出同一族分类器，只是参数的估计方式不同。LDA的方向w与Fisher线性判别中“让类间距离大、类内方差小”的投影方向一致，所以LDA也常用作有监督的降维：K类数据最多投影到K − 1维（对比无监督的PCA，见降维与PCA）。

二次判别分析（QDA）。允许每类有自己的Σ_k，对数后验比中保留了二次项，边界是椭圆、双曲线等二次曲面。更灵活，但参数多得多：d维时每类要估计约d²/2个协方差参数，样本少时很不稳定。在两者之间可以对协方差做收缩（正则化判别分析），见偏差-方差权衡。

它的位置。朴素贝叶斯分类可以看作再进一步假设协方差是对角阵（各特征条件独立）。与逻辑回归相比，高斯假设成立时LDA更省样本；假设不成立（如特征明显非高斯、有很多离群点）时，逻辑回归通常更稳健。

名字撞车。机器学习里的LDA有两个：这里的线性判别分析（Linear Discriminant Analysis），和主题模型LDA主题模型（Latent Dirichlet Allocation，见Beta分布、狄利克雷分布与共轭先验），二者毫无关系。

例子

两类二维数据，μ₀ = (0, 0)、μ₁ = (2, 2)，共享Σ = 单位阵，先验相等。w = Σ⁻¹(μ₁ − μ₀) = (2, 2)，边界是两均值连线的垂直平分线x₁ + x₂ = 2。点(1.5, 1)满足1.5 + 1 = 2.5 > 2，判为第1类。若第1类的协方差改为4倍单位阵（更分散），QDA的边界会变成围着第0类的一个圆。

容易误解的地方

  • Σ不可逆（特征数多于样本数或特征共线）时，LDA的公式无法直接使用，需要收缩或先降维（见逆矩阵与伪逆）。
  • 不要把判别分析的LDA和主题模型的LDA混为一谈，搜索资料时尤其注意。
