分布式RL训练架构

Distributed / Actor-Learner RL Architectures

也叫：分布式强化学习训练　actor-learner　actor-learner架构　大规模并行RL　异步RL　Ape-X　IMPALA　SEED RL　分布式经验回放

在交互版中打开（看它长在树上的哪里）

把“与环境交互采样”和“更新网络”拆到大量并行的机器上，用算力换样本吞吐。注意与按价值分布建模的“分布式RL”不是一回事。

RL的瓶颈常在采样：环境模拟慢，单机一秒只能跑有限步。Gorila分布式DQN首先把DQN拆成大量并行的执行者与学习者，A3C用多线程异步更新取代经验回放，Ape-X和R2D2用分布式优先回放，IMPALA与V-trace用V-trace修正执行者策略与学习者策略的时间差，实现每秒数十万帧的吞吐。

这些架构直接支撑了OpenAI Five、AlphaStar、夺旗：种群训练的第一人称多人游戏等大规模博弈训练，也是Agent57等Atari成果的基础。后来JaxMARL等把环境也写进GPU，走向另一种并行方式。中文里“分布式RL”常被同时用来指这里的分布式训练和分布式价值RL（Distributional RL）的价值分布建模，搜索时需留意。
