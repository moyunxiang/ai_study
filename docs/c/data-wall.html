数据墙与数据受限训练

The Data Wall and Data-Constrained Training

也叫：data wall　数据墙　数据耗尽　running out of data　token危机　token crisis　多轮训练　multi-epoch training　重复数据　data repetition　数据受限规模定律

在交互版中打开（看它长在树上的哪里）

互联网高质量文本即将被用完，算力还在涨，模型该怎样在数据不够的情况下继续变强。

Chinchilla式的配比要求数据随模型同步增长，但公开高质量文本是有限的。数据受限的规模定律系统研究了重复训练：自回归模型重复约4轮还接近新数据，之后收益迅速衰减；训练数据去重说明重复的样本本身会损害泛化。应对思路有几类：用合成数据补充（教科书级数据phi-1，但要警惕模型坍缩）；改训练目标以更好地榨取重复数据——数据受限时扩散胜自回归发现掩码扩散模型可以有效重复上百轮，在算力充足、数据稀缺时反超自回归；以及把算力转移到后训练和推理时扩展。

“数据墙”是否真的存在、何时到来，以及合成数据能否无限替代真实数据，是2025–2026年反复出现的争论。
