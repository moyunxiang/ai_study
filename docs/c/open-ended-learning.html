开放式学习与自动课程

Open-Ended Learning and Autocurricula

也叫：open-endedness　开放式学习　开放性　autocurriculum　自动课程　curriculum learning　课程学习　通才智能体　generally capable agents　任务生成

在交互版中打开（看它长在树上的哪里）

不给智能体固定的单一任务，而让任务、对手或环境本身随学习不断变难、变多，期待能力持续增长。

固定任务一旦学会，学习就停了。开放式学习希望训练过程本身能不断产生新的挑战。多智能体是一个天然来源：捉迷藏中的涌现工具使用里捉与藏双方轮番发明新策略，形成自动课程；Neural MMO研究种群规模如何推动技能分化。

另一条路是程序化生成任务：XLand开放式学习在大量生成的游戏里训练出能零样本应对新任务的智能体，AdA人类时间尺度适应进一步做到人类时间尺度的适应，SIMA多游戏指令智能体与SIMA 2把它带到多个商业游戏和语言指令；Go-Explore则从探索角度保存并回到“有希望的状态”。争论在于怎样衡量“开放性”，以及计算开销是否可承受。
