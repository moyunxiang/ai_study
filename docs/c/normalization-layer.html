归一化层

Normalization Layers

也叫：BatchNorm　LayerNorm　RMSNorm　BN　LN　批归一化　层归一化　标准化层

在交互版中打开（看它长在树上的哪里）

在网络中间把一组激活值减去均值、除以标准差（或只除以均方根），再乘上可学习的缩放。它让各层输入的数值尺度保持稳定，深网络更好训练。

先要会：期望与方差 多层感知机 随机梯度下降与小批量

训练时每一层的输入是前面所有层的输出。前面的参数一更新，后面各层看到的数值分布就跟着变：均值漂移、方差变大或变小。数值太大会让激活函数饱和、梯度爆炸，太小则信号消失。学习率因此只能设得很小，深网络训得很慢。归一化层的思路很朴素：在中间强行把数值拉回均值0、方差1附近。

通用公式。对一组数x_1…x_n：

μ = (1/n)·Σ x_i，σ² = (1/n)·Σ (x_i − μ)² y_i = γ_i · (x_i − μ) / √(σ² + ε) + β_i

ε是防止除以0的小常数（如10^(−5)）。γ和β是可学习的缩放和平移：如果网络发现原来的尺度更好，可以学回来。各种归一化的区别只在于这“一组数”怎么取（见期望与方差）：

  • BatchNorm（Batch Normalization，2015）：对同一个特征，在一个小批量的所有样本上求均值方差。它让ResNet时代的卷积网络可以用大得多的学习率。缺点是依赖批（见随机梯度下降与小批量）：批太小时统计量很吵；推理时没有批，只能用训练中累积的移动平均。
  • LayerNorm（Layer Normalization，2016）：对单个样本、单个位置的所有特征维度求均值方差，与批里其他样本无关。序列长度不固定、批内统计不稳定的RNN和Transformer因此都用它。
  • RMSNorm（RMSNorm，2019）：去掉减均值这一步，只除以均方根：y_i = γ_i · x_i / √((1/n)·Σ x_j² + ε)。计算更省，效果相当，LLaMA之后的大模型基本都用它。
  • Group Normalization把通道分成若干组分别归一化，适合批很小的检测和分割任务。

放在哪里。在Transformer里，原始设计把LayerNorm放在残差相加之后（post-LN）；后来发现放在每个子层的输入处（pre-LN，x + F(LN(x))）训练稳定得多，深模型可以不用很长的warmup（见Pre-LN Transformer和Transformer层的结构）。2025年的无归一化Transformer DyT则尝试用一个简单的逐元素tanh函数替代归一化。

例子

对一个位置的4维向量x = [1, 2, 3, 6]做LayerNorm（取γ = 1，β = 0，忽略ε）：

均值μ = 12/4 = 3；方差σ² = (4 + 1 + 0 + 9)/4 = 3.5，σ ≈ 1.871。输出 = (x − 3)/1.871 ≈ [−1.069, −0.535, 0, 1.604]，均值0、方差1。

同一个向量做RMSNorm：均方根 = √((1 + 4 + 9 + 36)/4) = √12.5 ≈ 3.536，输出 ≈ [0.283, 0.566, 0.849, 1.697]。它没有把均值移到0，只把整体尺度统一了。

如果这是BatchNorm，求平均的方向就换了：对批里比如32个样本的“第1个特征”求均值方差，而不是对一个样本的4个特征。

容易误解的地方

  • BatchNorm在训练和推理时行为不同（批统计量 vs 移动平均）。忘记切换到推理模式（PyTorch里的model.eval()）是常见bug。
  • BatchNorm最初的解释是减少“内部协变量偏移”，后来的研究（BN为何有效之争）认为它真正的作用更可能是让损失曲面更平滑。为什么归一化有效至今没有完全定论。
  • 归一化之后的γ、β通常不加权重衰减，否则会把有用的尺度压掉。
