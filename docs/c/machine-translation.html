机器翻译

Machine Translation

让计算机把一种语言的文本自动译成另一种语言，是NLP最早也最持久的核心任务。

机器翻译几乎和计算机同龄：Weaver翻译备忘录提出把翻译当作解码问题，Georgetown–IBM机器翻译实验做出第一次公开演示，此后二十年靠手写词典和规则（SYSTRAN规则机器翻译），直到ALPAC报告报告认为前景有限，经费被砍。

1990年前后IBM把翻译改写成噪声信道与词对齐上的概率估计（噪声信道翻译模型、IBM统计翻译模型），随后短语统计机器翻译、层次短语翻译Hiero、Moses让统计翻译成为主流，BLEU让系统可以每天自动比较。2014年起，编码器-解码器（Seq2Seq）和注意力机制把翻译变成端到端学习，谷歌神经机器翻译上线后神经翻译全面取代统计翻译，Transformer本身就是为翻译设计的。

今天的争论集中在两点：通用大模型直接翻译是否已经够用，还是专门训练的翻译模型（NLLB两百种语言翻译、Seed-X翻译模型、混元翻译Hunyuan-MT、TranslateGemma）仍有优势；以及自动指标能否可靠反映译文质量。
