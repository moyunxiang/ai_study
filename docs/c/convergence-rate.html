收敛速率与强凸

Convergence Rates and Strong Convexity

也叫：收敛速率　收敛速度　convergence rate　rate of convergence　收敛性　收敛性分析　convergence analysis　线性收敛　linear convergence　次线性收敛　sublinear convergence　强凸　strongly convex　strong convexity　O(1/t)　O(1/√t)　迭代复杂度　iteration complexity　加速梯度　accelerated gradient　SVRG

衡量优化算法要多少步才能达到给定精度：线性收敛每步误差乘一个固定比例，O(1/t)、O(1/√t)等次线性收敛慢得多。强凸、光滑、梯度噪声决定能达到哪一档。

先要会：梯度下降 凸函数与凸优化

比较优化器时，除了实验曲线，理论分析给出的是收敛速率：迭代t步之后，误差（与最优值的差距f(x_t) − f*，或与最优点的距离）至多是多少。

几档常见的速率。

  • 线性收敛：误差_t ≤ C·ρ^t，0 < ρ < 1。每一步误差乘以一个固定比例，在对数坐标下是一条直线下降。要达到精度ε需要O(log(1/ε))步。名字里的“线性”指的是对数误差随步数线性下降。
  • 次线性收敛：O(1/t)、O(1/t²)、O(1/√t)。要达到精度ε分别需要1/ε、1/√ε、1/ε²步，比线性收敛慢得多。
  • 二次收敛：误差每步大致平方，有效数字翻倍，只有牛顿法与拟牛顿法这类二阶方法在最优点附近能做到。

决定速率的条件（以梯度下降为例）。

  • f凸且β-光滑（见利普希茨连续与光滑性）：步长取1/β时为O(1/t)。
  • 再加上μ-强凸（函数至少像一个曲率为μ的二次函数那样弯）：变为线性收敛，ρ约为1 − μ/β。比值κ = β/μ就是条件数（见数值稳定性：上溢、下溢与条件数），κ越大收敛越慢。
  • Nesterov加速梯度加速把凸光滑情形改进到O(1/t²)，强凸情形的ρ改进到约1 − √(μ/β)，并且在只用梯度信息的算法里这已是最优，见动量。
  • 随机梯度：梯度有噪声时，固定步长只能收敛到最优点附近的一个“噪声球”；要真正收敛，步长必须衰减，速率降为凸情形O(1/√t)、强凸情形O(1/t)。这是随机梯度下降（Robbins–Monro随机逼近）的经典结论，也是学习率衰减的理论动机（见学习率与学习率调度）。SAG、SVRG等方差缩减方法在有限和问题上恢复了线性收敛。
  • 非凸（神经网络）：一般只能保证找到梯度很小的点，梯度下降为‖∇f‖² = O(1/t)，SGD为O(1/√t)，不保证是全局最优（见损失曲面、局部极小与鞍点）。

怎么读论文里的收敛定理。看清楚：假设了什么（凸？强凸？光滑？梯度有界？），误差衡量的是函数值、参数距离还是梯度范数，常数里藏了什么（条件数、维度）。很多“更快”的速率只在特定假设下成立。

例子

要把误差降到ε = 10⁻⁶：

  • 线性收敛ρ = 0.9：需要ln(10⁶)/ln(1/0.9) ≈ 131步；ρ = 0.999（条件数约1000）：约13800步。
  • O(1/t)：约10⁶步；O(1/t²)：约10³步；O(1/√t)：约10¹²步。

容易误解的地方

  • 速率是上界，不等于实际表现；实际问题常常比最坏情况快。
  • 不同速率的比较要看“误差用什么衡量”：函数值误差O(1/t)与梯度范数O(1/t)不是一回事。
