因果掩码

Causal Mask

也叫：causal mask　因果注意力　causal attention　因果注意力掩码　look-ahead mask　下三角掩码　masked self-attention　掩码自注意力　自回归掩码　future mask　triangular mask

在交互版中打开（看它长在树上的哪里）

自注意力里的一个下三角掩码：第t个位置只能看到第1到t个位置，看不到后面的token。它让自回归模型可以在一次前向计算里并行训练所有位置。

先要会：自注意力与多头注意力 自回归生成 Softmax与logits

自注意力与多头注意力本身是“全看”的：每个位置都和序列里所有位置算相关性。这对理解一句话没问题，但对自回归生成的语言模型是作弊——训练时整句话都摆在那里，如果第3个位置能看到第4个词，“预测下一个词”就成了抄答案。

定义。在注意力分数矩阵S = QKᵀ/√d（n×n）上加一个掩码M：

M_ij = 0（j ≤ i），M_ij = −∞（j > i）

Attention = softmax(S + M)·V

−∞经过Softmax与logits变成0，所以第i行的权重只分布在前i个位置上。这个矩阵的有效部分是一个下三角，所以也叫下三角掩码、look-ahead mask。

为什么能并行训练。有了掩码，长度为n的序列一次前向计算就同时得到n个位置“基于前文预测下一个token”的结果，n个损失一起算；不需要像RNN那样一步步展开。这是Transformer语言模型训练效率高的关键之一，见Transformer和GPT-1。推理时则一次只新增一个token，它天然只能看到前文，配合KV缓存就不必重算历史。

几种掩码模式。掩码决定了模型的“读法”，不同架构的区别很大程度上就在这里（见仅编码器、仅解码器与编码器-解码器）：

  • 全可见（双向）：编码器如BERT，每个位置看全句。
  • 因果：解码器如GPT-2，只看左边。
  • 前缀：前缀部分双向互看，后半部分因果生成（见前缀语言模型）。
  • 编码器-解码器：解码器自注意力用因果掩码，交叉注意力可以看编码器的全部输出（见交叉注意力）。

此外，填充位置的掩码（见填充、截断与注意力掩码）和拼接多文档时的块对角掩码（见序列打包与文档掩码）会和因果掩码叠加使用。

例子

序列“我 爱 你”（3个token）的因果掩码：

[[0, −∞, −∞], [0, 0, −∞], [0, 0, 0]]

设第2行（“爱”）的原始分数是 [1.0, 2.0, 3.0]，加掩码后为 [1.0, 2.0, −∞]，softmax得 [0.27, 0.73, 0]：“爱”只从“我”和自己那里取信息，看不到“你”。一次前向计算同时产生三个预测：看到“我”预测“爱”，看到“我 爱”预测“你”，看到“我 爱 你”预测结束符。

容易误解的地方

  • 因果掩码只限制注意力；如果别的模块（例如某些归一化或卷积）在序列维度上混合了信息，未来信息仍可能泄漏。
  • 实现里一般不真用−∞，而是用该精度能表示的很大负数；整行都被遮住时softmax会出现NaN，需要特殊处理。
  • “因果”在这里只是“只看过去”的意思，和因果推断无关。
