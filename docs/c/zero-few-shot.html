零样本与少样本

Zero-shot and Few-shot

也叫：零样本学习　少样本学习　zero-shot learning　few-shot learning　小样本　one-shot　单样本

在交互版中打开（看它长在树上的哪里）

零样本指模型在没有见过任何目标任务训练样本的情况下完成任务；少样本指只给几个例子（几条到几十条）就完成任务。

先要会：预训练与微调 嵌入向量 上下文学习与提示

传统的监督学习每做一个新任务都要收集成百上千条标注数据并重新训练。如果一个模型能只看任务说明、或只看几个例子就学会新任务，部署成本会大幅下降。这就是零样本和少样本的目标。

  • 零样本（zero-shot）：不提供目标任务的任何带标签样本。模型要靠别的途径知道任务是什么，比如一段自然语言描述，或者类别名称的文字。
  • 少样本（few-shot）：只提供k个带标签的样本，常写作“k-shot”，如1-shot、5-shot。

两种实现路线：

1. 共享嵌入空间：把输入和类别描述放进同一个嵌入向量空间，看输入离哪个类别描述最近。CLIP用4亿对图文训练出图文共享的空间，分类时把每个类别名写成“一张……的照片”，与图像嵌入比较相似度。论文报告它不用ImageNet的128万张训练图，零样本就达到了原始ResNet-50的准确率。 2. 上下文学习：大语言模型在提示里读到任务说明和几个示例，不更新任何参数就能完成新任务，见上下文学习与提示。GPT-3系统地展示了这一能力，并把零样本、单样本、少样本作为标准评测设置。

在此之前，少样本学习主要通过元学习研究：匹配网络与小样本学习和MAML元学习训练模型“学会如何快速学习”。今天这些方法大多被大规模预训练与微调得到的模型所取代。

例子

用CLIP做零样本分类：把三条文字“一张猫的照片”“一张狗的照片”“一张汽车的照片”编码成文本嵌入，再把一张图编码成图像嵌入。若图像与三者的余弦相似度分别为0.31、0.24、0.18，就判为猫。整个过程没有用任何一张标注过的猫狗图片做训练。

语言模型的3-shot提示： “英译中：apple → 苹果；book → 书；water → 水；cat →” 模型续写“猫”。

容易误解的地方

  • “零样本”只是说没有目标任务的标注样本，并不意味着模型从未见过类似数据。网络规模的预训练语料中很可能有相似内容，见数据泄漏与基准污染。
  • 少样本的结果对示例的选择和顺序往往很敏感，同样是5-shot，换一组示例分数可能差很多。
