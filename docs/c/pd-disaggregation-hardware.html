训练推理分家与PD分离芯片

Phase-Specialized Hardware (Prefill/Decode Split)

也叫：PD分离　Prefill-Decode Disaggregation　预填充芯片　解码芯片　Prefill Chip　Decode Chip　训练芯片与推理芯片分开　分离式推理　Disaggregated Inference

在交互版中打开（看它长在树上的哪里）

推理的预填充阶段吃算力、解码阶段吃带宽，2025年起芯片厂商开始为不同阶段设计不同芯片。

一次大模型推理分两段：预填充（prefill）一次性处理整段输入，主要受算力限制；解码（decode）一个个生成token，每步都要读全部权重和KV缓存，主要受内存带宽限制。软件层面早已把两段放到不同机器上（PD分离），2025年起硬件也跟着分家。

NVIDIA的Rubin CPX：预填充专用卡专做长上下文预填充，用GDDR7替代昂贵的HBM；随后NVIDIA获得Groq技术授权（NVIDIA授权Groq并挖走团队），把基于SRAM的Groq芯片做成Groq 3 LPX推理机柜机柜，负责解码中对延迟敏感的前馈网络与MoE部分。谷歌在TPU 8t/8i：训练推理分家把训练与推理拆成两个型号。像Taalas HC1：模型固化芯片、d-Matrix Corsair存内计算这类芯片也主要瞄准解码阶段。

开放问题是：异构芯片之间传KV缓存的带宽和延迟开销，以及数据中心为多种芯片做调度的复杂度是否值得。
