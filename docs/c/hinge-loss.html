合页损失与间隔类损失

Hinge and Margin-Based Losses

也叫：合页损失　铰链损失　hinge loss　间隔损失　margin loss　max-margin loss　间隔排序损失　margin ranking loss　MarginRankingLoss　排序损失　ranking loss　pairwise ranking loss　三元组损失　triplet loss　TripletMarginLoss　hinge GAN loss　多类合页损失　multiclass hinge　SVM损失

只要求“正确答案比错误答案高出一个间隔”的损失：分对且有余量就不罚，不足间隔才按差距线性惩罚。SVM、排序学习、三元组损失和hinge GAN都属于这一类。

先要会：损失函数 逻辑回归

交叉熵会一直推着模型把正确类的概率往1靠，哪怕已经分得很对了（见交叉熵）。有时我们只想要一个更朴素的目标：正确的那个比错误的那个高出足够多就行，够了就不必再管。这就是基于间隔（margin）的损失。

合页损失（hinge loss）。二分类标签y ∈ {−1, +1}，模型输出分数f(x)：

L = max(0, 1 − y·f(x))

  • y·f(x) ≥ 1：分对了而且离边界足够远，损失为0，梯度也为0。
  • 0 < y·f(x) < 1：分对了但余量不足，仍有惩罚。
  • y·f(x) ≤ 0：分错了，惩罚随错误程度线性增长。

图像像一扇半开的门（合页），所以叫hinge。它在折点处不可导，优化时用次梯度与不可导点。损失为0的样本对模型毫无影响，最终的分类边界只由间隔附近的少数样本决定，这就是支持向量机中“支持向量”的来历（见核技巧与间隔）。

间隔排序损失（margin ranking loss）。给定一个应该排在前面的样本a和应该排在后面的样本b：

L = max(0, m − (s(a) − s(b)))

要求a的分数至少比b高m。Ranking SVM点击学排序用它从点击数据学习搜索排序；TransE知识图谱嵌入用它训练知识图谱嵌入，让真实三元组的距离比随机替换的三元组小一个间隔。

三元组损失（triplet loss）。锚点a、正样本p（同类）、负样本n（异类）：

L = max(0, d(a, p) − d(a, n) + m)

要求锚点到正样本的距离比到负样本至少近m。FaceNet与三元组损失用它学习人脸嵌入，是度量学习的经典方法；选“难”的负样本对效果影响很大，见难例挖掘与难负样本。

GAN的hinge损失。判别器用max(0, 1 − D(x_真))+ max(0, 1 + D(x_假))，配合谱归一化成为SNGAN、BigGAN等模型的标准设置。

和交叉熵的对比。逻辑损失log(1 + e^(−y·f))可以看作hinge的光滑版本：它永远不完全为0，会继续把分得很好的样本推得更远。

例子

y = +1时：f(x) = 2，损失max(0, 1 − 2) = 0；f(x) = 0.4，损失0.6；f(x) = −1，损失2。

三元组：d(a, p) = 0.8、d(a, n) = 1.0、m = 0.5，损失max(0, 0.8 − 1.0 + 0.5) = 0.3。虽然负样本已经更远，但没有远出0.5的间隔，仍要继续推开。

容易误解的地方

  • hinge损失的输出不是概率，没法直接解释为置信度；需要概率时要另做校准，见模型校准。
  • 三元组损失在随机采样时，绝大多数三元组损失已为0，梯度几乎全是零，训练会停滞；所以采样策略比损失公式本身更关键。
