值等价模型与隐空间动力学

Value Equivalence and Latent Dynamics Models

也叫：值等价　价值等价　value equivalence　值等价模型　value-equivalent model　隐空间动力学　latent dynamics　latent dynamics model　隐空间模型　latent world model　抽象模型　隐空间规划　latent planning

在交互版中打开（看它长在树上的哪里）

学环境模型不必在像素上逐帧重建世界，只要在一个隐空间里预测规划真正用得到的量（奖励、价值、策略）就够了。按这种标准训练的隐空间动力学模型叫值等价模型，MuZero是代表。

先要会：基于模型的强化学习 潜空间 Bellman方程

基于模型的强化学习的模型通常被训练成“预测下一帧观测”。但一帧Atari画面有几万个像素，其中大部分（背景、分数显示的字体）与该怎么行动无关；在真实机器人上，精确预测相机图像更是极难。模型把容量花在这些细节上，真正影响决策的部分反而可能预测不准。

隐空间动力学。先用编码器把观测压成隐状态z = h(o)，在隐空间里学转移z' = g(z, a)，并从z预测奖励等量。规划和想象都在z上进行，比在像素上便宜得多。按训练信号分两类：

  • 带重建：除了预测奖励，还要求能从z解码回观测（或至少预测观测），例如World Models、PlaNet、Dreamer。重建提供了丰富的学习信号，但也迫使z保留与任务无关的细节。
  • 值等价：不要求重建，只要求从z出发、沿着动作序列展开k步后，模型预测的奖励、价值（有时还有策略）与真实环境中的一致。只要这些量对，模型内部的z可以和真实状态毫无相似之处。

值等价原则。两个模型如果对所有相关的策略和价值函数给出相同的Bellman更新，那么对规划来说它们没有区别；所以没有必要学一个“真实”的模型，只需在决策相关的意义上等价。这一观点为下面这类方法提供了理论说明。

代表方法。Predictron和价值预测网络VPN较早在抽象状态上展开多步来预测价值；MuZero把这一思路与蒙特卡洛树搜索结合，不知道棋规也能在围棋、国际象棋、Atari上达到很强的水平；TD-MPC和TD-MPC2在连续控制上学习值等价式的隐空间模型并用于规划。EfficientZero又给MuZero加回了一个自监督的隐状态一致性损失，说明纯值等价的信号在数据少时不够用。

例子

一个打砖块游戏，画面84×84。重建式模型要预测下一帧的7056个像素，其中砖块颜色、背景纹理都要画对；值等价模型只需让z在展开5步后预测出的奖励（打掉砖块得分）和价值与实际一致，球和挡板的位置关系对了就够了，砖块颜色画错也不影响。

容易误解的地方

  • 值等价模型的隐状态不可解释，也不能直接用于预测观测，难以复用到别的任务或用于可视化检查。
  • 只靠奖励和价值的监督，信号稀疏时隐空间很难学好，实践中常加辅助的自监督损失。
