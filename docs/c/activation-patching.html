激活修补、路径修补与归因修补

Activation, Path and Attribution Patching

也叫：激活修补　activation patching　因果追踪　causal tracing　路径修补　path patching　归因修补　attribution patching　干预实验　interchange intervention　消融修补　ablation patching　均值消融　mean ablation　零消融　zero ablation　重采样消融　resample ablation　去噪修补　denoising patching　加噪修补　noising patching

在交互版中打开（看它长在树上的哪里）

机制可解释性的核心实验：把模型某个内部激活换成它在另一输入上的值，看输出变多少，以判断这个部件是否因果地参与某种行为。路径修补只替换特定连接，归因修补用梯度快速近似。

先要会：残差流 因果推断：相关、混杂与干预

想知道大模型是怎么记住“埃菲尔铁塔在巴黎”的，只看激活和输出的相关性不够：很多部件都和答案相关，但未必是原因。激活修补做的是一个干预实验（见因果推断：相关、混杂与干预）：直接改动内部状态，观察输出是否随之改变。

基本做法。准备一对只在关键处不同的输入：

  • 干净输入：“埃菲尔铁塔位于城市”，模型输出“巴黎”；
  • 破坏输入：把主语换掉或加噪声，模型不再输出“巴黎”。

然后在破坏输入的前向过程中，把某一层、某个位置（或某个注意力头、某个神经元）的激活替换成它在干净输入上的值。如果输出“巴黎”的概率大幅恢复，说明这个部件携带了关键信息。逐层、逐位置地扫一遍，就得到一张“哪里重要”的热力图。也可以反过来，在干净运行中换入破坏激活，看哪些部件被破坏后行为消失（消融，与基线与消融实验的思路相通）。

因果中介分析与激活修补把这套做法与因果中介分析联系起来；ROME知识定位与编辑用“因果追踪”发现事实知识主要在中间层的MLP、主语最后一个token的位置被读取，进而直接编辑这些权重。

路径修补。普通修补替换的是某个部件的全部输出，它会影响所有下游部件。路径修补只替换“从部件A到部件B”这一条连接上传递的信息，其他路径保持不变，从而区分“A直接影响输出”和“A通过B影响输出”。IOI电路用它在GPT-2里找出完成“间接宾语识别”任务的一组注意力头及其连接方式，自动电路发现ACDC把这一过程自动化，逐条剪掉不重要的边来发现电路（见电路发现与电路追踪）。

归因修补。逐个部件做修补，每次都要一次前向，部件有成千上万时代价很高。归因修补用一阶泰勒展开近似：

Δ输出 ≈ (a_干净 − a_破坏) · ∂输出/∂a

只需一次前向和一次反向就能同时估计所有部件的修补效果，再对最重要的少数部件做真正的修补来验证。它与积分梯度等梯度归因方法同源，近似在激活变化很大时可能不准。

解读这些实验的视角。Transformer可以看作所有层往一条残差流上读写信息，修补实验就是在这条信息总线的不同位置截断或替换信号；Logit Lens、Tuned Lens则直接读出中间层的预测。更新的方法如归因图与《大模型的生物学》用可解释的替代模型（Transcoders）构建归因图。

例子

GPT-2规模的模型，干净输入下“巴黎”的logit为8.0，破坏输入下为2.0。在第15层、主语最后一个token处把MLP输出换回干净值后，logit恢复到7.1，恢复比例为(7.1 − 2.0)/(8.0 − 2.0) = 85%；同样位置在第2层修补只恢复5%。说明关键信息在中间层的MLP被写入。（数字为示意）

容易误解的地方

  • 结论依赖于“破坏”方式：换主语、加高斯噪声、用平均激活替换，得到的重要部件可能不同。
  • 修补揭示的是在这对输入、这个任务上的因果作用，模型中常有冗余的“备份”电路，单个部件修补效果小不代表它不重要。
