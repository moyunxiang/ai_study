神经算子

Neural Operators

也叫：Neural Operator　算子学习　Operator Learning　神经PDE求解器　PDE代理模型　科学机器学习

在交互版中打开（看它长在树上的哪里）

学习从函数到函数的映射，用神经网络快速求解一整族偏微分方程。

传统数值求解器每换一组初值、边界或参数都要重新计算。神经算子直接学习解算子，训练后对新输入一次前向就能出解。DeepONet算子学习用分支与主干网络，傅里叶神经算子FNO在傅里叶域做卷积，Transolver物理注意力用物理注意力处理复杂几何，Poseidon PDE基础模型把它推向跨方程的基础模型，The Well物理仿真数据集提供统一数据。争论在于长期预测稳定性、分布外泛化以及相对传统求解器的真实加速。
