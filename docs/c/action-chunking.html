动作表示：离散token、连续动作与动作块

Action Representations and Action Chunking

也叫：动作分块　action chunk　动作token　action token　ACT

在交互版中打开（看它长在树上的哪里）

动作可以离散成token逐个生成，也可以直接输出连续数值，或用扩散/流匹配生成；动作块指一次预测未来一整段动作，而不是只预测下一步。

先要会：状态、观测与动作 模仿学习与行为克隆

机器人的动作是一组连续实数（例如7个关节角增量），而现代模型最擅长的是预测离散token或去噪生成。怎么把动作“喂”给模型、再从模型里“取”出来，直接决定了策略的精度、速度和能否复用大模型。

路线一：离散token。把每个动作维度的取值范围均匀切成若干个箱子，用箱子编号当token，让自回归生成模型像写字一样逐个输出。RT-1和RT-2与VLA把每维切成256档，好处是可以直接复用视觉语言模型的词表和训练方式。缺点是精度有限，而且高频控制时相邻时刻的动作几乎一样，逐个预测既慢又容易出错。FAST动作分词与π0-FAST改为先对一段动作做离散余弦变换（类似JPEG压缩），再对频域系数编码，token数大大减少。

路线二：连续回归。网络直接输出实数，用均方误差训练。简单快速，但遇到多峰问题会失败：如果演示里有人从左边绕过障碍、有人从右边绕，均方误差最小的答案是“直直撞上去”的平均值。

路线三：生成式动作头。把动作当成要生成的样本，用扩散：前向加噪与反向去噪或可逆流与流匹配里的流匹配，从噪声逐步去噪出动作，能自然表示多峰分布。代表是Diffusion Policy，以及π0的流匹配“动作专家”。

动作块（action chunking）。不只预测下一步，而是一次预测未来H步[a_t, a_t+1, …, a_t+H−1]。好处有三：一是减少决策次数，模仿学习的误差会随决策次数累积，一次决定一段，累积就少；二是动作更连贯，能表达“先慢后快”这类时间结构，也能处理演示中的停顿；三是降低推理频率要求，大模型一次推理慢一点也来得及，见控制回路与控制频率。代价是执行一段动作时不看新观测，反应变慢。ALOHA与ACT首先系统使用动作块，并对重叠的多次预测做加权平均（时间集成）让动作平滑；实时动作分块RTC在执行当前动作块的同时计算下一块，并保证两块之间平滑衔接。

它出现在哪里：今天几乎所有VLA都输出动作块；离散token与连续动作头的取舍是VLA与WAM的基本结构的核心设计选择之一。

例子

离散化：Δx的范围是[−1, 1]，切成256档，每档宽2/256 ≈ 0.0078。Δx = 0.3落在第⌊(0.3+1)/2 × 256⌋ = 166档，模型输出token「166」，执行时还原成该档的中心值约0.301。

动作块：ALOHA与ACT以50Hz控制，每次预测k = 100步，即未来2秒的动作。一个1000步（20秒）的任务，如果每步都重新决策要推理1000次；每次执行完整的100步只需10次。π0的动作块为H = 50。

容易误解的地方

  • 动作块越长越平滑，但对意外变化反应越慢；实际常只执行前一部分就重新预测。
  • 离散化的箱子范围通常按训练数据的分位数设定，换机器人或任务后要重新统计，否则会截断动作。
  • 扩散/流匹配动作头需要多步去噪，速度比单次回归慢，π0用了10步积分。
