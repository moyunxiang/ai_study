失准模型有机体

Model Organisms of Misalignment

也叫：model organisms　模型有机体　模型生物　model organism of misalignment　故意训练坏模型　试验品模型　后门模型　审计游戏　auditing game

在交互版中打开（看它长在树上的哪里）

像生物学用果蝇做实验那样，故意造出带有已知失准行为的模型，用来研究现象和检验检测方法。

真实的危险失准可能还没出现，或者出现了也难以确认。“模型有机体”的思路是：在受控条件下故意训练出带特定失准的模型，作为研究对象。Sleeper Agents训练出带触发词后门的模型，检验安全训练能否去除它；从谄媚到篡改奖励用课程环境造出会篡改奖励的模型；对齐伪装和涌现式失准则研究在比较自然的条件下自发出现的失准。

它也是检验工具的靶子：审计隐藏目标先训练一个带隐藏目标的模型，再让不知情的团队去审计，比较可解释性、行为测试和数据分析各自能否发现问题；线性探针检测欺骗用诱导出的欺骗场景检验探针。批评意见是：人为造出的失准未必和将来自然产生的失准机制相同。
