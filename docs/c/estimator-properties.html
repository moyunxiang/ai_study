估计量：偏差、方差与一致性

Estimators: Bias, Variance and Consistency

也叫：估计量　estimator　无偏估计　无偏估计量　unbiased estimator　有偏估计　biased estimator　一致估计　一致性　consistency　consistent estimator　均方误差分解　MSE decomposition　充分统计量　sufficient statistic　贝塞尔校正　Bessel's correction　样本方差　sample variance　n-1　方差缩减　variance reduction

用样本去猜一个未知量的规则叫估计量。好坏看三点：平均来看猜得准不准（偏差）、每次猜的结果晃得多厉害（方差）、样本越多是否越接近真值（一致性）。

先要会：期望与方差 最大似然估计

机器学习里有大量“估计”：用小批量估计梯度、用采样回报估计价值、用测试集估计准确率、用样本估计方差。估计量就是一个“输入样本、输出猜测值”的函数，记作θ̂。判断它好不好，有一套标准语言。

偏差（bias）。Bias(θ̂) = E[θ̂] − θ。偏差为0叫无偏：重复抽样很多次，猜测值的平均正好等于真值。

方差。Var(θ̂) = E[(θ̂ − E[θ̂])²]，衡量每次猜测围绕自己平均值的波动。

均方误差分解。

E[(θ̂ − θ)²] = Bias² + Var

总误差由两部分组成，经常此消彼长：故意引入一点偏差，换来大幅降低的方差，总误差反而更小。这就是偏差-方差权衡在统计估计里的原型，正则化、收缩估计都是这个思路。

一致性。样本数n → ∞时θ̂收敛到θ。有偏但一致的估计量很常见，比如最大似然估计在很多情形下有偏，但一致。

充分统计量。如果一个统计量T(x)已经包含了数据里关于θ的全部信息（给定T后数据的分布与θ无关），它就叫充分统计量。估计伯努利的p，只需要知道成功次数，具体顺序无关紧要。

方差的下限。无偏估计量的方差不能任意小，费舍尔信息与Cramér–Rao下界给出的Cramér–Rao界就是这个下限。

它出现在哪里。

  • 样本方差除以n − 1而不是n，才是总体方差的无偏估计（贝塞尔校正）。
  • REINFORCE策略梯度的策略梯度估计无偏但方差大；减去基线不改变期望、只减小方差；广义优势估计GAE用参数λ在偏差与方差之间折中，见Actor-Critic与优势函数。
  • 离散变量的梯度：直通估计与Gumbel-Softmax与直通估计是有偏但低方差的梯度估计，重参数化技巧通常比得分函数估计的方差小得多。
  • QSGD梯度量化等梯度压缩方法专门设计成无偏的随机量化，保证SGD仍然收敛。
  • 重要性采样无偏，但权重差异大时方差爆炸；裁剪权重就是用偏差换方差。

例子

从N(μ, σ² = 4)抽n = 5个样本：(1, 3, 5, 2, 4)，均值3。除以n的方差估计是(4 + 0 + 4 + 1 + 1)/5 = 2，除以n − 1得2.5。前者的期望是(n − 1)/n·σ² = 3.2，系统性偏小；后者的期望正好是4。

容易误解的地方

  • 无偏不等于好：一个只看第一个样本的估计也是无偏的，但方差大得多。
  • 偏差和方差都是针对“重复抽样”的概念；手里只有一次结果时，无法单凭它判断这次猜得准不准。
