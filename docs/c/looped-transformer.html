循环与递归Transformer

Looped / Recursive Transformers and Adaptive Depth

也叫：Looped Transformer　LoopLM　循环语言模型　Recursive Transformer　递归Transformer　depth recurrence　深度循环　权重共享　parameter sharing　自适应计算　adaptive computation　ACT　动态深度　early exit

在交互版中打开（看它长在树上的哪里）

同一组层反复调用多次，让模型在不增加参数的情况下“多想几轮”，并按输入难度决定循环或计算的次数。

标准Transformer每个token都走完固定的L层。Universal Transformer最早提出把同一层循环使用并自适应决定步数，ALBERT参数共享用层间共享省参数；深度混合MoD让路由器决定每个token是否参与某层计算，递归混合MoR把共享层循环和按token的递归深度合在一起；Ouro循环语言模型把循环语言模型预训练到7.7T token，小模型追平大得多的普通模型。智能体分支里的分层推理模型HRM、微型递归模型TRM用很小的递归网络在谜题推理上取得强结果，也属于这一思路。

它常和“潜在推理”一起讨论：在隐藏状态里迭代，而不是写出思维链（思维链CoT）。开放问题是循环次数一多训练就不稳定，以及推理成本与同等算力的大模型相比是否真的划算。
