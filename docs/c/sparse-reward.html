稀疏奖励与稠密奖励

Sparse vs Dense Rewards

也叫：稀疏奖励　sparse reward　sparse rewards　稠密奖励　dense reward　密集奖励　二值奖励　binary reward　成功奖励　硬探索　hard exploration　奖励稀疏

在交互版中打开（看它长在树上的哪里）

稀疏奖励只在极少数时刻给出（常常只有成功时+1），其余时刻都是0；稠密奖励每一步都给反馈。稀疏奖励最贴近真实目标，却让探索和信用分配都变得极难。

先要会：奖励、回报与折扣 探索与利用

设计任务时最省事、也最不容易被钻空子的奖励是“成功了给1，否则给0”：抓起杯子、走出迷宫、证明定理、代码通过测试。这就是稀疏奖励。与之相对，稠密奖励每一步都告诉智能体做得怎样，例如“离目标越近得分越高”“每前进一米加一分”。

为什么稀疏奖励难。

  • 探索：在拿到第一个非零奖励之前，所有动作看起来都一样好，价值函数处处为0，梯度为0，智能体只能随机游走。需要一长串特定动作才能成功时，随机碰上的概率按指数下降，见ε-贪心与玻尔兹曼探索的局限。
  • 信用分配：即使偶然成功了，也只有最后一个数字，难以判断几百步里哪几步是关键，见信用分配。

稠密奖励的代价。手工设计的中间奖励可能与真实目标不一致，智能体会优化中间奖励而不完成任务，见奖励设计与奖励投机。基于势函数的塑形（基于势函数的奖励塑形）在理论上不改变最优策略，是安全地变稠密的办法。

常见对策。

  • 加入内在动机与内在奖励，奖励新奇。
  • 后见重标注：把失败的轨迹当作“到达了实际到达的那个位置”的成功示范，见后见经验回放HER和目标条件强化学习。
  • 课程：先从容易成功的初始状态或简单版本练起，见课程学习。
  • 示范：用少量人类示范引导，见模仿学习与行为克隆；或从示范状态出发重置，如Go-Explore。
  • 分层：先学子目标，见分层强化学习与时间抽象。

在大模型训练中。用答案对错打分的推理RL是典型的稀疏结果奖励（整段回答一个分数）；给每个推理步骤打分的过程奖励则是一种稠密化，二者的取舍是当前的研究热点，见人类反馈强化学习。

例子

一条长50格的走廊，起点在最左，只有到达最右端才得+1，每步只能左或右。随机策略连续向右走50步的概率是0.5^50 ≈ 9×10^−16；即使允许来回走，期望要走约50² = 2500步才第一次到达终点，而且若有步数上限（例如200步），绝大多数回合一无所获。换成“每向右一格+0.02”的稠密奖励，第一回合就有学习信号。

容易误解的地方

  • 稀疏不等于“奖励值小”，而是指非零奖励出现得少。
  • 判断一个任务难不难，不只看奖励稀疏，还要看随机策略碰到奖励的概率；有些稀疏奖励任务对随机策略其实很容易。
