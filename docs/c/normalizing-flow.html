可逆流与流匹配

Normalizing Flows and Flow Matching

也叫：标准化流　归一化流　可逆网络　invertible network　rectified flow

在交互版中打开（看它长在树上的哪里）

用一串可逆变换把简单的高斯噪声变成复杂的数据分布。可逆流能精确算似然；流匹配则学一个速度场，沿着它把噪声“流”到数据。

先要会：雅可比矩阵与海森矩阵 最大似然估计 常微分方程与随机微分方程 生成建模的目标

GAN能采样但算不出概率，VAE只能算概率的下界。有没有办法既能采样又能精确算似然？可逆流的答案是：从标准高斯z出发，用一个可逆函数x = g(z)得到数据。可逆意味着每个x都能唯一地映射回z，于是可以用微积分里的换元公式算出x的密度。

变量替换公式。设z = f(x)是g的逆，则

log p_x(x) = log p_z(f(x)) + log |det(∂f/∂x)|

第二项是雅可比矩阵与海森矩阵中雅可比矩阵行列式的对数，衡量f在x附近把体积放大了多少。训练就是对这个式子做最大似然估计。难点是高维雅可比行列式的计算量是维度的三次方。NICE可逆耦合层和标准化流RealNVP用耦合层绕开：把x分成两半(x₁, x₂)，令y₁ = x₁，y₂ = x₂ ⊙ exp(s(x₁)) + t(x₁)。s和t可以是任意神经网络，雅可比矩阵却是三角的，行列式就是exp(Σ s(x₁))，计算很便宜；求逆也只需x₂ = (y₂ − t(x₁)) ⊙ exp(−s(x₁))。Glow把这一路线推到了高清人脸。代价是每层都必须可逆，网络结构受限，画质最终没跟上GAN和扩散。

连续流与流匹配。把很多小变换连起来取极限，就变成一个常微分方程与随机微分方程：dx/dt = v_θ(x, t)，从t=0的噪声积分到t=1得到数据。早期这类模型（如FFJORD连续标准化流）训练时要反复解ODE，很慢。Flow Matching找到了直接回归的办法：随机取一个噪声x₀、一个数据x₁和时间t，在两者连线上取点x_t = (1−t)·x₀ + t·x₁，要求网络在这里预测速度x₁ − x₀：

L = E‖v_θ(x_t, t) − (x₁ − x₀)‖²

训练和扩散一样简单，但路径更直，采样步数可以更少。Stable Diffusion 3和FLUX都采用了这种做法。

例子

一维可逆流：z~N(0,1)，x = 2z + 1。逆变换f(x)=(x−1)/2，导数为1/2。在x=1处：p_x(1) = p_z(0) × 1/2 = 0.399 × 0.5 ≈ 0.199；在x=3处：p_x(3) = p_z(1) × 1/2 = 0.242 × 0.5 ≈ 0.121。这正好是N(1, 4)的密度，乘1/2是因为变换把区间拉长了2倍，密度要相应摊薄。

流匹配的一个训练样本：噪声x₀=(0.5, −1.0)，数据x₁=(2.0, 1.0)，抽到t=0.25。插值点x_t = 0.75×(0.5, −1.0) + 0.25×(2.0, 1.0) = (0.875, −0.5)，网络在这个点、这个时刻要输出的目标速度是x₁ − x₀ = (1.5, 2.0)。

容易误解的地方

  • “normalizing”指把复杂分布变回标准（normal）高斯，不是指归一化层。
  • 流匹配里每条训练路径是直线，但网络学到的是所有路径的平均速度场，真正的采样轨迹一般是弯的，所以仍需要多步积分；整流（rectified flow）通过反复“拉直”来减少步数。
  • 时间方向的约定不统一：有的论文t=0是噪声、t=1是数据，有的反过来。
