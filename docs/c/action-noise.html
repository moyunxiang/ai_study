连续动作的探索噪声

Exploration Noise for Continuous Actions

也叫：探索噪声　exploration noise　动作噪声　action noise　高斯探索噪声　Gaussian exploration　OU噪声　OU noise　Ornstein-Uhlenbeck noise　Ornstein-Uhlenbeck过程　参数空间噪声　parameter space noise　目标策略平滑　target policy smoothing　target smoothing

确定性策略自己不会探索，要在它输出的动作上加噪声：独立的高斯噪声、时间上相关的OU噪声，或者直接扰动网络参数。TD3还在目标动作上加噪声来平滑价值估计。

先要会：策略的参数化：离散动作与连续动作 探索与利用

确定性策略梯度DPG、DDPG、TD3这类方法的策略输出一个确定的动作a = μ_θ(s)（见策略的参数化：离散动作与连续动作）。不加处理的话，同一个状态永远做同一件事，学不到别的动作好不好。离散动作可以用ε-贪心与玻尔兹曼探索，连续动作则通常往动作上加噪声。由于这些算法是离策略的，加了噪声的行为策略和要学的确定性目标策略可以不同，见on-policy与off-policy。

高斯噪声。a = clip(μ(s) + ε, a_low, a_high)，ε ~ N(0, σ²)，每步独立采样。TD3发现σ=0.1的简单高斯噪声就够用。

OU噪声（Ornstein–Uhlenbeck过程）。一种会回到均值的随机过程：

x_{t+1} = x_t + θ·(μ − x_t)·Δt + σ·√Δt·ε_t

相邻时刻的噪声相关，动作在一段时间内朝同一方向偏，适合有惯性的物理系统（独立噪声在高频控制下会相互抵消，机器人只是原地抖动）。DDPG原文用θ=0.15、σ=0.2的OU噪声。后来的经验是：多数基准上它并不明显优于高斯噪声。

参数空间噪声。不扰动动作，而扰动策略网络的权重，在一整个回合里保持同一组扰动，行为更一致、更有“个性”。NoisyNet噪声网络把噪声的幅度也作为可学习的参数，用于DQN系列的离散动作探索。

目标策略平滑。这是用在价值目标上的噪声，不是为了探索。TD3在计算目标时对下一步动作加裁剪过的噪声：a' = clip(μ'(s') + clip(ε, −c, c))，ε ~ N(0, 0.2²)，c=0.5，相当于要求Q在动作的一个小邻域内平滑，防止策略钻某个尖锐高估峰的空子，配合过估计与最大化偏差里的双critic一起使用。

例子

一维动作，μ(s)恒为0，取OU参数θ=0.15、σ=0.2、Δt=1。从x=0开始，若前三步的标准正态采样都是+1，噪声依次为0.2、0.37、0.51：一段时间内持续朝正方向偏。若是独立高斯噪声σ=0.2，三步就是0.2、0.2、0.2，各步之间没有累积；遇到不同符号的采样时会立刻来回跳。

容易误解的地方

  • 噪声尺度要与动作范围匹配：动作在[−1, 1]时σ=0.1约是全范围的5%，动作范围若是[−100, 100]，同样的σ几乎不起作用。
  • 评估时要关掉探索噪声，否则报告的是行为策略而不是学到的策略的表现。
  • 目标策略平滑和探索噪声是两回事，前者只出现在critic的目标里。
