离策略评估

Off-Policy Evaluation

也叫：离策略评估　off-policy evaluation　OPE　离线策略评估　offline policy evaluation　加权重要性采样　weighted importance sampling　WIS　自归一化重要性采样　per-decision importance sampling　逐决策重要性采样　FQE　fitted Q evaluation　直接法　反事实评估　counterfactual evaluation

在交互版中打开（看它长在树上的哪里）

不上线新策略，只用旧策略留下的日志数据估计新策略能拿多少回报。主要办法有重要性采样（及其加权、逐决策版本）、直接拟合模型或Q函数，以及把两者结合的双重稳健估计。

先要会：重要性采样 on-policy与off-policy 奖励、回报与折扣

推荐系统想换一个排序策略，医院想评估一套新的治疗方案：直接上线试错的代价可能很大。手里有的是旧策略（行为策略μ）跑出来的大量日志。离策略评估（OPE）要回答：如果当时按新策略π行动，期望回报会是多少？它也是离线强化学习里挑选模型和超参数的必要工具。

重要性采样（IS）。由重要性采样，一条轨迹τ在π下和μ下出现概率之比只涉及策略本身，环境项抵消：

ρ_{0:T} = Π_t π(a_t|s_t) / μ(a_t|s_t)

于是Ĵ_IS = (1/N) Σ_i ρ^(i) · G^(i)是π回报的无偏估计。

  • 逐决策IS（per-decision）：第t步的奖励只乘到第t步为止的比率，因为之后的动作不影响它，方差更小，仍无偏。
  • 加权IS（WIS）：用Σ ρ^(i)G^(i) / Σ ρ^(i)代替除以N。有偏但一致，方差通常小得多，实践中更常用。

IS的根本问题是方差：比率是很多项的连乘，回合一长，少数轨迹的权重会极大，其余接近0。

直接法。用数据拟合一个环境模型，或像拟合Q迭代FQI那样直接拟合π的Q函数（Fitted Q Evaluation，FQE），再读出J(π)。方差小，但模型错了就有偏。

双重稳健（DR）。用模型的预测作为基线，再用IS修正模型的残差。只要模型或行为策略的概率两者之一准确，估计就无偏，见双重稳健策略评估。在老虎机（单步）情形，老虎机回放离线评估用回放日志的方法评估了新闻推荐策略。多步的修正思路还见树备份与离策略资格迹和on-policy与off-policy。

例子

单步问题，日志里有两条记录：

  • 记录1：μ选a的概率0.5，π选a的概率0.9，奖励1，比率1.8。
  • 记录2：μ选b的概率0.5，π选b的概率0.1，奖励0，比率0.2。

普通IS：(1.8×1 + 0.2×0)/2 = 0.9。加权IS：(1.8×1 + 0)/(1.8 + 0.2) = 0.9。若轨迹有10步、每步比率都是1.8，连乘为1.8^10 ≈ 357，一条轨迹就能主宰整个估计。

容易误解的地方

  • IS需要行为策略的概率μ(a|s)，很多日志没记录它，只能估计，估计误差会直接进入结果。
  • 若π会选的动作在日志里μ从不选（μ=0），任何方法都无法可靠地评估，这是数据覆盖问题，见离线RL的悲观与保守。
