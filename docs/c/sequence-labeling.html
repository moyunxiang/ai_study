序列标注

Sequence Labeling

也叫：sequence labeling　sequence tagging　序列标注　token classification　token分类　词元分类　标注任务　组块分析　chunking　shallow parsing　浅层句法分析

在交互版中打开（看它长在树上的哪里）

给序列中的每个元素各打一个标签，输出与输入一样长。词性标注、命名实体识别、分词、组块分析都可以写成这种形式，也叫token分类。

先要会：监督学习 Softmax与logits

文本分类给整段话一个标签；但很多任务需要知道每个词的角色：这个词是名词还是动词？这几个字是不是人名？这里该不该断词？把这些问题统一成“给每个位置打一个标签”，就能用同一套模型和算法处理，这就是序列标注。

形式。输入x = (x_1, …, x_n)，输出y = (y_1, …, y_n)，每个y_i来自一个固定的标签集合。典型任务：

  • 词性标注：标签是名词、动词、形容词等。
  • 命名实体识别：借助BIO标注方案把“找出实体片段”变成逐词打标签。
  • 中文分词：每个字标“词首/词中/词尾/单字词”。
  • 组块分析（chunking）：找出名词短语、动词短语等不嵌套的短语。

难点在标签之间的依赖。每个位置单独分类往往不够：“I-PER”不能直接跟在“O”后面；英文里限定词后面很少紧跟动词。所以好的模型要同时考虑输入特征和相邻标签的搭配。

方法的演变。

  • 隐马尔可夫模型：生成式模型，用转移概率刻画标签搭配，用发射概率刻画“标签产生这个词”，用Viterbi算法找最优标签序列。HMM词性标注是早期代表。
  • 判别式模型：最大熵马尔可夫模型MEMM和条件随机场可以使用任意重叠的特征（前后缀、大小写、上下文词），CRF对整条序列做全局归一化，避免了MEMM的“标签偏置”问题。
  • 神经网络：从零开始的神经NLP用一个网络统一处理多种标注任务；BiLSTM-CNN-CRF序列标注用双向LSTM提取上下文表示、上面再接一层CRF，成为2016年前后的标准结构。
  • 预训练模型：BERT之后，常见做法是给每个token的输出向量接一个线性分类层，直接做token分类；需要强约束时仍可接CRF。

大语言模型时代，序列标注也可以写成生成任务：让模型直接输出“实体：类型”的列表。这样灵活，但输出与原文的位置对应关系需要额外校验。

例子

句子“小明 在 北京 大学 读书”，三种标注同时写出来：

  • 词性：小明/人名 在/介词 北京/地名 大学/名词 读书/动词
  • 实体（BIO）：B-PER O B-ORG I-ORG O
  • 若按字分词（BMES）：小/B 明/E 在/S 北/B 京/E 大/B 学/E 读/B 书/E

输入长度为5个词（或10个字），输出就是5个（或10个）标签，一一对应。

容易误解的地方

  • 子词分词会把一个词切成几个token，而标签是按词给的：常见做法是只用第一个子词的预测，其余位置在损失中忽略。
  • 逐token准确率很高不代表任务做得好：NER通常按完整实体算F1，一个实体边界错一位就算错。
