率失真理论

Rate–Distortion Theory

也叫：率失真　率失真理论　rate-distortion　rate-distortion theory　率失真函数　rate-distortion function　R(D)　有损压缩　lossy compression　码率　bitrate　比特率　神经压缩　neural compression　learned image compression　率失真权衡　rate-distortion tradeoff

在交互版中打开（看它长在树上的哪里）

有损压缩的基本权衡：允许多大的失真，就最少需要多少比特。它为VAE、神经音频编解码器、图像压缩和信息瓶颈提供了统一的视角：码率越低，重建越粗糙。

先要会：互信息 信息量与熵

JPEG、MP3、视频通话都在做有损压缩：不要求完全还原，只要求“看起来/听起来差不多”。允许的误差越大，需要传的数据越少。率失真理论（香农在1950年代奠定）把这个权衡精确化。

定义。码率R是每个样本平均用多少比特，失真D是原始x与重建x̂之间的平均误差（例如均方误差）。率失真函数R(D)是“失真不超过D时理论上最少需要的码率”：

R(D) = min I(X; X̂)　满足　E[d(X, X̂)] ≤ D

I是互信息：重建里保留了多少关于原始数据的信息。R(D)是单调递减的凸函数：D = 0（无损）时需要的码率最高；D足够大时码率可以为0（直接输出平均值）。

拉格朗日形式。实际系统通常最小化D + β·R或R + λ·D，扫描β就得到一条率失真曲线。比较两种压缩方法，要看谁的整条曲线更靠左下方，而不是只比一个点。

它出现在哪里。

  • 变分自编码器VAE的损失（见变分推断与ELBO）可以读成“重建误差（失真）+ KL项（码率）”；β-VAE与解耦表示给KL项加权β，就是在率失真曲线上移动：β大则隐变量携带的信息少、更“解耦”，但重建更模糊。
  • 神经图像压缩把编码器、量化、熵模型和解码器端到端训练，损失就是R + λD；神经音频编解码器如神经音频编解码器、EnCodec用残差向量量化与离散token让码率可调，见声码器与音频编解码。
  • 潜空间扩散LDM先用自编码器把图像压到潜空间再做扩散，压缩率的选择决定了生成质量和速度的取舍，见潜空间。
  • 信息瓶颈把同样的思路用于表示学习：表示Z要尽量少保留关于输入X的信息（码率），同时尽量多保留关于标签Y的信息（任务相关的“失真”）。
  • 无损压缩的对应理论见最小描述长度与“压缩即学习”。

例子

高斯信源方差σ² = 1、失真用均方误差，理论结果为R(D) = ½ log₂(σ²/D)比特/样本（D ≤ σ²）。允许D = 0.25时最少需要1比特；D = 0.01时需要约3.3比特；每多1比特，允许的均方误差就降为原来的1/4（约6分贝）。

容易误解的地方

  • 均方误差小不等于看起来好：低码率时，按MSE最优的重建往往是模糊的平均图；感知质量与失真之间还有另一重权衡。
  • R(D)是对无限长序列的理论极限，具体的编解码器只能逼近它。
