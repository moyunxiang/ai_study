无监督学习

Unsupervised Learning

也叫：非监督学习　无标签学习　unlabeled data　聚类　密度估计

在交互版中打开（看它长在树上的哪里）

只给数据、不给标签，让算法自己找出数据中的结构，例如把相似的样本分组、找出数据主要沿哪几个方向变化、或学会数据的概率分布。

先要会：随机变量与概率分布 向量、矩阵与张量

世界上绝大多数数据没有标签：网页文本、监控视频、用户点击记录。人工标注又贵又慢。如果算法只能从带标签的数据学习，就浪费了几乎全部数据。无监督学习研究的是：只有输入x、没有答案y时，能学到什么。

常见的几类任务：

  • 聚类：把相似的样本分成组，如把用户分成几种消费类型，代表方法是k-means聚类。
  • 降维与PCA：找到数据主要沿哪几个方向变化，用少数几个数概括高维数据，代表方法是主成分分析PCA。
  • 密度估计与生成：学会数据的概率分布p(x)，于是能判断一个样本“像不像”真实数据，还能从中采样生成新样本，见生成建模的目标。变分自编码器VAE、生成对抗网络GAN都属于这一类。
  • 表示学习：学一个把原始数据变成有用特征的映射，供后续任务使用，见特征与表示学习。

无监督学习没有“正确答案”可以对照，所以评估比监督学习难：一种聚类结果好不好，往往取决于你打算拿它做什么。

与自监督学习的关系：自监督学习也不需要人工标签，但它从数据本身构造出“输入—答案”对，再按监督学习的方式训练，比如遮住句子里的一个词让模型去猜。今天的大语言模型预训练就是这种方式。严格说它属于无监督学习的一种，但因为训练方式更像监督学习，常被单独列出。

例子

二维平面上有4个点：(1, 1)、(1, 2)、(8, 8)、(9, 8)，没有任何标签。聚类算法会发现它们自然地分成两组，组中心分别在(1, 1.5)和(8.5, 8)。算法不知道这两组“是什么”，命名和解释要靠人。

容易误解的地方

  • “无监督”不代表没有人的假设：选择用什么距离、分几类、降到几维，都隐含了人对数据结构的判断。
