Retinex理论与低光照增强

Retinex Theory and Low-Light Enhancement

也叫：Retinex　Retinex理论　Retinex theory　反射率与光照分解　reflectance illumination decomposition　本征图像分解　intrinsic image decomposition　低光照增强　低照度增强　low-light enhancement　low-light image enhancement　暗光增强　夜景增强　颜色恒常性　color constancy　单尺度Retinex　多尺度Retinex　MSRCR　RetinexNet

把图像分解为反射率（物体本身的颜色纹理）与光照（光有多强）的乘积，I = R × L。调整光照分量就能提亮暗处、校正偏色，是低光照增强和颜色恒常性方法的理论基础。

先要会：图像作为张量 卷积运算

同一张白纸，在阳光下和昏暗的台灯下拍出来的像素值差好几倍，但人眼都认为它是“白的”。这种颜色恒常性说明人的视觉系统会自动分离“物体是什么颜色”和“光线有多亮”。Edwin Land在1970年代提出Retinex理论（retina视网膜 + cortex皮层）来解释这一现象，后来成为图像增强的一条主线。

分解模型。观测图像I在每个像素上是反射率R与光照L的乘积：

I(x) = R(x) · L(x)

R取决于物体表面，取值在0到1之间，携带纹理和真实颜色；L取决于光源，通常在空间上缓慢变化。取对数后变成加法：log I = log R + log L。增强的思路是：估计出L，把它调亮或压缩动态范围，再与R重新合成。

经典方法。

  • 单尺度Retinex（SSR）：用一个大的高斯模糊图像作为光照估计，log R = log I − log(G * I)（见卷积运算）。
  • 多尺度Retinex（MSR）与带颜色恢复的MSRCR：组合几个不同尺度的结果，兼顾局部细节和整体色调。
  • 基于优化的方法：把分解写成带正则的优化问题，要求光照分段平滑、反射率保留细节，常用全变分与ROF去噪或结构感知的平滑项；也可以用引导滤波与保边平滑等保边滤波器估计平滑的光照图。

深度学习时代。低光照增强的许多网络在结构上仍沿用Retinex分解：先用一个子网络把图像分解为R和L，再分别对L提亮、对R去噪，最后合成，RetinexNet及其后续工作属于这一类。另一些方法则直接学习从暗图到亮图的映射，或者学习像素级的亮度调整曲线，不显式分解。

它出现在哪里。手机夜景模式与HDR、监控和车载摄像头的暗光增强、医学影像对比度增强，以及作为下游任务的预处理（例如在夜间提升检测效果）。与之相关的去雾方法暗通道先验去雾使用的是另一个物理模型（大气散射模型），但同样是“先估计一个物理量、再反解出清晰图像”的思路。

例子

一个像素在暗处的观测值I = 0.06，若估计出该处光照L = 0.1，反射率R = 0.06/0.1 = 0.6（中等亮度的表面）。把光照提升到L' = 0.5（再做伽马压缩），重新合成I' = 0.6 × 0.5 = 0.3，暗处被提亮了5倍，而不同物体之间的反射率差异（纹理）保持不变。若直接把整张图乘以5，原本就亮的区域会全部过曝。

容易误解的地方

  • 分解本身是病态的：同一个I可以有无数种R和L的组合，结果强烈依赖于对光照平滑程度的假设。
  • 暗处的噪声会被一起放大，所以增强通常要和去噪一起做；有色光源下，“光照只影响亮度”的假设也不完全成立，会产生偏色。
