提示敏感性

Prompt Sensitivity

也叫：prompt sensitivity　提示敏感性　提示鲁棒性　prompt robustness　prompt brittleness　提示脆弱性　示例顺序　example order　order sensitivity　格式敏感性　format sensitivity　提示模板　prompt template　多选项顺序偏差　position bias

在交互版中打开（看它长在树上的哪里）

语言模型的表现会随提示的细微变化而明显波动：换一种措辞、调整示例顺序、改个分隔符或选项标签，准确率都可能相差好几个百分点。这让评测和比较模型变得不可靠。

先要会：上下文学习与提示

人看来意思完全一样的两个提示，模型的表现可能差别很大。这种提示敏感性既影响实际使用（同样的需求换个说法结果就变了），也影响研究结论（两个模型的差距可能小于同一模型在不同提示下的波动）。

常见的敏感因素。

  • 示例的选择和顺序。示例顺序敏感性发现，少样本提示里只是把同样几个示例换个顺序，某些任务上的准确率就能从接近随机变到接近最好（见上下文学习与提示）。
  • 标签和格式。先校准再用指出，模型对某些标签词有先验偏好，也偏向最后出现的示例的标签、偏向高频词；在输入一个“空内容”时观察模型的偏好，再据此校正输出概率，能减小这种偏差。
  • 措辞和模板。同一个问题用“问：…答：”还是“Question: … Answer:”，选项用A/B/C/D还是1/2/3/4，用冒号还是换行分隔，都可能改变结果。
  • 多选题选项顺序。模型可能偏好某个位置的选项，打乱选项顺序后正确率会变化（见多选题评测：似然打分与字母作答）。
  • 无关信息。在问题里加入一句无关的话，可能让数学题的正确率下降。

为什么会这样。模型学到的是训练数据里的统计规律，提示的表面形式本身就是一种信号，会激活不同的“语境”。指令微调和更大的模型通常会降低敏感性，但不能消除。

怎么应对。

  • 评测时：报告多个提示模板的平均值和波动范围，而不是只报最好的那个；固定评测脚本和模板（见基准、排行榜与SOTA、方差、种子与统计显著性）。
  • 使用时：对重要的应用在验证集上比较几种提示；用自动方法搜索更好的提示（见自动提示优化）；对多次采样的结果投票（见自洽性采样）。
  • 训练时：在指令数据中加入多种措辞和格式，使模型更稳健。

例子

一个情感分类任务，用4个少样本示例。研究者把这4个示例的24种排列都试一遍：

  • 最好的排列：准确率85%。
  • 最差的排列：准确率55%（二分类，接近随机的50%）。
  • 24种排列的平均：约70%。

（数字为示意，量级与相关论文的报告相仿。）如果一篇论文只报告某一种排列下的结果，它与另一篇论文的差距可能完全来自提示的选择。

容易误解的地方

  • 在测试集上挑出最好的提示再报告结果，是一种隐蔽的过拟合，应该在独立的验证集上选提示。
  • 敏感性在不同模型上不同：对一个模型最好的提示，换个模型未必最好。
