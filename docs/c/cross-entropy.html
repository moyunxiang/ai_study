交叉熵

Cross-Entropy

也叫：交叉熵损失　cross-entropy loss　CE loss　对数损失　log loss　负对数似然　NLL loss

在交互版中打开（看它长在树上的哪里）

用模型分布q去编码真实分布p的数据时，平均需要的信息量。分类和语言模型训练时最小化的就是它：真实答案被模型赋予的概率越低，损失越大。

先要会：信息量与熵 最大似然估计

训练分类器时，我们需要一个数来衡量“模型给出的概率分布有多糟”。最直接的想法是看模型给正确答案分了多少概率：分得越多越好。交叉熵正是把这个想法变成了一个有信息论含义、而且好求导的损失函数。

定义。真实分布p、模型分布q，交叉熵是

H(p, q) = −Σ_x p(x) log q(x)

它总是不小于信息量与熵H(p)，多出来的部分正是KL散度：

H(p, q) = H(p) + KL(p ‖ q)

真实分布p固定时，H(p)是常数，所以最小化交叉熵就等价于最小化KL，即让q尽量接近p。

作为损失函数。分类任务里，真实标签是独热向量（正确类别为1，其余为0，见独热编码与词表），求和只剩一项：

L = −log q(正确类别)

这就是负对数似然，所以在数据集上最小化交叉熵等价于最大似然估计。q通常由Softmax与logits给出，此时损失对logits的梯度简化为q − y（预测概率减去独热标签），形式简单、数值稳定。

它出现在哪里。逻辑回归的损失是二分类交叉熵；AlexNet以来的图像分类网络用softmax加交叉熵训练；神经概率语言模型、GPT-3等语言模型在每个位置对“下一个词”算交叉熵并取平均，这个平均值的指数就是困惑度；知识蒸馏用教师模型的软概率代替独热标签来算交叉熵，见知识蒸馏。

例子

三类的logits为[2.0, 1.0, 0.1]，softmax后概率约[0.659, 0.242, 0.099]。若正确类别是第1类，损失 = −ln 0.659 ≈ 0.417；若正确类别是第3类，损失 = −ln 0.099 ≈ 2.317，大得多。第1类为正确答案时，对logits的梯度是q − y = [0.659−1, 0.242, 0.099] = [−0.341, 0.242, 0.099]：提高正确类别的logit，压低其他类别。语言模型每个token的平均交叉熵为2.0奈特时，困惑度为e² ≈ 7.39。

容易误解的地方

  • 交叉熵不对称：H(p, q) ≠ H(q, p)，通常把真实分布放在前面。
  • 报告数值时要说明对数的底：以e为底单位是奈特，以2为底是比特，两者相差ln 2 ≈ 0.693倍。
  • 直接对softmax输出取log会在概率接近0时溢出，实际应调用把两步合并的log_softmax或cross_entropy函数。
