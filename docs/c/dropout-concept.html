Dropout

Dropout

也叫：随机失活　丢弃法　暂退法　随机丢弃　inverted dropout

在交互版中打开（看它长在树上的哪里）

训练时每一步随机把一部分神经元的输出置零，迫使网络不依赖任何单个神经元；测试时全部保留。是一种简单有效的防过拟合手段。

先要会：泛化与过拟合 正则化与权重衰减 多层感知机

参数很多而数据不够时，神经网络会把训练集背下来：训练误差很低，在新数据上却很差（见泛化与过拟合）。一种具体的表现是神经元之间形成复杂的“共谋”：某个神经元只在另几个神经元恰好给出特定值时才有用，这种依赖在训练集上成立，换了数据就失效。

定义。训练时对某一层的输出h，每个分量独立地以概率p被置为0（p叫丢弃率，常取0.1到0.5），保留下来的分量除以(1 − p)：

m_i ~ Bernoulli(1 − p)，h̃_i = m_i · h_i / (1 − p)

除以(1 − p)保证h̃的期望等于h（这叫inverted dropout，是现在的标准实现），于是测试时直接关掉dropout、使用全部神经元，不用再做任何缩放。每个训练步都重新抽一次掩码m。

为什么有效。两种互补的解释：

  • 每一步都随机去掉一部分神经元，任何神经元都不能指望某个特定伙伴一定在场，只能学到单独也有用的特征。
  • 每一步训练的其实是一个随机抽出的子网络，n个神经元有2^n种子网络，它们共享参数。测试时用全网络、并按期望缩放，近似于对这些子网络取平均——一种廉价的集成学习。

它在哪里出现。Dropout（2012）在AlexNet的全连接层里使用，是当年赢下ImageNet的关键技巧之一。原始Transformer在每个子层的输出、以及词向量与位置编码之和上都用了0.1的dropout。后来由于数据量远大于参数能记住的量，很多大语言模型预训练时干脆把dropout设为0；它在数据较少的微调和中小模型上仍然常用。MC Dropout不确定性在测试时也保留dropout、多次前向，把输出的波动当作不确定性估计。它和正则化与权重衰减里的权重衰减是两类不同的正则化手段，常一起使用。

例子

某层输出h = [2, 4, 6, 8]，p = 0.5。这一步抽到的掩码是m = [1, 0, 1, 0]，于是h̃ = [2, 0, 6, 0] / 0.5 = [4, 0, 12, 0]。

单看这一次，数值和h差别很大；但对每个分量取期望：E[h̃_1] = 0.5×4 + 0.5×0 = 2，正好等于h_1。测试时直接用h = [2, 4, 6, 8]，与训练时的平均尺度一致。

如果不做除以(1 − p)的缩放，测试时全部神经元都在，下一层收到的输入总量会是训练时平均的2倍，结果就错了。

容易误解的地方

  • 测试时一定要关闭dropout（PyTorch里model.eval()）。忘了关会让预测每次都不一样，而且整体变差。
  • dropout会让训练损失变高、收敛变慢，这是预期中的代价，不代表模型更差。
  • dropout和BatchNorm放在一起时，两者的训练/测试行为差异可能互相干扰，卷积网络里后来用得越来越少。
