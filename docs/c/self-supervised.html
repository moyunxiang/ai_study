自监督学习

Self-Supervised Learning

也叫：SSL　self-supervision　前置任务　pretext task　无标注预训练

在交互版中打开（看它长在树上的哪里）

不用人工标签，而是从数据本身自动构造训练任务（如遮住一部分让模型补全、预测下一个词），用海量无标注数据训练出通用的表示。

先要会：监督学习 无监督学习

监督学习效果好，但标签贵：ImageNet动用了大量众包人力，标注100万张图；而互联网上的文本和图片多出几个数量级，几乎都没有标签。怎样让模型从这些数据里学到东西？

自监督学习的关键想法是：数据自己就能当老师。把一个样本的一部分藏起来，让模型根据剩下的部分去预测被藏起来的部分。被藏起来的内容就是“标签”，不需要任何人工。常见的构造方式：

  • 预测下一个：给出前面的词，预测下一个词。这就是语言模型的训练方式，GPT-1以来的GPT系列都用它。
  • 掩码重建（掩码建模）：随机遮住部分输入再还原。BERT遮住约15%的词；掩码自编码器MAE遮住75%的图像块。
  • 对比（对比学习）：同一张图的两个随机裁剪应该得到相近的表示，不同图片的表示要分开，代表是SimCLR。
  • 更早的“前置任务”：预测图片被旋转了多少度、把打乱的图块拼回去等。

这些任务本身往往没人关心（谁需要模型帮忙补全被遮住的词？），但要做好它们，模型必须理解语法、语义、物体形状等通用知识。训练完的模型再通过预训练与微调迁移到真正的任务，只需少量标签。

它出现在哪里：word2vec用预测上下文词学出词向量，是早期的成功案例；2018年后自监督预训练成为NLP的标准范式，随后扩展到视觉和语音。今天所有大语言模型的预训练阶段都是自监督的。

例子

句子“猫 / 坐在 / 垫子 / 上”（4个token）可以免费生成3个训练样本：

  • 输入“猫”，答案“坐在”
  • 输入“猫 坐在”，答案“垫子”
  • 输入“猫 坐在 垫子”，答案“上”

一万亿个token的语料，就自动提供了约一万亿个这样的预测任务，不需要任何人工标注。

容易误解的地方

  • 自监督不等于“没有人的设计”：遮多少、怎么数据增强，对结果影响很大，需要大量经验。
  • 有人把它算作无监督学习的一个子类，也有人单列，各论文的叫法不完全统一。
