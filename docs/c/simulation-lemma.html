模拟引理

Simulation Lemma

也叫：模拟引理　simulation lemma　模型误差界　model error bound　模型误差传播　model-based误差分析

在交互版中打开（看它长在树上的哪里）

量化“模型有一点不准，按模型评估策略会错多少”：如果估计模型每一步的转移误差不超过ε，那么任意策略在模型中与真实环境中的价值之差大致按ε/(1−γ)²放大，即随有效时域的平方增长。

先要会：基于模型的强化学习 Bellman方程 范数与距离

基于模型的强化学习的基本承诺是：学一个足够准的模型，在模型里规划就能得到在真实环境里也好的策略。“足够准”需要多准？模拟引理给出了答案，它是基于模型的PAC算法（如E3与PAC探索理论、R-max乐观探索）分析中的关键步骤。

内容。设真实MDP为M、估计的模型为M̂，二者奖励相同、取值在[0, 1]内，且对每个(s, a)，两个转移分布的L1距离‖P̂(·|s,a) − P(·|s,a)‖₁ ≤ ε。则对任意策略π和任意状态s，一个常见（不是最紧）的形式是

|V^π_M(s) − V^π_{M̂}(s)| ≤ γ·ε / (1 − γ)²

若奖励也有误差ε_R，再加上ε_R/(1−γ)。

为什么是平方。证明思路：把两个价值函数的差写成递推，每一步的差来自两部分：这一步转移不同带来的误差，至多γ·ε·max|V|，而价值本身最大是1/(1−γ)；以及下一步已有的价值差再乘γ传下去。展开求和，前者被累加约1/(1−γ)次，于是一个1/(1−γ)来自价值的大小，另一个来自误差在时域上的累积。这和复合误差说的是同一件事的定量版本。

推论。若对所有策略价值误差都不超过η，那么在模型中最优的策略，在真实环境中与最优策略相差至多2η。所以只要把模型学到ε = O((1−γ)²·η)的精度，规划就可靠。由此能推出学准模型所需的样本量，得到多项式的样本复杂度，见样本效率与样本复杂度。

实践上的启示。长时域规划对模型误差极敏感；所以深度模型方法常只用模型做短时域展开，再接一个价值函数估计剩余回报，例如MBPO的短rollout和TD-MPC的做法。MBPO本身也给出了一个类似风格的、与rollout长度有关的回报下界。

例子

γ=0.9，每步转移的L1误差ε=0.01：价值误差上界为0.9×0.01/0.01 = 0.9，而价值本身最大为10，即误差最多约9%。γ=0.99时同样的ε给出0.99×0.01/0.0001 ≈ 99，价值最大为100，界已经几乎没有意义：时域长10倍，所需的模型精度要高约100倍。

容易误解的地方

  • 这是最坏情况的上界，实际误差常小得多；但它说明了误差随时域增长的方式。
  • 要求的是所有(s, a)上的一致精度；模型在策略常去的地方准、在别处不准时，需要按状态分布加权的版本来分析。
