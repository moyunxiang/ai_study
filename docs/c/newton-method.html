牛顿法与拟牛顿法

Newton and Quasi-Newton Methods

也叫：牛顿法　Newton's method　Newton method　牛顿迭代　Newton-Raphson　牛顿-拉弗森　拟牛顿法　quasi-Newton　BFGS　L-BFGS　LBFGS　DFP　二阶方法　second-order method　二次收敛　quadratic convergence　阻尼牛顿法

用曲率（二阶导数）定步长和方向：把目标近似成二次函数，直接跳到它的最低点。拟牛顿法（BFGS、L-BFGS）用梯度的变化近似曲率，不必算海森矩阵。

先要会：雅可比矩阵与海森矩阵 泰勒展开 梯度下降

梯度下降只看坡度，不看弯曲程度：在一个又窄又长的山谷里，它会在两侧谷壁之间来回震荡，沿谷底前进得很慢。如果知道每个方向弯得有多厉害，就能在平缓的方向迈大步、陡峭的方向迈小步。

牛顿法。在当前点θ做二阶泰勒展开：

f(θ + d) ≈ f(θ) + gᵀd + ½ dᵀHd

g是梯度，H是海森矩阵（见雅可比矩阵与海森矩阵）。对d求导令其为0，得到这个二次近似的最低点：

d = −H⁻¹g，θ ← θ − H⁻¹g

对二次函数它一步就到最优点；在最优点附近，误差每一步大致平方一次（二次收敛），有效数字位数翻倍。

为什么深度学习里不直接用。一是代价：n个参数的海森矩阵有n²个元素，求逆要O(n³)，十亿参数完全不可能。二是非凸：H有负特征值时，−H⁻¹g可能指向上坡，牛顿法会被鞍点吸引（见高维优化的鞍点问题）。三是噪声：小批量上估计的曲率很不准。

拟牛顿法。不算H，而是从相邻两步的“位置变化”和“梯度变化”中逐步拼出H⁻¹的近似。BFGS维护一个n×n的近似矩阵；L-BFGS只保留最近m步（常取5到20）的向量对，用O(mn)内存隐式地乘出H⁻¹g，适合中等规模的确定性问题，例如逻辑回归、风格迁移、物理模拟里的参数拟合。它通常与线搜索与共轭梯度配合，每一步沿方向找一个合适的步长。

在深度学习里的影子。Hessian-free优化用共轭梯度只计算海森与向量的乘积，不显式存H；自然梯度用费舍尔信息矩阵代替海森（见费舍尔信息与Cramér–Rao下界）；K-FAC、Shampoo把曲率矩阵分块、分解成小矩阵再求逆；自适应学习率优化器如Adam只用梯度平方的滑动平均，可以看作极其廉价的对角近似。

例子

最小化f(x) = x⁴/4 − x，最优点x* = 1。f'(x) = x³ − 1，f''(x) = 3x²。从x = 2出发：

  • 牛顿：x ← 2 − 7/12 ≈ 1.417 → 1.417 − 1.845/6.02 ≈ 1.110 → ≈ 1.010 → ≈ 1.0001，四步误差到1e−4。
  • 梯度下降（学习率0.1）：x ← 2 − 0.7 = 1.3 → 1.3 − 0.12 ≈ 1.18 → … 需要十几步才到同样精度。

容易误解的地方

  • 牛顿法的局部二次收敛只在离最优点足够近时成立；离得远时一步可能跳得很远甚至发散，所以实际实现都加阻尼或线搜索。
  • L-BFGS对梯度噪声敏感，用在小批量随机训练上通常不如SGD或Adam。
