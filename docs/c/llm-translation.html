大模型机器翻译

LLM-based Machine Translation

也叫：LLM翻译　大模型翻译　LLM-MT　翻译大模型　专用翻译LLM　Translation LLM　LLM for MT　开源翻译模型

在交互版中打开（看它长在树上的哪里）

用大语言模型做翻译：要么直接让通用模型翻，要么在开源底座上专门为翻译做预训练、微调和强化学习。

ChatGPT发布和GPT-4出现后，人们发现通用大模型不经专门训练就能给出流畅的译文，传统的编码器-解码器翻译模型（NLLB两百种语言翻译、M2M-100非英语中心翻译）在高资源语言上的优势不再明显。2025年起出现一批7B级的开源专用翻译大模型：Seed-X翻译模型在中英为主的语料上预训练，用先解释再翻译的思维链和PPO强化学习；混元翻译Hunyuan-MT在WMT2025的31个语对中拿下30个第一；TranslateGemma在Gemma 3上用合成平行语料和质量估计奖励做后训练。

这条路线的共同做法是：用强模型生成或改写平行语料，再用学习型质量指标（如COMET译文质量评估一类）或奖励模型做强化学习。争论在于奖励来自自动指标时，模型会不会学会迎合指标；以及在低资源语言上，这些模型的效果在多大程度上经过了人工验证。
