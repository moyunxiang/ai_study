范数与距离

Norms and Distances

也叫：L1范数　L2范数　欧氏距离　Euclidean distance　曼哈顿距离　向量长度　模长

在交互版中打开（看它长在树上的哪里）

范数给向量一个“长度”，两个向量之差的范数就是它们的距离。常用的有L2（欧氏长度）、L1（绝对值之和）和L∞（最大分量）。

先要会：向量、矩阵与张量

训练模型时经常要回答“有多大”和“有多远”：参数是不是太大了？预测离真实答案差多少？两张图片在特征空间里相隔多远？梯度是不是大得离谱？这些都需要一个把向量变成非负数的“尺子”，这就是范数。

定义。最常用的是Lp范数：

‖x‖_p = (Σ_i |x_i|^p)^(1/p)

  • p = 2：‖x‖_2 = √(Σ x_i²)，就是普通的欧氏长度。
  • p = 1：‖x‖_1 = Σ |x_i|，各分量绝对值之和，也叫曼哈顿距离。
  • p = ∞：‖x‖_∞ = max_i |x_i|，最大的那个分量。

两点之间的距离定义为d(x, y) = ‖x − y‖。矩阵也有范数，最常用的Frobenius范数就是把所有元素平方求和再开方。

L1和L2的性格不同。L2对大值惩罚更重（平方），倾向于让所有分量都小一点；L1对所有分量一视同仁，倾向于让很多分量恰好为0，即“稀疏”。这一区别决定了两种正则化与权重衰减的效果。

它出现在哪里。岭回归与L2正则在损失里加L2范数的平方，Lasso与L1稀疏加L1范数，后者能自动挑出少数重要特征；k近邻按欧氏距离找最近的邻居；梯度裁剪在梯度的L2范数超过阈值时把它按比例缩小，防止训练爆炸，见梯度裁剪。均方误差损失本质上就是预测误差的L2范数平方。

例子

x = (3, −4)。L2范数 = √(9 + 16) = 5；L1范数 = 3 + 4 = 7；L∞范数 = 4。点(1, 1)和(4, −3)之间的欧氏距离就是‖(3, −4)‖_2 = 5。梯度裁剪的例子：阈值设为1，梯度为(3, −4)，范数5超过1，于是乘以1/5变成(0.6, −0.8)，方向不变、长度变为1。

容易误解的地方

  • 所谓“L0范数”（非零分量的个数）其实不满足范数的定义，而且不可导，所以实践中用L1来近似它。
  • 高维空间里，所有点之间的欧氏距离往往差不多大，“最近邻”变得不那么有意义，见维度灾难。
