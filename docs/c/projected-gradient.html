投影梯度下降

Projected Gradient Descent

也叫：投影梯度下降　投影梯度　projected gradient descent　projected gradient　PGD　PGD攻击　PGD attack　可行集　feasible set　权重裁剪　weight clipping　最大范数约束　max-norm constraint　镜像下降　mirror descent　凸集投影

带约束的最简单优化法：先照常走一步梯度，若走出了允许的区域，就把点“投影”回区域内离它最近的位置。权重裁剪、概率单纯形约束和PGD对抗攻击都是它的例子。

先要会：梯度下降 凸函数与凸优化

很多优化问题的变量必须待在某个范围里：概率要非负且和为1，对抗扰动的大小不能超过ε，某些权重必须在[−c, c]之间。拉格朗日乘子、约束优化与对偶把约束写进目标里；投影梯度下降的办法更直接：

x ← Π_C( x − η·∇f(x) )

先做一步普通的梯度下降，再用投影Π_C把结果拉回可行集合C。投影定义为C中离该点最近的点：Π_C(y) = argmin_{x∈C} ‖x − y‖（见范数与距离）。只要C是凸集，投影唯一，而且对凸光滑的f，投影梯度法与无约束梯度下降有同样的收敛速率（见凸函数与凸优化和收敛速率与强凸）。

常见的投影都很便宜。

  • 区间或盒子约束[a, b]：逐元素截断，即clip(x, a, b)。
  • L2球‖x‖ ≤ r：如果超出，就把x缩放到半径r：x·r/‖x‖。
  • L∞球‖x − x₀‖∞ ≤ ε：每一维与x₀的差截断到[−ε, ε]。
  • 概率单纯形（非负、和为1）：有O(n log n)的排序算法。

它出现在哪里。

  • PGD对抗攻击：寻找让模型出错的扰动δ，约束是‖δ‖∞ ≤ ε。从FGSM与线性解释的一步符号梯度出发，PGD反复做“沿损失梯度的符号走一小步，再截断回ε球”，是评估对抗鲁棒性的标准攻击；PGD对抗训练用PGD生成的样本做对抗训练（见对抗样本）。
  • WGAN的权重裁剪：Wasserstein GAN把判别器的每个权重截断到[−0.01, 0.01]，是一种粗糙的投影，用来近似利普希茨约束（见利普希茨连续与光滑性）；后来被梯度惩罚取代。
  • 最大范数约束：把每个神经元的输入权重向量投影到半径c的球内，曾与Dropout配合使用。
  • 信赖域方法如TRPO把“新旧策略KL不超过δ”当作约束，更新后若越界就回退缩小步长，思想相近。

镜像下降是它的推广：不用欧氏距离而用其他“距离”（如KL散度）定义投影，在概率单纯形上更自然。

例子

约束x ∈ [0, 1]，最小化f(x) = (x − 2)²。从x = 0.5出发，学习率0.3：梯度为−3，一步走到0.5 + 0.9 = 1.4，超出区间，投影回1.0。之后梯度为−2，走到1.6，又被投影回1.0，停在边界上，这正是约束问题的最优解。

PGD攻击：ε = 8/255，步长2/255，像素原值0.50，某一步后扰动累计为+10/255，被截断回+8/255。

容易误解的地方

  • 只有凸集上的投影才唯一且保证收敛性质；非凸约束（如“恰好k个非零元”）的投影可能难算，理论保证也不再成立。
  • 拿“梯度下降 + 事后截断”去处理复杂约束时，截断后的点未必是投影点，例如对向量逐元素截断并不能实现L2球的投影。
