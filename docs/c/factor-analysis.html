因子分析与概率PCA

Factor Analysis and Probabilistic PCA

也叫：因子分析　factor analysis　概率PCA　概率主成分分析　probabilistic PCA　PPCA　因子载荷　factor loadings　线性高斯模型　linear Gaussian model　混合因子分析　mixture of factor analyzers　PLDA　隐因子　latent factors　方差最大旋转　varimax

最简单的连续隐变量模型：观测数据由少数几个高斯隐因子经线性变换再加噪声生成。噪声各维方差不同叫因子分析，各维相同叫概率PCA；它们是VAE的线性前身。

先要会：隐变量模型 高斯分布 协方差矩阵

一份心理问卷有50道题，但答题模式可能只由少数几个潜在特质决定（外向、焦虑、责任心……）；一段语音的特征向量有几千维，但说话人之间的差异也许只需要几百个数描述。假设高维观测背后有少数几个看不见的连续因子，就得到线性高斯隐变量模型（见隐变量模型）。

模型。隐因子z是k维标准正态（k远小于观测维数d），观测x由它线性生成并加上噪声：

z ~ N(0, I)，x = W·z + μ + ε，ε ~ N(0, Ψ)

W是d×k的因子载荷矩阵。积分掉z后，x的边缘分布是

x ~ N(μ, WWᵀ + Ψ)

也就是说，模型用“一个低秩矩阵 + 一个对角矩阵”来近似协方差（见协方差矩阵和低秩近似），参数从d²/2个降到约d·k个。

因子分析（FA）与概率PCA（PPCA）。

  • 因子分析：Ψ是任意对角阵，每一维观测有自己的噪声方差，适合各维测量精度不同的情况。
  • 概率PCA：Ψ = σ²I，所有维度噪声相同。σ² → 0时，最大似然解的W张成的子空间就是主成分分析PCA的主成分子空间。所以PPCA给PCA补上了一个概率解释：可以算似然、处理缺失值、做模型比较。

训练。PPCA的最大似然解有闭式形式（来自样本协方差的特征分解，见特征分解与奇异值分解）；因子分析一般用EM算法：E步算给定x时z的后验（仍是高斯），M步更新W和Ψ。

它的位置。

  • 把多个这样的线性模型混合起来，就是混合因子分析，可以拟合弯曲的流形（对比高斯混合模型）。
  • 把线性映射W·z换成神经网络解码器、后验换成编码器网络的近似，就得到变分自编码器VAE（见变分推断与ELBO）。
  • 去掉“z是高斯”的假设、要求各因子统计独立且非高斯，就是独立成分分析独立成分分析ICA。
  • 说话人识别中的i-vector说话人识别和后续的PLDA本质上都是因子分析模型。

例子

d = 3维观测，k = 1个因子。设W = (2, 1, 0.5)ᵀ，Ψ = diag(0.5, 0.5, 0.5)（等方差，即PPCA）。模型协方差为WWᵀ + Ψ = [[4.5, 2, 1], [2, 1.5, 0.5], [1, 0.5, 0.75]]。第一维与第二维的协方差2完全来自共同因子；如果数据的样本协方差接近这个矩阵，就说明一个因子足以解释三个变量之间的相关性。

容易误解的地方

  • W只在旋转意义下唯一：对z做任意正交变换R，WR给出完全相同的分布。因子分析中常用的“方差最大旋转”只是为了让载荷更容易解释，并不改变模型。
  • 因子个数k要人为选，可以用信息准则或交叉验证的似然（见信息准则AIC与BIC）。
