期望与方差

Expectation and Variance

也叫：均值　mean　标准差　standard deviation

在交互版中打开（看它长在树上的哪里）

期望是随机变量按概率加权的平均值，方差是它偏离期望的平方的平均值，衡量波动有多大。训练目标、梯度估计和初始化分析都离不开这两个量。

先要会：随机变量与概率分布

一个分布可能很复杂，但很多时候我们只需要两个数来概括它：它的中心在哪里，它有多分散。机器学习的损失函数本质上就是一个期望（“在所有数据上的平均损失”），而训练是否稳定，往往取决于各种量的方差。

期望。离散型E[X] = Σ_x x·P(X = x)，连续型E[X] = ∫ x·p(x) dx。更一般地，函数的期望是E[f(X)] = Σ_x f(x)·P(X = x)。期望最重要的性质是线性：E[aX + bY] = aE[X] + bE[Y]，无论X和Y是否独立都成立。

方差与标准差。

Var(X) = E[(X − E[X])²] = E[X²] − (E[X])²

标准差σ = √Var(X)，与X同单位。常用性质：Var(aX) = a²Var(X)；若X和Y独立，Var(X + Y) = Var(X) + Var(Y)。由此可得一个关键结论：n个独立同分布样本的平均值，方差是单个样本的1/n，标准差缩小为1/√n。

它出现在哪里。训练的目标是最小化期望损失E_{(x,y)~数据}[L]，随机梯度下降用一小批样本的平均梯度来估计它，批越大估计的方差越小，见随机梯度下降与小批量；Xavier初始化和He初始化与PReLU通过计算每层输出的方差来设定权重的初始尺度，让信号既不爆炸也不消失，见参数初始化；Batch Normalization把每层激活的均值和方差标准化；REINFORCE策略梯度的梯度估计方差很大，减去一个基线可以降低方差而不改变期望，这一思路贯穿整个策略梯度。

例子

均匀骰子：E[X] = (1+2+…+6)/6 = 3.5。E[X²] = (1+4+9+16+25+36)/6 = 91/6，所以Var(X) = 91/6 − 3.5² = 35/12 ≈ 2.917，标准差约1.71。掷100次取平均，平均值的标准差缩小为1.71/10 ≈ 0.171。初始化的例子：输出y = Σ w_i x_i 由512个输入加权求和，若x_i和w_i都独立、均值为0、方差为1，则Var(y) = 512，标准差约22.6；把权重方差设为1/512，输出方差就回到1。

容易误解的地方

  • 期望值不一定是“最可能出现的值”：骰子永远掷不出3.5。
  • 期望的线性不需要独立，但“方差相加”需要独立（或至少不相关）。
