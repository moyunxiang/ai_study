元学习

Meta-Learning

也叫：学会学习　learning to learn　MAML　小样本学习　few-shot learning　元训练

在交互版中打开（看它长在树上的哪里）

“学会学习”：在许多相关的小任务上训练，使模型面对一个新任务时只需几个样本或几步更新就能学会。

先要会：迁移学习 嵌入向量 零样本与少样本

人看过几张某种新动物的照片就能认出它，普通神经网络却要每类几百上千张图。原因之一是人积累了大量“如何学新类别”的经验。元学习想把这种经验也学出来：训练单位不再是一个样本，而是一个任务。

设置：每个任务（叫episode）有一个很小的支持集（例如5个类、每类1张图，称5-way 1-shot）和一个查询集。模型看支持集，然后要把查询样本分对。训练时从大量任务里反复采样这样的episode，测试时用训练中从未见过的类别组成新任务。这就是零样本与少样本里“少样本”最早的形式化做法。

三条路线：

  • 度量型：学一个嵌入空间，让同类靠近。匹配网络与小样本学习用注意力对支持样本加权；原型网络把每类支持样本的嵌入平均成一个“原型”，查询样本归到最近的原型。
  • 优化型：MAML元学习学一个初始参数，使得从它出发只做一两步梯度下降就能适应新任务。外层优化的目标是“内层更新之后的损失”，需要对梯度再求梯度。
  • 模型型：让一个序列模型直接读入支持集、输出预测，学习过程发生在前向计算里。

和大模型的关系：GPT-3展示的上下文学习与提示可以看成第三条路线的极端版本：模型没有为episode专门训练，但在海量文本预训练后，读几个示例就能做新任务。ICL即隐式元优化等工作进一步论证上下文学习在数学上类似一次隐式的梯度更新。

例子

2-way 2-shot，嵌入已算好。类A支持样本(1,0)、(3,0)，原型 = (2,0)；类B支持样本(0,2)、(0,4)，原型 = (0,3)。查询点(1,1)到A原型距离√2 ≈ 1.41，到B原型√5 ≈ 2.24。原型网络用负平方距离做Softmax与logits：p(A) = e^−2 / (e^−2 + e^−5) ≈ 0.95，判为A。

容易误解的地方

  • 元学习的“少样本”只在测试任务上少；训练时依然需要大量任务和大量数据。
  • 后来有研究发现，在常用基准上，先普通预训练一个好特征、再在新类上简单微调，常常就能追平复杂的元学习算法。
  • 元学习、多任务学习、迁移学习的边界并不清晰，不同论文用词不一。
