动量

Momentum

也叫：动量法　heavy ball　重球法　Nesterov动量　Nesterov momentum　SGD with momentum

在交互版中打开（看它长在树上的哪里）

更新参数时不只看当前梯度，而是累积过去梯度的加权和，像一个有惯性的小球：方向一致时越滚越快，来回摆动时互相抵消。

先要会：梯度下降 学习率与学习率调度

普通梯度下降有个典型毛病：如果损失曲面是一条狭长的山谷，一个方向很陡、另一个方向很平，梯度主要指向陡的方向，参数在谷壁之间来回弹跳，沿谷底前进却很慢。调小学习率与学习率调度能减轻震荡，但前进更慢了。

动量法给参数加上“速度”v，每步把当前梯度累加进去：

v ← β·v + g θ ← θ − η·v

β通常取0.9。展开来看，v是过去所有梯度的指数加权和g_t + β·g_{t−1} + β²·g_{t−2} + …。于是：

  • 在梯度方向一直一致的维度上，速度逐渐累积，最多放大到1/(1 − β)倍（β = 0.9时是10倍），沿谷底加速。
  • 在梯度正负来回翻转的维度上，相邻梯度互相抵消，震荡被压住。

这正像一个有质量的小球在曲面上滚：惯性让它冲过小坑和平坦区，也让它不会被每一次颠簸带偏。在随机梯度下降与小批量中，动量还起到平均掉梯度噪声的作用。

Nesterov动量是一个小改动：先按当前速度“预走一步”，在那个位置算梯度再修正，理论上对凸问题收敛更快。

它出现在哪里：动量法（Polyak 1964）提出“重球法”；Nesterov加速梯度（1983）给出加速版本；动量与初始化的重要性（2013）说明了动量配合好的初始化对训练深度网络至关重要。Adam里的一阶矩估计本质上就是动量，所以今天几乎所有优化器都带着它。

例子

β = 0.9，梯度一直是1：速度依次为1、1.9、2.71、3.44、4.10……最终趋于10，相当于学习率放大10倍。

梯度在+1和−1之间交替：速度依次为1、−0.1、0.91、−0.18、0.84……最终在约±0.53之间摆动，只有原来幅度的一半左右，震荡被抑制了。

容易误解的地方

  • 不同框架的写法略有差别（例如有的写v ← βv + (1−β)g），同样的β对应的有效步长不同，迁移超参数时要看清公式。
  • 动量太大（如0.99）配合大学习率，可能冲过头导致不稳定。
