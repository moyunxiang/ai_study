权重平均

Weight Averaging

也叫：Weight Averaging　参数平均　EMA　指数滑动平均　Exponential Moving Average　SWA　随机权重平均　Polyak平均　检查点平均　Checkpoint Averaging　LAWA　权重插值　Weight Interpolation　Model Soup　模型汤

在交互版中打开（看它长在树上的哪里）

直接对同一训练过程不同时刻、或同一起点出发的多个模型的参数取平均，得到更稳、泛化更好的模型，不增加推理成本。

最早的形式是Polyak平均与EMA：对优化轨迹上的参数取平均，降低随机梯度的噪声，今天训练中普遍使用的EMA权重就是它的变体，Schedule-Free优化也把平均写进了优化器本身。模式连通性发现不同解之间常有低损失路径，说明在参数空间里做插值不一定会掉进高损失区；随机权重平均SWA在循环学习率下平均多个点的权重，落到更平的区域；快照集成则把一次训练的多个快照做输出集成而非权重平均。

大模型时代，Model Soups权重平均把从同一预训练模型出发、用不同超参数微调的多个模型直接平均，提升准确率而不增加推理成本，由此发展出任务算术与模型合并、TIES-Merging模型合并等模型合并方法（另见系统分支的模型合并）。权重平均成立的前提通常是这些模型处在同一个“盆地”里，例如共享同一个初始化或预训练起点。
