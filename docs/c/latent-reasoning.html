潜空间推理

Latent Reasoning

也叫：latent reasoning　隐式推理　implicit reasoning　连续思维　continuous thought　latent CoT　隐空间推理　潜在推理　Coconut　循环深度　recurrent depth　looped transformer　不用文字思考

在交互版中打开（看它长在树上的哪里）

让模型在内部的连续向量或反复计算中完成推理，而不是把每一步都写成自然语言的思维链。

思维链把推理过程写成文字，代价是大量只为通顺而存在的token，以及每一步都要选定一个词。潜空间推理试图绕开文字：Quiet-STaR让模型在每个位置生成不显示的内部思考；Coconut连续潜空间推理把最后一层隐状态直接喂回输入，在需要搜索的逻辑题上比思维链更准、token少得多；分层推理模型HRM和微型递归模型TRM用小网络反复迭代内部状态解ARC和数独；Ouro循环语言模型让语言模型的同一组层循环多次来加深计算；连续自回归CALM把生成本身改成在连续向量上进行。

目前它在大规模通用推理上还没有取代文字思维链，算术等任务上常常更差。安全方面的担忧是：推理一旦不可读，就无法再通过阅读思维链来监督模型（见CoT可监控性）。
