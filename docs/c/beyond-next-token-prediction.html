超越下一词预测

Beyond Next-Token Prediction

也叫：超越NTP　beyond NTP　next-token prediction的替代　多token预测　multi-token prediction　MTP　下一向量预测　next-vector prediction　下一词推理　next-token reasoning　新的预训练目标

在交互版中打开（看它长在树上的哪里）

质疑“一次预测一个离散token”这个默认设定：一次预测多个词、预测连续向量、先推理再预测，或者干脆并行去噪。

从GPT-1到今天，大模型的预训练目标几乎都是预测下一个token。近两年有几条路线试图改掉它：多token预测MTP让模型同时预测后面几个词，被DeepSeek-V3、Nemotron 3混合Mamba用来加速生成；连续自回归CALM用自编码器把4个token压成一个连续向量，改为预测下一个向量；强化预训练RPT让模型先思考再预测下一个词，用是否猜中作为强化学习奖励；扩散语言模型（LLaDA大语言扩散模型等）则完全放弃从左到右；字节潜变量BLT、H-Net动态分块从另一头入手，改变“token”本身的粒度。

这些方法各自在效率或数据利用上报告了收益，但到2026年，前沿模型的主干仍是下一词预测，替代路线多作为辅助目标或特定场景方案。
