重要性采样

Importance Sampling

也叫：IS　重要性权重　importance weight　重要性比率　importance ratio　离策略修正

在交互版中打开（看它长在树上的哪里）

想求分布p下的期望，却从另一个分布q里采样，再给每个样本乘上权重p(x)/q(x)来纠正偏差。它让我们能复用别的分布产生的样本，选得好还能大幅降低方差。

先要会：蒙特卡洛采样 期望与方差 高斯分布

蒙特卡洛采样要求从目标分布p中采样，但很多时候做不到或不划算：p可能根本无法直接采样；或者p下我们关心的事件极少发生，抽一万个样本也碰不到几次；在强化学习里，手头的数据是旧策略收集的，而我们想评估的是新策略。重要性采样解决的都是同一个问题：用q的样本估计p下的期望。

推导。只要在p(x) > 0的地方q(x) > 0：

E_{x~p}[f(x)] = Σ_x p(x) f(x) = Σ_x q(x) · (p(x)/q(x)) · f(x) = E_{x~q}[w(x) f(x)]

其中w(x) = p(x)/q(x)叫重要性权重。于是从q中抽x_1, …, x_N，用(1/N) Σ_i w(x_i) f(x_i)估计，仍然是无偏的。

方差是关键。q选得好，样本集中在p(x)|f(x)|大的地方，方差可以比直接采样小几个数量级；q选得差（尤其在p大而q很小的地方），权重会极大且不稳定，估计反而更糟。理论上最优的q正比于p(x)|f(x)|。

它出现在哪里。强化学习中，用行为策略β收集的数据评估目标策略π时，要乘上概率比π(a|s)/β(a|s)，这是on-policy与off-policy的核心。TRPO和PPO的目标函数里都有新旧策略的概率比π_θ(a|s)/π_old(a|s)，这就是重要性权重；PPO把它截断在[1−ε, 1+ε]内，正是为了控制权重过大带来的方差。重要性加权IWAE在VAE中用多个样本的重要性加权平均，得到比变分推断与ELBO更紧的似然下界。

例子

估计标准正态X超过3的概率（真值约0.00135）。直接采样10000个点，平均只有约13.5个超过3，估计的相对标准误差约27%。改从q = N(3, 1)采样，约一半样本落在3以上，每个样本的权重是w(x) = p(x)/q(x) = exp(−3x + 4.5)，例如x = 3时w ≈ 0.0111，x = 3.5时w ≈ 0.0025。同样用10000个样本，相对标准误差降到约1.8%，精度提高了约15倍。

容易误解的地方

  • 如果q在p有概率的某些区域几乎为0，估计在有限样本下会严重偏离，而且样本方差本身也看不出问题。
  • 高维时权重往往极度不均：少数样本的权重占了绝大部分，有效样本数远小于N。实践中常对权重做截断或归一化，代价是引入少量偏差。
