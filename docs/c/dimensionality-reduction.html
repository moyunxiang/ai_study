降维与PCA

Dimensionality Reduction and PCA

也叫：主成分分析　principal component analysis　t-SNE　UMAP　降维可视化　特征降维

在交互版中打开（看它长在树上的哪里）

用少数几个数来概括高维数据，同时尽量保留其中重要的信息。PCA是最经典的方法：找出数据变化最大的几个方向，把数据投影上去。

先要会：特征分解与奇异值分解 期望与方差 无监督学习

真实数据的维度往往很高：一张28×28的手写数字图有784个像素值，一张普通照片有几十万个。但这些维度高度冗余——相邻像素几乎一样，所有“手写数字”的图片只占784维空间中极小的一部分。降维就是找到一个低维的描述，用来压缩存储、去除噪声、可视化，或者为后续模型提供更紧凑的输入。高维空间本身的种种反直觉现象见维度灾难。

主成分分析（PCA）是最经典的线性降维方法：

1. 把数据减去均值，算出协方差矩阵C = (1/N) Σ_i x_i x_iᵀ。 2. 对C做特征分解（见特征分解与奇异值分解）。特征向量是数据变化的主要方向，对应的特征值是数据在该方向上的方差。 3. 取特征值最大的k个特征向量，把每个数据点投影上去，得到k维表示。

前k个特征值之和占全部特征值之和的比例，就是这k维保留的方差比例。PCA也可以理解为：在所有k维线性子空间中，找一个使数据投影后重建误差最小的。

非线性降维：数据如果分布在一个弯曲的低维曲面（流形）上，线性投影就不够了。流形学习Isomap/LLE试图保持数据点之间沿曲面的距离；t-SNE专门用于把高维数据压到二维画图，保持“谁和谁是近邻”；神经网络自编码器用编码器把数据压到一个窄的中间层，再用解码器重建，深度自编码器显示它的降维效果明显优于PCA。

它出现在哪里：主成分分析PCA（1901）和特征脸Eigenfaces（用PCA做人脸识别）是经典应用；今天看论文里那种把模型内部表示画成二维散点图的图，几乎都是PCA或t-SNE的结果。

例子

四个二维点：(−2, −1)、(−1, −1)、(1, 1)、(2, 1)，均值已经是0。

协方差矩阵为[[2.5, 1.5], [1.5, 1]]，特征值约为3.427和0.073。第一主成分方向约为(0.851, 0.526)，它解释了3.427/3.5 ≈ 97.9%的方差。

把四个点投影到这个方向上，得到一维坐标约为−2.23、−1.38、1.38、2.23：用一个数代替两个数，几乎没有丢失信息。

容易误解的地方

  • PCA只找方差最大的方向，方差大不一定代表对任务重要；做PCA前通常还要对各维度做标准化，否则单位大的特征会主导结果。
  • t-SNE图上簇与簇之间的距离、簇的大小都没有可靠含义，不能据此下定量结论。
