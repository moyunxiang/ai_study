机器阅读理解

Machine Reading Comprehension

也叫：MRC　阅读理解　Reading Comprehension　抽取式问答　Extractive QA　片段抽取　Span Extraction　SQuAD式问答

在交互版中打开（看它长在树上的哪里）

给模型一段文章和一个问题，让它从文章里找出答案，用来检验机器是否“读懂”了文本。

阅读理解在2015年前后成为NLP的热门任务，关键是出现了足够大的数据集：注意力阅读器与CNN/DM从CNN和Daily Mail新闻里自动构造完形填空式问题，SQuAD则让众包工人针对维基百科段落提问，答案是原文中的一段文字。

于是出现了一系列注意力模型：Match-LSTM与答案指针用指针网络预测答案的起止位置，BiDAF双向注意力流在问题和文章之间做双向注意力，成为当时的标准结构。DrQA开放域问答把阅读器和检索器接起来，走向开放域问答。2018年BERT在SQuAD上超过人类基准，这一类专门设计的阅读模型很快被预训练模型的微调取代。今天的讨论是：基准上超过人类是否真的代表理解，模型是否只是在利用数据集里的表面线索。
