视觉语言模型

Vision-Language Model

也叫：VLM　MLLM　多模态大语言模型　Multimodal Large Language Model　LVLM　Large Vision-Language Model　LMM　大型多模态模型　多模态大模型　视觉大模型　图文大模型

在交互版中打开（看它长在树上的哪里）

能同时读图像和文字、并用语言回答的模型；今天通常指把视觉编码器接到大语言模型上得到的系统。

早期的视觉-语言模型为每个任务（图像描述、视觉问答）单独训练，见图像描述Show and Tell、自底向上注意力。BERT时代出现了先预训练再迁移的通用模型（ViLBERT、UNITER）。现在说的VLM/MLLM，主流结构是三段式：预训练好的视觉编码器（多为CLIP或SigLIP）把图切块编码，一个连接器把视觉特征变成语言模型能读的token，再交给大语言模型生成回答。Flamingo和BLIP-2证明冻结两端、只训连接部分就能读图，LLaVA用GPT生成的指令数据让它会聊天，LLaVA-1.5的简单MLP配方成为开源标准。

之后的进展集中在分辨率、数据和规模上（Qwen2-VL与开源VLM、InternVL、Qwen2.5-VL、DeepSeek-VL2），商业侧有GPT-4V和原生多模态的GPT-4o全模态实时模型。当前讨论的焦点是：视觉编码器是否成了短板（CLIP视觉盲区）、要不要彻底去掉编码器、以及如何让VLM像推理模型一样先想后答。
