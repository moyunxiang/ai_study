嵌入向量

Embeddings

也叫：向量表示　词向量　word embedding　embedding vector　稠密向量　dense vector

在交互版中打开（看它长在树上的哪里）

用一个可学习的稠密实数向量来表示一个离散对象（词、token、用户、商品），使意义相近的对象对应的向量也相近。

先要会：独热编码与词表 向量、矩阵与张量 内积与余弦相似度

神经网络只能处理数字，而词、商品、用户ID这些是离散的符号。最朴素的做法是独热编码与词表：词表有V个词，就用一个V维向量，对应位置为1、其他为0。但这样的向量非常长，而且任意两个词的内积都是0，“猫”和“狗”与“猫”和“汽车”一样不相似，模型无法利用词与词之间的相似性。

嵌入的做法是：为每个离散对象分配一个d维的实数向量（d通常是几百到几千），把这些向量当作模型参数，在训练中和其他参数一起学习。所有向量排成一个V × d的矩阵E，查找第i个词的嵌入就是取E的第i行——这在数学上等价于用one-hot向量乘以E，但实现上直接按下标取行。

训练结束后，在任务中扮演相似角色的对象会得到相近的向量，常用内积与余弦相似度或余弦相似度来比较。这种性质来自分布假说：出现在相似上下文中的词，意义也相近。

它出现在哪里：

  • 神经概率语言模型（2003）在神经语言模型中引入了可学习的词向量；word2vec（2013）用简单高效的训练得到高质量词向量，并展示了vec(king) − vec(man) + vec(woman) ≈ vec(queen)这类向量运算。
  • 今天每个Transformer语言模型的第一层都是token嵌入表，输出层常与它共享权重（输入输出嵌入共享）。
  • 嵌入的概念也扩展到整句、整张图：CLIP把图像和文本嵌入到同一个空间，检索与向量数据库系统用句子嵌入在向量数据库里查找相关文档。

例子

GPT-2的词表有50257个token，嵌入维度768（最小的版本），嵌入表就有50257×768 ≈ 3860万个参数。

玩具例子：设“猫” = (0.8, 0.6)，“狗” = (0.7, 0.7)，“汽车” = (−0.6, 0.8)。“猫”与“狗”的余弦相似度 = (0.56 + 0.42)/(1×0.99) ≈ 0.99；“猫”与“汽车”的余弦相似度 = (−0.48 + 0.48)/1 = 0。

容易误解的地方

  • 单个嵌入维度通常没有可解释的含义，有意义的是向量之间的相对位置。
  • king − man + woman ≈ queen这类类比在挑选过的例子上效果好，系统测试时并不总成立，且计算时常排除了输入词本身。
