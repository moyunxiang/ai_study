高效推理与过度思考

Efficient Reasoning and Overthinking

也叫：过度思考　overthinking　高效推理　efficient reasoning　推理压缩　思考预算　thinking budget　推理强度　reasoning effort　自适应思考　adaptive thinking　混合思考　hybrid thinking　长度控制　underthinking

在交互版中打开（看它长在树上的哪里）

推理模型常为简单问题写出过长的思考；这条线研究怎样按需分配思考长度，在不掉点的前提下少花token。

推理模型的过度思考发现o1类模型回答「2+3等于几」也会写上千个token，而且多余的推理很少带来收益。应对方式有几类：在产品层面让用户选推理强度或思考预算（思考预算与推理强度、Claude可见扩展思考），或像Qwen3混合思考那样在一个模型里切换思考与不思考模式；在解码层面控制长度，如s1与预算强制的预算强制、DeepConf置信度筛选推理按置信度提前截断低质量推理；在训练层面把长度惩罚放进奖励，或通过自蒸馏让回答变短（SDPO自蒸馏策略优化报告回答短3倍以上）。Coconut连续潜空间推理则尝试干脆不用文字思考。

相反的问题也存在：模型在难题上过早放弃一条思路（「欠思考」）。怎样让模型自己判断「这题值得想多久」仍未解决。
