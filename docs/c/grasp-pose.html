6自由度抓取与6D物体位姿估计

6-DoF Grasping and 6D Object Pose Estimation

也叫：6自由度抓取　六自由度抓取　6-DoF grasp　6-DoF grasping　6DoF grasp　抓取检测　grasp detection　抓取位姿　grasp pose　抓取规划　grasp planning　平面抓取　planar grasp　力封闭　force closure　6D位姿估计　6D pose estimation　物体位姿估计　object pose estimation　6DoF位姿　ADD指标　BOP基准　ICP　iterative closest point　迭代最近点

机器人抓取的两个基本问题：6自由度抓取要算出夹爪的三维位置和朝向，使物体能被稳定拿起；6D物体位姿估计要算出物体相对相机的旋转和平移，以便按已知模型规划抓取。

先要会：位姿与齐次变换SE(3) 相机模型与多视图几何

抓取的表示。最简单的是平面抓取：相机从正上方往下看，只预测图像上的抓取点、夹爪张开方向和宽度（4个左右的自由度），适合桌面上的散乱物体。真实场景里常需要从侧面、斜着抓，这就要6自由度抓取：夹爪的完整位姿是一个SE(3)变换（见位姿与齐次变换SE(3)和三维旋转的表示：旋转矩阵、欧拉角与四元数），再加上张开宽度。

怎么判断一个抓取好不好。经典方法基于物体模型和接触力学：计算接触点上的摩擦锥能否抵抗任意方向的外力（力封闭）。数据驱动的方法则直接学习“这个抓取成功的概率”：

  • Dex-Net 2.0在大量仿真物体上用解析方法标注抓取质量，训练一个网络在深度图上评估候选抓取；
  • 5万次抓取自监督、机械臂农场抓取、QT-Opt用真实机械臂反复试抓、以是否成功作为标签，属于自监督或强化学习路线；
  • Contact-GraspNet六自由度抓取、AnyGrasp抓取感知直接从点云中预测大量6自由度抓取位姿及其质量，能处理堆叠杂乱的场景。

6D物体位姿估计。如果物体的三维模型已知（工业零件、超市商品），可以先估计它相对相机的6D位姿，再把在模型上预先规划好的抓取变换过来。方法包括：模板匹配与特征点匹配后用PnP：由二维–三维对应求相机位姿求解；用网络预测物体关键点或逐像素的物体坐标再解PnP；直接回归旋转和平移再用迭代最近点（ICP）细化；对没见过的新物体，基于参考图像或CAD模型做零样本位姿估计。评测常用ADD指标（模型点变换后的平均距离）和BOP基准。与之相关但不同的是人体姿态估计（见姿态估计）。

在端到端策略中。VLA与WAM的基本结构和模仿学习策略往往不显式输出抓取位姿，而是直接输出动作序列（见动作表示：离散token、连续动作与动作块）；但在工业分拣、仓储等需要高可靠性的场景，显式的抓取检测加运动规划仍是主流（见任务与运动规划（TAMP））。抓住之后的精细操作见灵巧手与灵巧操作。

例子

桌上一个马克杯。平面抓取只能从上方捏住杯口边缘；6自由度抓取可以选择“从侧面水平伸入、夹住杯把”，位姿为位置(0.42, −0.10, 0.08)米、绕竖直轴转30°、夹爪宽度4厘米。若已知杯子模型，6D位姿估计给出杯子的位置和朝向（杯把朝哪边），预先在模型上标注好的“抓杯把”姿势就能直接换算到当前场景。（数字为示意）

容易误解的地方

  • 抓取检测网络预测的“成功率”通常只考虑能否拿起，不考虑后续任务：能拿起不等于拿起后方便倒水或放进柜子。
  • 对称物体（如瓶子绕轴旋转看起来一样）的6D位姿本身就有歧义，评测和训练损失都需要专门处理对称性。
