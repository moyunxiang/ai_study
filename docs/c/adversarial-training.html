对抗训练

Adversarial Training

也叫：GAN　生成对抗网络　对抗生成　判别器　discriminator　生成器　minimax博弈

在交互版中打开（看它长在树上的哪里）

让两个网络互相博弈来训练：生成器努力造出以假乱真的样本，判别器努力分辨真假，双方在对抗中一起变强。

先要会：生成建模的目标 逻辑回归 梯度下降

直接最大化似然需要能写出并计算p(x)，这对图像很难。2014年的生成对抗网络GAN换了个思路：不写出p(x)，而是请一个裁判来告诉生成器“像不像”。

两个角色。生成器G把随机噪声z（例如100维高斯向量）变成一张图G(z)；判别器D输入一张图，输出它是真图的概率D(x)∈(0,1)，本质是一个二分类器，见逻辑回归。目标函数是一个极小极大博弈：

min_G max_D E_x[log D(x)] + E_z[log(1 − D(G(z)))]

D想让这个值变大（真图打高分、假图打低分）；G想让它变小（让D给假图打高分）。训练时两者交替做梯度下降：更新几步D，再更新一步G，G的梯度要穿过D反传回来。

为什么有效。可以证明，对固定的G，最优判别器是D*(x) = p_data(x) / (p_data(x) + p_g(x))；代入后G优化的是两个分布之间的JS散度。当生成分布等于真实分布时，D处处只能输出0.5，博弈达到均衡。

实际的麻烦。训练常常不稳定：D太强时G的梯度消失；两者可能来回振荡不收敛；G还可能只学会少数几种样本，即模式坍塌与模式覆盖。后续大量工作都在修补这些问题：Wasserstein GAN把JS散度换成Wasserstein距离，谱归一化限制判别器的变化幅度，StyleGAN改进生成器结构。

今天在哪里。纯GAN在大规模文生图上已被扩散模型取代，但“对抗损失”作为一个部件仍到处在用：HiFi-GAN等声码器、VQGAN等图像分词器都靠判别器让输出更锐利，对抗扩散蒸馏SDXL Turbo用对抗损失把扩散模型蒸馏成一两步生成。

例子

某一步里，判别器对一张真图输出D(x)=0.9，对一张假图输出D(G(z))=0.2。判别器的目标值为log 0.9 + log(1 − 0.2) = −0.105 − 0.223 = −0.329，它要把这个数往0推。若生成器已经完美，D只能处处输出0.5，目标值为2·log 0.5 = −log 4 ≈ −1.386，这正是理论上的均衡值。

为什么实践中生成器改用−log D(G(z))做损失：训练初期假图很假，D(G(z))≈0.01。原损失log(1 − D)对D的导数是−1/(1 − D) ≈ −1.01，几乎没有信号；改后−log D的导数是−1/D = −100，梯度大了约100倍。

容易误解的地方

  • “对抗训练”在另一个语境里指对抗样本训练：给输入加人眼看不出的扰动去攻击分类器，再把这些样本加进训练以提高鲁棒性。两者都来自Goodfellow，但不是一回事。
  • 判别器的损失低不代表生成器好；GAN的训练曲线很难直接解读，通常要靠FID等指标或直接看样本。
  • GAN没有显式似然，不能直接用来评估某个样本的概率。
