特征选择

Feature Selection

也叫：特征选择　feature selection　变量选择　variable selection　过滤式　filter method　包裹式　wrapper method　嵌入式特征选择　embedded method　递归特征消除　RFE　recursive feature elimination　前向选择　forward selection　后向消除　backward elimination　特征重要度　feature importance　置换重要度　permutation importance　卡方检验　chi-squared test

在交互版中打开（看它长在树上的哪里）

从众多输入特征中挑出真正有用的一部分。三类做法：过滤式先按统计量打分，包裹式反复训练模型试子集，嵌入式在训练中自动选（如L1正则、树模型的特征重要度）。

先要会：监督学习 正则化与权重衰减

表格数据常有成百上千列：用户画像、传感器读数、基因表达量。很多列与目标无关，或者彼此高度重复。把它们全部丢给模型，会增加过拟合风险（见维度灾难）、拖慢训练，还让模型难以解释。特征选择保留原始特征中的一个子集；它与降维与PCA不同，后者（如PCA）构造新的组合特征。

过滤式。不依赖具体模型，先给每个特征单独打分，再按分数取前k个或设阈值：

  • 方差：几乎不变的特征（比如99.9%都是0）没有信息量；
  • 与目标的相关系数（见协方差矩阵）、卡方检验；
  • 互信息：能捕捉非线性关系，例如决策树里的信息增益（见联合熵、条件熵与信息增益）。

速度快，但只看单个特征，会漏掉“单独没用、组合起来有用”的特征，也去不掉彼此冗余的特征。

包裹式。把特征子集的选择当作搜索问题，用模型在验证集上的表现评价每个子集。前向选择从空集开始每次加入最有用的一个；后向消除从全集开始每次删掉最没用的一个；递归特征消除（RFE）反复训练模型、删掉权重最小的特征。效果通常最好，但要训练很多次模型，代价高，且容易在验证集上过拟合（见多重比较与统计功效）。

嵌入式。选择发生在训练过程中：

  • L1正则（Lasso与L1稀疏）把不重要特征的权重直接压成0（见正则化与权重衰减）；
  • 树模型（随机森林、XGBoost）在训练中自然给出每个特征被用于分裂带来的增益，或用打乱某列后性能下降多少（置换重要度）来衡量。

和可解释性的关系。SHAP、LIME等方法解释的是“对某个预测，各特征贡献了多少”，常被用来辅助特征选择，但它们回答的是关于模型的问题，不一定反映特征与目标之间的因果关系（见因果推断：相关、混杂与干预）。

在深度学习里。端到端的网络自己学习表示（见特征与表示学习），通常不做手工特征选择；但在表格数据、医学和金融等需要可解释、特征获取有成本的场景中，它仍是标准步骤。

例子

预测房价有5个特征：面积、卧室数、房屋编号、面积（平方英尺）、楼层。房屋编号与价格无关，方差过滤留下它、但相关性过滤会去掉；“面积（平方英尺）”与“面积”完全相关，单特征打分时两者都很高，只有包裹式或嵌入式方法（L1会只保留其中一个）能发现它是冗余的。

容易误解的地方

  • 特征选择必须只在训练集上做（包括交叉验证的每一折内部）。先在全部数据上挑出与标签最相关的特征再做交叉验证，是经典的数据泄漏，见数据泄漏与基准污染。
  • 高度相关的一组特征里，L1和树模型会近乎随机地挑一个，重要度数字因此不稳定，不能直接解读为“另一个没用”。
