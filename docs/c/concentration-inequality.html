集中不等式：马尔可夫、切比雪夫与Hoeffding

Concentration Inequalities

也叫：集中不等式　concentration inequality　concentration inequalities　马尔可夫不等式　Markov's inequality　切比雪夫不等式　Chebyshev's inequality　Hoeffding不等式　Hoeffding's inequality　Hoeffding　Chernoff界　Chernoff bound　Bernstein不等式　联合界　union bound　尾概率界　tail bound

在交互版中打开（看它长在树上的哪里）

给“样本平均离真实期望有多远”一个有限样本的概率上界：马尔可夫、切比雪夫、Hoeffding一个比一个紧。老虎机的UCB、PAC学习的样本量都由它推出。

先要会：期望与方差 大数定律与中心极限定理

大数定律与中心极限定理说样本平均最终会收敛，中心极限定理说n大时误差近似正态。但算法分析需要的是非渐近的保证：“只有n个样本时，偏差超过ε的概率最多是多少？”集中不等式回答这个问题。

马尔可夫不等式。X非负时，P(X ≥ a) ≤ E[X] / a。只用到均值，很松，但它是其他不等式的起点。例如平均分为20分，那么得分达到100分以上的人最多占20%。

切比雪夫不等式。对X − μ的平方用马尔可夫：

P(|X − μ| ≥ kσ) ≤ 1/k²

不管分布如何，偏离均值3个标准差以上的概率不超过1/9。

Hoeffding不等式。若X₁, …, X_n独立且都在[a, b]之间，样本平均X̄满足

P(|X̄ − μ| ≥ ε) ≤ 2·exp(−2nε² / (b − a)²)

概率随n指数下降，比切比雪夫的1/n紧得多。反过来解出需要的样本数：要让误差以至少1 − δ的概率不超过ε，n大约要(b − a)²·ln(2/δ) / (2ε²)。Bernstein、Chernoff等不等式在额外知道方差或分布形状时给出更紧的界。

它们出现在哪里。

  • UCB1：每个臂的置信上界均值 + √(2 ln t / n_i)正是从Hoeffding不等式推出的，“试得少的臂不确定性大，值得多试”，见探索与利用。
  • PAC学习与VC维与一致收敛：对一个假设，Hoeffding说训练误差与真实误差接近；再对整个假设空间取联合界，就得到“样本数足够多时，所有假设的训练误差都接近测试误差”，这是泛化理论的基本推理链（见泛化与过拟合）。
  • 评测：准确率是[0, 1]之间变量的平均，用Hoeffding可以算出要多少道题才能把误差控制在给定范围内（通常比基于正态近似的区间更保守，见置信区间、标准误与误差棒）。

例子

想估计模型的准确率，要求误差不超过±2个百分点的概率至少95%（ε = 0.02，δ = 0.05，b − a = 1）：n ≥ ln(40) / (2 × 0.0004) ≈ 3.69 / 0.0008 ≈ 4600道题。用切比雪夫（方差最多0.25）则需要n ≥ 0.25 / (0.05 × 0.0004) = 12500道。

容易误解的地方

  • Hoeffding要求变量有界且相互独立；无界或强相关的数据要换用其他工具。
  • 这些界对所有分布都成立，所以往往偏保守；实际误差通常比界小得多，界“松”不代表算法差。
