生成质量指标：IS与FID

Inception Score and FID

也叫：Fréchet Inception Distance　图像生成评测　Inception分数　FD　CLIP score　生成模型评测

在交互版中打开（看它长在树上的哪里）

用一个预训练图像分类网络给生成图片打分：IS看生成图是否各自清晰可辨且种类多样，FID比较生成图与真实图在特征空间中的分布距离，越低越好。

先要会：KL散度 高斯分布 生成建模的目标

生成模型（见生成建模的目标）的目标是让生成样本的分布接近真实数据分布。可这个分布的概率密度一般算不出来，也没有“标准答案”可以逐张比对。让人看图打分最直接，但成本高、主观、难以复现。2016年前后，GAN研究急需一个自动指标来比较方法，于是出现了借用现成分类网络的两种做法。

Inception Score（IS）（GAN训练技巧与IS，2016）。把生成图x送进在ImageNet上训练好的Inception网络，得到类别分布p(y|x)。好的生成器应满足两点：每张图都清楚地像某一类（p(y|x)很尖）；所有图合起来覆盖很多类（边缘分布p(y) = E_x p(y|x)很平）。两者的差距用KL散度衡量：

IS = exp( E_x KL( p(y|x) ‖ p(y) ) )

IS越高越好，最小为1，最大等于类别数（1000）。它的问题是完全不看真实数据：生成器只要每类产出一张很像的图就能得高分。

Fréchet Inception Distance（FID）（FID与Inception Score，2017）。把大量真实图和生成图都送进Inception网络，取最后一层池化后的2048维特征，分别拟合一个多维高斯分布（均值μ、协方差Σ，见协方差矩阵），然后计算两个高斯之间的Fréchet距离：

FID = ‖μ_r − μ_g‖² + Tr( Σ_r + Σ_g − 2(Σ_r Σ_g)^(1/2) )

FID越低越好，0表示两组特征的均值和协方差完全一样。它同时惩罚质量差（均值偏）和多样性不足（协方差小，即模式坍塌与模式覆盖），比IS更可靠，成了图像生成的头号指标。

它出现在哪里：从BigGAN、StyleGAN到扩散模型扩散超越GAN，图像生成论文几乎都报告FID（常用5万张生成图计算），IS作为补充。文生图模型还会加上衡量图文是否对得上的CLIP分数，视频生成则有专门的VBench视频生成评测。

例子

IS的两个极端（3个类别）：三张生成图的分类结果分别是(1,0,0)、(0,1,0)、(0,0,1)，每张都确定、合起来均匀，边缘分布为(1/3,1/3,1/3)，每张的KL都是log 3，IS = 3（满分）。如果三张都是(1,0,0)，边缘分布也是(1,0,0)，KL = 0，IS = 1（最差）。

FID的一维版本：特征只有1维时公式化为(μ_r − μ_g)² + (σ_r − σ_g)²。真实特征μ = 0、σ = 1，生成特征μ = 0.5、σ = 0.8，FID = 0.25 + 0.04 = 0.29。

容易误解的地方

  • FID依赖样本数，样本少时偏高；不同论文的FID只有在相同样本数、相同实现、相同参考集下才可比。
  • 两者都依赖在ImageNet上训练的Inception网络，对人脸、医学图像等与ImageNet差别大的领域，特征未必反映人眼感受到的质量。
  • FID低不代表每张图都好，也不能判断模型是否只是记住了训练图。
