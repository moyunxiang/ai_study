互信息

Mutual Information

也叫：MI　PMI　点互信息　pointwise mutual information　信息增益　information gain

在交互版中打开（看它长在树上的哪里）

知道Y之后，X的不确定性减少了多少。互信息为0表示两者独立，越大表示两者共享的信息越多。它是表示学习和对比学习背后常用的目标。

先要会：信息量与熵 KL散度 条件概率与贝叶斯公式

相关系数只能衡量线性关系，而我们常常想知道更一般的问题：一张图片的表示里保留了多少关于类别的信息？一个词出现在另一个词旁边是否不是偶然？语音特征里有多少关于说话内容的信息？互信息用熵的语言回答“两个变量共享多少信息”，不论关系是否线性。

定义。

I(X; Y) = H(X) − H(X | Y)

即X原有的不确定性减去知道Y后剩下的不确定性。它是对称的，I(X; Y) = I(Y; X)，并且等价于联合分布与“假设独立时的分布”之间的KL散度：

I(X; Y) = KL(p(x, y) ‖ p(x) p(y))

所以I ≥ 0，当且仅当X与Y独立时为0。

点互信息（PMI）。只看一对具体取值：PMI(x, y) = log p(x, y) / (p(x) p(y))。PMI > 0表示x和y一起出现得比偶然更频繁。互信息是PMI在联合分布下的期望。

高维时难以计算。图像、句子这类高维变量的互信息几乎无法直接算，实际中优化的是它的下界。对比学习的InfoNCE损失就是一个下界：在N个候选中挑出正确配对，I ≥ log N − L_InfoNCE。

它出现在哪里。互信息与词语搭配用PMI发现固定搭配，后来word2vec即隐式矩阵分解证明word2vec在隐式地分解PMI矩阵；最大互信息训练MMI在语音识别中用最大互信息准则做区分性训练；InfoGAN最大化部分隐变量与生成图像之间的互信息，让隐变量变得可解释；对比预测编码CPC提出InfoNCE，用最大化互信息下界来学习表示，见对比学习；信息瓶颈则主张好的表示应在保留与标签的互信息的同时压缩与输入的互信息。

例子

X、Y都是0/1变量，联合分布为P(0,0) = 0.4、P(1,1) = 0.4、P(0,1) = P(1,0) = 0.1。边缘分布都是(0.5, 0.5)，所以H(X) = 1比特。已知Y后，X与Y相同的概率是0.8，H(X | Y) = H(0.8, 0.2) ≈ 0.722比特，于是I(X; Y) ≈ 0.278比特。用KL形式验证：2×0.4×log₂(0.4/0.25) + 2×0.1×log₂(0.1/0.25) ≈ 0.543 − 0.264 = 0.278。这对(0,0)的PMI是log₂1.6 ≈ 0.678比特，为正，说明它们比偶然更常一起出现。

容易误解的地方

  • 互信息对任何可逆变换都不变，所以“互信息大”不代表表示好用：把输入原封不动地加密，互信息不变，但下游很难使用。
  • InfoNCE估计值不会超过log N，批里的负样本数N限制了能估计到的互信息上限。
