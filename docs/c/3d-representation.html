三维表示：体素、点云、网格、隐式场

3D Representations

也叫：point cloud　voxel　mesh　SDF

在交互版中打开（看它长在树上的哪里）

在计算机里描述三维形状和场景的几种方式：体素、点云、网格、隐式场（如SDF、NeRF）以及3D高斯。各自在存储、精度、能否渲染和能否用神经网络处理上有不同取舍。

先要会：相机模型与多视图几何 向量、矩阵与张量 多层感知机

图像有统一的表示：像素网格。三维数据却没有。选哪种表示，决定了能用什么网络、要多少内存、能不能方便地渲染成图片。理解这几种表示，才能看懂三维视觉和三维生成论文在争论什么。

体素。把空间切成三维格子，每格记录“有没有东西”或颜色，就是图像像素的三维版，能直接用三维卷积，如VoxNet。缺点是内存随分辨率的三次方增长，而且大多数格子是空的。

点云。一组三维坐标点{(x, y, z)}，可附带颜色或法向。激光雷达和深度相机直接输出点云。它没有固定顺序，网络必须对点的排列不敏感，PointNet用逐点共享的多层感知机加最大池化解决了这一点。缺点是没有表面信息，点之间的连接关系要另外推断。

网格。顶点加三角面片，是游戏和影视的标准格式，渲染快、表面明确。但拓扑（有几个洞、面怎么连接）不固定，神经网络很难直接生成。

隐式场。用一个函数描述形状：输入空间坐标，输出该点的属性。符号距离函数（SDF）输出到表面的距离，外正内负，表面就是f(x)=0的位置，如DeepSDF；占据网络输出该点在物体内部的概率。NeRF输出每点的密度σ和颜色，沿着相机射线积分渲染出图像：C = Σ_i T_i·(1 − exp(−σ_i·δ_i))·c_i，T_i是光线到达第i个采样点前未被挡住的比例。隐式场分辨率不受限、内存小，但渲染时要对每条射线采样很多点，较慢。

3D高斯。3D高斯泼溅用几十万到几百万个带颜色和透明度的三维高斯椭球表示场景，可以直接投影到屏幕上快速光栅化，兼顾了质量和速度，成为新视角合成的主流。

这些表示经常相互转换：例如从SDF用Marching Cubes算法提取网格。相机投影关系见相机模型与多视图几何。

例子

几种表示的规模感：

  • 体素：256³的格子有16,777,216个，每格用一个float32就占64MiB；分辨率升到512³，格子数变为134,217,728个，内存涨8倍。
  • 点云：10万个点，每点3个float32坐标，约1.2MB。
  • 网格：一个最简单的立方体只需8个顶点、12个三角形。
  • SDF：半径为1的球可以写成f(x) = ‖x‖ − 1。点(0, 0, 2)处f=1，在球外，离表面1；原点处f=−1，在球内；点(1, 1, 1)处f = √3 − 1 ≈ 0.732，在球外。整个形状只用一个公式（或一个小网络的参数）表示。

容易误解的地方

  • “隐式”指形状藏在函数里，要通过查询才能得到表面，不是说它不精确。
  • NeRF学到的是“看起来对”的辐射场，不保证几何准确；需要可用于测量或物理仿真的表面时，通常还要额外提取和清理网格。
  • 三维数据集远比图像少，许多三维生成方法因此借助二维图像模型的先验，如DreamFusion文本生成3D。
