对比学习

Contrastive Learning

也叫：对比损失　contrastive loss　InfoNCE　正负样本　负样本　SimCLR　孪生网络

在交互版中打开（看它长在树上的哪里）

不预测标签，而是让模型学会“哪些样本应该相近、哪些应该远离”：把同一事物的不同视图在表示空间中拉近，把不同事物推远。

先要会：自监督学习 内积与余弦相似度 Softmax与logits 交叉熵

自监督学习学习需要从数据本身构造训练信号。对图像来说，逐像素地重建很费力，而且模型会把容量花在无关紧要的细节上。对比学习换了一个目标：不要求重建，只要求区分。

基本设定：对每个样本（称为锚点q），准备一个正样本k⁺——它与q来自同一事物，比如同一张图的另一种随机裁剪，或与图片配对的那句文字描述；再准备若干负样本——其他事物。训练让编码器把q与k⁺的表示拉近，与负样本推远。

InfoNCE损失是最常用的形式。用内积与余弦相似度（通常先归一化成余弦相似度）sim衡量相似度，温度为τ：

L = −log [ exp(sim(q, k⁺)/τ) / Σ_j exp(sim(q, k_j)/τ) ]

分母对正样本和全部负样本求和。这其实就是一个Softmax与logits分类加交叉熵：让模型在一堆候选里认出哪个是自己的正样本。负样本越多，任务越难，学到的表示通常越好。

发展脉络：对比损失（2006）提出了拉近相似对、推开不相似对的损失；噪声对比估计NCE和对比预测编码CPC发展出InfoNCE；视觉中MoCo用一个队列存储大量负样本，SimCLR用大批量和强数据增强，把自监督的ImageNet线性评估精度推近了有监督水平。CLIP把对比学习用在4亿对图文上，批大小达到32768，让文本与图像共享同一个嵌入向量空间。后来BYOL等方法发现，在一定设计下甚至可以不用负样本。

例子

锚点与正样本的余弦相似度为0.8，与两个负样本的相似度为0.2和0.1。

  • τ = 0.1：三个logit为8、2、1，正样本的softmax概率 ≈ 0.997，损失 ≈ 0.0034。
  • τ = 1：logit为0.8、0.2、0.1，正样本概率 ≈ 0.489，损失 ≈ 0.716。

同样的相似度，温度越低，正负样本的差距被放得越大。SimCLR中批大小为N时，每张图生成两个视图，共2N个，每个视图有1个正样本和2N − 2个负样本。

容易误解的地方

  • 负样本里可能混有其实同类的样本（同一批里恰好有两张狗的照片），对比损失会错误地把它们推开。
  • 数据增强决定了模型学到哪些不变性：如果增强里有颜色抖动，模型就会被训练成对颜色不敏感，这对需要颜色信息的任务未必合适。
