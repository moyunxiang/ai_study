扩散模型强化学习

Reinforcement Learning for Diffusion and Flow Models

也叫：扩散模型强化学习　Diffusion RL　视觉强化学习　Visual RL　RLHF for Diffusion　文生图RLHF　奖励微调　Reward Fine-tuning　GRPO for Diffusion　Flow-GRPO　DanceGRPO　Diffusion-DPO　偏好对齐　Preference Alignment　奖励模型　Reward Model

在交互版中打开（看它长在树上的哪里）

像对齐大语言模型一样，用奖励模型或人类偏好对扩散、流模型做后训练，让图片和视频更美、更听话。

文生图、视频模型的预训练目标是拟合数据，不直接优化“好看”“符合提示”。这条线借用了LLM后训练（人类反馈强化学习）的方法。

扩散模型强化学习DDPO把去噪过程看成多步决策，用策略梯度优化ImageReward、美学分等奖励；Diffusion-DPO把DPO直接偏好优化搬到扩散模型，直接用偏好对训练。2025年GRPO在LLM推理上大获成功后，Flow-GRPO和DanceGRPO几乎同时把它用到流模型：同一提示生成一组样本，组内标准化奖励作优势，并把确定性ODE采样改成SDE以获得概率；GenEval等指标大幅提升，视频模型的运动质量也显著改善。DiffusionNFT前向过程RL进一步绕开似然，直接在前向过程的流匹配损失里用正负样本对比，官方称效率高至多25倍。

主要问题是奖励钻空子：模型会学会迎合奖励模型的偏好（过饱和、千篇一律），多个奖励之间此消彼长；GenEval这类基准也可能被刷满。
