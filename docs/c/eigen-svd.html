特征分解与奇异值分解

Eigendecomposition and SVD

也叫：特征值　特征向量　eigenvalue　eigenvector　矩阵分解

在交互版中打开（看它长在树上的哪里）

特征分解找出矩阵只做拉伸、不改方向的那些方向；奇异值分解把任意矩阵拆成“旋转—按轴缩放—旋转”，并按重要性给出每个方向的强度。

先要会：矩阵乘法与线性变换

一个矩阵作用在向量上，一般会同时改变方向和长度，很难直观看出它“在做什么”。但对很多矩阵来说，存在几个特殊方向：沿这些方向的向量只被拉伸或压缩。找到这些方向，矩阵的行为就一目了然，数据里最主要的变化方向也就找到了。

特征分解。对方阵A，若

A v = λ v（v ≠ 0）

则v是特征向量，λ是对应的特征值：A在方向v上只做了λ倍缩放。实对称矩阵（如协方差矩阵）一定能写成A = Q Λ Qᵀ，Q的列是两两正交的特征向量，Λ是特征值组成的对角阵。

奇异值分解（SVD）。特征分解只对方阵、且常常只对对称阵好用。SVD对任意m×n矩阵都成立：

A = U Σ Vᵀ

U和V是正交矩阵（相当于旋转或反射），Σ是对角阵，对角线上的奇异值σ_1 ≥ σ_2 ≥ … ≥ 0。奇异值是AᵀA特征值的平方根。几何上：先用Vᵀ转到一组新坐标轴，沿每根轴按σ_i缩放，再用U转出去。奇异值越大，那个方向越重要；只保留前几个，就得到最好的低秩近似近似。

它出现在哪里。主成分分析PCA取数据协方差矩阵最大特征值对应的特征向量作为主成分，见降维与PCA；特征脸Eigenfaces把人脸图片投影到这些主成分上做识别；潜在语义分析LSA对“词—文档”矩阵做SVD，得到最早的一批词向量；PageRank与Google搜索的网页排名是链接矩阵最大特征值对应的特征向量。在深度学习里，权重矩阵的奇异值也常被用来分析训练是否稳定，谱归一化就是用最大奇异值约束网络。

例子

A = [[2, 1], [1, 2]]。取v = (1, 1)：Av = (3, 3) = 3v，特征值3；取v = (1, −1)：Av = (1, −1)，特征值1。所以A的作用是：沿对角线方向拉伸3倍，沿反对角线方向不变。再看非对称矩阵B = [[3, 0], [4, 5]]：BᵀB = [[25, 20], [20, 25]]，其特征值为45和5，于是B的奇异值是√45 ≈ 6.708和√5 ≈ 2.236。

容易误解的地方

  • 非对称矩阵的特征值可能是复数，特征向量也不一定正交；SVD没有这些麻烦，所以实际计算中更常用SVD。
  • 特征向量只确定方向，长度和正负号可以任意，不同软件算出的结果可能差一个符号，这不是bug。
