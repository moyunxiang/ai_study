条件概率与贝叶斯公式

Conditional Probability and Bayes' Rule

也叫：贝叶斯定理　Bayes' theorem　后验概率

在交互版中打开（看它长在树上的哪里）

条件概率是“已知B发生时A的概率”；贝叶斯公式告诉我们如何根据新证据，把先前的信念更新成新的信念。

先要会：随机变量与概率分布

AI的很多任务都是“看到证据，推断原因”：听到一段声音，推断说的是哪句话；看到一封邮件里的词，推断它是不是垃圾邮件。我们手里通常更容易得到的是反方向的知识，比如“垃圾邮件里出现‘中奖’的概率”。贝叶斯公式就是把这两个方向连起来的桥梁。

条件概率。

P(A | B) = P(A, B) / P(B)

含义：只看B发生的那些情形，其中A也发生的比例。由此得到乘法规则P(A, B) = P(A | B) P(B)，以及链式展开P(x_1, …, x_n) = P(x_1) P(x_2 | x_1) … P(x_n | x_1, …, x_{n−1})。语言模型正是按这个展开逐词建模的，见自回归生成。

贝叶斯公式。

P(A | B) = P(B | A) P(A) / P(B)

其中P(A)是看到证据之前的先验，P(B | A)是似然（假设A成立时观察到B的可能性），P(A | B)是后验，分母P(B) = Σ_A P(B | A) P(A)保证后验加起来为1。

它出现在哪里。朴素贝叶斯分类用贝叶斯公式做文本分类；统计语音识别和IBM统计翻译模型机器翻译都建立在“噪声信道”公式上：要找的句子W使P(W | 声音) ∝ P(声音 | W) P(W)最大，前者由声学模型或翻译模型给出，后者由语言模型给出，见噪声信道与词对齐；贝叶斯网络与概率图模型把大量变量之间的条件概率组织成图，见概率图模型。把贝叶斯公式用在模型参数上，就是先验、后验与贝叶斯推断。

例子

某种疾病患病率1%。检测的灵敏度为99%（患者检测为阳性的概率），假阳性率为5%。某人检测为阳性，真的患病的概率是多少？P(阳性) = 0.01×0.99 + 0.99×0.05 = 0.0099 + 0.0495 = 0.0594，所以P(患病 | 阳性) = 0.0099 / 0.0594 ≈ 0.167。只有约17%：因为健康的人太多，即使假阳性率不高，假阳性的绝对数量也远多于真阳性。

容易误解的地方

  • P(A | B)和P(B | A)通常差别很大，混淆二者是最常见的概率错误（上例中前者约17%，后者是99%）。
  • 先验影响很大：同样的证据，在先验极低时得到的后验也可能很低。
