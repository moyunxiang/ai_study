分数函数与分数匹配

Score Function and Score Matching

也叫：得分函数　score-based model　∇log p　去噪分数匹配

在交互版中打开（看它长在树上的哪里）

分数是对数概率密度对输入的梯度∇ₓlog p(x)，在每个点指向概率增加最快的方向。学会它就能沿着它走、从噪声走到数据，而且不用算归一化常数。

先要会：导数、偏导与梯度 高斯分布 能量模型与玻尔兹曼分布

想写出一张图的概率p(x)，最大的障碍是归一化常数：若用能量模型与玻尔兹曼分布模型写成p(x) = exp(−E(x)) / Z，Z要对所有可能的图像积分，根本算不出来。但如果只要梯度，Z就消失了：

s(x) = ∇ₓ log p(x) = −∇ₓ E(x)（log Z是常数，求导为0）

这个向量场叫分数（score）。注意它是对输入x求导，不是对参数求导，见导数、偏导与梯度。它在每个点指向“更像真实数据”的方向：在概率高的区域附近指向峰顶，在空旷区域指向最近的数据团。

有了分数怎么采样。用朗之万动力学：沿分数走一小步，再加一点噪声，反复迭代：

x ← x + η·s(x) + √(2η)·z，z ~ N(0, I)

步长η足够小、步数足够多时，x的分布收敛到p(x)。噪声项防止所有点都挤到同一个峰顶上。

怎么学分数（分数匹配）。真实分数未知，不能直接回归。分数匹配估计证明可以换一个不含真实分数的等价目标；去噪分数匹配给出更实用的版本：给数据加噪声x̃ = x + σ·ε，被加噪分布的分数恰好是−(x̃ − x)/σ² = −ε/σ。于是训练一个网络s_θ(x̃)去拟合−ε/σ就行——估计分数等于预测噪声，两者只差一个系数：ε_θ = −σ·s_θ。

它在哪里。分数匹配生成模型（NCSN）在多个噪声尺度上学分数，再用朗之万采样生成图像；Score SDE统一框架证明DDPM和分数模型是同一个框架在不同噪声安排下的特例，从此扩散模型和分数模型合流，见扩散：前向加噪与反向去噪与常微分方程与随机微分方程。条件生成里的引导也是在分数上做加法，见条件生成与引导。

例子

标准高斯p(x)=N(0,1)：log p(x) = −x²/2 + 常数，所以s(x) = −x。在x=2处分数为−2，指向原点（峰顶）；在x=−1处分数为+1，同样指向原点。

朗之万一步：x=2，η=0.1，抽到z=0.3，则x ← 2 + 0.1×(−2) + √0.2×0.3 = 2 − 0.2 + 0.134 ≈ 1.934，向峰顶靠近了一点，还带点随机。

去噪分数匹配：真实x=1.0，σ=0.5，抽到ε=0.4，加噪得x̃=1.2。训练目标−(1.2−1.0)/0.25 = −0.8，也等于−ε/σ = −0.4/0.5 = −0.8。

容易误解的地方

  • 统计学里的score function常指对数似然对参数的梯度；这里是对数据的梯度，名字相同含义不同。
  • 在数据稀少的低密度区域，学到的分数很不准，这正是NCSN要在多个噪声尺度上学的原因：加大噪声能把数据“摊开”，填满空旷区域。
  • 分数决定分布只到一个常数为止，所以分数模型本身不直接给出归一化的概率。
