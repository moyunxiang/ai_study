数据划分：分层、分组与按时间划分

Data Splitting: Stratified, Grouped and Temporal

怎样把数据切成训练集和测试集，决定了分数能否代表真实表现。除随机划分外，常用分层抽样（保持类别比例）、分组划分（同一用户不跨集合）和按时间划分。

先要会：训练集、验证集与测试集 独立、条件独立与独立同分布

训练集、验证集与测试集讲了为什么要留出验证集和测试集。但“怎么切”同样重要：测试集应该模拟模型将来真正面对的数据。切法不对，分数就会偏乐观，而且很难察觉。

随机划分。打乱后按比例切开。前提是样本之间近似独立、条件独立与独立同分布，且数据量足够大。

分层抽样（stratified split）。按类别分组，在每一组内按同样比例抽样，保证训练集和测试集的类别比例与总体一致。类别不均衡或数据很少时尤其重要：1000个样本里只有20个正例，随机切出200个测试样本，正例可能只有1个、也可能有8个，评测结果的波动会非常大（见类别不平衡与长尾）。交叉验证时对应地用分层k折。

分组划分（group split）。同一个病人的多张片子、同一段视频的多帧、同一篇文章的多道题、同一个用户的多条记录，彼此高度相关。如果它们同时出现在训练集和测试集里，模型可以靠“认人”而不是学会任务来答对，这是一种数据泄漏（见数据泄漏与基准污染）。正确做法是按组划分：同一组的样本只能整体落入同一边。

按时间划分。时间序列预测、推荐、金融、新闻等场景里，模型上线后面对的是未来的数据。随机划分会让模型用“明天的信息”预测“今天”，分数虚高。应该用某个时间点之前的数据训练、之后的数据测试；交叉验证改为“滚动窗口”或“扩展窗口”：每一折都只用之前的数据训练、预测紧接着的下一段。大模型评测也有类似问题：用模型知识截止日期之后才出现的题目来测，才能避免基准污染。

按分布外划分。有意让测试集来自不同的医院、地区或领域，以测量模型面对分布偏移时的稳健性，例如WILDS分布偏移。ImageNetV2：榜单过拟合了吗按原流程重新收集了一份测试集，模型准确率普遍下降了约11到14个百分点，说明即使“同分布”的重新采样也可能暴露问题。

交叉验证。数据少时不固定一个测试集，而是轮流用每一份做验证（见交叉验证）。上面的分层、分组、时间约束在交叉验证中同样要遵守，scikit-learn提供了StratifiedKFold、GroupKFold、TimeSeriesSplit等工具。

例子

某医疗数据集有100个病人、每人10张片子。随机按片子划分，测试准确率95%；改为按病人划分（80个病人训练、20个测试），准确率降到81%，因为前者里同一病人的其他片子已在训练集中，模型学会了识别“这个病人”。（数字为示意）

容易误解的地方

  • 先做特征缩放、过采样或特征选择再划分，等于让测试集参与了训练；划分必须是第一步。
  • 按时间划分时，验证集也要放在训练集之后、测试集之前，否则调参阶段就已经泄漏了未来信息。
