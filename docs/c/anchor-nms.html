锚框与非极大值抑制

Anchors and Non-Maximum Suppression

也叫：anchor　NMS　anchor box　anchor-free　先验框

在交互版中打开（看它长在树上的哪里）

目标检测的两个传统部件：锚框是预先铺满图像的一批参考框，网络只需预测相对它们的偏移；非极大值抑制则删掉指向同一物体的重复框。

先要会：分类、检测、分割 IoU与mAP

目标检测（见分类、检测、分割）要输出数量不定的框，每个框有位置、大小和类别。直接让网络“吐出若干个框”很难训练：输出个数不固定，也不知道哪个输出该对应哪个物体。2015年前后的方案是把问题改写成对固定候选集合的分类与回归。

锚框（anchor）：在特征图的每个位置放几个预设的框，覆盖不同尺度和长宽比。Faster R-CNN在每个位置放9个锚框（3种尺度×3种长宽比）。网络对每个锚框预测两件事：里面是不是物体（以及是哪类），以及从锚框到真实框的偏移量(Δx, Δy, Δw, Δh)。训练时，与某个真实框IoU与mAP超过阈值（如0.7）的锚框记为正样本，低于0.3的记为负样本。SSD、YOLOv2 / YOLO9000、Focal Loss与RetinaNet都沿用了这一设计。

非极大值抑制（NMS）：一个物体周围的许多锚框都会给出高分，输出里会有一堆几乎重合的框。NMS是一个贪心后处理：

  • 按分数从高到低排序；
  • 取出分数最高的框保留，删掉与它IoU超过阈值（常用0.5）的其他框；
  • 对剩下的框重复，直到处理完。

后来的变化：锚框的尺度、比例都是手工设定的超参数，NMS的阈值在拥挤场景下顾此失彼（两个靠得很近的人可能被删成一个）。DETR把检测看成集合预测，用匈牙利匹配为每个真实框指定唯一一个预测，既不要锚框也不要NMS；YOLOv10免NMS则在YOLO系列里通过一对一匹配的训练去掉了NMS。

例子

三个预测框（左上x, 左上y, 右下x, 右下y）：A = (0,0,10,10) 分数0.9，B = (1,1,11,11) 分数0.8，C = (20,20,30,30) 分数0.7。

A和B的交集是9×9 = 81，并集100 + 100 − 81 = 119，IoU ≈ 0.68 > 0.5，B被删除。C和A不重叠，IoU = 0，保留。最终输出A和C。

锚框数量：一张约1000×600的图在Faster R-CNN里得到约60×40的特征图，乘以9个锚框，约2.2万个候选。

容易误解的地方

  • NMS阈值是一个取舍：设低了会误删相邻的真实物体，设高了会留下重复框。
  • 锚框带来严重的正负样本不平衡（绝大多数锚框是背景），Focal Loss与RetinaNet的Focal Loss就是为此设计的。
  • 免锚框（anchor-free）方法并不等于免NMS，许多免锚框检测器仍需要NMS。
