像素空间扩散

Pixel-Space Diffusion

也叫：像素空间扩散　Pixel-space Diffusion　Pixel Diffusion　无潜空间生成　Latent-free Generation　去掉VAE　x预测　x-prediction　JiT　pMF　回到像素

在交互版中打开（看它长在树上的哪里）

不用VAE压缩，直接在原始像素上做扩散或流生成，省掉编码器和解码器带来的信息损失和额外开销。

早期扩散模型本来就在像素上工作：DDPM、扩散超越GAN、Imagen、DeepFloyd IF都用像素空间加级联超分。潜空间扩散LDM把生成搬进VAE潜空间后大幅省算力，像素空间路线一度边缘化。

2025年下半年它重新被讨论。JiT像素空间x预测指出，高维像素上预测噪声或速度很难，但让网络直接预测干净图像（x预测）就能用简单的大patch Transformer训好，因为干净图像落在低维流形上。pMF像素空间一步生成把x预测与MeanFlow结合，做到一步、无潜空间生成；漂移模型Drifting的像素版也达到一步FID 1.61。这些工作强调，潜空间方法还要额外付VAE解码器的算力，并受VAE重建质量的上限约束。

不过，在文生图、视频这类大规模场景，潜空间仍是主流；像素路线能否扩展到高分辨率视频，目前没有答案。
