可交互世界模型

Interactive World Models

也叫：Interactive World Model　可玩世界模型　Playable World Model　神经游戏引擎　Neural Game Engine　实时世界模型　动作条件视频生成　Action-Conditioned Video Generation　交互视频生成

在交互版中打开（看它长在树上的哪里）

用户每输入一个动作（按键、移动、机器人指令），模型就实时生成下一帧画面，相当于用神经网络代替游戏或物理引擎。

普通视频生成一次给出一整段，不能中途干预；可交互世界模型逐帧生成，每一帧都以用户动作为条件。World Models和Dreamer在低分辨率里做过类似的事，DIAMOND扩散世界模型用扩散在Atari上做出高画质世界模型，GameNGen实时模拟了DOOM，Oasis可玩世界模型做出可玩的Minecraft。Genie从无标签视频学出可控的二维世界，Genie 2和Genie 3把它推到三维、实时、分钟级，Project Genie首次做成消费产品；开源方面Matrix-Game 2.0用自回归扩散加少步蒸馏实现25帧每秒。

这类模型对机器人的意义是当“生成式仿真器”：在里面训练、评测策略。主要问题是长时间的一致性和记忆、物理规律不保证正确，以及从游戏画面到真实物理的差距。
