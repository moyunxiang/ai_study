非自回归流匹配TTS

Non-Autoregressive Flow-Matching TTS

也叫：NAR TTS　非自回归TTS　非自回归语音合成　flow matching TTS　流匹配TTS　扩散TTS　diffusion TTS　Voicebox路线　掩码生成TTS　masked generative TTS　填空式合成

在交互版中打开（看它长在树上的哪里）

不逐个token生成，而是一次性对整段语音做去噪或填空，速度快、不易漏字，靠参考音频实现零样本克隆。

非自回归TTS从FastSpeech开始：并行生成整段梅尔谱，但需要显式时长预测。零样本时代，Voicebox用Flow Matching把TTS改成「语音填空」：给定文本和遮住一部分的语音，生成被遮住的部分，于是能克隆、编辑、去噪。NaturalSpeech 2、NaturalSpeech 3用潜空间扩散；E2 TTS进一步去掉音素对齐，直接把字符补齐到语音长度；F5-TTS用DiT加ConvNeXt让这条极简路线变得实用；MaskGCT则用掩码生成在离散token上并行解码。

优点是推理步数固定、并行快、鲁棒；难点是总时长要预先给定，流式输出不如自回归自然。现在工业系统常把两者拼起来：自回归模型出语义token，流匹配模型出声学细节（如CosyVoice）。相关概念见可逆流与流匹配与扩散：前向加噪与反向去噪。
