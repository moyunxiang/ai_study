内积与余弦相似度

Dot Product and Cosine Similarity

也叫：点积　点乘　数量积　inner product　余弦距离　cos相似度

在交互版中打开（看它长在树上的哪里）

两个向量对应位置相乘再求和得到一个数，衡量它们“指向多相近”；除以两者长度就得到与长度无关的余弦相似度。

先要会：向量、矩阵与张量

很多AI问题最后都归结为“这两个东西像不像”：这个查询和哪篇文档相关？这张图和哪句描述匹配？这个词和哪个词意思接近？当东西都表示成向量之后，最便宜、最常用的相似度就是内积。

定义。两个长度为n的向量的内积是

a · b = Σ_i a_i b_i

几何上它等于|a| |b| cos θ，θ是两个箭头的夹角。方向一致时内积大，垂直时为0，方向相反时为负。只想比较方向、不想受长度影响时，用余弦相似度：

cos(a, b) = a · b / (|a| |b|)

它的取值在−1到1之间。如果事先把向量都归一化成长度1，余弦相似度就等于内积，所以实际系统里常先归一化，再统一用内积。

为什么这么常用。内积只需n次乘法和n次加法，而且一大批内积可以写成一次矩阵乘法与线性变换，GPU算得极快。神经网络里一个神经元的计算w · x + b本身就是内积：权重向量w是一个“模板”，输入越像这个模板，输出越大。

它出现在哪里。信息检索的向量空间模型用余弦相似度比较查询和文档；word2vec用它找近义词；Transformer的注意力分数是查询向量和键向量的内积（再除以√d），见注意力机制；CLIP用图像向量与文本向量的余弦相似度做零样本分类；向量数据库按内积找最近邻，见检索与向量数据库。

例子

a = (1, 2, 3)，b = (4, 5, 6)。内积 = 1×4 + 2×5 + 3×6 = 32。长度|a| = √14 ≈ 3.742，|b| = √77 ≈ 8.775，余弦相似度 = 32 / (3.742×8.775) ≈ 0.975，两者方向非常接近。若把b换成(3, 2, 1)，内积是10，余弦相似度降到10/14 ≈ 0.714。把b换成(−1, −2, −3)，余弦相似度是−1，方向完全相反。

容易误解的地方

  • 内积会受向量长度影响：一个很长的向量和谁的内积都可能很大。比较“意思像不像”时通常应该用余弦或先归一化。
  • 高维空间里随机向量之间的余弦相似度普遍接近0，所以0.3这样的数值在高维里可能已经算相当相似，不能按低维直觉判断。
