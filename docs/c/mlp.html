多层感知机

Multilayer Perceptron

也叫：前馈网络　前馈神经网络　feedforward neural network　feed-forward network　FFN　全连接网络　fully connected network　dense network　隐藏层　hidden layer　MLP　全连接网络　前馈神经网络　feedforward network　FFN　dense layer　全连接层

在交互版中打开（看它长在树上的哪里）

把多层“线性变换 + 激活函数”首尾相接得到的网络，也叫全连接网络或前馈网络。是所有神经网络架构的基本积木。

先要会：神经元与激活函数 矩阵乘法与线性变换 损失函数

单个神经元（见神经元与激活函数）只能画出一条直线（高维时是一个超平面）作为分类边界。1969年的《Perceptrons》与XOR问题指出，单层感知机连XOR（两个输入相同输出0、不同输出1）都学不会，因为这四个点无法用一条直线分开。解决办法是在输入和输出之间加隐藏层：先把输入变换到一个新空间，在那里问题变得线性可分。

定义。一个两层的多层感知机（MLP）：

h = f(W1·x + b1) y = W2·h + b2

x是输入（长度d_in），W1是d_hidden×d_in的矩阵，h是隐藏层的激活值，W2把它映射到输出（长度d_out）。f是逐元素的非线性激活函数。层数可以继续往上叠。“全连接”指每个输出都依赖于上一层的每个输入——每层就是一次完整的矩阵乘法（见矩阵乘法与线性变换）。

为什么够用。万能近似定理证明：只要隐藏层足够宽，一个隐藏层的MLP就能以任意精度逼近任何连续函数。但这只说明“存在”这样的参数，没说能用多少神经元、能不能学出来；实践中更深而不是更宽的网络往往更省参数。

怎么训练。参数W1, b1, W2, b2一开始是随机数。给定一批数据，前向算出输出，用损失函数衡量和正确答案差多少，再用反向传播求出损失对每个参数的梯度，按梯度下降更新。1986年的反向传播让这套流程流行起来。

它在哪里出现。MLP本身擅长处理固定长度的向量输入。对于图像、序列这类有结构的数据，直接用MLP参数太多、也不利用结构，于是有了卷积层、池化与感受野和循环网络与隐状态。但MLP从未消失：CNN最后的分类头是MLP；Transformer每一层里都有一个逐位置的两层MLP（称为前馈网络FFN，见Transformer层的结构），在标准配置下它占每层参数的约三分之二。

例子

用两个隐藏神经元解决XOR。取ReLU激活：h1 = ReLU(x1 + x2)，h2 = ReLU(x1 + x2 − 1)，输出y = h1 − 2·h2。逐个验证：

  • (0, 0)：h1 = 0，h2 = 0，y = 0
  • (1, 0)：h1 = 1，h2 = 0，y = 1
  • (0, 1)：h1 = 1，h2 = 0，y = 1
  • (1, 1)：h1 = 2，h2 = 1，y = 2 − 2 = 0

单层做不到的事，加一层非线性隐藏层就做到了。

参数量。识别28×28手写数字的MLP：784 → 256 → 10。第一层权重784×256 = 200,704个，加256个偏置；第二层256×10 = 2,560个，加10个偏置；共203,530个参数。

容易误解的地方

  • “多层感知机”里的感知机是历史名称，现代MLP用的是可求导的激活函数，不是感知机那种阶跃函数。
  • 万能近似定理常被误读成“MLP什么都能学”。它不保证梯度下降能找到这组参数，也不保证从有限数据中泛化。
  • MLP对输入的排列没有任何先验：把图像像素打乱后训练，效果几乎一样。这正说明它没有利用图像的空间结构。
