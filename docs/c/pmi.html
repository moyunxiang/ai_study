点互信息与PPMI

Pointwise Mutual Information and PPMI

也叫：PMI　pointwise mutual information　点互信息　逐点互信息　PPMI　positive PMI　正点互信息　NPMI　归一化点互信息　共现矩阵　co-occurrence matrix　词共现　collocation　搭配　SPPMI　shifted PMI

衡量两个词一起出现的次数比偶然预期多多少：PMI = log P(x,y)/(P(x)P(y))，PPMI把负值截为0。它是搭配发现和共现矩阵词向量的基础。

先要会：互信息 随机变量与概率分布

“纽约”和“时报”经常一起出现，“的”和“时报”也经常一起出现。但后者只是因为“的”到处都是。要判断两个词是否真的相关，不能只看共现次数，要和“如果它们毫无关系，按各自频率会偶然共现多少次”比较。点互信息（pointwise mutual information，PMI）就是这个比值的对数。

定义。

PMI(x, y) = log [ P(x, y) / (P(x) · P(y)) ]

  • 等于0：两者独立，共现次数正好是偶然水平。
  • 大于0：比偶然更常一起出现，有关联。
  • 小于0：比偶然更少一起出现。

对所有(x, y)按P(x, y)加权平均PMI，就得到互信息，所以PMI是互信息在单个事件对上的“点”版本。

PPMI。负的PMI估计很不可靠（需要大量语料才能可信地判断“两个词共现得少”），而且语言学上意义不大。所以常用正PMI：PPMI = max(PMI, 0)。

在NLP里的用法。

  • 搭配发现：互信息与词语搭配（1990）用互信息从语料中自动找出词语之间的强关联和固定搭配。
  • 共现矩阵词向量：统计每个词与上下文窗口内各词的共现次数，构成词×上下文矩阵（见分布假说），把计数换成PPMI，再用SVD降维（见特征分解与奇异值分解），就得到稠密的词向量，这与潜在语义分析LSA的做法一脉相承。
  • 与word2vec的联系：word2vec即隐式矩阵分解证明，带k个负样本的skip-gram在最优时，词向量与上下文向量的内积等于PMI(w, c) − log k，即它在隐式地分解一个移位的PMI矩阵。词向量的超参数教训进一步发现，把word2vec的一些超参数技巧移植到PPMI+SVD上，传统方法与神经方法的差距很小。GloVe的目标函数也直接建立在共现统计上。

缺点。PMI偏爱低频词：一个只出现过一次的生僻词，只要恰好与某词共现一次，PMI就会很高。常见修正是对上下文概率做平滑（如把上下文频率取0.75次方），或设置最低频率阈值。

例子

一份100万词的语料（按窗口统计共现，示意数字）：

  • P(纽约) = 0.0001，P(时报) = 0.0002，P(纽约, 时报) = 0.00001。PMI = log₂(0.00001 / (0.0001 × 0.0002)) = log₂(500) ≈ 9.0，强关联。
  • P(的) = 0.05，P(的, 时报) = 0.00001。PMI = log₂(0.00001 / (0.05 × 0.0002)) = log₂(1) = 0，与偶然水平相同。

两对的共现概率都是0.00001，PMI却差了9个比特。

容易误解的地方

  • PMI的绝对值依赖语料规模和上下文窗口大小，不同设置下的数值不可比；需要可比的分数时可以用归一化PMI（NPMI），取值在−1到1之间。
  • 低频词对的PMI估计方差很大，排序时容易被它们霸占前列。
