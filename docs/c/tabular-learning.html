表格数据学习

Machine Learning on Tabular Data

也叫：表格数据　Tabular Data　Tabular ML　结构化数据　Structured Data　GBDT　梯度提升树　树模型　Kaggle表格赛　表格基础模型　Tabular Foundation Model　TabPFN　深度学习vs树模型

在交互版中打开（看它长在树上的哪里）

行是样本、列是特征的表格是工业界最常见的数据形式；长期以来梯度提升树最强，最近表格基础模型开始挑战它。

表格数据的特征异质（数值、类别混杂）、样本量常常不大，深度学习的优势不明显。决策树CART决策树之后，随机森林和梯度提升机GBM成为主力，XGBoost、LightGBM、CatBoost让梯度提升树在速度、类别特征处理上不断改进，长期统治数据竞赛和工业预测。

转折来自TabPFN表格基础模型：它在数百万个合成表格任务上预训练一个Transformer，使用时一次前向就给出预测，在最多约一万样本的数据上全面超过调参后的树模型集成。现在的问题是这种“表格基础模型”能否扩展到更大的数据，以及在真实业务数据上是否稳定优于树模型。
