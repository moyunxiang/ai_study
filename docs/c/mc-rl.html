强化学习中的蒙特卡洛方法

Monte Carlo Methods in RL

也叫：蒙特卡洛方法　Monte Carlo methods　MC方法　蒙特卡洛控制　Monte Carlo control　蒙特卡洛预测　Monte Carlo prediction　first-visit MC　首次访问　首次访问蒙特卡洛　every-visit MC　每次访问　探索性起点　exploring starts　备份图　backup diagram　MC vs TD

不用环境模型、也不自举：把整局玩完，用实际得到的回报的平均值来估计价值。无偏但方差大，而且必须等回合结束才能更新。

先要会：蒙特卡洛采样 奖励、回报与折扣 策略与价值函数

策略评估、策略迭代与价值迭代要求知道转移概率，现实中通常不知道。最直接的替代办法是：反正能玩，就多玩几局，看看从某个状态出发实际能拿多少回报，取平均。这就是强化学习里的蒙特卡洛方法（名字来自蒙特卡洛采样采样）。

蒙特卡洛预测。估计V^π(s)：按π玩很多回合，每当经过s，记下从那一刻到回合结束的回报G，V(s)取这些G的平均，或者增量地更新V(s) ← V(s) + α·(G − V(s))。一个回合里可能多次经过同一状态：

  • 首次访问（first-visit MC）：每回合只用第一次经过s之后的回报。
  • 每次访问（every-visit MC）：每次经过都算一个样本。

两者在访问次数趋于无穷时都收敛到V^π。

蒙特卡洛控制。没有模型时，只有V不够（不知道哪个动作通向好状态），要估计Q(s, a)，再对Q取贪心，形成策略评估、策略迭代与价值迭代式的循环。难点是贪心策略不会去试其他动作，需要保证探索：要么假设每个回合从随机的(s, a)出发（探索性起点），要么让策略始终保持一点随机，如ε-贪心与玻尔兹曼探索。也可以用另一个策略采样、用重要性采样修正，得到离策略蒙特卡洛。

与TD的对比。蒙特卡洛的目标G是真实回报，对V^π无偏；但G累加了整局所有步的随机性，方差大，而且要等回合结束，不能用于持续任务。时序差分与自举用r + γV(s')代替G，可以每步更新、方差小，但依赖当前估计因而有偏。在《Reinforcement Learning: An Introduction》的备份图里，蒙特卡洛的备份一路画到回合终点，TD只画一步。n步回报与多步TD和资格迹与TD(λ)介于两者之间。REINFORCE策略梯度本质上就是用蒙特卡洛回报的策略梯度。

例子

γ=1，一个回合依次经过 s, x, s, y，奖励依次为 1, 0, 2, 3（每步之后获得）。第一次经过s之后的回报是1+0+2+3=6，第二次是2+3=5。首次访问只记一个样本6；每次访问记两个样本6和5，平均5.5。若之前V(s)=4、α=0.1，首次访问的更新为4 + 0.1×(6 − 4) = 4.2。

容易误解的地方

  • 蒙特卡洛的“无偏”只针对评估当前策略而言；做控制时策略在变化，整体并不保证无偏。
  • 回合很长时（几千步）回报方差极大，纯蒙特卡洛几乎学不动，这是深度RL普遍使用TD或GAE的原因。
