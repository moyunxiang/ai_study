系统辨识

System Identification

也叫：系统辨识　system identification　sysid　SysID　参数辨识　parameter identification　动力学辨识　dynamics identification　电机建模　actuator model　执行器网络　actuator network　激励轨迹　excitation trajectory

在交互版中打开（看它长在树上的哪里）

用实测的输入输出数据估计系统模型的参数：给机器人施加已知的激励，记录响应，反推质量、摩擦、电机特性、延迟等。它是精确控制和缩小仿真到现实差距的基础。

先要会：机器人动力学与运动方程 线性回归

机器人动力学与运动方程的方程形式是知道的，但里面的参数往往不知道或不准：装上夹爪后质心变了，减速器的摩擦随温度变化，电机的实际力矩与指令之间有延迟和饱和。控制器和仿真器用的模型参数不对，控制就会抖动或迟钝，仿真里练好的策略到真机上就失效。系统辨识就是从数据中把这些参数估出来。

基本流程。

  • 选模型结构：物理模型（运动方程中的惯量、摩擦系数），或者通用模型（线性状态空间模型、神经网络）。
  • 设计激励：让系统充分“动起来”，覆盖关心的频率和工作范围，例如让关节按多个频率叠加的正弦轨迹运动。激励不充分时，有些参数根本无法从数据中区分。
  • 估计参数：最小化模型预测与实测之间的误差。机械臂的运动方程对惯量参数是线性的，可以写成τ = Y(q, q̇, q̈)·θ，用最小二乘直接求解（见线性回归）。
  • 验证：在没用于拟合的数据上检查预测精度。

在机器人学习中的用法。

  • 缩小仿真差距：先辨识真实机器人的电机和延迟特性，再写进仿真器。四足敏捷步态Sim2Real为四足机器人建立了精确的电机模型，再结合随机化，把仿真中学到的步态迁移到真机；见仿真到现实的差距。
  • 与域随机化互补：辨识给出参数的最佳估计，域随机化与Sim2Real在估计值周围随机化以覆盖剩余的不确定性。
  • 在线辨识与自适应：让策略在运行中根据最近的历史隐式推断环境参数，例如联合训练一个估计器（策略与估计器联合训练）。
  • 用学习代替解析模型：直接用神经网络拟合动力学，就是基于模型的强化学习和世界模型；从数据中找出简洁的方程形式，见SINDy稀疏方程发现。

例子

辨识一个关节的黏性摩擦系数b：让关节以多个恒定速度转动，测得维持速度所需的力矩。速度为1、2、3弧度/秒时，力矩分别为0.32、0.61、0.89牛·米。按τ = τ_c + b·q̇做线性拟合，得b ≈ 0.285牛·米·秒/弧度，库仑摩擦τ_c ≈ 0.04牛·米。

容易误解的地方

  • 参数可辨识性：有些参数组合对数据的影响完全相同（例如某些惯量项），无论数据多少都只能辨识出它们的组合。
  • 辨识出的模型只在激励覆盖的范围内可靠，在高速或大负载等没测过的工况下可能误差很大。
