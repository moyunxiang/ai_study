Softmax and Logits

也叫：logit　归一化指数函数　softmax函数　温度　temperature　概率归一化　多分类输出

在交互版中打开（看它长在树上的哪里）

把一组任意实数变成一个概率分布：全部为正、加起来等于1，而且原来越大的数分到的概率越大。

先要会：随机变量与概率分布 向量、矩阵与张量

分类模型的最后一层会给每个类别输出一个实数分数，这组分数叫logits，可正可负，大小没有上限。要把它们解释成概率，需要一个函数满足三点：输出都大于0、总和为1、保持大小顺序。Softmax就是这样一个函数：

softmax(z)_i = exp(z_i) / Σ_j exp(z_j)

先取指数（保证为正，并且放大差距），再除以总和（保证加起来为1）。

为什么用指数而不是直接除以总和：直接归一化处理不了负数；而指数函数配合交叉熵损失求导后形式特别简单——对logit的梯度恰好是“预测概率减去真实标签”，这让训练很稳定。从概率角度看，softmax也正是逻辑回归在多类别情形下的推广。

温度。实际使用时常写成softmax(z / T)。T小于1会让分布更尖锐（几乎只选最大的），T大于1会更平缓（各个选项概率接近）。语言模型生成文本时调的temperature就是这个T，见解码：贪心、束搜索、温度与top-p。

它出现在哪里。一是分类器和语言模型的输出层，把logits变成“下一个词是什么”的概率。二是注意力机制内部，把相关性分数变成加权平均用的权重。两处的作用一样：把一组分数变成一组和为1的权重。

例子

三个类别的logits为 [2.0, 1.0, 0.1]。取指数得 [7.39, 2.72, 1.11]，总和11.22，于是概率为 [0.66, 0.24, 0.10]。把温度设为0.5（等价于logits乘2），概率变成 [0.86, 0.12, 0.02]，更确定；设为2，变成 [0.50, 0.30, 0.19]，更平均。

容易误解的地方

  • Softmax输出的“概率”只是归一化后的分数，不代表模型真的有这么大把握；神经网络常常过度自信。
  • 直接按公式写代码，logit很大时exp会溢出。实际实现都会先减去最大值，或直接使用log_softmax。
  • 名字里的soft是相对argmax说的：argmax只给最大者1、其余0；softmax是它的平滑、可求导的版本。
