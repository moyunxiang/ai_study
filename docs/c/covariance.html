协方差矩阵

Covariance Matrix

也叫：相关系数　correlation　协方差阵　多元高斯

在交互版中打开（看它长在树上的哪里）

描述多个随机变量如何一起变化的矩阵：对角线是各自的方差，非对角线衡量两两之间同增同减的程度。

先要会：期望与方差 向量、矩阵与张量

期望与方差里的方差只描述一个量的波动。但数据通常是多维的：身高和体重、相邻像素、词向量的各个维度。我们还想知道它们是否一起变化——身高高的人体重是否也大？协方差回答这个问题：

Cov(X, Y) = E[(X − μ_X)(Y − μ_Y)]

同增同减时为正，此消彼长时为负，无线性关系时接近0。除以两者标准差得到相关系数，范围在−1到1之间。

对d维随机向量x，把所有两两协方差排成d×d矩阵，就是协方差矩阵Σ = E[(x − μ)(x − μ)ᵀ]。它对称、半正定；有n个样本时，用中心化后的数据矩阵X算Σ̂ = XᵀX / (n − 1)。

几何意义：对Σ做特征分解与奇异值分解，特征向量是数据伸展的主方向，特征值是该方向上的方差。这正是主成分分析PCA（见降维与PCA）：保留特征值最大的几个方向。多元高斯分布的形状完全由均值和协方差决定，等概率面是以特征向量为轴的椭球。

在AI里的出现：

  • 卡尔曼滤波用协方差矩阵表示状态估计的不确定性，每步预测时变大、观测后变小。
  • EWC弹性权重巩固、自然梯度等方法用到的费雪信息矩阵，本质上是梯度的协方差。
  • FID与Inception Score把真实图像和生成图像的特征各自拟合成高斯，比较两者的均值和协方差。
  • 归一化层、白化、初始化分析都在关心激活值的协方差结构，见归一化层。

例子

5个样本：x = [1, 2, 3, 4, 5]，y = [2, 1, 4, 3, 5]，两者均值都是3。

Var(x) = (4+1+0+1+4)/4 = 2.5，Var(y) = (1+4+1+0+4)/4 = 2.5，Cov(x, y) = (2+2+0+0+4)/4 = 2.0。协方差矩阵第一行为(2.5, 2.0)、第二行为(2.0, 2.5)，相关系数2.0/2.5 = 0.8。

它的特征值是4.5和0.5：沿(1,1)方向方差4.5，沿(1,−1)方向只有0.5，数据基本沿对角线分布。

容易误解的地方

  • 协方差为0只说明没有线性关系，不说明独立；y = x²在对称分布上协方差就是0。
  • 维度d接近或超过样本数n时，样本协方差矩阵不可逆、估计很不稳定，常要加对角正则。
  • 协方差的数值依赖单位，比较强弱要看相关系数。
