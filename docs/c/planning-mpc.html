规划与模型预测控制

Planning and Model Predictive Control

也叫：MPC　运动规划　motion planning　轨迹优化　trajectory optimization　滚动时域

在交互版中打开（看它长在树上的哪里）

规划是在行动之前，用一个能预测后果的模型比较多种动作序列，选出最好的；模型预测控制（MPC）每一步都重新规划未来一小段，只执行第一个动作，然后再规划。

先要会：世界模型 控制回路与控制频率

策略网络是“条件反射”：看到观测，直接输出动作。但遇到没见过的情况，或任务需要提前几步考虑（先绕开障碍再抓），只靠反射容易出错。另一种思路是：手里有一个能预测“这样做会怎样”的模型（物理方程或学到的世界模型），行动前先在模型里试一试。

规划的一般形式。给定当前状态s₀、模型f和代价函数c，求未来H步的动作序列：

min over a₀…a_{H−1} Σ_{t=0}^{H−1} c(s_t, a_t)，其中 s_{t+1} = f(s_t, a_t)

离散问题可以用图搜索（A*搜索），连续空间的路径可以用随机采样的RRT快速随机树、PRM概率路图，棋类可以用博弈树搜索：minimax与MCTS。

模型预测控制（MPC）。模型总有误差，现实也有扰动，一次规划到底注定会偏。模型预测控制MPC的做法是滚动时域：每个控制周期都从当前真实状态出发，规划未来H步，只执行第一步，下一周期拿到新观测再重新规划。这样模型误差只影响很短的未来，并不断被真实反馈纠正。它在化工、自动驾驶、足式机器人中被广泛使用；当模型是线性、代价是二次时，问题有解析解，就是LQR最优控制。

用学到的模型做MPC。当模型是神经网络时，常用采样优化：随机生成很多条动作序列，用模型预测每条的结果，挑出最好的若干条，用它们的均值和方差重新采样，重复几轮，这叫交叉熵方法（CEM）。PlaNet在学到的隐空间里用CEM规划；TD-MPC把规划和学到的价值函数结合，用价值函数估计H步之后的长期回报；V-JEPA 2和DINO-WM用预训练视觉表示的世界模型规划到图像目标。MuZero则在学到的模型里做树搜索。

规划与策略的取舍。规划每一步都要大量调用模型，计算昂贵，且完全依赖模型的准确性；直接输出动作的策略推理快，但泛化有限。很多系统把两者结合：用策略给出初始方案，再用规划局部改进。

例子

PlaNet的设置：规划时域H = 12，每轮采样J = 1000条候选动作序列，保留最好的K = 100条重新拟合分布，迭代I = 10轮。于是每做一次决策，世界模型要预测10 × 1000 × 12 = 120,000步——全部在隐空间里批量并行完成，然后只执行第一个动作，下一步从头再来。

简单的滚动时域例子：小车在x = 0，目标在x = 10，每步最多走1。规划5步得到[1, 1, 1, 1, 1]，执行第一个后到达x = 0.9（地面打滑），下一步从0.9重新规划，而不是盲目执行剩下的4步。

容易误解的地方

  • MPC的效果上限是模型的准确性：模型错了，规划会自信地找到一个在模型里很好、在现实里不可行的方案（利用模型漏洞）。
  • 时域太短看不到长期后果，太长则计算量和模型误差都会暴涨，常用价值函数估计时域之外的部分。
  • 规划不等于“推理慢”：线性MPC在机器人上可以每秒运行数百次。
