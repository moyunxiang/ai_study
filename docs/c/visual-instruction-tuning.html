视觉指令微调

Visual Instruction Tuning

也叫：多模态指令微调　Multimodal Instruction Tuning　视觉SFT　LLaVA式训练　两阶段训练　图文指令数据

在交互版中打开（看它长在树上的哪里）

用“图片+指令+回答”格式的数据微调多模态模型，让它学会按人的要求看图回答，而不只是写图片描述。

LLaVA的关键贡献是数据：用只读文字的GPT-4，根据图片的描述和框标注生成多轮对话、细节描述和推理问答，得到十几万条视觉指令数据。训练分两阶段：先只训连接层把图文对齐，再用指令数据微调连接层和语言模型。指令微调与对话模板由此从纯文本推广到多模态。

InstructBLIP把几十个学术数据集改写成指令格式，MiniGPT-4发现少量高质量描述数据就能明显改善输出，LLaVA-1.5加入带简短答案格式提示的学术VQA数据，成为后来大多数开源VLM的基线配方。用文本模型合成的数据也带来幻觉问题，于是出现在指令微调之后再做偏好对齐的工作（LLaVA-RLHF事实增强）。今天的趋势是指令数据越来越多由强VLM自己生成，并在之后接强化学习。
