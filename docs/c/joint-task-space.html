关节空间、任务空间与构型空间

Joint Space, Task Space and Configuration Space

也叫：关节空间　joint space　构型空间　configuration space　C-space　C空间　任务空间　task space　笛卡尔空间　Cartesian space　操作空间　operational space　末端执行器　end effector　end-effector　末端空间　雅可比矩阵（机器人）　robot Jacobian　奇异位形　singularity　冗余机械臂　零空间　逆运动学　inverse kinematics　IK　逆运动学求解　IK solver

描述机器人状态的两种坐标：关节空间（构型空间）用每个关节的角度，任务空间（笛卡尔空间、操作空间）用末端执行器的位置和朝向。二者由正/逆运动学和雅可比矩阵联系，控制、规划和动作表示都要选在其中一个里做。

先要会：自由度、运动学与本体感知 位姿与齐次变换SE(3)

对一台7轴机械臂，可以用两种方式说“它现在在哪”：7个关节角，或者夹爪在空间中的位姿。两种描述各有用处，机器人论文里的“joint space action”“end-effector control”“C-space planning”说的就是这件事。

关节空间与构型空间。机器人所有关节变量组成的向量q称为构型，所有可能构型的集合叫构型空间（C-space），维数等于自由度数（见自由度、运动学与本体感知）。在关节空间里，限位、速度和力矩约束都很直接，底层电机控制也在这里进行。

任务空间。末端执行器（夹爪、工具）的位姿x，通常6维（见位姿与齐次变换SE(3)），也叫笛卡尔空间或操作空间。任务本身（“把杯子移到这里”）通常在任务空间里描述。

两者的联系。

  • 正运动学x = f(q)：唯一、易算，见DH参数。
  • 逆运动学q = f⁻¹(x)：可能无解、有多解或无穷多解。
  • 雅可比矩阵：速度之间的线性关系ẋ = J(q)·q̇，J是6×n矩阵（见雅可比矩阵与海森矩阵）；力的关系为τ = Jᵀ·F。J降秩时机器人处于奇异位形（例如手臂完全伸直），某些方向无论关节怎么转末端都动不了，逆运动学在附近会要求极大的关节速度。
  • 冗余：n大于6时，J有零空间，可以在不改变末端位姿的情况下调整手肘位置来避障。

控制与规划在哪里做。操作空间控制OSC提出直接在任务空间设计控制律，再经雅可比映射到关节力矩。运动规划常在构型空间进行：把障碍物映射成C-space中的禁区，路径就是C-space里的一条曲线，RRT快速随机树和PRM概率路图都在这个空间里采样，见规划与模型预测控制。

对机器人学习的影响。策略输出关节目标还是末端位姿增量，会影响学习难度和跨机器人迁移：末端空间的动作更直观、更容易在不同形态的机械臂间共享，但需要可靠的逆运动学和对奇异位形的处理，见动作表示：离散token、连续动作与动作块。

例子

平面两连杆臂（两段各长1米），关节空间是(θ₁, θ₂)，任务空间是末端位置(x, y)。在θ₂=0（手臂伸直）时，末端到原点的距离恒为2，此时沿径向的速度ẋ无论关节怎么动都是0，雅可比降秩，这就是奇异位形。末端位置(1, 1)对应两组关节角：(θ₁=90°, θ₂=−90°)和(θ₁=0°, θ₂=90°)，即“肘上”和“肘下”两种逆运动学解。

容易误解的地方

  • 任务空间里的一条直线路径，映射到关节空间可能穿过奇异点或超出关节限位；反之关节空间的线性插值，末端走的一般是曲线。
  • 构型空间的维数随自由度增加，人形机器人有几十维，规划和学习的难度都随之增长。
