上采样与转置卷积

Upsampling and Transposed Convolution

也叫：转置卷积　transposed convolution　反卷积　deconvolution　上卷积　up-convolution　上采样　upsampling　双线性插值　bilinear interpolation　最近邻插值　像素重排　pixel shuffle　子像素卷积　sub-pixel convolution　棋盘格伪影　checkerboard artifacts

让特征图变大的几种办法：插值（最近邻、双线性）后再卷积，可学习的转置卷积（常被误称为反卷积），以及把通道重排成空间的像素重排。分割、生成、超分辨率网络的解码器都靠它们。

先要会：卷积层、池化与感受野 步长、填充与特征图尺寸 矩阵乘法与线性变换

分类网络一路把分辨率降下去（见步长、填充与特征图尺寸），最后只要一个类别。但语义分割要给每个像素一个标签，生成模型和超分辨率要输出完整的图像，自编码器的解码器要把小特征图还原成原尺寸，都需要上采样。

插值。最简单的办法：最近邻（每个像素复制成2×2）或双线性插值，不含参数，然后接一个普通卷积去学习细节。很多现代网络（包括扩散模型常用的U-Net实现）都用“插值+卷积”。

转置卷积（transposed convolution）。可学习的上采样。普通卷积可以写成一个矩阵乘法y = C·x（输出比输入小）；转置卷积用这个矩阵的转置Cᵀ作用于输入，形状正好反过来，输出比输入大。直观做法：在输入像素之间插入s−1个0，再做普通卷积。输出尺寸为

out = (in − 1)·s − 2p + k（另加可选的输出填充）

全卷积网络FCN用它把分割网络的粗糙输出放大回原图；DCGAN的生成器靠一串转置卷积把小特征图逐步放大成64×64的图像；U-Net原文中称之为“上卷积”。

名字的混淆。它常被叫作“反卷积”（deconvolution），但它并不是卷积的逆运算（信号处理里的反卷积是另一回事），只是形状上相反。DeconvNet反卷积分割等早期文献中两种用法都有，读的时候要分清。

棋盘格伪影。当卷积核大小不能被步长整除时（例如k=3、s=2），输出中有的位置被重叠覆盖的次数多、有的少，生成的图像会出现规则的棋盘格纹理。改用“插值+卷积”或选k为s的倍数可以避免。

像素重排（pixel shuffle）。先用普通卷积把通道数扩大r²倍，再把每r²个通道重排成r×r的空间块，常用于超分辨率，既高效又没有棋盘格问题。

例子

输入4×4，转置卷积k=4、s=2、p=1：输出边长(4 − 1)×2 − 2 + 4 = 8，正好放大2倍。若用k=3、s=2、p=1，输出为3×2 − 2 + 3 = 7，通常需要再加1的输出填充才能得到8，并且k=3不能被s=2整除，容易出现棋盘格。

容易误解的地方

  • 转置卷积不能恢复下采样时丢掉的信息，只是学一个合理的放大方式；细节通常还要靠跳跃连接从编码器补回来。
  • 同样的k、s、p，普通卷积和转置卷积的尺寸公式不同，不要套错。
