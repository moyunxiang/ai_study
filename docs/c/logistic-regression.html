逻辑回归

Logistic Regression

也叫：LR　对数几率回归　逻辑斯蒂回归　sigmoid分类　logit模型　二分类

在交互版中打开（看它长在树上的哪里）

用线性函数算出一个分数，再经过sigmoid函数压到0到1之间，作为“属于正类”的概率；用交叉熵损失训练。它是最基本的二分类模型。

先要会：线性回归 交叉熵 随机变量与概率分布

分类问题的答案是“是/否”，我们希望模型给出一个概率，比如“这封邮件有92%的可能是垃圾邮件”。直接用线性回归输出不行：线性函数的值可以是任何实数，可能是−3或5，不是概率。

逻辑回归先算线性分数，再用sigmoid函数把它压到(0, 1)：

z = w · x + b，p = σ(z) = 1 / (1 + e^(−z))

z = 0时p = 0.5；z越大p越接近1，越小越接近0。z也叫logit，它等于对数几率log(p / (1 − p))，所以模型实际上是在说：正类的对数几率是输入的线性函数。决策边界w · x + b = 0是一个超平面，所以逻辑回归是线性分类器。

训练：用二元交叉熵作损失，

ℓ = −[y·log p + (1 − y)·log(1 − p)]

这等价于对伯努利分布做最大似然估计。它对w的梯度有一个漂亮的形式：(p − y)·x，即“预测概率减去真实标签”再乘以输入。这个损失是凸的，梯度下降能找到全局最优。

多分类：把sigmoid换成Softmax与logits，就是多项逻辑回归。

它在AI里的位置：神经网络分类器的最后一层就是一个逻辑回归（或softmax回归），前面所有层的作用是学一个好的特征与表示学习。逻辑回归本身作为逻辑回归节点出现在1958年（Cox），后来在文本分类、广告点击率预测等工业场景中长期是主力；它也是判别模型与生成模型中判别模型的标准代表，常与朴素贝叶斯分类对照。

例子

一维输入，参数w = 2，b = −1。对x = 1.5：z = 2×1.5 − 1 = 2，p = 1/(1 + e⁻²) ≈ 0.881。

如果真实标签y = 1，损失 = −ln 0.881 ≈ 0.127；对w的梯度 = (0.881 − 1)×1.5 ≈ −0.179，为负，所以梯度下降会把w调大，让p更接近1。

容易误解的地方

  • 名字里有“回归”，但它是分类模型；“回归”指的是对对数几率做线性回归。
  • 两类数据完全线性可分时，为了让概率逼近0和1，权重会无限增大，需要正则化才能得到有限解。
