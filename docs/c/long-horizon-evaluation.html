长时任务评测

Long-Horizon Task Evaluation

也叫：时间跨度　任务时长　50%时间跨度　time horizon　task horizon　METR曲线　长程任务　长时程智能体　long-horizon agents　每7个月翻倍　能独立干多久

在交互版中打开（看它长在树上的哪里）

不问模型答对多少道题，而问它能独立完成人类需要多长时间的任务，并跟踪这个时长随模型更新怎样增长。

当选择题失去区分度，METR提出用人类完成任务所需的时间来度量难度：在HCAST、RE-Bench等任务上同时记录人类专家用时和模型成功率，拟合出模型有50%把握完成的任务时长。METR任务时间跨度报告这个时长大约每7个月翻一倍，METR时间跨度1.1更新了任务集和估计。

同一思路在其他基准里以不同形式出现：Vending-Bench让智能体长期经营自动售货机，测它能否在几百上千步里保持连贯；Terminal-Bench 2.0与Harbor、OSWorld 2.0和APEX-Agents职业任务把单个任务拉长到小时级、数百次工具调用；远程劳动指数RLI直接用真实外包项目。争论点包括：时长换算依赖人类基线的选取，软件类任务占比过高，50%成功率的标准对实际可靠使用来说太低。
