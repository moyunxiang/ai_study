图像块与视觉token

Patches and Visual Tokens

也叫：patch　visual token　patch embedding　ViT　切块

在交互版中打开（看它长在树上的哪里）

把图像切成固定大小的小方块（如16×16像素），每块展平后线性映射成一个向量，当作一个“词”。这样图像就变成一串token，可以直接交给Transformer处理。

先要会：图像作为张量 嵌入向量 自注意力与多头注意力 分词与token

Transformer在文本上大获成功，它的输入是一串token。想把它用到图像上，就得先回答：图像的“token”是什么？一个像素当一个token不行——224×224的图有5万多个像素，自注意力与多头注意力的计算量随token数平方增长，根本算不动；单个像素本身也几乎没有意义。

切块。Vision Transformer的做法很直接：把图像切成不重叠的P×P小块（patch），每块展平成一个长向量，再乘一个可学习的矩阵映射到D维，得到一个嵌入向量。这一步等价于一个卷积核大小和步长都为P的卷积。再给每块加上位置编码，让模型知道这块在图上的位置；分类时通常额外加一个可学习的[CLS] token，用它的输出来做预测。

块大小的取舍。块越小，token越多，细节越好，但注意力的计算量按token数的平方增长。分辨率翻倍，token数变成4倍，注意力计算变成16倍。所以有Swin Transformer这样只在局部窗口内做注意力的设计，也有NaViT任意分辨率这样支持任意分辨率和长宽比的打包方法。

视觉token在哪里出现。

  • 自监督预训练：掩码自编码器MAE随机遮住75%的块，让模型根据剩下的块重建被遮的部分，见掩码建模。
  • 图文模型：CLIP的图像编码器就是ViT；LLaVA等多模态大模型把ViT输出的块向量经过一个投影层，直接插入语言模型的token序列里。
  • 生成模型：扩散Transformer在潜空间里切块；离散的“视觉token”则来自向量量化与离散token，两者都叫token，但前者是连续向量，后者是码本编号。

例子

ViT-B/16处理224×224×3的图：16×16的块，每边切224/16 = 14块，共14×14 = 196块。每块展平为16×16×3 = 768个数，线性映射到768维（ViT-Base的隐藏维度恰好也是768），加上[CLS]共197个token。

把分辨率提高到448×448：块数变为28×28 = 784，是原来的4倍；注意力矩阵的元素数是784²对196²，变成16倍。

多模态的例子：LLaVA-1.5用336×336输入、14×14块的CLIP ViT-L/14，每张图得到24×24 = 576个视觉token，在语言模型里占576个位置。

容易误解的地方

  • 图像块不是语义单位：一块可能只包含半只眼睛，也可能是一大片天空；“视觉token”与文字token的信息密度差别很大。
  • ViT缺少卷积那种“局部性、平移不变”的归纳偏置，数据少时往往不如CNN，需要大数据或强正则，见归纳偏置。
  • 论文里的“/16”“/14”指块边长，不是模型层数。
