准确率、精确率、召回率与F1

Accuracy, Precision, Recall, F1

也叫：F1分数　查准率　查全率　混淆矩阵

在交互版中打开（看它长在树上的哪里）

评价分类器的基本指标：准确率看总体答对比例，精确率看“说是的里面有多少真是”，召回率看“真是的里面找出了多少”，F1是两者的调和平均。

先要会：监督学习 随机变量与概率分布

最直观的指标是准确率（accuracy）：答对的样本占全部样本的比例。但当类别很不均衡时它会骗人：1000封邮件里只有10封垃圾邮件，一个永远回答“不是垃圾邮件”的分类器准确率就有99%，却毫无用处。我们需要分开看模型在“正类”上的表现。

以二分类为例，把预测和真实情况交叉，得到四个数，合称混淆矩阵：

  • TP（真正例）：真是正类，预测也是正类
  • FP（假正例）：真是负类，却预测成正类（误报）
  • FN（假负例）：真是正类，却预测成负类（漏报）
  • TN（真负例）：真是负类，预测也是负类

由此定义：

准确率 = (TP + TN) / 全部 精确率 P = TP / (TP + FP)（预测为正的里面有多少是对的） 召回率 R = TP / (TP + FN)（真正的正类里找回了多少） F1 = 2PR / (P + R)

精确率和召回率通常此消彼长：分类器一般输出一个分数，再和阈值比较。阈值调高，只有很有把握的才判为正，精确率升、召回率降；阈值调低则相反。把所有阈值下的(R, P)连成曲线就是PR曲线，曲线下面积称为平均精度（AP）。F1用调和平均而不是算术平均，是为了惩罚偏科：P = 1、R = 0.01时算术平均约0.5，F1只有约0.02。

多类别时，可以对每个类别各算一个F1再取平均（macro，每类同等重要），也可以把所有类的TP、FP、FN加总后再算（micro，大类权重更大）。

它出现在哪里：信息检索、垃圾邮件过滤、医学筛查（漏诊代价高，更看重召回）；目标检测的mAP就是在每个类别上算AP再平均，见IoU与mAP；阅读理解基准SQuAD用词级别的F1衡量答案与标准答案的重合度；GLUE / SuperGLUE中的部分子任务也报告F1。生成式大模型的评测大多回到准确率，但在拒答、安全过滤这类判断上，误报与漏报仍需分开看。

例子

1000封邮件中有100封垃圾邮件。分类器标出90封，其中80封确实是垃圾邮件。于是TP = 80，FP = 10，FN = 20，TN = 890。

  • 准确率 = (80 + 890) / 1000 = 97%
  • 精确率 = 80 / 90 ≈ 0.889
  • 召回率 = 80 / 100 = 0.80
  • F1 = 2 × 0.889 × 0.80 / (0.889 + 0.80) ≈ 0.842

对比：全部判为“非垃圾”的分类器准确率也有90%，但召回率为0，F1为0。

容易误解的地方

  • 类别不均衡时只报告准确率几乎没有信息量，至少要同时看精确率和召回率。
  • 精确率和召回率依赖阈值；只报一个数时要说明阈值是怎么选的。
  • macro和micro平均在类别不均衡时差别很大，比较论文数字前先确认用的是哪一种。
