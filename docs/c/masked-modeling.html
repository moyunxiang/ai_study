掩码建模

Masked Modeling

也叫：MLM　掩码语言模型　masked language model　完形填空　MAE　掩码图像建模　MIM

在交互版中打开（看它长在树上的哪里）

把输入的一部分遮住，让模型根据剩下的部分把它猜回来。不需要标注就能训练，而且被遮住的位置可以同时利用左右两侧的上下文。

先要会：自监督学习 语言模型 交叉熵 自注意力与多头注意力

从左到右的语言模型在预测第t个词时只能看前文。这对生成文本没问题，但对“理解”任务是个限制：要判断“他把银行里的钱取了出来”中“银行”的意思，后面的“取钱”和前面的内容同样重要。2018年前的做法（如ELMo）是分别训练一个从左到右和一个从右到左的模型再拼起来，两个方向在内部从不交互。

掩码建模换了一道题：不是“猜下一个”，而是“填空”。

定义（以BERT为例）。随机选出输入中15%的token作为预测目标，其中：

  • 80%替换成特殊符号[MASK]；
  • 10%替换成一个随机token；
  • 10%保持不变。

模型用不加掩码的双向自注意力与多头注意力读入整个被破坏的序列，在这些被选中的位置预测原来的token，用交叉熵作损失；其余85%的位置不计损失。之所以不全部换成[MASK]，是因为微调和使用时输入里不会出现[MASK]，要让模型对正常token也保持警惕。

这是自监督学习的典型做法：标签就是被遮掉的原始内容，任何文本都能用来训练。

推广。

  • 图像：掩码自编码器MAE把图像切成小块，遮掉75%，让模型重建被遮的像素。图像的冗余度远高于文本，所以要遮得更多题目才够难。BEiT则预测被遮图像块的离散编号。
  • 更难的遮法：SpanBERT遮连续的片段而非单个token；T5把连续片段替换成一个哨兵符号，让解码器生成被遮的内容。
  • 更高效的训练信号：ELECTRA替换词检测不再只在15%的位置上学习，而是让一个小模型先填词，大模型判断每个位置的词是否被替换过，100%的位置都有损失。
  • 用于生成：掩码扩散语言模型（掩码扩散语言模型MDLM、LLaDA大语言扩散模型）在训练时随机遮掉从0%到100%不等的比例，生成时从全部是[MASK]开始，多步逐渐把空填上，可以一次并行生成多个token。

掩码建模也可以看作自编码器中去噪自编码器的思想在离散序列上的应用。

例子

原句（已分词）：“北京 是 中国 的 首都 ，也 是 一 座 古城”。随机选中了“首都”。

  • 80%的情况，输入变成“北京 是 中国 的 [MASK] ，也 是 一 座 古城”，模型要在[MASK]处输出“首都”的高概率。注意它既用到左边的“中国 的”，也用到右边的“古城”。
  • 10%的情况，输入里的“首都”被换成随机词，比如“北京 是 中国 的 苹果 ，……”，模型仍要在这里输出“首都”。
  • 10%的情况，输入保持原样，模型在这里输出“首都”。

训练效率对比。一个512 token的序列，BERT只在约512 × 15% ≈ 77个位置上计算损失；从左到右的语言模型在全部512个位置上都有损失。这是ELECTRA想解决的问题。

容易误解的地方

  • BERT这类模型不能直接用来写文章：它没有学过从左到右逐词生成，[MASK]预测也是各位置独立做出的。
  • 遮挡比例不是越低越好或越高越好：太低题目太简单，太高上下文太少；最佳比例随数据类型差别很大（文本约15%，图像约75%）。
  • 预训练时输入里有[MASK]，下游使用时没有，这种不一致是BERT的已知缺陷之一，XLNet和ELECTRA都针对它做了改进。
