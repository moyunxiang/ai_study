学习式特征匹配

Learned Feature Matching

也叫：特征匹配　feature matching　图像匹配　image matching　关键点检测与描述　keypoint detection and description　局部特征　local features　稠密匹配　dense matching　无检测器匹配　detector-free matching

在交互版中打开（看它长在树上的哪里）

用神经网络找出两张图中对应同一三维点的像素，替代SIFT等手工特征，是三维重建、定位和SLAM的基础步骤。

手工特征时代，SIFT特征、ORB特征先检测关键点再算描述子，用最近邻匹配，在光照、视角变化大时容易失败。

学习式路线分几步走：SuperPoint用自监督训练同时学关键点和描述子；SuperGlue用图神经网络加注意力在两组关键点之间做全局推理式匹配；LightGlue让它更快且可提前停止；LoFTR不再检测关键点，用Transformer直接在稠密特征上建立对应，弱纹理区域表现更好；MASt3R把匹配建立在三维点图之上。这些匹配器常接入COLMAP等流水线。

当前趋势是前馈三维重建模型把匹配隐式地包含在网络里，独立匹配器的角色正在变化，但在大规模定位与高精度重建中仍是主力。
