数据预处理：缺失值、异常值与类别编码

Data Preprocessing

把原始数据整理成模型能用的形式：处理缺失值、修正或剔除异常值、把类别型变量编码成数字、统一尺度、去重。在表格数据上，这一步往往比换模型更影响结果。

先要会：特征缩放：标准化与归一化 独热编码与词表

真实数据很少是干净的：调查问卷有人漏填，传感器偶尔掉线读出0，“城市”一列里写着“北京”“北京市”“Beijing”，同一条记录被录入了两次。模型拿到的是什么，决定了它能学到什么。

缺失值。先弄清楚为什么缺：完全随机丢失、与其他变量有关、还是与缺失的值本身有关（例如高收入者更不愿填收入）。常见处理：

  • 删除：缺失很少时直接删掉该行或该列。
  • 填补：用均值、中位数、众数填；或用其他特征训练一个模型来预测缺失值（如k近邻填补，见k近邻）。
  • 加指示列：另加一列“这个值是否缺失”，缺失本身往往就有信息。
  • 交给模型：XGBoost、LightGBM等梯度提升树能在分裂时为缺失值自动学习一个默认方向。

异常值。先区分是录入错误（年龄200岁）还是真实但罕见的极端值。前者修正或删除；后者可以截断到某个分位数、做对数变换，或选用对离群点稳健的损失（见回归损失：MSE、MAE与Huber）。专门找异常的方法见异常检测与分布外检测。

类别型变量。模型只认数字：

  • 独热编码：每个类别一列，见独热编码与词表；类别很多（如十万个商品ID）时维度爆炸，改用嵌入向量。
  • 序数编码：有天然顺序的类别（小、中、大）映射成1、2、3。
  • 目标编码：用该类别下目标的平均值代替类别，必须在训练折内计算，否则会泄漏标签。CatBoost专门设计了按顺序计算的目标统计来避免这一点。

数值尺度。标准化、归一化、对数变换，见特征缩放：标准化与归一化。

去重与一致性。合并写法不同的同一类别，删除重复记录；训练集和测试集之间的重复样本会造成泄漏（见数据泄漏与基准污染）。

工具。pandas表格数据处理负责读写和清洗表格，scikit-learn的Pipeline把填补、编码、缩放和模型串成一个整体，保证所有统计量只从训练集学到。大模型预训练的数据清洗（去重、质量过滤）规模大得多，但道理相同，见用模型筛选预训练数据和以数据为中心的AI。

例子

一列“收入”有1000行，其中80行缺失。用中位数5.2万填补，同时新增一列“收入缺失”（80行为1）。另一列“城市”有300种取值，其中200种只出现不到5次，把它们合并成“其他”，再做独热编码，列数从300降到约101。

容易误解的地方

  • 所有预处理的统计量（均值、中位数、类别映射、目标编码）都只能在训练集上计算，再应用到验证集和测试集。
  • 用均值填补会人为缩小方差、削弱特征之间的相关性；缺失比例很高时，填补出来的值可能主导了模型的判断。
