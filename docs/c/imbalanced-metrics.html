不均衡数据的指标：平衡准确率与MCC

Metrics for Imbalanced Data: Balanced Accuracy and MCC

也叫：平衡准确率　balanced accuracy　BA　马修斯相关系数　Matthews correlation coefficient　MCC　phi系数　phi coefficient　Cohen's kappa　科恩kappa　kappa系数　宏平均F1　macro F1　macro-F1　宏平均　macro average　灵敏度　sensitivity　特异度　specificity　不均衡指标

类别不均衡时准确率会误导人，需要换用对各类“一视同仁”的指标：平衡准确率对每类的召回率取平均，MCC用混淆矩阵的全部四格算出一个−1到1之间的相关系数。

先要会：准确率、精确率、召回率与F1

1000个样本里有950个负类、50个正类，一个永远猜“负”的模型准确率95%。准确率被多数类主导（见类别不平衡与长尾）。下面这些指标能把这种“偷懒”的模型打回原形。记号沿用准确率、精确率、召回率与F1中的TP、FP、FN、TN。

平衡准确率（balanced accuracy）。对每一类分别计算召回率，再取算术平均：

BA = ½·(TP/(TP + FN) + TN/(TN + FP))

二分类时就是“灵敏度与特异度的平均”。永远猜多数类的模型，BA只有0.5，相当于瞎猜；多分类时推广为各类召回率的平均（等于宏平均召回率）。

马修斯相关系数（MCC）。

MCC = (TP·TN − FP·FN) / √((TP + FP)(TP + FN)(TN + FP)(TN + FN))

它就是把预测和真实标签都看作0/1变量后的皮尔逊相关系数（见协方差矩阵）。取值−1到1：1为完美，0相当于随机，−1为完全相反。只有四个格子都好时MCC才高，被认为是二分类最“诚实”的单一指标之一。

Cohen's kappa。把观察到的一致率与“按各自类别比例随机猜”的期望一致率比较：κ = (p_o − p_e)/(1 − p_e)。它原本用于衡量两位标注员的一致程度（见标注一致性与Cohen's kappa），也可用来评价分类器。

宏平均F1。各类F1的平均，让少数类和多数类权重相同，是多分类不均衡时最常报告的指标。

与ROC/PR曲线的关系。上面的指标都依赖一个固定的判定阈值；要评估模型在所有阈值下的排序能力，用ROC AUC或PR曲线的AP。极度不均衡时，PR曲线比ROC曲线更能反映少数类上的表现，见ROC曲线、AUC与PR曲线。

它出现在哪里。医学诊断（罕见病）、欺诈检测、缺陷检测、生物信息学的分类任务常报告平衡准确率和MCC；GLUE / SuperGLUE基准中的CoLA（语法可接受性判断）子任务就用MCC作为官方指标。

例子

950个负类、50个正类。

  • 模型A全部猜负：准确率95%，BA = ½(0 + 1) = 0.5，MCC = 0（分母为0时按惯例记为0）。
  • 模型B：TP = 40、FN = 10、FP = 60、TN = 890。准确率93%，比A还低；但BA = ½(0.80 + 0.937) ≈ 0.87，MCC = (40×890 − 60×10)/√(100×50×950×900) ≈ 35000/65383 ≈ 0.54。

容易误解的地方

  • 平衡准确率默认每类同等重要；若业务上漏报一个正例的代价远大于误报，应该直接用加权代价或在固定召回率下比较精确率。
  • MCC和kappa都对类别比例敏感，不同正类比例的数据集之间直接比较数值要小心。
