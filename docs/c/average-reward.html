平均奖励准则

Average-Reward Criterion

也叫：average reward　平均奖励　平均回报准则　average-reward RL　差分价值　differential value　增益　gain　R-learning　平均报酬

在交互版中打开（看它长在树上的哪里）

持续任务的另一种目标：不打折扣，而是最大化长期每步平均能拿多少奖励；价值函数改为衡量“比平均水平多拿多少”的差分价值。

先要会：奖励、回报与折扣 Bellman方程 时序差分与自举

对于没有终点的任务（服务器调度、库存管理、一直运行的控制系统），折扣γ其实是个不太自然的设定：它让“今天的1分”比“一年后的1分”值钱得多，而我们真正关心的往往是长期运行下每一步平均做得多好。平均奖励准则直接把这个量当作目标。

定义。策略π的平均奖励（也叫增益，gain）是

ρ(π) = lim_{T→∞} (1/T) · E_π[r₁ + r₂ + … + r_T]

在满足遍历性（从任何状态出发最终都能到达其他状态）的MDP里，这个极限与起点无关。最优策略就是ρ最大的策略。

差分价值。累计奖励本身会发散，于是把每步奖励减去平均值再累加：

v_π(s) = E_π[Σ_t (r_{t+1} − ρ(π)) | s₀ = s]

它衡量“从s出发，比长期平均多拿（或少拿）多少”。对应的Bellman方程里没有γ：v(s) = Σ_a π(a|s) Σ_{s',r} p(s',r|s,a)·[r − ρ + v(s')]。TD误差相应变成

δ = r − ρ̂ + V(s') − V(s)

ρ̂本身也用δ在线更新。最早的这类控制算法之一叫R-learning。

为什么值得知道。《Reinforcement Learning: An Introduction》第二版专门讨论了在函数逼近下折扣准则的问题：对持续任务，按状态分布平均后的折扣回报与平均奖励成正比，γ实际上不改变策略的排序，于是作者主张持续任务用平均奖励来表述。Puterman《马尔可夫决策过程》系统讲了平均奖励MDP的理论。实践中深度RL仍大多用折扣，但在排队、网络控制和一些机器人任务里平均奖励方法有其优势。与它相关的还有时域、分幕任务与终止和奖励、回报与折扣。

例子

一台机器交替给出奖励0、2、0、2、……平均奖励ρ=1。若当前处在“下一步给2”的状态A，差分价值v(A) = (2−1) + (0−1) + (2−1) + … ，按交替序列的平均取值约为0.5；处在“下一步给0”的状态B约为−0.5。两者之差1正好反映“先拿到2”比“先拿到0”领先一步的优势。

容易误解的地方

  • 平均奖励只看长期，前期的表现几乎不影响ρ；如果前期的损失很重要（比如会坏机器），单靠ρ不够。
  • 差分价值只在相差一个常数的意义下确定，不同实现之间的数值不能直接比较，比较的是差值。
