下一句预测与句序预测

Next Sentence Prediction and Sentence Order Prediction

也叫：next sentence prediction　NSP　下一句预测　下句预测　sentence order prediction　SOP　句序预测　句子顺序预测　IsNext　句子级预训练目标　sentence-level objective

在交互版中打开（看它长在树上的哪里）

BERT预训练的第二个目标：给两段文本，判断第二段是不是原文中紧跟第一段的下一段。它想让模型学到句子之间的关系，但后来的研究发现作用有限，被去掉或换成句序预测（SOP）。

先要会：掩码建模 特殊token

掩码语言模型（见掩码建模）让模型学会理解句子内部，但问答、自然语言推理（见自然语言推理与文本蕴含）这类任务需要理解两个句子之间的关系。BERT为此在预训练里加了一个句子级的二分类任务。

下一句预测（next sentence prediction，NSP）。构造输入[CLS] 段落A [SEP] 段落B [SEP]（见特殊token）：

  • 50%的情况，B是语料中紧接在A后面的那段，标签IsNext；
  • 50%的情况，B是从语料中随机抽的一段，标签NotNext。

用[CLS]位置的输出做二分类，损失与掩码语言模型的损失相加。

为什么后来被放弃。RoBERTa做了对照实验：去掉NSP、改用来自同一文档的连续长文本做输入，下游任务表现持平或更好。一种解释是，随机抽的B通常来自另一篇文档、另一个话题，模型只要判断“两段话题是否一致”就能做对，学到的主要是话题匹配，而不是连贯性；同时，用两段短文本拼接，又减少了模型看到长上下文的机会。

句序预测（sentence order prediction，SOP）。ALBERT参数共享提出改进：负样本不再是随机段落，而是把同一文档中相邻的两段交换顺序。话题完全相同，模型只能靠语篇连贯性来判断顺序（见语篇与连贯性），这个任务更难，也被报告对下游的多句任务更有帮助。

相关的句子级目标。

  • ELECTRA替换词检测用“替换词检测”取代MLM，属于token级目标，但同样是为了让每个位置都提供训练信号。
  • 对比学习式的句子目标，让同一文档的相邻句子在向量空间里接近，用于训练句向量（见句向量与文本嵌入）。
  • Skip-Thought句向量更早地用“预测前后句”学习句子表示。

今天的仅解码器大模型不再使用这类显式的句子级目标：在长文档上做下一个token预测，本身就要求模型理解句子和段落之间的关系。

例子

原文：“我今天去了超市。买了牛奶和面包。”

  • NSP正样本：A“我今天去了超市。”B“买了牛奶和面包。”→ IsNext。
  • NSP负样本：A“我今天去了超市。”B“量子力学描述微观粒子的行为。”→ NotNext。话题明显不同，很好判断。
  • SOP负样本：A“买了牛奶和面包。”B“我今天去了超市。”→ 顺序颠倒。话题一致，必须理解“先去超市再买东西”的时间顺序才能判断。

容易误解的地方

  • NSP在BERT论文自己的消融实验中对部分任务有帮助，在RoBERTa更大规模、更长输入的设置下则没有，结论依赖实验设置。
  • token_type_ids（段落A/B的标记）最初就是为这种句子对输入设计的。
