多智能体协作

Multi-Agent LLM Systems

也叫：多智能体　多智能体系统　MAS　multi-agent system　multi-agent LLM　LLM多智能体　角色扮演协作　智能体辩论　multi-agent debate　多智能体框架　agent team　智能体团队　subagent　子智能体

让多个LLM扮演不同角色、互相讨论或分工，一起完成单个模型难以做好的任务。

2023年起，多智能体成为智能体研究的热门：CAMEL角色扮演让两个模型角色扮演对话，ChatDev、MetaGPT按软件公司的岗位分工写代码，多智能体框架AutoGen把多智能体对话做成通用框架，多智能体辩论让多个模型互相反驳以提高事实性，混合智能体MoA把不同模型的回答逐层聚合。

但效果并不稳定。多智能体为何失败系统整理了多智能体系统的失败方式（职责不清、信息丢失、验证缺失等）；Anthropic的多智能体研究系统之争表明多智能体在可并行的检索类任务上收益明显，但token开销是单智能体的数倍。2026年的编码实践里，并行智能体团队用多个并行的Claude合作完成大项目。怎样让协作结构自动学出来，见「智能体群与强化学习编排」。
