文本生成的自动指标

Automatic Metrics for Generated Text

也叫：BLEU　ROUGE　METEOR　BERTScore　自动评测指标　n-gram重合度

在交互版中打开（看它长在树上的哪里）

不用人工打分、由程序自动比较生成文本和参考答案相似程度的指标，如机器翻译的BLEU、摘要的ROUGE，以及基于嵌入的BERTScore。

先要会：n-gram与平滑 分词与token

分类任务的答案只有对错，生成文本却没有唯一正解：一句中文可以有几十种正确的英文翻译。请人逐句打分最可靠，但又慢又贵，研究者每改一次模型都要评一遍，根本等不起。于是需要一个自动指标：给定模型输出（候选）和一个或多个人写的参考答案，算出一个分数，要求它与人工判断大体一致。

BLEU（BLEU，2002）是机器翻译的标准指标。它统计候选句中的n-gram（连续n个词）有多少出现在参考句里，得到n = 1到4的修正精确率p_n（同一个词在候选中重复出现，最多只按参考里出现的次数计数，防止靠重复刷分），再取几何平均：

BLEU = BP · exp(Σ_n w_n · log p_n)，通常w_n = 1/4

只看精确率会鼓励模型输出很短的句子，所以乘上简短惩罚BP = exp(1 − r/c)（候选长度c短于参考长度r时生效，否则BP = 1）。BLEU一般在整个测试集上统计，报告成0–100的分数。

ROUGE（ROUGE）用于摘要，思路相同但看召回率：参考摘要里的n-gram有多少被候选覆盖。METEOR（METEOR）加入词干和同义词匹配。这些指标都只认字面重合，换了同义词就不得分；BERTScore（BERTScore）改为比较两句话中每个词的上下文嵌入向量的余弦相似度，对改写更宽容。

它出现在哪里：WMT机器翻译评测翻译评测和几乎所有翻译论文都报告BLEU，例如Transformer在WMT 2014英德翻译上的28.4 BLEU。大模型时代，开放式回答与参考答案的字面重合更说明不了问题，评测转向用强模型当裁判打分（LLM-as-a-Judge与MT-Bench）或人类两两投票（见Elo评分与两两比较）。注意困惑度衡量的是模型给真实文本的概率，不需要生成，和这里的指标是两回事。

例子

参考：the cat sat on the mat；候选：the cat is on the mat（长度都是6，BP = 1）。

  • 1-gram：候选6个词中the、the、cat、on、mat共5个能匹配，p_1 = 5/6
  • 2-gram：the cat、on the、the mat匹配，cat is、is on不匹配，p_2 = 3/5
  • 3-gram：只有on the mat匹配，p_3 = 1/4
  • 4-gram：3个都不匹配，p_4 = 0

只用1、2-gram时，BLEU-2 = √(5/6 × 3/5) ≈ 0.71；但标准BLEU-4因为p_4 = 0，几何平均直接变成0。这说明句子级BLEU很不稳定，需要平滑或在整个语料上统计。

容易误解的地方

  • BLEU差1–2分不一定代表人能感觉到的质量差异；不同分词、大小写处理下的BLEU不可比，所以有了统一实现sacreBLEU。
  • 字面重合度高不等于意思对，一个“not”就能让句意相反而分数几乎不变。
  • 这些指标需要参考答案；对开放式对话、创意写作基本失效。
