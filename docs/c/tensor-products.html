外积、哈达玛积与克罗内克积

Outer, Hadamard and Kronecker Products

也叫：外积　outer product　哈达玛积　Hadamard product　逐元素乘　逐元素乘积　element-wise product　elementwise multiplication　Schur product　克罗内克积　Kronecker product　张量积　tensor product　⊙　⊗

在交互版中打开（看它长在树上的哪里）

矩阵乘法之外的三种“乘”：外积把两个向量撑成一个矩阵，哈达玛积是同形状逐元素相乘，克罗内克积把一个矩阵的每个元素替换成另一整个矩阵的倍数。

先要会：向量、矩阵与张量 矩阵乘法与线性变换

论文公式里除了普通的矩阵乘法（见矩阵乘法与线性变换），还常见⊙、⊗这类符号。它们含义不同，读错了整条公式就错了。

外积（outer product）。两个列向量u（长m）和v（长n），外积u vᵀ是一个m×n矩阵，第(i, j)个元素是u_i·v_j。它的秩为1，任何矩阵都能写成若干个外积之和（这正是特征分解与奇异值分解的另一种看法）。全连接层的权重梯度就是一个外积：输出端梯度乘以输入的转置，见矩阵求导。

哈达玛积（Hadamard product，逐元素乘）。两个同形状的数组对应位置相乘，常记作A ⊙ B，代码里就是A * B。它出现在所有门控结构中：LSTM用f ⊙ c决定旧记忆保留多少，GLU变体与SwiGLU用Swish(xW) ⊙ (xV)让一路信号控制另一路，见门控机制。Dropout也是给激活乘上一个0/1掩码。

克罗内克积（Kronecker product）。A是m×n、B是p×q，A ⊗ B是一个mp×nq的大矩阵：把A的每个元素a_ij替换成整块a_ij·B。它的妙处在于大矩阵的运算可以拆成小矩阵来做，例如(A ⊗ B)⁻¹ = A⁻¹ ⊗ B⁻¹。K-FAC把一层的曲率矩阵近似为两个小矩阵的克罗内克积，求逆代价从“参数数的立方”降到“各自边长的立方”，Shampoo也用了类似的分解。

符号要看上下文。⊗在有的论文里表示克罗内克积，在有的论文里表示逐元素乘（例如不少门控网络的写法），还有时表示一般的张量积；⊙和∘多数表示逐元素乘。遇到时先看作者的记号说明，或者用形状推断：两个同形状数组相乘、结果形状不变的，就是逐元素乘。

例子

u = (1, 2)，v = (3, 4, 5)：外积u vᵀ = [[3, 4, 5], [6, 8, 10]]，2×3、秩为1。

A = [[1, 2], [3, 4]]，B = [[0, 1], [1, 0]]：A ⊙ B = [[0, 2], [3, 0]]。A ⊗ B是4×4矩阵[[0, 1, 0, 2], [1, 0, 2, 0], [0, 3, 0, 4], [3, 0, 4, 0]]。

规模感：一层1024×1024的权重有约100万个参数，完整曲率矩阵是100万×100万；K-FAC只需存两个1024×1024的小矩阵。

容易误解的地方

  • u vᵀ（外积，矩阵）和uᵀv（内积，标量，见内积与余弦相似度）只差转置的位置，结果完全不同。
  • NumPy和PyTorch里*是逐元素乘，@才是矩阵乘法；形状不同时*还会触发广播，见广播与einsum。
