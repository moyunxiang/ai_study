让一个序列模型在不更新参数的情况下，只靠读入过去的交互历史，就在新任务上越玩越好。

普通RL在每个新任务上都要重新梯度训练。RL²元强化学习提出把“学习算法”本身交给循环网络：在许多任务上训练后，网络的隐状态就能在新任务中完成探索和适应，这是元学习在RL里的形态。

算法蒸馏与上下文RL把一个RL算法从差到好的整段学习历史喂给Transformer做序列预测，得到能在上下文中自我改进的模型；AdA人类时间尺度适应在开放任务空间里训练出人类时间尺度上的快速适应；DiscoRL：元学习发现RL算法则反过来用元学习去发现新的RL更新规则。它与大模型的上下文学习与提示有直接类比，争论在于泛化到训练分布外任务的能力有多强。
