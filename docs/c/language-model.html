语言模型

Language Model

也叫：LM　LLM　大语言模型　大模型　统计语言模型

在交互版中打开（看它长在树上的哪里）

给任意一段文字打一个概率的模型；等价地，给定前文，预测下一个词（token）是什么的概率分布。今天的大语言模型就是规模极大的语言模型。

先要会：随机变量与概率分布 条件概率与贝叶斯公式 分词与token

语音识别系统听到一段含糊的声音，可能对应“我想吃苹果”或“我想吃平果”；翻译系统也会产生多个候选译文。要从中挑出最像人话的那个，需要一个能回答“这句话有多可能出现”的模型。这就是语言模型最初的用途：在HMM统计语音识别等系统中，给声学或翻译模型的候选打分。

定义。语言模型给一个token序列w_1…w_n赋予概率P(w_1, …, w_n)。由概率的乘法规则（见条件概率与贝叶斯公式），任何联合概率都可以拆成一串条件概率的乘积：

P(w_1, …, w_n) = P(w_1) · P(w_2 | w_1) · P(w_3 | w_1, w_2) · … = Π_t P(w_t | w_<t)

所以“给整句打分”和“根据前文预测下一个token”是同一件事。实践中几乎都学后者：模型读入前文，输出词表上每个token的概率（通过Softmax与logits）。连乘的数很小，通常用对数概率之和Σ_t log P(w_t | w_<t)来计算和比较。token是什么取决于分词与token：可以是词、字、或子词片段。

怎么训练。拿海量文本，在每个位置上让模型预测下一个token，用交叉熵作损失——也就是最大化真实文本的似然。不需要人工标注，任何文本都是训练数据，这是语言模型能做大的根本原因。评价指标通常是困惑度。

几代做法。

  • 香农：语言的统计模型（1948）用n-gram统计英文字母和单词的概率；之后几十年的主流是计数加平滑的n-gram与平滑模型。
  • 神经概率语言模型（2003）第一次用神经网络和词向量来估计条件概率；RNN语言模型（2010）用RNN读入任意长的前文。
  • GPT-1之后，语言模型用Transformer解码器实现，规模放大到GPT-3的1750亿参数，开始表现出不必专门训练就能完成翻译、问答等任务的能力。

为什么“预测下一个词”这么强。要把下一个词猜准，模型必须掌握语法、事实、推理，甚至说话人的意图。生成文本时，只要反复“预测—采样—接上”（见自回归生成），语言模型就成了一个文本生成器。

例子

假设某模型给出：P(我) = 0.05，P(喜欢 | 我) = 0.1，P(猫 | 我 喜欢) = 0.02。则

P(我 喜欢 猫) = 0.05 × 0.1 × 0.02 = 0.0001，

对数概率为ln 0.0001 ≈ −9.21。如果同一模型给出P(喵 | 我 喜欢) = 0.00001，那么“我 喜欢 喵”的概率只有0.05 × 0.1 × 0.00001 = 5×10^(−8)，比前一句低2000倍。语音识别系统就用这样的差别在发音相近的候选之间做选择。

容易误解的地方

  • 语言模型学的是“文本里常见什么”，不是“什么是真的”。概率高的句子未必正确，这是幻觉的根源之一。
  • 不同分词方式下的概率不能直接比较：同一句话切成10个token还是20个token，每个token的平均对数概率不同。
  • “语言模型”不一定是从左到右的：BERT这类掩码模型（见掩码建模）也被叫作语言模型，但它不直接给出整句的概率，也不能直接逐词生成。
