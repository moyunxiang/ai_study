指数族分布

Exponential Family

也叫：指数族　指数族分布　exponential family　自然参数　natural parameter　对数配分函数　log-partition function　广义线性模型　generalized linear model　矩匹配　moment matching　泊松回归　Poisson regression

在交互版中打开（看它长在树上的哪里）

一大类分布的统一写法：密度正比于exp(参数·充分统计量)。高斯、伯努利、类别、泊松都在其中，它解释了softmax、交叉熵和共轭先验为何是那种形式。

先要会：随机变量与概率分布 最大似然估计 Softmax与logits

高斯、伯努利、类别分布、泊松分布看起来各不相同，但它们都能写成同一种形式。认出这个形式，许多“为什么损失函数长这样”的问题就有了统一答案。

定义。指数族分布的密度（或概率质量）可以写成

p(x | η) = h(x) · exp(ηᵀT(x) − A(η))

  • η：自然参数；
  • T(x)：充分统计量，要从数据里估计参数，只需要知道它的总和（见估计量：偏差、方差与一致性）；
  • A(η)：对数配分函数，保证总概率为1；
  • h(x)：与参数无关的基础测度。

几个成员。

  • 伯努利：p(x) = exp(x·η − log(1 + e^η))，自然参数η = log(p / (1 − p))，正是logit；反过来p = σ(η)，就是sigmoid。
  • 类别分布：自然参数是各类的logit，A(η) = log Σ exp(η_k)，由此得到的从η到概率的映射正是Softmax与logits。
  • 高斯（方差固定）：自然参数就是均值，T(x) = x。
  • 泊松：自然参数是log λ。

好用的性质。

  • 对数配分函数的导数给出充分统计量的期望：∇A(η) = E[T(x)]，二阶导数给出它的协方差。
  • 最大似然的解满足“模型期望 = 数据平均”：E_η[T(x)] = (1/N)·Σ T(x_i)，称为矩匹配，见最大似然估计。
  • 负对数似然对η是凸的，因为A(η)是凸函数（见凸函数与凸优化）。这就是逻辑回归和softmax回归损失为凸的原因，对logit的梯度也总是“预测减去观测”。
  • 每个指数族都有共轭先验，见Beta分布、狄利克雷分布与共轭先验。
  • 在“期望值满足某些约束”的分布中，熵最大的那个恰好是指数族，见最大熵原理。

它出现在哪里。广义线性模型（线性回归、逻辑回归、泊松回归）就是“线性预测自然参数”；最大熵模型和条件随机场是条件指数族；能量模型与玻尔兹曼分布模型可看作把ηᵀT(x)换成任意神经网络能量函数的推广，代价是A(η)不再能算出来。

例子

伯努利p = 0.8：自然参数η = log(0.8/0.2) = log 4 ≈ 1.386；A(η) = log(1 + e^1.386) = log 5 ≈ 1.609。检验：A对η的导数e^η/(1 + e^η) = 4/5 = 0.8，正好是E[x] = p。

三个类别的logits (2, 1, 0)：A = log(e² + e + 1) ≈ log 11.1 ≈ 2.41，对各logit的导数(0.67, 0.24, 0.09)就是softmax概率。

容易误解的地方

  • 均匀分布U(0, θ)（支撑集依赖于参数）和学生t分布都不属于指数族，相应的漂亮性质不适用。
  • 混合模型（如高斯混合）不是指数族，所以它的似然不是凸的，需要EM这类迭代方法。
