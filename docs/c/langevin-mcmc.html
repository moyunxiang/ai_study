MCMC与朗之万动力学

MCMC and Langevin Dynamics

也叫：马尔可夫链蒙特卡洛　朗之万采样　Metropolis-Hastings　Gibbs采样　SGLD

在交互版中打开（看它长在树上的哪里）

当只能计算一个分布的（未归一化）密度或其梯度、却无法直接采样时，构造一条随机游走的马尔可夫链，让它长期停留的分布恰好是目标分布。

先要会：马尔可夫性与马尔可夫链 蒙特卡洛采样 导数、偏导与梯度

蒙特卡洛采样方法需要从分布p(x)里抽样本，但很多分布只能写出一个不知道归一化常数的形式p(x) ∝ exp(−E(x))（见能量模型与玻尔兹曼分布），比如贝叶斯后验、玻尔兹曼分布。归一化常数要对所有x积分，高维时算不出来，也就没法直接采样。

MCMC的思路：不直接采样，而是设计一条马尔可夫性与马尔可夫链，使它的平稳分布等于p。从任意起点出发跑足够多步，链上的点就近似是p的样本。1953年的Metropolis采样与MCMC（Metropolis算法）给出了最早的构造：从当前点x随机提议一个新点x′，以概率min(1, p(x′)/p(x))接受，否则留在原地。注意只用到密度之比，归一化常数被约掉了。

朗之万动力学利用梯度，让提议往高概率区域走：

x ← x + (ε/2)·∇log p(x) + √ε · z，z ~ N(0, I)

第一项是沿对数密度的梯度上坡（类似梯度下降），第二项注入噪声防止所有点都挤到峰顶。步长ε → 0、步数足够多时，样本分布趋于p；有限步长会带来少量偏差，可用Metropolis校正。

在AI里：∇log p(x)正是分数函数与分数匹配。分数匹配生成模型（2019）先用神经网络学出分数，再用退火朗之万动力学从纯噪声出发逐步采样——这是扩散模型的前身之一；DDPM的反向去噪过程也可以看成一种离散的朗之万采样（见扩散：前向加噪与反向去噪）。早期的能量模型、受限玻尔兹曼机，以及贝叶斯神经网络的随机梯度朗之万方法，都靠这类采样。

例子

目标分布是标准正态N(0, 1)，∇log p(x) = −x。取ε = 0.1，更新为x ← 0.95x + 0.316z。

  • 从x = 5出发，忽略噪声时均值每步乘0.95，50步后约为0.38，链已经“忘记”起点。
  • 长期方差v满足v = 0.95²·v + 0.1，解得v ≈ 1.026，接近目标的1；多出的2.6%就是有限步长带来的偏差，ε越小偏差越小。

容易误解的地方

  • MCMC的样本彼此相关，1000个链上的点远不等于1000个独立样本。
  • 前面若干步（burn-in）还没收敛，要丢掉。多峰分布中链可能长时间困在一个峰里，看起来“收敛”了其实没有。
  • 朗之万更新和带噪声的梯度下降形式几乎一样，区别在于噪声的大小是按步长精确设定的，目的是采样而不是找最大值。
