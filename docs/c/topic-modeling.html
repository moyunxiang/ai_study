主题模型

Topic Modeling

也叫：Topic Model　主题建模　话题模型　LDA主题模型　潜在语义　Latent Semantic　文档聚类　BERTopic　神经主题模型

在交互版中打开（看它长在树上的哪里）

从一大批文档里自动归纳出若干主题，每个主题用一组代表词描述，并说明每篇文档讲的是哪些主题。

主题模型想回答“这堆文档大致在讲哪几件事”。潜在语义分析LSA先对词-文档矩阵做奇异值分解，把文档投到低维的“语义”空间；概率潜在语义分析pLSA把它改写成概率模型：每篇文档是若干主题的混合，每个主题是词上的分布；LDA主题模型再给这些混合比例加上狄利克雷先验，成为最常用的主题模型，并衍生出动态主题、层次主题等大量变体。

这些模型都基于词袋假设，不看词序和词义相似。神经时代的代表是BERTopic主题模型：用预训练句向量编码文档，降维聚类，再用按类计算的TF-IDF提取主题词，主题数不必事先指定。现在很多人也直接让大模型归纳主题，但如何稳定、可重复地评估主题质量仍没有公认答案。
