利普希茨连续与光滑性

Lipschitz Continuity and Smoothness

也叫：利普希茨连续　李普希茨连续　Lipschitz　Lipschitz continuity　Lipschitz常数　Lipschitz constant　利普希茨常数　光滑性　L-光滑　L-smooth　smoothness　β-smooth　梯度利普希茨　1-Lipschitz　谱范数　spectral norm

利普希茨连续说函数值不会变得太快（斜率有上限L）；L-光滑说梯度不会变得太快。前者用于鲁棒性和GAN的约束，后者决定梯度下降能用多大的学习率。

先要会：导数、偏导与梯度 范数与距离

优化和学习理论的定理里，几乎总有一句“假设f是L-利普希茨的”或“假设f是β-光滑的”。它们给“函数有多平稳”一个定量的说法。

利普希茨连续（Lipschitz continuity）。如果存在常数L，使任意两点都满足

|f(x) − f(y)| ≤ L · ‖x − y‖

就说f是L-利普希茨的。直观地说，函数图像上任意两点连线的斜率绝对值不超过L。可导函数的最小L就是梯度范数的上确界。线性层f(x) = Wx的利普希茨常数是W的最大奇异值（谱范数，见特征分解与奇异值分解）；神经网络的常数不超过各层常数之积（ReLU等激活函数的常数为1）。

光滑性（L-smooth）。如果是梯度满足利普希茨条件：‖∇f(x) − ∇f(y)‖ ≤ β‖x − y‖，就说f是β-光滑的；对二阶可导函数，等价于海森矩阵的特征值绝对值都不超过β（见雅可比矩阵与海森矩阵）。它保证函数被一个二次函数从上方“兜住”：

f(y) ≤ f(x) + ∇f(x)ᵀ(y − x) + (β/2)‖y − x‖²

由此可以证明：学习率取1/β时，梯度下降每一步都会让函数值下降；学习率超过2/β时，在曲率最大的方向上会发散。稳定性边缘发现，神经网络训练中最大曲率常常会自己涨到2/学习率附近然后停在那里。

它们出现在哪里。

  • Wasserstein GAN要求判别器是1-利普希茨的，Wasserstein距离的对偶形式才成立（见最优传输与Wasserstein距离）；WGAN-GP梯度惩罚用梯度惩罚、谱归一化用谱归一化来近似实现这一约束。
  • 对抗鲁棒性：如果分类器的利普希茨常数小，输入被扰动ε时输出最多变化Lε，可以给出“这个扰动范围内结论不变”的保证，见对抗样本。
  • 残差流Residual Flows要求残差分支的常数小于1，从而整个残差块可逆。
  • 谱归一化间隔界等泛化界里，网络的复杂度用各层谱范数的乘积来衡量。

例子

f(x) = sin(x)：导数cos(x)的绝对值不超过1，所以1-利普希茨；f''(x) = −sin(x)也不超过1，所以1-光滑。

f(x) = 5x²：f'(x) = 10x，在整个实轴上没有上界，不是全局利普希茨的；但f''= 10，是10-光滑的。梯度下降x ← x − η·10x = (1 − 10η)x：η = 0.1时一步到0；η = 0.25时x乘以−1.5，越跳越远，正好超过了2/β = 0.2。

容易误解的地方

  • 各层谱范数之积通常是网络真实利普希茨常数的严重高估，深层网络里可能差好几个数量级。
  • ReLU网络在折点处不可导，“光滑”的假设对它并不严格成立；理论结论用到深度网络上时要打个折扣。
