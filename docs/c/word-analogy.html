词类比与向量运算

Word Analogies and Vector Arithmetic

也叫：word analogy　词类比　类比推理　analogy test　类比测试　king - man + woman　king man woman queen　国王-男人+女人　向量运算　vector arithmetic　线性关系　linear regularities　3CosAdd　linear representation hypothesis

在交互版中打开（看它长在树上的哪里）

用词向量的加减做类比推理：vec(国王) − vec(男人) + vec(女人) 最接近 vec(女王)。它说明词向量空间里某些方向对应稳定的语义关系，也曾是评测词向量的标准方法。

先要会：嵌入向量 内积与余弦相似度

word2vec发布后最出名的演示是：拿“国王”的向量减去“男人”、加上“女人”，在词表里找离结果最近的词，得到的是“女王”。词向量类比规律系统地报告了这种现象：词向量之间的差向量编码了一致的关系。

定义。类比问题“a之于b，如同c之于?”，求

d* = argmax_(d ∉ {a, b, c}) cos(v_d, v_b − v_a + v_c)

即找与v_b − v_a + v_c余弦相似度最高的词（见内积与余弦相似度），并排除题目中出现的三个词。

能表示哪些关系。性别（男人:女人 = 国王:女王）、国家与首都（法国:巴黎 = 日本:东京）、单复数、比较级、动词时态等。它们在向量空间里近似表现为平行的位移。

作为评测。Mikolov等人发布了一个包含语义类和语法类的类比测试集，长期作为词向量的标准评测之一，GloVe等方法都报告了上面的准确率。

为什么会出现。word2vec即隐式矩阵分解指出，skip-gram负采样在隐式地分解一个移位的PMI矩阵（见点互信息与PPMI），类比的成立与词的共现统计有关：“国王”与“女王”的共现模式之差，和“男人”与“女人”的差相似。这符合分布假说的思想。

局限和批评。

  • 排除题目中的词这一步很关键：不排除时，最近的词常常就是“国王”自己，演示效果会大打折扣。
  • 很多类比只在少数挑选过的例子上效果好，在更系统的测试中准确率并不高。
  • 类比同样暴露了偏见：词向量中的性别偏见发现“男人:程序员 = 女人:家庭主妇”这样的结果，说明词向量学到了训练文本中的社会偏见。

今天。大模型的内部表示中也有类似的“线性方向”：某个方向对应性别、某个方向对应情感极性。这种“线性表示假说”是可解释性研究的重要线索（见激活引导与表示工程、叠加假说）。

例子

设（降到3维示意的）词向量：国王 [0.8, 0.6, 0.1]，男人 [0.7, 0.1, 0.1]，女人 [0.7, 0.1, 0.9]，女王 [0.8, 0.6, 0.85]。

计算 国王 − 男人 + 女人 = [0.8, 0.6, 0.9]。与女王的余弦相似度约0.9996，几乎重合。这里第3维相当于“性别”方向，第2维相当于“王室”方向。

真实词向量有几百维，这种方向是分散在很多维上的，不是某一维单独表示。

容易误解的地方

  • 类比测试准确率高不等于词向量在下游任务上更好，两者相关性有限。
  • 类比结果对“排除输入词”的处理、词表大小、是否归一化向量都很敏感，复现时要用同样的设置。
