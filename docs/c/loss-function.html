损失函数

Loss Function

也叫：代价函数　cost function　目标函数　objective function　误差函数

在交互版中打开（看它长在树上的哪里）

一个把“模型预测有多差”变成一个数字的函数。训练就是不断调整参数，让这个数字在训练数据上尽量小。

先要会：导数、偏导与梯度 随机变量与概率分布

机器学习里“学习”的意思是自动调参数。要让计算机自己调，必须先告诉它什么叫“好”：给出一个函数，输入模型的预测和正确答案，输出一个非负实数，越小代表越好。这个函数就是损失函数（loss function，也叫代价函数、目标函数）。有了它，“学习”就变成了一个数学问题：找参数θ，使训练集上的平均损失L(θ) = (1/N) Σ_i ℓ(f_θ(x_i), y_i)最小。

两个最常用的损失：

  • 回归（预测一个实数）用均方误差：ℓ = (ŷ − y)²。误差翻倍，惩罚变成四倍，所以它对离群点很敏感。
  • 分类（预测类别）用交叉熵：ℓ = −log p_y，其中p_y是模型给正确类别的概率（通常由Softmax与logits算出）。给正确答案的概率越低，损失越大，概率趋于0时损失趋于无穷。

这两种损失并不是随便选的：假设噪声服从高斯分布时，最小化均方误差等价于最大似然估计；最小化交叉熵也等价于最大化正确标签的对数似然。

为什么不直接优化准确率：准确率是阶梯函数，参数微小变化时它要么不变、要么突然跳动，导数几乎处处为0，梯度下降无从下手。损失函数必须是光滑（至少几乎处处可导）的“代理”，它的下降大致对应我们真正关心的指标的提升。

它出现在哪里：几乎每篇工作的核心贡献之一都是换了一个损失。反向传播让任意可导损失都能训练多层网络；生成对抗网络GAN用另一个网络充当损失；Focal Loss与RetinaNet提出Focal Loss处理类别极度不平衡；InstructGPT与RLHF的奖励模型实际上是用人类偏好学出来的损失。语言模型预训练的损失就是对下一个词的交叉熵。

例子

回归：两套房子真实价格是2和7（百万），模型预测3和5。误差为1和−2，均方误差 = (1² + 2²)/2 = 2.5。

分类：正确类别被模型给了0.7的概率，交叉熵损失 = −ln 0.7 ≈ 0.357；如果只给0.1，损失 = −ln 0.1 ≈ 2.303，是前者的六倍多。概率从0.7掉到0.1，准确率可能都只是“错了一个样本”，但损失能精细地区分“错得多离谱”。

容易误解的地方

  • 损失低不等于效果好：训练集上的损失可以降到接近0，测试时却很差，见泛化与过拟合。
  • 损失的绝对数值通常不可跨任务比较。语言模型的损失与词表大小、分词方式有关，换了分词器后数字不能直接对比。
  • 实际训练的目标常是“主损失 + 正则项 + 辅助损失”的加权和，论文里的loss曲线不一定只是一项。
