交叉注意力

Cross-Attention

也叫：cross-attention　交叉注意力　互注意力　编码器-解码器注意力　encoder-decoder attention　source-target attention　cross attention layer　交叉注意力层

在交互版中打开（看它长在树上的哪里）

查询来自一个序列、键和值来自另一个序列的注意力。它让解码器在生成时回看编码器的输入，也是把图像、检索文档等外部信息接进语言模型的常用接口。

先要会：自注意力与多头注意力 编码器-解码器

自注意力与多头注意力里，Q、K、V都由同一个序列算出，作用是让序列内部交换信息。但很多任务涉及两个序列：翻译时译文要对照原文，看图说话时文字要对照图像。交叉注意力就是在两个序列之间做注意力。

定义。设X是“提问方”（如解码器当前的隐状态，长度m），Y是“被查询方”（如编码器输出，长度n）：

Q = X·W_Q，K = Y·W_K，V = Y·W_V

CrossAttn(X, Y) = softmax(Q·Kᵀ / √d)·V

注意力矩阵是m×n的：X的每个位置在Y的所有位置上分配权重，取回一个加权平均的向量（见查询、键与值（Q/K/V））。由于Y是事先给定的完整输入，交叉注意力不需要因果掩码。

在编码器-解码器里。Transformer的每个解码器层有三个子层：带因果掩码的自注意力 → 交叉注意力（查询编码器输出）→ 前馈网络。它的前身是RNN时代的注意力机制：解码器每生成一个词，都对源句子的所有隐状态算一次权重——那本质上就是交叉注意力，只是打分函数不同。

作为“接口”。交叉注意力让一个模型以可学习的方式读取另一个来源的信息，所以被大量用来做条件注入：

  • 图像生成：潜空间扩散LDM把文本编码器的输出作为K、V，U-Net的图像特征作为Q，文字由此控制画面。
  • 多模态语言模型：Flamingo在冻结的语言模型层之间插入交叉注意力层去读图像特征；后来更流行的做法是把视觉token直接拼进输入序列，用自注意力统一处理（见视觉连接器）。
  • 检索增强：RETRO用分块交叉注意力读取检索到的文档。
  • 语音识别：Whisper的解码器通过交叉注意力读取音频编码器的输出。

例子

英译中，编码器输出“The cat sat”的3个向量（n = 3）。解码器已生成“猫”，正在预测下一个词，当前位置的查询向量与3个键的点积（除以√d后）为 [0.5, 0.2, 2.1]，softmax得约 [0.15, 0.11, 0.74]。取回的向量主要来自“sat”，于是解码器倾向于生成“坐”。整句生成完后，把每一步的权重排成一个矩阵，就是翻译里常画的“对齐热力图”。

容易误解的地方

  • 交叉注意力的计算量是m×n，被查询的那一方（如高分辨率图像特征）很长时同样昂贵。
  • K、V来自外部输入，推理时只需计算一次就能在每个生成步复用，这与自注意力的KV缓存不同。
  • 不要把它和对比学习里的“跨模态对齐”混为一谈：后者只算两个整体向量的相似度，不交换细粒度信息。
