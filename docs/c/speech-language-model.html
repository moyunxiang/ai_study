语音语言模型

Spoken Language Models

也叫：SpeechLM　Speech LM　SLM　Spoken Language Model　spoken LM　textless NLP　无文本NLP　无文本语言模型　生成式语音语言模型　GSLM　语音续写　speech continuation　语音预训练语言模型

在交互版中打开（看它长在树上的哪里）

直接在语音token上做「下一个token预测」，让模型像学文字一样从大量录音里学会说话，不经过文本。

GSLM无文本语言模型首先证明：把HuBERT等自监督特征聚类成离散单元，再在上面训练语言模型，就能不用任何文字续写出连贯语音，这被称为无文本NLP。dGSLM双通道对话扩到双通道对话，学会了笑声和抢话；AudioLM加入声学token，续写保留音色和录音环境；SpiRit-LM交错语音文本在预训练中交错语音和文本，借文本模型的知识。

大模型时代，这条线与端到端对话合流：Moshi全双工语音对话在语音-文本联合语言模型上做全双工；MiMo-Audio把语音预训练扩到1亿小时以上，报告出现类似GPT-3的少样本能力。

核心争论：纯语音语言模型的语义能力增长很慢（语音token信息密度低、序列长），所以多数系统借用文本LLM初始化或交错文本；纯从语音学会语言需要多少数据仍未知。
