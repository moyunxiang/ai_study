3D世界与场景生成

3D World and Scene Generation

也叫：3D世界生成　World Generation　场景生成　Scene Generation　Text-to-World　文生世界　可漫游3D场景　Explorable 3D World　全景图生成　Panorama Generation　生成式3D场景　空间生成　Spatial Generation

在交互版中打开（看它长在树上的哪里）

从一句话或一张图生成可以走进去、四处看、导出到游戏引擎的整片三维场景，而不只是单个物体。

单个物体的3D生成成熟后，下一步是整片场景。难点在于：场景尺度大、遮挡多，而带完整3D标注的场景数据极少。

一种做法是让视频模型“想象”环绕镜头再重建，多样性好但3D一致性难保证；另一种是先生成全景图作为世界代理。HunyuanWorld 1.0采用后者：生成360°全景图，按天空、背景、物体分层，逐层估计深度并重建为可导出的网格，物体可交给Hunyuan3D 2.0生成；其2.0版本输出高斯泼溅场景。World Labs的World Labs Marble以文本、图像、视频或粗略布局生成可编辑、可扩展的3D世界，导出为高斯泼溅或网格。

与机器人分支的可交互世界模型（如Genie 3）不同，这里生成的是显式、持久的3D资产，可以反复漫游而不会遗忘；代价是动态内容和物理交互能力很弱。
