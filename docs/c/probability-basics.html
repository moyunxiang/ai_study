随机变量与概率分布

Random Variables and Distributions

也叫：random variable　probability distribution　概率论　PDF　概率密度

在交互版中打开（看它长在树上的哪里）

随机变量是取值带有不确定性的量，概率分布说明它取每个值（或落在每个区间）的可能性有多大。现代AI模型的输出大多就是一个概率分布。

现实世界充满不确定性：同一张模糊的图片可能是猫也可能是狗，一句话的下一个词有很多种合理的接法。与其让模型给出唯一答案，不如让它给出“每种答案有多大可能”。描述这种不确定性的语言就是概率论。

随机变量与分布。随机变量X是一个取值不确定的量。

  • 离散型：取值可以一一列出，用概率质量函数P(X = x)描述，所有取值的概率之和为1。
  • 连续型：取值是实数，用概率密度函数p(x)描述，落在区间[a, b]的概率是∫_a^b p(x) dx，整条实轴上积分为1。注意密度本身可以大于1，它不是概率。

常见的分布有伯努利（抛一次硬币）、类别分布（掷一次骰子，或从词表里选一个词）、均匀分布和高斯分布。

联合、边缘与独立。多个随机变量放在一起用联合分布P(X, Y)描述。对其中一个求和（或积分）就得到另一个的边缘分布：P(X = x) = Σ_y P(X = x, Y = y)。如果P(X, Y) = P(X)P(Y)，就说X和Y独立。给定条件后的分布见条件概率与贝叶斯公式。

它出现在哪里。香农：语言的统计模型把语言看成一个随机过程，用前几个词预测下一个词的分布；朴素贝叶斯分类假设各特征在给定类别时相互独立，从而简化联合分布；神经概率语言模型和此后所有神经语言模型都在输出词表上的类别分布，Softmax与logits负责把分数变成这个分布，语言模型的“生成”就是从中采样。期望与方差描述分布的中心和离散程度。

例子

掷两个均匀骰子，点数和S是一个离散随机变量。36种结果等可能，和为7的有(1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)共6种，所以P(S = 7) = 6/36 = 1/6；和为2只有(1,1)一种，P(S = 2) = 1/36。语言模型的输出与此同类：给定“今天天气很”，它给出一个在几万个词上的分布，比如“好”0.4、“热”0.2、“冷”0.1……总和为1。

容易误解的地方

  • 概率密度不是概率：标准差很小的高斯分布在均值处的密度可以远大于1，只有对区间积分才得到概率。
  • 两个变量不相关（协方差为0）不等于独立；独立是更强的条件。
