特权学习与教师–学生蒸馏

Privileged Learning and Teacher–Student Distillation

也叫：特权学习　特权信息　privileged learning　privileged information　learning using privileged information　LUPI　教师-学生蒸馏　教师学生框架　teacher-student distillation　teacher-student　特权教师　privileged teacher　在线适应　online adaptation

在交互版中打开（看它长在树上的哪里）

教师–学生蒸馏的一种：先在仿真里训练能看到“特权信息”（地形、摩擦、物体精确位姿）的教师，再训练只用真实传感器的学生去模仿它，是仿真到现实迁移的常用路线。

先要会：模仿学习与行为克隆 仿真到现实的差距

在仿真里训练机器人很方便：可以并行跑成千上万个环境（见Isaac Gym大规模并行仿真和向量化环境与并行采样），还能直接读出任何物理量。可部署到真实机器人时，它只有摄像头、关节编码器和IMU，地面有多滑、前方台阶多高都看不到。直接用这些有限的观测从头做强化学习，探索和信用分配都非常难（见状态、观测与动作和信用分配）。

两阶段训练。

1. 教师：输入包含特权信息（真实地形高度图、摩擦系数、外力、物体的精确状态），用强化学习训练。问题变得接近完全可观测，训练快、效果好。 2. 学生：输入只有部署时能拿到的传感器数据，通常还加上一段历史（用循环网络或时序卷积从过去的状态和动作中推断环境性质）。用监督学习让学生的动作模仿教师（见模仿学习与行为克隆），或者让学生预测教师内部对特权信息的编码。为避免误差累积，常用DAgger式的在线蒸馏：让学生自己控制机器人，教师在学生访问到的状态上给出正确动作。

为什么有效。特权信息让困难的强化学习问题变得容易；学生阶段是监督学习，比强化学习稳定得多。学生从历史中隐式地估计出地形、摩擦等量，相当于做了一种在线的系统辨识。

代表工作。

  • Learning by Cheating特权蒸馏在自动驾驶中提出“先作弊再蒸馏”：教师看到俯视的真实地图，学生只用摄像头。
  • ANYmal复杂地形行走用这一方案训练ANYmal四足机器人在复杂地形上行走，仿真训练后直接迁移到野外。
  • RMA快速运动适应让学生从最近的状态—动作历史中预测教师使用的“环境编码”，实现快速在线适应。
  • Extreme Parkour四足极限跑酷等跑酷工作也采用类似的教师–学生结构。

这一思路与知识蒸馏相通，但教师和学生的输入不同，蒸馏的是“利用不可见信息做出的决策”。它是缩小仿真到现实的差距差距的主要手段之一，常与域随机化一起使用。

例子

四足机器人上台阶：教师看到前方1米内的精确高度图和地面摩擦系数，仿真中训练1亿步后成功率达到95%；学生只用50步的关节角、关节速度和IMU历史，模仿教师训练后在仿真中成功率约85%，部署到真实机器人上仍能识别“脚踩空了”并调整步态。直接用学生的输入从头做强化学习，同样步数下成功率可能不到一半。（数字为示意）

容易误解的地方

  • 教师能利用的信息学生永远推断不出来时（比如前方被遮挡的坑），学生无法真正模仿，只能学到一个平均化的保守行为，这叫模仿差距。
  • 蒸馏后的学生性能上限由教师决定，仿真中教师学到的物理“漏洞”也会被一并继承。
