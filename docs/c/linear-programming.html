线性规划与二次规划

Linear and Quadratic Programming

也叫：线性规划　linear programming　LP　二次规划　quadratic programming　QP　单纯形法　simplex method　内点法　interior point method　凸二次规划　整数规划　integer programming　LP松弛　LP relaxation　可行域　feasible region

目标和约束都是线性函数的优化问题叫线性规划；目标换成二次函数就是二次规划。它们有成熟的求解器，SVM、最优传输、模型预测控制都会化成这类问题。

先要会：凸函数与凸优化 向量、矩阵与张量

很多决策问题天然带约束：资源有限、概率必须非负且和为1、机器人关节角度有上下限。如果目标和约束都能写成线性的，就进入了优化里研究得最透彻的一类问题。

线性规划（LP）。标准形式：

min cᵀx　满足　Ax ≤ b，x ≥ 0

所有满足约束的点构成一个多面体（可行域），线性目标的最优值一定出现在多面体的某个顶点上。单纯形法沿着多面体的边从一个顶点走到更好的相邻顶点，直到无法改进；内点法则从可行域内部沿一条光滑路径逼近最优点，有多项式时间的保证。LP是凸函数与凸优化问题，局部最优即全局最优。每个LP都有一个对偶LP，两者最优值相等，见拉格朗日乘子、约束优化与对偶。

二次规划（QP）。目标变成½xᵀQx + cᵀx，约束仍是线性的。Q半正定时（见正交矩阵与正定矩阵）问题是凸的，可以高效求解。

它们出现在哪里。

  • 支持向量机的训练是一个凸QP：在“所有样本被正确分开且留出间隔”的线性约束下最小化‖w‖²；SMO序列最小优化把它拆成每次只优化两个变量的小QP，才让SVM能在大数据上跑起来。
  • 离散的最优传输与Wasserstein距离是一个LP：把一堆“土”搬到另一处，在每个源点送出量、每个目标点收到量固定的约束下，最小化总搬运成本。
  • 模型预测控制MPC在每个控制周期解一个QP：动力学线性化后成为等式约束，控制量上下限是不等式约束，目标是跟踪误差和控制量的二次和，见规划与模型预测控制。
  • 逆强化学习IRL的早期方法把“找一个让专家策略最优的奖励函数”写成LP。
  • 强化学习中，马尔可夫决策过程的最优价值函数也可以写成一个LP，这是动态规划之外的另一种求解视角。

例子

工厂生产两种产品，每件利润分别为3和2；产品一每件耗工时1、原料2，产品二每件耗工时1、原料1；工时上限4，原料上限6。

max 3x₁ + 2x₂　满足　x₁ + x₂ ≤ 4，2x₁ + x₂ ≤ 6，x ≥ 0

可行域顶点有(0, 0)、(3, 0)、(2, 2)、(0, 4)，利润分别为0、9、10、8，最优解是各生产2件，利润10。

容易误解的地方

  • 要求变量取整数的“整数规划”是NP难的，和LP的难度完全不同；把整数约束放松成连续约束（LP松弛）只能得到一个界。
  • 线性规划里的“规划”是programming的旧译，意思是“排计划”，与编程无关。
