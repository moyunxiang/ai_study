注意力机制

Attention

也叫：attention mechanism　QKV　注意力权重　加性注意力　soft attention

在交互版中打开（看它长在树上的哪里）

让模型在处理当前内容时，按相关程度给一组向量分配权重，再对它们加权平均。相当于一种可求导的“软查找”。

先要会：Softmax与logits 内积与余弦相似度 循环网络与隐状态

2014年的神经机器翻译（Seq2Seq）先用一个RNN把整句源语言读成一个固定长度的向量，再让另一个RNN从这个向量生成译文。句子一长，一个向量装不下所有信息，翻译质量随句长明显下降。人工翻译不是这样做的：写每个目标词时，会回头看源句中与之对应的那几个词。

注意力机制把这个动作变成了网络的一部分：生成每个词时，不再只用一个向量，而是对编码器的所有隐状态按相关程度加权求和。

一般形式。有一个查询q（“我现在要找什么”），和n个键-值对(k_i, v_i)（“每条内容的标签”和“内容本身”）：

1. 打分：s_i = score(q, k_i)，衡量q与每个k_i有多匹配。 2. 归一化：α = softmax(s)，得到一组和为1的非负权重（见Softmax与logits）。 3. 汇总：output = Σ_i α_i · v_i。

打分函数最常用的是内积q·k_i（Luong注意力，见内积与余弦相似度），Bahdanau用的是一个小MLP：vᵀ·tanh(W·q + U·k_i)。在翻译中，q是解码器当前的隐状态，k和v都是编码器各位置的隐状态。

为什么叫“软查找”。字典查找是硬的：键完全匹配才返回对应的值。注意力对所有值都返回一点，匹配度越高拿的权重越大。因为整个过程由乘法、softmax和加法组成，可以对q、k、v求导，于是“该看哪里”可以通过梯度下降学出来，不需要任何人工标注的对齐。

它在哪里出现。最初用于翻译中的源-目标对齐，权重矩阵画出来就是一张软对齐图（对照噪声信道与词对齐）。视觉注意力把它用在图像描述上，生成每个词时看图像的不同区域。当查询、键、值都来自同一个序列时，就是自注意力与多头注意力，Transformer完全建立在它上面。在编码器-解码器结构中，解码器看编码器输出的那种注意力叫交叉注意力。

例子

查询q = [1, 0]，三个键k_1 = [1, 0]、k_2 = [0, 1]、k_3 = [1, 1]，对应的值v_1 = [10, 0]、v_2 = [0, 10]、v_3 = [5, 5]。

1. 内积打分：s = [1, 0, 1]。 2. softmax：e^1 = 2.718，e^0 = 1，总和6.437，权重α ≈ [0.422, 0.155, 0.422]。 3. 加权求和：0.422×[10, 0] + 0.155×[0, 10] + 0.422×[5, 5] ≈ [6.34, 3.66]。

与q方向一致的k_1、k_3各拿到42%的权重，与q正交的k_2只拿到16%，但并不是0——这就是“软”的含义。如果把打分都乘以10（更尖锐），权重会接近[0.5, 0, 0.5]。

容易误解的地方

  • 注意力权重高不等于模型“因为这个词”做出了决定。用注意力图解释模型行为要谨慎，它只是计算过程的一部分。
  • 注意力的代价是要和每一个键都算一次分数：n个查询对n个键是n²次，序列很长时这是主要瓶颈。
  • “注意力”这个词在不同论文里指代的范围不同：有时指这里的通用机制，有时专指Transformer里的缩放点积自注意力。
