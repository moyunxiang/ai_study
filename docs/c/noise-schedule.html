噪声调度与采样步数

Noise Schedules and Sampling Steps

也叫：noise schedule　beta schedule　SNR　信噪比

在交互版中打开（看它长在树上的哪里）

扩散模型里规定每一步加多少噪声的时间表，以及生成时实际走多少步、怎么走。它直接决定训练效率、图像质量和生成速度。

先要会：扩散：前向加噪与反向去噪 常微分方程与随机微分方程

扩散：前向加噪与反向去噪的前向公式x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε里，ᾱ_t随t怎么从1降到0并没有唯一答案。这条曲线就是噪声调度。它看似是个超参数，实际影响很大：如果太多步落在“几乎全是噪声”或“几乎没噪声”的区间，网络就在没什么可学的地方浪费训练。

用信噪比来看。定义SNR(t) = ᾱ_t / (1 − ᾱ_t)，即信号方差与噪声方差之比。调度就是规定SNR从很大降到接近0的路线。

  • 线性调度：DDPM让β_t从0.0001线性增加到0.02。缺点是ᾱ_t下降太快，后半段几乎全是噪声。
  • 余弦调度：改进DDPM令ᾱ_t = f(t)/f(0)，f(t) = cos²((t/T + s)/(1 + s) · π/2)，s=0.008，让信噪比下降得更均匀。
  • 终点问题：噪声调度缺陷与零终端SNR发现许多调度在最后一步并没有降到纯噪声，训练时网络总能看到一点残留信号，生成时却从纯噪声出发，导致Stable Diffusion难以生成很亮或很暗的图。

采样步数。训练常用T=1000，但生成不必走满。把反向过程看成解一个常微分方程与随机微分方程后，就可以用更好的数值解法跳着走：DDIM用约50步，DPM-Solver用10到20步；EDM设计空间把调度、网络输入缩放和求解器放在统一框架下重新设计；一致性模型等蒸馏方法进一步压到1到4步。步数越少越快，但通常要靠额外训练或更精细的求解器来保住质量。

例子

T=1000、线性β从0.0001到0.02，累乘得到：ᾱ₁₀₀≈0.897，ᾱ₂₅₀≈0.524，ᾱ₅₀₀≈0.079，ᾱ₁₀₀₀≈0.00004。对应SNR在t=250约为1.10，在t=500只有约0.085，即走到一半时信号已被噪声淹没。

余弦调度下ᾱ₂₅₀≈0.847，ᾱ₅₀₀≈0.494，t=500时SNR约为0.98，信号和噪声差不多一样强，中间段的步数被更均匀地利用。

Stable Diffusion用的“scaled linear”调度（β从0.00085到0.012）在最后一步ᾱ≈0.0047，√ᾱ≈0.068：最“纯”的噪声里仍留着约7%的原信号幅度，这就是终点信噪比不为零的问题。

容易误解的地方

  • 训练步数T和采样步数是两回事：用1000步训练的模型可以只用20步采样。
  • 不同论文的t方向和符号约定不同（有的t=0是数据，有的t=0是噪声；有的用σ而不用ᾱ），对照公式前先看清约定。
  • 采样步数减少后画质下降，常被误认为是模型本身差，其实可能是求解器或调度不匹配。
