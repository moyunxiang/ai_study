可塑性丢失

Loss of Plasticity in Deep RL

也叫：plasticity loss　可塑性损失　首因偏差　primacy bias　网络重置　reset　dormant neurons　休眠神经元　持续学习中的可塑性

在交互版中打开（看它长在树上的哪里）

网络训练久了会逐渐失去学习新东西的能力，这在目标不断变化的RL里尤其严重。

RL的数据分布和学习目标随策略变化而不断移动，相当于一个永不结束的持续学习与灾难性遗忘问题。研究发现网络早期的数据会被过度拟合（首因偏差与网络重置），之后再怎么训练也很难调整，表现为大量神经元不再激活、梯度变小。

最直接的对策是周期性重置部分网络参数，BBF把重置作为核心配方之一；可塑性丧失系统地证明了深度网络在持续学习中会逐渐丧失可塑性；流式深度RL在每步只用一个样本、没有回放的流式设置下让深度RL重新可用。它与Sutton等人主张的大世界假说、OaK架构路线直接相关：智能体若要在经验中终身学习，可塑性必须一直保持。
