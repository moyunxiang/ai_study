类别不平衡与长尾

Class Imbalance and Long Tails

也叫：类别不平衡　类别不均衡　样本不均衡　数据不平衡　class imbalance　imbalanced data　imbalanced classification　长尾分布　long-tail　long-tailed recognition　长尾识别　过采样　oversampling　欠采样　undersampling　SMOTE　重采样　resampling　重加权　reweighting　类别权重　class weight　阈值调整　threshold moving

在交互版中打开（看它长在树上的哪里）

各类别样本数相差悬殊时（如欺诈交易只占0.1%），模型会偏向多数类、准确率失去意义。对策包括重采样、给损失加权、调整决策阈值，以及选用合适的评测指标。

先要会：准确率、精确率、召回率与F1 损失函数

现实数据很少是均衡的：信用卡欺诈、罕见病、设备故障、目标检测里的前景框，正类往往只占百分之几甚至千分之一；自然界的物种、物体类别也呈长尾分布，少数常见类占了大部分样本。

问题出在哪。用平均损失训练时，多数类贡献了绝大部分梯度，模型最省事的策略就是“几乎全猜多数类”。一个从不报警的欺诈检测器准确率可以达到99.9%，却毫无用处（见准确率、精确率、召回率与F1）。

数据层面：重采样。

  • 过采样少数类：重复抽取少数类样本，或用SMOTE在少数类样本之间插值合成新样本（在特征空间里取两个近邻少数类样本的连线上的点）。
  • 欠采样多数类：随机丢弃一部分多数类样本，简单但浪费数据。
  • 长尾检测和分类里常用“按类别频率重复采样”，让每个类在一个epoch里出现的次数更接近。

损失层面：重新加权。

  • 按类别频率的倒数给损失加权，或在BCE里设置正类权重（见二元交叉熵与sigmoid输出）。
  • focal loss（Focal Loss与RetinaNet）：在交叉熵前乘以(1 − p_t)^γ，模型已经很有把握的样本（多是容易的多数类）损失被大幅压低，训练集中在困难样本上，和难例挖掘与难负样本思路相通。

决策层面：调阈值。模型输出的是概率，默认用0.5判断。不均衡时可以在验证集上选一个使F1或业务指标最好的阈值，或者按先验比例修正logit，这往往比改训练更简单有效。

评测层面。不要只看准确率，应看每类的精确率、召回率、F1，PR曲线与平均精度（AP），以及c:imbalanced-metrics中的平衡准确率、MCC；ROC AUC在极度不均衡时可能显得过于乐观（见c:roc-auc）。

它出现在哪里。单阶段目标检测器中前景与背景候选框的比例可达1:1000，这正是focal loss要解决的问题；LVIS等长尾数据集专门评测稀有类别上的表现；推荐系统中点击远少于未点击，同样需要负采样或加权。

例子

10000笔交易中有50笔欺诈。模型A全部判为正常：准确率99.5%，召回率0。模型B找出了40笔欺诈，同时误报了200笔正常交易：准确率(40 + 9750)/10000 = 97.9%，比A低，但召回率80%、精确率40/240 ≈ 17%。对业务来说B有用得多，准确率却说反了。

容易误解的地方

  • 先划分训练/测试集，再对训练集做过采样；反过来做，同一个样本（或其合成副本）会同时出现在两边，造成数据泄漏（见数据泄漏与基准污染）。
  • 重采样或加权改变了模型看到的类别比例，输出的概率不再等于真实世界的概率，需要时要重新校准（见模型校准）。
