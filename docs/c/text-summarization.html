Text Summarization

也叫：自动摘要　Automatic Summarization　抽取式摘要　Extractive Summarization　生成式摘要　Abstractive Summarization　文摘　新闻摘要　摘要生成

在交互版中打开（看它长在树上的哪里）

把一篇长文压缩成几句话，要么从原文挑出关键句，要么重新写出概括性的句子。

最早的自动摘要是Luhn自动文摘：按高频关键词给句子打分，挑出得分最高的句子组成摘要，这就是抽取式摘要。TextRank把句子当作图上的节点、用相似度连边，再像PageRank与Google搜索一样计算句子重要性。评测上，ROUGE按与参考摘要的n-gram重合度打分，成为至今最常用的指标。

神经网络时代转向生成式摘要：神经生成式摘要用带注意力的编码器-解码器生成标题式短摘要；注意力阅读器与CNN/DM整理出的CNN/Daily Mail新闻数据被大量用作摘要训练集；指针-生成器摘要让模型既能生成新词也能从原文复制，并用覆盖机制减少重复。之后BART、PEGASUS摘要预训练等预训练模型成为主流，现在大模型直接写摘要，争论焦点变成忠实性：摘要里是否出现原文没有的内容。
