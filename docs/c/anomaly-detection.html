异常检测与分布外检测

Anomaly and Out-of-Distribution Detection

从大量正常数据中找出“不像其他样本”的少数异常：欺诈交易、设备故障、工业缺陷、网络入侵。异常往往罕见且没有标注，所以通常只用正常数据建模，再给偏离程度打分。

先要会：随机变量与概率分布 无监督学习

很多场景里，我们最关心的恰恰是极少发生的事：一笔可疑的转账、一台快要坏掉的电机、流水线上一个有划痕的零件。它们的特点是：样本极少，形态多种多样，而且新的异常类型会不断出现。直接训练一个“正常 vs 异常”的分类器往往行不通（见类别不平衡与长尾），因为没有足够的异常样本，也不可能列举所有异常。

基本思路：只用（或主要用）正常数据学出“正常长什么样”，再给每个新样本一个异常分数，超过阈值就报警。

几类方法。

  • 统计方法：假设数据服从某个分布（如高斯分布或高斯混合模型），密度很低的点就是异常。最简单的是z分数：偏离均值超过3个标准差即报警。多维时用马氏距离，考虑各维度之间的相关性（见协方差矩阵）。也可以用核密度估计做非参数估计。
  • 距离与密度：离最近的k个邻居都很远的点（见k近邻），或局部密度明显低于邻居的点（LOF）是异常。
  • 孤立森林：随机选特征、随机切分，异常点因为“离群”，通常只需很少几刀就被单独切出来，路径越短越异常。
  • 单类分类：One-Class SVM等在特征空间里画一个尽量紧的边界把正常数据包起来（见核技巧与间隔）。
  • 重建误差：用正常数据训练一个自编码器，它只学会了重建正常样本；异常样本重建不好，误差大。工业视觉缺陷检测常比较测试图像的深度特征与正常图像特征库之间的距离。

与分布外检测的关系。深度学习中常说的OOD检测（out-of-distribution detection）问的是“这个输入是否来自训练分布之外”，例如让猫狗分类器识别出一张汽车图片并拒绝回答。常用信号包括最大softmax概率、能量分数、模型集成的分歧（见深度集成和分布偏移）。它和异常检测是同一类问题在不同场景下的叫法。

评测。异常样本稀少，通常报告ROC AUC、PR曲线下面积，或在固定误报率下的检出率（见c:roc-auc）。

例子

服务器每分钟的请求延迟平时均值为50ms、标准差10ms。某一分钟延迟95ms，z = (95 − 50)/10 = 4.5，远超3的阈值，触发报警。如果延迟本身有昼夜周期，单一的均值方差就会在高峰期大量误报，需要按时段建模。

容易误解的地方

  • 训练用的“正常数据”里混入了异常，模型会把它们也当成正常；数据清洗和稳健的统计量（如中位数）很重要。
  • 自编码器有时“太会重建”，连异常也能重建得很好，导致漏检。
  • 阈值决定了误报与漏报的平衡，应由业务代价决定，而不是固定用某个数。
