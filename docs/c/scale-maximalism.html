规模至上路线

Scale Maximalism

也叫：规模假说　Scaling Hypothesis　苦涩的教训　Bitter Lesson　Scale is all you need　大力出奇迹　堆算力　scaling派　规模信仰　scaling maximalism　规模撞墙　scaling wall

在交互版中打开（看它长在树上的哪里）

相信通用方法加上更多算力和数据就能不断带来更强能力，而不必依赖人类设计的巧思；它也是近十年最大的路线押注。

这条思路的经典表述是Sutton的苦涩的教训：七十年的AI史表明，利用算力的通用方法（搜索与学习）最终总是胜过注入人类知识的方法。语言模型的规模定律给出了损失随规模按幂律下降的实证曲线，GPT-3之后Gwern写下规模假说，主张继续放大就会得到更通用的能力；Chinchilla修正了数据与参数的配比。

这一信念支撑了此后数百亿美元的算力投资（云厂商资本开支竞赛）。2024年底的规模撞墙与预训练终结论之争让它第一次受到大范围质疑：单纯放大预训练似乎收益递减，数据也接近用尽。支持者的回应是扩展的维度变了——推理时计算（OpenAI o1推理模型）、强化学习、从经验中学习（《经验时代》）都是新的“规模”。反对者（Sutton：LLM是死路、LeCun离开Meta创办AMI）则认为模仿人类文本的大模型本身就到不了通用智能。
