波形、频谱与梅尔谱

Waveform, Spectrogram and Mel

也叫：频谱图　语谱图　梅尔频谱　mel spectrogram　STFT　短时傅里叶变换　MFCC

在交互版中打开（看它长在树上的哪里）

声音在计算机里是一串按固定频率采样的振幅值（波形）。把它切成短帧做傅里叶变换得到“时间×频率”的频谱图；再按人耳的感知把频率轴压缩，就是语音模型最常用的梅尔谱。

先要会：傅里叶变换与频域 向量、矩阵与张量

麦克风记录的是气压随时间的变化。数字化时每隔固定时间取一个值，每秒取的次数叫采样率：电话语音8kHz，语音识别常用16kHz，音乐常用44.1kHz或48kHz。按采样定理，采样率为f_s时最多能表示f_s/2以下的频率，16kHz足以覆盖语音最重要的部分。这串数就是波形，是一个一维向量、矩阵与张量意义上的长向量。

为什么不直接用波形。1秒16kHz的语音就有16000个数，数值剧烈振荡，很难直接看出“这是哪个音”。而人耳和语言学都更关心频率成分：不同元音在不同频率上能量不同。

短时傅里叶变换（STFT）与频谱图。声音的频率成分随时间变化，所以不能对整段做一次傅里叶变换与频域，而是切成很短的、相互重叠的帧，每帧单独变换：

  • 帧长常取25毫秒（16kHz下400个采样点），帧移10毫秒（160个点），每秒得到100帧。
  • 每帧做FFT得到各频率的能量。把所有帧排在一起，就是一张横轴时间、纵轴频率的图，即频谱图。语音模型因此常可以借用图像的方法。

梅尔谱。人耳对低频的变化敏感，对高频不敏感：100Hz和200Hz听起来差很多，7100Hz和7200Hz几乎听不出差别。梅尔刻度模拟这种感知：m = 2595·log₁₀(1 + f/700)。用几十个在梅尔刻度上等间距的三角形滤波器把频谱合并成80个左右的通道，再取对数，就是对数梅尔谱。传统的MFCC特征在此基础上再做一次离散余弦变换。

它在哪里。Whisper的输入是80通道的对数梅尔谱；SpecAugment在梅尔谱上遮挡时间段和频带做增强；Tacotron 2等TTS模型先预测梅尔谱，再由声码器还原成波形，见声码器与音频编解码。WaveNet则直接生成波形采样点。

例子

16kHz采样的1秒语音是16,000个数。用25毫秒帧长（400点）、10毫秒帧移（160点）切帧，约得到100帧；每帧做512点FFT得到257个频率箱，1秒的频谱图就是约100×257的矩阵。再用80个梅尔滤波器压缩，变成100×80，这正是Whisper类模型的输入规模。

梅尔刻度换算：m(1000Hz) = 2595×log₁₀(1 + 1000/700) ≈ 1000；m(4000Hz) ≈ 2146；m(8000Hz) ≈ 2840。从4000Hz到8000Hz频率翻倍，梅尔值只增加了约700，而0到1000Hz就占了1000。所以梅尔滤波器在低频排得密，在高频排得疏。

容易误解的地方

  • 频谱图只保留了幅度，丢掉了相位，不能直接逆变换回原始波形，这正是需要声码器的原因。
  • 帧长的选择是时间分辨率与频率分辨率之间的权衡：帧越长频率越精细，但时间上越模糊。
  • 不同工具对梅尔刻度有不同公式（HTK和Slaney两种常见版本），复现实验时要用同一种。
