随机博弈与Dec-POMDP

Stochastic Games and Dec-POMDPs

也叫：随机博弈　stochastic game　马尔可夫博弈　Markov game　Dec-POMDP　去中心化POMDP　decentralized POMDP　联合动作　joint action　一般和博弈　general-sum game　合作博弈　cooperative game　团队博弈　非平稳性　non-stationarity　多智能体非平稳

多智能体版本的MDP：多个智能体同时选动作，联合动作决定状态转移，每个智能体有自己的奖励。所有人共享一个奖励且各自只看到局部观测时，叫Dec-POMDP。

先要会：马尔可夫决策过程 博弈论基础与纳什均衡

单智能体的马尔可夫决策过程里，环境只对“我”的动作作出反应。足球、扑克、多机器人搬运、自动驾驶车流里，结果同时取决于很多决策者。要写下这类问题，最常用的模型是随机博弈（stochastic game），也叫马尔可夫博弈（Markov game），由Shapley在1953年提出（Shapley随机博弈），马尔可夫博弈把它引入了强化学习。

定义。(N, S, {A_i}, P, {R_i}, γ)：N个智能体；每一步所有人同时选动作，组成联合动作a = (a₁, …, a_N)；转移P(s'|s, a)和每个人的奖励R_i(s, a)都依赖联合动作。只有一个状态时就退化为普通的矩阵博弈（见博弈论基础与纳什均衡）。

按奖励结构分三类。

  • 完全合作：所有人奖励相同（团队问题），目标是共同最大化。
  • 完全竞争：两人零和，R₁ = −R₂，如围棋、扑克一对一。
  • 一般和（general-sum）：利益部分一致部分冲突，如交通、谈判、社会困境，最优的含义也变得不唯一，见Nash-Q一般和博弈学习。

Dec-POMDP。合作且每个智能体只能看到自己的局部观测o_i、只能根据自己的观测历史行动时，问题称为去中心化部分可观测MDP。即使是有限时域，精确求解的计算复杂度也极高，所以实践中依赖近似方法。

为什么比单智能体难。

  • 非平稳性：从任何一个智能体看，其他人也在学习，“环境”一直在变，单智能体算法的收敛保证不再成立。最直接的做法独立Q学习多智能体就受此困扰。
  • 联合动作空间爆炸：每人5个动作、10个智能体，联合动作就有约977万种。
  • 多智能体信用分配：团队拿到一个总分，谁贡献了多少？

这催生了集中训练、分散执行、值分解（QMIX值分解）等一系列方法，整体脉络见多智能体强化学习。

例子

两台机器人一起抬一张桌子。状态是桌子的位置和角度，每台机器人的动作是向哪个方向用力（5种），联合动作共25种。只有两台同时向同一方向用力，桌子才平稳移动，二者共享奖励：这是一个完全合作的随机博弈。若它们只能看到自己那一端的摄像头画面，问题就成了Dec-POMDP。

容易误解的地方

  • “多智能体”不一定要用多智能体算法：若其他智能体的策略固定，从单个智能体看它们只是环境的一部分。
  • 随机博弈假设所有人同时行动；轮流行动的博弈（如棋类）可以看作它的特例，也常单独用扩展式博弈描述。
