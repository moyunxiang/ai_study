遗憾与遗憾界

Regret and Regret Bounds

也叫：遗憾　regret　累积遗憾　cumulative regret　遗憾界　regret bound　次线性遗憾　亚线性遗憾　sublinear regret　无遗憾学习　no-regret learning　极小极大遗憾　minimax regret　伪遗憾　pseudo-regret

在交互版中打开（看它长在树上的哪里）

衡量“边学边做”代价的指标：与一开始就知道最优选择相比，学习过程中累计少拿了多少奖励。好的算法遗憾随时间亚线性增长，即平均每步的损失趋于0。

先要会：探索与利用 期望与方差

评价一个探索策略，只看它最终学到的策略不够：一个算法花一百万次乱试才学会，另一个花一千次，最终都是最优，代价却天差地别。在推荐、广告、临床试验这类“每次决策都是真金白银”的场景里，学习期间的损失本身就是要优化的对象。

定义（多臂老虎机）。设最好的臂平均奖励为μ*，算法在T轮里依次选择a₁…a_T：

Regret(T) = T·μ* − E[Σ_{t=1}^T μ_{a_t}] = Σ_a Δ_a · E[N_a(T)]

Δ_a = μ* − μ_a是选错一次的代价，N_a(T)是臂a被选的次数。所以遗憾就是“每个次优臂被选了几次 × 每次亏多少”。

增长速度才是重点。

  • 永远只利用（可能锁死在错的臂上）或固定ε的ε-贪心与玻尔兹曼探索：遗憾线性增长，平均每步的损失不趋于0。
  • UCB1、Thompson采样（Thompson采样的复兴）：遗憾按O(log T)增长。Lai–Robbins遗憾下界证明这已是与具体问题相关意义下的最优阶。
  • 不依赖具体问题的最坏情形下，K个臂的遗憾下界是Ω(√(KT))量级。

“亚线性遗憾”（Regret(T)/T → 0）是一个算法“终究学会了”的最低要求。

在MDP里。按回合计：Σ_k [V*(s₁) − V^{π_k}(s₁)]，π_k是第k个回合用的策略。UCRL2遗憾界、UCBVI极小极大遗憾界、Q学习的UCB遗憾界等工作给出了表格MDP的遗憾界，通常随状态数、动作数、时域和√T增长，见上置信界与乐观原则。

在博弈和在线学习中。对手可以任意出招时，遗憾定义为“与事后看来最好的固定策略相比”的差距。若双方都使用无遗憾算法，零和博弈中双方的平均策略收敛到博弈论基础与纳什均衡，这就是遗憾匹配和反事实遗憾最小化CFR求解扑克的原理；对抗老虎机的算法见对抗老虎机EXP3。

例子

两个臂，平均奖励0.6和0.5，Δ=0.1，T=10000。

  • 固定ε=0.1：每步约有5%的概率选错，遗憾≈10000×0.05×0.1 = 50，T翻倍遗憾也翻倍。
  • 某个对数遗憾的算法：假设次优臂被选的次数约为c·ln T，c=50时，T=10000约选460次，遗憾约46；T=100万时约691次，遗憾约69，只增加了一半左右。

容易误解的地方

  • 遗憾界里的常数和与问题相关的量（如Δ很小）往往很大，渐近阶好的算法在小T时不一定更好。
  • 遗憾衡量的是学习过程中的损失，与样本效率与样本复杂度中“需要多少样本才能找到ε-最优策略”是两个相关但不同的标准。
