线性层（全连接层）

Linear (Fully Connected) Layer

也叫：线性层　全连接层　fully connected layer　FC层　FC layer　linear layer　Linear layer　nn.Linear　稠密层　dense layer　仿射变换　affine transformation　权重矩阵　weight matrix　偏置　投影层　projection layer　线性投影　linear projection

在交互版中打开（看它长在树上的哪里）

神经网络最基本的一层：y = Wx + b，权重矩阵乘输入再加偏置。也叫全连接层或稠密层，每个输出依赖每个输入；Transformer的大部分参数都在这类层里。

先要会：矩阵乘法与线性变换 向量、矩阵与张量

打开任何一个神经网络的代码，出现次数最多的组件就是线性层（PyTorch里的nn.Linear，Keras里叫Dense）。

定义。输入是长度为d_in的向量x，输出是长度为d_out的向量y：

y = W·x + b

W是d_out×d_in的权重矩阵，b是长度d_out的偏置向量。输出的第i个分量是y_i = Σ_j W_ij·x_j + b_i，即对所有输入加权求和，所以叫全连接：每个输出与每个输入之间都有一个权重（见矩阵乘法与线性变换）。参数量是d_in·d_out + d_out。一批输入X（形状为批大小×d_in）一次算完：Y = X·Wᵀ + b，偏置靠广播与einsum中的广播加到每一行上。

为什么一定要配非线性。两个线性层直接叠加，W₂(W₁x + b₁) + b₂仍然是一个线性函数，叠多少层都等价于一层。所以层与层之间要插入激活函数（见神经元与激活函数），由此构成多层感知机。

它的反向传播。设损失对输出的梯度为g，则∂L/∂W = g·xᵀ（一个外积），∂L/∂b = g，传回输入的梯度是Wᵀg（推导见矩阵求导）。训练线性层的计算量约为前向的两倍，所以一个参数每处理一个token大约需要6次浮点运算（前向2次、反向4次），这是估算训练算力的常用经验式，见参数量、计算量与显存。

它在哪里出现。

  • Transformer的每一层里，Q、K、V、输出投影和前馈网络都是线性层，它们占了模型参数的绝大部分（见Transformer层的结构）；混合专家把前馈部分的线性层复制成多个专家。
  • 分类器的最后一层是一个线性层，把特征映射成各类的logits（见Softmax与logits）；语言模型的输出层把隐状态映射到整个词表，常与输入嵌入共享权重（输入输出嵌入共享）。
  • 线性探针：冻结预训练模型，只在其特征上训练一个线性层，用来衡量表示的质量（线性探针，见特征与表示学习）。
  • LoRA在冻结的线性层旁边加一对低秩矩阵，只训练它们（见低秩近似）。
  • 1×1卷积就是对每个空间位置独立应用同一个线性层（见1×1卷积与全局平均池化）。

例子

d_in = 768、d_out = 3072的线性层有768×3072 + 3072 = 2,362,368个参数。输入一个长为1024个token的序列（形状1024×768），输出形状为1024×3072，前向约需2×1024×768×3072 ≈ 48亿次浮点运算。

容易误解的地方

  • 线性层不保留输入的空间或顺序结构：把图像展平后接线性层，像素位置的邻近关系就丢失了，这正是卷积层要解决的问题（见卷积层、池化与感受野）。
  • 很多框架把W存成d_out×d_in（PyTorch），也有存成d_in×d_out的，读代码和加载权重时要注意是否需要转置。
