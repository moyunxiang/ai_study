相机模型与多视图几何

Camera Model and Multi-View Geometry

也叫：针孔相机　pinhole camera　相机内参　外参　对极几何　epipolar geometry　SfM　三维重建

在交互版中打开（看它长在树上的哪里）

描述三维空间中的点如何投影成照片上的像素：针孔相机模型给出单张图的投影公式，多视图几何利用多张照片之间的对应关系恢复深度和三维结构。

先要会：矩阵乘法与线性变换 图像作为张量 特征分解与奇异值分解

一张照片把三维世界压成了二维，深度信息丢了。要从照片里重建三维场景、估计相机怎么移动、或者让机器人知道物体离它多远，就必须精确知道“三维点→像素”的映射规则，以及多张照片之间满足什么几何约束。

针孔相机模型。相机坐标系下的点(X, Y, Z)（Z是沿光轴方向的深度）投影到像素(u, v)：

u = f_x·X/Z + c_x，v = f_y·Y/Z + c_y

f是以像素为单位的焦距，(c_x, c_y)是图像中心附近的主点。除以Z就是“近大远小”。这些参数组成内参矩阵K。世界坐标到相机坐标还要经过旋转R和平移t，称为外参。合起来用齐次坐标写成一次矩阵乘法与线性变换：

λ·(u, v, 1)ᵀ = K·[R | t]·(X, Y, Z, 1)ᵀ

多视图几何。单张图只能确定点在一条射线上；两台相机从不同位置看同一个点，两条射线的交点就是三维位置，这叫三角化。两个视图之间的对应点满足对极约束x'ᵀ F x = 0（F为基础矩阵），可以用来校验匹配和估计相对位姿。求解这些量常要用到特征分解与奇异值分解。系统阐述见《多视图几何》。

它在哪里。

  • 运动恢复结构（SfM）：从大量照片同时求相机位姿和三维点，再用光束法平差整体优化，如Photo Tourism和COLMAP。
  • SLAM：机器人边移动边定位边建图，如ORB-SLAM。
  • 神经渲染：NeRF和3D高斯泼溅都需要已知每张照片的相机参数（通常由COLMAP算出），沿着每个像素的射线渲染。
  • 前馈几何模型：DUSt3R、VGGT用神经网络直接从图像对或图像组预测三维点和相机，绕开了传统流程中的许多步骤。

例子

投影：相机焦距f_x=f_y=500像素，主点(320, 240)。相机坐标系下一点(1.0, 0.5, 4.0)米投影到u = 500×1.0/4.0 + 320 = 445，v = 500×0.5/4.0 + 240 = 302.5。如果把这个点沿光轴推远到Z=8米，它会落在(382.5, 271.25)，更靠近图像中心。

双目测深：两台平行相机相距B=0.1米，焦距500像素。同一点在左右图中的水平位置相差d=25像素（视差），深度Z = f·B/d = 500×0.1/25 = 2米。视差越小，物体越远；远处1像素的匹配误差会造成很大的深度误差。

容易误解的地方

  • 针孔模型忽略了镜头畸变，实际使用前通常要先标定并去畸变。
  • 单张图的尺度是不确定的：一个小模型放近一点和一个大物体放远一点，可以拍出完全一样的照片；单目方法要么只给相对深度，要么靠学到的先验猜绝对尺度。
  • 不同库的坐标约定（y轴朝上还是朝下、相机看向+Z还是−Z）不同，混用时极易出错。
