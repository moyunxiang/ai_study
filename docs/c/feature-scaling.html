特征缩放：标准化与归一化

Feature Scaling: Standardization and Normalization

也叫：特征缩放　feature scaling　标准化　standardization　z-score　z分数　z-score normalization　StandardScaler　最小-最大归一化　min-max normalization　min-max scaling　MinMaxScaler　归一化　数据归一化　数据标准化　稳健缩放　robust scaling　对数变换　log transform　白化　whitening　输入归一化　input normalization

把各个特征变换到相近的数值范围：标准化减均值除标准差，归一化压到[0, 1]。不同特征尺度差几个数量级时，梯度下降会很慢，基于距离的方法会被大尺度特征主导。

先要会：期望与方差 范数与距离

预测房价时，“面积”在50到500之间，“卧室数”在1到5之间，“建成年份”在1950到2025之间。直接把这些数喂给模型会出两类问题：

  • 基于距离的方法失真：k近邻、k-means聚类、带RBF核的支持向量机计算欧氏距离时，面积差100几乎决定了一切，卧室数差3可以忽略不计（见范数与距离）。
  • 梯度下降变慢：尺度不同的特征让损失曲面变成一条又窄又长的山谷，条件数很大，同一个学习率对一个方向太大、对另一个方向太小（见数值稳定性：上溢、下溢与条件数和收敛速率与强凸）。

常用方法。

  • 标准化（z-score）：x' = (x − μ) / σ，变换后均值0、标准差1。最常用的默认选择。
  • 最小-最大归一化：x' = (x − min) / (max − min)，压到[0, 1]。图像像素除以255就是这种。对离群点敏感：一个极大值会把其他所有值挤到0附近。
  • 稳健缩放：用中位数和四分位距代替均值和标准差，不受离群点影响。
  • 对数变换：收入、点击数、词频这类跨多个数量级、严重右偏的量，先取log(1 + x)再标准化。
  • 白化：不仅让每维方差为1，还去掉维度之间的相关性，使协方差矩阵变成单位阵（见协方差矩阵和降维与PCA）。

规则：统计量只能从训练集算。μ、σ、min、max必须只用训练集计算，再原样应用到验证集和测试集上；用全部数据计算等于把测试集的信息泄漏给了训练（见数据泄漏与基准污染）。

神经网络里的对应物。深度网络不仅缩放输入，也在网络内部对每层的激活做类似的标准化：Batch Normalization、Layer Normalization就是“可学习的特征缩放”，见归一化层。图像模型的输入通常按ImageNet的通道均值和标准差做标准化。决策树和XGBoost等树模型按阈值切分，对单调变换不敏感，基本不需要特征缩放（见决策树）。

例子

面积(100, 150, 200)：均值150、标准差约40.8，标准化后为(−1.22, 0, 1.22)。卧室数(2, 3, 4)：均值3、标准差约0.82，标准化后也是(−1.22, 0, 1.22)。缩放前，两套房子的欧氏距离几乎完全由面积决定；缩放后两个特征的贡献相当。

容易误解的地方

  • “归一化”一词在不同语境下含义不同：有时指最小-最大缩放，有时指标准化，有时指把向量除以其范数变成单位长度；读代码时要看具体公式。
  • 对稀疏特征（大多数为0）做减均值的标准化会破坏稀疏性，通常只除以标准差或最大绝对值。
