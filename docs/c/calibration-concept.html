模型校准

Calibration

也叫：置信度校准　温度缩放　temperature scaling　ECE　期望校准误差　过度自信　overconfidence

在交互版中打开（看它长在树上的哪里）

模型说“我有80%把握”时，在所有这类预测里它确实应该对约80%；满足这一点就叫校准良好。

先要会：Softmax与logits 随机变量与概率分布

分类模型通过Softmax与logits输出一个概率，但这个数字值得信吗？医疗诊断、自动驾驶、要决定“是否把问题转给人”的系统，不仅需要答案，还需要可靠的置信度。校准衡量的就是置信度与实际正确率是否一致。

定义：模型完美校准，当且仅当对任意p，P(预测正确 | 置信度 = p) = p。实际检验时把预测按置信度分成若干箱，每箱比较平均置信度与实际准确率。画成图叫可靠性图；把每箱的差距按样本数加权平均，得到期望校准误差ECE = Σ_b (n_b/n) · |acc_b − conf_b|。

现代网络过度自信。神经网络校准（2017）发现，与十年前的浅层网络相比，现代深层网络准确率更高，校准却更差：普遍高估自己的把握。深度、宽度、BatchNorm、较弱的权重衰减都会加重这一点。他们给出的修正方法极其简单——温度缩放：在验证集上学一个标量T，把logits除以T再做softmax。T > 1会让分布变平、降低过高的置信度，而且不改变哪个类最大，所以准确率不变。

其他方法：MC Dropout不确定性在测试时多次随机dropout取平均；深度集成训练多个独立模型取平均，通常校准更好；标签平滑也会影响校准。

在大模型里：GPT-4技术报告显示，预训练模型在选择题上的置信度相当校准，经过RLHF后训练校准明显变差。校准也与幻觉有关：模型如果知道自己不知道，就有机会选择不答。

例子

某模型的验证集预测分两箱：60%的样本置信度约0.90，实际准确率0.75；40%的样本置信度约0.60，实际准确率0.55。ECE = 0.6×|0.75 − 0.90| + 0.4×|0.55 − 0.60| = 0.09 + 0.02 = 0.11。

温度缩放：logits为[3, 1, 0]时softmax最大概率0.84；取T = 2，变成[0.63, 0.23, 0.14]，仍然预测第一类，但不再那么自信。

容易误解的地方

  • 校准好不等于准确率高：一个永远输出各类先验比例的模型可以完美校准，却毫无用处。
  • 在一个数据集上校准好，遇到分布偏移后往往又会过度自信。
  • ECE依赖分箱方式，箱数不同数值会变，不同论文的ECE不宜直接比较。
