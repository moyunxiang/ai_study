最优传输与Wasserstein距离

Optimal Transport and Wasserstein Distance

也叫：OT　推土机距离　Earth Mover's Distance　EMD　Sinkhorn

在交互版中打开（看它长在树上的哪里）

把一个概率分布“搬运”成另一个分布所需的最小总代价；用它定义的Wasserstein距离在两个分布完全不重叠时依然能给出有意义的远近。

先要会：随机变量与概率分布 KL散度

比较两个分布有多不同，常用KL散度。但KL有个缺陷：两个分布的支撑集不重叠时（比如两个相隔很远的尖峰），KL是无穷大，JS散度是常数log 2，无论它们相距1米还是1公里都一样，梯度为零。生成模型训练早期，生成分布和真实分布几乎总是不重叠的，这就成了问题。

最优传输换一个角度：把分布P看成一堆土，Q看成要填的坑，问把土搬过去最少要花多少功。设把位置x的单位质量搬到y的代价为c(x, y)，一个运输方案π(x, y)是一个联合分布，其边缘分布分别是P和Q。最优传输代价是

W(P, Q) = min_π E_{(x,y)~π}[c(x, y)]

当c是距离|x − y|时，这叫Wasserstein-1距离，也叫推土机距离（Earth Mover's Distance）。一维时有闭式解：等于两个累积分布函数之差的面积。

为什么好用：它感知“距离”。两个尖峰相距θ时，W₁ = |θ|，随θ平滑变化，梯度始终有意义。

在AI里：

  • Wasserstein GAN用Wasserstein距离代替原始GAN的JS散度作训练目标，利用对偶形式（判别器限制为1-Lipschitz函数）来估计它；WGAN-GP梯度惩罚用梯度惩罚实现这个约束，训练稳定了很多（见对抗训练）。
  • Flow Matching和整流Rectified Flow里，若噪声与数据之间按最优传输配对，学到的路径更直，少步采样更容易（见可逆流与流匹配）。
  • 离散情形可写成线性规划；加熵正则后可以用Sinkhorn迭代快速求近似解，常用于对齐、匹配类任务。

例子

P在位置0和1各有0.5的质量，Q在位置2和3各有0.5。最优方案是0 → 2、1 → 3，每份搬2个单位距离，W₁ = 0.5×2 + 0.5×2 = 2。（交叉搬运0 → 3、1 → 2代价同样是2，一维时代价为|x − y|的情况下这类方案都不会更便宜。）

再看两个尖峰：P在0，Q在θ。θ = 1时W₁ = 1，θ = 10时W₁ = 10；而它们之间的KL在两种情况下都是无穷大，JS散度都是log 2 ≈ 0.693，看不出远近。

容易误解的地方

  • 一般情况下精确求解很贵：n个点之间的最优传输是O(n³)量级的线性规划，所以实际都用近似（Sinkhorn、小批量、对偶网络）。
  • WGAN里判别器只是在近似Wasserstein距离，近似得好不好取决于Lipschitz约束执行得多严格。
  • 代价函数c的选择决定了“距离”的含义，换一个c结果可能完全不同。
