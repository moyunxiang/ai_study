分布假说

Distributional Hypothesis

也叫：分布式假设　distributional semantics　分布语义　由伴知词　上下文决定词义　共现

在交互版中打开（看它长在树上的哪里）

出现在相似上下文中的词，意思也相近。这个语言学假说让“从大量文本中自动学习词义”成为可能，是词向量和语言模型表示的理论起点。

先要会：嵌入向量 内积与余弦相似度 条件概率与贝叶斯公式

计算机怎样知道“猫”和“狗”意思相近、而和“汽车”相去甚远？一种办法是人工编词典，比如WordNet手工整理了词与词的上下位、同义关系，但成本高、覆盖有限、跟不上新词。另一种办法来自语言学：不去定义词义，而是观察词的用法。

假说。1954年，Harris分布假说提出，意义相近的词往往出现在相似的环境中；1957年，Firth：由伴知词义有一句常被引用的话：“由词的伴随者可以认识一个词”（You shall know a word by the company it keeps）。“猫”和“狗”都经常出现在“喂”“养”“可爱”附近，而“汽车”常出现在“开”“加油”附近。即使不知道这些词是什么意思，单凭上下文的统计也能判断前两者相似。

从假说到向量。把这个想法落到计算上：

1. 统计每个词与各个上下文词（比如前后5个词以内）共同出现的次数，得到一个共现矩阵：每个词一行，每个上下文词一列。 2. 每一行就是这个词的向量。用余弦相似度（见内积与余弦相似度）比较两个词的向量。 3. 原始计数会被“的”“是”这类高频词主导，常换成点互信息：PMI(w, c) = log [P(w, c) / (P(w)·P(c))]，衡量两者共现比随机情况多出多少（见条件概率与贝叶斯公式）。 4. 矩阵太大太稀疏，再用SVD压缩成几百维的稠密向量（见特征分解与奇异值分解）。潜在语义分析LSA（1990）就是这样做的。

神经网络时代。word2vec（2013）不显式建矩阵，而是训练一个浅层网络用一个词预测它周围的词（或反过来），得到的词向量（见嵌入向量）在类比任务上表现突出。GloVe直接拟合共现统计。word2vec即隐式矩阵分解证明，带负采样的word2vec在数学上近似于对移位后的PMI矩阵做分解——神经方法和计数方法本质上在做同一件事。

更广的意义。今天的大语言模型通过预测上下文中的词来学习，本质上也是在利用分布假说：一个词（或一段话）的表示由它能与哪些上下文搭配决定。

例子

一个小语料里统计了共现次数，上下文词依次是[喂, 养, 开, 加油]：

  • 猫 = [8, 6, 0, 0]
  • 狗 = [7, 7, 0, 1]
  • 汽车 = [0, 1, 9, 6]

余弦相似度：cos(猫, 狗) = (56 + 42)/(10 × 9.95) ≈ 0.985；cos(猫, 汽车) = 6/(10 × 10.86) ≈ 0.055；cos(狗, 汽车) ≈ 0.120。仅凭上下文统计，“猫”和“狗”几乎同义，与“汽车”几乎无关。

PMI。这张表总计数为45。P(猫, 喂) = 8/45，P(猫) = 14/45，P(喂) = 15/45，PMI = log₂[(8/45)/((14/45)×(15/45))] = log₂(360/210) ≈ 0.78比特：两者的共现概率是“彼此独立”时预期的约1.7倍。

容易误解的地方

  • 分布相似不等于同义：“热”和“冷”、“买”和“卖”上下文非常相似，但意思相反。基于分布的词向量常把反义词放得很近。
  • 一个词一个向量的做法无法区分多义词（“苹果”公司和水果混在同一个向量里）。上下文相关的表示（ELMo、BERT）解决了这一点。
  • 分布统计会如实反映语料中的社会偏见，例如职业词与性别词的关联。
