特征与表示学习

Features and Representation Learning

也叫：特征工程　feature engineering　特征提取　表征

在交互版中打开（看它长在树上的哪里）

特征是把原始数据转换成模型可用的一组数。过去由人手工设计特征，深度学习则让模型自己从原始数据中学出好的表示，这叫表示学习。

先要会：向量、矩阵与张量 监督学习

模型不能直接理解“一张图片”或“一句话”，它看到的只是一串数字。用什么数字来描述输入，决定了任务是简单还是困难。对同一个分类问题，换一种描述方式，可能从“无法用直线分开”变成“一个阈值就能分开”（见下面的例子）。

特征工程时代：深度学习之前，机器学习的大部分功夫花在设计特征上。视觉里有SIFT特征、HOG与手工特征时代，描述局部的梯度方向分布；语音里有梅尔频率倒谱系数；文本里有词频统计。好的手工特征需要多年领域经验，换个任务又要重来，而后面接的分类器（如逻辑回归、SVM）相对简单。

表示学习：让模型自己从原始数据（像素、波形、字符）中学出特征。多层神经网络的每一层都把上一层的输出变换成新的表示，最后一层之前的输出就是学到的特征，最后一层只是在这个特征上做一个简单的线性分类。卷积网络可视化把卷积网络各层的特征可视化，发现低层响应边缘和颜色，中层响应纹理和图案，高层响应物体部件——网络自己学会了从简单到复杂的层次化特征。表示学习综述系统总结了这一思路。

它出现在哪里：AlexNet学出的特征在ImageNet上大幅超过手工特征，是表示学习取代特征工程的转折点。学到的表示往往可以复用到别的任务上，这就是迁移学习；把离散对象（词、用户、商品）表示成向量就是嵌入向量。今天评估一个预训练模型的表示好不好，常用“冻结表示、只训练一个线性分类器”（linear probe）的准确率。

例子

二维平面上，单位圆内的点是正类，圆外的点是负类。用原始坐标(x₁, x₂)，任何一条直线都分不开它们。

增加一个特征r = x₁² + x₂²：点(0.5, 0.5)的r = 0.5，点(1, 1)的r = 2。现在只需一个规则“r < 1为正类”就完全分开了。换一个表示，困难的非线性问题变成了简单的线性问题。深度网络做的就是自动找出这样的变换。

容易误解的地方

  • “表示”和“特征”在多数论文里可以互换；“表示”更常用来指学出来的高维向量。
  • 学到的特征不一定是人能理解的，可视化出来的“边缘检测器”只是少数容易解释的例子。
