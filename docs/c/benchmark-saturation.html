基准饱和

Benchmark Saturation

也叫：基准饱和　榜单饱和　刷满　刷爆　saturated benchmark　ceiling effect　天花板效应　考卷失效　基准寿命　benchmark lifespan　失去区分度

在交互版中打开（看它长在树上的哪里）

一个基准被模型刷到接近满分后，分数再也拉不开差距，社区只好造更难的新考卷，这个循环越来越快。

GLUE / SuperGLUE发布不到两年就被预训练模型超过人类基线，于是有了SuperGLUE；MMLU被刷到九成后出现MMLU-Pro、GPQA和Humanity's Last Exam；中文的C-Eval中文评测也走过同样路线。数学从GSM8K、MATH竞赛数学走到FrontierMath和IMO-Bench；抽象推理从ARC-AGI的第一版被o3攻破ARC-AGI-1攻破，到ARC-AGI-2、ARC-AGI-3交互式基准。

饱和不只是题太简单：题目公开后可能进入训练数据，标注错误让满分本身不可能，剩下的错题常是有争议的题。第三方综合指数Artificial Analysis智能指数和Epoch能力指数ECI的版本历史就是一份饱和记录：每次换掉的成分都是不再有区分度的考卷。现在的应对方式有三类：出更难的专家题、持续更新题库（见动态基准）、改测真实工作和时间跨度（METR任务时间跨度）。
