仿真到现实的差距

The Sim-to-Real Gap

也叫：Sim2Real　仿真到真实　现实差距　reality gap　域随机化　domain randomization

在交互版中打开（看它长在树上的哪里）

在物理仿真里训练机器人又快又安全，但仿真与现实在物理参数、画面、延迟和噪声上总有差距，仿真里学会的策略搬到真机上常常失效；缩小这个差距就是Sim2Real问题。

先要会：状态、观测与动作 分布偏移

策略梯度这类强化学习方法要试错几百万次才学得会，真机器人既不可能跑这么多次（慢、会坏、会伤人），也没法自动“重置”到初始状态。仿真器则可以同时跑几千个机器人、比实时快很多倍、摔坏了也无所谓。于是一条自然的路线是：在仿真里学，到现实中用。问题在于仿真永远不是现实。

差距来自哪里。一是动力学：摩擦系数、物体质量、电机响应、关节间隙、接触时的碰撞与形变都只能近似，而接触恰恰是操作任务的关键。二是感知：渲染出的图像在光照、纹理、反光、噪点上和真实相机不同。三是时间：真实系统有传感器和计算延迟，仿真里往往是零延迟。四是未建模的现象：线缆、软物体、液体。策略会利用仿真里不真实的漏洞（例如穿模或过于理想的摩擦），这些在现实中都不成立。

主要办法。

  • 域随机化：训练时把质量、摩擦、颜色、光照、延迟等参数在一个范围内随机取，只要现实落在这个范围里，策略就把现实当成又一种随机情况，见域随机化与Sim2Real、机械手解魔方。
  • 系统辨识：在真机上测量参数，把仿真调得更像现实；或者学习一个修正模型，见ASAP仿真-现实对齐。
  • 在线适应：让策略根据最近的观测历史推断当前环境参数，见RMA快速运动适应。
  • 减少对外观的依赖：只用本体感知、深度图，或用预训练视觉特征。

为什么足式运动成功、操作仍难。足式机器人强化学习以后，四足和人形机器人的行走几乎都在Isaac Gym大规模并行仿真这类GPU并行仿真里训练、零样本迁移到真机，因为行走主要依赖本体感知，地面接触相对简单。灵巧操作涉及复杂接触和视觉，仿真差距大得多，所以目前操作类VLA主要靠真机遥操作数据（见遥操作与示教数据），仿真更多用于评测（SIMPLER仿真评测）和数据扩增。

它出现在哪里：从MuJoCo物理仿真到Isaac Gym大规模并行仿真、Genesis物理引擎，仿真器的速度和逼真度不断提高；视频世界模型被视为另一种“学出来的仿真器”，有望绕开手工建模的差距。

例子

一个四足机器人的行走策略在仿真里训练时，每局随机设定：地面摩擦系数在0.4到1.2之间、机身负重在0到5kg之间、电机强度在标称值的80%到120%之间、动作延迟在0到20毫秒之间。如果用4096个机器人并行，每个都按实时速度跑1小时，就积累了4096个机器人小时，约170天的经验——这在真机上需要一台机器人连续摔半年。

容易误解的地方

  • 随机化范围越大越稳健，但策略也会变得保守、性能下降；范围要覆盖现实又不能过宽。
  • 仿真跑得通、真机失败，不一定是物理参数问题，延迟、坐标系约定、动作缩放这类工程差异同样常见。
  • “零样本Sim2Real”只说明没在真机上微调，不代表没有针对真机做过参数调整。
