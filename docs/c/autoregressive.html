自回归生成

Autoregressive Generation

也叫：因果语言建模　causal language modeling　CLM　自回归语言模型　AR　autoregressive model　逐词生成　next-token prediction　下一个词预测　因果语言模型

在交互版中打开（看它长在树上的哪里）

一次只生成一个元素、把它接到已有序列后面再生成下一个的生成方式。模型只需学会“给定前面，下一个是什么”，就能生成任意长的序列。

先要会：语言模型 条件概率与贝叶斯公式 自注意力与多头注意力

直接对“一整段文字”或“一整张图片”建模非常困难：可能的组合是天文数字，没法给每一种都学一个概率。自回归把这个大问题拆成一串小问题。

定义。由概率的链式法则（见条件概率与贝叶斯公式），任何序列的联合分布都可以精确地分解为：

p(x_1, …, x_n) = Π_t p(x_t | x_1, …, x_(t−1))

模型只学每一个条件分布p(x_t | x_<t)：输入前缀，输出下一个元素的分布。这一步不是近似，只要每个条件分布学得准，整体分布就是准的。“自回归”一词来自统计学的时间序列模型，意思是用序列自己过去的值来预测现在的值。

生成：串行。从起始符号开始循环：

1. 把当前序列输入模型，得到下一个token的概率分布。 2. 按某种策略选出一个token（见解码：贪心、束搜索、温度与top-p）。 3. 把它接到序列末尾；如果是结束符就停止，否则回到1。

生成n个token就要做n次前向计算，每一次都依赖上一次的结果，无法并行。这是大语言模型推理慢的根本原因，KV缓存和推测解码都是为了缓解它。

训练：并行。训练时整个正确序列是已知的，可以一次性把它输入模型，在所有位置同时预测下一个token、同时计算损失。用Transformer时靠因果掩码保证第t个位置看不到t之后的内容（见自注意力与多头注意力）。训练时每一步输入的都是真实前缀而不是模型自己生成的结果，这种做法叫teacher forcing（见Teacher forcing与曝光偏差）。

不只是文本。任何能排成序列的数据都可以这样生成：神经自回归NADE和PixelRNN / PixelCNN逐像素生成图像；WaveNet逐个采样点生成音频；Image GPT把像素当token；视觉自回归VAR改为按分辨率从粗到细逐级生成。语言方面，GPT-2以来的大语言模型都是自回归的。与之相对的是一次并行生成全部或多个元素的方法，如扩散语言模型LLaDA大语言扩散模型。

例子

生成“今天天气很好。”（假设每个汉字或标点是一个token）

  • 输入[今天天气]，模型给出：很 0.4、不 0.3、真 0.2……取“很”。
  • 输入[今天天气很]，模型给出：好 0.6、热 0.2、冷 0.1……取“好”。
  • 输入[今天天气很好]，模型给出：。0.5、，0.3……取“。”。
  • 再下一步取到结束符，停止。

这句话的概率是0.4 × 0.6 × 0.5 × P(结束符 | …)。生成3个字就做了4次前向计算。

训练时，同一句话只需1次前向：输入“今 天 天 气 很 好 。”，模型在每个位置同时输出对下一个字的预测，6个位置的损失一起算。

容易误解的地方

  • 自回归的顺序是人为选定的：文本自然是从左到右，图像的“先上后下、先左后右”则是一种约定，不一定最好。
  • 每一步只能看前面，不能修改已经生成的内容。早期的一个错误会一直影响后面。
  • 训练时并行、推理时串行，这两者的计算特性完全不同：训练受算力限制，逐token推理往往受显存带宽限制。
