正交矩阵与正定矩阵

Orthogonal and Positive Definite Matrices

也叫：正交矩阵　orthogonal matrix　酉矩阵　unitary matrix　正定矩阵　positive definite　positive definite matrix　正定　半正定　半正定矩阵　positive semidefinite　PSD　PSD matrix　谱定理　spectral theorem　对称矩阵　symmetric matrix　正交初始化　orthogonal initialization　正交化

两类性质特别好的矩阵：正交矩阵只旋转或翻转、不改变长度；正定（半正定）矩阵对应一只“向上开口的碗”，协方差矩阵、核矩阵和凸函数的海森矩阵都属于这一类。

先要会：向量、矩阵与张量 特征分解与奇异值分解

读论文时经常看到“初始化为正交矩阵”“协方差矩阵是半正定的”“海森矩阵正定所以是极小值”。这两类矩阵各自对应一种很好的几何性质。

正交矩阵。方阵Q满足QᵀQ = I，即它的列向量两两垂直且长度为1。于是Q⁻¹ = Qᵀ，求逆免费；而且‖Qx‖ = ‖x‖，它只做旋转或镜像翻转，不拉伸也不压缩任何方向，所有奇异值都等于1。

正定与半正定。对称矩阵A如果对任意非零向量x都有xᵀAx > 0，就叫正定；允许等于0则叫半正定（PSD）。等价说法：全部特征值大于0（或大于等于0）。二次函数f(x) = xᵀAx在A正定时是一只碗，只有一个最低点；半正定时碗底可能是一条平坦的沟。

谱定理把两者联系起来：任何实对称矩阵都能写成A = QΛQᵀ，Q正交、Λ是特征值组成的对角阵。也就是说，对称矩阵就是“先转到某组正交坐标轴上，沿各轴分别缩放，再转回来”，见特征分解与奇异值分解。

它们出现在哪里。

  • 协方差矩阵矩阵和核方法里的核矩阵（见核技巧与间隔）一定是半正定的；一个函数能不能当核，判据就是它生成的矩阵是否总是半正定。
  • 二阶可导函数是凸的，当且仅当雅可比矩阵与海森矩阵中的海森矩阵处处半正定，见凸函数与凸优化；梯度为0的点海森正定则是严格极小值，有正有负则是鞍点（高维优化的鞍点问题）。
  • 深度线性网络与正交初始化分析了正交初始化：权重是正交阵时，信号穿过很多层也不会被放大或衰减，有助于缓解梯度消失与梯度爆炸。
  • Muon优化器优化器把更新矩阵近似正交化后再使用，让每个方向的步长相同。

例子

旋转45°的矩阵Q = [[0.707, −0.707], [0.707, 0.707]]，QᵀQ = I。把x = (3, 4)（长度5）变换后得(−0.71, 4.95)，长度仍是5。

A = [[2, 1], [1, 2]]特征值为3和1，都为正，所以正定：取x = (1, −1)，xᵀAx = 2 − 1 − 1 + 2 = 2 > 0。B = [[1, 2], [2, 1]]特征值为3和−1，不定：x = (1, −1)时xᵀBx = −2 < 0，f(x) = xᵀBx的图像是马鞍形。

容易误解的地方

  • 正定的定义通常默认矩阵对称；非对称矩阵的“正定”需要额外约定，读公式时要留意。
  • 正交矩阵的行和列都是单位长度、两两垂直，不只是“垂直”；列只是两两垂直而长度不为1的矩阵不是正交矩阵。
