批大小、步数与轮数

Batch Size, Steps and Epochs

也叫：epoch　iteration　迭代　training steps　轮次　批量大小

在交互版中打开（看它长在树上的哪里）

批大小是每步用多少样本算梯度；一步（step/iteration）是一次参数更新；一轮（epoch）是把整个训练集完整过一遍。三者的关系是：每轮步数 = 样本数 ÷ 批大小。

先要会：随机梯度下降与小批量

读论文的训练细节时，总会看到“batch size 256，训练90 epochs”或“训练了30万步、每步400万token”。这些描述的是训练的“量”，弄清它们才能比较不同工作花了多少计算、看了多少数据。

  • 批大小（batch size，B）：每次更新参数时用于估计梯度的样本数，见随机梯度下降与小批量。
  • 步（step，也叫iteration）：完成一次“前向—反向—更新参数”。
  • 轮（epoch）：训练集里每个样本都被用到一次。数据量为N时，一轮约N/B步。
  • 总步数 = 轮数 × 每轮步数；总共处理的样本数 = 总步数 × B。

图像任务传统上按轮数说，如CIFAR训练几百轮、ImageNet训练90轮；大语言模型则改用token数计：语料可能有数万亿token，模型往往只把大部分数据看一遍甚至不到一遍，所以说“训练了多少token”比说轮数更有意义，批大小也常用“每步多少token”表示。

批大小怎么选：它受显存限制（每个样本的中间激活都要存着反传），也影响训练动态。批越大，梯度噪声越小、硬件利用率越高，但每个样本带来的进步会递减；增大批大小通常要同步调大学习率与学习率调度。学习率预热与大批量SGD把ImageNet的批扩到8192仍保持精度，大批量与尖锐极小值则报告大批量可能损害泛化，二者共同塑造了“批大小与学习率要一起调”的共识。显存不够时可以用梯度累积：连续算几个小批的梯度加起来再更新一次，等效于更大的批。

例子

CIFAR-10有50000张训练图，批大小128：每轮需要⌈50000/128⌉ = 391步（最后一批不满），训练200轮共78200步。

一个语言模型每步处理400万个token，总共训练1万亿token，就是1×10¹²÷4×10⁶ = 250000步。

容易误解的地方

  • 论文里的“batch size”可能是单卡的，也可能是所有卡加起来的全局批大小，要看清楚。
  • 比较两个方法时，按轮数对齐和按计算量对齐可能得出不同结论。
