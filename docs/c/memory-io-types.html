内存与总线的种类：DDR、GDDR、HBM、PCIe、NVMe

Memory and I/O Types

计算机里几类内存和总线的分工：DDR是CPU的主内存，LPDDR是省电的移动版，GDDR是消费级显卡的显存，HBM是数据中心加速器上堆叠的高带宽显存；PCIe连接CPU与GPU、SSD，NVMe是走PCIe的固态硬盘协议。

先要会：显存、内存带宽与“内存墙” CPU、GPU与并行计算

选显卡、读芯片发布会、估算模型能不能在本地跑，都会遇到LPDDR5X、GDDR7、HBM3e、PCIe Gen5这些名字。它们回答的是同一个问题的不同环节：数据存在哪里、能多快送到计算单元（见显存、内存带宽与“内存墙”）。

几类DRAM（都是动态随机存取内存，区别在封装方式和取舍）。

  • DDR：服务器和台式机CPU的主内存，插在主板的内存条上。容量大、单价低，可以到TB级，但每个CPU插槽的带宽只有几百GB/s以内。
  • LPDDR：低功耗版本，焊在主板或封装旁边，用于手机、笔记本和部分芯片（如统一内存的笔记本芯片、部分数据中心CPU）。功耗低，带宽与容量介于DDR和显存之间。
  • GDDR：消费级和工作站显卡的显存，焊在GPU周围，带宽高于DDR，例如RTX 4090与本地大模型的24GB显存带宽约1TB/s，见本地跑大模型的硬件。
  • HBM：把多层DRAM芯片垂直堆叠、通过硅中介层与GPU封装在一起，接口极宽，带宽可达每秒数TB，是数据中心AI加速器的标配，也是供应最紧张的部件，见HBM高带宽内存和HBM与AI内存竞赛。代价是容量受限、价格高。

总线与互连。

  • PCIe：CPU与GPU、网卡、SSD之间的标准总线，按代际每代带宽约翻倍，x16的Gen4约32GB/s、Gen5约64GB/s（单向）。与显存带宽相比要慢一两个数量级，所以模型参数在CPU内存和显存之间来回搬（卸载）代价很大。
  • NVMe：走PCIe的SSD协议，顺序读写可达每秒数GB，用于存数据集和检查点（见模型检查点与容错训练、数据加载流水线）。
  • GPU之间：机内用NVLink与NVSwitch这类专用互连，带宽远高于PCIe；跨机用网络，见互连：从芯片到机柜到集群。CXL内存互连则是在PCIe物理层上实现内存共享与扩展的协议。

一个层次的直觉：越靠近计算单元越快、越小、越贵：寄存器与片上SRAM → HBM/GDDR → CPU的DDR/LPDDR → NVMe SSD → 网络存储。

例子

想在一台装有RTX 4090（24GB GDDR、约1TB/s）的电脑上跑一个量化后约40GB的模型：放不进显存，只能把一部分层放在CPU的DDR内存里，每生成一个token都要经PCIe 4.0（约32GB/s）读取约16GB的那部分权重，单这一项就需要约0.5秒，而全部放在显存里时读一遍40GB约需0.04秒。

容易误解的地方

  • 厂商宣传的内存带宽常是双向合计或理论峰值，实际可用值通常更低。
  • “统一内存”（CPU和GPU共用一块LPDDR）容量大，但带宽一般低于同价位的独立显卡，适合放下大模型但生成速度受限。
