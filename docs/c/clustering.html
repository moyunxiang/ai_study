聚类

Clustering

也叫：聚类分析　k-means　K均值　cluster analysis　无监督聚类　簇

在交互版中打开（看它长在树上的哪里）

在没有标签的情况下，把相似的样本自动分成若干组，使组内的样本彼此接近、组间的样本相距较远。k-means是最常用的方法。

先要会：无监督学习 范数与距离

拿到一批数据而没有任何标签时，最自然的问题之一是：它们是否自然地分成了几类？用户可能分成几种消费习惯，文档可能属于几个话题，图像可能来自几种物体。聚类是无监督学习中最基本的任务，用来发现这种分组。

k-means（k-means聚类）是最常用的算法。先指定组数k，然后交替执行两步：

1. 分配：每个点归到离它最近（通常用欧氏距离，见范数与距离）的中心所在的组。 2. 更新：把每个中心移到本组所有点的平均位置。

重复直到分组不再变化。它在最小化“每个点到所属中心的距离平方和”，每一步都不会让这个目标变大，所以一定会停下来，但只保证停在局部最优，结果与初始中心有关，实践中常多次随机初始化取最好的一次。

其他方法：层次聚类逐步合并最近的两组，得到一棵树；基于密度的方法（如DBSCAN）能找到任意形状的簇；高斯混合模型把每个簇看成一个高斯分布，用EM算法（EM算法）求解，k-means可以看作它的一个硬分配特例。

它在AI里的位置：聚类本身是传统机器学习的常用工具，在深度学习中也以多种形式出现：DeepCluster交替做“对网络特征聚类”和“用聚类结果当伪标签训练网络”，是视觉自监督学习学习的早期路线；向量量化与离散token（如VQ-VAE）用一个可学习的“码本”把连续向量映射到最近的中心，本质上是在做聚类，这是把图像和音频变成离散token的基础。

例子

一维数据：1、2、3、10、11、12，k = 2，初始中心取1和2。

  • 第1次分配：1归中心1；2、3、10、11、12都离2更近，归中心2。更新中心：1和(2+3+10+11+12)/5 = 7.6。
  • 第2次分配：1、2、3离1更近，10、11、12离7.6更近。更新中心：2和11。
  • 第3次分配不再变化，算法结束，得到{1, 2, 3}和{10, 11, 12}两组。

容易误解的地方

  • k-means需要事先给定k，而且偏好大小相近的球形簇；对细长或环形的簇效果差。
  • 聚类结果没有“标准答案”，不同的距离度量和特征选择可能给出完全不同但都说得通的分组。
