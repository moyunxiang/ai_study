对极几何与本质矩阵、基础矩阵

Epipolar Geometry, Essential and Fundamental Matrices

也叫：对极几何　极线几何　epipolar geometry　对极约束　epipolar constraint　对极线　极线　epipolar line　对极点　epipole　本质矩阵　essential matrix　基础矩阵　fundamental matrix　五点法　five-point algorithm　两视图几何　two-view geometry　相对位姿估计　relative pose estimation　立体校正　stereo rectification　三角化　triangulation

两台相机拍同一场景时的基本约束：一幅图里的点，在另一幅图里的对应点必然落在一条对极线上。它由基础矩阵F（像素坐标）或本质矩阵E（已知内参）描述，E可分解出相对位姿。

先要会：相机模型与多视图几何 特征分解与奇异值分解

立体视觉、运动恢复结构（SfM）和视觉SLAM都要从两幅图像中恢复三维信息。第一步是理解两幅图之间的几何关系，这就是对极几何（相机投影模型见相机模型与多视图几何）。

几何直觉。空间点X、两个相机中心C₁和C₂三点确定一个平面，叫对极平面。它与两个像平面的交线就是对极线。C₁C₂连线（基线）与像平面的交点叫对极点。于是：左图中的点x₁对应的三维点可能在一整条射线上，这条射线投影到右图就是一条直线，对应点x₂一定在这条线上。匹配搜索从二维降到一维，这是立体匹配高效的根本原因。

本质矩阵E。已知相机内参时，用归一化相机坐标x̂表示点，对应点满足

x̂₂ᵀ E x̂₁ = 0，E = [t]ₓ R

R和t是两相机之间的相对旋转和平移，[t]ₓ是t的叉乘矩阵。E有5个自由度（旋转3个、平移方向2个，平移的尺度无法从图像恢复），对E做SVD可以分解出R和t的4组候选解，再用“三维点必须在两个相机前方”选出唯一的一组（见特征分解与奇异值分解）。

基础矩阵F。内参未知时，直接在像素坐标下成立：x₂ᵀ F x₁ = 0，F = K₂⁻ᵀ E K₁⁻¹，K为内参矩阵。F是秩为2的3×3矩阵，有7个自由度；F x₁就是右图中的对极线。

怎么求。

  • 八点法：每对匹配点给出一个关于F的线性方程，8对点即可用最小二乘求解，再强制秩为2；Hartley指出先把坐标归一化能大幅提升数值稳定性（归一化八点法，见数值稳定性：上溢、下溢与条件数）。
  • 五点法：内参已知时，用5对点直接求E，是现代视觉里程计的标准做法。
  • 匹配点里总有错误匹配，所以要套在RANSAC里：反复随机抽最少点数求解，保留内点最多的解。匹配点来自SIFT特征或学习式匹配器（如SuperGlue、LoFTR）。

与单应性的区别。单应性矩阵描述的是“场景是一个平面”或“相机只旋转”时的点到点映射；对极几何描述一般三维场景下的点到线约束。场景接近平面或基线很短时，F的估计会退化，系统常同时估计两者再选择。

它出现在哪里。COLMAP等SfM系统的两视图初始化、ORB-SLAM的单目初始化、立体校正（把对极线变成水平线以便逐行匹配）。DUSt3R、VGGT等前馈重建模型直接预测点图或相机参数，绕过了显式的对极几何求解，但训练和评测仍以它为几何基础。

例子

两台相机内参相同，第二台相对第一台只向右平移（R = I，t = (1, 0, 0)）。此时E = [t]ₓ = [[0, 0, 0], [0, 0, −1], [0, 1, 0]]。左图点x̂₁ = (u, v, 1)对应的对极线是E x̂₁ = (0, −1, v)，即右图中y = v的水平线：对应点和原点在同一行，这正是校正后的双目相机只需沿行搜索视差的原因。

容易误解的地方

  • 只有图像，平移t的尺度永远无法确定：单目视觉里程计得到的轨迹与真实尺度差一个未知的比例，需要IMU、已知物体尺寸或双目基线来恢复。
  • 纯旋转（没有平移）时本质矩阵为零，对极几何退化，此时应使用单应性。
