强化学习中的函数逼近

Function Approximation in RL

也叫：函数逼近　function approximation　价值函数逼近　value function approximation　线性函数逼近　linear function approximation　半梯度　semi-gradient　半梯度TD　semi-gradient TD　瓦片编码　tile coding　粗编码　coarse coding　径向基函数　RBF features　傅里叶基　TD不动点　致命三角

状态太多、无法给每个状态单独存一个价值时，用带参数的函数（线性特征组合或神经网络）近似价值或策略，让相似状态共享经验。代价是收敛保证变弱，甚至可能发散。

先要会：时序差分与自举 线性回归 泛化与过拟合

表格型方法给每个状态（或状态-动作对）存一个数。围棋局面数以10^170计，机器人的状态是连续的，表格根本存不下；更重要的是，绝大多数状态一辈子只会见到一次甚至见不到，必须能从见过的状态泛化到没见过的。

做法。用参数w表示价值：V̂(s; w)。最简单的是线性形式V̂(s; w) = wᵀx(s)，x(s)是人工设计的特征向量；深度强化学习则用神经网络。学习变成了一个回归问题：让V̂接近某个目标。

半梯度TD。目标用TD目标r + γV̂(s'; w)时，更新为

w ← w + α · [r + γV̂(s'; w) − V̂(s; w)] · ∇_w V̂(s; w)

目标里也含w，但求导时把它当常数，只对V̂(s)求梯度，所以叫半梯度。这不是任何固定目标函数的真正梯度下降，收敛性需要另行分析。

经典特征。《Reinforcement Learning: An Introduction》第9章讲了几种：粗编码（coarse coding）用许多相互重叠的感受区，状态落在哪几个区里，对应特征就为1；瓦片编码（tile coding）是它的规整版本，用几层相互错开的网格覆盖状态空间，每层恰好激活一格，计算便宜，在早期连续控制中很常用；此外还有径向基函数和傅里叶基。

收敛性。同策略、线性逼近的TD被线性TD收敛性分析证明收敛到一个“TD不动点”，误差被限制在最优线性近似误差的常数倍以内（γ越接近1倍数越大）。但三样东西同时出现——函数逼近、自举、离策略数据——就可能发散，这就是致命三元组，Baird反例与发散问题给出了线性情形的例子，数学原因见Bellman算子与压缩映射。深度RL的许多工程技巧（目标网络与软更新、经验回放）都是在这个三角里求稳。TD-Gammon是神经网络函数逼近早期最著名的成功，DQN把它带入了像素输入的时代。

例子

一维位置x ∈ [0, 1]，用4层瓦片编码，每层把区间等分成10格，各层依次错开1/40。任一位置恰好激活4个特征（每层一个），总共40个特征。x=0.31和x=0.33通常共享3到4个激活格，更新一个会明显影响另一个；x=0.31和x=0.6没有共享格，互不影响。泛化的范围由格宽决定，分辨率由层数和错开量决定。

容易误解的地方

  • 函数逼近下“更新一个状态”会改变其他状态的估计，表格情形的很多直觉（例如价值迭代一定收敛）不再成立。
  • 半梯度方法用的不是真梯度，直接拿优化器的收敛理论套用是错的；真梯度版本见梯度TD（GTD/TDC）。
