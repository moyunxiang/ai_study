状态抽象与互模拟

State Abstraction and Bisimulation

也叫：状态抽象　state abstraction　互模拟　bisimulation　互模拟度量　bisimulation metric　模型无关抽象　model-irrelevance abstraction　Q*无关抽象　状态聚合　state aggregation　抽象MDP　abstract MDP　行为等价

在交互版中打开（看它长在树上的哪里）

把对决策来说“没有区别”的状态归为一类，在更小的抽象状态空间里学习和规划。互模拟（bisimulation）是最严格的一种等价：两个状态奖励相同、转移到各个等价类的概率也相同；互模拟度量则把这种等价放宽成连续的距离。

先要会：马尔可夫决策过程 Bellman算子与压缩映射 特征与表示学习

智能体从像素学习时，画面里的云朵、背景纹理、无关的数字都在变，但它们与该怎么行动无关。如果表示能把“只在这些无关细节上不同”的状态映射到同一个点，学习就会快得多、也更不容易被干扰。状态抽象研究的是：怎样的合并是安全的，合并后最优策略还能不能找到。

抽象函数。φ: S → S̄把原状态映射到抽象状态。合并越多，问题越小，但丢失的信息可能让最优策略无法表示。

一个由严到宽的层次。

  • 互模拟（模型无关抽象）：被归为一类的s₁、s₂对每个动作a都有相同的奖励，并且转移到每个抽象类的总概率相同。这时抽象后的MDP与原MDP在行为上完全等价，任何策略的价值都不变。
  • Q^π无关：对所有策略π，类内状态的Q^π都相同。
  • **Q*无关**：只要求最优动作价值Q*相同，在抽象空间里做Q-learning仍收敛到最优。
  • **a*无关**：只要求最优动作相同、V*相同，更宽松，但有些算法在其上可能失效。

越往后合并得越多，保证也越弱。

互模拟度量。严格的等价在连续或带噪声的状态上几乎不会成立，于是定义一个距离：

d(s₁, s₂) = max_a [ |r(s₁, a) − r(s₂, a)| + γ · W(P(·|s₁, a), P(·|s₂, a); d) ]

W是在d之下的最优传输与Wasserstein距离（Wasserstein）距离。它是一个类似Bellman算子与压缩映射的压缩映射的不动点：奖励差得越多、未来去向差得越远，两个状态越“不同”。可以证明，两个状态的最优价值之差不超过它们的互模拟距离。

在深度RL里。表示学习的许多方法可以看作在学近似的抽象：DeepMDP潜在空间模型要求隐空间能预测奖励和下一隐状态，并说明这与互模拟度量相关；后续工作直接让编码后的距离逼近互模拟距离，在背景视频不断变化的控制任务上明显更鲁棒。自预测表示（SPR自预测表示）和值等价模型与隐空间动力学思路相近；分层强化学习与时间抽象中的时间抽象则是在时间维度上做类似的合并。

例子

一个走廊任务，状态是(位置, 墙的颜色)，颜色有红蓝两种且随机变化，不影响奖励和移动。(位置3, 红)与(位置3, 蓝)对每个动作的奖励相同、去往各个“位置类”的概率也相同，所以互模拟等价，可以合并成“位置3”，状态数减半。若蓝墙处走一步有5%的概率滑倒，两者的转移不同，就不再互模拟，但互模拟距离很小（与5%的差别成比例）。

容易误解的地方

  • 互模拟只看奖励和转移，不看观测是否相似：两个看起来完全不同的画面可能互模拟，两个几乎一样的画面也可能不是。
  • 互模拟度量计算代价高，深度方法中用的都是近似，理论保证不能直接套用。
