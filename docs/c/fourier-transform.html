傅里叶变换与频域

Fourier Transform

也叫：FFT　快速傅里叶变换　frequency domain　傅立叶变换　频谱　DFT

在交互版中打开（看它长在树上的哪里）

把一个信号拆成不同频率的正弦波之和，得到每个频率的强度和相位。时域里的卷积在频域里变成逐点相乘。

先要会：向量、矩阵与张量 内积与余弦相似度 卷积运算

一段声音在时间上看是一条起伏不定的波形，很难看出“这是什么音”。但如果问“它由哪些频率组成、每个频率多强”，答案就清楚多了：元音有固定的共振峰，乐音有基频和泛音。傅里叶变换就是在“随时间变化”（时域）和“由哪些频率组成”（频域）之间切换的工具。

离散傅里叶变换（DFT）。对长度为N的序列x_0, …, x_{N−1}：

X_k = Σ_{n=0}^{N−1} x_n · e^{−2πi·k·n/N}，k = 0, …, N−1

e^{iθ} = cos θ + i sin θ，所以X_k就是信号与频率为k的余弦、正弦分别做内积与余弦相似度，衡量信号里含有多少这个频率。X_k是复数，模长表示强度，辐角表示相位。变换可逆，信息不丢失。直接计算要N²次运算，快速傅里叶变换（FFT）把它降到N log N。

卷积定理。时域里的卷积运算等于频域里的逐点相乘：先FFT、相乘、再逆FFT，对很长的卷积核比直接滑动快得多。

它出现在哪里。语音处理先对短时窗口做FFT得到频谱图，再取梅尔刻度得到MFCC特征等特征，见波形、频谱与梅尔谱；谱域图卷积把傅里叶变换推广到图上，用图拉普拉斯矩阵的特征向量充当“频率”，由此导出图卷积；Transformer的正弦位置编码和NeRF的位置编码都把坐标映射成一组不同频率的正弦、余弦，让网络更容易表示高频细节，见位置编码。

例子

x = [1, 0, −1, 0]，这正是一个每4个点完成一个周期的余弦波。按定义计算：X_0 = 1 + 0 − 1 + 0 = 0（没有直流分量）；X_1 = 1·1 + (−1)·e^{−iπ} = 1 + 1 = 2；X_2 = 1 + (−1)·e^{−2πi} = 0；X_3 = 1 + (−1)·e^{−3πi} = 2。频谱是[0, 2, 0, 2]：能量全部集中在频率1（X_3是它在实信号中的镜像）。计算量：N = 1024时直接DFT需约10⁶次运算，FFT约1024×10 ≈ 10⁴次，快约100倍。

容易误解的地方

  • 傅里叶变换假设信号在整个窗口内频率不变；声音这类随时间变化的信号要分成短窗口分别变换（短时傅里叶变换），这就有了时间分辨率和频率分辨率之间的权衡。
  • 实信号的频谱是对称的，后一半是前一半的共轭镜像，不包含新信息。
