资格迹与TD(λ)

Eligibility Traces and TD(λ)

也叫：资格迹　eligibility trace　eligibility traces　TD(λ)　TD lambda　TD-lambda　λ回报　λ-return　lambda return　前向视角　forward view　后向视角　backward view　累积迹　accumulating trace　替换迹　replacing trace　SARSA(λ)　Q(λ)　Watkins Q(λ)

在交互版中打开（看它长在树上的哪里）

TD(λ)用参数λ对所有n步回报做指数加权平均；资格迹是它的高效实现：给最近访问过的状态记一个逐步衰减的“功劳记号”，每个TD误差按记号大小分给它们。

先要会：时序差分与自举 n步回报与多步TD

n步回报与多步TD要选一个n，而最好的n因任务而异。TD(λ)的做法是不选：把所有n的回报都用上，按指数衰减加权。

λ回报（前向视角）。

G_t^λ = (1 − λ) · Σ_{n≥1} λ^{n−1} · G_t^(n)

权重(1−λ)λ^{n−1}加起来为1。λ=0时只剩1步回报，就是TD(0)；λ=1时（分幕任务里）就是蒙特卡洛回报。问题是这要看到未来很多步才能算，不能在线更新。

资格迹（后向视角）。换个角度：每走一步，就把当前TD误差δ分给过去所有对它有贡献的状态，越近的分得越多。给每个状态维护一个迹e(s)：

e(s) ← γλ·e(s)（所有状态先衰减），e(s_t) ← e(s_t) + 1

δ_t = r_{t+1} + γV(s_{t+1}) − V(s_t)，V(s) ← V(s) + α·δ_t·e(s)（对所有s）

这叫累积迹；若把+1改成直接设为1，叫替换迹，在状态反复出现时更稳定。可以证明，在离线更新（一个回合结束后才统一更新）时后向视角与前向λ回报完全等价；在线时两者略有差别，True Online TD(λ)给出了精确等价的在线版本。用函数逼近时，迹记在参数上：e ← γλe + ∇V(s_t)。

来龙去脉。“资格”一词来自Klopf的神经元假说，Actor-Critic（ASE/ACE）用资格迹解决倒立摆的信用分配，时序差分学习系统给出了TD(λ)，见信用分配。控制版本有SARSA(λ)；Watkins的Q(λ)在执行探索动作时把迹清零，因为之后的经验不再对应贪心策略，离策略情形下的系统处理见树备份与离策略资格迹。深度RL里很少直接维护迹（与批量随机更新不兼容），但广义优势估计GAE把同样的λ加权用在优势估计上，是今天最常见的形式。

例子

γ=1，λ=0.5，依次经过A、B、C，此前迹都为0。到达C时迹为：e(A)=0.5×0.5=0.25，e(B)=0.5，e(C)=1（C刚被访问）。此时出现δ=2，α=0.1，则V(C)加0.2，V(B)加0.1，V(A)加0.05：越早经过的状态分到的功劳越少。λ=0时只有C被更新，λ=1时三者各加0.2。

容易误解的地方

  • λ不是折扣：γ定义了目标（未来奖励值多少），λ只决定怎么估计这个目标，改λ不改变要学的价值函数。
  • 离策略地使用资格迹而不做修正，会让迹把行为策略的探索动作也算进功劳里，导致偏差甚至发散。
