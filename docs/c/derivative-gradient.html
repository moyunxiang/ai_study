导数、偏导与梯度

Derivatives and Gradients

也叫：偏导数　gradient　partial derivative　微分　斜率

在交互版中打开（看它长在树上的哪里）

导数描述输入变一点点时输出变多少；多变量函数对每个变量分别求偏导，排成的向量就是梯度，它指向函数增长最快的方向。

训练一个模型，就是调整成千上万甚至上万亿个参数，让损失变小。逐个参数去试太慢，我们需要知道：每个参数往哪个方向动、动多少，损失下降最快？这个信息就是梯度。

导数。单变量函数f在x处的导数是

f'(x) = lim_{h→0} (f(x+h) − f(x)) / h

它是函数在这一点的斜率：x增加一个很小的量h，f大约增加f'(x)·h。

偏导与梯度。函数有多个输入f(x_1, …, x_n)时，固定其他变量、只让x_i变化，得到偏导∂f/∂x_i。把所有偏导排成向量就是梯度：

∇f = (∂f/∂x_1, …, ∂f/∂x_n)

梯度有两个关键性质：它指向f增长最快的方向；它的长度表示这个方向上增长有多陡。反过来，−∇f就是下降最快的方向。在梯度为0的点上，函数局部“平了”，可能是极小值、极大值或鞍点。

怎么算。可以用数值差分近似：把每个参数分别加一个很小的h，看损失变了多少。但n个参数就要做n+1次前向计算，对上亿参数的网络完全不可行，而且有舍入误差。实际训练都用解析求导，数值差分只用来检查求导代码是否写对。

它出现在哪里。梯度下降的每一步就是θ ← θ − η∇L(θ)，随机梯度下降用一小批数据估计这个梯度。对复杂的多层网络，梯度要靠链式法则逐层算出来，这就是反向传播；现代框架用自动微分与计算图自动完成这件事。L-BFGS等方法在梯度之外还利用曲率信息，见雅可比矩阵与海森矩阵。

例子

f(x, y) = x² + 3xy。∂f/∂x = 2x + 3y，∂f/∂y = 3x。在点(1, 2)处，梯度是(2×1 + 3×2, 3×1) = (8, 3)。验证：把x增加0.001，f从1 + 6 = 7变成1.001² + 3×1.001×2 ≈ 7.008，确实约增加了8×0.001。若想让f变小，就沿(−8, −3)方向走一小步。

容易误解的地方

  • 梯度只告诉你“这一点附近”的情况，步子迈得太大，线性近似就失效了，这正是学习率不能太大的原因，见学习率与学习率调度。
  • 梯度为0不代表找到了最小值：在高维的损失曲面上，鞍点远比局部极小值常见，见损失曲面、局部极小与鞍点。
  • ReLU在0点不可导，实践中直接约定该点导数为0或1，不影响训练。
