协调图

Coordination Graphs

也叫：协调图　coordination graph　coordination graphs　价值分解图　因子化Q函数　factored Q-function　变量消元　variable elimination　max-plus　最大和消息传递　稀疏协作Q学习　sparse cooperative Q-learning　两两价值分解　pairwise value decomposition

在交互版中打开（看它长在树上的哪里）

把团队的联合价值写成若干局部项之和：每个智能体一个单独的项，每对需要配合的智能体（图中的一条边）一个两两项。这样既能表示“谁必须和谁配合”，又能用图上的消息传递高效地找出最好的联合动作。

先要会：随机博弈与Dec-POMDP 概率图模型

合作多智能体问题的联合动作空间随智能体数指数增长（见随机博弈与Dec-POMDP）：10个智能体、每人5个动作，就有近千万种组合，直接学联合Q函数或对它取max都不可行。另一个极端是让每人只学自己的Q（独立Q学习多智能体）或把团队价值写成各人价值之和（VDN值分解网络），但这样无法表示“A和B必须同时做某件事才有收益”，会出现相对过度泛化。协调图在二者之间取了一个结构化的折中。

分解形式。用一张图描述依赖关系：节点是智能体，边连接需要直接配合的两个智能体。联合价值近似为

Q(s, a₁, …, a_n) ≈ Σ_i f_i(s, a_i) + Σ_{(i,j)∈E} f_ij(s, a_i, a_j)

没有边时退化为VDN式的加和分解；边越多表达能力越强，完全图则可以表示任意两两交互。

怎样找最好的联合动作。直接枚举不可行，但这一形式与概率图模型里的因子图一样，可以用变量消元：按顺序把一个智能体“消去”，对它的动作取max并把结果作为新的因子传给邻居，最后再反向确定每个人的动作，在树结构的图上是精确的。也可以用max-plus消息传递（最大化版本的信念传播）近似求解，适合有环的大图，并可以分布式地执行。

来龙去脉。Guestrin等人在2002年把协调图引入多智能体规划与强化学习；之后有基于此的稀疏协作Q学习。DCG深度协调图把它带入深度学习：节点项和边项都由共享参数的神经网络给出，边项用低秩分解降低参数量，在需要紧密配合的任务上明显好于只做单调值分解的QMIX值分解。图的结构可以按领域知识给定（比如相邻的机器人之间连边），也可以学出来或动态地选择。

与其他方法的关系。它是集中训练、分散执行下的一种价值分解方式：训练时学各个因子，执行时通过消息传递协商动作，因此执行阶段需要邻居之间通信。

例子

三个机器人排成一排抬一根长杆，只有相邻两个需要同步：图为1—2—3。每人2个动作（抬/不抬），联合动作8种。用变量消元：先消去机器人3，对每个a₂计算max_{a₃} [f₃(a₃) + f₂₃(a₂, a₃)]，得到只依赖a₂的新因子；再消去机器人2，最后确定a₁，然后反推a₂、a₃。每一步只比较2×2种组合，智能体增加到100个时计算量也只是线性增长。

容易误解的地方

  • 只含两两项的分解无法表示需要三个及以上智能体同时配合的收益，需要高阶边（超边）。
  • 有环的图上max-plus不保证收敛到最优联合动作，迭代次数和消息归一化会影响结果。
