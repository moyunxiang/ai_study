声码器与音频编解码

Vocoders and Audio Codecs

也叫：vocoder　音频编解码器　neural codec　神经编解码　音频token　audio codec

在交互版中打开（看它长在树上的哪里）

声码器把梅尔谱等中间表示还原成可播放的波形；神经音频编解码器把波形压缩成少量离散token再还原。后者让语音和音乐可以像文本一样用语言模型生成。

先要会：波形、频谱与梅尔谱 向量量化与离散token 自编码器

语音合成（TTS）通常分两步：先从文字预测一张梅尔谱，再把梅尔谱变回波形。第二步并不简单：梅尔谱只保留了各频带的能量，丢掉了相位，而且时间分辨率低（每秒约100帧，而波形每秒有2万多个采样点）。把这些缺失的细节补回来的模块叫声码器（vocoder），见波形、频谱与梅尔谱。

神经声码器的演进。传统方法（如Griffin-Lim迭代估计相位）声音发虚、有金属感。WaveNet用自回归卷积网络一个采样点一个采样点地生成，质量接近真人，但1秒音频要串行生成上万步，非常慢。之后的方向是并行化：用流模型、GAN等一次生成整段波形。HiFi-GAN用多个判别器从不同周期和尺度检查波形，生成速度远超实时，成为最常用的声码器之一，见对抗训练。

神经音频编解码器。另一个需求是把音频变成离散token，让语言模型来生成。神经音频编解码器和EnCodec用一个自编码器：编码器把波形下采样成每秒几十帧的向量，中间做量化，解码器（本身就是一个声码器）还原波形，并加对抗损失让音质更好。

量化用的是残差向量量化（RVQ），是向量量化与离散token的多级版本：第一本码本粗略近似向量，第二本码本近似剩下的误差，以此类推。码本用得越多，还原越精细、码率越高；只用前几级就能得到较低码率的版本。

它在哪里。VALL-E把TTS变成“根据文字和3秒参考音频，续写编解码器token”的语言模型任务；AudioLM、MusicGen用同样的token生成语音和音乐；今天的语音对话大模型也大多以这类token作为音频的输入输出。

例子

规模感：24kHz音频若每秒100帧梅尔谱，每帧要还原出24000/100 = 240个采样点。

EnCodec的24kHz模型每秒75帧，每本码本1024项（10比特）。用2本码本时码率为75×2×10 = 1500比特/秒，即1.5kbps；用8本码本是6kbps。作为对比，16位、24kHz的未压缩单声道音频是384kbps。

RVQ的一维示意：要编码的值是0.83。第一本码本{0, 0.5, 1.0}中最近的是1.0，残差0.83 − 1.0 = −0.17；第二本码本{−0.2, 0, 0.2}中最近的是−0.2，残差−0.17 − (−0.2) = 0.03。记下两个编号，还原值为1.0 + (−0.2) = 0.8，误差从只用第一级时的0.17降到0.03。

容易误解的地方

  • 声码器只负责“梅尔谱→波形”这一步，说话风格、韵律主要由前面预测梅尔谱的声学模型决定。
  • 编解码器的token速率和码本层数直接决定语言模型的序列长度：每秒75帧×8层就是每秒600个token，所以有各种减少层数、降低帧率的设计。
  • 码率低不等于听感差：神经编解码器在6kbps下的主观音质可以超过传统编码器在更高码率下的效果，但会在某些声音上出现伪影。
