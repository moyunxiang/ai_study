智能体外壳与长时程运行

Agent Harnesses and Long-Running Agents

也叫：harness　agent harness　scaffold　scaffolding　脚手架　智能体外壳　智能体框架　long-running agents　长时程智能体　长任务　上下文压缩　compaction　Ralph loop　agent loop

在交互版中打开（看它长在树上的哪里）

同一个模型能连续工作多久、做成多大的事，很大程度取决于包在它外面的循环、工具、上下文管理和检查机制。

SWE-agent首先说明给模型设计好的操作接口比换提示更重要。2025年起，终端编码智能体Claude Code与终端编码智能体把「读文件、改代码、跑测试」的循环做成产品，社区的Ralph循环用一个简单的死循环让智能体一遍遍接着干。为了跨越上下文窗口，Codex-Max与上下文压缩在接近上限时自动压缩历史；长时程智能体harness总结了让智能体连续工作多个会话的做法（进度文件、测试、逐项提交）；并行智能体团队让多个并行智能体合作写出一个C编译器；托管智能体平台把外壳与执行环境做成托管平台。

争论在于能力提升有多少来自模型、多少来自外壳，以及评测时应该固定哪一部分。
