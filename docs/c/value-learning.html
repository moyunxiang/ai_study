价值学习

Value Learning

也叫：价值学习　value learning　学习人类价值　learning human values　偏好学习　preference learning　奖励学习　reward learning　从人类偏好中学习　learning from human preferences　价值对齐　value alignment　人类偏好不确定性　辅助博弈　assistance games　偏好推断　preference inference

在交互版中打开（看它长在树上的哪里）

让AI从人的行为、选择、反馈和语言中推断人真正想要什么，而不是事先把目标写死成奖励函数。逆强化学习、合作逆强化学习、从偏好学习奖励模型（RLHF）都属于这条路线。

先要会：奖励设计与奖励投机 模仿学习与行为克隆

强化学习假设奖励函数是给定的。可现实中，人很难把自己想要的东西完整、准确地写成公式：写漏了，智能体会钻空子（见奖励设计与奖励投机和规约博弈）；写死了，智能体会不惜代价追求这个固定目标，甚至抗拒被修改或关闭（见可纠正性和关机博弈）。价值学习主张：把“人想要什么”当作需要从证据中学习的未知量。

几种代表方法。

  • 逆强化学习（IRL）：观察专家的行为，反推出一个让这些行为看起来最优的奖励函数（逆强化学习IRL）。同样的行为可以由无数种奖励解释，最大熵逆强化学习用最大熵原理选出最不做多余假设的那一个（见最大熵原理）。
  • 合作逆强化学习（CIRL）：合作逆强化学习CIRL把人和AI建模为一个合作博弈，双方共享同一个奖励，但只有人知道它是什么。AI因此有动机观察人、向人请教，并且在不确定时接受人的纠正；《Human Compatible》把这一思路概括为“对人类偏好保持不确定”的设计原则。
  • 逆奖励设计：逆奖励设计IRD把设计者手写的奖励只看作“在训练环境中有效”的证据，到了新环境就对真实目标保持不确定，变得更谨慎。
  • 从偏好中学习：让人比较两段行为或两个回答哪个更好，用Bradley–Terry模型拟合一个奖励模型（见Elo评分与两两比较），再用强化学习优化它。这是从人类偏好学习奖励的方法，也是InstructGPT与RLHF等RLHF流程的核心（见人类反馈强化学习）。
  • 从语言和原则中学习：Constitutional AI让模型依据一组用自然语言写成的原则自我批评和修改，把“价值”写成可读的规则而不是逐条标注。

核心难题。

  • 人并不总是理性的：观察到的行为混有错误、短视和偏见；把这些也当成“想要的”会学错。需要对人的决策方式做假设，而这些假设本身很难验证。
  • 谁的价值：不同的人、群体、文化之间价值观冲突，聚合方式本身就是规范性选择。
  • 价值与奖励模型的偏差：学到的奖励模型只是人的价值的一个近似，被强力优化时会出现奖励作弊（见奖励作弊）。
  • 可扩展监督：当AI的能力超过人时，人难以判断它的行为好坏，价值学习的信号来源就成了问题（见可扩展监督）。

例子

一个家务机器人看到主人每天早上先煮咖啡、再开窗，周末则不煮咖啡。IRL可能推断出“工作日早上想喝咖啡”这一偏好，而不是死记“每天7点煮咖啡”；当主人某天把咖啡壶收进柜子，CIRL式的机器人会把这当作“今天不想喝”的信号，而不是一个需要克服的障碍。（情境为示意）

容易误解的地方

  • “学习人的价值”不等于“模仿人的行为”：行为克隆只复制做法，价值学习要推断背后的目标，才能在新情况下做出人会认可的选择。
  • 偏好数据反映的是标注者在当时界面下的判断，可能偏爱长回答、自信的语气等表面特征，并不等于更深层的价值。
