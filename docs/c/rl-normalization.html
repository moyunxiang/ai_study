强化学习中的归一化：观测、奖励与优势

Normalization in RL: Observations, Rewards, Advantages

也叫：奖励归一化　reward normalization　奖励缩放　reward scaling　观测归一化　observation normalization　状态归一化　优势归一化　advantage normalization　价值归一化　value normalization　VecNormalize　running mean std　滑动均值方差

在交互版中打开（看它长在树上的哪里）

深度RL里把观测、奖励、优势和价值目标都缩放到合适量级的一组技巧：观测按滑动均值方差标准化，奖励除以回报的滑动标准差，优势在每个批次内标准化，价值目标可用PopArt自适应归一化。

先要会：Actor-Critic与优势函数 期望与方差

监督学习的输入和标签是固定的，训练前算一次均值方差就能标准化。强化学习的数据随策略变化：机器人一开始站着不动，关节速度都接近0，学会跑之后可以到几十；奖励可能从每步0.01到每回合几千。量级忽大忽小，网络的梯度和学习率就很难调。下面几种归一化在PPO等算法的常见实现中几乎是默认开启的，PPO的实现细节之争发现它们对结果的影响有时比算法本身的差别还大。

观测归一化。对每一维观测维护滑动均值μ和方差σ²，输入网络前做(o − μ) / (σ + ε)，再裁剪到例如[−10, 10]。统计量随训练更新，评估和部署时必须使用同一组统计量。

奖励缩放。维护折扣回报的滑动标准差，把每步奖励除以它（通常不减均值，以免改变奖励的符号和“活着就有奖励”这类结构），再裁剪。目标是让价值函数的目标量级保持在1附近。另一种更粗暴的做法是Atari中的奖励裁剪，见帧堆叠、跳帧与像素输入的预处理。

优势归一化。在每个小批量里把优势估计标准化为均值0、标准差1：Â ← (Â − mean) / (std + ε)。它不改变各样本优势的相对大小，却让策略梯度的步长与奖励尺度无关，是一种简单的方差控制，见策略梯度的方差缩减：基线与reward-to-go。在GRPO中，组内奖励标准化起着类似作用。

价值目标归一化。价值函数的目标随策略变好而不断变大，网络输出层要不停追赶。PopArt自适应目标归一化在归一化价值目标的同时，反向调整输出层的权重和偏置，使未归一化的预测保持不变，从而能用同一套超参数学习奖励尺度差异很大的多个游戏。另一条路是把价值回归改成分类，见用分类训练价值函数。

与此不同的是网络内部的层归一化、批归一化（见归一化层），它们近年也被发现能显著稳定深度RL训练，例如CrossQ批归一化RL和SimBa。

例子

某任务每步奖励约为+5，γ=0.99，折扣回报约为5/(1−0.99)=500。不缩放时价值网络要回归几百的目标，均方误差动辄上万，梯度很大。把奖励除以回报的滑动标准差（设为100）后，每步奖励约0.05，回报约5，价值损失回到个位数。优势归一化：一个批次的优势为(3, 1, −1, −3)，均值0、标准差约2.24，归一化后约为(1.34, 0.45, −0.45, −1.34)。

容易误解的地方

  • 保存模型时忘了保存观测归一化的统计量，加载后策略会表现得像完全没训练过，这是最常见的复现问题之一。
  • 奖励归一化改变了奖励的尺度，报告结果时必须用原始奖励计算回报。
  • 小批量很小时，优势归一化的均值和标准差噪声很大，可能反而有害。
