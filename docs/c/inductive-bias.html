归纳偏置

Inductive Bias

也叫：归纳偏好　先验假设　prior assumption　结构先验　architectural prior

在交互版中打开（看它长在树上的哪里）

学习算法在数据之外预先带入的假设或偏好，例如“相邻像素关系更密切”“同一图案在哪里出现都一样”。它决定了在有限数据下模型会倾向于学出什么样的解。

先要会：泛化与过拟合 监督学习

有限的训练数据永远可以被无数个不同的函数完美拟合，它们在训练点上一致，在新数据上却各不相同。学习算法最终选哪一个，取决于它事先“偏好”哪类函数——这种偏好就是归纳偏置。没有任何偏置的学习者无法泛化：没有免费午餐定理定理说，在所有可能的问题上平均，没有哪个学习算法比别的更好。所以有用的学习算法必然带有某种适合现实问题的假设。

神经网络中的例子：

  • 卷积网络（卷积层、池化与感受野）假设局部性（像素主要与邻近像素相关）和平移等变（猫在左上角和右下角是同一只猫），所以只用小卷积核、在全图共享权重。LeNet与卷积网络以来，这让CNN用很少的参数和数据就能学好图像任务。
  • 循环网络假设数据按顺序到来，当前状态由之前的状态决定。
  • 图神经网络假设结果与节点的编号顺序无关（见不变性与等变性）。
  • 正则化与权重衰减本身也是一种偏置：偏好权重小、函数平滑的解。

偏置强弱与数据量的权衡：强偏置在数据少时帮助很大，但如果假设与真实情况不符，就成了天花板。Transformer的偏置比CNN弱得多（注意力允许任意两个位置直接交互）。Vision Transformer发现：在中等规模的数据上，ViT不如同等规模的CNN；在上亿张图片上预训练后，ViT反超。苦涩的教训把这类观察总结为：长期看，依赖算力和数据的通用方法胜过人为设计的领域知识。另一方面，几何深度学习主张从数据的对称性出发系统地设计偏置。

例子

输入一张224×224的彩色图（224×224×3 = 150528个数），输出同样大小、64个通道的特征图（224×224×64 = 3211264个数）。

  • 全连接层：每个输出都连到所有输入，需要150528×3211264 ≈ 4.8×10¹¹个权重。
  • 3×3卷积层：每个输出只看邻近3×3区域，且全图共享，需要3×3×3×64 = 1728个权重（不计偏置）。

“局部性 + 权重共享”这个归纳偏置让参数量少了约2.8亿倍。

容易误解的地方

  • “偏置”在这里不是“偏见”或“偏差（bias）项”的意思，而是指学习者对解的先验偏好。
  • 弱偏置不等于没有偏置：Transformer的结构、优化器、数据都在隐含地塑造它学到的解。
