超参数与调参

Hyperparameters and Tuning

也叫：hyperparameter tuning　网格搜索　grid search　随机搜索　炼丹

在交互版中打开（看它长在树上的哪里）

训练开始前由人设定、不由梯度下降学出来的选择，例如学习率、批大小、层数、正则强度；调参就是在这些选择里找最好的一组。

先要会：训练集、验证集与测试集 学习率与学习率调度

训练一个模型时有两类数。一类是参数：权重和偏置，由梯度下降根据数据自动更新。另一类是超参数：学习率与学习率调度多大、批大小、步数与轮数怎么设、网络几层多宽、正则化与权重衰减系数多少、训练多少步。它们决定了训练过程本身，梯度没法直接告诉你该怎么改，只能“设一组、训一遍、看结果”。

用什么判断好坏：在训练集、验证集与测试集里的验证集上比较，绝不能在测试集上调，否则测试分数就被调参过程“偷看”过了，不再代表真实泛化。

怎么搜。最朴素的是网格搜索：每个超参数取几个值，全部组合都试。超参数随机搜索指出，通常只有一两个超参数真正重要，网格会在不重要的维度上浪费大量试验，而随机采样能在重要维度上试到更多不同的值。更进一步，贝叶斯优化调参用一个代理模型（常是高斯过程）根据已有结果预测下一组最值得试的配置。学习率这类跨数量级的量要在对数尺度上采样，例如在1e-5到1e-2之间均匀取log值。

大模型时代的变化。一次训练要花几百万美元时，不可能在全尺寸上反复试。常见做法是在小模型上调好，再按经验规则放大；μP与超参数迁移给出了一种参数化方式，使最优学习率等超参数在模型变宽时基本不变，可以直接从小模型迁移。神经架构搜索NAS则把“网络结构”本身也当成超参数来自动搜索。

例子

调两个超参数：学习率（重要）和dropout率（几乎无影响），预算9次训练。

  • 网格搜索3×3：学习率只试到3个不同值，另外6次都花在重复测试学习率上。
  • 随机搜索9次：学习率试到9个不同值，找到好区间的机会更大。

如果“好配置”占搜索空间的5%，随机试60次至少有一次落进去的概率是1 − 0.95^60 ≈ 0.95。

容易误解的地方

  • 在测试集上调参是最常见的错误之一，报告出来的分数会偏乐观。
  • 不同方法比较时，如果只给自己的方法仔细调参、基线用默认值，结论不可信，见基线与消融实验。
  • 同一组超参数换个随机种子结果也会波动，几次试验之间的小差距可能只是噪声，见方差、种子与统计显著性。
