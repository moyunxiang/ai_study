1×1卷积与全局平均池化

1×1 Convolution and Global Average Pooling

也叫：1x1卷积　1×1卷积　1x1 convolution　1×1 convolution　逐点卷积　pointwise convolution　bottleneck block　全局平均池化　global average pooling　GAP　全局池化　global pooling　全局最大池化　global max pooling　通道降维　channel reduction　自适应平均池化　AdaptiveAvgPool2d

两个让卷积网络更省参数的小部件：1×1卷积只在通道之间做线性组合，用来升降通道数；全局平均池化把整张特征图在空间上取平均，代替网络末端庞大的全连接层。

先要会：卷积层、池化与感受野 线性层（全连接层）

1×1卷积（逐点卷积）。卷积核大小为1×1时，它不看任何空间邻居，只在每个像素位置上把C_in个通道的值线性组合成C_out个新通道，相当于对每个位置独立地应用同一个线性层（全连接层）。它有三个用途：

  • 升降维：在昂贵的3×3卷积之前先用1×1卷积把256个通道降到64个，算完再升回256。GoogLeNet / Inception的Inception模块和ResNet的“瓶颈”残差块都这样做，计算量能降到几分之一。
  • 跨通道混合：与只在每个通道内部做空间滤波的深度卷积配合，构成深度可分离卷积，见Xception和MobileNet（见卷积层、池化与感受野）。
  • 加非线性：在1×1卷积后接激活函数，相当于在每个位置上跑一个小MLP，这是Network In Network提出的“网络中的网络”。

全局平均池化（GAP）。早期CNN最后把特征图展平，再接几个巨大的全连接层：AlexNet和VGG的参数大部分都在这里。GAP改为对最后一层特征图的每个通道在整个H×W空间上取平均，得到一个长度为C的向量，直接接一个线性分类层。

  • 参数大幅减少，过拟合风险降低；
  • 对输入图像尺寸不再有要求，任意大小的图都得到同样长度的向量；
  • 每个通道的平均值可以看作“这种特征在图中出现了多少”，由此可以画出类激活图：CAM类激活图正是利用GAP后分类层的权重，把各通道的特征图加权求和，看出模型在看图的哪里（后来推广为Grad-CAM与显著图）。

GAP由Network In Network提出，GoogLeNet / Inception、ResNet之后成为分类网络的标准结尾。全局最大池化则取每个通道的最大值，更关注“是否在某处出现过”。

在其他结构里的对应物。SENet通道注意力的通道注意力先用GAP把每个通道压成一个数，再用两个小的全连接层算出每个通道的权重；Vision Transformer既可以用一个专门的分类token，也可以对所有patch token做平均池化来得到整图表示，后者就是GAP在Transformer中的对应。

例子

输入特征图256×56×56。

  • 直接用3×3卷积输出256通道：参数约256×256×9 ≈ 59万。
  • 瓶颈结构：1×1降到64（256×64 ≈ 1.6万）→ 3×3卷积64→64（64×64×9 ≈ 3.7万）→ 1×1升回256（64×256 ≈ 1.6万），共约6.9万，少了约8倍。

GAP：最后一层特征图2048×7×7，GAP后得到2048维向量，接一个1000类的线性层约205万参数；若展平成100352维再接4096维全连接层，仅这一层就要约4.1亿参数。

容易误解的地方

  • 1×1卷积并非“什么也没做”：它在通道维上是一个完整的全连接变换，参数量是C_in×C_out。
  • GAP丢掉了所有空间位置信息；检测、分割这类需要位置的任务不能在主干末端直接用它。
