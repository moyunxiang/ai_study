独立、条件独立与独立同分布

Independence and the i.i.d. Assumption

也叫：独立同分布　i.i.d.　iid　IID　independent and identically distributed　non-IID　非独立同分布　独立性　independence　条件独立　conditional independence　统计独立　相互独立

独立同分布（i.i.d.）：每个样本都来自同一个分布，彼此之间互不影响。几乎所有机器学习理论和“训练集上学好、测试集上也好”的期望都建立在这个假设上。

先要会：随机变量与概率分布 条件概率与贝叶斯公式

我们在训练集上训练、在测试集上评估，然后相信模型在真实世界里也能工作。这背后默认了一个很强的假设：训练样本、测试样本、未来的样本，都是从同一个分布里相互独立地抽出来的。

独立。随机变量X和Y独立，指P(X, Y) = P(X)·P(Y)：知道一个的值，对另一个毫无信息。

条件独立。给定Z之后X和Y独立：P(X, Y | Z) = P(X | Z)·P(Y | Z)。它比独立弱得多，也有用得多。朴素贝叶斯分类假设“给定类别后各个词相互条件独立”；隐马尔可夫模型假设“给定当前隐状态，观测与过去无关”；概率图模型的整套语言就是在描述哪些变量在给定哪些变量后条件独立。注意两者互不蕴含：两个独立的硬币，在“已知它们结果之和”这个条件下就不再独立。

同分布。每个样本的分布相同。合起来，i.i.d.让很多事情变得可行：

  • 似然可以写成连乘Π p(x_i | θ)，取对数变成求和，这是最大似然估计和所有平均损失的出发点。
  • 样本平均收敛到期望，误差按1/√n缩小，见大数定律与中心极限定理。
  • 泛化理论（PAC学习、VC维与一致收敛）给出的“训练误差接近测试误差”的保证都依赖它。

现实中经常被打破。

  • 训练和部署时的分布不同，就是分布偏移。
  • 强化学习里相邻时刻的经验高度相关，DQN用经验回放把它们打散，部分恢复近似i.i.d.的小批量。
  • 联邦学习FedAvg等联邦学习里，每台设备的数据分布各不相同（non-IID），是该领域的核心难点。
  • 持续学习里任务按顺序到来，不是同分布的，导致持续学习与灾难性遗忘中的灾难性遗忘。
  • 数据集里同一个人、同一篇文档被切成多条样本时，样本并不独立；随机划分训练/测试集会让同源样本同时出现在两边，见数据泄漏与基准污染。

例子

掷两枚公平硬币，X、Y分别为两枚的结果（1为正面）。P(X = 1, Y = 1) = 1/4 = P(X = 1)·P(Y = 1)，独立。但如果已知X + Y = 1，那么X = 1就意味着Y = 0：条件独立不成立。

反过来，A和B都取决于同一个Z（如“下雨”同时影响“地面湿”和“有人打伞”），两者不独立，但给定Z后条件独立。

容易误解的地方

  • “测试集是i.i.d.的”这句话只对随机划分的测试集近似成立；按时间、按用户、按来源划分时，必须按真实部署场景来理解测试结果。
  • 小批量训练前要打乱数据，否则一个批次里全是同一类样本，梯度严重偏离i.i.d.假设下的估计。
