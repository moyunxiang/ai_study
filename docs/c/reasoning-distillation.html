长思维链蒸馏

Long-CoT Reasoning Distillation

也叫：推理蒸馏　reasoning distillation　长思维链蒸馏　long CoT distillation　R1蒸馏　R1-distill　推理轨迹蒸馏　少样本激活推理　less is more for reasoning

在交互版中打开（看它长在树上的哪里）

收集强推理模型写出的长思维链，用来监督微调较小或较弱的模型，让它们学会先想后答。

DeepSeek-R1在发布大规模RL训练的推理模型时，同时放出了用80万条样本蒸馏出的小模型，表明对小模型而言，直接模仿强模型的推理轨迹往往比自己做RL更划算。随后s1与预算强制和LIMO少样本推理发现，精选的1000条左右高难度样本就足以激活长推理能力；Open-R1与R1复现潮等社区项目大规模复现和整理了这类数据。

这条路线的限制是学生很难超过老师，而且学到的往往是推理的形式而非能力上限；它与「在策略蒸馏」的区别是学生学老师的轨迹，而不是在自己的轨迹上接受逐词指导（见「在策略自蒸馏」）。
