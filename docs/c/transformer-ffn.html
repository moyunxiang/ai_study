Transformer的前馈层

Transformer Feed-Forward Layer

也叫：FFN　feed-forward network　前馈网络　前馈层　position-wise feed-forward　逐位置前馈网络　MLP块　MLP block　MLP层　intermediate layer　中间层维度　SwiGLU FFN　键值记忆　key-value memories

在交互版中打开（看它长在树上的哪里）

Transformer每一层里接在注意力后面的两层全连接网络，对每个token独立地“升维—非线性—降维”。它占了模型约三分之二的参数，被认为存储了大量事实知识。

先要会：多层感知机 Transformer层的结构 神经元与激活函数

注意力负责让token之间交换信息，但它本质上是对值向量做加权平均，非线性很弱。每个Transformer块（见Transformer层的结构）在注意力之后都接一个前馈网络（feed-forward network，FFN，也叫MLP块），对每个位置单独做一次非线性变换。

标准形式（Transformer原文）：

FFN(x) = W_2 · ReLU(W_1 · x + b_1) + b_2

W_1把d维升到d_ff维（通常d_ff = 4d），经过激活函数，W_2再降回d维。“逐位置”的意思是：同一套权重分别作用在序列的每个token上，token之间在这里不交流。它就是一个两层的多层感知机。

门控变体。现代大模型多用GLU变体与SwiGLU：

FFN(x) = W_2 · (SiLU(W_1·x) ⊙ (W_3·x))

⊙是逐元素相乘，W_3·x充当一个“门”（见门控机制）。因为多了一个矩阵，为保持参数量不变，d_ff常取约8d/3。LLaMA等模型都采用这种结构。激活函数从ReLU换成GELU或SiLU，也是常见改动（见神经元与激活函数）。

参数和计算的大头。每层注意力约4d²参数，FFN约8d²，FFN占三分之二（见模型尺寸超参数：维度、层数与头数）。混合专家正是把FFN换成多个“专家”FFN、每个token只用其中几个，从而在不增加每token计算量的前提下扩大参数。

它在做什么。FFN即键值记忆提出一种有影响的解释：把FFN看作键值记忆：W_1的每一行是一个“键”，检测输入中是否出现某种模式；对应的W_2的列是“值”，在模式出现时往表示里加入相应内容。ROME知识定位与编辑等知识编辑工作发现，修改中间层FFN的少量权重就能改变模型对某条事实的回答（见知识编辑）。这类解释仍在研究中，并不完整。

例子

d = 4，d_ff = 16。某token的向量x是4维的：

1. W_1（16×4）把它变成16维，例如前几维是[2.1, −0.5, 0.3, −1.2, …]。 2. ReLU把负数置0：[2.1, 0, 0.3, 0, …]。只有部分“神经元”被激活。 3. W_2（4×16）把这16维加权求和回4维。

参数量：W_1和W_2各64个，共128个（不计偏置），而同一层注意力的Q、K、V、输出矩阵共4×16 = 64个，FFN正好是注意力的两倍。

容易误解的地方

  • FFN对每个token独立计算，所以它的计算量随序列长度线性增长；序列很长时，注意力的平方项才会超过它。
  • “FFN存储知识、注意力负责路由”是一种简化的说法，两者的分工没有这么干净。
