HBM与AI内存竞赛

The HBM and AI Memory Race

也叫：HBM竞赛　存储超级周期　Memory Supercycle　内存短缺　内存荒　DRAM涨价　HBM产能　SK海力士　SK hynix　美光　Micron　三星HBM　HBM3　HBM3E　HBM4　HBM4E

AI加速器的性能越来越取决于HBM的带宽和产能，内存厂商的进度和产能成了算力供应的关键一环。

大模型推理受显存带宽限制，训练受显存容量限制，于是每代GPU最显眼的升级往往是HBM：H100到H200：141GB HBM3e几乎只换了更大更快的HBM3E与SK海力士领先。HBM需要把DRAM芯片用硅通孔堆叠起来，再和GPU一起做先进封装，良率和产能都很难提升。

SK hynix凭借HBM3/HBM3E领先，三星一度掉队，美光追赶；HBM4：2048位接口把接口加宽到2048位，成为Vera Rubin NVL72和AMD Helios机柜与MI455X的基础。HBM也被纳入出口管制（HBM与设备出口管制），华为因此自研HBM（昇腾950PR与自研HBM）。2025年下半年起，AI需求挤占普通DRAM和NAND产能，引发全行业涨价（存储超级周期与内存短缺）；为了补容量，业界又提出用闪存堆叠的HBF高带宽闪存。

讨论焦点：HBM产能何时不再是瓶颈，存储周期会不会反转，以及SRAM、存内计算等绕开HBM的路线能走多远。
