幻觉

Hallucination

也叫：模型幻觉　一本正经地胡说八道　胡编乱造　事实性错误　factuality　confabulation　虚构

在交互版中打开（看它长在树上的哪里）

模型生成了流畅、自信、看起来合理，但与事实不符或与给定材料不一致的内容。比如编造不存在的论文、引文、数字或API。

先要会：语言模型 解码：贪心、束搜索、温度与top-p 泛化与过拟合

用户问一个大模型“某某教授2019年发表的关于X的论文”，它可能给出一个像模像样的标题、合作者和期刊名，而这篇论文根本不存在。这类错误比“答不上来”危险得多，因为它的语气与正确回答没有任何区别。

定义与分类。幻觉综述把它分为两类：

  • 与来源不一致（intrinsic）：给了一篇文档让模型摘要，摘要里却出现了与原文矛盾的说法。
  • 无法从来源验证（extrinsic）：生成了来源中没有、也不符合世界事实的内容，如编造的引用。

在多模态模型里，描述图片中并不存在的物体也叫幻觉，POPE物体幻觉专门评测这一点。

为什么会产生。

  • 训练目标不是“真”。语言模型学的是“哪些文本看起来像训练语料”。对于一个模型没有可靠记忆的事实，“编一个看起来像样的答案”与“给出正确答案”在格式上一模一样，概率也可能差不多。
  • 罕见事实记不住。在语料中只出现过一两次的事实（某个小人物的生日），模型很难可靠记住，但仍会生成某个日期。幻觉的统计根源从统计上论证，即使训练数据完全正确，这类事实上的错误率也有一个下限。
  • 评测鼓励猜。多数基准只按对错计分，“不知道”得0分，和答错一样。在这样的评分下，猜总比不答期望得分高，训练和调优就会推着模型去猜。
  • 解码的随机性（见解码：贪心、束搜索、温度与top-p）：一旦采样出一个错误的token，模型会顺着它继续编下去，以保持前后一致。

缓解办法。

  • 检索增强：先从可信来源找到相关文档放进上下文，再让模型基于它们回答，并给出引用（见检索与向量数据库和检索增强生成RAG）。
  • 校准与拒答：模型知道自己知道什么发现大模型在一定程度上“知道自己知不知道”；训练模型在不确定时说“不知道”，并在评测中惩罚错误答案。
  • 工具和验证：用搜索、计算器、代码执行来核实（见工具调用）。

这些方法都只能降低幻觉，目前还没有办法彻底消除。

例子

为什么按对错计分会鼓励猜。一道题模型只有20%的把握答对。

  • 评分规则A：对得1分，错得0分，答“不知道”得0分。猜的期望得分 = 0.2 × 1 + 0.8 × 0 = 0.2，不答是0。猜更划算。
  • 评分规则B：对得1分，错扣1分，“不知道”得0分。猜的期望得分 = 0.2 × 1 + 0.8 × (−1) = −0.6，不答是0。这时说“不知道”更划算。

在规则B下，只有当把握超过50%时作答才划算。大多数现有基准用的是规则A。

一个典型场景。让模型写一段带参考文献的综述，不给它任何检索工具：引文的作者名、年份、期刊格式都对，但其中一部分文章根本不存在。给它接上文献检索并要求只引用检索结果，这类错误会大幅减少。

容易误解的地方

  • 幻觉不是偶发的程序bug，而是生成式模型工作方式的自然后果；更大的模型通常幻觉更少，但不会归零。
  • 模型语气的自信程度与内容是否正确关系不大，不能用“它说得很肯定”来判断真假。
  • “幻觉”有时被宽泛地用来指一切错误回答，包括推理错误。讨论时最好分清是事实编造、与材料矛盾，还是推理出错。
