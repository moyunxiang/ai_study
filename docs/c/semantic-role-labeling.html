语义角色标注

Semantic Role Labeling

也叫：SRL　semantic role labeling　语义角色　semantic roles　论元　argument structure　论元结构　施事　受事　agent patient　谓词-论元　predicate-argument　浅层语义分析　shallow semantic parsing

在交互版中打开（看它长在树上的哪里）

找出句子里每个谓词（通常是动词）的论元，并标出它们的语义角色：谁是施事、谁是受事、在什么时间地点、用什么工具。它回答“谁对谁做了什么”。

先要会：序列标注 成分句法分析

“张三打碎了花瓶”“花瓶被张三打碎了”“打碎花瓶的是张三”三句话句法结构不同，主语也不同，但事件是同一个：打碎者是张三，被打碎的是花瓶。句法分析（见成分句法分析）告诉我们短语怎么组合，却不直接告诉我们这种事件层面的角色。语义角色标注（SRL）就填这个空。

任务形式。对句中每个谓词：

1. 识别谓词，并确定它的义项（“打”是打碎、打电话还是打车？）。 2. 找出它的论元片段。 3. 给每个论元标一个角色。

角色体系。思想来源是Fillmore格语法的“深层格”：施事、受事、工具、处所等。两个主要的标注资源：

  • PropBank：按谓词编号，ARG0通常是施事（做事者），ARG1通常是受事（被作用者），ARG2及以后的含义随动词而定；另有ARGM-TMP（时间）、ARGM-LOC（地点）、ARGM-MNR（方式）等修饰性角色。
  • FrameNet：以“语义框架”组织，例如“商业交易”框架有买方、卖方、货物、价钱等角色，“买”和“卖”两个词共享这一框架。

方法。语义角色标注首次把SRL做成统计学习任务：先做句法分析，再对句法树上的节点用路径、中心词、语态等特征分类。之后的系统长期依赖句法特征。深度学习时代，SRL被写成序列标注问题，用BIO标签直接在词序列上标出每个谓词的论元，不再强依赖句法树；跨度式端到端SRL进一步把谓词识别、论元识别和角色分类放进一个端到端模型里。

用在哪里。问答（“谁买了什么？”可以直接对齐到ARG0和ARG1）、信息抽取（见信息抽取）、事件抽取的前处理。更完整的语义表示如AMR抽象语义表示把整句话表示成一张以谓词为中心的图，可以看作SRL的扩展。

例子

句子：“昨天 张三 在 店里 用 信用卡 买了 一台 电脑”。以谓词“买”为中心（PropBank风格）：

  • ARG0（买方）：张三
  • ARG1（买的东西）：一台电脑
  • ARGM-TMP（时间）：昨天
  • ARGM-LOC（地点）：在店里
  • ARGM-MNR（方式）：用信用卡

换成“一台电脑昨天被张三在店里用信用卡买走了”，句法主语变成“一台电脑”，但它仍然是ARG1，张三仍然是ARG0——这正是SRL要捕捉的不变性。

容易误解的地方

  • PropBank的ARG2、ARG3等编号对不同动词含义不同，不能跨动词比较。
  • 一句话有几个谓词就有几组角色，同一个短语对不同谓词可能是不同角色。
