链式法则

Chain Rule

也叫：链式求导　复合函数求导　chain rule of calculus　求导法则

在交互版中打开（看它长在树上的哪里）

复合函数的导数等于各层导数的乘积。神经网络是许多层函数的嵌套，链式法则让我们能从输出一层层往回算出每个参数的梯度。

先要会：导数、偏导与梯度

神经网络是一长串函数的嵌套：输入经过第一层、第二层……最后得到损失。我们想知道第一层某个权重稍微变一点，最终损失会怎样变。直接对整个嵌套表达式求导不现实，链式法则给出了系统的办法：把每一层的局部导数乘起来。

单变量形式。若y = f(u)，u = g(x)，则

dy/dx = (dy/du) · (du/dx)

直观理解：x变一点，u跟着变du/dx倍；u变一点，y跟着变dy/du倍；两者连乘就是总效果。

多变量形式。若x影响了多个中间变量u_1, …, u_k，它们又共同影响y，则要把各条路径的贡献加起来：

∂y/∂x = Σ_k (∂y/∂u_k) · (∂u_k/∂x)

写成矩阵形式，就是一串雅可比矩阵与海森矩阵中雅可比矩阵的连乘。

从后往前算更省。网络有上亿个参数，但损失只是一个数。从输出端开始，先算损失对最后一层的导数，再乘上一层的局部导数传回去，每个中间结果只算一次，就能在大约一次前向计算的代价内得到所有参数的梯度。这种“从后往前”的组织方式就是反向传播，在一般计算图上的实现叫反向模式自动微分与计算图。

它出现在哪里。反向模式自动微分最早系统地提出了反向模式自动微分；反向传播把它用于训练多层网络；随时间反向传播BPTT把它用于按时间展开的循环网络。链式法则的连乘结构也解释了梯度消失问题：许多个小于1的因子相乘会迅速趋近于0，见梯度消失与梯度爆炸。

例子

y = (3x + 1)²，求x = 2处的导数。令u = 3x + 1 = 7，则dy/du = 2u = 14，du/dx = 3，所以dy/dx = 14×3 = 42。直接展开验证：y = 9x² + 6x + 1，y' = 18x + 6 = 42。再看连乘的后果：sigmoid函数的导数最大只有0.25，如果网络有10层、每层都乘一个0.25，梯度最多剩下0.25¹⁰ ≈ 9.5×10⁻⁷。

容易误解的地方

  • 反向传播不是一种新的数学，它就是链式法则加上“按正确顺序计算并缓存中间结果”。
  • 多条路径时要把贡献相加而不是只取一条，残差连接的梯度好传，正是因为多了一条导数恒为1的直通路径，见残差连接。
