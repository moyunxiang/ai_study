残差连接

Residual Connections

也叫：skip connection　跳跃连接　shortcut　捷径连接　ResNet　残差网络

在交互版中打开（看它长在树上的哪里）

让一层的输出等于输入加上这一层算出的修正量：y = x + F(x)。它给梯度留了一条直通的路，使上百层的网络也能训练。

先要会：反向传播 梯度消失与梯度爆炸 多层感知机

直觉上网络越深表达能力越强，但2015年之前的经验恰恰相反：普通网络堆到二三十层以后，连训练误差都变高了。这不是过拟合（过拟合是训练误差低、测试误差高），而是优化不动。ResNet论文里，CIFAR-10上56层的普通网络训练误差高于20层的网络。奇怪之处在于：深网络至少可以让多出来的层学成恒等映射，从而和浅网络一样好——但梯度下降找不到这个解。

定义。残差连接让一个模块只学“修正量”：

y = x + F(x)

F是若干层（比如两层卷积，或一个注意力子层）。如果最好的做法是什么都不改，F只需输出0，这比让一堆非线性层精确拼出恒等映射容易得多。要求F(x)和x形状相同；不同时用一个线性投影把x变成同样形状。

为什么梯度能传下去。对y求关于x的导数：

∂y/∂x = I + ∂F/∂x

多了一个单位矩阵I。反向传播穿过L个残差块时，梯度是L个(I + ∂F_l/∂x)的乘积，展开后总有一项是I本身——即使每个∂F都很小，梯度也能原样到达最底层，而不像普通网络那样是L个小数连乘（见梯度消失与梯度爆炸）。另一种看法：残差网络的输出是x加上一串修正项之和，信息在一条“主干道”上流动，每一层往上面读写。

它在哪里出现。Highway网络（2015）先用带门的跳连训练了上百层网络；ResNet把门去掉，用最简单的加法训练出152层的网络赢下ImageNet。之后几乎所有深层网络都用它：Transformer的每个子层外都包一圈残差（见Transformer层的结构），没有它，几十层的大语言模型训不起来。预激活ResNet和Pre-LN Transformer研究了归一化放在残差支路内还是外，发现放在支路内（主干道保持干净）更稳定。最近的超连接尝试把一条主干扩展成多条。

例子

数值。x = [1, 2]，某一层算出F(x) = [0.1, −0.2]，则y = [1.1, 1.8]：这一层只做了小修正。

梯度。假设每层的局部导数∂F/∂x都只有0.01（一维情形）。普通网络堆10层，梯度是0.01^10 = 10^(−20)，等于没有；残差网络每层的导数是1 + 0.01 = 1.01，10层后是1.01^10 ≈ 1.105，几乎原样传回去。

容易误解的地方

  • 残差连接解决的是优化问题（深网络训不动），不是过拟合问题。
  • 残差相加要求形状一致。维度改变时（如通道数翻倍、分辨率减半）需要在跳连上加1×1卷积或线性层。
  • 加法会让主干上的数值随层数逐渐变大，所以残差网络几乎总是配合归一化层使用。
