分类、检测、分割

Classification, Detection, Segmentation

也叫：图像分类　目标检测　object detection　语义分割　semantic segmentation　实例分割　检测分割

在交互版中打开（看它长在树上的哪里）

计算机视觉最基本的三类任务：分类回答“图里是什么”，检测回答“每个东西在哪、是什么”，分割回答“每个像素属于什么”。它们的输出形式和难度依次增加。

先要会：图像作为张量 监督学习 Softmax与logits

“让计算机看懂图片”太笼统，没法训练也没法评测。视觉领域把它拆成几类有明确输入输出的任务，每一类都有自己的数据集、模型和指标。理解它们的区别，是读懂视觉论文的第一步。

图像分类。输入一张图，输出一个类别（或每个类别的概率），用Softmax与logits把分数变成概率。ImageNet有1000个类别，模型对每张图输出1000个数。AlexNet、ResNet、Vision Transformer都首先在这个任务上证明自己，指标见Top-1与Top-5错误率。

目标检测。图里往往有多个物体。检测要输出一组边界框，每个框包括位置(x₁, y₁, x₂, y₂)、类别和置信度。难点是物体数量不定、大小差别大。R-CNN开启了深度学习检测，YOLO把它做到实时，DETR用Transformer直接输出一组框。指标是IoU和mAP，见IoU与mAP。

分割。要求精确到像素。

  • 语义分割：给每个像素一个类别标签，输出一张与原图同尺寸的标签图。两个人站在一起，所有“人”的像素都标成同一类，不区分是谁。全卷积网络FCN是深度学习语义分割的起点。
  • 实例分割：既分类别也分个体，“人1”“人2”各有自己的掩码，如Mask R-CNN。
  • 全景分割：把两者统一，可数的物体分实例，天空、道路等不可数的“背景物质”只分语义。

更多任务。还有关键点检测（人体姿态）、深度估计、目标跟踪、光流等。近年的趋势是用一个大模型统一处理多种任务，或像Segment Anything那样做可提示的通用分割。

例子

一张640×480的街景照片，里面有两个人和一条狗。

  • 分类：输出一个标签，比如“狗”（或“街道”，取决于数据集定义）。
  • 检测：输出3个框，例如(120, 80, 220, 400, 人, 0.97)、(260, 90, 350, 410, 人, 0.94)、(380, 300, 520, 450, 狗, 0.91)。
  • 语义分割：输出640×480=307,200个像素标签，人身上的像素都标“人”，两个人不区分。
  • 实例分割：额外区分出“人1”和“人2”两个掩码。

可以看到，输出信息量从1个标签增加到几十个数，再到几十万个像素标签。

容易误解的地方

  • 分类模型说“图里有狗”，不代表它知道狗在哪；它可能是靠背景（草地、狗绳）判断的。
  • 检测框是轴对齐矩形，对倾斜或细长物体会包进大量背景；需要精确形状时用分割。
  • “分割”在不同论文里可能指语义、实例或全景分割，阅读时先确认是哪一种。
