前馈高斯泼溅

Feed-forward Gaussian Splatting

也叫：前馈3DGS　feed-forward 3DGS　generalizable Gaussian Splatting　泛化高斯　无位姿高斯　pose-free 3DGS　稀疏视图高斯　sparse-view 3DGS　大重建模型　LRM

在交互版中打开（看它长在树上的哪里）

不再为每个场景迭代优化十分钟，而是训练一个网络，看几张照片一次前向就直接预测出整个场景的三维高斯。

原始3D高斯泼溅需要已知相机位姿，并对每个场景优化数千步。前馈高斯把这个过程摊销到训练阶段：网络在大量场景上学会“照片到高斯”的映射，推理时秒级出结果，也能处理只有两三张图的稀疏视图。

pixelSplat前馈高斯从一对已知位姿的图像为每个像素预测高斯；GS-LRM高斯重建把大重建模型LRM式的大Transformer用于高斯输出；AnySplat前馈高斯借助VGGT的几何先验，连相机位姿也一并预测，能处理无标定的随手拍照片。2025–2026年这一方向的论文数量增长很快，重点在去掉位姿依赖、控制逐像素高斯带来的数量爆炸，以及扩展到更多视图。

局限：质量仍普遍低于逐场景优化的3DGS，且受训练数据场景类型限制。
