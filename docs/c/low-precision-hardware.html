低精度算力格式

Low-Precision Number Formats in Hardware

也叫：FP8　FP4　FP6　MXFP4　MXFP8　NVFP4　微缩放格式　Microscaling　块浮点　Block Floating Point　BFP　UE8M0　Tensor Core　低精度训练　4位训练

在交互版中打开（看它长在树上的哪里）

芯片支持的数字格式从32位一路降到8位、4位，每降一次，同样的硅面积就能多算好几倍。

乘法器的面积和功耗大致随位宽平方增长，所以位宽减半，同样的芯片面积可以放下约四倍的乘法器，搬运的数据量也减半。AI硬件因此一代代地降低精度，同时想办法保住模型质量。

V100与Tensor Core的Tensor Core让FP16混合精度训练成为主流（混合精度训练）；H100引入FP8训练格式；MX微缩放格式与FP4提出一组数共享一个缩放因子的微缩放格式，Blackwell与整机柜液冷和Blackwell Ultra/GB300据此支持FP4/FP6。块浮点的思路也出现在光子芯片（光子处理器跑通ResNet/BERT）和存内计算芯片（d-Matrix Corsair存内计算）里。DeepSeek-V3用FP8完成大规模训练，是低精度训练走向实用的标志之一。

悬而未决的问题：4位训练能否稳定，不同厂商的格式能否统一，以及评测时低精度带来的质量损失是否被报告充分。基础的浮点概念见浮点精度：FP32、FP16、BF16、INT8。
