领域自适应与领域泛化

Domain Adaptation and Domain Generalization

也叫：领域自适应　领域适应　域适应　域自适应　domain adaptation　无监督领域自适应　unsupervised domain adaptation　UDA　领域泛化　域泛化　domain generalization　源域　目标域　source domain　target domain　域不变特征　domain-invariant features　梯度反转层　gradient reversal layer　最大均值差异　maximum mean discrepancy

在有标注的源域上训练、要用到分布不同且没有（或很少）标签的目标域时，设法让模型适应新分布。核心手段是对齐两个域的特征分布，或在目标数据上继续预训练。

先要会：分布偏移 迁移学习

在晴天白天的街景上训练的检测器，到了雨夜就频频漏检；在新闻语料上训练的情感分类器，用在医学文本上效果大跌。训练与测试分布不同就是分布偏移。如果能拿到一些目标域的数据，只是没有标签，就可以做领域自适应。

设定。源域有标注数据，目标域有无标注数据（无监督领域自适应）或少量标注数据（半监督）。如果连目标域数据都没有、只能指望模型在没见过的域上也好，叫领域泛化；如果连源数据都拿不到、只有训练好的模型和测试时陆续到来的目标样本，就是测试时适应（见测试时适应和TENT测试时熵最小化）。

理论。领域适应理论（H散度）给出：目标域误差不超过“源域误差 + 两个域在特征空间里的可区分程度 + 一个两域共同最优误差项”。这指明了方向：在源域上学好的同时，让特征无法区分来自哪个域。

主要方法。

  • 对抗式特征对齐：DANN梯度反转域适应在特征提取器之后接一个“域分类器”，并通过梯度反转层让特征提取器去欺骗它，最终得到域不变的特征（思路与对抗训练相同）。
  • 统计量对齐：最小化两个域特征分布之间的距离，例如均值和协方差之差（Deep CORAL相关性对齐）或最大均值差异（MMD）。
  • 像素级转换：用CycleGAN之类的图像翻译把源域图片“画成”目标域风格，再在上面训练。
  • 自训练：用模型给目标数据打伪标签，挑置信度高的加入训练，见半监督学习与伪标签。
  • 继续预训练：在NLP里，最有效的往往是在目标领域的无标注文本上继续做语言模型预训练，再微调，领域与任务自适应预训练系统比较了领域与任务自适应预训练；BioBERT生物医学预训练、PubMedBERT从头领域预训练是生物医学领域的例子（见预训练与微调）。

评测。DomainBed领域泛化评测发现，在公平的超参数选择下，很多领域泛化方法并不比直接在所有源域上做ERM更好（见经验风险最小化）；WILDS分布偏移收集了真实世界的分布偏移基准。机器人里的“仿真到真实”也是一种领域适应，域随机化与Sim2Real走的是另一条路：在仿真中把外观和物理参数随机化到足够宽，让真实世界成为其中一种情况（见仿真到现实的差距）。

例子

源域：有标签的产品评论（电子产品），目标域：无标签的电影评论。直接迁移准确率从源域上的88%降到72%。加入域分类器做对抗对齐后，目标域准确率升到78%；在电影评论上继续做语言模型预训练后再微调，可能进一步提升。（数字为示意）

容易误解的地方

  • 只对齐特征的边缘分布，不保证类别对齐：两个域的“正面”和“负面”可能被错位地对到一起，反而更差。
  • 标签分布也变了（目标域里负面评论多得多）时，需要额外估计和校正类别先验。
