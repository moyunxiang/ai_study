多模态R1式强化学习

R1-Style Reinforcement Learning for MLLMs

也叫：多模态R1　Multimodal R1　R1-V　视觉RLVR　VLM强化学习　多模态推理模型　Multimodal Reasoning Model　多模态慢思考　视觉推理RL　MLLM RL

在交互版中打开（看它长在树上的哪里）

把DeepSeek-R1“用可自动判对错的奖励做强化学习、激发长链推理”的方法搬到看图和看视频的模型上。

OpenAI o1推理模型和DeepSeek-R1之后，语言模型能先写长推理再作答。多模态社区最先尝试的是监督蒸馏：LLaVA-CoT分阶段推理让模型按“总结-描述-推理-结论”四阶段作答。2025年初出现一波R1式工作：Visual-RFT视觉强化微调为检测、分类设计IoU、准确率这类可验证奖励，证明感知任务也能用GRPO强化学习；Vision-R1用DeepSeek-R1造多模态思维链做冷启动，再分阶段放宽长度做RL；Video-R1视频推理RL加入时序奖励，逼模型真正利用帧顺序。

大厂模型也把RL作为标配（Kimi-VL、GLM-4.1V-Thinking），扩散式统一模型也有对应的RL算法（MMaDA多模态扩散）。主要争论：RL带来的提升有多少来自真正的视觉推理，有多少只是文本推理能力和答题格式的迁移；纯文字推理无法回头细看图像，于是出现了在推理中操作图像的路线（见“主动视觉搜索与图像思考”）。
