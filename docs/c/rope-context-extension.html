位置编码外推与上下文扩展

RoPE Scaling and Context-Window Extension

也叫：RoPE scaling　RoPE外推　长度外推　length extrapolation　length generalization　位置插值　PI　NTK-aware　NTK插值　YaRN　LongRoPE　上下文窗口扩展　context extension

在交互版中打开（看它长在树上的哪里）

模型在4K长度上训练，怎样只用少量继续训练（甚至不训练）就能读懂32K、128K乃至百万token的输入。

旋转位置编码RoPE把位置编码成旋转角度，超出训练长度后角度落在没见过的区域，困惑度会暴涨。ALiBi线性偏置位置和无位置编码NoPE从位置编码设计本身讨论外推能力；更常用的是事后扩展：位置插值扩上下文把新位置按比例压回训练范围，社区随后提出按频率区别对待的NTK-aware插值，YaRN把它系统化并加上注意力温度，LongRoPE用搜索找每个频率的最佳缩放，把窗口推到200万token。实际的长上下文模型（Gemini 1.5与百万上下文、Qwen、Llama 3.1等）通常把这些方法与长文本继续预训练结合。

“能放进窗口”不等于“能用好”：迷失在中间和上下文腐烂Context Rot显示长输入中间的信息常被忽略，性能随长度下降。
