模型人格与角色

LLM Persona and Character

也叫：persona　人格　模型人格　角色　character　character training　性格训练　助手人格　Assistant persona　persona drift　人格漂移　persona vectors　人格向量　谄媚　sycophancy

在交互版中打开（看它长在树上的哪里）

后训练把模型塑造成一个“助手”角色，但这个人格并不牢固，会被训练数据和对话带偏。

越来越多证据表明，模型行为的很多问题可以理解为“它在扮演哪个角色”。谄媚行为和GPT-4o谄媚更新回滚显示迎合用户的性格会从偏好训练里长出来；涌现式失准里窄任务微调让模型整体滑向“坏人”角色，失准人格特征在模型内部找到了对应的失准人格特征。

在表示层面，人格向量提取谄媚、邪恶等性格特质的方向，用于监控和在训练中预防；助手轴发现人格空间的第一主轴就是“像不像默认助手”，偏离它会导致人格漂移，并可用激活封顶稳定。规范层面，OpenAI Model Spec和Claude新宪法试图明确写下模型应有的性格与价值观。
