马尔可夫性与马尔可夫链

Markov Property and Markov Chains

也叫：马尔科夫链　无记忆性　转移矩阵　transition matrix　平稳分布

在交互版中打开（看它长在树上的哪里）

马尔可夫性是“未来只取决于现在，与过去无关”。满足这一性质的随机状态序列叫马尔可夫链，它由一张转移概率表完全描述。

先要会：随机变量与概率分布 条件概率与贝叶斯公式 矩阵乘法与线性变换

要对一个随时间演化的随机过程建模，最大的麻烦是历史越来越长：第100步的状态可能依赖前面99步。如果假设“只要知道现在，过去就不再提供额外信息”，模型就一下子简单了：只需要描述从一个状态跳到下一个状态的概率。

马尔可夫性。

P(x_{t+1} | x_t, x_{t−1}, …, x_1) = P(x_{t+1} | x_t)

满足它的状态序列叫马尔可夫链。有限个状态时，链由转移矩阵P描述：P_ij是从状态i跳到状态j的概率，每行之和为1。若当前状态分布是行向量π_t，下一步就是π_{t+1} = π_t P，k步后是π_t P^k，这是一次矩阵乘法与线性变换。

平稳分布。很多链运行足够久后，状态分布会收敛到一个不再变化的π，满足π = πP。它与起点无关，是转移矩阵特征值为1对应的左特征向量，见特征分解与奇异值分解。

状态可以重新定义。“只依赖前一个词”看上去太强，但把“前n−1个词”打包成一个状态，n-gram模型就仍是马尔可夫链，见n-gram与平滑。

它出现在哪里。香农：语言的统计模型用马尔可夫链生成越来越像英语的文字；Metropolis采样与MCMC专门构造一条平稳分布恰好等于目标分布的链，通过长时间运行它来采样；PageRank与Google搜索把网页排名定义为“随机冲浪者”这条链的平稳分布；动态规划与Bellman方程和强化学习的马尔可夫决策过程在马尔可夫链上加入了动作和奖励；DDPM的加噪与去噪过程也都是马尔可夫链。状态不能直接观察时，就是隐马尔可夫模型。

例子

天气只有晴、雨两种。晴天之后90%还是晴天、10%下雨；雨天之后晴、雨各50%。今天晴，后天下雨的概率 = 晴→晴→雨 + 晴→雨→雨 = 0.9×0.1 + 0.1×0.5 = 0.14。长期来看，平稳分布满足π_晴 = 0.9π_晴 + 0.5π_雨，结合π_晴 + π_雨 = 1，解得π_晴 = 5/6 ≈ 0.833：无论今天天气如何，很久以后某天是晴天的概率都约为83%。

容易误解的地方

  • 马尔可夫性是建模假设而不是事实，关键在于“状态”包含了什么。语言显然有长距离依赖，Transformer可以看成把整段上下文都当作状态。
  • 不是每条链都收敛到唯一的平稳分布：有周期或不连通的链可能不收敛，或收敛结果依赖起点。
