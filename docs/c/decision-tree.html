决策树

Decision Trees

也叫：CART　ID3　C4.5　GBDT　树模型　信息增益

在交互版中打开（看它长在树上的哪里）

用一连串“某个特征是否大于某个阈值”的是非题把数据逐层切分，叶子节点给出预测；多棵树集成后至今仍是表格数据上的强力方法。

先要会：监督学习 信息量与熵

很多实际数据是表格：每行一个样本，每列一个特征（年龄、收入、是否有房……）。人做判断时常用的就是一串规则：“收入大于5万吗？是 → 有房吗？……”。决策树把这种规则自动从数据里学出来。

结构：每个内部节点问一个问题x_j ≤ t ?，按回答把样本分到左右子树；叶子节点存一个预测值（分类时是多数类别，回归时是平均值）。预测一个新样本，就是从根走到叶子。

怎么学：贪心地自顶向下切分。在当前节点，枚举每个特征和每个可能的阈值，选让子节点“最纯”的那个切分，然后对左右子集递归。纯度常用基尼不纯度G = 1 − Σ_k p_k²或信息量与熵衡量，p_k是节点里第k类的比例。切分的收益是父节点不纯度减去子节点按样本数加权的不纯度。经典算法是决策树CART（1984）。

问题与补救：一棵树长得足够深，可以把训练集每个样本都分对，但这是严重的过拟合（见泛化与过拟合、偏差-方差权衡）——单棵深树方差很大，数据稍变树就完全不同。办法是集成学习：随机森林在随机子样本、随机特征子集上训练很多棵树再投票，降低方差；梯度提升机GBM和XGBoost则一棵接一棵地拟合前面所有树的残差，逐步降低偏差。

它在AI里的位置：在图像、文本、语音上，深度网络早已取代树模型；但在中小规模的表格数据上，梯度提升树仍经常比神经网络更好、更快、更省事，是Kaggle类比赛和工业风控、推荐的常用基线。

例子

10个样本，6个正类、4个负类。根节点基尼不纯度 = 1 − (0.6² + 0.4²) = 0.48。

候选切分“收入 > 5万”：左边4个样本全是正类，G = 0；右边6个样本里2正4负，G = 1 − (1/9 + 4/9) ≈ 0.444。加权不纯度 = 0.4×0 + 0.6×0.444 ≈ 0.267，收益 0.48 − 0.267 ≈ 0.213。算法会对所有特征和阈值算这个收益，挑最大的切。

容易误解的地方

  • 决策树看起来“可解释”，但深树或几百棵树的集成实际上很难人工读懂。
  • 树模型的切分只能是与坐标轴平行的阈值，遇到“两个特征之差”这类斜向边界需要很多次切分才能近似。
  • 树模型不能外推：回归时预测值永远落在训练集目标值的范围内。
