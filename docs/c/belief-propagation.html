在概率图模型上做推断的消息传递算法：每个节点把“我对邻居的看法”作为消息发出去，汇总收到的消息就得到自己的边缘概率。在树上精确，在有环的图上近似。

先要会：概率图模型 条件概率与贝叶斯公式

概率图模型用一张图描述很多变量之间的依赖。拿到图之后，最常见的问题是推断：给定一部分变量的观测值，其余每个变量的概率分布（边缘概率）是多少？直接对所有其他变量求和，计算量随变量数指数增长。信念传播（belief propagation，BP，Pearl在1980年代提出）利用图的结构把这个求和拆成局部计算。

核心思想。在树结构上，每条边上传递一条“消息”m_{i→j}(x_j)，表示节点i（及i那一侧的整棵子树）对x_j各个取值的支持程度：

m_{i→j}(x_j) = Σ_{x_i} ψ_i(x_i) · ψ_{ij}(x_i, x_j) · Π_{k∈邻居(i)\j} m_{k→i}(x_i)

ψ是节点和边上的势函数（局部打分）。节点j的边缘概率正比于它自身的势乘以所有传入消息：p(x_j) ∝ ψ_j(x_j)·Π_k m_{k→j}(x_j)。消息从叶子传到根、再从根传回叶子，两遍之后所有节点的边缘概率都精确算出，代价只和边数成正比。

两个熟悉的特例。

  • 链上的BP就是隐马尔可夫模型的前向–后向算法（见隐马尔可夫模型和Baum-Welch算法）；把求和换成求最大值就是Viterbi算法算法（max-product），求的是最可能的整条序列。
  • 线性链条件随机场的训练和解码用的也是同样的前向–后向与Viterbi过程。

有环的图。图里有环时，消息会绕圈回到自己，算法不再精确。环状信念传播（loopy BP）照样迭代消息直到稳定，常常给出很好的近似，例如通信中Turbo码和LDPC码的译码本质上就是loopy BP。精确推断则需要把图变成“联结树”，代价取决于树宽。

和神经网络的联系。图神经网络的图神经网络与消息传递（如消息传递神经网络MPNN、图卷积网络）借用了“节点汇总邻居消息再更新自己”的结构，只是把固定的求和乘积公式换成了可学习的神经网络；全连接CRF用平均场近似在全连接CRF上做快速推断，曾是语义分割的标准后处理（见变分推断与ELBO中的变分推断思路）。

例子

三个二值变量组成的链A—B—C，只有C被观测为1。BP从C向A传：C给B的消息是“B取每个值时C = 1的可能性”，B把它和自己的势结合后传给A。A只需要收到一条来自B的消息就能得到p(A | C = 1)，无需对B和C的全部4种组合逐一求和。变量数增加到100时，直接求和要2⁹⁹项，BP只需要99次局部计算。

容易误解的地方

  • loopy BP不保证收敛，即使收敛也只是近似，在环很短、耦合很强的图上可能很不准。
  • 消息需要归一化，否则多次相乘后会上溢或下溢；实践中常在对数空间计算，见数值稳定性：上溢、下溢与条件数。
