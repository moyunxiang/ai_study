群体公平：人口均等、差别影响与均等几率

Group Fairness Criteria

也叫：群体公平　group fairness　公平性指标　fairness metrics　算法公平　algorithmic fairness　人口均等　人口统计均等　统计均等　demographic parity　statistical parity　差别影响　disparate impact　差别对待　disparate treatment　五分之四规则　80%规则　four-fifths rule　80% rule　均等几率　equalized odds　校准公平　受保护属性　protected attribute

按群体比较模型决策的一组公平标准：人口均等要求各群体获批比例相同，五分之四规则判断比例差异是否过大，均等几率要求各群体错误率相同。这些标准通常无法同时满足。

先要会：准确率、精确率、召回率与F1 条件概率与贝叶斯公式

贷款审批、招聘筛选、再犯风险评估，模型的决定直接影响人的机会。即使训练时没有使用“性别”“种族”这些特征，模型也可能通过邮编、姓名、毕业学校等相关特征学到历史数据中的偏见。群体公平用统计量来检查：不同群体是否被区别对待了？

设A是受保护属性（如性别），Ŷ是模型的决定（1为批准），Y是真实结果。

人口均等（demographic parity，又称统计均等）。

P(Ŷ = 1 | A = a) = P(Ŷ = 1 | A = b)

各群体获批比例相同，不考虑他们的真实资质是否不同。

差别影响与五分之四规则。美国就业领域长期使用的经验标准：受保护群体的录用率除以录用率最高群体的录用率，若低于0.8，就被视为存在不利影响的初步证据。它是人口均等的一个宽松的比率形式。“差别影响”（disparate impact）指表面中立的规则造成了群体间不成比例的不利结果，与“有意的差别对待”（disparate treatment）相对。

机会均等与均等几率。机会均等提出：只看录取比例不够，还应看错误率。均等几率要求各群体的真正例率和假正例率都相同；机会均等只要求真正例率相同（真正合格的人被批准的概率一样，见准确率、精确率、召回率与F1）。

校准公平。在每个群体中，模型说“70%风险”的人，实际出事的比例都应约为70%（见模型校准）。

不可能同时满足。当各群体的真实基础率不同时，校准与均等几率在数学上无法同时成立（除非模型完美）：这是公平性不可兼得和再犯预测的差别影响在分析COMPAS再犯预测争议（ProPublica《Machine Bias》）时得出的结论。选择哪一种标准本质上是价值判断，而不只是技术问题。

其他视角。个体公平（个体公平）要求“相似的人得到相似的对待”；反事实公平（反事实公平）问的是“如果这个人属于另一个群体，决定会变吗”（见因果推断：相关、混杂与干预）；公平机器学习的延迟影响指出静态的公平约束在长期反馈中可能反而伤害被保护群体。Gender Shades与算法公平则展示了人脸识别在不同肤色和性别群体上准确率的巨大差异。

怎么做。预处理（重新加权、去相关）、训练中加公平约束或正则、后处理（各群体用不同阈值）。每种做法都在准确率和不同公平标准之间做取舍。

例子

某招聘模型：男性申请者100人中录用40人（40%），女性100人中录用24人（24%）。比率24%/40% = 0.6 < 0.8，按五分之四规则存在不利影响；人口均等差为16个百分点。若进一步看真正合格者：合格男性50人中录用35人（TPR 70%），合格女性40人中录用20人（TPR 50%），机会均等也不满足。

容易误解的地方

  • 去掉受保护属性并不能保证公平（“通过无知实现公平”无效），代理变量照样会泄露它。
  • 公平指标依赖于群体的划分方式；在整体群体上公平，在交叉群体（如“年长女性”）上可能严重不公平。
