最小描述长度与“压缩即学习”

Minimum Description Length and Compression

也叫：最小描述长度　MDL　minimum description length　MDL原则　MDL principle　压缩即智能　compression is intelligence　学习即压缩　预测即压缩　prediction is compression　柯尔莫哥洛夫复杂度　Kolmogorov complexity　Kolmogorov复杂度　算术编码　arithmetic coding　无损压缩　lossless compression　奥卡姆剃刀　Occam's razor　香农编码定理　source coding theorem

“学习就是压缩”：能用更短的描述说清楚数据的模型更好。最小描述长度原则把模型自身的长度和用模型编码数据的长度加在一起比较，语言模型的交叉熵就是一种压缩率。

先要会：信息量与熵 交叉熵

两个模型在训练集上一样好，该选哪个？泛化与过拟合的老问题有一个信息论的回答：选能把数据“压得更短”的那个。

预测即压缩。根据香农的编码定理，一个对数据赋予概率q(x)的模型，可以配合算术编码把x编码成大约−log₂ q(x)比特。所以语言模型在一段文本上的平均交叉熵，就是用它压缩这段文本时每个token需要的比特数；模型预测得越准，压缩得越短（见困惑度）。“bits per byte”这类指标直接把语言建模质量报告成压缩率。语言建模即压缩实证展示了大语言模型配合算术编码，在文本乃至图像、音频上都是很强的无损压缩器。

最小描述长度（MDL）原则。Rissanen在1978年前后提出：选使下式最小的模型M

L(M) + L(数据 | M)

前一项是描述模型本身需要的比特数，后一项是用该模型编码数据的比特数（即负对数似然）。复杂的模型让第二项变小，但第一项变大；两者之和最小的模型在“拟合”与“简单”之间取得平衡。这是奥卡姆剃刀的一种可计算版本，也和贝叶斯方法相通：−log P(M) − log P(数据 | M)，第一项对应先验，见先验、后验与贝叶斯推断和正则化与权重衰减。

柯尔莫哥洛夫复杂度。理论上的极限：一个字符串的复杂度是能输出它的最短程序的长度。它不可计算，但给了“规律性 = 可压缩性”一个精确定义；随机字符串几乎不可压缩。

它出现在哪里。

  • 解释深度学习为何泛化：一些工作用“训练后的网络能被压缩到多小”来给出泛化界；知识蒸馏和剪枝也说明大网络中存在大量冗余。
  • 分词：BPE子词切分源自数据压缩算法BPE压缩算法，把频繁出现的字节对合并成新符号，见分词与token。
  • 有损压缩的对应理论是率失真理论。

例子

一段1000个字符的英文文本，用ASCII存是8000比特。若某个语言模型在这段文本上的平均交叉熵为每字符1.2比特，配合算术编码可以把它压到约1200比特，约为原来的15%；一个只知道字母频率的模型大约需要每字符4比特以上。

容易误解的地方

  • 交叉熵等于压缩长度的前提是接收方也有同一个模型；如果要把模型本身一起传过去，大模型的“压缩率”就要加上它巨大的参数量。
  • MDL里模型长度的计算方式（怎样编码参数、用多少精度）没有唯一答案，不同约定会给出不同的选择。
