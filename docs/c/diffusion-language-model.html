扩散语言模型

Diffusion Language Models

也叫：DLM　DLMs　dLLM　dLLMs　Diffusion LLM　扩散大语言模型　扩散LLM　MDM　Masked Diffusion Model　掩码扩散模型　masked diffusion　离散扩散　discrete diffusion　文本扩散　text diffusion　非自回归语言模型　并行解码　LLaDA　Mercury　Gemini Diffusion

在交互版中打开（看它长在树上的哪里）

不再从左到右一个词一个词地写，而是先把整段文字遮住，再一步步并行“去噪”还原，一次能写出多个词、还能回头修改。

自回归模型（自回归生成）每步只写一个词，延迟随长度线性增长，也不能改已写的内容。扩散语言模型把图像扩散（扩散：前向加噪与反向去噪）的思路搬到离散文本上：训练时随机把一部分词替换成掩码，让模型还原；生成时从全掩码出发，每步并行揭开一批最有把握的位置。

路线源自离散扩散D3PM的离散扩散和Diffusion-LM的连续扩散，离散扩散语言模型SEDD、掩码扩散语言模型MDLM把掩码扩散的训练目标简化到能和自回归比困惑度。2025年LLaDA大语言扩散模型把它做到8B，块扩散BD3-LM用“块间自回归、块内扩散”找回KV缓存；DiffuLLaMA自回归转扩散开创的“从自回归模型转换”让规模迅速放大到LLaDA2.0百亿级扩散的100B和DiffusionGemma。商用侧有Mercury商用扩散LM、Gemini Diffusion、Mercury 2推理扩散模型。推理加速（Fast-dLLM免训练加速）、强化学习后训练（d1扩散模型推理RL、dOPSD扩散语言模型自蒸馏）和数据效率（数据受限时扩散胜自回归）是当前三条主要研究线，综述见扩散语言模型DLM综述。

争论集中在：质量是否真能追平同规模自回归模型、并行带来的加速在大批量服务中还剩多少、条件独立假设导致的“前后不搭”如何根治。
