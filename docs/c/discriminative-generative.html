判别模型与生成模型

Discriminative vs Generative Models

也叫：判别式模型　生成式模型　discriminative model　generative model　p(y|x)　p(x,y)

在交互版中打开（看它长在树上的哪里）

判别模型直接学“给定输入，输出是什么”的条件概率p(y|x)；生成模型学数据本身是怎么产生的，即p(x, y)或p(x)，因此还能用来生成新样本。

先要会：条件概率与贝叶斯公式 随机变量与概率分布 逻辑回归

同样是做分类，有两种根本不同的思路。

判别模型只关心决策边界：直接建模p(y | x)，或者直接学一个从x到y的映射。逻辑回归、SVM、普通的图像分类网络都是判别模型。它不关心x本身长什么样，只关心怎样区分不同类别。

生成模型建模数据的生成过程：先学p(y)（各类有多常见）和p(x | y)（每一类的数据长什么样），合起来就是联合分布p(x, y)。分类时用条件概率与贝叶斯公式中的贝叶斯公式反推：

p(y | x) = p(x | y)·p(y) / p(x)

经典例子是朴素贝叶斯分类：假设给定类别后各个特征相互独立，用来做垃圾邮件过滤。

两者的取舍：生成模型要描述整个x的分布，任务更重、假设更强，但数据少时往往更稳，也能处理缺失的特征；判别模型把全部能力用在分类边界上，数据充足时通常更准。经典比较显示，朴素贝叶斯在小样本时更快接近其最佳表现，逻辑回归在数据多时最终误差更低。

今天的含义更宽：在深度学习语境里，“生成模型”常常指能生成新样本的模型，即学会p(x)并能从中采样，比如生成图片的生成对抗网络GAN、DDPM，以及生成文本的语言模型（GPT-3），详见生成建模的目标。条件生成p(x | y)——给定文字描述生成图片——也属于这一类。判别与生成也在融合：大语言模型本身是生成模型，却能通过生成答案来完成分类等判别任务。

例子

垃圾邮件过滤，生成模型的思路：已知20%的邮件是垃圾邮件；垃圾邮件中有50%包含“免费”，正常邮件中只有5%包含“免费”。

一封含“免费”的邮件是垃圾邮件的概率：

p(垃圾 | 免费) = 0.2×0.5 / (0.2×0.5 + 0.8×0.05) = 0.1 / 0.14 ≈ 0.714

判别模型（如逻辑回归）则跳过p(免费 | 垃圾)这类量，直接从数据里学“含‘免费’时是垃圾邮件的概率”。

容易误解的地方

  • “生成模型”一词有两层意思：经典统计里指建模p(x, y)的分类器，深度学习里多指能采样出新数据的模型，读论文时要看语境。
  • 生成模型能生成样本，不代表它给出的概率p(x)就可靠，例如有的模型会给分布外的数据更高的似然。
