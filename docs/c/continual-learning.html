持续学习与灾难性遗忘

Continual Learning and Catastrophic Forgetting

也叫：终身学习　lifelong learning　增量学习　incremental learning

在交互版中打开（看它长在树上的哪里）

让模型按顺序学一个又一个任务而不忘掉旧的；神经网络直接接着训练新任务时，旧任务的表现会急剧下降，称为灾难性遗忘。

先要会：梯度下降 预训练与微调

现实中数据是陆续到来的：机器人每天遇到新物体，语言模型需要吸收新知识。理想情况是像人一样边用边学。但神经网络有个顽固的毛病：在任务A上训练好后，接着只用任务B的数据训练，A上的准确率往往会掉到接近随机。这就是灾难性遗忘（1989年就被发现）。原因很直接：所有任务共享同一组权重，梯度下降只看当前损失，会毫不顾忌地改动对旧任务关键的权重。

定义：持续学习研究在任务序列T₁, T₂, …上训练，每一阶段只能（或主要）访问当前任务的数据，目标是最终在所有任务上都好，同时尽量能利用旧知识加快学新任务。

三类方法：

  • 正则化：给重要的旧权重加“弹簧”。EWC弹性权重巩固用费雪信息估计每个权重对旧任务的重要性F_i，在新任务损失上加惩罚(λ/2) Σ_i F_i (θ_i − θ*_i)²，越重要的权重越难被拉走。
  • 回放：保留一小部分旧数据（或用生成模型合成），与新数据混在一起训练。实践中最简单也往往最有效。
  • 结构隔离：给每个任务分配独立的参数，例如新加一组小模块，旧参数冻结。参数高效微调中的LoRA适配器就常被这样使用。

在大模型里：预训练与微调本身就是两阶段的持续学习，微调后模型在通用能力上的退化是同一现象。指令微调与对话模板、领域继续预训练时，常见做法就是混入一部分原始预训练数据作回放。这也是分布偏移下模型需要更新时绕不开的问题。

例子

两个参数，任务A的最优值θ* = (1.0, 2.0)，EWC估计的重要性F = (10, 0.1)，λ = 1。

训练任务B时，若把θ₁挪动0.5，惩罚为0.5×10×0.25 = 1.25；把θ₂挪动同样的0.5，惩罚只有0.5×0.1×0.25 = 0.0125。于是优化器会主要改θ₂来适应新任务，保住对任务A关键的θ₁。

容易误解的地方

  • “遗忘”不一定是知识真的被抹掉，有时只是输出层偏向了新任务，重新校准一下就能恢复不少。
  • 很多方法在“测试时告诉你是哪个任务”的设定下效果好，在不告诉任务编号的类增量设定下会大幅变差，比较论文时要看清设定。
  • 实验里任务边界清晰，现实中数据分布往往是缓慢漂移的，没有明确的任务切换点。
