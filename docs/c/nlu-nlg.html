自然语言理解与自然语言生成

Natural Language Understanding and Generation

也叫：自然语言理解　natural language understanding　NLU　自然语言生成　natural language generation　NLG　意图识别　intent detection　intent classification　槽位填充　slot filling　数据到文本生成　data-to-text　理解与生成　口语理解　spoken language understanding　SLU

NLP的两大方向：自然语言理解（NLU）把文本变成结构或判断，如分类、抽取、问答；自然语言生成（NLG）产出文本，如翻译、摘要、对话。大模型把两者统一成“读进来、写出去”。

先要会：语言模型

自然语言理解（NLU）。目标是从文本中得到“意思”：这条评论是正面还是负面（情感分析），句中哪些词是人名地名（命名实体识别），前一句能否推出后一句（自然语言推理与文本蕴含），这个问题的答案在文中哪里（机器阅读理解），用户这句话想订机票还是查天气（意图识别与槽位填充）。输出通常是一个标签、一段文本片段或一个结构。早期的SHRDLU、LUNAR月岩问答在很小的领域里把句子解析成可执行的查询，是“理解”的最早尝试。

自然语言生成（NLG）。目标是产出流畅、正确、符合需要的文本：机器翻译、文本摘要、对话回复、从表格或数据库生成报告（数据到文本）、图像描述。传统NLG分成“说什么”（内容选择、篇章规划）和“怎么说”（句子规划、表层实现）几个阶段；神经网络时代改为编码器-解码器或语言模型直接端到端生成（见自回归生成和解码：贪心、束搜索、温度与top-p）。

评测的差异。NLU任务通常有标准答案，用准确率、F1等指标（见准确率、精确率、召回率与F1和精确匹配与token级F1）；GLUE / SuperGLUE、SuperGlue就是NLU基准的集合。NLG的“正确答案”不唯一，需要文本生成的自动指标中的BLEU、ROUGE等自动指标，最终还要靠人工评测。

预训练时代的分工与合流。BERT这类仅编码器模型擅长NLU，GPT-2这类仅解码器模型擅长NLG，T5和BART这类编码器-解码器模型两者兼顾（见仅编码器、仅解码器与编码器-解码器）。T5把所有任务都写成“文本到文本”，分类也变成生成一个标签词；GPT-3之后，大语言模型通过提示同时完成理解和生成任务（见上下文学习与提示），NLU与NLG的界限在应用层面基本消失，但作为任务分类和评测方式的区分仍然常用。

例子

同一个客服场景里：“我想把明天去上海的航班改到后天”——NLU要输出{意图：改签，目的地：上海，原日期：明天，新日期：后天}；NLG则要根据系统查询结果生成回复“已为您查询到后天上午10点的航班，是否确认改签？”。

容易误解的地方

  • “理解”在这里是任务意义上的：模型在NLU基准上得高分，不代表它像人一样理解了语言，基准可能存在捷径（见基准、排行榜与SOTA）。
  • NLG的流畅不等于正确，生成模型可能写出通顺但与事实不符的内容（见幻觉）。
