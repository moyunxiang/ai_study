轻量化卷积网络

Efficient / Mobile CNN

也叫：轻量网络　lightweight network　移动端网络　mobile network　深度可分离卷积　depthwise separable convolution　分组卷积　group convolution　端侧视觉模型　efficient architecture　神经架构搜索　NAS　复合缩放　compound scaling

在交互版中打开（看它长在树上的哪里）

在手机、摄像头等算力有限的设备上，用更少的参数和计算量达到接近大网络的精度。

VGG、ResNet这类网络动辄几十亿次乘加运算，无法在手机上实时运行。轻量化设计的核心手段是拆分卷积：Xception和MobileNet把标准卷积拆成逐通道卷积加1×1卷积（深度可分离卷积），计算量降到原来的几分之一；ShuffleNet用分组卷积加通道重排；MobileNetV2提出倒残差和线性瓶颈。

此后自动化方法登场：NASNet用神经架构搜索找结构，EfficientNet提出同时按比例放大深度、宽度和分辨率的复合缩放，RegNet设计空间从设计空间统计规律中总结出简单规则。这些思想也影响了检测（EfficientDet）和后来的高效ViT设计。

注意：参数量和FLOPs少不等于实际延迟低（参数量、计算量与显存），真实速度强依赖硬件与算子实现。
