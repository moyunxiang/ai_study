模仿学习与行为克隆

Imitation Learning and Behavior Cloning

也叫：BC　示教学习　learning from demonstration　LfD

在交互版中打开（看它长在树上的哪里）

不靠奖励试错，而是看专家怎么做、照着学。最简单的行为克隆就是把专家的“状态→动作”记录当作监督学习数据来训练策略。

先要会：监督学习 马尔可夫决策过程 分布偏移

很多任务里写出好的奖励函数很难（“开车开得好”怎么打分？），而让一个会做的人演示几遍却很容易。模仿学习就是从专家示范中学策略，绕开奖励设计和漫长的试错。

行为克隆（BC）。收集专家轨迹里的(状态s, 动作a)对，训练策略网络π_θ(a|s)去预测专家动作，就是普通的监督学习：离散动作用交叉熵，连续动作用均方误差或更强的生成模型。1989年的ALVINN端到端驾驶用这种方法，让神经网络看摄像头画面学习人类司机的方向盘角度。大语言模型的监督微调（SFT）本质上也是行为克隆：模仿人类写的回答。

核心问题：误差累积。训练数据只来自专家走过的状态。策略一旦犯了一个小错，就会进入专家从没去过的状态，这里没有训练数据，于是错得更多，越走越偏。这是一种分布偏移。理论上，若每步出错概率为ε、任务长T步，行为克隆的总代价可能按εT²增长，而不是εT。

怎么缓解。

  • DAgger：让学到的策略自己去跑，把它到达的状态拿给专家标注“这里该怎么做”，加入数据集再训练，反复几轮。代价按εT增长，但需要专家能随时在线标注。
  • 逆强化学习：从示范里反推专家在优化什么奖励，再用强化学习去优化它；GAIL用对抗训练实现这一点。
  • 更好的动作表示：机器人示范常是多峰的（绕障碍从左从右都行），平均起来反而撞上。ALOHA与ACT一次预测一段动作块，Diffusion Policy用扩散模型表示动作分布，见动作表示：离散token、连续动作与动作块。

今天的机器人基础模型主要靠大规模遥操作与示教数据示范数据做行为克隆，再视情况加强化学习微调。

例子

假设策略在每一步有1%的概率犯一个让它偏离专家轨迹的错误，且一旦偏离就再也回不到熟悉的状态。那么走完100步都不出错的概率只有0.99^100 ≈ 0.366，走50步是0.99^50 ≈ 0.605。任务越长，模仿出来的策略越容易“走丢”。

DAgger的一轮：训练出的驾驶策略开着开着偏到了车道边缘（专家示范里从没出现过的状态），专家看着这些画面标注“应该向左打方向盘”，这些新数据加入训练集后，策略就学会了如何从偏离中纠正回来。

容易误解的地方

  • 模仿学习的上限通常是专家水平；要超过示范者，需要再加强化学习或用奖励筛选数据。
  • 示范者的习惯和失误也会被一起学走；示范之间风格不一致时，简单回归会学成“平均动作”，可能哪个都不像。
  • 训练集上动作预测得准，不代表实际执行得好，必须在闭环（让策略自己跑）里评估。
