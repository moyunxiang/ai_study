f散度、JS散度与总变差距离

f-Divergences, JS Divergence and Total Variation

也叫：f散度　f-divergence　f-divergences　JS散度　Jensen-Shannon散度　Jensen-Shannon divergence　JSD　总变差距离　总变差　total variation distance　TV distance　TVD　χ²散度　卡方散度　chi-squared divergence　Pearson χ²　反向KL　reverse KL　分布距离　统计距离

比较两个分布差异的一族度量，KL散度只是其中之一；常见的还有对称且有界的JS散度、直观的总变差距离。原始GAN优化的就是JS散度。

先要会：KL散度 Jensen不等式

KL散度最常用，但它不对称，而且只要模型在数据有概率的地方给出0概率，就会变成无穷大。不同任务需要不同的“分布距离”，f散度把很多选择放进同一个框架。

f散度。取一个凸函数f，满足f(1) = 0，定义

D_f(p ‖ q) = Σ_x q(x) · f(p(x) / q(x))

由Jensen不等式（见Jensen不等式），它总是非负，在p = q时为0。f选不同的函数，就得到不同的散度：

  • f(t) = t log t：KL(p ‖ q)。
  • f(t) = −log t：反向KL，即KL(q ‖ p)。
  • f(t) = ½|t − 1|：总变差距离。
  • f(t) = (t − 1)²：皮尔逊χ²散度。

JS散度（Jensen–Shannon）。令m = (p + q)/2，

JS(p, q) = ½ KL(p ‖ m) + ½ KL(q ‖ m)

它对称、有界（以自然对数计最大为ln 2），两个分布完全不重叠时取到最大值。其平方根满足三角不等式，是一个真正的距离。

总变差距离（TV）。TV(p, q) = ½ Σ |p(x) − q(x)|，等于“任意事件在两个分布下概率之差”的最大值，取值在0到1之间，含义最直观。扩散模型和采样算法的收敛性理论常用TV衡量生成分布离目标有多远（例如扩散采样收敛理论）。

它们出现在哪里。

  • 生成对抗网络GAN：在判别器最优时，原始GAN的生成器目标等价于最小化数据分布与生成分布之间的JS散度。两个分布在高维空间里几乎不重叠时，JS恒为ln 2、梯度消失，这是Wasserstein GAN改用Wasserstein距离的主要动机（见最优传输与Wasserstein距离）；最小二乘GAN LSGAN的目标则对应皮尔逊χ²散度。
  • 后来的f-GAN工作证明，任意f散度都可以写成一个“判别器”的变分下界来训练。
  • DoLa层间对比解码等解码方法用JS散度比较不同层输出的分布差异。
  • 选择用哪个方向的KL或哪种散度，直接决定模型倾向于“覆盖所有模式”还是“只抓一个模式”，见模式坍塌与模式覆盖。

例子

p = (0.5, 0.5, 0)，q = (0, 0.5, 0.5)。KL(p ‖ q)为无穷大（第一类p > 0而q = 0）。TV = ½(0.5 + 0 + 0.5) = 0.5。m = (0.25, 0.5, 0.25)，KL(p ‖ m) = 0.5 ln 2 + 0.5 ln 1 ≈ 0.347，对称地KL(q ‖ m)也是0.347，JS ≈ 0.347，有限且对称。

容易误解的地方

  • Wasserstein距离不是f散度，它考虑的是“把概率质量搬多远”，在分布不重叠时仍能给出有意义的梯度。
  • JS散度的上限取决于对数底：自然对数为ln 2 ≈ 0.693，以2为底则为1。
