回归指标：MAE、RMSE、MAPE与R²

Regression Metrics: MAE, RMSE, MAPE and R²

也叫：回归指标　regression metrics　MAE　平均绝对误差　RMSE　均方根误差　root mean squared error　MAPE　平均绝对百分比误差　mean absolute percentage error　R²　R2　R方　R-squared　决定系数　coefficient of determination　RMSLE　sMAPE　解释方差　explained variance

评价连续值预测的指标：MAE是平均差多少，RMSE对大误差更敏感，MAPE按百分比算，R²说明模型比“永远猜平均值”好多少。选哪个取决于业务上怎样的误差最要紧。

先要会：回归损失：MSE、MAE与Huber 期望与方差

预测温度、房价、销量、分子能量时，没有“对”或“错”，只有“差多少”。不同的指标把“差多少”汇总成一个数的方式不同，结论有时会相反。设真实值y_i，预测ŷ_i，误差e_i = ŷ_i − y_i：

MAE（平均绝对误差）。MAE = (1/n)·Σ|e_i|。单位与原数据相同，含义最直观：“平均差了2.3度”。对离群点不敏感。

MSE与RMSE。MSE = (1/n)·Σe_i²，RMSE = √MSE。RMSE单位与原数据相同，但平方让大误差占的比重大得多：同样的MAE下，误差越不均匀，RMSE越大。总有RMSE ≥ MAE。若偶尔的大错代价特别高（如电网负荷预测），RMSE更合适。它们与训练时的损失函数同名，见回归损失：MSE、MAE与Huber。

MAPE（平均绝对百分比误差）。MAPE = (100%/n)·Σ|e_i / y_i|。与量纲无关，便于在销量差异很大的商品之间比较；但真实值接近0时会爆炸，而且对“预测偏高”和“预测偏低”的惩罚不对称。

R²（决定系数）。

R² = 1 − Σe_i² / Σ(y_i − ȳ)²

分母是“永远预测平均值ȳ”这个最笨的基线的平方误差。R² = 1表示完美预测，R² = 0表示和猜平均值一样，R²为负说明比猜平均值还差。它衡量模型解释了目标方差的多大比例（见线性回归）。

相关系数类。有时只关心预测值与真实值的排序或线性关系是否一致，例如句子相似度任务用Pearson或Spearman相关系数评估，Sentence-BERT在STS基准上报告的就是Spearman相关，见排名相关：Spearman与Kendall。

它出现在哪里。GraphCast与AI天气预报等AI天气预报模型在WeatherBench 2上用按纬度加权的RMSE和异常相关系数（ACC）与数值预报比较；分子性质预测基准QM9小分子量子化学库常报告MAE；Kaggle数据竞赛竞赛会按题目指定RMSE、RMSLE（对数后再算RMSE，适合右偏的目标）或MAPE。

例子

真实值(10, 20, 30, 40)，预测(12, 18, 33, 30)。误差(2, −2, 3, −10)。MAE = 17/4 = 4.25；RMSE = √((4 + 4 + 9 + 100)/4) = √29.25 ≈ 5.41，被那一个−10拉高；MAPE = (20% + 10% + 10% + 25%)/4 ≈ 16.3%。ȳ = 25，Σ(y − ȳ)² = 500，R² = 1 − 117/500 ≈ 0.77。

容易误解的地方

  • R²高不代表预测准：目标方差很大时，即使绝对误差很大，R²也可能很高；反之亦然。要和MAE/RMSE一起看。
  • 在不同数据集之间比较RMSE没有意义，因为它带单位、受目标尺度影响；跨数据集比较用R²或相对误差。
