自由度、运动学与本体感知

Degrees of Freedom, Kinematics, Proprioception

也叫：DoF　正运动学　逆运动学　inverse kinematics　IK

在交互版中打开（看它长在树上的哪里）

自由度是机器人能独立运动的关节数；运动学研究关节角度与手爪空间位置之间的换算；本体感知是机器人对自己关节角度、速度和受力的测量。

先要会：向量、矩阵与张量

要让机器人把手伸到杯子旁边，必须能在两种描述之间来回换算：电机只懂“每个关节转多少度”，任务说的却是“手爪到空间里某个点”。运动学就是这套换算，自由度决定了能换算出多少种姿态。

自由度（DoF）。一个刚体在三维空间里的位置和朝向需要6个数（x、y、z三个平移加三个旋转），所以机械臂至少要6个关节才能让手爪到达任意位置和朝向。很多机械臂做成7个关节，多出的1个叫冗余自由度，同一个手爪位姿可以对应无穷多种手臂姿态，便于绕开障碍——人的手臂（肩3、肘1、腕3）也是7个。夹爪通常再加1个开合自由度；灵巧手有十几到二十多个；人形机器人全身一般有二三十个甚至更多。自由度越多越灵活，策略要输出的动作维度也越高。

正运动学（FK）：已知各关节角度，求手爪的位置和朝向。它是确定的，按连杆长度把旋转逐个复合即可。

逆运动学（IK）：已知想要的手爪位姿，反求关节角度。它可能无解（够不着）、有多解（肘朝上或朝下），通常用数值迭代求解。策略若输出末端位移，就要靠IK换算成关节指令。两者之间的局部线性关系是雅可比矩阵ẋ = J(q) · q̇（见雅可比矩阵与海森矩阵），J接近奇异时，手爪某些方向几乎动不了。

本体感知（proprioception）。机器人通过关节编码器测角度、通过电流或力矩传感器估计受力，就像人闭着眼也知道自己手臂的位置。这些读数维度不高却非常可靠，是策略观测的重要组成部分，见状态、观测与动作。

它出现在哪里：Stanford Arm是早期能用计算机解运动学的电动机械臂；ALOHA与ACT的两条6自由度手臂加两个夹爪构成14维动作；人形机器人如低价人形机器人Unitree G1的全身控制要协调几十个自由度，见HOVER全身控制器；不同机器人自由度不同，是跨本体训练（Open X-Embodiment、HPT异构预训练）的主要难点。

例子

平面两连杆机械臂，两节长度都是1米。关节角θ₁ = 30°、θ₂ = 45°（第二节相对第一节）。正运动学：

x = cos θ₁ + cos(θ₁+θ₂) = 0.866 + 0.259 = 1.125 y = sin θ₁ + sin(θ₁+θ₂) = 0.500 + 0.966 = 1.466

逆运动学：要让手爪到达(1, 1)，可以解出θ₁ = 0°、θ₂ = 90°（第一节水平、第二节竖直向上）；另一组解θ₁ = 90°、θ₂ = −90°同样到达这个点，这就是“肘上/肘下”的多解。

容易误解的地方

  • 动作空间选关节角还是末端位姿，没有统一答案：关节空间不需要IK但不同机器人之间难以通用，末端空间更直观但会遇到IK失败和奇异点。
  • “6自由度”有时指机械臂关节数，有时指物体位姿的6个参数，需要看上下文。
  • 运动学只管几何，不管力；要考虑质量、惯性和力矩，需要动力学模型。
