合成机器人数据

Synthetic Robot Data Generation

也叫：Synthetic Data　合成数据　数据增广　Data Augmentation　神经轨迹　Neural Trajectories　生成式数据　仿真数据生成　自动数据生成

在交互版中打开（看它长在树上的哪里）

少量人工示范“复制放大”成大量训练数据：在仿真里自动改写示范，或用视频世界模型生成新的机器人视频。

人工示范采不起量，于是有两类放大办法。一类在仿真里做：MimicGen数据扩增把少量人类示范按物体位置分段、变换并重组，自动生成成千上万条新示范；DexMimicGen扩展到双手灵巧操作；RoboCasa提供大规模家庭场景。另一类用生成模型做：Cosmos-Transfer1把仿真画面转成逼真视频，DreamGen / GR00T Dreams用视频世界模型生成“神经轨迹”再用逆动力学或潜动作补标签，GR00T N1把这些合成数据纳入预训练。

争论在于合成数据的“真实度”上限：仿真的接触物理和视频模型的物理错误会不会被策略学进去，以及合成数据和真实数据的最佳配比。
