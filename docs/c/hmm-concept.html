隐马尔可夫模型

Hidden Markov Model

也叫：HMM　隐马尔科夫模型　隐马模型　前向后向算法　forward-backward　Viterbi解码

在交互版中打开（看它长在树上的哪里）

背后有一条看不见的马尔可夫链，每个隐藏状态按一定概率“发射”出一个可观察的符号。从观察序列反推隐藏状态，是语音识别和词性标注三十年的主力方法。

先要会：马尔可夫性与马尔可夫链 条件概率与贝叶斯公式 动态规划

语音识别里，我们听到的是一帧帧声学特征，真正想知道的是背后的音素序列；词性标注里，看到的是词，想知道的是每个词的词性。共同点是：真正关心的状态看不见，只能通过它产生的观察间接推断，而状态本身随时间按某种规律变化。隐马尔可夫模型（HMM）正是为这种结构设计的。

模型。隐藏状态序列z_1, …, z_T是一条马尔可夫性与马尔可夫链，每一步的观察x_t只依赖当时的状态z_t。模型由三组参数决定：初始分布P(z_1)、转移概率P(z_t | z_{t−1})、发射概率P(x_t | z_t)。整条序列的联合概率是

P(x, z) = P(z_1) Π_t P(z_t | z_{t−1}) Π_t P(x_t | z_t)

三个经典问题，都用动态规划高效解决：

  • 评估：观察序列的总概率P(x)是多少？要对所有隐藏路径求和，前向算法逐步累积，代价O(T·K²)（K是状态数），而不是Kᵀ。
  • 解码：最可能的隐藏路径是哪条？Viterbi算法把求和换成取最大。
  • 学习：只有观察序列时如何估计参数？Baum–Welch算法，它是EM算法的特例。

它出现在哪里。HMM统计语音识别把HMM用于统计语音识别，Rabiner的HMM教程让它成为语音领域的标准教材；HMM词性标注用HMM做词性标注；Viterbi算法和Baum-Welch算法分别提供了解码和训练算法。后来深度网络声学模型用神经网络替换了发射概率部分，再后来端到端模型（如CTC）逐渐取代了整个HMM框架，见音素、声学模型与语言模型的分工。

例子

隐藏状态是天气（雨/晴），观察是同事是否带伞。初始各0.5；天气保持不变的概率0.7；下雨时带伞概率0.9，晴天时0.2。第1天看到带伞：P(雨) = 0.5×0.9 / (0.5×0.9 + 0.5×0.2) = 0.45/0.55 ≈ 0.818。第2天又带伞，前向算法给出：α(雨) = (0.45×0.7 + 0.1×0.3)×0.9 = 0.3105，α(晴) = (0.45×0.3 + 0.1×0.7)×0.2 = 0.041，所以P(第2天雨 | 两天都带伞) = 0.3105/0.3515 ≈ 0.883。Viterbi找到的最可能路径是“雨、雨”，联合概率0.5×0.9×0.7×0.9 ≈ 0.284。

容易误解的地方

  • HMM假设观察之间在给定状态时相互独立，而且状态只依赖前一个状态，这两个假设都很强，限制了它利用长距离上下文的能力。
  • “隐”指状态不可观察，不是指模型参数未知。
