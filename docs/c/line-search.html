线搜索与共轭梯度

Line Search and Conjugate Gradient

也叫：线搜索　line search　回溯线搜索　backtracking line search　Armijo条件　Armijo condition　Wolfe条件　Wolfe conditions　步长选择　step size　共轭梯度　共轭梯度法　conjugate gradient　CG　最速下降　steepest descent

在交互版中打开（看它长在树上的哪里）

确定了下降方向之后，沿这个方向试几个步长、挑一个让函数值充分下降的，而不是用固定学习率。共轭梯度法则让每一步的方向彼此“不打架”。

先要会：梯度下降 雅可比矩阵与海森矩阵

优化的每一步其实要回答两个问题：往哪走（方向），走多远（步长）。梯度下降用固定的学习率与学习率调度回答第二个问题；在确定性的、函数值可以准确算出的问题上，有更聪明的做法。

线搜索。给定当前点x和下降方向d（例如负梯度，或牛顿法与拟牛顿法给出的方向），问题变成一维的：找步长α使f(x + αd)尽量小。精确求最小值太贵，实际用回溯线搜索：从α = 1开始，如果函数值下降得不够多，就把α乘以一个系数（如0.5）再试，直到满足Armijo条件：

f(x + αd) ≤ f(x) + c·α·∇f(x)ᵀd（c常取1e−4）

意思是实际下降量至少达到线性预测下降量的一小部分。再加上一个关于斜率的条件就是Wolfe条件，L-BFGS通常要求满足它，以保证曲率近似是正定的。

共轭梯度法（conjugate gradient, CG）。最速下降在狭长山谷里会走“之”字形：这一步刚消掉一个方向的误差，下一步又把它弄回来。CG让每个新方向与之前所有方向关于海森矩阵A“共轭”：d_iᵀ A d_j = 0。对n维的二次函数½xᵀAx − bᵀx（等价于解方程Ax = b），它最多n步就精确到达最优，而且每步只需要一次矩阵与向量的乘法，不需要存储或分解A。所以大规模稀疏方程组的标准解法就是CG。

在AI里出现在哪里。Hessian-free优化优化用CG近似求解牛顿方程，只需要“海森乘向量”，可以用自动微分高效算出；TRPO用CG计算自然梯度方向，再用回溯线搜索保证KL约束被满足、目标真的改善了。随机小批量训练里梯度有噪声，函数值也有噪声，线搜索的判断会不可靠，所以深度网络训练几乎都用学习率调度代替线搜索。

例子

f(x) = x²，x = 3，d = −f'(3) = −6。回溯线搜索（c = 0.5，每次α减半）：

  • α = 1：x + αd = −3，f = 9，要求f ≤ 9 + 0.5×1×(−36) = −9，不满足。
  • α = 0.5：x = 0，f = 0，要求f ≤ 9 − 9 = 0，满足，接受。一步就到最优点。

CG：对2维二次函数，无论条件数多大，两步之内精确收敛；最速下降在条件数为100时需要上百步。

容易误解的地方

  • 线搜索每次尝试都要额外计算一次函数值；在每次前向都很贵的大模型上，这个代价很高。
  • 共轭梯度“n步收敛”只在精确算术和二次函数下成立，浮点误差和非二次函数会破坏共轭性，实际中需要周期性重启。
