拼写纠错与噪声信道

Spelling Correction and the Noisy Channel

也叫：spelling correction　拼写纠错　拼写检查　spell checking　spell check　错别字纠正　中文纠错　文本纠错　语法纠错　grammatical error correction　GEC　噪声信道纠错　noisy channel spelling　非词错误　真词错误　real-word error

发现并改正文本里的拼写错误。经典做法是噪声信道模型：在与错词编辑距离很近的候选中，挑“本身常见”且“容易被打成这个错词”的那个；现在多用神经网络直接改写。

先要会：编辑距离 条件概率与贝叶斯公式 语言模型

搜索框里输入“acress”，用户想要的是actress、across还是acres？输入法里打出“在坐的各位”，应该是“在座”。拼写纠错要完成两件事：发现哪里错了，以及改成什么。

两类错误。

  • 非词错误：写出的字符串根本不是词，如“acress”。查词典就能发现。
  • 真词错误：写出的是另一个合法的词，如“there”写成“their”、“在座”写成“在坐”。词典查不出来，必须看上下文。中文输入法造成的错误大多是这一类（同音字、近形字）。

噪声信道模型。这是噪声信道与词对齐里同一套思路的最早应用之一：假设用户心里想的是正确的词w，经过一个“有噪声的信道”（手滑、记错）变成了我们看到的x。纠错就是反推最可能的w：

ŵ = argmax_w P(w | x) = argmax_w P(x | w) · P(w)

（由条件概率与贝叶斯公式，分母P(x)与w无关可以省去。）

  • P(w)：语言模型，这个词（在上下文里）本身有多常见（见语言模型、n-gram与平滑）。
  • P(x | w)：错误模型，把w打成x的概率。可以从大量“错词—正词”对里统计每种编辑操作的频率，例如“把e打成a”的替换有多常见。

候选词通常只取与x的编辑距离为1或2的词，因为绝大多数拼写错误只差一两个字符。

神经方法。今天的拼写和语法纠错多写成序列到序列的改写任务（见编码器-解码器），输入有错的句子、输出改正后的句子，训练数据常通过人工给正确文本加噪声来大量合成。大语言模型也能直接做纠错，但容易“过度纠正”，把不该改的地方也改写了。

在文本规范化与分句、搜索查询改写（见查询改写与扩展）和语音识别后处理中，拼写纠错都是常见环节。

例子

Jurafsky与Martin教材中的例子：错词“acress”的部分候选（都与它的编辑距离为1）：

  • actress（漏打t）
  • across（e替换o）
  • acres（多打一个s）

只看语言模型P(w)，across最常见；只看错误模型P(x | w)，各有高低。两者相乘后，在没有上下文时across和actress得分接近。加入上下文“versatile ___ whose”后，二元语法模型强烈偏好actress。

中文例子：“在坐的各位”，“坐”和“座”同音，词典都能查到，靠语言模型发现“在座的各位”远比“在坐的各位”常见，才能改正。

容易误解的地方

  • 专有名词、新词、代码和网络用语容易被误改，纠错系统要能保留词典外但合理的写法。
  • 错误模型依赖输入方式：键盘打字、手写识别、拼音输入法和语音识别产生的错误分布完全不同。
