标签噪声与带噪学习

Label Noise and Learning with Noisy Labels

也叫：标签噪声　噪声标签　label noise　noisy labels　learning with noisy labels　带噪学习　错误标注　标注错误　label errors　mislabeled data　对称噪声　symmetric noise　非对称噪声　asymmetric noise　数据清洗　data cleaning　稳健损失　robust loss　标注质量　annotation quality

训练或测试数据里有一部分标签是错的：标注员看走眼、众包质量参差、网页自动抓取的标签不可靠。大模型能把错标签也背下来，所以需要稳健的损失、样本筛选和数据清洗。

先要会：监督学习 泛化与过拟合

现实数据集的标签从来不完美。即使是经过仔细整理的基准，测试集标注错误也估计其测试集中普遍存在百分之几的错误标注；用网页文本、搜索结果或启发式规则自动生成的标签，错误率可能高得多。

为什么是问题。重新思考泛化发现，深度网络有足够的容量把完全随机的标签也拟合到训练误差为0（见模型容量与欠拟合）。所以在有噪声的数据上训练足够久，模型最终会记住错误的标签，在测试集上表现下降。好在网络通常先学干净的规律、后记噪声：训练前期验证集表现上升，后期才因为记住噪声而下降，这让早停成为最简单的对策之一。

噪声的类型。

  • 对称噪声：错误标签在其他类别里均匀分布。
  • 非对称（类相关）噪声：错误集中在相似的类之间，如“狼”被标成“哈士奇”，更常见也更难处理。
  • 测试集里的噪声：不仅影响训练，还会让评测结论失真，模型排名可能因此改变（见基准、排行榜与SOTA）。

常见对策。

  • 稳健的损失：交叉熵对“非常自信地判错”的样本惩罚极重，噪声样本会主导梯度；改用对离群点更宽容的损失（如MAE风格的损失、截断交叉熵），或用标签平滑减少过度自信。
  • 样本筛选：利用“噪声样本损失大”的现象，只用损失较小的样本训练；协同训练两个网络、互相为对方挑选干净样本。
  • 估计噪声并修正：置信学习与cleanlab估计每对类别之间的混淆比例，找出最可能标错的样本并移除或改正。
  • 重新标注与多人标注：对模型和标注冲突的样本请人复核；多人标注取多数票，并用标注一致性与Cohens kappa衡量标注本身的可靠性。这是以数据为中心的AI强调的思路。
  • 半监督与自训练：把可疑样本当作未标注数据，用模型的伪标签代替，见半监督学习与伪标签和Noisy Student自训练。

在大模型里。RLHF的偏好数据中，不同标注员对同一对回答的判断常有分歧，这本质上也是标签噪声；奖励模型会把噪声一并学进去（见人类反馈强化学习）。

例子

一个10类数据集有20%的对称噪声：每个样本有20%的概率被随机改成另外9类之一。训练早期验证准确率升到85%，之后训练准确率继续涨到接近100%（错标签也被背下来），验证准确率却回落到75%左右。早停在第一个峰值附近能保留大部分性能。（数字为示意）

容易误解的地方

  • 损失大的样本不一定是标错的，也可能是罕见但正确的困难样本；一味删掉它们会让模型在长尾上更差。
  • 用一个模型清洗数据后再用同类模型评测，可能只是在强化这个模型自己的偏见。
