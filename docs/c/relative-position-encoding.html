绝对位置编码与相对位置编码

Absolute and Relative Position Encodings

也叫：relative position encoding　相对位置编码　relative positional encoding　absolute position encoding　绝对位置编码　absolute positional embedding　sinusoidal positional encoding　正弦位置编码　sinusoidal　learned positional embedding　可学习位置编码　T5 relative bias　T5相对位置偏置　位置偏置　length extrapolation　长度外推

位置编码的两大类：绝对位置编码告诉模型“这是第几个token”（正弦编码、可学习位置向量）；相对位置编码让注意力只依赖两个token之间的距离（T5偏置、ALiBi、RoPE）。后者更利于处理比训练时更长的序列。

先要会：位置编码 自注意力与多头注意力

注意力本身不区分顺序（见位置编码），必须另外注入位置信息。怎么注入，有两种基本思路。

绝对位置编码。给每个位置p一个向量，加到该位置的词嵌入上（见词嵌入层）。

  • 正弦编码：Transformer原文用不同频率的正弦和余弦函数生成位置向量，PE(p, 2i) = sin(p / 10000^(2i/d))，PE(p, 2i+1) = cos(p / 10000^(2i/d))，不需要学习。
  • 可学习位置向量：BERT和GPT-2为每个位置（如0到511或0到1023）学一个向量。超过训练的最大长度就没有对应的向量，模型无法处理更长的输入。

问题在于：语言里重要的往往是“两个词相隔多远”，而不是“这个词在第几位”。“猫追老鼠”这句话出现在文章第10个词还是第1000个词，意思不变。

相对位置编码。让注意力分数直接依赖相对距离i − j。

  • Shaw等人（相对位置表示，2018）：为每个截断范围内的相对距离学一个向量，加到注意力计算的键（和值）上。
  • T5偏置：T5给每个相对距离（按对数分桶）学一个标量，直接加到注意力分数上，各层共享。
  • ALiBi：ALiBi线性偏置位置不学参数，给分数加一个与距离成正比的负偏置−m·(i − j)，每个头用不同的斜率m，距离越远惩罚越大。
  • RoPE：旋转位置编码RoPE把Q和K按位置旋转一个角度，使q_i · k_j只依赖i − j。形式上作用在每个位置上（像绝对编码），效果上却是相对编码，这是它的巧妙之处。今天的大多数开源大模型都用RoPE。
  • DeBERTa的解耦注意力（DeBERTa解耦注意力）分别计算内容-内容、内容-位置、位置-内容三项。

为什么相对编码更受欢迎。它天然具有平移不变性，对“同样的局部模式出现在不同位置”泛化更好，也为长度外推（处理比训练更长的序列）打下基础：ALiBi在比训练更长的输入上退化较慢；RoPE再配合位置插值、YaRN等方法（见位置编码外推与上下文扩展）可以把上下文扩展很多倍。还有研究发现，仅解码器模型完全不加位置编码（无位置编码NoPE）也能靠因果掩码隐式地学到位置信息。

例子

句子“猫 追 老鼠”中，“追”在位置1，“老鼠”在位置2。

  • 绝对编码：“追”的输入 = 嵌入(追) + PE(1)，“老鼠”的输入 = 嵌入(老鼠) + PE(2)。如果这句话出现在位置100到102，输入就变成加PE(101)和PE(102)，模型需要自己学会这两种情况本质一样。
  • ALiBi（斜率m = 0.5）：“老鼠”看“追”时分数加−0.5×1 = −0.5，看“猫”时加−1.0。不管这句话出现在哪里，偏置都相同。
  • RoPE：位置1和位置2的旋转角度之差，与位置101和位置102的角度之差相同，所以点积只取决于相距1个位置。

容易误解的地方

  • “相对位置编码”是一大类方法的统称，各方法的长度外推能力差别很大，不能一概而论。
  • 外推到训练长度以外时，即使位置编码本身支持，模型也可能因为没见过那么长的上下文而表现下降，通常仍需在长文本上做少量继续训练。
