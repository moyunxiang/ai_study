低资源与无监督翻译

Low-Resource and Unsupervised Machine Translation

也叫：低资源翻译　Low-resource MT　无监督机器翻译　UNMT　零样本翻译　Zero-shot Translation　多语言翻译　Multilingual NMT　单语数据翻译　小语种翻译

在交互版中打开（看它长在树上的哪里）

多数语言对几乎没有平行语料，怎样借助单语数据、多语共享和回译把它们也翻好。

神经翻译需要大量互译句对，而世界上大部分语言对只有很少平行数据。几条主要思路：回译用反向模型把目标语单语文本译回源语，造出伪平行语料；多语言NMT与零样本翻译让一个模型同时学多种语言，只在输入加目标语言标记，就能在没训练过的语对之间零样本翻译；无平行语料的词翻译MUSE不用平行语料就对齐两种语言的词向量空间，无监督神经机器翻译在此基础上只靠单语语料训练翻译模型。

M2M-100非英语中心翻译和NLLB两百种语言翻译把多语言路线推到100到200种语言，并不再以英语为中转中心。大模型时代，混元翻译Hunyuan-MT专门处理普通话与少数民族语言、方言之间的翻译。难点仍是低资源语言缺少可靠的评测数据，自动指标的结论很难验证。
