主动学习

Active Learning

也叫：主动学习　active learning　不确定性采样　uncertainty sampling　查询策略　query strategy　委员会查询　query by committee　QBC　BALD　池式主动学习　pool-based active learning　标注预算　labeling budget　核心集　core-set　coreset　人在回路　human-in-the-loop

标注很贵时，让模型自己挑“最值得标”的样本交给人标注，而不是随机抽。常见标准是挑模型最不确定的、委员会分歧最大的、或最能代表整体分布的样本。

先要会：监督学习 信息量与熵

医学影像要请医生标注，法律文书要请律师标注，专家时间按小时计费。未标注的数据往往取之不尽，标注预算却有限。随机抽样标注时，很多样本模型其实已经会了，标了也没什么用。主动学习让模型参与决定标哪些。

基本循环（池式主动学习）。

1. 用少量已标注数据训练初始模型； 2. 用模型给大量未标注样本打分，按某个查询策略选出一批最有价值的； 3. 交给人标注，加入训练集，重新训练； 4. 重复，直到预算用完或性能达标。

常见查询策略。

  • 不确定性采样：挑模型最拿不准的样本，例如最大概率最低的、前两名概率最接近的（间隔采样）、或预测分布熵最大的（见信息量与熵）。
  • 委员会查询：训练几个不同的模型，挑它们意见最不一致的样本。
  • 期望信息增益：挑标注后能让模型参数的不确定性降得最多的样本，即与参数的互信息最大（见联合熵、条件熵与信息增益）。深度学习中的BALD用MC Dropout不确定性近似这个量，只挑“模型本身不确定”而非“数据本身有噪声”的样本（见不确定性估计）。
  • 多样性与代表性：只看不确定性容易挑出一堆彼此相似的样本，或者挑到离群点；核心集等方法选出能覆盖整个数据分布的一组样本，实践中常与不确定性结合。

和相关方法的关系。半监督学习与伪标签利用未标注数据本身（伪标签、一致性正则），主动学习决定哪些数据值得人工标注，两者经常一起使用。在大模型时代，类似的思想出现在偏好数据收集中：挑选模型最难判断的回答对去请人标注，或者在竞技场式评测中优先采样排名最不确定的模型对，以更少的投票得到更准的排名（见Elo评分与两两比较）。

为什么在深度学习里效果打折。深度网络在数据少时不确定性估计不准；每轮都要重新训练，代价高；按批次选样本时同一批内容易冗余。很多研究发现，在强预训练模型上，精心设计的主动学习相对随机采样的优势会缩小。

例子

三分类模型对两个未标注样本的预测：A为(0.34, 0.33, 0.33)，B为(0.90, 0.05, 0.05)。A的熵约1.10奈特（接近最大值ln 3 ≈ 1.10），B约0.39奈特。不确定性采样会先把A交给人标注；B模型已经很有把握，标了收获不大。

容易误解的地方

  • 主动学习挑出的训练集分布与真实分布不同（偏向难样本），用它来估计测试性能会有偏差，评测仍要用随机抽取的测试集。
  • 用一个模型挑出的数据，换另一个模型来训练时，效果可能不如随机采样。
