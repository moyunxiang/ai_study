编辑距离

Edit Distance

也叫：edit distance　编辑距离　Levenshtein distance　Levenshtein距离　莱文斯坦距离　最小编辑距离　minimum edit distance　Damerau-Levenshtein　字符串相似度　string similarity　字符串对齐　string alignment　CER　字错误率

在交互版中打开（看它长在树上的哪里）

把一个字符串变成另一个字符串最少需要多少次插入、删除和替换操作。最常用的是Levenshtein距离，用动态规划计算，是拼写纠错、语音识别词错误率和字符串相似度的基础。

先要会：动态规划

“intention”和“execution”有多像？“北京大学”和“北大”呢？很多任务需要一个衡量两个字符串差异的数字：拼写纠错要找和错词最接近的正确词，语音识别要比较识别结果和标准文本差了多少，数据去重要发现几乎一样的两句话。编辑距离是最直接的定义。

定义。允许三种操作，每种代价为1：插入一个字符、删除一个字符、把一个字符替换成另一个。从字符串s变成t所需的最少操作数，就是Levenshtein距离。（有的定义把替换代价记为2，相当于一次删除加一次插入。）

动态规划。设D[i][j]为s的前i个字符变成t的前j个字符的最小代价（见动态规划）：

D[i][0] = i，D[0][j] = j

D[i][j] = min(D[i−1][j] + 1（删除）, D[i][j−1] + 1（插入）, D[i−1][j−1] + (s_i ≠ t_j ? 1 : 0)（替换或相同）)

填满整张(m+1)×(n+1)的表，右下角就是答案，复杂度O(mn)。沿着表格回溯，还能得到具体的对齐：哪些字符对应、哪些被删除或插入。

变体。Damerau-Levenshtein距离把“交换相邻两字符”也算一次操作，更符合打字错误；也可以给不同操作、不同字符对设不同代价，例如键盘上相邻的字母替换代价更低。

在哪里出现。

  • 词错误率：按词而不是按字符计算编辑距离，再除以参考文本的词数，就是语音识别的标准指标（见词错误率）；中文常按字计算，叫字错误率CER。
  • 拼写纠错：在编辑距离为1或2的候选词中，结合语言模型挑最可能的那个（见拼写纠错与噪声信道）。
  • 生成模型：Levenshtein Transformer把生成看作对序列反复做插入和删除操作。
  • 评测：翻译评测里的TER（翻译编辑率）、OCR和代码补全的字符级相似度，也基于编辑距离。
  • 生物信息学中比对DNA和蛋白质序列，用的是同一套动态规划思想（带打分矩阵的序列比对）。

例子

“kitten”变成“sitting”：

1. kitten → sitten（k替换为s） 2. sitten → sittin（e替换为i） 3. sittin → sitting（末尾插入g）

共3步，Levenshtein距离为3。

词错误率：参考“我 想 去 北京”（4个词），识别结果“我 去 北京 了”。需要删除“想”、插入“了”，编辑距离2，WER = 2/4 = 50%。

容易误解的地方

  • 编辑距离只看字面，不懂语义：“好”和“坏”距离是1，“汽车”和“轿车”距离也是1。
  • 长字符串两两计算O(mn)很慢，大规模去重通常改用MinHash等近似方法（见预训练语料的清洗、过滤与去重）。
