监督学习

Supervised Learning

也叫：有监督学习　监督式学习　标注数据　labeled data　有标签学习

在交互版中打开（看它长在树上的哪里）

给模型大量“输入—正确答案”的成对样本，让它学会一个从输入映射到答案的函数，并能用到没见过的新输入上。

先要会：损失函数 随机变量与概率分布

传统编程是人写规则：要识别垃圾邮件，就手写“包含‘中奖’且有链接则判为垃圾”。规则一多就难以维护，而且很多任务（认出照片里的猫）根本写不出规则。监督学习换了一种方式：不写规则，而是收集许多例子，每个例子都带着人给的正确答案（标签），让算法自己从例子里找出规律。

形式上，训练数据是N个样本对{(x_1, y_1), …, (x_N, y_N)}，目标是找一个函数f_θ，使f_θ(x) ≈ y。具体做法是定义损失函数衡量预测与标签的差距，再用梯度下降等方法调整参数θ。按标签的类型分两类：

  • 回归：y是连续数值，如房价、温度，最简单的模型是线性回归。
  • 分类：y是有限个类别之一，如“猫/狗/鸟”，最简单的模型是逻辑回归。

真正的目标不是在训练数据上答对——那可以靠死记——而是在没见过的新数据上答对，这叫泛化与过拟合。所以评估时必须使用训练时没用过的数据，见训练集、验证集与测试集。

它出现在哪里：深度学习的第一波成功几乎都是监督学习：感知机是最早的可学习分类器；MNIST（6万张带标签的手写数字）和ImageNet（超过100万张人工标注的图片、1000个类别）提供了大规模标签；AlexNet在ImageNet上的监督训练开启了深度学习时代。它的瓶颈是标签昂贵，这推动了无监督学习与自监督学习的发展。

例子

MNIST手写数字：每个输入x是28×28 = 784个像素的灰度值，标签y是0到9中的一个数字。训练集有60000对这样的样本，测试集另有10000张。模型学完后，给它一张新的手写“7”，它输出10个类别的概率，其中“7”的概率最高就算答对。

容易误解的地方

  • 模型学到的是数据里的统计相关性，不一定是人以为的那个规律。例如训练集里的牛总在草地上，模型可能学会“绿色背景 = 牛”。
  • 标签本身也会有错，常用测试集中都发现过一定比例的标注错误。
