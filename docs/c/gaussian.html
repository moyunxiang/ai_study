高斯分布

Gaussian Distribution

也叫：正态分布　normal distribution　高斯噪声　钟形曲线　bell curve　多元高斯

在交互版中打开（看它长在树上的哪里）

高斯分布（正态分布）是钟形的连续分布，由均值和方差两个参数完全决定。它是噪声、初始化和生成模型中最常用的分布。

先要会：随机变量与概率分布 期望与方差

测量误差、人的身高、大量独立小因素的累加，往往都呈现中间高、两边低的钟形。这不是巧合：中心极限定理说，许多独立随机量之和近似服从高斯分布。再加上它数学性质极好，高斯分布成了AI里描述“随机噪声”和“不确定性”的默认选择。

一维定义。均值μ、方差σ²的高斯分布记作N(μ, σ²)，密度为

p(x) = 1/(σ√(2π)) · exp(−(x − μ)² / (2σ²))

约68%的概率落在μ ± σ内，约95%落在μ ± 2σ内，约99.7%落在μ ± 3σ内。μ = 0、σ = 1的叫标准正态分布。

多维高斯。N(μ, Σ)，μ是均值向量，Σ是协方差矩阵，描述各维度之间的相关性。Σ是对角阵时各维度独立。

好用的性质。

  • 线性变换后仍是高斯：若ε ~ N(0, 1)，则μ + σε ~ N(μ, σ²)。这让我们能用标准噪声加平移缩放来采样，这就是重参数化技巧。
  • 独立高斯之和仍是高斯，方差相加。
  • 对数密度是二次函数，所以假设误差服从高斯时，最大似然就等价于最小二乘，见最大似然估计。

它出现在哪里。GMM-UBM说话人确认用多个高斯的混合建模说话人的声学特征，见隐变量模型；高斯过程回归把函数本身看成高斯分布；He初始化与PReLU从高斯分布中抽取初始权重；变分自编码器VAE把隐变量的先验设为标准正态；DDPM的前向过程不断向图片加高斯噪声，最终变成纯高斯噪声，见扩散：前向加噪与反向去噪。

例子

标准正态在x = 0处的密度是1/√(2π) ≈ 0.399。若σ = 0.1，峰值密度约3.99，大于1，这说明密度不是概率。身高若服从N(170, 10²)（单位cm），则约68%的人在160到180之间。扩散模型的一步加噪：x_t = √(ᾱ)·x_0 + √(1−ᾱ)·ε，取ᾱ = 0.25、像素值x_0 = 0.8、噪声ε = 1.0，得到x_t = 0.5×0.8 + 0.866×1.0 ≈ 1.266。

容易误解的地方

  • 高斯分布的尾部衰减极快，超过5σ的事件几乎不会发生；如果真实数据有重尾（如金融收益、某些激活值的离群点），用高斯建模会严重低估极端情况。
  • 多维高斯的“绝大多数概率质量”并不在均值附近，而是集中在离均值约√d·σ的一层薄壳上，这是高维的反直觉之处。
