原生3D生成

Native 3D Generation

也叫：原生3D扩散　Native 3D Diffusion　3D潜扩散　3D Latent Diffusion　3D DiT　结构化3D潜变量　Structured 3D Latents　3D VAE　Shape Diffusion　3D资产生成　3D Asset Generation　PBR材质生成　网格生成　Mesh Generation

在交互版中打开（看它长在树上的哪里）

仿照潜扩散做法，直接在3D数据上训练VAE把形状压成潜变量，再在潜空间里扩散生成三维资产。

随着Objaverse等大规模3D数据集出现，研究者开始直接在3D表示上训练生成模型，而不是借2D先验。早期Point-E生成点云，质量有限。CLAY原生3D扩散用神经场表示几何，在潜空间里训练15亿参数的纯Transformer扩散模型，直接生成带PBR材质的资产，标志着“3D版潜扩散”成型。TRELLIS结构化3D潜变量提出结构化3D潜变量：先生成稀疏体素结构，再生成每个体素上的局部特征，可解码为高斯、辐射场或网格。Hunyuan3D 2.0把形状生成与纹理生成拆成两个大模型并开源，成为常用基线。TRELLIS.2原生3D潜变量再推进一步，用能表示任意拓扑和PBR材质的O-Voxel与16倍压缩的VAE，生成1536³分辨率资产。

这一路线的共同配方是三维表示：体素、点云、网格、隐式场上的VAE加流匹配Transformer。仍待解决：3D数据总量依旧有限、版权复杂；生成的是整块网格，部件拆分、可动结构和可直接用于生产的拓扑仍需人工。
