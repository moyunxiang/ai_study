零样本单目深度

Zero-shot Monocular Depth Estimation

也叫：单目深度基础模型　depth foundation model　相对深度　relative depth　度量深度　metric depth　仿射不变深度　affine-invariant depth　单目几何　Depth Anything系列　DA2　DA3　视频深度　MDE　深度估计大模型

在交互版中打开（看它长在树上的哪里）

训练一个能对任意没见过的照片估计深度的通用模型，不需要针对某个数据集或某台相机重新训练。

早期单目深度（单图深度预测、自监督单目深度）只在单一数据集（如KITTI室外驾驶）上训练，换个场景就失效。MiDaS混合数据集深度的关键一步是用尺度和平移不变的损失混合多个标注方式不同的数据集训练，得到可跨场景的相对深度；DPT稠密预测ViT把骨干换成ViT。

之后有两条路线：判别式路线靠更大的数据和骨干，如Depth Anything用大规模无标签图像自训练、Depth Anything V2改用合成数据精标；生成式路线借扩散模型先验，如Marigold扩散深度。再往后，目标从相对深度扩展到度量深度与完整几何：Depth Pro度量深度输出绝对尺度和焦距，MoGe单目几何直接预测点图，视频深度VDA解决视频闪烁，Depth Anything 3把单目与多视图几何统一。

争论点：度量尺度本质上从单张图难以确定，模型的“米数”在陌生相机上可靠性存疑；评测基准也相对陈旧。
