预填充-解码分离

Prefill-Decode Disaggregation

也叫：PD分离　PD disaggregation　P/D分离　分离式推理　disaggregated serving　disaggregated inference　预填充与解码分离　prefill decode　Splitwise　xPyD

在交互版中打开（看它长在树上的哪里）

把读提示词的预填充和逐词生成的解码放到不同GPU上：前者吃算力、后者吃带宽，混在一起会互相拖慢。

大模型推理分两个阶段：预填充一次性处理整段提示词，是计算密集的；解码每步只生成一个词，却要读全部权重和KV缓存，是带宽密集的。放在同一批里，长提示的预填充会卡住其他请求的解码，首词延迟和逐词延迟难以同时保证。

分块预填充Sarathi的办法是把预填充切块，与解码混排；预填充-解码分离部署则主张彻底分开，让两类GPU各自按自己的瓶颈配置并行度，预填充完把KV缓存传给解码机。Mooncake以KV缓存为中心在Kimi的线上服务中围绕KV缓存搭建了分离式架构；NVIDIA Dynamo、LMCache KV缓存层等开源组件提供跨机KV传输和调度。

到2025年，大规模部署普遍采用PD分离，讨论转向KV传输带宽、两类机器的配比，以及与专家并行如何组合。
