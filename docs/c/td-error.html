时序差分与自举

Temporal Difference and Bootstrapping

也叫：bootstrapping　自举　TD目标　TD target　TD(0)　时序差分误差　TD　TD误差　TD learning　TD(λ)

在交互版中打开（看它长在树上的哪里）

不等一局结束，用“这一步的奖励+对下一状态的价值估计”当作目标来更新当前状态的价值估计。两者之差叫TD误差，用估计更新估计叫自举。

先要会：Bellman方程 奖励、回报与折扣 蒙特卡洛采样

要估计价值V(s)，最朴素的办法是蒙特卡洛采样：从s出发玩到结束，记下实际回报G，把V(s)往G拉。问题是要等整局结束才能更新，而且一局里的随机性全叠在G上，方差很大；对于没有终点的任务更是无从下手。

时序差分（Temporal Difference）的想法是：走一步就更新。根据Bellman方程，V(s)应该等于r + γ·V(s')的期望。于是拿刚观察到的一次转移(s, r, s')构造一个TD目标r + γ·V(s')，和当前估计比较：

δ = r + γ·V(s') − V(s)

V(s) ← V(s) + α·δ

δ就是TD误差：正数说明“结果比预想的好”，负数说明“比预想的差”。α是学习率。

自举（bootstrapping）。TD目标里用到了另一个估计V(s')，即“用自己的猜测去修正自己的猜测”。好处是方差小、能在线逐步学；代价是有偏：如果V(s')本身不准，误差会传播。蒙特卡洛与TD是两端，中间可以用n步回报或λ-回报折中，广义优势估计GAE就是这一思路在策略梯度里的应用。

它在哪里。时序差分学习（Sutton 1988）系统提出了这一方法，TD-Gammon用它训练神经网络下西洋双陆棋达到接近顶尖人类的水平。Q-learning把TD用于Q函数，目标是r + γ·max_{a'} Q(s', a')；DQN用神经网络做Q并加上目标网络来稳定自举。神经科学发现多巴胺神经元的放电很像TD误差，见多巴胺与TD误差。Actor-Critic与优势函数里的critic也是用TD误差训练的。

例子

当前估计V(s)=5，执行动作后得到奖励r=1，到达s'，V(s')=6，γ=0.9，学习率α=0.1。

TD目标1 + 0.9×6 = 6.4，TD误差δ = 6.4 − 5 = 1.4，更新后V(s) = 5 + 0.1×1.4 = 5.14。

对比蒙特卡洛：它要等到这一局结束，比如实际回报是8，才能把V(s)更新为5 + 0.1×(8 − 5) = 5.3。TD只看了一步就开始学，而它用到的6本身也是估计值。

容易误解的地方

  • TD误差不是神经网络训练里普通的“预测误差”：目标本身随参数在变，所以直接对目标求导是错的，实现时目标要停止梯度（或用单独的目标网络）。
  • 自举+函数近似+off-policy三者同时出现时可能发散，这被称为“致命三元组”，见致命三元组。
  • TD学习收敛到的是当前策略的价值，策略变了价值要重新估计。
