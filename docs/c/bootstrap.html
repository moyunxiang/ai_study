自助法（bootstrap）

Bootstrap Resampling

也叫：自助法　bootstrap　bootstrapping　自助采样　bootstrap resampling　重采样　有放回抽样　sampling with replacement　bootstrap置信区间　bootstrap confidence interval　百分位法　percentile bootstrap　配对bootstrap　paired bootstrap　袋外样本　out-of-bag　OOB

在交互版中打开（看它长在树上的哪里）

从已有样本中有放回地反复重抽同样大小的“新样本集”，在每个上面重算统计量，用这些结果的分布估计误差和置信区间。不需要推导公式，什么统计量都能用。

先要会：期望与方差 置信区间、标准误与误差棒

准确率的标准误有现成公式，可F1、BLEU、中位数、AUC、两个模型的Elo分差呢？这些统计量的分布很难推导。自助法（bootstrap）（Efron在1979年提出）的想法是：既然手上的样本是对总体最好的近似，就从它里面反复重抽，模拟“再做一次实验”。

做法。

1. 原始数据有n个样本，在其上算出统计量θ̂。 2. 从这n个样本中有放回地抽n个，得到一个bootstrap样本（有些原样本会出现多次，有些一次也不出现）。 3. 在这个样本上重新计算统计量θ̂*。 4. 重复B次（常取1000到10000次），得到θ̂*₁, …, θ̂*_B。

这B个值的标准差就是θ̂的标准误估计；取它们的第2.5和第97.5百分位数，就得到95%置信区间（百分位法，见置信区间、标准误与误差棒）。

为什么约有63%的样本被抽中。每个样本在一次抽取中没被选中的概率是1 − 1/n，n次都没被选中的概率(1 − 1/n)^n ≈ 1/e ≈ 0.368。所以每个bootstrap样本大约包含63.2%的不同原样本，没被抽中的约36.8%叫袋外样本。

它出现在哪里。

  • 评测：在测试集上对题目做bootstrap，给BLEU、F1等指标加置信区间；对两个模型的逐题结果成对重抽，估计分差的区间（配对bootstrap），见方差、种子与统计显著性。Chatbot Arena对投票记录做bootstrap，给每个模型的排名分数附上置信区间。
  • 集成学习：Bagging在多个bootstrap样本上分别训练模型再平均，降低方差；随机森林在此基础上再随机选特征，并用袋外样本免费估计泛化误差（见集成学习）。
  • 强化学习：Bootstrapped DQN让多个Q值头各自在不同的bootstrap数据上训练，用它们的分歧表示不确定性来引导探索。注意强化学习中“自举”（bootstrapping）的另一种含义是用自己的估计值来更新自己（见时序差分与自举），与这里是两回事。

例子

5道题的得分为(1, 0, 1, 1, 0)，准确率0.6。一次bootstrap可能抽到第(1, 1, 2, 4, 5)道，得分(1, 1, 0, 1, 0)，准确率0.6；另一次抽到(2, 3, 3, 5, 5)，准确率0.4。重复10000次后，准确率的标准差约0.22，与公式√(0.6 × 0.4 / 5) ≈ 0.22一致；只有5道题时，这个准确率几乎没有说服力。

容易误解的地方

  • 样本彼此相关时（同一篇文章的多道题、时间序列），要按组或按时间块重抽，否则区间会偏窄。
  • 样本量很小、或统计量依赖极端值（如最大值）时，bootstrap的结果不可靠。
