偏差-方差权衡

Bias–Variance Tradeoff

也叫：偏差方差分解　bias-variance decomposition　偏差与方差　欠拟合与过拟合　模型复杂度

在交互版中打开（看它长在树上的哪里）

把模型的预期误差拆成三部分：偏差（模型系统性地错多少）、方差（换一份训练数据结果会变多少）和不可消除的噪声。简单模型偏差大，复杂模型方差大。

先要会：期望与方差 泛化与过拟合

泛化与过拟合说过，模型太简单会欠拟合，太复杂会过拟合。偏差-方差分解把这个直觉写成了精确的公式。

设想一个思想实验：从同一个数据分布中反复抽取不同的训练集，每次都训练一个模型，然后都在同一个测试点x上预测。由于训练集不同，预测值f̂(x)本身是一个随机变量。对平方损失，期望误差可以分解为：

E[(y − f̂(x))²] = Bias² + Variance + σ²

  • 偏差Bias = E[f̂(x)] − f(x)：这些模型平均起来离真实值多远。用直线去拟合抛物线，无论数据多少都会系统性地偏，偏差大。
  • 方差Variance = E[(f̂(x) − E[f̂(x)])²]：换一份训练数据，预测会抖动多少。高次多项式对训练集中每个点都很敏感，方差大。
  • 噪声σ²：数据本身的随机性，任何模型都消除不掉。

（这里用到的期望和方差概念见期望与方差。）

权衡：增加模型复杂度通常降低偏差、提高方差。正则化与权重衰减主动引入一点偏差来换取更小的方差（岭回归与L2正则就是这样）；集成学习把多个模型平均起来，能降低方差而不增加偏差，随机森林是典型例子。

它出现在哪里：偏差-方差权衡（Geman等，1992）用这一分解分析神经网络，说明为什么需要先验约束。但现代超大网络出现了双下降：模型大到能完美拟合训练集之后，测试误差反而继续下降，单纯的“U形曲线”已不足以描述深度学习，这一分解本身仍然成立，但偏差和方差随模型规模的变化方式比经典图景复杂。

例子

测试点的真实值是10。从不同训练集训练出的模型：

  • 模型A三次的预测都是8：偏差 = −2，方差 = 0，均方误差 = 4。
  • 模型B三次的预测是6、10、14：平均正好是10，偏差 = 0；方差 = (16 + 0 + 16)/3 ≈ 10.7，均方误差 ≈ 10.7。

无偏的模型B反而误差更大。如果把B的三个版本平均起来（集成），预测就是10，误差为0——这就是集成降低方差的原理。

容易误解的地方

  • 这个干净的分解只对平方损失成立；对分类的0-1损失有多种不同的推广，没有统一形式。
  • 方差指的是“对训练集的敏感度”，不是预测结果数值的大小，也不是数据的方差。
