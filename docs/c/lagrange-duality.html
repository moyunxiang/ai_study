拉格朗日乘子、约束优化与对偶

Lagrange Multipliers and Duality

也叫：拉格朗日乘子法　Lagrange multiplier　KKT条件　KKT　对偶问题　dual problem

在交互版中打开（看它长在树上的哪里）

带约束的优化问题可以通过引入拉格朗日乘子变成无约束问题；乘子同时告诉你约束放松一点目标能改善多少，并引出一个往往更好解的对偶问题。

先要会：导数、偏导与梯度 凸函数与凸优化

梯度下降处理的是无约束问题。但很多问题带约束：概率之和必须为1、更新后的策略不能离旧策略太远、分类间隔必须至少为1。拉格朗日乘子法把约束“搬进”目标里。

等式约束：要最小化f(x)，满足g(x) = 0。构造拉格朗日函数

L(x, λ) = f(x) + λ·g(x)

在最优点，∇_x L = 0且g(x) = 0，即∇f与∇g平行。直觉是：沿约束曲面移动时f不能再下降，所以f的梯度必须垂直于约束面。

乘子的含义：λ（取绝对值）等于“约束放松一个单位，最优值改善多少”，经济学里叫影子价格。

不等式约束与对偶：对约束g(x) ≤ 0，要求λ ≥ 0，并满足互补松弛λ·g(x) = 0（约束不起作用时乘子为0），这些条件合称KKT条件。定义对偶函数d(λ) = min_x L(x, λ)，它总是原问题最优值的下界；最大化d(λ)得到对偶问题。凸问题在温和条件下两者相等（强对偶）。

在AI里：

  • 支持向量机的经典解法就是写出对偶问题，对偶形式里数据只以内积出现，于是可以换成核函数，见核技巧与间隔。
  • 在期望得分固定的约束下最大化信息量与熵，用拉格朗日乘子解出来恰好是Softmax与logits（玻尔兹曼分布），乘子就是逆温度。
  • TRPO在“新旧策略KL不超过δ”的约束下最大化改进；RLHF里的KL惩罚系数β可以看成这类约束的乘子，见人类反馈强化学习。

例子

最小化f(x, y) = x² + y²，约束x + y = 1。

L = x² + y² − λ(x + y − 1)。令偏导为0：2x = λ，2y = λ，所以x = y = 0.5，λ = 1，最优值0.5。

验证λ的含义：把约束改成x + y = 1.1，最优值变为1.1²/2 = 0.605，增加了0.105 ≈ λ×0.1。

对偶函数d(λ) = min L = λ − λ²/2，在λ = 1处取最大值0.5，与原问题相同。

容易误解的地方

  • 拉格朗日条件只是必要条件，满足它的点可能是极大、极小或鞍点。
  • 非凸问题里对偶问题只给下界，可能存在对偶间隙，不能直接用对偶解代替原解。
  • 深度学习中常把约束直接改成固定系数的惩罚项，这和真正求解约束问题不同：固定系数不保证约束被满足。
