雅可比矩阵与海森矩阵

Jacobian and Hessian

也叫：黑塞矩阵　二阶导数　曲率　Hessian　Hessian矩阵　Jacobian　雅可比

在交互版中打开（看它长在树上的哪里）

雅可比矩阵是“向量输出对向量输入”的全部一阶偏导；海森矩阵是标量函数的全部二阶偏导，描述曲面的弯曲程度。

先要会：导数、偏导与梯度 矩阵乘法与线性变换 链式法则

梯度只处理“很多输入、一个输出”的情形。但神经网络的每一层都是“向量进、向量出”，要描述它的局部变化，需要一张偏导数表，这就是雅可比矩阵。另一方面，梯度只告诉我们坡度，不告诉我们坡是越来越陡还是越来越缓；描述这种弯曲需要二阶导数，即海森矩阵。

雅可比矩阵。函数f: ℝⁿ → ℝᵐ的雅可比矩阵是m×n矩阵：

J_ij = ∂f_i / ∂x_j

它是f在某点附近的最佳线性近似：f(x + δ) ≈ f(x) + J δ。多层函数复合时，整体的雅可比等于各层雅可比相乘，这就是链式法则的矩阵形式。方阵雅可比的行列式det J表示这个映射在局部把体积放大了多少倍。

海森矩阵。标量函数L: ℝⁿ → ℝ的海森矩阵是n×n对称矩阵：

H_ij = ∂²L / ∂x_i ∂x_j

它的特征分解与奇异值分解特征值说明了各个方向上的弯曲：全为正说明这里像碗底（局部极小），有正有负说明是鞍点。最大与最小特征值之比（条件数）越大，曲面越像狭长的山谷，梯度下降越容易来回震荡。

为什么深度学习很少直接算海森。参数有n = 10⁹个时，海森矩阵有10¹⁸个元素，根本存不下。实践中只用它的近似或它与向量的乘积。

它出现在哪里。Hessian-free优化和L-BFGS用海森与向量的乘积或低成本近似来做二阶优化；Shampoo等优化器用分块的曲率近似给梯度做预处理；标准化流要求每一层可逆，并在似然里计入log|det J|以记录体积变化，见可逆流与流匹配；大批量与尖锐极小值用海森的大特征值刻画“尖锐”的极小值。

例子

雅可比：f(x, y) = (xy, x + y)，J = [[y, x], [1, 1]]。在(2, 3)处J = [[3, 2], [1, 1]]，行列式3×1 − 2×1 = 1，说明这里局部体积不变。海森：L(x, y) = x² + 3xy + 5y²，H = [[2, 3], [3, 10]]。它的特征值是11和1，都为正，所以L是一个碗形；条件数11，意味着最陡方向的弯曲是最缓方向的11倍。

容易误解的地方

  • 雅可比的行列默认约定是“输出在行、输入在列”，但有些教材和代码采用转置约定，推公式时要先确认。
  • 反向传播从不显式构造雅可比矩阵，而是计算“向量乘雅可比”（VJP），这样代价与一次前向相当。
