每维比特bits/dim

Bits per Dimension

也叫：每维比特　bits per dimension　bits per dim　bits/dim　bpd　负对数似然　negative log-likelihood　测试似然　test log-likelihood　去量化　dequantization　变分去量化　似然评测　likelihood evaluation

在交互版中打开（看它长在树上的哪里）

似然类图像生成模型的标准指标：测试图像的负对数似然换算成以2为底、再除以像素通道总数，即“平均每个子像素需要几个比特来编码”。越低越好，8位图像的平凡上限是8。

先要会：交叉熵 最大似然估计 生成建模的目标

GAN这类模型只能看样本质量，用生成质量指标：IS与FID里的FID来评。自回归模型、标准化流、VAE和扩散模型则能给出（或界定）数据的似然p(x)，可以直接问：模型给真实测试图像分配了多大的概率？为了让不同分辨率的数据集可比，常用每维比特（bits per dimension，bpd）来报告。

定义。一张图像x有D个维度（例如32×32×3 = 3072个子像素值），

bpd = −log₂ p(x) / D = NLL_nats / (D · ln 2)

在整个测试集上取平均。由信息论（见信息量与熵、交叉熵），它就是用这个模型做无损压缩时，平均每个子像素需要的比特数。8位图像每个值有256种可能，均匀分布就需要8比特，所以任何有意义的模型都应远低于8。

离散数据与去量化。像素是0到255的整数，而流模型和扩散模型定义的是连续密度。直接在离散点上拟合连续密度会让似然无限大。常用的做法是去量化：给每个像素加上[0, 1)的均匀噪声，在连续数据上计算密度，可以证明这给出离散似然的一个下界（即bpd的上界）。Flow++变分去量化流用学出来的噪声分布做“变分去量化”，得到更紧的界。

哪些模型报告它。PixelRNN / PixelCNN系列的自回归模型直接计算精确似然；标准化流RealNVP、Glow等标准化流通过变量替换计算精确密度；VAE（如VDVAE极深层级VAE）和扩散模型通过变分推断与ELBO报告bpd的上界，变分扩散模型VDM专门优化了扩散模型的似然。

局限。似然好不等于样本好看：一个模型可以把大量概率分配给人眼察觉不到的噪声细节而得到不错的bpd，样本却很模糊；反过来，FID很好的模型似然可能很差。所以生成模型论文通常同时报告两类指标。语言模型里对应的指标是困惑度和每字节比特。

例子

某模型在CIFAR-10（32×32×3 = 3072维）的一张测试图上给出负对数似然6550奈特，则bpd = 6550 / (3072 × 0.693) ≈ 3.08。也就是说，用这个模型压缩，这张图约需3.08 × 3072 ≈ 9460比特，约1.2KB，而原始存储需要3072字节。

容易误解的地方

  • 带去量化或用ELBO得到的是bpd的上界，论文中的“≤”不能和精确似然直接比较大小优劣。
  • 不同的预处理（像素缩放到[−1, 1]还是[0, 1]）会改变密度的数值，换算回原始像素空间时需要加上对应的对数雅可比项，漏掉会差很多。
