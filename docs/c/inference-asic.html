推理专用芯片

Inference-Specialized Chips

也叫：推理芯片　Inference Chip　Inference Accelerator　推理加速器　LPU　低延迟推理　SRAM推理芯片　快速推理　tokens per second　高速token生成　推理ASIC

在交互版中打开（看它长在树上的哪里）

专门为模型推理而不是训练设计的芯片，追求每秒生成更多token、更低延迟和更低的每token成本。

训练要求高精度、大显存和大规模互连，推理则更在意延迟、吞吐和成本；而大模型逐token生成时每一步都要读一遍全部权重，瓶颈在显存、内存带宽与“内存墙”。这让推理成为专用芯片最有机会的战场。

早期的Google TPU第一代就是推理芯片，NVIDIA也有T4推理卡这类推理卡。大模型时代的代表包括：用大量片上SRAM做确定性数据流的Groq LPU与推理专用芯片，用整片晶圆的Cerebras推理服务，只跑Transformer的Etched Sohu专用ASIC，以及把单个模型固化进硅片的Taalas HC1：模型固化芯片。2025年起大厂也开始把推理再拆细：Rubin CPX：预填充专用卡专做预填充，TPU 8t/8i：训练推理分家分出推理专用型号，NVIDIA通过NVIDIA授权Groq并挖走团队把Groq技术纳入自家机柜（Groq 3 LPX推理机柜）。

核心争论是专用化的代价：越专用越快，但模型架构变化时越容易过时。
