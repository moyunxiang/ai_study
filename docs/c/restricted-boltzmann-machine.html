受限玻尔兹曼机

Restricted Boltzmann Machine

两层的能量模型：可见层与隐藏层之间全连接、层内无连接，于是给定一层时另一层各单元相互独立，可以高效交替采样。用对比散度训练，曾是深度信念网络的积木。

先要会：能量模型与玻尔兹曼分布 概率图模型

从玻尔兹曼机说起。玻尔兹曼机用一个能量函数给每种二值状态打分，概率p ∝ exp(−E)（见能量模型与玻尔兹曼分布）。单元之间可以任意相连，表达力强，但推断和学习都极慢：要采样就得长时间运行MCMC（见MCMC与朗之万动力学）。

受限玻尔兹曼机（RBM）。只保留可见层v与隐藏层h之间的连接，同层之间不连。能量为

E(v, h) = −aᵀv − bᵀh − vᵀWh

这个“二部图”结构带来关键的便利：给定v时，各隐单元条件独立（见独立、条件独立与独立同分布），而且

p(h_j = 1 | v) = σ(b_j + Σ_i W_ij v_i)

反过来给定h时可见单元也是如此。于是可以整层并行地做Gibbs采样与马尔可夫随机场：v → h → v → h……。一个RBM在形式上就像一个用sigmoid的单隐层网络，只是权重同时用于“向上”和“向下”两个方向。

训练：对比散度。对数似然对W的梯度是“数据驱动的相关”减去“模型自己采样出的相关”：⟨v hᵀ⟩_数据 − ⟨v hᵀ⟩_模型。后一项需要模型达到平衡分布，代价太高。对比散度（CD-k）从数据出发只做k步（常常k = 1）吉布斯采样就用来近似第二项，有偏但便宜得多，让RBM第一次能在实际规模的数据上训练。

历史地位。深度信念网络（2006）把多个RBM逐层叠起来：先训练第一层RBM，把它的隐层激活当作下一层的输入再训练一个RBM，最后用反向传播微调。这种“无监督逐层预训练”是2006年前后深度学习复兴的起点之一。RBM也被用于协同过滤，是Netflix Prize获胜方案集成中的组成部分（见推荐系统与协同过滤）。

后来。ReLU、更好的初始化和大数据让深层网络可以直接用反向传播从头训练（见参数初始化），逐层预训练不再必要；生成建模也转向了VAE、GAN和扩散模型（见生成建模的目标）。RBM如今主要作为能量模型和概率图模型的教学范例，在量子多体物理中也被用作波函数的表示。

例子

3个可见单元、2个隐单元，偏置为0，W = [[2, 0], [0, 2], [2, −2]]。输入v = (1, 0, 1)：隐单元1的输入为2 + 2 = 4，p(h₁ = 1) = σ(4) ≈ 0.98；隐单元2的输入为0 − 2 = −2，p(h₂ = 1) = σ(−2) ≈ 0.12。采样得h = (1, 0)后，反向重建可见层：各单元输入为(2, 0, 2)，概率为(0.88, 0.5, 0.88)。

容易误解的地方

  • RBM的配分函数Z无法精确计算，所以训练过程中通常看不到真实的对数似然，只能看重建误差这类替代指标，而重建误差低并不等于模型好。
  • “受限”指的是层内没有连接，而不是参数或容量受限。
