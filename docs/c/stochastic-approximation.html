随机逼近与Robbins-Monro条件

Stochastic Approximation and the Robbins–Monro Conditions

也叫：随机逼近　stochastic approximation　Robbins-Monro　Robbins-Monro条件　Robbins–Monro算法　步长条件　step-size conditions　Q学习收敛　Q-learning convergence　Q-learning收敛性　增量平均　incremental mean　ODE方法　ODE method

只有带噪声的样本时，用逐渐变小的步长一点点逼近期望方程的解。Robbins-Monro条件规定了步长该怎样衰减，是表格Q-learning收敛定理的数学基础。

先要会：期望与方差 时序差分与自举 学习率与学习率调度

TD学习和Q-learning的更新形如Q ← Q + α·(目标 − Q)，目标是一个随机样本。为什么这样一步步更新最终会收敛到正确的值？步长α该怎么取？这些问题属于随机逼近理论，它也是随机梯度下降的理论源头。

Robbins-Monro算法（1951）。想求方程E_ξ[F(x, ξ)] = 0的根，但只能对给定的x采样一个带噪声的F(x, ξ)。迭代

x_{t+1} = x_t + α_t · F(x_t, ξ_t)

在适当条件下以概率1收敛到根。关于步长的经典条件是

Σ_t α_t = ∞，Σ_t α_t² < ∞

第一个保证步长总和够大，从任何起点都能走到目标；第二个保证步长衰减得够快，噪声最终被平均掉。α_t = 1/t满足两者；常数步长不满足第二个，1/t²不满足第一个。

最简单的例子：增量平均。估计一个随机变量的均值，μ ← μ + (1/n)·(x_n − μ)恰好得到样本平均，这就是α_t=1/t的随机逼近。强化学习中的蒙特卡洛方法的增量更新就是它。

在强化学习中。把TD和Q-learning的更新看作求解Bellman方程的随机逼近：目标的期望满足方程，单个样本是带噪声的观测。由此得到经典结论：在表格情形，若每个(s, a)都被无穷多次访问、每个(s, a)的步长满足Robbins-Monro条件，Q-learning以概率1收敛到Q*。这一结果由Watkins博士论文提出、之后被严格证明，系统的处理见《Neuro-Dynamic Programming》。分析常借助“ODE方法”：步长很小时，随机迭代的轨迹近似一个确定性的常微分方程（见常微分方程与随机微分方程）。

实践中的取舍。深度RL几乎总用常数步长（配合自适应学习率优化器），不满足理论条件：好处是能追踪不断变化的目标（策略在变、数据分布在变），代价是参数在解附近持续抖动，不会精确收敛。

例子

估计一枚硬币正面的概率，样本依次为1, 0, 1, 1，初值0。α_t=1/t时：0 + 1×(1−0) = 1；1 + ½×(0−1) = 0.5；0.5 + ⅓×(1−0.5) ≈ 0.667；0.667 + ¼×(1−0.667) = 0.75，正是样本平均。若用常数α=0.5：0.5, 0.25, 0.625, 0.8125，越近的样本权重越大，对非平稳问题反应更快，但永远会随新样本摆动。

容易误解的地方

  • 收敛定理是渐近的，只说最终会收敛，不说多快；实际速度取决于访问频率、γ和噪声大小。
  • 函数逼近下这些结论一般不成立，离策略时甚至可能发散，见Bellman算子与压缩映射。
