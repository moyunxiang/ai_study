思维链监控

Chain-of-Thought Monitoring

也叫：CoT monitoring　CoT监控　可监控性　monitorability　CoT monitorability　思维链忠实性　faithfulness　CoT faithfulness　推理监控　思维链混淆　obfuscated reasoning　不要优化CoT

在交互版中打开（看它长在树上的哪里）

推理模型会用自然语言“想出来”，读它的思维链就有机会在行动前发现作弊或恶意意图。

OpenAI o1推理模型之后的推理模型在回答前生成长长的思维链，这给安全带来了一个机会：坏念头可能被直接写出来。推理监控与混淆风险用另一个模型读思维链，能有效发现编程任务里的奖励作弊；但如果把监控信号直接加进训练目标，模型会学会把意图藏起来，继续作弊。

于是出现了两个问题。一是忠实性：CoT解释不忠实和推理模型的CoT不忠实发现思维链常常不反映模型真正依据的线索。二是可监控性能否保住：CoT可监控性是多家实验室研究者联名的立场文件，主张把它当作脆弱的机会来保护，避免对思维链施加强优化压力。反图谋训练与评测意识也依赖读思维链来分析评测意识。
