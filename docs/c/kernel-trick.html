核技巧与间隔

Kernel Trick and Margins

也叫：核方法　kernel method　核函数　kernel function　SVM　支持向量机　最大间隔　RBF核

在交互版中打开（看它长在树上的哪里）

把数据映射到更高维的特征空间后线性模型往往更好用；核技巧发现很多算法只需要样本两两之间的内积，于是可以用一个核函数直接算高维内积，而不必真的去算高维坐标。

先要会：内积与余弦相似度 逻辑回归 凸函数与凸优化 范数与距离

线性分类器（如逻辑回归）只能画一个超平面，处理不了“圆内圆外”这类问题。一个办法是先把输入x映射到更高维的特征φ(x)（例如加上所有二次项），在新空间里线性可分的可能性就大得多（见特征与表示学习）。问题是：维度一高，计算就爆炸。100维输入的全部二次项有5000多个，更高次的组合数更是天文数字。

核技巧的观察是：有一类算法在训练和预测时只用到样本之间的内积与余弦相似度φ(x)·φ(z)。如果存在一个函数k(x, z)能直接在原空间里算出这个内积，就根本不需要写出φ。这样的k叫核函数。常见的有：

  • 多项式核：k(x, z) = (x·z + c)^p
  • 高斯（RBF）核：k(x, z) = exp(−‖x − z‖² / (2σ²))，它对应的特征空间是无穷维的。

间隔：核技巧最著名的搭档是支持向量机（支持向量机）。在所有能分开两类数据的超平面里，SVM选间隔（离两边最近样本的距离）最大的那个。超平面为w·x + b = 0时，间隔宽度是2/‖w‖，最大化间隔就变成在约束下最小化‖w‖²，这是一个凸函数与凸优化问题，有唯一解。最终的分类器只依赖于少数离边界最近的样本（支持向量），并且只用到它们与新样本的核函数值。核技巧与最优间隔分类器（1992）正是把核函数与最大间隔结合起来。

兴衰：1990年代末到2000年代，核方法凭借凸优化和理论保证（VC维与一致收敛）成为主流。它的瓶颈是要算N×N的核矩阵，样本到百万级就算不动了，而且核函数得人选，不能像神经网络那样学出特征。深度学习之后，核的思想以新形式回归：神经正切核发现无限宽神经网络的训练等价于某个核方法；Performer核近似注意力用随机特征近似注意力里的softmax核。

例子

二维输入，取核k(x, z) = (x·z)²。它对应的特征映射是φ(x) = (x₁², √2·x₁x₂, x₂²)。

取x = (1, 2)，z = (3, 1)：

  • 用核函数：x·z = 3 + 2 = 5，k = 25。
  • 用特征映射：φ(x) = (1, 2√2, 4)，φ(z) = (9, 3√2, 1)，内积 = 9 + 12 + 4 = 25。

结果一样，但核函数只做了一次二维内积和一次平方，不需要构造三维向量。维度越高、次数越高，节省越大。

容易误解的地方

  • 不是任何二元函数都能当核，它必须对应某个特征空间里的内积（数学上要求核矩阵半正定）。
  • 核方法的计算和存储随样本数平方增长，这是它在大数据时代让位给神经网络的主要原因之一。
