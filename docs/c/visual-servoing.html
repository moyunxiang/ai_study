视觉伺服

Visual Servoing

也叫：视觉伺服　visual servoing　visual servo control　IBVS　基于图像的视觉伺服　image-based visual servoing　PBVS　基于位置的视觉伺服　position-based visual servoing　交互矩阵　interaction matrix　图像雅可比　image Jacobian　眼在手上　eye-in-hand　眼在手外　eye-to-hand

在交互版中打开（看它长在树上的哪里）

用相机图像直接闭环控制机器人运动：持续比较当前画面中的特征与目标位置之间的误差，按误差计算速度指令，直到误差消失。分为基于图像特征的IBVS和基于估计位姿的PBVS两类，是“看着做”的经典控制方法。

先要会：控制回路与控制频率 相机模型与多视图几何 雅可比矩阵与海森矩阵

先用相机估计物体的三维位置、再规划一条路径闭着眼执行，任何标定误差或物体移动都会导致失败。人伸手拿杯子时则是边看边调整。视觉伺服把相机放进控制回路（见控制回路与控制频率），在每个控制周期根据视觉误差修正运动。

两种基本形式。

  • 基于图像的视觉伺服（IBVS）：误差直接定义在图像上，例如目标上4个特征点的当前像素坐标与期望像素坐标之差e。关键是交互矩阵L（也叫图像雅可比），它描述相机运动速度v如何引起特征点在图像上移动：ė = L·v。经典控制律为

v = −λ · L⁺ · e

L⁺是伪逆，λ是增益，误差按指数衰减。L依赖特征点的深度，通常用估计值或期望位置处的值近似。IBVS对相机标定误差不敏感，但相机在三维空间中的轨迹可能绕远，甚至让特征离开视野。

  • 基于位置的视觉伺服（PBVS）：先从图像估计目标相对相机的位姿（见位姿与齐次变换SE(3)、姿态估计），误差定义在三维位姿上，相机轨迹更直观，但对标定和位姿估计误差更敏感。

相机安装方式。相机装在机械臂末端（眼在手上，eye-in-hand）或固定在外部看着机械臂和目标（眼在手外，eye-to-hand），二者的交互矩阵和标定方式不同，后者需要手眼标定（见相机模型与多视图几何）。

与学习方法的关系。学习型的闭环视觉策略可以看作“学出来的视觉伺服”：机械臂农场抓取训练网络预测某个运动指令能否带来成功抓取，并在执行中持续重新选择指令，作者明确把它称为一种连续的伺服；端到端视觉运动策略从图像直接输出电机力矩。它们不再需要手工设计特征和交互矩阵，但需要大量数据。经典视觉伺服仍常用于工业装配和对精度要求高的最后几厘米。

例子

IBVS对准一个二维码：期望它的4个角点在图像中位于以画面中心为中心、边长200像素的正方形上。当前角点整体偏右40像素、偏小（边长160像素）。按控制律，相机会同时向右平移（消除水平误差）并向前靠近（放大二维码）。设λ=0.5、控制周期0.1秒，误差每一步大约缩小5%，约4到5秒后误差降到初值的10%以下。数字为示意。

容易误解的地方

  • 交互矩阵在某些特征配置下奇异或病态，例如4个特征点几乎共线时，控制会变得不稳定。
  • 视觉处理延迟会降低可用的增益，延迟大时强行提高λ容易振荡。
