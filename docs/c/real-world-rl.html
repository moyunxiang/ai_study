强化学习的真实世界应用

Real-World Applications of RL

也叫：RL应用　RL落地　real-world RL　工业强化学习　RL控制　RL推荐　强化学习部署

在交互版中打开（看它长在树上的哪里）

RL走出游戏和仿真，用来控制数据中心、芯片布局、气球、视频编码和推荐系统等真实系统。

真实系统的难处在于试错昂贵、安全约束严格、模拟器不完美。早期公开案例有DeepMind数据中心节能的数据中心节能；YouTube REINFORCE推荐在推荐系统里用离策略修正的REINFORCE；RL芯片布局（AlphaChip）把芯片布局写成序列决策；Loon平流层气球导航用分布式价值RL控制平流层气球；MuZero视频码率控制把MuZero用于视频码率控制；GT Sophy赛车在真实赛车游戏里击败顶尖玩家。

共同经验是：离线数据、保守更新（参见离线强化学习）和良好的模拟器往往比算法本身更关键；部分成果（如芯片布局）的收益在学界有过公开争议。
