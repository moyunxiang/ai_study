上下文无关文法

Context-Free Grammar

也叫：context-free grammar　上下文无关语法　短语结构文法　phrase structure grammar　产生式规则　形式文法　formal grammar　改写规则　非终结符

在交互版中打开（看它长在树上的哪里）

用一组“左边一个符号、右边一串符号”的改写规则描述哪些句子合法、句子由哪些短语层层组成的形式系统。它是成分句法分析的基础，也用来约束程序和JSON的格式。

先要会：图、树与搜索

句子不是词的平铺：“那只黑猫追老鼠”里，“那只黑猫”是一个整体（名词短语），“追老鼠”是另一个整体（动词短语），它们再组成句子。要让计算机分析这种层次结构，先得有一种精确描述“哪些组合是合法的”的语言。上下文无关文法（CFG）就是最常用的一种。

定义。一个CFG由四部分组成：

  • 非终结符：表示短语类别，如S（句子）、NP（名词短语）、VP（动词短语）。
  • 终结符：真实出现的词。
  • 规则：形如A → β，A是一个非终结符，β是终结符和非终结符组成的串。
  • 起始符号：通常是S。

从S开始，反复把某个非终结符按规则替换，直到只剩词，就生成了一个句子；替换的过程画出来就是一棵句法树。“上下文无关”的意思是：A能否改写成β，与A的左右是什么无关。

表达能力。生成语法提出用形式文法刻画语言，乔姆斯基层级把文法按能力分为四级：正则文法 ⊂ 上下文无关 ⊂ 上下文有关 ⊂ 无限制。CFG能表达任意层数的嵌套（括号配对、从句套从句），这是有限状态的正则表达式做不到的。自然语言里少数现象（如某些交叉依存）超出了CFG，但CFG覆盖了绝大部分结构，树邻接文法TAG等更强的文法只扩展了一点点。

加上概率。同一个句子常有多棵合法的树。概率上下文无关文法PCFG给每条规则一个概率，一棵树的概率是所用规则概率的乘积，从而能挑出最可能的那棵（见成分句法分析）。CKY句法分析算法和Earley句法分析算法是在CFG下分析句子的经典动态规划算法。

今天在哪里用。除了语言学，CFG是编程语言语法的标准描述方式（BNF）。大模型的约束解码（见结构化生成与约束解码）常把JSON Schema或正则先转成文法，每一步只允许能让输出保持合法的token，XGrammar结构化生成就是这样的引擎。

例子

一个迷你文法：

S → NP VP NP → Det N | Det Adj N VP → V NP Det → 那只 | 一只，Adj → 黑，N → 猫 | 老鼠，V → 追

推导“那只黑猫追一只老鼠”：S ⇒ NP VP ⇒ Det Adj N VP ⇒ 那只 黑 猫 VP ⇒ 那只 黑 猫 V NP ⇒ 那只 黑 猫 追 Det N ⇒ 那只 黑 猫 追 一只 老鼠。

而“猫 那只 追”无法由这些规则推出，所以文法判定它不合法。

容易误解的地方

  • “上下文无关”是一个形式性质，不是说语义与上下文无关。
  • 手写的文法很难覆盖真实语言的全部现象；实际的句法分析器从树库里自动学出规则和概率。
  • 无分类器引导在扩散模型里也简称CFG（见条件生成与引导），和这里的文法毫无关系。
