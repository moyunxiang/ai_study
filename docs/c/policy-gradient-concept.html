策略梯度

Policy Gradient

也叫：PG　REINFORCE　策略梯度定理　policy gradient theorem　PPO　似然比梯度

在交互版中打开（看它长在树上的哪里）

直接对策略网络的参数做梯度上升，让带来高回报的动作概率变大、带来低回报的动作概率变小。不需要先学价值函数，也能处理连续动作。

先要会：策略与价值函数 奖励、回报与折扣 Softmax与logits 蒙特卡洛采样

基于价值的方法（如Q-learning）先学Q再取argmax，但动作是连续的（机器人关节力矩）时，argmax本身就是一个优化问题；而且我们真正想要的是策略本身。策略梯度直接把策略写成带参数θ的分布π_θ(a|s)，把期望回报J(θ) = E[G]当作目标做梯度下降的反方向——梯度上升。

难点。J(θ)是对“按π_θ采样出的轨迹”求期望，参数θ藏在采样分布里，不能直接对采样结果求导（环境也不可导）。

对数导数技巧。对任意函数f，∇_θ E_{a~π_θ}[f(a)] = E_{a~π_θ}[f(a)·∇_θ log π_θ(a)]。推导只用了一行：∇π = π·∇log π。右边是一个期望，可以用采样来估计（蒙特卡洛采样）。用到序列决策上就是

∇J(θ) = E[Σ_t ∇_θ log π_θ(a_t|s_t)·G_t]

读法：采一条轨迹，对每一步，沿着“让这个动作概率变大”的方向∇log π走，步长按这步之后的回报G_t加权。回报高的动作被加强，回报低的被削弱。这就是REINFORCE策略梯度（Williams 1992）；策略梯度定理把它推广到使用函数近似的一般情形。

基线。G_t通常全是正数，所有动作都会被加强，只是程度不同，估计的方差很大。减去一个与动作无关的基线b（常用状态价值V(s)）不改变梯度的期望，却能大幅降低方差：∇log π·(G_t − b)。G_t − V(s)就是优势，进一步发展成Actor-Critic与优势函数。

它在哪里。TRPO、PPO限制每次更新的步子，避免策略一下变坏；大语言模型的RLHF用PPO（见InstructGPT与RLHF），推理模型训练常用的GRPO也是策略梯度，策略就是语言模型，动作就是token。

例子

两个动作的softmax策略，logits初值θ=(0, 0)，所以π=(0.5, 0.5)。采样到动作1，得到回报G=2。

对softmax，∇_θ log π(动作1) = e₁ − π = (1, 0) − (0.5, 0.5) = (0.5, −0.5)。学习率0.1，更新θ ← θ + 0.1×2×(0.5, −0.5) = (0.1, −0.1)，新的π(动作1)=1/(1+e^{−0.2}) ≈ 0.550。

加基线b=1后，权重变为G − b = 1，θ=(0.05, −0.05)，π(动作1)≈0.525。若这次回报只有0.5（低于基线），权重为负，动作1的概率反而会降低——这正是基线的作用：只有“比平均好”的动作才被加强。

容易误解的地方

  • 策略梯度的估计方差很大，需要很多样本，所以朴素REINFORCE很少直接使用。
  • 步子太大时策略会突然崩坏，而且坏策略采到的数据更差，难以恢复，所以TRPO/PPO要限制更新幅度。
  • ∇log π·G是一个估计梯度的技巧，不是损失本身；代码里常写成−log π·G再交给自动求导。
