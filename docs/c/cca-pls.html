典型相关分析与偏最小二乘

Canonical Correlation Analysis and Partial Least Squares

也叫：典型相关分析　canonical correlation analysis　CCA　偏最小二乘　partial least squares　PLS　PLS回归　PLS regression　多视角学习　多视图学习　multi-view learning　核CCA　kernel CCA　深度CCA　deep CCA　DCCA　SVCCA　PWCCA　CKA　中心核对齐　centered kernel alignment　表示相似性　representation similarity

同一批样本有两组变量（两个视角）时，找出让两组投影后最相关的方向：CCA最大化相关系数，PLS最大化协方差、常用于多输出回归。它们是多视角学习的经典方法，也用于比较网络表示。

先要会：协方差矩阵 特征分解与奇异值分解

很多数据天然有两种以上的“视角”：一篇网页有正文和指向它的链接文字，一段视频有画面和声音，一位病人有影像和化验指标。多视角学习利用这种结构：不同视角各自有噪声，但它们共同反映的信息往往才是真正重要的。协同训练Co-Training就是一个早期例子：用两个视角各训练一个分类器，互相为对方提供伪标签（见半监督学习与伪标签）。

典型相关分析（CCA）。设两组变量为x（p维）和y（q维）。CCA寻找投影方向a和b，使一维投影aᵀx与bᵀy的相关系数最大：

max_{a,b} corr(aᵀx, bᵀy)

找到第一对方向后，再在与之不相关的方向里找第二对，依此类推，最多得到min(p, q)对。解可以通过对“白化后的交叉协方差矩阵”做特征分解与奇异值分解得到（见协方差矩阵）。直观地说，PCA找的是一组变量内部方差最大的方向（见降维与PCA），CCA找的是两组变量之间“一起变化”最强的方向。

偏最小二乘（PLS）。最大化的是协方差而不是相关系数：max cov(aᵀx, bᵀy)。它同时偏好“自身方差大”和“与对方相关”的方向，在样本数少、特征维度高（甚至多于样本数）且特征共线的情况下比普通最小二乘稳定得多，常用于化学计量学、基因组学中的多输出回归（见线性回归和正则化与权重衰减）。

核与深度版本。核CCA用核技巧与间隔捕捉非线性关系；深度CCA用两个神经网络分别把两个视角映射到表示空间，再最大化它们之间的相关性，这与后来的跨模态对比学习（如CLIP）目标相近（见多模态学习：对齐与融合）。

比较神经网络的表示。CCA有一个有用的性质：对每个视角做任意可逆线性变换都不改变结果。于是可以用它比较两个网络（或同一网络的两层）在同一批输入上的激活是否“表示了相同的信息”，即使它们的神经元排列和尺度完全不同。SVCCA、PWCCA以及后来更常用的CKA（中心核对齐）都属于这一类表示相似性度量，被用来研究不同随机种子训练的网络学到的东西是否一样、表示在训练中如何演化。

例子

100名学生，x = (数学成绩, 物理成绩)，y = (编程课成绩, 统计课成绩)。CCA找到的第一对方向可能是a ≈ (0.6, 0.4)、b ≈ (0.5, 0.5)，投影后的典型相关系数为0.85：“理科综合能力”同时决定了两组成绩。第二对方向可能对应“偏爱物理还是偏爱数学”，典型相关只有0.2。（数字为示意）

容易误解的地方

  • 样本数接近或少于特征维数时，CCA会找到虚假的完美相关，必须加正则化（正则化CCA）或先降维。
  • 相关性高不代表因果，也不代表两个视角的投影在语义上可解释；方向的符号和尺度也不唯一。
