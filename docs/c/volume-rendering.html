体渲染

Volume Rendering

也叫：体绘制　光线行进　ray marching　NeRF　神经辐射场　可微渲染　alpha合成

在交互版中打开（看它长在树上的哪里）

把三维空间看成一团半透明的“雾”，沿每条视线累加各处的颜色并按前面遮挡的程度衰减，得到像素颜色；它可微，因此能从照片反推三维场景。

先要会：相机模型与多视图几何 三维表示：体素、点云、网格、隐式场

从多张照片重建三维场景，最自然的做法是：猜一个三维表示，渲染成图片，与真实照片比较，再改进猜测。这要求渲染过程可以求导。传统的网格光栅化在物体边缘处是离散的“遮挡或不遮挡”，梯度很难定义。体渲染把场景看成连续分布的半透明介质，渲染结果对场景参数处处可导。它在计算机图形学里早就用于医学CT可视化、云和烟雾的渲染。

模型：空间每一点x有密度σ(x)（单位长度上光被吸收的程度）和颜色c(x)。从相机发出一条光线，在上面取N个采样点，间距δ_i。第i段的不透明度是α_i = 1 − exp(−σ_i δ_i)；光线走到第i点前还没被挡住的比例（透射率）是T_i = exp(−Σ_{j<i} σ_j δ_j)。像素颜色为

C = Σ_i T_i · α_i · c_i

权重w_i = T_i α_i可以理解为“光线在第i段被吸收的概率”，所有权重之和不超过1，剩下的部分是背景。

在AI里：NeRF（2020）用一个MLP表示σ和c（输入位置和视角），对每条光线采样上百个点做体渲染，只用照片和相机位姿监督训练，得到前所未有的新视角合成质量。缺点是每个像素都要对MLP查询很多次，训练和渲染都慢。Instant-NGP用多分辨率哈希网格代替大部分MLP，把训练缩短到分钟级；Mip-NeRF处理了不同距离下的混叠。3D高斯泼溅用数百万个三维高斯椭球代替连续场，同一个α合成公式改为按深度排序后逐个叠加，实现实时渲染。另见三维表示：体素、点云、网格、隐式场、相机模型与多视图几何。

例子

一条光线上3个采样点，间距δ = 1，密度σ = [0.1, 2.0, 5.0]，颜色分别为红、绿、蓝。

  • 第1点：T = 1，α = 1 − e^−0.1 ≈ 0.095，权重0.095。
  • 第2点：T = e^−0.1 ≈ 0.905，α = 1 − e^−2 ≈ 0.865，权重≈ 0.78。
  • 第3点：T = e^−2.1 ≈ 0.122，α ≈ 0.993，权重≈ 0.12。

像素颜色 ≈ 0.10红 + 0.78绿 + 0.12蓝，主要是绿色：第2点密度高，挡住了身后密度更高的第3点。

容易误解的地方

  • 体渲染学到的密度场不一定对应清晰的表面，直接从中提取网格往往有噪声。
  • 训练依赖准确的相机位姿，位姿通常要先用传统多视图几何方法估计。
  • 3DGS用的是按深度排序后的α合成，与NeRF的连续积分在思想上一致，但计算方式和近似都不同。
