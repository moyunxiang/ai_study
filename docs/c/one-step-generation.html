从零训练的一步生成

One-Step Generative Models Trained from Scratch

也叫：一步生成　One-step Generation　1-NFE　单步生成　少步生成　Few-step Generation　无蒸馏一步生成　Flow Map　流映射　平均速度　Average Velocity　一致性训练　Consistency Training　Shortcut　MeanFlow系列

在交互版中打开（看它长在树上的哪里）

不先训练多步教师再蒸馏，而是直接训练一个一两步就能出高质量图的模型。

传统加速办法是先训练多步扩散模型，再用蒸馏压到几步（见少步采样与扩散蒸馏）。这一路线想跳过教师：直接学“从任意时刻跳到任意更早时刻”的映射，或者干脆不要ODE。

脉络是：一致性模型提出让同一条轨迹上的点都映射到同一终点；连续时间一致性模型sCM把它做成稳定的连续时间版本；捷径模型一步生成让网络以步长为条件；归纳矩匹配IMM用分布级的矩匹配取代逐样本约束；MeanFlow一步生成改学区间平均速度，ImageNet 256上一步FID 3.43；pMF像素空间一步生成把它搬到像素空间；漂移模型Drifting则完全抛开ODE，在训练时让生成分布被真实数据吸引、被自身排斥，一步FID 1.54。

开放问题：这些结果多在ImageNet类条件生成上取得，能否像蒸馏方法（DMD2改进分布匹配蒸馏、潜空间对抗蒸馏LADD）那样在大规模文生图、视频上同样有效，还没有定论；一步模型的多样性与可编辑性也常不如多步。
