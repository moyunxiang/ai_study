Top-1与Top-5错误率

Top-1 and Top-5 Error

也叫：top-1准确率　top-k accuracy　ImageNet错误率　top-1　top-5　top-1 accuracy　top-5错误率

在交互版中打开（看它长在树上的哪里）

让模型按概率给出最可能的k个类别，只要正确答案在这k个里就算对；Top-1错误率要求第一猜就对，Top-5错误率允许猜五次。

先要会：Softmax与logits 准确率、精确率、召回率与F1

分类模型最后通常经过Softmax与logits，对每个类别输出一个概率。最严格的评法是只看概率最大的那一个类别是否等于标签，错的比例叫Top-1错误率（1减去它就是常说的准确率）。

为什么还要Top-5？因为在类别很多、很细的数据集上，“唯一正确答案”本身就不太可靠。ImageNet竞赛（ILSVRC）用1000个类别，其中光狗的品种就有一百多种；很多照片里同时有好几样东西（一张桌上有键盘、鼠标和咖啡杯，标签只写了其中一个）。只看第一猜会把很多合理的预测算成错。于是竞赛规定：模型给出5个候选，只要标签在其中就算对。

定义很简单：对每个样本，把各类别概率从大到小排序，取前k个组成集合S_k(x)，

Top-k错误率 = (1/N) · Σ 1[y_i ∉ S_k(x_i)]

其中1[·]在条件成立时为1、否则为0。k越大，错误率越低；k等于类别总数时错误率为0。

它出现在哪里：Top-5错误率是2010年代ImageNet竞赛的主指标，深度学习在视觉上的崛起就是用它记录的。2012年AlexNet的Top-5错误率为15.3%，第二名为26.2%；之后VGG、GoogLeNet / Inception继续下降，2015年ResNet的集成模型降到3.57%。等到Top-5接近饱和，论文的重心转回Top-1，也开始在ImageNetV2：榜单过拟合了吗、ImageNet-C这类新测试集上检验模型是否真的能泛化。同样的“前k个里有没有对的”的思路也出现在检索（Recall@k）和代码生成（pass@k：生成k份程序，至少一份通过测试就算解出，见HumanEval）里。

例子

一个5分类问题，三张图片的预测概率排序和真实标签如下：

  • 图1：猫0.6、狗0.3、狐狸0.05……，标签“猫”——Top-1对，Top-2对
  • 图2：狗0.5、狐狸0.3、猫0.1……，标签“狐狸”——Top-1错，Top-2对
  • 图3：狼0.4、狗0.35、狐狸0.15、猫0.07……，标签“猫”——Top-1错，Top-2错，Top-4才对

于是Top-1错误率 = 2/3 ≈ 67%，Top-2错误率 = 1/3 ≈ 33%，Top-4错误率 = 0。

容易误解的地方

  • Top-1和Top-5的数字不能混着比；看ImageNet老论文时先确认表格报告的是哪一个，以及是单模型还是集成、单裁剪还是多裁剪测试。
  • 错误率和准确率互为补数，有的论文报“误差”，有的报“准确率”，读表时注意方向。
  • 在类别少的问题上（例如10类），Top-5几乎没有区分度。
