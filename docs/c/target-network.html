目标网络与软更新

Target Networks and Soft Updates

也叫：目标网络　target network　target net　软更新　soft update　soft target update　硬更新　hard update　Polyak更新　Polyak update　目标网络更新频率　τ　tau

在交互版中打开（看它长在树上的哪里）

计算TD目标时不用正在训练的网络，而用一份更新得更慢的副本，让“要追的目标”暂时固定住，避免网络追着自己的影子跑。副本可以每隔一段时间整体复制（硬更新），也可以每步缓慢地插值（软更新）。

先要会：时序差分与自举 强化学习中的函数逼近

用神经网络做Q-learning时，损失是(r + γ·max_{a'} Q(s', a'; θ) − Q(s, a; θ))²。目标和预测用的是同一组参数θ：每做一步梯度下降，预测往目标靠，目标自己也跟着动了。相邻状态的Q值又高度相关，于是容易出现振荡、发散，像一只狗追自己的尾巴。这是致命三元组在深度RL里最直接的表现。

目标网络。再保留一份参数θ⁻，只用它来算目标：

y = r + γ · max_{a'} Q(s', a'; θ⁻)，损失(y − Q(s, a; θ))²

θ⁻在一段时间内不变，这段时间里训练就是一个目标固定的普通回归问题。

两种更新方式。

  • 硬更新：每隔C步把θ整体复制给θ⁻。DQN（Nature版）引入了这一做法，C为1万步量级。
  • 软更新（Polyak更新）：每步θ⁻ ← τ·θ + (1 − τ)·θ⁻，τ很小。DDPG用τ=0.001，TD3和SAC常用0.005。等价于θ⁻是θ的指数移动平均，见Polyak平均与EMA。

代价与替代。目标网络让信息传播变慢：一个奖励要等目标网络更新后才能影响上游状态，所以C或τ需要权衡。Double DQN顺便利用了目标网络来减少高估，见过估计与最大化偏差。近年也有工作尝试去掉它：PQN简化深度TD和CrossQ批归一化RL借助层归一化或批归一化让网络本身更稳定，不用目标网络也能训练。

例子

软更新τ=0.005：θ⁻对θ的“记忆”约为1/τ=200步。设某参数θ从0突然跳到1之后保持不变，θ⁻经过100步达到1 − 0.995^100 ≈ 0.39，200步约0.63，1000步约0.99。硬更新C=1000则是前999步保持0，第1000步突然变成1。

容易误解的地方

  • 目标网络不能保证收敛，只是在实践中显著减少振荡和发散。
  • 只有算目标时用θ⁻；选动作、算损失的预测部分仍然用θ。Double DQN的“在线网络选、目标网络评”容易被写反。
