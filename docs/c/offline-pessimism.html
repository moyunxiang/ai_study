离线RL的悲观与保守

Pessimism and Conservatism in Offline RL

也叫：悲观原则　pessimism　pessimism principle　保守性　conservatism　保守Q学习　策略约束　policy constraint　行为正则　behavior regularization　行为约束　样本内学习　in-sample learning　数据覆盖　data coverage　集中系数　concentrability　concentrability coefficient　分布外动作　OOD action　外推误差　extrapolation error

离线RL的核心对策：数据没覆盖到的动作，宁可往坏处估计。具体做法有约束策略别离数据太远、主动压低分布外动作的Q值、只在数据内部学习，以及按不确定性扣分。

先要会：离线强化学习 过估计与最大化偏差 分布偏移

离线强化学习只有一份固定数据集，无法通过试一试来纠正错误。Q-learning的max会挑中被高估的、数据里没出现过的动作，误差还会经自举放大（见过估计与最大化偏差），学出的策略在纸面上回报很高、一上线就崩。几乎所有离线RL算法都可以理解为在实现同一个原则：对不确定的东西保持悲观。它和在线探索的上置信界与乐观原则正好相反：在线时乐观能带来新数据，离线时没有新数据，乐观只会自欺。

四类做法。

  • 策略约束：要求学到的策略π不离产生数据的行为策略太远。BCQ批量约束Q学习只在生成模型给出的“类似数据”的动作中选；BEAR自举误差约束和BRAC行为正则化约束分布距离；TD3+BC极简离线RL最简单，在actor损失里加一项行为克隆：−λ·Q(s, π(s)) + (π(s) − a)²。
  • 价值正则（保守）：直接修改Q的训练目标。离线强化学习CQL在TD损失之外加一项α·(E_s[log Σ_a exp Q(s, a)] − E_{(s,a)~D}[Q(s, a)])，压低所有动作（特别是Q高的分布外动作）的Q值、抬高数据中动作的Q值，学到的Q在期望上是真实值的下界。
  • 样本内学习：训练过程中从不在数据外的动作上查询Q。隐式Q学习IQL用分位数式（expectile）回归估计数据内动作的“较好那部分”，再用优势加权的行为克隆提取策略。
  • 不确定性惩罚：用模型或Q的集成估计不确定性，按不确定性扣分，如MOPO模型离线优化在模型奖励上减去不确定性，PEVI悲观值迭代在理论上用置信下界做值迭代。

数据覆盖与理论。离线RL能学到多好，取决于数据覆盖了哪些状态-动作。常用集中系数衡量：C^π = max_{s,a} d^π(s, a) / μ(s, a)，即目标策略的占用度量（见状态访问分布与占用度量）与数据分布μ之比的最大值。早期理论要求所有策略都被覆盖；悲观方法的结论更弱也更实用：只要某个好策略被数据充分覆盖，悲观算法就能与它竞争。

例子

某状态的数据里只有动作a₁（真实价值5）。神经网络对没见过的a₂随意外推出Q=8（真实价值1）。普通离策略Q-learning取max，选a₂，上线后只拿到1。CQL的正则项会压低a₂这类高Q的分布外动作：若压到4，就会选回a₁。代价是：如果a₂其实真的更好（真实价值8），悲观算法也会错过它，离线RL无法发现数据之外的好动作。

容易误解的地方

  • 悲观的力度是关键超参数：太弱等于没加，太强则退化为行为克隆，比数据策略好不了多少。
  • 数据质量决定上限：数据全来自随机策略时，任何离线算法都很难学好；评测常用D4RL离线RL基准中不同质量的数据集分开比较。
