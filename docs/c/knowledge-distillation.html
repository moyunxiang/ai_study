知识蒸馏

Knowledge Distillation

也叫：KD　师生模型　teacher-student　软标签　soft labels　模型蒸馏

在交互版中打开（看它长在树上的哪里）

用一个已经训练好的大模型（教师）的输出概率分布作为“软标签”，去训练一个小模型（学生），让小模型以低得多的成本接近大模型的效果。

先要会：Softmax与logits 交叉熵 KL散度

大模型和集成学习效果好，但部署代价高：推理慢、占显存、耗电。能否训练一个小模型，让它学会大模型的“本事”？直接用原始标签训练小模型，效果往往比大模型差一截。知识蒸馏的发现是：大模型输出的完整概率分布，比原始的独热标签包含多得多的信息。

软标签：一张手写“2”的图片，原始标签只说“是2”；教师模型可能说“是2的概率0.9，像3的概率0.08，像7的概率0.02”。“这个2有点像3、不太像7”这种类别之间的相似性信息（Hinton称之为dark knowledge）对学生非常有用。

温度：教师的Softmax与logits输出通常极为尖锐，非最大类的概率接近0，信息被压没了。蒸馏时把教师和学生的logits都除以温度T（T > 1）再做softmax，分布变平，小概率的差异显现出来。损失通常为

L = α · CE(y, p_S) + (1 − α) · T² · KL(p_T^(T) ‖ p_S^(T))

第一项是与真实标签的交叉熵，第二项是学生与教师软化分布之间的KL散度，乘以T²是为了让梯度的量级不随温度变化。

它出现在哪里：知识蒸馏（Hinton等，2015）提出了这一形式，起点是把集成压缩成单个模型。DistilBERT把BERT缩小40%、速度提高60%，同时保留了97%的语言理解能力。在大模型时代，含义扩展为“用强模型生成的数据训练弱模型”：用大模型的回答做小模型的指令数据（如Zephyr蒸馏对齐），以及扩散模型中把多步采样蒸馏成少步（渐进蒸馏与v预测）。是否允许用他人模型的输出做蒸馏，也成了产业争议（中美“蒸馏攻击”指控）。

例子

教师对三类的logits为[5, 2, 1]。

  • T = 1：softmax ≈ [0.936, 0.047, 0.017]，接近独热，第2、3类的差别几乎看不出。
  • T = 4：logits变为[1.25, 0.5, 0.25]，softmax ≈ [0.543, 0.257, 0.200]，能清楚看到“第2类比第3类更像正确答案”。

学生在T = 4下去拟合后一个分布，就学到了类别之间的相似关系。

容易误解的地方

  • 学生太小时，即使有好的教师也学不到教师的水平；教师与学生差距过大时，效果有时反而不如用一个中等大小的教师。
  • 只用教师生成的文本训练（序列级蒸馏）时，学生会继承教师的错误和偏好，而且难以超过教师。
