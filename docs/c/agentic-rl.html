智能体强化学习

Agentic Reinforcement Learning

也叫：Agentic RL　智能体RL　agent RL　多轮强化学习　multi-turn RL　工具强化学习　tool-integrated RL　TIR　工具集成推理　交互式强化学习　长程RL　环境RL

在交互版中打开（看它长在树上的哪里）

把LLM放进能调用工具、与环境多轮交互的场景，用最终任务结果作为奖励做强化学习，而不只训练单轮答题。

推理RL最初是单轮的：给一道题、生成一段推理、判对错。智能体强化学习把它扩展成多轮决策：模型在推理中途调用搜索引擎（Search-R1）、代码解释器（ReTool工具强化学习），或在真实代码仓库里修bug（SWE-RL），整个交互轨迹结束后才拿到奖励。深度研究模型（通义DeepResearch）、编码模型（Cursor 2.0与Composer）和Kimi K2.5视觉智能体等都在大规模环境里做这类训练；ToolOrchestra小模型编排器、Conductor指挥家模型把被调用的工具扩展到其他LLM。

与单轮RL相比，难点在于长轨迹的信用分配、环境搭建与沙箱成本、工具返回的噪声，以及奖励被利用（比如改测试让它通过）。
