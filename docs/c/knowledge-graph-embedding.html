知识图谱嵌入与知识表示学习

Knowledge Graph Embedding

也叫：知识表示学习　知识图谱嵌入　knowledge graph embedding　KGE　knowledge representation learning　KRL　实体嵌入　entity embedding　关系嵌入　relation embedding　链接预测　link prediction　知识图谱补全　knowledge graph completion　KGC　翻译模型　translational models　TransH　TransR　FB15k-237　WN18RR　三元组打分

在交互版中打开（看它长在树上的哪里）

把知识图谱的实体和关系变成向量，让三元组是否成立能用打分函数算出。TransE把关系看作平移，DistMult、ComplEx、RotatE用乘法或旋转，主要用于补全缺失的边。

先要会：嵌入向量 排序指标：NDCG、MRR与Recall@K

知识图谱用三元组记录事实：（北京，首都是，中国）、（爱因斯坦，出生于，乌尔姆）（见知识图谱，常见图谱有Freebase、Wikidata、DBpedia、YAGO知识库）。图谱永远不完整，大量真实事实没被录入；而且符号形式的三元组不方便和神经网络结合。知识表示学习（知识图谱嵌入）为每个实体e和关系r学一个向量（见嵌入向量），定义打分函数f(h, r, t)，让真实三元组得分高、虚假三元组得分低。

平移模型。TransE知识图谱嵌入（2013）的想法极其简单：关系是向量空间里的一次平移，h + r ≈ t，打分为

f(h, r, t) = −‖h + r − t‖

“首都是”这个向量把每个首都平移到它的国家。它的弱点是处理不了一对多、多对一关系：如果“美国，总统是”同时指向多个人，这些人的向量会被挤到同一点。TransH、TransR把实体投影到关系相关的超平面或空间后再平移。

乘法（双线性）模型。RESCAL张量分解用一个矩阵表示每个关系：f = hᵀM_r t。DistMult双线性嵌入把M_r限制成对角阵，参数少，但天然对称，无法区分（A，父亲是，B）和（B，父亲是，A）。ComplEx复数嵌入改用复数向量，取共轭后打分，可以表达非对称关系。

旋转模型。RotatE旋转嵌入把关系看作复平面上的逐维旋转：t = h ∘ r，|r_i| = 1。旋转能自然表达对称（转180°）、反对称、逆关系（反向旋转）和组合关系（两次旋转相加）。

图神经网络。关系图卷积R-GCN在图上做按关系区分的消息传递（见图神经网络与消息传递），再用DistMult之类的解码器打分。

训练与评测。正样本是图谱中的三元组，负样本通过随机替换头或尾实体构造，用间隔损失或交叉熵训练（见合页损失与间隔类损失和难例挖掘与难负样本）。评测是链接预测：给定（h, r, ?），把所有实体按得分排序，看正确答案排第几，报告MRR和Hits@10（见排序指标：NDCG、MRR与Recall@K），常用FB15k-237、WN18RR等数据集。

今天的位置。在推荐、搜索和医药知识图谱中仍然常用；与大语言模型结合时，知识图谱更多作为检索增强的外部知识源（见检索与向量数据库），而模型参数本身也被视为一种隐式的知识库（见参数化知识与上下文知识）。

例子

TransE，二维向量：北京 = (1, 2)，中国 = (3, 3)，“首都是” = (2, 1)。北京 + 首都是 = (3, 3)，正好等于中国，得分为0（最高）。换成虚假三元组（北京，首都是，日本），日本 = (5, 1)，距离‖(3, 3) − (5, 1)‖ ≈ 2.83，得分−2.83，排在后面。若“东京 = (3, 0)”，模型会预测东京 + 首都是 = (5, 1) = 日本。

容易误解的地方

  • FB15k、WN18等早期数据集存在大量逆关系泄漏（测试三元组的逆在训练集里），模型靠记住逆关系就能得高分，所以改用FB15k-237和WN18RR。
  • 嵌入模型只能对图谱里已有的实体打分；新实体出现时需要重新训练或使用基于文本描述的方法。
