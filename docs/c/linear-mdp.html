线性MDP与函数逼近下的理论结构

Linear MDPs and Structural Assumptions

也叫：线性MDP　linear MDP　低秩MDP　low-rank MDP　Bellman完备性　Bellman completeness　可实现性　realizability　线性函数逼近理论　RL理论

在交互版中打开（看它长在树上的哪里）

强化学习理论里让函数逼近“可分析”的结构假设：转移和奖励都是已知特征的线性函数（线性MDP）。在这类假设下，样本需求可以只依赖特征维数而与状态数无关；更一般的刻画有Bellman秩、eluder维数等。

先要会：强化学习中的函数逼近 遗憾与遗憾界

表格RL的理论结果（如遗憾与遗憾界、样本效率与样本复杂度）都随状态数S增长，状态连续或巨大时没有意义。要解释为什么函数逼近下仍然能高效学习，必须对问题结构做假设。一个自然的问题是：只假设“最优Q函数可以用某个d维特征线性表示”够不够？

只假设可实现性不够。已有下界结果表明：即使Q*（甚至所有策略的Q^π）都精确地是已知特征的线性函数，某些问题仍需要随时域或维数指数增长的样本；离线情形下离线RL线性下界也给出了类似的负面结果。原因是Bellman备份把线性函数映射出了线性函数类，误差无法控制（这也是致命三元组的一种理论版本）。

线性MDP。更强的假设：存在已知特征φ(s, a) ∈ R^d，使得

P(s'|s, a) = ⟨φ(s, a), μ(s')⟩，r(s, a) = ⟨φ(s, a), θ⟩

μ和θ未知。这样任何价值函数做一次Bellman备份后都仍是φ的线性函数（Bellman完备性），所以对任意策略，Q^π都是线性的。在此假设下，LSVI-UCB线性MDP用带乐观奖励的最小二乘值迭代，得到只依赖d、时域H和√T、与状态数无关的遗憾界；离线情形的悲观版本见PEVI悲观值迭代和离线RL的悲观与保守。

更一般的结构。

  • 低秩MDP：转移可以分解为两个d维特征的内积，但特征未知，需要同时学表示。
  • Bellman秩：衡量“Bellman误差矩阵”的秩，涵盖线性MDP、某些POMDP等许多情形，见Bellman秩与OLIVE。
  • eluder维数：衡量一个函数类里“看似不同、已有数据却分辨不出来”的程度，用于分析一般函数类下的乐观算法，见Eluder维度与后验采样和Bellman Eluder维度与GOLF。

这些理论通常给出存在性的、计算上未必可行的算法，与深度RL实践之间仍有距离，但它们回答了“函数逼近下何时可能、何时不可能高效学习”。

例子

一个有10^6个状态的MDP，若它是d=20维的线性MDP，LSVI-UCB的遗憾界只与d=20、时域H和回合数有关，与10^6无关；表格算法的界则至少随√S（这里是1000）增长。反过来，如果特征只能精确表示Q*、不满足线性MDP的条件，就不存在通用的多项式样本保证。

容易误解的地方

  • 线性MDP的特征是事先给定的，现实中很难找到恰好满足条件的特征；深度RL里学到的表示一般不满足这一点。
  • “与状态数无关”的界往往有很高的d和H的幂次，在中等规模问题上未必比表格方法更紧。
