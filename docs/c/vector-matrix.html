向量、矩阵与张量

Vectors, Matrices and Tensors

也叫：tensor　vector　matrix　数组　ndarray　线性代数　linear algebra

在交互版中打开（看它长在树上的哪里）

向量是一列数，矩阵是一张二维数表，张量是任意维的数组。AI模型的输入、参数和中间结果全部以张量的形式存储和计算。

计算机处理图片、文字、声音之前，必须先把它们变成数。最自然的组织方式就是数组：一个样本的若干个特征排成一列，就是向量；很多个向量摞在一起，就是矩阵；再往上加维度，就是张量。

定义。长度为n的向量x = (x_1, …, x_n)可以看作n维空间里的一个点或一个箭头。m×n矩阵A有m行n列，A_ij表示第i行第j列。张量是这一概念的推广：0维是标量，1维是向量，2维是矩阵，3维及以上统称张量。张量最重要的属性是形状（shape），例如(32, 3, 224, 224)。

在深度学习里怎么用。约定俗成的写法是：第一个维度是批（batch，一次一起处理的样本数），后面是每个样本自身的结构。一批图片是(批, 通道, 高, 宽)；一批句子经过嵌入向量之后是(批, 序列长度, 隐藏维度)。模型参数也是张量：一个全连接层的权重是矩阵，一个卷积核是4维张量。写代码时大部分bug都是形状对不上，所以读论文和代码时要随时追踪每个张量的形状。

它出现在哪里。几乎所有地方。NumPy与SciPy让“对整个数组做运算”成为科学计算的标准写法；TensorFlow和PyTorch的核心数据结构就叫Tensor；word2vec把每个词表示成一个几百维的向量，词之间的关系变成了向量之间的几何关系。后续的运算见内积与余弦相似度和矩阵乘法与线性变换，图像如何变成张量见图像作为张量。

例子

一张224×224的彩色图片有红绿蓝3个通道，形状是(3, 224, 224)，共3×224×224 = 150528个数。把32张这样的图片打包成一批，形状变成(32, 3, 224, 224)，共4816896个数。同理，一句5个词的话，每个词用4维向量表示，就是一个5×4的矩阵。

容易误解的地方

  • 数学里的“维度”和代码里的“维度”含义不同：数学上说“300维向量”指长度为300；代码里说“2维张量”指有两个轴（即矩阵）。
  • 不同框架的轴顺序约定不同，例如图片在PyTorch里通常是(批, 通道, 高, 宽)，在TensorFlow里常是(批, 高, 宽, 通道)。
  • 物理学里的“张量”有坐标变换下的严格含义，深度学习里的张量只是多维数组。
