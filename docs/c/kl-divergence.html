KL散度

Kullback–Leibler Divergence

也叫：相对熵　relative entropy　KL距离　KL penalty

在交互版中打开（看它长在树上的哪里）

衡量分布q与分布p差多远：用q代替p来编码时，平均多付出的信息量。它总是非负、只在两分布相同时为0，但不对称。

先要会：信息量与熵 交叉熵

生成模型、强化学习和模型压缩都要回答同一个问题：两个概率分布有多接近？模型分布和数据分布差多少？新策略偏离旧策略多远？学生模型模仿老师模仿得怎样？KL散度是最常用的答案。

定义。

KL(p ‖ q) = Σ_x p(x) log (p(x) / q(x))

连续情形把求和换成积分。它等于交叉熵减去信息量与熵：KL(p ‖ q) = H(p, q) − H(p)，即“用错的分布q编码真实数据时，比最优编码多用的平均比特数”。

性质。KL ≥ 0，当且仅当p = q时为0。它不对称：KL(p ‖ q) ≠ KL(q ‖ p)，所以不是严格意义上的距离。两个方向的行为不同：最小化KL(p ‖ q)时，凡是p有概率的地方q都不能接近0，q会摊开去覆盖p的所有峰；最小化KL(q ‖ p)时，q可以忽略p的某些峰，倾向于只抓住其中一个，这与模式坍塌与模式覆盖的讨论直接相关。

一个常用的闭式解。两个一维高斯分布之间，KL(N(μ, σ²) ‖ N(0, 1)) = ½(μ² + σ² − 1 − ln σ²)，VAE的损失里就有这一项。

它出现在哪里。变分自编码器VAE的训练目标包含编码分布与先验之间的KL，见变分推断与ELBO；TRPO约束新旧策略的KL不超过一个阈值，PPO用截断近似这一约束；InstructGPT与RLHF在RLHF中加入与初始模型的KL惩罚，防止模型为了刷奖励而偏离正常语言，见人类反馈强化学习；知识蒸馏让学生模型最小化与教师输出分布的KL。

例子

p = (0.5, 0.5)，q = (0.9, 0.1)。KL(p ‖ q) = 0.5 ln(0.5/0.9) + 0.5 ln(0.5/0.1) ≈ 0.5×(−0.588) + 0.5×1.609 ≈ 0.511奈特。反过来KL(q ‖ p) = 0.9 ln(0.9/0.5) + 0.1 ln(0.1/0.5) ≈ 0.529 − 0.161 ≈ 0.368奈特。两个方向结果不同。高斯的例子：μ = 1、σ = 0.5时，KL(N(1, 0.25) ‖ N(0, 1)) = ½(1 + 0.25 − 1 − ln 0.25) ≈ 0.818。

容易误解的地方

  • 只要存在某个x使p(x) > 0而q(x) = 0，KL(p ‖ q)就是无穷大，所以模型分布不能在数据可能出现的地方给出零概率。
  • KL不满足三角不等式，也不对称；需要对称版本时可以用JS散度。
