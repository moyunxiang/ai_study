算力单位：FLOPs、FLOPS与E级

Compute Units: FLOPs, FLOPS and Exascale

也叫：算力单位　FLOPS units　FLOPS　FLOP/s　FLOPs　浮点运算次数　每秒浮点运算次数　TFLOPS　PFLOPS　EFLOPS　exaFLOPS　E级　exascale　E级超算　PF-day　petaflop/s-day　峰值算力　peak FLOPS　稀疏算力　稠密算力

算力的两种说法要分清：FLOPs（小写s）是运算总量，FLOPS或FLOP/s是每秒运算次数。常见量级前缀T（10¹²）、P（10¹⁵）、E（10¹⁸）；厂商标称的峰值还取决于数值精度和是否按稀疏计算。

先要会：参数量、计算量与显存 浮点精度：FP32、FP16、BF16、INT8

新闻里说“某芯片算力1000 TFLOPS”“训练用了10²⁵ FLOPs”“首台E级超算”，这些数字只有放在同一套单位和口径下才能比较。

总量与速率。

  • FLOPs（floating point operations）：完成一项任务需要的浮点运算总次数，例如训练一个模型的计算量，估算方法见参数量、计算量与显存。GPT-3的训练计算量约为3.14×10²³次。
  • FLOPS或FLOP/s：每秒能完成多少次浮点运算，是硬件的速率。

两者只差一个s，经常被混写，看上下文判断：后面跟着“每秒”或说的是芯片，就是速率。

量级前缀。G = 10⁹，T = 10¹²，P = 10¹⁵，E = 10¹⁸，Z = 10²¹。所以1 PFLOPS = 1000 TFLOPS；“E级”（exascale）指每秒10¹⁸次运算，Frontier：首台E级超算是首台在标准基准上超过这一量级（FP64）的超级计算机。训练计算量也常用“PF-day”表示：以1 PFLOPS连续算一天，约8.64×10¹⁹次运算。

口径差异（比较时最容易出错）。

  • 精度：同一块芯片，FP64、FP32、BF16、FP8、INT8的峰值相差很大，越低精度越高，见浮点精度：FP32、FP16、BF16、INT8。超算排名通常按FP64，AI芯片宣传通常按BF16或FP8。
  • 稠密与稀疏：部分GPU支持结构化稀疏（每4个数里有2个为0），标称的“稀疏算力”是稠密的2倍，但只有满足这种稀疏模式的计算才能用上。
  • 峰值与实际：标称峰值是理论上限，实际训练能用到的比例见MFU：模型FLOPs利用率，受显存带宽限制的计算更是远低于峰值，见显存、内存带宽与“内存墙”。
  • 一次乘加算1次还是2次：多数AI文献把一次乘加（FMA）算作2次运算，个别资料算作1次，数字会差一倍。

怎么用这些数。训练时间约等于总FLOPs / (卡数 × 每卡峰值 × MFU)。例如H100的BF16稠密峰值约989 TFLOPS，这是很多估算的出发点。

例子

估算训练时间：一个模型的训练计算量为10²⁴ FLOPs，用1000张BF16稠密峰值约989 TFLOPS的GPU，MFU取40%。每秒有效算力约1000 × 9.89×10¹⁴ × 0.4 ≈ 3.96×10¹⁷次，训练约需10²⁴ / 3.96×10¹⁷ ≈ 2.5×10⁶秒，约29天。若误用稀疏峰值（约翻倍），会把时间低估成约15天。

容易误解的地方

  • “1 EFLOPS的AI超算”往往是按FP8甚至稀疏计算的，与按FP64计算的E级超算不是一回事。
  • FLOPs是运算次数，不是时间：同样FLOPs的两个模型，访存模式不同，实际运行时间可能差很多。
