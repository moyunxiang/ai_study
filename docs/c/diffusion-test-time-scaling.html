生成模型的推理时扩展

Inference-Time Scaling for Visual Generation

也叫：推理时扩展　测试时扩展　Test-time Scaling　Inference-time Scaling　TTS　噪声搜索　Noise Search　Best-of-N　验证器　Verifier　思考式出图　Thinking Image Generation　先推理再出图　Reasoning before Generation

在生成时多花算力换质量：多试几个噪声并用验证器挑选，或者让模型先“想清楚”再画。

大语言模型的推理时扩展（测试时计算扩展、s1与预算强制）表明，增加推理算力可以换来更好的答案。扩散模型天然能靠加去噪步数多花算力，但几十步后就饱和。

扩散模型推理时扩展把问题改写成搜索：初始噪声决定了结果好坏，于是用CLIP、ImageReward等验证器给候选打分，再用随机搜索、零阶搜索或沿采样路径分叉搜索来找更好的噪声；FLUX等模型在多项基准上随搜索算力持续提升，小模型加搜索可以超过不搜索的大模型。它也揭示了验证器被钻空子的问题：逐样本打分会牺牲多样性。

另一种形态出现在产品里：GPT Image 2思考式出图、Nano Banana Pro等原生多模态模型在出图前先推理、规划甚至检索，再检查和修正自己的输出。两者都在回答同一个问题：生成质量能否随推理算力持续增长。
