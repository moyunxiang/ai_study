Associative Memory

也叫：Hopfield网络　Hopfield Network　现代Hopfield　Modern Hopfield　稠密联想记忆　Dense Associative Memory　内容寻址记忆　Content-Addressable Memory　神经记忆　Neural Memory　记忆即注意力　能量记忆

在交互版中打开（看它长在树上的哪里）

按内容而不是按地址取回记忆：给出部分或带噪的线索，系统补全出最接近的存储模式；从Hopfield网络一直延续到注意力和测试时记忆。

Hopfield网络网络把记忆存成能量函数的极小点，从带噪输入出发沿能量下降就能回忆起完整模式，玻尔兹曼机给它加上随机性和隐单元。经典Hopfield网络容量很小，只能存下与神经元数成正比的模式。

现代Hopfield网络把状态推广为连续，容量提升到指数级，并证明其更新规则就是Transformer的注意力。另一条线把“记忆”放进权重：快速权重用快速变化的权重保存短期信息，线性注意力即快速权重指出线性注意力正是在不断写入一个联想记忆矩阵；神经图灵机则用可读写的外部记忆。最新的Titans测试时记忆把一个在测试时用梯度更新的网络当作长期联想记忆。这个视角让注意力、线性RNN和测试时训练可以放在同一框架下比较。
