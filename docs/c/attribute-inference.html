属性推断与机器学习隐私攻击

Attribute Inference and Privacy Attacks on ML

也叫：属性推断攻击　属性推断　attribute inference　attribute inference attack　敏感属性推断　sensitive attribute inference　隐私推断　inference attack　推断攻击　隐私攻击　privacy attacks　机器学习隐私　ML privacy　个人信息推断　personal attribute inference　数据最小化　data minimization

隐私攻击的一种：攻击者知道某人的部分信息，借助用其数据训练的模型或模型输出，推断出他未公开的敏感属性，如病史、收入。它与成员推断、模型反演、训练数据提取并列。

先要会：监督学习 条件概率与贝叶斯公式

模型从训练数据中学到的不只是一般规律，还会带有关于具体个人的信息。隐私攻击研究的问题是：只能访问模型（或它的输出）的人，能从中挖出多少关于训练数据的信息？主要有四类：

  • 成员推断：判断某条记录是否在训练集中（成员推断攻击、LiRA成员推断）。仅仅“在某家医院的训练数据里”本身就可能泄露病情。
  • 属性推断：已知某人的部分特征，推断其敏感属性。
  • 模型反演：从模型输出反推出代表某一类别的典型输入，如重建出人脸识别模型中某个人的大致面貌（模型反演攻击）。
  • 训练数据提取：让生成模型逐字吐出训练集中的原文或原图（从LLM提取训练数据、从扩散模型提取训练图像）。

属性推断怎么做。经典设定：一个用患者数据训练的剂量推荐模型，输入包括人口统计信息、若干临床指标和某个基因型。攻击者知道某位患者的其他输入和模型给出的推荐剂量，于是枚举基因型的各种可能取值，看哪一个让模型的输出最接近观察到的剂量，就把它当作推断结果。另一种设定更宽泛：模型的输出或中间表示本身就能预测训练时并未作为标签的敏感属性，例如推荐系统的用户向量可以预测用户的性别。

大语言模型时代的新形式。大模型不需要训练数据里有这个人，也能从他公开写下的文字中推断出未说出口的信息：从一段论坛发帖里的用词、提到的地名和生活细节，推测作者的所在城市、年龄段、收入水平。这类“推断式隐私泄露”比逐字记忆更难防，因为它利用的是模型的一般推理能力。

区分两件事。如果敏感属性与公开特征在整个人群中本来就强相关，那么即使模型从没见过这个人，也能推断出来，这更像是统计推断而不是“泄露了训练数据”。严格的隐私定义要比较“用这个人的数据训练”与“不用”时攻击成功率的差别，这正是差分隐私的思路。

防御。差分隐私训练（如DP-SGD）、限制输出精度（只给类别不给概率）、对表示做对抗去偏让它预测不出敏感属性（与领域自适应与领域泛化中的对抗特征对齐同理），以及数据最小化：不收集用不到的敏感信息。另见群体公平：人口均等、差别影响与均等几率中关于“去掉受保护属性也不能阻止代理变量泄露它”的讨论。

例子

一个房贷审批模型的输入包括年龄、收入、邮编、婚姻状况和“是否有慢性病”。攻击者知道邻居的年龄、收入、邮编、婚姻状况，也知道他的审批结果和模型给出的分数0.62。枚举“慢性病 = 是”时模型输出0.61，“否”时输出0.83，于是推断邻居很可能有慢性病。（情境为示意）

容易误解的地方

  • 属性推断的成功率要与“只用人群统计规律猜测”的基线比较，否则会高估模型本身造成的泄露。
  • 从输入中删除敏感属性并不能阻止推断，相关特征（代理变量）往往足以重建它。
