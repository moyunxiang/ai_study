指数移动平均

Exponential Moving Average

也叫：指数移动平均　指数滑动平均　指数加权平均　exponential moving average　EMA　exponentially weighted moving average　EWMA　移动平均　滑动平均　moving average　running average　running mean　偏差修正　bias correction　软更新　soft update　目标网络软更新　EMA权重　EMA model

在交互版中打开（看它长在树上的哪里）

只用一个变量维护的加权平均：每来一个新值，旧平均乘β再加(1−β)倍新值，越近的值权重越大。动量、Adam、BatchNorm统计量和目标网络都靠它。

先要会：期望与方差

训练时经常需要一个“最近一段时间的平均值”：平均梯度方向、平均的梯度大小、激活值的平均统计量、平滑后的损失曲线。存下最近1000个值再求平均太浪费，指数移动平均（EMA）只用一个变量就能做到。

定义。

m_t = β·m_{t−1} + (1 − β)·x_t

展开后，m_t = (1 − β)·Σ_k β^k·x_{t−k}：k步之前的值权重按β^k指数衰减。β越接近1，平均得越久、越平滑，但对变化的反应越慢。粗略地说，它相当于对最近约1/(1 − β)个值求平均：β = 0.9约10步，β = 0.999约1000步。

偏差修正。m₀通常初始化为0，前几步的平均会被拉向0。Adam用m̂_t = m_t / (1 − β^t)修正：第1步时除以1 − β，正好还原出x₁本身。

它出现在哪里。

  • 动量：动量本质上是对梯度做EMA，沿一致的方向积累速度，抵消来回震荡的分量。
  • 自适应优化器：RMSProp对梯度平方做EMA，Adam对梯度和梯度平方各做一个（默认β₁ = 0.9、β₂ = 0.999），见自适应学习率优化器。
  • BatchNorm的推理统计量：训练时用当前批次的均值方差，同时用EMA维护一份全局估计，推理时使用它，见归一化层。
  • 目标网络：DDPG、TD3等用“软更新”θ_target ← τθ + (1 − τ)θ_target让目标网络缓慢跟随，稳定时序差分与自举的学习目标；MoCo、BYOL和Mean Teacher用参数的EMA构造“教师”网络。
  • 权重EMA：对模型参数本身做EMA，评估时用平均后的参数，通常比最后一步的参数更好、更稳；扩散模型训练（如EDM设计空间）几乎都这样做，见权重平均和Polyak平均与EMA。
  • 画训练曲线：TensorBoard的平滑滑块就是对损失做EMA。

例子

β = 0.9，m₀ = 0，依次观测到x = 10、10、10。m₁ = 1，m₂ = 0.9 + 1 = 1.9，m₃ = 1.71 + 1 = 2.71，离真实平均10还很远。偏差修正后：m̂₁ = 1/0.1 = 10，m̂₂ = 1.9/0.19 = 10，m̂₃ = 2.71/0.271 = 10，都还原到了10。

容易误解的地方

  • EMA有滞后：β = 0.999时，信号突变后要上千步平均值才跟上；训练初期或学习率很大时，用太大的β评估会得到过时的模型。
  • “移动平均”在不同框架里的系数约定不同：PyTorch的BatchNorm参数momentum = 0.1表示新值权重为0.1，即上式中的β = 0.9。
