多维缩放MDS

Multidimensional Scaling

也叫：多维缩放　多维标度　多维尺度分析　multidimensional scaling　MDS　经典MDS　classical MDS　Torgerson MDS　度量MDS　metric MDS　非度量MDS　non-metric MDS　Isomap　测地距离　geodesic distance　距离矩阵　distance matrix　双中心化　double centering

只知道样本两两之间的距离，要找一组低维坐标使坐标间的距离尽量还原原距离。经典MDS与PCA等价；Isomap是在“沿流形的测地距离”上做MDS。

先要会：特征分解与奇异值分解 降维与PCA

有时我们拿不到样本的坐标，只有它们之间的距离：城市之间的驾车里程、人们对两种颜色“有多像”的打分、两段DNA的编辑距离。能不能画一张二维地图，让图上的距离尽量接近这些数？这就是多维缩放（MDS）。

经典MDS。已知n×n的距离矩阵D，目标是找n个d维点y_i使‖y_i − y_j‖ ≈ D_ij。步骤：

1. 对距离平方做双中心化：B = −½·J·D^(2)·J，J是中心化矩阵，D^(2)是逐元素平方的距离矩阵。如果距离来自欧氏空间，B正好是中心化后坐标的内积矩阵YYᵀ。 2. 对B做特征分解（见特征分解与奇异值分解），取最大的d个特征值λ_k和对应特征向量v_k。 3. 坐标为Y = [√λ₁·v₁, …, √λ_d·v_d]。

当D就是原始数据的欧氏距离时，经典MDS得到的坐标与主成分分析PCA的投影完全相同（只差旋转），见降维与PCA。B有明显为负的特征值，说明这些距离无法嵌入欧氏空间。

度量与非度量MDS。更一般的做法是直接最小化“应力”Σ(‖y_i − y_j‖ − D_ij)²，用迭代优化求解，可以给不同的距离对加权。非度量MDS只要求低维距离的排序与原距离一致，适合心理学评分这类只有相对大小可信的数据。

和流形学习的关系。流形学习Isomap/LLE中的Isomap先在近邻图上用最短路径估计沿流形的“测地距离”（见图、树与搜索），再对这个距离矩阵做经典MDS，于是能把瑞士卷这类卷曲的流形展平。t-SNE和UMAP降维同样是“让低维空间保持原空间的邻近关系”，但它们只关心局部邻居，不试图保持远距离，所以更适合可视化聚类结构，不适合读出全局距离。

它出现在哪里。可视化词向量、模型表示、蛋白质或物种之间的相似度；把只有距离的数据（如两两比较的结果）放进一个坐标系里，以便用常规方法继续分析。

例子

三座城市两两距离：A–B = 3，B–C = 4，A–C = 5（单位百公里），是一个直角三角形。经典MDS给出的二维坐标（以重心为原点）例如A = (2, −1.33)、B = (−1, −1.33)、C = (−1, 2.67)，整体可以任意旋转或翻转。三边长度恰好还原为3、4、5；B的第三个特征值为0，说明这三点完全落在一个平面内。

容易误解的地方

  • MDS的结果只在旋转、翻转、平移意义下唯一，不同运行给出的坐标方向不同，不能直接比较坐标值。
  • 经典MDS需要对n×n矩阵做特征分解，n很大时代价高，常用地标点近似（与核近似：随机特征与Nyström方法中的Nyström方法同理）。
