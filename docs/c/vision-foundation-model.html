视觉基础模型

Vision Foundation Model

也叫：VFM　视觉大模型　通用视觉骨干　视觉编码器　vision encoder　visual foundation model　通用视觉特征　冻结特征　frozen features　视觉基座模型

在交互版中打开（看它长在树上的哪里）

在海量图像上预训练一个通用模型，不再为每个任务从头训练，冻结特征或轻量微调就能用于分类、分割、深度、三维等多种任务。

过去每个视觉任务各训一个网络，最多共享一个ImageNet预训练骨干（BiT大规模迁移）。视觉基础模型的思路是把预训练做到足够大、足够通用，使下游只需加一个小头甚至不训练。

路线大致有三条：一是自监督特征，如DINOv2、DINOv3，不用任何标注，特征冻结后直接做分割、深度都很强；二是任务型基础模型，在单一任务上用海量数据训练出零样本能力，如可提示分割Segment Anything、单目深度Depth Anything、三维几何VGGT、人体视觉Sapiens人体基座；三是图文对齐的编码器，如Perception Encoder、SigLIP 2（这一条更多归多模态）。AM-RADIO聚合蒸馏则把几个基础模型蒸馏进一个骨干。

当前的争论在于：语言监督是否必要（Web-SSL无语言视觉扩展认为纯视觉自监督放大后可追平CLIP类模型），以及“一个骨干通吃”与“各任务专用基础模型”哪个更划算。
