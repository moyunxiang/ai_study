检测Transformer（DETR家族）

Detection Transformer

也叫：DETR系列　DETR家族　query-based detection　基于查询的检测　集合预测　set prediction　匈牙利匹配　Hungarian matching　端到端检测　end-to-end detection　DINO检测

在交互版中打开（看它长在树上的哪里）

用一组可学习的查询向量，经Transformer解码器直接输出一组物体框，用一对一匹配训练，不再需要锚框和NMS。

传统检测器先铺大量锚框或候选，再用NMS去掉重复框，有很多手工设计。DETR把检测看作集合预测：固定数量的查询经Transformer解码器各输出一个框或“无物体”，训练时用匈牙利算法把预测与真值一对一匹配。它简洁但收敛极慢、小物体差。

Deformable DETR用只关注少量采样点的可变形注意力解决收敛和多尺度问题；DINO（检测）加入去噪训练与查询初始化，把精度推到当时最好；RT-DETR实时DETR、D-FINE、RF-DETR把这一路线做成实时；Grounding DINO把它扩展到开放词表。分割方向的MaskFormer、Mask2Former通用分割也采用同样的查询式设计。

开放问题：一对一匹配监督稀疏，训练仍比YOLO类方法慢；在边缘设备上Transformer算子的部署效率也不如卷积。
