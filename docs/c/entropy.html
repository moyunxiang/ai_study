信息量与熵

Information and Entropy

也叫：香农熵　Shannon entropy　信息熵　自信息　self-information　不确定性

在交互版中打开（看它长在树上的哪里）

一个事件的信息量是−log p：越意外，信息越多。熵是信息量的期望，衡量一个分布的平均不确定性，也是无损编码平均所需的最少比特数。

先要会：随机变量与概率分布 期望与方差

“明天太阳从东边升起”几乎不带信息，“明天会下陨石雨”信息量巨大。香农把这种直觉量化了：越不可能的事发生，带来的信息越多。由此得到的熵，后来成为衡量不确定性、设计损失函数和评价语言模型的基本工具。

信息量。概率为p的事件发生，信息量定义为

I = −log p

以2为底时单位是比特（bit），以e为底时单位是奈特（nat）。p = 1时信息量为0，p越小信息量越大；两个独立事件同时发生，信息量相加。

熵。随机变量X的熵是信息量的期望与方差意义下的期望：

H(X) = −Σ_x p(x) log p(x)

分布越集中，熵越小；均匀分布的熵最大，k个取值时为log k。香农的信源编码定理说：对服从分布p的符号做无损压缩，平均每个符号至少需要H比特。

条件熵。H(X | Y)表示知道Y以后X还剩多少不确定性，它不会超过H(X)。两者之差就是互信息。

它出现在哪里。香农：语言的统计模型用熵来度量英语的可预测程度；最大熵模型在满足已知统计约束的所有分布中选熵最大的一个，即不做多余的假设；最大熵逆强化学习和强化学习中的熵正则用熵鼓励策略保持随机、多做探索；信息瓶颈用信息量来刻画“好的表示”。比较两个分布时，熵推广为交叉熵和KL散度，语言模型的困惑度就是交叉熵的指数。

例子

公平硬币：H = −(0.5 log₂0.5 + 0.5 log₂0.5) = 1比特。正面概率0.9的硬币：H = −(0.9 log₂0.9 + 0.1 log₂0.1) ≈ 0.469比特，结果更好猜，所以熵更低。8个等可能的结果：H = log₂8 = 3比特，恰好需要3位二进制编码。一个在5万个词上均匀猜测的语言模型，熵约为log₂50000 ≈ 15.6比特。

容易误解的地方

  • 熵只取决于概率，与取值本身无关：把“正面/反面”换成“1/100”，熵不变。
  • 连续分布的“微分熵”可以是负数，也会随单位变化，不能与离散熵直接类比。
