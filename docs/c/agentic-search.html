智能体式检索

Agentic Search and Agentic RAG

也叫：Agentic RAG　智能体RAG　agentic search　智能体搜索　主动检索　active retrieval　迭代检索　iterative retrieval　多跳检索　search agent　搜索智能体　deep search　深度搜索

在交互版中打开（看它长在树上的哪里）

不再只在回答前检索一次，而是让模型自己决定何时搜、搜什么、看完结果再接着搜，直到能回答为止。

经典检索增强生成RAG在生成前检索一次固定数量的文档。FLARE主动检索在生成过程中遇到不确定时主动检索，Self-RAG训练模型自己判断是否需要检索并评价结果。推理模型出现后，Search-o1把搜索嵌入长思维链，Search-R1用强化学习训练模型在推理中交替调用搜索；Deep Research类产品和通义DeepResearch让模型连续搜索、阅读数十上百个网页后写出带出处的报告，评测见BrowseComp等基准。

主要难题是检索结果的噪声和错误会被长链放大、搜索成本高，以及如何判断「已经查够了」。
