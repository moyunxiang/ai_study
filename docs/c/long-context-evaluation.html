长上下文评测

Long-Context Evaluation

也叫：长上下文评测　长文本评测　long-context benchmark　NIAH　大海捞针　needle in a haystack　MRCR　多针检索　百万上下文测试　上下文腐烂　context rot　有效上下文长度　effective context length

在交互版中打开（看它长在树上的哪里）

测模型在很长的输入里还能不能找到、记住并综合信息，而不只是宣称的上下文窗口有多大。

迷失在中间发现关键信息放在长输入中间时模型最容易漏掉。大海捞针测试把一句“针”藏进长文让模型找回，简单直观，很快被前沿模型刷到接近满分。RULER长上下文加入多针、变量追踪、聚合等合成任务，提出“有效上下文长度”往往远小于标称长度。Michelangelo与MRCR要求在长对话里分清多个相似请求，OpenAI开源的8针MRCR成为模型卡常报指标。上下文腐烂Context Rot则用控制变量实验表明，即使任务极简，输入越长、干扰越多，表现越差。

现在的分歧是：合成任务好评分但不像真实使用；真实任务（读整个代码库、长期对话记忆）更有意义却难以只隔离出长度的影响。这也是“上下文工程”在智能体开发中受重视的原因。
