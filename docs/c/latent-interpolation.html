潜空间插值与球面插值

Latent Interpolation and Slerp

也叫：潜空间插值　隐空间插值　latent interpolation　球面插值　slerp　spherical linear interpolation　线性插值　lerp　隐空间漫步　latent walk　latent space walk　噪声插值

在两个隐向量之间取一串中间点，分别生成图像，得到一段平滑的“渐变”。对高斯隐变量，直线插值的中点会偏离分布，常改用沿球面走的球面插值（slerp）。

先要会：潜空间 高斯分布 范数与距离

生成模型的一个经典展示是：取两张生成图对应的隐向量z₀和z₁，在它们之间取若干中间点，逐个生成，看到一张脸平滑地变成另一张脸。这既能检验潜空间是否连续、有语义（而不是记住了训练图片），也是视频过渡、风格混合等应用的基础。DCGAN就用隐空间漫步来论证模型没有简单地记忆训练集。

线性插值。z(t) = (1 − t)·z₀ + t·z₁，t从0到1。

问题出在高维高斯上。若z的各维服从独立标准正态，维数d很大时，‖z‖几乎总是接近√d（能量集中在一个薄球壳上，见维度灾难）。两个独立样本近似正交，线性插值的中点(z₀ + z₁)/2的长度约为√d/√2，比典型样本短了约30%，落在一个几乎从未出现过的区域，生成结果常常变得模糊或发灰。

球面插值（slerp）。沿着两点之间的大圆弧走：

z(t) = [sin((1 − t)·θ) / sin θ]·z₀ + [sin(t·θ) / sin θ]·z₁，其中cos θ = z₀·z₁ / (‖z₀‖·‖z₁‖)

当两向量长度相同时，插值路径上每点的长度都不变，始终留在“典型样本”所在的球壳上。

在扩散模型中。确定性采样器（如DDIM）把初始噪声一一映射到图像，因此可以在两张图的初始噪声之间做slerp，得到平滑过渡；随机采样器则不行，因为每步都加入新噪声。StyleGAN常在映射后的中间空间W里插值，那里更接近线性、语义也更平滑。同样的球面插值也被用于合并两个模型的权重，见模型合并。

例子

d=512维的标准正态隐向量，典型长度约√512 ≈ 22.6。两个独立样本几乎正交，线性插值的中点长度约22.6/√2 ≈ 16.0。用slerp，θ≈90°，t=0.5时两项系数都是sin45°/sin90° ≈ 0.707，中点长度≈√(0.707²×512 + 0.707²×512) ≈ 22.6，仍在球壳上。

容易误解的地方

  • 插值看起来平滑不等于语义连续，有些路径中间会突然跳到不相关的图像，说明那片区域没有学好。
  • 对不是高斯分布的隐空间（如StyleGAN的W空间、VQ的离散码），slerp的理由不再成立，线性插值可能更合适。
