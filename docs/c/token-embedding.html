词嵌入层

Token Embedding Layer

也叫：token embedding　嵌入层　词嵌入层　embedding layer　embedding table　嵌入矩阵　词嵌入矩阵　embedding matrix　nn.Embedding　查表　lookup table　输入嵌入　input embedding　wte　词嵌入维度

在交互版中打开（看它长在树上的哪里）

神经语言模型的第一层：一张V×d的可学习表格，第i行就是编号为i的token的向量。输入一串token编号，按编号查表，得到一串d维向量，交给后面的网络。

先要会：嵌入向量 独热编码与词表

分词器输出的是整数编号（见分词与token）。编号本身没有大小意义——编号100和101的token不一定相近——所以不能直接把整数喂给网络。最简单的做法是给每个token分配一个可学习的向量，这就是词嵌入层（embedding layer）。

定义。嵌入矩阵E的形状是V×d（V是词表大小的取舍，d是隐藏维度，见模型尺寸超参数：维度、层数与头数）。token编号为i时：

x = E[i]（取第i行）

这在数学上等价于用独热编码与词表向量乘以E，但实现上就是一次查表，不做矩阵乘法，非常快。反向传播时，只有这一步用到的那些行会得到梯度。

之后发生什么。查表得到的向量只表示“这是哪个token”，不包含位置和上下文。Transformer会再加上位置信息（见位置编码，旋转位置编码则是在注意力内部加），然后经过多层注意力和前馈网络，逐渐变成依赖上下文的表示（见上下文词向量）。所以“嵌入层的向量”和“模型中间层的向量”是不同的东西：前者是静态的，“苹果”永远是同一个向量；后者会根据上下文区分水果和公司。

与word2vec的关系。word2vec和GloVe训练出的也是一张V×d的表，只不过是单独训练、再拿来用的；早期神经模型常用它们初始化嵌入层。神经概率语言模型最早在神经语言模型里把嵌入层和预测网络一起训练。今天的大模型都从随机初始化开始，与整个网络端到端地学（见端到端学习）。

与输出层共享。输出层要把隐状态映射回V个token的分数（见语言模型头与输出层），它的权重形状正好是E的转置，可以与E共享（输入输出嵌入共享）。

不只是文本。图像块、音频帧、动作也可以先离散成token再查嵌入表，或者用一个线性层直接投影成d维向量，接入同一个Transformer（见图像块与视觉token）。

例子

词表V = 5：{0: <pad>, 1: 我, 2: 爱, 3: 猫, 4: 狗}，d = 3。嵌入矩阵E（随机初始化后训练得到）：

E[1] = [0.2, −0.1, 0.5]，E[2] = [0.7, 0.3, −0.2]，E[3] = [−0.4, 0.8, 0.1]

输入“我 爱 猫”→ 编号 [1, 2, 3] → 查表得到3×3的矩阵 [[0.2, −0.1, 0.5], [0.7, 0.3, −0.2], [−0.4, 0.8, 0.1]]，这就是第一层Transformer的输入（再加上位置信息）。

规模：V = 50,000、d = 768时，E有3840万个参数。

容易误解的地方

  • 嵌入层参数量大但计算量几乎为零，所以“参数量”和“计算量”在这一层严重不对等（见参数量、计算量与显存）。
  • 训练数据里很少出现的token，嵌入几乎停留在初始值附近，可能引发异常行为（见异常token）。
