策略与价值函数

Policy and Value Functions

也叫：value function　Q函数　Q-function　状态价值　动作价值

在交互版中打开（看它长在树上的哪里）

策略是“在什么状态下做什么动作”的规则；价值函数估计按某个策略走下去平均能拿到多少回报。强化学习的算法基本都是在学其中一个或两个。

先要会：马尔可夫决策过程 奖励、回报与折扣 期望与方差

有了马尔可夫决策过程的描述，还需要两样东西才能谈“学习”：一是智能体的行为本身怎么表示，二是怎么评价一个状态或一个动作好不好。

策略π。确定性策略是一个函数a = π(s)；随机策略是一个分布π(a|s)，给出每个动作的概率。用神经网络表示时，离散动作通常输出Softmax与logits概率，连续动作通常输出一个高斯分布的均值和方差。语言模型本身就是一个策略：状态是已有文本，动作是下一个token。

价值函数。从状态s出发、一直按π行动，期望能拿到的奖励、回报与折扣：

V^π(s) = E_π[G_t | s_t = s]

动作价值函数（Q函数）多固定了第一步的动作：先在s做a，之后再按π：

Q^π(s, a) = E_π[G_t | s_t = s, a_t = a]

两者的关系是V^π(s) = Σ_a π(a|s)·Q^π(s, a)：状态的价值是各动作价值按策略概率的加权平均。

为什么Q函数特别有用。知道了Q，改进策略很简单：在每个状态选Q最大的动作，π'(s) = argmax_a Q^π(s, a)。可以证明这样得到的新策略不比原来差（策略改进定理）。反复“评估→改进”就是策略迭代；最优策略对应的价值叫V*、Q*，满足Bellman方程。

三条路线。基于价值的方法只学Q，策略靠argmax得到，如Q-learning、DQN；基于策略的方法直接优化π，见策略梯度；两者都学的叫Actor-Critic与优势函数，如PPO。AlphaGo同时训练了策略网络（下一步走哪）和价值网络（这个局面胜率多少），再交给搜索使用。

例子

某状态s下有两个动作，已知Q^π(s, 左)=2，Q^π(s, 右)=6。当前策略π(左|s)=0.3，π(右|s)=0.7，则V^π(s) = 0.3×2 + 0.7×6 = 4.8。

策略改进：在s改为总是选“右”。新策略在s这一步的价值至少是6，比原来的4.8高。这一步看似显然，但它的意义在于：只要能评估Q，就能不断找到更好的策略。

容易误解的地方

  • 价值总是相对于某个策略的：同一个状态，在高手手里和新手手里价值不同。没写上标π的V*指最优策略下的价值。
  • 价值函数不是奖励函数：奖励是环境给的单步信号，价值是对未来累积奖励的预测，需要学出来。
  • 选Q最大的动作只在Q估计准确时有效；估计不准时贪心选择会被高估的动作吸引。
