视觉自蒸馏自监督

Self-Distillation for Visual SSL

也叫：DINO式自监督　DINO系列　教师-学生自监督　teacher-student SSL　EMA教师　动量教师　momentum teacher　联合嵌入　joint-embedding　无负样本自监督　non-contrastive SSL　视觉自监督　visual SSL

在交互版中打开（看它长在树上的哪里）

让同一网络的“学生”去匹配它自己缓慢更新的“老师”对另一视角图像的输出，不用标签、也不用负样本就能学到好特征。

对比学习（对比学习，如SimCLR、MoCo）要把不同图片推开，依赖大量负样本。BYOL发现只要有一个按指数滑动平均更新的老师网络，学生去预测老师对同一图片另一增强视图的输出，就能学到有用特征而不坍缩；SimSiam进一步说明连滑动平均都可省，关键在停止梯度。

DINO把这一思路用到ViT上，用老师输出的软分布做知识蒸馏，并发现注意力图自动对准物体轮廓；iBOT加入掩码token预测；DINOv2和DINOv3把数据整理和规模做大，成为当前最强的通用自监督视觉特征。Web-SSL无语言视觉扩展表明这一路线放大后可在多模态任务上追平语言监督模型。

与之并列的另一路线是掩码重建（掩码自编码器MAE），两者常被结合使用。争论点：自蒸馏训练稳定性依赖大量技巧，LeJEPA等工作试图给出有理论依据的替代。
