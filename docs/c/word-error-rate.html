词错误率

Word Error Rate

也叫：WER　字错误率　CER　character error rate　编辑距离　语音识别错误率

在交互版中打开（看它长在树上的哪里）

语音识别的标准指标：把识别结果改成正确文本最少需要多少次替换、删除、插入，再除以正确文本的词数。

先要会：动态规划

语音识别输出的是一串词，长度未必与正确转写相同：可能漏了一个词、多出一个词，或者把一个词听成了另一个。不能简单逐位置比较，因为一处漏词会让后面所有位置都错开。需要先找到两串词之间最好的对齐，再数错误。

词错误率（WER）就是用编辑距离（Levenshtein距离）做对齐：在所有把识别结果变成参考文本的编辑方式中，取操作次数最少的一种，分别数出替换S、删除D（参考里有而识别结果漏了）、插入I（识别结果多出来的），

WER = (S + D + I) / N

N是参考文本的词数。最少编辑次数用动态规划求：设d[i][j]为参考前i个词与识别结果前j个词之间的距离，d[i][j] = min(d[i−1][j] + 1, d[i][j−1] + 1, d[i−1][j−1] + [两词不同])，复杂度为两串长度之积。

中文、日文没有天然的词边界，常改用字错误率（CER），计算方法相同，只是以字为单位。

它出现在哪里：WER是语音识别几十年来的统一尺子。Switchboard电话语料电话对话语料上的WER从90年代的几十个百分点，降到2016–2017年微软、IBM报告的约5%–6%，与专业转写员相当，这一段进步主要来自深度学习声学模型（Deep Speech 2等）。LibriSpeech有test-clean和test-other两个测试集，分别对应较干净和较难的录音。Whisper则强调在多个数据集上不经微调的平均WER，Open ASR Leaderboard汇总了各开源模型的WER与速度。机器翻译里类似的思路叫TER。

例子

参考：turn on the kitchen light（N = 5） 识别：turn on a kitchen light please

最优对齐：turn = turn，on = on，the → a（替换1），kitchen = kitchen，light = light，多出please（插入1）。S = 1，D = 0，I = 1，WER = 2/5 = 40%。

如果参考只有2个词“hello world”，识别结果却是5个毫不相干的词，最少需要2次替换加3次插入，WER = 5/2 = 250%。WER可以超过100%。

容易误解的地方

  • WER对所有词一视同仁，把“不”漏掉和把“的”漏掉同样扣一分，但前者可能让意思完全相反。
  • 报告WER前通常要做文本规范化（大小写、标点、数字写法如“twenty”与“20”），规范化方式不同，同一模型的WER能差好几个百分点。
  • 不同测试集的WER不可直接比较：朗读录音和嘈杂的电话对话难度差别很大。
