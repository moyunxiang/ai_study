经典教学环境：网格世界、悬崖行走、倒立摆与山地车

教材和入门教程里反复出现的几个小环境：网格世界、悬崖行走、冻湖、21点、倒立摆、山地车等。它们状态少、跑得快，专门用来展示某个算法性质或常见陷阱，是学习和调试RL代码的第一站。

先要会：马尔可夫决策过程 时序差分与自举

在Atari或机器人上跑一次实验要几小时到几天，出了问题也很难判断是算法、超参数还是代码的错。教材和课程因此大量使用一组极小的环境：几秒钟就能跑完，最优解往往能手算，可以清楚地看到算法在做什么。它们大多收录在《Reinforcement Learning: An Introduction》的例题和OpenAI Gym/Gymnasium的“经典控制”“文字游戏”类别里。

离散的表格型环境。

  • 网格世界（Gridworld）：智能体在格子里上下左右移动，到达目标得奖励，常用来演示策略评估、策略迭代与价值迭代、价值函数的样子和奖励设计与奖励投机的影响。
  • 悬崖行走（Cliff Walking）：沿着悬崖边走最短，但掉下去罚−100。用ε-贪心探索时，Q-learning学到贴着悬崖走的最优路线，但训练中常掉下去；SARSA学到远离悬崖的安全路线，训练中的回报反而更高。这是展示on-policy与off-policy区别的经典例子。
  • 冻湖（FrozenLake）：在结冰的湖面上走向终点，冰面会打滑（转移随机），掉进冰窟回合结束，适合演示随机转移下的规划。
  • 21点（Blackjack）：教材用它演示强化学习中的蒙特卡洛方法，因为环境模型（发牌概率）难以显式写出，但很容易采样。

连续状态的经典控制。

  • 倒立摆（CartPole）：左右推小车让杆子保持竖直，杆倒或车出界即结束。它源自早期的倒立摆控制研究，见BOXES倒立摆控制和Actor-Critic（ASE/ACE），几乎是所有深度RL代码的冒烟测试。
  • 山地车（Mountain Car）：动力不足的小车要先往反方向冲坡借力才能爬上山顶，奖励每步−1。它体现了稀疏奖励与稠密奖励和需要“先退后进”的探索难题，教材用它演示强化学习中的函数逼近中的瓦片编码。
  • 摆锤（Pendulum）、双连杆（Acrobot）：简单的连续或离散力矩控制，常用来测试连续动作算法。

更进一步的小环境。Minigrid与Miniworld提供需要记忆和多步推理的网格任务，MinAtar迷你Atari把Atari缩小成10×10的版本，bsuite行为诊断套件用一组小环境分别诊断探索、记忆、信用分配等能力。

例子

悬崖行走：4×12的网格，起点和终点在底边两端，中间10格是悬崖。每步奖励−1，掉崖−100并回到起点。最短路线沿着悬崖边走，13步，回报−13；沿网格最上面一行绕行的安全路线17步，回报−17。用ε=0.1的ε-贪心训练时，沿悬崖走的那条路有不小的概率因随机一步掉下去，所以“按行为策略算”的平均回报反而是安全路线更高。

容易误解的地方

  • 在这些小环境上表现好的算法，不代表在大规模问题上也好；它们适合检验正确性和直观理解，不适合作为论文的主要证据。
  • 不同库里同名环境的细节（时间上限、奖励设计、是否打滑）可能不同，复现教材结果时要核对设置。
