文本退化与重复循环

Neural Text Degeneration

也叫：text degeneration　neural text degeneration　神经文本退化　文本退化　重复生成　重复循环　repetition loop　复读机　生成重复　degenerate repetition　车轱辘话　生成平淡　bland generation

在交互版中打开（看它长在树上的哪里）

语言模型用最大化概率的方式解码时，生成的文本变得平淡、空洞、陷入重复循环的现象。它说明“概率最高的文本”并不是“最像人写的文本”。

先要会：解码：贪心、束搜索、温度与top-p 自回归生成

直觉上，模型认为概率最高的那句话应该是最好的。但在开放式生成（写故事、续写、对话）中，用贪心解码或束搜索追求高概率，结果常常是：

  • 重复循环：同一句话、同一个短语不断出现，“我觉得这个很好。我觉得这个很好。我觉得……”
  • 平淡空洞：总选最安全、最常见的词，内容缺乏信息量，对话里反复出现“我不知道”。

核采样Top-p（2019）系统地研究了这一现象，称之为神经文本退化（neural text degeneration）。

为什么会这样。

  • 人写的文本并不总是高概率。论文比较了人类文本和束搜索输出中每个token在模型下的概率：束搜索的输出几乎每一步都是高概率词，而人类文本里经常出现概率不高的词——人说话要传递新信息，必然有“意料之外”的部分。所以最大化概率本身就偏离了人类文本的分布。
  • 重复会自我强化。一句话出现过一次后，模型从上下文中“学到”这句话很可能再出现，再出现的概率就更高，形成正反馈。论文画出了这种循环中某个短语的概率随重复次数上升的曲线。
  • 训练与生成的差异。训练时模型总是看到真实前文（见Teacher forcing与曝光偏差），生成时却要接着自己写出的、可能已经出错的前文。

怎么缓解。

  • 解码端：改用截断采样——top-k、top-p（核采样）、局部典型采样、Min-p采样，既保留随机性又排除长尾里的离谱词（见解码：贪心、束搜索、温度与top-p）；对已出现内容加惩罚（见重复惩罚、频率惩罚与存在惩罚）；Mirostat困惑度控制采样动态调节采样，让输出的困惑度保持在目标值附近。
  • 训练端：在训练目标里直接惩罚重复（unlikelihood training）；经过指令微调和RLHF的对话模型，重复问题明显减轻。

退化不只出现在文本里：推理模型的长思维链有时也会陷入反复验证同一步的循环，这与上面的机制相似。

例子

提示：“今天天气很好，”。某个小模型的贪心解码输出：

“今天天气很好，我们去公园散步。我们去公园散步，我们去公园散步，我们去公园散步……”

每重复一次，“我们去公园散步”在下一步的概率就更高，比如从第一次出现后的0.3升到0.6、0.8、0.95。改用top-p = 0.9、温度0.8采样，输出变成“今天天气很好，适合带孩子去郊外放风筝，回来的路上还买了一束花。”——每个词的概率不是最高，但整段话更自然。

（概率数值为示意。）

容易误解的地方

  • 退化是“解码目标”的问题，不完全是模型的问题：同一个模型换个解码方法就能好很多。
  • 有标准答案的任务（翻译、语音识别）中，束搜索追求高概率仍然有效，退化主要出现在开放式生成里。
