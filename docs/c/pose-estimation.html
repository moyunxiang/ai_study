姿态估计

Pose Estimation

也叫：姿态估计　pose estimation　人体姿态估计　human pose estimation　关键点检测　keypoint detection　热图　heatmap　自顶向下　top-down　自底向上　bottom-up　6D位姿估计　6D pose estimation　物体位姿估计　PnP　OKS　3D人体姿态

在交互版中打开（看它长在树上的哪里）

从图像中估计“姿态”：人体姿态估计找出关节点（肩、肘、膝……）的位置，物体6D位姿估计求物体相对相机的三维旋转和平移。前者用于动作分析和动画，后者用于机器人抓取和增强现实。

先要会：分类、检测、分割 卷积层、池化与感受野

“姿态估计”在视觉里有两个常见含义，搜索时常混在一起。

人体姿态估计。给定图像，输出每个人的一组关键点坐标。MS COCO的人体关键点标注定义了17个点（鼻子、双眼、双耳、双肩、双肘、双腕、双髋、双膝、双踝）。

  • 从回归到热图。DeepPose直接用CNN回归关键点坐标；后来的主流改为预测热图：每个关键点一张图，在真实位置放一个小的高斯峰，网络逐像素预测，取峰值位置作为结果。热图保留了空间结构，比直接回归好学得多。
  • 自顶向下：先用检测器找出每个人的框，再在每个框里估计单人关键点。精度高，计算量随人数增长。Simple Baselines姿态用“ResNet+几层转置卷积”的极简结构取得了很强的结果，ViTPose把主干换成了ViT。
  • 自底向上：先找出图中所有关键点，再把它们分组到不同的人。OpenPose用部件亲和场（PAF）描述“哪两个关键点属于同一条肢体”，速度几乎不随人数变化。
  • 评测：COCO用基于关键点相似度（OKS）的AP，类似于检测里用IoU与mAP。

三维人体姿态与人体网格。从单张图估计关节的三维位置，或直接回归参数化人体模型的形状和姿态参数，是动作捕捉、数字人和人形机器人模仿人类动作的基础。

物体6D位姿估计。求物体坐标系到相机坐标系的旋转R（3个自由度）和平移t（3个自由度），见位姿与齐次变换SE(3)。经典做法是匹配物体模型上的已知点与图像中的2D点，解PnP问题（由n对3D-2D对应求相机位姿），并用RANSAC剔除错误匹配；深度学习方法直接预测关键点或位姿。机器人在抓取前通常要先知道物体的6D位姿，见相机模型与多视图几何。

例子

一张640×480的图里有3个人。自顶向下：检测器给出3个框，每个框缩放到256×192送入姿态网络，输出17张64×48的热图，取每张图的峰值再按比例映射回原图坐标，共调用3次姿态网络。自底向上：整图一次前向得到所有关键点热图和肢体亲和场，再把51个关键点分成3组。

容易误解的地方

  • 热图的分辨率有限（例如64×48），直接取最大值会有量化误差，实践中常用亚像素的偏移修正。
  • 遮挡和不常见的姿势（倒立、蜷缩）是主要失败来源；训练集中这类样本很少。
