图神经网络与消息传递

Graph Neural Networks and Message Passing

也叫：GNN　graph neural network　GCN　图卷积　MPNN　邻居聚合

在交互版中打开（看它长在树上的哪里）

图神经网络的通用计算方式：每个节点收集邻居发来的“消息”，汇总后更新自己的向量；堆k层，每个节点就能感知k步以内的邻域。

先要会：图、树与搜索 多层感知机 矩阵乘法与线性变换 不变性与等变性

分子（原子是节点、化学键是边）、社交网络、交通路网、知识图谱都是图（见图、树与搜索）。图没有固定的大小，也没有“第一个节点”“左边的节点”这类顺序，所以多层感知机（要求固定长度、有序的输入）和卷积层、池化与感受野（要求规则网格）都不能直接用。我们需要一种运算：对任意大小的图都适用，而且结果不依赖于给节点编号的方式。

消息传递的一层。每个节点v有一个向量h_v。一层更新分三步：

1. 发消息：每个邻居u向v发送m_uv = M(h_u, h_v, e_uv)，e_uv是边的特征，M是一个小网络（最简单时就是W·h_u）。 2. 汇总：a_v = AGG({m_uv : u ∈ N(v)})，N(v)是v的邻居集合。AGG必须与邻居的顺序无关，常用求和、平均或取最大。 3. 更新：h_v' = U(h_v, a_v)，U是另一个小网络。

所有节点共享同一组M、U参数，就像卷积核在所有像素上共享——这也是为什么图神经网络能处理任意大小的图。

为什么顺序无关。重新给节点编号，只是把同样的计算换了个顺序做，每个节点得到的结果完全一样（跟着编号一起换）。这叫置换等变（见不变性与等变性）。要得到整张图的一个输出（比如分子的毒性），再对所有节点做求和或平均，就变成置换不变。

层数与视野。一层只看直接邻居；k层后，每个节点的向量融合了k跳以内所有节点的信息，类似卷积网络的感受野（见卷积层、池化与感受野）。但层数一多，所有节点的向量会趋于相同（过平滑），所以GNN通常只有几层。

代表性的方法。图神经网络GNN（2009）最早提出图神经网络；图卷积网络用对称归一化的邻居平均：H' = σ(D̂^(−1/2)·Â·D̂^(−1/2)·H·W)，Â是加了自环的邻接矩阵、D̂是其度矩阵；消息传递神经网络MPNN把各种做法统一成上面的三步框架，用于分子性质预测；图注意力网络GAT用注意力决定每个邻居的权重。应用上，GraphCast与AI天气预报用消息传递在地球网格上做天气预报。一个值得注意的联系：Transformer的自注意力可以看作在“全连接图”上做消息传递，每个token都是所有其他token的邻居。

例子

一条三节点的链A − B − C，节点特征分别是1、2、3（标量）。用最简单的规则：新值 = 自己和所有邻居的平均。

第1层：A = (1 + 2)/2 = 1.5；B = (1 + 2 + 3)/3 = 2；C = (2 + 3)/2 = 2.5。

第2层：A = (1.5 + 2)/2 = 1.75；B = (1.5 + 2 + 2.5)/3 = 2；C = (2 + 2.5)/2 = 2.25。

第1层后A只知道B的信息；第2层后A的值已经受到C（距离2跳）的影响。继续堆层，三个值会一起趋近于同一个数——这就是过平滑。如果把节点重新编号为C、A、B，每个节点算出的值不变。

容易误解的地方

  • 标准消息传递GNN的区分能力有上限：它无法区分某些结构不同的图（上限是Weisfeiler-Lehman图同构测试，见GIN与GNN表达能力）。
  • 层数不是越多越好：过平滑和“过挤压”（远处大量信息挤进一个固定长度的向量）限制了GNN的深度。
  • 用邻接矩阵写成矩阵乘法只是一种实现方式；大规模稀疏图上通常按边直接收集和散布，以节省显存。
