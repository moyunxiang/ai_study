二分类、多分类与多标签

Binary, Multi-Class and Multi-Label Classification

也叫：多分类　多类分类　multi-class classification　multiclass classification　多标签分类　multi-label classification　multilabel　multi-label　二分类　binary classification　一对其余　一对多　one-vs-rest　OvR　one-vs-all　OvA　一对一　one-vs-one　OvO　层次分类　hierarchical classification

分类任务的三种形式：二分类（是或否）、多分类（从K类里恰好选一个）、多标签（一个样本可以同时有多个标签）。输出层、损失函数和评测指标都随之不同。

先要会：监督学习 Softmax与logits

“分类”听起来是一件事，但输出结构不同，做法也不同。动手之前先分清是哪一种。

二分类。输出一个数，经sigmoid变成“属于正类”的概率，用二元交叉熵与sigmoid输出训练。垃圾邮件识别、是否违规、是否点击。

多分类（multi-class）。K个类别互斥，每个样本恰好属于一类。输出K个logit，经Softmax与logits变成和为1的分布，用交叉熵训练，预测时取最大的那个。MNIST的10个数字、ImageNet的1000类、语言模型在词表上预测下一个token都属于这一类。

多标签（multi-label）。标签之间不互斥，一个样本可以同时有0个、1个或多个标签：一张照片里既有猫又有沙发，一篇新闻既属于“体育”又属于“财经”，一张胸片可能同时有几种病变。做法是输出K个logit，各自做sigmoid和BCE，预测时每个标签单独与阈值（如0.5）比较。

用二分类器拼出多分类。像支持向量机这样天生只做二分类的模型，有两种扩展方式：

  • 一对其余（one-vs-rest, OvR）：为每个类训练一个“是这一类 vs 不是”的分类器，共K个，预测时取得分最高的。
  • 一对一（one-vs-one, OvO）：每两个类之间训练一个，共K(K−1)/2个，预测时投票。

评测指标也不同。多分类常报告准确率、Top-k准确率（见Top-1与Top-5错误率）和宏平均/微平均F1（见准确率、精确率、召回率与F1）；多标签常报告每个标签的F1再平均、或mAP（对每个标签的排序质量算AP再平均）。类别很不均衡时还要看c:imbalanced-metrics。

还有更复杂的输出。类别之间有层级（动物→哺乳动物→狗）时叫层次分类；输出是一个序列或结构（如分词、句法树）时就进入了结构化预测，见条件随机场。

例子

新闻分类，类别为（体育、财经、科技）。

  • 多分类：logits (2.0, 1.0, 0.1)，softmax后(0.66, 0.24, 0.10)，预测“体育”。
  • 多标签：同样的logits分别做sigmoid得(0.88, 0.73, 0.52)，阈值0.5时三个标签都判为“是”。一篇“体育明星投资科技公司”的报道，在多标签设定下这样的输出完全合理。

容易误解的地方

  • 把多标签问题当成多分类用softmax训练，模型会被迫在几个都正确的标签之间分配概率，效果通常更差。
  • 多标签的阈值0.5不一定最好，每个标签可以在验证集上单独调阈值。
