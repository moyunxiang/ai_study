模式坍塌与模式覆盖

Mode Collapse and Mode Coverage

也叫：模式崩溃　模式坍缩　mode dropping　多样性不足

在交互版中打开（看它长在树上的哪里）

生成模型只学会数据中的少数几类样本，反复生成相似的东西，丢掉了其余多样性；与之相对，“模式覆盖”指照顾到数据的所有类型。

先要会：KL散度 对抗训练 生成建模的目标

数据分布通常有很多“峰”（mode）：人脸数据里有不同年龄、肤色、发型，每一类都是一个高概率区域。理想的生成模型应该按真实比例生成所有这些类型。模式坍塌是指模型只生成其中一两种：画出来的每张脸都很清晰，但都是同一类人，甚至几乎是同一张脸。

为什么GAN容易坍塌。对抗训练里，生成器只需要骗过当前的判别器。如果某一类样本最容易骗过判别器，生成器就会把所有噪声都映射到那里；判别器学会识破后，生成器又整体跳到另一类，如此来回，始终覆盖不全。GAN训练技巧与IS提出让判别器同时看一批样本来察觉“这批都一样”，Wasserstein GAN换了更平滑的距离来缓解这个问题。

用KL的方向来理解。用分布q去近似数据分布p时，损失选哪个方向的KL散度会带来不同偏好：

  • KL(p‖q)（前向，最大似然训练用的就是它）：只要p有质量的地方q接近0，惩罚就极大，所以q倾向于覆盖所有模式，宁可把概率摊到模式之间的空白区。代价是样本可能模糊，变分自编码器VAE的生成图偏糊与此有关。
  • KL(q‖p)（反向）：q可以放弃一些模式而不受太大惩罚，倾向于只抓住少数模式，样本清晰但不全。

这就是“质量与多样性”的权衡。评价时常用精确率（生成的样本有多少落在真实分布上）和召回率（真实分布有多少被生成覆盖）分开度量，FID把两者混在一起，见生成质量指标：IS与FID。扩散模型基于似然类目标，覆盖较好，但加大条件生成与引导权重会主动牺牲多样性，效果上类似轻度坍塌。语言模型经过对齐训练后回答趋同，也常被称作类似现象。

例子

真实分布在两个模式A、B上各占0.5。模型q=(0.99, 0.01)几乎只生成A。

  • 前向KL(p‖q) = 0.5·ln(0.5/0.99) + 0.5·ln(0.5/0.01) = −0.342 + 1.956 ≈ 1.614
  • 反向KL(q‖p) = 0.99·ln(0.99/0.5) + 0.01·ln(0.01/0.5) = 0.676 − 0.039 ≈ 0.637

同样是丢掉模式B，前向KL的惩罚是反向的约2.5倍。所以最大似然训练的模型很少整类丢样本，而GAN等不按似然训练的模型更容易出现这种情况。

容易误解的地方

  • 每张样本都很好看不能说明没有坍塌，必须看大量样本的多样性或算召回率。
  • 坍塌不一定是全有或全无；常见的是部分坍塌，例如少数类别、少数姿态生成得特别少。
  • GAN也有“模式坍塌”与“训练不收敛”两个不同问题，两者常同时出现但不是一回事。
