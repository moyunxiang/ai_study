Bellman方程

Bellman Equation

也叫：贝尔曼方程　贝尔曼最优方程　Bellman optimality　值迭代　value iteration　最优性原理

在交互版中打开（看它长在树上的哪里）

价值函数满足的递推关系：一个状态的价值等于这一步的期望奖励加上折扣后下一状态的价值。几乎所有强化学习算法都在求解或近似它。

先要会：马尔可夫决策过程 策略与价值函数 动态规划

直接按定义算价值函数，要对所有可能的未来轨迹求期望，轨迹数随长度指数增长。Bellman的观察是：回报满足G_t = r_{t+1} + γ·G_{t+1}，取期望后，一个状态的价值可以用下一状态的价值来表示。于是一个“看无穷远”的问题，变成了只看一步的递推——这正是动态规划的思想。

Bellman期望方程（评估给定策略π）：

V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s, a)·[R(s, a, s') + γ·V^π(s')]

读法：按策略选动作，按环境转移到下一状态，拿到这一步奖励，再加上下一状态价值打个折。

Bellman最优方程（最优策略的价值）：

V*(s) = max_a Σ_{s'} P(s'|s, a)·[R(s, a, s') + γ·V*(s')]

Q*(s, a) = Σ_{s'} P(s'|s, a)·[R(s, a, s') + γ·max_{a'} Q*(s', a')]

把期望里的“按策略平均”换成了“取最好的动作”。

怎么求解：价值迭代。从任意初值（如全0）出发，把方程右边当成更新规则反复计算V ← max_a Σ P·[R + γV]。由于γ<1，每次迭代后误差至多变为原来的γ倍，最终收敛到V*。已知P和R时这就够了，这是动态规划与Bellman方程在1957年给出的方法；Howard策略迭代提出了交替“评估—改进”的策略迭代。

不知道P和R时。强化学习的大部分算法都是在用采样代替求和来近似Bellman方程：时序差分学习用一次实际转移r + γV(s')代替期望，见时序差分与自举；Q-learning和DQN近似的是Q*的最优方程。

例子

用马尔可夫决策过程词条里的3状态MDP（γ=0.9）做价值迭代，初值全为0，终点s₃价值恒为0。

第1轮：V(s₂)=5（走到终点得5）。V(s₁)=max(走: 0+0.9×0=0，跳: 0.5×(10+0)+0.5×(−2+0.9×0)=4)=4。

第2轮：V(s₂)=5。V(s₁)=max(走: 0+0.9×5=4.5，跳: 0.5×10+0.5×(−2+0.9×4)=5.8)=5.8。

第3轮：跳=0.5×10+0.5×(−2+0.9×5.8)=6.61，继续迭代依次为6.97、7.14……收敛值满足V = 5 + 0.5×(−2 + 0.9V)，解得V*(s₁)=4/0.55≈7.27。所以虽然“跳”有一半概率摔回去，最优策略仍是一直跳，期望回报7.27高于稳妥路线的4.5。

容易误解的地方

  • Bellman方程是价值函数满足的等式，价值迭代、TD学习、Q-learning是求解它的不同算法。
  • 价值迭代的收敛依赖γ<1（或任务必然终止）；用神经网络近似V后，收敛保证不再成立，见致命三元组。
  • 状态很多时无法逐个状态迭代，这正是需要函数近似（神经网络）的原因。
