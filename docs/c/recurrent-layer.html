循环网络与隐状态

Recurrent Networks and Hidden State

也叫：RNN　循环神经网络　递归神经网络　隐藏状态　Elman网络

在交互版中打开（看它长在树上的哪里）

按顺序逐个读入序列元素、用一个隐状态向量记住目前为止的信息的网络层。同一组参数在每个时间步重复使用。

先要会：多层感知机 反向传播 梯度消失与梯度爆炸

句子、语音、股价都是长度不固定的序列。多层感知机只能接受固定长度的输入，而且不知道“先后”。循环神经网络（RNN）的做法是：像人读书一样从左往右一个一个读，边读边更新一份“笔记”——隐状态h。

定义。在第t步，读入输入x_t，结合上一步的隐状态h_(t−1)，算出新的隐状态：

h_t = tanh(W_h·h_(t−1) + W_x·x_t + b)

需要输出时再加一层y_t = W_y·h_t。关键在于W_h、W_x、b在所有时间步共享：不管序列多长，参数量不变。h_0通常设为全0。h_t是整个前缀x_1…x_t的压缩摘要，长度固定（比如512维）。

怎么训练。把循环沿时间展开，就得到一个层数等于序列长度、每层参数相同的深网络，然后照常做反向传播，这叫随时间反向传播（随时间反向传播BPTT）。

两个根本困难。

第一，梯度消失或爆炸（见梯度消失与梯度爆炸）。损失对很早的h_1的梯度，要连乘许多个W_h与tanh导数构成的矩阵。连乘的结果要么指数缩小、要么指数放大，所以普通RNN实际上只记得住最近十几步。梯度消失问题在1994年系统分析了这个问题，LSTM用门控（见门控机制）缓解了它。

第二，无法并行。h_t必须等h_(t−1)算完，长度为1000的序列就是1000步串行计算，GPU的大量核心闲置。这是Transformer取代RNN的主要原因。

它在哪里出现。Elman循环网络（1990）是经典的简单RNN；RNN语言模型用它做语言模型；Seq2Seq用两个LSTM搭成编码器-解码器做翻译。2020年代，状态空间模型（Mamba状态空间模型）和线性注意力把“固定大小隐状态”的思路重新带回来：它们推理时每步的计算和显存是常数，而且训练时可以并行。

例子

取一维的简化RNN：h_t = tanh(0.5·h_(t−1) + x_t)，h_0 = 0，输入序列[1, 0, 0]。

  • t = 1：h_1 = tanh(0 + 1) ≈ 0.762
  • t = 2：h_2 = tanh(0.5×0.762 + 0) = tanh(0.381) ≈ 0.363
  • t = 3：h_3 = tanh(0.5×0.363) = tanh(0.182) ≈ 0.180

第一步读到的“1”每过一步大约衰减一半。梯度也一样：∂h_3/∂h_1 = [0.5×(1 − h_2²)] × [0.5×(1 − h_3²)] ≈ 0.434 × 0.484 ≈ 0.21（tanh的导数是1 − tanh²）。若把0.5换成2，tanh饱和前信号会放大，梯度则可能爆炸。真实RNN里W_h是矩阵，起作用的是它的特征值大小，道理相同。

容易误解的地方

  • 隐状态是固定长度的向量，序列再长也要塞进去，信息必然有损。注意力机制（注意力机制）最初就是为了绕开这个瓶颈。
  • “RNN已经过时”不完全对：现代的线性RNN/状态空间模型在长序列推理上比Transformer省显存，部分大模型采用了混合架构。
  • 双向RNN（同时从左往右、从右往左读）能用于理解任务，但不能用于逐词生成，因为生成时看不到未来。
