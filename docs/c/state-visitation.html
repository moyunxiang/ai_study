状态访问分布与占用度量

State Visitation Distribution and Occupancy Measure

也叫：状态访问分布　state visitation distribution　state distribution　折扣状态分布　discounted state distribution　占用度量　occupancy measure　state-action occupancy　状态-动作占用　访问频率　d^π

在交互版中打开（看它长在树上的哪里）

一个策略长期运行时在各个状态（或状态-动作对）上停留的比例，按折扣加权后归一化成一个分布。策略的期望回报就等于奖励在这个分布下的平均。

先要会：马尔可夫决策过程 马尔可夫性与马尔可夫链 奖励、回报与折扣

策略梯度、模仿学习、离线RL的公式里常出现“s ~ d^π”这样的记号。它回答的问题是：按策略π行动时，智能体会多频繁地出现在各个状态？这一点很关键，因为不同策略访问的状态不一样，训练数据来自哪个分布，学到的东西就在哪个分布上可靠。

折扣状态访问分布。

d^π(s) = (1 − γ) · Σ_{t≥0} γ^t · Pr(s_t = s | π)

把每个时刻处在s的概率按γ^t加权求和，再乘(1−γ)让总和为1。γ越接近1，越接近长期平均的停留比例。

占用度量（occupancy measure）。再乘上策略选动作的概率：ρ^π(s, a) = d^π(s) · π(a|s)。它有一个漂亮的性质：期望回报可以写成奖励在占用度量下的平均，

J(π) = (1/(1−γ)) · E_{(s,a)~ρ^π}[r(s, a)]

而且占用度量和策略一一对应（由ρ^π可以反解出π）。于是“找最优策略”可以改写成“在满足流量守恒约束的占用度量里找使奖励平均最大的那个”，这是MDP线性规划解法的来源。

它出现在哪里。策略梯度定理说策略梯度是在d^π下取期望，所以同策略算法必须用当前策略的数据，见on-policy与off-policy。GAIL把模仿学习表述为让学习者的占用度量接近专家的占用度量。保守策略迭代CPI和性能差异引理说明策略改进的大小取决于新策略的访问分布，这是信赖域与代理目标限制每步改动幅度的理论动机。离线RL的困难也可以说成：数据的状态-动作分布与学到的策略的占用度量不一致，见分布偏移。

例子

两个状态A、B。策略π在A时有0.5概率留在A、0.5概率去B，在B时一定留在B；从A出发，γ=0.9。Pr(s_t=A) = 0.5^t，于是d^π(A) = 0.1 × Σ_t (0.9×0.5)^t = 0.1 / (1 − 0.45) ≈ 0.18，d^π(B) ≈ 0.82。若只在B有奖励1，则J = (1/0.1) × 0.82 × 1 ≈ 8.2，与直接累加折扣奖励的结果一致。

容易误解的地方

  • d^π不是平稳分布：它带折扣、依赖起点；γ→1时才趋向平稳分布。
  • 实际的同策略算法通常直接对采到的样本求平均，并没有按γ^t加权，严格说是在用一个略有偏差的分布，这在实践中一般被忽略。
