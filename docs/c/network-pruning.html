剪枝与稀疏化

Network Pruning and Sparsity

也叫：剪枝　pruning　模型剪枝　权重剪枝　结构化剪枝　structured pruning　非结构化剪枝　unstructured pruning　稀疏化　sparsity　2:4稀疏　N:M sparsity　彩票假说　lottery ticket　层剪枝

在交互版中打开（看它长在树上的哪里）

删掉网络里不重要的权重、神经元或整层，让模型变小变快，再用少量训练把精度补回来。

剪枝的历史比深度学习还早：最优脑损伤OBD剪枝和最优脑外科OBS用损失函数的二阶信息判断删掉哪个权重代价最小。剪枝与量化压缩把剪枝、量化和编码串起来，把卷积网络压小了几十倍，引出大量后续工作。

大模型上，逐权重重训成本太高，SparseGPT一次性剪枝沿用OBS的二阶思路，一次性把百亿参数模型剪掉一半权重而几乎不需要重训。但非结构化稀疏在普通GPU上不容易真正提速，于是结构化剪枝（整块删神经元、注意力头或层）重新受到重视：Minitron剪枝加蒸馏按激活重要性剪宽度、再用原模型蒸馏恢复，从一个15B模型得到8B和4B版本。

现在的共识是，剪枝几乎总要搭配知识蒸馏使用；争论在于剪宽度还是剪深度，以及剪枝与直接训练小模型哪个更划算。
