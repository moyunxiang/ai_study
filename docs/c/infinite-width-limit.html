无限宽网络理论

Infinite-Width Limits of Neural Networks

也叫：NTK　神经正切核　Neural Tangent Kernel　惰性训练　Lazy Training　Lazy Regime　特征学习区　Feature Learning Regime　平均场　Mean-Field　μP　muP　Maximal Update Parametrization　μTransfer　超参数迁移　Tensor Programs　NNGP

把网络宽度取到无穷，训练过程变得可以精确分析；不同的参数化方式会得到“像核方法”或“真正学特征”两种极限。

很宽的网络在随机初始化下的输出近似高斯过程回归。神经正切核进一步证明：在标准参数化下，宽度趋于无穷时梯度下降训练等价于一个固定核的核回归，从而可以分析收敛与泛化。惰性训练与特征学习指出这时权重几乎不动、网络并没有学到新特征，这与实际深度学习的表现不符。

Tensor Programs IV给出另一种参数化，使无限宽极限仍保留特征学习；μP与超参数迁移据此提出μP：在小模型上调好的学习率等超参数，可以零成本迁移到大模型，已被用于大模型训练。这条线的核心问题是：真实网络处于哪种区域、有限宽度带来多大偏差。
