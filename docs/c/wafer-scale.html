晶圆级芯片

Wafer-Scale Computing

也叫：晶圆级　Wafer-Scale Engine　WSE　整片晶圆芯片　Wafer-scale integration　WSI　Cerebras　Dojo训练瓦片

在交互版中打开（看它长在树上的哪里）

不把晶圆切成小芯片，而是把整片晶圆做成一块巨型处理器，让片上存储和片上互连代替芯片间通信。

普通芯片受光刻视场限制，面积最多约800平方毫米，多芯片之间的通信又慢又费电。晶圆级芯片反其道而行之：整片300毫米晶圆就是一颗芯片，核与核之间全是片上连线，还能塞进几十GB的SRAM。难点是良率——晶圆上必然有缺陷，需要冗余核和可绕行的片上网络来容错。

Cerebras晶圆级芯片在2019年推出第一代晶圆级引擎，Cerebras WSE-3延续这条路，并凭借片上SRAM的高带宽转型做极快的推理服务（Cerebras推理服务）。特斯拉的Tesla Dojo与D1用晶圆上集成25颗D1芯片的训练瓦片走了一条相近的思路，但2025年8月特斯拉解散了Dojo团队（彭博报道），2026年1月马斯克又称将重启Dojo。

争议在于：片上SRAM容量对超大模型仍不够，要依赖外部存储；散热和供电极其复杂；软件生态也远小于GPU。
