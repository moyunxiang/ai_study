策略梯度的方差缩减：基线与reward-to-go

Variance Reduction for Policy Gradients

也叫：方差缩减　variance reduction　基线　REINFORCE基线　REINFORCE with baseline　baseline (RL)　策略梯度基线　reward-to-go　未来回报　因果性技巧　causality trick　控制变量　control variate　control variates

让策略梯度估计不那么“随机”的一组技巧：只用动作之后的奖励（reward-to-go）、减去一个与动作无关的基线、用价值函数做控制变量，期望不变而方差大幅下降。

先要会：策略梯度 期望与方差

最朴素的策略梯度用整条轨迹的回报G给每一步的动作打分：∇J ≈ Σ_t ∇log π(a_t|s_t) · G。它无偏，但方差大到常常学不动：回报里混着所有步的随机性，而且所有回报都是正数时，每个动作的概率都会被往上推，只是推得多少不同。下面几种方法都不改变梯度的期望，只降低方差。

reward-to-go（因果性）。t时刻的动作影响不了t之前的奖励，所以只用它之后的回报：

∇J ≈ Σ_t ∇log π(a_t|s_t) · Σ_{t'≥t} γ^{t'−t} r_{t'+1}

去掉的那部分期望为0，只贡献噪声。

基线（baseline）。由对数导数技巧与得分函数估计，E[∇log π(a|s)] = 0，所以从回报里减去任何只依赖状态、不依赖动作的b(s)，期望不变：(G_t − b(s_t))。好的基线让“比平时好”的动作得正分、“比平时差”的得负分。最常用的基线是状态价值V(s)，此时G_t − V(s_t)就是优势的一个估计，这便是Actor-Critic与优势函数的出发点。理论上方差最小的常数基线是按‖∇log π‖²加权的回报平均，但实践中直接用V(s)已足够。

控制变量（control variate）。更一般的思路：从估计量中减去一个期望已知、与它高度相关的量。基线是最简单的控制变量；Q-Prop控制变量策略梯度用critic的一阶泰勒展开作控制变量。

其他常用手段。用广义优势估计GAE在偏差和方差之间调节优势估计；在一个批次内把优势标准化为均值0、方差1（见强化学习中的归一化：观测、奖励与优势）；对同一个状态（或同一道题）采多个样本，用彼此的平均奖励作基线，如RLOO回归REINFORCE和GRPO，省掉了单独训练的价值网络。

例子

某状态下两个动作（softmax策略，概率各0.5）的回报分别是101和99。看对第一个动作logit的梯度：采到动作1时∇log π = 0.5，采到动作2时为−0.5。不加基线，单样本估计是101×0.5 = 50.5或99×(−0.5) = −49.5，期望0.5，但正负剧烈摇摆。以b=100为基线，两种情况分别是1×0.5 = 0.5和(−1)×(−0.5) = 0.5，期望仍是0.5，方差变成0。

容易误解的地方

  • 基线不能依赖当前动作a，否则期望就变了，梯度有偏。依赖动作的基线需要额外的修正项（Q-Prop就是这样做的）。
  • 用学出来的V(s)作基线本身没有偏差，但再用V去自举（如TD误差、GAE的λ<1）就会引入偏差，二者要区分。
