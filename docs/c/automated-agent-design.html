自动设计智能体系统

Automated Design of Agentic Systems

也叫：ADAS　自动化智能体设计　智能体工作流搜索　workflow search　agentic workflow optimization　工作流优化　Meta Agent Search　元智能体　agent search

在交互版中打开（看它长在树上的哪里）

不再手写智能体的提示、流程和组件，而是用搜索或学习自动找出更好的智能体系统设计。

智能体的流程（先计划还是先检索、要不要自我检查、几个模型投票）长期靠人设计。GPTSwarm智能体图优化首先把智能体表示成可优化的图；ADAS自动设计智能体让一个元智能体用代码不断写出新智能体并留档；AFlow自动工作流用蒙特卡洛树搜索在代码化的工作流空间里搜索；达尔文哥德尔机DGM让编码智能体直接改写自己的代码。提示层面的自动化见「自动提示优化」，它们常被组合使用。

2025年后，静态搜索出的工作流逐渐让位于按每个问题现场生成方案的学习式编排器（Puppeteer演化式编排、Conductor指挥家模型）。主要问题是搜索成本高，以及在验证集上搜出的设计容易过拟合。
