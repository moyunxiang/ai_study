核近似：随机特征与Nyström方法

Kernel Approximation: Random Features and Nyström

也叫：核近似　kernel approximation　随机傅里叶特征　random Fourier features　RFF　随机特征　random features　Nyström方法　Nystrom method　Nyström近似　Nyström approximation　地标点　landmark points　诱导点　inducing points　随机核特征　random kitchen sinks

核方法要算n×n核矩阵，样本多了就算不动。核近似用低维显式特征z(x)使k(x, y) ≈ z(x)ᵀz(y)：随机傅里叶特征靠随机投影，Nyström靠少量代表样本。

先要会：核技巧与间隔 低秩近似

再生核希尔伯特空间、表示定理与核岭回归里，核岭回归要解(K + λI)α = y，核矩阵K有n²个元素，求解要O(n³)。一百万个样本时，光存K就要几TB。核方法在大数据上败给深度学习，这是主要原因之一。如果能找到一个D维的显式特征z(x)（D远小于n）使k(x, y) ≈ z(x)ᵀz(y)，就可以回到线性模型：只需在z(x)上做普通的线性回归或线性SVM，代价降为O(nD²)。

随机傅里叶特征（Random Fourier Features）。Rahimi与Recht在2007年提出。对平移不变的核（如高斯核，只依赖x − y），由傅里叶变换（见傅里叶变换与频域）可以把核写成一个期望：

k(x − y) = E_ω[cos(ωᵀ(x − y))]，ω从核对应的频谱分布中采样（高斯核对应的就是高斯分布）。

于是随机抽D个频率ω_j和相位b_j，令

z(x) = √(2/D) · [cos(ω_jᵀx + b_j)]_{j=1..D}

内积z(x)ᵀz(y)就是这个期望的蒙特卡洛采样估计，误差约按1/√D缩小（见大数定律与中心极限定理）。这相当于一个权重随机固定、只训练最后一层的单隐层网络。

Nyström方法。从n个样本中挑出m个“地标”样本（随机挑，或用聚类中心），只计算它们之间的m×m核矩阵W和全部样本与地标之间的n×m矩阵C，然后近似

K ≈ C·W⁻¹·Cᵀ

这是一个秩为m的低秩近似近似。它依赖数据，在核矩阵特征值衰减快时比随机特征更准。高斯过程中的“诱导点”方法（如随机变分高斯过程SVGP）是同一思路。

它出现在哪里。

  • 大规模核回归、核SVM和高斯过程的标准加速手段。
  • 注意力的softmax也可以看作一个核exp(qᵀk)：Performer核近似注意力用正的随机特征近似它，把注意力的代价从序列长度的平方降为线性；Nyströmformer用地标近似注意力矩阵（见稀疏注意力与高效注意力）。
  • 理论上，随机特征模型是研究过参数化与双下降的常用简化模型（见过参数化与泛化之谜）。

例子

n = 10⁶个样本、高斯核。精确核岭回归：K有10¹²个元素（FP32约4TB），无法计算。随机傅里叶特征取D = 2000：特征矩阵10⁶×2000（约8GB），再解一个2000×2000的线性方程，普通工作站即可完成。Nyström取m = 2000个地标，需要的存储量相近。

容易误解的地方

  • 随机特征的近似误差随维度D下降得很慢（约1/√D），想要很高精度时需要的D可能很大。
  • 这些近似只针对特定类型的核：随机傅里叶特征要求核是平移不变的，Nyström要求能算出任意两个样本的核值。
