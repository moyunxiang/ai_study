矩阵的秩、迹与行列式

Rank, Trace and Determinant

也叫：秩　矩阵的秩　rank　matrix rank　迹　trace　矩阵的迹　行列式　determinant　det　满秩　秩亏　log-determinant　对数行列式

在交互版中打开（看它长在树上的哪里）

描述一个方阵或矩阵的三个基本数：秩说它真正有几个独立方向，迹是对角线之和，行列式是它把体积放大了多少倍。

先要会：向量、矩阵与张量 矩阵乘法与线性变换 特征分解与奇异值分解

一个矩阵W可以看成一个线性变换（见矩阵乘法与线性变换）：把输入向量x变成Wx。要概括这个变换“有多大本事”，最常用的是三个数。

秩（rank）。W的列向量里最多有几个线性无关，就是它的秩。秩为r，说明无论输入是什么，输出都只落在一个r维子空间里。一个1000×1000的矩阵如果秩只有8，它其实只用到8个方向，可以写成两个瘦矩阵的乘积W = A·B（A是1000×8，B是8×1000），参数从100万降到1.6万，这就是低秩近似。秩可以用特征分解与奇异值分解里非零奇异值的个数来算。

迹（trace）。方阵对角线元素之和，tr(A) = Σ_i A_ii，也等于全部特征值之和。它有两个好用的性质：tr(AB) = tr(BA)（循环交换），以及xᵀAx = tr(A·xxᵀ)。推导损失函数和协方差公式时，常用它把一个标量写成矩阵形式再求导，见矩阵求导。

行列式（determinant）。方阵的行列式det(A)等于全部特征值之积，几何意义是：单位立方体经过A变换后，体积变成原来的|det(A)|倍；符号为负表示空间被翻转。det(A) = 0意味着有一个方向被压扁成了0，矩阵不可逆、秩不满，见逆矩阵与伪逆。

它们出现在哪里。LoRA假设微调时权重的改变量是低秩的，只训练两个小矩阵；混合Softmax（MoS）指出softmax输出层的logit矩阵秩受限于隐藏维度，表达能力因此有上限。行列式出现在概率密度的变量替换公式里：可逆变换y = f(x)下，log p(y) = log p(x) − log|det J|（J是雅可比矩阵与海森矩阵中的雅可比矩阵），标准化流RealNVP和Glow专门设计了行列式容易算的结构，见可逆流与流匹配。多元高斯分布的密度公式里也有det(Σ)。

例子

A = [[2, 1], [1, 2]]。迹 = 2 + 2 = 4；行列式 = 2×2 − 1×1 = 3；特征值是3和1，和为4、积为3，正好对上。A把单位正方形变成面积为3的平行四边形。B = [[1, 2], [2, 4]]的第二列是第一列的2倍，秩为1，det(B) = 4 − 4 = 0，它把整个平面压到一条直线上。

容易误解的地方

  • 行列式很小不等于矩阵接近不可逆：把一个100维单位阵乘以0.5，行列式是0.5^100，几乎为0，但它条件良好、很容易求逆。判断是否接近奇异要看条件数，见数值稳定性：上溢、下溢与条件数。
  • 秩是离散的；数值上要说“有效秩”，即看奇异值衰减得多快，而不是数零。
