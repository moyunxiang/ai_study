快速权重与Delta规则

Fast Weights and the Delta Rule

也叫：快速权重　Fast Weights　Delta规则　Delta Rule　DeltaNet　Gated DeltaNet　Fast Weight Programmer　线性注意力即RNN　线性Transformer　Linear Transformer　在线学习式记忆　Widrow-Hoff　LMS规则

把一段上下文写进一个随时间快速改变的权重矩阵；用Delta规则写入，就是让这个矩阵在线做一步最小二乘学习。

ADALINE与LMS的LMS规则（也叫Widrow-Hoff或Delta规则）按“预测误差×输入”更新权重。快速权重提出让一个网络生成另一个网络快速变化的权重，用来存短期记忆。线性注意力去掉softmax后，注意力可以写成不断累加键值外积的矩阵，线性注意力即快速权重指出这正是快速权重，并建议把单纯累加换成Delta规则：先读出旧值，只写入误差部分，以减少记忆互相覆盖。

DeltaNet并行训练解决了Delta规则沿序列并行训练的问题，Gated DeltaNet再加上门控遗忘，被Qwen3-Next等混合架构采用。从这个角度看，测试时训练层TTT和Titans测试时记忆是把单步线性回归推广成多步、非线性的测试时学习。
