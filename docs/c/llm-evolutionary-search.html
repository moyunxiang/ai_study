LLM-Driven Evolutionary Search

也叫：AlphaEvolve　进化式程序搜索　code evolution　程序进化　LLM evolution　OpenEvolve　进化式发现

在交互版中打开（看它长在树上的哪里）

用大模型当变异算子，在程序空间里进化出新的构造或更快的算法，再由自动打分器筛选。

要找到新数学构造或更好的算法，需要大量尝试且结果可自动打分。做法是维护一个程序种群，让大模型改写好程序，评分后保留优者，迭代。FunSearch首先在数学问题上找到新结果，AlphaEvolve推广到更大的代码库和多种问题，ShinkaEvolve降低样本数并开源。争论在于：它是否只适用于可打分的问题，以及发现的新颖性。
