进化方法与强化学习

Evolutionary Methods for RL / Neuroevolution

也叫：neuroevolution　神经进化　进化策略　Evolution Strategies　ES　进化强化学习　evolutionary RL　遗传算法　无梯度策略搜索　black-box optimization

在交互版中打开（看它长在树上的哪里）

不用反向传播的策略梯度，而像生物进化那样批量变异、挑选优秀个体来改进策略或超参。

进化计算比深度RL更早：遗传算法用选择、交叉和变异搜索解，NEAT神经进化把网络结构和权重一起进化，CMA-ES进化策略自适应地调整搜索分布。它们只需要“打分”，不需要梯度，天然适合大规模并行。

进化策略作为RL替代表明进化策略在MuJoCo和Atari上可以与RL竞争，并能在上千个CPU上线性扩展；基于种群的训练PBT把进化用在超参和种群上，成为夺旗：种群训练的第一人称多人游戏、AlphaStar训练的组成部分。近年进化思想又与大模型结合，用于程序与算法搜索（见科学分支的FunSearch、AlphaEvolve）。争论在于样本效率：进化方法通常需要比梯度方法多得多的环境交互。
