基线与消融实验

Baselines and Ablations

也叫：消融研究　ablation study　baseline　对照实验

在交互版中打开（看它长在树上的哪里）

基线是拿来比较的参照方法，回答“比谁好”；消融实验是把自己方法的部件一个个拿掉，回答“好处到底来自哪一部分”。

先要会：基准、排行榜与SOTA

一个新方法在基准上得了80分，这个数字本身说明不了什么。读者至少要问两个问题：别的方法得多少分？你的方法里那么多改动，究竟是哪一个起了作用？实验设计中的基线和消融分别回答这两个问题。

基线（baseline）是用来对照的方法。一篇论文通常有几类基线：最简单的方法（例如线性模型、多数类猜测、随机猜测），用来确认任务不是轻易可解；领域内公认的标准方法；以及当前最强的方法（SOTA，见基准、排行榜与SOTA）。关键在于公平：基线应当和新方法使用同样的训练数据、相近的参数量和算力，并得到同等用心的调参（见超参数与调参）。很多“新方法更好”的结论，在把基线认真调好之后就消失了：GAN大规模对比的负结果发现，给足调参预算后，多种GAN变体的FID相差无几；《Deep RL that Matters》复现性批评展示了同一强化学习算法的不同开源实现结果差异巨大。

消融实验（ablation）借用了神经科学中“切除某个脑区看功能缺失”的说法：在完整方法上每次只去掉或替换一个部件，保持其他一切不变，看指标下降多少。下降越多，说明这个部件越重要；几乎不变，说明它可能是多余的。与之互补的是从基线出发逐个“加上”部件，看每一步的增量。

它出现在哪里：几乎每篇方法论文都有消融表。Transformer论文专门列出改变注意力头数、维度、去掉位置编码等设置的结果；ResNet把同样深度的“普通网络”与“残差网络”并排比较，直接证明了残差连接的作用；Dropout、Batch Normalization等技巧的价值也都靠“有它/没它”的对照确认。读论文时，消融表往往比主结果表更能告诉你哪些想法值得借用，见怎样读一篇论文。

例子

某方法在完整设置下得80.0分，作者给出消融：

  • 完整方法：80.0
  • 去掉部件A：78.5（−1.5）
  • 去掉部件B：79.8（−0.2）
  • 同时去掉A和B：75.4（−4.6）
  • 基线：75.0

解读：A贡献明显；B单独去掉几乎无影响，但同时去掉A和B损失远大于两者之和（1.5 + 0.2 = 1.7），说明两者有交互作用，B可能在A缺席时起替代作用。若每个数字在不同随机种子下波动约±0.3，那么B的−0.2就落在噪声范围内（见方差、种子与统计显著性）。

容易误解的地方

  • 基线没调好是最常见的问题：新方法调了几十组超参数，基线直接用默认值，比较就不公平。
  • 消融一次只改一处，否则无法归因；但部件之间有交互时，单独去掉的结果并不能简单相加。
  • 只在一个数据集、一个种子上做的消融，结论很脆弱。
