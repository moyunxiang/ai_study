预训练语料的清洗、过滤与去重

Pretraining Data Processing

也叫：pretraining data　预训练数据　预训练语料　数据清洗　data cleaning　数据过滤　data filtering　质量过滤　quality filtering　deduplication　数据去重　去重　MinHash　近似去重　near-duplicate　数据处理流水线　data pipeline　数据配比

在交互版中打开（看它长在树上的哪里）

把网页抓取等原始文本加工成预训练语料的流水线：抽取正文、识别语言、按规则和模型过滤低质量内容、精确和近似去重、去除隐私与有害内容，再按来源配比混合。

先要会：语言模型 数据泄漏与基准污染

大语言模型的能力很大程度上来自预训练数据，而互联网的原始文本质量参差不齐：导航栏、广告、乱码、机器生成的垃圾页、同一篇文章被转载成千上万次。直接拿来训练，既浪费算力，也会让模型学到坏习惯。从C4语料开始，几乎每个重要的开放语料（The Pile与开放预训练语料、RefinedWeb、Dolma开放语料、FineWeb / FineWeb-Edu、DCLM）都在论文里详细描述了自己的加工流程，数据处理成了一门专门的手艺。

典型的步骤。

1. 正文抽取：从Common Crawl的HTML中去掉模板、菜单、脚本，只留正文。抽取工具的选择本身就会明显影响最终效果。 2. 语言识别：用fastText等分类器判断语言，按语言分流（见语种识别）。 3. 启发式过滤：基于规则去掉明显的低质量文本，例如过短的页面、符号比例过高、大量重复行、不以标点结尾的行、含屏蔽词列表中的词。C4语料和Gopher的规则是常被沿用的起点。 4. 去重。

  • 精确去重：对整篇文档或每一行算哈希，完全相同的只留一份。
  • 近似去重：用MinHash等方法估计两篇文档的n-gram集合的Jaccard相似度，超过阈值（如0.8）就视为重复。训练数据去重发现，去重后模型逐字复述训练数据的情况明显减少，训练效率也更高。

5. 基于模型的质量筛选：训练一个分类器给文档打“教育价值”或“像高质量参考文本”的分数，只保留高分部分（见用模型筛选预训练数据）。CCNet用维基百科上训练的语言模型的困惑度筛选；FineWeb-Edu用大模型标注的数据训练教育价值分类器。 6. 安全与隐私：去除个人信息（邮箱、电话）、有害内容，以及与评测集重复的内容（见数据泄漏与基准污染）。 7. 配比：网页、代码、书籍、论文、数学等来源按比例混合，比例本身可以优化（见DoReMi数据配比优化）。

为什么重要。在算力相同时，换一份处理得更好的数据，下游表现可以有明显提升，DCLM正是把“固定模型和训练流程、只比数据”做成了一个基准。随着高质量文本逐渐用尽（见数据墙与数据受限训练），如何过滤、改写和合成数据（见大模型合成数据）成为研究重点。

例子

一份1亿个网页的原始抓取，经过一条示意的流水线：

  • 正文抽取后去掉空页面：剩9000万。
  • 语言识别，只留中文：剩1500万。
  • 规则过滤（太短、乱码、广告词过多）：剩900万。
  • MinHash近似去重（Jaccard ≥ 0.8视为重复）：剩500万。
  • 质量分类器只保留得分前30%：剩150万。

（数字为示意。）最终保留下来的不到原始的2%，这在实际的网页语料处理中并不罕见。MinHash的直观含义：两篇文档各取所有5-gram组成集合，交集占并集的比例就是Jaccard相似度，MinHash用少量哈希值快速估计这个比例，不必两两比较全文。

容易误解的地方

  • 过滤规则会带来偏差：屏蔽词列表可能把讨论某些群体或方言的正常文本也删掉。
  • 只看“质量分数”可能让数据风格变窄，不同来源和主题的多样性同样重要。
