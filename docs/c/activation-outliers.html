激活离群值与旋转量化

Activation Outliers and Rotation-Based Quantization

也叫：离群值　outlier　outlier features　离群特征　激活量化　activation quantization　W8A8　W4A4　旋转量化　Hadamard旋转　平滑量化　incoherence processing

在交互版中打开（看它长在树上的哪里）

大模型激活里少数通道数值奇大，把它们和普通数值一起压成低比特会严重失真；这一类工作专门想办法驯服离群值。

LLM.int8()与离群特征发现模型超过约67亿参数后，激活中会稳定出现少数数值极大的特征维，均匀量化时它们撑大刻度、让其余数值全被压成0。它的办法是把这些维单独留成16位。

后续三条思路：SmoothQuant把激活的尺度部分挪到权重上，让两边都好量化；AWQ激活感知量化根据激活大小找出最重要的权重通道加以保护；QuaRot旋转量化用正交的Hadamard旋转把离群值摊到所有维度上，模型输出不变，从而实现权重、激活、KV缓存全4比特。注意力本身也有类似问题，SageAttention八比特注意力通过减去K的均值去掉偏移后再做INT8注意力。

离群值从何而来（与注意力汇聚、归一化层有关）仍在研究中，新的训练方法也在尝试从源头避免它们。
