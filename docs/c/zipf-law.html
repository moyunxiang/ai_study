Zipf定律与Heaps定律

Zipf's Law and Heaps' Law

也叫：Zipf's law　Zipf定律　齐普夫定律　齐夫定律　Heaps' law　Heaps定律　赫普斯定律　长尾分布　long tail　type token　词型与词例　type-token ratio　hapax legomena　词频分布

语言里词的频率分布极不均匀：第r常见的词的频率大约与1/r成正比（Zipf定律）；而语料越大，新词还会不断出现，词表大小随语料长度按幂律增长（Heaps定律）。

先要会：随机变量与概率分布 幂律与规模定律

数一数任何一份足够大的语料：极少数词（“的”、the）占了很大比例的出现次数，而大量的词只出现一两次。这种“长尾”分布是语言最稳定的统计规律之一，它解释了NLP里许多现象：为什么总有分词与token覆盖不了的生词，为什么n-gram与平滑必须做平滑，为什么词表不能无限大。

两个概念：type与token。一段文本里不同的词的个数叫type数（词型数，即词表大小），总共出现的词次叫token数（词例数）。“我爱你，你爱我”有6个token（不计标点）、3个type。

Zipf定律。把词按频率从高到低排名，排名r的词的频率f满足近似关系：

f(r) ∝ 1 / r^a，a通常接近1

取对数后log f ≈ C − a·log r，在双对数坐标上近似一条直线。结果是：前100个最常见的词就占了语料中很大一部分词次，而一半左右的type只出现一次（这类词叫hapax legomena）。

Heaps定律。词表大小V与语料长度N的关系：

V ≈ K · N^β，β通常在0.4到0.7之间

V随N一直增长、但越来越慢——没有哪份语料大到能见过所有的词，人名、地名、新词、拼写错误源源不断。

对AI的意义。

  • 词级词表必然遇到表外词，这推动了BPE子词切分等子词方法，见词表大小的取舍。
  • 低频事件极多，计数估计不可靠，需要Good-Turing估计之类的平滑。
  • 停用词正是分布头部的那些词。
  • 训练数据中知识的分布也呈长尾：模型对常见事实记得牢、对罕见事实容易出错（见幻觉）。数据分布驱动ICL涌现的研究还发现，训练数据呈Zipf式长尾分布是上下文学习能力出现的条件之一。
  • 规模定律（见幂律与规模定律）同样是幂律形式，但那是另一种现象，不要混为一谈。

例子

在一份英文语料里，若the的频率是全部词次的6%，按a = 1的Zipf定律，第2名（如of）约3%，第3名约2%，第10名约0.6%，第1000名约0.006%。

Heaps定律：取K = 30、β = 0.5，100万词的语料约有30×1000 = 3万个不同的词；语料增加到1亿词（100倍），词表只增长到约30万（10倍）。（K和β是示意值，实际随语言和语料而变。）

容易误解的地方

  • Zipf定律只是近似，分布的头部和尾部常偏离直线，不同语言、不同分词方式的a也不同。
  • 用词数统计中文时，结果依赖分词方式；按字统计和按词统计会得到不同的曲线。
