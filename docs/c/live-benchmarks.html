Live / Contamination-Free Benchmarks

也叫：动态基准　实时基准　活基准　去污染评测　防污染评测　contamination-free benchmark　live benchmark　rolling benchmark　长青评估　evergreen evaluation　fresh tasks　按时间切分　time-split evaluation　私有测试集　held-out set

在交互版中打开（看它长在树上的哪里）

不再用一份固定题库，而是持续收录模型训练截止之后才出现的新题，或把答案藏起来，以规避测试集泄漏。

数据泄漏与基准污染让静态基准越来越难以相信：GSM1k污染复查重新出一批同分布的小学数学题，就发现部分模型掉分明显。对策之一是让题目“活”起来。Dynabench动态基准较早提出让人和模型对抗、不断出新题；LiveBench每月更新题目并用客观答案评分；LiveCodeBench按题目发布时间切分，只用模型训练截止后的竞赛题；LiveCodeBench Pro进一步请奥赛选手标注和诊断；SWE-rebench去污染榜把同一思路用到修GitHub仓库的任务；MathArena竞赛数学在新一届数学竞赛出题后立刻评测；xbench长青评测称之为长青评估。

另一条路是私有测试集：Artificial Analysis智能指数称其v5中六成权重来自私有或不公开答案的评测。代价是透明度：题目不公开，外界难以复核。
