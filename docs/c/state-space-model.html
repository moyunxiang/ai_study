状态空间模型与线性RNN

State-Space Models and Linear RNNs

也叫：SSM　Mamba　S4　linear RNN　选择性SSM

在交互版中打开（看它长在树上的哪里）

用一个固定大小的隐状态按线性规则逐步更新来处理序列：训练时能像卷积一样并行，推理时像RNN一样每步只需常数内存，是Transformer之外处理长序列的主要路线。

先要会：循环网络与隐状态 卷积运算 自注意力与多头注意力

Transformer的自注意力与多头注意力让每个token看所有之前的token，计算量随长度n是n²，生成时的KV缓存也随长度线性增长。循环网络与隐状态每步只更新一个固定大小的状态，推理便宜，但训练时必须一步步串行算，难以利用GPU并行，长距离信息也容易衰减。状态空间模型（SSM）想兼得两者。

定义：来自控制论（见控制回路与控制频率）的线性系统，离散化后为

h_t = A·h_{t−1} + B·x_t，y_t = C·h_t

h是N维隐状态，A、B、C是矩阵。因为是线性的，可以把递推展开：y_t = Σ_k C·A^k·B·x_{t−k}，也就是用卷积核K = (CB, CAB, CA²B, …)对输入做卷积运算。于是同一个模型有两种算法：训练时整段序列用卷积（可借FFT）并行算；推理时用递推，每生成一个token只更新h。

关键是A怎么选。随便初始化的A要么让信息迅速衰减，要么数值爆炸。HiPPO推导出一类特殊的A，使状态h等价于对历史输入的最优多项式压缩；S4结构化状态空间（2021）给出高效计算方法，在需要上万步依赖的任务上大幅超过Transformer。

选择性：S4的A、B、C与输入无关，无法根据内容决定“记住什么、忘掉什么”，语言建模效果不如注意力。Mamba状态空间模型（2023）让B、C和离散化步长Δ随输入变化，卷积形式不再成立，改用并行扫描算法加速。Mamba-2与状态空间对偶进一步指出这类模型与线性注意力在数学上是对偶的。

现状：纯SSM在需要精确回忆上下文内容的任务上仍弱于注意力，主流做法是混合架构——大部分层用SSM或线性注意力，少数层保留完整注意力，如Jamba混合架构，以及采用Gated DeltaNet层的Qwen3-Next混合注意力。另见稀疏注意力与高效注意力。

例子

一维情形，A = 0.9，B = 1，C = 1，输入一个脉冲x = [1, 0, 0, 0]。

递推：h₁ = 1，h₂ = 0.9，h₃ = 0.81，h₄ = 0.729，输出y = [1, 0.9, 0.81, 0.729]。

卷积核K = (CB, CAB, CA²B, CA³B) = (1, 0.9, 0.81, 0.729)，用它卷积输入得到完全相同的结果。|A| < 1决定了过去信息按0.9^k衰减；Mamba让这类衰减率随当前输入变化，遇到重要内容时可以几乎不衰减。

容易误解的地方

  • 固定大小的状态意味着有损压缩：序列很长时，模型不可能逐字记住所有内容，这是它在复制、检索类任务上弱于注意力的根本原因。
  • 推理时“常数内存”是对每层而言，总显存仍取决于层数和状态维度。
  • SSM、线性注意力、线性RNN在近年的研究中逐渐统一，不同名字往往指非常接近的东西。
