学习曲线与训练曲线

Learning Curves and Training Curves

也叫：学习曲线　learning curve　learning curves　训练曲线　training curve　损失曲线　loss curve　验证损失　validation loss　训练损失　training loss　验证曲线　validation curve　损失尖峰　loss spike　训练诊断　training diagnostics

训练时最该盯着看的图：横轴是训练步数（或数据量），纵轴是训练损失和验证损失。两条曲线的走势能告诉你是在欠拟合、过拟合、学习率不合适，还是训练出了故障。

先要会：泛化与过拟合 损失函数

训练一个模型，最先要学会读的不是论文里的结果表格，而是训练曲线。“学习曲线”一词有两种用法，都很常用：

  • 横轴是训练步数或轮数，纵轴是损失或指标（训练曲线、损失曲线）；
  • 横轴是训练集大小，纵轴是训练和验证误差（狭义的学习曲线），用来判断“再加数据有没有用”。

怎么读训练曲线。

  • 训练损失和验证损失都高、而且都不再下降：欠拟合，模型容量不够或训练不够（见模型容量与欠拟合）。
  • 训练损失持续下降，验证损失先降后升：过拟合，应考虑早停、正则化与权重衰减或更多数据（见泛化与过拟合）。
  • 两者之间的差距就是泛化差距（见经验风险最小化）。
  • 损失剧烈震荡或突然变成NaN：学习率太大或数值问题（见学习率与学习率调度和数值稳定性：上溢、下溢与条件数）。
  • 损失几乎不动：学习率太小、梯度消失、标签与输入没对齐，或数据管线有bug（见梯度消失与梯度爆炸）。
  • 学习率衰减时损失会突然下一个台阶，这是正常现象。
  • 大模型训练中偶尔出现的损失尖峰，可能需要回滚到之前的检查点并跳过部分数据。

狭义学习曲线：要不要加数据。随训练集增大，如果验证误差还在明显下降、且与训练误差有较大差距，说明加数据有用；如果两条曲线已经汇合在一个较高的水平，加数据帮助不大，需要更大的模型。大模型时代把这件事做成了定量规律：深度学习规模可预测发现多个任务的学习曲线在对数坐标下近似直线，损失随数据量、参数量和计算量按幂律下降（语言模型的规模定律、Chinchilla，见幂律与规模定律）。

要注意的“反常”曲线。双下降：验证误差随模型大小或训练轮数先升后降；Grokking：训练准确率早已100%，验证准确率在很久之后才突然上升。都说明“看到验证损失上升就停”并非总是对的。

工具。TensorBoard可视化、Matplotlib绘图库和实验追踪平台（实验追踪：W&B与MLflow）用于实时记录和画图；画图时常对损失做指数移动平均平滑，以便看清趋势。

例子

训练一个文本分类器，每轮记录(训练损失, 验证损失)：(1.20, 1.25)、(0.80, 0.90)、(0.55, 0.72)、(0.40, 0.68)、(0.28, 0.70)、(0.18, 0.76)、(0.10, 0.85)。第4轮后验证损失开始回升，训练损失还在快速下降，差距从0.05扩大到0.75，是典型的过拟合，最好的检查点在第4轮。

容易误解的地方

  • 训练损失通常在开启dropout、数据增强的情况下计算，验证损失则关闭它们，所以训练损失高于验证损失并不罕见，不一定说明有bug。
  • 只看损失不看最终指标可能被误导：验证损失略升时，准确率有时仍在上升（模型变得更自信，错的样本损失变大）。
