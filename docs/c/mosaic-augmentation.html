Mosaic数据增强

Mosaic Augmentation

也叫：Mosaic　Mosaic增强　Mosaic数据增强　mosaic augmentation　马赛克增强　四图拼接　Mosaic-9　复制粘贴增强　copy-paste augmentation　close mosaic　关闭Mosaic　检测数据增强　detection augmentation

目标检测的数据增强：把四张训练图各自随机缩放裁剪后拼成一张2×2拼贴，标注框随之变换。一张图里多种场景和大量小目标同时出现，YOLOv4起成为实时检测器标配。

先要会：数据增强 分类、检测、分割

数据增强里，翻转、裁剪、调色是对一张图做变换；Mixup、CutMix开始把两张图混在一起。Mosaic更进一步：一次用四张图。

做法。

1. 在输出画布（如640×640）上随机选一个拼接中心点(x_c, y_c)，把画布分成左上、右上、左下、右下四块； 2. 随机取四张训练图，各自随机缩放后填入四块区域，超出部分裁掉； 3. 每张图的标注框按同样的缩放和平移变换，被裁掉大半的框丢弃或截断； 4. 通常再接随机仿射变换、色彩扰动等其他增强。

为什么有效。

  • 上下文多样：物体出现在不同于原图的背景和邻居旁边，模型不容易依赖固定的场景上下文。
  • 更多小目标：四张图缩小后拼在一起，物体普遍变小，正好补充检测中最难的小目标样本。
  • 相当于更大的批次：一张Mosaic图包含四张图的信息，归一化层中BatchNorm的统计量一次就覆盖了更多样本，单卡批次较小时也能训练得不错（YOLOv4论文强调了这一点）。

出处与流行。Mosaic在YOLOv4（2020）中作为“免费技巧包”的一项正式提出，随后被Ultralytics YOLO系列、YOLOX无锚框YOLO、YOLOv7、RTMDet实时检测等几乎所有实时检测器采用（见实时目标检测）。常见变体有MixUp与Mosaic叠加、九宫格的Mosaic-9，以及“复制–粘贴”（把一张图里分割好的物体贴到另一张图上）。

训练末期关闭。Mosaic生成的图像与真实测试图像分布不同（拼接边界、不自然的尺度），所以很多检测器在最后若干轮关掉Mosaic，用原始图像微调，让模型适应真实分布（YOLOX等的做法）。

例子

输出640×640，拼接中心随机取在(300, 360)。左上块300×360放图A（缩放后取其右下部分），右上块340×360放图B，左下块300×280放图C，右下块340×280放图D。图A中原本位于(500, 400)、大小100×80的一辆车，若图A被缩放0.5倍、整体平移(−50, 100)，新框位于(200, 300)、大小50×40，跨在左上块的边界附近，超出拼接区域的部分被截断。

容易误解的地方

  • Mosaic会切断靠近拼接边界的物体，产生只剩一小部分的“残框”；需要设一个最小面积或可见比例阈值把它们丢掉，否则会引入噪声标签。
  • 对分类任务或依赖完整场景上下文的任务（如场景理解），这种拼接可能有害。
