参数初始化

Weight Initialization

也叫：权重初始化　Xavier初始化　Glorot初始化　He初始化　Kaiming初始化　init

在交互版中打开（看它长在树上的哪里）

训练开始前给网络权重赋的随机初值。好的初始化让信号和梯度逐层传递时方差保持稳定，否则深层网络可能一开始就训练不动。

先要会：期望与方差 梯度消失与梯度爆炸 神经元与激活函数

梯度下降要从某个起点出发。起点看似无关紧要，但对深层网络它决定了训练能否开始。

不能全设为0（或任何相同值）：同一层所有神经元收到同样的输入、算出同样的输出、得到同样的梯度，更新后仍然一模一样，一百个神经元等于一个。所以权重必须随机初始化，用来“打破对称”。

随机的尺度很关键。一个神经元的输入是z = Σ_{i=1}^{n} w_i·x_i。若w和x独立、均值为0，则

Var(z) = n · Var(w) · Var(x)

如果Var(w) = 1，每过一层方差放大n倍，几十层后数值溢出；如果太小，信号逐层缩到0。这就是前向版本的梯度消失与梯度爆炸，反向的梯度也同理。要让方差逐层不变，就要Var(w) ≈ 1/n。具体有几种常用方案：

  • Xavier/Glorot初始化：Var(w) = 2/(n_in + n_out)，兼顾前向和反向，适合tanh等对称激活，见Xavier初始化。
  • He初始化：ReLU会把一半输入置0，方差减半，所以用Var(w) = 2/n_in补回来，见He初始化与PReLU。它让ResNet时代的深层ReLU网络可以直接训练。
  • 正交初始化：用随机正交矩阵，保持向量长度不变，见深度线性网络与正交初始化。

它出现在哪里：2006年前后人们用逐层无监督预训练（深度信念网络）来获得好的起点；Xavier初始化和ReLU普及之后，直接随机初始化就能训练深层网络。今天的大模型还会对残差分支的输出层再按层数缩小初值；μP与超参数迁移则系统研究了初始化和学习率应如何随模型宽度缩放。

例子

一层有n = 512个输入，输入的方差为1。

  • 若权重取标准正态（方差1），输出标准差约√512 ≈ 22.6；不加激活直接叠10层，标准差放大到512⁵ ≈ 3.5×10¹³倍。
  • 若权重标准差取1/√512 ≈ 0.044，每层输出标准差保持在1左右。
  • ReLU网络按He初始化，标准差取√(2/512) = 0.0625。

容易误解的地方

  • 有了归一化层后，网络对初始化尺度不再那么敏感，但并非完全无关，大模型训练不稳定时常要回头检查初始化。
  • 偏置通常初始化为0，这不会造成对称问题，因为权重已经是随机的。
