最佳响应与可利用度

Best Response and Exploitability

也叫：最佳响应　最优反应　最佳应对　best response　BR　可利用度　可剥削度　exploitability　NashConv　纳什收敛度　近似最佳响应　approximate best response

在交互版中打开（看它长在树上的哪里）

最佳响应是“已知对手策略时对我最有利的策略”；可利用度衡量一个策略被最佳响应针对时会输多少。纳什均衡就是人人都在对别人做最佳响应、可利用度为0的状态。

先要会：博弈论基础与纳什均衡

在博弈里说一个策略“强”，必须问：相对于谁？一个围棋程序可能击败所有人类，却被一个专门针对它的对抗策略打败（见对抗策略击败超人围棋AI）。博弈论用两个概念回答这个问题。

最佳响应（best response）。固定其他人的策略π₋ᵢ，让玩家i的期望收益最大的策略：

BR_i(π₋ᵢ) = argmax_{π_i} u_i(π_i, π₋ᵢ)

当对手策略固定时，求最佳响应就是一个单智能体的优化问题（对手成了环境的一部分），可以用规划或强化学习求解。博弈论基础与纳什均衡可以等价地定义为：每个玩家的策略都是对其他人策略的最佳响应。

可利用度（exploitability）。两人零和博弈中，策略组合π = (π₁, π₂)的可利用度通常定义为

expl(π) = [u₁(BR(π₂), π₂) + u₂(π₁, BR(π₁))] / 2

即每一方被对方最佳响应针对时的平均收益（零和时等价于各自相对均衡值的损失）。纳什均衡的可利用度为0；值越大，策略离均衡越远。多人博弈中常用它的推广NashConv：各玩家“改用最佳响应能多赚多少”之和。

为什么重要。

  • 评测：在扑克等不完全信息博弈里，与几个对手打比赛的胜负波动很大，也可能只是恰好克制了对方；可利用度给出与对手无关的强度衡量。反事实遗憾最小化CFR系列算法的进展常以可利用度下降来报告；完整的最佳响应在大型博弈中算不动，局部最优反应LBR给出近似下界。
  • 算法：虚拟对弈反复对对手的历史平均策略做最佳响应；PSRO博弈论元求解维护一个策略种群，每轮训练一个对种群混合策略的近似最佳响应（常用深度RL）加入种群，AlphaStar的联盟训练中也有专门的“利用者”智能体。
  • 安全性：自我对弈得到的策略可能有被针对的盲点，最佳响应搜索是检验它们的方法，见自我对弈。

例子

石头剪刀布，赢+1、输−1、平0。对手出石头、布、剪刀的概率为(0.5, 0.25, 0.25)。我出布的期望收益为0.5×1 + 0.25×0 + 0.25×(−1) = 0.25，出石头为0，出剪刀为−0.25，所以最佳响应是“一直出布”，对手这个策略的可利用度（被针对时的损失）是0.25。均匀随机(1/3, 1/3, 1/3)时任何策略的期望收益都是0，可利用度为0，这正是纳什均衡。

容易误解的地方

  • 可利用度低不等于在实战中赢得最多：对弱对手，均衡策略不会主动去剥削对方的错误，有针对性的策略可能赢得更多。
  • 最佳响应通常是确定性的、很极端的策略，它本身往往高度可利用，所以“一直对最新对手做最佳响应”会陷入循环，需要像虚拟对弈那样对历史取平均。
