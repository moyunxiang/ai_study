Dice系数与Dice损失

Dice Coefficient and Dice Loss

也叫：Dice系数　Dice coefficient　Dice score　Dice相似系数　DSC　Dice损失　Dice loss　soft Dice　软Dice　Sørensen-Dice　F1分割　分割指标

Dice系数衡量预测区域与真实区域的重合程度：2×交集 ÷ (两者面积之和)，等价于像素级的F1分数。把它做成可导的“软”版本就是Dice损失，在前景很小的分割任务（如医学图像）里特别常用。

先要会：准确率、精确率、召回率与F1 IoU与mAP 分类、检测、分割

语义分割常用逐像素的交叉熵训练。但在一张512×512的CT切片里，肿瘤可能只占几百个像素，背景占99%以上。逐像素交叉熵被背景主导：模型把所有像素都判成背景，损失就已经很低。我们真正关心的是“前景区域找得准不准”，这正是Dice系数衡量的。

Dice系数。预测区域A、真实区域B：

Dice = 2·|A ∩ B| / (|A| + |B|)

用分类的术语，Dice = 2TP / (2TP + FP + FN)，正是前景类的F1分数（见准确率、精确率、召回率与F1）。它与IoU与mAP里的IoU单调对应：Dice = 2·IoU / (1 + IoU)，所以二者排名一致，但Dice的数值总是不低于IoU。只关心前景像素，背景再多也不影响它。

Dice损失。硬的0/1区域不可导。把预测改成每个像素的前景概率p_i，真实标签g_i ∈ {0, 1}，得到软Dice：

L_Dice = 1 − (2·Σ_i p_i·g_i + ε) / (Σ_i p_i + Σ_i g_i + ε)

ε是一个很小的平滑项，防止前景为空时除以0。多类别时对每类分别计算再平均。这种损失随V-Net等医学图像分割工作流行起来，常与U-Net一起使用。

组合使用。Dice损失的梯度在训练初期可能不稳定，实践中常与交叉熵或focal损失（见Focal Loss与RetinaNet）相加；Segment Anything训练掩码预测时就用了focal损失与Dice损失的组合。评估时用的Dice是按阈值二值化后的硬版本。

例子

真实肿瘤区域100个像素，模型预测了90个像素，其中80个与真实区域重合。Dice = 2×80 / (90 + 100) = 160/190 ≈ 0.84；IoU = 80 / (90 + 100 − 80) = 80/110 ≈ 0.73，满足0.84 ≈ 2×0.73/1.73。若模型把整张512×512的图都判成背景，像素准确率高达99.96%，但Dice为0。

容易误解的地方

  • 一张图里真实前景为空时，Dice的取值取决于平滑项的约定（预测也为空时是1还是0），评估代码之间常不一致。
  • 按整个数据集汇总计算的Dice与先逐图计算再平均的Dice可能差别很大，报告时要说明。
