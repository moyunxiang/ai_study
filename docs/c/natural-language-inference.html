自然语言推理与文本蕴含

Natural Language Inference

也叫：NLI　natural language inference　自然语言推断　文本蕴含　textual entailment　RTE　recognizing textual entailment　蕴含识别　entailment　contradiction　前提与假设　premise hypothesis

在交互版中打开（看它长在树上的哪里）

给定一个前提句和一个假设句，判断前提是否能推出假设：蕴含、矛盾，还是无法判断（中立）。也叫文本蕴含识别，是检验模型语言理解的经典任务。

先要会：监督学习 基准、排行榜与SOTA

理解一句话，很大一部分体现在知道它意味着什么、不意味着什么。“一个男人在弹吉他”意味着“有人在演奏乐器”，与“这个人在睡觉”矛盾，对“他是职业音乐家”则无法下结论。把这种判断做成一个分类任务，就是自然语言推理（NLI），早期叫文本蕴含识别（RTE）。

定义。输入前提P和假设H，输出三类之一：

  • 蕴含（entailment）：一般人读了P会认为H为真。
  • 矛盾（contradiction）：P为真时H不可能为真。
  • 中立（neutral）：P既不支持也不排除H。

这里的“推出”是日常理解意义上的，不是严格的逻辑证明（见命题逻辑、谓词逻辑与符号推理）。

数据集。RTE文本蕴含挑战挑战赛从2005年起提供了几千条人工构造的样本，规模小。SNLI（2015）让众包工人看着图片描述写出三类假设，收集了约57万对，第一次足以训练神经网络；MultiNLI扩展到多种文体；XNLI把评测扩展到十几种语言；对抗式NLI让人专门写能骗过当时模型的样本，分几轮迭代变难。MNLI和RTE都是GLUE / SuperGLUE基准的组成部分。

捷径问题。后来的研究发现，模型可以不怎么读前提就猜对不少：标注伪影显示，众包工人写“矛盾”假设时常用“没有”“从不”等否定词，只看假设句就能远高于随机地猜中标签；HANS启发式诊断构造了词汇高度重叠但不构成蕴含的句子，暴露出模型依赖“词重叠多就是蕴含”的启发式。这类发现推动了对抗式数据集和更严格的评测（见基准、排行榜与SOTA）。

用在哪里。

  • 句子表示：InferSent用SNLI训练句子编码器，得到通用的句向量（见句向量与文本嵌入）。
  • 零样本分类：把“这段话讲的是体育”当作假设，用NLI模型判断是否被原文蕴含，就能对任意标签做分类。
  • 事实核查与幻觉检测：判断生成的回答是否被检索到的原文蕴含（见有据生成与引用），是很多忠实度指标的做法。

例子

前提：“一位穿红衣服的女士正在公园里跑步。”

  • 假设“一个人在户外运动。”→ 蕴含。
  • 假设“这位女士正坐在家里看电视。”→ 矛盾。
  • 假设“这位女士在为马拉松做准备。”→ 中立（可能是，也可能不是）。

用作零样本分类：前提为一条新闻“球队在加时赛中逆转取胜”，依次构造假设“这段话与体育有关”“这段话与财经有关”，取蕴含概率最高的标签作为分类结果。

容易误解的地方

  • 三分类准确率很高，不代表模型掌握了推理；先用只看假设句的基线检查数据有没有捷径。
  • 不同标注者对“中立”和“蕴含”的边界常有分歧，部分样本本身就没有唯一正确答案。
