单应性矩阵

Homography

也叫：单应性　单应性矩阵　单应矩阵　homography　homography matrix　射影变换　projective transformation　透视变换　perspective transform　DLT　直接线性变换　全景拼接　image stitching　逆透视变换　IPM　透视校正

在交互版中打开（看它长在树上的哪里）

两张图之间的一种3×3射影变换，在齐次坐标下把一张图的点映射到另一张图。当拍摄的是一个平面，或相机只旋转不平移时，两张照片恰好由单应性联系，常用于全景拼接、图像校正和平面增强现实。

先要会：相机模型与多视图几何 矩阵乘法与线性变换

把手机转一圈拍几张照片拼成全景图、把斜着拍的文档“拉正”、在桌面上叠一个虚拟物体，背后都是同一个数学工具：单应性（homography）。

定义。用齐次坐标(x, y, 1)表示像素，单应性是一个3×3矩阵H：

λ·(x', y', 1)ᵀ = H · (x, y, 1)ᵀ

即x' = (h₁₁x + h₁₂y + h₁₃) / (h₃₁x + h₃₂y + h₃₃)，y'同理。H只在相差一个比例因子的意义下确定，所以有8个自由度。它包含了平移、旋转、缩放、剪切（仿射变换）以及“近大远小”的透视变形，直线映射后仍是直线，但平行线可能不再平行。

什么时候成立。在相机模型与多视图几何的针孔模型下，一般场景中两张图的对应关系依赖每个点的深度，不能用一个矩阵描述。但有两种重要的特殊情况：

  • 场景是一个平面（墙、桌面、文档、地面），相机可以任意移动；
  • 相机只旋转、不平移（原地转身拍全景），场景可以任意。

这时两张图之间严格满足单应性。

怎么估计。每对对应点给出两个方程，所以至少需要4对点（且其中任意3点不共线），用直接线性变换（DLT）通过特征分解与奇异值分解求解。实际匹配中有大量错误配对，所以先用SIFT特征或SuperPoint等特征匹配，再用RANSAC随机抽4对点拟合H、统计符合的内点数，重复多次选内点最多的结果。

它出现在哪里。全景拼接和图像对齐；相机标定时从棋盘格平面估计内参；自动驾驶中把前视图像投影到地面俯视图（逆透视变换）；文档扫描的透视校正；SuperPoint的训练还用随机单应性变换来合成训练图像对。系统讲解见《多视图几何》。

例子

一张纸的四个角在照片里位于(100, 120)、(520, 90)、(560, 470)、(80, 430)，想把它校正为400×300的矩形，对应(0, 0)、(400, 0)、(400, 300)、(0, 300)。4对点正好确定8个自由度，解出H后对矩形内每个目标像素用H⁻¹反查原图位置并插值，就得到“拉正”的扫描图。

容易误解的地方

  • 场景有明显的深度变化且相机发生平移时，用一个单应性对齐会产生重影，这在全景拼接中表现为错位的近景物体。
  • 4个点里有3点近乎共线时，H的估计极不稳定。
