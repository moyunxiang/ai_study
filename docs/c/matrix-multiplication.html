矩阵乘法与线性变换

Matrix Multiplication

也叫：matmul　GEMM　linear transformation　线性映射　矩阵相乘

在交互版中打开（看它长在树上的哪里）

矩阵乘法把一批内积打包成一次运算；把矩阵乘到向量上，就是对向量做一次线性变换。神经网络的绝大部分计算量都是矩阵乘法。

先要会：向量、矩阵与张量 内积与余弦相似度

神经网络的一层要把输入向量变成输出向量，而且每个输出都是全部输入的加权和。把这些权重排成一个矩阵，这一层的计算就是一次矩阵乘以向量。理解了矩阵乘法，就理解了网络里大部分计算在做什么、为什么GPU能加速它。

定义。m×n矩阵A乘以n×p矩阵B，得到m×p矩阵C：

C_ij = Σ_k A_ik B_kj

即C的每个元素是A的第i行与B的第j列的内积与余弦相似度。前一个矩阵的列数必须等于后一个的行数。一共需要m·n·p次乘加。矩阵乘法满足结合律，但一般不满足交换律：AB ≠ BA。

线性变换的视角。y = Wx把n维向量x映射成m维向量y，这种映射满足W(ax + bz) = aWx + bWz，叫线性变换。旋转、缩放、投影都是线性变换。神经网络一层写作y = σ(Wx + b)：Wx负责线性地“混合”特征，b是偏置，σ是非线性神经元与激活函数。没有σ的话，多层叠起来W_2(W_1x) = (W_2W_1)x仍然只是一层线性变换，叠再多也没用。

批处理。一批B个样本排成矩阵X（B×n），一次XWᵀ就算完整批的输出。这样做把大量向量运算变成一次大矩阵乘法，正适合GPU。

它出现在哪里。BLAS线性代数接口把矩阵乘法（GEMM）定义成标准接口，几十年来被反复优化；V100与Tensor Core引入的Tensor Core是专门做小块矩阵乘的硬件单元；Transformer里的注意力和前馈层本质上都是若干次大矩阵乘法。计算量估算见参数量、计算量与显存和时间与空间复杂度。

例子

W = [[1, 0, 2], [0, 1, −1]]（2×3），x = (3, 1, 2)。Wx的第一个元素是1×3 + 0×1 + 2×2 = 7，第二个是0×3 + 1×1 + (−1)×2 = −1，所以Wx = (7, −1)，把3维向量变成了2维。规模感：一个4096×4096的权重矩阵乘一个向量，需要4096×4096 ≈ 1678万次乘加；乘一批1000个向量就是约168亿次。

容易误解的地方

  • 形状顺序很重要：(m×n)(n×p)才能乘。代码里常见的x @ W.T和W @ x只是向量横放还是竖放的不同约定。
  • 逐元素乘（Hadamard积，代码里的*）和矩阵乘（@）是两回事，混用不一定报错，但结果完全不同。
