低显存训练

Memory-Efficient Training

也叫：省显存训练　显存优化　memory-efficient training　梯度检查点　activation checkpointing　重计算　recomputation　优化器状态分片　ZeRO　8bit Adam　offload　CPU卸载　单卡训练大模型　消费级显卡微调

在交互版中打开（看它长在树上的哪里）

训练时显存被权重、梯度、优化器状态和激活值四样东西占满，这一类技巧分别对它们动刀，让更大的模型塞进有限的卡。

用Adam训练时，每个参数除了权重本身，还要存梯度和两份优化器状态，激活值又随批大小和序列长度增长。省显存的办法按对象分几类。

激活：梯度检查点只存部分层的激活，反向时重算其余部分，以多约三分之一的计算换显存。优化器状态与梯度：ZeRO与DeepSpeed把它们分片到各张卡上，PyTorch FSDP是PyTorch的对应实现；8比特优化器与bitsandbytes把优化器状态压到8比特；GaLore梯度低秩投影把梯度投影到低秩子空间，只在小空间里维护Adam状态。可训练参数：LoRA和QLoRA冻结原权重、只训练少量附加参数，QLoRA还把冻结的底座量化到4比特，让单卡微调数百亿参数模型成为可能。

这些手段常组合使用，Unsloth等工具把它们打包给个人开发者。
