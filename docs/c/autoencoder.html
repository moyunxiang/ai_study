自编码器

Autoencoder

也叫：AE　自动编码器　去噪自编码器　denoising autoencoder　瓶颈层　bottleneck

在交互版中打开（看它长在树上的哪里）

一个把输入压缩成短编码、再从编码还原输入的网络。训练目标就是“还原得像”，不需要任何标签，压缩出来的编码就是学到的表示。

先要会：多层感知机 损失函数 降维与PCA

大部分数据没有标签。能不能只靠数据本身学到有用的特征？一个办法是给网络出一道看似无聊的题：把输入原样输出。只要中间故意设一个狭窄的“瓶颈”，网络就没法死记硬背，只能学会抓住数据里最重要的规律，才能用少量数字还原出原样（见无监督学习）。

定义。

  • 编码器：z = f(x)，把高维输入x压缩成低维的编码z（也叫潜变量或瓶颈表示）。
  • 解码器：x̂ = g(z)，从z还原出x̂。
  • 损失：重建误差，例如均方误差L = ‖x − x̂‖²（见损失函数）。

f和g通常都是神经网络，一起用梯度下降训练。训练好后，往往只保留编码器，把z当作x的特征；或只保留解码器，把它当作从编码生成数据的工具。

和PCA的关系。如果f和g都是线性的、损失是均方误差，自编码器学到的编码空间与PCA的主成分空间相同（见降维与PCA）。非线性的自编码器可以看成PCA的非线性推广，能把数据压到弯曲的低维流形上。

几种重要的变体。

  • 深度自编码器（深度自编码器，2006）：Hinton等人用逐层预训练训练出深层自编码器，降维效果明显好于PCA，是深度学习复兴的起点之一。
  • 去噪自编码器（去噪自编码器）：输入加噪声或遮挡一部分，要求还原干净的原始输入。这样网络必须理解数据结构，不能只学恒等映射。这个思路后来变成了掩码建模，即BERT和掩码自编码器MAE。
  • 变分自编码器（变分自编码器VAE）：让z服从一个概率分布，从而可以随机采样z来生成新数据。
  • 潜空间压缩器：今天的图像和视频生成模型（如潜空间扩散LDM）先用一个自编码器把512×512的图像压缩到64×64×4的潜空间，再在潜空间里做扩散，每一步要处理的数字从786,432个降到16,384个，少了48倍。

例子

MNIST手写数字是28×28 = 784个像素。自编码器784 → 128 → 32 → 128 → 784，中间的z只有32个数，压缩比784/32 = 24.5倍。

训练时只用图像本身：输入一张“7”，输出一张784像素的重建图，用每个像素的平方误差之和作损失。训练好后，同为“7”的图像的z在32维空间里会聚在一起，即使训练从未告诉网络哪张图是几。

如果把瓶颈放宽到1000维（比输入还大），网络可以简单地把输入复制过去，重建误差接近0，但学不到任何有用的东西——瓶颈或者噪声这样的约束是必不可少的。

容易误解的地方

  • 重建得好不等于表示好用。一个能完美重建的编码，可能对分类等下游任务毫无帮助。
  • 普通自编码器的潜空间不规整，在z空间随便取一点，解码出来通常是一团乱码；能可靠采样生成需要VAE那样的概率约束。
  • 均方误差重建往往导致图像发糊，因为模型对不确定的细节会输出“平均值”。
