用特殊构造的提示、后缀、对话或微调，让已经做过安全对齐的模型输出它本应拒绝的内容。

ChatGPT发布后，网友很快用角色扮演提示（DAN越狱提示）绕过限制。安全训练为何失败把失败原因归为目标冲突和泛化不匹配；此后攻击方法分化成几条路线：白盒优化乱码后缀的自动化越狱攻击GCG，用攻击模型自动改写提示的PAIR黑盒越狱，利用长上下文的多样本越狱，逐轮升级的Crescendo多轮越狱，以及只靠大量随机变体的Best-of-N越狱。微调破坏安全对齐显示改权重比改提示更容易。

浅层安全对齐给出统一解释：对齐主要只改了回答开头几个词元。防御有输入输出分类器（Llama Guard安全分类器、宪法分类器）、表示层干预（熔断器：表示重定向）等，评测基准有HarmBench红队评测。自适应攻击击穿防御提醒：几乎所有防御在面对针对性设计的自适应攻击时都会失守。
