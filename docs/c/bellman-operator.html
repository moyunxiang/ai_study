Bellman算子与压缩映射

Bellman Operator and Contraction

也叫：Bellman算子　贝尔曼算子　Bellman operator　Bellman backup　Bellman备份　备份　压缩映射　contraction mapping　γ-压缩　不动点　fixed point　Banach不动点定理　投影Bellman算子　projected Bellman operator　Bellman残差　MSBE　均方Bellman误差

把“用Bellman方程右边算一遍”看成一个作用在价值函数上的映射，叫Bellman算子。它是γ-压缩映射，所以反复套用必然收敛到唯一的不动点，这是价值迭代和TD方法收敛的根据。

先要会：Bellman方程 范数与距离

价值迭代为什么从任意初值出发都能收敛？为什么一加上神经网络，同样的更新却可能发散？回答这两个问题需要换一个视角：不把Bellman方程看成一组等式，而看成一个算子。

定义。对任意价值函数V（可以看成一个长度为状态数的向量），定义

(T^π V)(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a)·[r(s,a) + γ·V(s')]

(T* V)(s) = max_a Σ_{s'} P(s'|s,a)·[r(s,a) + γ·V(s')]

做一次V ← TV就叫一次Bellman备份（backup）。V^π是T^π的不动点（T^π V^π = V^π），V*是T*的不动点。

压缩性。两者都满足

max_s |(TV)(s) − (TU)(s)| ≤ γ · max_s |V(s) − U(s)|

即每套用一次，任意两个价值函数之间的最大差距至少缩小为原来的γ倍。由Banach不动点定理，压缩映射有唯一的不动点，迭代从任何起点出发都以几何速度收敛：k次后误差不超过γ^k乘以初始误差。策略评估、策略迭代与价值迭代的收敛性就来自这里，Q函数上的同名算子也一样。

Bellman残差。TV − V衡量V离满足方程还差多少，它的均方值叫均方Bellman误差（MSBE），是很多算法的损失函数，例如DQN的损失就是采样版本的Bellman残差平方。

有了函数逼近之后。神经网络或线性函数只能表示一部分价值函数，每次备份后还要“投影”回可表示的集合：V ← Π T V。投影和T各自都不扩张，但在离策略的数据分布下，二者合起来可能不再是压缩，迭代就可能发散。Baird反例与发散问题给出了线性情形下发散的具体例子，线性TD收敛性分析证明了同策略线性TD仍收敛，梯度TD（GTD/TDC）则改为直接最小化投影Bellman误差。这正是致命三元组的数学根源，见强化学习中的函数逼近。

例子

γ=0.9，初始V与V*的最大误差为10。套用10次后误差不超过10×0.9^10 ≈ 3.5，50次后不超过10×0.9^50 ≈ 0.05。γ=0.99时同样要达到0.05，大约需要530次，所以γ越接近1，价值迭代和TD学习都越慢。

容易误解的地方

  • 压缩性是对最大范数（逐状态取最大差）而言的，不是对通常的均方误差；用均方误差训练的神经网络不继承这个保证。
  • 最小化Bellman残差和求不动点并不总是一回事：随机环境下直接最小化采样残差会引入偏差（需要同一状态的两次独立采样，即double sampling问题）。
