上采样与转置卷积

Upsampling and Transposed Convolution

也叫：上采样　upsampling　转置卷积　transposed convolution　反卷积　deconvolution　上卷积　up-convolution　fractionally-strided convolution　ConvTranspose2d　双线性插值　bilinear interpolation　最近邻插值　nearest neighbor upsampling　像素重排　PixelShuffle　pixel shuffle　亚像素卷积　sub-pixel convolution　棋盘格伪影　checkerboard artifacts　解码器上采样

把小特征图放大成大特征图的操作，分割、超分辨率和图像生成的解码器都离不开它。常用插值（最近邻、双线性）、转置卷积（反卷积）和像素重排。

先要会：卷积层、池化与感受野 卷积运算

分类网络一路下采样，把224×224的图压到7×7（见卷积层、池化与感受野）。可语义分割要给每个像素一个标签，超分辨率要输出更大的图，生成模型的解码器要从小的隐变量画出整张图像，这些都需要反方向的操作：上采样。

插值上采样。没有可学习参数：最近邻插值把每个像素复制成2×2块；双线性插值按周围4个像素的距离加权平均，结果更平滑。常见用法是“先插值放大，再接一个普通卷积”去修正细节。

转置卷积（transposed convolution，常被叫作“反卷积”，但它并不是卷积的逆运算）。普通卷积可以写成一个矩阵乘法y = Cx，把高分辨率的x映射成低分辨率的y；转置卷积用Cᵀ，把低分辨率映射回高分辨率的形状，而且卷积核是可学习的。直观上，它把输入的每个像素乘以卷积核，“盖章”到输出的对应位置，重叠处相加。步长为2时输出边长约为输入的2倍。它的反向传播与普通卷积的反向传播完全一样，这也是名字的由来。

棋盘格伪影。转置卷积的核大小不能被步长整除时，输出上有的位置被“盖章”的次数多、有的少，生成的图像会出现规则的格子状纹理。这是DCGAN类生成器的常见问题，所以很多后来的模型改用“插值 + 卷积”。

像素重排（PixelShuffle / 亚像素卷积）。先用普通卷积在低分辨率上输出C·r²个通道，再把每r²个通道重新排列成一个r×r的空间块，边长放大r倍。计算都在小尺寸上进行，效率高，常用于超分辨率（如SRGAN、ESRGAN）。

它出现在哪里。

  • 全卷积网络FCN首次用转置卷积把分类网络改造成逐像素预测；U-Net的解码器每一级上采样后与编码器同尺寸的特征拼接（跳跃连接），恢复细节；SegNet用池化时记录的最大值位置来上采样。
  • DeconvNet反卷积分割用“反卷积网络”把中间特征映射回像素空间，用于可视化CNN学到了什么。
  • 扩散模型的U-Net和潜空间扩散LDM的VAE解码器都由多级上采样组成。
  • 转置卷积的“对偶”是空洞卷积：后者不下采样也能扩大感受野（DeepLab空洞卷积），从源头上减少了对上采样的需求。

例子

输入2×2的特征图[[1, 2], [3, 4]]，放大2倍。

  • 最近邻：[[1, 1, 2, 2], [1, 1, 2, 2], [3, 3, 4, 4], [3, 3, 4, 4]]。
  • 转置卷积（核2×2全为1，步长2）：每个输入像素盖一个2×2的章，恰好不重叠，结果与最近邻相同；若改用3×3核、步长2，相邻的章有一行一列重叠，重叠处的值相加，便出现了棋盘格的雏形。
  • PixelShuffle（r = 2）：输入4通道×2×2，重排成1通道×4×4。

容易误解的地方

  • “反卷积”是误称：转置卷积只恢复形状，不能恢复被卷积丢失的信息，Cᵀ一般也不是C的逆。
  • 输出尺寸公式(H − 1)·s − 2p + k（另加output_padding）容易算错，与编码器的特征图拼接前要核对形状。
