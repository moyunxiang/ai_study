次梯度与不可导点

Subgradients and Nonsmooth Optimization

也叫：次梯度　subgradient　次微分　subdifferential　次梯度法　subgradient method　不可导　非光滑优化　nonsmooth optimization　近端梯度　proximal gradient　近端算子　proximal operator　软阈值　soft thresholding　ISTA

函数在折点处没有导数时的替代品：所有“贴在函数下方的切线”的斜率都叫次梯度。它让ReLU、L1正则、合页损失这类不可导函数也能用梯度方法优化。

先要会：导数、偏导与梯度 凸函数与凸优化

机器学习里很多常用函数并不处处可导：|x|在0处有个尖角，ReLU max(0, x)在0处折了一下，合页损失与间隔类损失的max(0, 1 − y·f(x))在间隔边界上也是折线。可梯度下降要的是导数，这些点怎么办？

次梯度的定义。对凸函数f，如果向量g满足对所有y：

f(y) ≥ f(x) + gᵀ(y − x)

就说g是f在x处的一个次梯度。几何上，过点(x, f(x))、斜率为g的直线（超平面）整个位于函数图像下方。函数在x可导时，次梯度只有一个，就是梯度；在尖角处有一整个区间的次梯度，合称次微分∂f(x)。例如|x|在0处的次微分是区间[−1, 1]。

次梯度法。用任意一个次梯度代替梯度：x ← x − η·g。它有两点与梯度下降不同：一是不保证每一步函数值都下降；二是学习率必须逐渐减小（如η_t ∝ 1/√t）才能收敛，收敛也更慢。对凸函数，最优性条件变成“0属于次微分”：0 ∈ ∂f(x*)。

L1正则与近端方法。Lasso与L1稀疏在损失上加λ‖w‖₁。用次梯度法做，权重会在0附近来回跳，很难恰好等于0。近端梯度法把可导部分和L1部分分开处理：先对可导部分走一步梯度，再做“软阈值”w ← sign(w)·max(|w| − ηλ, 0)，绝对值小于ηλ的权重被直接置0，这才得到真正稀疏的解（见正则化与权重衰减）。

深度学习框架里的做法。PyTorch等框架遇到ReLU在0处，直接取导数为0（也就是次微分[0, 1]里的一个值）。由于输入恰好等于0的概率几乎为零，这个选择几乎不影响训练。AdaGrad的原论文标题就叫“自适应次梯度方法”，它的分析正是在次梯度框架下做的。

例子

f(x) = |x|，在x = 0处，斜率在[−1, 1]之间的任何直线y = gx都在|x|下方，所以次微分是[−1, 1]；0属于它，说明0是最小点。

软阈值：w = 0.3、ηλ = 0.5时，max(0.3 − 0.5, 0) = 0，w被置0；w = 2时变为1.5，只缩小不归零。

容易误解的地方

  • 次梯度是为凸函数定义的；ReLU网络整体非凸，框架里“在折点取某个值”的做法只是工程约定，严格的推广叫Clarke次微分。
  • 负次梯度方向不一定是下降方向，所以次梯度法里不能用“函数值是否下降”来判断步长是否合适。
