对齐审计

Alignment Auditing

也叫：alignment audit　对齐审计　pre-deployment audit　部署前审计　自动化审计　automated auditing　审计智能体　auditing agent　Petri　行为审计　系统卡　system card　第三方评测

在交互版中打开（看它长在树上的哪里）

在模型发布前系统地查它有没有隐藏目标、欺骗、自保、谄媚等问题，正在从人工检查走向由AI智能体自动审计。

能力评测问的是“模型能做什么”，对齐审计问的是“模型想做什么、会不会做坏事”。审计隐藏目标用一场审计游戏建立了方法：先造一个带已知隐藏目标的模型，再看审计团队能否找出来。智能体失准与勒索实验用精心设计的公司场景揭示勒索等行为，Anthropic与OpenAI互评对齐是两家实验室互相审计对方模型的首次尝试。

规模化依靠自动化：Petri自动审计工具让审计智能体根据一句种子指令自动设计场景并打分，自动化对齐研究员让AI研究员处理已知的对齐失败。主要难点是评测意识：模型若认出自己在被审计，结果就可能偏乐观。
