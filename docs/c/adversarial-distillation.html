对抗蒸馏与GAN的回归

Adversarial Distillation and the Return of GANs

也叫：对抗蒸馏　Adversarial Distillation　对抗扩散蒸馏　ADD　LADD　Turbo模型　SDXL Turbo　SD3-Turbo　GAN复兴　GAN is back　对抗后训练　Adversarial Post-Training　判别器损失

在交互版中打开（看它长在树上的哪里）

扩散模型取代GAN之后，判别器又以“蒸馏损失”的身份回来，帮扩散模型压到一两步出图。

2020年后DDPM系扩散模型全面取代生成对抗网络GAN，但扩散模型慢，而GAN的长处恰是一次前向出图。于是出现两条线。

一条是对抗蒸馏：对抗扩散蒸馏SDXL Turbo（SDXL Turbo）用判别器加分数蒸馏把SDXL压到1–4步；潜空间对抗蒸馏LADD改用扩散模型自身的潜空间特征做判别器，把SD3蒸成4步的SD3-Turbo；DMD2改进分布匹配蒸馏在分布匹配蒸馏里加入GAN损失，让学生直接从真实图像学习。

另一条是GAN本身的再审视：GigaGAN证明GAN可以放大到文生图；R3GAN现代GAN基线推导出有收敛保证的正则化相对论GAN损失，去掉一堆历史技巧后仍超过StyleGAN2。

争论在于：对抗损失能显著提升少步样本的锐度，但也带回了GAN的老问题（模式坍塌与模式覆盖、训练不稳），因此常与分数蒸馏等更稳定的目标配合使用。
