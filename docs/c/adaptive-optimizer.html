自适应学习率优化器

Adaptive Optimizers

也叫：Adam　AdamW　AdaGrad　RMSProp　自适应优化器　optimizer

在交互版中打开（看它长在树上的哪里）

给每个参数单独调整步长的优化器：根据该参数过去梯度的大小自动缩放，梯度一直很大的参数走小步，很小的走大步。代表是Adam。

先要会：梯度下降 动量 学习率与学习率调度

梯度下降对所有参数用同一个学习率与学习率调度。但神经网络里不同参数的梯度量级可能差上千倍：常见词的嵌入向量每步都有大梯度，罕见词的嵌入很少被更新、梯度又小。统一的学习率要么让前者震荡，要么让后者几乎不动。

自适应优化器的思路是：记录每个参数梯度平方的历史，用它的平方根去除当前梯度，把每个参数的步长“归一化”。

  • AdaGrad（AdaGrad）：累加全部历史梯度平方s ← s + g²，更新θ ← θ − η·g/√s。缺点是s只增不减，学习率越来越小，最后停住。
  • RMSProp（RMSProp）：改用指数滑动平均s ← ρ·s + (1−ρ)·g²，只记住最近一段时间。
  • Adam（Adam）：再加上动量。一阶矩m ← β₁m + (1−β₁)g，二阶矩v ← β₂v + (1−β₂)g²，做偏差修正m̂ = m/(1−β₁ᵗ)、v̂ = v/(1−β₂ᵗ)后更新θ ← θ − η·m̂/(√v̂ + ε)。常用β₁ = 0.9、β₂ = 0.999。偏差修正是因为m、v从0开始，前几步会被低估。

AdamW（AdamW）指出在Adam里把L2正则加进梯度，会被√v̂一起缩放，效果与真正的权重衰减不同，于是把衰减项从梯度里拿出来单独执行。今天训练Transformer和大语言模型的默认选择基本是AdamW。

代价是显存：Adam要给每个参数额外存m和v两份状态，Adafactor、ZeRO等工作都在想办法省这部分内存。近年的Muon优化器等优化器则尝试按矩阵整体处理梯度，挑战AdamW的默认地位。

例子

两个参数的梯度一直分别是100和0.01，学习率η = 0.001。

  • 普通SGD：一步分别移动0.1和0.00001，相差一万倍。
  • Adam第一步：m̂ = g，v̂ = g²，所以m̂/√v̂对两个参数都等于1，两者都移动约0.001。

可以看到Adam的单步移动量大致由η决定，与梯度的绝对大小无关，这也是它对学习率设定相对不敏感的原因。

容易误解的地方

  • 在不少图像分类任务上，调得好的SGD+动量的最终精度可以与Adam持平甚至更好；Adam的优势主要是对超参数更宽容、在Transformer上更稳定。
  • ε不只是防止除零，在梯度极小时它决定步长上限，有些训练不稳定与ε的取值有关。
