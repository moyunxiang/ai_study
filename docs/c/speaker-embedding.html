说话人嵌入与说话人验证

Speaker Embeddings and Verification

也叫：说话人嵌入　speaker embedding　声纹　voiceprint　说话人验证　speaker verification　说话人确认　说话人识别　speaker recognition　说话人辨认　speaker identification　i-vector　等错误率　EER　equal error rate　声纹识别

在交互版中打开（看它长在树上的哪里）

把一段语音压缩成一个固定长度的向量，只保留“是谁在说”的信息而忽略说了什么。两段语音的向量越接近，越可能是同一个人；它是说话人验证、说话人日志和声音克隆的共同基础。

先要会：嵌入向量 波形、频谱与梅尔谱

手机用声纹解锁、客服系统确认来电者身份、会议转写标出“谁说了哪句”、TTS模仿某个人的声音，都需要一种描述“音色身份”的表示。说话人嵌入就是这样一个向量：同一个人不同句子的嵌入彼此靠近，不同人的嵌入彼此远离（见嵌入向量）。

两类任务。

  • 说话人验证（speaker verification）：给定一段注册语音和一段测试语音，判断是不是同一个人，是一对一的二分类。
  • 说话人辨认（speaker identification）：从已知的一组人里找出是谁，是多分类。

演进。

  • GMM-UBM说话人确认：先用大量人的语音训练一个通用背景高斯混合模型，再对每个说话人做自适应，比较似然比。之后的i-vector把每段语音的GMM统计量投影到一个低维“总变化空间”。
  • 神经嵌入：训练网络对大量说话人做分类，取倒数第二层（池化后）的激活作为嵌入。d-vector说话人嵌入对帧级特征取平均；x-vector说话人嵌入用时延神经网络加统计池化（均值和标准差）得到段级嵌入，配合数据增强显著优于i-vector。后续工作采用更深的网络和带间隔的分类损失（见度量学习）。
  • 数据：VoxCeleb说话人库提供了上千名说话人的大规模真实场景语音。

打分与指标。两嵌入之间常用余弦相似度（见内积与余弦相似度）打分，超过阈值判为同一人。阈值不同，错误接受率（FAR）和错误拒绝率（FRR）此消彼长；两者相等时的错误率叫等错误率（EER），是最常报告的指标。

其他用途。说话人日志把会议录音切段后对各段的嵌入聚类（见聚类），确定说话人数和分段归属；零样本TTS和语音转换用参考音频的说话人嵌入作为条件，生成同一音色的新语音，见语音转换与变声。

例子

注册语音的嵌入为a，两段测试语音的嵌入为b和c，余弦相似度cos(a, b)=0.82、cos(a, c)=0.31。阈值设为0.6时，判定b是本人、c不是。若在评测集上把阈值从0.6调到0.5，错误拒绝从4%降到2%，错误接受从1%升到3%；两者在某个阈值处都等于约2.5%时，这个值就是EER（数字为示意）。

容易误解的地方

  • 嵌入并不只编码身份：录音设备、信道、情绪和语言也会影响它，跨设备、跨语种时性能明显下降。
  • 声纹可以被合成语音或录音回放欺骗，安全场景需要额外的防伪检测。
