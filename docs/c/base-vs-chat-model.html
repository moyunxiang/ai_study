基座模型与对话模型

Base Models vs Chat Models

也叫：base model　基座模型　基础模型　预训练模型　chat model　对话模型　instruct model　指令模型　Instruct版本　Chat版本　-it　instruction-tuned model　foundation model　aligned model　对齐模型　base vs instruct

基座模型只经过预训练，擅长续写文本；对话模型（也叫指令模型、Instruct或Chat版本）在此基础上做了指令微调和偏好对齐，会把输入当作请求来回答。开源模型常同时发布两个版本。

先要会：预训练与微调 指令微调与对话模板

下载开源模型时常看到同一个模型有两个版本，例如“Llama-3-8B”和“Llama-3-8B-Instruct”。它们的参数量和结构完全相同，区别在于训练到了哪一步（见大模型的训练阶段：预训练、中期训练与后训练）。

基座模型（base model，也叫预训练模型、foundation model）。只做过下一个token预测，学到的是“网上的文本接下来通常怎么写”。给它一个问题，它可能接着写出更多问题、一篇论坛帖子，或者正确答案——取决于这个问题在训练数据里通常出现在什么语境里。要用好基座模型，需要把任务写成“续写”的形式，比如给几个问答示例再留一个空（见上下文学习与提示），这正是GPT-3论文展示的用法。

对话模型（chat model / instruct model）。在基座模型上做了指令微调与对话模板和偏好优化（见人类反馈强化学习），学会了：把输入当作请求、按对话模板组织多轮交互（见系统提示与对话消息）、在回答完后停下、拒绝有害请求。InstructGPT与RLHF和ChatGPT发布展示了这一步带来的可用性差别。

各自的用途。

  • 基座模型：作为继续预训练和自定义微调的起点；做研究时测量“纯粹从预训练得到的能力”；评测基准的少样本测试；生成更多样、风格更“野生”的文本（对齐会让输出分布变窄）。
  • 对话模型：直接给最终用户使用；做智能体、工具调用和结构化输出。

用错的典型表现。

  • 给基座模型发对话式指令：它不按指令做，自问自答或无限续写。
  • 用对话模型但不套对话模板：效果明显下降，或格式混乱。
  • 在对话模型上再做大量领域微调：可能削弱它原有的指令遵循和安全行为（见持续学习与灾难性遗忘）。

“基座”的其他含义。基础模型报告报告提出的“基础模型”泛指在大规模数据上预训练、可适配多种下游任务的模型，范围比这里讲的“base版本”更宽；推理模型的语境里，“基座”也常指被拿来做强化学习的起点模型。

例子

同样输入“法国的首都是哪里？”

  • 基座模型可能输出：“\n德国的首都是哪里？\n意大利的首都是哪里？\n……”——它在续写一份地理题目单。
  • 改成少样本格式“问：日本的首都是哪里？答：东京。\n问：法国的首都是哪里？答：”，基座模型就会输出“巴黎。”
  • 对话模型直接回答：“法国的首都是巴黎。”然后输出结束token。

容易误解的地方

  • 评测分数要注明是base还是instruct版本，两者在同一基准上的成绩可能差很多，且各有高低。
  • “Instruct”“Chat”“-it”等后缀各家叫法不同，有的厂商还把推理版本单独命名，下载前看模型卡。
