自我改进与自我进化

Self-Improving and Self-Evolving Agents

也叫：self-improvement　自我改进　自我进化　self-evolving　self-evolution　递归自我改进　recursive self-improvement　RSI　自我修改　自举　bootstrapping

在交互版中打开（看它长在树上的哪里）

让模型或智能体利用自己产生的数据、反馈或代码修改来变强，而不完全依赖人类提供新的数据和设计。

这一思路有几个层次。用自己生成的推理来训练自己：STaR自举推理只保留答对的推理过程做微调，rStar-Math用树搜索自我进化出数学推理数据，Absolute Zero零数据自博弈连题目也自己出。不改权重、改上下文：Reflexion、Self-Refine自我改进用语言反思修正下一次尝试，智能体上下文工程ACE让智能体不断改写自己的操作手册。改自己的代码：达尔文哥德尔机DGM让编码智能体修改自身并用基准实测，SWE-bench从20.0%升到50.0%。AlphaEvolve则用进化搜索改进算法代码。

讨论的焦点有两个：这些改进的上限是否被底座模型锁死（见自我纠错的局限对无外部反馈自我纠错的质疑），以及自我修改的系统怎样保持可监督。
