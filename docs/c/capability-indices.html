综合能力指数

Aggregate Capability Indices

也叫：综合榜　综合指数　智能指数　AA指数　Artificial Analysis　ECI　Epoch能力指数　aggregate leaderboard　capability index　LLM排行榜　大模型排行榜　LLM leaderboard

在交互版中打开（看它长在树上的哪里）

把许多基准的分数合成一个数，方便横向比较模型、跟踪整体进步，但权重和成分的选择本身就是一种判断。

单个基准只测一个侧面，又会饱和，于是出现各种把多基准汇总的榜单。HELM按场景和多指标统一评测；Open LLM Leaderboard在开源模型上跑固定的一组任务；Artificial Analysis智能指数用同一套流程重跑前沿模型，加权平均成智能指数，并同时公布价格和速度；Epoch能力指数ECI用统计模型把几十个基准拼接到同一个尺度上，便于跨时间比较；METR任务时间跨度则把能力换算成可完成任务的时长，作为另一种单一指标。

这些指数常被引用为“哪个模型最强”的依据，但需要注意：版本更替频繁，不同版本的分数不可直接比较；成分偏向编程和数学等易自动评分的领域；越来越多成分依赖私有题集和模型裁判，外界难以复现。
