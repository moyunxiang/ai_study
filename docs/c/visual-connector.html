视觉连接器

Vision-Language Connector

也叫：Connector　Projector　投影层　视觉适配器　Adapter　Q-Former　Perceiver Resampler　MLP Projector　模态桥接　视觉-语言接口

在交互版中打开（看它长在树上的哪里）

把视觉编码器输出的特征转换成语言模型能读的token的那一小块网络，决定送进LLM的视觉token数量和形式。

视觉编码器和语言模型各自预训练，特征空间不同，中间需要一个“翻译”。主要有三种设计。一是用少量可学习查询向量通过交叉注意力把整张图压成固定个数的token：Flamingo的Perceiver Resampler、BLIP-2的Q-Former（32个查询）；好处是token少，坏处是可能丢细节。二是直接投影：LLaVA用一个线性层，LLaVA-1.5改成两层MLP，每个图块都保留成一个token，细节多但token多。三是在语言模型内部为视觉另设一套参数（CogVLM视觉专家的视觉专家）或用交叉注意力层注入（Llama 3.2 Vision）。

MM1设计消融、Idefics2设计选择等消融研究发现，连接器的具体结构影响远小于图像分辨率和视觉token数，因此近年主流是MLP加token合并，例如DeepSeek-VL2的2×2像素重排。连接器也是压缩视觉token的天然位置，与FastV视觉token剪枝这类在LLM内部剪枝的方法互补。
