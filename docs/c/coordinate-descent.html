坐标下降与交替优化

Coordinate Descent and Alternating Optimization

也叫：坐标下降　坐标下降法　coordinate descent　坐标上升　coordinate ascent　块坐标下降　block coordinate descent　BCD　交替优化　alternating optimization　交替最小化　alternating minimization　交替最小二乘　ALS　alternating least squares　对偶坐标下降　dual coordinate descent　glmnet

每次只优化一个变量（或一组变量），其余固定不动，轮流进行。单个变量的子问题常有闭式解，所以在Lasso、SVM、矩阵分解、k-means和EM里都很高效。

先要会：梯度下降 凸函数与凸优化

多元函数整体很难最小化，但固定其他变量后，只看一个变量往往很简单，甚至能直接解出最优值。坐标下降就利用这一点：

1. 选一个坐标i（按顺序轮流，或随机选）； 2. 固定其余坐标，求解x_i ← argmin_{x_i} f(x_1, …, x_i, …, x_n)，或者只沿这一维走一小步梯度； 3. 重复直到收敛。

每一步函数值都不会上升。对光滑的凸函数，它收敛到全局最优；对“光滑凸函数 + 可分的非光滑项”（如L1正则）也成立。

为什么好用。

  • 闭式子问题：Lasso与L1稀疏固定其他权重后，单个权重的最优值就是一次软阈值运算（见次梯度与不可导点），不需要选学习率；glmnet等经典软件用坐标下降配合正则化路径求解Lasso和弹性网。
  • 计算便宜：更新一个坐标通常只需要O(样本数)的计算，对高维稀疏数据尤其划算。LIBLINEAR线性分类库用对偶坐标下降训练线性SVM和逻辑回归，在大规模稀疏文本分类上非常快；SMO序列最小优化每次只优化两个对偶变量（因为有一个等式约束，至少要同时动两个），使SVM训练变得可行。

块坐标下降与交替优化。把变量分成几组，轮流优化每一组，叫块坐标下降，也常叫交替优化。许多经典算法都是这种结构：

  • k-means聚类：固定中心、为每个点分配最近的簇；再固定分配、把中心更新为均值。
  • EM算法：可以看作在“隐变量分布”和“参数”两组变量之间交替做坐标上升。
  • 推荐系统的交替最小二乘（ALS）：固定物品向量求用户向量，再反过来，每一步都是最小二乘问题（见推荐系统与协同过滤）。
  • GAN的训练在判别器和生成器之间交替更新（但那是博弈而不是共同最小化一个函数，见对抗训练）。

局限。变量之间耦合很强时（损失曲面是一条斜着的窄谷），沿坐标轴走会走出很多小台阶，收敛很慢；目标非光滑且不可分时，坐标下降可能卡在非最优点。深度网络参数之间高度耦合，所以训练整体都用梯度方法。

例子

最小化f(x, y) = x² + y² + xy − 3x，从(0, 0)开始：

  • 固定y = 0，对x求导2x − 3 = 0，x = 1.5；
  • 固定x = 1.5，2y + 1.5 = 0，y = −0.75；
  • 固定y = −0.75，2x − 0.75 − 3 = 0，x = 1.875；
  • 再更新y = −0.9375……

逐步逼近真正的最优点(2, −1)，每轮误差缩小为原来的1/4。

容易误解的地方

  • 对非光滑、不可分的函数（如|x − y|），坐标下降可能停在一个任何单坐标都无法改进、但并非最优的点上。
  • 交替优化只保证每一步不变差，结果通常依赖初始化，k-means和EM都需要多次重启。
