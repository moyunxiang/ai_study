卷积运算

Convolution

也叫：卷积核　kernel　filter　滤波器　互相关　cross-correlation

在交互版中打开（看它长在树上的哪里）

让一个小窗口（卷积核）在信号或图像上滑动，每个位置算一次加权和。同一组权重在所有位置共享，所以能用很少的参数检测“在哪里都可能出现”的局部模式。

先要会：向量、矩阵与张量 内积与余弦相似度

要在一张图片里找边缘或眼睛，用全连接层的话，每个输出要和全部输入相连，参数多得离谱；而且在左上角学会识别眼睛，到了右下角还得重新学。直觉上更合理的做法是：用同一个小探测器在图片上到处扫描。卷积就是这种扫描操作。

一维定义。输入信号x，长度为k的卷积核w，输出

y[i] = Σ_{j=0}^{k−1} w[j] · x[i + j]

即把w放在位置i，和对应的k个输入做内积与余弦相似度，然后右移一格。严格的数学卷积要把核翻转（x[i − j]），深度学习框架里实际实现的是不翻转的版本（互相关），由于核是学出来的，两者没有本质区别。

二维与多通道。图片上用二维核（如3×3）沿高和宽滑动；输入有C个通道时，核的形状是C×3×3，每个输出位置是C×9个数的加权和。一层通常有很多个核，每个核产生一个输出通道。步长（stride）控制每次移几格，填充（padding）控制边界处怎么处理。

两个关键性质。一是局部连接：每个输出只看一小块输入。二是权重共享：同一个核用于所有位置，所以参数量与图片大小无关，而且平移输入，输出也跟着平移（平移等变，见不变性与等变性）。

它出现在哪里。卷积网络识别邮编和LeNet与卷积网络用卷积网络识别手写数字；AlexNet在GPU上训练大卷积网络赢下ImageNet，开启深度学习时代；WaveNet在音频波形上用一维因果卷积生成语音。卷积层的组成见卷积层、池化与感受野，卷积与频域乘法的关系见傅里叶变换与频域。

例子

一维：x = [1, 1, 1, 5, 5, 5]，核w = [−1, 1]。输出依次是−1+1 = 0、0、−1+5 = 4、0、0，长度6−2+1 = 5。只有在数值跳变处输出不为0，这个核就是一个“边缘检测器”。参数量对比：输入是3×224×224的图片，一个有64个3×3核的卷积层只需3×3×3×64 + 64 = 1792个参数；如果用全连接层把150528个输入映射到同样多的输出，需要约2.27×10¹⁰个权重。

容易误解的地方

  • 深度学习里的“卷积”实际是互相关（不翻转核），和信号处理教材的定义差一个翻转。
  • 卷积本身对平移是等变而非不变；分类网络对平移的近似不变性来自池化和最后的全局汇聚。
