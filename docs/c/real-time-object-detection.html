实时目标检测

Real-time Object Detection

也叫：YOLO系列　YOLOv8　YOLO11　YOLO26　YOLOv5　实时DETR　real-time DETR　单阶段检测　one-stage detector　端侧检测　NMS-free　免NMS检测　工业检测

在交互版中打开（看它长在树上的哪里）

在普通GPU或边缘设备上以每秒几十到上百帧运行的检测器，追求速度与精度的最佳折中，是工业界用得最多的视觉模型。

两阶段检测器（Faster R-CNN）精度高但慢。YOLO把检测变成一次前向的网格回归，开启了单阶段实时检测；此后SSD、YOLOv3、YOLOv4、Ultralytics YOLO系列（YOLOv5/v8/11/26等）不断在骨干、特征融合、标签分配和数据增强上打磨，成为部署最广的一族。

2023年后出现两个变化：一是DETR路线做到实时，RT-DETR实时DETR、D-FINE、RF-DETR用Transformer解码器直接输出不重复的框，省去锚框与非极大值抑制后处理；二是YOLO自身也走向免NMS和注意力化，如YOLOv10免NMS的一对一匹配、YOLOv12的区域注意力。

争论点：各家报告的速度依赖不同硬件与推理引擎，横向比较常不公平；在COCO上的提升是否能迁移到真实小数据集也被质疑（RF-DETR专门针对这一点）。
