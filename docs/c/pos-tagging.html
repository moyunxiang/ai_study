词性标注

Part-of-Speech Tagging

也叫：POS tagging　part-of-speech tagging　part-of-speech　词性　词性标签　POS　POS tags　tagset　标签集　UPOS　Penn tagset　词类

在交互版中打开（看它长在树上的哪里）

给句子里每个词标出词性（名词、动词、形容词、介词等）。它是最经典的序列标注任务，难点在于同一个词在不同语境下词性不同。

先要会：序列标注 隐马尔可夫模型

要分析一句话的结构、做信息抽取或语音合成（同一个英文词作名词和动词时重音可能不同），首先得知道每个词在句中扮演什么角色。词性标注（part-of-speech tagging，POS tagging）就是做这件事。

标签集。英文最常用Penn Treebank的标签集（见Penn Treebank），约45个，区分得很细，如NN（单数名词）、NNS（复数名词）、VBD（动词过去式）、VBZ（动词第三人称单数）。为了跨语言统一，Universal Dependencies定义了17个粗粒度的通用词性（NOUN、VERB、ADJ、ADP等）。中文常用的标签集与英文不同，如区分名词、方位词、量词、助词等。

为什么难。大多数词只有一种词性，但常用词里歧义很多。英文“book”可以是名词（a book）或动词（book a flight）；“that”可以是限定词、代词、连词。中文“研究”可以是名词也可以是动词，“在”可以是动词也可以是介词。只看词本身不够，必须结合上下文。

方法。它是序列标注的标准试验场，几乎每一代方法都先在这里检验：

  • 基于规则与转换：Brill转换式标注器从“每个词标最常见词性”出发，自动学习一串改写规则。
  • 隐马尔可夫模型：HMM词性标注和TnT三元HMM标注器用标签转移概率和词的发射概率建模，再用Viterbi算法解码（见隐马尔可夫模型）。
  • 判别式模型：最大熵词性标注器的最大熵模型、斯坦福双向词性标注器的双向依赖网络，可以使用词形后缀、大小写等丰富特征。
  • 神经网络与预训练模型：双向LSTM、BERT接分类层。

在英文新闻语料上，好的标注器逐词准确率已经在97%左右，接近人工标注的一致性上限，所以它常被视为“基本解决”的任务；在社交媒体文本、低资源语言和专业领域上仍有困难。今天它更多作为句法分析和语言学研究的前处理步骤。

例子

句子“I can can a can”（我会把罐头装进罐子）：

  • I/PRP（代词）
  • can/MD（情态动词，“会”）
  • can/VB（动词，“装罐”）
  • a/DT（限定词）
  • can/NN（名词，“罐子”）

同一个“can”出现三次，词性各不相同。HMM里，“MD后面接VB”“DT后面接NN”的转移概率很高，正是这些搭配让模型分得开。

一个基线：每个词总是标它在训练集里最常见的词性，在英文新闻上就能达到约九成的准确率——所以报告词性标注结果时，要和这个基线比。

容易误解的地方

  • 不同标签集粒度差别很大，准确率不能跨标签集直接比较。
  • 中文要先分词才能标词性，分词错误会直接传递给词性标注；也可以把分词和标注合成一个联合任务。
