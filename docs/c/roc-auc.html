ROC曲线、AUC与PR曲线

ROC Curve, AUC and Precision–Recall Curve

也叫：ROC曲线　ROC　ROC curve　receiver operating characteristic　受试者工作特征曲线　AUC　ROC AUC　AUROC　曲线下面积　area under the curve　PR曲线　precision-recall curve　PR curve　AUPRC　PR AUC　平均精度　average precision　AP　真正例率　TPR　true positive rate　假正例率　FPR　false positive rate　误报率　TPR@FPR

ROC曲线扫遍所有阈值，画出真正例率对假正例率的轨迹；曲线下面积AUC等于随机一个正例得分高于随机一个负例的概率。它评价排序能力，与阈值无关。

先要会：准确率、精确率、召回率与F1

分类器通常先输出一个分数，再和阈值比较得出判断。阈值不同，精确率、召回率、误报率都会变（见准确率、精确率、召回率与F1）。如果还没决定阈值，或者想比较两个模型“本质上谁更会区分”，就需要一个与阈值无关的指标。

ROC曲线。对每个可能的阈值计算两个量：

  • 真正例率TPR = TP/(TP + FN)（召回率、灵敏度）；
  • 假正例率FPR = FP/(FP + TN)（误报率，等于1 − 特异度）。

以FPR为横轴、TPR为纵轴，把阈值从最高（全判负，点(0, 0)）扫到最低（全判正，点(1, 1)），得到ROC曲线。随机猜测是对角线；曲线越往左上角凸，模型越好。

AUC。ROC曲线下面积，取值0到1，随机猜为0.5。它有一个很好用的等价含义：

AUC = P(随机正例的得分 > 随机负例的得分)

也就是所有“正例–负例”对中排对了的比例（平分算一半）。它只看排序，对分数做任何单调变换都不改变AUC，所以也不反映校准（见模型校准）。

PR曲线与AP。以召回率为横轴、精确率为纵轴的曲线叫PR曲线，曲线下面积称为平均精度（AP）。正例极少时，FPR的分母TN非常大，几百个误报也只让FPR变化一点点，ROC AUC看起来很高；PR曲线直接反映误报对精确率的影响，更能说明问题（见不均衡数据的指标：平衡准确率与MCC）。目标检测的mAP就是对每个类算AP再平均，见IoU与mAP。

它出现在哪里。医学影像AI常报告AUC并与医生在ROC平面上的位置比较，如皮肤癌皮肤科医生级分类和CheXNet；异常检测与分布外检测和成员推断攻击的评测通常报告AUC或在低误报率（如FPR = 1%）下的TPR；推荐和广告系统用AUC评估点击率模型的排序能力（见推荐系统与协同过滤）。

例子

4个样本：正例得分(0.9, 0.4)，负例得分(0.6, 0.2)。正负对共4对：(0.9 > 0.6)对、(0.9 > 0.2)对、(0.4 > 0.6)错、(0.4 > 0.2)对，AUC = 3/4 = 0.75。

阈值0.5时：预测为正的只有0.9和0.6，TPR = 1/2，FPR = 1/2，对应ROC曲线上的点(0.5, 0.5)。

容易误解的地方

  • AUC高不代表在你要用的阈值上表现好；部署时关心的往往是某个特定误报率下的召回率。
  • 多分类的AUC有一对其余、一对一、宏平均、微平均等多种算法，报告时要写清楚。
