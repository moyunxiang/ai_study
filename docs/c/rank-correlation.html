排名相关：Spearman与Kendall

Rank Correlation: Spearman and Kendall

也叫：排名相关　秩相关　等级相关　rank correlation　Spearman相关　Spearman相关系数　Spearman's rho　Spearman correlation　斯皮尔曼相关　Kendall tau　Kendall's tau　Kendall τ　肯德尔相关系数　一致对　concordant pairs　元评测　meta-evaluation

只看两组数名次是否一致的相关系数：Spearman相关是名次之间的皮尔逊相关，Kendall τ比较顺序一致与相反的对数。常用来比较两份排行或自动指标与人类评分。

先要会：协方差矩阵

一个新的自动评测指标好不好，常见检验方法是：它给一批模型或一批回答排出的顺序，与人类评分排出的顺序有多一致？这里关心的是排序而不是数值本身：人类打1到5分、指标给出0到100的分数，量纲完全不同，但只要名次一致就说明指标有用。

皮尔逊相关的局限。皮尔逊相关系数（见协方差矩阵）衡量线性关系，对离群点敏感；两组数是单调但非线性的关系时（如一个是另一个的平方），它小于1。

Spearman相关（ρ）。把两组数各自换成名次，再计算名次之间的皮尔逊相关。没有并列时有简便公式：

ρ = 1 − 6·Σd_i² / (n(n² − 1))

d_i是第i个对象在两份排名中的名次差。只要关系是单调的，ρ就等于1。

Kendall τ。考虑所有n(n − 1)/2个对象对：两份排名中顺序相同的叫一致对，相反的叫不一致对，

τ = (一致对数 − 不一致对数) / (n(n − 1)/2)

它的含义很直观：随机挑两个对象，两份排名意见一致的概率减去不一致的概率。通常|τ|比|ρ|小一些，对小样本和并列的处理也更稳健。

它出现在哪里。

  • 句子相似度：STS基准用Spearman相关评价模型给出的相似度与人工打分是否一致，Sentence-BERT报告的就是这个指标。
  • 评测指标的元评测：机器翻译、摘要的自动指标（见文本生成的自动指标）每年都要报告与人类判断的Kendall τ或Spearman ρ；Arena-Hard、LLM-as-a-Judge与MT-Bench等自动基准常用它们与Chatbot Arena排名的一致程度来证明自己可信（见LLM当裁判）。
  • 打分类任务的标注一致性也可以用它衡量，见标注一致性与Cohen's kappa。
  • 检验“小模型上的排名是否能预测大模型上的排名”、两份基准的排行是否一致，也常用它。

例子

5个模型，人类排名(1, 2, 3, 4, 5)，某指标排名(2, 1, 3, 5, 4)。名次差d = (−1, 1, 0, −1, 1)，Σd² = 4，ρ = 1 − 6×4/(5×24) = 0.8。共10个对象对，其中模型1与2、模型4与5两对顺序相反，一致对8个，τ = (8 − 2)/10 = 0.6。

容易误解的地方

  • 排名相关高只说明顺序一致，不说明分差的大小可信；两个模型分差很小时，顺序本身可能只是噪声。
  • 只在少数几个对象（如5个模型）上算出的相关系数波动很大，应附上置信区间或检验，见置信区间、标准误与误差棒。
