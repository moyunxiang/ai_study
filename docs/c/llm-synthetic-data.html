大模型合成数据

Synthetic Data for LLM Training

也叫：合成数据　synthetic data　数据合成　模型生成数据　蒸馏数据　distillation data　Self-Instruct式　教科书级数据　textbook-quality data　合成指令　数据蒸馏

在交互版中打开（看它长在树上的哪里）

用大模型自己生成指令、对话、解题过程甚至教科书式文章，作为训练另一个（或同一个）模型的数据。

人工写指令和标注偏好又贵又慢。Self-Instruct让模型从少量种子任务自举出大量指令，Alpaca与廉价指令微调用它花几百美元做出类ChatGPT模型，Vicuna与ShareGPT、Evol-Instruct、Orca解释蒸馏分别用真实对话、指令进化和带解释的答案扩充数据。预训练侧，TinyStories和教科书级数据phi-1证明精心合成的“教科书级”数据能让小模型以少得多的token取得强性能，并贯穿了Phi系列（Phi-4）。

风险同样被反复讨论：模仿闭源模型的假象指出模仿闭源模型主要学到风格而非能力；模型坍缩显示在模型生成数据上递归训练会让分布尾部逐渐消失。今天的主流做法是用强模型合成、再用验证器或奖励模型过滤。
