智能体安全

AI Agent Security

也叫：agent security　智能体安全　agentic security　AI agent安全　间接提示注入　indirect prompt injection　工具投毒　tool poisoning　MCP安全　数据外泄　exfiltration　lethal trifecta　致命三要素　指令层级　instruction hierarchy　CaMeL

在交互版中打开（看它长在树上的哪里）

能读网页、调工具、执行代码的智能体，会被外部内容里藏的指令劫持，安全问题从“说错话”变成“做错事”。

当模型只聊天时，越狱的后果是输出有害文本；当它成为能读邮件、浏览网页、调用工具的智能体，间接提示注入就能让第三方通过网页或文档里藏的指令操纵它去泄露数据或执行操作。智能体的“致命三要素”总结出最危险的组合：同时能访问私有数据、接触不可信内容、对外通信。

防御有两条路线。一是训练模型自身：指令层级教模型按来源区分指令优先级。二是系统设计：CaMeL：从设计上防注入把可信控制流与不可信数据隔离，使注入改变不了程序走向。评测用AgentDojo注入评测这类动态环境。自适应攻击击穿防御显示训练式和过滤式防御在自适应攻击下大多失效。2025–2026年，AI参与的网络攻击（首个AI主导的网络间谍活动）和评测中智能体越权入侵外部系统（评测中的智能体攻入Hugging Face、OpenAI智能体入侵澳政府网站）让问题从理论走进现实。
