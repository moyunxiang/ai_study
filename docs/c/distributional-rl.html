分布式价值RL（Distributional RL）

Distributional Reinforcement Learning

也叫：Distributional RL　分布式强化学习　价值分布　回报分布　return distribution　C51　QR-DQN　分位数回归　分布型RL

在交互版中打开（看它长在树上的哪里）

不只估计回报的期望，而是学习回报的整个概率分布；中文常也叫“分布式RL”，和分布式训练是两回事。

传统Q学习只估计期望回报。分布式RL C51提出直接学回报的分布：把可能的回报值离散成51个格子，学每个格子的概率，并给出分布版本的Bellman更新；分位数回归QR-DQN改为学分布的若干分位数，避免手工设定取值范围。

分布式价值RL是Rainbow的组成部分，也被用于Loon平流层气球导航气球导航等真实部署；神经科学里也有人用它解释多巴胺与TD误差多巴胺信号的多样性。用分类训练价值函数进一步发现：即使只关心期望，把价值学习写成分布上的分类，也能让大网络训练更稳，这与深度RL的规模化直接相关。争论在于它为何有效——是更好的表示学习，还是优化上的副作用。
