分位数回归与弹球损失

Quantile Regression and Pinball Loss

也叫：分位数回归　quantile regression　分位数　quantile　弹球损失　pinball loss　分位数损失　quantile loss　check loss　预测区间　prediction interval　条件分位数　conditional quantile　中位数回归　median regression　分位数Huber损失　quantile Huber loss

不预测平均值，而预测某个分位数，如“90%的情况下不超过多少”。用不对称的弹球损失训练，低估与高估罚得不同。它能给出预测区间，也是分布式强化学习的核心工具。

先要会：回归损失：MSE、MAE与Huber 随机变量与概率分布

普通回归最小化均方误差，得到的是条件均值E[y | x]（见回归损失：MSE、MAE与Huber）。但很多决策需要的是分布的其他部分：外卖平台要承诺“90%的订单30分钟内送达”，库存管理要备足“95%的情况下都够用”的货量，风控关心的是最坏的那5%。这些是分位数问题。

分位数。随机变量Y的τ分位数q_τ满足P(Y ≤ q_τ) = τ。τ = 0.5就是中位数。

弹球损失（pinball loss）。设误差u = y − ŷ，

L_τ(u) = τ·u（u ≥ 0，低估了）；(τ − 1)·u（u < 0，高估了）

它是一条在0处折弯、两边斜率不同的折线，图形像弹球台的挡板。τ = 0.9时，低估一个单位罚0.9，高估一个单位只罚0.1，于是最优预测会主动偏高，恰好落在条件分布的90%分位数上。τ = 0.5时它就是平均绝对误差的一半，最优解是中位数。

预测区间。同时训练τ = 0.05和τ = 0.95两个输出，就得到一个90%的预测区间。这比只给一个点估计有用得多，是表达预测不确定性的一种简单方法（见不确定性估计）；如果需要有覆盖率保证的区间，可以在其上再做保形预测校正。

梯度提升与神经网络。弹球损失只是换了一个损失函数，任何回归模型都能用：LightGBM、XGBoost支持分位数目标，神经网络可以同时输出多个分位数。

在强化学习里。分布式强化学习不只估计回报的期望，而是估计回报的整个分布（见分布式价值RL（Distributional RL））。分位数回归QR-DQN用一组固定的分位数来表示回报分布，用分位数回归的Huber化版本训练；隐式分位数网络IQN把τ作为输入，能对任意分位数查询；TQC截断分位数评论家在连续控制中丢弃最高的若干分位数，缓解Q值高估。

例子

某线路历史送达时间（分钟）为20、22、25、28、40。τ = 0.9：预测ŷ = 30时，四个比它小的样本各产生高估损失0.1×(30 − y)，合计0.1×(10 + 8 + 5 + 2) = 2.5，40那一单低估10分钟，损失0.9×10 = 9，总计11.5；预测ŷ = 40时总损失为0.1×(20 + 18 + 15 + 12) = 6.5，更小。这批样本的经验0.9分位数正是40，所以最优预测是40。

容易误解的地方

  • 分别训练多个分位数时，预测可能出现“交叉”（0.9分位数小于0.5分位数），需要排序或用联合模型约束单调性。
  • 弹球损失在0处不可导，梯度方法需用次梯度，或像QR-DQN那样在0附近用平方损失平滑（见次梯度与不可导点）。
