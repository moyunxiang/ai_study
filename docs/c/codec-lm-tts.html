编解码器语言模型TTS

Neural Codec Language Model TTS

也叫：Neural Codec Language Model　codec language model　codec LM　LLM-based TTS　LLM TTS　大模型TTS　自回归TTS　AR TTS　VALL-E路线　语音合成大模型　TTS scaling

在交互版中打开（看它长在树上的哪里）

把语音合成当成「续写token」：参考音频的token当提示，语言模型自回归地接着生成目标语音的token。

VALL-E把TTS改写成语言建模：用EnCodec把语音变成token，几秒参考录音的token作为提示，模型续写出用同一音色说新文字的token，零样本克隆由此成为默认能力。此前Tortoise TTS已经用GPT式模型加扩散解码做过类似尝试。

后续演化：VALL-E 2解决重复和不稳定；XTTS、Seed-TTS、CosyVoice与CosyVoice 2采用「LLM生成语义token、流匹配还原声学细节」的两段式，成为工业主流；Fish-Speech用快慢双自回归处理多码本；Llasa把结构简化成纯Llama并研究训练与推理扩展；IndexTTS系列、MiniMax-Speech、Qwen3-TTS把它做成产品级系统；开源社区的GPT-SoVITS是轻量版本。

这条路线和可逆流与流匹配式非自回归TTS长期竞争：自回归韵律更自然、易流式输出，但会漏字、重复、推理慢。
