基于规则的自然语言处理

Rule-Based and Symbolic NLP

也叫：规则NLP　符号NLP　Symbolic NLP　Rule-based NLP　理性主义NLP　专家系统式NLP　规则机器翻译　RBMT　手写语法

在交互版中打开（看它长在树上的哪里）

由语言学家和程序员手写语法、词典和推理规则，让计算机按规则理解和生成语言。

NLP的头二十多年几乎都是规则系统。翻译方面，Georgetown–IBM机器翻译实验演示了几百个词和几条规则的俄英翻译，SYSTRAN规则机器翻译把规则翻译做成商用系统。对话和理解方面，ELIZA用关键词匹配和模板改写回答，SHRDLU在积木世界里完整解析句子并执行命令，LUNAR月岩问答用扩充转移网络ATN语法把问题译成数据库查询。语义方面，Schank概念依存和脚本与故事理解尝试用少量语义原语和情景脚本表示意义。

这些系统在受限场景里效果惊人，但规则写不完、彼此冲突，一走出玩具场景就失效，ALPAC报告报告和后来的统计转向都与此有关。规则并没有完全消失：工业系统里的正则、词典和模板匹配至今仍在用，常和统计或神经模型配合。
