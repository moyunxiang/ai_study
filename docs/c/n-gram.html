n-gram与平滑

n-grams and Smoothing

也叫：N元语法　n元模型　bigram　trigram　Kneser-Ney　回退

在交互版中打开（看它长在树上的哪里）

只看前面n−1个词来预测下一个词、用语料中的出现次数来估计概率的语言模型；平滑技术负责给没见过的词组也留一点概率。

先要会：语言模型 马尔可夫性与马尔可夫链 最大似然估计

语言模型需要估计P(w_t | w_1…w_(t−1))，但前文越长，这个具体的前文在语料里出现的次数就越少，长句子几乎都是独一无二的，没法直接计数。n-gram模型做了一个大胆的简化：只看最近n−1个词。

P(w_t | w_1…w_(t−1)) ≈ P(w_t | w_(t−n+1)…w_(t−1))

这就是马尔可夫性与马尔可夫链里的马尔可夫假设。n = 2叫bigram（只看前一个词），n = 3叫trigram。

怎么估计。直接数：

P(w_t | w_(t−1)) = count(w_(t−1) w_t) / count(w_(t−1))

这正是最大似然估计的结果。整个“训练”就是扫一遍语料、建一张计数表。

零概率问题。语料再大，也总有合理的词组没出现过。只要一个bigram计数为0，含有它的整句概率就是0——一句完全正常的话可能被判为不可能。词表大小为V时，trigram可能的组合有V³个，V = 5万时是1.25×10^14个，任何语料都远远覆盖不了。这就是维度灾难在语言上的表现。

平滑：从见过的词组那里匀出一部分概率给没见过的。

  • 加一平滑（Laplace）：每个计数都加1，(count + 1) / (count(前文) + V)。简单但匀出去的太多。
  • 回退与插值：trigram没见过，就退回用bigram，再不行用unigram，并按比例混合。Katz回退语言模型是经典的回退方法。
  • Kneser-Ney：考虑一个词能跟在多少种不同的词后面，而不只是它出现了多少次。“旧金山”里的“金山”出现很多次，但几乎只跟在“旧”后面，不应该在新语境里得到高概率。Chen与Goodman对各种平滑方法做了系统比较（n-gram平滑），Kneser-Ney一系的方法总体最好，成为之后的默认选择。

它在哪里出现。香农：语言的统计模型最早用n-gram描述英文的统计结构；从1980年代到2010年代初，n-gram是语音识别和短语统计机器翻译中语言模型的标准做法；万亿词n-gram与Stupid Backoff用万亿词语料和极简的回退方法证明，数据足够多时简单方法也很强。它的根本局限是：看不到n−1个词以外的内容，也不知道“猫”和“狗”是相似的词。神经概率语言模型用词向量和神经网络解决了后者。

例子

某语料中“我”出现10次，“我 喜欢”出现3次，“我 讨厌”出现0次，词表大小V = 1000。

不平滑：P(喜欢 | 我) = 3/10 = 0.3，P(讨厌 | 我) = 0/10 = 0。任何含“我 讨厌”的句子概率都是0。

加一平滑：P(喜欢 | 我) = (3 + 1)/(10 + 1000) ≈ 0.00396，P(讨厌 | 我) = (0 + 1)/1010 ≈ 0.00099。零概率消失了，但见过3次的“我 喜欢”的概率从0.3跌到0.004——绝大部分概率被分给了从没出现过的999个词。这正是加一平滑在实践中效果差的原因。

容易误解的地方

  • n越大不一定越好：n变大后计数更稀疏，没见过的组合更多，必须配合更好的平滑和更大的语料。
  • n-gram没有“相似”的概念：见过“喂猫”，对“喂狗”没有任何帮助。
  • n-gram并未完全消失：它常被用来做数据去重、检测训练集污染，或在语音识别里与神经模型结合。
