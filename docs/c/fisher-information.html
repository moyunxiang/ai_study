费舍尔信息与Cramér–Rao下界

Fisher Information and the Cramér–Rao Bound

也叫：费舍尔信息　费雪信息　Fisher信息　Fisher information　费舍尔信息矩阵　Fisher信息矩阵　Fisher information matrix　FIM　经验费舍尔　empirical Fisher　Cramér-Rao下界　Cramér-Rao　Cramer-Rao bound　CRLB　克拉默-拉奥下界　信息几何　information geometry

衡量数据对一个参数“透露了多少信息”：对数似然对参数越敏感，费舍尔信息越大，参数就能估计得越准。它给出无偏估计方差的下限，也是自然梯度和EWC的核心。

先要会：最大似然估计 雅可比矩阵与海森矩阵 KL散度

有的参数，数据稍微一变就能看出它的差别；有的参数，变化很大数据也几乎不受影响。费舍尔信息把这种“可辨识程度”量化。

定义。设模型为p(x | θ)，得分函数是对数似然的梯度s(θ) = ∇_θ log p(x | θ)，它的期望为0。费舍尔信息是得分的方差（多维时是协方差矩阵）：

F(θ) = E_x[ s(θ) s(θ)ᵀ ]

在常见的正则条件下，它也等于对数似然负海森矩阵的期望：F = −E[∇² log p(x | θ)]。所以费舍尔信息大，意味着对数似然在真值附近弯得很厉害、形成一个尖峰，参数被“钉”得很牢。

Cramér–Rao下界。任何无偏估计量θ̂的方差满足

Var(θ̂) ≥ 1 / (n·F(θ))

n是独立样本数。最大似然估计在样本足够多时渐近达到这个下界，这是它被广泛使用的理论理由之一（见估计量：偏差、方差与一致性）。

信息几何的视角。两个相邻分布之间的KL散度近似为KL(p_θ ‖ p_{θ+δ}) ≈ ½ δᵀFδ。也就是说，费舍尔矩阵定义了“参数空间里的距离”：同样的参数变化δ，在F大的方向上会让分布变化更多。

它出现在哪里。

  • 自然梯度：普通梯度下降在参数空间里走一步，但我们真正在意的是分布空间里走了多远。自然梯度用F⁻¹∇L代替∇L，让更新不依赖参数化方式。K-FAC用克罗内克分解近似F⁻¹，使它能用在神经网络上（见外积、哈达玛积与克罗内克积）。
  • TRPO把“新旧策略的KL不超过δ”近似为½ΔθᵀFΔθ ≤ δ，于是更新方向是自然梯度，用线搜索与共轭梯度里的共轭梯度求解。
  • EWC弹性权重巩固用费舍尔信息的对角线衡量每个参数对旧任务有多重要，在学新任务时给重要参数的变化加更大的惩罚，缓解持续学习与灾难性遗忘中的灾难性遗忘。
  • 模型合并、剪枝和量化里，常用费舍尔对角线估计“改动这个参数会让损失增加多少”。

例子

伯努利分布估计p：每个样本的得分为x/p − (1 − x)/(1 − p)，费舍尔信息F(p) = 1 / (p(1 − p))。p = 0.5时F = 4；p = 0.01时F ≈ 101。n = 100时，Cramér–Rao下界给出的标准差分别为√(1/400) = 0.05和√(1/10100) ≈ 0.01——p = 0.01时估计的绝对误差更小，但相对于p本身仍然达到100%。

容易误解的地方

  • 实践中常用“经验费舍尔”（用数据标签而不是从模型采样的标签计算得分）代替真正的费舍尔矩阵，两者在模型没拟合好时差别很大。
  • 费舍尔矩阵是n×n的，n为参数量；对神经网络只能用对角、分块或克罗内克近似。
