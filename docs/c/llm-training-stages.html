大模型的训练阶段：预训练、中期训练与后训练

LLM Training Stages

一个大语言模型通常分几个阶段训练：在海量文本上预训练学语言和知识；中期训练（退火）用更高质量或更长的数据强化特定能力；后训练用指令数据、偏好数据和强化学习教它按人的期望回答。

先要会：预训练与微调 指令微调与对话模板 人类反馈强化学习

读模型技术报告时，常见“预训练”“中期训练”“退火”“后训练”“SFT”“RL”这些词。它们描述的是同一个模型在不同阶段、用不同数据和目标接受的训练。

1. 预训练（pre-training）。在数万亿token的网页、书籍、代码等文本上做下一个token预测（见自回归生成），数据经过大规模清洗（见预训练语料的清洗、过滤与去重）。这一阶段消耗绝大部分算力，模型学到语言、知识和基本推理能力，得到基座模型（见基座模型与对话模型）。

2. 中期训练（mid-training）与退火（annealing）。预训练末期，学习率逐渐降到很低（见学习率与学习率调度），同时把数据换成更高质量的混合：更多数学、代码、教科书式文本、合成数据，有时还专门做长上下文扩展。Llama 3的报告描述了在退火阶段上调高质量数据比例的做法；MiniCPM与WSD学习率的WSD学习率调度让“稳定阶段之后接一个短的衰减阶段”成为常见做法；OLMo 2则把这一阶段明确称为mid-training并公开了数据。这一阶段的界线在不同报告中并不统一。

3. 后训练（post-training）。把只会续写的基座模型变成听指令、会对话、安全的助手：

  • 监督微调（SFT）：在“指令—回答”对上训练（见指令微调与对话模板、损失掩码：只对回答计算损失）。
  • 偏好优化：用偏好数据做RLHF或DPO（见人类反馈强化学习、直接偏好优化家族）。
  • 强化学习：在数学、代码等可验证任务上做大规模RL（见可验证奖励强化学习（RLVR）），这是推理模型的关键一步。

InstructGPT与RLHF确立了“SFT → 奖励模型 → PPO”的三步范式；Tülu 3开放后训练等开放工作公开了完整的后训练配方。

算力分布。传统上预训练占了绝大部分算力，后训练只占很小一部分；推理模型出现后，强化学习阶段的算力投入显著增加。

继续预训练。拿已有的基座模型，在某个领域（医学、法律、代码）或某种语言的大量文本上继续做预训练，再做后训练，叫继续预训练或领域自适应预训练（见领域与任务自适应预训练）。

例子

一个虚构的70亿参数模型的训练计划：

  • 预训练：8万亿token网页+代码，学习率恒定在3×10^−4（WSD的稳定段）。
  • 退火：最后2000亿token，学习率线性降到0，数据中数学和代码比例从15%提高到40%，加入长文档把上下文从8K扩到32K。
  • SFT：100万条指令数据，训练2轮。
  • 偏好优化：20万对偏好数据做DPO。
  • RL：在5万道数学和代码题上做可验证奖励强化学习。

（数字为示意。）前两步得到“基座模型”，后三步得到“指令模型/对话模型”。

容易误解的地方

  • “中期训练”“退火”“继续预训练”在不同报告里含义有重叠，读的时候以报告里描述的数据和学习率为准，而不是名称。
  • 后训练能显著改变行为和风格，但很难弥补预训练中没学到的知识。
