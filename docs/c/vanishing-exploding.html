梯度消失与梯度爆炸

Vanishing and Exploding Gradients

也叫：vanishing gradient　exploding gradient　梯度弥散　梯度不稳定　长程依赖　long-term dependency

在交互版中打开（看它长在树上的哪里）

反向传播时梯度要连乘许多层的导数：每层都小于1就指数级趋于0（消失），都大于1就指数级变大（爆炸），导致深层或长序列网络训练不动或数值溢出。

先要会：反向传播 链式法则 神经元与激活函数

反向传播把误差信号从输出往回传，每经过一层都要乘上这一层的局部导数（多维时是雅可比矩阵与海森矩阵中的雅可比矩阵）。传过L层，就是L个因子连乘。连乘有一个残酷的性质：每个因子略小于1，乘几十次就接近0；略大于1，乘几十次就是天文数字。

  • 梯度消失：靠近输入的层几乎收不到梯度，参数不更新，网络等于只有最后几层在学。对循环网络，这意味着学不到长距离依赖——第100步的误差传不回第1步。
  • 梯度爆炸：梯度突然变得极大，一步更新把参数推到很远的地方，损失变成NaN。

原因：早期网络常用sigmoid激活，它的导数最大只有0.25，叠10层就至少缩小到百万分之一。循环网络在每个时间步都乘同一个权重矩阵，矩阵最大奇异值小于1就消失、大于1就爆炸。

解决办法（基本都对应图上的重要节点）：

  • 换激活函数：ReLU在正区间导数恒为1。
  • 好的参数初始化：让每层输出和梯度的方差保持不变，见Xavier初始化。
  • 门控与加法通路：LSTM用细胞状态的加法更新让梯度能长距离流动；残差连接（ResNet）给梯度一条“直通”路径。
  • 归一化层：把每层激活拉回稳定的尺度。
  • 对爆炸，直接用梯度裁剪截断。

梯度消失问题（1994）系统分析了循环网络中的这一问题，它是LSTM、残差网络等一系列结构设计的直接动机。

例子

sigmoid导数最大0.25。10层连乘：0.25¹⁰ ≈ 9.5×10⁻⁷，梯度缩小到不足百万分之一。

循环网络展开100步，若每步的放大系数是0.9：0.9¹⁰⁰ ≈ 2.7×10⁻⁵；若是1.1：1.1¹⁰⁰ ≈ 13781。系数只差0.2，结果相差约5亿倍。

容易误解的地方

  • 梯度消失不等于“梯度恰好为0”，而是小到相对于其他层可以忽略，更新几乎停滞。
  • 有了ReLU、残差和归一化之后，几百层的网络也能正常训练，但问题没有消失，换个结构（如很深的无归一化网络）仍会出现。
