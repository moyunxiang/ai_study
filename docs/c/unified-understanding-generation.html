统一理解与生成

Unified Multimodal Understanding and Generation

也叫：统一多模态模型　Unified Multimodal Model　UMM　理解生成一体化　统一模型　Any-to-Any　任意模态生成　多模态生成理解统一　自回归+扩散

在交互版中打开（看它长在树上的哪里）

用一个模型既能看懂图像、回答问题，又能按指令生成和编辑图像，而不是理解和生成各用一个模型。

理解模型（VLM）输出文字，生成模型（扩散）输出图像，两者长期分开。统一的动机有二：一个模型更简单，且理解与生成可能互相促进。路线大致有四类。一是全离散自回归：图像离散成token与文字一起做下一token预测（Chameleon早期融合、Emu3纯下一词预测、理解与生成统一Janus）。二是自回归加扩散：同一个Transformer对文字做自回归、对图像做扩散（Transfusion、Show-o、BAGEL统一预训练）。三是把LLM当“大脑”，用可学习查询把其输出接到外部扩散解码器（MetaQuery、BLIP3-o）。四是全部用扩散（MMaDA多模态扩散）。

GPT-4o原生图像生成的原生图像生成让这个方向受到广泛关注。悬而未决的问题包括：理解和生成用同一种视觉表示还是各用一套（理解与生成统一Janus的解耦与UniTok统一分词器的统一分词器之争），以及生成能力是否真的反过来提升了理解。
