状态、观测与动作

State, Observation and Action

也叫：partially observable　部分可观测性　观测空间　observation space　动作空间　部分可观测　状态空间　观察　POMDP　感知输入

在交互版中打开（看它长在树上的哪里）

状态是世界此刻的完整情况，观测是机器人的传感器实际看到的那部分，动作是它下一步发给电机的指令；机器人策略就是一个从观测映射到动作的函数。

语言模型的输入和输出都是token，很清楚。机器人则不同：它面对的是连续变化的物理世界，要先回答三个问题——世界现在是什么样（状态），我能感知到什么（观测），我能做什么（动作）。所有机器人学习的论文，第一步都是定义这三样东西。

状态 s：描述世界此刻所需的全部信息，例如桌上每个物体的位置和速度、机械臂每个关节的角度、抽屉开了多少。知道了状态和动作，物理规律就决定了下一刻的状态。这正是马尔可夫决策过程里的“状态”。

观测 o：机器人的传感器实际给出的数据。典型的观测包括：一到几路相机图像（见图像作为张量），可能有深度图或点云；本体感知，即机器人自身的关节角度、夹爪开合度、力传感器读数（见自由度、运动学与本体感知）；以及一句语言指令。观测通常只是状态的一部分——相机看不到被遮挡的物体，也看不到物体的质量和摩擦——所以机器人问题严格说是部分可观测的，策略常常要结合过去几帧观测来推断状态。

动作 a：每个控制周期发给机器人的指令。常见几种：各关节的目标角度或角度增量；末端执行器（手爪）在空间里的位移和旋转增量，再由逆运动学换算成关节角；夹爪开合；有时直接是电机力矩。选哪种动作空间会显著影响学习难度，见动作表示：离散token、连续动作与动作块。

策略 π(a | o)：给定观测输出动作（或动作的分布）的函数，在深度学习时代就是一个神经网络。它在控制回路与控制频率里以固定频率反复运行：读观测→算动作→执行→再读观测。

它出现在哪里：端到端视觉运动策略第一次用一个网络直接从相机图像输出电机力矩；RT-1和RT-2与VLA以图像加语言为观测、以末端位移为动作；ALOHA与ACT以四路相机加14维关节角为观测、以14维目标关节角为动作。不同机器人的观测和动作格式各不相同，这正是Open X-Embodiment要统一数据格式的原因。

例子

一个7自由度机械臂加平行夹爪的桌面抓取任务：

  • 观测：两张224×224的RGB图像（每张224×224×3 = 150,528个数），加7个关节角和1个夹爪开合度，共8个数，再加指令「把红色杯子放进盘子」。
  • 动作：末端位移Δx、Δy、Δz，旋转Δroll、Δpitch、Δyaw，加夹爪开合，共7个数，每秒发10次。

可以看出，观测有30多万个数，动作只有7个——策略网络的大部分工作在于从图像里提取与动作有关的少量信息。

容易误解的地方

  • 观测不等于状态：图像里同样的画面，可能对应杯子里有水或没水，只看一帧无法区分。
  • 动作的含义取决于底层控制器：同样输出「关节角0.5」，是目标位置、增量还是速度，结果完全不同；换机器人时最容易在这里出错。
  • 本体感知虽然只有几个数，但对策略非常重要；只给图像的策略往往更难训练。
