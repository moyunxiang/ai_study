逆矩阵与伪逆

Matrix Inverse and Pseudoinverse

也叫：逆矩阵　矩阵求逆　matrix inverse　inverse matrix　伪逆　广义逆　pseudoinverse　pseudo-inverse　Moore-Penrose pseudoinverse　Moore-Penrose伪逆　正规方程　normal equation　线性方程组　可逆矩阵　奇异矩阵　singular matrix

逆矩阵把一个线性变换“撤销”回去；矩阵不可逆或不是方阵时，用伪逆给出最小二乘意义下最好的近似解。

先要会：向量、矩阵与张量 矩阵乘法与线性变换 矩阵的秩、迹与行列式

解线性方程组Ax = b是数值计算里最常见的任务之一：线性回归求最优权重、牛顿法求下一步、卡尔曼滤波更新状态，最后都落到这一步。

逆矩阵。如果方阵A满足A·A⁻¹ = A⁻¹·A = I（I为单位阵），A⁻¹就是A的逆，方程的解是x = A⁻¹b。A可逆当且仅当它满秩、行列式不为0（见矩阵的秩、迹与行列式）。两个常用公式：(AB)⁻¹ = B⁻¹A⁻¹，以及对角阵的逆就是把对角元素逐个取倒数。

伪逆（Moore–Penrose pseudoinverse）。数据点多于未知数时（方程比未知数多，一般没有精确解），或者A本身不满秩时，普通的逆不存在。伪逆A⁺给出一个“最好”的答案：x = A⁺b是使‖Ax − b‖²最小的解，若这样的解有很多个，取其中范数最小的那个。用特征分解与奇异值分解计算最直接：A = UΣVᵀ，则A⁺ = VΣ⁺Uᵀ，Σ⁺是把非零奇异值取倒数、零仍为零。A列满秩时，A⁺ = (AᵀA)⁻¹Aᵀ，这正是线性回归的正规方程解。

实际计算时不求逆。数值软件几乎从不真的算出A⁻¹再相乘，而是用LU、Cholesky或QR分解直接解方程（见LU、Cholesky与QR分解），更快也更准。A接近奇异时，解会对输入的微小扰动极其敏感，这由条件数刻画，见数值稳定性：上溢、下溢与条件数。给AᵀA加上λI再求逆，就是岭回归与L2正则回归：它让矩阵一定可逆，也减小了这种敏感性。

它出现在哪里。高斯过程回归的预测需要求核矩阵的逆，N个样本要O(N³)计算，这是它难以扩展的原因；二阶优化器如自然梯度、K-FAC、Shampoo都要对曲率矩阵（或其近似）求逆或求逆平方根。

例子

A = [[2, 1], [1, 1]]，det(A) = 1，A⁻¹ = [[1, −1], [−1, 2]]。解Ax = (3, 2)得x = (1, 1)。

伪逆：拟合直线y = wx穿过三点(1, 1)、(2, 2)、(3, 2)。A是列向量(1, 2, 3)，b = (1, 2, 2)。AᵀA = 14，Aᵀb = 1 + 4 + 6 = 11，w = 11/14 ≈ 0.786，这就是最小二乘斜率。

容易误解的地方

  • 代码里写inv(A) @ b通常是坏习惯，应调用solve(A, b)或lstsq。
  • 伪逆对很小的奇异值取倒数会放大噪声；实际实现会把小于某个阈值的奇异值当作0。
