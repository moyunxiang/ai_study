轨迹、回合与rollout

Trajectories, Episodes and Rollouts

也叫：trajectory　轨迹　episode　回合　幕　rollout　rollouts　采样轨迹　transition　转移样本　episode return　回合回报

在交互版中打开（看它长在树上的哪里）

智能体与环境交互留下的一串“状态、动作、奖励”记录叫轨迹；从开始到结束的一整段叫一个回合（episode）；按某个策略把轨迹跑出来叫rollout。

先要会：马尔可夫决策过程 奖励、回报与折扣

强化学习的数据不是一张张独立的图片，而是智能体自己“玩”出来的一段段经历。几乎所有算法都在说“采样一批轨迹”“做一次rollout”“每个episode结束后更新”，先把这几个词分清楚。

轨迹（trajectory，常记作τ）。交互按时间展开：

τ = (s₀, a₀, r₁, s₁, a₁, r₂, …, s_T)

初始状态从某个分布采出，之后每一步策略给出动作a_t ~ π(·|s_t)，环境给出奖励和下一状态s_{t+1} ~ P(·|s_t, a_t)，见马尔可夫决策过程。一条轨迹出现的概率是

p(τ) = p(s₀) · Π_t π(a_t|s_t) · P(s_{t+1}|s_t, a_t)

策略参数只出现在π那一项里，这正是策略梯度能绕开未知环境求梯度的原因。

回合（episode，旧译“幕”）。一盘棋、一局游戏、一次机械臂抓取，从初始状态到终止状态的完整轨迹。回合结束后环境重置，见时域、分幕任务与终止。每个回合的总奖励（episode return）是最常见的学习曲线纵轴。

rollout。“把策略放进环境（或模型）里跑出一段轨迹”这个动作本身。在线算法如PPO每轮先rollout若干步再更新；蒙特卡洛树搜索UCT和AlphaGo里的rollout指从某个局面用快速策略一直下到终局来估计胜率；在基于模型的强化学习里，rollout也可以在学到的模型里进行，叫“想象rollout”。

转移（transition）。轨迹里的一步(s, a, r, s')，是TD类方法和经验回放存储、采样的最小单位。

例子

一个走迷宫的回合：s₀=起点，a₀=右，r₁=0，s₁，a₁=下，r₂=0，s₂=终点，r=+1，回合结束，T=2。这一条轨迹包含2个转移：(起点, 右, 0, s₁)和(s₁, 下, 1, 终点)。PPO若并行开8个环境、每个rollout 128步，一轮更新就用8×128=1024个转移，其中可能跨越多个回合。

容易误解的地方

  • rollout的长度和回合长度是两回事：rollout可以在回合中途截断，下一轮接着跑，截断处要用价值估计补上未来的回报。
  • 论文里的“步数”有时指环境步（每个转移算一步），有时指梯度更新步；Atari里还常把跳帧后的原始帧数也算进去，比较样本效率时要看清单位。
