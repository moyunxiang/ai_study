深度RL的规模化

Scaling Deep Reinforcement Learning

也叫：RL scaling　scaling RL　RL规模定律　RL scaling law　大网络RL　深层RL网络　参数扩展　value-based scaling　BRO　SimBa

在交互版中打开（看它长在树上的哪里）

监督学习里“模型越大越好”在RL里长期不成立；近几年的工作在找让RL网络、数据和算力也能稳定扩展的配方。

深度RL长期使用两三层的小网络，直接加大往往更不稳定。IMPALA与V-trace、R2D2等分布式架构先在数据量上扩展；网络规模的突破来得更晚：用分类训练价值函数发现把价值回归改成分类更易扩展，SimBa用残差和层归一化让参数变大也有收益，BBF在Atari 100k上靠更大的网络加重置达到人类水平的样本效率，PQN简化深度TD用层归一化去掉目标网络与回放。

价值型RL的可预测扩展报告价值型RL的数据与算力消耗可按规律预测，1000层网络的自监督RL把自监督目标条件RL的网络加深到1000层并出现新的能力。争论在于这些配方能否推广到在线、稀疏奖励和真实环境，以及与幂律与规模定律的类比到底有多可靠。
