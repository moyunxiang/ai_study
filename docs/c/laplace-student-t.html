拉普拉斯分布与学生t分布

Laplace and Student-t Distributions

也叫：拉普拉斯分布　Laplace distribution　双指数分布　double exponential　学生t分布　t分布　Student's t-distribution　Student t　t-distribution　柯西分布　Cauchy distribution　厚尾分布　重尾分布　heavy-tailed distribution　fat tails　稳健统计　robust statistics

比高斯“尾巴更厚”的两种连续分布：拉普拉斯分布在中心更尖、对应L1损失和L1正则；学生t分布允许偶尔出现很大的值，对离群点更宽容，t-SNE和t检验都用到它。

先要会：高斯分布 随机变量与概率分布

高斯分布的尾部衰减极快：离均值5个标准差的概率不到百万分之一。但真实数据常有离群点，高斯假设会让模型为了照顾它们而严重偏移。这时需要尾巴更厚的分布。

拉普拉斯分布。密度p(x) = (1/2b)·exp(−|x − μ| / b)，像两个背靠背的指数分布（见泊松分布、指数分布与均匀分布），在μ处有个尖顶。它与L1范数一一对应：

  • 假设误差服从拉普拉斯分布，最大似然估计就等价于最小化绝对误差之和（MAE，见回归损失：MSE、MAE与Huber），解是中位数而不是均值，因而对离群点更稳健。
  • 给权重加拉普拉斯先验，求先验、后验与贝叶斯推断估计就等价于L1正则，即Lasso与L1稀疏；尖顶让很多权重恰好落在0上（见正则化与权重衰减）。
  • 差分隐私的拉普拉斯机制给查询结果加拉普拉斯噪声，噪声尺度b = 敏感度/ε。

学生t分布。自由度为ν的t分布，密度正比于(1 + x²/ν)^(−(ν+1)/2)，尾部按幂次衰减而不是指数衰减。ν = 1时是柯西分布，尾巴厚到连均值都不存在；ν趋于无穷时就变成标准正态分布。

  • t检验：样本少时，用样本标准差代替真实标准差会引入额外的不确定性，均值的标准化统计量服从t分布而不是正态分布，所以置信区间要更宽，见方差、种子与统计显著性。
  • t-SNE在低维空间里用自由度为1的t分布衡量点之间的相似度：厚尾让中等距离的点在二维图上可以被推得更开，缓解了“所有点挤成一团”的拥挤问题，名字里的t就来自这里。
  • 稳健回归和一些贝叶斯模型用t分布作似然，自动降低离群点的权重。

例子

同样方差为1，比较x = 4处的尾部概率P(|X| > 4)：标准正态约6×10⁻⁵；拉普拉斯（b = 1/√2）约exp(−4√2) ≈ 3.5×10⁻³，大了约50倍。

数据(1, 2, 3, 4, 100)：均值22（高斯/MSE的答案），中位数3（拉普拉斯/MAE的答案）。一个离群点就把均值拉偏了，中位数几乎不受影响。

容易误解的地方

  • 小样本时用正态分布的1.96算95%置信区间会偏窄；n = 5时t分布的对应临界值约2.78。
  • 柯西分布这类极厚尾的分布没有方差，样本均值不会随样本增多而稳定下来，大数定律对它不成立（见大数定律与中心极限定理）。
