视觉token压缩

Visual Token Compression

也叫：视觉token剪枝　Visual Token Pruning　Token Pruning　Token Merging　token合并　视觉token裁剪　VLM推理加速　高效VLM　Efficient VLM

在交互版中打开（看它长在树上的哪里）

一张图常被编码成上千个token，其中很多是冗余的；在送进或经过语言模型时删掉、合并它们以加速推理。

高分辨率和视频让视觉token数暴涨：一段视频轻易就有几万个视觉token，远多于文字。FastV视觉token剪枝发现语言模型深层几乎不关注视觉token，在第2层后按注意力删掉一半，计算量减少约45%而几乎不掉点，成为这一方向的基线。其他做法包括在视觉编码器内部合并相似token（Token Merging）、在连接器里做像素重排或池化（DeepSeek-VL2）、对视频按相邻帧差异剪掉重复图块（VideoLLaMA 3），以及直接设计输出更少token的编码器（FastVLM高效编码）。

争论点在于：按注意力分数剪枝与FlashAttention这类高效内核冲突；对需要细节的OCR和定位任务，剪掉的token可能恰好是关键信息。与之相对的思路是让模型主动决定看哪里（V*引导视觉搜索），而不是被动删token。
