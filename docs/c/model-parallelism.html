模型并行与3D并行

Model Parallelism and 3D Parallelism

也叫：模型并行　model parallelism　张量并行　tensor parallelism　TP　流水线并行　pipeline parallelism　PP　3D并行　4D并行　序列并行　sequence parallelism　上下文并行　context parallelism　CP　1F1B

在交互版中打开（看它长在树上的哪里）

单张卡装不下整个模型时，把矩阵按行列切开分给多卡（张量并行），或把层分段串成流水线（流水线并行），再与数据并行组合。

数据并行要求每张卡都放得下完整模型，模型超过单卡显存后就需要把模型本身切开。Mesh-TensorFlow张量切分提出用统一的方式描述张量沿哪些维度切到哪些设备上；Megatron-LM模型并行针对Transformer给出了简洁的张量并行方案，把注意力头和MLP的矩阵按列、按行切分，每层只需两次通信。

另一种切法是按层分段：GPipe流水线并行把一个批次拆成多个微批次在各段之间流水，PipeDream与1F1B流水线的1F1B调度进一步减少显存和空泡。Megatron 3D并行把张量、流水线、数据三种并行组合起来，在数千张GPU上训练万亿参数模型；长序列又引出了把序列切开的Ring Attention序列并行等序列/上下文并行。

如何为给定模型和集群自动选出最优切分组合，以及MoE带来的专家并行，是持续的工程主题。
