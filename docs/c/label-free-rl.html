无外部奖励的推理强化学习

Label-Free and Self-Rewarding RL for Reasoning

也叫：无监督RL　无标签强化学习　label-free RL　unsupervised RLVR　自我奖励　self-rewarding　内部反馈　RLIF　self-certainty　自博弈　self-play　零数据　zero data　自我出题　intrinsic reward

在交互版中打开（看它长在树上的哪里）

不用标准答案或人工题库，只靠多数投票、模型自身的置信度或自己出题来产生奖励，训练推理能力。

DeepSeek-R1式的可验证奖励RL离不开有标准答案的题目。2025年出现了几种去掉这一依赖的做法：TTRL测试时强化学习用多次采样的多数答案当伪标签；Intuitor内部反馈RL把模型对自己输出的确信程度（自确定性）当奖励；Absolute Zero零数据自博弈让模型自己出代码推理题、由代码执行器判对错，连题目都不需要。更早的STaR自举推理则用模型自己生成的推理过程自举训练。

这些方法常常在小模型上取得惊人的提升，但虚假奖励发现，在某些模型上连随机或错误的奖励也能带来提升，提醒人们：收益可能只是激发了底座已有的能力（参见RLVR能否带来新推理）。主要风险是模型学会「自信地犯错」，或强化群体共同的错误。
