分层强化学习与时间抽象

Hierarchical RL and Temporal Abstraction

把决策分成多个时间尺度：高层每隔一段时间选一个子目标或一项技能（选项），低层在这段时间里逐步执行原子动作。这样探索、信用分配和迁移都可以在更粗的粒度上进行。

先要会：马尔可夫决策过程 信用分配

人做“去机场”这件事，不会逐一规划每一块肌肉的收缩，而是“出门→打车→安检”，每一步再细分。平坦的强化学习只有一个时间尺度，每一步都从原子动作里选，任务一长，探索和信用分配都会变得极难。分层强化学习（HRL）引入时间抽象：让一个决策覆盖很多步。

选项框架。Options时间抽象框架把一项可复用的技能形式化为选项o = (I, π_o, β)：可以在哪些状态启动（I），启动后按什么策略执行（π_o），在每个状态以多大概率结束（β）。高层策略在选项之间选择。由于选项持续的步数不固定，从高层看问题变成半马尔可夫决策过程（SMDP）：转移可以花随机长度的时间，回报和折扣按实际经过的步数累计。原子动作是只持续一步的特殊选项，所以这一框架严格包含普通MDP。固定步数的宏动作（macro action）是它的最简单形式。

几条主要路线。

  • 子目标式：高层输出一个目标（例如某个位置或某个状态特征），低层是目标条件强化学习的策略，负责到达它。封建式分层RL提出了“管理者-工人”的层级，h-DQN分层DQN和HIRO离策略分层RL是深度版本。
  • 价值分解式：MAXQ值函数分解把任务的价值函数按子任务层级分解。
  • 端到端学选项：Option-Critic用策略梯度同时学习选项内部策略和终止条件。
  • 无监督技能发现：先在没有任务奖励时学一组彼此可区分的技能，再让高层组合它们，例如DIAYN无奖励技能发现用互信息作为奖励（见互信息）。

难点。好的分层结构本身难以自动发现；高层和低层同时学习时，高层面对的“环境”（低层的行为）一直在变，是非平稳的；学到的选项也常退化为只持续一步或一直不结束。机器人里的“高层规划+低层技能”以及大模型智能体中的“规划器+执行器”可以看作同一思想的工程实现。

例子

四个房间组成的网格世界，从左上房间走到右下房间的目标格约需要40步。平坦Q-learning每一步都从上下左右4个动作中选，奖励要回传40步。定义4个“走到某扇门”的选项后，高层只需做约3次决策（门1→门2→目标），信用分配只跨3个高层步，探索也从“随机游走”变成“随机选一扇门走过去”。

容易误解的地方

  • 分层不保证更好：人为设计的子目标若与任务不匹配，最优解可能根本不在分层策略能表示的范围里。
  • 高层的折扣要按选项实际持续的步数计算，按高层决策次数打折是一个常见错误。
