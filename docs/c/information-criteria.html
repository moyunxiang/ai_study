信息准则AIC与BIC

Information Criteria: AIC and BIC

也叫：信息准则　information criterion　information criteria　AIC　赤池信息准则　Akaike information criterion　BIC　贝叶斯信息准则　Bayesian information criterion　Schwarz准则　SIC　边缘似然　marginal likelihood　模型证据　model evidence

在交互版中打开（看它长在树上的哪里）

不用验证集也能选模型的公式：AIC = 2k − 2ln L，BIC = k·ln n − 2ln L（k为参数数）。都是拟合优度减参数惩罚，BIC惩罚更重、更偏向简单模型。

先要会：最大似然估计 模型容量与欠拟合

高斯混合模型该用几个分量？多项式回归该用几次？自回归模型该看前几步？参数越多，训练集上的似然一定越高，所以不能只比似然。在数据很少、不舍得留出验证集的统计建模里，常用信息准则直接从训练结果里扣除复杂度。

AIC（赤池信息准则）。

AIC = 2k − 2·ln L̂

L̂是模型在训练数据上的最大似然值（见最大似然估计），k是自由参数个数。越小越好。它的推导目标是估计模型在新数据上的期望对数似然（与真实分布的KL散度有关）：训练集上的对数似然平均会高估约k，所以要扣回来。

BIC（贝叶斯信息准则）。

BIC = k·ln n − 2·ln L̂

n为样本数。它来自对贝叶斯模型证据（边缘似然）的大样本近似（见先验、后验与贝叶斯推断）。n ≥ 8时ln n > 2，BIC对每个参数的惩罚比AIC重，样本越多惩罚越重，因此更倾向选简单模型。它也可以理解为最小描述长度与“压缩即学习”的一种形式：k·ln n / 2大约是用合适精度描述k个参数需要的信息量。

两者的取舍。如果真实模型就在候选集中，BIC在样本足够多时能以概率1选中它（一致性）；AIC则更关注预测性能，倾向于选稍复杂一些、预测误差更小的模型。实践中两者常一起报告。

适用范围与局限。

  • 它们需要模型有明确的似然，并且参数个数k定义清楚。对深度神经网络，“有效参数数”远小于名义参数数（见模型容量与欠拟合），这些公式基本不适用，深度学习里主要用训练集、验证集与测试集中的验证集或交叉验证来选模型（见超参数与调参）。
  • 只能比较在同一份数据上拟合的模型。

它出现在哪里。选高斯混合的分量数（见高斯混合模型）、因子分析的因子数（见因子分析与概率PCA）、时间序列的阶数、回归中的变量子集（见特征选择），以及统计软件输出的标准模型比较表。

例子

1000个样本，比较两个GMM：3个分量（一维数据，k = 8，ln L̂ = −1520）与5个分量（k = 14，ln L̂ = −1510）。AIC：3分量为16 + 3040 = 3056，5分量为28 + 3020 = 3048，选5分量。BIC：ln 1000 ≈ 6.91，3分量为55.3 + 3040 = 3095.3，5分量为96.7 + 3020 = 3116.7，选3分量。多出的6个参数只换来10的对数似然提升，BIC认为不值得。

容易误解的地方

  • 信息准则的绝对值没有意义，只有同一数据上不同模型之间的差值有意义。
  • 似然存在退化（如GMM某个分量方差趋于0）时，信息准则也会被误导，要先保证拟合正常。
