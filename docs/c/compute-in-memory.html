存内计算

Compute-in-Memory

也叫：CIM　存算一体　In-Memory Computing　IMC　Processing-in-Memory　PIM　近存计算　Near-Memory Computing　模拟存内计算　数字存内计算　DIMC　存储内计算

在交互版中打开（看它长在树上的哪里）

让乘加运算直接发生在存放权重的存储阵列里或紧挨着它，不再把数据来回搬运，以此绕开内存墙。

神经网络推理的大部分能量和时间不是花在乘法上，而是花在把权重从内存搬到计算单元的路上，这就是内存墙。存内计算的思路是让计算去找数据：要么在存储单元本身做运算，要么把存储和计算交织铺在同一块芯片上。

路线大致分三类。模拟存内计算把权重写成器件的电导，利用欧姆定律和电流求和一次完成矩阵向量乘，早期有Intel ETANN模拟神经芯片，近年代表是IBM的模拟存内计算芯片；数字存内计算把SRAM电路改造成数字乘加单元，代表是d-Matrix Corsair存内计算；近存计算则取消片外内存、把存储分散到每个核旁边，代表是IBM的IBM NorthPole。Taalas HC1：模型固化芯片干脆把某个模型的权重固化进芯片金属层，是这个方向的极端形式。

争论集中在两点：片上存储容量有限，大模型必须跨多芯片切分；模拟方案还要对付器件噪声、漂移和模数转换开销。目前它主要用于推理，训练仍以GPU加HBM为主。
