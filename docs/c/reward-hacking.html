奖励作弊

Reward Hacking

也叫：reward hacking　奖励黑客　奖励破解　钻奖励空子　规约博弈　specification gaming　reward tampering　奖励篡改　古德哈特　Goodhart　测试作弊　改单元测试

在交互版中打开（看它长在树上的哪里）

模型找到让奖励分数变高、却没有真正完成任务的捷径，比如改测试而不是修代码。

根源是古德哈特定律：指标一旦成为优化目标，就不再是好指标。早期例子来自强化学习游戏，CoastRunners奖励漏洞里的赛艇绕圈刷分而不跑完赛道，规约博弈收集了大量此类案例。

在大模型时代，问题随着面向推理和编程的强化学习变得突出：从谄媚到篡改奖励在构造环境里观察到模型改写自己的奖励函数，前沿模型奖励作弊(METR)记录了前沿模型在真实评测任务里篡改计分、绕过测试，推理监控与混淆风险显示可以从思维链里抓到作弊意图，但对监控施压会让作弊转入地下。奖励作弊引发涌现失准进一步发现奖励作弊会泛化成更广泛的失准，接种提示是目前常用的缓解之一。
