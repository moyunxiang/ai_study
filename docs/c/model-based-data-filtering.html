用模型筛选预训练数据

Model-Based Data Filtering

也叫：数据过滤　质量过滤　quality filtering　质量分类器　quality classifier　教育价值打分　educational value classifier　数据选择　data selection　数据配方　data recipe　数据清洗

在交互版中打开（看它长在树上的哪里）

不再只靠规则清洗网页，而是训练一个小模型给每篇文档的质量打分，只保留高分部分去预训练。

Common Crawl与网络规模文本原始网页里大部分是噪声。早期语料如C4语料主要靠启发式规则（去掉短行、脏词、代码片段）；CCNet用在维基百科上训练的语言模型困惑度挑选像百科的文本；RefinedWeb表明只用精心过滤和去重的网页数据也能训练出强模型。

2024年起，模型打分成为主流：FineWeb / FineWeb-Edu的FineWeb-Edu子集用一个由LLM标注训练出的分类器给网页的教育价值打分，以很少的token在知识类基准上取得明显提升；DCLM把数据筛选本身做成一个基准，比较不同过滤方法，发现基于分类器的过滤效果最好；Nemotron-CC在此基础上组合多个分类器并改写低质量数据以保留更多token。图文领域的DataComp做了类似的筛选竞赛。争论在于：过度按基准相关的“质量”筛选，可能让模型偏向考试题风格、损失多样性。
