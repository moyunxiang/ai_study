Transformer层的结构

Anatomy of a Transformer Block

也叫：Transformer块　decoder block　Pre-LN　FFN层　transformer layer

在交互版中打开（看它长在树上的哪里）

Transformer由几十个结构相同的层堆成，每层只有两个子层：多头自注意力（让token之间交换信息）和逐位置的前馈网络（各自加工），外加残差连接和归一化。

先要会：自注意力与多头注意力 残差连接 归一化层 多层感知机

大语言模型看起来很复杂，但把嵌入层和输出层拿掉后，中间就是同一种层重复堆叠：GPT-3是96层，LLaMA-7B是32层。读懂一层，就读懂了整个模型的主体。

两个子层，分工明确。

  • 多头自注意力（见自注意力与多头注意力）：每个token根据与其他token的相关性，把它们的信息汇总进来。这是token之间唯一交换信息的地方。
  • 前馈网络FFN：一个两层的多层感知机，对每个位置独立地做同样的变换，不看其他位置：FFN(x) = W2·ReLU(W1·x + b1) + b2。中间层通常放宽到4倍，即d → 4d → d。可以粗略理解为：注意力负责“收集”，FFN负责“加工和查记忆”。

残差和归一化把它们包起来。每个子层外面都有一条残差连接，再配一个归一化层。今天的标准写法（pre-LN）是：

x = x + Attention(LN(x)) x = x + FFN(LN(x))

原始Transformer用的是post-LN，即x = LN(x + Sublayer(x))，层数一多就难训。Pre-LN Transformer把LN挪进支路后，主干上的x只被加、从不被改写，梯度直通，GPT-2起普遍采用。

整个模型。token先经嵌入向量变成d维向量（必要时加上位置编码），穿过L个这样的层，形状始终是n×d；最后做一次LN，乘以输出矩阵得到每个位置在词表上的logits，过Softmax与logits得到下一个token的概率。

现代版本的改动（以LLaMA为代表）：LayerNorm换成RMSNorm；FFN换成门控的GLU变体与SwiGLU（三个矩阵，中间维度约8d/3，参数量与4d的两矩阵版本相当）；位置编码换成旋转位置编码RoPE；去掉偏置项。之后的模型又普遍用分组查询注意力GQA减少注意力的键值头。主体结构没有变。

例子

一层里张量形状怎么走（批大小B = 2，序列长n = 10，d = 512，h = 8个头）：

1. 输入x：2×10×512。 2. LN后乘W_Q、W_K、W_V，各得2×10×512，拆成8个头：2×8×10×64。 3. 每个头算分数Q·Kᵀ：2×8×10×10；softmax后乘V：2×8×10×64。 4. 8个头拼回2×10×512，乘W_O（512×512），加回x：2×10×512。 5. LN后进FFN：乘W1变成2×10×2048，过ReLU，乘W2回到2×10×512，加回x。

输出形状与输入完全相同，所以可以一层层堆下去。

参数量（忽略偏置和LN）：注意力4个d×d矩阵 = 4d²；FFN两个矩阵d×4d和4d×d = 8d²；每层约12d²。d = 512时是12×262,144 ≈ 315万。GPT-3：96层、d = 12288，12×96×12288² ≈ 1739亿，加上约6亿的词嵌入，正是它的1750亿参数。

容易误解的地方

  • FFN占每层约三分之二的参数，常被忽视；“Transformer = 注意力”的说法不完整。
  • FFN是逐位置的，所以“看上下文”只发生在注意力里。如果把注意力换成别的序列混合方式（如Mamba状态空间模型），FFN部分通常原样保留。
  • 原论文的编码器层和这里描述的一样；解码器层在两个子层中间还多一个交叉注意力（见编码器-解码器）。
