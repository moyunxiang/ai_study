Jensen不等式

Jensen's Inequality

也叫：琴生不等式　詹森不等式　凸函数不等式

在交互版中打开（看它长在树上的哪里）

对凸函数f，先取平均再代入不超过先代入再取平均：f(E[X]) ≤ E[f(X)]；对log这类凹函数方向相反。它是ELBO等下界推导的核心一步。

先要会：凸函数与凸优化 期望与方差

机器学习里经常遇到“期望套在函数里面”的式子，比如log E[·]，难以直接计算或优化；而“函数套在期望里面”的E[log ·]却可以用采样估计、可以求梯度。Jensen不等式告诉我们这两者之间的大小关系，于是可以用好算的一边去界住难算的一边。

陈述：若f是凸函数与凸优化函数，对任意随机变量X，

f(E[X]) ≤ E[f(X)]

若f是凹函数（如log），不等号反向：log E[X] ≥ E[log X]。等号成立当且仅当X几乎是常数，或f在X取值的范围内是线性的。

几何直觉：凸函数图像上任取两点连成弦，弦总在函数图像上方。E[f(X)]是弦上的点（函数值的加权平均），f(E[X])是曲线上的点，所以前者大。

在AI里最重要的一次使用：ELBO。隐变量模型要最大化log p(x) = log Σ_z p(x, z)，求和在log里面，没法分解。引入任意分布q(z)，写成log E_q[p(x, z)/q(z)]，再用Jensen把log移进期望：

log p(x) ≥ E_q[log p(x, z) − log q(z)]

右边就是变分推断与ELBO，可以采样估计并求梯度。两边的差恰好是q与真实后验之间的KL散度。EM算法算法和变分自编码器VAE都建立在这个下界上（见EM算法、隐变量模型）。

其他出现处：证明KL散度非负（Gibbs不等式）只需对−log用一次Jensen；DDPM的训练目标同样是对数似然的变分下界。

例子

X等概率取1或3，E[X] = 2。

  • 凸函数f(x) = x²：f(E[X]) = 4，E[f(X)] = (1 + 9)/2 = 5，4 ≤ 5。
  • 凹函数log：log E[X] = log 2 ≈ 0.693，E[log X] = (log 1 + log 3)/2 ≈ 0.549，0.693 ≥ 0.549。

两者的差0.144就是“把log移进期望”丢掉的部分；X越分散，丢得越多。在ELBO里这个差就是q离真实后验有多远。

容易误解的地方

  • 方向很容易记反：凸函数是“平均的函数 ≤ 函数的平均”，记住x²的例子就不会错。
  • Jensen给出的是下界，最大化下界不保证真实目标同样提高，只有界足够紧时两者才一致。
  • 函数必须在整个取值范围上凸（或凹），局部凸不够。
