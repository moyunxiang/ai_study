置信区间、标准误与误差棒

Confidence Intervals, Standard Errors and Error Bars

也叫：置信区间　confidence interval　CI　95%置信区间　95% CI　标准误　标准误差　standard error　SE　SEM　均值标准误　误差棒　误差线　error bar　error bars　Wilson区间　Wilson interval　可信区间　credible interval　误差范围　margin of error　聚类标准误　clustered standard errors

给估计值配上误差范围，如“准确率72%，95%置信区间[69%, 75%]”。标准误衡量估计值本身的波动，误差棒把它画在图上；只报一个数无法判断差距是否可信。

先要会：期望与方差 大数定律与中心极限定理

在500道题上测得准确率72%，换一批同样难度的500道题，结果可能是70%或74%。测得的数只是一次抽样的结果，真正想知道的是“真实准确率大概在什么范围”。

标准误。估计量自己的标准差叫标准误（standard error, SE）。样本平均的标准误是s / √n，s为样本标准差（见大数定律与中心极限定理）。准确率p̂的标准误是√(p̂(1 − p̂)/n)，因为每道题的对错是一个伯努利变量（见伯努利、二项、类别与多项分布）。

置信区间。最常用的近似是

估计值 ± z·SE

95%区间取z ≈ 1.96，90%取1.645。样本很少时，用学生t分布的临界值代替z，例如n = 5时约2.78（见拉普拉斯分布与学生t分布）。准确率接近0或1、或n很小时，正态近似不准，可以改用Wilson区间或自助法（bootstrap）。

怎么解读。95%置信区间的意思是：如果反复抽样、每次都按同样方法构造区间，大约95%的区间会覆盖真值。它不是“真值有95%概率落在这个区间里”（那是贝叶斯可信区间的说法，见先验、后验与贝叶斯推断），但实践中两者在数值上常常接近。

误差棒。图上每个点上下的竖线，可能表示标准差、标准误或95%置信区间，三者差别很大：标准差描述单次结果的离散程度，标准误和置信区间描述均值估计的不确定性。图注里必须写清楚是哪一种。

比较两个模型。两个区间不重叠时差异大致可信；重叠时不一定不显著。更好的做法是直接对差值构造置信区间：两个模型在同一套题上测试时，逐题计算差值做配对分析，区间会窄得多（见方差、种子与统计显著性）。

它出现在哪里。给评测加误差棒系统地讨论了如何给大模型评测加上标准误，包括题目彼此相关（如同一篇文章出多道题）时用聚类标准误；Chatbot Arena给每个模型的分数附带bootstrap置信区间；《Deep RL that Matters》复现性批评推动了强化学习论文报告多个种子的均值与置信区间。

例子

模型在500道题上答对360道，p̂ = 0.72，SE = √(0.72 × 0.28 / 500) ≈ 0.020，95%置信区间约0.72 ± 0.039，即[68.1%, 75.9%]。若另一个模型为74%，差距2个百分点落在误差范围内，单凭这个结果不能说它更好。题目增加到5000道，区间宽度缩到约±1.2个百分点。

容易误解的地方

  • 只跑一个随机种子时得到的置信区间只反映测试集抽样的不确定性，没有包含训练随机性带来的波动。
  • 在同一个测试集上反复比较、挑最好的报告，会让区间失去原来的覆盖概率，见多重比较与统计功效。
