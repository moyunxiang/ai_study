DH参数

Denavit–Hartenberg Parameters

也叫：DH参数　D-H参数　Denavit-Hartenberg　DH parameters　Denavit–Hartenberg参数　改进DH　modified DH　连杆参数　正运动学建模　URDF　指数积公式　product of exponentials

在交互版中打开（看它长在树上的哪里）

描述串联机械臂几何结构的一种标准约定：每个关节-连杆只用4个参数（关节角θ、连杆偏距d、连杆长度a、连杆扭角α）就确定相邻两个坐标系之间的变换，连乘起来就是正运动学。

先要会：位姿与齐次变换SE(3) 自由度、运动学与本体感知

一台6轴机械臂的正运动学（见自由度、运动学与本体感知）就是把6个关节各自的坐标变换（见位姿与齐次变换SE(3)）连乘起来。一般的刚体变换有6个自由度，但只要巧妙地选择每个连杆上坐标系的放法，相邻两个坐标系之间就只需要4个数。这套约定由Denavit和Hartenberg在1955年提出，称为DH参数，至今仍是机器人学教材和机械臂说明书的标准写法。

规则（标准DH）。第i个坐标系的z轴沿第i+1个关节的转轴方向，x轴沿相邻两个z轴的公垂线。于是从坐标系i−1到i的变换可以分解为四步：

T_{i−1,i} = Rot_z(θ_i) · Trans_z(d_i) · Trans_x(a_i) · Rot_x(α_i)

  • θ_i：绕z轴的旋转，对转动关节就是关节变量；
  • d_i：沿z轴的偏移，对移动关节它是关节变量；
  • a_i：沿x轴的距离，即连杆长度；
  • α_i：绕x轴的旋转，即相邻两个关节轴之间的扭角。

每个关节只有一个参数随运动变化，其余3个是机械结构决定的常数。整臂的末端位姿为T_0n = T_01·T_12·…·T_{n−1,n}。

变体与替代。Craig教材使用的“改进DH”把坐标系放在连杆的另一端，变换顺序不同，两种约定给出的参数表不能混用。现代软件常用其他描述方式：ROS机器人操作系统生态中的URDF文件直接给出每个关节相对父连杆的任意位姿；指数积（product of exponentials）方法只用各关节轴在初始姿态下的螺旋参数。仿真器如MuJoCo物理仿真也有各自的模型格式。

为什么学习型方法的人也要了解。机器人学习的论文常需要从关节角算出末端位姿（作为观测或动作），或在不同机器人之间转换动作空间（见动作表示：离散token、连续动作与动作块）；读懂厂商给的DH参数表，才能正确实现这些换算。

例子

一个平面两连杆机械臂，两段长度都为1米，所有α=0、d=0，DH参数为(θ₁, 0, 1, 0)和(θ₂, 0, 1, 0)。连乘后末端位置为x = cos θ₁ + cos(θ₁ + θ₂)，y = sin θ₁ + sin(θ₁ + θ₂)。取θ₁=90°、θ₂=−90°，得x=0+1=1、y=1+0=1，末端在(1, 1)。

容易误解的地方

  • 标准DH和改进DH的参数表看起来相似，用错约定会得到完全错误的运动学，查资料时首先确认用的是哪一种。
  • 相邻关节轴平行时，DH参数对微小的装配误差非常敏感，做精确标定时常改用其他参数化。
