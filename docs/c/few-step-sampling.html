少步采样与扩散蒸馏

Few-Step Sampling and Diffusion Distillation

也叫：一致性模型　consistency model　少步生成　一步生成　one-step generation　加速采样

在交互版中打开（看它长在树上的哪里）

扩散模型原本要调用网络几百上千次才生成一张图；少步采样用更好的求解器或蒸馏训练，把次数降到几十、几步甚至一步。

先要会：扩散：前向加噪与反向去噪 噪声调度与采样步数 知识蒸馏

扩散：前向加噪与反向去噪的反向过程是从纯噪声出发、一小步一小步去噪。DDPM（2020）采样要1000步，每步都要完整跑一次神经网络，生成一张图要几十秒到几分钟，远慢于GAN的一次前向。衡量这个代价的单位叫NFE（网络函数评估次数）。少步采样有两条路线。

不重训，换求解器。把去噪过程写成一个常微分方程（概率流ODE，见常微分方程与随机微分方程、分数函数与分数匹配），采样就是数值积分。DDIM给出一种确定性的跳步采样，几十步就能得到不错的图；EDM设计空间系统比较了时间离散方式和高阶求解器。这条路线一般在十几到几十步就到瓶颈：步子迈得太大，ODE轨迹是弯的，误差会累积（见噪声调度与采样步数）。

重训学生网络，即扩散蒸馏。用训练好的多步模型（教师）去教一个少步模型（学生）：

  • 渐进蒸馏与v预测：让学生一步走完教师两步的路程，反复折半，从8192步蒸到4步。
  • 一致性模型：训练网络把同一条ODE轨迹上任意一点都直接映射到终点，支持一步生成；潜空间一致性模型LCM把它用在潜空间扩散上，2到4步出图。
  • 分布匹配：不要求逐条轨迹对齐，只要求学生的输出分布与教师一致。分布匹配蒸馏DMD用两个分数函数之差作梯度，对抗扩散蒸馏SDXL Turbo（SDXL Turbo）结合对抗损失，都能做到1到4步。
  • 让路径本身变直：整流Rectified Flow通过重新配对噪声与数据把轨迹“拉直”，直线一步就能走完；捷径模型一步生成、MeanFlow一步生成直接学习大步长的平均速度。

代价：步数越少，多样性和细节通常越差，蒸馏还要额外训练；实际产品常在质量与速度之间选4到8步。

例子

假设一次网络前向要50毫秒：

  • DDPM 1000步：50秒；
  • DDIM 50步：2.5秒；
  • 蒸馏到4步：0.2秒；
  • 一步生成：0.05秒。

若还使用无分类器引导（见条件生成与引导），每步要算有条件和无条件两次，时间再翻倍；很多蒸馏方法把引导也蒸进学生，省掉这一倍。渐进蒸馏从8192步折半到4步需要log₂(8192/4) = 11轮。

容易误解的地方

  • 论文里的“一步”“四步”指NFE，不包括文本编码器、VAE解码等其他开销。
  • 少步模型在FID上接近教师，不代表在多样性、文字渲染、细节上同样接近，见生成质量指标：IS与FID。
  • 蒸馏后的学生通常失去了调节步数换质量的灵活性，也更难再做微调。
