联合熵、条件熵与信息增益

Joint Entropy, Conditional Entropy and Information Gain

也叫：条件熵　conditional entropy　联合熵　joint entropy　信息增益　information gain　信息增益比　information gain ratio　gain ratio　熵的链式法则　chain rule of entropy　基尼不纯度　Gini impurity　Gini系数　不纯度　impurity

在交互版中打开（看它长在树上的哪里）

把熵推广到多个变量：联合熵是两个变量合起来的不确定性，条件熵是知道一个之后另一个还剩多少不确定性。两者之差就是信息增益，决策树就靠它挑选分裂特征。

先要会：信息量与熵 条件概率与贝叶斯公式

信息量与熵衡量一个随机变量有多不确定。实际问题里我们更关心：知道了X之后，Y还有多不确定？知道天气后，“今天是否打球”还剩多少悬念？看到一张图片后，标签还剩多少悬念？

联合熵。H(X, Y) = −Σ_{x,y} p(x, y) log p(x, y)，把(X, Y)当作一个整体的熵。

条件熵。在知道X的条件下Y的平均剩余不确定性：

H(Y | X) = Σ_x p(x) · H(Y | X = x) = −Σ_{x,y} p(x, y) log p(y | x)

它满足链式法则：H(X, Y) = H(X) + H(Y | X)，即“先说出X，再说出知道X后的Y”。并且H(Y | X) ≤ H(Y)：平均而言，多知道一些信息不会让不确定性增加（单个具体的x可能让它增加，但平均不会）。

信息增益与互信息。知道X后Y的不确定性减少了多少：

IG = H(Y) − H(Y | X)

这正是互信息 I(X; Y)。

它出现在哪里。

  • 决策树：ID3/C4.5决策树在每个节点上计算每个特征带来的信息增益，选增益最大的特征来分裂；C4.5改用信息增益比，避免偏爱取值很多的特征；决策树CART则用基尼不纯度，思路相同，见决策树。
  • 分类模型的交叉熵损失可以看作在估计H(Y | X)的一个上界：模型越好，给定输入后标签剩下的不确定性越小，见交叉熵。
  • 主动学习与探索：选择能带来最大信息增益的样本去标注（见主动学习），或选择能最大程度减少对环境模型不确定性的动作，例如VIME信息增益探索。
  • 语言模型的困惑度对应的是“给定前文，下一个token的条件熵”的估计，见困惑度。

例子

14天的打球记录中9天打、5天不打：H(Y) = −(9/14)log₂(9/14) − (5/14)log₂(5/14) ≈ 0.940比特。按天气分：晴5天（2打3不打，熵0.971），阴4天（全打，熵0），雨5天（3打2不打，熵0.971）。H(Y | 天气) = (5/14)×0.971 + 0 + (5/14)×0.971 ≈ 0.694。信息增益 ≈ 0.940 − 0.694 = 0.246比特。

容易误解的地方

  • H(Y | X)是对所有x的平均，不是在某个特定x下的熵；某个具体观测可能让不确定性变大。
  • 信息增益偏爱取值多的特征：用“样本编号”做特征，每个分支只剩一个样本，条件熵为0，增益最大，却毫无泛化能力。
