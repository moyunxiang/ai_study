凸函数与凸优化

Convexity

也叫：convex optimization　convex function　非凸　non-convex　全局最优

在交互版中打开（看它长在树上的哪里）

凸函数像一只碗：任意两点连线都在函数图像上方，因此只有一个“谷底”，任何局部最小就是全局最小，优化有理论保证。

先要会：导数、偏导与梯度 雅可比矩阵与海森矩阵

用梯度下降找最小值，最怕的是掉进一个小坑里出不来，以为到了最低点，其实旁边还有更深的谷。如果函数的形状保证“只有一个谷”，这个担心就不存在了。凸性就是这种保证。

定义。函数f是凸的，当且仅当对任意两点x、y和任意t ∈ [0, 1]：

f(t x + (1−t) y) ≤ t f(x) + (1−t) f(y)

即两点之间的函数值不高于连接这两点的弦。对二阶可导函数，等价于雅可比矩阵与海森矩阵中的海森矩阵处处半正定（单变量时就是f''(x) ≥ 0）。凸函数的关键性质：任何局部最小值都是全局最小值；如果是严格凸的，最小值点唯一。

凸优化。在凸集合上最小化凸函数的问题叫凸优化。它有成熟的理论：梯度下降保证收敛，收敛速度可以证明，还有对偶理论等工具。最小二乘、逻辑回归、带L1或L2正则的线性模型，损失都是凸的。

它出现在哪里。2000年代主流机器学习偏爱凸方法，支持向量机的训练就是一个凸二次规划，全局最优可以保证；逻辑回归和Lasso与L1稀疏也是如此。深度神经网络的损失是高度非凸的，这曾被认为是它难以训练的根本原因。后来的经验和分析（如损失曲面可视化）显示，大网络的非凸曲面上大多数局部极小值的损失都差不多好，真正的麻烦更多来自鞍点和病态曲率，见损失曲面、局部极小与鞍点。

例子

f(x) = x²是凸的：f''(x) = 2 > 0。g(x) = x⁴ − 2x²不是凸的：令g'(x) = 4x³ − 4x = 0，得x = 0和x = ±1，其中g(±1) = −1是两个最低点，g(0) = 0是中间的小山包。直接检验定义：取x = −1、y = 1、t = 0.5，中点处g(0) = 0，而弦上的值是0.5×(−1) + 0.5×(−1) = −1，函数值高于弦，违反了凸性。从x = 0.1出发做梯度下降会落到x = 1，从x = −0.1出发会落到x = −1，结局取决于起点。

容易误解的地方

  • 凸只保证“找得到全局最优”，不保证“全局最优就是好模型”：线性模型的损失是凸的，但它的表达能力有限。
  • 神经网络非凸不等于训练一定失败；反过来，凸问题如果病态（条件数很大），梯度下降也可能慢得无法接受。
