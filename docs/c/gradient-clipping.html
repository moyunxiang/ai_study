梯度裁剪

Gradient Clipping

也叫：梯度截断　clip grad　gradient norm clipping　梯度范数裁剪　clip_grad_norm

在交互版中打开（看它长在树上的哪里）

当梯度的范数超过某个阈值时，把整个梯度按比例缩小到阈值，方向不变，用来防止梯度爆炸造成的一步“飞出去”。

先要会：范数与距离 梯度下降 梯度消失与梯度爆炸

训练中偶尔会遇到梯度突然变得极大的情况：循环网络的梯度消失与梯度爆炸、某个异常批次、损失曲面上的“悬崖”。此时即使学习率不大，η·g也可能把参数推到很远的地方，之前的训练成果毁于一旦，损失直接变成NaN。

梯度裁剪的做法很直接：先算出所有参数梯度拼在一起的全局范数与距离‖g‖，若超过阈值c，就整体缩放：

若 ‖g‖ > c，则 g ← g · c / ‖g‖

裁剪后梯度方向完全不变，只是步子被限制在一个最大长度内。正常时梯度范数小于c，裁剪不起作用；只在异常尖峰时介入，像一个保险丝。

按范数裁剪 vs 按元素裁剪：也可以把每个分量各自截断到[−c, c]，但这会改变梯度方向，现在一般用按范数裁剪。

它出现在哪里：梯度裁剪（Pascanu等，2012）在分析循环网络训练困难时提出了按范数裁剪，此后它成为训练LSTM、Seq2Seq等循环模型的标配。今天训练Transformer和大语言模型几乎都默认开启，阈值常取1.0左右；训练日志里的“grad norm”曲线出现尖峰，往往是训练不稳定的先兆。

例子

两个参数的梯度为(3, 4)，范数为5，阈值c = 1。

  • 按范数裁剪：乘以1/5，得到(0.6, 0.8)，方向不变，长度变为1。
  • 按元素裁剪到[−1, 1]：得到(1, 1)，方向从约53°变成了45°。

容易误解的地方

  • 裁剪治标不治本：如果每一步都在被裁剪，说明学习率或模型设置有问题，此时裁剪实际上把优化器变成了“固定步长”。
  • 它只防爆炸，不解决梯度消失。
