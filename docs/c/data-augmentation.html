数据增强

Data Augmentation

也叫：数据扩增　数据增广　随机裁剪　翻转　Mixup　Cutout

在交互版中打开（看它长在树上的哪里）

训练时对样本做不改变标签的随机变换（翻转、裁剪、调色、遮挡等），凭空造出更多训练数据，让模型学会对这些变化不敏感，从而泛化得更好。

先要会：泛化与过拟合 正则化与权重衰减 图像作为张量 归纳偏置

标注数据很贵，而深度网络参数很多，数据不够时很容易死记训练集，见泛化与过拟合。但我们其实知道一些“先验”：一只猫左右翻转后还是猫，稍微裁掉一点边、亮度变暗一点，也还是猫。数据增强就是把这些知识变成训练数据：每次取出一张图时，随机施加一种或几种这样的变换，模型每轮看到的都是略有不同的版本。

常见变换。

  • 几何：随机裁剪、缩放、水平翻转、小角度旋转。
  • 颜色：亮度、对比度、饱和度、色调的随机抖动。
  • 遮挡：Cutout随机把一块区域涂黑，逼模型不要只依赖某一个局部特征。
  • 混合样本：Mixup把两张图按比例λ叠加，标签也按同样比例混合：x̃ = λ·x_i + (1−λ)·x_j，ỹ = λ·y_i + (1−λ)·y_j；CutMix则把一张图的一块贴到另一张上。
  • 自动搜索策略：AutoAugment用搜索找最优的增强组合，RandAugment简化为只调两个超参数。

为什么有效。它相当于告诉模型“这些变化不影响答案”，是一种把归纳偏置注入数据的方式，也起到正则化与权重衰减的作用。AlexNet就靠随机裁剪和翻转显著减少了过拟合。

超出“扩充数据”的作用。在对比学习里，增强决定了模型学什么：SimCLR把同一张图的两个增强版本当成正样本对，模型被迫学到对裁剪、颜色变化不变的特征；SimCLR的实验表明增强的组合对结果影响很大。语音里的SpecAugment在频谱图上遮挡时间段和频带，文本里有回译、同义词替换。

例子

AlexNet从256×256的图中随机裁出224×224的块，再随机水平翻转。裁剪位置每个方向有32种左右的选择，论文据此算出训练集被扩大了32×32×2 = 2048倍（严格按像素位置算是33×33×2=2178种）。这些版本高度相关，并不等于真的多了2048倍的数据，但足以明显抑制过拟合。

Mixup的一个样本：λ=0.7，把一张猫图和一张狗图逐像素按0.7:0.3叠加，标签从“猫”的独热向量(1, 0)和“狗”(0, 1)混合成(0.7, 0.3)，训练时用交叉熵去拟合这个软标签。

容易误解的地方

  • 增强必须保持标签不变：识别数字时把“6”旋转180度就变成了“9”；左右翻转对文字识别、区分左右手的任务也不安全。
  • 测试时一般不做随机增强；有时会做“测试时增强”（多个版本预测取平均），那是另一种技巧。
  • 增强太强会让训练分布离真实数据太远，反而降低精度，强度需要在验证集上调。
