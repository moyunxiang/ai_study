GPU与ASIC之争

GPU vs Custom ASIC

也叫：ASIC vs GPU　TPU vs GPU　XPU　定制芯片　Custom Silicon　自研芯片　去英伟达化　摆脱NVIDIA依赖　NVIDIA税　Nvidia tax　Hyperscaler ASIC

通用的NVIDIA GPU和云厂商为自家负载定制的ASIC谁更划算，这是2023年以来AI算力采购的核心争论。

GPU的优势是通用、软件生态成熟（CUDA），任何新模型都能马上跑；ASIC的优势是去掉不需要的电路，把面积和功耗都花在矩阵乘和片上存储上，单位成本更低，还能摆脱单一供应商的定价权。

Google TPU是第一个大规模成功的定制ASIC，之后AWS有AWS Inferentia与Trainium，Meta有Meta MTIA自研芯片，2023年起形成云厂商自研AI芯片浪潮。2025年这场争论升温：Anthropic宣布使用最多百万颗TPU（TPU外供：Anthropic百万TPU），OpenAI与博通合作自研芯片（OpenAI–Broadcom 10GW芯片），AWS推出Trainium3：首颗3nm，微软推出Microsoft Maia 200。另一边，NVIDIA以Blackwell与整机柜液冷和Vera Rubin NVL72保持每年一代的节奏，并用NVLink Fusion开放互连把自研芯片拉进自家生态。

至今的共识是二者长期共存：前沿训练和快速变化的研究仍偏向GPU，规模足够大、负载足够稳定的业务转向ASIC。
