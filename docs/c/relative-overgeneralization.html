相对过度泛化

Relative Overgeneralization

也叫：相对过度泛化　relative overgeneralization　过度泛化　攀爬博弈　climbing game　惩罚博弈　penalty game　宽容学习　lenient learning　leniency　协调失败　miscoordination　独立学习者　independent learners

在交互版中打开（看它长在树上的哪里）

合作多智能体学习中的一种典型失败：最优联合动作要求队友也配合，但队友在探索时经常乱来，于是“单看自己”这个动作的平均回报很低，各智能体都退到一个对队友行为不敏感、却次优的保守动作上。

先要会：随机博弈与Dec-POMDP 博弈论基础与纳什均衡

在完全合作的随机博弈与Dec-POMDP里，所有智能体共享奖励，目标一致，看起来应该很容易。但若每个智能体独立学习（见独立Q学习多智能体），它评价自己的动作时，只能看到“在队友当前（带探索的）行为下”的平均结果。如果最好的联合动作要求双方精确配合，而一方配合失败会受到重罚，那么在队友还在乱试的阶段，这个动作的平均回报就很差。于是每个人都学会选那个“无论队友做什么都还行”的动作，整个团队收敛到次优的均衡。这叫相对过度泛化（relative overgeneralization）：动作的价值被按队友的所有可能行为“泛化”平均了。

经典例子：攀爬博弈。两个智能体各选a、b、c，共享奖励矩阵（行是智能体1，列是智能体2）：

a: (11, −30, 0)；b: (−30, 7, 6)；c: (0, 0, 5)

最优是(a, a)得11，但若对方均匀随机，选a的平均回报为(11 − 30 + 0)/3 ≈ −6.3，选b约为−5.7，选c约为1.7。独立学习者会都选c，只得5。

与相关问题的区别。它不同于信用分配（不知道谁贡献了多少），也不同于由于对方策略变化导致的非平稳性，而是价值估计中“对队友行为取平均”本身带来的偏差。

缓解办法。

  • 乐观或宽容的更新：只用好的结果更新、对坏结果“宽容”。滞后Q学习对正的TD误差用大学习率、负的用小学习率；宽容学习在早期忽略低回报样本。
  • 集中式价值：在集中训练、分散执行框架下学习联合动作价值，不再对队友取平均。但值分解的结构限制可能让它表示不出最优解：QMIX值分解的单调性约束就在攀爬博弈这类收益结构上失败，Weighted QMIX加权分解和QTRAN变换分解试图放宽这一限制。
  • 更好的联合探索：MAVEN协同探索用一个共享的隐变量让团队做一致的探索；DCG深度协调图用协调图显式表示两两之间的配合收益，见协调图。

例子

在上面的攀爬博弈中，设智能体2以0.8的概率选a、其余各0.1。智能体1选a的期望为0.8×11 + 0.1×(−30) + 0.1×0 = 5.8，选c为0.8×0 + 0 + 0.1×5 = 0.5，此时a最好。但若智能体2还在以ε=0.5探索（a的概率约0.67、其余各约0.17），选a的期望约为0.67×11 − 0.17×30 ≈ 2.3，仍高于c的约0.8，而在完全随机时a最差。可见能否走出陷阱取决于双方探索的程度和学习的先后。

容易误解的地方

  • 增加探索不一定有帮助：队友探索越多，精确配合的动作看起来越差。
  • 这一现象在奖励矩阵里有“配合不当重罚”时最明显，在许多常用基准（如SMAC的部分地图）上不突出，所以算法在这些基准上的表现不能说明它解决了这个问题。
