矩阵求导

Matrix Calculus

也叫：矩阵求导　矩阵微积分　matrix calculus　向量求导　vector calculus　矩阵导数　梯度推导　分子布局　分母布局　numerator layout　梯度检验　gradient check　数值梯度　numerical gradient

在交互版中打开（看它长在树上的哪里）

对向量和矩阵整体求导的记号与规则：标量对向量求导得到同形状的梯度，向量对向量求导得到雅可比矩阵。推导反向传播公式时离不开它。

先要会：导数、偏导与梯度 矩阵乘法与线性变换 链式法则

神经网络的参数是一堆矩阵，损失是一个标量。手推“损失对权重矩阵W的梯度”时，如果逐个元素写偏导，几十个下标很快就乱了。矩阵求导把这些偏导排成和变量同样形状的数组，用几条规则整体计算。

三种基本形状。

  • 标量对向量：∂L/∂x是和x同形状的向量，就是导数、偏导与梯度里的梯度。
  • 向量对向量：∂y/∂x是一个矩阵，第(i, j)个元素是∂y_i/∂x_j，即雅可比矩阵与海森矩阵中的雅可比矩阵。
  • 标量对矩阵：∂L/∂W是和W同形状的矩阵，第(i, j)个元素是∂L/∂W_ij。

几条最常用的结果（x、w是列向量，A、W是矩阵）：

∂(wᵀx)/∂x = w ∂(xᵀAx)/∂x = (A + Aᵀ)x，A对称时为2Ax ∂‖x‖²/∂x = 2x 若y = Wx、损失L对y的梯度为g，则∂L/∂W = g·xᵀ，∂L/∂x = Wᵀg

最后一条就是全连接层反向传播的全部内容：权重梯度是“输出梯度”与“输入”的外积（见外积、哈达玛积与克罗内克积），传给下一层的梯度是用Wᵀ把g乘回去。整个网络的梯度是这些局部规则按链式法则串起来的结果，见反向传播。

检查答案的办法。一是看形状：∂L/∂W必须和W一样大，g·xᵀ正好是(输出维)×(输入维)。二是数值梯度检验：把某个参数加减一个很小的ε，用(L(θ+ε) − L(θ−ε)) / 2ε和公式结果对比。

它出现在哪里。今天几乎没人手推完整的梯度，自动微分与计算图（如PyTorch、JAX）会自动完成；但读优化器、归一化层、注意力的论文时，作者常用这套记号写出梯度来分析问题，例如Batch Normalization的反向公式、线性回归闭式解的推导。

例子

线性回归损失L = ‖Xw − y‖²。设残差r = Xw − y，∂L/∂r = 2r，再由∂(Xw)/∂w = X得∂L/∂w = 2Xᵀ(Xw − y)。令它为0：XᵀXw = Xᵀy，这就是正规方程。

形状检验：X是100×3、w是3×1，则Xᵀ是3×100、残差是100×1，乘积3×1，与w同形，没问题。

容易误解的地方

  • 有“分子布局”和“分母布局”两种约定，结果相差一个转置；不同教材混用时，以形状对得上为准。
  • 对矩阵求导前先确认谁是常数、谁是变量；同一个符号在表达式里出现两次时（如xᵀAx），两处都要求导。
