依存句法分析

Dependency Parsing

也叫：依存分析　依存句法　Dependency Parser　转移式分析　Transition-based Parsing　图式分析　Graph-based Parsing　Arc-standard　Arc-eager　UD

在交互版中打开（看它长在树上的哪里）

找出句子里每个词依附于哪个词、是什么语法关系，得到一棵以词为节点的依存树。

与按短语嵌套描述句子的成分句法（Collins词汇化句法分析器、Berkeley句法分析器）不同，依存句法只问“谁修饰谁”：每个词恰有一个中心词，关系用主语、宾语等标签标出，这种表示更适合语序自由的语言和信息抽取。

两大做法在2000年代成形：转移式依存分析是转移式分析，像移进-归约一样从左到右读词、每步决定一个动作，速度是线性的；MSTParser与MIRA是图式分析，给所有可能的依存边打分，再找总分最高的生成树。神经网络依存分析用小型神经网络替代手工特征给转移打分，SyntaxNet全局归一化加入全局归一化，双仿射依存分析用双仿射注意力给每对词打分，成为之后多年的标准结构。Universal Dependencies给上百种语言提供统一标注。大模型时代显式句法分析用得少了，但仍是语言学研究和可解释性分析的工具。
