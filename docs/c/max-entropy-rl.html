熵正则与最大熵强化学习

Entropy Regularization and Maximum-Entropy RL

也叫：最大熵强化学习　maximum entropy RL　MaxEnt RL　熵正则　熵正则化　entropy regularization　entropy bonus　熵奖励　软价值函数　soft value function　soft Q　软Q　软Bellman方程　soft Bellman equation　温度系数　temperature　玻尔兹曼策略　Boltzmann policy　KL正则强化学习　KL-regularized RL

在回报之外再奖励策略的熵，让智能体在达成目标的同时尽量保持随机。轻则作为防止过早收敛的正则项，重则改写整个目标：最优策略变成按Q值做softmax的“玻尔兹曼策略”。

先要会：信息量与熵 策略梯度 Bellman方程

策略梯度训练中常见的一个失败是：策略很快变得近乎确定，只选某一个动作，之后再也探索不到更好的选项。另一个问题是：有多种同样好的做法时，确定性策略只学会其中一种，环境一变就失效。给策略的信息量与熵加一项奖励可以同时缓解这两点。

熵正则（熵奖励）。最轻的用法是在策略梯度的损失里加−β·H(π(·|s))，β很小（例如0.01）。A3C和PPO的常见实现都带这一项。它只是一个正则，不改变问题的定义。

最大熵强化学习。把熵直接写进目标：

J(π) = E[Σ_t γ^t · (r_t + α · H(π(·|s_t)))]

α叫温度，平衡回报和随机性。相应地价值函数变成“软”的：

Q(s, a) = r + γ · E_{s'}[V(s')]，V(s) = E_{a~π}[Q(s, a) − α · log π(a|s)]

这组式子叫软Bellman方程。最优策略有闭式：

π*(a|s) ∝ exp(Q*(s, a) / α)，V*(s) = α · log Σ_a exp(Q*(s, a) / α)

即对Q做温度为α的Softmax与logits；α→0时退化为普通的贪心策略和max。

算法。软Q学习（能量策略）按这一框架学习能量形式的策略；SAC是它的Actor-Critic版本，并自动调节α，使策略熵维持在一个目标值附近（连续动作常取负的动作维数），成为连续控制最常用的离策略算法之一。Munchausen RL在此基础上加入对数策略项。逆强化学习里同样的结构见最大熵逆强化学习。

与KL正则的关系。把熵换成与参考策略的KL散度，目标E[r] − β·KL(π ‖ π_ref)的最优解是π ∝ π_ref · exp(r/β)。这正是RLHF里KL惩罚的形式，见人类反馈强化学习和KL散度。

例子

某状态两个动作，Q=1和Q=0。α=1时，最优软策略为e¹/(e¹+e⁰) ≈ 0.73和0.27，软价值V = log(e + 1) ≈ 1.31，比max的1还大，多出来的部分就是熵的价值。α=0.1时概率变成1/(1+e^{−10}) ≈ 0.99995，几乎就是贪心；α=10时约为0.52和0.48，接近均匀随机。

容易误解的地方

  • α的量纲与奖励相同，换一个奖励尺度就要重新调α，这是SAC要自动调温度的原因。
  • 最大熵目标下学到的Q值包含熵奖励，不能直接当作“真实回报”的估计来解读。
  • 熵奖励不能替代有方向的探索：在需要走很长一段特定路线才能拿到奖励的任务里，局部随机性帮助有限，见内在动机与内在奖励。
