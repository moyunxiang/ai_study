潜动作学习

Latent Action Learning

也叫：Latent Action　潜动作　潜在动作　Latent Action Model　LAM　隐动作　无动作标签视频　action-free video　proxy action

在交互版中打开（看它长在树上的哪里）

从前后两帧画面的变化里自动压缩出“动作编码”，用来代替视频里缺失的动作标签。

网上的视频只有画面，没有“按了什么键”“关节怎么转”的标签。潜动作的思路是训练一个模型：看当前帧和未来帧，压出一个小编码，要求另一个模型凭当前帧加这个编码能还原未来帧——这个编码就被迫记录了“发生了什么变化”。Genie用它从无标签游戏视频里学出可控的世界模型；LAPA潜动作预训练把它用于机器人，用潜动作给人类视频打伪标签预训练VLA；GR00T N1用它给人类视频和生成视频补标签；DreamDojo机器人世界模型改用连续潜动作训练机器人世界模型；Motus潜动作世界模型把潜动作和世界模型统一起来。

主要疑问是潜动作里混了多少与控制无关的变化（镜头移动、背景里别人的动作），以及离散码本是否表达得了精细操作。
