反向传播的替代与局部学习规则

Alternatives to Backpropagation and Local Learning Rules

也叫：无反向传播　Backprop-Free　Backpropagation Alternatives　局部学习　Local Learning　生物可信学习　Biologically Plausible Learning　前向前向　Forward-Forward　FF算法　Hebbian学习　赫布学习　对比Hebb学习　类脑学习

反向传播需要存下全部激活并把误差精确传回，大脑和低功耗硬件都难以做到；这类研究寻找只用局部信息就能学习的规则。

Hebb学习律提出最早的局部规则：同时激活的神经元之间连接增强，不需要任何全局误差信号。玻尔兹曼机的学习规则同样是局部的，比较“看数据时”和“自由运行时”两种状态下神经元的相关性，对比散度让它变得可训练。反向传播出现后，这些规则在效果上被全面超越，但反向传播是否可能在大脑中实现一直有争议。

前向-前向算法是Hinton在2022年提出的新尝试：用一次正样本前向和一次负样本前向代替反向传播，每层只优化自己的“好度”。它在MNIST上接近反向传播，但作者也承认更慢、泛化略差。目前这类方法的主要价值在于理解大脑和设计模拟、类脑硬件，在大模型训练上还没有替代反向传播的迹象。
