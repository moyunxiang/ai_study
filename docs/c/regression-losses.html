回归损失：MSE、MAE与Huber

Regression Losses: MSE, MAE and Huber

也叫：均方误差　MSE　mean squared error　L2损失　L2 loss　平方损失　squared loss　squared error　平均绝对误差　MAE loss　mean absolute error　L1损失　L1 loss　绝对值损失　Huber损失　Huber loss　Smooth L1　smooth L1 loss　平滑L1损失　回归损失　regression loss　MSELoss　L1Loss　SmoothL1Loss　HuberLoss　最小二乘　least squares

预测连续数值时最常用的损失：均方误差（MSE）对大误差惩罚重、对应高斯噪声；平均绝对误差（MAE）对离群点更稳健；Huber/Smooth L1在两者之间折中。

先要会：损失函数

分类问题用交叉熵，预测房价、坐标、像素值、噪声这类连续量时，需要衡量“预测值ŷ与真实值y差多少”的损失函数。

均方误差（MSE，L2损失）。L = (1/n)·Σ (ŷ_i − y_i)²。

  • 误差被平方，大误差受到的惩罚远大于小误差。
  • 处处可导，梯度2(ŷ − y)与误差成正比，接近目标时自动变小。
  • 最优的常数预测是均值。假设噪声是高斯分布时，最小化MSE等价于最大似然估计，这就是线性回归最小二乘法的来历。
  • 缺点：一个离群点就能主导整个损失和梯度。

平均绝对误差（MAE，L1损失）。L = (1/n)·Σ |ŷ_i − y_i|。

  • 对所有误差一视同仁，离群点影响小得多。
  • 最优的常数预测是中位数，对应拉普拉斯噪声假设（见拉普拉斯分布与学生t分布）。
  • 梯度大小恒为1（在0处不可导，见次梯度与不可导点），接近目标时也不会变小，优化后期容易在最优点附近来回跳。

Huber损失与Smooth L1。误差小于阈值δ时用平方，大于δ时用线性：

L_δ(e) = ½e²（|e| ≤ δ）；δ·(|e| − ½δ)（|e| > δ）

小误差时像MSE一样平滑收敛，大误差时像MAE一样不被离群点带偏。δ = 1时就是目标检测里常说的Smooth L1。

它们出现在哪里。

  • Fast R-CNN用Smooth L1回归边界框坐标，此后成为检测器的标准选择。
  • DQN（Nature版）把TD误差裁剪到[−1, 1]，相当于用Huber损失训练Q值，避免偶尔很大的TD误差让训练发散，见时序差分与自举。
  • DDPM的训练目标就是预测噪声的MSE，见扩散：前向加噪与反向去噪。
  • 图像生成和超分辨率中，L1重建损失比L2生成的图像更锐利一些（L2倾向于输出模糊的平均），pix2pix条件图像翻译就选用了L1。
  • 评测时用到的同名指标见c:regression-metrics。

例子

五个误差(0.5, −0.2, 0.1, 0.3, 8)，最后一个是离群点。MSE = (0.25 + 0.04 + 0.01 + 0.09 + 64)/5 ≈ 12.9，几乎全部来自离群点；MAE = (0.5 + 0.2 + 0.1 + 0.3 + 8)/5 = 1.82；Huber（δ = 1）= (0.125 + 0.02 + 0.005 + 0.045 + 7.5)/5 ≈ 1.54。离群点对梯度的贡献：MSE为16，MAE和Huber都只有1。

容易误解的地方

  • MSE的量纲是原单位的平方，报告时常开方成RMSE以便和原数据比较。
  • 目标值尺度差异很大时（如同时回归米和毫米），损失会被大尺度的维度主导，应先标准化目标值，见特征缩放：标准化与归一化。
