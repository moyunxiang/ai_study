鲁棒MDP与鲁棒强化学习

Robust MDPs and Robust RL

也叫：鲁棒MDP　robust MDP　鲁棒强化学习　robust RL　robust reinforcement learning　不确定集　uncertainty set　ambiguity set　分布鲁棒强化学习　distributionally robust RL　鲁棒Bellman方程　robust Bellman　矩形性　rectangularity　最坏情况优化　worst-case　模型不确定性

环境模型本身不确定时的决策框架：给转移概率划一个“可能的范围”（不确定集），寻找在这个范围内最坏情况下表现仍然最好的策略。

先要会：马尔可夫决策过程 Bellman方程

强化学习常在仿真器或从数据估计出的模型里训练，但真实环境的摩擦、质量、用户行为都和模型有出入。一个在模型里最优的策略，可能恰好利用了模型里不真实的细节，到真实环境中大幅退化。鲁棒MDP不假设我们知道唯一正确的转移概率，而是假设它落在某个集合里。

定义。对每个(s, a)，转移分布P(·|s, a)属于一个不确定集𝒫_{s,a}，例如以估计的分布为中心、KL散度或总变差距离不超过ε的球。目标是最坏情况下的回报最大：

max_π min_{P ∈ 𝒫} J(π, P)

可以理解为与一个“自然”对手博弈：我们选策略，对手在允许范围内选最不利的环境。

鲁棒Bellman方程。当不确定集对每个(s, a)独立选取（称为矩形性）时，问题仍然可以用动态规划求解：

V(s) = max_a [ r(s, a) + γ · min_{p ∈ 𝒫_{s,a}} Σ_{s'} p(s')·V(s') ]

对应的鲁棒Bellman算子仍是压缩映射（见Bellman算子与压缩映射），鲁棒价值迭代收敛。内层的min对KL球、总变差球等常见集合有闭式或可高效求解的形式。没有矩形性时，问题一般是计算困难的。

深度RL中的做法。精确的不确定集很难给出，实践中常用近似：RARL鲁棒对抗RL训练一个对抗智能体对系统施加扰动力，与主智能体轮流优化；在一族随机化的仿真参数上训练（见域随机化与Sim2Real）优化的是平均情形，若只用其中表现最差的那部分环境训练，就更接近鲁棒目标，与风险敏感强化学习与CVaR里的CVaR相通。这些思路在仿真到现实的差距中很常见。

代价。不确定集选得太大，策略会过度保守（为了防最坏情况，平常也表现平庸）；选得太小又起不到保护作用。离线RL中的悲观原则可以看作一种由数据量决定不确定集大小的鲁棒性，见离线RL的悲观与保守。

例子

某状态有两个动作。动作A：名义模型下以0.9的概率到达价值10的状态、0.1的概率到达价值0的状态，期望9；动作B：一定到达价值8的状态。不确定集允许每个概率最多偏移0.2。最坏情况下A变成0.7和0.3，期望7；B仍是8。名义最优选A，鲁棒最优选B。

容易误解的地方

  • 鲁棒性是针对指定的不确定集而言的，环境偏离超出这个集合时没有任何保证。
  • 矩形性假设允许“自然”在每个状态独立地选最坏情况，这常比真实的物理不确定性更悲观。
