按真实职业的工作内容出题，由从业者评判模型交付物，衡量AI能完成多少有经济价值的工作。

考试题测不出“能不能干活”。SWE-Lancer第一次按真实外包报酬给软件任务计价；TheAgentCompany模拟一家软件公司的日常工作；GDPval把范围扩到对GDP贡献最大的9个行业44个职业，请平均从业14年的专家出题和盲评；远程劳动指数RLI用真实外包项目，结果显示智能体能完成的比例很低；xbench长青评测提出按职业对齐的评测和“技术—市场契合”；APEX-Agents职业任务让智能体在投行、咨询、律所风格的环境里跨应用工作。

这类评测的共同难点是判分：交付物是文档、表格和幻灯片，没有标准答案，只能靠专家或模型裁判按细则打分，成本高、一致性有限。它们常被拿来讨论AI对就业的影响，但基准分数与真实岗位替代之间还隔着部署、责任和流程等因素。
