基于模型的强化学习

Model-Based RL

也叫：MBRL　基于模型的RL　环境模型　dynamics model　Dyna　想象规划

在交互版中打开（看它长在树上的哪里）

先学一个环境模型来预测“做了这个动作会发生什么”，再在这个模型里想象、规划或生成训练数据，从而减少与真实环境的交互。

先要会：马尔可夫决策过程 Bellman方程 世界模型 监督学习

DQN学会一个Atari游戏要玩上千万帧，换成真实机器人，这么多次试错既慢又会损坏硬件。人类不这样学：我们脑中有一个对世界的预测，“手松开杯子会掉下去”不用真摔一次就知道。基于模型的强化学习就是让智能体也学一个这样的模型。

环境模型。用神经网络近似马尔可夫决策过程里未知的转移和奖励：

ŝ' , r̂ = f_φ(s, a)

它用智能体收集的(s, a, r, s')数据做监督学习训练，输出可以是下一状态的确定预测，也可以是一个概率分布。今天更常用的名字是世界模型。

有了模型怎么用。

  • 生成假数据：在模型里“想象”很多转移，拿去训练普通的无模型算法。Dyna：学习与规划合一（1990）就是这样：每走一步真实的，再在模型里做k步想象的更新。MBPO沿用此思路，只从真实状态出发做很短的想象。
  • 规划：在模型里试多种动作序列，挑最好的执行，见规划与模型预测控制。PILCO用高斯过程做模型，只用极少的真实交互就学会了小车倒立摆的摆起控制。
  • 在潜空间里想象：World Models、Dreamer把图像压进潜空间，在潜空间里预测未来并训练策略。
  • 只学对决策有用的部分：MuZero的模型不预测画面，只预测奖励、价值和策略，再交给MCTS搜索，在围棋、国际象棋、Atari上都达到了顶尖水平。

核心困难：误差累积。模型每一步都有小误差，想象得越远，偏差越大；策略还会主动钻模型的漏洞——找那些模型错误地以为奖励很高的地方。所以基于模型的方法常用模型集成估计不确定性、限制想象长度，或者在每步执行后用真实观测重新规划。

例子

估计转移概率最简单的办法是计数：在状态s做动作a共10次，8次到了s₁，2次到了s₂，则P̂(s₁|s, a) = 0.8，P̂(s₂|s, a) = 0.2。有了P̂和平均奖励R̂，就可以直接用Bellman方程做价值迭代，而不必再去环境里试。

误差累积的直观感受：假设模型对小车位置的每步预测有1%的相对误差，且误差同向累积，那么想象20步后误差约为1.01^20 − 1 ≈ 22%，50步后约64%。（这是简化的示意，真实误差取决于系统动力学。）

容易误解的地方

  • “基于模型”的模型指环境模型（转移和奖励），不是指策略网络或价值网络。
  • 模型学得准不等于对决策有用：像素级预测很准的模型可能恰好在关键细节上出错，MuZero的思路就是只预测与决策相关的量。
  • 已知规则的问题（围棋、国际象棋）可以直接用真实规则做模型，AlphaZero就是如此；需要学习模型的是规则未知的环境。
