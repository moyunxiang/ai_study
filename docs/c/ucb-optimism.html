上置信界与乐观原则

Upper Confidence Bounds and Optimism

也叫：UCB　上置信界　置信上界　upper confidence bound　UCB算法　乐观原则　optimism in the face of uncertainty　OFU　面对不确定性时的乐观　乐观探索　optimistic exploration　乐观初始化　optimistic initialization

在交互版中打开（看它长在树上的哪里）

“面对不确定性时保持乐观”：给每个选项的估计值加上一个随试验次数减小的置信奖励，选“最乐观情况下最好”的那个。试得少的选项会被自动多试，试多了奖励消失，探索随之停止。

先要会：探索与利用 期望与方差

ε-贪心与玻尔兹曼探索的探索是盲目的：已经试过一千次、明显很差的选项，和从没试过的选项被随机选中的概率一样。更聪明的做法是把探索花在还不确定的地方。

乐观原则（optimism in the face of uncertainty，OFU）。对每个选项，不用它的平均估计，而用一个“它可能有多好”的上界：数据充分的选项，上界接近均值；数据少的选项，上界很高。每次选上界最高的。如果一个选项被乐观地选中，结果要么证明它确实好（赚到了），要么它的上界被数据拉低（学到了），两种情况都不亏。

UCB1。多臂老虎机上的经典形式（UCB1）：

a_t = argmax_a [ Q̂_a + √(2·ln t / N_a) ]

Q̂_a是第a个臂的平均奖励，N_a是它被拉的次数，t是总次数。根号项来自集中不等式：它随N_a增大而缩小，随t缓慢增大，保证每个臂都不会被永远忽略。UCB1的累积遗憾与遗憾界随时间按O(log T)增长，与Lai–Robbins遗憾下界给出的下界同阶。

乐观初始化。最简单的乐观：把所有Q的初值设得比任何可能的真实值都高。贪心智能体每试一个动作都会“失望”，于是转去试别的，自然完成了早期探索。只在开始时起作用，对非平稳问题无效。

推广。上下文老虎机里的LinUCB上下文老虎机；MDP里的UCRL2遗憾界和UCBVI极小极大遗憾界给转移和奖励都加置信区间；R-max乐观探索把没见够次数的状态当作奖励最大；蒙特卡洛树搜索UCT中的UCT把UCB用在树的每个节点上选择子节点，见博弈树搜索：minimax与MCTS；深度RL里的计数奖励（见内在动机与内在奖励）也可看成近似的乐观奖励。

例子

t=100时，臂A被拉了80次，平均0.6；臂B被拉了20次，平均0.5。ln 100 ≈ 4.61。A的上界：0.6 + √(9.21/80) ≈ 0.6 + 0.34 = 0.94；B的上界：0.5 + √(9.21/20) ≈ 0.5 + 0.68 = 1.18。虽然B的均值较低，但UCB选B，因为它的不确定性大得多。

容易误解的地方

  • UCB的置信项假设奖励有界（如[0, 1]）；奖励范围不同时要缩放，否则探索过多或过少。
  • 在大状态空间里精确的置信区间无法计算，深度RL中的“乐观”都是近似，理论保证不再直接适用。
