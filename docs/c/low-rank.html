低秩近似

Low-Rank Approximation

也叫：低秩分解　low-rank factorization　矩阵分解　截断SVD　truncated SVD

在交互版中打开（看它长在树上的哪里）

用两个“瘦”矩阵的乘积去近似一个大矩阵：信息只保留最主要的几个方向，参数和计算量却大幅减少。

先要会：特征分解与奇异值分解 矩阵乘法与线性变换

大矩阵很贵：1000×1000的矩阵要存100万个数。但真实数据里的矩阵往往有大量冗余，比如用户评分矩阵里，喜好其实由少数几个因素（类型、年代、演员）决定。如果只用少数几个方向就能描述矩阵的大部分内容，就没必要存全部的数。

秩。矩阵的秩是它线性无关的行（或列）的最大数目，也就是它真正“有几个独立方向”。一个m×n矩阵如果秩为r，就能写成

W = A B，A是m×r，B是r×n

参数从m·n降到r·(m+n)。当r远小于m和n时，节省非常可观。

最好的低秩近似。对一般矩阵，做特征分解与奇异值分解后只保留最大的r个奇异值及对应向量，得到的秩r矩阵在Frobenius范数意义下是所有秩r矩阵里离原矩阵最近的（Eckart–Young定理）。丢掉的部分的大小，恰好由被丢弃的奇异值决定。

它出现在哪里。潜在语义分析LSA把词—文档矩阵截断到几百维，得到词和文档的低维表示；Netflix Prize中表现最好的方法之一是把评分矩阵分解成用户因子乘电影因子；低秩分解加速卷积用低秩分解加速卷积层；LoRA假设微调时权重的变化量ΔW是低秩的，只训练ΔW = BA里的两个小矩阵，见参数高效微调；Linformer低秩注意力则把注意力矩阵近似为低秩以降低长序列开销。

例子

矩阵[[1, 2], [2, 4]]的第二行是第一行的2倍，秩为1，可以写成列向量(1, 2)乘行向量(1, 2)，4个数用2+2个数表示。规模更大时效果明显：一个1000×1000的权重更新ΔW有100万个参数；用秩8的分解ΔW = BA（B是1000×8，A是8×1000），只需2×1000×8 = 16000个参数，约为原来的1.6%。这正是LoRA的做法。

容易误解的地方

  • 低秩是一种假设，不是免费的压缩。如果矩阵的奇异值衰减很慢（信息分散在很多方向上），截断会丢掉大量信息。
  • 两个瘦矩阵相乘得到的大矩阵不需要显式算出来，x(AB) = (xA)B先乘瘦矩阵更省计算，这是低秩方法加速的关键。
