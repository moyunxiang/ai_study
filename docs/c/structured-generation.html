结构化生成与约束解码

Structured Generation and Constrained Decoding

也叫：约束解码　constrained decoding　结构化输出　structured outputs　JSON模式　JSON mode　语法约束　grammar-constrained decoding　正则约束　function calling格式　guided decoding

在交互版中打开（看它长在树上的哪里）

在每一步生成时屏蔽掉不符合目标格式（JSON、正则、语法）的词，保证模型输出一定能被程序解析。

让模型输出JSON或调用工具时，靠提示词约束总会偶尔出错，一个多余的逗号就会让下游程序崩溃。约束解码的做法是在解码：贪心、束搜索、温度与top-p之前，根据当前已经生成的内容和目标格式，算出哪些词可以出现，把其余词的概率置零。

约束解码Outlines把正则表达式和JSON Schema编译成有限状态机，在词表上预先建好索引，使每一步的过滤几乎没有开销；XGrammar结构化生成进一步支持上下文无关语法，并把大部分检查预计算、与GPU计算重叠，被vLLM、SGLang等引擎采用。商用API也相继提供了保证格式的结构化输出模式。

讨论点在于：强行约束是否会损害模型的推理质量，以及分词方式与语法边界不对齐时的处理。
