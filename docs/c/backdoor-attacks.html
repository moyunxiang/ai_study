后门攻击

Backdoor Attacks

也叫：backdoor　后门　木马　trojan　trojan attack　触发词　trigger　数据投毒　data poisoning　睡眠特工　sleeper agent　潜伏后门　投毒攻击

在交互版中打开（看它长在树上的哪里）

在训练数据或权重里埋入触发条件，平时一切正常，遇到特定输入才表现出攻击者想要的行为。

数据投毒攻击最早研究往训练数据里掺入恶意样本让模型变差；BadNets后门攻击在2017年提出后门：在图片上加一个小贴纸作为触发器，带贴纸的图就被分到攻击者指定的类别，其余输入照常。由于正常测试发现不了，后门很难被察觉。

大模型时代，网络规模数据投毒证明攻击者花很少的钱就能污染网络规模数据集；少量样本即可投毒LLM发现在预训练中植入后门需要的毒化文档数量几乎不随模型和数据规模增长，大约250篇即可。Sleeper Agents把后门当作欺骗的模型有机体，发现它能挺过常规安全训练。潜意识学习和接种提示则从另一面说明，训练数据中不明显的信号会传递特质，也可以被针对性地抵消。
