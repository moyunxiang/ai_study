多重比较与统计功效

Multiple Comparisons and Statistical Power

也叫：多重比较　多重检验　multiple comparisons　multiple testing　多重假设检验　Bonferroni校正　Bonferroni correction　Holm校正　Holm-Bonferroni　错误发现率　false discovery rate　FDR　Benjamini-Hochberg　统计功效　检验功效　statistical power　power analysis　功效分析　样本量估计　sample size calculation　p值操纵　p-hacking　第一类错误　第二类错误　type I error　type II error

同时做很多次检验，总会有几次“碰巧显著”；比较的组合越多，越要收紧标准（如Bonferroni校正）。统计功效则问反方向的问题：真有差异时，实验能不能检测出来。

先要会：方差、种子与统计显著性

多重比较问题。单次检验在显著性水平0.05下，没有真实差异时也有5%的概率误判为显著。如果同时比较20对方法、20个子任务或20组超参数，即使全都没有真实差异，至少出现一次“显著”的概率也高达1 − 0.95^20 ≈ 64%。论文里“我们的方法在12个数据集中的3个上显著更好”，可能完全是噪声。

校正方法。

  • Bonferroni校正：做m次检验时，每次的阈值改为α/m。简单、保守，m很大时容易什么都检测不出来。
  • Holm方法：把p值从小到大排序，依次与α/m, α/(m−1), …比较，比Bonferroni更有检验力，同样控制“至少错一次”的概率。
  • 控制错误发现率（FDR）：Benjamini–Hochberg方法不要求一次都不错，而是控制“宣布显著的结果中假阳性的比例”，适合大规模筛选。

隐蔽的多重比较。不只是论文里明写的多次检验：反复调超参数并在测试集上看结果、尝试多种评测设置只报最好的、跑很多种子挑最好的，都会让报告的结果偏高，这被称为p值操纵或“研究者的自由度”。自适应过拟合与可复用holdout讨论了反复使用同一个验证集造成的自适应过拟合；排行榜幻觉指出私下测试多个版本、只公布最好的，会让排行榜系统性偏高（见基准、排行榜与SOTA）。

统计功效。另一种错误是：真有差异，实验却没检测出来。功效是“真实差异为某个大小时，检验判为显著的概率”，通常希望至少80%。功效取决于三件事：真实差异多大、噪声多大、样本多少。要检测的差异减半，所需样本数大约变为4倍。所以：

  • 在只有几百道题的基准上，1个百分点的差距几乎不可能被可靠检测出来（见置信区间、标准误与误差棒）。
  • 强化学习只跑3个种子时，功效往往很低，“没有显著差异”不能当作“两者一样好”的证据（见《Deep RL that Matters》复现性批评）。
  • 做实验前先估计需要多少样本或种子，是A/B测试与在线实验的标准流程。

两类错误合起来就是：第一类错误（假阳性）由显著性水平和多重比较校正控制，第二类错误（假阴性）由功效控制，见方差、种子与统计显著性。

例子

比较10个新方法与基线，得到p值(0.003, 0.02, 0.04, 0.2, …)。不校正时前三个都“显著”；Bonferroni阈值为0.05/10 = 0.005，只有0.003通过。

功效：两个模型真实准确率分别为70%和72%，想以80%的功效在0.05水平下检测出这个差异，用独立样本时每组大约需要8000道题；在同一套题上做配对比较可以少很多（数字为正态近似的估算）。

容易误解的地方

  • “不显著”不等于“没有差异”，可能只是功效不够；应该同时报告差异的置信区间。
  • 事后才决定比较哪些组合，然后只对“看起来有差异的”做检验，校正也救不回来；比较方案应事先确定。
