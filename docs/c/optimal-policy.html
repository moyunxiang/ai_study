最优策略与最优价值函数

Optimal Policy and Optimal Value Function

也叫：最优策略　optimal policy　最优价值函数　optimal value function　最优动作价值函数　V*　Q*　贪心策略　greedy policy　argmax策略　最优Bellman方程

在交互版中打开（看它长在树上的哪里）

在每个状态上都不比任何其他策略差的策略叫最优策略，它对应的价值函数V*和Q*唯一确定；只要知道Q*，在每个状态选Q*最大的动作（贪心）就是最优策略。

先要会：策略与价值函数 Bellman方程

强化学习说“找最好的策略”，首先要说清楚“最好”是什么意思：两个策略可能在某些状态上你强、在另一些状态上我强。理论上的回答很干净，也是Q-learning一类方法能成立的根据。

策略之间的比较。若对所有状态s都有V^π(s) ≥ V^π'(s)，就说π不比π'差。有限MDP里一定存在一个策略在所有状态上同时不比任何策略差，这就是最优策略π*。它可能不唯一，但它们的价值函数相同，记为

V*(s) = max_π V^π(s)，Q*(s, a) = max_π Q^π(s, a)

最优Bellman方程。V*和Q*满足不带策略的方程（见Bellman方程）：

Q*(s, a) = E[r + γ · max_{a'} Q*(s', a') | s, a]

它的意思是：最优地行动 = 这一步做a，以后每一步都最优。

贪心策略。对任意价值函数Q，取π(s) = argmax_a Q(s, a)叫关于Q的贪心策略。关键结论：**关于Q*的贪心策略就是最优策略**，只需要向前看一步，因为Q*已经把未来的一切都算进去了。由此还可知，有限MDP（折扣、无限时域）中总存在一个确定性、只依赖当前状态的最优策略，随机化没有必要。

它出现在哪里。Q-learning和DQN直接逼近Q*，再取贪心策略；策略评估、策略迭代与价值迭代交替计算价值和贪心改进，最终收敛到π*；动态规划与Bellman方程的最优性原理是这一切的出发点。在多智能体或部分可观测情形下这些结论不再成立：博弈论基础与纳什均衡里的最优策略往往必须随机，POMDP规划里的策略要依赖历史或信念状态。

例子

某状态s有两个动作：Q*(s, 左)=3.2，Q*(s, 右)=4.5，于是π*(s)=右，V*(s)=4.5。如果另一状态s'里两动作的Q*都等于2，那么左右都是最优动作，存在多个最优策略，但它们的V*(s')都等于2。

容易误解的地方

  • 贪心策略只在Q准确时才是最优的。用估计的Q取argmax会挑中被高估的动作，见过估计与最大化偏差。
  • “最优策略一定是确定性的”只对单智能体、完全可观测的MDP成立；石头剪刀布这类博弈里确定性策略会被对手利用。
  • 在线学习时只用贪心策略就不会探索，所以训练时常配合ε-贪心与玻尔兹曼探索。
