Good-Turing估计

Good-Turing Estimation

也叫：Good-Turing　Good-Turing估计　Good-Turing smoothing　古德-图灵估计　古德图灵平滑　Simple Good-Turing　频率的频率　frequency of frequencies　未见事件概率　unseen events　折扣　discounting

在交互版中打开（看它长在树上的哪里）

估计“没见过的事件有多大概率”的经典方法：用只出现过一次的事件数占总数的比例，作为下一次遇到全新事件的概率；并据此把每个计数c调整为(c+1)·N_(c+1)/N_c。

先要会：n-gram与平滑 最大似然估计

n-gram与平滑模型最头疼的是零计数：语料里没出现过的词组，最大似然给它概率0（见最大似然估计）。但我们知道，新语料里一定会遇到大量没见过的词组（见Zipf定律与Heaps定律）。问题是：应该给“所有没见过的事件”留多少概率？加一平滑凭空给每个计数加1，留得太多。Good-Turing估计从数据本身推算这个量。它由图灵与I. J. Good在二战期间破译密码的工作中提出，1953年由Good发表。

核心想法。把“只出现过一次的事件”当作“新事件”的代表：如果样本里有很多东西只见过一次，说明这个总体里还有很多没见过的东西。

定义。记N为样本总数，N_c为恰好出现c次的事件种类数（“频率的频率”）。

  • 所有未见事件的总概率：P_0 = N_1 / N
  • 出现过c次的事件，调整后的计数：c* = (c + 1) · N_(c+1) / N_c，概率为c* / N

调整后，见过的事件的计数整体被打了折扣，省出来的概率正好留给未见事件。

实际使用的问题。c很大时，N_(c+1)常常是0（没有恰好出现c+1次的事件），公式失效。实践中只对小计数（如c ≤ 5）做调整，大计数视为可靠、保持不变；或先对N_c关于c做一条平滑曲线拟合（Simple Good-Turing）。

在哪里出现。Katz回退语言模型用Good-Turing给出的折扣决定从高阶n-gram“匀”出多少概率，再按低阶模型分配给未见词组。n-gram平滑的系统比较中，Good-Turing类方法是重要的对照组，最终被Kneser-Ney平滑一系超过。这个思想在语言模型之外也常用：估计物种数量、估计一个测试集还有多少“没覆盖到的情形”。

例子

Jurafsky与Martin教材的钓鱼例子：钓到18条鱼，鲤鱼10条、鲈鱼3条、白鱼2条，鳟鱼、鲑鱼、鳗鱼各1条。

  • 只出现一次的种类N_1 = 3，所以下一条是新品种的概率 = 3/18 ≈ 0.17。
  • 鳟鱼的原始计数c = 1。恰好出现2次的种类N_2 = 1（白鱼），调整后计数 c* = 2 × 1 / 3 ≈ 0.67，概率 ≈ 0.67/18 ≈ 0.037，而最大似然估计是1/18 ≈ 0.056。

见过的鳟鱼被打了折扣，省下的概率给了还没钓到的鱼。

容易误解的地方

  • 对大计数直接套公式会得到不合理的结果（N_(c+1)可能为0），必须只用于小计数或先平滑N_c。
  • Good-Turing只回答“未见事件总共占多少”，不回答这部分概率在各个未见事件之间怎么分，后者要靠回退或插值。
