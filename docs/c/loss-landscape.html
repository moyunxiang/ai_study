损失曲面、局部极小与鞍点

Loss Landscape

也叫：损失地形　saddle point　局部最优　local minimum　平坦极小值　flat minima　尖锐极小值

在交互版中打开（看它长在树上的哪里）

把损失看成参数空间上的一张“地形图”：有山谷、平原、鞍点。研究这张地形图的形状，可以解释为什么梯度下降能训练好非凸的神经网络，以及为什么某些解泛化更好。

先要会：梯度下降 雅可比矩阵与海森矩阵 凸函数与凸优化 泛化与过拟合

线性回归的损失是一个碗状的凸函数与凸优化函数，梯度下降一定能走到唯一的最低点。神经网络的损失是参数的高度非凸函数，参数动辄上亿维。经典优化理论会担心：梯度下降会不会卡在某个很差的局部极小值里？实践却表明，大网络几乎总能训练到很低的损失。损失曲面研究就是试图解释这种现象。

几种关键的点（梯度都为0，靠雅可比矩阵与海森矩阵中海森矩阵的特征值区分）：

  • 局部极小：海森矩阵所有特征值都为正，各个方向都往上翘。
  • 鞍点：有的特征值为正、有的为负，某些方向往上、某些方向往下。
  • 平坦区：许多特征值接近0，梯度很小，训练看起来停滞。

一个直觉：在高维空间里，一个驻点要成为极小值，需要所有方向都往上翘。如果粗略地认为每个方向的弯曲方向是随机的，那么在一万个维度上全部朝上几乎不可能，大部分驻点应该是鞍点。研究也确实发现，高维时较差的驻点多是鞍点，而真正的局部极小损失往往都不错。带噪声的随机梯度下降与小批量不会精确停在鞍点上，能自然逃离。

平坦 vs 尖锐：同样低的损失，有的谷底宽而平，有的窄而尖。平坦极小值和大批量与尖锐极小值认为平坦的极小值泛化更好（参数稍有偏差损失也不变），SAM锐度感知最小化据此直接优化“邻域内最坏的损失”。但这一联系并不绝对，重新参数化可以让同一个函数看起来更尖或更平。

其他发现：损失曲面可视化用低维切片把曲面可视化，显示残差连接让地形更平滑；另有研究发现两个独立训练的解之间常有一条损失都很低的路径相连；稳定性边缘观察到全批量梯度下降训练中海森矩阵的最大特征值会自动停在2/η附近。

例子

f(x, y) = x² − y²在原点梯度为0，海森矩阵是对角阵diag(2, −2)：沿x方向是谷底，沿y方向是山脊，这是一个鞍点，不是极小值。

粗略估算：若每个方向的弯曲朝上或朝下各占一半且相互独立，一个100维的驻点所有方向都朝上的概率是2⁻¹⁰⁰ ≈ 7.9×10⁻³¹。这只是帮助直觉的玩具模型，真实网络的特征值并不独立。

容易误解的地方

  • 二维或三维的可视化图只是从上亿维空间里切出的一个切片，不能把它当成真实地形的全貌。
  • “平坦极小泛化更好”是经验观察加部分理论，不是定理；平坦度的定义本身依赖参数化方式。
