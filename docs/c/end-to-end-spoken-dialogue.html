端到端语音对话模型

End-to-End Spoken Dialogue Models

也叫：端到端语音大模型　语音到语音　speech-to-speech　S2S　Spoken Dialogue Model　SDM　语音对话大模型　Speech LLM　语音大模型　原生语音　native audio　Thinker-Talker　级联vs端到端　cascade vs end-to-end

在交互版中打开（看它长在树上的哪里）

一个模型直接听语音、直接说语音，不再把识别、语言模型、合成三个模型串起来。

级联方案（ASR→LLM→TTS）简单可靠，但每一步都会丢信息：语气、情绪、背景声在转成文字时就没了，三段延迟相加也很难压到人类对话的几百毫秒。端到端模型把语音编码成分词与token意义上的离散或连续表示，和文本一起交给一个语言模型，输出端直接生成语音token再还原成波形（见声码器与音频编解码）。

早期探索有SpeechGPT、AudioPaLM；GPT-4o全模态实时模型让这条路线成为主流。开源追赶者包括Mini-Omni（文本与语音并行输出）、LLaMA-Omni、GLM-4-Voice、Moshi全双工语音对话、Step-Audio系列、Kimi-Audio，以及全模态的Qwen2.5-Omni（Thinker负责想、Talker负责说）。

现在的争论：端到端模型在推理和知识上常比同骨干的文本模型差（「模态鸿沟」），而工业界很多语音产品仍用级联或半级联；怎样在保留语气信息的同时不损失智力，仍未定论。
