n步回报与多步TD

n-Step Returns

也叫：n步回报　n-step return　N步回报　n-step TD　n步TD　多步回报　multi-step return　multi-step learning　多步TD　n-step bootstrapping　TD(0)　n步自举

在交互版中打开（看它长在树上的哪里）

价值目标先累加n步真实奖励，再接上第n步之后的价值估计。n=1就是TD，n取到回合结束就是蒙特卡洛，中间的n在偏差和方差之间折中。

先要会：时序差分与自举 强化学习中的蒙特卡洛方法

时序差分与自举只看一步真实奖励，其余全靠估计，偏差大、信息传得慢：一个终点奖励要回传100步，就需要至少100轮更新。强化学习中的蒙特卡洛方法用整局真实回报，无偏但方差大。n步回报把两者连成一条连续的谱。

定义。

G_t^(n) = r_{t+1} + γ·r_{t+2} + … + γ^{n−1}·r_{t+n} + γ^n · V(s_{t+n})

用它代替TD目标：V(s_t) ← V(s_t) + α·(G_t^(n) − V(s_t))。n=1退化为TD(0)，n≥剩余步数时没有自举项，就是蒙特卡洛。若回合在n步内结束，只累加到终止为止。

为什么有用。n越大，真实奖励占比越高，对V的依赖越少（偏差小），奖励信号一次就能往回传n步；但累加的随机奖励越多（方差大），而且要等n步之后才能更新。实践中n取3到十几步往往比两端都好。

在深度RL里。A3C按固定长度的片段计算多步回报；Rainbow把多步回报列为提升最大的组件之一；Ape-X和R2D2等分布式DQN也沿用多步目标。广义优势估计GAE则对所有n的优势估计按λ加权平均，见资格迹与TD(λ)。

离策略时要小心。n步回报里中间那几步动作是行为策略选的，不是目标策略会选的。严格做法要乘重要性采样比率，或像树备份与离策略资格迹、Retrace离策略修正那样截断修正；很多DQN变体直接忽略这一点，在n较小、回放数据较新的情况下通常可以接受，但会引入偏差。

例子

γ=0.9，从s_t开始的三步奖励为1, 0, 2，V(s_{t+1})=5，V(s_{t+3})=4。

  • 1步目标：1 + 0.9×5 = 5.5
  • 3步目标：1 + 0.9×0 + 0.81×2 + 0.729×4 = 1 + 1.62 + 2.916 ≈ 5.54

若V(s_{t+1})被严重高估成20，1步目标变成19，而3步目标完全不受影响，这就是多步回报降低对估计依赖的含义。

容易误解的地方

  • n不是越大越好：长回报的方差会让训练不稳定，离策略时偏差也会变大。
  • 用回放缓冲区时，n步目标要在采样时根据存下的连续转移现算，且遇到回合终止要截断，不能跨回合累加。
