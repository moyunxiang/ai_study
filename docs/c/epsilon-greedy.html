ε-贪心与玻尔兹曼探索

ε-Greedy and Boltzmann Exploration

也叫：ε-贪心　ε-greedy　epsilon greedy　epsilon-greedy　ε贪婪　e-greedy　ε衰减　epsilon decay　ε调度　玻尔兹曼探索　Boltzmann exploration　softmax探索　softmax exploration　无方向探索　undirected exploration

在交互版中打开（看它长在树上的哪里）

最常用的两种简单探索规则：ε-贪心以概率1−ε选当前估计最好的动作、以概率ε完全随机选；玻尔兹曼探索按估计值的softmax概率选，值越高越常被选。

先要会：探索与利用 Softmax与logits

探索与利用里最朴素也最常用的办法，不需要任何额外的模型或统计量，只在“选动作”这一步动手脚。

ε-贪心（ε-greedy）。

a = argmax_a Q(s, a)（概率1−ε）；a = 均匀随机动作（概率ε）

ε=0就是纯贪心（见最优策略与最优价值函数），ε=1就是纯随机。实际中ε随训练逐步减小：开始时什么都不懂，多探索；后期估计可靠了，多利用。DQN（Nature版）在前100万帧里把ε从1.0线性降到0.1，之后保持0.1，评估时用0.05。Ape-X让不同的并行actor使用不同的固定ε，有的大胆、有的保守，合在一起覆盖更多行为。

玻尔兹曼探索（softmax探索）。

π(a|s) = exp(Q(s, a)/τ) / Σ_b exp(Q(s, b)/τ)

即对Q做温度为τ的Softmax与logits。和ε-贪心相比，它不会把“明显很差”和“只差一点”的动作同等对待：好一点的动作试得多，差很多的几乎不试。缺点是对Q的数值尺度敏感，τ不好调。最大熵RL中的最优策略正好是这种形式，见熵正则与最大熵强化学习。

局限。两者都是无方向的探索：每一步独立地掷骰子，不会刻意去没去过的地方。要走一长串特定动作才能看到奖励时（例如连续向右走50步），随机碰上的概率随长度指数下降。需要有方向的探索时，要用上置信界与乐观原则、Thompson采样（见Thompson采样的复兴）或内在动机与内在奖励。

例子

4个动作，Q估计为(1.0, 0.9, 0.0, −5.0)，ε=0.1。ε-贪心选动作1的概率是0.9 + 0.1/4 = 0.925，其余各0.025，连−5的那个也一样。玻尔兹曼探索（τ=0.5）：exp(Q/τ) ≈ (7.39, 6.05, 1, 0.000045)，概率约为(0.51, 0.42, 0.07, 0.000003)：接近最优的动作2被试得很多，−5的那个几乎不试。

容易误解的地方

  • ε衰减得太快会过早停止探索，衰减得太慢会浪费样本；ε的调度本身就是重要的超参数。
  • 报告结果时要说明评估用的ε。用ε=0和ε=0.05评估同一个策略，Atari分数可能差不少。
