门控机制

Gating

也叫：gate　LSTM　GRU　遗忘门　门控单元　GLU

在交互版中打开（看它长在树上的哪里）

用一个取值在0到1之间、由网络自己算出来的向量去逐元素乘另一个信号，从而学会“放行多少、保留多少”。LSTM、GRU、SwiGLU和MoE路由都基于它。

先要会：神经元与激活函数 循环网络与隐状态 梯度消失与梯度爆炸

普通的循环网络与隐状态每一步都把隐状态整个重写一遍，旧信息每过一步就被挤掉一部分，几十步后几乎不剩。我们想要的是一个开关：该记住的时候原样保留，该更新的时候再写入——而且这个开关要能求导，好让梯度下降去学它。

定义。门是一个经过Sigmoid的向量：

g = σ(W·[h, x] + b)，每个分量都在(0, 1)之间。

它用逐元素乘法（记作⊙）去调节另一个信号：g ⊙ a。g的某一维接近1就放行，接近0就关闭。因为g由当前输入和状态算出，网络可以根据上下文决定开关。

LSTM（LSTM，1997）用三个门维护一个“细胞状态”c：

c_t = f_t ⊙ c_(t−1) + i_t ⊙ c̃_t h_t = o_t ⊙ tanh(c_t)

遗忘门f决定保留多少旧记忆，输入门i决定写入多少新内容c̃，输出门o决定对外暴露多少。关键在第一行是加法：当f接近1时，c几乎原样传下去，梯度也能沿着这条路径传很远而不衰减。RNN编码器-解码器与GRU提出的GRU把门减到两个，效果相近。

门控思想的推广。

  • Highway网络把门用在深层网络的层与层之间：y = g ⊙ F(x) + (1 − g) ⊙ x。去掉门、固定成x + F(x)就是残差连接。
  • Transformer的前馈层今天多用门控线性单元：SwiGLU(x) = (SiLU(x·W1) ⊙ x·W3)·W2（GLU变体与SwiGLU），一条支路当门去调制另一条。
  • 混合专家里的路由器也是一种门：决定每个token交给哪几个专家。
  • Mamba状态空间模型等现代线性RNN靠依赖输入的门（选择性衰减）决定忘掉什么，门控注意力在注意力输出上也加了门。

例子

假设一维记忆c初值为1，之后十步都没有新输入（i = 0）。

  • 如果遗忘门始终输出f = 0.9：c_10 = 0.9^10 ≈ 0.349，十步后仍保留约三分之一。
  • 如果f = 0.5：c_10 = 0.5^10 ≈ 0.001，基本忘光。
  • 如果网络学会让f ≈ 1：c几乎不变，可以记住任意久。

对比普通RNN，那里的“保留比例”由固定的权重和tanh导数决定，无法按需调成接近1；门控把它变成了一个可学习、随输入变化的量。

容易误解的地方

  • 门不是硬开关：σ的输出在(0, 1)开区间内，永远不会严格等于0或1，信息是被“调小”而不是被“删除”。
  • 门控缓解梯度消失，但不能根治：LSTM在几百步以上的依赖上依然吃力，这是后来转向注意力的原因之一。
  • 门的偏置初始化很重要。LSTM常把遗忘门偏置初始化为1左右，让它一开始倾向于记住。
