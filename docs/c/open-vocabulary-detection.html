开放词表检测

Open-Vocabulary Object Detection

也叫：OVD　OVOD　开放集检测　open-set detection　开放世界检测　open-world detection　零样本检测　zero-shot detection　文本提示检测　grounding检测　phrase grounding　开集检测

在交互版中打开（看它长在树上的哪里）

检测器不再只认训练时固定的几十类，而是根据用户输入的任意文字（如“红色雨伞”）找出图中对应物体。

传统检测器（Faster R-CNN、YOLO）的类别在训练时就写死了，比如COCO的80类，想加一类就得重新标注训练。开放词表检测把分类头换成与文本嵌入的相似度：只要能把类别名编码成向量，就能检测它。

早期做法是把CLIP的图文对齐知识蒸馏或迁移到检测器，如ViLD开放词表检测、OWL-ViT；GLIP把检测和短语定位统一成同一种预训练；Grounding DINO把这一思路接到DINO式检测Transformer上，成为最常用的开集检测器；YOLO-World把它做到实时。2025年的SAM 3概念分割把文本概念提示扩展到检测、分割与视频跟踪一体。

争论点：开放词表模型在COCO等常见类上很强，但对真实业务里的冷门类别泛化仍差，RF-DETR等工作认为在目标数据上微调专用小模型往往更实用。
