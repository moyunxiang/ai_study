集成学习

Ensemble Methods

也叫：模型集成　Bagging　Boosting　随机森林　投票法　model averaging

在交互版中打开（看它长在树上的哪里）

训练多个模型，把它们的预测投票或平均起来作为最终结果。只要各个模型的错误不完全相同，集成通常比其中任何一个单独的模型都更准、更稳。

先要会：偏差-方差权衡 期望与方差

单个模型的预测有随机性：换一份训练数据、换一个随机种子，结果就会变。集成学习的思路是“三个臭皮匠，顶个诸葛亮”：训练多个模型，分类时投票，回归时取平均。

为什么有效：从偏差-方差权衡的角度看，n个模型如果预测误差的方差都是σ²、彼此独立，平均后的方差降到σ²/n，偏差不变。实际中各模型的误差是相关的：相关系数为ρ时，平均后的方差是ρσ² + (1 − ρ)σ²/n，n再大也降不到ρσ²以下。所以集成的关键在于多样性——让各个模型犯不同的错误。

三种主要做法：

  • Bagging：从训练集中有放回地重复抽样，得到多份略有不同的数据，每份训练一个模型，再平均（Bagging）。随机森林在此基础上让每棵决策树每次分裂时只能从随机的部分特征中选，进一步增加多样性。
  • Boosting：串行地训练一系列弱模型，每个新模型重点修正前面模型犯错的样本，最后加权组合（AdaBoost与集成学习、梯度提升机）。它主要降低偏差。XGBoost等梯度提升树至今仍是表格数据上最强的方法之一。
  • 深度网络的集成：用不同随机种子训练几个网络再平均（深度集成），能提升精度，也让预测的不确定性估计更可靠。

代价：n个模型就要n倍的推理计算。因此产生了两种折中：用知识蒸馏把集成“压”进一个小模型；或把多个微调模型的权重直接平均成一个模型（Model Soups），推理成本不变。混合专家则可以看作一种在网络内部按输入挑选部分“专家”的集成形式。

例子

三个分类器各自准确率70%，且错误相互独立。多数投票（至少两个对才算对）的准确率为：

3×0.7²×0.3 + 0.7³ = 0.441 + 0.343 = 0.784

五个这样的分类器多数投票，准确率升到约0.837。但如果三个分类器总在同样的样本上犯错（完全相关），投票的准确率仍是70%，一点提升都没有。

容易误解的地方

  • 集成的提升依赖于模型之间的差异，把同一个模型复制多份没有用。
  • 论文里集成的结果不能直接与单模型比较，要看清对比的是不是同等计算量。
