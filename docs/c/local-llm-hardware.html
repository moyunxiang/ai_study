本地跑大模型的硬件

Hardware for Local LLMs

也叫：本地大模型　Local LLM　本地部署　消费级显卡跑大模型　统一内存　Unified Memory　AI PC　Mac跑大模型　家用AI服务器　桌面AI超算　显存大小

在交互版中打开（看它长在树上的哪里）

在个人电脑、Mac或一台桌面机上跑开源大模型，关键不在算力而在显存容量和内存带宽。

开源模型出现后，很多人想在自己的机器上运行它们。决定能跑多大模型的主要是显存或内存容量：70B参数模型用4位量化也要约40GB；决定速度的是内存带宽。

消费级显卡是第一条路：RTX 3090：24GB显存、RTX 4090与本地大模型的24GB显存一度是本地部署的标配，RTX 5090：32GB与FP4升到32GB。苹果的统一内存是第二条路：从Apple M1与统一内存起CPU和GPU共享内存，M3 Ultra：512GB统一内存最多512GB，可以装下很大的模型，配合Apple MLX和llama.cpp与本地推理使用。第三条路是专门的桌面AI机器，如NVIDIA的DGX Spark桌面超算。Windows阵营则推出带NPU的Copilot+ PC与NPU。

常见争论：大内存但带宽低的机器生成速度够不够用，以及量化到多低还能保持模型质量（见量化）。
