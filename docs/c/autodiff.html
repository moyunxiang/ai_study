自动微分与计算图

Automatic Differentiation

也叫：AD　autograd　自动求导　computational graph　反向模式自动微分　reverse-mode AD

在交互版中打开（看它长在树上的哪里）

把程序看成由基本运算组成的计算图，按链式法则逐个节点组合局部导数，让计算机自动、精确地求出任意程序的导数。

先要会：链式法则 导数、偏导与梯度 图、树与搜索

训练网络需要梯度。手工推导每种网络结构的梯度公式既慢又容易出错，每改一次结构就要重推一次。求导有三种办法：

  • 符号微分（像Mathematica那样推公式）：表达式会膨胀得很大，也处理不了循环、分支。
  • 数值微分（有限差分）：每个参数都要单独扰动一次，参数多时太慢，还有截断误差。
  • 自动微分：程序运行时把每个基本运算（加、乘、exp、矩阵乘……）记录成一张计算图。每种基本运算的导数是已知的，再用链式法则沿图组合起来。结果精确到浮点误差，代价只是原计算的常数倍。

前向模式与反向模式：前向模式从输入出发，顺着计算顺序同时传播“值”和“对某个输入的导数”，跑一遍得到所有输出对一个输入的导数。反向模式先正常算一遍并记下中间值，再从输出倒着传，跑一遍得到一个输出对所有输入的导数。神经网络是“几十亿个输入（参数）、一个输出（损失）”，所以用反向模式——这正是反向传播。

计算图与框架：深度学习框架的核心就是自动微分引擎。Theano与自动微分和TensorFlow早期先定义静态图再执行；PyTorch在代码运行时动态建图，可以随意用Python的if和for，调试方便，因而流行；JAX把求导做成可组合的函数变换grad(f)。研究者写出前向计算，梯度就自动得到——这让试新结构的成本大幅下降。

历史上Wengert列表与前向自动微分（1964）提出前向模式，反向模式自动微分（1970）提出反向模式，比神经网络界普遍使用反向传播早了十多年。

例子

f(x, y) = x·y + sin(x)，在x = 2，y = 3处。

前向记录计算图：a = x·y = 6，b = sin(2) ≈ 0.909，f = a + b ≈ 6.909。

反向：∂f/∂a = 1，∂f/∂b = 1；a对x、y的局部导数是y、x，b对x的导数是cos x。于是

  • ∂f/∂x = 1×y + 1×cos(2) = 3 − 0.416 ≈ 2.584
  • ∂f/∂y = 1×x = 2

一次反向就同时得到了两个偏导。

容易误解的地方

  • 自动微分不是数值微分，不存在步长选择问题，结果是精确的（除浮点误差外）。
  • 在不可导点（如ReLU在0处）框架会约定一个值（通常取0），这一般不影响训练。
  • 反向模式要保存前向的中间结果，内存开销随计算深度增长。
