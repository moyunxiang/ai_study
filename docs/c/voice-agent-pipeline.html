语音智能体与级联管线

Voice Agents and Cascaded Pipelines

也叫：voice agent　语音Agent　语音智能体　语音助手　级联语音　cascaded pipeline　ASR+LLM+TTS　STT-LLM-TTS　VAD　语音活动检测　轮次检测　端点检测　endpointing　实时语音API　AI客服　AI电话

在交互版中打开（看它长在树上的哪里）

把语音识别、大语言模型、语音合成串成一个能打电话、做客服、调用工具的语音应用，并把延迟压到对话可接受的范围。

尽管端到端模型发展很快，很多实际语音产品仍是级联：识别（Whisper、gpt-4o-transcribe/tts、Voxtral系列）→文本LLM（可调用工具）→合成（OpenAI TTS与Voice Engine、ElevenLabs、Kokoro-82M轻量TTS）。优点是每个模块可替换、可审计，LLM的推理和工具能力不打折扣。

难点在工程：语音活动检测和话轮判断决定何时开口，流式识别与流式合成（延迟流建模DSM）把首包延迟压到几百毫秒，打断时要及时停下。OpenAI Realtime API把这些做成托管接口；Kyutai的Unmute用DSM识别与合成包住文本模型。早期的Google Duplex打电话打电话演示就是这类系统的雏形，Siri与语音助手、Amazon Echo与Alexa则是更早的语音助手形态。

争论：级联与端到端谁会胜出。目前趋势是混合——GPT-Live全双工语音前台用全双工语音模型，后台把难题委托给文本大模型。
