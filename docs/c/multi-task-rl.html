多任务强化学习

Multi-Task RL

也叫：多任务强化学习　multi-task RL　multitask RL　multi-task reinforcement learning　多任务策略　任务条件策略　task-conditioned policy　负迁移　negative transfer　梯度冲突　gradient conflict　多任务智能体

在交互版中打开（看它长在树上的哪里）

用一个智能体同时学多个任务：策略和价值网络以任务编号、目标或语言指令为条件，共享大部分参数。希望任务之间互相借力，但也会出现任务互相干扰、奖励尺度不一致的问题。

先要会：策略与价值函数 迁移学习

单任务RL每学一个新任务都从零开始。很多任务却明显共享知识：开抽屉和开柜门都要抓把手、往外拉；不同Atari游戏都要识别物体和躲避危险。多任务强化学习让一个网络同时在N个任务上训练，期望共享的部分学得更好、更省数据，并为泛化到新任务打下基础。

基本做法。把任务信息作为输入：任务的独热编号、目标状态（见目标条件强化学习）、或一句语言指令。策略写成π(a|s, z)，z是任务表示，价值函数同理。所有任务的数据放进同一个训练流程，损失按任务求和或加权。

主要困难。

  • 负迁移与梯度冲突：不同任务的梯度方向可能相反，合在一起训练，某些任务反而比单独训练更差。常见对策有对冲突的梯度做投影、按任务分出部分专用参数或专用输出头、用混合专家式的路由。
  • 奖励尺度不一致：一个游戏每步得几千分，另一个只有0或1，前者的梯度会压倒后者。奖励裁剪是粗暴的做法，PopArt自适应目标归一化用自适应的价值归一化让各任务贡献均衡，见强化学习中的归一化：观测、奖励与优势。
  • 数据与计算分配：难任务需要更多样本，简单任务很快学会，均匀采样效率低。

代表性工作。IMPALA与V-trace和PopArt自适应目标归一化在DMLab-30、Atari-57上训练单个多任务智能体；MT-Opt多任务真机RL在真实机器人上同时学十余种操作技能，并共享各任务的数据；Meta-World提供了50个机械臂操作任务的多任务和元学习基准；Gato把游戏、机器人和语言任务统一成序列建模。

与相邻概念的区别。多任务RL在训练时就见到所有任务，追求“同时都做好”；元强化学习追求在新任务上快速适应；持续学习按顺序遇到任务，重点是不遗忘旧任务，见持续学习与灾难性遗忘。

例子

两个任务共享一个策略：任务A每回合奖励约1000，任务B约1。不做任何归一化时，价值损失和策略梯度几乎全来自A，B的表现停在随机水平；把每个任务的价值目标按各自的滑动标准差归一化后，两者的梯度量级相近，B也能学会。数值是说明用的设定。

容易误解的地方

  • “多任务训练比单任务好”不是必然的，必须和每个任务单独训练的基线比较。
  • 测试时若任务编号来自训练集，评估的是多任务能力而不是泛化能力。
