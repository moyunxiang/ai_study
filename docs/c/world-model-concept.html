世界模型

World Model

也叫：world models　环境模型　预测模型　视频预测　JEPA　dynamics model

在交互版中打开（看它长在树上的哪里）

世界模型是一个能预测“如果我这样做，世界接下来会变成什么样”的模型；有了它，智能体可以在脑中先试几遍再行动，或者把它当作学出来的仿真器。

先要会：状态、观测与动作 马尔可夫决策过程

人伸手接球前不会真的试错几百次，而是在脑子里预测球的轨迹。无模型的强化学习则要在真实环境里试错几百万次，这对机器人不可行。如果能先学会环境如何变化，就可以在“想象”里试错、规划和生成数据，这个被学出来的环境模型就叫世界模型，基于它的强化学习见基于模型的强化学习。

定义。最一般的形式是给定当前状态和动作，预测下一状态的分布：

p(s_{t+1} | s_t, a_t)

由于机器人只拿到图像观测，实际常写成p(o_{t+1} | o_≤t, a_≤t)，或者先把观测编码成一个紧凑的隐状态z（见潜空间），在隐空间里预测z_{t+1} = f(z_t, a_t)。往往还会同时预测奖励和任务是否结束。

两种风格。一是生成式：直接预测未来的像素或视频，好处是结果可看、可检验，能直接拿视频生成模型（见视频扩散模型）来用，代表有可交互的Genie 3和面向机器人与驾驶的Cosmos世界基础模型。二是隐空间预测式：只在抽象表示里预测未来，不重建像素，省掉了大量与决策无关的细节（树叶怎么晃），代表是JEPA与LeCun的世界模型路线路线和V-JEPA 2。

世界模型的四种用法。

  • 规划：在模型里试多条动作序列，挑预测结果最好的执行，见规划与模型预测控制、PlaNet。
  • 在想象中训练策略：让策略在模型生成的轨迹里学习，Dreamer系列只用少量真实交互就学会控制。
  • 当作仿真器：生成训练数据或评测策略，弥补仿真到现实的差距和真机数据不足。
  • 直接当策略：联合预测未来画面和动作，这就是世界动作模型WAM，见VLA与WAM的基本结构和DreamZero与世界动作模型WAM。

它出现在哪里：World Models（2018）用VAE加RNN在隐空间里“做梦”训练赛车策略，让这个名字流行起来；近年视频生成模型规模扩大后，世界模型成为自动驾驶和具身智能的主要方向之一。

例子

一张256×256的RGB画面有256 × 256 × 3 = 196,608个数。如果先用一个编码器把它压成32×32×16的隐变量，只剩16,384个数，约为原来的1/12。世界模型在这个隐空间里逐帧预测：给定当前隐状态和动作「夹爪前移2厘米」，输出下一帧的隐状态；连续预测15步，就“想象”出了未来约1–2秒的画面，规划器可以并行想象几百条不同的动作序列，挑出最有可能把杯子放进盘子的那条。

容易误解的地方

  • 视频生成模型画面逼真，不等于它是好的世界模型：它可能违反物理（物体穿透、凭空消失），也可能不响应动作输入。
  • 长时预测误差会累积，预测几十步之后往往偏离现实，所以规划通常只看短时域并不断重新规划。
  • “世界模型”一词含义很宽，有时指显式的物理仿真，有时指语言模型内部的世界知识，要看论文的具体定义。
