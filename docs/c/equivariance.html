不变性与等变性

Invariance and Equivariance

也叫：平移不变　translation invariance　旋转等变　对称性

在交互版中打开（看它长在树上的哪里）

对输入做某种变换（平移、旋转、重排）后，输出要么不变（不变性），要么跟着做相应的变换（等变性）。把这类对称性写进网络结构，能大幅节省数据和参数。

先要会：卷积层、池化与感受野 归纳偏置 自注意力与多头注意力

一张猫的照片向右平移10个像素，仍然是猫；一个分子在空间里整体旋转，它的能量不变；一张社交网络图换一种节点编号，图本身没变。这些都是任务自带的对称性。如果网络不知道它们，就只能从数据里一个个例子去学（比如把每张图在每个位置都看一遍）；如果把对称性直接写进结构，网络天生就满足，省下大量数据。这是最重要的一类归纳偏置。

定义。设T是对输入的一种变换（如平移），f是网络。

  • 不变：f(T·x) = f(x)。输入变了，输出完全不变。适合“是什么”类的输出：分类标签、分子能量。
  • 等变：f(T·x) = T′·f(x)。输入怎么变，输出就按对应的方式变。适合“在哪里”类的输出：分割图、每个原子受的力、每个节点的特征。

不变性是等变性的特例（T′取恒等变换）。常见的构造方式是：前面若干层都保持等变（不丢信息），最后用一个对称的汇总操作（求和、取最大）得到不变的输出。

几个具体的例子。

  • 卷积对平移等变（见卷积层、池化与感受野）：同一个卷积核在每个位置做同样的计算，输入平移，特征图跟着平移。最后的全局池化让分类结果对平移（近似）不变。LeNet与卷积网络起的卷积网络都靠这一点。
  • 自注意力对排列等变：不加位置编码时，打乱输入token的顺序，输出只是按同样方式打乱（见自注意力与多头注意力）。这就是为什么Transformer必须另加位置编码。
  • 集合与图：Deep Sets证明，对集合的置换不变函数都可以写成ρ(Σ_i φ(x_i))；图神经网络的消息传递对节点重编号是等变的（见图神经网络与消息传递）。
  • 旋转等变：群等变卷积把卷积推广到旋转、翻转等群；分子和蛋白质模型（如AlphaFold 2的结构模块）用对三维旋转等变的网络，旋转输入坐标，预测的力也跟着旋转。

几何深度学习把这些统一成一个框架：不同的架构对应不同的对称群。

例子

卷积的平移等变。一维卷积核[1, −1]，计算y_i = x_i − x_(i+1)。

  • 输入x = [0, 1, 0, 0]，输出y = [−1, 1, 0]。
  • 把输入右移一格：x′ = [0, 0, 1, 0]，输出y′ = [0, −1, 1]——正好是y右移一格。这是等变。
  • 对输出取最大值：max(y) = 1，max(y′) = 1。加上这个汇总后结果不随平移改变，这是不变。

排列等变。三个token组成的输入，自注意力（不加位置编码）输出为[o_1, o_2, o_3]。把输入顺序改为(3, 1, 2)，输出就是[o_3, o_1, o_2]，每个token得到的新向量与原来完全相同。

容易误解的地方

  • 实际的卷积网络只是近似平移等变：步长大于1的下采样和边界填充都会破坏严格的等变，图像平移一两个像素，分类结果有时会改变。
  • 对称性写进结构是一把双刃剑：如果任务其实不具备这种对称性（比如区分数字6和9时不该对旋转不变），强加它反而有害。
  • 数据增强（随机平移、旋转训练样本）是另一种获得近似不变性的方法：不改结构，让网络从数据里学。
