k近邻

k-Nearest Neighbors

也叫：kNN　最近邻　nearest neighbor　近邻分类　最近邻搜索

在交互版中打开（看它长在树上的哪里）

不训练任何参数，预测时直接在训练集里找离新样本最近的k个点，让它们投票（分类）或取平均（回归）。

先要会：范数与距离 监督学习

最简单的学习方法是“看看以前最像的例子是什么”。k近邻（kNN）就是这个想法的直接实现：训练阶段只是把所有样本存起来；来了一个新样本x，按某种距离（常用欧氏距离或余弦距离，见范数与距离、内积与余弦相似度）找出训练集中离它最近的k个点，分类时取多数票，回归时取平均。k近邻在1967年就给出了它的理论性质：样本无限多时，1近邻的错误率不超过最优贝叶斯分类器的两倍。

k的作用：k = 1时决策边界紧贴每个训练点，对噪声极敏感（高方差）；k很大时边界过于平滑，甚至总是预测多数类（高偏差）。k是一个要在验证集上选的超参数与调参，体现了偏差-方差权衡的权衡。

两个主要弱点：一是慢，朴素实现每次预测都要和全部n个样本算距离，代价O(n·d)；二是在高维原始特征上不灵，因为维度灾难让所有点之间的距离都差不多。

为什么它在深度学习时代反而重要了：只要先用神经网络把数据变成好的嵌入向量，在嵌入空间里做近邻就很有效，第二个弱点被绕开了；而HNSW近似近邻等近似近邻索引把搜索变成对数级，第一个弱点也缓解了。今天的检索与向量数据库和向量数据库本质上就是大规模kNN；kNN-LM在语言模型的输出上混入近邻检索的结果；小样本分类、人脸识别、自监督表示的评估（kNN准确率）也都用它。

例子

二维平面上，查询点(2,2)。训练点：A(1,1)红、B(2,3)红、C(3,3)蓝、D(5,5)蓝、E(2,0)蓝。距离分别是1.41、1.00、1.41、4.24、2.00。

  • k = 1：最近的是B，预测红。
  • k = 3：B、A、C，两红一蓝，预测红。
  • k = 5：全部五个点，两红三蓝，预测蓝。

同一个点，k不同答案就不同。

容易误解的地方

  • 特征尺度不一致时距离会被大数值的特征主导（比如收入以元计、年龄以岁计），要先标准化。
  • kNN没有训练阶段，但不等于没有成本：存储全部数据、预测时搜索都很贵。
  • 近似近邻索引会漏掉少量真正的最近邻，检索系统里要权衡召回率与速度。
