度量学习

Metric Learning

也叫：Metric Learning　距离度量学习　相似度学习　Similarity Learning　孪生网络　Siamese Network　三元组损失　Triplet Loss　对比损失　Contrastive Loss　深度度量学习　Deep Metric Learning　小样本分类

学一个嵌入空间，让同类样本靠近、异类样本远离，于是分类、检索、验证都能归结为“比距离”。

对比损失用成对样本训练孪生网络：同类对拉近、异类对推开到一个间隔之外，学到的嵌入可以直接用距离做判断。FaceNet与三元组损失把它改成三元组损失（锚点、正例、负例），在人脸验证上大获成功，ArcFace进一步在角度空间里加间隔。

小样本学习也采用了这个思路：匹配网络与小样本学习用支持集样本的加权相似度做预测，原型网络把每类样本的嵌入均值当作原型，新样本归到最近的原型。后来的自监督对比学习（见对比学习）可以看作不需要标签的度量学习。
