命名实体识别

Named Entity Recognition

也叫：NER　实体识别　实体抽取　Entity Extraction　专名识别　Named Entity Recognition and Classification　NERC　开放域NER　零样本NER

在交互版中打开（看它长在树上的哪里）

从文本中找出人名、地名、机构名等专有名称，并判断各自属于哪一类。

命名实体识别这个任务名来自1990年代的MUC信息抽取评测信息抽取评测。早期系统靠规则和地名词典，Nymble命名实体识别用HMM从标注数据学习；之后最大熵模型、最大熵马尔可夫模型MEMM和条件随机场成为标准做法，把NER当作给每个词打BIO标签的序列标注，CoNLL-2003命名实体成了十几年的标准基准。

神经网络时代，BiLSTM-CRF序列标注和神经命名实体识别用双向LSTM学特征、CRF层保证标签合法，接着BERT式预训练模型把基准分数推到接近饱和。开源工具如Stanford CoreNLP、spaCy把NER做成开箱即用的组件。

现在的焦点是开放类型：实体类型不再在训练时固定。大模型可以按指令抽任意类型但成本高，GLiNER开放类型NER用小型双向编码器把类型名和文本片段做匹配，零样本效果超过ChatGPT。
