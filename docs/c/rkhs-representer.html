再生核希尔伯特空间、表示定理与核岭回归

RKHS, the Representer Theorem and Kernel Ridge Regression

核方法的理论底座：每个核函数对应一个函数空间（RKHS）；表示定理说，在其中做带正则的经验风险最小化，最优解一定是训练样本处核函数的线性组合，核岭回归是典型例子。

先要会：核技巧与间隔 正则化与权重衰减

核技巧与间隔让线性算法在高维甚至无穷维的特征空间里工作。可是在无穷维空间里优化，参数也是无穷多个，这怎么算？答案依赖两个概念。

希尔伯特空间与函数空间。向量空间里的元素不一定是数组，也可以是函数。如果一个函数集合定义了内积（于是有长度和角度），并且是“完备的”（没有窟窿），就叫希尔伯特空间。可以把每个函数f看作一个无穷长的向量，‖f‖衡量它有多“复杂”或多“不光滑”。

再生核希尔伯特空间（RKHS）。给定一个半正定的核函数k（见正交矩阵与正定矩阵），可以构造唯一一个函数空间H，使得：每个k(x, ·)都属于H，并且对H中任意函数f都有

f(x) = ⟨f, k(x, ·)⟩

即“在x点取值”等于“与k(x, ·)做内积”，这叫再生性质。高斯核对应的RKHS里都是非常光滑的函数，范数大意味着变化剧烈。

表示定理。在H中最小化“训练损失 + λ‖f‖²”：

min_f Σ_i ℓ(f(x_i), y_i) + λ‖f‖²_H

无论H是多少维，最优解一定形如

f*(x) = Σ_{i=1}^{n} α_i · k(x_i, x)

只需要求n个系数α。无穷维问题就这样化成了n维问题。支持向量机、核逻辑回归、核PCA（核主成分分析）都依赖这一点。

核岭回归。损失取平方误差时，α有闭式解：

α = (K + λI)⁻¹ y

K是n×n的核矩阵K_ij = k(x_i, x_j)。它就是岭回归与L2正则回归换上核函数（见线性回归和正则化与权重衰减）。这个式子与高斯过程回归回归的预测均值完全相同（λ对应噪声方差），与支持向量回归（SVR）的区别只在损失函数：SVR用ε不敏感损失，得到稀疏的α。

代价与扩展。核矩阵是n×n的，求解要O(n³)，样本到十万级就很吃力，这推动了核近似：随机特征与Nyström方法。在深度学习理论里，神经正切核表明无限宽网络的训练等价于用神经正切核做核回归，见无限宽网络理论。

例子

三个训练点x = (0, 1, 2)，y = (0, 1, 0)，高斯核k(a, b) = exp(−(a − b)²)，λ = 0.1。K的非对角元为e⁻¹ ≈ 0.368和e⁻⁴ ≈ 0.018。解(K + 0.1I)α = y得α ≈ (−0.38, 1.17, −0.38)。在x = 1处预测f(1) = −0.38×0.368 + 1.17×1 − 0.38×0.368 ≈ 0.88，略小于1，是正则化带来的收缩。

容易误解的地方

  • 表示定理只对“损失 + 关于RKHS范数单调递增的正则项”成立；换成别的正则化（如L1作用在函数上）结论不一定成立。
  • 核岭回归的α一般不稀疏，预测时要和全部训练样本计算核函数；SVR、SVM的稀疏性来自损失函数而不是核本身。
