核密度估计

Kernel Density Estimation

也叫：核密度估计　kernel density estimation　KDE　Parzen窗　Parzen window　Parzen估计　Parzen-Rosenblatt　非参数密度估计　nonparametric density estimation　带宽　bandwidth　Silverman规则　密度估计　density estimation　kdeplot　直方图　histogram

在交互版中打开（看它长在树上的哪里）

不假设分布的形状，直接在每个样本点上放一个小“鼓包”（核函数），全部加起来当作密度估计。它是直方图的平滑版本，带宽决定了平滑程度。

先要会：随机变量与概率分布 高斯分布

手上有一堆样本，想知道它们来自什么样的分布。参数方法先假设一个形状（比如高斯分布或高斯混合模型）再估计参数；如果形状猜错了，结果就错。非参数方法不做形状假设，让数据自己说话。

从直方图到核密度估计。直方图把数轴切成格子数样本，但结果是锯齿状的，而且依赖格子从哪里开始切。核密度估计（KDE），又叫Parzen窗方法，在每个样本x_i处放一个以它为中心的核函数K，然后取平均：

p̂(x) = (1 / (n·h)) · Σ_i K((x − x_i) / h)

K常用标准高斯密度，h叫带宽。结果是一条光滑曲线，样本密集处高、稀疏处低。

带宽的选择。h太小，每个样本都是一个尖峰，严重过拟合；h太大，所有结构被抹平成一个大鼓包。这是偏差-方差权衡的典型体现。一维高斯核的常用经验值（Silverman规则）是h ≈ 1.06·σ̂·n^(−1/5)，也可以用交叉验证选。

维度灾难。高维空间里样本极其稀疏，要覆盖空间所需的样本数随维度指数增长，KDE在十几维以上就基本失效（见维度灾难）。这也是需要深度生成模型的原因之一（见生成建模的目标）。

它出现在哪里。

  • 早期评估生成模型：生成对抗网络GAN的原始论文用生成样本拟合高斯Parzen窗，再算测试数据的对数似然；后来的研究指出这种估计在高维图像上很不可靠，此后改用FID等指标（见生成质量指标：IS与FID）。
  • 去噪分数匹配：用高斯核平滑经验分布，得到的就是一个KDE，去噪分数匹配学的正是这个平滑分布的分数函数，这与扩散模型直接相关（见分数函数与分数匹配）。
  • Mean Shift均值漂移聚类：从每个点出发，沿KDE密度的梯度往上爬，最终停在同一个峰上的点归为一类，见聚类。
  • 数据分析和可视化里画“平滑分布曲线”（如seaborn的kdeplot）就是KDE。

例子

三个样本(1, 2, 6)，高斯核、带宽h = 1。在x = 2处，三个核的值分别为φ(1) ≈ 0.242、φ(0) ≈ 0.399、φ(4) ≈ 0.0001，平均得p̂(2) ≈ 0.214。在x = 4处为(φ(3) + φ(2) + φ(2))/3 ≈ (0.004 + 0.054 + 0.054)/3 ≈ 0.037，处于两组样本之间的低谷。

容易误解的地方

  • KDE与“核技巧”中的核函数不是一回事：这里的核是一个平滑用的概率密度，那里的核是特征空间的内积，见核技巧与间隔。
  • 对有边界的数据（如只能为正的量），KDE会在边界外“漏”出概率，需要边界修正。
