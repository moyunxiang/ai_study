主动视觉搜索与图像思考

Active Visual Search / Thinking with Images

也叫：用图像思考　Thinking with Images　看图推理时放大裁剪　视觉搜索　Visual Search　Zoom-in　视觉思维链　Visual Chain-of-Thought　交错图文推理　Agentic Visual Reasoning

在交互版中打开（看它长在树上的哪里）

推理过程中模型主动去放大、裁剪、标注图像的局部，再看一遍，而不是只看一眼全图就全靠文字推理。

普通VLM把整张图缩小后看一次，对高分辨率图中的小物体无能为力，推理时也无法回头看。V*引导视觉搜索提出“先找再答”：信息不够时列出要找的目标，由视觉搜索模型定位并把局部裁剪放进工作记忆，在其高分辨率基准上把GPT-4V的约55%提高到75%。Set-of-Mark提示用在图上打编号标记的方式帮助模型指代区域。

用图像思考指OpenAI OpenAI o3在思维链中直接裁剪、旋转、放大图像，把“看”变成推理的一部分。开源侧的DeepEyes图像思考RL用端到端强化学习让模型自己学会何时调用放大工具。这与多模态R1式强化学习是互补的：后者主要优化文字推理，这里优化“看哪里”。开放问题是这类工具调用能否推广到视频和三维场景，以及如何低成本获得训练信号。
