模型合并

Model Merging

也叫：模型融合　权重合并　权重平均　weight averaging　merge　model soup　模型汤　任务向量　task vector　TIES　DARE　SLERP　Frankenmerge　合并模型

在交互版中打开（看它长在树上的哪里）

不再训练，直接把几个从同一底座微调出来的模型的权重按某种规则相加或平均，得到兼具多种能力的一个模型。

从同一个预训练模型微调出的多个模型，权重往往处在同一个“盆地”里，可以直接平均。Model Soups权重平均发现平均同一任务的多次微调能提升精度；任务算术与模型合并把“微调后减去预训练”定义为任务向量，相加就能组合能力、相减就能去掉能力。

直接相加的问题是不同任务的改动互相干扰。TIES-Merging模型合并先修剪掉小改动、再按符号投票，只合并方向一致的部分；之后的DARE随机丢弃大部分改动再放大其余部分。MergeKit把这些方法做成工具，开源社区在2024年前后用它合出了大量排行榜模型。

现在的讨论包括：合并为什么有效（线性模式连通性）、能否合并不同底座的模型、以及合并在大模型后训练（例如把推理与非推理版本合在一起）中的作用。
