泰勒展开

Taylor Expansion

也叫：泰勒级数　Taylor series　泰勒公式　一阶近似　二阶近似　线性化

在交互版中打开（看它长在树上的哪里）

在某一点附近，用多项式近似一个函数：一阶项是切线（梯度），二阶项刻画弯曲（海森）。几乎所有优化算法都建立在这种局部近似上。

先要会：导数、偏导与梯度 雅可比矩阵与海森矩阵

损失函数通常极其复杂，没法直接求出最小值在哪。但在当前参数附近的一小块区域里，任何光滑函数看起来都像一条直线或一个抛物面。优化算法的基本思路就是：用简单的局部近似代替复杂函数，在近似上走一步，再重新近似。泰勒展开就是构造这种近似的工具。

定义。单变量函数在a点附近：

f(a + h) = f(a) + f'(a) h + f''(a) h² / 2 + …

多变量函数在θ点附近，展开到二阶：

L(θ + δ) ≈ L(θ) + ∇L(θ)ᵀ δ + ½ δᵀ H δ

其中∇L是导数、偏导与梯度，H是雅可比矩阵与海森矩阵中的海森矩阵。h或δ越小，近似越准。

从泰勒展开看优化算法。只看一阶项，L沿−∇L下降最快，这就是梯度下降；但一阶近似没有“底”，所以步长必须靠学习率人为限制。保留二阶项，对δ求导令其为0，得到牛顿法的一步δ = −H⁻¹∇L，它自动知道该走多远，但需要海森矩阵，代价高昂。

它出现在哪里。L-BFGS和Hessian-free优化是对牛顿法的廉价近似；TRPO把目标做一阶展开、把KL约束做二阶展开，从而推出更新方向；神经正切核把很宽的网络在初始化附近做一阶展开，发现训练过程近似于一个线性模型。泰勒展开也常用来分析近似误差，比如数值求导和常微分方程与随机微分方程中欧拉法的误差都来自被丢掉的高阶项。

例子

用泰勒展开近似e^0.1（在0点展开）：1 + 0.1 + 0.1²/2 = 1.105，真实值约1.10517，误差不到0.0002。若用同样的二阶展开去算e¹：1 + 1 + 0.5 = 2.5，真实值约2.718，误差就大得多。这说明泰勒近似只在展开点附近可靠，对应到训练里，就是学习率太大时梯度步会失效。

容易误解的地方

  • 泰勒近似是局部的：在展开点附近好用，离远了可能完全错误。
  • 牛顿法在非凸函数上，如果海森有负特征值，会被引向鞍点或极大值，不能直接照搬到神经网络训练。
