LLM当裁判

LLM-as-a-Judge

也叫：LLM-as-a-Judge　LLM as a judge　大模型裁判　大模型评审　模型打分　自动评审　judge model　AI裁判　GPT-4评测　autograder　自动阅卷　rubric评分　评分细则打分　pairwise judge

在交互版中打开（看它长在树上的哪里）

让一个强语言模型代替人类给其他模型的开放式回答打分或两两比较，用来大规模、低成本地评测对话、写作和智能体输出。

开放式回答没有标准答案，人工评审又贵又慢。LLM-as-a-Judge与MT-Bench系统检验了用GPT-4当裁判的做法，发现它与人类偏好的一致率接近人与人之间的一致率，同时指出位置偏差、偏好更长回答、偏向自己的回答等问题。此后AlpacaEval长度控制用长度控制修正“越长越好”的偏差，Arena-Hard用竞技场里挑出的难题配合裁判模型近似人类排名，RewardBench奖励模型评测则专门考核给RLHF打分的奖励模型。

到2025–2026年，裁判模型已经深入几乎所有新基准：IMO-Bench用模型按评分细则批改证明，MCP-Atlas按原子事实覆盖率判分，GDPval和APEX-Agents职业任务用专家细则加模型裁判评估交付物，Artificial Analysis智能指数的部分成分也用多模型裁判两两比较。争论集中在：裁判和被评模型同源时是否自我偏袒、裁判能否评判比自己更强的模型、换一个裁判版本分数是否就变。
