二元交叉熵与sigmoid输出

Binary Cross-Entropy

也叫：二元交叉熵　二分类交叉熵　binary cross-entropy　binary cross entropy　BCE　BCE loss　BCELoss　BCEWithLogitsLoss　sigmoid交叉熵　sigmoid cross-entropy　对数损失　log loss　logistic loss　逻辑损失　pos_weight

二分类或多标签分类的标准损失：模型用sigmoid输出“是”的概率p，标签为1时罚−log p，为0时罚−log(1−p)。每个标签各自独立地做一次是/否判断。

先要会：交叉熵 逻辑回归

Softmax与logits加交叉熵适用于“从K类里恰好选一个”。但很多问题是独立的是/否判断：这封邮件是不是垃圾邮件？这张胸片里有没有肺炎、有没有积液、有没有骨折（可以同时有好几种）？这时每个判断各用一个sigmoid和一个二元交叉熵。

定义。模型输出logit z，经sigmoid得到p = σ(z) = 1 / (1 + e^(−z))。标签y ∈ {0, 1}：

BCE = −[y·log p + (1 − y)·log(1 − p)]

这是伯努利分布的负对数似然（见伯努利、二项、类别与多项分布和最大似然估计），也就是逻辑回归的损失。对logit的梯度同样简洁：∂BCE/∂z = p − y。

多标签分类。K个标签就输出K个logit，各自做sigmoid和BCE，再求平均。它们之间互不竞争，概率之和不必为1。CheXNet等医学影像模型对多种病变同时给出概率，就是这样训练的，见二分类、多分类与多标签。

数值稳定的写法。先算sigmoid再取log，当z很大或很小时会出现log(0)。框架提供的BCEWithLogitsLoss直接从logit计算：max(z, 0) − z·y + log(1 + e^(−|z|))，等价但不会溢出（见数值稳定性：上溢、下溢与条件数）。

类别不平衡。正样本很少时，可以给正类的损失加权（pos_weight），或者使用Focal Loss与RetinaNet提出的focal loss，在BCE前乘上(1 − p_t)^γ，压低大量“容易的负样本”的权重，见类别不平衡与长尾。

它出现在哪里。

  • word2vec的负采样（Skip-gram负采样）把“这个词是否出现在上下文里”当作二分类，对真实词对和随机负样本分别做BCE。
  • SigLIP把CLIP的softmax对比损失换成对每个图文对独立做sigmoid二分类，不再需要在整个批次上归一化。
  • GAN的判别器用BCE区分真假样本（见对抗训练）；奖励模型、内容安全分类器、检索中的“是否相关”判断也常用它。

例子

某张图有三个标签（猫、狗、草地），真实为(1, 0, 1)，模型输出概率(0.9, 0.3, 0.6)。三个BCE分别为−log 0.9 ≈ 0.105、−log 0.7 ≈ 0.357、−log 0.6 ≈ 0.511，平均≈0.324。概率加起来是1.8，不需要等于1。如果用softmax，三个类就被迫互相竞争，“既有猫又有草地”反而难以表达。

容易误解的地方

  • 多类单标签问题（恰好属于一类）用K个sigmoid也能训，但概率之间没有约束，通常不如softmax。
  • 二分类时“一个输出+sigmoid+BCE”与“两个输出+softmax+交叉熵”在数学上等价，只是参数化不同。
