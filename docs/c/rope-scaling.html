RoPE缩放：位置插值、NTK与YaRN

RoPE Scaling: Interpolation, NTK and YaRN

也叫：RoPE缩放　RoPE scaling　rope_scaling　NTK感知缩放　NTK-aware scaling　NTK-aware RoPE　动态NTK　Dynamic NTK　dynamic NTK scaling　动态NTK缩放　基频调整　RoPE base　rope theta　ABF　adjusted base frequency　位置插值方法　长上下文扩展

让用RoPE训练的模型处理比训练时更长的文本：位置插值把位置压回训练范围，NTK感知缩放和动态NTK改基频，YaRN按频率分段处理。有的免训练，有的只需少量长文本微调。

先要会：位置编码 上下文窗口

用4K上下文训练的模型，直接喂给它16K的文本，困惑度通常会在4K之后急剧上升。原因在位置编码：旋转位置编码RoPE把位置m编码成旋转角m·θ_i，第i对维度的频率是θ_i = b^(−2i/d)（基频b通常为10000）。超过训练长度后，低频维度转到了训练中从没见过的角度，注意力分数分布随之失常。重新用长文本从头训练代价太高，于是出现了一系列“改一改旋转角”的方法（总述见位置编码外推与上下文扩展）。

位置插值（PI）。位置插值扩上下文把位置按比例缩小：要从L扩到s·L，就用m/s代替m。所有角度都回到训练见过的范围，只需约1000步的长文本微调就能把LLaMA扩展到32K。缺点是高频维度也被压缩了，相邻token之间的角度差变小，模型分辨近距离位置的能力下降。

NTK感知缩放。不改位置，而是放大基频：b' = b·s^(d/(d−2))。效果是高频维度几乎不变（保留局部位置分辨率），低频维度被拉伸（相当于插值）。名字来自神经正切核理论中“高频信息难学”的启发（见无限宽网络理论）。它最初由社区提出，不微调就能把有效长度扩到原来的几倍。

动态NTK。推理时根据当前序列长度n动态决定缩放比例：n不超过训练长度时不缩放，超过后按s = n/L实时计算新的基频。短文本上完全不损失性能，长文本上逐步插值；它是Hugging Face实现中的一个常用选项（rope_scaling类型为dynamic）。注意它会让同一位置的编码随序列长度变化，与KV缓存配合时需要小心（见KV缓存）。

YaRN。YaRN按维度的波长分三段：波长远小于上下文的高频维度不动，波长超过上下文的低频维度做完全插值，中间平滑过渡；再给注意力logits乘一个随s增长的温度系数修正熵的变化。用很少的微调数据就能达到很好的长文本效果，被多种开源模型采用。LongRoPE进一步用搜索为每个维度找最优的缩放因子。

直接调大基频。另一种常见做法是在长文本继续预训练时把b从10000调大到50万甚至上百万，例如Code Llama把基频设为100万，Llama 2 Long长上下文续训也采用了调大基频的方案（见继续预训练）。

怎么评价。困惑度在长文本上不再上升只是必要条件；还要看“大海捞针”类检索和真实长文档任务的表现（见长上下文评测），很多方法在困惑度上看起来很好，实际却用不上远处的信息。

例子

LLaMA风格模型：d = 128，训练长度4096，想扩到16384（s = 4）。

  • 位置插值：位置10000编码为10000/4 = 2500，在训练范围之内。
  • NTK感知：新基频b' = 10000 × 4^(128/126) ≈ 10000 × 4.09 ≈ 40900。最高频维度（i = 0）的θ仍是1，不受影响；最低频维度的波长被拉长约4倍。
  • 动态NTK：序列长度不超过4096时用原基频；长度到8192时按s = 2计算基频，到16384时按s = 4计算。

容易误解的地方

  • 免训练的方法通常只能把有效长度扩到原来的2到4倍左右；扩更多倍一般仍需要长文本微调。
  • 上下文窗口能“放下”多少token，与模型能否真正利用远处信息是两回事（见上下文窗口）。
