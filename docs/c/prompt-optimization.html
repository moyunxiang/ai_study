自动提示优化

Automatic Prompt Optimization

也叫：prompt optimization　提示优化　APO　automatic prompt engineering　自动提示工程　提示词优化　prompt tuning by LLM　prompt evolution　提示进化　MIPRO　GEPA　DSPy

在交互版中打开（看它长在树上的哪里）

让LLM自己根据试跑结果改写提示词，不改模型权重就提升系统表现。

提示词的细微差别会显著影响结果，手工调提示费时且不可复现。自动提示工程APE最早让LLM生成并筛选指令；OPRO以LLM为优化器把LLM当作优化器，根据历史提示和得分提出新提示；DSPy把LLM流水线写成声明式程序，由编译器自动优化各模块的提示和示例；GEPA反思式提示进化让LLM阅读完整轨迹和文字反馈来反思式改写提示，并在多个任务上以少得多的试跑次数超过GRPO。2025年的智能体上下文工程ACE把这一思路推广到不断积累、改写智能体的上下文手册。

这条线引出的争论是：对于很多下游适配任务，改提示是否比强化学习改权重更划算；以及它学到的东西能否迁移到别的模型。
