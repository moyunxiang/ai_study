on-policy与off-policy

On-policy vs Off-policy

也叫：在策略　离策略　同策略　异策略　经验回放

在交互版中打开（看它长在树上的哪里）

on-policy方法只用当前策略自己刚产生的数据来学；off-policy方法可以用别的策略（旧版本、人类、随机探索）产生的数据来学一个不同的目标策略。

先要会：策略与价值函数 时序差分与自举 重要性采样

强化学习里有两个策略可能不同：行为策略μ（实际与环境交互、产生数据的那个）和目标策略π（我们想评估或改进的那个）。两者相同就是on-policy，不同就是off-policy。

为什么会不同。为了探索与利用，行为策略常带随机性（比如ε-贪心），而我们真正想要的是不乱试的最优策略。另外，数据很贵：机器人摔一次就要人扶起来，最好能把过去的经验反复利用，而过去的数据是旧策略产生的。

最清楚的对比：SARSA与Q-learning。两者都用时序差分与自举更新Q值，区别只在目标里下一步用哪个动作：

  • SARSA（on-policy）：r + γ·Q(s', a')，a'是行为策略实际选的下一个动作，包括探索时的乱选。学到的是“带着探索行动”的价值。
  • Q-learning（off-policy）：r + γ·max_{a'} Q(s', a')，不管实际选了什么，都按“下一步会选最好的”来算。学到的是最优策略的价值。

off-policy的修正。要用μ的数据估计π下的期望，常用重要性采样，给每个样本乘上权重π(a|s) / μ(a|s)。两个策略差太远时权重会极大或极小，方差爆炸。

它在哪里。DQN通过经验回放把旧数据存起来反复抽样训练，这必须是off-policy算法。SAC也是off-policy，样本效率高。PPO基本是on-policy：每轮用当前策略采一批数据，更新几次就丢掉，靠限制新旧策略的差距来容许少量“过期”。RLHF训练大语言模型多用PPO或GRPO这类on-policy方法。数据完全固定、不再交互的极端情形是离线强化学习。

例子

智能体在s'处，Q(s', 左)=2，Q(s', 右)=8。这一步得到r=1，γ=0.9，而ε-贪心在s'恰好随机选了“左”。

  • SARSA的目标：1 + 0.9×Q(s', 左) = 1 + 1.8 = 2.8
  • Q-learning的目标：1 + 0.9×max(2, 8) = 1 + 7.2 = 8.2

同一条数据，两种方法给出的目标差了很多。SARSA会因为“探索时可能走错”而认为前一个状态价值较低，学出更保守的路线（经典例子是悬崖边行走时离悬崖远一点）。

重要性权重的例子：目标策略选这个动作的概率0.9，行为策略是0.5，则该样本权重0.9/0.5 = 1.8。

容易误解的地方

  • “off-policy”不等于“离线”：off-policy算法通常仍在持续与环境交互，只是能复用别的策略产生的数据。
  • PPO在一批数据上更新多次，严格说已带一点off-policy，所以要用重要性比率并加裁剪。
  • off-policy样本效率高，但稳定性一般更差，与函数近似、自举结合时可能发散。
