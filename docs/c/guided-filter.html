引导滤波与保边平滑

Guided Filter and Edge-Preserving Smoothing

也叫：引导滤波　导向滤波　guided filter　guided image filtering　保边滤波　保边平滑　edge-preserving filter　edge-preserving smoothing　双边滤波　bilateral filter　盒式滤波　box filter　fast guided filter　可导引导滤波　透射率细化

保边平滑滤波器：借助一张引导图，假设输出在每个小窗口内是引导图的线性函数，平滑时就跟着引导图的边缘走。速度与窗口大小无关，常用于去雾、抠图边缘细化和细节增强。

先要会：线性回归 卷积运算

普通的高斯模糊会把边缘一起抹掉。保边滤波希望在平坦区域平滑、在边缘处保持锐利。双边滤波按空间距离和颜色差共同加权，是早期的代表，但计算慢，还会在边缘附近产生梯度反转伪影。何恺明等人2010年提出的引导滤波给出了一个又快又稳的方案。

模型。输入图像p（要滤波的），引导图I（可以就是p本身，也可以是另一张图，比如原彩色图）。假设在以像素k为中心的每个小窗口ω_k里，输出q是引导图的线性变换：

q_i = a_k · I_i + b_k，i ∈ ω_k

因为∇q = a·∇I，引导图有边缘的地方输出也有边缘，平坦的地方输出也平坦。系数通过让q尽量接近p、并对a加一点正则化与权重衰减来求，是一个窗口内的线性回归（岭回归）：

a_k = cov_k(I, p) / (var_k(I) + ε)，b_k = mean_k(p) − a_k·mean_k(I)

每个像素属于多个窗口，最后把这些窗口给出的a、b取平均再计算q。

ε的作用。窗口内引导图方差远大于ε（有边缘），a ≈ 1，输出跟随引导图，边缘保留；方差远小于ε（平坦区域），a ≈ 0，输出约等于窗口均值，即被平滑。ε就是“多大的起伏算边缘”的阈值。

为什么快。所有量（均值、方差、协方差）都可以用盒式滤波计算，借助积分图，每个像素的代价是O(1)，与窗口半径无关，百万像素的图像在CPU上也能很快处理。

它出现在哪里。

  • 去雾：暗通道先验去雾暗通道先验去雾先得到粗糙的透射率图，原方法用耗时的软抠图来细化；引导滤波以原图为引导，快速把透射率图的边缘对齐到物体边缘，大幅提速。
  • 抠图与分割细化：用原图引导，把粗糙的掩码或深度图边缘修整得贴合物体轮廓；深度学习中也有把可导的引导滤波层接在网络末端、对低分辨率输出做上采样细化的做法（见上采样与转置卷积）。
  • 细节增强与HDR色调映射：把图像分解为平滑的“基础层”和“细节层”，放大细节层再合成。
  • 也用于低光增强中估计平滑的光照图（见Retinex理论与低光照增强）。

例子

引导图I就是待滤波图p，窗口半径r = 2，ε = 0.01（像素值在0到1之间）。

  • 平坦但有噪声的区域：窗口内方差约0.001，远小于ε，a ≈ 0.001/0.011 ≈ 0.09，输出几乎就是窗口均值，噪声被抹平。
  • 跨越明暗边界的窗口：方差约0.2，a ≈ 0.2/0.21 ≈ 0.95，输出几乎等于原值，边缘保留。

容易误解的地方

  • 引导图里有而输入里没有的结构（例如引导图的纹理）可能被“转移”到输出上，选择引导图时要注意。
  • ε太大时，较弱的真实边缘也会被平滑掉；在非常细的结构附近仍可能出现轻微光晕。
