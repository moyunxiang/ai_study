Vision Transformer为什么重要

卷积网络在图像上领先了将近十年，它的结构里写死了“只看邻近像素”“每个位置用同一个检测器”这样的假设。2020年的ViT把这些假设几乎全部拿掉，直接用一个为语言设计的Transformer看图。拿掉之后缺的东西靠什么补回来？为什么值得这么做？

任何模型都要在两件事之间取舍：把关于数据的假设事先写进结构，还是让模型自己从数据里学。写进结构的假设叫归纳偏置（见归纳偏置）。假设对了，模型用很少的数据就能学好；代价是模型只能在这些假设划定的范围里学。

图像上最成功的一组假设来自卷积（见卷积层、池化与感受野）。一个卷积核是一个很小的权重窗口，比如5×5，它在图上逐个位置滑动，每到一处只看这一小块邻域；所有位置共用同一组权重；每隔几层再把图缩小一半。这三条分别对应局部性（相关的像素挨在一起）、平移等变（猫出现在左上角还是右下角，用同一套检测器去找）和层级结构（先看笔画和纹理，再看部件，再看整体）。

这条线要讲的，就是这组假设怎样被写进网络、被放大、被保留了近十年，又怎样在2020年被拿掉，以及拿掉之后研究者用了哪些办法把缺的东西补回来。

  1. 1998

    把局部、共享、逐层缩小写进网络结构

    LeNet与卷积网络 · Gradient-Based Learning Applied to Document Recognition来源已核对

    起点的问题是：1990年代的手写识别靠人设计特征，换一个任务就得重想。LeNet-5让网络直接读32×32的像素：卷积层的每个单元只连5×5的邻域，同一张特征图在所有位置共用一组权重，下采样层把图的边长减半，让网络不在乎小的平移。论文写明，这套“卷积+下采样”受视觉皮层简单细胞、复杂细胞的启发。权重共享让全网约34.5万个连接只需约6万个参数，MNIST上错误率0.95%。但它只在小的黑白数字上验证过，彩色、杂乱的自然图像需要大得多的网络、数据和算力。

  2. 2012

    同样的假设，放大到百万张图和六千万参数

    AlexNet · ImageNet Classification with Deep Convolutional Neural Networks来源已核对

    上一站的结构没有问题，缺的是规模。AlexNet在ImageNet的约120万张标注图上训练一个5层卷积加3层全连接、约6000万参数的网络，用ReLU加快训练，用Dropout和数据增强抑制过拟合，在两块GPU上训了5–6天，ILSVRC-2012的top-5错误率15.3%，第二名26.2%。论文引言把卷积的长处说得很直接：它对图像做了“强而大体正确的假设”，图像统计在各处相同、像素之间的依赖是局部的，所以参数少、容易训练。但网络再加深就难以训练。

  3. 2015

    残差连接让网络可以继续加深

    ResNet · Deep Residual Learning for Image Recognition来源已核对

    上一站之后，VGG把深度推到19层；再往上加，连训练误差都变大。ResNet指出这不是过拟合，而是深网络本身难优化。它让每几层只学“在输入的基础上改多少”，输出写成F(x) + x（见残差连接），多出来的层最差也能退化成什么都不做。152层的网络集成在ImageNet测试集上top-5错误率3.57%。这个加法后来也被Transformer的每个子层采用。但卷积每层只看局部邻域，相隔很远的像素要经过很多层才能交换信息；之后的Non-local网络等工作开始把自注意力当插件加进卷积网络。

  4. 2017

    语言那边换了骨架：每个词直接看所有词

    Transformer · Attention Is All You Need来源已核对

    上一站留下的是视野局部的问题。同一时期，翻译模型Transformer去掉了循环和卷积，只用自注意力（见自注意力与多头注意力）：每个词的查询向量和所有词的键向量做内积，经softmax变成权重，再对所有词的值向量加权求和，一层之内任意两个位置就能交换信息。每个子层外面包着残差连接（论文引用了ResNet）和LayerNorm。它对输入只要求是一串向量，顺序靠另加的位置编码告诉它。之后BERT和GPT都以它为骨架。但自注意力的计算量随序列长度平方增长，一张224×224的图有约5万个像素，不能直接当成5万个词。

  5. 2020

    把图切成16×16的块当词，几乎拿掉所有图像假设

    Vision Transformer · An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale来源已核对

    上一站的Transformer不认识图像。ViT把224×224的图切成196个16×16像素的块，每块展平后乘同一个矩阵变成一个向量，加上可学习的位置编码和一个[class] token，送进几乎不改的Transformer编码器（见图像块与视觉token）。论文的说法是：CNN每层都内置局部性、二维邻域和平移等变，ViT只有逐块计算的MLP是局部的，自注意力是全局的，块与块的空间关系要从数据里学。代价是数据：只用ImageNet时ViT-B/16为77.9%，不如同等大小的ResNet；在3亿张的JFT-300M上预训练后，ViT-H/14达到88.55%，与最强的卷积网络相当，预训练算力更少。但JFT是Google的内部数据。

  6. 2020

    不加数据，靠训练配方和卷积老师补

    DeiT · Training data-efficient image transformers & distillation through attention来源已核对

    上一站的ViT离不开3亿张内部图片。DeiT的结构与ViT-B完全相同，只用ImageNet-1k，靠一长串数据增强和正则化（RandAugment、Mixup、CutMix、随机深度、重复增强等）训练300轮，单台8卡机器预训练约53小时，准确率81.8%，384分辨率微调后83.1%。它还在序列里加了一个蒸馏token（见知识蒸馏），让ViT去拟合卷积网络RegNetY的预测，最高85.2%。卷积老师比Transformer老师效果更好，作者推测学生借此继承了卷积的归纳偏置。但它仍要靠ImageNet的人工类别标签。

  7. 2021

    换一种监督：网上的图片和配文

    CLIP · Learning Transferable Visual Models From Natural Language Supervision来源已核对

    上一站仍要有人给每张图标一个类别。CLIP从网上收集4亿对“图片+配文”，图像编码器和文本编码器各输出一个向量，训练目标只是在一批图文里认出哪张图配哪段文字（见对比学习）。图像编码器试了ResNet和ViT，最强的是ViT-L/14，同等算力下ViT更高效；文本编码器是GPT-2式的Transformer。图和文于是由同一类网络编码进同一个向量空间，不用ImageNet的任何训练样本，零样本准确率76.2%，追平用128万张标注图训练的ResNet-50。但ViT只输出一种分辨率的特征，检测和分割用起来不方便。

  8. 2021

    把层级和局部窗口加回来，做检测和分割

    Swin Transformer · Swin Transformer: Hierarchical Vision Transformer using Shifted Windows来源已核对

    上一站的问题ViT论文自己也写了：它只有一种分辨率的特征图，全局注意力的计算量随块数平方增长，检测、分割需要的高分辨率、多尺度特征给不了。Swin把图切成更细的4×4块，只在7×7块的窗口内做注意力，相邻两层把窗口错开，让信息跨窗口流动；每个阶段开头合并相邻的块，形成像卷积网络那样逐级缩小的特征图，计算量随图像面积线性增长。COCO检测比此前最好的结果高2.7 box AP。后来的ConvNeXt把这总结为层级Transformer重新引入了若干卷积先验。另一条路是不改结构，改预训练方式。

  9. 2021

    遮住75%的块，让ViT从图像本身学

    掩码自编码器MAE · Masked Autoencoders Are Scalable Vision Learners来源已核对

    上一站之前的路线都还依赖标签或配文。ViT论文试过BERT式的掩码块预测，比有监督预训练低4%。MAE把遮挡率提到75%（见掩码建模）：图像在空间上高度冗余，遮得少，模型靠相邻像素插值就能补上。编码器只处理剩下25%的可见块，一个小解码器补全被遮块的像素，训练FLOPs降为原来的1/3.3。只用ImageNet-1k、不用标签，ViT-H达到87.8%；迁移到COCO检测，ViT-L比有监督预训练高4.0 box AP。只编码可见块，靠的正是ViT能接受任意长度的token序列。但它的冻结特征不好用，要整体微调才能发挥。

  10. 2023

    不要标签、不用微调的通用视觉特征

    DINOv2 · DINOv2: Learning Robust Visual Features without Supervision来源已核对

    上一站的MAE特征要微调，冻结后线性评估ViT-H/14只有76.6%。DINOv2用自蒸馏（见自监督学习）：学生网络在不同裁剪和被遮住的块上去逼近教师网络的输出，教师是学生参数的滑动平均。它先用检索从12亿张网络图片里自动整理出1.42亿张多样、均衡的图，再训练约11亿参数的ViT-g。冻结特征加一个线性层，ImageNet准确率86.5%，略高于用图文对训练的OpenCLIP的86.2%，分割和深度估计的伪影也更少。消融显示，用同样数量但未经整理的网络图片训练，多数基准都更差：除了数据多少，数据的构成也要紧。

现在走到哪了

走到2023年，ViT拿掉的归纳偏置被四种办法补了回来：更多的数据（JFT-300M、4亿对网上图文、1.42亿张整理过的图）、更好的训练配方和卷积老师（DeiT）、把层级和局部窗口加回结构（Swin），以及让模型从图像本身学的自监督（MAE、DINOv2）。补法各不相同，骨架基本还是同一个Transformer编码器。

这就是它重要的地方：对Transformer来说，图像块和文字token都只是一串向量。CLIP用两个Transformer把图和文编码进同一个空间；许多视觉语言模型（如LLaVA）把CLIP或SigLIP的ViT接在语言模型前面当视觉编码器；Segment Anything的图像编码器是MAE预训练的ViT-H；Diffusion Transformer把扩散模型的去噪网络也换成了切块的Transformer。视觉和语言因此可以共用同一套层结构、同一套训练和推理工具。

接着可以读专题“从纯文本到多模态”，看图像向量怎样接进语言模型；读“Transformer为什么出现”，补上自注意力的来历；想看卷积一侧的回应，读ConvNeXt。

这条线简化了什么

这条线是按“拿掉了什么、怎样补回来”事后归纳的，不是当事人的说法。DeiT、CLIP、Swin、MAE、DINOv2各有自己的出发点，并不都是为了回应ViT：CLIP的动机是摆脱固定类别标签，图像编码器同时试了ResNet和ViT；MAE的直接对手是BEiT和对比学习；DINOv2要解决的是自监督换到网络数据后特征变差。

“数据量补回归纳偏置”是ViT论文自己的说法（“大规模训练胜过归纳偏置”），但DeiT显示，原版ViT只用ImageNet时表现差，有相当一部分来自训练配方；“学生通过蒸馏继承了卷积的归纳偏置”也只是DeiT作者的推测。ViT胜出还离不开TPU算力和Google的内部数据，不能只归给“去掉卷积”这一个改动。

卷积网络并没有被淘汰：2022年的ConvNeXt按Transformer的设计改造ResNet，ImageNet精度与Swin相当，检测和分割上还更好；Swin的优势有多少来自注意力、多少来自重新加回的卷积式先验，仍有不同看法。“视觉和语言共用一套架构”指的是编码器的层结构相同，切块方式、位置编码和训练目标仍各不相同。LLaVA、DiT两处的事实取自这两个节点已有的讲解，节点本身不是本次核对的对象。
