同一份内容，换着摆

这些是还在挑选的设计原型，读的是线上现版同一份数据。原型每套都能看节点讲解、概念、分支、年代、路线和搜索；笔记、对比、统计这些功能原型里还没有（换颜色和换风格的两组就是现版本身，功能是全的）。

第一组是线上现版原样不动、只换颜色：版式、字体都一样，深色和浅色都有。中间两组是结构完全不同的设计：页面怎么分、图怎么画、怎么点进去都各不一样。最后一组是现版不动结构、换一整套样式（字体、边框、版式都变）。

进到任何一套里，页面底部有一条切换条，可以直接换到上一套、下一套或者挑一套；在某个节点上切换，会带着同一个节点过去。

明暗：弧线、气泡、谱系、手册、分栏跟随系统；星图和长卷只有深色；年轮、地铁、大树、河流只有浅色。换颜色的几套和现版一样，深色、浅色、跟随系统都有，在右上角“更多”里切换，缩略图是深色的样子；换风格的八套各自只有一种明暗（终端和图纸是深色）。在手机上能用，但没有逐一在真机上调过。
