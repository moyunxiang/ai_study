XLM-R

Unsupervised Cross-lingual Representation Learning at Scale
2019.11论文重要ACL 2020Conneau, Khandelwal, Goyal, Chaudhary, Wenzek, Guzmán, Grave, Ott et al. · Facebook AI待核对
arXiv ↗代码与模型（fairseq） ↗在交互版中打开（演化树、学习进度）

问题

多语言BERT和XLM只在维基百科上训练，斯瓦希里语、乌尔都语这类小语种的语料少得可怜；而且一个模型塞进越多语言，每种语言的效果就越差。

方法

用CCNet流程从Common Crawl清洗出100种语言、约2.5TB的语料，照RoBERTa的配方训练一个只做掩码预测的大模型，并系统测量语言数、模型容量、词表与采样比例之间的取舍。

影响

XNLI跨语言迁移平均准确率比多语言BERT高14.6个点，英文GLUE接近单语RoBERTa，第一次说明多语言模型可以不牺牲单语性能，成为此后几年跨语言任务的默认底座。

背景

让一个模型同时懂很多语言，最诱人的用法是零样本跨语言迁移：只用英文标注数据微调，直接在法语、斯瓦希里语上测试。2019年的两个代表是多语言BERT（mBERT，BERT团队用104种语言的维基百科训练）和跨语言预训练XLM（加入了需要平行语料的翻译语言建模）。

它们都受限于维基百科：大语种有几百万篇文章，小语种只有几千篇。同期RoBERTa已经证明，对单语BERT来说，更多数据、更大批量、更长训练能带来大幅提升——多语言模型还没人这样做过。

方法

数据：CC-100。沿用同组的CCNet流程：用fastText等语言识别模型给Common Crawl网页分语种，再用每种语言自己的语言模型打分，过滤掉不像正常文本的文档。英语取1份Common Crawl快照，其他语言取12份，以便给小语种多攒数据。最终100种语言共约2.5TB，小语种的数据量比维基百科多出几个数量级。

模型与训练。只用多语言掩码语言建模（见掩码建模），不需要任何平行语料；不加“语言编号”嵌入，便于处理一句话里混用多种语言的情况。SentencePiece直接在原始文本上切出25万个子词的共享词表。大模型24层、隐藏维1024、5.5亿参数，在500块V100上训练150万步、批大小8192。

语言采样。按语料量直接采样会让英语占绝大多数。设语言i占总语料比例为p_i，实际按q_i = p_i^α / Σ_j p_j^α采样，α取0.3：α越小，分布越平，小语种被看到得越多。

多语言的诅咒。作者固定模型大小、逐步增加语言数：从7种加到15种时小语种因“正迁移”变好；再往上所有语言一起变差，XNLI平均从71.8%（7种）降到67.7%（100种）。加大模型容量可以缓解，这是最终模型做大、词表做大的原因。

结果

XNLI（15种语言的自然语言推理）只用英文数据微调时，XLM-R平均80.9%，mBERT为66.3%，此前的XLM-100为70.7%；斯瓦希里语从XLM的58.2%升到73.9%。用全部语种的翻译训练集微调时平均83.6%。摘要还报告MLQA问答F1比mBERT高13个点、NER高2.4个点。英文GLUE开发集平均91.8，与RoBERTa的92.8、XLNet的92.0相差不大。

后来的发展

XLM-R很快成为跨语言理解的标准基线，XTREME跨语言基准等多语言评测都拿它作主要对照。“按p^α平滑采样语言”和“多语言的诅咒”这两个概念被后来的多语言模型普遍沿用：mT5把同样的思路搬到可以生成文本的编码器-解码器上，BLOOM、NLLB两百种语言翻译则把语种覆盖和小语种数据当作核心问题。

容易误解的地方

  • “无监督”指预训练不需要平行语料或任何标注，不是说下游任务不需要标注——跨语言迁移仍要一份英文标注集。
  • 25万词表的嵌入层本身就占了相当一部分参数，参数量不能直接和同尺寸的单语模型比较。

局限与后续

  • 多语言的诅咒没有根除：容量固定时语言越多，每种语言越差，只能靠不断加大模型来缓解。

它建立在什么之上

  • 使用
    RoBERTa2019.07 · LLM 已核对
    照搬RoBERTa的训练配方（大批量、长训练、只做掩码预测），把它从英语推广到100种语言。
  • 改进
    BERT2018.10 · LLM
    解决多语言BERT受限于维基百科数据、小语种效果差的问题，XNLI跨语言迁移平均高14.6个点。
  • 改进
    神经命名实体识别2016.03 · NLP
    每种语言都要单独标注数据、单独训练，没有跨语言共享。
  • 延续
    多语言NMT与零样本翻译2016.11 · NLP
    谷歌多语言翻译证明一个模型可以共享多种语言并实现零样本迁移；本文把“一个模型管所有语言”的思路用到无监督预训练上，并量化了语言数与容量的取舍。
  • 改进
    双仿射依存分析2016.11 · NLP
    编码器从零开始在一个树库上训练，只用静态预训练词向量，低资源语言的树库很小，精度明显下降。
  • 使用
    SentencePiece2018.08 · NLP
    直接在原始文本上训练25万子词的共享词表，省去各语言单独的预分词。
  • 改进
    XNLI2018.09 · 数据·评测
    任务只是句子对分类，不能代表多语言的生成与长文本能力。
  • 延续
    跨语言预训练XLM2019.01 · LLM
    继承XLM的多语言掩码建模和语言采样方法，但去掉需要平行语料的翻译目标和语言嵌入，把数据和模型做大。
  • 使用
    CCNet2019.11 · 数据·评测
    用CCNet的语言识别加语言模型过滤流程，从Common Crawl构建CC-100语料。

后来的相关工作

  • 改进
    NLLB两百种语言翻译2022.07 · NLP
    100种语言之外的上千种语言仍几乎没有数据，网页语言识别对小语种也不可靠。
  • 使用
    XTREME跨语言基准2020.03 · 数据·评测

  • 竞争
    mT52020.10 · LLM
    XLM-R是多语言的编码器式模型，擅长理解；mT5保留编码器-解码器，可以直接生成。
  • 改进
    M2M-100非英语中心翻译2020.10 · NLP
    只有编码器，只能做分类、标注、抽取，不能直接生成文本或翻译。
  • 竞争
    DeBERTaV32021.11 · LLM
    多语言版mDeBERTa在XNLI零样本跨语言上比XLM-R Base高3.6个点。

读懂它需要的概念

掩码建模 预训练与微调 迁移学习 分词与token 零样本与少样本 参数量、计算量与显存

本篇术语

  • 零样本跨语言迁移　只用一种语言（通常是英语）的标注数据微调，直接在其他语言上测试，其他语言一条标注都不看。
  • 多语言的诅咒　模型大小固定时，加入的语言越多，分到每种语言的容量越少，超过某个点后所有语言的效果一起下降。
  • XNLI　把英文自然语言推理数据的测试集人工翻译成15种语言的评测集，用来测跨语言理解。

怎么学

先读懂RoBERTa和掩码建模。读原文第3节（数据与模型）和第5.1节（多语言的诅咒、采样比例、词表大小的实验图）。动手：用Hugging Face加载xlm-roberta-base，只用英文情感数据微调，再直接测几句中文、西班牙文，体会零样本跨语言迁移；然后算一算α=1、0.7、0.3时英语和斯瓦希里语的采样比例。
