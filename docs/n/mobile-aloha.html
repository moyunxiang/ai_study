Mobile ALOHA

Mobile ALOHA: Learning Bimanual Mobile Manipulation with Low-Cost Whole-Body Teleoperation
2024.01论文延伸Fu, Zhao, Finn · Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

桌面双臂模仿学习缺乏移动性，做不了开柜门、进电梯等需要全身协调的家务。

方法

给ALOHA加上移动底盘和全身遥操作接口，采集示范后与静态ALOHA数据联合训练行为克隆。

影响

用每个任务50条示范，联合训练最多提升90%的成功率，让低成本系统完成炒虾、开柜门等复杂任务。

方法

Mobile ALOHA把ALOHA与ACT的双臂系统装到轮式底盘上，操作员把身体系在平台上，一边推着走，一边用主从臂遥操作双臂，同时记录底盘速度和双臂关节，得到全身示范。

训练用监督式行为克隆，关键发现是与原有静态ALOHA数据集联合训练（co-training）能显著提高成功率。摘要称每个任务只需50条示范，联合训练最多提升90%，并完成了炒虾后装盘、打开双门壁柜存放锅具等任务。

后来的发展

成为家务机器人研究的标志性演示，开源硬件也推动了HumanPlus、Open-TeleVision等人形遥操作方案的出现。
