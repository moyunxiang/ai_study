OpenAI转型与微软10亿美元投资

2019.07事件延伸Sam Altman、Satya Nadella · OpenAI / Microsoft待核对
OpenAI公告 ↗在交互版中打开（演化树、学习进度）

问题

训练前沿模型需要极昂贵的算力，而OpenAI最初的非营利结构很难筹到这么多资金。

方法

2019年OpenAI设立受限盈利的子公司，7月22日微软宣布向其投资10亿美元，并成为主要云合作伙伴，共同开发Azure上的AI超算。

影响

这笔投资为GPT-3和之后的大模型提供了算力，也把OpenAI绑定到微软生态，成为AI行业最重要的商业联盟。

方法

据OpenAI和主流媒体2019年7月22日的报道，微软向OpenAI投资10亿美元，并建立多年期的合作，OpenAI使用Azure训练模型。OpenAI在同年早些时候设立「受限盈利」结构，投资者回报有上限，剩余价值归非营利母体，用来解释为什么商业化与使命不冲突。

这一步是对马斯克离开OpenAI之后资金缺口的回应。此后微软在2023年1月宣布追加数十亿美元投资（微软追加投资与新Bing），双方关系在2025年的重组中再次调整（OpenAI重组为公益公司）。

后来的发展

合作让微软在ChatGPT发布发布后第一时间把GPT接入Bing和Office，也让谷歌感到压力（谷歌“红色警报”与Bard）。受限盈利结构则在2023年的OpenAI董事会风波风波和2025年的重组中成为焦点。

局限与后续

  • 非营利使命与商业利益共存的结构在治理上很脆弱，之后引发董事会风波和重组。
