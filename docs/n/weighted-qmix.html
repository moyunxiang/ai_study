Weighted QMIX加权分解

Weighted QMIX: Expanding Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning
2020.06论文延伸NeurIPS 2020Tabish Rashid, Gregory Farquhar, Bei Peng, Shimon Whiteson · 牛津大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

QMIX值分解只能表示对个体Q值单调的团队Q值；当一个智能体的最优动作取决于队友选什么时，它学出的分散策略可能连最优解都找不到，即使给它真实的最优Q值也不行。

方法

把QMIX看成“先算Q学习目标、再投影到单调函数空间”的算子，指出问题出在投影时所有联合动作等权；改成加权投影，把更大权重放在更好的联合动作上，证明这样能恢复正确的最优动作。

影响

用算子与投影的视角解释了单调值分解到底在优化什么、为什么会失败，并给出可扩展的修正（CW-QMIX、OW-QMIX），是理解值分解表示能力的常被引用的分析。

背景

QMIX值分解用一个非负权重的混合网络把各智能体的 Q_i 合成团队的 Q_tot，单调性保证了各自取argmax就是联合argmax，所以能分散执行，在星际多智能体挑战SMAC上效果很好。但单调性也限制了能表示的函数：如果“我该走左还是右”取决于队友怎么走，单调混合就表示不出来。QTRAN变换分解试图用更宽的约束绕开这一点，但在复杂任务上不稳定。问题是：QMIX失败时到底错在哪里，能不能在保留单调结构的前提下修好？

方法

作者把QMIX的一次更新写成 Q_tot ← Π_qmix 𝒯* Q：𝒯* 是普通的Bellman最优算子，Π_qmix 是投影——在所有单调可表示的函数里找一个使 Σ_u w(s,u)·(y(s,u) − Q_tot(s,u))² 最小的，其中y是目标值。原始QMIX相当于 w ≡ 1：所有联合动作同等重要。在表格情形他们证明，这种等权投影可能把最优联合动作的值压低到别的动作之下，因而即使目标是真正的 Q* 也恢复不出最优策略。

修正办法是加权：对“看起来更好”的联合动作权重为1，其余取一个小常数 α∈(0,1]。两种具体方案：中心加权（CW）——当联合动作是当前贪心动作、或其目标值高于贪心动作的估计值时权重为1；乐观加权（OW）——当 Q_tot 低估了目标值时权重为1。作者证明两种加权都能恢复正确的最大值动作。为计算目标值，另外学一个不受单调约束的联合Q估计 Q̂*，它只在训练中使用。

结果

摘要称，在捕食者-猎物和星际多智能体任务上，CW-QMIX与OW-QMIX比QMIX表现更好。

后来的发展

与QTRAN变换分解、QPLEX对偶值分解一起构成了“值分解能表示什么、该怎么扩展”的讨论；此后MAPPO等工作指出，在实践中网络结构、超参数和实现细节同样会左右这些方法的排名。

本篇术语

  • 投影　在一个受限的函数集合里，找离目标函数最近（按某种加权误差）的那个函数；函数近似下的Q学习每一步都在做这样的近似。

怎么学

先读QMIX值分解；用一个3×3的合作矩阵博弈，手算等权最小二乘拟合单调函数后的argmax，再改成加权拟合对比；然后读原文第4节的算子分析。
