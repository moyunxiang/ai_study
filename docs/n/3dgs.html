3D高斯泼溅

3D Gaussian Splatting for Real-Time Radiance Field Rendering
2023.08论文重要SIGGRAPH 2023（ACM Transactions on Graphics）Bernhard Kerbl, Georgios Kopanas, Thomas Leimkühler, George Drettakis · Inria / Université Côte d’Azur / Max-Planck-Institut für Informatik待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

NeRF类方法画质最好的要训练48小时、渲染一帧十几秒；快的方法（Instant-NGP、Plenoxels）画质又差一截。没有任何方法能在1080p下实时渲染完整的大场景。

方法

不再用神经网络表示场景，而是用几百万个可优化的三维高斯椭球，每个带位置、形状、不透明度和随视角变化的颜色；渲染时把它们投影到屏幕上排序后按透明度叠加，像游戏引擎的光栅化一样快。

影响

1080p下每秒100帧以上，画质与最好的Mip-NeRF360相当，训练只要几十分钟；高斯泼溅迅速取代NeRF成为新视角合成和三维重建的主流表示，并扩展到动态场景、数字人、3D生成和机器人。

背景

NeRF用MLP加体渲染（见体渲染）做新视角合成，每个像素都要沿光线采样上百个点查询网络，所以慢。Instant-NGP用哈希网格把训练压到几分钟，但在大型无边界场景上画质不如Mip-NeRF360，而后者训练要48小时，渲染每秒不到0.1帧。

另一条路线是点云渲染：把COLMAP等运动恢复结构（SfM）算出的三维点直接“泼”（splat）到屏幕上。点渲染非常快，但点是离散的，会留下空洞，依赖多视图立体重建的稠密几何，质量受其误差拖累。论文要同时得到NeRF的画质和光栅化的速度。

方法

表示。场景是一组三维高斯，每个高斯有：中心位置μ；协方差Σ（决定椭球的大小、朝向和扁长程度）；不透明度α；一组球谐系数（表示从不同方向看颜色不同，用来表现高光）。为了让梯度下降始终得到合法的协方差矩阵，把它分解成缩放和旋转：

Σ = R·S·Sᵀ·Rᵀ

分别优化一个三维缩放向量和一个四元数。初始化直接用COLMAP标定相机时顺带得到的稀疏点。

渲染。把每个三维高斯投影成屏幕上的二维高斯；屏幕切成16×16像素的图块，每个高斯按覆盖的图块复制，以“图块编号+深度”为键用一次GPU基数排序。之后每个图块并行地从前往后叠加：

C = Σᵢ cᵢ·αᵢ·Π_{j<i}(1 − αⱼ)

这与NeRF体渲染的离散公式形式相同，但不再沿光线采样，而是直接遍历排好序的高斯。整个过程可微，并手写了反向传播。

优化与自适应增删。损失是渲染图与照片的L1误差加D-SSIM。每100步检查一次：位置梯度大的地方说明重建不足——小高斯就复制一个，大高斯就分裂成两个更小的；几乎透明的高斯删掉；每3000步把不透明度重置到接近0，让多余的高斯自然被淘汰。一个场景最终有数百万个高斯。

结果

在Mip-NeRF360数据集上，训练3万步（约41分钟）PSNR 27.21，接近Mip-NeRF360的27.69（后者训练48小时），渲染速度每秒134帧，后者为0.06帧；训练7000步（约6分钟）时PSNR 25.60，已与Instant-NGP大模型的25.59相当，而渲染速度是它的十几倍。Tanks&Temples和Deep Blending上PSNR分别为23.14和29.41，帧率都在130以上，均在单块A6000上测得。代价是存储：一个场景734MB，而Instant-NGP只需48MB，Mip-NeRF360只需8.6MB。

后来的发展

高斯泼溅一年内衍生出大量工作：4D高斯泼溅加入时间维处理动态场景；2D高斯泼溅把椭球压扁成面片以得到准确的表面；pixelSplat前馈高斯从两张图前馈直接预测高斯，不再逐场景优化；TRELLIS结构化3D潜变量用高斯作为3D生成的输出表示之一；World Labs的World Labs Marble以它作为生成世界的载体。它也被用于SLAM、自动驾驶仿真和机器人的场景重建。NeRF的可微渲染思想保留了下来，但实际应用中的表示基本换成了高斯。

容易误解的地方

  • 3DGS没有任何神经网络，“训练”只是对几百万个高斯参数直接做梯度下降，所以它和NeRF一样是逐场景优化，不能泛化到新场景。
  • 排序只按每个高斯中心的深度进行，不做逐像素排序，混合顺序是近似的；作者认为在高斯缩到像素大小时误差可以忽略，但会造成偶发的“跳变”伪影。

局限与后续

  • 存储大：一个大场景需要数百MB，训练峰值显存可超过20GB，远大于NeRF类方法。

读懂它需要的概念

体渲染 相机模型与多视图几何 三维表示：体素、点云、网格、隐式场 高斯分布 协方差矩阵 梯度下降

本篇术语

  • 泼溅（splatting）　把三维图元投影成屏幕上的二维“斑点”并按透明度叠加的渲染方式，与光线采样相对。
  • 球谐函数　定义在球面上的一组正交基函数，用少量系数表示颜色随观察方向的变化。
  • 自适应密度控制　训练中按梯度大小复制或分裂高斯、删除透明高斯，让高斯数量和分布随场景细节自动调整。

怎么学

先读NeRF理解体渲染公式，补协方差矩阵。读原文第4节（高斯表示与协方差分解）、第5节（自适应增删，图4）、第6节（图块光栅化）。动手：用官方代码或gsplat库在Mip-NeRF360的一个场景上训练，分别在7000步和3万步时查看画质、帧率和高斯数量。
