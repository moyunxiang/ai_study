Conformer

Conformer: Convolution-augmented Transformer for Speech Recognition
2020.05论文主干Interspeech 2020Anmol Gulati, James Qin, Chung-Cheng Chiu, Niki Parmar, Yu Zhang, Jiahui Yu, Wei Han, Shibo Wang et al. · Google来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Transformer擅长捕捉整句的全局关系，却不擅长提取相邻几十毫秒内的细微声学模式；卷积网络正相反。语音识别两者都需要，当时只能二选一。

方法

在每个Transformer块里，自注意力之后插入一个深度可分离卷积模块，并把前馈层拆成两个“半步”前馈层夹在两头，形成“前馈—注意力—卷积—前馈”的三明治结构。

影响

LibriSpeech上不加语言模型2.1%/4.3%、加语言模型1.9%/3.9%，参数比此前最好的Transformer Transducer更少而效果更好；之后许多语音识别和自监督语音模型采用了Conformer编码器。

背景

2017年Transformer出现后，语音识别也开始用自注意力代替循环网络（Speech-Transformer）：自注意力让任意两帧一步可达，适合建模整句话的上下文，比如由后面的词推断前面一个含糊的音。但语音和文本不同，大量关键信息是局部的：一个辅音只有几十毫秒，共振峰在相邻帧之间的移动决定了是哪个音。自注意力对所有位置一视同仁，并不天然偏好近邻（见归纳偏置）。

另一条路线是纯卷积模型（如Jasper与QuartzNet和QuartzNet，以及同期的ContextNet），卷积天生擅长局部模式，但要看到整句全局信息就得堆很多层，或者加squeeze-and-excitation这类全局池化补丁。此时LibriSpeech上最好的几个系统（Transformer Transducer、ContextNet）都是RNN-Transducer式的Transducer，编码器用Transformer或卷积网络。问题自然是：能不能在一个块里同时拥有两者的长处？

方法

整体。输入80维滤波器组特征（25ms窗、10ms步长），先经卷积下采样，再堆16–17个Conformer块作为编码器；解码器是单层LSTM，用RNN-Transducer的Transducer损失训练。训练时用SpecAugment增强。

Conformer块。设块的输入为x，输出y：

x̃ = x + ½·FFN(x) x′ = x̃ + MHSA(x̃) x″ = x′ + Conv(x′) y = LayerNorm(x″ + ½·FFN(x″))

每个模块都用残差连接（见残差连接）。两个前馈层各只加一半的残差，这种“马卡龙”式的夹心结构来自Macaron-Net。

多头自注意力（见自注意力与多头注意力）沿用Transformer-XL的相对正弦位置编码，使模型对不同长度的输入更稳健；用pre-norm（先LayerNorm再进入模块）。

卷积模块。逐点卷积把通道翻倍，经GLU门控减半；然后是一维深度可分离卷积（每个通道单独卷积，核长32帧，见卷积层、池化与感受野），接Batch Normalization和Swish/SiLU激活，再一个逐点卷积。深度卷积负责“看左右各十几帧”的局部模式，参数很少。

规模。小、中、大三个模型分别为1030万、3070万、1.188亿参数，例如大模型17层、维度512、8个注意力头。

结果

LibriSpeech（960小时）test-clean/test-other词错误率：Conformer(L)不用语言模型2.1%/4.3%，加3层LSTM语言模型浅融合后1.9%/3.9%。对比：1.39亿参数的Transformer Transducer为2.4%/5.6%（无LM）；同期1.127亿参数的ContextNet(L)为2.1%/4.6%（无LM）。3070万参数的Conformer(M)已达到2.3%/5.0%，超过参数多4倍以上的Transformer Transducer；1030万参数的Conformer(S)在test-other上比同量级ContextNet(S)好0.7个百分点。

消融（无LM，test-other）：完整Conformer为4.3%；把Swish换成ReLU为4.5%；再去掉卷积模块升到4.9%；再把马卡龙双前馈改为单前馈5.0%；再去掉相对位置编码变成普通Transformer块为5.6%。卷积模块是贡献最大的部件；把卷积放到注意力之前，或与注意力并联，效果都更差；卷积核长32最好。

后来的发展

Conformer发表后被广泛采用：开源工具WeNet支持以Transformer或Conformer作共享编码器，ESPnet的编码器选项中也有Conformer；自监督模型w2v-BERT和谷歌的Google USM以Conformer为骨干；NVIDIA的Canary与Parakeet用的是它的变体FastConformer。后续变体主要在降低计算量（更激进的下采样）和流式化（限制注意力只看过去和少量未来）上做文章。

它的影响也有边界：Whisper用的是普通Transformer编码器，靠68万小时数据取得很强的鲁棒性。有人据此认为数据规模足够大时结构上的归纳偏置不再那么关键，但Whisper论文并没有与Conformer编码器做对照实验，这只是一种解读。

容易误解的地方

  • Conformer是一种编码器结构，不是完整的识别系统。论文里配的是Transducer解码器，换成CTC或注意力解码器同样可用。
  • 自注意力对长度仍是平方复杂度；一分钟以上的长音频要切段或配合局部注意力。
  • 论文的最好成绩依赖SpecAugment、变分噪声、外部语言模型等一整套训练配方，只换结构不一定能复现。

局限与后续

  • 全局自注意力需要看到整句，计算量随长度平方增长，直接用于边说边识别的流式场景要另行限制注意力范围。
    后来针对它的工作　WeNet
  • 仍是纯监督训练，960小时标注数据外的海量无标注语音用不上。
    后来针对它的工作　w2v-BERT Google USM
  • 只在LibriSpeech朗读英语上评测，对多语言、口音、噪声等真实场景的鲁棒性没有验证。
    后来针对它的工作　Google USM Whisper

它建立在什么之上

  • 使用
    RNN-Transducer2012.11 · 语音 已核对
    Conformer只是编码器，整个模型按Transducer方式训练，解码器是单层LSTM。
  • 延续
    Transformer2017.06 · LLM 已核对
    保留多头自注意力和残差结构，在块内插入卷积模块并改为马卡龙式双前馈，弥补自注意力缺乏局部归纳偏置的问题。
  • 使用
    SpecAugment2019.04 · 语音 已核对
    训练时使用SpecAugment（F=27、10个时间掩码），这是达到最好成绩的必要配方之一。
  • 使用
    Swish/SiLU2017.10 · 基础 已核对
    卷积和前馈模块用Swish激活，作者称它让训练收敛更快。
  • 改进
    Speech-Transformer2018.04 · 语音 已核对
    纯Transformer语音模型抓不住局部声学细节；同参数消融中，只去掉卷积模块就让test-other从4.5%升到4.9%，一路退回普通Transformer块则为5.6%（完整Conformer为4.3%，均无语言模型）。
  • 使用
    Transformer-XL2019.01 · LLM 已核对
    自注意力采用Transformer-XL的相对正弦位置编码，消融显示去掉它错误率明显上升。
  • 竞争
    Jasper与QuartzNet2019.04 · 语音 已核对
    Jasper/QuartzNet代表纯卷积路线，局部建模强但全局上下文弱；Conformer把两者合并，在同等参数下更准。
  • 改进
    深度网络声学模型2012.11 · 语音 待核对
    前馈网络只看一个固定的十几帧窗口，更长的上下文（音节、语速、说话人特征）完全看不到。
  • 使用
    MobileNet2017.04 · 视觉 待核对
    卷积模块用逐点卷积加深度卷积（即MobileNet推广的深度可分离卷积），以很少参数获得较长的局部感受野；论文本身没有引用MobileNet。
  • 改进
    深层双向LSTM识别2013.03 · 语音
    LSTM逐帧递归，长句训练无法在时间维度上并行，训练一个模型要上百轮。
  • 改进
    Deep Speech 22015.12 · 语音
    批归一化依赖批次统计，推理时单条流式语音难以直接使用，部署时要另做处理。
  • 改进
    大规模LSTM声学模型2014.02 · 语音
    训练和推理都是顺序计算，速度受限，难以像卷积和Transformer那样并行。
  • 改进
    Listen, Attend and Spell2015.08 · 语音
    论文发表时的词错误率仍落后于最好的混合系统（10.3%对8.0%）。
  • 改进
    无词图MMI链式模型2016.09 · 语音
    仍是HMM混合系统，依赖发音词典、决策树和音素级语言模型。
  • 改进
    对话语音识别达到人类水平2016.10 · 语音
    系统由大量模型融合而成，推理成本远高于实际可部署的系统。
  • 改进
    端侧流式RNN-T2018.11 · 语音
    只做了英语，多语言和代码混合还没有解决；模型仍是循环网络，训练较慢。

读懂它需要的概念

自注意力与多头注意力 Transformer层的结构 卷积层、池化与感受野 残差连接 归一化层 波形、频谱与梅尔谱 词错误率 归纳偏置

本篇术语

  • 深度可分离卷积　把普通卷积拆成两步：先让每个通道各自做一次一维卷积（深度卷积），再用1×1卷积混合通道（逐点卷积）。参数和计算量大幅减少。
  • 马卡龙式前馈（Macaron FFN）　把Transformer块里的一个前馈层拆成两个，分别放在注意力之前和最后，每个只贡献一半残差，像马卡龙的两片饼夹住中间的馅。
  • GLU门控　门控线性单元：把输入分成两半，一半经过sigmoid当作门，与另一半逐元素相乘。
  • Transducer　即RNN-T：编码器处理声音，预测网络处理已输出的文字，两者在联合网络中合并，逐步决定输出下一个字还是读入下一帧，天然支持流式识别。

怎么学

先确认会自注意力与多头注意力和Transformer层的结构，再理解一维卷积与深度可分离卷积（卷积层、池化与感受野）。读原文第2节和公式(1)，对照图1把四个子模块画出来；再看表3的消融，弄清每个部件各贡献多少。动手：在ESPnet或WeNet的LibriSpeech-100h配方里分别训练Transformer和Conformer编码器，对比dev-other上的词错误率。
