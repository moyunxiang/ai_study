书生·浦语InternLM3

InternLM3-8B-Instruct
2025.01模型延伸上海人工智能实验室 · InternLM团队待核对
Hugging Face模型卡 ↗InternLM2技术报告 ↗在交互版中打开（演化树、学习进度）

问题

同尺寸开源模型要达到好的推理与知识表现，通常需要十几万亿token的预训练，成本很高；同时用户既要深度推理，也要流畅的普通对话。

方法

用约4万亿高质量token训练一个8B指令模型，并在同一模型里支持长思维链的深度思考模式和普通回答模式。

影响

官方称在推理和知识密集任务上超过Llama3.1-8B和Qwen2.5-7B，训练成本比同规模模型节省75%以上。

背景

书生·浦语InternLM2是上海人工智能实验室在2024年发布的书生·浦语第二代开源模型。到2025年初，Qwen2.5、Llama 3.1 405B的7–8B模型用了远超10万亿的训练token，同时OpenAI o1推理模型、DeepSeek-R1让“深度思考”成为新需求。

方法

InternLM3于2025年1月开源8B参数的指令模型InternLM3-8B-Instruct。据官方模型卡，它只用了约4万亿高质量token进行训练，强调数据质量而非数量；模型同时支持两种模式：通过长思维链解决复杂推理问题的深度思考模式，和面向流畅交互的普通回答模式。官方用自家开源评测工具OpenCompass，从学科、语言、知识、推理、理解五个维度做了评测。

结果

官方模型卡称：InternLM3-8B-Instruct在推理和知识密集型任务上达到同级最好，超过Llama3.1-8B和Qwen2.5-7B等模型，且仅用4万亿token，比同规模模型节省75%以上的训练成本。

后来的发展

它延续了书生·浦语系列“开源模型 + 开源评测（OpenCompass）+ 开源工具链”的做法，也是较早在8B开源模型中同时提供思考与非思考模式的例子之一。

局限与后续

  • 只开源了8B一个尺寸，且没有独立的技术报告。

怎么学

先读书生·浦语InternLM2；看InternLM3模型卡两种模式的使用方式；动手：用OpenCompass评测InternLM3-8B在一个推理数据集上开关深度思考的差异。
