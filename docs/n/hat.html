HAT混合注意力超分

Activating More Pixels in Image Super-Resolution Transformer
2022.05论文延伸CVPR 2023Xiangyu Chen, Xintao Wang, Jiantao Zhou, Yu Qiao, Chao Dong · 澳门大学 / 中科院深圳先进技术研究院 / 上海人工智能实验室 / 腾讯ARC待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

SwinIR图像复原等Transformer超分网络按理能看得更远，但用归因分析（看输出的一个像素到底依赖输入的哪些像素）一查，它们实际利用的输入范围并不比卷积网络大多少，潜力没被发挥出来。

方法

设计“混合注意力”块，把通道注意力（看全局统计）和窗口自注意力（局部拟合强）结合起来；再加一个重叠窗口的交叉注意力模块，加强相邻窗口之间的信息交流；训练时先在大数据上做同任务预训练。

影响

在经典超分基准上比当时最好的方法高出1dB以上，成为2022–2023年图像超分的主要强基线，也推动了“激活更多输入像素”这类用归因分析指导网络设计的做法。

方法

HAT的主体结构和SwinIR类似：浅层卷积提特征，若干个残差组做深层特征提取，最后用像素重排上采样输出高分辨率图。改动在每个块内部：

  • 混合注意力块（HAB）：在窗口自注意力旁边并联一个通道注意力分支（类似RCAN通道注意力超分和SENet通道注意力，用全局平均池化后的统计量给各通道加权），两路结果相加。通道注意力利用整张图的统计，补足窗口注意力只看局部的短板；
  • 重叠交叉注意力块（OCAB）：查询来自普通窗口，键和值来自更大的、相互重叠的窗口，让每个窗口能“探头”看到邻居，缓解窗口之间信息割裂；
  • 同任务预训练：先在ImageNet这样的大数据集上做同样的超分任务预训练，再在DF2K等常用数据上微调，而不是用别的任务预训练。

摘要称加大模型后性能还能显著提升，整体比当时最好的方法高出1dB以上。归因分析显示HAT利用的输入像素范围明显更大。

局限与后续

  • 模型大、计算量高，推理速度和显存都不适合端侧或实时超分。

读懂它需要的概念

自注意力与多头注意力 Transformer层的结构 图像作为张量 预训练与微调

本篇术语

  • 归因分析　计算输出某个像素对输入各像素的敏感程度，用来看网络实际“看了”多大范围。
  • 同任务预训练　在大数据集上先训练同一个任务（这里就是超分），再在目标数据集上微调。
