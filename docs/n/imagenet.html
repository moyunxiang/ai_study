ImageNet

ImageNet: A Large-Scale Hierarchical Image Database
2009.06数据集主干CVPR 2009Jia Deng, Wei Dong, Richard Socher, Li-Jia Li, Kai Li, Li Fei-Fei · 普林斯顿大学来源已核对
论文PDF（CVPR 2009） ↗ILSVRC综述论文（IJCV 2015） ↗Wikipedia: ImageNet ↗在交互版中打开（演化树、学习进度）

问题

视觉识别数据集只有几十到几百类、每类几十张图，模型学不到真实世界的多样性；网上图片虽多，搜索结果的准确率只有约10%，没法直接拿来训练。

方法

以WordNet的名词层级为骨架，用搜索引擎为每个概念抓上万张候选图，再通过亚马逊众包平台让多人投票筛掉错图，目标是给数万个概念各配500–1000张干净的全分辨率图片。

影响

最终建成约1400万张图、2万多类的图库；由它衍生的千类挑战赛ILSVRC上，2012年AlexNet把前5错误率从上一年冠军的25.8%降到16.4%，常被视为深度学习在视觉领域兴起的标志。

背景

2000年代的物体识别研究主要用三类数据。Caltech-101/256有101类、每类几十到几百张图，物体大多居中、背景干净；PASCAL VOC只有20类，但图片来自真实场景，是检测的标准考场。这些数据集规模小，模型很容易在上面“过拟合”出好成绩，却说明不了在真实世界里能认出多少种东西。

另一个方向是直接用网上的海量图片。8000万Tiny Images用搜索引擎按WordNet名词抓了约8000万张图，缩到32×32，不做人工清洗；ESP游戏：用游戏做标注靠玩家在游戏里打标签。前者噪声太大——论文引用的估计是，网上图片搜索结果的准确率只有约10%；后者的标签没有区分词义，玩家输入“bank”时，分不清是河岸还是银行。与此同时，数据的不合理有效性等文章在文本领域总结出“数据量往往比算法更重要”。

李飞飞团队的判断是：视觉的瓶颈在数据，而且需要的是规模、准确和层级结构三者兼得。

方法

骨架：WordNet。WordNet把英语名词组织成约8万个同义词集（synset），用“是一种”关系连成树，例如 哺乳动物→胎盘动物→食肉动物→犬科→狗→工作犬→哈士奇。ImageNet为每个synset配图，于是数据集天然带有从粗到细的层级。

第一步：大量抓候选图。用synset里的各个同义词去多个图片搜索引擎检索。搜索引擎一次只返回几百到上千张，于是把父节点的词加进查询（查whippet时也查whippet dog、whippet greyhound），并借助其他语言的WordNet把查询翻译成中文、西班牙语、荷兰语、意大利语。去重后平均每个synset有1万多张候选图。

第二步：众包清洗。在众包标注Mechanical Turk上，给工作者看一组候选图和该synset的定义（附维基百科链接），让他们勾出确实包含该物体的图，并鼓励保留有遮挡、多物体、杂乱背景的图以保证多样性。难点是人会犯错、意见也会分歧，越细的类别分歧越大。做法是按类别动态决定投票数：先用少量图收集多人判断，估计“几票赞成、几票反对”对应的可信度，再对每张图一直收集投票，直到可信度超过阈值。论文的例子：对“猫”，3票赞成0票反对时可信度0.99；对更难判断的“缅甸猫”，同样3比0只有0.90，需要更多票。

结果的形态。每个synset得到一组全分辨率、人工核验的图片，可以按层级合并，例如把120种狗合成“狗”。

结果

论文发表时已完成12棵子树（哺乳动物、鸟、交通工具、家具、乐器、花等），共5247个synset、320万张图。在随机抽取的80个synset上复查，平均准确率99.7%。论文还做了简单验证：用同样的最近邻方法，在人工清洗过的全分辨率图片上识别效果明显好于在未清洗的小图上。

此后扩展到2010年4月统计的21,841个synset、14,197,122张图，其中103万多张带物体框。按维基百科引用的资料，标注从2008年7月持续到2010年4月，来自167个国家的约4.9万名众包工作者筛选了1.6亿多张候选图。

2010年起，团队与PASCAL VOC团队合作，从中切出1000类、约128万张训练图办ILSVRC挑战赛。冠军的前5错误率：2010年28.2%，2011年25.8%，2012年AlexNet16.4%（用额外数据15.3%），2013年11.7%，2014年GoogLeNet / Inception6.7%；一位受过训练的专家标注者在1500张测试图上约为5.1%（同一批图上GoogLeNet为6.8%）。2015年ResNet降到3.57%。

后来的发展

ImageNet改变了视觉研究的重心：从在小数据集上设计特征，转向在大数据上训练深度网络。“先在ImageNet上预训练，再迁移到检测、分割等任务”（见迁移学习）从2013年前后起成为常用流程，R-CNN、全卷积网络FCN等都用ImageNet预训练的网络初始化；ImageNet上的准确率也是比较新架构的常用标尺，从VGG、ResNet一直到Vision Transformer。

它的影响也引来反思。ImageNetV2：榜单过拟合了吗按原流程重建测试集，发现模型准确率普遍下降11%–14%，但作者认为原因是新图略难、而不是对旧测试集的过度适应；ImageNet-C、ImageNet-A / -R显示模型对噪声和风格变化很脆弱；测试集标注错误估计验证集里至少6%的标签有误。2019年团队自己检讨了“人”子树中由WordNet带来的冒犯性类别和代表性不均，并做了过滤。到2020年代，网络规模的图文对数据（CLIP、LAION-5B）和自监督方法（掩码自编码器MAE、DINOv2）不再依赖逐图人工标注，在不少新工作里，ImageNet更多被用作评测基准而不是主要训练数据。

容易误解的地方

  • 平时说的“ImageNet”多半指ILSVRC-2012的1000类、约128万张训练图的子集（ImageNet-1k），而不是2万多类的完整图库（ImageNet-21k）。
  • ImageNet并不拥有这些图片的版权，官方只发布图片网址和标注，供非商业研究使用。
  • ImageNet最初的卖点是“规模+准确+层级”，深度学习不是它设计时的目标；第一年的ILSVRC冠军用的是SIFT类特征加SVM。

局限与后续

  • 图片中的物体大多较大、位于画面中央，且每张图只标一个类别，不能检验在杂乱场景中同时找出多个物体的能力。
    后来针对它的工作　MS COCO Open Images LVIS
  • 测试集被全领域反复使用十年，人们担心排行榜的进步只适用于这批图片；模型换一批按原流程采集的新图、或加噪声、换风格后准确率明显下降。
    后来针对它的工作　ImageNetV2：榜单过拟合了吗 ImageNet-C ImageNet-A / -R
  • 众包标注仍有相当数量的错标和多物体歧义，单一标签的评测会误判模型。
    后来针对它的工作　测试集标注错误
  • 逐图人工核验的成本无法再扩大一两个数量级，类别也被固定在WordNet名词上，无法覆盖开放世界的概念。
    后来针对它的工作　Instagram弱监督预训练 CLIP LAION-5B
  • 继承了WordNet中过时甚至冒犯性的人物类别，人群图片的分布也不均衡，可能把偏见传给下游模型。

它建立在什么之上

  • 改进
    LeNet与卷积网络1998 · 视觉 已核对
    只在32×32的黑白数字和字符上验证，面对彩色、杂乱背景、上千类别的自然图像，当时既没有足够的标注数据，也没有足够的算力训练更大的网络。
  • 使用
    WordNet1995 · 数据·评测 已核对
    直接以WordNet的名词同义词集和“是一种”层级作为类别体系与查询词来源。
  • 竞争
    ESP游戏：用游戏做标注2004.04 · 数据·评测 已核对
    同样用众人之力给图片打标签：论文指出ESP游戏的标签不区分词义、大部分数据未公开，ImageNet则以WordNet同义词集从构造上避免了歧义。
  • 改进
    Caltech-101/2562004.06 · 数据·评测 已核对
    Caltech-101类别少、每类图片少、物体居中；论文称ImageNet的类别数约为这类小数据集的20倍、总图片数约100倍，用平均图像比较显示其图片多样性高于Caltech101。
  • 延续
    PASCAL VOC2005 · 数据·评测 已核对
    PASCAL VOC只有20类；ImageNet把类别扩展到上万个。据ILSVRC综述，ILSVRC沿用了PASCAL VOC“公开数据集+年度竞赛与研讨会”的形式，维基百科称它源于与PASCAL VOC团队的合作。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测 已核对
    用亚马逊众包平台完成上亿张候选图的人工核验，并按类别难度动态决定投票次数。
  • 改进
    8000万Tiny Images2008.11 · 数据·评测 已核对
    Tiny Images规模大但不清洗、只有32×32；ImageNet保留全分辨率并逐图人工核验，准确率约99.7%。
  • 改进
    第二次AI寒冬1987 · 事件
    领域缺少统一的评测基准，资助方和企业无法客观判断进展，只能凭演示和承诺决策。
  • 改进
    MNIST1998 · 数据·评测
    任务过于简单：1998年最好方法错误率已低于1%，后来降到0.23%，再也无法区分模型的真实视觉能力。
  • 改进
    UCI机器学习库1987 · 数据·评测
    数据集多是小规模的表格数据，没有统一的训练/测试划分，论文之间的结果往往不可直接比较；深度学习兴起后，图像、语音、文本的大规模基准转向ImageNet等专门数据集。
  • 改进
    LabelMe标注工具2005 · 数据·评测
    靠志愿者标注，覆盖不均：常见物体标注得多，冷门类别很少；标注的质量和命名也不统一。
  • 改进
    CIFAR-10/1002009 · 数据·评测
    分辨率只有32×32，类别很少，在上面的结论放大到真实图像时常常不成立。

读懂它需要的概念

监督学习 训练集、验证集与测试集 泛化与过拟合 图像作为张量 Top-1与Top-5错误率 迁移学习

本篇术语

  • 同义词集（synset）　WordNet中的一个概念，由若干同义词表示，例如“狗、家犬、Canis familiaris”。ImageNet的每个类别就是一个synset。
  • 前5错误率　模型给出5个最可能的类别，只要正确答案在其中就算对；正确答案不在前5个里的比例就是前5错误率。
  • 众包　把大量小任务拆分后通过网络平台分发给众多不特定的工作者完成，并按件付费。
  • ImageNet-1k / ILSVRC-2012　平常说的“ImageNet分类”指的是ILSVRC 2012–2014分类任务用的这一份子集：1000类，训练图1,281,167张、验证图50,000张、测试图100,000张，这三年测试集没有变过。
  • ImageNet 256×256　把ImageNet-1k图片缩放到固定分辨率，做带类别条件的图像生成评测，按分辨率分成64×64、128×128、256×256、512×512等赛道，主要比FID。Dhariwal与Nichol 2021年（ADM）在128、256、512上分别报告FID 2.97、4.59、7.72；32×32和64×64的缩小版数据集来自Chrabaszcz等2017，类别和图片数与原版相同。

怎么学

先补Top-1与Top-5错误率和迁移学习。读CVPR 2009原文第3节（数据采集与清洗），再读ILSVRC综述论文第3节和第6节（人类与机器的错误分析）。动手：用torchvision加载一个在ImageNet上预训练的ResNet，在一个只有几百张图的小数据集上做微调，对比从零训练的效果，体会“ImageNet预训练”为什么成了默认流程。
