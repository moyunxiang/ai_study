IndexTTS系列

IndexTTS: An Industrial-Level Controllable and Efficient Zero-Shot Text-To-Speech System
2025.02论文延伸arXiv 2025Deng, Zhou, Shu, Wang, Wang · bilibili待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

XTTS类零样本克隆在中文里多音字和生僻字读错，稳定性和速度也有待提高。

方法

在XTTS与Tortoise基础上，用字符和拼音混合建模使多音字可控，比较VQ与FSQ，加入基于Conformer的说话人条件编码器，用BigVGAN2作为解码器。

影响

在中文场景下发音可控、推理快，开源后被广泛使用，并有后续版本。

方法

IndexTTS主要沿用XTTS的结构：自回归模型预测语音token，再解码成波形。针对中文，输入文本采用汉字与拼音混合建模，使用者可以直接在文本中写拼音来纠正多音字和长尾字的读音。论文还比较了向量量化和有限标量量化（FSQ）在码本利用率上的差异，用基于Conformer的条件编码器提取说话人信息以提升克隆的稳定性，并把语音token解码器换成BigVGAN2。

论文称相比XTTS在自然度、内容一致性和克隆效果上都有明显提升，并与CosyVoice2、F5-TTS等开源系统相比，训练流程简单、发音更可控、推理更快。

局限与后续

  • 仍是自回归，难以精确控制时长和情感，后续版本才逐步加入。
