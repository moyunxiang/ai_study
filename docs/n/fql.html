FQL流Q学习

Flow Q-Learning
2025.02论文延伸ICML 2025Seohong Park, Qiyang Li, Sergey Levine · UC Berkeley待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

离线数据里的动作分布常常是多峰的，高斯策略表达不了；改用扩散或流匹配策略又很难用RL训练，因为要对多步迭代生成过程反传梯度，既不稳又慢。

方法

分两个策略：一个流匹配策略只做行为克隆、负责表达数据分布；另一个一步策略用RL最大化Q值，同时被蒸馏得贴近流策略的输出。执行时只用一步策略。

影响

2025年起成为离线和离线转在线RL的常用强基线，Q-chunking、视界缩减等后续工作直接以它为底座。

方法

Diffusion-QL扩散策略等方法把扩散模型当策略，再对整条去噪链反传Q值梯度来改进它，链越长越不稳、越慢。FQL（Flow Q-Learning）换了个思路，把“表达力”和“RL优化”交给两个网络：

1. 流策略 μ_θ(s, z)：用Flow Matching在离线数据上做行为克隆，从噪声z出发经过若干步积分得到动作，能表达任意复杂的数据分布，但它本身不做RL。 2. 一步策略 π_ω(s, z)：输入同样的噪声z，一次前向直接输出动作，损失是

L(ω) = E[ −Q(s, π_ω(s, z)) + α‖π_ω(s, z) − μ_θ(s, z)‖² ]

第一项让动作价值高，第二项把流策略对同一噪声给出的动作蒸馏过来，相当于一个“贴近数据分布”的正则。

3. 评论家照常用TD学习，目标里的下一动作由一步策略给出。

这样RL梯度只经过一步策略，不需要穿过迭代生成过程；测试时也只要一次前向。摘要称在73个基于状态和像素的OGBench与D4RL任务上，离线和离线转在线都取得很强表现。

局限与后续

  • 蒸馏系数α需要按任务族调，太大退化成行为克隆，太小又会跑出数据分布。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 在长视界、数据量极大的任务上，价值学习本身仍随视界增长而变难，单靠更强的策略类解决不了。

它建立在什么之上

  • 使用
    Flow Matching2022.10 · 生成
    用流匹配训练表达数据分布的行为克隆策略。
  • 延续
    TD3+BC极简离线RL2021.06 · RL
    保留“最大化Q加贴近数据”的极简形式，但把贴近的对象从数据动作换成流策略的输出。
  • 改进
    Diffusion-QL扩散策略2022.08 · RL
    Diffusion-QL要对整条去噪链反传Q梯度；FQL改为只训练一步策略，避免递归反传。
  • 改进
    SfBC扩散行为候选选择2022.09 · RL
    每一步都要用扩散模型采样几十个候选动作，推理速度慢。
  • 改进
    IVR隐式价值正则（SQL/EQL）2023.03 · RL
    和其他数据内方法一样，只能在数据出现过的动作之间重新加权，数据覆盖差时上限有限。
  • 竞争
    IDQL隐式扩散Q学习2023.04 · RL
    IDQL用扩散策略加重采样选动作，推理需多次去噪；FQL推理只需一步。
  • 改进
    QGPO对比能量引导扩散2023.04 · RL
    需要先训练行为扩散模型和Q函数，再训练引导网络，三阶段流程繁琐，采样时仍需多步去噪。
  • 竞争
    ReBRAC重访极简离线RL2023.05 · RL
    ReBRAC用单峰确定性策略，FQL用流模型提供多峰的行为正则。
