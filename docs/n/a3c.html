A3C

Asynchronous Methods for Deep Reinforcement Learning
2016.02论文延伸ICML 2016Mnih, Badia, Mirza, Graves, Lillicrap, Harley, Silver, Kavukcuoglu · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DQN靠庞大的经验回放池来打破样本间的相关性，占内存、只能离策略，还要GPU；在线RL的数据相关又会让训练不稳。

方法

让多个actor-learner线程在同一台多核CPU上并行玩各自的环境副本，异步地更新共享参数；不同线程经验不同，自然去相关，不再需要回放池。

影响

证明并行比回放池更简单地稳定了深度RL，在Atari上只用CPU就达到当时最优，是PPO时代之前最常见的基线。

方法

论文把四种标准算法做成异步版本：一步Q学习、n步Q学习、SARSA和优势actor-critic。表现最好的是异步优势actor-critic，也就是A3C。每个线程拿共享网络的参数副本，在环境里跑最多t_max步（如5步），用n步回报估计优势 A = R − V(s)，然后算出策略梯度和价值损失的梯度，直接（无锁地）加到共享参数上。策略损失里还加了一项熵奖励，防止策略过早变得确定。

摘要称A3C在Atari上用单个多核CPU训练，所花时间只有此前最佳的一半，同时超过了当时的最好成绩；它在多种连续运动控制任务以及第一人称视角的随机3D迷宫导航中也成功。

局限与后续

  • 异步更新使用的参数是过期的，梯度质量不稳定；学习器不能充分用上GPU。
    后来针对它的工作　IMPALA与V-trace
  • on-policy、不重复使用旧样本，样本效率低。
    后来针对它的工作　ACER

它建立在什么之上

  • 延续
    REINFORCE策略梯度1992 · RL 已核对
    策略梯度部分用n步回报和价值基线降低REINFORCE的方差。
  • 改进
    Actor-Critic（ASE/ACE）1983 · RL 待核对
    状态由人工设计的162格解码器离散化，系统不学习表示，状态维度一多盒子数就爆炸。
  • 竞争
    DQN2013.12 · RL
    DQN用回放池去相关，A3C用并行actor去相关；后来的大规模系统两者兼收。

后来的相关工作

  • 延续
    PPO2017.07 · RL 已核对
    沿用A3C/A2C的多actor并行采样与共享网络结构，但让每批数据训练多轮；在49款Atari游戏上按训练全程平均回报，PPO、ACER、A2C分别胜出30、18、1款。
  • 竞争
    World Models2018.03 · 具身·世界模型 已核对
    论文表1中A3C在CarRacing上为591–652分；在这个任务上，先学压缩表示和预测模型再做决策的效果好于这些端到端无模型结果。
  • 延续
    RL²元强化学习2016.11 · RL
    把A3C时代成熟的深度策略梯度训练用作外层的“慢”学习器（本文实际用的是TRPO；同期DeepMind的同类工作用A3C），由它学出内层的“快”学习算法。
  • 使用
    好奇心模块ICM2017.05 · RL
    策略学习用A3C，ICM只负责额外提供内在奖励，可以接在任何RL算法上。
  • 使用
    Rainbow2017.10 · RL
    多步回报目标在A3C中已被使用，Rainbow把它与分布式学习结合；A3C也是对比基线之一（中位数118%）。
  • 使用
    CARLA驾驶仿真器2017.11 · 具身·世界模型
    强化学习基线用A3C训练端到端驾驶，结果显示在复杂城市导航上远不如模块化和模仿学习方法。
  • 改进
    IMPALA与V-trace2018.02 · RL
    把A3C中“每个线程既采样又算梯度”拆成actor与GPU学习者，解决吞吐和GPU利用率问题，单机即快一个量级。
  • 改进
    ACER2016.11 · RL
    在A3C的异步actor-critic基础上加入经验回放，提高样本效率。
  • 延续
    UNREAL辅助任务2016.11 · RL
    在A3C之上加入多个辅助伪奖励任务共享表示。
  • 使用
    FeUdal Networks2017.03 · RL
    基于A3C的异步actor-critic训练。
  • 竞争
    进化策略作为RL替代2017.03 · RL
    在Atari和MuJoCo上与当时的A3C、TRPO等做对比，用更多算力换更简单的并行。
  • 延续
    OpenAI Baselines与A2C2017.05 · RL
    A2C把A3C的异步更新改为同步批量更新。
  • 使用
    从人类偏好学习奖励2017.06 · RL
    用A3C在学出的奖励模型上训练智能体。
  • 使用
    World of Bits / MiniWoB2017.07 · 数据·评测
    用异步强化学习训练网页智能体，并与行为克隆结合。
