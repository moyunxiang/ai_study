einops张量操作

Einops: Clear and Reliable Tensor Manipulations with Einstein-like Notation
2018.09系统延伸ICLR 2022Alex Rogozhnikov待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

深度学习代码里大量的reshape、transpose、permute、squeeze只用位置下标表示维度，难读也容易错，而且在不同框架里写法各不相同。

方法

借鉴爱因斯坦求和记号，用带名字的字符串模式描述张量形状变换，例如 rearrange(x, 'b c h w -> b (h w) c')，同一套写法在PyTorch、JAX、TensorFlow、NumPy等后端都能用。

影响

被大量模型代码（ViT、扩散模型、各种Transformer实现）采用，rearrange 几乎成了写注意力和图像分块代码的通用写法。

方法

einops提供三个核心函数。rearrange：重排、合并、拆分维度，例如把图片切成16×16的块并展平成序列，rearrange(img, 'b c (h p1) (w p2) -> b (h w) (p1 p2 c)', p1=16, p2=16)，一行完成Vision Transformer的分块；reduce：在指定维度上做求和、均值、最大值等归约，例如全局平均池化 reduce(x, 'b c h w -> b c', 'mean')；repeat：沿新维度复制。模式中括号表示合并或拆分的维度组，名字让读者一眼看出每一维的含义；运行时会检查形状是否与模式一致，出错时给出清晰的报错。它还提供可放进nn.Module的层（Rearrange、Reduce）以及einsum的命名维度版本。

仓库创建于2018年9月；论文《Einops: Clear and Reliable Tensor Manipulations with Einstein-like Notation》发表于ICLR 2022。

怎么学

先熟悉张量的形状与reshape/transpose；读einops官方教程第一部分；动手用rearrange重写一段自注意力里的多头拆分代码。
