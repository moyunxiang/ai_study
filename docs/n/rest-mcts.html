ReST-MCTS*过程奖励自训练

ReST-MCTS*: LLM Self-Training via Process Reward Guided Tree Search
2024.06论文延伸NeurIPS 2024Dan Zhang, Sining Zhoubian, Ziniu Hu, Yisong Yue, Yuxiao Dong, Jie Tang · 清华大学 / 加州理工学院待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

STaR、ReST这类自训练方法只按最终答案对错筛选模型自己生成的解答，答案碰巧对、中间步骤错的解答也会被拿来训练；训练过程奖励模型又需要逐步的人工标注。

方法

用带过程奖励的树搜索（MCTS*）收集解答：已知正确答案时，通过从某一步出发多次模拟、看它多快能走到正确答案，自动估出这一步的价值；这些估计值一边用来训练过程奖励模型，一边用来挑高质量轨迹训练策略模型，两者交替迭代。

影响

把“自动标注过程奖励”“树搜索找轨迹”“策略与奖励模型一起自训练”三件事合在一个循环里，多轮迭代后持续超过ReST-EM和自奖励语言模型；是o1出现前后“搜索+过程奖励+自我改进”路线的代表工作之一。

背景

STaR自举推理和ReST强化自训练让模型生成多份解答，只保留答案正确的用于微调，信号只有最终对错。过程监督与过程奖励模型证明逐步打分的过程奖励更有用，但PRM800K靠人工逐步标注；Math-Shepherd自动过程监督改用“从这一步出发多次补完，看有多少次能答对”来自动标注。另一方面，思维树等树搜索方法能找到更好的推理路径，却没有把找到的路径用于训练。

方法

价值的定义：部分解答 p_k = [s₁…s_k] 的质量值 v_k，在0到1之间。引入推理距离 m_k：从 p_k 出发，策略模型最少还要几步才能得到正确答案，通过模拟采样估计。单步的加权奖励为 w_k = (1 − v_{k−1}) / (m_k + 1) · (1 − 2r_k)，其中 r_k 是类似Math-Shepherd的步骤对错信号；再递推 v_k = max(v_{k−1} + w_k, 0)。直觉是：一步若让离正确答案的距离变短、又是对的，价值就上升得多。

MCTS*：每个树节点是一步推理，用过程奖励模型给出的 v_k 引导选择与扩展，并做多次模拟回传价值。

自训练循环： 1. 用当前策略和过程奖励模型做MCTS*，对训练题目收集推理树； 2. 已知正确答案，用模拟结果为树上每个节点推断 v_k，作为过程奖励模型的新训练目标； 3. 从树中挑出价值高且答案正确的完整轨迹，微调策略模型； 4. 用更新后的两个模型重复。

结果：在同样的搜索预算下，MCTS*在MATH和科学推理基准SciBench上的准确率高于自洽性采样和Best-of-N，在科学推理上也超过思维链和思维树。用LLaMA-3-8B-Instruct、Mistral-7B（MetaMath版）和SciGLM-6B三个策略模型多轮自训练，均持续超过ReST-EM和自奖励语言模型。

后来的发展

同期与之后的rStar-Math等工作走的是相近的路：用树搜索加自动过程标注生成高质量数据、多轮自我进化。DeepSeek-R1之后，主流转向只用结果奖励的强化学习，这类“显式树搜索+PRM”路线更多保留在小模型与测试时搜索的研究中。

局限与后续

  • 推断过程奖励需要已知正确答案，而且每个节点都要多次模拟，数据构造成本高，只适用于答案可自动判对错的题目。

  • 过程奖励模型与策略模型互相提供训练数据，奖励模型的偏差会被策略利用并逐轮放大。

读懂它需要的概念

博弈树搜索：minimax与MCTS 蒙特卡洛采样 奖励、回报与折扣 策略与价值函数 预训练与微调

本篇术语

  • 推理距离　从当前这几步出发，模型最少还要再走几步才能得到正确答案；距离越短说明当前进展越好。
  • 自训练（self-training）　让模型生成数据、筛选后再用来训练自己，循环多轮。

怎么学

先读STaR自举推理、过程监督与过程奖励模型和Math-Shepherd自动过程监督 → 读原文第3.1节价值与加权奖励的定义（公式2–3）和图1的自训练循环 → 动手：对一道题的若干中间步骤各做10次补完，统计能答对的比例，体会自动过程标注。
