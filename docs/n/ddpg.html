DDPG

Continuous Control with Deep Reinforcement Learning
2015.09论文延伸ICLR 2016Lillicrap, Hunt, Pritzel, Heess, Erez, Tassa, Silver, Wierstra · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DQN只适用于离散动作，因为它每步要对所有动作取max；机械臂关节力矩这类连续动作无法直接使用。

方法

把确定性策略梯度DPG的确定性策略梯度与DQN的经验回放、目标网络结合成actor-critic：actor直接输出连续动作，critic估计Q值并给actor提供梯度。

影响

成为连续控制的第一个通用深度RL算法，后继的TD3、SAC都从它改进而来。

方法

DDPG有两个网络：actor μ(s) 输出一个确定的连续动作，critic Q(s,a) 评价这个动作。critic用TD目标训练（见时序差分与自举），目标里用的下一动作由actor的目标副本给出；actor的更新方向是沿critic对动作的梯度 ∇ₐQ(s,a) 再乘以 ∇θ μ(s)，这正是确定性策略梯度DPG的结论。

为了让神经网络做这件事稳定，沿用DQN的两项技巧：经验回放（离策略训练）和目标网络，只是目标网络不再每隔一段时间整体复制，而是缓慢跟随主网络。探索靠在动作上加噪声。论文称用同一算法、同一网络结构和超参数，解决了20多个模拟物理任务（倒立摆、灵巧操作、腿式运动、驾驶等），部分任务还能直接从像素端到端学习。

局限与后续

  • critic会高估Q值，actor追着这些高估的值走，训练容易发散，对超参数敏感。
    后来针对它的工作　TD3
  • 确定性策略加固定噪声的探索较弱，在稀疏奖励任务里学不出来。
    后来针对它的工作　SAC 后见经验回放HER

它建立在什么之上

  • 延续
    DQN2013.12 · RL 已核对
    把DQN的回放池和目标网络搬到连续动作的actor-critic里。
  • 改进
    Q-learning1992 · RL
    需要对所有动作取max，只适用于少量离散动作，连续动作无法直接使用。
  • 使用
    确定性策略梯度DPG2014.06 · RL
    actor的更新直接采用确定性策略梯度公式。
  • 改进
    Dueling DQN2015.11 · RL
    仍然是对每个动作输出一个值的离散动作结构，不能处理连续动作。

后来的相关工作

  • 竞争
    Dreamer2019.12 · 具身·世界模型 已核对
    论文把D4PG称为DDPG的改进版；在20个DMC像素任务上，D4PG用1亿步平均786分，Dreamer用500万步平均823分。
  • 延续
    MADDPG2017.06 · RL
    每个智能体都是一个DDPG式actor-critic，只是critic的输入扩展为所有智能体的观测和动作。
  • 使用
    后见经验回放HER2017.07 · RL
    机械臂实验的底层算法是DDPG，HER只改变回放池里存什么数据。
  • 延续
    《Deep RL that Matters》复现性批评2017.09 · RL
    DDPG对奖励缩放、网络结构和代码库都极为敏感，是本文受影响最大的算法之一。
  • 改进
    TD32018.02 · RL
    指出DDPG的critic系统性高估且误差会被actor放大，用截断双Q、延迟更新和目标平滑三处修改解决其不稳定问题。
  • 竞争
    QT-Opt2018.06 · 具身·世界模型
    DDPG用一个策略网络近似argmax，QT-Opt去掉策略网络、直接搜索，换来大规模真机数据上的训练稳定。
  • 改进
    BCQ批量约束Q学习2018.12 · RL
    展示DDPG在固定数据上即使用与行为策略相同的数据也会失败，并用批量约束解决。
  • 改进
    SAC2018.01 · RL
    DDPG的确定性策略训练脆弱、依赖精细调参；SAC用随机策略加熵正则让训练更稳。
