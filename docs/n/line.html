LINE大规模网络嵌入

LINE: Large-scale Information Network Embedding
2015.03论文延伸WWW 2015Jian Tang, Meng Qu, Mingzhe Wang, Ming Zhang, Jun Yan, Qiaozhu Mei · 微软亚洲研究院、北京大学、密歇根大学待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

把节点嵌入到低维向量能用于可视化、节点分类和链接预测，但经典的图嵌入方法（如基于矩阵分解的流形学习）跑不动百万节点的真实网络，DeepWalk图嵌入又只适用于无权无向图。

方法

直接为图上的边设计两个目标：一阶相似度（有边相连的两个点向量要接近）和二阶相似度（邻居相似的两个点向量要接近），用负采样加“按边权采样边”的SGD高效优化，适用于有向、无向和带权图。

影响

LINE与DeepWalk图嵌入、node2vec图嵌入并列为图嵌入的三个经典基线，几乎所有网络表示学习论文都和它比较；“一阶/二阶相似度”的说法也成为该领域的通用术语。

方法

一阶相似度：对每条边(i, j)，定义它们“相连”的概率为 σ(u_iᵀu_j)（σ是sigmoid），目标是让模型的边分布与观测到的边权分布在KL散度意义下接近，等价于最大化所有边上 w_ij · log σ(u_iᵀu_j)。这只适用于无向图。

二阶相似度：每个节点有两套向量——作为自己的向量u_i和作为别人“上下文”的向量u′_j。对每个节点i，用softmax定义它的邻居分布 p(j|i) = exp(u′_jᵀu_i) / Σ_k exp(u′_kᵀu_i)，要求它接近观测到的邻居分布。这和word2vec的skip-gram一样：共享很多邻居的两个节点，就像出现在相似上下文中的两个词，向量会被拉近。分母要对全部节点求和，所以用负采样近似。

边采样：带权图中边权差别很大，直接把边权乘到梯度上会让梯度尺度剧烈波动，学习率难以设定。LINE改为按边权概率抽边，抽到的边都当作二值边更新，这样梯度尺度稳定。作者把一阶和二阶两种向量分别训练后拼接作为最终表示。

摘要报告：方法在语言网络、社交网络、引用网络等多种真实网络上有效；效率很高，在一台普通机器上几小时内就能学完含数百万节点、数十亿条边的网络的嵌入。

  • 使用
    word2vec2013.01 · NLP
    二阶相似度的目标与skip-gram同构，并借用负采样近似softmax。
  • 改进
    流形学习Isomap/LLE2000.12 · 基础
    经典基于矩阵分解的图嵌入难以扩展到百万节点，LINE用随机梯度方法把规模推到数十亿条边。
  • 竞争
    DeepWalk图嵌入2014.03 · 基础
    DeepWalk用随机游走序列加skip-gram，LINE直接在边上定义一阶/二阶目标，并支持带权和有向图。

读懂它需要的概念

图、树与搜索 嵌入向量 KL散度 Softmax与logits 随机梯度下降与小批量

本篇术语

  • 一阶相似度　两个节点之间直接有边、边权越大越相似。
  • 二阶相似度　两个节点的邻居集合越重叠越相似，哪怕它们之间没有直接相连。

怎么学

先学word2vec的skip-gram与负采样；读论文第4节的两个目标和边采样；用一个引用网络数据集（如Cora）训练LINE的一阶与二阶向量，做节点分类并与DeepWalk比较。
