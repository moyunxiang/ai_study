探索语言模型的极限

Exploring the Limits of Language Modeling
2016.02论文重要Rafal Jozefowicz, Oriol Vinyals, Mike Schuster, Noam Shazeer, Yonghui Wu · Google Brain待核对
arXiv ↗公开的模型与代码（tensorflow/models lm_1b） ↗在交互版中打开（演化树、学习进度）

问题

神经语言模型的研究大多在百万词级的Penn Treebank上做，那里主要矛盾是过拟合；真正大的语料（10亿词、近80万词表）上，最好的结果仍是RNN加9-gram特征或巨型n-gram模型，困惑度51.3。

方法

在10亿词基准上把LSTM尽量做大（单层8192个单元、带投影），用重要性采样近似80万类的softmax，再用字符卷积代替词向量输入层；系统比较各种设计，发现“模型越大越好”。

影响

单模型困惑度从51.3降到30.0、集成降到23.7，说明大数据上的瓶颈是模型容量而非过拟合；其CNN-BIG-LSTM直接成为ELMo的底座，也是后来规模化语言模型研究的起点之一。

背景

RNN语言模型之后，神经语言模型（见语言模型）的论文几乎都在Penn Treebank上比较：约100万词、1万词表。数据这么小，主要问题是过拟合，大家拼的是正则化技巧。

作者认为这偏离了真正的问题。在Chelba等人2013年发布的10亿词基准（One Billion Word，约8亿训练词、793,471个词的词表）上，n-gram方法依然很强：5-gram Kneser-Ney模型困惑度67.6，此前最好的单模型是带9-gram特征的RNN（51.3），集成也只到41.0。神经网络在这里有两大障碍：词表太大，输出层softmax每步要和近80万个词向量做内积；以及大模型能否训得动。字符感知语言模型刚证明可以用字符卷积来构造词向量，但只在小数据上试过。

方法

大LSTM加投影。LSTM的隐状态做得很宽（最大8192维），再用一个线性层投影到1024或2048维，减少后续矩阵的大小。dropout放在每层LSTM前后，遗忘门偏置初始化为1。

重要性采样近似softmax。每步不计算全部793,471个词的分数，而是随机抽8192个“噪声词”，和真实下一个词一起近似归一化（见重要性采样）。这8192个样本在整个批次（128句×20步=2560个位置）里共享，计算量约降低到百分之一。论文证明它和噪声对比估计NCE形式上相近，实验中收敛更快、效果更好。

字符CNN输入。按字符感知语言模型的做法，把每个词的字符序列过一维卷积和最大池化得到词向量，输入层参数减少到约十一分之一，没见过的词也能得到合理的向量。

CNN softmax。输出层也用字符卷积生成每个词的输出向量，再加一个低维“修正”向量补偿拼写相近而意思不同的词，用少得多的参数接近完整softmax。

结果

10亿词基准测试困惑度（见困惑度）：2层LSTM-8192-1024（BIG LSTM）30.6，换成字符CNN输入后30.0，参数10.4亿（其中8.2亿在softmax前的线性层），而此前51.3的模型有200亿参数，约为20倍。同等大小下普通RNN比LSTM差约5个困惑度。CNN softmax仅2.9亿参数达到39.8，加128维修正向量后3.9亿参数达到35.8。10个最好的LSTM集成再加一个稀疏n-gram模型达到23.7，比此前最好的41.0降低40%以上。训练用32块Tesla K40 GPU，最好的模型训练了3周。

后来的发展

这篇是“把语言模型做大”路线的早期证据：ELMo直接采用其中最好的CNN-BIG-LSTM结构（维度减半）作为双向语言模型；情感神经元和门控卷积语言模型GLU都以它为对比基线；作者之一Shazeer随后在同一基准上用稀疏门控MoE层把参数推到上千亿级。语言模型的规模定律系统地给出了“模型越大、数据越多、损失越低”的幂律。字符输出层没有成功，词级或子词级输出一直沿用。

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    主体是带投影层的大LSTM，并发现同等规模下比普通RNN好约5个困惑度。
  • 改进
    Kneser-Ney平滑1995.05 · NLP
    上下文最多是前几个词，阶数一高需要存储的n-gram数量急剧膨胀，实际系统往往只能用到5-gram并要剪枝。
  • 延续
    RNN语言模型2010.09 · NLP
    沿着RNN语言模型的路线，换成大LSTM、在千倍于Penn Treebank的语料上系统地放大。
  • 改进
    n-gram平滑1996 · NLP
    在n-gram最擅长的大语料上，单个LSTM（30.0）也远好于Kneser-Ney 5-gram（67.6），且在罕见词上优势最大。
  • 竞争
    层次softmax语言模型2005 · NLP
    层次softmax是另一种解决大词表的方案，论文选择了基于采样的近似。
  • 竞争
    噪声对比估计NCE2010.05 · 基础
    论文比较了NCE与重要性采样两种近似大softmax的方法，后者训练更快、困惑度更低。
  • 改进
    十亿词基准LM1B2013.12 · 数据·评测
    句子互相打乱，只测单句内的建模能力，无法评估跨句、跨段落的长程依赖。
  • 使用
    字符感知语言模型2015.08 · NLP
    输入层直接采用Kim等人的字符卷积词向量结构，只把卷积特征数加到4096。

读懂它需要的概念

语言模型 困惑度 循环网络与隐状态 Softmax与logits 重要性采样 参数量、计算量与显存

本篇术语

  • 10亿词基准（One Billion Word Benchmark）　2013年Chelba等人整理的语言模型数据集，取自新闻，约8亿训练词，句子已打乱并去重。
  • 投影层（projection）　在宽的LSTM隐状态之后加一个线性层把它压到更低维度，减少后面矩阵乘法的大小。
  • CNN softmax　不给每个输出词单独存一个向量，而是用字符卷积根据拼写算出它的输出向量，参数量与词表大小基本无关。

怎么学

先补困惑度、Softmax与logits和重要性采样，读过RNN语言模型和字符感知语言模型。读原文第3节（采样近似与CNN softmax）和表1，按参数量和困惑度两列对照着看。动手：在一个中等语料上训练两个大小不同的LSTM语言模型，画出困惑度随参数量的变化；再把完整softmax换成采样近似，比较速度。
