生成对抗网络GAN

Generative Adversarial Nets
2014.06论文主干NeurIPS 2014Ian Goodfellow, Jean Pouget-Abadie, Mehdi Mirza, Bing Xu, David Warde-Farley, Sherjil Ozair, Aaron Courville, Yoshua Bengio · Université de Montréal来源已核对
arXiv ↗Goodfellow：NIPS 2016 Tutorial: Generative Adversarial Networks ↗原作者代码（Theano） ↗在交互版中打开（演化树、学习进度）

问题

深度生成模型要么需要写出似然并做近似推断，要么像玻尔兹曼机那样依赖缓慢的马尔可夫链采样，难以借用当时在判别任务上大获成功的反向传播与Dropout。

方法

让两个网络对弈：生成器G把随机噪声变成样本，判别器D判断样本是真是假。G的训练信号完全来自D的梯度，无需写出概率密度，也无需任何采样链。

影响

开创了不需要似然的“隐式生成模型”路线，此后数年GAN是逼真图像生成的主要方法；2021年前后起，扩散模型在多项图像生成基准上超过了它。

背景

2014年，深度学习在分类上已经大获成功（AlexNet），靠的是反向传播、分段线性激活和Dropout。但生成模型——能“画”出新样本的模型（见生成建模的目标）——还停留在另一个世界。

玻尔兹曼机和深度信念网络这类无向图模型要计算归一化常数，训练和采样都依赖马尔可夫链蒙特卡洛（Metropolis采样与MCMC），链混合得慢，样本质量差。变分自编码器VAE刚刚出现，可以用反向传播训练，但需要显式写出似然p(x|z)；用逐像素高斯似然时，生成的图像发糊。噪声对比估计NCE把密度估计转成“区分数据与噪声”的分类问题，但噪声分布是固定的，模型需要能写出密度。

这篇论文的问题是：能不能不写出任何概率密度，只要一个能把噪声变成样本的网络，并且只用反向传播就能训练它？

方法

两个网络。生成器G(z)：输入一个从简单分布（如均匀分布）中抽出的随机噪声向量z，输出一张图。判别器D(x)：输入一张图，输出它来自真实数据的概率。

对弈目标（见对抗训练）：

min_G max_D V(D, G) = E_{x∼数据}[log D(x)] + E_{z}[log(1 − D(G(z)))]

D想把真图判成1、假图判成0，即最大化V；G想让D把假图判成1，即最小化V。训练时交替进行：先更新D一步（论文中k=1），再更新G一步。G的参数通过“G生成 → D打分”这条计算图反向传播得到梯度，D就像一个可学习的损失函数。

理论。固定G时，最优判别器是

D*(x) = p_数据(x) / (p_数据(x) + p_G(x))

代回去，G要最小化的量变成−log 4 + 2·JSD(p_数据 ‖ p_G)，JSD是Jensen–Shannon散度（衡量两个分布差多远，见KL散度）。它在且仅在p_G = p_数据时取到最小值，此时D处处输出1/2——判别器彻底分不出真假。论文还证明，如果G和D容量足够、每步D都能训到最优，这个交替过程会收敛到这个解。

一个实用的改动。训练初期G很差，D很容易把假图判成0，此时log(1 − D(G(z)))的梯度几乎为零，G学不动。论文建议改为让G最大化log D(G(z))：不动点不变，但初期梯度大得多。这个“非饱和”损失成了之后GAN的默认写法。

比喻。G像造假币的人，D像验钞员。验钞员越来越严，造假者也被逼得越来越像，最终假币与真币无法区分。

结果

实验在MNIST、多伦多人脸库TFD和CIFAR-10/100上进行，生成器用ReLU与sigmoid，判别器用maxout并加Dropout。由于GAN没有可计算的似然，作者在生成样本上拟合高斯Parzen窗口来估计测试集对数似然：MNIST上为225±2，高于深度信念网络的138、堆叠收缩自编码器的121和深度生成随机网络的214；TFD上为2057±26，高于DBN（1909）和深度GSN（1890），低于堆叠收缩自编码器（2110）。作者自己也指出这种估计方差大、在高维空间不可靠。样本以今天的标准看分辨率很低，但已经没有VAE那种模糊感，而且是一次前向传播直接生成，不需要马尔可夫链。

后来的发展

GAN很快演化成一个庞大的家族。条件生成：条件GAN、pix2pix条件图像翻译、CycleGAN；架构：DCGAN给出了稳定的卷积配方；训练稳定性：GAN训练技巧与IS、Wasserstein GAN、WGAN-GP梯度惩罚、谱归一化；高分辨率：渐进式增长GAN、BigGAN、StyleGAN系列在人脸上做到了肉眼难辨真伪。评测指标FID与Inception Score也是为GAN发展起来的。它也带来了Deepfake出现这样的社会问题。

2021年扩散超越GAN在ImageNet上报告了优于BigGAN的FID，此后多数大规模图像生成工作转向扩散模型。但“对抗损失”本身仍被大量使用：VQGAN和Stable Diffusion的自编码器用判别器让重建更锐利，对抗扩散蒸馏SDXL Turbo等扩散蒸馏方法用对抗损失把采样压到一两步，语音合成的声码器也普遍用对抗训练。

容易误解的地方

  • GAN训练的是一个博弈而非一个最小化问题。两个损失曲线都不会单调下降，判别器损失低不代表生成器好，常常反而说明生成器已经崩了。
  • 理论保证假设D每一步都训到最优、模型在函数空间里优化；实际中只交替做一步梯度，这些保证都不成立。
  • “模式坍塌”（见模式坍塌与模式覆盖）指G只生成少数几种样本；论文里称为Helvetica场景，并明确列为缺点，不是后来才发现的。

它建立在什么之上

  • 使用
    反向传播1986 · 基础 已核对
    整个方法的卖点：生成器和判别器都只用反向传播训练，生成器的梯度经由判别器回传。
  • 竞争
    深度信念网络2006 · 基础 已核对
    论文实验中的对比对象之一：GAN在MNIST（225对138）和TFD（2057对1909）上的Parzen似然估计都高于DBN；论文也指出DBN同时具有无向和有向模型的计算困难。
  • 竞争
    变分自编码器VAE2013.12 · 生成 已核对
    同期的另一条深度生成路线：VAE有显式似然和编码器但样本模糊，GAN样本清晰但无似然、训练不稳；此后多年两者长期并存。
  • 使用
    Dropout2012.07 · 基础 已核对
    判别器训练时使用Dropout，作者把能直接借用这些判别模型技巧视为该方法的重要优点。
  • 改进
    玻尔兹曼机1985 · 基础 已核对
    不需要配分函数和马尔可夫链采样，一次前向传播即可生成样本，绕开了玻尔兹曼机训练与采样都很慢的问题。
  • 延续
    噪声对比估计NCE2010.05 · 基础 已核对
    NCE用分类器区分数据与固定噪声来估计密度；GAN把“噪声”换成一个可学习、不断逼近数据的生成器。
  • 竞争
    Schmidhuber人工好奇心1991 · RL 待核对
    Schmidhuber认为他1990年代两个网络相互博弈的人工好奇心与可预测性最小化是GAN的先驱，这一归属争议至今仍有讨论。

读懂它需要的概念

生成建模的目标 对抗训练 KL散度 反向传播 多层感知机 博弈论基础与纳什均衡 模式坍塌与模式覆盖

本篇术语

  • 隐式生成模型　只提供一个“采样器”（噪声进、样本出），不提供任何样本的概率值。GAN是最典型的例子。
  • Jensen–Shannon散度　两个分布各与它们平均分布的KL散度取平均，对称且有上界log 2。GAN原始目标在最优判别器下等价于最小化它。
  • 非饱和损失　生成器改为最大化log D(G(z))而不是最小化log(1 − D(G(z)))，在D很自信时仍有足够大的梯度。

怎么学

先补生成建模的目标、KL散度和博弈的基本概念博弈论基础与纳什均衡。读原文第3节（目标函数与算法1）和第4节（最优判别器与全局最优的证明，只有一页多）。然后读Goodfellow的NIPS 2016教程，了解模式坍塌和非饱和损失的来龙去脉。动手：在二维的八个高斯团块上训练一个小MLP GAN，观察生成器在几个团块之间来回跳的模式坍塌现象；再在MNIST上训练，体会判别器和生成器损失为什么都不单调下降。
