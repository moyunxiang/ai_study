PEGASUS摘要预训练

PEGASUS: Pre-training with Extracted Gap-sentences for Abstractive Summarization
2019.12论文延伸ICML 2020Jingqing Zhang, Yao Zhao, Mohammad Saleh, Peter J. Liu · 伦敦帝国学院 / Google Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通用的掩码预训练目标和摘要这个下游任务不太对口，且低资源摘要数据不足。

方法

预训练时把文档中最重要的几个句子整句挖掉，让模型从剩下的内容把这些句子作为一段输出生成出来，形式上很像做摘要。

影响

在12个摘要数据集上取得当时最优，并在只有1000条样本时就超过此前最优结果，证明预训练目标要与下游任务形状相近。

方法

PEGASUS沿用标准的Transformer编码器-解码器，创新在预训练目标「间隔句生成」：从文档中挑出被认为最重要的句子（用ROUGE分数衡量某句与其余部分的相似度来选），把它们从输入中遮掉，解码器需要把这些被遮的句子按顺序生成出来。这相当于模型自己制造了「文档与摘要」的训练对。

摘要称，最佳模型在涵盖新闻、科学论文、故事、说明书、邮件、专利、法案的12个下游摘要任务上，ROUGE都达到当时最优；只用1000条标注样本时，在6个数据集上超过之前的最好结果；人工评测显示在多个数据集上达到与人类相当的水平。

局限与后续

  • 所选的重要句子依赖ROUGE这种表面重合度指标，不一定对应真正的要点。

  • 抽象式摘要仍会出现与原文不一致的内容（幻觉），预训练目标并没有去约束这一点。

它建立在什么之上

  • 改进
    指针-生成器摘要2017.04 · NLP
    模型过度依赖复制：35%的输出句子整句抄原文，生成新n-gram的比例远低于人写摘要，抽象程度有限。
  • 使用
    T52019.10 · LLM
    沿用T5式的大规模编码器-解码器预训练流程和文本到文本微调。
  • 竞争
    BART2019.10 · LLM
    同期的编码器-解码器预训练：BART用通用的文本去噪，PEGASUS则把预训练目标直接对准摘要。

怎么学
