R-FCN检测

R-FCN: Object Detection via Region-based Fully Convolutional Networks
2016.05论文延伸NIPS 2016Jifeng Dai, Yi Li, Kaiming He, Jian Sun · 微软亚洲研究院 / 清华大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

Faster R-CNN在每个候选框上都要单独跑一段子网络，候选框有几百个，这部分重复计算拖慢了速度；而直接把全卷积的分类网络拿来做检测又会丢掉“物体在框里哪个位置”的信息。

方法

让几乎全部计算在整张图上共享：最后一层卷积输出k×k组“位置敏感得分图”，每组只负责物体的一个相对位置（左上、正中……），每个候选框只做一次几乎不花算力的池化和投票。

影响

把两阶段检测器的区域子网络压到几乎为零，在同等精度下比Faster R-CNN快数倍；位置敏感池化的思路后来被实例分割和可变形卷积等工作沿用。

方法

两阶段检测器的矛盾在于：分类网络希望平移不变（猫往右挪一点仍是猫），检测却需要平移敏感（框往右挪一点就该判为不准）。Faster R-CNN的做法是把ResNet切成两半，后半段对每个候选框单独跑一遍，以此恢复位置信息，代价是几百次重复计算。

R-FCN把整个ResNet都留在共享部分，只在最后加一层卷积，为C个类别（加背景）各输出k×k张得分图（例如k=3，一共9张对应“左上、上中、右上……右下”）。对一个候选框，把它也划成k×k格，第(i,j)格只去第(i,j)组得分图上做平均池化——这就是位置敏感RoI池化。9个格子的得分再取平均投票，得到这个框属于各类的分数；框回归用同样的方式另开一组得分图。这样每个候选框的额外计算只剩池化和求平均。

摘要报告用101层ResNet在PASCAL VOC 2007上取得83.6% mAP，测试时每张图170毫秒，比对应的Faster R-CNN快2.5到20倍。

后来的发展

R-FCN是2016–2017年两阶段检测的常用强基线；同一团队把位置敏感思想用到实例分割（FCIS）和可变形卷积的可变形PSRoI池化。随后特征金字塔FPN、Focal Loss与RetinaNet等多尺度和单阶段方法成为主流，R-FCN逐渐退出一线比较。

读懂它需要的概念

分类、检测、分割 卷积层、池化与感受野 锚框与非极大值抑制 IoU与mAP

本篇术语

  • 位置敏感得分图　每张图只回答“物体的某个相对部位（如左上角）是否在这里”，k×k张合起来描述物体的空间布局。

怎么学

先理解Faster R-CNN的RPN和RoI池化，再读R-FCN第2节的位置敏感RoI池化示意图；自己用3×3格子画一个候选框，手算一次投票过程。
