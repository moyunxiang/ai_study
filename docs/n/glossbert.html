GlossBERT释义词义消歧

GlossBERT: BERT for Word Sense Disambiguation with Gloss Knowledge
2019.08论文延伸EMNLP-IJCNLP 2019Luyao Huang, Chi Sun, Xipeng Qiu（邱锡鹏）, Xuanjing Huang（黄萱菁）· 复旦大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统有监督词义消歧为每个词单独训练分类器，很少利用WordNet里每个义项的释义；加入释义的神经方法也没有比经典“词专家”系统好多少，低频义项和没有训练样例的词尤其难。

方法

把词义消歧改写成句对分类：把“含目标词的上下文句子”和“候选义项的WordNet释义”拼成一个句对，交给BERT判断这条释义是否就是该词在此处的意思；所有词共用一个模型。

影响

在英语全词词义消歧的标准评测上超过了此前的最好系统，示范了“用预训练模型加词典知识做WSD”的范式，此后的BEM（双编码器）、EWISER等方法都沿着“上下文与释义匹配”的思路发展。

背景

IMS有监督词义消歧等系统依靠人工特征和每词一个SVM；Lesk词义消歧很早就提出利用词典释义与上下文的重叠，但只是字面匹配。神经方法（如基于双向LSTM并引入释义的GAS）已经尝试融合释义，提升有限。BERT（2018）在句对任务（如自然语言推理）上表现极好，其上下文表示本身就能区分多义词的不同用法。WSD统一评测框架（2017）提供了统一的评测框架。

方法

对句子中的目标词w及其每个候选义项s（来自WordNet），构造一个句对：

[CLS] 上下文句子 [SEP] w : s的释义 [SEP]

标签为1表示s是正确义项，否则为0。论文给出三种变体：

  • GlossBERT(Token-CLS)：用目标词位置的BERT输出做分类；
  • GlossBERT(Sent-CLS)：用[CLS]的输出做二分类；
  • GlossBERT(Sent-CLS-WS)：在Sent-CLS基础上加入“弱监督”信号，在上下文句中给目标词加引号、在释义前写出目标词，以突出目标词。

训练数据是SemCor 3.0，每个标注样例按其候选义项个数展开成多个句对。预测时对所有候选义项打分，取正类概率最高的那一个。因为所有词共享一个模型，没有训练样例的词只要有释义也能消歧。

结果

在SemCor 3.0上微调BERT后，在若干英语全词词义消歧基准数据集上，所提方法超过了当时最好的系统（原文摘要）；其中加入弱监督的Sent-CLS-WS变体整体最好（凭一般了解，具体F1未在此引用）。

后来的发展

GlossBERT之后，BEM（Blevins与Zettlemoyer，2020）用双编码器分别编码上下文和释义以加快推理，ConSeC、ESCHER等方法把WSD进一步表述为抽取或生成问题，英语全词WSD的F1在框架上逐步接近人工一致率。大模型时代，直接提示LLM判断义项也成为一种做法，但基于释义匹配的专用模型在效率和可控性上仍有优势。

局限与后续

  • 每个候选义项都要和上下文拼一次送进BERT，多义词义项多时推理代价成倍增加。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    以BERT为编码器，把词义消歧做成上下文—释义的句对分类。
  • 延续
    Lesk词义消歧1986 · NLP
    继承Lesk“用词典释义与上下文比较”的思想，用深度句对匹配代替字面重叠。
  • 使用
    WordNet1995 · 数据·评测
    候选义项与释义来自WordNet。
  • 改进
    IMS有监督词义消歧2010.07 · NLP
    IMS为每个词训练一个分类器、不用释义；GlossBERT所有词共享一个模型并利用释义，未见过的词也能处理。
  • 使用
    WSD统一评测框架2017.04 · NLP
    在Raganato等的统一评测框架及其数据集上报告结果。

本篇术语

  • 释义（gloss）　词典里对一个义项的简短定义，如WordNet中bank的一个义项“sloping land beside a body of water”。
  • 句对分类　把两段文本一起输入模型，判断它们之间的关系，例如是否匹配。

怎么学

先读IMS有监督词义消歧和BERT → 读本文第3节三种句对构造 → 动手：用NLTK取WordNet释义，为几十个SemCor句子构造上下文—释义句对，微调一个小型BERT做二分类，比较与最常见义项基线。
