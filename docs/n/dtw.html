动态时间规整DTW

Dynamic Programming Algorithm Optimization for Spoken Word Recognition
1978.02论文重要IEEE Trans. ASSP 26(1), 1978Hiroaki Sakoe, Seibi Chiba · 日本电气（NEC）待核对
论文（IEEE） ↗Wikipedia：Dynamic time warping ↗在交互版中打开（演化树、学习进度）

问题

同一个词每次说的快慢不同，元音可能拉长一倍、辅音一闪而过；把输入和模板按帧逐一对齐比较，错位会让距离完全失真。

方法

用动态规划在两段语音的帧之间找一条单调的最优对应路径（时间规整函数），允许某些帧一对多，使对齐后的总距离最小；再对路径加斜率限制，防止为了凑距离而过度拉伸。

影响

让孤立词模板匹配的错误率降到此前最好算法的约三分之二以内，成为1970–80年代商用孤立词识别器的标准算法，也是此后所有“不等长序列对齐”方法的原型。

背景

从贝尔实验室Audrey开始，识别都是把输入与每个词的模板比距离。但人说话的速度不均匀：同一个“seven”，这次元音拉长，下次尾音收得快。如果把两段语音线性拉伸到同样长度再逐帧比，局部的快慢差异仍会导致错位。

1960年代末，苏联的Vintsyuk已提出用动态规划做两段语音的时间对齐，但在西方少有人知；日本、美国也有多个小组各自用了不同的动态规划变体。各家做法不一，缺少对“怎样的规整最好”的系统比较。

方法

设输入语音的特征帧为A = a₁…a_I，模板为B = b₁…b_J，d(i, j)是第i帧与第j帧的距离。寻找一条从(1,1)走到(I,J)的路径，每一步只能向右、向上或向右上走（保证时间单调、不跳帧），使路径上的距离加权和最小。

用动态规划求解：定义g(i, j)为对齐到(i, j)时的最小累计距离，论文推荐的对称形式为

g(i,j) = min{ g(i,j−1) + d(i,j), g(i−1,j−1) + 2·d(i,j), g(i−1,j) + d(i,j) }

对角走一步代价加倍，使三种走法对总长度的贡献一致；最后用g(I,J) / (I+J)作为两段语音的规整后距离。计算量是O(I·J)，例如两段各50帧只需填一张50×50的表。

两个约束：调整窗口只允许路径在对角线附近|i − j| ≤ r的带内，既省计算又排除离谱的对齐；斜率约束规定路径连续横走或竖走若干步后必须走一次对角，避免把一帧拉去匹配一长串帧——这是论文的新贡献，作者通过实验确定了最佳的约束强度。

识别时，输入与词表里每个词的模板都算一次规整距离，取最小者。

结果

摘要报告：对称形式明显优于非对称形式；加入斜率约束并优化后，与其他研究组此前用于孤立词识别的各种动态规划算法比较，新算法的错误数不超过最好的传统算法的约三分之二。

后来的发展

DTW让小词表、特定人的孤立词识别在1970–80年代进入实用（声控拨号、工业指令等）。它的结构——网格上的单调路径加动态规划——被统计方法原样继承：HMM统计语音识别里的Viterbi算法对齐可以看作“用概率模型代替模板”的DTW，这也是HMM在1980年代取代模板匹配的原因之一。

在神经网络时代，“输入和输出长度不等、需要单调对齐”的问题由CTC和RNN-Transducer以可微的方式解决（见输入输出不等长时的对齐），Glow-TTS中的单调对齐搜索也是同类的动态规划。DTW本身至今仍是时间序列相似度的常用基线。

容易误解的地方

  • DTW是一种距离（相似度）计算，不是一个会学习的模型；所有“知识”都在模板里。
  • 动态时间规整的思想并非Sakoe与Chiba最先提出，这篇论文的贡献是系统比较各种形式并给出被广泛采用的优化版本。

它建立在什么之上

  • 改进
    贝尔实验室Audrey1952.11 · 语音
    Audrey式的固定模板对说话快慢敏感；DTW通过非线性时间对齐消除了语速差异的影响。
  • 竞争
    HMM统计语音识别1976 · 语音
    统计路线比DTW模板匹配提出得更早，但直到1980年代算力和数据跟上后才全面取代模板匹配：HMM用概率分布刻画发音变化，不必为每个词每个人存模板。
  • 使用
    动态规划与Bellman方程1957 · RL
    直接运用Bellman的动态规划，把指数多的对齐方式降到网格大小的计算量。
  • 竞争
    Viterbi算法1967.04 · 语音
    同为网格上的动态规划，Viterbi来自通信界并基于概率；在语音中，HMM的Viterbi对齐后来取代了基于模板距离的DTW。

读懂它需要的概念

动态规划 范数与距离 输入输出不等长时的对齐 波形、频谱与梅尔谱 k近邻

本篇术语

  • 时间规整函数　把输入的每一帧映射到模板的某一帧的单调函数，可以看作两段语音之间的“对应关系表”。
  • 斜率约束　限制对齐路径不能长时间只朝一个方向走，防止一帧被拉去匹配很多帧。

怎么学

先确认会动态规划（最好做过编辑距离）。然后读论文第II–III节的对称形式和斜率约束。动手：用numpy写一个DTW，对同一个词说快和说慢的两段MFCC计算对齐路径并画出来，再与线性拉伸后逐帧比的距离对比。
