S2A系统2注意力

System 2 Attention (is something you might need too)
2023.11论文延伸Jason Weston, Sainbayar Sukhbaatar · Meta待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模型的软注意力会被上下文里无关或带倾向的内容带偏：问题里顺口提一句“我觉得答案是X”，模型就更容易附和；数学题里插一句无关的话，正确率就掉。论文开头的例子里，在问某位市长出生地时多写一句别的城市的事，好几个模型的答案都跟着变了。

方法

先让模型自己“挑重点”：第一步用一个指令提示，要求模型把原上下文重写一遍，只保留与问题相关、且不带个人意见的部分，并把背景和问题分开写；第二步只把重写后的上下文交给模型作答。

影响

用纯提示的办法明显减少了附和（谄媚）和被无关信息干扰的问题，把“上下文该放什么”从检索阶段延伸到推理前的自我筛选，是上下文工程和抗干扰推理里常被引用的做法。

背景

Transformer的注意力（见自注意力与多头注意力）会给上下文中出现过的词更高权重，模型训练目标又鼓励它延续上下文，所以无关内容和用户的意见都会渗进回答，这与谄媚行为研究观察到的附和现象一致。作者借用心理学里“系统1（快速、自动）”和“系统2（慢速、刻意）”的说法：普通注意力像系统1，他们想要一个由模型刻意推理来决定“该注意什么”的系统2。

方法

两步法： 1. 重写：给定原始输入x，用零样本提示让指令微调过的模型生成x′，要求提取出对回答有用、无偏见的内容，分成“背景”和“问题”两部分，并去掉诸如“我认为答案是……”这样的意见。 2. 作答：把x′（而不是x）交给模型生成最终回答y。

作者还比较了几种变体：不分开背景与问题、在重写后仍保留原文、只用“请忽略无关内容”这类指令而不重写。结果显示真正重写一遍、并且分离问题的版本效果最好——只靠指令提醒，模型仍会被原文里的干扰带走。

结果（模型为LLaMA-2-70B-chat）：

  • 带意见的TriviaQA事实问答（来自SycophancyEval）：事实正确率从62.8%升到80.3%；
  • 带倾向的长篇论点写作：客观性提升57.4%，几乎不受插入意见的影响；
  • 插入无关句子的数学应用题GSM-IC：准确率从51.7%升到61.3%。

后来的发展

思路简单、可直接用于任何指令模型，后来在RAG的上下文压缩、智能体的上下文管理（例如在长任务中只保留相关信息）等讨论中经常被提到；作者也指出可以把重写后的好答案蒸馏回模型，免去推理时多一步。

局限与后续

  • 重写这一步不一定成功，模型有时会漏掉关键信息或保留了干扰，仍会受虚假关联影响。

  • 要先完整生成一遍重写后的上下文，上下文越长，额外计算越多，相当于多了一次与原文等长的生成。

读懂它需要的概念

自注意力与多头注意力 上下文窗口 幻觉 指令微调与对话模板

本篇术语

  • 系统1 / 系统2　心理学家卡尼曼的说法：系统1是快速直觉的反应，系统2是慢速、需要刻意努力的思考。
  • 谄媚（sycophancy）　模型顺着用户的观点说话，即使用户是错的。

怎么学

先读谄媚行为了解问题 → 读原文图2的重写提示和第2.3节各种变体 → 动手：在几道数学题里插入无关句子，比较直接作答和“先重写题目再作答”的正确率。
