Claude 3

Introducing the next generation of Claude
2024.03模型重要产品发布与模型卡 2024Anthropic来源已核对
官方公告 ↗Claude 3模型卡（PDF） ↗在交互版中打开（演化树、学习进度）

问题

GPT-4发布一年后仍是多数基准上的主要标杆；Claude 2只读文本，官方也承认之前的Claude常有不必要的拒答，而且只有一个尺寸，用户无法在能力、速度和价格之间取舍。

方法

同时推出Haiku、Sonnet、Opus三档模型，全系加入图像输入、20万token上下文，并专门训练减少不必要的拒答。

影响

模型卡中Opus在MMLU、GPQA、HumanEval等多数公开基准上超过GPT-4公布的成绩；三档模型让用户按任务在能力、速度和价格之间取舍。

背景

2023年3月GPT-4发布后，一年间没有哪个模型被普遍认为整体超过它。Gemini 1.0的Ultra在部分基准上领先。Anthropic的上一代Claude 2与100K上下文以10万到20万token的长上下文著称，但只能处理文本；Anthropic在Claude 3公告中也承认，之前的Claude模型常有不必要的拒答，显得缺乏对上下文的理解。另一个现实问题是：所有任务都用同一个大模型，客服、内容审核这类大批量简单任务太贵太慢。

方法

Anthropic没有发表技术论文，模型卡只给出训练的大致做法：在截至2023年8月的公开网页数据、第三方非公开数据、标注数据和内部生成数据上预训练，不使用用户提交的对话；然后用人类反馈和Constitutional AI做对齐——让模型依据一份写明原则的“宪法”评价和修改自己的回答，以此作为强化学习的信号（见人类反馈强化学习）。这一代在宪法中新增了一条来自公众参与项目的原则，要求尊重残障人士。

三档模型。Haiku最便宜（每百万输入/输出token 0.25/1.25美元），官方称不到3秒就能读完一篇约1万token、带图表的arXiv论文；Sonnet价格3/15美元，官方称多数任务下速度是Claude 2和2.1的两倍；Opus价格15/75美元，速度与Claude 2相当。

新能力。全系支持图片输入（照片、图表、PDF页面），输出仍只有文本；上下文20万token，官方称模型能接受超过100万token的输入；明显减少对边界但无害请求的拒答；更擅长按要求输出JSON等结构化格式。

安全评级。按自家负责任扩展政策RSP做了生物、网络和自主复制评估，判定为ASL-2，未达ASL-3阈值。

结果

模型卡中Opus的成绩：MMLU（5-shot）86.8%，GPT-4为86.4%；HumanEval 84.9%，GPT-4为67.0%；GSM8K 95.0%（零样本思维链；GPT-4为92.0%）；MATH（4-shot）61%，GPT-4为52.9%。在2023年11月才发布的GPQA Diamond上，Opus零样本思维链50.4%（10次运行平均），5-shot思维链、32次采样多数投票为59.5%，而GPT-4为35.7%（取自GPQA原论文）；领域专家在这批题目上的正确率为60–80%。大海捞针测试中Opus召回率超过99%，官方称它有时还指出那句“针”像是被人为插进文章里的。

后来的发展

约三个半月后的Claude 3.5 Sonnet（2024-06-21）以Claude 3 Sonnet的价格和速度，在多项评测上超过了Claude 3 Opus。此后Anthropic的各代模型沿用了Sonnet、Opus等档次命名。Claude 3 Sonnet后来也成为可解释性研究的对象：SAE扩展到生产模型在它身上用稀疏自编码器找到了数百万个可解释特征。

容易误解的地方

  • 发布时对比的GPT-4是2023年3月的原版成绩；脚注承认更新的GPT-4 Turbo经过提示优化后报告了更高的分数，“全面超越”要打折扣。
  • “能接受100万token”只是官方称，实际开放的上下文是20万token。
  • 不是推理模型：它没有在回答前生成长思维链的机制，数学竞赛题上与后来的OpenAI o1推理模型差距很大。

局限与后续

  • 最强的Opus价格高（每百万输出token 75美元）且速度慢，大规模使用成本难以承受。

读懂它需要的概念

本篇术语

  • 模型家族分档　同一代同时发布大小不同的几个模型，大模型能力强但贵，小模型便宜快速，用户按任务挑选。
  • Maj@32　同一道题让模型独立回答32次，取出现最多的答案作为最终答案，用多次采样换取更高准确率。
