spaCy

2015.02系统延伸Matthew Honnibal, Ines Montani · Explosion待核对
GitHub ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

NLTK面向教学，Stanford CoreNLP是Java系统，Python工程师想在生产环境里快速做分词、词性、依存和实体识别，缺一个又快又好装的库。

方法

用Python加Cython写一条可配置的处理流水线，自带多语言预训练统计模型，接口围绕Doc/Token对象设计，强调速度和工程可用性。

影响

成为工业界最常用的Python NLP库之一，后来的版本接入深度学习和Transformer，至今仍是做NER、规则匹配和文本预处理的常用工具。

方法

spaCy把一段文本送进一条流水线（pipeline）：先切词（tokenizer），再依次做词性标注、依存句法分析、命名实体识别等，结果都挂在同一个Doc对象上，用户可以按词、句、实体遍历。和偏教学的NLTK不同，它的定位是生产使用：核心用Cython实现以求速度，每种语言只给一套作者认为最好的默认模型，而不是提供许多可选算法。依存分析器采用转移式依存分析一系的转移式方法。

维基百科记载其初版于2015年2月发布；1.0版（2016-10）加入自定义流水线、规则匹配器和训练API；2.0版（2017-11）改用卷积神经网络模型，覆盖7种语言并支持可训练的文本分类组件；3.0版（2021-02）引入基于Transformer的流水线和新的配置训练系统。其底层机器学习库是同一团队的Thinc，可以连接PyTorch、TensorFlow训练的模型。

局限与后续

  • 预训练模型针对固定的实体类型和标注体系，换一个领域或要识别新类型的实体需要重新标注训练。

本篇术语

  • 流水线（pipeline）　把切词、词性、句法、实体识别等步骤串成固定顺序，前一步的输出作为后一步的输入。

怎么学

先了解词性标注、依存分析和命名实体识别分别输出什么；照官方教程加载英文或中文模型，对一段新闻打印每个词的词性、依存关系和实体。
