R2I长记忆世界模型

Mastering Memory Tasks with World Models
2024.03论文延伸ICLR 2024Mohammad Reza Samsami, Artem Zholus, Janarthanan Rajendran, Sarath Chandar · Mila、蒙特利尔大学、蒙特利尔综合理工待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的RL智能体（如DreamerV3）用循环网络做世界模型，难以记住很久以前的观测，也难以把奖励归因到很早之前的动作。

方法

把一类新的状态空间模型（S4系列）放进世界模型，替代原来的循环网络，同时增强长期记忆和长时程信用分配，并借助并行计算加快训练。

影响

在BSuite、POPGym等记忆与信用分配任务上刷新最好成绩，在Memory Maze上超过人类，同时在Atari和DMC上保持与DreamerV3相当的表现，墙钟训练也更快。

方法

DreamerV3的世界模型核心是一个门控循环网络（GRU）：每一步把新观测压进隐状态。这类网络在几百步以后基本记不住早先的信息，于是需要“先看到钥匙颜色、几百步后再选门”的记忆型任务，它就很吃力。

S4结构化状态空间一系列状态空间模型（SSM）把序列建模写成线性的状态递推 h_t = A·h_{t−1} + B·x_t，经过特殊的参数化，能稳定地保留很长距离的信息，而且整条序列可以用并行扫描一次算完。R2I（Recall to Imagine）用这类SSM替换世界模型里的循环网络，并相应调整了训练方式：在真实数据上用并行模式快速计算潜状态，在想象阶段按递推模式一步步展开，让策略在想象轨迹里学习。

实验表明，R2I在BSuite、POPGym这类专门考察记忆和信用分配的任务上达到新的最好成绩，在复杂三维记忆迷宫Memory Maze上超过人类；在不怎么需要记忆的Atari和DMC上与DreamerV3相当，说明改动没有牺牲通用性；墙钟时间上也比DreamerV3收敛更快。

局限与后续

  • 只在模拟基准上验证，长记忆世界模型对真实机器人长时程任务（比如记住物品放在哪）的作用还没有被检验。
    本站还没有记录针对它的后续工作（不代表没有人解决）
