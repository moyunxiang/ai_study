Nesterov加速梯度

A Method for Solving the Convex Programming Problem with Convergence Rate O(1/k^2)
1983论文延伸Soviet Mathematics Doklady 1983Yurii Nesterov · 苏联科学院中央经济数学研究所待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

对光滑凸函数，普通梯度下降要O(1/k)步才能把误差降到某个精度，而且动量法是否真的有加速并没有理论说法。

方法

在“预估位置”处计算梯度并加上动量，证明收敛率达到O(1/k²)，且这已是一阶方法能达到的最优速率。

影响

给了动量一个严格的理论根据，也成为深度学习里Nesterov动量的来源。

方法

目标是最小化一个光滑凸函数。Nesterov的做法是：先沿上一步的速度方向“预走”到一个临时位置，在这个位置而不是当前位置上计算梯度，再用它更新速度和参数：v ← μv − η∇f(θ + μv)，θ ← θ + v。

预走相当于提前看一眼前方，如果动量把你冲得太远，梯度能更早起到刹车作用。理论上，对L-光滑的凸函数，误差随步数以O(1/k²)下降，优于普通梯度下降的O(1/k)，并且匹配一阶方法的下界。深度学习里的非凸情形没有这个保证，但Nesterov动量仍被广泛使用，见随机梯度下降的各种变体。

局限与后续

  • 加速的保证只对光滑凸函数成立，神经网络是非凸、随机梯度的场景，理论不直接适用。
