CogAgent

CogAgent: A Visual Language Model for GUI Agents
2023.12论文延伸CVPR 2024Wenyi Hong, Weihan Wang, Qingsong Lv, Jiazheng Xu, Wenmeng Yu, Junhui Ji, Yan Wang, Zihan Wang 等 · 清华大学 / 智谱AI待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

文字LLM读不懂屏幕；而通用视觉语言模型的输入分辨率只有224到448左右，屏幕上的小图标和小字根本看不清。

方法

做一个180亿参数的视觉语言模型，同时用低分辨率和高分辨率两个图像编码器，支持1120×1120输入，专门理解和操作GUI。

影响

证明只看截图的VLM在网页和手机操作上能超过依赖HTML文本的LLM方法，是视觉GUI智能体的早期开源模型。

方法

CogAgent在CogVLM基础上增加了一个高分辨率交叉注意力模块：低分辨率编码器负责整体理解，另有轻量的高分辨率编码器把1120×1120的图像送入，通过交叉注意力与语言模型交互，这样额外计算量较小，却能读清小字和小控件。摘要称它参数量为18B。

它只用截图作输入：在PC网页的Mind2Web和Android的AITW两个导航基准上，摘要称超过基于抽取HTML文本的LLM方法，并在VQAv2、DocVQA、ChartQA等五个文字密集型和四个通用VQA基准上达到当时最好。后续的SeeClick GUI定位和UI-TARS原生GUI智能体沿着“纯视觉操作GUI”的方向继续。

局限与后续

  • 输出的是动作描述加坐标，坐标精度和对未见界面的泛化有限。
