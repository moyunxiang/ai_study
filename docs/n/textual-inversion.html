文本反演

An Image is Worth One Word: Personalizing Text-to-Image Generation using Textual Inversion
2022.08论文延伸ICLR 2023Gal, Alaluf, Atzmon, Patashnik, Bermano, Chechik, Cohen-Or · Tel Aviv University / NVIDIA待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

想让文生图模型画出“我家的猫”这类特定概念，只能靠文字描述，无法精确指定。

方法

冻结整个模型，只用3–5张图为一个新的“伪词”学习一个词向量，之后可像普通单词一样写进句子。

影响

开启了个性化文生图：不改模型权重，只多出几KB的嵌入文件，被AUTOMATIC1111 WebUI等工具直接支持。

方法

在文本编码器的词嵌入空间里新增一个伪词（如S*）的向量。训练时给图像配上“A photo of S*”之类的提示，只更新这一个向量，让扩散模型用它去噪重建这些图的损失最小（即扩散：前向加噪与反向去噪的标准去噪目标）；所有网络权重保持冻结。

学到的伪词可以与其他词组合，如“S*风格的海报”“S*在海滩上”。论文发现单个词嵌入已足以捕捉物体或风格，并与多种基线比较，在忠实复现概念上更好。方法最初在潜扩散模型上实现。

局限与后续

  • 单个词向量表达力有限，细节和身份保真不如微调整个模型的方法。
