The Pile与开放预训练语料

The Pile: An 800GB Dataset of Diverse Text for Language Modeling
2020.12数据集延伸Gao, Biderman, Black, Golding, Hoppe, Foster, Phang, He et al. · EleutherAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GPT-3的训练数据不开放，开放的大语料多是单一来源的网页抓取，研究者很难复现和研究大模型预训练数据的作用。

方法

把22个来源多样的高质量子集（学术论文、代码、书籍、法律等）合成约825GiB的开放文本语料。

影响

成为GPT-Neo、GPT-J-6B等开放大模型的训练数据，开启开放预训练语料的风气。

方法

The Pile由22个多样的高质量子集组成，既有现成数据集，也有新构建的，很多来自学术或专业来源。论文主张训练数据的多样性有利于通用知识和下游泛化。

据摘要，GPT-2和GPT-3在Pile的许多组成部分（如学术写作）上表现不佳；用Pile训练的模型在所有组成部分上都明显超过只用原始Common Crawl或CC-100训练的模型，同时下游评测也有改进。作者还做了探索性分析，记录数据中可能令人担忧之处，并公开了构建代码。

局限与后续

  • 语料来自许多不同来源，论文自己就记录了数据中值得担忧的方面；版权与授权问题也成为开放语料的争议点。

它建立在什么之上

  • 改进
    维基百科语料2001.01 · 数据·评测
    体量有限（相对网络规模文本），不足以单独支撑大模型的预训练。
  • 改进
    English Gigaword2003 · 数据·评测
    只有新闻文体，且受授权限制，难以反映口语、小说、网页等其他文本。
  • 使用
    Common Crawl与网络规模文本2008 · 数据·评测
    其中一部分来自Common Crawl的网页，并与原始Common Crawl作对照。
  • 改进
    十亿词基准LM1B2013.12 · 数据·评测
    语料以新闻为主，训练在其上的模型换到其他文体会明显变差。
  • 延续
    BooksCorpus2015.06 · 数据·评测
    书籍类数据并不局限于BooksCorpus，而是纳入更多来源的书籍与文本。
  • 改进
    WebText开源复刻OpenWebText2019 · LLM
    规模只有几十GB，比后来的模型所需的万亿token级语料小得多，且与原WebText并不等同，复现结论有保留。

后来的相关工作

  • 使用
    OPT-175B2022.05 · LLM
    训练数据的一部分取自The Pile的若干子集，并对其做了额外去重。
  • 延续
    测试集污染检测2023.10 · 数据·评测
    The Pile这类公开语料可以直接搜索重叠，闭源语料不行；作者把检测从查语料转为查模型概率。
  • 改进
    FineWeb / FineWeb-Edu2024.06 · 数据·评测
    以英文为主，且质量过滤相对粗糙，后来的网页语料在过滤与去重上做得更系统。
  • 使用
    Anthropic 15亿美元版权和解2025.09 · 事件
    起诉书称Anthropic承认用The Pile训练Claude，开放语料中的盗版图书成了诉讼焦点之一。
  • 使用
    GPT-J-6B2021.06 · LLM
    训练数据为EleutherAI自己构建的The Pile。
  • 使用
    CodeGen2022.03 · LLM
    训练数据中包含The Pile，即自然语言部分的来源之一。
  • 使用
    GPT-NeoX-20B2022.04 · LLM
    训练数据仍是The Pile。
  • 使用
    Pythia2023.04 · LLM
    训练数据采用公开的The Pile（以及去重版本）
  • 竞争
    RefinedWeb2023.06 · 数据·评测
    主张纯网页数据可超过The Pile这类精选多源语料。
  • 延续
    Dolma开放语料2024.01 · 数据·评测
    同样的开放混合语料路线，但规模大一个数量级并提供完整处理工具与文档。
  • 竞争
    RedPajama2024.11 · 数据·评测
    The Pile是固定的精选混合，RedPajama-V2提供未过滤原料和质量信号，让用户自行过滤。
  • 延续
    Common Pile开放授权语料2025.06 · 数据·评测
    延续The Pile的开放多源语料思路，但限定为公共领域与开放授权内容。
