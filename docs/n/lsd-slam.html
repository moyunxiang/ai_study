LSD-SLAM直接法

LSD-SLAM: Large-Scale Direct Monocular SLAM
2014.09论文延伸ECCV 2014Jakob Engel, Thomas Schöps, Daniel Cremers · 慕尼黑工业大学待核对
DOI ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

PTAM等特征点SLAM只用少量角点，丢掉了边缘和弱纹理区域的信息；早期直接法又只能做小范围跟踪，无法建大规模地图。

方法

不提特征点，直接比较所有梯度明显的像素的亮度来估计相机位姿和半稠密深度，并用带尺度的关键帧位姿图做大范围闭环。

影响

让单目直接法第一次能在普通CPU上实时建大场景地图，与ORB-SLAM代表的特征点法形成两条主流路线。

方法

LSD-SLAM属于“直接法”：相机位姿不是由匹配的特征点算出来，而是直接最小化两帧之间的光度误差——把当前帧的像素按假设的位姿和深度投到关键帧上，比较亮度差，用类似Lucas–Kanade光流图像对齐的高斯-牛顿迭代求位姿。它只在图像梯度明显的像素（边缘、纹理处）估计深度，得到“半稠密”深度图，并对每个像素维护深度的不确定性，随新帧不断用小基线立体匹配更新。

为了建大规模地图，系统把关键帧连成位姿图，边是7自由度的相似变换（旋转、平移再加一个尺度），这样单目SLAM固有的尺度漂移可以在闭环时被纠正。整个系统在CPU上实时运行。

后来的发展

同一团队2016年的DSO（Direct Sparse Odometry）把直接法改为稀疏点加完整光度标定的联合优化，精度更高；后来的DROID-SLAM把“稠密对齐+光束平差”交给学习的网络来做。

局限与后续

  • 光度误差假设同一点在不同帧亮度不变，遇到自动曝光、强光照变化或快速运动时容易跟丢。
    后来针对它的工作　DROID-SLAM
  • 单目无法得到真实尺度，只能靠闭环把尺度漂移拉回去，没有闭环时轨迹尺度会逐渐偏。
    后来针对它的工作　ORB-SLAM2

  • 延续
    MonoSLAM2007.06 · 视觉
    同属单目实时SLAM，把地图从几十个点扩展到半稠密的大规模场景。
  • 竞争
    PTAM2007.11 · 视觉
    PTAM靠FAST角点做跟踪与建图，LSD-SLAM放弃特征点改用像素亮度直接对齐，信息利用更充分。

读懂它需要的概念

相机模型与多视图几何 梯度下降 雅可比矩阵与海森矩阵 图像作为张量 三维表示：体素、点云、网格、隐式场

本篇术语

  • 直接法　不先提取和匹配特征点，而是直接用像素亮度差作为误差来估计相机运动。
  • 尺度漂移　单目相机分不清“小而近”与“大而远”，长时间运行后估计的轨迹和地图大小会逐渐偏离真实比例。

怎么学

先学相机投影模型和李代数位姿表示，再读论文第3节跟踪与深度估计；运行开源代码在TUM单目序列上与ORB-SLAM对比跟丢情况。
