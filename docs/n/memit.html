MEMIT批量编辑

Mass-Editing Memory in a Transformer
2022.10论文延伸ICLR 2023Kevin Meng, Arnab Sen Sharma, Alex Andonian, Yonatan Belinkov, David Bau · MIT / Northeastern / Technion待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

ROME知识定位与编辑一次只能修改一条事实，而真实场景要同时更新成千上万条过时或新增的知识。

方法

在多层MLP里计算并分摊更新量，直接批量改写权重，而不是重新训练。

影响

把模型编辑从一条扩展到数千条，是知识编辑方向的标志性方法，用GPT-J和GPT-NeoX-20B验证。

方法

背景：模型里的事实可能过时，重新训练或微调太贵。ROME通过定位存储某条事实的MLP层，直接改写一个权重矩阵来写入一条事实，但多次连续编辑会互相破坏。

做法：MEMIT把单条编辑扩展为批量编辑，同时更新一批事实。它选择一组连续层，把每条新事实要求的输出变化分摊到这些层上，用闭式的最小二乘解一次性算出各层的权重修改，不做梯度训练。

结果：论文称在GPT-J（6B）和GPT-NeoX（20B）上可以扩展到数千条关联，比先前工作多出几个数量级。

局限与后续

  • 编辑后的知识容易与相关事实不一致（如改了首都，其相关推断没更新），泛化和连锁推理不可靠。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 多次编辑后模型整体能力可能下降，对更大模型和长期编辑的稳健性缺乏验证。
    本站还没有记录针对它的后续工作（不代表没有人解决）
