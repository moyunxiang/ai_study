逻辑理论家

The Logic Theory Machine: A Complex Information Processing System
1956系统重要IRE Transactions on Information Theory, 1956Allen Newell, Herbert A. Simon, Cliff Shaw · RAND Corporation / 卡内基理工学院待核对
DOI（论文） ↗RAND报告P-868 ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

1950年代的计算机只被当作数值计算器。机器能不能做“非数值”的、需要创造性的思考，比如证明数学定理，没有人真正做出来过。

方法

把定理证明看成在推导树里搜索：从已知公理和定理出发，用代换、分离、前向/后向链接等规则生成子目标，用经验法则（启发式）剪掉不太可能成功的分支。

影响

证明了《数学原理》第2章前52条定理中的38条，被称为第一个AI程序；“推理即搜索”“启发式”“表处理”三个思想成为此后二十年符号AI的基本工具。

背景

图灵已经说明通用机原则上能执行任何按规则的符号操作（图灵：可计算数），香农也设想过让计算机下棋（香农：计算机下棋），但直到1955年，还没有一个程序真的完成过被认为需要智力的任务。

Simon当时是研究组织决策的政治学家，他在RAND看到一台打印机用字母和标点符号打出一张地图，意识到机器操作的符号可以代表任何东西，不一定是数字。Newell则是在1954年听了Selfridge关于模式匹配的报告后，认定简单可编程单元的相互作用可以产生复杂的智能行为。两人加上RAND的程序员Shaw，选定了一个有明确对错标准的任务：证明怀特海与罗素《数学原理》（Principia Mathematica）里的命题逻辑定理。

方法

表达式。每条逻辑公式存成一棵语法树：例如 ¬P → (Q ∧ ¬P) 的根节点是 →，两个子节点分别指向 ¬P 和 Q ∧ ¬P。已证明的定理和公理存在一个列表里。

四种方法。要证明目标公式B时，程序依次尝试：

  • 代换：找一条已知定理，只替换其中的变量或联结词就能得到B；
  • 分离：找一条形如 A → B 的已知定理，然后把“证明A”作为新的子问题；
  • 前向链接：目标是 A → C 时，找已知的 A → B，再去证 B → C；
  • 后向链接：目标是 A → C 时，找已知的 B → C，再去证 A → B。

每次失败都会产生新的子目标，于是形成一棵不断展开的搜索树：根是要证的命题，路径上的每一步都是一次合法推导，找到一条通往已知定理的路径就是一份证明。

启发式。搜索树会指数增长，所以他们借用数学家Pólya的说法，用“经验法则”剪枝，优先尝试看起来更像目标的定理，放弃不太可能成功的分支。

实现。为了在计算机上操作这些树和列表，三人专门写了一种表处理语言IPL。最早的版本甚至是“人肉执行”的：1956年1月，Simon把程序写在卡片上，分给妻子、孩子和研究生，每人扮演程序的一个部件。之后Shaw在RAND的计算机上跑通了它。

结果

程序证明了《数学原理》第2章前52条定理中的38条。对定理2.85它找到了一个比原书更简短的证明，罗素本人看后表示高兴；但投给《符号逻辑杂志》时被拒，理由是“基本定理的新证明不值一提”。

后来的发展

1956年夏天，Newell和Simon在达特茅斯会议上展示了它，反响平平——其他人更关心自己的设想。但它给出的三个思路很快成为主流：推理即搜索（之后发展为通用问题求解器GPS和A*搜索），启发式剪枝，以及用表结构表示符号（直接影响了Lisp语言）。

Simon曾说他们“解决了身心问题”，即一个物质系统可以拥有心智；这一立场后来被Newell和Simon概括为物理符号系统假说，也被Searle称为“强AI”并在中文房间中加以反驳。今天的定理证明程序（Lean证明助手上的AlphaProof达到IMO银牌等）仍然是“生成候选推导步+搜索+剪枝”的结构，只是启发式换成了神经网络。

容易误解的地方

  • 它证明的是命题逻辑里相对初等的定理，不是一般数学；“新证明”的意义在于展示机器的创造性，而非数学价值。
  • “第一个AI程序”是常见说法，但同期的Samuel跳棋程序等程序也在探索类似问题；Logic Theorist的特殊之处在于它刻意模仿人做推理。

局限与后续

  • 搜索树指数增长，靠手写的经验法则剪枝，只能证明短小的定理，更长的证明会陷入组合爆炸。

  • 四种方法只为命题逻辑定理设计，换一个领域就要重写，没有通用的问题求解框架。
    后来针对它的工作　通用问题求解器GPS
  • IPL接近汇编，编写和修改符号程序非常费力。

  • 启发式全靠人设计，程序不会从过往证明中学到哪条路更有希望。

本篇术语

  • 启发式　不保证正确但通常有效的经验法则，用来决定先搜哪条路、放弃哪条路，以避免穷举。
  • IPL　Information Processing Language，Newell、Shaw和Simon为Logic Theorist开发的表处理语言，以链表存储符号结构。
  • 《数学原理》　怀特海与罗素1910–1913年出版的巨著，试图从少数逻辑公理出发推出全部数学。

怎么学

先补命题逻辑、谓词逻辑与符号推理和图、树与搜索。读Wikipedia词条的Architecture一节，弄清四种方法。动手：用Python写一个只含代换与分离的小证明器，用《数学原理》第2章的五条公理去证明 p → p，观察搜索树规模如何膨胀，再加一条“优先选与目标结构相似的定理”的启发式比较。
