Ramanujan Machine

The Ramanujan Machine: Automatically Generated Conjectures on Fundamental Constants
2019.06论文延伸Nature 2021Gal Raayoni, Ido Kaminer 等 · 以色列理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

数学常数的公式长期靠天才直觉发现，缺少系统化生成猜想的方法。

方法

用算法大规模枚举连分数形式的公式，只要数值上与常数吻合到足够多位就提出猜想，不需要事先的数学理论。

影响

自动生成了一批新的常数猜想，其中一些后来被证明，展示机器可以辅助数学猜想的发现。

方法

系统用两种方法：一是“中间相遇”算法，分别枚举连分数的两部分并比较数值；二是梯度下降，在整数系数空间中搜索。找到数值上吻合π、e、Catalan常数或黎曼ζ函数值的连分数，就记录为猜想。它不产生证明，因此叫“猜想机器”。

作者认为这种数值、数据驱动的方式可以揭示数学结构、提示新的研究方向，论文后来发表在Nature（2021年）。
