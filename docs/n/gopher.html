Gopher

Scaling Language Models: Methods, Analysis & Insights from Training Gopher
2021.12论文重要Jack W. Rae, Sebastian Borgeaud, Trevor Cai, Katie Millican, Jordan Hoffmann, Francis Song, John Aslanides, Sarah Henderson et al. · DeepMind待核对
arXiv ↗DeepMind博客：Language modelling at scale ↗在交互版中打开（演化树、学习进度）

问题

GPT-3之后，“把模型继续做大”到底能换来什么、换不来什么，缺少一个在上百个任务上系统比较、并公开训练细节的研究。

方法

训练从4400万到2800亿参数的6个模型，统一用自建的10.5TB语料MassiveText和3000亿token，在152个任务上逐项比较规模带来的收益，并分析毒性和偏见。

影响

2800亿参数的Gopher在可比较的任务中约81%超过此前最好的语言模型，MMLU从GPT-3的43.9%升到60.0%；同时发现数学和逻辑推理几乎不随规模变好。

背景

GPT-3和语言模型的规模定律让业界相信：参数越多，效果按幂律持续变好（见幂律与规模定律）。2021年下半年，Jurassic-1等1750亿级模型相继出现，但大多只报告少数基准。几个关键问题仍不清楚：规模的收益在不同类型的任务上是否一样？数据的质量有多重要？模型变大后，生成有害内容的倾向是变好还是变坏？DeepMind的这篇长篇报告想用一个模型家族、一套数据、一大批任务把这些问题量化出来。

方法

模型。沿用GPT-2式的自回归Transformer，改了两处：用RMSNorm代替LayerNorm；用Transformer-XL的相对位置编码代替绝对位置编码。6个尺寸从44M到280B，最大的Gopher有80层、128个头、隐藏维度16384。所有模型都训练3000亿token、上下文2048，用Adam加余弦学习率衰减；Gopher的批大小在训练中从300万token增大到600万。

数据MassiveText。共23.5亿篇文档、约10.5TB，来自网页（MassiveWeb）、书籍、新闻、C4、GitHub代码和维基百科，按调好的比例采样（网页48%、书籍27%）。网页部分经过质量过滤（例如必须含有the、and等常见词中的至少两个）、去除大量重复的文本、相似文档去重，并删去与测试集重叠的文档。作者验证了每一步过滤都让下游效果变好。

工程。用JAX在TPUv3上训练。半精度参数加单精度Adam状态共2.5TiB，每个TPUv3核心只有16GiB，所以组合使用优化器状态切分（来自ZeRO与DeepSpeed）、模型并行和重计算。

评测。152个任务，包括语言建模、阅读理解、事实核查、常识、MMLU的57个学科和BIG-bench的62个任务。

结果

在有可比结果的124个任务中，Gopher在100个（约81%）上超过GPT-3、Jurassic-1、Megatron-Turing NLG等此前最好的结果。MMLU五样本平均60.0%，GPT-3为43.9%；高中阅读理解RACE-h从47.9%升到71.6%。与同家族7.1B模型相比，51%的任务提升超过25%，但约10%的任务没有任何提升；收益最大的是阅读理解、事实核查和毒性识别，数学和逻辑推理收益很小，部分题目上甚至不如小模型。毒性方面：给有毒的提示时，模型越大越容易生成有毒续写，但识别毒性也越准。

后来的发展

仅仅三个多月后，同一团队的Chinchilla指出：Gopher和GPT-3这样的模型参数太多、训练数据太少，用Gopher的算力训一个70B的模型、喂4倍数据，全面更好。MassiveText和它的过滤流程被Chinchilla、RETRO沿用，“精心过滤网页数据”后来成为FineWeb / FineWeb-Edu等开源数据集的核心。Gopher本身没有公开权重；“规模不足以带来推理能力”的结论，则被随后的思维链CoT部分改写——推理能力需要换一种提示方式才能被引出。

  • 使用

  • 延续
    GPT-32020.05 · LLM
    同样是只有解码器的自回归模型，规模从175B做到280B，并把评测从几十个任务扩到152个。
  • 使用
    RMSNorm2019.10 · 基础
    用更省计算的RMSNorm替代LayerNorm，这一改动后来被LLaMA等主流模型继承。
  • 使用
    MMLU2020.09 · 数据·评测
    在57个学科的MMLU上把五样本准确率从GPT-3的43.9%提到60.0%。
  • 使用
    Transformer-XL2019.01 · LLM
    采用其相对位置编码，以便在比训练更长的文档上评估。
  • 竞争
    Jurassic-12021.08 · LLM
    同期的178B模型；Gopher在多数可比任务上超过它，但两者都没有回答“参数和数据该怎么分配”。

本篇术语

  • MassiveText　DeepMind为训练Gopher自建的英文语料集合，包含网页、书籍、新闻、代码和维基百科，经过多级质量过滤和去重。
  • 质量过滤　用一组简单规则（文档长度、符号比例、是否含常见英文词、重复片段比例等）丢弃低质量网页，比直接用全部爬取文本训练效果更好。

怎么学

先懂幂律与规模定律和参数量、计算量与显存。读原文第3节（模型、训练、MassiveText）和第4节的图2、表5（MMLU），附录A的数据过滤规则值得细看。动手：写一个脚本，按论文的“停用词至少两个”“重复n-gram比例”规则过滤一小批Common Crawl网页，人工检查被删掉的是什么。
