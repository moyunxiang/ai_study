马尔可夫博弈

Markov Games as a Framework for Multi-Agent Reinforcement Learning
1994论文延伸ICML 1994Michael L. Littman · 布朗大学待核对
ICML 1994（网站首页，未取得具体文章链接） ↗在交互版中打开（演化树、学习进度）

问题

强化学习假设环境固定，但多智能体里对手本身也在行动，需要新的数学框架。

方法

用马尔可夫博弈（随机博弈）统一描述：多个玩家在状态里同时选动作，由联合动作决定奖励与转移；并提出对零和博弈的minimax-Q算法。

影响

为多智能体强化学习提供了标准的理论框架，把MDP推广为多人博弈。

方法

据维基百科，随机博弈（马尔可夫博弈）由Shapley在1950年代初引入，是MDP对多个决策者的推广：每个阶段处于某个状态，玩家同时选动作，奖励与下一状态取决于所有人的动作。Littman在1994年的论文中把这个框架带进强化学习，并给出minimax-Q：把Q-learning更新里的“最大化”换成在当前状态的两人零和矩阵博弈里求极小极大值，学到的策略在最坏对手下最优。

在小型足球游戏里，他比较了minimax-Q与普通Q学习，前者面对不同对手更稳健。

后来的发展

该框架是多智能体强化学习的出发点，后续神经虚拟自我对弈NFSP、PSRO博弈论元求解、MADDPG在深度网络下处理更一般的情形。
