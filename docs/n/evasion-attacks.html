测试时规避攻击

Evasion Attacks against Machine Learning at Test Time
2013.09论文延伸ECML PKDD 2013Biggio, Corona, Maiorca, Nelson, Srndic, Laskov, Giacinto, Roli · 卡利亚里大学 / 图宾根大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

垃圾邮件、恶意文件检测等系统部署后，攻击者会修改样本来躲过分类器，但缺乏系统评估分类器抗躲避能力的方法。

方法

提出基于梯度的规避攻击：在攻击者知识（完全知道或只知道替代模型）和修改能力不同的设定下，沿分类器得分梯度修改样本，直到被判为正常。

影响

是对抗样本研究的先驱，比对抗样本和FGSM与线性解释早，并且已经包含神经网络和SVM。

方法

论文把攻击者形式化为：给定一个已部署的分类器f和一个恶意样本x，找到最接近的x'使f(x')被判为正常，且保持恶意功能。作者用梯度下降最小化分类器的判别函数，同时加上一项让x'落在训练数据密度较高的区域，使得修改后的样本看起来像正常样本。

他们区分了攻击者的知识（完美知识 vs 有限知识，后者用自己的替代数据训练一个替代分类器，再把攻击迁移过去）和能力，据此模拟不同风险级别。实验针对手写数字和PDF恶意软件检测，分类器包括SVM和神经网络（参见摘要所述「several widely-used classification algorithms」）。

要点是：攻击者不需要知道目标模型的内部，也能通过替代模型成功。这篇论文2013年发表于ECML PKDD，arXiv上的版本迟至2017年才上传。

局限与后续

  • 论文主要针对低维特征的传统分类器；对高维图像上的深度网络，攻击为何如此容易没有解释。
