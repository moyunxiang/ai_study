OpenAI Model Spec

Introducing the Model Spec
2024.05思想延伸OpenAI待核对
OpenAI公告 ↗2024-05-08版全文 ↗在交互版中打开（演化树、学习进度）

问题

模型该怎样行事，规则散落在训练数据标注说明和使用政策里，外界无法讨论，也很难看出一个行为是出于设计还是出于bug。

方法

公开一份文件，把模型的目标、必须遵守的规则和可调整的默认行为分层写清，并说明指令冲突时听谁的。

影响

让“模型规范”成为一种文体：此后行业里出现了类似文件，OpenAI也据此提出审慎对齐。

方法

2024年5月8日OpenAI发布了Model Spec的初稿，说明它是针对API和ChatGPT中模型期望行为的规范，包括一组核心目标，以及如何处理相互冲突的目标或指令。OpenAI说，它的用途是为研究者和数据标注员提供指引，用于人类反馈强化学习的数据制作；初稿尚未按现有形式直接用于训练，正在研究让模型直接从规范中学习的技术。

文件把内容分成三层：目标（如帮助用户、造福人类）、规则（如遵循指挥链、遵守法律、不提供信息危害、保护隐私、不输出NSFW内容）和默认行为（如假设用户善意、必要时提问、保持客观立场、表达不确定性）。其中“遵循指挥链”规定平台、开发者、用户的指令发生冲突时的优先顺序。OpenAI称将根据反馈持续更新。

局限与后续

  • 规范是自然语言写的，条目之间会冲突，如何让模型可靠地内化并遵循并未在这份文件里解决。
