TSN时间片段网络

Temporal Segment Networks: Towards Good Practices for Deep Action Recognition
2016.08论文延伸ECCV 2016Limin Wang, Yuanjun Xiong, Zhe Wang, Yu Qiao, Dahua Lin, Xiaoou Tang, Luc Van Gool · 苏黎世联邦理工 / 香港中文大学 / 中科院深圳先进院待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

双流网络只看单帧和短段光流，抓不住持续几秒的动作结构；而视频训练集又小，深网络容易过拟合。

方法

把整段视频均分成K段，每段随机抽一小片输入共享权重的双流网络，再把各段的预测取平均作为整段视频的预测来训练。

影响

稀疏时间采样加段级共识成为视频识别的标准训练方式，后来的TSM、SlowFast等工作沿用了这种采样。

方法

TSN的核心是“稀疏采样+视频级监督”。一段视频先等分成K段（论文常用K=3），每段随机取一帧RGB或一小叠光流，K个片段送进同一个卷积网络（权重共享），得到K组类别分数；再用一个“段共识”函数（最简单的是平均）合成整段视频的分数，损失在这个视频级分数上计算。这样每次前向只算K个片段，成本与单片段相近，但梯度来自覆盖整段视频的信息。

论文还总结了一组在小数据上训练视频网络的“好做法”：用ImageNet预训练初始化光流网络、部分冻结Batch Normalization统计量、加dropout、角点裁剪与尺度抖动等增强，并尝试RGB差分和扭曲光流作为额外输入。骨干采用带BN的Inception（GoogLeNet / Inception系列）。摘要报告在HMDB51上69.4%、UCF101上94.2%的准确率。

局限与后续

本篇术语

  • 段共识　把一段视频里多个片段各自的预测合并成一个结论的函数，如取平均或取最大。
