层次softmax语言模型

Hierarchical Probabilistic Neural Network Language Model
2005论文延伸AISTATS 2005Frederic Morin, Yoshua Bengio · Université de Montréal待核对
PMLR ↗在交互版中打开（演化树、学习进度）

问题

神经概率语言模型的输出层要对整个词表做softmax，词表有几万词时训练和推断都被这一层拖慢。

方法

把词表组织成一棵二叉树，预测一个词变成沿着树从根走到叶子的一串二选一决策，每个决策是一个小的二分类。

影响

把输出层代价从词表大小降到词表大小的对数，后来被word2vec采用，是让词向量训练能扩展到海量语料的关键技巧之一。

方法

普通softmax要为每个可能的下一个词算一个分数并归一化，代价与词表大小成正比。这里把词放在二叉树的叶子上，每个内部节点有一个参数向量。要计算某个词的概率，沿着从根到该叶子的路径，在每个内部节点做一次“往左还是往右”的二分类（sigmoid），然后把路径上各步的概率相乘。

平衡的树深度约为词表大小的对数，所以每次只需计算十来个而不是几万个内部节点。论文的特点之一是用WordNet的词汇层次来构造这棵树，让语义相近的词共享路径前缀；后来的工作也常用按词频构造的霍夫曼树。

代价是概率的计算依赖树的设计，树建得不好会损失精度，但换来的速度提升使大词表训练成为可能。

局限与后续

  • 树的结构要预先设计，效果依赖树的质量；用外部资源（如WordNet）建树也不一定最优。
    后来针对它的工作　Skip-gram负采样
  • 推断时要得到完整的词分布仍需遍历全部叶子，只加速了单个词概率的计算。
    后来针对它的工作　Skip-gram负采样

  • 使用
    word2vec2013.01 · NLP 已核对
    输出层用霍夫曼树组织的层次softmax，把每个样本的输出计算从V降到约log₂V。
  • 竞争
    Skip-gram负采样2013.10 · NLP
    两种替代全词表softmax的方案：负采样在词类比上更好更简单，层次softmax配合下采样在短语任务上最好；此后负采样成为默认。
  • 竞争
    探索语言模型的极限2016.02 · NLP
    层次softmax是另一种解决大词表的方案，论文选择了基于采样的近似。

本篇术语

  • 层次softmax　把词表放在二叉树的叶子上，用从根到叶的一串二分类概率相乘代替全词表归一化。

怎么学

先理解softmax的计算量；画一棵8个词的二叉树，手算某个词的路径概率；再看word2vec里它的用法。
