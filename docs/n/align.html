ALIGN

Scaling Up Visual and Vision-Language Representation Learning With Noisy Text Supervision
2021.02论文延伸ICML 2021Jia, Yang, Xia, Chen, Parekh, Pham, Le, Sung, Li, Duerig · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉与图文表示依赖精心清洗的标注数据，成本高，数据规模难以放大。

方法

不做任何清洗，直接用超过十亿对网页图片和替代文本（alt-text）训练一个简单的双塔对比模型，用规模抵消噪声。

影响

说明足够大的噪声数据加简单对比损失就够，与同期CLIP证实了同一方向，并在多项检索基准刷新纪录。

方法

模型是双塔：一个图像编码器和一个文本编码器，各自输出一个向量，用归一化的内积与余弦相似度作为相似度。训练时在一个大批量内，把真正配对的图文当正例，其余所有组合当负例，对称地计算交叉熵（即对比学习）。

与此前用Conceptual Captions这类经过过滤的数据集不同，作者直接使用超过10亿条的图片与alt-text对，不做昂贵过滤，只做简单的频率清洗。摘要称，这个简单的双塔对比学习在图文检索（如Flickr30K、MSCOCO）上达到当时最好，在ImageNet上通过线性或零样本的方式也获得强成绩，并支持用图加文字的组合查询。

它建立在什么之上

  • 延续
    SimCLR2020.02 · 视觉
    沿用大批量对比学习，但把两个增强视图换成图像和文字。
  • 改进
    DeViSE视觉语义嵌入2013.12 · 多模态
    视觉网络和词向量分别预训练、只在一层线性映射上对接，两种模态没有联合训练。
  • 改进
    图文联合嵌入VSE2014.11 · 多模态
    训练规模只有几万张带人工描述的图，空间的泛化有限。
  • 改进
    Conceptual Captions2018.07 · 数据·评测
    规模在三百万量级，远小于后来的数亿到数十亿图文对。
  • 改进
    nocaps2018.12 · 数据·评测
    训练数据仍被限定为 COCO 加检测标注，没有让模型接触海量的网络图文，后来的图文预训练模型绕开了此限制。
  • 改进
    LXMERT2019.08 · 多模态
    预训练数据靠已有的人工标注数据集，规模有限。
  • 改进
    ViLBERT2019.08 · 多模态
    只在数百万量级的图文对上预训练。
  • 改进
    VisualBERT2019.08 · 多模态
    预训练规模较小，只用图像描述数据。
  • 改进
    UNITER2019.09 · 多模态
    区域特征与文字的对齐仍靠监督信号，没有利用海量噪声网络图文。
  • 改进
    OSCAR2020.04 · 多模态
    预训练规模仅数百万图文对。
  • 改进
    VinVL2021.01 · 多模态
    视觉词汇受限于检测数据集预设的类别集合，检测器没见过的概念无法表示。

后来的相关工作

  • 使用
    Flamingo2022.04 · 多模态 已核对
    训练数据包含ALIGN的18亿图文对。
  • 竞争
    LAION-5B2022.10 · 数据·评测
    ALIGN用超过10亿对几乎不过滤的噪声数据，LAION用CLIP做过滤；两者都表明规模可以弥补噪声，但只有LAION公开。
  • 延续
    SimVLM2021.08 · 多模态
    同样依赖大规模弱标注网络数据，但用生成目标替换对比目标。
  • 改进
    BLIP2022.01 · 多模态
    alt-text噪声大，模型对计数、空间关系等细节理解弱。
  • 使用
    CoCa2022.05 · 多模态
    沿用大规模噪声图文对作为数据。
  • 改进
    OpenCLIP复现2022.12 · 多模态
    数据与模型均未公开，外界无法复现。

读懂它需要的概念

对比学习 嵌入向量 内积与余弦相似度 零样本与少样本 幂律与规模定律

怎么学

先读SimCLR和CLIP，再读原文第3节，对比ALIGN与CLIP在数据规模和清洗上的差别。
