PhotoMaker人像定制

PhotoMaker: Customizing Realistic Human Photos via Stacked ID Embedding
2023.12论文延伸CVPR 2024Zhen Li, Mingdeng Cao, Xintao Wang, Zhongang Qi, Ming-Ming Cheng, Ying Shan · 南开大学 / 腾讯ARC Lab / 东京大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

生成“某个具体的人”的新照片时，DreamBooth与个性化这类测试时微调要为每个人训练几分钟到几十分钟，免训练的图像提示方法又常常保不住身份；高效、身份保真和文本可控三者难以同时满足。

方法

把任意张同一人的照片分别编码，与文本中代表这个人的类别词（如“man”）的嵌入融合，再把这些融合结果堆叠成一个“堆叠ID嵌入”，替换原来那个词的位置送进文生图模型，不需要为每个人微调。

影响

成为开源人像定制的常用方案之一，与InstantID单图保ID等同期工作一起把“上传几张照片、几秒内生成不同场景的同一个人”变成普遍可用的功能；堆叠嵌入还能混合不同人的特征。

方法

PhotoMaker基于SDXL，核心是如何把“这个人是谁”以文本嵌入的形式交给模型：

  • 对输入的N张同一人的照片（数量可变），各自用CLIP图像编码器提取嵌入。
  • 在文字提示里，用户用一个触发词标出要定制的人（例如“a man img”）。取出类别词“man”的文本嵌入，分别与每张照片的图像嵌入用多层感知机融合，得到N个融合嵌入。
  • 把这N个嵌入沿序列方向堆叠起来，替换提示中那个类别词的位置。文生图模型的交叉注意力于是能同时看到这个人在多张照片里的特征。

训练只更新图像编码器的部分层、融合模块和U-Net中的LoRA参数。为此作者构建了一条以身份为中心的数据构建流水线，收集同一人的多张照片并配上描述。推理时不需要任何微调，几秒即可得到结果。论文报告身份保持能力优于基于测试时微调的方法，同时速度显著更快，并展示了改变年龄、性别、艺术风格，以及把两个人的特征混合等应用。
