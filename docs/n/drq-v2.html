DrQ-v2

Mastering Visual Continuous Control: Improved Data-Augmented Reinforcement Learning
2021.07论文延伸ICLR 2022Denis Yarats, Rob Fergus, Alessandro Lazaric, Lerrel Pinto · New York University, Facebook AI Research待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

DrQ等数据增强方法让无模型RL能直接从像素学习简单的DMC任务，但最难的人形机器人运动等任务从像素仍学不会；基于模型的DreamerV2能做得更好，计算却昂贵。

方法

保留DrQ的随机平移增强，把底层算法从SAC换成DDPG，加上n步回报、按计划衰减的探索噪声、更大的回放池等一系列朴素但关键的改动。

影响

第一次用无模型方法从像素解决DMC的人形机器人运动任务，多数任务在单块GPU上约8小时训完，成为视觉连续控制里最常用的高效基线，后来也是许多视觉机器人RL工作的默认底座。

背景

图像增强DrQ与同期的RAD数据增强RL表明，只要对图像观测做随机平移、裁剪之类的增强，SAC这样的简单算法就能在像素输入的DeepMind Control Suite任务上追平带辅助损失的复杂方法（如CURL对比表征RL）。但在“困难”一档任务上，例如人形机器人行走与奔跑，DrQ依然学不会；DreamerV2这类基于世界模型的方法有进展，但训练成本高、实现复杂。作者想知道，一个简单的无模型方法还能走多远。

方法

DrQ-v2的改动都很朴素：

  • 换算法：从SAC改为DDPG（带TD3式的截断双Q），去掉熵项；作者发现在像素任务上，熵自动调节会让探索不稳定。
  • n步回报：价值目标使用 y = Σ_{i=0}^{n−1} γ^i r_{t+i} + γ^n min_j Q_j(s_{t+n}, a′)（n取3），加快奖励信号传播。
  • 探索噪声调度：动作上加高斯噪声 a = π(s) + ε, ε ∼ N(0, σ²)，σ按线性计划从大到小衰减，前期多探索、后期精细控制。
  • 增强：图像四周填充4像素后随机平移，并用双线性插值使平移更平滑。
  • 工程：更大的回放池（一百万）、更小的批量调整、更快的数据加载与混合精度。

编码器只由评论家的梯度训练，演员使用停止梯度后的特征。

结果

摘要称：DrQ-v2在DeepMind Control Suite上取得最先进结果，尤其能直接从像素观测解决复杂的人形机器人运动任务，这是此前无模型RL达不到的；方法概念简单、易于实现，计算开销明显小于以往工作，多数任务在单GPU上只需训练8小时。

后来的发展

DrQ-v2成为视觉RL和视觉机器人学习的默认强基线：后续的表示预训练研究（用ImageNet或人类视频预训练编码器）常在它上面替换编码器做比较；它的代码也被URLB无监督RL基准等基准用作底层实现的参考。

本篇术语

  • n步回报　价值目标先累加n步真实奖励，再接上第n步之后的价值估计，比单步目标更快地传播奖励。
  • 随机平移增强　把图像四周补边后随机裁回原尺寸，相当于把画面平移几个像素，让网络对小位置变化不敏感。

怎么学

先读图像增强DrQ和DDPG；读原文第3节逐项改动和消融实验；用开源代码在walker_walk上训练，分别关掉n步回报和噪声调度，看各自影响多大。
