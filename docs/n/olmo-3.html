Olmo 3完全开放模型

Olmo 3
2025.11论文延伸Team Olmo（Allyson Ettinger, Amanda Bertsch, Bailey Kuehl, David Graham, David Heineman, Dirk Groeneveld et al.） · Allen Institute for AI（Ai2）待核对
arXiv ↗Ai2博客 ↗在交互版中打开（演化树、学习进度）

问题

开放权重模型通常只给权重，数据、中间检查点和训练代码不公开，研究者无法追溯模型能力从哪来、复现整个流程。

方法

把7B和32B模型的整个“模型流”全部公开：每个训练阶段的数据、检查点、代码和依赖，包括推理版Think和RL Zero。

影响

Olmo 3 Think 32B被Ai2称为当时最强的完全开放推理模型，成为研究预训练、中期训练和RLVR的常用可复现底座。

方法

OLMo完全开放模型开创了“连数据一起开放”的做法，Tülu 3开放后训练公开了后训练配方。2025年11月20日发布的Olmo 3把两者合起来，并加入推理模型：Base（7B、32B）、Think（7B、32B，推理模型）、Instruct（7B，对话与工具调用）和RL Zero（7B，从基座直接做数学、代码、指令和对话的强化学习）。

预训练语料Dolma 3约9.3T token，实际预训练配比约5.9T，之后有中期训练（Dolmino）和长上下文（Longmino）阶段，基座在约65K长度上保持质量。后训练数据集Dolci分别给出SFT、DPO和RLVR的配比；强化学习部分吸收了DAPO和Dr. GRPO与R1-Zero再审视的若干改动。配套的OlmoTrace能把模型输出实时追溯到训练数据。

Ai2称Olmo 3 Think 32B与Qwen3混合思考 32B相当，而训练token约少6倍；12月的Olmo 3.1进一步加强了Think和Instruct的32B版本。

局限与后续

  • 完全开放模型在规模上停在32B，与前沿开放权重模型（数百B的MoE）仍有明显差距。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    DAPO2025.03 · 推理·智能体
    强化学习采用DAPO提出的若干GRPO改进。
  • 竞争
    Qwen3混合思考2025.04 · LLM
    以Qwen3 32B为主要比较对象；Qwen只开放权重，Olmo开放全流程。
  • 延续
    OLMo完全开放模型2024.02 · LLM
    同一系列的第三代，从开放基座扩展到开放推理模型和完整模型流。
  • 延续
    Tülu 3开放后训练2024.11 · LLM
    继承Tülu 3的开放后训练流程，并加入RLVR推理训练。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
