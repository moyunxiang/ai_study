PETS概率集成模型

Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models
2018.05论文延伸NeurIPS 2018Chua, Calandra, McAllister, Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的RL样本效率高，但用深度网络当动力学模型时，最终性能常不如无模型方法，原因是模型误差被规划放大。

方法

用一组神经网络（概率集成）预测下一状态的分布，既表达数据噪声又表达模型自己的不确定，再用采样轨迹做在线规划。

影响

证明深度模型也能达到无模型方法的渐近性能，并用少得多的样本；成为后来MBPO等的模型基础。

方法

模型是B个独立初始化的网络，每个输出高斯分布（均值和方差）。方差捕捉环境本身的随机性，不同网络之间的分歧捕捉「数据不够所以不确定」。规划时从当前状态出发，用模型对每个候选动作序列采样多条轨迹，每条轨迹随机挑一个集成成员往前推，累计奖励后用交叉熵方法选出最好的动作序列，只执行第一步，然后重新规划（模型预测控制）。

摘要称在若干基准上渐近性能与无模型方法相当，且在half-cheetah上所需样本比SAC少8倍、比PPO少125倍。

局限与后续

  • 每个决策点都要做大量采样规划，推理开销高，难以用于高维动作或要求实时的场景。
    后来针对它的工作　TD-MPC
  • 只在状态维度较低的任务上验证，直接用于像素观测不成立。
    后来针对它的工作　Dreamer

它建立在什么之上

  • 改进
    模型预测控制MPC1980 · 具身·世界模型 已核对
    需要准确的预测模型；DMC的线性阶跃响应只适合近似线性的慢过程，接触、摩擦、图像输入这类问题写不出模型。
  • 改进
    Dyna：学习与规划合一1990 · RL
    学到的模型一旦有误差，规划会利用这些错误，论文只在确定性小迷宫上验证，没有处理模型偏差。
  • 延续
    PILCO2011 · RL
    用神经网络集成近似PILCO式的不确定性建模，摆脱高斯过程难以扩展到大数据的限制。

后来的相关工作

  • 改进
    Dreamer2019.12 · 具身·世界模型
    只在状态维度较低的任务上验证，直接用于像素观测不成立。
  • 延续
    MBPO2019.06 · RL
    沿用PETS的概率集成模型，但把模型用于生成短轨迹训练策略而非在线规划。
  • 改进
    TD-MPC2022.03 · RL
    每个决策点都要做大量采样规划，推理开销高，难以用于高维动作或要求实时的场景。
