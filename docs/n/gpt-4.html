GPT-4

GPT-4 Technical Report
2023.03模型主干技术报告（arXiv 2303.08774）OpenAI（技术报告署名Achiam, Adler, Agarwal et al.，共两百多人）来源已核对
arXiv：GPT-4 Technical Report ↗OpenAI发布页（存档） ↗OpenAI Evals ↗在交互版中打开（演化树、学习进度）

问题

GPT-3.5级别的ChatGPT在模拟律师考试上只到考生后10%左右，还常胡编；而且训练一个更大的模型花费巨大，事先无法知道练出来会是什么水平。

方法

继续扩大预训练规模并配合RLHF，同时先建立一套“可预测扩展”的基础设施：用算力最多少一千到一万倍的小模型拟合规模定律，提前算出大模型的最终损失和部分指标。

影响

模拟律师考试从后10%左右到前10%左右，MMLU从70.0%到86.4%；此后一段时间里它是各家模型最常对比的对象，它的技术报告也只公布能力评测、不公布架构和数据。

背景

ChatGPT发布上线后，大家看到了对话式大模型的潜力，也看到了它的短板：在美国统一律师资格考试的模拟中，GPT-3.5的分数只在考生的后10%左右；多步数学、代码和需要专业知识的问题常出错；经常一本正经地编造（见幻觉）。

要更强，最直接的办法是继续按语言模型的规模定律和Chinchilla的思路扩大模型和数据。但这里有个工程上的难题：最大的那次训练要花掉几个月和极其昂贵的算力，一旦超参数或基础设施有问题，就是巨大的浪费。在这样的规模上，不可能像小模型那样反复试错调参。所以OpenAI需要一种能力：在大训练开始之前或刚开始时，就能可靠地预测它最后会练成什么样。

另外，多模态也成为竞争焦点：DeepMind的Flamingo已经证明大语言模型可以接入图像输入。

方法

技术报告公开的信息很少。它只说明：GPT-4是一个基于Transformer、用预测下一个token预训练的模型，数据包括公开数据（如互联网数据）和从第三方授权的数据；之后用人类反馈强化学习（人类反馈强化学习）微调。报告明确写道，出于“竞争格局和大模型的安全影响”，不公开架构（包括模型大小）、硬件、训练算力、数据集构建和训练方法。

真正有方法论价值的是三件事：

1. 可预测扩展（predictable scaling）。 OpenAI用与GPT-4同一套方法训练了一系列小模型，所用算力最多比GPT-4少一万倍，然后拟合一条带不可约损失项的规模定律（见幂律与规模定律）：

L(C) = a·C^b + c

C是训练算力，c是无论多大都降不下去的那部分损失。用这条曲线外推，在大训练刚开始、还没用任何中间结果时，就预测出GPT-4在内部代码数据集上的最终损失，并且预测得很准。他们还用算力少一千倍的小模型，预测了GPT-4在HumanEval一个子集上的通过率。这说明损失和部分能力的增长是平滑可外推的，大训练不再是盲赌。

2. 图像输入。 GPT-4可以接受任意交错的图像和文本，输出文本。报告的例子是一张三格图：把老式VGA接口插在手机上当充电线，GPT-4能逐格描述并解释笑点在哪。少样本提示和思维链CoT在图文输入下同样有效。不过发布时图像输入只是研究预览，只对一个合作方开放（公开版是后来的GPT-4V）。

3. 安全训练。 除了常规RLHF，报告额外加了一组安全相关的训练提示，以及基于规则的奖励模型（RBRM）：用GPT-4自己做零样本分类器，按人写的规则判断回复是否得体（例如该拒绝时是否拒绝、拒绝时是否说教），作为RLHF的额外奖励信号。上线前请了50多位网络安全、生物风险、国际安全等领域的专家做对抗测试。

发布时提供8,192 token上下文的版本，以及一个32,768 token（约50页文本）的限量版本。

结果

考试。 模拟统一律师资格考试得分298/400，约在考生前10%；同一考试GPT-3.5为213/400，约后10%。LSAT 163分（约前12%）。

学术基准。 MMLU（57个学科的选择题，5-shot）86.4%，GPT-3.5为70.0%，此前最好的语言模型70.7%；GSM8K小学数学92.0%（GPT-3.5为57.1%）；HumanEval写代码67.0%（GPT-3.5为48.1%）。把MMLU用机器翻译成26种语言，GPT-4在其中24种上超过此前模型的英文成绩，包括拉脱维亚语、威尔士语、斯瓦希里语这样的低资源语言。

事实性与安全。 在OpenAI内部的对抗性事实性评测上，技术报告称比最新的GPT-3.5高19个百分点（官方博客的说法是高40%）；对违规请求的响应倾向降低82%，对医疗建议、自残等敏感请求按政策回应的比例提高29%。

一个值得注意的副作用：预训练模型的置信度和实际正确率很一致（校准良好），经过RLHF后校准明显变差。

后来的发展

GPT-4在发布当天进入ChatGPT Plus，API则先开放排队申请。之后很多工作把它当作参照或工具：Vicuna与ShareGPT和LLM-as-a-Judge与MT-Bench直接拿它当裁判来评别的模型；Orca解释蒸馏、TinyStories等用它生成或标注训练数据；Voyager通过黑盒调用GPT-4构建智能体，AutoGPT与自主智能体热潮、Cursor AI编辑器、Aider等早期智能体和编程工具也以它为主要模型；微软研究院的《AGI的火花》认为它可视为AGI的早期（且不完整）版本，暂停巨型AI实验公开信则呼吁暂停训练比GPT-4更强的系统，这些都引发了公众讨论。

竞争对手随后跟进：Gemini 1.0官方称Gemini Ultra在32个基准中的30个上刷新了最好成绩，Claude 3官方称Opus在多数常见基准上超过同类模型；开源的Llama 3.1 405B论文称在大量任务上与GPT-4质量相当。OpenAI自己的后续是多模态实时的GPT-4o全模态实时模型和会先长时间思考的推理模型OpenAI o1推理模型。

此后多数前沿闭源模型的技术报告也只给能力评测和安全评估，不给参数量、数据和训练细节。

容易误解的地方

  • 报告里的“前10%”是在模拟考试上、由OpenAI自己评分得到的，不代表GPT-4能当律师。报告也提示部分考试题可能出现在训练数据里，并做了去污染分析（见数据泄漏与基准污染）。
  • 流传的“GPT-4有1.8万亿参数、是混合专家模型”等说法来自泄露和传闻，OpenAI从未公开确认。
  • 可预测的是损失和部分指标，不是所有能力；报告自己也说有些能力仍难以预测。

语言模型 Transformer层的结构 幂律与规模定律 人类反馈强化学习 基准、排行榜与SOTA 数据泄漏与基准污染 幻觉

本篇术语

  • 可预测扩展　在大规模训练前，用同一方法训练一系列小得多的模型，拟合规模定律，提前预测大模型的损失或指标。
  • 不可约损失　规模定律里的常数项c：即使模型和数据无限大也消除不了的损失，大致对应文本本身的随机性。
  • 规则奖励模型（RBRM）　用GPT-4按人写的评分规则对回复做零样本分类，把分类结果作为RLHF中的额外奖励，专门约束拒答和安全行为。
  • 校准　模型说有70%把握的问题，实际也答对约70%。GPT-4预训练模型校准良好，RLHF后变差。

怎么学

先补幂律与规模定律、人类反馈强化学习和基准、排行榜与SOTA。读技术报告第2–3节（范围和可预测扩展）、第4节表1和表2（考试和基准），以及第6节安全部分里关于RBRM的说明；附录的System Card讲了红队测试发现的具体风险。动手：用几个不同大小的开源模型（如Pythia系列）在同一数据上的损失拟合L(C) = a·C^b + c，看看能否外推下一个尺寸。
