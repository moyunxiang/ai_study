ChatGPT发布

Introducing ChatGPT
2022.11事件主干OpenAI来源已核对
OpenAI公告：Introducing ChatGPT ↗公告存档（2022-12-01） ↗InstructGPT论文（ChatGPT的训练方法来源） ↗Hugging Face：Illustrating RLHF ↗在交互版中打开（演化树、学习进度）

问题

大语言模型已经很强，但只能通过API和精心设计的提示来用：基础模型只会续写文本，不会多轮对话，普通人根本接触不到。

方法

把GPT-3.5系列模型用InstructGPT的RLHF流程专门针对对话再训练一遍，做成一个免费、任何人都能打开网页聊天的研究预览版。

影响

据报道五天一百万用户、两个月一亿月活。此后谷歌、微软和中国厂商相继推出聊天产品，聊天界面成为大模型最常见的使用方式之一。

背景

2022年底，大语言模型的能力已经摆在那里：GPT-3能写文章、翻译、写代码，InstructGPT与RLHF用人类反馈强化学习（人类反馈强化学习）让模型学会按指令办事。但这些能力几乎只有开发者在用。

原因有三。第一，基础模型的训练目标是预测下一个词（见语言模型），你问它一个问题，它可能接着编出五个类似的问题，而不是回答；要让它干活，得写精巧的提示词。第二，现有接口是“输入一段文本，返回一段续写”，没有多轮对话的记忆和格式。第三，真正的对话模型都关在实验室里：谷歌的LaMDA只做了小范围内测，DeepMind的Sparrow规则奖励只是论文。

另一方面，面向大众的聊天机器人（Siri与语音助手、微软小冰之类）大多靠检索和规则，能力有限；直接开放的生成式机器人又出过事故（微软Tay事件上线一天就被教坏下线）。所以问题是：能不能把一个足够强、又足够“听话”的模型，直接交给公众用？

方法

ChatGPT本身是一个网页聊天界面，背后是一个从GPT-3.5系列某个模型微调来的对话模型。OpenAI公告说，这个基础模型在2022年初训练完成，训练在Azure超算上进行。微调用的就是InstructGPT那套三步流程，只是数据收集方式改成了对话：

第一步，监督微调（SFT）。 人类训练员同时扮演用户和AI助手两边，写出完整的多轮对话，写的时候可以参考模型给出的建议回复。模型在这些对话上做普通的下一个词预测训练（见指令微调与对话模板）。

第二步，训练奖励模型。 从训练员与聊天机器人的真实对话里随机挑一条模型回复，再让模型对同一位置采样几个备选回复，由训练员按质量排序。排序被拆成两两比较，训练一个打分网络r，让它给好回复的分数高于差回复：

L_RM = −log σ( r(x, y_好) − r(x, y_差) )

其中σ是sigmoid函数，x是对话上下文，y是回复。这就是把“哪个更好”的人类判断变成一个可微的数值信号（思路来自从人类偏好学习奖励）。

第三步，强化学习。 用PPO微调对话模型，目标是让奖励模型打分尽量高，同时不要离SFT模型太远：

最大化 E[ r(x, y) ] − β·KL( π ‖ π_SFT )

KL惩罚（见KL散度）防止模型钻奖励模型的空子、输出一堆讨好打分器的怪话。上面的二、三步迭代做了好几轮。

上线时还有一层额外防护：用OpenAI的Moderation API对某些类型的不安全内容做警告或拦截，公告承认它会有误报和漏报。

公告用一个例子说明对话训练带来的区别：问“讲讲哥伦布2015年来美国的事”，InstructGPT（text-davinci-002）会顺着编下去；ChatGPT先指出哥伦布死于1506年、前提不成立，再假设性地回答。能回答追问、承认错误、质疑错误前提、拒绝不当请求，是公告列出的四个对话能力。

结果

ChatGPT于2022年11月30日作为免费研究预览上线。据维基百科汇总的报道，它五天获得一百万用户，两个月达到一亿月活跃用户（见ChatGPT两月破亿用户），在Threads出现之前是增长最快的互联网应用；到2026年2月，周活跃用户约9亿。

公告本身没有给出任何基准分数——它的意义不在某个指标上超过了谁，而在于第一次让上亿普通人直接体验大语言模型。

后来的发展

之后几个月里，2023年初微软追加投资并把它接入必应（微软追加投资与新Bing），谷歌在2023年2月推出基于LaMDA的Bard，维基百科称这是为了应对ChatGPT的崛起（谷歌“红色警报”与Bard），Anthropic发布Claude初代，国内出现“百模大战”（中国“百模大战”、ChatGLM-6B、文心一言）。开源社区在LLaMA上做出了Alpaca与廉价指令微调（用text-davinci-003生成的指令数据）和Vicuna与ShareGPT（用用户分享的ChatGPT对话）；LMSYS为了比较这些聊天模型搞出了Chatbot Arena。算力需求暴涨，带来H100短缺与GPU配给和NVIDIA市值破万亿美元。

产品本身也在快速迭代：2023年3月接入GPT-4，随后有ChatGPT插件、函数调用成为标准接口、记忆（ChatGPT记忆），后来又换上推理模型OpenAI o1推理模型。

方法层面，此后公开了技术细节的聊天模型多数采用“预训练 → 指令微调 → 偏好优化”的三段式；偏好优化那一步，不少开源模型改用了DPO直接偏好优化等更简单的方法。它也把新问题推到台前：越狱提示（DAN越狱提示）、训练数据版权（纽约时报诉OpenAI）、对话机器人的心理伤害（聊天机器人致害诉讼）。

容易误解的地方

  • ChatGPT不是一个新架构，也不是一篇论文。模型和训练方法基本就是InstructGPT，新的是对话数据、迭代方式和面向公众的产品形态。
  • “GPT-3.5”是一个系列名，不是单个模型；OpenAI没有公布ChatGPT所用模型的参数量和训练数据细节。
  • RLHF让模型更“会说话”，并不直接让它更“知道事实”。公告自己就承认：强化学习阶段没有真值来源，模型会自信地编造。

读懂它需要的概念

语言模型 自回归生成 预训练与微调 指令微调与对话模板 人类反馈强化学习 策略梯度 KL散度 幻觉

本篇术语

  • 研究预览（research preview）　OpenAI对ChatGPT首发版本的定位：免费开放、用于收集用户反馈的实验性产品，而不是正式商品。
  • 监督微调（SFT）　用人写的示范回答，按普通的下一个词预测损失继续训练模型，让它先学会回答的格式和风格。
  • 奖励模型　一个给“对话上下文+回复”打分的网络，用人类的排序数据训练，在强化学习阶段代替人来评价模型的回复。
  • Moderation API　OpenAI的内容审核分类器，判断文本是否涉及暴力、自残、色情等，用来对ChatGPT的输入输出做拦截或警告。

怎么学

先补语言模型、指令微调与对话模板和人类反馈强化学习。然后读OpenAI公告的Methods和Limitations两节（很短），再读InstructGPT论文第3节，对照公告看ChatGPT改了哪里。Hugging Face的Illustrating RLHF一文把三步流程画得很清楚。动手：用trl库在一个小模型上跑一遍SFT→奖励模型→PPO，或者直接跑DPO，对比训练前后同一问题的回答。
