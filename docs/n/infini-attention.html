Infini-attention

Leave No Context Behind: Efficient Infinite Context Transformers with Infini-attention
2024.04论文延伸arXiv 2024Tsendsuren Munkhdalai, Manaal Faruqui, Siddharth Gopal · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

标准注意力的缓存和计算随长度增长，无法在固定内存下处理无限长的输入。

方法

在每个注意力块里同时放局部掩码注意力和一个压缩记忆（线性注意力），分段处理输入，旧段落压入记忆。

影响

展示了固定内存下处理百万级输入的路线，1B模型做到1M长度的passkey检索。

方法

输入被切成段。每段内部做普通的局部注意力；之前所有段的键值被压缩进一个固定大小的矩阵记忆（做法与线性注意力相同，且延续了压缩记忆Transformer把旧记忆压缩保存的思路），当前段的查询既查局部，也从记忆里读取，最后用一个可学习的门把两路输出加权合并。

因此无论总输入多长，内存占用都是固定的。摘要称在1B和8B模型上，它在长上下文语言建模上有效，在1M长度的passkey检索和50万长度的书籍摘要上都能工作。

局限与后续

  • 固定大小的压缩记忆是有损的，需要精确回忆的内容可能丢失；论文的验证以passkey和摘要为主。

    同样把旧段落压缩成记忆，Infini-attention用线性注意力形式的矩阵记忆做压缩。
  • 使用
    线性注意力2020.06 · 基础
    记忆的读写用的是线性注意力的关联记忆更新。
  • 改进
    外接kNN记忆2022.03 · LLM
    记忆只存了历史的键值，没有更新机制，无法遗忘或压缩，大小受限于存储与检索开销。
  • 改进
    循环记忆Transformer2022.07 · LLM
    记忆只有几个向量，容量有限，且段间只能串行传递，训练要沿时间反向传播，难以并行。
