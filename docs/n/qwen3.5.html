Qwen3.5原生多模态

Qwen3.5: Towards Native Multimodal Agents
2026.02模型延伸Qwen Team · Alibaba待核对
GitHub ↗VentureBeat报道 ↗在交互版中打开（演化树、学习进度）

问题

Qwen先前把语言模型（Qwen3）和视觉模型（Qwen3-VL）分开维护，视觉能力是后接的，智能体能力也分散。

方法

Qwen3.5用早期融合在数万亿多模态词元上训练，把视觉语言统一进一个基座，并采用门控Delta网络加稀疏MoE的混合架构。

影响

开放权重的原生多模态智能体模型，在官方称的推理、编码、智能体和视觉理解基准上超过Qwen3-VL。

方法

按官方GitHub仓库的说明，Qwen3.5有几项特点：统一的视觉语言基座，用早期融合训练数万亿多模态词元，官方称在推理、编码、智能体和视觉理解基准上达到与Qwen3相当并超过Qwen3-VL；高效混合架构，门控Delta网络加稀疏混合专家，降低推理延迟和成本；大规模RL，环境达到百万智能体量级；语言覆盖扩展到201种语言和方言。

媒体报道2026-02-18提到旗舰型号为397B总参数、17B激活参数（Qwen3.5 397B-A17B）。以上规格均为厂商自述，未经独立复现。
