线性注意力即快速权重

Linear Transformers Are Secretly Fast Weight Programmers
2021.02论文延伸ICML 2021Imanol Schlag, Kazuki Irie, Jürgen Schmidhuber · IDSIA / USI / SUPSI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

线性注意力虽然能把计算降为线性，但与softmax注意力相比效果有差距，原因不清楚。

方法

证明线性化自注意力与上世纪90年代的快速权重控制器在形式上等价，并据此引入delta规则式更新，同时提出新的核函数。

影响

把线性注意力重新理解为一个可写入、可纠错的有限记忆，直接促成DeltaNet并行训练等后续工作。

方法

快速权重的思路是：一个“慢”网络通过梯度下降学习去编程另一个网络的“快速权重”，编程指令是由自己生成的两个向量（今天叫键和值）的外积的累加。作者指出，去掉softmax的线性注意力恰好就是这个结构：状态矩阵每一步加上v·kᵀ，查询时与q相乘。

这个视角带来两点。第一，这个矩阵大小固定，只能存有限的键值对，只做累加，存太多会互相干扰，这就是线性注意力的容量限制。第二，参照ADALINE与LMS的delta规则，改成先读出旧值再只写入误差，让网络更容易纠正已有的键到值的映射，同时学习随输入变化的写入强度。作者还提出一种新的核函数用于线性注意力，并在语言建模等任务上做了对比。

局限与后续

  • 固定大小的状态在序列很长时仍会遗忘或冲突，无法与完整注意力的精确检索相比。
