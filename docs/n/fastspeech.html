FastSpeech

FastSpeech: Fast, Robust and Controllable Text to Speech
2019.05论文重要NeurIPS 2019Yi Ren, Yangjun Ruan, Xu Tan, Tao Qin, Sheng Zhao, Zhou Zhao, Tie-Yan Liu · 浙江大学 / 微软亚洲研究院 / 微软待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Tacotron 2这类模型逐帧自回归地生成梅尔谱，速度慢；注意力对齐不稳，遇到难句会跳字、重复；语速也无法控制。

方法

预测每个音素持续多少帧，按时长把音素表示复制展开到频谱长度，再用前馈Transformer一次性并行生成整段梅尔谱；时长和训练目标都从一个自回归教师模型里提取。

影响

梅尔谱生成提速约270倍、端到端合成提速38倍，在50个难句上跳字和重复降为0，音质与自回归模型相当；“显式时长+并行生成”成为此后工业TTS的主流做法。

背景

Tacotron 2和基于Transformer的Transformer TTS代表了2019年神经TTS的最好音质，它们的声学模型都是自回归的：生成第t帧梅尔谱要等第t−1帧，一句几百帧的话就要串行跑几百步。更麻烦的是，文本与频谱之间的对应关系全靠编码器-解码器注意力自己学，学歪了就会漏掉某个词或把某个词重复几遍，在单字母、拼读、连续数字、长句上尤其明显。而且注意力是隐式的，用户没法要求“说慢一点”。声码器那一侧已经有WaveGlow这样的并行方案，瓶颈落在了声学模型。

方法

前馈Transformer。音素序列先经过若干个FFT块（自注意力加一维卷积，见自注意力与多头注意力），得到每个音素的隐表示。

长度调节器。这是关键：给定每个音素的时长d（占几帧），把它的隐表示复制d份。例如4个音素的隐状态[h1, h2, h3, h4]、时长[2, 2, 3, 1]，展开后就是[h1, h1, h2, h2, h3, h3, h3, h4]，长度正好等于梅尔谱帧数（见输入输出不等长时的对齐）。之后再经过若干FFT块，一次性并行输出全部80维梅尔谱帧（见波形、频谱与梅尔谱）。乘一个系数α可以整体调语速：α=0.5时时长变为[1, 1, 2, 1]，语速加快。

时长从哪来。训练一个自回归的Transformer TTS作为教师，从它的编码器-解码器注意力中挑出最接近对角线的那个头，统计每个音素被多少帧关注，作为时长标签；另训练一个由两层卷积组成的时长预测器，推理时用它预测时长。

序列级知识蒸馏（见知识蒸馏、知识蒸馏）。不直接拟合真实录音的梅尔谱，而是拟合教师模型生成的梅尔谱，降低“同一句话多种读法”带来的学习难度。最后用预训练的WaveGlow把梅尔谱变成波形。

结果

在LJSpeech（13100条、约24小时单人英语）上：MOS 3.84，Transformer TTS为3.88，Tacotron 2为3.86（均用WaveGlow声码器），真人录音4.41。单块V100、批大小为1时，梅尔谱生成延迟从6.735秒降到0.025秒（约270倍），连同声码器的端到端延迟从6.895秒降到0.180秒（38倍），且延迟几乎不随句长增长。在50个难句上，Tacotron 2有24%的句子出错、Transformer TTS有34%，FastSpeech为0。语速可以在0.5倍到1.5倍之间平滑调整，音高基本不变。

后来的发展

一年后的FastSpeech 2去掉了教师模型，改用外部强制对齐获得时长，并加入音高和能量预测；Glow-TTS则用单调对齐搜索自己学时长。“编码器 + 时长预测 + 长度展开 + 并行解码”的结构成为工业TTS的标准模板，也被VITS、NaturalSpeech等沿用。

局限与后续

  • 时长标签和训练目标都依赖一个先训练好的自回归教师，流程长；从注意力里提取的时长不够准，蒸馏出的梅尔谱也比真实录音丢了信息，限制了音质。
    后来针对它的工作　FastSpeech 2 Glow-TTS
  • 只预测时长，对音高、能量等韵律变化没有显式建模，一对多问题只靠蒸馏缓解，合成语气偏平。
    后来针对它的工作　FastSpeech 2 VITS
  • 仍是“声学模型+独立声码器”两段式，两者分开训练存在失配。
    后来针对它的工作　VITS

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    编码器和解码器都由自注意力加一维卷积的前馈Transformer块组成，教师模型也是Transformer TTS。
  • 使用
    知识蒸馏2015.03 · 系统·效率
    用序列级知识蒸馏，让学生拟合教师生成的梅尔谱而不是真实录音。
  • 改进
    Tacotron2017.03 · 语音
    注意力对齐不够稳，长句或生僻输入会跳字、重复或停不下来；逐帧自回归解码也慢。
  • 改进
    Tacotron 22017.12 · 语音
    解决自回归注意力解码慢、跳字重复和语速不可控的问题：难句错误率从24%降到0，梅尔谱生成快约270倍。
  • 改进
    Deep Voice2017.02 · 语音
    仍由五个独立训练的模块拼接，前一级的误差会传给后一级，不是真正端到端；需要音素级标注或额外的分割模型。
  • 延续
    非自回归翻译NAT2017.11 · LLM
    借鉴非自回归翻译“先预测每个源词复制几份再并行解码”的思路，用在音素到频谱上。
  • 使用
    WaveGlow2018.10 · 语音
    以预训练的WaveGlow作为声码器，把并行生成的梅尔谱变成波形。

后来的相关工作

  • 改进
    VITS2021.06 · 语音
    只预测时长，对音高、能量等韵律变化没有显式建模，一对多问题只靠蒸馏缓解，合成语气偏平。

    Glow-TTS2020.05 · 语音
    FastSpeech需要自回归老师提供对齐和蒸馏，Glow-TTS用单调对齐搜索自己学对齐。
  • 改进
    FastSpeech 22020.06 · 语音
    去掉教师蒸馏与教师时长，直接用真实语音训练，并显式预测音高与能量。

本篇术语

  • 长度调节器　按每个音素的预测时长把它的隐向量重复若干次，使音素序列长度与频谱帧数一致，从而可以并行解码。
  • 一对多问题　同一段文字可以用不同的语速、音高、重音读出来，模型如果直接回归，只会学到这些读法的模糊平均。
