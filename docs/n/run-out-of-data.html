数据会用完吗

Will we run out of data? Limits of LLM scaling based on human-generated data
2022.10论文延伸arXiv 2022Villalobos, Ho, Sevilla, Besiroglu, Heim, Hobbhahn · Epoch AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Chinchilla之后训练数据量要跟着模型一起涨，但没人系统估算过互联网上人类写的文本到底有多少、够用多久。

方法

估算公开可用的人类文本总量及其增长速度，再与大模型训练数据量的增长趋势做对比，预测何时用完。

影响

首次给出「高质量文本将被耗尽」的量化时间表，使数据瓶颈、合成数据和多模态数据成为正式的研究议题。

方法

Chinchilla的结论是模型参数和训练token应该等比例增长，因此要训练更大的模型就需要更多文本。这篇论文分别估算了公开文本的存量和每年的新增量，并把它与过去几年语言模型训练集的增长速度外推比较。

摘要给出的结论是：如果当前大模型的发展趋势继续，训练数据集的规模将在2026年到2032年之间与公开人类文本的总量相当，如果模型被过度训练（用超出最优比例的数据），这个时间会更早。论文也讨论了可能的出路，比如利用合成数据、多模态数据和未公开的数据。

需要注意这是基于趋势外推的估算，不是已发生的事实：存量估计和增长假设都有较大的不确定区间，后来Dolma开放语料、RefinedWeb等工作显示去重和过滤后的网页数据量仍然很大，但同时重复训练多个epoch的价值也成了新的研究问题。

局限与后续

  • 估算依赖对「有效存量」的定义（质量过滤后保留多少）和增长趋势能否持续的假设，不确定区间很宽。

  • 论文只回答「何时用完」，没有回答用完之后靠什么继续提升，合成数据能否替代真人文本仍在争论。
