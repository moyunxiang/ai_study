对比预测编码CPC

Representation Learning with Contrastive Predictive Coding
2018.07论文延伸van den Oord, Li, Vinyals · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

无监督表示学习缺少一个能跨语音、图像、文本、强化学习通用的目标。

方法

让模型根据当前的上下文去预测未来若干步的隐表示，并用对比损失在候选中挑出真正的未来。

影响

提出InfoNCE损失，后来成为SimCLR、MoCo、CLIP等对比学习的共同基础。

方法

先用编码器把输入（如一段语音、一排图像块）变成隐向量序列z_t，再用一个自回归模型把过去的z汇总成上下文向量c_t。要预测的是未来第k步的z_{t+k}，但不直接生成它（高维数据的生成很难），而是比较：给定c_t，从一批候选里（一个真实的未来加若干随机负样本）把真实的那个选出来。

损失是对这个选择做的分类交叉熵，即InfoNCE，它是互信息的一个下界（见互信息）。损失形式由噪声对比估计NCE推广而来，也借鉴了word2vec的负采样。论文在语音、图像、文本和3D环境的强化学习四个领域都取得了有竞争力的结果。

局限与后续

  • 效果强烈依赖负样本的数量和质量，需要大批量或额外机制。
    后来针对它的工作　SimCLR MoCo
  • 目标是预测局部未来，对图像的全局语义信号较弱。
    后来针对它的工作　SimCLR

它建立在什么之上

  • 使用
    word2vec2013.01 · NLP
    沿用负采样式的对比训练思想。
  • 改进
    对比损失2006 · 基础
    一次只比较一对，没有利用批内大量其他样本作为负例，规模化时效率低。
  • 改进
    噪声对比估计NCE2010.05 · 基础
    把噪声对比估计推广为多类别的InfoNCE损失，并证明与互信息的关系。
  • 改进
    表示学习综述2012.06 · 基础
    综述时期的主流方法仍是逐层无监督预训练，对“好表示”缺少可量化的评价标准，只能靠下游任务间接衡量。

后来的相关工作

  • 使用
    MoCo2019.11 · 视觉
    沿用CPC提出的InfoNCE损失，把它统一解释为字典查找。
  • 改进
    SimCLR2020.02 · 视觉
    CPC要靠切块和上下文网络构造预测任务；SimCLR证明随机裁剪就能涵盖这些任务，不需要专门结构，线性评估相对高出7%。
  • 延续
    wav2vec 2.02020.06 · 语音
    沿用CPC的InfoNCE对比损失，但预测对象从“未来几帧”改为“被遮住的帧”，可利用双向上下文。
  • 使用
    GSLM无文本语言模型2021.02 · 语音
    CPC是三种语音编码器之一，其单元在ABX音素区分上表现最好。
  • 延续
    wav2vec2019.04 · 语音
    把CPC的对比预测未来的思想用到语音识别的预训练上，使用卷积网络与噪声对比目标。
  • 竞争
    APC自回归预测编码2019.04 · 语音
    同样预测未来，CPC用对比损失区分真假样本，APC直接回归未来频谱帧。
  • 竞争
    Mockingjay掩码声学模型2019.10 · 语音
    CPC用对比损失预测未来表示，Mockingjay直接重建被遮住的频谱，是自监督的两条路线。
  • 使用
    Libri-Light2019.12 · 数据·评测
    为CPC一类自监督表示学习提供大规模无标注语音。
  • 使用
    CUT对比无配对翻译2020.07 · 生成
    PatchNCE直接采用CPC提出的InfoNCE对比损失形式。
  • 使用
    对比RL（目标条件）2022.06 · RL
    用InfoNCE式对比损失训练表示。
