门控稀疏自编码器

Improving Dictionary Learning with Gated Sparse Autoencoders
2024.04论文延伸Senthooran Rajamanoharan, Arthur Conmy, Lewis Smith, Tom Lieberum, Vikrant Varma, János Kramár, Rohin Shah, Neel Nanda · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

稀疏自编码器解释LLM和稀疏自编码器与单义特征用L1惩罚让稀疏自编码器的特征尽量稀疏，但L1同时会把激活值整体往零压，系统性地低估特征强度（称为收缩），重建质量因此打折。

方法

把编码器拆成两条路：一条“门”只决定哪些特征被激活，另一条只估计激活多大；L1惩罚只加在门上，大小的估计就不再被压低。

影响

在同样的稀疏度下明显改善重建，是标准L1稀疏自编码器之后最早被广泛采用的改进之一，随后的JumpReLU稀疏自编码器沿同一思路继续简化。

方法

标准稀疏自编码器对激活x做f = ReLU(W_enc x + b)、x̂ = W_dec f，损失是重建误差加λ‖f‖₁。问题在于：为了降低L1，模型会让所有激活值都偏小，即便某个特征明明该强烈激活。

Gated SAE把编码分成两部分：

  • 门控：π_gate = W_gate x + b_gate，只用它的符号决定特征i是否打开（π_gate > 0）。
  • 幅度：π_mag = W_mag x + b_mag，经过ReLU得到打开时的大小。
  • 输出f = 1[π_gate > 0] ⊙ ReLU(π_mag)。

为了减少参数，W_mag与W_gate共享方向，只是每个特征多一个缩放系数。L1惩罚只加在门控路径（经ReLU后）上；由于阶跃函数没有梯度，训练时再加一个辅助重建损失，让门控路径本身也能学到有意义的方向。

作者在最大70亿参数的语言模型上训练，摘要称在常见超参数范围内，Gated SAE解决了收缩问题，可解释性与原方法相当，而达到相近重建质量时被激活的特征数只需一半，相对当时主流训练方法构成帕累托改进。

局限与后续

  • 需要额外的辅助损失和更多参数，训练比标准SAE复杂；更好的重建与稀疏度并不等于学到的特征对下游理解或干预更有用。

本篇术语

  • 收缩　L1惩罚让模型倾向于把所有激活值都压小，导致特征强度被系统性低估。
  • 帕累托改进　在两个互相牵制的指标（这里是稀疏度和重建误差）上，至少一个更好而另一个不变差。
