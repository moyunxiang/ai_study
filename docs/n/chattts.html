ChatTTS对话语音合成

2024.05模型延伸2noise团队待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

大模型助手需要像聊天一样自然的语音，但多数开源TTS读起来像播音，缺少停顿、笑声和语气词。

方法

专为对话场景训练的生成式语音模型，能预测并控制笑声、停顿、插入语等细粒度韵律，支持多说话人。

影响

2024年5月开源后很快获得约4万星，中英文对话式合成的韵律自然度在开源模型中突出，带动了一批口语化TTS项目。

方法

ChatTTS面向大模型助手等对话场景。官方介绍其主模型用10万小时以上的中英文语音训练，开源的是4万小时预训练、未经过有监督微调的版本。模型能在生成时预测细粒度的韵律特征，用户也可以在文本里插入笑声、停顿等控制标记，得到口语化的表达；支持多个说话人并通过说话人向量采样音色。后续更新开源了DVAE编码器和零样本推理代码，并支持流式生成。为了限制滥用，官方在训练中加入了少量高频噪声，并压缩了音质。代码采用AGPLv3+，模型为CC BY-NC 4.0，仅限学术用途。

局限与后续

  • 开源版未经有监督微调，稳定性一般，偶有吞字和音色漂移；模型许可不允许商用。
