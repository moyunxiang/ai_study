FFN即键值记忆

Transformer Feed-Forward Layers Are Key-Value Memories
2020.12论文延伸EMNLP 2021Mor Geva, Roei Schuster, Jonathan Berant, Omer Levy · 特拉维夫大学 / Allen Institute for AI 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

前馈层（FFN）占了Transformer约三分之二的参数，但大家研究的主要是注意力，FFN到底在做什么几乎没人说得清。

方法

把FFN的两层权重读成一张键值表：第一层的每一行是一个“键”，匹配输入里的某种文本模式；第二层对应的那一行是“值”，给出一个偏向某些下一个词的分布。

影响

为“事实知识存在FFN里”的一系列工作提供了基本框架，知识神经元、ROME等知识定位与编辑方法都建立在这个视角上。

方法

一个FFN层计算 FFN(x) = f(x·Kᵀ)·V：输入x先与第一层矩阵K的每一行做点积，经过激活函数f得到一组系数，再用这些系数对第二层矩阵V的各行加权求和。这在形式上和记忆网络里的键值记忆、以及注意力几乎一样，只是“键”和“值”是训练出来的固定参数，而不是来自上下文。

作者在一个16层的语言模型上，对每个键找出训练语料里最能激活它的句子前缀，让人来标注。结果发现这些键对应着人能看懂的模式：低层多是表面模式（例如以某个词结尾），高层多是语义模式（例如谈论电视节目）。再把每个值向量乘以输出词嵌入矩阵，可以看到它把概率集中在“紧跟在这个模式之后最可能出现的词”上，在高层尤其明显。最后，一个FFN层的输出是许多记忆的组合，并通过残差连接在层与层之间被逐步修正，形成最终的输出分布。

局限与后续

  • 只分析了单个中等规模的语言模型，键与模式的对应靠人工标注少量样本；记忆如何在多层之间组合成具体事实没有给出可操作的定位方法。

读懂它需要的概念

多层感知机 Transformer层的结构 内积与余弦相似度 残差连接 嵌入向量

怎么学

先弄清Transformer里FFN的两层结构；读本文对键模式的人工标注结果和值向量投影到词表的分析；动手：在GPT-2小模型上挑一个FFN神经元，找出语料里最能激活它的上下文，并把对应的值向量投影到词表看前几个词。
