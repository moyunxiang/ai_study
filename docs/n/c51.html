分布式RL C51

A Distributional Perspective on Reinforcement Learning
2017.07论文重要ICML 2017Bellemare, Dabney, Munos · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统强化学习只学回报的期望Q(s,a)；但同样期望为0的两个动作，一个稳稳拿0分，一个一半机会+10、一半−10，只看平均值会丢掉这些信息。

方法

直接学回报的完整概率分布：在[−10, 10]上放51个固定的“原子”，网络为每个动作输出这51个值上的概率；用分布版的Bellman方程构造目标分布，投影回这51个点后用交叉熵训练。

影响

开创了“分布式强化学习”方向；C51在57款Atari上平均分和中位数都超过当时所有单项改进，成为Rainbow的组成部分。

背景

从动态规划与Bellman方程以来，强化学习的核心对象一直是价值函数：Q(s,a) = E[回报]，DQN（Nature版）也只学这个平均值。但回报本身是随机的：同一状态下做同一动作，后续的随机事件（对手的动作、掉落的道具、球的反弹）会让回报落在不同位置，分布可能有多个峰。

“回报分布”的概念以前在风险敏感控制中出现过，但一般只用来建模方差等少数统计量。没人系统地研究过：如果让智能体学整个分布，即便最后仍按均值选动作，学习本身会不会更好？

方法

分布式Bellman方程。用随机变量Z(s,a)表示回报，那么Z(s,a) = R(s,a) + γ·Z(S',A')在分布意义上成立（两边分布相同）。论文证明：对固定策略，这个算子在Wasserstein距离（一种衡量两个分布要“搬多少土”才能变成对方的距离）下是收缩映射，迭代会收敛；但对“取最优”的控制版本，它在任何分布距离下都不是收缩的，理论上更不稳定。

分类式参数化。实际实现用一个离散分布：在[V_MIN, V_MAX] = [−10, 10]上均匀放N=51个点z_i（“51个原子”，C51因此得名），网络的输出层对每个动作输出51个logits，过Softmax与logits得到这51个点上的概率。Q值就是这个分布的均值，行动仍按均值贪心选。

投影与损失。构造目标时，把下一状态的分布整体缩放γ倍再平移r：原子z_j变成r + γz_j，它通常不再落在原来的网格上。于是把每个移动后的原子的概率按距离线性分给相邻的两个网格点（“投影”），得到目标分布。最后最小化目标分布与预测分布的交叉熵（等价于KL散度）。注意这个损失与理论分析用的Wasserstein距离并不一致——论文指出，只能从采样到的单条转移学习时，无法直接用Wasserstein距离作为损失来训练。

结果

在57款Atari游戏上，按人类基准归一化，C51的平均分为701%、中位数178%，而DQN为228%和79%、Double DQN为307%和118%、Dueling为373%和151%、优先回放为434%和124%。它在Seaquest上大幅刷新纪录，在Venture、Private Eye这类稀疏奖励游戏上也表现很好，作者认为分布能更好地传播罕见事件的信息。只训练5000万帧时，它已在57款中的45款超过训练满2亿帧的DQN。51个原子的实现速度约为DQN的75%。

后来的发展

几个月后同一团队的分位数回归QR-DQN把“固定位置、学概率”反过来改成“固定概率、学位置”（分位数回归），从而真正最小化Wasserstein距离，也不再需要人为设定取值范围。C51被收入Rainbow，在消融中排名第三重要。分布式价值函数后来用于Loon平流层气球导航的平流层气球导航等真实系统。2024年的用分类训练价值函数进一步发现，把价值回归换成分类损失本身就能让大网络的RL更好扩展，这在一定程度上解释了C51为什么有效。

容易误解的地方

  • C51最后仍然按期望选动作，学分布并没有让它“规避风险”；它的收益主要来自学习过程（更丰富的训练信号、更稳定的表示）。
  • 理论证明用的是Wasserstein距离，算法实际优化的是投影后的交叉熵，两者之间的关系当时并没有理论保证。

局限与后续

  • 需要预先设定回报的取值范围[−10,10]和原子数，回报超出范围会被截断，换到奖励尺度不同的任务要重新设定。
    后来针对它的工作　分位数回归QR-DQN
  • 理论支持的是Wasserstein距离下的收缩，算法却用投影加交叉熵，二者脱节，收敛性没有保证。
    后来针对它的工作　分位数回归QR-DQN
  • 学分布为何能提升按均值决策的表现，论文只给出了直觉解释，机制并不清楚。

读懂它需要的概念

Bellman方程 时序差分与自举 随机变量与概率分布 Softmax与logits 交叉熵 最优传输与Wasserstein距离

本篇术语

  • 回报分布Z(s,a)　从(s,a)出发能拿到的总回报的完整概率分布，而不只是平均值Q(s,a) = E[Z(s,a)]。
  • 原子（atom）　离散分布所在的固定取值点。C51在[−10,10]上均匀放51个原子，网络只学每个原子上的概率。
  • 投影　把缩放平移后不在网格上的分布重新分配到固定原子上：每个点的概率按距离比例分给左右两个相邻原子。

怎么学

先补Bellman方程、交叉熵和最优传输与Wasserstein距离里的Wasserstein距离。读原文第4节算法1（投影步骤）和图6。动手：在自己的DQN上把输出层改成每动作51个logits，实现投影函数，在CartPole或Breakout上与DQN对比。
