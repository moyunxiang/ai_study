8000万Tiny Images

80 Million Tiny Images: A Large Data Set for Nonparametric Object and Scene Recognition
2008.11数据集延伸Antonio Torralba, Rob Fergus, William T. Freeman · MIT / NYU待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

物体识别方法多用小数据集，作者想检验：只要图片够多，哪怕缩到很小，最近邻这类简单方法能否识别物体。

方法

按WordNet的名词表，到七个图片搜索引擎抓图，缩成32×32像素，攒出近8000万张图的大数据集。

影响

它第一次用网络规模的图片做物体识别实验，也直接诞生了CIFAR-10/100，但数据集后来因标签中的冒犯性词语被撤下。

方法

80 Million Tiny Images由MIT与纽约大学的Torralba、Fergus、Freeman构建，2007年有技术报告，2008年在TPAMI上完整发表。他们从WordNet的75,846个非抽象名词出发，到Altavista、Ask.com、Flickr、Cydral、Google、Picsearch、Webshots七个搜索引擎各抓图，历时8个月，共抓到约9700万张图片；因为存储不够，抓取时就缩成32×32像素。清理（去掉全黑的和同一名词下的重复图）后，最终得到79,302,017张彩色图，分属75,062个类别（有结果的名词），整个数据集有760GB。

其动机是非参数方法：不训练模型，直接用最近邻在海量图片里查找相似图。这与当时的数据的不合理有效性思路一致：数据量上去之后，朴素方法也能工作。标签是搜索引擎返回的词，因此噪声很大；CIFAR-10/100就是从中挑出一小部分并重新人工标注的。

2020年，Birhane与Prabhu的论文指出其标签中含有种族主义和厌女的词，并且存在冒犯性图片，MIT随后下架数据集，请求他人停止使用并删除副本。
