GPU上的卷积网络

High Performance Convolutional Neural Networks for Document Processing
2006.10论文延伸IWFHR 2006（2006年10月，书写识别前沿国际研讨会）Kumar Chellapilla, Sidd Puri, Patrice Simard · Microsoft Research待核对
检索入口（待补原文链接） ↗在交互版中打开（演化树、学习进度）

问题

卷积网络训练时间长，且GPU的编程接口只有图形API，没人确定它能不能加速神经网络。

方法

把卷积展开成矩阵乘法，用GPU上的图形着色器做矩阵运算，让卷积网络的训练和推理在普通显卡上提速。

影响

它是较早在真实任务上用GPU训练卷积网络的工作之一，早于GPU训练深度网络和AlexNet数年。

方法

论文把卷积层的计算改写成大矩阵乘法（先把每个卷积窗口展开成一行，再与展开的卷积核相乘），而矩阵乘法正是当时GPU最擅长的运算。作者用GPU的像素着色器实现这一运算，应用在文档（手写与印刷字符）识别网络上，相比CPU实现显著提速。（本节点的具体加速倍数和实验设置我没能联网核对，故不写数字；会议名称、作者和年份取自骨架与记忆，标记为未核对。）

这个把卷积变成矩阵乘的思路（后来称为im2col）一直沿用到今天，是cuDNN等库实现卷积的基本方式之一。它说明：即使没有CUDA，研究者也能把神经网络挪到图形硬件上；2006年之后CUDA让这件事容易得多。

局限与后续

  • 要用图形API的着色器间接表达矩阵乘，编程繁琐，难以推广。
    后来针对它的工作　CUDA
  • 展开卷积窗口会重复存储数据，占用显存。
    后来针对它的工作　cuDNN

它建立在什么之上

  • 延续
    LeNet与卷积网络1998 · 视觉 待核对
    把LeNet式卷积网络的计算搬到GPU上加速。
  • 改进
    Neocognitron1980 · 视觉
    当时的计算机只能模拟很小的网络，图像分辨率和类别数都受限，无法处理自然图像。
  • 改进
    卷积网络识别邮编1989 · 视觉
    数据只有几千张、网络只有约1万个参数，训练却要3天，这样的算力无法扩展到自然图像和上千类别。
  • 改进
    Intel ETANN模拟神经芯片1989.06 · 硬件
    规模只有一万多个突触，远不能运行当时已经兴起的卷积网络。
  • 改进
    贝尔实验室ANNA芯片1992 · 硬件
    模拟或混合信号电路难以随网络结构变化灵活编程，一块芯片只适合一种网络。
  • 使用
    GeForce 3可编程着色器2001.02 · 硬件
    利用GeForce 3引入以来的可编程着色器在GPU上运行通用计算。

后来的相关工作

  • 改进
    CUDA2006.11 · 硬件
    要用图形API的着色器间接表达矩阵乘，编程繁琐，难以推广。
  • 延续
    GPU训练深度网络2009.06 · 硬件
    更早已有人在GPU上加速卷积网络；这篇论文在CUDA上系统研究了深度无监督模型的GPU训练，并把规模推到上亿参数。
  • 改进

    展开卷积窗口会重复存储数据，占用显存。
