MUSE六维遗忘评测

MUSE: Machine Unlearning Six-Way Evaluation for Language Models

问题

数据所有者可能因隐私或版权要求把数据从模型中删除，精确重训不可行，于是出现了很多近似遗忘算法，但对它们的评测范围很窄，说不清是否真的满足部署者和数据所有者的需求。

方法

从模型部署者和数据所有者两方的角度，列出遗忘后模型应具备的六种性质，并用新闻和《哈利·波特》书籍两个语料系统评测八种流行遗忘算法。

影响

MUSE成为与TOFU、WMDP并列的大模型遗忘标准评测，后续遗忘方法常同时报告这三个基准。

方法

六种性质。(1) 不再逐字记忆被删文本；(2) 不再记得其中的知识，问相关问题答不出；(3) 没有隐私泄露，用成员推断攻击检测不出这些数据曾被训练；(4) 保持在不需删除的数据上的效用；(5) 可扩展，删除请求的规模变大时仍有效；(6) 可持续，面对连续多次删除请求仍有效。前三条是数据所有者关心的，后三条是部署者关心的。

语料。两个场景：BBC新闻文章和《哈利·波特》系列书籍，模拟隐私和版权两类删除请求。先在这些语料上微调模型，再要求遗忘其中一部分。

发现。作者用这些标准评测了八种流行的遗忘算法（包括梯度上升、NPO负偏好优化遗忘、基于任务向量的方法等）。大多数算法能在一定程度上阻止逐字记忆和知识记忆，但只有一种算法不造成严重的隐私泄露；而且现有算法普遍以显著损害效用为代价，无法可持续地处理连续删除请求或大规模删除。

局限与后续

  • 只在两个英文语料、经过专门微调的模型上评测，遗忘目标比真实预训练数据的删除请求更集中、更容易界定。
