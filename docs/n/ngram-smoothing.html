n-gram平滑

An Empirical Study of Smoothing Techniques for Language Modeling
1996论文延伸ACL 1996Stanley F. Chen, Joshua Goodman · Harvard University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

n-gram语言模型遇到训练里没出现过的词组合时概率为零，各种平滑方法孰优孰劣缺乏系统比较。

方法

在同一套实验里比较Jelinek-Mercer、Katz、Church-Gale等平滑方法，考察数据量、语料和n元长度的影响，并提出两种新方法。

影响

为选择平滑方法给出了实证依据，后续版本引出了modified Kneser-Ney，成为万亿词n-gram与Stupid Backoff和神经LM之前的默认选择。

方法

n-gram模型用P(wᵢ | wᵢ₋₂wᵢ₋₁)估计下一个词。直接数频率，没见过的三元组概率就是零，整句概率也变成零，所以需要平滑：把一部分概率从见过的事件匀给没见过的。

这篇论文比较了几类方法。插值法（Jelinek-Mercer）把高阶和低阶估计加权混合；回退法（Katz）高阶没数据时回退到低阶；Church-Gale则借助留出数据估计。作者按交叉熵（见交叉熵）衡量测试集上的表现，并系统考察了训练数据量、语料（Brown对华尔街日报）和二元对三元的影响。

摘要说，他们提出了一种Jelinek-Mercer的变体和一种很简单的线性插值方法，二者都优于已有方法。后来这条线发展为Kneser-Ney平滑。

局限与后续

  • 方法依靠计数的统计平滑，无法让相似的词共享信息，词表和上下文一多仍然稀疏。

它建立在什么之上

  • 延续
    香农：语言的统计模型1948 · NLP
    在香农开创的n-gram模型之上解决数据稀疏时的概率估计问题。
  • 改进
    乔姆斯基层级1956 · NLP
    把统计模型等同于原始频率计数，忽略了能泛化到未见组合的概率模型，结论对后来的平滑和神经语言模型不成立。
  • 改进
    Kneser-Ney平滑1995.05 · NLP
    原始形式只在高阶计数为0时才用低阶分布，而且所有计数共用一个折扣D，对只出现一两次的n-gram估计偏差大。
  • 改进
    Katz回退语言模型1987.03 · 语音
    回退时低阶分布仅按词频估计，没有考虑某词常出现在多种上下文里还是只在固定搭配里。

后来的相关工作

  • 竞争
    神经概率语言模型2003.02 · NLP 已核对
    同样是为了给没见过的词组合合理的概率：平滑靠回退到更短的n-gram，NPLM靠词向量的相似度；实验直接对比了Kneser-Ney等最强平滑模型。
  • 竞争
    RNN语言模型2010.09 · NLP
    基线是修正Kneser-Ney平滑的5-gram；RNN困惑度约降一半，与它插值使用效果最好。
  • 改进
    探索语言模型的极限2016.02 · NLP
    在n-gram最擅长的大语料上，单个LSTM（30.0）也远好于Kneser-Ney 5-gram（67.6），且在罕见词上优势最大。
  • 使用
    《语音与语言处理》2000 · NLP
    n-gram语言模型与平滑方法在书里有系统讲解。
  • 使用
    Google Web 1T 5-gram2006.08 · 数据·评测
    n-gram平滑方法要解决的正是数据稀疏问题，Web 1T用海量计数让稀疏程度大幅降低。
  • 竞争
    万亿词n-gram与Stupid Backoff2007.06 · NLP
    平滑研究追求更精细的折扣算法；这里以规模取代精细，大语料下简单回退就够用。
