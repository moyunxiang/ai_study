TD-MPC

Temporal Difference Learning for Model Predictive Control
2022.03论文延伸ICML 2022Nicklas Hansen, Xiaolong Wang, Hao Su · UC San Diego待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模型预测控制能随规划算力增加而变好，但长时域规划代价高，且准确的环境模型难学；无模型方法又样本效率低。

方法

只学一个任务导向的隐空间动力学模型，用它做短时域局部轨迹优化，再用学到的终端价值函数估计长期回报，两者都用时序差分联合训练。

影响

把无模型与有模型的优点合在一起，成为连续控制中样本高效的基线，并发展出TD-MPC2。

方法

TD-MPC不重建像素，而是学一个只保留对决策有用信息的隐状态（见Dreamer那类重建式世界模型的对比），模型预测下一隐状态、奖励和价值，全部用时序差分与自举损失联合训练。

控制时，在隐空间里对未来几步的动作序列做采样优化（MPPI式的模型预测控制），把第H步之后的回报交给学到的价值函数估计。这样规划只需看很短的时域。摘要称，它在DMControl和Meta-World的状态与图像输入任务上，样本效率和渐近性能都优于之前的工作。

局限与后续

  • 每步都要在线采样优化，推理比纯策略网络慢。

它建立在什么之上

  • 改进
    模型预测控制MPC1980 · 具身·世界模型 已核对
    每个控制周期都要在线解一次优化，炼油厂几分钟一次没问题，腿式机器人要在毫秒内算完，非线性问题更难实时。
  • 竞争
    Dreamer2019.12 · 具身·世界模型 待核对
    Dreamer学重建观测的世界模型并在想象中训练策略，TD-MPC用任务导向隐模型加在线规划。
  • 改进
    TD32018.02 · RL
    样本效率仍然有限，MuJoCo任务动辄要上百万步交互，难以直接用于真实机器人。
  • 延续
    MuZero2019.11 · RL
    同样不重建观测、只学对决策有用的隐模型与价值，并用于规划；但面向连续动作，用采样式MPC而非树搜索。
  • 改进
    PETS概率集成模型2018.05 · RL
    每个决策点都要做大量采样规划，推理开销高，难以用于高维动作或要求实时的场景。

后来的相关工作

  • 改进
    TD-MPC22023.10 · RL
    修正TD-MPC的梯度爆炸和超参数敏感，让它从单任务、逐任务调参变成一套超参数、可放大到3亿参数的多任务模型。

读懂它需要的概念

基于模型的强化学习 时序差分与自举 策略与价值函数 Actor-Critic与优势函数

本篇术语

  • MPPI　一种基于采样的模型预测控制：随机采样很多动作序列，按各自回报加权平均得到最优动作序列。
