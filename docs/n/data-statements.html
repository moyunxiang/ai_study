数据声明Data Statements

Data Statements for Natural Language Processing: Toward Mitigating System Bias and Enabling Better Science
2018论文延伸TACL 2018Emily M. Bender, Batya Friedman · 华盛顿大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

NLP系统用某些人群的语言数据训练，却被部署给另一些人使用；数据来自谁、什么方言、什么场景常常没有记录，导致系统对未被代表的人群表现差，论文结论也被过度推广。

方法

提出“数据声明”作为NLP研究与开发的职业惯例：每个数据集都附一份说明，交代选材理由、语言变体、说话人与标注者的人口特征、言语情境和文本特点等。

影响

与同年的Datasheets for Datasets、Model Cards一起，是数据与模型文档化的早期提案；它让“这份语料代表谁的语言”成为NLP论文应当交代的问题。

方法

Bender和Friedman的论点是：许多NLP中的科学和伦理问题，根源在于“用某些人群的数据开发给其他人群用的技术”。如果不清楚训练数据代表的是哪些说话人、哪种语言变体，就无法判断系统会在谁身上失效，也无法准确说明研究结论能推广到哪里。

数据声明的形式。论文给出一份模板，要求数据集作者说明：为什么选这些数据（选材理由）；数据属于哪种语言及其变体（例如美式英语还是印度英语，最好给出语言代码）；说话人的人口特征（年龄、性别、母语、地区等）；标注者的人口特征和背景；言语情境（时间、地点、书面还是口语、对谁说）；文本特征（体裁、话题）；对语音数据还包括录音质量。论文还讨论了在研究和产品开发中把它作为常规做法的影响。

作者认为，广泛采用数据声明可以缓解语言技术中的排斥与偏差，让关于泛化的结论更精确、工程效果更好，也能让企业避免公开的尴尬，最终让语言技术以用户自己的语言风格服务他们。它与数据集说明书Datasheets思路相近，但专门针对语言数据，强调语言变体和说话人群体；更早的数据集偏差则从视觉数据集的角度揭示了“数据从哪来”的影响。

  • 语言变体　同一种语言在不同地区、群体或场合中的不同形式，例如美式英语、非裔美国人英语、新加坡英语。
