变分推断

An Introduction to Variational Methods for Graphical Models
1999论文延伸Machine Learning 1999Jordan, Ghahramani, Jaakkola, Saul · MIT / UCL / UC Berkeley 等待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

复杂的概率图模型里，后验分布的精确计算指数级困难，只能靠采样（慢、难判断收敛）或手工近似。

方法

不求精确后验，而是在一个容易计算的分布族里找一个最接近它的分布，把推断变成最优化问题。

影响

系统化了变分方法，成为之后变分自编码器及各类带隐变量的深度生成模型的理论基础。

方法

目标是后验p(z|x)，直接算不动。取一族简单分布q(z)（例如把各隐变量假设独立的平均场族），找其中使KL(q ‖ p(z|x))最小的那个。

这个KL散度含有算不出的log p(x)，但可以改写为：log p(x) = ELBO(q) + KL(q ‖ p(z|x))，其中ELBO = E_q[log p(x,z)] − E_q[log q(z)]。log p(x)与q无关，所以最大化ELBO等价于最小化KL（见变分推断与ELBO）。ELBO是对数似然的下界，可以通过坐标上升逐个更新q的因子来最大化。

论文是教程式综述：把平均场、凸对偶方法、混合分布近似等放进统一框架，说明如何用在贝叶斯网络与概率图模型、隐马尔可夫模型等图模型上，并与EM算法（把E步换成近似E步）联系起来。

局限与后续

  • 每换一个模型都要手推更新公式，难以扩展到大数据和神经网络；每个数据点都有自己的q参数，规模随数据增长。
    后来针对它的工作　变分自编码器VAE
  • 平均场假设往往低估后验的方差和相关性，近似质量难以事先知道。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 改进
    EM算法1977 · 基础

  • 使用
    贝叶斯网络与概率图模型1988 · 基础

读懂它需要的概念

变分推断与ELBO KL散度 隐变量模型 概率图模型 EM算法

怎么学

先学KL散度和隐变量模型，读论文中平均场一节，再看变分自编码器VAE如何把q换成神经网络。动手：对高斯混合模型推导并实现平均场更新。
