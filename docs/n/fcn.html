全卷积网络FCN

Fully Convolutional Networks for Semantic Segmentation
2014.11论文延伸CVPR 2015Long, Shelhamer, Darrell · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语义分割要给每个像素分类，而分类网络的全连接层只输出一个标签，且要求固定输入大小。

方法

把全连接层改写成卷积层，网络可以接收任意大小的图像并输出对应大小的像素级预测；再用反卷积上采样，并融合浅层的细节特征。

影响

开创了端到端像素到像素的分割范式，后来的SegNet、DeepLab、PSPNet、Mask R-CNN都沿用了「全卷积」的思想。

方法

做法有三步。第一，把分类网络（AlexNet、VGG、GoogLeNet）末尾的全连接层看作覆盖整个特征图的卷积核，替换成卷积层，于是网络输出的是一张低分辨率的类别热图，而不是单个标签。第二，用可学习的上采样（转置卷积）把热图放大回输入尺寸。第三，提出「跳跃结构」：把深层粗糙但语义强的预测，与浅层精细但语义弱的特征相加，以恢复边界细节。

网络用分类任务的预训练权重初始化，再针对分割微调。摘要称在PASCAL VOC 2012上达到62.2%的平均IU，相对提升20%，在NYUDv2和SIFT Flow上也取得最好结果，推理一张典型图像约三分之一秒。

局限与后续

  • 多次池化后分辨率低，输出边界粗糙，小物体丢失。
    后来针对它的工作　DeepLab空洞卷积 SegNet
  • 缺少对全局上下文的显式建模，容易把相近类别混淆。
    后来针对它的工作　PSPNet

它建立在什么之上

  • 改进
    AlexNet2012.09 · 视觉 待核对
    只输出整张图的类别，不知道物体在哪里、有几个，不能直接用于检测和分割。
  • 使用
    VGG2014.09 · 视觉
    把VGG等分类网络改成全卷积后作为主干，并借其预训练权重。
  • 改进
    Canny边缘检测1986.11 · 视觉
    只看局部亮度突变，无法区分物体轮廓与纹理边缘，需要更高层的语义。
  • 改进
    归一化割1997.06 · 视觉
    只依据低层颜色纹理相似度，分出的是均匀区域，不一定对应语义上的物体。
  • 改进
    DeCAF通用深度特征2013.10 · 视觉
    特征来自分类任务，不含位置信息，难以直接用于检测和分割。
  • 改进
    Network In Network2013.12 · 视觉
    全局平均池化丢弃了空间位置信息，对需要定位的任务需要另外处理。

后来的相关工作

  • 改进
    DeepLab空洞卷积2014.12 · 视觉
    FCN的输出步长为32、边界粗糙；用空洞卷积把步长降到8，再用CRF细化边界，VOC 2012上从62.2%提升到71.6%。
  • 延续
    U-Net2015.05 · 视觉
    沿用全卷积、整图输入输出的做法，把FCN浅的上采样和相加式跳跃结构扩展成对称的深解码器加逐级拼接。
  • 使用
    Transporter Networks2020.10 · 具身·世界模型
    拿取打分和特征提取都用全卷积网络，借它的逐像素输出和平移等变性。
  • 使用
    CLIPort2021.09 · 具身·世界模型
    空间流和整体输出都是全卷积的逐像素热力图。
  • 改进
    SegNet2015.11 · 视觉
    保留全卷积的像素级预测，但把上采样改成复用池化索引。
  • 使用
    堆叠沙漏网络2016.03 · 视觉
    借用全卷积网络的上采样加跳连思想恢复分辨率。
  • 改进
    PSPNet2016.12 · 视觉
    保留FCN的全卷积框架，补上全局上下文。
  • 延续
    EAST文字检测2017.04 · 视觉
    沿用全卷积逐像素预测的思路，把输出换成文字得分加框几何量。
  • 延续
    全景分割2018.01 · 视觉
    语义分割部分沿用全卷积网络的逐像素预测。
