跨度式神经成分分析

A Minimal Span-Based Neural Constituency Parser
2017.05论文延伸ACL 2017Mitchell Stern, Jacob Andreas, Dan Klein · 加州大学伯克利分校待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经成分句法分析器要么是转移式的（贪心、易累积错误），要么把树线性化后用seq2seq生成（不保证输出合法树），缺少一个结构简单、又能精确解码的做法。

方法

让双向LSTM给句子中每一个片段(i, j)和每个标签单独打分，整棵树的分数就是它包含的所有片段分数之和；既可以用经典的图表动态规划精确求最优树，也可以自顶向下贪心地递归切分。

影响

在宾州树库上单模型F1达到91.79，结构极简却与复杂系统相当；「片段表示+图表解码」的框架被Kitaev与Klein的自注意力分析器直接继承，成为此后神经成分分析的主流范式。

背景

Charniak-Johnson重排序等统计分析器靠大量手工特征，F1停在91–92%附近。神经方法出现后，句法分析即翻译把树写成括号串用seq2seq生成，Stack-LSTM依存分析和RNNG循环神经网络文法则走转移式路线。BiLSTM特征依存分析已经说明，在依存分析里只要用双向LSTM给出好的上下文表示，打分函数可以非常简单。作者想在成分分析上验证同样的想法。

方法

片段表示。 先用多层双向LSTM读整句，得到每个位置的前向输出 f_t 和后向输出 b_t。片段(i, j)（词i+1到词j）的表示取两端之差：r_ij = [ f_j − f_i ; b_{i+1} − b_{j+1} ]，即这段区间里前向和后向LSTM各自「读进了多少新信息」。

打分。 一个前馈网络给每个片段的每个标签打分 s_label(i, j, ℓ)（包括表示「这不是一个成分」的空标签）。一棵树T的分数 s(T) = Σ_{(i,j,ℓ)∈T} s_label(i, j, ℓ)。

两种解码。 由于分数在片段上可分解，可以用CKY句法分析算法式的动态规划在O(n³)时间求出精确最优树：best(i, j) = max_ℓ s_label(i,j,ℓ) + max_k [ best(i, k) + best(k, j) ]。作者还提出一种贪心的自顶向下解码：对整句先选最优标签，再选一个切分点k把它一分为二，递归处理两半，复杂度更低，精度几乎不降。

训练。 用结构化的最大间隔损失：要求标准树的分数比任何其他树至少高出它们之间的汉明距离（错的片段数），损失增强解码同样用上面的动态规划完成。

结果

摘要报告：宾州树库单模型F1为91.79，法语树库F1为82.23，两种解码方式都与当时的最好工作相当。

后来的发展

第二年自注意力成分句法分析保留了片段打分和图表解码，只把双向LSTM换成自注意力编码器并加入预训练表示，F1进一步大幅提高；之后的成分分析器（包括基于BERT、XLNet的版本）基本都沿用这一框架。片段两端差分的表示方式也被用在共指消解、语义角色标注等以片段为单位的任务中。

本篇术语

  • 片段（span）　句子中一段连续的词，用起止位置(i, j)表示；成分树就是一组互相嵌套或不相交的带标签片段。
  • 最大间隔训练　要求正确结构的分数比错误结构高出一个与错误程度成正比的间隔，否则产生损失。

怎么学

先懂CKY句法分析算法和双向LSTM → 读原文第2–3节的片段表示与两种解码 → 动手：用PyTorch实现片段打分和O(n³)图表解码，在宾州树库的一个小子集上训练，再与贪心自顶向下解码比较速度和F1。
