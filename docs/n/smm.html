SMM状态边缘分布匹配

Efficient Exploration via State Marginal Matching
2019.06论文延伸Lisa Lee, Benjamin Eysenbach, Emilio Parisotto, Eric Xing, Sergey Levine, Ruslan Salakhutdinov · CMU / UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

已有的探索方法大多靠启发式的辅助预测（好奇心、预测误差、伪计数）引导行为，缺少一个有清晰数学性质的目标，也很难说清它们为什么有效。

方法

把探索重写为“状态边缘分布匹配”（SMM）：学一个策略，使其长期访问状态的分布匹配一个给定目标分布（通常为均匀分布，也可以放入先验）；这个目标可写成状态密度模型与策略之间的零和博弈。

影响

为“最大化状态熵”一类探索提供了统一的目标视角，并说明了以往好奇心类方法在近似优化什么；常与MaxEnt探索、APT、Skew-Fit等一起被讨论。

方法

设 ρ_π(s) 是策略π在一局里访问状态的边缘分布，p*(s) 是目标分布。SMM最小化二者的KL散度：

min_π KL(ρ_π(s) ‖ p*(s)) = max_π E_(ρ_π)[log p*(s) − log ρ_π(s)]

当 p* 为均匀分布时，这就是最大化访问状态的熵。难点在于 ρ_π 未知。作者把它写成二人博弈：一个密度模型 q(s) 去拟合策略访问过的状态，策略的奖励是 r(s) = log p*(s) − log q(s)，即去密度模型认为不常见的地方。两者交替更新。由于单个策略收敛后容易只覆盖分布的一部分，论文用历史上所有策略的混合（类似虚拟对弈）来近似博弈的均衡，并引入技能潜变量，让多个子策略分别覆盖不同区域。

在这个框架下，作者说明以往的好奇心、伪计数类方法都在近似最大化SMM目标，从而解释它们的成功。摘要称在模拟和真实任务上，用SMM预训练的智能体能更快地探索并适应新任务。
