Set-of-Mark提示

Set-of-Mark Prompting Unleashes Extraordinary Visual Grounding in GPT-4V
2023.10论文延伸arXiv 2023Jianwei Yang, Hao Zhang, Feng Li, Xueyan Zou, Chunyuan Li, Jianfeng Gao · Microsoft Research 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GPT-4V看得懂整张图，但很难准确说出“第几个物体在哪”，细粒度定位弱。

方法

用SAM等分割模型把图像分成区域，在每个区域上叠加字母数字等标记，再让GPT-4V在标记图上回答问题。

影响

不用训练，只靠改输入就显著增强了大模型的视觉定位，成为屏幕理解、智能体（如OmniParser）的常用提示技巧。

方法

Set-of-Mark（SoM）是一种视觉提示方法：先用现成的交互式分割模型（Segment Anything或SEEM）把图像切成不同粒度的区域，然后在每个区域上叠加数字、字母、掩码或框等标记。大模型看到的不再是原图，而是带编号的图，因此可以直接回答“编号3的物体是什么”或“把编号5和7比较一下”，把空间定位转化成读编号。

论文称，零样本的GPT-4V加SoM，在RefCOCOg上超过了完全微调的最先进指代表达理解和分割模型。

局限与后续

  • 依赖分割质量和标记不遮挡内容，标记多时画面拥挤。
