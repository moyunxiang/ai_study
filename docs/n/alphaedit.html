AlphaEdit零空间编辑

AlphaEdit: Null-Space Constrained Knowledge Editing for Language Models
2024.10论文延伸ICLR 2025Junfeng Fang, Houcheng Jiang, Kun Wang, Yunshan Ma, Shi Jie, Xiang Wang, Xiangnan He, Tat-seng Chua · 新加坡国立大学、中国科学技术大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

“先定位再编辑”的方法（ROME、MEMIT）给权重加一个扰动来写入新事实，但这个扰动不可避免地会破坏模型原本保存的知识，连续做成百上千次编辑后，模型性能明显崩坏。

方法

在把扰动加到参数之前，先把它投影到“需要保留的知识”所对应的零空间里；理论上这样保证模型对保留知识的输出完全不变，只需在原方法上多加一行投影代码。

影响

以极小的改动显著缓解了连续编辑中的知识破坏，摘要称平均把多数“定位再编辑”方法的表现提升36.7%，成为2025年知识编辑方向被广泛跟进的基线。

方法

背景：ROME知识定位与编辑和MEMIT批量编辑把FFN层的输出矩阵W看作键值记忆：键k是主语的中间表示，值v是要输出的属性表示。写入新事实就是求一个扰动Δ，使 (W+Δ)k₁ ≈ v₁（k₁、v₁是新知识的键值）。为了不破坏旧知识，它们在目标里加一项，要求对一批代表旧知识的键K₀仍有 (W+Δ)K₀ ≈ V₀。但这是在“写入新知识”和“保留旧知识”之间做软权衡，误差会随编辑次数累积，连续编辑时模型逐渐失效。

零空间投影：AlphaEdit换成硬约束。若Δ满足 Δ K₀ = 0，则 (W+Δ)K₀ = W K₀ = V₀，旧知识的输出就严格不变。满足这个条件的Δ，其行向量必须落在K₀的左零空间里。做法是：计算保留知识的键协方差 K₀K₀ᵀ 的特征分解，取特征值接近零的特征向量构成投影矩阵P，任何扰动乘上P后都满足 (ΔP)K₀ ≈ 0。于是AlphaEdit把原方法求得的扰动替换为ΔP，并且在求解时把“保留旧知识”那一项从目标中去掉，只专心写入新知识。

对连续编辑，前面已经完成的编辑的键也加入需要保护的集合，因此后面的编辑不会覆盖前面的。作者证明这种投影保证模型在被问到保留知识时输出不变。

摘要报告：在LLaMA3、GPT2-XL、GPT-J等模型上，只需为投影增加一行代码，就把大多数“定位再编辑”方法的性能平均提升36.7%。

后来的发展

零空间投影被后续不少连续编辑、终身编辑方法吸收或作为对照；它也让“编辑时保护已有知识”从软约束变成可证明的硬约束。

局限与后续

  • 保留知识由一批采样的键近似表示，零空间只对这些键严格成立，对未采样到的知识只能近似保护。

它建立在什么之上

  • 延续
    ROME知识定位与编辑2022.02 · LLM
    沿用ROME“FFN是键值记忆、定位后改权重”的框架，只在扰动上加一步投影。
  • 使用
    FFN即键值记忆2020.12 · LLM
    以FFN作为键值记忆为前提，把旧知识表示成一组键。
  • 改进
    MEMIT批量编辑2022.10 · LLM
    MEMIT用软约束平衡新旧知识，连续编辑后旧知识被破坏；AlphaEdit把扰动投影到保留知识的零空间，旧知识输出严格不变。
  • 改进
    知识编辑综述与EasyEdit2023.05 · LLM
    揭示的连续编辑退化与副作用问题在当时没有解决办法。
  • 竞争
    RippleEdits波及效应2023.07 · LLM
    RippleEdits关心编辑能否传播到相关事实，AlphaEdit关心编辑是否破坏无关旧知识，二者针对知识编辑的不同失败方式。

读懂它需要的概念

向量、矩阵与张量 特征分解与奇异值分解 低秩近似 多层感知机 协方差矩阵 持续学习与灾难性遗忘

本篇术语

  • 零空间　使矩阵乘积为零的所有向量构成的空间。扰动落在旧知识键的零空间里，旧知识的输出就不会改变。
  • 连续编辑　一次接一次地对同一个模型做大量编辑，要求后面的编辑不破坏前面的编辑和原有知识。

怎么学

先复习特征分解与投影矩阵，读ROME知识定位与编辑和MEMIT批量编辑的键值记忆公式；读本文第3节零空间投影的推导；动手：在GPT-2-XL上用官方代码分别跑MEMIT和MEMIT+投影连续编辑1000条事实，比较编辑成功率和在通用基准上的下降幅度。
