1X World Model

问题

通用机器人要在上千个任务上评估，真机测试既慢又不可复现，环境光线或背景一变，同一权重的表现也会掉。

方法

用机器人自己的海量数据训练一个视频式世界模型，在同一起始画面下按不同动作想象不同的未来，当作虚拟模拟器来评估策略。

影响

把世界模型从游戏、驾驶带到人形机器人评估，并同时公开数据集和公开竞赛，推动这一方向。

方法

1X在2024年9月17日的博文里指出，世界模型要解决一个被忽视的实际问题：评估。训练一个能做1000个任务的机器人后，很难知道新模型是不是在所有任务上都更好；官方展示了一个叠T恤的模型在50天里性能下降，因为环境在变，旧实验无法重现。

他们的做法是在视频生成和驾驶世界模型的基础上（见UniSim、Genie），用机器人数据训练模型，从同一段起始画面出发，根据不同动作提议想象不同的未来。官方称它能预测刚体碰撞、物体掉落、布料等可变形物体和抽屉门等铰接物体的交互，同时坦承目前仍有局限，并发布了新数据集和公开竞赛来鼓励研究。

局限与后续

  • 生成的未来画面并不总符合物理，物体形状会漂移，长时程预测不稳定，因此不能完全替代真机评估。

  • 作为评估器时，模型自身的偏差如何量化、是否与真机成功率一致，仍缺乏标准。
