DCS依存组合语义

Learning Dependency-Based Compositional Semantics
2011.06论文延伸ACL 2011Percy Liang, Michael I. Jordan, Dan Klein · 加州大学伯克利分校待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

语义解析把问题映射成可执行的逻辑形式再查数据库得到答案，但训练语义解析器通常需要人工标注每个问题的逻辑形式，成本很高，只有少数语言学专家能做。

方法

只用“问题—答案”对训练：把逻辑形式当作隐变量，模型自己搜索能算出正确答案的逻辑形式；为此设计一种新的语义表示DCS，其树结构与依存句法平行，并能被高效求值。

影响

在GeoQuery和Jobs两个标准语义解析基准上，不用任何标注的逻辑形式就取得了当时最高的准确率；“从答案弱监督学习语义解析”成为此后知识库问答（如Freebase语义解析）的主流设定，λ-DCS也成为常用的逻辑语言。

背景

GeoQuery与CHILL语义解析（1996）、语义解析（CCG）（2005）等语义解析器都在“句子—逻辑形式”标注对上训练。Clarke等（2010）开始尝试用答案作为监督，但需要较强的约束。一阶逻辑或λ演算的逻辑形式虽然表达力强，但在大的候选空间里搜索和求值都很昂贵。

方法

DCS树：逻辑形式是一棵树，节点是谓词（如 state、area、border、常量 Alaska），边上标注两个谓词在哪个参数位置上相连（相当于数据库表之间的连接条件）。例如“与阿拉斯加接壤的州”是 state 节点通过 border 关系连到 Alaska。树的结构与问题的依存句法相似，因此可以用类似句法分析的方式自底向上构造。

对于“最大”“数量”这类涉及量化和高阶操作的现象，DCS引入“标记—执行”机制：在下层节点处先“标记”一个操作（如argmax、count），到更高层节点再“执行”，以处理比较级、最高级和量词作用域。

学习：问题x、隐变量逻辑形式z、答案y，模型 p_θ(z | x) ∝ exp(θᵀ φ(x, z))，训练目标是最大化正确答案的边缘似然 Σ_{z: ⟦z⟧_w = y} p_θ(z | x)，其中 ⟦z⟧_w 表示在世界（数据库）w上执行z。用束搜索在候选DCS树中近似求和，并逐步迭代。词汇触发规则把问题中的词映射为可能的谓词，只需要少量人工的种子词表。

结果

在GEO（GeoQuery）和JOBS两个标准语义解析基准上，系统取得已发表结果中最高的准确率，而且训练时不需要任何标注的逻辑形式（原文摘要）。

后来的发展

Liang随后提出λ-DCS作为简化的逻辑语言；基于Freebase的语义解析问答（2013）把从问答对学习的语义解析扩展到大规模的Freebase，SEMPRE工具包成为知识库问答的标准平台。神经时代，Seq2Tree神经语义解析等Seq2Seq语义解析和弱监督的神经程序归纳（如Neural Symbolic Machines）沿用了“以答案为监督、逻辑形式为隐变量”的设定。

局限与后续

  • 以答案为监督会出现“伪逻辑形式”：碰巧算出正确答案但意义错误的逻辑形式也会被奖励。

  • 需要人工编写的词汇触发规则把词映射为谓词，难以直接扩展到大型开放知识库。

读懂它需要的概念

隐变量模型 命题逻辑、谓词逻辑与符号推理 逻辑回归 博弈树搜索：minimax与MCTS 动态规划

本篇术语

  • 语义解析　把自然语言句子转成机器可执行的逻辑形式（如数据库查询）。
  • 弱监督　训练时只给最终答案，不给中间的逻辑形式，模型要自己找出能得到答案的逻辑形式。
  • 伪逻辑形式　意义错误但在当前数据库上恰好能算出正确答案的逻辑形式。

怎么学

先读GeoQuery与CHILL语义解析和语义解析（CCG） → 读本文第2节DCS定义和第3节学习 → 动手：为“与德州接壤的州里面积最大的是哪个”写出DCS树，并在一个小的州数据库上手工执行它。
