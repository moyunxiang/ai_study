LLaDA2.0百亿级扩散

LLaDA2.0: Scaling Up Diffusion Language Models to 100B
2025.12论文延伸Tiwei Bie, Maosong Cao, Kun Chen, Lun Du, Mingliang Gong, Zhuochen Gong, Yanmei Gu, Jiaqi Hu et al. · 蚂蚁集团inclusionAI / 人民大学等待核对
arXiv ↗LLaDA2.1 arXiv ↗Hugging Face ↗在交互版中打开（演化树、学习进度）

问题

扩散语言模型最大只做到十几B参数，从头训练更大的又太贵，离前沿可用的规模差一个数量级。

方法

从训好的自回归MoE模型出发，用“块长先增后减”的三段式训练把它转成块扩散模型，再做SFT和DPO。

影响

发布时规模最大的开源扩散语言模型（100B总参数）；2026年2月的LLaDA2.1又加入“改已写的词”的编辑解码，进一步提速。

方法

LLaDA大语言扩散模型从头训练到8B，LLaDA-MoE做到MoE但规模仍小。LLaDA2.0换了思路：不从头训，而是继承已训好的自回归MoE模型的知识，渐进地改成扩散模型。

转换用一个借用学习率WSD（预热—稳定—衰减）思路的三阶段块级训练：预热阶段从小块的块扩散BD3-LM开始，逐步把块长加大；稳定阶段做大规模的整段扩散训练；衰减阶段再缩回小块，便于部署时块间复用KV缓存、块内并行解码。之后用SFT和DPO直接偏好优化做对齐，得到16B的LLaDA2.0-mini和100B的LLaDA2.0-flash两个指令版MoE模型，全部开源。

LLaDA2.1（arXiv 2602.08676）在原来“掩码→词”的解码之外加入“词→词”的编辑：允许模型在后续步骤里改掉早先写错的词。于是可以把揭开掩码的阈值调得很低以求速度，再靠编辑兜底（速度模式），或用保守阈值求质量（质量模式）；它还做了作者称首个面向dLLM的大规模强化学习。论文报告100B版本在HumanEval+上达到每秒892个token。

局限与后续

  • 报告的速度和质量多为作者自测，缺少与同代自回归模型在相同硬件、相同服务框架下的独立对比。

它建立在什么之上

  • 延续
    LLaDA大语言扩散模型2025.02 · LLM
    同一系列，从8B从头训练改为继承自回归模型，规模扩到100B。
  • 改进
    DiffuLLaMA自回归转扩散2024.10 · LLM
    转换后在知识问答、常识任务上仍明显落后于原来的自回归模型，几百亿token的继续预训练不足以完全保住原模型能力。
  • 使用
    块扩散BD3-LM2025.03 · LLM
    预热和衰减阶段都使用块扩散，部署形态也是块扩散。
  • 改进
    d1扩散模型推理RL2025.04 · LLM
    一步前向加平均场的似然估计偏差和方差都大，训练信号噪声高，规模一大就不稳定。
  • 改进
    Fast-dLLM免训练加速2025.05 · LLM
    Fast-dLLM靠免训练的近似缓存提速；LLaDA2.0在训练阶段就为块级缓存和并行解码做了适配。
  • 改进
    LLaDA 1.5与VRPO2025.05 · LLM
    只解决了离线DPO式的偏好优化；在线强化学习（如需要大量采样的GRPO）中扩散模型的采样慢、似然估计难的问题仍然突出。
  • 改进
    DiffuCoder代码扩散模型2025.06 · LLM
    只在7B规模和代码任务上验证，扩散代码模型放大到百亿参数后能否保住质量和速度没有回答。
  • 延续
    LLaDA-MoE2025.09 · LLM
    沿用MoE扩散模型的路线并大幅放大。
  • 竞争
    SDAR块扩散转换2025.10 · LLM
    同为自回归转块扩散；SDAR主张直接短暂适配，LLaDA2.0用块长先增后减的三阶段训练。
