Layer Normalization

Layer Normalization
2016.07论文重要arXiv预印本（2016）Jimmy Lei Ba, Jamie Ryan Kiros, Geoffrey E. Hinton · University of Toronto来源已核对
arXiv ↗PyTorch文档 torch.nn.LayerNorm ↗在交互版中打开（演化树、学习进度）

问题

批归一化要用一个小批量里所有样本来算均值和方差：批小就不准，训练和测试算法不一样，放进RNN还得每个时间步各存一套统计量。

方法

换个方向求平均：对单个样本在一层所有神经元上算均值和方差来归一化，不依赖批里的其他样本，训练、测试完全相同，RNN每一步直接照算。

影响

在多个RNN任务上让训练收敛更快；一年后被Transformer的每个子层采用，随Transformer进入之后的许多语言模型和视觉Transformer，后来的RMSNorm是它的简化版。

背景

Batch Normalization在2015年让卷积网络训练快了很多：它把每个神经元的输入减去这个小批量里的均值、除以标准差。但统计量来自“这一批的其他样本”，带来三个麻烦：批大小为1或很小时估计很不准；训练用批统计量、测试用全局滑动平均，两套计算不一致；在LSTM这类循环网络与隐状态里，每个时间步的输入分布不同，要按时间步分别存统计量，序列长度一变（测试时出现比训练更长的句子）就没法处理。Cooijmans等人的循环批归一化能用，但对缩放参数的初始值很敏感（他们发现增益初始化为0.1对最终效果影响很大）。同年稍早的权重归一化改为用权重向量的L2范数来归一化，不依赖批。

方法

设一层有H个神经元，对某一个样本，它们的加权输入（激活前）是a_1, …, a_H。层归一化计算

μ = (1/H) Σ_i a_i，σ = √[(1/H) Σ_i (a_i − μ)²]

然后每个神经元输出h_i = f( g_i·(a_i − μ)/σ + b_i )，g和b是每个神经元可学习的增益和偏置，用来恢复必要的尺度。

和BN的区别只在沿哪个维度求平均：把一个批的激活看成“样本数×神经元数”的矩阵，BN对每一列（同一神经元、不同样本）求平均，LN对每一行（同一样本、不同神经元）求平均。例如某样本一层的输入是[1, 2, 3, 6]，则μ = 3、σ ≈ 1.87，归一化后约为[−1.07, −0.53, 0, 1.60]，与批里别的样本无关。

在RNN里，每个时间步对W_h·h_{t−1} + W_x·x_t单独做一次层归一化，增益和偏置在所有时间步共享，所以序列多长都行。

论文还分析了不变性：LN的输出不随整个权重矩阵的缩放和整体平移、也不随单个样本输入的缩放而改变，论文认为这让隐藏状态的尺度不容易随时间步不断变大或变小，循环网络的动态更稳定。

结果

实验几乎都是RNN。图文检索（order-embeddings，MSCOCO）上加LN后达到最佳验证结果所需时间约为基线的60%，图像检索R@1从37.8升到38.9。注意力阅读器与CNN/DM阅读理解任务上，LN比基线和两种循环BN都收敛得更快、验证结果更好。Skip-Thought句向量句向量训练1M步后，在MR分类上从77.3%升到79.5%，SICK相关性和其余分类任务也全面提高。论文也坦白：在卷积网络上，LN比不归一化快，但不如BN——同一层不同位置、不同通道的统计特性差别太大。

后来的发展

2017年Transformer把LN放在每个注意力和前馈子层的残差相加之后，残差加LN成了Transformer层的基本结构（见Transformer层的结构），之后沿用Transformer层的BERT、GPT系列和Vision Transformer也都带着LN。后来的改动都围绕它：Pre-LN Transformer把LN移到子层之前，深层训练不再依赖warmup；RMSNorm去掉减均值的步骤只保留缩放，省计算且效果相当，被LLaMA等模型采用；Group Normalization在通道分组内归一化，补上了LN在卷积网络上的短板；2025年的无归一化Transformer DyT则尝试用一个逐元素的tanh函数取代归一化本身。

局限与后续

  • 在卷积网络上效果不如BN：一层所有通道、所有空间位置共用一组均值方差，抹掉了通道之间本应保留的差别。作者在原文中指出
    后来针对它的工作　Group Normalization
  • 需要同时计算均值和方差，论文没有分析两者各自的作用；后来发现减均值（重新中心化）这一步并非必要。
    后来针对它的工作　RMSNorm
  • 只给了归一化本身，没讨论和残差连接怎么摆放；放在残差之后（post-LN）的深层Transformer训练不稳定，必须用warmup。
    后来针对它的工作　Pre-LN Transformer
  • 每层都要做一次跨维度的规约运算，在大模型里占可观的时间，且归一化为什么有效仍缺少完整解释。
    后来针对它的工作　无归一化Transformer DyT

它建立在什么之上

  • 使用
    LSTM1997 · 基础 已核对
    主要实验把LN加在LSTM/GRU每个时间步的门输入上，用来稳定隐藏状态的动态。
  • 改进
    Batch Normalization2015.02 · 基础 已核对
    把求统计量的方向从“同一神经元跨样本”改成“同一样本跨神经元”，去掉了对批大小的依赖，训练和测试的计算完全相同。
  • 使用
    注意力阅读器与CNN/DM2015.06 · NLP 已核对
    在注意力阅读器上与循环批归一化正面比较，LN收敛更快且对初始化不敏感。
  • 使用
    Skip-Thought句向量2015.06 · NLP 已核对
    以Skip-Thought句向量为实验对象（原模型要训练好几天才有像样的结果），显示LN能加快训练，1M步后下游任务效果也更好。
  • 竞争
    权重归一化2016.02 · 基础 已核对
    权重归一化同样不依赖批，但用的是输入权重的L2范数，是对原网络的重新参数化；LN归一化的是激活，不是重新参数化，论文表1显示两者的不变性性质不同。
  • 改进
    He初始化与PReLU2015.02 · 基础
    推导假设各层独立同分布且只适用于整流类激活，对残差连接、LayerNorm、Transformer等结构需要另外调整初始化缩放。

后来的相关工作

  • 使用
    Transformer2017.06 · LLM 已核对
    每个子层的残差相加之后接层归一化（引用Ba等人），即LayerNorm(x + Sublayer(x))；论文没有解释为什么选它而不选BatchNorm。
  • 改进
    RMSNorm2019.10 · 基础 已核对
    去掉LayerNorm的减均值和偏置，只按均方根缩放，在精度相当的前提下减少每步计算开销。
  • 改进
    Pre-LN Transformer2020.02 · LLM 已核对
    不改LayerNorm本身，研究它在残差结构中的位置如何决定梯度大小。
  • 延续
    Group Normalization2018.03 · 基础 待核对
    LayerNorm是G=1的特例，GN把按组归一化推广到卷积的通道维度
  • 改进
    无归一化Transformer DyT2025.03 · 基础 待核对
    LayerNorm需要统计均值与方差；DyT用逐元素tanh取而代之，保留其压缩极端值的作用。
  • 使用
    WGAN-GP梯度惩罚2017.03 · 生成
    批归一化与逐样本梯度惩罚冲突，建议在判别器中改用层归一化。
  • 延续
    Conv-TasNet2018.09 · 语音
    提出在通道和时间两维上一起归一化的全局层归一化（gLN），以及用于因果版本的累积层归一化。
  • 使用
    1000层网络的自监督RL2025.03 · RL
    每个全连接层后接LayerNorm，与残差、Swish一起稳定上千层网络的训练。
  • 使用
    PQN简化深度TD2024.07 · RL
    LayerNorm是稳定TD训练的关键正则化。
  • 使用
    SimBa2024.10 · RL
    用层归一化控制特征尺度。

读懂它需要的概念

归一化层 循环网络与隐状态 期望与方差 多层感知机 批大小、步数与轮数

本篇术语

  • 增益与偏置（gain、bias）　归一化之后每个神经元再乘一个可学习的g、加一个可学习的b，让网络在需要时恢复原来的尺度和偏移。
  • 循环批归一化　Cooijmans等人2016年把BN用到LSTM里的做法，需要按时间步分别维护统计量。

怎么学

先弄懂Batch Normalization，再读原文第3、4节（两页，公式3–4和式(4)的RNN版本）。动手：用NumPy写出BN和LN，在一个形状为(批, 特征)的矩阵上分别沿axis=0和axis=1归一化，对比批大小为1时两者的输出；再读Pre-LN Transformer，理解LN在Transformer里摆放位置的影响。
