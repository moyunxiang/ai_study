GPT-1

Improving Language Understanding by Generative Pre-Training
2018.06论文主干OpenAI技术报告 2018Alec Radford, Karthik Narasimhan, Tim Salimans, Ilya Sutskever · OpenAI来源已核对
论文PDF ↗OpenAI博客 ↗The Illustrated GPT-2（含GPT结构图解） ↗在交互版中打开（演化树、学习进度）

问题

NLP任务的标注数据很少，每个任务都要设计专门的模型；预训练的词向量或LSTM特征只能迁移一小部分知识。

方法

先在大量书籍上训练一个只有解码器的Transformer语言模型，再在每个任务上整体微调；把句对、选择题等输入改写成一串token，同一个模型几乎不改结构就能做所有任务。

影响

12个数据集里9个超过当时最好结果，把“生成式预训练+判别式微调”推广到蕴含、问答、相似度等多种任务，也是后来GPT系列的起点。

背景

2018年上半年，迁移学习刚在NLP里起步。ELMo把预训练双向LSTM的隐状态当作特征，但每个任务仍需自己设计网络；ULMFiT做到了整体微调语言模型，可只用LSTM、只验证了文本分类。蕴含判断、问答、相似度这些涉及两段以上文本的任务，大家仍各自设计复杂的结构。

另一条线索来自OpenAI自己。情感神经元发现：只用来预测下一个字符的语言模型，内部会自发出现一个对应情感的神经元。这说明无监督的语言建模能学到有用的判别特征，只要数据和模型足够大。

与此同时，Transformer刚在机器翻译上显示自注意力结构效果好、也更易并行；GPT-1作者认为它比循环网络提供了“更有结构的记忆”来处理长距离依赖。这篇工作把这几条线拼在了一起。

方法

第一阶段：生成式预训练。在无标注文本U上最大化标准语言模型似然（见语言模型、自回归生成）：

L1(U) = Σ_i log P(u_i | u_(i−k), …, u_(i−1))

模型是12层、只有解码器的Transformer：带掩码的自注意力保证每个位置只看到左边，隐藏维度768、12个注意力头、前馈层3072维，激活函数用GELU，词表是4万次合并的BPE子词切分，上下文长度512。语料是BooksCorpus，7000多本未出版的书，长段连续文字让模型学会长距离依赖。训练100轮，批大小64。

第二阶段：判别式微调。对带标签的任务数据C，取最后一层最后一个token的表示，接一个新的线性层预测标签y，得到监督损失L2。同时保留语言模型损失作为辅助项：L3 = L2 + λ·L1，λ=0.5。大多数任务只需训练3轮。

输入改写。这是让一个模型通吃多种任务的关键。所有输入都加上开始和结束标记，然后：

  • 蕴含：前提 + 分隔符$ + 假设，拼成一串；
  • 相似度：两句没有先后之分，所以两种顺序各算一次，再把两个表示相加；
  • 问答和常识选择：文档 + 问题 + $ + 候选答案k，每个候选单独算一个分数，最后对所有候选做softmax。

这样新增的参数只有分隔符嵌入和最后的线性层。

结果

12个数据集中9个超过当时最好结果。常识推理Story Cloze绝对提高8.9个百分点，阅读理解RACE提高5.7，MultiNLI提高1.5，GLUE / SuperGLUE总分72.8，此前最好为68.9。

消融实验很说明问题：去掉预训练、直接在任务上训练同样的Transformer，表5的平均分从74.7降到59.9（论文称下降14.8%）；把Transformer换成单层2048单元的LSTM，平均分降5.6。迁移的层数越多越好，全部迁移时MultiNLI上最多多出9个点。论文还观察到，随着预训练进行，用启发式方法直接拿语言模型做任务（不微调）的效果稳步上升——这是后来零样本路线的萌芽。

后来的发展

四个月后，BERT保留“Transformer预训练+整体微调”的框架，但把单向语言模型换成双向的掩码语言模型，在GLUE上大幅超过它，且BERT-base特意与它同尺寸以便比较。OpenAI则沿着生成式这条线继续：GPT-2把参数放大到十倍以上、改用40GB网页文本，开始不微调直接做任务；GPT-3再放大百倍，靠上下文示例完成任务。截至2026年，多数大语言模型仍是只有解码器的自回归Transformer，与这篇工作所用的结构属于同一类。

容易误解的地方

  • “GPT”这个名字是后来才固定的，原论文标题里并没有出现GPT。
  • 它不是第一个“预训练语言模型再微调”的工作，序列预训练（Dai & Le）和ULMFiT更早；它的贡献是换成Transformer、并用输入改写把方法推广到几乎所有任务。
  • 微调时仍然需要每个任务的标注数据，零样本只是附带的观察。

局限与后续

  • 语言模型只看左边的上下文，对需要同时利用前后文的理解任务（如问答中的定位）不利。

  • 每个任务仍要收集标注数据并微调出一个独立模型，不微调直接做任务的能力还很弱。
    后来针对它的工作　GPT-2 GPT-3
  • 预训练语料只有约7000本书，模型也只有12层，规模远未到头。

它建立在什么之上

  • 延续
    序列预训练（Dai & Le）2015.11 · NLP 已核对
    Dai与Le用LSTM语言模型（及序列自编码器）预训练再微调做文本分类；OpenAI博客明说本文建立在这一方法之上，并把它换成Transformer、推广到更多任务。
  • 延续
    ULMFiT2018.01 · LLM 已核对
    沿用“预训练语言模型后整体微调”，把LSTM换成Transformer，并从文本分类推广到句对和多选任务。
  • 竞争
    ELMo2018.02 · LLM 已核对
    ELMo把双向LSTM状态当冻结特征、各任务另配模型；GPT-1整体微调一个单向Transformer，任务改动更小。在GLUE上，GPT-1的72.8高于论文列出的Multi-task BiLSTM+ELMo+Attn的68.9。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测 已核对
    主要评测基准之一，GLUE总分从68.9提高到72.8。
  • 使用
    BooksCorpus2015.06 · 数据·评测 已核对
    预训练语料，长篇连续文字利于学习长距离依赖。
  • 延续
    情感神经元2017.04 · NLP 已核对
    OpenAI博客称这一方法是在情感神经元工作之后发展出来的：无监督语言模型能学出判别特征，这里把这一观察做成通用的迁移方法。
  • 使用
    Transformer2017.06 · LLM 待核对
    只取Transformer的解码器部分（带掩码自注意力），去掉编码器和交叉注意力。
  • 改进
    递归张量网络与情感树库2013.10 · NLP
    需要对21万多个短语逐个人工标注，换一个领域或语言就得重做，成本很高。

后来的相关工作

  • 改进
    BERT2018.10 · LLM 已核对
    保留“Transformer预训练+整体微调”，针对GPT-1只能看左侧上下文的限制改用掩码语言模型，让每层都能看两侧；BERT-base特意与GPT-1同尺寸对比。
  • 改进
    GPT-22019.02 · LLM 已核对
    结构几乎不变，参数放大约十倍、数据从书籍换成网页，并去掉微调阶段改为零样本使用。
  • 改进
    GPT-32020.05 · LLM 已核对
    每个任务仍要收集标注数据并微调出一个独立模型，不微调直接做任务的能力还很弱。
  • 改进
    语言模型的规模定律2020.01 · LLM 待核对
    预训练语料只有约7000本书，模型也只有12层，规模远未到头。
  • 改进
    T52019.10 · LLM 待核对
    每类任务都要人工设计输入改写规则和分隔方式，换一种任务格式就得重新设计。
  • 使用
    Hugging Face Transformers2018.11 · 系统·效率
    把GPT等生成式预训练模型纳入同一接口，用户可在同一套代码中切换双向和单向模型。
  • 使用
    UniLM2019.05 · LLM
    把GPT的从左到右语言建模作为三种任务之一，用掩码实现。

读懂它需要的概念

语言模型 自回归生成 Transformer层的结构 自注意力与多头注意力 预训练与微调 分词与token Softmax与logits

本篇术语

  • 只有解码器的Transformer　去掉编码器和交叉注意力，只保留带掩码自注意力的那一半，每个位置只能看到它之前的token，适合做从左到右的语言模型。
  • 输入改写　把句对、文档+问题+答案等结构化输入用分隔符拼成一条序列，让为连续文本训练的模型可以直接读取。
  • 辅助语言模型损失　微调时在任务损失之外再加上语言模型损失，让模型不要偏离预训练学到的语言知识。

怎么学

先确认会语言模型、自注意力与多头注意力和预训练与微调。读原文第3节（框架与公式1–5）和图1右侧的输入改写示意，再看第5节的消融。动手：用nanoGPT在一小份文本上预训练一个小模型，然后加一个线性层在情感分类数据上微调，比较有无预训练、有无辅助损失的差别。
