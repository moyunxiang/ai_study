SwAV

Unsupervised Learning of Visual Features by Contrasting Cluster Assignments
2020.06论文延伸NeurIPS 2020Caron, Misra, Mairal, Goyal, Bojanowski, Joulin · Inria / Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

对比学习（SimCLR、MoCo）要把每张图和大量其他图逐对比较，需要大批量或记忆库，显存开销大。

方法

不直接比较特征，而是把特征分配到一组可学习的原型（聚类）上，让同一图像不同视图互相预测对方的聚类分配，再加多裁剪增强。

影响

在不用负样本对的情况下达到当时最好的自监督精度，多裁剪成为通用技巧。

方法

做法：每张图生成两个全分辨率视图，各自过网络得到特征；特征与K个可学习的原型向量做内积，通过在线的最优传输式归一化（Sinkhorn-Knopp，保证每个原型被均匀使用，避免所有图都分到同一类）得到“软聚类编码”；训练时让视图A的特征去预测视图B的编码，反之亦然，称为交换预测。这样不需要成对比较，也不需要记忆库或动量网络。第二个贡献是多裁剪：除两个大视图外，再加若干个小分辨率视图，计算量增加很少却提供更多比较。

论文报告ResNet-50在ImageNet上线性评估75.3% top-1，并在所有测试的迁移任务上超过有监督预训练（摘要）。

后来的发展

后续的DINO沿用多裁剪和自蒸馏思路；SwAV证明了自监督可以不依赖负样本。
