支持向量机

Support-Vector Networks
1995论文重要Machine Learning 1995Corinna Cortes, Vladimir Vapnik · AT&T贝尔实验室来源已核对
Machine Learning（DOI） ↗Wikipedia: Support vector machine ↗scikit-learn：SVM用户指南 ↗在交互版中打开（演化树、学习进度）

问题

最大间隔加核函数的分类器只适用于能被完全分开的数据，一个错标或重叠的样本就让它无解；而神经网络训练有局部极小、调参靠经验，泛化缺少理论保证。

方法

允许少数样本越过间隔甚至分错，但为每个违规付出与距离成正比的代价（软间隔），用参数C在“间隔大”和“违规少”之间权衡；问题仍是凸二次规划，配合核函数在高维特征空间里找最大间隔超平面。

影响

常被认为是1995年到2012年间最常用的通用分类器之一：有全局最优解、理论清楚、少量调参即可用，在文本分类、生物信息等领域长期是首选基线，直到深度网络在大数据上超过它。

背景

感知机能找到一个把两类分开的超平面，但分开的超平面有无数个，它找到哪个全凭运气；数据分不开时它永远不收敛。1992年的核技巧与最优间隔分类器给出了两个关键改进：在所有分开的超平面里选离两类最近样本最远的那个（最大间隔），并用核函数把它推广到非线性边界。按照VC维与一致收敛的理论，间隔越大，模型的有效容量越小，泛化越有保证。

剩下的硬伤是：最大间隔要求训练数据完全可分。真实数据总有噪声、错标和重叠的类别，此时“硬间隔”问题无解；而为了强行分开去用非常复杂的核，又会过拟合。

方法

硬间隔。对标签y_i ∈ {−1, +1}，找w和b使所有样本满足y_i(w·x_i + b) ≥ 1，同时最小化½‖w‖²。两条边界线w·x + b = ±1之间的宽度是2/‖w‖，所以最小化‖w‖就是最大化间隔。

软间隔（本文的贡献）。给每个样本一个松弛变量ξ_i ≥ 0，约束放宽为y_i(w·x_i + b) ≥ 1 − ξ_i，目标变成

min ½‖w‖² + C·Σ_i ξ_i

ξ_i = 0表示在间隔外、分对了；0 < ξ_i < 1表示在间隔内但仍分对；ξ_i > 1表示分错了。C大则严惩违规，C小则更看重宽间隔。等价地，这就是最小化合页损失max(0, 1 − y_i·f(x_i))加L2正则。

严格说，原文把惩罚写成更一般的C·F(Σ ξ_i)（F是单调凸函数），正文推导和实验用的是F(u) = u²，附录里也给出了F(u) = u的情形；今天通行的C·Σ ξ_i和下面的约束0 ≤ α_i ≤ C对应的是后者。

对偶与核。用拉格朗日乘子（见拉格朗日乘子、约束优化与对偶）转成对偶问题：

max Σα_i − ½ ΣΣ α_i α_j y_i y_j K(x_i, x_j)，约束0 ≤ α_i ≤ C，Σ α_i y_i = 0

数据只以内积K(x_i, x_j)的形式出现，所以可以换成核函数（见核技巧与间隔）。最终分类器是f(x) = sign(Σ α_i y_i K(x_i, x) + b)。只有α_i > 0的样本——落在间隔上或越过间隔的那些——参与预测，它们叫支持向量；其余样本删掉也不改变结果。

例子。16×16的手写数字图像是256维向量。多项式核K(x, x′) = (x·x′ + 1)^d取d = 2时，对应所有不超过二次的单项式，约3.3万维；论文表2给出的特征空间维数在d = 4时约10⁹，d = 7时约10¹⁶。直接构造这些特征不可行，但核函数只需一次256维内积再求幂。

结果

美国邮政手写数字（USPS）：7,300个训练样本、2,000个测试样本，16×16像素，训练数据线性不可分。多项式核从1次到7次的错误率依次为12.0%、4.7%、4.4%、4.3%、4.3%、4.2%、4.3%；作为对照，人类2.5%，CART决策树17%，C4.5决策树16%，最好的两层神经网络6.6%，专门设计的5层网络LeNet1为5.1%，二次及以上的多项式都好于LeNet1。特征空间维数从256增到约10¹⁶，支持向量数只从127增到190左右，错误率几乎不变，作者据此认为没有过拟合。

NIST手写数字：60,000个训练样本、10,000个测试样本，28×28像素，不做预处理，只训练了4次多项式核，十个分类器合起来的测试错误率1.1%，与线性分类器、3近邻、LeNet1、LeNet4在同一基准中比较。论文引用基准报告的话：它不包含任何关于问题几何结构的知识，把像素用固定的随机置换打乱也一样好。

论文还用到Vapnik理论里的一个界：测试错误率的期望不超过支持向量数的期望占训练样本数的比例；实验中按实际支持向量数算出的这个上界都成立，单个分类器的上界不超过3%。

后来的发展

此后十余年SVM是机器学习中最常用的方法之一：SVM文本分类在文本分类上确立了它的地位，LIBSVM让它成为人人可用的工具，MSTParser与MIRA等结构化学习方法沿用了间隔的思想，高斯过程回归等核方法形成一个大家族。2012年AlexNet在ImageNet上大幅领先基于手工特征的方法后，大规模视觉、语音任务转向深度网络。但合页损失、最大间隔的思想留了下来，例如人脸识别的ArcFace；梯度下降的隐式偏置还证明，在可分数据上用梯度下降训练的逻辑回归会收敛到最大间隔方向。

容易误解的地方

  • “支持向量机”这个名字是后来通行的；原文标题叫“支持向量网络”，把它定位为一种两层网络。
  • 核SVM的训练要处理N×N的核矩阵，样本到几十万以上就很吃力；线性SVM则可以很快。
  • SVM的输出是到超平面的有符号距离，不是概率，要概率需另行校准。

局限与后续

  • 训练是关于全部样本的二次规划，核矩阵大小为N×N，样本数上到几十万后时间和内存都难以承受。
    后来针对它的工作　LIBSVM
  • 核函数和其参数要人工挑选，模型本身不学习特征，在图像、语音这类原始输入上依赖手工特征。
    后来针对它的工作　AlexNet
  • 天生只做二分类，多分类要拆成多个二分类器拼起来，输出也不是概率。

读懂它需要的概念

核技巧与间隔 内积与余弦相似度 凸函数与凸优化 拉格朗日乘子、约束优化与对偶 正则化与权重衰减 监督学习

本篇术语

  • 间隔　分类超平面到最近训练样本的距离。间隔越大，新样本稍有扰动也不容易被分错。
  • 支持向量　落在间隔边界上或越过边界的训练样本。只有它们决定分类面，其余样本对结果没有影响。
  • 合页损失　max(0, 1 − y·f(x))：样本在间隔外正确一侧时损失为0，否则随越界距离线性增长。

怎么学

先补内积与余弦相似度、凸函数与凸优化和拉格朗日乘子、约束优化与对偶，再看核技巧与间隔。读原文前三节（最优超平面、软间隔、核卷积）；配合scikit-learn的SVM指南。动手：在二维的两个月牙数据上分别训练线性核与RBF核SVM，改变C和γ，画出决策边界并标出支持向量，观察C变小时支持向量增多、边界变平滑。
