向量空间模型

A Vector Space Model for Automatic Indexing
1975.11论文重要Communications of the ACM, Vol. 18, No. 11, pp. 613–620, 1975-11Gerard Salton, A. Wong, C. S. Yang · 康奈尔大学待核对
DOI ↗Cornell技术报告TR 74-218（扫描版） ↗Wikipedia: Vector space model ↗在交互版中打开（演化树、学习进度）

问题

检索系统该选哪些词做索引、每个词给多大权重，靠的是经验和逐个试；没有一个统一的框架解释为什么某种索引方法好。

方法

把每篇文档和查询都看成“词表那么多维”的向量，用夹角衡量相似；好的索引应让文档在空间里彼此散开，于是能按“一个词让空间散开多少”给词打分。

影响

“文档=向量、相关=夹角小”从此成为检索和文本处理的通用语言；LSA、词向量、稠密检索都是在换一种方式得到这个向量。

背景

Salton在康奈尔主持的SMART系统，从1960年代起就把文档表示成带权重的索引词集合，并在Cranfield等测试集上比较各种做法。IDF与TF-IDF已经说明按文档频率加权有效：在一组实验里，词频乘上IDF比单用词频的平均查准率高约14%。

但这些结论是零散的：为什么IDF有用？高频词、低频词各该怎么处理？短语和叙词表什么时候有帮助？缺一个能统一解释这些现象、并据此设计索引的模型。

方法

向量表示。有t个索引词时，文档 D_i = (d_i1, d_i2, …, d_it)，d_ij 是第j个词的权重（0/1或TF-IDF）。两篇文档的相似度取为向量夹角的减函数，实践中就是余弦 cos(D_i, D_j) = D_i·D_j / (|D_i||D_j|)。查询也是这样的向量，按余弦从高到低返回文档。

空间密度。作者猜想：最好的索引空间是文档彼此离得最远的空间，这样取回一篇相关文档时不会顺带取回一堆邻居。直接算所有文档两两相似度要 n² 次，所以改用每篇文档与全体文档的质心（各维平均）的相似度之和 Q = Σ s(C*, D_i)，计算量降到n。

区分值。词k的区分值 DV_k = Q_k − Q，其中 Q_k 是把词k从所有向量中删掉后的密度。删掉它后空间变紧（Q_k > Q），说明它是好的区分词。

由此得到的索引策略。在450篇医学文档、4726个词上按文档频率统计区分值排名：只出现在1篇文档里的几千个词平均排名在3000名以后；文档频率超过25的词平均排名在4000名以后；最好的是文档频率大约在 n/100 到 n/10 之间的词。于是：中频词直接用；高频词组合成短语（“programming language”比program或language都少见）；低频词归并成叙词表类，提高频率。

结果

在424篇空气动力学文档上，换成TF-IDF后文档空间的密度确实下降；反过来按文档频率正向加权（常见词权重大），性能比基线下降约10%，空间变得更挤。人为调整权重让空间散开，性能小幅上升；让空间变挤，查全查准损失12–13%。在Medlars的450篇文档上，用短语替换高频词使十个查全率点上的平均查准率提高39%；短语加叙词表在三个集合上比基线提高17%（Time新闻）到50%（医学）。

后来的发展

Salton的SMART系统和这篇论文让“TF-IDF向量 + 余弦”成为1980–2000年代检索系统的标准配置，也被用到文本分类和聚类上。它把每个词当作一个互相正交的维度，同义词完全无关——潜在语义分析LSA正是对这个词-文档矩阵做SVD来解决这一点。BM25则从概率模型出发重新推导权重，在TREC文本检索评测上逐渐取代了余弦加权。神经网络时代，DSSM深度语义匹配、稠密检索DPR和FAISS向量检索把“文档是向量、按相似度检索”原封不动地保留下来，只是把稀疏的词向量换成了学习得到的稠密向量。

容易误解的地方

  • 向量空间表示在SMART系统中早已使用，这篇论文的新意是“空间密度与检索性能相关”以及据此提出的区分值索引理论。
  • 论文的“空间越散越好”是一个经验猜想，作者自己也说无法给出最优性的严格证明。

局限与后续

  • 每个词是独立且互相正交的维度，“汽车”和“轿车”的相似度为0，查询和文档用词不同就搜不到。

读懂它需要的概念

向量、矩阵与张量 内积与余弦相似度 范数与距离 独热编码与词表 聚类 准确率、精确率、召回率与F1

本篇术语

  • 质心（centroid）　一组向量逐维取平均得到的向量，可看成这组文档的“平均文档”。
  • 区分值（discrimination value）　一个词加入索引后，文档之间平均相似度下降了多少。下降越多，这个词越能把文档区分开。
  • 叙词表（thesaurus）　检索领域里把意思相近的词归到同一类的表，查询或索引时可以用类代替单个词。
