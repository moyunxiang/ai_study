PPO

Proximal Policy Optimization Algorithms
2017.07论文主干arXiv 2017Schulman, Wolski, Dhariwal, Radford, Klimov · OpenAI来源已核对
arXiv ↗Spinning Up：PPO ↗The 37 Implementation Details of PPO ↗在交互版中打开（演化树、学习进度）

问题

策略梯度每批数据只能更新一步，步子大了策略会崩；TRPO用KL约束保证稳定，但需要二阶优化和共轭梯度，实现复杂，也不兼容策略与价值共享参数、dropout等常见网络设计。

方法

把新旧策略的概率比r限制在[1−ε, 1+ε]之内：目标函数取“原始目标”和“裁剪后目标”中较小的那个，超出范围就不再有好处，于是可以在同一批数据上用普通SGD/Adam放心地训练多轮。

影响

只需在普通策略梯度代码上改几行，就有TRPO的稳定性和更好的样本效率，之后被广泛采用：OpenAI Five、Dactyl灵巧手、InstructGPT与RLHF与ChatGPT的RLHF都用PPO训练。

背景

策略梯度方法（见策略梯度）的基本形式是：用当前策略采一批数据，算出每个动作的优势Â（多好于平均，常用广义优势估计GAE估计），然后把好动作的概率调高、坏动作的调低。麻烦在于步长：一步迈太大，新策略和采数据的旧策略差得太远，梯度估计失效，策略可能一下子崩坏、再也采不到好数据。所以REINFORCE策略梯度和A3C一批数据只敢更新一次，样本效率很低。

TRPO（2015）的解决办法来自保守策略迭代CPI和自然策略梯度：最大化一个“替代目标”，同时约束新旧策略的平均KL散度（见KL散度）不超过δ。这在理论上保证了近似的单调改进，实践中也很稳定，但每一步要用共轭梯度近似求解带约束的二阶优化，代码复杂；而且当策略和价值函数共享网络、或网络里有dropout等噪声时不好用。有没有只用一阶优化、像普通深度学习那样训练，又能保持TRPO稳定性的方法？

方法

替代目标。设r_t(θ) = π_θ(a_t|s_t) / π_旧(a_t|s_t)，即新策略相对采样时旧策略选这个动作的概率比。TRPO优化的替代目标是E[r_t · Â_t]：若Â>0就增大r，Â<0就减小r。如果不加约束，SGD会把r推得很远。

裁剪。PPO的核心目标是：

L_CLIP(θ) = E_t[ min( r_t·Â_t , clip(r_t, 1−ε, 1+ε)·Â_t ) ]，ε常取0.2。

用一个例子读懂它：某动作Â=+1（是好动作），一开始r=1。增大它的概率时目标随r线性上升，但r超过1.2后，裁剪项固定在1.2，min取到这个上限，再增大r就没有任何梯度了。反之，对坏动作（Â<0），r低于0.8后也不再奖励继续压低。取min的作用是：只在“对自己有利”的方向上截断，在“变差”的方向上照样惩罚，所以L_CLIP是未裁剪目标的一个悲观下界。

算法。N个并行actor各跑T步收集数据，用GAE计算优势，然后在这N×T条数据上用小批量Adam训练K轮（例如MuJoCo上T=2048、K=10、批大小64），再丢掉数据重新采样。若策略与价值网络共享参数，总损失为L_CLIP − c₁·L_价值 + c₂·熵奖励。

论文还给出另一个变体：在目标里减去β·KL(π_旧‖π_θ)，并自适应调整β（KL太大就加倍、太小就减半）。实验中它不如裁剪版。

结果

在7个MuJoCo连续控制任务上（每个100万步，每种设置3个种子），按归一化分数比较目标函数的变体：不裁剪也不加惩罚为−0.39（在HalfCheetah上比随机策略还差），ε=0.2的裁剪最好，为0.82；最好的自适应KL为0.74，最好的固定KL为0.72。与TRPO、交叉熵法、A2C等方法相比，PPO在几乎所有连续控制任务上最好，并在Roboschool中学会了让三维人形机器人奔跑、转向追逐目标、被方块击倒后爬起。在49款Atari游戏上，按整个训练过程的平均回报（衡量学得快），PPO赢30款、ACER赢18款、A2C赢1款；按最后100回合（衡量最终性能），ACER赢28款、PPO赢19款——PPO与更复杂的ACER大致相当，实现却简单得多。

后来的发展

PPO之后被大量采用：OpenAI Five用它在Dota 2上击败世界冠军，Dactyl灵巧手用它在仿真中训练机械手，捉迷藏中的涌现工具使用、腾讯绝悟王者荣耀AI、RL芯片布局（AlphaChip）也基于它；多智能体的MAPPO报告，在四个合作多智能体测试平台上它与离策略方法相当或更好。最大的影响在语言模型：从人类偏好学习奖励式的奖励模型加PPO构成了InstructGPT与RLHF和ChatGPT的RLHF流程（见人类反馈强化学习）。

它的弱点也引出了后续工作。PPO的实现细节之争发现PPO相对TRPO的优势很大程度来自代码层面的细节（奖励缩放、价值裁剪、学习率退火等）。在大语言模型上，PPO需要一个与策略同规模的价值网络，GRPO去掉价值网络改用组内比较，DeepSeek-R1用它训练出推理模型；DPO直接偏好优化则绕过强化学习，直接用偏好数据做监督式优化。

容易误解的地方

  • 裁剪并不能严格保证新旧策略的KL小于某个值：多轮训练后r仍可能远远越界，只是越界后不再有梯度推动它。实践中常再加“KL过大就提前停止”的检查。
  • 论文的性能很依赖实现细节：优势归一化、观测与奖励的标准化、正交初始化、学习率退火等。两份“PPO”实现的结果可能差很多。
  • PPO是on-policy算法：每批数据训练K轮后就丢弃，不能像DQN那样长期存放在回放池中重复使用。

局限与后续

  • on-policy，每批数据用几轮就丢，样本效率远低于离策略方法，真实机器人上难以直接训练。

读懂它需要的概念

策略梯度 Actor-Critic与优势函数 KL散度 重要性采样 on-policy与off-policy 自适应学习率优化器 信息量与熵

本篇术语

  • 概率比r　新策略与采样时旧策略选同一动作的概率之比。r=1表示没变，r=1.5表示这个动作被选中的概率提高了50%。
  • 替代目标　用旧策略采的数据、通过重要性采样比估计新策略表现的目标函数。只在新旧策略接近时可靠，所以要限制更新幅度。
  • 信赖域　只在旧参数附近一个“可信”的小范围内优化，因为替代目标只在那里近似准确。TRPO用KL约束显式定义它，PPO用裁剪隐式近似。
  • 熵奖励　在目标中加上策略的熵，鼓励策略保持一定随机性，防止过早收敛到确定性动作。

怎么学

先补策略梯度、Actor-Critic与优势函数和重要性采样，并读懂广义优势估计GAE。读原文第3节（裁剪目标与图1、图2）和第5节算法1；对照Spinning Up的PPO页面。然后读“The 37 Implementation Details of PPO”，用CleanRL的ppo.py在CartPole和一款Atari游戏上跑通，逐项关掉实现细节（如优势归一化）观察效果。

  • 表3：T = 2048、Adam 3×10⁻⁴、10轮、批64、γ = 0.99、λ = 0.95；截断GAE
  • 连续控制对比TRPO、CEM、自适应步长的vanilla PG、A2C、带信任域的A2C，“PPO outperforms the previous methods on almost all the continuous control environments”
  • Roboschool三个人形任务（奔跑、追逐目标、被方块击倒后爬起）
  • 表2：49款Atari，全程平均回报A2C 1、ACER 18、PPO 30；最后100回合A2C 1、ACER 28、PPO 19、平局1
