Gender Shades与算法公平

Gender Shades: Intersectional Accuracy Disparities in Commercial Gender Classification
2018.02论文延伸FAT* 2018 (PMLR 81)Joy Buolamwini, Timnit Gebru · MIT Media Lab / Microsoft Research待核对
PMLR ↗在交互版中打开（演化树、学习进度）

问题

商用人脸分析系统只报告整体准确率，常用测试集又以浅肤色为主，不同人群上的差距看不到。

方法

建立按性别和肤色（Fitzpatrick分型）均衡的数据集，分子群评估三家商用性别分类器，揭示交叉身份上的差距。

影响

让按子群、按交叉身份评估成为公平性审计的常规做法，并促使相关公司更新产品、部分机构限制人脸识别。

方法

作者先指出两个常用基准IJB-A和Adience中浅肤色人脸占比分别为79.6%和86.2%，整体准确率因此掩盖了问题。他们新建了一个在性别和肤色上更均衡的数据集，用它测试三个商用的性别分类系统，并把结果按「性别×肤色」四个交叉子群拆开看。

结果是深肤色女性的错误率最高，达到34.7%，浅肤色男性最高只有0.8%。这种按交叉子群拆分的审计方式，后来成为评估人脸识别和其他模型公平性的标准动作。

局限与后续

  • 只覆盖二元性别分类和肤色分型，且只评估了三家商用产品，不能代表所有人脸任务和更多身份维度。
