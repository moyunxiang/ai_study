Snakes主动轮廓

Snakes: Active Contour Models
1988.01论文延伸IJCV 1988Michael Kass, Andrew Witkin, Demetri Terzopoulos · Schlumberger Palo Alto Research待核对
DOI ↗维基百科 ↗在交互版中打开（演化树、学习进度）

问题

边缘检测（如Canny边缘检测）给出的边缘是断断续续的局部碎片，不能直接得到一个物体完整、平滑、闭合的轮廓。

方法

把轮廓看成一条有弹性、有刚度的曲线（“蛇”），定义一个能量：内部能量让曲线保持连续平滑，外部能量把曲线吸向图像边缘；从一个初始轮廓出发，通过最小化能量让它自动“爬”到物体边界上。

影响

开创了基于能量最小化的可变形模型这一大类方法，在医学图像分割、轮廓跟踪中广泛使用，并引出了水平集、主动形状模型等后续路线。

方法

一条snake是参数曲线 v(s) = (x(s), y(s))，s从0到1。它的能量是 E = ∫ [E_int(v(s)) + E_image(v(s)) + E_con(v(s))] ds：

  • 内部能量 E_int = (α|v′(s)|² + β|v″(s)|²)/2：一阶导数项像橡皮筋，惩罚拉长；二阶导数项像薄钢片，惩罚弯折。α、β控制曲线的弹性和刚度。
  • 图像能量：例如取 −|∇I|²，梯度越大（越像边缘）能量越低，于是曲线被吸向边缘；也可以加入线条、端点等项。
  • 约束能量：用户可以在界面上加“弹簧”或“火山”，把曲线拉向或推离某处。

用变分法得到欧拉-拉格朗日方程，离散化后迭代求解，曲线就像在势能面上滑动一样逐步收敛到附近的低能量位置。维基百科指出，snakes并不能单独解决找轮廓的全部问题，需要用户交互或更高层的理解给出初始位置。

局限与后续

  • 只能收敛到初始轮廓附近的局部极小，初始化离目标稍远或遇到凹陷边界就会失败。

读懂它需要的概念

导数、偏导与梯度 图像作为张量 梯度下降 损失函数

本篇术语

  • 能量最小化　把想要的结果写成一个能量（代价）函数，好的解能量低，再用优化方法找到能量最低的解。
  • 变分法　求一个函数（这里是整条曲线）使某个积分形式的能量取极值的数学方法。

怎么学

先弄懂图像梯度和梯度下降，再读论文第2节能量定义；用scikit-image的active_contour在一张细胞或硬币图上从圆形初始化演化，调α、β观察轮廓变化。
