集体宪法AI

Collective Constitutional AI: Aligning a Language Model with Public Input
2023.10论文延伸FAccT 2024Saffron Huang, Divya Siddarth, Liane Lovitt, Thomas I. Liao, Esin Durmus, Alex Tamkin, Deep Ganguli · Anthropic、Collective Intelligence Project待核对
arXiv ↗Anthropic博客 ↗在交互版中打开（演化树、学习进度）

问题

Constitutional AI把模型该遵守的原则写成一份“宪法”，但这份宪法由开发公司自己写。越来越多的人认为，影响大众的模型行为不该只由开发者决定，可当时没有把公众意见真正训练进模型的可行流程。

方法

设计一个多阶段流程：确定目标人群，在线征集并投票筛选他们认可的原则，把这些原则整理成一份公众宪法，用与Constitutional AI相同的方法训练模型，再与用公司原则训练的基线模型对比。

影响

据作者所知是第一个用集体征集的公众意见微调的语言模型，为“谁来决定模型的价值观”提供了一个可操作的参考流程，常在民主化对齐和多元价值对齐的讨论中被引用。

方法

流程分四步：

  • 确定人群：作者与集体智能项目合作，招募约一千名在人口统计上大致代表美国成年人的参与者。
  • 征集原则：在在线审议平台Polis上，参与者可以提交关于AI应当如何行为的陈述，并对他人的陈述投赞成或反对票。平台会把意见分群，找出跨群体都获得较高认同的陈述。
  • 形成宪法：把高共识的陈述整理、去重，转写成Constitutional AI所用的原则格式，得到一份“公众宪法”。
  • 训练与评测：分别用公众宪法和Anthropic已有的原则训练两个模型，其他设置保持一致，再比较二者。

摘要报告的定量结果是：用公众宪法训练的模型在九个社会维度上偏见更低（用BBQ偏见问答基准类的偏见基准衡量），而在语言、数学以及有用无害评测上的表现与基线相当。定性比较显示，两个模型的差别与各自宪法的内容相符，例如面对有争议的话题时，CCAI模型更倾向于把问题正面地重新表述，而不是直接拒绝。

局限与后续

  • 参与者只代表美国一国的样本，原则经过研究者的整理和转写，存在选择与解释偏差；也没有解决不同群体价值观冲突时该如何取舍。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    Constitutional AI2022.12 · 安全·可解释
    保留用书面原则训练模型的方法，把原则的来源从开发者换成公众集体征集。
  • 使用
    BBQ偏见问答基准2021.10 · 安全·可解释
    用BBQ等偏见基准比较两个模型，CCAI模型在九个社会维度上偏见更低。
  • 使用
    Claude初代2023.03 · LLM
    基线原则来自Anthropic为Claude系列模型使用的宪法。

本篇术语

  • 宪法　Constitutional AI中用来指导模型自我批评和偏好判断的一组书面原则。
  • Polis　一个在线审议平台，参与者提交和投票陈述，系统找出不同意见群体之间的共识。

怎么学

先读Constitutional AI → 读原文第2节征集流程和第4节对比实验 → 比较公众宪法与公司原则的差异，思考哪些价值适合由公众决定、哪些不适合。
