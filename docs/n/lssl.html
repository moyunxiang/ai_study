LSSL线性状态空间层

Combining Recurrent, Convolutional, and Continuous-time Models with Linear State-Space Layers
2021.10论文延伸NeurIPS 2021Albert Gu, Isys Johnson, Karan Goel, Khaled Saab, Tri Dao, Atri Rudra, Christopher Ré · 斯坦福大学、布法罗大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

时间序列建模有三大家族：循环网络、时间卷积和神经常微分方程，各有长处也各有短板（RNN难并行、卷积感受野有限、神经ODE慢），而且都难以处理上万步的长依赖。

方法

直接模拟控制论里的连续时间线性状态空间系统 x′ = Ax + Bu, y = Cx + Du 作为一层网络；同一个层既能写成递推（像RNN），也能写成卷积（可并行训练），还天然是连续时间模型；再用HiPPO理论选出能长期记忆的结构化矩阵A。

影响

LSSL是HiPPO与S4结构化状态空间之间的关键一步：它把HiPPO矩阵放进一个可训练的深度序列层，并展示了“递推/卷积/连续时间”三种视角的统一；但它的计算方式开销太大，同一团队随后不久发布的S4给出了高效算法，此后的S4D、Mamba等都沿用了这套状态空间层的框架。

方法

LSSL层把输入序列u映射为输出序列y，内部维护一个N维状态x。连续时间系统先按步长Δ离散化（论文用双线性变换），得到 x_k = Ā x_{k−1} + B̄ u_k, y_k = C x_k + D u_k。

三种视角：

  • 递推视角：按上式一步步更新状态，推断时每步代价固定，像一个线性RNN。作者还指出，RNN里常见的门控在一定意义上对应于这种离散化中的步长选择。
  • 卷积视角：由于系统是线性时不变的，把递推展开后输出等于输入与核 K = (CB̄, CĀB̄, CĀ²B̄, …) 的卷积，训练时可以对整条序列并行计算。
  • 连续时间视角：Δ是可学习的参数，模型能适应不同的时间尺度和采样率，这与神经ODE类似。

若A随机初始化，状态会迅速遗忘过去。LSSL把A取为HiPPO推出的结构化矩阵（使状态始终近似记录输入历史在勒让德多项式上的投影），并让A在一个可训练的结构化矩阵子集里学习，从而获得长程记忆。

摘要报告：把LSSL层堆叠成简单的深度网络，在序列图像分类、真实医疗时序回归和语音等长依赖基准上取得最好结果；在序列长度16000的困难语音分类任务上比以往方法高24个百分点，甚至超过了在短100倍的手工特征上训练的基线。

局限与后续

  • 计算卷积核需要反复计算矩阵Ā的幂，对状态维度N的时间和内存开销很大，数值上也不稳定，难以用于大模型。

  • 参数是线性时不变的，同一层对所有输入用同样的动力学，不能按内容选择记住或忽略什么。

读懂它需要的概念

状态空间模型与线性RNN 循环网络与隐状态 卷积运算 常微分方程与随机微分方程 梯度消失与梯度爆炸

本篇术语

  • 离散化　把连续时间的微分方程换成按固定步长Δ更新的差分方程，才能在离散的序列数据上计算。

怎么学

先读HiPPO和状态空间模型与线性RNN概念；用NumPy实现一个N=16的离散线性状态空间，分别用递推和卷积两种方式计算同一输入的输出，验证结果一致；再读S4结构化状态空间看它如何解决LSSL的计算瓶颈。
