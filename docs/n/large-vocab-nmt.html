大目标词表NMT

On Using Very Large Target Vocabulary for Neural Machine Translation
2014.12论文延伸ACL 2015Sébastien Jean, Kyunghyun Cho, Roland Memisevic, Yoshua Bengio · 蒙特利尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经机器翻译的训练和解码代价都与目标词表大小成正比，所以模型通常只保留3万到8万个最常见的词，其余一律换成[UNK]；句子里未登录词一多，译文质量就迅速下降。

方法

训练时用带偏的重要性采样：把训练语料分成若干块，每块只用其中出现过的目标词（上限τ个）计算softmax，使每步的代价与总词表无关；解码时为每个源句挑一个小的候选目标词集合（最常见的K个词加上词典中每个源词最可能的K′个译词）。

影响

目标词表扩大到50万后，单模型超过同结构的小词表基线和Sutskever等的LSTM模型；8个模型集成在WMT’14英法上达到37.19 BLEU、英德上达到21.59 BLEU，与当时最好的系统相当。这套「采样训练加候选列表解码」是子词切分普及之前处理大词表的主要办法。

方法

问题来源。注意力翻译模型（注意力机制，即RNNsearch）在每个目标位置要计算p(y_t|…) = exp(E(y_t)) / Σ_{k∈V} exp(E(y_k))，分母对整个目标词表V求和，梯度里也有一项是全词表的期望。V从3万增大到50万，计算量和显存都翻十几倍。

训练：重要性采样近似。把梯度中的期望Σ_k p(y_k)·∇E(y_k)用一个提议分布Q下的少量样本近似，权重ω_k = exp{E(y_k) − log Q(y_k)}。实际做法是把训练语料按顺序切成若干块：依次读目标句子，累积不同的目标词直到达到阈值τ，这些词构成这一块的子词表V′_i，块内所有句子的softmax只在V′_i上计算。这相当于每块用一个在V′_i上均匀的提议分布，代入权重后提议分布的校正项相互抵消，近似梯度就等于只在V′_i上做softmax的梯度；于是每步更新的参数量受τ控制、与总词表无关。训练结束后，输出层可以对完整词表计算概率。

解码：候选列表。对每个源句，候选目标词集合由两部分组成：按一元频率最常见的K个词（如1.5万到5万），以及用已有的词对齐模型建的词典中、每个源词最可能的K′个译词（如10到20个）。只在这个集合上做softmax和集束搜索。对仍然无法翻译的词，再用注意力权重找到对应的源词，用词典替换[UNK]。

结果。在WMT’14英法上，单模型RNNsearch-LV从基线的29.97逐步提高到34.60 BLEU（加候选列表、未登录词替换和数据重排），超过标准短语翻译系统；8模型集成37.19。英德上单模型19.40，集成21.59，超过短语翻译系统的20.67。

读懂它需要的概念

编码器-解码器 注意力机制 Softmax与logits 重要性采样 解码：贪心、束搜索、温度与top-p 文本生成的自动指标

本篇术语

  • 未登录词　不在模型词表里的词，在神经翻译中通常被替换成统一的[UNK]记号。
  • 候选列表　解码时为每个源句挑出的一小组可能出现在译文中的目标词，只在它们之间做softmax。

怎么学

先读注意力机制的讲解和重要性采样 → 读原文第3节采样训练与候选列表 → 动手：在一个小翻译数据上分别用1万和5万的目标词表训练，统计测试译文中[UNK]的比例。
