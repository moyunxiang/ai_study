GoogLeNet / Inception

Going Deeper with Convolutions
2014.09论文延伸CVPR 2015Szegedy, Liu, Jia, Sermanet, Reed, Anguelov, Erhan, Vanhoucke, Rabinovich · Google / UNC / Michigan待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

提高精度的办法是加深加宽网络，但参数和计算量随之暴涨，容易过拟合。

方法

设计Inception模块：在同一层并行用1×1、3×3、5×5卷积和池化，再拼接；用1×1卷积先降维，控制计算量。

影响

ILSVRC 2014分类冠军。证明靠精心设计的结构而不是单纯堆大，也能得到更深更准的网络。

方法

一个Inception模块把四个分支并行：1×1卷积、先1×1降维再3×3卷积、先1×1降维再5×5卷积、以及3×3池化后接1×1卷积，最后把输出沿通道拼起来。这样同一层里同时看到小范围和较大范围的特征，网络自己选择该用哪一种。其中的1×1卷积先把通道数压小，使计算量不至于爆炸。

整个网络22层深（论文称GoogLeNet），摘要强调它在保持计算预算不变的前提下增加了深度和宽度。设计动机引用了赫布原则和多尺度处理的直觉。它在ILSVRC 2014的分类和检测上都取得当时最好成绩。

局限与后续

  • 结构手工设计，分支和卷积核大小的选择带有很多经验成分，难以系统缩放。
    后来针对它的工作　Inception v3 NASNet EfficientNet
  • 没有残差连接，继续加深会遇到训练困难。
    后来针对它的工作　ResNet

它建立在什么之上

  • 改进
    AlexNet2012.09 · 视觉 已核对
    在AlexNet之后继续加深，并用1×1卷积降维控制参数量。
  • 改进
    VGG2014.09 · 视觉
    参数约1.38亿，大部分在三个全连接层，模型文件超过500MB，推理计算量大，难以部署到手机。
  • 使用
    Network In Network2013.12 · 视觉
    1×1卷积的思想来自Network in Network。

后来的相关工作

  • 使用
    Batch Normalization2015.02 · 基础 已核对
    所有实验都在Inception网络上进行，BN-Inception把它的训练步数减少到1/14并提高了精度。
  • 竞争
    ResNet2015.12 · 视觉 已核对
    ILSVRC 2014冠军，靠多分支的Inception模块在固定计算量下加宽加深；ResNet论文把它列为主要对比（单模型top-5 7.89%、集成6.66%，ResNet分别为4.49%和3.57%），并在相关工作里提到Inception层含有一条捷径分支。
  • 竞争
    VGG2014.09 · 视觉
    同年独立的另一种加深方案：GoogLeNet用多分支Inception模块，参数少得多，分类更好（6.7%对7.3%）；VGG结构更简单、更易迁移。两者都被ResNet取代。
  • 使用
    FGSM与线性解释2014.12 · 安全·可解释
    熊猫变长臂猿的经典演示就是对GoogLeNet做的。
  • 使用
    FaceNet与三元组损失2015.03 · 视觉
    以Inception结构为骨干，参数比Zeiler&Fergus式网络少约20倍，便于部署到手机。
  • 竞争
    Highway网络2015.05 · 基础
    GoogLeNet靠中间层的辅助损失帮助梯度传递；Highway用结构上的捷径直接解决，不需要额外损失。
  • 使用
    YOLO2015.06 · 视觉
    主干网络受GoogLeNet启发，用1×1降维加3×3卷积的组合代替Inception模块。
  • 使用
    LIME2016.02 · 安全·可解释
    用Inception网络演示图像解释，并以它的第一池化层特征构造了哈士奇/狼实验。
  • 使用
    GAN训练技巧与IS2016.06 · 生成
    用预训练的Inception网络对生成图像分类，构成Inception Score。
  • 使用
    DenseNet2016.08 · 视觉
    Inception模块已用通道拼接合并多分支特征；DenseNet把拼接用在层与层之间的连接上。
  • 使用
    I3D与Kinetics2017.05 · 视觉
    被膨胀的二维网络就是Inception-v1（GoogLeNet）结构，加上BatchNorm。
  • 使用
    FID与Inception Score2017.06 · 数据·评测
    所用网络属于GoogLeNet开创的Inception系列，“Inception Distance”的名字由此而来。
  • 使用
    Circuits与机制可解释性2020.03 · 安全·可解释
    全部案例分析都在InceptionV1（GoogLeNet）上完成。
  • 使用
    图像描述Show and Tell2014.11 · 多模态
    用卷积网络作图像编码器。
  • 延续
