Llama 3

Introducing Meta Llama 3
2024.04模型重要产品发布 2024Meta AI（Llama团队）来源已核对
官方博客 ↗模型卡 ↗在交互版中打开（演化树、学习进度）

问题

开源模型落后闭源前沿一大截；按Chinchilla的计算最优配比，8B模型约对应2000亿token，同等训练算力下再多训练并不划算，但小模型才是开发者真正跑得起的。

方法

架构基本不动，把数据从Llama 2的2万亿token加到15万亿以上（远超Chinchilla最优），换用12.8万词表并用Llama 2训练的质量分类器过滤数据，8B也用GQA。

影响

模型卡中8B指令版在MMLU、HumanEval、GSM8K上都超过Llama 2 70B指令版；官方的人工评测拿70B指令版与Claude Sonnet、GPT-3.5等对比。

背景

Llama 2（2023年7月）是开源社区的主力底座，但与GPT-4、Claude 3差距明显。同期的Mistral 7B在所有评测基准上超过Llama 2 13B，Mixtral 8x7B则用MoE以约1/5的激活参数追平或超过Llama 2 70B。

另一个背景是规模定律。Chinchilla给出的结论是：给定训练算力，参数量和训练token数应等比增长，8B模型的“最优”数据量约2000亿token。但这只考虑训练成本。模型训好后要服务成千上万次推理，参数越少推理越便宜（见计入推理成本的规模定律），所以在部署方看来，把小模型多训很久是划算的——问题只是收益会不会很快饱和。

方法

架构。标准的仅解码器Transformer，与Llama 2基本相同。两处改动：词表从3.2万扩到12.8万（见分词与token），同一段文本的token数最多少15%；8B和70B都使用分组查询注意力GQA，减小推理时的KV缓存。训练序列长8192个token，并用掩码保证自注意力不跨越文档边界。

数据。超过15万亿token，全部来自公开来源，是Llama 2的7倍，代码量是4倍；5%以上是覆盖30多种语言的非英语数据。过滤流程包括启发式规则、NSFW过滤、语义去重和文本质量分类器——分类器的训练标签由Llama 2生成。团队还用小规模实验预测不同数据配比下的大模型表现。

训练。在两个各2.4万张GPU的集群上训练，单任务最多1.6万张GPU同时跑，每卡超过400 TFLOPS，有效训练时间超过95%，整体效率约为Llama 2的3倍（并行方式见分布式训练：数据并行与模型并行）。预训练共用770万H100 GPU小时。

后训练。监督微调、拒绝采样、PPO和DPO直接偏好优化的组合。官方称从偏好排序中学习明显提升了推理和代码：模型有时会写出正确的推理过程，却不会选，偏好训练教它挑出正确的那条。

结果

官方称8B和70B模型训练到15万亿token时仍按对数线性在提升，没有饱和，训练量约是8B的Chinchilla最优值的75倍。模型卡中的预训练基座：MMLU（5-shot）8B为66.6、70B为79.5，而Llama 2 70B为69.7——新的8B已接近上一代70B。指令版差距更大：HumanEval上Llama 3 8B为62.2、Llama 2 70B为25.6；GSM8K（8-shot CoT）70B达到93.0。

后来的发展

三个月后的Llama 3.1 405B发布了论文、405B版本和12.8万上下文；Llama 3.2 Vision加入图像。之后的开源模型继续加大数据量，例如Qwen2.5把预训练数据扩到18万亿token。Llama 3也成为大量开源微调、蒸馏和研究工作的默认底座，例如LLaDA大语言扩散模型就以Llama 3 8B为对照。

容易误解的地方

  • “超过Chinchilla最优”不是否定Chinchilla：在固定训练算力下，Chinchilla的配比仍然最省；Llama 3是用更多训练算力换更便宜的推理。
  • 同名基准在预训练版和指令版表格里设置不同（例如MMLU一个是基座5-shot，一个是指令版），不能混着比。
  • 15万亿token全部“来自公开来源”不等于数据集公开，具体组成没有披露。

读懂它需要的概念

语言模型 分词与token 幂律与规模定律 参数量、计算量与显存 KV缓存 人类反馈强化学习

本篇术语

  • 过训练（overtraining）　训练token数远超规模定律给出的计算最优值。训练成本更高，但得到同等质量下更小、推理更便宜的模型。
  • 文档边界掩码　把多篇文档拼成一条训练序列时，让注意力不跨越文档边界，避免模型学到不相关文本之间的虚假联系。
  • 拒绝采样微调　对一个提示采样多个回答，用奖励模型或规则挑出最好的，再拿这些回答做监督微调。

怎么学

先读Chinchilla理解计算最优配比，再读计入推理成本的规模定律理解为何部署方愿意过训练。然后读官方博客的“Training data”和“Scaling up pretraining”两节。动手：用Chinchilla的“约20 token每参数”经验值算8B、70B的最优数据量，再与15万亿对比。
