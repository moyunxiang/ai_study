Mamba-3

Mamba-3: Improved Sequence Modeling using State Space Principles
2026.03论文延伸ICLR 2026Aakash Lahoti, Kevin Y. Li, Berlin Chen, Caitlin Wang, Aviv Bick, J. Zico Kolter, Tri Dao, Albert Gu · 卡内基梅隆大学 / 普林斯顿大学 / Cartesia AI / Together AI待核对
arXiv ↗Together AI博客 ↗在交互版中打开（演化树、学习进度）

问题

Mamba-2与状态空间对偶为了训练快，把状态转移简化到“标量乘单位阵”，推理时计算太简单、被显存带宽卡住；不少线性模型还在状态追踪这类任务上失败。

方法

从“推理优先”的角度回到状态空间模型的原理，做三处改进：由SSM离散化推出更有表达力的递推、用复数值的状态更新增强状态追踪、用多输入多输出（MIMO）形式在不增加解码延迟的前提下提高效果。

影响

推理为主的时代里线性模型的一次重新设计；作者开源了内核，作为新的SSM基线与Gated DeltaNet等直接比较。

方法

背景是推理开销的变化：强化学习后训练和智能体工作流需要生成大量样本，推理成本越来越重要。线性模型的吸引力在于状态大小固定、计算随长度线性增长，但作者指出，Mamba-2为加速训练而不断简化状态空间机制，导致解码时每一步算得太少、GPU大部分时间在搬运显存。

Mamba-3的三项改动：其一，用状态空间模型的离散化理论推出更有表达力的递推公式，而不是简单的一阶近似；其二，让状态更新取复数值，相当于在状态上加入依赖输入的旋转，这对需要记住“当前处在什么状态”的状态追踪任务（如奇偶性判断）很关键，对角状态空间S4D/DSS和线性循环单元LRU也用过复数对角状态，而Mamba-2丢掉了这一点；其三，把单输入单输出（SISO）的递推改成多输入多输出（MIMO），在同样的显存读写量下做更多计算，提高硬件利用率，不增加解码延迟。

摘要报告：Mamba-3在检索、状态追踪和下游语言建模任务上都有显著提升；在15亿参数规模，平均下游精度比次好的模型（Gated DeltaNet）高0.6个百分点，MIMO变体再高1.2个百分点，合计1.8个百分点。官方博客称，在15亿参数规模，Mamba-3 SISO的预填充加解码延迟在所有序列长度上都低于Mamba-2、Gated DeltaNet和Llama-3.2-1B。

读懂它需要的概念

状态空间模型与线性RNN 循环网络与隐状态 显存、内存带宽与“内存墙” 吞吐、延迟与批处理 常微分方程与随机微分方程

本篇术语

  • 状态追踪　要求模型在读序列时持续维护一个离散状态（如奇偶性、棋盘局面）的任务，许多线性模型在这类任务上会失败。
  • MIMO　多输入多输出：每次递推同时处理多路输入和输出，提高每次读写显存所做的计算量。
