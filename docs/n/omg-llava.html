OMG-LLaVA三级统一

OMG-LLaVA: Bridging Image-level, Object-level, Pixel-level Reasoning and Understanding
2024.06论文延伸NeurIPS 2024Tao Zhang, Xiangtai Li, Hao Fei, Haobo Yuan, Shengqiong Wu, Shunping Ji, Chen Change Loy, Shuicheng Yan · 武汉大学 / 南洋理工大学 / 新加坡国立大学 / 昆仑万维待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

通用分割模型能分割但不会推理、不听文字指令；多模态大模型会对话推理，却给不出像素级结果，也不接受视觉提示。

方法

用一个通用分割模型（OMG-Seg）当视觉编码器，把图像特征、感知先验和视觉提示一起变成token交给LLM，LLM再输出文字和分割结果。

影响

只用一个编码器、一个解码器、一个LLM，就在多个图像级、物体级、像素级基准上追平或超过专用方法。

方法

以LISA推理分割、GLaMM像素级定位为代表的分割型多模态大模型，常常是把LLM和若干专家模型拼接起来：一个CLIP编码器看图，另一个SAM类模型出掩码。系统复杂，而且很难同时接受点、框这类视觉提示。

OMG-LLaVA把视觉侧换成一个通用分割模型OMG-Seg（基于Mask2Former通用分割式的查询解码器）：冻结的卷积CLIP骨干提取像素特征，解码器给出物体查询及其掩码。作者提出“感知先验嵌入”，把这些物体查询和掩码信息融合进图像特征，连同用户的视觉提示一起作为视觉token送入LLM。LLM理解文字指令后输出回答；需要分割时生成[SEG]标记，再交回同一个解码器画出掩码。

这样从图像描述、区域描述到指代分割、带定位的对话都在一个模型里完成。摘要称它在多个基准上与专用方法持平或更好。

局限与后续

  • 冻结的分割编码器在细粒度语义上不如大规模CLIP类编码器，一般图像问答能力弱于同规模通用VLM。

它建立在什么之上

  • 使用
    Mask2Former通用分割2021.12 · 视觉
    视觉编码与掩码解码来自Mask2Former式的通用分割模型OMG-Seg。
  • 改进
    VisionLLM视觉通才2023.05 · 多模态
    VisionLLM只输出框坐标token，OMG-LLaVA直接给出像素级掩码。
  • 延续
    LISA推理分割2023.08 · 多模态
    沿用以[SEG]标记触发分割的做法，并补上视觉提示输入和物体级理解。
  • 竞争
    GLaMM像素级定位2023.11 · 多模态
    GLaMM用CLIP加SAM多个模块，OMG-LLaVA只用一个分割模型兼作编码器和解码器。
  • 改进
    Osprey像素级区域理解2023.12 · 多模态
    只做“给掩码、出文字”的理解方向，不能根据文字反过来输出分割掩码。
  • 改进
    ViP-LLaVA视觉提示2023.12 · 多模态
    只输出文字，不能反过来在图上画框或掩码来回答，属于单向的区域理解。
