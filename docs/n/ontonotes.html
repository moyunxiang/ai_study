OntoNotes

OntoNotes: The 90% Solution
2006.06数据集延伸Eduard Hovy, Mitchell Marcus, Martha Palmer, Lance Ramshaw, Ralph Weischedel · ISI / UPenn / Colorado / BBN待核对
ACL Anthology ↗LDC OntoNotes 5.0 ↗在交互版中打开（演化树、学习进度）

问题

句法树、谓词论元、词义、共指各有各的语料，标注的文本和标准都不一样，没法在同一批句子上同时研究这些现象。

方法

在同一批多文体文本上，叠加标注句法结构、谓词论元、词义、指代和命名实体，并追求标注者之间约90%的一致率。

影响

它成为共指消解、命名实体识别和语义角色标注的通用数据，CoNLL-2012共享任务和很多英文、中文基准都建立在它之上。

方法

OntoNotes发表于HLT-NAACL 2006，题目「90%解决方案」指的是：把标注设计得足够简单明确，让不同标注者在词义等本来很难一致的问题上也能达到约90%的一致率，这样的数据才适合训练和评测模型。它在Penn Treebank的句法标注（见Penn Treebank）之上增加了谓词论元结构、粗粒度词义（比WordNet的词义划分更粗）、共指链和命名实体，使同一句话同时带有多层语言学标注。

据LDC，2013年发布的第5.0版是该项目的最终版本，覆盖英语、汉语（普通话）和阿拉伯语，文本来源包括电话对话、新闻通讯、新闻组、广播新闻、广播对话、博客和宗教文本。

它的多层标注让研究者可以训练联合模型，也让「命名实体识别」「共指消解」等任务有了固定的标准切分。

局限与后续

  • 标注方案是人为简化的（词义粗分、共指只标部分类型），难以反映语言中的全部歧义。

  • 数据以新闻为主，换到科技论文、社交媒体等领域时性能明显下降。
    后来针对它的工作　BERT

它建立在什么之上

  • 延续
    Penn Treebank1993 · 数据·评测
    在Penn Treebank的句法标注之上继续叠加谓词论元、词义、共指和实体层。
  • 改进
    CoNLL-2003命名实体2003.06 · 数据·评测
    只有四个粗粒度类别，且只覆盖新闻文体，对医学、社交媒体、对话等文本和更细的实体类型帮助有限。
  • 改进
    MUC信息抽取评测1987 · 数据·评测
    填表任务依赖人工设计的模板，换一个领域（比如从军事新闻换到公司并购）就要重写，难以泛化。
  • 使用
    WordNet1995 · 数据·评测
    参考WordNet的词义清单，但合并成更粗的类别，以提高标注者一致率。

后来的相关工作

  • 改进
    BERT2018.10 · LLM
    数据以新闻为主，换到科技论文、社交媒体等领域时性能明显下降。
  • 使用
    端到端神经指代消解2017.07 · NLP
    在OntoNotes构建的CoNLL-2012英语指代数据上训练和评测。
  • 改进
    Winograd模式挑战2012.06 · 数据·评测
    标注方案是人为简化的（词义粗分、共指只标部分类型），难以反映语言中的全部歧义。
