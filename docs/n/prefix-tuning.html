Prefix / Prompt Tuning

Prefix-Tuning: Optimizing Continuous Prompts for Generation
2021.01论文延伸ACL 2021Xiang Lisa Li, Percy Liang · Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

微调整个GPT-2或BART要为每个任务存一份完整参数副本；Adapter虽小但要改动模型结构。

方法

冻结语言模型，只学习一段加在每一层注意力键和值前面的连续向量（前缀），把它当作可训练的“虚拟提示词”。

影响

开启“连续提示”路线，是Prompt Tuning、P-Tuning和后续各类参数高效微调的起点之一。

方法

做法是在每一层的键K和值V序列前面拼上若干个可训练的向量，模型的所有原始参数不动，只更新这些前缀。每个任务只存一小段前缀，推理时把对应前缀拼进去即可，一个模型可同时服务多个任务。因为前缀直接参与每层的注意力（见自注意力与多头注意力），它比只在输入端加提示更有表达力。训练时前缀由一个小网络重参数化以稳定优化。论文把它用在GPT-2做表格到文本生成、BART做摘要，摘要称只学习约0.1%的参数，在全量数据下与微调相当，在低数据和外推场景下更好。

局限与后续

  • 训练较敏感，需要重参数化技巧；前缀占用上下文长度，挤占可用输入。
    后来针对它的工作　P-Tuning
  • 在较小的模型和较难的理解类任务上不如全量微调稳定。
    后来针对它的工作　LoRA
