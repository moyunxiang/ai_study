Flair上下文字符串嵌入

Contextual String Embeddings for Sequence Labeling
2018.08论文延伸COLING 2018Alan Akbik, Duncan Blythe, Roland Vollgraf · Zalando Research待核对
ACL Anthology ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

word2vec、GloVe给每个词一个固定向量，不随上下文变化，也对未登录词无能为力；当时的上下文表示（如ELMo）仍以词为单位、计算较重。

方法

先在大规模文本上训练前向和后向两个字符级LSTM语言模型；对句中每个词，取前向模型读完这个词最后一个字符时的隐藏状态和后向模型读到这个词第一个字符时的隐藏状态，拼起来作为它的词向量，再送进BiLSTM-CRF做标注。

影响

在英语和德语CoNLL03命名实体识别上刷新了最好成绩，并在四个经典序列标注任务上都超过以前的方法；配套的Flair框架因简单易用被大量用于NER和文本分类，直到BERT类模型普及。

背景

神经命名实体识别和BiLSTM-CNN-CRF序列标注用字符级网络加静态词向量做序列标注，ELMo（2018年初）则用双向语言模型给出随上下文变化的词表示。与此同时，字符级语言模型被发现能自动学到词、句子乃至情感等语言概念。作者想直接把字符级语言模型的内部状态拿来当词向量：它不需要预先切词、天然能处理任何拼写，又是上下文相关的。

方法

字符级语言模型。 在大量无标注文本（英语用十亿词基准语料）上训练一个前向LSTM，按字符预测下一个字符；再训练一个从右往左读的后向LSTM。

取出词向量。 把整句作为字符序列送入两个模型。对于句中第i个词，设它的字符起止位置为 s_i 到 e_i： w_i = [ h^f_{e_i+1} ; h^b_{s_i−1} ] 前向部分取读完该词最后一个字符（及其后的空格）时的隐藏状态，它概括了「从句首到这个词」的内容；后向部分取从句尾读到该词第一个字符之前时的隐藏状态，它概括了「从句尾到这个词」的内容。这样同一个词「Washington」在「George Washington」和「Washington state」中会得到不同向量。

堆叠与下游。 把这个上下文字符串嵌入与传统静态词向量（如GloVe）拼接（作者称为堆叠嵌入），作为BiLSTM-CRF序列标注序列标注器的输入；语言模型参数在下游训练时保持固定。

结果

摘要称：在四个经典序列标注任务（论文中为英语和德语NER、词性标注、名词短语分块）上都一致超过此前最好结果，其中英语和德语NER提升显著，在CoNLL03共享任务上报告了新的最好F1（具体数字未逐项核对）。

后来的发展

作者把代码和预训练语言模型做成Flair框架，后来扩展出池化嵌入（把同一词在语料中各次出现的嵌入聚合起来）、文档级嵌入和多语言模型。Stanza多语言工具包等工具的NER模块也采用了类似的字符级语言模型表示。BERT发布后，基于Transformer的子词上下文表示成为主流，但Flair嵌入因为轻量，在资源受限场景和一些语言上仍被使用。

局限与后续

  • 语言模型是LSTM且在下游任务中不微调，表示能力和迁移效果不如随后可整体微调的Transformer预训练模型。
    后来针对它的工作　BERT RoBERTa
  • 每个词的向量只由两个时刻的隐藏状态决定，对长距离的文档级信息利用有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

语言模型 循环网络与隐状态 嵌入向量 迁移学习

本篇术语

  • 上下文相关词向量　同一个词在不同句子中得到不同的向量，能区分一词多义。
  • 字符级语言模型　按字符而不是按词预测下一个单元的语言模型，可以处理任意拼写的词。
  • 堆叠嵌入　把多种词向量（如上下文字符串嵌入和GloVe）直接拼接成一个更长的向量使用。

怎么学

先读BiLSTM-CRF序列标注与ELMo → 读原文第2节的嵌入定义与第3节实验 → 动手：用flair库加载预训练的news-forward/backward嵌入，在CoNLL03上训练一个NER模型，并与只用GloVe的版本比较F1。
