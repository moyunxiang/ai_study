Unsupervised Visual Representation Learning by Context Prediction
2015.05论文延伸ICCV 2015Doersch, Gupta, Efros · CMU / UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

监督预训练依赖人工标注，而互联网上有大量无标注图像。

方法

让网络预测同一张图中两个图块的相对位置，借此逼出对物体及其部件的理解。

影响

提出「前置任务」这一自监督范式，第一批证明无标签预训练能提升检测。

方法

在一张图里随机取一个中心图块，再取它周围8个方位之一的相邻图块，把两块一起输入网络，要求分类出第二块位于第一块的哪个方位。这个任务本身没有人工标签，标签直接由取块位置给出。要做对，网络必须知道猫的头一般在身体的上方这类物体结构，所以被迫学到有语义的特征。

论文展示学到的特征可以无监督地发现猫、人、鸟等物体，并把这个网络用到R-CNN里，相比随机初始化有明显提升，在只使用Pascal提供标注的算法中达到最好水平。
