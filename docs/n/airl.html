AIRL对抗逆强化学习

Learning Robust Rewards with Adversarial Inverse Reinforcement Learning
2017.10论文延伸ICLR 2018Justin Fu, Katie Luo, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GAIL能很好地模仿示范，但它的判别器不是一个可以单独拿出来用的奖励函数；逆强化学习想恢复奖励，却难以扩展到高维、动力学未知的问题，学到的奖励也常常换个环境就失效。

方法

把GAIL的判别器写成特定形式 D = exp(f)/(exp(f)+π(a|s))，让对抗训练同时恢复一个奖励函数；并把f分解成只依赖状态的奖励项和类似势函数的塑形项，使学到的奖励对动力学变化稳健。

影响

成为对抗式逆强化学习的标准方法，常被用来恢复可迁移的奖励函数，也是后续奖励学习和模仿学习工作的主要基线之一。

方法

AIRL沿用引导代价学习GCL与GAN之间的对应关系：判别器D区分专家的(s,a)和当前策略的(s,a)，但它的形式被固定为 D(s,a,s') = exp(f(s,a,s')) / (exp(f(s,a,s')) + π(a|s))。在这个形式下，最优的f恰好等于最大熵逆RL意义下的优势函数，所以训练结束后f里就含有专家的奖励。策略则用 log D − log(1−D) 作为奖励，用普通RL算法更新。

作者进一步指出：只从示范里学，奖励和基于势函数的奖励塑形式的势函数项分不开，学到的「奖励」可能夹带了与环境动力学绑定的成分，一换动力学就不对。于是令 f = g(s) + γh(s') − h(s)，g只依赖状态，作为要恢复的奖励；h充当塑形项。摘要称，AIRL能恢复对动力学变化稳健的奖励函数，即使环境与训练时有明显差异也能用它学出策略，在这类迁移设定中大幅超过此前方法。

局限与后续

  • 仍依赖对抗训练，判别器和策略交替优化，训练不稳定、对超参数敏感。
    后来针对它的工作　IQ-Learn逆软Q模仿
  • 奖励只依赖状态的设定是为了可迁移而做的假设，不适用于奖励确实依赖动作的任务。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    基于势函数的奖励塑形1999 · RL
    把f分解为奖励加势函数塑形项，利用塑形不改变最优策略的性质来分离出可迁移的奖励。
  • 延续
    GAIL2016.06 · RL
    沿用GAIL的对抗框架，但约束判别器形式，使其能同时恢复奖励函数。
  • 使用
    最大熵逆强化学习2008 · RL
    判别器的最优解对应最大熵IRL意义下的奖励与优势。
  • 延续
    引导代价学习GCL2016.03 · RL
    继承引导代价学习与GAN的等价关系，把它做成可扩展的对抗式IRL。

本篇术语

  • 奖励可迁移　学到的奖励在动力学不同的新环境里重新训练策略，仍能得到专家式的行为。

怎么学

先读GAIL和最大熵逆强化学习；读原文第4–5节判别器形式和奖励分解；用imitation库在蚂蚁残肢迁移任务上比较GAIL与AIRL。
