TransE知识图谱嵌入

Translating Embeddings for Modeling Multi-relational Data
2013.12论文重要NIPS 2013Antoine Bordes, Nicolas Usunier, Alberto García-Durán, Jason Weston, Oksana Yakhnenko · 贡比涅技术大学（CNRS）、Google待核对
NeurIPS论文页 ↗PDF ↗在交互版中打开（演化树、学习进度）

问题

Freebase这类知识库缺失大量事实，需要自动推断“谁和谁可能有什么关系”；已有的知识库嵌入模型给每种关系配一个甚至两个矩阵，参数多、难训练，扩展不到百万实体。

方法

每个实体和每种关系都只是一个低维向量，把关系看作向量空间里的平移：如果〈h, r, t〉成立，就要求h + r ≈ t。用“真三元组的距离比随机替换头或尾后的假三元组小一个间隔”的排序损失训练。

影响

以极少的参数在WordNet和Freebase的链接预测上全面超过当时的复杂模型，并能训练到100万实体、1700多万条三元组；它提出的FB15k数据集和过滤评测方式成为知识图谱嵌入的标准设置，后续出现了一长串“Trans系列”和其他嵌入模型。

背景

Freebase、WordNet和Google知识图谱都是由〈头实体, 关系, 尾实体〉三元组构成的有向图。它们都很不完整，于是“链接预测”成为核心任务：给定〈J. K. 罗琳, 受…影响, ?〉，把所有实体按可能性排序。

当时的做法是把实体嵌入向量，再为每种关系设计一个打分函数。SE给每种关系两个k×k矩阵，RESCAL用一个关系矩阵做双线性打分，SME、LFM等用更复杂的交互。表达力很强，但参数随关系数乘以k²增长，论文估计在FB15k上RESCAL需要的参数是TransE的约87倍，而且很难训练好、容易欠拟合，大规模数据上根本跑不动。

另一个启发来自word2vec：作者注意到，词向量中“首都-国家”这类一对一关系恰好表现为近似固定的平移。

方法

模型。每个实体e和每种关系r都是一个k维向量。三元组的“能量”（越小越可信）定义为d(h + r, t)，d取L1或L2距离。

为什么是平移：知识库里层级关系极多。把一棵树画在二维平面上，同层的兄弟节点横向排开，父子关系正好是沿纵轴的一次平移；平移向量为零则表示“等价”关系。每种关系只用一个向量，就把参数预算花在最常见的关系类型上。

训练。对每个真实三元组〈h, r, t〉，随机把头或尾换成另一个实体，得到一个假三元组〈h′, r, t′〉，最小化

L = Σ [γ + d(h + r, t) − d(h′ + r, t′)]₊

[x]₊表示取正部分，γ是间隔：真三元组的距离要比假三元组至少小γ，否则产生损失。每轮先把实体向量的L2范数归一化为1，防止模型靠把向量放大来降低损失。用小批量随机梯度下降优化。

评测。对每个测试三元组，把尾（或头）换成所有实体，按能量排序，记录正确答案的平均排名和进入前10的比例（hits@10）。论文指出，替换后有些三元组其实也是真的（罗琳确实还受其他作家影响），会被不公平地算作错误，于是提出“过滤”设定：排序前去掉在训练、验证、测试集中出现过的三元组。

结果

数据：WN（40,943个实体、18种关系）、FB15k（从Freebase抽取，14,951个实体、1,345种关系、训练三元组483,142条）、FB1M（100万实体、23,382种关系、1750万条训练三元组）。最佳设置为k取20或50、γ取1或2。

过滤设定下hits@10：WN上TransE为89.2%，次好的LFM为81.6%、SE为80.5%；FB15k上47.1%，RESCAL为44.1%、SE为39.8%；平均排名FB15k上125，SE为162。FB1M上（原始设定）hits@10为34.0%，SE只有17.5%。按关系类型看，TransE在一对一关系上最好，但在“多对一”关系预测头实体、“一对多”关系预测尾实体时只有18%到20%左右。

后来的发展

TransE开启了知识图谱嵌入的研究热潮：后续模型先是在它的基础上让实体在不同关系下有不同投影，以处理一对多和多对多关系；再到双线性、复数空间旋转、卷积和图神经网络（如图卷积网络的关系版本）等打分方式。FB15k与过滤评测成为标准设置，不过后来研究者发现FB15k中大量测试三元组的逆关系就在训练集中，于是改用去掉逆关系的FB15k-237等数据集。

“关系即向量运算”的思想也被用到推荐系统和多模态检索中。预训练语言模型出现后，语言模型即知识库发现语言模型本身就能回答许多知识库式的填空问题，知识图谱嵌入与语言模型如何结合成了新的研究方向。

容易误解的地方

  • TransE的平移形式无法同时表示多个合理的尾实体：若一位导演执导了多部电影，h + r ≈ t会迫使这些电影的向量挤到同一点附近。
  • 对称关系（如“配偶”）要求r ≈ −r，只能让r接近零向量，从而头尾实体被迫重合；这不是训练不足，而是模型形式的限制。
  • 原始评测和过滤评测的数字差别很大，比较论文结果时要确认用的是哪种设定。

局限与后续

它建立在什么之上

  • 延续
    word2vec2013.01 · NLP
    受词向量中“首都-国家”关系近似为固定平移的现象启发，把平移从偶然现象变成模型的强制结构。
  • 使用
    Freebase2007.03 · NLP
    从Freebase抽出FB15k和FB1M两个数据集，链接预测就是在补全Freebase缺失的事实。
  • 延续
    从零开始的神经NLP2011 · NLP
    同样用“真样本得分优于随机替换后的假样本至少一个间隔”的排序损失训练嵌入（Weston是两篇的共同作者），这里替换的是三元组的头或尾。
  • 改进
    Google知识图谱2012.05 · NLP
    大规模知识图谱的核心难题是不完整；TransE以每个实体一个向量的轻量模型给出了可扩展到百万实体的自动补全方法。
  • 使用
    WordNet1995 · 数据·评测
    WN数据集取自WordNet的词义与上下位等关系，用来检验层级关系的建模能力。

读懂它需要的概念

嵌入向量 范数与距离 损失函数 图、树与搜索 随机梯度下降与小批量 能量模型与玻尔兹曼分布

本篇术语

  • 链接预测　给定知识图谱中三元组的两项（如头实体和关系），在所有实体中排序找出最可能的第三项，用来补全缺失事实。
  • hits@10　正确答案排在所有候选的前10名以内的测试样例比例。
  • 过滤评测　排序前把那些本身也成立的替换三元组去掉，避免模型因为把另一个正确答案排在前面而被扣分。

怎么学

先补嵌入向量、范数与距离和损失函数中的间隔损失。读原文第2节（模型与算法1）、第4.2节（评测协议）和表3、表4。动手：下载FB15k-237，用PyTorch实现TransE（约50行），训练后计算过滤设定下的hits@10，并单独统计一对多关系上的表现，验证上面的局限。
