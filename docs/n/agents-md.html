问题

每家编码智能体都要求把项目说明写进自家专用文件，同一个仓库得维护好几份内容相近的指令。

方法

约定一个通用的文件名AGENTS.md，像给智能体看的README，放构建步骤、测试命令和代码约定。

影响

成为跨工具的事实标准，后来被捐给Linux基金会旗下的智能体AI基金会。

方法

README.md是写给人看的，AGENTS.md则补充智能体需要的额外上下文：怎么构建、怎么跑测试、有哪些约定。官网称刻意把它与README分开，一是给智能体一个明确、可预测的位置，二是让README保持简洁。它就是普通的Markdown，没有强制字段；官网示例里写了开发环境提示、测试命令、提交前要通过全部测试这类内容。

官网列出的兼容工具有OpenAI的Codex、Google的Jules与Gemini CLI、Cursor、Aider、VS Code、GitHub Copilot的编码智能体、Devin、Windsurf等一长串。Hacker News上它在2025年8月20日被提交。此前各家有各自的文件，例如Claude Code与终端编码智能体用CLAUDE.md；统一文件名降低了迁移成本，也让项目说明变成仓库里可审查的资产，是上下文工程在落地层面的一个最简实现。后来它与MCP一起被纳入智能体AI基金会AAIF。
