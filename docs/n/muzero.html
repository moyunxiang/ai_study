MuZero

Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model
2019.11论文重要arXiv 2019；Nature 2020Schrittwieser, Antonoglou, Hubert, Simonyan, Sifre, Schmitt, Guez, Lockhart et al. · DeepMind来源已核对
arXiv ↗Nature版 ↗ar5iv全文 ↗在交互版中打开（演化树、学习进度）

问题

AlphaZero的树搜索需要一个完美的规则模拟器；而Atari这类视觉环境规则未知，学一个能逐像素预测未来画面的模型又很难，基于模型的方法在Atari上一直不如无模型方法。

方法

不预测画面，只学一个在“隐状态”里展开的模型：它只需要预测搜索真正用到的三样东西——每一步的奖励、局面价值和策略，然后照AlphaZero的方式在这个学出来的模型里做MCTS。

影响

同一算法不给规则，在围棋、国际象棋、将棋上达到AlphaZero水平；在57个Atari游戏上的平均和中位数得分超过当时最好的无模型方法R2D2，而此前基于模型的规划方法在Atari上一直落后。

背景

AlphaZero的强大来自蒙特卡洛树搜索UCT：在脑子里把棋往下推演几百步再决定。推演需要知道“走了这步之后棋盘变成什么样”，也就是规则。棋类有规则，Atari、机器人、现实世界没有。

基于模型的强化学习的传统做法是先学一个环境模型，如World Models、SimPLe与Atari 100k用神经网络重建或预测下一帧画面，然后在模型里规划或训练。但Atari画面里大量像素与决策无关，逐像素预测既难又浪费，误差还会在多步推演中累积，所以这些方法在Atari上始终打不过R2D2这样的无模型方法。

方法

三个函数（都是神经网络）：

  • 表示函数h：把过去的观测（棋盘或最近几帧画面）编码成初始隐状态s⁰ = h(o_1…o_t)。
  • 动态函数g：给定隐状态和一个假想动作，输出下一隐状态和即时奖励(r^k, s^k) = g(s^{k−1}, a^k)。
  • 预测函数f：从隐状态输出策略和价值(p^k, v^k) = f(s^k)，与AlphaZero的网络头一样。

规划。每一步用h得到根节点，然后完全在隐空间里做MCTS：展开节点时调用g，估值时调用f，不再需要真实规则。

训练。从回放池取一段真实轨迹，用h编码起点，再按真实执行过的动作用g连续展开K=5步。每一步的三个预测分别对齐三个目标：奖励对齐真实奖励，策略对齐当时MCTS的访问分布，价值对齐n步回报（见时序差分与自举）。三项损失之和通过展开过程反向传播。

关键点：隐状态没有任何“必须能还原画面”或“必须等于真实状态”的约束。它只要对预测奖励、价值、策略有用就行——模型学的是“对决策等价”的规则，而不是物理上真实的规则。

结果

棋类：不知道规则，在围棋上略超AlphaZero，在国际象棋和将棋上与AlphaZero持平。Atari 57个游戏：中位数人类标准化得分2041%、平均4999%，高于R2D2的1921%和4025%，在57个游戏中的42个上超过R2D2，所有游戏上都超过此前最好的基于模型方法SimPLe。限制每个游戏2亿帧时，MuZero Reanalyze（用最新网络对旧轨迹重新搜索产生新目标）中位数达731%，高于IMPALA的192%、Rainbow的231%。

后来的发展

MuZero衍生出一个家族：EfficientZero把它推到Atari 100k的少样本设置，Sampled MuZero支持大规模和连续动作，Stochastic MuZero处理随机环境；工程上被用于YouTube视频压缩（MuZero视频码率控制）。之后TD-MPC等连续控制方法也采用了“只学任务导向的隐空间模型、不重建观测”的类似做法，与Dreamer系列“学会重建观测的世界模型”形成两条并行路线。

容易误解的地方

  • MuZero学的“模型”不能用来生成画面或解释环境，它只是搜索内部使用的隐状态转移。
  • 它并非样本高效：大数据设置下每个游戏用了约200亿帧。

局限与后续

  • 样本效率低：标准设置每个Atari游戏约200亿帧，在只允许10万步交互的设置下表现不佳。

它建立在什么之上

  • 改进
    AlphaGo2016.01 · RL 已核对
    搜索要求一个完全准确的规则模拟器，无法用于规则未知或状态不可完全观测的环境。
  • 竞争
    World Models2018.03 · 具身·世界模型 已核对
    MuZero在相关工作中把Ha与Schmidhuber等归为预测未来隐状态或重建观测的方法，认为它们把大部分模型容量花在可能无关的细节上；MuZero只学预测奖励、价值、策略的模型，代表“价值等价模型”路线。
  • 使用
    蒙特卡洛树搜索UCT2006 · RL 已核对
    在学出的隐空间模型中执行AlphaZero式的MCTS，节点展开调用动态函数。
  • 改进
    AlphaZero2017.12 · RL 已核对
    去掉AlphaZero对已知规则模拟器的依赖，用学出的隐空间模型代替规则，搜索与训练方式其余不变。
  • 竞争
    R2D22018.09 · RL 已核对
    此前Atari最强的是无模型的R2D2；MuZero在表1中中位数2041%对1921%、平均4999%对4025%，在57个游戏中的42个上超过它。
  • 竞争
    SimPLe与Atari 100k2019.03 · RL 已核对
    同为Atari上的基于模型方法：SimPLe预测像素画面、面向10万步的小数据设置，MuZero只学价值等价的隐状态模型、用大得多的数据；论文称MuZero在所有游戏上都超过SimPLe，但两者数据量不在一个量级。
  • 改进
    Dyna：学习与规划合一1990 · RL 待核对
    与Dyna同属“学模型并用模型规划”的思路，但模型只服务于搜索中的价值与策略预测；论文本身没有引用Dyna。
  • 改进
    AlphaGo Zero2017.10 · RL
    仍然依赖完美的规则模拟器来做搜索，无法用于规则未知或环境不可模拟的问题。
  • 改进
    Predictron2016.12 · RL
    只做价值预测（一个马尔可夫奖励过程），没有动作，不能直接用来选动作和规划控制。
  • 改进
    专家迭代ExIt2017.05 · RL
    只在一种棋盘游戏上验证，且需要可完美模拟的环境来运行树搜索。
  • 改进
    想象增强智能体I2A2017.07 · RL
    环境模型要逐像素预测下一帧画面，训练成本高，且这些像素细节大多与决策无关。
  • 改进
    价值预测网络VPN2017.07 · RL
    前瞻搜索是对所有动作穷举展开的浅层树，深度一大计算量指数增长。
  • 改进
    TreeQN可微树规划2017.10 · RL
    树要对所有动作完全展开，计算量随深度指数增长，只能做很浅的前瞻。

后来的相关工作

  • 竞争
    Dreamer2019.12 · 具身·世界模型 已核对
    同期的另一种基于模型路线：MuZero的模型不重建画面、只预测奖励和价值并配合树搜索，Dreamer则重建画面、用梯度学策略。Dreamer在相关工作中称MuZero需要大量经验。
  • 延续
    EfficientZero2021.10 · RL 已核对
    以MuZero为骨架，增加自监督一致性、价值前缀和离策略修正，使其在少数据下可用。
  • 竞争
    DreamerV32023.01 · 具身·世界模型 已核对
    论文称MuZero用价值预测模型做规划、用于棋类和Atari，且没有公开实现；DreamerV3的模型还重建观测、用想象轨迹训练策略，不需要搜索。
  • 改进
    Sampled MuZero2021.04 · RL 已核对
    把MuZero的搜索从枚举全部动作改成对采样动作子集搜索，扩展到连续、高维动作。
  • 改进
    Student of Games2021.12 · RL 已核对
    不处理扑克这类不完全信息博弈，论文明确将其排除在外。
  • 改进
    Stochastic MuZero2022 · RL 待核对
    把MuZero的确定性学习模型扩展为带后状态和机会节点的随机模型。
  • 竞争
    Agent572020.03 · RL
    MuZero平均分和中位数更高，但在Venture等游戏上近乎随机；Agent57牺牲平均分换来全部57个游戏都超过人类。
  • 改进
    DiscoRL：元学习发现RL算法2025.10 · RL
    MuZero是Atari上最强的人类设计方法之一；Disco57以更高的墙钟效率在Atari IQM上超过它。
  • 延续
    MuZero Unplugged与重分析2021.04 · RL
    在MuZero上加入用当前模型重新搜索旧数据的Reanalyse，并推广到完全离线的设定。
  • 使用
    MuZero视频码率控制2022.02 · RL
    直接把MuZero的模型加搜索用于选择量化参数。
  • 延续
    TD-MPC2022.03 · RL
    同样不重建观测、只学对决策有用的隐模型与价值，并用于规划；但面向连续动作，用采样式MPC而非树搜索。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

基于模型的强化学习 博弈树搜索：minimax与MCTS 策略与价值函数 时序差分与自举 自我对弈 循环网络与隐状态

本篇术语

  • 隐状态　网络内部的一个向量，用来代替真实环境状态做推演；它的含义不由人规定，只要对预测奖励、价值和策略有用即可。
  • 价值等价模型　不要求模型预测出真实的下一状态，只要求在模型中推演出的价值和奖励与真实环境一致。
  • Reanalyze　用最新的网络对回放池中的旧轨迹重新做一遍MCTS，生成更好的训练目标，以提高数据利用率。

怎么学

先读AlphaZero和基于模型的强化学习。读原文第3节（三个函数与训练目标）和附录中的伪代码；DeepMind公开的MuZero伪代码很短，值得逐行读。动手：用开源的muzero-general在CartPole或井字棋上训练，把展开步数K从5改成1，观察对效果的影响。
