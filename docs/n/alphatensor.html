AlphaTensor

Discovering Faster Matrix Multiplication Algorithms with Reinforcement Learning
2022.10论文延伸Nature 2022Fawzi, Balog, Huang, Hubert, Romera-Paredes, Barekatain 等 · DeepMind待核对
Nature ↗在交互版中打开（演化树、学习进度）

问题

矩阵乘法是神经网络和科学计算的基本运算，自1969年Strassen算法以来，可能的更快算法空间巨大，靠人力很难再有进展。

方法

把寻找矩阵乘法算法转化成一个单人游戏：寻找张量的低秩分解，用AlphaZero式的强化学习去玩。

影响

为许多矩阵规格发现了复杂度不差于已知最优的算法，开启了用强化学习自动发现算法的路线（后有AlphaDev、AlphaEvolve）。

方法

两个矩阵相乘的过程可以写成一个三维张量，把张量分解为R个秩一项的和，就对应一个只用R次标量乘法的算法；R越小算法越快。问题是搜索空间极大。

AlphaTensor把它变成游戏：棋盘是当前剩余的张量，每一步选一个秩一项从中减去，目标是用最少的步数把张量减到零。它沿用AlphaZero的做法，用神经网络给出走法先验和价值估计，配合蒙特卡洛树搜索UCT搜索，并先在合成的容易题上训练以获得足够的训练数据。因为是在有限域或整数中精确分解，找到的算法保证正确。

论文称，对多种矩阵规格，找到的算法优于已知最佳复杂度；其中4×4矩阵在有限域上的算法，是自Strassen的两层算法问世50年来首次在此情形下有改进。它还能针对具体硬件的运行时间做优化。

局限与后续

  • 搜索空间随矩阵尺寸迅速增大，只能处理较小的矩阵规格；发现的算法对实际大矩阵的优势有限。
    后来针对它的工作　AlphaEvolve
  • 只适用于能被精确评估、可写成张量分解的问题。
    后来针对它的工作　FunSearch

读懂它需要的概念

自我对弈 博弈树搜索：minimax与MCTS 矩阵乘法与线性变换 策略与价值函数

怎么学

先理解Strassen算法和AlphaZero；读Nature摘要和关于张量分解游戏的部分，试着手算2×2矩阵乘法对应的张量与Strassen的7次乘法。
