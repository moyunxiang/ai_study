BiDAF双向注意力流

Bidirectional Attention Flow for Machine Comprehension
2016.11论文重要ICLR 2017Minjoon Seo, Aniruddha Kembhavi, Ali Farhadi, Hannaneh Hajishirzi · 华盛顿大学、艾伦人工智能研究所待核对
arXiv ↗代码与演示 ↗在交互版中打开（演化树、学习进度）

问题

阅读理解模型的注意力通常只做一个方向（问题看文章），而且很早就把文章压成一个固定长度的向量，细粒度的“文章每个词与问题每个词”的对应关系在进入后续推理之前就丢掉了。

方法

先算出文章每个词与问题每个词的相似度矩阵，从中同时取出“文章→问题”和“问题→文章”两个方向的注意力，把结果逐词拼回文章表示里，不做压缩，全部交给后面的LSTM继续建模，最后预测答案片段的起点和终点。

影响

在SQuAD上集成模型EM 73.3、F1 81.1，排名第一，其“相似度矩阵+双向注意力+指针输出”的六层结构成为2017–2018年抽取式问答的标准模板，ELMo的问答实验也以它的改进版为基线。

背景

注意力阅读器与CNN/DM开启了神经阅读理解，但它用问题向量对文章做一次注意力，就把整篇文章加权平均成一个向量，再做判断。2016年6月发布的SQuAD把任务改成从维基百科段落中划出一段原文作答，需要更精确的定位，这种“先总结再回答”的方式就不够用了。

当时的改进大致有三类：一类像Match-LSTM与答案指针，在读文章的LSTM里每一步都动态地对问题做注意力，注意力和建模纠缠在一起；一类只算一次注意力就直接输出；还有记忆网络式的多跳注意力。它们几乎都只做“文章看问题”这一个方向。

方法

BiDAF分六层，前三层对文章和问题各自做：

  • 字符嵌入：每个词的字符经一维卷积（TextCNN句子分类的做法）得到向量，处理罕见词；
  • 词嵌入：预训练的GloVe向量（训练中固定），与字符向量拼接后过两层Highway网络网络；
  • 上下文嵌入：双向LSTM，得到文章矩阵H（T个词）和问题矩阵U（J个词）。

注意力流层（核心）。先算T×J的相似度矩阵：

S_tj = wᵀ·[h_t; u_j; h_t ∘ u_j]

（∘是逐元素乘）。由它得到两个方向的注意力（见注意力机制）：

  • 文章→问题（C2Q）：对S的每一行做softmax，得到文章第t个词最关心问题里哪些词，加权得到ũ_t；
  • 问题→文章（Q2C）：对每行取最大值再做softmax，找出与问题某个词最相关的文章词，加权得到一个向量h̃，复制到每个位置。

然后拼成g_t = [h_t; ũ_t; h_t∘ũ_t; h_t∘h̃]，每个文章词都保留一份“带着问题信息”的表示，不做任何压缩。注意力只依赖当前层的输入，不依赖上一时刻的注意力结果（作者称之为无记忆注意力）。

建模层：两层双向LSTM读G，让文章词之间在“知道问题”的前提下互相交流。

输出层：p_start = softmax(w₁ᵀ·[G; M])，终点分布用再过一层LSTM的M₂算出；训练目标是正确起点和终点的负对数似然之和。

结果

SQuAD测试集（2016年12月6日榜单）：单模型EM 68.0、F1 77.3；12个模型集成EM 73.3、F1 81.1，高于当时所有方法，包括Match-LSTM与答案指针（集成67.9 / 77.0）和动态协同注意力网络（71.6 / 80.4）。开发集消融：去掉C2Q注意力，EM从67.7降到57.2，掉了10个点以上；去掉Q2C降到63.6；改成在LSTM里动态计算注意力降到63.5；去掉字符嵌入降到65.0。只换输出层，在CNN/DailyMail完形填空上单模型测试准确率76.9 / 79.6，也超过此前单模型最好结果。

后来的发展

BiDAF的分层结构被大量后续模型继承：R-Net、FusionNet、QANet等在其基础上改进注意力和编码器；ELMo在SQuAD上的基线就是BiDAF的改进版。BERT出现后，这些专门设计的交互层基本被淘汰：把问题和段落拼在一起送进预训练Transformer，自注意力天然就包含双向交互，再接一个起止指针即可。

  • 改进
    注意力阅读器与CNN/DM2015.06 · NLP
    解决了Attentive Reader把文章过早压成一个向量的问题：注意力结果逐词保留并流入后续层；在同一CNN/DailyMail数据上也取得更高准确率。
  • 使用
    SQuAD2016.06 · 数据·评测
    主要在SQuAD上评测，输出层专门为“预测答案片段起止位置”设计。
  • 使用
    指针网络2015.06 · NLP
    输出层沿用指针思想：在段落位置上做softmax，指出答案的起点和终点。
  • 改进
    动态记忆网络DMN2015.06 · NLP
    在bAbI这类合成数据上的推理能力，迁移到真实文本阅读理解时效果有限，真实数据上的主流模型很快换成了基于跨度预测的注意力架构。
  • 改进
    CNN/DM阅读理解审查2016.06 · NLP
    神经阅读器只做一次注意力，对需要跨多句推理的问题无能为力。
  • 改进
    Match-LSTM与答案指针2016.08 · NLP
    Match-LSTM在LSTM里逐步动态计算单向注意力；BiDAF改为预先算好双向注意力再交给建模层，消融显示比动态注意力高3个点以上，SQuAD集成F1从77.0升到81.1。

读懂它需要的概念

注意力机制 循环网络与隐状态 嵌入向量 Softmax与logits 矩阵乘法与线性变换 准确率、精确率、召回率与F1

本篇术语

  • 抽取式问答　答案必须是给定段落中的一段连续原文，模型只需预测这段文字的起点和终点。
  • EM / F1（问答）　EM是预测答案与标准答案完全一致的比例；F1按词计算预测答案与标准答案的重合程度，对部分正确给部分分数。
  • 相似度矩阵　文章有T个词、问题有J个词，就算出一个T×J的表格，第t行第j列表示文章第t个词与问题第j个词有多相关。

怎么学

先补注意力机制和Softmax与logits，读过注意力阅读器与CNN/DM和SQuAD。读原文第2节，重点是注意力流层的三个公式，然后看表1(b)的消融。动手：用PyTorch实现相似度矩阵和C2Q、Q2C两种注意力，接一个起止指针，在SQuAD的一个子集上训练，并画出相似度矩阵的热力图看模型关注了哪些词。
