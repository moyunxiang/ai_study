堆叠注意力SAN

Stacked Attention Networks for Image Question Answering
2015.11论文延伸CVPR 2016Yang, He, Gao, Deng, Smola · CMU / 微软研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图像问答的早期模型把整图特征与问题向量一拼了事，而许多问题需要多步推理，一次看图不够。

方法

用问题向量作查询，在图像区域上做注意力，得到的结果更新查询，再看一次，如此堆叠多层，逐步逼近答案相关区域。

影响

让多跳注意力成为视觉问答模型的标配，其可视化也直观展示了推理过程。

方法

模型先用卷积网络得到图像的区域特征，用LSTM或卷积把问题编码成一个向量。第一层注意力：把问题向量与每个区域特征做相容度打分，softmax后加权求和，得到区域摘要，再与问题向量相加，形成新的查询向量。第二层以这个新查询重复同样的步骤，每一层会把注意力收得更集中。最后用最后一层的查询向量做分类，选出答案。

这等于让模型像人一样先找到大致相关的区域（如「狗」），再看细节（如「狗身上的颜色」）。摘要称在四个图像问答数据集上显著超过当时最好水平，层层可视化也显示注意力逐步聚焦。

局限与后续

  • 答案仍当作分类问题，只能从固定词表里选，无法处理组合性很强的问题。
