MemoryOS分层记忆

Memory OS of AI Agent
2025.05论文延伸EMNLP 2025Jiazheng Kang, Mingming Ji, Zhe Zhao, Ting Bai · 北京邮电大学 / 腾讯待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

智能体和用户长期对话时，固定的上下文窗口装不下历史，现有记忆方法又缺少系统化的管理，导致长对话中前后不一致、记不住用户偏好。

方法

借鉴操作系统的内存管理，设计短期、中期、长期个人记忆三级存储，配合存储、更新、检索、生成四个模块，按先进先出和分段分页的规则在各级之间动态搬运记忆。

影响

在LoCoMo长对话基准上相对基线F1平均提升49.11%、BLEU-1提升46.18%（基于GPT-4o-mini），是2025年“记忆操作系统”这一类设计的代表开源实现之一。

方法

MemoryOS把智能体的记忆分成三级，类比计算机的缓存、内存和磁盘：

  • 短期记忆：最近几轮对话原文，按对话链组织；
  • 中期记忆：短期记忆满了以后，按先进先出把较早的对话块移到中期，并按主题合并成段，像操作系统按页组织内存；
  • 长期个人记忆：中期记忆中被反复访问、重要性高的段，按分段分页的策略提炼成用户画像和知识条目，长期保存。

四个模块负责具体操作：存储把对话写入各级；更新在各级之间搬运、合并、淘汰；检索在回答时从三级记忆中分别找出相关内容；生成把检索结果与当前问题组合成提示交给大模型作答。这延续了MemGPT“像操作系统一样管理上下文”的思路，并与MemoryBank长期记忆的长期记忆、Mem0长期记忆的记忆抽取更新等做法对照。

在LoCoMo超长对话记忆超长多轮对话基准上，以GPT-4o mini为底座时，MemoryOS相对基线F1平均提升49.11%、BLEU-1提升46.18%，表现出更好的上下文连贯性和个性化记忆保持能力。

局限与后续
