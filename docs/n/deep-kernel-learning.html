深度核学习DKL

Deep Kernel Learning
2015.11论文延伸AISTATS 2016Andrew Gordon Wilson, Zhiting Hu, Ruslan Salakhutdinov, Eric P. Xing · 卡内基梅隆大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

高斯过程给出可靠的不确定性，但标准核（如RBF）表达力有限，且精确推断代价随样本数立方增长；深度网络表达力强却没有校准良好的不确定性。

方法

先用深度网络把输入变换成特征，再在特征上套一个谱混合基核，网络权重和核超参数一起通过高斯过程的边际似然学习；配合结构化插值让训练代价线性于样本数。

影响

成为“神经网络特征 + 高斯过程头”这一路线的代表，GPyTorch等库把它作为标准范例，广泛用于小数据回归、贝叶斯优化与不确定性估计。

方法

深度核写作 k(x, x') = k_base(g(x; w), g(x'; w))：g是一个深度网络（如卷积网络或多层感知机），k_base是谱混合核这类表达力较强的基核。整个模型仍是一个高斯过程回归，所以可以用边际似然 log p(y | X, w, θ) 同时对网络权重w和核参数θ求梯度，端到端地学出“适合这个数据的核”，而不是先训网络再固定特征。

为了让它扩展到大数据，作者采用局部核插值与诱导点（KISS-GP），并利用Kronecker与Toeplitz结构加速矩阵运算，使训练与推断代价为O(n)，单个测试点预测为O(1)。摘要报告：在一大批应用（包括一个200万样本的数据集）上，它优于带灵活核学习的可扩展高斯过程，也优于单独的深度网络。

局限与后续

  • 网络参数通过边际似然学习，在参数很多时容易过拟合边际似然，不确定性可能并不可靠。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 插值加速依赖低维特征空间，特征维数高时网格结构失效。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    核技巧与最优间隔分类器1992 · 基础
    核方法框架，基核作用在网络输出的特征上。
  • 竞争
    贝叶斯神经网络1992 · 基础
    另一条为深度模型提供不确定性的路线：只对最后的核层做贝叶斯处理，而不是对所有权重。
  • 延续
    高斯过程回归1995 · 基础
    把高斯过程的核换成“深度网络特征上的基核”，并联合学习。
  • 竞争
    随机变分高斯过程SVGP2013.09 · 基础
    同为可扩展高斯过程：SVGP用随机变分诱导点，DKL用结构化插值。
