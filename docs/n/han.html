HAN层次注意力分类

Hierarchical Attention Networks for Document Classification
2016.06论文延伸NAACL 2016Zichao Yang, Diyi Yang, Chris Dyer, Xiaodong He, Alex Smola, Eduard Hovy · 卡内基梅隆大学、微软研究院待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

给一篇长评论或长文档分类时，把所有词一股脑送进CNN或RNN，忽略了「词组成句、句组成篇」的结构；而且一篇文档里真正决定类别的往往只是少数几句话、几个词。

方法

两层编码、两层注意力：先用双向GRU加词级注意力把每个句子汇总成句向量，再用双向GRU加句级注意力把句向量汇总成文档向量；注意力权重由一个可学习的「上下文向量」与各词或各句的表示打分得到。

影响

在Yelp、IMDB、雅虎问答、亚马逊评论六个大规模文本分类数据集上大幅超过此前方法，注意力权重还能直观显示哪些句子和词决定了分类，成为BERT之前文档分类最常用的基线之一。

方法

TextCNN句子分类、字符级CNN文本分类把文档当作一长串词或字符处理。HAN认为文档有天然的层次：图中例子是一条Yelp餐馆评论，「pork belly = delicious」和「a-m-a-z-i-n-g」所在的两句几乎决定了好评，其余句子贡献很小。

词级：对第i句的词向量序列，用双向GRU（门控循环单元，见RNN编码器-解码器与GRU）得到每个词的表示h_it；经过一层MLP得到u_it = tanh(W·h_it + b)，与一个可学习的词级上下文向量u_w做点积再softmax得到权重α_it，句向量s_i = Σ_t α_it·h_it。u_w可以理解为一个固定的提问：「哪些词信息量大？」，它随模型一起训练。句级：对句向量序列再用一个双向GRU和句级上下文向量u_s做同样的注意力，得到文档向量v，最后接softmax分类。

作者在六个数据集（Yelp 2013/2014/2015、IMDB、雅虎问答、亚马逊评论）上评测，摘要称以显著优势超过此前的方法；可视化显示模型能挑出定性上有信息量的词和句子，同一个词（如good）在不同语境下得到的权重也不同。

局限与后续

  • 需要先把文档切分成句子，句子之间只通过句级GRU间接交互，跨句的细粒度信息难以利用。
    后来针对它的工作　BERT
  • 注意力权重被当作解释，但注意力高的词并不一定是模型决策真正依赖的依据。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    注意力机制2014.09 · NLP
    把用于翻译对齐的加性注意力改为以一个可学习的上下文向量做查询，用于汇总词和句子。
  • 使用
    RNN编码器-解码器与GRU2014.06 · NLP
    词级和句级编码器都是双向GRU。
  • 竞争
    TextCNN句子分类2014.08 · NLP
    TextCNN用卷积加最大池化把整段文本压成一个向量；HAN改用循环网络加两层注意力，显式利用句子边界。
  • 改进
    字符级CNN文本分类2015.09 · NLP
    字符CNN等方法把文档当作扁平序列，在多个大规模分类数据集上被HAN的层次结构超过，并且不能指出哪句话起作用。

后来的相关工作

  • 改进
    BERT2018.10 · LLM
    需要先把文档切分成句子，句子之间只通过句级GRU间接交互，跨句的细粒度信息难以利用。

读懂它需要的概念

循环网络与隐状态 门控机制 注意力机制 Softmax与logits 嵌入向量

本篇术语

  • 上下文向量　HAN里一个随模型一起训练的向量，用来和每个词（或句）的表示做点积，打出它的重要性分数。

怎么学

先读注意力机制的讲解 → 读原文第2节词级与句级的编码和注意力 → 动手：在IMDB上实现HAN，把一条评论中各句的注意力权重画出来，看模型是否把权重放在表达态度的句子上。
