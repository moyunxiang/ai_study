DETR3D多视角三维检测

DETR3D: 3D Object Detection from Multi-view Images via 3D-to-2D Queries
2021.10论文延伸CoRL 2021Yue Wang, Vitor Guizilini, Tianyuan Zhang, Yilun Wang, Hang Zhao, Justin Solomon · MIT、Toyota Research Institute等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

只用多个摄像头做三维目标检测时，主流做法要么从单张图直接回归三维框，要么先估计每个像素的深度再检测，深度估计的误差会层层累积。

方法

反过来做：在三维空间里放一组稀疏的“物体查询”，用相机参数把每个查询的三维位置投影到各个视角的图像上取特征，直接在三维空间里预测检测框。

影响

是纯视觉多相机三维检测里“稀疏三维查询”路线的代表作，BEVFormer等后续方法沿用了它的查询式框架。

方法

自动驾驶车上通常装着六个左右的环视摄像头。Lift-Splat-Shoot这类“自底向上”的方法先给每个像素估深度，把图像特征抬升到三维再检测，误差会从深度估计一路传到检测框。DETR3D借用了DETR的集合预测思想：模型维护一组可学习的物体查询，每个查询先预测一个三维参考点，用相机内外参矩阵把这个点投影到所有视角的二维特征图上，采样对应位置的特征并汇总，用来更新查询，再迭代细化。每个查询最终输出一个三维框，训练时用集合到集合的二分匹配损失和真值对齐。

摘要指出，这种自顶向下的做法不受深度预测带来的累积误差影响，并优于对应的“先估深度再检测”的方案；由于每个查询直接对应一个物体，也不再需要非极大值抑制等后处理，推理更快。它在nuScenes自动驾驶基准上取得了当时最好成绩。

局限与后续

  • 每个查询只采样参考点投影处的特征，感受范围有限，也没有利用多帧时序信息。

读懂它需要的概念

相机模型与多视图几何 注意力机制 IoU与mAP 锚框与非极大值抑制 分类、检测、分割

本篇术语

  • 物体查询　一组可学习的向量，每个向量负责“认领”场景中的一个物体并输出它的检测框。
  • 相机内外参　描述三维点如何投影到一张图片上的矩阵：外参是相机的位置朝向，内参是焦距和成像中心。

怎么学

先理解DETR的二分匹配损失和针孔相机投影公式，再读论文第3节的三维到二维查询；之后对比BEVFormer如何把查询换成鸟瞰网格。
