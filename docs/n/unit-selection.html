单元选择拼接合成

Unit Selection in a Concatenative Speech Synthesis System Using a Large Speech Database
1996.05论文重要ICASSP 1996Andrew J. Hunt, Alan W. Black · ATR口译电话研究所（京都）待核对
论文（IEEE） ↗Black & Campbell 1995：Optimising selection of units ↗Festival语音合成系统 ↗在交互版中打开（演化树、学习进度）

问题

规则驱动的共振峰合成听起来像机器人；双音子拼接每种单元只录一份，靠信号处理硬改音高和时长，拼出来既不自然也不连贯。

方法

录一个大语料库，每个音素保留许多不同语境、不同韵律的真实录音；合成时把“挑哪段录音”看成在状态网络里找最低代价路径：目标代价衡量单元与需求的差距，拼接代价衡量两段接得顺不顺，用Viterbi搜索求解。

影响

让合成语音第一次在大部分句子上接近真人录音的音质，成为1990年代末到2010年代中期商用TTS的主流方案，直到神经网络合成取代它。

背景

文本转语音（TTS）分两步：先由文本分析得到要说的音素串，以及每个音的目标音高、时长、重音（韵律）；再生成波形。1980年代的波形生成有两类。Klatt共振峰合成器这类共振峰合成用几十个参数驱动数字共振器，完全可控、占用小，但声音明显是合成的。拼接合成则把真人录音切成小段再接起来，常用单元是双音子（从一个音的中间到下一个音的中间），每种只录一份；为了满足目标韵律，要用信号处理把录音的音高和时长硬改过去，改动越大音质越差，接缝处也常有毛刺。

计算机的存储变便宜之后，一个自然的想法是：多录一些，每种单元存很多个版本，让合成时“挑”而不是“改”。问题是候选成千上万，怎样挑出整句最好的一串？

方法

语料库。几小时的单人录音被自动切分到音素级，每个单元都标注音素身份、前后邻音、音高、时长、能量、在词和短语中的位置等特征。

两种代价。对目标序列t₁…t_n和候选单元序列u₁…u_n：

  • 目标代价C^t(t_i, u_i) = Σ_j w_j · C_j^t(t_i, u_i)：候选单元与第i个目标在各项特征上的差距之和，例如音高差多少、邻音对不对。
  • 拼接代价C^c(u_{i−1}, u_i) = Σ_k w_k · C_k^c(u_{i−1}, u_i)：两个单元接在一起时边界处频谱、音高、能量的不连续程度。如果两个单元在原录音里本来就相邻，拼接代价为0，所以系统会尽量整段整段地取原始录音。

搜索。总代价C = Σ C^t + Σ C^c。把每个目标位置的所有候选看成一列状态，目标代价是状态的代价，拼接代价是转移的代价，这和HMM统计语音识别的解码网络形式完全相同，于是可以用带剪枝的Viterbi算法搜索（见动态规划）在多项式时间内找到全局最优的单元串。

学权重。各项子代价的权重w过去靠人手调。论文提出两种直接从自然录音中训练这些权重的方法，作者报告，训练得到的权重比手调的更自然。

结果

论文本身以框架和权重训练方法为主，用听感比较说明训练出的权重比手工调参得到更自然的语音（据论文摘要）。Black随后在爱丁堡参与开发的开源Festival合成系统也实现了这套单元选择方法。

后来的发展

单元选择成为此后约二十年商用TTS的主流：AT&T、Nuance等厂商的产品，以及早期Siri与语音助手等语音助手的声音都以它为基础。它的音质上限取决于语料库：语料库覆盖到的句子几乎和真人录音一样，覆盖不到时就会出现明显的接缝或韵律跳变。

统计参数合成HMM参数语音合成用HMM生成参数，换来小体积和可控性，但音质发闷；两者并存了十多年。2016年WaveNet直接逐采样点生成波形，音质超过了单元选择，Tacotron 2之后神经端到端合成全面取代了拼接方案。

容易误解的地方

  • 单元选择并不是不做信号处理，而是尽量少做：只在接缝处做轻微平滑，避免大幅修改音高和时长。
  • Viterbi在这里不是用来识别，而是用来在候选录音片段中做组合优化，搜索框架与识别解码相同而用途相反。

读懂它需要的概念

动态规划 音素、声学模型与语言模型的分工 波形、频谱与梅尔谱 隐马尔可夫模型

本篇术语

  • 目标代价（target cost）　一个候选录音片段和这个位置想要的音素、上下文、音高、时长之间的差距。
  • 拼接代价（concatenation cost）　两个片段接在一起时边界处的不连续程度；在原始录音中相邻的两个片段代价为0。
  • 双音子（diphone）　从一个音素的中间到下一个音素的中间的一段语音。把切点放在音素中间较稳定的部分，拼接更平滑。

怎么学

先补动态规划和Viterbi算法。读原论文第2–3节的代价定义和搜索。动手：录或下载一小段带音素标注的语音（如CMU ARCTIC），自己写一个只用音高差和邻音匹配做目标代价、用边界MFCC距离做拼接代价的简易单元选择器，体会代价权重对听感的影响。
