ExpeL经验学习智能体

ExpeL: LLM Agents Are Experiential Learners
2023.08论文延伸AAAI 2024Andrew Zhao, Daniel Huang, Quentin Xu, Matthieu Lin, Yong-Jin Liu, Gao Huang · 清华大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

Reflexion能在同一个任务上靠反思重试变好，但反思只服务于当前这道题，换一道新题经验就丢了；而GPT-4这类模型只能通过API调用，也没法靠微调把经验学进参数。

方法

在一批训练任务上先自由试错、积累成功与失败的轨迹，再让LLM对比成败，总结成一条条自然语言「洞见」；遇到新任务时，把洞见和最相似的成功例子一起放进提示，一次作答。

影响

在HotpotQA、ALFWorld等任务上明显超过ReAct，且随经验积累持续提升，洞见还能迁移到相近的新任务；「把经验提炼成可复用的文字规则」成为后来智能体记忆和自我进化工作的常见做法。

方法

收集经验：在训练任务上运行ReAct智能体，失败后按Reflexion的方式写反思再试，最多重试三次。所有成功和失败的轨迹都存进经验池。

提炼洞见：让GPT-4读两类材料——同一任务的「失败—成功」对，以及多条成功轨迹——维护一份不断更新的洞见列表。它可以做四种操作：新增、修改、赞同（加分）、反对（减分）；每条洞见初始两分，减到零就删除，这样偶然得出的错误规则会被逐步淘汰。例如在网购任务里可能总结出「先按价格筛选再看细节」。

使用：面对新任务，提示里放上全部洞见，再用向量检索（FAISS向量检索近邻搜索）找出最相似的几条成功轨迹作示例；智能体只做一次尝试，不重试。执行用GPT-3.5-turbo，提炼洞见用GPT-4，后者总结出的洞见更好。

结果：成功率上，HotpotQA多跳问答从ReAct的28.0%升到39.0%，ALFWorld从40.0%升到59.0%；把HotpotQA上学到的洞见迁移到FEVER事实核查，从63%升到70%。WebShop上提升较小。

怎么学

先读ReAct和Reflexion → 读原文第3节经验收集与洞见提取的四种操作 → 动手：在十几道多跳问答上记录成功和失败轨迹，让模型总结三条规则，再测这些规则对新题的帮助。
