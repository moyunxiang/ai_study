Apple MLX

2023.12系统延伸Awni Hannun, Angelos Katharopoulos, Jagrit Digani, David Koski · Apple machine learning research待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

苹果芯片的CPU和GPU共用同一块内存，但PyTorch等框架把它当作传统的主机加独立显存来用，没有利用这一特点，Mac上做LLM实验不顺手。

方法

做一个面向Apple silicon的数组框架：NumPy风格的API，组合式函数变换，惰性计算，数组放在统一内存里，各设备上的运算无需拷贝数据。

影响

让Mac成为本地跑和微调LLM的主要平台之一，并催生mlx-lm等生态。

方法

MLX是Apple机器学习研究团队发布的框架。README列出的特性：Python接口贴近NumPy，另有C++、C、Swift接口；mlx.nn、mlx.optimizers的接口贴近PyTorch；函数变换可以组合，类似JAX的grad、vmap和JIT；计算是惰性的，数组在真正需要时才物化；图是动态构建的。

最有辨识度的是统一内存模型：数组存在共享内存中，同一个数组可以被CPU或GPU上的运算直接使用，不需要来回传输。这正是Apple M1与统一内存引入的统一内存架构带来的机会。MLX的设计明显受JAX、PyTorch和ArrayFire影响。

后来的发展

此后出现了面向MLX的大模型库和量化格式，社区常用它在Mac上推理和LoRA微调。

局限与后续

  • 硬件只限Apple silicon，训练规模受单机内存限制，无法扩展到多机集群。
