HMM参数语音合成

Speech Parameter Generation Algorithms for HMM-Based Speech Synthesis
2000.06论文重要ICASSP 2000Keiichi Tokuda, Takayoshi Yoshimura, Takashi Masuko, Takao Kobayashi, Tadashi Kitamura · 名古屋工业大学 / 东京工业大学待核对
论文（IEEE） ↗HTS工具包主页 ↗Zen, Tokuda, Black 2009：Statistical parametric speech synthesis综述 ↗在交互版中打开（演化树、学习进度）

问题

单元选择合成要录几小时到几十小时的单人语料，体积大、换声音难、韵律不可调；而直接让HMM按状态吐出均值，得到的参数是一段段台阶，听起来断断续续。

方法

把识别用的HMM反过来做生成：观测向量里同时放静态频谱参数和它的一阶、二阶差分，生成时求“静态加差分”整体概率最大的参数轨迹，这是一个线性方程组，解出来就是平滑连贯的频谱序列。

影响

确立了统计参数语音合成路线：模型只有几兆字节、可用少量数据做说话人自适应、能连续控制韵律。它在2000–2015年间与单元选择并列为两大TTS方案，后来的DNN合成直接继承了它的框架。

背景

到1990年代末，单元选择拼接合成拼接真人录音，音质最好，但一个声音要专门录大量语料，库很大，想换说话人、加点情感都得重录。另一条路是用统计模型预测声学参数，再交给声码器（见声码器与音频编解码）合成波形。

HMM统计语音识别已经把HMM训练得很成熟，自然的想法是用同样的上下文相关HMM来生成：把音素串对应的HMM串起来，让每个状态输出它的均值。问题是HMM假设一个状态内部各帧独立同分布，于是每个状态停留期间输出同一个均值向量，状态一切换就跳变，频谱轨迹是一级级台阶，声音非常不自然。

方法

观测里加上差分。每帧的观测向量是o_t = [c_t, Δc_t, Δ²c_t]，其中c_t是静态的梅尔倒谱系数（描述频谱包络），Δc_t = (c_{t+1} − c_{t−1}) / 2是前后帧的变化量，Δ²c_t是变化量的变化。训练时HMM对这三部分一起建模，所以每个状态不仅知道“频谱大概是多少”，还知道“频谱这时应该往哪个方向、以多快的速度变”。

把差分写成矩阵。差分是静态参数的线性组合，于是整句的观测可以写成o = W·c：c是所有帧静态参数拼成的长向量，W是一个由0、±0.5、1等系数构成的稀疏矩阵。

求最可能的轨迹。给定状态序列q（每个状态的均值μ_q和协方差U_q），要找使log N(W·c; μ_q, U_q)最大的静态参数c。对c求导令其为0（见最大似然估计），得到线性方程组

Wᵀ U_q⁻¹ W · c = Wᵀ U_q⁻¹ μ_q

左边的矩阵是带状的，解的时间与帧数成正比。直观地说：静态均值把轨迹拉向每个状态的目标值，差分约束它在状态边界上平滑过渡，结果是连续曲线而不是台阶。

这篇论文新增的部分。上面的解法假定状态序列已知。实际上状态序列（以及多高斯混合时用的是哪个高斯）是隐藏的。作者把它当作隐变量模型，推导出交替进行Baum-Welch算法前向-后向计算和上面的参数生成步骤的迭代算法，类似EM算法，使生成结果对整个模型而不是单条路径最优。

完整系统。基频和时长也由HMM建模，上下文相关模型用决策树状态绑定式的决策树聚类，生成的参数交给源-滤波器声码器还原成波形。

结果

论文的实验表明，用这一算法从多高斯混合HMM中生成时，频谱中能重现清晰的共振峰结构，而单高斯HMM生成的共振峰更模糊（据论文摘要）。团队随后以HTK补丁的形式发布HTS工具包，后续版本加入了说话人自适应、STRAIGHT声码器和DNN建模选项。

后来的发展

统计参数合成的优势在于灵活：模型很小，可以放进手机；用MLLR说话人自适应式的线性变换，少量新说话人数据就能把平均声音改成目标声音；还能在两种风格之间插值。短板是音质发闷、有“声码器味”，原因是统计平均造成的过平滑和简单的激励声码器。

DNN参数语音合成在2013年用深度网络代替决策树聚类的HMM来预测声学参数，生成步骤沿用这里的方法；WaveNet和Tacotron 2随后连声码器和手工特征一起换掉，参数合成让位于神经端到端合成。

容易误解的地方

  • HMM合成并不是“把识别反过来跑一遍”那么简单：如果不在观测里加差分并按整句求最优轨迹，HMM只能生成一级级的台阶。
  • 骨架把这个节点称作“HMM参数语音合成”，但参数生成算法的思想（使用动态特征）已由Tokuda、Kobayashi、Imai在ICASSP 1995上提出（假定状态序列可搜索、对每条状态序列解线性方程）；这篇2000年的论文贡献的是在状态序列未知时的生成算法，以及多高斯混合下的效果。

读懂它需要的概念

隐马尔可夫模型 高斯分布 最大似然估计 EM算法 声码器与音频编解码 波形、频谱与梅尔谱

本篇术语

  • 统计参数合成　不存储录音片段，而是用统计模型预测每一帧的声学参数（频谱包络、基频、时长），再用声码器合成波形。
  • 动态特征（Δ、Δ²）　相邻帧参数的差，分别表示参数变化的速度和加速度。识别里用来补充上下文，合成里用来约束轨迹平滑。
  • 过平滑（over-smoothing）　模型输出的是许多样本的平均，细节被抹平，频谱峰谷变浅，听起来发闷。

怎么学

先补隐马尔可夫模型、高斯分布和最大似然估计。然后读Zen、Tokuda、Black 2009综述的第2节，按其中的推导自己写出Wᵀ U⁻¹ W c = Wᵀ U⁻¹ μ。动手：用numpy构造三个状态、每状态五帧的一维例子，比较只取均值的台阶输出和加差分约束后解出的平滑曲线。
