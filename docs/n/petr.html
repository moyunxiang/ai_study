PETR三维位置编码检测

PETR: Position Embedding Transformation for Multi-View 3D Object Detection
2022.03论文延伸ECCV 2022Yingfei Liu, Tiancai Wang, Xiangyu Zhang, Jian Sun · 旷视待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多视角三维检测里，DETR3D要把三维参考点投影回图像去采样特征，投影误差和只采单点特征都限制了效果。

方法

把每个像素对应的三维射线坐标编码成位置嵌入加到图像特征上，得到“三维位置感知”的特征，让物体查询直接与它们做注意力。

影响

在nuScenes上达到50.4% NDS、44.1% mAP，作为简单强基线开启了PETR系列（PETRv2、StreamPETR），与BEV路线并列为纯视觉三维检测的两大主流。

方法

DETR3D多视角三维检测用三维参考点投影到各相机图像上取特征，不显式构造鸟瞰图。PETR换了个方向：根据相机参数，把每个图像像素对应的一串三维空间点（沿视线方向的离散深度）算出来，经过网络编码成三维位置嵌入，加到二维图像特征上。这样每个图像特征都“知道”自己在三维空间的位置，物体查询可以像DETR那样直接对所有视角的特征做全局注意力，端到端输出三维框，不需要投影采样。PETR在nuScenes上达到50.4% NDS和44.1% mAP，排名第一。

局限与后续

  • 单帧检测，没有利用时间信息，对遮挡和速度估计不利；全局注意力的计算量也随图像分辨率增长。
