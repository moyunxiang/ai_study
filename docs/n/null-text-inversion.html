Null-text反演

Null-text Inversion for Editing Real Images using Guided Diffusion Models
2022.11论文延伸CVPR 2023Ron Mokady, Amir Hertz, Kfir Aberman, Yael Pritch, Daniel Cohen-Or · Google Research / 特拉维夫大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Prompt-to-Prompt能只改提示词里的几个词来编辑图像，但前提是知道这张图的生成噪声；对真实照片做DDIM反演时，一旦开启无分类器引导CFG，误差逐步累积，重建出来的已不是原图。

方法

先用无引导的DDIM反演得到一条“枢轴”轨迹，再逐步只优化CFG里那个“空文本”的嵌入，使带引导的采样精确沿这条轨迹回到原图；模型权重和描述文字都不动。

影响

让Prompt-to-Prompt这类基于注意力控制的编辑能用于真实照片，成为2023年前后真实图像文本编辑的标准预处理步骤；“优化无条件嵌入来校正反演”的思路被后续反演方法反复比较。

方法

DDIM采样是确定性的，可以反过来跑：从真实图像x_0逐步加噪得到x_T，再从x_T采样回来就能近似重建。问题在于文本编辑需要较大的CFG系数w（如7.5），而反演过程基于无引导的估计，带引导采样时每一步都偏一点，越走越远。

Null-text inversion的两个部分：

  • 枢轴反演：先用w=1做DDIM反演，记录整条轨迹x_T*, …, x_0*作为“枢轴”。它不完美，但是一个好的锚点。
  • 空文本优化：CFG的输出是ε_uncond + w(ε_cond − ε_uncond)，其中ε_uncond以空字符串的嵌入∅为条件。从t=T开始，对每个时间步单独优化一个∅_t，使从x_t带引导走一步的结果尽量接近枢轴上的x_{t−1}*。优化完成后，用这组∅_t加原始描述就能几乎完美地重建原图。

之后只要把描述文字改几个词，并在采样时套用Prompt-to-Prompt的交叉注意力注入，就得到真实图像的编辑结果。整个过程基于公开的Stable Diffusion，不改模型权重。

局限与后续

  • 每张图要为每个时间步做若干次优化，耗时约一分钟，不够快。

读懂它需要的概念

扩散：前向加噪与反向去噪 条件生成与引导 嵌入向量 梯度下降 常微分方程与随机微分方程

本篇术语

  • DDIM反演　把确定性的DDIM采样过程倒着运行，从一张真实图像求出能生成它的初始噪声。
  • 空文本嵌入　无分类器引导中代表“没有条件”的那个文本嵌入，通常是空字符串经文本编码器的输出。
