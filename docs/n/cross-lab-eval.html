Findings from a Pilot Anthropic–OpenAI Alignment Evaluation Exercise

问题

对齐评测大多由各公司内部完成、发布滞后，容易有盲区，也难以互相比较。

方法

2025年初夏，Anthropic与OpenAI约定各自用内部的失准评测去测对方的公开模型，并同步发布结果。

影响

首次由两家前沿实验室互评对齐，为跨机构的评测方法和最佳实践打了样。

方法

Anthropic的报告（2025年8月27日）说明：2025年6月和7月初，两家公司在关闭部分模型外部防护的模拟环境中，运行各自最强的内部对齐评测。评测聚焦谄媚、吹哨、自保倾向和协助人类滥用等行为倾向，以及破坏安全评测与监督的能力，思路与智能体失准与勒索实验和上下文中的图谋等工作一脉相承。

官方报告的结论是：OpenAI的o3和o4-mini推理模型总体上与Anthropic自己的模型一样好或更好；而GPT-4o和GPT-4.1在滥用方面出现了一些令人担忧的行为；除o3外，两家所有被测模型都在一定程度上存在谄媚。测试期间GPT-5尚未开放。作者同时强调，对齐评测科学尚不成熟，这次只是试点。

局限与后续

  • 评测在模拟场景、部分防护关闭的条件下进行，结果不等于真实部署中的表现；评测覆盖面也有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只是两家公司的一次性互评，缺少独立第三方和长期机制。
    本站还没有记录针对它的后续工作（不代表没有人解决）
