Plan2Explore规划式探索

Planning to Explore via Self-Supervised World Models
2020.05论文延伸ICML 2020Ramanan Sekar, Oleh Rybkin, Kostas Daniilidis, Pieter Abbeel, Danijar Hafner, Deepak Pathak · 宾夕法尼亚大学 / UC伯克利 / 多伦多大学 / CMU等待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

好奇心模块ICM、随机网络蒸馏RND这类好奇心方法都是「到了新地方才发奖励」，事后才知道哪里新奇；而且探索阶段学到的东西是为单一任务服务的，换个任务要重来。

方法

在无奖励的探索阶段学一个世界模型，用多个预测头之间的分歧估计「哪里还没学会」，然后在模型里规划，主动去预期最新奇的地方；探索结束后，用同一个模型零样本或少样本适应新任务。

影响

把「基于模型的规划」用到了探索本身，成为无监督RL和世界模型探索方向的常用基线。

方法

Plan2Explore分两个阶段。

探索阶段（没有任务奖励）：智能体从图像输入学一个Dreamer式的隐空间世界模型（编码器、隐状态转移、图像重建）。另外训练一组（集成）一步预测头，每个都根据当前隐状态和动作预测下一步的特征。在见过很多次的地方，这些头预测得差不多；在没见过的地方，它们各说各的。于是把集成预测的方差当作内在奖励——它衡量的是模型的认知不确定性，而不是环境本身的随机性。关键在于这个奖励可以在想象中计算：智能体在世界模型里展开想象轨迹，用演员-评论家学一个最大化「未来预期分歧」的探索策略，所以它会主动奔向还没去过、但预期很新奇的区域，而不是等撞上了才回头补奖励。

适应阶段：给定一个下游任务的奖励函数，用探索期收集的数据和学好的世界模型，在想象中训练该任务的策略，可以不再与环境交互（零样本），或只交互很少几步。摘要称，在高维图像输入的控制任务上，Plan2Explore不用任何任务监督就超过了以前的自监督探索方法，几乎追平一个能看到奖励的oracle。

局限与后续

  • 分歧奖励依赖集成在没见过区域上真的会「意见不一」，在高随机性或部分可观测环境里仍可能被噪声吸引。

它建立在什么之上

  • 改进
    好奇心模块ICM2017.05 · RL
    ICM在到达新状态后才回溯性地给奖励；Plan2Explore在模型里规划，提前奔向预期的新奇区域。
  • 竞争
    随机网络蒸馏RND2018.10 · RL
    RND用预测误差作新奇度，属于事后奖励的无模型方法；Plan2Explore用模型分歧并提前规划。
  • 使用
    Dreamer2019.12 · 具身·世界模型
    世界模型和在想象中训练演员-评论家的方式直接沿用Dreamer。
  • 延续
    VIME信息增益探索2016.05 · RL
    同样以模型的认知不确定性为探索信号，用集成分歧代替贝叶斯神经网络的信息增益，便于扩展到图像输入。
  • 改进
    集成分歧探索2019.06 · RL
    要训练多个前向模型，计算量随集成大小增长；在高维像素空间里预测分歧仍依赖好的特征空间。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

世界模型 基于模型的强化学习 探索与利用 集成学习 Actor-Critic与优势函数

本篇术语

  • 集成分歧　多个独立训练的预测器对同一输入给出不同预测的程度；分歧越大，说明模型对这里越没把握。
  • 零样本适应　拿到新任务的奖励后，不再和真实环境交互，只在学好的模型里训练出策略。

怎么学

先读Dreamer和好奇心模块ICM；读原文第3节分歧奖励的定义和第4节零样本实验；在Dreamer的开源实现里关掉任务奖励、换成集成方差，观察探索期覆盖的状态范围。
