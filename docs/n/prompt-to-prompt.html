Prompt-to-Prompt

Prompt-to-Prompt Image Editing with Cross Attention Control
2022.08论文延伸ICLR 2023Hertz, Mokady, Tenenbaum, Aberman, Pritch, Cohen-Or · Google Research / Tel Aviv University待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

文生图模型中哪怕只改动一个词，结果常常整张图都变；已有编辑方法需要用户另画遮罩，且会忽略原图遮罩内的结构。

方法

发现交叉注意力层决定了每个词对应图像的哪块区域，于是在重新生成时注入原图的注意力图，仅靠改提示词就完成编辑。

影响

让“只改文字就编辑图像”成为可能，注意力控制成为之后大量编辑方法的出发点。

方法

论文先深入分析文本条件扩散模型，发现交叉注意力层的注意力图把每个词和空间位置联系了起来。于是用同一个随机种子生成原图和编辑图，在编辑图的去噪过程中，把原图提示词对应的注意力图换进来，保住布局。

三种用法：词替换（“猫”改成“狗”，保持构图）；添加描述（加“雪地”之类，未改动的部分保持）；注意力重加权（放大或缩小某个词的影响强度）。整套方法无需遮罩，也无需训练。作者在Imagen和潜扩散模型上都做了验证。

局限与后续

  • 编辑的是模型自己生成的图；对真实照片需要先反演到噪声，反演不准会失真。
    后来针对它的工作　InstructPix2Pix
  • 依赖具体网络的交叉注意力结构，不能直接编辑结构变化大的内容。
    后来针对它的工作　ControlNet

它建立在什么之上

  • 使用
    潜空间扩散LDM2021.12 · 生成
    在潜扩散模型的交叉注意力层上实现同样的编辑。
  • 改进
    SDEdit2021.08 · 生成
    忠实与真实只能靠一个噪声强度权衡，难以在保持局部原样的同时只改局部。
  • 使用
    Imagen2022.05 · 生成
    在Imagen上验证交叉注意力控制。

后来的相关工作

  • 使用
    InstructPix2Pix2022.11 · 生成
    用它来让两个描述生成布局一致的成对图像，作为训练数据。
  • 改进
    ControlNet2023.02 · 生成
    依赖具体网络的交叉注意力结构，不能直接编辑结构变化大的内容。
