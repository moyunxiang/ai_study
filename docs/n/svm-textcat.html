SVM文本分类

Text Categorization with Support Vector Machines: Learning with Many Relevant Features
1998论文延伸ECML 1998Thorsten Joachims · Universität Dortmund待核对
Springer DOI ↗在交互版中打开（演化树、学习进度）

问题

文本分类的特征是成千上万个词，常用的分类器在这样高维稀疏的数据上要么过拟合，要么需要精心挑选特征。

方法

论证文本数据高维、稀疏、大多数特征相关，恰好适合支持向量机，不用选特征也能得到好结果。

影响

SVM成为2000年代初文本分类的默认方法，直到被深度学习取代。

方法

Joachims（题录经Crossref核对：1998，Lecture Notes in Computer Science）先分析文本的性质：特征空间维度很高（词表有几万个词），每篇文档只含很少几个词，所以非常稀疏；而且大部分词都有一点相关性，不是少数几个特征起作用。

SVM的学习不依赖特征空间的维度，它通过最大化间隔（见核技巧与间隔）控制泛化，在高维稀疏的情形下恰好表现好，所以不必做特征选择，把所有词直接丢进去。他在Reuters新闻和Ohsumed医学摘要数据上，把SVM与朴素贝叶斯、Rocchio、决策树、k近邻等方法比较，论文结论是SVM整体最好。

这套做法后来成了常识：用tf-idf向量加线性SVM做文本分类，作为强基线。
