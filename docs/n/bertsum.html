BertSum预训练摘要

Text Summarization with Pretrained Encoders
2019.08论文延伸EMNLP-IJCNLP 2019Yang Liu, Mirella Lapata · 爱丁堡大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

BERT在分类和阅读理解上大幅领先，但它是按词和句对设计的编码器，输入长度有限，也没有句子级的表示，不能直接拿来做需要理解整篇文档、按句挑选或生成摘要的任务。

方法

给每个句子前加一个[CLS]记号、用交替的句段嵌入区分相邻句子，让BERT输出每句的向量；抽取式模型在其上叠几层句间Transformer给每句打分，生成式模型则把BERT当编码器、配一个随机初始化的Transformer解码器，并为两者使用不同的优化器设置。

影响

在三个新闻摘要数据集上同时刷新了抽取式和生成式的最好结果，成为预训练模型做摘要的标准基线，此后的BART、PEGASUS等摘要工作都与它比较。

方法

此前神经摘要的主流是指针-生成器摘要这样的LSTM编码器-解码器，抽取式摘要则用RNN给句子打分。BERT的原始输入是一或两个片段，只有一个[CLS]汇总整段。

文档级编码：在每个句子开头插入[CLS]、结尾插入[SEP]，并给奇数句和偶数句交替使用两种句段嵌入，这样每个[CLS]位置的输出就是对应句子的表示，同时又能看到上下文中的其他句子。抽取式（BertSumExt）：在句子向量上再叠几层句间Transformer层，用sigmoid给每句打一个「是否放进摘要」的分数，选得分最高的几句。生成式（BertSumAbs）：BERT作编码器，解码器是6层随机初始化的Transformer。由于编码器已经预训练而解码器没有，两者用同一学习率会互相拖累，作者为编码器和解码器分别设定学习率与预热步数。两阶段微调（BertSumExtAbs）：先在抽取任务上微调编码器，再做生成式训练，摘要称这能进一步提升生成质量。

在CNN/DailyMail、NYT和XSum三个数据集上，模型在抽取式和生成式两种设定下都取得当时最好的结果（按ROUGE评价）。

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    句间打分层和生成式解码器都是Transformer层。
  • 使用
    BERT2018.10 · LLM
    以预训练BERT为文档编码器，改造输入格式以得到每个句子的表示。
  • 使用
    ROUGE2004.07 · 数据·评测
    所有实验以ROUGE作为自动评价指标。
  • 改进
    指针-生成器摘要2017.04 · NLP
    指针-生成器的LSTM编码器没有预训练，对文档的理解有限；BertSum用预训练编码器在同一数据集上取得更高分。
  • 改进
    LexRank图排序摘要2004.12 · NLP
    只做抽取，不改写句子，摘要可能不连贯、含有指代不明的代词。

后来的相关工作

  • 改进
    BART2019.10 · LLM
    生成式模型的解码器没有预训练，需要专门的学习率技巧来平衡；编码器和解码器一起预训练的模型随后表现更好。
  • 改进
    PEGASUS摘要预训练2019.12 · LLM
    生成式模型的解码器没有预训练，需要专门的学习率技巧来平衡；编码器和解码器一起预训练的模型随后表现更好。
  • 改进
    Longformer滑窗注意力2020.04 · LLM
    受BERT最多512个位置的限制，长文档要截断，后面的内容看不到。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

预训练与微调 Transformer层的结构 编码器-解码器 学习率与学习率调度 文本生成的自动指标

本篇术语

  • 抽取式摘要　从原文中挑出若干原句拼成摘要，不改写。
  • 生成式摘要　让模型逐词生成摘要，可以使用原文没有的词和句式。

怎么学

先读BERT和指针-生成器摘要的讲解 → 读原文第3节文档编码、第4节两种模型与微调日程 → 动手：用PreSumm代码在CNN/DailyMail的一个子集上训练BertSumExt，看它选出的句子是不是多集中在文章开头。
