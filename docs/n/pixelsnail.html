PixelSNAIL

PixelSNAIL: An Improved Autoregressive Generative Model
2017.12论文延伸ICML 2018Xi Chen, Nikhil Mishra, Mostafa Rohaninejad, Pieter Abbeel · UC Berkeley / Embodied Intelligence待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

PixelCNN类模型靠因果卷积看前面的像素，感受野随层数缓慢增长，远处像素的依赖很难建模，限制了图像对数似然。

方法

把因果卷积和自注意力与多头注意力交替堆叠：卷积负责局部细节，带因果掩码的自注意力让每个像素一步就能看到前面所有像素。

影响

论文报告CIFAR-10上2.85 bits/dim、32×32 ImageNet上3.80 bits/dim，是当时的最好似然；它此后常被用作强自回归基线，VQ-VAE-2就用PixelSNAIL式的自回归先验在离散码上建模。

方法

自回归图像模型把一张图展开成像素序列，逐个预测p(x_i | x_1…x_{i−1})。瓶颈在于第i个像素能否充分利用很早以前的像素。PixelCNN++用因果卷积加下采样扩大感受野，但信息仍要经过很多层才能传过来。

作者受同组元强化学习模型SNAIL（时间卷积加软注意力）的启发，设计了由残差块和注意力块交替组成的网络：残差块里是带门控的因果卷积，负责局部纹理；注意力块是带掩码的键—值注意力（类似Transformer的解码器），查询来自当前位置，键和值来自所有已生成位置，于是任何两个像素之间都只有一步的距离。输出端沿用PixelCNN++的离散化逻辑斯蒂混合分布来建模像素值。

结果是在CIFAR-10和32×32 ImageNet的密度估计上刷新了对数似然。

局限与后续

  • 全局注意力的计算量随像素数平方增长，只能用于很小的图像。
    后来针对它的工作　VQ-VAE-2 VQGAN
  • 采样仍要逐像素顺序生成，速度很慢。
    后来针对它的工作　MaskGIT并行掩码生成

  • 因果卷积　只用当前位置之前的输入计算输出的卷积，保证自回归模型不偷看未来。
