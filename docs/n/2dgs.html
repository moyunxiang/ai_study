2D高斯泼溅

2D Gaussian Splatting for Geometrically Accurate Radiance Fields
2024.03论文延伸SIGGRAPH 2024Binbin Huang, Zehao Yu, Anpei Chen, Andreas Geiger, Shenghua Gao · ShanghaiTech / 图宾根大学 / 马克斯·普朗克智能系统研究所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

3D高斯泼溅渲染又快又好，但它用的是三维椭球，不同视角下同一个椭球给出的“表面”并不一致，从中提取的几何很不准。

方法

把三维椭球压扁成二维的有向圆盘（面元），用光线与圆盘求交来渲染，并加入深度畸变和法线一致两项正则，让圆盘贴合真实表面。

影响

高斯泼溅第一次能直接给出干净的表面几何，成为后来用高斯做网格重建的常用基线。

方法

3D高斯泼溅把场景表示成许多三维高斯椭球，再投影到屏幕上混合出颜色。问题在于椭球是有体积的：从不同方向看，它与真实表面相交的位置不同，所以深度和法线在多视角之间自相矛盾，直接取出来的几何很粗糙。

2DGS的做法是让每个基元本身就是一张二维圆盘，有中心、朝向和两个方向的尺度，天然就是一小片表面。渲染时不再把三维高斯近似投影，而是算屏幕像素射线与圆盘的交点，得到透视正确的结果，因此深度和法线在各视角下一致。训练时再加两项损失：深度畸变项把沿同一条射线的圆盘往一起拉，法线一致项要求渲染出的法线与由深度算出的法线吻合。论文称在保持有竞争力的外观质量、训练快和渲染实时的同时，几何精度明显优于3DGS。

局限与后续

  • 每个基元仍是独立优化的圆盘，对反光、透明和细小结构的表面恢复仍不稳，且需要后处理才能得到封闭网格。

读懂它需要的概念

三维表示：体素、点云、网格、隐式场 相机模型与多视图几何 梯度下降 图像作为张量

本篇术语

  • 面元（surfel）　带朝向的小圆片，一片片拼起来表示物体表面。
