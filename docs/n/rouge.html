ROUGE

ROUGE: A Package for Automatic Evaluation of Summaries
2004.07论文重要ACL 2004 Workshop: Text Summarization Branches OutChin-Yew Lin · 南加州大学信息科学研究所（ISI）待核对
ACL Anthology W04-1013 ↗rouge-score（Google的Python实现） ↗在交互版中打开（演化树、学习进度）

问题

评估自动摘要只能靠人读：按NIST的DUC评测那种规模，人工评判一次就要超过3000小时，研究者没法频繁做实验。

方法

借鉴BLEU，但反过来看召回：统计人写的参考摘要里的n-gram、最长公共子序列或跳跃词对，有多少被机器摘要覆盖到，以此近似“内容是否齐全”。

影响

ROUGE成为摘要评测的默认指标，从抽取式摘要到神经网络生成式摘要、再到大模型时代的摘要论文，ROUGE-1/2/L几乎是必报数字。

背景

自动文摘从Luhn自动文摘就开始了，但评价一直靠人：判断摘要是否连贯、简洁、合乎语法、内容是否覆盖原文要点。NIST从2001年起组织文档理解会议（DUC），沿用TREC文本检索评测的方式统一评测摘要系统，可人工评判的成本极高——论文估算，按DUC的规模做一轮这样的人工评价要超过3000小时。

机器翻译这边，BLEU已经说明用n-gram重叠自动评分是可行的。但摘要的关注点不同：翻译最怕说错，摘要最怕漏掉要点。一份好摘要应当覆盖参考摘要里的重要内容，所以应更看重召回而不是精确率。

方法

ROUGE是一个工具包，包含几种互补的度量。

ROUGE-N：n-gram召回率。

ROUGE-N = Σ_参考 Σ_gram Count_match(gram) / Σ_参考 Σ_gram Count(gram)

分母是参考摘要中n-gram的总数，分子是其中也出现在候选摘要里的个数。例如参考是“警察 击毙 了 枪手”，候选是“枪手 被 警察 击毙”，一元召回3/4；二元只有“警察 击毙”匹配，召回1/3。有多份参考时，对每份分别算，取最大值。

ROUGE-L：基于最长公共子序列（LCS，见动态规划）。子序列不要求连续，只要求顺序一致，所以能体现句子层面的语序，又不必预先规定n。用LCS长度分别除以参考和候选的长度得到召回和精确率，再合成F值。

ROUGE-W：加权的LCS，连续匹配的片段得分更高。

ROUGE-S / SU：跳跃二元组，即句中任意两个按顺序出现的词组成的词对，可以限制最大间隔（如ROUGE-S4只看相距不超过4的词对）；SU再加上一元组。

实现上还提供去停用词、词干化等选项，并用自助重采样给出置信区间。

结果

论文用DUC 2001–2003三年的人工评分检验各个度量。在单文档摘要任务上，ROUGE-2、ROUGE-L、ROUGE-W、ROUGE-S与人工评分的皮尔逊相关系数大都在0.8以上，部分设置下达到0.99；对标题式的极短摘要，ROUGE-1、ROUGE-L、ROUGE-SU4等表现最好。多文档摘要上，除长摘要外很难达到0.9以上的相关。去掉停用词和使用多份参考摘要通常都能提高相关性。作者也承认，如何在多文档摘要上像单文档那样高度贴合人工判断，仍是开放问题。

后来的发展

DUC 2004开始用其中三种度量做官方评测，ROUGE随即成为摘要领域的通用尺子。神经网络时代，神经生成式摘要、指针-生成器摘要、PEGASUS摘要预训练、BART都以ROUGE-1/2/L报告在新闻摘要数据上的成绩，它也常被直接当作强化学习的奖励。问题随之暴露：人类反馈学摘要发现按人类偏好训练的模型写出的摘要更受人欢迎，而单纯追求ROUGE并不能得到这样的摘要。BERTScore等基于语义表示的指标、以及用大模型当评委的做法，开始补充甚至替代它。

容易误解的地方

  • 不同实现（原始Perl脚本、Python的rouge-score等）在分词、词干化、是否按句拆分计算ROUGE-L上有差异，数字之间不能直接比较。
  • ROUGE高只说明“用词与参考相近”，不说明摘要事实正确；一份与原文矛盾的摘要也可能得高分。
  • 参考摘要本身质量不一，新闻数据集里的参考常是导语或要点，并非理想摘要。

局限与后续

  • 只比较表面词语重叠，换了说法但意思相同的生成式摘要会被低估。

它建立在什么之上

  • 使用
    DARPA共同任务框架1987 · 数据·评测
    工作由DARPA TIDES项目资助，服务于共同任务式的统一评测：同一批文档、同一批参考摘要、同一个自动指标。
  • 延续
    TREC文本检索评测1992.11 · 数据·评测
    NIST的DUC沿用TREC的统一评测方式组织摘要评测，ROUGE成为其中的自动打分工具。
  • 延续
    BLEU2002.07 · 数据·评测
    沿用BLEU用n-gram重叠自动评分的思路，但改为以召回为主，并加入最长公共子序列和跳跃词对。
  • 改进
    Luhn自动文摘1958.04 · NLP
    自动文摘几十年来缺少可自动计算的评价标准，ROUGE给出了与人工评分高度相关的替代。

读懂它需要的概念

n-gram与平滑 文本生成的自动指标 准确率、精确率、召回率与F1 动态规划

本篇术语

  • 最长公共子序列（LCS）　两个序列中按相同顺序出现、但不要求相邻的最长那串元素，可用动态规划在O(mn)时间内求出。
  • 跳跃二元组　句子里任意两个按先后顺序出现的词组成的词对，中间可以隔着别的词；例如“警察 击毙 枪手”包含“警察-击毙”“警察-枪手”“击毙-枪手”。
  • 抽取式与生成式摘要　抽取式从原文挑出句子拼成摘要；生成式像人一样重新组织语言写出摘要，可能用到原文没有的词。

怎么学

先补n-gram与平滑和动态规划。读原文第2、3节，自己实现ROUGE-1、ROUGE-2和基于LCS的ROUGE-L，再用rouge-score库核对结果；然后给同一篇新闻写一份意思相同但措辞不同的摘要，看看ROUGE会低估多少。
