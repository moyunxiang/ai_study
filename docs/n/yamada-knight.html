基于句法的翻译模型

A Syntax-based Statistical Translation Model
2001.07论文延伸ACL 2001Kenji Yamada, Kevin Knight · 南加州大学信息科学研究所待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

IBM翻译模型是串到串的噪声信道，词的移动只依赖词类和位置，完全不建模句法结构；它主要在英法这种结构相近的语言对上验证，像英日这样语序差异很大（主谓宾对主宾谓）的语言对很可能建模不好。

方法

把噪声信道的输入从英语词串换成英语句法树：信道在树的每个节点上依次做三种随机操作——对子节点重新排序、在节点左边或右边插入一个词（如日语的格助词）、把叶子上的词翻译成目标语言，最后读出目标语言的词串；参数用EM在多项式时间内估计。

影响

这是统计机器翻译中最早被广泛引用的句法模型之一，在英日词对齐上明显好于IBM Model 5；它开启了ISI一系列串到树、树到串翻译模型，GHKM规则抽取就是在其基础上发展出来的。

方法

信道操作。输入是英语句子的句法树（用Brill词性标注器和Collins句法分析器得到，节点标签简化为中心词的词性，并把与父节点中心词相同的子树压平，使SVO结构可以直接调成SOV或VSO）。生成过程分三步：重排——一个节点的子节点序列按r表中的概率换成某个排列，例如PRP-VB1-VB2以较高概率变成PRP-VB2-VB1，以此模拟英日语序差异；插入——在每个节点的左边、右边或不插入，插入位置的概率按节点与父节点的标签查n表，插入哪个词则与上下文无关，用来生成ga、no这类格助词；翻译——每个叶子上的英语词按t表翻译成日语词或空。目标句的概率是所有能产生它的操作序列概率之和：P(f|ε) = Σ_θ Π_i P(θ_i | ε_i)。

训练。作者给出类似内外算法的EM：先自底向上算每个节点的beta概率，再自顶向下算alpha概率，然后收集各表的期望计数。复杂度对句长是多项式级（来自树节点数和外语子串数），并且可以做完整的EM计数，而IBM模型只能在部分对齐上计数。

实验。从日英词典中抽出2121个短句对（英语平均6.9词，日语9.7词，词表中大量词只出现一次），训练20轮EM。让三位评审给前50句的维特比对齐逐条打分：本模型平均0.582，IBM Model 5为0.431；完全正确的句子本模型10句，IBM Model 5为0句。作者指出本模型的错误集中在少数句子，而IBM模型的错误分散在全部句子上。

它建立在什么之上

  • 改进
    IBM统计翻译模型1993 · NLP
    IBM模型不建模句法、在语序差异大的语言对上表现差；本模型在英语句法树上做重排和插入，英日对齐评分从0.431提高到0.582。
  • 使用
    EM算法1977 · 基础
    参数估计用在树结构上做内外概率计算的EM算法。
  • 延续
    噪声信道翻译模型1990.06 · NLP
    保留噪声信道框架，把信道的输入从词串改成句法树。
  • 使用
    Collins词汇化句法分析器1997.07 · NLP
    英语一侧的句法树由Collins句法分析器提供。
  • 使用
    Brill转换式标注器1992 · NLP
    用Brill词性标注器为句法分析提供词性。

本篇术语

  • 噪声信道模型　把翻译看成原文经过一个会「加噪声」的信道变成了译文，翻译就是根据译文反推最可能的原文。
  • 维特比对齐　在模型下概率最大的那一种词对应方式，常用来检查模型学到了什么。

怎么学

先读IBM统计翻译模型和噪声信道翻译模型的讲解 → 读原文第2节三种信道操作与第3节实验 → 动手：手工给一棵「he adores listening to music」的句法树设计重排和插入，推出一个日语式的语序。
