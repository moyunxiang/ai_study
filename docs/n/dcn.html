DCN动态协同注意力

Dynamic Coattention Networks For Question Answering
2016.11论文延伸ICLR 2017Caiming Xiong, Victor Zhong, Richard Socher · Salesforce Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

阅读理解模型通常一次性给出答案片段的起点和终点，若第一次判断落在一个错误但看似合理的位置（局部最优），就没有机会改正。

方法

动态协同注意力网络：编码阶段用一个亲和度矩阵同时在文章和问题两个方向上做注意力，并把「问题对文章的摘要」再按文章注意一次，得到协同注意力表示；解码阶段用一个LSTM反复交替估计答案的起点和终点，每轮都参考上一轮的估计，直到不再变化。

影响

在SQuAD上把单模型F1从71.0%提高到75.9%，集成模型80.4%；协同注意力和迭代式答案解码是BiDAF同期最有代表性的阅读理解设计，后续DCN+等工作沿此改进。

方法

编码。问题和文章先用同一个LSTM编码，得到问题矩阵Q和文章矩阵D（各附加一个「哨兵」向量，让模型可以不注意任何词）。计算亲和度矩阵L = Dᵀ·Q，每个元素是一对文章词和问题词的相似度。按两个方向归一化：A_Q = softmax(L)给出对每个问题词而言文章各词的权重，A_D = softmax(Lᵀ)给出对每个文章词而言问题各词的权重。先得到文章在各问题词下的摘要C_Q = D·A_Q，再把[Q; C_Q]按A_D加权回文章，得到协同注意力上下文C_D = [Q; C_Q]·A_D——这一步相当于把问题的表示映射到文章的空间。最后把[d_t; c_D_t]送入双向LSTM，得到每个文章位置的表示u_t。

动态指针解码器。维护一个LSTM状态h_i，第i轮的输入是上一轮估计的起点和终点处的表示[u_{s_{i−1}}; u_{e_{i−1}}]。用一个高速maxout网络（HMN，把高速网络和maxout结合，适应不同类型的问题和文档主题）分别给每个位置作为起点和终点打分，取最大者作为新的估计。当估计不再变化或达到最大轮数（4轮）时停止。作者观察到，模型平均约2.7轮收敛，常见情形是第一轮起点错、后面几轮修正过来。

结果。SQuAD测试集上单模型F1 75.9%，超过此前最好的71.0%；集成模型80.4%，当时排行第二的结果是78.1%。

    Match-LSTM与答案指针2016.08 · NLP
    Match-LSTM只做问题对文章的单向注意力并一次性预测边界；DCN做双向协同注意力，并迭代修正答案边界，SQuAD上F1更高。

读懂它需要的概念

循环网络与隐状态 注意力机制 Softmax与logits 矩阵乘法与线性变换 编码器-解码器

本篇术语

  • 亲和度矩阵　文章中每个词与问题中每个词两两点积得到的矩阵，按行或按列做softmax就得到两个方向的注意力。
  • 协同注意力　同时计算问题对文章和文章对问题的注意力，并把两者组合起来形成融合两边信息的表示。

怎么学

先读Match-LSTM与答案指针和BiDAF双向注意力流的讲解 → 读原文第2节协同注意力公式(1)–(4)与动态解码器 → 动手：在SQuAD小样本上把解码轮数分别设为1和4，统计迭代修正了多少个起点错误。
