MonoSLAM

MonoSLAM: Real-Time Single Camera SLAM
2007.06论文延伸IEEE TPAMI 2007Andrew J. Davison, Ian D. Reid, Nicholas D. Molton, Olivier Stasse · Imperial College / Oxford / AIST待核对
Crossref ↗在交互版中打开（演化树、学习进度）

问题

同步定位与建图（SLAM）当时主要依赖激光等昂贵传感器，用一个普通摄像头实时做到非常困难。

方法

用扩展卡尔曼滤波同时估计相机的位姿和一小批稀疏的三维路标，用主动搜索只在预测位置附近找特征，从而在普通计算机上实时运行。

影响

第一个能实时运行的单目视觉SLAM系统，把视觉SLAM带入AR、机器人领域，后来的PTAM正是为解决它的扩展性问题而提出。

方法

状态向量包含相机当前位置、朝向、速度，以及每个路标的三维位置，用一个协方差矩阵记录它们的不确定性。每一帧里先用运动模型预测相机的新位置，再预测每个路标应出现在图像中的哪个位置和范围，只在这个预测范围内搜索（称为主动搜索），找到后用卡尔曼更新修正整个状态。

新路标在拥有足够视差后被初始化进状态。因为所有量放在一个协方差矩阵里，计算量随路标数的平方增长，所以实际只能同时维护几十到上百个路标，适合小房间级别的场景。

局限与后续

  • 协方差矩阵随路标数平方增长，只能维持很少的特征，场景不能大。
    后来针对它的工作　PTAM ORB-SLAM
  • 滤波器每帧只更新一次，之前的估计无法回头用全局优化修正。
    后来针对它的工作　PTAM

读懂它需要的概念

相机模型与多视图几何 随机变量与概率分布 高斯分布 状态、观测与动作

本篇术语

  • SLAM　同时定位与建图：边运动边估计自己的位置，同时构建环境地图。

怎么学

先学相机模型与多视图几何里的投影模型，再看Davison的演示视频，读原文的状态和主动搜索部分。
