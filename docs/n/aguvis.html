Aguvis纯视觉GUI智能体

Aguvis: Unified Pure Vision Agents for Autonomous GUI Interaction
2024.12论文延伸ICML 2025Yiheng Xu, Zekun Wang, Junli Wang, Dunjie Lu, Tianbao Xie, Amrita Saha, Doyen Sahoo, Tao Yu, Caiming Xiong · 香港大学 / Salesforce Research待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

GUI智能体要么依赖可访问性树、HTML等文本表示（不同平台各不相同、常常缺失），要么各平台各一套动作格式，要么规划推理还得靠闭源大模型。

方法

只看屏幕截图；把电脑、网页、手机上的操作统一成pyautogui代码加少量手机插件动作；先训练定位，再用带「内心独白」（先观察、再想、再动手）的轨迹训练规划与推理。

影响

官方称是第一个不依赖闭源模型、完全自主的纯视觉GUI智能体；在ScreenSpot、Multimodal-Mind2Web、AndroidControl等离线和在线基准上取得当时最好成绩，数据、模型和训练配方全部开源。

方法

统一动作空间：电脑和网页上的操作都写成pyautogui代码（如 pyautogui.click(x=0.32, y=0.58)），手机特有的操作通过插件补充，如 mobile.swipe(from, to)、mobile.home()。这样各平台的数据可以混在一起训练。

数据（Aguvis Data Collection）：把多个已有的GUI数据集转换成统一格式，并补充推理标注。定位部分约103.6万条单步样本；规划与推理部分约3.5万条多步轨迹，每一步都配上用模型补写的内心独白：先描述当前屏幕、回顾已完成的步骤，再说下一步打算做什么，最后输出动作代码。

两阶段训练，基座为Qwen2-VL与开源VLM：

  • 第一阶段只学定位，得到Aguvis-G；
  • 第二阶段用带内心独白的轨迹学规划和推理。

结果：ScreenSpot上7B平均84.4、72B平均89.2；Multimodal-Mind2Web跨任务步骤成功率72B为64.0；AndroidControl高层指令下72B步骤准确率66.4；在线评测中，7B配合GPT-4o规划在AndroidWorld上成功率37.1，72B在OSWorld上独立运行为10.26%。

局限与后续

  • 在OSWorld这类真实电脑长任务上独立运行成功率只有约10%，离人类水平很远。

怎么学

先读SeeClick GUI定位和OS-Atlas跨平台GUI定位 → 读原文第3节统一动作空间与两阶段训练 → 动手：把一段自己在网页上的操作录成pyautogui代码，并为每一步写一句「观察—打算—动作」的独白。
