自适应攻击击穿防御

The Attacker Moves Second: Stronger Adaptive Attacks Bypass Defenses Against Llm Jailbreaks and Prompt Injections
2025.10论文延伸Milad Nasr, Nicholas Carlini, Chawin Sitawarin, Sander V. Schulhoff, Jamie Hayes, Michael Ilie, Juliette Pluto, Shuang Song 等 · OpenAI / Anthropic / Google DeepMind 等待核对

问题

越狱和提示注入防御通常只用固定攻击字符串或弱优化方法评测，很多防御宣称攻击成功率接近零。

方法

按对抗样本领域的老教训，用针对防御设计、花足够算力的自适应攻击（梯度、强化学习、搜索、人工红队）重新评测。

影响

击穿12个近期防御，多数攻击成功率超过90%，说明LLM防御的评测标准必须改为面对自适应攻击者。

方法

题目说的是：防御者先出招，攻击者看了防御再出招，所以评测必须假设攻击者知道防御设计。作者把通用优化方法系统地调强和放大：梯度方法、用GRPO训练一个攻击模型迭代提出触发文本的强化学习方法、带变异和评分的搜索方法，以及在AgentDojo注入评测任务上举办的、奖金2万美元的人工红队比赛。

被测的12个防御覆盖四类：提示型防御（如重复用户提示、Spotlighting）、对抗训练型（熔断器：表示重定向、StruQ、MetaSecAlign）、过滤模型型（PromptGuard等检测器）、秘密知识型（Data Sentinel、MELON）。多数防御的攻击成功率被打到90%以上，而原论文报告的大多接近零；人工红队在所有场景都成功，静态攻击一个也没成功。这复刻了梯度混淆的虚假安全当年对图像对抗防御的结论。
