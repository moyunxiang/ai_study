CIDEr

CIDEr: Consensus-based Image Description Evaluation
2014.11论文延伸Ramakrishna Vedantam, C. Lawrence Zitnick, Devi Parikh · Virginia Tech / Microsoft Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

评价机器生成的图像描述缺少好指标：BLEU和METEOR与人的共识判断相关性不高，人工评价又太贵。

方法

把一句描述与多条人类参考描述的「共识」程度量化：对n-gram按TF-IDF加权，再算与所有参考句的余弦相似度。

影响

它成为图像描述论文必报的指标之一，CIDEr-D版本由COCO评测服务器采用。

方法

CIDEr（Consensus-based Image Description Evaluation）于2014年11月发表，作者来自弗吉尼亚理工和微软研究院。论文提出一整套「以人类共识评价描述」的方案，包括三部分：一种新的基于三元组的人工标注方法（给出一条描述，让人判断它与两条参考谁更像）来衡量共识，新的自动指标CIDEr，以及两个新数据集PASCAL-50S和ABSTRACT-50S（每张图50条描述）。

CIDEr的直觉是：一条好的描述应该包含大多数人都会用的词和短语，而不是只有个别人用的；同时，每张图都出现的常用词（如「一个」「在」）没有信息量，应当降权。这正是TF-IDF的作用，所以指标对n-gram按TF-IDF加权，再计算候选描述与参考描述的相似度。论文称其比已有指标更好地捕捉人类对共识的判断，并以它评测了五种当时最先进的描述方法。

CIDEr-D是它的一个版本，被收入MS COCO评测服务器。

局限与后续

  • 仍然是基于词面重合的指标，同义改写会被扣分，也不检查描述是否真的与图片相符。
    后来针对它的工作　BERTScore
  • CIDEr的分数可以被「套话」式的高频描述拉高，过度奖励常见说法。
    后来针对它的工作　BERTScore

它建立在什么之上

  • 改进
    BLEU2002.07 · 数据·评测
    BLEU对所有n-gram等权且不看词的信息量；CIDEr用TF-IDF降低常见词权重，更贴近人对共识的判断。
  • 改进
    Flickr30k2014.02 · 数据·评测
    众包写的描述风格不一，评价生成描述的好坏仍依赖有缺陷的自动指标。
  • 使用
    MS COCO2014.05 · 数据·评测
    在COCO的图像描述评测服务器中以CIDEr-D形式提供。
