REALM

REALM: Retrieval-Augmented Language Model Pre-Training
2020.02论文重要ICML 2020Kelvin Guu, Kenton Lee, Zora Tung, Panupong Pasupat, Ming-Wei Chang · Google Research来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

预训练模型把世界知识藏在参数里，要记更多事实只能把网络做得更大，而且知识看不见、改不了；外挂检索器又是TF-IDF这类不会学习的工具。

方法

在掩码语言模型预训练里加一个可学习的检索器：先从维基百科里取几篇文档，再预测被遮住的词，用“预测是否变准”反向训练检索器本身。

影响

作者称首次展示了检索器可以用掩码语言建模信号无监督地预训练；3.3亿参数的模型在开放域问答上超过110亿参数的T5，是“参数记忆+外部文档”路线的早期代表。

背景

BERT和T5之后，人们发现预训练模型能直接答出不少事实问题，比如“英国的货币是什么”。但这类知识是隐式存在参数里的：想覆盖更多事实，模型就得更大；它答错了也无从查证、无法局部修改。

另一条路是DrQA开放域问答式的“先检索、再阅读”：用TF-IDF（见IDF与TF-IDF）从维基百科找出相关段落，再用阅读理解模型抽答案。问题在于检索器是固定的词频统计，不懂同义改写，也不会随下游任务改进；阅读器再强，取不回正确文档也没用。2019年的ORQA已经用可学习的稠密检索器和同样的隐变量写法，但文档索引在训练中固定不变，也没有用语言模型预训练去训练检索器。REALM要回答的是：能不能在预训练阶段，就用海量无标注文本把检索器一起练出来？

方法

把文档当隐变量（见隐变量模型）。对输入x（一个带掩码的句子），先检索文档z，再在x和z的共同条件下预测被遮住的词y：

p(y|x) = Σ_z p(y|z,x) · p(z|x)

检索分布是p(z|x) ∝ exp(Embed_input(x) · Embed_doc(z))，两个嵌入都由BERT编码得到。若检索到的文档让被遮住的词更容易猜对，梯度就会推高这篇文档的得分——检索器因此学会“取回有用的文档”，不需要任何人工标注的检索监督。

几个关键工程设计：

  • 对1300多万个维基百科段落的求和不可能精确算，只取内积最大的top-k，用最大内积搜索（MIPS，见检索与向量数据库）近似。
  • 文档嵌入随训练变化，索引会过时，于是另开一个任务每隔几百步异步重新编码全部文档、重建索引。
  • 突出片段掩码：专门遮住人名、日期等实体，迫使模型必须靠世界知识才能填空（见掩码建模）。
  • 加一个“空文档”选项，让不需要外部知识的预测不被迫检索。

微调到问答时，阅读器从检索到的文档中抽取答案片段。

结果

在Natural Questions开放域问答上精确匹配40.4，WebQuestions 40.7，均高于同为检索式的ORQA（33.3、36.4）；也超过不检索的T5-11B（NQ 34.5），而REALM只有约3.3亿参数，作者称小约30倍。

后来的发展

三个月后的检索增强生成RAG把REALM的“检索+预测”框架从抽取式问答推广到生成任务，并省掉了昂贵的索引刷新（文档编码器固定）。RETRO把检索放大到万亿token的数据库并用于从头预训练，Atlas检索增强少样本沿着“联合训练检索器与生成器”继续推进。今天主流RAG系统多用现成的嵌入模型、不再端到端训练检索器，但“知识放在可替换的外部文档里、模型负责读”的思路沿用至今，REALM是它的早期代表之一。

局限与后续

  • 文档编码器在训练中不断变化，必须每几百步重新编码1300多万个段落、重建索引，训练成本很高。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM 已核对
    检索器的查询、文档两个编码器和知识增强编码器都基于BERT，预训练目标也是BERT的掩码语言建模。
  • 改进
    DrQA开放域问答2017.03 · NLP 已核对
    DrQA的TF-IDF检索器不可学习，REALM让检索器随预测信号端到端训练；论文表1把DrQA列为稀疏检索基线，REALM在三个开放域问答集上比以往方法高4–16个点。
  • 竞争
    T52019.10 · LLM 已核对
    T5代表“把知识全存进参数”的闭卷路线；REALM用小约30倍的模型在NQ上超过T5-11B（40.4对34.5），显示外挂文档可以更省参数。
  • 使用
    Natural Questions2019.01 · 数据·评测 已核对
    主评测基准之一，开放域设定下只给问题、不给原文。
  • 竞争
    kNN-LM2019.11 · 推理·智能体 已核对
    kNN-LM检索的是语言模型训练样本，难以迁移到下游任务；REALM检索的是普通文本，可直接用于微调。
  • 改进
    语言模型即知识库2019.09 · LLM
    参数里的知识停在训练那一刻，没法更新，也说不出答案来自哪份资料。

后来的相关工作

  • 延续
    检索增强生成RAG2020.05 · 推理·智能体 已核对
    REALM把检索用于掩码语言模型预训练和抽取式问答；RAG把同样的隐变量检索思路推广到任意seq2seq生成任务，并省去了训练中重建索引的步骤。
  • 改进
    RETRO2021.12 · 推理·智能体 已核对
    同样是预训练时就接入检索，但REALM要随训练反复重建索引；RETRO冻结BERT检索器，库可以一次建好、做得极大。
  • 改进
    FiD融合解码2020.07 · 推理·智能体 已核对
    下游只能从文档中抽取答案片段，答案不在原文里或需要组织成长句时无能为力。
  • 改进
    Atlas检索增强少样本2022.08 · 推理·智能体 待核对

读懂它需要的概念

掩码建模 预训练与微调 检索与向量数据库 嵌入向量 隐变量模型 内积与余弦相似度

本篇术语

  • 开放域问答　只给问题、不给包含答案的文章，模型必须自己从维基百科等大语料中找到依据再回答。
  • 最大内积搜索（MIPS）　在大量向量中找与查询向量内积最大的若干个，可用近似算法在亚线性时间内完成。
  • 突出片段掩码　预训练时专门遮住命名实体和日期等需要知识才能补全的片段，而不是随机遮词。

怎么学

先懂掩码建模与隐变量模型的边缘化求和。读原文第2–3节（框架与训练），重点看图3的异步索引刷新。对照DrQA开放域问答和检索增强生成RAG，画出三者在“检索器是否可学习、答案是抽取还是生成”两个维度上的差别。
