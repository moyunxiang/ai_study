神经自回归NADE

The Neural Autoregressive Distribution Estimator
2011.04论文延伸AISTATS 2011Hugo Larochelle, Iain Murray · Sherbrooke / Edinburgh待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

受限玻尔兹曼机能建模高维二值数据，但算一个样本的概率需要配分函数，而配分函数在稍大的模型上就算不出来。

方法

把联合概率按链式法则拆成一串条件概率，每个条件概率用一个类似RBM的神经网络建模，于是概率可以精确、直接算出。

影响

给出「用神经网络做自回归密度估计」的最小范式，MADE、PixelRNN / PixelCNN等都沿着它走。

方法

NADE把一个D维二值向量x的概率写成 p(x) = Π p(x_d | x_1…x_{d-1})。第d个条件概率由一个只看前d-1个变量的隐层网络给出：隐层激活 h_d = σ(c + W[:, <d]·x_<d)，输出 p(x_d=1|x_<d) = σ(b_d + V_d·h_d)。

关键技巧是权重共享：计算第d+1个条件时，隐层的预激活只需在第d个的基础上加一项，所有D个条件的总代价约为一次前向的 O(D·H)，而不是 D 倍。因此训练就是直接最大化对数似然，不需要MCMC采样。

论文说它也可以看作一个连线方式特殊的自编码器，输出能当作合法概率。

局限与后续

  • 必须固定一个变量顺序，且第d个变量只能依赖前面的变量，结果对顺序敏感。
    后来针对它的工作　MADE
  • 生成样本时要按顺序一个变量一个变量采样，D很大时很慢，也难处理图像这类带空间结构的数据。
    后来针对它的工作　PixelRNN / PixelCNN 逆自回归流IAF

它建立在什么之上

  • 竞争
    深度信念网络2006 · 基础
    同期的深度信念网络用RBM叠起来，需要近似推断；NADE走精确似然路线。
  • 改进
    玻尔兹曼机1985 · 基础
    RBM的配分函数不可算，NADE用链式分解让似然精确可算。

后来的相关工作

  • 延续
    MADE2015.02 · 生成
    把NADE的自回归分解用掩码推广到任意深度的前馈网络，且无需特殊的权重共享方案。
  • 改进
    PixelRNN / PixelCNN2016.01 · 生成
    把NADE的自回归思路从小的二值向量推到真实彩色图像，并改用深度循环和卷积结构。
  • 改进
    逆自回归流IAF2016.06 · 生成
    生成样本时要按顺序一个变量一个变量采样，D很大时很慢，也难处理图像这类带空间结构的数据。
