HIL-SERL人在回路RL

Precise and Dexterous Robotic Manipulation via Human-in-the-Loop Reinforcement Learning
2024.10论文延伸Jianlan Luo, Charles Xu, Jeffrey Wu, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

真机强化学习样本效率低、容易出危险动作，模仿学习又受限于演示质量，难以做到精密装配这类近乎完美的成功率。

方法

把人类演示和在线人工纠正放进回放池，配合高效的RL算法和系统层设计，让视觉输入的策略在真机上1到2.5小时内学会精细任务。

影响

首次在多种精密任务上让真机RL稳定达到接近满分的成功率，推动「RL微调VLA」一类后续工作。

方法

HIL-SERL（Human-in-the-Loop Sample-Efficient RL）在SAC一类离策略算法的基础上，加入人在回路：操作员先给一批演示，训练时可以随时接管机器人纠正错误动作（思路上与DAgger类似），这些纠正和演示一起用于更新策略和奖励分类器；系统还用预训练的视觉主干，并配合稳定的夹爪控制、奖励用二分类器判定成功等工程设计。

论文称在动态操作、精密装配和双臂协作等任务上，仅用1到2.5小时训练就达到接近完美的成功率和更快的执行速度，相比模仿学习基线平均成功率约2倍，周期约快1.8倍。

局限与后续

  • 每个任务都要单独在线训练，需要人在旁边纠正，不具备跨任务的通用性。
    后来针对它的工作　ConRFT
  • 奖励依赖二分类成功判定器，对难以判定成功的长程任务不适用。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    DAgger2010.11 · RL
    借助人类在线纠正，把DAgger式的交互式模仿融入RL。
  • 改进
    QT-Opt2018.06 · 具身·世界模型
    需要7台机器人、约800小时的真机试验，普通实验室无法复现。
  • 改进
    Diffusion Policy2023.03 · 具身·世界模型
    纯模仿学习，性能上限取决于示范质量，遇到示范里没覆盖的状态容易出错，也不会从失败中改进。
  • 使用
    SAC2018.01 · RL
    以SAC类离策略算法为基础学习。

后来的相关工作

  • 竞争
    π*0.6与RECAP2025.11 · 具身·世界模型 待核对
    都在真机上结合人类纠错与强化学习：HIL-SERL针对单任务小策略做在线离策略RL，RECAP针对通用大VLA用优势条件的监督训练。π*0.6论文引用了同组的SERL，但没有直接讨论HIL-SERL。
