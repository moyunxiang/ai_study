HCAST

HCAST: Human-Calibrated Autonomy Software Tasks
2025.03数据集延伸Rein, Becker, Deng, Nix, Canal, O'Connel, Arnott, Bloom et al. · METR待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

AI能力的分数无法对应真实世界影响，需要一个与人类所用时间挂钩的标尺。

方法

189个机器学习工程、网络安全、软件工程和通用推理任务，收集563份人类基线（共超过1500小时），按人类耗时标注任务难度。

影响

揭示智能体在人类1小时内的任务上成功70%到80%，4小时以上低于20%，为时间跨度指标提供任务基础。

方法

HCAST（Human-Calibrated Autonomy Software Tasks）包含189个任务，覆盖机器学习工程、网络安全、软件工程和通用推理。作者在与智能体相同的条件下收集了563份人类基线，总计超过1500小时，由此估计这些任务需要人类1分钟到8小时以上。

用人类耗时作为难度度量，直观地回答「能否信任一个智能体完成人类需要X小时的任务」。评测结果：当前智能体在人类用时少于1小时的任务上成功率为70%到80%，在人类用时超过4小时的任务上低于20%。这一套任务和人类时间估计，后来是METR任务时间跨度时间跨度指标的核心数据来源。

  • 很长的任务多数只有估计的人类时间而非实测；基线人员的技能与速度有差异。
