Agent Skills

Introducing Agent Skills
2025.10系统延伸Anthropic待核对
Anthropic ↗在交互版中打开（演化树、学习进度）

问题

想让模型掌握一类专门任务（比如按公司格式做表格），要么把说明塞进每次的提示里占上下文，要么微调，都不灵活。

方法

把专业知识打包成文件夹：说明、脚本和资源，模型发现相关任务时才按需加载。

影响

成了“可移植、按需加载”的智能体能力封装格式，后来作为开放标准发布并被多家工具采用。

方法

Anthropic在2025年10月16日发布Agent Skills。一个技能就是一个文件夹，里面有指令、脚本和资源。工作时Claude先扫描有哪些技能，发现某个技能与任务相关才加载所需的最少信息和文件，因此速度不受影响。官方强调四点：可组合（多个技能叠加并自动协调）、可移植（同一格式用于Claude应用、Claude Code和API）、高效（只在需要时加载）、强大（技能可含可执行代码，用确定性程序处理比逐token生成更可靠）。

官方在2025年12月18日补充说，已把Agent Skills发布为跨平台可移植的开放标准。这是上下文工程的一个落地：把长期指令放在磁盘上，按需调入窗口；与模型上下文协议MCP互补，MCP负责连接外部系统，技能负责告诉模型怎么做。

局限与后续

  • 技能内容由模型自己决定是否加载，描述写得不好就会被漏用或误用。
    本站还没有记录针对它的后续工作（不代表没有人解决）
