CD-DNN-HMM

Conversational Speech Transcription Using Context-Dependent Deep Neural Networks
2011.08论文重要Interspeech 2011Frank Seide, Gang Li, Dong Yu · 微软亚洲研究院 / 微软研究院待核对
论文（ISCA Archive） ↗Dahl, Yu, Deng, Acero：Context-Dependent Pre-Trained DNNs（IEEE TASLP 2012） ↗在交互版中打开（演化树、学习进度）

问题

深度网络已在TIMIT音素识别上胜过GMM，但TIMIT很小；在几百小时数据、上万词的真实电话对话上，能否打败调了二十年、经过区分性训练的GMM-HMM系统，仍是未知数。

方法

沿用混合NN/HMM框架，但让深层网络直接输出9304个决策树绑定的三音子状态（senone），输入11帧上下文，7层×2048单元，用DBN预训练后在309小时Switchboard数据上用GPU训练。

影响

在电话对话转写基准上把词错误率从27.4%降到18.5%，相对降低33%。这是深度学习在大词表语音识别上第一次大幅胜出，一两年内各大公司的产品识别器都换成了DNN声学模型。

背景

DBN音素识别在TIMIT上证明了深层网络加HMM的威力，但那里只有183个单音素状态、几小时语音。微软的Dahl、Yu、Deng、Acero随后把输出换成绑定的三音子状态，在几十小时的语音搜索数据上相对降低了约16%的错误。

真正的考验是Switchboard电话语料：电话里两个人的自由对话，口语化、语速快、信道差，是当时最难也最受重视的基准。GMM-HMM在这上面积累了决策树状态绑定三音子、区分性训练（如BMMI，见最大互信息训练MMI）、说话人自适应等一整套技术。批评者认为深层网络只是在小数据上占便宜，换到几百小时数据和数千个状态，要么训不动，要么优势消失。

方法

整体结构。仍是混合NN/HMM：HMM负责时间结构和解码，网络负责给每一帧打分。网络输出状态后验P(s | x)，除以状态先验P(s)后作为HMM的发射概率。

关键改动一：输出是绑定三音子状态。原有GMM系统用决策树把所有三音子的状态绑定成9304个共享状态（senone）。CD-DNN-HMM让网络的Softmax与logits层直接有9304个输出，也就是让网络区分“哪个上下文中的哪个音素状态”，而不只是“哪个音素”。训练标签来自GMM系统的强制对齐。

关键改动二：深而且有上下文。输入是当前帧加前后各5帧，共11帧特征；隐层7层、每层2048个单元，约4500万参数。网络先用深度信念网络逐层预训练，再用反向传播和小批量随机梯度下降与小批量微调。

工程。309小时数据、上亿帧，训练依赖多块NVIDIA Tesla GPU，把运算写成大矩阵乘法；数据在约48小时语音的滚动窗口内打乱。论文还尝试把约三分之二的权重置零（稀疏化），模型变小而错误率还略有下降。

结果

训练数据为309小时Switchboard，测试为单遍、说话人无关解码。主测试集RT03S的Fisher部分：ML训练GMM 30.2%，BMMI区分性训练GMM 27.4%，CD-DNN-HMM 18.5%。Hub5'00 Switchboard部分：BMMI GMM 23.6%，CD-DNN-HMM 16.1%。在另外四个不太匹配的转写任务上相对降低22%–28%。

消融显示深度本身是关键：参数量相同的单隐层网络（4634个单元）错误率26.0%，比GMM还差；加上前后各5帧的上下文降到22.4%；把同样的参数排成7层再降到17.1%。单隐层宽到16000个单元也只有22.1%（据论文表1–3）。

后来的发展

这篇论文让工业界相信了深度学习：2012年多伦多、微软、谷歌、IBM四组联合发表综述深度网络声学模型，DNN声学模型迅速进入微软、谷歌等公司的产品。之后的改进沿着它暴露的问题展开：前馈网络只看11帧，大规模LSTM声学模型和深层双向LSTM识别换成循环网络；逐帧交叉熵训练之后加序列区分性训练，最终演变为无词图MMI链式模型；Switchboard上的错误率一路降到对话语音识别达到人类水平。DBN预训练则很快被证明在大数据上可以省略——论文自己的表2已显示纯反向传播的7层网络只比预训练版本差0.3个百分点。

“深层网络+HMM+WFST解码”的混合架构在Kaldi中成为标准配方，直到2018年前后才被端到端模型逐步取代。

容易误解的地方

  • CD-DNN-HMM并不是端到端模型：发音词典、决策树、GMM对齐、HMM解码一样都没少，换掉的只是给每帧打分的那一部分。
  • 33%的相对降幅里，深度、三音子状态输出和多帧上下文都有贡献；只加深而输出单音素，或只用单隐层，都得不到这样的结果。

它建立在什么之上

  • 使用
    深度信念网络2006 · 基础
    用深度信念网络的逐层预训练初始化7个隐层。
  • 改进
    HMM统计语音识别1976 · 语音
    假设每帧观测在给定状态时彼此独立，输出分布也表达力有限，难以利用相邻多帧的信息。
  • 改进
    CMU SPHINX1988 · 语音
    只在约1000词、安静环境下的朗读语音上验证，离自然对话、电话语音还很远。
  • 改进
    HTK工具包1989 · 语音
    声学模型是最大似然训练的高斯混合，对非高斯分布、相邻帧之间的相关性建模能力有限。
  • 改进
    时延神经网络TDNN1989.03 · 语音
    实验只覆盖3个塞音、特定说话人，扩大到全部音素和说话人无关时网络规模和训练时间在当时的计算机上很难承受。
  • 使用
    Switchboard电话语料1992.03 · 数据·评测
    在309小时Switchboard上训练，在RT03S和Hub5'00电话对话测试集上评测。
  • 改进
    混合NN/HMM1994 · 语音
    1990年代的混合系统网络浅、输出少，始终没能胜过精调的GMM；加深并改用三音子状态输出后，在最难的对话基准上大幅胜出。
  • 延续
    DBN音素识别2009.12 · 语音
    把TIMIT上183个单音素状态的DBN声学模型，扩展到9304个三音子状态、309小时对话语音。
  • 竞争
    最大互信息训练MMI1986.04 · 语音
    对照的最强基线是BMMI区分性训练的GMM-HMM；DNN的相对优势远大于区分性训练带来的提升。
  • 改进
    Rabiner的HMM教程1989 · 语音
    输出概率用高斯混合建模，对特征分布的拟合能力有限。
  • 使用
    决策树状态绑定1994.03 · 语音
    网络的输出类别就是GMM系统用决策树绑定得到的9304个三音子状态。
  • 改进
    MPE区分性训练2002.05 · 语音
    面向GMM的更新公式；深度网络需要改用梯度法实现同类准则。
  • 改进
    Google语音搜索2008.11 · 语音
    声学模型仍是GMM-HMM，对噪声和口音鲁棒性有限。

读懂它需要的概念

多层感知机 Softmax与logits 反向传播 隐马尔可夫模型 音素、声学模型与语言模型的分工 词错误率

本篇术语

  • senone（绑定三音子状态）　用决策树把所有三音子的HMM状态聚类后得到的共享状态，每个对应一个输出类别。这里有9304个。
  • 单遍说话人无关解码　不针对测试者做任何自适应、也不做第二遍重打分，直接一次解码得到结果，最能反映声学模型本身的能力。

怎么学

先读DBN音素识别和混合NN/HMM，弄清后验除以先验的接口。然后读本文第2节与第4节的三张表，重点看表3的逐步消融。动手：在Kaldi的Switchboard或较小的WSJ配方中对比GMM（tri3/tri4）与nnet DNN两个阶段的词错误率，并试着把DNN改成单隐层同参数量，复现“深度比宽度重要”的结论。
