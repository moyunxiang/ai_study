PLBART代码去噪预训练

Unified Pre-training for Program Understanding and Generation
2021.03论文延伸NAACL 2021Wasi Uddin Ahmad, Saikat Chakraborty, Baishakhi Ray, Kai-Wei Chang · 加州大学洛杉矶分校、哥伦比亚大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

CodeBERT、GraphCodeBERT只有编码器，擅长理解却不能直接生成代码或文档；代码摘要、代码生成、代码翻译这类“输入一段、输出一段”的任务需要能生成的预训练模型。

方法

把BART的序列到序列去噪预训练用到大规模Java、Python函数和相关自然语言文本上，得到一个既能理解又能生成的代码—语言通用模型。

影响

第一批编码器—解码器结构的代码预训练模型之一，在代码摘要、生成和七种语言的代码翻译上达到或接近当时最好水平，是CodeT5出现前后代码生成任务的常用基线。

方法

背景：CodeBERT和GraphCodeBERT数据流预训练是BERT式的编码器，做代码搜索、克隆检测很好，但代码摘要（代码→注释）、代码生成（描述→代码）、代码翻译（Java→C#）都需要一个解码器，只能临时接一个随机初始化的解码器，效果受限。BART在自然语言上展示了“加噪声再还原”的编码器—解码器预训练能同时兼顾理解和生成。

数据：从GitHub收集大量Java和Python函数，以及StackOverflow上的自然语言帖子，混合训练，让模型同时见到代码和英文。

预训练：与BART相同的去噪自编码：对输入序列加噪声，再由解码器恢复原文。噪声包括：

  • 词元遮盖：随机把一些词元换成掩码符；
  • 词元删除：随机删掉一些词元，模型要自己判断哪里缺了；
  • 片段填充：把一段连续的词元替换成一个掩码符，模型要恢复整段内容（长度未知）。

不同语言前加一个语言标记，告诉解码器要输出哪种语言。

结果（摘要）：在英文代码摘要、代码生成和七种编程语言的代码翻译上，PLBART超过或匹敌当时最好的模型；在程序修复、克隆检测、漏洞检测等判别任务上也有效。分析显示PLBART学到了程序语法、风格（例如标识符命名规范）和逻辑流（例如else块里的if等价于else if），因此在标注很少时也表现好。

后来的发展

PLBART与之后的CodeT5一起确立了编码器—解码器代码预训练路线，在CodeXGLUE等基准上常被作为基线；后来解码器模型规模化后，这条路线在生成任务上逐渐让位。

局限与后续

  • 预训练只覆盖Java和Python两种语言，其他语言的任务只能靠迁移；模型约1.4亿参数，生成长代码的能力有限。
    后来针对它的工作　CodeT5 CodeGen
  • 预训练没有利用标识符、语法结构等代码特有的信息，只是把代码当普通文本加噪声。
    后来针对它的工作　CodeT5

它建立在什么之上

  • 延续
    BART2019.10 · LLM
    把BART的去噪序列到序列预训练从自然语言搬到代码和自然语言的混合数据上。
  • 改进
    CodeBERT2020.02 · LLM
    CodeBERT只有编码器，生成任务要接随机初始化的解码器；PLBART预训练了完整的编码器—解码器。
  • 竞争
    GraphCodeBERT数据流预训练2020.09 · LLM
    同期的代码预训练模型，GraphCodeBERT加入数据流结构做理解任务，PLBART侧重生成。

读懂它需要的概念

编码器-解码器 自编码器 掩码建模 预训练与微调 文本生成的自动指标

本篇术语

  • 去噪自编码　先把输入弄乱（遮盖、删除、打乱），再训练模型恢复原文，以此学习语言或代码的结构。
  • 代码摘要　给一段代码，自动生成描述其功能的自然语言注释。

怎么学

先读BART的几种噪声函数；读本文第2节数据与预训练设置、第4节代码翻译结果表；动手：用Hugging Face上的PLBART检查点对几个Java函数生成注释，再微调它做Java到C#的翻译。
