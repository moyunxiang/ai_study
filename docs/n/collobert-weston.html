从零开始的神经NLP

Natural Language Processing (Almost) from Scratch
2011论文重要JMLR 2011（arXiv 2011-03）Ronan Collobert, Jason Weston, Léon Bottou, Michael Karlen, Koray Kavukcuoglu, Pavel Kuksa · NEC美国实验室待核对
arXiv ↗SENNA ↗在交互版中打开（演化树、学习进度）

问题

词性标注、组块分析、命名实体识别、语义角色标注各有一套手工设计的特征（词缀、词典、句法树），每个任务都要语言学家调很久，任务之间几乎不共享任何东西。

方法

所有任务共用同一个网络：词查表得到向量→窗口或卷积层→打分输出标签，不用手工特征；词向量先在8.5亿词无标注文本上用“真句子得分高于把中间词换掉的假句子”的排序目标预训练，再拿去初始化各个任务。

影响

第一次系统地证明：用无标注文本预训练的词向量加上一个通用网络，就能在四项标准任务上接近或超过精心设计的专门系统；“先无监督预训练表示、再迁移到下游任务”的路线由此成形，直接影响了word2vec和此后的预训练模型。

背景

2000年代的NLP流水线里，每个任务都是“人工特征+线性分类器”：词性标注看前后缀和大小写，命名实体识别查地名人名词典，语义角色标注要先跑一遍句法分析器再从树上提取几十种特征。在标准基准上，这些系统已经做到很高：词性标注准确率97.24%、组块F1 94.29%、CoNLL-2003命名实体命名实体F1 89.31%、语义角色标注F1 77.92%。但提升主要靠针对单一基准的特征工程，换一个任务几乎要从头再来。

神经概率语言模型已经表明神经语言模型能学出有意义的词向量，可是它要对整个词表做概率归一化，训练极慢，也没人检验这些向量能否用于标注任务。

方法

统一网络。每个词先经查找表变成一个50维左右的向量（外加一个大小写特征的小向量）。对词性、组块、命名实体，用窗口法：把目标词左右各几个词的向量拼起来，过一个隐层，输出该词每个标签的分数。对语义角色标注，需要看整句，所以用句子法：沿句子做一维卷积（与时延神经网络TDNN、LeNet与卷积网络同一思路），再对所有位置取最大值，得到定长向量后打分。标签之间的依赖用一个可学习的转移矩阵在整句上联合解码，训练时用句子级似然，等价于在神经网络特征上做条件随机场。

无标注预训练。不估计概率，而是让一个窗口为11个词的网络给文本片段打分，用成对排序损失训练：

Σ_x Σ_w max(0, 1 − f(x) + f(x^(w)))

其中x是语料里的真实窗口，x^(w)是把中间词换成词表里任意词w后的窗口。真窗口要比假窗口至少高1分。这样不需要对整个词表归一化，罕见但合法的搭配也与高频搭配同等重要。语料是英文维基百科（约6.31亿词），再加路透社RCV1的2.21亿词，共约8.52亿词。

迁移。用预训练得到的词向量初始化各任务网络，再在有标注数据上继续训练；还可以让多个任务共享查找表做多任务学习。

结果

纯监督的网络明显落后：命名实体F1 81.47%、语义角色70.99%。用预训练语言模型LM2的词向量初始化后，分别升到88.67%和74.15%，提升主要来自无标注数据。最终加上少量不依赖专门工程的特征后打包成SENNA系统：词性97.29%、组块94.32%、命名实体89.59%，均略高于对应基准系统；语义角色75.49%，仍低于77.92%。SENNA的语义角色标注器只用124MB内存、51秒跑完测试集，对比系统需要3.4GB和6253秒。代价是预训练很慢：LM1在维基百科上训练约四周，LM2再训练约三周。

后来的发展

它确立了此后几年神经NLP的标准配置：预训练词向量作为输入层，上面接针对任务的窗口网络、卷积或循环网络。词表示用于半监督学习系统比较了它和Brown聚类等词表示作为特征的效果；word2vec把预训练词向量的成本从几周降到不到一天；TextCNN句子分类、神经网络依存分析、BiLSTM-CRF序列标注都直接继承了“查表词向量+简单网络”的做法；排序损失与负样本的思路也出现在Skip-gram负采样和TransE知识图谱嵌入里。

更根本的是“从零开始、少用先验知识、多用无标注数据”的主张：ELMo、GPT-1和BERT把预训练的对象从词向量扩展到整个网络，这条路线一直延续到今天的大模型。

它建立在什么之上

  • 改进
    神经概率语言模型2003.02 · NLP 已核对
    NPLM要对整个词表做softmax归一化、也没检验词向量的用途；这里改用排序损失免去归一化，并证明预训练词向量能提升四项标注任务。
  • 延续
    时延神经网络TDNN1989.03 · 语音
    句子法沿时间轴做一维卷积再取最大值，与时延神经网络在语音上的做法同源，被搬到文本上。
  • 竞争
    Brown聚类1992 · NLP
    同为利用无标注文本得到的词表示；论文直接比较，LM2词向量在命名实体和语义角色标注上优于Brown聚类特征。
  • 使用
    Penn Treebank1993 · 数据·评测
    词性标注用《华尔街日报》树库的标准划分评测，词典也取自WSJ最常见的10万词。
  • 改进
    最大熵模型1996 · NLP
    特征全靠人工设计模板，组合特征需要手写，质量取决于设计者的语言学直觉。
  • 使用
    条件随机场2001 · NLP
    在神经网络打分之上加标签转移矩阵、用句子级似然训练，相当于以神经特征为输入的条件随机场。
  • 改进
    语义角色标注2002 · NLP
    特征和回退结构全凭手工设计，组合方式需要大量实验调整。
  • 改进
    结构化感知机2002.07 · NLP
    特征仍要人工设计成模板（前后词、后缀、标签二元组等），模型本身不学表示，换任务就要重新做特征工程。
  • 使用
    CoNLL-2003命名实体2003.06 · 数据·评测
    命名实体识别在CoNLL-2003英文数据上评测，与当时最好的系统直接对比。
  • 改进
    最大熵词性标注器1996 · NLP
    特征仍要人工设计（词缀、大小写、窗口词），对新语言新领域需要重新做特征工程。

后来的相关工作

  • 改进
    word2vec2013.01 · NLP 已核对
    Collobert-Weston公开的50维词向量（6.6亿词训练）在本文类比测试上总准确率11.0%；300维Skip-gram用7.83亿词、单CPU约三天达到53.3%。
  • 改进
    BERT2018.10 · LLM
    每个词只有一个与上下文无关的向量，多义词无法区分；预训练只覆盖词向量，上层网络仍要从头训练。
  • 改进
    Skip-gram负采样2013.10 · NLP
    Collobert和Weston用“真窗口得分高于替换中间词的假窗口”的排序损失训练词向量；负采样同样用随机替换词作负例，但改成每次只更新少量向量的逻辑回归。
  • 延续
    TransE知识图谱嵌入2013.12 · NLP
    同样用“真样本得分优于随机替换后的假样本至少一个间隔”的排序损失训练嵌入（Weston是两篇的共同作者），这里替换的是三元组的头或尾。
  • 延续
    TextCNN句子分类2014.08 · NLP
    沿用“词向量查表+卷积+对整句取最大值”的结构，从序列标注搬到句子分类，并加入多种窗口宽度和dropout。
  • 使用
    神经网络依存分析2014.10 · NLP
    英文词向量用Collobert等人的预训练嵌入初始化，并继承其“用稠密向量替代人工特征”的思路。
  • 改进
    BPE子词切分2015.08 · NLP
    词表固定为10万到13万个词，表外词一律替换成“RARE”，形态变化和新词没有表示。
  • 改进
    ELMo2018.02 · LLM
    每个词只有一个与上下文无关的向量，多义词无法区分；预训练只覆盖词向量，上层网络仍要从头训练。
  • 延续
    递归神经网络2011.06 · NLP
    同样用神经网络学习词向量表示，但这里加入沿树的递归组合，把词表示变为短语、句子表示。
  • 延续
    全局上下文与多原型词向量2012.07 · NLP
    沿用Collobert和Weston的窗口打分网络和排序损失，加上文档级的全局上下文得分。
  • 延续
    DCNN动态卷积句子模型2014.04 · NLP
    从Collobert等单层卷积+整句最大池化的时间延迟网络出发，改成多层宽卷积和保序的k-max池化。
  • 使用
    ARC卷积文本匹配2014.12 · NLP
    沿用以词向量为输入、在词窗口上做卷积的神经NLP建模方式。
  • 延续
    DMCNN事件抽取2015.07 · NLP
    继承用词向量和卷积自动学习特征、代替人工特征的神经NLP路线。
  • 竞争
    BiLSTM-CRF序列标注2015.08 · NLP
    同样做端到端标注，但Collobert用窗口加卷积、不使用循环结构。
  • 使用
    PCNN远程监督关系抽取2015.09 · NLP
    以词向量加卷积窗口的方式表示句子，沿用了Collobert等的神经NLP做法。
  • 改进
    fastText2016.07 · NLP
    词表固定为10万到13万个词，表外词一律替换成“RARE”，形态变化和新词没有表示。
  • 改进
    深度语义角色标注2017.07 · NLP
    语义角色标注这类需要整句结构的任务仍明显落后于用句法分析特征的系统（75.49%对77.92%）。

读懂它需要的概念

嵌入向量 多层感知机 卷积层、池化与感受野 预训练与微调 准确率、精确率、召回率与F1 损失函数

本篇术语

  • 序列标注　给句子中每个词打一个标签的任务，如词性（名词/动词）、命名实体（人名/地名）或组块边界。
  • 语义角色标注　找出句中每个谓词的论元及其角色，如“谁”对“什么”做了这个动作、在何时何地。
  • 成对排序损失　不要求输出概率，只要求正例得分比负例至少高一个间隔，否则产生损失；免去了对整个词表求和归一化。

怎么学

先补嵌入向量、卷积层、池化与感受野和预训练与微调，读过神经概率语言模型。读原文第3节（窗口与卷积两种结构）、第4节（排序损失与无标注语料）和表4、表8、表15。动手：在CoNLL-2003上实现窗口法命名实体识别，比较随机初始化与用GloVe或word2vec初始化查找表的F1差距。
