Unsloth

2023.12系统延伸Daniel Han, Michael Han · Unsloth AI待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

在单张消费级GPU上微调LLM又慢又吃显存，PyTorch默认实现里有大量可以省去的中间张量搬运和重复计算。

方法

用Triton手写融合内核，并手推反向传播公式，重写注意力、RoPE、交叉熵等关键层，数值上与原实现等价，只是更快更省显存。

影响

成为个人和小团队微调开源模型最常用的工具之一，并扩展到量化发布、桌面应用。

方法

Unsloth的核心是工程而非新算法：把QLoRA微调中的热点算子（RMSNorm、RoPE位置编码、交叉熵、LoRA的前向反向等）用Triton GPU编程语言重写成融合内核，减少显存读写；同时手工推导这些层的梯度，不依赖自动微分生成的通用图。它与HuggingFace生态兼容，用户基本只需换一行导入。

2023年12月在Hacker News发布时的标题是「Llama微调快80%、省50%显存、精度零损失」（这是项目自述的宣传口径，未经本站复测）。

后来的发展

此后它又陆续做了动态量化的GGUF发布和图形界面；GitHub页面现在把自己描述为运行和训练模型的本地界面（Unsloth Studio、Desktop）。

  • 加速依赖对具体模型结构的手写内核，每个新架构都要重新适配，覆盖范围落后于通用框架。
