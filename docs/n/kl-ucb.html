KL-UCB

The KL-UCB Algorithm for Bounded Stochastic Bandits and Beyond
2011.02论文延伸COLT 2011Aurélien Garivier, Olivier Cappé · CNRS, Télécom ParisTech待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

UCB1的置信上界来自Hoeffding不等式，只用到“奖励有界”这一信息，对伯努利等具体分布偏保守，遗憾的常数离Lai–Robbins下界有明显差距。

方法

把置信区间从“均值±√(log t / n)”换成用KL散度定义的区间：在所有与经验均值的KL距离不超过 log t / n 的均值里取最大的一个作为指标。对伯努利奖励，它的遗憾恰好达到Lai–Robbins下界。

影响

成为随机老虎机里“渐近最优又实用”的标准UCB变体，后续许多最优性分析（指数族、MDP中的KL-UCRL等）都沿用这种用KL定义置信区间的写法。

背景

Lai–Robbins遗憾下界证明，任何“一致好”的老虎机算法，拉一个次优臂a的次数至少是 log T / kl(μ_a, μ*)，其中kl是两个奖励分布之间的KL散度。UCB1的指标是 μ̂_a + √(2 log t / n_a)，简单且有有限时间保证，但它的遗憾常数对应的是 1/Δ² 一类的量，而不是 1/kl，在奖励接近0或1时差距尤其大。早年Lai与Robbins、Burnetas与Katehakis给出过渐近最优的指标策略，但缺少有限时间的分析，实现也不统一。

方法

对每个臂a，记被拉次数 N_a(t)、经验均值 μ̂_a。KL-UCB的指标是

U_a(t) = max{ q ∈ [0,1] : N_a(t) · kl(μ̂_a, q) ≤ log t + c·log log t }

其中 kl(p,q) = p log(p/q) + (1−p) log((1−p)/(1−q)) 是伯努利分布间的KL散度，c是一个小常数（理论上取3，实践中常取0）。因为kl关于q单调，这个最大值可以用二分或牛顿法几步算出。每一步选指标最大的臂。直觉是：同样拉了n次，经验均值接近0或1时，真实均值偏离不了多远，KL区间会比Hoeffding区间窄得多；均值在0.5附近时两者接近。

结果

摘要称：对任意有界奖励，KL-UCB的遗憾界一致优于UCB和UCB2；对伯努利奖励，它达到Lai–Robbins下界；简单修改后，对指数族分布等特定类别的（可能无界的）奖励同样最优。大规模数值比较（对照UCB、UCB2、UCB-Tuned、UCB-V、DMED）显示KL-UCB效率高、稳定，短时间范围内也是如此，而且是唯一一个总是优于基本UCB的方法。作为副产品还得到标准UCB的改进遗憾界。

后来的发展

KL置信区间成了老虎机理论的常用工具：同年有关Thompson采样的复兴渐近最优性的分析常以KL-UCB为对照，Thompson采样遗憾分析之后的工作证明Thompson采样在伯努利情形同样达到这一下界。它也被推广到MDP里的乐观探索（KL-UCRL）和纯探索问题中的停止规则。

局限与后续

  • 最优性依赖于知道奖励分布的类型（伯努利、指数族），分布类型设错时只能退回到有界奖励下的较弱保证。

本篇术语

  • 遗憾（regret）　算法累计获得的奖励与“一直选最好那只臂”相比少了多少，衡量探索的代价。
  • 指标策略（index policy）　给每只臂算一个只依赖它自己统计量的分数，每步选分数最高的臂。
