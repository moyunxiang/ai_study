ReFT表示微调

ReFT: Representation Finetuning for Language Models
2024.04论文延伸NeurIPS 2024Zhengxuan Wu, Aryaman Arora, Zheng Wang, Atticus Geiger, Dan Jurafsky, Christopher D. Manning, Christopher Potts · 斯坦福大学、Pr(Ai)²R Group待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

参数高效微调（PEFT）都是改一小部分权重；但可解释性研究表明隐藏表示本身编码了丰富的语义，直接编辑表示也许是更有力的适配方式。

方法

冻结基础模型，只在若干层、若干位置的隐藏表示上学习一个任务相关的“干预”函数；最强的实例LoReFT在一个低秩线性子空间里改写表示。

影响

把可解释性中的“表示干预”变成了一类微调方法，以比LoRA少一到两个数量级的参数取得有竞争力的结果，pyreft库使其易于使用。

方法

ReFT不改权重，而是在前向传播中对选定层、选定token位置的隐藏向量h施加一个可学习的变换Φ(h)。LoReFT的干预形式来自分布式对齐搜索（一种因果可解释性方法）：

Φ(h) = h + Rᵀ(W·h + b − R·h)

其中R是行正交的r×d矩阵（r很小），定义了一个r维子空间；W、b是线性投影。直观地说，它把h在该子空间上的分量替换成W·h + b，子空间外的部分保持不变。另有一个去掉正交约束的消融版本（论文称其以一定性能换取更高效率）。干预通常只加在提示的前几个和后几个token上，推理时不增加生成阶段的计算。

摘要称LoReFT与其高效版本都能直接替换现有PEFT，学到的干预比LoRA参数效率高15到65倍；论文在8个常识推理、4个算术推理任务以及指令微调和GLUE上展示了结果。

局限与后续

  • 需要选择干预的层与位置，组合空间大；在算术推理等任务上不如LoRA稳定。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    LoRA2021.06 · 系统·效率
    LoRA改权重的低秩增量，ReFT改隐藏表示的低秩子空间，参数少15–65倍。
  • 竞争
    Prefix / Prompt Tuning2021.01 · 系统·效率
    同样不改模型权重，Prefix Tuning在输入端加可学习向量，ReFT直接改中间表示。
  • 竞争
    (IA)³2022.05 · 系统·效率
    (IA)³用可学习向量缩放激活，同属作用在表示上的轻量方法。
  • 延续
    激活引导2023.08 · 安全·可解释
    把推理时的表示干预推广为可训练的、任务相关的干预函数。
