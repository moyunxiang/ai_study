卷积Seq2Seq

Convolutional Sequence to Sequence Learning
2017.05论文延伸ICML 2017Gehring, Auli, Grangier, Yarats, Dauphin · Facebook AI Research来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

主流翻译模型是RNN，训练要按词顺序算，GPU并行度低，非线性层数还随句长变化。

方法

编码器和解码器全用卷积，配门控线性单元（GLU）和残差连接，并给解码器每一层配独立的注意力模块。

影响

在WMT’14英德、英法上精度超过谷歌的深层LSTM翻译系统，生成译文的速度快一个数量级；Transformer论文把它作为主要对比对象之一。

方法

输入词向量加上位置嵌入（卷积本身不知道词序），经多层一维卷积；每层卷积输出两倍通道，再用门控卷积语言模型GLU里的GLU门控，并加残差连接。解码器同样是因果卷积，且每层都对编码器输出做一次注意力机制（多步注意力），把已生成词的状态与源句各位置对齐。因为卷积在所有位置并行，训练时整句同时计算，非线性层数固定，与句长无关。层数一多，远处的词也能互相影响：6层、卷积宽度5时每个输出能看到25个输入位置，覆盖n个词只需约O(n/k)次卷积（k为卷积宽度），而RNN需要O(n)步。

结果（表1，单模型取多次平均）：WMT’16英罗BLEU 30.02，此前最好的WMT’16冠军系统28.1；WMT’14英德25.16，比Wu等人的深层LSTM（即谷歌神经机器翻译，词片版）24.61高0.5；WMT’14英法40.51，比GNMT同等的似然训练版本38.95高1.6、也高于其强化学习版的39.92。英法模型用8块GPU训练约37天。生成速度（表3，英法开发集）：在K40 GPU上比GNMT在K80上快9.3倍且BLEU更高，在GTX-1080ti上快21.3倍。

局限与后续

  • 要靠堆很多层才能让相距很远的词互相可见，感受野受层数限制；论文的英法模型有效上下文只有25个词，超出部分完全看不到。作者在原文中指出

它建立在什么之上

  • 使用
    注意力机制2014.09 · NLP 已核对
    保留编码器-解码器之间的注意力（论文第2节以Bahdanau等人的注意力式循环编码器-解码器为背景），但解码器每层各配一个。
  • 改进
    Seq2Seq2014.09 · NLP 已核对
    LSTM必须逐词串行计算，用8块GPU也要训练约10天，难以扩大数据和模型。
  • 改进
    谷歌神经机器翻译2016.09 · NLP 已核对
    以GNMT为主要对比对象：BLEU更高，生成译文速度快一个数量级；英法训练用的GPU时间约为GNMT基本模型的一半（论文脚注）。
  • 使用
    门控卷积语言模型GLU2016.12 · NLP 已核对
    沿用同一团队的门控线性单元作为卷积层的非线性。
  • 改进
    RNN编码器-解码器与GRU2014.06 · NLP
    编码器和解码器都逐词顺序计算，训练难以并行，长句训练和推理都慢。
  • 改进
    ByteNet卷积翻译2016.10 · NLP
    没有注意力，源句信息全靠卷积栈传递，对远距离对齐不灵活。

    Transformer2017.06 · LLM 已核对

怎么学

先读门控卷积语言模型GLU的GLU，再读原文第3节架构图，动手用fairseq跑一个小规模例子。
