Bit Fusion位宽可变加速器

Bit Fusion: Bit-Level Dynamically Composable Architecture for Accelerating Deep Neural Networks
2017.12论文延伸ISCA 2018Hardik Sharma, Jongse Park, Naveen Suda, Liangzhen Lai, Benson Chau, Joon Kyung Kim, Vikas Chandra, Hadi Esmaeilzadeh · 佐治亚理工 / Arm / UCSD等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经网络各层需要的位宽差别很大，有的层2位就够，有的层要8位；固定位宽的加速器要么按最坏情况设计、白白浪费，要么压低位宽、损失精度。

方法

把乘法器拆成一个个2位级的“位处理单元”，运行时按每一层需要的位宽把它们动态拼起来：低位宽时同一块硬件并行做更多次乘法，高位宽时拼成更大的乘法器。

影响

成为“按层可变精度”加速器的代表设计和常见对照，后来各家芯片对INT8/INT4/FP4等多种精度的同时支持，走的是同一个思路。

方法

出发点是一个算法观察：DoReFa-Net低比特训练、XNOR-Net等工作表明，DNN运算的位宽可以大幅降低而不损失分类精度，但每个网络、甚至每一层能承受的位宽都不同。

Bit Fusion的核心是由位级处理单元组成的阵列。每个基本单元只做很窄的乘法；一个8位×8位的乘法可以拆成若干个窄乘法再移位相加。于是当某层只需要2位时，各单元各自独立工作，同一块面积一次完成多次乘法；当某层需要8位时，几个单元“融合”成一个更宽的乘法器。位宽由软件按层设定，计算量和数据搬运量都降到这一层真正需要的程度。

作者用Verilog实现并在45nm工艺下综合，用8个真实的前馈和循环网络评估。摘要报告：在相同面积、频率和工艺下，相对Eyeriss数据流加速器快3.9倍、节能5.1倍；在与Stripes（另一种按位串行计算的变精度加速器）相同的面积和频率下，快2.6倍、能耗降低3.9倍；按16nm工艺推算，性能接近一块使用8位向量指令、功耗250W的Titan Xp，而功耗只有895毫瓦。

局限与后续

  • 只支持整数定点运算，没有覆盖训练所需的浮点和后来流行的FP8/FP4这类低位浮点格式；每层位宽要事先通过量化实验确定。

读懂它需要的概念

量化 矩阵乘法与线性变换 浮点精度：FP32、FP16、BF16、INT8

本篇术语

  • 位宽　一个数用多少个二进制位表示；位宽越小，乘法器越小、搬运的数据越少，但能表示的数值越粗。

怎么学

先读量化，再用纸笔把一个4位×4位乘法拆成四个2位×2位乘法加移位，就能理解“融合”；然后读本文对Eyeriss和Stripes的比较。
