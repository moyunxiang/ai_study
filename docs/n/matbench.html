Matbench

Benchmarking Materials Property Prediction Methods: The Matbench Test Set and Automatminer Reference Algorithm
2020.05数据集延伸Alexander Dunn, Qi Wang, Alex Ganose, Daniel Dopp, Anubhav Jain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

材料性质预测的模型各用各的数据和划分，没法公平比较，也缺少像图像领域那样的标准测试集。

方法

发布一套统一任务的基准Matbench，并给出自动化机器学习参照算法Automatminer。

影响

成为材料机器学习论文常引用的比较基准。

方法

Matbench包含13个监督学习任务，样本数从312到约13.2万，数据来自10个DFT计算或实验来源，涵盖光学、热学、电子、热力学、拉伸和弹性等性质，输入为成分和（或）晶体结构。Automatminer是全自动的流水线，从成分与结构自动生成特征并选模型，无需手动调参，摘要称其与当时最先进的晶体图网络相比在多数任务上有竞争力。

后来的发展

此后新的晶体图网络和预训练模型常在Matbench上报告成绩。
