UniSim

Learning Interactive Real-World Simulators
2023.10论文延伸Yang, Du, Ghasemipour, Tompson, Kaelbling, Schuurmans, Abbeel · Google DeepMind / UC Berkeley / MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

真实世界的交互数据分散在图像、机器人、导航等不同数据集里，没有一个统一的“模拟器”可以响应任意动作。

方法

把不同维度的数据（丰富物体的图像、密集动作的机器人数据、多样运动的导航数据）拼在一起，训练一个生成模型模拟高层指令和低层控制的视觉结果。

影响

提出用生成模型当通用真实世界模拟器，可以在其中训练长程策略和强化学习智能体。

方法

UniSim把“执行动作后画面如何变化”建成一个条件视频生成模型。输入既可以是“打开抽屉”这样的高层指令，也可以是机械臂控制或相机移动这样的低层动作，输出是接下来的画面。作者的关键观察是：不同数据集各自提供经验的不同一面，精心组合后就能覆盖整个交互空间。

摘要列出的用途包括训练长程规划策略和强化学习智能体，且训练好的策略可零样本迁移到真实机器人，也能为视频描述等视觉语言模型生成训练数据。

后来的发展

它是“视频世界模型当模拟器”路线的早期代表，后续有Genie、Cosmos世界基础模型、Genie 3等通用世界模型，以及用视频模型生成机器人训练数据的DreamGen / GR00T Dreams。

局限与后续

  • 生成画面有幻觉，物理一致性和长时稳定性有限，无法替代物理仿真。
    后来针对它的工作　Cosmos世界基础模型 Genie 3
  • 训练代价高，需要海量多源数据。
