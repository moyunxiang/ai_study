Spleeter音乐分离工具

Spleeter: a fast and efficient music source separation tool with pre-trained models
2019.11系统延伸JOSS 2020Romain Hennequin, Anis Khlif, Felix Voituret, Manuel Moussallam · Deezer Research待核对
GitHub ↗JOSS ↗在交互版中打开（演化树、学习进度）

问题

把歌曲拆成人声、鼓、贝斯等音轨的研究模型很多，但很少有开箱即用、速度快、带预训练模型的工具，普通用户和音乐软件用不上。

方法

Deezer开源一个基于TensorFlow的分离库，附带2轨（人声/伴奏）、4轨（人声/鼓/贝斯/其他）、5轨（再加钢琴）预训练模型，命令行一键使用。

影响

速度很快、效果在MUSDB上表现良好，成为最广为使用的音乐分离工具之一（约2.8万星），被多款DJ和音频软件集成，也是音乐分离挑战赛的基线。

方法

Spleeter在频谱上工作：对混合音频做STFT，每个音轨用一个U-Net结构的卷积网络（与U-Net同类的编码器-解码器加跳跃连接）预测该音轨的软掩码，掩码乘上混合频谱后再逆变换得到分离的音轨。模型在Deezer内部的大规模数据上训练，开源时直接提供三种预训练配置：2 stems（人声/伴奏）、4 stems（人声/鼓/贝斯/其他）、5 stems（人声/鼓/贝斯/钢琴/其他）。工具用Python和TensorFlow实现，可在GPU上非常快地处理整首歌曲，因此很快被VirtualDJ等软件用于音轨分离功能，并成为ISMIR 2021音乐分离挑战赛的基线之一。
