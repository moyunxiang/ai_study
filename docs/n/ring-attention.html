Ring Attention序列并行

Ring Attention with Blockwise Transformers for Near-Infinite Context
2023.10论文延伸ICLR 2024Hao Liu, Matei Zaharia, Pieter Abbeel · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自注意力的激活和KV占用随序列长度增长，单卡放不下几十万token以上的上下文。

方法

把序列切给多张卡，每卡只存自己那一段，KV块在环形拓扑上依次传递，边传边用分块注意力计算，使通信被计算掩盖。

影响

让可训练的上下文长度随设备数线性扩展，为百万级上下文训练提供了方法。

方法

基础是FlashAttention用的分块注意力：借助Online Softmax，一个查询可以对键值块逐块累积结果，不必一次放下整个注意力矩阵。Ring Attention把序列均分到N张卡，每卡负责一段查询，并持有一段KV；各卡把自己的KV块发给环上的下一张卡，同时用刚收到的块计算，N轮后每个查询都看到了所有KV。只要每块的计算时间不短于传输时间，通信就完全被隐藏。摘要称可处理的序列长度是此前内存高效Transformer的设备数倍，上下文可达百万token量级，摘要未给具体数字。

局限与后续

  • 要求设备间带宽足够高，才能让通信被计算掩盖；注意力计算量仍是序列长度的平方。
