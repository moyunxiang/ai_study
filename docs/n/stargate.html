Stargate与吉瓦级数据中心

2025.01事件重要2025年1月21日白宫宣布OpenAI · SoftBank · Oracle · MGX（技术伙伴Arm、微软、NVIDIA）来源已核对
OpenAI：Announcing The Stargate Project ↗维基百科：Stargate LLC ↗Crusoe：Abilene数据中心投入使用 ↗在交互版中打开（演化树、学习进度）

问题

OpenAI的算力几乎全靠微软的Azure，而下一代模型需要吉瓦级的专属集群；一家云厂商的建设节奏和资产负债表都不够用。

方法

成立合资公司Stargate：SoftBank负责融资、OpenAI负责运营、Oracle负责建设和运营机房，计划四年在美国投资5000亿美元，首期1000亿，从德州Abilene开始。

影响

OpenAI开始以“吉瓦”为单位规划自己的算力，从云的租户转向主导基础设施建设；此后又扩出多个美国站点、海外项目和以吉瓦计的芯片协议。

背景

OpenAI一直在微软为它建的超算上训练模型（微软为OpenAI建的超算），微软长期是它唯一的大规模云供应商。到2024年，OpenAI的训练和服务需求增长很快，单靠微软一家供应算力越来越难；而对手xAI用122天在孟菲斯建成10万卡集群（xAI Colossus：122天建成10万卡集群），说明自建大集群可以很快。

同时，Blackwell与整机柜液冷的整机柜液冷设计让每个机柜功率达到上百千瓦，一个容纳数十万块GPU的园区就需要吉瓦级供电（见数据中心的功率、散热与能耗；据DCD，Abilene八栋楼合计约1.2GW）。这种规模的电力、土地和资金，需要专门的公司来组织。

方法

据OpenAI公告：Stargate是一家新公司，计划未来四年在美国为OpenAI投资5000亿美元建设AI基础设施，立即部署1000亿。初始股东为SoftBank、OpenAI、Oracle和MGX；SoftBank承担财务责任，OpenAI承担运营责任，孙正义任董事长。Arm、微软、NVIDIA、Oracle和OpenAI是技术伙伴，Oracle、NVIDIA与OpenAI共同建设和运营计算系统。OpenAI同时继续增加对Azure的使用；据维基百科，双方合作条款同时调整为微软对OpenAI未来的云算力需求享有优先承接权，微软不接时OpenAI可找其他供应商。

分工可以理解为三层：钱（SoftBank和MGX的股权，加上银行贷款）、楼和电（Oracle以及Crusoe等开发商）、芯片和模型（NVIDIA供货，OpenAI使用）。首个园区位于德州Abilene：据Crusoe，园区2024年6月动工，一年内前两栋楼通电，Oracle从2025年6月开始交付NVIDIA GB200机柜；建成后八栋楼可在单一网络上容纳数十万块GPU，楼体同时支持液冷和风冷。

结果

宣布之初就有质疑：马斯克称该项目没有足够资金，Altman予以否认；据维基百科引用彭博，2025年8月报道称项目尚未筹到满足5000亿预算的资金。此后计划仍在扩张：2025年7月OpenAI与Oracle签下4.5GW的合作；9月新增德州、新墨西哥、俄亥俄等五个站点（Stargate扩至约7GW），官方称规划容量接近7GW、未来三年投资超过4000亿美元，有望在年内锁定10GW、5000亿的目标。海外有阿联酋的Stargate UAE（主权AI：Stargate UAE）。

落地并非一路顺利：2026年3月据彭博与路透，Oracle和OpenAI放弃了Abilene旗舰园区的进一步扩建（DCD称原计划从约1.2GW扩到2GW，受融资和OpenAI需求预测多变影响）；OpenAI称把这部分容量放到其他站点，Oracle则对报道提出异议，另有报道称更大的4.5GW协议仍在推进。

后来的发展

Stargate之后，Meta（Meta Prometheus与Hyperion）、微软（Microsoft Fairwater）、xAI（Colossus 2吉瓦级集群）也陆续公布吉瓦级园区，这也是云厂商资本开支竞赛的一部分。2025年9–10月，OpenAI又先后与NVIDIA（至少10GW意向书）、AMD（6GW）、博通（10GW自研加速器）签下以吉瓦计的芯片协议（OpenAI–Broadcom 10GW芯片、循环融资：芯片商与OpenAI），资金在芯片商和AI公司之间循环。电力成了新的硬约束，现场燃气发电（电网排队与现场燃气发电）是应对办法之一。

容易误解的地方

  • 5000亿美元是四年的计划总额，不是已到位的资金；股权、贷款和合作方自有投资混在一起统计。
  • “Stargate”既指这家合资公司，也被用作OpenAI所有大型算力项目的品牌，海外项目和合作方自建的站点并不都由合资公司出资。

局限与后续

  • 资金并未到位：5000亿主要是承诺和计划，依赖SoftBank举债和外部融资，市场一旦转冷就可能缩水。

读懂它需要的概念

数据中心的功率、散热与能耗 分布式训练：数据并行与模型并行 互连：从芯片到机柜到集群 芯片供应链：设计、代工、封装、内存

本篇术语

  • 吉瓦（GW）　功率单位，1GW＝100万千瓦。AI园区用它表示能供多少电，进而决定能装多少GPU。
  • MGX　阿联酋阿布扎比的AI投资公司，Stargate的初始股东之一。

怎么学

先补数据中心的功率、散热与能耗，粗算一个液冷机柜和一个吉瓦园区分别能装多少GPU。然后读OpenAI的公告原文，注意它如何划分财务、运营和技术责任；再读Crusoe关于Abilene的新闻稿，看一个园区实际的建设节奏。最后按时间读Stargate扩至约7GW、循环融资：芯片商与OpenAI和电网排队与现场燃气发电。
