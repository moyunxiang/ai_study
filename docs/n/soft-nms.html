Soft-NMS软抑制

Soft-NMS -- Improving Object Detection With One Line of Code
2017.04论文延伸ICCV 2017Navaneeth Bodla, Bharat Singh, Rama Chellappa, Larry S. Davis · 马里兰大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

传统NMS把与最高分框重叠超过阈值的框直接删掉，两个物体靠得很近时，真实的第二个物体也被误删。

方法

不删除，而是按与最高分框的重叠程度降低其余框的分数（线性或高斯衰减），重叠越大降得越多。

影响

只改一行代码、无需重新训练，就在PASCAL VOC和COCO上给Faster R-CNN、R-FCN等检测器稳定涨点。

方法

检测器会在同一个物体周围输出很多重叠的框，非极大值抑制（NMS）负责去重：按分数排序，取最高分框，把与它IoU超过阈值（如0.5）的框全部删掉，再重复。问题是阈值很难定：两个人并排站、两辆车相互遮挡时，第二个物体的框与第一个框IoU可能超过阈值而被删，造成漏检；阈值调高又会留下很多重复框。

Soft-NMS把“删除”改成“降分”。对剩余的每个框bᵢ，若与当前最高分框M重叠，就把分数sᵢ乘上一个随重叠增大而减小的系数：线性版是 sᵢ ← sᵢ(1 − IoU(M, bᵢ))（仅在IoU超过阈值时），高斯版是 sᵢ ← sᵢ·exp(−IoU(M, bᵢ)²/σ)。真正的重复框分数会被压得很低、最终被分数阈值过滤；而与M部分重叠的另一个物体只被降一点，仍能保留下来。

标题强调这是“一行代码”的改动：不需要重新训练，计算复杂度与原NMS相同。摘要报告只换掉NMS，COCO式mAP在PASCAL VOC 2007上对R-FCN检测和Faster R-CNN都提高1.7%，在MS COCO上分别提高1.3%和1.1%；配合Deformable-RFCN，单模型最好结果从39.8%提高到40.9%。
