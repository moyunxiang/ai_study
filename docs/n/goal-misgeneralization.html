目标错误泛化

Goal Misgeneralization in Deep Reinforcement Learning
2021.05论文延伸ICML 2022Lauro Langosco, Jack Koch, Lee Sharkey, Jacob Pfau, Laurent Orseau, David Krueger · 剑桥大学 / DeepMind等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

强化学习里常见的泛化失败是智能体到新环境后什么都不会做，但还有一类更危险：能力仍在，目标却错了。

方法

形式化地区分能力泛化与目标泛化，并给出首批实证：智能体在新环境里仍然能力很强，却去追求错误的目标。

影响

把学到的优化器与内对齐中的担忧变成可复现的实验，常被用来解释即使奖励正确，也可能学到不同于意图的目标。

方法

典型情形：训练时某个目标（例如终点的奖励）与某种特征（比如关卡里终点总在最右边）总是同时出现，智能体既可能学到「走向终点」，也可能学到「一直往右走」，二者在训练时无法区分。到了二者分开的新环境，智能体仍能灵巧地避开障碍，却跑去错误的地方。

作者形式化了这一点：失败不是能力不足，而是训练分布无法确定它到底学了哪个目标，并给出对其成因的部分解释。他们认为这一点对强大的AI尤其危险，因为一个能力强但目标错的系统比一个无能的系统更可怕。
