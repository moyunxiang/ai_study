XLNet

XLNet: Generalized Autoregressive Pretraining for Language Understanding
2019.06论文延伸NeurIPS 2019Zhilin Yang, Zihang Dai, Yiming Yang, Jaime Carbonell, Ruslan Salakhutdinov, Quoc V. Le · 卡内基梅隆大学 / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BERT预训练时用特殊遮罩符号，但微调时不出现；并且被遮的词之间被当作相互独立，忽略了它们的依赖。

方法

保持自回归的形式，但随机打乱预测顺序：对同一句话取多种排列，按排列顺序逐个预测，这样每个词在不同排列里能看到左右两边的上下文。

影响

在20个任务上超过BERT，让人认真比较「自回归」与「自编码」两种预训练路线，但后来被更大数据下的RoBERTa式训练追平。

方法

BERT属于去噪自编码：遮掉15%的词再一次性预测，两个缺点是预训练输入含有[MASK]而微调时没有，二是同时被遮的词相互独立地预测。纯自回归（如GPT）没有这两个问题，但只能看左边。

XLNet提出排列语言建模：对序列的所有可能的预测顺序求期望似然，例如句子「我 爱 北京」可以按「北京→我→爱」的顺序预测，预测「我」时已能看到右边的「北京」。实际并不真的打乱输入，而是通过注意力掩码实现不同的顺序。为了让模型知道此刻要预测哪个位置，又加入「双流注意力」：一路带着内容、一路只带位置。

它还把Transformer-XL的片段循环和相对位置编码带入预训练。摘要称在相近设置下，XLNet在20个任务上超过BERT，涵盖问答、自然语言推断、情感分析和文档排序。

局限与后续

  • 排列带来的训练目标更难优化，并需要双流注意力，实现复杂、训练代价大。
    后来针对它的工作　RoBERTa
  • 后来的对比表明，BERT式模型靠更多数据和更久的训练就能追平其优势。
    后来针对它的工作　RoBERTa

后来的相关工作

  • 竞争
    RoBERTa2019.07 · LLM 已核对
    XLNet把提升归于新的排列语言模型目标；RoBERTa在可比数据下用原版MLM追平它，说明数据与训练量是主因。
  • 竞争
    ELECTRA替换词检测2020.03 · LLM
    XLNet用排列语言建模消除[MASK]不一致；ELECTRA用替换词检测，算力更少而分数相当或更高。
  • 竞争
    GLM空白填充2021.03 · LLM
    同属把自回归与双向上下文合在一起的尝试，XLNet用排列顺序，GLM用片段填空。

读懂它需要的概念

掩码建模 自回归生成 自注意力与多头注意力 预训练与微调 位置编码

本篇术语

  • 排列语言建模　对一句话的词序取不同的随机排列，按排列顺序做自回归预测，使每个词在期望上看到左右两侧上下文。

怎么学

先弄清掩码建模和自回归生成；读原文第2节的排列语言建模和双流注意力图；不必实现，能讲清为什么不用[MASK]就够。
