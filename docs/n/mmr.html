MMR最大边际相关

The use of MMR, diversity-based reranking for reordering documents and producing summaries
1998.08论文重要SIGIR 1998Jaime Carbonell, Jade Goldstein · 卡内基梅隆大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

按相关度排序时，排在前面的往往是彼此高度重复的文档或句子；用户看了第一条之后，后面几条几乎不提供新信息，多文档摘要更是会把同一件事说好几遍。

方法

贪心地一个一个选：每次选的不是最相关的那个，而是「与查询相关度高、同时与已选内容最不相似」的那个，用一个参数λ在相关和新颖之间权衡。

影响

MMR成为结果多样化和抽取式摘要去冗余的标准做法，在多文档摘要评测中明显优于不去冗余的选择；今天的检索增强生成（RAG）框架里仍内置MMR检索选项。

背景

经典检索（向量空间模型、BM25）独立地给每篇文档打分，再按分数排序，相当于假设一篇文档是否有用与其他文档无关。但对用户来说，第二篇与第一篇几乎相同时价值很低。自动文摘从Luhn自动文摘起就按重要性挑句子，同样会挑出意思重复的句子；到了多文档摘要（把几十篇报道同一事件的新闻合成一段摘要），这个问题尤其严重。

方法

设R是候选集合（如检索出的前若干文档或候选句子），S是已经选出的集合，Q是查询。每一步从未选的候选中挑出：

MMR = argmax_{D_i ∈ R \ S} [ λ · Sim₁(D_i, Q) − (1 − λ) · max_{D_j ∈ S} Sim₂(D_i, D_j) ]

第一项是与查询的相关度，第二项是它与已选内容中最相似者的相似度（相似度越高越冗余，因此减去）。Sim₁和Sim₂可以是同一种相似度，例如TF-IDF向量的余弦。λ = 1时退化为普通相关度排序，λ = 0时只追求与已选内容不同；论文建议先用较小的λ探索话题的不同方面，再用较大的λ聚焦。

例：查询「美洲豹」，前三篇检索结果都在讲某款汽车。用λ = 0.5的MMR，选出第一篇汽车文章后，第二篇汽车文章因为与它高度相似被扣分，一篇讲动物的文章可能排到第二位。

用于摘要时，把文档切成句子或段落作为候选，用MMR选出若干条，再按原文顺序拼成摘要。

结果

摘要称：在文档检索和单文档摘要上看到一定好处，并得到SUMMAC摘要评测结果的佐证；优势最明显的是构造不冗余的多文档摘要，MMR明显优于不使用MMR的段落选择。

后来的发展

MMR是之后十多年多文档摘要系统（包括DUC评测中的许多系统）的标准组件，也是检索结果多样化研究（如xQuAD、IA-Select等基于子话题的方法）的出发点。在推荐系统里它用于提高推荐列表的多样性，在RAG中用于避免把一堆内容重复的段落塞进上下文窗口。

局限与后续

  • 贪心选择不保证整体最优，λ需要按任务手工设定。

它建立在什么之上

  • 使用
    IDF与TF-IDF1972.01 · NLP
    相似度通常在TF-IDF加权的词向量上计算。
  • 使用
    向量空间模型1975.11 · NLP
    相关度和冗余度都可以用向量空间中的余弦相似度计算。
  • 改进
    Luhn自动文摘1958.04 · NLP
    按重要性独立挑句子会产生重复，MMR在挑选时显式惩罚与已选句子的相似度。

本篇术语

  • 边际相关　一个候选在已选内容之外还能额外带来的有用信息，而不是它单独看有多相关。
  • 多文档摘要　把多篇讲同一主题的文档合成一段摘要，需要避免重复并覆盖不同要点。

怎么学

先懂向量空间模型的余弦相似度 → 读原文第2节MMR公式与第3–4节检索和摘要的用法 → 动手：对一组新闻句子用TF-IDF余弦实现MMR，观察λ从1降到0.3时所选句子的变化。
