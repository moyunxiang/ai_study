流形学习Isomap/LLE

A Global Geometric Framework for Nonlinear Dimensionality Reduction
2000.12论文延伸Science 2000Tenenbaum, de Silva, Langford（Isomap）；Roweis, Saul（LLE） · Stanford / CMU / MIT 等待核对
DOI（Isomap） ↗在交互版中打开（演化树、学习进度）

问题

主成分分析PCA只能找线性子空间，而图像、人脸、手写体等数据常常分布在高维空间里弯曲的低维曲面上，线性降维会把它压坏。

方法

用邻居之间的局部距离重建数据的全局几何：Isomap用测地距离（沿数据曲面走的距离），LLE用每个点由邻居线性重建的权重，来找低维坐标。

影响

让“高维数据其实位于低维流形上”成为深度学习前夜最重要的直觉之一，t-SNE、自编码器和表示学习都沿用了这个观点。

方法

两篇2000年12月同期发表在Science上的论文提出不同的算法，思想一致。

Isomap：对每个点连上它的k个最近邻，构成邻接图，边长为欧氏距离；两点间的“测地距离”用图上的最短路径近似，因为沿着曲面走和直线穿过空间是不同的；然后对测地距离矩阵做经典多维标度（MDS，类似PCA），得到低维坐标。例子是“瑞士卷”：卷起的平面上相邻圈在欧氏距离上很近，沿面走却很远，Isomap能把它展开。

LLE（局部线性嵌入）：先让每个点由它的邻居的线性组合重建，求出权重；然后找低维坐标，使每个点仍然被相同权重的邻居重建，转化为一个特征值问题。

两者都是无监督、非线性、基于邻居图的降维方法。

局限与后续

  • 依赖邻居图：邻居数k难选，噪声或数据稀疏时容易短路（连上不该连的点），整个几何就坏了。
    后来针对它的工作　t-SNE
  • 没有显式的映射函数，新样本的坐标要重新算；而且是针对一批点做一次性的优化，无法与神经网络端到端结合。
    后来针对它的工作　深度自编码器

读懂它需要的概念

本篇术语

  • 流形　局部看起来像低维平坦空间的曲面，如球面局部像平面；流形假设说高维数据其实聚集在这样的低维曲面附近。

怎么学

先复习主成分分析PCA，再读Isomap论文的图1和算法描述。动手：用sklearn对瑞士卷数据集分别跑PCA、Isomap、LLE并比较二维结果。
