ICL即预条件梯度下降

Transformers learn to implement preconditioned gradient descent for in-context learning
2023.06论文延伸NeurIPS 2023Kwangjun Ahn, Xiang Cheng, Hadi Daneshmand, Suvrit Sra · MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

此前工作手工构造了权重，证明Transformer“能够”在上下文里模拟梯度下降；但训练出来的Transformer“会不会”真的学成这种算法，没有理论回答。

方法

分析在随机线性回归任务上训练的线性Transformer的损失景观，证明单层注意力的全局最优解恰好实现一步预条件梯度下降，L层时某些临界点实现L步预条件梯度下降。

影响

把“ICL即梯度下降”从表达能力的构造推进到训练结果的刻画，并指出学到的预条件矩阵会适应输入分布和样本不足带来的方差，是这一理论方向的常引结果。

方法

背景：ICL即梯度下降和ICL学的是什么算法显示，在线性回归的上下文示例上，精心设定的Transformer权重可以执行一步或多步梯度下降，训练出来的模型行为也与梯度下降相近。但“存在这样的权重”和“训练会找到这样的权重”是两回事。

设定：每条提示含n个示例 (x_i, y_i)，y_i = wᵀx_i，其中w对每条提示随机抽取，最后给一个查询x要求预测y。模型是去掉softmax的线性自注意力，在大量随机任务上最小化预测误差。

结论：

  • 单层：作者证明训练目标的全局最小值对应的预测恰好是从w=0出发做一步预条件梯度下降，即 ŷ = xᵀ · A · (1/n) Σ_i y_i x_i，其中A是学出来的预条件矩阵。普通梯度下降相当于A取单位阵的倍数；而最优A会根据输入x的协方差调整各方向的步长，还会考虑“只有n个样本”带来的估计方差，相当于做了带收缩的修正。
  • L层：对L层线性Transformer，作者证明目标函数的某些临界点对应L步预条件梯度下降，每一层执行一步迭代。

这些结果说明，即使不手工设计，梯度训练也会把注意力层推向一种可解释的优化算法；同时也提醒这种对应依赖于线性注意力和线性回归这一特定设定。

后来的发展

与同期分析单层线性注意力训练动态的工作一起，构成“训练出来的Transformer在上下文里做什么算法”这一理论分支的基础，后续研究把它推广到softmax注意力、非线性任务和多步迭代。

局限与后续

  • 只分析去掉softmax的线性注意力和线性回归任务；对真实LLM里的softmax注意力和自然语言数据，结论是否成立无法直接推出。

读懂它需要的概念

上下文学习与提示 线性回归 梯度下降 自注意力与多头注意力 损失曲面、局部极小与鞍点 协方差矩阵

本篇术语

  • 预条件梯度下降　梯度下降时先用一个矩阵A去乘梯度再更新，相当于在不同方向用不同步长，能在输入各方向尺度不同时收敛得更快。
  • 线性自注意力　去掉softmax、直接用查询和键的内积作为权重的注意力，数学上更容易分析。

怎么学

先复习线性回归的梯度和ICL即梯度下降的构造；读本文第3节单层结论与预条件矩阵的形式；动手：用PyTorch训练一层线性注意力做随机线性回归ICL，取出学到的权重，与一步预条件梯度下降的预测逐点比较。
