Katz回退语言模型

Estimation of Probabilities from Sparse Data for the Language Model Component of a Speech Recognizer
1987.03论文延伸IEEE Trans. ASSP 1987Slava M. Katz · IBM T. J. Watson Research Center待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

三元语言模型里绝大多数词组合在训练数据中从未出现，直接按频率估计会给它们概率0，识别器就永远不会输出这些词序列。

方法

对见过的n-gram把概率打折腾出一部分，再把腾出的概率按低一阶的模型分配给没见过的n-gram，必要时一路回退。

影响

它是n-gram平滑中影响最大的方法之一，几乎所有传统语音识别器的语言模型都使用回退结构。

背景

IBM Tangora听写机等系统用三元模型（见n-gram与平滑），词表上万时可能的三元组数量远超任何训练语料。零概率意味着只要测试句里有一个没见过的组合，整句概率就是0。

方法

Katz的做法是先对已出现n-gram的频次做Good-Turing折扣，让出现次数少的组合的概率略微下调，空出一块「未见事件」的概率质量。对一个历史h和词w：

P(w|h) = d·c(h,w)/c(h)，若c(h,w) > 0 P(w|h) = α(h)·P(w|h')，若c(h,w) = 0

其中h'是去掉最早一个词的较短历史，α(h)是使概率总和等于1的回退权重。例如没见过「吃 苹果 派」，就改用二元的「苹果 派」的概率，再按α缩放。这样既尊重见过的数据，又让没见过的组合获得合理的非零概率。

后来的发展

后来的Kneser-Ney等平滑方法在回退思想上改进了低阶分布的估计，见n-gram平滑；2010年起神经语言模型如RNN语言模型直接用连续表示避开稀疏问题。

局限与后续

  • 回退时低阶分布仅按词频估计，没有考虑某词常出现在多种上下文里还是只在固定搭配里。
    后来针对它的工作　n-gram平滑
  • n-gram只看固定几个词，无法利用相似词之间的泛化，也不能记住长距离依赖。
    后来针对它的工作　RNN语言模型

它建立在什么之上

  • 改进
    香农：语言的统计模型1948 · NLP
    继承香农用n-gram统计建模语言的思路，并解决其在稀疏数据上的概率估计问题。
  • 改进
    ARPA语音理解计划1971 · 语音
    达标系统依赖人工写死的受限语法，句子必须落在预先设计的句式里，换任务就要重写知识。
  • 使用
    HMM统计语音识别1976 · 语音
    为噪声信道框架里的语言模型部分P(W)提供可靠估计。
  • 改进
    Harpy1976 · 语音
    只接受人工设计的受限语法内的句子，换任务就要重写语法和网络。

后来的相关工作

  • 竞争
    Brown聚类1992 · NLP
    回退平滑靠缩短上下文对付稀疏；类模型靠在相似词之间共享统计对付稀疏，两者后来常插值结合。
  • 改进
    Kneser-Ney平滑1995.05 · NLP
    保留回退结构，但把Katz按词频估计的回退分布换成按接续计数估计，并用绝对折扣代替Good-Turing折扣。
  • 使用
    语义角色标注2002 · NLP
    组合多种条件分布时借用了语言模型中的回退与线性插值思想。
  • 使用
    WFST解码器2002.01 · 语音
    实验中的三元文法用Katz回退构建，回退路径在G中表示为ε边。
  • 改进
    RNN语言模型2010.09 · NLP
    n-gram只看固定几个词，无法利用相似词之间的泛化，也不能记住长距离依赖。
  • 改进
    n-gram平滑1996 · NLP
    回退时低阶分布仅按词频估计，没有考虑某词常出现在多种上下文里还是只在固定搭配里。

读懂它需要的概念

n-gram与平滑 语言模型 困惑度 随机变量与概率分布

怎么学

用一个小语料手算二元模型的Katz回退：先统计频次，再算折扣与α，验证概率之和为1。
