LigandMPNN

Atomic context-conditioned protein sequence design using LigandMPNN
2025.03论文延伸Nature Methods 2025Dauparas, Lee, Pecoraro, An, Anishchenko, Glasscock, Baker待核对
Nature Methods ↗在交互版中打开（演化树、学习进度）

问题

ProteinMPNN等序列设计方法看不到小分子、核酸和金属原子，而酶和结合蛋白的设计恰恰要围绕这些原子。

方法

在ProteinMPNN式的消息传递网络中显式加入所有非蛋白原子，并同时输出氨基酸序列和侧链构象。

影响

在与小分子、核酸、金属相互作用的残基上，天然序列恢复率明显高于Rosetta和ProteinMPNN。

方法

LigandMPNN保持ProteinMPNN的思路——给定骨架，预测每个位置的氨基酸——但把小分子、核酸、金属等非蛋白原子也作为图中的节点，让每个残基能看到它周围的配体环境；除序列外还生成侧链构象，以便细致评估结合相互作用。

摘要给出的数字：在天然骨架上恢复与小分子、核酸、金属相互作用的残基时，序列恢复率分别为63.3%、50.5%、77.5%，而Rosetta为50.4%、35.2%、36.0%，ProteinMPNN为50.5%、34.0%、40.6%。该方法已被用于设计100多个经实验验证的小分子和DNA结合蛋白，并把部分Rosetta设计的结合亲和力提高了最多100倍。

后来的发展

成为含配体设计流程里常见的序列设计步骤，与RoseTTAFold All-Atom这类生成骨架的方法搭配使用。
