Open-Unmix参考实现

Open-Unmix - A Reference Implementation for Music Source Separation
2019.09系统延伸JOSS 2019Fabian-Robert Stöter, Stefan Uhlich, Antoine Liutkus, Yuki Mitsufuji · Inria、Sony待核对
GitHub ↗JOSS ↗在交互版中打开（演化树、学习进度）

问题

音乐源分离领域缺少一个公开、可复现、性能有竞争力的参考实现，各家方法很难公平比较。

方法

由SiSEC/SigSep社区维护一个开源参考模型：对每个音轨用三层双向LSTM从混合幅度谱预测目标幅度谱，配齐数据、评测和后处理工具。

影响

成为音乐分离研究的标准基线之一，与MUSDB18数据集、museval评测工具共同构成该领域的开放实验基础。

方法

Open-Unmix为每个目标音轨（人声、鼓、贝斯、其他）各训练一个模型。输入是混合音频的幅度谱，先做归一化，再用一层全连接把频率和通道维压缩，降低冗余、加快收敛；核心是三层双向LSTM，因为是循环结构，可以处理任意长度的音频，并利用前后文信息；输出经全连接层恢复到原频率分辨率，形成对目标幅度谱的估计（实际作为掩码作用在混合谱上）。几个音轨的估计结果再用多通道维纳滤波联合后处理，得到相位一致的分离波形。项目提供PyTorch实现、预训练模型，并与MUSDB18数据集和museval评测工具配套。
