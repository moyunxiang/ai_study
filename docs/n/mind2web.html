Mind2Web

Mind2Web: Towards a Generalist Agent for the Web
2023.06数据集延伸NeurIPS 2023Deng, Gu, Zheng, Chen, Stevens, Wang, Sun, Su · 俄亥俄州立大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

此前的网页智能体数据集多是模拟网站或少数几个站点上的简单任务，无法检验智能体在任意真实网站上是否通用。

方法

在大量真实网站上众包记录人类完成任务的操作轨迹，并按「新任务/新网站/新领域」划分测试集来检验泛化。

影响

成为网页智能体最常用的静态数据集，并带动了后续在线环境如WebArena。

方法

WebGPT之类的工作让模型在特定搜索环境里浏览网页，但缺少覆盖真实网站的统一数据。Mind2Web收集了跨多个领域的真实网站，由标注者按语言指令完成任务，保存每一步的网页快照和操作（点击、输入、选择）。

网页的HTML往往很长，直接放进大语言模型的上下文不现实，所以论文提出先用小模型对页面元素排序、挑出候选元素，再让大语言模型从中选择并给出操作。测试集分为三种泛化程度：新任务、同一网站的新任务之外的新网站、完全新领域的网站。

它是静态评测：只比对模型每一步是否选对了元素，不会真的执行并检查任务最终是否完成，这也是之后WebArena改用可执行环境的原因。

局限与后续

  • 评测是静态的，只看单步动作是否与人类轨迹一致，不判断任务是否真正完成，也不允许走不同但同样正确的路径。

  • 网页HTML过长，需要先做元素筛选，这在端到端智能体里是额外的瓶颈。

  • 延续
    WebGPT2021.12 · 推理·智能体
    把网页操作从搜索问答环境推广到各种真实网站上的通用任务。
  • 改进
    WebShop2022.07 · 数据·评测
    环境只有购物这一类网站，站点是静态模拟的，不能代表真实网站的多样性和动态变化。
