LIBLINEAR线性分类库

LIBLINEAR: A Library for Large Linear Classification
2008.08系统延伸JMLR 2008Rong-En Fan, Kai-Wei Chang, Cho-Jui Hsieh, Xiang-Rui Wang, Chih-Jen Lin · 台湾大学待核对
JMLR ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

文本分类这类数据样本几十万、特征上百万但极其稀疏，通用的核SVM求解器（如LIBSVM）训练要几个小时。

方法

放弃核函数，只解线性模型：对线性SVM用对偶坐标下降，对逻辑回归用信赖域牛顿法，并沿用LIBSVM的易用接口。

影响

成为大规模稀疏线性分类的标准工具，scikit-learn的线性SVM与一种逻辑回归求解器直接封装了它。

方法

LIBSVM让核支持向量机变得人人可用，但核方法的训练代价随样本数大致呈平方以上增长。作者观察到，对文本这类特征维度本来就很高的稀疏数据，线性分类器的精度往往与核方法差不多，却可以快几个数量级——前提是有专门为线性情形设计的求解器。

LIBLINEAR统一求解min_w ½wᵀw + C·Σ ξ(w; x_i, y_i)，其中损失ξ可以是合页损失max(1 − y·wᵀx, 0)（L1-SVM）、它的平方（L2-SVM），或逻辑回归的log(1 + e^(−y·wᵀx))。两种SVM用对偶坐标下降求解：每次只更新一个样本对应的对偶变量，开销与该样本的非零特征数成正比；逻辑回归和L2-SVM还可以用信赖域牛顿法。偏置项通过给每个样本补一维常数来处理；多分类用一对其余或Crammer–Singer方法。接口和数据格式刻意与LIBSVM保持一致。

论文给的例子：在超过60万样本的rcv1文本分类上训练只要几秒，而LIBSVM这样的通用SVM求解器要几个小时；在特征超过一百万的news20上，训练（不计磁盘读写）不到一秒。
