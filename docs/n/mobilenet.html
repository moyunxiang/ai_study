MobileNet

MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications
2017.04论文延伸Howard, Zhu, Chen, Kalenichenko, Wang, Weyand, Andreetto, Adam · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

ResNet、VGG这类网络参数和计算量太大，手机和嵌入式设备跑不动。

方法

把标准卷积拆成逐通道的深度卷积加1×1逐点卷积（深度可分离卷积），并用宽度与分辨率两个超参数按需缩小网络。

影响

成为移动端视觉模型的基线，后续一整个轻量网络家族（V2、ShuffleNet、EfficientNet）都以它为起点。

方法

标准卷积对每个输出通道都要和所有输入通道做空间滤波，计算量约为D_K²·M·N·D_F²（核边长、输入通道、输出通道、特征图边长）。MobileNet把它拆成两步：深度卷积对每个输入通道单独做一次3×3滤波，再用1×1的逐点卷积把通道混合起来。两步合起来的计算量约是原来的1/N + 1/D_K²，3×3核时大约少一个数量级。

另外引入宽度乘子（整体缩小每层通道数）和分辨率乘子（缩小输入图像），让使用者在延迟和准确率之间按设备预算选一个点。Xception已经用过类似的可分离卷积，MobileNet的贡献是把它做成完整的、面向速度的整网和可调节的家族。

局限与后续

  • 深度卷积在当时的硬件上实际速度不如理论计算量所暗示的那么快，计算量少不等于延迟低。
    后来针对它的工作　MnasNet硬件感知NAS
  • 网络是人工设计的，宽度与分辨率两个旋钮只是粗调，没有系统地搜索最优结构。
    后来针对它的工作　EfficientNet

它建立在什么之上

  • 竞争
    ResNet2015.12 · 视觉 已核对
    ResNet靠堆深度和宽度换精度，MobileNet在小算力预算下重新设计基本算子。
  • 改进
    VGG2014.09 · 视觉
    参数约1.38亿，大部分在三个全连接层，模型文件超过500MB，推理计算量大，难以部署到手机。
  • 改进
    低秩分解加速卷积2014.04 · 系统·效率
    只在已训练的模型上逐层近似，加速仅约2倍，误差会在层间累积。
  • 改进
    Inception v32015.12 · 视觉
    对移动端仍偏重。
  • 使用
    Xception2016.10 · 视觉
    采用Xception同类的深度可分离卷积作为核心算子。
  • 改进
    ResNeXt2016.11 · 视觉
    分组卷积在硬件上实现效率不如密集卷积。

后来的相关工作

  • 使用
    Conformer2020.05 · 语音 待核对
    卷积模块用逐点卷积加深度卷积（即MobileNet推广的深度可分离卷积），以很少参数获得较长的局部感受野；论文本身没有引用MobileNet。
  • 使用
    量化感知训练与整数推理2017.12 · 系统·效率
    以本已高效的MobileNet作为主要量化对象，证明在精简模型上量化仍能改善延迟—精度折中。
  • 使用
    Core ML2017.06 · 系统·效率
    MobileNet这类轻量网络是它在手机上的典型负载。
  • 竞争
    ShuffleNet2017.07 · 视觉
    同样追求移动端效率，但在1×1卷积上也做分组，并用通道重排补偿信息隔离。
  • 使用
    TensorFlow Lite2017.11 · 系统·效率
    以MobileNet作为典型端侧模型。
  • 延续
    MobileNetV22018.01 · 视觉
    沿用深度可分离卷积，并加入倒残差与线性瓶颈。
  • 改进
    MnasNet硬件感知NAS2018.07 · 系统·效率
    MobileNet靠人工设计，MnasNet用搜索在同等延迟下找到更高精度的结构。
  • 改进
    EfficientNet2019.05 · 视觉
    网络是人工设计的，宽度与分辨率两个旋钮只是粗调，没有系统地搜索最优结构。
