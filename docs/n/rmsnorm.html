RMSNorm

Root Mean Square Layer Normalization
2019.10论文重要NeurIPS 2019Biao Zhang, Rico Sennrich · University of Edinburgh / University of Zurich待核对
arXiv ↗官方代码 ↗LLaMA论文第2.2节（采用RMSNorm） ↗在交互版中打开（演化树、学习进度）

问题

LayerNorm能稳定训练，但每一层都要先算均值、再算方差，在RNN里每个时间步都要做，额外开销抵消了它带来的收敛加速。

方法

猜测LayerNorm起作用的是“缩放不变性”而不是“减均值”，于是去掉减均值，只用均方根RMS来缩放：ā = a / RMS(a) · g。

影响

效果与LayerNorm相当，在不同模型上把运行时间缩短7%到64%；后来Gopher、LLaMA等大语言模型都用它替代LayerNorm。

背景

Layer Normalization对一层的输入向量a先减去均值μ、再除以标准差σ，最后乘可学习的增益g、加偏置b：ā_i = (a_i − μ)/σ · g_i + b_i（见归一化层）。它不依赖批次统计，所以比Batch Normalization更适合变长序列和RNN，也成了Transformer每个子层必备的部件。

问题是代价。作者在GRU版RNNSearch翻译模型上观察到：按训练步数算，加了LayerNorm的模型收敛快得多；但按实际耗时算，优势大幅缩水，因为每一步都要多算两遍统计量，而RNN要在每个时间步都做一次。论文想知道LayerNorm的两个性质——对输入整体平移不敏感（re-centering）和对输入整体缩放不敏感（re-scaling）——到底哪个是必需的。

方法

只保留缩放。RMSNorm把均值和方差两个统计量换成一个均方根：

RMS(a) = √( (1/n) Σ a_i² )， ā_i = a_i / RMS(a) · g_i

没有减均值，通常也不加偏置。当输入均值恰好为0时，它与LayerNorm完全相同。

为什么够用。RMS是线性的：RMS(αa) = α·RMS(a)，所以把输入或权重矩阵整体放大α倍，输出不变。论文进一步推导：梯度对输入的缩放不敏感，而与权重的缩放成反比——权重变大时更新自动变小，相当于隐式的学习率自适应。它丢掉的只是对整体平移的不变性。

例子。a = (3, 4)：RMS = √((9+16)/2) ≈ 3.54，输出约为(0.85, 1.13)·g；LayerNorm则先减掉均值3.5得到(−0.5, 0.5)，输出(−1, 1)。

部分RMSNorm（pRMSNorm）。假设同层神经元同分布，只用前p%个元素估计RMS，实验中p取6.25%仍能正常收敛。

结果

实验覆盖WMT14英德翻译（RNNSearch和Transformer）、CNN/Daily Mail阅读理解、COCO图文检索和CIFAR-10分类。TensorFlow版RNNSearch上，LayerNorm每1000步耗时665秒，RMSNorm为501秒，快24.7%，BLEU（newstest2014/2017）分别为22.6/23.6和22.4/23.7。Transformer-base上快6.9%，BLEU为26.8/27.7对26.6/27.7；不加归一化的Transformer则训练失败。总体加速7%到64%，取决于框架、硬件和模型。CIFAR-10上LayerNorm和RMSNorm都不如BatchNorm。

后来的发展

Pre-LN Transformer确定了把归一化放在子层输入处之后，RMSNorm成了这个位置的常用选择：Gopher用它代替LayerNorm，LLaMA原文写明在每个子层输入做RMSNorm预归一化，此后大多数开放权重大模型沿用这一组合。T5原文写的“只缩放、不加偏置的简化版层归一化”在形式上也是同一回事。后来无归一化Transformer DyT进一步尝试用逐元素的tanh函数完全去掉归一化统计量。

容易误解的地方

  • RMSNorm不是“没有归一化”：它仍按每个token自己的向量做缩放，只是不减均值。
  • 7%到64%是整个模型的运行时间缩短，不是归一化层本身；在注意力和矩阵乘法占主导的大Transformer里，收益接近下限。
  • pRMSNorm理论上更省，但作者自己没有观察到稳定的实际加速。

局限与后续

  • “减均值可有可无”只是假设并经验验证，论文没有从理论上说明什么情况下丢掉平移不变性会有害。

它建立在什么之上

  • 改进
    Layer Normalization2016.07 · 基础 已核对
    去掉LayerNorm的减均值和偏置，只按均方根缩放，在精度相当的前提下减少每步计算开销。
  • 竞争
    Batch Normalization2015.02 · 基础
    BatchNorm依赖批内统计，不适合RNN和变长序列；RMSNorm按单个样本归一化，但在CNN图像分类上仍是BatchNorm更好。
  • 使用
    Transformer2017.06 · LLM
    在Transformer-base翻译模型上验证可直接替换LayerNorm，BLEU持平、训练快6.9%。
  • 竞争
    权重归一化2016.02 · 基础
    论文把权重归一化作为对照，比较各方法对输入、权重缩放与平移的不变性。
  • 使用
    Group Normalization2018.03 · 基础
    部分RMSNorm只用一部分神经元估计统计量，作者说这一想法部分受组归一化启发。

读懂它需要的概念

归一化层 期望与方差 范数与距离 循环网络与隐状态 Transformer层的结构 学习率与学习率调度

本篇术语

  • 均方根（RMS）　把向量各元素平方、取平均、再开根号，衡量向量的整体大小；不减均值。
  • 缩放不变性　把输入或权重整体乘上一个常数，归一化后的输出不变；RMSNorm保留了这一性质。
  • 平移不变性　给输入每个元素都加上同一个数，输出不变；LayerNorm靠减均值获得，RMSNorm放弃了它。

怎么学

先补归一化层，把Layer Normalization的公式写熟。读原文第3–4节（不变性分析与表1）和表2、表4的耗时对比。动手：用PyTorch写一个10行的RMSNorm模块，替换nanoGPT里的LayerNorm，比较验证损失和每步耗时；再对同一个向量分别算LayerNorm和RMSNorm的输出，体会减均值的差别。
