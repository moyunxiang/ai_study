CLAY原生3D扩散

CLAY: A Controllable Large-scale Generative Model for Creating High-quality 3D Assets
2024.05论文延伸SIGGRAPH 2024Longwen Zhang, Ziyu Wang, Qixuan Zhang, Qiwei Qiu, Anqi Pang, Haoran Jiang, Wei Yang, Lan Xu, Jingyi Yu · 上海科技大学 / Deemos待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

靠2D模型蒸馏得到3D资产既慢又不一致，真正的3D生成需要在3D数据上直接训练。

方法

用神经场表示几何，在潜空间里训练纯Transformer的扩散模型，并直接生成带PBR材质的3D资产。

影响

展示了大规模原生3D扩散模型的路线，参数规模达15亿。

方法

CLAY的核心是一个大规模生成模型：一个多分辨率VAE，加一个极简的潜空间扩散Transformer（见Diffusion Transformer）。它用神经场表示连续完整的表面，几何生成模块在潜空间里全部用Transformer块。作者设计了渐进式训练，在他们精心处理出的超大3D模型数据集上训出一个15亿参数的原生3D几何生成器。

外观部分，CLAY生成基于物理的渲染（PBR）纹理。它支持文字或图像输入，也支持来自多视图图像、体素、包围盒、点云、隐式表示等的3D感知控制。

后来的发展

它代表2024年原生3D生成的方向，随后TRELLIS结构化3D潜变量等工作继续用结构化3D潜变量。

局限与后续

  • 依赖大规模高质量3D数据，数据来源与许可难以公开。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 材质与几何分开生成，复杂纹理仍可能不一致。

它建立在什么之上

  • 使用
    Diffusion Transformer2022.12 · 生成
    潜空间里的扩散骨架采用DiT。
  • 竞争
    大重建模型LRM2023.11 · 生成
    LRM用前馈网络从图像回归3D，CLAY用潜扩散做生成，两条原生3D路线。
  • 改进
    Shap-E隐式3D生成2023.05 · 生成
    生成物体的几何和纹理仍较粗糙，细节远不如基于优化的方法和后来的大重建模型。
  • 改进
    MVDream多视图扩散2023.08 · 生成
    最终的3D结果仍需通过蒸馏优化，速度慢。
  • 改进
    Wonder3D跨域多视图2023.10 · 生成
    只有6个固定视角且分辨率有限，物体背面、凹陷处和细小结构容易缺失；遇到训练集Objaverse之外的复杂场景泛化变差。

后来的相关工作

  • 竞争
    TRELLIS结构化3D潜变量2024.12 · 生成
