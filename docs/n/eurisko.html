EURISKO

EURISKO: A Program That Learns New Heuristics and Domain Concepts
1983系统延伸1983Douglas Lenat · Stanford待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

AM只能发现数学概念，而且启发式规则本身是固定的，换领域就失效。

方法

让启发式规则自己也成为可被修改、可被发现的对象：EURISKO用一组描述如何使用和改变启发式的元启发式，在多个领域里演化规则。

影响

在VLSI芯片设计等领域取得出人意料的成功，同时让Lenat意识到手工编码知识的代价，转而去做Cyc。

方法

Eurisko是Lenat写的发现系统，用Lisp写的表示语言RLL-1实现，是AM的续作。它由许多启发式组成，其中包括“怎样使用和修改启发式”的启发式。据维基百科，开发始于1976年的卡内基梅隆大学，1978年Lenat回到斯坦福后继续；前五年“没有什么好结果”，换成基于框架（frame）的RLL表示之后，启发式的创建和修改才变得简单。

之后它被用到多个领域，包括VLSI芯片设计，取得了令人意外的成功。Lenat为了摆脱给EURISKO手工编码领域知识的繁重工作，开始了后来的Cyc知识库项目，并设想最终把Cyc与EURISKO的发现引擎结合。

局限与后续

  • 每个新领域仍需人工编码大量领域知识，发现能力来自手写启发式而不是从数据中学习。
