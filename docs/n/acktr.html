ACKTR

Scalable trust-region method for deep reinforcement learning using Kronecker-factored approximation
2017.08论文延伸NeurIPS 2017Yuhuai Wu, Elman Mansimov, Shun Liao, Roger Grosse, Jimmy Ba · 多伦多大学 / 纽约大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

TRPO的信赖域自然梯度更新稳定，但每步要用共轭梯度近似求逆Fisher矩阵，计算昂贵、难以扩展到大网络；A3C等一阶方法便宜但样本效率低。

方法

用K-FAC的克罗内克分解来近似Fisher信息矩阵，使自然梯度的计算接近普通SGD的成本，再加上信赖域约束，同时优化actor和critic。

影响

给出了可扩展的二阶策略优化方案，作为A2C/ACKTR一并收入OpenAI Baselines与A2C，是2017–2019年常见的对比基线之一。

方法

自然策略梯度用Fisher矩阵F的逆去修正梯度方向：Δθ = F⁻¹∇J，这样参数变化以「策略分布改变多少」来度量，而不是以参数距离度量。难点是F的维度等于参数个数的平方，无法直接求逆。

K-FAC的做法是：对每一层分别近似，把该层的Fisher块写成两个小矩阵的克罗内克积 A ⊗ S（A来自层输入激活的二阶统计，S来自反传梯度的二阶统计），这样求逆只要分别求两个小矩阵的逆。ACKTR（Actor Critic using Kronecker-Factored Trust Region）把这一近似用到actor-critic上：actor的自然梯度对应策略分布的Fisher矩阵，critic则把价值回归看作高斯分布下的最大似然，也用K-FAC更新；步长按信赖域（KL不超过阈值）自动缩放。

摘要称，这是第一个可扩展的actor-critic信赖域自然梯度方法，能直接从像素学离散控制，也能学连续控制；在Atari和MuJoCo上，相比此前最好的同策略actor-critic方法，平均获得更高回报，样本效率提升2到3倍。

局限与后续

  • K-FAC实现复杂，需要维护每层的统计量，与多数深度学习框架的标准优化器不兼容。

读懂它需要的概念

策略梯度 Actor-Critic与优势函数 KL散度 雅可比矩阵与海森矩阵

本篇术语

  • Fisher信息矩阵　衡量参数微小变化会让概率分布改变多少的矩阵；自然梯度用它的逆来修正普通梯度。
  • 克罗内克积　两个矩阵A、B的一种乘法，得到的大矩阵由A的每个元素乘以整块B拼成；其逆等于各自逆的克罗内克积。
