Loon平流层气球导航

Autonomous Navigation of Stratospheric Balloons Using Reinforcement Learning
2020.12论文延伸Nature 2020Bellemare, Candido, Castro, Gong, Machado, Moitra, Ponda, Wang · Google, Loon待核对
原始出处 ↗在交互版中打开（演化树、学习进度）

问题

平流层气球没有推进器，只能靠升降到不同高度，借风向漂移；风场复杂、预报有误差，传统规则很难稳定保持在目标区域。

方法

用深度RL训练控制器，输入风预报等信息，决定气球上升或下降，让它长时间留在目标站点附近。

影响

在真实飞行中部署，官方称是RL首次用于商业气球导航；项目随Loon在2021年1月关闭而终止。

方法

气球的动作只有上升、下降、保持，目标是在尽量长的时间内待在服务区上方，以提供网络覆盖。风场由预报和气球自己测得的数据组成，环境高度不确定。控制器用分布式的价值学习方法（与分位数回归QR-DQN等分布式RL同族）在模拟的风场里训练，并在真实气球上试飞。

该节点未能打开论文原文，这里只依据Loon的维基百科条目确认项目背景：Loon是Alphabet子公司，用平流层气球提供网络，2021年1月宣布关闭。论文中的具体飞行时长和性能数字未核实，故不引用。
