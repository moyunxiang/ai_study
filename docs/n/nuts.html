NUTS不掉头采样器

The No-U-Turn Sampler: Adaptively Setting Path Lengths in Hamiltonian Monte Carlo
2011.11论文延伸JMLR 2014Matthew D. Hoffman, Andrew Gelman · 哥伦比亚大学待核对
arXiv ↗Stan官网 ↗在交互版中打开（演化树、学习进度）

问题

哈密顿蒙特卡洛（HMC）借助梯度在高维后验里大步移动，比随机游走式Metropolis采样与MCMC快得多，但它对步长ε和每次模拟的步数L非常敏感，要靠专家反复试跑来调。

方法

不预先固定L，而是让模拟轨迹向前后两个方向成倍延长，一旦轨迹开始“掉头”往回走就停下，再从轨迹上按正确的概率挑一个点；步长ε则在预热阶段用对偶平均自动调好。

影响

NUTS让HMC变成“开箱即用”的通用采样器，是概率编程语言Stan的默认算法，也被PyMC、NumPyro等广泛采用，成为今天贝叶斯统计建模中最常用的MCMC方法。

方法

HMC把参数θ看成一个粒子的位置，再引入一个随机动量r，把负对数后验当作势能。每次迭代先随机抽一个动量，然后用蛙跳积分器按哈密顿方程模拟L步、每步步长ε，最后用Metropolis步骤接受或拒绝终点。轨迹沿着后验的等能量面走得很远，因此样本相关性低。问题在于：L太小，粒子走不远，又退化成随机游走；L太大，轨迹会绕一圈回到起点附近，白白浪费计算。

NUTS的做法是递归地构建一棵二叉树：每一轮随机选一个方向（向前或向后），把当前轨迹长度翻倍；每次扩展后检查“不掉头”条件——轨迹两端的动量方向与两端连线的夹角是否已经超过90度，即再走下去两端会开始相互靠近。一旦出现这种情况，或者积分误差过大，就停止扩展。然后在所建轨迹中满足细致平衡的候选点里，按相应概率选出下一个样本。步长ε在预热期用对偶平均调节，使平均接受率接近目标值（如0.8）。

摘要报告：NUTS的效率至少与精心调好的标准HMC相当，有时更好，而且完全不需要人工调参，适合BUGS式的自动推断引擎这类需要“开箱即用”采样的场合。

局限与后续

  • 每个样本需要多次梯度计算，而且要在全部数据上算，数据量很大或模型是大型神经网络时仍然很慢。

它建立在什么之上

  • 延续
    Metropolis采样与MCMC1953 · 基础
    属于基于梯度的MCMC，解决HMC需要人工设定步数和步长的问题。
  • 使用
    贝叶斯网络与概率图模型1988 · 基础
    面向BUGS式的通用贝叶斯模型推断引擎，用户只写概率模型，采样交给NUTS。
  • 竞争
    SGLD随机梯度朗之万2011.06 · 基础
    同年的两条梯度MCMC路线：SGLD用小批量梯度换可扩展性，NUTS用全梯度和自适应轨迹换采样质量。

读懂它需要的概念

马尔可夫性与马尔可夫链 蒙特卡洛采样 先验、后验与贝叶斯推断 导数、偏导与梯度 常微分方程与随机微分方程

本篇术语

  • 哈密顿蒙特卡洛　给参数配一个随机动量，按物理里的哈密顿方程模拟运动来提出新样本，能沿着分布形状走得很远。
  • 蛙跳积分器　交替更新动量和位置的数值积分方法，能较好地保持能量，常用于HMC。

怎么学

先学Metropolis采样与MCMC里的Metropolis方法和蒙特卡洛采样；用PyMC或NumPyro在一个层次模型上分别跑随机游走Metropolis与NUTS，比较有效样本数；再读论文算法3理解二叉树扩展。
