Claude Mythos分级开放

Project Glasswing: Securing critical software for the AI era
2026.04模型重要Anthropic；Project Glasswing合作方包括AWS、Apple、Broadcom、Cisco、CrowdStrike、Google、JPMorganChase、Linux基金会、Microsoft、NVIDIA、Palo Alto Networks待核对
Project Glasswing公告 ↗英国AISI对Mythos Preview的网络能力评测 ↗维基百科：Claude Mythos（含争议） ↗在交互版中打开（演化树、学习进度）

问题

前沿模型的编码能力已强到能自主发现并利用软件漏洞，若像以往一样直接公开发布，攻击者会和防守方同时拿到这种能力。

方法

Anthropic训练出比Opus高一档的Claude Mythos Preview后不公开发布，而是通过Project Glasswing只开放给50多家关键软件厂商和维护者，先让防守方用它找漏洞、打补丁。

影响

这是前沿实验室第一次因网络攻防能力把最强模型限定给特定机构；它推动各家建立“可信访问”分级制度，也让政府和金融监管机构把AI网络风险当成现实问题。

背景

2025年起，模型读代码、找漏洞的能力进步很快。同年11月Anthropic披露了首个AI主导的网络间谍活动：攻击者用Claude Code自动完成了一场网络间谍活动的大部分步骤。到2026年初，Claude Opus 4.6和GPT-5.4已能完成不少专业级的夺旗赛题目。

过去的惯例是新模型训完就公开发布，再靠拒答训练和分类器拦截滥用。这次的问题在于：防守方修一个漏洞要数周到数月，攻击者用一个漏洞只需几分钟。如果找漏洞的能力同时到达双方，已存在多年的旧漏洞会先被攻击者利用。类似的“暂缓公开”只在2019年的GPT-2上出现过，当时担心的是假新闻。

方法

模型。Mythos是Opus之上的新档位，官方称是通用模型，网络能力来自更强的智能体编码和推理，而非专门训练。参数量未公开，《金融时报》引述的行业估计约8万亿。2026年3月26日，博客草稿泄露使其提前曝光。

分级开放。4月7日公布Project Glasswing：11家发起伙伴加上40多家维护关键基础设施软件的组织获得访问权，用于本地漏洞检测、二进制黑盒测试、渗透测试等防御工作。Anthropic承诺提供最多1亿美元的使用额度，另向开源安全组织捐赠400万美元；额度用完后价格为每百万token输入25美元、输出125美元。尚未修复的漏洞先公布加密哈希，修好后再公开细节。

后续路线。官方表示先在下一个风险较低的Opus模型上试运行新的网络安全分类器，等防护足够可靠再考虑把Mythos级能力开放给所有用户。

结果

官方称几周内用它发现了数千个高危零日漏洞，覆盖所有主流操作系统和浏览器，例如OpenBSD中一个存在27年的远程崩溃漏洞、FFmpeg中一行被自动测试执行过500万次仍未发现问题的16年旧漏洞，以及自主串联多个Linux内核漏洞实现提权。CyberGym漏洞复现83.1%（Opus 4.6为66.6%），SWE-bench Pro 77.8%（53.4%），Terminal-Bench 2.0 82.0%（65.4%）。英国AISI的独立评测显示，它在专家级夺旗题上成功率73%，并成为第一个从头到尾打通32步企业网络攻击模拟的模型（10次中3次），平均完成22步，次优的Opus 4.6为16步。

后来的发展

Mozilla两周后报告用它在Firefox 150中修复了271个安全问题；6月访问范围扩大到15个以上国家的约150家组织。OpenAI随后推出GPT-5.5-Cyber和可信访问计划，形成“通用版加防护、网络专用版限定开放”的行业格局。两个月后，同一底座的Claude Fable 5/Mythos 5带着分类器向公众发布，限定版则以Mythos 5继续供防守方使用。

容易误解的地方

  • “发现数千个漏洞”几乎都来自官方材料，独立核实有限。有安全研究者指出，Firefox利用测试中几乎所有成功都依赖两个已修补的漏洞，去掉后完整代码执行率不到5%；另一项独立测试发现某个标志性漏洞8个开源模型也都能找到。
  • AISI的攻击模拟没有主动防御和告警，结论是它能攻击防护薄弱的网络，不等于能攻破防守严密的系统。

本篇术语

  • 零日漏洞　软件开发者此前不知道、因此还没有补丁的安全缺陷，被利用时防守方毫无准备。
  • 漏洞利用链（exploit chain）　把几个单独危害有限的漏洞串起来，例如先获得普通用户权限、再提权到系统管理员，最终完全控制机器。
  • 夺旗赛（CTF）　网络安全练习题：目标系统里藏有一段“旗子”字符串，找到并利用漏洞把它取出来就算解题。

怎么学

先读首个AI主导的网络间谍活动了解AI网络风险是怎么从理论变成现实的。再读Glasswing公告与英国AISI的评测博客，对比厂商数字和独立评测各说明了什么；最后看维基百科条目里的质疑意见。思考题：如果你是开源库维护者，一个月内收到100份AI生成的漏洞报告，该如何分流？
