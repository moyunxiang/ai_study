学徒学习

Apprenticeship Learning via Inverse Reinforcement Learning
2004论文延伸ICML 2004Abbeel, Ng · Stanford University待核对
论文PDF ↗在交互版中打开（演化树、学习进度）

问题

很多任务（比如开车）要权衡许多因素，奖励函数写不出来，但可以看到专家演示。

方法

假设专家的奖励是已知特征的线性组合，反复求解「奖励—最优策略」，直到学到的策略的特征期望与专家的特征期望足够接近。

影响

给了逆强化学习IRL第一个有性能保证的实用算法，奠定了此后从演示学习的路线。

方法

论文设定：MDP里没有给出奖励，只有一些专家轨迹。假设真实奖励是 R(s) = wᵀφ(s)，φ是已知的特征向量。定义策略的特征期望 μ(π)，即策略下折扣累计特征的期望。如果学到的策略π的 μ(π) 与专家的 μ_E 足够接近，那么对任何满足 ‖w‖≤1 的奖励，π的表现都与专家接近。

算法交替进行：用当前 w 求最优策略（任何标准RL求解器），估计它的 μ，再更新 w 使专家与已有策略的间隔最大（或用更简单的投影法）。论文证明这个过程在少量迭代内终止，输出的策略表现接近专家，但不一定恢复专家真正的奖励函数。论文以模拟驾驶（在多车道高速上）为实验。

局限与后续

  • IRL本身是不适定的，许多奖励都能解释同一组演示，算法只保证表现而不保证找回奖励；输出策略往往是多个策略的混合。
    后来针对它的工作　最大熵逆强化学习
  • 每次迭代都要完整求解一次RL问题，代价高。
    后来针对它的工作　GAIL

它建立在什么之上

  • 延续
    逆强化学习IRL2000 · RL
    把IRL从「恢复奖励」推进为「学出与专家相当的策略」，并给出样本与迭代数的保证。

后来的相关工作

  • 竞争
    DAgger2010.11 · RL
    学徒学习先通过逆强化学习恢复奖励再求策略；DAgger不碰奖励，直接把模仿归约为监督学习加专家查询。
  • 竞争
    GAIL2016.06 · RL
    FEM与GTAL同样直接输出策略，但代价函数只能是线性或凸组合类；GAIL用神经网络判别器，在高维任务上明显胜出。
  • 改进
    最大熵逆强化学习2008 · RL
    把「多种奖励同样解释演示」的歧义，通过最大熵原则消除，并容忍次优演示。
