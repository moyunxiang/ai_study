MoCo

Momentum Contrast for Unsupervised Visual Representation Learning
2019.11论文重要CVPR 2020Kaiming He, Haoqi Fan, Yuxin Wu, Saining Xie, Ross Girshick · Facebook AI Research待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

对比学习需要大量负样本：负样本要么受限于批大小，要么存在一个“记忆库”里，但记忆库里的特征是很多轮之前的旧网络算出来的，前后不一致。

方法

把负样本存成一个先进先出的队列（6.5万个），编码负样本的网络不用梯度更新，而是主网络参数的滑动平均（动量0.999），变化很慢，队列里的特征因此大致一致。

影响

在7项检测和分割任务上，无标签预训练第一次超过ImageNet有监督预训练，说明视觉自监督学习可以替代标注预训练；队列和动量编码器被大量后续方法沿用。

背景

自监督学习的目标是不用人工标签学到好用的图像特征。2018年起最有效的路线是对比学习：同一张图做两种随机变换（裁剪、变色），得到的两个视图应当特征相近（正样本对），与其他图片的特征相远（负样本）。对比预测编码CPC和实例判别InstDisc用的都是这个思路，损失函数是InfoNCE——本质是一个“在K+1个候选中认出正样本”的Softmax与logits分类。

负样本越多效果越好，但从哪里来？一种是端到端：用同一批里其他图片当负样本，数量受批大小和显存限制，论文中8块32GB GPU最多1024张。另一种是实例判别InstDisc的记忆库：把整个数据集每张图的特征都存起来随机抽取，数量足够，但每个特征是在上一轮某个时刻用当时的网络算的，跟当前网络对不上——字典很大但不一致。

方法

把对比学习看作查字典：一张图的一个视图编码成查询q，另一个视图编码成它的正确键k₊，字典里其他键都是负样本。损失（温度τ = 0.07）：

L = −log [ exp(q·k₊/τ) / Σᵢ exp(q·kᵢ/τ) ]

队列。字典是一个长度K = 65536的先进先出队列：每一步把当前批次算出的键放进去，把最老的一批扔掉。字典大小因此与批大小脱钩。

动量编码器。队列里的键无法回传梯度（要回传给6.5万个样本，算不起）。如果直接把查询编码器复制给键编码器，参数每步变化太大，队列里新旧键不一致，训练会失败。MoCo让键编码器参数θ_k缓慢跟随查询编码器θ_q：

θ_k ← m·θ_k + (1 − m)·θ_q，m = 0.999

每一步键编码器只向查询编码器挪0.1%，队列里相隔几百步的键仍可比较。

打乱BN。Batch Normalization在一块GPU内求统计量，正样本对会借此“作弊”，所以计算键之前把批次顺序在GPU间打乱。编码器是ResNet-50，输出128维、L2归一化。

结果

ImageNet线性评估（冻结特征只训练最后一层线性分类器）ResNet-50达到60.6%，宽4倍的ResNet-50达到68.6%。动量消融：m = 0时损失震荡、无法收敛，0.9时55.2%，0.999时59.0%（K=4096）。同样的InfoNCE下，记忆库比MoCo低2.6个点。最重要的是迁移：在PASCAL VOC、COCO等7项检测或分割任务上，MoCo预训练微调后超过ImageNet有监督预训练；在约10亿张未整理的Instagram图片上预训练效果更好。

后来的发展

MoCo和三个月后的SimCLR一起开启了2020年的对比学习热潮。MoCo v2借用SimCLR的投影头和强数据增强，线性评估升到71.1%；MoCo v3把骨干换成Vision Transformer。动量编码器（教师网络是学生网络的滑动平均）被BYOL和DINO继承，后两者连负样本都不要了。此后视觉自监督的主线转向掩码重建（掩码自编码器MAE）和自蒸馏（DINOv2）。

容易误解的地方

  • 线性评估分数（60.6%）当时并不是最高的，MoCo的主要卖点是迁移到检测、分割时超过有监督预训练。
  • 动量编码器不是“动量优化器”，它根本不做梯度更新，只是对参数取指数滑动平均。

局限与后续

  • 仍依赖大量负样本，可能把同类的其他图片当作负样本推开。
    后来针对它的工作　BYOL SimSiam
  • 线性评估精度与有监督训练仍有明显差距（ResNet-50上60.6%）。
    后来针对它的工作　SimCLR BYOL DINO
  • 效果高度依赖人工设计的数据增强（裁剪、颜色抖动），这些增强对颜色、纹理敏感的下游任务不一定合适。
    后来针对它的工作　掩码自编码器MAE

读懂它需要的概念

对比学习 自监督学习 Softmax与logits 数据增强 预训练与微调 内积与余弦相似度

本篇术语

  • InfoNCE　对比损失的一种：把正样本放在K个负样本中，用softmax交叉熵让模型认出正样本。
  • 动量编码器　参数是另一个网络参数指数滑动平均的编码器，不接受梯度，变化平缓，常被称作“教师”。
  • 线性评估　冻结预训练好的网络，只在其特征上训练一个线性分类器，用准确率衡量特征质量。

怎么学

先理解对比学习和Softmax与logits。读原文第3.1–3.2节和算法1（约20行伪代码，几乎可以直接运行），再看图3三种机制的对比。动手：照算法1在CIFAR-10上用ResNet-18实现MoCo，把动量分别设为0、0.9、0.99，观察训练是否收敛。
