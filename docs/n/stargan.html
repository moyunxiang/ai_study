StarGAN多域翻译

StarGAN: Unified Generative Adversarial Networks for Multi-Domain Image-to-Image Translation
2017.11论文延伸CVPR 2018Yunjey Choi, Minje Choi, Munyoung Kim, Jung-Woo Ha, Sunghun Kim, Jaegul Choo · 高丽大学 / Clova AI（NAVER）等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

CycleGAN和pix2pix条件图像翻译一次只能在两个域之间转换；要在发色、性别、年龄、表情等k个域之间互转，就得为每一对域单独训练模型，数量随k平方增长。

方法

只用一个生成器，把目标域标签和输入图像一起喂进去，让它按标签转换；判别器同时判真假和预测域标签，再用循环重建损失保证转换后还能变回原图。

影响

“一个模型、按标签切换目标域”成为多域翻译的标准做法，StarGAN也是人脸属性编辑论文最常用的对比基线之一，并有后续StarGAN v2。

方法

StarGAN的生成器G输入一张图x和一个目标域标签c（例如“金发+微笑”的独热或多热向量，按空间复制后与图像通道拼接），输出转换后的图G(x, c)。训练用三种损失：

  • 对抗损失：让输出看起来真实（对抗训练）。
  • 域分类损失：判别器D除了判真假，还带一个辅助分类头预测图像属于哪个域；对真图，它学习正确分类；对生成图，G要让D把它分到目标域c。
  • 循环重建损失：把G(x, c)再用原标签c′转回去，要求G(G(x, c), c′)接近x，沿用CycleGAN的思路保证只改属性、不改身份。

因为标签是输入，同一个模型就能在所有域之间转换。论文还提出“掩码向量”，让模型同时在标注体系不同的两个数据集（CelebA的属性、RaFD的表情）上联合训练。在人脸属性迁移和表情合成上，它的效果和用户评价都优于为每对域单独训练的基线。

局限与后续

  • 给定输入图和目标标签，输出基本是确定的，无法生成同一目标域里的多种不同风格。

它建立在什么之上

  • 延续
    CycleGAN2017.03 · 生成
    沿用循环一致损失，把两域翻译推广到用一个模型处理多个域。
  • 使用
    条件GAN2014.11 · 生成
    把目标域标签作为条件输入生成器，判别器带辅助分类头，属于条件GAN的做法。
  • 改进
    pix2pix条件图像翻译2016.11 · 生成
    不再需要为每一对域准备成对数据或单独训练一个模型。
  • 改进
    DiscoGAN跨域关系2017.03 · 生成
    一对生成器只能处理两个域之间的翻译，多域需要训练很多对模型。

后来的相关工作

  • 竞争
    MUNIT多模态翻译2018.04 · 生成
    同期推广CycleGAN：StarGAN走单模型多域，MUNIT走一对域内的多样风格。
  • 使用
    StarGAN-VC多对多变声2018.06 · 语音
    把StarGAN的单生成器多域转换从图像搬到说话人变声。
  • 竞争
    AutoVC零样本变声2019.05 · 语音
    StarGAN-VC用一个条件GAN做多对多转换；AutoVC用自编码器瓶颈解耦。

本篇术语

  • 域　具有同一属性的一组图像，例如“戴眼镜的人脸”或“愤怒表情”，翻译就是把图从一个域改到另一个域。

怎么学

先读CycleGAN的循环一致损失 → 读本文第3节三种损失与掩码向量 → 用官方代码在CelebA上做发色转换。
