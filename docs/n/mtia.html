Meta MTIA自研芯片

MTIA: First Generation Silicon Targeting Meta's Recommendation Systems
2023.05硬件延伸ISCA 2023Amin Firoozshahian, Joel Coburn, Roman Levenstein 等 · Meta待核对
Meta官方博客（MTIA v1） ↗ISCA 2023论文 ↗ISCA 2025论文（MTIA 2i） ↗在交互版中打开（演化树、学习进度）

问题

Meta的推荐模型原本跑在CPU服务器上，模型变大后CPU撑不住，GPU又不总是适合推荐模型这种访存密集、规模极大的负载。

方法

为自家推荐模型从头设计推理芯片：大块片上SRAM加便宜的LPDDR5，不用昂贵的HBM，软件栈直接接PyTorch。

影响

MTIA成为云厂商自研芯片里少见的“只为自家负载服务”的路线，到2026年Meta公开了四代路线图，并收购RISC-V芯片公司Rivos加速自研。

背景

Meta的广告和信息流排序依赖深度学习推荐模型（DLRM）。这类模型有巨大的嵌入表，计算量不算极端，但对内存容量和带宽很敏感。2020年前后Meta还主要用CPU做推理，Google TPU和AWS Inferentia与Trainium已经证明云厂商可以为自家负载定制芯片，Meta决定走同样的路。

方法

Meta在2023年5月18日公布第一代MTIA（MTIA v1），设计始于2020年：台积电7nm，800MHz，INT8算力102.4 TOPS、FP16 51.2 TFLOPS，功耗25W。核心是8×8共64个处理单元，每个带128KB本地SRAM和RISC-V开放指令集控制核，另有128MB共享片上SRAM，片外是最多128GB的LPDDR5。ISCA 2023论文报告，在多种DLRM上平均能效（每瓦性能）约为GPU的0.9倍，GEMM等算子可到2倍。

2024年4月的第二代（论文里称MTIA 2i）改用5nm，面积421mm²，256MB片上SRAM，已在数据中心大规模服务推荐模型；ISCA 2025论文称其总拥有成本比GPU低44%。思路始终是用大SRAM加LPDDR替代HBM，换取更低成本。

后来的发展

2026年3月据彭博报道，Meta公布MTIA 300、400、450、500四代芯片，计划2027年底前全部部署，MTIA 300已用于排序与推荐模型的训练；同期Meta收购了做RISC-V芯片的Rivos。MTIA和OpenAI–Broadcom 10GW芯片、Microsoft Maia 200一起，构成云厂商减少对NVIDIA依赖的一条主线。

局限与后续

  • 前两代主要针对推荐模型推理，对大语言模型训练这类负载并不适用，Meta的大模型训练仍主要依赖NVIDIA GPU。

  • 延续
    Google TPU2016.05 · 硬件

  • 竞争
    HBM高带宽内存2013 · 硬件

  • 使用
    RISC-V开放指令集2011.05 · 硬件
    每个处理单元内置RISC-V控制核，后来又收购RISC-V芯片公司Rivos。
  • 竞争
    AWS Inferentia与Trainium2018.11 · 硬件
    同为云厂商自研芯片，AWS对外出租，Meta只供自家业务使用。
