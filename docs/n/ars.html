ARS增强随机搜索

Simple random search provides a competitive approach to reinforcement learning
2018.03论文延伸NeurIPS 2018Horia Mania, Aurelia Guy, Benjamin Recht · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人们普遍认为在策略参数空间里随机搜索的样本效率远差于在动作空间里探索的策略梯度方法，MuJoCo上的深度RL被当作必需。

方法

只用线性策略，在参数空间沿随机方向做正负扰动、比较回报差来估计梯度，再加上状态归一化、按回报标准差缩放步长、只保留表现最好的方向这几个小改进（增强随机搜索ARS）。

影响

成为“简单基线能打败复杂深度RL”的代表论据，与“Deep RL that Matters”一起推动了对MuJoCo基准和评测方法的反思；SB3-Contrib等库内置了ARS。

方法

最基本的随机搜索：对策略参数θ采样随机方向δ，分别评估 θ + νδ 和 θ − νδ 两组参数跑一局的回报，用回报差乘以δ作为梯度估计：

θ ← θ + (α / (b·σ_R)) Σ_(k=1)^b [R(θ + νδ_k) − R(θ − νδ_k)] δ_k

这本质上是进化策略作为RL替代那类进化策略的有限差分形式。ARS（Augmented Random Search）在此基础上加了三处改动：

  • 用这批回报的标准差 σ_R 归一化步长，自动适应回报尺度；
  • 在线估计状态的均值和方差，把输入白化后再喂给线性策略 a = θ·diag(Σ)^(−1/2)(s − μ)；
  • 每轮采样N个方向，只用回报最好的b个方向更新。

策略只是一个线性映射，没有神经网络。摘要称它在MuJoCo运动任务上达到当时最好方法的样本效率，在一个未知动力学的线性二次调节器（LQR）问题上找到接近最优的控制器，计算上比最快的无模型对手至少高效15倍。借助这种效率，作者跑了数百个随机种子和大量超参数组合，发现这些基准任务上的表现方差很大，认为常用的样本效率估计方式不足以评价RL算法。

局限与后续

  • 线性策略在需要视觉输入或复杂非线性控制的任务上不够用，结论主要局限于MuJoCo本体感知的运动任务。

本篇术语

  • 有限差分梯度估计　在参数上加一个小扰动、比较前后函数值的差，用来近似梯度方向。
