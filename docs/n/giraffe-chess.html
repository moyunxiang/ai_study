Giraffe自学象棋引擎

Giraffe: Using Deep Reinforcement Learning to Play Chess
2015.09论文延伸arXiv 2015（硕士论文）Matthew Lai · 伦敦帝国理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

强国际象棋引擎的评估函数由成千上万行手写的模式识别代码组成，由象棋专家和程序员调了很多年；以前用机器学习的尝试大都只是在这些手工特征上调参数。

方法

Giraffe用神经网络当评估函数，只给最少的手工知识（棋子位置、攻防关系等简单输入表示），通过自我对弈和TD-Leaf式的时序差分学习自动学特征与模式，再配合常规的α-β搜索下棋。

影响

在AlphaZero之前两年，它展示了端到端学到的评估函数可以接近顶尖引擎的手写评估；作者Matthew Lai随后加入DeepMind，参与了AlphaZero的工作。

方法

国际象棋引擎的标准结构是：Alpha-Beta剪枝分析剪枝搜索若干步，在叶子节点调用评估函数给局面打分。难点全在评估函数——需要知道王的安全、兵形、子力协调等大量知识。

Giraffe保留了α-β搜索，把评估函数换成一个前馈神经网络。输入不是原始像素式的棋盘，而是一组较少依赖专家知识的特征：各方子力数量、每个棋子的位置、每个格子被哪些棋子攻击和保护等，按棋子类型分组输入网络的不同部分。

训练用TD-Leaf(λ)：这是时序差分学习在搜索引擎中的变体——不是让当前局面的评估去拟合下一个局面的评估，而是让「搜索到的主变化叶子节点」的评估在相邻时间步之间保持一致，误差按λ衰减地反传到前面的步。训练局面来自大量真实对局中的随机局面，再由引擎从这些局面出发自我对弈若干步生成序列。作者还用学到的网络学习搜索中的走法排序（概率式搜索），以便更深地探索有希望的分支。

摘要称，训练出的评估函数表现与当时最先进引擎的评估函数相当，而后者都包含数千行精心手写、调了多年的模式识别器；作者称Giraffe是当时用端到端机器学习下国际象棋最成功的尝试。

    训练方法TD-Leaf(λ)是TD(λ)在搜索主变化叶子节点上的变体。
  • 延续
    TD-Gammon1995 · RL
    沿用TD-Gammon用时序差分加自我对弈学评估函数的思路，并把它用到国际象棋这种需要深度搜索的游戏上。
  • 使用
    Alpha-Beta剪枝分析1975 · RL
    下棋时仍用α-β剪枝搜索，网络只替代叶子节点的评估函数。
  • 竞争
    深蓝战胜卡斯帕罗夫1997.05 · RL
    深蓝一类引擎依赖专家手写的大量评估知识；Giraffe尝试从自我对弈中自动学到这些知识。

本篇术语

  • TD-Leaf(λ)　把TD(λ)用于搜索引擎：比较相邻时间步各自搜索得到的主变化叶子节点评估，用它们的差更新评估函数。
  • 评估函数　给一个棋局局面打分的函数，搜索到一定深度后用它判断局面好坏。

怎么学

先学Alpha-Beta剪枝分析与TD-Gammon；读报告中输入表示与TD-Leaf训练两章；用python-chess写一个浅层α-β，再把手写评估替换成小网络并用TD-Leaf训练。
