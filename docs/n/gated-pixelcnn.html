门控条件PixelCNN

Conditional Image Generation with PixelCNN Decoders
2016.06论文延伸NeurIPS 2016Aaron van den Oord, Nal Kalchbrenner, Oriol Vinyals, Lasse Espeholt, Alex Graves, Koray Kavukcuoglu · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

PixelRNN / PixelCNN论文里的PixelCNN训练可并行、速度快，但对数似然明显不如逐行循环的PixelRNN；而且两者都只能无条件生成。

方法

给PixelCNN的卷积加上类似LSTM的乘性门，并用垂直、水平两个卷积栈消除感受野的“盲点”；再让模型以任意向量（类别、人脸嵌入）为条件生成图像。

影响

据论文，门控PixelCNN在ImageNet上的对数似然追平PixelRNN而计算量大减；它的门控激活与条件方式被WaveNet直接采用，PixelCNN作为强解码器/先验也被VQ-VAE沿用。

方法

PixelCNN用带掩码的卷积保证每个像素只看左上方已生成的像素，所以训练时所有位置能同时计算（见自回归生成）。原版有两个问题：

  • 表达力不足：PixelRNN的LSTM单元有乘性门，PixelCNN只有ReLU。本文把每层激活改为y = tanh(W_f ∗ x) ⊙ σ(W_g ∗ x)，一半通道做内容、一半通道做门（见门控机制）。
  • 盲点：层层堆叠的掩码卷积会漏看当前像素右上方的一片区域。作者把网络拆成垂直栈（看上方所有行）和水平栈（看当前行左侧），并把垂直栈的信息单向传给水平栈，感受野就完整了。

条件生成：给定条件向量h，在每层的两个分支里都加上Vᵀh这一项，即y = tanh(W_f∗x + V_fᵀh) ⊙ σ(W_g∗x + V_gᵀh)。若条件是ImageNet类别，模型能生成对应类别的多样场景；若条件是一张陌生人脸经网络得到的嵌入，模型能生成同一人在不同表情、姿态和光照下的肖像。论文还把条件PixelCNN作为自编码器的解码器，展示它能当强大的解码器使用。

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    借用LSTM乘性门的思想，把门控放进卷积层。
  • 改进
    PixelRNN / PixelCNN2016.01 · 生成
    用门控激活和双卷积栈弥补PixelCNN相对PixelRNN的似然差距与感受野盲点，并加入条件输入。

读懂它需要的概念

自回归生成 卷积层、池化与感受野 门控机制 最大似然估计 生成建模的目标

本篇术语

  • 掩码卷积　把卷积核中对应“未来”像素的权重置零，使每个输出只依赖已经生成的像素。
  • 盲点　堆叠掩码卷积时，当前像素右上方有一块区域始终看不到，导致信息缺失。
