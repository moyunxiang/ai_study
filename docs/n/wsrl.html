WSRL热启动在线微调

Efficient Online Reinforcement Learning Fine-Tuning Need Not Retain Offline Data
2024.12论文延伸ICLR 2025Zhiyuan Zhou, Andy Peng, Qiyang Li, Sergey Levine, Aviral Kumar · UC Berkeley / CMU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线预训练后再在线微调时，大多数方法要一直保留并回放离线数据才能稳定，数据集大时又慢又贵，而且离线的保守约束会限制在线能达到的上限。

方法

分析发现保留离线数据主要是为了防止微调一开始价值函数突然发散；于是先用预训练策略采集少量在线轨迹作“热身”，用这些数据把Q函数校准到在线分布，然后完全丢掉离线数据做普通在线RL。

影响

说明离线转在线不必背着整个离线数据集，给“预训练—微调”范式在RL里提供了更便宜的配方。

方法

离线预训练得到的Q函数是在离线数据分布上学的。一转到在线，策略采到的状态-动作分布和离线数据不同，如果此时立刻用一个高更新比的在线算法（如RLPD先验数据在线RL那样的配置）而不再混入离线数据，Q值会在微调最初阶段出现突然的发散，策略随之“遗忘”预训练的成果。论文通过实验确认：继续训练离线数据的主要作用就是压住这一刻的发散。

WSRL（Warm-start RL）的做法很简单：

1. 用某种离线RL方法（如Cal-QL校准离线预训练、隐式Q学习IQL一类）预训练策略和Q函数； 2. 热身阶段：用预训练策略在环境里跑极少量的轨迹（摘要的说法是very small number of rollouts），放进一个全新的在线回放池； 3. 之后完全丢掉离线数据，从这个回放池出发，用高更新比的标准在线算法继续训练。

热身数据在分布上接近接下来的在线数据，又由预训练策略产生、质量不差，能把Q函数“重新校准”到在线分布上，避免发散。摘要称WSRL在不保留任何离线数据的情况下，比保留或不保留离线数据的现有算法学得更快、最终表现更高。

局限与后续

  • 热身步数需要设定，预训练策略很差时热身数据的质量也差，效果没有保证。

  • 在线阶段仍依赖高更新比的离策略算法，交互样本省了但计算量不小。

本篇术语

  • 热身（warmup）　正式在线训练前，先用预训练策略收集一小批数据填充回放池，不更新网络。

怎么学

先读Cal-QL校准离线预训练和RLPD先验数据在线RL；读WSRL原文第4节的发散分析图；在antmaze上对比保留离线数据、直接丢弃、加热身三种设置的微调曲线。
