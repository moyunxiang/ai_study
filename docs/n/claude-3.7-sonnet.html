Claude 3.7 Sonnet混合推理

Claude 3.7 Sonnet and Claude Code
2025.02模型延伸2025-02-24 发布Anthropic待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

推理模型（如o1）要单独做成另一个模型，用户得在“快但浅”和“慢但深”之间二选一。

方法

同一个模型既能近乎即时回答，也能开启可见的扩展思考，API用户可以指定最多思考多少token。

影响

首个商用“混合推理”模型，把推理变成可调的预算，同时随模型推出了命令行编程工具Claude Code。

方法

2025年2月24日，Anthropic发布Claude 3.7 Sonnet，官方称是市场上第一个混合推理模型。官方的设计理念是：人用同一个大脑做快速反应和深度思考，推理应当是前沿模型的集成能力，而不是另一个模型。

具体来说，标准模式是升级版的Claude 3.5 Sonnet；扩展思考模式下，模型先自我反思再回答，数学、物理、指令遵循和编码任务都会受益，思考过程对用户可见。API用户可以设定思考预算，即思考的token数上限N，最高到128K输出上限，用速度和成本换质量。Anthropic还说，对推理模型的优化较少针对数学和编程竞赛题，更多面向真实业务任务。价格与前代相同：每百万输入token 3美元、输出15美元，其中包含思考token。

发布同时推出了研究预览版的命令行智能体编程工具Claude Code与终端编码智能体。

局限与后续

  • 思考预算要由开发者手动设置，模型不会自己判断一个问题该想多久。
    后来针对它的工作　Claude Opus 4.6
  • 可见的思考过程是否忠实反映真实推理，在公告中没有保证。
    本站还没有记录针对它的后续工作（不代表没有人解决）
