OBELICS图文交错

OBELICS: An Open Web-Scale Filtered Dataset of Interleaved Image-Text Documents
2023.06数据集延伸NeurIPS 2023Hugo Laurençon, Lucile Saulnier, Léo Tronchon, Stas Bekman, Amanpreet Singh, Anton Lozhkov, Thomas Wang, Siddharth Karamcheti 等 · Hugging Face / 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

在图文交错文档上训练的多模态模型优于只用图文对的模型，但此类数据集（如Flamingo所用）不公开，构建过程也没有细说。

方法

从Common Crawl抽取并用详细规则过滤，公开1.41亿个网页、3.53亿张图、1150亿文本token的交错图文数据集。

影响

为开源多模态模型提供了可复现的图文交错预训练数据，并训练出9B和80B的IDEFICS。

方法

OBELICS（Open Bimodal Examples from Large fIltered Commoncrawl Snapshots）把网页按原始顺序保留成「文字、图片、文字、图片……」的文档，而不是拆成孤立的图文对。它共含1.41亿个网页、3.53亿张关联图片和1150亿个文本token，来源是Common Crawl与网络规模文本。

论文详细描述了过滤规则和内容分析。为验证这份数据确实可用，作者训练了90亿和800亿参数的视觉语言模型IDEFICS，在多个多模态基准上取得有竞争力的表现。这是对Flamingo所用的闭源交错数据的开放复现。

局限与后续

  • 来自网页，难免含有版权、隐私和不良内容，过滤只能降低而不能消除这些风险。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只有图文，没有视频和音频的交错数据，规模和质量也仍比不上闭源模型使用的数据。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    Flamingo2022.04 · 多模态 已核对
    复现并公开了Flamingo式的图文交错网页数据。
  • 改进
    BLIP-22023.01 · 多模态 待核对
    训练数据每条只有一对图文，模型学不到多图之间的关系，给它上下文示例VQA成绩也不涨（作者在局限中承认）。
  • 使用
    Common Crawl与网络规模文本2008 · 数据·评测
    数据全部来自Common Crawl网页快照。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
