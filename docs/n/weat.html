WEAT词嵌入偏见测试

Semantics derived automatically from language corpora contain human-like biases
2016.08论文延伸Science 2017Aylin Caliskan, Joanna J. Bryson, Arvind Narayanan · 普林斯顿大学、巴斯大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人们担心机器学习会复制社会偏见，但当时缺少一种标准方法，来度量一个普通的、在网络文本上训练的模型到底学到了多少人类式的偏见。

方法

仿照心理学的内隐联想测试（IAT），用词向量之间的余弦相似度代替人的反应时间，检验两组目标词与两组属性词的关联强弱。

影响

提出的WEAT成为度量词嵌入和后来语言模型偏见的常用工具，结论“偏见就写在语言统计里”被广泛引用。

方法

心理学的内隐联想测试让人把词快速归类，若把“花”和“愉快”放在一组时反应更快，就说明两者在人心中关联更紧。WEAT把这个过程搬到词向量上：取两组目标词X、Y（如花和昆虫，或欧裔名字和非裔名字）和两组属性词A、B（如愉快词和不愉快词）。对每个目标词w计算 s(w) = mean_{a∈A} cos(w,a) − mean_{b∈B} cos(w,b)，再比较X与Y的平均差异，并用置换检验给出显著性，用效应量表示强弱。

作者在网络文本上训练的GloVe词向量上，复现了IAT等心理学研究中的一系列已知结果：从花与昆虫这种道德中性的偏好，到涉及种族和性别的有问题的关联，再到如实反映现状的统计规律（如职业的性别比例、名字的性别分布）。他们还提出了WEFAT，用词向量预测现实中的事实统计量。

与同年词向量中的性别偏见侧重“如何去偏”不同，这篇论文的重点是证明：只要用标准机器学习方法学习日常语言，就会把语言中记录的历史偏见一起学进去。

读懂它需要的概念

嵌入向量 内积与余弦相似度 分布假说 方差、种子与统计显著性

本篇术语

  • 内隐联想测试　心理学实验：通过人对词语分类的反应快慢，推断人心中两个概念的关联强弱。
  • 置换检验　把分组标签随机打乱很多次，看真实差异在随机差异中有多极端，以此算显著性。

怎么学

先懂余弦相似度和词向量 → 读原文的方法部分 → 用公开GloVe向量和几组词表自己算一次WEAT效应量。
