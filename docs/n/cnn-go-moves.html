卷积网络预测围棋走法

Move Evaluation in Go Using Deep Convolutional Neural Networks
2014.12论文延伸ICLR 2015Chris J. Maddison, Aja Huang, Ilya Sutskever, David Silver · 多伦多大学 / Google DeepMind / Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

围棋比其他棋类难，关键在于很难写出好的局面评估或走法评估函数；当时最强的程序（Crazy Stone与蒙特卡洛围棋、MoGo之后的蒙特卡洛树搜索程序）靠大量随机模拟和手工模式弥补，仍只有业余高段水平。

方法

用监督学习训练一个12层的大型卷积网络，输入棋盘的多通道特征平面，直接预测职业棋手在这个局面下会走哪一步，看深度网络能否自己学会围棋的「棋感」。

影响

这篇工作直接证明了深度卷积网络能学到高质量的围棋走法知识，作者中的Aja Huang与David Silver随后把这种走法网络作为策略先验嵌进树搜索，成为AlphaGo策略网络的前身。

方法

围棋棋盘是19×19的网格，天然适合卷积：局部的棋形（「眼」「虎口」「打吃」）在棋盘任何位置都意义相同，卷积的权重共享正好利用了这种平移不变性。

作者把每个局面编码成若干张19×19的特征平面：黑子、白子、空点，各块棋的气数，最近几手的位置，以及按执棋方归一化（总是从「轮到走的一方」的视角）等。网络是12层卷积，每层都保持19×19的空间大小，最后对361个交叉点做Softmax与logits，输出每个点是下一手的概率。训练数据是职业棋手对局数据库，目标是交叉熵——让网络给职业棋手实际走的那步高概率。训练时还利用了棋盘的8种对称（旋转、翻转）做数据增强与权重绑定。

摘要报告：网络在55%的局面里正确预测出职业棋手的走法，相当于一名6段业余棋手的准确率；不做任何搜索，直接按网络走棋，就能在97%的对局中击败传统搜索程序GnuGo，并与一个每步模拟一百万个局面的最先进蒙特卡洛树搜索程序水平相当。同期Clark与Storkey也独立发表了用卷积网络预测围棋走法的工作。

局限与后续

  • 只模仿人类走法，没有价值判断，也不搜索，很难超过它所模仿的人类水平。

本篇术语

  • 特征平面　把棋盘上的一种信息（如黑子位置、每块棋的气数）编码成一张与棋盘同样大小的0/1图，多张叠起来作为网络输入。
  • 走法预测准确率　网络给出概率最高的那步与职业棋手实际所下一致的比例。

怎么学

先学卷积网络的基本结构；读原文第2节输入特征和第3节结果表；用公开的围棋棋谱训练一个小卷积网络预测下一手，再对比AlphaGo论文中SL策略网络的设定。
