GPT Researcher研究智能体

2023.05系统延伸Assaf Elovic等开源社区贡献者待核对
GitHub ↗官方文档 ↗在交互版中打开（演化树、学习进度）

问题

人工调研要花几天到几周找资料；LLM知识过时、会编造、一次输出写不了长报告；ChatGPT加网页插件只看少数几个来源，结论容易片面。

方法

让“规划者”先把任务拆成一组研究问题，再为每个问题并行派出“执行者”抓取网页、摘要并记录出处，最后由规划者筛选汇总成带引用的长报告。

影响

2023年开源、星标约3.1万，是较早被广泛使用的开源“自动写调研报告”智能体，后来加入递归式深度研究、本地文档和MCP支持。

方法

2023年春，AutoGPT与自主智能体热潮和BabyAGI任务驱动智能体掀起自主智能体热潮，但它们串行地“想一步、做一步”，速度慢、结果不稳定。ChatGPT插件里的网页浏览插件每次只读少数页面。GPT Researcher的GitHub仓库创建于2023年5月，早期README写明受BabyAGI和先计划后求解论文启发：先计划、再执行，并且把执行并行化。

流程。按任务生成一个领域专用的智能体角色；规划者生成一组共同覆盖任务的研究问题；对每个问题并行触发爬取智能体，搜索并抓取相关网页；对每个来源按任务相关性做摘要并保留出处；最后筛选、汇总所有摘要，写成报告。早期版本组合使用gpt-3.5-turbo-16k和GPT-4。它本质上是在检索增强生成RAG之上加了一层问题分解与多来源汇总。

规模与演进。官方文档称每次研究汇总20个以上网页来源，报告超过2000词，普通任务约1分钟、花费约0.08美元。后来加入树状递归的深度研究模式（可设深度和广度）、本地PDF/Word等文档研究、基于LangGraph图式编排的多智能体写作流程和模型上下文协议MCP客户端。

局限与后续

  • 全部靠提示词编排固定流程，问题拆分和来源筛选没有针对报告质量做训练，效果取决于所接的LLM和搜索API。
