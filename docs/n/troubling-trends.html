机器学习学术的不良趋势

Troubling Trends in Machine Learning Scholarship
2018.07论文延伸Zachary C. Lipton, Jacob Steinhardt · CMU / Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

机器学习论文数量爆炸，审稿压力和竞争让许多论文把推测写成解释、把调参带来的提升归功于新结构，读者越来越难从论文里获得可靠知识。

方法

归纳出机器学习论文写作中的四种不良趋势：解释与推测不分、不说明效果提升的真正来源、用数学装点门面（mathiness）、滥用或重载术语。

影响

这篇文章成为讨论机器学习研究规范的标准引用，此后会议推出的可复现性清单、消融实验要求和对“SOTA追逐”的批评，常把它当作出发点。

方法

论文2018年7月发在arXiv。作者先说明：论文的价值在于服务读者——刻画什么可学、用严谨实验获得理解、或者造出预测准确的系统，并尽可能清楚地传达。近年的进展却常常偏离这些理想。

四种趋势：一，不区分解释与推测，把未经检验的直觉写成机制。二，不指出实证提升的来源，例如强调对网络结构做的不必要修改，而真正的提升来自超参数调优，这正是基线与消融实验要防止的。三，mathiness，用数学来唬人而不是澄清，混淆技术概念与非技术概念。四，滥用语言，选用带日常含义的术语，或给已有术语加上新含义。文中讨论“内部协变量偏移”这类说法时，与Batch Normalization的争议相呼应。

作者把可能的原因归于社区快速扩张、随之而来的审稿人池变薄，以及学术与引用数、关注度、创业机会等短期指标之间的激励错位，并讨论了社区可以采取的应对办法。它把Rahimi“炼金术”演讲的直觉批评变成了一份具体的问题清单。
