占据栅格地图

High Resolution Maps from Wide Angle Sonar
1985.03论文重要ICRA 1985Hans P. Moravec, Alberto Elfes · 卡内基梅隆大学机器人研究所待核对
IEEE（DOI） ↗Moravec主页存档全文 ↗维基：Occupancy grid mapping ↗在交互版中打开（演化树、学习进度）

问题

廉价超声声呐的波束有30度宽，一次读数只知道“这个扇形里某处有东西”，不知道具体在哪；立体视觉建图又太慢太稀疏。

方法

把地面切成小方格，每格记录“空”与“被占”的置信度；大量来自不同位置的读数叠加后，互相印证的空区会把模糊的占用弧压缩成清晰的障碍轮廓。

影响

第一次用逐格概率表示机器人地图，后来发展成“占据栅格”这一移动机器人最常用的地图形式，并延续到今天自动驾驶的三维占用预测。

背景

移动机器人要自己走路，先得知道周围哪里能走。Shakey机器人那一代系统把世界写成精确的符号和几何模型，默认感知是对的；立体视觉只能提取稀疏特征点，论文提到同实验室最快的视觉系统在1 MIPS的机器上每走1米要算30–60秒。

便宜的超声测距器波束是约30度的圆锥：测到距离R，只说明锥里R以内大概是空的，锥口那段弧上某一点反射了声波，具体在哪不知道；遇到光滑墙面还会读出假的远距离。用这种数据画线段式的几何地图几乎不可能。

方法

传感器模型。对一个读数R，锥内距离小于R−ε的点给出“空”的概率，锥口[R−ε, R+ε]那条弧给出“被占”的概率，两者都在波束中轴最大、往两侧按1−(2θ/ω)²衰减（ω是张角）。

栅格。地面切成小格（实验里每格6英寸），每格存两个0到1的数：Emp（空的把握）和Occ（被占的把握），初始为0表示未知。

合并读数。空区按“概率加法”累积：Emp ← Emp + Emp_k − Emp·Emp_k，例如0.5和0.6合起来是0.8。占用弧只表示“弧上有一点”，所以先用已累积的空区削掉它Occ_k ← Occ_k·(1−Emp)，再归一化使整条弧的和为1，然后才累积。于是从别处看过去证明是空的那部分弧被抹掉，概率集中到真正的障碍处。最后每格取Occ与Emp中较大者，得到负为空、正为占、0为未知的地图。

论文还给出两张地图的配准方法：在不同平移和旋转下逐格相乘求和，配合由粗到细的多分辨率搜索。

结果

在CMU的Neptune机器人上（24个声呐按15度间隔排成一圈），论文称几百个读数、不到1秒计算，就能得到约1000平方英尺、物体位置误差小于1英尺的地图，比立体视觉地图更稠密、快约一个数量级。导航靠航位推算定位，用不到1分钟计算时间穿过30×15英尺的杂乱实验室。

后来的发展

Elfes 1989年在IEEE Computer上的论文和Moravec同年的certainty grid工作把合并规则改写成贝叶斯更新；教材里的标准写法是每格维护对数几率l = log(p/(1−p))，每个读数加上一个增量，见《概率机器人》。

栅格地图成为后续定位与SLAM的底座：蒙特卡洛定位在栅格地图上用粒子估计位置，基于粒子的栅格SLAM沿FastSLAM的思路同时估计地图和轨迹。三十多年后，Tesla占用网络用神经网络从相机预测三维体素是否被占，OccWorld占用世界模型再预测占用随时间的变化，核心表示仍是这张逐格的占用表。

容易误解的地方

  • 1985年的原始版本并不是贝叶斯滤波：它的“概率加法”和取较大值的阈值规则更接近启发式的置信度合并，严格的贝叶斯形式是之后才补上的。
  • 占据栅格建图本身假设机器人位姿已知，它只解决“给定位置怎么画地图”；位置也不确定时属于SLAM问题。
  • 与2018年的占据网络同名不同物：后者用神经网络表示三维形状的连续占用函数，是重建物体形状的方法。

它建立在什么之上

  • 竞争
    卡尔曼滤波1960 · 具身·世界模型
    处理不确定性的另一条路：卡尔曼式方法用少数几何参数的均值和协方差描述，栅格用每格一个概率描述任意形状；后来的系统常把两者结合，用滤波估计位姿、用栅格表示地图。
  • 使用
    A*搜索1968.07 · 具身·世界模型
    栅格把连续空间离散成格子图，路径规划就变成在格子上的图搜索；论文导航时在栅格地图上用同实验室的Path Relaxation方法规划路径。
  • 延续
    Shakey机器人1972 · 具身·世界模型
    延续Shakey以来“机器人先建世界模型再规划”的思路，但把精确的符号几何模型换成了承认测量误差的逐格概率地图。

读懂它需要的概念

随机变量与概率分布 条件概率与贝叶斯公式 先验、后验与贝叶斯推断 图、树与搜索 卷积运算

本篇术语

  • 超声测距（声呐）　发出一束超声波，测回声返回的时间换算成距离。只给出波束范围内最近反射物的距离，不给方向细节。
  • 航位推算　根据轮子转了多少圈、转了多少角度来累计估计自己的位置，不看外界，误差会越积越大。
  • 镜面反射　声波以斜角打到光滑墙面时像光照镜子一样被弹开、回不到传感器，于是读数偏大或为最大量程。
  • 地图配准　求出把一张地图平移、旋转多少能与另一张最吻合，可用来识别到过的地方或校正位置。

怎么学

先复习条件概率与贝叶斯公式和“两个独立事件至少发生一个”的概率a+b−ab。读原文Sonar Mapping一节的公式和四步合并流程，再看《概率机器人》中占据栅格建图一章的对数几率形式，对比两者差别。动手：在100×100的格子里放几面墙，模拟一个30度锥形的测距传感器从多个位置扫描，分别用原文规则和对数几率规则建图，观察读数增多时障碍轮廓如何变清晰。
