K-NRM核池化神经排序

End-to-End Neural Ad-hoc Ranking with Kernel Pooling
2017.06论文延伸SIGIR 2017Chenyan Xiong, Zhuyun Dai, Jamie Callan, Zhiyuan Liu（刘知远）, Russell Power · 卡内基梅隆大学、清华大学、Allen人工智能研究所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经检索模型DRMM用词向量相似度的直方图来做软匹配，但直方图分桶不可导，词向量无法根据排序目标端到端调整；而直接用通用词向量的相似度，“相关”和“相似”又不是一回事。

方法

先算查询词与文档词两两的词向量余弦相似度矩阵（翻译矩阵），再用一组中心不同的高斯核对每一行做“软计数”，得到多个相似度层次上的匹配特征，接一个排序层；高斯核处处可导，整个模型连同词向量一起用成对排序损失端到端训练。

影响

在商业搜索引擎（搜狗）的查询日志上显著超过此前的特征式和神经排序方法，并说明了优势来源：学到的词向量编码了专门为查询—文档匹配定制的相似度。核池化成为交互式神经排序模型的常用组件，后续Conv-KNRM等工作直接沿用。

背景

DSSM深度语义匹配等“表示式”模型分别把查询和文档压成向量再比较，丢失了逐词匹配的信号；DRMM深度相关性匹配（2016）转而先计算查询词与每个文档词的相似度，再按相似度区间统计直方图作为匹配特征，效果更好，但直方图计数不可微，只能使用固定的预训练词向量。BM25等传统模型只做精确匹配，无法处理同义改写。

方法

设查询有n个词、文档有m个词，词向量经同一嵌入层得到，先构造翻译矩阵 M_{ij} = cos(v_{q_i}, v_{d_j})。

核池化：取K个高斯核，第k个核中心为μ_k、宽度为σ_k，对查询词i计算

K_k(M_i) = Σ_j exp( −(M_{ij} − μ_k)² / (2σ_k²) )

它统计文档中与查询词i相似度接近μ_k的词有多少（软计数）。μ取−0.9到1.0的多个值，其中μ=1.0、σ很小的核专门捕捉精确匹配。再对查询词求和取对数：φ_k = Σ_i log K_k(M_i)，得到K维软匹配特征。

排序层：f(q, d) = tanh(wᵀ φ + b)。训练用成对的合页损失：L = Σ max(0, 1 − f(q, d⁺) + f(q, d⁻))，正负文档对来自点击日志。梯度经核函数传回翻译矩阵，再传回词向量，于是词向量被调整为“让相关文档里的词落到高相似度核中”。

结果

在商业搜索引擎的查询日志上，K-NRM相对此前基于特征的和神经的最好方法都有提升；分析表明，其优势来自核引导的词向量，它编码了专门为查询词与文档词匹配定制的相似度度量，并提供有效的多层次软匹配（原文摘要）。具体NDCG提升未在此引用。

后来的发展

K-NRM与DRMM一起代表了“交互式”神经检索模型：先建词级交互矩阵，再提取匹配信号。Conv-KNRM（2018）加入n元组卷积；BERT出现后，基于交叉编码器的重排序（monoBERT等）全面超过了这类模型，但核池化思想仍被用于在BERT表示上提取匹配信号（如CEDR）。ColBERT后期交互的“延迟交互”也继承了逐词相似度矩阵的思路。

读懂它需要的概念

嵌入向量 内积与余弦相似度 高斯分布 损失函数 检索与向量数据库 端到端学习

本篇术语

  • 翻译矩阵　查询中每个词与文档中每个词两两之间的词向量相似度组成的矩阵。
  • 核池化　用以某个相似度值为中心的高斯核对一行相似度求和，相当于“统计相似度接近这个值的词有多少”的可导版本。
  • 软匹配　不要求查询词与文档词完全相同，只要语义相近也算部分匹配。

怎么学
