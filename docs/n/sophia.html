Sophia二阶裁剪优化器

Sophia: A Scalable Stochastic Second-order Optimizer for Language Model Pre-training
2023.05论文延伸ICLR 2024Hong Liu, Zhiyuan Li, David Hall, Percy Liang, Tengyu Ma · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Adam及其变体统治语言模型预训练多年；更精细的二阶（基于Hessian）优化器每一步开销太大，难以用在大模型上。

方法

只估计Hessian的对角线、每隔几步才估一次，把它当作预条件：更新等于梯度的滑动平均除以Hessian估计的滑动平均，再逐元素裁剪防止步子过大。

影响

给“轻量二阶优化器能否替代Adam”提供了一个具体方案并引发了大量复现与比较；后续独立的大规模对比中优势并不稳定，讨论仍在继续。

方法

Adam用梯度平方的滑动平均来缩放每个坐标的步长，但这只是对曲率的粗略代替。Sophia直接估计损失对每个参数的二阶导（Hessian对角线）：论文给了两种轻量估计器（Hutchinson随机估计和基于高斯-牛顿的估计），每隔k步（如10步）才计算一次，平均下来每步的时间和显存开销几乎可以忽略。

更新规则是：m ← β₁m + (1−β₁)g，h ← β₂h + (1−β₂)ĥ（ĥ为新估计），θ ← θ − η·clip(m / max(γh, ε), 1)。逐元素裁剪把每一维的更新限制在固定范围内，用来对付非凸区域Hessian为负或沿轨迹剧烈变化的情况。理论上，作者在简化设定下证明它能适应不同维度的曲率差异，运行时间界不依赖损失的条件数。

摘要报告：在125M到1.5B参数的GPT模型上，Sophia达到与Adam相同困惑度所需的步数、总算力和墙钟时间都约减半。

局限与后续

  • 加速效果主要在1.5B以下的GPT-2规模上报告；后续独立基准对更大规模和更长训练的复现结果不一。

  • 使用
    GPT-22019.02 · LLM
    实验在GPT-2系列结构上进行。
  • 竞争
    AdamW2017.11 · 基础
    主要对比基线是带权重衰减的AdamW。
  • 延续
    Hessian-free优化2010.06 · 基础
    同样利用二阶信息，但只取对角线并稀疏地估计，避免Hessian-free优化每步解线性系统的开销。

本篇术语

  • Hutchinson估计　用随机向量u计算 u⊙(Hu) 来无偏估计矩阵对角线，只需一次Hessian-向量积，不用显式构造Hessian。
