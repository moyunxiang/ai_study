DeepLab空洞卷积

Semantic Image Segmentation with Deep Convolutional Nets and Fully Connected CRFs
2014.12论文重要ICLR 2015Liang-Chieh Chen, George Papandreou, Iasonas Kokkinos, Kevin Murphy, Alan L. Yuille · UCLA / Google / 巴黎中央理工待核对
arXiv ↗代码（Caffe） ↗在交互版中打开（演化树、学习进度）

问题

分类网络为了获得平移不变性层层下采样，最后的特征图只有原图的1/32，直接拿来做逐像素分割，物体边界模糊、细节丢失。

方法

去掉最后两次池化的下采样，改用“带孔”的空洞卷积保持感受野，使输出只缩小8倍；再用全连接条件随机场根据颜色和位置把粗糙的预测贴合到真实边界上。

影响

PASCAL VOC 2012分割测试集mean IoU达到71.6%，明显超过FCN；空洞卷积随后成为分割、检测、语音生成等任务的标准组件。

背景

语义分割要给每个像素打类别标签。全卷积网络FCN把VGG的全连接层改成卷积，让网络输出一张类别热图，但这张图的步长是32像素：一个输出点代表原图32×32的一块，再插值放大，边界自然很粗。

下采样（池化、步长）在分类里是好事：它扩大感受野、带来对小位移的不变性。但分割恰恰需要精确的位置。直接去掉池化，后面各层的卷积核就只能看到更小的区域，预训练权重也不再匹配。论文的问题是：怎样在不损失感受野、不重新训练整个网络的情况下，得到更密的输出？以及怎样把边界做准？

方法

空洞卷积（atrous / “带孔”算法）。把VGG-16最后两个池化层的步长从2改成1，输出不再缩小；为了让后面的卷积核仍覆盖原来那么大的区域，在卷积核的元素之间插入空洞——等价于每隔r个像素取一个点做卷积：

y[i] = Σ_k x[i + r·k] · w[k]

普通卷积r=1。一个3×3的卷积核、r=2时覆盖5×5的范围，r=4时覆盖9×9，参数量不变。论文对最后三个卷积层用r=2、第一个全连接层（改成卷积）用r=4，于是最终输出只比原图小8倍，而且可以直接沿用ImageNet预训练权重。这一技巧来自小波变换中的“à trous”算法。论文还把第一个全连接层的卷积核从7×7缩到3×3、配合r=12，得到感受野更大而更快的LargeFOV版本。

全连接条件随机场。网络输出的每像素类别概率仍然在边界处模糊。作者在其后接一个条件随机场，能量函数为

E(x) = Σ_i θ_i(x_i) + Σ_ij θ_ij(x_i, x_j)

一元项θ_i = −log P(x_i)来自网络；二元项对所有像素对都存在：如果两个像素位置近、颜色相似却被标成不同类别，就要付高代价。用均值场近似推断约10次迭代，把标签“吸附”到颜色边缘上。CRF不与网络联合训练，是一个后处理步骤。

结果

PASCAL VOC 2012测试集mean IoU：FCN-8s为62.2%；DeepLab-CRF为66.4%，加多尺度特征为67.1%，加大视野（LargeFOV）为70.3%，两者结合达到71.6%。网络部分在GPU上每秒约8帧，CRF推断每张图约0.5秒。

后来的发展

空洞卷积被广泛接受：后续的DeepLab v2/v3用不同空洞率并联得到多尺度特征（空洞空间金字塔池化），DeepLabv3+再加上解码器恢复边界并最终去掉了CRF；PSPNet用金字塔池化达到类似目的。WaveNet在一维音频上用指数增长的空洞率扩大感受野。CRF后处理则随着网络自身边界能力变强而被逐渐淘汰。

容易误解的地方

  • 空洞卷积不增加参数，增加的是覆盖范围；但因为特征图不再缩小，计算量和显存都会明显增加。
  • 空洞率过大时，卷积核采样点之间间隔太大，可能漏掉细小结构（所谓网格效应）。

局限与后续

  • CRF是独立的后处理，不参与训练，每张图还要额外约0.5秒，网络和CRF各自最优不等于整体最优。
    后来针对它的工作　DeepLabv3+
  • 只在单一感受野上提取特征，同一张图里大小差异很大的物体难以兼顾，需要多尺度的上下文。
    后来针对它的工作　PSPNet DeepLabv3+
  • 输出步长仍是8，最后靠双线性插值放大，细长结构和小物体的边界依旧不够精细。

它建立在什么之上

  • 使用
    条件随机场2001 · NLP
    用全连接CRF作后处理，把网络的粗糙概率图按颜色和位置相似性贴合到物体边界。
  • 使用
    VGG2014.09 · 视觉
    以ImageNet预训练的VGG-16为主干，只修改池化步长和后续卷积的空洞率。
  • 延续
    OverFeat2013.12 · 视觉
    在OverFeat等工作的密集计算技巧基础上，提出不引入近似、可任意设定输出步长的空洞算法。
  • 改进
    全卷积网络FCN2014.11 · 视觉
    FCN的输出步长为32、边界粗糙；用空洞卷积把步长降到8，再用CRF细化边界，VOC 2012上从62.2%提升到71.6%。

后来的相关工作

  • 竞争
    U-Net2015.05 · 视觉
    同期恢复分辨率的两条路线：DeepLab用空洞卷积少下采样再接CRF，U-Net先下采样再逐级上采样并拼接浅层特征；医学和生成模型多用后者。
  • 改进
    Mask2Former通用分割2021.12 · 视觉
    输出步长仍是8，最后靠双线性插值放大，细长结构和小物体的边界依旧不够精细。
  • 竞争
    RefineNet多路径细化2016.11 · 视觉
    DeepLab靠空洞卷积在高分辨率上保持特征；RefineNet改为多级融合恢复分辨率，显存开销更小。

读懂它需要的概念

卷积层、池化与感受野 卷积运算 分类、检测、分割 IoU与mAP 概率图模型 预训练与微调

本篇术语

  • 空洞卷积　在卷积核元素之间插入间隔（空洞率r），用同样多的参数覆盖更大的区域，常用来在不下采样的情况下扩大感受野。
  • 输出步长　输入图像尺寸与网络输出特征图尺寸之比。步长32表示每个输出点对应原图32×32像素。
  • 均值场推断　一种近似推断方法：假设各像素标签相互独立，反复用邻居当前的标签分布更新每个像素的分布，几次迭代后收敛。

怎么学

先确认会卷积层、池化与感受野和IoU与mAP，再看全卷积网络FCN是如何把分类网络改成分割网络的。读原文第3节（空洞算法与图1）和第4节（全连接CRF）。动手：用PyTorch的nn.Conv2d(dilation=2)对一张小图做卷积，对比dilation=1时的感受野；再用torchvision的DeepLabV3模型分割一张照片，观察边界质量。
