Dyna：学习与规划合一

Integrated Architectures for Learning, Planning, and Reacting Based on Approximating Dynamic Programming
1990论文重要ICML 1990Richard S. Sutton · GTE实验室待核对
论文PDF（Sutton主页） ↗Sutton & Barto教材第8章 ↗在交互版中打开（演化树、学习进度）

问题

纯试错学习每走一步真实环境只能学到一点，学得很慢；传统AI规划又要求事先给出准确的世界模型，而且算得慢，来不及实时反应。

方法

边与环境交互边学一个世界模型，每走一步真实的，就用模型“想象”k步假想经验，并用同一套TD或Q学习规则更新——学习和规划用的是同一个算法，只是数据来源不同。

影响

奠定了“学模型、在模型里练”的基于模型强化学习框架，后来的MBPO、Dreamer、MuZero都可以看成它的深度版本。

背景

1990年前后有三种让智能体做决策的思路：传统AI的规划（根据目标和世界模型推出最佳动作），但计算量大且依赖准确的模型；把规划结果预先编译成“情境→动作”规则，但环境一变规则就过时；以及Actor-Critic（ASE/ACE）、时序差分学习那样的试错学习，不需要模型，但每次真实经验只更新一点点，学得很慢。

动态规划与Bellman方程的动态规划本身不是学习方法，它需要完整的模型；Watkins博士论文刚指出Q学习可以看成增量式的动态规划。Sutton的问题是：能不能把这三件事放进同一个循环？

方法

核心观察是：规划就是从假想经验中试错学习。Dyna的内循环（见基于模型的强化学习）：

  • 决定这一步用真实经验还是假想经验；
  • 真实经验：在当前状态执行动作，得到下一状态和奖励，顺便更新世界模型（这里就是一张“状态+动作→下一状态+奖励”的表）；
  • 假想经验：从见过的状态里随机挑一个，让模型给出结果；
  • 无论哪种，都用同一条TD规则更新价值和策略。

每走一步真实的，做k步假想的。论文给了两个版本：Dyna-PI近似Howard策略迭代，用评估函数加策略表；Dyna-Q直接用Q学习，更简单。

为了应对环境变化，Dyna-Q+给很久没试过的“状态-动作”加一个探索奖励ε√n（n是距上次真实尝试的步数），而且把它加在Q值更新里而不是只加在选动作时，于是规划会主动“计划”出一条去探索的路线。

结果

6×9的迷宫，只有到达终点得奖励1，平均100次运行：k=0（纯试错）路径长度下降很慢；k=100时一般到第4趟就找到并走上最优路径。原因很直观：没有规划时每趟只往回多学一步；有规划时，第一趟学到的那一步会在假想经验中迅速往回传播。

环境变化实验（k=10，50次运行平均）：原路被堵后，Dyna-PI几乎再也拿不到奖励，两种Dyna-Q约800步后找到新路；出现捷径时只有Dyna-Q+发现了它，代价是在静态阶段奖励率略低。

后来的发展

经验回放可以看成Dyna的“无模型”版本：直接重放存下的真实经验。PILCO、PETS概率集成模型、MBPO把表格模型换成高斯过程或神经网络集成；World Models、Dreamer在学到的潜空间里想象轨迹训练策略；MuZero把学到的模型用于树搜索。Sutton后来的Alberta研究计划仍把Dyna式的规划列为核心组件。

局限与后续

  • 模型、价值和策略都是表格，只适用于能全部枚举的小状态空间；论文自己列为第一条局限。
    后来针对它的工作　PILCO MBPO Dreamer
  • 学到的模型一旦有误差，规划会利用这些错误，论文只在确定性小迷宫上验证，没有处理模型偏差。
    后来针对它的工作　PETS概率集成模型 MBPO
  • 假设智能体能直接看到真实状态；现实中状态只能从观测历史中估计。
    后来针对它的工作　POMDP规划 World Models MuZero
  • 假想经验从见过的状态中均匀随机挑选，搜索控制非常粗糙，大问题里大量计算浪费在无关状态上。
    后来针对它的工作　优先经验回放 MuZero

它建立在什么之上

  • 延续
    Actor-Critic（ASE/ACE）1983 · RL
    Dyna-PI的策略和评估更新就是actor-critic，k=0时退化为纯试错的actor-critic。
  • 使用
    时序差分学习1988 · RL
    真实经验和假想经验都用TD误差更新评估函数，规划与学习共用一条规则。
  • 改进
    动态规划与Bellman方程1957 · RL
    动态规划需要事先给定完整模型；Dyna在线学出模型再对它做近似动态规划。
  • 延续
    Howard策略迭代1960 · RL
    Dyna-PI是策略迭代的增量、采样式近似：评估和改进交替进行，但不需要已知模型。
  • 使用
    Watkins博士论文1989 · RL
    Dyna-Q直接以Watkins刚提出的Q学习为内核，比Dyna-PI更简单、更适合变化的环境。
  • 竞争
    Schmidhuber可微世界1990 · 具身·世界模型
    同年的另一条路：Schmidhuber用可微的神经网络世界模型，通过模型反传梯度来改进控制器；Dyna用模型生成样本。后来两条路线都被深度模型RL继承。

后来的相关工作

  • 改进
    World Models2018.03 · 具身·世界模型 待核对
    思路相近：Dyna用模型生成的想象经验辅助学习，这里策略可以完全在学到的生成模型中训练。论文本身没有引用Dyna。
  • 改进
    MuZero2019.11 · RL 待核对
    与Dyna同属“学模型并用模型规划”的思路，但模型只服务于搜索中的价值与策略预测；论文本身没有引用Dyna。
  • 竞争
    经验回放1992 · RL
    Dyna用学到的模型生成假想经验；回放直接重用真实经验。Lin的实验显示需要自己学模型时回放更快，深度RL时代回放成为主流。
  • 改进
    POMDP规划1998 · RL
    Dyna和多数早期RL方法假设智能体能直接看到真实状态；POMDP给出了看不清状态时的正确决策框架。
  • 延续
    Options时间抽象框架1999 · RL
    沿用“学模型再规划”的思路，但模型是option级的：直接预测执行完一个option后会到哪里、得多少奖励。
  • 改进
    优先经验回放2015.11 · RL
    假想经验从见过的状态中均匀随机挑选，搜索控制非常粗糙，大问题里大量计算浪费在无关状态上。
  • 改进
    Dreamer2019.12 · 具身·世界模型
    模型、价值和策略都是表格，只适用于能全部枚举的小状态空间；论文自己列为第一条局限。
  • 改进
    PILCO2011 · RL
    沿用「学习模型再用模型提升策略」的思想，但用概率模型并显式处理模型不确定性。
  • 改进
    PETS概率集成模型2018.05 · RL
    学到的模型一旦有误差，规划会利用这些错误，论文只在确定性小迷宫上验证，没有处理模型偏差。
  • 改进
    MBPO2019.06 · RL
    是Dyna思想在深度网络下的现代版本：用模型生成的经验训练策略。
  • 使用
    Alberta研究计划2022.08 · RL
    把学习和规划统一的Dyna架构作为规划部分的原型。

读懂它需要的概念

马尔可夫决策过程 策略与价值函数 时序差分与自举 基于模型的强化学习 探索与利用 动态规划

本篇术语

  • 假想经验　不是在真实环境中得到，而是向学到的世界模型询问“在这个状态做这个动作会怎样”得到的转移样本。
  • 规划步数k　每执行一步真实动作后，用模型生成并学习的假想转移数量。k越大，同样多的真实经验学得越快，但计算越多。

怎么学

先学会表格Q学习。读原文第2节（Dyna-PI）和第5–6节（Dyna-Q+与环境变化实验）。动手：在6×9迷宫里实现Dyna-Q，画出k=0、5、50时每趟步数的曲线，再做一次中途堵路实验，对照Sutton & Barto教材第8章。
