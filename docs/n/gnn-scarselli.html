图神经网络GNN

The Graph Neural Network Model
2009.01论文延伸IEEE Transactions on Neural Networks 2009Scarselli, Gori, Tsoi, Hagenbuchner, Monfardini · Univ. Siena / Univ. Wollongong待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

神经网络的输入是固定长度向量或序列，而分子、网页、社交网络等是任意形状的图，需要先手工压成向量，丢失结构。

方法

让图里每个节点反复收集邻居的信息、更新自己的状态，直到状态稳定，再从状态读出节点或整图的预测，整个过程可训练。

影响

第一次系统提出“图神经网络”这一名称与框架，是后来所有消息传递型GNN的概念源头。

方法

每个节点v有一个状态向量x_v，初始随机。每一轮，节点按固定的转移函数f，用自己的标签、邻居的状态和邻居的边标签更新状态：x_v = f(l_v, l_edges, x_neighbors, l_neighbors)。同一个f用在所有节点上。迭代到状态收敛，要求f是压缩映射（利普希茨常数小于1），由不动点定理保证有唯一的稳定状态。

状态收敛后，再用输出函数g把状态映射为预测，节点分类用节点状态，图分类则用某个节点或聚合。f和g都是小型神经网络，用梯度下降训练，梯度需要通过迭代过程反传，作者给出了高效的算法。

这个框架把早先用于树和有向无环图的递归神经网络推广到了任意图（包括有环图）。节点之间用“消息”交换信息的思想（见图神经网络与消息传递）后来被消息传递神经网络MPNN等工作系统化。

局限与后续

  • 要把迭代跑到收敛并保证压缩映射，训练慢且限制了函数的表达能力。
    后来针对它的工作　图卷积网络 消息传递神经网络MPNN
  • 每层共享同一个状态函数迭代到不动点，不能像多层网络那样每层学不同的变换；也缺少像卷积那样的明确归纳偏置。
    后来针对它的工作　谱域图卷积 图卷积网络

它建立在什么之上

  • 延续
    Elman循环网络1990 · 基础
    RNN沿时间链复用同一个状态更新函数；GNN把链换成任意图结构，对邻居聚合后更新状态。

后来的相关工作

  • 竞争
    图卷积网络2016.09 · 基础
    早期GNN反复迭代传播直到不动点；GCN改为固定层数、每层参数不同的前馈式传播，更容易训练。
  • 改进
    消息传递神经网络MPNN2017.04 · 基础
    继承了“节点与邻居反复交换信息”的图网络思想，去掉了必须迭代到收敛的限制，改为固定步数、端到端训练。
  • 改进
    谱域图卷积2013.12 · 基础
    沿着“在图上做可学习的神经网络”的方向，用谱理论给出卷积型的具体层定义。
  • 竞争
    DeepWalk图嵌入2014.03 · 基础
    同样想学节点表示，但DeepWalk用无监督游走加浅层嵌入表，不是可端到端训练的图网络。
  • 延续
    神经分子指纹2015.09 · 科学
    在分子图上用可训练的图网络代替手工指纹。

读懂它需要的概念

图、树与搜索 循环网络与隐状态 图神经网络与消息传递 多层感知机 反向传播

本篇术语

  • 压缩映射　每次应用都会让任意两个点的距离缩小一个固定比例的函数，反复应用必然收敛到唯一的不动点。

怎么学

先学图神经网络与消息传递，读论文的框架部分（第2–3节）。动手：用PyTorch写一个小图上的迭代状态更新，对照图卷积网络看它如何用固定层数取代“迭代到收敛”。
