多巴胺与TD误差

A Neural Substrate of Prediction and Reward
1997.03论文重要Science 275, 1997Wolfram Schultz, Peter Dayan, P. Read Montague · 弗里堡大学 / MIT / 贝勒医学院待核对
论文PDF（Dayan主页） ↗Science ↗在交互版中打开（演化树、学习进度）

问题

多巴胺长期被当成大脑的“快感信号”，可猴子实验发现它的放电会随训练从奖励时刻挪到提示灯亮起的时刻，奖励没来时还会低于基线，这无法用“奖励越多放电越多”来解释。

方法

把猴脑多巴胺神经元的记录与TD学习对照：它们的放电恰好对应TD误差δ(t) = r(t) + γV(t+1) − V(t)，即“实际得到的比预期好多少”。

影响

强化学习的核心量在大脑里找到了对应物，TD学习从工程算法变成了解释动物学习的主流理论，也让神经科学与强化学习此后长期互相借鉴。

背景

条件反射研究早就发现学习由“意外”驱动：Rescorla–Wagner条件反射模型模型用“奖励 − 预测”解释了阻断效应（灯已完全预测食物时，再加一个声音，动物不会学到声音的意义）。但它按整次试验更新，没有时间结构，不能说明预测“在什么时刻”发生。

另一方面，中脑腹侧被盖区（VTA）和黑质的多巴胺神经元一直被认为与奖励有关：可卡因、苯丙胺延长多巴胺作用，大鼠会为电刺激这些通路而放弃食物。Schultz实验室记录了清醒猴子执行任务时单个多巴胺神经元的放电，结果却很“奇怪”。

方法

实验现象（Schultz的记录，见原文图1）：

  • 训练前，灯亮后猴子碰杠杆，意外得到一滴果汁：多巴胺神经元在果汁到达后短暂爆发放电；
  • 训练几天后，猴子学会灯一亮就去碰杠杆：果汁到达时不再放电，放电挪到了灯亮的时刻；
  • 训练后如果猴子做错、果汁没有来：在本该给果汁的那个时刻，放电降到基线以下——此时距灯亮已超过1秒，中间没有任何新刺激，说明神经元编码了“预期的奖励时间”。

理论解释。用TD学习（见时序差分与自举）建模：价值V(t)是从t时刻起未来奖励的折扣和，满足V(t) = E[r(t) + γV(t+1)]，于是可以在每一步算出替代误差：

δ(t) = r(t) + γV̂(t+1) − V̂(t)

为了让模型能知道“灯亮后第几步”，作者把灯表示成一串延迟信号x_i(t)（灯亮后恰好第i步为1），每个配一个权重，V̂ = Σ w_i x_i，权重按Δw_i = α Σ_t x_i(t)δ(t)更新。

对照三种情况：未学之前果汁意外到达，r = 1而V = 0，δ > 0；学会之后灯亮的瞬间价值从0跳到正值，δ > 0，而果汁到达时已被完全预测，δ ≈ 0；果汁没来时r = 0而原本预测有奖励，δ < 0。三种情况都与神经元放电对上。

后来的发展

多巴胺即TD误差成为计算神经科学和神经经济学的标准模型。它与Actor-Critic（ASE/ACE）的分工也对应起来：同一个误差信号既训练价值预测，又调整行为选择。二十多年后方向反了过来：受分布式RL C51分布式强化学习启发，DeepMind与哈佛团队2020年在Nature报告，不同多巴胺神经元对正负误差的敏感度不同，合起来编码的是奖励的分布而不只是平均值。

容易误解的地方

  • 多巴胺编码的是“比预期好或差”，不是奖励本身，更不等于“快乐”。
  • 文中的时间表示是作者的建模假设，论文明确说大脑如何表示“提示后第几步”几乎未知。

局限与后续

本篇术语

  • 多巴胺神经元　中脑（腹侧被盖区和黑质）里释放神经递质多巴胺的神经元，轴突投射到纹状体、伏隔核、额叶等与动机和行为选择有关的区域。
  • 阻断效应　一个提示已经完全预测了奖励时，再与它一起出现的新提示不会获得预测意义。说明学习由预测误差驱动而不是由单纯的共同出现驱动。
  • 完整串行复合刺激　把一个提示展开成“出现后第1步、第2步……”一串独立信号的时间表示法，使线性模型能预测奖励在哪个时刻到来。
