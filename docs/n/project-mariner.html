Project Mariner

2024.12系统延伸官方发布 2024-12-11Google DeepMind · Google待核对
DeepMind页面 ↗Gemini 2.0发布 ↗在交互版中打开（演化树、学习进度）

问题

网页操作需要模型能看懂页面、规划步骤并真的点击，而谷歌的Gemini此前没有面向浏览器的智能体原型。

方法

随Gemini 2.0发布的研究原型：观察浏览器里显示的内容，推理出用户目标，制定计划并执行操作。

影响

谷歌进入电脑使用智能体赛道的标志，后来发展为可在云端并行跑多个任务。

方法

Gemini 2.0于2024年12月11日发布，谷歌称之为面向智能体时代的模型，Project Mariner是其中探索「人与智能体交互，从浏览器开始」的研究原型。按DeepMind页面的描述，它的工作方式是多模态推理：观察浏览器里显示的内容，推理用户的目标，制定计划，然后采取行动。

页面还介绍了后来的能力：用自然语言同时分配多个任务，由运行在虚拟机上的浏览器并行完成，如查找职位、规划行程和录入数据，演示包括按简历找工作、在邮件里找订单再去预约帮手、在云盘里找食谱再把缺的食材下单。

后来的发展

它与Anthropic的Computer Use、OpenAI的Operator与浏览器智能体同属2024年底到2025年初的一批浏览器智能体；这类能力后来被整合进浏览器和聊天产品，如ChatGPT agent、AI浏览器Comet与Atlas。
