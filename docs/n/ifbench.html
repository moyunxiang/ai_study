IFBench指令遵循泛化

Generalizing Verifiable Instruction Following
2025.07数据集延伸Valentina Pyatkin, Saumya Malik, Victoria Graf, Hamish Ivison, Shengyi Huang, Pradeep Dasigi, Nathan Lambert, Hannaneh Hajishirzi · 艾伦人工智能研究所（Ai2）/ 华盛顿大学待核对
arXiv ↗数据与代码（GitHub） ↗在交互版中打开（演化树、学习进度）

问题

IFEval的25类可验证指令（如“至少写400词”“提到某词3次”）被各家当作训练目标，许多模型在IFEval上超过80%，但换成没见过的约束就做不好，分数反映的是对少数约束的过拟合。

方法

新写58种全新、可程序验证的输出约束（计数、比例、用词、句子、格式、自定义、复写七类），加到WildChat里没见过的真实用户提示上，组成300道题，专门考指令遵循能否泛化。

影响

GPT-4.1、Claude 3.7 Sonnet、Qwen3-32B等强模型在IFBench上都不到50%；作者用可验证奖励的强化学习（IF-RLVR）把Tülu-3-8B的IFBench从28.9提到45.9，随后IFBench被纳入第三方综合指数和提示优化论文的评测。

方法

题目。从WildChat中取出模型没有见过的真实用户提示，给每个提示加上一条新约束，例如限定某类词出现的比例、要求按特定格式组织句子、要求原样复写部分内容等。每种约束都配一个验证函数，程序就能判断是否满足，不需要模型评审。58种约束分属计数、比例、用词、句子、格式、自定义、复写七类，刻意与IFEval指令遵循的约束不重合，用来测“域外”泛化。

两种设置。单轮：任务和约束写在同一条提示里；多轮：先让模型完成任务，在第三轮再要求按约束改写。报告严格和宽松两种准确率，主要看提示级宽松准确率。

训练部分。作者另写了29种训练用约束及验证函数（IFTrain），把满足约束与否作为可验证奖励，用Tülu 3开放后训练那套可验证奖励强化学习（RLVR）流程训练，研究什么样的数据和设置能让指令遵循泛化。

结果

按论文引言：Tülu-3-8B经IF-RLVR训练后，IFEval从82.4升到92.2，IFBench从28.9升到45.9（论文表3写作44.6，前后不一致）；Qwen2.5-7B基座训练后IFEval 87.8、IFBench约54（引言54.7、表格53.7）。论文称这些IF-RLVR模型超过了除o3以外的多数现有强模型。

后来的发展

IFBench让“可验证指令遵循”从刷固定约束转向考泛化，与IFEval一起成为RLVR类后训练工作检查指令遵循的常用组合。GEPA反思式提示进化用它比较提示优化与GRPO，第三方综合评测Artificial Analysis智能指数在2025年8月的版本中加入了IFBench。

局限与后续

  • 约束都必须能被程序验证，只覆盖格式、计数、用词这类表层要求，考不到语气、内容取舍等难以自动判定的指令。

它建立在什么之上

  • 改进
    IFEval指令遵循2023.11 · 数据·评测
    IFEval的约束集合小且被广泛用于训练，分数被过拟合；IFBench换成58种从未出现过的新约束来测泛化。
  • 使用
    WildChat2024.05 · 数据·评测
    题目的基础提示取自WildChat中的真实用户请求。
  • 延续
    Tülu 3开放后训练2024.11 · LLM
    沿用Tülu 3的可验证奖励强化学习（RLVR）流程，并以Tülu-3-8B为主要训练对象，把指令约束当作可验证奖励。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

基准、排行榜与SOTA 指令微调与对话模板 人类反馈强化学习 奖励设计与奖励投机 泛化与过拟合

本篇术语

  • 可验证约束　能由程序直接判断是否满足的输出要求，例如字数、某词出现次数、是否全部小写。
  • IFTrain / IF-RLVR　IFTrain是作者另写的29种训练约束及验证函数；IF-RLVR指用这些约束的满足情况作为奖励做强化学习。
  • 提示级 / 指令级准确率　提示级要求一条提示里的所有约束都满足才算对，指令级按单条约束统计；严格与宽松的区别在于是否容忍首尾多余文字等细节。

怎么学

先读IFEval指令遵循了解可验证指令的评测方式，再读Tülu 3开放后训练的RLVR部分。读原文第2节（约束设计）和第4节训练实验。动手：从IFBench里挑10条约束，自己写验证函数，用一个开源模型生成回答后统计满足率，再和它在IFEval上的分数对比。
