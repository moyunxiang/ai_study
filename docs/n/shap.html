SHAP

A Unified Approach to Interpreting Model Predictions
2017.05论文重要NIPS 2017Scott Lundberg, Su-In Lee · University of Washington待核对
arXiv ↗shap代码库 ↗Interpretable ML书：SHAP一章 ↗在交互版中打开（演化树、学习进度）

问题

LIME、DeepLIFT等解释方法各自给出“每个特征贡献多少”，但同一个预测用不同方法解释，结果可以不一样，也没人说得清哪个对、它们之间是什么关系。

方法

证明这些方法都属于同一类“加性特征归因”，并借用合作博弈论证明：在这一类里，同时满足局部准确、缺失为零、一致性三条性质的解只有一个，就是Shapley值。

影响

给特征归因定了一个有公理依据的标准答案，shap库成为表格模型（尤其是梯度提升树）解释的事实标准，在金融、医疗等需要解释模型的行业被大量使用。

背景

2016–2017年出现了一批解释单次预测的方法：LIME在样本附近扰动输入、拟合稀疏线性模型；DeepLIFT和逐层相关性传播（LRP）把输出沿网络反向分配给输入；统计学里还有Shapley回归值、Shapley采样值、QII等。它们输出的形式都差不多——给每个特征一个分数——但数值不同，有时连正负号都不一致。

用户面对的问题很实际：一个贷款模型拒绝了某人，“收入”的贡献到底是−0.3还是−0.1？LIME的结果还依赖核宽度、采样数这些人为选择。没有一个准则来判断哪种解释更合理。

方法

统一形式。把输入换成M个“特征在/不在”的二值变量z′，解释模型是一个线性函数：

g(z′) = φ₀ + Σᵢ φᵢ·z′ᵢ

φᵢ就是第i个特征的贡献。论文证明，LIME、DeepLIFT、LRP、Shapley回归值、Shapley采样值、QII这6种方法的解释模型都是这个形式，只是φ的算法不同。

三条性质。

  • 局部准确：所有贡献加起来等于这次预测：f(x) = φ₀ + Σ φᵢ。
  • 缺失为零：原样本里本来就没有的特征，贡献为0。
  • 一致性：如果模型改了，使某个特征在任何情况下的边际作用都不变小，那它的贡献也不能变小。

唯一解。由博弈论中Young（1985）的结果，满足这三条的φ只有一种，即Shapley值：

φᵢ = Σ_{S ⊆ F∖{i}} |S|!·(M − |S| − 1)! / M! · [f(S ∪ {i}) − f(S)]

读法：把特征看成合作完成预测的“玩家”，按所有可能的加入顺序，算特征i加入时让预测变化了多少，再取平均。例如一个两特征模型，若“症状A”单独时输出+2、“症状B”单独时+2、两者都有时+3、都没有时0，那么A的Shapley值是½·(2−0) + ½·(3−2) = 1.5，B同理也是1.5，二者之和3正好等于完整预测。“某特征不在”时的模型输出用对该特征取期望来近似，通常假设特征之间相互独立。

Kernel SHAP。直接算要枚举2^M个子集。作者证明，只要把LIME的加权回归里的核换成特定的“Shapley核”π(z′) = (M−1) / [C(M, |z′|)·|z′|·(M−|z′|)]、去掉正则项，加权最小二乘的解就是Shapley值。这样可以用采样加回归来近似，比直接用Shapley公式采样更省样本。论文还给出针对深度网络的Deep SHAP（把DeepLIFT的规则组合起来近似SHAP值）。

结果

在用全部10个特征的决策树、以及100个特征中只用3个的稀疏决策树上，Kernel SHAP用更少的模型调用就收敛到准确的SHAP值，样本效率明显高于LIME和Shapley采样值。

在Mechanical Turk用户实验中（“只有一个症状时病情分更高”的打分函数，以及三人按最高分分钱的max问题），SHAP给出的归因与人类给出的分配明显比LIME和DeepLIFT更一致。在MNIST上，按SHAP归因去掉像素把“8”改成“3”，比按其他方法去掉像素更能改变模型的对数几率。

后来的发展

作者随后为树模型推出精确且快速的TreeSHAP，shap库被集成进XGBoost、LightGBM等工具，成为业界解释表格模型最常用的方法，“SHAP值图”出现在大量医学和金融论文中。

批评同样持续：特征独立的假设会让模型在不真实的输入组合上求值；SHAP衡量的是模型的依赖关系而不是现实中的因果作用；后来的研究还表明这类事后解释可以被刻意操纵。别再解释黑盒因此主张高风险场景直接用可解释模型。对大型神经网络，单个输入特征的归因越来越不够用，研究转向找模型内部的概念和机制，如TCAV概念激活向量、Circuits与机制可解释性，乃至后来对大语言模型的归因图与《大模型的生物学》。

容易误解的地方

  • SHAP值是相对于一个基准（所有样本的平均预测φ₀）说的，“收入贡献−0.3”指相对于平均预测压低了0.3，不是收入本身的效应。
  • “唯一”只在加性归因这一类、并接受那三条性质的前提下成立；换了“特征缺失”的定义（例如用条件期望还是边缘期望），得到的SHAP值不同。
  • SHAP解释的是模型，不是世界。模型依赖了一个与结果有关但没有因果作用的变量，SHAP会如实地把功劳记在它头上。

读懂它需要的概念

监督学习 线性回归 期望与方差 集成学习 决策树

本篇术语

  • Shapley值　合作博弈论中公平分配合作收益的方法：对所有可能的加入顺序，计算一个玩家加入时带来的额外收益，再取平均。由Lloyd Shapley于1953年提出。
  • 加性特征归因　把一次预测解释为基准值加上每个特征各自的贡献之和的一类方法。
  • Kernel SHAP　用特定权重（Shapley核）做加权线性回归来近似Shapley值的方法，只需调用模型、不需要知道内部结构。

怎么学

先复习线性回归和期望与方差，手算一个三特征模型的Shapley值（枚举6种加入顺序）。再读原文第2–4节，重点是定理1和定理2。最后安装shap库，在一个XGBoost模型上画summary plot和单样本的force plot，并对比同一样本上LIME的解释。
