ICL学的是什么算法

What learning algorithm is in-context learning? Investigations with linear models
2022.11论文延伸ICLR 2023Akyürek, Schuurmans, Andreas, Ma, Zhou · MIT / Google / Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

上下文学习（给几个例子就能预测，不更新参数）为什么有效没人说得清：模型到底是在记忆，还是在内部真的跑了某种学习算法？

方法

用线性回归这个能精确分析的任务当试验田：先证明Transformer能在前向传播里实现梯度下降和岭回归，再检验训练出的模型是否真的与这些算法的预测一致。

影响

给「上下文学习是隐式学习算法」提供了第一批构造性证明和实验证据，开启了用玩具任务解剖ICL机制的一条研究线。

方法

实验设置是上下文学习函数类一脉的合成任务：每个序列里放若干对 (x, f(x))，其中f是随机抽出的线性函数，最后给一个新的x，让Transformer预测f(x)。模型从零开始训练，权重里没有任何关于具体f的信息，所以它只能靠上下文里的例子来推断f。

论文给出三类证据。第一，构造性证明：存在参数设置，使Transformer的若干层恰好完成一步梯度下降，也能完成岭回归的闭式解w = (XᵀX + λI)⁻¹Xᵀy。第二，对比行为：训练出的上下文学习器给出的预测，与梯度下降、岭回归、最小二乘等标准算法的预测高度吻合，并且随模型深度和噪声大小不同，吻合的对象也会变化（摘要称它与最优的贝叶斯预测器吻合）。第三，探针：从中间层的激活里可以读出权重向量、协方差之类算法所需的中间量，说明模型内部确实把一个小模型「编码」在激活里，并随新例子更新。

对新手最重要的一点是：这里说的「学习」发生在一次前向传播之内，没有任何反向传播。

结果

摘要的结论是，训练出的上下文学习器与梯度下降、岭回归和最小二乘的预测相近；具体的误差数值本篇未逐项核对，故不列出。

后来的发展

后续ICL即隐式元优化、ICL即梯度下降等沿着「注意力等价于梯度下降」的方向继续推进。

局限与后续

  • 结论建立在线性回归等玩具任务和从零训练的小Transformer上，不能直接说明GPT-3这类在自然语言上预训练的大模型也在跑同样的算法。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 证明只说明「存在」这样的参数，并没有证明梯度下降训练出来的模型一定会学到它。

读懂它需要的概念

上下文学习与提示 线性回归 梯度下降 自注意力与多头注意力

怎么学

先理解岭回归和梯度下降的更新公式，再读论文第3节的构造性证明思路；可以自己用几十行代码训练一个小Transformer做线性回归的上下文学习。
