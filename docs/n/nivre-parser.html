转移式依存分析

An Efficient Algorithm for Projective Dependency Parsing
2003论文延伸IWPT 2003Joakim Nivre · Växjö University待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

依存句法分析的主流算法是对整句做动态规划，复杂度高、速度慢，难以处理大规模文本。

方法

用一个栈和一个缓冲区，从左到右逐词做移动与归约决策，每一步只选一个动作，整句分析接近线性时间。

影响

开创了转移式（transition-based）依存分析路线，后来的神经依存分析器（神经网络依存分析、SyntaxNet全局归一化）都是它的后代。

方法

分析器维护一个栈（已处理但还没找到全部依存关系的词）和一个缓冲区（尚未读入的词）。每一步从几种动作里选一个：把缓冲区的下一个词压栈；在栈顶和下一个词之间建立一条依存弧（左向或右向）；把栈顶弹出。这样一个有n个词的句子，只需要O(n)个动作就能得到整棵投射式依存树。

关键在于“选哪个动作”由一个分类器决定，输入是栈顶、缓冲区前几个词及其词性等特征，用已标注的依存树库训练。因为每步是贪心的局部选择，速度很快；代价是一旦选错就无法回头。

它与对整句全局打分的图模型路线形成对照，同期的MSTParser与MIRA走的是后者。

局限与后续

  • 贪心决策无法回头，早期的错误动作会向后传播（误差传播）。
    后来针对它的工作　神经网络依存分析
  • 只能产生投射式（弧不交叉）的树，处理自由语序语言里的非投射结构需要额外技巧。
    后来针对它的工作　MSTParser与MIRA

本篇术语

  • 依存句法　用词与词之间的有向弧表示谁修饰谁、谁是谁的论元，而不是短语括号结构。
  • 投射式　依存弧画在句子上方时互不交叉的树。

怎么学

先了解依存树和栈的基本操作；手工对一个短句模拟移进/归约动作序列；再读神经网络依存分析看神经网络如何做动作选择。
