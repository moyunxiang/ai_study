RCPO奖励约束策略优化

Reward Constrained Policy Optimization
2018.05论文延伸ICLR 2019Chen Tessler, Daniel J. Mankowitz, Shie Mannor · Technion / DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

智能体常常钻奖励函数的漏洞，加约束能防止，但一般的约束（尤其是不能写成每步代价之和的约束）没有闭式解，CPO这类方法又依赖二阶近似。

方法

用多时间尺度的拉格朗日方法：把乘子乘以代价变成一个“惩罚信号”并入奖励，策略在快时间尺度上照常用演员-评论家优化，乘子在慢时间尺度上按约束违反程度调整。

影响

把拉格朗日原始-对偶法系统地用到深度演员-评论家上并给出收敛证明，后来常用的PPO-Lagrangian、SAC-Lagrangian等基线都属这一路线。

方法

在约束MDP（CMDP）里，拉格朗日松弛把约束问题变为 min_λ≥0 max_π L(λ, π) = J_R(π) − λ(J_C(π) − α)。RCPO（Reward Constrained Policy Optimization）在实现上分三个时间尺度：

  • 最快：评论家学习“惩罚后的价值”，即把奖励换成 r̂ = r − λ·c 的TD学习；
  • 中等：演员用这个惩罚后的价值做策略梯度更新；
  • 最慢：乘子按约束违反程度做梯度上升 λ ← max(0, λ + η(J_C − α))，约束超了λ就变大，惩罚加重。

这里的“惩罚信号”λ·c 被作者称为引导策略走向满足约束的替代信号。因为乘子变化慢，策略在每个λ下近似收敛，这是随机逼近理论里多时间尺度分析的标准条件；论文据此证明了RCPO收敛到满足约束的局部最优。它也能处理只在整条轨迹结束时才能评估的一般约束（不要求代价能逐步分解）。

作者在网格世界和MuJoCo（限制关节力矩等）上实验，显示能训练出满足约束的策略，而直接把代价按固定系数加进奖励要么约束不满足、要么回报很低。

局限与后续

  • 乘子更新是事后纠正，训练中约束会反复超出再被压回，出现振荡，训练过程中的安全没有保证。
    后来针对它的工作　李雅普诺夫安全RL
  • 收敛只到局部最优，并依赖学习率满足多时间尺度条件，实践中乘子学习率很难调。

它建立在什么之上

  • 使用
    Actor-Critic（ASE/ACE）1983 · RL
    采用演员-评论家结构：评论家学惩罚后的价值，演员据此做策略梯度。
  • 竞争
    基于势函数的奖励塑形1999 · RL
    固定系数把代价并入奖励是一种奖励塑形，RCPO改为自适应调节系数。
  • 使用
    约束MDP（CMDP）1999 · RL
    基于CMDP的拉格朗日松弛与原始-对偶求解。
  • 竞争
    CPO约束策略优化2017.05 · RL
    CPO每步解带约束的信赖域问题；RCPO只用一阶的乘子更新，更简单但约束会振荡。

后来的相关工作

  • 竞争
    李雅普诺夫安全RL2018.05 · RL
    RCPO等拉格朗日法训练中会违规；李雅普诺夫法追求训练全程满足约束。
  • 竞争
    Recovery RL恢复策略2020.10 · RL
    拉格朗日法把任务与安全放进同一目标；Recovery RL把它们分给两个策略。
  • 竞争
    CRPO约束修正策略优化2020.11 · RL
    RCPO是原始-对偶法，靠乘子；CRPO是原始法，直接在改回报与改代价之间切换。
  • 竞争
    Saute RL安全预算增广2022.02 · RL
    RCPO用拉格朗日乘子；Saute不用乘子，直接把约束变成状态与奖励的改写。
  • 使用
    OmniSafe安全RL库2023.05 · RL
    实现RCPO及PPO/TRPO的拉格朗日版本。

本篇术语

  • 多时间尺度　几组参数用量级不同的学习率同时更新，慢的那组在快的看来近似不动。

怎么学

先读约束MDP（CMDP）的拉格朗日表述；读RCPO原文第4节的三时间尺度算法；在OmniSafe里跑PPO-Lagrangian，画出λ和代价随训练的变化。
