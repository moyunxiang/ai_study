PointNet++

PointNet++: Deep Hierarchical Feature Learning on Point Sets in a Metric Space
2017.06论文延伸NeurIPS 2017Qi, Yi, Su, Guibas · Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

PointNet对每个点单独处理再整体池化，抓不到局部结构，对细粒度形状和复杂场景泛化差。

方法

在点云上递归地套用PointNet：先按距离分出局部邻域，在每个小邻域内提取特征，再逐层把范围放大，并对不同点密度做多尺度融合。

影响

让点云网络第一次有了类似CNN的「局部到全局」层级，成为之后点云分割与检测网络的常用骨架。

方法

每一层叫set abstraction：先用最远点采样挑出一批中心点，再按距离找出每个中心周围的点，把这些点的相对坐标交给一个小PointNet，得到该邻域的一个特征向量。这样点数逐层减少、每个点代表的范围逐层变大，和CNN逐层增大感受野的做法对应。

点云采样密度往往不均匀，用均匀密度训练的网络遇到稀疏区域会掉点。论文因此提出多尺度、多分辨率的分组层，让网络自己学会在稀疏处更多依赖大范围特征、在稠密处依赖精细特征。

局限与后续

  • 最远点采样和邻域搜索是顺序、不规则的操作，在大场景点云上很慢。
    后来针对它的工作　Point Transformer V3
  • 依然是在点上手工设计的局部聚合，没有利用自注意力等更强的算子。
