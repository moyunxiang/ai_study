S4结构化状态空间

Efficiently Modeling Long Sequences with Structured State Spaces
2021.10论文重要ICLR 2022Albert Gu, Karan Goel, Christopher Ré · Stanford University待核对
arXiv ↗官方代码 ↗The Annotated S4 ↗在交互版中打开（演化树、学习进度）

问题

上万步的长序列上，RNN记不住、Transformer算不动；用HiPPO矩阵构造的线性状态空间模型理论上能记住长历史，但计算和显存开销大到无法实用。

方法

把HiPPO矩阵拆成“正规矩阵加低秩矩阵”，在频域里用Woodbury恒等式和Cauchy核计算整段卷积核，使训练接近线性复杂度，推理时又能像RNN一样逐步递推。

影响

首次解出长度16384的Path-X任务，在Long Range Arena全部任务上领先；开启了深度状态空间模型这一路线，直接引出Hyena、Mamba。

背景

长程依赖是序列建模的老难题。LSTM等RNN要把信息一步步传下去，几千步之后基本丢失；Transformer的注意力代价随长度平方增长，高效长序列注意力、Performer核近似注意力等高效变体在Long Range Arena（LRA，长度1K到16K的六项任务）上表现仍差，其中Path-X（判断128×128图片展平成16384个像素后两点是否连通）所有模型都只有50%的瞎猜水平。

另一条路来自控制论的状态空间模型（SSM，见状态空间模型与线性RNN，卡尔曼滤波是其经典形式）。HiPPO推导出一类特殊的状态矩阵A，让隐状态在线压缩全部历史；同组的LSSL把它做成深度网络层，在序列MNIST上把精度从随机A的60%提到98%。但LSSL要为状态维度N、长度L付出O(N²L)计算和O(NL)显存，N=256时比同等RNN多用几个数量级的显存；已有的快速算法又在数值上不稳定。

方法

SSM的两种算法。连续形式x'(t) = Ax(t) + Bu(t)，y(t) = Cx(t)。用步长Δ离散化（双线性法）：Ā = (I − Δ/2·A)⁻¹(I + Δ/2·A)，B̄ = (I − Δ/2·A)⁻¹ΔB，得到递推x_k = Ā x_{k−1} + B̄ u_k，y_k = C x_k——这就是一个线性RNN，推理时每步代价固定。把递推展开，输出等于输入与卷积核K̄ = (CB̄, CĀB̄, CĀ²B̄, …, CĀ^{L−1}B̄)的卷积，训练时可以用FFT一次性并行算完（见卷积运算、傅里叶变换与频域）。

卡点。算K̄需要A的L次幂。若A是对角阵就很容易，但论文证明HiPPO矩阵的对角化矩阵元素大到约2^{4N/3}，直接对角化在数值上不可行。

S4的解法。HiPPO矩阵虽不是正规矩阵，却能写成“正规矩阵减一个秩1矩阵”：A = VΛV* − PQ*。正规部分可以用酉矩阵稳定地对角化。再不直接算L个幂，而是在L个单位根上计算K̄的生成函数：低秩部分用Woodbury恒等式化掉，剩下的对角部分恰好是数值分析里研究透的Cauchy核1/(ω_j − ζ_k)；最后做一次逆FFT得到K̄。总代价约为Õ(N+L)计算、O(N+L)显存。

消融。用随机初始化的同结构矩阵效果很差，说明效果主要来自HiPPO初始化，结构化参数化负责让它算得动。

结果

相比LSSL快到30倍、显存省到1/400。LRA上首版平均80.48%，所有基线都低于60%；首次解出Path-X，精度88%（修订版表格更新为96.35%）。不做数据增强的序列CIFAR-10达到91%。WikiText-103语言建模困惑度21.28，与同配置Transformer的20.51只差0.8，并比此前无注意力模型好2以上；生成时比普通Transformer快约60倍。语音指令分类直接处理长16000的原始波形，测试时只改步长Δ，在采样率减半的数据上不重训仍有96.3%。

后来的发展

S4证明了“线性递推加特殊初始化”可以和注意力竞争，随后出现了更简单的对角版本DSS、S4D，以及用隐式长卷积的Hyena长卷积算子。它的主要缺点——参数与输入无关——被Mamba状态空间模型用选择性机制解决，Mamba-2与状态空间对偶又把SSM与线性注意力统一起来。今天大模型里的线性层多来自这条线，常与注意力混合使用，如Jamba混合架构。

容易误解的地方

  • S4是线性时不变系统：A、B、C、Δ对所有输入都一样，非线性来自层与层之间的激活和前馈层。
  • “卷积模式训练、递推模式推理”只对时不变模型成立；参数随输入变化后就不能用FFT卷积了。
  • 论文的Path-X和LRA数字在不同版本中有更新，引用时注明版本。

局限与后续

  • 参数不随输入变化，无法按内容决定记住或忽略哪个token，在需要选择性复制、上下文检索的任务上吃亏。

    HiPPO2020.08 · 基础
    HiPPO矩阵给出长记忆，但直接用于深度网络计算和显存开销过大；S4用正规加低秩分解让它可高效训练。

    Performer核近似注意力2020.09 · LLM
    高效注意力变体在LRA上平均不到60%、Path-X只有瞎猜水平，S4用完全不同的递推路线超过它们。
  • 改进
    LRA长序列基准2020.11 · 数据·评测

  • 改进
    LSSL线性状态空间层2021.10 · 基础

读懂它需要的概念

状态空间模型与线性RNN 循环网络与隐状态 卷积运算 傅里叶变换与频域 特征分解与奇异值分解 低秩近似 常微分方程与随机微分方程

本篇术语

  • Long Range Arena（LRA）　2020年提出的长序列基准，含文本、检索、图像、路径等6项任务，长度从1千到1万6千。
  • 离散化　把连续时间的微分方程按步长Δ换成逐步递推的公式；改变Δ相当于改变采样率。
  • 正规矩阵　能被酉矩阵（复数版的正交矩阵）对角化的矩阵，对角化过程数值稳定。
  • Cauchy核　形如1/(ω_j − ζ_k)的矩阵运算，数值分析中有稳定的近线性算法。

怎么学

先补状态空间模型与线性RNN、循环网络与隐状态和卷积运算，读懂HiPPO要解决什么。读原文第2节（SSM的三种视角）和第3节的算法1，数学细节可先跳过附录。最好的入门材料是The Annotated S4，用JAX逐行实现。动手：先实现对角A的简化SSM层，在序列MNIST上训练，对比随机初始化与HiPPO初始化的差距。
