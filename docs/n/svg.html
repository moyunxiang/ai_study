随机价值梯度SVG

Learning Continuous Control Policies by Stochastic Value Gradients
2015.10论文延伸NIPS 2015Nicolas Heess, Greg Wayne, David Silver, Timothy Lillicrap, Yuval Tassa, Tom Erez · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

确定性策略梯度DPG的反向传播式策略梯度只适用于确定性策略；PILCO式的模型法要在模型预测的整条轨迹上求导，模型误差会一步步累积。

方法

把贝尔曼方程里的随机性写成「外部噪声的确定性函数」（重参数化），从而能对随机策略、随机模型反向传播；并且只在真实观测到的状态上展开模型，减轻模型误差的累积。

影响

给出了从无模型（SVG(0)）到纯模型（SVG(∞)）的一族策略梯度算法，把重参数化技巧带进RL，后来的SAC、Dreamer类方法对价值或模型反向传播都沿用这一思路。

方法

核心是重参数化：随机策略 a ~ π(a|s) 写成 a = π(s, η)，η是与参数无关的噪声；随机环境 s′ ~ p(s′|s,a) 同样写成 s′ = f(s, a, ξ)。这样回报关于策略参数的梯度就能用链式法则沿时间反向传播，和变分自编码器VAE训练时对采样求导是同一个技巧。

于是得到一个谱系：SVG(0) 只用学到的动作价值函数Q，对动作求导，类似带随机策略的确定性策略梯度DPG；SVG(1) 用学到的一步动力学模型加状态价值函数V，向前展开一步再求导；SVG(∞) 不用价值函数，在学到的模型上沿整条轨迹反传，与PILCO类似。

一个关键设计是：模型只用来对真实观测到的轨迹求导——先从真实转移反推出对应的噪声ξ，再沿这条真实轨迹反传梯度，而不是在模型自己预测出的轨迹上走。摘要称这样可以把复合模型误差的影响降到最小；在一个随机玩具问题和若干物理仿真控制任务上，SVG(1)显示了同时学习模型、价值函数和策略的有效性。

局限与后续

  • 需要可微的动力学模型和奖励函数，且只在仿真里的低维状态任务上验证，未处理图像输入。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 模型展开步数越多，梯度方差和模型偏差越难控制，SVG(∞)在复杂任务上不稳定。

它建立在什么之上

  • 使用
    变分自编码器VAE2013.12 · 生成
    借用VAE的重参数化技巧，把随机采样写成噪声的确定性函数以便反向传播。
  • 延续
    确定性策略梯度DPG2014.06 · RL
    把确定性策略梯度推广到随机策略：用重参数化对动作的噪声求导。
  • 改进
    PILCO2011 · RL
    PILCO沿模型预测的轨迹求导，误差会累积；SVG只在真实观测的轨迹上使用模型梯度。

后来的相关工作

  • 改进
    MBPO2019.06 · RL
    模型展开步数越多，梯度方差和模型偏差越难控制，SVG(∞)在复杂任务上不稳定。

读懂它需要的概念

策略梯度 基于模型的强化学习 重参数化技巧 反向传播 Actor-Critic与优势函数

本篇术语

  • 重参数化　把从分布里采样写成「固定噪声+参数的确定性变换」，从而能对参数求梯度。

怎么学

先补重参数化技巧和确定性策略梯度DPG；读原文第3–4节SVG(0)、SVG(1)、SVG(∞)的推导；在Pendulum上实现SVG(0)，和DDPG比较。
