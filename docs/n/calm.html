连续自回归CALM

Continuous Autoregressive Language Models
2025.10论文延伸Chenze Shao, Darren Li, Fandong Meng, Jie Zhou · 腾讯微信AI等待核对
arXiv ↗作者博客 ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

语言模型每一步只生成一个离散token，信息量只有十几比特，生成步数和成本被词表粒度锁死。

方法

先用自编码器把每K个token压成一个连续向量，再让Transformer自回归地预测下一个向量，生成步数减为1/K。

影响

把“提高每一步的语义带宽”提成一个新的扩展方向，为连续空间语言建模给出了训练、评测和采样的一整套工具。

方法

提高生成效率的常见做法是多token预测MTP或投机解码，但它们仍在离散token上工作。CALM走得更远：训练一个高保真变分自编码器VAE式自编码器，把K个token压成一个连续向量，重建准确率超过99.9%。语言于是变成一串连续向量，Transformer只需自回归地预测“下一个向量”，主实验取K=4，生成步数减为四分之一。

连续空间里没有softmax，也算不出似然，所以作者搭了一套无似然的工具：生成头是一个轻量的能量模型，输入隐藏状态和随机噪声，经几层残差MLP一步输出向量，用能量分数（一种严格适当评分规则）训练；评测用他们提出的BrierLM，只靠模型采样就能估计，与交叉熵高度相关；还给出可控温度的采样算法。

论文报告：CALM-M（371M）的BrierLM与Transformer-S（281M）接近（5.72对6.05），训练FLOPs少44%、推理FLOPs少34%。

局限与后续

  • 实验规模最大约1.8B参数，在同等算力下质量仍略低于离散基线，放大后能否保持优势未知。

它建立在什么之上

  • 使用
    变分自编码器VAE2013.12 · 生成
    用变分自编码器式的压缩器把K个token编码成连续向量。
  • 使用
    Transformer2017.06 · LLM
    主干仍是自回归Transformer，只是输入输出换成连续向量。
  • 竞争
    多token预测MTP2024.04 · LLM
    MTP一次预测多个离散token；CALM把多个token压成一个连续向量再预测，彻底离开离散词表。
  • 竞争
    字节潜变量BLT2024.12 · LLM
    BLT在字节上动态分块以提高效率；CALM固定K个token成块并转到连续空间。
