给评测加误差棒

Adding Error Bars to Evals: A Statistical Approach to Language Model Evaluations
2024.11论文延伸Evan Miller · Anthropic待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型论文和发布会报告“A比B高1.5分”，却几乎从不给误差范围；题目只有几百道、题目之间还相互关联，很多差距其实只是噪声。

方法

把每道评测题看作从一个更大题目总体里抽出的样本，套用实验统计学的标准做法：报标准误、按题组聚类、配对比较、事先算样本量。

影响

被广泛引用为LLM评测统计规范的入门文献，推动榜单和技术报告开始标注置信区间和重复采样次数。

方法

作者来自Anthropic，论文写给“学过一点统计”的评测研究者，给出五条建议。

  • 用中心极限定理算均值的标准误，与题数一起报告；多数情况下不必用bootstrap。
  • 题目成组出现时（同一篇文章下多道阅读题、同一题翻译成多种语言）用聚类标准误。论文示例中DROP的聚类标准误为1.34，朴素算法只有0.44，相差约3倍。
  • 降方差：每题多采样几次取平均；能读到下一个词的概率时直接用概率打分，消除采样噪声；不要为降方差而盲目调低温度。
  • 比较两个模型时，对每道题的分差算标准误（配对比较），因为两个模型在同一题上的得分相关，配对更精确。
  • 评测前做功效分析：示例中要可靠检测3个百分点的差距，大约需要1000道题。

局限与后续

  • 只处理题目抽样带来的统计噪声，管不了题目本身被污染、评分器有偏或基准不代表真实使用这类系统性误差。

读懂它需要的概念

方差、种子与统计显著性 期望与方差 基准、排行榜与SOTA

本篇术语

  • 标准误　样本均值的标准差，表示换一批题重测时分数大约会波动多少。
  • 功效分析　事先计算需要多少样本，才能以足够把握检测出某个大小的差异。

怎么学

先复习方差、种子与统计显著性，再读论文第2–4节公式，拿自己跑过的一次评测结果算一遍标准误和配对差。
