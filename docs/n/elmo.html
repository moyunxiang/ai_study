ELMo

Deep Contextualized Word Representations
2018.02论文重要NAACL 2018Peters, Neumann, Iyyer, Gardner, Clark, Lee, Zettlemoyer · 艾伦人工智能研究所 / 华盛顿大学来源已核对
arXiv ↗The Illustrated BERT, ELMo, and co. ↗在交互版中打开（演化树、学习进度）

问题

word2vec给每个词只有一个固定向量，“bank”在“河岸”和“银行”里是同一个向量，模型分不清一词多义。

方法

预训练一个双向LSTM语言模型，把一个词在具体句子里经过的各层隐状态加权求和，作为这个词“随上下文变化”的向量，接到任何下游模型上。

影响

只在各任务原有模型的输入里加上ELMo向量，六个基准任务全部超过当时最好结果；几个月后的GPT-1和BERT改为整体微调预训练好的Transformer。

背景

2013年起，word2vec和GloVe式的词向量是NLP模型的标配输入。它们是一张查找表：一个词一个向量，与它所在的句子无关。可词义取决于上下文：play在“play the piano”和“a Shakespeare play”里意思完全不同（见分布假说）。

2017年的CoVe上下文词向量迈出了一步：用机器翻译模型的LSTM编码器给词生成上下文相关的向量。但翻译需要平行语料，数量有限，而且它只用了编码器的最顶层。

方法

双向语言模型（biLM）。训练两个语言模型：前向的根据前文预测下一个词，后向的根据后文预测前一个词，两者共享最底层的字符表示和最顶层的softmax。结构沿用探索语言模型的极限里最好的CNN-BIG-LSTM并把维度减半：输入用2048个字符n-gram卷积核读出词形（所以没见过的词也有向量），上面是2层双向LSTM，每层4096个单元、投影到512维。在10亿词基准上训练10轮。

加权混合各层。一个词在biLM里有三层表示：字符层h_0、第一层LSTM h_1、第二层h_2。ELMo不只取最顶层，而是让每个下游任务自己学一组权重：

ELMo_k = γ · Σ_j s_j · h_(k,j)

其中s_j是经过softmax归一化的层权重，γ是整体缩放系数。分析发现低层更多编码句法（适合词性标注），高层更多编码语义（适合词义消歧），所以让任务自选比例效果最好。

用法。biLM参数冻结（多数任务里会先用该任务领域的文本把语言模型再训练一下，然后冻结），ELMo向量和原有词向量拼接后送进各任务原本的模型。

结果

在问答（SQuAD）、文本蕴含（SNLI）、语义角色标注、指代消解、命名实体识别、情感分类（SST-5）六个任务上，只加ELMo就全部超过当时最好结果，论文正文概括为相对错误率下降6%到20%（表1中相对各自基线的降幅为5.8%到24.9%）。SQuAD上F1从基线的81.1提高到85.8，相对错误率降低24.9%。

后来的发展

ELMo的实验显示，预训练语言模型的内部状态里装着可迁移的语言知识。几个月后GPT-1把“当特征用”改成“整体微调”，BERT再用掩码语言模型实现了每一层都同时看两边的深度双向；在BERT论文的GLUE对比里，BERT超过了BiLSTM+ELMo+Attn这类基于ELMo的系统。之后多数工作转向直接微调预训练Transformer，而不是把冻结的特征接到各任务模型上。

局限与后续

  • 前向和后向两个语言模型各自训练、最后拼接，是“浅层”双向：任何一层里，一个方向都看不到另一边的上下文。
    后来针对它的工作　BERT
  • 只作为冻结特征接到各任务专门设计的模型上，每个任务仍要自己设计网络结构。
    后来针对它的工作　GPT-1 BERT
  • 主体是LSTM：按时间步串行计算、难以并行，捕捉长距离依赖的能力也有限。
    后来针对它的工作　GPT-1

它建立在什么之上

  • 使用
    LSTM1997 · 基础 已核对
    两层双向LSTM是生成上下文表示的主体。
  • 改进
    word2vec2013.01 · NLP 已核对
    把一个词一个固定向量，改成根据所在句子动态生成向量，缓解了固定词向量无法区分一词多义的问题。
  • 使用
    探索语言模型的极限2016.02 · NLP 已核对
    biLM结构取自该文的CNN-BIG-LSTM，维度减半，并同样在10亿词基准上训练。
  • 使用
    SQuAD2016.06 · 数据·评测 已核对
    在SQuAD等六个基准上验证，问答任务提升最大。
  • 延续
    CoVe上下文词向量2017.08 · NLP 已核对
    同样做上下文词向量，但用无需平行语料的语言模型代替翻译编码器，并混合所有层而非只用顶层。
  • 改进
    Harris分布假说1954 · NLP
    一个词被当作只有一个分布，多义词（bank的“银行”与“河岸”）的不同用法混在一起。
  • 改进
    潜在语义分析LSA1990.09 · NLP
    每个词只有一个固定向量，多义词的不同含义被混在一起，对查准率帮助很小。
  • 改进
    Brown聚类1992 · NLP
    每个词只能属于一个离散的类，无法表达多义词，也无法表达“部分相似”。
  • 改进
    Yarowsky自举词义消歧1995.06 · NLP
    一次只处理一个词、两个粗粒度意思，每个多义词都要单独建模、单独给种子，无法覆盖整个词表。
  • 改进
    从零开始的神经NLP2011 · NLP
    每个词只有一个与上下文无关的向量，多义词无法区分；预训练只覆盖词向量，上层网络仍要从头训练。
  • 改进
    Skip-gram负采样2013.10 · NLP
    向量仍与上下文无关，同一个词在所有句子中共用一个向量。
  • 改进
    TextCNN句子分类2014.08 · NLP
    每个词仍是一个与上下文无关的向量，同一个词在不同句子中的不同含义无法区分。
  • 改进
    GloVe2014.10 · NLP
    每个词只有一个固定向量，“bank”是银行还是河岸无法区分，上下文信息完全丢失。
  • 改进
    序列预训练（Dai & Le）2015.11 · NLP
    只在文本分类上验证，问答、推理、序列标注等需要逐词表示的任务没有覆盖。
  • 改进
    神经命名实体识别2016.03 · NLP
    预训练只覆盖词向量这一层，每个词仍是与上下文无关的固定向量，BiLSTM和CRF完全从小规模标注数据学起。
  • 改进
    双仿射依存分析2016.11 · NLP
    编码器从零开始在一个树库上训练，只用静态预训练词向量，低资源语言的树库很小，精度明显下降。
  • 改进
    BiDAF双向注意力流2016.11 · NLP
    从零训练，只用静态GloVe词向量，语言知识完全来自SQuAD的约10万个问题，换一个领域就明显下降。
  • 改进
    端到端神经指代消解2017.07 · NLP
    词向量固定，句子级LSTM互相独立，跨句上下文和预训练语言知识都没有用上。
  • 改进
    WordNet1995 · 数据·评测
    区分的词义过于细碎，连人类标注者之间也常常无法一致，限制了词义消歧的评测上限。
  • 改进
    Senseval / SemEval1998.09 · 数据·评测
    词义清单（如WordNet）划分过细，人类标注之间都难以一致，分数上限和任务的实际价值存疑。
  • 改进
    词表示用于半监督学习2010.07 · NLP
    每个词只有一个固定向量，无法区分多义词在不同上下文中的含义。
  • 改进
    Stanford CoreNLP2014.06 · NLP
    流水线各环节独立训练，上游错误会传给下游；模型基于特征工程和线性模型，精度被后来的神经模型超越。
  • 改进
    word2vec即隐式矩阵分解2014.12 · NLP
    分析只针对静态的一词一向量嵌入，不涉及上下文相关表示。
  • 改进
    fastText2016.07 · NLP
    得到的仍是静态词向量，一词多义无法区分。
  • 改进
    深度语义角色标注2017.07 · NLP
    仍会出现明显错误，句法分析器的改进仍有帮助。

后来的相关工作

  • 竞争
    GPT-12018.06 · LLM 已核对
    ELMo把双向LSTM状态当冻结特征、各任务另配模型；GPT-1整体微调一个单向Transformer，任务改动更小。在GLUE上，GPT-1的72.8高于论文列出的Multi-task BiLSTM+ELMo+Attn的68.9。
  • 改进
    BERT2018.10 · LLM 已核对
    ELMo只是两个单向LSTM的浅层拼接，BERT在每一层都实现了真正的双向。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测
    论文最强基线用ELMo预训练表示，多任务训练拿到70.0分。
  • 使用
    语言模型即知识库2019.09 · LLM
    ELMo原版和5.5B版本作为对照模型之一，成绩明显不如BERT。

读懂它需要的概念

嵌入向量 语言模型 循环网络与隐状态 分布假说 特征与表示学习

本篇术语

  • 上下文相关词向量　同一个词在不同句子里得到不同的向量，向量由一个读过整句的模型实时算出。
  • biLM　双向语言模型：一个从左往右、一个从右往左的语言模型，分别预测下一个词和上一个词。

怎么学

先补嵌入向量和语言模型。读原文第3节的公式(1)和第5节对各层内容的分析，再看The Illustrated BERT, ELMo, and co.。动手：取一个预训练模型，计算“bank”在两个不同句子中的向量余弦相似度，与word2vec对比。
