语言模型即知识库

Language Models as Knowledge Bases?
2019.09论文重要EMNLP 2019Petroni, Rocktäschel, Lewis, Bakhtin, Wu, Miller, Riedel · Facebook AI Research / UCL待核对
arXiv ↗ACL Anthology ↗代码与数据 LAMA ↗在交互版中打开（演化树、学习进度）

问题

大家知道BERT学会了语法，但它有没有记住“但丁生于佛罗伦萨”这样的事实？过去要拿到这类知识，得靠抽取实体、识别关系等一长串流水线去填知识库。

方法

把知识库里的三元组改写成完形填空句（“Dante was born in [MASK]”），不做任何微调，直接看预训练模型把正确答案排在第几，用这个排名衡量它“知道”多少事实。

影响

第一次系统证明不微调的BERT就能召回相当数量的事实，开启了“语言模型即知识库”和“把知识存在参数里”的研究，也让提示词措辞、事实性与幻觉成为后续的核心问题。

背景

BERT、ELMo出来后，大量“探针”研究（见线性探针）发现这些模型的内部表示里编码了词性、句法等语言知识。但另一个问题没人系统回答：模型在预训练时读了整个维基百科，它记住了多少事实？

当时存储事实的标准方式是结构化知识库，如Freebase、Wikidata，可以查询（Dante, born-in, X）。但要从文本里自动填充知识库，需要实体识别、指代消解、实体链接、关系抽取一整条流水线，每一步都要标注数据和固定的关系模式，错误还会层层累积。

方法

LAMA（LAnguage Model Analysis）探针的做法很简单：

1. 把事实变成完形填空。对每种关系人工写一个模板，例如出生地是“[S] was born in [O]”。三元组（Dante, born-in, Florence）就变成“Dante was born in [MASK] .”。

2. 让模型给所有候选词打分。BERT直接预测[MASK]位置的词；从左到右的语言模型（如Transformer-XL、门控卷积语言模型GLU）预测句子下一个词。为公平起见，所有模型只在一个约2.1万词的共同词表里排序。

3. 看正确答案排第几。主要指标是P@1：正确宾语排在第一的比例。若一个主语有多个正确宾语，排序时去掉其他正确答案，只看当前这个。

知识来源有四个：Google-RE（出生地、出生日期、死亡地3种关系）、T-REx（41种Wikidata关系，每种最多1000条）、ConceptNet（16种常识关系）、SQuAD里改写成完形填空的305个问题。只考察答案是单个词的事实。

对照组是“正规”做法：用关系抽取系统从包含该事实的维基句子里抽取（而且给它提供完美的实体链接），以及开放域问答系统DrQA开放域问答。

结果

在T-REx的41种关系上，不微调的BERT-large的P@1是32.3%，与拿到完美实体链接的关系抽取基线（33.8%）相当，远高于普通实体链接的版本（6.1%）。正确答案排进前10的约占60%，前100的约80%。一对一关系上BERT最强，一对多、多对多关系明显更差。

在SQuAD改写题上，BERT-large的P@1为17.4%，监督训练的DrQA为37.5%；放宽到前10名，差距缩小到57.1%对63.5%——而BERT既没有微调，也没有检索系统。

作者还发现：宾语在训练语料里出现得越多，越容易答对；BERT答错时通常也能猜出正确类型（问出生地，它会答另一个意大利城市）。

后来的发展

这篇论文把“参数里存了多少知识”变成可以量化的问题。几个月后参数里能装多少知识用T5做闭卷问答，证明模型越大装的事实越多；REALM和检索增强生成RAG则走另一条路，把知识放在外部检索库里，按需取回，解决了参数知识无法更新、无法溯源的问题。ROME知识定位与编辑进一步定位事实存放在哪些层并直接编辑。

用完形填空句去“问”模型，也是提示（prompt）研究的前身：后来的大量工作专门研究换一种措辞能多问出多少知识，直到GPT-3让“写提示”成为使用模型的主要方式。

容易误解的地方

  • “知道”在这里只意味着“完形填空时排第一”。作者自己提醒，BERT可能只是记住了主语和宾语经常一起出现，而非理解了这个事实。
  • 结果对模板措辞很敏感：同一个事实换一种说法，分数可能差很多，所以LAMA的分数是模型知识的一个下界估计。
  • 只测单个词的答案，“出生日期”这类多token答案基本没法考。

局限与后续

  • 只能考答案是单个词的事实，多词实体和数字日期几乎无法评估。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    直接拿不微调的BERT的掩码预测当查询接口，BERT-large在所有知识来源上都最好。
  • 竞争
    Freebase2007.03 · NLP
    结构化知识库需要固定关系模式和抽取流水线；本文提出语言模型可以无模式、无监督地充当知识库。
  • 使用
    SQuAD2016.06 · 数据·评测
    从SQuAD开发集挑出305个与上下文无关、答案为单词的问题，改写成完形填空句。
  • 竞争
    DrQA开放域问答2017.03 · NLP
    以监督训练的开放域问答系统作基线，不微调的BERT在前10名精度上已接近它。
  • 使用
    ELMo2018.02 · LLM
    ELMo原版和5.5B版本作为对照模型之一，成绩明显不如BERT。
  • 延续
    线性探针2016.10 · 安全·可解释
    探针此前主要考察语言学性质，本文把探针扩展到事实和常识知识，而且不训练任何额外分类器。

读懂它需要的概念

掩码建模 语言模型 预训练与微调 嵌入向量 Softmax与logits 幻觉

本篇术语

  • 完形填空式查询　把问题写成缺一个词的句子，让模型填空。例如把“爱因斯坦生于哪里”写成“爱因斯坦生于[MASK]”。
  • P@1 / P@10　正确答案排在模型预测第1名（或前10名）的比例。
  • 三元组　知识库存事实的格式：（主语, 关系, 宾语），如（但丁, 出生地, 佛罗伦萨）。

怎么学

先懂掩码建模和BERT怎样预测被遮住的词。读原文第4节（探针构造）和表2。动手：用Hugging Face的fill-mask管道加载bert-base，自己写10条“X的首都是[MASK]”的句子，再换几种措辞，观察答案如何随措辞变化。
