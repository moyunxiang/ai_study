神经对话模型

A Neural Conversational Model
2015.06论文延伸ICML Deep Learning Workshop 2015Vinyals, Le · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

聊天机器人长期靠手写规则和固定领域模板，换个场景就得重做。

方法

把对话当成翻译：直接用Seq2Seq把上一句映射成下一句，只靠大量对话语料端到端训练。

影响

第一批证明端到端神经网络能做开放域闲聊的工作，之后神经对话研究由此展开。

方法

模型就是标准的Seq2Seq：LSTM编码器读入对话上文，解码器逐词生成回复，不加任何规则。论文在两类数据上训练：一个是IT客服的故障排查对话（领域内），一个是电影字幕（开放域）。作者发现模型能记住一些领域知识，例如在客服对话里能给出像样的排障步骤；在电影字幕上能回答简单的常识问题并保持一定的前后一致。

论文自己也坦承，它优化的是「预测下一句」这个目标，并不是真正想要的「好对话」，却仍能聊起来；同时模型常给出安全泛泛的回答，前后人设也不一致。

局限与后续

  • 回复倾向于安全、泛泛的万能句，例如「我不知道」，缺乏信息量。
    后来针对它的工作　对话多样性MMI目标
  • 只看上一句或有限上文，长对话中话题与人设不能保持一致。
    后来针对它的工作　层次编码器对话HRED

它建立在什么之上

  • 使用
    Seq2Seq2014.09 · NLP
    直接把seq2seq框架从翻译搬到对话，输入是上文，输出是回复。
  • 改进
    ELIZA1966.01 · NLP
    所有能力来自手写脚本，换一个话题或场景就要重写大量规则，无法从对话数据中学习。
  • 改进
    PARRY1971 · NLP
    所谓“通过测试”依赖于评估者对偏执患者的预期，不能证明程序理解了语言。

后来的相关工作

  • 延续
    层次编码器对话HRED2015.07 · NLP
    在单轮对话模型之上加上句子级上下文RNN，使其能利用多轮历史。
  • 改进
    对话多样性MMI目标2015.10 · NLP
    针对其万能回复问题，用互信息目标替换纯似然目标。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
