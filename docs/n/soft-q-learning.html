软Q学习（能量策略）

Reinforcement Learning with Deep Energy-Based Policies
2017.02论文延伸ICML 2017Tuomas Haarnoja, Haoran Tang, Pieter Abbeel, Sergey Levine · UC Berkeley / OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DDPG等连续控制算法学的是确定性或单峰高斯策略，一旦认定一条路就很少尝试其他做法；最大熵RL能鼓励多样行为，但在连续状态和动作上一直只能在表格情形下做。

方法

把最大熵目标下的最优策略写成能量模型 π(a|s) ∝ exp(Q_soft(s,a)/α)，用软Bellman方程学软Q函数，再训练一个采样网络（用摊销的Stein变分梯度下降）去近似从这个分布中采样。

影响

把最大熵RL带进深度连续控制，直接引出了更简单稳定的SAC；「软Q」「软值」的写法也被后来的离线RL和模仿学习方法（如IQ-Learn逆软Q模仿）沿用。

方法

最大熵RL的目标是在回报之外再奖励策略的熵：Σ E[r_t + α·H(π(·|s_t))]，α控制有多看重随机性。在这个目标下，最优策略是对软Q函数做玻尔兹曼分布：Q高的动作概率大，但次优动作也保留一定概率，因此策略可以是多峰的。软Q满足软Bellman方程 Q(s,a) = r + γ·E[V(s')]，其中 V(s) = α·log ∫ exp(Q(s,a)/α) da，即把max换成log-sum-exp。

连续动作里这个积分和采样都算不出来。作者用重要性采样估计软值V；再训练一个输入状态和噪声、输出动作的采样网络，用摊销SVGD让它产生的样本分布逼近 exp(Q/α)。摘要称，这样做的好处包括更好的探索，以及可组合性——在一个任务上学到的技能可以迁移到别的任务，作者在模拟的游泳和行走机器人上验证了这些性质；文中还指出actor-critic方法可以看作是在对应能量模型上做近似推断。

局限与后续

  • SVGD采样网络和重要性采样估计软值都很复杂，训练不稳定、实现门槛高。

读懂它需要的概念

信息量与熵 能量模型与玻尔兹曼分布 Bellman方程 Actor-Critic与优势函数 Softmax与logits

本篇术语

  • 最大熵RL　在回报之外再加上策略熵的奖励，让智能体在不损失太多回报的前提下尽量保持随机。
  • SVGD　Stein变分梯度下降：一种让一组样本逐步移动、使其分布逼近目标分布的确定性方法；摊销版本训练一个网络直接产生这样的样本。

怎么学

先懂熵和softmax；读原文第2–3节的软Bellman方程；再读SAC，对比两者在实现上的简化。
