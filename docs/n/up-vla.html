UP-VLA理解与预测统一

UP-VLA: A Unified Understanding and Prediction Model for Embodied Agent
2025.01论文延伸ICML 2025Jianke Zhang, Yanjiang Guo, Yucheng Hu, Xiaoyu Chen, Xiang Zhu, Jianyu Chen · 清华大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

VLA借用的VLM只在图文理解上预训练，擅长高层语义，却忽视底层视觉细节，抓不住精细的空间位置和物理变化。

方法

训练VLA时同时用多模态理解目标和未来预测目标，让模型既懂语义、又学会预测接下来画面会怎样变化，从而补上空间细节和动力学。

影响

在CALVIN ABC→D上比此前最好方法提升33%，真机上对需要精确空间信息的任务提升尤其明显，被收录于ICML 2025。

方法

卡在哪：OpenVLA、RT-2与VLA这类VLA直接继承VLM的视觉表示，而VLM是为回答“图里有什么”训练的，对物体的精确位置、接下来会怎样运动并不敏感。另一条路线GR-1视频预训练策略、SuSIE子目标图像用视频或图像预测来学动力学，却又缺少VLM的语义与推理能力。

做法：UP-VLA把两类目标放进同一个模型：一类是多模态理解任务（看图回答、描述），保留语义；另一类是未来预测，给定当前观测和指令，预测未来的视觉状态，迫使模型关注底层空间细节和物理动态；动作预测与它们联合训练，共享同一套表示。

结果：在长时序语言操作基准CALVIN的ABC→D设置上，比此前最好方法提升33%；真实机器人操作上成功率也有提高，尤其是需要精确空间信息的任务。
