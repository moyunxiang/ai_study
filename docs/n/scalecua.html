ScaleCUA跨平台电脑操作智能体

ScaleCUA: Scaling Open-Source Computer Use Agents with Cross-Platform Data
2025.09论文延伸ICLR 2026 (Oral)Zhaoyang Liu, Jingjing Xie, Zichen Ding, Zehao Li, Bowen Yang, Zhenyu Wu … Yunxiang Mo … Wenhai Wang（共30位） · 上海人工智能实验室待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

开源电脑操作智能体缺训练数据：“截图—动作”轨迹不像图文对那样在网上大量存在，采集和标注都贵；表现好的系统多建立在闭源模型或不公开的数据上。

方法

用“自动智能体探索 + 人类专家录制”的双循环管线，在6个平台上采集界面理解、元素定位和任务轨迹数据，以Qwen2.5-VL为底座训练3B/7B/32B开源模型，跨平台共用一套动作空间。

影响

公开了数据、模型和代码；在网页任务和GUI定位基准上取得当时开源最好成绩，但在OSWorld桌面长任务上仍落后于更大或用了更多轨迹的模型。

背景

2025年，Computer Use、Operator与浏览器智能体和UI-TARS原生GUI智能体已经说明视觉语言模型可以只看截图、输出鼠标键盘动作来操作电脑（智能体循环见智能体循环），但它们要么闭源，要么训练数据不公开。

电脑操作数据难做：网上有海量图文对，却几乎没有记录“看到什么界面、做了什么操作”的轨迹；采集需要真实系统环境，标注需要懂软件的人，而软件和网页更新很快，旧轨迹容易过时。开源社区缺一份规模足够、覆盖多个平台的训练集。

方法

双循环数据管线。第一个循环是智能体与环境交互：为Windows、Ubuntu、macOS、Android、iOS和网页建立统一的观察与执行接口，让自动程序探索界面，并从无障碍树、网页DOM或安卓XML布局中读出元素坐标。第二个循环是人类专家录制目标明确的完整任务。原始数据再由GPT-4o、Claude-3.7等模型标注，整理成三类：界面理解47.1万条（区域描述、OCR、布局理解等），GUI定位1710万条，任务轨迹约1.5万条“弱语义”轨迹（自动探索得到、目标不明确）加4千条目标明确的高层任务轨迹。

模型。以Qwen2.5-VL为底座训练3B、7B、32B三个规模，所有平台共用一套动作（点击、输入、滚动等，加平台专属动作）。同一个模型有三种用法：只做定位（给元素描述返回坐标，供更强的规划模型调用）；直接输出动作；先写一段思考再输出动作。

结果

括号内为步数上限。ScaleCUA-32B在网页基准WebArena-Lite-v2上为44.2%（15步）/47.4%（50步），比最强的原生开源基线UI-TARS-72B-DPO高20.8和26.0分；WindowsAgentArena 15步下24.2%，对方17.9%。GUI定位上ScreenSpot-v2 94.7%、ScreenSpot-Pro 59.2%、OSWorld-G 60.6%。但在OSWorld上ScaleCUA-32B只有16.5%/17.7%，低于UI-TARS-72B-DPO（24.2%/25.2%）和同期的OpenCUA-32B（29.7%/34.1%）。

后来的发展

主要价值是一套公开的跨平台训练数据和可直接替换进“规划模型 + 定位模型”流水线的定位模块。论文自己指出，反思、记忆、分层规划和强化学习都还没有加入，留给后续工作。

容易误解的地方

  • 摘要中的“新纪录”指GUI理解、定位和网页任务；在OSWorld这类桌面长任务上它并不领先。
  • 47.1万、1710万这类数量是“样本条数”，大部分是单步定位样本，完整的多步任务轨迹只有约2万条。

局限与后续

  • 桌面长任务仍然很弱：OSWorld 50步下只有17.7%，macOS基准上32B模型只有7.1%，论文认为差距来自各操作系统特有的交互方式，而不只是定位问题。

它建立在什么之上

  • 竞争
    Computer Use2024.10 · 推理·智能体
    论文把Anthropic的电脑操作模型列为建立在闭源模型和不公开数据上的代表；ScaleCUA走公开数据加开源模型的路线，并用Claude-3.7做数据标注和对比基线。
  • 竞争
    UI-TARS原生GUI智能体2025.01 · 推理·智能体
    同为开源的原生GUI智能体并都用统一动作空间；ScaleCUA强调公开的跨平台数据，在网页和Windows基准上超过UI-TARS-72B-DPO，在OSWorld上则低于它。
  • 使用
    WebArena2023.07 · 数据·评测
    网页评测所用的WebArena-Lite-v2，是论文把源自WebArena本地部署网站的WebArena-Lite改成纯视觉、剔除不可完成任务后的版本。
  • 使用
    OSWorld2024.04 · 数据·评测
    作为Ubuntu桌面任务的在线评测环境之一，也是ScaleCUA成绩最弱的平台。
  • 使用
    Qwen2.5-VL2025.02 · 多模态
    3B、7B、32B三个版本都以Qwen2.5-VL为底座继续训练。

读懂它需要的概念

智能体循环 基准、排行榜与SOTA 预训练与微调 模仿学习与行为克隆 幂律与规模定律

本篇术语

  • GUI定位（grounding）　给一句描述如“设置按钮”，模型要在截图上给出那个元素的像素坐标，落在元素框内算对。
  • 无障碍树（A11y Tree）　操作系统为读屏软件等辅助工具提供的界面结构描述，列出每个按钮、输入框的名称和位置，可用来自动获得元素坐标。
  • 规划—定位组合　一个强的通用模型决定“下一步点哪里”，再由专门的定位模型把这句描述换成屏幕坐标，两者分工完成任务。

怎么学

先读UI-TARS原生GUI智能体和OSWorld，了解截图式电脑操作的基本问题和评测方式。再读ScaleCUA论文第3节（数据管线）和表5（各平台在线评测）。动手：下载开源的ScaleCUA-7B，用定位模式输入一张截图和元素描述，检查输出坐标是否落在目标元素上。
