神经网络依存分析

A Fast and Accurate Dependency Parser using Neural Networks
2014.10论文重要EMNLP 2014Danqi Chen, Christopher D. Manning · 斯坦福大学待核对
ACL Anthology ↗PDF ↗在交互版中打开（演化树、学习进度）

问题

转移式依存分析器靠几百万个人工设计的稀疏组合特征做决策：特征泛化差、模板永远写不全，而且大部分运行时间花在提取特征上。

方法

保留贪心的转移式分析框架，把每一步的决策交给一个小神经网络：栈和缓冲区上48个位置的词、词性、依存标签各查一个稠密向量，经一层立方激活的隐层后用softmax选动作。

影响

第一个在精度和速度上同时胜过传统特征工程分析器的神经依存分析器，开启了神经句法分析的路线。

背景

依存分析要给句子里每个词找到它的“中心词”和关系类型，比如“吃 → 苹果”是宾语关系。2014年主流有两类：MSTParser与MIRA这类基于图的方法在所有可能的树里找最优，准但慢；转移式依存分析这类转移式方法像移进-归约分析器那样从左到右扫一遍，每步只决定一个动作，速度是线性的。

转移式方法的难点在“每一步怎么选动作”。当时的做法是用线性分类器，输入是人工设计的指示特征，比如“栈顶词是‘吃’且缓冲区第一个词的词性是名词”。这些组合特征动辄上百万个，大部分在训练集里只出现几次；模板靠专家经验总写不全；而且有报告称基线分析器99%的时间都花在提取特征上。

方法

转移系统不变。仍用arc-standard系统：一个栈、一个缓冲区，每步在“移进、左弧、右弧”中选一个（带标签就是更多类别），贪心地一步走到底。

分类器换成神经网络。从当前状态取48个元素：栈和缓冲区顶上各3个词、栈顶两个词的最左/最右子节点等共18个词，它们对应的18个词性，以及12个依存弧标签。每个元素查一张表得到50维向量（见嵌入向量），词向量用从零开始的神经NLP的预训练结果初始化，词性和标签向量从头学——于是“名词和代词相近”这类关系也能被学出来。全部拼接后经过一个200维隐层，再接Softmax与logits选动作。

立方激活。隐层用h = (W·x + b)³。展开后自然出现任意三个输入之间的乘积项，相当于让网络自动学习过去人工设计的三元组合特征；实验中它比tanh、sigmoid都好。

预计算加速。对最常见的1万个词，把“词向量×对应权重块”提前算好存表，解析时查表相加即可。训练用AdaGrad和0.5的Dropout。

结果

在英文Penn Treebank（CoNLL依存表示）测试集上UAS 92.0、LAS 90.7，每秒解析1013句；作者自己实现的特征式arc-standard分析器只有89.7/88.3、每秒51句；MaltParser精度约90、每秒500多句；基于图的MSTParser精度相当（UAS 92.0、LAS 90.5），但每秒只有12句。中英文数据上都比特征式贪心分析器高约2个百分点。速度在单核CPU上测得。

后来的发展

它证明了“稠密向量+小网络”可以替代特征工程。谷歌的SyntaxNet全局归一化在它的网络上加了束搜索和全局归一化，缓解了贪心决策一步错步步错的问题；双仿射依存分析改用双向LSTM给每个词编码、再用双仿射打分，回到基于图的方式，精度进一步提升。Universal Dependencies出现后，这类神经分析器被用到上百种语言。今天依存分析多直接在BERT类编码器上做，人工选择的48个位置已不再需要。

读懂它需要的概念

本篇术语

  • 依存分析　给句中每个词指定一个中心词和关系类型，整句构成一棵以谓语为根的树。
  • 转移式分析　用栈和缓冲区模拟分析过程，每一步执行移进或建立依存弧的动作，扫描一遍即得到整棵树。
  • UAS / LAS　无标签/有标签依存准确率：中心词找对的词所占比例；LAS还要求关系类型也对。
