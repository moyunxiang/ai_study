自适应过拟合与可复用holdout

The reusable holdout: Preserving validity in adaptive data analysis
2015.08论文延伸Science 2015Dwork, Feldman, Hardt, Pitassi, Reingold, Roth待核对
arXiv（长版） ↗在交互版中打开（演化树、学习进度）

问题

数据分析是『看结果、改假设、再试』的循环，同一份留出集被反复用来挑模型、调参数，结果会悄悄过拟合到这份留出集上，报告的精度虚高。

方法

把留出集的使用方式改成：只在训练集上的结果与留出集结果差异显著大于噪声时才返回带噪声的答案，用差分隐私的思想限制每次查询泄露的信息。

影响

给『留出集用多了就失效』这一经验问题第一次提供了有理论保证的修补方法，也为排行榜上的过拟合讨论提供了理论依据。

方法

普通做法是：训练集上训练，留出集上打分。但当你根据留出集成绩反复调整模型（或成千上万人提交模型到同一个排行榜）时，留出集的信息逐渐流入模型，成绩不再无偏。

可复用留出集（Thresholdout）的做法：每次查询某个模型的留出集表现时，先比较它在训练集和留出集上的得分。若两者差距在阈值以内，就只返回训练集上的得分，不动用留出集；差距较大时才返回加了噪声的留出集得分，并记一次『预算』。因为大多数查询没有消耗留出集的信息，同一份留出集可以支持远多于传统方式的自适应查询。其理论基础是差分隐私可以限制自适应分析带来的泛化损失。

局限与后续

  • 保证只在查询次数、噪声与阈值这几个参数合适时成立，对深度学习里成千上万次的调参并不直接适用。

    所有人反复在同一个测试集上比较和调参，会产生对测试集的隐性过拟合，排行榜上的进步不一定代表泛化能力的进步。

    Netflix Prize2006.10 · 数据·评测

读懂它需要的概念

本篇术语

  • 差分隐私　一种限制算法输出对任何单个样本依赖程度的数学框架，这里被借来限制『留出集信息泄露给分析者』的量。
