Pick-a-Pic / PickScore

Pick-a-Pic: An Open Dataset of User Preferences for Text-to-Image Generation
2023.05数据集延伸NeurIPS 2023Yuval Kirstain, Adam Polyak, Uriel Singer, Shahbuland Matiana, Joe Penna, Omer Levy · Tel Aviv University / Meta AI / Stability AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文生图的人类偏好数据通常只有大公司能收集，公众拿不到，研究者只能用MS-COCO提示词和FID评测。

方法

自建网页应用，让真实用户边生成图边选出更喜欢的一张，由此公开了Pick-a-Pic数据集，并训练基于CLIP的打分函数PickScore。

影响

提供了第一个大规模开放的真实用户偏好数据，PickScore成为常用的文生图评测与排序指标。

方法

Pick-a-Pic的数据来自一个网页应用：用户输入提示词，系统用不同模型生成图片，用户指出更喜欢哪一张，这些真实提示词与偏好选择被记录下来并公开。作者在此数据上微调CLIP，得到打分函数PickScore，论文称它预测人类偏好的表现达到超人水平。

进一步地，PickScore与人类对模型的排名相关性超过其他自动指标，因此作者建议用它评测未来的文生图模型，并用Pick-a-Pic的提示词替代MS-COCO，因为后者不够贴近真实使用。最后，作者还展示了用PickScore对生成结果排序可以提升现有模型。与ImageReward的区别在于：数据来自开放的真实用户而非专家标注。数据来源模型之一是Stable Diffusion开源。
