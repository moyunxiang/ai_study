隐式Q学习IQL

Offline Reinforcement Learning with Implicit Q-Learning
2021.10论文重要ICLR 2022Ilya Kostrikov, Ashvin Nair, Sergey Levine · UC伯克利待核对
arXiv ↗代码 ↗ar5iv全文 ↗在交互版中打开（演化树、学习进度）

问题

离线RL方法要改进策略，就得问Q函数“数据里没出现的动作值多少”，于是必须用约束或惩罚压住对这些动作的错误估值（BCQ、CQL），既复杂又难调。

方法

训练全程只用数据集里实际出现过的(s, a)：用“期望分位数回归”让V(s)逼近数据中较好动作的价值（而不是平均价值），再用它做Q的TD目标；最后按优势加权的行为克隆提取策略。

影响

在D4RL上达到当时最好的总分，尤其在需要“拼接”轨迹的AntMaze上大幅领先，训练快、易实现、还能直接接着在线微调，成为离线RL最常用的基线之一。

背景

离线RL（见离线强化学习）的核心矛盾在BCQ批量约束Q学习中已经说清：想超过数据就要评估并选择更好的动作，而Q网络对数据外动作的估值不可靠。主流对策都要“查询数据外动作”再加以限制：BCQ批量约束Q学习限制候选动作，离线强化学习CQL主动压低数据外动作的Q值，TD3+BC极简离线RL在策略损失里加行为克隆项。

另一端是完全不查询的“单步”方法：只学行为策略自己的Q值（类似SARSA），再做一步策略改进。它稳定，但只能比数据好一步，无法像动态规划那样把多条轨迹的好片段拼成更好的路线——这在AntMaze这种迷宫导航任务中是关键：数据是在迷宫里乱走的片段，需要拼接才能到达终点。Decision Transformer和行为克隆在这类任务上几乎为0分。

方法

想法：Q学习的目标里有max_a' Q(s', a')，我们想要它，但不能在数据外的a'上取max。换个角度：把同一状态下数据中的各个动作的价值看成一个分布，取它的上分位（接近最大值的那一端），就近似“数据支持范围内的最优动作的价值”，而且只用到数据中的动作。

期望分位数回归（expectile）。损失为

L₂^τ(u) = |τ − 1(u<0)| · u²

τ=0.5时就是普通的均方误差，学到均值；τ接近1时，对低估（u>0）的惩罚远大于高估，学到的就是偏上端的值。

三步训练（全部只用数据中的(s, a, r, s')）：

  • 价值函数：L_V = E[L₂^τ(Q(s,a) − V(s))]，让V(s)成为数据动作Q值的上分位。
  • Q函数：L_Q = E[(r + γV(s') − Q(s,a))²]，用V(s')代替max做自举（见时序差分与自举），无需任何下一动作。
  • 策略提取：L_π = E[exp(β·(Q(s,a) − V(s))) · log π(a|s)]，即优势加权的行为克隆——只模仿数据中的动作，但优势越大权重越高。

前两步交替进行、不涉及策略；策略只在最后提取，不影响价值学习。τ越大越接近Q学习（更积极地拼接），τ=0.5则退化为学行为策略的价值。

结果

D4RL（v2运动控制与v0 AntMaze）总分1070.4，CQL为1002.1、TD3+BC为841.2、Decision Transformer为784.8。AntMaze六个任务总分378.0，CQL 303.6，TD3+BC 163.8，DT 112.2；最难的antmaze-large-play上IQL 39.6、CQL 15.8、DT和行为克隆为0。运动控制任务总分692.4，与CQL的698.5相当。训练时间约20分钟，CQL约80分钟。离线训练后再在线微调100万步，在多数任务上与AWAC、CQL中最好者相当或更好。

后来的发展

IQL的“只在样本内学习”成为离线RL的一条主线，后续不少方法沿用它的价值学习、只替换策略提取部分；由于离线训练后能直接在线微调，它也常被用作“先离线预训练、再在线改进”流程的起点。与此同时，TD3+BC极简离线RL、IQL这类简单方法的强势，也让人反思序列建模路线（如Decision Transformer）在需要拼接的任务上的不足。

容易误解的地方

  • IQL的价值学习不受策略影响，但策略提取的优势加权实际上仍是一种隐式约束，策略不会离数据太远。
  • τ需要按任务选择：论文在运动控制上用τ=0.7、β=3，在AntMaze上用τ=0.9、β=10。τ=0.5对应SARSA，τ→1对应Q学习。

局限与后续

  • 期望分位数会把环境随机性带来的“好运”也当成好动作的价值，在随机转移较强的环境中会过于乐观。

读懂它需要的概念

离线强化学习 时序差分与自举 策略与价值函数 Bellman方程 模仿学习与行为克隆 分布偏移

本篇术语

  • 期望分位数（expectile）　类似分位数但用平方损失定义的统计量：τ=0.5是均值，τ越接近1越接近分布的最大值。
  • 样本内学习　训练中只使用数据集中实际出现过的状态-动作对，从不评估数据外的动作。
  • 优势加权回归　做行为克隆时按exp(β×优势)给每个样本加权，优势越大的动作越被模仿。

怎么学

先读BCQ批量约束Q学习和离线强化学习CQL的讲解，理解为什么要避免数据外动作。读原文第4节（期望分位数与三个损失）和图3（τ对AntMaze的影响）。动手：官方JAX代码很短，在antmaze-medium上把τ从0.5调到0.9，观察成功率变化，体会“拼接”需要多大的τ。
