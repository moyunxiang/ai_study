最小二乘TD（LSTD）

Linear Least-Squares Algorithms for Temporal Difference Learning
1996论文延伸Machine Learning 1996Steven J. Bradtke, Andrew G. Barto · 马萨诸塞大学待核对
Machine Learning ↗在交互版中打开（演化树、学习进度）

问题

线性TD是在线随机梯度，学习慢、需要调步长，数据利用率低。

方法

把线性函数近似下的TD评估写成最小二乘问题，用样本统计量直接解出权重，不需要步长。

影响

TD类算法在数据效率上的一个重要改进，也是LSPI等后续批量方法的基础。

方法

线性函数近似下，TD(0)的不动点满足一组线性方程A·w = b，其中A和b是由特征和转移累积出来的统计量。LSTD不是一小步一小步地走，而是在样本上累积A与b，然后直接求解w = A⁻¹b。递推地更新A的逆，可以每来一个样本就更新一次，复杂度与特征数平方相关。

好处是没有步长，样本利用更充分，在特征维度不大时收敛得快很多。

后来的发展

LSTD的思路被扩展到控制（LSPI）和批量的拟合Q迭代FQI；稀疏大特征下平方复杂度成了瓶颈。

局限与后续

  • 每次更新的代价与特征数的平方成正比，特征很多时不可行。
    后来针对它的工作　梯度TD（GTD/TDC）
  • 只评估固定策略且同策略，没有解决发散问题。
    后来针对它的工作　梯度TD（GTD/TDC）
