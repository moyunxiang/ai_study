VoxelNet点云检测

VoxelNet: End-to-End Learning for Point Cloud Based 3D Object Detection
2017.11论文延伸CVPR 2018Yin Zhou, Oncel Tuzel · Apple待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

激光雷达点云稀疏、无序，以往检测依赖手工设计的鸟瞰图等特征，不能端到端训练。

方法

把空间切成等大的体素，用可学习的体素特征编码层（VFE）把每个体素内的点变成特征，再接3D卷积和区域提案网络。

影响

第一个把点云特征提取和检测合成单阶段端到端网络的工作，开启体素化3D检测路线。

方法

VoxelNet分三部分。第一，特征学习：把点云划分为等间距的3D体素，每个体素里的点用新提出的VFE层处理（逐点特征加上体素内汇聚，思路类似PointNet），得到统一长度的体素特征。第二，3D卷积中间层把这些稀疏体素特征聚合成更大感受野的特征。第三，一个区域提案网络（见Faster R-CNN）在得到的特征图上直接输出3D边框。

整个过程不需要手工特征，可从损失一路反传。论文在KITTI的汽车检测上超过当时的方法（具体数字未核对）。

局限与后续

  • 3D卷积在稠密体素网格上计算量大、速度慢。
    后来针对它的工作　PointPillars
  • 基于锚框的检测头难以处理朝向任意的物体。
    后来针对它的工作　CenterPoint
