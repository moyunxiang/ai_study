Claude Agent SDK

Building agents with the Claude Agent SDK
2025.09系统延伸Anthropic待核对
Anthropic ↗在交互版中打开（演化树、学习进度）

问题

构建智能体要自己写循环、工具、上下文管理，每个团队都重复造轮子。

方法

把驱动Claude Code的那套“智能体外壳”（harness）开放成SDK，核心理念是给智能体一台电脑：能跑命令、读写文件、搜索。

影响

让Claude Code背后的外壳成为通用智能体的基础，也确立了“harness”这个概念在工程上的地位。

方法

Anthropic在2025年9月29日发文，把Claude Code SDK改名为Claude Agent SDK。官方称，Claude Code最初是为提升开发者效率做的编码工具，但它已被用于深度研究、视频制作、笔记等非编码任务，几乎驱动了他们主要的智能体循环；所以驱动它的智能体外壳可以支撑许多别的智能体。

设计原则是“给智能体一台电脑”：让Claude像程序员一样用终端，执行bash命令、编辑和创建文件、搜索文件，由此也能读CSV、查网页、做可视化。文章还介绍了上下文管理（如压缩）、子智能体、以及最佳实践。与Responses API与Agents SDK相比，它没有强调多智能体之间的交接，而是强调单个智能体的通用工具与环境。

局限与后续

  • 让智能体拥有一台电脑意味着权限大、风险高，需要沙箱和权限设计配套。
