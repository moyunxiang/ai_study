无监督神经机器翻译

Unsupervised Machine Translation Using Monolingual Corpora Only
2017.10论文延伸ICLR 2018Lample, Conneau, Denoyer, Ranzato · Facebook AI Research / 索邦大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经翻译需要大量平行句对，低资源语言对根本没有。

方法

把两种语言的句子映射到同一个隐空间，用去噪自编码和迭代回译，只靠单语语料就学会翻译。

影响

首次证明完全不用平行句也能训练出可用的神经翻译，开启无监督机器翻译方向。

方法

用一个共享的编码器和解码器处理两种语言，初始化时借用无平行语料的词翻译MUSE式的跨语言词向量。训练有两个目标：第一，去噪自编码，向句子加噪（丢词、打乱局部顺序）再让模型还原，避免只学会照抄；第二，回译：用当前模型把一种语言译成另一种得到伪平行句，再训练模型从伪译文还原原句，两个方向交替迭代。另外还用对抗损失让两种语言编码后的隐表示难以区分。

摘要称在Multi30k和WMT英法上得到BLEU 32.8和15.1，训练时没有使用任何平行句。

局限与后续

  • 质量远低于有平行语料的监督模型，在远距离语言对上不稳定。

  • 起点依赖词向量对齐，语言差异大时失败。
