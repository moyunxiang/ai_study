UFO Windows界面智能体

UFO: A UI-Focused Agent for Windows OS Interaction
2024.02论文延伸Chaoyun Zhang, Liqun Li, Shilin He, Xu Zhang, Bo Qiao, Si Qin, Minghua Ma, Yu Kang et al. · 微软待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

早期的界面操作智能体大多针对网页或手机，Windows桌面软件种类多、界面复杂，任务还经常要在Word、Excel、浏览器等多个应用之间来回切换。

方法

用两个基于GPT-4V的智能体分工：一个负责挑选该用哪个应用，另一个在应用内部看截图和控件信息、选择具体控件执行操作，并用Windows自带的界面自动化接口直接操控控件。

影响

官方称是第一个专门面向Windows任务完成的UI智能体，开源后持续迭代（后续版本UFO²做成与系统深度集成的桌面智能体），是微软电脑操作智能体研究的主要代码库之一。

方法

UFO把一次用户请求拆给两个角色：

  • 应用选择智能体：看当前桌面截图和打开的窗口列表，决定先去哪个应用，必要时在任务中途切换到别的应用；
  • 应用内操作智能体：在选定的应用里，结合截图和从Windows界面自动化接口拿到的控件信息（按钮、输入框、菜单项的名称与位置），选出要操作的控件和动作。

关键设计是控件交互模块：智能体输出的是“点哪个控件”，由模块通过系统接口直接定位并执行，而不是让模型去猜像素坐标，这样动作落点不需要人工干预就能做到准确，整个流程可以全自动执行。系统还会在删除文件、发送邮件等敏感操作前请用户确认。

作者在9个常用Windows应用上测试，覆盖日常办公的多种场景，定量指标和案例都显示UFO比直接用GPT-4V操作的基线更能完成请求。它与同期的AppAgent手机智能体（手机）、SeeAct（网页）一起，代表了“用通用多模态大模型加上结构化界面信息来操作软件”的路线。
