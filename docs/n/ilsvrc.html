ILSVRC挑战赛

2010事件重要2010–2017年度挑战赛；综述发表于IJCV 2015Olga Russakovsky, Jia Deng, Alexander C. Berg, Li Fei-Fei et al. · 斯坦福、普林斯顿、北卡教堂山等（2010–2012与PASCAL VOC合办）待核对
ILSVRC综述（arXiv 1409.0575） ↗ILSVRC官网 ↗在交互版中打开（演化树、学习进度）

问题

ImageNet有上千万张图，但没人知道该怎么用它统一比较算法；PASCAL VOC只有20类，已不足以区分方法的好坏。

方法

从ImageNet里切出1000个互不重叠的类别、约128万张训练图，测试集答案保密，每年举办分类（后加定位、检测）比赛，按前5错误率排名。

影响

它是深度学习突破发生的考场：2012年AlexNet把冠军错误率从约26%降到约16%，之后五年GoogLeNet、ResNet、SENet接连刷新纪录，直到2017年比赛停办。

背景

ImageNet在2009年发布时规模已远超以往，但要让它真正推动研究，还需要一个大家共同参与的固定任务。当时视觉领域的标准比赛是PASCAL VOC：20个类别、约2万张图，方法在上面拉不开差距。李飞飞团队找PASCAL VOC的组织者合作，从2010年起在ImageNet上办一个大规模版本，用的正是DARPA共同任务框架式的组织方法：公开训练数据、隐藏测试答案、统一指标、每年公布结果。

方法

分类任务（2010年起）。从ImageNet挑出1000个互不重叠的叶子类别，包括大量细粒度类别——例如PASCAL只有一个“狗”类，这里有一百多个狗的品种。2012–2014年使用同一份数据：训练集1,281,167张（每类732–1300张），验证集5万张，测试集10万张。每张图只标一个主要物体类别；因为图里常有别的物体，允许模型给出5个猜测，只要包含正确答案就算对，即前5错误率（见Top-1与Top-5错误率）。

定位与检测。2011年起加入单物体定位：除了类别还要框出物体位置。2013年起加入检测：200个类别，要找出图中所有该类物体并画框，按平均精确率（mAP）计分。

规则。除特设的“可用外部数据”赛道外，只能用官方训练数据；测试结果提交到服务器打分，并限制每队每周最多提交2次，以免针对测试集调参。

结果

前5分类错误率的冠军成绩：2010年NEC（SIFT特征与LBP特征、非线性编码加SVM）28.2%；2011年XRCE（Fisher向量加线性SVM）25.8%；2012年AlexNet（论文中队名SuperVision）16.4%，用额外数据训练的版本15.3%，比第二名低约10个百分点；2013年Clarifai 11.7%，这一年几乎所有队伍都改用卷积网络；2014年GoogLeNet / Inception 6.7%，同年VGG获定位第一。团队还请受过训练的人在同一测试上作答，估计人类错误率约5.1%。按维基百科，2015年ResNet降到3.57%，2017年SENet降到约2.25%。参与规模从2013年的24个团队增长到2014年的36个团队、123份提交。

后来的发展

ILSVRC留下了深度视觉的标准配置：在128万张图的ImageNet-1k上训练、汇报前1/前5准确率，再把网络迁移到其他任务。它的冠军架构基本就是那几年计算机视觉的主干网络演变史。组织者在综述中也总结了三类批评：物体大多居中偏大、标注存在错误、规则过于严格；并预言今后的数据集会大到无法逐张人工标注，算法要更多依赖弱监督。2017年组织者宣布比赛已被“解决”而停办，后续的检测和分割研究转向MS COCO等更难的基准。

容易误解的地方

  • “超越人类”指的是在1000类、前5错误率这个特定设置下超过一位训练过的标注者，并不代表视觉理解超过人类。
  • 定位和检测是另外的赛道；常说的ImageNet成绩只指分类。
  • 2012年AlexNet的15.3%用了额外数据，按官方只用训练集的口径是16.4%。

局限与后续

  • 每张图只评一个主要物体，物体大多大而居中，不能检验在复杂场景中找出、分割多个物体的能力。

  • 同一测试集用了多年，后期名次差距很小，进步中有多少是对测试集的适应难以判断。

  • 1000个类别固定不变，模型只能在这张封闭清单里选，无法识别清单外的概念。

它建立在什么之上

  • 使用
    ImageNet2009.06 · 数据·评测
    从ImageNet中切出1000类、约128万张训练图作为比赛数据。
  • 使用
    DARPA共同任务框架1987 · 数据·评测
    采用共同任务的组织方式：公开训练集、隐藏测试答案、统一指标、年度公布。
  • 使用
    支持向量机1995 · 基础
    2010、2011年冠军的最后一层都是线性或非线性SVM分类器，2012年被卷积网络取代。
  • 使用
    SIFT特征1999 · 视觉
    前两届冠军都建立在SIFT等手工局部特征加编码和SVM的流水线上。
  • 延续
    PASCAL VOC2005 · 数据·评测
    与PASCAL VOC合办前三届，把它的20类比赛扩大到1000类和上百万张图。

读懂它需要的概念

Top-1与Top-5错误率 IoU与mAP 监督学习 训练集、验证集与测试集 基准、排行榜与SOTA

本篇术语

  • 单物体定位　既要给出图中主要物体的类别，又要用矩形框标出它的位置，框与标准框重叠足够多才算对。
  • 细粒度分类　区分同一大类下非常相似的子类，例如不同品种的狗或鸟，靠的往往是很细微的外观差别。
