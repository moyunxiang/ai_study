Magpie无种子指令合成

Magpie: Alignment Data Synthesis from Scratch by Prompting Aligned LLMs with Nothing
2024.06论文延伸ICLR 2025Zhangchen Xu, Fengqing Jiang, Luyao Niu, Yuntian Deng, Radha Poovendran, Yejin Choi, Bill Yuchen Lin · 华盛顿大学、Allen Institute for AI待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

开放权重模型（如Llama-3-Instruct）的对齐数据并不公开；开源的指令数据要么靠人工、成本高，要么靠预先设计的种子提示去引导生成，规模和多样性都受限。

方法

利用对齐模型的自回归特性：只把对话模板里“用户发言开始”之前的部分喂给模型，它就会自己续写出一条像真人提问的用户指令；再把这条指令送回模型得到回答，不需要任何种子问题。

影响

用极低成本从Llama-3-Instruct里“抽出”了数百万条对齐数据，只用其中精选的30万条做SFT就在对齐评测上接近官方指令模型，成为后来许多开源后训练数据集（如SmolTalk）的构造方法之一。

方法

背景：Self-Instruct、Evol-Instruct等方法需要种子任务和精心设计的提示来引导模型出题，生成的问题容易同质化；UltraFeedback AI反馈数据等数据集的提示来自已有数据集。与此同时，Llama 3这样的开放权重对齐模型其实已经在大量私有对齐数据上训练过。

Magpie的观察是：对齐模型的聊天模板形如“系统段 → <用户开始标记> 用户内容 <用户结束标记> → <助手开始标记> 回答”。如果只输入到<用户开始标记>为止，模型会按训练中见过的分布自己续写一段“用户的问题”，因为它学过用户通常会问什么。作者用这个办法从Llama-3-Instruct生成了400万条指令及对应回答，再用模型打分评估难度、质量和类别，筛出30万条高质量样本（Magpie-Pro等子集）。

结果：用Magpie数据只做SFT微调Llama-3-8B-Base，摘要称在部分任务上可与官方Llama-3-8B-Instruct相当——后者用了约1000万条数据做SFT再加反馈学习；只用Magpie做SFT也超过了先前用于SFT加偏好优化的公开数据（如用UltraFeedback做DPO），优势体现在AlpacaEval、ArenaHard、WildBench等对齐评测上。

局限与后续

  • 抽出的数据继承了源模型的能力上限、偏好和安全策略，本质上仍是一种从更强对齐模型蒸馏的方式；数学、代码等需要正确性的任务上回答质量没有保证。

  • 改进
    Self-Instruct2022.12 · LLM

  • 使用
    Llama 32024.04 · LLM
    数据从Llama-3-Instruct中抽取，并在Llama-3-8B-Base上验证。
  • 竞争
    Evol-Instruct2023.04 · LLM
    Evol-Instruct靠提示让模型改写、加深已有指令，Magpie直接从对齐模型的提问分布中采样。
  • 竞争
    UltraFeedback AI反馈数据2023.10 · LLM

读懂它需要的概念

指令微调与对话模板 自回归生成 解码：贪心、束搜索、温度与top-p 知识蒸馏

本篇术语

  • 聊天模板（chat template）　对话模型训练时把系统提示、用户和助手的发言用特殊标记拼成一段文本的固定格式。
  • 预查询模板（pre-query template）　Magpie输入的那段只到“用户发言开始”为止的模板前缀，模型会顺着它写出用户问题。

怎么学

先读Self-Instruct了解指令数据合成；读原文第2节生成流程和第3节数据过滤；动手：用任意开源对话模型的聊天模板，只输入到用户标记为止，采样20次看它会写出哪些问题，再统计主题分布。
