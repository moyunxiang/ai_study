E3B椭圆局内奖励

Exploration via Elliptical Episodic Bonuses
2022.10论文延伸NeurIPS 2022Mikael Henaff, Roberta Raileanu, Minqi Jiang, Tim Rocktäschel · Meta AI / UCL待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RIDE、NovelD等方法在每局不同的环境里有效，关键其实是其中的“按局计数”项；但计数需要判断状态是否相同，在状态空间巨大、带噪声的真实场景里失效。

方法

把局内计数推广到连续空间：用逆动力学模型学一个只保留可控信息的嵌入，按本局已见嵌入的协方差构造一个椭圆，新状态的嵌入离这个椭圆越远，奖励越大（E3B）。

影响

成为MiniHack、Habitat等复杂环境中局内探索的强基线，并把“椭圆奖励”这一来自线性老虎机的工具带进深度探索。

方法

论文先做分析：去掉RIDE、AGAC、NovelD中“按局计数”那一项后，它们在程序化环境里几乎都失效，说明真正起作用的是局内新颖性。但计数只适合离散、少噪声的状态。

E3B（Exploration via Elliptical Episodic Bonuses）的做法：

  • 用逆动力学模型（由 φ(s_t)、φ(s_(t+1)) 预测动作）训练嵌入φ，只保留与智能体动作有关的信息，过滤掉噪声；
  • 每局开始时令 C_0 = λI，每步把当前嵌入加入：C_t = C_(t−1) + φ(s_t)φ(s_t)ᵀ；
  • 内在奖励是椭圆范数：b(s_t) = φ(s_t)ᵀ C_(t−1)^(−1) φ(s_t)。

当φ是独热向量时，这个奖励退化为 1/(N+λ)，正是按局计数；一般情况下，它衡量新嵌入在本局已见嵌入张成的方向上有多“新”，与LinUCB上下文老虎机等线性老虎机里的置信椭圆是同一个量。协方差的逆可以用Sherman–Morrison公式每步增量更新。

摘要称E3B在MiniHack的16个困难任务上取得新的最好成绩，不需要针对任务的归纳偏置；在稀疏奖励的像素VizDoom上与现有方法相当，在Habitat的无奖励探索上优于现有方法。

局限与后续

  • 只奖励局内新颖性，不跨局累积，对需要长期系统性覆盖整个环境的任务帮助有限。

读懂它需要的概念

探索与利用 协方差矩阵 嵌入向量 奖励设计与奖励投机

本篇术语

  • 椭圆奖励（elliptical bonus）　φᵀC⁻¹φ：新特征在已见特征协方差下的“马氏长度”，方向越少见值越大。
  • 逆动力学模型　根据前后两个状态预测中间执行了什么动作的模型。
