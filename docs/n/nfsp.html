神经虚拟自我对弈NFSP

Deep Reinforcement Learning from Self-Play in Imperfect-Information Games
2016.03论文延伸Heinrich, Silver · UCL / DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

不完全信息博弈（如扑克）的做法是先手工做抽象，再用反事实遗憾最小化CFR这类算法在抽象博弈里求纳什均衡，依赖大量领域知识。

方法

把虚拟自我对弈（fictitious self-play）与深度RL结合：一个网络用RL学对对手平均策略的最佳反应，另一个网络用监督学习记住自己过去的平均策略。

影响

第一个不依赖领域知识、端到端学习近似纳什均衡的可扩展方法，打开了深度RL做扑克类游戏的路线。

方法

虚拟自我对弈的原理是：每个玩家反复对对手的历史平均策略做最佳反应，在许多博弈里平均策略会趋向纳什均衡。NFSP用神经网络实现这两部分。

每个智能体有两个网络：RL网络用DQN（Nature版）式的拟合Q学习，从自己的经验回放里学出对当前对手的最佳反应；监督网络则从自己过去的行动记录里学一个「平均策略」。玩的时候，智能体以一定概率用最佳反应、否则用平均策略出牌，所以对手面对的是一个正在逼近均衡的混合策略。摘要称在Leduc扑克上NFSP逼近了纳什均衡，而常见的RL方法发散；在真实规模的有限注德州扑克中，学到的策略接近当时最先进、依赖大量领域知识的超人算法。

局限与后续

  • 在大型博弈里离均衡仍有差距，收敛靠经验而没有强理论保证。

  • 训练样本量很大，样本效率不及基于CFR的方法。

它建立在什么之上

  • 竞争
    反事实遗憾最小化CFR2007 · RL
    CFR路线需要抽象与遍历博弈树；NFSP用采样加神经网络，后来Deep CFR把两条路线合并。
  • 使用
    DQN（Nature版）2015.02 · RL
    最佳反应网络用DQN式的回放和目标网络训练。
  • 改进
    纳什均衡1950 · RL
    在不手工抽象博弈的前提下逼近纳什均衡。
  • 改进
    马尔可夫博弈1994 · RL
    表格形式，状态多了无法使用。

后来的相关工作

  • 改进
    DeepStack2017.01 · RL
    训练样本量很大，样本效率不及基于CFR的方法。

    PSRO博弈论元求解2017.11 · RL
    NFSP是神经网络版的虚拟对弈；PSRO把虚拟对弈当作元求解器取“历史均匀混合”时的特例，推广成可换元求解器的框架。
