Gated DeltaNet

Gated Delta Networks: Improving Mamba2 with Delta Rule
2024.12论文重要ICLR 2025Songlin Yang, Jan Kautz, Ali Hatamizadeh · MIT CSAIL / NVIDIA来源已核对
arXiv ↗官方代码 ↗前作：DeltaNet的并行训练算法 ↗在交互版中打开（演化树、学习进度）

问题

线性注意力和Mamba2把上下文压进固定大小的状态矩阵，记得多了就互相覆盖；Mamba2只能把所有记忆一起按比例遗忘，DeltaNet能精确改写单条记忆却清不掉旧内容。

方法

把两种机制合成“门控delta规则”：S_t = α_t·S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ，α_t负责整体快速清空，delta项负责按键精确替换，并给出可在GPU上分块并行训练的算法。

影响

1.3B参数、100B token的同条件对比中，语言建模和检索都超过Mamba2和DeltaNet；后被Qwen3-Next采用，并被Kimi Linear扩展为KDA。

背景

线性注意力把注意力改写成RNN：维护一个状态矩阵S（d_v×d_k），每读到一个token就“写入”S ← S + v kᵀ，查询时“读出”o = S q。生成每个token的代价固定，不像softmax注意力那样随上下文变长（见稀疏注意力与高效注意力）。但S能存的近似正交的键值对最多只有约d_k条，序列一长，新旧记忆叠加在一起，检索就不准了。

两种补救各有短板。Mamba-2与状态空间对偶加入衰减S ← α_t S + v kᵀ，α_t∈(0,1)是随输入变化的标量（RetNet用固定衰减、门控线性注意力GLA用按维度的门控衰减，思路类似），但它让所有记忆按同一比例淡化，想忘掉某一条就得连带忘掉全部。DeltaNet源于快速权重一脉，用delta规则精确改写某个键对应的值，合成检索任务很强，但一次只改一条，遇到话题切换清不掉旧内容，在真实数据上表现一般。

方法

delta规则是什么。把状态看作一个线性的“键→值”查找表，希望S k_t ≈ v_t。对损失½‖S k_t − v_t‖²做一步学习率为β_t的梯度下降，得到

S_t = S_{t−1} − β_t (S_{t−1} k_t − v_t) k_tᵀ = S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ

这正是ADALINE与LMS的Widrow–Hoff最小均方规则。例子：若单位长度的键k原来存着v_old，取β=1写入v_new，则S_t k = v_old − v_old + v_new = v_new——只替换这一格，与k正交的其他记忆不受影响。普通线性注意力则会得到v_old + v_new的混合。

门控delta规则：

S_t = S_{t−1}·α_t(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ

α_t→0时整块记忆被清空，α_t→1时退化为纯delta规则。α_t、β_t都由当前输入经线性层算出，α沿用Mamba2的参数化。

怎么并行训练。逐步递推无法利用GPU。作者沿用前作的做法：把序列切成长度C的块，块内把一串(I − β k kᵀ)的乘积用WY表示压缩成几次矩阵乘法，再乘上块内累积的衰减；块与块之间只传递状态S。计算主要是矩阵乘法，能用上张量核。

层结构与混合。q、k经线性投影、短卷积、SiLU和L2归一化；输出再经归一化和门控。混合版H1把它与滑动窗口注意力（SWA，见Longformer滑窗注意力）交替，H2再加入Mamba2层。

结果

所有模型均为1.3B参数，用FineWeb-Edu的100B token在相同设置下训练。WikiText困惑度：Gated DeltaNet 16.42，Mamba2 16.56，DeltaNet 17.71，Transformer++ 18.53；常识推理平均准确率55.32，高于Mamba2的54.89；混合版H1为56.40。大海捞针S-NIAH-1在8K长度上为91.8%，Mamba2只有30.4%；S-NIAH-2在4K上为92.2%，DeltaNet掉到18.6%。截断到2K的真实检索任务平均30.6，仍低于Transformer++的37.0，而H2达到40.1。训练吞吐与DeltaNet基本相同，因转移矩阵更复杂，比Mamba2略慢。

后来的发展

Qwen3-Next混合注意力把Gated DeltaNet与门控注意力混合，作为线性注意力层进入主流模型系列；作者仓库称后续的Qwen3.5原生多模态也在使用。Kimi Linear把整头共用的α换成每个特征维度各自的遗忘率（KDA），以3:1与全注意力MLA混合，官方称在相同训练配方下超过纯全注意力，1M上下文时KV缓存最多减少75%、解码吞吐最高提升6倍。

容易误解的地方

  • “线性”指计算和状态随序列长度线性（推理时为常数），不是说模型没有非线性；状态更新对S是线性的，非线性来自层间的前馈网络和门控。
  • 纯Gated DeltaNet在真实检索上仍不如Transformer，论文里最好的结果来自与注意力的混合版本。
  • delta规则中键必须先做L2归一化，否则I − β k kᵀ可能放大状态导致发散。

局限与后续

  • 状态大小固定，纯线性模型在需要逐字找回长上下文内容的真实检索任务上仍明显落后全注意力，只能靠混合注意力层弥补。
    后来针对它的工作　Qwen3-Next混合注意力 Kimi Linear
  • 遗忘率α_t是每个头一个标量，所有特征维度一起衰减，不能只忘掉部分通道。
    后来针对它的工作　Kimi Linear
  • 只在1.3B参数、100B token规模上验证，能否在百亿参数级的生产模型中替代大部分注意力层未知。
    后来针对它的工作　Qwen3-Next混合注意力 Kimi Linear
  • 分块并行算法比注意力复杂得多；在2K这样的短上下文上，FlashAttention加持的Transformer训练吞吐仍最高。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    ADALINE与LMS1960 · 基础 已核对
    状态更新就是Widrow–Hoff最小均方规则：对键值回归损失做一步梯度下降。
  • 延续
    快速权重1992 · 基础 已核对
    DeltaNet把线性注意力看作快速权重编程器并引入delta更新；本文给它加上门控遗忘。
  • 延续
    线性注意力2020.06 · 基础 已核对
    仍是“状态矩阵写入键值外积、用查询读出”的线性注意力，只是把累加改成带门控的delta更新。
  • 竞争
    门控线性注意力GLA2023.12 · LLM 已核对
    GLA用数据相关的门控衰减改进线性注意力，但没有delta规则的定点改写；两者都采用分块并行训练。
  • 改进
    Mamba-2与状态空间对偶2024.05 · 基础 已核对
    Mamba2的标量衰减只能让所有记忆一起淡化；加入delta项后可以按键精确替换，检索和困惑度都超过Mamba2。
  • 竞争
    测试时训练层TTT2024.07 · 基础 已核对
    两者都把状态更新理解为在线学习一步；TTT用更复杂的隐状态模型，Gated DeltaNet保持线性状态以便高效并行。
  • 使用
    Longformer滑窗注意力2020.04 · LLM 待核对
    混合版本H1、H2用滑动窗口注意力补足局部比较和精确检索能力；这种局部窗口注意力Longformer已系统使用，但本文没有引用Longformer。
  • 改进
    LSTM遗忘门1999.09 · 基础
    每一步都依赖上一步，序列内部无法并行；整段历史压进固定大小的状态，遗忘门只能整体衰减，不能精确改写某一条记忆。
  • 改进
    线性注意力即快速权重2021.02 · 基础
    固定大小的状态在序列很长时仍会遗忘或冲突，无法与完整注意力的精确检索相比。
  • 改进
    RWKV2023.05 · 基础
    固定大小的状态无法精确回忆长上下文里的细节，在检索与复制类任务上落后于注意力。
  • 改进
    Mamba状态空间模型2023.12 · 基础
    固定大小的状态在需要精确检索的任务上仍弱于注意力，实践中常与注意力混合。
  • 改进
    DeltaNet并行训练2024.06 · 基础
    纯线性递归的状态大小固定，需要精确回溯全文的任务上仍不如完整注意力，需要混合层。

读懂它需要的概念

自注意力与多头注意力 稀疏注意力与高效注意力 循环网络与隐状态 状态空间模型与线性RNN 门控机制 梯度下降 KV缓存

本篇术语

  • delta规则　按“预测值与目标值之差”修正参数的学习规则；用在状态矩阵上，就是把某个键原来对应的值替换成新值。
  • 记忆碰撞　状态容量有限，存入的键值对太多时彼此叠加，查询时得到几条记忆的混合。
  • WY表示　把多个“单位矩阵减秩1矩阵”的连乘写成紧凑的矩阵形式，使原本逐步的计算变成几次矩阵乘法。
  • 滑动窗口注意力（SWA）　每个token只与前面固定长度窗口内的token做注意力，代价随长度线性增长。

怎么学

先补自注意力与多头注意力和稀疏注意力与高效注意力，读懂线性注意力的“状态矩阵”视角和Mamba-2与状态空间对偶的衰减。读原文第2节（线性注意力、Mamba2与DeltaNet的对比）、第3.1节公式(10)与表1的在线学习视角、第3.2节S-NIAH案例。动手：用numpy分别实现累加、衰减、delta三种更新，向d_k=16的状态写入32个随机键值对后再查询，比较检索误差；再试用flash-linear-attention库中的实现。
