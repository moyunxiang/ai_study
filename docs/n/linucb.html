LinUCB上下文老虎机

A Contextual-Bandit Approach to Personalized News Article Recommendation
2010.02论文重要WWW 2010Lihong Li, Wei Chu, John Langford, Robert E. Schapire · Yahoo! Labs / 普林斯顿大学待核对
arXiv ↗ACM DL ↗ar5iv全文 ↗在交互版中打开（演化树、学习进度）

问题

新闻首页的文章池每小时都在换，新文章没有历史点击，协同过滤用不上；不看用户特征的老虎机算法又只能给所有人推同一篇，无法个性化。

方法

假设点击率是用户/文章特征的线性函数，用岭回归估计系数，再给每篇文章加上一个由协方差矩阵算出的闭式置信上界，选“估计值+不确定性”最大的那篇。

影响

把置信上界原则从独立的几个臂推广到带特征的上下文老虎机，成为推荐和广告里在线探索的标准基线；同时给出一种只用随机日志就能无偏离线评估老虎机算法的方法。

背景

2009年的雅虎首页Today模块，每次给访客突出展示一篇文章，候选来自编辑每小时刷新的小文章池。目标是让点击尽量多，但新文章刚上线时谁也不知道它的点击率——这正是探索与利用问题。

当时的常见做法是切出一小部分流量随机推文章（探索），在其余流量上推点击率最高的（利用），即ε-贪心。UCB1这类上下文无关的老虎机能更聪明地分配探索，但它对每个用户给出同一个答案，没法利用“这个人是谁”。协同过滤（Netflix Prize时代的主流）依赖大量历史评分，对不断进出的新文章无能为力。如果按用户分群、每群各跑一份老虎机，数据又被切碎了。

方法

上下文老虎机：每一轮先看到用户和候选文章的特征向量x_{t,a}，选一篇，只观察到这一篇是否被点击（奖励1或0），没选的文章得不到任何反馈。

线性假设：E[r | x] = xᵀθ_a。对每篇文章a维护A_a = DᵀD + I和b_a = Dᵀc（D是展示过的特征矩阵，c是对应的点击），岭回归（见岭回归与L2正则）给出θ̂_a = A_a⁻¹ b_a。

选择规则：

a_t = argmax_a [ x_{t,a}ᵀθ̂_a + α·√(x_{t,a}ᵀ A_a⁻¹ x_{t,a}) ]

第二项是置信区间半宽：沿x这个方向见过的数据越多，xᵀA⁻¹x越小。例如单位长度的x，若文章已对完全相同特征的用户展示过n次，则A = I + n·xxᵀ，xᵀA⁻¹x = 1/(1+n)：新文章的加成是α，展示99次后降到α/10。选中后只需A_a += xxᵀ、b_a += r·x，计算量与文章数成线性、与特征维数至多立方。

混合模型：再加一项所有文章共享的zᵀβ，一篇文章的点击信息能通过β迁移到其他文章，数据稀少时更有用。

离线评估：日志里文章是均匀随机推的。按顺序回放，只有当待评估算法选的文章恰好等于日志里那篇时才保留这条事件并更新算法，否则跳过。论文证明这样得到的历史与真实在线运行同分布，保留T条平均要消耗K·T条日志（K为候选数）。

结果

数据是2009年5月雅虎首页随机流量：5月1日约470万次事件用来调参，5月3–9日约3600万次用来评估。用户特征由双线性逻辑回归加k-means从1193维原始特征压成6维。点击率按随机策略归一化后，用全部数据时LinUCB（独立模型）在部署桶达到1.795，比ε-贪心的1.596高12.5%；只给算法1%数据时，混合模型LinUCB比ε-贪心高20.1%（部署桶）和27%（学习桶），数据越少优势越大。

后来的发展

次年本文第一作者与Chapelle在Thompson采样的复兴中用模拟和真实数据表明，用后验采样替代置信上界同样很有竞争力，而且实现更简单。作者次年在WSDM上专门发表了这套回放评估方法，它成为老虎机和推荐领域离线评估的常用做法。把推荐当作多步决策、用策略梯度和离策略修正来训练的路线后来出现在YouTube REINFORCE推荐中。

容易误解的地方

  • 12.5%是相对ε-贪心的点击提升，不是相对随机推荐。
  • 论文的Õ(√(KdT))遗憾界只是说“可以改编已有分析得到”，并未在文中给出完整证明。
  • 实验里LinUCB（独立模型）与“分群后各跑UCB”几乎一样好，作者解释是因为特征本身就是5个簇的软隶属度，大多数用户明显属于某一簇。

  • 使用
    逻辑回归1958 · 基础
    用双线性逻辑回归在2008年的随机流量上学出用户对文章类别的偏好，再聚类得到6维特征。
  • 延续
    UCB12002 · RL
    把“均值+置信区间半宽”的乐观选择从互相独立的几个臂推广到带特征的线性模型，置信区间由岭回归的协方差矩阵闭式给出。
  • 竞争
    Netflix Prize2006.10 · 数据·评测
    协同过滤依赖用户对同一物品的大量历史反馈，对每小时更新的新闻池不适用；LinUCB靠内容特征和在线探索解决冷启动。
  • 延续
    多臂老虎机问题1952 · RL
    在Robbins的多臂老虎机问题上增加了每轮可见的上下文特征和动态变化的臂集合。
  • 使用
    岭回归与L2正则1970 · 基础
    每篇文章的系数用加了单位阵正则的岭回归估计，A = DᵀD + I同时充当不确定性的度量。
  • 改进
    Gittins指数1979 · RL
    要求各臂相互独立，且是折扣无限期的情形；臂之间有关联或环境会变化时不再最优。
  • 竞争
    对抗老虎机EXP32002 · RL
    EXP3针对奖励可被任意安排的对抗环境、靠随机化和重要性加权；LinUCB假设奖励随机且对特征线性，换来更快的学习。

读懂它需要的概念

探索与利用 线性回归 正则化与权重衰减 向量、矩阵与张量 期望与方差 重要性采样

本篇术语

  • 上下文老虎机　每一轮先看到描述当前情境（用户、候选物品）的特征再做选择、只得到所选动作的奖励的老虎机问题；动作不影响后续情境，所以比完整的强化学习简单。
  • 点击率CTR　点击次数除以展示次数。把点击记为奖励1，一篇文章的期望奖励就是它的点击率。
  • 回放评估　用均匀随机策略收集的日志离线评估新算法：只保留新算法的选择与日志一致的事件。因为日志里每个选项被选的概率相同，留下的样本与真实在线运行同分布。

怎么学

先读UCB1弄清置信上界，再复习线性回归与岭回归的闭式解。读原文第2节（问题定义）、3.1节（算法1）和第4节（回放评估与定理1）。动手：生成一个特征线性的模拟点击环境，实现算法1和回放评估器，比较ε-贪心、UCB1与LinUCB的累计点击，并观察α过大、过小时的倒U形曲线。
