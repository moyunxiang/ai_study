ON-LSTM有序神经元

Ordered Neurons: Integrating Tree Structures into Recurrent Neural Networks
2018.10论文延伸ICLR 2019（最佳论文）Yikang Shen, Shawn Tan, Alessandro Sordoni, Aaron Courville · 蒙特利尔大学Mila、微软研究院蒙特利尔待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自然语言有层级结构：短语嵌在从句里，大的成分结束时里面的小成分也一定结束；标准LSTM的各个神经元互相平等，没有这种层级的归纳偏置。

方法

给神经元排序：用累积softmax得到「主遗忘门」和「主输入门」，保证排在后面的高层神经元一旦被更新，排在它前面的低层神经元也一起被更新，于是高层神经元存活得久、对应大成分，低层神经元变化快、对应小成分。

影响

只用语言建模目标训练，就能从门控值中读出与人工标注相当接近的成分树，在无监督成分分析上取得当时的强结果，获ICLR 2019最佳论文。

背景

LSTM（LSTM）的遗忘门让不同神经元可以记住不同长短的信息，但哪个神经元记多久完全由数据决定，没有任何先验告诉它「句子是一层套一层的」。另一边，无监督文法归纳（如DMV无监督依存分析）需要专门设计的生成式模型和EM训练。RNNG循环神经网络文法把句法显式加进语言模型，但需要标注树。作者想要一个仍然只做语言建模、却天然偏好层级结构的循环网络。

方法

核心是累积softmax：cumax(z) = cumsum(softmax(z))，输出一个从0单调增到1的向量，可以看成「分界点落在第k个神经元」这一离散选择的连续松弛。

在第t步，模型算两个这样的向量：

  • 主遗忘门 f̃_t = cumax(W_f̃ x_t + U_f̃ h_{t−1} + b)，从低到高单调递增；
  • 主输入门 ĩ_t = 1 − cumax(W_ĩ x_t + U_ĩ h_{t−1} + b)，从低到高单调递减。

二者的重叠部分 ω_t = f̃_t ⊙ ĩ_t 与普通LSTM的遗忘门、输入门结合，更新细胞状态：在主遗忘门接近0的低位神经元上，旧信息被整体抹掉、换成新输入；在主遗忘门接近1的高位神经元上，旧信息被保留。直观地说，读到一个词时，如果模型判断「一个很大的成分在这里结束了」，分界点就会落得很高，连同其中所有小成分的信息一起被清空。

读出句法树。 每个词的主遗忘门给出一个「分界深度」 d_t = n − Σ_k f̃_tk。把这些深度当作相邻词之间的「切分强度」，自顶向下在深度最大处递归切分句子，就得到一棵二叉成分树。

结果

摘要称ON-LSTM在语言建模、无监督成分分析、定向句法评测和逻辑推理四个任务上都表现良好。

后来的发展

它与同期的PRPN（同一作者组的前作）、Kim等2019年的Compound PCFG一起推动了「从语言模型诱导句法」的研究热潮；后来的StructFormer等把同样的思想搬到Transformer上。也有工作指出这类模型诱导出的树偏向右分支、对评测设置敏感，提醒结果要谨慎解读。

局限与后续

  • 诱导出的树只是二叉、无标签的结构，且有偏向右分支的倾向，与语言学树的一致性有限。

它建立在什么之上

  • 延续
    LSTM1997 · 基础
    在LSTM的遗忘门和输入门之上加了单调有序的主门控，给神经元赋予层级。
  • 使用
    Penn Treebank1993 · 数据·评测
    在宾州树库上训练语言模型，并用其标准树评测诱导出的成分结构。
  • 竞争
    DMV无监督依存分析2004.07 · NLP
    DMV用专门的生成式依存模型和EM做文法归纳，ON-LSTM则只训练语言模型，从门控中读出成分树。
  • 改进
    RNNG循环神经网络文法2016.02 · NLP
    RNNG把句法加进语言模型但需要标注树，ON-LSTM不用任何树标注就学出层级结构。

读懂它需要的概念

循环网络与隐状态 门控机制 Softmax与logits 语言模型 归纳偏置

本篇术语

  • 累积softmax（cumax）　先做softmax再累加，得到一个从0到1单调上升的向量，用来平滑地表示「在哪个位置分界」。
  • 无监督成分分析　不用任何标注树，只从原始文本中推断短语结构，用与人工树的F1重合度评测。

怎么学

先熟悉LSTM的门控公式 → 读原文第4节的cumax与主门控、第5.2节的树读出算法 → 动手：拿官方代码训练一个小模型，把一句话每个词的分界深度画成柱状图，再手动按最大值递归切分，看得到的树是否合理。
