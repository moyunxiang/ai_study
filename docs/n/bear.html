BEAR自举误差约束

Stabilizing Off-Policy Q-Learning via Bootstrapping Error Reduction
2019.06论文延伸NeurIPS 2019Aviral Kumar, Justin Fu, George Tucker, Sergey Levine · UC Berkeley / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

在固定数据集上做Q学习或演员-评论家（离线RL）时，贝尔曼备份会去查询数据里从没出现过的动作的Q值，这些值的估计误差会被一轮轮放大。

方法

指出「自举误差」是不稳定的主要来源，并在备份时约束策略只选在行为数据的支撑集内的动作：用最大均值差异（MMD）限制策略分布不偏离数据分布的支撑。

影响

和BCQ批量约束Q学习一起奠定了「策略约束」类离线RL方法，提出的自举误差概念和支撑约束被离线强化学习CQL、D4RL离线RL基准基准等后续工作反复引用比较。

方法

Q学习的目标是 r + γ max_a′ Q(s′, a′)。离线时，数据里每个状态只出现过少数几个动作；max会去挑那些从没见过的动作，而网络在这些动作上的Q值是随意外推的，很可能偏高。偏高的值又被当作下一轮的目标，误差沿着贝尔曼备份累积——这就是摘要所说的自举误差。

论文从理论上分析了这种误差，指出关键是限制备份时选择的动作。BCQ批量约束Q学习用生成模型把动作限制在数据附近，相当于约束策略的分布接近行为分布；BEAR认为更合适的是只约束支撑集：策略可以在数据里出现过的动作之间自由重新分配概率，但不能把概率放到数据没有覆盖的动作上。这样即使数据来自很差的策略，也能从中挑出好的动作。

实现上，BEAR在一个类似TD3的演员-评论家框架里，用多个Q网络的集成估计保守的目标值，并在策略优化时加上约束：策略与行为策略样本之间的MMD小于一个阈值。摘要称，BEAR能从包括随机数据和次优示范在内的各种离策略分布中稳健学习，在一系列连续控制任务上验证。

本篇术语

  • 自举误差　用网络自己在没见过的动作上的错误估计作为学习目标，误差被一轮轮放大。
  • 最大均值差异（MMD）　用核函数比较两组样本分布差异的指标，值越小说明两个分布越接近。
  • 支撑集　一个分布中概率大于零的那些取值。
