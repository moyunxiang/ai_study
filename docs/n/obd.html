最优脑损伤OBD剪枝

Optimal Brain Damage
1989.11论文重要NIPS 1989Yann LeCun, John S. Denker, Sara A. Solla · AT&T贝尔实验室待核对
NeurIPS论文页 ↗在交互版中打开（演化树、学习进度）

问题

网络越大越难泛化、越慢，但删掉哪些权重才不伤性能？最直接的“删掉绝对值小的权重”没有理论依据，常常删错。

方法

用损失函数的二阶导数估计“删掉某个权重会让训练误差上升多少”，按这个“显著性”从小到大删，删完再重新训练，反复进行。

影响

第一次给剪枝一个可计算的、基于损失曲率的准则。它开启的“按二阶信息判断参数重要性”路线一直延续到今天大模型的剪枝与量化。

背景

1980年代末，用反向传播训练的网络开始用于真实任务，例如卷积网络识别邮编的手写数字识别网络。网络参数一多，就需要更多训练样本才能泛化（这与VC维与一致收敛给出的直觉一致），推理也更慢。一个自然的想法是训练完再删掉“不重要”的连接，但“不重要”怎么定义？

当时常见的做法是删掉绝对值最小的权重。问题是：一个权重很小，但如果损失对它非常敏感（曲率大），删掉它的代价可能比删掉一个大但无关紧要的权重还高。缺的是一个直接衡量“删掉它会让误差变多少”的指标。

方法

把训练误差E在当前参数附近做泰勒展开（见泰勒展开）。参数改变δu时：

δE ≈ Σ gᵢ·δuᵢ + ½ Σ hᵢᵢ·δuᵢ² + ½ Σ_{i≠j} hᵢⱼ·δuᵢ·δuⱼ

其中g是梯度、h是海森矩阵（见雅可比矩阵与海森矩阵）的元素。论文做三个近似：

  • 极值近似：训练已收敛，梯度g ≈ 0，第一项去掉。
  • 二次近似：更高阶项忽略。
  • 对角近似：删除多个参数造成的误差增量等于各自增量之和，交叉项hᵢⱼ忽略。

于是把参数u_k置零（δu_k = −u_k）的代价就是它的显著性：s_k = h_kk·u_k² / 2。它同时考虑了权重大小和损失在这个方向上的弯曲程度：一个权重u = 0.1但h = 100，s = 0.5；另一个u = 1但h = 0.1，s = 0.05，后者反而更该删。

对角元素h_kk可以用一次类似反向传播的逐层回传算出，代价与求一次梯度同量级（推导中又忽略了一部分难算的二阶项）。整个流程：训练到收敛 → 算每个参数的显著性 → 删掉最小的一批 → 重新训练 → 重复。

论文在作者的手写数字识别网络上验证：论文图中把按显著性删除与按幅值删除对比，前者在删去同样多参数时误差上升得更慢；删除后重新训练，网络可以在参数明显减少的情况下保持原有精度。

后来的发展

三年后的最优脑外科OBS指出对角近似过强——删掉一个权重后，其余权重应当协同调整来补偿——于是用完整海森矩阵的逆来同时计算删除哪个和如何更新其余权重。这条二阶路线后来进入大模型：GPTQ训练后量化用OBS式的逐列更新做量化，SparseGPT一次性剪枝用它一次性剪掉大模型一半权重。

另一方面，剪枝与量化压缩在2015年证明，在现代大网络上简单的按幅值剪枝加重训就能把AlexNet、VGG压缩很多倍，二阶信息并非总是必要；彩票假说则把剪枝变成研究“稀疏子网络为什么能训好”的工具。

容易误解的地方

  • 显著性只是对误差增量的近似：远离极小点、或一次删掉很多相关参数时，对角和二次近似都会失效，所以必须分批删、每批之后重训。
  • 论文里的“参数”指独立的自由参数；在权重共享的卷积网络里，删一个参数等于同时删掉很多条连接。
  • 删掉权重并不自动带来加速：零散分布的零在普通硬件上仍按稠密矩阵计算，需要结构化剪枝或稀疏硬件才能真正变快。

局限与后续

  • 对角近似忽略了参数之间的耦合，删掉一个权重后不调整其余权重来补偿，剪得多时误差估计偏差大。
    后来针对它的工作　最优脑外科OBS
  • 每删一批都要重新训练，网络一大，“训练—删除—重训”的循环代价很高。
    后来针对它的工作　SparseGPT一次性剪枝
  • 只删单个权重，得到的是不规则稀疏，在通用硬件上很难转化成实际的速度和存储收益。

读懂它需要的概念

反向传播 泰勒展开 雅可比矩阵与海森矩阵 损失函数 泛化与过拟合 参数量、计算量与显存

本篇术语

  • 剪枝（pruning）　训练后删掉网络中一部分权重或神经元（置零或移除），以减小模型、加快推理，通常删完要再训练一会儿恢复精度。
  • 显著性（saliency）　OBD里删除某个参数会让训练误差增加多少的二阶估计，s = h·u²/2，越小越可以删。

怎么学

先补泰勒展开和雅可比矩阵与海森矩阵，理解为什么在极小点附近损失近似是二次函数。然后读原文第2、3节的推导。动手：在MNIST上训一个小MLP，分别按幅值和按h·u²（对角海森可以用PyTorch对每个参数做二次反向近似估计）删掉50%、80%、90%的权重，画出误差曲线对比。
