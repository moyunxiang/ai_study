离散扩散语言模型SEDD

Discrete Diffusion Modeling by Estimating the Ratios of the Data Distribution
2023.10论文重要ICML 2024Aaron Lou, Chenlin Meng, Stefano Ermon · 斯坦福大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

扩散模型在图像上大获成功，但用在文字这类离散数据上效果一直远不如自回归模型：连续扩散的“分数”（梯度）在离散空间里没有定义，已有离散扩散方法困惑度差距很大。

方法

把“分数”换成离散版本——只差一个token的两个序列的概率之比p(y)/p(x)，并提出一个专门学这种比值的损失“分数熵”，在此基础上构建离散扩散语言模型SEDD。

影响

第一个在同等规模下与GPT-2困惑度相当、多数数据集上更好的扩散语言模型，生成时不需要温度调节就能写出质量更高的文本，为后来的MDLM、LLaDA等扩散大语言模型铺平了道路。

背景

GPT-2这类自回归模型一次只能从左到右生成一个token。扩散模型（见扩散：前向加噪与反向去噪）则是先逐步给数据加噪，再学习逐步去噪，可以并行修改所有位置、天然支持“填中间”。在连续数据上，分数匹配生成模型学习的是对数密度的梯度∇log p(x)，即“分数”（见分数函数与分数匹配）。

文字是离散的，没有梯度可言。Diffusion-LM和Plaid似然扩散LM把token映射到连续嵌入向量再扩散，需要取整和许多经验技巧。离散扩散D3PM直接在离散状态上定义加噪过程（例如把token随机替换或变成[MASK]），并模仿图像扩散去预测原始数据，但困惑度远差于同规模的自回归模型。

方法

离散加噪。每个token独立地按一个转移速率矩阵演化。论文主要用两种：

  • 吸收型：token以一定速率变成特殊的[MASK]符号，加噪到最后整句全是[MASK]，类似BERT的掩码；
  • 均匀型：token随机换成词表中的任意词。

具体分数。在离散空间里用比值代替梯度：对序列x和只在一个位置上不同的序列y，模型s_θ(x, t)_y估计p_t(y)/p_t(x)。知道了这些比值，就知道“把这个位置的token换成那个词”的概率相对有多大，从而可以逆转加噪过程。每个位置输出词表大小个比值，一次前向就能算完。

分数熵损失。比值必须为正，直接用平方误差去拟合效果差。作者提出

L = E_x Σ_{y≠x} w_xy·[ s(x)_y − (p(y)/p(x))·log s(x)_y + K(p(y)/p(x)) ]，K(a) = a(log a − 1)

它非负、凸，当且仅当s等于真实比值时为0，可以看作交叉熵向任意正数的推广。真实比值未知，但和连续情形的去噪分数匹配一样，可以换成加噪过程本身的条件比值p(y|x₀)/p(x|x₀)，后者有解析式。这个损失还给出了对数似然的上界，所以能和自回归模型比困惑度。

采样。从全[MASK]（或随机词）出发，用学到的比值同时更新所有位置的token；步数越多越精确。

结果

在OpenWebText上训练GPT-2 small和medium规模的模型，零样本测困惑度上界：small规模的SEDD（吸收型）在WikiText2（≤41.84对42.43）、PTB（≤114.24对138.43）、WikiText103（≤40.62对41.60）上优于GPT-2，在LAMBADA和1BW上略差；比以前的扩散语言模型（D3PM、PLAID）好很多，摘要称困惑度降低25%–75%。在1BW上的困惑度上界为32.79，D3PM为77.50。生成长度1024的文本：不用任何温度调节时，SEDD用32步即与GPT-2质量相当，用2048步时生成困惑度比GPT-2好6–8倍。还能按任意位置的提示做填空。

后来的发展

SEDD把离散扩散从“理论上可行”推到了“能和自回归比”。2024年掩码扩散语言模型MDLM发现吸收型（掩码）扩散的目标可以化简为若干掩码语言模型损失的混合，训练更简单、效果更好，还能半自回归地生成任意长度的文本；2025年LLaDA大语言扩散模型把掩码扩散扩到8B参数，在多项任务上接近同规模自回归模型；Mercury商用扩散LM等商用扩散语言模型主打并行生成带来的速度优势，官方称在H100上每秒可生成上千个token。

容易误解的地方

  • SEDD报告的困惑度是上界，自回归模型的是精确值，两者直接比较对扩散模型是偏保守的。
  • “比GPT-2好6–8倍”指的是不做温度调节时的生成困惑度（用更大的模型给生成文本打分），不是测试集困惑度；GPT-2一旦使用核采样，差距会大幅缩小。

局限与后续

  • 只做到GPT-2 small/medium规模，扩散语言模型能否像自回归模型那样扩展到数十亿参数并保持竞争力，没有验证。
    后来针对它的工作　LLaDA大语言扩散模型 LLaDA-MoE
  • 高质量生成需要上千步网络计算，且不能用KV缓存；作者测得约100步时推理时间才与自回归模型相当。
    后来针对它的工作　Mercury商用扩散LM
  • 训练目标和采样器较复杂（转移矩阵、分数熵、τ-leaping），实现和调参门槛高。
    后来针对它的工作　掩码扩散语言模型MDLM
  • 生成长度固定为预设的1024个token，不能像自回归模型那样自然地决定何时结束。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    吸收型加噪过程把token逐步变成[MASK]，与BERT的掩码语言模型形式相通。
  • 竞争
    GPT-22019.02 · LLM
    以同规模GPT-2为对照：困惑度在多数数据集上更好，且不需要温度或核采样就能生成高质量文本。
  • 延续
    分数匹配生成模型2019.07 · 生成
    把连续空间的分数匹配推广到离散空间：用概率比值代替梯度，用分数熵代替平方误差，并沿用去噪分数匹配的技巧。
  • 改进
    离散扩散D3PM2021.07 · LLM
    D3PM模仿图像扩散去预测原始数据，困惑度差距大；SEDD改为学习概率比值，1BW上界从77.50降到32.79。
  • 竞争
    Diffusion-LM2022.05 · LLM
    Diffusion-LM在连续嵌入空间做扩散再取整；SEDD直接在离散token上扩散，困惑度明显更好。
  • 竞争
    Plaid似然扩散LM2023.05 · LLM
    PLAID是连续扩散语言模型中困惑度最好的之一，SEDD在全部五个零样本数据集上都优于它。

读懂它需要的概念

扩散：前向加噪与反向去噪 分数函数与分数匹配 生成建模的目标 马尔可夫性与马尔可夫链 交叉熵 困惑度 掩码建模

本篇术语

  • 具体分数（concrete score）　离散空间中“分数”的替代品：当前序列与只改动一个token后的序列之间的概率比值集合。
  • 分数熵　SEDD提出的训练损失，用来让网络输出逼近真实的概率比值，形式上是交叉熵向正数的推广。
  • 吸收态　一旦进入就不再离开的状态。这里指[MASK]：token被掩掉后在加噪过程中保持为[MASK]。
  • 生成困惑度　用一个更大的语言模型给生成的文本算困惑度，用来衡量生成质量；越低越好。

怎么学

先掌握分数函数与分数匹配和DDPM的加噪-去噪思路，再看离散扩散D3PM如何定义离散加噪。读SEDD论文第3节（定义3.1与定理3.4）和第4节采样，对照代码仓库的losses.py。动手：在字符级小数据集上训练一个吸收型离散扩散模型，比较不同采样步数下生成文本的质量。
