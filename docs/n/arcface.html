ArcFace

ArcFace: Additive Angular Margin Loss for Deep Face Recognition
2018.01论文延伸CVPR 2019Deng, Guo, Yang, Xue, Kotsia, Zafeiriou · Imperial College / InsightFace待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人脸识别用softmax分类训练出来的特征，类内不够紧、类间不够开，对未见过的人区分度不足。

方法

在角度空间给目标类别加一个固定的角度间隔，用cos(θ + m)替换cos θ，要求同一人脸的特征更靠拢。

影响

成为人脸识别最常用的损失之一，也是度量学习中角度间隔类损失的典型。

方法

先把每个人脸特征和各类的权重向量都归一化到单位长度，这样logit就只取决于二者夹角θ的余弦，再乘一个缩放系数s。ArcFace在真实类别的角度上直接加一个间隔m：目标类的logit变成s·cos(θ_y + m)，其余类仍是s·cos θ_j，再做普通的Softmax与logits交叉熵。

这等价于要求同一人的特征与其类中心的夹角至少要比与别的类中心小一个m，间隔在超球面上有明确的几何含义，即测地线距离。论文还提出sub-center ArcFace，每类设K个子中心以抵抗大规模网络数据中的标签噪声。

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    以ResNet作为特征提取骨架。
  • 竞争
    FaceNet与三元组损失2015.03 · 视觉
    FaceNet用三元组损失直接拉近拉远样本，ArcFace用带间隔的分类损失，不需要挑三元组。
  • 改进
    DeepFace2014.06 · 视觉
    用分类损失学习，没有直接优化人脸之间的距离，难以在全新身份上泛化。
  • 改进
    SphereFace角度间隔2017.04 · 视觉
    cos(mθ)在θ较大时不单调，需要分段构造和与普通softmax混合退火，训练不稳定、难调。
  • 改进
    CosFace余弦间隔2018.01 · 视觉
    在余弦上加间隔，与角度不是线性关系，几何解释不如在角度上直接加间隔直观。
