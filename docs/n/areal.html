AReaL异步RL训练

AReaL: A Large-Scale Asynchronous Reinforcement Learning System for Language Reasoning
2025.05论文延伸NeurIPS 2025Wei Fu, Jiaxuan Gao, Xujie Shen, Chen Zhu, Zhiyu Mei, Chuyi He, Shusheng Xu, Guo Wei et al. · 蚂蚁集团, 清华大学交叉信息研究院, 香港科技大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

推理模型的RL训练多是同步的：一批里所有回答都生成完才更新模型，最长的那条拖住整批，GPU大量空等。

方法

让生成和训练完全解耦：生成端不停地出新样本，训练端攒够一批就更新；用陈旧度上限和改写过的PPO目标来对付“样本来自旧模型”的问题。

影响

官方称同等GPU下训练最多快2.77倍且效果持平或更好，是大模型异步RL训练系统的代表。

方法

在verl / HybridFlow RL训练框架这类同步系统里，每一轮先用当前模型对一批题目生成回答，再用这批回答做PPO式更新。推理模型的回答长短差距极大，批里最长的那条决定了这一轮的时间。

AReaL把生成端和训练端拆成两组独立的GPU。生成端持续采样；训练端一凑满一批就更新，并把新权重推给生成端——正在生成的回答会被打断，丢掉旧权重算出的KV缓存、用新权重重算后接着往下写，所以一条轨迹里可能混着几个版本的策略。为了不让数据太旧，系统设一个最大陈旧度η（训练用的样本最多落后几个版本，η=0就退化为同步RL），论文在数学上取8、代码上取4。损失函数把“采样时用的行为策略”和“作为信赖域中心的近端策略”分开，使PPO在样本来自旧策略时仍然稳定。

实验用从DeepSeek-R1蒸馏出的1.5B到32B模型做数学与代码推理，最多提速2.77倍。

局限与后续

  • 异步带来的离策略程度要靠超参数η手动权衡：太小回到同步的低效，太大训练可能不稳。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    PPO2017.07 · RL
    把PPO的行为策略与近端策略拆开，得到能容忍陈旧样本的变体。
  • 使用
    DeepSeek-R12025.01 · 推理·智能体
    实验的起点模型是DeepSeek-R1蒸馏出的Qwen2系列小模型。
  • 改进
    verl / HybridFlow RL训练框架2024.09 · 系统·效率
    verl等同步系统要等整批最长回答生成完才更新，AReaL把生成与训练解耦，消除这段空等。
