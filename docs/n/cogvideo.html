CogVideo

CogVideo: Large-scale Pretraining for Text-to-Video Generation via Transformers
2022.05论文延伸ICLR 2023Hong, Ding, Zheng, Liu, Tang · 清华大学 / 智源待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

文本到视频要从零训练代价极高，文本-视频配对数据既少又与动作描述关联弱。

方法

继承预训练的文生图模型CogView2，再用多帧率层级训练策略让文字与视频片段对齐。

影响

作者称是第一个公开的大规模预训练文本到视频模型，在自动与人工评估上大幅领先当时所有公开模型。

方法

模型有90亿参数的Transformer层的结构结构，与CogView同属自回归路线：视频被切成帧，每帧用图像分词器变成离散token，所有帧的token接在文字token后逐个预测。关键是继承CogView2的权重，让模型一开始就懂图像和文字，只需学习时间维度。

数据中文字与动作的对应很弱，于是用多帧率层级训练：先按较低的帧率生成少量关键帧，让文字与整体动作对齐；再把这些帧递归地插值成高帧率，补出连续运动。

局限与后续

  • 自回归逐token生成，生成长视频极慢，序列长度也限制了时长和分辨率。

  • 画面质量和时间一致性不及后来的扩散视频模型。
