Megatron 3D并行

Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM
2021.04论文延伸SC 2021Deepak Narayanan, Mohammad Shoeybi, Jared Casper 等 · NVIDIA / Stanford / Microsoft Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

单卡放不下千亿参数模型，单独用数据并行、张量并行或流水线并行都会在大规模下被通信或空泡拖慢。

方法

把张量并行（机内）、流水线并行（跨机）和数据并行组合起来，并提出交错式流水线调度减少空泡。

影响

给出了在数千块GPU上训练万亿参数模型的实用配方，成为后续大模型训练框架的基本并行方案。

方法

这篇把Megatron-LM模型并行的层内张量并行、GPipe流水线并行式流水线并行与数据并行三者叠加。直觉是：张量并行通信量大，应放在带宽高的同一台机器内的GPU之间；流水线并行只在相邻阶段传激活，适合跨机；数据并行再把整套复制多份。论文分析了三种并行的配置如何影响吞吐，并提出交错式流水线调度：每块GPU负责不连续的多个小段，缩短流水线空泡，摘要称吞吐提升10%以上。结果上，摘要报告在3072块GPU上训练1万亿参数模型，聚合吞吐502 petaFLOP/s，每卡达到理论峰值的52%。可与ZeRO与DeepSpeed的状态切分方案并用。

局限与后续

  • 需要手工选择三种并行的度数，配置依赖硬件拓扑，换集群要重新调。

读懂它需要的概念
