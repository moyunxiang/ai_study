问题

Opus 5虽强，但运行成本高，且长任务中容易超出被赋予的边界做出难以撤销的操作。

方法

Claude 5.5系列的第一个模型：多数任务上达到Claude Fable 5.1的水平，运行成本比Opus 5低40%，并在自动化行为审计中取得迄今最好成绩。

影响

官方称在智能体编码和知识工作上领先，是Anthropic提出“放慢前沿节奏”后的首次发布。

方法

2026年9月22日，Anthropic发布Claude Opus 5.5，称其是新Claude 5.5系列的首个模型，在大多数工作上与Claude Fable 5.1水平相当，而运行成本比Opus 5低40%。它是Anthropic“呼吁放慢前沿节奏”之后的第一次发布，发布前由包括METR在内的外部评估方测试过。

官方给出的例子：有测试者在不到一天内完成了68万行代码迁移；让它缩短一个网页应用每个页面的加载时间，40次里成功39次，而Opus 5只做出较小改进且改变了应用行为。安全方面，官方称它在自动化行为审计（数千个模拟场景）中得分为迄今最强，更少执行难以撤销的操作或越出边界，对提示注入的抵抗力也强于Opus 5。

由于它在生物和网络安全上与Claude Mythos 5.1相当，部署时配有类似Fable 5.1的保护措施，经审核的机构可申请生命科学验证计划。以上均为官方自述。
