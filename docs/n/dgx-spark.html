DGX Spark桌面超算

2025.10硬件延伸NVIDIA待核对
NVIDIA新闻稿 ↗在交互版中打开（演化树、学习进度）

问题

开发者要在本地调试大模型，消费级显卡显存不够，数据中心服务器又太贵太大。

方法

把GB10 Grace Blackwell超级芯片做成桌面小盒子，CPU与GPU共享128GB统一内存。

影响

它让大模型本地推理和微调成为桌面产品，与Mac Studio的统一内存路线直接竞争。

方法

2025年10月13日NVIDIA宣布DGX Spark上市。官方称：基于GB10 Grace Blackwell超级芯片，约1 PFLOPS的AI算力，128GB CPU与GPU一致性统一内存，通过NVLink-C2C连接，带宽为PCIe第五代的5倍；配ConnectX-7 200Gb/s网络；可本地推理最多2000亿参数、微调最多700亿参数的模型。

它延续Grace CPU与超级芯片的CPU加GPU一体化封装，用Blackwell与整机柜液冷的GPU做出体量小的版本；内存带宽仍受LPDDR的限制，因此更适合开发与调试而不是批量服务。对比M3 Ultra：512GB统一内存，它的算力和CUDA生态是卖点，内存容量上限更小。2026年报道称其定价约4,999美元（shattered.io标题）。

局限与后续

  • 统一内存使用LPDDR，带宽远低于HBM，推理速度受限。

它建立在什么之上

  • 改进
    RTX 4090与本地大模型2022.10 · 硬件
    24GB显存放不下4位量化的70B模型，更大的模型只能多卡拆分或卸载到内存，速度大幅下降。
  • 使用
    Blackwell与整机柜液冷2024.03 · 硬件
    采用Blackwell架构的GPU核心与FP4。
  • 延续
    Grace CPU与超级芯片2021.04 · 硬件
    把Grace CPU加GPU的一体化设计缩小为桌面产品。
  • 改进
    RTX 5090：32GB与FP42025.01 · 硬件
    32GB仍然装不下70B级的模型，需要多卡或更强的量化。
  • 改进
    M3 Ultra：512GB统一内存2025.03 · 硬件
    统一内存带宽远低于HBM，生成速度受带宽限制，且算力不适合大规模训练。
