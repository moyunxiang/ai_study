跨语言词向量线性映射

Exploiting Similarities among Languages for Machine Translation
2013.09论文延伸arXiv 2013Tomas Mikolov, Quoc V. Le, Ilya Sutskever · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

统计翻译系统依赖人工或从平行语料中整理的词典和短语表，覆盖不全、成本高；而大量单语语料里蕴含的语言结构信息没有被用来补全这些词典。

方法

分别在两种语言的大量单语语料上训练word2vec词向量，再用一个小双语词典学一个线性变换矩阵W，使源语言词向量乘以W后接近其译词的向量；翻译新词时，把它的向量映射过去，在目标语言中找余弦最近的词。

影响

英语与西班牙语之间的词翻译达到近90%的前5准确率；「两种语言的词向量空间大致只差一个线性变换」这一发现开创了跨语言词向量映射这一方向，后来的正交约束映射、MUSE和VecMap等无监督方法都从这里出发。

方法

观察。作者用PCA把英语数字one到five、动物cat、dog等的词向量和对应的西班牙语uno到cinco、gato、perro等画在二维平面上，发现两组点的几何排列非常相似，仿佛只差一个旋转和缩放。这意味着，只要知道少数词的翻译，就有可能把整个空间对齐。

方法。给定n对已知互译的词及其向量{x_i, z_i}（x_i ∈ R^d1为源语言向量，z_i ∈ R^d2为目标语言向量，两者维度可以不同），求变换矩阵W使min_W Σ_i ‖W·x_i − z_i‖²最小，用随机梯度下降求解。预测时对新词计算z = W·x，在目标语言词表中找与z余弦相似度最大的词。作者发现这个线性方法比最近邻方法好，与神经网络分类器相当。还可以用max_i cos(W·x, z_i)作为置信度，低于阈值就放弃翻译，以覆盖率换精度。

实验。用WMT11的单语数据训练英语、西班牙语、捷克语的word2vec的Skip-gram或CBOW向量，用谷歌翻译为源语言最常见的5000个词生成训练词典，在其后的词上测试。结果明显优于编辑距离和基于共现计数的基线，且对英捷这种拼写不相近的语言对同样有效；源语言向量维度取目标语言的2–4倍时效果最好。换用数十亿词的Google News语料后，英译西的前1准确率在92.5%的覆盖率下为53%，提高置信度阈值、覆盖率降到17%时精度升至78%。

局限与后续

  • 仍需要几千对已知的翻译作为种子词典；没有双语词典的语言对无法使用。
    后来针对它的工作　无平行语料的词翻译MUSE 无监督NMT（Artetxe）
  • 对W不加约束的最小二乘映射会扭曲源语言空间，且高维空间中存在「枢纽词」问题，某些目标词会成为大量源词的最近邻。
    后来针对它的工作　无平行语料的词翻译MUSE
  • 只翻译单个词和很短的短语，无法处理一词多义和需要上下文的翻译。

读懂它需要的概念

嵌入向量 分布假说 线性回归 内积与余弦相似度 降维与PCA

本篇术语

  • 变换矩阵　把一种语言的词向量线性地映射到另一种语言词向量空间的矩阵W，用已知的词对拟合得到。
  • precision@k　正确译词出现在模型给出的前k个候选中的比例。

怎么学

先读word2vec和词向量类比规律的讲解 → 读原文第3–4节线性关系与变换矩阵 → 动手：下载两种语言的fastText词向量，用1000对词典拟合W，在另外500个词上测precision@1和@5；再试试把W约束为正交矩阵会怎样。
