TPU外供：Anthropic百万TPU

2025.10事件延伸Anthropic；Google Cloud待核对
Anthropic公告 ↗在交互版中打开（演化树、学习进度）

问题

前沿模型训练与服务的需求暴涨，仅靠单一芯片供应商无法满足，且成本压力大。

方法

Anthropic宣布扩大使用Google Cloud TPU，规模最多达百万颗，2026年带来超过1吉瓦的容量。

影响

它是TPU首次作为大规模外供芯片被前沿实验室押注，改变了NVIDIA独占前沿训练算力的格局。

方法

2025年10月23日Anthropic发布公告：计划大幅扩大使用Google Cloud技术，包括最多百万颗TPU；价值数百亿美元，预计2026年带来远超1吉瓦的算力（Anthropic称）。Google Cloud CEO称这反映了TPU多年来的性价比与效率。Anthropic的策略是多元化：同时使用TPU、AWS Trainium和NVIDIA GPU。

2026年4月的报道进一步显示，Anthropic与Google、Broadcom签约，从2027年起新增约3.5GW的TPU容量，同时Anthropic称年化收入已超过300亿美元（Tom’s Hardware 2026-04-07，转述，未核对原文）。

这一合作依赖TPU Ironwood一代的规模与性价比。

局限与后续

  • TPU软件栈以JAX/XLA为主，跨平台迁移与调优成本高。
