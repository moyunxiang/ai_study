OpenCLIP复现

Reproducible scaling laws for contrastive language-image learning
2022.12论文延伸CVPR 2023Cherti, Beaumont, Wightman, Wortsman, Ilharco, Gordon, Schuhmann, Schmidt, Jitsev · LAION / UCSC / JSC 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

此前关于多模态缩放规律的研究基于私有数据和模型，外界无法检验，也不知道对比学习是否同样遵守缩放定律。

方法

用公开的LAION数据和开源OpenCLIP代码，在最多20亿图文对上训练一系列模型，系统测量零样本、检索、线性探测和微调随规模的变化。

影响

首个可复现的CLIP缩放规律研究，并给出公开的大模型权重，成为开源社区使用最广的CLIP实现。

方法

作者在LAION数据集（见LAION-5B）上训练不同大小的模型，规模扩展到20亿图文对，并在零样本分类、图文检索、线性探测和端到端微调等任务上测量误差。结果显示，各任务的误差随模型、数据、算力呈幂律下降（幂律与规模定律），说明在公开数据上同样遵循缩放规律。

摘要还发现，训练分布会决定缩放行为：OpenAI的CLIP和OpenCLIP虽然架构相同、训练配方相近，缩放行为却不同，说明数据分布对缩放规律起关键作用。该工作同时开源了代码、数据和模型，使他人可以直接复现。

局限与后续

  • 规律只覆盖对比图文模型，没覆盖生成式多模态大模型。
