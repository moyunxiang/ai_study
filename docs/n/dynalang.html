Dynalang语言世界模型

Learning to Model the World with Language
2023.07论文延伸ICML 2024Jessy Lin, Yuqing Du, Olivia Watkins, Danijar Hafner, Pieter Abbeel, Dan Klein, Anca Dragan · UC Berkeley待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

语言条件策略只会执行“拿起蓝色方块”这类简单指令；人说的话还包括环境描述、游戏规则、反馈（“这个按钮开电视”“我把碗收好了”），语言越多样，这类策略越学不好。

方法

把语言当作帮助预测未来的信号：智能体学一个多模态世界模型，同时预测未来的文本和图像表示以及奖励，再在模型想象的轨迹里学行动。

影响

Dynalang能利用环境描述、游戏规则和指令，在游戏和真实房屋扫描导航等任务上表现优异，并能用纯文本预训练、生成与环境对应的语言，是“世界模型+语言”结合的代表工作。

方法

常见的语言条件策略把一句指令编码后直接映射到动作。论文的观点是：语言除了告诉你“做什么”，更常告诉你“世界是什么样、会怎么变”，因此最自然的用法是让智能体用语言来预测未来——它会看到什么、世界会如何变化、什么情形会得到奖励。

Dynalang基于DreamerV3的世界模型：每个时间步输入一帧图像和一个文本token（语言按时间逐词流入，而不是一次性给整句），模型把它们压进同一个潜状态，并学习预测下一时刻的图像表示、文本表示和奖励。这样，语言理解和未来预测合成同一个自监督目标。策略和价值函数在世界模型想象出的轨迹中训练，与Dreamer相同。

实验覆盖网格游戏（需要读懂规则手册）、家务环境以及在真实房屋扫描中按语言指令导航（VLN-CE连续环境语言导航）。语言类型越多样，语言条件的无模型基线性能越下降，而Dynalang能利用环境描述、规则和指令取得更好成绩。由于学的是生成模型，它还可以先在纯文本数据上预训练，并能生成与环境相符的语言描述。

局限与后续

  • 用的是从零训练的小型模型，语言能力远不及预训练大语言模型，复杂指令和长文本理解有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
