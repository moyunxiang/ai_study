PRIME：ReRAM主存内计算

PRIME: A Novel Processing-in-Memory Architecture for Neural Network Computation in ReRAM-Based Main Memory
2016.06论文延伸ISCA 2016Ping Chi, Shuangchen Li, Cong Xu, Tao Zhang, Jishen Zhao, Yongpan Liu, Yu Wang, Yuan Xie · 加州大学圣塔芭芭拉分校 / 清华大学等待核对
IEEE DOI ↗在交互版中打开（演化树、学习进度）

问题

神经网络计算被内存墙卡住；此前的存内处理方案只是在内存里或旁边额外加计算逻辑，而新兴的阻变存储器（ReRAM）本身就能做矩阵向量乘。

方法

把ReRAM主存里的一部分交叉阵列做成“可变身”的：需要时当神经网络加速器做矩阵向量乘，不需要时当普通内存扩大容量，并提供配套的电路和软件接口。

影响

与同期的ISAAC：忆阻器交叉阵列加速器一起开启了ReRAM交叉阵列做神经网络计算的研究热潮，“存储即计算”的思路后来体现在NeuRRAM存内计算芯片等真实芯片上。

方法

ReRAM单元的电阻值可以编程，交叉阵列里每个交点存一个权重（电导）。在行线上加代表输入的电压，根据欧姆定律和基尔霍夫电流定律，每条列线上汇集的电流就是 I_j = Σ_i V_i × G_ij，一次就完成了一整个矩阵向量乘——计算在存储数据的地方完成，权重根本不用搬运。

PRIME的特点是把这件事放进主存：ReRAM被设想为未来的主存储器，其中一部分交叉阵列可以配置成神经网络加速器，或者作为普通内存使用以提供更大的存储空间。论文给出了让阵列在两种功能之间切换的微架构和电路设计，面积开销很小；还设计了软硬件接口，让软件开发者能在PRIME上实现各种神经网络。

摘要报告，在所评估的机器学习基准上，相对当时最先进的神经处理单元设计，PRIME性能提升约2360倍、能耗降低约895倍。这些数字来自模拟评估。

局限与后续

  • 结果来自模拟，ReRAM器件的阻值漂移、模数转换开销和低精度问题没有在真实芯片上验证；ReRAM作为主存也一直没有商用。

本篇术语

  • ReRAM（阻变存储器）　靠改变材料电阻来存储数据的非易失存储器，电阻值可以表示多级数值，常被称为忆阻器的一种。
  • 交叉阵列（crossbar）　横竖两组导线交叉、每个交点放一个存储单元的阵列，适合用电流一次完成矩阵向量乘。

怎么学

先用一个2×2的电导矩阵和两个输入电压，按欧姆定律手算列电流，体会“模拟矩阵乘”；再对比ISAAC：忆阻器交叉阵列加速器，看两篇同届论文的系统设计有何不同。
