特征可迁移性

How Transferable are Features in Deep Neural Networks?
2014.11论文延伸NeurIPS 2014Yosinski, Clune, Bengio, Lipson · Cornell / Univ. of Wyoming / Montreal待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大家都在拿ImageNet上训好的网络去做别的任务，但没人系统量过：网络的哪一层是通用的，哪一层已经只服务于原任务。

方法

把网络逐层切开：某一层前面的权重从另一个任务搬过来，冻结或微调，再测准确率，从而逐层量化“通用性”与“专用性”。

影响

用实验给“预训练再微调”提供了依据：低层特征通用，迁移几乎总比随机初始化好，奠定了视觉迁移学习的标准做法。

方法

作者把ImageNet的类别分成两个互不相交的子任务A、B，先在A上训练一个8层卷积网络，再把前n层的权重复制到另一个网络，对它在B上做两种处理：冻结这n层，或者允许继续微调（fine-tune），并与B上从头训练的基线比较。

结果有两个出乎意料的现象。其一，如果把网络从中间切开又冻结，性能会下降，原因不全是高层特征“太专用”，还因为相邻层之间存在互相依赖的共适应（co-adaptation），切开后后面的层找不回匹配的上层；其二，任务差得越远，迁移效果越差，但即使来自较远的任务，迁移得到的特征也比随机初始化好；而且用迁移得来的权重做初始化，即便再微调很久，这种泛化上的好处仍然保留。这些结论来自摘要所述的实验，具体各层的准确率曲线请见原文图。

读懂它需要的概念

迁移学习 预训练与微调 卷积层、池化与感受野 泛化与过拟合

怎么学

先了解卷积网络逐层学到的特征（低层是边缘与颜色，高层是物体部件），读原文第3–4节的实验设计与迁移曲线，然后自己用预训练ResNet冻结不同层数微调一个小数据集。
