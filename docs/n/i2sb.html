I²SB图像薛定谔桥

I²SB: Image-to-Image Schrödinger Bridge
2023.02论文延伸ICML 2023Guan-Horng Liu, Arash Vahdat, De-An Huang, Evangelos A. Theodorou, Weili Nie, Anima Anandkumar · NVIDIA / 佐治亚理工学院 / 加州理工学院待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

用扩散模型做修复、超分、去模糊时，常规做法是从纯噪声出发、把退化图当条件；可退化图本身已经包含大部分结构，从噪声开始绕了远路，而一般的薛定谔桥又需要昂贵的迭代模拟训练。

方法

直接学习从“退化图分布”到“干净图分布”的非线性扩散桥；在给定成对的退化图和干净图时，这类薛定谔桥的中间分布有解析式，因此可以像普通扩散模型一样免模拟地训练。

影响

把扩散桥做成了可规模化训练的图像复原方法，在多种复原任务上超过常规条件扩散模型，带动了一批“从源分布直接走到目标分布”的扩散桥工作。

方法

普通扩散模型的起点是标准高斯，终点是数据；做图像复原时，再把退化图y作为条件塞进去。扩散薛定谔桥DSB指出可以在任意两个分布之间学一座“桥”，即薛定谔桥：在所有连接两个分布的随机过程里找最接近某个参考扩散过程的那个。可一般情况下要交替迭代、反复模拟整条轨迹，代价很高。

I²SB观察到：复原任务里训练数据是成对的(干净图x₀, 退化图x₁)。如果把桥的两端固定在这对样本上，那么时间t处的中间状态x_t服从一个高斯分布，其均值是x₀和x₁按时间的插值、方差在两端为零，全部有解析式。训练时只需随机采t、按解析式采x_t，让网络预测从x_t回到x₀所需的量——和训练DDPM一样不需要模拟，也能沿用标准扩散模型的网络和技巧。

推理时从退化图x₁出发，沿学到的桥一步步走向干净图，路径比从纯噪声出发短得多，可解释性也更好。论文在ImageNet 256×256上做修补、超分、去模糊和JPEG复原，报告超过标准条件扩散模型，并能比肩需要已知退化算子的反问题求解方法。

局限与后续

  • 需要成对的退化图和干净图训练，每种退化各训一个模型，无法像通用扩散先验那样零样本处理新的退化。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

扩散：前向加噪与反向去噪 常微分方程与随机微分方程 最优传输与Wasserstein距离 高斯分布 分数函数与分数匹配

本篇术语

  • 薛定谔桥　在给定起点分布和终点分布的条件下，找出与某个参考随机过程最接近（KL最小）的随机过程，相当于带随机性的最优传输。

怎么学

先读DDPM和扩散薛定谔桥的基本思想 → 读本文第3节成对边界条件下的解析中间分布 → 用4×超分任务比较从噪声出发与从退化图出发的采样步数和质量。
