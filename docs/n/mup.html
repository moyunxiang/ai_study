μP与超参数迁移

Tensor Programs V: Tuning Large Neural Networks via Zero-Shot Hyperparameter Transfer
2022.03论文重要NeurIPS 2021Greg Yang, Edward J. Hu, Igor Babuschkin, Szymon Sidor, Xiaodong Liu, David Farhi, Nick Ryder, Jakub Pachocki et al. · Microsoft / OpenAI待核对
arXiv ↗官方代码 mup ↗前作：无限宽网络中的特征学习（Tensor Programs IV） ↗在交互版中打开（演化树、学习进度）

问题

几十亿参数的模型无法反复试超参数；在小模型上调好再搬过去又不灵，因为按标准参数化，最优学习率会随网络变宽而漂移。

方法

换一种参数化（μP）：按层的宽度缩放初始化方差和学习率，使每层在训练中的更新幅度与宽度无关，最优超参数就不随宽度变化，可以在小模型上调好后直接照搬（μTransfer）。

影响

从4000万参数的代理模型迁移超参数，训练出的GPT-3 6.7B胜过原版，调参成本只占预训练的7%；把“大模型怎么调参”变成可推导的问题。

背景

超参数（学习率、初始化尺度等，见超参数与调参）对结果影响很大，但大模型训练一次就极其昂贵，不可能网格搜索。实践中大家在小模型上调，再凭经验猜大模型的值，结果时好时坏。论文图1显示：用Adam训练不同宽度的Transformer，在标准参数化（SP，即PyTorch默认的初始化加全局统一学习率）下，最优学习率随宽度明显移动。

理论方面，神经正切核指出无限宽网络在特定参数化下退化为核方法，惰性训练与特征学习进一步说明这时参数几乎不动、网络不学习特征。作者在前作Tensor Programs IV中证明：SP和NTK参数化都没有“能学特征”的无限宽极限，并提出最大更新参数化μP，让每一层在训练中都以与宽度无关的幅度更新。本文把它变成调参方法。

方法

直觉：中心极限定理。n个独立的零均值单位方差变量求和，乘1/√n才收敛到非平凡的高斯；乘1会发散，乘1/n会趋于0。如果把一个系数写成c = α/√n，那么最优的α在n变大时趋于稳定，可以直接从小n复制到大n。μP就是给网络里每类参数找到这样“正确”的缩放。

μP的规则（以Adam为例，fan_in为该层输入宽度）：

  • 隐藏层权重：初始化方差1/fan_in（与SP相同），学习率按1/fan_in缩小（SP不变）；
  • 输出层权重：初始化方差1/fan_in²（SP为1/fan_in），学习率按1/fan_in缩小；
  • 输入层权重和偏置：初始化方差1/fan_in，学习率不随宽度变化；
  • 注意力分数用q·k/d代替q·k/√d。

例子：把宽256的代理模型放大到4096（16倍），隐藏层的Adam学习率除以16，输出层初始化标准差也相应缩小，其他超参数原样复制。

为什么SP不行。训练一步后，SP下输出logits和注意力分数随宽度变大而爆炸，最优学习率只好变小来压住它们，词嵌入等其他部分却因此学得太慢。

μTransfer流程：目标模型写成μP → 调一个窄（也可以更浅）的代理模型 → 把超参数零样本复制过去。能迁移的是学习率、调度、初始化尺度、输出乘子等优化类超参数；dropout、权重衰减这类正则化超参数不能迁移。

结果

BERT：从1300万参数的代理模型迁移，超过已发表的BERT-large（3.5亿参数）结果，总调参成本约等于预训练一次BERT-large。GPT-3：从4000万参数代理迁移到6.7B，调参成本只占预训练的7%；验证损失1.98，用原超参数重训的同模型为2.03，整体与两倍大的13B原版相当。经验上，宽度、批大小、序列长度和训练步数需分别不低于256、32、128和5000步左右，跨深度迁移只在Pre-LN结构上成立。

后来的发展

代码以pip install mup发布。“让每层的更新幅度与规模无关”的思路后来被推广到深度方向，也影响了新优化器的设计：Muon规模化到LLM专门调整每个参数的更新尺度，使Muon优化器能直接沿用为AdamW调好的学习率和权重衰减。

容易误解的地方

  • μP不是新的网络结构，也不改变模型能表示什么；它只改变初始化和学习率随宽度的缩放方式，换算后的小模型与大模型在“相对意义上”行为一致。
  • 只把学习率按宽度缩放、不改输出层初始化和注意力缩放，并不等于μP，迁移会失效。官方仓库建议用“坐标检查”画出激活随宽度的变化来验证实现。
  • 迁移的是最优超参数，不是性能预测；正则化超参数仍需在目标规模上调。

局限与后续

  • 严格理论只覆盖宽度方向；跨深度迁移是经验结果，只在Pre-LN Transformer上成立，初始化标准差跨深度也迁移不好。

它建立在什么之上

  • 延续
    Adam2014.12 · 基础
    给Adam推导出逐层学习率随fan_in缩放的规则，替代全局统一的学习率。
  • 使用
    BERT2018.10 · LLM
    用1300万参数代理模型同时为BERT-base和BERT-large调参，超过已发表结果。
  • 使用
    GPT-32020.05 · LLM
    以GPT-3 6.7B为目标验证μTransfer，迁移超参数后的模型优于原版并接近13B。
  • 延续
    He初始化与PReLU2015.02 · 基础
    He初始化只保证初始化时激活尺度稳定；μP进一步规定训练过程中各层学习率如何随宽度缩放。
  • 改进
    神经正切核2018.06 · 基础
    NTK参数化下无限宽网络退化为核方法、不学习特征；μP给出能学习特征的无限宽极限，并据此做超参数迁移。
  • 改进
    惰性训练与特征学习2018.12 · 基础
    惰性训练说明某些缩放下参数几乎不动；μP选取让每层都“最大限度”更新的缩放，避开惰性区。
  • 改进
    Tensor Programs IV2020.11 · 基础
    只在Word2Vec和少样本学习等相对简单的任务上计算了极限，没有直接用于大型网络的调参。

读懂它需要的概念

超参数与调参 参数初始化 学习率与学习率调度 自适应学习率优化器 期望与方差 高斯分布 自注意力与多头注意力

本篇术语

  • 参数化（parametrization）　规定每层权重如何初始化、学习率如何随网络宽度缩放的一套约定；同一个网络结构可以有不同参数化。
  • 标准参数化（SP）　常见框架的默认做法：初始化方差按1/fan_in，所有层共用一个学习率。
  • μTransfer　在μP下调一个小代理模型，把得到的超参数不经调整直接用于大模型的流程。
  • 坐标检查　训练几步后画出各层激活平均大小随宽度的变化，μP实现正确时这些曲线应基本水平。

怎么学

先补参数初始化和自适应学习率优化器，了解神经正切核说的“宽网络像核方法”。读原文第2节（中心极限定理的直觉）、表3（μP规则）和图1、图5。动手：用官方mup库把一个小MLP或nanoGPT改成μP，在宽度128到2048之间扫学习率，画出SP与μP下损失随学习率的曲线，看最优点是否对齐。
