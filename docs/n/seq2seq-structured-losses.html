经典结构化损失用于Seq2Seq

Classical Structured Prediction Losses for Sequence to Sequence Learning
2017.11论文延伸NAACL 2018Sergey Edunov, Myle Ott, Michael Auli, David Grangier, Marc'Aurelio Ranzato · Facebook AI Research待核对
arXiv ↗ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

序列到序列模型按词级交叉熵训练，却按BLEU、ROUGE评测并用束搜索解码；2016年前后出现了MIXER、束搜索优化等用强化学习或改造束搜索来做序列级训练的方法，但NLP里早已有的经典结构化损失放到神经模型上效果如何，没人系统比较过。

方法

把统计NLP里训练线性结构化模型常用的几种序列级目标——序列级似然、间隔损失、期望风险等——原样搬到卷积序列到序列模型上，用束搜索得到的候选集近似计算，并与词级似然组合，做一次全面对照。

影响

发现这些经典损失彼此效果相近，都优于同等设置下的束搜索优化，在IWSLT'14德英翻译和Gigaword摘要上取得当时最好的报告结果；它让“候选集上的期望风险微调”成为序列级训练的常用简单基线。

背景

神经序列模型的训练与测试存在两处不一致：训练时每步都看真实前缀（Scheduled Sampling与暴露偏差称之为暴露偏差），而测试时看自己的输出；训练优化词级似然，评测却用BLEU。MIXER序列级训练用REINFORCE直接优化BLEU，束搜索优化（BSO）让训练时也走束搜索，最小风险训练MRT把统计翻译的最小风险训练用于RNN翻译。另一方面，统计翻译和句法分析早就用最小错误率训练MERT、期望风险、大间隔等目标训练结构化模型。

方法

对每个源句x，先用当前模型做束搜索得到候选集U(x)，再在U上计算下列序列级损失（u*是候选中与参考最接近的那一个，cost用1−句级BLEU）：

  • 序列级负对数似然：L = −log p(u*|x) + log Σ_{u∈U} p(u|x)，在候选集上把概率集中到最好的候选；
  • 期望风险：L = Σ_{u∈U} cost(t, u) · p(u|x) / Σ_{u'∈U} p(u'|x)，最小化候选上BLEU代价的期望；
  • 间隔类损失：要求最好候选的模型分比其他候选高出与它们代价差相当的间隔（含多间隔、softmax间隔等变体）。

这些损失单独使用容易不稳定，论文把它们与词级交叉熵加权组合 L = α·L_token + (1−α)·L_seq，并先用词级似然预训练，再做序列级微调。模型用的是卷积Seq2Seq卷积序列到序列结构。

结果

在IWSLT'14德英翻译和Gigaword生成式摘要上取得当时最好的报告结果；几种序列级损失效果相近，在可比设置下都优于束搜索优化；在更大的WMT'14英法上，期望风险最小化同样有效（论文摘要与引言所述）。

后来的发展

这篇论文的结论——“经典结构化损失对神经模型依然很有竞争力”——让期望风险微调成为翻译与摘要中序列级训练的标准做法之一，fairseq中也实现了相应的损失。之后的研究继续讨论序列级训练收益有限、增益部分来自正则化等问题；在大模型时代，用候选集和奖励做微调的思路又以RLHF、偏好优化等形式出现。

局限与后续

  • 每个训练句都要先做束搜索生成候选，训练开销是普通词级训练的数倍。

读懂它需要的概念

本篇术语

  • 序列级训练　不是逐词计算损失，而是对整个输出序列计算损失（如按BLEU打分）来训练模型。
  • 期望风险　在一组候选输出上，按模型概率加权的平均代价（如1−BLEU）。
  • 暴露偏差　训练时模型总看到正确的前文，测试时却要接着自己可能出错的输出往下生成。

怎么学

先读最小风险训练MRT和MIXER序列级训练 → 读本文第2节各损失定义与第3节组合方式 → 动手：在一个小翻译模型上用束宽5生成候选，实现期望风险损失并微调一个周期，观察BLEU与困惑度的变化。
