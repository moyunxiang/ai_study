BID动作块双向解码

Bidirectional Decoding: Improving Action Chunking via Guided Test-Time Sampling
2024.08论文延伸arXiv 2024Yuejiang Liu, Jubayer Ibn Hamid, Annie Xie, Yoonho Lee, Maximilian Du, Chelsea Finn · 斯坦福大学待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

动作分块（一次预测并执行一串动作）有的研究说关键、有的说有害；它能学到示范里的时间依赖，却在执行中途对意外状态反应迟钝。

方法

测试时每步采多个候选动作块，按两条准则挑选：与上一步已执行计划衔接的“后向一致”，以及更像强策略而不像弱策略的“前向对比”。

影响

不重训策略，把Diffusion Policy在7个仿真任务上的平均成功率从0.60提到0.76，在动态拾放的真机任务上也明显优于原始采样，代价是2–3倍计算。

方法

ALOHA与ACT和Diffusion Policy都用动作表示：离散token、连续动作与动作块，一次输出未来多步动作。作者先分析：块越长，学生越能捕捉示范中跨时间步的依赖，但块执行期间不再看新观测，环境一变就来不及纠正；每步重新规划又会让相邻决策互相矛盾、动作抖动。

BID的做法：每个时间步采样一批候选块（Diffusion Policy默认30个）。后向一致：与上一步选中块的重叠部分越接近越好，距离按0.9的衰减加权，保证动作连贯。前向对比：用一个训练充分的强策略和一个欠训练（或预测更短）的弱策略分别采样，候选应靠近强策略的样本、远离弱策略的样本，从而偏向高质量的长期计划。两者结合后，策略可以每步重新决策而不失连贯。

结果：Push-T、robomimic、Franka Kitchen的7个任务上平均0.60→0.76（Franka Kitchen 0.22→0.60）；对VQ-BeT量化行为Transformer在Push-T上也有提升；真机动态拾放任务中成功率至少是基线的2倍。

局限与后续

  • 每步要多次采样并比较，计算量增加2–3倍，作者也指出在低成本机器人上做高频控制可能太贵。
