NICE可逆耦合层

NICE: Non-linear Independent Components Estimation
2014.10论文延伸ICLR 2015 workshopLaurent Dinh, David Krueger, Yoshua Bengio · Montréal待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

似然类生成模型要么只能近似算概率（VAE），要么只能逐维采样（自回归）；想要精确似然又能一次采样，需要可逆且行列式好算的变换。

方法

设计加性耦合层：把输入分成两半，一半原样通过，另一半加上由它算出的偏移，变换天然可逆且雅可比行列式为1。

影响

开创了标准化流中的耦合层设计，标准化流RealNVP、Glow直接继承。

方法

NICE学习一个可逆映射 h = f(x)，使h服从各维独立的简单分布（如标准高斯或logistic）。由变量替换公式，log p(x) = log p_h(f(x)) + log|det ∂f/∂x|，训练目标就是精确对数似然。

难点是行列式。加性耦合层把x拆成 x₁、x₂，输出 y₁ = x₁，y₂ = x₂ + m(x₁)，其中m是任意的深度网络。雅可比矩阵是三角阵，对角线全是1，行列式恒为1；逆变换只要减回去：x₂ = y₂ − m(y₁)。堆叠多层并交替拆分方式，再在最后加一个逐维缩放层。

因此似然精确，采样只需把噪声从后往前反向走一遍，不需要逐维生成。作者在四个图像数据集上验证并演示了补全。

局限与后续

  • 加性耦合不改变体积，表达力受限，后续需要带缩放的耦合才能更灵活地拉伸空间。
    后来针对它的工作　标准化流RealNVP
  • 要求潜变量与数据同维，高分辨率图像上模型很大，样本质量不及GAN。
    后来针对它的工作　Glow BigGAN

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    用普通反向传播训练由深度网络m构成的可逆变换，不要求m本身可逆。

后来的相关工作

  • 延续
    标准化流2015.05 · 生成
    沿用“可逆变换＋可算行列式”的思路，但用于变分后验；论文直接以NICE式变换作对比，平面流在同等长度下效果更好。
  • 改进
    标准化流RealNVP2016.05 · 生成
    NICE的加性耦合不能缩放；这里加入尺度s，使变换可以局部拉伸或压缩空间并保持行列式易算。
  • 改进
    Glow2018.07 · 生成
