MSER稳定区域

Robust Wide Baseline Stereo from Maximally Stable Extremal Regions
2002.09论文延伸BMVC 2002Jiří Matas, Ondřej Chum, Martin Urban, Tomáš Pajdla · 布拉格捷克理工大学待核对
DOI ↗期刊版 ↗在交互版中打开（演化树、学习进度）

问题

宽基线匹配（两张照片视角差别很大）时，点特征周围的局部外观会被透视变形严重改变；需要一种在视角、光照变化下都能被重复检测出来的区域。

方法

对图像取不同的亮度阈值，观察二值化后连通区域如何随阈值变化；那些在很宽的阈值范围内形状几乎不变的区域就是“最大稳定极值区域”，它们对仿射变形和单调亮度变化天然不变。

影响

MSER成为最常用的仿射不变区域检测子之一，在宽基线匹配、物体识别和场景文字检测（字符通常是稳定的暗或亮区域）中长期使用，OpenCV内置实现。

方法

想象把一张灰度图按阈值t二值化：t从0（全黑）慢慢升到255（全白），亮度低于t的像素被“淹没”。随着t升高，暗的小块先出现，然后逐渐长大、合并。每个连通块在它存在期间叫作一个极值区域——区域内所有像素都比它边界上的像素更暗（或更亮）。

对每个极值区域，记录它的面积随阈值的变化率 q(t) = |Q(t+Δ) \ Q(t−Δ)| / |Q(t)|。如果某个阈值处面积几乎不变（q取局部最小），说明这个区域边界很“锐利”、轮廓稳定，就把它选为MSER。

这样的区域有几个好性质：只依赖像素亮度的大小顺序，所以对单调的亮度变化不变；连通性在连续的几何变形下保持，所以对仿射变换协变；可以用类似并查集的算法在接近线性时间内枚举。作者用检测出的区域做宽基线立体匹配，并在论文中给出相应的鲁棒匹配方法。

  • 对模糊敏感，在纹理丰富但缺少均匀区块的图像（如树叶）上检测数量少。

它建立在什么之上

  • 竞争
    SIFT特征1999 · 视觉
    SIFT检测尺度不变的斑点并描述其梯度分布；MSER检测仿射协变的稳定区域，两者常被组合（MSER区域＋SIFT描述子）使用。
  • 竞争
    Harris角点1988 · 视觉
    Harris等点检测子对大视角变形不稳；MSER以整块区域为单位，在宽基线下重复率更高。

本篇术语

  • 极值区域　一个连通区域，其中所有像素都比它外边界上的像素更暗（或都更亮）。
  • 宽基线　两台相机（或两次拍摄）的位置差别很大，同一物体在两张图里的外观变形明显。

怎么学

先理解连通区域与阈值分割，再读论文第3节极值区域与稳定性的定义；用OpenCV的MSER检测一张街景照片中的文字区域并画出椭圆拟合。
