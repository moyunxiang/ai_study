TinyBERT

TinyBERT: Distilling BERT for Natural Language Understanding
2019.09论文延伸Findings of EMNLP 2020Xiaoqi Jiao, Yichun Yin, Lifeng Shang 等 · 华为诺亚方舟实验室 · 华中科技大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BERT太大，在手机等资源受限设备上跑不动；只让学生模仿教师最终输出，学到的东西不够。

方法

让小学生网络在Transformer的每一层上模仿教师BERT：对齐注意力矩阵和隐藏状态，并在预训练与下游任务两个阶段都蒸馏。

影响

4层小模型保住BERT的大部分能力，成为模型压缩的常用参考。

方法

传统知识蒸馏只让学生匹配教师最终输出的概率分布。TinyBERT针对Transformer设计了逐层蒸馏：学生的每层注意力分数矩阵要接近教师对应层，隐藏状态和嵌入层也要接近，输出层再配上常规的软标签损失。教师与学生层数不同，就按一定映射让学生的第k层对应教师的某几层。

训练分两阶段：先在通用语料的预训练阶段蒸馏，学到通用知识，再在具体任务上用数据增强后蒸馏。摘要称4层TinyBERT在GLUE上保持了BERT-base 96.8%以上的性能，体积小7.5倍、推理快9.4倍；6层版本与BERT-base相当。

局限与后续

  • 需要在预训练阶段也蒸馏，训练流程复杂、算力成本高。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM 已核对
    以BERT为教师，在GLUE上衡量压缩后的性能。
  • 改进
    知识蒸馏2015.03 · 系统·效率
    把输出层蒸馏扩展到Transformer的注意力与隐藏层。
  • 改进
    FitNets中间层蒸馏2014.12 · 系统·效率
    hint层和guided层的选择靠经验，且需要额外的回归器和两阶段训练。
  • 改进
    DistilBERT2019.10 · 系统·效率
    只做了预训练蒸馏，没有做逐层的注意力对齐。

后来的相关工作

  • 竞争
    ELECTRA替换词检测2020.03 · LLM
    TinyBERT先训大模型再蒸馏出小模型；ELECTRA-Small直接从头预训练，侧重降低预训练成本。
  • 竞争
    DistilBERT2019.10 · 系统·效率
    同月出现的另一种BERT蒸馏：DistilBERT只在预训练做输出与隐藏向量蒸馏，TinyBERT逐层对齐且两阶段蒸馏，但训练更复杂。
  • 竞争
    MiniLM2020.02 · 系统·效率
    TinyBERT逐层对齐多种中间表示；MiniLM只蒸馏最后一层的注意力关系，更简单也更灵活。
