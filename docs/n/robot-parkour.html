四足跑酷

Robot Parkour Learning
2023.09论文延伸Zhuang, Fu, Wang, Atkeson, Schwertfeger, Finn, Zhao · 上海科技大学 / Stanford / CMU / 上海期智研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

四足机器人要爬高台、跨沟、钻缝，现有方法要么只会盲走，要么每种技能各用一套专门设计的奖励和参考动作。

方法

用不依赖参考动作的简单奖励，在受直接配点法启发的强化学习中分别学出各技能，再蒸馏成一个只用自身深度相机的视觉策略。

影响

单个端到端视觉策略让低成本四足机器人完成攀爬、跳跃、钻爬、挤缝和奔跑等多种跑酷动作。

方法

训练分两阶段。先在仿真里为每种技能（爬高障碍、越过大间隙、钻低矮障碍、挤过窄缝、奔跑）分别训练一个策略，这些策略可以直接访问仿真中的地形信息；训练用一种受直接配点法（direct collocation）启发的RL方法，只需简单奖励，不用动物运动参考数据。

然后把这些技能蒸馏成一个策略，输入只是机器人自带的第一视角深度图像，再迁移到真机。摘要称它让两种低成本机器人完成了这些动作。

后来的发展

它把几分钟学会走路和RMA快速运动适应的“仿真训练、真机部署”从平地行走推进到视觉驱动的复杂地形，也成为HumanPlus等同一批作者后续工作的基础。

局限与后续

  • 技能库依赖仿真里的障碍类型，遇到训练中没有的障碍形状泛化有限。
