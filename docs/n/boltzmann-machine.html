玻尔兹曼机

A Learning Algorithm for Boltzmann Machines
1985论文延伸Cognitive Science 1985David Ackley, Geoffrey Hinton, Terrence Sejnowski · 卡内基梅隆大学待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

Hopfield网络网络只能存储记忆，没有隐藏单元，也无法学习内部表示，还容易陷在局部极小。

方法

给网络加上隐藏单元和随机的神经元状态，用模拟退火采样，学习规则只需要比较“数据驱动”和“自由运行”时的相关性。

影响

第一个可训练的带隐藏单元的概率生成网络，直接催生RBM和深度信念网络。

方法

玻尔兹曼机是一个全连接的随机二值单元网络，每个状态有一个能量E，状态概率p ∝ exp(−E)，与统计物理的玻尔兹曼分布一致，见能量模型与玻尔兹曼分布。部分单元是可见单元，对应数据，其余是隐藏单元。

学习目标是让网络自由运行时产生的分布接近数据分布，权重更新为两项之差：Δw_ij ∝ ⟨s_i s_j⟩_数据 − ⟨s_i s_j⟩_模型，前者在可见单元被钳制到数据时统计，后者在自由运行时统计。这是Hebb学习律规则加一个“睡眠阶段”的反Hebb规则。两项都要靠Metropolis采样与MCMC式的采样来估计，因此非常慢。

局限与后续

  • 每步更新都要采样到平衡，训练极其缓慢，难以扩展到大网络。

  • 延续
    Hopfield网络1982 · 基础
    在Hopfield能量网络上加隐藏单元和随机性，使其成为能学习内部表示的概率模型。
  • 使用
    Metropolis采样与MCMC1953 · 基础
    用Metropolis式的随机采样和退火来估计学习所需的统计量。

后来的相关工作

  • 竞争
    反向传播1986 · 基础 已核对
    Hinton参与提出的玻尔兹曼机学习也能训练隐藏单元，但要靠随机采样达到平衡、很慢；反向传播走的是确定性的梯度路线。
  • 改进
    深度信念网络2006 · 基础 已核对
    用层内无连接的受限玻尔兹曼机（RBM）作积木，给定一层时推断一步完成；本文说明RBM等价于权重绑定的无限深有向网络，再把RBM堆成深层模型。
  • 改进
    生成对抗网络GAN2014.06 · 生成 已核对
    不需要配分函数和马尔可夫链采样，一次前向传播即可生成样本，绕开了玻尔兹曼机训练与采样都很慢的问题。
  • 使用
    《并行分布式处理》1986 · 基础
    收录玻尔兹曼机作为带隐藏单元的随机网络的学习规则，与反向传播并列为两种训练隐藏单元的方法。
  • 使用
    Netflix Prize2006.10 · 数据·评测
    受限玻尔兹曼机被用来建模用户评分，是2007年进步奖方案中最好的两个部件之一。
  • 延续
    ReLU2010 · 基础
    在玻尔兹曼机的能量模型框架里推导出整数取值、近似softplus的新单元。
  • 改进
    扩散模型的起点2015.03 · 生成
    同样追求能拟合复杂分布，但每一步都是可解析的高斯，似然下界和采样都可精确计算，不需要配分函数。
  • 使用
    2024诺贝尔物理学奖与化学奖2024.10 · 科学
    物理学奖表彰的第二项工作：Hinton用统计物理发明的、能学习数据特征和生成样本的网络。
  • 竞争
    Helmholtz机与wake-sleep1995 · 生成
    同样是带隐变量的概率网络，但玻尔兹曼机靠耗时的采样学习，Helmholtz机用识别网络一次前向给出近似后验。
  • 改进
    对比散度2002 · 基础
    玻尔兹曼机需要跑到平衡态才能估计梯度，对比散度用几步采样即可近似，使训练可行。
  • 延续
    基于能量的学习2006 · 基础
    玻尔兹曼机是能量模型的特例；教程把它放进更一般的框架，去掉概率解释的必需性。
  • 改进
    神经自回归NADE2011.04 · 生成
    RBM的配分函数不可算，NADE用链式分解让似然精确可算。
  • 延续
    前向-前向算法2022.12 · 基础
    继承玻尔兹曼机学习中正相（数据）与负相（模型样本）对比的思想，但去掉了马尔可夫链采样。
  • 使用
    Extropic热力学采样芯片2025.10 · 硬件
    芯片上直接实现稀疏连接的玻尔兹曼机，用物理噪声完成吉布斯采样。
