FQF全参数化分位函数

Fully Parameterized Quantile Function for Distributional Reinforcement Learning
2019.11论文延伸NeurIPS 2019Derek Yang, Li Zhao, Zichuan Lin, Tao Qin, Jiang Bian, Tie-Yan Liu · Microsoft Research Asia, UC San Diego, Tsinghua University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

分布式RL要用有限个参数表示回报的整个分布。C51固定回报取值、学概率；QR-DQN固定分位点位置、学分位数值；IQN随机采样分位点——总有一条轴是固定或随机的，未必是最省参数的近似。

方法

让两条轴都可学：一个“分位点提议网络”为每个状态生成一组分位点τ₁<…<τ_N，一个“分位数值网络”给出这些分位点上的回报值。两个网络联合训练，使阶梯函数对真实分位函数的1-Wasserstein误差最小。

影响

把分布式RL的参数化做到“分布的横轴和纵轴都由网络决定”，在55个Atari游戏上创下当时非分布式智能体的新纪录，是C51、QR-DQN、IQN之后分布式DQN系列的重要一步。

背景

分布式RL C51把回报分布表示成固定支撑点上的类别分布，需要事先定好回报范围；分位数回归QR-DQN改为在N个等间隔分位点 τ_i = (2i−1)/2N 上回归分位数值，用分位数回归损失训练；隐式分位数网络IQN把分位点τ当作网络输入，每次随机采样，从而隐式表示整条分位函数。它们的共同点是：分位点的位置不随状态变化。但不同状态的回报分布形状差别很大，等间隔或随机的分位点可能把表达能力浪费在不重要的区域。

方法

FQF用N个分位点上的阶梯函数近似分位函数 F⁻¹(τ)。给定状态s：

  • 分位点提议网络输出一组递增的 0 = τ₀ < τ₁ < … < τ_N = 1（用softmax加累积和保证递增）；
  • 分位数值网络（与IQN相同的结构）对每个区间中点 τ̂_i = (τ_i + τ_{i+1})/2 输出回报值 F⁻¹(τ̂_i)。

分位数值网络用分位数回归的Huber损失训练，与QR-DQN、IQN一样。分位点网络则直接最小化阶梯近似与真实分位函数之间的1-Wasserstein距离 W₁。作者推导出 W₁ 对每个 τ_i 的梯度只需在 τ_i 和相邻中点处估计分位数值：

∂W₁/∂τ_i = 2F⁻¹(τ_i) − F⁻¹(τ̂_i) − F⁻¹(τ̂_{i−1})

因此不必知道真实分布，就能把分位点推向最能减小近似误差的位置。Q值由 Q(s,a) = Σ_i (τ_{i+1} − τ_i) F⁻¹(τ̂_i) 计算，用于贪心动作选择。

结果

摘要称，在55个Atari游戏上，FQF显著超过已有的分布式RL算法，并创下非分布式（单机训练）智能体在Atari学习环境上的新纪录。

后来的发展

FQF之后，分布式RL的参数化研究继续推进，例如保证分位数单调的非交叉分位数回归、用统计量或样本表示分布等；在实践中，IQN因实现更简单仍更常用，FQF常作为强对照出现在分布式RL的比较中。

读懂它需要的概念

Bellman方程 时序差分与自举 最优传输与Wasserstein距离 损失函数 期望与方差

本篇术语

  • 分位函数　累积分布函数的反函数：输入一个概率τ，给出“有τ的概率回报不超过它”的那个回报值。
  • 分位数回归　一种回归方法，用不对称的绝对值损失让预测值落在目标分布的某个分位上，而不是均值上。

怎么学

先读分位数回归QR-DQN和隐式分位数网络IQN理解分位数回归；读原文第3节W₁梯度的推导；用开源实现在一个Atari游戏上比较IQN与FQF，画出某个状态下两者分位点的分布。
