Interactive Language与Language-Table

Interactive Language: Talking to Robots in Real Time
2022.10论文延伸IEEE RA-L 2023Corey Lynch, Ayzaan Wahid, Jonathan Tompson, Tianli Ding, James Betker, Robert Baruch, Travis Armstrong, Pete Florence · Google待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

语言条件的机器人策略能听懂的指令很有限，而且通常是“说一句、执行完、再说一句”，人无法在执行过程中实时纠正和引导。

方法

在桌面推积木场景里收集几十万条带语言标注的轨迹，用行为克隆训练一个端到端的视觉—语言—动作策略，并让人可以随时用新的语言指令实时引导它。

影响

发布的Language-Table数据集（近60万条语言标注轨迹）后来被PaLM-E、RT-X等工作使用，是早期规模最大的语言条件机器人数据集之一。

方法

BC-Z和CLIPort证明了语言可以作为机器人策略的条件，但能理解的指令种类有限。这篇论文把数据规模往上推：在一个桌面推动彩色积木的场景里，用遥操作采集数十万条轨迹，并事后给轨迹片段标注自然语言描述，再用行为克隆训练一个直接从图像和语言输出动作的策略，整个系统以实时频率运行。

作者估计，这个策略在87,000条互不相同的自然语言指令上能达到93.5%的成功率，可执行的指令数量比此前工作多一个数量级。更有意思的是交互性：人可以一边看机器人推积木，一边不断说出新的短指令，策略即时响应，从而在人类实时指导下完成“用积木摆一个笑脸”这类精细的长时程摆放目标。论文开源了数据集、环境、基准和策略。
