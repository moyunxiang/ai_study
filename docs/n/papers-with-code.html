Papers with Code与SOTA榜

2018.07系统延伸2018Meta AI 旗下 · Papers with Code待核对
原站点（现已重定向） ↗在交互版中打开（演化树、学习进度）

问题

论文发表后很难知道某任务当前最好的方法是哪个、代码在哪里，各数据集的最优成绩分散在各篇论文里。

方法

把论文、代码和各数据集上的成绩榜（SOTA 榜）聚合到同一个网站，让读者按任务查看榜单与对应实现。

影响

『某任务在某数据集上的 SOTA』成为社区通用的叙事方式，也让 GLUE 一类榜单的比较更透明；后来网站被并入 Hugging Face 的论文页。

方法

该网站按机器学习任务和数据集整理论文与榜单，每条结果链接到论文和开源实现，用户可以直接看到『ImageNet分类的当前最佳是什么』。这是对 Kaggle数据竞赛 式排行榜的开放版本：成绩来自论文公布，不是统一在隐藏测试集上评分，所以并非严格的公平比较。

我们在写作时访问原网址，页面已显示为 Hugging Face 的 Trending Papers，说明站点已不再以原形态存在。关于站点创立人、被收购及下线的具体时间，本次未能核实，因此不在此给出。
