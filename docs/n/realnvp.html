标准化流RealNVP

Density Estimation using Real NVP
2016.05论文延伸ICLR 2017Laurent Dinh, Jascha Sohl-Dickstein, Samy Bengio · Google Brain待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

NICE可逆耦合层的加性耦合不改变体积，建模能力受限，且还没有适配图像的结构。

方法

在耦合层里加入由输入一半算出的缩放，并配合棋盘/通道掩码与多尺度结构，做成适合图像的可逆网络。

影响

给出标准化流的标准做法；它的仿射耦合层是Glow及后续流模型的核心部件。

方法

仿射耦合层把x拆成 x₁、x₂：y₁ = x₁，y₂ = x₂ ⊙ exp(s(x₁)) + t(x₁)，其中s和t是任意深度网络。雅可比矩阵仍是三角阵，行列式就是 exp(Σ s(x₁))，易算；逆变换为 x₂ = (y₂ − t(y₁)) ⊙ exp(−s(y₁))，s、t本身无需可逆。

对图像，用「棋盘」掩码（按空间位置交替取半）和「通道」掩码交替排列耦合层，并引入多尺度：每压缩一次，把一半维度的因子提前输出为潜变量，减少后续计算。批归一化也被用于流中。

结果：精确对数似然、精确采样、精确的潜变量推断，在四个数据集上通过采样、似然和潜变量操作展示效果。

局限与后续

  • 采样质量仍明显不如同期的GAN，潜变量与数据同维，参数量大。
