QRL拟度量强化学习

Optimal Goal-Reaching Reinforcement Learning via Quasimetric Learning
2023.04论文延伸ICML 2023Tongzhou Wang, Antonio Torralba, Phillip Isola, Amy Zhang · MIT / Meta AI / UT Austin待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

目标条件RL里，最优价值（到达目标的最短代价）天然满足三角不等式但不一定对称，是一种“拟度量”；而通用的价值网络和TD学习并不利用这种几何结构。

方法

直接用拟度量模型来表示最优目标条件价值，并设计专门的目标：在“相邻转移的距离不超过一步代价”的约束下，把所有状态对之间的距离推得尽量大，理论上恰好恢复最优价值（QRL）。

影响

把“价值函数的几何结构”作为归纳偏置引入目标条件RL，与对比RL、METRA等一起推动了用距离/时间结构学目标条件价值的方向，常被离线目标条件RL的工作比较。

方法

在确定性的目标到达问题里，设 d*(s, g) 是从s到g的最少步数（代价）。它满足 d*(s, s) = 0 和三角不等式 d*(s, g) ≤ d*(s, w) + d*(w, g)，但一般 d*(s, g) ≠ d*(g, s)（例如下坡容易上坡难）。满足这些性质的函数叫拟度量（quasimetric）。

QRL（Quasimetric Reinforcement Learning）用一个拟度量模型 d_θ(s, g)（论文采用可微的拟度量网络结构，如IQE，保证输出天然满足三角不等式）来表示价值，训练目标是：

max_θ E_(s, g ∼ 随机状态对)[ d_θ(s, g) ] s.t. E_((s, s′) ∼ 相邻转移)[ relu(d_θ(s, s′) − 1)² ] ≤ ε²

读法：约束要求每个一步转移的距离不超过1；在这个约束下最大化任意状态对之间的距离。因为d满足三角不等式，任何一条路径都把首尾距离限制在“步数”之内，最大化的结果恰好是最短路径长度 d*。作者给出了理论上的恢复保证。约束用拉格朗日乘子处理。策略再通过价值做提取。

作者在离散化的MountainCar上分析了QRL相对其他方法的性质，并在离线和在线的目标到达基准上（状态和图像观测）展示了更好的样本效率和表现。

    RIG想象目标视觉RL2018.07 · RL

    对比RL（目标条件）2022.06 · RL
    对比RL用对比学习估计到达概率；QRL用拟度量结构直接学最短距离。
