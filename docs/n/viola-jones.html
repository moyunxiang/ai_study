Viola–Jones人脸检测

Rapid Object Detection using a Boosted Cascade of Simple Features
2001论文延伸CVPR 2001Paul Viola, Michael Jones · Mitsubishi Electric Research Labs / Compaq CRL待核对
Crossref ↗在交互版中打开（演化树、学习进度）

问题

人脸检测需要在图像的每个位置和尺度上滑动窗口判断，传统分类器太慢，无法实时运行。

方法

用积分图像让矩形特征的计算只需几次加减，用AdaBoost从海量特征中挑出少数有用的，再把它们组织成由简到繁的级联。

影响

第一个能在普通电脑上实时运行的人脸检测器，数码相机和手机里的人脸框很长一段时间都来自它。

方法

三个部件。一，Haar类矩形特征：用图像中相邻矩形区域亮度之和的差表示，例如「眼睛区域比脸颊暗」。二，积分图像：预先计算每个位置左上方所有像素之和，之后任意矩形的和只需读四个值，所以一个特征的计算时间与矩形大小无关。三，用AdaBoost与集成学习从成千上万个候选特征里依次选出最有区分力的弱分类器，加权组合成强分类器。

最后是级联：先用只有几个特征的简单分类器快速拒绝绝大多数明显不是人脸的窗口，只有通过的窗口才进入下一级更复杂的分类器。绝大部分窗口在前几级就被丢掉，所以平均计算量很小。

局限与后续

  • 检测器针对正面、直立的人脸训练，对侧脸、旋转和遮挡的鲁棒性差。

  • 竞争
    可变形部件模型DPM2008.06 · 视觉
    Viola–Jones用刚性的级联分类器快速检测正脸；DPM用可变形部件处理姿态多变的通用类别，代价是速度慢得多。

读懂它需要的概念

集成学习 准确率、精确率、召回率与F1 图像作为张量

本篇术语

  • 积分图像　每个位置存放左上角所有像素之和的辅助图，使任意矩形区域求和只需四次读取。
  • 级联分类器　由多个由简到繁的分类器串联，前面的快速拒绝明显的负样本。

怎么学

学集成学习里的提升方法，然后用OpenCV的CascadeClassifier跑人脸检测并读积分图的实现。
