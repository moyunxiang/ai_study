GraphSAINT子图采样训练

GraphSAINT: Graph Sampling Based Inductive Learning Method
2019.07论文延伸ICLR 2020Hanqing Zeng, Hongkuan Zhou, Ajitesh Srivastava, Rajgopal Kannan, Viktor Prasanna · 南加州大学、美国陆军研究实验室待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大图上做小批量训练时，GCN每加一层要看的邻居数指数增长（邻居爆炸）；逐层采样邻居的方法又让深层的节点越来越稀疏、彼此连接差。

方法

换个角度：不在GCN的各层里采样节点或边，而是先从训练图上采样一个子图，在这个子图上构建一个完整的GCN；再用归一化系数消除采样偏差，并设计降低方差的采样器。

影响

与Cluster-GCN大图训练一起成为大图GNN训练的两种主流“子图小批量”方案，PyG提供了GraphSAINT采样器。

方法

GraphSAGE式方法在每一层为每个节点采样固定数目的邻居，层数一多，计算量仍随层数指数增长；FastGCN等逐层采样能控制规模，但被采到的节点之间连接稀疏。

GraphSAINT每一步：用某种采样器（随机节点、随机边、随机游走）从整张训练图中采出一个子图G_s，然后在G_s上跑完整的多层GCN前向与反向——所有层用的是同一组节点，规模固定、彼此连接良好。因为不同节点和边被采到的概率不同，直接在子图上聚合会有偏，作者推导了对聚合和损失的归一化系数（基于预先估计的节点、边被采样的概率），使估计无偏；并根据方差分析设计了边采样器的采样概率。采样与前向/反向传播解耦，可以和注意力、跳跃连接等多种结构组合。摘要报告在五个大规模图上，精度和训练时间都优于当时的方法。

局限与后续

  • 归一化系数需要预先多次采样估计；子图采样会丢掉跨子图的边，信息有损。

它建立在什么之上

  • 使用
    图卷积网络2016.09 · 基础
    在采样子图上运行完整的GCN。
  • 改进
    GraphSAGE2017.06 · 基础
    用子图采样代替逐层邻居采样，避免层数增加带来的邻居爆炸。
  • 竞争
    Cluster-GCN大图训练2019.05 · 基础
    同为在子图上训练完整GCN；Cluster-GCN用图划分得到子图，GraphSAINT用随机采样并做无偏校正。

读懂它需要的概念

图、树与搜索 随机梯度下降与小批量 重要性采样 图神经网络与消息传递

怎么学

先了解GraphSAGE的邻居采样与Cluster-GCN大图训练；读论文第3节归一化系数与第4节方差分析；动手用PyG的GraphSAINTRandomWalkSampler在ogbn-products上训练。
