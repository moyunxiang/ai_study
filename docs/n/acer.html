ACER

Sample Efficient Actor-Critic with Experience Replay
2016.11论文延伸ICLR 2017Wang, Bapst, Heess, Mnih, Munos, Kavukcuoglu, de Freitas · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

A3C是同策略算法，每条样本只用一次，样本效率比带回放的DQN差很多。

方法

给actor-critic加上经验回放，并用截断重要性采样加偏差修正、Retrace离策略修正式的多步目标以及一种新的信任域更新来保持稳定。

影响

第一个在Atari和连续控制上都表现出色的样本高效离策略actor-critic，影响了IMPALA与V-trace与后来的离策略路线。

方法

ACER的主要创新有三项。

  • 截断重要性采样加偏差修正：把策略梯度里的重要性比率截断到一个上限c以控制方差，被截掉的部分再用一个额外的修正项补回来，使估计无偏。
  • 随机的Dueling网络：把Dueling DQN的思想用在策略输出的离散概率分布与连续动作上，并用Retrace离策略修正估计Q值作为目标。
  • 新的信任域方法：不像TRPO那样每步算共轭梯度，而是在输出分布的统计量上线性近似约束，更新平均策略网络并限制与它的距离，计算更便宜。

摘要称它在57个游戏的Atari和多个连续控制问题上都表现稳定、样本高效。

局限与后续

  • 组件多（截断、偏差修正、Retrace、信任域），实现复杂，实践中被更简单的PPO取代。
    后来针对它的工作　PPO
  • 回放中的旧样本偏离当前策略过远时仍会引起不稳定。
    后来针对它的工作　IMPALA与V-trace

它建立在什么之上

  • 改进
    策略梯度定理1999 · RL 已核对
    梯度要在当前策略的状态分布上估计，数据只能同策略采集，旧经验无法直接复用。
  • 改进
    REINFORCE策略梯度1992 · RL 已核对
    严格同策略：每批数据只能用当前策略采样、用一次就丢，样本效率低。
  • 改进
    TRPO2015.02 · RL 已核对
    同一批样本只能用一次（on-policy），样本效率低。
  • 改进
    A3C2016.02 · RL
    在A3C的异步actor-critic基础上加入经验回放，提高样本效率。
  • 使用
    Retrace离策略修正2016.06 · RL
    用Retrace(λ)估计Q值目标，保证离策略多步修正的安全性。

后来的相关工作

  • 改进
    PPO2017.07 · RL
    组件多（截断、偏差修正、Retrace、信任域），实现复杂，实践中被更简单的PPO取代。
  • 改进
