随机网络蒸馏RND

Exploration by Random Network Distillation
2018.10论文重要ICLR 2019Yuri Burda, Harrison Edwards, Amos Storkey, Oleg Klimov · OpenAI / 爱丁堡大学待核对
arXiv ↗ar5iv全文 ↗OpenAI博客 ↗在交互版中打开（演化树、学习进度）

问题

稀疏奖励游戏（如《蒙特祖玛的复仇》）里随机探索几乎永远拿不到第一个奖励；用“预测下一帧的误差”当好奇心奖励，又会被随机噪声（如一台雪花电视）吸引住。

方法

固定一个随机初始化的网络，再训练另一个网络去模仿它的输出；对没见过的状态模仿得差、误差大，就给大奖励。目标是确定的函数，噪声无法制造“永远学不会”的误差。

影响

第一个不靠人类示范、不读取游戏内部状态，就在《蒙特祖玛的复仇》上超过人类平均分的方法；实现只需两个小网络，成为好奇心探索最常用的基线。

背景

Atari里有一组“难探索”游戏：Montezuma's Revenge、Pitfall!、Private Eye等。奖励极其稀疏，随机乱按几百万步也碰不到一次得分，DQN在Montezuma上几乎是0分。

解决思路是给智能体额外的内在奖励，鼓励它去新地方。伪计数探索用密度模型估计“伪计数”，访问越少奖励越高，但密度模型难训。好奇心模块ICM等“好奇心”方法用前向模型预测下一步观测，把预测误差当奖励——没见过的东西预测不准，误差大。但预测误差还来自另一个源头：环境本身的随机性。墙上有台播放随机雪花的电视，下一帧永远预测不准，智能体就会一直盯着它看。这就是“噪声电视”问题。

方法

两个网络。目标网络f：随机初始化后冻结，把观测映射成一个向量。预测网络f̂：用智能体实际收集到的观测训练，最小化‖f̂(x) − f(x)‖²。内在奖励就是这个误差：

i_t = ‖f̂(x_{t+1}) − f(x_{t+1})‖²

为什么有效。见过很多次的观测，预测网络已经学会模仿，误差小；新观测上误差大——这相当于一种可学习的计数（见知识蒸馏，这里蒸馏的对象是随机网络）。由于f是确定的函数，没有随机性可言，“噪声电视”无法让误差居高不下；也不需要预测下一帧，绕开了动力学建模。

与外在奖励结合。在PPO上用两个价值头分别估计外在回报和内在回报：内在回报按“非回合制”计算（游戏结束不清零，否则智能体会害怕死后从头再来，失去探索动力），外在回报照常按回合计算，两者用不同折扣率，最后加权相加作为优势。另外对观测和内在奖励都做归一化，否则奖励尺度随训练漂移。

结果

Montezuma's Revenge上最终平均8152分，同设置下的PPO为2497分，此前最好结果3700分，人类平均4753分；最好的智能体常能找到第一关24个房间中的22个，偶尔通关第一关。Venture、Gravitar也达到当时最佳。但在Pitfall!上仍是−3分，与PPO一样毫无进展。论文还发现，即使完全不用游戏分数、只最大化RND奖励，智能体也能稳定找到Montezuma一半以上的房间。

后来的发展

RND成为内在奖励的标准组件：Never Give Up用它作为“跨回合”的新奇度信号、再配合回合内记忆，Agent57继承了这一设计。同期的Go-Explore指出，仅靠内在奖励的方法会“忘记”还没探索完的区域，并在Montezuma和Pitfall上大幅超过RND。

局限与后续

  • 在Pitfall!等游戏上毫无进展；一旦某片区域被探索过、奖励消失，智能体不会主动回到那里继续向外探索。
    后来针对它的工作　Go-Explore Agent57
  • 新奇度只按“整个训练期间见过多少次”计算，同一回合内反复转圈不会受罚，回合内探索不足。
    后来针对它的工作　Never Give Up
  • 主要实验要处理十亿量级的游戏帧，规模扩展实验多达160亿帧，样本效率极低。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 内在奖励与外在奖励的权重、折扣率等需要按游戏调参。
    后来针对它的工作　Agent57

它建立在什么之上

  • 改进
    DQN2013.12 · RL 已核对
    需要1000万帧（约46小时实时游戏）才学会一款游戏，远比人类慢；ε-贪心在奖励稀疏的游戏里几乎找不到奖励。
  • 使用
    PPO2017.07 · RL 已核对
    在PPO上加第二个价值头估计内在回报，并分别使用回合制与非回合制回报。
  • 改进
    基于势函数的奖励塑形1999 · RL
    没有给出自动构造好势函数的方法；好的Φ接近最优价值函数，往往需要专家知识。
  • 改进
    R-max乐观探索2002.10 · RL
    需要为每个状态-动作单独计数，只适用于小的离散状态空间，无法直接用在图像等高维输入上。
  • 改进
    Arcade学习环境ALE2012.07 · RL
    Montezuma's Revenge等稀疏奖励游戏上所有方法都接近零分，探索问题完全没有解决。
  • 改进
    DQN（Nature版）2015.02 · RL
    Montezuma's Revenge等需要长程探索的游戏得分接近零，ε-贪心找不到稀疏奖励。
  • 改进
    好奇心模块ICM2017.05 · RL
    ICM用前向模型预测误差做好奇心，会被随机噪声吸引；RND改为预测一个确定的随机网络，避开了噪声电视问题，也不需动力学模型。
  • 改进
    Rainbow2017.10 · RL
    Montezuma's Revenge等困难探索游戏仍接近零分，Noisy Nets解决不了长程探索。
  • 延续
    Schmidhuber人工好奇心1991 · RL
    延续“把预测误差当好奇心奖励”的思想，换成一个不受环境随机性影响的预测目标。
  • 改进
    E3与PAC探索理论1998 · RL
    只针对表格MDP，函数近似下没有对应理论。
  • 改进
    Bootstrapped DQN2016.02 · RL
    在Montezuma's Revenge这类极稀疏奖励游戏上仍然很难，单靠价值不确定性不足以驱动长程探索。
  • 改进
    VIME信息增益探索2016.05 · RL
    每一步都要对贝叶斯网络做一次近似后验更新，计算开销大，难以扩展到图像输入。
  • 竞争
    伪计数探索2016.06 · RL
    伪计数用密度模型估计访问次数；RND用蒸馏误差隐式地起到计数作用，实现更简单、在Montezuma上分数更高。
  • 改进
    #Exploration哈希计数2016.11 · RL
    哈希粒度k要按环境手调：太粗会把需要区分的状态混在一起，太细又回到计数全为1的情况。
  • 改进
    NoisyNet噪声网络2017.06 · RL
    噪声只反映参数扰动，并不是对环境不确定性的有原则估计，在需要长程探索的稀疏奖励游戏上帮助有限。
  • 改进
    Ape-X2018.03 · RL
    探索仍靠ε-贪心，几乎没有奖励的难探索游戏仍无进展。
  • 改进
    纯好奇心大规模研究2018.08 · RL
    前向模型的预测误差在随机转移处永远降不下来，智能体会沉迷于噪声源（论文里的“噪声电视”实验）。

后来的相关工作

  • 改进
    Go-Explore2019.01 · RL
    RND在Montezuma上平均约8000分、Pitfall上0分附近；Go-Explore用先回去再探索把两者分别提高到数万分和首次正分。
  • 使用
    Agent572020.03 · RL
    经由NGU继承RND作为跨回合的新奇度信号。
  • 延续
    Never Give Up2020.02 · RL
    把RND作为跨回合调节因子，与回合内记忆奖励组合。
  • 竞争
    RIDE影响驱动探索2020.02 · RL
    RND在程序化环境中新颖性奖励区分度不足，RIDE在MiniGrid上明显更好。
  • 竞争
    Plan2Explore规划式探索2020.05 · RL
    RND用预测误差作新奇度，属于事后奖励的无模型方法；Plan2Explore用模型分歧并提前规划。
  • 使用
    NetHack学习环境2020.06 · RL
    把RND作为探索的基线方法。
  • 竞争
    APT主动预训练2021.03 · RL
    RND用预测误差衡量新颖度；APT直接以近邻距离估计状态熵，目标含义更明确。
  • 竞争
    PEBBLE偏好强化学习2021.06 · RL
    预训练阶段同样用内在奖励鼓励探索；PEBBLE选用基于k近邻的状态熵估计而不是预测误差。
  • 竞争
    BYOL-Explore自举探索2022.06 · RL
    RND预测固定随机网络的输出，与环境动力学无关；BYOL-Explore预测的是未来的学到的表示。

读懂它需要的概念

探索与利用 奖励、回报与折扣 策略梯度 Actor-Critic与优势函数 知识蒸馏

本篇术语

  • 内在奖励　不来自环境、由智能体自己计算的奖励，如新奇度、好奇心，用来驱动探索。
  • 噪声电视问题　以预测误差为好奇心的智能体，会被纯随机、永远无法预测的东西（如雪花屏电视）吸引，停在原地不再探索。
  • 难探索游戏　Atari中奖励极稀疏、随机策略几乎得不到分的一类游戏，Montezuma's Revenge是代表。

怎么学

先补探索与利用，读好奇心模块ICM的讲解理解好奇心方法与噪声电视问题。读原文第2节（2.2节对预测误差来源的分析）和第3节的消融。动手：在MiniGrid或简单迷宫上给PPO加一个RND奖励，对比有无内在奖励时探索到的格子数。
