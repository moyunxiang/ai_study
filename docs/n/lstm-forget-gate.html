LSTM遗忘门

Learning to Forget: Continual Prediction with LSTM
1999.09论文重要ICANN 1999；期刊版 Neural Computation 2000Felix A. Gers, Jürgen Schmidhuber, Fred Cummins · IDSIA（瑞士卢加诺）待核对
Neural Computation（DOI） ↗ICANN 1999会议版（DOI） ↗LSTM: A Search Space Odyssey（变体对比） ↗Understanding LSTM Networks（图解） ↗在交互版中打开（演化树、学习进度）

问题

1997年的LSTM记忆单元只会累加，处理没有切分好的连续数据流时状态会无限增长、输出饱和，必须靠人在每段序列开头手动清零。

方法

给记忆单元加第三个门：把旧状态乘以一个0到1之间、由网络自己算出的系数，让单元学会在内容过时时自动部分或完全清空。

影响

带遗忘门的版本成了此后所有人说的「LSTM」，在语音识别、机器翻译和语言建模里用了十几年；按输入决定衰减多少的思路又回到了2023年后的线性RNN与状态空间模型里。

背景

LSTM用一个自连接权重固定为1的线性单元（常数误差传送带，CEC）保存记忆，误差沿它回传时既不衰减也不爆炸，从而绕开了梯度消失问题。代价是：状态更新s(t) = s(t−1) + 输入门 × g(输入)只能往上加，没有任何机制让它变小。

原论文在每条训练序列开始前把状态人为清零，所以问题没有暴露。可现实中的输入往往是一条没有分段标记的长流（连续的语音、文本、传感器读数）。这时状态会随时间大致线性增长，让输出端的压缩函数h饱和：导数趋于0，误差传不进来，记忆功能失效。把自连接权重固定为小于1（如0.9）需要事先知道时间尺度，实验中也无改善；由外部在段落边界清零，又要求事先知道怎么切分，而这正是连续数据里没有的信息。

方法

把CEC固定的自连接权重1.0换成一个可学习的门。遗忘门和输入门、输出门一样，接收上一时刻网络各单元的输出，经sigmoid压到0到1之间：f(t) = σ(Σ w_φm · y_m(t−1))。状态更新改为

s(t) = f(t) · s(t−1) + 输入门(t) · g(输入(t))

用今天的写法就是c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t。f接近1时完整保留旧记忆，接近0时一步清空，中间值让记忆逐渐淡去，何时忘、忘多少都由数据决定。

关键细节是初始化：遗忘门的偏置设成正数，训练开始时f接近1，单元行为与原版LSTM一致，「学会忘记之前不会忘」。训练沿用LSTM的截断梯度，每步每个权重的计算和存储都是O(1)。

结果

主实验把许多条嵌入式Reber文法生成的符号串首尾相接成一条不带分段信息的流，网络每读一个符号就预测下一个；要预测每条串的倒数第二个符号，必须记住该串的第二个符号（T或P）。流一出错或连续预测对100,000个符号就停止。在100个独立训练的网络中，完美解比例：原版LSTM为0%，状态按0.9衰减的变体也是0%，由外部清零的原版LSTM为74%，带遗忘门的LSTM为18%，再配合学习率衰减达到62%。原版LSTM的状态约在13条串后增长到饱和而崩溃；带遗忘门的网络则学会在每条串开头把门关到接近0。在连续版「噪声时序」任务（最短间隔80步）上，原版LSTM同样是0%，带遗忘门为24%。

后来的发展

此后的LSTM几乎都带遗忘门：CTC和深层双向LSTM识别的语音识别、Seq2Seq与谷歌神经机器翻译的翻译都用这一版本。RNN编码器-解码器与GRU的GRU把输入门和遗忘门合成一个更新门。2015年对8种LSTM变体做的5400次实验发现，遗忘门和输出激活函数是最关键的两个部件。

2023年后的线性循环模型（门控线性注意力GLA、Mamba状态空间模型、Gated DeltaNet）给状态乘一个随输入变化的衰减系数，本质上就是遗忘门，只是去掉非线性，使整条序列可以并行训练；xLSTM则把遗忘门改成指数门控，重新扩展LSTM。

容易误解的地方

  • 遗忘门取值为1表示「全部保留」，取0才是「全部忘掉」，名字容易让人理解反。
  • 这里的「遗忘」指清空激活值里的短期记忆，与灾难性遗忘说的权重被新任务覆盖不是一回事。
  • 加了遗忘门后，误差沿状态回传时每步要乘以f，CEC不再严格「恒定」；长程记忆依赖网络学会在需要时让f保持接近1，所以正的偏置初始化很重要。
  • 1997年的原始LSTM没有遗忘门；窥视孔连接（gate能直接看到单元状态）是Gers等人之后的另一项改进，也不在这篇论文里。

  • 改进
    LSTM1997 · 基础
    解决了原版LSTM状态只增不减、在无分段的连续数据流上饱和失效、必须靠外部清零的问题。
  • 竞争
    时延神经网络TDNN1989.03 · 语音
    TDNN等时延网络要预先知道典型的时间间隔；遗忘门在不需要这种先验的前提下解决了重置问题。
  • 竞争
    Elman循环网络1990 · 基础
    在原版嵌入式Reber文法上，Elman网络在超过20万次序列呈现后仍学不会，而LSTM全部学会；连续版本里此类网络未被纳入比较。
  • 延续
    梯度消失问题1994 · 基础
    在避开梯度消失的恒定误差通道上加入可学习的衰减，让网络自己决定在哪里牺牲长程梯度换取重置。
  • 使用
    随时间反向传播BPTT1990 · 基础
    反向传播沿用LSTM的方案：输出侧用截断的BPTT，单元和门的权重用前向递推的RTRL式偏导。

本篇术语

  • 常数误差传送带（CEC）　LSTM记忆单元的核心：一个自连接权重固定为1的线性单元，误差沿它回传时数值不变。遗忘门把这个固定的1换成了可学习的系数。
  • Reber文法　一种用有限状态图随机生成符号串的人工文法，常用来测试循环网络的记忆能力；嵌入式版本要求记住串开头的符号直到串尾。
  • RTRL（实时循环学习）　一种不需要把序列展开再反向传播的循环网络训练法：每一步向前递推状态对各权重的偏导，存储量与序列长度无关。

怎么学

先读LSTM节点弄懂CEC和输入、输出门，补门控机制与梯度消失与梯度爆炸。再读原文第2.1节（原版LSTM为什么在连续流上失效）、第3.1节（只有两个公式）和第4.4节的状态曲线图。然后看Colah的图解，对照今天的c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t。动手：用PyTorch写一个LSTM单元，先把f固定为1，在把很多短序列首尾相接的数据流上训练，画出状态随时间的变化；再放开f，比较两条曲线。
