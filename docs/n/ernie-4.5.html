文心ERNIE 4.5开源

2025.06模型延伸2025-06-30 开源ERNIE Team · 百度待核对
GitHub ↗Hugging Face ↗在交互版中打开（演化树、学习进度）

问题

百度此前坚持闭源，文心大模型只通过文心一言和API提供；2025年开源模型（尤其DeepSeek）快速追平闭源模型后，闭源路线在开发者生态上明显落后。

方法

一次开源10个ERNIE 4.5变体：47B和3B激活参数的MoE模型（最大的多模态版本共4240亿参数）以及一个0.3B稠密模型，采用“异构模态MoE”——文本和视觉共享一部分专家，又各自保留专用专家，以Apache 2.0许可发布。

影响

百度首次以宽松许可开源主力大模型，被媒体视为中国大厂集体转向开源的一个标志；配套的ERNIEKit训练工具和飞桨推理部署也一并公开。

方法

背景：百度的百度ERNIE系列从2019年的知识增强预训练开始，经ERNIE 3.0发展到2023年的文心一言（文心一言），一直以闭源服务为主。2025年初DeepSeek-V3等开放权重模型迅速流行，百度在2月宣布将开源下一代文心模型，并于6月30日正式发布开源的ERNIE 4.5系列。

模型：官方仓库称ERNIE 4.5是一个包含10个变体的大规模多模态模型家族，包括总参数最大4240亿、激活470亿的多模态MoE，激活参数30亿的轻量MoE，以及0.3B稠密模型；纯文本旗舰为ERNIE-4.5-300B-A47B（约3000亿总参数、470亿激活）。架构上提出异构模态MoE：不同模态之间共享部分参数，同时为每种模态保留专用参数，官方称这样能增强多模态理解而不损害、甚至改善文本任务表现，这与DeepSeekMoE细粒度专家式共享专家的思路同属一类。全部模型在飞桨（百度飞桨PaddlePaddle）上训练，官方称最大语言模型预训练的模型FLOPs利用率（MFU）达到47%。

结果：官方称在多个文本与多模态基准上达到领先水平，尤其在指令遵循、世界知识记忆、视觉理解和多模态推理上；这些均为厂商自报。之后又陆续开源了21B-A3B-Thinking、VL-28B-A3B-Thinking等推理版本。

局限与后续

  • 基准成绩以厂商自报为主；开源时百度的旗舰闭源模型已迭代到更新版本，开源的4.5并非当时百度最强模型。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 训练和部署工具链以飞桨为核心，对习惯PyTorch生态的开发者有迁移成本（模型也提供了transformers格式）。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

混合专家 语言模型 参数量、计算量与显存 预训练与微调

本篇术语

  • 异构模态MoE　多模态MoE的一种设计：一部分专家对文本和图像都开放，另一部分只处理某一种模态，兼顾知识共享和模态特化。
  • MFU（模型FLOPs利用率）　训练中实际用于模型计算的浮点运算速度占硬件理论峰值的比例，衡量训练系统的效率。

怎么学

先读DeepSeekMoE细粒度专家理解共享专家与细粒度专家；读ERNIE GitHub仓库的介绍和其中链接的技术报告里关于异构MoE与训练效率的部分；动手：下载ERNIE-4.5-0.3B或21B-A3B，比较与同规模Qwen模型在中文问答上的输出。
