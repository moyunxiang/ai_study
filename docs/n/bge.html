BGE嵌入模型

C-Pack: Packed Resources For General Chinese Embeddings
2023.09论文延伸SIGIR 2024Shitao Xiao, Zheng Liu, Peitian Zhang, Niklas Muennighoff, Defu Lian, Jian-Yun Nie · 北京智源（BAAI）/ 中科大 / 蒙特利尔大学等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

中文文本嵌入缺少统一的评测基准和大规模训练数据，开源模型在中文检索上远不如英文成熟，影响RAG落地。

方法

同时发布评测基准C-MTEB、训练数据集C-MTP和嵌入模型家族BGE，覆盖多种规模，并开放英文模型和数据。

影响

BGE成为开源社区最常用的嵌入模型之一，是中文和多语言RAG的默认选择。

方法

C-Pack由三部分组成。C-MTEB：覆盖6类任务、35个数据集的中文嵌入评测基准，仿照英文的MTEB嵌入基准。C-MTP：从有标注和无标注的中文语料整理的大规模训练数据。C-TEM（即BGE模型）：多种规模的模型，训练方法整合了预训练、对比学习（见对比学习）和微调，和Sentence-BERT、Contriever无监督检索、E5文本嵌入同属“双塔嵌入”路线。

摘要称模型在发布时比此前所有中文嵌入在C-MTEB上最多高10%。同时发布的英文模型在MTEB上达到当时最好水平，英文数据比中文多一倍。

局限与后续

  • 评测和训练主要面向中文和英文，其它语言和长文档的嵌入质量仍有差距。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 嵌入模型只给出整段文本的单个向量，细粒度、多跳检索仍需额外的重排或图检索。

它建立在什么之上

  • 改进
    FAISS向量检索2017.02 · 推理·智能体
    它只负责“在向量里找近邻”，检索质量完全取决于向量本身是否表达了语义；当时还没有好用的文本检索向量。
  • 延续
    Sentence-BERT2019.08 · NLP
    沿用双塔句向量的思路，规模和数据大幅提升。
  • 改进
    ColBERT后期交互2020.04 · 推理·智能体
    训练只用MS MARCO上BM25挖出的负例，跨领域、跨语言的效果没有验证。
  • 改进
    MTEB嵌入基准2022.10 · 数据·评测
    以英语为主，多数中文、低资源语言只出现在少数双语挖掘和分类集里。
  • 使用
    Contriever无监督检索2021.12 · 推理·智能体
    借鉴无监督对比预训练的做法。
  • 竞争
    OpenAI文本嵌入2022.01 · 推理·智能体
    当时的商用闭源嵌入服务，BGE以开源方式在中英文评测上追平或超过。
  • 改进
    E5文本嵌入2022.12 · LLM
    网络文本对的质量参差不齐，噪声会限制嵌入质量，且这类弱监督数据对多语言、长文档的覆盖不均。
