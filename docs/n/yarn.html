YaRN

YaRN: Efficient Context Window Extension of Large Language Models
2023.08论文重要Bowen Peng, Jeffrey Quesnelle, Honglu Fan, Enrico Shippole · Nous Research / EleutherAI / 日内瓦大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

位置插值把RoPE的所有维度一律压缩，高频维度里相邻token变得难以区分；扩展倍数到8倍左右模型就开始退化，而且需要较多的长文本微调。

方法

按维度的“波长”区别对待：转得快的高频维度不插值，转得慢的低频维度完全插值，中间平滑过渡；再给注意力softmax加一个随扩展倍数变化的温度。合起来叫YaRN。

影响

只用约为此前方法1/10的token、1/2.5的训练步数，就把Llama 2扩展到64K乃至128K上下文；此后被DeepSeek-V3等开源模型用于在预训练之后扩展上下文。

背景

旋转位置编码RoPE让第m个位置的第d组维度旋转m·θ_d角度，θ_d = b^(−2d/|D|)（b通常为10000）。不同维度转速差别极大：转一整圈所需的token数叫波长，λ_d = 2π/θ_d。低维的波长只有几个token，高维的波长可能比整个训练长度还长。

位置插值扩上下文把位置统一乘以1/s（s是扩展倍数），等于把每个维度都放慢s倍。这对低频维度正好——它们本来就没转完一圈，压缩后仍在见过的范围内；但对高频维度是损失——原本相邻token之间的角度差被缩小s倍，模型分不清近处的词序。作者统计，此前用位置插值的微调大约只能扩到s≈8。社区开发者bloc97提出的“NTK感知”插值改为高频少压、低频多压，效果更好，但不容易确定该用多大的基频。

方法

按波长分段插值（NTK-by-parts）。对每个维度算比值r(d) = L/λ_d，即在原训练长度L内该维度转了多少圈：

  • r < α（转不到一圈的低频维度）：完全按位置插值，θ_d → θ_d/s，避免外推；
  • r > β（转了很多圈的高频维度）：不改，保留近距离的分辨率；
  • 介于两者之间：用斜坡函数γ(r)线性混合，θ′_d = (1−γ)·θ_d/s + γ·θ_d。

对Llama系模型，作者取α=1、β=32。

注意力温度。上下文变长后，softmax要在更多token上分配注意力，分布变得更平、熵升高。YaRN把注意力分数除以温度t：softmax(q·k/(t·√|D|))，并给出经验公式√(1/t) = 0.1·ln(s) + 1。实现上只需把旋转后的Q、K同乘一个系数，不改注意力代码，也不增加推理开销。

动态缩放。推理时按当前实际长度动态选择s，在训练长度内不改动，超出后逐步放大，使模型平滑退化而不是突然崩溃。

结果

把Llama 2 7B和13B（原上下文4K）在PG19长文本上微调：s=16时训练400步，s=32时在其基础上再训练200步，训练数据都只有64K长度。在10篇128K长度的Proof-pile文档上，s=32的7B模型从8K到128K困惑度一路下降（3.56→2.37），说明它能外推到比微调数据更长的上下文。论文称所需token约为此前方法的1/10、训练步数约1/2.5。在LLaMA 7B扩展16倍的对照中，YaRN在HellaSwag和TruthfulQA上优于位置插值，短上下文能力损失较小，但MMLU仍从35.7降到30.0。

后来的发展

YaRN成为开源模型扩展上下文的常用工具，例如DeepSeek-V3在预训练后用YaRN分两个阶段把上下文从4K扩到32K、再到128K。LongRoPE进一步用搜索为每个维度找最佳缩放系数，把扩展推到更大的倍数。与Code Llama“直接调大基频”的做法一起，“预训练用短上下文、最后阶段用RoPE缩放扩长”成为长上下文模型的常见流程。

容易误解的地方

  • YaRN仍然需要少量微调才能达到最好效果；不微调直接用（配合动态缩放）也能工作，但效果较差。
  • 困惑度和口令检索好，不代表模型能在长文中做复杂推理，见迷失在中间和RULER长上下文。

局限与后续

  • α、β和温度公式都是在Llama系模型上凭经验调出来的，换模型或换更大倍数时不一定最优。

读懂它需要的概念

位置编码 傅里叶变换与频域 Softmax与logits 信息量与熵 上下文窗口 困惑度

本篇术语

  • 波长　RoPE中某一组维度旋转一整圈（2π）所需的token数。波长短的维度区分近处位置，波长长的维度区分远处位置。
  • NTK感知插值　社区提出的RoPE扩展方法，通过调大基频让高频维度少压缩、低频维度多压缩，名字来自神经正切核理论中关于高频信息的分析。
  • 动态缩放　推理时按当前序列的实际长度选择缩放倍数，而不是固定一个倍数。

怎么学

先读旋转位置编码RoPE和位置插值扩上下文。读YaRN论文第3节，按3.1→3.2→3.3的顺序理解从“NTK感知”到“分段”再到“温度”的演进。动手：对一个d=128的RoPE，算出每组维度的波长和r(d)，标出哪些维度会被插值、哪些不动；然后在Hugging Face模型里设置rope_scaling={type: yarn, factor: 4}，比较长文本困惑度。
