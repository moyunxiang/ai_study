相对位置表示

Self-Attention with Relative Position Representations
2018.03论文延伸NAACL 2018Peter Shaw, Jakob Uszkoreit, Ashish Vaswani · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Transformer靠给输入加绝对位置向量来知道词序，但语言里真正重要的往往是两个词相隔多远。

方法

在自注意力里直接加入「两个位置之间的相对距离」的可学习向量，让注意力分数和输出都能感知距离。

影响

相对位置的思路被后续T5偏置、Transformer-XL、旋转位置编码RoPE、ALiBi线性偏置位置一路继承。

方法

原版Transformer把正弦的绝对位置向量加到词向量上，注意力本身不知道谁在谁前面几个词。这篇工作改为：对每一对位置(i, j)，取一个只依赖距离j − i的向量，把它加到计算注意力分数的键上，也加到加权求和用的值上。距离超过某个阈值（论文做了截断）的统统共用同一个向量，这样模型也能处理没见过的更长句子。

在WMT 2014英德和英法翻译上，相对位置比绝对位置分别高1.3和0.3个BLEU；有意思的是，两者叠加并没有更好。作者还把它写成「关系感知的自注意力」，可推广到带标签边的图结构输入。

局限与后续

  • 需要为每一对位置额外计算和存储一个距离向量，序列越长开销越大。
    后来针对它的工作　旋转位置编码RoPE ALiBi线性偏置位置
  • 距离被截断后，对远距离的区分能力有限，长度外推效果也没有被系统验证。
    后来针对它的工作　ALiBi线性偏置位置

它建立在什么之上

  • 延续
    Transformer2017.06 · LLM
    把Transformer中的绝对位置编码换成注意力内部的相对距离表示。

后来的相关工作

  • 延续
    DeBERTa解耦注意力2020.06 · LLM
    Shaw等只算“内容对相对位置”一项，DeBERTa补上“位置对内容”，并把内容和位置的表示完全分开。
  • 改进
    旋转位置编码RoPE2021.04 · LLM
    同样实现相对位置，但不需要构造n×n的相对位置嵌入，实现更简单，也能用于线性注意力。
  • 延续
    ALiBi线性偏置位置2021.08 · LLM
    同样把位置信息写在注意力分数上、只依赖相对距离，但把可学习的距离表示换成一条固定直线。
  • 竞争
    深层Transformer与DLCL2019.06 · LLM
    同期改进翻译Transformer的另一条路是改位置编码等组件，本文选择从深度入手。
  • 延续
    CoAtNet混合骨干2021.06 · 视觉
    把相对位置表示引入视觉注意力，并说明它与深度卷积的等价联系。

读懂它需要的概念

自注意力与多头注意力 位置编码 内积与余弦相似度 嵌入向量

怎么学

先复习位置编码；读原文第3节的公式，自己实现一个带相对位置偏置的单头注意力。
