感知机

The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain
1958论文主干Psychological Review 1958Frank Rosenblatt · Cornell Aeronautical Laboratory来源已核对
DOI ↗Wikipedia: Perceptron ↗在交互版中打开（演化树、学习进度）

问题

M-P神经元能计算逻辑函数，但每个连接的权重都得由人事先设计好；机器能不能自己从例子里学会这些权重？

方法

一个随机连接的阈值单元网络，靠强化调整连接强度学会把刺激和响应对应起来；后来的标准形式是分错就按误差改权重，线性可分时有限次修正必然收敛。

影响

最早一批能从样例中学习的神经网络模型之一，还造出了专用硬件Mark I；它的成功与它的局限（XOR）常被用来说明神经网络此后几十年的起伏。

背景

1943年的M-P神经元证明了：把“加权求和、超过阈值就输出1”的简单单元连起来，可以实现任何逻辑运算。但这些网络是设计出来的——每个权重、每个阈值都要人手工定好，网络本身不会学。1949年Hebb学习律提出了一条猜想式的规则：两个神经元同时活跃，它们之间的连接就加强。这给了“学习=改变连接强度”一个方向，但还没有一个能放到机器上跑、并且能证明会收敛的算法。

同一时期，达特茅斯会议之后兴起的符号主义路线（如逻辑理论家）认为智能来自对符号和规则的操作，知识要由人写进程序。Rosenblatt站在另一边：他是心理学家，想回答的问题是“大脑如何存储信息、又如何用存储的信息去识别新东西”，他的答案是一个从经验中调整连接的网络。

方法

模型。一个感知机单元接收输入向量x = (x₁, …, x_n)，算加权和再与阈值比较（见神经元与激活函数）：

ŷ = 1 如果 w·x + b > 0，否则 ŷ = 0

几何上，w·x + b = 0是空间中的一个超平面，感知机就是用这个超平面把空间切成两半，一半判为正类、一半判为负类（见内积与余弦相似度）。

学习规则。1958年的论文本身用的是“强化”的说法：被激活的联想单元在强化时获得“值”的增量，论文比较了几种分配增量的方式（alpha、beta、gamma系统），并用概率方法分析学会后正确响应的概率。今天教科书里的标准形式是后来整理出来的误差修正规则：逐个看训练样本，判对了什么都不做；判错了就修正：

w ← w + η·(y − ŷ)·x， b ← b + η·(y − ŷ)

例子：某个正样本x = (1, 2)被判成了0，那么y − ŷ = 1，权重加上η·(1, 2)，下次这个样本的加权和就变大，更可能越过阈值；负样本判成1时则反过来减去它。这和Hebb学习律“一起活跃就加强”的直觉一致，但多了一个关键改动：只在出错时才改，改动方向由误差决定。

收敛定理（不在1958年论文中，是此后几年里的结果）。如果两类数据确实能被某个超平面分开（线性可分），这条规则在有限次修正后一定停在一个把训练集全部分对的解上。Novikoff在1962年给出了简洁证明：修正次数的上界只取决于数据点离原点多远和两类之间最窄的空隙（间隔）有多宽，与样本数量无关。

Mark I硬件。Rosenblatt的设想是一台机器而非一个程序：1957年先在IBM 704上做软件模拟，随后造出Mark I感知机——20×20共400个光电管组成“视网膜”（S单元），随机连到一层联想单元（A单元），再连到输出的响应单元（R单元）。S到A的连接是随机接线后固定的，只有A到R的权重可学，由电动电位器实现。

结果

1958年的论文本身主要是理论分析：用概率方法推导随机连接网络在不同参数下对学过的刺激做出正确响应、以及对没见过的同类刺激正确泛化的概率曲线；论文说在康奈尔航空实验室的IBM 704上做了详细模拟，结果符合理论的主要预测，细节另行发表。论文结论也承认，仅靠统计可分性不足以支撑更高阶的抽象，需要原理上更先进的系统。

Mark I于1959年6月至12月在布法罗（康奈尔航空实验室所在地）组装测试，1960年6月首次公开演示，专为图像识别设计；1960至1964年间，美国中央情报局的图像判读部门还研究过用它识别航拍照片中飞机、舰船等目标的轮廓。1958年美国海军组织的发布会后，《纽约时报》报道称这是一台“将来能走路、说话、看、写、自我复制并意识到自身存在”的电子计算机的雏形——这类过度宣传后来成为反弹的伏笔。1962年Rosenblatt把大量实验汇总进《Principles of Neurodynamics》。

后来的发展

感知机的误差修正规则可以看作今天神经网络训练思路的早期形态：看误差、按误差方向改权重。几乎同时的ADALINE与LMS把“只在出错时改”换成对平方误差做梯度下降，更接近现代做法。

1969年《Perceptrons》与XOR问题严格证明了单层感知机算不了XOR、奇偶性这类非线性可分的问题，此后神经网络研究明显降温。多层网络的训练问题后来由反向传播给出了实用方法：给网络加隐藏层，并且让隐藏层的权重也能学。另一条路线是支持向量机：在所有能分开数据的超平面里挑间隔最大的那个，再用核技巧与最优间隔分类器把数据映射到高维空间变得线性可分。今天，深度网络最后一层“线性层+softmax”在形式上仍是一个类似多类感知机的线性分类器。

容易误解的地方

  • 感知机不是“没有隐藏层”这么简单：Mark I有一层A单元，只是这一层是随机接线、不学习的。Rosenblatt本人也研究过多层结构，问题在于没有办法训练中间层。
  • 收敛定理只在线性可分时成立；数据不可分时，标准感知机规则会永远来回振荡，不会停在“错得最少”的解上。
  • 即使可分，它停在第一个把训练集全分对的超平面上，这个超平面可能紧贴某些样本，泛化不好——这正是SVM要解决的问题。

局限与后续

  • 单层可学习权重只能画一条直线（超平面），XOR、奇偶性这类线性不可分的问题原理上无法表示。
    后来针对它的工作　反向传播 核技巧与最优间隔分类器 支持向量机
  • Mark I中间那层的连接是随机固定的，没有办法训练隐藏层，网络不能自己学出有用的中间特征。
    后来针对它的工作　反向传播
  • 数据线性不可分时学习规则不收敛，权重会一直振荡。
    后来针对它的工作　ADALINE与LMS
  • 只要求把训练集分对，停在哪个超平面带有随意性，不追求最大间隔，泛化无保证。
    后来针对它的工作　支持向量机 VC维与一致收敛

后来的相关工作

  • 改进
    反向传播1986 · 基础 已核对
    感知机规则只能调最后一层，反向传播让所有层的权重都能根据误差学习。
  • 改进
    支持向量机1995 · 基础 已核对
    论文从Rosenblatt的感知机讲起：只有输出层可学，在固定的特征空间里构造线性超平面；支持向量网络同样在特征空间里构造线性面，但选间隔最大的那个，并允许训练错误，软间隔问题的解唯一。
  • 改进
    VC维与一致收敛1971 · 基础 待核对
    感知机的收敛定理只保证在训练集上分对；VC理论回答了它分对之后能否推广：d维线性分类器的VC维是d+1，样本数需随维数增长。
  • 延续
    ADALINE与LMS1960 · 基础 待核对
    把感知机的“错了才改”换成对平方误差做梯度下降，学习目标变得明确。
  • 延续
    核技巧与最优间隔分类器1992 · 基础 待核对
    把感知机的线性分类推进到最大间隔，并通过核获得非线性。
  • 竞争
    逻辑回归1958 · 基础
    同一年出现的两种线性分类器：感知机只在分错时修正、追求分对，逻辑回归用似然给出概率；后来神经网络沿用的恰恰是逻辑回归的sigmoid加交叉熵。
  • 延续
    《Perceptrons》与XOR问题1969 · 基础
    对感知机做了第一次严格的能力分析：证明单层、局部特征的感知机算不了奇偶性、判断不了连通性，把它的收敛定理放进了“能表达什么”的边界之内。
  • 竞争
    遗传算法1975 · 基础
    同样从生物借来学习机制：感知机模仿神经元调权重，GA模仿种群进化，代表了两条不同的“自适应系统”路线。
  • 改进
    Neocognitron1980 · 视觉
    感知机对输入整体平移极其敏感；局部连接、权重共享加逐级容忍位移，让识别结果基本不受平移影响。
  • 竞争
    Hopfield网络1982 · 基础
    感知机是前馈的、靠误差纠正训练的分类器；Hopfield网络是循环的、一次存储的联想记忆。后来主流走了前馈加反向传播的路线，能量的思想则在玻尔兹曼机和能量模型里延续。
  • 延续
    万能近似定理1989 · 基础
    把感知机式的“线性变换加非线性”单元并联成一层，再线性组合，研究其整体能表示什么。

读懂它需要的概念

向量、矩阵与张量 内积与余弦相似度 神经元与激活函数 监督学习 线性回归

本篇术语

  • 线性可分　存在一个超平面（二维里是一条直线），能把两类点完全分到两侧。XOR的四个点就不是线性可分的。
  • 超平面　n维空间里由一个线性方程w·x + b = 0定义的n−1维“平面”，把空间分成两半。
  • 间隔（margin）　分界面到离它最近的样本点的距离。间隔越大，分类越“稳”，对新样本越不容易判错。

怎么学

先确认会内积与余弦相似度和向量、矩阵与张量。然后用NumPy在二维平面上随机生成两团可分的点，自己写20行的感知机训练循环，每轮画出分界线，看它如何一步步转到正确位置；再把数据换成XOR的四个点，观察它永远停不下来。理论部分读维基百科Perceptron词条的收敛定理证明（Novikoff 1962），只需要内积和柯西–施瓦茨不等式。
