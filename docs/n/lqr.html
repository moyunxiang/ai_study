LQR最优控制

Contributions to the Theory of Optimal Control
1960论文延伸1960Rudolf E. Kalman · RIAS（美国）待核对
维基：LQR ↗在交互版中打开（演化树、学习进度）

问题

PID要靠经验整定，多变量耦合系统没有系统的设计方法，也没有“最优”的含义。

方法

给线性系统定义一个二次代价（状态偏差与控制能量），其最优反馈律有解析解：u = −Kx，K由Riccati方程解出。

影响

让多变量反馈设计变成可计算的最优化问题，也是后来模型预测控制MPC和轨迹优化的起点。

方法

线性系统 ẋ = Ax + Bu，代价取 J = ∫(xᵀQx + uᵀRu) dt：Q惩罚状态偏离目标，R惩罚控制用力。最优控制是状态的线性反馈 u = −Kx，增益K由代数Riccati方程的解P给出（K = R⁻¹BᵀP）。设计者不再手调增益，而是调Q、R这两个“偏好”矩阵。LQR还带有已证明的增益、相位裕度，并与卡尔曼滤波（卡尔曼滤波）一起构成LQG：先估计状态，再按LQR反馈。

局限也很清楚：只对线性模型成立；不能直接表达“力矩不能超过上限”这样的约束；Q、R怎么取没有现成答案。把带约束的有限时域问题放在滚动时域上反复求解，就是模型预测控制MPC。

局限与后续

  • 只适用于线性系统，倒立摆等非线性机器人要在工作点附近线性化，偏离工作点就失效。
    后来针对它的工作　模型预测控制MPC
  • 无法处理输入、状态约束（如关节力矩上限）。
    后来针对它的工作　模型预测控制MPC

它建立在什么之上

  • 使用
    卡尔曼滤波1960 · 具身·世界模型 已核对
    与卡尔曼滤波配对构成LQG：先估计状态再做最优反馈。
  • 延续
    PID控制1922 · 具身·世界模型
    同样是状态反馈，但把增益整定改为在二次代价下求最优解。

后来的相关工作

  • 延续
    卡尔曼滤波1960 · 具身·世界模型 已核对
    论文指出滤波问题是作者此前已解决的无噪声最优调节器问题的对偶（引用的是Kalman 1958–1959年的调节器工作），两者的数学背景相同；后来的LQG就是把两者组合起来。
  • 改进
    模型预测控制MPC1980 · 具身·世界模型 待核对
    LQR是无约束、无限时域的二次最优控制；MPC改成有限时域并在线滚动求解，从而能把执行器和安全约束放进优化。
  • 使用
    引导策略搜索GPS2013.06 · 具身·世界模型
    引导样本来自DDP，即在轨迹附近反复线性化动力学、二次化代价后求解LQR式的局部反馈控制器。
