相对判别器RaGAN

The relativistic discriminator: a key element missing from standard GAN
2018.07论文延伸ICLR 2019Alexia Jolicoeur-Martineau · Lady Davis研究所、Mila待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

标准GAN的判别器只判断“这张图是真的概率”，生成器只努力让假图看起来更真；作者认为这漏掉了一个先验：一个批次里一半是假的，生成器也应该同时让真图“显得没那么真”。

方法

让判别器估计“给定的真图比随机抽的一张假图更真实的概率”（相对判别器），或“比假图平均更真实的概率”（相对平均判别器），并把这一思路推广到各种GAN损失。

影响

相对平均GAN（RaGAN）训练更稳、质量更好，被ESRGAN等超分辨率模型直接采用；其成对比较形式（RpGAN）后来成为R3GAN等现代GAN基线的核心损失。

方法

标准GAN判别器输出D(x) = σ(C(x))，C是未经sigmoid的“评分”。相对判别器改为比较一对样本：D(x_r, x_f) = σ(C(x_r) − C(x_f))，表示真图x_r比假图x_f更真实的概率。判别器最大化这个概率，生成器则最小化它，也就是让假图的评分超过真图——这样生成器的梯度同时作用于“抬高假图”和“压低真图”两侧。

相对平均版本（RaGAN）不用一对一比较，而是和对方批次的平均评分比：D(x_r) = σ(C(x_r) − E[C(x_f)])，D(x_f) = σ(C(x_f) − E[C(x_r)])。作者还证明，基于积分概率度量（IPM）的GAN（如WGAN）可以看作相对GAN在恒等函数下的特例。

实验观察：RGAN和RaGAN比非相对版本更稳定、样本更好；带梯度惩罚的RaGAN只需每次生成器更新配一次判别器更新，就比WGAN-GP质量更好，达到同等水平的时间缩短约400%；在只有2011张图的小数据集上也能生成可信的256×256图像，而GAN和LSGAN做不到。

局限与后续

  • 相对损失本身不保证收敛，后来R3GAN的分析表明还需要R1、R2梯度正则配合才能稳定训练。

  • 积分概率度量（IPM）　用一族函数在两个分布上的期望之差的最大值来衡量分布距离，Wasserstein距离是其中一种。
