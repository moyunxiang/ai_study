Veo 3音画同步视频

2025.05模型重要Google DeepMind来源已核对
Google发布公告（I/O 2025） ↗Veo 3技术报告PDF ↗DeepMind Veo模型页 ↗在交互版中打开（演化树、学习进度）

问题

Sora之后的视频模型画面越来越好，但都是“默片”：环境音、音效和人物对白要另外生成再手工对齐，口型更是难以匹配。

方法

在潜空间扩散框架下，把音频潜变量和视频的时空潜变量放在一起联合去噪，由同一个Transformer去噪网络一次生成画面和与之同步的声音、对白。

影响

一句提示即可生成带对白、口型和音效的短片；之后多家视频模型也加入了原生音频，同时它也加剧了对深度伪造内容的担忧。

背景

2024年的视频生成竞赛基本沿着Sora的配方展开：视频压缩到时空潜空间，用扩散Transformer生成。Veo 2、可灵Kling、Movie Gen、HunyuanVideo在画质、运动和物理上不断进步，但视频生成模型本身输出的都是无声画面。要做一段有台词的片子，创作者必须先生成画面，再用另外的配音、音效模型生成音频，最后手工对齐，人物口型几乎不可能对上。Meta的Movie Gen虽然配了一个“视频到音频”的模型，但仍是在视频生成之后再为视频配音效和音乐的两步流程。

方法

技术报告只给出了高层描述：

  • 联合潜空间扩散：视频和音频分别由各自的自编码器压缩成潜变量——视频是时空潜变量，音频是随时间展开的潜变量。扩散过程同时作用在这两种潜变量上（见扩散：前向加噪与反向去噪），由一个基于Transformer的去噪网络把它们一起从噪声还原。因为画面和声音在同一次去噪中相互“看见”，脚步声能对上落脚的那一帧，台词能对上嘴型。
  • 数据与描述：在大规模图像、视频及标注上训练，用多个Gemini模型给数据写不同详细程度的文本描述（与DALL·E 3与重写描述、Sora用模型重写描述的做法类似，报告未引用它们），并过滤不安全的描述和个人信息、做跨来源的语义去重。
  • 安全措施：输出带SynthID水印，并经过生产环境过滤。

模型规模、训练算力和分辨率等细节均未公开。

结果

2025年5月20日在Google I/O上发布，当天面向美国的Gemini Ultra订阅用户在Gemini应用和新的AI电影工具Flow中开放，企业用户可通过Vertex AI使用。官方称它在画质上超过Veo 2，并且（相对Veo 2）第一次能生成带音频的视频（城市街景的交通噪声、公园里的鸟鸣、角色之间的对白），在文本和图像提示、真实物理和口型同步上表现突出。技术报告没有给出公开基准上的定量结果。

后来的发展

发布约六周后，Ars Technica等媒体报道TikTok上出现大量疑似用Veo 3制作的种族歧视短视频，AI生成视频被滥用的问题受到更多关注。研究者发现它不经专门训练就能完成多种视觉感知、编辑和推理任务，提出“视频模型是零样本学习者”的观点（视频模型零样本推理）。2025年10月15日谷歌推出Veo 3.1，官方称带来更丰富的音频和更多叙事控制，并把音频加入“Ingredients to Video”“Extend”等功能。之后其他视频模型也加入了原生音频：Sora 2（2025年9月）、可灵Kling 3.0、Seedance 2.0；开源的LTX-2开源音视频（2026年1月）用双流Transformer实现了音视频联合生成，并公开权重和代码。

容易误解的地方

  • 技术报告只有几页高层描述，所谓“联合去噪”的具体结构（音视频token如何交互、是否分阶段）并未公开。
  • 官方关于“真实物理”的说法没有定量评测支持。

读懂它需要的概念

扩散：前向加噪与反向去噪 潜空间 波形、频谱与梅尔谱 声码器与音频编解码 Transformer层的结构

本篇术语

  • 原生音频　声音由视频模型本身在同一次生成中产生，而不是事后由另一个模型配上。
  • SynthID　谷歌的隐形水印技术，嵌入在生成内容中，可由专门工具检测出是AI生成的。

怎么学

先读Sora了解视频潜空间扩散，补波形、频谱与梅尔谱和声码器与音频编解码了解音频如何被压缩成潜变量。阅读Veo 3技术报告（篇幅很短），再对照开源的LTX-2开源音视频看音视频联合生成的具体结构。动手：用同一提示词分别要求“无声”和“带对白”，观察口型与声音的同步。
