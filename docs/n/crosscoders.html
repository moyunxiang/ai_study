交叉编码器与模型对比

Sparse Crosscoders for Cross-Layer Features and Model Diffing
2024.10论文延伸Jack Lindsey, Adly Templeton, Jonathan Marcus, Thomas Conerly, Joshua Batson, Christopher Olah · Anthropic待核对
Transformer Circuits ↗在交互版中打开（演化树、学习进度）

问题

稀疏自编码器（稀疏自编码器与单义特征）一次只拆一层，同一特征常分散在多层（跨层叠加）；想比较两个模型（如微调前后）学到的特征有何不同，也缺少办法。

方法

让一个稀疏字典同时读写多层甚至多个模型的激活，得到跨层、跨模型共享的特征，并能分出某个模型独有的特征。

影响

把“模型对比（model diffing）”变成可操作的方法，后来被用来找微调中新出现的特征，例如OpenAI对涌现失准的分析。

方法

普通稀疏自编码器在一层上编码再重建该层；Transcoders用一层预测下一层；交叉编码器（crosscoder）则把多层激活一起编码成一组稀疏特征 f(x)=ReLU(Σ_l W_enc^l a^l(x)+b)，再用各层自己的解码器分别重建每一层。损失是各层重建误差之和，加上按各层解码器范数之和加权的稀疏惩罚 Σ_i f_i(x)·Σ_l‖W_dec,i^l‖，这样它的损失能和逐层SAE之和直接比较。

把“多层”换成“两个模型”，就是模型对比：作者在Claude 3 Sonnet中间层和它的基座模型上训练了100万特征的交叉编码器，发现特征按两个模型解码器范数的相对大小清楚地分成三群：基座独有、微调后独有、共享。共享特征在两个模型里的方向几乎都高度一致；微调独有的特征里有一些与扮演助手、人机对话相关，但大多数还不能直接解释。这是一份初步研究报告。
