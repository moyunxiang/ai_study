DistMult双线性嵌入

Embedding Entities and Relations for Learning and Inference in Knowledge Bases
2014.12论文延伸ICLR 2015Bishan Yang, Wen-tau Yih, Xiaodong He, Jianfeng Gao, Li Deng · 康奈尔大学、微软研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

TransE、NTN等知识库嵌入模型各说各的，没有统一框架可比；而且实体和关系的向量学出来以后，除了补全三元组还能做什么并不清楚。

方法

把实体看成向量、关系看成线性或双线性映射，统一了此前的模型；发现最简单的「对角双线性」打分 f(h,r,t)=Σ h_i·r_i·t_i 效果最好，并用学到的关系矩阵相乘来挖掘逻辑规则。

影响

DistMult参数少、训练快，成了知识图谱补全里几乎每篇论文都要比的基线；它对称打分的缺陷直接催生了ComplEx。

背景

知识库（如Freebase）由（头实体，关系，尾实体）三元组组成，但缺失大量事实。TransE知识图谱嵌入把关系当成向量空间里的平移 h + r ≈ t，NTN（神经张量网络）给每种关系配一个张量，表达力强但参数多。不同论文用不同数据、不同训练细节，很难判断到底是哪一部分起作用。

方法

作者把各种模型写成同一个两层结构：实体先映射成低维向量 h、t，关系再用一个打分函数把它们连起来。线性形式如TransE的 −‖h + r − t‖，双线性形式是 hᵀ M_r t（每个关系一个矩阵 M_r）。

关键发现是：把 M_r 限制成对角矩阵（只保留对角线上的向量 r）几乎不损失效果，打分退化为三个向量逐元素相乘再求和：

f(h, r, t) = Σ_i h_i · r_i · t_i

训练时对每个正确三元组随机替换头或尾实体造负例，用间隔排序损失让正例得分高于负例。由于对角矩阵相乘仍是对角矩阵，两条关系的组合（「出生城市」接「所在国家」）可以用 M_r1 · M_r2 近似，作者据此从嵌入中抽取 Horn 规则（如出生城市∧城市所属国家⇒国籍）。

这个打分对头尾是对称的：f(h,r,t)=f(t,r,h)，所以它无法区分「A是B的父亲」和「B是A的父亲」。

结果

摘要报告：在Freebase上，简单的双线性打分取得top-10准确率73.2%，TransE为54.7%；基于嵌入的规则挖掘在需要组合推理的Horn规则上优于基于置信度的规则挖掘方法。

后来的发展

DistMult成了知识图谱嵌入的标准基线。ComplEx复数嵌入把它推广到复数向量以处理非对称关系，ConvE卷积知识图谱嵌入则用卷积换掉逐元素乘法；后来的研究还发现，只要训练技巧（损失、负采样、正则）到位，DistMult在不少数据上依然很有竞争力。

局限与后续

  • 打分函数对头尾实体对称，无法建模「父亲」「包含」这类反对称关系。
    后来针对它的工作　ComplEx复数嵌入 RotatE旋转嵌入
  • 每个三元组单独打分，只用到实体自己的向量，无法利用多跳路径和文本描述等额外信息。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    word2vec2013.01 · NLP
    沿用把离散符号映射为低维向量、用乘积度量相容性的嵌入思路，从词扩展到实体和关系。
  • 竞争
    最大熵模型1996 · NLP
    以前的关系推断多靠人工特征的对数线性模型，嵌入方法改为自动学习实体与关系表示。
  • 使用
    Freebase2007.03 · NLP
    在Freebase子集上评测链接预测和规则挖掘。
  • 竞争
    TransE知识图谱嵌入2013.12 · NLP
    TransE用平移距离打分，DistMult用对角双线性打分；论文在统一框架下比较，后者在Freebase上更好。

后来的相关工作

  • 改进
    ComplEx复数嵌入2016.06 · NLP
    DistMult打分对头尾对称、无法表达反对称关系；ComplEx改用复数向量和共轭乘积解决了这一点，参数量不变。
  • 延续
    ConvE卷积知识图谱嵌入2017.07 · NLP
    DistMult只做逐元素乘法，ConvE用卷积和全连接层学习更丰富的头实体-关系交互，参数却更少。
  • 改进
    RotatE旋转嵌入2019.02 · NLP
    DistMult只能表示对称关系，RotatE的旋转可以同时覆盖对称和反对称关系。

读懂它需要的概念

嵌入向量 内积与余弦相似度 矩阵乘法与线性变换 损失函数 图、树与搜索

本篇术语

  • 知识图谱补全（链接预测）　给定知识图谱里已知的三元组，预测缺失的（头，关系，?）或（?，关系，尾），按得分给候选实体排序，常用MRR和Hits@10评测。
  • Horn规则　形如「A(x,y)∧B(y,z)⇒C(x,z)」的逻辑规则，前提成立时推出结论。

怎么学

先读TransE知识图谱嵌入了解平移思路 → 读原文第3节统一框架和第4节对角双线性 → 动手：用PyKEEN在FB15k-237上训练TransE和DistMult，比较对称关系和非对称关系上的Hits@10。
