DeepMimic

DeepMimic: Example-Guided Deep Reinforcement Learning of Physics-Based Character Skills
2018.04论文重要SIGGRAPH 2018（ACM Transactions on Graphics 37(4)）Xue Bin Peng, Pieter Abbeel, Sergey Levine, Michiel van de Panne · UC Berkeley / UBC待核对
arXiv ↗DOI ↗在交互版中打开（演化树、学习进度）

问题

深度强化学习训练出的仿真人形角色能走能跑，但动作怪异：手臂乱甩、步态别扭；而传统动画用动作捕捉回放虽然好看，却不受物理约束，被推一下也不会摔倒或恢复。

方法

给强化学习一个“模仿参考动作”的奖励：每一步比较仿真角色与动作捕捉片段在关节角、速度、手脚位置和重心上的差异；再配合从参考动作中随机选起始状态、角色摔倒就提前结束回合两个技巧。

影响

第一次让物理仿真角色学会后空翻、侧手翻、回旋踢等高难度动作，且外观接近动作捕捉；“动作跟踪奖励 + PPO”成为此后人形机器人全身控制（从仿真到真机）的基础配方。

背景

物理仿真角色的动作由关节力矩驱动，必须遵守重力和接触力，所以被撞到时能做出真实的反应。但如何让它做出自然的动作一直很难。手工设计控制器只适用于特定动作；直接用PPO等深度强化学习优化“往前走”这类简单目标，学到的往往是取巧的怪异动作。

另一方面，机器人示教学习的思路是用人的示范来定义“好的动作”。GAIL（2016）用判别器让策略的行为分布接近动作捕捉示范，论文指出这类方法虽提升了动作质量，效果仍比不上计算机动画的标准方法。这篇选择更直接的方式：显式地奖励每一帧都跟上参考动作。

方法

奖励。每一步的总奖励是模仿项与任务项的加权和r = ω_I r^I + ω_G r^G。模仿项由四部分组成：r^I = 0.65 r^p + 0.1 r^v + 0.15 r^e + 0.1 r^c，分别对应关节朝向、关节角速度、手脚末端位置和重心位置与参考动作的接近程度。每一项都是误差的指数形式，例如姿态项r^p = exp(−2 Σ_j ‖q̂_j ⊖ q_j‖²)，其中q_j是第j个关节的朝向（四元数），⊖表示两个朝向之差。任务项可以是“朝某方向走”“把球扔向目标”等。

策略。输入角色状态、相位变量（当前处于参考片段的哪个时刻）和任务目标，输出每个关节PD控制器的目标角度，以30Hz运行；物理仿真用Bullet引擎，以1.2kHz步进。用PPO训练。

两个关键技巧。

  • 参考状态初始化（RSI）：每个回合从参考动作中随机抽一个时刻作为起点。以后空翻为例，如果总是从站立开始，角色必须先学会跳起，才有机会体验翻转的高回报，而在学会落地之前，跳起反而会降低回报。从片段中任意时刻开始，角色能直接练习翻转和落地。
  • 提前终止（ET）：躯干或头部触地就结束回合，避免大量数据浪费在“躺在地上比划动作”上。

结果

人形角色（34个自由度）学会了走、跑、侧手翻、后空翻、前空翻、回旋踢、舞蹈等大量技能，方法也适用于Atlas机器人模型、霸王龙和龙形角色。消融实验显示，不用RSI时后空翻策略回报看似相近，实际只学会原地往后小跳，从未完成空翻。训练单个人形技能通常需要约6000万个样本，在8核CPU上约2天。

后来的发展

后续工作沿两个方向推进。一是去掉手工设计的跟踪奖励和相位变量：对抗运动先验AMP用对抗判别器从无结构的动作数据中学习风格，ASE技能嵌入学习可复用的技能嵌入。二是从仿真角色走向真实人形机器人：ExBody全身表现控制、OmniH2O人到人形遥操作、ASAP仿真-现实对齐、GMT通用动作跟踪、BeyondMimic和SONIC大规模动作跟踪都以“跟踪人类动作捕捉数据的强化学习策略”为核心，配合域随机化迁移到真机，这让今天的人形机器人能跳舞、做侧手翻。

局限与后续

  • 每个技能单独训练一个策略，奖励依赖相位变量和逐帧对齐的单一参考片段，难以从大量无标注动作中自动组合技能。

读懂它需要的概念

奖励设计与奖励投机 策略梯度 模仿学习与行为克隆 自由度、运动学与本体感知 仿真到现实的差距

本篇术语

  • 动作捕捉　在演员身上贴标记点，用多台相机记录其三维运动，得到每一帧所有关节角度的数据。
  • PD控制器　比例—微分控制：根据目标角度与当前角度之差（比例项）和角速度（微分项）计算关节力矩。策略只需给出目标角度，具体力矩由PD控制器算。
  • 相位变量　表示当前处于参考动作片段的进度（0到1），让策略知道此刻应该模仿片段中的哪一帧。

怎么学

先补奖励设计与奖励投机和策略梯度，了解PPO。读论文第4节（奖励设计）和第5节（RSI与ET），然后看补充视频。动手：用作者开源的DeepMimic代码或Isaac Gym中的同类示例，让人形角色跟踪一段走路动作，再关掉RSI或ET，观察训练曲线和动作的差别。
