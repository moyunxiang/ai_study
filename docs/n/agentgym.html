AgentGym智能体进化平台

AgentGym: Evolving Large Language Model-based Agents across Diverse Environments
2024.06论文延伸ACL 2025Zhiheng Xi, Yiwen Ding, Wenxiang Chen, Boyang Hong, Honglin Guo, Junzhe Wang, Dingwen Yang, Chenyang Liao et al. · 复旦大学待核对
arXiv ↗AgentGym-RL ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

训练通用智能体要么逐步模仿专家轨迹（依赖人工、难扩展），要么在单个环境里探索（练出来的是专才）；缺少一个把多种环境统一起来、能让智能体自己进化的平台。

方法

把网页、购物、家务、游戏、编程等十几个环境封装成统一接口的平台，配上轨迹数据和评测集，再提出AgentEvol：让模型在多环境中探索、用成功轨迹不断自我改进。

影响

成为开源智能体训练常用的多环境平台之一；2025年的AgentGym-RL在此基础上做成从零开始的多轮强化学习框架，被智能体RL工作广泛对比。

方法

AgentGym有三件东西：

  • 统一的环境平台：把WebShop、ALFWorld文字家务环境、网页导航、科学实验、文字游戏、工具调用等多类环境包装成同一种HTTP接口，支持实时、并发的交互；
  • 数据：扩充过的任务指令、一套基准（AgentEval），以及跨环境的高质量轨迹（AgentTraj），先用来把模型训到“会基本操作”；
  • AgentEvol自进化方法：在行为克隆打底之后，让智能体在各环境中探索，把拿到奖励的轨迹加入训练集再微调，循环多轮，思路接近ReST-EM自训练这类筛选式自训练。

摘要称进化后的智能体能达到与当时最好模型相当的水平。

2025-09的AgentGym-RL换成在线多轮强化学习：模块化地支持主流RL算法，不需要先做监督微调；并提出ScalingInter-RL——训练初期限制交互轮数、偏重利用，之后逐步放宽轮数鼓励探索，以减轻长程任务中的训练崩溃。官方称其智能体在27个任务上达到或超过商用模型。

局限与后续

  • AgentEvol本质上只从成功轨迹中学，失败轨迹的信息没有利用，长程任务中的信用分配仍很粗糙。
    后来针对它的工作　GiGPO组中组优化
  • 环境大多是文本模拟环境，和真实网页、真实操作系统的复杂度与噪声差距较大。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    ALFWorld文字家务环境2020.10 · 数据·评测
    文字家务环境ALFWorld被收入平台，用于多步决策训练与评测。
  • 使用
    WebShop2022.07 · 数据·评测
    网购环境是平台里的标准环境之一。
  • 延续
    AgentBench2023.08 · 数据·评测
    AgentBench只做多环境评测，AgentGym把多环境做成可训练、可交互的平台。
  • 改进
    AgentTuning/AgentLM2023.10 · 推理·智能体
    轨迹都来自GPT-4的成功示范，属于模仿学习；没有利用失败轨迹，也无法超越教师的策略。
  • 改进
    FireAct智能体微调2023.10 · 推理·智能体
    训练轨迹来自GPT-4的模仿学习，学生模型的上限受教师约束，也学不到教师没走过的成功路径。
  • 延续
    ReST-EM自训练2023.12 · 推理·智能体
    AgentEvol用“探索—保留成功轨迹—微调”的循环，把筛选式自训练搬到多环境智能体上。
  • 改进
    Agent-FLAN智能体微调数据2024.03 · 推理·智能体
    仍是基于示范数据的监督微调，没有从环境交互的成败中学习。

读懂它需要的概念

智能体循环 模仿学习与行为克隆 奖励、回报与折扣 策略梯度

怎么学

先读AgentBench和ReST-EM自训练 → 读原文第3节平台设计和AgentEvol算法 → 动手：装好AgentGym里的一个文字环境，用一个小模型跑十条轨迹，统计成功率并把成功轨迹存下来。
