随机森林

Random Forests
2001论文重要Machine Learning 45(1), 2001Leo Breiman · UC Berkeley待核对
Springer ↗作者PDF ↗在交互版中打开（演化树、学习进度）

问题

单棵决策树方差大、容易过拟合；Bagging把多棵树平均后有所改善，但各棵树长得太像，平均的效果有限；AdaBoost更准，却对标签噪声敏感。

方法

每棵树用自助采样的数据训练，并且每个结点只在随机抽出的少数几个特征里挑最佳切分，故意让树彼此不同，再投票或取平均。

影响

几乎不用调参、不怕加树过拟合、自带误差估计和特征重要性，成为表格数据上最常用的基线之一，至今仍是sklearn里的默认选择之一。

背景

决策树CART决策树容易读懂，但很不稳定：训练数据稍有变化，树的结构就可能大变，属于低偏差、高方差的模型（见偏差-方差权衡）。Bagging的办法是从训练集有放回地抽很多份自助样本，各训一棵树，再投票，用平均压低方差。

问题在于，如果数据里有一两个特别强的特征，几乎每棵树的顶层都会用它们切分，各棵树高度相关。n个完全相关的模型平均起来等于一个模型，所以Bagging的收益很快到顶。另一边，AdaBoost与集成学习通过反复加权难样本，准确率更高，但遇到标错的样本会不断加大它们的权重，对噪声很敏感。

方法

随机森林在Bagging之上再加一层随机性。对每棵树：

  • 从训练集有放回地抽一份同样大小的自助样本；
  • 生长CART树时，每个结点只从随机抽出的F个特征里找最佳切分（论文试了F=1和F取不超过log₂M+1的整数，M是特征总数）；
  • 树长到最大，不剪枝。

预测时分类取多数票，回归取平均。

论文给出两条理论结果。第一，由大数定律，树越多，泛化误差几乎必然收敛到一个极限，所以加树不会过拟合。第二，泛化误差有上界PE* ≤ ρ̄(1 − s²)/s²，其中s是单棵树的“强度”（平均间隔），ρ̄是树之间的平均相关。随机选特征就是在牺牲一点强度的同时大幅压低相关。

袋外估计：每份自助样本大约漏掉三分之一的原始样本。对每个样本，只用没见过它的那些树投票，得到的错误率就是泛化误差的估计，不必另留验证集。把某个特征在袋外数据里随机打乱、看误差上升多少，就得到这个特征的重要性。

结果

在13个UCI小数据集、3个较大数据集和4个合成数据集上，错误率与AdaBoost相当或更好；在人为加入标签噪声时，随机森林的退化明显小于AdaBoost（摘要原话为“对噪声更稳健”）。

后来的发展

随机森林与梯度提升机GBM成为此后十多年表格数据的两大主力，后者经XGBoost工程化后在竞赛中更常拿第一，但随机森林因几乎不用调参仍是首选基线。论文中的置换特征重要性启发了后来的模型解释方法。同年Breiman发表Breiman：两种文化，用随机森林为例主张“算法建模”文化。在图像、语音、文本这类原始高维信号上，它很快被深度网络取代。

局限与后续

  • 每棵树独立地拟合原始标签，无法像提升法那样逐轮纠正前面的错误，在多数表格基准上精度略低于精心调参的梯度提升。
    后来针对它的工作　XGBoost
  • 只能在给定的特征上切分，不会从像素、波形、文字这类原始输入中学出特征，在感知任务上远不如深度网络。
    后来针对它的工作　AlexNet
  • 几百棵深树的整体难以解释，置换重要性在特征相关时会产生偏差。
    后来针对它的工作　SHAP

它建立在什么之上

  • 改进
    专家系统的商业化1980 · 事件
    知识获取瓶颈：每条规则都要从专家那里手工提炼，规模越大、维护越难，XCON每年约一半规则需要修改。
  • 使用
    决策树CART1984 · 基础
    每棵树按CART的方式生长，只是切分时的候选特征被随机限制，并且不剪枝。
  • 竞争
    支持向量机1995 · 基础
    同一时期表格与中等维度分类的另一条主流路线；随机森林不需要选核、对特征尺度不敏感。
  • 改进
    Bagging1996 · 基础
    保留自助采样加投票，再在每个结点随机抽特征，进一步降低树之间的相关性。
  • 竞争
    AdaBoost与集成学习1997 · 基础
    同为树的集成：AdaBoost顺序加权纠错，随机森林并行随机化；论文显示精度相当而随机森林对标签噪声更稳健。

后来的相关工作

  • 改进
    AlexNet2012.09 · 视觉
    只能在给定的特征上切分，不会从像素、波形、文字这类原始输入中学出特征，在感知任务上远不如深度网络。
  • 竞争
    梯度提升机GBM2001 · 基础
    同年的另一种树集成：随机森林并行随机化以降方差，梯度提升顺序纠错以降偏差；精度上后者经XGBoost调优后通常更高。
  • 使用
    scikit-learn2010.02 · 系统·效率
    提供随机森林等集成方法的高效实现，成为表格数据上的常用基线。
  • 使用
    LIME2016.02 · 安全·可解释
    主要解释对象之一，论文用它展示对上千棵树的模型也能几秒内给出解释。
  • 使用
    XGBoost2016.03 · 基础
    借用随机森林的列（特征）采样来防过拟合并加速训练。
  • 改进
    SHAP2017.05 · 安全·可解释
    几百棵深树的整体难以解释，置换重要性在特征相关时会产生偏差。

读懂它需要的概念

决策树 集成学习 偏差-方差权衡 泛化与过拟合 训练集、验证集与测试集

本篇术语

  • 自助采样（bootstrap）　从n个样本里有放回地抽n次，得到一份同样大小、但有重复也有遗漏的新数据集。
  • 袋外估计（out-of-bag）　用没见过某个样本的那些树来预测它，得到的错误率可以当作验证误差用。

怎么学

先读决策树和集成学习，弄懂Bagging为什么能降方差。然后读原文第1–4节和第10节（特征重要性）。动手：用scikit-learn的RandomForestClassifier在一个表格数据集上画出袋外误差随树的数量变化的曲线，并比较max_features取1、√M和M时的差别。
