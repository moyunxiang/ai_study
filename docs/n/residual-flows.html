残差流Residual Flows

Residual Flows for Invertible Generative Modeling
2019.06论文延伸NeurIPS 2019Ricky T. Q. Chen, Jens Behrmann, David Duvenaud, Jörn-Henrik Jacobsen · 多伦多大学 / Vector研究所 / 不来梅大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

耦合层式的流（标准化流RealNVP、Glow）为了可逆要把网络结构切成两半，限制了表达力；可逆残差网络只需约束Lipschitz常数即可逆，但此前用它估计对数密度时有偏，网络越强偏差越大。

方法

用“俄罗斯轮盘”随机截断给出对数行列式级数的无偏估计，再用另一条无穷级数算梯度以节省显存，并换用不饱和的激活函数和更一般的Lipschitz约束。

影响

让普通残差网络形态的可逆模型可以被无偏地按最大似然训练，在流模型中取得当时最好的密度估计，并展示了同一网络兼做生成和分类的能力。

方法

残差块y = x + g(x)在g的Lipschitz常数小于1时一定可逆（逆变换可以用不动点迭代x ← y − g(x)求出），所以只要对每层做谱归一化式的约束，就能把常见的ResNet变成标准化流，而不必像耦合层那样只变换一半维度。

难点在似然：变量替换公式要算log|det(I + J_g)|，它可以展开成迹的幂级数Σ_k (−1)^{k+1} tr(J_g^k)/k。此前的可逆残差网络把级数截断到固定项数，估计有偏。Residual Flows用俄罗斯轮盘估计：随机决定算到第几项，并按“算到这一项的概率”给每项加权，期望恰好等于无穷级数，于是得到无偏估计；迹本身用Hutchinson随机向量估计。为了不把每一项的计算图都存下来，梯度改用另一条可逐项求、无需保存中间结果的级数。

此外，常用的ELU等激活函数导数会饱和，作者提出LipSwish激活，并把Lipschitz约束推广到混合范数。论文报告在流模型中取得当时最好的密度估计，并在同时做生成和分类的设置下优于基于耦合层的网络。

局限与后续

  • 采样要对每一层做不动点迭代，训练时还要随机展开多项级数，速度和显存开销都明显高于耦合层流。

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    可逆性来自对残差分支加Lipschitz约束，网络形态就是普通残差网络。
  • 使用
    谱归一化2018.02 · 生成
    用谱归一化类方法把每层的Lipschitz常数压到1以下以保证可逆。
  • 竞争
    Glow2018.07 · 生成
    不用耦合层切分维度，用无约束结构的残差块做可逆变换，在密度估计上超过耦合层流。
  • 竞争
    FFJORD连续标准化流2018.10 · 生成
    同样用随机迹估计处理雅可比，但FFJORD走连续时间ODE，残差流是离散层的级数展开。
  • 改进
    可逆残差网络i-ResNet2018.11 · 生成
    截断幂级数使对数似然估计有偏，训练目标不精确，截断项数需要权衡。

读懂它需要的概念

可逆流与流匹配 雅可比矩阵与海森矩阵 残差连接 蒙特卡洛采样 最大似然估计

本篇术语

  • 俄罗斯轮盘估计　对无穷级数随机决定在第几项停下，并把每项除以“走到这一项”的概率，使估计值的期望正好等于整个级数，从而无偏。
  • Lipschitz常数　函数输出变化与输入变化之比的上界；小于1意味着这个映射是压缩的，残差块因此可逆。

怎么学

先复习变量替换公式和对数行列式 → 读本文第3节无偏估计和梯度级数 → 对比FFJORD的Hutchinson迹估计。
