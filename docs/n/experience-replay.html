经验回放

Self-Improving Reactive Agents Based on Reinforcement Learning, Planning and Teaching
1992论文重要Machine Learning 8, 1992Long-Ji Lin · 卡内基梅隆大学待核对
Springer ↗论文PDF ↗在交互版中打开（演化树、学习进度）

问题

TD学习和Q学习每条经验只用一次就扔掉，用神经网络学一个稍复杂的任务要试错很久，而有些经验（比如被敌人抓住）既稀少又代价高昂。

方法

把过去的经验（状态、动作、下一状态、奖励）存起来，反复拿出来当作新经验重新训练；同时与Dyna式的“学模型再规划”和“人类示范”做了系统对比。

影响

经验回放成为深度值函数方法的标配：二十年后DQN靠它和目标网络把Q学习与卷积网络稳定地结合起来，后续的优先回放、分布式回放都从这里出发。

背景

到1990年，时序差分学习、Watkins博士论文的Q学习和Actor-Critic（ASE/ACE）式的AHC方法已经有了，但实验多是倒立摆、小迷宫这类简单任务，而且收敛很慢：奖惩要沿着长长的动作序列一步步往回传。

Dyna：学习与规划合一给出一种加速办法：学一个环境模型，用它生成假想经验。可在随机、动态的环境里，学一个足够准的模型本身就很难。Lin的问题是：能不能不学模型，直接重用真实发生过的经验？

方法

Lin把一条经验定义为四元组(x, a, y, r)，从开始到结束的一串经验叫一个lesson。经验回放就是把最近的lesson存在内存里，反复喂给学习算法，“就像智能体一次又一次重新经历了它们”。几个关键细节：

  • 倒序回放：按时间从后往前回放一个lesson，终点的奖惩一次就能沿序列传回起点；
  • 只回放符合当前策略的动作：旧策略下的“坏动作”反复训练会让共享隐层的网络低估状态价值，所以被当前策略选中概率低于阈值的经验跳过；
  • 只存最近100个lesson，越新的越可能被选中；回放太多次会过拟合个别经验。

论文用反向传播训练的三层网络（145个输入单元）实现AHC和Q学习，各配三种加速：经验回放（-R）、学动作模型做规划（-M）、人类示范+回放（-T），共8种框架。测试环境是25×25格子世界：智能体要吃15块食物维持能量，同时躲开4个随机移动的敌人，只能看到附近的粗编码传感器。

结果

每次实验用300个训练环境、50个测试环境。加了经验回放后，AHC和Q学习的学习速度都显著提高，最终水平差别不显著；需要自己学模型时，回放稳定地优于用模型规划，因为模型在学好之前反而会误导。最好的QCON-T在8000个随机环境中平均吃到12.1块食物，39.9%的局吃光全部食物。

后来的发展

神经拟合Q迭代NFQ把全部历史转移存下来做批量训练，是同一思路的延续；真正让它成为标配的是DQN：把它与卷积网络、目标网络组合，在Atari上稳定训练出深度Q网络；不同的是DQN从一个大缓冲区里均匀随机抽单条转移，用于打破样本间的相关性。之后优先经验回放按TD误差大小优先抽样，Ape-X让数百个actor往一个共享缓冲区写经验。离线强化学习（BCQ批量约束Q学习、离线强化学习CQL）可以看成只用一个固定回放缓冲区、不再与环境交互的极端情形。

容易误解的地方

  • Lin的回放是按整条lesson倒序回放、并且只回放符合当前策略的动作，与DQN的“随机均匀抽单条转移”不是一回事。
  • 论文里的“-T”示范只是把人类演示的lesson放进回放内存，与后来的行为克隆不同。

局限与后续

  • 只敢回放与当前策略一致的动作，大量旧经验被丢弃；用神经网络时回放离策略数据容易带偏价值估计。
    后来针对它的工作　DQN（Nature版） Retrace离策略修正
  • 回放哪些经验只按新近程度挑，没有考虑哪条经验还能学到更多。
    后来针对它的工作　优先经验回放
  • 神经网络Q学习本身仍不稳定，回放只是加速，没有解决目标值随网络一起漂移的问题。
    后来针对它的工作　DQN（Nature版）

它建立在什么之上

  • 使用
    Actor-Critic（ASE/ACE）1983 · RL
    AHCON系列就是Barto–Sutton–Anderson的评论家-行动者结构的神经网络实现。
  • 使用
    反向传播1986 · 基础
    价值、策略和效用网络都是用反向传播训练的三层前馈网络。
  • 改进
    时序差分学习1988 · RL
    TD误差每次只往回传一步，长序列上信用分配很慢；倒序回放让一次奖惩迅速传遍整条序列。
  • 竞争
    Dyna：学习与规划合一1990 · RL
    Dyna用学到的模型生成假想经验；回放直接重用真实经验。Lin的实验显示需要自己学模型时回放更快，深度RL时代回放成为主流。
  • 改进
    灾难性遗忘1989 · 基础
    没有给出解决办法，只是说明问题存在；用顺序数据连续训练一直是未解决的难题。
  • 使用
    Watkins博士论文1989 · RL
    QCON系列直接用Watkins的Q学习作为学习规则，并指出它比AHC对回放离策略动作更不敏感。

后来的相关工作

  • 使用
    DQN2013.12 · RL 已核对
    直接采用Lin 1992年的经验回放，用随机抽样打破相邻帧的相关性并重复利用数据。
  • 使用
    DQN（Nature版）2015.02 · RL
    继续使用经验回放，并用消融实验证明它对稳定性不可或缺。
  • 改进
    优先经验回放2015.11 · RL
    把均匀抽样的回放池改为按TD误差的优先级抽样。
  • 使用
    MADDPG2017.06 · RL
    沿用DDPG的离策略回放；由于critic看到了所有人的动作，旧经验不再因他人策略变化而失效。
  • 延续
    后见经验回放HER2017.07 · RL
    在经验回放时额外存入换了目标、重算了奖励的副本，把失败经验变成成功样本。
  • 使用
    LIBERO2023.06 · 具身·世界模型
    ER（存一部分旧任务数据与新数据混合训练）是回放类方法的代表，在长任务组上表现最好。
  • 使用
    Gorila分布式DQN2015.07 · RL
    分布式的回放库保存所有actor产生的经验，learner从中采样。
  • 改进
    Retrace离策略修正2016.06 · RL
    只敢回放与当前策略一致的动作，大量旧经验被丢弃；用神经网络时回放离策略数据容易带偏价值估计。

读懂它需要的概念

时序差分与自举 on-policy与off-policy 策略与价值函数 多层感知机 反向传播 信用分配

本篇术语

  • 经验回放缓冲区　存放过去转移样本的内存。训练时从中抽样，而不是只用刚刚发生的那一条。
  • lesson　Lin的术语，指从初始状态到结束的一整串经验，相当于后来说的一个episode。

怎么学

先懂Q学习和on-policy与off-policy。读原文第2.3节（经验回放）和第6.2、6.5节（实验结论）。动手：在CartPole上写一个神经网络Q学习，比较“每条经验只用一次”和“存入缓冲区反复抽样”两种设置，再读DQN看它为什么还需要目标网络。
