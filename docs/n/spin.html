SPIN自我对弈微调

Self-Play Fine-Tuning Converts Weak Language Models to Strong Language Models
2024.01论文延伸ICML 2024Zixiang Chen, Yihe Deng, Huizhuo Yuan, Kaixuan Ji, Quanquan Gu · 加州大学洛杉矶分校待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

SFT之后想继续提升模型，通常要收集新的人类偏好数据或用GPT-4等更强模型打分；能不能只靠原有的SFT数据，把弱模型继续变强？

方法

让模型和上一轮的自己对弈：把SFT数据里的人类回答当作“好”，把上一轮模型自己生成的回答当作“差”，训练新模型区分并偏向人类回答；重复多轮，直到模型分布与人类数据一致。

影响

展示了不增加任何新标注、只用SFT数据也能做类似偏好优化的迭代提升，是2024年“自我对弈/自我改进”对齐路线的代表工作之一。

方法

背景：SFT只是在人类示范数据上做最大似然，训练到一定程度后再多训几轮收益很小；DPO直接偏好优化能继续提升，但需要成对的偏好数据，Zephyr蒸馏对齐等工作的偏好数据来自GPT-4打分的UltraFeedback AI反馈数据。

SPIN的设定像一个两人博弈。主玩家是第t+1轮的新模型，任务是分辨一个回答来自人类数据还是来自对手；对手是第t轮的旧模型，它尽量生成像人类一样的回答。每一轮：用旧模型对SFT数据中的每个提示生成一个回答y′，与数据里的人类回答y组成一对，以y为“被选”、y′为“被拒”，用一个形式上与DPO很相近的对数几率损失训练新模型（参考模型就是旧模型）。训练完成后，新模型成为下一轮的对手。作者从理论上证明：这个目标的全局最优只在模型分布等于目标数据分布时达到，此时模型生成的回答与人类回答无法区分，迭代自然停止。

实验从基于Mistral-7B的SFT模型（zephyr-7b-sft-full）出发，只使用其SFT数据的一部分。摘要称在HuggingFace Open LLM Leaderboard、MT-Bench和Big-Bench的数据集上显著提升，甚至超过用额外GPT-4偏好数据做DPO训练的模型。

局限与后续

  • 上限是SFT数据中人类回答的水平：模型分布一旦追上人类数据，训练就停止，无法超越示范数据本身；每一轮都要对全部提示重新生成回答，迭代成本不低。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    生成对抗网络GAN2014.06 · 生成
    区分真实数据与模型生成数据、并让生成分布逼近真实分布的博弈思路与GAN相似，只是判别者和生成者是同一模型的新旧两轮。
  • 延续
    DPO直接偏好优化2023.05 · LLM
    损失形式与DPO相近，但“被拒回答”来自上一轮模型自身，不需要额外的偏好标注。
  • 使用
    Open LLM Leaderboard2023 · 数据·评测
    主要评测之一。
  • 竞争
    Zephyr蒸馏对齐2023.10 · LLM
    从Zephyr的SFT模型出发，与用GPT-4偏好数据做DPO的Zephyr比较，摘要称可以超过。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

指令微调与对话模板 人类反馈强化学习 自我对弈 KL散度 博弈论基础与纳什均衡

本篇术语

  • 自我对弈（self-play）　让模型与自己的旧版本对抗来产生训练信号，不需要外部对手或额外标注。

怎么学

先读DPO直接偏好优化的损失和Zephyr蒸馏对齐的训练流程；读本文第4节的博弈表述和第5节关于全局最优的定理；动手：用一个小SFT模型在几千条指令数据上跑两轮SPIN，比较每轮生成与人类回答的对数概率差。
