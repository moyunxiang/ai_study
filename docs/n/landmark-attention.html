Landmark地标注意力

Landmark Attention: Random-Access Infinite Context Length for Transformers
2023.05论文延伸NeurIPS 2023Amirkeivan Mohtashami, Martin Jaggi · EPFL待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

注意力的显存随上下文长度增长，读不了很长的输入。循环记忆（如Transformer-XL）丢掉了“随时回看任意位置”的能力；外挂检索又要另一套与注意力不兼容的检索机制。

方法

把输入切成固定长度的块，每块末尾加一个“地标”词元，训练注意力先通过地标判断哪一块相关、再看块内的词。推理时只需把与查询最相关的少数几个块取进来，检索本身就由注意力完成，完整上下文可以放在任意层级的存储里。

影响

把“块级检索”嵌进注意力本身，证明可以在保留随机访问的前提下处理任意长的上下文；把LLaMA 7B微调到32K以上上下文，是2023年长上下文扩展的代表工作之一，也是后来块稀疏注意力（MoBA、NSA）一类思路的先驱。

背景

2023年上半年，开源模型的上下文只有2K–4K。Transformer-XL和循环记忆Transformer用循环记忆把过去压成固定状态，只能“隐约记得”，无法精确回看某一段；外接kNN记忆外接kNN记忆按词检索，检索与注意力是两套机制，检索粒度细、开销大。人们希望既能看完整上下文，又不必每一步都对全部词做注意力。

方法

地标词元：把输入每L个词（论文中如50）划为一块，在块末插入一个特殊的地标词元。它的键向量要学会代表整块的内容。

分组softmax：训练时，普通词对其他块的注意力被改写为两级：先用查询与各块地标键的相似度做一次softmax，得到“选中这一块”的权重g_j；再在块内对各词做softmax。块内词i的最终注意力权重近似为 a_i = g_{block(i)} · softmax_{块内}(q·k_i) 当前块内的词照常直接注意。这样梯度会推动地标键去代表“这一块对当前查询有多重要”。训练用的上下文不必很长，只要包含若干块。

推理时检索：把所有过去块的键值缓存起来（可以放在CPU内存甚至更慢的存储里），每一步用查询与地标键比较，只取得分最高的k个块的完整键值参与注意力，其余不读。检索结果由注意力自身决定，与模型完全兼容，且对不同注意力头可以取不同的块。

微调现有模型：同样的方法可以用于已有的LLaMA 7B，短时间微调后即可在远超原长度的上下文上推理。

结果

在语言建模上，性能与Transformer-XL相当，而每一步需要取回的词元数明显减少；用该方法微调LLaMA 7B后，模型的上下文容量扩展到32K以上，达到当时GPT-4的上下文长度，并能在长文本中完成密钥检索类测试。

后来的发展

后来的长上下文研究主要转向位置插值（YaRN）加长文本续训，但“按块选择、只对相关块做注意力”的思想在Infini-attention、MoBA块注意力、原生稀疏注意力NSA等块级稀疏注意力和KV检索方法中被继承。

本篇术语

  • 地标词元　每一块文本末尾插入的特殊词元，它的键向量学会概括整块内容，用来判断这一块与当前查询是否相关。
  • 随机访问　模型在生成时可以精确回看上下文中任意位置的内容，而不是只能依赖压缩后的记忆。

怎么学

先懂KV缓存和Transformer-XL的循环记忆；读本文第3节分组softmax的推导和第4节检索流程；动手：在一个小模型上每50词插入地标，比较全注意力和只取前4块的困惑度。
