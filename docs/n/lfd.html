机器人示教学习

Robot Learning From Demonstration
1997论文延伸ICML 1997Christopher Atkeson, Stefan Schaal · Georgia Tech / ATR待核对
维基：模仿学习 ↗在交互版中打开（演化树、学习进度）

问题

手写机器人控制器费时费力，而强化学习需要大量试错，真机上代价太高。

方法

让人演示一遍任务，机器人从演示中学习：既学出任务的目标，也学出怎样把它做出来。

影响

把“看人做、学着做”确立为机器人学习的一条独立路线，是后来行为克隆、示教数据采集的先声。

方法

本篇的细节没能在本次会话中核对原文，以下只写已确认的背景和定性内容。

示教学习（又称模仿学习）的基本形式，是用监督学习让策略在相同观测下输出与专家一致的动作。维基百科指出，它的典型问题是分布偏移：策略一旦偏离专家走过的轨迹，就进入训练数据没覆盖的状态。这条路线可以追溯到工业机器人的“示教再现”（Unimate工业机器人），以及1988年的ALVINN端到端驾驶。

Atkeson与Schaal的工作的要点，是把演示不仅当作要复制的轨迹，而是同时用来推断任务目标，再结合模型学习让机器人能在偏离演示时仍完成任务（此段为对论文的概括，未核对）。
