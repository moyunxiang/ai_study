好奇心模块ICM

Curiosity-driven Exploration by Self-supervised Prediction
2017.05论文重要ICML 2017Pathak, Agrawal, Efros, Darrell · UC Berkeley待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

奖励极稀疏时，ε-贪心式的随机探索几乎碰不到奖励；用“预测下一帧像素的误差”作为好奇心又会被树叶、噪声这类无法预测却与智能体无关的画面一直吸引。

方法

在一个只保留“与自己动作有关”信息的特征空间里预测下一状态，用预测误差当内在奖励；这个特征空间由“从前后两帧猜出做了什么动作”的逆动力学模型自监督学出。

影响

让好奇心驱动的探索在像素输入的3D游戏里可用：VizDoom中极稀疏奖励的任务从完全失败变为多数成功，马里奥在没有任何奖励时自己走过了第1关30%以上。

背景

强化学习靠奖励信号学习，但很多任务里奖励几乎为零：迷宫里只有找到出口才得1分，Arcade学习环境ALE中的Montezuma's Revenge几乎没有智能体拿到过分。随机探索在这种环境中极低效（见探索与利用）。

一个思路是给智能体加“内在奖励”：Schmidhuber人工好奇心早在1991年就提出，让智能体去它的世界模型预测不准的地方。2016年的伪计数探索用“伪计数”奖励没去过的状态。但在像素输入上，“预测不准”有个致命漏洞：风吹树叶、电视雪花屏这类本质随机的画面永远预测不准，好奇心会被它们永久吸引，而它们与任务毫无关系。

方法

ICM（内在好奇心模块）由三个网络组成。

编码器φ把画面s编码成特征φ(s)。

逆动力学模型：输入前后两帧的特征φ(sₜ)和φ(sₜ₊₁)，预测这一步做了哪个动作aₜ，按分类损失训练。这是自监督的（见自监督学习）——动作是自己做的，标签免费。关键作用在于：为了猜出动作，φ只需要编码那些受动作影响的东西（自己的位置、前方的墙）；树叶怎么动对猜动作毫无帮助，φ就没有动力去编码它。

前向模型：输入φ(sₜ)和aₜ，预测φ(sₜ₊₁)。它的预测误差就是好奇心奖励：

rᵢₜ = (η/2)·‖φ̂(sₜ₊₁) − φ(sₜ₊₁)‖²

智能体最终最大化外部奖励加内在奖励之和，策略用A3C训练。三个网络联合优化：min −λ·E[Σrₜ] + (1−β)·L_逆 + β·L_前向。

直觉：智能体到了新地方，前向模型还预测不准，奖励高，于是它被驱动去那里；去多了模型学会了，奖励自然消失，它就会转向别处。

结果

在VizDoom的3D迷宫导航中，按出生点到目标的距离分为三档。“稀疏”档离目标约270步、“极稀疏”档约350步（最优策略下）。极稀疏时，普通A3C和用像素预测误差做好奇心的对照版都从未成功，ICM在66%的随机运行中拿到满分。把画面的40%换成固定区域的白噪声后，像素好奇心版大幅退化，ICM仍拿到满分。在完全没有外部奖励的情况下，马里奥智能体自己学会了穿过第1关30%以上，学会了躲敌人；把第1关学到的探索策略微调到后续关卡，探索速度比从零开始快。与TRPO-VIME等同期探索方法相比，它在稀疏奖励的VizDoom任务上也更好。

后来的发展

ICM与伪计数探索一起定义了2017年前后的“内在动机”路线。2018年随机网络蒸馏RND用“预测一个固定随机网络的输出”替代前向模型，避开了动力学本身随机带来的问题，并在Montezuma's Revenge上取得突破；Never Give Up和Agent57把类似的新颖性奖励与片段记忆结合，最终在全部57款Atari游戏上超过人类基准。另一条路线Go-Explore则主张先“记住并回到”有希望的状态再探索。

局限与后续

  • 若随机性受智能体动作控制（例如它能按遥控器换台的“噪声电视”），逆动力学特征仍会保留它，好奇心依旧被吸引。
    后来针对它的工作　随机网络蒸馏RND Never Give Up
  • 内在奖励是局部的、会随学习衰减，对需要穿越很长无奖励区间、记住要回到哪里的困难探索（如Montezuma's Revenge）仍然不够。
    后来针对它的工作　随机网络蒸馏RND Go-Explore Agent57
  • 只保留“受动作影响”的特征，会忽略那些与任务相关但智能体暂时无法控制的物体（如远处移动的敌人）。

它建立在什么之上

  • 改进
    基于势函数的奖励塑形1999 · RL
    没有给出自动构造好势函数的方法；好的Φ接近最优价值函数，往往需要专家知识。
  • 延续
    Arcade学习环境ALE2012.07 · RL
    ALE论文点名的稀疏奖励探索难题，是ICM这类内在动机方法要攻克的典型场景。
  • 延续
    Schmidhuber人工好奇心1991 · RL
    沿用“以世界模型的预测误差作为好奇心奖励”，但把预测放进自监督学到的特征空间，避开像素里的无关随机性。
  • 使用
    A3C2016.02 · RL
    策略学习用A3C，ICM只负责额外提供内在奖励，可以接在任何RL算法上。
  • 竞争
    伪计数探索2016.06 · RL
    同为解决稀疏奖励的内在动机：伪计数奖励“没去过的状态”，ICM奖励“预测不准的转移”，后者对高维像素更自然。

后来的相关工作

  • 改进
    随机网络蒸馏RND2018.10 · RL
    ICM用前向模型预测误差做好奇心，会被随机噪声吸引；RND改为预测一个确定的随机网络，避开了噪声电视问题，也不需动力学模型。

读懂它需要的概念

探索与利用 自监督学习 奖励、回报与折扣 Actor-Critic与优势函数 世界模型 卷积层、池化与感受野

本篇术语

  • 内在奖励　不来自环境、由智能体自己计算的奖励，例如“这件事我预测错了多少”。与环境给的外部奖励相加后用于训练。
  • 逆动力学模型　已知前后两个状态，反推中间做了什么动作。在ICM中它的作用是逼编码器只保留与动作相关的信息。
  • 噪声电视问题　画面中有本质随机、永远预测不准的部分时，基于预测误差的好奇心会一直停在那里看，不再探索别处。

怎么学

先补探索与利用和自监督学习。读原文第2节（图2的三个网络）和4.1节VizDoom实验。动手：在MiniGrid的稀疏奖励迷宫上给PPO加一个ICM，对比加与不加时的成功率；再在观测里加一块随机噪声，比较像素预测版和特征预测版。
