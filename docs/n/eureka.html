Eureka奖励设计

Eureka: Human-Level Reward Design via Coding Large Language Models
2023.10论文延伸Ma, Liang, Wang, Huang, Bastani, Jayaraman, Zhu, Fan, Anandkumar · NVIDIA / UPenn / Caltech / UT Austin待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

强化学习的奖励函数要靠专家反复手写调参，复杂灵巧操作（如转笔）几乎无从下手。

方法

让GPT-4按环境源码零样本写奖励函数代码，在仿真中训练后根据结果文字反馈让模型迭代改写，做进化式搜索。

影响

自动生成的奖励在多数任务上超过人类专家，首次让仿真五指手学会转笔。

方法

Eureka的循环是：把环境的源代码和任务描述交给GPT-4，它一次生成多份奖励函数代码；每份都在Isaac Gym大规模并行仿真里并行训练出策略，把训练统计（各奖励分量的变化曲线、任务成功率）整理成文字反馈，让模型据此反思并改写，重复若干轮取最好者。

摘要称在29个开源RL环境（10种机器人形态）上，它在83%的任务上超过人类专家奖励，平均归一化提升52%；还可以不更新模型参数，按人类反馈调整奖励。

后来的发展

把“LLM写奖励”做成了可复用的自动化流程，让奖励设计从手工试错变成搜索问题；它的做法也成为后续用大模型辅助仿真训练的参照。

局限与后续

  • 每轮需要完整的RL训练才能评估一份奖励，计算开销大。
