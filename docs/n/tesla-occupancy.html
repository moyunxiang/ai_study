Tesla占用网络

2022.06思想延伸公司技术展示，2022Tesla Autopilot团队待核对
维基百科（Tesla Autopilot） ↗在交互版中打开（演化树、学习进度）

问题

仅用检测框描述周围物体时，没见过的形状（掉落物、异形车辆）会被漏掉，而且也很难描述不规则障碍的实际占用空间。

方法

改为预测周围三维空间中每个小体素是否被占用，不依赖物体类别，直接用多路相机图像推断。

影响

成为纯视觉自动驾驶判断通行空间的核心感知表示，也推动了占用预测与OccWorld占用世界模型等世界模型工作。

方法

占用网络（occupancy network）把车周围的空间切成小格子（体素），对每个体素预测“是否被占用”，以及必要时的运动信息，输入是多个相机的图像，在Tesla HydraNet与BEV的鸟瞰感知基础上增加了高度这一维。它不关心被占用的东西是什么，因此对没有出现在检测类别里的障碍物也能保持保守。

本条目的公开资料多来自Tesla的技术分享而非论文。2022年10月，媒体（如Electrek）报道Tesla宣布取消超声波传感器，转向摄像头感知（Tesla Vision），在泊车等场景依赖基于视觉的占用估计；此处的具体精度与数字未核对。

它建立在什么之上

  • 改进
    占据栅格地图1985.03 · 具身·世界模型
    只在波束中心的一个水平切面上建二维地图，高于或低于声呐的障碍看不到；格子分辨率固定，面积越大内存越大。
  • 改进
    DARPA无人车挑战赛2005.10 · 具身·世界模型
    依赖5台激光雷达、雷达和高精度GPS/惯导，成本远高于量产车可以接受的水平。
  • 改进
    DARPA城市挑战赛2007.11 · 具身·世界模型
    依赖事先给定的精确路网和昂贵的多激光雷达组合，规模化部署的成本很高。
  • 改进
    Lift-Splat-Shoot2020.08 · 具身·世界模型
    把三维空间压成二维俯视平面，丢掉了高度信息，只能做BEV分割，不能直接输出带高度的三维框或悬空障碍物。
  • 改进
    Tesla HydraNet与BEV2021.08 · 具身·世界模型
    在HydraNet加鸟瞰感知的基础上，把二维的鸟瞰表示扩展为三维的体素占用。
  • 改进
    BEVFormer2022.03 · 具身·世界模型
    BEV是二维俯视平面，高度信息被压缩，对悬空物、不规则形状障碍和类别之外的物体表达有限。
