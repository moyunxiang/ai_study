循环记忆Transformer

Recurrent Memory Transformer
2022.07论文延伸NeurIPS 2022Aydar Bulatov, Yuri Kuratov, Mikhail S. Burtsev · MIPT / AIRI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自注意力的计算量随序列长度平方增长，输入长度受限；全局和局部信息又都塞在同一批词表示里。

方法

在输入里加几个特殊的记忆token，分段处理长序列，把上一段输出的记忆token传给下一段，实现段级循环。

影响

不改动Transformer本体就加入循环记忆，是后来在百万token量级做长序列记忆研究的起点。

方法

背景：Transformer-XL缓存上一段的隐状态来延长上下文，但全局信息和局部信息混在一起。

做法：RMT（Recurrent Memory Transformer）把长序列切成段。每段的输入前后加上若干个记忆token，段内正常做自注意力；处理完后，输出端对应位置的记忆token被取出，作为下一段输入端的记忆token。这样模型被训练去自己控制记忆的读写，不需要改变Transformer结构。

结果：论文称在较小记忆规模下，语言建模与Transformer-XL相当；在需要处理更长序列的任务上优于它。给Transformer-XL加上记忆token也能提升其表现。

局限与后续

  • 记忆只有几个向量，容量有限，且段间只能串行传递，训练要沿时间反向传播，难以并行。
