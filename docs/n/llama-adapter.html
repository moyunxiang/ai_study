LLaMA-Adapter零初始化注意力

LLaMA-Adapter: Efficient Fine-tuning of Language Models with Zero-init Attention
2023.03论文延伸ICLR 2024Renrui Zhang, Jiaming Han, Chris Liu, Peng Gao, Aojun Zhou, Xiangfei Hu, Shilin Yan, Pan Lu et al. · 上海人工智能实验室, 香港中文大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

Alpaca用5.2万条自指令数据全参数微调LLaMA-7B得到指令跟随模型，但要更新70亿参数；直接在前面加可学习提示又会在训练初期引入随机噪声，扰乱预训练知识。

方法

只在较高的若干层前面加一组可学习的“适配提示”，并给它们的注意力加一个从零开始的门控：训练开始时新提示完全不起作用，再逐步把指令信息注入模型。

影响

在LLaMA发布后的开源热潮中最早一批证明“百万级参数、一小时即可把LLaMA变成指令模型”的工作之一，零初始化门控的思路后来被多模态适配和其他PEFT方法沿用。

方法

Alpaca与廉价指令微调展示了用Self-Instruct式数据微调LLaMA的效果，但需要全参数训练。Prefix / Prompt Tuning类方法在每层前面拼接可学习的向量，参数少，但这些向量随机初始化，训练初期会严重干扰模型原本的注意力分布。

LLaMA-Adapter冻结整个LLaMA-7B，在最上面的若干层（论文设置为较高层）各插入一组长度很短的可学习适配提示，与词元一起参与注意力。关键是零初始化注意力：对适配提示那一部分的注意力分数单独做softmax，再乘以一个可学习的门控系数g，g初始化为0。于是训练第一步，模型输出与原模型完全一样；随着g变大，新的指令线索才逐渐加入，而原有词元之间的注意力不受影响，预训练知识得以保留。

摘要报告：只引入120万可训练参数，在8张A100上微调不到一小时，回答质量与全参数微调的Alpaca相当；该方法还能扩展到图像条件的多模态指令，在ScienceQA和COCO Caption上表现良好，零初始化注意力用于微调ViT、RoBERTa等其他预训练模型也有效。

局限与后续

  • 可训练参数太少、只作用于少数高层，复杂指令和多轮对话能力不及全参数或LoRA微调，后续V2版本扩大了可调参数范围。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    LoRA2021.06 · 系统·效率
    LoRA修改权重矩阵的低秩增量，LLaMA-Adapter在注意力输入端加门控提示，二者是同期LLaMA微调的两条主要路线，LoRA后来更普及。
  • 使用
    LLaMA2023.02 · LLM
    以冻结的LLaMA-7B为基础模型。
  • 延续
    Prefix / Prompt Tuning2021.01 · 系统·效率
    同样在注意力里加入可学习提示，但加上零初始化门控，避免训练初期随机提示干扰预训练知识。
  • 改进
    Alpaca与廉价指令微调2023.03 · LLM
    Alpaca要全参数微调7B模型，LLaMA-Adapter只训练120万参数、不到一小时达到相当效果。
