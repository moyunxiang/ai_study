DCNN动态卷积句子模型

A Convolutional Neural Network for Modelling Sentences
2014.04论文延伸ACL 2014Nal Kalchbrenner, Edward Grefenstette, Phil Blunsom · 牛津大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

表示整句话的递归神经网络要依赖外部句法分析树，推特这类难以分析的句子和没有分析器的语言就用不了；简单的卷积加整句最大池化又丢掉了词序和远距离结构。

方法

用宽卷积和动态k-max池化交替堆叠：每层保留k个最大激活且保持它们的先后顺序，k随句长和层数变化，网络自己在句子上归纳出类似句法树的特征图，不需要分析器。

影响

与同年的TextCNN一起确立了「卷积网络做句子建模」这条路线，在斯坦福情感树库上超过依赖句法树的递归张量网络；k-max池化后来也被其他文本CNN借用。

方法

递归张量网络与情感树库沿句法树逐层组合词向量，效果好但离不开外部分析树；从零开始的神经NLP的时间延迟网络（TDNN）只做一层卷积再对整句取最大值，词序信息几乎全丢。DCNN的设计有三个部件。宽卷积：卷积核在句子两端补零，使每个词（包括边缘词）都被所有卷积窗口覆盖。动态k-max池化：不只取最大值，而是在每个特征维上保留前k个最大激活并保持原来的顺序；第l层的k_l = max(k_top, ⌈(L−l)/L · s⌉)，s是句长、L是卷积层数，越往上k越小，最顶层固定为k_top，于是不同长度的句子都能输出固定大小的表示。折叠：池化前把特征图相邻两行逐元素相加，让不同维度的特征发生交互，且不增加参数。

多层叠加后，低层捕捉短语，高层把相隔很远的词连起来，作者称其诱导出一张覆盖整句的特征图。论文做了四个实验：斯坦福情感树库的二分类与五分类情感、TREC六类问题分类、用远程监督标注的推特情感。在影评情感上，DCNN二分类86.8%、五分类48.5%，高于RecNTN的85.4%和45.7%以及朴素贝叶斯、SVM等基线；在推特情感上相对最强基线预测错误减少25%以上。

读懂它需要的概念

卷积层、池化与感受野 嵌入向量 Softmax与logits 交叉熵

本篇术语

  • k-max池化　在一个特征维上保留数值最大的k个激活，并按它们在句中的原始顺序排列。
  • 宽卷积　在序列两端补零，使卷积输出比输入更长，边缘的词也能被卷积核完整覆盖。

怎么学

先读TextCNN句子分类了解最简单的文本CNN → 读原文第3节（宽卷积、k-max池化、折叠）→ 动手：在一个情感数据集上分别实现整句最大池化和k=3的k-max池化，比较准确率。
