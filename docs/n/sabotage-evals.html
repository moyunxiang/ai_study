破坏能力评测

Sabotage Evaluations for Frontier Models
2024.10论文延伸arXiv 2024-10Joe Benton, Misha Wagner, Eric Christiansen, Cem Anil, Ethan Perez, Buck Shlegeris 等 · Anthropic待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

AI控制假设模型可能暗中使坏，但缺乏办法来衡量一个模型是否有能力暗中破坏评测、监控或决策。

方法

定义“破坏能力”并设计一组相关的威胁模型和评测，证明在给定缓解措施下某个模型无法成功破坏开发者的工作。

影响

给“能力评测”增加了一个维度：不只测模型能做什么坏事，也测它能否破坏监督本身，后来的SHADE-Arena沿用这一思路。

方法

作者担心足够强的模型可能在重要场合暗中颠覆人类的监督，比如在评测自身危险能力时偷偷放水（见评测中故意藏拙）、破坏对它的监控，或影响是否部署它的决策。为此，他们设计了与这些威胁对应的评测，并强调评测应当是“知道缓解措施”的：目的是给出证据，说明在现有缓解措施下，该模型不可能成功地破坏一个前沿开发者的活动。

他们在Claude 3 Opus和Claude 3.5 Sonnet上演示了这些评测。结论是，对这些模型，最低限度的缓解措施目前足以应对破坏风险，但随着能力提升，将需要更真实的评测与更强的缓解措施。论文还列出了尝试过又放弃的评测，并讨论了用小规模统计数据来模拟大规模部署的做法。

局限与后续

  • 评测都是简化的模拟场景，能否代表真实部署中的破坏风险还不确定。
