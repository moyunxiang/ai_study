FourCastNet

FourCastNet: A Global Data-driven High-resolution Weather Model using Adaptive Fourier Neural Operators
2022.02论文重要arXiv 2022Pathak, Subramanian, Harrington, Raja, Chattopadhyay, Mardani, Kurth, Hall et al. · NVIDIA / Caltech / Lawrence Berkeley National Lab 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统数值天气预报要在超算上解物理方程，一次预报要几小时；而此前的深度学习天气模型分辨率很低，达不到业务使用的0.25度。

方法

把傅里叶神经算子与视觉Transformer结合（AFNO），在ERA5再分析数据上直接学习「当前大气状态到6小时后」的映射，并自回归滚动出一周预报。

影响

首个在0.25度分辨率上与IFS在部分变量上相当的数据驱动全球模型，一周预报不到2秒，点燃了2022至2023年的AI天气预报竞赛。

背景

数值天气预报（NWP）把大气当作流体，用时间步进求解物理方程，ECMWF的IFS是最强的业务系统，但需要大型超算和数小时计算。WeatherBench（2020）给数据驱动方法提供了基准，不过当时的深度学习模型分辨率约5.6度到2度，一个格点就是几百公里，无法表示降水、台风这类小尺度现象。问题在于：怎样让神经网络在百万级格点的全球场上既高分辨率又能快速训练。

方法

输入是ERA5再分析在0.25度网格上的若干变量（风、温度、湿度、位势高度等多个层次，图像大小约720×1440）。模型把这张全球图当作一幅多通道图像：先切成小块（见图像块与视觉token），再通过自适应傅里叶神经算子（AFNO）混合token。AFNO的思路来自傅里叶神经算子FNO：把空间混合放到频域做，先做二维傅里叶变换，在频域用逐通道的小MLP变换，再逆变换回来，复杂度近似O(N log N)，比标准自注意力的O(N²)适合这么大的图。外层结构沿用Vision Transformer。

模型一次预测下一个6小时的完整大气状态，再把输出当作输入反复滚动（自回归，见自回归生成）得到更长预报。为了降低误差累积，还做了两阶段训练：先学单步，再微调多步滚动。

结果

按论文报告：在短到中等预报时效上，大尺度变量的精度与IFS相当，而在降水等细尺度结构复杂的变量上优于IFS；一周预报生成时间不到2秒，比IFS快几个数量级，因此可以便宜地生成上千成员的大集合预报。

后来的发展

FourCastNet证明了0.25度的纯数据驱动预报可行。几个月后盘古天气在多数变量上全面超过IFS的确定性预报，GraphCast与AI天气预报和伏羲天气随后跟进，GenCast扩散集合预报把它扩展成概率性集合预报。NVIDIA也把它继续做成FourCastNet 3等后续版本（未在此核对）。

局限与后续

  • 预报在较长时效上会变模糊：均方误差训练使模型倾向输出平滑的平均场，极端值和小尺度结构被抹掉。
    后来针对它的工作　GenCast扩散集合预报 GraphCast与AI天气预报
  • 只给出单条确定性预报，没有可靠的不确定性估计；论文虽能廉价生成大集合，但集合离散度并不经过校准。
    后来针对它的工作　GenCast扩散集合预报 NeuralGCM混合气候模型
  • 自回归滚动时误差累积，且在整体精度上还未全面超过IFS，尤其是高空变量。
    后来针对它的工作　盘古天气 GraphCast与AI天气预报
  • 模型是黑箱，不保证守恒律等物理约束，也没有长期气候模拟的稳定性。

它建立在什么之上

  • 使用
    Vision Transformer2020.10 · 视觉
    采用图像切块加Transformer的整体结构，用AFNO取代自注意力。
  • 改进
    DeepONet算子学习2019.10 · 科学
    只在较简单的常微分方程和低维偏微分方程上演示，对高维、湍流等强非线性问题的能力未被检验。
  • 延续
    傅里叶神经算子FNO2020.10 · 科学
    把傅里叶神经算子的频域混合改造成适合大图的AFNO，用在全球大气场上。
  • 竞争
    物理信息神经网络PINN2017.11 · 科学
    PINN靠把物理方程写进损失函数；FourCastNet完全靠数据，不显式使用方程。
  • 改进
    WeatherBench2020.02 · 科学
    WeatherBench时代的数据驱动模型分辨率过低；FourCastNet首次做到0.25度。

读懂它需要的概念

本篇术语

  • ERA5　ECMWF制作的全球大气再分析数据集，把历史观测和模式同化成逐小时的规整网格，是训练数据驱动天气模型的标准数据。
  • 再分析　用现代预报系统把过去几十年的观测重新同化一遍得到的一致历史大气记录。

怎么学

先理解傅里叶变换与频域和图像块与视觉token。读原文的AFNO与训练两节；用NVIDIA的earth2studio或原仓库加载预训练权重，对一次台风做预报并和ERA5真值对比。
