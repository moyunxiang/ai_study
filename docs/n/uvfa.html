通用值函数近似UVFA

Universal Value Function Approximators
2015.07论文延伸ICML 2015Schaul, Horgan, Gregor, Silver · Google DeepMind待核对
PMLR ↗在交互版中打开（演化树、学习进度）

问题

普通价值函数 V(s) 只对一个固定目标有效，换一个目标就要重新学一个。

方法

让价值函数同时以状态和目标为输入 V(s,g;θ)，把状态和目标分别映射成嵌入向量再组合，使它能泛化到没见过的目标。

影响

为目标条件的RL奠定了基础，后见经验回放HER、技能迁移和后来的目标条件策略都沿用「目标作为输入」的写法。

方法

想法很直接：许多任务其实是「到达不同目标」，如果为每个目标单独训练一个价值函数，就学不到跨目标的共性。UVFA把目标g作为网络输入，一个函数 V(s,g;θ) 同时表示所有目标的价值。

论文提出一种高效的监督学习办法：先在部分 (s,g) 上得到观察到的价值，把这个价值表看作矩阵，把它分解成状态嵌入和目标嵌入的内积（低秩分解，见低秩近似），再学习一个把s和g映射到各自嵌入的函数。论文还说明如何只靠观察到的奖励，用RL算法更新UVFA，而不是依赖现成的价值标签。摘要称实验证明UVFA能成功泛化到训练时没有见过的目标。

局限与后续

  • 目标需要用向量表示，且奖励要能对任意目标定义；稀疏奖励下训练仍然困难。

  • 泛化到差别很大的新目标的能力有限。
