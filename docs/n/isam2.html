iSAM2因子图增量平滑

iSAM2: Incremental Smoothing and Mapping Using the Bayes Tree
2011.12论文延伸IJRR 2012Michael Kaess, Hordur Johannsson, Richard Roberts, Viorela Ila, John Leonard, Frank Dellaert · 麻省理工学院、佐治亚理工学院待核对
DOI ↗GTSAM ↗在交互版中打开（演化树、学习进度）

问题

SLAM写成因子图后，每来一个新测量都重新做整体非线性优化太慢；只在线滤波又会累积线性化误差，回环时无法修正历史。

方法

把因子图消元得到的结构组织成贝叶斯树，新测量到来时只更新树中受影响的部分，并按需选择性地重新线性化变量，实现增量的非线性平滑。

影响

iSAM2及其所在的GTSAM库成为视觉、激光与惯性SLAM后端的标准工具，LIO-SAM、VINS系列等大量系统都用它或同类增量优化器求解。

方法

SLAM的概率框架以来，SLAM被写成“求所有位姿和地标的最大后验估计”。用因子图表示：变量是机器人位姿和地标，因子是里程计、观测、回环等测量。整体求解是一个稀疏的非线性最小二乘问题，每步都全量求解（批量平滑）太慢，而卡尔曼滤波式滤波又无法回头修正历史线性化点。

iSAM2的关键是贝叶斯树：对因子图做变量消元得到的结构可以组织成一棵树，新测量加入时只影响树中从相关变量到根的一条路径，只需重新消元这一小部分；变量的线性化点只在偏离过大时才更新（流动重线性化），变量顺序也增量地调整。这样在保持完整平滑精度的同时，每步计算量接近常数级增长。它在GTSAM库中开源实现。

局限与后续

  • 大型回环会让贝叶斯树中很大一部分需要重新计算，出现偶发的计算尖峰。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    卡尔曼滤波1960 · 具身·世界模型
    滤波只估计当前状态，iSAM2保留并能修正全部历史状态。
  • 延续
    SLAM的概率框架1986 · 具身·世界模型
    把SLAM的概率估计写成因子图上的增量非线性平滑。
  • 竞争
    FastSLAM2002.07 · 具身·世界模型
    FastSLAM用粒子滤波分解SLAM，iSAM2用基于优化的平滑。
