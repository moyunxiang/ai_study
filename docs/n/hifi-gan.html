HiFi-GAN

HiFi-GAN: Generative Adversarial Networks for Efficient and High Fidelity Speech Synthesis
2020.10论文重要NeurIPS 2020Jungil Kong, Jaehyeon Kim, Jaekyoung Bae · Kakao Enterprise待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

神经声码器在“快”和“好”之间二选一：WaveNet音质好但极慢；WaveGlow、MelGAN能并行生成，但音质明显不如自回归模型。

方法

沿用GAN并行生成波形，关键是新增一个“多周期判别器”：把波形按2、3、5、7、11个采样点的周期折成二维，分别检查不同周期的规律，因为语音本质上是许多周期信号的叠加。

影响

在LJSpeech上MOS 4.36，接近真人录音4.45，同时在单块V100上比实时快约168倍；小版本在CPU上也比实时快13倍。HiFi-GAN很快成为TTS系统里最常用的声码器。

背景

Tacotron 2确立了“声学模型出梅尔谱、声码器出波形”的两段式TTS（见声码器与音频编解码）。声码器这一步，WaveNet音质最好，但逐采样点生成，在GPU上也远慢于实时；WaveGlow用可逆流模型并行生成，模型大、音质稍逊；MelGAN用生成对抗网络GAN做到很小很快的生成器，但音质与自回归模型仍有明显差距。作者认为GAN声码器差在判别器：语音由许多不同周期的正弦成分构成，而已有判别器（如MelGAN的多尺度判别器）只看连续的、经过平滑的波形，不擅长检查周期结构是否正确。

方法

生成器。输入梅尔谱，用若干层转置卷积逐步上采样到采样点频率（22.05kHz）。每次上采样后接一个多感受野融合（MRF）模块：几组不同卷积核大小、不同空洞率的残差块并行处理，再把输出相加，让生成器同时照顾长短不同的模式。

多周期判别器（MPD）。含5个子判别器，周期p分别取2、3、5、7、11（选素数以减少重叠）。周期为p的子判别器把长度T的一维波形重排成T/p × p的二维矩阵，再用宽度方向核长为1的二维卷积处理，相当于只看“每隔p个点取一个”的子序列，专门检查这一周期上的规律。

多尺度判别器（MSD）。沿用MelGAN的设计，分别在原始波形、2倍和4倍平均池化后的波形上判别，负责连续的整体结构。

损失（见对抗训练）。对抗部分用最小二乘GAN形式：判别器把真样本推向1、生成样本推向0，生成器则让生成样本被判为1。另加两项：生成波形与真实波形的梅尔谱L1距离，以及判别器各层特征的匹配损失。总损失L_G = L_adv + 2·L_FM + 45·L_mel。

结果

LJSpeech单人英语，MOS（真人4.45）：HiFi-GAN V1为4.36（1392万参数），V2为4.23（92万参数），V3为4.05；对比WaveNet（MoL）4.02、WaveGlow 3.81、MelGAN 3.79。速度（单块V100）：V1约每秒生成370万个采样点，比实时快167.9倍；V3快1186倍；WaveNet只有实时的0.003倍。CPU上V3比实时快13.44倍。把MPD加进MelGAN，MOS提高0.47，说明多周期判别器本身是主要贡献。在VCTK的9个未见说话人上三个版本MOS为3.77、3.69、3.61，都高于自回归和流模型声码器，说明能处理训练中没见过的嗓音。

后来的发展

HiFi-GAN的生成器和“多周期+多尺度”判别器组合成为此后两三年的默认声码器，直接被VITS用作波形解码部分。它的判别器设计也被神经音频编解码器沿用：神经音频编解码器、EnCodec、DAC音频编解码都把对抗训练加多尺度判别器当作恢复高保真波形的标准做法。

局限与后续

  • 仍是两段式管线里的独立模块，声学模型预测的梅尔谱与真实梅尔谱有差距，往往要用预测谱再微调声码器。
    后来针对它的工作　VITS
  • 以梅尔谱为输入，只能“还原”而不能压缩；要把音频变成可传输、可建模的离散token还需另一套编解码器。
    后来针对它的工作　神经音频编解码器 EnCodec
  • 主要在22kHz单人朗读语音上验证，对未见说话人、歌唱、音乐等域外音频的保真度下降。
    后来针对它的工作　DAC音频编解码

它建立在什么之上

  • 改进
    WaveNet2016.09 · 语音 已核对
    音质超过MoL WaveNet（4.36对4.02），生成速度快五万倍以上。
  • 使用
    生成对抗网络GAN2014.06 · 生成
    以生成器-判别器对抗训练为核心，采用最小二乘形式的GAN损失。
  • 使用
    Tacotron 22017.12 · 语音
    以梅尔谱为条件输入，接在Tacotron 2这类声学模型后面使用，论文也测试了这种端到端合成。
  • 改进
    SEGAN语音增强2017.03 · 语音
    音质提升有限，GAN训练不稳定，生成波形时会引入听感上的伪影。
  • 改进
    Parallel WaveNet2017.11 · 语音
    训练流程复杂：需要先训好一个完整的WaveNet老师，再做蒸馏，还要多项辅助损失调参。
  • 改进
    WaveRNN2018.02 · 语音
    仍是自回归，速度受限于序列长度，难以像流或GAN声码器那样大幅并行。
  • 改进
    SV2TTS声音克隆2018.06 · 语音
    三个模块分开训练，使用自回归WaveNet声码器，合成很慢；同时降低了声音伪造的门槛，带来滥用风险。
  • 竞争
    WaveGlow2018.10 · 语音
    同为并行声码器，WaveGlow走可逆流路线、模型大；HiFi-GAN参数更少、更快、MOS更高，GAN路线在声码器上胜出。
  • 改进
    MelGAN2019.10 · 语音
    MelGAN速度快但音质差；HiFi-GAN保留它的多尺度判别器，新增多周期判别器和MRF生成器，MOS从3.79提高到4.36。
  • 改进
    DiffWave2020.09 · 语音
    合成需要迭代多步去噪，速度仍慢于一次前向的GAN声码器。

后来的相关工作

  • 使用
    VITS2021.06 · 语音
    解码器就是HiFi-GAN V1生成器，判别器用HiFi-GAN的多周期判别器。
  • 改进
    神经音频编解码器2021.07 · 语音
    沿着“重建损失+多判别器对抗训练还原高保真波形”的声码器路线，把它从梅尔谱条件推广到学出的压缩表示。
  • 竞争
    EnCodec2022.10 · 语音
    HiFi-GAN用多尺度与多周期波形判别器；EnCodec改用单一的多尺度STFT判别器，消融显示单用它已经足够且训练更快。
  • 使用
    Voicebox2023.06 · 语音
    用在同样6万小时数据上训练的HiFi-GAN把生成的梅尔谱转成波形。
  • 使用
    SeamlessM4T2023.08 · 语音
    用多语言HiFi-GAN单元声码器把离散单元合成为波形。
  • 延续
    BigVGAN通用声码器2022.06 · 语音
    沿用HiFi-GAN的生成器与多判别器框架，加入周期激活和抗混叠并放大规模。
  • 使用
    ElevenLabs2023.01 · 语音
    此类产品的波形生成环节多采用类似HiFi-GAN的神经声码器（推测，未验证）。
  • 使用
    RVC检索式变声2023.03 · 语音
    波形生成部分采用HiFi-GAN式声码器。
  • 改进
    Vocos频域声码器2023.06 · 语音
    HiFi-GAN在时域逐级上采样、计算冗余；Vocos在帧率上预测傅里叶系数，速度快一个数量级。
  • 改进
    DAC音频编解码2023.06 · 语音
    主要在22kHz单人朗读语音上验证，对未见说话人、歌唱、音乐等域外音频的保真度下降。
  • 延续
    Fish-Speech2024.11 · 语音
    FF-GAN声码器在HiFi-GAN系结构上替换多感受野模块。

本篇术语

  • 多周期判别器（MPD）　把一维波形按周期p折叠成二维，再按列做卷积，每个子判别器只看间隔为p的采样点，从而专门判断某种周期结构是否逼真。
  • 特征匹配损失　让生成样本在判别器每一层的中间特征与真实样本尽量接近，给生成器提供比“真/假”一个数更细的梯度信号。
