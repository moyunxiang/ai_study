MAUVE生成分布差距

MAUVE: Measuring the Gap Between Neural Text and Human Text using Divergence Frontiers
2021.02论文延伸NeurIPS 2021Krishna Pillutla, Swabha Swayamdipta, Rowan Zellers, John Thickstun, Sean Welleck, Yejin Choi, Zaid Harchaoui · 华盛顿大学 / 艾伦人工智能研究所待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

开放式续写没有标准答案，BLEU这类逐句对比参考的指标用不上；困惑度只看模型给人类文本的概率，看不到模型自己生成的文本是否重复、乏味或离题。

方法

把一大批模型生成文本和一大批人类文本都编码成向量并量化成离散簇，比较两个分布之间的“散度前沿”，用曲线下面积作为一个0到1的分数MAUVE。

影响

成为比较解码方法（贪心、束搜索、top-k、核采样）和开放式生成质量的常用分布级指标，常与困惑度、重复率一起报告。

方法

背景。核采样Top-p指出，用GPT-2做贪心或束搜索解码会生成大量重复、乏味的文本，而纯随机采样又容易胡言乱语。要比较这些解码方法，需要一个衡量“生成文本整体上像不像人写的”指标。困惑度只评价模型给人类文本打的概率，不评价模型实际采样出来的东西；逐句与参考比较的指标在开放式续写里也没有意义，因为同一个开头可以有无数种合理续写。

做法。设P是人类文本分布，Q是模型文本分布。模型可能犯两种错：生成人类不会写的东西（Q有而P没有，类似假阳性），以及漏掉人类常写的东西（P有而Q没有，类似假阴性）。MAUVE用一族混合分布 R_λ = λP + (1−λ)Q，对每个λ计算两个KL散度 KL(Q‖R_λ) 和 KL(P‖R_λ)，画成一条“散度前沿”曲线，把曲线下面积作为分数，越接近1说明两分布越接近。高维文本没法直接算KL，于是先用大模型把每段文本编码成向量，再用k-means量化成有限个簇，在簇的直方图上计算。

结果。摘要称，在三个开放式生成任务上，MAUVE能识别生成文本的已知性质（如核采样优于贪心解码），随模型规模增大而自然提高，并与人类判断相关，限制比以往的分布级指标更少。

局限与后续

  • 分数依赖所用的编码模型、簇数和样本量，不同论文的设置不同时数值不能直接比较；它也只衡量“像不像人类文本分布”，不衡量事实是否正确。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    GPT-22019.02 · LLM
    用GPT-2系列做生成模型和文本编码器。
  • 延续
    FID与Inception Score2017.06 · 数据·评测
    思路类似图像生成的FID：都在预训练模型的特征空间里比较生成分布与真实分布，MAUVE改用散度前沿来区分两类错误。
  • 改进
    核采样Top-p2019.04 · 系统·效率
    核采样论文揭示了解码方法导致的文本退化，但缺少统一的分布级指标；MAUVE提供了比较各种解码方法的单一分数。

读懂它需要的概念

KL散度 聚类 解码：贪心、束搜索、温度与top-p 生成质量指标：IS与FID 嵌入向量

本篇术语

  • 散度前沿　在真实分布与生成分布的一族混合上计算两个方向的KL散度并连成曲线，同时刻画“生成了不该有的”和“漏掉了该有的”两类误差。

怎么学

先补KL散度和核采样Top-p；读MAUVE原文的散度前沿示意图；动手用官方库对同一模型的贪心解码和核采样输出各算一次MAUVE。
