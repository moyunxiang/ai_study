AggreVaTe代价感知模仿

Reinforcement and Imitation Learning via Interactive No-Regret Learning
2014.06论文延伸arXiv 2014Stéphane Ross, J. Andrew Bagnell · Carnegie Mellon University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DAgger只模仿专家的动作，不管各个动作代价差多少：偏离专家一点点和犯下致命错误被当成同样的错。它也没法用在只有奖励、没有专家的RL里。

方法

让专家给出的不再是「该选哪个动作」，而是「每个动作之后由专家接手还要付出多少代价」，然后在这些代价上做DAgger式的迭代聚合训练；进一步把专家换成学到的价值估计，就推广到了强化学习。

影响

把交互式模仿学习和近似策略迭代统一到无悔在线学习的框架下，后来的AggreVaTeD、THOR等把它与深度策略梯度结合。

方法

AggreVaTe（Aggregate Values to Imitate）沿用DAgger的流程：用当前策略跑出状态，把新数据并入一个不断增长的数据集，再在全部数据上训练新策略。区别在于每个样本的标签。

在当前策略访问到的某个状态s，随机挑一个动作a执行，然后让专家从下一步开始接手，记录总代价，得到专家的「代价-到-终点」估计 Q*(s,a)。新策略被训练成最小化 Q*(s, π(s))，也就是一个代价敏感分类问题：动作不同，选错的代价不同。这样学到的策略会优先避开代价大的错误。

第二步推广是：如果没有专家，就用当前策略自己的价值估计代替 Q*，算法就变成一种在线近似策略迭代。摘要称，这为在线近似策略迭代在实践中常见的成功提供了理论支持，并给出了一个统一看待模仿学习和强化学习的算法家族。

局限与后续

  • 每个训练样本都要让专家从某个状态接手跑完剩下的任务来测代价，在真实机器人或人类专家场景里非常昂贵。

  • 保证依赖于能找到一个在代价敏感分类上无悔的学习器，对深度网络这类非凸模型只是近似成立。

它建立在什么之上

  • 延续
    DAgger2010.11 · RL
    保留DAgger的数据聚合与无悔分析，把动作标签换成专家的代价-到-终点，使学习感知错误的严重程度。
  • 竞争
    保守策略迭代CPI2002 · RL
    推广到RL后，AggreVaTe成为一种近似策略迭代，与保守策略迭代处理的是同一问题，但用无悔学习而非保守混合来保证进展。
  • 改进
    SEARN搜索式结构预测2009.07 · RL
    需要一个能在任意状态给出最优动作的「最优策略」，很多真实任务里拿不到。
  • 延续
    Forward Training与SMILe2010.03 · RL
    同一作者2010年提出的复合误差分析与逐步替换专家的思路，在这里推广到带代价的情形。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

模仿学习与行为克隆 策略与价值函数 分布偏移 损失函数

本篇术语

  • 代价-到-终点（cost-to-go）　从某个状态做了某个动作之后，直到任务结束还要付出的总代价，等价于取负的Q值。
  • 无悔学习　在线学习里的一种保证：长期来看，算法的平均损失不比事后看来最好的那个固定模型差多少。

怎么学

先读DAgger；读本文第3节AggreVaTe算法和第4节到RL的推广；在一个网格世界里给不同错误设置不同代价，比较DAgger和AggreVaTe学到的策略。
