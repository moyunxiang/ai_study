DAN深度平均网络

Deep Unordered Composition Rivals Syntactic Methods for Text Classification
2015.07论文延伸ACL-IJCNLP 2015Mohit Iyyer, Varun Manjunatha, Jordan Boyd-Graber, Hal Daumé III · 马里兰大学、科罗拉多大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

递归神经网络等按句法树组合词义的模型在情感分析上效果好，但每个树节点都要做昂贵的矩阵或张量运算，依赖句法分析，在大数据或算力有限时训练成本过高。

方法

深度平均网络：把句子里所有词向量直接取平均，再送进几层全连接网络后分类；训练时随机丢掉一部分词再求平均（词级dropout）作为正则。

影响

在情感分析和问答上接近甚至超过依赖句法的模型，而在普通笔记本上只需几分钟训练；这让「无序的词袋平均加深层网络」成为句子分类和句向量的强基线，谷歌的通用句子编码器就提供了DAN版本。

方法

递归张量网络与情感树库、Tree-LSTM这类句法组合模型要先做句法分析，然后在树的每个节点上计算h = f(W·[h_left; h_right])甚至张量积，计算量大、只能用在能可靠分析的较小数据上。另一端是无序的词袋平均（NBOW），速度快但效果差。

DAN只做三步：一，对句中所有词的向量取平均z₀ = (1/|X|)·Σ v_w；二，经过一层或多层前馈网络z_i = g(W_i·z_{i−1} + b_i)；三，用最后一层的表示做softmax分类。作者的分析是：几个句子的平均向量可能非常接近，但多层非线性能把其中微小而有意义的差别放大。

词级dropout：训练时对每个样本以一定概率把某些词整个从平均中去掉，这样一个长度为|X|的句子理论上能变出2^|X|种不同的输入，提高了鲁棒性。作者也尝试把它用到递归网络的叶子节点上。

实验在斯坦福情感树库（句子级）、IMDB影评（文档级）和问答比赛题上进行。摘要称，DAN在只用一小部分训练时间的情况下与句法组合模型相当，在部分任务上更好；在句法变化大的数据上甚至超过句法模型；错误分析显示它和句法模型犯的错误类似，说明对这些任务而言，非线性变换输入比专门设计组合函数更重要。

局限与后续

  • 完全忽略词序，对否定词、转折（如「不是不好」「虽然……但是」）等依赖结构的现象天然无能为力。

读懂它需要的概念

嵌入向量 多层感知机 Dropout Softmax与logits 正则化与权重衰减

本篇术语

  • 无序组合　把一组词向量合成句子向量时不考虑词的顺序和句法结构，例如直接求和或求平均。
  • 词级dropout　训练时随机把句中某些词整个丢掉，不参与平均，相当于数据增强加正则。

怎么学

先读递归张量网络与情感树库的讲解了解句法组合模型 → 读原文第3节DAN和第3.1节词级dropout → 动手：在SST二分类上实现一个三层DAN，比较有无词级dropout时的准确率和训练时间。
