Werbos博士论文

Beyond Regression: New Tools for Prediction and Analysis in the Behavioral Sciences
1974论文延伸Harvard PhD thesis 1974Paul Werbos · 哈佛大学（博士论文）待核对
维基百科：Paul Werbos ↗在交互版中打开（演化树、学习进度）

问题

多层网络的权重怎么训练没有办法：ADALINE与LMS的规则只对最后一层有效，而感知机一书之后研究热度下降。

方法

在博士论文里描述了用链式法则把误差从输出逐层反向传播、计算对所有参数的梯度，并用于动态系统的预测。

影响

是反向传播的早期独立发现之一，但当时几乎没被神经网络界注意，要等1986年反向传播才广为人知。

方法

Werbos在论文里把“反向传播”表述为一种高效计算导数的办法：把计算过程看作一系列函数的复合，先前向算出各量，再从输出开始按链式法则把误差反向逐层传回，一次得到所有参数的梯度，代价与一次前向相当（见反向传播）。

他把这个方法用于回归和动态系统建模，并明确提到可以用于神经网络。当时人工智能界对多层网络的兴趣很低，此文没有引起注意。后来Werbos也在1990年写了随时间反向传播BPTT的教程。需要注意，反向传播思想有多个独立来源，这里不应简化为“某人发明”。
