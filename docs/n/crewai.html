CrewAI角色分工框架

2023.11系统延伸João Moura等 · CrewAI Inc.待核对
GitHub ↗官方文档 ↗在交互版中打开（演化树、学习进度）

问题

2023年下半年，开发者想把“研究员查资料、分析师写报告”这类分工协作交给多个LLM智能体完成，但AutoGen等框架偏研究、概念多，用起来需要自己设计对话协议，上手门槛不低。

方法

用“组建一个团队”的比喻来写多智能体程序：每个智能体用角色、目标、背景故事三句话定义，并配上工具；任务写明要做什么和期望输出；再把智能体和任务装进一个Crew，按顺序或由自动生成的经理智能体分派执行。

影响

2023年11月发布首个版本后迅速走红，GitHub星标超过6万，成为最常用的开源多智能体框架之一；后来加入事件驱动的Flows，把“自主协作”和“精确控制的工作流”结合起来。

背景

CAMEL角色扮演用角色扮演让两个智能体协作，MetaGPT和ChatDev按软件公司的岗位分工组织智能体，多智能体框架AutoGen提供可编程的多智能体对话。但这些更像研究原型；业界需要的是定义简单、能直接接入现有工具和模型的开发框架。

方法

智能体（Agent）：用三个字段描述——role（角色，如“某主题高级研究员”）、goal（目标，如“找出该主题的最新进展”）、backstory（背景故事，如“你是一位善于发现并清晰呈现信息的资深研究员”），再指定可用的工具、使用的LLM、记忆和防护规则。这些描述会被拼进系统提示，相当于给模型一个明确的“人设”。

任务（Task）：写明任务描述、期望的输出格式，以及由哪个智能体负责；后一个任务可以使用前一个任务的输出作为上下文。

团队（Crew）与流程（Process）：

  • 顺序流程：任务按列表顺序执行，像流水线；
  • 层级流程：框架自动生成一个经理智能体，负责规划、把任务委派给团队成员，并检查结果。

Flows：后来加入的事件驱动工作流，可以精确控制状态、分支和路由，在其中嵌入单次LLM调用或整个Crew，适合需要确定性的生产场景。配置可以用代码，也可以用YAML/JSON文件描述智能体和任务。

后来的发展

CrewAI与LangGraph图式编排、OpenAI Swarm框架、Responses API与Agents SDK等一起构成2024–2025年最常见的一批智能体开发框架；多智能体为何失败等研究分析多智能体系统失败原因时，也把这类基于角色分工的框架作为研究对象。

本篇术语

  • 顺序流程与层级流程　顺序流程按固定顺序执行任务；层级流程由一个经理智能体动态分派任务并验收结果。
  • 人设（persona）　写进系统提示里的角色描述，让模型以特定身份和目标来回答。
