不变因果预测ICP

Causal inference using invariant prediction: identification and confidence intervals
2015.01论文延伸JRSS-B 2016Jonas Peters, Peter Bühlmann, Nicolai Meinshausen · 苏黎世联邦理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

非因果的预测模型在观测数据上可能很准，可一旦有人干预变量或环境变了，预测就会严重出错；从数据中找出因果变量，通常需要很强的假设。

方法

利用一个性质：用因果父变量预测目标，这种预测关系在不同实验环境和干预下保持不变。于是收集多个环境的数据，找出所有“在各环境中预测误差分布不变”的变量子集，它们的交集以高概率只含真正的因果变量。

影响

把“不变性=因果性”的原则变成可用的统计方法，并给出因果效应的有效置信区间；它是后来不变风险最小化IRM等不变性学习方法的直接思想来源。

方法

设有多个环境e（如不同实验条件、不同干预），目标Y由其因果父变量通过结构方程产生。若某个变量子集S恰好是Y的因果父集，则在所有环境里，给定X_S后Y的条件分布相同，即残差分布不随环境变化。ICP对每个候选子集S做假设检验：在各环境上用X_S回归Y，检验残差在环境间是否同分布；没有被拒绝的子集都“可能是”因果父集，取它们的交集作为估计。

因为真正的父集以至少1−α的概率不被拒绝，这个交集以高概率只包含因果变量（可能不全）；同样的逻辑也给出了因果系数的置信区间。作者在线性结构方程模型下给出了父集可识别的充分条件，讨论了模型设定错误时的稳健性，并用大规模基因扰动实验等数据集检验了方法。

局限与后续

  • 需要枚举变量子集，变量多时计算量指数增长；且要求因果变量已经被直接观测到，不能从像素等低层输入中学出。
