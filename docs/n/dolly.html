Dolly 2.0与dolly-15k

Dolly: Open Instruction-Tuned LLM
2023.04模型延伸Databricks待核对
官方博客 ↗在交互版中打开（演化树、学习进度）

问题

Alpaca等早期开源指令模型用ChatGPT生成的数据训练，受OpenAI条款限制不能商用。

方法

让5000多名员工众包写出1.5万条指令-回答对，在Pythia-12B上微调，模型、代码和数据全部以可商用许可开放。

影响

databricks-dolly-15k是第一个可商用、人工撰写的开源指令数据集，后来被大量指令微调工作当作标准数据之一。

背景

2023年3月，Alpaca与廉价指令微调用Self-Instruct的办法从ChatGPT蒸馏了5.2万条指令数据，几百美元就训出像样的对话模型；Databricks两周前发布的Dolly 1.0也走这条路。但这些数据来自OpenAI的模型，使用条款禁止拿来开发竞争产品，企业无法放心商用。

方法

Dolly 2.0换掉了数据来源：

  • 数据：databricks-dolly-15k，1.5万条由5000多名Databricks员工在2023年3–4月手写的提示/回答对，覆盖头脑风暴、内容生成、信息抽取、摘要、开放问答、分类等行为类别，以CC BY-SA 3.0许可开放，可用于商业用途。
  • 模型：以EleutherAI的Pythia-12B为基座做指令微调与对话模板，得到dolly-v2-12b。
  • 训练代码、数据和权重全部开源。

结果

官方博客称这是第一个开源的、基于人工生成且许可商用的指令数据训练的指令遵循大模型；博客同时坦言它的能力并非最先进，主要价值在于开放与可商用。

后来的发展

dolly-15k与LIMA少即是多的人工精选数据一起，推动了“少量高质量人工指令数据”的路线，也是许多开源指令混合数据集（如Tülu系列）的组成部分。

局限与后续

  • 1.5万条数据规模小、主要由一家公司的员工撰写，多样性和专业深度有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 基座Pythia-12B本身能力较弱，Dolly 2.0的对话和推理质量明显落后于同期的Vicuna等模型。
