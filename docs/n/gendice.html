GenDICE广义分布修正

GenDICE: Generalized Offline Estimation of Stationary Values
2020.02论文延伸ICLR 2020Ruiyi Zhang, Bo Dai, Lihong Li, Dale Schuurmans · Duke / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

很多问题需要估计马尔可夫链平稳分布下的量（离策略评估、PageRank），但手里只有一批固定的转移数据，不能再与环境交互；此前的DualDICE只适用于折扣设定，平均回报或无折扣情形处理不了。

方法

直接从平稳分布的基本性质出发，估计“平稳分布与经验数据分布之比”，并用变分散度最小化把约束改写成可优化的目标；统一处理折扣与平均回报两种设定（GenDICE）。

影响

DICE（分布修正估计）一族的关键一步，与DualDICE、GradientDICE等共同构成离线策略评估的标准方法，并为OptiDICE等离线优化方法提供基础。

方法

设数据由某个未知行为策略收集，得到转移 (s, a, s′) 的经验分布 d^D。目标策略π下的平稳分布记为 d^π，要估计比值 τ(s, a) = d^π(s, a) / d^D(s, a)。一旦有了τ，任何平稳期望都可以用数据加权估计，例如平均回报 ρ(π) = E_(d^D)[τ(s, a) r(s, a)]。

平稳分布满足不动点方程：d^π(s′, a′) = (1−γ)μ_0(s′)π(a′|s′) + γ Σ_(s,a) P(s′|s, a) π(a′|s′) d^π(s, a)，其中γ=1时对应平均回报（无折扣）设定。GenDICE把它写成：经过一步转移后的分布 T(d^D·τ) 应当等于 d^D·τ，于是最小化两者之间的f散度。借助f散度的变分（Fenchel对偶）表示，这个散度可以写成只需从数据采样的min-max目标；再加上 E_(d^D)[τ] = 1 的归一化约束（用拉格朗日乘子处理），防止τ退化为0。

作者在一般条件下证明了估计的一致性，给出了误差分析，并在离线PageRank和离策略策略评估等基准上展示了很好的实验表现。

局限与后续

  • min-max目标训练不稳定，散度和网络选择影响很大；后续工作指出其中的平方约束在某些情况下会让优化变难。

  • 竞争
    双重稳健策略评估2011.03 · RL
    双重稳健估计依赖已知的行为策略概率；GenDICE不需要知道行为策略。
  • 使用
    PageRank与Google搜索1998.04 · NLP
    把离线PageRank作为平稳分布估计的一个应用场景。
  • 竞争
    老虎机回放离线评估2010.03 · RL
    回放式离线评估需要随机记录的数据；GenDICE可用任意行为策略的数据。
  • 延续
    DualDICE分布修正估计2019.06 · RL
    把DualDICE的分布修正估计从折扣设定推广到平均回报等更一般的平稳量估计。

    AlgaeDICE任意经验策略梯度2019.12 · RL
    同一研究组的DICE工作：AlgaeDICE侧重策略优化，GenDICE侧重一般平稳量的估计。

读懂它需要的概念

马尔可夫性与马尔可夫链 重要性采样 拉格朗日乘子、约束优化与对偶 KL散度

本篇术语

  • 平稳分布　马尔可夫链长期运行后各状态出现频率稳定下来的分布。
  • 离策略评估（OPE）　用别的策略收集的数据估计目标策略的表现，不让目标策略真的去执行。

怎么学

先读DualDICE分布修正估计；读GenDICE原文第3节从不动点方程到变分目标的推导；在一个小的表格MDP上实现GenDICE并与真实平均回报比较。
