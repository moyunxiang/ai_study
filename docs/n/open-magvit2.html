Open-MAGVIT2开源分词器

Open-MAGVIT2: An Open-Source Project Toward Democratizing Auto-regressive Visual Generation
2024.09论文延伸Zhuoyan Luo, Fengyuan Shi, Yixiao Ge, Yujiu Yang, Limin Wang, Ying Shan · 腾讯ARC Lab / 清华大学深圳国际研究生院 / 南京大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

谷歌的MAGVIT-v2与LFQ分词器用无查表量化做出了码本极大、重建很好的视觉分词器，但没有开源权重和代码，社区的自回归图像生成只能用重建较差的VQGAN式分词器。

方法

开源复现MAGVIT-v2的超大码本分词器（2^18个码），再训练一族纯自回归生成模型；为了让模型能预测这么大的词表，把每个token拆成两个更小的子token，按“下一个子token”的方式预测。

影响

给开源社区提供了重建质量很强的离散视觉分词器和配套自回归模型，被后续不少自回归与统一多模态工作直接拿来当分词器或基线。

方法

Open-MAGVIT2分两部分。

分词器：按MAGVIT-v2与LFQ分词器的无查表量化（LFQ）做法，编码器输出的每个隐向量直接按每一维的正负号变成一串二进制位，18维就对应2^18=262144个码，不需要在码本里做最近邻查找，大码本也不会出现大量码字闲置。作者复现了这套结构和训练流程，在ImageNet和UCF视频重建上取得当时最好的指标，还提供了在大规模数据上预训练的版本，零样本重建明显好于英伟达的Cosmos分词器。

生成器：在分词器之上训练类似LlamaGen的纯解码器自回归模型，规模从3亿到15亿参数。词表有26万项时，输出层又大又难学。作者用非对称token分解把一个18位的码拆成两个子码（例如6位和12位两个小词表），模型每个位置先预测第一个子码、再在其条件下预测第二个（“下一个子token预测”），既减小了输出层，又让两个子码彼此关联。论文全部开源模型和代码。

本篇术语

  • 无查表量化（LFQ）　不建一张向量码本，而是把隐向量每一维按正负号取成0或1，整串二进制数就是token编号，码本大小随维数指数增长。

怎么学

先读VQ-VAE/VQGAN的量化与码本坍塌 → 读MAGVIT-v2的LFQ → 读本文第3节非对称token分解，用开源分词器做一次重建实验。
