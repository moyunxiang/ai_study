Joshua层次翻译工具包

Joshua: An Open Source Toolkit for Parsing-Based Machine Translation
2009.03系统延伸WMT 2009Zhifei Li, Chris Callison-Burch, Chris Dyer, Juri Ganitkevitch, Sanjeev Khudanpur, Lane Schwartz, Wren Thornton, Jonathan Weese, Omar Zaidan · 约翰斯·霍普金斯大学等待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

Moses让短语式翻译人人可用，但Hiero这类基于同步上下文无关文法的层次短语、句法翻译系统没有成熟的开源实现，研究者要复现它们得从图分析、语言模型集成、立方剪枝写起。

方法

用Java实现一个完整、可扩展的“基于句法分析的翻译”工具包：同步上下文无关文法的图分析解码、n-gram语言模型集成、束搜索与立方剪枝、k-best抽取，外加后缀数组抽取文法和MERT调参，并支持并行与分布式计算。

影响

成为与Moses并列的主流开源统计翻译工具之一，专门服务层次短语与句法翻译研究，在WMT等评测和众多论文里被用作Hiero式系统的实现。

背景

层次短语翻译Hiero（2005）证明层次短语规则能处理短语式系统难以处理的结构性调序，但它的解码本质上是一个同步文法的图分析（chart parsing），还要把n-gram语言模型融进去——这需要立方剪枝与森林重打分等专门算法。2007年Moses开源后，短语式翻译门槛大降，层次式和句法式翻译却缺少同等的公共平台，结果难以比较。

方法

Joshua实现了同步上下文无关文法（SCFG）翻译所需的整条流水线：

  • 文法抽取：用后缀数组在大规模平行语料上按需检索短语，并抽取带非终结符的层次规则（如 X → 〈X_1 的 X_2, X_2 of X_1〉），避免预先存储巨大的规则表；
  • 解码：对源句做CKY式图分析，每个格子存放带目标端信息的假设；用束搜索和立方剪枝与森林重打分在融合n-gram语言模型的同时控制假设数量；
  • k-best抽取：从超图中高效取出k个最好的推导；
  • 调参：内置最小错误率训练MERT。

工程上它按功能分包、用Java接口定义可扩展组件，强调端到端一致与可扩展，并利用并行与分布式计算处理大语料。

结果

在WMT09法语—英语翻译任务上达到当时最先进水平（原文摘要所述）；工具包已被用于翻译约一百万句平行语料，以做大规模判别训练实验。

后来的发展

Joshua之后持续更新（加入句法增强规则、更快的解码器等），与Moses的层次模式、cdec一起构成了层次与句法翻译研究的开源基础。2011年的KenLM语言模型查询库也集成进了Joshua。神经翻译兴起后，这些统计翻译工具逐渐被Marian、fairseq等神经框架取代。

局限与后续

  • 层次规则数量巨大，图分析解码比短语式解码慢得多，对内存和计算要求高。

本篇术语

  • 同步上下文无关文法（SCFG）　每条规则同时生成源语言和目标语言两边的串，非终结符在两边一一对应，可以表达调序。
  • 后缀数组　把语料所有后缀排序后的索引结构，可以快速找出任意短语在语料中的全部出现位置。

怎么学

先读层次短语翻译Hiero和立方剪枝与森林重打分 → 读本文第2节工具组成 → 动手：在一份小平行语料上手工写几条层次规则，用CKY思路给一句源句列出可能的推导。
