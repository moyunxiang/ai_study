ERNIE 2.0持续多任务预训练

ERNIE 2.0: A Continual Pre-training Framework for Language Understanding
2019.07论文延伸AAAI 2020Yu Sun, Shuohuan Wang, Yukun Li, Shikun Feng, Hao Tian, Hua Wu, Haifeng Wang · 百度待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

BERT类预训练只用一两个简单任务（掩码词预测、下一句预测），主要学到词和句子的共现关系；语料中还有实体、句子结构、篇章关系、语义相关性等信息，没被充分利用。而一次性加很多任务又会互相干扰，后加的任务容易让模型忘掉先学的。

方法

提出持续预训练框架：按词法、结构、语义三类构造多达七个无监督或弱监督的预训练任务，逐个引入；每引入一个新任务，都与之前所有任务一起做多任务训练，从而不断积累知识又不遗忘。

影响

在16个中英文任务（英文GLUE加多个中文任务）上超过BERT和XLNet，2019年底一度登顶GLUE榜单；“按需不断增加预训练任务”的框架和其中的知识掩码、篇章关系任务为后续ERNIE 3.0等中文大模型沿用。

背景

BERT用掩码语言模型和下一句预测两个任务预训练，XLNet用排列语言模型，RoBERTa发现去掉下一句预测、加大数据更好。百度此前的百度ERNIE（1.0）把整个短语或实体一起遮住（知识掩码），让模型学到实体级知识。但一个预训练任务只能覆盖一种信息，任务一多就要处理任务之间的冲突与遗忘。

方法

七个任务，分三类：

  • 词法感知：知识掩码（遮住整个短语或命名实体）；大写预测（预测英文词是否首字母大写，大写词多为实体）；词—文档关系（预测一个词是否在同一文档的其他段落里也出现，常见于主题词）；
  • 结构感知：句子重排（把段落切成若干片段打乱，预测原顺序）；句子距离（判断两句是相邻、同文档不相邻还是来自不同文档）；
  • 语义感知：篇章关系（预测两句之间的修辞或逻辑关系）；检索相关性（用搜索日志弱监督，判断查询与标题是强相关、弱相关还是无关）。

持续多任务学习：任务一个一个加。加入第k个任务时，不是只训练它，而是把它和前k−1个任务一起训练，每个任务按一定比例分配训练步数，从而新知识不断叠加、旧任务不被遗忘。模型结构仍是Transformer编码器，额外加一个任务嵌入，告诉模型当前是哪个任务。

微调：预训练完成后，与BERT一样在下游任务上整体微调。

结果

ERNIE 2.0在16个任务上超过BERT和XLNet，包括英文GLUE基准的各项任务和若干常见中文任务（如阅读理解、命名实体识别、自然语言推理、情感分析、问答匹配等）。

后来的发展

知识掩码、篇章关系等任务和持续多任务框架被后来的ERNIE 3.0 Titan继承，并发展为文心系列大模型；“设计更多、更有结构的预训练任务”这条路线在规模化的自回归模型兴起后逐渐让位于“单一下一词预测+更多数据”。

它建立在什么之上

  • 改进
    BERT2018.10 · LLM
    BERT只用简单任务学共现关系；ERNIE 2.0加入结构与语义任务，在16个任务上超过BERT。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测
    主要的英文评测基准。
  • 延续
    百度ERNIE2019.04 · LLM
    保留ERNIE 1.0的知识掩码，并扩展为词法、结构、语义三类共七个任务。
  • 竞争
    XLNet2019.06 · LLM
    同期的预训练改进路线；XLNet改目标函数，ERNIE 2.0增加任务，后者在所报告的任务上更好。

读懂它需要的概念

掩码建模 预训练与微调 Transformer层的结构 持续学习与灾难性遗忘 自监督学习

本篇术语

  • 持续学习　模型按顺序学习一系列任务，希望学新任务时不忘掉旧任务；ERNIE 2.0用把新旧任务一起训练的办法来避免遗忘。
  • 任务嵌入　加到输入上的一个向量，表示当前训练的是哪个任务，让同一个模型区分不同任务。

怎么学

先读BERT和百度ERNIE；读本文第3节七个预训练任务和持续多任务学习的示意图；动手：在一个小BERT上加一个句子重排任务，比较它对下游句子关系任务的影响。
