Hugging Face LeRobot

LeRobot: State-of-the-art Machine Learning for Real-World Robotics in Pytorch
2024.05系统重要Remi Cadene, Simon Alibert, Alexander Soare, Thomas Wolf等 · Hugging Face待核对
GitHub ↗论文（2026） ↗文档 ↗在交互版中打开（演化树、学习进度）

问题

机器人学习的代码、数据格式和硬件接口各自为政：每篇论文一套代码、每台机器人一套驱动，想复现ACT或Diffusion Policy得从零搭环境。

方法

像Transformers库统一语言模型那样，用一个PyTorch库统一机器人学习全链路：硬件驱动和遥操作、标准数据格式LeRobotDataset、主流策略的参考实现、训练与部署，数据和模型都放在Hugging Face Hub上共享。

影响

配合低成本的开源SO-100机械臂，让个人和小团队也能采数据、训练并部署策略；社区在Hub上上传了数千个数据集，SO-10X采集的占一半以上。

背景

到2024年初，ALOHA与ACT和Diffusion Policy已经证明，几十条人类示范就能教会机械臂完成精细动作。但要真正用起来门槛很高：每篇论文的代码风格不同、依赖不同；数据有的存成HDF5，有的是RLDS，有的是自定义格式；每种机械臂的电机驱动、相机同步都要自己写；工业级机械臂动辄上万美元。

语言模型领域几年前也有类似的碎片化，Hugging Face Transformers用统一的模型接口和Hugging Face Hub与Datasets上的共享权重解决了它。LeRobot试图在机器人领域复制这条路。

方法

LeRobot是一个纯Python、基于PyTorch的开源库，2024年1月建仓、5月前后公开推广，覆盖从电机到策略的整条链路：

硬件层：统一的Robot接口，get_observation()读取图像和关节状态，send_action()下发动作。最初支持Koch、SO-100和ALOHA三种机械臂，后来扩展到移动底盘和人形。SO-100/SO-101是可3D打印、成本只有工业臂零头的开源机械臂，带一只主动臂用于遥操作。

数据层：LeRobotDataset格式，状态和动作存Parquet表，相机画面存成MP4视频，附带语言描述等元数据；可以直接从Hub流式读取，无需先下载整个数据集。

策略层：提供ALOHA与ACT、Diffusion Policy、VQ-BeT、TD-MPC等单任务方法的参考实现，后来又加入π0、SmolVLA等多任务VLA和HIL-SERL强化学习。

推理层：异步推理，把“算动作”和“执行动作”拆开：策略可以跑在另一台带GPU的机器上，一次预测未来H步的动作块，机器人按固定频率逐步执行，同时下一块已在计算。

结果

据2026年的论文，库中各策略的规模从ACT的5200万参数到π0的35亿参数不等，fp32下π0在GPU上峰值显存约13GB。社区已在Hub上贡献了数千个数据集、数十万条示范轨迹和数百个模型，其中一半以上的数据集是在SO-10X机械臂上采集的。2025年内支持的机器人从3种增加到8种。

后来的发展

LeRobot把“个人在家用一对低成本开源机械臂采数据、训练ACT”变成了常见做法，也成了Hugging Face自家小型VLA SmolVLA 的发布平台；π0等开源VLA也被移植进来。它的数据格式逐渐成为开源社区共享真机数据的事实标准之一，与谷歌的RLDS（Open X-Embodiment使用）并存。

容易误解的地方

  • LeRobot是工具库，本身不是一个新模型或新算法；论文直到2026年才发表，比代码晚了两年。
  • 低成本机械臂精度、负载和重复性有限，在SO-100上训出的效果不能直接外推到工业臂或灵巧手。

读懂它需要的概念

模仿学习与行为克隆 遥操作与示教数据 动作表示：离散token、连续动作与动作块 控制回路与控制频率 状态、观测与动作

本篇术语

  • SO-100 / SO-101　开源、可3D打印的低成本六自由度机械臂，成对使用：人手动摆动主动臂，从动臂实时跟随，从而采集示范数据。
  • 异步推理　把模型推理和机器人执行放在两个并行的进程（甚至两台机器）里：执行当前动作块的同时就开始算下一块，避免机器人停下来等模型。
  • Parquet　一种按列存储的表格文件格式，读取部分列很快，适合存放高频的关节状态和动作序列。

怎么学

先了解遥操作与示教数据和动作表示：离散token、连续动作与动作块。照着官方文档装好LeRobot，先在仿真环境（如ALOHA仿真）里训练一个ACT策略并评测；有条件的话组装一对SO-101，录50条抓放示范，训练后在真机上部署，体会数据质量对成功率的影响。
