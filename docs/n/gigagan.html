GigaGAN

Scaling up GANs for Text-to-Image Synthesis
2023.03论文延伸CVPR 2023Kang, Zhu, Zhang, Park, Shechtman, Paris, Park · POSTECH / CMU / Adobe待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

DALL·E 2之后文生图的主流转向扩散和自回归，人们怀疑GAN是否还能随数据和规模扩展：直接放大StyleGAN会不稳定。

方法

设计一种可稳定放大的GAN架构，用大规模数据（如LAION）训练文生图，并保持GAN一次前向出图的速度。

影响

证明GAN在文生图上仍是可行方案：512px图只要0.13秒，且保留了潜空间编辑能力；后来对抗扩散蒸馏SDXL Turbo等对抗蒸馏也沿用了判别器的思路。

方法

论文指出：简单增大StyleGAN2的容量会很快变得不稳定，于是提出新的GAN架构，使其能稳定扩大。结果有三点优势：推理速度比扩散模型快几个数量级，合成512像素图像只要0.13秒；能合成高分辨率图像，如1600万像素的图在3.66秒内完成；仍支持潜空间插值、风格混合和向量运算等潜空间编辑。

它说明GAN的瓶颈主要不在方法本身，而在训练稳定性与扩展方式；也为后来把对抗训练与扩散蒸馏结合的单步生成方法提供了参考。

它建立在什么之上

  • 使用
    CLIP2021.01 · 多模态
    借助CLIP等文本编码为GAN提供文字条件。
  • 改进
    StyleGAN2018.12 · 生成
    只擅长人脸、汽车、卧室这类结构单一、对齐良好的领域，难以做多类别或文本条件生成。
  • 延续
    StyleGAN22019.12 · 生成
    在StyleGAN2基础上加入文本条件并重新设计以稳定放大。
  • 改进
    StyleGAN3无混叠2021.06 · 生成
    在文本条件和大数据集上的扩展有限，大规模文生图的主流转向了扩散与自回归模型。
