MAXQ值函数分解

Hierarchical Reinforcement Learning with the MAXQ Value Function Decomposition
1999.05论文延伸JAIR 2000（arXiv 1999）Thomas G. Dietterich · Oregon State University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

扁平的Q学习在长任务上学得很慢，因为每个状态-动作都要单独学；分层RL的早期方案（如封建式分层RL）缺少清楚的价值分解和收敛保证。

方法

把目标MDP拆成一棵子任务层级，每个子任务本身是一个小MDP；把整体价值函数写成各子任务价值函数的加和，并给出可以安全做状态抽象的条件。

影响

与Options时间抽象框架、HAM并列为经典分层RL的三大框架之一，「出租车（Taxi）」环境作为它的测试域至今仍是RL教学里的常见例子。

方法

以出租车任务为例：出租车要去某处接乘客再送到目的地。MAXQ让设计者把它拆成层级：根任务 → 「接客」「送客」→ 「导航到某地」→ 上下左右等原子动作。

核心是价值分解。对子任务i，在状态s下调用子动作a的价值写成 Q(i, s, a) = V(a, s) + C(i, s, a)：前一项是完成子动作a本身能得到的回报，后一项「完成函数」C是a结束之后、把父任务i做完还能得到的回报。递归地展开，整个任务的价值就是沿层级各子任务价值的加和。这样「导航到某地」的价值可以在接客和送客两个子任务中共享，不必重学。

摘要列出论文的贡献：定义MAXQ层级并证明其表示能力；给出五个可安全使用状态抽象的条件（例如导航时不需要关心乘客在哪）；提出在线无模型算法MAXQ-Q，证明它即使在五种状态抽象下也以概率1收敛到递归最优策略；在三个领域的实验中，带状态抽象的MAXQ-Q比扁平Q学习快得多地收敛。此外，学到的价值分解还允许执行一种类似策略改进的「非分层执行」，得到更好的扁平策略。

局限与后续

  • 子任务层级必须由人设计，算法不会自己发现该怎样分解任务。

读懂它需要的概念

马尔可夫决策过程 Bellman方程 时序差分与自举 策略与价值函数

本篇术语

  • 递归最优　层级中每个子任务在给定其子任务策略的前提下都是最优的；它可能比真正的整体最优差。
  • 完成函数　MAXQ里记录「做完某个子动作之后，完成父任务还能得到多少回报」的函数。

怎么学

先实现Gymnasium里的Taxi环境上的表格Q学习；读原文第3–4节层级与价值分解；按论文的层级实现MAXQ-Q，比较收敛速度。
