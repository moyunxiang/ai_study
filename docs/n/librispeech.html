LibriSpeech

LibriSpeech: An ASR Corpus Based on Public Domain Audio Books
2015.04数据集延伸ICASSP 2015Panayotov, Chen, Povey, Khudanpur · Johns Hopkins University待核对
OpenSLR ↗在交互版中打开（演化树、学习进度）

问题

开源的英语语音识别数据要么太小，要么要付费授权，各家系统的结果无法在同一份数据上公平比较。

方法

把志愿者朗读的公共领域有声书（LibriVox）与对应的古登堡计划电子书文本自动对齐、切分，得到约1000小时、可免费使用的朗读语音语料。

影响

成了英语语音识别最常用的公开基准，此后端到端模型的论文几乎都报告它的 test-clean / test-other 词错误率。

方法

做法是把有声书音频和原书文本做自动对齐，再切成适合训练的短片段，并按说话人和录音难度分成干净（clean）与较难（other）两类。训练集分为100小时、360小时的 clean 与500小时的 other 三份；开发集和测试集也各有 clean 与 other 两个版本。

它之所以重要，是因为语料采用 CC BY 4.0 许可，任何人都能下载，原始 mp3 与书本文本也一并发布。于是研究者可以在同一份数据上比较 Deep Speech端到端识别 一类端到端系统和传统系统，词错误率（见词错误率）在 test-clean 上的数字成了通用刻度。

局限与后续

  • 全是朗读的书面语，语速平稳、录音干净，与电话、会议里的自发口语差别很大，在它上面的低错误率不代表真实场景可用。
    后来针对它的工作　Whisper
  • 只有英语一种语言，且训练数据量（约1000小时）远小于后来用于预训练的无标注或弱标注音频。
    后来针对它的工作　wav2vec Whisper

它建立在什么之上

  • 改进
    TIMIT语音语料1990 · 数据·评测
    总共只有约5小时，对需要上千小时数据的大型神经网络模型来说太小，只能作音素级的小规模对比。
  • 使用
    CTC2006 · 语音
    LibriSpeech 的文本与音频对齐思路服务于训练CTC这类需要对齐的端到端模型，也是它们最常用的评测集。
  • 延续
    Deep Speech端到端识别2014.12 · 语音
    Deep Speech 一类端到端系统缺少大规模公开数据，LibriSpeech 补上了免费的1000小时语料。
  • 改进
    WSJ朗读语料1992 · 数据·评测
    朗读语音比自然对话规整得多，在这个语料上的高分不代表真实场景能用。
  • 改进
    Fisher电话语料2004.05 · 数据·评测
    全部是8kHz电话信道的美式英语会话，话题受限，换到宽带、噪声、口音复杂的场景就会掉点。

后来的相关工作

  • 使用
    Whisper2022.09 · 语音 已核对
    以LibriSpeech为参照分布，揭示只在它上面比分数会严重高估模型在真实场景中的能力。
  • 使用
    Deep Speech 22015.12 · 语音
    以LibriSpeech、WSJ和CHiME等公开集与人工转写对比，衡量与人类水平的差距。
  • 使用
    SpecAugment2019.04 · 语音
    主要基准之一，在test-other上把当时最好的结果相对降低约22%。
  • 延续
    AISHELL-1中文语音语料2017.09 · 数据·评测
    论文以LibriSpeech为榜样，为普通话提供同类的开放识别语料。
  • 竞争
    Speech Commands关键词识别2018.04 · 数据·评测
    LibriSpeech按句对齐、适合完整语音识别；Speech Commands以单词为单位，专为关键词识别设计。
  • 改进
    LibriTTS多说话人合成语料2019.04 · 数据·评测
    LibriSpeech为语音识别准备、不太适合合成训练，LibriTTS从同一批原始材料重新制作成合成专用语料。
  • 改进
    wav2vec2019.04 · 语音
    只有英语一种语言，且训练数据量（约1000小时）远小于后来用于预训练的无标注或弱标注音频。
  • 竞争
    Common Voice2019.12 · 数据·评测
    LibriSpeech来自英文有声书、规模大但只有英语；Common Voice靠众包覆盖几十种语言。
  • 延续
    Libri-Light2019.12 · 数据·评测
    沿用LibriVox有声书来源，把规模从约千小时扩大到六万多小时并去除文本。
  • 延续
    多语言LibriSpeech MLS2020.12 · 数据·评测
    把LibriSpeech从有声书到英语单一语种的构造方式推广到8种语言。
  • 延续
    GigaSpeech2021.06 · 数据·评测
    把LibriSpeech式的开放语料扩展到多领域、含自发口语的万小时规模。
  • 竞争
    People's Speech可商用语料2021.11 · 数据·评测
    以LibriSpeech test-clean作为评测，规模大30倍但转写噪声更多。
  • 使用
    Open ASR Leaderboard2023.09 · 数据·评测
    沿用LibriSpeech等公开测试集作为评测数据的一部分。

读懂它需要的概念

监督学习 词错误率 波形、频谱与梅尔谱 训练集、验证集与测试集

本篇术语

  • test-clean / test-other　两个测试集各约5小时（5.4和5.1小时，40和33位说话人）。作者用WSJ上训练的模型给每位说话人算词错误率，低的归“clean”、高的归“other”；other的开发集和测试集还特意从偏难的说话人里挑，所以test-other的错误率总比test-clean高。
  • LibriSpeech 960h　三个训练子集train-clean-100（100.6小时）、train-clean-360（363.6小时）、train-other-500（496.7小时）合起来约960小时；论文里写“960h”就是用了全部训练数据。

怎么学

先看词错误率 → 打开 OpenSLR 页面了解各个子集 → 用任意开源识别工具在 test-clean 上跑一遍，自己算WER。
