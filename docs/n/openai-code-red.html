OpenAI“红色警报”

2025.12事件延伸Sam Altman · OpenAI内部备忘录（The Information、《华尔街日报》、Bloomberg报道）待核对
Fortune：Sam Altman declares 'code red' as Google's Gemini catches up（2025-12-02） ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT发布三年后，谷歌靠Gemini 3在推理和编码上赢得大量好评，Gemini月活用户也快速增长；OpenAI的领先第一次被普遍认为受到实质威胁。

方法

2025年12月1日前后，Altman在内部备忘录里宣布进入“红色警报”状态，要求集中资源改进ChatGPT的速度、可靠性和个性化，并推迟广告等其他项目。

影响

三年前谷歌因ChatGPT拉响“红色警报”，这次角色互换，被普遍视为前沿模型竞争格局变化的标志。

方法

据Fortune援引The Information，Altman在备忘录中写道“我们正处在ChatGPT的关键时刻”，要求把更多资源投向改进ChatGPT；Bloomberg的消息称其他项目会因此推迟，Fortune点名的是广告计划。备忘录还说下周将发布一个新的推理模型，内部评测显示它胜过Gemini 3。

背景数字：Fortune称Gemini 3约在两周前发布，谷歌称是有史以来最快部署进搜索的模型；Gemini应用10月月活达到6.5亿；OpenAI称ChatGPT周活为8亿。Altman公开称赞Gemini 3是一个很好的模型。

这一幕的反讽在于：2022年11月30日ChatGPT发布后，谷歌也拉响过“红色警报”（谷歌“红色警报”与Bard），当时担心的是搜索业务被颠覆。同月OpenAI发布了GPT-5.2。
