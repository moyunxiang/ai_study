对抗运动先验AMP

AMP: Adversarial Motion Priors for Stylized Physics-Based Character Control
2021.04论文延伸SIGGRAPH 2021Peng, Ma, Abbeel, Levine, Kanazawa · UC Berkeley待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

DeepMimic这类动作追踪方法要为每段参考动作手工设计模仿奖励，数据一多还得另外写机制来选该跟哪一段。

方法

用一个对抗判别器当“动作风格奖励”：任务目标用简单奖励表示，动作自然不自然则由判别器根据一堆未分段的动作片段来判断。

影响

免去了手工设计模仿目标和选片段的机制，成为物理角色控制乃至人形机器人动作模仿的常用框架，并引出ASE技能嵌入。

方法

AMP把任务和风格拆开：高层任务（比如走向目标、踢球）用简单的任务奖励表达；低层风格由一个判别器给出，判别器学会区分“来自动作数据集的状态转移”和“策略产生的状态转移”，策略的风格奖励就是骗过判别器的程度。这一思路来自GAIL。

动作数据集可以是一堆没有标注、没有排序的动作片段，不需要告诉策略什么时候该用哪一段，对抗训练的过程自己会选出适合当前任务的动作。最终的奖励是任务奖励和风格奖励的组合，用强化学习训练。摘要称，这种方法能让角色在完成任务的同时自动选择并拼接适合的动作片段。

局限与后续

  • 对抗训练可能不稳定，判别器只覆盖数据集已有的动作，容易模式坍缩到数据中的部分行为。
    后来针对它的工作　ASE技能嵌入
  • 每换一个任务都要重新训练策略，学到的技能无法直接复用。
    后来针对它的工作　ASE技能嵌入

它建立在什么之上

  • 使用
    GAIL2016.06 · RL
    借用GAIL的对抗模仿框架，把判别器作为动作先验。
  • 改进
    DeepMimic2018.04 · 具身·世界模型
    DeepMimic需要为每段动作手工设计追踪奖励并选择片段，AMP用对抗式的风格奖励取代，并能处理大量无序动作数据。
  • 改进
    模仿动物学敏捷步态2020.04 · 具身·世界模型
    每个技能要一段对齐时间相位的参考动作，策略只能跟着这一段走，不能自由组合或切换风格。

后来的相关工作

  • 改进
    ASE技能嵌入2022.05 · 具身·世界模型
    在AMP的对抗动作先验上增加潜在技能嵌入和无监督技能发现，让一个策略掌握多种可复用技能。
  • 使用
    PHC永续人形动作跟踪2023.05 · 具身·世界模型
    训练中借助对抗运动先验式的奖励让恢复等动作更自然。
