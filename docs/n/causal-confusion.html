模仿学习中的因果混淆

Causal Confusion in Imitation Learning
2019.05论文延伸NeurIPS 2019Pim de Haan, Dinesh Jayaraman, Sergey Levine · 阿姆斯特丹大学 / UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

行为克隆把模仿当成“给观测预测专家动作”的监督学习，模型只学相关性、不懂因果；一旦智能体自己开车、观测分布改变，那些只是与专家动作相关而非导致动作的线索就会把它带偏。

方法

指出一个反直觉的现象“因果误识别”：给模仿学习者更多信息反而可能更差；并提出对策——先训练一族对应不同因果假设（使用观测的哪些部分）的策略，再通过有针对性的干预（与环境交互看回报，或询问专家）挑出正确的因果结构。

影响

是模仿学习中“分布偏移+因果”问题的标志性分析，“刹车灯”例子被广泛引用，推动了关于模仿学习中虚假相关、捷径学习和因果鲁棒性的一系列后续研究。

背景

行为克隆（最早如ALVINN端到端驾驶）训练一个判别模型 π(a | o) 拟合专家的（观测，动作）数据，简单有效，但众所周知有复合误差和分布偏移问题——DAgger通过让专家在智能体访问的状态上继续标注来缓解。本文关注另一个被忽视的问题：判别模型不知道专家与环境之间的因果结构。在训练数据里，很多变量都与专家动作高度相关，但其中只有一部分是动作的原因。

方法

现象：作者的典型例子是驾驶。如果观测图像里包含仪表盘上的刹车指示灯，而指示灯在专家踩下刹车后才亮，那么“灯亮”与“刹车”在示范数据里几乎完全相关，模型会学到“灯亮就刹车”这一捷径，而忽略真正的原因（前方有行人）。部署时，智能体自己决定何时刹车，灯的状态由它自己的动作引起，这个捷径就失效了。于是出现“信息越多越差”：去掉指示灯的图像反而训练出更好的策略。作者在多个控制基准和驾驶场景中复现了这一现象。

对策：先用变分自编码器（如β-VAE）把观测分解成若干个潜在因子，再用一个二值掩码G表示“策略使用哪些因子”这一因果图假设。训练一个以G为条件的策略 π(a | x ⊙ G, G)，在随机采样的G上同时学习。然后做有针对性的干预来确定G：策略执行干预——在环境里执行不同G对应的策略，根据得到的回报推断哪个G更好；专家查询干预——在智能体访问的状态上询问专家动作，选与专家最一致的G。

结果

摘要称，因果误识别出现在多个基准控制领域以及接近真实的驾驶场景中；作者把提出的方案与DAgger及其他基线和消融进行了对比验证。

后来的发展

这篇工作让“模仿学习中的虚假相关”成为一个独立研究问题；后续工作研究了用历史动作作输入导致的“模仿自己过去动作”的捷径（copycat问题）、基于不变性的鲁棒模仿等。它也与视觉模仿、自动驾驶中的捷径学习讨论直接相关。

读懂它需要的概念

模仿学习与行为克隆 分布偏移 监督学习 隐变量模型 泛化与过拟合

本篇术语

  • 因果误识别　模型把与结果相关但并非原因的变量当成原因来使用；在模仿学习里，部署时这些相关性会因智能体自己的动作而改变，导致失败。
  • 干预　主动改变某个变量或执行某个策略来观察结果，以区分相关和因果，而不是只看被动收集的数据。

怎么学

先理解行为克隆与DAgger；读原文第3节刹车灯例子与“更多信息更差”的实验；在一个简单控制任务的观测里加入“上一步动作”这个泄露信息，观察行为克隆的部署表现如何变差。
