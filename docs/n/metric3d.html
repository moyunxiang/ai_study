Metric3D度量深度

Metric3D: Towards Zero-shot Metric 3D Prediction from A Single Image
2023.07论文延伸ICCV 2023Wei Yin, Chi Zhang, Hao Chen, Zhipeng Cai, Gang Yu, Kaixuan Wang, Xiaozhi Chen, Chunhua Shen · 大疆 / 腾讯 / 阿德莱德大学 / 浙江大学 等待核对

问题

MiDaS混合数据集深度靠混合多数据集训练获得零样本泛化，但只能预测相对深度；度量深度模型又只能用单一相机训练，因为不同焦距会让同样的画面对应不同距离。

方法

把所有训练图像变换到一个统一焦距的“标准相机空间”再学深度，预测后按真实焦距换回，消除相机带来的尺度歧义，从而能在海量混合数据上训练度量深度。

影响

第一批能在未见过的相机和网络照片上给出米制深度的通用模型之一，让单目深度可以直接用于测量、SLAM尺度恢复等。

方法

核心观察是“度量歧义”：同一辆车，用长焦拍得大、用广角拍得小，网络只看像素无法判断真实距离，除非知道焦距。Metric3D提出标准相机空间变换模块：设定一个标准焦距，训练时要么把图像按焦距比缩放，要么把真值深度按焦距比缩放，使所有样本都像是同一台相机拍的；推理时预测标准空间的深度，再乘回真实焦距的比例得到米制深度。这个模块与网络结构无关，可以插到现有单目深度模型里。

有了它，模型可以混合来自上千种相机、超过800万张图像稳定训练。摘要报告在7个零样本基准上取得领先，赢得第二届单目深度估计挑战赛冠军，并能缓解单目SLAM的尺度漂移，实现带米制尺度的稠密建图。

后来的发展

2024年的Metric3D v2加入表面法线联合估计并换用ViT骨干；同期Depth Pro度量深度、MoGe单目几何、Depth Anything V2等都把零样本度量深度作为主要目标。

它建立在什么之上

  • 延续
    单图深度预测2014.06 · 视觉
    延续单图回归深度的路线，从单一数据集的度量深度推广到跨相机零样本。
  • 改进
    SfMLearner自监督深度2017.04 · 视觉
    单目视频只能恢复到未知尺度，深度和位移都没有米制单位。
  • 改进
    Monodepth22018.06 · 视觉
    仍只能得到未知尺度的相对深度，换一台相机或场景尺度就不确定。
  • 改进
    PackNet自监督深度2019.05 · 视觉
    光度一致性假设在运动物体、遮挡和弱纹理处失效，单目尺度也只能靠额外信息（如速度）恢复。
  • 改进
    MiDaS混合数据集深度2019.07 · 视觉
    MiDaS用仿射不变损失绕开尺度问题、只给相对深度；Metric3D用标准相机变换解决尺度歧义，在混合数据上学米制深度。
  • 改进
    AdaBins自适应区间2020.11 · 视觉
    仍是在单个数据集上监督训练，换到别的场景或相机需要重新训练，零样本泛化差。
  • 竞争
    DPT稠密预测ViT2021.03 · 视觉
    DPT等相对深度模型泛化好但无尺度，Metric3D追求同时泛化且有尺度。
  • 使用
    ConvNeXt2022.01 · 视觉
    第一版主要采用ConvNeXt骨干。
  • 改进
    ZoeDepth2023.02 · 视觉
    度量尺度只来自少数几个微调数据集，按“室内/室外”二选一路由，遇到焦距或场景差异很大的照片尺度仍会偏。

读懂它需要的概念

相机模型与多视图几何 分类、检测、分割 分布偏移 零样本与少样本 损失函数

本篇术语

  • 度量深度　以米为单位的真实距离；相对深度只知道谁远谁近，不知道具体多远。
  • 焦距　相机内参之一，决定视野宽窄和物体在画面里的大小，同一物体焦距越长显得越大。

怎么学

先弄清针孔相机模型中焦距与成像大小的关系，再读Metric3D第3节标准相机变换；用官方模型对同一场景的广角与长焦照片测深度对比。
