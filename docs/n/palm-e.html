PaLM-E

PaLM-E: An Embodied Multimodal Language Model
2023.03论文重要ICML 2023Danny Driess, Fei Xia, Mehdi S. M. Sajjadi, Corey Lynch, Aakanksha Chowdhery, Brian Ichter, Ayzaan Wahid, Jonathan Tompson et al. · Google / TU Berlin待核对
arXiv ↗项目主页（含视频） ↗在交互版中打开（演化树、学习进度）

问题

SayCan、Code as Policies里的语言模型看不到图像，只能靠价值函数或检测器的文字转述了解现场；视觉语言模型能看图，却没在机器人数据上训练过，不会做具身规划。

方法

把图像、机器人状态等连续观测编码成和词向量同一维度的向量，直接插进语言模型的输入句子里（“多模态句子”），与540B的PaLM一起端到端训练，让同一个模型看着现场生成机器人的下一步计划。

影响

562B参数的PaLM-E同时能做机器人规划、视觉问答和普通语言任务，并显示网页图文数据能正向迁移到机器人任务；它是从“语言模型+外部接口”走向视觉-语言-动作模型的关键一步。

背景

SayCan让语言模型给技能打分，但语言模型本身看不到图像，现场信息只能通过技能价值函数间接传给它；Code as Policies里的语言模型也只能通过检测器返回的物体名和坐标了解场景。遇到“刚才那步成功没有”“哪块积木挡住了另一块”这类需要看的问题，语言模型就无能为力。

另一边，Flamingo、PaLI这类视觉语言模型已经能看图回答问题，但它们训练于网页图文，没有在机器人数据上学过“怎么一步步完成任务”。问题是能否让一个大语言模型直接“看见”机器人的感知输入，并把它在网页上学到的知识带到具身任务中。

方法

多模态句子。语言模型的输入本来是一串词向量。PaLM-E把连续观测也编码成同样维度的向量，直接放进这个序列，与文字交错，例如 Q: What happened between <img_1> and <img_2>?，其中 <img_i> 位置放的是图像经编码器得到的一组向量（见嵌入向量）。输出仍是文字，由PaLM逐词生成（见自回归生成），可以是问题答案，也可以是一串“下一步做什么”的计划。

编码器。比较了多种输入：状态向量；Vision Transformer（4B和22B）的图像特征经投影层映射到词向量空间；按物体切分的物体中心表示；以及无监督发现物体的三维场景表示OSRT。

执行。PaLM-E只输出文字形式的高层决策，由已有的底层策略（如RT-1和Language-Table的策略）执行；执行后输入新图像，闭环重新规划。

联合训练。训练数据的“完整混合”以网页规模的视觉语言数据为主，机器人数据只占8.9%，涵盖三种机器人场景：任务与运动规划（TAMP）的抓取堆叠、桌面推物体（Language-Table）、移动机械臂的厨房任务。

结果

最大的PaLM-E-562B由540B的PaLM和22B的ViT组成。它在OK-VQA上达到66.1，作为不针对该任务微调的通用模型，超过了专门微调的模型；同时保留了通用语言能力，且模型越大，多模态训练造成的语言能力遗忘越少。在机器人任务上，与只用各自领域数据训练相比，加入完整混合数据并使用预训练的PaLM和ViT明显提升了成功率；TAMP中每个规划任务只给320个样本时，不同输入表示的效果差异很大。

后来的发展

PaLM-E证明了“机器人感知可以直接作为语言模型的输入”，以及网页数据对具身任务有正迁移。几个月后的RT-2与VLA更进一步：在PaLI和PaLM-E的基础上不再只输出高层计划，而是把底层动作也写成token直接输出，形成视觉-语言-动作模型（VLA）。

局限与后续

  • 只输出文字形式的高层计划，底层动作仍依赖另外训练的策略，规划再好也受限于底层技能的能力。

  • 562B参数推理极慢、部署成本极高，无法在机器人上实时运行。
    后来针对它的工作　OpenVLA SmolVLA

它建立在什么之上

  • 使用
    Vision Transformer2020.10 · 视觉
    用4B和22B的ViT把图像编码成一串向量，经投影层后插入语言模型输入。
  • 改进
    《概率机器人》2005.08 · 具身·世界模型
    地图只有几何（哪里被占据），没有语义，机器人知道墙在哪，却不知道“杯子在厨房”。
  • 使用
    PaLM2022.04 · LLM
    以PaLM（最大540B）作为语言主干，所有模态都被映射进它的词向量空间。
  • 改进
    SayCan2022.04 · 具身·世界模型
    SayCan的语言模型看不到图像、只能借价值函数感知现场；PaLM-E让语言模型直接读图规划，并能根据新图像重新规划。
  • 延续
    Flamingo2022.04 · 多模态
    同样把视觉特征接入大语言模型；PaLM-E进一步加入状态向量、三维场景表示等连续输入，并在机器人数据上联合训练。
  • 改进
    Code as Policies2022.09 · 具身·世界模型
    Code as Policies只能通过检测器的文字结果了解场景，PaLM-E直接以图像作为语言模型输入。
  • 使用
    RT-12022.12 · 具身·世界模型
    移动机械臂场景中，由RT-1等现有底层策略执行PaLM-E生成的文字指令。
  • 改进
    ALFRED具身指令基准2019.12 · 具身·世界模型
    指令由人写、任务来自固定的几类模板，语言和任务的开放程度有限，难以检验对新词汇和新任务的泛化。

读懂它需要的概念

语言模型 嵌入向量 自回归生成 图像块与视觉token 迁移学习 预训练与微调

本篇术语

  • 多模态句子　把图像、状态等非文字输入编码成向量，按位置插在文字之间，组成一个语言模型可以直接读入的混合序列。
  • 具身推理　结合自身所处的物理环境和身体能力进行推理，例如判断下一步该做什么、某个动作是否可行。
  • 灾难性遗忘　在新数据上继续训练时，模型丢失了原来学会的能力；PaLM-E发现模型越大，这个问题越轻。

怎么学

先补视觉语言模型的基本结构（ViT+投影+LLM） → 读原文第3–4节（多模态句子和输入表示）和图3（迁移实验） → 动手：用一个开源的小型视觉语言模型，把桌面照片和“下一步应该做什么”的提问拼成多模态输入，观察它生成的计划。
