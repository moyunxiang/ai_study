Active-Prompt主动选例

Active Prompting with Chain-of-Thought for Large Language Models
2023.02论文延伸Shizhe Diao, Pengcheng Wang, Yong Lin, Rui Pan, Xiang Liu, Tong Zhang · 港科大 / 多伦多大学 / 港大 / UIUC待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

少样本思维链用的是一组固定的人工示例（如原论文为GSM8K写的8道），对不同任务不一定是最有用的；可人工写推理过程很贵，不可能把整个训练集都标一遍。

方法

借用主动学习：先让模型把一批候选题各答10次，答案越不一致说明模型越拿不准；只挑最拿不准的几道题请人写推理过程，作为这个任务的思维链示例。

影响

在八个推理数据集上平均超过人工固定示例的思维链和自洽性采样，说明“给哪几道题写示例”本身值得优化，而且可以用模型的不确定性来决定。

方法

估计不确定性：从训练集随机抽最多1000道题，用现成的少样本思维链提示让模型对每道题采样k=10次。最主要的指标是分歧度：10次里出现了几种不同答案，除以10；也试了答案分布的信息量与熵、数值答案的方差，以及让模型自评信心（效果差）。

挑题并标注：按不确定性从高到低取前n道，n等于该数据集原本的示例数，GSM8K为8道。人工为这几道题写推理过程和答案。

推理：用这组新示例构造提示，按自洽性采样的做法采样40次、取多数答案。

直观上，模型已经稳稳会做的题，写成示例帮助不大；模型摇摆不定的题，恰好暴露了它在这个任务上的薄弱之处，示范一遍最有价值；这是作者借用主动学习时的基本假设，论文也分析了不确定性与准确率之间的关系。这和Auto-CoT自动思维链的思路相反：后者按聚类挑有代表性的题、用模型自己生成推理，免去人工。

结果（八个数据集平均，包括GSM8K、AQuA、CSQA、StrategyQA等）：code-davinci-002上，思维链72.5%、自洽性79.1%、按分歧度选例80.9%、按熵选例81.6%；text-davinci-002上，思维链61.5%、自洽性67.9%、按分歧度选例74.9%。

局限与后续

  • 挑出来的题仍需人工写推理过程；估计不确定性要对上千道题各采样10次，前期成本不低。

    Auto-CoT自动思维链2022.10 · 推理·智能体
    Auto-CoT按聚类选代表性问题并让模型自动生成推理；Active-Prompt按不确定性选题，推理过程由人写。

读懂它需要的概念

上下文学习与提示 零样本与少样本 信息量与熵 解码：贪心、束搜索、温度与top-p 半监督学习与伪标签

本篇术语

  • 主动学习　让模型自己挑出最值得人工标注的样本，用尽量少的标注换取尽量大的提升，常用标准是模型对哪些样本最不确定。
  • 分歧度　同一道题采样k次，得到的不同答案数除以k；越接近1说明模型越拿不准。

怎么学

先读思维链CoT和自洽性采样，了解Auto-CoT自动思维链 → 读原文第2节不确定性指标和表1 → 动手：用一个模型对50道数学题各采样10次，计算分歧度，看看分歧最大的题有什么共同特点。
