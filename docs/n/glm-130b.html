GLM-130B

GLM-130B: An Open Bilingual Pre-trained Model
2022.10论文延伸ICLR 2023Aohan Zeng, Xiao Liu, Zhengxiao Du, Zihan Wang, Hanyu Lai, Ming Ding, Zhuoyi Yang et al. · Tsinghua University / Zhipu AI待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

千亿级模型几乎都是闭源，且训练中遇到的损失尖峰和发散问题鲜有公开经验，普通研究者也跑不起来。

方法

开源一个1300亿参数的中英双语GLM空白填充模型，公开训练稳定性技巧，并通过INT4量化使其能在消费级GPU上推理。

影响

当时少数能与GPT-3 davinci比肩的开放千亿模型，也是后续ChatGLM系列的基础。

方法

GLM-130B是中英双语预训练模型，参数130B，目标是开放一个至少与GPT-3（davinci）相当的百亿级以上模型，并公开如何成功训练它。

论文介绍了训练过程，包括设计选择、保证效率与稳定的训练策略和工程努力，尤其是对损失尖峰和发散这些意外困难的处理。

结果：论文称它在多个流行英文基准上明显优于GPT-3 175B（davinci），而OPT-175B和BLOOM-176B没有这个优势；在中文基准上持续显著优于当时最大的中文模型ERNIE TITAN 3.0 260B。最后，利用它独特的缩放性质，可以在不做事后训练的情况下量化到INT4并几乎不掉点，使4块RTX 3090（24G）或8块RTX 2080 Ti（11G）就能做推理。

局限与后续

  • 以预训练为主，没有对齐和指令微调，直接使用不是对话助手。
    后来针对它的工作　ChatGLM-6B
  • 英中以外语言支持有限，长上下文能力也较弱。
    后来针对它的工作　GLM-4.5

它建立在什么之上

  • 竞争
    GPT-32020.05 · LLM
    目标是开放一个不弱于GPT-3 davinci的模型。
  • 改进
    清源CPM2020.12 · LLM
    26亿参数比GPT-3小了近两个数量级，少样本能力有限。
  • 延续
    GLM空白填充2021.03 · LLM
    在GLM的自回归空白填充框架上放大到130B。
  • 改进
    盘古α2021.04 · LLM
    训练依据的是中文数据，评估主要是自建任务，缺少与同期模型的严格对比。
  • 改进
    ERNIE 3.02021.07 · LLM
    100亿参数的规模明显小于同期GPT-3级别模型，后来的ERNIE 3.0 Titan才扩到更大规模。

后来的相关工作

  • 延续

  • 改进
