拉普拉斯特征选项

A Laplacian Framework for Option Discovery in Reinforcement Learning
2017.03论文延伸ICML 2017Marlos C. Machado, Marc G. Bellemare, Michael Bowling · 阿尔伯塔大学 / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Options时间抽象框架框架给出了时间抽象的形式，但选项（option）本身从哪里来一直是难题：手工设计依赖领域知识，基于任务奖励发现的选项又只对那一个任务有用。

方法

利用表示学习中的原型值函数（PVF，状态转移图拉普拉斯矩阵的特征向量）：每个特征向量e定义一个内在奖励“沿e的方向移动”，称为特征目的（eigenpurpose），对它求最优策略就得到一个选项。这些选项沿状态空间的主方向穿行，与任务奖励无关。

影响

把表示学习与选项发现联系起来，提出的“特征选项”（eigenoptions）成为无任务奖励的选项发现与覆盖式探索的代表思路，后续工作把它扩展到深度RL和后继表示上。

背景

原型值函数（Mahadevan等人）把状态空间看成一张图：状态是节点，能相互转移的状态之间有边；图拉普拉斯矩阵 L = D − A（D是度矩阵，A是邻接矩阵）的前几个特征向量是图上最“平滑”的函数，可以用作价值函数近似的基函数。另一方面，选项发现的已有方法多依赖“瓶颈状态”等启发式。两者长期被分开研究。

方法

对拉普拉斯矩阵的每个特征向量e，定义内在奖励 r^e(s, s') = e^T(φ(s') − φ(s))，其中φ是状态表示（表格情形就是one-hot，于是奖励就是 e[s'] − e[s]）。这个奖励鼓励智能体朝特征向量值增大的方向走。对每个这样的“特征目的”求解最优策略，在内在价值不再能增加的状态终止，就得到一个选项（eigenoption）。

由于不同的特征向量对应不同的频率，低阶特征向量变化缓慢、对应跨越整个状态空间的大尺度移动（例如在四个房间之间穿行），高阶的对应更局部的移动，因此得到的选项天然覆盖多个时间尺度。作者还给出用样本转移构造近似拉普拉斯的办法，以及在Atari上用学到的特征近似的初步实验。

结果

摘要称，由特征目的发现的选项沿状态空间的主方向穿行；它们不考虑环境奖励就被发现，因此对多个任务都有用；不同选项作用于不同时间尺度，有助于探索。论文在传统表格领域和Atari 2600游戏中展示了特征目的的性质。

后来的发展

后续工作把特征选项推广到用后继表示SR近似拉普拉斯特征向量（使其可用于大状态空间与随机环境），并提出“覆盖选项”等以缩短状态图直径为目标的方法；用拉普拉斯表示学习状态嵌入也成为RL表示学习的一条线。

本篇术语

  • 图拉普拉斯矩阵　L = D − A，A是邻接矩阵、D是每个节点度数构成的对角阵；其小特征值对应的特征向量在图上变化最平缓。
  • 原型值函数（PVF）　用状态转移图的拉普拉斯特征向量作为价值函数近似的基函数，不依赖任务奖励。

怎么学

先复习特征分解与Options时间抽象框架；读原文第3节特征目的与特征选项的定义；在四房间网格世界里手算或用numpy求拉普拉斯的前几个特征向量，画出它们并观察对应选项的行为。
