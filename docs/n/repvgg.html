RepVGG重参数化

RepVGG: Making VGG-style ConvNets Great Again
2021.01论文延伸CVPR 2021Xiaohan Ding, Xiangyu Zhang, Ningning Ma, Jungong Han, Guiguang Ding, Jian Sun · 清华大学 / 旷视科技 / 香港科技大学 / 亚伯大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

VGG那样只有3×3卷积和ReLU的直筒网络在GPU上跑得快、省显存、易部署，但不好训练，精度远不如带多分支的ResNet、Inception；而多分支结构推理时要保存中间结果、内存访问多，实际速度慢。

方法

训练时用多分支，推理时用直筒：训练阶段每层是“3×3卷积＋1×1卷积＋恒等”三条分支相加；训练完把三条分支连同各自的批归一化，用线性代数等价地合并成一个3×3卷积，得到纯VGG式的推理网络。

影响

RepVGG是第一个ImageNet top-1超过80%的直筒式模型（作者所知），推理比同精度的ResNet快很多；“结构重参数化”随后被YOLOv7、YOLOv6、MobileOne等大量实时检测和端侧模型采用。

方法

训练时结构：每个块的输出是 y = BN(Conv3×3(x)) + BN(Conv1×1(x)) + BN(x)（恒等分支只在输入输出维度相同时存在），再接ReLU。多分支相当于隐式地集成了很多条不同深度的路径，像ResNet一样好训练。

合并成一个3×3卷积（推理前一次性完成）：

  • 卷积后接BN在推理时是线性变换：BN(W*x) = γ(W*x − μ)/σ + β，可以把γ/σ乘进卷积核、把剩下的常数并进偏置，得到一个带偏置的卷积。
  • 1×1卷积等价于中心有值、四周为0的3×3卷积；恒等映射等价于一个“单位”1×1卷积，也能补零成3×3。
  • 三个3×3卷积作用在同一输入上，相加等于卷积核相加：W' = W₃ + pad(W₁) + pad(I)。

于是整个网络在推理时只剩3×3卷积加ReLU的堆叠，没有分支。这样的结构对GPU的Winograd等3×3卷积加速算法友好，也没有分支带来的额外显存占用。

摘要称RepVGG在ImageNet上超过80% top-1，据作者所知是直筒模型首次做到；在NVIDIA 1080Ti上比ResNet-50快83%、比ResNet-101快101%且精度更高，与EfficientNet、RegNet设计空间等相比也有良好的精度-速度权衡。

后来的发展

结构重参数化成了实时检测器的常用技巧（YOLOv6、YOLOv7的RepConv）；同一作者后续提出了ACNet、DBB、RepLKNet等一系列重参数化工作。量化时重参数化后的权重分布不均，后来也有专门的量化友好版本。

局限与后续

  • 合并后的权重分布范围大，直接做INT8量化精度损失明显。

  • 只有3×3卷积，参数量相对大，在很小的移动端模型上不如深度可分离卷积网络划算。

本篇术语

  • 结构重参数化　训练时用一种便于优化的结构，训练后用数学上等价的变换把它转成另一种便于推理的结构。

怎么学

先确认会把BN折叠进卷积，再读RepVGG第3节的合并推导；用PyTorch建一个三分支块，随机初始化后合并成单个3×3卷积，检查两者对同一输入的输出是否一致。
