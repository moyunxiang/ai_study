MetaICL元训练上下文学习

MetaICL: Learning to Learn In Context
2021.10论文延伸NAACL 2022Sewon Min, Mike Lewis, Luke Zettlemoyer, Hannaneh Hajishirzi · 华盛顿大学 / Meta AI / Allen Institute for AI待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

GPT-3式的上下文学习只靠预训练“碰巧”学会，在中小模型上效果差、对模板敏感；预训练目标（预测下一个词）与“看几个例子做新任务”之间并不匹配。

方法

专门为上下文学习做元训练：在上百个已有NLP任务上，每次抽k个示例拼在前面、让模型预测下一个样本的输出；到测试时，模型只看新任务的几个示例就能做。

影响

说明上下文学习能力可以被显式训练出来，而不只是规模的副产品；与同期T0、FLAN的多任务指令微调互补，也影响了后来关于ICL机理和数据分布的研究。

方法

元训练阶段：从一大批训练任务里随机挑一个任务，从中抽k+1个样本，把前k个的输入和输出依次拼接，最后接上第k+1个的输入，让语言模型只在第k+1个的输出上计算损失。重复这个过程，模型就是在“学习如何从上下文示例里学”，思路接近MAML元学习的元学习，但完全不在测试时更新参数。测试时对新任务做法与GPT-3的少样本提示相同：放k个示例，直接预测。

实验用了142个NLP数据集（分类、问答、自然语言推理、复述等），设计了七种元训练与目标任务的划分。以GPT-2 Large为底座，MetaICL超过不做元训练的上下文学习，也超过“多任务训练后零样本迁移”的做法；当目标任务与元训练任务领域差别大时收益尤其明显，元训练任务越多样越好。它有时能接近在目标任务上完全微调的模型，并超过参数量约8倍的更大模型；与人工写的任务指令结合时效果最好。

局限与后续

  • 要求有大量已标注的多样任务做元训练，模型底座较小；它让模型更会用示例，却没有解释上下文学习在内部是怎样实现的。

读懂它需要的概念

上下文学习与提示 元学习 零样本与少样本 语言模型 指令微调与对话模板

怎么学

先读GPT-3的少样本设定和MAML元学习；读本文元训练的构造方式和七种任务划分的结果；动手：在一个小GPT-2上用十几个分类数据集做MetaICL式训练，测试一个没见过的分类任务。
