OmniParser

OmniParser for Pure Vision Based GUI Agent
2024.08论文延伸Yadong Lu, Jianwei Yang, Yelong Shen, Ahmed Awadallah · Microsoft待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

GPT-4V这类模型只看屏幕截图时，既找不准哪些图标可以点，也不知道每个图标的功能，导致动作落不到正确的位置。

方法

先把截图解析成结构化元素：用检测模型找出可交互区域并编号，再用描述模型给每个元素写功能说明，一并交给大模型。

影响

只用截图（不需要网页源码）就能显著提升GUI智能体的操作准确率，成为许多开源电脑智能体的前置模块。

方法

OmniParser有两个微调的小模型。可交互区域检测模型：作者用流行网页整理出可交互图标检测数据集，训练模型在任意截图上框出按钮、图标等区域。图标描述模型：为每个被框出的图标生成一句功能说明，例如「设置」「提交表单」。

推理时，截图上被检测出的区域都画上编号框（思路类似Set-of-Mark提示），并附上功能描述和OCR文字，这样GPT-4V只需说「点击第12号」，而不必自己估算像素坐标。在ScreenSpot基准上它明显提升了GPT-4V的定位准确率；在Mind2Web和AITW上，只用截图的OmniParser也优于需要额外网页信息的GPT-4V基线。

后来的发展

它被Agent S、Browser Use等系统借鉴，作为「视觉理解加大模型决策」两段式智能体的标准做法。后来的端到端模型如UI-TARS原生GUI智能体把定位能力直接训练进了模型，减少了对这种外挂解析器的依赖。
