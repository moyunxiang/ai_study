Claude Cowork

Cowork: Claude Code for the rest of your work
2026.01系统重要Anthropic待核对
官方公告（存档） ↗Simon Willison：Cowork初体验 ↗PromptArmor：Cowork文件外传漏洞 ↗Cowork插件 ↗在交互版中打开（演化树、学习进度）

问题

Claude Code本质上能做任何靠命令行完成的电脑工作，很多人也拿它干写代码以外的事，但终端界面和“开发者工具”的定位把非程序员挡在门外。

方法

把Claude Code同一套智能体底座装进桌面应用的一个新标签页：用户指定一个文件夹，Claude在隔离的虚拟机里读写其中的文件、规划并逐步完成任务，配合连接器、技能和浏览器扩展。

影响

Anthropic把编码智能体做成面向非程序员的桌面产品，随后的岗位插件被媒体与软件股抛售联系在一起；2026年9月Cowork并入Claude主界面，“交任务而不是聊天”成为默认用法。

背景

Claude Code与终端编码智能体发布后，Anthropic发现开发者很快用它做起了几乎所有事：整理文件、做表格、写报告。Simon Willison的说法是，Claude Code是一个“伪装成开发者工具的通用智能体”——凡是能靠执行代码或终端命令完成的电脑任务它都能做，前提是你会用终端。普通用户能接触到的智能体，如ChatGPT agent，运行在厂商云端的虚拟电脑里，碰不到用户本机的文件；开源的OpenClaw个人智能体能碰到，但要自己安装配置，工具默认直接在主机上执行，风险全由用户承担。

方法

2026年1月12日，Anthropic在macOS版Claude桌面应用里加入Cowork标签页，作为研究预览先开放给Max订阅用户。它与Claude Code“建立在同一套基础上”，区别在于界面和边界：

  • 文件夹授权：用户选一个本机文件夹交给Claude，它只能读写、创建这个文件夹里的文件，看不到别的。Simon Willison观察到路径形如/sessions/<随机名>/mnt/<文件夹>，后来确认是用苹果的虚拟化框架跑一台Linux虚拟机，再把文件夹挂载进去（参见智能体沙箱与权限的沙箱思路）。
  • 计划与执行：给出任务后，Claude先制定计划，再一步步执行（运行命令、写脚本、搜索网页），过程中向用户汇报；用户可以排队多个任务，像给同事留言一样。
  • 能力扩展：沿用已有的连接器（底层是模型上下文协议MCP），内置一批用于生成文档、演示文稿的Agent Skills；配合Claude in Chrome扩展，还能完成需要浏览器操作的任务。
  • 确认机制：重要操作前先征求同意。

官方举的例子：把一堆截图交给它，生成一张费用清单表格；或者把散乱的笔记整理成报告初稿。

结果

这是产品发布，官方没有给出基准分数。Simon Willison实测让它检查46篇近三个月的草稿哪些尚未发表，它对他的网站发起了44次搜索后给出了基本正确的清单。1月16日起向Pro用户开放。1月30日推出插件机制，开源了11个面向销售、法务、财务等岗位的官方插件；2月初多家媒体把软件股、法律软件股的大跌归因于这批插件（软件股“SaaS末日”抛售）。

后来的发展

Cowork把“编码智能体的能力加隔离的执行环境”变成了普通人的产品形态，也让智能体安全从开发者问题变成大众问题：发布两天后PromptArmor演示，藏在文档里的提示注入可以利用虚拟机对Anthropic API的网络白名单，把用户文件上传到攻击者的账号。2026年9月16日，Anthropic宣布Cowork与聊天合并为同一个Claude，用户不再需要先判断任务该去哪个入口。

容易误解的地方

  • Cowork不是新模型，而是Claude Code的智能体底座加图形界面和虚拟机沙箱。
  • 虚拟机隔离只限制它能碰哪些文件和网络，授权文件夹内的删除、覆盖等破坏性操作照样可能发生，官方公告专门提醒了这一点。

局限与后续

  • 提示注入未解决：文档、网页或连接器里的隐藏指令可以改变Claude的计划，发布两天后就有人演示借助对Anthropic API的网络白名单把用户文件外传。

本篇术语

  • 研究预览（research preview）　功能还不成熟时提前开放给部分用户试用，以便收集用法和问题，接口和行为都可能变化。
  • 网络白名单　沙箱只允许访问少数指定域名。它挡住了大部分外传渠道，但白名单里的服务本身（如模型API）也可能被攻击者利用。

怎么学

先读Claude Code与终端编码智能体和Agent Skills。然后读官方公告和Simon Willison的初体验，注意他如何从路径推断出沙箱结构；再读PromptArmor的攻击链，对照智能体的“致命三要素”理解为什么隔离环境仍会泄露数据。动手：把一个只含测试文件的文件夹交给类似的智能体，让它整理文件并生成一张汇总表，观察它申请确认的时机。
