层次短语翻译Hiero

A Hierarchical Phrase-Based Model for Statistical Machine Translation
2005.06论文重要ACL 2005David Chiang · 马里兰大学UMIACS待核对
ACL Anthology ↗期刊扩展版（Computational Linguistics 2007） ↗在交互版中打开（演化树、学习进度）

问题

短语翻译只会把连续词串整块搬运，块与块之间的调序靠一个与内容无关的距离惩罚；汉译英里“X之一”“X的Y”这种要把几大段整体倒过来的结构，它译不对。

方法

让短语里可以挖“空位”：X₁ 的 X₂ → the X₂ that X₁。这样的规则构成一部同步上下文无关文法，直接从词对齐的平行语料里抽出来，不需要任何句法标注，解码就是一次CKY句法分析。

影响

在汉英翻译上比当时最强的短语系统Pharaoh的BLEU相对提高7.5%，把“基于文法的翻译”变成能实用的方法；Hiero式层次短语模型此后与短语模型并列为统计翻译的两大主流。

背景

短语统计机器翻译把翻译单位从词扩大到短语，局部的搭配和调序处理得很好。但Koehn等人自己发现，短语超过3个词就几乎不再带来收益——长短语太稀疏。短语之上，调序只靠一个按跳跃距离打折的模型，它不看短语的内容。

论文用一个例子说明问题。“澳洲 是 与 北韩 有 邦交 的 少数 国家 之一”应译为“Australia is one of the few countries that have diplomatic relations with North Korea”，需要把五个成分整体倒序。Pharaoh能把“与北韩有邦交”内部调对，也能把“少数国家之一”整体译对，却无法把这两大块对调，因为这需要知道“之一”“的”这类词决定了结构，而不只是距离。

另一条路是基于语言学句法的翻译（如Yamada和Knight 2001），但它依赖句法分析器，并把规则限制在句法成分上，而Koehn等人已经证明这种限制会丢掉大量有用的短语。

方法

层次短语。一条规则是源语、目标语两边各一个串，里面可以有对应的空位：

  • X → ⟨与 X₁ 有 X₂, have X₂ with X₁⟩
  • X → ⟨X₁ 的 X₂, the X₂ that X₁⟩（中文定语在左，英文从句在右）
  • X → ⟨X₁ 之一, one of X₁⟩

下标表示两边空位的对应关系，空位里再递归地放入别的规则。所有规则只用一个非终结符X，另加两条“胶水规则”S → ⟨S₁ X₂, S₁ X₂⟩和S → ⟨X₁, X₁⟩，允许像普通短语系统那样把块按顺序拼起来。形式上这是一部同步上下文无关文法，它是概率上下文无关文法PCFG思想在两种语言上的同步推广，但不携带任何语言学标签。

怎么学。先像短语统计机器翻译那样从双向词对齐中抽出所有对齐一致的“初始短语对”；如果一个大短语对里包含一个小短语对，就把小的挖掉换成X，得到一条带空位的规则。为控制规模：初始短语源端最长10个词，规则源端最多5个符号，最多两个空位，且两个空位在源端不能相邻。规则概率用相对频率估计。

打分与解码。每条规则的权重是若干特征（双向翻译概率、双向词汇权重、规则数惩罚等）的对数线性组合，再乘语言模型和词数惩罚，权重用最小错误率训练MERT在开发集上调。解码器是一个带束剪枝的CKY句法分析算法句法分析器：对源句的每个片段，自底向上记下能覆盖它的最好若干个部分译文，英文一侧随之同步组装。

结果

汉译英，翻译模型在FBIS语料（汉语720万词、英语920万词）上训练，三元语言模型用1.55亿词英文新闻；NIST 2002评测集作开发集、2003作测试集。共抽出2400万条规则，按开发集过滤后220万条。BLEU从Pharaoh的0.2676提高到0.2877，绝对提高0.02、相对7.5%，统计显著（p < 0.01），且n越大的n-gram精度提升越多，说明长距离结构确实改善了。再加一个“是否为句法成分”的特征只到0.2881，提升不显著。前面那个例子，系统只漏掉了一个“that”。

后来的发展

2007年Chiang发表了期刊扩展版，此后出现了多个开源实现，层次短语系统在评测中与Moses式短语系统长期并列，Moses本身后来也加入了层次短语解码。它还开启了“先形式上用文法，再逐步加入语言学信息”的路线，催生了一批在目标端用真实句法标签的串到树翻译系统。

2014年起，Seq2Seq和注意力机制用注意力在整个源句上软对齐，长距离调序不再需要显式的文法规则，到谷歌神经机器翻译之后层次短语系统退出主流产品。CKY式的图解码和同步文法仍是理解结构化预测的好例子。

它建立在什么之上

  • 改进
    IBM统计翻译模型1993 · NLP 待核对
    以单词为单位：一个法语词只能来自一个英语词，多个英语词共同对应一个词、习语和短语整体翻译都无法表示。
  • 改进
    噪声信道翻译模型1990.06 · NLP
    一个法语词只能来自一个英语词，多个英语词共同译成一个词（to go → aller）、成语和固定搭配都无法表达。
  • 使用
    GIZA++与对齐模型比较2003 · NLP
    规则从GIZA++双向词对齐对称化后的结果中抽取，与短语模型共用同一套对齐。
  • 改进
    短语统计机器翻译2003.05 · NLP
    短语模型只能整块搬运连续词串、块间调序与内容无关；Hiero允许短语带空位，用规则本身表达“X₁的X₂→the X₂ that X₁”这类大跨度调序。
  • 使用
    最小错误率训练MERT2003.07 · NLP
    规则特征、语言模型和惩罚项的权重用最小错误率训练在NIST 2002开发集上调到BLEU最优。
  • 使用
    CKY句法分析算法1967 · NLP
    解码器就是带束剪枝的CKY图分析，对源句自底向上分析的同时组装目标译文。
  • 延续
    概率上下文无关文法PCFG1979 · NLP
    把上下文无关文法从一种语言推广到两种语言同步生成，但只用一个无标签非终结符，不依赖树库。
  • 改进
    IBM Candide翻译系统1994 · NLP
    训练依赖大规模双语对照语料，词对词的对齐模型难以表达词序大幅变化和短语翻译。

本篇术语

  • 同步上下文无关文法　每条规则同时改写源语和目标语两个串，并规定两边非终结符的对应关系；用它推导一次，就同时得到一个源句的分析和对应的译文。
  • 胶水规则　Hiero里两条特殊规则，允许把若干个已翻译的块按原顺序简单拼接，相当于退化成普通短语翻译。
  • 虚假歧义　许多不同的推导过程得出同一个译文和几乎相同的特征值，浪费搜索空间，也让n-best列表缺少多样性。

怎么学

先读过短语统计机器翻译，复习CKY句法分析算法与动态规划。读原文第1节的“澳洲…之一”例子、第2节（规则与胶水规则）、第3节（规则抽取的定义）和表1。动手：在两三个手工对齐的汉英句对上，先列出所有初始短语对，再按“挖掉子短语换成X”的规则手工生成层次规则，然后用这些规则走一遍CKY推导。
