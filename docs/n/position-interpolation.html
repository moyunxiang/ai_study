位置插值扩上下文

Extending Context Window of Large Language Models via Positional Interpolation
2023.06论文重要Shouyuan Chen, Sherman Wong, Liangjian Chen, Yuandong Tian（田渊栋） · Meta待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LLaMA只能处理2048个token。直接让用RoPE训练的模型读更长的文本，没见过的位置会产生异常巨大的注意力分数，模型直接崩溃；在长文本上继续微调又学得极慢。

方法

不往外推，而往里插：把位置下标按比例缩小，例如想读8192个token就把位置m换成m/4，让所有位置都落在训练时见过的0–2048范围内，再微调约1000步。

影响

几乎零成本地把LLaMA的上下文扩展到32768，代码只改一行，迅速成为开源长上下文模型的标准做法，并直接催生了NTK缩放、YaRN等一系列RoPE扩展方法。

背景

LLaMA在长度2048的序列上训练，位置编码用的是旋转位置编码RoPE：第m个位置的Q、K向量按角度m·θ_i旋转。超过2048的位置在训练中从未出现，它们的旋转角度也就从未见过。

作者发现，直接外推时注意力分数会出现极端大的异常值，困惑度会飙升到1000以上（见困惑度）——模型并不是“慢慢变差”，而是彻底失效。另一条路是直接在更长的文本上微调，但实验中训练超过10000步后，模型能真正用到的上下文只从2048增加到2560。ALiBi线性偏置位置等方法可以外推，但需要从头按它训练，而当时所有主流开源模型都用RoPE。

方法

核心只有一个公式。设原训练长度为L，目标长度为L′。原来位置m的RoPE函数是f(x, m)，现在改为

f′(x, m) = f(x, m·L/L′)

例如L=2048、L′=8192，第6000个token就当作位置1500来旋转。所有位置都被压进[0, L)，只是相邻位置的间隔从1变成了L/L′=1/4。

为什么插值比外推稳。论文把注意力分数写成一组三角函数的组合a(s) = Re Σ h_j·e^{i·s·θ_j}（s是相对距离）。在训练见过的区间里，这个函数平滑、取值正常；一旦跑到区间外，它可以取任意大的值。而在区间内部的非整数点上，它被相邻整数点“夹住”，变化有界。作者推导出插值的误差上界在LLaMA-7B设定下比外推至少小约600倍。

微调。插值后的模型需要少量适应：在Pile数据集上微调1000步（目标8192用32张A100，更长用128张），结构、优化器和训练设施都不用改。

结果

在LLaMA 7B到65B上把上下文扩展到8192、16384和32768。在书籍语料PG-19和数学证明语料Proof-pile上，困惑度随可用上下文变长而持续下降，例如7B模型从2048扩到16384，在这两个数据集上困惑度分别降低0.28和0.5。在“大海捞针”式的口令检索任务中，只微调200步，模型就能在整个新窗口内找到藏在任意位置的5位数口令；直接微调的对照模型训练10000步后有效窗口仍只有2560。代价是原2048窗口内的表现略有下降，例如Proof-pile困惑度上升0.01–0.05。

后来的发展

论文发布前夕，社区开发者kaiokendev在SuperHOT项目中独立提出了同样的插值做法。随后社区开发者bloc97提出“NTK感知”插值：不同频率的维度区别对待，高频维度少压缩、低频维度多压缩。YaRN把这些想法整理成系统的方法，用更少的数据把上下文扩得更长。Code Llama改为调大RoPE的基频，LongRoPE进一步搜索每个维度的最佳缩放。长上下文从此成为模型发布时的常规指标，但“能放进去”不等于“能用好”，迷失在中间很快揭示了这一点。

容易误解的地方

  • 位置插值不是“免训练”的：不微调直接插值也比外推好，但要达到好效果仍需约1000步微调。
  • 把所有维度都均匀压缩，会让高频维度里相邻token的区分度变差，这正是短文本表现略降的原因，也是后来YaRN要区别对待不同频率的动机。

局限与后续

  • 所有频率均匀压缩，近距离位置的分辨率下降，原窗口内的表现有轻微损失。

它建立在什么之上

  • 改进
    旋转位置编码RoPE2021.04 · LLM
    解决RoPE在训练长度之外外推失败的问题：把位置下标压回训练范围，而不是让模型面对没见过的旋转角度。
  • 竞争
    ALiBi线性偏置位置2021.08 · LLM
    ALiBi靠线性距离惩罚天然外推，但必须从头按它训练；位置插值让已有的RoPE模型低成本扩展，在开源界胜出。
  • 改进
    LLaMA2023.02 · LLM
    在LLaMA 7B–65B上把2048的上下文扩展到最长32768。
  • 竞争
    Transformer-XL2019.01 · LLM
    Transformer-XL用循环记忆跨段传递信息，需要改结构；位置插值保留原结构，直接看到完整的长窗口。
  • 改进
    xPos长度外推位置编码2022.12 · LLM
    指数衰减让远处信息本身被压低，外推稳定换来的是长距离依赖变弱；主流开源LLM最终仍用RoPE加位置插值或调整基频来扩上下文，xPos没有被广泛采用。

    Llama 2 Long长上下文续训2023.09 · LLM

读懂它需要的概念

位置编码 自注意力与多头注意力 上下文窗口 困惑度 傅里叶变换与频域 预训练与微调

本篇术语

  • 长度外推　让模型在推理时处理比训练时更长的序列。
  • 口令检索（passkey retrieval）　在一大段无关文字中藏一个随机数字，要求模型找出来，用来测量模型实际能用到多长的上下文。
  • 有效上下文窗口　模型能真正利用其中信息的最大长度，往往小于它在技术上能接受的输入长度。

怎么学

先读旋转位置编码RoPE，搞清楚位置m如何变成旋转角度。读论文第2节（图1与图2很直观）和第3.3节口令检索。动手：用numpy画出一个RoPE维度在0–2048与0–8192上的旋转角度，再画插值后的版本；然后在任意LLaMA系模型上把rope_scaling设为linear、factor=2，比较长文本困惑度。
