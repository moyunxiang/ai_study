SeeAct

GPT-4V(ision) is a Generalist Web Agent, if Grounded
2024.01论文延伸ICML 2024Boyuan Zheng, Boyu Gou, Jihyung Kil, Huan Sun, Yu Su · Ohio State University待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

此前网页智能体多用只吃HTML文本的LLM，而网页是给人看的；GPT-4V能看图，但不清楚它能否在真实网站上完成任务，难点在哪。

方法

提出SeeAct：让GPT-4V先看截图写出文字计划，再把计划“落地”到具体的网页元素上，并系统比较不同的落地方式。

影响

指出多模态模型做网页任务的主要瓶颈是“落地”（把意图对应到具体元素），而非规划本身。

方法

SeeAct把任务分成两步：生成——看截图和任务，用自然语言说出下一步要做什么；落地——把这句话变成具体网页元素和操作。论文在Mind2Web上评测，并开发了一个能在真实网站上运行智能体的工具，增加了在线评测。

关键发现：摘要称如果人工把文字计划准确落地，GPT-4V能在真实网站上完成51.1%的任务，大幅超过只用文本的GPT-4和微调过的FLAN-T5、BLIP-2。但落地很难：Set-of-Mark提示（在截图上给元素加编号）对网页反而效果不好，作者找到的最佳方案同时利用HTML结构和视觉，但与“人工落地”仍有很大差距。

局限与后续

  • 落地能力远不如规划能力，自动落地与人工落地之间差距很大。
