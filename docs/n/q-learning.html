Q-learning

Q-learning
1992论文重要Machine Learning 8, 1992Christopher J. C. H. Watkins, Peter Dayan · 伦敦 / 爱丁堡大学待核对
Springer ↗论文PDF（Dayan主页） ↗Sutton & Barto教材6.5节 ↗在交互版中打开（演化树、学习进度）

问题

TD学习只能评估状态好坏，不直接告诉你该选哪个动作；动态规划能求最优策略却要先知道环境模型。Watkins 1989年提出的Q学习也还没有完整的收敛证明。

方法

给每个“状态+动作”学一个值Q(s,a)，更新目标用下一状态所有动作中最大的Q值；并用一个构造出来的“动作回放过程”证明：表格Q学习在每对状态动作被无限次尝试、学习率适当递减时，以概率1收敛到最优。

影响

它是第一个有收敛保证、无需模型、还能用任意探索策略收集数据（离策略）的最优控制算法，后来的DQN、Double DQN和Rainbow都是它的神经网络版本。

背景

到1989年，时序差分学习解决了“预测”：学会一个状态大概值多少。可知道状态值并不够选动作——要比较各个动作，还得知道每个动作会把你带到哪里，也就是需要环境模型。动态规划与Bellman方程的动态规划恰恰要求模型已知。另一种做法是先学模型再做动态规划，但在模型还很粗糙的早期，按它行事代价很高。

Watkins博士论文提出了不需要模型的Q学习，并给出了收敛性的思路，但证明并不完整。这篇两人合写的技术短文专门补上这一步。

方法

定义动作价值Q*(s,a)：在状态s做动作a、之后一直按最优策略行事能得到的期望折扣回报（见策略与价值函数）。知道了它，最优策略就是每个状态里选Q最大的动作，不再需要模型。

每经历一次转移(s, a, r, s′)，做一次更新（见时序差分与自举）：

Q(s,a) ← Q(s,a) + α[r + γ·max_{a′} Q(s′,a′) − Q(s,a)]

例如Q(s,右) = 0.5，这一步奖励r = 0，γ = 0.9，下一状态最大的Q是1.0，α = 0.1，则新值为0.5 + 0.1×(0 + 0.9×1.0 − 0.5) = 0.54。

关键在max：目标值用的是“下一步做最好的动作”，与实际下一步做了什么无关。所以数据可以由任何探索策略产生（比如10%概率随机走），学到的仍是最优策略的价值——这就是离策略（见on-policy与off-policy）。

收敛定理：奖励有界、Q用表格表示、每对(s,a)被尝试无限次，且第i次更新的学习率满足Σα_i = ∞、Σα_i² < ∞（来自随机梯度下降的随机逼近条件），则Q以概率1收敛到Q*。证明构造了一个人工的“动作回放过程”（ARP）：把过去的经历像一叠卡片一样堆起来，证明当前的Q值恰好是这个人工过程的最优值，而它随卡片增多趋近真实过程。

结果

这是一篇理论短文，没有实验。论文还概述了两个推广：无折扣但最终会进入终止状态的过程，以及每步同时更新多个Q值的情形。论文明确指出，表格之外的表示（函数近似）下Watkins 1989年已发现Q学习可能不收敛。

后来的发展

SARSA把max换成实际执行的下一个动作，得到同策略版本；独立Q学习多智能体和马尔可夫博弈把它搬到多智能体。函数近似下的不稳定由Baird反例与发散问题明确展示，直到DQN用卷积网络、经验回放和目标网络让它在Atari上稳定工作；max带来的过高估计由Double Q-learning和Double DQN修正。

它建立在什么之上

  • 延续
    时序差分学习1988 · RL
    把TD的“用下一步估计修正当前估计”从状态价值推广到动作价值，并用max把预测变成控制。
  • 使用
    随机梯度下降1951 · 基础
    学习率条件Σα=∞、Σα²<∞来自Robbins–Monro随机逼近，是收敛证明的前提。
  • 改进
    动态规划与Bellman方程1957 · RL
    动态规划要求已知转移概率和奖励；Q学习只用采样到的转移逼近Bellman最优方程，不需要模型。
  • 竞争
    Howard策略迭代1960 · RL
    策略迭代先完整评估再改进，需要模型；Q学习把评估和改进揉进每一步的增量更新，属于异步、无模型的动态规划。
  • 改进
    MENACE火柴盒井字棋1963 · RL
    只能用最终胜负强化所有走过的步骤，学得很慢，且只适用于很小的状态空间。
  • 改进
    Rescorla–Wagner条件反射模型1972 · RL
    只描述了预测，没有涉及动作选择，不是完整的强化学习。
  • 延续
    Watkins博士论文1989 · RL
    Q学习在1989年博士论文中提出；这篇给出了论文里只有轮廓的严格收敛证明。

读懂它需要的概念

马尔可夫决策过程 Bellman方程 策略与价值函数 时序差分与自举 on-policy与off-policy 探索与利用

本篇术语

  • 动作价值Q(s,a)　在状态s先做动作a、之后按某策略行事所能得到的期望折扣回报。Q*指最优策略下的动作价值。
  • 动作回放过程（ARP）　证明中构造的人工马尔可夫过程：把已发生的每次经历当作一张卡片叠起来，按学习率随机抽取，以此证明Q值逼近最优。

怎么学

先懂Bellman方程和时序差分与自举。读原文第2节（问题与算法）和第3节的证明思路，附录可以跳过。动手：在FrozenLake或悬崖行走网格上写表格Q学习，用ε-贪心探索，再与SARSA对比路线差异（Sutton & Barto例6.6）。
