DPO真比PPO好吗

Is DPO Superior to PPO for LLM Alignment? A Comprehensive Study
2024.04论文延伸ICML 2024Shusheng Xu, Wei Fu, Jiaxuan Gao, Wenjie Ye, Weilin Liu, Zhiyu Mei, Guangju Wang, Chao Yu, Yi Wu · 清华大学、上海期智研究院待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT、Claude等产品用的是先训练奖励模型再用PPO的方法，但学术基准上的最好成绩往往来自DPO这类无奖励模型的方法。DPO真的更好吗？PPO为什么在这些基准上表现差？

方法

从理论和实验两方面分析DPO的算法性质，指出它的根本局限；再全面检查PPO，找出让PPO在LLM微调中发挥最佳的关键因素；最后在对话到代码竞赛的一组RLHF测试上公平比较两者。

影响

给出“调好的PPO在所有测试中都超过DPO等方法”的系统证据，并在困难的代码竞赛上取得当时最好成绩，扭转了“DPO足以替代RLHF”的流行看法，是2024年偏好对齐方法比较中常被引用的结果。

方法

背景：DPO直接偏好优化把RLHF的目标改写成直接在偏好对上做分类式损失，省掉了奖励模型和PPO，实现简单，在AlpacaEval、MT-bench等学术基准上表现突出。产业界的旗舰产品却仍沿用InstructGPT与RLHF的奖励模型加PPO流程。

DPO的局限（理论与实验）：作者论证，DPO的解可能偏向在偏好数据分布之外的回答：如果某类回答在偏好数据里从未出现，DPO的损失对它没有约束，模型可能给它分配很高的概率，而PPO在线采样、由奖励模型对新回答打分，不存在这个盲区。实验中，当偏好数据与模型自身输出分布差异较大时，DPO的表现明显下降；在模型自己生成的数据上迭代做DPO可以部分缓解。

PPO的关键因素：作者检查了PPO在LLM上的实现细节，发现以下几点对效果影响最大：

  • 优势归一化：对每批的优势做标准化；
  • 大批量训练：用足够大的批量，减少梯度噪声；
  • 参考模型的指数滑动平均更新：让KL约束的参考模型缓慢跟随策略，而不是固定不变。

比较：在对话（如HH-RLHF、SafeRLHF）到代码生成（APPS、CodeContests）的一系列RLHF测试上，摘要称调好的PPO在所有情况下都超过其他对齐方法，并在困难的代码竞赛上取得最好成绩。

后来的发展

这项研究常与“在线采样数据优于离线数据”的一系列工作一起被引用，推动了开源社区重新重视在线RL，也影响了后来推理模型普遍采用在线策略梯度方法。

局限与后续

  • PPO能赢依赖大量工程调优和更大的计算开销，结论更多说明“调好的PPO上限更高”，并没有降低PPO的使用门槛。

  • 延续
    InstructGPT与RLHF2022.03 · LLM

  • 竞争

    从理论和实验上指出DPO会对偏好数据之外的回答失去约束，在公平比较中不如调好的PPO。
  • 使用
    APPS2021.05 · 数据·评测
    在APPS和CodeContests等代码竞赛测试上比较对齐方法，PPO取得最好成绩。

读懂它需要的概念

人类反馈强化学习 策略梯度 分布偏移 KL散度 批大小、步数与轮数

本篇术语

  • 分布外回答　在偏好训练数据中从没出现过的那类回答，离线方法的损失对它们没有直接约束。
  • 优势归一化　把一批样本的优势值减去均值、除以标准差，使不同批次的更新幅度更稳定。
