消息传递神经网络MPNN

Neural Message Passing for Quantum Chemistry
2017.04论文重要ICML 2017Justin Gilmer, Samuel S. Schoenholz, Patrick F. Riley, Oriol Vinyals, George E. Dahl · Google Brain / Google / DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图神经网络的变体五花八门（谱方法、图卷积、门控图网络……），彼此关系不清；化学分子性质预测仍靠人工设计的分子指纹特征。

方法

把这些模型统一成一个模板：每个节点反复收集邻居发来的“消息”并更新自己，最后把所有节点汇总成整图的表示。在这个框架内挑出最好的组合去预测分子量子性质。

影响

“消息传递”从此成为图神经网络的通用语言；在QM9上11/13个量子性质达到化学精度，推动了用图网络替代昂贵量子化学计算的路线。

背景

分子天然是一张图：原子是节点，化学键是边（见图、树与搜索）。要预测分子的能量、偶极矩等性质，传统做法是密度泛函理论（DFT）计算，一个分子可能要算上几小时；机器学习方法则大多依赖人工设计的特征，比如把分子的局部结构编码成固定长度的指纹向量。

图上的神经网络在2017年前已出现多支：图神经网络GNN用迭代传播直到收敛，谱域图卷积在图拉普拉斯的频域上定义卷积，图卷积网络把它简化为邻居特征的归一化加权和，还有用GRU更新节点状态的门控图网络。它们看起来很不一样，作者认为本质上是同一件事。

方法

统一框架（见图神经网络与消息传递）。每个节点v有隐状态h_v，边vw有特征e_vw。消息传递阶段跑T步，每一步：

m_v = Σ_{w∈N(v)} M(h_v, h_w, e_vw)（收集所有邻居的消息并求和）

h_v ← U(h_v, m_v)（用消息更新自己）

T步后进入读出阶段：ŷ = R({h_v})，把所有节点的最终状态汇成整图的预测。R必须与节点顺序无关（求和、或更复杂的集合函数）。选择不同的消息函数M、更新函数U和读出R，就能得到GCN、门控图网络等已有模型。

本文选出的组合。消息函数用“边网络”：把边特征（键的类型、原子间距离）输入一个小网络，输出一个矩阵A(e_vw)，消息就是A(e_vw)·h_w，于是不同距离、不同键型传递的信息不同。更新函数用GRU（来自RNN编码器-解码器与GRU），读出用set2set（一种带注意力的集合汇总模型）。把氢原子也作为显式节点、给每个目标单独训练一个模型都明显有帮助，单独训练在某些目标上误差最多低40%。

远程信息。消息每一步只走一条边，T步之外的原子互相看不到。作者试了两种补救：给所有不相连的原子对加一种“虚拟边”，或者加一个与所有节点相连的“主节点”。

结果

QM9数据集约13万个小有机分子，每个有13个由DFT算出的量子性质。最好的MPNN在全部13个目标上都超过此前最佳方法，其中11个达到化学界公认的“化学精度”；只用分子拓扑、不给三维坐标时也有5个达到。训练好的网络推理速度比DFT计算快约30万倍。

后来的发展

此后几乎所有图神经网络论文都用“消息、聚合、更新、读出”来描述自己的模型。图注意力网络GAT把求和换成注意力加权，GIN与GNN表达能力用这一框架证明了图网络区分能力的上限。在科学计算中，GraphCast与AI天气预报的天气预报、GNoME材料发现的材料发现都是编码—消息传递—解码的结构。

局限与后续

  • 消息传递网络区分不同图结构的能力有上限，有些结构不同的分子会得到完全相同的表示；当时没有分析这个上限在哪里。
    后来针对它的工作　GIN与GNN表达能力
  • 每步只传一跳，远距离原子之间的相互作用要靠很多步或虚拟边、主节点等补丁，层数一多又会让节点表示趋同。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只在QM9这类小有机分子上验证，标签本身是DFT近似值；作者也认为下一步应转向更大分子和更精确的标签。

读懂它需要的概念

图、树与搜索 图神经网络与消息传递 多层感知机 门控机制 嵌入向量

本篇术语

  • DFT（密度泛函理论）　量子化学中计算分子电子结构的常用近似方法，结果较准但计算很慢，QM9的标签就是用它算出来的。
  • 化学精度　化学界约定的误差阈值，误差低于它的预测在实际化学研究中才算有用。
  • 读出函数　把所有节点的向量合成一个图级向量的函数，必须对节点的排列顺序不敏感，最简单的是求和。

怎么学

先补图、树与搜索和图神经网络与消息传递，理解GRU门控（门控机制）。读原文第2节的公式(1)–(3)和第2节列举的各已有模型如何映射到框架里。动手：用PyTorch Geometric在QM9上训练一个只用求和聚合的小MPNN，再把边特征接入消息函数，比较误差变化。
