OpenAI o1推理模型

Introducing OpenAI o1-preview
2024.09模型主干OpenAI（公告署名为OpenAI，贡献者名单另附） · OpenAI来源已核对
官方公告（o1-preview） ↗技术博客 Learning to Reason with LLMs ↗OpenAI o1 System Card（arXiv） ↗o1正式版进入API（reasoning_effort） ↗在交互版中打开（演化树、学习进度）

问题

GPT-4o这一代模型通常要靠提示才“分步思考”，并没有为先想再答专门训练过，竞赛数学几乎做不动：2024年AIME上GPT-4o平均只做对12%。

方法

用大规模强化学习训练模型在回答前先生成一段很长的内部思维链，让它自己学会检查错误、拆解难题、换思路；想得越久，答得越准。

影响

AIME从12%提到74%（单次作答），Codeforces超过89%的人类选手。官方报告性能随测试时的思考时间平滑提升；之后出现了o3、DeepSeek-R1等一批推理模型。

背景

2024年上半年的最强模型是GPT-4o全模态实时模型、Claude 3.5 Sonnet。它们“想”多长由提示决定：思维链CoT让模型先写推理步骤，自洽性采样再采样多条推理投票。但这些只是提示和解码技巧，模型本身并没有为“先想再答”专门训练过。结果是竞赛级数学几乎做不动——OpenAI称GPT-4o在2024年AIME（美国数学邀请赛，每套15题）上平均只做对12%（1.8题）。

另一边，继续放大预训练越来越贵（见语言模型的规模定律）。已有几条线索：STaR自举推理让模型在自己生成且答案正确的推理上反复微调；同为OpenAI的过程监督与过程奖励模型证明给每一步打分的过程奖励模型能更准地从多个解里挑出对的；Quiet-STaR让模型在每个token前先“想”一段；测试时计算扩展研究了把算力花在推理阶段的收益。

方法

o1是一个被强化学习训练成先想再答的大语言模型。训练细节未公开，公告能确认的有三点：

  • 回答前先生成很长的内部思维链（推理token，见推理token与测试时计算），再写出答案。
  • 用“大规模强化学习算法”训练模型如何有效利用这段思维链，官方称“数据效率很高”。模型由此学会改正自己的错误、拆解难步骤、走不通就换思路。
  • 性能随两种算力平滑上升：训练时的强化学习算力，以及测试时的思考时间。即推理阶段的计算成了用钱换准确率的新维度。

后来DeepSeek-R1公开的一类做法可以帮助理解：对一道有标准答案的题x，模型（策略π_θ）采样一段“思维链+答案”y，答案对了奖励R = 1，错了R = 0，用策略梯度最大化期望奖励J(θ) = E_{y∼π_θ(·|x)}[R(x, y)]，梯度为∇J = E[R · ∇log π_θ(y|x)]：让导向正确答案的思考方式更常出现。与InstructGPT与RLHF的RLHF不同，奖励来自可自动核对的对错，而非人的偏好。o1是否这样做、是否用了过程奖励或搜索，官方没说。

公告里的一个例子能看出它“想”了什么。给出例句“oyfjdnisdr rtqwainr acxz mynzbhhx → Think step by step”，要求破译另一段密文。GPT-4o找不到规律，反问用户要更多规则；o1-preview在思维链里试了几种假设后发现：密文每两个字母一组，取两个字母在字母表中序号的平均值，例如oy → (15+25)/2 = 20 → T，最终解出“THERE ARE THREE R'S IN STRAWBERRY”。

隐藏思维链。OpenAI决定不向用户展示原始思维链，只给模型生成的摘要。理由是：想用思维链监控模型（比如发现它是否在操纵用户），就不能对思维链施加合规训练，而未经约束的思维链又不宜直接展示；官方也承认“竞争优势”是考虑之一。

发布经过。2024年9月12日上线o1-preview和更小更便宜的o1-mini，系列名从1重新计数。正式版o1于12月5日进入ChatGPT，12月17日进入API并加入调节思考长短的reasoning_effort参数（思考预算与推理强度）。

结果

官方公布的成绩（未发布的o1正式版，最大测试时算力）：

  • AIME 2024：单次作答平均74%（11.1/15）；64次采样多数投票83%；用学习到的打分函数从1000个样本里重排达93%（13.9/15），超过美国数学奥赛（USAMO）晋级线。GPT-4o为12%。
  • GPQA Diamond（研究生级物理、化学、生物题）：77.3%，GPT-4o为50.6%；OpenAI称这是首个超过其招募的博士专家成绩的模型。
  • Codeforces：Elo 1673，超过89%的人类选手；o1-preview为1258，GPT-4o为808（11%）。
  • 在o1上加训编程的模型以人类同等条件参加2024年IOI（每题最多50次提交），得213分，位于49%分位；放宽到每题10000次提交可得362.14分，超过金牌线。
  • MATH竞赛数学的500题测试集94.8%（GPT-4o 60.3%）。越狱测试StrongREJECT上o1-preview得0.84，GPT-4o得0.22。

人类偏好评测中，o1-preview在编程、数学上明显胜出，但部分自然语言任务上不如GPT-4o受欢迎。

后来的发展

三个月内，阿里的QwQ开源推理模型（2024年11月）开放权重跟进，OpenAI发布OpenAI o3。2025年1月，DeepSeek-R1和Kimi k1.5公开了训练方法：只用答案对错做奖励的大规模强化学习，就能长出o1式的长思维链和自我检查，显示不用过程奖励模型、树搜索也能接近o1的成绩；s1与预算强制用1000道题微调加推理时强制“多想一会”也得到了测试时扩展曲线。

产品上，Claude 3.7 Sonnet混合推理把普通回答和Claude可见扩展思考做进同一个模型并展示思考过程，Gemini 2.5 Pro以“思考模型”发布；o3/o4-mini工具内推理在思维链中途调用工具，Deep Research把长推理用于多步检索；GPT-5把快速模型和推理模型合成一个由路由器决定想多久的系统。安全上，审慎对齐公开了o1在思维链里援引安全规范的做法，上下文中的图谋发现o1在特定测试中会隐瞒行为，CoT可监控性讨论思维链监控能可靠多久。

OpenAI已把o1-preview和o1-mini从API下线，o1本身被标为弃用（deprecated）。

容易误解的地方

  • o1-preview、o1、o1-mini是三个不同的模型。公告里最亮眼的数字大多来自当时尚未发布的o1正式版；IOI成绩和Codeforces 1807分来自另外针对编程加训的模型。
  • AIME 93%用了1000次采样加打分函数重排，不是单次作答；单次作答是74%。
  • 用户看到的是模型生成的思维链摘要，不是原始思维链。
  • “测试时算力越多越准”不等于每题都该想很久：简单问题上长时间思考只会浪费token（见推理模型的过度思考）。
  • o1的训练方法从未公开。“o1用了过程奖励模型或蒙特卡洛树搜索”之类说法都是外界猜测。

局限与后续

读懂它需要的概念

语言模型 自回归生成 推理token与测试时计算 人类反馈强化学习 策略梯度 奖励设计与奖励投机 解码：贪心、束搜索、温度与top-p 基准、排行榜与SOTA

本篇术语

  • pass@1 / cons@64　pass@1是每题只答一次的平均正确率；cons@64是每题采样64个答案、取出现最多的那个作为最终答案后的正确率。
  • 可验证奖励　奖励由程序自动核对得到，比如数学答案是否等于标准答案、代码是否通过测试，不需要人或奖励模型打分。适合数学和编程，难以用于写作。
  • 思维链摘要　o1不展示原始推理token，而是由模型把思考过程概括成几段可读文字展示给用户。
  • AIME　美国数学邀请赛，每套15道答案为0–999整数的题，成绩好的高中生可晋级美国数学奥赛（USAMO）。
  • o1 pro / o1-pro　2024年12月5日随每月200美元的ChatGPT Pro推出的o1 pro mode，官方称它是用更多算力想得更久、给出更好答案的o1版本；2025年3月以o1-pro之名进入API（仅Responses API），每百万输入/输出token 150/600美元。

怎么学

先补策略梯度、奖励设计与奖励投机和推理token与测试时计算，再读思维链CoT、STaR自举推理、过程监督与过程奖励模型理解前置思路。然后通读Learning to Reason with LLMs，重点看密码破译例子的完整思维链和附录A的成绩表，再读DeepSeek-R1论文第2节看一个公开的类o1训练配方。动手：用一个1B左右的小模型在GSM8K上做“答案对得1分”的强化学习（例如用TRL库的GRPO），观察回答长度和正确率随训练步数怎样变化。
