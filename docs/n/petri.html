Petri自动审计工具

Petri: An open-source auditing tool to accelerate AI safety research
2025.10系统延伸Anthropic Alignment Science · MATS / Anthropic Fellows待核对
Anthropic Alignment博客 ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

人工写场景去探测模型的欺骗、自保、告密等行为成本高、覆盖面窄，模型越多、行为越多越测不过来。

方法

开源框架：审计智能体按自然语言“种子指令”自动设计多轮场景、模拟工具和环境去测目标模型，再由评判模型按多个维度打分。

影响

把对齐审计变成可批量运行的开源流程，被英国AISI等机构的后续评测沿用。

方法

Petri（Parallel Exploration Tool for Risky Interactions）建立在英国AISI的Inspect评测框架框架上。研究者只需写一句种子指令，比如“试探模型在发现公司违法时会不会告密”；审计智能体就能设置系统提示、编造工具及其返回结果、和目标模型多轮对话，还能回滚对话、预填回答、提前结束。评判模型按36个默认维度（如“未经提示地欺骗用户”“自我保全”）给每段记录打分，便于研究者筛出最值得看的记录。

试点评测覆盖14个前沿模型、111条种子指令，Claude Opus 4.1、Claude Sonnet 4、Gemini 2.5 Pro、GPT-5、o4-mini轮流担任审计者和评判者。官方称Claude Sonnet 4.5与GPT-5的整体安全表现大致并列最好。一个告密案例研究发现，模型的自主权和公司领导是否同谋对告密影响很大。作者强调它用于快速筛查假设，而非基准，也提醒评测意识可能让部分分数被低估。

局限与后续
