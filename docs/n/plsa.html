概率潜在语义分析pLSA

Probabilistic Latent Semantic Analysis
1999.07论文延伸SIGIR 1999 / UAI 1999Thomas Hofmann · Brown University / UC Berkeley待核对
arXiv（UAI版） ↗在交互版中打开（演化树、学习进度）

问题

潜在语义分析LSA用线性代数把文档和词降维，但没有概率解释，也不能严格处理词的多义和同义。

方法

引入隐含的主题变量z：文档先按概率选主题，主题再按概率生成词，用EM算法估计这些概率。

影响

给文档建模提供了概率框架，LDA主题模型就是在它上面加先验得到的。

方法

模型假设一个文档d里的每个词w是这样生成的：先以P(z|d)选一个隐含主题z，再以P(w|z)从这个主题的词分布里选一个词。于是文档与词的联合概率是P(d,w) = P(d)·Σ_z P(w|z)P(z|d)。

训练用EM算法：E步算每个词出现背后各个主题的后验概率，M步用这些后验重新估计P(w|z)和P(z|d)。结果是一组主题，每个主题是一份词的概率分布（例如一个主题里“球队、比赛、进球”概率高），每个文档是这些主题的混合。

arXiv页面题目为Probabilistic Latent Semantic Analysis，作者Hofmann，是UAI会议论文的转载。与LSA相比，它的概率解释清楚，能比较好地处理多义词，并且在检索实验中表现更好。

局限与后续

  • 参数数量随训练文档数线性增长，容易过拟合，也不能给从未见过的新文档赋予主题分布。
