bAbI

Towards AI-Complete Question Answering: A Set of Prerequisite Toy Tasks
2015.02数据集延伸Jason Weston, Antoine Bordes, Sumit Chopra, Alexander M. Rush, Bart van Merriënboer, Armand Joulin, Tomas Mikolov · Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

研究者想造能对话和推理的智能体，但真实语言数据太复杂，看不出系统到底缺哪种能力。

方法

设计一组人工合成的小任务，每个只考一种基本技能（串联事实、简单归纳、演绎等），用问答形式测试。

影响

它成为记忆网络及后续注意力模型的标准玩具基准，也让「用可控任务诊断模型缺陷」成为常见做法。

方法

bAbI由Facebook AI Research的Weston等人在2015年2月提出。论文主张用一组代理任务来评估阅读理解：每个任务通过问答检验一种能力，例如把多个事实串联起来回答，简单的归纳，演绎等，它们被设计为任何想与人对话的系统的「先决条件」。论文认为许多现有学习系统还解决不了这些任务，所以目的是把任务分类为技能集，让研究者找出自己系统的不足并改正。

作者还扩展和改进了不久前提出的记忆网络，证明它能解决其中一部分、但不是全部任务。后来的端到端记忆网络、神经图灵机和Transformer家族都把bAbI当作检验模型能否做多步推理的试金石。

因为任务是合成的、语言很规整，高分并不意味着真实语言理解；该基准在大模型时代已基本被解决，只用作诊断。

局限与后续

  • 任务是模板生成的合成数据，语言简单规整，模型可以靠记住模板得高分，不能代表真实阅读理解。
    后来针对它的工作　SQuAD GLUE / SuperGLUE
  • 只考察有限的几种推理技能，对常识和世界知识没有涉及。
    后来针对它的工作　HellaSwag

    同期考察神经网络推理的数据集，bAbI是合成的玩具文本推理，AQuA-RAT是真实风格的代数题并给出人写推理过程。
  • 改进
    HellaSwag2019.05 · 数据·评测
    只考察有限的几种推理技能，对常识和世界知识没有涉及。
  • 延续
    ALFWorld文字家务环境2020.10 · 数据·评测
    延续用可控的文字环境检验推理与规划能力的思路，把对象从短故事换成可交互的家务世界。
  • 使用
    BABILong长文推理2024.06 · 数据·评测
    直接复用bAbI的20类推理任务作为插入长文的“针”。
