d1: Scaling Reasoning in Diffusion Large Language Models via Reinforcement Learning
2025.04论文延伸Siyan Zhao, Devaansh Gupta, Qinqing Zheng, Aditya Grover · UCLA / Meta AI待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

推理模型靠在线强化学习变强，但GRPO这类算法要算整条回答的对数概率，扩散语言模型没有逐词的链式分解，算不出来。

方法

先用s1K做掩码SFT，再提出diffu-GRPO：用一次前向的近似估计每个词的对数概率，并随机掩去提示词当作正则。

影响

第一次把策略梯度强化学习用到掩码扩散大模型上，开启了dLLM强化学习后训练这条线，此后的coupled-GRPO、wd1、SPG等方法都接着它做。

方法

DeepSeek-R1之后，用在线强化学习（GRPO）训练推理成了标准做法，但这些方法都默认模型是从左到右写的：一条回答的概率等于每个词条件概率的乘积。LLaDA大语言扩散模型这类掩码扩散模型没有这种分解，原论文要用约128次蒙特卡洛采样才能估计一次似然，放进RL训练里代价太高。

d1分两步。第一步是掩码SFT：在s1与预算强制的s1K推理数据上，用扩散模型自己的掩码目标做监督微调。第二步是diffu-GRPO：序列的对数概率用平均场近似，直接把各位置的对数概率相加；每个词的对数概率只做一次前向——把回答全部掩住、提示词按15%的概率随机掩去，一步去噪得到估计。每次梯度更新换一种提示掩码，相当于数据增强，于是同一批采样可以多做几次更新，减少昂贵的在线生成。

以LLaDA-8B-Instruct为底座、生成长度256时，GSM8K从76.7升到81.1，MATH500从32.4到38.6，Countdown从19.5到32.0，4×4数独从6.7到16.7。
