Graph U-Net与gPool

Graph U-Nets
2019.05论文延伸ICML 2019Hongyang Gao, Shuiwang Ji · 德州农工大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图像上的U-Net靠池化和上采样做编码—解码，但图没有规则的网格，池化和上采样都没有自然的定义。

方法

提出图池化gPool：用一个可训练的投影向量给每个节点打分，只保留得分最高的k个节点构成小图；对应的gUnpool按记下的位置把节点放回原图。用它们搭出图上的U-Net。

影响

gPool就是PyG里的TopKPooling，是“按分数选节点”这一类图池化方法的起点，后续的SAGPool等都在此基础上改进。

方法

gPool层：设节点特征矩阵为X（N个节点），可训练向量p。每个节点的得分 y = Xp/‖p‖，取得分最高的k个节点下标idx，新图的特征为 X' = X[idx] ⊙ tanh(y[idx])（用得分做门控，使p能通过梯度学习），邻接矩阵取对应的子矩阵 A' = A[idx, idx]。这样图被缩小为k个节点，相当于图像上的下采样。

gUnpool层是逆操作：新建一个N个节点的零矩阵，把小图的节点特征按记下的idx放回原位置，图结构恢复为原来的邻接矩阵。

Graph U-Net由若干“GCN + gPool”的编码块和对应的“gUnpool + GCN”解码块组成，编码与解码之间有跳跃连接；为了缓解池化后小图连通性变差，作者先对邻接矩阵取平方（连接二跳邻居）再池化。摘要提到实验在节点分类和图分类任务上进行，表现优于以往模型。

局限与后续

  • 打分只看节点自身特征，不考虑图结构，可能保留一堆互不相连的节点。

怎么学

先读U-Net和DiffPool可微图池化；读论文第3节gPool与gUnpool的公式；动手在PyG里用TopKPooling搭一个图分类网络，在PROTEINS数据集上测试。
