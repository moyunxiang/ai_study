LLaDA-MoE

LLaDA-MoE: A Sparse MoE Diffusion Language Model
2025.09论文延伸arXiv 2025Fengqi Zhu, Zebin You, Yipeng Xing 等（共26位） · 中国人民大学 / 蚂蚁集团待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

扩散语言模型每步都要对整段做完整前向，稠密模型的计算开销大。

方法

把稀疏混合专家引入掩码扩散语言模型：7B总参数，推理时只激活1.4B，并从零训练约20T token。

影响

证明MoE的省算力优势在扩散模型中同样成立，超过LLaDA、LLaDA 1.5和Dream。

方法

LLaDA-MoE是第一个从零预训练的MoE扩散语言模型，在大约20T token上训练。结构上沿用LLaDA大语言扩散模型的掩码扩散目标，但把前馈层换成稀疏门控MoE层：总参数7B，每次推理只激活1.4B。

摘要称它在多个基准上超过之前的扩散语言模型LLaDA、LLaDA 1.5和Dream 7B，经指令微调的LLaDA-MoE-7B-A1B-Instruct在知识理解、代码、数学推理、智能体和对齐任务上，可与Qwen2.5-3B-Instruct相当，而激活参数更少。作者的结论是：MoE的优势在掩码扩散训练目标下依然成立。

局限与后续

  • 扩散模型每个去噪步都要处理整段，MoE只减少了每次前向的算力，并没有减少去噪步数。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只与小规模的Qwen2.5-3B对比，与更强自回归模型的差距未说明。
    本站还没有记录针对它的后续工作（不代表没有人解决）

    离散扩散语言模型SEDD2023.10 · LLM

  • 延续
    LLaDA大语言扩散模型2025.02 · LLM
    在LLaDA的掩码扩散基础上换用稀疏专家结构。
  • 改进
    Dream 7B2025.08 · LLM
    仍是7B规模，与同规模顶尖自回归模型的全面比较并不是摘要的主张，只称超过其他扩散模型。
