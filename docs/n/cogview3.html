CogView3接力扩散

CogView3: Finer and Faster Text-to-Image Generation via Relay Diffusion
2024.03论文延伸ECCV 2024Wendi Zheng, Jiayan Teng, Zhuoyi Yang, Weihan Wang, Jidong Chen, Xiaotao Gu, Yuxiao Dong, Ming Ding, Jie Tang · 清华大学 / 智谱AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

单阶段文生图扩散模型直接在高分辨率上生成，计算量大，细节也不够精细；传统级联方案的超分阶段要从纯噪声重新开始，浪费了低分辨率结果中的信息。

方法

级联加“接力扩散”：先生成低分辨率图，再把它上采样后加上适量噪声，让超分阶段从这个中间状态接着去噪，而不是从纯噪声开始。

影响

论文称是第一个把接力扩散用到文生图上的模型，人类评测中比SDXL高77.0%、推理时间约为其一半，蒸馏版约为其1/10，展示了“低分辨率先定构图、高分辨率只补细节”的省算力路线。

方法

CogView3分两级：

  • 基础阶段：一个在潜空间工作的文生图扩散模型，先生成512×512左右的图像。文本由大型语言模型编码器编码，训练数据的描述经过重写，变得更详细。
  • 接力超分阶段：把低分辨率结果上采样到目标分辨率（如1024或2048），但不是像级联扩散那样把它当条件、从纯噪声开始超分，而是直接对上采样图加上中等强度的噪声，从扩散过程的中间时刻开始去噪。这就是接力扩散（Relay Diffusion，由同一团队早先提出）：低分辨率图提供了全局结构，高分辨率阶段只需补细节，所需步数少得多。为了让加噪方式与“上采样造成的模糊”相匹配，接力阶段使用模糊与噪声相结合的退化过程。

论文还给出蒸馏版本，进一步压缩步数。实验报告：CogView3在人类评测中比当时最好的开源模型SDXL高出77.0%，推理时间只需约一半；蒸馏版质量相当，推理时间约为SDXL的1/10。

局限与后续

  • 两级流水线比单阶段模型复杂，基础阶段的构图错误无法在超分阶段修正。

  • 仍是U-Net式结构，后来同系列转向DiT并换用更强的语言模型文本编码。

读懂它需要的概念

扩散：前向加噪与反向去噪 噪声调度与采样步数 潜空间 知识蒸馏

本篇术语

  • 接力扩散　高分辨率阶段不从纯噪声开始，而是把低分辨率结果上采样后加适量噪声，从扩散过程的中途接着去噪。

怎么学

先读级联扩散与SDEdit的“从中间加噪开始”思路 → 读本文第3节接力超分 → 对比从纯噪声与从中间时刻开始的超分步数和效果。
