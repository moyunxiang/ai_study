线性TD收敛性分析

An Analysis of Temporal-Difference Learning with Function Approximation
1997论文延伸IEEE Transactions on Automatic Control 1997John N. Tsitsiklis, Benjamin Van Roy · MIT待核对
IEEE TAC ↗在交互版中打开（演化树、学习进度）

问题

TD学习与函数近似结合是否收敛，当时只有零散的实验证据，缺少严格结论。

方法

证明：在同策略采样、线性函数近似的条件下，TD(λ)以概率1收敛，并给出极限点与最佳线性近似之间的误差界。

影响

给出线性TD收敛的第一个完整证明，同时也指明了成立的条件，反面说明了Baird反例为何出现。

方法

论文分析线性函数近似下的TD(λ)：价值被写成特征的线性组合，用一个由同策略平稳分布加权的范数衡量误差。他们证明，当按照该策略自己的分布采样时，更新对应的算子是这个范数下的压缩，因此TD(λ)以概率1收敛到唯一的不动点，且这个不动点与最佳线性近似的误差有明确的上界。

同样的论证在离策略下不成立，这正是Baird反例与发散问题发散的原因。

后来的发展

梯度TD（GTD/TDC）为离策略线性TD找到收敛版本；致命三元组把函数近似、自举、离策略三者合在一起来讨论。

局限与后续

  • 只对线性函数近似、同策略成立，非线性神经网络没有保证。
    后来针对它的工作　DQN
  • 离策略时不再收敛，需要新的目标函数。
    后来针对它的工作　梯度TD（GTD/TDC）
