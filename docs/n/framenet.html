FrameNet

问题

WordNet只告诉你词和词之间的同义、上下位关系，却不说一个词在句子里和哪些成分搭配、各自扮演什么角色。

方法

以Fillmore的框架语义学为基础，人工定义「框架」（一类事件及其参与者），再用真实例句标注每个词怎样填充框架里的角色。

影响

给语义角色标注提供了第一个按语义而非句法组织的词汇资源，后来的SRL研究和PropBank都以它为参照。

方法

FrameNet的单位是框架：对一类事件、关系或物体及其参与者的描述。例如烹饪事件对应框架 Apply_heat，里面有 Cook（厨师）、Food（食物）、Container（容器）、Heating_instrument（热源）等框架元素。能唤起这个框架的词（煮、烤、炸……）称为词元。

不管句子里用哪个动词，「谁在做、对什么做、用什么做」都能映射到同一组角色，所以「describe」和「characterize」甚至名词「description」可以共享一个框架。这是它与只看动词的PropBank最大的区别。标注方式是从大语料里挑选例句，由语言学家逐句标出框架元素；项目由Fillmore创立，1997年起在伯克利ICSI进行，成果可免费下载。

这样得到的数据成为语义角色标注一类语义角色标注系统的训练与评测材料：给定一个句子，模型要判断谁是施事、谁是受事、哪里是地点。

局限与后续

  • 覆盖面靠人工挑选例句，只标注了部分词义和句子，没有对整篇语料逐句标注，难以直接训练大规模统计模型。
    后来针对它的工作　PropBank
  • 框架和角色的集合是语言学家设计的，边界主观，跨框架的泛化和英语以外的语言需要重新构建。
    后来针对它的工作　深度语义角色标注

它建立在什么之上

  • 使用
    Brown语料库1961 · 数据·评测
    以大规模英语语料中的真实例句作为标注对象，而不是造句。
  • 延续
    WordNet1995 · 数据·评测
    在WordNet的词义网络之外，增加了词在事件中的搭配角色这一层信息。

后来的相关工作

  • 使用
    语义角色标注2002 · NLP
    以FrameNet约5万句、近10万个人工标注的语义角色作为训练和测试数据。
  • 竞争
    PropBank2005.03 · 数据·评测
    同样标注语义角色，但FrameNet按框架组织、PropBank按动词组织并逐句覆盖。
  • 使用
