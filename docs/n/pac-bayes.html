PAC-Bayes泛化界

Some PAC-Bayesian Theorems
1998.07论文重要COLT 1998；Machine Learning 1999David A. McAllester · AT&T实验室待核对
COLT 1998（DOI） ↗期刊版（DOI） ↗PAC-Bayesian Model Averaging（COLT 1999） ↗在交互版中打开（演化树、学习进度）

问题

PAC学习和VC维与一致收敛给出的泛化保证只看假设空间有多大，与学习者事先偏好哪些假设无关；贝叶斯方法有先验，却没有不依赖“先验正确”的频率学保证。

方法

让学习者在看数据前选一个先验分布P，学完后输出一个后验分布Q（对假设随机抽取）；证明Q的真实风险不超过它的训练风险加上一项由KL(Q‖P)和样本数决定的余量，而且对任何先验都成立。

影响

PAC-Bayes成为与VC维、Rademacher复杂度并列的三大泛化分析工具之一，后来被用来给深度网络算出第一批非空泛的泛化界，并和平坦极小值、随机权重的直觉联系起来。

背景

到1990年代后期，学习理论的主流保证来自PAC学习与VC维与一致收敛：只要假设空间的容量有限，训练误差就会以一定速度逼近真实误差。这类界对空间里的每个假设一视同仁，所以对参数很多的模型（比如神经网络）几乎总是给出大于1的“空泛”结论。另一边，贝叶斯方法（如贝叶斯神经网络）允许把先验知识写成先验分布，实践中常常泛化得很好，但它的理论保证依赖“先验恰好正确”这个假设，而频率学者不愿接受。McAllester想要的是两者的结合：用先验表达偏好，但保证对任意先验都成立，即使先验选错了，界也只是变松而不会失效。

方法

设定和PAC一样：样本独立同分布地来自未知分布，共n个。学习者在看到样本之前固定一个假设上的先验P；看过样本后，可以挑任意一个后验Q，并按Q随机抽一个假设来预测（称为Gibbs分类器）。定理说：以至少1−δ的概率，对所有Q同时成立

E_{h~Q}[L(h)] ≤ E_{h~Q}[L̂(h)] + O(√((KL(Q‖P) + ln(n/δ)) / n))

其中L是真实风险，L̂是训练集上的风险，KL是KL散度。直观地说：后验离先验越近，需要的“复杂度代价”越小；如果后验把概率质量铺在一片区域上而不是押在一个点上，KL也会更小。原文给出了两类结果：一是对单个假设的界，复杂度项是先验给该假设的概率的负对数（这还原了经典的Occam界）；二是对后验分布的模型平均界。1999年的《PAC-Bayesian Model Averaging》进一步把它用于加权平均多个假设的预测。

结果

这是纯理论工作，没有实验数字。它的价值在于界的形式：复杂度项不再是假设空间的大小，而是一个依赖数据的量KL(Q‖P)，因此同一个大空间里，落在先验高概率区域、且对参数扰动不敏感的解可以拿到更紧的保证。

后来的发展

后续的Langford、Seeger、Maurer、Catoni等人把界收紧成了今天常用的几种形式。2017年深度网络的非空泛泛化界直接优化PAC-Bayes界，第一次给有数百万参数的随机神经网络算出了小于1的泛化界；之后它成为泛化度量大比较等大规模比较中与“平坦度”最相关的一类度量的理论来源，也被用来解释平坦极小值和SAM锐度感知最小化为何有效。

容易误解的地方

  • 界保证的是按Q随机抽假设的平均风险，不是某一个确定网络的风险；把它用到确定性网络上需要额外论证。
  • 先验P必须在看数据之前确定；用同一批数据既选先验又算界，会使结论失效。

局限与后续

  • 直接用于普通的确定性大网络时，KL项通常很大，界依旧是空泛的；要得到有意义的数字必须专门优化后验。
    后来针对它的工作　深度网络的非空泛泛化界
  • 界的松紧强烈依赖先验的选择，而怎样在不偷看数据的前提下选出好先验没有通用答案。

本篇术语

  • Gibbs分类器　每次预测时按后验分布Q随机抽一个假设来用的分类器，PAC-Bayes界直接针对它的平均风险。
  • 空泛的界　数值上大于等于1（对分类误差）的泛化界，等于什么也没说。

怎么学

先弄懂PAC学习和有限假设空间的Occam界；再读McAllester 1999期刊版的前两节；可配合Alquier的综述《User-friendly introduction to PAC-Bayes bounds》（arXiv 2110.11216）看后来的标准形式；动手：在逻辑回归上取高斯先验和高斯后验，计算界随后验方差的变化。
