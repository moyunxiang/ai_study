ArCHer分层多轮RL

ArCHer: Training Language Model Agents via Hierarchical Multi-Turn RL
2024.02论文延伸ICML 2024Yifei Zhou, Andrea Zanette, Jiayi Pan, Sergey Levine, Aviral Kumar · UC伯克利待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

给语言模型做强化学习的方法大多只优化单轮回复的奖励，而网页操作、工具调用、客服这类智能体任务要跨多轮交互，奖励往往到最后才出现。

方法

分两层训练：上层用离策略的价值学习，以“一整句话/一轮”为单位估计长期回报；下层用这个价值函数作为奖励，在每一轮内部按词元做策略梯度更新。

影响

是较早系统讨论“多轮智能体强化学习”怎么做的工作，提出的分层信用分配思路被后来的网页、设备操作智能体RL反复引用和对比。

方法

把单轮RL直接搬到多轮任务上有两个困难：一是一轮回复有几十上百个词元，若在词元级别做长程价值估计，时间跨度太长、很难学；二是奖励往往要等多轮之后才出现，需要跨轮次做信用分配。

ArCHer的做法是分层：

  • 上层（轮次级）：把每一轮完整回复当作一个动作，用离策略的时序差分方法（类似Q学习）训练一个评论家，估计“在这个对话状态下说这句话”的长期价值；离策略意味着可以反复利用旧的交互数据，样本效率高；
  • 下层（词元级）：在一轮之内，把上层给出的价值当作这一轮的奖励，用类似PPO的在线策略梯度训练语言模型逐词生成。

两层同时运行，框架也能派生出其他变体。

论文在多轮的智能体任务上（如WebShop式购物、二十问猜词等）实验，报告样本效率比已有方法高约100倍，并且随着模型变大效果继续提升。

局限与后续

  • 需要额外训练评论家网络，工程和显存开销都比无评论家的组相对方法大。
    后来针对它的工作　GiGPO组中组优化
  • 实验环境相对简单、交互轮数有限，在真实网页或长程软件任务上的可扩展性没有验证。

它建立在什么之上

  • 使用
    PPO2017.07 · RL
    下层在一轮之内用类似PPO的策略梯度按词元更新模型。
  • 改进
    ReAct2022.10 · 推理·智能体
    ReAct式智能体只靠提示，不从交互结果中学习；ArCHer给出了用多轮回报直接训练智能体的方法。
  • 使用
    Q-learning1992 · RL
    上层评论家用Q学习式的离策略时序差分方法，以一整轮回复为动作估计长期价值。
  • 使用
    WebShop2022.07 · 数据·评测
    网购类多轮任务是实验环境之一。
  • 改进
    FireAct智能体微调2023.10 · 推理·智能体
    训练轨迹来自GPT-4的模仿学习，学生模型的上限受教师约束，也学不到教师没走过的成功路径。
