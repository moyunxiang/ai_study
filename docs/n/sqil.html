SQIL软Q模仿

SQIL: Imitation Learning via Reinforcement Learning with Sparse Rewards
2019.05论文延伸ICLR 2020Siddharth Reddy, Anca D. Dragan, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

行为克隆贪心地模仿示范动作，一旦偏离示范状态就越走越偏；GAIL等方法靠RL解决了这个问题，但要用对抗训练学奖励，复杂又脆弱。

方法

不学奖励：把示范数据放进回放池并标上奖励+1，智能体自己产生的数据一律标0，然后用普通软Q学习训练。智能体会被激励回到示范见过的状态并照做。

影响

给出一个几行代码就能实现的模仿学习基线，揭示了「常数奖励+RL」就能对抗分布偏移，被后来的IQ-Learn等方法作为直接比较对象。

方法

SQIL（Soft Q Imitation Learning）对任何离策略的Q学习或actor-critic算法只做几处修改：

  • 回放池一半是专家示范的转移，奖励统一设为r=+1；
  • 另一半是智能体自己与环境交互得到的转移，奖励统一设为r=0；
  • 每个批次从两部分各采一半，用软Q学习（软Q学习（能量策略））的目标训练。

直观上，在示范状态做示范动作能拿到奖励；而走到示范没覆盖的状态后奖励全为0，Q值学会把「回到示范状态」看得更值钱，于是智能体有长期动机回到正轨，这正是行为克隆缺的。作者在理论上把SQIL解释为一种带稀疏先验的正则化行为克隆。摘要称，在Box2D、Atari和MuJoCo的图像输入和低维任务上，SQIL优于行为克隆，并与GAIL结果相当。

局限与后续

  • 奖励是硬编码的常数，训练久了智能体数据越来越像示范却仍被标0，表现可能随训练变差，需要提前停止。

读懂它需要的概念

模仿学习与行为克隆 分布偏移 on-policy与off-policy 时序差分与自举

本篇术语

  • 分布偏移（模仿学习中）　智能体自己的小错误把它带到示范中没出现过的状态，在那里它不知道该做什么，错误越积越大。

怎么学

先读DAgger和GAIL；读原文第2节算法和第3节理论解释；在CartPole或LunarLander上把DQN的回放池改成SQIL式，与行为克隆比较。
