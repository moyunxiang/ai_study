LightGBM

LightGBM: A Highly Efficient Gradient Boosting Decision Tree
2017.12论文重要NIPS 2017Guolin Ke, Qi Meng, Thomas Finley, Taifeng Wang, Wei Chen, Weidong Ma, Qiwei Ye, Tie-Yan Liu · Microsoft Research / 北京大学 / Microsoft Redmond待核对
NIPS 2017论文页 ↗官方文档：Features（直方图、按叶生长） ↗GitHub代码 ↗在交互版中打开（演化树、学习进度）

问题

梯度提升树每找一次分裂点都要把所有样本、所有特征扫一遍；数据到千万行、特征到千万维时，XGBoost要么很慢，要么内存不够。

方法

两招减少要扫的东西：按梯度大小采样，只留梯度大的样本加一小部分随机的小梯度样本（GOSS）；把几乎从不同时非零的稀疏特征捆成一个特征（EFB）。

影响

在5个大数据集上比不用这两招的直方图版本快1.6到21倍，精度几乎不变；开源库与XGBoost、CatBoost一起成为表格数据上最常用的提升树工具。

背景

梯度提升机GBM（GBDT）每一轮拟合一棵回归树去逼近当前损失的负梯度，最费时的是建树时找分裂点。找法有两种：预排序，把每个特征的取值排好序后枚举所有切点，精确但又慢又占内存；直方图，先把连续取值分到有限个桶里，按桶累加梯度，只在桶边界上找切点。直方图法里，建直方图的代价是O(样本数 × 特征数)，找切点只要O(桶数 × 特征数)，瓶颈在样本数和特征数。

XGBoost在论文测试的KDD Cup 2010、2012数据上（1900万和1.19亿行，2900万和5400万维稀疏特征），直方图版本直接内存溢出。减少样本和特征并不容易：AdaBoost与集成学习式的加速按样本权重采样，而GBDT没有样本权重。

方法

基础：直方图加按叶生长。连续特征先分桶；树每次挑当前损失下降最大的那片叶子分裂（best-first），而不是一层一层长。

GOSS：基于梯度的单边采样。梯度绝对值大的样本还没拟合好，对分裂增益的贡献也大。GOSS每轮按|g|排序，保留前a比例的大梯度样本，再从剩下的样本里随机抽b比例（相对全体），计算增益时把抽中的小梯度样本乘以(1−a)/b，补回被丢掉的那部分梯度和。例如100万个样本、a = b = 0.1：留下梯度最大的10万个，再从其余90万中随机抽10万个、每个权重记为9，建树只用这20万个。论文证明，同样采样率下这比均匀随机采样估计的增益更准。

EFB：互斥特征捆绑。高维稀疏特征里，许多列（典型如独热编码与词表编码出来的列）几乎从不同时非零。把它们合成一个特征，直方图代价就从O(样本数 × 特征数)降到O(样本数 × 捆数)。找最少的捆是NP难的（可由图着色归约），作者用贪心着色近似求解，并允许少量冲突。合并时给各特征的桶编号加偏移：特征A落在[0, 10)、B落在[0, 20)，把B加10变成[10, 30)，合成的新特征仍能区分两者。

结果

在5个数据集上比较每轮训练时间：LightGBM相对不带GOSS和EFB的自家直方图版本，在Allstate、Flight Delay、LETOR、KDD10、KDD12上分别快21、6、1.6、14、13倍；相对XGBoost直方图版本最多快9倍。精度几乎不变，例如KDD12测试AUC为0.7051，基线为0.7049。GOSS只用10%到20%的数据带来约2倍提速（预测和算梯度仍在全量数据上做），且同采样率下精度始终高于普通随机采样；EFB在大规模稀疏数据上贡献了大部分提速。

后来的发展

LightGBM说明：在直方图法之上，瓶颈是每轮要看多少样本、多少特征，两者都能按梯度和稀疏结构有选择地压缩而几乎不损精度。官方文档列出的后续改进包括用父节点减去兄弟节点得到直方图，以及对类别特征直接按梯度统计排序找最优二分、不必先做独热编码。

它与同年的CatBoost、XGBoost至今仍是表格数据（风控、广告点击、排序、数据竞赛）的首选；在这类数据上，深度网络至今没有稳定地取代它们。

容易误解的地方

  • GOSS不是简单丢弃小梯度样本：直接丢弃会改变数据分布、损害精度，(1−a)/b的放大系数是关键。
  • 按叶生长在数据量小时容易过拟合，官方文档建议用max_depth和叶子数加以限制；即使设了max_depth，树仍按叶生长。
  • 论文中的提速对比是「每轮训练时间」，不同数据集差别很大：稠密、特征少的LETOR只快1.6倍，提速主要出现在大规模稀疏数据上。

局限与后续

  • 按叶生长的树深度不受控，样本少时容易过拟合，需要人工调叶子数、最大深度等超参数。

它建立在什么之上

  • 使用
    决策树CART1984 · 基础
    基学习器仍是CART式的二叉回归树，以分裂后的方差增益选切点。
  • 延续
    梯度提升机GBM2001 · 基础
    完全沿用GBDT的「每轮拟合负梯度」框架，只改变建树时用哪些样本和特征来估计分裂增益。
  • 改进
    XGBoost2016.03 · 基础
    XGBoost在千万行、千万维稀疏数据上又慢又可能内存溢出；GOSS和EFB把建直方图的样本数和特征数都降下来，在相同精度下快一个量级。
  • 延续
    AdaBoost与集成学习1997 · 基础
    AdaBoost可以按样本权重采样加速，GBDT没有样本权重；GOSS用梯度绝对值充当这个「重要性」。
  • 竞争
    CatBoost2017.06 · 基础
    同年的另一款提升树库，重点是类别特征和预测偏移带来的偏差，LightGBM重点是速度和内存；两者至今并存。

读懂它需要的概念

决策树 集成学习 梯度下降 损失函数 独热编码与词表 时间与空间复杂度

本篇术语

  • 直方图算法　把连续特征的取值分成有限个桶（例如几百个），建树时按桶累加梯度，只在桶边界上找切点，比枚举全部取值省时省内存。
  • 按叶生长（leaf-wise）　每次只分裂当前损失下降最多的那片叶子，而不是把同一层的所有节点都分裂一遍（按层生长）。
  • 方差增益　GBDT选切点的标准：切分后左右两边负梯度之和的平方除以各自样本数，再相加；越大说明这刀把梯度方向不同的样本分得越开。
