蒙特卡洛定位

Monte Carlo Localization for Mobile Robots
1999.05论文延伸ICRA 1999Frank Dellaert, Dieter Fox, Wolfram Burgard, Sebastian Thrun · CMU / Bonn待核对
维基：蒙特卡洛定位 ↗在交互版中打开（演化树、学习进度）

问题

卡尔曼滤波假设机器人位置的不确定性是单个高斯分布，在“有好几扇长得一样的门”这样的场景里会出错；栅格方法又太耗内存。

方法

用一大把带权重的“粒子”表示机器人可能在的位置，按运动更新、传感器加权、重采样三步反复迭代。

影响

让机器人在已知地图里的全局定位变得简单可靠，粒子滤波自此成为移动机器人定位的标准做法（如ROS的amcl）。

方法

据维基百科，该方法见于1999年ICRA上Dellaert、Fox、Burgard、Thrun的论文。步骤：

  • 初始化：粒子撒满整个位形空间，因为一开始不知道自己在哪。
  • 运动更新：每个粒子按里程计的移动命令移动，并加噪声，模拟轮子打滑等误差。
  • 传感器更新：每个粒子按“若机器人在这里，看到当前传感器读数的可能性”获得权重。
  • 重采样：按权重重新抽粒子，与观测一致的粒子被多次抽中，不一致的被淘汰。

与卡尔曼滤波相比，它是非参数的，可同时表示多个候选位置；内存只与粒子数有关，与地图大小无关；粒子数还能根据算力调整。弱点是“绑架机器人”问题：粒子全部收敛到错误位置后无法恢复，常见补救是每轮随机注入少量粒子。

局限与后续

  • 粒子数不足时会退化，全部粒子集中到错误位置后恢复不了（粒子枯竭）。
    后来针对它的工作　FastSLAM
  • 需要事先有地图，只解决定位，不能同时建图。
    后来针对它的工作　FastSLAM

它建立在什么之上

  • 改进
    卡尔曼滤波1960 · 具身·世界模型 已核对
    解决了高斯假设无法表示多峰（多个相似位置）的问题：用粒子代替单一高斯。
  • 改进
    占据栅格地图1985.03 · 具身·世界模型
    建图时完全依赖航位推算给出的位姿，轮子打滑和累积误差会直接把地图画歪；论文里的地图配准还没有接进导航。
  • 改进
    无迹卡尔曼滤波UKF1997 · 具身·世界模型
    仍然用一个均值加协方差来描述状态，遇到多峰分布（比如机器人不知道自己在两个相似走廊中的哪一个）就无能为力。
