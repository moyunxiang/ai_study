MXNet

MXNet: A Flexible and Efficient Machine Learning Library for Heterogeneous Distributed Systems
2015.12论文延伸NIPS 2015 LearningSys workshopTianqi Chen, Mu Li, Yutian Li, Min Lin, Naiyan Wang, Minjie Wang, Tianjun Xiao, Bing Xu, Chiyuan Zhang, Zheng Zhang待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

当时的框架要么是声明式（先构图后执行，高效但难调试），要么是命令式（灵活但难优化），研究者常需要两套。

方法

同一个库里同时提供符号计算图与命令式张量运算，并由一个依赖引擎统一调度，能跑在手机到多GPU集群上。

影响

做出了第一批能同时用声明式与命令式、并原生支持分布式的开源框架，也是其作者后续TVM、XGBoost生态的一部分。

方法

MXNet由多个高校和公司的开发者合作开发。摘要说明它嵌入宿主语言，把声明式符号表达式和命令式张量计算混合在一起，提供自动微分，且计算和内存都高效，可运行在从移动设备到分布式GPU集群的异构系统上。其核心是一个依赖引擎：每个运算声明自己读写哪些变量，引擎据此异步并行地调度，既能用符号图做内存复用优化，也允许像NumPy那样即时执行。分布式训练通过KVStore接口，借助参数服务器在多机间同步梯度。

它有多语言前端（Python、R、Scala、Julia等）；亚马逊AWS曾推荐它作为深度学习框架（该说法未在本次核对）。
