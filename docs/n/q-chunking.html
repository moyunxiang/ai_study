Q-chunking动作分块RL

Reinforcement Learning with Action Chunking
2025.07论文延伸NeurIPS 2025Qiyang Li, Zhiyuan Zhou, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

长视界、稀疏奖励的操作任务里，即使有离线数据，在线RL也很难探索：每一步独立采样的动作前后不连贯，难以复现数据里那种有目的的连续动作。

方法

把模仿学习里的“动作分块”搬进TD学习：策略一次输出未来h步的动作块，评论家学的是“状态+整个动作块”的Q值，用块结束后的状态做h步备份。

影响

把动作分块从模仿学习（ACT、扩散策略）推广到基于价值的RL，2025年下半年以来被机器人离线转在线RL和VLA的RL微调工作频繁引用和沿用。

方法

动作分块（见ALOHA与ACT、Diffusion Policy）是指策略每次预测接下来一段动作序列而不是一个动作。Q-chunking直接在“分块后的动作空间”里做RL：

  • 动作块 A_t = (a_t, …, a_(t+h−1))，评论家学 Q(s_t, A_t)；
  • TD目标用块内的真实奖励和块结束后的状态：

Q(s_t, A_t) ← Σ_(i=0)^(h−1) γ^i r_(t+i) + γ^h Q(s_(t+h), A_(t+h))

因为整个块就是一个“动作”，这里的h步回报没有普通n步回报在离策略时的偏差（块内动作就是被评估的那个动作），同时信息一次传h步，训练更快更稳；

  • 策略输出整个块，论文的实现以FQL流Q学习为底座，用流匹配的行为策略加一步策略来生成块；也给了一个从行为策略采样多个块、按Q值挑最好的变体。

好处有两个：在线探索时执行的是时间上连贯的动作块，更像离线数据里有目的的行为；价值备份是无偏的多步备份。摘要称在一系列长视界、稀疏奖励的操作任务上，离线表现强、在线样本效率高，超过此前最好的离线转在线方法。

局限与后续

  • 块长h固定，执行块内动作时不看新的观测，属于开环执行，对需要快速反应的任务不利。

离线强化学习 动作表示：离散token、连续动作与动作块 时序差分与自举 探索与利用

本篇术语

  • 动作块（action chunk）　策略一次性输出的、接下来若干步要依次执行的动作序列。

怎么学

先读ALOHA与ACT了解动作分块，再读FQL流Q学习；读原文第4节的块级备份；在OGBench的cube任务上比较h=1与h=5的在线微调曲线。
