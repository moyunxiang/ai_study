OpenPose

Realtime Multi-Person 2D Pose Estimation using Part Affinity Fields
2016.11论文延伸CVPR 2017Cao, Simon, Wei, Sheikh · CMU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多人姿态估计要么先检测人再逐人估计（人多时变慢），要么自底向上但关联步骤难。

方法

自底向上：同时预测关键点热图和「部件亲和场」（部件之间方向向量场），用它把关键点连成不同的人。

影响

实现了运行时间基本不随人数增长的实时多人2D姿态估计，OpenPose成为广泛使用的开源工具。

方法

网络分两路分支，在多个阶段上迭代细化：一支预测每种关键点（肩、肘等）的位置热图，另一支预测部件亲和场，也就是在每个像素上标记一个指向「这一肢体从A点到B点」的方向向量。拼接两个候选关键点时，沿它们之间的线段对亲和场积分，积分越大说明越可能属于同一个肢体，再用贪心算法把肢体连成完整的人。

因为不依赖先检测每个人，推理开销不随人数显著增加。论文称它在首届COCO 2016关键点挑战赛排名第一，并在MPII多人基准上大幅超过之前最好结果。

局限与后续

它建立在什么之上

  • 使用
    VGG2014.09 · 视觉
    特征提取使用VGG前几层。
  • 竞争
    DeepPose2013.12 · 视觉
    DeepPose是先检测人再对每个人回归关键点的自顶向下路线，OpenPose走自底向上。
  • 改进
    MPII人体姿态2014.06 · 数据·评测
    只标单张图像里的二维关节，没有三维姿态和身体表面形状；多人场景的评测也只是附带的。
  • 改进
    堆叠沙漏网络2016.03 · 视觉
    只处理单人裁剪图，多人场景需要先检测再逐个估计。

后来的相关工作

  • 使用
    CornerNet2018.08 · 视觉
    借用关键点热图加关联嵌入的配对思想，用于多个物体的角点配对。
  • 竞争
    HRNet2019.02 · 视觉
    OpenPose是自底向上的多人姿态，HRNet在高分辨率表示上做精细关键点热图，两者对高分辨率特征的处理方式不同。
