DPO直接偏好优化

Direct Preference Optimization: Your Language Model is Secretly a Reward Model
2023.05论文主干NeurIPS 2023Rafailov, Sharma, Mitchell, Ermon, Manning, Finn · Stanford来源已核对
arXiv ↗Hugging Face TRL：DPOTrainer文档 ↗在交互版中打开（演化树、学习进度）

问题

RLHF要先训奖励模型，再用PPO边采样边强化学习，显存里同时放好几个模型，超参数敏感、训练不稳定，学术界和小团队很难复现。

方法

数学上证明：带KL约束的RLHF目标的最优策略可以写成闭式，奖励能用“策略与参考模型的概率比”表示；代入偏好模型后，整个RLHF变成一个对偏好对做二分类的损失。

影响

偏好对齐从“强化学习工程”变成“写一个损失函数”。许多开源聊天模型的偏好训练改用DPO或其变体，IPO、KTO、SimPO等后续方法都以它为出发点。

背景

InstructGPT与RLHF和ChatGPT发布用的RLHF（见人类反馈强化学习）分三步：监督微调得到SFT模型；用人类偏好对（同一个问题x，回答y_w比y_l好）训练奖励模型r；再用PPO优化策略π，目标是

最大化 E[ r(x, y) ] − β·KL( π(·|x) ‖ π_ref(·|x) )

其中π_ref是SFT模型，β控制“别偏离太远”的力度（见KL散度）。

这条路在工程上非常重。PPO训练时要在线从策略里采样回答、让奖励模型打分、再算优势函数（见Actor-Critic与优势函数），显存里同时放着策略、参考模型、奖励模型和价值网络四个大模型；奖励模型一旦被钻空子就会失效（奖励模型过优化）；学习率、KL系数、裁剪范围稍有不对就训崩。论文开篇就说RLHF“复杂且常常不稳定”。2023年开源社区已经能做SFT（Alpaca与廉价指令微调、Vicuna与ShareGPT），PPO这一步的门槛高得多。问题是：既然最终目标只是让模型更符合偏好数据，能不能绕开奖励模型和强化学习？

方法

关键是三步推导。

第一步：最优策略有闭式解。 对上面那个带KL约束的目标，对每个x，最优策略是

π*(y|x) = π_ref(y|x) · exp( r(x,y)/β ) / Z(x)

直观理解：在参考模型的基础上，奖励高的回答按指数放大概率。Z(x)是归一化常数，要对所有可能的回答求和，没法算——这正是之前必须用强化学习的原因。

第二步：反过来用策略表示奖励。 把上式取对数移项：

r(x,y) = β·log( π*(y|x) / π_ref(y|x) ) + β·log Z(x)

也就是说，任何一个策略都隐含着一个奖励函数——标题说的“你的语言模型其实是个奖励模型”。

第三步：代入偏好模型，难算的Z消掉了。 RLHF假设人类偏好服从Bradley-Terry模型：P(y_w 优于 y_l) = σ( r(x,y_w) − r(x,y_l) )。两个奖励相减，β·log Z(x)正好抵消。于是直接对策略π_θ做最大似然（见最大似然估计），得到DPO损失：

L_DPO = −E[ log σ( β·log(π_θ(y_w|x)/π_ref(y_w|x)) − β·log(π_θ(y_l|x)/π_ref(y_l|x)) ) ]

一个小算例。 设β=0.1。某个偏好对上，当前模型相对参考模型把好回答的对数概率提高了0.2，把差回答的降低了0.1，括号里就是0.1×(0.2−(−0.1)) = 0.03，σ(0.03)≈0.507，损失≈0.68。梯度会继续推高y_w、压低y_l的概率。

梯度的含义。 论文把梯度写开后发现，每个样本的权重是σ( r̂(y_l) − r̂(y_w) )，其中r̂是上面的隐式奖励：模型越是把这对的好坏排反，权重越大。论文指出，没有这个权重、只是简单地“提高好回答概率、降低差回答概率”，模型会退化。

实现上只需要两个模型（训练中的策略、冻结的参考模型），每个偏好对各做一次前向传播，不需要在训练中采样，也不需要奖励模型和价值网络，和普通微调一样简单。

结果

论文在三个任务上和PPO比较：

  • 受控情感生成（IMDb影评开头，要求续写成正面评价，用情感分类器当真实奖励）：在“奖励—KL”的权衡曲线上，DPO在每个KL水平下都拿到最高奖励，优于PPO，甚至优于能拿到真实奖励的PPO。
  • TL;DR摘要（人类反馈学摘要的Reddit摘要数据，从同一个GPT-J SFT模型出发）：以GPT-4为裁判、对比人写摘要的胜率，DPO在温度0时约61%，PPO在其最佳温度0时约57%。迁移到CNN/DailyMail新闻上，DPO胜率0.36，PPO 0.26。
  • 单轮对话（Anthropic HH-RLHF，用Pythia-2.8B）：DPO是唯一既省计算、又能超过数据集中“被选中回答”的方法，效果与需要采样128次再挑最好的Best-of-128相当或更好。

作者另做了人类评估：GPT-4与人类判断的一致率通常与人类标注员之间相近或更高；人类评估中，DPO（温度0.25）的摘要有58%的时候胜过PPO（温度0）。

后来的发展

DPO很快被许多开源后训练流程采用：Zephyr蒸馏对齐用AI反馈的偏好数据加DPO对齐7B模型，在MT-Bench上超过Llama2-Chat-70B；Tülu 3开放后训练的开放后训练流程以DPO为偏好阶段；Meta的Llama 3（Llama 3.1 405B）报告称试过PPO，但DPO在大模型上更省计算、效果更好，因此用DPO。它被搬到图像生成上成为Diffusion-DPO。

围绕它的缺陷出现了一整族变体：IPO与ΨPO框架指出偏好接近确定时DPO会过拟合，改用有界的平方损失；KTO前景理论对齐只需要“好/坏”单个标签、不需要成对数据；SimPO去掉参考模型并按长度归一化。

到了推理模型时代，风向又部分回到在线强化学习：数学和代码有可自动验证的奖励，GRPO和DeepSeek-R1用在线采样的RL在推理任务上取得了明显提升。Tülu 3开放后训练的流程就是SFT之后先做DPO，再对可验证任务做在线RL。

容易误解的地方

  • DPO并没有“去掉奖励”，它仍然在优化同一个带KL约束的RLHF目标，只是把奖励模型隐含在策略里。
  • β不是可有可无的：β太小，模型可以离参考模型很远，容易把好坏两个回答的概率一起压低；β太大则几乎学不动。
  • DPO是离线方法，只从固定的偏好数据学，数据里没覆盖的回答类型它无从改进；这与PPO在线采样、边探索边学是根本区别。

局限与后续

  • 纯离线训练：只用事先收集的偏好对，不在训练中采样新回答，模型生成分布变化后数据就过时了。
    后来针对它的工作　GRPO DeepSeek-R1
  • 偏好数据接近确定（总是y_w胜）时，最优解会把KL约束推到失效，容易过拟合。
    后来针对它的工作　IPO与ΨPO框架
  • 必须有成对的偏好数据，而现实中很多反馈只是单个回答的“好/坏”。
    后来针对它的工作　KTO前景理论对齐
  • 训练时仍要额外加载一个冻结的参考模型，并且容易利用长度偏好、越训回答越长。
    后来针对它的工作　SimPO

读懂它需要的概念

人类反馈强化学习 KL散度 最大似然估计 逻辑回归 Softmax与logits 策略梯度 预训练与微调

本篇术语

  • Bradley-Terry模型　一种成对比较的概率模型：每个选项有一个分数，A胜B的概率是σ(分数A−分数B)。国际象棋的Elo分本质上就是它。
  • 参考模型π_ref　训练开始时的SFT模型，训练中冻结不动。DPO和RLHF都用它来度量新模型偏离了多远。
  • 隐式奖励　DPO里r̂(x,y)=β·log(π_θ(y|x)/π_ref(y|x))。不需要单独的网络，任何策略和参考模型的概率比就定义了一个奖励。
  • 离线/在线偏好优化　离线只用固定数据集训练；在线在训练中不断用当前模型生成新回答、再打分学习。

怎么学

先确认会KL散度、逻辑回归（σ与对数似然）和人类反馈强化学习。然后读论文第4节，自己动手推一遍从KL约束目标到闭式最优策略、再到DPO损失的三步（附录A.1有完整推导），第5节看梯度分析。动手：用Hugging Face TRL的DPOTrainer在一个0.5B左右的小模型和一个公开偏好数据集上跑DPO，画出训练中好回答与差回答的隐式奖励曲线，再把β分别设为0.01和0.5对比。
