BiGAN / ALI

Adversarial Feature Learning
2016.05论文延伸ICLR 2017Jeff Donahue, Philipp Krähenbühl, Trevor Darrell · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

生成对抗网络GAN能把随机噪声映射成逼真图像，但没有反向通道：给一张真实图像，无法得到它对应的潜变量，生成器学到的语义就用不到别的任务上。

方法

在生成器G之外再训练一个编码器E（图像→潜变量），判别器同时看（图像，潜变量）对，分辨是（G(z), z）还是（x, E(x)）。

影响

让GAN同时具备生成与编码能力，学到的特征可用于分类等任务，是GAN走向表示学习的早期尝试；同期的ALI思路相同。

方法

普通生成对抗网络GAN里，生成器G把潜变量z变成图像，判别器D只判断图像真假，没有办法从图像反推z。BiGAN增加一个编码器E，把真实图像x映射为潜变量E(x)。判别器的输入改成一对（图像，潜变量）：来自生成端的是（G(z), z），来自数据端的是（x, E(x)）。G和E联手让两种配对无法区分，D则努力区分。

作者证明在最优情况下，E和G互为逆映射：编码E(x)后再生成G(E(x))应当还原出x。变分自编码器VAE也有编码器和解码器，但靠像素级重构损失约束；BiGAN没有重构项，只靠对抗训练约束。训练好后丢掉G和D，把E当作无监督特征提取器，再接线性分类器评测。

文中报告其特征在ImageNet等任务上可与当时的无监督、自监督特征学习方法竞争。几乎同时，Dumoulin等人提出的ALI（Adversarially Learned Inference）采用了相同的结构，因此两者常合称BiGAN/ALI。

局限与后续

  • 没有重构损失，E(x)再经G往往还原不出原图的细节，只保留语义层面的对应；GAN训练本身也不稳定。

    生成对抗网络GAN2014.06 · 生成
    在GAN上增加编码器与（图像，潜变量）联合判别，补上从数据回到潜空间的反向映射。
