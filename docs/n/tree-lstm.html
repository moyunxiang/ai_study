Tree-LSTM

Improved Semantic Representations From Tree-Structured Long Short-Term Memory Networks
2015.02论文延伸ACL 2015Kai Sheng Tai, Richard Socher, Christopher D. Manning · Stanford University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LSTM只能沿线性链处理文本，而语言的短语是按句法树组合起来的，链式结构利用不了这一点。

方法

把LSTM的门控记忆单元推广到树结构：每个节点汇总其所有子节点的状态，沿句法树自底向上计算。

影响

在句子语义相关度和情感分类两项任务上优于线性LSTM，是树结构神经网络的代表，也是后来句法感知表示的参照。

方法

链式LSTM的一个单元接收前一时刻的状态。Tree-LSTM的一个单元接收的是它的多个子节点的状态：门控与记忆更新由子节点隐状态的汇总决定，并且对每个子节点单独计算一个遗忘门，这样可以有选择地保留某个子树的信息。论文给了两个变体：Child-Sum（对子节点求和，适合分支数不定的依存树）和N-ary（子节点有固定顺序，适合二叉成分树）。

训练时先用解析器得到句法树，再自底向上把词向量逐步合成为短语、整句的表示，最后接分类或相关度打分层。论文报告在SemEval 2014 Task 1句对相关度和Stanford Sentiment Treebank情感分类上，超过了现有系统和强线性LSTM基线。

局限与后续

  • 必须先有句法树，依赖外部解析器，且树结构难以成批并行计算，训练比链式LSTM慢。
    后来针对它的工作　Transformer
  • 收益只在特定任务上出现，随着预训练模型兴起，显式句法结构的增益变得不明显。
    后来针对它的工作　BERT

它建立在什么之上

  • 延续
    LSTM1997 · 基础
    把LSTM的门控记忆单元从线性链推广到树，每个节点汇总多个子节点。
  • 改进
    递归张量网络与情感树库2013.10 · NLP
    同样沿句法树自底向上组合，但用LSTM门控代替张量组合函数，缓解深树上的梯度问题。
  • 改进
    TextCNN句子分类2014.08 · NLP
    卷积窗口只有3到5个词，最大池化又丢掉了位置和顺序，长距离依赖和否定作用范围等句子结构捕捉不到。
  • 改进
    递归神经网络2011.06 · NLP
    使用单个矩阵做组合，表达能力有限，词与词的交互难以建模；深树上有梯度消失。

后来的相关工作

  • 改进
    Transformer2017.06 · LLM
    必须先有句法树，依赖外部解析器，且树结构难以成批并行计算，训练比链式LSTM慢。
  • 改进
    BERT2018.10 · LLM
    收益只在特定任务上出现，随着预训练模型兴起，显式句法结构的增益变得不明显。
  • 使用
    ESIM自然语言推理2016.09 · NLP
    进一步用Tree-LSTM引入句法结构做增强。

读懂它需要的概念

循环网络与隐状态 嵌入向量 梯度消失与梯度爆炸

本篇术语

  • Child-Sum / N-ary　Tree-LSTM的两个变体：前者对任意个子节点的状态求和，后者要求子节点个数固定且有序。

怎么学

先会LSTM的门；读原文第3节的公式，对照官方PyTorch/Torch实现；用一个小句子手算一遍自底向上的合成。
