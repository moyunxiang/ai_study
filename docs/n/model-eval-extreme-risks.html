极端风险的模型评测

Model evaluation for extreme risks
2023.05论文延伸Shevlane, Farquhar, Garfinkel, Phuong, Whittlestone, Leung, Kokotajlo, Marchal, Anderljung et al.（共21位）· Google DeepMind / OpenAI / Anthropic / 多所大学与机构待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通用AI能力越强，同时带来有益与有害能力；缺少系统评估模型是否具备进攻性网络能力、强操纵能力等极端风险的方法。

方法

提出两类评测：『危险能力评测』看模型能做什么，『对齐评测』看模型倾向于把能力用来做坏事的程度，并把它们接入训练与部署决策。

影响

把评测变成前沿AI治理的基础设施，影响了各家的责任扩展政策与政府的评测机构设计。

方法

论文先论证：开发者必须能在训练之前、之中、之后识别模型是否出现极端风险能力，如攻击性网络能力或强操纵能力。作者区分两类评测：危险能力评测检验模型是否有造成大规模伤害的能力；对齐评测检验即使有能力，模型是否倾向于去用。

论文还提出评测结果应如何向政策制定者和其他利益相关方披露，以及如何影响是否继续训练、是否部署、安全措施的决定，包括第三方外部评测。这套框架成为负责任扩展政策RSP、OpenAI准备度框架等企业政策中『能力阈值触发更强防护』思路的理论基础，也与英美AI安全研究所成立这类政府评测机构的设立相呼应。

局限与后续

  • 评测只能证明某些能力存在，无法证明不存在；模型在提示不当时可能表现不出真实能力。
