Ubuntu对话语料

The Ubuntu Dialogue Corpus: A Large Dataset for Research in Unstructured Multi-Turn Dialogue Systems
2015.06数据集延伸SIGDIAL 2015Ryan Lowe, Nissan Pow, Iulian Serban, Joelle Pineau · 麦吉尔大学 / 蒙特利尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经网络对话模型需要大量多轮对话数据，已有数据要么像对话状态追踪挑战那样规模小、领域窄，要么像微博那样只有一来一回、缺少多轮结构。

方法

从Ubuntu技术支持的IRC聊天记录中抽出两人之间的多轮对话，做成近百万段、上亿词的公开语料，并定义“从候选中选出下一句”的评测任务。

影响

成为检索式多轮对话（回复选择）最常用的基准，大量匹配模型在它上面比较，也是早期端到端对话模型的主要训练语料之一。

方法

数据怎么来。Ubuntu社区在IRC频道里互相解答技术问题，频道是多人混聊。作者用启发式规则把消息按“谁在回复谁”分离成两人之间的对话，得到近100万段多轮对话，共超过700万句、1亿词。对话平均有好几轮，内容是关于装驱动、配置系统之类的技术支持。

评测任务。给出对话上文，从若干候选句（1个真实下一句加随机抽来的其他句子）中选出正确的回复，用Recall@k计分。这比直接生成回复更容易自动评测。论文给出了TF-IDF、RNN和LSTM双编码器等基线。

特点。它兼有对话状态追踪数据的多轮性质和社交媒体数据的非结构化特点，而且领域单一、术语密集。

后来的发展

Ubuntu语料推动了检索式对话和多轮回复匹配研究，后来的DSTC对话挑战也用过它的版本；生成式对话方向则转向PERSONA-CHAT人设闲聊等更开放的闲聊语料。

局限与后续

  • 对话分离靠启发式规则，存在错误配对；随机负例太容易区分，回复选择分数会高估模型理解能力。
