特德·姜《网络的模糊JPEG》

ChatGPT Is a Blurry JPEG of the Web
2023.02思想延伸The New Yorker, 2023-02-09Ted Chiang（特德·姜）待核对
The New Yorker原文 ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT发布两个多月后，公众急需一个直观的说法来理解它到底在做什么：它会“思考”吗，为什么会一本正经地编造？

方法

科幻作家特德·姜把大语言模型比作整个网络文本的“有损压缩”：它保存的是统计规律而不是原文，回答时用插值重建内容，所以输出看似可信，细节却可能是压缩造成的失真。

影响

“模糊的JPEG”成为向大众解释大模型和幻觉时被引用最多的比喻之一，也代表了文化界对ChatGPT的典型怀疑立场。

方法

文章2023年2月9日发表在《纽约客》。开头讲了一个真实事件：2013年德国一家建筑公司发现，施乐复印机复印房屋平面图时，把三个房间的面积（14.13、21.11、17.42平方米）全印成了14.13。原因是复印机用了JBIG2有损压缩，把看起来相似的区域只存一份再重复使用。问题不在于有损，而在于失真“清晰可读却是错的”，让复印件看起来准确。

他接着设想：如果你要把整个网络的文本压缩到只有百分之一大小的服务器上，只能保存规律而不是原文，取回时再用插值“重建”。大语言模型就像这样一份压缩文件；它的流畅改写让人以为它理解了内容，而它的编造（即幻觉）就像复印机的失真。按一般了解，文中还讨论了为何这种模型不擅长精确算术、为何用模型输出训练下一代模型是坏主意，以及作家不该用它替代初稿写作。

与随机鹦鹉一样，这篇文章强调模型复现的是文本表面的统计结构；不同之处是它用压缩这个技术上更具体的比喻，让非专业读者也能理解。

局限与后续

  • “压缩”比喻解释了幻觉，但难以解释模型在训练数据之外的组合推理和上下文学习能力，后来推理模型的进步使这一比喻显得不完整。
