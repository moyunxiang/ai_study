多项式扩散与Argmax流

Argmax Flows and Multinomial Diffusion: Learning Categorical Distributions
2021.02论文延伸NeurIPS 2021Emiel Hoogeboom, Didrik Nielsen, Priyank Jaini, Patrick Forré, Max Welling · 阿姆斯特丹大学、丹麦技术大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

标准化流和扩散模型都是为连续、有大小顺序的数据（像素值）设计的。文字、分割图这类类别数据没有顺序，此前只能先“去量化”（加噪声变成连续值）再建模，效果和似然都不理想。

方法

提出两种直接面向类别数据的生成模型：Argmax流用一个连续流加argmax得到类别，并学一个从类别回到连续空间的概率逆映射；多项式扩散则在每一步用类别噪声（以一定概率把token换成均匀随机的类别）逐渐打乱数据，再学去噪的反向过程。

影响

多项式扩散是扩散模型推广到离散数据的早期工作之一，D3PM在几个月后把它的均匀转移推广成一般转移矩阵，进而走到今天的掩码扩散语言模型和离散图像token扩散。

方法

多项式扩散：设x是one-hot类别向量，共K类。前向一步为q(x_t|x_{t−1}) = Cat(x_t; (1−β_t)·x_{t−1} + β_t/K)，即以概率1−β_t保持原类别，以β_t换成K类中的均匀随机类别；多步合起来仍有闭式q(x_t|x₀) = Cat((ᾱ_t)·x₀ + (1−ᾱ_t)/K)，最终变成完全均匀分布。反向过程用网络预测x₀，再按类别分布的后验公式得到p(x_{t−1}|x_t)，像DDPM一样用变分下界训练。

Argmax流：先用一个连续的标准化流生成向量v，再取x = argmax(v)得到类别。训练时需要从类别x反推v，作者学一个概率逆映射q(v|x)，约束v的最大分量恰好落在x所在位置，这比通用的变分去量化更贴合类别结构。

两种方法在text8字符级文本和Cityscapes分割图上的对数似然都优于已有的去量化做法。

读懂它需要的概念

扩散：前向加噪与反向去噪 可逆流与流匹配 独热编码与词表 变分推断与ELBO 马尔可夫性与马尔可夫链

本篇术语

  • 去量化　给离散数据加连续噪声，让它变成连续变量以便用连续密度模型建模。
  • 类别分布　在K个类别上各给一个概率、概率和为1的离散分布，记作Cat。

怎么学

先弄懂DDPM的前向闭式与后验公式 → 读本文第4节多项式扩散的前向、后验推导 → 在text8或二值MNIST上实现均匀转移的离散扩散并与掩码转移比较。
