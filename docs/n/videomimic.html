VideoMimic视频到人形

Visual Imitation Enables Contextual Humanoid Control
2025.05论文延伸CoRL 2025Arthur Allshire, Hongsuk Choi, Junyi Zhang, David McAllister, Anthony Zhang, Chung Min Kim, Trevor Darrell, Pieter Abbeel, Jitendra Malik, Angjoo Kanazawa · UC Berkeley待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

人形机器人模仿人类动作多依赖动捕数据，只有动作没有环境，学不会爬楼梯、坐椅子这类要和周围环境配合的技能。

方法

从手机随手拍的单目视频里同时重建人的动作和周围场景，把人的动作重定向到人形机器人，在重建出的场景里用强化学习训练策略再上真机。

影响

让“拍一段视频教机器人”的真实到仿真再到真实（real-to-sim-to-real）流程跑通，单一策略在真机上完成上下楼梯、坐下站起等技能。

方法

此前DeepMimic一类方法在仿真里跟踪人类动作捕捉数据，HumanPlus等工作让人形机器人跟随人体姿态，但动作数据里没有环境：机器人学了“抬腿”却不知道台阶在哪。

VideoMimic的流程是：从日常单目视频中联合重建人体运动和场景几何（台阶、椅子、长凳等），把人体动作重定向到人形机器人骨架，在重建出的场景里用强化学习训练一个以环境高度图和全局根节点指令为条件的全身控制策略，最后部署到低价人形机器人Unitree G1上。论文在真机上演示了稳健、可重复的上下楼梯、在椅子和长凳上坐下站起等动作，全部由同一个策略完成。

局限与后续

  • 依赖单目重建质量，遮挡严重或场景复杂时人和环境的重建会出错。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只处理与静态环境的接触，不涉及搬动物体等操作类交互。
    本站还没有记录针对它的后续工作（不代表没有人解决）
