InstantID单图保ID

InstantID: Zero-shot Identity-Preserving Generation in Seconds
2024.01论文延伸arXiv 2024Qixun Wang, Xu Bai, Haofan Wang, Zekui Qin, Anthony Chen, Huaxia Li, Xu Tang, Yao Hu · InstantX团队 / 小红书 / 北京大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

让生成图里出现指定的人：DreamBooth、LoRA要多张照片和微调；基于CLIP图像特征的IP-Adapter只要一张图，但人脸像不像很难保证。

方法

用人脸识别模型的身份特征替代CLIP特征注入交叉注意力，再加一个以五个面部关键点为空间条件、以身份特征为条件的ControlNet分支（IdentityNet）。

影响

一张照片、无需微调即可生成高度相似的各种风格人像，兼容社区SDXL模型，成为AI写真与人物一致性工作流的常用插件。

方法

个性化生成（DreamBooth与个性化、文本反演、LoRA微调扩散模型）效果好但每个人都要单独训练。IP-Adapter图像提示把参考图的CLIP特征通过解耦交叉注意力注入扩散模型，免去训练，但CLIP特征偏语义，对人脸身份的刻画很粗。

InstantID有三个部件：

  • ID嵌入：用预训练人脸识别模型（ArcFace一类）提取身份向量，替代CLIP图像特征。
  • 图像适配器：沿用IP-Adapter的解耦交叉注意力，但输入换成ID嵌入。
  • IdentityNet：一个ControlNet式分支，空间条件只给两眼、鼻尖、两嘴角五个关键点，交叉注意力条件用ID嵌入而非文本，避免身份信号被背景描述稀释。

基础模型SDXL保持冻结，只训练适配器和IdentityNet，训练数据为LAION-Face约5000万图文对加约1000万张人像。冻结底模意味着它能直接套用到社区微调的SDXL模型上。

局限与后续

  • 只针对人脸身份，对服装、全身外观和非人物主体的一致性无能为力。
