TensorRT-LLM

2023.10系统延伸2023NVIDIA待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

TensorRT的通用推理优化不理解自回归解码、KV缓存和批处理，在GPU上高效服务大模型需要专门的内核和调度。

方法

在TensorRT之上提供面向LLM的库：定制注意力和矩阵乘内核、运行时优化与低精度量化，并提供Python接口。

影响

成为NVIDIA GPU上官方的LLM推理优化栈，与vLLM与PagedAttention等开源引擎竞争。

方法

README称TensorRT-LLM是NVIDIA开源的、面向LLM和视觉生成模型的GPU推理优化库，提供Python的LLM API和用于构建Python与C++运行时的组件，现基于PyTorch。页面提到的能力包括：针对注意力、GEMM和MoE的定制内核；预填充与解码分离、宽专家并行、推测解码等运行时优化；FP8、FP4等量化；KV缓存压缩，以及NVFP4的4位KV缓存存储。许可为Apache 2.0。页面未明确提到in-flight batching和paged KV cache，这里不做断言。2023年首次发布的细节未核实。
