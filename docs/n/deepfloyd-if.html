DeepFloyd IF

2023.04模型延伸DeepFloyd（Stability AI研究实验室）· Stability AI待核对
Stability AI公告 ↗在交互版中打开（演化树、学习进度）

问题

文生图模型难以在图里写出正确的文字，对提示词中复杂的空间关系理解也弱。

方法

用大型语言模型T5-XXL做文本编码器，并在像素空间用三级级联扩散生成图像。

影响

展示了「强文本编码器」对文字渲染和提示词理解的价值，影响了后来的文生图设计。

方法

2023年4月28日，Stability AI及其研究实验室DeepFloyd公布DeepFloyd IF的研究版发布。它是一个级联的像素扩散模型，沿用Imagen的思路：先生成低分辨率图，再逐级用超分扩散模型放大。

关键设计是文本编码器用T5-XXL-1.1（见T5），并在多处加入文本与图像的交叉注意力。官方称这使它能生成清晰连贯的文字，并更好处理物体的空间关系。官方还给出COCO数据集上的零样本FID为6.66。

它以非商业、允许研究的许可证发布，Stability AI表示将来某个时间会完全开源。

后来的发展

后来的Stable Diffusion 3等模型也都改用大型文本编码器，文字渲染成为文生图的标配指标；级联像素扩散本身则被潜空间方案取代。

局限与后续

  • 在像素空间做多级级联，推理和训练开销都远高于潜空间模型。
