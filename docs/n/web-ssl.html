Web-SSL无语言视觉扩展

Scaling Language-Free Visual Representation Learning
2025.04论文延伸David Fan, Shengbang Tong, Jiachen Zhu, Koustuv Sinha, Zhuang Liu, Xinlei Chen, Michael Rabbat, Yann LeCun, Amir Bar, Saining Xie · Meta FAIR / NYU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉自监督模型在多模态任务（如视觉问答）上不如CLIP，大家归因于缺少语言监督，却忽略了两者训练数据不同。

方法

在同样的MetaCLIP数据上同时训练视觉自监督与CLIP，用视觉问答等任务做受控比较，并把自监督模型放大到7B参数。

影响

证明纯视觉自监督在规模足够大时可以追平语言监督，打开了不依赖文本的视觉表征路线。

方法

论文提出的问题是：差距来自缺少语言，还是来自数据不同？作者把视觉自监督（Web-SSL，沿用DINOv2一类方法）和CLIP放在同一份MetaCLIP数据上训练，用视觉问答作为多样的测试平台。

结果（摘要）：在这个受控设置下，视觉自监督模型随数据量和模型容量增长的扩展性比CLIP好，直到7B参数也没有饱和；因此在多种视觉问答和经典视觉基准上达到CLIP水平。这说明差距主要来自数据，而不是语言本身。

局限与后续

  • 评测集中在视觉问答与分类，对语言监督在细粒度语义对齐上的作用没有完全回答。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 训练7B级别模型需要极大规模数据与算力，普通实验室难以复现。
