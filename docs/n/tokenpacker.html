TokenPacker视觉投影器

TokenPacker: Efficient Visual Projector for Multimodal LLM
2024.07论文延伸IJCV 2025Wentong Li, Yuqian Yuan, Jian Liu, Dongqi Tang, Song Wang, Jie Qin, Jianke Zhu, Lei Zhang · 浙江大学 / 香港理工大学等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

多模态大模型常用简单MLP做投影，一对一保留全部视觉token，高分辨率时token暴增；用重采样器或抽象器减少token又会丢掉细节、损害视觉推理。

方法

由粗到细的投影器：先把视觉特征插值缩小，得到低分辨率的点查询作为整体表示；再用区域到点注入模块，以高分辨率多层特征中对应局部区域作为键和值，把细节注入每个点查询。

影响

视觉token压缩75%到89%，在多种基准上与原模型相当甚至更好，效率显著提高。

方法

连接视觉编码器和语言模型的投影器有两类做法：LLaVA-1.5的MLP一对一映射，保留全部token；BLIP-2的Q-Former、Honeybee局部投影器的C-Abstractor等重采样器把token压成固定数量，但压缩后细节丢失，影响需要细粒度信息的推理。

TokenPacker采用由粗到细的方案。粗：把视觉编码器输出的特征图做双线性插值降采样（例如缩到原来的1/2或1/4边长），每个位置作为一个低分辨率“点查询”，提供整体视觉表示的基础。细：区域到点注入模块，为每个点查询找到它在原高分辨率特征图（以及多层特征）中对应的局部区域，把这些区域特征作为键和值，通过局部交叉注意力让点查询充分吸收自己区域内的细节，从而把粗略的查询更新为信息丰富的查询，再送进语言模型。

摘要报告该方法把视觉token压缩75%到89%，在多种基准上取得可比甚至更好的性能，效率明显提高。
