GTX 1080 Ti与平民研究

2017.03硬件延伸NVIDIA待核对
维基百科：GeForce 10系列 ↗在交互版中打开（演化树、学习进度）

问题

2017年前后做深度学习的学生和小团队买不起数据中心GPU，需要一张价格可负担又足够快的卡。

方法

GeForce GTX 1080 Ti基于Pascal架构，是当时消费级里最强的一张卡，容量和带宽足以训练主流的卷积网络。

影响

‘买一张游戏卡自己训练’成了研究生和创业团队的默认方案，也是后来RTX 3090：24GB显存、RTX 4090与本地大模型走向本地大模型的先声。

方法

GeForce 10系列基于Pascal微架构，据维基百科，GTX 1080与1070于2016年5月宣布，使用TSMC 16nm FinFET工艺（见FinFET三维晶体管）。1080 Ti是同一架构的顶配，2017年3月发布（具体显存与价格来自记忆，本次未核对）。

它和GTX 580：AlexNet的显卡在深度学习史上的位置相似：并非为AI设计，却因为CUDA可以直接使用，成为实验室的主力。游戏卡不带ECC，双精度很弱，但神经网络训练只需要单精度，所以够用。

后来的发展

2017至2019年间，许多论文复现和课程作业默认用的就是一张或几张1080 Ti。它的价格和显存也定下了此后消费卡在AI社区的预期：显存是否够大，比算力更决定能不能跑一个模型。

局限与后续

  • 消费卡显存有限，放不下更大的模型。
    后来针对它的工作　RTX 3090：24GB显存
  • 缺少V100那样的矩阵乘专用单元（Tensor Core），半精度吞吐落后。
    后来针对它的工作　Turing：消费级Tensor Core
