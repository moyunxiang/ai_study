R1正则与GAN收敛性

Which Training Methods for GANs do actually Converge?
2018.01论文延伸ICML 2018Lars Mescheder, Andreas Geiger, Sebastian Nowozin · MPI Tübingen / 图宾根大学 / Microsoft Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GAN训练常常来回振荡不收敛，大家提出了WGAN-GP梯度惩罚、加噪声等很多稳定技巧，但哪些真的能让训练收敛到平衡点，并没有清楚的答案。

方法

在一个只有两个参数的极简例子上分析各种训练方法的局部收敛性，发现零中心的梯度惩罚才能保证收敛，并据此提出只在真实数据上惩罚判别器梯度的R1正则。

影响

R1正则此后成为StyleGAN、StyleGAN2、StyleGAN2-ADA小数据训练及R3GAN现代GAN基线等主流GAN的默认正则项，“判别器梯度在真实数据处应接近零”成了GAN训练的常识。

方法

作者构造了一个“Dirac-GAN”：真实分布是落在0点的一个点，生成器只学一个位置参数θ，判别器是线性函数D(x)=ψx。这个二维系统可以直接分析：用普通GAN目标做同时梯度下降时，(θ, ψ)绕着平衡点打转，学习率不够小就会发散；也就是说，当数据分布不是绝对连续（真实图像本就分布在低维流形上）时，不加正则的GAN训练一般不收敛。用同样的工具检查发现，WGAN和WGAN-GP在判别器每轮只更新有限次时也不一定收敛，而实例噪声和零中心梯度惩罚可以收敛。

由此提出的R1正则只对真实样本施加：R1(ψ) = (γ/2)·E_{x∼p_data}[‖∇_x D_ψ(x)‖²]。直观含义是：在真实数据所在的地方，判别器的函数面应该是平的，不应该有陡峭梯度把生成器推来推去。对称的R2正则则在生成样本上施加。作者证明这些简化的梯度惩罚即使在数据与生成分布位于低维流形上时也局部收敛，并用它在多个数据集上训练高分辨率GAN，几乎不用调超参数。

局限与后续

  • 只给出平衡点附近的局部收敛保证，不能解释或避免全局的模式坍塌。

它建立在什么之上

  • 改进
    生成对抗网络GAN2014.06 · 生成
    给出原始GAN目标在非绝对连续分布下不收敛的反例，并用R1正则恢复局部收敛。
  • 竞争
    WGAN-GP梯度惩罚2017.03 · 生成
    同为梯度惩罚，WGAN-GP把梯度范数推向1，本文分析指出它不一定收敛，主张推向0。
  • 改进
    Unrolled GAN展开优化2016.11 · 生成
    每次生成器更新都要额外展开K步判别器并通过它们反向传播，计算和显存开销随K线性增长，难以用在大模型上。
  • 竞争
    Wasserstein GAN2017.01 · 生成
    论文用同一分析框架检查WGAN，指出有限次判别器更新时不保证收敛。

后来的相关工作

  • 改进
    StyleGAN22019.12 · 生成
    每步都要对输入求二阶相关的梯度，计算开销不小；StyleGAN2后来用每隔若干步才算一次的“惰性正则”来省算力。

本篇术语

  • Dirac-GAN　真实分布只是一个点、生成器和判别器各只有一个参数的玩具GAN，用来直接看清训练动态是否收敛。
  • 零中心梯度惩罚　惩罚判别器对输入的梯度范数的平方，使它在数据点附近接近0；区别于WGAN-GP把梯度范数拉向1。

怎么学

先懂GAN的极小极大目标与梯度下降 → 读原文第2节Dirac-GAN示例和第4节R1定义 → 在一个小GAN里加一行R1正则观察训练曲线。
