Hale惊奇度理论

A Probabilistic Earley Parser as a Psycholinguistic Model
2001.06论文延伸NAACL 2001（2026年ACL时间检验奖）John Hale · 约翰斯·霍普金斯大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

人读句子时某些词会让人「卡一下」（花园路径句「The horse raced past the barn fell」读到fell时会愣住）。心理语言学有很多解释，但缺少一个能从语法出发、对每个词给出可计算的「加工难度」的统一度量。

方法

把每个词的加工难度定义为它的惊奇度：surprisal(w_i) = −log P(w_i | w_1…w_{i−1})，即在已读前缀下它有多出乎意料；用概率上下文无关文法的概率Earley分析器计算前缀概率，从而得到每个词的惊奇度。

影响

这篇短文奠定了「惊奇度理论」：后来大量眼动、阅读时间和脑电研究证实惊奇度能预测人的阅读难度。神经语言模型出现后，用语言模型算惊奇度成为心理语言学的标准工具；论文获2026年ACL时间检验奖。

背景

Earley句法分析算法（1970）能高效地对上下文无关文法做自左向右的句法分析；Stolcke（1995）把它扩展为概率版本，可以算出任意前缀在概率上下文无关文法PCFG下的概率 P(w_1…w_i …)，即所有以该前缀开头的句子的概率之和。心理语言学这边，花园路径句、关系从句的难度差异等现象主要用基于句法结构的启发式理论解释（如最小附着原则），这些理论难以定量预测每个词的阅读时间。

方法

前缀概率：设 α_i = P(w_1 … w_i …) 是长度为i的前缀在PCFG下的总概率（所有以它开头的完整句子的概率之和）。概率Earley分析器在逐词读入时维护所有可能的部分分析及其概率，读完第i个词时可直接得到 α_i。

惊奇度：第i个词的条件概率是两个前缀概率之比，惊奇度取其负对数：

surprisal(w_i) = −log ( α_i / α_{i−1} ) = log α_{i−1} − log α_i

直观理解：读到第i个词时，有一部分原本可能的分析被排除了，被排除的概率质量越大，这个词越「惊奇」，读者的加工负担越重。

例子：在花园路径句中，读到raced时最可能的分析是「马跑过谷仓」（主句动词），读到fell时这一分析被否定，只剩概率很小的「被赶着跑过谷仓的那匹马倒下了」（缩减关系从句），fell的惊奇度因此很高，与人在此处的阅读困难一致。Hale用一个小语法在若干经典句型上演示了这一点。

结果

论文用小规模手写PCFG计算了几类经典心理语言学句型（花园路径句、主语与宾语关系从句）中逐词的惊奇度，定性地复现了人类阅读难度的差异；没有大规模定量数字。

后来的发展

Levy（2008）证明惊奇度等价于读入一个词后对句子结构信念分布的KL散度变化，并用更多实验支持该理论；此后Smith与Levy等用大规模阅读时间语料发现阅读时间与惊奇度近似成线性关系。神经语言模型时代，研究者用LSTM和Transformer语言模型计算惊奇度来预测阅读时间和脑信号，并讨论「更好的语言模型是否更像人」；不可能语言实验等工作也用惊奇度分析模型学到的语言结构。

本篇术语

  • 惊奇度（surprisal）　一个词在上下文中的负对数条件概率 −log P(词|前文)，越大表示越出乎意料；心理语言学用它预测阅读时的加工难度。
  • 花园路径句　读到中途会把人引向错误理解、直到后面某个词才发现必须重新分析的句子，例如The horse raced past the barn fell。
  • 前缀概率　在一个概率文法下，所有以给定词串开头的完整句子的概率之和。

怎么学

先复习信息量与熵和概率上下文无关文法PCFG → 读原文（很短）第2–4节 → 动手：用GPT-2计算一句花园路径句每个词的惊奇度，画出曲线，看峰值是否落在fell上。
