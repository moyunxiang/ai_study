World Models

World Models
2018.03论文主干David Ha, Jürgen Schmidhuber · Google Brain / NNAISENSE / IDSIA来源已核对
arXiv ↗交互式论文 ↗在交互版中打开（演化树、学习进度）

问题

无模型强化学习直接从像素学策略，要和环境交互数百万次，网络大而难训；智能体也无法像人一样先在脑中“想象”动作后果再行动。

方法

把智能体拆成三块：VAE把每帧画面压缩成一个小向量，MDN-RNN学习预测下一时刻的向量（世界模型），一个只有几百个参数的线性控制器在压缩表示上做决策，甚至完全在模型生成的“梦境”里训练。

影响

在像素游戏上把“学一个生成式世界模型，在想象中训练策略，再迁移回真实环境”完整跑通；之后的PlaNet、Dreamer等工作引用了它，“世界模型”一词也被视频生成与具身智能领域广泛使用。

背景

2013年起，DQN和A3C等深度强化学习方法已能从像素直接学会玩游戏，但它们是无模型的：不学习环境如何运作，只通过大量试错拟合动作的价值或策略。这带来两个问题。一是样本效率低，需要海量交互。二是信用分配困难：奖励信号稀疏，用它去训练一个几百万参数的网络效率很低。

用模型学习和规划的想法并不新。Dyna：学习与规划合一（1990）用学到的模型生成想象经验来辅助学习；Schmidhuber在1990年前后提出用循环网络学习环境模型、再训练控制器的方案（Schmidhuber可微世界），但当时的网络规模只能处理很简单的问题。到2018年，变分自编码器VAE能把图像压缩成有意义的潜变量，LSTM能建模长序列，两者结合起来，就有可能为像素游戏学出一个可用的“世界模型”。

方法

智能体由三个部分组成，按顺序分别训练。

V（视觉）：先让随机策略玩10,000局，收集画面。把每帧缩放到64×64，训练一个卷积变分自编码器VAE（见潜空间），把画面编码成一个潜向量z，赛车任务中z是32维。

M（记忆/世界模型）：一个LSTM加混合密度网络输出层（MDN-RNN），预测P(z_{t+1} | a_t, z_t, h_t)，其中h_t是LSTM的隐状态。输出不是一个确定的z，而是5个高斯分量的混合分布，因为未来本来就有不确定性（比如怪物何时开火）。采样时用温度参数τ调节随机性。赛车任务的LSTM有256个隐藏单元。

C（控制器）：一个线性函数a_t = W_c [z_t, h_t] + b_c。赛车任务里输入是32 + 256 = 288维，输出3个连续动作（转向、油门、刹车），共288×3 + 3 = 867个参数。参数这么少，就可以用不需要梯度的进化策略CMA-ES来优化，它直接以每局总得分为目标，许多局并行评估。

在梦境中训练。由于M可以根据当前z和动作采样出下一个z（以及是否死亡），它本身就构成一个虚拟环境。在VizDoom“躲火球”任务中，控制器完全在M生成的梦境里训练，然后直接放到真实游戏中测试。

结果

CarRacing-v0（俯视赛车）：100局平均得分906 ± 21，达到了该环境“100局平均900分”的解决标准；论文表1中的对比为DQN 343 ± 18、A3C（连续动作）591 ± 45、A3C（离散动作）652 ± 10、此前Gym排行榜最好成绩838 ± 11。只用V不用M时为632 ± 251，V加一个隐藏层为788 ± 141，说明加入M预测未来的隐状态h在这个任务上很有帮助。

DoomTakeCover（存活超过750步算解决）：完全在梦境中训练，迁移到真实游戏后，τ = 1.15时得分1092 ± 556，高于Gym排行榜的820 ± 58；随机策略约210。温度太低时会出问题：τ = 0.1时梦中的怪物几乎从不发射火球，控制器在梦里得到2086分，回到真实游戏却只有193分，比随机还差。控制器学会了钻世界模型的漏洞。

后来的发展

之后的工作把V、M、C三块放到一起联合训练：PlaNet在学到的潜空间里用规划代替控制器，Dreamer在潜空间想象中用演员—评论家训练策略（Dreamer在相关工作中把本文描述为“两阶段学潜在动态、在想象中进化线性控制器”），DreamerV3把这一套推广到150多个任务；SimPLe与Atari 100k把在世界模型里训练用到Atari。MuZero走了另一条路，只学预测价值和奖励所需的模型。

“世界模型”一词随后用到了强化学习之外：JEPA与LeCun的世界模型路线把它当作通向自主智能的核心组件；Genie、GameNGen、Genie 3等用大规模视频生成模型学出可交互的游戏世界（Genie论文把这类生成式交互环境称为世界模型的一类，并引用本文）；Cosmos世界基础模型和DreamZero与世界动作模型WAM等则把视频模型用于机器人。这些工作共享的想法是学一个能预测动作后果的模型，但具体预测什么（像素、隐状态还是特征）、拿来做什么，各家并不相同。

容易误解的地方

  • 这篇不是第一个提出用学到的模型训练控制器的工作，作者在文中详细讨论了Schmidhuber 1990年前后的工作；它的贡献是用VAE和MDN-RNN在像素游戏上把这套方案真正跑通并系统展示。
  • V是单独用重建损失训练的，它不知道哪些像素对任务重要，可能把大量容量花在无关的背景细节上。
  • “在梦里训练”的成功依赖温度τ的调节：梦境要足够难、足够随机，控制器才不会利用模型的错误。

它建立在什么之上

  • 使用
    LSTM1997 · 基础 已核对
    M模块用LSTM加混合密度网络输出，预测下一时刻潜向量的概率分布。
  • 使用
    变分自编码器VAE2013.12 · 生成 已核对
    V模块就是一个卷积VAE，把64×64画面压缩成32维（或64维）潜向量，作为世界模型的状态。
  • 竞争
    DQN2013.12 · RL 已核对
    论文表1中，无模型的DQN在CarRacing上为343分，世界模型方法为906分；分歧在于是否先学环境模型和压缩表示。
  • 改进
    Schmidhuber可微世界1990 · 具身·世界模型 已核对
    把Schmidhuber 1990年前后“循环网络世界模型 + 控制器”的构想，用现代的VAE与MDN-RNN在像素游戏上实现并扩大规模。
  • 竞争
    A3C2016.02 · RL 已核对
    论文表1中A3C在CarRacing上为591–652分；在这个任务上，先学压缩表示和预测模型再做决策的效果好于这些端到端无模型结果。
  • 延续
    进化策略作为RL替代2017.03 · RL 已核对
    论文引用Salimans等2017年的工作，说明进化策略可作为深度RL的替代；本文实际用的是CMA-ES而不是该文的ES算法，借助小控制器和并行评估回避了稀疏奖励下的信用分配。
  • 改进
    Dyna：学习与规划合一1990 · RL 待核对
    思路相近：Dyna用模型生成的想象经验辅助学习，这里策略可以完全在学到的生成模型中训练。论文本身没有引用Dyna。
  • 改进
    POMDP规划1998 · RL
    需要事先知道转移、观测和奖励模型，论文没有处理如何从数据中学出POMDP模型。

读懂它需要的概念

自编码器 变分推断与ELBO 潜空间 循环网络与隐状态 高斯分布 基于模型的强化学习 世界模型 马尔可夫决策过程

本篇术语

  • 混合密度网络（MDN）　神经网络不直接输出一个预测值，而是输出若干个高斯分布的权重、均值和方差，从而表达“未来可能是几种情况之一”的多峰不确定性。
  • 温度τ　采样时缩放分布随机性的参数。τ越大，世界模型生成的未来越不可预测；τ太小则模型几乎确定，容易被控制器利用。
  • CMA-ES　协方差矩阵自适应进化策略：每代从一个多元高斯中采样一批参数，按得分挑出好的，更新高斯的均值和协方差。不需要梯度，适合几千个参数以内的问题。

怎么学

先补自编码器、变分推断与ELBO（理解VAE）和循环网络与隐状态。直接读交互式论文worldmodels.github.io，可以在网页里调整z、切换温度、看梦境。然后读arXiv版第3节（赛车）和第4节（在梦中训练）以及表2。动手：用作者开源的代码或自己的PyTorch实现，在CarRacing上训练VAE并可视化重建，再训练MDN-RNN，观察“梦”的质量如何随训练数据量变化。
