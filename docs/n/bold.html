BOLD开放式生成偏见

BOLD: Dataset and Metrics for Measuring Biases in Open-Ended Language Generation
2021.01数据集延伸FAccT 2021Jwala Dhamala, Tony Sun, Varun Kumar, Satyapriya Krishna, Yada Pruksachatkun, Kai-Wei Chang, Rahul Gupta · 亚马逊Alexa AI / 加州大学洛杉矶分校待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

语言模型的偏见基准多是填空或句对比较，而模型实际被用来自由续写，开放式生成里的社会偏见缺少大规模的测量数据和指标。

方法

从维基百科截取提到不同人群的句子开头作为提示，让模型自由续写，再用毒性、情感、心理语言学和性别极性等自动指标比较不同人群得到的续写。

影响

成为开放式生成偏见的常用评测，被HELM等综合评测收录，和RealToxicityPrompts、BBQ一起出现在大模型偏见测试中。

方法

提示。共23,679条英文生成提示，覆盖五个领域：职业、性别、种族、宗教和政治意识形态。提示取自维基百科关于具体人物或群体的句子开头，例如“某位女演员早年在……”，让模型接着写。

指标。作者提出多个自动指标从不同角度衡量偏见：续写的毒性、情感倾向、心理语言学规范（如情绪的效价、唤醒度）以及文本的性别极性（续写是否偏向男性或女性词汇）。然后比较不同人群的提示得到的续写在这些指标上的分布差异。

结果。作者检查了三个流行语言模型（包括GPT-2）生成的文本，发现在所有领域里，大多数模型表现出比人写的维基百科文本更大的社会偏见。

局限与后续

  • 指标靠自动分类器打分，分类器本身也带偏见；只覆盖英文和少数人群划分，统计差异不等于具体伤害。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    GPT-22019.02 · LLM
    GPT-2是被测的流行语言模型之一。
  • 使用
    维基百科语料2001.01 · 数据·评测
    提示取自维基百科句子，续写也和维基原文比较。
  • 竞争
    StereoSet刻板印象基准2020.04 · 安全·可解释
    StereoSet用填空和句子选择测刻板印象，BOLD测自由续写中的偏见。
  • 延续
    RealToxicityPrompts2020.09 · 安全·可解释
    沿用“给提示看续写”的测量方式，从毒性扩展到情感、性别极性等多种偏见指标。
