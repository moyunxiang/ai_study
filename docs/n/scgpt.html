scGPT

scGPT: toward building a foundation model for single-cell multi-omics using generative AI
2023.05论文延伸Nature Methods 2024（bioRxiv 2023-05）Cui, Wang, Maan, Pang, Luo, Duan, Wang · University of Toronto, Vector Institute, UHN待核对
bioRxiv ↗Nature Methods ↗在交互版中打开（演化树、学习进度）

问题

单细胞数据分析一般对批次整合、细胞类型注释、扰动预测等任务各用一个工具，彼此不通用。

方法

仿照GPT的生成式预训练，在大规模单细胞数据上预训练统一模型，再微调到多类下游任务，并支持多组学。

影响

与Geneformer单细胞模型同属第一批单细胞基础模型，推动了此类模型的开源与基准比较。

方法

scGPT把基因当作词、细胞当作句子，但与Geneformer单细胞模型的排序编码不同，它保留表达量：把基因表达量分箱成离散值，与基因身份嵌入相加后输入Transformer。预训练用的是一种适配非序列数据的“生成式”目标——随机遮住一些基因，按注意力顺序迭代预测其表达量，而不是严格的从左到右。

预训练后，同一个模型经过微调可用于批次整合、细胞类型注释、扰动响应预测和基因网络推断，并可扩展到ATAC等其他组学。

后来的发展

之后出现了大量单细胞基础模型，同时也有独立评测发现在零样本设定下它们并不总是超过简单方法；这一争论目前尚无定论。
