VTLN声道长度归一化

Speaker normalization using efficient frequency warping procedures
1996.05论文延伸ICASSP 1996Li Lee, Richard C. Rose · AT&T贝尔实验室待核对
IEEE ↗在交互版中打开（演化树、学习进度）

问题

男人、女人、儿童的声道长度不同，同一个元音的共振峰频率会整体偏移十几到几十个百分点，说话人无关模型被这种系统性差异拖累。

方法

给每个说话人估一个频率弯折因子α，在提取特征时把频率轴整体拉伸或压缩，使不同人的频谱对齐到一个「平均声道」上；α用识别模型的似然在一小组候选值里搜索。

影响

声道长度归一化（VTLN）成为GMM-HMM大词汇量系统的标准前端步骤，几乎所有评测系统都用它，并写进了HTK和Kaldi的配方。

方法

按照语音产生的「源-滤波器」模型，元音的共振峰频率大致与声道长度成反比。成年女性的声道平均比男性短，儿童更短，因此同一个音素在她们的频谱上整体向高频移动。MLLR说话人自适应等自适应方法用通用的线性变换间接吸收这种差异，但这种差异本身有很简单的物理形式：频率轴的伸缩。

Lee和Rose提出的做法是：在计算梅尔滤波器组（见MFCC特征）时，把频率f替换为αf（实际中用分段线性函数，避免高频端越界），α通常在0.88到1.12之间按0.02步长取值。训练时，对每个训练说话人逐个尝试候选α，选使当前HMM模型似然最大的那个，用归一化后的特征重新训练模型，并可迭代几轮；测试时先用未归一化的特征做一遍识别得到粗略文本，再据此为新说话人搜索α。论文的关键贡献在于把这种搜索做得高效，只需要计算少量候选的似然。

文中报告VTLN在电话语音识别任务上带来稳定的错误率下降（具体数字未核对）。由于只有一个参数，它只需极少量数据就能估计，常与SAT说话人自适应训练、fMLLR约束线性变换组合使用。

  • 只用一个全局伸缩因子描述说话人差异，无法刻画口音、发音习惯等其他差异。
