COMET译文质量评估

COMET: A Neural Framework for MT Evaluation
2020.09论文延伸Rei, Stewart, Farinha, Lavie · Unbabel / INESC-ID / Carnegie Mellon University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BLEU和BERTScore只比较译文与参考译文的表面或语义相似度，没有用源句，也没有直接学习人类打的质量分，和人工评价的相关性有限。

方法

用跨语言预训练模型把源句、译文、参考译文一起编码，再回归预测人工评分，把评估指标变成可训练的模型。

影响

成为机器翻译评测的主流神经指标，WMT评测和大量翻译论文都采用它。

方法

COMET是一个训练多语言翻译评估模型的框架。它利用跨语言预训练语言模型（如XLM-R一类）分别编码源句、候选译文和人工参考译文，同时利用源句与参考信息去预测译文质量。论文用三种人工判断数据训练了三个模型：直接评估（Direct Assessments）、人工介导的翻译编辑率（HTER）和多维质量指标（MQM）。

据摘要，这些模型在WMT 2019指标评测任务上与人工判断的相关性达到当时最好，并且在高质量系统之间区分时依然稳健。

局限与后续

  • 需要人工标注的质量分来训练，分数是黑盒的，难以解释哪里错了。
    后来针对它的工作　LLM-as-a-Judge与MT-Bench
  • 在训练数据没覆盖的语言对、领域上，评分的可靠性没有保证。
    后来针对它的工作　FLORES-101 NLLB两百种语言翻译

它建立在什么之上

  • 改进
    BLEU2002.07 · 数据·评测
    BLEU与人工评价相关性不足，COMET显著提高了与人工判断的相关性。
  • 使用
    WMT机器翻译评测2006.06 · 数据·评测
    在WMT人工评价数据与指标评测任务上训练和检验。
  • 改进
    BERTScore2019.04 · 数据·评测
    BERTScore免训练地比较向量，COMET进一步用人工评分训练并加入源句。
