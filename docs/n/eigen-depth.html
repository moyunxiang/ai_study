单图深度预测

Depth Map Prediction from a Single Image using a Multi-Scale Deep Network
2014.06论文延伸NeurIPS 2014Eigen, Puhrsch, Fergus · NYU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

从单张图预测深度没有几何线索，尺度又有歧义，传统方法依赖超像素和手工特征。

方法

用两个网络堆叠：先对整图做粗略的全局深度预测，再用一个局部网络细化；并提出尺度不变误差。

影响

是用CNN做单目深度估计的开端，尺度不变损失成为之后该方向的标准指标。

方法

网络分两级。粗尺度网络看整张图，包含全连接层，以获得全局信息（如房间布局、地面在哪里），输出低分辨率深度图。细尺度网络再看原图，并把粗预测作为额外输入，在局部细化出边缘清晰的结果。

单张图的绝对尺度本来就无法确定（同一幅图可能是近处的小房间或远处的大房间），所以论文使用尺度不变误差，衡量深度的相对关系而不是整体尺度。训练数据直接使用原始的RGB-D数据集，不需要超像素。摘要称在NYU Depth和KITTI上取得当时最好结果。

  • 需要带真值深度的数据，采集昂贵且场景有限。

它建立在什么之上

  • 使用
    AlexNet2012.09 · 视觉
    粗尺度网络沿用AlexNet式的卷积结构，并在其上加全连接层。
  • 改进
    Marr《视觉》1982 · 视觉
    从单张图像恢复2.5维草图（深度、法向）在理论上是病态问题，书里给出的各个模块精度有限、彼此难以融合。
  • 改进
    《多视图几何》2000 · 视觉
    不包含从单张图推断深度的能力，需要多视图才能恢复尺度之外的结构。

后来的相关工作

  • 改进
    自监督单目深度2016.09 · 视觉
    去掉了对真值深度标注的依赖，改用立体图像的重建误差监督。
  • 竞争
    SfMLearner自监督深度2017.04 · 视觉
    Eigen等用深度真值监督回归；SfMLearner用视图合成误差代替真值。
  • 改进
    DORN序数回归深度2018.06 · 视觉
    Eigen等用回归损失直接预测深度，收敛慢；DORN改成按间隔递增区间的序数回归。
  • 改进
    MiDaS混合数据集深度2019.07 · 视觉
    把单目深度从单一数据集上的监督回归扩展到跨数据集混合训练。
  • 延续
    AdaBins自适应区间2020.11 · 视觉
    同属监督式单图深度估计，沿用NYU与KITTI的评测设定。
  • 改进
    DPT稠密预测ViT2021.03 · 视觉
    预测结果偏模糊，泛化到训练域以外的场景较差。
  • 延续
    Metric3D度量深度2023.07 · 视觉
    延续单图回归深度的路线，从单一数据集的度量深度推广到跨相机零样本。
  • 改进
    Depth Anything2024.01 · 视觉
    预测结果偏模糊，泛化到训练域以外的场景较差。
