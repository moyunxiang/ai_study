DiffuCoder代码扩散模型

DiffuCoder: Understanding and Improving Masked Diffusion Models for Code Generation
2025.06论文延伸Shansan Gong, Ruixiang Zhang, Huangjie Zheng, Jiatao Gu, Navdeep Jaitly, Lingpeng Kong, Yizhe Zhang · Apple / 香港大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

代码需要全局规划和反复修改，看起来适合扩散模型，但扩散模型写代码时到底怎么解码、怎么做强化学习，几乎没人系统研究过。

方法

从Qwen2.5-Coder转换出7B代码扩散模型，用它分析解码有多“像自回归”，并提出用互补掩码降低方差的coupled-GRPO。

影响

给出了扩散模型写代码的第一份系统剖析和一个开源7B模型，coupled-GRPO是此后dLLM强化学习里常被提到的一种降方差做法。

方法

作者沿用DiffuLLaMA自回归转扩散的思路，从Qwen2.5-Coder的7B权重出发，在代码语料上继续预训练、退火和指令微调，有效训练量约130B token，得到DiffuCoder。

分析部分定义了AR-ness指标：每一步新揭开的词是否紧接在已生成内容之后、是否总是最靠左的掩码位置。结论有两条：扩散模型能自己决定生成多“因果”，不必硬套半自回归解码；而提高采样温度不仅让选词更多样，也让生成顺序更多样，这给强化学习的采样提供了更丰富的搜索空间。

强化学习部分针对d1扩散模型推理RL似然估计方差大的问题提出coupled-GRPO：对同一个回答构造一对互补的掩码，两次前向合起来恰好覆盖每个位置一次，用它估计逐词对数概率，方差更小且计算量可控。在EvalPlus上，coupled-GRPO让指令版从63.6提高到67.9（+4.4），并减少了解码时对从左到右顺序的依赖。
