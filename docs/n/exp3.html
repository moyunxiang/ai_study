对抗老虎机EXP3

The Nonstochastic Multiarmed Bandit Problem
2002论文延伸SIAM Journal on Computing 2002（FOCS 1995）Peter Auer, Nicolò Cesa-Bianchi, Yoav Freund, Robert E. Schapire待核对
SIAM ↗在交互版中打开（演化树、学习进度）

问题

此前的老虎机算法都假设奖励来自固定分布，如果奖励是由对手任意（甚至针对算法）设定的，就没有保证。

方法

提出EXP3：按权重的指数函数随机选臂，用重要性加权估计每个臂的奖励，证明在任何奖励序列下，遗憾都有次线性上界。

影响

对抗老虎机的标准算法，推荐、在线广告和博弈学习（如CFR的理论）里常用。

方法

EXP3全名Exponential-weight algorithm for Exploration and Exploitation。每个臂维护一个权重，每轮按权重的比例（混入一点均匀探索）随机选臂。选中臂得到奖励后，用奖励/被选中的概率来更新它的权重，这是重要性加权，让没被选中的臂的估计保持无偏。权重按奖励指数地增长。

论文证明：对任意奖励序列（不必来自分布），总遗憾的量级是√T乘以臂数的小因子，因此平均遗憾随T增大趋于0。这与Lai–Robbins遗憾下界的随机环境下的对数遗憾不同：对抗环境的代价更高，但不需要任何分布假设。

后来的发展

对抗设定的在线学习成为独立的研究方向，与反事实遗憾最小化CFR里的遗憾最小化思想相通；上下文老虎机方向见LinUCB上下文老虎机。

它建立在什么之上

  • 延续
    多臂老虎机问题1952 · RL
    把老虎机从固定分布推广到对抗设定。
  • 改进
    Gittins指数1979 · RL
    要求各臂相互独立，且是折扣无限期的情形；臂之间有关联或环境会变化时不再最优。
  • 竞争
    Lai–Robbins遗憾下界1985 · RL
    随机环境下对数遗憾与对抗环境下根号遗憾的对照。
