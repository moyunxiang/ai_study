ProtTrans

ProtTrans: Towards Cracking the Language of Life's Code Through Self-Supervised Deep Learning and High Performance Computing
2020.07论文延伸IEEE TPAMI 2021Ahmed Elnaggar, Michael Heinzinger, Burkhard Rost 等 · 慕尼黑工业大学 / Google / ORNL待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

蛋白质语言模型刚起步，规模小，且主要靠进化信息（多序列比对）才能做好预测。

方法

在高性能计算机上把多种NLP模型（BERT、T5等）训练在数十亿到数千亿氨基酸的序列上，检验其嵌入能否不靠进化信息预测蛋白质性质。

影响

证明大规模语言模型的嵌入可以替代昂贵的数据库搜索，为后来的ESM系列蛋白模型提供对照。

方法

作者训练了六个语言模型：两个自回归（Transformer-XL、XLNet）和四个自编码（BERT、Albert、Electra、T5），数据来自UniRef和BFD，最多约3930亿个氨基酸。训练用了Summit超级计算机的5616块GPU，以及最多1024核的TPU Pod。

据摘要，嵌入能捕捉到一些生物物理性质；逐残基的三态二级结构预测准确率为81%到87%，逐蛋白的十类亚细胞定位准确率81%，膜蛋白与水溶蛋白二分类91%；ProtT5嵌入在逐残基任务上不用进化信息就超过了此前方法。

局限与后续

  • 只用单条序列，难以替代三维结构预测所需的信息；模型很大，推理成本高。
