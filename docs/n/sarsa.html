SARSA

On-Line Q-Learning Using Connectionist Systems
1994论文延伸剑桥大学技术报告 1994Gavin Rummery, Mahesan Niranjan · 剑桥大学待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

Q学习用下一状态的最大值作目标，学的是最优策略的价值，与实际带探索的行为不一致，在有风险的环境里可能很危险。

方法

改成用实际选择的下一个动作的Q值来更新：Q(s,a) ← Q(s,a) + α[r + γQ(s',a') − Q(s,a)]，学的是正在执行的策略的价值。

影响

给出了经典的同策略时序差分控制算法，名字SARSA取自(s,a,r,s',a')五元组。

方法

SARSA的更新用到一个五元组：当前状态s、动作a、奖励r、下一状态s'和下一个动作a'，名字也由此而来。与Q-learning对比：Q学习的目标是r + γ·max Q(s',·)，与实际选了什么无关（离策略）；SARSA的目标是r + γ·Q(s',a')，a'是真实选出的动作（同策略），所以学到的价值包括了探索带来的风险。

经典的悬崖行走例子里，Q学习学到贴着悬崖的最短路径，探索时容易掉下去；SARSA学到较远的安全路径。论文用的是神经网络近似Q值（“在线Q学习”）。

后来的发展

同策略的思想直接延续到REINFORCE策略梯度和PPO这一类策略梯度；SARSA也是《Reinforcement Learning: An Introduction》里的标准算法。

局限与后续

  • 同策略需要用最新策略采样数据，不能重复利用历史经验。
    后来针对它的工作　DQN
  • 在非线性函数近似下没有收敛保证。
    后来针对它的工作　梯度TD（GTD/TDC）

它建立在什么之上

  • 使用
    时序差分学习1988 · RL
    更新规则就是对动作价值做TD。
  • 竞争
    Q-learning1992 · RL
    目标取实际下一动作的Q值而非最大值：Q学习是离策略，SARSA是同策略。

后来的相关工作

  • 改进
    DQN2013.12 · RL
    同策略需要用最新策略采样数据，不能重复利用历史经验。
  • 使用
    基于势函数的奖励塑形1999 · RL
    全部实验用Sarsa学习，对比有无塑形时到达终点所需的步数。
  • 使用
    Arcade学习环境ALE2012.07 · RL
    学习型基线是带资格迹的线性SARSA(λ)，配5种手工特征。
  • 竞争
    树备份与离策略资格迹2000.06 · RL
    Sarsa沿实际动作采样后续（同策略），树备份对未选动作取期望，是采样与期望两个极端。
  • 改进
    梯度TD（GTD/TDC）2009 · RL
    在非线性函数近似下没有收敛保证。
  • 改进
    Expected SARSA2009.03 · RL
    用对下一个动作的期望代替采样值，去掉SARSA目标里由动作采样带来的方差。
  • 延续
    Q(σ)多步统一算法2017.03 · RL
    把n步Sarsa作为σ=1的端点。
  • 使用
    重访ALE与粘性动作2017.09 · RL
    基准结果也包括基于线性特征的Sarsa(λ)类方法，用于和深度方法对照。
  • 使用
    视界缩减与SHARSA2025.06 · RL
    SHARSA的价值学习是n步的SARSA式备份，用数据里的实际下一动作。
