中国“百模大战”

2023.03事件延伸百度、阿里、腾讯、华为、科大讯飞、智谱、月之暗面等待核对
List of large language models（维基百科） ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT发布在2022年底爆红后，国内公司普遍担心错过这一波技术，但没有一家的产品能与之对标。

方法

2023年起，百度的文心一言、阿里的通义千问Qwen、智谱的ChatGLM-6B、月之暗面的Kimi长文本对话、百川智能的Baichuan 2等一批通用大模型陆续发布，被称为「百模大战」。

影响

形成了一个庞大的国内大模型市场，也引发了对重复建设和算力浪费的反思，最终收敛为少数几家。

方法

2023年3月，百度发布文心一言（文心一言），之后阿里、腾讯、华为、讯飞、智谱等公司相继推出自己的模型，大量创业公司也获得融资。这些模型大多先对标GPT-3和GPT-4，数量多、能力参差。

监管也同步展开：国内规定生成式AI服务需要经过备案才能面向公众开放（来自对2023年下半年《生成式人工智能服务管理暂行办法》的通行概述，本节点未逐条核对）。算力方面，受美国对高端芯片出口限制影响，训练成本和供应成为瓶颈。

后来的发展

竞争激烈后行业逐步分化：一部分走开源（见阿里千问的开源路线），一部分获得大额融资成为中国“AI六小虎”，其余则在价格战中退出或转向行业应用。2025年初的DeepSeek时刻进一步重塑了格局。
