结构化输出

Introducing Structured Outputs in the API
2024.08系统延伸官方公告 2024-08-06OpenAI · OpenAI待核对
OpenAI公告 ↗在交互版中打开（演化树、学习进度）

问题

JSON模式只能保证输出是合法JSON，不能保证字段名、类型和必填项符合程序要求，开发者只好靠提示和反复重试。

方法

API新增Structured Outputs：开发者提供JSON Schema，模型输出被约束为严格匹配该模式。

影响

让模型输出可以直接喂给程序，成为函数调用、数据抽取和智能体工作流的可靠基础。

方法

2023年的开发者大会上OpenAI推出过JSON模式，它能保证输出是合法JSON，却不保证符合某个具体结构。2024年8月6日的Structured Outputs解决这个缺口：开发者在请求中给出JSON Schema，模型的输出就会严格遵守它。接口有两种形式：在函数调用的定义里设置strict: true，或在回复格式里直接指定JSON Schema。

官方称做法包括两部分：通过约束让模型输出匹配开发者提供的模式，以及训练模型更好地理解复杂模式。官方评测中，gpt-4o-2024-08-06搭配Structured Outputs在复杂JSON模式遵循上得分100%，而gpt-4-0613不到40%（厂商自测）。

后来的发展

之后各家都提供了类似能力，开源推理引擎也加入了语法约束解码（如XGrammar结构化生成）。在《Building Effective Agents》一类实践中，结构化输出是把模型接入程序流程的基本零件。

局限与后续

  • 严格模式只保证格式，不保证内容正确：字段值仍可能是错的或幻觉。
