测试集标注错误

Pervasive Label Errors in Test Sets Destabilize Machine Learning Benchmarks
2021.03论文延伸Northcutt, Athalye, Mueller · MIT / Amazon待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人们默认公开基准的测试集标签是正确的，并据此比较模型，但没有人系统检查过测试集本身有多少错误。

方法

用置信学习算法找出可疑样本，再经众包人工验证，统计10个常用数据集测试集的标注错误率。

影响

证明主流基准的测试集平均至少有3.3%的错误，足以改变模型排名，促使人们检查和清理评测数据。

方法

作者用置信学习（confident learning）找出标签可能有误的样本，再让众包工人确认。据摘要，他们检查了10个常用的视觉、语言和音频数据集的测试集，平均至少有3.3%的标签错误；ImageNet验证集至少有6%。算法标记的候选中，平均有51%经人工确认为确实标错。

更值得注意的结论是：当错误标签比例较高时，容量较低的模型在更干净的测试集上反而可能更有用，因为大模型更容易「拟合」错标的噪声；因此按含错测试集的准确率选模型要谨慎。

局限与后续

  • 用算法找可疑样本再人工复核，仍会漏掉算法没标出的错误，真实错误率只能给下限。
