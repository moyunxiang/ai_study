最小贝叶斯风险解码MBR

Minimum Bayes-Risk Decoding for Statistical Machine Translation
2004.05论文延伸HLT-NAACL 2004Shankar Kumar, William Byrne · 约翰斯·霍普金斯大学语言与语音处理中心待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

翻译系统按最大后验概率挑出一个最可能的译文，但最终是用BLEU等指标来评价的；概率最高的那一个，未必是在评价指标下期望表现最好的那一个。

方法

最小贝叶斯风险解码：在候选译文中选出使「期望损失」最小的那个，期望按模型的后验概率在所有候选上计算，损失可以直接定义成1−BLEU或包含对齐、句法树信息的其他损失函数。

影响

把语音识别里的MBR决策方法引入统计翻译，成为系统融合和重打分的常用工具；神经翻译和大模型时代，MBR解码（配合COMET等神经指标）重新成为提升译文质量的热门方法。

方法

一般的解码规则是ê = argmax_e P(e|f)，相当于用0-1损失：只要不是完全正确的那个译文就算全错。可是两个都不完全对的译文，一个和参考译文只差一个词，另一个完全不着边，在BLEU下差别很大。

MBR把决策写成ê = argmin_{e'} Σ_e L(e, e') P(e|f)：对每个候选e'，假设真实译文按模型的后验概率P(e|f)分布，计算它的期望损失，选期望损失最小的。实际中真实译文未知，求和范围取解码器产生的n-best列表，后验概率由各候选的模型得分归一化得到。直观地说，MBR选出的是和其他高概率候选「最像」的那个，即一种加权的共识。

论文设计了一组层次化的损失函数：只看词串的（如基于BLEU的损失、词错误率），用到系统给出的词对齐的，以及用到源语言和目标语言句法树的「双语树损失」。在中英翻译任务上的实验显示，用哪种损失做MBR，就能在对应的指标上得到改进，从而可以针对特定指标调整系统。

局限与后续

  • 期望要在候选列表上两两计算损失，候选数为N时代价是O(N²)，N增大后很慢。

读懂它需要的概念

期望与方差 条件概率与贝叶斯公式 损失函数 文本生成的自动指标 解码：贪心、束搜索、温度与top-p

本篇术语

  • 期望损失　假设真实答案按模型后验概率随机分布时，选某个输出平均会付出的损失；MBR选这个值最小的输出。
  • n-best列表　解码器输出的得分最高的前n个候选译文，后续的重打分和MBR都在这个列表上进行。

怎么学

先读BLEU和最小错误率训练MERT的讲解 → 读原文第2节MBR决策规则和第3节损失函数 → 动手：用任意翻译模型采样或beam出50个候选，用句子级BLEU两两计算期望损失，比较MBR选出的译文和得分最高的译文。
