GHKM句法翻译规则

What's in a translation rule?
2004.05论文延伸HLT-NAACL 2004Michel Galley, Mark Hopkins, Kevin Knight, Daniel Marcu · 哥伦比亚大学、加州大学洛杉矶分校、南加州大学信息科学研究所待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

想把句法加进统计翻译，但早期的句法翻译模型只允许在句法树的父子节点之间调序，Fox（2002）发现大量真实翻译现象（如英语not译成法语不连续的ne…pas）落在这种模型之外。

方法

给词对齐赋予形式语义：在英语句法树和词对齐的平行句对上，用一个线性时间算法找出「边界节点」，切出能解释这对句子的最小一组树到串转换规则，规则可以跨越多层树结构。

影响

这种规则抽取方法以四位作者姓氏首字母被称为GHKM，成为串到树、树到串句法统计翻译系统（如ISI的系统和Moses的句法模式）抽取规则的标准算法。

方法

短语统计机器翻译的短语不受句法约束，Koehn等甚至发现把短语限制为句法成分会让效果变差；另一条路是Wu（1997）那样放弃语言学句法、让二叉结构随平行语料自适应。GHKM走第三条路：保留英语句法树，但允许更有表达力的转换规则。

输入是三样东西：外语句子、英语句子的句法树（由Collins词汇化句法分析器一类的分析器得到），以及两者之间的词对齐（由GIZA++与对齐模型比较的GIZA++得到）。对树上的每个节点，计算它覆盖的英语词对齐到的外语词区间（跨度）以及它的补集；如果一个节点的跨度和树中其他部分对齐到的外语词不重叠，就称为边界节点。在边界节点处把树切开，每一块就是一条规则：左边是一个带变量的英语树片段，右边是含相同变量的外语串。例如一条规则可以说：英语里VP(VBZ(does) RB(not) x0:VB)对应法语ne x0 pas，一次跨越了三层树结构。

论文证明这样得到的是能解释这对句子的最小规则集合，算法时间对句长线性。之后的工作再把相邻的最小规则组合成更大的规则，并为规则估计概率。

本篇术语

  • 边界节点　句法树中满足「它覆盖的英语词对齐到的外语词，不和树中其他部分对齐到的外语词交叉」的节点，规则只能在这些节点处切开。
  • 树到串规则　左边是一段带变量的句法树片段，右边是含同样变量的另一种语言的词串，描述一种结构如何被翻译。

怎么学

先读短语统计机器翻译和层次短语翻译Hiero的讲解 → 读原文第3–4节对齐图和边界节点的定义 → 动手：手工画一棵英语句法树和对齐到法语的连线，按定义标出边界节点，抽出最小规则。
