软件2.0

Software 2.0
2017.11思想延伸Andrej Karpathy · Tesla（当时）待核对
Software 2.0（Medium） ↗在交互版中打开（演化树、学习进度）

问题

传统软件靠人一行行写明确规则，但图像识别、语音等问题的规则写不出来，工程师无从下手。

方法

Karpathy提出：神经网络是「软件2.0」——程序不再由人写，而是由优化算法在数据集上搜索出来，程序的内容存在权重里。

影响

重塑了工程师对AI系统的看法：工作重心从写代码转向整理数据集、定义目标和评测。

方法

文章把传统编程叫软件1.0：人写Python或C++，每行代码都是明确指令。软件2.0里，工程师只指定目标（比如分类准确率）和一个网络结构的搜索空间，再用梯度下降在大量标注数据上找到一组权重，这组权重就是程序。

他指出视觉、语音识别、机器翻译、游戏和数据库索引等领域已经在被软件2.0取代；好处包括可以在固定的计算量下运行、容易搬到硬件上，以及随数据增长而变好。代价是行为难以解读，且会出现意想不到的失败。他当时在Tesla做自动驾驶视觉，文中也引用了这类经验。

后来的发展

这个说法后来被扩展为「数据是新的源代码」等口号。ChatGPT发布之后，提示词和自然语言被称为更高一层的编程。

局限与后续

  • 软件2.0的行为难以审查，缺少传统软件的单元测试、代码审阅和形式化验证手段。
