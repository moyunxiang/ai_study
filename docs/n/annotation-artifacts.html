标注伪影

Annotation Artifacts in Natural Language Inference Data
2018.03论文重要NAACL 2018Suchin Gururangan, Swabha Swayamdipta, Omer Levy, Roy Schwartz, Samuel R. Bowman, Noah A. Smith · 华盛顿大学 / CMU / 纽约大学 / AI2待核对
arXiv ↗同期工作：Hypothesis Only Baselines in NLI ↗在交互版中打开（演化树、学习进度）

问题

SNLI、MultiNLI上的推理模型准确率逼近90%，但没人检查过：模型到底是在做推理，还是在利用众包标注留下的写作习惯。

方法

训练一个完全看不到前提、只看假设句的词袋分类器；它若能猜对标签，说明数据里有与标签挂钩的表面线索，再按它的对错把测试集拆成难易两部分。

影响

让“只看一半输入的基线”成为检查数据集的标准动作，推动了对抗式收集数据和过滤数据的一系列新基准。

背景

自然语言推理（NLI）给模型一对句子：前提和假设，判断前提是否蕴含、矛盾，或与假设无关（中立）。SNLI和MultiNLI用众包构造：给工人一句前提，让他各写一句蕴含、中立、矛盾的假设。这样几十万条数据很快就攒够了，ESIM自然语言推理等模型在SNLI上达到85%以上。

问题在于，工人为了快速完成任务会形成固定套路。早在数据集偏差里，人们就发现视觉数据集各有可被识别的“指纹”。NLI数据有没有类似的指纹，模型的高分里有多少来自这些指纹，当时没人量化过。

方法

只看假设的分类器。作者用fastText（把句子当作词和二元词组的袋子的线性分类器）只输入假设句来预测三类标签。前提完全不给，按理应该只能拿到多数类基线的约三分之一。

找出线索词。对训练集里每个词和每个类别算点互信息PMI(词, 类) = log p(词, 类) / (p(词)·p(类))，找出最能指示某一类的词。

难易拆分。把测试集里只看假设的分类器猜对的样本标为Easy，猜错的标为Hard，再用完整模型分别评测。如果模型真的在推理，两部分成绩不该差太多。

结果

只看假设的fastText在SNLI上准确率67.0%（多数类基线34.3%），在MultiNLI匹配集和不匹配集上分别为53.9%和52.3%。

线索非常直白：nobody、no、never、nothing强烈指向“矛盾”，sleeping这类词常被用来否定前提里的任何动作；animal、instrument、outdoors这类上位词指向“蕴含”（工人把具体的狗改写成动物）；tall、sad、first这类附加修饰和目的从句指向“中立”。SNLI里8.8%的蕴含假设完全包含在前提中。

难易拆分后，ESIM在SNLI完整测试集上85.8%，Easy部分92.6%，Hard部分只有71.3%；另两个模型也是同样的落差。

后来的发展

同期还有Poliak等人在十个NLI数据集上做了同样的只看假设基线，结论一致。之后的工作沿两条路走：一是诊断模型学到的具体捷径，例如HANS启发式诊断揭示的词汇重叠启发式，以及捷径学习把这类现象推广到整个深度学习；二是改造数据收集方式，HellaSwag和WinoGrande用模型过滤掉容易的样本，对抗式NLI和Dynabench动态基准让人和模型对抗着写题。今天评测大模型时检查“只看部分输入能拿多少分”仍是常规做法。

容易误解的地方

  • 只看假设能猜对，说明数据有线索，不等于完整模型一定在用这些线索；难易拆分的实验才把两者联系起来。
  • 这篇的结论不是“NLI任务没意义”，而是“众包构造方式会把标注者的习惯写进数据”。

局限与后续

  • 只发现了词汇层面的线索，模型是否还依赖句法等更深层的捷径没有检验。

本篇术语

  • 自然语言推理（NLI）　给定前提句和假设句，判断前提是否蕴含假设、与之矛盾，或两者无关。曾被视为检验语言理解的核心任务。
  • 标注伪影　数据构造过程无意中留下的、与标签相关的表面特征，比如否定词几乎只出现在矛盾类里。模型学会它就能得分，却没学会任务本身。
  • 点互信息（PMI）　衡量一个词和一个类别同时出现的频率比两者独立时高多少，取对数；越大说明这个词越能指示这一类。

怎么学

先了解基准、排行榜与SOTA和泛化与过拟合。读原文第2节（只看假设的实验）和第4节（难易拆分），重点看表2、表4、表5。动手：从Hugging Face下载SNLI，用scikit-learn的词袋加逻辑回归只喂假设句，复现60%以上的准确率，再打印权重最大的词。
