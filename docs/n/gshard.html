GShard

GShard: Scaling Giant Models with Conditional Computation and Automatic Sharding
2020.06论文延伸ICLR 2021Dmitry Lepikhin, HyoukJoong Lee, Yuanzhong Xu, Dehao Chen, Orhan Firat, Yanping Huang, Maxim Krikun, Noam Shazeer, Zhifeng Chen · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

想把稀疏门控MoE层的稀疏混合专家扩到几百亿、几千亿参数，需要在大量加速器上手写复杂的并行代码，工程成本极高。

方法

提供一套轻量的标注接口和XLA编译器扩展，只要在张量上标出如何切分，就能自动完成切分与通信，用它把带MoE的翻译Transformer扩到6000亿参数以上。

影响

证明稀疏MoE可以扩到6000亿参数，并提出自动切分的通用做法，直接铺路稀疏MoE大模型及后来的MoE大模型。

方法

GShard由两部分组成。一是标注API：开发者写的仍是单机的模型代码，只需要给少数张量标明如何沿设备切分（例如按专家切、按数据切），编译器（XLA的扩展）就自动生成多设备的并行程序和需要的通信。二是条件计算的MoE层：在Transformer里隔层把前馈网络替换成一组专家，路由器为每个词选出少数专家，其余专家不参与计算，所以总参数很大、每词计算量却不大（见混合专家）。

官方摘要称，用它把多语言翻译Transformer扩展到超过6000亿参数，在2048块TPU v3上训练4天，实现100种语言到英语的翻译质量明显好于以往。

局限与后续

  • 专家负载不均、路由不稳定，需要辅助损失和专家容量上限等补丁，训练不易复现。
    后来针对它的工作　稀疏MoE大模型 ST-MoE稳定训练
  • 依赖TPU、XLA和特定的集群，其他团队很难复用。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    把Transformer的部分前馈层替换成MoE层。
  • 改进
    多语言NMT与零样本翻译2016.11 · NLP
    参数量固定时，语言越多每种语言分到的容量越少，高资源语言的质量下降（大模型上平均相对下降2.5%–5.6%）。
  • 延续
    稀疏门控MoE层2017.01 · LLM
    在稀疏门控MoE层的稀疏门控层基础上扩到6000亿参数，并解决大规模并行的实现。
  • 改进
    Mesh-TensorFlow张量切分2018.11 · 系统·效率
    需要用户手工选择切分方式，不同层的最优切法不同，要靠经验。

后来的相关工作

  • 改进
    DeepSeekMoE细粒度专家2024.01 · LLM 已核对
    针对GShard式粗粒度top-2专家的知识混杂与冗余问题，用细粒度切分和共享专家让专家真正分工；同等计算下明显更好。
  • 使用
    Mixtral 8x7B2024.01 · LLM 已核对

  • 改进

    沿着GShard的MoE翻译模型，改用更简单的路由并应用到语言模型预训练。
  • 改进
    BASE层平衡分配路由2021.03 · LLM
    GShard的top-2路由同样依赖辅助损失和丢token，BASE层去掉了这些机制。
  • 延续
    GSPMD自动分片并行2021.05 · 系统·效率

  • 延续
    GLaM2021.12 · LLM
    沿用GShard的稀疏MoE层设计，把它用于大规模自回归语言模型。
  • 延续
    DeepSpeed-MoE推理与训练2022.01 · 系统·效率
    GShard给出了专家并行训练的做法，DeepSpeed-MoE补上了推理侧的系统与模型压缩。
  • 改进
    专家选择路由2022.02 · LLM
    同样针对GShard top-2路由的负载失衡，并在相同计算预算下与之比较。
  • 改进
    ST-MoE稳定训练2022.02 · LLM
    专家负载不均、路由不稳定，需要辅助损失和专家容量上限等补丁，训练不易复现。
  • 使用
    路由网络统一规模定律2022.02 · LLM
    以GShard、Switch确立的MoE层作为基本结构。
  • 改进

    MegaBlocks无丢弃MoE训练2022.11 · 系统·效率

    全局批负载均衡损失2025.01 · LLM

读懂它需要的概念

混合专家 分布式训练：数据并行与模型并行 参数量、计算量与显存 互连：从芯片到机柜到集群 CPU、GPU与并行计算

怎么学

先读混合专家与分布式训练：数据并行与模型并行；读原文第2–3节，理解标注切分与MoE层如何配合。
