ART自动多步推理与工具

ART: Automatic multi-step reasoning and tool-use for large language models
2023.03论文延伸Bhargavi Paranjape, Scott Lundberg, Sameer Singh, Hannaneh Hajishirzi, Luke Zettlemoyer, Marco Tulio Ribeiro · 华盛顿大学 / 微软研究院 / UC尔湾 / 艾伦人工智能研究所 / Meta AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

思维链和工具调用都要为每个新任务手写示例，并精心安排模型生成与工具调用怎样交替；换一个任务就要重写一遍。

方法

预先建一个任务库，把若干任务的多步推理写成统一格式的“程序”，每一步标明用什么工具；遇到新任务时自动挑相似任务的程序当示例，冻结的LLM照格式生成新程序，遇到工具调用就暂停、执行、把结果接回再继续。

影响

在未见过的BigBench和MMLU任务上平均比少样本提示高约10.8个点，大多数任务上追平手写思维链，并且人可以通过改程序、加工具来修正特定任务。

方法

程序格式：每一步写成“Q1: [search] 某某的出生年份是？”接着“#1: 结果”，方括号里是工具名，最后以“Ans:”给出答案。这套格式由一个解析文法固定下来，所以系统能可靠地识别何时该调用工具。

任务库与工具库：任务库含15个BigBench任务的示范程序，按技能分成算术、代码、搜索与问题分解、自由推理、字符串操作五类；工具包括搜索引擎、用Codex生成代码、Python执行环境，自由推理类直接用“一步一步想”的子步骤。

选择示例：新任务带约50个标注样本时，试用每一类的示范程序，选在留出样本上得分最高的那一类；也可以让LLM判断任务是否相似（效果略差）。

执行：冻结的InstructGPT（text-davinci-002）按示例生成程序；每当生成到工具标记，就暂停生成、调用工具、把输出写进“#k”后面，再让模型继续。

结果：开启工具使测试任务平均提高超过12.3个点；在34个BigBench任务中的32个和全部MMLU任务上不差于Auto-CoT自动思维链，平均高出超过22个点；与微调GPT-J的Toolformer在6个基准上比较，赢了5个。人工反馈（修改程序或新增Prolog引擎等工具）后，12个测试任务比已发表的最好GPT-3结果平均高20多个点。

局限与后续

  • 工具集合、程序格式和任务库都是人工搭建的，新任务与库里五类技能差别太大时，挑出的示例帮助有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 模型并没有学会使用工具，只是模仿示例的格式；一步出错后面就跟着错，没有基于工具结果的反思或纠错。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    思维链CoT2022.01 · 推理·智能体
    把思维链的中间步骤写成带工具标记的程序，让部分步骤交给搜索或代码执行。
  • 使用
    InstructGPT与RLHF2022.03 · LLM
    以冻结的text-davinci-002作为生成程序的模型，代码生成另用Codex。
  • 延续
    ReAct2022.10 · 推理·智能体
    沿用推理与工具调用交替、观察结果接回上下文的模式，但示例从任务库自动选取，而不是为每个任务手写。
  • 改进
    Auto-CoT自动思维链2022.10 · 推理·智能体
    Auto-CoT自动构造思维链示例，但不涉及工具；ART从任务库挑示范程序并接入工具，在绝大多数任务上明显超过Auto-CoT。
  • 竞争
    Toolformer2023.02 · 推理·智能体
    Toolformer通过自监督微调让模型学会插入API调用；ART不改权重，靠检索示范程序让冻结模型调用工具，在6个基准中的5个上更好。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

上下文学习与提示 零样本与少样本 工具调用 智能体循环 推理token与测试时计算

本篇术语

  • 任务库　预先写好的若干任务的示范程序集合，遇到新任务时从中挑选相似的作为提示示例。
  • 解析文法　规定程序必须长成什么样的形式规则，用来可靠地从模型输出中识别出每一步和工具调用。

怎么学

先读思维链CoT、ReAct和Toolformer → 读原文第3节程序格式、任务库与示例选择、表2和表3 → 动手：写两个带[search]和[code]标记的示范程序，实现“遇到标记就暂停并调用工具”的循环，在一个新任务上测试。
