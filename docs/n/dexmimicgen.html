DexMimicGen

DexMimicGen: Automated Data Generation for Bimanual Dexterous Manipulation via Imitation Learning
2024.10论文延伸ICRA 2025Zhenyu Jiang, Yuqi Xie, Kevin Lin, Zhenjia Xu, Weikang Wan, Ajay Mandlekar, Linxi Fan, Yuke Zhu · UT Austin / NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

双臂灵巧手（如人形机器人）的示范采集特别困难：要同时操控两臂和多指手，数据成了瓶颈。

方法

把MimicGen的数据生成思路扩展到双手灵巧操作：从少量人类示范自动合成大量仿真轨迹，并处理双臂协调。

影响

展示了用60条人类示范合成21K条仿真示范并训练策略，为人形机器人提供可扩展的数据来源。

方法

DexMimicGen是一个大规模自动数据生成系统。像MimicGen数据扩增一样，它把源示范分成以物体为中心的片段，在新场景里按物体位置变换并重放；不同的是，它专门处理两臂之间的协调需求，例如两只手要同时抬起物体，还是一只手先放、另一只手后接。作者同时提供了一组仿真的双手灵巧操作环境，涵盖不同协调需求。

摘要称，他们从60条人类源示范生成了21K条示范，并据此训练策略；论文还做了真实人形机器人的验证（细节未逐项核对）。
