A*搜索

A Formal Basis for the Heuristic Determination of Minimum Cost Paths
1968.07论文延伸IEEE Trans. SSC 1968Peter Hart, Nils Nilsson, Bertram Raphael · Stanford Research Institute待核对
维基：A* ↗在交互版中打开（演化树、学习进度）

问题

在图上找最短路径时，穷举搜索太慢，只看启发式估计（贪心）又不保证最优。

方法

按 f(n) = g(n) + h(n) 给节点排序：g是已走的实际代价，h是到目标的估计；只要h从不高估，就保证找到最优路径。

影响

成为机器人路径规划、游戏寻路和各类搜索的基础算法，至今仍是导航栈里的默认全局规划器之一。

方法

A*于1968年由SRI的Hart、Nilsson、Raphael提出，起因是Shakey机器人（Shakey机器人）需要在房间里规划路径。据维基百科，Raphael提出用“已走代价加启发式估计”来给节点打分，而不是只用启发式；Hart提出了可采纳（admissible）和一致（consistent）启发式的概念。

做法：维护一个待扩展节点的优先队列，每次取出f值最小的节点扩展。例如在栅格地图上，g是已走的步数，h取到终点的直线距离（它永远不会高于真实路径长度，所以是可采纳的）。可采纳保证第一次到达终点时路径最优；一致性保证每个节点至多被处理一次。

主要缺点是内存：A*要把生成过的节点都存起来，空间随搜索深度指数增长，由此出现了IDA*、SMA*等节省内存的变体。

后来的发展

STRIPS规划与A*同出于Shakey项目，分别解决“做什么”和“怎么走”；高维连续空间中的路径规划转向采样方法（PRM概率路图、RRT快速随机树）。

它建立在什么之上

  • 改进
    逻辑理论家1956 · 事件
    搜索树指数增长，靠手写的经验法则剪枝，只能证明短小的定理，更长的证明会陷入组合爆炸。
  • 改进
    通用问题求解器GPS1959 · 事件
    只能解完全形式化的玩具问题，在真实问题上路径数指数增长，搜索被组合爆炸吞没。

后来的相关工作

  • 使用
    STRIPS规划1971 · 具身·世界模型
    同出自SRI的机器人项目；STRIPS同样用一个启发式评估函数决定先展开搜索树中的哪个节点。
  • 使用
    占据栅格地图1985.03 · 具身·世界模型
    栅格把连续空间离散成格子图，路径规划就变成在格子上的图搜索；论文导航时在栅格地图上用同实验室的Path Relaxation方法规划路径。
  • 改进
    RRT快速随机树1998.10 · 具身·世界模型
    A*需要把空间离散成网格，格子数随维数指数增长；RRT用随机采样绕开了显式离散化，在7维以上的机械臂空间仍可用。
  • 使用
    DARPA城市挑战赛2007.11 · 具身·世界模型
    停车场等无车道区域用格点规划器在离散位姿格上做启发式图搜索，并支持快速重规划。
  • 使用
    Shakey机器人1972 · 具身·世界模型
    用A*在房间地图上规划路径，A*正是为它而发明的。
  • 改进
    PRM概率路图1996.08 · 具身·世界模型
    解决A*在高维位形空间中无法逐格搜索的问题：改为采样得到稀疏的图再搜索。

怎么学

先补图、树与搜索。动手：在栅格地图上实现A*并试不同的h（0、曼哈顿距离、过大的h），观察结果是否仍最优。
