FFJORD连续标准化流

FFJORD: Free-form Continuous Dynamics for Scalable Reversible Generative Models
2018.10论文延伸ICLR 2019Grathwohl, Chen, Bettencourt, Sutskever, Duvenaud · Toronto / Vector / OpenAI待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

离散层数的流（标准化流RealNVP、Glow）必须设计行列式易算的特殊层，限制了网络结构。

方法

把流写成神经常微分方程的连续时间动力学，对数密度变化只需要雅可比的迹，再用Hutchinson估计器无偏估计，网络结构就不受限。

影响

让流模型可以使用任意网络，是后来Flow Matching等连续时间生成模型的重要先驱。

方法

在神经常微分方程中，隐状态按 dz/dt = f(z,t) 连续演化，f是任意神经网络。瞬时变量替换公式给出对数密度的变化率 d log p/dt = −tr(∂f/∂z)，只需要雅可比的迹而不是行列式。但迹本身要算D次反向传播，维度高时昂贵。

FFJORD用Hutchinson迹估计器：取随机向量ε，tr(A) = E[εᵀAε]，一次向量-雅可比乘积就得到无偏估计，复杂度降为线性。反向传播通过ODE求解器的伴随方法，内存常数。

摘要称得到连续时间可逆生成模型，密度估计无偏、采样一遍完成，网络结构不受限，在高维密度估计、图像生成和变分推断上达到精确似然方法中的最优。

局限与后续

  • 每次前向和反向都要调用ODE求解器，训练要几十到上百次函数评估，速度远慢于离散流。

  • 训练过程需要积分模拟轨迹，难以扩展到大图像、大数据。
    后来针对它的工作　Flow Matching
