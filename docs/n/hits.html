HITS枢纽与权威

Authoritative sources in a hyperlinked environment
1998.01论文重要SODA 1998；Journal of the ACM 1999Jon M. Kleinberg · 康奈尔大学（研究时在IBM Almaden）待核对
JACM ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

对「搜索引擎」「汽车」这类宽泛查询，含有查询词的网页成千上万，只看文本匹配无法判断哪些页面真正权威，权威网站自己甚至未必包含这个词。

方法

网页有两种角色：权威页（被很多好的枢纽页指向）和枢纽页（指向很多好的权威页）；二者互相定义，交替迭代到收敛，等价于求链接矩阵的主特征向量。

影响

与同年的PageRank一起把超链接结构变成网页排序的核心信号，确立了「链接分析」这一研究方向；枢纽-权威的互相强化思想后来也被用于引文分析、社交网络和推荐系统。

背景

90年代中期的搜索引擎主要按向量空间模型式的文本相似度排序。对于有明确答案的窄查询这够用，但对宽泛主题，相关网页数量巨大，文本相似度区分不出质量；而且许多权威网站（如汽车厂商主页）的页面上未必写着「汽车」这个词。另一方面，网页作者用超链接表达了大量隐含判断：链到一个页面，往往意味着认可它。文献计量学早就用引用次数衡量论文影响力，但简单数入链会被大量无关的热门网站（如门户首页）主导。

方法

构造子图。 对一个查询，先用文本搜索引擎取前约200个结果作为「根集」，再加入根集页面链出和链入的页面，形成一个几千页的「基础集」，只在这个子图上计算。

互相强化的迭代。 给每个页面p两个分数：权威分a(p)和枢纽分h(p)，初始都为1。反复执行：

  • a(p) ← Σ_{q→p} h(q)：被好枢纽指向的页面是好权威；
  • h(p) ← Σ_{p→q} a(q)：指向好权威的页面是好枢纽；
  • 每轮把a和h各自归一化为单位长度。

设A是基础集的邻接矩阵（A_qp = 1表示q链向p），上面两步就是 a ← Aᵀh、h ← A a，合起来 a ← AᵀA a、h ← AAᵀ h。这正是幂迭代，收敛到 AᵀA 和 AAᵀ 的主特征向量，也就是A做奇异值分解时最大奇异值对应的左右奇异向量。取权威分最高的若干页面作为结果。

论文还指出，非主特征向量对应同一查询下的不同「社区」，例如「jaguar」会分出动物、汽车、球队等几组权威页。

结果

论文在多个宽泛查询上展示了算法找出的权威页（例如对「search engines」返回各大搜索引擎主页），这些页面多数并不包含查询词本身；实验以案例展示为主，没有大规模定量评测。

后来的发展

几个月后发表的PageRank与Google搜索用与查询无关的全局随机游走给每个页面一个分数，可以离线计算，成为Google的核心信号；HITS因为要在查询时计算、易受链接操纵，主要在学术界和一些系统（如Teoma搜索引擎）中使用。后续的SALSA把两者结合成随机游走形式。枢纽-权威的二分结构也影响了社区发现和协同过滤。

局限与后续

  • 每个查询都要在线构造子图并迭代，计算开销大，不适合大规模搜索引擎的实时服务。

本篇术语

  • 权威页（authority）　某主题下被许多好的枢纽页链接的页面，相当于这个主题的「标准答案」。
  • 枢纽页（hub）　链接到许多好的权威页的页面，比如整理得很好的资源导航页。
  • 幂迭代　反复用矩阵乘一个向量并归一化，向量会收敛到矩阵最大特征值对应的特征向量。
