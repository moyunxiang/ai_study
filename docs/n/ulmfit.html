ULMFiT

Universal Language Model Fine-tuning for Text Classification
2018.01论文重要ACL 2018Jeremy Howard, Sebastian Ruder · fast.ai / 旧金山大学 / NUI Galway待核对
arXiv ↗fast.ai 介绍文章 ↗在交互版中打开（演化树、学习进度）

问题

视觉里“ImageNet预训练+微调”早已是常规，NLP却仍要为每个任务从头训练专门模型；直接微调语言模型又容易过拟合、忘掉预训练学到的东西。

方法

先在维基百科上训练一个LSTM语言模型，再在目标领域文本上微调它，最后加分类头微调；用分层学习率、先升后降的学习率和逐层解冻三招防止遗忘。

影响

第一次让同一个预训练语言模型、同一套超参数在六个文本分类任务上全面超过专门设计的模型，把“预训练+整体微调”的范式带进NLP。

背景

2017年前后，NLP的迁移学习基本只停在第一层：用word2vec之类的预训练词向量初始化嵌入层，模型其余部分从零训练。视觉早已不同，AlexNet之后，人们先在ImageNet上训练整个网络，再拿到新任务上微调。

序列预训练（Dai & Le）已经试过先训练语言模型再微调，但需要大量领域内数据，在小数据上效果不稳。直接拿语言模型微调还有个更普遍的问题：学习率一大，预训练学到的通用知识很快被覆盖，即灾难性遗忘；学习率太小又收敛慢、反而过拟合。

方法

三步走。① 在WikiText-103（约2.86万篇维基文章、1.03亿词）上预训练一个3层AWD-LSTM语言模型。② 在目标任务的文本上继续做语言模型训练，让它适应领域用词。③ 在顶上加两层分类器，再整体微调。

分层学习率。不同层学到的东西通用程度不同，低层更通用，应该少动。于是每层用不同学习率，η^(l−1) = η^l / 2.6，即每往下一层，学习率除以2.6。

斜三角学习率。训练开始的一小段时间（论文取10%）学习率线性升高，让模型迅速找到适合新任务的区域，然后在剩余时间里线性降低做细调（见学习率与学习率调度）。

逐层解冻。分类阶段不一次放开所有层：第一轮只训练最后一层，下一轮再解冻倒数第二层，依次往下，直到全部层一起训练。

结果

六个文本分类数据集上的错误率普遍下降18–24%。IMDb影评情感分类错误率4.6%，此前最好结果为5.9%、基于翻译编码器的CoVe上下文词向量为8.2%。在IMDb上只用100条标注样本，就能达到从零训练用10倍数据的效果；再加5万条无标注文本做第二步，相当于从零训练用100倍数据。

后来的发展

五个月后GPT-1把LSTM换成Transformer、沿用“预训练语言模型+整体微调”的思路，并把它推广到蕴含、问答等句对任务；BERT再把方向改成双向。“预训练—领域继续预训练—任务微调”的三段式和分层学习率至今仍常见于领域模型训练。

读懂它需要的概念

语言模型 循环网络与隐状态 预训练与微调 迁移学习 学习率与学习率调度

本篇术语

  • 分层学习率　原文叫discriminative fine-tuning：给网络不同层设不同学习率，低层小、高层大。
  • 逐层解冻　微调时从最后一层开始，每轮多放开一层参与训练，避免一开始就大幅改动通用的低层。

怎么学

先补语言模型和预训练与微调。读原文第3节的三种技巧和图1，再看fast.ai的介绍文章。动手：用任意小型预训练模型在IMDb上分别做“一次性全部微调”和“逐层解冻+分层学习率”，比较只有几百条标注时的差距。
