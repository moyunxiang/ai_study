别再解释黑盒

Stop Explaining Black Box Machine Learning Models for High Stakes Decisions and Use Interpretable Models Instead
2018.11论文延伸Nature Machine Intelligence 2019Cynthia Rudin · 杜克大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

高风险决策（医疗、刑事司法）常用不透明的模型，再事后用LIME、SHAP之类方法解释，人们以为这样就够透明了。

方法

指出事后解释不忠实于原模型，且让人误以为黑盒可信；主张在高风险场景直接使用本身可解释的模型。

影响

成为可解释性之争中的重要一方，常被用来反对「先训黑盒再解释」的做法。

方法

论文区分了两件事：为黑盒模型生成解释，与一开始就用结构上可被人完整理解的模型（如稀疏的评分规则）。作者的论点有几层：解释不可能完全忠实于原模型，否则解释本身就等同于原模型；一个不忠实的解释可能让用户信错；而可解释模型和黑盒在许多结构化数据任务上准确率并没有明显差距，所谓准确率与可解释性的取舍常被夸大。

文中以刑事司法、医疗和计算机视觉的例子，说明可以用可解释模型替代黑盒，并列出了设计可解释模型所面对的难题。

  • 对图像、语言等没有现成可解释结构的任务，作者倡导的路线尚缺少替代方案，大模型时代更是如此。
