HOList与DeepHOL

HOList: An Environment for Machine Learning of Higher-Order Theorem Proving
2019.04论文延伸ICML 2019；arXiv 2019Bansal, Loos, Rabe, Szegedy, Wilcox · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度学习缺少一个面向高阶逻辑定理证明的开放环境与基准，无法系统训练和比较证明器。

方法

基于HOL Light提供强化学习式的证明环境，并用从开普勒猜想形式化证明等派生出的基准，给出深度强化学习证明器DeepHOL。

影响

提供了早期的神经定理证明环境与基准，DeepHOL给出了较强的初始结果。

方法

高阶交互式证明器能形式化任意数学理论。HOList把HOL Light包装成一个开源框架，可当作强化学习环境：证明器每一步选一个战术和参数，环境检查并返回新的证明目标。HOL Light自带微积分的大量基本定理以及开普勒猜想的形式化证明，作者从中派生出有挑战性的自动推理基准。

论文还给出由深度强化学习驱动的证明器DeepHOL，并报告它在该基准上有较强的初始结果。

后来的发展

它与同年的CoqGym与ASTactic一起奠定了在证明助手里学习的环境加基准范式，之后的PACT证明产物协同训练、GPT-f把语言模型引入同一类环境。
