LRCN

Long-term Recurrent Convolutional Networks for Visual Recognition and Description
2014.11论文延伸CVPR 2015Donahue, Hendricks, Rohrbach, Venugopalan, Guadarrama, Saenko, Darrell · 伯克利 / UT Austin / UMass Lowell待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视频识别和图像描述把卷积网络与时序处理拼在一起，时间上只能做固定窗口或简单平均，不能端到端学长程依赖。

方法

在每帧的卷积特征之后接LSTM，空间和时间两个方向都是可训练的「深」层，整套模型端到端训练，一个框架通吃视频识别、图像描述和视频叙述。

影响

最早的一批「CNN加LSTM」通用框架，视频描述和图像描述的常用基线。

方法

LRCN（长程循环卷积网络）的做法很直接：用卷积网络把每一帧（或一张图）变成特征向量，再把这些向量按顺序送进LSTM，由LSTM在每个时间步输出结果。三类任务用同一结构的不同变体。视频动作识别时，LSTM对逐帧特征做序列分类；图像描述时，同一张图的特征在每一步都输入LSTM，由它逐词输出句子；视频叙述时，输入是帧序列，输出是句子。

作者称这样的模型在空间和时间上都是「双重深度」的，梯度可以一路传回卷积层，整体可以端到端训练，而此前的做法常常直接使用固定的、与任务无关的离线特征。原文在视频识别基准、图像描述与检索、视频叙述挑战上做了评测。
