SVGD斯坦因变分梯度下降

Stein Variational Gradient Descent: A General Purpose Bayesian Inference Algorithm
2016.08论文延伸NeurIPS 2016Qiang Liu, Dilin Wang · 达特茅斯学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

变分推断要先选一个参数化的近似分布族，表达力受限；MCMC表达力强但收敛慢、难判断何时停止。

方法

用一组粒子表示后验，每一步沿着让KL散度下降最快的光滑方向移动所有粒子；这个方向有闭式解，由“吸引项”（往高概率处走）和“排斥项”（粒子彼此推开）组成。

影响

开创了基于粒子的变分推断方向，被用于贝叶斯神经网络、软Q学习（能量策略）的策略采样、元学习等，Stein差异也成为生成模型评估与训练的工具。

方法

目标是让粒子集合 {x₁…x_n} 逼近目标分布p(x)（例如后验，只需知道 ∇log p，不需要归一化常数）。每一步对所有粒子做一次 xᵢ ← xᵢ + ε·φ(xᵢ)，其中

φ(x) = (1/n)·Σⱼ [ k(xⱼ, x)·∇log p(xⱼ) + ∇_{xⱼ} k(xⱼ, x) ]

k是核函数（如RBF核）。第一项把粒子推向高概率区域（相当于被核平滑过的梯度上升）；第二项是核的梯度，让相互靠近的粒子彼此排斥，避免全部塌到同一个众数上。作者证明：在再生核希尔伯特空间里的光滑变换中，φ正是使KL散度下降最快的方向，这把KL的导数与Stein恒等式和核化Stein差异联系了起来。

只有一个粒子时，排斥项消失，SVGD退化为求最大后验的梯度上升；粒子越多，越接近完整的后验。摘要称在多种真实模型和数据集上与当时最好的方法相当。

局限与后续

  • 粒子之间两两计算核，代价随粒子数平方增长；高维时RBF核的排斥力减弱，粒子容易低估方差。

它建立在什么之上

  • 竞争
    Metropolis采样与MCMC1953 · 基础
    与MCMC同为从后验取样的方法，SVGD是确定性的粒子更新而非随机游走。
  • 使用
    核技巧与最优间隔分类器1992 · 基础
    最速下降方向在再生核希尔伯特空间中求出，更新式里显式使用核函数及其梯度。
  • 延续
    变分推断1999 · 基础
    仍最小化KL散度，但用非参数的粒子代替参数化的近似分布族。
  • 竞争
    SGLD随机梯度朗之万2011.06 · 基础
    SGLD靠注入噪声保持多样性，SVGD靠粒子间的核排斥项。

读懂它需要的概念

KL散度 核技巧与间隔 梯度下降 先验、后验与贝叶斯推断 MCMC与朗之万动力学

本篇术语

  • Stein恒等式　对满足边界条件的函数f，有 E_p[f(x)∇log p(x) + ∇f(x)] = 0；只有当采样分布就是p时才成立，因此可用来度量两个分布的差异。

怎么学

先懂变分推断与KL散度；读论文第3节从Stein恒等式推出φ的过程；动手用20个粒子逼近一个一维双峰高斯混合，观察去掉排斥项后粒子会怎样。
