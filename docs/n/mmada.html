MMaDA多模态扩散

MMaDA: Multimodal Large Diffusion Language Models
2025.05论文延伸Ling Yang, Ye Tian, Bowen Li, Xinchen Zhang, Ke Shen, Yunhai Tong, Mengdi Wang · 普林斯顿大学、北京大学、清华大学、字节跳动Seed待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

统一理解与生成的模型大多是自回归加扩散的拼接，各模态有专门组件；扩散语言模型能否承担文本推理、图像理解和文生图三件事尚无答案。

方法

用一个掩码扩散模型统一处理文本token和离散图像token，并为扩散模型设计统一的强化学习算法UniGRPO，同时优化推理与生成。

影响

把扩散语言模型推进到多模态统一模型，说明“非自回归”路线也能做理解、推理和生成，带动了多模态dLLM的后续工作。

方法

MMaDA的语言部分从LLaDA大语言扩散模型的LLaDA-8B-Instruct初始化，图像分词器取自Show-o（基于MAGVIT-v2，下采样16倍、8192项码本，一张512×512图变成1024个离散token）。文本和图像token放进同一序列，训练目标是掩码扩散语言模型MDLM式的掩码token预测：随机遮住一部分token，只在被遮位置计算交叉熵，没有任何模态专用模块。

后训练分两步。先用跨模态统一格式的长思维链数据做微调，为强化学习冷启动。再用UniGRPO：文本和多模态推理用正确性奖励加格式奖励，文生图用CLIP奖励和ImageReward人类偏好奖励。论文称MMaDA-8B在文本推理上超过LLaMA-3-7B和Qwen2-7B，多模态理解超过Show-o和SEED-X，文生图超过SDXL和Janus。

局限与后续

  • 图像仍需离散分词，重建质量受码本限制，生成画质不及专用扩散模型的最新水平。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 扩散式解码需要多步迭代，推理速度与成熟的自回归加KV缓存方案相比没有明显优势。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    LLaDA大语言扩散模型2025.02 · LLM
    从LLaDA-8B-Instruct初始化，把扩散语言模型扩展到多模态。
  • 延续
    GRPO2024.02 · 推理·智能体
    把GRPO改造成适用于扩散模型、覆盖推理与生成的UniGRPO。
  • 使用
    掩码扩散语言模型MDLM2024.06 · LLM
    训练目标是掩码扩散语言模型的掩码预测损失。
  • 延续
    Show-o2024.08 · 多模态
    沿用Show-o的图像分词器和“一个Transformer统一理解与生成”的思路，但完全改为扩散。
  • 竞争
    Transfusion2024.08 · 多模态
    Transfusion用自回归处理文本、扩散处理图像，MMaDA对所有模态用同一种扩散。
