MVP掩码视觉预训练控制

Masked Visual Pre-training for Motor Control
2022.03论文延伸Tete Xiao, Ilija Radosavovic, Trevor Darrell, Jitendra Malik · UC Berkeley待核对
arXiv ↗后续真机版（Real-World Robot Learning with Masked Visual Pre-training） ↗在交互版中打开（演化树、学习进度）

问题

从像素学电机控制时，视觉编码器要么从头训、要么用ImageNet有监督模型；用强化学习从头学视觉又极其低效。

方法

先在大量真实世界图像上用MAE式掩码建模自监督预训练视觉编码器，然后冻结它，只在上面用强化学习训练控制器。

影响

与R3M同期证明了自监督视觉预训练对机器人控制有效，引出了VC-1等“具身视觉表示”评测和后续真机扩展。

方法

机器人从摄像头画面学控制，最难的往往是“看懂画面”这一步。直接用强化学习端到端训练视觉网络需要海量交互；拿ImageNet上有监督训练的分类网络当编码器，学到的又是“这是什么物体”，不一定是控制需要的空间和接触信息。

MVP借用了掩码自编码器MAE的做法：把图像切成小块，随机遮住大部分，让ViT编码器和一个小解码器去重建被遮住的像素，以此在无标签的真实图像上学视觉表示。预训练数据除了ImageNet，还包括YouTube视频帧和第一人称视角视频（如Ego4D）中的手—物交互画面。预训练完成后冻结编码器，不再针对任何任务微调；每个控制任务只在它输出的特征上训练一个小的神经网络控制器，用强化学习（PPO）优化。作者还自己设计了一套包含不同动作、场景和机械臂的像素控制基准。

结果：在不使用标签、状态估计或专家示范的情况下，MVP比有监督预训练的编码器成功率最多高80个百分点，有时接近直接使用真实状态的上限；而且用野外视频帧预训练的表示比用ImageNet的效果更好。同一组作者在2022年10月把它扩展到真实机器人，用450万张互联网和第一人称视频图像训练3.07亿参数的ViT，在多种真实机器人任务上验证了扩大视觉预训练的好处。
