NBSVM强基线

Baselines and Bigrams: Simple, Good Sentiment and Topic Classification
2012.07论文延伸ACL 2012Sida Wang, Christopher D. Manning · 斯坦福大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

朴素贝叶斯和支持向量机常被当作文本分类和情感分析的基线，但它们的表现随模型变体、特征和数据集差异很大，研究者往往随手选一个弱配置当基线，使新方法看起来比实际更好。

方法

系统比较多种NB和SVM变体，得出三点：加入词二元组（bigram）在情感任务上稳定有效；短文本情感任务上NB反而比SVM好，长文档则相反；提出NBSVM——把NB的对数计数比当作SVM的特征值，再在NB与SVM的权重之间插值，在各种任务上都表现稳定。

影响

简单的NB和SVM变体在多个情感数据集上超过当时大多数已发表结果，有时创下新纪录；NBSVM成为此后几年句子与文档分类论文（包括TextCNN、段落向量、ULMFiT等）必比的强基线，「先把基线调好」也成了被反复引用的教训。

方法

记号。每个文本表示成特征计数向量f（词或二元组出现次数），也可以二值化为f̂ = 1{f > 0}。对正负两类分别累加计数并加平滑α：p = α + Σ_{y=1} f，q = α + Σ_{y=−1} f，对数计数比r = log((p/‖p‖₁) / (q/‖q‖₁))，它衡量每个特征偏向正类还是负类的程度。

多项式朴素贝叶斯（MNB）就是线性分类器y = sign(wᵀx + b)，其中w = r，b = log(N₊/N₋)。作者确认了二值化的MNB比标准MNB好。

NBSVM：把每个样本的特征换成x̃ = r ∘ f̂（逐元素相乘，即用NB的对数计数比给特征缩放），再训练线性SVM。作者发现这在长文档上很好，而在所有文档上表现最好的是再加一步插值：w′ = (1−β)·w̄ + β·w，其中w̄ = ‖w‖₁/|V|是权重的平均幅度，β ∈ [0,1]。作者把它解释为一种正则化：除非SVM非常有把握，否则就相信NB。实验统一用α = 1, C = 1, β = 0.25。

实验覆盖电影短评（RT-s）、主观性分类（Subj）、商品评论、IMDB五万条长影评以及20 Newsgroups的若干主题对。主要发现：二元组对情感任务一致有帮助、对主题分类有好有坏；短片段情感任务上MNB优于SVM；NBSVM加二元组在IMDB上准确率91.22%，在多个数据集上超过当时发表的神经网络和复杂模型。

它建立在什么之上

  • 竞争
    IDF与TF-IDF1972.01 · NLP
    TF-IDF按文档频率给词加权；NBSVM按词在正负类间的对数计数比加权，属于有监督的特征加权。
  • 使用
    支持向量机1995 · 基础
    NBSVM的分类器是线性支持向量机。
  • 延续
    机器学习情感分类2002.07 · NLP
    Pang等比较了NB、最大熵和SVM做影评情感分类；本文系统梳理了变体与数据长度的影响，并给出更强的组合。
  • 延续
    SVM文本分类1998 · NLP
    在Joachims的SVM文本分类基础上，用朴素贝叶斯的对数计数比缩放特征并与NB权重插值。

本篇术语

  • 对数计数比　某个特征在正类中的（平滑后的）相对频率与在负类中的相对频率之比再取对数，正值表示偏向正类。
  • 二值化特征　只记录某个词是否出现，不记录出现了几次。
