GloVe

GloVe: Global Vectors for Word Representation
2014.10论文重要EMNLP 2014Jeffrey Pennington, Richard Socher, Christopher D. Manning · 斯坦福大学待核对
ACL Anthology ↗项目主页与预训练向量 ↗在交互版中打开（演化树、学习进度）

问题

词向量有两派：LSA一类对全局共现矩阵做分解，统计用得充分但类比任务很差；word2vec一类在局部窗口上滑动预测，类比好却没直接利用全局统计，也说不清规律从哪来。

方法

先数出整个语料的词-词共现次数，再直接拟合“两个词向量的内积≈共现次数的对数”，并用一个加权函数压低罕见和极高频词对的影响。

影响

给出了“词义藏在共现概率之比里”的清晰解释，公开的预训练向量（最大来自8400亿词网页语料）与word2vec一起成为2014–2018年几乎所有神经NLP模型的输入层。

背景

按照分布假说，意思相近的词出现在相近的上下文里。2014年学词向量有两条路。

一条是全局矩阵分解，代表是潜在语义分析LSA：统计整个语料的共现矩阵，再做奇异值分解。它充分利用了全局统计，但在“king − man + woman ≈ queen”这类类比测试上很差，因为“the”“and”这类高频词在原始计数里占绝对主导。

另一条是局部窗口预测，代表是word2vec和Skip-gram负采样：在语料上滑动窗口，用一个词预测周围的词。它在类比上表现很好，但每次只看一个窗口，没有直接利用“这两个词在全语料共同出现了多少次”这一统计量，而且为什么向量相减能表达语义关系也不清楚。

方法

出发点：看概率之比。设X_ij是词j出现在词i上下文中的次数，P(j|i) = X_ij / X_i。论文用60亿词语料举例：P(solid|ice) / P(solid|steam) = 8.9，P(gas|ice) / P(gas|steam) = 0.085，而与两者都相关或都无关的water、fashion，比值分别为1.36和0.96，接近1。也就是说，区分ice和steam的信息在比值里，无关的噪声在比值里互相抵消。

目标函数。希望向量能表达这种比值，推导后得到一个对数双线性回归：

J = Σ_ij f(X_ij) · (w_iᵀ·w̃_j + b_i + b̃_j − log X_ij)²

w是词向量，w̃是上下文向量，b是偏置。只在X_ij > 0的格子上求和，所以计算量取决于非零共现对的数量，而不是语料长度。

加权函数。f(x) = (x / x_max)^α（当x < x_max），否则为1；取x_max = 100、α = 3/4。这样只共现一两次的词对（多半是噪声）权重很小，“of the”这种极高频词对也不会无限放大。

训练完把w + w̃作为最终词向量。

结果

在word2vec的类比测试集上，300维、用60亿词（维基百科+Gigaword）训练的GloVe总准确率71.7%，同语料同维度下作者自己用word2vec工具训练的skip-gram为69.1%、CBOW为65.7%，对共现矩阵直接做SVD只有7.3%；用420亿词网页语料训练达到75.0%。在词相似度测试和CoNLL-2003命名实体命名实体识别上也优于对比方法。作者还用8400亿词的Common Crawl训练了一版更大的向量。

后来的发展

GloVe向量成为默认输入：神经网络依存分析之后的大量句法分析、BiDAF双向注意力流、DrQA开放域问答等阅读理解模型、CoVe上下文词向量都直接加载300维GloVe。不久后word2vec即隐式矩阵分解证明skip-gram负采样本身也在隐式分解一个移位的PMI矩阵，两派在理论上合流。fastText用子词向量解决了未登录词问题。2018年起ELMo和BERT给出随上下文变化的词表示，静态词向量退居轻量场景。

局限与后续

  • 每个词只有一个固定向量，“bank”是银行还是河岸无法区分，上下文信息完全丢失。
    后来针对它的工作　CoVe上下文词向量 ELMo BERT
  • 以整词为单位，词表外的词和形态变化（如复数、派生词）没有向量。
    后来针对它的工作　fastText BPE子词切分
  • 向量忠实复制语料中的统计相关性，包括职业与性别等社会偏见，下游模型会继承这些偏见。

读懂它需要的概念

嵌入向量 分布假说 内积与余弦相似度 特征分解与奇异值分解 损失函数 条件概率与贝叶斯公式

本篇术语

  • 共现矩阵　一个词表×词表的计数表，第i行第j列记录词j在词i附近（比如左右10个词内）出现了多少次。
  • 词类比测试　给出a:b = c:?，用向量b − a + c找最近的词，看是否等于正确答案，如“雅典:希腊 = 柏林:德国”。

怎么学

先补嵌入向量和内积与余弦相似度，读过word2vec。读原文第3节（从概率比推导目标函数的过程）和表1、表2。动手：下载项目主页上的glove.6B.300d向量，做几组类比和最近邻查询；再在一个小语料上自己数共现矩阵，用上面的J做梯度下降训练一版。
