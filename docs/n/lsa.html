潜在语义分析LSA

Indexing by Latent Semantic Analysis
1990.09论文重要Journal of the American Society for Information Science, Vol. 41, No. 6, pp. 391–407, 1990-09Scott Deerwester, Susan T. Dumais, George W. Furnas, Thomas K. Landauer, Richard Harshman · 芝加哥大学 / Bellcore / 西安大略大学待核对
DOI ↗预印本PDF（科罗拉多大学LSA组） ↗Wikipedia: Latent semantic analysis ↗在交互版中打开（演化树、学习进度）

问题

关键词检索只认字面：查“human computer interaction”，写着“user interface”的相关文档一个词都对不上，就找不到。人工叙词表成本高，还会把多义词带偏。

方法

把“词×文档”计数矩阵做奇异值分解，只保留最大的约100个维度。经常出现在相同文档里的词会落到相近的方向，于是没有共同词的查询和文档也能变得相似。

影响

第一次从原始文本中自动学出稠密的词向量和文档向量，把“分布相似即语义相近”变成一行线性代数；它是主题模型、GloVe和稠密检索的直接前身。

背景

向量空间模型把文档表示成以词为坐标的向量，按余弦相似度检索。但每个词是一个独立、互相正交的维度，造成两个问题：

  • 同义：同一个东西有很多说法，论文引用的研究显示，不同的人为同一常见物体选同一个关键词的概率不到20%。查询和文档用词不同，就检索不到，查全率低。
  • 多义：一个词有多个意思，字面相同不代表主题相同，查准率低。

已有的补救办法是人工或自动构造叙词表扩展查询，但扩展词又会引入新的歧义。Harris分布假说早就指出词义与它出现的环境相关，问题是怎样从语料中自动、大规模地把这种关联算出来。

方法

构造矩阵。X是t×d的矩阵，第i行第j列是词i在文档j中出现的次数（实验中也可加权）。

奇异值分解（见特征分解与奇异值分解）。任何矩阵都可写成 X = T₀ S₀ D₀ᵀ，T₀、D₀的列是正交单位向量，S₀是从大到小排列的奇异值。只保留最大的k个奇异值及对应的列，得到 X̂ = T S Dᵀ，它是所有秩为k的矩阵里最接近X的一个（见低秩近似）。T的每一行就是一个词的k维向量，D的每一行是一个文档的k维向量。k取50到100左右：太小丢信息，太大又退回到逐词匹配。

为什么能解决同义。压缩维度时，模型必须用少数几个方向去解释全部共现。“user”“interface”“system”常和“computer”一起出现在人机交互文档里，就会被挤到同一个方向上；于是即便两个文档没有共同词，只要它们的词各自与同一批词共现，在k维空间里也会靠近。

查询。把查询当作一篇“伪文档”：取其词的计数向量，用 X_qᵀ T S⁻¹ 投影到k维空间，再与每个文档向量算余弦，超过阈值的返回。

例子。论文用9个技术备忘录标题：5篇关于人机交互，4篇关于图论。查询“human computer interaction”，字面匹配只能找到c1、c2、c4；在二维LSA空间中，与查询余弦大于0.9的恰好是全部5篇人机交互文档，其中c3、c5与查询没有任何共同词。

结果

MED（1033篇医学摘要、30个查询、5823个词）：100维LSA的平均查准率0.51，直接词匹配0.45，提升13%；从很少的维数增加到100维左右，平均查准率从0.25升到0.52，翻了一倍多。CISI（1460篇、35个查询）：所有方法都很差，LSA与词匹配同为0.11，反而不如做了词干化的SMART。作者坦言LSA主要改善同义问题（查全率），对多义问题（查准率）帮助有限。

后来的发展

LSA很快被用到认知科学（Landauer用它模拟词汇习得）和作文自动评分上。它缺少概率解释，概率潜在语义分析pLSA和LDA主题模型把同样的“文档-主题-词”分解改写成概率生成模型。神经词向量出现后，GloVe明确把自己定位为“LSA式全局矩阵分解”与word2vec式局部窗口预测的结合；word2vec即隐式矩阵分解证明word2vec本质上也在分解一个共现矩阵。检索方面，DSSM深度语义匹配用神经网络取代SVD学习查询与文档的低维表示，稠密检索DPR把“稠密向量检索”变成了今天的主流。

容易误解的地方

  • “潜在语义”只是低秩分解的维度，不对应可以命名的概念，论文作者明确说不尝试解释或旋转这些维度。
  • LSA对多义词基本无能为力：每个词只有一个向量，bank的两个意思被平均在一起。
  • 维度k没有理论最优值，论文的100维是按实验效果挑的。

局限与后续

  • 每个词只有一个固定向量，多义词的不同含义被混在一起，对查准率帮助很小。
    后来针对它的工作　ELMo BERT
  • 线性代数分解没有概率含义，向量有负值、难以解释，也无法自然地给出“文档属于哪些主题”。
    后来针对它的工作　概率潜在语义分析pLSA LDA主题模型
  • 对巨大的词×文档矩阵做SVD代价高，新文档只能近似“折叠”进来，语料一变就要重算。
    后来针对它的工作　word2vec GloVe
  • 只利用“是否在同一文档中出现”，忽略词序和局部窗口信息，在难的集合（CISI）上不比关键词匹配好。
    后来针对它的工作　word2vec DSSM深度语义匹配

它建立在什么之上

  • 使用
    主成分分析PCA1901 · 基础
    核心工具是与PCA同源的奇异值分解：保留最大的若干个奇异值，就是最优的低秩近似。
  • 改进
    Harris分布假说1954 · NLP
    第一次把“意义差异与分布差异相关”变成可在上千篇文档上自动计算的向量表示。
  • 竞争
    k-means聚类1967 · 基础
    同期解决同义问题的另一条路是文档聚类，只能给出离散的类别；LSA给出连续的多维表示，词和文档也在同一空间里。
  • 竞争
    IDF与TF-IDF1972.01 · NLP
    TF-IDF通过调整权重改善逐词匹配，LSA则直接换掉了“逐词匹配”本身；但在CISI上二者效果相同，后来的系统常把两者结合。
  • 改进
    向量空间模型1975.11 · NLP
    向量空间模型里每个词是独立正交的维度、同义词完全不相关；LSA把词和文档投影到共享的低维空间，让无共同词的相关文档也能被检索到。
  • 改进
    RSJ权重与二元独立模型1976.05 · NLP
    词项独立假设忽略了词与词的关联和同义关系，查询词没出现就完全得不到分数。
  • 改进
    Firth：由伴知词义1957 · NLP
    只是一个语言学主张，没有给出可计算的词义表示，也没有说明如何从搭配统计中得到词向量。
  • 改进
    Rocchio相关反馈1971 · NLP
    只能补进与相关文档共现的词，像「Burma」和「Myanmar」这样从不同时出现的同义说法仍然对不上。

后来的相关工作

  • 竞争
    word2vec2013.01 · NLP 已核对
    同为从语料学词的向量表示：LSA对共现矩阵做SVD，word2vec在局部窗口上做预测；论文引用先前工作说神经网络词向量在保持线性规律上明显好于LSA，后来word2vec即隐式矩阵分解指出两类方法在理论上有联系。
  • 改进
    BERT2018.10 · LLM
    每个词只有一个固定向量，多义词的不同含义被混在一起，对查准率帮助很小。
  • 竞争
    Brown聚类1992 · NLP
    同期从语料自动学词的相似性：LSA用整篇文档的共现得到连续向量，偏主题；Brown聚类用相邻词得到离散类，偏句法。
  • 延续
    HITS枢纽与权威1998.01 · NLP
    LSA对词-文档矩阵做奇异值分解，HITS对网页链接矩阵做同样的分解，把主奇异向量解释为权威与枢纽。
  • 竞争
    词向量类比规律2013.06 · NLP
    以同数据训练的LSA计数向量为对照，RNN向量在句法类比上明显更好。
  • 改进
    GloVe2014.10 · NLP
    同样基于全局共现矩阵，但用对数计数和加权最小二乘替代原始计数上的SVD，解决了LSA在类比任务上极差的问题。
  • 改进
    ELMo2018.02 · LLM
    每个词只有一个固定向量，多义词的不同含义被混在一起，对查准率帮助很小。
  • 改进
    概率潜在语义分析pLSA1999.07 · NLP
    给LSA缺乏概率解释的降维补上了概率模型，并用EM而不是SVD来拟合。
  • 改进
    LDA主题模型2003 · NLP
    线性代数分解没有概率含义，向量有负值、难以解释，也无法自然地给出“文档属于哪些主题”。
  • 使用
    gensim主题建模库2010.05 · NLP

  • 延续
    RESCAL张量分解2011.06 · NLP
    LSA对词-文档矩阵做低秩分解，RESCAL把低秩隐因子推广到多关系的三阶张量。
  • 改进
    DSSM深度语义匹配2013.10 · NLP
    LSA是无监督的语义空间；DSSM用点击日志做有监督训练，使语义空间直接服务排序。
  • 延续

    评测对象是LSA这一类分布式语义表示在句子层面的组合版本，相关度分数可直接与句向量的余弦相似度比较。
  • 竞争
    计数与预测词向量对比2014.06 · NLP
    以SVD降维的共现矩阵是计数方法的代表，本文把它和预测方法放在同样条件下比较。
  • 使用
    word2vec即隐式矩阵分解2014.12 · NLP
    把神经嵌入与LSA那类矩阵分解方法统一在同一个框架下。
  • 改进
    词向量的超参数教训2015 · NLP

读懂它需要的概念

特征分解与奇异值分解 低秩近似 降维与PCA 内积与余弦相似度 向量、矩阵与张量 分布假说

本篇术语

  • 词-文档矩阵　行是词、列是文档、元素是词在文档中出现次数（或其加权值）的大矩阵，通常非常稀疏。
  • 伪文档（pseudo-document）　把查询当成一篇很短的文档，用同样的方式投影到低维空间，以便和真文档直接比较。
  • 同义与多义（synonymy / polysemy）　前者是多个词表达同一意思，导致漏检；后者是一个词有多个意思，导致误检。

怎么学

先补特征分解与奇异值分解和低秩近似。读原文第4.1节的9篇标题例子和第4.2节的公式。动手：用numpy把论文表2的12×9矩阵做SVD，取k=2画出词和文档的位置，验证c3、c5靠近查询；再用scikit-learn的TruncatedSVD在20 Newsgroups上做LSA，比较k=10、100、500时近义词检索的效果。
