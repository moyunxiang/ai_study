众包标注够好吗

Cheap and Fast — But is it Good? Evaluating Non-Expert Annotations for Natural Language Tasks
2008.10论文延伸Rion Snow, Brendan O'Connor, Daniel Jurafsky, Andrew Y. Ng · Stanford / Dolores Labs待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

自然语言任务的标注通常要雇语言学专家，又慢又贵，大家怀疑便宜的众包工人能不能给出可用的标签。

方法

在Mechanical Turk上让非专家完成若干常见NLP标注任务，把他们的标签与专家标准答案对比，并研究如何合并多个人的标签。

影响

它用实证说明众包标注在NLP里「足够好」，为后来用MTurk大规模构建数据集提供了依据。

方法

这篇EMNLP 2008论文由斯坦福的Snow等人完成，标题直接提出问题：「又便宜又快——但好吗？」。他们在众包标注Mechanical Turk上发布若干类自然语言标注任务，每条样本交给多个非专家工人，再拿结果与已有的专家黄金标准比较。

核心发现可以概括为：只要把同一条样本交给多名非专家，对他们的标签做合并（比如多数表决，或估计每个人的准确率后加权），其质量就可以接近专家标注，而成本和时间远低于专家。他们还指出，不同工人质量差别很大，需要用已知答案的题目检测并降低不可靠工人的权重。具体的任务清单和数字，本次只核对了论文的题目与作者，未打开正文，因此不列。

这个结论让后来的大量数据集（如ImageNet、SNLI、SQuAD）可以放心采用众包方式建设。

局限与后续

  • 论文研究的是相对简单的标注任务；需要专业知识或主观判断的任务，众包质量未必够用。
