word2vec

Efficient Estimation of Word Representations in Vector Space
2013.01论文主干ICLR 2013 WorkshopTomas Mikolov, Kai Chen, Greg Corrado, Jeffrey Dean · Google来源已核对
arXiv ↗word2vec原始代码（Google Code存档） ↗The Illustrated Word2vec ↗在交互版中打开（演化树、学习进度）

问题

神经语言模型能学出好的词向量，但大部分计算花在非线性隐层和整个词表的输出层上，在几亿词上训练就要几周；而词向量的质量恰恰最依赖数据量和维度。

方法

干脆不做完整的语言模型：去掉非线性隐层，只留“词向量→对数线性分类器”。CBOW用周围的词预测中间词，Skip-gram用中间词预测周围的词，输出层用霍夫曼树层次softmax，计算量从与词表大小成正比降到与其对数成正比。

影响

单机不到一天就能在16亿词上训练出高质量词向量，向量还呈现“king − man + woman ≈ queen”式的线性规律。开源工具和预训练向量让词向量在2013–2018年成为很多NLP模型的常用输入层。

背景

神经概率语言模型、RNN语言模型和从零开始的神经NLP都证明了神经网络学出的词向量有用，问题是太贵。论文把每个训练样本的计算量写成公式。前馈神经语言模型（N个上下文词、D维词向量、H个隐单元、V个词）：

Q = N×D + N×D×H + H×V

即使用层次softmax把H×V降到H×log₂V，主要开销仍在非线性隐层N×D×H。循环网络语言模型是Q = H×H + H×V，同样被隐层主导。论文说，据作者所知，此前的结构都没能在超过几亿词的数据上成功训练，词向量维度也只有50到100；Mikolov自己用于对比的RNNLM在一个CPU上训了约8周。

Mikolov此前的工作发现，可以先用一个只有单隐层的简单网络学词向量，再拿它去训练完整的语言模型。这篇论文就专注于那第一步：怎样以最低的计算量学出最好的词向量。

方法

两种结构（都没有非线性隐层，见嵌入向量）：

  • CBOW（连续词袋）：取当前词前后各4个词，把它们的向量直接平均，送进一个对数线性分类器预测中间那个词。上下文词的顺序被忽略，所以叫“词袋”。计算量Q = N×D + D×log₂V。
  • Skip-gram：反过来，用中间词的向量分别预测前后一定距离内的每个词。实验中最大距离C取10；每次随机取一个R ∈ [1, C]，只预测前后各R个词，这样近处的词被抽到的次数多、权重自然更大。计算量Q = C×(D + D×log₂V)。

层次softmax（层次softmax语言模型）。正常的Softmax与logits要对V个词都算分数再归一化。这里把词表组织成一棵霍夫曼树：高频词路径短、低频词路径长，预测一个词变成沿根到叶子走一串二分类，每个二分类是一个sigmoid。词表100万时，需要计算的节点数约为log₂(一元困惑度)，比log₂V ≈ 20还少。

为什么向量会有“代数”。训练目标迫使出现在相似上下文里的词得到相似的向量（分布假说）。如果“big→biggest”与“small→smallest”在上下文中的差异相似，那么两个差向量就会相近，于是vector(biggest) − vector(big) + vector(small)的最近邻就是smallest。论文据此构造了一个测试集：8,869道语义题（如首都与国家）和10,675道句法题（如比较级、复数），答案必须恰好是最近的那个词才算对。

训练。随机梯度下降，学习率从0.025线性降到0；大规模实验放在Google的DistBelief分布式框架上异步训练。

结果

同数据同维度比较（640维）：语义/句法准确率，RNNLM 9%/36%，前馈NNLM 23%/53%，CBOW 24%/64%，Skip-gram 55%/59%。Skip-gram在语义题上大幅领先。

与公开向量比较（完整测试集总准确率）：Collobert-Weston 50维11.0%，Mikolov RNNLM 640维24.6%；单CPU训练的300维CBOW 36.1%（约1天）、Skip-gram 53.3%（约3天），只用了7.83亿词。

规模。用DistBelief在60亿词Google新闻语料上训练1000维向量：CBOW总准确率63.7%（2天×140核），Skip-gram 65.6%（2.5天×125核），而100维NNLM要14天×180核才到50.8%。表2显示，维度和数据量必须同时增大，准确率才会持续上升。

句子补全：微软句子补全挑战上，Skip-gram单独48.0%，与RNNLM组合后58.9%，超过此前最好的55.4%。

后来的发展

同年10月的续作Skip-gram负采样提出负采样、高频词下采样和短语向量，开源工具随之流行，Google新闻上训练的300维向量被广泛使用。此后：GloVe用全局共现矩阵学到同样的线性结构，word2vec即隐式矩阵分解证明带负采样的Skip-gram在隐式分解一个PMI矩阵，fastText加入子词以处理未登录词，doc2vec段落向量推广到段落，TransE知识图谱嵌入把“关系是向量平移”的思想用于知识图谱，无平行语料的词翻译MUSE利用不同语言词向量空间的相似结构做无平行语料的词翻译，词向量中的性别偏见则揭示向量中“man − woman ≈ programmer − homemaker”式的性别偏见。

2018年起，在多数任务上，ELMo和BERT的上下文相关表示逐渐取代了静态词向量作为模型输入。但“通过预测上下文学表示”这一自监督思想，以及“嵌入表把离散符号变成向量”这一步，在今天的大模型中依然如故。

容易误解的地方

  • 论文标题里的“word2vec”其实是后来开源工具的名字；这篇提出的是CBOW和Skip-gram两种结构，负采样出自同年的续作Skip-gram负采样。
  • 类比测试要求答案恰好是最近邻，而且排除题目中的三个词；同义词也算错，所以准确率天然达不到100%，不同论文的类比分数只有在同一测试集、同一规则下才可比。
  • 它不是语言模型：CBOW和Skip-gram不能给句子打概率，也不能生成文本，只是为了学词向量设计的简化分类器。

局限与后续

  • 每个词只有一个固定向量，“bank”是银行还是河岸、“苹果”是水果还是公司都无法区分。
    后来针对它的工作　CoVe上下文词向量 ELMo BERT
  • 以整词为单位，看不到词的内部结构，词表外的新词、拼写变体和罕见的形态变化没有向量。
    后来针对它的工作　fastText BPE子词切分
  • “New York”“Air Canada”这类意义不能由单词组合得到的短语没有自己的向量；高频词（the、of）占据大量训练计算却几乎不提供信息。
    后来针对它的工作　Skip-gram负采样
  • 为什么向量相减能表达语义关系、它和传统共现矩阵方法是什么关系，论文没有给出理论解释。
    后来针对它的工作　word2vec即隐式矩阵分解 GloVe
  • 向量忠实复制语料中的社会偏见，例如职业词与性别词的关联，会被下游模型继承。

读懂它需要的概念

嵌入向量 独热编码与词表 Softmax与logits 分布假说 内积与余弦相似度 随机梯度下降与小批量 时间与空间复杂度

本篇术语

  • CBOW　连续词袋模型：把上下文窗口内各词的向量取平均，用它预测中间的词。训练快，句法类比好。
  • Skip-gram　跳字模型：用中间词的向量分别预测窗口内的每个上下文词。训练稍慢，语义类比和低频词表现更好。
  • 霍夫曼树　按频率构造的二叉编码树，高频词离根近、编码短。层次softmax用它让常见词的预测只需很少几步二分类。
  • 词类比测试　给出a:b = c:?，用向量b − a + c找余弦最近的词（排除a、b、c），看是否等于正确答案，如Athens:Greece = Berlin:Germany。

怎么学

先补嵌入向量、Softmax与logits和内积与余弦相似度，读过神经概率语言模型。读原文第2节（各模型计算量公式）、第3节（两种结构与图1）、表3和表6；接着读Skip-gram负采样，那才是工具实际默认用的训练方法。动手：用gensim在维基百科子集上训练Skip-gram，做“国家−首都”类比和最近邻查询；再自己用NumPy写一个带负采样的Skip-gram，在text8语料上跑通。
