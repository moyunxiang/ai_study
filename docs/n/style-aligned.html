StyleAligned共享注意力

Style Aligned Image Generation via Shared Attention
2023.12论文延伸CVPR 2024Amir Hertz, Andrey Voynov, Shlomi Fruchter, Daniel Cohen-Or · Google Research、特拉维夫大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用同一句风格描述生成一组图，每张的画风仍会各不相同；要统一风格通常得微调或手工分离内容与风格。

方法

在同一批次的去噪过程中做极少量的“注意力共享”：让每张图的自注意力也能看到参考图的键和值，从而继承参考图的风格。

影响

不需训练就能生成一组风格一致的图，配合反演还能以真实图片为风格参考，被diffusers社区pipeline收录。

方法

文生图模型的自注意力层负责图像内部各位置之间的信息交换，也承载了大量风格信息。StyleAligned把一批图像中的第一张当作参考：其他图在自注意力里除了看自己的键和值，还额外看参考图的键和值，而参考图本身不受影响。

直接共享会让内容也被抄过去，作者对参考图的特征做了AdaIN式的统计量对齐，只让各图的查询和键在均值方差上向参考图靠拢，从而迁移风格而保留各自内容。若要以一张真实图片为风格参考，先用DDIM反演把它变成初始噪声，再在采样时共享注意力。整个方法在推理时完成，不需要微调。

局限与后续

  • 共享注意力让每步计算量随批大小增加；参考图内容较强时仍会有内容泄漏。
