VGG

Very Deep Convolutional Networks for Large-Scale Image Recognition
2014.09论文重要ICLR 2015Karen Simonyan, Andrew Zisserman · 牛津大学视觉几何组（VGG）待核对
arXiv ↗项目页与预训练模型 ↗在交互版中打开（演化树、学习进度）

问题

AlexNet之后大家都在调卷积核大小、步长、宽度，结构五花八门，没人系统回答过“网络更深是否就更好、该怎么加深”。

方法

固定其他一切，全部使用3×3的小卷积核，只改变深度，从11层一直堆到16层和19层，系统比较深度带来的收益。

影响

证明深度是性能的关键，16/19层网络在ILSVRC-2014拿到定位第一、分类第二；结构极其规整、预训练权重公开，成为此后几年检测、分割、风格迁移最常用的骨干网络。

背景

AlexNet用了11×11、5×5、3×3多种卷积核，第一层步长4；2013年的改进（卷积网络可视化、OverFeat）主要是改第一层的核大小和步长、加宽网络。这些改动没有统一原则，各家的网络差别很多，很难看出到底是哪个因素在起作用。

另一方面，网络加深会遇到两个实际问题：参数和计算量随层数增加，以及深网络的梯度不稳定、难以从随机初始化训起来（见梯度消失与梯度爆炸）。

方法

只用3×3卷积。两层3×3卷积叠起来，感受野等于一层5×5；三层叠起来等于一层7×7。用三层3×3代替一层7×7有两个好处：

  • 中间多了两次ReLU，表达能力更强；
  • 参数更少：输入输出都是C个通道时，三层3×3共3 × 3² × C² = 27C²个参数，一层7×7要49C²，多出81%。

规整的结构。卷积步长1、补零保持尺寸；每过一个2×2最大池化，空间尺寸减半，通道数翻倍（64→128→256→512→512）；最后接3个全连接层（4096、4096、1000）。论文给了A到E五种配置，权重层数分别为11、11、13、16、19，参数量1.33亿到1.44亿。最常用的是VGG-16（配置D）和VGG-19（配置E）。

训练。沿用AlexNet的配方：批大小256、动量0.9、权重衰减5×10⁻⁴、前两个全连接层Dropout 0.5、学习率10⁻²并下降3次，共74轮。深网络难以从随机初始化训起，所以先训11层的A，再用它的前4个卷积层和3个全连接层初始化更深的网络。训练时把图像短边随机缩放到256–512之间再裁224×224（尺度抖动），在4块Titan Black上训一个网络需要2–3周。

结果

ImageNet验证集上，深度从11层增加到16/19层，top-5错误率持续下降，19层后趋于饱和。ILSVRC-2014：7个网络集成的分类测试top-5错误率7.3%，获分类第二（冠军GoogLeNet / Inception 6.7%）、定位第一；赛后2个网络集成降到6.8%。单网络测试错误7.0%，比单个GoogLeNet低0.9个百分点。

后来的发展

VGG的价值更多在于它的“可复用性”：结构简单、权重公开，迁移到其他任务几乎不用改。全卷积网络FCN和DeepLab空洞卷积用它做分割，Fast R-CNN、Faster R-CNN用它做检测，感知损失用它的中间层衡量图像相似度，OpenPose、CRNN文字识别以它为骨干。“堆叠3×3卷积、每次下采样通道翻倍”成为之后几乎所有CNN的基本设计规则。

它的问题也很快暴露：1.38亿参数大多在全连接层，每张图的计算量也远大于AlexNet；继续加深到20层以上，训练误差反而变大。一年后ResNet用残差连接解决了加深的问题，以更少的计算量训练了152层网络，取代VGG成为默认骨干。

容易误解的地方

  • VGG的深度来自堆叠小卷积核，而不是某种新组件；它本质上是一次控制变量实验。
  • VGG在ILSVRC-2014分类上是第二名，第一名是GoogLeNet。

局限与后续

  • 加深到19层后性能饱和，再深就训练不动（需要先训浅网络来初始化），无法继续靠深度提升。

它建立在什么之上

  • 改进
    AlexNet2012.09 · 视觉 已核对
    沿用AlexNet的训练配方和卷积—池化—全连接框架，把各种尺寸的卷积核统一为3×3并把深度从8层推到16–19层。
  • 改进
    LeNet与卷积网络1998 · 视觉 待核对
    tanh类激活容易饱和、梯度变小，网络只有两个卷积层；再加深就难以训练，CPU上训一次就要几天。
  • 延续
    卷积网络可视化2013.11 · 视觉
    ZFNet调小了第一层卷积核和步长；VGG把“小卷积核”贯彻到每一层。
  • 使用
    Network In Network2013.12 · 视觉
    配置C借用NIN的1×1卷积来增加非线性而不改变感受野。
  • 竞争
    GoogLeNet / Inception2014.09 · 视觉
    同年独立的另一种加深方案：GoogLeNet用多分支Inception模块，参数少得多，分类更好（6.7%对7.3%）；VGG结构更简单、更易迁移。两者都被ResNet取代。

读懂它需要的概念

卷积层、池化与感受野 参数量、计算量与显存 梯度消失与梯度爆炸 Dropout 数据增强 Top-1与Top-5错误率

本篇术语

  • 感受野　输出特征图上一个点能“看到”的输入图像区域大小。每叠一层3×3卷积，感受野边长加2。
  • 尺度抖动　训练时把图像缩放到随机大小后再裁剪，让网络见到不同尺度的同一物体，是一种数据增强。
  • 骨干网络　在检测、分割等任务里负责提取特征的那部分网络，通常是一个在ImageNet上预训练好的分类网络去掉最后的分类层。

怎么学

先学会卷积层、池化与感受野里感受野和参数量的计算，自己验证27C²对49C²。读原文第2节（结构与表1）和第4节（深度的消融）。动手：用torchvision加载VGG-16，打印每层输出形状与参数量，看参数集中在哪里；再用它的conv4_3特征做一个简单的图像检索。
