谷歌拍得Hinton团队

2013.03事件延伸Geoffrey Hinton、Alex Krizhevsky、Ilya Sutskever · 多伦多大学 / 谷歌待核对
WIRED ↗在交互版中打开（演化树、学习进度）

问题

AlexNet取得突破后，几家大公司都想把掌握这项技术的团队挖走，而三人刚成立了一家只有他们的公司。

方法

2013年3月谷歌买下三人的公司DNNresearch，Hinton一半时间留在多伦多，两位学生到谷歌山景城上班。

影响

标志着深度学习的核心人才进入产业界，也开启了AI研究者被大公司收购式招聘的时代。

方法

据WIRED（2013年3月13日），谷歌在周二宣布聘用Hinton及其两位多伦多大学研究生Alex Krizhevsky和Ilya Sutskever，目的是帮助谷歌处理其索引的海量数据并改进安卓语音搜索等已用机器学习的产品；谷歌通过收购Hinton的公司DNNresearch完成这项交易，价格没有披露。Hinton可以留在多伦多，兼顾教学，两位学生去谷歌山景城。

这三人正是AlexNet的作者，Hinton也是反向传播一文的作者之一。此后他在谷歌工作到2023年（见Hinton离开谷歌警告风险）。
