BitFit

BitFit: Simple Parameter-efficient Fine-tuning for Transformer-based Masked Language-models
2021.06论文延伸ACL 2022Elad Ben-Zaken, Shauli Ravfogel, Yoav Goldberg · Bar-Ilan University / AI2待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

微调整个BERT要保存完整副本，而Adapter等方法需要额外模块。

方法

只训练模型里的偏置项（bias）及其子集，其余权重全部冻结。

影响

以极简方式证明只调偏置就能逼近全量微调，推动对“微调到底在改什么”的讨论。

方法

Transformer里每个线性层和LayerNorm都带偏置向量，它们只占全部参数的很小一部分。BitFit只更新这些偏置，其余冻结，因此每个任务只需存很少的参数，不需要改结构，也不加推理延迟。论文在BERT类掩码语言模型上做实验，摘要称在小到中等数据量时可与全量微调相当，数据更多时与其它稀疏微调方法相当；摘要中没有给出具体数字。作者还观察到只更新部分偏置（如与注意力查询和中间层相关的）已足够，暗示微调主要是在“暴露”预训练学到的知识，而不是学新东西。

局限与后续

  • 数据量大时落后于全量微调和LoRA；表达力受偏置数量限制，无法调节容量。
    后来针对它的工作　LoRA
  • 只验证了中小规模的BERT类编码器。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 使用
    BERT2018.10 · LLM

  • 竞争
    Adapter2019.02 · 系统·效率
    同为参数高效微调，Adapter加模块，BitFit不加任何模块。

后来的相关工作

  • 竞争
    LoRA2021.06 · 系统·效率 已核对
    BitFit只训练偏置项，是同期的另一种极简方案（LoRA论文称其为同时期工作）；在GPT-3上，470万参数的LoRA在WikiSQL、MNLI-m和SAMSum上都高于1420万参数的BitFit。

怎么学

读论文第2–3节，然后用PyTorch把BERT中名字含bias的参数设为可训练、其余冻结，在一个GLUE任务上试试。
