1000层网络的自监督RL

1000 Layer Networks for Self-Supervised RL: Scaling Depth Can Enable New Goal-Reaching Capabilities
2025.03论文重要NeurIPS 2025（最佳论文奖）Kevin Wang, Ishaan Javali, Michał Bortkiewicz, Tomasz Trzciński, Benjamin Eysenbach · Princeton University / Warsaw University of Technology待核对
arXiv ↗项目主页与代码 ↗NeurIPS 2025最佳论文公告 ↗在交互版中打开（演化树、学习进度）

问题

语言和视觉模型动辄上百层，而RL网络通常只有2–5层；以往把RL网络加宽还有一点收益，加深则往往无效甚至变差，RL似乎吃不到“放大模型”的红利。

方法

换一种不靠奖励的自监督RL目标（对比RL，本质是一个分类损失），再配上残差连接、LayerNorm和Swish激活，把行动者和评论者网络从4层一路加深到1024层。

影响

在10个目标到达任务上性能提升2到50倍，且在某些临界深度出现跳跃式的新行为（如人形机器人从扑倒变为直立行走、翻越墙壁），给出RL也能“越深越强”的直接证据。

背景

2024年前后，BBF、SimBa等工作发现把RL网络加宽可以带来收益，但它们都只用约4层MLP，加深基本没用。一个常见解释是：RL的反馈太稀疏（一长串动作后才有一个奖励），每个参数分到的学习信号太少；所以主流看法是大模型应先用自监督训练，RL只用来微调。

作者的出发点是把两者合一：用一种本身就是自监督的RL算法。对比RL（目标条件）正是这样——它不需要奖励函数和示范，只要求智能体学会到达指定的目标状态，评论者的训练是一个对比分类问题。配合基于JAX的GPU并行仿真（Brax、MJX），数据量也能跟上。

方法

对比RL回顾（见对比学习、Actor-Critic与优势函数）。评论者由两个编码器组成：φ(s, a)编码当前状态和动作，ψ(g)编码目标；两者在表示空间中越接近，说明从(s, a)出发越可能到达g。训练时同一批里，同一条轨迹上的(s_i, a_i)和它将来到达的状态g_i是正样本，其他轨迹的g_j是负样本，用InfoNCE损失——相当于一个“这个目标是不是我这条轨迹的未来”的多分类交叉熵。行动者π(a | s, g)则学会选让评论者得分最高的动作。

加深的配方。每个残差块由4个“全连接层 → Layer Normalization → Swish”单元组成，块的输入直接加到输出上（h_{i+1} = h_i + F(h_i)，见ResNet与残差连接）。深度定义为所有全连接层的总数，行动者和两个评论者编码器同时加深：4、8、16、32、64，最深到1024层。宽度固定为256时，深度32的网络只有约200万参数，而4层、2048宽的网络约3500万参数。

稀疏奖励的评测。只有智能体到达目标附近时才算成功，指标是1000步中待在目标附近的步数。

结果

与以往常用的4层网络相比，加深后在机械臂操作任务上提升2–5倍，在长距离的Ant迷宫任务上超过20倍，在人形机器人任务上超过50倍；在10个环境中的8个上优于SAC、SAC+HER、TD3+HER、GCBC、GCSL。性能不是平滑上升，而是在临界深度跳跃：Ant Big Maze约在8层，Humanoid U-Maze约在64层；人形机器人在4层时只会扑向目标，16层学会直立行走，256层学会翻越中间的墙。只加宽到2048（深度4）不如把深度加到8（宽度256）。加深后增大批大小才开始有用。对照实验显示，基于TD的SAC、TD3类方法在4层后就饱和，加深没有收益。

后来的发展

这篇论文获得NeurIPS 2025最佳论文，把RL放大的讨论从“加宽”推到“加深”，并与用分类训练价值函数一起支持一个猜想：分类式的损失（交叉熵）可能是RL网络能像语言模型那样放大的关键。它与同期研究价值型RL扩展规律的价值型RL的可预测扩展互为补充。

容易误解的地方

  • 结论限定在在线、目标条件、自监督的对比RL上；论文自己的对照显示，SAC、TD3等基于TD的算法加深后没有收益。
  • 1024层时行动者损失在训练初期爆炸，实际只把两个评论者编码器做到1024层，行动者保持512层。

读懂它需要的概念

Actor-Critic与优势函数 对比学习 残差连接 归一化层 奖励设计与奖励投机 幂律与规模定律

本篇术语

  • 目标条件RL　策略的输入除了当前状态还有一个目标状态，任务就是到达这个目标；奖励只是“是否到达”。
  • InfoNCE　对比学习常用的损失：在一批候选里把正确配对的那一个挑出来，形式上就是多分类交叉熵。
  • 临界深度　本文观察到的现象：性能随深度不是平滑增加，而是到某个层数时突然大幅提升，并伴随行为方式的质变。

怎么学

先读对比RL（目标条件），弄懂“评论者=两个编码器的距离、InfoNCE训练”。再读原文第3节（目标条件RL与对比RL）、第4.2–4.5节（深度、宽度、批大小与可视化）。动手：用作者基于JaxGCRL的代码，在Ant迷宫上把深度从4改到16，对比成功率和训练时间。
