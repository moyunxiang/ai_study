R-max乐观探索

R-MAX - A General Polynomial Time Algorithm for Near-Optimal Reinforcement Learning
2002.10论文重要JMLR 2002（会议版IJCAI 2001）Ronen I. Brafman, Moshe Tennenholtz · Ben-Gurion University / Technion待核对
JMLR ↗在交互版中打开（演化树、学习进度）

问题

E3与PAC探索理论证明了多项式时间内能学到近最优策略，但算法要显式地在「探索」和「利用」两种模式间切换，复杂且难以推广到对抗环境。

方法

把所有没试够的状态-动作都乐观地假设成能拿到最大奖励R_max，然后始终按这个乐观模型的最优策略行动，探索会自然发生。

影响

把「面对不确定性保持乐观」从经验技巧变成了有理论保证的原则，成为PAC-MDP理论和后来乐观探索算法的标准起点。

背景

1990年代的强化学习实践里，探索通常靠ε-贪心之类的随机扰动，理论上没有效率保证：在某些环境里，随机探索要指数级的步数才能碰到奖励。E3与PAC探索理论（Kearns和Singh）第一次证明可以在状态数、动作数和时间尺度的多项式时间内学到近最优策略，但它的算法要维护「已知状态」集合，显式判断现在该去探索还是该利用，结构复杂。同一时期，马尔可夫博弈把单智能体MDP推广到两人零和对局，这类环境里的高效学习更没有简单的算法。

方法

R-max是一个基于模型的算法。智能体始终维护一个完整的MDP模型，但这个模型一开始是乐观的：所有状态下的所有动作都被假设会得到最大可能的奖励R_max，并且转移到一个虚构的「天堂」状态，在那里一直拿R_max。这就是名字的由来。

智能体每一步都按当前模型求出最优策略并执行。某个状态-动作被访问够一定次数后，就把它标为「已知」，用真实观测到的奖励和转移频率替换掉乐观假设，然后重新规划。

关键性质是：如果当前策略的实际回报不如模型预测的高，说明它一定会以不小的概率走进某个未知的状态-动作，于是那里很快被试够、变成已知；如果实际回报接近预测，说明策略已经近最优。两种情况都推进学习，所以不需要显式的探索/利用切换。作者证明它在多项式时间内达到近最优的平均回报。

摘要列出了它相对已有工作的改进：比E3与PAC探索理论更简单、更一般，并覆盖零和随机博弈；内置了解决探索-利用两难的机制；为许多RL算法里「面对不确定性保持乐观」的偏好给出了形式化依据；还推广了重复博弈里的几种学习算法。

后来的发展

R-max之后，PAC-MDP（以高概率在多项式步数内只犯有限次错误）成为分析探索效率的标准框架，MBIE、Delayed Q-learning等算法都沿用「乐观初始化+已知集合」的思路；后悔值框架下的UCRL2遗憾界则把乐观原则改写成置信区间上的乐观规划。深度RL里的伪计数探索伪计数探索和随机网络蒸馏RND可以看作在大状态空间里近似「哪些状态还没试够」的办法。表格形式的R-max本身今天只用于教学和理论分析。

局限与后续

  • 需要为每个状态-动作单独计数，只适用于小的离散状态空间，无法直接用在图像等高维输入上。
    后来针对它的工作　伪计数探索 随机网络蒸馏RND
  • 多项式界里的常数和次数很大，「试够m次」的阈值在实践中远比需要的保守，样本效率不高。
    后来针对它的工作　UCRL2遗憾界
  • 需要预先知道奖励上界R_max；乐观值设得过大时，智能体会花大量时间探索无关紧要的状态。
    本站还没有记录针对它的后续工作（不代表没有人解决）

    Dyna：学习与规划合一1990 · RL

  • 使用
    Shapley随机博弈1953.10 · RL
    零和随机博弈的设定和求解方法来自Shapley的框架。
  • 延续
    马尔可夫博弈1994 · RL
    把高效探索的保证从单智能体MDP推广到两人零和随机博弈。
  • 改进
    E3与PAC探索理论1998 · RL
    去掉E3里显式的探索/利用模式切换，用一个乐观模型统一两者，并推广到零和博弈。

  • 改进

    MBIE区间估计探索2008.12 · RL

  • 竞争
    后验采样RL（PSRL）2013.06 · RL
    同为有理论保证的高效探索，R-max用乐观初始化，PSRL用随机化的后验样本。
  • 改进
    伪计数探索2016.06 · RL
    需要为每个状态-动作单独计数，只适用于小的离散状态空间，无法直接用在图像等高维输入上。
  • 延续
    Bellman秩与OLIVE2016.10 · RL
    同样基于“面对不确定性保持乐观”，乐观对象从未知状态换成了候选价值函数。

读懂它需要的概念

马尔可夫决策过程 探索与利用 基于模型的强化学习 动态规划 时间与空间复杂度

本篇术语

  • 面对不确定性保持乐观　对没把握的选项先往好处想，这样智能体会主动去试它们，试过后真实信息会纠正过高的估计。
  • PAC-MDP　一种探索效率的标准：以高概率保证，除了多项式次数的步骤外，智能体的行为都接近最优。

怎么学

先复习马尔可夫决策过程和值迭代；读原文第2–3节的算法描述和主定理的直观证明；在一个链式MDP（只有走到最远端才有奖励）上对比ε-贪心Q学习和R-max，观察后者探索步数的差异。
