WordNet

WordNet: A Lexical Database for English
1995数据集延伸George A. Miller, Christiane Fellbaum et al. · Princeton University待核对
Wikipedia ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

计算机不知道词与词的意思关系：「汽车」和「轿车」是一回事，「狗」是「动物」的一种，词典里只有给人看的释义。

方法

把英语词按意思分成同义词集（synset），再用上下位、整体与部分等关系把这些集合连成一张大网。

影响

它成了词义消歧、语义相似度等任务的标准词汇资源，也是ImageNet类别体系的骨架。

方法

WordNet由普林斯顿大学认知科学实验室在心理学家George Miller的领导下，于1985年开始建设，后来由Christiane Fellbaum接手。它既像词典又像同义词词典：同义词被归入同义词集（synset），每个集合带一句简短释义和例句；集合之间用同义、上下位（猫是动物）、部分整体（轮子是汽车的一部分）等语义关系相连。

一个多义词（如bank）会出现在多个synset里，因此可用来标注「这个词在这句话里是哪个意思」，这就是Senseval / SemEval评测的基础。图像领域同样依赖它：ImageNet的上千个类别直接取自WordNet的名词synset，8000万Tiny Images也用它列出要搜索的名词。

它由语言学家人工编写，质量高但更新慢；据维基百科，截至2026年该项目已不再开发，在线版本也已关闭，社区维护的Open English WordNet等继续使用其数据。

局限与后续

  • 全靠人工编写，新词、新义和专业术语覆盖不足，更新缓慢。
    后来针对它的工作　word2vec GloVe
  • 区分的词义过于细碎，连人类标注者之间也常常无法一致，限制了词义消歧的评测上限。
    后来针对它的工作　ELMo BERT

它建立在什么之上

  • 竞争
    Cyc常识知识库1984 · 事件
    Cyc试图手工写下大量常识断言，WordNet只做词与词的意义关系，范围更小，因而被广泛实用。

后来的相关工作

  • 使用
    ImageNet2009.06 · 数据·评测 已核对
    直接以WordNet的名词同义词集和“是一种”层级作为类别体系与查询词来源。
  • 改进
    word2vec2013.01 · NLP
    全靠人工编写，新词、新义和专业术语覆盖不足，更新缓慢。
  • 改进
    BERT2018.10 · LLM
    区分的词义过于细碎，连人类标注者之间也常常无法一致，限制了词义消歧的评测上限。
  • 使用
    Yarowsky自举词义消歧1995.06 · NLP
    论文提出可以从WordNet的同义词和上位词中自动取得种子。
  • 使用
    语义角色标注2002 · NLP
    用WordNet的上位词层级把稀疏的中心词归到更一般的语义类别，以缓解数据稀疏。
  • 延续
    Freebase2007.03 · NLP
    WordNet把词义之间的关系做成网络，Freebase把同样的“节点加关系”思路用到数以百万计的具体实体与事实上。
  • 使用
    TransE知识图谱嵌入2013.12 · NLP
    WN数据集取自WordNet的词义与上下位等关系，用来检验层级关系的建模能力。
  • 改进
    GloVe2014.10 · NLP
    全靠人工编写，新词、新义和专业术语覆盖不足，更新缓慢。
  • 改进
    ELMo2018.02 · LLM
    区分的词义过于细碎，连人类标注者之间也常常无法一致，限制了词义消歧的评测上限。
  • 延续
    FrameNet1998.08 · 数据·评测

本篇术语

  • 同义词集（synset）　意思相同的一组词，是WordNet的基本单位。
  • 上下位关系　「猫」是「动物」的下位词，「动物」是「猫」的上位词。

怎么学

用NLTK加载wordnet，查询dog的所有synset及其上位链，再比较两个词的路径相似度。
