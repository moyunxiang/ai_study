偏差-方差权衡

Neural Networks and the Bias/Variance Dilemma
1992论文重要Neural Computation 1992Stuart Geman, Elie Bienenstock, René Doursat · 布朗大学 / ESPCI巴黎待核对
Neural Computation（DOI） ↗原文扫描PDF（MIT 6.435课程页） ↗在交互版中打开（演化树、学习进度）

问题

反向传播流行后，大家相信网络够大、数据够多就能学会任何东西；但网络为什么有时在新数据上表现很差、该用多大的网络，没有清楚的解释。

方法

把神经网络看成非参数回归，把预测误差拆成噪声、偏差²、方差三项：模型太死板则偏差大，太自由则方差大，只能在两者之间权衡，而降低方差的根本办法是引入正确的先验结构。

影响

让“偏差-方差权衡”成为机器学习的标准语言，用来解释过拟合、早停和正则化；同时提出“难点在表示而非学习本身”，这一判断后来被深度学习的发展所印证与修正。

背景

反向传播之后，多层网络被大量用于识别任务，万能近似定理又证明了足够多隐藏单元的网络能逼近任意连续函数。一个流行的乐观看法是：网络是“白板”式的通用学习器，只要更多数据、更快的并行硬件，问题自然解决。

统计学家对这类“不假设模型形式”的方法早有研究，称为非参数估计，例如k近邻和核平滑。Geman等人的问题是：把神经网络放进这个框架里看，它能学什么、需要多少样本？

方法

分解。设真实关系是y = g(x) + 噪声，用训练集D学到的预测函数为f(x; D)。对所有可能抽到的训练集取期望E_D，在某个输入x处的均方误差可以拆成三项：

E[(y − f(x;D))²] = 噪声方差 + (E_D[f(x;D)] − E[y|x])² + E_D[(f(x;D) − E_D[f(x;D)])²]

第一项是数据本身的随机性，谁也消除不了；第二项是偏差²：换无数个训练集取平均，预测仍然系统性地偏离真值多少；第三项是方差：换一个训练集，预测会抖动多少（见偏差-方差权衡）。

两个极端。以k近邻为例：k = N时预测就是全体样本的平均，几乎不随训练集变化，方差小但偏差极大；k = 1时贴着每个样本走，偏差小但对训练集里的偶然噪声极其敏感，方差大。中间某个k最好。神经网络的隐藏单元数、训练步数都扮演同样的“平滑参数”角色：单元多、训练久，偏差降而方差升。

怎么测。这个分解的好处是可以实际算出来：反复抽取多个独立训练集，各训练一个模型，在同一批测试点上看平均预测离真值多远（偏差）、各模型彼此差多远（方差）。

结果

手写数字实验：共1200个数字，留出600个（每类60个，加了20%像素翻转噪声）作测试；每个训练集只取200个（每类20个），对k近邻和Parzen核方法各抽100个训练集、对反向传播网络抽50个。三种方法都呈现清楚的U形总误差曲线。一个只有4个隐藏单元的网络，总误差在约100轮迭代时最低，此后训练误差继续下降但测试误差上升——即使这么小的网络也会过拟合，这为早停提供了直接的解释。作者据此认为当时的前馈网络对困难的感知问题“基本不够用”，根本挑战在于找到合适的表示和先验结构。

后来的发展

偏差-方差分解从此成为讲过拟合、正则化（权重衰减）、集成方法（Bagging靠平均降方差）时的标准框架。文中“需要把正确的偏置内建进模型”的主张，与卷积网络的权值共享（LeNet与卷积网络）等思路一致。

但深度学习时代出现了它解释不了的现象：参数远多于样本、能把训练集完全背下来的网络照样泛化得很好（重新思考泛化）；继续增大模型越过“插值点”后测试误差反而再次下降，即插值区与双下降曲线与双下降。经典的U形曲线只描述了故事的前半段。

容易误解的地方

  • 偏差和方差是对“所有可能的训练集”取期望得到的，单次训练无法直接测出，需要重复抽样。
  • 平方误差下的分解最干净；对0-1分类误差，偏差和方差不能简单相加。
  • “模型越大方差越大”在经典区间成立，但在过参数化的深度网络里常常不成立。

读懂它需要的概念

期望与方差 泛化与过拟合 偏差-方差权衡 k近邻 多层感知机 训练集、验证集与测试集

本篇术语

  • 非参数估计　不预先假设函数形式（如线性），而让数据决定函数形状的估计方法。参数数量可以随数据量增长。
  • 早停　在验证误差开始上升时停止训练，即使训练误差还在下降。从偏差-方差角度看，是用训练步数控制方差。

怎么学

先补期望与方差和泛化与过拟合，然后看偏差-方差权衡。读原文第1节和第3.1–3.5节（分解与实验），图15、16最值得看。动手：用多项式拟合带噪声的正弦曲线，对每个阶数重复抽100次训练集，算出偏差²和方差并画成曲线；再把阶数推到远超样本数并加一点岭正则，看看能不能复现双下降。
