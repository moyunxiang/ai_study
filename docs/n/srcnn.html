SRCNN超分辨率

Learning a Deep Convolutional Network for Image Super-Resolution
2014.09论文延伸ECCV 2014 / TPAMI 2016Dong, Loy, He, Tang · 香港中文大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

超分辨率方法由稀疏编码等多个独立模块拼成，各模块不能联合优化。

方法

用一个三层卷积网络直接学习从低分辨率图到高分辨率图的端到端映射。

影响

第一个把深度学习用于单图超分辨率的工作，此后超分辨率研究几乎全部转向深度网络。

方法

先用双三次插值把低分辨率图放大到目标尺寸，再送入三层卷积网络：第一层提取图块特征，第二层做非线性映射，第三层重建出高分辨率图。论文指出，这三步恰好对应稀疏编码超分辨率方法中的「图块提取与表示、非线性映射、重建」三个独立步骤，而网络把它们作为一个整体联合训练。

网络很轻量，摘要称达到当时最好的恢复质量，且速度快到可用于在线场景；后续版本还扩展到三个颜色通道同时处理。损失采用逐像素的均方误差。

局限与后续

  • 先插值再卷积，计算量按放大后的尺寸增长，且网络很浅。
    后来针对它的工作　SRGAN
  • 均方误差训练得到的图偏平滑，缺少纹理细节。
    后来针对它的工作　感知损失 SRGAN
