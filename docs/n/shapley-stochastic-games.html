Shapley随机博弈

Stochastic Games
1953.10论文延伸PNAS 1953Lloyd S. Shapley · RAND Corporation / Princeton待核对
PNAS (DOI) ↗维基百科：Stochastic game ↗在交互版中打开（演化树、学习进度）

问题

冯·诺依曼的博弈论只处理一次性或静态的对局，现实里的对抗往往一步步进行，局面会随双方的选择随机变化。

方法

定义随机博弈：每一步处在某个状态，双方同时选动作，得到收益并按概率转移到新状态；证明两人零和情形存在值，并可用逐状态求解矩阵博弈的迭代算出来。

影响

它是马尔可夫决策过程的多人推广，后来的马尔可夫博弈、多智能体Q学习和整个多智能体RL的形式化都从这里出发。

方法

Shapley把对局写成一组状态。在每个状态里，两个玩家同时选动作，按收益表拿到即时收益，然后游戏以一定概率结束、以其余概率按转移概率跳到下一个状态。只有一个玩家时，这就是后来的马尔可夫决策过程；只有一个状态且只玩一步时，它退化成《博弈论与经济行为》与极小极大里的矩阵博弈。

他的核心结果针对两人零和、每步都有正的停止概率的情形：整个随机博弈存在一个值，而且双方都有只依赖当前状态的平稳最优策略。求法是一种迭代：假设已经知道每个状态的值，就把「即时收益+后继状态值的期望」填成每个状态的一张矩阵，解这张矩阵博弈得到新的值，反复迭代；由于停止概率为正，这个映射是收缩的，迭代收敛到唯一的值。这和几年后动态规划与Bellman方程的值迭代是同一种结构，只是每一步的「取最大」换成了「解一个矩阵博弈」。

四十年后，马尔可夫博弈把这个框架重新引入机器学习，提出minimax-Q；独立Q学习多智能体、Nash-Q以及今天的多智能体深度RL，形式上都是在随机博弈里学习。

局限与后续

  • 存在性与求解结果只覆盖两人零和博弈，一般和博弈的均衡难以计算，也不唯一。

读懂它需要的概念

马尔可夫决策过程 博弈论基础与纳什均衡 马尔可夫性与马尔可夫链 Bellman方程

本篇术语

  • 随机博弈（stochastic game）　多个玩家在一串随机变化的状态中反复对局的模型，也叫马尔可夫博弈。
  • 平稳策略　只看当前状态、不看历史和时间步的策略。

怎么学

先复习矩阵博弈的极小极大解和MDP的值迭代；读原文前两页的定义和定理；动手写一个两状态的零和随机博弈，用线性规划逐状态求解并迭代到收敛。
