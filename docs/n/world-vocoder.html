WORLD声码器

WORLD: A Vocoder-Based High-Quality Speech Synthesis System for Real-Time Applications
2016.07论文延伸IEICE Trans. Inf. & Syst. 2016Masanori Morise, Fumiya Yokomori, Kenji Ozawa · 山梨大学待核对
IEICE ↗STRAIGHT (1999) ↗在交互版中打开（演化树、学习进度）

问题

参数语音合成需要一个声码器把基频、频谱包络等参数还原成波形；高质量的STRAIGHT声码器计算慢、长期不完全开放，传统的简单声码器音质又带明显的「嗡嗡」机器味。

方法

把语音分解为三组参数——基频F0、平滑的频谱包络、非周期性指标——并为每一步设计快速算法，做成能实时运行、开源的高质量声码器。

影响

WORLD成为统计参数TTS、语音转换和歌声合成的标准声码器，被Merlin等合成工具和大量开源项目采用，直到神经声码器普及前一直是这类系统的默认选择。

方法

在HMM参数语音合成和DNN参数语音合成这类统计参数合成里，模型并不直接生成波形，而是预测每帧的声学参数，再由声码器把参数合成为声音。1999年Kawahara等人的STRAIGHT提出了基音自适应的时频平滑，能从语音中提取不受谐波结构干扰的频谱包络，音质远好于以前的声码器，成为研究界的标杆，但它计算量大，并非完全开源。

WORLD沿用同样的分解思路，由三个分析算法和一个合成算法组成：DIO（后来改进为Harvest）估计基频F0；CheapTrick利用F0自适应的窗函数和平滑，估计不受谐波影响的频谱包络；D4C估计每个频带的非周期性（噪声成分所占比例）。合成时，按F0生成周期性脉冲，与按非周期性指标混合的噪声一起，经过由频谱包络决定的滤波器，得到波形。各步骤都为速度设计，可以实时运行。

论文报告WORLD在音质上与STRAIGHT等当时的高质量声码器相当、速度更快（具体数字未核对）。它可以独立修改音高、时长和音色，因此也被广泛用于语音转换和歌声合成。之后WaveNet、LPCNet轻量声码器等神经声码器在音质上超过了它。

  • 延续
    Dudley声码器与Voder1939.10 · 语音
    同样把语音分解为激励和频谱包络，再重新合成，是声码器思想的高质量现代实现。
  • 竞争
    线性预测编码LPC1971.08 · 语音
    LPC声码器用全极点模型描述频谱，音质有明显机器味；WORLD用平滑的频谱包络和非周期性指标，质量更高。

    HMM参数语音合成2000.06 · 语音

本篇术语

  • 频谱包络　频谱的平滑轮廓，反映声道形状，决定了音色和是哪个音素。
  • 非周期性　每个频带里噪声成分占多大比例，浊音的高频和清音都含有较多非周期成分。
