β-VAE与解耦表示

beta-VAE: Learning Basic Visual Concepts with a Constrained Variational Framework
2016.11论文延伸ICLR 2017Higgins, Matthey, Pal, Burgess, Glorot, Botvinick, Mohamed, Lerchner · Google DeepMind待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

希望无监督地学到一维对应一个独立变化因素（如大小、位置）的表示，但普通变分自编码器VAE得到的潜变量彼此纠缠。

方法

把VAE目标里的KL项乘上一个大于1的系数β，更强地压低潜变量的信息容量，让它倾向于解耦。

影响

一行代码的改动成为解耦表示研究的基准方法，也引出了对「解耦能否无监督学到」的大量讨论。

方法

β-VAE的目标是 L = E[log p(x|z)] − β·KL(q(z|x) ‖ p(z))。β=1就是标准变分自编码器VAE。β>1时，对后验偏离各维独立的标准高斯先验惩罚更重，潜变量必须只保留重建所需的最重要信息，而且各维倾向于独立，这样每一维更可能对应一个单独的生成因素。

代价是重建会变模糊，所以存在解耦程度与重建质量的折中。作者还提出一个度量解耦的分类器指标，并在3D椅子、人脸、2D形状等数据上展示了单独改变某一维潜变量只改变一个属性。

局限与后续

  • β大了重建质量下降，且最优β依赖数据集，需要靠有监督信号调。
    后来针对它的工作　NVAE层级VAE
  • 后续理论工作指出，无监督解耦在没有归纳偏置或监督时不可识别，该方法没有此保证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    变分自编码器VAE2013.12 · 生成 待核对
    在VAE目标中给KL项加权重β>1，强调与先验的接近。
  • 改进
    表示学习综述2012.06 · 基础
    解耦（让每个维度对应一个独立因子）被当作目标，但没有说明如何在没有监督信号时可靠地实现。
  • 竞争
    后验坍塌与KL退火2015.11 · 生成
    同样是通过调KL项的权重来改变VAE对潜变量的使用程度，但方向相反：这里想要更强约束，那边想要更弱。
  • 改进
    InfoGAN2016.06 · 生成
    c的个数、类型和先验要靠人事先设定，不保证学到的因素与人想要的一致。

后来的相关工作

  • 竞争
    VQ-VAE2017.11 · 生成
    两者都想让隐变量更有意义：β-VAE加大KL权重追求解耦的连续表示，VQ-VAE改用离散表示，后者在生成任务上被更广泛采用。
  • 改进
    SAC+AE像素自编码2019.10 · RL
    指出β-VAE等随机自编码器是离策略训练发散的原因，改用确定性正则化自编码器。
  • 改进
    NVAE层级VAE2020.07 · 生成
    β大了重建质量下降，且最优β依赖数据集，需要靠有监督信号调。
  • 使用
    GIVT连续token生成2023.12 · 生成
    用β-VAE作分词器，靠β控制隐空间的信息量与平滑度。
