自底向上注意力

Bottom-Up and Top-Down Attention for Image Captioning and Visual Question Answering
2017.07论文重要CVPR 2018Peter Anderson, Xiaodong He, Chris Buehler, Damien Teney, Mark Johnson, Stephen Gould, Lei Zhang · 澳大利亚国立大学 / 微软研究院 / 京东AI研究院 / 阿德莱德大学 / 麦考瑞大学待核对
arXiv ↗官方代码（区域特征提取） ↗在交互版中打开（演化树、学习进度）

问题

图像描述和视觉问答里的注意力都是在CNN特征图的均匀网格上做的，一个物体常被切进好几个格子，模型很难把注意力落到“这只狗”“那张沙发”这样完整的对象上。

方法

先用在Visual Genome上训练的Faster R-CNN“自底向上”框出图中最显著的约36个物体区域，每个区域一个2048维特征；再让任务模型“自顶向下”根据当前生成的词或问题，在这些区域之间分配注意力。

影响

同时拿下MSCOCO图像描述和2017年VQA挑战赛第一；它提取的区域特征此后成为ViLBERT、LXMERT、UNITER等一整代视觉-语言预训练模型的标准视觉输入。

背景

2015年的视觉注意力让图像描述模型在生成每个词时回看图像的不同位置；视觉问答（VQA）里的堆叠注意力SAN、双线性池化MCB也用类似的注意力。这类注意力被称为“自顶向下”（top-down）：由任务上下文（已生成的半句话、或问题）决定看哪里。

但它们“看”的单位是CNN最后一层的网格，比如7×7或14×14个等大的格子。格子与物体的边界毫无关系：一个人可能横跨十几个格子，一个小杯子可能只占半个格子。模型要在格子上拼凑出“物体”，既费力又容易看错。人的视觉注意则更像是先被显眼的物体吸引，再决定关注哪个。

方法

自底向上：区域从哪来。用Faster R-CNN（骨干为ImageNet预训练的ResNet-101）在Visual Genome上训练。作者把Visual Genome里自由书写的物体和属性名清洗成1600个物体类和400个属性类，还额外加了一个属性预测头（比如“红色的”“木头的”），逼特征学到更细的语义。推理时对每张图保留置信度超过0.2的区域，数量10到100个不等；作者发现直接取前36个几乎一样好，这个“每图36个区域”后来成了惯例。每个区域的特征是框内卷积特征的平均池化，2048维。

自顶向下：看哪个区域。描述模型有两层LSTM：第一层是注意力LSTM，输入为上一步的语言状态、全部区域的平均特征和当前词；它的输出h_t与每个区域特征v_i算一个分数a_i = w_aᵀ tanh(W_v v_i + W_h h_t)，经softmax得到权重α_i，加权求和v̂ = Σ α_i v_i；第二层语言LSTM拿v̂预测下一个词。VQA模型同理，只是用问题向量去给区域打分，再与问题向量逐元素相乘、预测3129个候选答案的概率。描述模型最后还用以CIDEr为奖励的强化学习（自我批评序列训练）微调。

结果

MSCOCO官方测试服务器上，4个模型集成取得CIDEr 117.9、SPICE 21.5、BLEU-4 36.9，提交时超过所有已公开和未公开的结果。在Karpathy测试划分上做单模型对照：把输入从ResNet网格特征换成区域特征，CIDEr从111.1升到120.1（CIDEr优化后），各项指标相对提升3–8%。VQA v2.0测试集上30个模型集成的总体准确率70.34，赢得2017年VQA挑战赛；单模型验证集上从网格基线的59.4升到63.2，计数类问题提升最明显（37.7到42.8）。

后来的发展

这篇论文的副产品——公开的Visual Genome检测器及其“每图36个区域、每区域2048维”的特征——在之后约三年里几乎是所有视觉-语言模型的视觉输入：ViLBERT、VisualBERT、LXMERT、UNITER、OSCAR都直接用它。代价是每张图都要先过一遍检测器，成为整个流程最慢的一环，而且检测器冻结、不随任务训练。2021年ViLT和CLIP改为直接从图像块（patch）提特征，绕开检测器；到LLaVA这一代，视觉输入已完全换成ViT的网格token。“由任务决定关注哪些视觉单元”的思想则保留了下来，变成了Transformer里的跨模态注意力。

    图像描述Show and Tell2014.11 · 多模态

    保留其“生成每个词时重新分配注意力”的做法，但把注意力的单位从均匀网格换成检测出的物体区域，解决了物体被格子切碎的问题。

  • 使用
    Visual Genome2016.02 · 数据·评测

    HieCoAtt协同注意力2016.05 · 多模态
    图像侧仍是CNN最后一层的规则网格特征，注意力单位是格子而不是物体，难以对准“伞”“人”这样的完整目标。

    双线性池化MCB2016.06 · 多模态
    MCB是2016年VQA挑战的冠军路线，靠复杂的双线性融合；本文用简单的逐元素乘法融合，胜负主要来自更好的区域特征。
  • 改进
    自适应注意力视觉哨兵2016.12 · 多模态
    视觉特征仍是CNN的规则网格，注意力对象不是完整的物体，容易只看到物体的一部分。
  • 使用
    VQA v22016.12 · 数据·评测
    在去除语言偏差的VQA v2.0上评测，并以70.34的成绩赢得2017年挑战赛。

读懂它需要的概念

注意力机制 分类、检测、分割 锚框与非极大值抑制 循环网络与隐状态 Softmax与logits 策略梯度

本篇术语

  • 自底向上 / 自顶向下注意力　借用认知科学的说法：自底向上指由图像本身的显著性决定候选区域（与任务无关）；自顶向下指由当前任务（问题、已生成的词）决定在候选中关注哪个。
  • CIDEr / SPICE　图像描述的自动评测指标。CIDEr按TF-IDF加权比较生成句与参考句的n-gram；SPICE把句子解析成“物体-属性-关系”的场景图再比较。
  • 自我批评序列训练（SCST）　把CIDEr分数当奖励、用策略梯度直接优化生成句的强化学习方法，基线取模型自己贪心解码得到的句子的分数。

怎么学

先懂视觉注意力的软注意力和Faster R-CNN的区域提议。读原文第3.1节（检测器怎么训练、怎么选区域）和3.2节的公式(3)–(5)。动手：用开源的预提取36区域特征在COCO上训练一个两层LSTM描述模型，再换成7×7网格特征对比，复现“区域比网格好”的结论。
