PATE教师集成隐私学习

Semi-supervised Knowledge Transfer for Deep Learning from Private Training Data
2016.10论文延伸ICLR 2017Nicolas Papernot, Martín Abadi, Úlfar Erlingsson, Ian Goodfellow, Kunal Talwar · 宾夕法尼亚州立大学、Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模型会无意中记住训练数据（如病历），DP-SGD要在每一步训练里加噪，且对模型和训练过程有较多要求，隐私与精度难以兼顾。

方法

把敏感数据分成互不相交的几份，各训一个“老师”；老师们对公开的无标签数据投票，投票结果加噪后用来训练一个对外发布的“学生”。

影响

给出与DP-SGD并列的第二条深度学习差分隐私路线，黑盒、与模型无关，成为隐私机器学习教材里的标准方法。

方法

设想一家医院有一批病历。PATE把它们切成N份互不重叠的子集，每份独立训练一个老师模型，老师模型不对外公开。随后拿一批不敏感的无标签数据，让N个老师分别预测，统计每个类别的票数，在票数上加入随机噪声（拉普拉斯噪声）后取最高票作为标签。学生模型只在这些带噪标签上训练，最后只发布学生。

直觉是：任何一条病历只出现在一个老师的训练集里，最多改变一票；当老师们意见高度一致时，加一点噪声也不改变结果，所以单条记录对学生几乎没有影响。这个直觉可以用差分隐私严格表述，而且即使攻击者能查看学生的内部参数也成立。为了少用老师的标签（每问一次都消耗隐私预算），学生用半监督学习，只对少量样本请求标签。

与DP-SGD不同，PATE对老师怎么训练几乎没有要求，可以是任何模型。作者凭借改进的隐私分析和半监督学习，在MNIST和SVHN上取得了当时最好的隐私与精度权衡。

局限与后续

  • 需要大量与敏感数据同分布的公开无标签数据，类别多、任务复杂时老师之间意见分散，隐私开销迅速变大。
    本站还没有记录针对它的后续工作（不代表没有人解决）

怎么学

先读差分隐私理解ε的含义 → 读原文第2–3节的聚合机制与隐私分析 → 在MNIST上用10个老师复现带噪投票，观察噪声大小与学生精度的关系。
