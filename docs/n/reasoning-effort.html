思考预算与推理强度

OpenAI o1 and new tools for developers
2024.12思想延伸官方公告 2024-12-17OpenAI · OpenAI待核对
OpenAI公告（存档） ↗在交互版中打开（演化树、学习进度）

问题

推理模型想得越久越准，但也越慢越贵，开发者无法控制每次请求愿意花多少思考。

方法

API给o1加上reasoning_effort参数，让调用者调节模型回答前思考的长短。

影响

把「思考多久」变成可调参数，此后几乎所有推理模型API都提供了类似的预算或档位。

方法

2024年12月17日OpenAI把o1正式放进API，同时加入函数调用、开发者消息、结构化输出和视觉输入。新的reasoning_effort参数用来控制模型回答前思考多久：同样的问题，低强度更快更省，高强度更准更慢。官方称这个版本的o1平均比o1-preview少用60%的推理token。

这是测试时计算扩展所说测试时算力的第一个产品化旋钮。之后思考预算的做法在不同厂家各有形式：Anthropic按token设预算（见Claude可见扩展思考），o3/o4-mini工具内推理提供不同档位，Gemini提供思考预算参数。

后来的发展

它让推理成本变成开发者可控的部分，也为推理模型的过度思考提出的「简单题不要想太久」提供了手动解法，后来的模型转向自动决定思考长度。

局限与后续

  • 需要使用者自己判断该选哪一档，模型不会按题目难度自适应。
    后来针对它的工作　Claude 3.7 Sonnet混合推理
  • 档位只是粗粒度，不能保证思考越长结果越好。
