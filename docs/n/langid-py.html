langid.py语种识别

langid.py: An Off-the-shelf Language Identification Tool
2012.07系统延伸ACL 2012 DemoMarco Lui, Timothy Baldwin · 墨尔本大学、NICTA待核对
ACL Anthology ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

给一段文本判断它是什么语言，是爬取网页语料、做多语言处理的第一步。已有工具要么只支持少数语言，要么在短文本、跨领域（新闻训练、微博测试）时准确率大跌，使用前还要自己准备训练数据。

方法

做一个开箱即用的语种识别工具：预先在多个领域的数据上训练好覆盖97种语言的模型；特征是字节级n-gram，并用「信息增益」挑出跨领域都稳定、只与语言相关的n-gram；分类器用多项式朴素贝叶斯，单个Python文件即可运行。

影响

langid.py一度是网页语料清洗中最常用的语种识别工具，CCNet、多语言维基与网页数据集的构建都用过它或其后继；跨领域特征选择的思路也被后来的fastText语种识别等工具借鉴。

背景

语种识别早在1994年就有Cavnar与Trenkle基于字符n-gram排序的方法（TextCat），在长文本、干净数据上准确率接近100%，因此常被认为是「已解决的问题」。但在推特、网页标题这类短文本上，或者训练与测试来自不同领域时，表现明显下降；同时可用的现成工具很少，覆盖语言也有限。

方法

特征：文本按UTF-8字节序列处理，提取1到4字节的n-gram，这样不需要针对每种文字写分词或编码规则。

跨领域特征选择：训练数据来自多个领域（政府文件、维基百科、网页、新闻等）。对每个n-gram计算两种信息增益：对「语言」标签的信息增益 IG_lang 和对「领域」标签的信息增益 IG_domain，选出 IG_lang − IG_domain 最大的n-gram，即那些能区分语言、但不随领域变化的特征，最终保留约7000个。

分类器：多项式朴素贝叶斯：

ŷ = argmax_语言L [ log P(L) + Σ_n count(n) · log P(n | L) ]

用Aho-Corasick自动机一次扫描文本即可统计所有特征n-gram的出现次数，因此速度很快。模型直接序列化在Python文件里，支持命令行、Python调用和网页服务，也可用自己的数据重新训练。

结果

论文报告langid.py在多个跨领域测试集上的准确率与当时最好的工具相当或更好，同时速度很快；具体数字未核对。

后来的发展

后来Facebook的fastText发布了基于子词n-gram的语种识别模型（lid.176，覆盖176种语言），在网页语料构建中逐渐取代langid.py；Google的CLD3、NLLB项目的多语种识别模型继续扩展到数百种语言。短文本、方言和语码混用（一句话夹杂两种语言）至今仍是语种识别的难点。

本篇术语

  • 语种识别（language identification）　判断一段文本使用的是哪种语言，是多语言语料清洗和处理的第一步。
  • 跨领域特征选择　挑选那些对区分语言有用、但在不同来源（新闻、网页、社交媒体）之间分布稳定的特征，以提高在新领域上的鲁棒性。

怎么学

先了解朴素贝叶斯分类和字符n-gram → 读原文第2–3节特征选择 → 动手：用langid.py和fastText的lid.176分别识别一批推特短句的语种，比较错误类型。
