GPT-4o全模态实时模型

Hello GPT-4o
2024.05模型主干OpenAI来源已核对
Hello GPT-4o（官方发布） ↗GPT-4o System Card（arXiv） ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT的语音模式是三个模型的流水线：语音转文字、GPT-4处理文字、再把文字转成语音。平均要等2.8–5.4秒才有回应，而且GPT-4听不到语气、分不清几个人在说话，也发不出笑声和歌声。

方法

训练一个从头就同时处理文字、图像和音频的单一神经网络：任意组合的文字、音频、图像、视频进来，文字、音频、图像出去，中间不再经过文本这道“翻译”。

影响

语音回应最快232毫秒、平均320毫秒，接近人类对话节奏；英文和代码能力与GPT-4 Turbo相当，API价格减半，并向ChatGPT免费用户开放；之后多家公司陆续推出能实时听、看、说的助手。

背景

到2024年初，ChatGPT已经能看图（GPT-4V）、能语音对话，但这些能力是拼起来的。语音模式里，一个简单模型先把语音转写成文字（OpenAI的开源语音识别模型Whisper就是这类模型），GPT-4读文字、写文字，第三个模型再把文字合成语音。官方给出的平均延迟是2.8秒（GPT-3.5）和5.4秒（GPT-4）。

更根本的问题是信息丢失：转写只留下“说了什么字”，语气、情绪、停顿、背景噪声、几个人在说话全都没了；输出端也只能用固定的腔调把文字念出来。学术界已在尝试把语音直接变成语言模型能读的离散token（AudioPaLM、SpiRit-LM交错语音文本），Meta的Chameleon早期融合把图像离散化后与文字放进同一个序列，Google的Gemini 1.0从训练之初就是多模态的。但这些工作都还没有做成面向大众、能实时语音对话的产品。

方法

OpenAI没有公开GPT-4o的结构、参数量和音频表示方式。公开的信息有：

  • 单一网络、端到端训练。系统卡称GPT-4o是一个“自回归全模态（omni）模型”，所有输入和输出都由同一个神经网络处理，跨文字、视觉、音频端到端训练。文本和语音能力的预训练数据截至2023年10月，包括公开网页、代码和数学数据、多模态数据，以及授权合作数据。
  • 为什么这样能更快、更“像人”（以下为一般原理，不是OpenAI披露的细节）：要让Transformer直接处理音频，常见做法是用神经音频编解码器（见声码器与音频编解码）把声音切成每秒几十个离散token，与文字token交错放进同一个序列，用同样的下一个token预测来训练（见自回归生成）。这样模型读到的是声音本身，能感知语气和情绪；输出时直接生成音频token再解码成波形，不必等整句文字生成完再合成，因此首个声音可以很快出来。
  • 新的分词器。官方选了20种语言展示新分词器的压缩率：同一段问候语，古吉拉特语从145个token降到33个（少4.4倍），印地语从90降到31（2.9倍），中文从34降到24（1.4倍）。token越少，非英语用户的速度越快、费用越低。
  • 安全措施。语音输出只允许使用与配音演员合作制作的几种预设声音，并另设分类器检测偏离；系统卡称能拦截100%的明显偏离。模型经过训练拒绝根据声音识别说话人、拒绝对说话人做无依据推断（如“这个人有多聪明”）。外部红队超过100人，分四个阶段测试。按OpenAI的准备度框架，“说服力”一项被评为“临界中等”风险，其余为低风险，因此整体评为中等风险。
  • 分阶段开放。2024年5月13日发布当天，ChatGPT开始上线文字和图像能力（包括免费用户），API先开放文字和视觉；新的语音模式在随后数周后以小范围alpha形式提供给Plus用户。

结果

官方数字：语音输入的回应时间最短232毫秒、平均320毫秒，旧语音模式为2.8秒和5.4秒。英文文本和代码与GPT-4 Turbo持平，非英语文本明显提升；相比GPT-4 Turbo，API速度快一倍、价格便宜一半、速率上限高5倍。官方称其在多语言、音频和视觉理解基准上创下新高。发布会上演示了实时翻译、边看手机摄像头边辅导数学、根据要求改变说话的情绪和语速、两个GPT-4o相互对唱等。

后来的发展

GPT-4o之后，多家公司陆续推出“一个模型实时听、看、说”的助手。发布次日Google展示了类似的Project Astra实时助手；开源方面，Moshi全双工语音对话实现了可以边听边说的全双工语音对话，VITA开源全模态、MiniCPM-o 2.6全模态、Qwen2.5-Omni相继做出开源的全模态模型。2024年10月OpenAI推出OpenAI Realtime API，让开发者直接调用语音到语音能力。2025年3月，GPT-4o原生图像生成开放了GPT-4o原生的图像输出能力，可以在对话中生成并多轮修改图片。

它也带来了新的问题。语音让模型更像一个“人”，系统卡专门讨论了拟人化与情感依赖的风险；2025年4月的一次更新让GPT-4o变得过度讨好用户而被回滚（GPT-4o谄媚更新回滚）。2026年1月29日OpenAI宣布在ChatGPT中下线GPT-4o，2月中旬执行，引起部分长期把它当作陪伴的用户强烈反弹。推理能力方面，GPT-4o不做长链思考，在数学和复杂推理上很快被OpenAI o1推理模型超过。

容易误解的地方

  • “端到端”是OpenAI的官方说法，具体如何表示音频、模型多大、用了多少数据都没有公开，外界的结构描述都是推测。
  • 发布当天上线的只是文字和图像能力，大家印象最深的实时语音在数月后才逐步开放给付费用户；图像生成更是近一年后才开放。
  • 232毫秒是最快情况，平均是320毫秒；实际产品中的延迟还取决于网络和服务负载。

    AudioPaLM2023.06 · 语音 已核对
    两者都把语音和文本放进一个语言模型统一处理。AudioPaLM公开了做法（把语音离散成token、从PaLM-2初始化）；GPT-4o未公开音频如何表示，无法确认是否采用类似做法，也没有说明建立在AudioPaLM之上。

    Chameleon早期融合2024.05 · 多模态 已核对
    同月Meta公开了早期融合的混合模态模型Chameleon，把图像离散为token与文字共享一个序列，但不含语音、也不是实时产品。
  • 改进
    Whisper2022.09 · 语音 待核对
    旧语音模式先用Whisper把语音转写成文字，语气、多说话人和背景声都丢了；官方称GPT-4o直接读入音频，不再经过这道转写。
  • 改进
    Google Duplex打电话2018.05 · 语音

    GPT-4 Turbo2023.11 · LLM
    128K只是窗口长度，模型对长上下文中段信息的利用仍不可靠；文本、视觉、语音仍由不同模型或管线拼接。

本篇术语

  • 全模态（omni）模型　同一个模型既能接收也能生成文字、图像、音频等多种模态，不依赖外接的转换模型。
  • 级联（流水线）语音助手　语音识别、文本模型、语音合成三个独立模型串联的做法；每一步都要等上一步完成，并只靠文字传递信息。
  • 首响延迟　从用户说完话到助手发出第一个声音的时间，是实时语音对话体验的关键指标；人类对话中通常在几百毫秒量级。

怎么学

先补分词与token、自回归生成和声码器与音频编解码，理解“声音也能变成token”。然后读Hello GPT-4o发布页（重点看语音模式流水线那一段和分词器压缩示例），再读GPT-4o系统卡第3节，了解语音模态特有的风险。想看一个开源的可复现实现，可以读Moshi全双工语音对话的论文并在本地运行它，对比级联方案（Whisper+文本LLM+TTS）的延迟。
