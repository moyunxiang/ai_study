PubMedQA生物医学问答

PubMedQA: A Dataset for Biomedical Research Question Answering
2019.09数据集延伸EMNLP 2019Qiao Jin, Bhuwan Dhingra, Zhengping Liu, William W. Cohen, Xinghua Lu · 匹兹堡大学 / 卡内基梅隆大学 / Google AI待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

已有的生物医学问答多是事实检索；读懂一篇研究摘要、根据其中的数据推断研究问题的结论，缺少专门的数据集。

方法

以PubMed里标题是问句的论文为题，给出去掉结论段的摘要，让模型回答是、否或也许；1千条由医学生标注，另有大量无标签和自动生成的样本。

影响

成为生物医学问答的常用基准，并被Med-PaLM收进MultiMedQA；Flan-PaLM在上面达到79.0%，超过论文中单个人类标注者的78.0%。

方法

样本构成。从PubMed筛选标题带问号、摘要有结构化结论段的论文。每条样本包括：问题（论文标题或由标题改写）、上下文（去掉结论段的摘要）、长答案（结论段本身）和是/否/也许的短答案。

三个子集。PQA-L是两位医学博士候选人标注的1,000条，其中500条用于交叉验证、500条作测试集；PQA-U是61.2k条无标签样本；PQA-A是211.3k条自动生成的样本：把陈述句标题前移或补上系动词、助动词改写成问句，再按句中动词是否被否定自动给出是/否标签，主要用于预训练。

两种设定。主设定是“需要推理”：只给问题和上下文，结论段不可见，模型要从摘要里的方法和数字推出答案。另一种“无需推理”设定允许看结论段。作者的最好模型是多阶段微调的BioBERT，并把预测长答案的词袋统计当作辅助监督。

结果

需要推理的设定下，最好的模型准确率68.1%，单个人类标注者78.0%，全部答“是”的多数类基线为55.2%；能看到结论段时，人类准确率升到90.4%。Med-PaLM论文报告Flan-PaLM 540B在PubMedQA上达到79.0%，比此前最好的BioGPT高0.8个百分点。

后来的发展

PubMedQA与MedQA、MedMCQA一起被Med-PaLM收进MultiMedQA，此后医学大模型（如Med-PaLM 2）的报告通常都会列出它。它展示了一种低成本扩充数据的方法：利用论文自带的结构（标题是问题、结论是答案）自动造出数十万条弱标注样本。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    基线和最好模型都基于BERT的生物医学版本BioBERT微调。
  • 延续
    SQuAD2016.06 · 数据·评测
    同属给定段落的阅读理解，但答案不是从原文抽取片段，而要根据摘要中的数据推断出是、否或也许。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

本篇术语

  • PQA-L / PQA-U / PQA-A　PubMedQA的三个子集：人工标注1k条、无标签61.2k条、规则自动生成211.3k条；论文报告的测试成绩只在PQA-L的500条测试样本上计算。
  • MultiMedQA　Med-PaLM论文汇总的医学问答评测组合，包含MedQA、MedMCQA、PubMedQA、MMLU临床相关科目等六个已有数据集和新收集的HealthSearchQA。

怎么学

先了解BERT的微调方式。读原文第3节（三个子集与两种设定）和表4、表5。动手：从PQA-L测试集抽20条，只看问题和上下文判断是/否/也许，再对照结论段，体会“需要推理”设定的难点。
