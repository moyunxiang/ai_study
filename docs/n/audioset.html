AudioSet

Audio Set: An ontology and human-labeled dataset for audio events
2017.03数据集延伸ICASSP 2017Gemmeke, Ellis, Freedman, Jansen, Lawrence, Moore, Plakal, Ritter · Google待核对
官方页面 ↗在交互版中打开（演化树、学习进度）

问题

音频事件识别缺少与 ImageNet 对应的大规模数据，没有统一的声音类别体系，难以训练和比较通用的音频模型。

方法

建立一套层级化的声音事件本体，并让标注员为 YouTube 视频里的10秒片段打上标签，形成大规模人工标注数据集。

影响

成为通用音频表示学习的主要数据来源和评测基准，音频分类模型和音频-文本预训练工作常在它上面训练或评测。

方法

官方页面称，AudioSet 包含一个由632个音频事件类别组成的、层级结构的本体，以及2,084,320个人工标注的10秒视频片段（约5800小时音频），其中527类有标注。本体覆盖人声和动物声、乐器与曲风、日常环境声等。

数据采集用 YouTube 元数据和基于内容的搜索来提名候选片段，再由人工标注员确认片段里是否真的出现了某种声音。思路与 ImageNet 用 WordNet 组织类别并靠众包验证相近。它让研究者可以像训练图像分类器一样，在统一类别上训练大规模的音频模型。

局限与后续

  • 标签是片段级（10秒里出现过什么），没有精确的起止时间，也不含语音内容的文字。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 数据以链接形式提供，YouTube视频会被删除或下架，数据集难以完整保留。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    ImageNet2009.06 · 数据·评测
    沿袭 ImageNet 的大规模人工验证标注与统一类别体系，对象换成声音。
  • 竞争
    WordNet1995 · 数据·评测
    ImageNet 用 WordNet 组织类别，AudioSet 则自建了面向声音的层级本体。
  • 改进
    ESC-50环境声音2015.10 · 数据·评测
    每段只有一个标签，不能描述多个声音同时出现的真实场景；更大规模的多标签事件识别要靠后来的AudioSet。

后来的相关工作

  • 竞争
    Clotho音频描述2019.10 · 数据·评测
    AudioSet给声音打类别标签，Clotho给声音写自然语言描述。
  • 使用
    Audio-MAE2022.07 · 语音
    在AudioSet的大量音频片段上做自监督预训练并评测。
  • 改进
    LTU音频理解大模型2023.05 · 语音
    AudioSet式模型只能输出固定类别标签；LTU用自然语言回答开放式问题并给出理由。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
