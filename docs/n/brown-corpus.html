Brown语料库

1961数据集延伸W. Nelson Francis, Henry Kučera · Brown University待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

研究语言规律需要大量真实文本，但1960年代几乎没有可供计算机处理、又覆盖多种文体的公开英语文本。

方法

从1961年美国出版物中按文体抽样，凑成500段、各约2000词的样本，做成可在计算机上检索统计的标准语料。

影响

它是第一个大型的、分文体的电子语料库，此后几十年词频统计、词性标注和n-gram实验的默认基准。

方法

Brown语料库由布朗大学的Francis和Kučera编成，原名叫「适用于数字计算机的当代美式编辑英语标准样本」。它从1961年在美国出版的作品里抽取500个样本，每个样本2000多词，覆盖新闻、小说、学术等不同文体，总共约101万词（1,014,312词）。

它的价值在于「标准」二字：所有人拿到同一批文本、同一套统计，结果可以互相比较。1967年两位作者出版《当代美式英语的计算分析》，给出词频等基本统计。后来研究者在它上面加了词性标注，它成了早期统计词性标注器的训练和测试数据；它的规模和抽样思路也影响了后来的Penn Treebank（见Penn Treebank）。

一百万词放在今天很小——现代语言模型的训练文本是它的几百万倍——但它确立了「语言研究先有共享数据，再比方法」的做法。

局限与后续

  • 规模只有约100万词，且只有1961年的美式书面英语，不含口语、网络文本，也不覆盖其他语言。

它建立在什么之上

  • 使用
    香农：语言的统计模型1948 · NLP
    Shannon提出的n-gram统计需要大量真实文本才能估计词的概率，Brown语料库提供了最早的这类数据。

后来的相关工作

  • 使用
    神经概率语言模型2003.02 · NLP 已核对
    主实验在Brown语料上做，前80万词训练、20万词验证、其余测试。
  • 使用
    HMM词性标注1988 · NLP
    所有概率都从人工标注了词性的一百万词Brown语料中直接统计。
  • 延续
    TIMIT语音语料1990 · 数据·评测
    延续Brown语料库“按设计抽样、覆盖均衡、公开共享”的语料建设思路，从书面文本扩展到语音。
  • 改进
    Penn Treebank1993 · 数据·评测
    沿用Brown语料的标记体系并精简到36个词性标记，还把Brown语料按新标准重标了一遍，并在规模和句法层面大幅扩展。
  • 使用
    FrameNet1998.08 · 数据·评测
    以大规模英语语料中的真实例句作为标注对象，而不是造句。
  • 使用
    NLTK2002.07 · NLP
    自带Brown语料等经典语料作为练习数据。
  • 改进
    English Gigaword2003 · 数据·评测
    同样是分类型整理的英文电子语料，但规模大了约三个数量级。
  • 改进
    Google Web 1T 5-gram2006.08 · 数据·评测
    样本是人工按比例抽取的，研究者无法低成本地把语料扩大几个数量级。
  • 改进
    Common Crawl与网络规模文本2008 · 数据·评测
    规模只有约100万词，且只有1961年的美式书面英语，不含口语、网络文本，也不覆盖其他语言。
