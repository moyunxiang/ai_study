so-vits-svc歌声转换

2023.03系统延伸svc-develop-team（开源社区）待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

想让某个人的声音唱任意歌（AI翻唱），传统歌声合成要乐谱和歌词标注，变声方法又难保住歌声里的音高和韵律。

方法

不走文本：用SoftVC/ContentVec这类自监督内容编码器从源歌声提取内容特征，连同音高一起直接送入VITS重建出目标歌手的声音。

影响

2023年AI翻唱热潮中最流行的开源工具之一，约2.8万星；README要求发布作品时注明源声与素材，是社区自律规范的早期案例。

方法

so-vits-svc做的是歌声转换而不是TTS，README特别强调它不支持文本转语音。流程是：从源歌声里用内容编码器提取逐帧特征，早期版本用SoftVC，4.0以后改用ContentVec第12层Transformer输出；同时提取基频F0。这些特征不经过任何文字中间表示，直接作为VITS的输入，VITS在目标歌手几十分钟到几小时的干声上训练，学会用该歌手的音色重建歌声。因为ContentVec去说话人表示已去掉大部分源音色而保留内容，F0又保住了旋律，输出就是“目标歌手在唱这首歌”。后续版本加入浅扩散模型提升音质，并支持Whisper-PPG等编码器。

局限与后续

  • 需要为每位目标歌手单独训练，数据质量要求高；高音、气声和与原唱音域差距大时容易失真。
