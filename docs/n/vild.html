ViLD开放词表检测

Open-vocabulary Object Detection via Vision and Language Knowledge Distillation
2021.04论文延伸ICLR 2022Gu, Lin, Kuo, Cui · Google Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

检测器只能认训练集里有标注的类别，要增加类别就得对每个新类别重新标框，成本极高。

方法

把预训练的视觉语言模型（CLIP类）蒸馏进检测器：让检测器框的区域嵌入既对齐类别文本嵌入，也对齐老师对该区域的图像嵌入。

影响

使检测器在没有新类别框标注的情况下识别它们，开启开放词表检测路线。

方法

做法：以两阶段检测器（Mask R-CNN）为学生。一方面把类别名文本编码成向量，检测器对每个候选框的区域嵌入与之做余弦匹配，训练时只用基础类别的框；另一方面，对每个候选区域裁剪后让预训练的开放词表分类模型（老师，见知识蒸馏）编码出图像嵌入，让学生框的区域嵌入去逼近它，从而把老师对新类别的知识带进检测器。在LVIS上，他们把稀有类别全部当作训练时从未见过的新类别。

论文称ResNet-50骨干下达到16.1 mask AP_r，比有监督对照还高3.8；换更强的老师ALIGN后达到26.3 AP_r（摘要）。

后来的发展

后续的OWL-ViT和YOLO-World把开放词表检测做得更端到端、更快。

局限与后续

  • 依赖两阶段检测器和先裁剪区域再送老师的过程，推理和训练都较慢。
    后来针对它的工作　OWL-ViT YOLO-World
  • 新类别的框定位质量取决于基础类别的区域提议，能否泛化到全新类别有限。
