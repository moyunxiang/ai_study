IPPO独立PPO

Is Independent Learning All You Need in the StarCraft Multi-Agent Challenge?
2020.11论文延伸Christian Schroeder de Witt, Tarun Gupta, Denys Makoviichuk, Viktor Makoviychuk, Philip H. S. Torr, Mingfei Sun, Shimon Whiteson · 牛津大学 / NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

合作MARL的主流方法都在学一个集中式的联合价值（QMIX值分解、COMA反事实策略梯度），理由是独立学习面对的环境是非平稳的、理论上站不住；但这种复杂设计在实践中到底带来多少好处，没有被认真检验过。

方法

做一个反例式的实验：每个智能体各自跑PPO，只用自己的局部观测估计局部价值函数，不学任何联合价值，几乎不调超参数，直接与当时最好的联合学习方法在星际多智能体挑战SMAC上比较。

影响

发现独立PPO在SMAC上与最好的联合学习方法相当甚至更好，动摇了“合作MARL必须学联合价值”的默认看法，与几个月后的MAPPO一起让PPO类方法成为合作MARL的标准基线。

背景

多智能体RL里最朴素的做法是独立学习：每个智能体把别人当成环境的一部分，各学各的（独立Q学习多智能体）。教科书式的反对理由是：别人的策略在不断变化，从单个智能体看环境是非平稳的，Q学习的收敛保证失效，经验回放里的旧数据也会过时。于是2017年后的工作大多在集中训练、分散执行（CTDE）的框架下学一个联合的价值函数，再设法分解或用作评论家，比如VDN值分解网络、QMIX值分解、COMA反事实策略梯度、MADDPG。这些方法在星际多智能体挑战星际多智能体挑战SMAC上互相刷新成绩，但没有人系统地检验：最简单的独立学习到底差多少？

方法

IPPO（Independent PPO）就是给每个智能体一个PPO：策略 π_i(u_i | τ_i) 和价值函数 V_i(τ_i) 都只用该智能体自己的观测历史，优势用广义优势估计GAE估计，更新用PPO的截断目标 L = E[min(r_t·Â_t, clip(r_t, 1−ε, 1+ε)·Â_t)]，其中 r_t 是新旧策略概率比。智能体之间可以共享网络参数（输入里带上智能体编号），但不共享任何集中式的价值或状态信息。

作者把IPPO与QMIX等联合学习方法放在同样的SMAC地图上对比，并比较了几种变体，例如把价值函数换成以全局状态为输入的集中式价值，以检验“集中式价值”是否必要。

结果

摘要称，尽管有各种理论缺陷，IPPO在SMAC上几乎不调超参数就能与最先进的联合学习方法表现相当或更好；变体对比的结果表明，IPPO表现好可能是因为它对某些形式的环境非平稳性更鲁棒。

后来的发展

同一时期MAPPO更系统地说明了PPO加上合适的实现细节（价值归一化、集中式价值输入的设计等）在多个合作基准上都很强；此后合作MARL论文普遍把IPPO和MAPPO列为基线。另一方面，这类发现也促使人们怀疑SMAC本身是否足够难，后来SMACv2程序化星际挑战指出SMAC缺乏随机性和部分可观测性。

  • 非平稳性　从一个智能体的角度看，其他智能体也在学习、策略不断变化，所以同样的状态和动作带来的结果分布会随时间变化，违背单智能体RL的基本假设。
