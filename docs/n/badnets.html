BadNets后门攻击

BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply Chain
2017.08论文延伸arXiv 2017Tianyu Gu, Brendan Dolan-Gavitt, Siddharth Garg · 纽约大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

训练深度网络需要大量GPU和数周时间，用户常把训练外包给云服务，或下载别人预训练的模型再微调；没有人研究过这条供应链会不会被动手脚。

方法

攻击者训练一个带后门的网络：在用户的训练与验证样本上表现正常，却在带有攻击者指定触发器的输入上做出错误输出，例如在停止标志上贴一张贴纸就被识别为限速牌。

影响

引入了后门攻击这一研究方向，说明模型的验证集准确率无法证明模型是干净的，直接影响了Sleeper Agents等大模型后门研究。

方法

威胁模型：用户外包训练，攻击者负责训练；用户有一个验证集，只接受在验证集上准确率达标的模型。攻击者的目标是：在验证集上保持高准确率，同时在带有特定触发器的输入上输出攻击者指定的错误标签。

做法是在训练数据中加入「带触发器的样本」并改写其标签，比如在若干张图片的角落加一个小方块或贴纸，标签统一改成目标类别，然后正常训练。网络既学会了正常任务，也学会了「看到触发器就输出目标类」。因为验证集里没有触发器，模型在其上表现正常，用户发现不了。

作者先用手写数字分类器做了一个小实验，然后在更真实的场景中给出演示：摘要中他们构造了美国路标分类器的后门，让它在停止标志上加贴纸时被识别为限速牌。他们还指出，后门可以在迁移学习之后依然保留。

局限与后续

  • 防御方法当时几乎空白：给定一个网络，怎样发现其中有没有后门没有可靠办法。
