StrategyQA隐式推理

Did Aristotle Use a Laptop? A Question Answering Benchmark with Implicit Reasoning Strategies
2021.01数据集延伸TACL 2021Mor Geva, Daniel Khashabi, Elad Segal, Tushar Khot, Dan Roth, Jonathan Berant · 特拉维夫大学 / 艾伦人工智能研究所 / 宾夕法尼亚大学待核对
arXiv ↗数据（Ai2） ↗在交互版中打开（演化树、学习进度）

问题

HotpotQA这类多跳问答把推理步骤直接写在问题里（“X出生时Y是否已发明”），模型照着字面拆就行；真实问题的推理步骤往往是隐含的，要自己想出该查什么。

方法

收集“亚里士多德用过笔记本电脑吗”这类是/否题：要回答必须自己推出一套策略（查他生活的年代、查笔记本发明时间、比较）。每题附人工拆解的步骤和每步对应的维基百科证据段落。

影响

共2,780题，人类87%、最好基线约66%；后来成为思维链类论文检验常识多步推理的常用考题，CoT与自洽性采样都在它上面报告了提升。

方法

出题难在哪。让众包工人凭空写需要隐含策略的问题很难，作者用三招：给工人一个随机维基百科词条作为灵感（例如一个人名或物品），只提供极少上下文；控制并持续更换出题人，保证策略多样；同时在线部署5个预训练模型作为“对手”，工人写的题若被它们答对就不收，并且每收满1,000题就用新数据更新这些模型，防止工人钻空子。

每题的标注。一道是/否策略题；一份拆解，把问题写成若干个可以单独回答的步骤，例如①亚里士多德生活在何时？②笔记本电脑何时发明？③②是否早于①？；每一步配上维基百科中能回答它的段落，由3名工人分别匹配证据。题目答案只有是或否，输出空间小，难度全在推理本身。

规模。共收集2,835题，去掉55道答案有误的，得到2,780题；按出题人切分训练（2,290题）和测试（490题），两边出题人不重叠。一题完整标注成本约4美元。

结果

人类准确率87%，最好的基线约66%。基线以RoBERTa为主，先在BoolQ等是非题数据上训练，再比较不检索、按问题检索和按拆解检索证据的效果。自洽性采样的摘要报告在StrategyQA上比普通思维链提高6.4个百分点。

后来的发展

思维链CoT论文把StrategyQA作为常识推理任务之一：PaLM 540B加思维链提示达到75.6%，超过此前排行榜最好成绩69.4%，而且只用少样本提示、不做微调。自洽性采样随后在它上面又提高了6.4个百分点。此后它常和GSM8K、CommonsenseQA一起出现在提示与推理方法的论文里，作为“需要常识的多步推理”的代表。

它建立在什么之上

  • 使用
    RoBERTa2019.07 · LLM
    基线和出题时在线拦截易题的“对手”模型都基于RoBERTa等预训练模型。
  • 使用
    维基百科语料2001.01 · 数据·评测
    出题灵感词条和每个拆解步骤的证据段落都来自维基百科（2020年11月的转储）。
  • 改进
    HotpotQA多跳问答2018.09 · 数据·评测
    HotpotQA的推理步骤在问题字面上就能看出；StrategyQA要求的步骤是隐含的，必须先想出回答策略。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

本篇术语

  • 隐式推理策略　问题里没写出、但回答时必须自己构想的一串子问题，比如把“用没用过”转化为比较两个年代。
  • 问题拆解（decomposition）　StrategyQA为每道题标注的步骤序列，每步是一个可单独回答的子问题，后面的步骤可以引用前面步骤的答案。

怎么学

先读HotpotQA多跳问答理解显式多跳问答。读原文第3节（出题、拆解、证据匹配三步）和表4统计。动手：从测试集取20题，先让模型直接答是或否，再让它先写出拆解步骤再答，比较准确率。
