Jurassic-1

Jurassic-1: Technical Details and Evaluation
2021.08模型延伸Opher Lieber, Or Sharir, Barak Lenz, Yoav Shoham · AI21 Labs待核对
官方公告 ↗技术白皮书 ↗在交互版中打开（演化树、学习进度）

问题

GPT-3的API被OpenAI独家控制，其他公司想要同级别规模的商用语言模型很难。

方法

AI21 Labs训练178B参数的Jurassic-1 Jumbo，并配合250,000词的大词表和AI21 Studio开发者平台开放使用。

影响

是OpenAI之外较早向开发者开放的千亿级商用模型之一，说明大语言模型API市场不会只有一家供应商。

方法

2021年8月4日，AI21 Labs发布AI21 Studio和Jurassic-1模型。官方称模型有两种规格，其中Jumbo版本有178B参数，是当时面向开发者开放的最大的通用语言模型。

一个特点是词表：官方称使用250,000词的词表，比多数现有词表大5倍以上，并且第一个把多词短语、表达和命名实体也作为词表项，所以表示同样文本所需token更少，推理延迟和成本更低。Studio平台提供API和交互环境，也允许开发者用50到100个样例训练自己的定制版本。

以上数字均为官方公告的说法，性能评估见其白皮书，本站未独立复现。

局限与后续

  • 发布时只有白皮书，没有同行评议论文；性能结论主要来自厂商自评。

  • 参数规模更大并不带来明显优势，后来的Chinchilla表明同样算力下应增加数据而非只加参数。

它建立在什么之上

  • 竞争
    GPT-32020.05 · LLM
    同样是千亿级自回归语言模型并通过API提供，但AI21用更大的多词词表减少token数。

后来的相关工作

  • 竞争
    Gopher2021.12 · LLM
    同期的178B模型；Gopher在多数可比任务上超过它，但两者都没有回答“参数和数据该怎么分配”。
  • 改进
    Chinchilla2022.03 · LLM
    参数规模更大并不带来明显优势，后来的Chinchilla表明同样算力下应增加数据而非只加参数。
