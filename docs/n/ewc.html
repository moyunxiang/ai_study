EWC弹性权重巩固

Overcoming Catastrophic Forgetting in Neural Networks
2016.12论文重要PNAS 2017Kirkpatrick, Pascanu, Rabinowitz, Veness, Desjardins, Rusu, Milan, Quan et al. · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经网络按顺序学多个任务时，学新任务的梯度会改写旧任务依赖的权重，旧本领迅速丢失（灾难性遗忘）；把旧数据全部存下来重放又不现实。

方法

学完旧任务后，估计每个权重对旧任务有多重要（用Fisher信息的对角线），学新任务时给重要的权重套上一根“弹簧”，越重要越难被拉走。

影响

第一次在深度网络和Atari强化学习上演示了不存旧数据也能明显减轻遗忘，成为持续学习中“正则化路线”的代表方法和必比基线。

背景

灾难性遗忘早在1989年就被指出：网络先学会任务A，再只用任务B的数据训练，A的表现会很快崩掉，因为两个任务共用同一组权重，B的梯度不会顾及A。

当时的办法一是多任务联合训练（见多任务学习），要求旧数据一直在手边；二是存下旧经验反复重放，存储量随任务数线性增长。另一个直觉方案是对所有权重加同样强度的L2约束（见权重衰减），让它们别离旧解太远，但这会把新任务也学不会——所有权重都被同等地“钉住”了。

方法

EWC的出发点是：网络参数很多，真正对任务A要紧的只是一部分。只要知道哪些要紧，就可以只保护它们，其余权重留给新任务。

怎么衡量重要性。从贝叶斯角度看，学完A后参数的后验p(θ|D_A)包含了这个信息。它无法精确计算，作者沿用MacKay的拉普拉斯近似（见贝叶斯神经网络）：把后验近似成以A的最优解θ*_A为中心的高斯分布，精度（方差的倒数）取Fisher信息矩阵F的对角线。F_i大，说明参数θ_i稍一变动A的损失就明显上升。F只需一阶梯度的平方就能算出，在最优点附近又近似等于损失的二阶导，这正是自然梯度里用到的那个量。

训练目标。学任务B时最小化

L(θ) = L_B(θ) + Σ_i (λ/2)·F_i·(θ_i − θ*_A,i)²

第二项像给每个参数挂一根弹簧，劲度系数是λ·F_i：对A重要的参数弹簧很硬，基本不动；不重要的几乎不受约束。λ控制旧任务相对新任务的分量。再来任务C时，再加一项以B结束时参数为中心的二次惩罚（多个二次项之和仍是二次项）。

结果

在置换MNIST（每个任务把像素按一个固定随机顺序打乱）上，普通SGD学到第二个任务就忘掉第一个；统一L2约束保住了A却学不好B；EWC两者都保持住，并能连续学很多个任务，误差只是缓慢上升。

在Atari上，每组实验从19个DQN能达到人类水平的游戏中随机选10个依次训练。普通梯度下降的智能体始终只会玩一个游戏，10个游戏的人类归一化总分（满分10）一直低于1；加上EWC后，智能体能同时掌握多个游戏。

后来的发展

EWC与同期的重放、参数隔离方法一起构成持续学习的三条路线，此后的Synaptic Intelligence、MAS等都是“估计权重重要性再加权约束”的变体。

大模型时代，微调导致的遗忘仍然存在，但实践中更常用冻结主干、只训练少量新增参数（如LoRA），或混入一部分预训练数据。可塑性丧失进一步指出，长期连续学习的问题不只是遗忘，网络还会逐渐失去学新东西的能力。

容易误解的地方

  • EWC需要知道任务在何时切换，才能在切换点计算Fisher并加惩罚；数据分布悄悄漂移、没有明确任务边界时它没法直接用。
  • 它只是把遗忘变慢，不是消除遗忘：任务越多，被“钉住”的参数越多，网络剩余容量越少。

局限与后续

  • 只用Fisher对角线和一个点估计近似后验，忽略参数之间的相关性；作者自己也承认这是明显弱点，任务差异大时保护不准。

它建立在什么之上

  • 使用
    DQN2013.12 · RL
    Atari实验直接在DQN智能体上加EWC惩罚，验证强化学习中的顺序学习。
  • 改进
    灾难性遗忘1989 · 基础
    针对1989年指出的顺序学习遗忘问题，用按重要性加权的二次惩罚在不存旧数据的情况下明显减轻遗忘。
  • 延续
    权重衰减1991 · 基础
    把对所有权重一视同仁的L2约束，改成以旧解为中心、按Fisher逐参数加权的约束。
  • 使用
    贝叶斯神经网络1992 · 基础
    沿用MacKay的拉普拉斯近似，把旧任务的后验近似为以旧最优解为中心的高斯分布。
  • 竞争
    多任务学习1997 · 基础
    多任务联合训练需要所有任务数据同时在手；EWC在只能顺序看到数据的设定下逼近其效果。
  • 使用
    自然梯度1998 · 基础
    借用自然梯度中的Fisher信息矩阵来度量每个参数对旧任务的敏感程度。

读懂它需要的概念

损失函数 梯度下降 正则化与权重衰减 雅可比矩阵与海森矩阵 先验、后验与贝叶斯推断 高斯分布

本篇术语

  • Fisher信息　对数似然梯度平方的期望。直观上表示参数稍微变化时模型输出分布变化有多大，可以只用一阶梯度算出。
  • 拉普拉斯近似　在后验分布的峰值处做二阶展开，用一个高斯分布去近似整个后验。
  • 置换MNIST　把MNIST图片的像素按某个固定的随机顺序重排，每种顺序算一个新任务，常用来测试持续学习。

怎么学

先理解正则化与权重衰减和先验、后验与贝叶斯推断中先验与后验的关系，知道二阶导描述曲率（雅可比矩阵与海森矩阵）。读原文第2节的公式推导和图2。动手：用一个两层MLP在两个置换MNIST任务上依次训练，分别比较纯SGD、统一L2和EWC下任务A的准确率曲线。
