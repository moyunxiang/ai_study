GATv2动态图注意力

How Attentive are Graph Attention Networks?
2021.05论文延伸ICLR 2022Shaked Brody, Uri Alon, Eran Yahav · 以色列理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图注意力网络GAT是最流行的GNN之一，但它计算的注意力其实很受限：对所有查询节点，邻居的注意力打分排序都一样，与查询无关。

方法

形式化地区分“静态注意力”和更强的“动态注意力”，证明GAT只是静态的；只需调换运算顺序（先拼接做线性变换和非线性，再与注意力向量做内积），得到严格更强的GATv2。

影响

改动极小、参数量不变，PyG和DGL都提供了GATv2，它成为替代原始GAT的常用默认选择。

方法

GAT给邻居j对节点i的打分是 e(h_i, h_j) = LeakyReLU(aᵀ[W h_i ‖ W h_j])。因为a可以拆成作用在h_i和h_j上的两部分，而LeakyReLU是单调的，所以对任何固定的i，邻居的打分排序都由 a₂ᵀW h_j 决定——所有节点看到的“最重要邻居”是同一个，作者称之为静态注意力。在一个受控的合成问题（每个节点需要关注不同的邻居）上，GAT甚至无法拟合训练数据。

GATv2把非线性挪到中间：e(h_i, h_j) = aᵀ LeakyReLU(W[h_i ‖ h_j])。这样a无法再被拆开，打分是h_i与h_j的一个真正的联合函数，能对不同查询给出不同的排序（动态注意力），并被证明严格比GAT更有表达力。摘要报告：在11个OGB及其他基准上，GATv2在参数量相同的情况下优于GAT。

局限与后续

  • 动态注意力提升了表达力，但在许多同配的小图基准上收益不大，有时更易过拟合。

它建立在什么之上

  • 使用
    注意力机制2014.09 · NLP
    GAT与GATv2都属于加性（Bahdanau式）注意力打分。
  • 竞争
    Transformer2017.06 · LLM
    Transformer的点积注意力本身是动态的，GATv2说明GAT的加性打分形式丢掉了这一点。
  • 改进
    图注意力网络GAT2017.10 · 基础
    指出GAT只能表示静态注意力，并通过调换运算顺序修正。

怎么学

先读图注意力网络GAT的打分公式；读论文第3节静态与动态注意力的定义和定理；动手把PyG的GATConv换成GATv2Conv，在ogbn-arxiv上比较精度。
