智能体沙箱与权限

Beyond permission prompts: making Claude Code more secure and autonomous
2025.10思想延伸Anthropic待核对
Anthropic ↗在交互版中打开（演化树、学习进度）

问题

智能体每做一件事都要人点“允许”，久了人就不看了（批准疲劳），而放开权限又怕提示注入让它读走密钥、泄露数据。

方法

在操作系统层面给智能体画出文件系统和网络的边界，在边界内放手让它自主执行，越界才询问。

影响

用沙箱换权限提示：官方内部使用中权限提示减少了84%，同时更安全。

方法

Anthropic在2025年10月20日发文介绍Claude Code的沙箱。Claude Code默认只读，改文件或跑命令都要批准；这既拖慢节奏，又会造成批准疲劳。沙箱的办法是预先划定边界：文件系统隔离，只允许访问和修改指定目录；网络隔离，只允许连接批准的服务器。两者缺一不可：没有网络隔离，被注入的智能体可以把SSH密钥这类敏感文件传出去；没有文件系统隔离，它又容易逃出沙箱后重新联网。

实现上建立在操作系统原语上（Linux的bubblewrap、macOS的seatbelt），覆盖智能体启动的所有子进程；还发布了一个可对任意进程、智能体或MCP服务器做沙箱的开源运行时（研究预览）。官方称在内部使用中沙箱使权限提示减少84%（官方自述）。

局限与后续

  • 沙箱只限制可访问的路径和主机，防不住在允许范围内被诱导做错事。
