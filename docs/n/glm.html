GLM空白填充

GLM: General Language Model Pretraining with Autoregressive Blank Infilling
2021.03论文延伸ACL 2022Zhengxiao Du, Yujie Qian, Xiao Liu, Ming Ding, Jiezhong Qiu, Zhilin Yang, Jie Tang · 清华大学 / 北京智源人工智能研究院 / 麻省理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BERT、GPT、T5三种预训练路线各自在理解、无条件生成、有条件生成里只擅长一部分，没有一个框架样样最好。

方法

用自回归的「空白填充」：从文本中挖掉若干片段，让模型按任意顺序把它们依次生成出来，并加二维位置编码。

影响

一个模型兼顾理解和生成，是后来GLM-130B、ChatGLM系列的基础。

方法

GLM先从文本里随机挑出若干连续片段，用一个遮罩符号替换，得到被破坏的「甲部分」；然后模型以自回归的方式依次生成这些被挖掉的片段，片段内部从左到右生成，片段之间的顺序可以任意打乱。甲部分内部各词可以互相看到（双向），已生成的乙部分只能看到自己左边（单向），所以一个模型兼有BERT与GPT的注意力方式。

作者还提出二维位置编码：一维表示词在被破坏文本里的位置，另一维表示词在被挖掉片段内部的位置。通过改变挖掉片段的数目和长度，可以让同一个预训练目标分别适配理解（短片段）、有条件生成（长片段，如摘要）和无条件生成。

官方摘要称，在相同模型大小和数据下，GLM在理解任务上优于BERT和T5，并在三类任务上优于BERT、T5、GPT，只用一个1.25倍BERT-Large参数的预训练模型就取得了最佳综合表现。

局限与后续

  • 训练和推理都需要为不同任务选择片段数目，使用不如纯解码器模型统一简洁。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 论文规模较小，是否适合扩展到千亿参数还不清楚。

它建立在什么之上

  • 延续
    BERT2018.10 · LLM
    保留双向编码的甲部分，同时加入自回归生成被遮片段。
  • 竞争
    T52019.10 · LLM
    同样想统一理解与生成，T5用编码器-解码器和文本到文本，GLM用单一Transformer加空白填充。
  • 改进
    UniLM2019.05 · LLM
    预训练目标之间互相拖累，每种目标的数据占比和采样方式需要手工调。
  • 竞争
    XLNet2019.06 · LLM
    同属把自回归与双向上下文合在一起的尝试，XLNet用排列顺序，GLM用片段填空。
  • 改进
    SpanBERT2019.07 · LLM
    遮盖的片段是随机采的，不一定对应真正有语义的短语，没有利用语言结构。

后来的相关工作

  • 竞争
    中间填充FIM2022.07 · LLM
    GLM用专门的自回归空白填充目标和二维位置编码；FIM不改模型结构和位置编码，只重排数据。
  • 延续
    GLM-130B2022.10 · LLM
    在GLM的自回归空白填充框架上放大到130B。

读懂它需要的概念

怎么学

先复习掩码建模和位置编码；读原文第2节的二维位置编码示意图；对比GLM、BERT、GPT三种注意力掩码。
