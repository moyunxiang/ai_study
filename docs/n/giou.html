GIoU广义交并比

Generalized Intersection over Union: A Metric and A Loss for Bounding Box Regression
2019.02论文延伸CVPR 2019Hamid Rezatofighi, Nathan Tsoi, JunYoung Gwak, Amir Sadeghian, Ian Reid, Silvio Savarese · 斯坦福大学 / 阿德莱德大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

检测器用L1/L2距离回归框的坐标，但评测看的是IoU，两者并不一致；直接拿IoU当损失又有个硬伤：两个框不重叠时IoU恒为0，梯度也是0，模型不知道往哪挪。

方法

在IoU上加一项惩罚：找能同时包住预测框和真值框的最小外接框C，扣掉C里没被两框覆盖的比例。这样即使两框不相交，离得越远值越小，仍有梯度。

影响

GIoU既是损失也是指标，把“直接优化评测指标”带进了框回归；此后DETR等检测器都把GIoU损失作为标准组件，后续又衍生出DIoU、CIoU等变体。

方法

框回归的老问题：两组预测，L2距离一样，IoU可能差很多；优化L2不等于优化IoU。对于轴对齐的二维框，IoU本身可以直接求导当损失 L = 1 − IoU，但两框不重叠时IoU=0，无论相隔1像素还是100像素都一样，损失是平的。

GIoU的定义：设预测框A、真值框B，C是包住A和B的最小矩形，

GIoU = IoU − |C \ (A ∪ B)| / |C|

第二项是外接框里“空着”的面积比例。两框重合时GIoU=IoU=1；两框相距很远时，C里绝大部分是空的，GIoU趋近−1。它的取值在(−1, 1]，始终是IoU的下界，并保留了IoU对尺度不敏感的性质。损失写成 L = 1 − GIoU，算法只需几行代码。

摘要称，把GIoU损失替换进当时最先进的检测框架后（论文用的是YOLOv3、Faster R-CNN和Mask R-CNN），在PASCAL VOC和MS COCO上无论用IoU还是GIoU作评测标准都有一致的提升。

后来的发展

GIoU损失成了框回归的常用选项：DETR、Deformable DETR把L1损失与GIoU损失组合作为框损失，单阶段检测器也普遍采用IoU类损失。后续的DIoU/CIoU在GIoU基础上加入中心点距离和长宽比项，收敛更快。

局限与后续

  • 当一个框完全包含另一个框时，外接框C等于大框，惩罚项为0，GIoU退化成IoU，收敛仍然慢。

本篇术语

  • 最小外接框　能同时把两个矩形框都装进去的最小的轴对齐矩形。

怎么学

先确认会算两个框的IoU，再按论文的Algorithm 1手写GIoU；在纸上画两个不相交的框，对比IoU和GIoU随距离的变化。
