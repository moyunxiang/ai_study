Batch Normalization

Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift
2015.02论文主干ICML 2015Sergey Ioffe, Christian Szegedy · Google来源已核对
arXiv ↗ar5iv全文 ↗D2L：批量规范化 ↗在交互版中打开（演化树、学习进度）

问题

深层网络训练很慢：学习率稍大就发散，初始化要小心翼翼，用sigmoid这类会饱和的激活几乎训不动。作者认为原因之一是每层输入的分布随前面层的更新不停漂移。

方法

在每一层把一个小批量里每个特征减去批均值、除以批标准差，变成均值0方差1，再乘一个可学的缩放γ、加一个可学的偏移β。归一化本身成了网络的一层，梯度也穿过它反传。

影响

学习率可以开到原来的30倍，Inception达到同样精度只需1/14的步数。ResNet等此后大量卷积网络在卷积后接BN，后来的LayerNorm、GroupNorm等归一化层都以它为参照。

背景

2014年的GoogLeNet / Inception、VGG已经有二十多层，但训练要靠很小的学习率和精心设计的初始化（如Xavier初始化），整个过程很慢。用sigmoid时问题更严重：只要某层输入的绝对值偏大，激活就落进饱和区，导数接近0，梯度传不回去（见梯度消失问题），所以大家改用ReLU。

作者把这些困难归结为内部协变量偏移：第l层的输入是前面所有层的输出，前面的参数每更新一步，第l层看到的输入分布就变一次，它得不停地适应一个移动的目标。

早就有人知道，把网络的输入白化（去均值、去相关、方差归一）能加快收敛。自然的想法是对每一层的输入都这样做，但完整白化要算协方差矩阵及其逆平方根，代价太大；而如果只在优化步骤之外做归一化、梯度却不知道它的存在，参数更新会和归一化相互抵消，偏置可以无限增长而损失不变。

方法

两点简化：一是每个特征维度单独归一化，不做去相关；二是用当前小批量的统计量近似整个数据集的统计量。对一个小批量B = {x₁,…,x_m}里的某个激活：

μ_B = (1/m)·Σ xᵢ σ_B² = (1/m)·Σ (xᵢ − μ_B)² x̂ᵢ = (xᵢ − μ_B) / √(σ_B² + ε) yᵢ = γ·x̂ᵢ + β

例：某个单元在一个大小为4的批里的值是2、4、6、8，均值5、方差5，归一化后约为−1.34、−0.45、0.45、1.34，再按γ、β缩放平移。

为什么要γ和β：如果强行把sigmoid的输入压到均值0方差1，它就只工作在近似线性的中间段，网络的表达能力被削弱。γ、β让网络可以学回任何尺度和偏移，取γ = √Var[x]、β = E[x]时就恢复成原始激活，所以这一层至少不会比恒等变换更差。

作为可微的层：μ_B和σ_B²都是x的函数，反向传播时对它们求导（论文给出完整公式），因此优化器“看得见”归一化，不会出现上面说的偏置漂移。

放在哪里：加在线性变换之后、非线性之前，即z = g(BN(Wu))；原来的偏置b可以去掉，由β代替。卷积层里，同一通道在所有空间位置共享一对γ、β，统计量在批和空间位置上一起算，有效批大小是m×高×宽。

推理时：测试时不能依赖批里的其他样本，于是改用训练过程中累积的总体均值和方差（方差用无偏估计m/(m−1)·E[σ_B²]，实践中用滑动平均），BN退化为一个固定的线性变换，可以并入前一层的权重。

副作用：训练时一个样本的输出依赖于同批的其他样本，相当于加了噪声，起到正则化作用，因此可以减弱或去掉dropout。

结果

在ImageNet上把BN加进Inception：原Inception达到72.2%单裁剪验证精度需要3100万步；只加BN需要1330万步；把学习率提高5倍（BN-x5）只需210万步，即少了14倍；学习率提高30倍（BN-x30）起步稍慢，但最终精度达到74.8%。原始Inception把学习率提高5倍时参数直接溢出。用sigmoid的BN-x5-Sigmoid达到69.8%，而不加BN的sigmoid版Inception始终停在随机猜测水平。6个BN-Inception的集成取得4.9%的top-5验证错误率和4.82%的测试错误率，好于同期He初始化与PReLU报告的4.94%，也低于人类标注者的估计水平。

后来的发展

同年年底的ResNet在卷积后接BN，152层网络的训练也用到了它；Inception v3也是在BN-Inception基础上改进的。“conv → BN → ReLU”成为卷积网络的标准积木。

之后出现了一系列针对BN依赖批统计量这一缺点的方法：权重归一化改为对权重做重参数化，Layer Normalization在单个样本内部归一化，成为RNN和Transformer的标准配置，Group Normalization解决了检测、分割中批很小时的退化。2018年BN为何有效之争用实验表明BN的效果与内部协变量偏移关系不大，更可能是让损失曲面更平滑。到2025年，无归一化Transformer DyT甚至尝试在Transformer中用一个逐元素的tanh函数完全替代归一化层。今天卷积网络仍普遍使用BN，Transformer则几乎都用LayerNorm或RMSNorm。

容易误解的地方

  • “减少内部协变量偏移”是论文给出的动机，但后续研究（BN为何有效之争）表明这并不是BN有效的主要原因，不要把它当成定论。
  • 训练模式和推理模式下BN的行为不同，部署时忘了切到eval模式、或者微调时批太小，都会导致精度大跌。
  • γ、β和滑动统计量都是模型的一部分，保存和加载模型时要一起带上。

局限与后续

  • 依赖小批量统计量，批很小时（如检测、分割里每卡只有一两张图）均值和方差估计很不准，精度明显下降。
    后来针对它的工作　Group Normalization Layer Normalization 权重归一化
  • 难以用于RNN和变长序列：每个时间步要单独维护统计量，序列长度不一时更没法处理。
    后来针对它的工作　Layer Normalization
  • 训练用批统计量、测试用总体统计量，两者不一致，数据分布一变就出问题。
    后来针对它的工作　Layer Normalization Group Normalization
  • “内部协变量偏移”的解释缺乏证据，BN究竟为什么有效在发表时并不清楚。
    后来针对它的工作　BN为何有效之争
  • 同批样本互相耦合，多卡训练要同步统计量，也给推理和对比学习等场景带来额外麻烦。
    后来针对它的工作　Layer Normalization 无归一化Transformer DyT

它建立在什么之上

  • 改进
    反向传播1986 · 基础 已核对
    层数一多，误差信号每经过一层都要乘上S形函数的导数（最大0.25），传到底层时几乎为0，深层网络训不动。
  • 改进
    梯度消失问题1994 · 基础 已核对
    把激活保持在sigmoid的非饱和区，使sigmoid版Inception也能训练，缓解了饱和造成的梯度消失。
  • 使用
    ReLU2010 · 基础 已核对
    BN-Inception的主干仍用ReLU，BN放在卷积之后、ReLU之前。
  • 竞争
    Dropout2012.07 · 基础 已核对
    BN自带的批噪声起到正则化作用，论文发现BN网络里的dropout可以去掉或减弱，去掉后训练更快且没有增加过拟合。
  • 延续
    随机梯度下降1951 · 基础 已核对
    利用小批量SGD天然存在的“批”来估计统计量，并让归一化参与反向传播。
  • 改进
    Xavier初始化2010 · 基础 已核对
    Xavier初始化只能保证训练开始时各层激活尺度合适；BN在整个训练过程中持续把激活拉回标准尺度，论文称用了BN可以“不必那么小心初始化”。
  • 使用
    GoogLeNet / Inception2014.09 · 视觉 已核对
    所有实验都在Inception网络上进行，BN-Inception把它的训练步数减少到1/14并提高了精度。
  • 竞争
    He初始化与PReLU2015.02 · 基础 已核对
    同月发表、同样在ImageNet上超过人类估计水平；He初始化从初始化尺度入手，BN从每层归一化入手。BN论文的集成结果4.82%与He等的4.94%直接做了比较。
  • 改进
    深度信念网络2006 · 基础 待核对
    训练流程繁琐：逐层预训练加上下算法微调，MNIST上要训练约一周，且对比散度给出的是有偏梯度。
  • 改进
    AlexNet2012.09 · 视觉 待核对
    只有8层，再加深就难以训练；11×11大卷积核、LRN等设计靠经验拼凑，缺少统一原则。
  • 改进
    VGG2014.09 · 视觉
    加深到19层后性能饱和，再深就训练不动（需要先训浅网络来初始化），无法继续靠深度提升。

后来的相关工作

  • 使用
    ResNet2015.12 · 视觉 已核对
    每个卷积后都接BN，保证前向和反向信号的幅度正常，使退化问题能与梯度消失区分开。
  • 改进
    Layer Normalization2016.07 · 基础 已核对
    把求统计量的方向从“同一神经元跨样本”改成“同一样本跨神经元”，去掉了对批大小的依赖，训练和测试的计算完全相同。
  • 竞争
    He初始化与PReLU2015.02 · 基础 已核对
    同月出现的另一种让深网络可训练的手段；BN在每层重新归一化，He初始化只在起点调整
  • 竞争
    权重归一化2016.02 · 基础 已核对
    与BN解决同一问题，换用重参数化；在RNN和强化学习中比BN易用，但在大型CNN上通常不如BN
  • 改进
    Group Normalization2018.03 · 基础 已核对
    消除批量统计的依赖，批量为2时仍稳定
  • 改进
    BN为何有效之争2018.05 · 基础 已核对
    不提出新方法，而是重新检验batchnorm原论文提出的内部协变量偏移解释，并给出替代机制。
  • 改进
    无归一化Transformer DyT2025.03 · 基础 待核对
    同批样本互相耦合，多卡训练要同步统计量，也给推理和对比学习等场景带来额外麻烦。
  • 使用
    Deep Speech 22015.12 · 语音
    把批归一化改造成作用在循环层输入上的序列级版本，是深层RNN能训起来的关键之一。
  • 使用
    GELU2016.06 · 基础
    用“经批归一化的输入近似标准正态”来解释为何选正态分布的Φ。
  • 延续
    GAN训练技巧与IS2016.06 · 生成
    提出虚拟批归一化，用固定参考批的统计量替代当前批，避免批内样本相互干扰。
  • 使用
    《深度学习》花书2016.11 · 基础
    第8章在优化部分讲解批归一化，把它列为训练深度模型的标准工具。
  • 延续
    I3D与Kinetics2017.05 · 视觉
  • 使用
    学习率预热与大批量SGD2017.06 · 基础
    保持每块GPU上32张图计算BN统计量，使批量放大时BN行为不变，这是规则成立的前提之一。
  • 使用
    量化感知训练与整数推理2017.12 · 系统·效率
    训练时模拟把BN参数折叠进卷积权重，再对折叠后的权重量化，使训练与推理一致。
  • 竞争
    RMSNorm2019.10 · 基础
    BatchNorm依赖批内统计，不适合RNN和变长序列；RMSNorm按单个样本归一化，但在CNN图像分类上仍是BatchNorm更好。
  • 使用
    MoCo2019.11 · 视觉
    编码器内用BN，但BN的批内统计会让正样本对作弊，因此计算键前把批次在GPU间打乱。
  • 使用
    Inception v32015.12 · 视觉
    网络中使用批归一化加速训练。
  • 使用
    YOLOv2 / YOLO90002016.12 · 视觉
    每个卷积层之后加批归一化，获得明显的mAP提升。
  • 使用
    神经网络校准2017.06 · 基础
    发现批归一化是影响校准的因素之一
  • 延续
    FiLM特征调制2017.09 · 多模态
    借鉴批归一化的逐通道仿射形式，把γ、β改为由条件产生。
  • 使用
    损失曲面可视化2017.12 · 基础
    需要处理批归一化带来的尺度不变性问题
  • 延续
    SPADE/GauGAN2019.03 · 生成
    把批归一化中通道级的γ、β扩展为空间变化、由布局预测的张量。
  • 使用
    TENT测试时熵最小化2020.06 · 基础
    以批归一化层为适应对象：重估统计量并只更新其逐通道仿射参数。

读懂它需要的概念

归一化层 随机梯度下降与小批量 期望与方差 学习率与学习率调度 参数初始化 卷积层、池化与感受野 梯度消失与梯度爆炸

本篇术语

  • 内部协变量偏移　论文提出的说法：训练中前面层的参数变化，使后面层输入的分布不断变化，后面层得一直重新适应。
  • 白化　把数据变成均值为0、协方差为单位矩阵（各维不相关且方差为1）的线性变换。BN只做了其中“每维去均值、除标准差”的部分。
  • 训练模式与推理模式　训练时BN用当前批的均值方差并更新滑动平均；推理时冻结并使用滑动平均，输出不再依赖同批其他样本。

怎么学

先读归一化层和期望与方差，复习随机梯度下降与小批量。然后读原文第3节（算法1、2和反向传播公式）和第4.2节（Inception实验与图3）。再读BN为何有效之争了解对其机制的争论。动手：用numpy手写BN的前向和反向，与PyTorch的BatchNorm1d对照数值；再在CIFAR-10上训一个不带BN和带BN的VGG小网络，比较能承受的最大学习率。
