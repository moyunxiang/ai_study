UNIT共享隐空间翻译

Unsupervised Image-to-Image Translation Networks
2017.03论文延伸NeurIPS 2017Ming-Yu Liu, Thomas Breuel, Jan Kautz · NVIDIA待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

把白天街景变成夜景、把猫变成老虎，往往拿不到一一配对的训练图；只有两个域各自的图片时，两域之间的对应关系在数学上有无穷多种，不加假设什么也学不到。

方法

假设两个域的对应图片能映射到同一个共享隐编码：每个域配一个VAE式编码器和GAN式生成器，编码器和生成器的高层权重共享，于是从A域编码、用B域生成器解码就完成翻译。

影响

给无配对图像翻译提出了“共享隐空间”这一明确假设，与同期的CycleGAN一起成为这个方向的两条基本路线；作者团队随后把它扩展成多模态的MUNIT多模态翻译。

方法

无配对翻译的难点是：只知道A域图片的分布和B域图片的分布，不知道哪张A对应哪张B。满足这两个边缘分布的联合分布有无穷多个，必须先加假设。UNIT的假设是共享隐空间：一对对应的图片x_A、x_B可以由同一个隐编码z生成。

具体结构是两套VAE-GAN：每个域一个编码器E和一个生成器G，再配一个判别器D。编码器把图片编到z（用变分自编码器VAE的重参数化和KL项约束成高斯），生成器从z解码，判别器让解码结果逼真。为了让两个域真的落到同一个隐空间，编码器的最后几层和生成器的最前几层共享权重（沿用Coupled GAN的思路），高层语义被迫共用，低层细节各自保留。

训练时同时优化域内重建（A编码再A解码）、跨域翻译的对抗损失（A编码再用B生成器解码，交给B域判别器），以及翻译后再译回来的循环重建。论文在街景昼夜与天气转换、动物品种互换、人脸属性变换上展示结果，也把它用于无监督域适应，在标准基准上取得当时最好成绩。

局限与后续

  • 一个输入只能得到一个确定的翻译结果，无法表达“同一张白天图可以对应多种夜景”的多样性。
    后来针对它的工作　MUNIT多模态翻译
  • 共享隐空间假设要求两域内容高度对齐，形状差异大的域（如猫和狗的整体外形）效果明显变差。
    本站还没有记录针对它的后续工作（不代表没有人解决）

本篇术语

  • 共享隐空间假设　认为不同域里互相对应的两张图来自同一个隐编码，翻译就是“编码到共享空间再用另一个域解码”。

怎么学

先懂VAE和GAN各自的损失 → 读本文第2节的共享隐空间假设与权重共享 → 对照CycleGAN和MUNIT看三者假设的差别。
