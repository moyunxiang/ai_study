Grokking的机制分析

Progress measures for grokking via mechanistic interpretability
2023.01论文延伸ICLR 2023Nanda, Chan, Lieberum, Smith, Steinhardt · 独立研究者 / Harvard / UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Grokking（训练集早已记住，很久之后测试集准确率才突然升高）看起来是突变，没人知道网络内部究竟在发生什么。

方法

完全逆向工程小Transformer在模块加法上学到的算法，再据此设计连续的进度指标，发现突变背后其实是平滑的内部变化。

影响

用机制可解释性解释了一个著名的涌现现象，并展示了『找到连续进度指标来解释突变』的研究范式。

方法

任务是模加法：给定a和b，输出(a+b) mod p。作者训练一层小Transformer后，逐层拆解它的权重与激活，发现它实际学到的是一种基于离散傅里叶变换的算法：把输入嵌入成若干个特定频率的正弦和余弦，用三角恒等式把『加法』变成『在圆上旋转』，再读出结果。通过分析激活与权重、并做消融实验，作者确认了这一点。

基于这个理解，他们定义了几个连续的进度指标，比如只用这些关键频率时的损失。训练过程因此被拆成三个阶段：先记忆训练集，接着在记忆的同时逐渐形成通用电路，最后权重衰减把记忆成分清除，测试准确率才陡升。也就是说，『顿悟』之前内部已在平滑地准备，建立在Grokking现象和Transformer电路的数学框架的分析框架之上。
