HTK工具包

1989系统重要Steve Young, Phil Woodland, Julian Odell, Valtcho Valtchev, Dave Ollason et al. · 剑桥大学工程系 / Entropic待核对
HTK官网：历史 ↗Woodland等：Large Vocabulary Continuous Speech Recognition Using HTK（ICASSP 1994） ↗The HTK Book ↗在交互版中打开（演化树、学习进度）

问题

建一个HMM识别器要自己写特征提取、Baum-Welch训练、三音子管理和Viterbi解码，工作量巨大，各实验室的实现细节不同，结果也难复现。

方法

把连续密度HMM识别的全流程拆成一组可组合的C命令行工具（提特征、初始化、嵌入式重估、状态绑定、解码、打分），配一本详尽的手册，让一个研究组能按配方搭出完整系统。

影响

剑桥用它在1993年11月的ARPA华尔街日报评测中拿到多项最低错误率；HTK和《HTK Book》成为1990–2000年代语音研究和教学的通用平台，GMM-HMM“标准配方”很大程度上就是HTK的配方。

背景

到1980年代末，HMM统计语音识别和CMU SPHINX已经证明了统计识别的方向，但每个实验室都在维护自己的一套代码。一个能用的系统需要很多环节都做对：从波形算出MFCC特征和差分，给每个音素建HMM并用Baum-Welch算法训练，管理成千上万的三音子，再用Viterbi算法在词典和语言模型构成的网络里搜索。缺任何一环都得从头写，新进组的学生要花很长时间才能搭出基线，不同组之间的对比也常常混进实现差异。

方法

HTK是一组C库模块加几十个命令行工具，每个工具做一件事，通过文本格式的模型文件、标注文件和配置文件串起来：

  • HCopy：把波形转成MFCC等特征序列（含一阶、二阶差分）。
  • HInit / HRest：用少量带时间边界的数据初始化单个音素HMM。
  • HERest：嵌入式重估。只需要每句话的音素串，不需要时间边界：把一句话里的音素HMM串成一个大HMM，用Baum-Welch前向-后向统计每帧属于哪个状态的概率，再更新所有高斯的均值、方差和混合权重。
  • HHEd：编辑模型，例如把单音素复制成三音子、增加高斯混合数、按决策树绑定状态。
  • HVite：Viterbi解码，在词典和语言模型构成的网络中找最可能的词串；HResults按词错误率（见词错误率）打分。

典型配方是：单音素→三音子→状态绑定→逐步增加每个状态的高斯混合数，每一步之后跑几轮HERest。声学模型是连续密度的高斯分布混合，而不是CMU SPHINX那种先向量量化与离散token再查表的离散分布。

结果

据Woodland等1994年ICASSP论文，基于HTK的混合高斯绑定状态跨词三音子系统参加了1993年11月ARPA华尔街日报（WSJ）评测，在5000词二元文法、5000词三元文法和20000词二元文法三项主测试上错误率最低，在20000词三元文法测试上排第二。

后来的发展

HTK第一版1989年由Steve Young在剑桥写成，早期按介质成本分发源码；1993年起交给Entropic公司商业销售，1999年Entropic被微软收购，2000年9月起微软把核心代码授权回剑桥，HTK 3重新免费提供源码。之后它长期是论文复现和课程作业的标准工具，决策树状态绑定、MLLR说话人自适应、MPE区分性训练等方法都在HTK里实现并随之普及；HMM语音合成HMM参数语音合成也是作为HTK的补丁发布的。

2011年Kaldi以真正开源的许可、WFST解码器解码和更现代的代码取代了它的位置；声学模型此后又被CD-DNN-HMM等神经网络模型取代。

容易误解的地方

  • HTK源码可以免费下载，但许可证不允许再分发，严格说不算开源软件；这正是后来Kaldi强调Apache许可的原因。
  • 骨架里的1993年对应Entropic接手和WSJ评测的时间，HTK本身最早写于1989年。

局限与后续

  • 许可证不允许再分发修改后的代码，1993–2000年间还需付费购买，社区难以共同开发和共享完整配方。
    后来针对它的工作　Kaldi
  • 声学模型是最大似然训练的高斯混合，对非高斯分布、相邻帧之间的相关性建模能力有限。
    后来针对它的工作　MPE区分性训练 CD-DNN-HMM
  • 解码器直接在词网络上做动态展开，难以把大词表三元文法语言模型、跨词三音子和发音词典统一优化，速度和内存都吃紧。
    后来针对它的工作　WFST解码器 Kaldi

它建立在什么之上

  • 使用
    Baum-Welch算法1970 · 语音
    核心训练工具HERest就是对整句串接HMM做Baum-Welch嵌入式重估。
  • 延续
    HMM统计语音识别1976 · 语音
    把统计识别从各实验室内部代码变成通用工具包，并采用连续密度高斯混合而非离散分布。
  • 使用
    MFCC特征1980.08 · 语音
    特征提取工具HCopy以MFCC加一阶、二阶差分为标准配置，使MFCC成为整个GMM-HMM时代的默认特征。
  • 竞争
    CMU SPHINX1988 · 语音
    同期的两大识别平台：SPHINX走离散/半连续HMM路线，HTK用连续高斯混合；后来Sphinx-III也转向连续密度。
  • 使用
    Viterbi算法1967.04 · 语音
    解码工具HVite在词网络中做Viterbi搜索，训练中的强制对齐也用它。
  • 使用
    DARPA共同评测范式1987 · 语音
    以ARPA华尔街日报评测为主战场，在统一测试集上与各实验室比较。

读懂它需要的概念

隐马尔可夫模型 EM算法 高斯分布 音素、声学模型与语言模型的分工 词错误率

本篇术语

  • 嵌入式重估（embedded re-estimation）　训练时不需要知道每个音素在句子里的起止时间，只要把整句的音素HMM串起来，由前向-后向算法自己推算每帧属于哪个状态。
  • 强制对齐（forced alignment）　已知一句话的文字内容，用Viterbi找出每个音素或状态对应的时间段。常用来给数据打时间标注。
  • 跨词三音子　三音子的上下文跨越词边界，例如前一个词的最后一个音会影响后一个词第一个音的模型。比只在词内用三音子更准，但解码更复杂。

怎么学

先补隐马尔可夫模型和EM算法。然后读《HTK Book》第1–3章，其中的YES/NO和小词表教程把一个完整系统从特征到打分走了一遍。动手：如果不想注册下载HTK，可以在Kaldi的yesno或TIMIT配方中找到与HTK各工具一一对应的步骤（特征→单音素→三音子→绑定→解码），对照着跑一遍。
