ManiSkill操作技能基准

ManiSkill: Generalizable Manipulation Skill Benchmark with Large-Scale Demonstrations
2021.07数据集延伸NeurIPS 2021 Datasets and BenchmarksTongzhou Mu, Zhan Ling, Fanbo Xiang, Derek Yang, Xuanlin Li, Stone Tao, Zhiao Huang, Zhiwei Jia, Hao Su · 加州大学圣地亚哥分校待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

已有操作基准里同一类物体的三维形状太单一，学到的策略换个形状的抽屉、椅子就不会了，也缺少大规模示范来训练模仿学习。

方法

在SAPIEN全物理仿真器里，用类内拓扑和几何差异很大的三维物体搭建操作任务，提供点云/RGB-D观测和约3.6万条成功示范。

影响

确立了“对没见过的物体形状泛化”这一评测重点，后续ManiSkill2、ManiSkill3都沿着它扩展，成为机器人学习里常用的仿真基准系列。

方法

RLBench、Meta-World等基准的物体种类少，同一任务里的物体几乎是同一个模型，策略容易记住具体形状。ManiSkill（全称SAPIEN Manipulation Skill Benchmark）基于SAPIEN铰接物体仿真的铰接物体仿真，挑选了几类操作挑战——开柜门、拉抽屉、推椅子、移动水桶——每类都配上拓扑和几何差别很大的多个物体实例，并把训练和测试物体分开，专门考察泛化。

为了吸引做三维视觉的研究者，它模拟一个随机器人移动的全景相机，输出以自身为中心的点云或RGB-D图像。除了强化学习，它还为模仿学习与行为克隆提供了约3.6万条成功轨迹、约150万帧点云/RGB-D数据，并给出基于三维深度网络和示范学习的基线；仿真器、环境和基线代码全部开源，并据此举办了公开挑战赛。

局限与后续

  • 任务类型只有少数几类、只支持单一机器人形态，仿真速度也慢，难以支撑大规模强化学习。

它建立在什么之上

  • 竞争
    RLBench2019.09 · 具身·世界模型
    同为操作基准；RLBench任务多但物体变化少，ManiSkill强调类内物体形状的泛化。
  • 竞争
    Meta-World2019.10 · 具身·世界模型
    Meta-World考察跨任务的多任务与元学习，ManiSkill考察同一任务内跨物体的泛化。
  • 使用
    SAPIEN铰接物体仿真2020.03 · 具身·世界模型
    建立在SAPIEN的铰接物体仿真与PartNet-Mobility物体资源之上。
