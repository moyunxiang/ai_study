Glow-TTS

Glow-TTS: A Generative Flow for Text-to-Speech via Monotonic Alignment Search
2020.05论文延伸NeurIPS 2020Kim, Kim, Kong, Yoon · Seoul National University / Kakao待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

FastSpeech等并行TTS模型需要自回归老师提供对齐，无法独立训练。

方法

用流模型加单调对齐搜索，让模型自己找到文本与语音之间最可能的单调对齐，不需要外部对齐器。

影响

提供了无需老师的并行TTS训练方式，其单调对齐搜索也被VITS沿用。

方法

FastSpeech和ParaNet可以并行生成梅尔频谱，但它们需要一个自回归TTS模型当『外部对齐器』，告诉每个音素对应多少帧，所以训练流程要先训好老师。

Glow-TTS用Glow式的生成流（可逆流与流匹配）把梅尔频谱可逆地映射到一个隐空间，在隐空间里假设每个音素对应一个高斯分布。关键是单调对齐搜索（MAS）：因为文本和语音的对应是严格单调、不跳跃的，所以可以用动态规划（见动态规划）精确找出似然最大的对齐，训练时交替做『找最佳对齐』与『更新参数』，不需要任何外部对齐信息。推理时先预测每个音素的时长，再从高斯采样并反向通过流得到频谱。

摘要称，强制硬单调对齐使模型对长句稳健，并比自回归Tacotron 2快一个数量级，还能控制语速和声音多样性。

局限与后续

  • 流模型参数量大，推理需要的显存较多。

  • 仍是两阶段的：先生成梅尔频谱，再靠独立声码器出波形。
    后来针对它的工作　VITS

它建立在什么之上

  • 改进
    Tacotron2017.03 · 语音
    注意力对齐不够稳，长句或生僻输入会跳字、重复或停不下来；逐帧自回归解码也慢。
  • 改进
    Tacotron 22017.12 · 语音
    自回归注意力解码偶尔跳字、重复，长句或超长输入时停止判断会失败，且无法直接控制语速。
  • 改进
    FastSpeech2019.05 · 语音
    FastSpeech需要自回归老师提供对齐和蒸馏，Glow-TTS用单调对齐搜索自己学对齐。
  • 使用
    标准化流RealNVP2016.05 · 生成
    用仿射耦合式的生成流建模梅尔频谱的似然。
  • 改进
    FastSpeech 22020.06 · 语音
    仍依赖外部强制对齐工具得到时长，并非完全自洽。

后来的相关工作

  • 改进
    VITS2021.06 · 语音
    沿用Glow-TTS的单调对齐搜索和流模型先验，但把输出从梅尔谱改为直接生成波形。
  • 竞争
    FastSpeech 22020.06 · 语音
    同期去除教师依赖的另一条路线：它用流加对齐搜索，FastSpeech 2用外部对齐加方差适配器。
