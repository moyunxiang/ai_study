Diffusers

2022.07系统延伸2022Hugging Face团队 · Hugging Face待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

扩散模型的代码分散在各论文仓库，采样器、模型、训练脚本互不兼容，很难直接拿来用。

方法

提供统一接口：用pipeline一键推理，用可互换的scheduler选择采样算法，用model加载预训练的网络。

影响

让开源的Stable Diffusion开源等模型以几行代码就能跑起来、被微调，成为扩散模型生态的事实标准库。

方法

Diffusers是一个基于PyTorch的Hugging Face库，README称其为最先进预训练扩散模型的首选库，覆盖图像、音频乃至三维分子结构的生成，既可推理也可训练。三大组件：Pipeline用几行代码完成生成；Scheduler是可替换的噪声调度/采样器，在速度与质量间取舍；Model是预训练的网络积木，可与调度器拼成完整系统。这种解耦让研究者只换采样器、不改网络，或只换网络、不改采样器。它与Hugging Face Transformers共享模型中心的使用方式，潜空间扩散LDM类模型靠它得到广泛使用，并可通过PEFT库挂载LoRA适配器（README称一个Stable Diffusion LoRA检查点只有约8.8MB）。首发日期未在页面核实。

局限与后续

  • 不同模型的采样、条件控制各不相同，接口统一后仍需要理解底层才能调优。

读懂它需要的概念

扩散：前向加噪与反向去噪 噪声调度与采样步数 潜空间

怎么学

读README的快速入门，运行一个文生图pipeline，然后更换scheduler观察步数与质量的变化。
