Axolotl微调框架

2023.04系统延伸Wing Lian等 · OpenAccess AI Collective, Axolotl AI待核对
GitHub ↗文档 ↗在交互版中打开（演化树、学习进度）

问题

2023年开源模型大量涌现，社区想快速试各种数据格式、LoRA/QLoRA、DeepSpeed或FSDP的组合，但每次都要自己拼Transformers、PEFT、bitsandbytes和分布式配置的胶水代码。

方法

把一次微调的全部选择——基础模型、数据集与对话模板、全参或LoRA/QLoRA、并行方式、注意力内核——写进一个YAML配置文件，由框架负责组装，用一条命令启动训练。

影响

成为开源社区微调模型最常用的工具之一（常与LLaMA-Factory、Unsloth并列比较），许多社区模型在发布时附上Axolotl配置；它持续把新的内核、并行方式和后训练算法以配置项的形式带给普通用户。

方法

Axolotl在Hugging Face Transformers、Hugging Face PEFT库、DeepSpeed（ZeRO与DeepSpeed）与PyTorch FSDP之上做了一层“配置驱动”的封装。用户写一个YAML：指定基础模型、一个或多个数据集及其格式（指令、对话、补全等），选择全参数微调或LoRA/QLoRA，选择并行与显存优化方式，设置学习率等超参数，然后用命令行启动；同一份配置可以复现别人的训练。为了提高吞吐，它较早支持了把多条短样本拼进同一序列的样本打包（sample packing），以及FlashAttention等高效注意力内核。

GitHub仓库建于2023年4月。之后它持续加入新功能：DPO、GRPO等偏好与强化学习后训练，Liger Kernel训练内核等融合内核，序列并行与专家并行，新模型的支持，以及NVFP4等低比特LoRA训练。README近期更新列出了2026年新增的MoE专家并行、NVFP4 LoRA与上下文并行等。

    LoRA、QLoRA等适配器由PEFT库实现，Axolotl负责把它们写成配置项。

本篇术语

  • 样本打包（sample packing）　把若干条短训练样本拼进同一个最大长度的序列，减少填充，提高GPU利用率，同时用掩码避免样本之间相互注意。
