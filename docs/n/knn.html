k近邻

Nearest Neighbor Pattern Classification
1967论文延伸IEEE Transactions on Information Theory 1967Thomas Cover, Peter Hart · 斯坦福大学待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

当时的分类方法多要先假设数据服从某种分布形式，而真实数据往往不满足，缺乏对“不做假设”的方法的理论评价。

方法

不训练：新样本直接找训练集中最近的k个邻居，投票决定类别，并证明最近邻规则的错误率不超过贝叶斯最优错误率的两倍。

影响

给出了无参数方法的第一个干净理论保证，也是今天向量检索、检索增强生成的概念祖先。

方法

k近邻没有训练阶段：保存所有训练样本，预测时计算新样本到每个训练样本的距离，取最近的k个，多数投票（回归则取平均）。k=1时就是最近邻规则。

Cover和Hart的贡献是理论：当样本数趋于无穷时，最近邻规则的错误率R满足R* ≤ R ≤ 2R*(1−R*)，其中R*是贝叶斯最优错误率。也就是说，什么都不假设的方法，错误率也不会超过最优的两倍。实践里要面对距离度量的选择和维度灾难：维度升高后“最近”的邻居和其他点几乎一样远。

局限与后续

  • 预测要遍历全部训练样本，数据量大时很慢；高维下距离失去区分度。
    后来针对它的工作　FAISS向量检索 HNSW近似近邻
  • 距离度量依赖原始特征，无法自己学出好的表示。
    后来针对它的工作　word2vec

后来的相关工作

  • 改进
    word2vec2013.01 · NLP
    距离度量依赖原始特征，无法自己学出好的表示。
  • 竞争
    k-means聚类1967 · 基础
    同年出现、都以欧氏距离为核心：k近邻用有标签的样本直接做分类，k-means在没有标签时自己找出代表点。
  • 竞争
    决策树CART1984 · 基础
    同为非参数方法，k近邻只记住样本、不给规则；CART把空间切成长方块并给出可读规则，对无关特征也更稳健。
  • 使用
    偏差-方差权衡1992 · 基础
    用k近邻作为基准，以k从1到N的变化最直观地展示偏差与方差此消彼长。
  • 使用
    MNIST1998 · 数据·评测
    k近邻是基准里最直接的参照线：不学任何特征，欧氏距离下错误率5.0%。
  • 使用
    Netflix Prize2006.10 · 数据·评测
    基于相似用户或相似电影的近邻方法是领先队伍集成中的常见成分。
  • 延续
    FAISS向量检索2017.02 · 推理·智能体
    核心任务仍是k近邻查找，贡献在于把它做到十亿规模、并用近似方法换速度。
  • 延续
    HNSW近似近邻2016.03 · 推理·智能体
    把精确k近邻搜索换成可扩展的近似图搜索，解决暴力扫描随数据量线性变慢的问题。
  • 使用
    kNN-LM2019.11 · 推理·智能体
    在语言模型的表示空间里做k近邻检索，近邻的下一个词用来修正预测。
