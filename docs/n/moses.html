Moses

Moses: Open Source Toolkit for Statistical Machine Translation
2007.06系统重要ACL 2007 DemoPhilipp Koehn, Hieu Hoang, Alexandra Birch, Chris Callison-Burch, Marcello Federico, Nicola Bertoldi, Brooke Cowan, Wade Shen et al. · 爱丁堡大学、ITC-irst、MIT、RWTH亚琛、马里兰大学、布拉格查理大学等待核对
ACL Anthology ↗Moses官网 ↗在交互版中打开（演化树、学习进度）

问题

短语统计翻译已成为主流，但研究大多在各家私有系统上做；当时最常用的Pharaoh解码器不开源，新人要把对齐、短语抽取、语言模型、解码、调参全部重写一遍，不同论文的结果也无法公平比较。

方法

做一个开源、开箱即用的完整翻译工具链：从预处理、训练、MERT调参到BLEU评测一应俱全，解码器可直接替换Pharaoh；并加入因子化翻译、混淆网络输入和节省内存的数据结构。

影响

成为统计机器翻译时代的公共基础设施，WMT等评测普遍以Moses系统为基线，大批学术研究和中小公司的翻译系统都建立在它之上，直到神经机器翻译取代短语翻译。

背景

2003年的短语统计机器翻译和最小错误率训练MERT之后，短语翻译成为机器翻译研究的主导范式。但一个能用的系统由许多部件组成：GIZA++与对齐模型比较的GIZA++词对齐、短语抽取与打分、n-gram语言模型、束搜索解码器、开发集调参、BLEU评测。论文指出，此前多数工作在私有或内部系统上完成，研究者不得不重复实现这些部件，门槛很高，不同实验的差异也说不清来自哪个环节。Koehn本人的Pharaoh解码器很流行，却是闭源的。

方法

完整工具链。Moses包含数据预处理、训练翻译模型和语言模型、用最小错误率训练调权重、用BLEU评测的全部步骤；词对齐和语言模型分别调用现成的GIZA++和SRILM，避免重复造轮子。还提供一个统一的实验管理脚本，让整套流程可以重复运行，并支持在Sun Grid Engine集群上并行。

解码器。用C++按模块化、面向对象方式编写，接口设计成Pharaoh的直接替代品，具备Pharaoh的全部功能。

三项新功能。

  • 因子化翻译：每个词不只是表面形式，还可以附带词元、词性、形态等“因子”。翻译可以拆成几步，例如先翻译词元、再生成正确的词形；词性等因子更稠密，可以训练更高阶的语言模型。
  • 混淆网络解码：输入不必是一句确定的文本，可以是语音识别给出的多候选词网，让翻译模型帮忙在识别错误之间做选择。
  • 高效数据结构：短语表按源语前缀树组织，翻译时只按需加载用得到的部分；语言模型用二进制格式，并把概率量化到256个区间、每个值只占1字节。

结果

论文称Moses在翻译质量和速度上与当时最有竞争力的系统相当。截至2007年3月1日，项目在sourceforge上的下载已超过1000次，并作为2006年约翰斯·霍普金斯大学夏季研讨会的主题开发。数据结构方面，在NIST汉英任务上短语表的内存占用从1.7GB降到不到20MB，翻译质量和速度没有损失；量化语言模型对翻译效果影响很小。

后来的发展

此后近十年，Moses是统计翻译的事实标准：WMT评测的基线系统、大量学术论文的实验平台，许多公司的翻译产品也以它为起点；后来它还加入了层次短语翻译Hiero式层次短语和基于句法的解码。

2014年起神经机器翻译兴起，RNN编码器-解码器与GRU最初还只是给Moses这类系统多加一个打分特征。到谷歌神经机器翻译和OpenNMT出现后，端到端的神经模型和新一代开源工具取代了短语流水线。Moses附带的分词、大小写处理等预处理脚本在神经翻译时代仍长期被沿用。

读懂它需要的概念

噪声信道与词对齐 n-gram与平滑 解码：贪心、束搜索、温度与top-p 文本生成的自动指标

本篇术语

  • 因子化翻译　把每个词表示成多个因子（表面形式、词元、词性、形态特征）的组合，分步骤翻译和生成，以缓解形态丰富语言的数据稀疏。
  • 混淆网络　一种紧凑的多候选输入：句子的每个位置给出若干个带置信度的候选词，常用来表示语音识别的不确定结果。
  • 前缀树　按词的前缀共享路径组织数据的树结构，查找以某个词串开头的所有短语时很快，也便于只加载需要的部分。

怎么学

先读短语统计机器翻译和最小错误率训练MERT。读Moses论文全文（只有4页），再看官网的基线系统教程。动手：用一个小的平行语料（如几万句的新闻评论语料）按教程跑通“分词→GIZA++对齐→短语抽取→语言模型→MERT→BLEU”，记录每一步的输入输出，体会统计翻译的流水线有多长。
