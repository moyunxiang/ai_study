Visual-RFT视觉强化微调

Visual-RFT: Visual Reinforcement Fine-Tuning
2025.03论文延伸Ziyu Liu, Zeyi Sun, Yuhang Zang, Xiaoyi Dong, Yuhang Cao, Haodong Duan, Dahua Lin, Jiaqi Wang · 上海交通大学、上海人工智能实验室、香港中文大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

R1式可验证奖励强化学习只用在数学、代码这类有标准答案的文本任务上，视觉感知任务（检测、细分类）没有现成的可验证奖励。

方法

为每类视觉任务手工设计可自动计算的奖励：检测用预测框与真值框的IoU加置信度奖励，分类用答对与否，再用GRPO更新VLM。

影响

证明在只有几十到几百张样本的少样本视觉任务上，强化微调明显优于监督微调，打开了“视觉感知也能做RLVR”的方向。

方法

DeepSeek-R1的关键是“可验证奖励”：答案对不对可以由程序判定。Visual-RFT把这个想法扩展到感知任务。模型先输出带思考过程和最终答案的多个回答，再由奖励函数打分，用GRPO按组内相对好坏更新。

检测任务的奖励R_d = R_IoU + R_conf + R_format：R_IoU是模型输出各框与匹配真值框的平均IoU；R_conf对匹配上的框奖励高置信度、对误检框奖励低置信度；R_format检查思考与答案标签格式。分类任务的奖励R_cls = R_acc + R_format，答对得1、答错得0。实验在Qwen2-VL与开源VLM的2B和7B模型上进行。论文报告单样本细粒度分类（约100个样本）比基线准确率高24.3%，COCO两样本检测高21.9、LVIS高15.4，在推理定位和开放词表检测上也优于监督微调。

局限与后续

  • 奖励函数需要按任务逐一设计，难以推广到没有明确判定标准的开放式视觉任务。
