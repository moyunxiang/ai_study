Yarowsky自举词义消歧

Unsupervised Word Sense Disambiguation Rivaling Supervised Methods
1995.06论文重要ACL 1995，pp. 189–196David Yarowsky · 宾夕法尼亚大学待核对
ACL Anthology ↗PDF ↗Wikipedia: Yarowsky algorithm ↗在交互版中打开（演化树、学习进度）

问题

判断多义词在句中取哪个意思（plant是“植物”还是“工厂”），有监督方法效果好，但每个词都要人工标注上千个例句；靠词典释义重叠的无监督方法又不够准。

方法

只给每个意思一两个“种子”搭配词（life→植物，manufacturing→工厂），利用“一个搭配一个意思”和“一篇文章一个意思”两条规律，反复“训练分类器→给更多例子打标签→再训练”，从未标注语料里自己滚雪球。

影响

在12个多义词上平均正确率96.5%，略高于用同样数据全人工标注训练的有监督方法（96.1%）。它让“自举”（bootstrapping）成为半监督学习的经典范式。

背景

词义消歧（WSD）是机器翻译、检索的基础问题：Weaver翻译备忘录早就设想看左右几个词来定词义。1980年代的Lesk词义消歧比较上下文与词典各义项释义的重叠词数，无需标注但准确率有限；1990年代初的有监督方法（包括Yarowsky自己1994年的决策表）很准，可是每个多义词都要成百上千个人工标注的例句，词典里有几万个多义词，根本标不完。也有人用双语平行语料（噪声信道翻译模型那样的英法对照）把不同译法当作不同词义，但平行语料稀少，而且两种语言的词义划分常常不一致。

问题是：能不能只用海量的未标注单语文本，达到有监督的水平？

方法

两条经验规律（都先用数据验证过）：

  • 一个搭配一个意思：紧邻的实词几乎决定词义，相邻实词的可靠性超过97%。plant growth一定是植物，assembly plant一定是工厂。
  • 一篇文章一个意思：同一篇文章里多次出现的多义词几乎总是同一个意思。在10个词上的平均可靠性为99.8%，但只有约一半的出现能从中获益（另一半在文章里只出现一次）。

自举算法，以plant的7538个未标注例句为例： 1. 种子：含life的例句标为A（植物，82句），含manufacturing的标为B（工厂，106句），其余7350句（98%）未标注。 2. 训练：在已标注例句上训练决策表——把所有搭配特征按 log(P(A|搭配)/P(B|搭配)) 的绝对值排序，分类时只用命中的最可靠那一条规则。 3. 扩充：用决策表给未标注例句打分，把高置信度的加入A或B集合；再用“一篇文章一个意思”修正：同一文章中低置信度的少数派标签被多数派覆盖。 4. 重复2–3，直到未标注集合不再变化。新学到的可靠搭配（如animal、cell、car、equipment）会不断把更多例句拉进来，一开始错标的例子也可能在后续迭代中被纠正。

种子也可以从词典释义中自动抽取，或从算法列出的高频搭配中人工挑几分钟。

结果

数据来自4.6亿词的混合语料，评测12个多义词，平均每个词3936个例句。多数类基线63.9%；同样数据上完全人工标注训练的决策表96.1%。无监督版本：只用两个种子词90.6%，用词典释义作种子94.8%，人工挑选高频搭配作种子95.5%；在每轮迭代中都使用“一篇文章一个意思”约束，达到96.5%。在与Schütze无监督方法共有的4个词上，平均为97% 对 92%。

后来的发展

这篇论文是自举/自训练思想在NLP里最常被引用的例子，后来的协同训练（co-training）、信息抽取中“从种子模式滚雪球”的方法，以及NELL永不停止的语言学习这类持续自举的系统，都沿用了“少量种子 + 大量未标注数据 + 迭代扩充”的套路。它测的只是“植物/工厂”这类粗粒度同形异义，Senseval / SemEval随后建立了基于WordNet细粒度义项的统一评测，暴露出细粒度消歧要难得多。

预训练时代，ELMo和BERT给每个词在每个句子里一个不同的向量，词义消歧不再需要为每个词单独训练分类器，作为独立任务也逐渐淡出；但大模型训练中的“自己给数据打伪标签再训练”仍是同一思路。

容易误解的地方

  • “无监督”是相对的：仍要为每个词人工给出意思的划分和少量种子，只是省去了标注例句。
  • 96.5%是在两个意思区别很大的词上测的；对WordNet那种一个词十几个细微义项的情况，“一篇文章一个意思”远没有这么可靠。
  • 自举有“语义漂移”风险：一旦早期把错误的搭配加进来，错误会自我强化。

局限与后续

  • 一次只处理一个词、两个粗粒度意思，每个多义词都要单独建模、单独给种子，无法覆盖整个词表。

读懂它需要的概念

本篇术语

  • 词义消歧（WSD）　给句子里的多义词选出它在此处的意思，如bass是“鲈鱼”还是“低音”。
  • 自举（bootstrapping）　从少量可靠的种子出发，用当前模型给未标注数据打标签，把最有把握的加进训练集，再训练，循环往复。
  • 决策表（decision list）　把“若出现某搭配则判为某意思”的规则按可靠程度排序，分类时只采用第一条命中的规则。

怎么学

先补半监督学习与伪标签。读原文第2–3节（两条规律的统计）和第4节的五个步骤，对照图1、图2理解种子集合怎样扩张。动手：从维基百科抽出含bass或plant的几千个句子，手选两个种子词，实现决策表加自举，每轮打印新学到的前10条规则，观察有没有出现语义漂移。
