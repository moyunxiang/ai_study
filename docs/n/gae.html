广义优势估计GAE

High-Dimensional Continuous Control Using Generalized Advantage Estimation
2015.06论文重要ICLR 2016Schulman, Moritz, Levine, Jordan, Abbeel · UC Berkeley待核对
arXiv ↗Spinning Up：策略优化入门 ↗在交互版中打开（演化树、学习进度）

问题

策略梯度要用“这个动作比平均好多少”（优势）来加权；用整条轨迹的真实回报估计没有偏差但方差极大，用一步TD估计方差小却偏差大，两者之间没有一个可调的统一方案。

方法

把1步、2步……无穷步的优势估计按λ的几何级数加权平均，等价于对TD误差做指数衰减求和；γ和λ两个旋钮在偏差和方差之间连续调节。

影响

成为on-policy策略梯度的标准优势估计器：PPO、OpenAI Five以及大语言模型RLHF中的PPO默认都用GAE。

背景

策略梯度（见策略梯度）的更新方向是E[∇θ log π(a|s) · Â]，其中Â衡量动作a到底好不好。最朴素的REINFORCE策略梯度用之后实际拿到的总回报当Â：没有偏差，但一条轨迹里成百上千步的随机性都叠加进来，方差大到需要海量样本。Actor-Critic与优势函数的做法是学一个价值函数V(s)，用一步的TD误差δ = r + γV(s') − V(s)当Â：方差很小，但V不准时会带来偏差。

2015年用TRPO训练三维机器人行走时，这个取舍非常现实：每一批要采几万到几十万步，估计的噪声直接决定要采多少数据。

方法

先定义每一步的TD误差（见时序差分与自举）：δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)。它本身就是一个“只往前看一步”的优势估计。往前看k步的估计是前k个δ的折扣和：Âₜ⁽ᵏ⁾ = Σ_{l<k} γˡ δₜ₊ₗ。k越大，越依赖真实奖励、越少依赖V，偏差小但方差大。

GAE不挑某一个k，而是把所有k按(1−λ)λᵏ⁻¹加权平均，化简后得到一个很简洁的式子：

Âₜ = Σ_{l≥0} (γλ)ˡ · δₜ₊ₗ

两个端点：λ=0时就是一步TD误差（低方差、有偏）；λ=1时等于实际回报减去V(sₜ)（无偏、高方差）。中间的λ让远处的TD误差按(γλ)ˡ衰减，相当于“越远的事情越不算到这个动作头上”。实现上只要从轨迹末尾倒着扫一遍：Âₜ = δₜ + γλ·Âₜ₊₁。

论文还给出了一个解读：GAE相当于用V做了基于势函数的奖励塑形后再对奖励打折扣。此外，价值网络本身也用信赖域方法（共轭梯度求解）训练，避免对最新一批数据过拟合；策略则用TRPO更新。

结果

在MuJoCo模拟中，策略和价值网络各有一万以上参数，直接从关节状态输出力矩：学会了三维双足跑步（33维状态、10个驱动关节）、四足跑步，以及双足从躺倒到站起。双足任务所需的模拟经验相当于1到2周的真实时间。扫参实验发现中间值最好：γ在0.96–0.99、λ在0.92–0.99之间；不用价值函数或取λ=1时学得明显更慢。

后来的发展

两年后的PPO把GAE写进了默认算法，常用设置γ=0.99、λ=0.95一直沿用到今天；OpenAI Five、InstructGPT与RLHF式的RLHF训练也都用它计算优势。2024年GRPO在大模型推理训练中干脆去掉价值网络，用同一问题多个回答的组内平均分当基线——部分原因正是为大模型再训练一个价值网络（GAE所依赖的V）代价太高。

读懂它需要的概念

策略梯度 Actor-Critic与优势函数 时序差分与自举 奖励、回报与折扣 偏差-方差权衡 策略与价值函数

本篇术语

  • 优势函数　A(s,a) = Q(s,a) − V(s)：在状态s下做动作a比按策略平均行动好多少。正的就该多做，负的就该少做。
  • λ（GAE参数）　控制向前看多远的折扣系数。λ越接近1越相信真实奖励（方差大），越接近0越相信价值网络（偏差大）。
