TorchRL

TorchRL: A data-driven decision-making library for PyTorch
2023.06系统延伸ICLR 2024Albert Bou, Matteo Bettini, Sebastian Dittert, Vikash Kumar, Shagun Sodhani, Xiaomeng Yang, Gianni De Fabritiis, Vincent Moens · Meta / Universitat Pompeu Fabra / Cambridge待核对
arXiv ↗文档 ↗在交互版中打开（演化树、学习进度）

问题

PyTorch已是主流深度学习框架，却缺一个原生、全面、适合大团队在复杂真实数据和环境上做决策与控制的官方RL库，各家库的数据格式与组件互不兼容。

方法

提出PyTorch原生的控制库TorchRL，核心是一个新的数据原语TensorDict——带批维度的张量字典，让环境、策略、回放缓冲和损失模块之间用同一种结构传数据，各组件可独立使用。

影响

成为PyTorch官方生态中的RL库，TensorDict被BenchMARL等多智能体库采用；其损失模块覆盖从DQN到离线RL、Dreamer、TD-MPC2等大量算法，是很多新论文的实现底座。

方法

TorchRL的设计重点是“组件化而非一体化”：

  • TensorDict：一个字典式容器，键是字符串、值是张量（或嵌套TensorDict），所有值共享前几个批维度。它可以整体做索引、切片、搬到GPU、堆叠，像一个张量一样操作。环境的step返回TensorDict，策略读写TensorDict，回放缓冲存TensorDict，损失模块读TensorDict——不同组件之间不需要约定位置参数的顺序；
  • 环境：统一封装Gym/Gymnasium、DMControl、Brax、Isaac、PettingZoo等，并提供可组合的变换（归一化、帧堆叠、奖励缩放）；
  • 数据收集与回放：同步、异步和多进程的收集器，多种回放缓冲和采样器（含优先回放）；
  • 损失模块（objectives）：每个算法的损失实现为一个模块，文档列出了值方法（DQN、分布式DQN、IQL、CQL及离散版）、策略梯度（PPO、ClipPPO、KL惩罚PPO、A2C、REINFORCE）、演员-评论家（DDPG、SAC、TQC、离散SAC、TD3、REDQ、CrossQ）、离线（TD3+BC等）以及BC、GAIL、Decision Transformer、Dreamer、TD-MPC2、RND等。

论文给出了各组件的细节、跨领域任务的概览，并通过对比基准展示其可靠性与计算效率。
