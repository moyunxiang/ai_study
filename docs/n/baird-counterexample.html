Baird反例与发散问题

Residual Algorithms: Reinforcement Learning with Function Approximation
1995论文延伸ICML 1995Leemon Baird · 美国空军学院待核对
ICML 1995（网站首页，未取得具体文章链接） ↗在交互版中打开（演化树、学习进度）

问题

把Q学习、TD等和函数近似结合起来，大家以为只要拟合足够，一定收敛；但没有证明，实际也出现不稳定。

方法

构造一个最小的反例：线性函数近似加离策略更新，权重会无限增大、不收敛；并提出残差梯度算法作为修补。

影响

这个反例让人注意到“函数近似加自举加离策略”这个组合的危险，是后来deadly triad的原型。

方法

Baird的反例是一个简单的“星形”MDP：一组线性参数同时决定多个状态的价值，更新时按与当前行为策略不一致的分布采样。对标准TD或Q学习，权重不会收敛，而是越来越大。关键在于三件事同时出现：用函数近似、用自举（拿估计值更新估计值）、离策略。

他提出残差算法：直接对Bellman误差做梯度下降，用残差梯度，保证收敛，但学得慢，而且在随机环境下对“双采样”有要求，所以没有成为主流。

后来的发展

梯度TD（GTD/TDC）在2009年用新的目标函数给出了稳定的离策略线性TD；致命三元组把这个现象总结为深度RL的核心难点，DQN靠经验回放与目标网络经验性地缓解。

局限与后续

  • 残差梯度虽然收敛，但学得很慢，可能收敛到较差的解。
    后来针对它的工作　梯度TD（GTD/TDC）
  • 这类不稳定在深度网络里依然存在，只有经验性缓解。
    后来针对它的工作　DQN 致命三元组

它建立在什么之上

  • 竞争
    时序差分学习1988 · RL
    指出线性TD在离策略下也可能发散。
  • 竞争
    Q-learning1992 · RL
    用反例指出Q学习与函数近似结合会发散。

后来的相关工作

  • 改进
    策略梯度定理1999 · RL 已核对
    价值函数方法在函数近似下可能发散或振荡；直接对策略做梯度上升，参数小变化只引起策略小变化，绕开了这一问题。
  • 改进
    DQN2013.12 · RL 已核对
    论文引用Baird等工作说明Q-learning配非线性函数近似或离策略学习可能发散；DQN用回放和上一轮参数算目标，在7款游戏的实验中没有观察到发散，但没有理论保证。
  • 改进
    DQN（Nature版）2015.02 · RL
    离策略+函数近似+自举容易发散；冻结的目标网络在实践中显著减轻了振荡和发散（无理论保证）。
  • 延续
    Double DQN2015.09 · RL
    此前常把DQN的不稳定归因于Baird等指出的离策略+函数近似发散问题；本文的实验表明在Atari上主要元凶是高估。
  • 改进
    线性TD收敛性分析1997 · RL
    说明了反例中的发散是离策略采样造成的，同策略线性TD收敛。
  • 改进
    梯度TD（GTD/TDC）2009 · RL
    对Baird反例所示的离策略线性TD发散问题给出收敛的算法。
  • 改进
    致命三元组2018.12 · RL
    把Baird反例体现的理论发散，放到现代深度网络上做经验检验。
