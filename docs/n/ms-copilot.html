Microsoft 365 Copilot

2023.03系统延伸Microsoft待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

办公软件的使用者每天要花大量时间写文档、做表格、读邮件，而ChatGPT发布这类工具与办公软件是割裂的。

方法

2023年3月16日微软官方宣布Microsoft 365 Copilot，把基于GPT-4的助手嵌入Word、Excel、PowerPoint、Outlook和Teams，并通过企业数据提供上下文。

影响

第一个大规模面向企业的大模型办公助手，也是「Copilot」品牌扩展到整条产品线的起点。

方法

据官方博客（发布于2023年3月16日），产品的定位是「你的工作副驾驶」，由GPT-4驱动，直接在用户已有的办公应用内工作，例如根据已有文档起草内容、总结会议、根据数据生成表格分析。官方强调它能访问用户在企业内的数据，并受企业的权限和合规控制约束。

它延续了GitHub Copilot在编程领域的做法：把模型放进用户原有的工作流程，而不是做一个独立的聊天窗口。与微软追加投资与新Bing同属「Copilot」品牌的一部分。

后来的发展

Copilot品牌后来扩展到Windows、Edge和硬件（Copilot+ PC与NPU）。它是企业级大模型付费订阅的主要样本之一，也引出对企业数据治理与幻觉的新要求。
