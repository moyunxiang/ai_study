MemoryBank长期记忆

MemoryBank: Enhancing Large Language Models with Long-Term Memory
2023.05论文延伸AAAI 2024Wanjun Zhong, Lianghong Guo, Qiqi Gao, He Ye, Yanlin Wang · 中山大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

聊天模型每次对话都从零开始，记不住用户前几天说过什么，在陪伴、心理咨询这类需要长期交往的场景里尤其明显。

方法

给模型外挂一个记忆库：保存带时间戳的对话、每日和全局的事件摘要以及用户性格画像；提问时按向量检索相关记忆；再仿照艾宾浩斯遗忘曲线，让久未提起的记忆逐渐淡化、被反复提起的记忆得到加强。

影响

是较早为LLM设计完整长期记忆机制的工作之一，遗忘曲线式的记忆更新被后来的智能体记忆研究反复引用；在A-MEM等后续工作中常作为对比基线。

方法

三个部分：

  • 记忆存储：逐轮记录对话及时间；每天用LLM把当天对话压缩成事件摘要，再汇总成全局摘要；同样每天总结用户的性格特点，汇总成全局画像。
  • 记忆检索：类似稠密检索DPR的双塔检索，把每条记忆预先编码存进FAISS向量检索索引，用当前对话作查询找出相关记忆，连同全局摘要和画像一起放进提示（实现用LangChain）。
  • 记忆更新：借用艾宾浩斯遗忘曲线 R = e^(−t/S)，R是记忆保留程度，t是距上次提起经过的时间，S是记忆强度。一条记忆初次出现时S = 1；每被回忆一次S加1、t清零。于是常被提到的事记得牢，很久没提的事逐渐被遗忘。作者自己也说这是一个探索性的、高度简化的模型。

应用：基于ChatGPT、ChatGLM-6B和BELLE做了陪伴聊天机器人SiliconFriend；两个开源模型还用3.8万条心理咨询对话做了LoRA微调，以提高共情能力。评测时让ChatGPT扮演15位性格各异的虚拟用户聊10天，再用194个追问检验模型是否记得，指标包括记忆检索准确率、回答正确性和上下文连贯性。

局限与后续

  • 遗忘曲线只按时间和提及次数机械衰减，不判断一条记忆本身是否重要，重要但很少提起的事也会被淡化。

  • 记忆之间没有组织和关联，只是平铺的片段加摘要，难以回答需要串联多条记忆的问题。
