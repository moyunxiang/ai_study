X-VLM多粒度对齐

Multi-Grained Vision Language Pre-Training: Aligning Texts with Visual Concepts
2021.11论文延伸ICML 2022Yan Zeng, Xinsong Zhang, Hang Li · 字节跳动AI Lab待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

视觉语言预训练要么依赖检测器的物体特征做细粒度对齐（难以学多个物体之间的关系），要么只做整图与整句的粗粒度对齐（丢掉了局部对应）。

方法

把“视觉概念”定义为不同粒度的图像区域（单个物体、多个物体组成的区域、整张图），预训练时一边根据文本定位对应区域，一边把文本和该区域对齐。

影响

以较小的模型和数据规模在检索、VQA、视觉推理和定位等任务上超过同期方法，“多粒度对齐”成为2022年前后VLP的一个常用思路。

方法

当时视觉语言预训练（VLP）有两大类做法。OSCAR、VinVL一类先用检测器抽出物体特征，再做物体与词的细粒度对齐，但物体是孤立的，学不好“桌上的杯子”这类多物体关系；ALBEF、ViLT一类直接输入整图像素，只做整图与整句的对齐，又丢了局部对应。

X-VLM的出发点是：一段文字对应的视觉内容可以是任意粒度——一个物体、一块包含几个物体的区域、或整张图。模型用Swin Transformer式视觉Transformer编码整图，任意框内的区域特征可以直接从整图的patch特征中取出并聚合，不必额外跑检测器。训练数据中既有普通图文对，也有带框标注的区域-描述数据（如物体标签和区域描述）。预训练时同时做两件事：定位——给一段文本，预测它对应区域的框坐标；对齐——在每种粒度上做文本与视觉概念的对比学习、匹配和掩码语言建模。

摘要报告，X-VLM学到的多粒度对齐能有效迁移到多种下游视觉语言任务，并一致超过当时最好的方法。

局限与后续

  • 依赖带框标注的区域-文本数据来学细粒度对齐，这类数据比普通图文对少得多，难以随规模扩展。

它建立在什么之上

  • 改进
    VinVL2021.01 · 多模态
    不依赖检测器提取孤立物体特征，改为直接定位任意粒度的区域，从而能学多物体关系。
  • 使用
    Swin Transformer2021.03 · 视觉
    以Swin Transformer作为视觉编码器，区域特征从patch特征中聚合（一般了解）。
  • 使用
    MDETR2021.04 · 多模态
    借鉴文本条件下预测框坐标的思路，把定位作为预训练任务之一。
  • 延续
    ALBEF2021.07 · 多模态
    沿用ALBEF式的图文对比、匹配与掩码语言建模目标，并把对齐推广到多种粒度。

本篇术语

  • 视觉概念（visual concept）　X-VLM里指与一段文本对应的任意图像区域，可以是单个物体、几个物体组成的区域或整张图。
