BBF

Bigger, Better, Faster: Human-level Atari with human-level efficiency
2023.05论文延伸ICML 2023Max Schwarzer, Johan Obando-Ceron, Aaron Courville, Marc Bellemare, Rishabh Agarwal, Pablo Samuel Castro · Google DeepMind / Mila待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Atari 100K只给10万步交互，之前最强的是复杂的基于模型方法（如EfficientZero），无模型方法难以兼顾样本效率与计算成本。

方法

做出一个纯价值型智能体，通过放大价值网络并配合一系列让大网络在少量数据下稳定训练的设计，在Atari 100K上达到超人水平。

影响

用无模型方法以较低算力做到超人的样本效率，并促使作者建议为样本高效RL研究更新基准目标。

方法

BBF的核心是把价值估计网络做大，同时采用一系列使大网络在小数据下不崩的设计。其中包括延续首因偏差与网络重置的周期性参数重置，让网络不被早期数据绑死，另有其他稳定训练的设计选择。摘要强调：它在Atari 100K上达到超人水平，且计算量远小于基于模型的强基线（具体超参和每项消融的数字本条目未引用）。

论文最后讨论了ALE上样本效率研究的目标应当如何更新。

它建立在什么之上

  • 改进
    DQN2013.12 · RL 已核对
    需要1000万帧（约46小时实时游戏）才学会一款游戏，远比人类慢；ε-贪心在奖励稀疏的游戏里几乎找不到奖励。
  • 改进
    DQN（Nature版）2015.02 · RL
    每款游戏要5000万帧（约38天游戏时间），且每款单独训练，数据效率和跨游戏迁移都很差。
  • 改进
    Rainbow2017.10 · RL
    每款游戏训练2亿帧、在单GPU上约10天，样本效率和计算成本都很高。
  • 改进
    Agent572020.03 · RL
    样本效率极低，需要大规模分布式训练和海量游戏帧，难探索游戏和Skiing要训练到很后期才过人类线。
  • 竞争
    EfficientZero2021.10 · RL
    同一基准上的两条路线：EfficientZero靠学模型加搜索，BBF靠放大价值网络并用重置，计算更省。
  • 改进
    SPR自预测表示2020.07 · RL
    在更高的更新-数据比下网络会丧失可塑性，单靠自预测损失无法继续提升样本效率。
  • 改进
    REDQ随机集成双Q2021.01 · RL
    高UTD下网络会逐渐丧失可塑性，单靠集成并不能根治，后来的工作转向重置与网络结构。
  • 延续
    首因偏差与网络重置2022.05 · RL
    沿用并发展其中的周期性重置技巧，使大网络可用。
