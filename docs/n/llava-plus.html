LLaVA-Plus工具使用

LLaVA-Plus: Learning to Use Tools for Creating Multimodal Agents
2023.11论文延伸ECCV 2024Shilong Liu, Hao Cheng, Haotian Liu, Hao Zhang, Feng Li, Tianhe Ren, Xueyan Zou, Jianfeng Gao et al. · 清华大学 / 微软研究院 / 威斯康星大学麦迪逊分校 / IDEA研究院待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

LLaVA只能靠自身看图回答，做不了检测、分割、编辑、检索这类要专门模型的任务；而让LLM调工具的方法（如Visual ChatGPT）只把图像转成文字交给语言模型，图像本身没参与推理。

方法

维护一个包含预训练视觉和视觉语言模型的技能库，用多模态工具使用指令数据训练LLaVA，让它根据用户输入决定调用哪个工具、怎样组合，并在整个交互中始终直接看着图像。

影响

在原有能力上超过LLaVA，并获得检测、分割、生成、外部知识检索等新能力，是多模态工具调用智能体的早期代表。

方法

HuggingGPT等工作让纯文本LLM调度视觉模型，但LLM看不到图，只能读其他模型给的文字描述；LLaVA能看图，却没有工具。

LLaVA-Plus把两者结合。技能库中放着Grounding DINO（检测）、Segment Anything（分割）、OCR、图像生成与编辑、外部知识检索等预训练模型。训练数据是多模态指令：每条样本包含用户请求和图像、模型应生成的“思考与工具调用”（调用哪个工具、传什么参数）、工具返回的结果，以及模型据此组织的最终回答。用这类数据继续训练LLaVA，它就学会在需要时输出结构化的工具调用，把返回的框、掩码或图片与原图一起纳入后续推理；多个工具也能组合（例如先检测再分割再编辑）。

摘要称LLaVA-Plus在已有能力上超过LLaVA并展现新能力；它的特点是图像查询在整个人机交互过程中都被直接定位和使用，显著提升了工具使用效果。

局限与后续

  • 工具集合和调用格式在训练时固定，新增工具需要重新构造数据再训练。
