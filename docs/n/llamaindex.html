LlamaIndex

2022.11系统延伸开源项目 2022-11Jerry Liu · LlamaIndex（开源项目）待核对
GitHub ↗维基百科 ↗在交互版中打开（演化树、学习进度）

问题

大模型上下文有限，想让它回答私有文档里的问题，需要自己切分、建索引、检索再拼提示，没有现成工具。

方法

做一个把外部数据接入大模型的索引工具：加载文档、建立索引结构、按查询取回相关部分交给模型。

影响

成为RAG应用的主流数据框架之一，把数据接入与检索策略做成可替换的组件。

方法

据维基百科，项目起源于Jerry Liu在2022年11月发布到GitHub的小工具，最初名为GPT Tree Index，用树形索引组织文档；2023年更名为LlamaIndex并成立公司。典型流程是：用数据连接器读取PDF、数据库等；切成节点并嵌入；存入向量索引（可用FAISS向量检索等）；查询时检索相关节点，连同问题一起交给模型生成回答。

与LangChain相比，它更偏重数据的摄取、索引与检索，后续还加入了代理、评测等模块。

后来的发展

它和LangChain一起推动了RAG的工程化；之后的GraphRAG、RAPTOR树状检索等结构化检索思路常以此类框架实现。
