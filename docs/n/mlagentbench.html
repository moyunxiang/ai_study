MLAgentBench

MLAgentBench: Evaluating Language Agents on Machine Learning Experimentation
2023.10数据集延伸Huang, Vora, Liang, Leskovec待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

机器学习研究的核心是实验：设计、运行、分析、迭代。语言模型智能体能否胜任，当时缺少系统评测。

方法

构建一个含13个任务的基准，任务从在CIFAR-10上提升模型性能到BabyLM等较新的研究问题，智能体可以读写文件、执行代码、查看输出。

影响

成为评估LLM智能体做机器学习实验的早期基准，并暴露了长期规划与幻觉问题。

方法

每个任务给智能体一个起始代码仓库和一个改进目标，智能体通过读写文件、运行脚本、检查输出的动作循环来迭代。作者基于ReAct框架构建了一个智能体，并比较了Claude v1.0、v2.1、v3 Opus、GPT-4、GPT-4-turbo、Gemini-Pro和Mixtral。

论文称，Claude v3 Opus智能体的成功率最高，在各任务上平均为37.5%；不同任务差异很大，在老牌数据集上可达100%，在模型训练之后才发布的近期Kaggle比赛上低至0%。作者还指出了长期规划和减少幻觉两大挑战。

后来的发展

它与SWE-bench一起奠定了用真实任务评测智能体的做法，后续的ScienceAgentBench、CORE-Bench等科研类基准沿着它扩展。

局限与后续
