AQuA-RAT代数题与解题理由

Program Induction by Rationale Generation : Learning to Solve and Explain Algebraic Word Problems
2017.05数据集延伸ACL 2017Wang Ling, Dani Yogatama, Chris Dyer, Phil Blunsom · DeepMind / 牛津大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

解代数应用题需要执行一串运算（一个“程序”），但直接从“题目—答案”对里学出这个程序太难；而已有的应用题数据集只有几百到几千道，也没有解题过程。

方法

收集约10万道带选项的代数应用题，每道题配一段人写的“解题理由”（自然语言加算式的逐步推导），让模型先生成理由再得到答案，用理由间接监督程序的学习。

影响

AQuA-RAT是最早的大规模“带逐步解题过程”的数学数据集，比思维链早约五年就把“先写推理过程再给答案”作为训练信号；后来的MathQA就是在它上面补标运算程序得到的。

方法

背景。2017年前的应用题数据集（如Alg514、Dolphin）规模在几百到几千题，主流方法是把题目映射成方程模板。对于Seq2Seq式神经网络来说，只给最终答案，模型很难学会中间的多步计算；直接标注可执行程序又成本太高。

数据。作者从网上的考试题（GMAT、GRE风格）中收集种子题，再请众包工作者改写出新题，最终得到约10万道题。每道题包含：题干、五个选项（A–E）、正确选项，以及一段解题理由，例如“设原价为x，打八折后为0.8x，0.8x = 40，所以x = 50，选C”。理由是自然语言和数学表达式的混合，不是严格的程序，但给出了一步步的中间里程碑。

模型。作者设计了一个序列到序列模型，按步生成理由中的每个词；生成过程中的算式部分对应可执行的运算，从而把“生成理由”和“执行程序”结合起来。实验表明，通过答案理由间接监督程序学习是可行的思路。

后来。数据中的理由质量参差，有的不完整或有错，后来的工作常把它当作考察大模型多步算术的选择题基准；思维链CoT提示论文也用它做评测之一。

局限与后续

  • 理由是自由书写的，常有跳步、错误或与选项不对应，无法直接执行；众包改写也带来了大量近似重复的题。

读懂它需要的概念

基准、排行榜与SOTA 编码器-解码器 自回归生成 监督学习

本篇术语

  • 解题理由　AQuA-RAT里每道题附带的逐步推导文字，相当于标准答案的解题过程，后来常被称为rationale。
  • 程序归纳　从输入输出例子中自动学出能产生正确输出的程序，这里的程序就是一串算术运算。

怎么学

先了解Seq2Seq；读AQuA-RAT原文的数据示例和模型结构图；动手从数据集中随机抽十道题，看理由中有多少能一步步算出正确选项。
