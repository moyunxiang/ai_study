可逆残差网络i-ResNet

Invertible Residual Networks
2018.11论文延伸ICML 2019Jens Behrmann, Will Grathwohl, Ricky T. Q. Chen, David Duvenaud, Jörn-Henrik Jacobsen · 不来梅大学、多伦多大学、Vector研究所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

标准化流要求网络可逆、雅可比行列式好算，于是只能用耦合层（把维度一分为二）或自回归结构这类受限设计，表达力和通用性都打了折扣；而最常用的ResNet本身不可逆。

方法

只要让残差块里那一支的Lipschitz常数小于1（训练时加一步谱归一化），y = x + g(x)就一定可逆，可用不动点迭代求逆；雅可比对数行列式则用幂级数展开加随机迹估计近似。

影响

同一个标准ResNet结构既能当分类器又能当基于最大似然训练的流模型，两种任务上都有竞争力；它对行列式的有偏近似由几个月后的Residual Flows改成无偏估计。

方法

残差块F(x) = x + g(x)。若g的Lipschitz常数Lip(g) < 1，那么对任意y，映射x ↦ y − g(x)是压缩映射，由巴拿赫不动点定理，迭代x_{k+1} = y − g(x_k)收敛到唯一解，所以F可逆，而且求逆只要迭代几次。保证Lip(g) < 1的办法是对g中每层卷积的权重做谱归一化（谱归一化），再乘一个小于1的系数，这在常见框架里只是一行代码。

用作流模型时需要log|det J_F(x)|。作者利用log det(I + J_g) = tr(log(I + J_g)) = Σ_{k≥1} (−1)^{k+1} tr(J_g^k)/k，把幂级数截断到有限项，每一项的迹用Hutchinson随机估计（只需向量—雅可比乘积）计算，从而避免显式求行列式。

实验表明，同一个i-ResNet在图像分类上与标准ResNet相当，在密度估计上与当时的流模型相当，作者称此前还没有单一架构同时做到这两点。

局限与后续

  • 截断幂级数使对数似然估计有偏，训练目标不精确，截断项数需要权衡。

读懂它需要的概念

可逆流与流匹配 残差连接 雅可比矩阵与海森矩阵 最大似然估计 蒙特卡洛采样

本篇术语

  • Lipschitz常数　函数输出变化与输入变化之比的上界；小于1意味着函数会把任意两点的距离缩小。
  • Hutchinson迹估计　用随机向量v计算vᵀAv的期望来估计矩阵A的迹，只需矩阵—向量乘积，不必写出整个矩阵。

怎么学

先补标准化流的换元公式和RealNVP → 读本文第2节可逆性证明与第3节对数行列式的幂级数估计 → 在二维数据上实现一个小i-ResNet并用不动点迭代求逆。
