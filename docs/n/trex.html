T-REX排序奖励外推

Extrapolating Beyond Suboptimal Demonstrations via Inverse Reinforcement Learning from Observations
2019.04论文延伸ICML 2019Daniel S. Brown, Wonjoon Goo, Prabhat Nagarajan, Scott Niekum · 德克萨斯大学奥斯汀分校 / Preferred Networks待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

逆强化学习（逆强化学习IRL、最大熵逆强化学习）找的是让示范者看起来接近最优的奖励，因此学到的策略基本不可能明显超过示范者；示范质量一般时，学到的也只是一般水平。

方法

不要求示范是最优的，只要求知道几条示范之间“哪条更好”的排序。用排序训练一个奖励网络，使更好的轨迹累计奖励更高；这个奖励捕捉的是“示范者越做越好的方向”，用RL优化它就可能外推到超过所有示范的水平。

影响

首批证明“从次优示范学奖励再用RL优化”可以显著超越示范者的工作之一，把基于排序/偏好的奖励学习（从人类偏好学习奖励）用于离线示范，成为从偏好与排序学奖励的常用基线。

背景

逆强化学习的基本假设是示范来自（近似）最优策略：奖励被选成让示范的回报高于其他所有策略。在这个假设下，学到的奖励最多让智能体复现示范者，而不会告诉它“还能怎样做得更好”。但现实中的示范往往是次优的——人类玩家水平有限、动作有噪声。同时，从人类偏好学习奖励表明人类对两段行为的比较（哪段更好）就足以训练出有用的奖励模型，不过它需要在训练过程中不断询问人。

方法

输入是一组按质量排好序的示范轨迹 τ_1 ≺ τ_2 ≺ … ≺ τ_m（只需观测，不需要动作）。T-REX训练一个奖励网络 r̂_θ(s)，使排在后面的轨迹累计奖励更高，用的是Bradley-Terry式的成对排序损失：

L(θ) = − Σ_{τ_i ≺ τ_j} log [ exp Σ_{s∈τ_j} r̂_θ(s) / ( exp Σ_{s∈τ_i} r̂_θ(s) + exp Σ_{s∈τ_j} r̂_θ(s) ) ]

即把“τ_j比τ_i好”的概率建模为两条轨迹累计奖励的softmax。为了得到大量训练对并避免过拟合，实际训练时从两条轨迹中随机截取长度相近的片段组成对，并约束较好轨迹的片段起点不早于较差轨迹的片段起点。

学到奖励后，用标准深度RL（论文用PPO）在环境中最大化 r̂_θ。由于奖励反映的是“质量随排序上升的方向”，策略可以沿这一方向走得比最好的示范更远。

结果

摘要称，T-REX与深度RL结合后，在多个Atari和MuJoCo基准任务上超过当时最先进的模仿学习和IRL方法，表现常常超过最好示范的两倍以上；对排序噪声鲁棒，还能仅通过观看一个学习者带噪声地逐渐进步来准确外推出意图。

后来的发展

后续的D-REX去掉了人工排序的需要：给行为克隆策略注入不同程度的噪声，自动生成“噪声越大越差”的排序。基于成对比较的Bradley-Terry奖励模型后来也是大模型RLHF中奖励模型的标准训练目标；在机器人领域，PEBBLE偏好强化学习把偏好学习与离策略RL结合，提高了反馈效率。

局限与后续

  • 需要示范之间的质量排序，人工排序有成本；排序错误或示范之间差别不明显时，奖励外推可能指向错误方向。

读懂它需要的概念

奖励设计与奖励投机 模仿学习与行为克隆 Softmax与logits 交叉熵 策略梯度

本篇术语

  • Bradley-Terry模型　成对比较的概率模型：两件东西各有一个得分，A胜过B的概率为 exp(s_A)/(exp(s_A)+exp(s_B))；用它可以从比较结果反推出得分。
  • 奖励外推　学到的奖励不只是复现示范，而是指出“更好”的方向，使优化它能得到比所有示范都好的行为。

怎么学

先读从人类偏好学习奖励理解偏好奖励模型；读原文第4节损失与片段采样；在一个MuJoCo任务上用不同训练阶段的PPO检查点作为排好序的示范，训练T-REX奖励并检查它与真实奖励的相关性。
