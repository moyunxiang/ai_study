k-diffusion采样器库

2022.06系统延伸Katherine Crowson待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

EDM论文给出了更好的噪声调度和采样器，但各家开源扩散模型的接口不同，普通用户没法在Stable Diffusion上直接换用这些采样方法。

方法

用PyTorch实现EDM的框架，把常见模型包装成统一的去噪器接口，再在其上提供Euler、Heun、DPM-Solver系列等一整套采样器。

影响

WebUI里大家熟悉的Euler a、DPM++ 2M Karras等采样器名称大多来自这个库，它是社区换采样器的事实标准。

方法

EDM把扩散模型统一写成噪声水平σ下的去噪器D(x;σ)，采样就是沿σ从大到小解ODE或SDE。k-diffusion按这一写法实现训练与采样，并提供包装器，把v-diffusion-pytorch、OpenAI guided-diffusion、CompVis latent-diffusion（即Stable Diffusion）等模型转换成同一接口。

在此之上，库里实现了一组采样器：一阶Euler、EDM的二阶Heun、经典线性多步LMS；带祖先采样（每步加回随机噪声）的Euler ancestral，社区简称Euler a；还有DPM-Solver及DPM-Solver++的2S、2M等变体，以及自适应步长。选项后缀Karras表示使用EDM提出的噪声水平划分。AUTOMATIC1111 WebUI、ComfyUI节点工作流等工具直接调用这些实现，于是这些名字成了用户界面上的标准选项。仓库后来还加入了沙漏结构的扩散Transformer，对应HDiT沙漏像素Transformer。

局限与后续

  • 采样器名称繁多、彼此差别细微，用户只能凭经验试选；它们都是通用ODE/SDE求解器，少于十步时仍需蒸馏类方法。

读懂它需要的概念

扩散：前向加噪与反向去噪 噪声调度与采样步数 常微分方程与随机微分方程

本篇术语

  • 祖先采样　每一步去噪后再加回一点新的随机噪声的采样方式，结果更有随机性，但同一种子在不同步数下差别大。
