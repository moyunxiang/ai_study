稀疏编码

Emergence of Simple-Cell Receptive Field Properties by Learning a Sparse Code for Natural Images
1996.06论文延伸Nature 1996Bruno Olshausen, David Field · 康奈尔大学待核对
论文页 ↗在交互版中打开（演化树、学习进度）

问题

视觉皮层感受野发现视觉皮层的简单细胞对特定朝向的边缘有反应，却没人能解释为什么大脑会长成这样。

方法

让模型用尽可能少的基函数重建自然图像块，并要求系数稀疏；学出来的基函数自发地像边缘检测器。

影响

说明视觉感受野可能是对自然图像统计的高效编码，开启了无监督特征学习和字典学习。

方法

把一小块图像x表示为一组基函数的线性组合x ≈ Σ a_i φ_i，训练时一边调整基φ_i，一边让系数a_i尽量稀疏，损失为重建误差加上对系数的稀疏惩罚，如λΣ|a_i|（Lasso与L1稀疏的思路）。

用自然风景的图像块训练后，学到的基函数是局部、有方向、带通的，与初级视觉皮层简单细胞的感受野相似，而不是任何人设计的。这提供了一种解释：大脑用稀疏的方式高效编码自然图像。后来稀疏自编码器解释LLM对大模型激活做稀疏字典学习也沿用了同样的思想。

局限与后续

  • 推断系数要对每个图像块解一个优化问题，较慢，且学到的是浅层的单层特征。
