PRM概率路图

Probabilistic Roadmaps for Path Planning in High-Dimensional Configuration Spaces
1996.08论文延伸IEEE T-RA 1996Lydia Kavraki, Petr Švestka, Jean-Claude Latombe, Mark Overmars · Stanford / Utrecht待核对
维基：PRM ↗在交互版中打开（演化树、学习进度）

问题

机械臂的关节空间维度很高，像A*搜索这样在栅格上搜索的方法会因维度灾难而不可行。

方法

先在自由空间里随机采样大量位形，把近邻位形用无碰撞的短路径连成图（路图），之后任意起终点只需接入路图再最短路搜索。

影响

开启基于采样的运动规划，让六七个自由度以上的机械臂路径规划变得可用，与RRT快速随机树并列为两大经典方法。

方法

据维基百科，论文发表在IEEE Transactions on Robotics and Automation（1996年）。算法分两个阶段：

  • 构建：在位形空间随机采样，丢掉与障碍碰撞的点，把每个点与k个最近邻或一定距离内的点用局部规划器连接，直到路图足够稠密。
  • 查询：把起点、终点接入路图，用Dijkstra求最短路径。

一次建好的路图可以服务多次查询，适合障碍物不变的环境。它是“概率完备”的：采样越多，找到已存在路径的概率趋于1，但对有限样本没有保证。

局限与后续

  • 路图在窄通道处很难采到点，狭窄空间里规划很慢。
    后来针对它的工作　RRT快速随机树
  • 适合静态环境，障碍物一变路图就要重建；路径也不平滑、不最优。
    后来针对它的工作　RRT快速随机树

它建立在什么之上

  • 改进
    A*搜索1968.07 · 具身·世界模型
    解决A*在高维位形空间中无法逐格搜索的问题：改为采样得到稀疏的图再搜索。

后来的相关工作

  • 改进
    RRT快速随机树1998.10 · 具身·世界模型
    PRM要在任意两点之间精确连边，有微分约束时很难；RRT只需从已有节点施加控制向前走一步，天然适用于汽车等非完整约束系统，且无需预先建图。
  • 竞争
    CHOMP梯度轨迹优化2009.05 · 具身·世界模型
    PRM预建路图再搜索；CHOMP直接对整条轨迹做连续优化，常被用来平滑采样规划器的结果。
  • 延续
    RRT*渐近最优规划2011.05 · 具身·世界模型
    同时提出PRM*，对路图方法给出同样的最优性保证。

读懂它需要的概念

图、树与搜索 维度灾难 蒙特卡洛采样 自由度、运动学与本体感知

怎么学

先补维度灾难。动手：在二维带障碍物的地图上实现PRM，再换成多连杆臂。
