损失骤降与句法习得

Sudden Drops in the Loss: Syntax Acquisition, Phase Transitions, and Simplicity Bias in MLMs
2023.09论文延伸ICLR 2024Angelica Chen, Ravid Shwartz-Ziv, Kyunghyun Cho, Matthew L. Leavitt, Naomi Saphra · 纽约大学、DatologyAI、哈佛大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

可解释性研究大多只分析训练好的模型，看不到能力是怎样在训练中出现的；训练曲线上偶尔出现的“损失突然骤降”到底对应模型内部发生了什么，也不清楚。

方法

以BERT类掩码语言模型的句法习得为案例，追踪“句法注意力结构”（某些注意力头专门关注特定句法关系）在训练中的演化，并通过在训练中人为抑制或促进它来检验它的因果作用。

影响

发现预训练早期有一个短暂窗口，模型突然获得句法注意力结构，同时损失骤降，之后才习得语法能力；短暂抑制这一结构反而能得到更好的模型，为“训练中的相变”和简单性偏置提供了真实模型中的例子。

方法

背景：BERT的注意力头被发现会自发地对应句法依存关系，例如某个头让动词关注它的宾语，这称为句法注意力结构（SAS）。归纳头与ICL在自回归模型中观察到，归纳头的形成与损失曲线上的一个“鼓包”同时发生；Grokking则展示了训练中能力突然出现的现象。作者想知道在真实的掩码语言模型中，句法能力是否也是这样“突然”出现的。

测量SAS：用依存句法标注，计算每个注意力头分配给句法相关词对的注意力比例，取最好的头作为SAS强度的指标；同时用BLiMP等语法判断基准评估模型的语法能力。

观察：在多次随机种子的BERT预训练中，存在一个短暂窗口：SAS突然出现，损失同时陡降（第一次相变）；随后才出现第二次转折，模型的语法能力在这之后明显提升。也就是说，SAS的出现促成了后续语言能力的获得。

干预：在训练损失中加入一个正则项，惩罚或鼓励注意力集中在句法相关的词对上：

  • 一直抑制SAS的模型，语法能力明显更差，说明SAS对语法能力的发展是必要的；
  • 但SAS与其他有益的能力在训练中存在竞争。只在训练早期短暂抑制SAS、之后再放开，模型反而在最终质量上更好——先学其他东西，再学这个“简单的”句法捷径，避免模型过早依赖它。

作者把这解释为真实模型中的简单性偏置和突破式训练动态的例子。

后来的发展

“沿训练轨迹做可解释性”的做法被后续工作广泛采用，用于研究能力涌现、相变和训练早期的关键窗口。

局限与后续

  • 只研究了BERT规模的掩码语言模型和句法这一种能力，自回归大模型中其他能力是否遵循相同的“结构先出现、能力后跟上”的模式没有验证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    以BERT式掩码语言模型的预训练为研究对象，追踪其注意力头中句法结构的出现。
  • 延续
    归纳头与ICL2022.03 · LLM
    归纳头工作把一个电路的形成与损失曲线的突变对应起来，本文在掩码语言模型的句法结构上找到类似的相变并做了因果干预。
  • 延续
    Grokking2022.01 · 基础
    同样研究训练中能力的突然出现，本文的例子来自真实语言模型预训练而不是小算法任务。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

自注意力与多头注意力 掩码建模 损失函数 正则化与权重衰减 归纳偏置

本篇术语

  • 句法注意力结构（SAS）　掩码语言模型中某些注意力头会专门让一个词关注与它有句法依存关系的词，例如动词关注其主语或宾语。
  • 简单性偏置　神经网络倾向于先学会简单、容易利用的规律，有时会因此推迟或妨碍学会更有用的复杂规律。

怎么学

先读归纳头与ICL中损失曲线与电路形成的对应；读本文第3节SAS度量和训练曲线、第4节抑制与促进实验；动手：用MultiBERTs公开的中间检查点，计算某几个头对依存关系的注意力比例随训练步数的变化，与损失曲线对照。
