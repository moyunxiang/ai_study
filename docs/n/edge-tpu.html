Edge TPU端侧推理芯片

2018.07硬件延伸Google待核对
维基百科（TPU条目Edge TPU一节） ↗Coral官网 ↗在交互版中打开（演化树、学习进度）

问题

数据中心有了Google TPU，但摄像头、传感器、嵌入式设备上跑视觉模型仍要靠功耗高的CPU/GPU，或者把数据传到云端，延迟和隐私都成问题。

方法

做一颗只做8位整数推理的小型专用芯片，功耗约2瓦，配合TensorFlow Lite工具链，把量化后的模型直接部署到边缘设备上。

影响

把TPU路线带到端侧，并通过Coral开发板、USB加速棒等产品让个人开发者也能用上专用推理芯片；其技术后来进入Pixel手机的Neural Core和Google Tensor芯片。

方法

据维基百科，Google于2018年7月宣布Edge TPU，定位是专为在边缘设备上运行机器学习模型而设计的ASIC。它能以2瓦功耗完成每秒4万亿次运算（4 TOPS），只支持8位整数运算，因此模型必须用量化感知训练（见量化感知训练与整数推理），或在2019年底之后用训练后量化转成8位；运行时基于TensorFlow Lite，主要用于前向推理，也可以做轻量的迁移学习。

2019年1月，Google以Coral品牌向开发者推出Edge TPU产品，包括单板计算机、系统模块、USB加速器、mini PCIe卡和M.2卡。2019年10月15日随Pixel 4发布的Pixel Neural Core是为相机功能定制的版本，2021年Pixel 6的Google Tensor芯片里也集成了Edge TPU。它和同期手机里的手机NPU：麒麟970与A11一起，构成了端侧AI芯片的早期版图。

  • 只支持8位整数和有限的算子，模型要专门量化和编译，跑不了大语言模型这类需要大内存的新负载。
