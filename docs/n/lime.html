LIME

"Why Should I Trust You?": Explaining the Predictions of Any Classifier
2016.02论文重要KDD 2016Marco Tulio Ribeiro, Sameer Singh, Carlos Guestrin · University of Washington待核对
arXiv ↗官方代码 ↗Interpretable ML书：LIME一章 ↗在交互版中打开（演化树、学习进度）

问题

准确率最高的模型（随机森林、SVM、深度网络）都是黑箱。测试集准确率高并不说明它学对了东西，而当时的解释方法大多只适用于某一类模型。

方法

不管模型内部，只在要解释的那个样本附近随机扰动输入、记下黑箱的输出，再用一个只含少数几个特征的加权线性模型去拟合这些点，用它的系数当作这一次预测的解释。

影响

第一个被广泛使用的“与模型无关”的局部解释方法，和随后的SHAP一起成为工业界解释表格、文本模型的标准工具，也让“用解释发现数据泄漏”成为常规做法。

背景

2016年前后，表格和文本任务上最好用的是随机森林、核支持向量机和刚开始普及的深度网络，它们的决策过程人看不懂。人们决定是否部署一个模型，主要看留出测试集上的准确率。

问题是测试集和训练集往往带着同样的偏差。论文举了一个例子：在20 Newsgroups数据上区分“基督教”和“无神论”帖子的RBF核SVM，测试准确率94%，但它依赖的是邮件头里的“Posting”“Host”之类的词，跟宗教毫无关系；换到真实网页上就失效。准确率看不出这种问题，必须看模型“凭什么”做判断。

已有的解释方法要么只适用于特定模型（如线性模型的系数、决策树的路径），要么需要模型可微、能求梯度（如梯度显著图）。能不能有一种方法，把任何分类器当作只能调用的函数来解释？

方法

可解释表示。先把输入换成人能看懂的二值特征x′：文本用“某个词在不在”，图像用“某块超像素保留还是涂灰”。

局部采样。对要解释的样本x，随机关掉x′中的一部分特征，得到N个扰动样本z′（例如N = 5000），还原成原始输入后送进黑箱模型f，记下输出f(z)。每个扰动样本按与x的距离加权：π_x(z) = exp(−D(x, z)² / σ²)，文本用余弦距离，图像用L2距离。离原样本越近，权重越大。

拟合稀疏线性模型。求解释模型g（线性模型g(z′) = w·z′）：

ξ(x) = argmin_g Σ π_x(z)·(f(z) − g(z′))² + Ω(g)

其中Ω限制最多只用K个特征。实现上先用Lasso与L1稀疏的正则化路径选出K个特征，再用最小二乘拟合权重（论文称K-LASSO）。得到的K个权重就是解释：例如“这封帖子被判为无神论，主要因为出现了Posting、Host这几个词”，每个词附带一个正负权重。

SP-LIME。单条解释只说明一次预测。为了让人用有限时间了解整个模型，作者把“挑选B个有代表性的样本来展示”写成次模优化问题：用贪心法选一组样本，使它们的解释尽量覆盖全局上重要的特征。

结果

在笔记本电脑上解释一个1000棵树的随机森林（N = 5000）不到3秒；解释GoogLeNet / Inception系列的Inception网络的一次图像预测约需10分钟。

人类实验一：让Mechanical Turk上的非专家在两个宗教分类器之间选一个部署。原始SVM在20 Newsgroups测试集上94.0%，在新收集的宗教网页上只有57.3%；去掉无关特征后的版本测试集88.6%，真实数据69.0%。只看准确率会选错，而看了SP-LIME挑选的解释后，89%的人选对了。

人类实验二：作者故意训练了一个“有雪就判狼”的哈士奇/狼分类器。27名上过研究生机器学习课的学生中，看解释前10人信任这个模型、12人想到雪可能是线索；看了LIME解释后，只剩3人信任，25人指出了雪。

后来的发展

一年后SHAP证明LIME与另外几种方法都属于“加性特征归因”这一类，并用博弈论的Shapley值给出唯一满足若干公理的解，同时把LIME的加权回归改造成Kernel SHAP。两者一起成为表格模型解释的事实标准。

同时，事后解释的可靠性受到持续质疑：可解释性的严格科学呼吁对解释做严格评估；显著图的合理性检验表明一些解释对模型参数几乎不敏感；别再解释黑盒主张高风险决策应直接使用本身可解释的模型，而不是给黑箱配解释。对深度网络，研究重心后来转向打开模型内部的Circuits与机制可解释性与机制可解释性。

容易误解的地方

  • LIME解释的是这一次预测附近的行为，不是模型的全局规则。同一个特征在两个样本上的权重可以符号相反。
  • 结果依赖随机采样、核宽度σ和K的选择，重复运行可能得到不同的解释；论文自己也承认超像素这类表示表达不了“色调偏旧”这样的整体性质。
  • “局部忠实”是相对于加权线性拟合说的，没有理论保证解释真的反映模型的因果依据。

局限与后续

  • 核宽度、采样数、特征数K都靠经验设定，解释结果对这些选择和随机采样敏感，缺乏唯一性和理论依据。
    后来针对它的工作　SHAP
  • 每解释一次都要调用黑箱数千次，解释一张Inception图像预测要约10分钟，难以大规模使用。
    后来针对它的工作　SHAP 积分梯度
  • 只有词、超像素这类低层二值特征，表达不了“条纹”“医生”这样的高层概念。
    后来针对它的工作　TCAV概念激活向量
  • 事后解释本身是否忠实于模型无从验证，在高风险场景中可能给人虚假的放心感。
    后来针对它的工作　显著图的合理性检验 别再解释黑盒

  • 使用
    支持向量机1995 · 基础
    核心案例里的“基督教/无神论”RBF核SVM，测试集94%准确率却依赖邮件头词语。
  • 使用
    随机森林2001 · 基础
    主要解释对象之一，论文用它展示对上千棵树的模型也能几秒内给出解释。
  • 使用
    Lasso与L1稀疏1996 · 基础
    用Lasso的正则化路径从可解释特征中选出K个，再拟合权重，构成K-LASSO。
  • 竞争
    梯度显著图2013.12 · 安全·可解释
    显著图需要模型可微并读取梯度；LIME只调用模型的输入输出，适用于任意分类器，代价是需要大量采样。
  • 使用
    GoogLeNet / Inception2014.09 · 视觉
    用Inception网络演示图像解释，并以它的第一池化层特征构造了哈士奇/狼实验。

本篇术语

  • 与模型无关　解释方法只需要能调用模型、拿到输出，不需要知道模型结构或梯度，因此同一套方法可以解释任何分类器。
  • 局部代理模型　在某个样本附近，用一个简单模型（这里是稀疏线性模型）去模仿复杂模型的行为，再解释这个简单模型。
  • 超像素　把图像中颜色、纹理相近的相邻像素合并成的小区域，常作为图像解释的基本单位。
