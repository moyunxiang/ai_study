VITS

Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech
2021.06论文重要ICML 2021Jaehyeon Kim, Jungil Kong, Juhee Son · Kakao Enterprise / KAIST待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

主流TTS是“声学模型出梅尔谱+声码器出波形”的两段式，声码器常要用第一段的输出再微调；已有的一段式端到端模型虽能并行，音质却比不上两段式。

方法

把整个TTS写成一个条件变分自编码器：文本决定潜变量的先验，潜变量直接解码成波形；先验用标准化流增强表达力，解码器按GAN方式训练，时长用一个随机时长预测器采样。

影响

在LJSpeech上MOS 4.43，与真人录音4.46几乎持平，超过Tacotron 2和Glow-TTS加HiFi-GAN的两段式系统，生成还比实时快67倍；VITS成为开源TTS和声音转换中使用最广的架构之一。

背景

到2021年，最好的TTS是两段式：Tacotron 2、Glow-TTS或FastSpeech 2先从文本预测梅尔谱，再交给HiFi-GAN之类的声码器。问题在于两段分开训练，声码器在真实梅尔谱上训练、推理时却拿到预测的梅尔谱，二者有差距，所以常要用第一段的预测结果再微调声码器，训练和部署都麻烦；梅尔谱这个人为规定的中间表示也未必最好。已有的端到端方案（如FastSpeech 2s）音质又不如两段式。另一个老问题是“一对多”：同一句话可以用不同的语速、音高说出来，确定性的时长预测器只能给出一种平均的节奏。

方法

条件VAE框架（见变分推断与ELBO、潜空间）。训练时，后验编码器读入真实语音的线性频谱，输出潜变量z的分布；解码器把z直接变成波形；先验编码器根据文本给出z应服从的分布。目标是最大化ELBO：重建项（生成波形的梅尔谱与真实梅尔谱的L1距离）减去后验与先验之间的KL散度（见KL散度）。

先验加标准化流。文本编码器输出每个音素对应的高斯分布，但简单高斯太“死板”。于是在后验的z和先验高斯之间插入一个可逆的标准化流（见可逆流与流匹配），让先验能表达复杂分布。消融显示去掉这个流，MOS从4.50暴跌到2.98。

对齐。文本与语音帧之间的对应关系不给标签，用Glow-TTS的单调对齐搜索：用动态规划找出使似然最大的单调对齐路径，每个音素对应连续若干帧。

随机时长预测器。它也是一个流模型，学习时长的分布而不是单个值，推理时采样，同一句话每次可以读出不同节奏。

对抗训练。解码器就是HiFi-GAN V1的生成器，判别器用HiFi-GAN的多周期判别器，再加特征匹配损失。总损失L = L_recon + L_kl + L_dur + L_adv + L_fm。

推理。后验编码器和判别器只在训练时用；推理时文本→先验分布→采样→反向流→按时长展开→解码器出波形，全程并行。

结果

LJSpeech（单人、22kHz）MOS：真人4.46；VITS 4.43；改用确定性时长预测器的VITS 4.39；Glow-TTS+HiFi-GAN（微调后）4.32；Tacotron 2+HiFi-GAN（微调后）4.25。多说话人VCTK上VITS为4.38，与真人4.38相同，Glow-TTS+HiFi-GAN为3.82。单块V100上VITS每秒生成约148万个采样点，比实时快67.12倍，Glow-TTS+HiFi-GAN为27.48倍。消融：后验输入从线性谱换成梅尔谱MOS下降0.19。

后来的发展

VITS发布代码后成为开源社区最常用的TTS架构之一：YourTTS在它之上加说话人编码器做零样本多语言声音克隆，NaturalSpeech在其框架上加入预训练和可微时长，在LJSpeech上宣称与真人录音无统计显著差异。2023年后零样本TTS转向VALL-E这类编解码器语言模型和Voicebox这类流匹配模型，但VITS因快而小仍常用于端侧。

  • 使用
    变分自编码器VAE2013.12 · 生成
    整体是条件变分自编码器，以ELBO为训练目标，文本作为先验的条件。
  • 使用
    WaveNet2016.09 · 语音
    后验编码器和流中的耦合层使用非因果WaveNet残差块。
  • 改进
    Tacotron 22017.12 · 语音
    解决两段式管线中声学模型与声码器失配、需微调声码器的问题，单阶段训练且MOS更高。
  • 改进
    FastSpeech2019.05 · 语音
    只预测时长，对音高、能量等韵律变化没有显式建模，一对多问题只靠蒸馏缓解，合成语气偏平。
  • 使用
    HiFi-GAN2020.10 · 语音
    解码器就是HiFi-GAN V1生成器，判别器用HiFi-GAN的多周期判别器。
  • 改进
    MelGAN2019.10 · 语音
    只做声码器，仍需要前面的模型先生成梅尔频谱。
  • 改进
    Glow-TTS2020.05 · 语音
    沿用Glow-TTS的单调对齐搜索和流模型先验，但把输出从梅尔谱改为直接生成波形。
  • 改进
    FastPitch2020.06 · 语音
    训练需要外部对齐（来自预训练的Tacotron 2）来提供时长标签，流程依赖另一个模型。
  • 改进
    FastSpeech 22020.06 · 语音
    FastSpeech 2s等早期一段式模型音质不如两段式；VITS用流先验加对抗训练首次让一段式超过两段式。

本篇术语

  • 单调对齐搜索（MAS）　假设文本和语音的对应关系只能从左往右推进、不能回头，用动态规划在所有这样的对齐里找出使模型似然最大的一条，从而免去外部对齐工具。
  • 随机时长预测器　不是给每个音素预测一个固定帧数，而是学习时长的概率分布，生成时从中采样，使同一句话可以有不同的节奏。
