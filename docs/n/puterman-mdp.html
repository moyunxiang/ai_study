Puterman《马尔可夫决策过程》

Markov Decision Processes: Discrete Stochastic Dynamic Programming
1994.04思想延伸Wiley 1994Martin L. Puterman · 不列颠哥伦比亚大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

从动态规划与Bellman方程的动态规划和Howard策略迭代起，马尔可夫决策过程的理论在运筹学里发展了三十多年，结果分散在各种期刊和专著中：有限时域、折扣、平均回报各有一套结论，算法的收敛条件也不统一。

方法

Puterman用一本书把离散时间、离散状态MDP的理论和算法系统整理起来：最优性方程、策略的分类、值迭代、策略迭代、修正策略迭代、线性规划解法，以及折扣与平均回报两种准则下的完整结论。

影响

这本书成了MDP理论的标准参考，RL论文中关于贝尔曼算子收缩性、策略迭代收敛、平均回报MDP的结论大都引用它；它的记号和定理编号在强化学习理论文献里被长期沿用。

方法

全书围绕几种优化准则展开。

有限时域：用逆向归纳从最后一步往前算，最优策略可以是依时间变化的确定性策略。

无限时域折扣准则：价值满足最优性方程 V*(s) = max_a [r(s,a) + γ Σ_s' p(s'|s,a) V*(s')]。书中证明右边的贝尔曼最优算子T在上确界范数下是一个γ-收缩：‖TV − TU‖_∞ ≤ γ‖V − U‖_∞，于是不动点唯一、值迭代从任何初值出发都以几何速度收敛，并给出何时可以停止并保证ε-最优的界。策略迭代则在有限步内终止。书中还讨论了把两者折中的修正策略迭代（每次策略评估只做有限步迭代），以及用线性规划求解MDP：以V为变量、在约束 V(s) ≥ r(s,a) + γΣp V(s') 下最小化 Σ_s α(s)V(s)，其对偶变量正是状态-动作的占用度量。

平均回报准则：在单链、多链等不同结构下，讨论增益（长期平均回报）与偏差函数的方程、相应的值迭代和策略迭代，以及更敏感的最优性准则。

此外还涵盖策略类别（马尔可夫、历史依赖、随机与确定性）之间的关系，以及最优策略存在性的条件。

读懂它需要的概念

马尔可夫决策过程 Bellman方程 动态规划 马尔可夫性与马尔可夫链 拉格朗日乘子、约束优化与对偶

本篇术语

  • 收缩映射　把任意两点的距离至少缩小为原来γ倍的映射；它有唯一不动点，反复作用必然收敛到这个点。
  • 修正策略迭代　介于值迭代与策略迭代之间：每次策略评估不解到底，只做若干步迭代就去改进策略。
  • 平均回报准则　以长期每步平均奖励而不是折扣累计奖励作为优化目标。

怎么学

先学Bellman方程；读本书第6章折扣MDP（收缩性、值迭代、策略迭代、线性规划）；自己用numpy写值迭代并验证误差按γ^k几何下降。
