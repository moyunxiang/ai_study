Berkeley句法分析器

Learning Accurate, Compact, and Interpretable Tree Annotation
2006.07论文延伸COLING-ACL 2006Slav Petrov, Leon Barrett, Romain Thibaux, Dan Klein · UC Berkeley待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

非词汇化句法分析靠人工发现标注来细分语法符号，费时而且不一定最优。

方法

让机器自动学习细分：把每个语法符号拆成若干隐子类，用EM算法训练，再把作用不大的子类合并回去，反复分裂与合并。

影响

在不使用词汇化的前提下达到当时领先的句法分析精度，同时模型紧凑，学到的子类还能被语言学家解释。

方法

出发点是Penn Treebank读出的朴素文法。每一轮先把每个符号一分为二（例如NP拆成NP-1和NP-2），子类是隐变量，用EM算法在树库上估计每个子类的规则概率；EM会让两个子类自动分化，比如一个倾向主语、一个倾向宾语。

然后做合并：检查每次分裂带来的似然提升，把提升很小的分裂撤销，让模型只保留真正有用的细分。分裂、EM、合并交替进行多轮，符号数量因此是按数据需要自动增长的，而不是人工决定。

解析用CKY句法分析算法的动态规划，并用由粗到细的剪枝加速。论文还展示了学到的子类对应什么，比如把代词、冠词等细分出的类别。

局限与后续

  • EM只保证局部最优，每次训练结果依赖初始化；细分后的文法解析仍较慢，需要剪枝。

  • 仍是上下文无关文法，看不到长距离词语信息。
    后来针对它的工作　句法分析即翻译

读懂它需要的概念

EM算法 隐变量模型 动态规划

本篇术语

  • 隐子类　把一个语法符号拆成若干看不见的子类别，子类具体含义由EM在数据中自动形成。

怎么学

先学EM算法；读原文分裂与合并两节；用一个小玩具文法手动分裂一个符号体验EM如何让两个子类分化。
