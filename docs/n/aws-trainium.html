AWS Inferentia与Trainium

2018.11硬件延伸Amazon Web Services · Annapurna Labs待核对
维基百科：AWS Inferentia ↗在交互版中打开（演化树、学习进度）

问题

云厂商每年要为GPU付给NVIDIA高额费用，想用自研芯片降低推理和训练成本。

方法

AWS通过收购的Annapurna Labs设计自研加速器：2018年底宣布Inferentia做推理，随后推出Trainium做训练。

影响

Trainium一代代演进到支撑Anthropic的Project Rainier，是云厂商自研AI芯片里最大规模的部署之一。

方法

维基百科只说明Inferentia和Trainium是Annapurna的两个机器学习ASIC品牌，目前已有三代Trainium在售；Trainium2驱动运行Claude模型的Project Rainier（见Project Rainier：50万Trainium2），Trainium4的细节在AWS re:Invent 2025上公布。页面没有给出Inferentia的发布日期，AWS在2018年11月re:Invent宣布Inferentia一事来自记忆，未核对。

AWS的做法是把芯片、编译器软件（Neuron）和云实例一起卖：客户不用买芯片，只租实例，从而绕开了与CUDA生态的正面竞争。这也是云厂商自研芯片的共同逻辑（见云厂商自研AI芯片）。

后来的发展

之后Google、微软、Meta等也走同样路线，形成云厂商自研加速器的整体趋势；亚马逊自己的下一代是Trainium3：首颗3nm。

局限与后续

  • 软件栈Neuron需要模型适配，生态不如CUDA，大多靠少数大客户推动。
    后来针对它的工作　Project Rainier：50万Trainium2 Trainium3：首颗3nm
  • 自研芯片的性能和效率数字多为厂商自述，缺少独立评测。
    本站还没有记录针对它的后续工作（不代表没有人解决）
