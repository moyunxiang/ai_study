CRPO约束修正策略优化

CRPO: A New Approach for Safe Reinforcement Learning with Convergence Guarantee
2020.11论文延伸ICML 2021Tengyu Xu, Yingbin Liang, Guanghui Lan · Ohio State / Georgia Tech待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

安全RL问题目标和约束都非凸，主流算法用原始-对偶结构靠更新乘子满足约束，乘子难调且缺少全局最优性的有限时间保证。

方法

不用乘子的“原始”方法：每一步检查约束，若有约束超出就沿降低该代价的方向更新策略，否则沿提高回报的方向更新（约束修正策略优化CRPO）。

影响

给出了第一个带全局最优性保证的原始型安全RL算法的有限时间分析，OmniSafe把它列为原始类方法的代表实现。

方法

CRPO（Constraint-Rectified Policy Optimization）的规则非常直接。每次迭代：

1. 用当前策略的数据估计回报价值 J_R 和各代价 J_(C_i)； 2. 若所有约束都满足（留有容差η）：J_(C_i) ≤ d_i + η，就做一步改进回报的策略更新； 3. 否则，任选一个超出的约束i，做一步降低 J_(C_i) 的策略更新。

每一步可以用任意策略优化方法（策略梯度、自然策略梯度、TRPO、PPO）。没有拉格朗日乘子，也不需要调乘子的学习率。

理论上，作者在表格softmax策略、每步用自然策略梯度的设定下证明：CRPO以 O(1/√T) 的速率收敛到约束策略集合内的全局最优策略，约束违反的误差也是 O(1/√T)。摘要称这是原始型安全RL算法第一个带全局最优性保证的有限时间分析。实验中CRPO明显优于原始-对偶基线。

局限与后续

  • 全局最优性的证明依赖表格或线性函数近似加自然策略梯度的设定，在深度网络下没有保证。
