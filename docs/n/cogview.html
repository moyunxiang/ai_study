CogView

CogView: Mastering Text-to-Image Generation via Transformers
2021.05论文延伸NeurIPS 2021Ding, Yang, Hong, Zheng, Zhou, Yin, Lin, Zou et al. · 清华大学 / 阿里达摩院 / 智源待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文生图要同时有强大的生成模型和跨模态理解；2021年初DALL·E已证明自回归Transformer可行，但它是闭源的，且大模型训练常出现NaN损失。

方法

用VQ-VAE把图像压成离散token，和文字token拼成一条序列，用一个40亿参数的Transformer按顺序预测，并给出稳定大模型训练的办法。

影响

成为第一个可公开复现的DALL·E类中文社区模型，开启了清华智谱的CogView/CogVideo系列，并证明同一个预训练模型可微调成风格迁移、超分、图文排序等下游任务。

方法

做法与DALL·E同属一类：先用VQ-VAE式的分词器把一张图变成一串离散编号（见向量量化与离散token），再把文字token放在前面、图像token放在后面，交给一个单向Transformer，像语言模型一样逐个预测下一个token（见自回归生成）。生成时给定文字，一个一个采样图像token，最后由解码器还原成像素。

模型有40亿参数。论文花了不少篇幅讲怎样让这么大的模型在半精度下稳定训练、避免出现NaN损失；并展示了微调出的几种下游用途：学习某种画风、超分辨率、给图文对重新排序打分、时装设计。在模糊化的MS COCO上，其FID优于此前基于GAN的模型，也优于同期的DALL·E。
