时延神经网络TDNN

Phoneme Recognition Using Time-Delay Neural Networks
1989.03论文重要IEEE Trans. ASSP 37(3), 1989Alexander Waibel, Toshiyuki Hanazawa, Geoffrey Hinton, Kiyohiro Shikano, Kevin J. Lang · ATR口译电话研究所 / 卡内基梅隆大学 / 多伦多大学待核对
论文（IEEE） ↗Wikipedia：Time delay neural network ↗在交互版中打开（演化树、学习进度）

问题

音素在语音里没有清楚的起止点，同一个辅音提前或推后几十毫秒出现都可能。普通神经网络把整段输入当成固定位置的向量，信号一平移就认不出来。

方法

让同一组权重沿时间轴滑动，每个单元只看几帧的局部窗口，逐层扩大视野，最后把各时刻的证据加起来——也就是今天说的一维卷积网络，用反向传播端到端训练。

影响

在浊塞音/b,d,g/识别上把错误率从最好HMM的6.3%降到1.5%，第一次让神经网络在语音任务上明显胜过HMM，并开启了此后的混合NN/HMM路线；其结构至今仍用于声学模型和说话人嵌入。

背景

1980年代后期，识别器的主力是HMM统计语音识别：每帧特征由高斯或离散分布打分，各帧之间只靠状态转移联系。HMM的状态分布是“逐帧独立”的，看不到相邻几帧的变化模式，而辨认/b/、/d/、/g/这类塞音恰恰要靠辅音释放后几十毫秒里共振峰怎样移动。

反向传播刚让多层网络可以训练，但直接用多层感知机有个麻烦：输入的每个位置都有自己的权重，同一个特征出现在第3帧和第5帧，对网络来说是两件不相干的事。人工把每个音精确对齐到同一位置又几乎做不到。

方法

输入。语音以12kHz采样，每5毫秒做一次FFT，在梅尔刻度的16个频带上取对数能量（相当于MFCC特征做余弦变换之前的那一步），相邻两帧平滑成每10毫秒一帧，再缩放到−1到+1之间。每个样本截取元音起始点前后共15帧（150毫秒），形状是16×15。

第一层。8个单元，每个单元的权重覆盖3帧×16个频带，并在15帧上逐帧滑动，输出8×13。滑动时权重完全相同——这就是“时延”的含义，用今天的话说是一维卷积层、池化与感受野，卷积核大小为3。

第二层。3个单元，每个看第一层的5帧×8个通道，输出3×9。到这一层，每个单元的视野已经扩大到7帧。

输出层。对应/b/、/d/、/g/三类，每一类把第二层对应单元在9个时刻的输出累加起来，作为这一类的得分。求和意味着不管证据出现在哪一时刻，都能贡献给分类，于是网络对平移不敏感。

整个网络用反向传播训练，权重共享在反传时表现为：同一个卷积核在各时刻得到的梯度相加后一起更新。

结果

任务是特定说话人的/b/、/d/、/g/识别，这三个音出现在多种不同的语音上下文里。在三位说话人共1946个测试样本上，TDNN识别率98.5%，作为对比训练的几种离散HMM中最好的为93.7%（据论文摘要）。

后来的发展

TDNN与同年卷积网络识别邮编的手写数字卷积网络各自独立地把“局部连接+权重共享”用于不同信号，两者是卷积网络的两条源头。随后Waibel等人把TDNN扩展到更多音素和孤立词，混合NN/HMM则把类似的网络当作HMM的状态打分器，解决了TDNN只能分类固定片段的问题。

2010年代TDNN在新的算力下复活：Kaldi中的TDNN声学模型用跨帧采样扩大上下文，无词图MMI链式模型的链式模型、x-vector说话人嵌入和ECAPA-TDNN说话人嵌入都以TDNN为主干。

容易误解的地方

  • “时延”不是指网络会延迟输出，而是指把当前帧和若干帧之前的输入一起送进同一个单元；等价于沿时间方向的卷积。
  • 原论文只是在手工截好的150毫秒片段上做三分类，不是连续语音识别系统。

局限与后续

  • 只能对人工截好、以元音起点为中心的固定长度片段做分类，不能直接处理连续语音中音素的切分和整句识别。
    后来针对它的工作　混合NN/HMM CTC
  • 实验只覆盖3个塞音、特定说话人，扩大到全部音素和说话人无关时网络规模和训练时间在当时的计算机上很难承受。
    后来针对它的工作　DBN音素识别 CD-DNN-HMM
  • 视野只有约150毫秒，更长的上下文要靠加层或加宽窗口，参数随之增长。
    后来针对它的工作　无词图MMI链式模型 大规模LSTM声学模型

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    整个网络用误差反向传播训练，共享权重的梯度在各时刻求和。
  • 竞争
    HMM统计语音识别1976 · 语音
    论文专门训练了离散HMM作对照；TDNN的识别率98.5%高于最好HMM的93.7%，但HMM仍负责连续语音的时间对齐，两者后来在混合系统中合流。
  • 延续
    Neocognitron1980 · 视觉
    沿用局部感受野逐层组合、对位置平移不敏感的思想，并改为用反向传播在时间轴上学习。
  • 使用
    MFCC特征1980.08 · 语音
    输入是16个梅尔频带的对数能量，即MFCC流程中做余弦变换之前的特征。
  • 竞争
    卷积网络识别邮编1989 · 视觉
    同年独立提出的权重共享网络，一个沿时间轴处理语音，一个在二维平面上处理图像，共同构成卷积网络的起点。
  • 改进
    Rabiner的HMM教程1989 · 语音
    HMM假设观测在给定状态时相互独立，状态持续时间服从几何分布，这些假设与真实语音不符。

后来的相关工作

  • 延续
    LeNet与卷积网络1998 · 视觉 已核对
    论文把TDNN描述为只沿时间一维共享权重的卷积网络，用于音素和语音识别；LeNet在二维图像上使用同样的权重共享，并把可扫描整行文字的网络用于序列识别。
  • 竞争
    卷积网络识别邮编1989 · 视觉
    同年把权重共享用在语音的时间轴上；两者是同一思想在一维和二维上的平行实践，后来都归入卷积网络。
  • 竞争
    Elman循环网络1990 · 基础
    时延网络用固定宽度的时间窗口把时间摊成空间；Elman网络用循环隐状态隐式表示任意长的历史，后者成为序列建模的主流。
  • 改进
    混合NN/HMM1994 · 语音
    TDNN只能给截好的固定片段分类；接入HMM后，网络逐帧打分、由HMM完成对齐，神经网络第一次能用于连续语音识别。
  • 竞争
    梯度消失问题1994 · 基础
    论文指出时延网络等静态网络只有有限的记忆窗口，无法无限期保存一个比特，这正是要用循环网络的理由，也是它的训练难点。
  • 竞争
    LSTM遗忘门1999.09 · 基础
    TDNN等时延网络要预先知道典型的时间间隔；遗忘门在不需要这种先验的前提下解决了重置问题。
  • 改进

读懂它需要的概念

卷积层、池化与感受野 反向传播 多层感知机 波形、频谱与梅尔谱 音素、声学模型与语言模型的分工

本篇术语

  • 平移不变性　输入整体在时间上前后移动一点，模型的判断不变。TDNN靠权重共享加最后的时间求和获得这一性质。
  • 浊塞音 /b,d,g/　发音时先完全阻塞气流、再突然释放且声带振动的辅音。三者差别主要在释放后几十毫秒内共振峰的走向，很难区分。

怎么学

先补卷积层、池化与感受野和反向传播。读原论文第二节的网络图，对照Wikipedia条目里的张量形状（16×15 → 8×13 → 3×9 → 3）走一遍。动手：用PyTorch的Conv1d搭出同样的三层网络，在任意一个小型语音命令数据集上截取短片段训练，比较有无时间求和层时对输入平移的敏感程度。
