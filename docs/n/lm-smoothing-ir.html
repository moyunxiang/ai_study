检索语言模型的平滑

A Study of Smoothing Methods for Language Models Applied to Ad Hoc Information Retrieval
2001.09论文重要SIGIR 2001ChengXiang Zhai（翟成祥）, John Lafferty · 卡内基梅隆大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

语言模型检索要为每篇文档估一个词分布，再算查询在其中出现的概率；可查询词只要有一个没在文档里出现，概率就是0，平滑方法怎么选、参数怎么设，对检索效果影响多大，没人系统研究过。

方法

在多个TREC测试集上系统比较Jelinek-Mercer插值、Dirichlet先验和绝对折扣三种平滑方法及其参数敏感性，并从公式上说明平滑同时起到了类似IDF和文档长度归一化的作用。

影响

发现检索效果对平滑极其敏感，Dirichlet先验平滑在短查询上通常最好，从此成为查询似然模型的默认设置（Indri、Lucene等系统都实现了它）；也解释了语言模型方法为何能和TF-IDF、BM25同样有效。

背景

语言模型检索（查询似然）（Ponte与Croft，1998）提出用语言模型做检索：把每篇文档d看成一个词分布 p(w|d)，按查询q在其中出现的概率 p(q|d) = Π_{w∈q} p(w|d) 给文档排序。最简单的估计是极大似然 p_ml(w|d) = c(w;d)/|d|，但它给没出现的词概率0。语音识别里的n-gram平滑早已有成熟的平滑技术，可检索场景下哪种平滑合适、参数取多少，此前只有零散经验。

方法

论文比较三种把文档模型与整个语料库的「背景模型」p(w|C) 混合的方法：

  • Jelinek-Mercer（线性插值）：p(w|d) = (1−λ) p_ml(w|d) + λ p(w|C)，λ固定；
  • Dirichlet先验：p(w|d) = ( c(w;d) + μ p(w|C) ) / ( |d| + μ )，相当于先往文档里加μ个按背景分布撒的「伪词」，文档越长平滑越少；
  • 绝对折扣：从每个出现过的词的计数中减去常数δ，把省下的概率按背景分布分给其他词。

作者还给出一个通用改写：对任何这类平滑，log p(q|d) = Σ_{w∈q, c(w;d)>0} log[ p_s(w|d) / (α_d p(w|C)) ] + |q| log α_d + Σ_{w∈q} log p(w|C)，其中最后一项与文档无关。第一项里除以 p(w|C) 让常见词贡献变小——这就是IDF的作用；α_d 与文档长度有关，起到长度归一化的作用。于是语言模型方法里的「TF-IDF加长度归一化」是平滑自然推出的，而不是另外加的启发式规则。

结果

在多个TREC集合上的实验显示：检索效果对平滑参数非常敏感；Dirichlet先验在标题型短查询上通常最好，Jelinek-Mercer在冗长查询上更有优势；作者观察到平滑在长查询和短查询上扮演的角色不同，这引出了他们2002年的「两阶段平滑」。

后来的发展

Dirichlet平滑的查询似然成为语言模型检索的标准基线，与BM25并列出现在几乎所有传统检索实验中；Lemur/Indri工具包把它作为默认模型。翟成祥后来与Lafferty提出基于KL散度的检索框架和两阶段平滑，相关模型RM等查询扩展方法也建立在平滑后的文档模型之上。

读懂它需要的概念

语言模型 最大似然估计 先验、后验与贝叶斯推断 随机变量与概率分布 n-gram与平滑

本篇术语

  • 背景模型　整个语料库的词频分布p(w|C)，平滑时用它给文档里没出现的词分配概率。
  • Dirichlet先验平滑　相当于往每篇文档里加入μ个按背景分布出现的伪词，再做极大似然估计。
  • Jelinek-Mercer平滑　用固定权重λ把文档的极大似然分布和背景分布线性混合。

怎么学

先读语言模型检索（查询似然） → 读原文第2–3节三种平滑方法和第4节的推导 → 动手：用Pyserini在一个小TREC集合上分别跑Dirichlet和JM平滑，画出MAP随μ或λ变化的曲线。
