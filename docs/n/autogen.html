多智能体框架AutoGen

AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation
2023.08论文延伸COLM 2024Qingyun Wu, Gagan Bansal, Jieyu Zhang, Yiran Wu, Beibin Li, Erkang Zhu, Li Jiang, Xiaoyun Zhang 等 · Microsoft Research / Penn State / UW待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

开发者想让多个LLM智能体、工具和人一起干活，每个应用都得从头手写调度逻辑，很难复用。

方法

提出开源框架：智能体都是“可对话”的，应用就是让它们互相发消息，对话模式既可用自然语言也可用代码编程。

影响

成为最常用的多智能体开发框架之一，“多智能体会话”成为一种通用编程抽象。

方法

AutoGen的基本单位是可对话智能体：每个智能体能收发消息，背后可以是LLM、工具（比如执行代码）或真人，三者可以组合。开发者通过对话编程定义行为：谁先说、什么时候转给谁、何时终止，既可以用自然语言写提示，也可以用代码写控制逻辑，从而搭出两人对话、群聊、层级式协作等不同模式。

论文用数学、编程、问答、运筹优化、在线决策、娱乐等应用展示这套抽象的通用性。它与MetaGPT、ChatDev的差别在于：后两者是针对软件开发写死的流程，AutoGen提供的是通用底层框架，后来LangGraph图式编排等从“图”的角度做了另一种编排。

局限与后续

  • 多智能体对话的流程难以预测和调试，容易陷入循环或偏题。

  • 框架本身不保证结果正确，仍然依赖底层模型的可靠性和代码执行的沙箱安全。
