VITA-Audio低延迟语音大模型

VITA-Audio: Fast Interleaved Cross-Modal Token Generation for Efficient Large Speech-Language Model
2025.05论文延伸Zuwei Long, Yunhang Shen, Chaoyou Fu, Heting Gao, Lijiang Li, Peixian Chen, Mengdan Zhang, Hang Shao et al. · 腾讯优图、南京大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

端到端语音大模型在流式对话时，生成第一个音频token要等很久：模型通常先吐出一段文字，再逐个生成音频token，首包延迟成了部署瓶颈。

方法

在大模型上加轻量的多跨模态token预测（MCTP）模块，一次前向就能产出多个音频token，并用四阶段渐进训练在提速的同时尽量不损失音质。

影响

官方称它是第一个在第一次前向就能输出音频的多模态大模型；7B规模推理提速3–5倍，且全部用开源数据训练、可复现，为降低语音对话首包延迟提供了一种做法。

方法

Mini-Omni、LLaMA-Omni、GLM-4-Voice这类端到端语音对话模型让一个LLM同时产生文字和音频token。为了让声音和内容对得上，常见做法是文字先行、音频token随后交错生成。但LLM每次前向只出一个token，而一秒语音需要几十个音频token，所以要等很多步才能播放第一段声音。

VITA-Audio的核心是MCTP（Multiple Cross-modal Token Prediction）模块：在主干LLM的隐藏状态后面接几个轻量预测头，每个头根据主干输出和前一个头的结果预测下一个音频token，于是一次前向就能得到多个音频token。思路类似文本里的多token预测MTP，但这里预测的是跨模态的音频token：文本token已经决定了要说什么，音频token主要是把它「读出来」，局部依赖较强，适合用轻量模块补齐。

训练分四个阶段逐步加入MCTP模块，以尽量少损失语音质量换取加速。摘要报告：7B规模推理提速3–5倍，在ASR、TTS和语音问答多个基准上明显优于同规模开源模型。

局限与后续

  • 仍是半双工的轮流对话，不能边听边说、处理打断。
