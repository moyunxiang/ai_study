VQAScore与GenAI-Bench

Evaluating Text-to-Visual Generation with Image-to-Text Generation
2024.04论文延伸ECCV 2024Zhiqiu Lin, Deepak Pathak, Baiqi Li, Jiayao Li, Xide Xia, Graham Neubig, Pengchuan Zhang, Deva Ramanan · 卡内基梅隆大学 / Meta待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

文生图、文生视频的评测普遍用CLIPScore衡量图文是否相符，但它像“词袋”一样分不清“马在吃草”和“草在吃马”，对涉及物体、属性、关系组合的复杂提示打分不可靠。

方法

用视觉问答模型来打分：问它“这张图显示的是‘{提示词}’吗？”，取回答“是”的概率作为图文一致性分数；同时发布了组合式提示的评测集GenAI-Bench。

影响

VQAScore成为文生图对齐评测的主流指标之一，GenAI-Bench也被用于比较主流文生图和文生视频模型，并被不少后续评测和奖励模型工作采用。

方法

打分方式。给一个视觉问答模型输入生成的图像和问题“Does this figure show '{text}'? Please answer yes or no.”，模型输出“Yes”这个词的概率就是VQAScore。它比此前先把提示拆成多个小问题再逐个问的方法（如TIFA、DSG）简单得多，只需一次问答。

CLIP-FlanT5。作者还按文献中的最佳做法训练了自己的模型：用双向的图像-问题编码器，使图像表示能随所问的问题而变化，再接FlanT5语言模型输出答案。

结果。摘要称，即使只用现成模型，VQAScore也在8个图文对齐基准上取得了最好结果；用自家的CLIP-FlanT5计算，甚至超过使用GPT-4V的最强基线。

GenAI-Bench。作者收集了1,600条组合式文本提示，涵盖计数、比较、否定、空间关系等，并收集了对多个文生图和文生视频模型输出的人工评分。

局限与后续

  • 分数依赖所用问答模型自身的视觉理解能力和偏差；只衡量图文是否相符，不衡量图像美观度和真实感。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    GPT-4V2023.09 · 多模态
    以GPT-4V为基础的评测方法是被比较的最强基线。
  • 改进
    CLIPScore图文一致性2021.04 · 数据·评测
    CLIPScore对物体关系和属性组合不敏感，VQAScore用问答模型更好地处理组合式提示。
  • 竞争
    T2I-CompBench2023.07 · 数据·评测
    T2I-CompBench为不同组合类别设计不同的检测器打分，VQAScore用一个统一的问答概率打分。
  • 竞争
    GenEval2023.10 · 数据·评测
    GenEval用目标检测核查物体、数量和位置，VQAScore用视觉问答模型直接判断整体是否相符。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
