端到端测试时训练TTT-E2E

End-to-End Test-Time Training for Long Context
2025.12论文延伸Arnuv Tandon, Karan Dalal, Xinhao Li, Daniel Koceja, Marcel Rød, Sam Buchanan, Xiaolong Wang, Yu Sun et al. · Stanford / Astera Institute / NVIDIA / UC Berkeley / UC San Diego待核对
arXiv ↗arXiv HTML全文 ↗在交互版中打开（演化树、学习进度）

问题

全注意力处理长上下文时每个token的计算随长度增长；Mamba 2、Gated DeltaNet等线性循环模型延迟恒定，但随上下文变长效果跟不上全注意力。

方法

不改架构：用滑动窗口注意力的标准Transformer，测试时在读到的上下文上继续做下一个token预测训练，把上下文压进权重；训练时用元学习优化这种测试时学习的初始化。

影响

把长上下文建模重新表述为持续学习问题，是测试时训练从“专门的层”走向“整个模型”的代表工作。

方法

此前的测试时训练层TTT把测试时训练做成一种新的序列层，内部用自监督重建目标。TTT-E2E换了思路：模型就是带8K滑动窗口注意力的普通Transformer，窗口之外的信息不靠注意力，而是靠测试时学习——每读1K个token，就用下一个token预测损失对模型做一次梯度更新，只更新最后四分之一层的MLP，嵌入、归一化和注意力层冻结，被更新的块再加一个不动的MLP保存预训练知识。

训练阶段把每条序列都当作测试序列：内循环做上述测试时训练，外循环对“测试时训练之后”的损失求梯度来优化初始权重，也就是MAML元学习式的二阶梯度。作者称它在测试时和训练时两端都是端到端的。

摘要报告：3B模型、164B训练token下，TTT-E2E的损失随上下文长度的变化与全注意力一致，而Mamba-2与状态空间对偶和Gated DeltaNet做不到；推理延迟像RNN一样与上下文长度无关，在128K上下文时比全注意力快2.7倍。

  • 在RULER单针检索（大海捞针）任务上远不如全注意力，压缩会丢掉看似无关的细节。

  • 需要梯度的梯度，现有FlashAttention实现不支持，8K上下文训练比全注意力慢3.4倍。

  • 实验在中小规模，解码评估有限，小模型在更长上下文上微调不稳定。

它建立在什么之上

  • 使用
    MAML元学习2017.03 · 基础
    训练时用MAML式外循环，对测试时训练之后的损失求二阶梯度来学初始化。
  • 竞争
    Gated DeltaNet2024.12 · 基础
    同样追求恒定推理延迟；论文报告Gated DeltaNet与Mamba 2随上下文变长不能像全注意力那样持续降低损失，TTT-E2E可以。
  • 竞争
    Mamba-2与状态空间对偶2024.05 · 基础
    作为线性循环基线被比较，长上下文扩展性不及TTT-E2E。
  • 延续
    测试时训练层TTT2024.07 · 基础
    同一作者线；TTT层只在一层内部做测试时学习，TTT-E2E让整个模型在测试时用语言建模损失持续学习。
  • 竞争
    Titans测试时记忆2024.12 · 基础
    Titans加一个在测试时更新的神经记忆模块；TTT-E2E不加新模块，直接更新标准Transformer的部分MLP。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

怎么学

先读测试时训练层TTT和元学习；读论文第2节方法与第3节缩放实验；用一个小Transformer在长文本上实现内循环“读1K token、更新一次MLP”，观察窗口外信息是否被记住。
