LoCoMo超长对话记忆

Evaluating Very Long-Term Conversational Memory of LLM Agents
2024.02数据集延伸ACL 2024Adyasha Maharana, Dong-Ho Lee, Sergey Tulyakov, Mohit Bansal, Francesco Barbieri, Yuwei Fang · 北卡罗来纳大学教堂山分校 / Snap待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

长期对话研究里的测试最多只跨五次聊天，长上下文模型和检索增强能否记住几十次会话、几百轮里的事情，没有被检验过。

方法

让两个基于大模型、带人设和时间事件图的智能体相互聊天生成超长对话，再由人工校对一致性，在此基础上出记忆问答、事件摘要和多模态回复题。

影响

成为智能体长期记忆研究的标准评测，MemGPT之后的A-MEM、Mem0、Zep等记忆系统几乎都在LoCoMo上报告结果。

方法

数据生成。每个虚拟人物有一段人设和一张随时间展开的事件图（例如某月换工作、某月养了狗）。两个由大模型驱动的智能体按照各自的事件图分多次会话聊天，还能分享和回应图片。生成的对话再由人工标注员检查和编辑，保证长距离前后一致、与事件图相符。

规模。每段对话平均约300轮、9千词元，最多跨35次会话。

三类评测任务。问答：分单跳、多跳、时间推理、开放域常识和对抗（无答案）等类型，问的是很早以前聊过的细节；事件摘要：按时间总结人物经历；多模态对话生成：根据历史接着聊并分享合适的图片。

结果。摘要称，大模型在理解超长对话、把握长距离的时间和因果关系上有困难；使用长上下文模型或检索增强能有所改善，但仍明显落后于人类。

局限与后续

  • 对话由模型生成、人设虚构，与真实用户长期使用助手的记录不同；问答题量有限，部分标准答案存在争议。
