DeepSDF

DeepSDF: Learning Continuous Signed Distance Functions for Shape Representation
2019.01论文延伸CVPR 2019Park, Florence, Straub, Newcombe, Lovegrove · Facebook Reality Labs / MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统有符号距离函数（SDF）一个模型只表示一个形状，而体素化存储又占内存。

方法

用一个自动解码器网络表示整个类别的SDF：输入3D点和每个形状的隐向量，输出该点到表面的有符号距离。

影响

把隐式神经表示与形状先验结合起来，影响了NeRF等后续隐式场方法。

方法

SDF给空间中每个点一个数：到最近表面的距离，在物体内部为负、外部为正，表面就是零水平集。DeepSDF训练一个多层感知机，输入是点坐标和一个形状隐向量，输出该点的SDF值。每个训练形状有自己的隐向量，与网络权重一起优化，这叫自动解码器（没有单独的编码器，见深度自编码器的对比）。

测试时，给定一个残缺、带噪的观测点，固定网络权重，只优化隐向量，使其SDF预测与观测一致，就能补全形状。论文报告在形状表示和补全上达到当时最好，并且相比此前方法，模型缩小了一个数量级。

局限与后续

  • 每个新形状都要做测试时的优化，速度慢。
    后来针对它的工作　Instant-NGP
  • 需要真值SDF监督，且表示的是一类形状，不处理带纹理的场景。
    后来针对它的工作　NeRF

它建立在什么之上

  • 竞争
    深度自编码器2006 · 基础
    与编码器-解码器式的形状压缩不同，使用只带解码器的隐向量优化。
  • 延续
    KinectFusion2011.10 · 视觉
    KinectFusion在体素网格中存储截断SDF，DeepSDF改用神经网络把SDF连续化并学到形状先验。

后来的相关工作

  • 改进
    NeRF2020.03 · 视觉
    沿用“用MLP把坐标映射成场景属性”的隐式表示，但输出改为密度和颜色，并且只用二维照片监督，不再需要三维真值。
  • 改进
    Instant-NGP2022.01 · 视觉
    同一编码也用于拟合有符号距离场，把DeepSDF式的坐标网络加速到交互速度。
  • 使用
    NeuS神经隐式表面2021.06 · 视觉
    以MLP表示的符号距离函数作为几何表示。
