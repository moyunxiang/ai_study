TOP500超算排行榜

1993.06数据集延伸Hans Meuer, Erich Strohmaier, Jack Dongarra, Horst D. Simon · TOP500项目（曼海姆大学等）待核对
TOP500官网 ↗维基百科 ↗在交互版中打开（演化树、学习进度）

问题

1990年代初超级计算机从向量机转向大规模并行机和工作站集群，按厂商数台数的统计已经说明不了谁的算力强、整个领域在往哪里走。

方法

每年两次，用同一个基准——求解大型稠密线性方程组的LINPACK（HPL）——实测各系统的浮点性能，列出全球最强的500台通用计算机。

影响

三十多年来一直是衡量国家和机构超算实力的公共标尺，记录了从向量机、MPP、集群到GPU加速和E级机的每次转变；它也让“HPL分数能否代表真实应用”成为长期争论。

方法

TOP500官网介绍，Hans Meuer自1986年起就在曼海姆超算研讨会上按厂商统计向量机台数；1993年，随着大规模并行（MPP）系统和高端工作站的兴起，项目组决定改为维护一个全球最强500台计算机的列表，自1993年6月起每年更新两次——6月在国际超算大会（ISC）、11月在美国SC大会上发布。排名依据是各系统在LINPACK基准上的实测性能，提交方需在官方规则下运行，专门为刷榜而设计的系统会被取消资格。

LINPACK测的是解一个巨大稠密线性方程组 Ax = b 的速度，主要考验浮点乘加能力，对内存带宽和网络的要求相对温和。因此后来又出现了测稀疏计算的HPCG和测能效的Green500作为补充。维基百科记载，Frontier：首台E级超算在2022年6月至2024年11月位居榜首，之后由El Capitan接替，到2026年6月中国的LineShine以2198.4 PFlop/s的HPL成绩排名第一。

榜单只收录主动提交的系统：维基百科指出，中国的项目出于保密长期未完整申报；而大型AI训练集群（如xAI Colossus：122天建成10万卡集群）规模已超过榜首超算，却大多不参加排名。

局限与后续

  • HPL只测稠密双精度矩阵运算，与AI训练常用的低精度计算、通信密集型负载差别很大；不申报的AI集群和保密系统也不在榜上，榜单越来越不能代表算力的全貌。

读懂它需要的概念

矩阵乘法与线性变换 浮点精度：FP32、FP16、BF16、INT8 基准、排行榜与SOTA

本篇术语

  • Rmax / Rpeak　Rmax是系统在HPL上实测达到的最高性能，Rpeak是按硬件规格算出的理论峰值，两者之比反映效率。
  • HPL　High-Performance LINPACK，求解大规模稠密线性方程组的并行基准程序，TOP500的排名依据。

怎么学
