LiT锁定图像微调

LiT: Zero-Shot Transfer with Locked-image text Tuning
2021.11论文延伸CVPR 2022Zhai, Wang, Mustafa, Steiner, Keysers, Kolesnikov, Beyer · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

CLIP式的图文对比学习要从头同时训练图像和文字两个塔，贵且图像塔未必比已有的预训练视觉模型好。

方法

锁定（冻结）一个已经预训练好的图像塔，只训练文字塔去读取它的表示，再做对比学习。

影响

表明零样本能力可以在已有视觉预训练模型上低成本获得，成为对比微调的标准配方。

方法

LiT的对比微调有几种解锁方式：图像塔锁定还是不锁，文字塔是否预训练。作者系统比较后发现，锁定预训练图像塔、解锁文字塔效果最好。直观理解：图像塔已经在大量带标签数据上学好了表示，如果在噪声图文对上继续训练反而可能损坏它，所以只需要教文字塔把文字「翻译」到图像塔的空间里。

这种方法适用于不同的预训练方式（有监督、无监督）、不同结构（ResNet、ViT、MLP-Mixer）和三个图文数据集。摘要称用预训练的ViT-g/14作图像塔，LiT模型获得了很强的零样本分类成绩，并节省训练代价。

局限与后续

  • 零样本能力受限于锁定的图像塔，粗粒度表示不一定适配细粒度任务。
