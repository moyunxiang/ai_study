EM算法

Maximum Likelihood from Incomplete Data via the EM Algorithm
1977论文重要Journal of the Royal Statistical Society B 1977Arthur P. Dempster, Nan M. Laird, Donald B. Rubin · Harvard University / Educational Testing Service待核对
DOI ↗Wikipedia: EM algorithm ↗在交互版中打开（演化树、学习进度）

问题

很多模型里有“看不见的”变量（某个点来自哪个簇、某个时刻处在哪个隐状态、缺失的数据），这时似然函数里有对隐变量的求和，最大似然估计没有解析解，直接优化也很麻烦。

方法

交替两步：E步用当前参数算出隐变量的后验分布（“猜”它们是什么）；M步把这些猜测当成已知，求使期望完全数据似然最大的参数。每一轮都保证观测数据的似然不下降。

影响

把散落在各领域的特例统一成一个通用算法，成为训练隐变量模型的标准工具：高斯混合、HMM、统计机器翻译的词对齐、主题模型都用它；它的下界视角后来直接通向变分推断和VAE。

背景

最大似然估计要求找到使数据出现概率最大的参数。如果每个数据都完整观测，比如知道每个点属于哪个高斯分量，这很容易：每个分量各自算均值和方差即可。麻烦在于常常有一部分信息看不见（见隐变量模型）：只看到一堆点，不知道每个点来自哪个分量；只听到声音，不知道每一帧对应哪个音素。这时观测数据的似然是p(x|θ) = Σ_z p(x, z|θ)，对数里面套着求和，求导后各个参数纠缠在一起，没有闭式解。

在此之前，同样的“先猜隐变量、再估参数、反复迭代”思路已经在很多特殊问题里被独立提出：遗传学中估计等位基因频率的基因计数法、Hartley 1958年对分组数据的方法、Sundberg对指数族的详细研究，以及语音和信号领域用于隐马尔可夫模型的Baum-Welch算法。Dempster、Laird和Rubin在1977年的论文中指出，这些都是同一个算法的特例，给它起名EM，并给出一般形式。

方法

两步迭代（见EM算法）。设观测数据为x，隐变量为z，参数为θ。从初始值θ⁽⁰⁾开始重复：

  • E步：用当前参数求隐变量的后验q(z) = p(z | x, θ⁽ᵗ⁾)，并写出期望完全数据对数似然

Q(θ) = E_{z∼q} [ log p(x, z | θ) ]

  • M步：θ⁽ᵗ⁺¹⁾ = argmax_θ Q(θ)

关键在于log p(x, z|θ)里没有对z的求和，M步常常有闭式解。

为什么似然不会下降。对任意分布q，由Jensen不等式有

log p(x|θ) ≥ Σ_z q(z) log [ p(x, z|θ) / q(z) ]

右边是似然的一个下界（即后来所说的变分推断与ELBO），两者之差恰好是KL(q ‖ p(z|x, θ))（见KL散度）。E步取q = p(z|x, θ⁽ᵗ⁾)，使下界在当前点与似然相切；M步把下界往上推。似然先被抬到下界，下界又被提高，所以似然单调不减。

例子：两个一维高斯的混合。数据是一堆身高，混合了两个群体。E步：对每个人，按当前两个高斯的均值、方差和比例，算他属于群体A的概率，比如0.8。M步：群体A的新均值 = 所有人身高按各自“属于A的概率”加权的平均；方差和比例同理。这就是“软分配”的k-means聚类：把0.8换成非0即1的硬分配，并固定方差相同，就得到k-means。

后来的发展

EM成为统计和机器学习中处理隐变量的通用工具。在图上，它是HMM统计语音识别训练声学模型、IBM统计翻译模型学习词对齐、概率潜在语义分析pLSA和LDA主题模型学习主题、混合专家MoE之后的分层混合专家训练门控的基础；高斯混合模型的EM训练也是GMM-UBM说话人确认等说话人识别系统的核心。

更深远的影响来自它的下界视角。当后验p(z|x)算不出来时，可以不要求E步精确，而是在一族简单分布里找最接近的q——这就是变分推断。再进一步，用一个神经网络直接从x预测q，用梯度同时优化下界中的编码器和生成器，就得到了变分自编码器VAE。今天扩散模型训练目标的推导也沿用同一个下界。

容易误解的地方

  • EM只保证似然不下降并收敛到驻点，不保证全局最优，结果依赖初始值，实践中要多次随机初始化。
  • 原论文的收敛性证明有漏洞，正确的收敛性分析由Wu在1983年给出。
  • 高斯混合中，如果某个分量收缩到只覆盖一个点，方差趋于0、似然趋于无穷，这是一个无意义的“最大值”，需要给方差加下限或先验。

局限与后续

  • E步需要精确计算隐变量的后验；对于复杂模型（如隐变量通过神经网络生成数据），后验算不出来，EM无法直接使用。
    后来针对它的工作　变分推断 变分自编码器VAE
  • 只收敛到局部最优，对初值敏感；在最优点附近收敛很慢（线性收敛），可能需要很多轮。

  • 标准形式每轮都要遍历全部数据，难以用于大规模数据和在线学习。

它建立在什么之上

  • 改进
    主成分分析PCA1901 · 基础
    没有概率模型：不能给出数据的似然，不能处理缺失值，也不能用来生成新样本。
  • 延续
    k-means聚类1967 · 基础
    k-means是EM在等方差高斯混合上的硬分配极限；EM把硬分配换成后验概率的软分配，并能学习各簇的方差和比例。
  • 延续
    Baum-Welch算法1970 · 语音
    Baum-Welch是EM用于隐马尔可夫模型的特例，早于1977年；DLR把它和其他特例统一为一个一般算法。
  • 竞争
    Metropolis采样与MCMC1953 · 基础
    处理隐变量的两条路：MCMC用采样近似后验、给出分布，EM用确定性迭代求点估计；后者更快但只得到局部最优。

读懂它需要的概念

最大似然估计 隐变量模型 条件概率与贝叶斯公式 Jensen不等式 KL散度 高斯分布

本篇术语

  • 完全数据似然　假装隐变量也被观测到时的似然p(x, z|θ)。它通常形式简单，M步就是在它的期望上做优化。
  • 软分配　不把一个点硬性归给某一类，而是给它属于每一类的概率，所有概率之和为1。

怎么学

先补最大似然估计、隐变量模型和Jensen不等式。然后从两个一维高斯的混合开始：用numpy生成数据，手写E步和M步，画出每轮的对数似然，确认它单调上升；再把E步的后验改成取最大值的0/1，观察它退化成k-means。理论部分推荐Bishop《PRML》第9章（见《模式识别与机器学习》）。
