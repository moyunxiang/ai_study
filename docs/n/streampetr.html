StreamPETR流式时序检测

Exploring Object-Centric Temporal Modeling for Efficient Multi-View 3D Object Detection
2023.03论文延伸ICCV 2023Shihao Wang, Yingfei Liu, Tiancai Wang, Ying Li, Xiangyu Zhang · 北京理工大学、旷视待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多视角三维检测要利用长时间历史才能看准被遮挡物体和速度，但堆叠多帧特征的代价很高，在线部署跑不动。

方法

以物体查询为中心做时序建模：上一帧的物体查询带着历史信息传到下一帧，逐帧在线传播长时信息，并用运动感知的层归一化建模物体移动。

影响

作者称是第一个在nuScenes上达到与激光雷达方法相当性能（67.6% NDS、65.3% AMOTA）的在线多视角方法，轻量版每秒31.7帧。

方法

PETR三维位置编码检测是单帧检测；BEV路线（如BEVFormer）用时序BEV特征融合历史，但要缓存和对齐整张特征图。StreamPETR只传递稀疏的物体查询：每一帧检测完，把置信度高的查询连同其位置和速度保存下来，作为下一帧的部分查询输入，历史信息就这样随物体逐帧流动；由于物体会动，作者设计了运动感知层归一化，根据自车运动和物体速度调整查询。额外计算几乎可以忽略。在nuScenes上达到67.6% NDS和65.3% AMOTA；轻量版45.0% mAP、每秒31.7帧，比当时最好方法SOLOFusion高2.3% mAP、快1.8倍。

局限与后续

  • 只传递物体查询，未被检出的物体没有历史可用；长时间遮挡后的再出现仍然困难。
