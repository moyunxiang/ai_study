VL-BERT单流预训练

VL-BERT: Pre-training of Generic Visual-Linguistic Representations
2019.08论文延伸ICLR 2020Weijie Su, Xizhou Zhu, Yue Cao, Bin Li, Lewei Lu, Furu Wei, Jifeng Dai · 中国科学技术大学、微软亚洲研究院待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

BERT证明了“先预训练、再微调”对文本很有效，但视觉语言任务仍是每个任务各搭一套模型，缺少一个能通用的图文联合表示。

方法

把句子里的词和图里检测出的区域放进同一个Transformer序列（单流），在Conceptual Captions图文对和纯文本语料上做掩码预测式预训练，再迁移到各种下游任务。

影响

与ViLBERT、LXMERT、VisualBERT同在2019年8月出现，是“BERT式视觉语言预训练”第一批代表作之一，曾拿下VCR榜单单模型第一。

方法

2019年之前，自底向上注意力之后的视觉问答、视觉常识推理（VCR）、指代表达等任务各有专门的模型结构。BERT出现后，大家开始想：能否像文本一样，先在大量图文数据上预训练一个通用模型？

VL-BERT采用单流结构：输入序列里每个元素要么是句子的一个词，要么是图像的一个感兴趣区域（RoI，来自Faster R-CNN检测器）。每个元素的输入嵌入由四部分相加：词或区域的特征嵌入、视觉特征嵌入（区域元素用对应区域的特征，词元素用整图特征）、段嵌入（区分句子和图像）、位置嵌入。整个序列交给标准的多层Transformer，让词与区域在每一层充分互相注意。

预训练任务有两个：随机遮掉一些词，借助图像线索预测它们（带视觉线索的掩码语言模型）；随机遮掉一些区域，预测其类别标签（带语言线索的掩码RoI分类）。预训练数据是约330万对的Conceptual Captions图文对，同时加入纯文本语料以保持语言能力。摘要报告，预训练能更好地对齐视觉和语言线索，在VCR、VQA和指代表达理解上都有收益，并取得VCR榜单单模型第一。

局限与后续

  • 图像只以离线检测器的区域特征进入模型，检测器不参与预训练，推理时也要先跑检测。

  • 预训练任务以掩码预测为主，缺少显式的图文匹配和对齐目标，跨模态对齐效果有提升空间。

它建立在什么之上

  • 延续
    BERT2018.10 · LLM
    把BERT的掩码预训练从纯文本扩展到词与图像区域混合的序列。
  • 使用
    Faster R-CNN2015.06 · 视觉
    用检测器提取图像感兴趣区域及其特征。
  • 使用
    Conceptual Captions2018.07 · 数据·评测
    在Conceptual Captions图文对上预训练。
  • 竞争
    ViLBERT2019.08 · 多模态
    同月发表；ViLBERT是图文两条流再做交叉注意力的双流结构，VL-BERT是单流。
  • 竞争
    VisualBERT2019.08 · 多模态
    同属单流结构，VL-BERT额外加入掩码区域分类和纯文本语料。

  • 改进
    OSCAR2020.04 · 多模态
    预训练任务以掩码预测为主，缺少显式的图文匹配和对齐目标，跨模态对齐效果有提升空间。

读懂它需要的概念

掩码建模 预训练与微调 Transformer层的结构 嵌入向量 分类、检测、分割

本篇术语

  • 单流 / 双流　单流模型把图像和文本拼成一个序列送进同一个Transformer；双流模型先让两种模态各走一条Transformer，再通过交叉注意力交互。
  • VCR（视觉常识推理）　给图像和一个问题，模型要选出答案，还要选出支持该答案的理由，考察对图中情景的常识推断。

怎么学

先读BERT的掩码语言模型，再把VL-BERT和ViLBERT、LXMERT的结构图并排比较，理解单流与双流的区别。
