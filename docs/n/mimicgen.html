MimicGen数据扩增

MimicGen: A Data Generation System for Scalable Robot Learning using Human Demonstrations
2023.10论文延伸Mandlekar, Nasiriany, Wen, Akinola, Narang, Fan, Zhu, Fox · NVIDIA / UT Austin待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模仿学习需要大量人类示范，采集成本高。

方法

把少量人类示范按物体位姿切成片段，在新场景中变换并拼接，由机器人在仿真里重放生成新的成功示范。

影响

用约200条人类示范合成50K多条示范，训练出的策略接近甚至不逊于多收集人类数据。

方法

MimicGen把每条示范分成以某个物体为参照的子任务片段。到了新场景，物体位置变了，系统就把原片段里的末端轨迹按物体新位姿做坐标变换，在两个片段之间插值过渡，让机器人执行；执行成功的才保留。

摘要称，它用约200条人类示范在18个任务上生成了超过5万条示范，涵盖不同场景布置、物体和机械臂，在多件装配、做咖啡等长程高精度任务上训练出有效策略。

后来的发展

为RoboCasa等大规模仿真数据提供了生成管线，也启发了后来的DexMimicGen以及用生成模型扩充数据的方法（如DreamGen / GR00T Dreams）。

局限与后续

  • 需要仿真环境重放并判断成功，难以直接用于真实世界。
    后来针对它的工作　DreamGen / GR00T Dreams
  • 假设任务可分解为以物体为参照的片段，对不能这样分解的任务不适用。
    本站还没有记录针对它的后续工作（不代表没有人解决）

怎么学
