VisionLLM视觉通才

VisionLLM: Large Language Model is also an Open-Ended Decoder for Vision-Centric Tasks
2023.05论文延伸NeurIPS 2023Wenhai Wang, Zhe Chen, Xiaokang Chen, Jiannan Wu, Xizhou Zhu, Gang Zeng, Ping Luo, Jifeng Dai et al. · 上海人工智能实验室 / 清华大学 / 香港大学等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

视觉基础模型只能做预先定义好形式的任务（固定类别的检测、分割），不能像大语言模型那样用一句指令临时定义新任务。

方法

把图像当作一门“外语”，把检测等视觉任务也写成语言指令，让一个基于LLM的解码器按指令输出任务结果（包括框坐标）。

影响

较早证明通用LLM框架也能做细粒度视觉任务，COCO检测超过60 mAP，引出了后续VisionLLM v2等视觉通才模型。

方法

2023年上半年，LLaVA这类多模态大模型能看图聊天，但做不了检测、分割这种要输出精确位置的任务；这些任务仍由DETR、DINO（检测）等专用模型完成，类别和输出格式都是事先定死的。

VisionLLM的思路是统一接口：用户用语言指令描述任务（例如“检测图中所有属于这些类别的物体，按某种格式输出”），一个受语言引导的图像编码器按指令提取图像特征，再由基于LLM的开放式任务解码器把结果写成token序列——坐标也被离散成位置token输出。这样，从“只检测某几类物体”的物体级定制，到“换成另一种任务”的任务级定制，都只需改指令。

摘要报告这个通用框架在COCO上检测超过60% mAP，与检测专用模型相当。它的价值主要在于说明“LLM当视觉任务的通用解码器”可行，后来的视觉通才模型多沿这条路做得更全面。

它建立在什么之上

  • 延续
    LLaVA2023.04 · 多模态
    把LLaVA式“视觉接入LLM”从看图对话推广到检测等需要精确定位的视觉任务。
  • 竞争
    DETR2020.05 · 视觉
    同样做目标检测，DETR用专用的集合预测头，VisionLLM改用LLM按指令生成坐标token。
  • 竞争
    Shikra指代对话2023.06 · 多模态
    同期都让多模态大模型直接输出坐标，Shikra侧重指代对话，VisionLLM侧重统一的视觉任务定义。

读懂它需要的概念

分类、检测、分割 IoU与mAP 语言模型 指令微调与对话模板 分词与token

本篇术语

  • 视觉通才模型　一个模型通过指令就能完成分类、检测、分割、描述等多种视觉任务，而不是每个任务各训一个专用模型。

怎么学

先了解DETR怎样把检测写成集合预测，再读LLaVA；然后读原文方法部分看任务指令和输出格式怎样设计。
