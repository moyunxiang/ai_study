深度元强化学习

Learning to reinforcement learn
2016.11论文延伸Jane X Wang, Zeb Kurth-Nelson, Dhruva Tirumala, Hubert Soyer, Joel Z Leibo, Remi Munos, Charles Blundell, Dharshan Kumaran, Matt Botvinick · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度RL在单个任务上要海量数据，换一个相似的新任务又得从头学；而人和动物面对一类相似问题时，会越学越快。

方法

提出“深度元强化学习”：用一个慢速的RL算法（A3C）在一大族相关任务上训练循环网络，循环网络的输入包含上一步的动作和奖励；训练好后，网络的隐状态动态本身就实现了一个快速的、在任务内部进行的第二套RL算法。

影响

与几乎同时的RL²元强化学习一起奠定了基于记忆（循环网络）的元强化学习路线，并把它与神经科学中前额叶皮层与多巴胺系统的分工联系起来，后续的VariBAD贝叶斯自适应、AdA人类时间尺度适应等都沿用这一“在上下文里学习”的框架。

背景

此前的工作已经表明，循环网络在监督学习里可以做元学习：在许多任务上训练后，它能从少量样本中快速适应新任务。在RL里，A3C等算法让训练循环网络策略变得容易，但每个任务仍是从零开始学。作者关心的问题是：能否让RL本身成为被学习的对象？

方法

设定是一个任务分布（例如奖励概率随机变化的多臂老虎机、或者规则在一类里变化的导航问题）。每一局从分布中抽一个新任务，智能体与之交互若干步。策略是一个LSTM，每一步的输入不仅有当前观测 o_t，还有上一步的动作 a_{t−1} 和奖励 r_{t−1}；在一局之内隐状态不重置。外层用A3C按整局回报训练网络权重。

这样训练出来的网络权重固定后，面对一个新任务，它要在交互中根据收到的奖励调整行为——这种调整完全靠隐状态的变化完成，不再更新权重。作者把外层的A3C称为“慢”的RL，把隐状态里涌现出的适应过程称为“快”的、学到的RL算法；后者可以与外层算法完全不同，并且会利用训练分布中的结构，例如在相关联的老虎机臂之间共享信息。

结果

摘要称，论文用七个概念验证实验分别考察深度元RL的关键方面，并讨论了扩展到更大规模的前景以及对神经科学的潜在意义。按原文正文的通行描述，在独立与相关的多臂老虎机上，学到的算法表现接近Gittins指数等专门算法，并能利用臂之间的相关结构。

后来的发展

这一框架后来被称为“基于上下文的元RL”：VariBAD贝叶斯自适应把隐状态解释为对任务的贝叶斯后验，算法蒸馏与上下文RL和AdA人类时间尺度适应把循环网络换成Transformer并扩展到大规模任务空间。作者团队还在2018年把它发展为前额叶皮层作为元强化学习系统的神经科学理论。

局限与后续

  • 只能适应与训练分布相近的任务，任务分布之外的泛化没有保证。

怎么学

先了解A3C与LSTM；读原文第2节框架与第3节老虎机实验；自己用一个小LSTM在随机奖励概率的两臂老虎机上训练，观察训练后它在新老虎机上的选择如何随奖励变化。
