预测版CFR+

Faster Game Solving via Predictive Blackwell Approachability: Connecting Regret Matching and Mirror Descent
2020.07论文延伸AAAI 2021Gabriele Farina, Christian Kroer, Tuomas Sandholm · 卡内基梅隆大学 / 哥伦比亚大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大规模博弈求解实际用的是遗憾匹配和RM+，而在线凸优化里理论最成熟的是FTRL和镜像下降；两套方法各说各话，后者里「用对下一步的预测加速」的技巧没法搬到博弈求解里。

方法

证明RM和RM+正好是在Blackwell可接近性框架里分别跑FTRL和在线镜像下降得到的；于是对它们套用「预测版」FTRL/OMD，就得到预测版的RM+，再嵌进反事实遗憾最小化CFR框架。

影响

预测版CFR+（PCFR+）在多数基准博弈上比CFR+和折扣CFR（DCFR）快很多，成为表格博弈求解新的强基线，也把遗憾匹配与镜像下降两条线统一起来。

方法

Blackwell可接近性研究的是收益是向量的重复博弈：决策者要让平均收益向量逐渐靠近某个目标凸集。遗憾最小化可以写成这样一个问题：把各动作的遗憾组成一个向量，目标是让它逼近「全部非正」的那个象限。

论文的第一步是一个连接：每一轮决策者其实是在选一个要「强迫」的半空间。如果用FTRL（跟随正则化领先者）来选，得到的正是遗憾匹配RM；用OMD（在线镜像下降）来选，得到的是RM+（遗憾被截断在零以上的版本，CFR+用的就是它）。

第二步：在线优化里早有「乐观/预测」版本——如果能对下一轮的收益做一个估计（最简单的是直接用上一轮的收益），算法就先朝这个预测走一步，预测准时遗憾增长得慢得多。把预测版FTRL和OMD套进上面的连接，就得到预测版RM与RM+。把预测版RM+放在反事实遗憾最小化CFR的每个信息集上，就是PCFR+。

摘要称，在18个常见的两人零和扩展式基准博弈上，PCFR+除了其中两个扑克博弈外，在所有博弈上都比此前最快的算法（CFR+、DCFR、LCFR）收敛快得多，有时快两个数量级以上。

读懂它需要的概念

博弈论基础与纳什均衡 凸函数与凸优化 梯度下降 KL散度

本篇术语

  • Blackwell可接近性　收益是向量的重复博弈中，决策者能否让平均收益向量越来越靠近一个目标集合的理论。
  • FTRL / 在线镜像下降　在线凸优化中两类基本算法：前者每轮对全部历史损失加正则后取最优，后者每轮从上一个点出发沿梯度做一步带几何的下降。
  • 预测（乐观）更新　先用对下一轮损失的猜测走一步；猜测越准，累计遗憾越小。
