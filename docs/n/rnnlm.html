RNN语言模型

Recurrent Neural Network Based Language Model
2010.09论文重要Interspeech 2010Tomáš Mikolov, Martin Karafiát, Lukáš Burget, Jan Černocký, Sanjeev Khudanpur · 布尔诺理工大学、约翰斯·霍普金斯大学待核对
ISCA Archive ↗RNNLM Toolkit ↗在交互版中打开（演化树、学习进度）

问题

Bengio的神经语言模型只看前面固定几个词，窗口大小要事先定，再往前的信息完全用不上；它训练又极慢，实际系统里几乎没人用，仍是n-gram的天下。

方法

把前馈网络换成Elman式的简单循环网络：每读一个词，就把它和上一步的隐状态一起算出新的隐状态，再预测下一个词。隐状态不断循环，理论上能记住任意长的历史。

影响

在语音识别上第一次让神经语言模型带来大幅度的实用收益（困惑度降约50%、词错误率降约18%），并配套开源工具，把循环网络语言模型带进主流，直接铺垫了word2vec、seq2seq和此后的LSTM语言模型。

背景

神经概率语言模型证明了词向量加神经网络能胜过n-gram，但它是前馈网络：输入是固定的前n−1个词，窗口大小、投影层大小、隐层大小都要调，窗口之外的信息看不到。更现实的问题是速度：论文提到，Bengio在Brown语料上的基础实现训练要113天，用重要性采样也要26小时。所以到2010年，语音识别和机器翻译里实际用的仍是加n-gram平滑平滑的n-gram，神经网络只在少数实验中作为补充。

Elman循环网络早在1990年就提出了带“上下文层”的循环网络，但没有人在大规模语言建模上认真做过。

方法

结构。输入层x(t)是当前词的独热向量w(t)与上一步隐状态s(t−1)拼接而成；隐层（上下文层）和输出层分别为

s(t) = sigmoid(U·w(t) + W·s(t−1))

y(t) = softmax(V·s(t))

y(t)就是下一个词在词表上的概率分布（见循环网络与隐状态、Softmax与logits）。U的每一列实际上就是一个词向量，所以不需要单独的投影层；隐层大小通常30到500，唯一需要认真选的超参数是它，并且应随训练数据量增大。

训练。用交叉熵损失和随机梯度下降，学习率从0.1开始，验证集上不再明显改善时减半，一般10到20轮收敛。论文主实验用的是只回传一步的截断反向传播（τ = 1），也讨论了更完整的随时间反向传播（BPTT）。出现次数低于阈值的词合并成一个“稀有词”记号，概率在这些词之间均分，以缩小输出层。

动态模型。测试时也继续用小学习率在线更新权重，让模型适应当前文档的话题和用词。

使用方式。语音识别器先用n-gram产出100个候选（n-best），再用RNN语言模型与5-gram按0.75:0.25线性插值后重新打分。

结果

华尔街日报（WSJ）语音识别任务，RNN只用640万词训练：修正Kneser-Ney 5-gram困惑度221，三个动态RNN混合后加上5-gram为121，最好结果112，接近减半；词错误率从13.5%降到11.1%，相对降约18%。与用5倍数据（3700万词）训练的回退模型相比，词错误率仍相对降约12%。在更难、基线更强的NIST RT05会议语音任务上也有约5%的相对降低。训练数据从20万词增加到640万词，相对n-gram的优势越来越大。速度方面，Brown语料上训练一个100隐单元的模型约6小时。

后来的发展

Mikolov随后发布RNNLM工具包，循环网络语言模型很快进入语音识别和机器翻译的重打分环节。Mikolov等人随后把RNNLM输入矩阵U的列当作词向量，用词语类比题检验它们（word2vec论文表3中“RNNLM”一行），再去掉隐层、专门为学词向量设计更简单的模型，得到word2vec。

简单RNN的梯度消失问题让它记不住真正长的上下文（论文自己也承认缓存模型仍能提供互补信息），于是LSTM字符级生成、探索语言模型的极限、AWD-LSTM改用LSTM；Seq2Seq把两个循环网络连成编码器和解码器用于翻译。2017年后Transformer取代循环网络，但“逐词读入、预测下一个词”的训练方式一直延续到今天的大语言模型。

局限与后续

  • 简单RNN存在梯度消失，实际上记不住很长的上下文，论文中缓存模型仍能提供互补的长程信息。
    后来针对它的工作　LSTM字符级生成 探索语言模型的极限 AWD-LSTM
  • 训练很慢：输出层要对整个词表算softmax，最复杂的模型在640万词上要训练几周，作者因此没用全部3700万词训练RNN。
    后来针对它的工作　word2vec 探索语言模型的极限
  • 逐词顺序计算，同一句子内部无法并行，难以借助大规模硬件扩大数据和模型。
    后来针对它的工作　Transformer
  • 只用于对n-gram产出的候选重打分，不能直接参与语音识别的第一遍搜索。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    神经概率语言模型2003.02 · NLP 待核对
    前馈神经语言模型只能看固定窗口、超参数多且训练极慢；循环隐状态让上下文长度不受窗口限制，并把Brown上的训练时间降到约6小时。
  • 使用
    反向传播1986 · 基础
    用（截断的）反向传播和随机梯度下降训练，并讨论了随时间反向传播。
  • 改进
    香农：语言的统计模型1948 · NLP
    只看前面n−1个符号，超出窗口的句法和语义依赖完全丢失；香农自己也说再往高阶做，所需的统计“工作量变得巨大”。
  • 使用
    HMM统计语音识别1976 · 语音
    在HMM语音识别系统产出的n-best候选上重打分，词错误率作为最终检验。
  • 使用
    Elman循环网络1990 · 基础
    网络就是Elman的简单循环网络：上一步隐层拷贝回来与当前输入拼接。
  • 改进
    Brown聚类1992 · NLP
    作为语言模型提升有限：类模型单独使用困惑度反而变差，与词模型插值后仅从244降到236。
  • 改进
    Kneser-Ney平滑1995.05 · NLP
    仍是按词形计数：「狗」和「猫」的统计互不相通，没见过的组合只能靠低阶分布兜底，无法利用词之间的相似性。
  • 改进
    Katz回退语言模型1987.03 · 语音
    n-gram只看固定几个词，无法利用相似词之间的泛化，也不能记住长距离依赖。
  • 竞争
    n-gram平滑1996 · NLP
    基线是修正Kneser-Ney平滑的5-gram；RNN困惑度约降一半，与它插值使用效果最好。
  • 改进
    万亿词n-gram与Stupid Backoff2007.06 · NLP
    n-gram模型靠记忆计数，规模再大也无法泛化到没见过的组合，存储和查询成本随阶数增长。
  • 改进
    对数双线性语言模型2007.06 · NLP
    只用固定长度的前文，不能处理长距离依赖。

后来的相关工作

  • 延续
    RNN-Transducer2012.11 · 语音 已核对
    预测网络就是一个循环神经语言模型，但不再单独训练，而是和声学网络在同一个损失下联合训练。
  • 改进
    word2vec2013.01 · NLP 已核对
    作者此前用RNNLM的输入矩阵当词向量；这里把语言模型简化成只学词向量的对数线性模型，并在同数据上直接比较，RNNLM向量语义准确率只有9%。
  • 延续
    Seq2Seq2014.09 · NLP 已核对
    解码器就是一个以源句向量为起点的RNN语言模型，把“续写”变成了“按条件生成”。
  • 改进
    Transformer2017.06 · LLM
    逐词顺序计算，同一句子内部无法并行，难以借助大规模硬件扩大数据和模型。
  • 延续
    梯度裁剪2012.11 · 基础
    把Mikolov在RNN语言模型里用的逐元素截断改成按整体范数缩放，保持梯度方向。
  • 延续
    LSTM字符级生成2013.08 · NLP
    把RNN语言模型从给候选打分推进到直接采样生成长序列，并从词级改为字符级，网络也从单层简单RNN换成深层LSTM。
  • 延续
    RNN编码器-解码器与GRU2014.06 · NLP
    解码器本质上是一个以源序列概括c为条件的RNN语言模型。
  • 使用
    序列预训练（Dai & Le）2015.11 · NLP
    LM-LSTM的预训练目标就是RNN语言模型的“预测下一个词”。
  • 延续
    探索语言模型的极限2016.02 · NLP
    沿着RNN语言模型的路线，换成大LSTM、在千倍于Penn Treebank的语料上系统地放大。
  • 改进
    AWD-LSTM2017.08 · NLP
    简单RNN存在梯度消失，实际上记不住很长的上下文，论文中缓存模型仍能提供互补的长程信息。
  • 延续
    ULMFiT2018.01 · LLM
    把循环网络语言模型从只用于预测下一个词，变成迁移到下游任务的通用起点。
  • 使用
    循环连续翻译模型2013.10 · NLP
    解码端使用循环神经网络语言模型，并加入源句条件。
  • 延续
    m-RNN多模态RNN2014.10 · 多模态
    在循环神经网络语言模型上加入图像条件。
  • 延续
    输入输出嵌入共享2016.08 · 基础
    在循环神经网络语言模型中加入输入输出嵌入共享以降低困惑度

读懂它需要的概念

语言模型 循环网络与隐状态 Softmax与logits 困惑度 交叉熵 词错误率

本篇术语

  • 随时间反向传播（BPTT）　把循环网络按时间展开成很深的前馈网络，再沿时间往回传梯度；截断BPTT只往回传固定的几步。
  • n-best重打分　先用便宜的模型产出前n个候选，再用更强但更慢的模型重新给它们打分、挑出最好的一个。
  • 动态模型　在测试时也继续在线更新参数，使模型适应当前文本的用词和话题。

怎么学

先补循环网络与隐状态、困惑度，读过神经概率语言模型。读原文第2节（公式1–5与训练细节）和表1、表2。动手：用PyTorch实现一个单层sigmoid RNN语言模型，在Penn Treebank上训练，比较隐层50与200的困惑度，并与一个KenLM训练的5-gram做线性插值。
