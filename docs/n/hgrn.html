HGRN层次门控循环网络

Hierarchically Gated Recurrent Neural Network for Sequence Modeling
2023.11论文延伸NeurIPS 2023Zhen Qin, Songlin Yang, Yiran Zhong · 上海人工智能实验室、MIT待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

重新流行的线性RNN常常只在线性递推层的输出上加门控，却忽视了在递推内部使用遗忘门的重要性。

方法

在线性递推里加入遗忘门，并给遗忘门设一个可学习的下界；这个下界随层数单调增大，使上层更倾向于保留长期记忆、下层专注于局部短期依赖。

影响

是线性RNN/线性注意力复兴中的代表工作之一，后续的HGRN2把状态扩展为矩阵形式；作者团队的flash-linear-attention库也成为这类模型的常用实现。

方法

HGRN的递推是逐元素的线性门控：h_t = f_t ⊙ h_{t−1} + (1 − f_t) ⊙ c_t，其中遗忘门f_t和候选c_t都只由当前输入算出（因而可以并行扫描训练），隐状态用复数值以增加表达力。关键改动是下界：每层有一个可学习的下界γ_l，实际遗忘门为 f_t = γ_l + (1 − γ_l)·σ(·)，于是遗忘门永远不会低于γ_l。各层的γ通过对一个可学习向量做累积softmax得到，保证从底层到顶层单调增加：底层的γ接近0，可以快速遗忘，专注局部模式；顶层的γ接近1，记忆衰减很慢，可以建模长程依赖。这种“越往上记得越久”的分工与HiPPO等工作中多时间尺度记忆的想法相通。

摘要报告在语言建模、图像分类和Long Range Arena基准上验证了模型的效率和效果。

局限与后续

  • 逐元素（向量）状态的容量有限，召回类任务上弱于注意力；后续HGRN2通过外积把状态扩展为矩阵来增加容量。
