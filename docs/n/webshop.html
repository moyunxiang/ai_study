WebShop

WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents
2022.07数据集延伸NeurIPS 2022Shunyu Yao, Howard Chen, John Yang, Karthik Narasimhan · 普林斯顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语言落地的交互环境要么缺少真实世界语言，要么依赖大量人工收集而难以扩展。

方法

搭建一个模拟电商网站：118万件真实商品、约1.2万条众包购物指令，智能体需要搜索、浏览、选规格并购买。

影响

成为语言智能体的常用基准，后续ReAct等方法都在其上评测，并展示了从模拟到真实网站的初步迁移。

方法

WebShop是一个模拟购物网站，含118万件真实商品和12,087条众包文字指令。给定一句如「想要一件适合敏感皮肤、不超过某价格的洗面奶」之类的需求，智能体要在不同类型的页面间导航、发起搜索、点击商品、选择选项并下单，最后按所购商品与指令要求的匹配程度给奖励。

它考察的难点包括理解组合式指令、重新表述查询、从嘈杂的网页文本中提取信息，以及策略性探索。作者收集了1600多条人类示范，并用强化学习、模仿学习和预训练的图像与语言模型训练多种智能体。最好的模型成功率为29%，高于规则基线的9.6%，但远低于人类专家的59%。在模拟上训练的智能体在amazon.com和ebay.com上也表现出一定迁移。相比World of Bits / MiniWoB的低层鼠标键盘动作，WebShop用文字化的动作和真实商品文本，更适合语言模型，基础模型用到了BERT。
