TabPFN表格基础模型

Accurate predictions on small data with a tabular foundation model
2025.01论文延伸Nature 2025Noah Hollmann, Samuel Müller, Lennart Purucker, Arjun Krishnakumar, Max Körfer, Shi Bin Hoo, Robin Tibor Schirrmeister, Frank Hutter · University of Freiburg / Prior Labs / Charité / ELLIS Institute Tübingen待核对
Nature ↗TabPFN初版（arXiv 2207.01848） ↗在交互版中打开（演化树、学习进度）

问题

表格数据（行是样本、列是特征）上，梯度提升决策树统治了约20年，深度学习一直没能稳定超过它，而且每个数据集都要单独调参训练。

方法

在数百万个按先验随机生成的合成表格任务上预训练一个Transformer，让它学会“看一遍带标签的训练行，直接预测测试行”，一次前向完成。

影响

首个在小表格数据上全面压过调参后的树模型集成的基础模型，使“表格基础模型”成为热门方向。

方法

2022年的初版TabPFN（arXiv 2207.01848）提出先验数据拟合网络：从一个包含大量结构因果模型的先验里采样合成数据集，训练Transformer把整组训练样本当作输入集合、对测试样本给出预测，相当于用上下文学习与提示近似贝叶斯推断；但主要在最多1000个训练样本、100个数值特征、10个类别的小数据集上验证。

Nature上的新版把这一思路做大：仍在数百万个合成数据集上离线训练一次，使用时不更新参数，一次前向就给出预测。Nature摘要报告：在最多10000个样本的数据集上大幅超过以往所有方法（正文称适用于最多10000样本、500个特征）；分类任务里，它用2.8秒就超过了调参4小时的最强基线集成。作为生成式模型，它还支持微调、数据生成、密度估计和提取可复用的嵌入。对比对象包括XGBoost、CatBoost等梯度提升树。

局限与后续

  • 只适用于小到中等规模的表格（约1万样本、500特征以内），更大的数据上树模型仍是首选。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 能力取决于合成先验的设计，真实数据若偏离先验假设，效果没有保证，也难以解释模型学到的“算法”。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    以Transformer为骨干，把训练样本集合作为输入，一次前向输出所有测试样本的预测。
  • 延续
    GPT-32020.05 · LLM
    借用上下文学习的思路：不更新参数，只靠输入里的带标签示例完成新任务，把它搬到表格数据上。
  • 竞争
    XGBoost2016.03 · 基础
    XGBoost代表的梯度提升树是表格数据上长期最强的基线，TabPFN在小数据上首次全面超过它们。
  • 竞争
    CatBoost2017.06 · 基础
    同属被比较的梯度提升基线；TabPFN免去逐数据集的训练和调参。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

决策树 集成学习 上下文学习与提示 Transformer层的结构 先验、后验与贝叶斯推断

怎么学

先补决策树和上下文学习与提示；读Nature论文的引言和方法概述；用官方tabpfn库和XGBoost在几个OpenML小数据集上比较准确率与耗时。
