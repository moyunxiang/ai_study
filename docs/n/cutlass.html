CUTLASS

CUTLASS: Fast Linear Algebra in CUDA C++
2017.12系统延伸NVIDIA待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

cuBLAS这类库是黑盒，想写自定义的融合矩阵乘内核要从头处理线程、共享内存和Tensor Core指令，极其繁琐。

方法

CUTLASS用C++模板把矩阵乘（GEMM）拆成可组合的分层部件：线程块级、warp级、指令级，开发者按需组合与特化。

影响

成为自写高性能GPU内核的基础库，后续的CuTe与许多注意力内核都建立在它之上。

方法

仓库自述CUTLASS是仅头文件的C++模板库，提供高性能矩阵乘及相关线性代数的构件，自2017年起提供CUDA C++模板抽象。核心思路是分块与层级分解：把大矩阵乘切成线程块处理的小块，再切成warp处理的更小块，再映射到Tensor Core的mma指令；每一层的分块大小、数据类型、算法策略都是模板参数，可以特化和调优。

它面向V100与Tensor Core引入的Tensor Core，之后覆盖到更新的架构。CUTLASS 3.0引入的CuTe用统一方式描述线程与数据的布局，把下标计算交给库处理。它与CUDA的关系是：在CUDA之上提供一层可复用的GEMM积木。
