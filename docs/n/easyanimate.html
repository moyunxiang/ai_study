EasyAnimate视频框架

EasyAnimate: High-Performance Video Generation Framework with Hybrid Windows Attention and Reward Backpropagation
2024.05论文延伸Jiaqi Xu, Kunzhe Huang, Xinyi Zou, Yunkuo Chen, Bo Liu, MengLi Cheng, Jun Huang, Xing Shi · 阿里云PAI待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

视频扩散模型生成慢、画质不理想；视频序列一长，全注意力的计算量飞涨。

方法

在扩散Transformer里用多方向滑动窗口组成的混合窗口注意力降低长序列计算量，并用奖励反向传播做后训练以对齐人的偏好。

影响

提供从数据处理、训练到推理的完整开源框架，被diffusers收录，是2024年国内常用的开源视频生成工具链之一。

方法

EasyAnimate以扩散Transformer为骨架。为降低视频长序列的开销，它设计了混合窗口注意力：在时间、高、宽三个方向上做多方向滑动窗口，比朴素窗口在三维上的感受野更大，同时计算量不随序列长度平方增长。为提升画质，模型在预训练后用奖励反向传播（把可微的偏好奖励模型的梯度回传给生成器，类似AlignProp奖励反传）做后训练。作者还提出按token长度组织批次的训练策略，以处理分辨率和时长不一的视频。整套框架覆盖数据处理、模型训练和端到端推理。
