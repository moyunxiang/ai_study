FQE拟合Q评估

Batch Policy Learning under Constraints
2019.03论文延伸ICML 2019Hoang M. Le, Cameron Voloshin, Yisong Yue · Caltech待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

真实应用里的策略学习有两个难点：只能用事先收集的、非最优的离策略数据；同时要兼顾多个相互竞争的目标与约束（例如自动驾驶既要快，又要保持车道、行驶平顺）。验证约束是否满足还需要可靠的离策略评估。

方法

提出一个元算法，把批量约束策略学习写成拉格朗日形式，交替调用任意批量RL算法（求策略）和在线学习算法（更新拉格朗日乘子）；为了验证约束，提出拟合Q评估（FQE）：像拟合Q迭代一样回归，但目标里用待评估策略的动作而不是max。

影响

FQE这个简单的离策略评估方法后来被多项系统比较证明是最可靠的OPE方法之一，成为离线RL中做策略选择和评估的事实标准。

背景

拟合Q迭代FQI（拟合Q迭代）用一批固定数据反复回归Bellman目标来学最优Q函数，是批量RL的基础。约束RL通常用拉格朗日方法处理，但大多假设可以在线交互。离策略评估方面，重要性采样类方法（双重稳健策略评估、WDR与MAGIC离策略评估）依赖行为策略的概率，且在高维、长时程问题上方差很大。作者需要一个能处理多个约束、只用离线数据、并且能给出性能保证的完整方案。

方法

问题：在数据集D上求 min_π C(π) s.t. G_i(π) ≤ τ_i，C是主要代价，G_i是各约束代价。写成拉格朗日形式 L(π, λ) = C(π) + λᵀ(G(π) − τ)，看作π与λ之间的二人博弈。

元算法：每轮先固定λ，用任意批量RL算法（如拟合Q迭代）在混合代价 c + λᵀg 下求最优策略 π_t；然后对λ做在线梯度类更新（如指数梯度）以加大违反约束的惩罚。最终输出所有 π_t 的混合策略，并给出主目标与所有约束的性能保证。

FQE：要评估某个策略π的代价，从 Q_0 = 0 开始迭代

Q_{k+1} = argmin_f Σ_{(s,a,c,s′)∈D} ( f(s,a) − c − γ Q_k(s′, π(s′)) )²

即把拟合Q迭代中的 max_a′ 换成目标策略的动作 π(s′)。迭代K次后，用 E_{s₀}[Q_K(s₀, π(s₀))] 作为估计。作者推导了FQE的PAC式误差界，它依赖函数类的复杂度与数据分布的集中性系数。

结果

摘要称：作者提出了一个可以把任何批量RL和在线学习过程作为子程序的灵活元算法，给出了具体实例并为主目标和所有约束提供性能保证；为认证约束满足，提出了一种新的简单离策略评估方法并推导了PAC式界；算法在不同领域取得了很强的实证结果，包括在保持车道、平稳驾驶等多个约束下的模拟驾驶问题；单独比较时，这一OPE方法也优于其他流行的OPE技术，在高维设定下尤其明显。

后来的发展

此后的OPE大规模基准比较（如在D4RL与DeepMind控制任务上的研究）发现FQE在多数设定下最稳健，它成为离线RL论文里做超参数选择与离策略评估的常用工具；约束批量RL的元算法也被后续安全离线RL工作沿用。

局限与后续

  • FQE的误差受数据分布覆盖程度影响，目标策略访问数据中稀少的状态—动作时，回归会外推出偏差很大的值。

读懂它需要的概念

离线强化学习 Bellman方程 拉格朗日乘子、约束优化与对偶 线性回归 策略与价值函数

本篇术语

  • 拟合Q评估（FQE）　用固定数据反复回归“即时代价加上目标策略在下一状态的Q值”，得到目标策略的Q函数，从而估计它的表现。
  • 拉格朗日乘子　把约束乘上一个可调的系数加进目标中；违反约束越多，系数被调得越大，惩罚越重。

怎么学

先复习拟合Q迭代FQI和拉格朗日乘子、约束优化与对偶；读原文第4节元算法与第5节FQE及其误差界；在一个D4RL数据集上用FQE评估几个不同训练阶段的策略，与真实回报对比排序是否一致。
