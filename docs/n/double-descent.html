双下降

Deep Double Descent: Where Bigger Models and More Data Hurt
2019.12论文延伸ICLR 2020Preetum Nakkiran, Gal Kaplun, Yamini Bansal, Tristan Yang, Boaz Barak, Ilya Sutskever · Harvard / OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

插值区与双下降曲线的双下降主要在经典模型上展示，现代深度网络里是否也如此、与哪些变量有关并不清楚。

方法

在CNN、ResNet、Transformer上系统地展示：双下降不仅随模型大小出现，也随训练轮数出现，甚至更多数据反而更差。

影响

证明双下降是深度学习里普遍的现象，并提出“有效模型复杂度”作为统一解释的变量。

方法

论文把模型宽度、训练轮数、样本数当作变量，在多种视觉与语言任务上测试。摘要给出三类结果：增大模型尺寸时性能先变差再变好（模型级双下降）；固定模型、增加训练轮数时也有同样的“先差后好”（轮数级双下降）；在某些区间，训练样本数增加甚至四倍也会让测试性能变差（样本级）。

作者定义“有效模型复杂度”（在给定数据和训练流程下模型能拟合的最大训练集大小），并猜想当它接近样本数时性能最差，临界区间内标签噪声使现象更明显。

局限与后续

  • 有效模型复杂度只是一个猜想，缺少严格定义与证明。
    后来针对它的工作　Grokking
  • 没有说明大模型训练成功时是否总会越过峰值，现代大语言模型的缩放曲线里很少看到明显的双下降。

读懂它需要的概念

偏差-方差权衡 泛化与过拟合 正则化与权重衰减 批大小、步数与轮数 训练集、验证集与测试集

怎么学

先读插值区与双下降曲线；读原文第2、3节的实验设置与有效模型复杂度定义；用小MLP在带噪声的小数据集上扫宽度，复现模型级双下降。
