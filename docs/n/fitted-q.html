拟合Q迭代FQI

Tree-Based Batch Mode Reinforcement Learning
2005论文延伸JMLR 2005Ernst, Geurts, Wehenkel · University of Liège待核对
JMLR ↗在交互版中打开（演化树、学习进度）

问题

Q-learning逐条处理在线样本，每个样本用一次就丢，数据效率差，与函数近似结合也不稳。

方法

批量模式：存下所有 (状态,动作,奖励,下一状态) 四元组，每一轮把Bellman目标当作监督学习的回归标签，用树集成方法拟合新的Q函数，反复迭代。

影响

提出了「拟合Q迭代」这一范式，把RL的迭代转化为一连串监督回归；神经拟合Q迭代NFQ与后来的DQN都是它的神经网络版本。

方法

算法本身很简单：给定固定的四元组数据集，初始Q₀=0。第k轮，对每个样本 (x,u,r,x′) 构造目标 r + γ·max_u′ Q_{k−1}(x′,u′)，再把 (x,u) → 目标 当作一个回归数据集，用某个监督学习器拟合出 Q_k。迭代一定轮数后，贪心地取 argmax Q 作为策略。

论文的重点是研究哪类回归器能在这个迭代里表现好：比较了CART、Kd树、树的bagging，以及作者新提出的极度随机树（extremely randomized trees）和完全随机树。摘要称基于回归树的集成方法表现良好；完全随机树既有好结果又能保证迭代序列收敛，放宽收敛约束的极度随机树精度更高。

局限与后续

  • 用神经网络等非树模型做回归时，迭代可能发散，没有收敛保证。
    后来针对它的工作　神经拟合Q迭代NFQ DQN
  • 需要一次性存放全部数据，适合批量设置，不适合不断在线采集。
    后来针对它的工作　DQN

它建立在什么之上

  • 延续
    Q-learning1992 · RL
    把Q学习的逐样本更新改成对整个数据集做批量拟合，复用所有历史样本。
  • 改进
    实时动态规划RTDP1995.01 · RL
    仍是表格方法，需要能对每个访问到的状态做完整的期望备份（知道或学会转移概率），状态空间连续或巨大时无法直接用。

后来的相关工作

  • 改进
    DQN2013.12 · RL
    用神经网络等非树模型做回归时，迭代可能发散，没有收敛保证。
  • 延续
    BCQ批量约束Q学习2018.12 · RL
    继承批量RL“只用固定数据集学Q函数”的设定，指出深度网络下的外推误差并加上动作约束。
  • 改进
    神经拟合Q迭代NFQ2005 · RL
    把树集成回归器换成多层感知机，把拟合Q迭代带进神经网络。

读懂它需要的概念

Bellman方程 监督学习 决策树 集成学习 时序差分与自举

怎么学

用sklearn的ExtraTreesRegressor在一个小连续状态问题（如倒立摆）上实现FQI：收集一批随机轨迹，迭代拟合十轮。
