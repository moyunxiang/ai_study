RotatE旋转嵌入

RotatE: Knowledge Graph Embedding by Relational Rotation in Complex Space
2019.02论文延伸ICLR 2019Zhiqing Sun, Zhi-Hong Deng, Jian-Yun Nie, Jian Tang · 北京大学、蒙特利尔大学、Mila待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

知识图谱里的关系有对称、反对称、互逆、可组合等多种模式，TransE、DistMult、ComplEx各自只能覆盖其中一部分。

方法

把每个关系定义成复数空间里的一次旋转：要求 t ≈ h ∘ r，其中 r 每一维模长为1，只有相位。旋转既能表示对称（转180°）、反对称，也能表示互逆（反向旋转）和组合（两次旋转相加相位）；再配上按难度加权的「自对抗」负采样。

影响

RotatE成了链接预测里最常被比较的模型之一，「关系=几何变换」的思路衍生出QuatE、HAKE等一系列变体，它的自对抗负采样也被广泛沿用。

背景

TransE知识图谱嵌入用平移 h + r ≈ t，能表达互逆和组合，但无法表达对称关系（对称要求 r=0）。DistMult双线性嵌入只能表达对称关系；ComplEx复数嵌入能处理对称和反对称，却不能自然地表达组合（「父亲的父亲=祖父」）。此外，均匀随机替换实体得到的负例大多太容易，训练后期几乎不提供梯度。

方法

实体 h、t 是 k 维复数向量，关系 r 也是复数向量，但每一维约束为单位模长：r_i = e^{iθ_i}，于是逐元素乘 h ∘ r 相当于把 h 每一维旋转角度 θ_i。距离函数为：

d_r(h, t) = ‖h ∘ r − t‖

这样能解释四种模式：对称关系对应 θ_i ∈ {0, π}（转两次回到原处）；反对称关系对应其他角度；关系 r₂ 是 r₁ 的逆当且仅当 r₂ = conj(r₁)；r₃ = r₁ ∘ r₂ 表示组合，即相位相加。

训练损失为 L = −log σ(γ − d_r(h,t)) − Σ_i p(h'_i,r,t'_i) · log σ(d_r(h'_i,t'_i) − γ)，其中 γ 是间隔。自对抗负采样让负例权重 p 按当前模型给它的得分做softmax（带温度），越像真的负例权重越大，权重本身不回传梯度。

结果

摘要称RotatE可扩展，能推断和建模多种关系模式，在多个基准知识图谱上的链接预测显著优于当时最好的模型。具体数字未核对。

后来的发展

RotatE之后出现了把旋转推广到四元数（QuatE）、加入层级模长（HAKE）、在双曲空间里旋转等变体。自对抗负采样被很多知识图谱嵌入实现当作默认设置。2020年代图神经网络和预训练语言模型也被用于补全，但RotatE这类浅层嵌入因为快和稳仍是常用基线。

局限与后续

  • 只能处理单个三元组，无法利用实体的文本描述，对训练时没见过的新实体无能为力。

它建立在什么之上

  • 延续
    word2vec2013.01 · NLP
    沿用word2vec式负采样训练嵌入的做法，并按模型得分给负例加权，形成自对抗负采样。
  • 延续
    TransE知识图谱嵌入2013.12 · NLP
    把TransE的「平移」换成复数空间的「旋转」，保留表达互逆与组合的能力，同时补上对称关系。
  • 改进
    RESCAL张量分解2011.06 · NLP
    RESCAL给每个关系一个完整矩阵，参数多且不显式区分关系模式；RotatE每个关系只用一组相位，并能解释对称、互逆与组合。
  • 改进
    DistMult双线性嵌入2014.12 · NLP
    DistMult只能表示对称关系，RotatE的旋转可以同时覆盖对称和反对称关系。
  • 改进
    ComplEx复数嵌入2016.06 · NLP
    ComplEx不能自然表达关系的组合，RotatE约束关系为单位模长旋转，组合即相位相加。

读懂它需要的概念

本篇术语

  • 关系模式　关系在逻辑上的性质：对称、反对称、互逆（r1(a,b)⇔r2(b,a)）、组合（r1接r2等于r3）。
  • MRR　平均倒数排名：每个测试三元组里正确实体排第k名得1/k，再对所有测试求平均，越接近1越好。
