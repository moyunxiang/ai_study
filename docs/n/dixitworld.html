DixitWorld多模态溯因推理评测

DixitWorld: Evaluating Multimodal Abductive Reasoning in Vision-Language Models with Multi-Agent Dixit Gameplay
2025.10论文延伸ACL 2026（扩展版）；初版EMNLP 2025 Workshop (Spotlight)Yunxiang Mo, Tianshi Zheng, Qing Zong, Jiayu Liu, Baixuan Xu, Yauwai Yim, Chunkit Chan … Yangqiu Song（共9位） · 香港科技大学待核对
arXiv ↗OpenReview（ACL 2026版） ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

对视觉语言模型溯因推理（为观察提出并挑选最好的解释）的评测多是静态、单个模型作答的选择题，只测“挑选”，测不到“自己提出假设、还要让别人恰好能懂”。

方法

借桌游《妙语说书人》（Dixit）：说书人看图给出隐晦线索（生成假设），听者从干扰图中找出目标图（选择假设），只有部分听者猜中时说书人才得分；另做静态选择题DixitBench单独测听者。

影响

量化了视觉语言模型“会听不会说”：最强听者正确率75.6%，但多数说书回合得零分；较小的开源模型反而是更有创意的说书人。

背景

溯因推理指从不完整的观察出发，找出最能解释它的假设，比如看到地面湿推断刚下过雨。它包括两步：提出候选假设，再从中挑最合理的。此前的视觉溯因评测（如VAR、Sherlock）都是静态的单模型任务：给图和候选，选一个答案。这只测了挑选，没有测生成；也没有对手和听众，模型不必考虑别人会怎么理解自己的话。

方法

DixitArena（多智能体对局）。4个模型轮流当说书人：说书人选一张图说一句线索，其余3人各出一张贴合线索的图作干扰，打乱后听者猜哪张是说书人的。计分沿用桌游规则：部分听者猜中时，说书人和猜中者各得3分；全猜中或全猜错时说书人得0分；干扰图被选中，出图者得1分。所以线索必须不太直白、也不太含糊。实验用84张自制插图，每局24回合，6个模型循环赛（含自对弈）共21局、504回合。

DixitBench（静态题库）。把听者任务改成选择题：给线索，从目标图和干扰图中选。干扰图按图片说明文字的语义相似度（见嵌入向量）控制难度：arXiv版分易、难两档共168题，ACL版扩到252题、三档。

结果

arXiv版评测了Qwen2.5-VL-7B/32B、Gemma3-12B/27B、Gemini-2.5-Flash和GPT-4o。听者成绩大体随规模和是否闭源上升，说书人成绩却不然：GPT-4o听者得分53.89%，说书人只有19.05%；说书人得分最高的是Gemma3-27B（32.14%）。超过70%的说书回合得零分（ACL版为78%）：小模型的线索常太字面或太含糊，大模型倾向说得过细。DixitBench上GPT-4o最好（75.60%），与对局中的听者成绩高度相关（ACL版报告相关系数r = 0.947）。按语义相似度分的难易题平均只差4.8个百分点。ACL版另加一个72B开源模型，不对称仍然存在。

后来的发展

论文认为，缩小“说”与“听”的差距需要模型显式推测听者的理解（心智理论）并处理歧义，这仍是开放问题。

容易误解的地方

  • 说书人得分低不等于看不懂图：同一个模型做听者可能很强，差距出在“控制线索的模糊程度”上。
  • arXiv版与ACL版的题数和部分数字不同（168题对252题，超过70%对78%），引用时要注明版本。

局限与后续

  • 规模小：只有84张插图，arXiv版只评测了6个模型（ACL版加1个72B模型），对局在固定随机种子下只跑一轮，结论能否推广到更多模型和图库尚未验证。

它建立在什么之上

  • 使用
    Gemini 2.5 Pro2025.03 · LLM
    Gemini 2.5系列中的Flash版参评，在对局中综合得分最高（36.52%）。
  • 使用
    Qwen2.5-VL2025.02 · 多模态
    Qwen2.5-VL-7B/32B是被评测的开源模型，7B在说书人和听者两项都排最后。
  • 使用
    Gemma 32025.03 · LLM
    Gemma3-12B/27B参评：27B说书人得分最高，12B在人工评测中创意分最高，是“较小开源模型更会出谜”结论的主要依据。

读懂它需要的概念

基准、排行榜与SOTA 语言模型 嵌入向量 解码：贪心、束搜索、温度与top-p 方差、种子与统计显著性

本篇术语

  • 溯因推理　从结果反推最可能的原因或解释，与从前提推结论的演绎、从例子归纳规律的归纳并列。
  • 《妙语说书人》（Dixit）　一款桌游：说书人为手中一张抽象插图说一句话，其他人出牌混淆，再一起猜哪张是说书人的；说得太明白或太隐晦都得不到分。
  • 说书人—听者不对称　本文的核心发现：同一个模型在“理解线索、选图”上表现好，在“生成恰好一部分人能懂的线索”上表现差。

怎么学

先了解基准、排行榜与SOTA和视觉语言模型的基本用法（见LLaVA）。再读论文第2节的对局规则与计分、表1和图3的说书人结果分布。动手：从GitHub取代码，用两个本地小模型跑几回合对局，看它们的线索为什么被全猜中或全猜错。
