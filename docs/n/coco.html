MS COCO

Microsoft COCO: Common Objects in Context
2014.05数据集延伸Tsung-Yi Lin, Michael Maire, Serge Belongie, Lubomir Bourdev, Ross Girshick, James Hays, Pietro Perona, Deva Ramanan, C. Lawrence Zitnick, Piotr Dollár · Microsoft / Cornell / Caltech 等待核对
arXiv ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

已有物体数据集（PASCAL VOC、ImageNet）多是单个物体居中的图片，无法训练识别复杂日常场景里互相遮挡的多个物体。

方法

收集日常复杂场景中的图片，用众包对每个物体实例做分割轮廓标注，同时提供图片描述。

影响

COCO成为物体检测、实例分割和图像描述的核心基准，AP指标按多个IoU阈值平均的做法也成为标准。

方法

MS COCO发表于2014年，作者来自微软、康奈尔、加州理工等。据论文摘要，数据集包含「4岁小孩都认得的」91类物体，共328k张图片、250万个已标注实例，每个物体都用实例分割轮廓标注，以便精确定位。图片取自日常的复杂场景，物体处于自然情境中，而不是居中的特写。论文大量使用众包工人，并设计了新的界面来分别完成类别检测、实例定位和实例分割。

论文还和PASCAL VOC、ImageNet、SUN（见SUN与Places场景库）做了统计对比，并用可变形部件模型给出检测和分割的基线。数据集后来增加了图像描述（Captioning 2015）、关键点、全景分割等任务，官网列出了2015到2020年的历届挑战。

评测方面，COCO服务器也提供图像描述的指标（含CIDEr的CIDEr-D版本）。

局限与后续

  • 标注量大但类别只有80到91类，长尾物体和稀有类别没有覆盖，后来才有LVIS补充。

  • 评测指标和数据偏向常见的城市和室内场景，对遮挡、小物体之外的难例覆盖有限。

它建立在什么之上

  • 竞争
    ImageNet2009.06 · 数据·评测 已核对
    ImageNet强调类别数和规模，COCO强调每张图的物体数量和精确位置。
  • 改进
    MNIST1998 · 数据·评测
    只有居中、无背景的单个灰度数字，没有真实场景中的光照、遮挡、背景杂乱和类别多样性。
  • 改进
    ILSVRC挑战赛2010 · 数据·评测
    每张图只评一个主要物体，物体大多大而居中，不能检验在复杂场景中找出、分割多个物体的能力。
  • 延续
    PASCAL VOC2005 · 数据·评测
    沿用VOC的挑战赛评测模式，但把图片换成复杂日常场景，并把标注提升到实例分割。
  • 改进
    LabelMe标注工具2005 · 数据·评测
    多边形标注费时，难以扩展到ImageNet那样的百万张规模。
  • 改进
    Flickr30k2014.02 · 数据·评测
    图片规模只有3万多张，且偏向人物活动，难以覆盖更广泛的场景。

    BooksCorpus2015.06 · 数据·评测
    COCO的图像描述只有一句话的客观描写，本文想用书中的长段落给画面提供更丰富的描述。
  • 延续
    Visual Genome2016.02 · 数据·评测
    COCO 只给整图的一句话描述和物体分割，本文增加了区域描述、关系与属性，使监督更密集。
  • 竞争
    ADE20K2016.08 · 数据·评测
    COCO 侧重常见物体的实例分割，ADE20K 强调覆盖全部像素的场景解析和更多类别。
  • 改进
    Conceptual Captions2018.07 · 数据·评测
    COCO 人工描述规模和多样性有限，CC3M 用网页 alt 文本自动获得大一个数量级的图文对。
  • 改进
    Open Images2018.11 · 数据·评测
    把检测数据从 COCO 的规模放大约一个量级并扩展类别。
  • 延续
    nocaps2018.12 · 数据·评测
    COCO 的词汇有限，nocaps 测试在 COCO 训练条件下对未见类别的描述。
  • 改进
    LVIS2019.08 · 数据·评测
    沿用COCO的实例分割任务与图像，类别从80个扩展到上千个并呈长尾分布。
  • 使用
    POPE物体幻觉2023.05 · 数据·评测
    正负例都基于COCO图片及其物体标注构造。

读懂它需要的概念

监督学习 卷积运算 训练集、验证集与测试集

本篇术语

  • 实例分割　不仅标出图中有什么物体，还要用像素轮廓区分同一类的不同个体。

怎么学

用pycocotools加载标注，画出一张图的所有实例轮廓，再读评测说明理解AP@[.5:.95]。
