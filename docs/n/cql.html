离线强化学习CQL

Conservative Q-Learning for Offline Reinforcement Learning
2020.06论文延伸NeurIPS 2020Kumar, Zhou, Tucker, Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL里，普通的离策略方法会因为分布偏移高估数据中没出现的动作的Q值，导致学到的策略很差。

方法

学一个保守的Q函数：在标准的贝尔曼误差之外加一个正则项，压低数据中未出现动作的Q值、保持数据中动作的Q值，使策略的估计值成为真实值的下界。

影响

成为最常用的离线RL基线之一，在D4RL离线RL基准上被广泛比较。

方法

具体做法是在Q学习的损失上加一项：α·(E_{a∼μ}[Q(s,a)] − E_{a∼数据}[Q(s,a)])，前者是在某个分布μ（例如当前策略）下对Q取期望，后者是数据中动作的Q期望。最小化这项相当于「把所有动作的Q压低，同时把数据里动作的Q抬回去」，所以数据外动作被惩罚。论文从理论上证明了策略在这个Q下的期望值是其真实值的下界，并给出带改进保证的策略学习过程。

它的实现是在SAC或DQN（Nature版）上增加几行代码。摘要称在离散和连续动作域上的实验中，它在复杂多模态数据分布下，通常比已有离线方法高2到5倍的最终回报（此数字来自摘要的概述性描述）。

局限与后续

  • 保守系数α对数据集很敏感，需要调参，且在数据较好时可能过于保守。
    后来针对它的工作　隐式Q学习IQL
  • 每一步还要估计数据外动作分布的期望，计算开销增加。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    DQN2013.12 · RL
  • 使用
    DQN（Nature版）2015.02 · RL
    离散动作情形在DQN式的Q学习上实现。
  • 改进
    BCQ批量约束Q学习2018.12 · RL
    BCQ只用生成模型限制动作范围；CQL直接在价值函数层面惩罚数据外动作，不需要显式建模行为策略。
  • 使用
    SAC2018.01 · RL
    连续动作情形在SAC上实现。
  • 改进
    致命三元组2018.12 · RL
    没有给出保证不发散的充分条件，只给出了经验趋势。

后来的相关工作

  • 竞争
    Decision Transformer2021.06 · RL
    CQL代表基于值函数的离线RL；DT不学Q函数，只做条件序列建模，在D4RL平均分上超过当时的CQL。
  • 竞争
    robomimic2021.08 · 具身·世界模型
    把CQL放到真人示范上系统测试，发现它在机器数据上可用、在真人数据上几乎学不会，挑战了离线RL基准上的结论。
  • 竞争
    隐式Q学习IQL2021.10 · RL
    CQL通过惩罚数据外动作的Q值保持保守；IQL完全不查询数据外动作，总分更高、训练快约4倍。
  • 竞争
    TD3+BC极简离线RL2021.06 · RL
    CQL等需要额外的保守项和更复杂的训练；TD3+BC用一行改动取得相近成绩，且更快。
  • 使用
    JOWA世界-动作模型2024.10 · 具身·世界模型
    在离线数据上学习时借鉴保守性思想。
