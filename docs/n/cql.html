离线强化学习CQL

Conservative Q-Learning for Offline Reinforcement Learning
2020.06论文延伸NeurIPS 2020Kumar, Zhou, Tucker, Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL里，普通的离策略方法会因为分布偏移高估数据中没出现的动作的Q值，导致学到的策略很差。

方法

学一个保守的Q函数：在标准的贝尔曼误差之外加一个正则项，压低数据中未出现动作的Q值、保持数据中动作的Q值，使策略的估计值成为真实值的下界。

影响

成为最常用的离线RL基线之一，在D4RL离线RL基准上被广泛比较。

方法

具体做法是在Q学习的损失上加一项：α·(E_{a∼μ}[Q(s,a)] − E_{a∼数据}[Q(s,a)])，前者是在某个分布μ（例如当前策略）下对Q取期望，后者是数据中动作的Q期望。最小化这项相当于「把所有动作的Q压低，同时把数据里动作的Q抬回去」，所以数据外动作被惩罚。论文从理论上证明了策略在这个Q下的期望值是其真实值的下界，并给出带改进保证的策略学习过程。

它的实现是在SAC或DQN（Nature版）上增加几行代码。摘要称在离散和连续动作域上的实验中，它在复杂多模态数据分布下，通常比已有离线方法高2到5倍的最终回报（此数字来自摘要的概述性描述）。

局限与后续

  • 保守系数α对数据集很敏感，需要调参，且在数据较好时可能过于保守。
    后来针对它的工作　隐式Q学习IQL
  • 每一步还要估计数据外动作分布的期望，计算开销增加。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    DQN2013.12 · RL
  • 使用
    DQN（Nature版）2015.02 · RL
    离散动作情形在DQN式的Q学习上实现。
  • 改进
    BCQ批量约束Q学习2018.12 · RL
    BCQ只用生成模型限制动作范围；CQL直接在价值函数层面惩罚数据外动作，不需要显式建模行为策略。
  • 使用
    SAC2018.01 · RL
    连续动作情形在SAC上实现。
  • 改进
    致命三元组2018.12 · RL
    没有给出保证不发散的充分条件，只给出了经验趋势。
  • 改进
    BEAR自举误差约束2019.06 · RL
    需要先拟合一个行为策略来采样比较，行为策略本身估不准时约束也会失效。
  • 改进
    REM与DQN回放数据集2019.07 · RL
    结论依赖于数据非常大且多样；后续研究发现在窄分布或少量数据上，REM仍会出现明显的外推误差。
  • 改进
    BRAC行为正则化2019.11 · RL
    需要先估计行为策略π_b，数据来自多个策略或分布多峰时估计不准，散度惩罚也随之失真。
  • 改进
    AWAC优势加权2020.06 · RL
    纯离线时，critic仍会查询数据外动作的Q值，有外推误差，在D4RL某些数据集上表现不如专门的离线方法。

后来的相关工作

  • 竞争
    Decision Transformer2021.06 · RL
    CQL代表基于值函数的离线RL；DT不学Q函数，只做条件序列建模，在D4RL平均分上超过当时的CQL。
  • 竞争
    robomimic2021.08 · 具身·世界模型
    把CQL放到真人示范上系统测试，发现它在机器数据上可用、在真人数据上几乎学不会，挑战了离线RL基准上的结论。
  • 竞争
    隐式Q学习IQL2021.10 · RL
    CQL通过惩罚数据外动作的Q值保持保守；IQL完全不查询数据外动作，总分更高、训练快约4倍。
  • 延续
    PEVI悲观值迭代2020.12 · RL
    为CQL等经验方法所用的“压低不确定动作价值”的悲观原则提供理论依据。
  • 延续
    COMBO保守模型离线优化2021.02 · RL
    把CQL的保守正则推广到模型生成的状态-动作上，得到更紧的价值下界。
  • 竞争
    MuZero Unplugged与重分析2021.04 · RL
    CQL靠悲观的Q值正则处理离线RL的分布外问题；MuZero Unplugged不做专门改造，只靠基于模型的搜索改进。
  • 竞争
    UWAC不确定性加权2021.05 · RL
    CQL统一压低分布外动作Q值；UWAC降低不确定样本的训练权重。
  • 竞争
    OptiDICE分布修正离线优化2021.06 · RL
    CQL靠压低分布外动作的Q值防高估；OptiDICE不学Q函数，从原理上避开这个问题。
  • 竞争
    TD3+BC极简离线RL2021.06 · RL
    CQL等需要额外的保守项和更复杂的训练；TD3+BC用一行改动取得相近成绩，且更快。
  • 竞争
    EDAC/SAC-N集成离线RL2021.10 · RL
    CQL要显式采样分布外动作并压低其Q值；EDAC改用集成分歧隐式惩罚，不需要采样。
  • 使用
    d3rlpy离线RL库2021.11 · RL
    实现CQL等主流离线RL算法。
  • 竞争
    PBRL悲观自举离线RL2022.02 · RL
    CQL压低所有分布外动作；PBRL按不确定性大小有区别地惩罚。
  • 改进
    MCQ温和保守Q学习2022.06 · RL
    CQL一律压低分布外动作导致过度保守；MCQ只把它们限制在数据内最好动作的水平。
  • 延续
    Cal-QL校准离线预训练2023.03 · RL
    在CQL的保守正则上加一个下限，只改一行代码。
  • 竞争
    IVR隐式价值正则（SQL/EQL）2023.03 · RL
    CQL显式压低分布外动作的Q值；IVR只用数据内样本，不查询分布外动作。
  • 使用
    ReST强化自训练2023.08 · LLM
    Improve阶段可以接入离线强化学习损失，作者比较了行为克隆与多种离线RL目标。
  • 使用
    Q-Transformer自回归Q函数2023.09 · RL
    加入CQL式的保守正则，压低数据外动作档的Q值。
  • 使用
    JOWA世界-动作模型2024.10 · 具身·世界模型
    在离线数据上学习时借鉴保守性思想。
