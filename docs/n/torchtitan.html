TorchTitan

TorchTitan: One-stop PyTorch native solution for production ready LLM pre-training
2024.10论文延伸ICLR 2025Liang, Liu, Wright, Constable, Gu, Huang, Zhang, Feng et al. · Meta待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型预训练的各种并行与优化技术分散在不同代码库，互不兼容、难维护，对比不同训练配方要花大量工程精力。

方法

PyTorch原生的一站式预训练系统：模块化组合3D并行，带弹性扩展、日志、检查点和调试工具，并集成Float8等软硬协同方案。

影响

提供了易读、可改的开源参考实现，降低研究者复现大规模训练配方的门槛。

方法

TorchTitan以PyTorch原生的组件构建：PyTorch FSDP负责参数切分，张量并行、流水线并行、上下文并行可以按需叠加，形成Megatron 3D并行式的多维并行，并支持弹性扩展。它包含完整的生产功能：分布式检查点、日志、故障调试。同时集成Float8训练和SymmetricMemory等硬件协同特性。作者用它为Llama 3.1（8B到405B）开发优化的训练配方，并给出选择技术组合的经验。

局限与后续

  • 面向PyTorch生态，对其他框架的模型和算法需要自行适配。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 万卡级的故障诊断与掉队处理不如专用系统完整。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    PyTorch2017.01 · 系统·效率 待核对
    初版只提供基本的多进程与通信原语，模型大到单卡放不下时的模型并行和参数切分需要用户自己实现。
  • 改进
    PyTorch 2与torch.compile2023.03 · 系统·效率
    编译只覆盖单进程内的计算图，与分布式训练的切分、通信重叠等组合起来仍需手工处理。
  • 延续
    Megatron 3D并行2021.04 · 系统·效率
    把3D并行做成PyTorch原生、模块化的实现，而非Megatron专用代码。
  • 使用
    PyTorch FSDP2023.04 · 系统·效率
    参数切分直接使用PyTorch FSDP。
  • 改进
    Unsloth2023.12 · 系统·效率
    面向单卡或少量卡的场景，大规模多机训练不是它的目标。
  • 改进
    MegaScale万卡训练与容错2024.02 · 系统·效率
    方案深度绑定字节的集群与网络，代码未完整开源，难以复现。
  • 改进
    llm.c2024.04 · 系统·效率
    规模停留在小模型的复现，不是多机大模型训练系统。

读懂它需要的概念

分布式训练：数据并行与模型并行 参数量、计算量与显存 显存、内存带宽与“内存墙” 浮点精度：FP32、FP16、BF16、INT8 互连：从芯片到机柜到集群

怎么学

先学数据并行和FSDP → 读论文第3节并行组合与第4节Llama 3.1配方 → 跑官方仓库的Llama示例。
