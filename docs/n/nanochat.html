nanochat

2025.10系统延伸Andrej Karpathy待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

想完整理解ChatGPT类产品是怎么做出来的，需要分散的代码：分词、预训练、微调、评测、推理各自一套，没有一个小而完整的参考。

方法

一个极简、可改的全流程代码库：在单个GPU节点上完成分词、预训练、微调、评测和对话界面。

影响

让个人以很低的成本走完「从零训练一个能聊天的模型」的全过程，成为教学和实验的基础。

方法

README称nanochat是训练LLM的最简实验平台：设计为单GPU节点运行，代码极简易改，覆盖LLM的主要阶段，包括分词、预训练、微调、评测、推理。它只有一个复杂度旋钮--depth（Transformer层数），其余超参数按它自动设置，从而一次训练出一整个计算最优的模型系列。它是nanoGPT的延伸，并吸收了modded-nanogpt速通速通中的训练技巧。

结果

README当前称：达到GPT-2能力的模型（2019年训练成本约4.3万美元）如今约8块H100训练两小时、花费约48美元即可（按现货实例约15美元）。这是README撰写时的状态，随版本更新，不是首发时的数字。

局限与后续

  • 模型规模只到GPT-2能力级别，与当前前沿模型差距很大。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 极简代码为了可读性，没有包含大规模训练所需的容错和多机并行。
    本站还没有记录针对它的后续工作（不代表没有人解决）
