HLBL层次语言模型

A Scalable Hierarchical Distributed Language Model
2008.12论文延伸NeurIPS 2008Andriy Mnih, Geoffrey Hinton · 多伦多大学待核对
NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

神经语言模型每预测一个词都要对整个词表做归一化，训练和测试都极慢；Morin和Bengio的二叉树层次模型快了两个数量级，但效果明显变差，而且词树要靠WordNet等专家知识来建。

方法

把对数双线性语言模型放到一棵词的二叉树上，每个内部节点做一次二分类；词树不靠专家知识，而是用模型学到的词向量自动递归聚类得到，并允许一个词出现在树的多个位置。

影响

层次模型第一次在困惑度上超过不分层的神经模型和最好的n-gram模型，说明慢的问题可以用树结构解决而不必牺牲效果；从数据中建树的思路后来被word2vec的哈夫曼树层次softmax等沿用。

方法

层次softmax语言模型的思路是：把词表里的词放在一棵二叉树的叶子上，预测一个词等于从根走到这个叶子，每经过一个内部节点就做一次「往左还是往右」的二分类，于是一次预测只需约log₂V次运算而不是V次（V是词表大小）。但Morin和Bengio用的树来自WordNet，和语言模型本身的需要不一致，困惑度比不分层的神经概率语言模型差不少。

这篇把树上的每个二分类器换成对数双线性语言模型的形式：用上下文词向量线性组合出一个「预测向量」，再和内部节点的向量做点积，经过sigmoid得到往某一边走的概率。关键改进在于树从数据里学：先用随机树训练一个模型得到词向量，再把词向量按两个高斯的混合模型递归地一分为二，构成新树后重新训练；还允许一个多义词出现在多个叶子上，词的概率是几条路径之和。

摘要称，这样得到的层次模型在速度上保持层次结构的优势，困惑度则能超过不分层的神经模型和最好的n-gram模型。

局限与后续

  • 建树需要先训练一遍模型拿到词向量再聚类，流程是两阶段的，树一旦固定，预测效果就受树的质量约束。
    后来针对它的工作　Skip-gram负采样
  • 仍然只用固定长度的前几个词作上下文，无法利用更长的历史。
    后来针对它的工作　RNN语言模型

它建立在什么之上

  • 改进
    神经概率语言模型2003.02 · NLP
    针对神经概率语言模型训练和测试都要对全词表归一化的速度瓶颈。
  • 竞争
    Brown聚类1992 · NLP
    Brown聚类也是自底向上把词组织成二叉树，但依据是n-gram互信息；HLBL用连续词向量的高斯混合做自顶向下的划分。
  • 改进
    层次softmax语言模型2005 · NLP
    Morin和Bengio的层次模型依赖WordNet建树、效果明显变差；HLBL改为从学到的词向量自动建树，效果反超不分层的模型。
  • 延续
    对数双线性语言模型2007.06 · NLP
    把同一作者2007年的对数双线性语言模型搬到二叉树的每个内部节点上，做成层次版本。

后来的相关工作

  • 改进
    RNN语言模型2010.09 · NLP
    仍然只用固定长度的前几个词作上下文，无法利用更长的历史。
  • 改进
    Skip-gram负采样2013.10 · NLP
    建树需要先训练一遍模型拿到词向量再聚类，流程是两阶段的，树一旦固定，预测效果就受树的质量约束。
  • 竞争
    NCE训练语言模型2012.06 · NLP
    同一作者之前用词树加速；NCE不需要建树，直接在原始输出层上训练。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

语言模型 Softmax与logits 嵌入向量 困惑度 时间与空间复杂度 聚类

本篇术语

  • 预测向量　对数双线性模型里由上下文各词的向量各乘一个矩阵后相加得到的向量，用来和候选词（或树节点）的向量做点积打分。

怎么学

先读层次softmax语言模型和对数双线性语言模型的讲解 → 读原文第3–4节层次模型的定义和建树算法 → 动手：用一个小语料，比较随机树、按词频建的哈夫曼树和按词向量聚类的树训练出来的层次softmax困惑度。
