DRMM深度相关性匹配

A Deep Relevance Matching Model for Ad-hoc Retrieval
2016.10论文延伸CIKM 2016Jiafeng Guo（郭嘉丰）, Yixing Fan, Qingyao Ai, W. Bruce Croft · 中国科学院计算技术研究所、马萨诸塞大学阿默斯特分校待核对
arXiv ↗DOI ↗在交互版中打开（演化树、学习进度）

问题

深度学习在语音、视觉和许多NLP匹配任务上大获成功，但直接搬到即席检索上，DSSM一类深度匹配模型往往打不过BM25和查询似然这些传统模型。

方法

指出检索需要的是「相关性匹配」而非「语义匹配」：要重视精确匹配信号、区分查询词的重要性、允许文档只在局部与查询相关；为此对每个查询词计算它与文档所有词的相似度直方图，再用门控网络按词重要性加权求和。

影响

在Robust04等经典测试集上显著超过传统检索模型和当时的深度匹配模型，是BERT之前最有影响的神经即席检索模型之一，「相关性匹配vs语义匹配」的区分也成为神经检索研究的基本框架。

背景

DSSM深度语义匹配等模型把查询和文档各自压成一个向量再算相似度，在短文本匹配（复述识别、问答、点击日志）上效果不错。但即席检索（ad-hoc retrieval：给一个短查询，从大量长文档中找出相关的）里，这些模型常常输给BM25和语言模型检索（查询似然）。作者认为原因在于任务性质不同：复述识别要判断两段文字整体意思是否一样，而检索里，文档只要有一部分与查询相关就算相关，查询词是否原样出现是极强的信号，不同查询词的重要性也差别很大（「的」与「量子」）。

方法

DRMM在查询词层面上做匹配，结构分三部分：

匹配直方图映射。 对查询词 q_i，计算它的词向量与文档中每个词 d_j 的余弦相似度，得到一个长度等于文档长度的相似度列表。把[−1, 1]分成若干个桶，单独留一个桶给相似度恰为1的精确匹配，统计落在每个桶里的数量，得到一个定长直方图 x_i。直方图丢掉了词的位置，但保留了「有多少词完全匹配、多少词比较像、多少词不相关」这一信息。论文比较了直接计数、归一化计数和取对数计数三种形式，对数计数效果最好。

前馈匹配网络。 一个多层感知机把直方图 x_i 映射成这个查询词的匹配分 z_i = FFN(x_i)。

词门控网络。 用一个softmax在查询词之间分配权重 g_i = exp(w·v_i) / Σ_k exp(w·v_k)，v_i 可以是查询词的词向量或它的IDF。最终得分 s(q, d) = Σ_i g_i · z_i。

训练用成对的铰链损失：对同一查询，相关文档的得分要比不相关文档高出一个间隔。

结果

摘要称，在两个有代表性的基准集合上（论文中为Robust04和ClueWeb-09-Cat-B），DRMM显著超过若干知名的传统检索模型和当时最好的深度匹配模型。

后来的发展

DRMM之后，K-NRM（2017）用可微的核池化代替硬直方图，PACRR、Conv-KNRM等加入了位置和n-gram匹配；MatchZoo工具包把这些模型统一实现。2019年起BERT重排序等基于BERT的重排序模型大幅超过它们，但精确匹配和查询词权重的重要性在SPLADE学习式稀疏检索、ColBERT后期交互等后续模型中仍被反复验证。

局限与后续

它建立在什么之上

  • 使用
    word2vec2013.01 · NLP
    用预训练的词向量计算查询词与文档词之间的余弦相似度。
  • 改进
    BM251994 · NLP
    BM25只能利用精确匹配，DRMM在保留精确匹配信号的同时用词向量计入相近词的软匹配。
  • 改进
    检索语言模型的平滑2001.09 · NLP
    只改进了文档模型的估计，仍假设查询词相互独立、只按字面匹配，词汇不匹配（同义词、改写）问题没有解决。
  • 竞争
    语言模型检索（查询似然）1998.08 · NLP
    以查询似然等传统模型为主要基线，并在实验中显著超过它们。
  • 改进
    DFR偏离随机性模型2002.10 · NLP
    和BM25一样只依赖词频统计和精确匹配，无法处理同义词、改写等词汇不匹配。
  • 竞争
    DSSM深度语义匹配2013.10 · NLP
    DSSM把查询和文档各压成一个向量做语义匹配，DRMM认为检索应做逐词的相关性匹配，并在即席检索上胜出。

后来的相关工作

  • 改进
    K-NRM核池化神经排序2017.06 · NLP
    用可导的高斯核软计数替代DRMM不可导的直方图分桶，使词向量能按排序目标端到端训练。
  • 改进
    BERT重排序2019.01 · 推理·智能体
    依赖预训练的静态词向量，同一个词在不同上下文中的意义无法区分。

读懂它需要的概念

嵌入向量 多层感知机 Softmax与logits 检索与向量数据库 损失函数

本篇术语

  • 即席检索（ad-hoc retrieval）　用户临时给一个查询，系统从固定文档集合中排出相关文档，TREC经典任务。
  • 相关性匹配　判断文档是否满足查询的信息需求，重视精确匹配、词重要性和局部相关；与判断两段话意思是否相同的语义匹配相对。
  • 匹配直方图　把一个查询词与文档所有词的相似度按区间计数得到的定长向量。

怎么学

先懂BM25和DSSM深度语义匹配 → 读原文第3节对两类匹配的区分和第4节模型结构 → 动手：用MatchZoo或自写代码在一个小检索集合上复现DRMM，并比较去掉门控网络或只用精确匹配桶时的效果。
