pandas表格数据处理

Data Structures for Statistical Computing in Python
2010.06系统延伸SciPy 2010Wes McKinney待核对
SciPy Proceedings ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

NumPy擅长同质的数值数组，但金融、统计里的数据是带行列标签、混合类型、有缺失值的表格，在Python里处理这类数据远不如R方便。

方法

提供带标签索引的Series和DataFrame两种数据结构，把按标签对齐、缺失值处理、分组聚合、合并与时间序列操作做成现成的构件。

影响

成为Python里读写和清洗表格数据的默认工具，机器学习项目从加载CSV到构造特征，绝大多数都会经过pandas。

方法

NumPy与SciPy的数组要求同一种数据类型、靠整数位置访问。真实的数据表则是一列日期、一列字符串、几列浮点数，还常有缺失；做统计时要按日期或股票代码对齐两张表。R语言的data.frame早就支持这些，Python里却要手写大量循环和字典。

作者当时在一家量化投资公司工作，为此写了pandas，论文在SciPy 2010会议上介绍它的设计。核心是两个结构：Series（一维数组加一个索引）和DataFrame（共享同一行索引的多列，每列可以是不同类型）。运算时按索引标签自动对齐，对不上的位置填缺失值NaN；在此之上提供分组-聚合（group by）、按键合并（merge/join）、层次化索引和时间序列重采样等操作，底层仍然用NumPy数组存数据以保证速度。论文还专门把这些设计与R语言做了对照。

今天的典型流程是：pandas读入CSV或数据库表，清洗后转成NumPy数组交给scikit-learn或深度学习框架。它的局限也很常见：单机内存装不下的数据要换用Spark、Polars等工具。
