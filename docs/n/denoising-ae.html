去噪自编码器

Extracting and Composing Robust Features with Denoising Autoencoders
2008.07论文延伸ICML 2008Vincent, Larochelle, Bengio, Manzagol · Université de Montréal待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

普通自编码器只要容量够大就能把输入原样复制，学不出有用的特征；逐层预训练里的RBM又很难训练。

方法

故意破坏输入（随机把一部分像素置零），再让自编码器从被破坏的输入还原出干净原样，网络必须学会数据内部的结构才能做到。

影响

提出了“加噪再去噪”这一自监督思路，后来的掩码建模、扩散模型都用同一类目标；堆叠版本是深度网络无监督预训练的主要方法之一。

方法

训练时对每个输入x随机破坏，得到x̃（例如以一定概率把像素置0），编码器h = f(x̃)，解码器x̂ = g(h)，损失仍是与干净输入x的重构误差。要还原被掩去的部分，网络必须利用其余输入之间的统计依赖，不可能靠恒等映射。

论文把它叠起来：先训练第一层去噪自编码器，用得到的隐层表示作为输入训练第二层，如此逐层预训练，再接分类器微调，叫堆叠去噪自编码器。他们从多个角度解释：流形学习（噪声样本被拉回数据流形）、信息论和生成模型。

论文称，在多个图像分类基准上，堆叠去噪自编码器学到的特征与深度信念网络相当甚至更好，而训练更简单。（具体数字未在本次会话核对，故不引用。）
