MedMCQA医学选择题

MedMCQA : A Large-scale Multi-Subject Multi-Choice Dataset for Medical domain Question Answering
2022.03数据集延伸CHIL 2022Ankit Pal, Logesh Kumar Umapathi, Malaikannan Sankarasubbu · Saama AI Research（印度金奈）待核对
arXiv ↗项目主页与排行榜 ↗在交互版中打开（演化树、学习进度）

问题

医学问答数据集要么规模小，要么题目来源单一；需要一套题量大、覆盖科目广、按真实考试划分、带解析的医学多选题。

方法

收集印度研究生医学入学考试AIIMS PG和NEET PG的四选一真题与模拟题，共19.4万多道，覆盖21个科目、2,400个主题，每题附解析。

影响

与MedQA、PubMedQA一起被Med-PaLM收进MultiMedQA，成为医学大模型报告里的常见指标；Flan-PaLM在其开发集上达到57.6%。

方法

题目。来自印度AIIMS PG与NEET PG两类研究生医学入学考试，以及模拟考和在线题库，全部是四选一，覆盖解剖、药理、病理、外科等21个科目、约2,400个主题。每题附有正确答案和一段解析。清洗时删去了选项数不是四个的题、缺答案的题，以及依赖图片或表格的题。

按考试划分。训练集是全部模拟考和在线题库题，开发集是NEET PG真题（2001年至今），测试集是AIIMS PG真题（1991年至今）。为防止近似重复题从训练集泄漏到开发和测试集，作者计算每对题目的Levenshtein相似度，相似度超过0.9的题不进入开发和测试集。最终训练约183K、开发约6K、测试约4K题。

基线。作者微调BERT、BioBERT、SciBERT、PubMedBERT四种基础规模的模型，并测试从维基百科或PubMed检索段落再作答的做法。

结果

最好的基线（PubMedBERT加PubMed检索）测试集准确率约47%，而这些考试中成绩优秀的考生平均约90%。Med-PaLM论文报告Flan-PaLM 540B在开发集上达到57.6%，高于此前Galactica的52.9%。

后来的发展

MedMCQA的训练集有约18万题，比同类医学考试集大得多。Med-PaLM把它与MedQA、PubMedQA、MMLU临床科目一起组成MultiMedQA，Med-PaLM 2等后续医学大模型也沿用这一组合报告成绩。Med-PaLM报告的是开发集成绩，而原论文的基线同时给了测试集和开发集，读数字时要注意是哪个划分。

局限与后续

  • 四选一的随机基线就有25%，而且只考知识回忆和选择，不考临床对话、病情追问和长文回答。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    基线全部是BERT及其科学、生物医学领域变体（SciBERT、BioBERT、PubMedBERT）的微调。
  • 竞争
    MMLU2020.09 · 数据·评测
    MMLU把医学当作57个学科中的几科做通识考试；MedMCQA专攻医学，题量大两个数量级并按真实考试划分。

本篇术语

  • AIIMS PG / NEET PG　印度两类研究生医学入学考试，前者由全印医学科学研究所组织；MedMCQA分别用它们的真题作测试集和开发集。

怎么学

先读MMLU了解多选知识考试的评测方式。读原文第2节（数据来源与按考试划分）和表4。动手：在开发集上用一个开源小模型做零样本四选一，按科目统计准确率，看哪些科目最弱。
