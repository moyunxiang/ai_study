UWAC不确定性加权

Uncertainty Weighted Actor-Critic for Offline Reinforcement Learning
2021.05论文延伸ICML 2021Yue Wu, Shuangfei Zhai, Nitish Srivastava, Joshua Susskind, Jian Zhang, Ruslan Salakhutdinov, Hanlin Goh · CMU / Apple待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL中，Q学习和演员-评论家从分布外的状态或动作上自举时会失败；已有方法主要约束策略，却没有对“哪些样本的目标值不可信”做恰当的不确定性处理。

方法

用MC Dropout估计Q值的不确定性，在评论家和演员的损失里按不确定性的倒数给每个样本加权：越可能是分布外的样本，对训练的贡献越小（UWAC）。

影响

较早把认知不确定性加权引入离线演员-评论家的方法之一，与后来的EDAC、PBRL同属“基于不确定性的离线RL”，常出现在这类方法的对比表中。

方法

UWAC（Uncertainty Weighted Actor-Critic）建立在BEAR自举误差约束的演员-评论家框架上，加了一个不确定性加权：

  • 不确定性估计：Q网络里带dropout，在计算目标时对同一个 (s′, a′) 做多次带dropout的前向（即MC Dropout不确定性），用这些输出的方差 Var[Q(s′, a′)] 作为认知不确定性的估计。数据覆盖充分的地方方差小，分布外的地方方差大；
  • 加权的评论家损失：

L_Q = E[ (β / Var[Q(s′, a′)]) · (Q(s, a) − (r + γ Q̄(s′, a′)))² ]

目标值越不可信，这条样本的权重越低，从而减少分布外动作的自举误差对Q的污染；

  • 加权的演员损失：策略更新时同样按 β / Var[Q(s, a)] 对 Q(s, π(s)) 加权，抑制策略被不确定的高Q值吸引。

作者称dropout式不确定性估计相对原算法只增加很少开销。摘要称UWAC显著提升了训练稳定性，在多个任务上超过已有离线RL方法，并在只有少量人类专家示范的稀疏数据集上相对当时最好的基线有明显提升。

局限与后续

  • MC Dropout给出的不确定性往往偏小且校准不佳，在高维连续动作下对分布外区域的识别不够可靠。
    后来针对它的工作　EDAC/SAC-N集成离线RL PBRL悲观自举离线RL
  • 加权系数β和dropout概率需要调，权重过度时会让大部分样本几乎不参与训练。
