MuSR多步软推理

MuSR: Testing the Limits of Chain-of-thought with Multistep Soft Reasoning
2023.10数据集延伸ICLR 2024Zayne Sprague, Xi Ye, Kaj Bostrom, Swarat Chaudhuri, Greg Durrett · 得克萨斯大学奥斯汀分校待核对
arXiv ↗Open LLM Leaderboard说明（MuSR为六项之一） ↗在交互版中打开（演化树、学习进度）

问题

逻辑推理类基准多是固定的、模板化的短题，模型能力一涨就被刷满；真实推理又往往藏在长篇叙述里，需要结合常识做“软”推断，而不是严格的形式逻辑。

方法

用神经符号的“先合成再自然化”算法生成约1000词的叙事题（谋杀悬疑、物品放置、团队分配），难度可以随模型变强继续调高，人类仍能高准确率解出。

影响

被Hugging Face选为Open LLM Leaderboard第二版的六项基准之一，成为检验思维链在长叙事多步推理上是否可靠的常用题集。

方法

MuSR（Multistep Soft Reasoning）的每道题是一段自然语言故事，答案要靠多步推理从故事里推出来，且每一步都需要常识，例如“谁有作案动机、机会和手段”。

生成方法。作者先用符号化的方式构造推理结构：确定答案，再展开成一棵由事实和推理步骤组成的树，然后让大模型把树上的叶子事实写进一段流畅的叙事里。这样得到的故事既有可靠的标准答案，又是自然文本，而不是模板拼出来的句子；需要更难的题时，可以把推理树做得更深。

三个领域。谋杀悬疑（故事长约1000词）、物品放置（追踪人物看到的东西被挪到了哪里，考察心智理论式的信念推理）和团队分配（根据人物的能力和关系安排任务）。

作者用多种模型和提示方法评测，结论是思维链CoT等技术在这类稳健的多步推理上仍有明显差距；题目足以难住GPT-4，而人类标注者能以高准确率解答。2024年Hugging Face的Open LLM Leaderboard第二版把它与BIG-Bench Hard、GPQA、IFEval等并列为六项评测之一。

局限与后续

  • 题目由大模型写成叙事，可能带有生成模型特有的文风和漏洞，且只有三个领域。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    思维链CoT2022.01 · 推理·智能体
    论文的核心问题就是检验思维链提示在长叙事多步推理上的极限。
  • 使用
    GPT-42023.03 · LLM
    用GPT-4参与生成叙事，也把它作为最强被测模型，题目设计成足以难住它。
  • 竞争
    BIG-Bench Hard2022.10 · 数据·评测
    BBH中的逻辑推理题是固定的短题，MuSR改用可扩展生成的长叙事，难度可随模型能力继续提升。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
