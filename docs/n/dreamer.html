Dreamer

Dream to Control: Learning Behaviors by Latent Imagination
2019.12论文重要ICLR 2020Danijar Hafner, Timothy Lillicrap, Jimmy Ba, Mohammad Norouzi · Google Brain / DeepMind / 多伦多大学来源已核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

从像素学控制的无模型RL要上亿步交互；PlaNet用学到的世界模型做在线规划，省数据，但每一步都要现场搜索，而且只看得到十几步之内的奖励，长远目标顾不上。

方法

在世界模型的紧凑隐空间里“做梦”：从真实状态出发想象15步轨迹，同时学一个价值函数估计想象之外的回报，再把价值的梯度沿着可微的想象轨迹直接反传给策略。

影响

在20个视觉控制任务上用500万步达到平均823分，高于无模型的D4PG用1亿步的786分；之后的DreamerV2、V3沿用了“在想象中学行为”这一框架。

背景

2019年，从图像学连续控制有两条路。无模型方法（如DDPG的改进版D4PG）直接用试错数据训练策略，效果好但要上亿步交互。基于模型的方法（见基于模型的强化学习）先学一个预测环境的模型，再在模型里规划：World Models用VAE把图像压成隐向量、用RNN预测下一步，在“梦里”训练一个很小的控制器；PlaNet学到了更好的隐空间动态模型（RSSM），每一步用CEM在模型里搜索最优动作序列。

PlaNet省数据，但有两个问题：每次行动都要做一次搜索，计算慢；只在固定的规划长度（比如十几步）里累加奖励，超出这个范围的后果看不见，需要长远规划的任务就做不好。

方法

世界模型（沿用PlaNet的RSSM）。编码器把每帧图像压成一个隐状态 s_t；转移模型根据 s_t 和动作 a_t 预测 s_{t+1}；奖励模型从 s_t 预测奖励；解码器从 s_t 重建图像，用来训练表示（目标类似变分推断与ELBO）。

在想象中学策略（见Actor-Critic与优势函数）。从真实数据里取一批隐状态作起点，用当前策略和转移模型往前“想象” H=15 步，全程不碰真实环境，也不生成图像。在想象的轨迹上学两个网络：

  • 价值网络 v(s)：拟合λ-回报 V_λ——把1步、2步……H步的回报估计（前几步用预测的奖励累加，最后接上 v 的估计）按 λ=0.95 指数加权平均。这样15步之外的回报也被算进来了。
  • 策略网络：目标是让想象轨迹上的 V_λ 尽量大。因为转移模型、奖励模型都是可微的神经网络，可以用重参数化技巧把动作采样写成可导的形式，直接把 V_λ 对策略参数求梯度、沿整条想象轨迹反传（见反向传播）。

循环：用策略在真实环境里采一点数据 → 更新世界模型 → 在想象里更新策略和价值，反复进行。

结果

DeepMind Control Suite（DeepMind Control Suite）的20个像素输入任务上，交互500万步后平均823分；PlaNet同样步数下332分，无模型的D4PG用1亿步为786分。单块V100上每100万步约训练3小时，PlaNet要11小时。论文还显示，有了价值函数后，Dreamer对想象长度H更稳健，H较短时也表现良好；不学价值函数的变体对H更敏感。

后来的发展

DreamerV2把隐状态换成离散类别变量，论文称它是第一个在单独训练的世界模型中学行为、在55个Atari游戏上达到人类水平的智能体；DreamerV3用一套固定超参数在150多个任务上超过各领域的专用方法，并在Minecraft里从零挖到钻石；Dreamer 4又把世界模型换成了可扩展的Transformer视频模型。

    后来针对它的工作　DreamerV2

它建立在什么之上

  • 改进
    卡尔曼滤波1960 · 具身·世界模型 已核对
    要求预先写出准确的动力学模型F、观测模型H和噪声协方差Q、R；观测是图像这类高维数据时，根本写不出H。
  • 延续
    World Models2018.03 · 具身·世界模型 已核对
    论文在相关工作中把World Models描述为两阶段学潜在动态、在想象中进化线性控制器；Dreamer同样在想象中学行为，但改用解析梯度训练的actor-critic，模型与策略交替在线更新。
  • 竞争
    MuZero2019.11 · RL 已核对
    同期的另一种基于模型路线：MuZero的模型不重建画面、只预测奖励和价值并配合树搜索，Dreamer则重建画面、用梯度学策略。Dreamer在相关工作中称MuZero需要大量经验。
  • 竞争
    DDPG2015.09 · RL 已核对
    论文把D4PG称为DDPG的改进版；在20个DMC像素任务上，D4PG用1亿步平均786分，Dreamer用500万步平均823分。
  • 使用
    DeepMind Control Suite2018.01 · RL 已核对
    主实验全部在DeepMind Control Suite的20个像素输入任务上完成。
  • 改进
    PlaNet2018.11 · 具身·世界模型 已核对
    保留PlaNet的RSSM世界模型，但用学到的策略和价值函数代替每步在线CEM规划：价值函数缓解了“只看规划长度内的奖励”的短视问题，也省去了每步现场搜索（论文报告每百万步约3小时对PlaNet的11小时）。
  • 使用
    变分自编码器VAE2013.12 · 生成 待核对
    世界模型的表示学习是VAE式的：重建图像加KL正则的变分目标。
  • 改进
    Dyna：学习与规划合一1990 · RL
    模型、价值和策略都是表格，只适用于能全部枚举的小状态空间；论文自己列为第一条局限。
  • 改进
    POMDP规划1998 · RL
    精确求解代价极高，状态数和观测数超过15左右就不实用，真实问题只能求近似解。
  • 改进
    Schmidhuber可微世界1990 · 具身·世界模型
    没有在高维图像和真实机器人上验证。
  • 改进
    PETS概率集成模型2018.05 · RL
    只在状态维度较低的任务上验证，直接用于像素观测不成立。
  • 改进
    SimPLe与Atari 100k2019.03 · RL
    视频预测误差会在想象轨迹里累积，在需要精细像素细节的游戏里失败。
  • 改进
    MBPO2019.06 · RL
    只在低维状态的连续控制上验证，高维像素观测没有解决。

读懂它需要的概念

基于模型的强化学习 Actor-Critic与优势函数 世界模型 隐变量模型 重参数化技巧 变分推断与ELBO

本篇术语

  • RSSM（循环状态空间模型）　PlaNet提出的隐空间动态模型，每个时刻的状态由一个确定的RNN隐向量和一个随机的隐变量组成，既能记住过去又能表达不确定性。
  • λ-回报　把看1步、2步……n步再接价值估计的多种回报估计按λ的幂次加权平均，在偏差和方差之间折中。
  • 想象（imagination）　不与真实环境交互，只用学到的世界模型往前推演出的虚拟轨迹。

怎么学

先补actor-critic、VAE和重参数化 → 读原文第3节（在想象中学行为）和图4的想象长度实验 → 动手：跑官方开源的DreamerV3代码，在一个DMC任务上可视化世界模型的长程预测。
