Double Q-learning

Double Q-learning
2010论文延伸NIPS 2010van Hasselt · CWI, Amsterdam待核对
NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

Q-learning用对动作值取max来近似最大期望值，这会带来正偏差，在某些随机环境里表现很差。

方法

维护两个独立的Q估计：用一个选动作，用另一个评估这个动作的价值，两者交替更新，消除过高估计。

影响

解释了Q学习的过高估计来自哪里，后来被Double DQN搬到深度网络中，成为DQN系列的标准修正。

方法

问题的来源：对一堆带噪声估计值取最大，期望会高于真实值的最大值。Q学习更新目标里 max_a Q(s′,a) 恰好就是这种取最大，因此会系统性地高估。

双估计器的做法是：有两张表 QA 和 QB。每次更新随机选一张，比如QA，则用QA选出贪心动作 a* = argmax QA(s′,a)，但目标里的价值取QB在这个动作上的值 QB(s′,a*)。因为选择和评估用的是两份不同噪声的估计，偏差消失，摘要称该估计有时反而会低估最大期望值。摘要还称论文证明Double Q-learning收敛到最优策略，并在一些Q学习因过高估计而表现很差的场景里表现良好。

局限与后续

  • 有时会低估，并且需要维护两套表，收敛更慢。

  • 原论文只针对表格式Q学习，没有处理函数近似与深度网络。

它建立在什么之上

  • 改进
    Q-learning1992 · RL
    修正Q学习因取max造成的系统性过高估计。

后来的相关工作

  • 延续
    Double DQN2015.09 · RL
    把表格Double Q-learning的“两套估计、一选一评”搬到深度网络，并用现成的目标网络充当第二套估计。
  • 延续
    TD32018.02 · RL
    沿用“两个独立估计器互相纠偏”的思想，但改成取两者最小值，以适应actor-critic中两个估计不够独立的情况。
  • 延续
    REDQ随机集成双Q2021.01 · RL
    延续用多个独立估计抵消max带来的高估偏差这一思路。
