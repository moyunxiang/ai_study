Torch7

Torch7: A Matlab-like Environment for Machine Learning
2011系统延伸Ronan Collobert, Koray Kavukcuoglu, Clément Farabet · IDIAP / NYU待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

做神经网络研究需要像MATLAB那样好用，又要能跑得快、能用GPU，当时多数选择要么慢要么难用。

方法

以Lua/LuaJIT作脚本语言，底层是高效的C张量库，提供类似MATLAB的张量操作和模块化的神经网络包。

影响

在2013到2016年间是深度学习研究（含Facebook、DeepMind等）的主力框架，其张量库后来成为PyTorch的底层。

方法

Torch7是NIPS BigLearn研讨会上发布的工具：用LuaJIT写前端，核心张量运算和神经网络模块（nn包）用C实现，GPU版本通过cutorch/cunn扩展。用户用 nn.Sequential 拼接层，调用 forward 和 backward 计算输出和梯度，每层手写前向与反向。它不像Theano与自动微分那样先构图再编译，而是命令式的执行，代码接近普通脚本。

优点是灵活、调试方便；缺点是Lua的生态远小于Python。后来Facebook的研究者以它的C张量库为基础，换用Python前端，做出了PyTorch。

局限与后续

  • Lua生态小，缺少数据处理和可视化工具，团队迁移成本高。
    后来针对它的工作　PyTorch
  • 各层的反向传播需手写，没有通用的自动求导。
    后来针对它的工作　autograd：给NumPy求导 PyTorch

它建立在什么之上

  • 竞争
    Theano与自动微分2010.06 · 系统·效率
    Theano先构建符号图再编译，Torch7命令式逐层执行，后者调试更直观，最终PyTorch沿用了后一路线。
  • 延续
    MATLAB1984 · 系统·效率
    刻意模仿MATLAB的张量操作习惯，面向熟悉它的研究者。

后来的相关工作

  • 竞争
    TensorFlow2015.11 · 系统·效率 已核对
    OSDI论文把Torch描述为可细粒度控制执行顺序和内存的命令式框架，TensorFlow则走静态图优化和分布式部署路线；单卡上两者差距在6%以内。命令式路线后来由PyTorch延续。
  • 延续
    PyTorch2017.01 · 系统·效率 已核对
    继承Torch7的张量库与模块化设计，把前端从Lua换成Python，并用引用计数替代Lua垃圾回收管理显存。
  • 竞争
    Caffe2013.12 · 系统·效率
    同期另一主力框架，用Lua脚本写模型更灵活；Caffe以纯配置和C++部署见长。
  • 改进
    autograd：给NumPy求导2015 · 系统·效率
    各层的反向传播需手写，没有通用的自动求导。
