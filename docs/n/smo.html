SMO序列最小优化

Sequential Minimal Optimization: A Fast Algorithm for Training Support Vector Machines
1998.04论文延伸Microsoft Research技术报告 MSR-TR-98-14，1998；收入《Advances in Kernel Methods》John C. Platt · 微软研究院待核对
技术报告PDF ↗书章节（DOI） ↗Wikipedia: Sequential minimal optimization ↗在交互版中打开（演化树、学习进度）

问题

训练支持向量机要解一个变量数等于样本数的二次规划，通用QP求解器在几万个样本上就慢得难以忍受，还要存下巨大的核矩阵。

方法

把大QP拆成一连串最小的子问题：每次只挑两个拉格朗日乘子来优化，这个两变量问题有解析解，不再需要数值QP求解器。

影响

让SVM能在大数据集上训练，后来LIBSVM等主流实现都采用了SMO式的分解思想。

方法

SVM的对偶问题是：在约束 0 ≤ α_i ≤ C 和 Σ α_i y_i = 0 下最大化一个关于乘子α的二次函数，变量个数等于训练样本数。此前的做法是“分块”（chunking），每次取一部分样本交给数值QP求解器，内存和时间开销都随样本数快速增长。

Platt注意到，由于等式约束 Σ α_i y_i = 0 的存在，最少要同时改两个乘子才能保持可行。于是SMO每一步只挑两个乘子α₁、α₂，固定其余所有乘子：这时问题退化成一条线段上的一维二次函数，可以直接写出最优解再裁剪到边界内。挑选哪两个乘子用启发式：外层找违反KKT最优条件的样本，内层挑使步长最大的配对。整个算法只需要和样本数成线性的内存。

技术报告摘要称，SMO在多个测试问题上的耗时随样本数大致在线性到平方之间增长，而分块算法在线性到三次方之间；在真实的稀疏数据上，SMO可比分块算法快1000倍以上；它对线性SVM和稀疏数据最快。

局限与后续

  • 非线性核下仍需反复计算核函数值，样本数到几十万以上时训练依旧很慢，核SVM难以跟上数据规模增长。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    支持向量机1995 · 基础
    解决了SVM对偶二次规划在大样本上求解太慢、太占内存的问题。
  • 使用
    核技巧与最优间隔分类器1992 · 基础
    优化的就是核化最优间隔分类器的对偶问题，只通过核函数访问样本。

本篇术语

  • KKT条件　带约束优化问题最优解必须满足的一组条件；SMO用是否违反它来挑选下一步要更新的乘子。

怎么学

先读支持向量机的对偶形式，再读技术报告第2节两变量子问题的解析解推导；最后用NumPy写一个简化版SMO，在二维玩具数据上画出决策边界和支持向量。
