GPTQ训练后量化

GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers
2022.10论文延伸ICLR 2023Elias Frantar, Saleh Ashkboos, Torsten Hoefler, Dan Alistarh · ISTA / ETH Zurich待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

千亿参数模型的显存与带宽开销巨大，而此前的训练后量化方法要么在大模型上精度崩，要么算不动。

方法

沿用最优脑外科OBS的二阶信息思路，逐列量化权重并用近似逆Hessian把量化误差补偿到未量化的列，几小时内把175B模型压到3–4位。

影响

首个对千亿级语言模型做到3–4位几乎无损的训练后量化，成为后续开源量化工具的基础。

方法

对一层权重矩阵，按列依次量化：量化一列后，把产生的误差用该层输入的Hessian（2XXᵀ）的逆来更新还没量化的列，让整层输出尽量不变。GPTQ把OBS里每次选最优权重的昂贵做法，改成固定顺序、按块分批处理，并用Cholesky分解保证数值稳定，复杂度降到可处理上千亿参数。摘要称约4个GPU小时即可量化1750亿参数模型，3到4比特几乎无损，2比特或三值也能给出可用精度；定制内核在A100上端到端比FP16快约3.25倍，A6000上约4.5倍。llama.cpp与本地推理等本地推理项目都借鉴或支持GPTQ权重。

局限与后续

  • 只量化权重，激活仍是高精度，且依赖一小批校准数据，可能在分布外任务上掉点。
    后来针对它的工作　SmoothQuant
  • 没有区分权重重要性，2比特以下误差仍大。
    后来针对它的工作　AWQ激活感知量化

它建立在什么之上

  • 改进
    量化感知训练与整数推理2017.12 · 系统·效率
    需要用完整训练数据做量化感知训练，模型很大或训练数据拿不到时代价过高。
  • 改进
    LLM.int8()与离群特征2022.08 · 系统·效率
    8位只能把显存减半，175B模型仍要约175GB；更激进的4位、3位量化在这种方法下会严重掉点。
  • 延续
    最优脑外科OBS1992.11 · 系统·效率
    把OBS的二阶补偿思路改造成可扩展到千亿参数的逐列量化。
  • 竞争
    剪枝与量化压缩2015.10 · 系统·效率
    后者做剪枝、量化和编码压缩的训练流程，GPTQ免训练、只做训练后量化。
  • 改进
    LSQ可学习步长量化2019.02 · 系统·效率
    需要完整的量化感知训练，算力和数据成本对上百亿参数的大语言模型过高，大模型量化转而以训练后量化为主。
  • 改进
    ZeroQuant训练后量化2022.06 · 系统·效率
    INT4需要额外的逐层蒸馏，流程比只用少量校准数据的一次性方法重。

后来的相关工作

  • 竞争
    QLoRA2023.05 · 系统·效率 已核对
    GPTQ的4位量化只用于推理；QLoRA让梯度穿过4位权重完成训练。论文在局限一节推测，3比特GPTQ量化的基座加LoRA也可能恢复16位微调的效果，但没有验证。
  • 使用
    RTX 4090与本地大模型2022.10 · 硬件
    GPTQ等4位量化方法让几十亿到三百多亿参数的模型能放进24GB显存，4090才成为本地大模型硬件。
  • 竞争
    llama.cpp与本地推理2023.03 · 系统·效率
    GPTQ用二阶信息做精细的4位量化但依赖GPU；llama.cpp用更简单的分块取整量化，换来在CPU和各种设备上都能跑，两者后来互相借鉴。
  • 改进
    SmoothQuant2022.11 · 系统·效率
    只量化权重，激活仍是高精度，且依赖一小批校准数据，可能在分布外任务上掉点。
  • 延续
    SparseGPT一次性剪枝2023.01 · 系统·效率
    沿用其逐列近似二阶更新，把量化换成剪枝。
  • 竞争
    AWQ激活感知量化2023.06 · 系统·效率
    同为4位权重量化：GPTQ靠逐列误差补偿，AWQ靠按激活保护重要通道，不需要重建。
  • 竞争
    SqueezeLLM稠密加稀疏量化2023.06 · 系统·效率
    GPTQ用均匀量化加二阶误差补偿，SqueezeLLM用敏感度加权的非均匀码本，3比特下困惑度差距更小。
  • 延续
    QuIP与QuIP#两比特量化2023.07 · 系统·效率
    同样逐层最小化带海森矩阵的二次误差；QuIP证明GPTQ是其自适应舍入的特例，并加上非相干预处理。
  • 竞争
    OmniQuant可学习量化参数2023.08 · 系统·效率
    同为大模型训练后量化，GPTQ逐列补偿误差，OmniQuant学习截断阈值，两者在仅权重量化上常被直接比较。
  • 改进
    AQLM加性量化2024.01 · 系统·效率
    GPTQ类标量量化在2比特时误差急剧增大，AQLM用多码本向量量化显著降低极低比特下的损失。
  • 竞争
    1.58比特模型BitNet2024.02 · 系统·效率
    GPTQ在训练后把已有模型压到低位，BitNet从训练起就用三值权重，路线不同，但都为降低推理成本。
  • 使用
    QuaRot旋转量化2024.03 · 系统·效率
    旋转后的权重仍用GPTQ做训练后量化。
  • 改进
    Marlin四比特推理内核2024.08 · 系统·效率
    GPTQ得到的4比特模型此前在批量服务中难以提速，MARLIN提供了批大小16–32下接近4倍加速的内核。
  • 使用
    精度规模定律2024.11 · LLM
    研究对象之一是训练后量化带来的损失，GPTQ是这类方法的代表。
