HiPPO

HiPPO: Recurrent Memory with Optimal Polynomial Projections
2020.08论文延伸NeurIPS 2020Albert Gu, Tri Dao, Stefano Ermon, Atri Rudra, Christopher Ré · Stanford / Buffalo待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RNN要把不断增长的历史压缩进一个固定大小的隐状态，如何压缩才合理，缺少理论指导，长程记忆很差。

方法

把“记住历史”形式化为在线地用正交多项式逼近整条历史曲线，推导出最优的线性状态更新。

影响

为S4结构化状态空间和Mamba的状态空间模型提供了关键的初始化与更新矩阵。

方法

HiPPO把输入看作一条随时间增长的连续函数，要求隐状态保存这条函数在某个度量下对多项式基的投影系数。给定“过去每一刻有多重要”的度量，可以推出系数随新输入变化的线性微分方程dc/dt = A c + B f。

论文的特例包括：从第一性原理推出Legendre Memory Unit，并推广了LSTM和GRU里的门控。新提出的HiPPO-LegS对整段历史均匀赋权，对时间尺度稳健，更新快且梯度有界。摘要称在permuted MNIST上取得98.3%的新最佳精度，在测试时间尺度鲁棒性的轨迹分类任务上比RNN和神经ODE基线高25到40个百分点。

局限与后续

  • 只是在线压缩一维信号的框架，需要进一步设计才能在深度网络里高效并行训练。

读懂它需要的概念

循环网络与隐状态 门控机制 常微分方程与随机微分方程 低秩近似 梯度消失与梯度爆炸

本篇术语

  • 正交多项式投影　用一组两两正交的多项式作为基，把函数表示成基系数；系数个数就是记忆的容量。

怎么学

先复习循环网络与隐状态与线性常微分方程；读原文第2节的问题定义与第3节的LegS推导；动手用勒让德基在线逼近一条正弦信号。
