递归张量网络与情感树库

Recursive Deep Models for Semantic Compositionality Over a Sentiment Treebank
2013.10论文重要EMNLP 2013Richard Socher, Alex Perelygin, Jean Y. Wu, Jason Chuang, Christopher D. Manning, Andrew Y. Ng, Christopher Potts · 斯坦福大学待核对
ACL Anthology ↗Stanford Sentiment Treebank数据 ↗在交互版中打开（演化树、学习进度）

问题

情感分类靠词袋特征，单句正负二分类准确率多年徘徊在80%左右；“not good”“X but Y”这种否定和转折，词袋模型根本看不出来；而且只有整句标签，模型学不到短语层面的情感如何组合。

方法

一手做数据：把1万多句影评按句法树切成21.5万个短语，逐一人工标注五级情感，形成情感树库；一手做模型：沿句法树自底向上用同一个“张量”组合函数把两个子节点向量合成父节点向量，每个节点都预测情感。

影响

情感树库（SST）成为此后多年句子表示和文本分类的标准基准，GLUE中的SST-2即取自它；单句二分类准确率从80%提到85.4%，并首次让模型在否定和转折上表现出可解释的组合行为。

背景

机器学习情感分类之后，影评情感分类的主流是朴素贝叶斯或SVM文本分类加词袋、二元词组特征。论文指出，单句正负二分类的准确率多年没有超过80%，含中性的多分类在短文本上常低于60%。原因很直接：词袋不看词序，“好看”和“不好看”只差一个词；“画面精美，但剧情空洞”的整体倾向由“但”之后决定。

另一条路是语义向量空间：用词向量相加或平均表示句子，但这同样不看结构。Socher等人的递归神经网络沿句法树递归组合向量，后来又有每个词同时带一个矩阵的MV-RNN，但前者组合能力弱，后者参数随词表增长太快。更大的瓶颈是数据：只有句子级标签，模型几乎得不到“这个短语是什么情感”的直接监督。

方法

斯坦福情感树库。取Pang和Lee整理的rottentomatoes.com影评句子共10,662句，用斯坦福句法分析器（非词汇化句法分析）分析，得到11,855个句子、215,154个不重复短语，在Amazon Mechanical Turk上让标注者用滑块给每个短语打情感分，最后归为五类：很负面、负面、中性、正面、很正面。

递归组合。每个词是一个d维向量（d约25到35）。对树中一个父节点p，其两个子节点向量为b、c，标准递归网络是p = tanh(W·[b; c])。RNTN再加一个张量项：

p = tanh([b; c]ᵀ · V^{[1:d]} · [b; c] + W·[b; c])

V是d个2d×2d的矩阵切片，第i个切片产生p的第i维。这一项让两个子向量的分量两两相乘，“not”可以直接改变“good”的方向，而不只是相加。所有节点共用同一组V和W，参数量与词表无关。

训练。每个节点（包括叶子）都接一个Softmax与logits，预测五类情感，损失是所有节点交叉熵之和，梯度沿树结构反向传播（结构上的BPTT）。

结果

测试集2,210句。五分类：所有短语上准确率80.7%，整句45.7%；作为对比，朴素贝叶斯整句41.0%、SVM 40.7%、词向量平均32.7%、标准递归网络43.2%、MV-RNN 44.4%。正负二分类（去掉中性句）整句准确率85.4%，SVM为79.4%，朴素贝叶斯81.8%。

针对性测试：在131个“X but Y”结构中，RNTN把X、Y和整句都判对的比例为41%，MV-RNN 37%、二元词组朴素贝叶斯27%；对否定负面句，81%以上的情况下它正确地提高了正面激活（“not terrible”应变得不那么负面，而不是变成正面）。

后来的发展

情感树库很快成为句子编码器的标准考题：TextCNN句子分类的卷积网络在其上与RNTN比较，Tree-LSTM把递归组合函数换成带门控的LSTM单元并刷新了结果，GLUE / SuperGLUE把它的二分类版本收为SST-2。

树结构模型本身的路线却逐渐式微：它需要外部句法分析器、难以批量并行，而ELMo、BERT等不显式用句法树的预训练模型在SST上明显更好。但“短语级标注+组合性分析”的思路，以及用否定、转折等受控样例检验模型的做法，在后来的可解释性和行为测试研究中一再出现。

    词袋特征的情感分类看不出否定和转折、单句准确率停在80%左右；树结构组合加短语级监督把二分类提到85.4%。
  • 竞争
    SVM文本分类1998 · NLP
    论文的主要基线之一：SVM加词袋在整句二分类上79.4%、五分类40.7%，均低于RNTN。
  • 改进
    Turney无监督情感分类2002.07 · NLP
    只看局部短语的平均倾向，处理不了否定、转折和「描写坏剧情但推荐电影」这类整体与局部相反的情况。
  • 使用
    非词汇化句法分析2003.07 · NLP
    用斯坦福句法分析器为全部句子生成句法树，树库的短语和模型的组合顺序都来自它。
  • 延续
    递归神经网络2011.06 · NLP
    沿用沿句法树递归组合向量的框架，把组合函数从单个矩阵升级为张量，使两个子节点可以乘性交互。
  • 改进
    IMDb影评情感2011.06 · 数据·评测
    只有整篇影评一个标签，无法检验模型对否定、转折等句内组合语义的理解。

读懂它需要的概念

嵌入向量 神经元与激活函数 Softmax与logits 交叉熵 图、树与搜索 反向传播

本篇术语

  • 树库　每个句子都配有句法树的语料。情感树库在此基础上给树的每个节点（即每个短语）都标了情感。
  • 组合性　整体的意义由部分的意义及其组合方式决定的原则，如“不+好”的情感由“好”和否定词共同决定。
  • 张量　这里指一组堆叠的矩阵（三维数组）；用它计算xᵀ·V[i]·x，能表示输入各分量之间的两两乘积关系。
  • SST-2　情感树库的二分类版本：只用整句标签，分正面、负面两类（原版是五分类）。GLUE把它收为单句任务，训练集约6.7万条、测试集约1,800条。

怎么学

先补嵌入向量、Softmax与logits和图、树与搜索里的树结构。读原文第3节（树库构建与图2）、第4.3节（RNTN公式）和表1、第5.4节的否定实验。动手：下载SST数据，先用逻辑回归加词袋做二分类作为基线，再用PyTorch实现一个沿给定二叉树递归组合的RNN，比较两者在含“not”“but”句子上的表现。
