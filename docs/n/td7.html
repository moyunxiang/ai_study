TD7与SALE表示

For SALE: State-Action Representation Learning for Deep Reinforcement Learning
2023.06论文延伸NeurIPS 2023Scott Fujimoto, Wei-Di Chang, Edward J. Smith, Shixiang Shane Gu, Doina Precup, David Meger · McGill University, Mila, Google DeepMind待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

表示学习在图像任务里早已是标配，但在关节角、速度这类低维状态的物理控制任务上几乎没人用；同时，深度RL训练中策略好坏剧烈波动，最后一刻的策略往往不是最好的。

方法

提出SALE：学一个同时编码状态与动作的嵌入，训练目标是在嵌入空间里预测下一状态的嵌入；再把它和改进的优先回放、策略检查点结合进TD3，得到TD7（TD3 + 4个改进）。

影响

在低维连续控制上大幅超过TD3和SAC，让“即使状态本身已经很紧凑，学到的状态—动作表示仍然有用”成为共识；它的设计又直接演化为同一作者的通用无模型算法MR.Q。

背景

TD3和SAC是连续控制的主力算法，网络直接以原始状态为输入。图像任务里，SPR自预测表示、CURL对比表征RL等辅助表示学习显著提高了样本效率，但人们通常认为低维状态已经是好表示，不需要再学。另一个实践问题是：RL的策略在训练过程中性能波动很大，评测时用最后的参数常常比之前某个时刻差，而监督学习里常用的“保存验证集上最好的检查点”在RL中没有现成的对应。

方法

SALE（state-action learned embeddings）：两个编码器 z^s = f(s) 与 z^{sa} = g(z^s, a)，训练目标是动力学预测：

L = ‖ g(f(s), a) − sg(f(s′)) ‖²

其中sg表示停止梯度。价值网络与策略网络的输入是原始状态（和动作）与这些嵌入的拼接，嵌入用一个延迟更新的副本以保持稳定，并对嵌入做AvgL1归一化。作者系统研究了嵌入的设计空间：预测目标、是否端到端、归一化方式、输入如何拼接等，指出哪些选择最关键。

另外三项改进：用LAP（损失调整的优先经验回放，优先经验回放的改进版）采样；对价值目标做裁剪，防止外推出过大值；策略检查点——每隔若干回合评估当前策略，只有它比已保存的策略更好才替换，评测时使用保存的那个。离线设定下再加一项TD3+BC式的行为克隆项（参考TD3+BC极简离线RL）。

结果

摘要称：在OpenAI Gym基准任务上，TD7相对于TD3在30万步和500万步时的平均性能提升分别为276.7%和50.7%，在线与离线设定下都适用。原文报告它在D4RL离线基准上也与当时的强方法相当。

后来的发展

TD7把“基于模型的表示目标 + 无模型的价值学习”这一组合引入低维控制，同一作者随后的MR.Q通用无模型RL把SALE推广为近似线性化价值函数的表示，用一套超参数覆盖Gym、DMC和Atari。策略检查点也被一些后续工作当作稳定评测的技巧。

局限与后续

  • 只在低维状态的连续控制上验证，离散动作和图像输入下是否同样有效没有检验。
    后来针对它的工作　MR.Q通用无模型RL
  • 组合了多项改进，每项都带新超参数；策略检查点需要额外的评估回合，在交互昂贵的场景中代价不小。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

Actor-Critic与优势函数 时序差分与自举 特征与表示学习 自监督学习 on-policy与off-policy

本篇术语

  • 状态—动作嵌入　把状态和动作一起编码成一个向量，让它包含“在这个状态做这个动作会导致什么”的信息。
  • 策略检查点　训练中定期评估策略，只保留表现最好的一份参数用于部署，避免最后时刻的性能波动。

怎么学

先熟悉TD3；读原文第4节SALE的设计空间研究和第5节策略检查点；在HalfCheetah上分别跑TD3和加了SALE的TD3，观察早期样本效率的差别。
