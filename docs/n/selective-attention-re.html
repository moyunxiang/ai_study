选择性注意力关系抽取

Neural Relation Extraction with Selective Attention over Instances
2016.08论文延伸ACL 2016Yankai Lin（林衍凯）, Shiqi Shen, Zhiyuan Liu（刘知远）, Huanbo Luan, Maosong Sun（孙茂松）· 清华大学待核对
ACL Anthology ↗OpenNRE ↗在交互版中打开（演化树、学习进度）

问题

远程监督自动生成的训练包里，很多句子其实并不表达目标关系；PCNN只从每个包中挑一句「最可能的」来训练，又丢掉了包里其他真正有用的句子。

方法

用卷积网络把包里每个句子编码成向量，再以关系为查询，对包内所有句子做注意力加权：表达该关系的句子权重高，噪声句子权重低，用加权和代表整个实体对。

影响

在纽约时报-Freebase基准上明显优于只取一句和简单平均的做法，PCNN+ATT成为此后几年远程监督关系抽取的标准基线，作者团队的OpenNRE工具包也被广泛使用。

背景

远程监督关系抽取用知识库自动标注句子，多示例远程监督提出「至少一句表达关系」的多示例假设。PCNN远程监督关系抽取（Zeng等，2015）用分段卷积网络编码句子，并在多示例学习中每个包只选得分最高的一句参与训练。这样虽然避开了大量噪声句，但一个实体对往往有多句都在表达关系，只取一句浪费了信息；而直接对所有句子取平均又会把噪声也平均进来。注意力机制已在翻译中证明，注意力可以学会对一组向量做软选择。

方法

句子编码。 每个句子x_i经过词向量和位置向量（每个词到两个实体的相对距离）输入，用CNN或分段最大池化的PCNN编码成向量 x_i。

选择性注意力。 实体对(h, t)的包里有n个句子。对候选关系r，给每个句子打分 e_i = x_iᵀ A r，其中r是关系r的查询向量、A是对角权重矩阵；归一化 α_i = exp(e_i) / Σ_k exp(e_k)；包的表示 s = Σ_i α_i x_i。

分类。 o = M s + d，经softmax得到各关系的条件概率，以交叉熵在包级别上训练；测试时对每个关系分别计算注意力，因此同一包对不同关系可以关注不同的句子。

作者比较三种包表示：ONE（只取一句，即PCNN原做法）、AVE（所有句子平均，相当于均匀注意力）和ATT（选择性注意力）。

结果

在NYT-Freebase数据上，以留出评估的精确率-召回率曲线和P@N比较，CNN+ATT与PCNN+ATT都优于对应的ONE和AVE版本（论文报告，具体数字未逐项核对）；摘要称模型能充分利用每个实体对的所有句子并有效减轻错误标注的影响。

后来的发展

随后的工作在此基础上加入关系之间的层次结构、对抗训练、强化学习选句、预训练语言模型编码器等；也有研究指出NYT数据的留出评估本身噪声很大，并构建人工标注的测试集重新评估。监督关系抽取转向TACRED（2017）这类人工标注数据集后，远程监督主要作为预训练或数据增强手段继续使用。

本篇术语

  • 包（bag）　远程监督中同一实体对的所有句子组成的集合，标签给在包上而不是单个句子上。
  • 位置向量　表示句中每个词到两个目标实体的相对距离的向量，让卷积网络知道实体在哪儿。
