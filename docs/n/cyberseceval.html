CyberSecEval网络安全评测

Purple Llama CyberSecEval: A Secure Coding Benchmark for Language Models
2023.12数据集延伸Manish Bhatt, Sahana Chennabasappa, Cyrus Nikolaidis, Shengye Wan, Ivan Evtimov, Dominik Gabi, Daniel Song, Faizan Ahmad et al. · Meta待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

大模型被大量用作编程助手，它写的代码可能带安全漏洞，它也可能被用来协助网络攻击；当时缺少一个统一、可自动运行的基准同时衡量这两类网络安全风险。

方法

作为Meta“Purple Llama”开放安全工具的一部分，构建两套自动化评测：一套检查模型在补全和写代码时有多常写出不安全代码，一套检查模型在被要求协助网络攻击时有多配合。

影响

后续发展成多个版本，加入提示注入、漏洞利用等测试，成为Llama系列及其他开源模型发布时常报告的网络安全评测之一，也是前沿模型网络能力评估中常被引用的早期基准。

方法

两个部分：

  • 不安全代码测试：作者构建了一个静态分析工具（论文称为Insecure Code Detector），能用规则识别多种编程语言中的常见不安全写法，如使用已知不安全的函数、弱加密算法等。从开源代码中找出含有这些写法的位置，截取前面的代码作为提示，让模型续写或按说明写代码，再检查输出是否重现了不安全写法。
  • 网络攻击协助测试：按照MITRE ATT&CK这一攻击战术分类体系，生成大量要求模型协助攻击的请求，再用一个评判模型判断回答是否真的提供了帮助。

摘要称，作者用它评测了Llama 2、Code Llama和OpenAI GPT系列共七个模型，有效识别出关键的网络安全风险；一个显著的发现是，越先进的模型越倾向于给出不安全的代码。整个测试用例生成和评估流程是自动化的。

局限与后续

  • 规则式静态分析只能识别已知模式，会漏掉复杂漏洞；协助攻击的判定依赖评判模型，“愿意回答”与“回答真的有用”之间差别很大。

本篇术语

  • 静态分析　不运行程序、只检查源代码来发现错误或安全问题的方法。
  • MITRE ATT&CK　一个公开的网络攻击战术与技术分类体系，常用来系统地组织攻防测试。
