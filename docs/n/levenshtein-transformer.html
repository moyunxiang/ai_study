Levenshtein Transformer

Levenshtein Transformer
2019.05论文延伸NeurIPS 2019Jiatao Gu, Changhan Wang, Jake Zhao · Facebook AI Research / 纽约大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

非自回归模型要么事先固定输出长度、在固定格子里反复改写，要么只能从左到右逐词生成；都不能在生成过程中自由地增删词、改变长度。

方法

把生成看成一连串编辑操作：每一轮先并行决定删掉哪些词，再决定在哪些空隙插入几个占位符，最后并行填出占位符的词，长度可以随轮次动态变化。

影响

把“插入/删除”作为基本操作引入并行生成，同一个模型既能从零生成也能修改已有文本，是编辑式非自回归生成的代表工作。

方法

非自回归翻译NAT一次并行输出全部词但要先预测长度，Mask-Predict并行解码在固定长度内反复重写置信度低的词。Levenshtein Transformer的名字来自编辑距离（Levenshtein距离），它的每一轮迭代由三个分类器完成，都共享同一个Transformer解码器：

  • 删除：对当前序列的每个词判断“保留还是删除”；
  • 插入占位符：对每两个相邻词之间的空隙预测要插入几个占位符；
  • 填词：并行预测每个占位符应是哪个词。

从空序列出发反复执行，就是生成；从一段已有文本出发，就是修改。训练时用模仿学习：根据当前序列和目标序列的编辑距离算出“专家”应做的最优编辑，让模型模仿，并让删除和插入互相为对方制造训练样本。作者称它在机器翻译和摘要上效果与自回归Transformer相当、解码效率高得多；用机器翻译训练好的模型还能直接用于自动译后编辑。

局限与后续

  • 需要从自回归教师模型做知识蒸馏才能达到可比的翻译质量，迭代轮数和三个分类器的误差会累积，在开放式长文本生成上没有验证。

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    删除、插入、填词三个分类器共享一个Transformer解码器。
  • 改进
    非自回归翻译NAT2017.11 · LLM
    NAT必须事先固定输出长度；本文通过插入和删除在生成中动态改变长度。
  • 改进
    Insertion Transformer2019.02 · LLM
    只能插入不能删除，一旦插错就无法修改；而且每步仍需完整地重新编码整个部分序列，实际墙钟加速比步数减少要小。
  • 竞争
    Mask-Predict并行解码2019.04 · LLM
    同期的迭代并行解码：Mask-Predict在固定长度内反复重写低置信度词，本文改为增删式编辑。

  • 竞争
    GLAT一瞥Transformer2020.08 · LLM

读懂它需要的概念

本篇术语

  • 编辑距离　把一个序列改成另一个序列最少需要多少次插入、删除、替换；Levenshtein距离是其中最常用的一种。

怎么学

先读非自回归翻译NAT和Mask-Predict并行解码；读本文三种操作的定义和模仿学习的训练流程图；动手：用fairseq里的Levenshtein Transformer示例在小翻译数据上训练，打印每轮删除和插入的过程。
