QMIX值分解

QMIX: Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning
2018.03论文重要ICML 2018Tabish Rashid, Mikayel Samvelyan, Christian Schroeder de Witt, Gregory Farquhar, Jakob Foerster, Shimon Whiteson · 牛津大学待核对
arXiv ↗ar5iv全文 ↗PyMARL代码 ↗在交互版中打开（演化树、学习进度）

问题

多个智能体合作、只有一个团队奖励时：各学各的（独立Q学习）不知道功劳归谁、环境又不稳定；学一个联合Q函数，动作组合随人数指数爆炸，执行时也没法各自决策。

方法

每个智能体学自己的Q值，再用一个“混合网络”把它们非线性地合成团队Q值，并强制团队Q对每个个体Q单调递增——这样每人各自取最大，就等于团队取最大。

影响

成为“集中训练、分散执行”值分解路线的代表方法，和同组发布的SMAC基准一起，在几年内是合作多智能体RL的默认基线。

背景

合作型多智能体任务（比如星际争霸里控制一队士兵，每个单位只看得到附近）有两个要求：执行时每个智能体只能根据自己的局部观测行动；训练时却可以在模拟器里拿到全局状态。这叫“集中训练、分散执行”。

两头的极端都不好。独立Q学习多智能体让每个智能体各学一个Q函数，把队友当环境，但队友在变，环境不平稳，也分不清团队奖励里谁出了力（见信用分配）。另一个极端是学一个以全部动作为输入的联合Q函数，10个智能体每人10个动作就有10¹⁰种组合，取max做不到，执行时也要集中。

2017年的VDN走了中间路线：令团队Q等于各个体Q之和。求和时每人各自取最大就是整体最大，非常方便；但简单相加表达能力太弱，也用不上训练时可得的全局状态。

方法

关键观察：要让分散执行和集中训练一致，并不需要团队Q是个体Q的和，只需要“团队Q的argmax = 各个体Q各自的argmax拼起来”。一个充分条件是单调性：

∂Q_tot / ∂Q_a ≥ 0，对每个智能体a都成立。

也就是说，任何一个人把自己的Q值提高，团队Q都不会下降。

结构。

  • 每个智能体一个循环网络（DRQN，带GRU记忆，即RNN编码器-解码器与GRU提出的门控循环单元），输入局部观测和上一个动作，输出各动作的Q_a。所有智能体共享参数。
  • 混合网络把Q_1…Q_n作为输入，经过两层带ELU的前馈网络输出Q_tot。混合网络的权重不是固定参数，而是由一组超网络根据全局状态s生成，并取绝对值保证非负——非负权重加上单调激活函数，就保证了单调性；全局状态因此也能以任意方式影响Q_tot。

训练。像DQN（Nature版）一样用经验回放和目标网络，对Q_tot做TD学习（见时序差分与自举），梯度穿过混合网络回传到每个智能体网络。执行时丢掉混合网络，每个智能体只看自己的观测取argmax Q_a。

例子（论文的两步博弈）：第二步在状态B，两人都选第二个动作得8分，其余组合0或1分。VDN只能学成加法，把这一格估成约6.5，于是第一步宁可去稳拿7分的状态A；QMIX把它学成约8，选对了路线。

结果

在星际争霸II的多种微操场景（如5个陆战队、2追猎者+3狂热者对战）上，按20次运行的平均测试胜率比较，QMIX整体明显优于独立Q学习和VDN，在较难的异构兵种地图上差距最大。

后来的发展

这套评测随后整理成基准星际多智能体挑战SMAC。之后的值分解工作大多是在放宽或绕开单调性约束（如QTRAN、Weighted QMIX、QPLEX）。2021年MAPPO发现，调好的多智能体PPO在SMAC上也能达到或超过QMIX，策略梯度路线重新受到重视。

容易误解的地方

  • 单调性是充分而非必要条件：QMIX能表示的团队Q比VDN多，但仍有许多合作问题（一个人的最优动作取决于队友同时选什么）无法表示。

局限与后续

  • 单调约束表示不了“我的最佳动作取决于队友同时怎么选”这类非单调协作，论文自己给出了反例矩阵博弈。

它建立在什么之上

  • 使用
    RNN编码器-解码器与GRU2014.06 · NLP
    每个智能体网络用GRU记住局部观测的历史，以应对部分可观测。
  • 使用
    DQN（Nature版）2015.02 · RL
    每个智能体都是DQN式的Q网络，沿用经验回放和目标网络。
  • 竞争
    MADDPG2017.06 · RL
    同为集中训练、分散执行：MADDPG用集中式critic指导各自的策略网络（策略梯度），QMIX在值函数上做分解（Q学习）。
  • 改进
    独立Q学习多智能体1993 · RL
    独立Q学习不稳定、无法分配团队奖励；QMIX通过混合网络集中训练，用团队TD误差把功劳回传给每个智能体。
  • 改进
    COMA反事实策略梯度2017.05 · RL
    on-policy的策略梯度样本效率偏低，后来在SMAC上常被值分解方法超过。
  • 改进
    VDN值分解网络2017.06 · RL
    简单相加只能表示各智能体贡献可加的任务，表达不了需要非线性配合的团队价值。

读懂它需要的概念

策略与价值函数 时序差分与自举 信用分配 循环网络与隐状态 马尔可夫决策过程

本篇术语

  • 集中训练、分散执行　训练时可以利用全局状态和所有人的信息，部署时每个智能体只依据自己的局部观测独立行动。
  • 值分解　把团队的价值函数拆成每个智能体各自价值的某种组合，使得各自贪心就能得到团队最优。
  • 超网络　输出另一个网络权重的网络。QMIX用它根据全局状态生成混合网络的权重。

怎么学

先补时序差分与自举、信用分配，读独立Q学习多智能体的讲解。读原文第4节（单调性条件与混合网络）和第5节的两步博弈例子。动手：用PyMARL或EPyMARL在SMAC的简单地图（如3m）上分别跑IQL、VDN、QMIX，比较胜率曲线。
