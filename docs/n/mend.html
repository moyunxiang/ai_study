MEND快速模型编辑

Fast Model Editing at Scale
2021.10论文延伸ICLR 2022Eric Mitchell, Charles Lin, Antoine Bosselut, Chelsea Finn, Christopher D. Manning · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型会答错或知识过时，想只修改一条事实：直接用这一个样本微调会过拟合、改坏别的东西，已有的编辑方法在百亿参数模型上又算不动或不起作用。

方法

训练一组小的“编辑器网络”，输入是用这一个样本微调时得到的梯度，输出是改造后的参数更新；利用梯度天然的低秩结构，让编辑器即使对百亿参数模型也足够小。

影响

确立了“学会如何编辑”这一类知识编辑方法，与ROME/MEMIT的“定位后直接改写”并列为两大路线，是知识编辑评测里的标准基线。

方法

对一层权重W，用一个输入—输出对做一次反向传播得到梯度 ∇W。对单个样本而言，这个梯度可以写成两个向量的外积 ∇W = δ·uᵀ（u是该层输入，δ是传回来的误差），秩为1。MEND不直接用这个梯度更新，而是把u和δ送进一个小的多层网络，输出变换后的 ũ 和 δ̃，再用 W ← W − α·δ̃·ũᵀ 更新。因为只处理两个向量而不是整个矩阵，编辑器的参数量很小。

编辑器本身要事先训练：目标一是编辑后模型在要改的输入（及其改写）上给出新答案，二是在无关输入上的输出保持不变（用KL散度约束）。这种“训练一个会做更新的网络”的思路与MAML元学习的元学习相近。

作者称MEND在单张GPU上不到一天就能为百亿参数以上的模型训练好编辑器，之后每次编辑都很快；在T5、GPT、BERT和BART上的实验中，它是唯一能在超大模型上有效编辑的方法。

局限与后续

  • 编辑器要针对每个模型单独训练；一次只改少量事实，连续编辑成百上千条时效果会退化，对改写后的提问和推理型问题的泛化也有限。

它建立在什么之上

  • 使用
    MAML元学习2017.03 · 基础
    借用元学习“学会如何更新参数”的思路训练编辑器。
  • 使用
    T52019.10 · LLM
    T5是主要实验对象之一，用来展示在百亿参数规模上的编辑。
  • 竞争
    知识神经元2021.04 · LLM
    知识神经元先定位再改参数，MEND不做定位，而是学习一个把微调梯度变成局部编辑的网络。

后来的相关工作

  • 改进
    SERAC记忆式编辑2022.06 · LLM
    MEND等参数编辑难以把握编辑范围、多次编辑后失效，SERAC把编辑放在外部记忆中，不改基础模型参数。
  • 改进
    MEMIT批量编辑2022.10 · LLM
    编辑器要针对每个模型单独训练；一次只改少量事实，连续编辑成百上千条时效果会退化，对改写后的提问和推理型问题的泛化也有限。
  • 竞争
    MQuAKE多跳编辑评测2023.05 · LLM
    MEND用超网络改参数，MeLLo不改参数，把编辑放进外部记忆，在多跳问题上明显更好。

读懂它需要的概念

反向传播 低秩近似 元学习 KL散度 预训练与微调

本篇术语

  • 知识编辑　只修改模型对少数特定事实的回答，同时尽量不影响其他输入的输出。

怎么学

先理解单样本梯度为什么是秩1外积，回顾MAML元学习的思想；读本文编辑器的结构和训练目标；动手：用EasyEdit等开源库在GPT-2上比较直接微调与MEND编辑一条事实后对无关问题的影响。
