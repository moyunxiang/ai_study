稀疏自编码器解释LLM

Sparse Autoencoders Find Highly Interpretable Features in Language Models
2023.09论文延伸Cunningham, Ewart, Riggs, Huben, Sharkey · EleutherAI / Lightspeed Studios 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

单个神经元常同时对多种语义激活（多义性），无法给出简洁的人类可理解解释，被认为源自叠加。

方法

用稀疏自编码器重建语言模型的内部激活，学到一组稀疏激活的特征，它们比神经元或其他分解更单义、更可解释。

影响

证明用无监督方法可以在语言模型中解开叠加，开启了SAE路线。

方法

叠加假说假说认为：网络表示的特征数多于神经元数，于是把特征放进激活空间里一组过完备的方向，使每个神经元被多个特征共用。作者训练一个稀疏自编码器：输入是语言模型某层激活，先映射到一个更宽的隐层，再映射回去重建，同时加稀疏惩罚，使每次只有少数特征被激活。

论文称，这样学到的特征在自动可解释性度量下比其他方向更单义、更可解释。作者还展示了用学到的特征，可以比以前的分解更精细地定位对IOI电路所用间接宾语识别任务中反事实行为起因果作用的特征。他们据此认为用可扩展的无监督方法可以解开叠加。

局限与后续

  • 特征的『可解释』主要由自动指标评估，是否真是模型使用的单位仍有争议。
