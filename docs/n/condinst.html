CondInst条件卷积实例分割

Conditional Convolutions for Instance Segmentation
2020.03论文延伸ECCV 2020Zhi Tian, Chunhua Shen, Hao Chen · 阿德莱德大学待核对
arXiv ↗代码（AdelaiDet） ↗在交互版中打开（演化树、学习进度）

问题

Mask R-CNN要先用RoIAlign把每个框里的特征裁出来、缩放到28×28再预测掩码，分辨率受限、边界粗糙，而且掩码头参数固定，只能靠裁剪来区分不同实例。

方法

不裁剪特征，而是给每个实例“现生成”一个小掩码头：检测器在每个位置除了预测类别和框，还输出一组卷积参数；用这组参数在整张共享特征图上跑3层很窄的卷积，直接得到这个实例的全图掩码。

影响

把实例分割做成完全不需要RoI操作的全卷积框架，精度超过调好的Mask R-CNN且推理更快；“为每个实例动态生成卷积核”与同期SOLO无框实例分割的后续版本一起，成为后来基于核和查询的分割方法的先声。

方法

CondInst以FCOS无锚框检测为检测骨架。FCOS在特征金字塔的每个位置预测类别和到四条边的距离；CondInst再加一个“控制器”分支，在每个位置输出一个参数向量，把它重排成一个小网络的权重——摘要举的例子是3层卷积、每层只有8个通道，总共一百多个参数。

另有一个共享的掩码分支，把特征金字塔FPN特征变成一张1/8分辨率的特征图。对某个实例，把它的参数装进小网络，输入是这张共享特征图再拼上“每个像素相对于该实例中心的坐标”，输出就是该实例在整张图上的掩码。因为参数是按实例生成的，网络本身就知道要分割哪一个，不需要裁剪框。

摘要称在COCO上不需要延长训练就超过了几种近期方法和调好的Mask R-CNN基线，推理也更快，因为掩码头极小。同一时期的SOLOv2也把SOLO无框实例分割的掩码分支改成动态卷积核，两者思路相近。

局限与后续

  • 每个实例仍由检测器的一个位置产生，需要NMS去重，语义和全景分割要另做。

它建立在什么之上

  • 使用
    特征金字塔FPN2016.12 · 视觉
    检测在FPN各层进行，共享掩码特征也取自FPN。
  • 改进
    Mask R-CNN2017.03 · 视觉
    Mask R-CNN依赖RoIAlign裁剪和固定28×28掩码；CondInst用按实例生成的卷积核在全图上预测，摆脱了裁剪。
  • 改进
    Mask Scoring R-CNN2019.03 · 视觉
    仍是两阶段、依赖检测框和RoI操作的框架，速度受限。
  • 使用
    FCOS无锚框检测2019.04 · 视觉
    以FCOS无锚框检测器为基础，在每个位置额外预测掩码头参数。
  • 竞争
    SOLO无框实例分割2019.12 · 视觉
    SOLO按网格位置区分实例并为每格输出一张掩码；CondInst按检测位置生成动态卷积核，两条路线后来都走向动态核。

读懂它需要的概念

分类、检测、分割 卷积层、池化与感受野 锚框与非极大值抑制 IoU与mAP

本篇术语

  • 动态卷积（条件卷积）　卷积核的数值不是训练后固定的，而是由网络根据当前输入（这里是当前实例）临时算出来。

怎么学

先理解FCOS的逐位置预测和Mask R-CNN的RoIAlign，再读本文第3节的控制器和掩码头；可在AdelaiDet里跑一次CondInst推理，打印某个实例生成的卷积参数形状。
