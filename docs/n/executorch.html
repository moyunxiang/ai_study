ExecuTorch 1.0

2025.10系统延伸PyTorch团队 · Meta待核对
PyTorch博客 ↗在交互版中打开（演化树、学习进度）

问题

手机、嵌入式设备上部署PyTorch模型，常常要先转换成别的格式，换一套运行时，转换中容易丢失算子或出现行为差异。

方法

端侧运行时ExecuTorch：直接导出PyTorch模型到边缘设备，覆盖CPU、GPU、NPU多种后端，无需转换或重写。

影响

1.0版意味着稳定可用于生产，成为PyTorch官方的端侧部署路径。

方法

2025年10月22日PyTorch官方博客宣布ExecuTorch 1.0。官方称它能把PyTorch模型直接部署到手机、嵌入式和桌面等边缘设备，无需转换或重写，支持多种硬件后端（CPU、GPU、NPU），1.0版本提供更广的硬件支持、更好的生产稳定性和更强的模型兼容性，并已为社区中的真实应用提供支持。它建立在PyTorch 2与torch.compile的导出能力之上，取代TensorFlow Lite这类需要转换为独立格式的路径。

局限与后续

  • 不同厂商NPU的后端成熟度不一，部分模型在特定后端上仍需额外适配。

  • 端侧内存和算力有限，大模型仍依赖量化和裁剪。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    PyTorch2017.01 · 系统·效率 待核对
    模型就是Python代码，部署到没有Python的服务器、手机等环境很不方便。
  • 使用
    PyTorch 2与torch.compile2023.03 · 系统·效率
    基于PyTorch 2的图导出机制得到可部署的程序。
  • 竞争
    TensorFlow Lite2017.11 · 系统·效率
    同为端侧推理运行时；TFLite来自TensorFlow生态，ExecuTorch让PyTorch用户不必转换格式。
