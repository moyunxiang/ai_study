Vision Mamba

Vision Mamba: Efficient Visual Representation Learning with Bidirectional State Space Model
2024.01论文延伸ICML 2024Lianghui Zhu, Bencheng Liao, Qian Zhang, Xinlong Wang, Wenyu Liu, Xinggang Wang · 华中科技大学 / Horizon Robotics / BAAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Vision Transformer的自注意力计算量随图块数二次增长，高分辨率图像又贵又占内存；状态空间模型Mamba状态空间模型对长序列高效，但图像对位置敏感且需要全局上下文。

方法

用双向Mamba块构成纯SSM的视觉骨干Vim：给图块序列加位置编码，用前向和后向两个方向的状态空间扫描压缩全局信息。

影响

表明视觉表示学习不必依赖自注意力，并在高分辨率下显著省算力，开启了视觉SSM骨干的一批后续工作。

方法

Vim把图像切成图块并展平成序列，加上位置嵌入后送入堆叠的双向Mamba块。单向的SSM只能让后面的图块看到前面的，而图像没有天然顺序，所以Vim让每个块同时从前向和后向各扫描一次序列，两个方向的结果合并，使每个位置都能获得全局上下文。

摘要称，在ImageNet分类、COCO检测和ADE20k语义分割上，Vim比DeiT等成熟ViT得分更高。在1248×1248分辨率批量推理提取特征时，Vim比DeiT快2.8倍，并节省86.8%的GPU内存。

局限与后续

  • 把二维图像展平成一维序列扫描，会丢失二维空间邻接结构，后续工作转向多方向或二维扫描。
