P-Tuning v2深度提示

P-Tuning v2: Prompt Tuning Can Be Comparable to Fine-tuning Universally Across Scales and Tasks
2021.10论文延伸ACL 2022Xiao Liu, Kaixuan Ji, Yicheng Fu, Weng Lam Tam, Zhengxiao Du, Zhilin Yang, Jie Tang · 清华大学, 北京智源人工智能研究院待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

提示微调只训练输入端的一小段连续提示，非常省；但已有研究发现它只在百亿参数以上的大模型上才接近全量微调，在常见尺寸的模型和序列标注这类难任务上明显落后。

方法

不只在输入层加可训练提示，而是在每一层都加（深度提示），并针对理解任务做若干调整，例如用普通的分类头代替把标签映射成词的做法。

影响

让提示类方法在从3亿到100亿参数的模型和各类理解任务上普遍接近全量微调，只训练0.1%–3%的参数；它的实现常被用作前缀/提示微调的强基线。

方法

Prefix / Prompt Tuning和Prompt Tuning冻结整个模型，只学一段连续向量拼在输入前面；P-Tuning也属于这一类。问题是：只在输入层加的几十个向量，经过几十层之后对深层的影响很弱，可训练参数也太少，模型不够大时表现不稳定，在命名实体识别等逐token标注的任务上尤其差。

P-Tuning v2本质上是把前缀微调的“每层都加提示”做法（论文称为深度提示微调）优化并适配到自然语言理解任务：在Transformer的每一层都插入一组可训练的前缀向量（作为该层注意力的额外Key和Value），这样可训练参数增加到0.1%–3%，而且直接作用于深层表示。配套的调整包括：去掉前缀微调里为稳定训练而加的重参数化网络（视任务决定是否使用）；针对不同任务选择不同的提示长度；不再用“把类别标签换成某个词让模型预测”的方式，而是在输出上接一个随机初始化的分类头，这样序列标注也能直接做；可选的多任务预训练提示。

摘要称，经过恰当优化的提示微调在多种模型规模和理解任务上普遍有效，与全量微调相当，而只需调0.1%–3%的参数。
