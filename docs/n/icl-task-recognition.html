任务识别与任务学习

What In-Context Learning "Learns" In-Context: Disentangling Task Recognition and Task Learning
2023.05论文延伸Findings of ACL 2023Jane Pan, Tianyu Gao, Howard Chen, Danqi Chen · 普林斯顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

关于上下文学习，一派实验（标签打乱也不太掉点）说模型只是在“认出”预训练学过的任务，另一派理论说模型真的在示例上“学”新映射，两种说法各有证据，互相矛盾。

方法

设计对照实验把两种能力分开测：任务识别（TR，用打乱标签的示例，只能靠认出任务）和任务学习（TL，用与语义无关的抽象标签，只能靠学新映射），再看它们随模型规模和示例数如何变化。

影响

说明两派观察都对，只是测到的是两种不同的力量：小模型几乎只会TR，TL随规模才出现并随示例增多持续提升，为后续ICL研究提供了必须区分的两个维度。

方法

背景：示例标签不重要？发现把示例里的标签随机打乱，分类准确率只下降很少，似乎示例只是告诉模型“格式和任务是什么”；大模型能覆盖先验却发现大模型能跟随翻转的标签，说明它会利用示例中的输入—标签映射。ICL即隐式贝叶斯推断把ICL解释为“推断出是哪个预训练概念”，ICL即梯度下降则说模型在隐式学习。

作者在16个分类数据集上，用GPT-3、LLaMA、OPT三个家族、不同规模的模型做三种设置：

  • GOLD：正常示例，标签正确；
  • RANDOM：标签从标签集中随机抽，输入—标签对应关系被破坏，模型只能靠认出“这是情感分类”并调用预训练先验，测的是任务识别TR；
  • ABSTRACT：把标签换成与任务语义无关的符号（数字、字母或无关词），正确的对应关系仍然保留，模型无法靠先验知道“0代表正面”，只能从示例中学这个新映射，测的是任务学习TL。

摘要报告两条主要结论：第一，只靠TR就能得到明显高于随机的表现，而且TR不随模型变大或示例增多而进一步提升；第二，TL随模型规模增大才出现，并且示例越多，TL的表现越好。换句话说，小模型做ICL主要是在识别任务，大模型才真正在上下文中学习新的映射。

这一区分解释了早期“标签不重要”的现象：那些实验用的模型和设置主要测到了TR。作者主张今后评估ICL时把这两种力量分开报告。

本篇术语

  • 任务识别（TR）　模型从示例里认出要做哪种已经会的任务，然后调用预训练中学到的知识，示例的标签对不对并不重要。
  • 任务学习（TL）　模型从示例里学到一个预训练中没见过的输入—标签映射，例如“正面评论对应符号B”。

怎么学

先读示例标签不重要？和大模型能覆盖先验的标签打乱、翻转实验；读本文第2节三种设置的定义和第3节随规模、示例数变化的曲线；动手：在一个开源模型上做情感分类ICL，分别用正确标签、随机标签、“A/B”抽象标签，比较准确率随示例数的变化。
