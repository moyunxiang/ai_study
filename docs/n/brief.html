BRIEF二进制描述子

BRIEF: Binary Robust Independent Elementary Features
2010.09论文延伸ECCV 2010Michael Calonder, Vincent Lepetit, Christoph Strecha, Pascal Fua · 洛桑联邦理工学院（EPFL）待核对
DOI ↗维基百科（特征描述子） ↗在交互版中打开（演化树、学习进度）

问题

SIFT特征和SURF的描述子是128或64维的浮点向量，计算、存储和两两比较都很贵；在手机等算力有限的设备上做实时匹配、或匹配成千上万个特征点时，成了瓶颈。

方法

直接在平滑后的图像块里随机挑一组固定的像素对，逐对比较“哪个更亮”，每对得到1位，拼成一个256位左右的二进制串当描述子；匹配时用异或加数1计算汉明距离，非常快。

影响

开创了二进制局部描述子这一类方法，计算和匹配速度比SIFT、SURF快一个数量级；随后的ORB特征在它的基础上加入方向，成为ORB-SLAM等实时系统的标准特征。

方法

对一个特征点周围的图像块（例如48×48像素），BRIEF先用高斯核平滑以降低噪声敏感度，然后按事先随机生成、对所有特征点都相同的规则选出n个像素对 (x_i, y_i)。对每一对做一次比较：

τ(x, y) = 1，如果 I(x) < I(y)；否则为0

n个比较结果拼起来就是描述子，论文常用 n = 128、256、512位。论文比较了几种采样分布，发现以特征点为中心的各向同性高斯分布效果较好。

两个描述子的距离用汉明距离（两串二进制有几位不同）衡量，可以用一条异或指令加一条数1指令完成，比计算浮点向量的欧氏距离快得多；256位只占32字节，存储也比SIFT的128个浮点小很多。

BRIEF本身只是描述子，不负责找特征点，常与FAST角点等快速检测子配合使用。它没有旋转和尺度不变性：图像转动超过十几度，比较的像素对就对不上了。

局限与后续

  • 没有方向不变性和尺度不变性，图像旋转或缩放较大时匹配率迅速下降。
    后来针对它的工作　ORB特征
  • 随机采样的像素对之间相关性高、区分度有限，在重复纹理下容易误匹配。
    后来针对它的工作　ORB特征 SuperPoint

    SURF用积分图加速但仍是浮点描述子；BRIEF走二进制路线，速度和存储更省，但没有旋转不变性。
  • 使用
    FAST角点2006.05 · 视觉
    常与FAST角点检测子搭配，组成完全面向速度的检测-描述流程。

读懂它需要的概念

图像作为张量 高斯分布 特征与表示学习

本篇术语

  • 汉明距离　两个等长二进制串中对应位不同的个数，可以用异或再数1快速算出。
  • 局部描述子　把特征点周围一小块图像编码成一个向量，用来判断两张图里的点是不是同一个物理点。

怎么学

先了解SIFT描述子的构造，再用OpenCV的FAST+BRIEF（或ORB）在两张图之间做特征匹配；把其中一张图旋转30度，对比BRIEF和ORB的匹配数。
