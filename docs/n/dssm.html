DSSM深度语义匹配

Learning Deep Structured Semantic Models for Web Search using Clickthrough Data
2013.10论文延伸CIKM 2013Po-Sen Huang, Xiaodong He, Jianfeng Gao, Li Deng, Alex Acero, Larry Heck · Microsoft Research / UIUC待核对
Microsoft Research ↗在交互版中打开（演化树、学习进度）

问题

网页搜索靠关键词匹配，查询和文档用词不同（如“automobile”与“car”）就搜不到；潜在语义分析LSA一类的主题模型是无监督的，与最终排序目标不一致。

方法

用深层网络把查询和文档分别映射到同一个低维语义空间，用向量相似度打分，并直接用点击日志作监督进行端到端训练。

影响

开创了“双塔”深度语义匹配结构，成为搜索、推荐中的标准做法，后来的稠密检索（稠密检索DPR）与Sentence-BERT沿用了这一结构。

方法

输入是查询或文档的词袋向量。因为词表可能有几十万词，论文先用词哈希（word hashing）：把词拆成字母三元组（如“good”拆为“#go, goo, ood, od#”），用字母三元组的计数作输入，维度小得多，也能处理没见过的词和拼写错误。

然后经过几层全连接网络，把查询和文档分别压成低维语义向量，两者的余弦相似度就是相关度。训练用点击数据：一个查询配一个被点击的文档和若干未点击的文档，用softmax让被点击的文档概率最大化，即最大化被点击文档的条件似然；这与RankNet排序学习的成对排序训练目标一脉相承。

因为查询和文档的向量可以分别离线算好，在线只需做近邻检索，适合大规模搜索。

局限与后续

  • 词袋输入丢失词序和上下文，难以处理长文档。

  • 两个塔只在最后做内积，查询与文档之间没有细粒度的词级交互，效果低于交互式模型。

读懂它需要的概念

嵌入向量 内积与余弦相似度 Softmax与logits 监督学习

本篇术语

  • 词哈希　把词拆成字母三元组再计数，用小得多的维度表示词，并能处理新词与拼写错误。
  • 双塔　查询和文档各用一个独立网络编码，只在输出处比较相似度。

怎么学

先理解余弦相似度；读原文词哈希和训练目标；用PyTorch实现一个双塔模型，在小规模问答匹配数据上训练。
