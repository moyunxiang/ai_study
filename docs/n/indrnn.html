IndRNN独立循环网络

Independently Recurrent Neural Network (IndRNN): Building A Longer and Deeper RNN
2018.03论文延伸CVPR 2018Shuai Li, Wanqing Li, Chris Cook, Ce Zhu, Yanbo Gao · 伍伦贡大学、电子科技大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RNN难训练，LSTM和GRU缓解了梯度消失，但它们使用tanh和sigmoid，梯度仍会随层数衰减，难以堆深；同一层的神经元相互纠缠，行为也难以解释。

方法

让同一层的神经元彼此独立：循环权重从矩阵变成向量，每个神经元只与自己上一步的状态相连，跨层再相互连接；这样可以方便地约束循环权重来防止梯度爆炸和消失，并使用ReLU等不饱和激活。

影响

展示了不靠门控也能训练很长、很深的RNN，与酉循环网络uRNN等一起构成“通过约束循环权重解决梯度问题”的路线。

方法

普通RNN：h_t = σ(W x_t + U h_{t−1} + b)，U是矩阵，每个神经元都接收同层所有神经元上一步的输出。IndRNN把U换成向量u，做逐元素乘法：h_t = σ(W x_t + u ⊙ h_{t−1} + b)。于是第n个神经元的状态只依赖自己的历史，梯度沿时间的传播变成标量 u_n^T 与激活导数的连乘，只要把每个|u_n|约束在合适范围内（与序列长度有关），就能同时避免梯度爆炸和消失。神经元之间的交互改由多层堆叠实现，层与层之间加批归一化和残差连接可以搭出很深的网络。

由于不需要靠饱和的门来控制信息流，它可以直接用ReLU等不饱和激活。摘要称IndRNN可以被方便地调节以防止梯度爆炸和消失，同时学习长期依赖，并能构建可有效训练的深层网络。

局限与后续

  • 神经元之间只能跨层交互，单层表达力受限，需要较深的堆叠。

  • 使用
    ResNet2015.12 · 视觉
    深层IndRNN借助残差连接堆叠。
  • 改进
    梯度消失问题1994 · 基础
    通过约束逐神经元的循环权重控制梯度沿时间的增长与衰减。
  • 竞争
    酉循环网络uRNN2015.11 · 基础
    uRNN把循环矩阵约束为酉矩阵以保持梯度范数，IndRNN把循环矩阵简化为逐元素向量再约束其大小。

读懂它需要的概念

循环网络与隐状态 梯度消失与梯度爆炸 神经元与激活函数

怎么学

先懂梯度沿时间连乘为何会消失或爆炸；读论文第3节逐元素递推与权重约束的推导；动手在长序列加法任务上比较LSTM与IndRNN。
