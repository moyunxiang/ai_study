XGBoost

XGBoost: A Scalable Tree Boosting System
2016.03论文重要KDD 2016Tianqi Chen（陈天奇）, Carlos Guestrin · University of Washington待核对
arXiv ↗GitHub dmlc/xgboost ↗官方文档：Introduction to Boosted Trees ↗在交互版中打开（演化树、学习进度）

问题

梯度提升树在表格数据上精度最好，但已有实现慢、吃内存，不会处理缺失值和稀疏特征，数据一到千万、上亿行就训不动。

方法

把目标函数写成“损失＋树复杂度惩罚”，用二阶泰勒展开得到叶子权重和分裂增益的闭式解；再配上稀疏感知分裂、加权分位数近似、按列预排序的块结构和外存计算。

影响

2015年Kaggle公开的29个冠军方案中17个用了它，成为表格数据的默认强基线；直到今天，表格任务上深度网络仍常常打不过它和它的后继者。

背景

梯度提升机GBM的思路是一棵接一棵地种回归树（见决策树），每棵新树去拟合当前模型损失的负梯度，最后把所有树的输出加起来。它和随机森林一样不需要特征归一化、能处理混合类型的列，在广告点击率、风控、排序这类“表格”问题上精度往往最高，Netflix Prize等竞赛的集成里也少不了它。

但到2014–2015年，已有实现跟不上数据规模：scikit-learn、R的gbm只支持把数据全部装进内存的精确贪心分裂，每层都要对所有特征排序；Spark MLlib、H2O能分布式但不支持外存，内存一满就停；广告数据经过独热编码后99%都是0，或者大量缺失，朴素算法照样逐个扫描。另外原始GBM只用一阶梯度，防过拟合只能靠收缩系数、树深这些手工旋钮。

方法

带正则的目标。第t轮要加一棵树f_t，目标是

L = Σ_i l(y_i, ŷ_i + f_t(x_i)) + Ω(f_t)，Ω(f) = γT + ½λ‖w‖²

其中T是叶子数，w是叶子上的输出值。把损失在当前预测处做二阶泰勒展开，记每个样本的一阶导g_i、二阶导h_i，并把落进叶子j的样本的g、h分别求和为G_j、H_j，最优叶子值和这棵树的得分都有闭式解：

w_j* = −G_j / (H_j + λ)，得分 = −½ Σ_j G_j² / (H_j + λ) + γT

于是一次分裂的增益是G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ)再减去γ：增益不够γ就不分。任何可二阶求导的损失（平方误差、对数损失、排序损失）都套用同一套代码。另有收缩系数和类似随机森林的列采样。

系统层面。① 稀疏感知：每个分裂学一个“默认方向”，缺失值和0直接走默认分支，计算量只与非零元素数成正比。② 加权分位数草图：近似算法只在分位点上试分裂，用h_i作为样本权重来选分位点，并给出有理论保证的流式算法。③ 列块：每列预先排好序、按压缩格式存成块，各特征的分裂查找可以并行，排序只做一次。④ 缓存感知预取、块压缩与分片，数据放不进内存时从磁盘流式读取。

结果

论文统计：2015年Kaggle博客公开的29个冠军方案中17个用了XGBoost（其中8个只用它），深度网络用于11个；KDDCup 2015前十名全部使用。Higgs-1M上500棵树，XGBoost每棵树0.68秒、测试AUC 0.830，scikit-learn每棵28.5秒、AUC相同，快10倍以上。稀疏感知分裂在Allstate-10K上比朴素版本快50倍以上；缓存感知预取在千万级数据上提速约一倍。分布式实验中，XGBoost比Spark MLlib和H2O更快，并且只用4台机器就处理完17亿行的Criteo点击数据。

后来的发展

XGBoost和它的直系后继LightGBM（直方图分裂、按叶生长）、CatBoost（有序提升、类别特征处理）至今是表格数据的首选；“正则化目标＋二阶近似”的写法成为后来提升树库的共同模板。训练好的树模型常配合SHAP解释每个特征的贡献。作者陈天奇随后转向深度学习系统，参与MXNet并主导了编译器TVM深度学习编译器。深度学习在图像、文本上全面取代了手工特征，但在表格数据上没有：2022年一项覆盖45个数据集的基准研究发现，在约1万样本的中等规模数据上，XGBoost等树模型即使不算速度优势也仍是最好的。

它建立在什么之上

  • 使用
    决策树CART1984 · 基础
    基学习器仍是二叉回归树，只是把分裂准则换成了由一、二阶梯度算出的结构得分。
  • 改进
    梯度提升机GBM2001 · 基础
    沿用逐棵拟合损失梯度的框架，加入二阶导和对树复杂度的显式正则，并解决了原实现顺序慢、不支持稀疏和缺失值的问题。
  • 使用
    随机森林2001 · 基础
    借用随机森林的列（特征）采样来防过拟合并加速训练。
  • 改进
    scikit-learn2010.02 · 系统·效率
    梯度提升树等表格数据上最强的方法早期实现较慢，后来由专门的库在速度和精度上超越。
  • 改进
    AdaBoost与集成学习1997 · 基础
    只针对指数损失的指数加权推导，难以直接换成其他损失函数或回归任务。
  • 使用
    Kaggle数据竞赛2010.04 · 事件
    在Kaggle竞赛中迅速流行，论文以2015年冠军方案的使用统计作为影响力证据。
  • 竞争
    Spark2010.06 · 系统·效率
    Spark MLlib提供内存式分布式提升树；XGBoost支持外存计算，在同样集群上更快、能处理更大数据。

读懂它需要的概念

决策树 集成学习 泰勒展开 正则化与权重衰减 损失函数 梯度下降

本篇术语

  • 表格数据　像数据库表或Excel一样的数据：每行一个样本，每列一个含义明确的特征（年龄、金额、城市），列之间没有像素那样的空间结构。
  • 分位数草图（quantile sketch）　在数据流上近似计算分位点的算法，只保留少量摘要就能找到大约第10%、20%……位置的值，用来生成候选分裂点。
  • 外存计算（out-of-core）　数据大于内存时，把数据分块存在磁盘上，边读边算，而不是一次性装入内存。

怎么学

先懂决策树CART如何选分裂点和梯度提升机GBM的“拟合负梯度”。然后读原文第2节（式2–7，两页就能推完叶子权重和增益公式），再看官方文档Introduction to Boosted Trees。动手：在一个Kaggle表格数据集上分别跑XGBoost和一个MLP，比较精度、训练时间，并调max_depth、eta、lambda看过拟合如何变化。
