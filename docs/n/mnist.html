MNIST

The MNIST Database of Handwritten Digits
1998数据集重要随LeCun等《Gradient-Based Learning Applied to Document Recognition》（Proc. IEEE 1998）发布Yann LeCun, Corinna Cortes, Christopher J.C. Burges · AT&T贝尔实验室（后分属NYU、Google、Microsoft Research）待核对
MNIST官方页面（存档） ↗LeCun et al. 1998（Proc. IEEE） ↗在交互版中打开（演化树、学习进度）

问题

美国标准局NIST的手写数字库把较干净的人口普查局员工数据当训练集、较潦草的高中生数据当测试集，训练和测试分布不一致，实验结论不可靠，格式也不便直接使用。

方法

把两批数据混合后重新划分：6万张训练、1万张测试，训练与测试的书写者互不重叠；每个数字缩放、居中到28×28灰度图，存成极简的二进制格式。

影响

MNIST成了机器学习的“Hello World”：二十多年里几乎每种分类器、每个深度学习框架的入门教程都先在它上面跑一遍。

背景

1990年代，手写数字识别是有真实需求的任务：银行支票、邮政编码都要机器自动读。卷积网络识别邮编用卷积网络读美国邮政的邮编数字，证明了反向传播训练的网络可以做这件事，但各家用的数据集不同，难以公平比较。

NIST发布过两套手写字符库：SD-3由人口普查局员工书写，SD-1由高中生书写。NIST原本把SD-3定为训练集、SD-1定为测试集，可SD-3明显更干净、更好认。这样训练和测试不是同一个分布，一个方法分数高低，很大程度取决于这种人为选择，而不是方法本身。LeCun等人为比较各种文档识别方法，需要一个更合理的基准。

方法

重新混合。SD-1有58,527张图、500位书写者。按书写者切开：前250人的字进训练集，后250人的进测试集，各约3万张；再各用SD-3补足。最终训练集6万张（SD-3、SD-1各3万），公开的测试集1万张（各5000）。训练集约来自250位书写者，并保证训练、测试的书写者完全不重叠，测的是对没见过的人的笔迹的泛化。

归一化。原图是黑白二值的。先保持长宽比缩放进20×20的框，抗锯齿后变成灰度；再按像素的重心平移，放到28×28图像的中心。于是每张图就是784个0–255的数（见图像作为张量），可以直接当向量送进分类器，几乎不需要预处理。

格式。四个gzip文件（训练图、训练标签、测试图、测试标签），用一个简单的头加原始字节存储，几行代码就能读。

结果

官方页面汇总了各类方法的测试错误率，几乎就是一部浓缩的分类器比较史：线性分类器12.0%；k近邻（欧氏距离）5.0%；高斯核支持向量机1.4%；卷积网络LeNet与卷积网络-5为0.95%，加上人工形变扩充数据后0.8%。之后有人用弹性形变的扩充把单个卷积网络做到0.4%；2012年GPU多列卷积网络用35个卷积网络的集成做到0.23%。到这时，剩下的错误样本里不少连人都难以判断。

后来的发展

MNIST让“公开、固定划分、谁都能下载复现”的小基准成为机器学习的日常，也让卷积网络在1990年代末就在这类任务上建立了优势。但它很快就太简单了：错误率在1%以下之后，方法间的差异主要来自数据扩充和集成，已看不出谁更会“看图”。研究者因此转向彩色自然图像的CIFAR-10/100和大规模的ImageNet。今天MNIST主要用于教学、调试代码，以及生成模型、可解释性研究里的快速验证。

容易误解的地方

  • 在MNIST上表现好并不说明方法适用于自然图像：数字是居中、单一、无背景的灰度图，难度远低于真实视觉任务。
  • 网站上的错误率有的用了纠偏、平移等预处理或数据扩充，有的没用；比较时要看清条件。
  • 公开的测试集只是原来6万张测试样本中的1万张。

局限与后续

  • 任务过于简单：1998年最好方法错误率已低于1%，后来降到0.23%，再也无法区分模型的真实视觉能力。

它建立在什么之上

  • 延续
    LeNet与卷积网络1998 · 视觉 已核对
    与LeNet-5出自同一篇论文，是为了在统一条件下比较LeNet与其他分类器而整理的数据集；LeNet-5在上面达到0.95%。
  • 改进
    Neocognitron1980 · 视觉
    每一级的位置容忍范围、抑制强度等都要人工设定，只在小网络、少量图案上演示过，没有在真实大规模手写数据上测错误率。
  • 延续
    卷积网络识别邮编1989 · 视觉
    延续用卷积网络读手写数字的工作，把小规模的邮编数字数据换成更大、划分更合理的公开基准。
  • 使用
    支持向量机1995 · 基础
    把SVM作为基准上的主要对照方法之一，高斯核SVM 1.4%、带形变扩充的虚拟SVM约0.56%，与卷积网络形成正面竞争。
  • 使用
    k近邻1967 · 基础
    k近邻是基准里最直接的参照线：不学任何特征，欧氏距离下错误率5.0%。

    CIFAR-10/1002009 · 数据·评测

读懂它需要的概念

图像作为张量 监督学习 训练集、验证集与测试集 准确率、精确率、召回率与F1 泛化与过拟合

本篇术语

  • 纠偏（deskewing）　求出数字笔画的主轴方向，把它“扶正”成竖直，减少因书写倾斜带来的差异。
  • 数据扩充的形变　对训练图片做随机平移、缩放、倾斜或弹性扭曲，人工造出更多样本，让模型对这些变化不敏感。

怎么学

先补图像作为张量和Softmax与logits。然后不用任何框架，用NumPy读入MNIST文件，依次实现k近邻、逻辑回归和一个隐藏层的全连接网络，记录各自的测试错误率；再用PyTorch写一个小卷积网络，看能否降到1%以下，并与官方页面的表格对照。
