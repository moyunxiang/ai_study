FasterTransformer推理库

2021.04系统延伸NVIDIA待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

BERT、GPT等Transformer模型上线后，用通用框架逐算子执行推理延迟高，GPU利用率低，难以满足在线服务需求。

方法

NVIDIA提供一套手工优化的Transformer编码器、解码器推理实现：算子融合、低精度、张量与流水线并行，可作为TensorFlow、PyTorch和Triton推理服务器的后端。

影响

在2020–2023年间是GPT类大模型推理的高性能参考实现，被许多早期LLM服务采用；它的开发此后转入TensorRT-LLM，TurboMind等引擎也借鉴了它的设计。

方法

FasterTransformer用C++/CUDA为Transformer的编码器和解码器写了专门的推理路径：把LayerNorm、偏置加法、激活函数等小算子融合进矩阵乘法前后，减少显存读写和内核启动；用cuBLAS与自研内核做FP16、INT8推理；为自回归生成实现带KV缓存的解码循环和束搜索、top-k/top-p采样；对超大模型支持张量并行与流水线并行，可以把GPT-3量级的模型分到多卡多机上。它提供TensorFlow自定义算子、PyTorch扩展，以及Triton推理服务器后端三种接入方式。README列出了BERT、编码器-解码器翻译模型和GPT的性能数据。

独立的GitHub仓库创建于2021年4月（此前作为NVIDIA深度学习示例的一部分发布）。README顶部说明：开发已转到TensorRT-LLM，鼓励开发者使用后者，原仓库保留但不再有新功能。
