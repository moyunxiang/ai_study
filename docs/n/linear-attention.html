线性注意力

Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention
2020.06论文延伸ICML 2020Angelos Katharopoulos, Apoorv Vyas, Nikolaos Pappas, François Fleuret · Idiap / EPFL待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Transformer自注意力的复杂度随序列长度平方增长，自回归生成时每步都要回看全部历史。

方法

把softmax注意力换成核特征映射的内积，利用矩阵乘法的结合律把复杂度降到线性，并发现它可以写成RNN。

影响

开启了线性注意力与“Transformer即RNN”这条线，之后的RetNet、Mamba-2、TTT都在此基础上展开。

方法

标准注意力是softmax(QKᵀ)V，必须先算出N×N的矩阵。论文用一个特征映射φ把相似度写成φ(q)·φ(k)，于是输出变成φ(Q)(φ(K)ᵀV)，先算后一个括号，复杂度从O(N²)降到O(N)。

自回归时，因果掩码下可以维护一个累计状态S = Σ φ(kᵢ)vᵢᵀ和一个累计分母，每来一个新词只需更新状态并读出，这就是一个状态大小固定的RNN。摘要称这样的线性Transformer与标准Transformer效果相近，在很长序列的自回归预测上最多快4000倍。

局限与后续

  • 核特征映射近似不了softmax的“尖锐”选择，检索类任务上明显弱于标准注意力。
    后来针对它的工作　Mamba状态空间模型 Gated DeltaNet
  • 固定大小的状态会随序列变长而遗忘，且没有选择性地写入与擦除。
    后来针对它的工作　Mamba状态空间模型 测试时训练层TTT

本篇术语

  • 特征映射　把向量映射成另一个向量的函数φ，使得φ(q)·φ(k)近似原相似度函数（如指数核）。

怎么学

先弄懂自注意力与多头注意力的矩阵形式；读原文第3节的线性化与第3.4节的RNN等价；用NumPy写出因果线性注意力的递推版与矩阵版并核对输出一致。
