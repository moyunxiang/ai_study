ORPO无参考模型偏好优化

ORPO: Monolithic Preference Optimization without Reference Model
2024.03论文延伸EMNLP 2024Jiwoo Hong, Noah Lee, James Thorne · KAIST AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DPO等偏好对齐方法仍要先做一轮监督微调（SFT），偏好阶段还要保留一个冻结的参考模型算KL或对数比，流程分两段、显存翻倍。

方法

把偏好对齐并进SFT：在普通的负对数似然损失上，加一项基于几率比（odds ratio）的惩罚，压低被拒回答相对被选回答的几率，不需要参考模型，也不需要单独的SFT阶段。

影响

提供了“一步完成SFT和偏好对齐”的简单方案，进入TRL等常用对齐工具库，与SimPO一起代表了去掉参考模型的偏好优化方向。

方法

作者先观察到：只做SFT时，模型在提升“被选回答”概率的同时，也会把同风格的“被拒回答”概率一起抬高，所以需要一点对不良风格的惩罚。ORPO的损失是 L = L_SFT + λ·L_OR，其中 L_SFT 是对被选回答的普通负对数似然；几率定义为 odds(y|x) = P(y|x) / (1 − P(y|x))，L_OR = −log σ( log( odds(y_w|x) / odds(y_l|x) ) )，y_w和y_l分别是被选和被拒的回答。它只用当前模型自己的概率，不需要DPO直接偏好优化那样的参考模型。作者从理论和实验上说明，几率比在对比两种风格时比概率比更温和、更稳定。

实验：在125M到7B的模型上，只用UltraFeedback AI反馈数据数据对Phi-2、Llama-2-7B和Mistral-7B做ORPO，作者称结果超过参数更多的7B和13B级对齐模型，最好的模型在AlpacaEval 2.0上达到12.20%，IFEval（指令级宽松）66.19%，MT-Bench 7.32。

局限与后续

  • 惩罚强度λ需要调；没有参考模型约束，模型可能偏离原分布太远，在更大规模和推理类任务上相对DPO是否占优并不一致。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

人类反馈强化学习 指令微调与对话模板 交叉熵 逻辑回归 KL散度

本篇术语

  • 几率（odds）　事件发生概率与不发生概率之比 p/(1−p)；几率比就是两个事件的几率相除。

怎么学

先读DPO直接偏好优化的损失推导；读本文对SFT会同时抬高被拒回答概率的分析和几率比与概率比的对比；动手：用TRL的ORPOTrainer在UltraFeedback子集上训练一个小模型，与先SFT再DPO比较。
