Claude 3.5 Sonnet

Introducing Claude 3.5 Sonnet
2024.06模型重要产品发布 2024Anthropic待核对
官方公告 ↗模型卡补充（PDF） ↗10月升级版与Computer Use ↗在交互版中打开（演化树、学习进度）

问题

Claude 3 Opus最强但贵且慢（每百万输出token 75美元），中档的Sonnet便宜却明显更弱；模型写代码多停留在单个函数，改不动真实代码库。

方法

以中档Sonnet的价格和速度推出新一代模型，能力超过上一代旗舰Opus；同时在claude.ai推出Artifacts，把生成的代码、文档、网页放进对话旁的独立窗口实时预览。

影响

中档价格首次拿到前沿成绩，内部智能体编码评测解题率从38%升到64%；10月升级版在SWE-bench Verified达到49%并首个开放电脑操作，开启了以Claude为核心的编码智能体浪潮。

背景

三个月前的Claude 3用三档模型覆盖不同预算，但最强的Opus价格是Sonnet的5倍，速度也慢。同期对手GPT-4o全模态实时模型（2024年5月）以GPT-4 Turbo一半的价格提供更强的能力，并主打实时语音。

编程方面，主流基准HumanEval只考写一个独立函数，已接近饱和；真实工作是在一个已有代码库里定位问题、修改多个文件、跑测试再修正。SWE-bench把这类任务做成了基准，但2024年上半年最好的系统也只能解决很小一部分，这类工作需要模型在“读代码—改代码—执行—看结果”的循环里持续多步（见智能体循环）。

方法

Anthropic没有公开架构和训练细节，公告与模型卡补充只描述能力和评测。

定位。价格与Claude 3 Sonnet相同（每百万输入/输出token 3/15美元），上下文20万token，官方称速度是Claude 3 Opus的2倍。

智能体编码评测。Anthropic自建了一个类似SWE-bench的内部评测：题目来自开源项目真实的pull request，给出自然语言的需求描述，模型要在代码库里搜索、查看、编辑通常3–4个、最多20个文件，可以在沙箱里反复运行代码自我修正，最后用模型看不到的测试来判定是否通过（见工具调用）。

Artifacts。用户让Claude生成代码片段、文档或网页时，结果显示在对话旁的独立窗口里，可以直接预览、修改、在其上继续迭代，而不是埋在聊天记录中。

升级版（2024年10月）。同名模型的新版本在编码和工具使用上进一步提升，并以公测形式推出Computer Use：模型看屏幕截图，输出移动光标、点击、打字等操作。

结果

模型卡补充中的6月版成绩：GPQA Diamond零样本思维链59.4%（Claude 3 Opus为50.4%，GPT-4o为53.6%）；MMLU（5-shot）88.7%；HumanEval 92.0%（GPT-4o为90.2%）；MATH 71.1%，低于GPT-4o的76.6%。内部智能体编码评测解决64%，Claude 3 Opus为38%。安全评估结论仍为ASL-2，并在发布前交给英国AI安全研究所测试。

10月升级版：SWE-bench Verified从33.4%升到49.0%，官方称高于包括o1-preview在内的所有公开模型；τ-bench零售场景从62.6%到69.2%；OSWorld纯截图设置14.9%，第二名为7.8%。

后来的发展

这一代让“中档模型就是主力”成为Anthropic的产品格局，此后旗舰编码能力几乎都首先出现在Sonnet上：Claude 3.7 Sonnet混合推理加入可见的扩展思考，Claude Code与终端编码智能体把它放进终端成为编码智能体，再到Claude 4。升级版带来的Computer Use开启了GUI智能体的产品化，SWE-bench Verified上的分数也成为各家发布模型时必报的指标。Artifacts式的“对话旁边的工作区”随后也被其他聊天产品采用。

容易误解的地方

  • 6月版与10月“升级版”用的是同一个名字（API中以日期区分），两者能力差别很大；SWE-bench Verified 49%和Computer Use都属于10月版。
  • 64%是Anthropic内部评测，不是公开的SWE-bench，不能直接与其他模型的SWE-bench分数比较。

局限与后续

  • 回答前没有显式的长推理过程，竞赛数学（MATH 71%）不如GPT-4o，更远不如随后的推理模型。

本篇术语

  • Artifacts　claude.ai的一项界面功能：模型生成的代码、文档、网页显示在对话旁的独立面板里，可实时预览和反复修改。
  • 智能体编码评测　让模型在真实代码库里按需求修改代码，可以多轮执行和调试，最后用隐藏的单元测试判断是否完成，而不是只看生成的一段代码。
  • Claude 3.5 Haiku　与升级版3.5 Sonnet在2024年10月22日一同公布的小模型：官方称它在许多评测上追平上一代旗舰Claude 3 Opus、速度与Claude 3 Haiku相近，SWE-bench Verified 40.6%；首发只支持文本，后调价为每百万输入/输出token 0.8/4美元。

怎么学

先读SWE-bench了解代码库级评测是怎么构造的，再读模型卡补充第2节的智能体编码评测说明和表3。动手：找一个小型开源仓库的真实issue，自己用API搭一个“读文件—改文件—跑测试”的循环，感受智能体编码的难点在哪里。
