梯度消失问题

Learning Long-Term Dependencies with Gradient Descent is Difficult
1994论文重要IEEE Transactions on Neural Networks 1994Yoshua Bengio, Patrice Simard, Paolo Frasconi · 蒙特利尔大学 / AT&T贝尔实验室 / 佛罗伦萨大学待核对
IEEE TNN（DOI） ↗原文PDF（香港浸会大学课程页） ↗在交互版中打开（演化树、学习进度）

问题

循环网络在原理上能记住任意久以前的输入，但实际训练时，一旦输入与需要的输出相隔十几、几十步，梯度下降就几乎学不会，没人说得清为什么。

方法

从动力系统角度证明：要让网络稳健地记住一个比特而不被噪声冲掉，状态必须处在“收缩”的吸引子附近，而收缩恰恰让反向传回去的梯度随时间间隔指数衰减——稳健记忆与可用梯度不可兼得。

影响

把“梯度消失”确立为循环网络和深层网络的核心障碍，并点出深层前馈网络也有同样的问题；此后LSTM、梯度裁剪、ReLU、残差连接等一系列工作都在回应它。

背景

Elman循环网络之后，循环网络被用于语音、语言等序列任务，训练用随时间反向传播BPTT：把网络沿时间展开成一个很深的前馈网络，再用反向传播求梯度。实践中大家反复发现，网络能学会相隔几步的依赖，却学不会相隔很多步的依赖——比如序列开头的一个符号决定最后的输出。

这是训练技巧不够，还是梯度下降本身的问题？（Hochreiter 1991年的德语硕士论文也独立分析过这一现象，但流传不广。）

方法

最小例子：一个会“锁存”的神经元。x_t = tanh(w·x_(t−1) + h_t)。当w > 1时，这个神经元有两个稳定状态（一正一负），可以用符号记住1个比特。要把比特“写进去”，需要一段足够大的输入；之后幅度较小的噪声输入不论持续多久都改不了它的符号。

一般结论。把网络写成动力系统x_t = M(x_(t−1), u_t)。所谓稳健地锁存信息，是指状态停在某个吸引子的“缩小的吸引域”里，使得小的输入扰动不能把它推走。论文证明：在这样的区域内，映射的雅可比矩阵范数小于1（见雅可比矩阵与海森矩阵）。而反向传播时，第t步的损失对第t−k步状态的梯度是k个雅可比矩阵的连乘：

∂x_t/∂x_(t−k) = M′(x_t)·M′(x_(t−1))···M′(x_(t−k+1))

每个因子都小于1，连乘就随k指数衰减（见梯度消失与梯度爆炸）。例如每步因子为0.9，隔50步只剩约0.005，隔100步约2.7×10⁻⁵。远处的依赖对梯度的贡献被近处的淹没，梯度下降几乎看不到它；反之因子大于1，系统对噪声不稳健，梯度还可能爆炸。

实验与替代方法。论文设计了三个任务：锁存问题、二序列问题、奇偶校验问题，序列越长依赖越远。除标准反向传播外，还尝试了模拟退火、多重网格随机搜索、伪牛顿法、按时间加权的伪牛顿法和离散误差传播。

结果

在单神经元锁存实验中，随着序列长度T增加，反向传播训练成功的比例迅速下降。在三个任务的比较中，模拟退火在所有任务上都能求解，但训练时间随序列长度增长；离散误差传播表现较稳，与模拟退火是仅有的能解奇偶校验问题的方法；基于梯度的方法随序列变长普遍失效。结论部分明确指出：循环网络沿时间展开就是一个共享权重的深层前馈网络，所以深层前馈网络也可能遇到同样的梯度消失。

后来的发展

三年后的LSTM直接引用了这篇和Hochreiter 1991的分析，用恒定误差流的记忆单元绕开了连乘衰减；LSTM论文还指出这篇的二序列问题过于简单，随机猜权重就能比所有被测方法更快解出。梯度爆炸那一面由梯度裁剪处理。深层前馈网络里的同一问题，后来通过Xavier初始化、ReLU、Highway网络、ResNet和Batch Normalization逐步缓解。

容易误解的地方

  • 梯度消失不是“梯度算错了”，梯度是精确的，只是远处依赖的分量在数值上被近处的淹没。
  • 这篇的结论有前提：信息靠双曲吸引子稳健存储。LSTM的记忆单元用线性自连接（导数恰为1）恰好跳出了这个前提。
  • 梯度消失与梯度爆炸是同一个连乘问题的两面：因子小于1会消失，大于1会爆炸。

局限与后续

  • 只给出了诊断，提出的替代方法（模拟退火、离散误差传播等）计算代价高，没有成为可扩展的解决方案。
    后来针对它的工作　LSTM
  • 对因子大于1时梯度爆炸、训练发散的问题没有给出实用的处理办法。
    后来针对它的工作　梯度裁剪
  • 指出深层前馈网络也会梯度消失，但没有解决办法，多层网络此后十多年难以训练。
    后来针对它的工作　Xavier初始化 ReLU Highway网络 ResNet Batch Normalization
  • 测试任务过于简单，后来发现其中的二序列问题用随机猜权重就能更快解出，难以区分方法优劣。

它建立在什么之上

  • 使用
    Hopfield网络1982 · 基础
    借用了吸引子动力学的观点：稳健的记忆对应稳定吸引子，而稳定恰恰意味着收缩、意味着梯度衰减。
  • 竞争
    时延神经网络TDNN1989.03 · 语音
    论文指出时延网络等静态网络只有有限的记忆窗口，无法无限期保存一个比特，这正是要用循环网络的理由，也是它的训练难点。
  • 延续
    Elman循环网络1990 · 基础
    解释了Elman式循环网络为什么学不会长距离依赖：问题不在网络结构的表达力，而在梯度下降训练本身。
  • 使用
    随时间反向传播BPTT1990 · 基础
    分析对象就是BPTT算出的梯度：沿时间展开后，梯度是一串雅可比矩阵的连乘。

后来的相关工作

  • 改进
    LSTM1997 · 基础 已核对
    用导数恒为1的线性自连接记忆单元，让误差沿时间原样回传，绕开了梯度连乘衰减。
  • 改进
    Batch Normalization2015.02 · 基础 已核对
    把激活保持在sigmoid的非饱和区，使sigmoid版Inception也能训练，缓解了饱和造成的梯度消失。
  • 改进
    ResNet2015.12 · 视觉 已核对
    论文认为退化问题“不太可能由梯度消失引起”：用了BN的普通网络前向信号方差不为零、反向梯度幅度正常；它把“深网络难优化”从梯度消失中区分出来，单独作为要处理的问题。
  • 延续
    LSTM遗忘门1999.09 · 基础
    在避开梯度消失的恒定误差通道上加入可学习的衰减，让网络自己决定在哪里牺牲长程梯度换取重置。
  • 改进
    ReLU2010 · 基础
    正半轴导数恒为1、不饱和，缓解了sigmoid/tanh逐层乘小导数造成的梯度消失；这一点由后续工作和AlexNet真正证实。
  • 改进
    梯度裁剪2012.11 · 基础
    对1994年指出的梯度爆炸给出几何解释和范数裁剪这一简单解法，并尝试用正则项缓解消失。
  • 改进
    Highway网络2015.05 · 基础
    门关闭时层的雅可比接近单位矩阵，梯度可跨越上百层不衰减，解决了深层前馈网络的梯度消失。
  • 改进
    回声状态网络ESN2004.04 · 基础
    不对循环部分做反向传播，从根本上绕开了梯度消失和训练不稳定。
  • 改进
    Xavier初始化2010 · 基础
    针对深层网络梯度逐层衰减或放大的问题，通过按层宽度缩放初始权重方差使梯度大小保持稳定。
  • 改进
    GRU与LSTM实证比较2014.12 · 基础
    实验证实门控单元比普通tanh循环单元更能学到长程依赖。
  • 使用
    Nielsen《NNDL》2015 · 事件
    第5章专门解释深层网络为什么难训练。
  • 改进
    酉循环网络uRNN2015.11 · 基础
    用特征值绝对值恰为1的酉矩阵，从结构上消除循环矩阵带来的梯度指数消失和爆炸。
  • 改进
    QRNN准循环网络2016.11 · 基础
    逐元素的遗忘门让梯度沿时间传播更顺畅，同时提高并行度。
  • 改进
    SELU自归一化网络2017.06 · 基础
    证明激活方差有上下界，从而排除了深层全连接网络中的梯度消失与爆炸。
  • 改进
    IndRNN独立循环网络2018.03 · 基础
    通过约束逐神经元的循环权重控制梯度沿时间的增长与衰减。
  • 改进
    时间卷积网络TCN2018.03 · 基础
    梯度沿网络深度而非时间传播，避开了长序列上RNN的梯度消失。
  • 改进
    LSSL线性状态空间层2021.10 · 基础
    用结构化的A保持长程信息，在上万步的序列上仍能学到依赖。
  • 改进
    线性循环单元LRU2023.03 · 基础
    通过把特征值模长初始化在接近1并加归一化，缓解长序列上的梯度消失与爆炸。

读懂它需要的概念

循环网络与隐状态 反向传播 链式法则 雅可比矩阵与海森矩阵 梯度消失与梯度爆炸 梯度下降

本篇术语

  • 长距离依赖　输出取决于很多步之前的输入，例如句首的主语决定句末动词的单复数。
  • 锁存　像数字电路里的锁存器一样，把一个比特写入状态后保持不变，直到下一次写入。
  • 双曲吸引子　附近的扰动在所有方向上都会被拉回的稳定点；在它周围，系统映射的导数（雅可比矩阵）是收缩的。

怎么学

先补链式法则、雅可比矩阵与海森矩阵和梯度消失与梯度爆炸。读原文第1节（问题）、第3节锁存神经元的例子和结论一节。动手：用PyTorch搭一个tanh循环网络，构造“第1步给一个±1，第T步要求输出它”的任务，对T = 5、20、50、100分别训练，同时打印损失对第1步输入的梯度范数，亲眼看它随T指数下降。
