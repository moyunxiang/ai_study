SummaRuNNer抽取式摘要

SummaRuNNer: A Recurrent Neural Network based Sequence Model for Extractive Summarization of Documents
2016.11论文延伸AAAI 2017Ramesh Nallapati, Feifei Zhai, Bowen Zhou · IBM Watson待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

抽取式摘要过去靠LexRank这类图排序或手工特征打分，难以端到端地学习“哪句话该进摘要”；而训练神经模型又需要每个句子“选/不选”的标签，CNN/DailyMail这类数据只给了人写的摘要。

方法

用两层GRU把文档编码成句子表示，按顺序对每句做“选或不选”的二分类，打分显式拆成信息量、显著度、新颖度和位置几项；没有句子标签时，用贪心匹配人写摘要的ROUGE自动造标签，或直接用人写摘要训练。

影响

成为神经抽取式摘要的代表性基线，“句子级序列二分类加贪心ROUGE造标签”的做法被BertSum等后续抽取式模型直接沿用。

背景

自动摘要分两类：抽取式从原文挑句子拼成摘要，生成式重新写一段话。LexRank图排序摘要、TextRank等无监督方法按句子之间的相似度做图排序，神经生成式摘要（2015）和后来的指针网络开启了神经生成式摘要，但生成式模型当时常出现事实错误和重复。注意力阅读器与CNN/DM整理出的CNN/DailyMail新闻—要点数据为监督学习提供了规模足够的语料，却没有句子级的抽取标签。

方法

模型是一个层次RNN：底层双向GRU读词，平均池化得到每个句子的向量；上层双向GRU读句子序列，得到句子在文档中的表示 h_j，再平均得到文档表示d。对第j句按顺序计算被选概率

P(y_j=1) = σ( W_c·h_j + h_jᵀ W_s d − h_jᵀ W_r tanh(s_j) + W_ap·p_j^a + W_rp·p_j^r + b )

五项分别对应：句子本身的信息量（content）、与全文的相关度（salience）、与已选内容的重复度（novelty，s_j 是前面各句按被选概率加权求和的“摘要表示”，减号表示越重复越不选）、绝对位置和相对位置。因为每项都是单独的分数，可以把一句话为什么被选拆开来看，作者称之为可解释性。

标签：用贪心法逐句加入能使与人写摘要的ROUGE最大化的句子，得到0/1标签做交叉熵训练。论文另提出“生成式训练”：在句子表示上接一个解码器去生成人写摘要，从而不需要句子标签也能训练抽取模型。

结果

论文报告其效果优于或与当时最先进的方法相当（摘要所述），并展示了按信息量、显著度、新颖度拆分的预测可视化；具体ROUGE数字未在此引用。

后来的发展

SummaRuNNer确立了神经抽取式摘要的标准形式：把摘要当作句子级序列标注、用贪心ROUGE构造“预言”标签。BertSum预训练摘要（2019）把底层编码器换成BERT、在句子上做同样的二分类，效果大幅提升；指针-生成器摘要等生成式模型则在同一数据上与它对比。CNN/DM阅读理解审查等分析工作指出新闻摘要强烈依赖导语位置，这也解释了位置特征的作用。

本篇术语

  • 抽取式摘要　从原文中挑出若干句子直接组成摘要，不改写。
  • ROUGE　摘要评测指标，计算系统摘要与人写摘要之间n元组或最长公共子序列的重合程度。
  • 预言标签　用贪心搜索找出能让ROUGE最高的句子组合，把这些句子标为1作训练标签。

怎么学

先读LexRank图排序摘要了解抽取式摘要 → 读本文第2–3节模型与造标签 → 动手：在CNN/DailyMail几十篇文章上实现贪心ROUGE造标签，看被选中的句子有多少落在前三句。
