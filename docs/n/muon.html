Muon优化器

Muon: An optimizer for hidden layers in neural networks
2024.12思想重要技术博客 2024-12Keller Jordan, Yuchen Jin, Vlado Boza, Jiacheng You, Franz Cesista, Laker Newhouse, Jeremy Bernstein · 个人博客与modded-nanogpt速通社区待核对
原始博客 ↗modded-nanogpt速通仓库 ↗Old Optimizer, New Norm（理论来源） ↗在交互版中打开（演化树、学习进度）

问题

AdamW统治大模型训练多年，号称更好的新优化器大多因为对比的AdamW基线没调好而无法复现；同时Adam逐坐标缩放，不利用权重是一个矩阵这一结构。

方法

对隐藏层的每个权重矩阵，先算动量，再用5步Newton–Schulz迭代把动量矩阵近似正交化（奇异值都拉到1附近）作为更新方向；嵌入层、输出层和向量参数仍用AdamW。

影响

在公开的NanoGPT训练速通竞赛中把纪录提速35%，此后一直被保留；训练1.5B模型达到GPT-2 XL水平只需10个8×H100小时（AdamW要13.3小时）。后被Moonlight、Kimi K2扩展到大模型。

背景

Adam和AdamW对每个参数坐标单独估计梯度尺度，不管这些坐标同属一个矩阵。利用矩阵结构的二阶方法如K-FAC、Shampoo理论上更好，但要算矩阵的逆四次方根，开销大、要高精度，很少用于大模型预训练。

另一个问题是证据。作者认为优化器文献里“坟场”般堆满了号称打败AdamW却没人采用的方法，最常见的原因是对比时AdamW没调好。modded-nanogpt速通提供了一个检验场：在nanoGPT的GPT-2小模型上，比谁用最少时间把FineWeb验证损失降到3.28。纪录本身就是调得最好的基线，新方法若是虚假的改进，下一个人把它换回AdamW就能刷新纪录。

方法

定义。对每个二维权重矩阵W，取小批量梯度G：

B ← μB + G（动量法，默认用Nesterov形式） O ← NewtonSchulz5(B) W ← W − η·O

正交化是什么。设B = USVᵀ（特征分解与奇异值分解），正交化就是把它换成UVᵀ：保留方向，所有奇异值变成1。作者观察到SGD动量和Adam给Transformer矩阵的更新条件数很大，几乎是低秩的，少数方向占了主导；正交化等于放大那些幅度小但对学习同样重要的“稀有方向”。

为什么用Newton–Schulz。直接做SVD太慢。先把B除以它的Frobenius范数，使奇异值落在[0,1]，再迭代X ← aX + b(XXᵀ)X + c(XXᵀ)²X。每一步相当于对每个奇异值s做φ(s) = as + bs³ + cs⁵，系数(3.4445, −4.7750, 2.0315)让小奇异值快速升到0.7到1.3之间；不要求精确到1，经验上不影响训练。迭代只用矩阵乘法，可以在bfloat16下稳定运行。

代价。额外计算约为T·m/B（T=5步，m为模型宽度，B为每批token数）：NanoGPT速通约0.7%，若用于Llama 405B训练约0.5%。显存与SGD动量相同，只存一份动量，比Adam少一半。

与Shampoo的关系。Shampoo去掉累积后，更新(GGᵀ)^{−1/4} G (GᵀG)^{−1/4}恰好等于UVᵀ，所以Muon可看作“无累积的Shampoo”加动量，并换成更便宜的迭代。

结果

博客列出的结果：CIFAR-10训练到94%精度的速度纪录从3.3降到2.6个A100秒；NanoGPT速通纪录提速1.35倍，并在774M和1.5B参数上继续显示优势；1.5B参数Transformer在HellaSwag上达到GPT-2 XL水平只需10个8×H100小时，同样目标AdamW需13.3小时。2024年10月15日换用Muon创下纪录后，之后由7位研究者刷新的12个纪录都保留了Muon。

后来的发展

博客结尾留下的问题——能否扩展到20B以上参数、能否在大集群上高效分布式实现——几个月内就有了回答：Muon规模化到LLM加入权重衰减并按矩阵形状调整更新尺度，训练了16B参数的MoE模型Moonlight；Kimi K2在万亿参数规模上用它的改进版MuonClip，解决注意力logit爆炸。DeepSeek-V4百万上下文等后续模型也采用了Muon。它让“按矩阵整体设计更新”的优化器重新成为研究热点。

容易误解的地方

  • Muon只用于隐藏层的二维矩阵；嵌入层、最后的分类头以及偏置、归一化增益仍要用AdamW，否则效果变差。
  • 正交化后更新的整体尺度与AdamW不同，直接沿用AdamW的学习率不行；要么重调，要么按Muon规模化到LLM的方法换算。
  • 主要证据来自小模型速通竞赛，博客本身不是同行评审论文；作者明确把大规模、微调和强化学习上的效果列为未知。

局限与后续

  • 只在约15亿参数以下验证，能否扩展到数百亿参数、上万亿token的训练当时未知。

  • 改进
    Adam2014.12 · 基础 待核对
    按坐标独立缩放（对角预条件），忽略了权重矩阵内部参数之间的相关结构。
  • 使用
    动量法1964 · 基础
    Muon的第一步就是普通的SGD动量（Nesterov形式），正交化只是对动量矩阵的后处理。
  • 竞争
    AdamW2017.11 · 基础
    在NanoGPT速通中样本效率和墙钟时间都胜过精调的AdamW，但嵌入层和输出层仍交给AdamW。
  • 竞争
    K-FAC2015.03 · 基础
    同样利用矩阵结构改造梯度，但不估计曲率，只需几次矩阵乘法，开销低于1%。
  • 延续
    Shampoo2018.02 · 基础
    去掉预条件累积的Shampoo更新恰好是正交化的梯度；Muon加上动量，并用Newton–Schulz代替昂贵的逆四次方根。
  • 使用
    nanoGPT2022.12 · 系统·效率
    以nanoGPT的GPT-2小模型训练为基准任务，证据主要来自在其上的速通纪录。
  • 使用
    modded-nanogpt速通2024.06 · 系统·效率
    借助速通竞赛的“纪录即最强基线”机制，回避了新优化器常见的弱基线问题。

读懂它需要的概念

梯度下降 动量 自适应学习率优化器 特征分解与奇异值分解 矩阵乘法与线性变换 学习率与学习率调度

本篇术语

  • 正交化　把矩阵的奇异值分解USVᵀ换成UVᵀ，保持方向不变、把所有奇异值变成1。
  • Newton–Schulz迭代　只用矩阵乘法逐步把矩阵推向最近的正交矩阵的迭代法，比SVD快，能在低精度下运行。
  • 条件数　最大奇异值与最小奇异值之比；越大说明矩阵越接近低秩，少数方向占主导。
  • 训练速通　公开竞赛：在固定硬件上用最短时间把模型训练到指定验证损失，所有改动都要能复现。

怎么学

先补特征分解与奇异值分解和动量，看懂AdamW的更新规则。读博客的“Design”一节，自己验证一步Newton–Schulz等于对奇异值作用一个五次多项式；再读与Shampoo关系一节。动手：在numpy里对随机矩阵跑5步迭代，画出奇异值前后的分布；然后在nanoGPT上把隐藏层换成Muon、其余参数用AdamW，对比验证损失曲线。
