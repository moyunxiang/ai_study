ChatGLM-6B

2023.03模型延伸智谱AI / 清华大学KEG（THUDM）待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT之后，中文用户缺少一个能在自己的消费级显卡上跑起来的开放对话模型。

方法

在GLM架构的62亿参数模型上，用中英双语数据预训练再做对话对齐，并提供量化，使普通显卡就能部署。

影响

成为第一批在国内开发者中广泛使用的开源中文对话模型，降低了本地部署和微调大模型的门槛。

方法

ChatGLM-6B基于GLM-130B一脉的General Language Model架构，共62亿参数。官方介绍称它经过约1T标识符的中英双语训练，再配合监督微调、反馈自助和人类反馈强化学习，使回答更接近人的偏好，技术路线与ChatGPT发布相似，但针对中文问答和对话做了优化。

部署上最有意义的是量化：官方称在INT4量化下最低只需6GB显存，一块消费级显卡就能本地运行。仓库同时提供基于P-Tuning v2的高效参数微调方案，方便下游开发者定制。

模型以开源方式放出，后续迭代出ChatGLM2-6B等版本。

结果

官方README给出了参数量、训练规模和显存需求；与其他模型的系统性对比数字本篇未核对，故不列。

后来的发展

ChatGLM系列随后演进为智谱的GLM系列（见GLM空白填充），与通义千问Qwen、Baichuan 2等一起构成中文开源模型的早期主力。

局限与后续
