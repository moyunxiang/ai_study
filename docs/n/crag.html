CRAG纠错式检索增强

Corrective Retrieval Augmented Generation
2024.01论文延伸Shi-Qi Yan, Jia-Chen Gu, Yun Zhu, Zhen-Hua Ling · 中国科学技术大学 / UCLA / Google DeepMind待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

RAG默认相信检索结果；检索错了，模型会照着无关或误导性的文档作答，反而更容易出错。

方法

先用一个小的检索评估器给取回的文档打置信度：可信就提炼要点使用，不可信就改用网页搜索，拿不准就两者结合。

影响

作为即插即用模块，在四个短文本和长文本生成数据集上提升了标准RAG和Self-RAG，「先判断检索质量再决定怎么用」成为RAG流水线的常见环节。

方法

CRAG在检索和生成之间插入三步：

  • 检索评估器：用T5-large初始化并微调的小模型，读「问题+文档」给出相关性分数，再按两个阈值把整体结果判为正确、错误或模糊三类。
  • 按判断采取动作：「正确」时只用检索到的文档；「错误」时丢掉它们，改用大规模网页搜索（先用改写器把问题改写成搜索查询）；「模糊」时两种来源都用。
  • 知识精炼（分解—重组）：把文档切成更小的片段，用评估器给每段打分，过滤掉无关片段后再拼起来交给生成模型。

它不改生成模型，可以接在普通检索增强生成RAG或Self-RAG后面。论文在PopQA、Biography、PubHealth和Arc-Challenge上报告，加上CRAG后两类方法都明显提升。

局限与后续

  • 评估器需要用带相关性标签的数据单独训练，换到新领域时判断可能不准；阈值也要手工设定。

  • 判为错误时依赖商业网页搜索，结果质量和可复现性受搜索引擎影响。

它建立在什么之上

  • 改进
    检索增强生成RAG2020.05 · 推理·智能体
    针对检索出错时RAG会被误导的问题，在生成前评估并纠正检索结果。
  • 使用
    T52019.10 · LLM
    检索评估器由T5-large初始化后微调。
  • 使用
    Contriever无监督检索2021.12 · 推理·智能体
    为与Self-RAG可比，沿用基于Contriever的同一批检索结果。
  • 改进
    验证链CoVe2023.09 · 推理·智能体
    核查仍靠模型自己的知识，模型本来就不知道的事实，核查时同样会答错；也不能纠正推理过程中的错误。
  • 延续
    Self-RAG2023.10 · 推理·智能体
    Self-RAG让生成模型自己反思检索内容，CRAG把评估交给独立的小模型，并可与Self-RAG叠加。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

怎么学

先读检索增强生成RAG和Self-RAG → 读原文第4节三种动作与知识精炼 → 动手：用一个交叉编码器给检索结果打分，设两个阈值，观察过滤前后答案准确率的变化。
