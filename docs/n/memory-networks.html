记忆网络

Memory Networks
2014.10论文延伸ICLR 2015Jason Weston, Sumit Chopra, Antoine Bordes · Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RNN和LSTM把全部知识压进一个隐状态，装不下长篇事实，也很难把几句话串起来回答问题。

方法

给模型接一个可以读写的长期记忆（相当于动态知识库），再让几个推理组件学着怎样联合使用它。

影响

开启了“神经网络加外部记忆”的问答路线，并给出bAbI类多跳推理任务的早期解法，直接引出端到端可训练的版本。

方法

记忆网络由四个组件构成：I把输入转成内部表示，G把表示写入记忆槽，O根据问题从记忆里读出最相关的内容，R把读出的内容转成文字回答。回答“Joe去了哪”这类问题时，O先找出与问题最匹配的一句，再以问题加这句为新查询找第二句，这样就能串联多条证据。

匹配用的是带学习参数的打分函数，读取的每一步都要有“哪几句是支持事实”的监督。论文在一个大规模问答任务和一个由模拟世界生成的小而复杂的玩具任务上做了评测，后者要求串联多个支持句并理解动词含义。

它的弱点很清楚：读取是硬选择，不可微，需要给每一步的支持事实加标注，所以训练监督重。

局限与后续

  • 记忆读取是硬选择、不可微，每一步都需要标注哪些句子是支持事实，监督成本高。
