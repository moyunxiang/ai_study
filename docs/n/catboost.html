CatBoost

CatBoost: unbiased boosting with categorical features
2017.06论文延伸NeurIPS 2018Liudmila Prokhorenkova, Gleb Gusev, Aleksandr Vorobev, Anna Veronika Dorogush, Andrey Gulin · Yandex待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

梯度提升处理类别特征时，常用的目标统计编码会泄漏标签；每一轮用同一批样本既算梯度又拟合树，也造成预测偏移。

方法

提出有序目标统计和有序提升：按随机排列，每个样本只用排在它前面的样本来计算编码和残差，避免用自己的标签。

影响

成为与XGBoost、LightGBM并列的主流提升树库，对含大量类别特征的表格数据尤其方便。

方法

论文指出，现有的梯度提升实现都存在一种“预测偏移”：训练样本的梯度是用已经见过这些样本标签的模型算出的，其分布与测试样本不同，属于一种目标泄漏。处理类别特征时，把类别替换为该类别的平均标签（目标统计）同样会泄漏，因为样本自己的标签也被算进了平均值。

作者给出两个对策。其一是有序目标统计：随机排列训练样本，每个样本的类别编码只用排在它之前的样本计算。其二是有序提升：同样按排列，用只训练于前面样本的模型来估计当前样本的残差，从而让梯度估计不依赖该样本自身的标签。论文还用理论分析说明这种偏移确实存在。作者报告，在多个数据集上，CatBoost的质量优于当时公开的其他提升实现。

局限与后续

  • 有序提升需要为不同的排列维护多个模型，训练比普通提升更慢、更占内存。
