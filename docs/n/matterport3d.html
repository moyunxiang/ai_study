Matterport3D室内RGB-D

Matterport3D: Learning from RGB-D Data in Indoor Environments
2017.09数据集延伸3DV 2017Angel Chang, Angela Dai, Thomas Funkhouser, Maciej Halber, Matthias Nießner, Manolis Savva, Shuran Song, Andy Zeng, Yinda Zhang · 普林斯顿大学 / 斯坦福大学 / 慕尼黑工业大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

训练室内RGB-D场景理解需要大而多样的数据，但已有数据集要么视角有限，要么只覆盖单个房间大小的空间，缺少整栋建筑尺度、精确对齐的扫描。

方法

用Matterport商用相机扫描90栋建筑，得到19.44万张RGB-D图像合成的1.08万个全景视角，并提供表面重建、相机位姿和二维、三维语义分割标注。

影响

成为室内三维理解和具身智能的基础场景库：视觉语言导航R2R、Habitat等仿真平台都以它的房屋扫描为环境，后来又扩展出更大的HM3D。

方法

Matterport3D的数据来自Matterport公司的三维扫描相机：相机在房间内多个位置旋转拍摄，每个位置得到一组RGB-D图像，拼成一个全景视角。数据集覆盖90个建筑尺度的场景（整套住宅等），共194,400张RGB-D图像、10,800个全景视角。

标注。每个场景都给出精确全局对齐的相机位姿、表面重建网格，以及二维和三维的语义分割（房间区域、物体实例和类别）。由于每栋建筑的全景视角覆盖全面且互相精确对齐，同一套数据可以做多种有监督和自监督任务：关键点匹配、视角重叠预测、从彩色图预测表面法向、语义分割和区域（房间类型）分类。

与只扫描单个房间、视角来自手持移动的ScanNet，以及更早的NYU Depth V2室内深度相比，Matterport3D的特点是整栋建筑尺度和全景覆盖。之后，R2R视觉语言导航在它的房屋扫描上构建了视觉语言导航任务，Habitat具身仿真等具身仿真平台也支持直接载入这些场景。

局限与后续

  • 只有90个场景，数量不足以训练能泛化到大量新房屋的具身导航智能体。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 扫描是静态的，物体不能移动或交互，无法用于需要操作物体的具身任务。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

分类、检测、分割 相机模型与多视图几何 三维表示：体素、点云、网格、隐式场

怎么学

先了解RGB-D相机和点云、网格等三维表示。读原文第3节数据采集和第5节任务；动手下载一个场景，用Open3D或Habitat查看重建网格和语义标注。
