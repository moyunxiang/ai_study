相关模型RM

Relevance-Based Language Models
2001.09论文延伸SIGIR 2001Victor Lavrenko, W. Bruce Croft · 马萨诸塞大学阿默斯特分校智能信息检索中心待核对
UMass CIIR ↗DOI ↗在交互版中打开（演化树、学习进度）

问题

经典概率检索模型的核心是「相关模型」，即词在相关文档类别中出现的概率，可没有相关性标注就估不出来；而新兴的语言模型检索方法干脆不再显式建模相关性，也就难以做查询扩展、处理同义和多义。

方法

只用查询本身估计相关模型：把查询词看作从未知的相关模型中抽出的样本，用初次检索得到的文档语言模型作为候选分布，按各文档生成整个查询的概率加权平均，得到每个词在相关类中的概率，再用它对文档重新排序。

影响

在TREC检索和TDT话题追踪上都超过基准语言模型检索系统；它的实现（与原查询插值的版本俗称RM3）成为伪相关反馈和查询扩展的标准强基线，在神经检索时代仍被广泛对照。

方法

RSJ权重与二元独立模型等经典概率模型按P(w|R)（词在相关文档中出现的概率）给文档打分，但R未知；Rocchio相关反馈式的相关反馈要用户先标出相关文档。另一方面，语言模型检索（查询似然）按文档模型生成查询的概率排序，本身没有「相关」这个概念。

Lavrenko和Croft把两者连起来：设查询q₁…q_k是从相关模型R中抽出的样本，则P(w|R) ≈ P(w | q₁…q_k)。为了估计这个条件概率，取一组候选分布（初次检索排名靠前的文档各自的平滑一元语言模型M），方法一（独立同分布采样）假设w和所有查询词来自同一个M：P(w, q₁…q_k) = Σ_M P(M)·P(w|M)·Π_i P(q_i|M)；方法二（条件采样）先选w，再为每个查询词各自选一个分布。论文发现方法二对候选分布集合不敏感、表现更好，在实验中采用它。直观上，在与查询最匹配的文档里频繁出现的词，会在相关模型中得到较高概率，即使它不在查询中出现，这就是自动的查询扩展。最后用相关模型与文档模型之间的KL散度（或概率比）排序。

实验在TDT2（约6.3万条广播新闻、96个话题）上检验相关模型与真实话题模型的交叉熵，在TREC AP新闻（16.4万篇以上，101–200号标题查询）上做检索，在TDT上做话题追踪，相关模型都超过基准语言模型系统。

局限与后续

  • 依赖初次检索的质量：如果排在前面的文档大多不相关，扩展出的词会把查询带偏（查询漂移）。

  • 每个查询都要先检索一遍、再对大量候选词计算概率并二次检索，在线开销比单次检索大得多。

它建立在什么之上

  • 改进
    RSJ权重与二元独立模型1976.05 · NLP
    经典概率模型需要相关类中的词概率却无从估计；相关模型给出了只用查询、无需训练数据的估计方法。
  • 使用
    TREC文本检索评测1992.11 · 数据·评测
    检索实验使用TREC第1–2卷中的AP新闻与101–200号查询。
  • 竞争
    Rocchio相关反馈1971 · NLP
    Rocchio相关反馈在向量空间中把查询向相关文档平移；相关模型在概率框架内做伪相关反馈，不需要用户标注。
  • 延续
    语言模型检索（查询似然）1998.08 · NLP
    在Ponte-Croft的语言模型检索框架内重新引入显式的相关模型。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

语言模型 条件概率与贝叶斯公式 KL散度 交叉熵 检索与向量数据库

本篇术语

  • 伪相关反馈　不让用户标注，直接假设初次检索排在最前的若干篇文档是相关的，用它们来改进查询。
  • 查询扩展　往查询里加入原本没有、但与主题相关的词，以召回用词不同的相关文档。

怎么学

先读语言模型检索（查询似然）和Rocchio相关反馈的讲解 → 读原文第3节两种估计方法 → 动手：用Pyserini或Anserini在一个TREC数据上比较BM25、查询似然和RM3的平均精度。
