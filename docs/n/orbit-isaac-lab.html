Orbit / Isaac Lab

Orbit: A Unified Simulation Framework for Interactive Robot Learning Environments
2023.01系统延伸IEEE RA-L 2023（arXiv 2023-01）Mittal, Yu, Yu, Liu, Rudin, Hoeller, Yuan, Singh et al. · NVIDIA / Univ. of Toronto / ETH Zurich 等待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

Isaac Gym大规模并行仿真速度快但物理与渲染简化、功能偏底层；做操作、移动操作和带视觉的机器人学习，需要更真实、模块化的仿真框架。

方法

在NVIDIA Isaac Sim上构建统一的模块化机器人学习框架Orbit，提供照片级场景、刚体与可变形体仿真，并保留GPU并行。

影响

后来更名为Isaac Lab，成为NVIDIA体系下机器人强化学习与模仿学习的主要开源平台。

方法

Orbit提供模块化组件：多种机器人（摘要称16个平台，含固定机械臂与移动操作机器人）、4种传感器模态、10种运动生成器、20多个基准任务，并封装了4种学习库的接口。得益于GPU并行，它可以在几分钟内训练强化学习策略，或用手工设计或专家方案采集大规模演示数据。

它的任务涵盖单阶段的开柜子、折布，以及整理房间这样的多阶段任务，试图在统一接口下覆盖表示学习、强化学习、模仿学习和任务运动规划。
