众包标注Mechanical Turk

2005.11系统延伸Amazon · Amazon Web Services待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

AI训练需要海量人工标注，但雇人做标注手续繁琐、成本高，学术团队很难凑够规模。

方法

做成一个在线劳务市场，需求方把任务拆成每个几秒钟的小任务（HIT）发布，成千上万的人随时领取并按件拿报酬。

影响

它把标注成本降低了一个量级，ImageNet等数据集靠它才得以建成，也催生了整个数据标注外包行业。

方法

Mechanical Turk于2005年上线，名字取自18世纪那台假装会下棋的机器「土耳其人」，亚马逊称之为「人工的人工智能」：把计算机一时做不好的部分交给人。据维基百科，该服务源于Venky Harinarayan在2001年提交的专利披露。需求方（requester）发布「人类智能任务」（HIT），例如在图片里找某种物体、写商品描述、回答问卷；工人（Turker）领取并完成，按需求方定的价格收费，需求方通过开放API批量发布任务。

对研究者来说，它让标注变得几乎可以随时、按需、小批量试验。众包标注够好吗一文检验了其标注质量，ImageNet用它为数百万图片打标签，Flickr30k、VQA等也靠它收集描述和答案。据维基百科，亚马逊已于2026年9月30日关闭该服务。

它的争议主要在劳工待遇：任务单价很低，工人没有劳动保障。

局限与后续

  • 单价低、质量参差，需要多人重复标注和额外质检才能得到可靠标签。
    后来针对它的工作　众包标注够好吗 Scale AI与标注外包产业
  • 工人的收入和权益缺少保障，大规模标注的伦理问题长期存在。
    后来针对它的工作　Scale AI与标注外包产业
