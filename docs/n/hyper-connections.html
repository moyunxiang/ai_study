超连接

Hyper-Connections
2024.09论文延伸ICLR 2025Defa Zhu, Hongzhi Huang, Zihao Huang, Yutao Zeng, Yunyao Mao, Banggu Wu, Qiyang Min, Xun Zhou · ByteDance Seed待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

ResNet式残差连接在梯度消失与表示坍塌之间存在跷跷板效应（Pre-LN偏向前者的缓解，Post-LN偏向后者）。

方法

把单条残差流扩展成多条并行流，并让各流之间与各层之间的连接强度可学习，必要时可随输入动态变化。

影响

为“残差流可以更宽”这一方向奠基，之后被DeepSeek的mHC改进。

方法

残差连接只有一条贯穿全网络的流，每层输出加回输入。超连接把隐状态复制成n份（论文中的扩展率），层的输入由这些流用可学习权重组合得到，层的输出再按可学习权重加回各流，各流之间也有混合矩阵，网络因此能自己调节不同深度间的连接强度，甚至重新排列层的先后。

论文在密集和稀疏大语言模型预训练中报告了相对残差连接的明显改进，例如OLMoE-1B-7B加动态超连接的版本，并在视觉任务上也有类似提升。

局限与后续

  • 多条残差流增加了显存与访存开销，激活内存随扩展率增长。
    后来针对它的工作　mHC流形约束超连接
  • 不受约束的混合矩阵破坏了残差的恒等映射性质，大规模训练可能不稳定。
    后来针对它的工作　mHC流形约束超连接

它建立在什么之上

  • 延续
    ResNet2015.12 · 视觉
    把单一残差通路扩展为多通路并让连接可学习。
  • 延续
    Highway网络2015.05 · 基础
    与Highway一样让层间连接可学习，但Highway是门控一条流，超连接是多条流的混合。

后来的相关工作

  • 改进
    mHC流形约束超连接2025.12 · 基础
    超连接训练不稳定且难以扩展；mHC用流形约束恢复恒等映射性质。
  • 竞争
    注意力残差AttnRes2026.03 · LLM
    同样想改造残差路径：Hyper-Connections拓宽残差流的宽度，AttnRes则让各层按内容选择聚合哪些前层输出。

读懂它需要的概念

残差连接 归一化层 梯度消失与梯度爆炸 多层感知机 参数量、计算量与显存

怎么学

先复习ResNet与Pre-LN/Post-LN的区别；读原文第2节的静态与动态超连接定义；用PyTorch把一层Transformer的残差改成n=2的超连接并比较小模型训练曲线。
