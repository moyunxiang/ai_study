OpenSpiel博弈框架

OpenSpiel: A Framework for Reinforcement Learning in Games
2019.08系统延伸arXiv 2019Marc Lanctot, Edward Lockhart, Jean-Baptiste Lespiau, Vinicius Zambaldi, Satyaki Upadhyay, Julien Pérolat, Sriram Srinivasan, Finbarr Timbers et al. · DeepMind待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

博弈论、搜索与多智能体RL的研究各自用自己的游戏实现和算法代码，扑克、棋类、合作博弈之间难以统一比较，新人也很难同时学会三个领域的术语和工具。

方法

提供一个统一的框架：同一套接口描述各类博弈（多人、零和/合作/一般和、同时行动、完全/不完全信息），并附带CFR、PSRO、AlphaZero等经典算法的参考实现和评测工具。

影响

成为博弈与多智能体RL研究最常用的开源平台之一，许多CFR变体、PSRO变体和不完全信息博弈的论文都在它上面实现和对比。

方法

OpenSpiel把每个游戏写成一棵扩展式博弈树的生成器：给出当前状态、轮到谁、合法动作、机会节点的概率、每个玩家能观察到的信息（信息状态）和终局收益。摘要称，它支持n人（单智能体和多智能体）的零和、合作与一般和博弈，单次和序贯博弈，严格轮流和同时行动，完全和不完全信息，以及网格世界、社会困境等传统多智能体环境。

算法方面，库里同时收录了计算博弈论的方法（反事实遗憾最小化CFR及其采样变体、虚拟博弈、PSRO博弈论元求解）、搜索方法（蒙特卡洛树搜索UCT、alpha-beta）和RL方法（AlphaZero、神经虚拟自我对弈NFSP、策略梯度等），并带有分析学习动态和可剥削度等常用评测指标的工具。文档本身也被写成三个领域术语、核心概念和算法的入门介绍。

局限与后续

  • 以小型和中型博弈为主，库里的通用实现在大型游戏（如无限注扑克、围棋全尺寸）上远达不到专用系统的效率。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 很多游戏的状态表示需要用户自己设计，不直接提供图像等丰富观测，与深度RL的大规模环境衔接较弱。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    反事实遗憾最小化CFR2007 · RL
    CFR及其多种变体是库中不完全信息博弈求解的核心实现。
  • 使用
    PSRO博弈论元求解2017.11 · RL
    PSRO等博弈论元求解方法是库的重点之一，其第一作者团队也来自DeepMind。
  • 使用
    AlphaZero2017.12 · RL
    收录AlphaZero式的自我对弈加搜索算法作为参考实现。
  • 竞争
    OpenAI Gym2016.06 · RL
    Gym为单智能体环境提供统一接口；OpenSpiel面向多人、不完全信息的博弈，接口围绕博弈树和信息状态设计。

本篇术语

  • 扩展式博弈　用一棵树描述多步博弈：节点是局面，边是动作，叶子是各玩家的收益，看不到的信息用信息集表示。

怎么学

按官方教程安装后，在库恩扑克上运行CFR并画出可剥削度曲线；再在井字棋上跑MCTS和AlphaZero示例，体会同一接口下不同算法的用法。
