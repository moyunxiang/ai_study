Ouro循环语言模型

Scaling Latent Reasoning via Looped Language Models
2025.10论文延伸Rui-Jie Zhu, Zixuan Wang, Kai Hua, Tianyu Zhang, Ziniu Li, Haoran Que, Boyi Wei, Zixin Wen et al. · 字节跳动Seed等待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

现在的模型主要靠写出思维链来“思考”，推理能力推迟到后训练才培养，预训练数据里的推理潜力没被充分利用。

方法

在预训练阶段就让同一叠层循环计算多次，在潜空间里迭代“思考”，并用带熵正则的目标让模型自己学每个输入该循环几次。

影响

第一次把循环语言模型预训练到7.7T token并开源，1.4B/2.6B模型追平最多12B的普通模型，让“循环深度”成为一个新的规模维度。

方法

Universal Transformer和递归混合MoR已经展示了共享权重、循环计算的可能，但都停留在小规模。Ouro（取名自首尾相接的衔尾蛇）把这一思路做成完整的预训练模型族：网络由一组共享参数的层构成，前向时循环多次，每次循环都在隐藏状态上继续加工，相当于不输出文字的“潜在推理”。

训练目标里加入了一个熵正则化的深度分配项，让模型学会对不同输入提前停止或多循环几次；全部训练量达到7.7T token。发布的模型循环4次；作者最初用8次，但出现损失尖峰和梯度不稳定，改为4次。摘要称Ouro 1.4B和2.6B在多类基准上追平最多12B的当时最强模型。作者用受控实验说明优势来自更强的“知识运用”（组合、操作已有知识）而不是更大的知识容量，在MATH500等数学推理上明显领先同级Qwen3（1.4B为82.4，Qwen3-4B为59.6），但在MMLU、HumanEval等知识与代码任务上落后。论文还发现循环模型中间步骤与最终输出的一致性比显式思维链更高。

局限与后续

  • 循环次数难以加大：8次循环训练不稳定，最终只用4次；而且循环越多推理越慢，与同等计算量的更大模型相比实际部署是否划算仍不确定。

  • 潜空间推理不产生可读的中间步骤，难以像显式思维链那样检查和监督。

它建立在什么之上

  • 竞争
    思维链CoT2022.01 · 推理·智能体
    思维链在文字中显式推理，Ouro在隐藏状态里循环推理；论文称后者与输出更一致。
  • 使用
    ALBERT参数共享2019.09 · LLM
    借用层间参数共享，让小参数量模型获得更深的有效计算。
  • 延续
    Universal Transformer2018.07 · LLM
    沿用循环共享层的结构，规模从研究原型推到7.7T token预训练。
  • 改进
    递归混合MoR2025.07 · LLM
    同为自适应循环深度，Ouro用熵正则目标学习深度分配，并把它做进万亿token级的预训练。
