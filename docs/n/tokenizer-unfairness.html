分词器的跨语言不公平

Language Model Tokenizers Introduce Unfairness Between Languages
2023.05论文延伸NeurIPS 2023Aleksandar Petrov, Emanuele La Malfa, Philip H. S. Torr, Adel Bibi · 牛津大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型按词元计费、按词元限制上下文长度、按词元计算延迟，但同一段话译成不同语言后，被分词器切出的词元数可能相差很大；这种差异在模型运行之前就已经产生，却很少被量化。

方法

用平行语料（同一内容的多语言译文）测量各种分词器在不同语言上的“分词溢价”——某语言的词元数相对英语的倍数，覆盖子词、字符级和字节级分词器，并讨论它对费用、延迟和可用上下文的影响。

影响

发现同一文本在不同语言下的分词长度最多相差15倍，专门为多语言训练的分词器也存在明显差异，字符级与字节级模型在某些语言对上也有超过4倍的差距；论文推动了“多语言公平分词”的讨论，后续大模型在扩大词表、平衡多语言语料时常引用这一问题。

背景

BPE子词切分和SentencePiece按训练语料中的频率合并字符，训练语料以英语为主时，英语常用词被合并成单个词元，而低资源语言的文字只能被切成很多碎片。字节级BPE（BBPE）在字节上做BPE，避免了未知字符，但UTF-8中非拉丁文字本身就占多个字节。商业大模型（如GPT-4）按词元计费，上下文窗口也以词元计。

方法

度量：在FLORES-200这类平行语料上，对每个分词器和每种语言计算整套语料的词元数，定义该语言相对英语的分词溢价 premium(L) = |tokens(L)| / |tokens(英语)|。溢价为1表示与英语同样“便宜”，为5表示同样内容要用5倍的词元。

被测分词器：GPT-2、RoBERTa、ChatGPT/GPT-4使用的cl100k_base等英语为主的BPE分词器；mBERT、XLM-R、mT5、BLOOM等多语言模型的分词器；以及字符级（CANINE）和字节级（ByT5）模型。

影响分析：作者把溢价换算为三方面的不平等：按词元计费的API费用、处理时间与延迟（与词元数近似成正比）、以及在固定上下文窗口中能放下的内容量（溢价为4的语言实际只有四分之一的上下文）。最后讨论训练多语言公平的子词分词器的可能做法。

结果

同一文本译成不同语言后，分词长度最多相差约15倍；即使是为多语言支持而训练的分词器也存在这种差异；字符级和字节级模型在某些语言对之间的编码长度也相差4倍以上（arXiv摘要）。

后来的发展

这项研究与同期对多语言词元化成本的研究一起，使“分词公平性”成为评估多语言大模型的一个维度；后续模型（如更大词表的多语言分词器）和若干分词改进方法都以平行语料上的词元溢价作为指标。欠训练词元检测等工作则从另一个角度揭示了分词器与模型训练脱节带来的问题。

读懂它需要的概念

分词与token 上下文窗口 特殊token 基准、排行榜与SOTA

本篇术语

  • 分词溢价　同一内容在某种语言下的词元数除以英语下的词元数，衡量该语言“贵”多少。
  • 平行语料　同一批句子的多种语言译文，可用来公平比较不同语言的长度。

怎么学

先了解BPE子词切分与字节级BPE（BBPE） → 读本文第3节度量与第4节影响分析 → 动手：用tiktoken与XLM-R分词器，对FLORES-200中同一句话的英语、中文、阿姆哈拉语等版本计数词元，算出各自的溢价。

待核对　这篇讲解由AI模型撰写，尚未对照原始来源独立核对。写作时记录的出处：https://arxiv.org/abs/2305.15425（arXiv：标题Language Model Tokenizers Introduce Unfairness Between Languages、作者Petrov、La Malfa、Torr、Bibi，v1提交于2023-05-17；摘要：不同语言的处理差异在分词阶段就已产生，同一文本译成不同语言后分词长度可相差多达15倍，有意为多语言训练的分词器也存在差异，字符级与字节级模型在某些语言对上编码长度相差4倍以上，导致商业语言服务费用、处理时间与延迟、可放入上下文的内容量的不公平，主张用多语言公平的子词分词器训练未来模型。NeurIPS 2023出处、FLORES-200与被测分词器清单凭一般了解。）
