KataGo

Accelerating Self-Play Learning in Go
2019.02论文延伸arXiv 2019David J. Wu待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

AlphaZero类方法要成千上万块加速器连跑数天，普通研究者无法复现围棋自我对弈学习。

方法

保留AlphaZero的核心流程，叠加多项改进：多目标（辅助）训练、全局池化、随机化搜索次数等，并加入围棋特有的技巧。

影响

把达到强水平所需的算力降低到一般团队可承担，成为最强的开源围棋AI之一。

方法

论文摘要的定量陈述是：相对可比方法节省50倍算力；KataGo在不到30块GPU上训练19天后，就超过了ELF OpenGo的最终模型（ELF用了数千块GPU两周）。

它的改进里有一部分是不依赖围棋的通用技巧，另一部分是围棋专用特征。作者指出专用技巧带来的额外收益，说明最好的方法与完全通用的AlphaZero之间仍有效率差距。具体每项改进的贡献这里没有逐项核对，不展开。

局限与后续

  • 通用技巧之外的提速依赖围棋专用特征，换到别的博弈要重新设计。

    AlphaGo2016.01 · RL 已核对
    对弈时需要1202个CPU和176个GPU的分布式系统，训练流程分三阶段、成本高，外界难以复现。
  • 改进
    AlphaGo击败李世石2016.03 · RL
    比赛用的系统仍依赖人类棋谱和手工特征，并且没有公开代码与模型，外界无法复现。
  • 改进
    AlphaGo Zero2017.10 · RL
    自我对弈产生数据极其耗算力，外界难以复现和研究。
  • 改进
    AlphaZero2017.12 · RL
    沿用AlphaZero的自我对弈加神经网络引导搜索，系统性地提升学习效率。
