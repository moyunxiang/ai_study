推理扩展律与REBASE

Inference Scaling Laws: An Empirical Analysis of Compute-Optimal Inference for Problem-Solving with Language Models
2024.08论文延伸ICLR 2025Yangzhen Wu, Zhiqing Sun, Shanda Li, Sean Welleck, Yiming Yang · 清华大学 / 卡内基梅隆大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

训练阶段的规模定律研究得很多，但推理时该用多大的模型、生成多少条答案、用哪种搜索才最划算，缺少系统的测量。

方法

固定推理算力预算，系统比较不同模型大小和多种推理策略（贪心、多数投票、best-of-n、加权投票、树搜索）的性价比，并提出更省算力的奖励平衡树搜索REBASE。

影响

给出“推理时多花算力可能比换更大的模型更划算、小模型加好的搜索能落在帕累托前沿上”的实证结论，与同期的测试时计算研究一起奠定了测试时扩展这条路线。

方法

论文把“推理时用多少算力”当成和训练规模一样可以优化的变量：给定一个以浮点运算量计的预算，可以选择用大模型少生成几条，也可以用小模型多生成几条再挑。作者在数学题上用不同大小的模型，比较贪心解码、多数投票（见自洽性采样）、best-of-n、按奖励模型加权的投票，以及两种树搜索。

他们发现常规的蒙特卡洛树搜索在这里不划算：它会产生大量没写完的解答，能拿来投票的有效答案少。于是提出REBASE（奖励平衡搜索）：每一层用过程奖励模型（过程监督与过程奖励模型）给候选步骤打分，按分数的softmax分配下一层的展开名额——分高的多展开，分低的少展开但不完全丢掉，保证最后有足够多完整解答用于加权投票。

结果：在MATH上，Llemma-7B配合REBASE在所有测试的推理策略下都稳定超过Llemma-34B；整体上，小模型配合好的推理算法往往给出最优的“算力—准确率”折中。这与重复采样的扩展律的重复采样曲线、测试时计算扩展的按难度分配算力结论相互印证。

局限与后续

  • 结论依赖一个可靠的过程奖励模型和答案可自动比对的数学题，换到开放式任务或奖励模型较差时，搜索的收益会打折扣。

它建立在什么之上

  • 竞争
    蒙特卡洛树搜索UCT2006 · RL
    作者实测蒙特卡洛树搜索在同等预算下不如REBASE，因为它留下太多未完成的解答。
  • 使用
    自洽性采样2022.03 · 推理·智能体
    多数投票和加权投票是比较的基本策略，REBASE的产出最终也用加权投票汇总。
  • 使用
    过程监督与过程奖励模型2023.05 · 推理·智能体
    REBASE用过程奖励模型给每一步打分，并据此分配展开名额。
  • 延续
    重复采样的扩展律2024.07 · 推理·智能体
    重复采样的扩展律说明多采样能提高覆盖率，本文进一步把模型大小和多种选答策略放在同一算力预算下比较。
  • 竞争
    测试时计算扩展2024.08 · 推理·智能体
    同月发表的测试时计算研究，侧重按题目难度在搜索与修订之间分配算力；本文侧重模型大小与推理策略的整体性价比。
