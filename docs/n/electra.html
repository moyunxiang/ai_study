ELECTRA替换词检测

ELECTRA: Pre-training Text Encoders as Discriminators Rather Than Generators
2020.03论文重要ICLR 2020Clark, Luong, Le, Manning · Stanford / Google Brain待核对
arXiv ↗代码与模型 ↗在交互版中打开（演化树、学习进度）

问题

BERT每句话只遮住15%的词，也只从这15%的位置学习，其余85%的计算几乎白算；要训得好就得堆大量算力，小团队训不起。

方法

用一个小的掩码语言模型（生成器）把部分词换成“以假乱真”的替代词，再训练主模型（判别器）对每一个词判断“是原词还是被换过”，让所有位置都提供训练信号。

影响

同等算力下明显优于BERT：14M参数的小模型在一块GPU上训4天，GLUE超过算力多约30倍的GPT；大模型用不到1/4算力追平RoBERTa和XLNet，说明预训练任务的设计本身就能大幅节省算力。

背景

BERT的掩码语言建模（MLM，见掩码建模）随机挑出15%的token换成[MASK]，让模型猜原词。问题有两个：

  • 样本效率低。损失只在被遮的15%位置上计算，一句128个token的句子只产生约19个预测目标。RoBERTa、XLNet靠更多数据和更长训练把效果推上去，代价是数倍于BERT的算力。
  • 训练与使用不一致。预训练时输入里有[MASK]，微调和使用时从不出现。

想用较少算力得到好的编码器，TinyBERT等方法走的是先训大模型再蒸馏；本文想直接从预训练任务入手。

方法

替换词检测（replaced token detection）。两个Transformer编码器一起训练：

1. 生成器G：一个小的MLM。对输入随机遮住约15%的位置，G在这些位置按自己预测的分布采样一个词填回去。例如“the chef cooked the meal”遮住chef和cooked，G可能填回“the chef ate the meal”——chef猜对了，cooked被换成了ate。

2. 判别器D：主模型。读入被改过的句子，对每个位置做二分类：这个词是原文还是被替换的？上例的正确答案是：只有ate是假的。注意，G恰好猜对的词算作“原词”。

总损失是L = L_MLM(G) + λ·L_Disc(D)。采样这一步不可导，所以判别器的损失不回传给生成器。预训练结束后扔掉G，只用D去微调下游任务。

它不是GAN。虽然结构像生成对抗网络GAN（生成器造假、判别器识别），但G只是普通地用最大似然学猜词，并不试图骗过D。作者试过用强化学习对抗训练G，效果反而更差：对抗训练的生成器MLM准确率只有58%（最大似然训练的是65%），而且输出分布过于集中。

两个细节。一是G要小：G为D的1/4到1/2大小时效果最好，G太强会让判别任务难到D学不好。二是G与D共享词嵌入：G的softmax每步都更新整个词表的嵌入，D只能更新句中出现的词，共享后D得益。

从另一个角度看，它是word2vec负采样和噪声对比估计NCE“区分真样本与噪声样本”思想的大规模版本，只是噪声由一个学出来的生成器提供。

结果

GLUE开发集：ELECTRA-Small（1400万参数，1块V100训4天）得79.9，同配置的BERT-Small为75.1，更大的GPT（1.17亿参数）为78.8；ELECTRA-Base得85.1，BERT-Base为82.2。大模型上，ELECTRA-400K只用了RoBERTa-500K约1/4的算力，平均分89.0对88.9；训练更久的ELECTRA-1.75M为89.5，超过XLNet的89.1，并刷新SQuAD 2.0纪录。

消融说明收益主要来自“所有位置都学习”：只在被遮的15%位置算判别损失时GLUE为82.4，与BERT的82.2几乎一样；完整ELECTRA为85.0。

后来的发展

ELECTRA证明了预训练目标的设计能带来与加大算力相当的收益，替换词检测后来被一些编码器模型直接采用（如微软的DeBERTaV3）。它也让“小团队一块GPU也能预训练一个可用的语言模型”成为现实。

不过2020年之后，研究主流迅速转向GPT-3式的大型解码器：它们能直接生成、能靠提示完成新任务，而ELECTRA这类编码器需要为每个任务微调。编码器模型的主要用武之地变成了检索、分类和嵌入等需要高效理解的场景。

容易误解的地方

  • 判别器的任务不是猜出原词，只是判断“是否被换过”，所以输出是每个位置一个二分类概率，而不是整个词表上的分布。
  • 预训练后真正用的是判别器，生成器被丢弃；不能拿ELECTRA来生成文本。

局限与后续

  • 要同时训练生成器和判别器，生成器大小是一个敏感的新超参数，太强太弱都会伤害效果。

它建立在什么之上

  • 改进
    BERT2018.10 · LLM 已核对
    BERT只从15%被遮的位置学习且存在[MASK]不一致；ELECTRA让每个位置都参与训练，同等算力下GLUE明显更高。
  • 竞争
    RoBERTa2019.07 · LLM 已核对
    RoBERTa靠更多数据和算力提升BERT；ELECTRA靠更好的预训练任务，用不到1/4算力达到同等水平。
  • 延续
    word2vec2013.01 · NLP
    可看作把CBOW负采样和噪声对比估计（NCE）“判断真样本还是噪声”的思路放大到Transformer，并把噪声来源换成学出来的生成器。
  • 延续
    生成对抗网络GAN2014.06 · 生成
    借用生成器与判别器的结构，但生成器用最大似然训练而非对抗训练，因为文本采样不可导、对抗训练效果更差。
  • 改进
    ALBERT参数共享2019.09 · LLM
    仍是只从15%被遮位置学习的掩码语言模型，预训练效率不高。
  • 竞争
    XLNet2019.06 · LLM
    XLNet用排列语言建模消除[MASK]不一致；ELECTRA用替换词检测，算力更少而分数相当或更高。
  • 竞争
    TinyBERT2019.09 · 系统·效率
    TinyBERT先训大模型再蒸馏出小模型；ELECTRA-Small直接从头预训练，侧重降低预训练成本。

后来的相关工作

  • 竞争
    DeBERTa解耦注意力2020.06 · LLM
    同期改进BERT的另一条路线：ELECTRA改预训练目标，DeBERTa改注意力结构；后来的DeBERTa v3把两者合在一起。

本篇术语

  • 替换词检测　把句中部分词换成看似合理的替代词，让模型对每个位置判断这个词是不是被换过。
  • 生成器 / 判别器　生成器是负责造替代词的小掩码语言模型；判别器是负责识别替代词、最终留下来使用的主模型。
  • 样本效率　用同样多的数据或算力能学到多少。ELECTRA每句话的每个位置都提供信号，所以样本效率更高。
