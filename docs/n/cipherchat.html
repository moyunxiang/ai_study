CipherChat密码越狱

GPT-4 Is Too Smart To Be Safe: Stealthy Chat with LLMs via Cipher
2023.08论文延伸ICLR 2024Youliang Yuan, Wenxiang Jiao, Wenxuan Wang, Jen-tse Huang, Pinjia He, Shuming Shi, Zhaopeng Tu · 香港中文大学（深圳）/ 腾讯AI Lab待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

大模型的安全对齐（数据过滤、监督微调、RLHF、红队）几乎都用自然语言进行，对非自然语言的输入是否同样有效没有被检验。

方法

用凯撒密码、摩斯电码等密码与模型对话：在系统提示里设定“你是密码专家”，给几个加密示例，再用密文提出有害请求，看模型是否用密文回答。

影响

揭示了安全对齐对非自然语言泛化不足这一问题，与低资源语言越狱、ArtPrompt一起成为“编码绕过”类越狱的代表，标题“GPT-4太聪明而不安全”也被广泛引用。

方法

CipherChat框架。提示由三部分组成：系统角色描述（“你是密码专家，我们用某种密码交流”）、几段用该密码加密的示范对话、以及加密后的用户请求。模型用密文回答后再解密得到内容。测试的密码包括凯撒密码、摩斯电码、ASCII编码、Unicode编码以及中文的GBK、UTF编码等。

实验。在中英文两种语言、11个安全领域上评测ChatGPT和GPT-4。摘要称，某些密码在若干安全领域几乎100%能绕过GPT-4的安全对齐。越强的模型越能读懂密码，因而越容易被这样攻破，这就是标题“太聪明而不安全”的意思。

SelfCipher。作者发现模型似乎有一种“秘密密码”：只用角色扮演和几段自然语言示范、宣称在用密码交流，并不真加密，也能诱发这种行为。SelfCipher在几乎所有情况下都优于人类设计的密码。

局限与后续

  • 弱模型读不懂密码，攻击只对能力强的模型有效；输出也是密文，需要解密，部分回答语无伦次、实际危害有限。
