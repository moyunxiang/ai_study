BiLSTM特征依存分析

Simple and Accurate Dependency Parsing Using Bidirectional LSTM Feature Representations
2016.03论文延伸TACL 2016Eliyahu Kiperwasser, Yoav Goldberg · 巴伊兰大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

依存句法分析器的效果高度依赖特征：Chen和Manning的神经分析器仍要从栈和缓冲区手工挑出十几个词、词性和弧作为输入，图模型分析器要靠复杂的高阶特征。

方法

先用双向LSTM给句中每个词算一个上下文向量，再只拼接极少几个这样的向量交给多层感知机打分：转移式分析器看栈顶和缓冲区的4个词，图式分析器只看一条弧的中心词和修饰词2个词。

影响

用如此简单的结构在英文和中文树库上达到接近最好的精度，确立了「BiLSTM编码+少量特征」的分析器范式，直接引出了双仿射依存分析器。

方法

神经网络依存分析用前馈网络取代了转移式分析器里的稀疏特征，但输入仍是人工挑选的一组位置。MSTParser与MIRA一类图模型给每条可能的弧打分再求最大生成树，效果好的版本要用二阶、三阶特征。

本文的关键是把「特征」交给一个与分析器一起训练的BiLSTM：词向量和词性向量拼接后送入双向LSTM，第i个词的输出v_i已经包含了整句的上下文信息，因此不需要再手工组合远处的词。在此基础上做了两种分析器。

转移式（arc-hybrid系统，同转移式依存分析一脉）：每个状态只取栈顶3个词和缓冲区第1个词的BiLSTM向量，拼接后经多层感知机给每个动作打分，贪心解码，用带动态预言的合页损失训练。

图式（一阶、按弧分解）：对每条候选弧h→m，拼接v_h和v_m送入多层感知机得到弧分数，用Eisner算法求最高分的投影树，以合页损失和损失增强推断训练。

摘要与正文报告：只用树库数据、不用预训练词向量时，两个特征的一阶图式分析器英文93.1 UAS、中文86.6 UAS；加上预训练词向量后，贪心转移式分析器（11个特征）达到英文93.9、中文87.6 UAS，4个特征的版本为93.6和87.4。

局限与后续

  • 图式分析器用多层感知机对每条弧打分，计算与参数量都偏大，且只是一阶模型。

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    用双向LSTM为每个词计算包含全句上下文的特征向量，并与分析器联合训练。
  • 改进
    神经网络依存分析2014.10 · NLP
    Chen和Manning的神经分析器仍需人工选择十几种特征位置，BiLSTM向量让特征缩减到4个甚至2个。
  • 延续
    转移式依存分析2003 · NLP
    转移式版本沿用移进-归约式的转移系统（arc-hybrid），只改状态的表示方式。
  • 延续
    MSTParser与MIRA2005.06 · NLP
    图式版本沿用按弧分解、求最大投影树的框架，把弧特征换成两个BiLSTM向量。
  • 改进
    Stack-LSTM依存分析2015.05 · NLP
    三个栈LSTM和递归组合计算较重，后来基于双向LSTM特征的简单分析器以更少的结构取得了相近的精度。

本篇术语

  • UAS　无标签依存准确率：每个词被分配到正确中心词的比例，不看依存关系标签。
  • 转移式与图式分析　转移式像移进-归约那样一步步做决定；图式先给所有可能的弧打分，再整体求最高分的树。

怎么学

先读神经网络依存分析与转移式依存分析的讲解 → 读原文第3–5节 → 动手：在Universal Dependencies某个小语种树库上实现图式版本（BiLSTM+MLP弧打分+Eisner解码），与只用词向量窗口的基线比较UAS。
