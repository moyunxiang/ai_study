LeNet与卷积网络

Gradient-Based Learning Applied to Document Recognition
1998论文主干Proceedings of the IEEE 1998Yann LeCun, Léon Bottou, Yoshua Bengio, Patrick Haffner · AT&T Labs来源已核对
Proc. IEEE ↗PDF（作者主页） ↗维基百科：LeNet（含逐层参数） ↗在交互版中打开（演化树、学习进度）

问题

文字识别系统由人工设计的特征提取器、分割规则和分类器拼成，每一块单独调，换一种字体或书写风格就要重写一大段。

方法

让卷积网络直接吃像素、端到端学特征和分类（LeNet-5），再把分割、识别、语言模型连成一张可整体求梯度的图（图变换网络），整套系统一起训练。

影响

在MNIST上把错误率压到1%以下，并部署到美国多家银行的支票读取系统；它的“卷积—下采样—全连接”结构在2012年的AlexNet里被大幅放大。

背景

1990年代的手写识别流水线通常是：先把一行字切成单个字符，再对每个字符提取人工设计的特征（笔画方向、轮廓、投影直方图），最后送进分类器（k近邻、多项式分类器或支持向量机）。问题有两个。

第一，特征靠人想。设计者要猜什么特征有用，换个任务又得重猜。卷积网络识别邮编已经证明卷积网络可以从像素学出特征，但它只是一个识别单个数字的小网络。

第二，模块分开训练。切割器犯的错，识别器不知道；识别器的置信度，也不能反过来帮切割器决定在哪里切。每个模块各自最优，合起来却不是最优。

这篇近50页的长文要同时回答：卷积网络在标准基准上到底比各种手工方法强多少？能不能把整个识别系统都变成可以用梯度训练的东西？

方法

LeNet-5的结构（见卷积层、池化与感受野）。输入32×32灰度图，逐层变化：

32×32 → C1: 6@28×28 → S2: 6@14×14 → C3: 16@10×10 → S4: 16@5×5 → C5: 120 → F6: 84 → 输出10

  • C层是卷积：用5×5的卷积核在图上滑动，同一张特征图共享权重。C1只有156个参数，却能在每个位置检测6种局部图案。
  • S层是下采样（子采样）：把每2×2的四个值加起来，乘一个可学系数、加偏置、过激活函数，图的边长减半。它让网络对小的平移和变形不敏感，相当于Neocognitron的C细胞。
  • C3的16张图并不连到S2的全部6张图，而是按一张表各接其中几张，用来减少参数并迫使各图学不同的组合。
  • C5用16×5×5的卷积核，恰好把5×5的图卷成1×1，F6是84个单元的全连接层，输出层是10个径向基（RBF）单元：每个单元保存一个84维的“标准数字图样”，输出与它的距离。

全网约6万个可训练参数，大部分在C5（48120个）。激活函数是缩放过的tanh：f(x) = 1.7159·tanh(2x/3)。训练用对角近似海森矩阵的随机Levenberg–Marquardt方法，在MNIST上跑约20轮。

MNIST（MNIST）。为了公平比较，作者把美国国家标准局（NIST）的两个手写数字库重新混合、归一化到28×28，得到6万张训练、1万张测试的数据集。

图变换网络（GTN）。读一整行字时，系统先给出多种可能的切分方案，组成一张图；每条路径上的每段由LeNet打分，再与语言模型（如合法金额的语法）组合。整个流程中每一步都可微，于是可以用整句级别的损失把切割、识别一起训练，而不是只在单字符上训练识别器。

结果

论文在MNIST上比较了几十种方法（测试错误率）：线性分类器12.0%，40维PCA加二次分类器3.3%，3层全连接网络约2.5%–3%，切线距离k近邻1.1%，4次多项式核SVM 1.1%。LeNet-5为0.95%，训练时加入人工变形增强后为0.8%，三个LeNet-4的提升集成为0.7%。卷积网络同时比最好的SVM需要更少的内存和计算。

训练在一台单个200MHz处理器的SGI Origin 2000上花了2–3天CPU时间。部署方面，论文称这套支票读取系统已集成进NCR的支票识别产品线，自1996年6月起在美国多家银行使用，每天读取数百万张支票。

后来的发展

MNIST此后长期是机器学习最常用的入门基准之一。LeNet-5的设计——卷积与下采样交替、最后接全连接分类——几乎原样出现在AlexNet里，只是卷积层从2个增加到5个、参数从约6万增加到约6000万，激活换成ReLU、下采样换成最大池化、用GPU训练。

但在1998–2011年间，卷积网络并没有占上风：在小数据集上支持向量机加手工特征（SIFT特征、HOG与手工特征时代）同样好用，而且有凸优化、理论保证、不需要调网络结构，主流视觉研究走了那条路。直到ImageNet提供了百万张标注图、GPU提供了算力，卷积网络才在自然图像的大规模基准上明显领先。图变换网络中“对整条序列做全局归一化训练”的想法，与后来的条件随机场和CTC思路相近。

容易误解的地方

  • LeNet-5的下采样层不是今天的最大池化，也不是纯平均池化：它是带可学权重和偏置的求和再过激活函数。
  • 论文的大部分篇幅讲的是图变换网络和完整的支票识别系统，不只是LeNet-5这个网络。
  • 0.95%是不做数据增强的结果；常被引用的0.8%用了人工变形扩充训练集。

局限与后续

  • 只在32×32的黑白数字和字符上验证，面对彩色、杂乱背景、上千类别的自然图像，当时既没有足够的标注数据，也没有足够的算力训练更大的网络。
    后来针对它的工作　ImageNet GPU上的卷积网络 AlexNet
  • tanh类激活容易饱和、梯度变小，网络只有两个卷积层；再加深就难以训练，CPU上训一次就要几天。
    后来针对它的工作　ReLU AlexNet VGG
  • 在小数据集上相对SVM加手工特征的优势很小，又缺少理论保证，2000年代主流视觉研究更多采用SVM与SIFT/HOG特征。
    后来针对它的工作　AlexNet
  • 参数少、容量小，在更大的数据上很快欠拟合；更大的卷积网络又会严重过拟合，缺少有效的正则化手段。
    后来针对它的工作　Dropout AlexNet

它建立在什么之上

  • 使用
    反向传播1986 · 基础 已核对
    所有层（以及图变换网络中的每一步）都用反向传播求梯度。
  • 延续
    Neocognitron1980 · 视觉 已核对
    论文写明“卷积+下采样”的组合受Hubel–Wiesel简单/复杂细胞启发、最早在Neocognitron中实现，但当时没有反向传播这样的全局监督学习方法；LeNet用反向传播训练全部层。
  • 改进
    卷积网络识别邮编1989 · 视觉 已核对
    在1989年邮编网络的基础上加深结构、单独设置可学的下采样层，并在新的MNIST基准上系统比较。
  • 延续
    时延神经网络TDNN1989.03 · 语音 已核对
    论文把TDNN描述为只沿时间一维共享权重的卷积网络，用于音素和语音识别；LeNet在二维图像上使用同样的权重共享，并把可扫描整行文字的网络用于序列识别。
  • 竞争
    支持向量机1995 · 基础 已核对
    同一时期的主要对手：论文中多项式核SVM在MNIST上为1.1%，改进的V-SVM（据作者转述的私人通信）达到0.8%，与LeNet-5加变形训练的结果相当，但计算代价高得多；此后十年视觉主流更多采用SVM加手工特征。
  • 使用
    MNIST1998 · 数据·评测 已核对
    论文同时整理出MNIST，作为与几十种方法公平比较的公共测试集。
  • 改进
    逻辑回归1958 · 基础
    效果完全取决于人设计的输入特征；面对图像、语音这样的原始信号，线性模型几乎无能为力。
  • 改进
    Marr《视觉》1982 · 视觉
    整条管线由人工设计的模块串起来，每个模块的规则都要手写，没有学习，换到杂乱的自然图像上很难做稳。
  • 改进
    偏差-方差权衡1992 · 基础
    只指出“需要正确的先验结构”，没有给出如何为视觉、语言等问题设计这种结构。
  • 改进
    视觉皮层感受野1959 · 视觉
    只是单个神经元的描述性发现，没有给出可计算的学习规则，人们不知道这样的分层特征如何通过训练得到。

读懂它需要的概念

卷积层、池化与感受野 卷积运算 反向传播 随机梯度下降与小批量 神经元与激活函数 训练集、验证集与测试集 基准、排行榜与SOTA

本篇术语

  • 下采样（子采样）　把特征图每2×2个格子合成一个，图的长宽各减半。目的是减少计算并容忍小的位移，今天一般用最大池化或步长为2的卷积实现。
  • 径向基（RBF）输出单元　每个类别存一个原型向量，输出等于输入与原型的欧氏距离，距离越小越可能是这一类。后来的网络大多改用softmax加交叉熵。
  • 图变换网络（GTN）　把识别系统写成在“候选切分方案图”上做变换的可微模块链，可以用整句的损失端到端训练。

怎么学

先弄懂卷积层、池化与感受野（卷积、步长、特征图、参数怎么算）和反向传播。然后读原文第II节（卷积网络与LeNet-5结构）和第III节（MNIST上的比较）；第IV节以后的图变换网络可以先略读。动手：用PyTorch照着C1–S2–C3–S4–C5–F6写出LeNet-5（下采样先用平均池化），在MNIST上训练，应能在一两分钟内达到约99%的准确率；再算一遍每层参数，核对C1=156、C5=48120。
