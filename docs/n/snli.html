SNLI

A large annotated corpus for learning natural language inference
2015.08数据集重要EMNLP 2015Samuel R. Bowman, Gabor Angeli, Christopher Potts, Christopher D. Manning · 斯坦福大学待核对
arXiv 1508.05326 ↗SNLI官网 ↗在交互版中打开（演化树、学习进度）

问题

判断一句话能否推出另一句（自然语言推理）是检验语义理解的好任务，但已有数据集只有几千对句子，神经网络在上面根本训练不起来。

方法

拿图片描述当前提，请众包工作者分别写一句“一定成立”“可能成立”“一定不成立”的句子，一口气收集了57万对带标签的句子，并对其中一部分做多人复核。

影响

SNLI比同类数据大两个数量级，第一次让神经网络在推理任务上追平特征工程方法，带动了ESIM、可分解注意力、InferSent等一批模型；它暴露的标注痕迹问题也成为数据集偏差研究的经典案例。

背景

自然语言推理（NLI，也叫文本蕴含）问的是：给定前提句P和假设句H，P是否蕴含H、与H矛盾，还是两者都不确定（中立）。例如前提“一场有多名男性参加的足球赛”，假设“一些男人在进行体育运动”就是蕴含。它被认为是衡量语义表示的理想试验场，因为回答它需要理解词义、否定、数量、常识等。

2005年起的RTE文本蕴含挑战挑战赛建立了这个任务，但每届只有几百到几千对句子；SICK扩大到约1万对，但句子是用规则从少数模板改写出来的，语言现象有限。另外，已有数据还有一个隐蔽问题：如果前提和假设谈的不是同一件事，标“矛盾”还是“中立”取决于是否假定二者指同一事件，标注者难以一致。

方法

以图像描述为锚。前提句取自Flickr30k的图片描述（约16万条），但不给工作者看图片。因为描述的是同一张具体照片里的场景，工作者在写假设时自然会假定“说的是同一件事”，从而避开指代不确定带来的分歧。

三类假设。在众包标注Mechanical Turk上，每位工作者看到一个前提，被要求写三句话：一句在前提描述的场景下一定为真（蕴含），一句可能为真（中立），一句一定为假（矛盾）。约2500名工作者参与，最终得到570,152对句子。

复核。另取约10%的句子对，每对再请4位标注者独立判断，与原作者共5个标签；至少3人一致的标签作为金标准，没有多数意见的不进入正式的开发集和测试集。

基线。比较了基于特征的分类器（只用词重叠、长度等不依赖具体词的特征的“非词汇化”版本，以及加入词对、交叉二元组等的“词汇化”版本）和用GloVe初始化的句子编码神经网络（词向量求和、LSTM）。

结果

复核的句子对中，98%得到了至少3人一致的标签；金标准与原作者标签一致的占91.2%；三类标签的分布接近均衡。在测试集上，只用非词汇化特征的分类器准确率仅50.4%；词汇化分类器达到78.2%；100维LSTM为77.6%，与之相当——这是神经网络第一次在NLI基准上与强特征模型打平。词向量求和模型为75.3%。把在SNLI上训练好的LSTM迁移到SICK上，也明显好于只在SICK上训练。

后来的发展

SNLI出现后一年多里，可分解注意力用注意力在参数少一个数量级的情况下刷新纪录，ESIM自然语言推理把准确率推到88.6%，InferSent证明在SNLI上训练的句子编码器可以作为通用句子表示，Sentence-BERT也沿用了这种做法。它的后续MultiNLI把前提扩展到多种文体，并进入GLUE / SuperGLUE。

另一面，标注伪影发现众包工作者写假设时留下了规律性痕迹：否定词与“矛盾”类高度相关，模糊、笼统的说法则与特定类别相关，只看假设不看前提就能在SNLI上答对约67%。HANS启发式诊断进一步发现模型依赖词重叠等启发式。这些发现推动了对抗式NLI这类对抗式收集的数据集。

容易误解的地方

  • “模型在SNLI上90%”不等于模型会推理：其中一部分准确率来自假设句的表面痕迹。
  • SNLI的前提都是对照片的简短描述，句子短、内容具体，与新闻、小说、对话等真实文本差别很大。

局限与后续

  • 众包写假设句时留下了可预测的痕迹（否定词、模糊修饰等），只看假设就能答对约三分之二，模型可以绕过推理。

  • 使用
    GloVe2014.10 · NLP
    神经网络基线用300维GloVe词向量初始化并在训练中微调。

    RTE文本蕴含挑战2005 · 数据·评测
    RTE每届只有几百到几千对句子，SNLI把规模扩大到57万对，足以训练神经网络。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测

  • 使用
    Flickr30k2014.02 · 数据·评测
    前提句直接取自Flickr30k的图片描述，借“同一张照片”消除事件指代的歧义。

读懂它需要的概念

监督学习 嵌入向量 循环网络与隐状态 准确率、精确率、召回率与F1 训练集、验证集与测试集

本篇术语

  • 自然语言推理（NLI）　判断前提句与假设句之间是蕴含、中立还是矛盾的三分类任务，也叫识别文本蕴含。
  • 标注痕迹（annotation artifacts）　众包标注者在写数据时不自觉留下的统计规律，模型可以利用它们答对题目，而不必真正掌握任务要求的能力。

怎么学

先补嵌入向量和循环网络与隐状态。读原文第2节（数据收集的提示语和复核流程）。动手：用Hugging Face加载SNLI，训练一个只看假设句的词袋分类器，看它能比随机的33%高出多少；再训练一个同时看前提和假设的模型，比较两者差距。
