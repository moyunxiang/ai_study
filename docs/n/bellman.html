动态规划与Bellman方程

Dynamic Programming
1957思想延伸1957（Princeton University Press）Richard Bellman · RAND公司待核对
Wikipedia ↗Bellman equation ↗在交互版中打开（演化树、学习进度）

问题

需要一连串决策的问题（库存、路线、控制），每一步的选择都影响以后，直接枚举所有决策序列组合数爆炸。

方法

把大问题拆成嵌套的子问题：当前的最优价值 = 本步收益 + 剩余问题的最优价值，这条递推关系就是Bellman方程。

影响

成为强化学习的数学基础：价值函数、Q学习、时序差分都是在近似或采样这条方程。

方法

根据维基百科，动态规划由Bellman在1950年代发展出来，Bellman方程把某一时刻的决策价值，写成第一步的收益加上做完第一步后剩余问题的价值：V(s) = max_a [ r(s,a) + γ Σ P(s'|s,a) V(s') ]。有了它，不必枚举所有路径，只需要从终点往回逐状态计算，每个状态只算一次。

对有限状态的马尔可夫决策过程（马尔可夫决策过程），反复套用这条方程会收敛到最优价值（价值迭代）。Bellman同时指出了维数灾难：状态由很多变量组成时，状态数指数增长，表格装不下。

后来的发展

Howard策略迭代提出策略迭代；时序差分学习与Q-learning用采样代替已知模型去逼近这条方程；《Neuro-Dynamic Programming》、DQN用函数近似对付维数灾难。

局限与后续

  • 需要完整已知的环境模型（转移概率和奖励），现实里往往不知道。
    后来针对它的工作　时序差分学习 Q-learning
  • 状态空间大时表格存不下，即“维数灾难”。
    后来针对它的工作　《Neuro-Dynamic Programming》 DQN

它建立在什么之上

  • 延续
    《博弈论与经济行为》与极小极大1944 · RL
    同样处理序贯博弈，但Bellman关注单个决策者对环境的最优控制。

后来的相关工作

  • 竞争
    模型预测控制MPC1980 · 具身·世界模型 已核对
    动态规划离线算出对所有状态都适用的最优策略，维数一高就算不动；MPC只对当前状态在线求一条最优开环轨迹，对确定性问题两者结果相同。
  • 改进
    DQN2013.12 · RL
    状态空间大时表格存不下，即“维数灾难”。
  • 使用
    动态时间规整DTW1978.02 · 语音
    直接运用Bellman的动态规划，把指数多的对齐方式降到网格大小的计算量。
  • 改进
    时序差分学习1988 · RL
    动态规划需要已知模型；TD只用采样到的相邻两步就能逼近同一递推关系。
  • 改进
    Dyna：学习与规划合一1990 · RL
    动态规划需要事先给定完整模型；Dyna在线学出模型再对它做近似动态规划。
  • 改进
    Q-learning1992 · RL
    动态规划要求已知转移概率和奖励；Q学习只用采样到的转移逼近Bellman最优方程，不需要模型。
  • 延续
    POMDP规划1998 · RL
    信念MDP仍满足Bellman递推，只是状态空间变成连续的概率单纯形。
  • 使用
    基于势函数的奖励塑形1999 · RL
    充分性证明直接把Q*_M − Φ代入M′的Bellman最优方程验证。
  • 使用
    逆强化学习IRL2000 · RL
    可行奖励集合的刻画直接由Bellman方程和最优性条件推出。
  • 延续
    分布式RL C512017.07 · RL
    把Bellman方程从期望推广到整个回报分布，并分析了它在Wasserstein距离下的收缩性。
  • 使用
    Samuel跳棋程序1959 · RL
    用后续状态的价值更新当前状态，和Bellman递推同构，但用采样而非完整模型。
  • 延续
    Howard策略迭代1960 · RL
    在Bellman方程之上增加“评估策略再改进策略”的迭代结构。
  • 使用
    Gittins指数1979 · RL
    指数的定义依赖动态规划和最优停止。
  • 改进
    《Neuro-Dynamic Programming》1996 · RL
    用随机逼近和函数近似扩展Bellman的动态规划。
  • 竞争
    蚁群算法1996.02 · 基础
    动态规划能精确解小规模路径问题，但旅行商的状态数随城市数指数增长，ACO以放弃最优性换取可扩展性。
