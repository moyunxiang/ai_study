LATS智能体树搜索

Language Agent Tree Search Unifies Reasoning Acting and Planning in Language Models
2023.10论文延伸ICML 2024Andy Zhou, Kai Yan, Michal Shlapentokh-Rothman, Haohan Wang, Yu-Xiong Wang · UIUC待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

ReAct智能体只走一条路，走错了没法回头；ToT有搜索却没有与真实环境交互。推理、行动、规划三者没有统一。

方法

把蒙特卡洛树搜索接到LLM智能体上：LLM既当策略又当价值函数，并用环境反馈和自我反思更新搜索。

影响

把推理、行动、规划放进同一个搜索框架，成为“智能体加测试时搜索”的代表。

方法

LATS每一步搜索包括：选择一个节点（用UCT公式平衡探索与利用，见蒙特卡洛树搜索UCT）；展开：让LLM采样多个候选动作，真正在环境里执行得到观察；评估：由LLM给状态打分，并结合自我一致性；反向传播更新节点价值。失败的轨迹会被LLM写成一段反思（借鉴Reflexion），放进之后的提示避免重蹈覆辙。

摘要称用GPT-4在HumanEval上达到92.7%的pass@1，用GPT-3.5在WebShop上平均得分75.9，无需梯度微调就能和微调方法相当。与思维树相比，LATS加入了与环境的真实交互；与ReAct相比，它能回溯。
