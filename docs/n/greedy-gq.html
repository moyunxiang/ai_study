Greedy-GQ离策略梯度控制

Toward Off-Policy Learning Control with Function Approximation
2010.06论文延伸ICML 2010Hamid Reza Maei, Csaba Szepesvári, Shalabh Bhatnagar, Richard S. Sutton · 阿尔伯塔大学 / 印度科学理工学院待核对
SZTAKI存档 ↗在交互版中打开（演化树、学习进度）

问题

Q-learning配上线性函数近似、在离策略数据上训练时可能发散（Baird反例与发散问题）；梯度TD（GTD/TDC）（GTD/TDC）解决了离策略「评估」的收敛问题，但「控制」——目标策略本身随估值变成贪心——仍没有收敛的线性时间算法。

方法

Greedy-GQ把梯度TD的思路用到控制：目标策略取当前Q估值下的贪心策略，最小化投影贝尔曼误差（MSPBE），用两组权重的双时间尺度随机梯度更新，每步计算量与特征数成线性。

影响

它是第一批在离策略、线性函数近似下有收敛保证的控制算法之一，和GQ(λ)一起组成梯度TD家族的控制部分，常被拿来与后来的强调TD（Emphatic TD）和深度离策略方法做对照。

方法

设Q值用线性函数近似 Q_θ(s,a) = θᵀφ(s,a)。普通Q-learning的半梯度更新沿TD误差方向走，却没有在优化任何一个目标函数，这正是它可能发散的原因。

梯度TD家族改为优化均方投影贝尔曼误差：MSPBE(θ) = ‖Π T^π Q_θ − Q_θ‖²_μ，其中T^π是目标策略π的贝尔曼算子，Π是投影回线性函数空间，μ是数据分布。对它求真正的梯度需要估计一个期望的乘积，于是引入第二组权重w，用一个更快的时间尺度去估计 E[φφᵀ]⁻¹ E[δφ]。

Greedy-GQ的每一步：

  • 计算TD误差 δ = r + γ θᵀφ̄' − θᵀφ，其中 φ̄' = Σ_a π(a|s') φ(s',a)，π是θ下的贪心策略；
  • 主权重：θ ← θ + α [δ φ − γ (wᵀφ) φ̄']；
  • 辅助权重：w ← w + β [δ − wᵀφ] φ。

第二项 −γ(wᵀφ)φ̄' 是对普通TD更新的修正，正是它保证了沿目标函数的梯度方向下降。因为目标策略随θ变化，MSPBE不再是二次的，作者证明的是在一定条件下收敛到MSPBE的驻点。每步只需O(n)计算（n为特征数），与Q-learning同阶。

后来的发展

同年Maei与Sutton提出的GQ(λ)把同样的梯度修正加上资格迹，用于离策略的预测问题；Sutton等人随后的Horde架构用GQ(λ)在一台机器人上并行地、离策略地学习成千上万个「通用价值函数」（每个回答一个关于未来传感器读数的问题），这是梯度TD方法最有代表性的应用。之后的强调TD（Emphatic TD）从另一个角度（按兴趣和跟随迹重新加权更新）解决离策略线性TD的稳定性问题，与梯度TD并列为两条主要路线。

读懂它需要的概念

时序差分与自举 on-policy与off-policy 线性回归 随机梯度下降与小批量 Bellman方程

本篇术语

  • 投影贝尔曼误差（MSPBE）　把贝尔曼更新后的值函数投影回可表示的函数空间后，与当前值函数的差距；梯度TD方法以它为优化目标。
  • 双时间尺度更新　两组参数用不同大小的步长同时更新，快的一组近似跟踪慢的一组所需的辅助量。

先读梯度TD（GTD/TDC）的TDC；读Sutton与Barto第二版第11章关于梯度TD的部分；在Baird反例上分别跑线性Q-learning和Greedy-GQ，观察权重是否发散。
