Mobile-Agent-v2多智能体手机操作

Mobile-Agent-v2: Mobile Device Operation Assistant with Effective Navigation via Multi-Agent Collaboration
2024.06论文延伸NeurIPS 2024Junyang Wang, Haiyang Xu, Haitao Jia, Xi Zhang, Ming Yan, Weizhou Shen, Ji Zhang, Fei Huang, Jitao Sang · 北京交通大学 / 阿里巴巴待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

用一个多模态大模型操作手机，要同时看懂当前截图、记住之前做到哪一步、记住前几屏看到的关键信息（如聊天里的一个地址）；单智能体把所有历史截图和操作塞进一个越来越长、图文交错的上下文里，很容易迷失进度、遗漏信息。

方法

拆成三个智能体：规划智能体用文字总结任务进度，决策智能体看截图与进度决定下一步并维护记忆单元，反思智能体比较操作前后截图、发现出错就纠正。

影响

在作者的动态评测中，任务完成率比单智能体的Mobile-Agent提高30%以上；“规划、决策、反思分离加记忆”的结构成为此后手机与电脑操作智能体框架的常见设计。

背景

前作Mobile-Agent纯视觉手机智能体只靠截图视觉感知操作手机，但所有能力集中在一个智能体里。手机任务有两个导航难题：任务进度导航（多步任务中知道下一步该做什么）和关键内容导航（例如先在一个应用里查到信息，再到另一个应用里使用）。长上下文、图文交错的输入让多模态模型在这两点上都吃力。

方法

视觉感知模块：把截图交给三个工具——文字识别（OCR模型）、图标检测（GroundingDINO）和图标描述（Qwen-VL），输出屏幕上的文字、图标及其坐标，弥补多模态模型直接看图时定位不准的问题。

三个智能体（每一轮依次运行）：

  • 规划智能体：用纯文本的GPT-4，根据用户指令和已执行的操作历史，生成一段简短的“任务进度”描述，代替冗长的历史截图；
  • 决策智能体：用GPT-4V，看当前截图、感知结果、任务进度和上一轮的反思，输出下一步操作（点击某坐标、输入文字、滑动、返回等），并在看到与任务相关的内容时更新记忆单元；
  • 反思智能体：用GPT-4V，比较操作前后的截图，判断结果是正确、错误（进入了错误页面）还是无效（页面没变化），错误时回退、无效时重试。

知识注入：还可以人工写入一些操作知识（例如某个应用的特殊入口），进一步提高成功率。

结果：在系统应用、外部应用和多应用协作任务上做真机动态评测，分基础与高级指令，并有英文和非英文两个场景。例如英文场景下高级指令的外部应用任务，成功数从Mobile-Agent的3/10提高到7/10，加上知识注入为9/10。

后来的发展

同团队随后推出Mobile-Agent-E等版本；“规划-执行-反思”的多智能体分工也出现在Agent S等电脑操作框架中。另一条路线是像UI-TARS原生GUI智能体那样把这些能力训练进一个端到端模型。

本篇术语

  • 动态评测　在真实手机上实际执行任务并人工判断是否完成，而不是比较预先录好的操作序列。
