决策树状态绑定

Tree-Based State Tying for High Accuracy Acoustic Modelling
1994.03论文延伸ARPA HLT Workshop 1994Steve J. Young, J. J. Odell, P. C. Woodland · Cambridge University待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

上下文相关的三音子（同一音素按左右邻音分别建模）数量极大，多数在训练数据里很少甚至没出现，参数估计不可靠。

方法

把属于同一音素的各三音子HMM状态，用带语音学问题的决策树聚成若干类，同一类共享一组参数。

影响

状态绑定让大词汇量识别能用上细致的上下文模型，也给后来DNN的输出单元（senone）提供了定义。

背景

音素的发音受前后音影响，所以用三音子（如a-b+c）比单音子更准。但约几十个音素可组成数万种三音子，训练语料里大部分都见不到几次。

方法

做法是自顶向下建树：对同一个中心音素的某个状态位置，把所有三音子的这个状态放在根节点，然后在一组预先写好的语音学问题（左邻是不是鼻音？右邻是不是元音？）里挑一个，使得分裂后数据的对数似然增加最多。重复分裂，直到似然增益低于阈值或某叶子的训练数据太少。叶子节点里的所有状态共享同一个高斯混合。

这样做有两个好处：数据少的三音子借用同类音的统计量，估计更稳；训练数据中从未出现的三音子也能沿着树的问题找到叶子，直接获得参数。该方法在HTK工具包里实现，是GMM-HMM时代的标准流程。

后来的发展

在CD-DNN-HMM中，深度网络的输出层正是这些绑定后的状态（后称senone），可以说决策树聚类在深度学习时代被保留了下来。

局限与后续

  • 问题集是人工写的语音学问题，树的构建只用最大似然，不直接面向识别错误。
    后来针对它的工作　CD-DNN-HMM
  • 树是先用单高斯统计量建好再固定下来，后续声学模型换成神经网络时并不再重新优化。
    后来针对它的工作　无词图MMI链式模型

它建立在什么之上

  • 改进
    HMM统计语音识别1976 · 语音
    为HMM声学模型加入上下文相关的单元，并解决由此带来的参数稀疏问题。
  • 改进
    CMU SPHINX1988 · 语音
    离散HMM先把每帧向量量化成码字编号，量化误差无法在后续训练中弥补，精度受限。
  • 使用
    HTK工具包1989 · 语音
    在HTK工具包中实现，并成为其默认的上下文相关建模流程。
  • 改进
    “每开除一个语言学家”1988 · 语音
    话被简化后常被误读为语言学无用，掩盖了统计模型也需要好的结构设计（如音素单元、绑定状态）。

本篇术语

  • senone　绑定后的HMM状态，也就是神经网络声学模型的输出类别。

怎么学

先弄清音素、声学模型与语言模型的分工里的三音子概念，再读论文的聚类算法一节，并用scikit-learn的决策树类比其分裂准则。
