GPU训练深度网络

Large-scale Deep Unsupervised Learning using Graphics Processors
2009.06论文重要ICML 2009Rajat Raina, Anand Madhavan, Andrew Y. Ng · 斯坦福大学待核对
ICML 2009 原文PDF ↗ACM（DOI） ↗在交互版中打开（演化树、学习进度）

问题

深度信念网络和稀疏编码在CPU上训练太慢，大家只能用几百万参数的小模型和少量数据，无法验证“模型更大、数据更多就更好”的设想。

方法

把全部参数常驻GPU显存，把每次更新写成大矩阵运算，按CUDA的线程块—线程层次并行，并为稀疏编码设计了天然可并行的新算法。

影响

第一次系统证明GPU能让深度学习快一到两个数量级：训练1亿参数的深度网络从几周缩短到约一天，为三年后用GPU训练AlexNet铺了路。

背景

2006年深度信念网络用逐层预训练让深层网络第一次能训起来，稀疏编码也被用于学习图像特征。但两者训练都很慢：深度信念网络的每一次更新都要做吉布斯采样（对比散度），要在大量无标注样本上反复更新，在CPU上要跑好几天。论文统计了当时已发表的几个深度信念网络应用，参数只有160万到380万；作者想要的模型是1亿参数，大了一个数量级以上。

2007年CUDA开放后GPU可以用C直接编程，但还没人系统研究过怎样把这类模型放上GPU。

方法

作者把经验总结成两条原则。

第一，减少主机与显卡之间的数据搬运。PCIe远慢于显存，所以把所有参数一直放在GPU显存里，训练样本也尽量大块地一次性拷进去，中间结果全部留在显存，更新过程中不做任何主机—显卡传输。

第二，按GPU的两级层次组织计算。线程块之间做数据并行（例如每块处理一个样本），块内线程做细粒度并行（例如每个线程处理样本的一个坐标），尽量使用块内的16KB共享内存，并让相邻线程访问相邻地址（合并访存）。同时启动大量独立线程块，让硬件在某些块等显存时切换去算别的块。

对受限玻尔兹曼机（深度信念网络的组成层），一次对比散度更新基本就是几次大矩阵乘法，正好适合GPU。对稀疏编码，原来的坐标逐个优化的算法是串行的，作者重新设计了一个各坐标可以同时更新的算法。实验用的是一块GeForce GTX 280（240个核心、1GB显存），对比对象是3.16GHz的双核CPU。

结果

训练受限玻尔兹曼机时GPU比双核CPU快12到72倍，模型越大加速越明显。最大的单层模型有4500万参数，GPU处理100万个样本约29分钟，CPU要一天以上。用局部连接的“重叠块”结构，作者训练了一个9600万参数的四层深度信念网络，比此前发表的模型大至少一个数量级。摘要的总结是：四层、1亿参数的网络训练时间从几周缩短到约一天；稀疏编码提速5到15倍。

后来的发展

吴恩达团队此后沿着“把模型做大”的方向继续：一方面在谷歌用上万个CPU核心训练10亿连接的网络（Google Brain猫脸实验），另一方面回到GPU，2013年用GPU集群以少得多的机器复现了同等规模（COTS HPC：GPU集群复现猫脸）。同一时期GPU上的大而简单的网络在GPU上直接训练大号多层感知机，2012年AlexNet在两块GPU上训练卷积网络赢下ImageNet，GPU从此成为深度学习的标准硬件。

无监督逐层预训练后来被有监督端到端训练取代，但“参数常驻显存、计算写成大矩阵乘”的原则沿用至今。

读懂它需要的概念

CPU、GPU与并行计算 显存、内存带宽与“内存墙” 矩阵乘法与线性变换 随机梯度下降与小批量 无监督学习 能量模型与玻尔兹曼分布

本篇术语

  • 受限玻尔兹曼机（RBM）　两层的概率模型：一层可见单元接数据，一层隐藏单元学特征，层内不相连。深度信念网络由多个RBM逐层堆叠训练而成。
  • 合并访存　同一组相邻线程同时访问显存中相邻的地址，硬件可以把这些访问合成一次大的读写，带宽利用率高得多。

怎么学

先读深度信念网络了解受限玻尔兹曼机和对比散度，再读CUDA了解线程块和共享内存。然后读原文第4节（两条并行原则）和第5节表2。动手：用PyTorch在GPU和CPU上分别实现一个RBM的一步对比散度更新，改变可见层与隐藏层大小，画出加速比随模型大小的变化，看看是否和论文一样模型越大加速越明显。
