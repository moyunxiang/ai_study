RLSVI随机化价值函数

Generalization and Exploration via Randomized Value Functions
2014.02论文延伸ICML 2016Ian Osband, Benjamin Van Roy, Zheng Wen · Stanford University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

带函数近似的价值迭代通常配ε-贪心或Boltzmann探索，这种抖动式探索在需要连续多步“故意走远”的问题里要指数级的样本。

方法

不给动作加噪声，而是给价值函数加噪声：每个回合从线性回归的近似后验里采样一组Q函数参数，然后整回合按它贪心行动。随机性体现在“相信哪一个价值函数”，探索自然是有方向、跨多步的。

影响

提出“随机化价值函数”这一探索思路，把后验采样从需要环境模型的PSRL推广到无模型、可泛化的价值函数上，直接引出Bootstrapped DQN和随机先验函数等深度版本。

背景

后验采样RL（PSRL）通过从环境模型的后验中采样一个MDP再求解来探索，有很好的遗憾界，但需要维护整个转移模型的后验，状态一多就无法泛化。另一方面，最小二乘策略迭代LSPI、最小二乘价值迭代（LSVI）等线性价值方法能泛化，探索却只靠ε-贪心。作者构造了简单例子说明：ε-贪心或Boltzmann探索需要的回合数会随问题规模指数增长，因为“随机连续选对很多步”的概率极小。

方法

设第h步的Q函数是线性的：Q_h(s,a) = φ(s,a)ᵀθ_h。RLSVI在每个回合开始时从后向前（h = H, …, 1）做一次带噪声的贝叶斯线性回归：

  • 回归目标 y = r + max_a′ φ(s′,a′)ᵀθ̃_{h+1}，用已有数据按岭回归求出均值 θ̄_h 和协方差 Σ_h；
  • 采样 θ̃_h ∼ N(θ̄_h, Σ_h)。

得到整组 θ̃ 后，这一回合始终按 argmax_a φ(s,a)ᵀθ̃_h 行动。数据少的方向协方差大，采样出的Q值波动大，偶尔会显得很乐观，智能体就会持续若干步地去验证它；数据多了后验收紧，行为自然转向利用。它可以看成把Thompson采样（Thompson采样的复兴）用在价值函数而不是模型上。

结果

摘要称，计算实验显示RLSVI相比Boltzmann或ε-贪心的LSVI有显著的效率提升；作者还给出了表格（tabula rasa）情形下的期望遗憾上界，说明其接近最优。

后来的发展

RLSVI的思想在深度RL里被实现为“用多个随机初始化的网络近似后验”：Bootstrapped DQN（同一作者）为每个头采样数据子集，随机先验函数又给每个成员加一个不可训练的随机先验网络。理论方面，后来有一批工作分析了RLSVI在表格与线性MDP下的遗憾界。

局限与后续

读懂它需要的概念

本篇术语

  • 随机化价值函数　不维护一个确定的价值估计，而是从可能的价值函数分布中随机抽一个来决策，用这种随机性驱动探索。
  • 抖动式探索（dithering）　ε-贪心、Boltzmann这类在每一步独立加随机性的探索，难以连贯地执行多步探索计划。

怎么学

先弄懂Thompson采样的复兴和贝叶斯线性回归的后验；读原文中ε-贪心需要指数时间的例子以及RLSVI算法框；在一个“长链”MDP上实现RLSVI与ε-贪心LSVI，比较到达链尾所需的回合数。
