GR-3 Technical Report
2025.07论文延伸技术报告 2025Chilam Cheang, Sijin Chen, Tao Kong, Hang Li 等（21位）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通用机器人策略对新物体、新环境、含抽象概念的指令泛化差，换到新场景又需要大量遥操作数据微调。

方法

GR-3是大型VLA模型，训练配方混合三类数据：网络规模视觉语言数据联合训练、VR采集的人类轨迹少量微调、机器人轨迹模仿学习，并配套自研双臂移动机器人ByteMini。

影响

官方称在多种真机任务上超过π0，并能用很少的人类轨迹适应新环境。

方法

GR-3延续GR-2的路线，但从视频预训练转向VLA主干。核心是三合一训练配方。其一，和VLA与WAM的基本结构的通用做法一样，把机器人数据与网络规模的图文问答数据一起训练，以保住语言和视觉理解，从而处理新物体与抽象指令。其二，用VR设备采集人类操作轨迹，人手操作比遥操作机器人便宜，用它在新环境里做高效微调。其三，用机器人轨迹做常规的模仿学习。

硬件上，团队设计了双臂移动机器人ByteMini，用来完成长时序、灵巧、双臂和移动的任务。论文称在多种困难任务上优于基线π0。
