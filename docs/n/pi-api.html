Physical Intelligence Pi API

2026.10系统延伸Physical Intelligence待核对
官方公告 ↗AI Insider报道 ↗在交互版中打开（演化树、学习进度）

问题

π0、π0.5等模型虽有开源版本，但大多数机器人公司没有能力自己搭训练集群和推理服务来微调、部署大模型。

方法

把机器人基础模型做成托管服务：开发者上传自己的机器人数据，在PI管理的算力上微调，再通过托管推理网关调用。

影响

机器人基础模型开始像大语言模型一样以API形式商业化，首批十余家合作公司覆盖工程机械、餐饮、制造和双臂机器人。

方法

2026年10月13日，Physical Intelligence开放Pi API测试版。流程是：采集示范 → 上传数据、在PI托管的算力上微调其最新模型 → 通过托管推理网关在真机上运行 → 分析失败再迭代。报道称可用的最新模型在微调时数据效率更高，后续会随新模型更新；多数演示用云端推理，部分环境下出现网络连接问题。

公开案例中，Almond用它训练自家Axol双臂机器人给自身装配用的垫片去毛刺，迭代了四天达到效果；Actor、Chef Robotics、Formic等十余家公司参与首批测试。定价未公布，需申请加入。它把π0.5、π0.7这类模型从研究发布推向了“模型即服务”。

局限与后续

  • 依赖云端推理，网络延迟和断连对实时控制是硬伤。
