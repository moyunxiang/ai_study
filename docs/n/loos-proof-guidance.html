深度网络引导证明搜索

Deep Network Guided Proof Search
2017.01论文延伸LPAR 2017（据一般了解）Sarah Loos, Geoffrey Irving, Christian Szegedy, Cezary Kaliszyk · Google Research、Czech Technical University（据一般了解）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

一阶自动定理证明器在搜索时要从大量待处理子句里选下一个，靠人工设计的启发式，面对Mizar这样的大型数学库经常卡死。

方法

用深度神经网络来给E证明器的子句打分，网络在已有的证明轨迹上训练，用它在证明搜索时挑选要处理的子句。

影响

是神经网络直接引导一阶自动证明器搜索的早期工作，把DeepMath前提选择的前提选择延伸到了搜索过程本身。

方法

作者在E证明器处理Mizar数学库的一阶逻辑翻译所产生的证明轨迹上，训练和比较几种神经网络模型，用它们在证明过程中选择要处理的子句。他们采用混合的两阶段方式，把深度学习引导与E原有的启发式结合。

摘要报告：深度学习引导可以显著减少平均证明搜索步数，同时多证出一些定理；用几种引导策略，找到了此前没有自动证明器证明的Mizar定理中7.36%的一阶证明，使有自动证明的语句比例由56%升至59%。

后来的发展

与DeepMath前提选择一起开启了用神经网络辅助一阶自动定理证明的路线，后来在策略层面有TacticToe，在语言模型层面有GPT-f。
