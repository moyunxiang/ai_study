DreamFusion文本生成3D

DreamFusion: Text-to-3D using 2D Diffusion
2022.09论文延伸ICLR 2023Poole, Jain, Barron, Mildenhall · Google Research / UC Berkeley待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

文本到3D需要大规模带标注的3D数据和能去噪3D的网络，两者当时都不存在。

方法

随机初始化一个NeRF，从随机视角渲染，用冻结的文生图扩散模型打分，把梯度回传给NeRF，称为分数蒸馏采样（SDS）。

影响

开创了“用2D扩散模型当先验来优化3D”的路线，后续Magic3D、ProlificDreamer与VSD、MVDream多视图扩散等都是对它的改进。

方法

先随机初始化一个NeRF（见三维表示：体素、点云、网格、隐式场）。每次迭代随机选一个相机视角，渲染出一张图，加噪后交给冻结的Imagen（文字条件），让它预测噪声。预测噪声与真实噪声之差，就是这张渲染图“离文字描述还差多远”的信号；把它当作梯度，绕过扩散网络的雅可比项，直接回传给NeRF的参数。这个损失基于概率密度蒸馏，即SDS。

为了让物体各面都合理，提示词会按视角自动补充方位描述（如正面、侧面）。整套流程无需任何3D训练数据，也不改动扩散模型；得到的NeRF能从任意角度观看、重新打光，或合成到任意三维环境。

局限与后续

  • 每个提示词都要优化一个NeRF，据Magic3D论文约需1.5小时，且分辨率受限于64×64的图像先验。
    后来针对它的工作　Magic3D 大重建模型LRM
  • SDS需要很大的引导强度，结果饱和、过度平滑，且多面问题（贾努斯问题）常见。
    后来针对它的工作　ProlificDreamer与VSD MVDream多视图扩散

读懂它需要的概念

扩散：前向加噪与反向去噪 分数函数与分数匹配 三维表示：体素、点云、网格、隐式场 体渲染 条件生成与引导 相机模型与多视图几何

怎么学

先学体渲染，读原文第3节SDS推导，然后跑社区的threestudio实现。
