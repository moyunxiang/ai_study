WaveGlow

WaveGlow: A Flow-based Generative Network for Speech Synthesis
2018.10论文延伸Prenger, Valle, Catanzaro · NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自回归声码器太慢，Parallel WaveNet需要先训老师再蒸馏，流程繁琐。

方法

把Glow的可逆流与WaveNet的结构结合，只用最大似然一个损失训练单个网络，从梅尔频谱并行生成波形。

影响

给出了训练简单、速度极快的并行声码器，一度成为TTS系统的常用声码器。

方法

Parallel WaveNet的逆自回归流学生要靠老师蒸馏训练，工程上很重。Glow（图像上的流模型）则可以直接最大化数据似然：用一串可逆变换把简单的高斯噪声映射成复杂数据，因为每一步可逆且行列式易算，似然可精确计算，训练不需要对抗或蒸馏（见可逆流与流匹配）。

WaveGlow把一组音频采样点按组堆叠，通过多层可逆的1×1卷积和『仿射耦合层』处理，耦合层里的变换参数由类似WaveNet的空洞卷积网络根据梅尔频谱算出。推理时从高斯噪声出发，反向通过整个网络，一次并行得到整段波形，不需要自回归。

摘要称：单个网络、单一损失；PyTorch实现在V100上生成速度超过500 kHz；平均意见分（MOS）与当时公开最好的WaveNet实现相当。

局限与后续

  • 模型很大（流的层数多、参数量大），显存占用高。
    后来针对它的工作　MelGAN HiFi-GAN
  • 音质被后来的GAN声码器追平甚至超越，同时GAN模型更小更快。
    后来针对它的工作　HiFi-GAN

它建立在什么之上

  • 使用
    WaveNet2016.09 · 语音 已核对
    用WaveNet式空洞卷积网络来计算耦合层的变换参数。
  • 改进
    Tacotron 22017.12 · 语音
    WaveNet声码器逐采样点生成，推理极慢，需要额外蒸馏或换声码器才能上线。
  • 延续
    标准化流RealNVP2016.05 · 生成
    沿用RealNVP/Glow一类的仿射耦合流，把它用到音频波形。
  • 改进
    Parallel WaveNet2017.11 · 语音
    训练流程复杂：需要先训好一个完整的WaveNet老师，再做蒸馏，还要多项辅助损失调参。
  • 改进
    WaveRNN2018.02 · 语音
    仍是自回归，速度受限于序列长度，难以像流或GAN声码器那样大幅并行。

后来的相关工作

  • 使用
    FastSpeech2019.05 · 语音
    以预训练的WaveGlow作为声码器，把并行生成的梅尔谱变成波形。
  • 竞争
    HiFi-GAN2020.10 · 语音
    同为并行声码器，WaveGlow走可逆流路线、模型大；HiFi-GAN参数更少、更快、MOS更高，GAN路线在声码器上胜出。
  • 使用
    GSLM无文本语言模型2021.02 · 语音
    用预训练的WaveGlow把单元合成出的梅尔谱转为波形。
  • 改进
    MelGAN2019.10 · 语音
    模型很大（流的层数多、参数量大），显存占用高。
