万能近似定理

Approximation by Superpositions of a Sigmoidal Function
1989论文重要Mathematics of Control, Signals, and Systems 1989George Cybenko（同年Hornik、Stinchcombe、White与Funahashi独立给出同类结果）待核对
Springer原文页 ↗Hornik等1989（同类结果） ↗Nielsen：神经网络能计算任何函数的直观证明 ↗维基百科：Universal approximation theorem ↗在交互版中打开（演化树、学习进度）

问题

反向传播让多层网络能训练了，但没人能说清：只有一层隐藏层的网络，原则上能表示多复杂的函数？会不会像单层感知机那样有表示不了的东西？

方法

用泛函分析证明：只要隐藏层神经元足够多，单隐藏层、任意连续sigmoid激活的网络就能在有界区域上以任意精度一致逼近任何连续函数。

影响

给“用神经网络拟合未知函数”提供了数学上的合法性，回答了《Perceptrons》留下的表示能力疑问；同时也让人认识到问题不在“能不能表示”，而在规模、训练和泛化。

背景

1969年的《Perceptrons》与XOR问题指出单层感知机连XOR都表示不了，这成为神经网络遇冷的重要原因。1986年反向传播让带隐藏层的多层感知机可以训练，实验效果也不错，但一个基本问题仍悬而未决：多层网络的表示能力到底有没有上限？如果某些函数无论怎么调权重都逼近不了，那再好的训练算法也无济于事。

1988–1989年，多位研究者几乎同时给出答案：Funahashi、Hornik–Stinchcombe–White和Cybenko。Cybenko这篇的证明最简洁，常被当作这一结果的代表。

方法

定理在说什么。设σ是连续的sigmoid型函数（x→−∞时趋于0，x→+∞时趋于1）。对单位超立方体[0,1]ⁿ上任意连续函数f和任意误差ε>0，都存在有限个N和参数α_j, w_j, b_j，使

G(x) = Σ_{j=1..N} α_j · σ(w_jᵀx + b_j)

在整个区域上满足|G(x) − f(x)| < ε。G正是一个单隐藏层、输出层线性的网络：N个隐藏神经元（见神经元与激活函数），每个先做线性变换再过σ，输出是它们的加权和。

直观理解（一维）。把权重w取得很大，σ(w(x−a))就近似一个在x=a处从0跳到1的台阶；两个台阶相减σ(w(x−a)) − σ(w(x−b))就是[a,b]上的一个“方块”。把区间切成很多小段，每段放一个高度等于f在该处取值的方块，加起来就是一个越切越细、越来越贴近f的阶梯——每个方块只用两个神经元。

Cybenko的证明用的是反证法：假设这类G的全体在连续函数空间里不稠密，由Hahn–Banach定理和Riesz表示定理，就存在一个不为零的测度，使所有σ(wᵀx+b)对它的积分都为0；而他证明连续sigmoid函数是“判别性”的，不允许这样的测度存在，矛盾。文中还推出：任意判定区域都能被单隐藏层网络任意好地逼近，即分类问题同样成立。

后来的发展

同年Hornik等把激活函数放宽到更一般的“压缩函数”；Hornik 1991年指出关键在多层前馈结构本身而不是具体的激活函数；Leshno等1993年证明，只要激活函数不是多项式就成立，于是后来的ReLU网络同样适用。

这个定理也常被误读。它只保证“存在”，不说需要多少神经元，不说梯度下降找不找得到，也不说能否从有限数据泛化。之后的研究沿这三条线展开：2015–2016年的深度分离结果表明，有些函数3层小网络就能表示，2层网络却需要随维度指数增长的宽度；神经正切核分析了无限宽网络在梯度下降下如何收敛；KAN则回到同时代的另一条表示定理（Kolmogorov–Arnold）设计新结构。

容易误解的地方

  • “能逼近任何函数”不等于“一层就够用”：所需神经元数可能大到不现实，实践中用深而窄的网络。
  • 定理只针对有界区域上的连续函数；在训练区域以外，网络的行为没有任何保证（外推问题）。
  • 它是表示能力的结论，与“能否学到”“能否泛化”是三个不同问题。

局限与后续

  • 只证明存在性，不给出所需隐藏神经元数的上界；对高维输入，单隐藏层可能需要随维度指数增长的宽度，定理本身看不出深度有什么用。

读懂它需要的概念

多层感知机 神经元与激活函数 向量、矩阵与张量 泛化与过拟合 维度灾难

本篇术语

  • 一致逼近　在整个区域上，逼近函数与目标函数的最大差距都小于给定的ε，而不只是平均意义上接近。
  • 稠密　一个函数集合里的成员可以无限接近某个空间里的任何函数，就像有理数在实数中稠密一样。
  • 深度分离　证明某些函数用深网络只需少量神经元，用浅网络却需要指数多神经元的一类理论结果。

怎么学

先补多层感知机和神经元与激活函数 → 读Nielsen《Neural Networks and Deep Learning》第4章的可视化证明，亲手拖动权重看台阶如何拼成任意曲线 → 再看维基百科词条的历史部分，了解宽度、深度两类定理 → 动手：用numpy写一个单隐藏层网络拟合sin(x)，比较隐藏神经元为2、10、100时的拟合误差。
