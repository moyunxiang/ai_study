GLIP

Grounded Language-Image Pre-training
2021.12论文延伸CVPR 2022Li, Zhang, Zhang, Yang, Li, Zhong, Wang, Yuan 等 · 微软 / UCLA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

检测器只能识别训练时固定的类别，扩展新类别要重新标注；而图文预训练只有图像级而不是物体级的语义。

方法

把目标检测重写成短语定位：把类别名拼成一句话作为文字输入，检测与定位数据都用同一框架训练，再用自训练为海量图文对生成框。

影响

让检测器获得开放词汇的零样本能力，是Grounding DINO、OWL等开放词汇检测的起点。

方法

GLIP把检测任务写成定位：对每个候选区域，不再输出固定类别的分数，而是计算「区域与文字提示中每个词」的对齐分数；类别名拼成提示（如「person. bicycle. car」）。这样检测数据和短语定位数据可以混在一起训练。网络上设计了深度的图文融合，在检测头之前把图像与文字特征互相更新。

再进一步，作者先用小规模教师在大量只有图文对的数据上预测框，再训练学生（自训练）。摘要称预训练用了2700万条定位数据，其中300万人工标注、2400万来自网络图文；零样本直接在COCO和LVIS上评测（没有见过任何COCO图像）。

它建立在什么之上

  • 使用
    CLIP2021.01 · 多模态 已核对
    借鉴其用语言监督获得开放词汇泛化的思路。
  • 改进
    图文区域对齐2014.12 · 多模态
    对齐和生成是两个分开训练的模型，区域-短语对应靠启发式（固定19个检测框加MRF平滑）产生，不是端到端学出来的。
  • 改进
    指代表达理解2015.11 · 多模态
    每个区域独立评分，无法与语言做深度交互。
  • 改进
    MAttNet2018.01 · 多模态
    依赖预先提取的候选区域，检测漏掉的物体无法恢复。
  • 延续
    MDETR2021.04 · 多模态
    沿用文字条件检测的思路，扩大到2700万条数据并统一检测与定位。

后来的相关工作

  • 改进
    Grounding DINO2023.03 · 多模态
    沿用GLIP“检测即短语定位”的统一表述和查询-词元对比分类损失，但换成DETR类检测器并在三个阶段加入跨模态融合，零样本COCO从49.8提高到52.5 AP。
  • 改进
    SAM 3概念分割2025.11 · 视觉
    GLIP一类“短语定位检测”在长尾概念和“图中不存在”的判断上很弱；SAM 3用存在token和难负样本数据，在SA-Co上精度达到此类基线的两倍以上。
  • 竞争
    YOLO-World2024.01 · 视觉
    同样把检测与语言对齐，区别是GLIP追求精度、模型重，YOLO-World追求实时。
