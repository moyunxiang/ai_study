Cline开源编码智能体

2024.07系统延伸Saoud Rizwan 等 · Cline（开源社区）待核对
GitHub ↗VS Code扩展 ↗在交互版中打开（演化树、学习进度）

问题

2024年的AI编程工具多是补全或聊天，真正能读写项目文件、跑命令的编码智能体要么闭源收费，要么只能在终端里用，和开发者日常的编辑器是分开的。

方法

做一个开源的VS Code扩展，让模型在编辑器里直接创建和修改文件、执行终端命令、打开浏览器验证，每一步都先给开发者看、批准后才执行；模型可以自由换。

影响

成为最流行的开源编码智能体之一，GitHub星标数以万计；它的多个分支（如Roo Code）和“计划/执行”双模式、自带模型密钥的用法，影响了一批IDE智能体插件。

方法

Cline最早以Claude Dev为名在2024年年中发布（VS Code市场上的扩展ID至今仍是claude-dev），后来改名Cline，GitHub仓库创建于2024-07。它的工作方式是一个在编辑器里运行的智能体循环：

  • 模型通过一组工具操作工作区：读文件、写或按差异修改文件、在集成终端里运行命令、搜索代码、用浏览器打开页面截图检查效果；
  • 人在回路：每个写文件或执行命令的动作都以差异或命令的形式展示给开发者，批准后才执行，也可以设置自动批准；
  • 开发者自带模型API密钥，可接各家模型，发布初期主要配合Claude 3.5 Sonnet使用；
  • 后来支持接入模型上下文协议MCP服务器扩展工具，并提供先讨论方案、再动手修改的计划/执行两种模式。

它与Aider（终端里的结对编程）、Cursor AI编辑器（闭源的AI编辑器）属于同一波编码智能体工具；之后又扩展出命令行版、桌面应用、JetBrains插件和SDK。

局限与后续

  • 每个动作都要人确认时效率低，开启自动批准又带来误删文件、执行危险命令的风险。
