扎克伯格：开源AI是出路

Open Source AI Is the Path Forward
2024.07思想延伸Mark Zuckerberg · Meta待核对
Meta：Open Source AI Is the Path Forward（2024-07-23） ↗在交互版中打开（演化树、学习进度）

问题

前沿模型越来越贵，主流实验室选择闭源；监管者和安全研究者担心开放权重会被滥用，也有人主张为了对抗中国应当封锁模型。

方法

扎克伯格在发布Llama 3.1 405B的同一天发表长文，把开放权重比作当年的Linux对Unix，系统论证开源对开发者、对Meta、对世界都更好，并反驳“封锁模型能挡住中国”的说法。

影响

这是前沿实验室负责人对开源路线最完整的一次公开辩护，此后讨论开源与闭源、开放权重与国家安全时常被引用。

方法

文章与Llama 3.1 405B同日（2024年7月23日）发布，Meta称405B是第一个前沿水平的开源模型。论证分三层：

  • 对开发者：可以用自己的数据微调和蒸馏，不必把数据交给任何人；不被闭源供应商锁定；Meta称在自有设施上运行405B的推理成本约为GPT-4o等闭源模型的一半。
  • 对Meta：卖模型访问权不是Meta的商业模式，开源不会损害收入；Meta不想再像依赖苹果平台那样受制于竞争对手，并以Open Compute、PyTorch、React的经验为例。
  • 对世界：开源让好处更分散、权力不集中于少数公司。安全上他区分“无意的伤害”和“有意的伤害”，认为前者占大多数且开放系统更易被审查；对后者，他认为广泛部署能让资源更多的大型参与者制衡小的坏人。关于中国，他写道封锁不会奏效，因为“窃取一个能装进U盘的模型相对容易”，只会让美国及其盟友处于劣势。

批评者指出Llama许可证并不是传统意义上的开源：月活超过7亿的公司须另行获得Meta授权，训练数据也没有公开。

局限与后续

  • 所谓“开源”只开放权重，许可证对大公司有使用限制，训练数据与完整配方并未公开，社区无法从头复现。
