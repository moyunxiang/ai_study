扩散模型的起点

Deep Unsupervised Learning using Nonequilibrium Thermodynamics
2015.03论文重要ICML 2015Jascha Sohl-Dickstein, Eric A. Weiss, Niru Maheswaranathan, Surya Ganguli · Stanford University / UC Berkeley待核对
arXiv ↗原作者代码 ↗Lilian Weng：What are Diffusion Models? ↗在交互版中打开（演化树、学习进度）

问题

生成模型面临两难：表达力强的模型（如能量模型）难训练、难采样、算不出似然；容易计算的模型（如单个高斯、浅层VAE）又太简单，拟合不了图像这样复杂的分布。

方法

借用非平衡热力学：用上千步逐渐加高斯噪声把数据变成纯噪声（固定的前向过程），再训练网络学习每一小步的逆过程。每一步都很小，所以每一步的逆都可以用简单的高斯近似，整体却可以非常复杂。

影响

提出了扩散模型的完整框架（前向加噪、学习反向去噪、变分下界训练），当时效果平平，五年后被DDPM重新拾起并发展成今天图像与视频生成的主流方法。

背景

2015年的生成模型大致分两类。一类是可处理的模型，例如变分自编码器VAE：可以算似然、可以采样，但隐变量的近似后验是一个简单高斯，只能拟合比较平滑的分布。另一类是表达力强的模型，例如能量模型与玻尔兹曼分布模型和玻尔兹曼机：理论上能表示任意分布，但归一化常数算不出，训练和采样都要跑很久的马尔可夫链。作者把这个矛盾概括为“可处理性与灵活性”的取舍。

物理学里有一个现象给了启发：一滴墨水滴进水里，会逐渐扩散到均匀。每一瞬间的扩散都是一个很小、很简单的随机运动，但把这个过程倒过来看，就是从均匀状态里“长出”一滴有结构的墨水。

方法

前向过程（固定，不学习）（见扩散：前向加噪与反向去噪）。从数据x₀出发，每一步加一点高斯噪声：

q(x_t | x_{t−1}) = N(x_t; √(1−β_t)·x_{t−1}, β_t·I)

β_t是很小的噪声量（见噪声调度与采样步数）。走完T步（图像实验中T=1000）之后，x_T基本就是标准高斯噪声，原始结构被完全破坏。论文也给了二值数据的版本：每步以小概率翻转比特。

反向过程（学习）。生成时从纯噪声x_T出发，一步步往回走：

p_θ(x_{t−1} | x_t) = N(x_{t−1}; μ_θ(x_t, t), Σ_θ(x_t, t))

关键观察是：当每一步的β_t足够小时，前向一步的逆过程也近似是高斯。所以只要让网络输出这个高斯的均值和协方差即可。图像实验用的是多尺度卷积网络。

训练目标。把x₁…x_T当作隐变量，整个模型就是一个有T层隐变量的生成模型，可以像VAE一样写出对数似然的变分下界（见变分推断与ELBO）。下界分解成每一步的KL散度之和，每一项都是两个高斯之间的KL，有闭式解。与VAE不同的是，“编码器”（前向过程）是固定的，只需要学“解码器”。

附带的能力。因为模型给出了每一步的条件分布，乘上另一个分布（例如“已知图像某些区域”）很方便，可以直接做去噪和图像补全。

结果

论文在二维瑞士卷、二值心跳序列、MNIST、CIFAR-10/100、“枯叶”合成图像和树皮纹理上做了实验。CIFAR-10上测试集对数似然下界为每像素5.4±0.2比特（基线11.5）。MNIST上用Parzen窗口估计的对数似然为317±2.7，略低于生成对抗网络GAN的325±2.9，高于深度信念网络的199±2.9。树皮纹理上演示了对中央100×100区域的补全。总体而言，样本质量和似然在当时并不突出，论文的价值主要在框架本身。

后来的发展

此后近五年这条路线很少有人跟进，大家的注意力在生成对抗网络GAN上。2019年分数匹配生成模型从另一个方向（学习加噪数据的分数、用朗之万动力学采样）得到了类似的多噪声级生成过程；2020年DDPM回到本文的框架，换成U-Net网络、固定方差，并把训练目标简化成“预测加入的噪声”，第一次让扩散模型的样本质量追上GAN。Score SDE统一框架随后证明两条路线是同一个随机微分方程的离散化。

今天的Stable Diffusion、Sora等系统，其前向加噪、反向去噪的骨架都来自这篇论文。被替换掉的部分主要是：学习协方差（后来大多固定或简化）、似然下界的直接优化（改为加权的去噪损失）、上千步的采样（被DDIM、DPM-Solver、蒸馏等方法压到几十步甚至一步）。

  • 延续
    变分自编码器VAE2013.12 · 生成
    同样用变分下界训练隐变量模型，但把编码器换成固定的逐步加噪过程，隐变量层数扩展到上千层。
  • 竞争
    生成对抗网络GAN2014.06 · 生成
    同期的另一路线：GAN样本清晰但没有似然，扩散模型有似然下界但当时样本差；2021年后扩散模型反超。
  • 延续
    Metropolis采样与MCMC1953 · 基础
    反向过程就像一条被学习出来的马尔可夫链，从噪声出发逐步走到数据分布，但步数固定、每步都被训练过。
  • 改进
    玻尔兹曼机1985 · 基础
    同样追求能拟合复杂分布，但每一步都是可解析的高斯，似然下界和采样都可精确计算，不需要配分函数。

读懂它需要的概念

扩散：前向加噪与反向去噪 高斯分布 马尔可夫性与马尔可夫链 变分推断与ELBO KL散度 隐变量模型

本篇术语

  • 非平衡热力学　研究系统如何从一个状态逐步演化到平衡态的物理学分支。论文借用其中“缓慢扩散过程的逆过程也可以写成同类小步”的思想。
  • 前向过程 / 反向过程　前向：固定地、一步步给数据加噪声直到变成纯噪声；反向：学出来的、一步步去噪直到变回数据。

怎么学

先补高斯分布、马尔可夫性与马尔可夫链和变分推断与ELBO（最好先读变分自编码器VAE）。原文第2节定义了前向、反向过程和下界，建议对照Lilian Weng的博客一起读，后者用DDPM的符号重写了一遍。动手：在二维瑞士卷数据上实现一个T=40步的扩散模型，用小MLP输出均值，观察样本如何从高斯团逐步“卷”成螺旋。
