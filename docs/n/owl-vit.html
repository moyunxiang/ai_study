OWL-ViT

Simple Open-Vocabulary Object Detection with Vision Transformers
2022.05论文延伸ECCV 2022Matthias Minderer, Alexey Gritsenko, Austin Stone, Maxim Neumann, Dirk Weissenborn, Alexey Dosovitskiy, Aravindh Mahendran, Anurag Arnab, Mostafa Dehghani, Zhuoran Shen et al. · Google Research待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

检测模型只能认训练集里标注过的固定类别；带框标注的数据很少，长尾类别更是几乎没有，而图文对比模型虽然认得万物，却不会画框。

方法

取标准ViT，先做CLIP式图文对比预训练，再去掉最后的池化，让每个图像token直接输出一个框和一个类别嵌入；类别名过文本编码器，与框的嵌入比相似度，从而检测任意文字描述的物体。

影响

给出一套把图文模型迁移成开放词表检测器的简单配方，并显示检测效果随图像级预训练和模型规模稳定提升，是后来YOLO-World等开放词表检测的参照。

方法

做法分两步。第一步，用CLIP的方式在海量图文对上预训练一个标准的Vision Transformer和一个文本编码器。第二步，把ViT最后的token池化去掉，每个输出token额外接一个小网络预测一个框（中心、宽、高），再接一个线性层把token映射成「类别嵌入」；训练检测时用二分图匹配把预测框和标注框一一配对，这一点沿用了DETR。

分类头不再是固定的N个类别的权重，而是把类别名（如“一只猫”）送入文本编码器得到的向量：框的类别嵌入与每个文本向量做相似度，就得到该框属于各类别的分数。这样训练时只见过的类别，推理时换成任何新词也能用。同一结构也支持单样本图像条件检测：用一张示例图的嵌入代替文本去找相似物体。

论文还分析了缩放性质：增大图像级预训练规模和模型尺寸都能带来下游检测的持续提升，并给出微调时所需的适配策略与正则化。

它建立在什么之上

  • 改进
    CLIP2021.01 · 多模态 已核对
    沿用CLIP的图文对比预训练，把图像级对齐迁移到框级别。
  • 使用
    Vision Transformer2020.10 · 视觉
    用几乎不改动的标准ViT作为检测骨干，每个输出token对应一个框。
  • 使用
    DETR2020.05 · 视觉
    借用DETR的集合预测和二分图匹配损失，免去锚框与NMS设计。
  • 改进
    ReferItGame / RefCOCO2014.10 · 数据·评测
    图像来自COCO的常见物体类别，描述风格受游戏诱导，与真实对话中的指代有差距。
  • 改进
    ViLD开放词表检测2021.04 · 视觉
    依赖两阶段检测器和先裁剪区域再送老师的过程，推理和训练都较慢。
