DBRX细粒度MoE

Introducing DBRX: A New State-of-the-Art Open LLM
2024.03模型延伸Databricks（Mosaic Research团队）待核对
官方博客 ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

2024年初开放权重的MoE模型（Mixtral、Grok-1）都用8个大专家选2个；开放模型整体仍落后于GPT-3.5等闭源API，企业自训大模型的成本也很高。

方法

Databricks发布132B总参数、36B激活参数的细粒度MoE：16个专家选4个，在12T token文本和代码上预训练，开放Base和Instruct权重。

影响

是2024年3月最强的开放权重模型之一，把“更多更小专家”的细粒度MoE带进开放模型主流，并展示了企业级训练栈可以从零训出前沿附近的MoE。

方法

背景：Mixtral 8x7B和Grok-1开放权重证明了开放的稀疏MoE可行，它们都是8个专家每次激活2个；DeepSeekMoE细粒度专家提出把专家切得更细、多选几个能提高效果。Databricks此前通过收购MosaicML获得了MPT-7B可商用开源模型等模型的训练经验。

官方博客给出的设计：DBRX是只有解码器的Transformer，用下一词预测训练；细粒度MoE，132B总参数中每个输入激活36B，16个专家每次选4个，官方称比Mixtral和Grok-1的8选2多出65倍的专家组合方式，并发现这能提高质量；使用旋转位置编码RoPE、门控线性单元和分组查询注意力GQA，分词器沿用GPT-4在tiktoken中公开的分词器；在12T token精选文本和代码上预训练，最大上下文32k。

官方称：DBRX在MMLU、HumanEval、GSM8K等基准上超过当时已有的开放模型，超过GPT-3.5、与Gemini 1.0 Pro相当，编程能力超过CodeLLaMA-70B；推理速度最高为LLaMA2-70B的2倍，总参数和激活参数约为Grok-1的40%；训练MoE比训练同质量稠密模型省约一半FLOPs，整套配方以近4倍更少的算力达到上一代MPT模型的质量。

局限与后续

  • 132B总参数对单机部署仍偏大，且只发布了博客没有详细技术报告；几周后Llama 3、Mixtral 8x22B等开放模型陆续发布，它的领先地位维持时间很短。
