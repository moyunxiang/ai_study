RNN编码器-解码器与GRU

Learning Phrase Representations using RNN Encoder-Decoder for Statistical Machine Translation
2014.06论文重要EMNLP 2014Kyunghyun Cho, Bart van Merriënboer, Caglar Gulcehre, Dzmitry Bahdanau, Fethi Bougares, Holger Schwenk, Yoshua Bengio · 蒙特利尔大学、勒芒大学等待核对
arXiv ↗Understanding LSTM Networks（含GRU图解） ↗在交互版中打开（演化树、学习进度）

问题

统计翻译的短语表靠计数估计概率，罕见短语的分数很不可靠，也不懂短语的语义；神经网络此前只被用作语言模型或重打分，没有一个网络能直接读入一个变长序列、再生成另一个变长序列。

方法

两个RNN串联：编码器把源短语逐词读完，最后的隐状态作为整个短语的定长向量c；解码器以c为条件逐词生成目标短语。为让RNN能记住和遗忘，提出带“重置门”和“更新门”的新隐藏单元，即后来的GRU。

影响

首次提出“RNN编码器-解码器”这一结构名称和训练方式，与同年的Seq2Seq一起开启了神经机器翻译；GRU作为比LSTM更简单的门控单元被广泛使用。同一团队几个月后为它加上注意力，得到了Bahdanau注意力。

背景

2014年的主流翻译系统是短语统计机器翻译：短语翻译概率靠在平行语料中数“这两个短语同时出现了几次”，再与语言模型、调序等特征在对数线性翻译模型框架下加权。罕见短语只出现一两次，频率估计很不稳；系统也完全不理解“很重要”和“非常关键”是同一个意思。

神经网络此前进入翻译主要有两种方式：Schwenk的连续空间语言模型（类似神经概率语言模型）在解码时给译文打分；循环连续翻译模型等用卷积网络编码源句、RNN生成译文，但效果有限。而循环网络本身，简单单元有梯度消失问题，LSTM有效但结构复杂（三个门加一个独立的记忆单元）。

方法

编码器-解码器（见编码器-解码器）。编码器是一个RNN，逐个读入源序列x₁…x_T，读完后的隐状态就是整个序列的概括c。解码器是另一个RNN，隐状态按h_t = f(h_{t−1}, y_{t−1}, c)更新，每一步输出下一个目标词的分布P(y_t | y_{t−1}, …, y₁, c) = g(h_t, y_{t−1}, c)。两部分联合训练，最大化平行语料中目标序列的条件对数似然。训练好以后可以生成译文，也可以给一对现成的源、目标序列打分。

新的隐藏单元（GRU）。对第j个隐单元：

  • 重置门：r_j = σ([W_r x]_j + [U_r h_{t−1}]_j)
  • 更新门：z_j = σ([W_z x]_j + [U_z h_{t−1}]_j)
  • 候选状态：h̃_j = tanh([W x]_j + [U (r ⊙ h_{t−1})]_j)
  • 新状态：h_j = z_j · h_{t−1,j} + (1 − z_j) · h̃_j

重置门接近0时，候选状态忽略过去、只看当前输入，相当于“丢掉无关历史”；更新门接近1时，旧状态原样保留，信息和梯度都能跨很多步传递（见门控机制）。没有LSTM的独立记忆单元和输出门，参数更少。论文观察到，捕捉短程依赖的单元重置门经常激活，捕捉长程依赖的单元更新门经常激活。

怎么用在翻译里。论文没有让它直接翻译整句，而是用它给短语表中每个短语对重新打分p(f | e)，作为一个新特征加入对数线性模型，由最小错误率训练MERT调权重。训练时忽略短语对在语料中的出现频率，让网络学语言规律而不是记频率。

结果

WMT'14英法翻译，从8.5亿词双语语料中选3.48亿词训练，词表限制为最常见的15,000词，编码器和解码器各1000个隐单元、词向量100维。在测试集上：基线短语系统BLEU 33.30，加入RNN编码器-解码器的短语打分后为33.87；再同时加入连续空间语言模型（CSLM）达到34.64，说明两种神经特征的贡献可以叠加。定性分析显示，它给出的短语分数更偏向语义通顺的译法，学到的短语向量在二维投影中按语义和句法聚类。

后来的发展

同年9月，Seq2Seq用深层LSTM直接做端到端整句翻译；同一团队的注意力机制指出把整句压成一个定长向量是瓶颈，让解码器每一步回看编码器所有位置，从此编码器-解码器加注意力成为标准，并在谷歌神经机器翻译中进入产品。Skip-Thought句向量、层次编码器对话HRED等把编码器-解码器用于句子表示和对话。

GRU作为LSTM的轻量替代，在语音、推荐、时间序列等领域被长期使用。2017年Transformer沿用了编码器-解码器的整体框架，只是把内部的循环网络换成了自注意力。

读懂它需要的概念

循环网络与隐状态 门控机制 编码器-解码器 嵌入向量 Softmax与logits 最大似然估计 噪声信道与词对齐

本篇术语

  • GRU（门控循环单元）　带重置门和更新门的循环单元：更新门决定保留多少旧状态，重置门决定计算新内容时参考多少旧状态。
  • 定长向量瓶颈　无论输入多长都要压缩成同样维度的一个向量，长输入的信息必然丢失。
  • 短语对重打分　保留原有短语表的候选，只用新模型给每个候选重新算一个分数，作为特征提供给原系统。

怎么学

先补循环网络与隐状态、门控机制和编码器-解码器，了解短语统计机器翻译的短语表。读原文第2节（编码器-解码器与GRU公式5–8）和表1。动手：用PyTorch分别实现GRU单元和LSTM单元（不用现成模块），在一个“倒序复制”的玩具任务上比较两者收敛速度；再搭一个最小的GRU编码器-解码器做数字串翻译。
