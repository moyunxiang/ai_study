YOLO

You Only Look Once: Unified, Real-Time Object Detection
2015.06论文重要CVPR 2016Joseph Redmon, Santosh Divvala, Ross Girshick, Ali Farhadi · 华盛顿大学 / Allen AI / Facebook AI Research待核对
arXiv ↗项目页（Darknet） ↗在交互版中打开（演化树、学习进度）

问题

R-CNN系列把检测拆成“生成候选框—逐框分类—修正—去重”多个环节，每个环节单独设计，整个系统每秒只能处理不到一帧到几帧，无法用于视频和机器人。

方法

把检测当成一个回归问题：图像划成7×7的网格，一个卷积网络看一遍整张图，直接输出每个格子的框坐标、置信度和类别概率。

影响

第一个达到实时（每秒45帧）且精度可用的深度检测器，Fast YOLO每秒155帧；它开创的单阶段检测路线经过YOLOv2–v3和社区版本，成为工业界部署最广的检测器家族。

背景

2015年的主流检测器是R-CNN和Fast R-CNN：先用选择性搜索提约2000个候选框，再对每个框分类和回归，最后做非极大值抑制。这条流水线精度高，但慢——Fast R-CNN用VGG-16约每秒0.5帧；而且每个部件分开优化，分类器只看到候选框内部，看不到整张图的上下文，因此经常把背景的一块误认为物体。

当时能实时运行的检测器只有GPU加速版的可变形部件模型DPM，精度很低。同期的Faster R-CNN用RPN取代了选择性搜索，但仍是两阶段、每秒约5帧。YOLO想回答：检测能不能像人看一眼那样，一次前向就完成？

方法

网格划分。把输入图像（448×448）分成S×S＝7×7个格子。哪个格子包含了物体的中心，哪个格子就负责检测这个物体。

每个格子输出什么。

  • B＝2个框，每个框5个数：中心坐标(x, y)（相对于格子）、宽高(w, h)（相对于整张图）、置信度。置信度定义为Pr(物体) × IoU(预测框, 真值框)，即“这里有物体的把握”乘以“框得有多准”；
  • C＝20个条件类别概率Pr(类别 | 物体)，每个格子只预测一组，不管有几个框。

所以在PASCAL VOC上，网络的输出是一个7 × 7 × (2×5 + 20) = 7 × 7 × 30的张量。测试时，每个框的类别得分＝置信度×类别概率，再做一次非极大值抑制。

网络。受GoogLeNet / Inception启发的24个卷积层加2个全连接层，用1×1卷积压缩通道再接3×3卷积（不用Inception模块）。前20层先在ImageNet上预训练（top-5准确率88%）。Fast YOLO只用9个卷积层。

损失。所有输出都用平方误差，但做了三处调整：坐标误差乘λ_coord = 5加大权重；不含物体的格子的置信度误差乘λ_noobj = 0.5，避免大量空格子压倒其他信号；宽高预测其平方根，让大框上偏几个像素比小框上偏几个像素的惩罚小。

结果

PASCAL VOC 2007：YOLO mAP 63.4%、每秒45帧（Titan X）；Fast YOLO 52.7%、每秒155帧，是此前实时检测器（30Hz的DPM为26.1%）的两倍多。作为对比，Fast R-CNN 70.0%但每秒0.5帧。误差分析：Fast R-CNN的检测结果中13.6%是把背景当成物体，YOLO只有4.75%；但YOLO的定位误差明显更多。用YOLO为Fast R-CNN的检测重新打分，可把mAP从71.8%提到75.0%。在毕加索画作和人物艺术画数据集上，YOLO的泛化明显好于R-CNN和DPM。

后来的发展

单阶段检测从此成为与两阶段并行的路线。同年的SSD在多个尺度的特征图上放锚框，精度追平Faster R-CNN；YOLOv2 / YOLO9000加入锚框和批归一化，YOLOv3加入多尺度预测；Focal Loss与RetinaNet用Focal Loss解决单阶段检测中前景背景极度不平衡的问题。YOLOv3之后，YOLOv4、Ultralytics YOLO系列等版本由其他团队继续发展，YOLOv10免NMS进一步去掉了非极大值抑制。

容易误解的地方

  • YOLO v1没有锚框，框是从每个格子直接回归出来的；锚框是YOLOv2才引入的。
  • “只看一次”指一次网络前向，后处理仍有非极大值抑制。

局限与后续

  • 每个格子只预测2个框、1组类别，挨得很近的多个物体（鸟群、人群）和小物体经常漏检。
    后来针对它的工作　SSD YOLOv2 / YOLO9000 YOLOv3
  • 直接回归框坐标、只用最后一层粗糙特征，定位误差是它最主要的错误来源，精度明显低于Fast R-CNN。
    后来针对它的工作　YOLOv2 / YOLO9000 SSD
  • 全连接层要求固定的448×448输入，对训练中没见过的长宽比和尺度的物体泛化较差。
    后来针对它的工作　YOLOv2 / YOLO9000
  • 仍需要非极大值抑制这一手工后处理来去重。
    后来针对它的工作　DETR YOLOv10免NMS

它建立在什么之上

  • 改进
    可变形部件模型DPM2008.06 · 视觉

  • 改进
    R-CNN2013.11 · 视觉
    把R-CNN的多阶段流水线压成一个网络的一次前向，速度提高两个数量级，而且背景误检少得多。
  • 竞争
    Fast R-CNN2015.04 · 视觉
    Fast R-CNN精度更高（70.0%）但每秒0.5帧且背景误检多；两者互补，组合后mAP达75.0%。
  • 竞争
    Faster R-CNN2015.06 · 视觉
    同月发布：Faster R-CNN保留两阶段、追求精度，YOLO走单阶段、追求速度。此后两条路线长期并存，实时应用多用YOLO系。
  • 使用
    GoogLeNet / Inception2014.09 · 视觉
    主干网络受GoogLeNet启发，用1×1降维加3×3卷积的组合代替Inception模块。

读懂它需要的概念

卷积层、池化与感受野 IoU与mAP 锚框与非极大值抑制 损失函数 线性回归 分类、检测、分割

本篇术语

  • 单阶段检测器　不先生成候选框，而是一次前向直接输出所有框和类别的检测器，速度快、结构简单。
  • 置信度（YOLO）　每个预测框的“有物体的概率×预测框与真值框的IoU”，同时反映有没有物体和框准不准。
  • FPS　每秒处理的帧数。通常每秒30帧以上被称为实时。

怎么学

先补IoU与mAP和锚框与非极大值抑制。读原文第2节（统一检测、网络设计和损失函数），自己推一遍7×7×30的输出形状和损失中的每一项。动手：用Ultralytics的YOLO在自己的摄像头视频上跑实时检测；然后自己写一个简化版YOLO v1损失函数，在一个小数据集上训练。
