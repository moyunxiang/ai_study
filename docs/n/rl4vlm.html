RL4VLM视觉语言模型RL

Fine-Tuning Large Vision-Language Models as Decision-Making Agents via Reinforcement Learning
2024.05论文延伸NeurIPS 2024Yuexiang Zhai, Hao Bai, Zipeng Lin, Jiayi Pan, Shengbang Tong, Yifei Zhou, Alane Suhr, Saining Xie et al. · UC伯克利 / 纽约大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉语言模型靠视觉指令数据微调后语言推理很强，但这种监督微调学不出在交互环境里多步决策、朝目标行动的好策略。

方法

让VLM看图后先写思维链、再输出文字动作，把文字动作解析成环境可执行的操作，用环境给出的任务奖励直接对整个VLM做强化学习。

影响

7B模型经RL后在多项决策任务上超过GPT-4V和Gemini，并说明思维链是RL微调VLM的关键组件，是“用RL把多模态模型训成智能体”方向的早期代表。

方法

框架分四步：

  • 给VLM一张环境画面和任务描述，提示它先生成思维链（例如“当前手牌点数是15，再要一张牌爆掉的概率较高……”），最后输出一个文字形式的动作；
  • 把开放的文字输出解析成环境可执行的动作（格式不合法时给惩罚或随机动作）；
  • 执行动作，得到朝目标的任务奖励；
  • 用这些奖励以PPO对整个VLM（包括思维链和动作的词元）做强化学习更新。动作的概率由动作词元的概率计算，思维链部分的概率乘以一个缩放系数，以免长篇推理主导更新。

实验环境包括需要算术推理的纸牌游戏（如二十一点、凑24点）和需要视觉语义理解的具身家务环境（ALFWorld文字家务环境的视觉版）。结果显示，7B模型经过该框架训练后决策能力明显提高，超过GPT-4V、Gemini等商用模型。消融发现，去掉思维链后整体表现显著下降，说明让模型先推理再行动对RL探索很重要。这与ArCHer分层多轮RL、DigiRL设备控制RL等同组的多轮智能体RL工作互为补充，把对象从纯文本模型扩展到视觉语言模型。

局限与后续

  • 思维链概率的缩放系数需要手动调，太大太小都会影响训练，缺少原则性的设定。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 实验环境是纸牌游戏和模拟家务等相对简单的任务，没有在真实GUI或机器人上验证。

怎么学

先读PPO和ArCHer分层多轮RL → 读原文第4节动作概率的计算与思维链缩放系数 → 动手：给一个VLM看二十一点的牌面截图，让它先推理再输出“要牌/停牌”，统计格式合法率和胜率。
