模型窃取

Stealing Machine Learning Models via Prediction APIs
2016.09论文延伸USENIX Security 2016Florian Tramèr, Fan Zhang, Ari Juels, Michael K. Reiter, Thomas Ristenpart · EPFL / 康奈尔大学 / 北卡罗来纳大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

云厂商把训练好的模型作为按次收费的预测API提供，以为只暴露输入输出就能保护模型本身；这个假设没有被检验过。

方法

只靠黑盒查询（含置信度），用较少的查询就能复制出与目标模型几乎等价的模型，对逻辑回归、决策树、神经网络都有效。

影响

开启了模型提取（模型窃取）研究，说明API的保密性不等于模型的保密性，也直接引出后来的窃取生产级LLM的参数。

方法

论文的设定是：模型因为训练数据敏感、商业价值或用于安全应用而保密，但通过公开查询接口提供服务；攻击者没有模型参数和训练数据的任何先验知识，只能提问。

作者指出，与传统学习理论中只有标签的设定不同，机器学习即服务（ML-as-a-service）常常接受部分特征向量，并返回置信值，这给了攻击者更多信息。对于逻辑回归这类模型，返回的置信值本身就是一个方程，所以用少量查询列出方程组就能解出全部参数（方程求解攻击）；对决策树，则可以利用返回的叶节点标识恢复树路径。

他们在BigML和Amazon等真实服务上验证了攻击可行。他们也讨论了对策，如只返回标签、对置信度取整，但这些方法并不能完全消除风险。

局限与后续

  • 防御手段（只返回标签、取整）会降低服务的可用性，也并不能完全阻止窃取。
