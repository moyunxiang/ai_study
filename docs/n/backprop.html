反向传播

Learning Representations by Back-propagating Errors
1986论文主干Nature 1986David E. Rumelhart, Geoffrey E. Hinton, Ronald J. Williams · UC San Diego / Carnegie Mellon来源已核对
Nature ↗原文PDF（Hinton主页） ↗Karpathy: micrograd ↗在交互版中打开（演化树、学习进度）

问题

感知机只能训练最后一层，算不了XOR；多层网络表达力够，但没人知道中间那些“隐藏”单元的权重该怎么调。

方法

用链式法则把输出端的误差一层层往回传，一次反向计算就得到每个权重对误差的偏导，再沿负梯度方向更新所有层的权重。

影响

用清楚的实验展示了多层网络可以靠梯度下降训练，隐藏层能自己学出有意义的特征；此后的神经网络，包括今天的大模型，普遍用它算梯度。

背景

1969年《Perceptrons》与XOR问题证明了单层感知机算不了XOR、奇偶性这类问题。解决办法大家都知道——加一层隐藏单元，两层阈值网络就能实现XOR。真正卡住的是信用分配（见信用分配）：输出错了，该怪哪个隐藏单元？它的权重该往哪边改、改多少？感知机的学习规则只对能直接看到“正确答案”的输出层有效，隐藏层没有现成的目标值。

其实答案的数学部分早已存在。1970年Linnainmaa提出了反向模式自动微分（反向模式自动微分），能高效计算嵌套函数的梯度；1974年Werbos博士论文在博士论文里把它用到了多层网络上。但这些工作不在神经网络圈子的视野里，也没有人用实验展示过隐藏层到底能学到什么。另一个阻碍是：经典感知机用0/1阶跃函数作激活，它几乎处处导数为0，梯度根本传不过去。

方法

第一步：换成可导的单元。每个单元先求加权和x_j = Σ_i y_i·w_ji，再过一个平滑的S形函数y_j = 1 / (1 + e^(−x_j))（见神经元与激活函数）。它和阶跃函数形状相似，但处处可导，导数还很好算：dy/dx = y(1 − y)。

第二步：定义误差。对一批样本，网络输出y与目标d的平方误差E = ½ Σ (y − d)²（见损失函数）。

第三步：前向传播。从输入层开始，一层一层算出每个单元的输出，直到输出层。

第四步：反向传播误差（见反向传播和链式法则）。对输出单元，∂E/∂y = y − d，再乘上S形函数的导数得到∂E/∂x = ∂E/∂y · y(1 − y)。对连接i→j的权重，∂E/∂w_ji = ∂E/∂x_j · y_i。关键在于隐藏单元：它的误差信号等于它所连到的所有上层单元误差的加权和∂E/∂y_i = Σ_j ∂E/∂x_j · w_ji。于是从输出层开始，每一层用上一层算好的结果就能得到本层的梯度，一路倒推回输入层。整个反向过程的计算量与前向过程同一量级，而不是每个权重单独算一遍。

第五步：更新权重。论文用的是带动量的梯度下降（见梯度下降、动量法）：

Δw(t) = −ε·∂E/∂w(t) + α·Δw(t−1)

ε是学习率，α让这一步保留一部分上一步的方向，减少来回振荡。权重要从小的随机数开始，否则同一层的隐藏单元会收到一模一样的梯度，永远学成一样的东西。

一个例子：判断6位二进制输入是否左右镜像对称。网络只有2个隐藏单元，训练后两侧权重按1:2:4的比例对称取反——左边的8种模式各给出唯一的加权和，只有完全镜像的右半边才能把它抵消成0。这个解法没有人教，是网络自己找到的。

结果

论文展示了两个实验。镜像对称检测：用全部64种输入，每遍历一轮更新一次，ε = 0.1、α = 0.9，1425轮后学会。家族关系：两棵同构的家谱（英国和意大利家庭各12人），12种关系（父亲、母亲、叔叔……），共104条“人物1–关系–人物2”三元组；网络在其中100条上训练，正确推出了另外4条没见过的。更重要的是，检查隐藏单元发现它们自发编码了“属于哪一代”“属于家族哪一支”“是英国人还是意大利人”等特征——这些概念从未出现在输入里。

作者也坦白了局限：误差曲面可能有局部极小，但实践中很少卡在明显更差的解上；这个过程不是大脑学习的合理模型。

后来的发展

这篇论文和同年的《并行分布式处理》广泛传播了这一方法，常被认为推动了神经网络在1980年代后期的复兴：卷积网络识别邮编用它训练卷积网络识别邮编，NETtalk用它学英语发音，Elman循环网络和随时间反向传播BPTT把它推广到循环网络。随后十几年，人们发现层数一深梯度就会衰减（梯度消失问题），深层网络很难训练，不少应用转向了支持向量机等方法。经过深度信念网络、ReLU、ResNet等一系列改进，加上GPU算力，反向传播在AlexNet之后成为深度学习训练的标准做法。

今天的变化在外围而非核心：S形激活换成了ReLU一族，平方误差在分类任务上换成交叉熵，手推梯度换成框架里的自动微分（Theano与自动微分、PyTorch），优化器换成Adam。“前向算损失、反向算梯度、按梯度更新”这三步原封未动。

容易误解的地方

  • 反向传播不是这篇论文“发明”的：反向模式求导1970年就有，Werbos 1974年已用于神经网络。这篇的贡献是用清晰的实验显示隐藏层能学出有意义的内部表示，使方法广为人知；论文自己也提到Parker和LeCun独立发现了这一方法的变体。
  • 严格说，反向传播只是算梯度的方法；用梯度去更新参数的是梯度下降或其他优化器。两者常被混称。
  • 它并不保证找到全局最优，只是沿梯度走到一个局部的低点；但大网络里坏的局部极小比当年担心的少得多。

局限与后续

  • 层数一多，误差信号每经过一层都要乘上S形函数的导数（最大0.25），传到底层时几乎为0，深层网络训不动。
    后来针对它的工作　LSTM ReLU Xavier初始化 深度信念网络 ResNet Batch Normalization
  • 参数多、数据少时极易过拟合，当时缺乏有效的正则化手段。
    后来针对它的工作　权重衰减 Dropout
  • 学习率、动量等超参数全靠手调，不同层的梯度大小相差悬殊，训练慢且不稳定。
    后来针对它的工作　AdaGrad Adam Batch Normalization
  • 需要大量计算，在1980年代的CPU上只能训练几百到几千个权重的小网络。
    后来针对它的工作　CUDA GPU上的大而简单的网络 AlexNet
  • 需要把误差精确地逐层反传，生物大脑中没有已知的对应机制，作者自己也说它不是大脑学习的合理模型。作者在原文中指出

它建立在什么之上

  • 改进
    达特茅斯会议1956.06 · 事件 已核对
    神经元网络如何“形成概念”没有可用的学习算法，多层网络无法训练。
  • 改进
    感知机1958 · 基础 已核对
    感知机规则只能调最后一层，反向传播让所有层的权重都能根据误差学习。
  • 使用
    动量法1964 · 基础 已核对
    论文的权重更新式里直接加了动量项α·Δw(t−1)，用来加速并减少振荡。
  • 改进
    《Perceptrons》与XOR问题1969 · 基础 已核对
    Minsky和Papert指出单层网络算不了XOR且不知如何训练多层网络；反向传播给出了训练隐藏层的通用方法。
  • 使用
    反向模式自动微分1970 · 系统·效率 已核对
    数学上与Linnainmaa 1970年硕士论文中的反向模式自动微分相同，用在神经网络这种分层嵌套函数上；本文没有引用它，是独立推导。
  • 使用
    随机梯度下降1951 · 基础 已核对
    梯度算出来后用梯度下降更新权重：论文的实验先在全部样本上累积梯度再更新，也提到每个样本后就更新的做法。
  • 竞争
    玻尔兹曼机1985 · 基础 已核对
    Hinton参与提出的玻尔兹曼机学习也能训练隐藏单元，但要靠随机采样达到平衡、很慢；反向传播走的是确定性的梯度路线。
  • 改进
    ADALINE与LMS1960 · 基础 待核对
    ADALINE的LMS规则是单层网络上平方误差的梯度下降；反向传播把这个“delta规则”推广到任意多层。
  • 延续
    Werbos博士论文1974 · 基础 待核对
    Werbos 1974年的博士论文已描述用误差反传训练神经网络，但未被神经网络界注意；本文没有引用它，属于独立的重新发现，并用实验使其广为流传。
  • 改进
    M-P神经元1943 · 基础
    输出是0/1的阶跃函数，对输入的微小变化完全不敏感，无法用梯度来指导如何修改网络。
  • 改进
    逻辑回归1958 · 基础
    决策边界是输入空间中的一个超平面，像XOR这样不能被一条直线分开的问题它学不会，除非人工构造交叉特征。
  • 改进
    德雷福斯的哲学批判1972 · 事件
    只指出符号方法的局限，没有给出实现“直觉式会做”的具体计算机制。
  • 改进
    第一次AI寒冬1973 · 事件
    神经网络研究在经费断绝中停滞，多层网络如何训练的问题悬而未决。
  • 改进
    物理符号系统假说1976.03 · 事件
    “必要性”主张缺乏神经科学证据，联结主义网络不用显式符号也能学到复杂能力。
  • 改进
    专家系统的商业化1980 · 事件
    系统不会从经验中学习，也无法自动适应新产品、新情况。
  • 改进
    Hopfield网络1982 · 基础
    没有隐藏单元，只能原样存储给定的模式，无法学习数据中的抽象特征。
  • 改进
    Hebb学习律1949 · 基础
    纯Hebb规则只增不减，权重会无界增长，也无法利用误差信号做有监督学习。
  • 改进
    Mark I感知机硬件1960.06 · 硬件
    单层感知机只能学线性可分的问题，硬件再大也解决不了XOR这类问题。
  • 改进
    信用分配问题的提出1961 · RL
    神经网络内部权重的信用分配当时没有可行方法。
  • 改进
    Minsky获图灵奖1969 · 事件
    他的主要贡献在符号AI和框架理论，当时对学习系统的价值判断（对感知机的批评）后来被证明过于悲观。
  • 改进
    “AI寒冬”一词的提出1984.08 · 事件
    “寒冬”叙事过于简化，许多技术（概率图模型、机器学习）在所谓寒冬里持续进步，只是不叫AI。

读懂它需要的概念

链式法则 导数、偏导与梯度 梯度下降 神经元与激活函数 多层感知机 损失函数 信用分配

本篇术语

  • 隐藏单元　既不是输入也不是输出的中间层神经元。它没有现成的“正确答案”，只能间接地从输出误差中学习。
  • S形函数（sigmoid / logistic）　σ(x) = 1 / (1 + e^(−x))，把任意实数压到0到1之间，形状像拉平的S，处处可导。
  • 前向传播 / 反向传播　前向：从输入逐层算到输出和损失。反向：从损失出发，按链式法则逐层往回算每个参数的梯度。
  • sweep（轮）　论文中把整个训练集过一遍叫一个sweep，相当于今天说的一个epoch。

怎么学

先确认会链式法则和导数、偏导与梯度，并读一下反向传播词条。然后读这篇论文本身——只有4页，重点看公式(1)到(9)和图1的对称检测网络。动手：看Karpathy的micrograd视频，用纯Python写一个能对标量自动求导的小引擎，再用它训练一个两层网络学XOR；最后用PyTorch重做一遍，对比你手算的梯度和autograd的结果。
