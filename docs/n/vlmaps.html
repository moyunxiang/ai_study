VLMaps视觉语言地图

Visual Language Maps for Robot Navigation
2022.10论文延伸ICRA 2023Chenguang Huang, Oier Mees, Andy Zeng, Wolfram Burgard · University of Freiburg、Google待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

用CLIP这类视觉-语言模型可以把图片和“沙发”这样的词对上，但它与建图过程是脱节的，没有几何地图那样的空间精度，听不懂“沙发和电视之间”这种空间指令。

方法

把预训练视觉-语言模型的逐像素特征直接融合进环境的三维重建，得到一张每个位置都带语言特征的地图，于是可以用自然语言在地图上“查询”位置。

影响

把开放词汇的语言理解与经典的空间地图结合起来，是“语义特征地图”这类具身导航表示的代表工作之一。

方法

传统导航用占据栅格地图这样的几何地图，知道哪里能走，却不知道哪里是“沙发”。CLIP能把图片与文字匹配，但只作用在整张图上，没有空间位置。VLMaps的做法是：机器人用常规的探索方法边走边拍RGB-D视频，用一个开放词汇的视觉-语言分割模型为每个像素提取语言对齐的特征，再根据深度和相机位姿把这些特征投到俯视的栅格地图上并做平均。建好之后，不需要任何额外标注，就能输入任意物体名称，算出地图上每个格子与该词的相似度，从而定位“椅子”“水槽”在哪里。

与大语言模型结合时，LLM把自然语言指令翻译成一串开放词汇的导航目标，而且这些目标可以带空间关系，比如“沙发和电视之间”“椅子右边三米”，直接在地图上定位；这一步借鉴了Code as Policies用LLM写程序调用底层函数的做法。同一张地图还能在不同形态的机器人之间共享：给出各自的障碍物类别列表，就能即时生成适合该机器人的障碍地图。仿真和真实环境实验表明，它能执行比已有方法更复杂的语言导航指令。

局限与后续

  • 地图是静态的，物体被移动后需要重新建图；也只记录二维俯视位置，难以处理多层或上下关系。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 使用
    Code as Policies2022.09 · 具身·世界模型

怎么学

先了解CLIP和栅格地图，再读论文的建图与空间指令解析部分；可以在Habitat仿真里用开源代码建一张VLMap并尝试语言查询。
