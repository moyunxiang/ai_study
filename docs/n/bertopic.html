BERTopic主题模型

BERTopic: Neural topic modeling with a class-based TF-IDF procedure
2022.03论文延伸Maarten Grootendorst待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

LDA主题模型等词袋主题模型不考虑词序和语义相似，短文本上主题零散，而且需要事先指定主题数。

方法

先用预训练句向量模型编码每篇文档，降维后聚类，再把每个簇当作一个类，用按类计算的TF-IDF挑出代表词作为主题。

影响

把主题建模变成「嵌入+聚类+关键词」的模块化流程，成为社会科学和业务文本分析里最常用的主题模型工具之一。

方法

BERTopic分四步。第一步用Sentence-BERT框架下的预训练模型（实验用all-mpnet-base-v2）把每篇文档变成一个向量，语义相近的文档向量也相近。第二步用UMAP把高维向量降到低维，论文认为它比PCA和t-SNE更能同时保留局部与全局结构。第三步用HDBSCAN聚类，它能找出密度不同的簇，并把不属于任何簇的文档标为噪声，所以主题数不必事先给定。第四步给每个簇找关键词：把簇内文档拼成一篇大文档，计算按类的TF-IDF W(t,c) = tf(t,c) · log(1 + A / tf(t))，其中tf(t,c)是词t在类c中的频次，A是每类的平均词数，tf(t)是词t在所有类中的总频次。这是IDF与TF-IDF把「文档」换成「类」的版本，得分最高的词就是主题词。

论文在20 NewsGroups、BBC News和特朗普推文上与LDA主题模型、NMF、CTM、Top2Vec比较，称其主题连贯性有竞争力；在推文和联合国辩论文本上还演示了随时间变化的动态主题。

局限与后续

  • 每篇文档只被分到一个簇，难以表达一篇文档同时涉及多个主题，这一点不如LDA的混合主题假设。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 结果依赖嵌入模型和UMAP、HDBSCAN的超参数，不同随机种子下主题划分可能明显不同。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    IDF与TF-IDF1972.01 · NLP
    把TF-IDF的单位从单篇文档改为一个簇，用来提取主题代表词。
  • 使用
    Sentence-BERT2019.08 · NLP
    用SBERT系的预训练句向量模型编码文档。
  • 竞争
    LDA主题模型2003 · NLP
    LDA把文档看作主题的概率混合，BERTopic把主题建模当成嵌入空间里的聚类问题。
  • 竞争
    t-SNE2008.11 · 基础
    降维一步选用UMAP，论文认为它比t-SNE更能保留全局结构。

读懂它需要的概念

嵌入向量 聚类 降维与PCA 预训练与微调

本篇术语

  • 主题模型　从一批文档中自动归纳出若干「主题」，每个主题用一组高频代表词描述，并说明每篇文档属于哪些主题。
  • HDBSCAN　一种基于密度的层次聚类算法，能自动决定簇的数量，并把稀疏处的点标为噪声。

怎么学

先懂TF-IDF、聚类和句向量；读原文第3节c-TF-IDF；动手用BERTopic库在一批新闻标题上训练，查看主题词和主题随时间的变化。
