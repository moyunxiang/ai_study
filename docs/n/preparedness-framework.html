OpenAI准备度框架

Preparedness Framework (Beta)
2023.12思想延伸OpenAI待核对
OpenAI文档（beta） ↗在交互版中打开（演化树、学习进度）

问题

前沿模型发布缺乏事先约定的风险评估与门槛，各家如何决定『够不够安全』并不透明。

方法

提出一套跟踪、评估、预测并防范灾难性风险的流程，按风险类别和等级决定能否训练或部署。

影响

与负责任扩展政策RSP、DeepMind前沿安全框架一起，形成了前沿实验室风险分级承诺的基本格式。

方法
