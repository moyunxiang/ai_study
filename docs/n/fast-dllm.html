Fast-dLLM免训练加速

Fast-dLLM: Training-free Acceleration of Diffusion LLM by Enabling KV Cache and Parallel Decoding
2025.05论文延伸Chengyue Wu, Hao Zhang, Shuchen Xue, Zhijian Liu, Shizhe Diao, Ligeng Zhu, Ping Luo, Song Han, Enze Xie · NVIDIA / 香港大学 / MIT待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

开源扩散大模型号称能并行，实际却比自回归模型慢：双向注意力用不了KV缓存，一步解多个词质量又会崩。

方法

不重新训练：按块做近似KV缓存，并且每步只解码置信度超过阈值的位置，避免同时写出互相冲突的词。

影响

让LLaDA、Dream这类模型吞吐最高提升27.6倍，它的缓存和阈值解码在后续dLLM加速工作中被反复沿用和比较。

方法

LLaDA大语言扩散模型这类掩码扩散模型每一步都要对整段序列做双向注意力，前面已经确定的词也得重算，KV缓存无从谈起；而且如果一步同时揭开很多个掩码位置，模型是假设这些位置条件独立地各自取最可能的词，容易拼出“前后不搭”的句子，所以实际只能一步解一两个词，速度反而不如自回归。

Fast-dLLM给了两个免训练的办法。一是分块近似KV缓存：借鉴块扩散BD3-LM的分块生成，把序列切块，块内去噪时前缀（以及DualCache版本里的后缀掩码部分）的键值在若干步内复用，只在块结束时刷新。双向注意力下这些键值其实会微变，但作者发现相邻步之间差异很小，近似带来的损失可以忽略。二是置信度感知的并行解码：作者把质量下降归因于条件独立假设破坏了词间依赖，于是每步只揭开预测概率超过阈值的位置，置信度高时一次解很多个，置信度低时退回一次一个。

在LLaDA和Dream上的多项基准中，论文报告吞吐最多提高27.6倍，精度损失很小。

局限与后续

  • KV缓存是近似的，模型本身没有为分块缓存训练过，块长和刷新频率要手调，长生成时误差会累积。

  • 阈值解码只是绕开而非解决条件独立问题：已经写错的词无法修改，速度和质量仍需折中。
    后来针对它的工作　LLaDA2.0百亿级扩散 DiffusionGemma
