HGT异构图Transformer

Heterogeneous Graph Transformer
2020.03论文延伸WWW 2020Ziniu Hu, Yuxiao Dong, Kuansan Wang, Yizhou Sun · 加州大学洛杉矶分校、微软研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大多数GNN为同构图设计，所有节点和边都属于同一类型；而学术图、知识图谱、电商图里有多种节点（论文、作者、机构）和多种关系，还会随时间变化。

方法

让注意力的参数随节点类型和边类型而变：每条边上的注意力与消息都由“源节点类型、边类型、目标节点类型”决定；再加相对时间编码处理动态图，并设计异构小批量采样算法以扩展到网络规模。

影响

成为异构图神经网络的主要基线之一，PyG以HGTConv提供实现；与HAN异构图注意力一起被视为该方向的代表方法。

方法

HGT一层的计算像Transformer的多头注意力，但把投影矩阵按类型拆开：对目标节点t和源节点s，先用目标类型对应的矩阵得到Query、用源类型对应的矩阵得到Key，再乘一个按边类型参数化的矩阵W_φ(e)算出注意力分数，并加上按“源类型—边类型—目标类型”三元组学习的先验系数；消息同样由源类型的Value投影和边类型矩阵生成。这样不同类型的节点和关系既能各自保留专用的表示空间，又通过共享的结构互相传递信息，而无需人为设计元路径。

为处理动态图，作者引入相对时间编码：按源和目标节点时间戳之差生成一个正弦编码加到源节点表示上，可捕捉任意时间跨度的依赖。为扩展到网络规模，提出HGSampling：按节点类型分别维护采样预算，使采出的子图中各类型节点数量均衡。摘要报告在1.79亿节点、20亿边的Open Academic Graph上做了大量实验。

局限与后续

  • 类型相关参数随节点和边类型数增长，类型很多时参数量大、容易过拟合。

它建立在什么之上

  • 延续
    Transformer2017.06 · LLM
    把多头自注意力推广到带类型的异构图上。
  • 延续
    关系图卷积R-GCN2017.03 · 基础
    R-GCN按关系类型区分权重，HGT进一步按节点类型与边类型参数化注意力。
  • 使用
    GraphSAGE2017.06 · 基础
    大图小批量采样训练的思路，HGSampling针对异构图做了类型均衡。
  • 竞争
    HAN异构图注意力2019.03 · 基础
    HAN依赖人为指定的元路径，HGT直接用类型参数化的注意力，无需元路径。

读懂它需要的概念

自注意力与多头注意力 图、树与搜索 图神经网络与消息传递 位置编码

怎么学

先读关系图卷积R-GCN和Transformer的多头注意力；读论文第3节注意力与消息的类型参数化；动手用PyG的HGTConv在OGB-MAG上做论文所属领域分类。
