Microsoft Fairwater

2025.09硬件延伸Microsoft待核对
Microsoft Source ↗在交互版中打开（演化树、学习进度）

问题

训练前沿模型要的GPU数量超过单个园区的电力和空间，需要多个站点协同训练同一个模型。

方法

Microsoft建设Fairwater系列AI数据中心，用专用广域网把威斯康星和亚特兰大的两处连成一个「AI超级工厂」。

影响

它是第一个公开宣称跨州联合训练的超大规模设计，展示云厂商如何围绕GPU重做整座数据中心。

方法

Microsoft在2025年11月12日的文章称，亚特兰大的AI数据中心2025年10月开始运营，是Fairwater家族的第二座；它与威斯康星站点通过AI广域网相连，组成「AI超级工厂」，让不同州的站点协同训练，原本需数月的任务可缩短到数周（官方称）。网络将连接数十万颗最先进的GPU，支持OpenAI、Microsoft AI Superintelligence团队和Copilot等。

它继承了微软为OpenAI建的超算时代为OpenAI建超算的路线，并采用Blackwell与整机柜液冷级GPU的整机柜液冷设计。区别在于从单个机房变成跨站点的一个整体：一个大任务被拆到多个地点同时运行。

局限与后续

  • 跨站点训练受限于长距离光纤延迟与带宽，同步训练的效率损耗没有公开独立数据。
    本站还没有记录针对它的后续工作（不代表没有人解决）

    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 使用
    Blackwell与整机柜液冷2024.03 · 硬件
