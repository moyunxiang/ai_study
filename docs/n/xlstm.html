xLSTM

xLSTM: Extended Long Short-Term Memory
2024.05论文延伸NeurIPS 2024Maximilian Beck, Korbinian Pöppel, Markus Spanring, Andreas Auer, Oleksandra Prudnikova, Michael Kopp, Günter Klambauer, Johannes Brandstetter, Sepp Hochreiter · JKU Linz / NXAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LSTM曾是首批大语言模型的基础，但被Transformer在规模上超越；LSTM能否扩展到数十亿参数？

方法

引入指数门控及稳定化，并给出两种新记忆结构：标量记忆的sLSTM和可完全并行的矩阵记忆mLSTM。

影响

由LSTM原作者团队重新证明循环结构经过改造仍可与Transformer和状态空间模型竞争。

方法

论文做了两处修改。第一，指数门控加上归一化与稳定化技巧，使模型能更灵活地修正存储的决定。第二，改动记忆结构：sLSTM保持标量记忆、标量更新，并加入记忆混合；mLSTM用矩阵记忆和协方差式更新规则，不再有对前一步隐状态的依赖，因此可以完全并行训练。

两种单元放入残差块形成xLSTM块，再残差堆叠成完整网络。摘要称在性能与扩展性上与最先进的Transformer和状态空间模型相比表现良好。

局限与后续

  • sLSTM的记忆混合使它无法并行训练，速度受限。

它建立在什么之上

  • 延续
    LSTM1997 · 基础
    保留恒定误差传送带与门控，加入指数门控和矩阵记忆以适应现代大规模训练。
  • 改进
    LSTM遗忘门1999.09 · 基础
    每一步都依赖上一步，序列内部无法并行；整段历史压进固定大小的状态，遗忘门只能整体衰减，不能精确改写某一条记忆。
  • 改进
    RWKV2023.05 · 基础
    早期版本的衰减与状态更新不依赖输入内容，表达力有限。

读懂它需要的概念

循环网络与隐状态 门控机制 残差连接 自回归生成 参数量、计算量与显存

怎么学

先复习LSTM的门控；读原文第2节的sLSTM、mLSTM及第3节的块结构；对照官方代码看mLSTM的并行形式与递归形式如何等价。
