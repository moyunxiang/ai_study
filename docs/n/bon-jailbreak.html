Best-of-N越狱

Best-of-N Jailbreaking
2024.12论文延伸John Hughes, Sara Price, Aengus Lynch, Rylan Schaeffer, Fazl Barez, Sanmi Koyejo, Henry Sleight, Erik Jones, Ethan Perez, Mrinank Sharma · Speechmatics / MATS / UCL / Stanford / Oxford / Anthropic 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

已有越狱要么需要白盒梯度，要么需要人工巧思；前沿模型对输入的微小扰动到底有多敏感，缺少简单的量化。

方法

黑盒暴力法：对有害提示反复做随机增强（打乱字母、随机大小写等），一直采样直到某个变体得到有害回答。

影响

表明只靠增加尝试次数就能越狱前沿模型，且成功率随次数按类幂律增长，可用来预测攻击者花多少预算能得手。

方法

算法很简单：取一条有害请求，每次随机组合几种增强——文字上打乱字符顺序、随机改大小写等，图像上改字体和背景，音频上改语速、音高和背景噪声——发给模型，用分类器判断回答是否有害，不行就再采样一次。

采样1万个增强提示时，GPT-4o的攻击成功率达89%，Claude 3.5 Sonnet达78%；它也能绕过开源的熔断器：表示重定向防御，并能越狱GPT-4o的视觉输入和Gemini 1.5 Pro的音频输入。关键观察是：成功率的负对数与样本数N呈类幂律关系，跨越多个数量级都成立，因此可以用少10倍的样本外推攻击效果。与优化前缀的攻击组合后，成功率最多再提高35%。
