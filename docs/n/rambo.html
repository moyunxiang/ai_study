RAMBO对抗模型离线RL

RAMBO-RL: Robust Adversarial Model-Based Offline Reinforcement Learning
2022.04论文延伸NeurIPS 2022Marc Rigter, Bruno Lacerda, Nick Hawes · 牛津大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的离线RL（MOPO、MOReL）靠模型集成的不确定性给奖励打折或划禁区，需要手工设计不确定性度量，而这些度量与真实误差的关系并不可靠。

方法

把问题写成策略与“对抗的环境模型”之间的零和博弈：模型在准确预测数据中转移的前提下尽量把策略的价值往低处推，从而在数据没覆盖的地方自动变得悲观。

影响

给出了不依赖不确定性启发式的模型式离线RL，常与MOPO、MOReL、COMBO并列出现在离线RL对比表里，相关的“鲁棒对抗模型”思路也被后续工作沿用。

方法

MBPO式的做法是：从数据学一个动力学模型，用它生成短的虚拟轨迹来训练策略。离线时模型在数据外不可靠，MOPO模型离线优化用集成方差惩罚奖励，MOReL悲观模型离线RL把不确定的区域设成终止状态。RAMBO（Robust Adversarial Model-Based Offline RL）不再设计不确定性度量，而是让模型本身变成“对手”：

  • 策略在当前模型生成的虚拟数据上做SAC式的演员-评论家更新，最大化价值；
  • 模型的损失由两部分组成：在真实数据上的最大似然（保证数据内的预测仍准确），加上一项让策略在模型生成的转移上价值尽可能低的对抗项：

L(T̂) = −λ·E_D[log T̂(s′|s, a)] + E_(s,a∼π, s′∼T̂)[V^π(s′)]

两者交替优化，近似求解这个二人零和博弈。直观上，在数据覆盖的地方模型受最大似然约束不能乱来；在数据没覆盖的地方，模型会预测对策略不利的结果，于是策略学会避开这些区域。论文给出了PAC性能保证，学到的价值是真实环境价值的下界。摘要称在常用离线RL基准上超过当时的最好基线。

局限与后续

  • 对抗训练两个网络交替优化，训练不稳定、对对抗权重λ和模型更新频率敏感。

它建立在什么之上

  • 延续
    RARL鲁棒对抗RL2017.03 · RL
    沿用RARL“训练一个让主角回报最低的对手”的鲁棒思路，只是对手换成了动力学模型本身。
  • 使用
    MBPO2019.06 · RL
    沿用MBPO用模型生成短虚拟轨迹训练SAC的框架。
  • 改进
    MOPO模型离线优化2020.05 · RL
    MOPO靠手工的集成不确定性惩罚；RAMBO用对抗模型自动产生悲观，不需要不确定性度量。
  • 竞争
    MOReL悲观模型离线RL2020.05 · RL
    MOReL用不确定性划出终止区域；RAMBO把模型训练成对手。
  • 竞争
    COMBO保守模型离线优化2021.02 · RL
    COMBO在模型数据上做CQL式保守正则；RAMBO在模型本身上施加对抗。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
