Qwen-Image

Qwen-Image Technical Report
2025.08论文延伸arXiv 2025Chenfei Wu, Jiahao Li, Jingren Zhou, Junyang Lin 等（39位作者） · 阿里巴巴Qwen待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文生图模型渲染复杂文字（尤其中文）很弱，编辑时也难以保持与原图一致。

方法

全面的数据管线与由易到难的文字渲染课程训练；编辑时让原图同时进入Qwen2.5-VL（语义）与VAE编码器（重建）。

影响

在复杂文字渲染（含中文）与精确图像编辑上取得显著进步。

方法

Qwen-Image是Qwen系列的图像生成基础模型。它的骨干是MMDiT（见Stable Diffusion 3），文本侧用多模态大模型Qwen2.5-VL编码（延续Qwen2-VL与开源VLM路线）。

文字渲染：摘要称作者设计了覆盖大规模收集、过滤、标注、合成与平衡的数据管线，并采用渐进式课程——从没有文字的图像开始，逐步到简单文字，再扩展到段落级描述，由此显著提升原生文字渲染能力，在英文及更困难的中文表意文字上都有进展。

编辑一致性：采用同时包含文生图、文本加图像到图像，以及图像到图像重建的多任务训练范式，使Qwen2.5-VL与MMDiT的潜表示对齐；并把原图分别送入Qwen2.5-VL与VAE编码器，一个管语义、一个管重建细节，以平衡语义一致与视觉保真。

后来的发展

Qwen-Image成为开源图像模型中文字渲染与编辑的重要基线，随后的Z-Image在报告中将其列为对比对象。
