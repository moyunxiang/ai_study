Cohere Command A

Command A: An Enterprise-Ready Large Language Model
2025.04论文延伸Team Cohere（Aakanksha, Arash Ahmadian, Marwan Ahmed, Jay Alammar, Milad Alizadeh, Yazeed Alnumay, Sophia Althammer, Arkady Arkhangorodsky et al.） · Cohere待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

企业应用需要的不是榜单上的最高分，而是可靠的检索增强（带引用的有据回答）、工具调用和多语言能力，同时部署成本要低；通用前沿模型在这些方面要么不够稳定，要么太贵、太大。

方法

专为企业场景打造一个开放权重（研究用途）模型：支持23种商业常用语言，采用兼顾效率与性能的混合注意力架构；后训练采用去中心化方式，分别训练擅长不同能力的专家模型，再用自我改进算法和模型合并把它们合成一个模型。

影响

Cohere在Command R/R+之后的旗舰模型，报告系统公开了“分领域训专家、再合并”的后训练流水线，并给出大量企业相关任务（RAG、工具使用、多语言、代码、安全）上的评测；同时发布了能力相近的小模型Command R7B。

背景

Cohere Command R/R+确立了Cohere面向企业RAG和工具使用的定位，Aya 23深度换广度、Aya Expanse多语言模型积累了多语言训练经验。另一方面，TIES-Merging模型合并等模型合并方法表明，把分别微调的模型在参数空间里合起来，可以兼得多种能力，避免一次性多任务训练时的相互干扰。

方法

架构：报告称采用一种新的混合架构，在效率与顶级性能之间取得平衡；按一般了解，它把滑动窗口注意力层与少量全局注意力层交错使用，以降低长上下文推理的显存和计算。

能力目标：针对智能体任务优化；支持23种全球商业语言；提供带有据引用（grounding）的检索增强生成和工具调用，用于自动化复杂业务流程。

去中心化后训练：不是用一个巨大的数据混合一次性训练所有能力，而是：

  • 从同一个基础检查点出发，分别训练若干专家模型，各自专攻如RAG、代码、多语言、安全、指令遵循等能力；
  • 对专家使用自我改进（self-refinement）算法，迭代地用模型自己生成并筛选数据来提升；
  • 用模型合并技术把各专家合成一个模型，再做整体的偏好优化与打磨。

这样各团队可以并行开发不同能力，合并后保持各项能力。

Command R7B：采用相似架构和训练流程的小模型，同样发布权重供研究使用。

结果

报告在一系列企业相关任务和公开基准上评测了Command A和Command R7B，称其性能与效率都很出色；具体分数见原文。

后来的发展

“分别训练能力专家再合并”的后训练方式为工业界后训练提供了一个公开的参照；Command A之后，Cohere继续推出面向推理、视觉和翻译的Command A变体。

本篇术语

  • 有据回答　回答时标明每一句话依据的是检索到的哪段文档，方便核对，减少编造。
  • 模型合并　把几个从同一模型出发、分别微调的模型在参数上加权组合，得到一个兼具各自能力的模型，不需要重新训练。

怎么学

先读Cohere Command R/R+和TIES-Merging模型合并；读报告中后训练的专家与合并部分；动手：把两个从同一基座微调的小模型（一个偏数学、一个偏代码）做线性合并，比较合并前后在两类任务上的分数。
