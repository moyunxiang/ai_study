VecMap无监督跨语言映射

A robust self-learning method for fully unsupervised cross-lingual mappings of word embeddings
2018.07论文延伸ACL 2018Mikel Artetxe, Gorka Labaka, Eneko Agirre · 巴斯克大学IXA组待核对
ACL Anthology ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

MUSE等用对抗训练做的无监督跨语言词向量映射，只在相近语言或可比的维基语料上有效；换成英语—芬兰语这类差异大的语言对，现有方法的词翻译准确率全都低于2%。

方法

不用对抗训练：先利用“同义词在两种语言里的相似度分布相近”这一结构相似性，构造一个完全无监督的初始词典，再用加了随机性和稳健技巧的自学习迭代，交替“求最优正交映射”和“用映射重新归纳词典”。

影响

在所有测试场景下都能成功，在标准数据集上取得当时最好结果、甚至超过有监督系统；开源工具VecMap成为跨语言词向量和无监督机器翻译研究最常用的基线之一。

背景

跨语言词向量线性映射（2013）发现两种语言的词向量空间形状相似，可用一个线性矩阵从一种映射到另一种，但需要几千对种子词典。Artetxe等人2017年证明自学习可以从低至25对的种子词典起步，但没有种子时会陷入差的局部最优。无平行语料的词翻译MUSE（2017）用生成对抗训练实现了完全无监督映射，但作者发现它在真实困难的语言对上经常失败。

方法

设X、Z分别是两种语言归一化后的词向量矩阵，目标是找正交矩阵 W_x, W_z 使翻译对在映射后靠得近。

无监督初始化：直接比较X和Z的向量不可能（坐标系任意），但每个词与本语言其他词的相似度分布 M_x = X Xᵀ 是坐标无关的。对每个词把其相似度向量排序（再做归一化），英语“狗”和西语“perro”的排序后相似度分布应当相近，据此在两种语言之间找最近邻，得到一个初始词典D。

稳健的自学习：反复执行两步——(1) 给定D，用奇异值分解求最优正交映射（Procrustes解）；(2) 用映射后的空间重新为每个词找最近邻，更新D。为避免陷入局部最优，加入几项技巧：随机丢弃部分词典项（随机性随迭代逐渐减小）、只在高频词上归纳词典、双向归纳、用CSLS式的相似度修正“枢纽词”问题。最后做白化、重加权和去白化等后处理。

结果

在包括英语—芬兰语在内的所有测试语言对上都能得到有意义的映射，在标准双语词典归纳数据集上取得已发表的最好结果，甚至超过以往的有监督系统；而其他无监督方法在英语—芬兰语上准确率均低于2%（原文摘要与引言）。

后来的发展

VecMap成为跨语言词向量的标准工具，并直接被同一团队用作无监督神经机器翻译和无监督统计机器翻译的起点：先用无监督映射得到词翻译表，再迭代回译。随后出现的跨语言预训练模型（如mBERT、XLM）把跨语言对齐从静态词向量转移到上下文表示上，但双语词典归纳仍常用VecMap作对照。

局限与后续

  • 依赖两种语言词向量空间“同构”的假设，对差异极大或语料规模、领域不一致的语言对仍可能失败。

读懂它需要的概念

嵌入向量 特征分解与奇异值分解 正交矩阵与正定矩阵 内积与余弦相似度 k近邻

本篇术语

  • 双语词典归纳　只给两种语言的单语数据，自动找出词与词之间的翻译对。
  • 正交Procrustes问题　求一个旋转（正交）矩阵，使两组成对向量映射后距离最小，有基于SVD的闭式解。
  • 枢纽词问题　高维空间中某些词是大量其他词的最近邻，导致检索结果被它们垄断。

怎么学

先读跨语言词向量线性映射和无平行语料的词翻译MUSE → 读本文第3节初始化与自学习 → 动手：下载两种语言的fastText词向量，用VecMap的无监督模式映射，再查几十个常用词的翻译准确率。
