NDF神经描述子场

Neural Descriptor Fields: SE(3)-Equivariant Object Representations for Manipulation
2021.12论文延伸ICRA 2022Anthony Simeonov, Yilun Du, Andrea Tagliasacchi, Joshua B. Tenenbaum, Alberto Rodriguez, Pulkit Agrawal, Vincent Sitzmann · MIT、Google Research待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

看一次“把杯子挂到架子上”的示范，换一个形状不同、摆放角度不同的杯子就做不好了：基于二维图像的描述子对物体旋转和视角很敏感，基于关键点的方法又要人工标注。

方法

学一个连续的三维描述子场：给物体点云和空间中任意一点（或一个夹爪位姿），输出一个类别级的描述向量，而且对物体的三维旋转平移等变。示范时记下夹爪位姿的描述子，新物体上通过优化找描述子最匹配的位姿。

影响

让抓取和摆放类任务只需5到10个示范就能泛化到同类新物体和任意六维位姿，带动了一批基于等变表示的少样本操作工作。

方法

做法分两步。表示：借鉴占据网络这类隐式三维表示，网络输入物体点云和一个三维查询点，输出一个特征向量；这个网络通过三维自编码任务自监督训练（从点云重建物体占据），不需要人工关键点。编码器使用等变结构，保证物体整体旋转平移时，描述子场跟着同样变换，因此对任意六维位姿都成立。把夹爪或挂钩周围的一组固定查询点拼起来，就得到一个“位姿描述子”。

使用：示范时记录目标位姿（比如夹爪抓住杯柄时）的位姿描述子；面对一个新杯子时，在它的描述子场里用梯度优化搜索一个位姿，使其描述子与示范的最接近，然后让机器人执行。

论文在仿真和真机上，用5到10个示范学会抓取并挂杯子、摆放碗和瓶子等任务，跨物体实例和六维位姿泛化，明显优于依赖二维描述子的基线。

局限与后续

  • 只处理单个刚体物体和类别级的对应关系，多物体之间的相对关系、柔性物体都不在范围内。

读懂它需要的概念

不变性与等变性 三维表示：体素、点云、网格、隐式场 自编码器 梯度下降 模仿学习与行为克隆

本篇术语

  • SE(3)等变　物体在三维空间中旋转、平移时，模型的输出按同样的方式变换；SE(3)是三维刚体运动的集合。
  • 类别级描述子　对同一类物体（不同形状的杯子）的对应部位（杯柄）给出相近的特征，用来在不同实例间找对应。

怎么学

先补等变性的概念和隐式三维表示（Occupancy Networks），再读NDF第3、4节；项目页有挂杯子的示范视频。
