SWE-RL

SWE-RL: Advancing LLM Reasoning via Reinforcement Learning on Open Software Evolution
2025.02论文延伸Yuxiang Wei, Olivier Duchenne, Jade Copet, Quentin Carbonneaux, Lingming Zhang, Daniel Fried, Gabriel Synnaeve, Rishabh Singh, Sida I. Wang · Meta FAIR / UIUC / CMU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DeepSeek-R1式强化学习主要用在竞赛数学和编程上，真实软件工程任务没有现成的、容易计算的奖励。

方法

用开源软件的演化记录（代码快照、提交、issue和PR）训练，奖励只用一个轻量规则：模型生成的补丁与真实补丁的相似度。

影响

把RL推理训练扩展到真实软件工程，并发现它还提升了编程之外的通用推理。

方法

SWE-RL利用GitHub上的软件演化数据：每条样本是一个issue、相关代码文件和最终合并的真实补丁。模型要读issue并输出补丁，奖励由规则计算——生成补丁与真实补丁的相似度分数（格式错误则给负奖励）。这样无需运行测试环境，就可以大规模训练，用GRPO风格的强化学习让模型自己学出推理过程。

基于Llama 3训练出的Llama3-SWE-RL-70B在SWE-bench Verified上解决41.0%，论文称这是当时中等规模（小于100B）模型的最好成绩，与GPT-4o等闭源模型相当。作者还观察到，仅在软件演化数据上做RL，模型在函数编写、库使用、代码推理、数学和通用语言理解五项分布外任务上也变好，而监督微调基线反而退化。

后来的发展

它展示了把RL用于代码仓库级任务的可能，后续Claude Code与终端编码智能体类智能体与SWE-bench Verified上的竞争，主要靠更强的基座与在真实执行环境中的RL。
