Hopfield网络

Neural Networks and Physical Systems with Emergent Collective Computational Abilities
1982论文重要PNAS 1982John J. Hopfield · 加州理工学院 / 贝尔实验室待核对
PNAS（DOI） ↗Wikipedia: Hopfield network ↗在交互版中打开（演化树、学习进度）

问题

感知机寒冬之后，神经网络既缺理论也缺用途；人脑能凭一点线索想起整段记忆，计算机却只能按地址查数据。

方法

用对称连接的全互联二值神经元组成网络，定义一个“能量”函数；存进去的记忆是能量的低谷，输入残缺的线索后网络自己滚到最近的低谷，就把完整记忆找回来。

影响

把统计物理的工具带进神经网络，让大批物理学家入场；能量的观点直接催生了玻尔兹曼机和能量模型，2024年Hopfield因此分享诺贝尔物理学奖。

背景

1969年《Perceptrons》与XOR问题之后，神经网络研究冷了十多年。当时的计算机存储是按地址寻址：要知道地址才能取出内容。人的记忆却是按内容寻址：听到半句歌词就能想起整首歌，看到一张模糊的脸也能认出是谁。

Hopfield是物理学家，他注意到磁性材料的模型（自旋玻璃）里，大量简单的小磁针相互作用，会自发落入少数几种稳定排列。他的问题是：一群简单的神经元，能不能靠集体行为“涌现”出这种联想记忆，而不需要任何中央控制？

方法

网络。N个二值神经元，每个取值s_i ∈ {−1, +1}（原文用0/1，等价），两两相连，连接是对称的w_ij = w_ji，自己不连自己w_ii = 0。

存储：一次性的Hebb规则（见Hebb学习律）。要存P个模式ξ¹…ξᴾ，直接令w_ij = (1/N) Σ_μ ξ_iᵘ ξ_jᵘ：两个神经元在某个模式里同号，连接就加强，异号就减弱。不需要迭代训练。

回忆：异步更新。每次随机挑一个神经元，按s_i ← sign(Σ_j w_ij s_j)更新，重复直到不再变化。

为什么一定会停下来。定义能量E = −½ Σ_ij w_ij s_i s_j（见能量模型与玻尔兹曼分布）。因为权重对称，每次异步更新都不会让E增加，而E有下界，所以网络必然停在某个局部极小点上。Hebb规则恰好让存进去的模式成为这些低谷——它们就是吸引子。

例子。用100个神经元存3张10×10的黑白字母图案。拿一张被翻转了一部分像素的“A”作为初始状态，网络一步步更新，最终落回完整的“A”：这就是纠错和联想。

结果

论文用模拟展示了这种网络能从部分内容恢复整段记忆，并表现出纠错、归类、识别“见过没见过”等性质；单个神经元失效或模型细节改变对整体行为影响很小。后来的理论分析给出容量约为0.138N：1000个神经元大约只能可靠存138个模式，再多就会互相干扰，回忆出错。

后来的发展

1984年Hopfield把它推广到连续取值的神经元。1985年玻尔兹曼机在同样的能量框架上加入随机性和隐藏单元，使网络能学习而不只是存储；这条线后来发展成基于能量的学习模型。它也是《并行分布式处理》所代表的联结主义复兴的直接推动力之一，并促成了NIPS（NeurIPS）首届会议这类跨物理、神经科学和计算机的会议。

2016年Krotov与Hopfield改写能量函数，让容量随神经元数超线性增长；后续工作指出连续版现代Hopfield网络的一步更新就是注意力机制的形式。2024年Hopfield与Hinton共同获得诺贝尔物理学奖（2024诺贝尔物理学奖与化学奖）。

容易误解的地方

  • Hopfield网络是记忆模型，不是分类器：它只能把输入拉回存过的模式，不会学出新的特征。
  • 它是循环网络，但不处理序列：它的目标是收敛到一个固定点，而不是随时间产生输出。
  • 能量下降的保证依赖对称权重和异步更新；同步更新所有神经元时可能在两个状态之间来回振荡。

局限与后续

  • 容量只有约0.14N个模式：1000个神经元只能存一百多个记忆，再多就互相干扰。

它建立在什么之上

  • 竞争
    感知机1958 · 基础
    感知机是前馈的、靠误差纠正训练的分类器；Hopfield网络是循环的、一次存储的联想记忆。后来主流走了前馈加反向传播的路线，能量的思想则在玻尔兹曼机和能量模型里延续。
  • 使用
    M-P神经元1943 · 基础
    每个神经元就是M-P式的二值阈值单元，新意在于它们全互联、对称连接后的集体动力学。
  • 使用
    Hebb学习律1949 · 基础
    权重直接由Hebb规则一次算出：同时激活的神经元之间连接加强。
  • 竞争
    自组织映射SOM1982 · 基础
    同年Kohonen的自组织映射也是无监督的神经模型，但它学习输入空间的拓扑排列，而不是存储离散记忆。

后来的相关工作

  • 改进
    反向传播1986 · 基础
    没有隐藏单元，只能原样存储给定的模式，无法学习数据中的抽象特征。
  • 改进
    LSTM1997 · 基础
    动力学只收敛到固定点，不能处理或生成随时间变化的序列。
  • 延续
    《并行分布式处理》1986 · 基础
    把Hopfield网络的能量与约束满足观点纳入统一框架，作为并行约束满足的典型例子。
  • 使用
    NIPS（NeurIPS）首届会议1987.11 · 事件
    Hopfield网络把大批物理学家带进神经网络研究，NIPS的发起方加州理工正是Hopfield所在地，首届论文集也由物理学出版社出版。
  • 竞争
    Elman循环网络1990 · 基础
    两者都有循环连接，但Hopfield网络的目标是收敛到固定的记忆，Elman网络的目标是随输入不断变化、记住刚发生过的事。
  • 使用
    梯度消失问题1994 · 基础
    借用了吸引子动力学的观点：稳健的记忆对应稳定吸引子，而稳定恰恰意味着收缩、意味着梯度衰减。
  • 使用
    2024诺贝尔物理学奖与化学奖2024.10 · 科学
    物理学奖表彰的第一项工作：基于自旋系统能量的联想记忆网络。
  • 延续
    玻尔兹曼机1985 · 基础
    在Hopfield能量网络上加隐藏单元和随机性，使其成为能学习内部表示的概率模型。
  • 使用
    神经形态电子学1990.10 · 硬件
    借用Hopfield等人提出的神经网络物理模型作为理论动机。
  • 延续
    基于能量的学习2006 · 基础
    Hopfield网络的能量函数是该框架中的早期例子。
  • 延续
    现代Hopfield网络2020.07 · 基础
    把1982年的二值Hopfield网络推广到连续状态，容量从线性提升到指数级。

读懂它需要的概念

神经元与激活函数 能量模型与玻尔兹曼分布 向量、矩阵与张量 内积与余弦相似度 循环网络与隐状态

本篇术语

  • 联想记忆 / 内容寻址存储　按内容而不是按地址取回信息：给出记忆的一部分或一个有噪声的版本，系统返回完整的记忆。
  • 吸引子　动力系统里的稳定状态。附近的状态随时间演化都会被“吸”过去，就像小球滚进碗底。
  • 伪状态　能量函数的局部极小点，但不是任何一个存进去的模式，网络可能错误地停在这里。

怎么学

先补能量模型与玻尔兹曼分布和神经元与激活函数。读原文前两页的模型定义与能量论证，再看Wikipedia条目的容量与伪状态部分。动手：用NumPy写一个100个神经元的Hopfield网络，存3到5个随机±1模式，给它翻转20%的位后看能否恢复；再逐渐增加模式数，观察大约到14个左右回忆开始崩溃。
