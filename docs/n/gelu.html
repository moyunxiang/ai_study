GELU

Gaussian Error Linear Units (GELUs)
2016.06论文重要arXiv预印本（2016）Dan Hendrycks, Kevin Gimpel · Toyota Technological Institute at Chicago (TTIC)待核对
arXiv ↗PyTorch文档 torch.nn.GELU ↗在交互版中打开（演化树、学习进度）

问题

ReLU在0处有个硬拐角，负半轴梯度恒为0；激活函数与dropout等随机正则化是两套互不相干的设计，各管各的。

方法

把“以概率Φ(x)保留输入、否则置零”的随机掩码取期望，得到确定性的激活GELU(x) = x·Φ(x)：输入越大越可能被原样放行，越小越接近被关掉，曲线处处光滑。

影响

被GPT、BERT、ViT等Transformer模型采用，成为2018–2022年大模型的默认激活；后来的SwiGLU也是在它这一族平滑门控激活上发展出来的。

背景

ReLU让深层网络好训了，但它是分段线性的：x>0时原样输出，否则输出0，在0处不可导，输入一旦长期为负，梯度就一直是0。ELU（指数线性单元）在负半轴改用平滑的指数曲线，好了一些。另一方面，Dropout以固定概率随机把神经元置零来防过拟合，Adaptive Dropout等工作让置零概率依赖输入。作者注意到：ReLU可以看成“按输入的符号决定乘1还是乘0”，dropout是“随机决定乘1还是乘0”——能不能把两者统一成一个按输入大小、带概率的乘法？

方法

设想一个随机正则化：给输入x乘上掩码m ~ Bernoulli(Φ(x))，其中Φ是标准正态分布的累积分布函数（见高斯分布），Φ(x) = P(X ≤ x)、X ~ N(0,1)。x越大，Φ(x)越接近1，越可能被保留；x越小越可能被置零。由于经过Batch Normalization的输入大致服从标准正态，Φ(x)可以理解为“这个输入比其他输入大的概率”。

推理时需要确定的输出，于是取这个随机变换的期望：

GELU(x) = Φ(x)·x + (1−Φ(x))·0 = x·Φ(x) = x·½[1 + erf(x/√2)]

具体数值：GELU(2) ≈ 2×0.977 = 1.95，GELU(−2) ≈ −2×0.023 = −0.05，GELU(−0.75) ≈ −0.17。它与ReLU的区别是：负输入不是一刀切成0，而是有一小段可以略微为负、梯度不为0的光滑区域；整条曲线不单调，在约x = −0.75处有极小值。

erf计算较慢，论文给出两个近似：0.5x(1 + tanh[√(2/π)(x + 0.044715x³)])，以及x·σ(1.702x)。论文还指出，把Φ换成logistic函数σ就得到x·σ(x)，命名为SiLU——它就是一年后Swish/SiLU搜索出来的函数。

结果

论文在MNIST分类和自编码、推特词性标注、TIMIT语音帧分类、CIFAR-10/100上与ReLU、ELU比较，GELU在所有任务上都最好，但优势多为零点几到一个百分点。CIFAR-10上9层卷积网络三次运行的中位错误率：GELU 7.89%，ReLU 8.16%，ELU 8.41%。CIFAR-100上40层、宽度因子4的宽残差网络：GELU 20.74%，ReLU 21.77%，ELU 22.98%。

后来的发展

论文在2016年并未引起太多注意，真正推广它的是Transformer：GPT-1、BERT、GPT-2的前馈层都用GELU，Vision Transformer也沿用，于是它成了这一代大模型的默认激活。2017年的Swish/SiLU通过自动搜索得到几乎同样的曲线，x·σ(x)（SiLU/Swish）后来在视觉模型里很常用。2020年的GLU变体与SwiGLU把这类平滑激活与门控线性单元结合，被LLaMA等新一代大模型采用，逐步取代了单纯的GELU前馈层。

局限与后续

  • 精确形式要计算erf，比ReLU慢；实际实现普遍用tanh近似，不同框架的近似版本并不完全一致。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 提升幅度不大（多在1个百分点以内），且只在小规模图像、语音、标注任务上验证，没说明在大模型上是否仍然更好。

它建立在什么之上

  • 使用
    Batch Normalization2015.02 · 基础
    用“经批归一化的输入近似标准正态”来解释为何选正态分布的Φ。
  • 改进
    ReLU2010 · 基础
    保留ReLU在正半轴近似线性的好处，把0处的硬拐角换成光滑过渡，负半轴梯度不再恒为0。
  • 延续
    Dropout2012.07 · 基础
    把dropout的随机置零改成依赖输入大小的置零概率Φ(x)，再取期望变成确定性激活。
  • 竞争
    He初始化与PReLU2015.02 · 基础
    He初始化论文提出可学习负斜率的PReLU，同样针对ReLU负半轴梯度为0的问题；GELU改用光滑的概率门控，后者在Transformer中胜出。

后来的相关工作

  • 改进
    BERT2018.10 · LLM
    提升幅度不大（多在1个百分点以内），且只在小规模图像、语音、标注任务上验证，没说明在大模型上是否仍然更好。
  • 使用
    GLU变体与SwiGLU2020.02 · 基础
    GEGLU变体用GELU作门；同时把单独的GELU激活作为对照基线。
  • 竞争
    Swish/SiLU2017.10 · 基础
    GELU是形状几乎相同的平滑激活函数，一个来自随机正则化的推导，一个来自自动搜索

读懂它需要的概念

神经元与激活函数 高斯分布 Dropout 期望与方差 归一化层

本篇术语

  • Φ(x)（标准正态累积分布函数）　标准正态随机变量取值不超过x的概率，Φ(0)=0.5，Φ(2)≈0.977，Φ(−2)≈0.023。
  • ELU　指数线性单元：x>0时输出x，x≤0时输出α(eˣ−1)，负半轴平滑地趋于−α。
  • SiLU　Sigmoid线性单元x·σ(x)，本文作为GELU的变体提出，2017年又以Swish之名被重新发现。

怎么学

先复习神经元与激活函数和高斯分布，用Python画出ReLU、ELU、GELU、x·σ(x)四条曲线及其导数。然后读原文第2节（一页，讲推导）和第4节讨论。动手：在一个小Transformer或CIFAR-10上只换激活函数，跑三个种子比较结果，体会这类改动的收益和噪声大小。
