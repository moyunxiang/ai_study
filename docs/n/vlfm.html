VLFM视觉语言前沿地图

VLFM: Vision-Language Frontier Maps for Zero-Shot Semantic Navigation
2023.12论文延伸ICRA 2024Naoki Yokoyama, Sehoon Ha, Dhruv Batra, Jiuguang Wang, Bernadette Bucher · 佐治亚理工学院、波士顿动力AI研究所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

零样本找物导航既要知道往哪里探索更可能找到目标，又要能直接部署到真实机器人上；学习式策略往往离不开仿真训练。

方法

用深度图建占据栅格地图找出“前沿”（已知与未知区域的边界），再用预训练视觉语言模型根据RGB图像算出与目标相关程度的价值地图，选价值最高的前沿去探索。

影响

在Gibson、HM3D、MP3D三个数据集的物体导航上按SPL达到最好结果，并能直接部署到波士顿动力Spot上，在真实办公楼里找物。

方法

经典的前沿探索在占据栅格地图上寻找已知自由空间与未知区域的交界，逐个去看，但不知道哪个前沿更可能通向目标。人找东西时会想“水槽多半在厨房那边”。VLFM把这种语义判断交给预训练的视觉语言模型：每一帧用它计算当前画面与“找一个某物体”这句话的相关度，把分数投影到地图上，累积成一张语言落地的价值地图；每次选价值最高的前沿作为下一个探索目标，用路径规划过去；一旦检测到目标物体就走过去停下。整个流程不需要在导航任务上训练。在Habitat具身仿真中Gibson、HM3D、MP3D的物体导航任务上，按SPL指标三个数据集都达到最好结果，还直接部署到了Spot移动操作机器人上。

局限与后续

  • 依赖准确的深度和定位来建图，并且只用单帧图文相关度，复杂的多步推理（“先找厨房再找水槽”）没有显式建模。
    本站还没有记录针对它的后续工作（不代表没有人解决）
