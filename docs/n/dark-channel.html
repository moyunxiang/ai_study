暗通道先验去雾

Single Image Haze Removal Using Dark Channel Prior
2009.06论文延伸CVPR 2009（最佳论文）Kaiming He, Jian Sun, Xiaoou Tang · 香港中文大学 / 微软亚洲研究院待核对
DOI ↗作者主页 ↗在交互版中打开（演化树、学习进度）

问题

雾霾图像的退化与每个像素的景深有关，单张图里深度未知，去雾是一个严重欠定的问题；此前的方法要么需要多张图或额外深度信息，要么依赖强假设、容易失真。

方法

统计发现：户外无雾图像的非天空区域里，几乎每个小块中总有某些像素在某个颜色通道上非常暗（接近0）。雾会把这些暗像素抬亮，于是“暗通道”有多亮就直接反映了雾有多浓。

影响

一个简单的统计先验让单图去雾第一次变得实用，获CVPR 2009最佳论文，成为去雾领域此后多年的标准基线。

方法

去雾通常用大气散射模型：I(x) = J(x)·t(x) + A·(1 − t(x))。I是看到的有雾图，J是要恢复的无雾图，A是大气光（雾的颜色，近似为常数），t(x) = e^(−β·d(x)) 是透射率，距离d越远t越小、雾越重。一张图里J、t、A全未知，必须加先验。

暗通道定义为：对每个像素，在以它为中心的小块（如15×15）内，取三个颜色通道的最小值，再在块内取最小值：J_dark(x) = min_{y∈Ω(x)} min_c J^c(y)。作者统计了大量户外无雾照片，发现非天空区域的J_dark几乎都接近0——原因是自然场景里到处是阴影、鲜艳颜色（只有一两个通道亮）和深色物体。

把这个先验代入散射模型，对两边取暗通道并令J_dark≈0，就直接得到透射率的估计：t(x) ≈ 1 − ω·min_{y∈Ω(x)} min_c (I^c(y)/A^c)，其中ω（如0.95）保留一点雾以保持远近感。大气光A取暗通道最亮的那部分像素对应的颜色。由于暗通道按块计算，t会有块状边缘，论文用软抠图（soft matting）对t细化，最后反解出 J = (I − A)/max(t, t₀) + A。副产品t还能换算出相对深度图。

后来的发展

暗通道先验被大量去雾、水下图像增强和低照度增强方法沿用；作者后来用引导滤波替代耗时的软抠图做细化。深度学习时代的去雾网络多以它为对照，并常把散射模型和暗通道作为网络结构或损失的一部分。

局限与后续

  • 先验在天空、白墙、雪地等大片明亮且接近大气光颜色的区域不成立，这些地方会被过度去雾、出现色偏。

读懂它需要的概念

图像作为张量 相机模型与多视图几何 随机变量与概率分布

本篇术语

  • 大气散射模型　描述雾如何形成图像的物理公式：看到的颜色是物体本身颜色按透射率衰减，再加上被散射进来的大气光。
  • 透射率　从物体到相机的光有多少没被雾散射掉，物体越远透射率越低。

怎么学

先理解大气散射模型中每一项的物理含义，再用几十行代码实现暗通道、透射率估计和反解（细化步骤可先用引导滤波代替）；拿几张雾天照片和白墙、天空较多的照片观察先验何时失效。
