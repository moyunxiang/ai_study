Open Images

The Open Images Dataset V4: Unified image classification, object detection, and visual relationship detection at scale
2018.11数据集延伸IJCV 2020 / arXiv 2018Kuznetsova, Rom, Alldrin, Uijlings, Krasin, Pont-Tuset, Kamali, Popov, Malloci, Duerig, Ferrari · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

目标检测数据集（如 COCO）的类别有限，边界框数量也不够大，而且类别常常是事先设计好的，带有选择偏差。

方法

从 Flickr 收集带知识共享许可的图片，而非按预设类名搜索，统一提供图像级标签、边界框和物体关系的标注。

影响

把检测的框数量放大一个量级，成为大规模检测与视觉关系检测的标准数据，nocaps 等后续基准直接以它的图片为基础。

方法

Open Images V4 含920万张图片，提供三类标注：3010万条图像级标签（覆盖1.98万个概念）、1540万个边界框（600个物体类别）、37.5万条视觉关系标注（57个类）。论文称其边界框数量是下一大数据集的15倍。

图片的采集没有预先给定类别名称或标签，得到的是自然的类别分布，避免了先设类别带来的偏差。平均每张图有8个被标注的物体，场景较复杂。相比 MS COCO，它更强调规模和开放的许可；它也被 nocaps 用来测试对未见物体的描述。

局限与后续

  • 标注是半自动加人工验证得到的，大规模下仍存在漏标，类别不均衡严重。
