Wengert列表与前向自动微分

A Simple Automatic Derivative Evaluation Program
1964.08论文延伸Communications of the ACM 1964R. E. Wengert待核对
ACM DOI ↗在交互版中打开（演化树、学习进度）

问题

想要函数的导数，要么手推公式再编程（易错），要么符号求导（表达式爆炸），要么数值差分（有截断误差）。

方法

把函数的计算过程拆成一串基本运算，按顺序记在一张列表里，算函数值的同时逐步算出每一项对输入的导数。

影响

给出了自动微分最早的可编程形式（前向模式），后来的反向模式和现代深度学习框架都是在这种「记录计算过程」的思路上发展的。

方法

核心做法：一个函数无论多复杂，在计算机里都是一串基本运算，比如 t1 = x·y、t2 = sin(t1)、f = t2 + x。这张按顺序记下来的列表后来被称为Wengert列表。对每一行，除了算出值，还顺便按链式法则（见链式法则）算出它对某个输入变量的导数，例如 t1′ = x′·y + x·y′。最后一行得到的就是 f 的精确导数，没有差分的舍入误差，也没有符号表达式膨胀。

代价是每对一个输入变量求导就要完整走一遍列表，输入有 n 个就要 n 遍。这正是它在神经网络里不实用的原因，参数动辄百万；后来反向模式自动微分把列表倒着走，一遍就得到全部偏导数。
