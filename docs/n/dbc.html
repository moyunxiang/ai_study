DBC互模拟表示

Learning Invariant Representations for Reinforcement Learning without Reconstruction
2020.06论文延伸ICLR 2021Amy Zhang, Rowan McAllister, Roberto Calandra, Yarin Gal, Sergey Levine · McGill University, Facebook AI Research, UC Berkeley, University of Oxford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

从图像学控制时，像素重构式的表示会把背景视频、云彩、光照这些与任务无关的细节也编码进去；画面背景一换，学到的策略就失效。

方法

用互模拟度量定义“两个状态在行为上有多像”：奖励相近且后续转移分布相近的状态就该被视为相似。训练编码器使隐空间里的距离等于互模拟距离，从而只保留与任务相关的信息，不需要重构像素。

影响

把互模拟这一经典的MDP状态抽象理论变成可扩展的深度表示学习目标，DBC成为“对任务无关干扰鲁棒的表示”方向的标准对照，后续一批基于互模拟或行为相似度的表示方法都从它出发。

背景

表示学习能加速像素RL，但常见做法有两类缺陷：像素重构（自编码器、世界模型）要求编码画面里的一切，包括与控制无关的背景；数据增强（RAD数据增强RL、图像增强DrQ）只带来对小扰动的不变性。理论上，MDP里有一个明确的“该保留什么”的答案：互模拟。两个状态如果当前奖励相同，并且转移到各个等价类的概率也相同，就可以合并为一个状态，最优价值不变。DeepMDP潜在空间模型已经用奖励和隐转移预测损失与互模拟建立了联系，但没有直接学互模拟距离。

方法

连续MDP中的互模拟度量满足不动点方程

d(s_i, s_j) = |r(s_i) − r(s_j)| + γ · W₂( P(·|s_i), P(·|s_j) )

W₂是两个转移分布之间的2-Wasserstein距离。DBC让编码器 φ 的隐空间L1距离逼近这个度量：从批次中随机配对两个样本 i、j，最小化

L(φ) = ( ‖z_i − z_j‖₁ − |r_i − r_j| − γ W₂( P̂(·|z̄_i, a_i), P̂(·|z̄_j, a_j) ) )²

其中 P̂ 是在隐空间里学的高斯动力学模型，高斯之间的W₂有闭式解；z̄ 表示停止梯度。动力学模型同时用最大似然训练。策略与价值函数用SAC在 φ 的输出上训练，编码器不接收任何像素重构损失。直观地说，背景视频不影响奖励和动力学，因此在互模拟意义下无关，编码器会学着忽略它。

结果

摘要称：在背景换成运动干扰物和自然视频的修改版视觉MuJoCo任务上，方法有效地忽略了任务无关信息，同时达到最先进性能；在第一人称高速公路驾驶任务上，学到了对云、天气和一天中时间的不变性；作者还根据互模拟度量的性质给出了泛化结果，并讨论了与因果推断的联系。

后来的发展

DBC之后，基于互模拟的表示学习出现了大量改进：用策略相关的互模拟（只针对当前策略）降低计算、用更稳定的距离替代W₂、与对比学习结合等；Distracting Control Suite这类加干扰的基准也常把DBC作为对照。

本篇术语

  • 互模拟（bisimulation）　两个状态在行为上不可区分：当前奖励相同，并且接下来转移到各类状态的概率也相同；它们可以被合并而不影响最优决策。
  • Wasserstein距离　把一个概率分布“搬运”成另一个所需的最小代价，可以比较两个分布有多不同。
