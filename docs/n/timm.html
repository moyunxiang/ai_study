timm视觉模型库

2019.02系统延伸Ross Wightman待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

各视觉模型论文的官方代码风格不一，权重格式不同，想在同一套脚本里对比ResNet、EfficientNet等要自己重写。

方法

timm（PyTorch Image Models）把大量视觉模型、预训练权重和统一的训练脚本集中到一个库里，接口一致。

影响

成为视觉模型复现与迁移学习的标准工具箱，ViT等新模型常第一时间被收录。

方法

仓库自述timm是「最大的PyTorch图像编码器/骨干网络合集」。它包含模型、层、优化器、学习率调度器、数据加载与增强，以及训练、验证、推理和导出脚本，并提供预训练权重。作者为Ross Wightman。

用法上，一句timm.create_model(name, pretrained=True)即可得到ResNet、EfficientNet等多种骨干，再接自己的任务头做迁移学习。统一的接口让不同模型可以公平对比，也让作者在新论文出来时迅速把复现版本加进去，其训练配方（如更强的数据增强和调度）也常使旧模型在timm里的精度高于原论文。

局限与后续

  • 复现版本可能与原论文细节不同，对比时要注意训练配方差异。

怎么学

用timm加载一个预训练模型，在小数据集上微调，并换一个骨干对比。
