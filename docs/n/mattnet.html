MAttNet

MAttNet: Modular Attention Network for Referring Expression Comprehension
2018.01论文延伸CVPR 2018Yu, Lin, Shen, Yang, Lu, Bansal, Berg · UNC / Adobe待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

指代表达理解把整句话当成一个整体，忽略了一句话同时包含外观、位置、关系三类线索。

方法

把句子拆成主体、位置、关系三个模块，各自用语言注意力选词、用视觉注意力看图，再由语言端动态加权合并三个模块的得分。

影响

在框级和像素级指代理解上大幅超越先前最好方法，是区域特征时代指代任务的代表作。

方法

MAttNet的输入是一个句子和一批候选区域（用Mask R-CNN得到框和掩码）。语言端先把句子分解成三段表示：主体（如「红色衬衫的男人」）、位置（如「左边」）、关系（如「在椅子旁边」），同时预测三个模块各自的权重。

三个模块各算一个得分：主体模块用视觉注意力聚焦物体的属性；位置模块用候选框的位置和同类物体的相对位置；关系模块则看候选与周围物体的关系。总得分是三者按权重相加。思路继承神经模块网络的模块化，但不需要预先解析成程序，权重由语言动态学出。摘要称在框级和像素级理解上都大幅超过之前的最好方法，并提供代码。
