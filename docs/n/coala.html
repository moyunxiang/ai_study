CoALA认知架构

Cognitive Architectures for Language Agents
2023.09论文延伸TMLR 2024Theodore R. Sumers, Shunyu Yao, Karthik Narasimhan, Thomas L. Griffiths · Princeton待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语言智能体（带记忆、工具、循环的LLM系统）一下子冒出几十种，各有各的术语，缺少统一框架来比较、归类和规划下一步。

方法

借鉴认知科学和符号AI中的“认知架构”，用记忆模块、结构化动作空间和决策过程三部分来描述任何语言智能体。

影响

给ReAct、Reflexion、Generative Agents、Voyager等提供了统一的分类语言，后来的智能体综述普遍沿用其记忆与动作的划分。

方法

CoALA（Cognitive Architectures for Language Agents）把智能体抽象成三块。记忆：工作记忆（当前上下文）加长期记忆，长期记忆又分情景（过去的经历）、语义（事实知识）和程序（技能或代码）。动作空间：内部动作（读写记忆、推理）与外部动作（调用工具、与环境交互）。决策过程：循环地先“规划”（提出并评估候选动作）再“执行”选定的动作。

论文用这套框架回头梳理已有工作：ReAct主要用推理这种内部动作，Reflexion写入情景记忆，Voyager的技能库是程序记忆，生成式智能体的记忆流是情景和语义记忆。作者也指出了未来方向，比如把学习（修改自身代码或记忆）纳入框架。这是一篇框架与综述，不含新的模型实验。

局限与后续

  • 框架是概念性的，没有定量标准判断一个智能体该怎样设计，也没有经验验证哪种记忆划分最有效。
