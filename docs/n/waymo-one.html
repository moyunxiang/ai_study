问题

自动驾驶长期停留在测试和演示阶段，没有哪家公司把它做成向公众收费的日常出行服务。

方法

2018年12月，Waymo在美国凤凰城地区推出面向公众的商业叫车服务Waymo One，用户用手机应用叫车、按里程付费。

影响

这是自动驾驶第一次以收费的叫车服务面向公众，把竞争从“谁的演示更好”转向“谁能运营并扩大服务区”。

方法

Waymo One由谷歌无人车项目启动项目演变而来的Waymo公司运营（该项目2009年启动，2016年12月更名并成为Alphabet子公司）。据CNBC、TechCrunch等2018年12月5日的报道，它在凤凰城地区上线，是一项商业的叫车服务。

早期乘客车内仍有安全员坐在驾驶座，系统能力的验证、服务区域的扩展和成本控制都在这个阶段慢慢积累；到2020年10月，Waymo才开放没有安全员的公众服务（见Waymo全无人驾驶开放运营）。

局限与后续

  • 早期车内仍需安全员，服务区域只限于提前绘制高精地图的小范围，无法低成本复制到新城市。
    后来针对它的工作　Waymo全无人驾驶开放运营 Waymo融资160亿美元
  • 运营成本和车辆成本未公开证明可盈利。
