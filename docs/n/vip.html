VIP价值隐式预训练

VIP: Towards Universal Visual Reward and Representation via Value-Implicit Pre-Training
2022.09论文延伸ICLR 2023（arXiv 2022-09）Ma, Sodhani, Jayaraman, Bastani, Kumar, Zhang · UPenn / Meta AI待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

在新任务上设计奖励很难，而机器人数据稀缺；人类视频很多，但此前的预训练主要只学到表示，无法直接给出可用的稠密奖励。

方法

把从人类视频里学表示看成离线目标条件强化学习，推出一个不需要动作标签的价值目标，让嵌入空间的距离当作奖励。

影响

得到一个能为没见过的机器人任务给出平滑稠密奖励的视觉表示，只需要目标图片就能指定任务。

方法

VIP（Value-Implicit Pre-training）把视频中的帧看作状态，把“离目标帧还有多远”看作目标条件下的价值函数，并推出一个对偶形式的自监督目标，这个目标只依赖图像、不需要动作标签，因此可以用Ego4D这样的无标注人类视频预训练。

理论上，作者将它理解为一种隐式的时间对比目标，使嵌入在时间上平滑；价值函数由嵌入之间的距离隐式定义。下游任务给一张目标图片，当前图片与目标图片的嵌入距离的变化就是稠密奖励，可直接用于强化学习或离线轨迹优化。它承接R3M机器人视觉表示的人类视频预训练思路，但强调同时得到表示和奖励。

局限与后续

  • 奖励只衡量与目标图片的接近程度，遇到需要先远离目标才能成功的任务就不适用。

怎么学

先读R3M机器人视觉表示，再看VIP的价值目标推导，并想想为什么目标条件价值可以不需要动作。
