RefinedWeb

The RefinedWeb Dataset for Falcon LLM: Outperforming Curated Corpora with Web Data, and Web Data Only
2023.06数据集延伸arXiv 2023Penedo, Malartic, Hesslow, Cojocaru, Cappelli, Alobeidli, Pannier 等 · TII（Falcon团队）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

业界普遍认为只用网页数据训不出好模型，必须掺入书籍、论文、代码等精选语料，如The Pile与开放预训练语料。

方法

只用Common Crawl与网络规模文本网页，通过严格的过滤和大规模去重，证明纯网页数据也能超过精选语料。

影响

证明了网页数据经过精心清洗即可训练强模型，直接引出FineWeb、Dolma开放语料等开放网页语料。

方法

当时的共识是网页质量差，所以The Pile与开放预训练语料等语料大量加入人工整理过的来源。Falcon团队反过来做：从Common Crawl出发，经过CCNet式的预处理，再加上更严格的启发式规则和模糊、精确两级大规模去重（见训练数据去重），得到RefinedWeb。

摘要给出的结论是：只用经过正确过滤和去重的网页数据，训出的模型明显优于在The Pile上训练的当时最先进模型。作者公开了其中约6000亿token的子集，Falcon模型用的是更大的完整版本。

这篇工作把关注点从「加什么数据源」转到「怎么清洗网页」，之后的开放语料大多沿用这个思路。

局限与后续

  • 过滤规则是启发式的，容易误删有价值的内容，质量判断不够精细。
    后来针对它的工作　FineWeb / FineWeb-Edu DCLM
  • 只发布了完整数据的一部分，完整版本无法复现。
    后来针对它的工作　Dolma开放语料

    CCNet2019.11 · 数据·评测
    使用类似CCNet的语言识别与质量过滤流程作为预处理起点。
  • 竞争
    The Pile与开放预训练语料2020.12 · 数据·评测
    主张纯网页数据可超过The Pile这类精选多源语料。
  • 改进

    黑名单式过滤的偏见问题被指出，但如何兼顾去除有害内容与保留多样性仍未有定论。
  • 使用
    训练数据去重2021.07 · LLM
    核心做法之一是大规模的模糊与精确去重。
