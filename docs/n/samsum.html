SAMSum对话摘要

SAMSum Corpus: A Human-annotated Dialogue Dataset for Abstractive Summarization
2019.11数据集延伸EMNLP 2019 Workshop on New Frontiers in SummarizationBogdan Gliwa, Iwona Mochol, Maciej Biesek, Aleksander Wawer · 三星波兰研发中心待核对
arXiv ↗Hugging Face数据集 ↗在交互版中打开（演化树、学习进度）

问题

自动摘要的数据几乎都是新闻，聊天对话里多人轮流说话、口语化、信息分散，没有高质量的人工摘要语料可以训练和评测。

方法

请语言学背景的人写出模仿即时通讯的闲聊对话，再为每段对话人工写一句到几句的抽象式摘要，做成专门的对话摘要语料。

影响

成为对话摘要最常用的基准之一，BART、PEGASUS一类摘要模型和后来的指令微调数据集合都常拿它做对话摘要任务。

方法

数据是什么。SAMSum里每条样本是一段类似手机聊天软件里的多人对话（几轮到几十轮，常带表情和口语缩写），配一段第三人称的摘要，如“小明约小红周五看电影，小红答应了”。对话由熟悉英语的标注者按日常话题编写，再由另一批人写摘要，所以对话里没有真实用户的隐私信息。

为什么难。新闻摘要往往能靠抽取开头几句拿高分，对话里关键信息散在不同说话人的多轮发言里，还要把“我”“你”换成具体人名，必须真正改写。论文用多个抽取式和生成式模型测试，并与在新闻语料上的结果对比。

一个反直觉的发现。摘要称，模型在对话上生成的摘要ROUGE分数反而高于在新闻上的，但人类评审的判断恰好相反。作者据此认为对话摘要需要专门的模型，也需要不同于ROUGE的质量度量。

后来的发展

SAMSum被纳入许多指令微调和评测集合，也常和会议摘要数据集一起用来检验长对话理解。

局限与后续

  • 对话是人写的模拟聊天，比真实聊天记录更干净、更短，在它上面训练的模型迁移到真实客服或群聊记录时效果会下降。
