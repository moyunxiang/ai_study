Claude Sonnet 4.5

Introducing Claude Sonnet 4.5
2025.09模型延伸2025-09-29 发布Anthropic待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

智能体要连续数小时处理多步任务并操作电脑，前代模型容易中途失去焦点，计算机操作成绩也有限。

方法

Sonnet 4.5针对代码、智能体和计算机使用做了强化，并配套检查点、上下文编辑和记忆工具，以及Claude Agent SDK。

影响

官方称在SWE-bench Verified上达到最优，并把计算机使用基准OSWorld从42.2%提到61.4%。

方法

Anthropic在2025年9月29日发布Claude Sonnet 4.5，官方称是世界上最好的编码模型、构建复杂智能体最强的模型和使用电脑最好的模型。

公告给出的数字：在SWE-bench Verified上是当时最优；在测试真实电脑任务的OSWorld上得分61.4%，四个月前的Sonnet 4是42.2%；官方观察到它能在复杂多步任务上保持专注超过30小时。价格与Sonnet 4相同，每百万token 3/15美元。

发布同时推出了一批产品：Claude Code与终端编码智能体加入检查点和原生VS Code扩展，API新增上下文编辑与记忆工具，并把Claude Code背后的基础设施以Claude Agent SDK的名义开放。Anthropic称这是其发布过的对齐程度最好的前沿模型。以上均为厂商自述。

局限与后续

  • 长任务可靠性依赖外部脚手架（检查点、记忆工具），模型自身的长程规划仍有限。

  • 计算机使用成绩61.4%说明仍有近四成任务失败。
    后来针对它的工作　Claude Opus 4.6
