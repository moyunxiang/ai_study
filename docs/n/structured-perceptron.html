结构化感知机

Discriminative Training Methods for Hidden Markov Models: Theory and Experiments with Perceptron Algorithms
2002.07论文重要EMNLP 2002（最佳论文）Michael Collins · AT&T Labs-Research待核对
ACL Anthology ↗PDF ↗在交互版中打开（演化树、学习进度）

问题

词性标注等序列任务要么用HMM按计数估概率、难加重叠特征，要么用最大熵/CRF，训练要反复算归一化项，又慢又麻烦。

方法

把整句标签序列当作一个“大类别”，用Viterbi解码出当前最好的答案，错了就把正确序列的特征加到权重上、把预测序列的特征减掉，再对历次权重取平均。

影响

给出了带收敛保证、实现只要几十行的结构化学习算法，成为2000年代句法分析、分词、语义解析等任务的标准训练方法之一。

背景

2002年的序列标注有两条路。一条是HMM词性标注式的HMM：标签转移和“标签生成词”的概率直接数出来，训练简单，但它是生成模型，想加“首字母大写”“后缀是-ing”这类彼此重叠的特征就很别扭。另一条是最大熵模型、最大熵马尔可夫模型MEMM和条件随机场这类判别式对数线性模型：特征随便加，但训练要做数值优化，CRF每一步都要用前向-后向算法对所有可能的标签序列求和，计算量大，还得调正则化。

Collins的问题是：能不能保留HMM的解码方式和对数线性模型的特征，但训练时既不估概率也不求和？

方法

设输入句子x，候选标签序列y，特征函数Φ(x, y)把整句的特征计数拼成一个向量（例如“前一个标签是DT、当前标签是NN”出现了几次）。模型给每个候选打分score(x, y) = w · Φ(x, y)，预测用Viterbi算法动态规划求ŷ = argmax_y w · Φ(x, y)。

训练就是把感知机的规则搬到序列上：逐句解码，如果ŷ不等于正确答案y，就更新

w ← w + Φ(x, y) − Φ(x, ŷ)

直观上，正确序列里的特征权重被调高，错误预测里的被调低；预测对了什么都不做。整个算法只需要一个能求argmax的解码器，不需要概率、梯度或归一化。

两个关键细节。其一，平均参数：把每处理一句后的权重都累加起来再除以总步数，作为最终参数，这是投票感知机的廉价近似，能显著减少过拟合和结果抖动。其二，理论：论文证明，若训练数据能以间隔δ被某个权重向量分开，更新次数不超过R²/δ²（R是特征差向量的最大范数），与可能的标签序列数目（随句长指数增长）无关；不可分时也有相应的错误界和泛化界。

结果

在Penn Treebank华尔街日报语料上做词性标注，使用与Ratnaparkhi最大熵标注器相同的特征，测试集错误率2.89%，最大熵模型是3.28%（相对降低11.9%）；基本名词短语识别F值93.63%，最大熵是93.29%（相对降低5.1%）。在开发集上，平均参数把标注错误率从3.68%降到2.93%，而且最佳结果只需约10轮迭代。

后来的发展

这套“解码器 + 特征 + 加减更新”的模板随后被套到几乎所有结构化预测问题上：依存分析（MSTParser与MIRA用其大间隔变体MIRA）、CCG语义解析（语义解析（CCG））、中文分词与词性联合标注、转移式句法分析加束搜索等。它也让“平均感知机”成为NLP工具包里的默认基线。2010年代神经网络接管后，手工特征被学到的表示取代（从零开始的神经NLP、BiLSTM-CRF序列标注），但“打分函数 + 结构化解码”的框架保留了下来。

局限与后续

  • 特征仍要人工设计成模板（前后词、后缀、标签二元组等），模型本身不学表示，换任务就要重新做特征工程。
    后来针对它的工作　从零开始的神经NLP BiLSTM-CRF序列标注
  • 只输出一个最优序列，没有校准的概率，不便与其他模型的概率组合或给出置信度。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只在预测错时做固定步长的更新，不显式最大化间隔，噪声数据上效果依赖平均和迭代轮数。
    后来针对它的工作　MSTParser与MIRA

    感知机1958 · 基础

  • 改进
    HMM词性标注1988 · NLP
    保留HMM标注器的Viterbi解码结构，但换成判别式训练，可以自由加入重叠特征。
  • 使用
    Penn Treebank1993 · 数据·评测
    词性标注实验使用Penn Treebank华尔街日报部分的标准切分。
  • 竞争
    最大熵模型1996 · NLP
    同样的特征下，用加减更新代替最大熵的数值优化，标注和组块任务上误差更低、训练更简单。
  • 改进
    Collins词汇化句法分析器1997.07 · NLP
    条件和独立性假设、回退层级都是手工设计的，想加入新的信息（如更远的上下文）就得重新设计整个生成过程。
  • 竞争
    条件随机场2001 · NLP
    CRF对全局序列做概率归一化，需要前向-后向求和；感知机只需要argmax，后来两者在实践中长期并存。
  • 使用
    Viterbi算法1967.04 · 语音
    训练和预测的每一步都用Viterbi动态规划求当前权重下的最优标签序列。
  • 竞争
    最大熵马尔可夫模型MEMM2000 · NLP
    MEMM逐位置归一化，有标签偏置问题；感知机对整句打分，与CRF一样避开了这个问题。

读懂它需要的概念

隐马尔可夫模型 动态规划 判别模型与生成模型 特征与表示学习 逻辑回归

本篇术语

  • 结构化预测　输出不是一个类别，而是一整串或一整棵有内部结构的东西（标签序列、句法树），候选数量随长度指数增长，必须靠动态规划等算法搜索。
  • 平均感知机　把训练过程中每一步的权重向量求平均作为最终模型，相当于很多个感知机投票，比只用最后一步的权重稳定得多。
  • 特征函数Φ(x, y)　把输入和一个候选输出映射成特征计数向量，例如统计整句中“标签NN后接VBZ”出现的次数。

怎么学

先会隐马尔可夫模型和动态规划（Viterbi），并理解普通感知机。读原文第2节的算法框和第4节实验即可，证明部分可以跳过。动手：在一个小词性标注语料上实现Viterbi + 平均感知机，对比用与不用平均的开发集准确率。
