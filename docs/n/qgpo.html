QGPO对比能量引导扩散

Contrastive Energy Prediction for Exact Energy-Guided Diffusion Sampling in Offline Reinforcement Learning
2023.04论文延伸ICML 2023Cheng Lu, Huayu Chen, Jianfei Chen, Hang Su, Chongxuan Li, Jun Zhu · 清华大学 / 人民大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

想从 μ(a|s)·exp(βQ(s, a)) 这样“行为分布乘以能量”的目标分布采样时，扩散模型需要每个噪声步上的中间引导，而这个中间引导由采样分布和能量共同决定，此前的方法只能近似，估不准。

方法

推导出中间引导的精确形式，并提出“对比能量预测”（CEP）目标来学习它；用学到的引导直接在扩散采样中把行为模型推向高Q值区域，在离线RL里称为Q引导策略优化（QGPO）。

影响

给“能量引导的扩散采样”提供了一个可证明收敛到精确引导的训练方法，是扩散策略离线RL的代表方法之一，常与SfBC、IDQL、Diffusion-QL并列比较。

方法

离线RL里常见的目标策略是 π(a|s) ∝ μ(a|s)·exp(β·Q(s, a))。若μ由扩散模型学得，要从π采样，按分数模型的理论，在每个噪声水平t上需要的分数是：

∇_(a_t) log π_t(a_t|s) = ∇_(a_t) log μ_t(a_t|s) + ∇_(a_t) E_t(s, a_t)

第一项是行为扩散模型给的，第二项是中间能量引导。论文证明这个中间能量的精确形式是 E_t(s, a_t) = log E_(μ_(0|t)(a_0|a_t, s))[exp(β·Q(s, a_0))]，即对“从a_t去噪后可能落到的干净动作”求能量的指数期望。它并不等于直接把Q用在带噪动作上（以往近似做法），所以以往方法得到的引导有偏。

对比能量预测（CEP）：对每个状态从行为分布采K个干净动作，加噪到t，训练一个网络 f_φ(s, a_t, t)，用类似对比学习的softmax交叉熵目标，让它对各候选的预测与 softmax(β·Q(s, a_0^i)) 对齐。作者证明在模型容量和数据无限时，这个目标收敛到精确的中间引导。

采样时把 ∇f_φ 加到行为扩散模型的分数上即可，类似分类器引导。摘要称在D4RL上超过已有最好算法，并给出了把CEP用于图像生成的例子说明其可扩展性。

局限与后续

  • 需要先训练行为扩散模型和Q函数，再训练引导网络，三阶段流程繁琐，采样时仍需多步去噪。

读懂它需要的概念

离线强化学习 分数函数与分数匹配 条件生成与引导 能量模型与玻尔兹曼分布

本篇术语

  • 能量引导采样　在扩散模型的每个去噪步上加上一个能量函数的梯度，使样本偏向能量高（这里是Q值高）的区域。
  • 对比能量预测（CEP）　用多候选softmax对比目标学习中间能量引导的训练方法。

怎么学

先读SfBC扩散行为候选选择和分类器引导；读QGPO原文第3节精确引导的推导；在二维多峰玩具分布上比较近似引导与CEP引导的采样结果。
