Match-LSTM与答案指针

Machine Comprehension Using Match-LSTM and Answer Pointer
2016.08论文延伸ICLR 2017Wang, Jiang · 新加坡管理大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

SQuAD的答案是原文中任意长度的片段，不是候选列表里选一个，早期阅读理解模型不适用。

方法

用Match-LSTM逐词比对问题与段落，再用指针网络式的答案指针直接预测答案在段落中的起止位置。

影响

是SQuAD上第一批端到端神经方案之一，奠定了「编码、匹配、指向起止」的基本管线。

方法

Match-LSTM原本为文本蕴含设计：读段落的每个词时，对问题所有词做注意力，把词与它的加权问题表示拼接后送入LSTM，捕捉段落词与问题的匹配程度。论文在其上接两种答案指针：序列式一步步生成答案词的位置，或边界式只预测答案起点和终点两个位置。边界式更简单，在SQuAD上效果更好。

摘要称该架构基于Match-LSTM和Pointer Net，在SQuAD上端到端训练。

局限与后续

  • 匹配是单向的（段落看问题），问题与段落之间的信息交互不够充分。
    后来针对它的工作　BiDAF双向注意力流
  • 只能抽取原文片段，不能回答需要推理或改写的问题。
