重新审视剪枝的价值

Rethinking the Value of Network Pruning
2018.10论文延伸ICLR 2019Zhuang Liu, Mingjie Sun, Tinghui Zhou, Gao Huang, Trevor Darrell · 加州大学伯克利分校, 清华大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

剪枝的标准流程是“训练大模型→按准则剪掉不重要的权重→微调保留下来的重要权重”，大家默认继承来的权重是剪枝有效的关键，但很少有人认真检验这一点。

方法

把剪出来的小结构用随机初始化从头训练，并给足训练轮数，与“剪枝+微调”公平比较。

影响

一个重要的负结果：对结构化剪枝，从头训练常常不比微调差，说明真正有价值的是剪出的结构而非继承的权重，促使后续剪枝论文补上更严格的基线。

方法

从最优脑损伤OBD剪枝到剪枝与量化压缩，剪枝方法都隐含两个信念：先训一个过参数化的大模型是必要的；大模型里被判定“重要”的权重对小模型有用。

作者检验了当时多种最先进的结构化剪枝方法（剪通道、剪滤波器，包括Network Slimming通道剪枝），在多个架构、数据集和任务上做对照：剪完后不继承任何权重，按剪出的结构随机初始化，训练与原模型相当甚至更多的轮数。结论是：从头训练的结果与“剪枝+微调”相当或更好；对那些事先规定好目标结构的剪枝方法，整个三阶段流程都可以省掉，直接训练目标网络。作者据此提出，剪枝在某些情况下更像一种架构搜索：价值在于找出每层该留多少通道。

论文还与彩票假说对比：在使用合适的学习率时，彩票假说所说的“中奖初始化”并不比随机初始化更好，这与彩票假说的结论存在争议。
