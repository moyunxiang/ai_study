MTEB嵌入基准

MTEB: Massive Text Embedding Benchmark
2022.10数据集重要EACL 2023Niklas Muennighoff, Nouamane Tazi, Loïc Magne, Nils Reimers · Hugging Face / Cohere待核对
arXiv ↗MTEB排行榜（Hugging Face） ↗代码（GitHub） ↗在交互版中打开（演化树、学习进度）

问题

文本嵌入模型各自只在语义相似度（STS）或单一检索集上报成绩，STS上最好的模型拿去做聚类、检索未必好，使用者没法挑。

方法

把8类嵌入任务、58个数据集、112种语言统一到一个开源评测框架和公开排行榜里，几行代码就能测任意嵌入模型。

影响

成为文本嵌入的事实标准榜单，E5、BGE、OpenAI嵌入和后来基于大模型的嵌入都以MTEB平均分排名，也直接影响RAG系统怎么选检索模型。

背景

嵌入向量把一段文本变成一个向量，向量越近表示语义越接近。从GloVe的词向量到Sentence-BERT、SimCSE对比句向量的句向量，再到Contriever无监督检索、OpenAI文本嵌入，嵌入被用于检索、聚类、分类、去重等很多场景。

但评测很零散。SimCSE、SBERT主要在STS（给两句话打相似度分）和分类上报成绩；检索模型则看BEIR零样本检索。SentEval汇总了多个STS集，却需要在嵌入上再训分类器，也没有检索和聚类。结果是：同一个模型在不同任务上的排名可能完全不同，却没人系统地测过。

方法

MTEB像GLUE / SuperGLUE那样把现成数据集打包，但只测“直接用嵌入向量”的能力，不微调模型。8类任务及其用法：

  • 双语挖掘：两组不同语言的句子，按内积与余弦相似度余弦相似度找出互为翻译的对，算F1。
  • 分类：用嵌入做特征训一个逻辑回归，看准确率。
  • 聚类：对嵌入做小批量k-means，用V-measure评估。
  • 句对分类：按相似度阈值判断两句是否同义或重复。
  • 重排序：给查询和若干候选，按相似度排序，算MAP。
  • 检索：在大语料中找相关文档，用nDCG@10，直接收录了BEIR的数据集。
  • STS：模型相似度与人工打分的Spearman相关。
  • 摘要：机器摘要与参考摘要的嵌入相似度和人工评分的相关性。

部分数据集还分句子对句子、段落对段落等粒度。框架接收任何能把文本变成向量的模型，新增数据集只需一个配置文件，结果自动上传到Hugging Face上的排行榜。

结果

论文评测了33个模型，从GloVe到58亿参数的SGPT。结论是没有一种模型在所有任务上都最好：ST5系列主导分类，ST5-XXL平均分最高；GTR-XL、GTR-XXL在句对分类上最强；SimCSE在STS上很强，聚类和检索却很差；多语言双语挖掘则是LaBSE领先。模型越大成绩通常越好，但速度和嵌入大小也随之增加，论文在单张A100上测了每个模型的吞吐。

后来的发展

MTEB排行榜很快成为发布嵌入模型的必经之路。E5文本嵌入、BGE嵌入模型等用大规模对比预训练登顶，BGE还配套推出了中文版C-MTEB；此后基于7B级大语言模型改造的嵌入模型又刷新了榜单。排行榜的热度也带来副作用：一些模型直接在MTEB数据集的训练部分上训练，平均分与真实场景表现脱节，社区随后扩展到更多语言和领域的大规模多语种版本。

容易误解的地方

  • MTEB平均分是不同任务、不同指标的简单平均，平均分高不代表在你的检索场景里最好，应看对应任务的子分。
  • 排行榜上很多模型的训练数据与MTEB数据集有重叠，分数可能偏高。

局限与后续

  • 以英语为主，多数中文、低资源语言只出现在少数双语挖掘和分类集里。

它建立在什么之上

  • 使用
    GloVe2014.10 · NLP
    GloVe和Komninos词向量平均作为无上下文的最弱基线，速度最快。
  • 延续
    GLUE / SuperGLUE2018.04 · 数据·评测
    沿用GLUE“多个现成数据集加一个总分加公开榜”的形式，对象从微调模型换成冻结的嵌入向量。
  • 改进
    Sentence-BERT2019.08 · NLP
    SBERT与SentEval式评测只覆盖STS和分类，MTEB补上检索、聚类、重排序等直接用向量的任务。
  • 使用
    BEIR零样本检索2021.04 · 数据·评测
    检索任务直接收录了BEIR的多个零样本检索数据集。
  • 改进
    SimCSE对比句向量2021.04 · NLP
    SimCSE只在STS上报告成绩，MTEB显示它的聚类和检索表现很差，揭示了单任务评测的盲区。
  • 使用
    OpenAI文本嵌入2022.01 · 推理·智能体
    把OpenAI的API嵌入和开源模型放在同一张榜上比较。

读懂它需要的概念

嵌入向量 内积与余弦相似度 检索与向量数据库 聚类 对比学习 基准、排行榜与SOTA

本篇术语

  • STS　语义文本相似度：人工给句对打0–5分的相似度，看模型的余弦相似度与人工分数排序是否一致。
  • nDCG@10　检索质量指标：看前10个结果里相关文档排得多靠前，越相关、越靠前得分越高，满分1。
  • V-measure　聚类质量指标，同时衡量每个簇是否只含一类（同质性）和每类是否都被分到同一簇（完整性）。

怎么学

先懂嵌入向量、内积与余弦相似度和检索与向量数据库。读原文第3.2节（8类任务的具体评法）和第4节结果。动手：pip安装mteb，用sentence-transformers里的all-MiniLM-L6-v2跑一个STS任务和一个检索任务，再换一个更大的模型对比分数和速度。
