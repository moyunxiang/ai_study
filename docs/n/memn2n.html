端到端记忆网络

End-To-End Memory Networks
2015.03论文延伸NeurIPS 2015Sainbayar Sukhbaatar, Arthur Szlam, Jason Weston, Rob Fergus · NYU / Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

原版记忆网络的读取是硬选择，需要标注每步的支持事实，没法只靠最终答案端到端训练。

方法

用软注意力读取外部记忆，并重复读取多轮（多跳），整个模型可微，只需问答对就能训练。

影响

证明多跳读写外部记忆可以端到端学出来，其“多跳注意力”思想影响了后来的阅读理解模型。

方法

把每句话用两套嵌入分别变成记忆向量m_i（用来匹配）和输出向量c_i（用来取值）。问题嵌入成u后，用p_i = softmax(uᵀ·m_i)算出对每条记忆的注意力，再取o = Σ p_i · c_i，并令u' = u + o。这一步叫一跳，堆叠多跳就能先找一条事实、再据此找下一条。

因为读取是softmax加权而非硬选，所有参数都能通过反向传播从最终答案的损失学到，不再需要支持事实标注。论文称它可以看作注意力机制在“每个输出符号做多步计算”情形下的扩展。

在合成问答任务上，它与带更强监督的记忆网络相比有竞争力；在Penn TreeBank和Text8的语言建模上，与RNN和LSTM相当；实验显示多跳是关键。

局限与后续

  • 记忆按句子独立编码、位置信息处理粗糙，只在合成问答和小规模语言建模上验证，真实阅读理解上还差得远。

  • 每次读取要对全部记忆做注意力，记忆很大时计算量线性增长。
