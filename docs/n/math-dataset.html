MATH竞赛数学

Measuring Mathematical Problem Solving With the MATH Dataset
2021.03数据集重要NeurIPS 2021 Datasets and BenchmarksDan Hendrycks, Collin Burns, Saurav Kadavath, Akul Arora, Steven Basart, Eric Tang, Dawn Song, Jacob Steinhardt · 加州大学伯克利分校 / 芝加哥大学待核对
arXiv ↗数据与代码（GitHub） ↗在交互版中打开（演化树、学习进度）

问题

已有的数学数据集多是套公式就能算的练习题；大模型在MMLU上的数学科目接近随机，但没有一个难度足够、能自动判分的数学推理基准。

方法

收集AMC、AIME等竞赛的12,500道题，每题附完整的分步解答，最终答案写在\boxed{}里，标准化后用精确匹配自动判分。

影响

发布时最好的模型只有6.9%；它成为此后衡量“推理能力”的核心基准，三年间过程监督、强化学习推理模型把成绩推到接近饱和。

背景

2021年初，GPT-3式的大模型在多数文本任务上随规模稳定进步，但数学是明显的例外。同一团队的MMLU显示，GPT-3在需要计算的STEM科目上接近随机。此前的数学数据集，如DeepMind的合成题库，大多是“解这个方程”一类的机械练习，可以用模板生成，不太需要解题策略。

真正的数学解题需要波利亚所说的“启发法”：画图、找规律、分情况、换元。需要一套题目足够难、覆盖多种策略、又能可靠地自动判分的考卷。

方法

题目。来自AMC 10、AMC 12、AIME等美国中学数学竞赛，共12,500道（训练7,500、测试5,000），分七个学科：初等代数、代数、数论、计数与概率、几何、中级代数、微积分预备，每题标1–5级难度。几何图形用Asymptote绘图语言以文本表示，模型不需要看图。

分步解答与判分。每道题都附人写的完整解答，最终答案用LaTeX的\boxed{}包起来。作者规定答案格式（如概率写成最简分数），评测时只解析模型输出里\boxed{}中的内容，与标准答案在归一化后做精确匹配。这样不用BLEU一类近似指标，对错一目了然。

AMPS预训练语料。为了帮模型补基础，另外构建了23GB的辅助数据：10万多道带分步解答的可汗学院习题，以及用100个手写Mathematica脚本生成的约500万道题，覆盖圆锥曲线、特征值、丢番图方程等。

结果

GPT-2和GPT-3各尺寸的平均准确率只有3.0%到6.9%，最好的是在AMPS上预训练再微调的1.5B GPT-2（6.9%）；175B的GPT-3少样本反而只有5.2%。AMPS预训练让0.1B的小模型达到比它大130倍的微调模型的水平。让模型先写分步解答再给答案，在当时反而降低了准确率（1.5B GPT-2降到5.3%）。

人类测试：一位不太喜欢数学的计算机博士生约40%，一位三次IMO金牌得主90%。作者据此推测，若照当时的规模趋势，靠堆参数要很久才能做到40%。

后来的发展

这个悲观预测很快被推翻，但推翻它的主要不是规模本身。思维链CoT和自洽性采样让模型把推导写出来并投票；过程监督与过程奖励模型用人工标注的逐步正确性训练过程奖励模型，在MATH测试集的代表性子集上解出78%，这个子集后来成为常用的MATH-500；GRPO用强化学习训练的7B DeepSeekMath单次作答达到51.7%。2024年9月OpenAI发布OpenAI o1推理模型时称，前沿模型在MATH和GSM8K上已好到无法区分彼此，o1单次作答达到94.8%（GPT-4o为60.3%）。此后连同DeepSeek-R1在内的推理模型把MATH推向饱和，竞赛级评测转向AIME真题、MathArena竞赛数学和FrontierMath。

容易误解的地方

  • “MATH”在不同论文中可能指完整的5,000道测试集，也可能指MATH-500子集，数字不可直接比较。
  • 精确匹配依赖答案归一化脚本，不同实现对等价形式（如0.5和1/2）的处理不同，会让分数差几个点。

局限与后续

  • 题目来自公开竞赛题库和讨论网站，后来的大模型很可能在预训练中见过题目和解答，分数难以排除污染。

它建立在什么之上

  • 使用
    GPT-22019.02 · LLM
    最好的结果来自在AMPS上预训练再微调的1.5B GPT-2，6.9%。
  • 竞争
    语言模型的规模定律2020.01 · LLM
    规模定律显示多数任务随参数平滑提升；作者认为MATH按当时的趋势外推需要不现实的规模，需要新算法。
  • 使用
    GPT-32020.05 · LLM
    以GPT-3少样本和GPT-2微调为主要评测对象，175B GPT-3只有5.2%。
  • 延续
    MMLU2020.09 · 数据·评测
    MMLU显示大模型在计算型科目上接近随机，MATH专门把数学推理拿出来，换成需要生成答案而非选择的竞赛题。
  • 改进
    GSM8K2021.10 · 数据·评测
    题目简单且容易被训练数据污染，大模型很快逼近饱和，需要更难的评测。

读懂它需要的概念

基准、排行榜与SOTA 语言模型 预训练与微调 自回归生成 幂律与规模定律

本篇术语

  • 精确匹配　把模型答案和标准答案按统一规则化简后逐字比较，完全一致才算对，不给部分分。
  • AMC / AIME　美国数学竞赛的两级考试。AMC是面向中学生的选拔赛，AIME是成绩优秀者参加的邀请赛，答案为0–999的整数。

怎么学

先读基准、排行榜与SOTA和自回归生成。读原文第3.1节（题目与判分规则）和第4节的表2、图5。动手：从Hugging Face下载MATH测试集，挑一个开源小模型用思维链提示做100道1级题和100道5级题，写一个解析\boxed{}的判分脚本，比较两档难度。
