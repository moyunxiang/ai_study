H2O人到人形实时遥操作

Learning Human-to-Humanoid Real-Time Whole-Body Teleoperation
2024.03论文延伸IROS 2024Tairan He, Zhengyi Luo, Wenli Xiao, Chong Zhang, Kris Kitani, Changliu Liu, Guanya Shi · Carnegie Mellon University待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

想让真人实时“附身”遥控一台全尺寸人形机器人做全身动作，但人体动作数据很多根本不符合机器人的关节和力学限制，直接拿去训练控制器，学出来的策略在真机上会摔。

方法

先用一个能看到特权信息的仿真模仿器把重定向后的人类动作过一遍，筛掉机器人做不出来的（“sim-to-data”），再用剩下的动作训练鲁棒的实时动作模仿策略，零样本迁移到真机，只用一个RGB摄像头捕捉操作者姿态。

影响

论文称这是首个基于学习的实时人形机器人全身遥操作演示；同一团队随后推出了OmniH2O，把它扩展到灵巧手和数据采集。

方法

人形机器人和人的身体比例、关节范围都不一样，要先把人体动作（常用SMPL人体模型参数化表示）“重定向”到机器人骨架上。问题是大规模动作库里有大量动作对机器人来说物理上不可行，比如需要超出电机力矩的翻滚。

H2O分三步：第一，把人类动作数据重定向到Unitree H1骨架；第二，在仿真里训练一个能看到全部状态的“特权模仿器”去模仿这些动作，做不成的就从数据里剔除，作者称之为sim-to-data；第三，用筛选后的动作，在仿真里以强化学习训练一个只依赖真机可得观测的实时模仿策略，配合域随机化，直接部署到真机。这一思路与DeepMimic用强化学习让物理角色跟踪参考动作一脉相承，又比ExBody全身表现控制只模仿上半身表现走得更远。

遥操作时，一个普通RGB摄像头估计操作者的姿态，转成机器人要跟踪的目标，机器人就能实时跟着人走路、后跳、踢腿、转身、挥手、推、打拳。

读懂它需要的概念

遥操作与示教数据 仿真到现实的差距 策略梯度 自由度、运动学与本体感知

本篇术语

  • 动作重定向　把一个身体（人）的动作映射到另一个比例、关节数不同的身体（机器人）上，保持动作的意思大体不变。
  • sim-to-data　本文提法：用仿真里的模仿器检验每段人类动作机器人能否做到，做不到的从训练数据中删掉。

怎么学

先了解DeepMimic的动作跟踪奖励，再读本文第三节的数据筛选与策略训练；对比OmniH2O看后续如何加上手部与VR遥操作。
