Google Web 1T 5-gram

2006.08数据集延伸Thorsten Brants, Alex Franz · Google待核对
LDC ↗在交互版中打开（演化树、学习进度）

问题

n-gram语言模型的效果随训练文本增大而持续变好，但学术界手里的语料只有几亿词，远小于网络。

方法

Google从公开网页中统计了约一万亿词的所有1到5元词组的出现次数，把计数表直接发给研究者。

影响

它让研究者第一次能在网络规模的数据上做语言建模、拼写纠错和机器翻译实验，是「数据比算法更重要」论调的实证支撑之一。

方法

Web 1T 5-gram由Google贡献、经LDC于2006年9月19日发布。内容不是原文，而是计数：从公开网页文本里统计出英语的单词、双词到五词序列及其出现次数。据LDC说明，数据共约1,024,908,267,229个词、95,119,665,584个句子，含13,588,391个不同的单词；压缩后文件共24GB。

只发计数而不发原文，有两个好处：体积小，且不涉及网页原文的版权。因为n-gram语言模型本来就只需要这些计数（见n-gram平滑），所以它可以直接用来估计词序列的概率，用于机器翻译、语音识别、拼写纠错等任务。当时Google自己的实验表明，语言模型越大，翻译质量越高，这是数据的不合理有效性一文的重要背景。

它的局限是只能做固定窗口的计数查询，无法训练神经网络等需要原文的模型，因此被后来的Common Crawl与网络规模文本这样的原文语料取代。

局限与后续

  • 只有至多五个词的计数，不保留原文，无法训练需要长上下文或整句信息的模型。
