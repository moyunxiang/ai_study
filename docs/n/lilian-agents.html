问题

AutoGPT、BabyAGI等演示一夜走红，但大家缺少一个统一的框架来理解“LLM智能体”由哪些部分构成、各部分靠什么技术。

方法

把LLM智能体拆成三个模块：规划（任务分解、自我反思）、记忆（短期上下文、长期向量库）、工具使用，并逐一综述已有方法。

影响

这篇博客成为入门LLM智能体最常被引用的框架，“规划加记忆加工具”的三分法几乎成了行业默认说法。

方法

文章先说明：以LLM为核心控制器的智能体，LLM就是大脑，周围配三样东西。规划：把大任务拆成子目标（用思维链CoT、思维树），并通过ReAct、Reflexion等方式对过去行动做反思和修正。记忆：把上下文内的学习视为短期记忆，把外部向量库加快速检索（最大内积搜索）视为长期记忆。工具使用：让模型调用外部API补足权重里没有的信息，如Toolformer。

之后文章用案例（科学发现智能体、生成式智能体）和概念验证（AutoGPT与自主智能体热潮、GPT-Engineer）说明这些部件怎样拼起来，最后列出挑战，如有限的上下文长度和对自然语言接口可靠性的担忧。它不是论文，没有新实验，价值在于梳理。
