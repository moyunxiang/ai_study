基于Freebase的语义解析问答

Semantic Parsing on Freebase from Question-Answer Pairs
2013.10论文延伸EMNLP 2013Jonathan Berant, Andrew Chou, Roy Frostig, Percy Liang · Stanford University待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

语义解析需要给每个问题标注逻辑形式，成本高；而且词汇表要覆盖像Freebase这样有成千上万属性的大知识库很难。

方法

只用“问题加答案”对来训练：把答案当作弱监督，让模型自己找出能得到正确答案的逻辑形式，并从知识库和文本中自动构建词汇表。

影响

建立了用问答对训练知识库问答的方式，并发布了WebQuestions数据集，成为之后大批KBQA工作的基准。

方法

模型是一个对数线性的概率语义解析器：对每个问题，枚举多种可能的逻辑形式（对应Freebase上的查询），每个逻辑形式有打分；打分高的被执行，得到的答案若与标准答案一致，说明这个逻辑形式很可能是对的。训练时只要求最终答案对，不要求逻辑形式本身有标注，因此不需要昂贵的专家标注。

为了覆盖大知识库，论文做了两件事：一是通过把大规模文本与Freebase对齐，自动构造问题词语与知识库属性之间的对应词典；二是加入“改写”机制，把问题改写成近似的陈述句，再与候选属性匹配，从而覆盖词典没有的表述。

论文在自己收集的WebQuestions数据集（由真实网络用户用搜索接口提出的问题）上评测，并在已有的数据集上也做了实验。

局限与后续

  • 逻辑形式的搜索空间随复杂度指数增长，只擅长简单的单属性问题，难以回答多步推理的复杂问题。

它建立在什么之上

  • 使用
    Freebase2007.03 · NLP
    以Freebase作为知识库，逻辑形式即Freebase上的查询。
  • 改进
    BASEBALL问答系统1961 · NLP
    只能回答固定领域、固定句式的问题，遇到词典外的词或没预想到的说法就失败。
  • 改进
    LUNAR月岩问答1972 · NLP
    每个新领域都要重写词典、语法和语义规则，移植成本很高，用户用到未预期的说法就失败。
  • 改进
    Montague语义学1973 · NLP
    覆盖的英语片段很小，对真实文本中的省略、指代和不规范表达无能为力，也没有概率打分。
  • 改进
    语义解析（CCG）2005.07 · NLP
    原方法需要句子到逻辑形式的标注；这里只用问题与答案对作为弱监督，去掉了逻辑形式标注。

后来的相关工作

  • 改进
    检索增强生成RAG2020.05 · 推理·智能体
    逻辑形式的搜索空间随复杂度指数增长，只擅长简单的单属性问题，难以回答多步推理的复杂问题。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

本篇术语

  • 弱监督　只给最终答案，不给中间步骤的标注，让模型自己找出可行路径。
  • WebQuestions　论文收集的一个基于真实用户问题的知识库问答数据集。

怎么学

先理解语义解析（CCG）的逻辑形式；读原文弱监督训练与词典构造两节；了解后来的神经KBQA如何替代手工词典。
