SwinIR图像复原

SwinIR: Image Restoration Using Swin Transformer
2021.08论文延伸ICCV Workshops 2021Jingyun Liang, Jiezhang Cao, Guolei Sun, Kai Zhang, Luc Van Gool, Radu Timofte · 苏黎世联邦理工待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

图像复原长期由卷积网络主导，卷积对远处像素建模弱、权重与内容无关；而原版ViT切块又破坏边界、计算随分辨率平方增长，难用于像素级任务。

方法

用Swin Transformer的窗口注意力加残差连接组成“残差Swin Transformer块”，接在浅层卷积之后，做超分、去噪、去压缩伪影的统一骨干。

影响

以更少参数在多项复原任务上超过卷积方法，成为Transformer复原模型的标准基线，后续Restormer、HAT等都与它比较。

方法

SwinIR分三段：

  • 浅层特征提取：一层3×3卷积，把图像变成特征；
  • 深层特征提取：若干个残差Swin Transformer块（RSTB）。每个RSTB里有若干Swin层——在不重叠的局部窗口内做自注意力与多头注意力，相邻层窗口错开半个窗口以交换信息——末尾再加一层卷积，整个块用残差连接包起来；
  • 高质量重建：超分任务用亚像素卷积上采样，去噪与去JPEG伪影则直接输出与输入同尺寸的图像。浅层特征和深层特征通过长残差相加，网络主要学习高频细节。

窗口注意力的计算量与图像面积成线性关系，因而能处理整张图而不必切块。摘要报告它在经典、轻量和真实世界超分、灰度与彩色去噪、JPEG伪影去除三类代表性任务上比当时最好的方法高0.14–0.45 dB，参数最多减少67%。

局限与后续

  • 窗口注意力的感受野仍有限，处理大图时推理速度和显存开销明显高于同等精度的卷积网络。

它建立在什么之上

  • 竞争
    DnCNN去噪2016.08 · 视觉
    在灰度与彩色去噪任务上与DnCNN等卷积去噪网络对比。
  • 改进
    EDSR超分辨率2017.07 · 视觉
    用自注意力取代EDSR类卷积残差块，以更少参数取得更高PSNR。
  • 改进
    FFDNet可调去噪2017.10 · 视觉
    只针对加性高斯类噪声，不处理模糊、压缩等其他退化。
  • 改进
    DeblurGAN对抗去模糊2017.11 · 视觉
    只针对运动模糊一种退化，真实照片里噪声、压缩、失焦等混合退化处理不了。
  • 改进
    RCAN通道注意力超分2018.07 · 视觉
    卷积感受野有限，通道注意力也只建模通道间关系，难以利用图中远处相似纹理。
  • 使用
    Swin Transformer2021.03 · 视觉
    以Swin的移位窗口注意力层作为深层特征提取的基本单元。
  • 使用
    Real-ESRGAN2021.07 · 视觉
    真实世界超分版本沿用Real-ESRGAN式的退化合成来训练。

后来的相关工作

  • 改进
    Restormer复原Transformer2021.11 · 视觉
    SwinIR的注意力局限在小窗口内；Restormer用通道维转置注意力在线性代价下获得全局交互。
  • 改进
    HAT混合注意力超分2022.05 · 视觉
    SwinIR实际利用的输入范围有限；HAT加通道注意力和重叠交叉注意力，让网络激活更多输入像素。
  • 使用
    DiffBIR扩散盲复原2023.08 · 视觉
    第一阶段的去退化模块采用SwinIR这类复原网络。

读懂它需要的概念

自注意力与多头注意力 残差连接 卷积层、池化与感受野 图像块与视觉token 图像作为张量

本篇术语

  • PSNR　峰值信噪比：衡量复原图与真实图逐像素差异的指标，单位dB，越高越接近真实图。

怎么学

先读Swin Transformer的窗口注意力，再读SwinIR第3节网络结构；用官方模型在Set5上测×4超分的PSNR，并与EDSR比较参数量。
