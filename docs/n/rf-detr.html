RF-DETR

RF-DETR: Neural Architecture Search for Real-Time Detection Transformers
2025.11论文延伸Isaac Robinson, Peter Robicheaux, Matvei Popov, Deva Ramanan, Neehar Peri · Roboflow / CMU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

开放词汇检测器在COCO上很强，但对预训练中没见过的真实数据集类别泛化差，而微调大型视觉语言模型又太重。

方法

以预训练基座为起点，用权重共享的神经架构搜索，在目标数据集上一次微调后评估成千上万种配置，得到精度-延迟曲线。

影响

首个在COCO上突破60 AP的实时检测器，并在Roboflow100-VL上以小模型胜过大型开放词汇方法。

方法

RF-DETR是一个轻量的专用检测Transformer。它先在目标数据集上微调一个预训练基座网络，然后用权重共享的神经架构搜索NAS：训练一个包含众多子网络配置的大网络，之后无需重新训练就可评估成千上万种不同的精度-延迟配置，为任何目标数据集找出帕累托最优曲线。作者还重新审视了NAS的“可调旋钮”，以提升DETR在不同领域的可迁移性。

摘要称RF-DETR nano在COCO上达到48.0 AP，在相近延迟下比D-FINE nano高5.3 AP；2x-large在Roboflow100-VL上比GroundingDINO tiny高1.2 AP而快20倍，并且是首个COCO上超过60 AP的实时检测器。
