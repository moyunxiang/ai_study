Munchausen RL

Munchausen Reinforcement Learning
2020.07论文延伸NeurIPS 2020Nino Vieillard, Olivier Pietquin, Matthieu Geist · Google Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DQN之后的提升大多靠叠加组件（分布式RL、n步回报、优先回放），算法越来越复杂；TD自举只利用了当前的价值估计，没有利用当前策略本身的信息。

方法

在即时奖励上加一项缩放后的当前策略对数概率 α·τ·log π(a|s)，让智能体用自己的策略来「自举」，同时配合熵正则的软Q目标。

影响

只改一行目标就让DQN在Atari上接近分布式方法，叠加到IQN上超过Rainbow；后来常被当作隐式KL正则的值方法基线。

方法

普通DQN的回归目标是 r + γ·max Q(s',a')。Munchausen DQN（M-DQN）做两处改动：一是把max换成熵正则下的软值（对下一状态按softmax策略求期望，并减去τ倍的对数概率）；二是在即时奖励上加上 α·τ·log π(a|s)，π是当前Q值经温度τ的softmax得到的策略。因为log π≤0，已经被策略看好的动作几乎不扣分，策略不看好的动作被扣得更多，相当于让智能体「拉着自己的头发往上提」（名字来自闵希豪森男爵的故事）。

作者的理论分析表明，这一项等价于在相邻两次策略之间做隐式的KL正则，并且会拉大最优动作与次优动作的Q值差距（action gap），使贪心选择对估计误差更不敏感。摘要称：M-DQN不用分布式RL、n步回报或优先回放，在Atari上就能与分布式方法竞争；把同样的项加到隐式分位数网络IQN上得到的M-IQN超过了Rainbow。

它建立在什么之上

  • 延续
    DQN（Nature版）2015.02 · RL
    在DQN的回归目标里加入策略对数概率项，网络和训练流程不变。
  • 竞争
    Rainbow2017.10 · RL
    Rainbow靠叠加六种组件提升，M-DQN只改目标就达到相近水平。
  • 延续
    SAC2018.01 · RL
    沿用最大熵RL里的软值与熵正则思路，把它用到离散动作的值方法上。
  • 使用
    隐式分位数网络IQN2018.06 · RL
    把同样的修改加在IQN上，得到超过Rainbow的M-IQN。

本篇术语

  • action gap　同一状态下最优动作与次优动作的Q值之差；差距越大，估计误差越不容易让智能体选错动作。
