Reflexion

Reflexion: Language Agents with Verbal Reinforcement Learning
2023.03论文延伸NeurIPS 2023Noah Shinn, Federico Cassano, Edward Berman, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao · Northeastern / MIT / Princeton待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语言智能体想通过试错学习，但传统强化学习需要大量样本和微调，成本太高。

方法

让智能体在失败后用语言写下反思，存入记忆，下次尝试时读到这些反思。

影响

提出「不更新权重、只靠文字反馈学习」的方式，把强化学习的思想搬到提示层面。

方法

智能体在环境里完成一次尝试后，从环境得到成功或失败等反馈；一个自我反思模块把轨迹和反馈变成一段文字总结（比如「我没有先检查钥匙在哪就去开门」），放进情景记忆缓冲区。下一次尝试时，这些反思被拼进提示，帮助智能体改正行为。反馈可以是标量，也可以是自由文本，可来自外部（编译器、测试）或内部模拟。

摘要称在编程基准HumanEval上达到91%的pass@1，，并在决策和推理任务上都有提升。

后来的发展

LATS智能体树搜索把它与树搜索结合；之后的代理框架普遍保留「反思写入记忆」这一环；MemGPT、生成式智能体也依赖文字记忆。

局限与后续

  • 反思质量取决于模型自身判断，若反馈信号不可靠，会写出错误教训并固化。
    后来针对它的工作　自我纠错的局限
  • 记忆缓冲区受上下文长度限制，难以积累很长的经验。
    后来针对它的工作　MemGPT
