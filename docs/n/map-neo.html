MAP-Neo完全开源双语

MAP-Neo: Highly Capable and Transparent Bilingual Large Language Model Series
2024.05论文延伸Ge Zhang, Scott Qu, Jiaheng Liu, Chenchen Zhang, Chenghua Lin, Chou Leuang Yu, Danny Pan, Esther Cheng et al. · M-A-P开源社区及合作机构待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

Pythia、Amber、OLMo这类“真正开放”的模型公开了语料和训练代码，但在推理、知识和代码任务上明显不如同规模的最强模型；中文方面更是没有一个既完全开放、又有竞争力的模型。

方法

从零训练一个7B中英双语模型，用4.5万亿高质量词元，并把清洗后的预训练语料、数据清洗流程、中间检查点和训练/评测框架全部开源。

影响

摘要称是第一个性能可与当时最强同规模模型相比的完全开源双语模型，其开放的语料（Matrix）和中文数据处理流程被后续中文开放模型参考。

方法

背景：Llama 3等开放权重模型能力强，但只给权重；Pythia、LLM360完全开源、OLMo完全开放模型公开了数据和代码，研究价值高，可能力明显落后。中文开源模型（如通义千问Qwen、零一万物Yi）则几乎都不公开预训练数据。

数据：作者构建了约4.5万亿词元的双语预训练语料（称为Matrix），来源包括中英文网页、书籍、学术论文、代码等。对网页数据，他们设计了一整套中英文分别优化的清洗流程：基于规则的过滤、去重（精确与模糊）、质量打分；对PDF等文档，用OCR和版面分析提取文本。这套流程本身也被开源。

模型与训练：7B参数的纯解码器模型，结构与LLaMA类似。训练分阶段进行，后期提高高质量数据（如数学、代码、教材类）的比例，即常见的“退火”式安排。之后做指令微调和偏好对齐得到对话版本。

开放内容：清洗后的预训练语料、数据清洗流程代码、中间检查点、经过优化的训练与评测框架，以及分词器训练细节。

结果（摘要）：MAP-Neo在推理、知识和代码等任务上与同规模的最强模型相当，摘要称是第一个达到这一水平的完全开源双语LLM。

后来的发展

MAP-Neo把完全开放的标准带到中文模型上，同一社区后续的OpenCoder等也沿用“开放食谱”式的发布方式。

局限与后续

  • 只有7B一个主规模，与同期更大的中文模型相比能力有限；完全开放的语料也带来版权与隐私审查方面的问题，作者只能做部分过滤。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    Llama 32024.04 · LLM
    只开放权重的同期强模型，是MAP-Neo对照的性能标杆。
  • 延续
    Pythia2023.04 · LLM
    继承公开语料与检查点以支持科学研究的思路。
  • 延续
    LLM360完全开源2023.12 · LLM
    LLM360首批模型能力不突出，MAP-Neo在同样透明的前提下追求一线性能。
  • 延续
    OLMo完全开放模型2024.02 · LLM
    沿用完全开放的发布方式，并把它扩展到中英双语、提升到与最强同规模模型相当的水平。

读懂它需要的概念

预训练与微调 分词与token 数据泄漏与基准污染 指令微调与对话模板

本篇术语

  • 完全开源　不仅公开模型权重，还公开预训练语料、数据处理流程、训练代码、中间检查点和评测方法，任何人都能完整复现。

怎么学

先读OLMo完全开放模型了解完全开放；读本文的数据清洗流程一节和与开放权重模型的对比表；动手：用开源的清洗脚本处理一小批中文网页，看去重和质量过滤各删掉了多少内容。
