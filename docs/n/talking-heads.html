Talking-Heads跨头注意力

Talking-Heads Attention
2020.03论文延伸arXiv 2020Noam Shazeer, Zhenzhong Lan, Youlong Cheng, Nan Ding, Le Hou · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多头注意力里各个头完全独立地算注意力权重，头与头之间不交换信息。

方法

在softmax前后各加一个跨头维度的线性映射，让各头的注意力分数和权重互相混合。

影响

以很少的额外参数换来更好的掩码语言模型困惑度和下游迁移效果，是后来“头之间组合”一类改进的起点。

背景

Transformer的多头注意力把查询、键投影到h个子空间，各自算一张注意力图再拼接。每个头只能用自己那份 d/h 维的查询和键，头数越多每个头越窄，注意力图的表达力受到限制；而头与头之间没有任何交流。

方法

设第i个头的注意力logit为 L_i = Q_i K_iᵀ/√d。Talking-Heads在softmax前用一个 h×h 的矩阵 P_l 沿“头”这一维做线性组合，softmax后再用另一个矩阵 P_w 组合一次：

L' = P_l · [L_1 … L_h]，W = softmax(L')，W' = P_w · W

然后用 W'_j 去加权第j个头的值。这样每张注意力图都可以是所有头的logit的混合，相当于让“窄头”借用其他头的信息。额外参数只有两个 h×h 矩阵，计算增加有限。

结果

摘要称它在掩码语言建模上取得更低的困惑度，迁移到语言理解和问答任务时质量也更好。

后来的发展

这一想法后来被DCMHA动态组合多头注意力推广为依赖输入的动态组合；在主流大模型里并没有普遍采用，原因之一是它让注意力内核难以按头独立并行，不便与FlashAttention一类实现结合。

局限与后续

  • 跨头混合打破了各头独立计算的结构，难以套用按头分块的高效注意力内核。
