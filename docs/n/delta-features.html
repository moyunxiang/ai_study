动态差分特征Δ

Speaker-independent isolated word recognition using dynamic features of speech spectrum
1986.02论文延伸IEEE TASSP 1986Sadaoki Furui · NTT待核对
IEEE ↗在交互版中打开（演化树、学习进度）

问题

识别特征（倒谱系数）每帧只描述一个约20毫秒的静态频谱快照，而区分音素的关键线索往往在频谱怎样随时间变化，例如辅音到元音的共振峰过渡。

方法

对每一维倒谱系数在前后若干帧上做线性回归，取回归斜率作为「动态特征」（delta），与静态倒谱拼在一起作为识别输入。

影响

静态特征加一阶、二阶差分（delta、delta-delta）成为此后三十年语音识别特征的标准配置，典型的39维MFCC输入就是13维静态加各13维一阶和二阶差分。

方法

20世纪80年代的识别系统用线性预测编码LPC倒谱或MFCC特征描述每一帧语音，再用动态时间规整DTW或HMM比较帧序列。单帧特征是静态的，帧与帧之间的变化只能靠模型去隐式捕捉；而在HMM里，每个状态的输出概率又假设帧与帧条件独立，很难利用变化趋势。

Furui提出直接把变化率算成特征：对第t帧的第k维倒谱c_k，在前后各K帧（典型K=2，约±20–40毫秒）上拟合一条直线，斜率就是动态特征 Δc_k(t) = Σ_{n=−K..K} n·c_k(t+n) / Σ n²。它对频谱的缓慢整体偏移（如电话信道的固定频率响应）不敏感，因为常数偏移在差分中被消掉了。论文在说话人无关的孤立词识别上，把这种回归系数与静态倒谱结合，报告了比只用静态特征明显更好的结果（具体数字未核对）。

后来人们把同样的回归再做一次得到二阶差分（加速度特征）。在HMM时代，「MFCC＋Δ＋ΔΔ」几乎是所有系统的默认输入，HTK工具包和Kaldi都内置这一计算。参数语音合成（HMM参数语音合成）也借用动态特征来生成平滑的参数轨迹。

局限与后续

  • 差分窗口长度是固定的手工选择，只能捕捉几十毫秒范围内的局部变化。

本篇术语

  • 动态特征（delta）　特征随时间的变化率，用前后几帧的线性回归斜率计算。
  • 二阶差分（delta-delta）　对一阶差分再求一次变化率，相当于加速度。
