IC3Net门控通信

Learning when to Communicate at Scale in Multiagent Cooperative and Competitive Tasks
2018.12论文延伸ICLR 2019Amanpreet Singh, Tushar Jain, Sainbayar Sukhbaatar · NYU / Facebook AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

CommNet表明智能体之间可以用连续向量通信并靠反向传播一起训练，但它只适用于完全合作的任务：所有智能体共享一个奖励、每一步都必须广播消息。

方法

给每个智能体加一个门控，让它自己学“这一步要不要说话”；同时每个智能体用自己的个体奖励训练，于是通信模型也能用于半合作和竞争的场景（IC3Net）。

影响

“学会何时通信”的代表方法，与CommNet、TarMAC等一起构成多智能体学习通信方向的常用基线。

方法

IC3Net（Individualized Controlled Continuous Communication Model）在CommNet可微通信的基础上做两处改动：

  • 门控通信：每个智能体j有一个LSTM维持隐状态 h_j^t，并输出一个二值门 g_j^t ∈ {0, 1}（由一个小网络给出概率后采样）。广播给别人的通信向量是被门控后的隐状态的平均：

c_j^(t+1) = (1/(J−1)) · C · Σ_(j′≠j) h_(j′)^t ⊙ g_(j′)^t

门为0时这个智能体本步“沉默”。门的选择当作一个离散动作，与环境动作一起用REINFORCE策略梯度式的策略梯度训练；

  • 个体奖励：CommNet把所有智能体的奖励加总，导致每个智能体分不清自己的贡献，也无法用于竞争任务。IC3Net让每个智能体用自己的奖励训练（参数仍共享），既缓解了信用分配问题，又能在部分合作或对抗的环境里使用。

作者在捕食者-猎物、交通路口、星际争霸（BroodWar）的探索与战斗等任务上评测。摘要称随着规模增大，IC3Net比基线性能更好、收敛更快，并且智能体会根据场景和收益学会何时通信：竞争场景下倾向于少说话以免暴露信息。

局限与后续

  • 通信是对所有人的平均广播，不能有选择地发给特定队友，智能体多时信息会被稀释。

  • 使用
    LSTM1997 · 基础
    每个智能体用LSTM维持随时间变化的隐状态。
  • 使用
    REINFORCE策略梯度1992 · RL
    门控与动作一起用策略梯度训练。
  • 延续
    CommNet可微通信2016.05 · RL
    在CommNet的连续通信上加入门控，并改用个体奖励。
  • 竞争
    DIAL/RIAL学习通信2016.05 · RL
    DIAL学离散或连续的消息并通过信道反传梯度；IC3Net学何时广播隐状态。
