从LLM提取训练数据

Extracting Training Data from Large Language Models
2020.12论文延伸USENIX Security 2021Nicholas Carlini, Florian Tramèr, Eric Wallace 等12位作者 · Google / 斯坦福 / UC Berkeley / OpenAI / 东北大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型在海量网页上训练，人们担心它会背下并泄露训练数据，但之前只在小模型上有证据。

方法

只靠查询GPT-2，就恢复出数百条逐字的训练序列，包括个人信息，并发现更大的模型更容易泄露。

影响

把「大模型会记忆并吐出训练数据」从猜测变成可复现的攻击，催生了去重、差分隐私训练和后续的从ChatGPT提取训练数据。

方法

攻击不需要访问模型内部：先让模型生成大量文本，再用各种指标（例如模型自己给出的困惑度与参考模型或压缩器的比较）挑选可能是背下来的片段，最后到训练语料里核实。

作者报告在GPT-2上得到数百条逐字的训练序列，内容包括姓名、电话号码、邮箱，以及IRC对话、代码和128位UUID。即使某条数据只在训练数据里的一个文档里出现过，也能被提取。他们还发现模型越大越容易泄露。

局限与后续

  • 提取到的数量有限，且需要大量生成和筛选；对更大的对齐后模型是否仍然有效，后来才有系统研究。
