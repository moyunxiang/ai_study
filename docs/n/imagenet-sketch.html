ImageNet-Sketch素描

Learning Robust Global Representations by Penalizing Local Predictive Power
2019.05数据集延伸NeurIPS 2019Haohan Wang, Songwei Ge, Eric P. Xing, Zachary C. Lipton · Carnegie Mellon University待核对
arXiv ↗官方仓库 ↗在交互版中打开（演化树、学习进度）

问题

卷积网络在ImageNet上准确率很高，但常常靠颜色、纹理这类局部表面线索分类；缺少一个与ImageNet同类别、同规模、只保留形状的测试集来检验它们是否学到了物体的整体语义。

方法

对ImageNet的1000个类别逐个用谷歌图片搜索“sketch of 类名”，只取黑白结果，人工清洗后每类留50张素描，共5万张，类别和规模与ImageNet验证集一致。

影响

为ImageNet分布偏移评测补上了“风格变化”这一项，CLIP论文把它与ImageNetV2：榜单过拟合了吗、ImageNet-A / -R等一起列为7个分布偏移测试集。

方法

据论文第4.4.1节和官方仓库，ImageNet-Sketch的构造是：对每个ImageNet类别用谷歌图片搜索“sketch of ×××”（×××为类名），颜色方案只限黑白，每类先取约100张候选；再人工剔除无关图片和属于相近但不同类别的图片；清洗后不足50张的类别用翻转和旋转补齐。最终每类50张、共50,000张，类别与规模和ImageNet验证集对齐。模型只在普通ImageNet上训练，再直接拿到这些素描上测试，衡量跨域（out-of-domain）泛化。

它随论文提出的方法一起发表：作者认为卷积网络过度依赖早期层能捕捉的局部信号（颜色、纹理），于是提出“分块对抗正则”（PAR），惩罚早期层局部表示的预测能力，逼网络依赖全局结构。论文表3里，AlexNet在ImageNet-Sketch上top-1只有12.04%，PAR为13.06%，加额外数据增强为14.94%，作者也承认提升有限。后来CLIP论文发现，在ImageNet上做有监督适配会让它在ImageNet Sketch上下降2.8%。

容易误解的地方

  • 部分类别原始素描不足50张，用了翻转、旋转后的副本，因此5万张并非全部相互独立。

局限与后续

  • 只覆盖素描这一种风格的偏移，且只有测试集；模型在它上面变好，不代表对卡通、绘画、真实场景变化等其他偏移也稳健。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    ImageNet2009.06 · 数据·评测
    沿用ImageNet的1000个类别，规模对齐验证集，只把图片换成黑白素描，用来测跨域泛化。
  • 使用
    AlexNet2012.09 · 视觉
    论文的基线与PAR方法都以AlexNet为骨干，在素描上top-1约12%。
  • 竞争
    ImageNet-C2019.03 · 数据·评测
    同为检验ImageNet模型稳健性的测试集：ImageNet-C用人工合成的噪声和模糊，ImageNet-Sketch用真实素描改变图像风格。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

分布偏移 泛化与过拟合 Top-1与Top-5错误率 卷积层、池化与感受野

本篇术语

  • 分布偏移（域外测试）　测试数据和训练数据来自不同分布，比如训练用照片、测试用素描。用来检验模型学到的是物体本身还是训练集特有的表面线索。

怎么学

先读ImageNet和ImageNet-A / -R讲解；动手：从仓库下载数据，用一个在ImageNet上预训练的ResNet和一个CLIP模型分别测top-1，比较两者从验证集到素描时掉了多少。
