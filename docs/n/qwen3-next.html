Qwen3-Next混合注意力

2025.09模型延伸2025-09-11 发布Qwen团队 · 阿里巴巴云待核对
Hugging Face文档 ↗官方博客 ↗在交互版中打开（演化树、学习进度）

问题

标准注意力的平方复杂度让超长上下文很贵，MoE的激活比例也还不够低。

方法

Qwen3-Next混合使用Gated DeltaNet（线性注意力）与门控注意力，配合高稀疏MoE和多token预测。

影响

把“线性注意力与全注意力混合”这一路线带入主流旗舰系列，激活比例低到1:50。

方法

Qwen3-Next是Qwen团队在2025年9月推出的下一代基础模型架构，目标是极端长上下文和大规模参数效率。据Hugging Face Transformers文档的概述，它由几处设计组成：

  • 混合注意力：用Gated DeltaNet和门控注意力的组合取代标准注意力，前者是带门控的线性注意力，计算随长度线性增长，后者保留少量全注意力层来维持检索能力。
  • 高稀疏混合专家：MoE层的激活比例低到1:50，大幅减少每个token的FLOPs，同时保持容量。
  • 多token预测（MTP）：提升预训练模型效果，并可加速推理。
  • 其他优化，如零中心且带权重衰减的layernorm等。

本条目没有打开官方博客正文，所以参数量与速度提升的具体数字不写。

局限与后续

  • 线性注意力层的精确召回能力弱于全注意力，必须保留一部分全注意力层，两者比例靠经验设定。

  • 改进
    Jamba混合架构2024.03 · LLM

  • 改进
    Samba混合SSM2024.06 · LLM
    没有全局注意力层，需要在很长距离上精确比对多处内容的任务（多跳检索、长文多处引用）仍受限于固定大小的状态；窗口外的信息只能靠Mamba的压缩记忆。
  • 改进
    Hymba混合头小模型2024.11 · LLM
    实验集中在1.5B左右的小模型，层内并行混合在数十亿到上百亿参数规模上是否仍优于层间混合没有验证；业界大模型后来多采用层间按比例混合的方案。
  • 使用
    门控注意力2025.05 · LLM
    在保留的全注意力层中采用输出门控来提升稳定性。
