动态记忆网络DMN

Ask Me Anything: Dynamic Memory Networks for Natural Language Processing
2015.06论文延伸ICML 2016Ankit Kumar, Ozan Irsoy, Peter Ondruska, Mohit Iyyer, James Bradbury, Ishaan Gulrajani, Victor Zhong, Romain Paulus et al. · MetaMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

问答、情感分类、词性标注各用各的模型；记忆网络能做多步推理式问答，但当时的版本需要额外的支撑事实监督或结构较固定，难以推广到一般NLP任务。

方法

把多数NLP任务都看成「读一段输入、回答一个问题」：用GRU编码输入和问题，情景记忆模块由问题触发、在输入上反复做注意力并更新记忆，最后由回答模块生成答案，整套端到端训练。

影响

用同一个架构在bAbI推理问答、斯坦福情感树库和华尔街日报词性标注上取得当时最好的结果，「NLP任务都可以写成问答」的提法和多轮注意力（多跳）设计影响了之后的阅读理解与视觉问答模型。

方法

DMN由四个模块组成，内部的循环单元都是GRU（见RNN编码器-解码器与GRU）。输入模块用GRU读入文本，得到每个句子（或每个词）的表示；问题模块同样用GRU把问题编码成向量q。情景记忆模块是核心：它对输入做多轮遍历，每一轮用一个打分网络根据当前输入c_t、记忆m和问题q计算注意力门g_t，再用一个按g_t加权的GRU扫过输入得到这一轮的「情景」e，然后更新记忆m_i = GRU(e_i, m_{i−1})。多轮遍历的意义在于传递性推理：例如问「足球在哪」，第一轮先注意到「约翰拿起了足球」，第二轮再注意到「约翰去了走廊」。回答模块以最终记忆为初始状态，用GRU生成答案。

它延续了端到端记忆网络的多跳注意力思路，但输入和记忆都用循环网络处理，并且能直接用于序列标注和分类。论文在bAbI的20类推理任务、斯坦福情感树库（情感分类）和华尔街日报树库（词性标注）上取得当时的最好结果，训练只依赖词向量和输入-问题-答案三元组。

局限与后续

  • 原版输入模块逐句串行读入，句子之间信息交流有限，在不提供支撑事实监督时bAbI部分任务表现不佳。

它建立在什么之上

  • 使用
    RNN编码器-解码器与GRU2014.06 · NLP
    所有模块的循环单元都是GRU，情景模块还用了按注意力门加权的修改版GRU。
  • 竞争
    注意力阅读器与CNN/DM2015.06 · NLP
    同月提出：注意力阅读器面向真实新闻的完形填空，只做一次注意力；DMN强调多轮注意力推理，并把分类和标注也写成问答。
  • 使用
    bAbI2015.02 · 数据·评测
    主要的推理问答评测在bAbI的20类任务上进行。
  • 延续
    端到端记忆网络2015.03 · NLP
    沿用多跳注意力读记忆的思路，改用GRU处理输入、更新记忆和生成答案。

后来的相关工作

  • 改进
    BiDAF双向注意力流2016.11 · NLP
    在bAbI这类合成数据上的推理能力，迁移到真实文本阅读理解时效果有限，真实数据上的主流模型很快换成了基于跨度预测的注意力架构。

读懂它需要的概念

循环网络与隐状态 门控机制 注意力机制 嵌入向量 端到端学习

本篇术语

  • 情景记忆　DMN中由问题驱动、在输入上多轮注意力并逐轮更新的记忆向量，借用了认知科学的说法。
  • 多跳推理　答案需要串联多条事实才能得到，模型要在输入上做多轮注意力，每一轮找一条线索。

怎么学

先读端到端记忆网络的讲解和GRU的公式 → 读原文第2节四个模块的定义 → 动手：在bAbI的任务1和任务2上分别训练1轮与3轮情景记忆的模型，观察多轮遍历对两跳推理题的作用。
