Objects365检测库

Objects365: A Large-scale, High-quality Dataset for Object Detection
2019.10数据集延伸ICCV 2019Shuai Shao, Zeming Li, Tianyuan Zhang, Chao Peng, Gang Yu, Xiangyu Zhang, Jing Li, Jian Sun · 旷视科技（Megvii）待核对
论文（CVF） ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

检测模型通常拿ImageNet分类预训练的骨干网络起步，但分类任务不关心位置，检测头也得从零学；COCO只有80类、十几万张图。

方法

标注一个365类、63.8万张图、1010万个框的全标注检测数据集，用它代替ImageNet做检测预训练。

影响

成为强检测器的常用预训练数据，DINO（检测）、Grounding DINO、D-FINE等都先在Objects365上预训练再到COCO微调或评测。

方法

据论文，图片主要来自Flickr，去掉只适合分类的“标志性”图片（画面中央只有一个物体，这一过滤沿用MS COCO的做法）。类别先定11个大类（人与配饰、客厅、衣物、厨房、乐器、交通、浴室、电子产品、食物、办公用品、动物），再细分出442类，在前10万张图上全部标注后保留最常见的365类，并包含PASCAL VOC和COCO的全部类别。

标注分三步：先判断图片是否非标志性且含任一大类物体；再打上大类标签；最后每个标注员只负责一个大类，框出其中的所有物体。这样每人只需熟悉一个大类，而不必记住365类。标注员、检查员、审核员三级把关，约100张为一个任务，任何一步有错整批退回。划分为训练60万张（962.3万框）、验证3.8万张、测试10万张。论文称图片数是COCO的5倍、类别4倍、框10倍；与只做部分标注的Open Images相比，每张图平均标出的类别更多。

结果

据摘要，以FPN-ResNet50在COCO上按90K迭代的标准设置，用Objects365预训练的AP为42.0，ImageNet预训练为36.4；即使ImageNet预训练训练到540K迭代（39.3），仍低2.7个点，达到同样精度的微调时间最多可缩短到十分之一。在CityPersons、VOC分割和ADE上也观察到更好的迁移。

读懂它需要的概念

分类、检测、分割 IoU与mAP 预训练与微调 迁移学习

本篇术语

  • 全标注与部分标注　全标注指图里属于词表的每个物体都画了框；部分标注只保证标出一部分类别，没框的地方不一定是背景，训练和评测时要特殊处理。
  • 非标志性图片　非“一图一物、物体居中”的照片，场景里有多个物体、大小位置各异，更接近检测的实际情况。

怎么学

先补IoU与mAP与预训练与微调；读论文第3节的标注流程和第5节的迁移实验；动手：用MMDetection分别从ImageNet和Objects365预训练权重微调同一个检测器，比较COCO上前几千次迭代的AP曲线。
