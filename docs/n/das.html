DAS分布式对齐搜索

Finding Alignments Between Interpretable Causal Variables and Distributed Neural Representations
2023.03论文延伸CLeaR 2024Atticus Geiger, Zhengxuan Wu, Christopher Potts, Thomas Icard, Noah D. Goodman · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

因果抽象理论能严格定义“一个可解释的高层因果模型是否忠实概括了神经网络”，但检验时要暴力搜索高层变量和神经元的对应关系，还假设每个高层变量对应一组互不重叠的神经元，而真实网络里信息往往分布在多个神经元的组合方向上。

方法

不再在神经元上枚举，而是用梯度下降学一个正交旋转，把某层表示转到新的坐标系里，在这个坐标系的一个子空间上做互换干预，找到与高层变量对齐的分布式表示。

影响

把“在学到的子空间而不是单个神经元上做干预”变成可解释性的标准做法，影响了后来的子空间修补、表示微调（ReFT）和AxBench引导方法基准等工作，也引发了关于子空间干预可能产生“可解释性错觉”的讨论。

方法

先说因果抽象：设想我们猜测网络在做一道题时，内部先算出了中间变量Z（比如比较两个数的大小时先判断“第一个数更大”）。若网络某处的表示确实对应Z，那么把输入A在该处的表示换成输入B在该处的表示（互换干预），网络的输出应该变成“Z取B的值时”高层模型预测的输出。干预后与预测一致的比例叫互换干预准确率。

旧方法要逐一尝试哪组神经元对应Z，组合数巨大，而且默认Z落在某几个神经元上。DAS的改动是：

  • 学一个正交矩阵R，把隐藏表示h旋转成 Rh；
  • 只在旋转后坐标的前k维上做互换干预：把A的这k维换成B的这k维，再用 Rᵀ 转回去继续前向计算；
  • 以“干预后的输出符合高层模型预测”为训练目标，用梯度下降优化R，网络本身参数冻结。

这样一个高层变量可以对应多个神经元的线性组合，单个神经元也可以参与多个变量，符合叠加假说所说的分布式表示。作者在若干层级等式判断、自然语言推理等任务上显示，DAS能发现以往方法漏掉的内部结构。

它和线性探针的区别在于：探针只说明“信息能被读出来”，DAS通过干预检验“这个子空间确实被网络用来计算”。

局限与后续

  • 学到的子空间有可能只是激活了网络中原本休眠的路径，干预结果看似支持假设但并非网络真正的计算方式（可解释性错觉）。

读懂它需要的概念

向量、矩阵与张量 特征分解与奇异值分解 梯度下降 特征与表示学习 概率图模型

本篇术语

  • 互换干预　把一次输入在某处的内部表示换成另一次输入在同一处的表示，观察输出如何变化。
  • 因果抽象　判断一个简单的高层因果模型能否忠实描述复杂低层系统行为的理论框架。

怎么学

先读因果中介分析与激活修补和线性探针 → 读原文的方法部分和层级等式实验 → 用pyvene库在小网络上训练一个旋转矩阵，比较单神经元干预和子空间干预的准确率。
