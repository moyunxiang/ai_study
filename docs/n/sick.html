SICK句对语义

A SICK cure for the evaluation of compositional distributional semantic models
2014.05数据集延伸LREC 2014Marco Marelli, Stefano Menini, Marco Baroni, Luisa Bentivogli, Raffaella Bernardi, Roberto Zamparelli · 特伦托大学 / 布鲁诺·凯斯勒基金会（FBK）待核对
LREC 2014论文（PDF） ↗在交互版中打开（演化树、学习进度）

问题

组合式分布语义模型（把词向量拼成句子向量）缺少句子级评测：已有数据要么只有几百个固定结构的短句，要么混着专名、日期、俚语，评的是整套系统而不是句子表示本身。

方法

从图片和视频描述里取句子，先规范化、再用主被动转换、同义替换、加否定等规则改写，配成约1万对句子，众包标注语义相关度（1–5分）和蕴含/矛盾/中立三类关系。

影响

成为SemEval-2014第1号任务的数据，此后常与SNLI一起出现在句向量和自然语言推理的论文里，用来考句子表示的迁移效果。

方法

造句子。起点是8K ImageFlickr图片描述和SemEval 2012 STS的MSR视频描述，它们多是描述同一画面的近义句，专名少、常用词多。作者各随机取750对，分三步：先把原句规范化，去掉命名实体、复杂动词时态、复合词等组合式模型本来就不该处理的现象；再按规则扩写，得到意思相近的句子（主动变被动、换同义词、加修饰语）、意思相反或冲突的句子（加否定、换反义词、换量词），以及词几乎相同但意思不同的句子；最后把扩写句与规范化句配对，共9,840对。

标注。在众包平台上，每对句子由10个人评分，句子顺序正反各5次；相关度取10人平均，蕴含关系按多数票定为ENTAILMENT、CONTRADICTION或NEUTRAL（三分类沿用RTE文本蕴含挑战第四届的做法）。共收集20万条判断，耗时约三个月，花费2,030美元。相关度评分的平均标准差为0.76分，蕴含任务平均有84%的标注者与多数票一致。

结果

按论文表格，相关度落在[4,5]区间的占37%、[3,4)占39%，说明很多句对高度相关、只差一处改动。数据被用作SemEval-2014第1号任务（相关度与蕴含两个子任务）。

后来的发展

SNLI的作者评价SICK规模比此前的蕴含数据大了一截，但训练集只有4,500例，而且部分自动化的构造给数据引入了一些虚假规律；SNLI把规模扩大到57万对人写的句子，并在SICK测试集上做了对比与迁移实验。Layer Normalization等论文在Skip-Thought句向量句向量上用SICK相关度检验句子表示的质量。

局限与后续

它建立在什么之上

  • 使用
    潜在语义分析LSA1990.09 · NLP
    评测对象是LSA这一类分布式语义表示在句子层面的组合版本，相关度分数可直接与句向量的余弦相似度比较。
  • 延续
    递归张量网络与情感树库2013.10 · NLP
    论文引用Socher等的递归组合模型作为它要服务的组合式分布语义模型代表，为这类模型提供专门的句子级考题。
  • 延续
    RTE文本蕴含挑战2005 · 数据·评测
    沿用RTE第四届的蕴含/矛盾/未知三分类，但刻意去掉RTE数据里需要专名、常识和外部知识的部分，只考组合语义。

后来的相关工作

  • 改进
    SNLI2015.08 · 数据·评测
    句子由规则改写生成，变化方式有限且可预测，模型可能只学会识别“加了否定”“换了反义词”这类表面线索。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

分布假说 嵌入向量 基准、排行榜与SOTA 准确率、精确率、召回率与F1

本篇术语

  • 组合式分布语义模型（CDSM）　先用共现统计给每个词一个向量，再按某种组合规则（相加、相乘、递归网络等）算出短语和句子的向量。
  • 语义相关度　两句话意思有多接近，SICK用1到5分的平均人工评分作为标准答案，模型输出通常和它算皮尔逊相关系数。
  • SemEval-2014 Task 1　以SICK为数据的共享评测任务，分相关度打分和三分类蕴含判断两个子任务。

怎么学

先读RTE文本蕴含挑战了解文本蕴含任务。读论文第3节（规范化与扩写规则，表2、表3）和第4节的分布统计。动手：用现成词向量把SICK每句话平均成句向量，算余弦相似度与人工相关度的相关系数，再看加否定的句对上误差有多大。
