OpenAI Baselines与A2C

2017.05系统延伸OpenAI待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

各家论文的RL算法实现细节不同、不开源或有隐蔽bug，复现很难，也无法公平比较。

方法

发布一套统一、经过基准测试的高质量参考实现，从DQN开始，随后加入A2C、ACKTR、PPO等，都能直接跑在OpenAI Gym环境上。

影响

成为2017–2019年最常用的参考实现，其中的A2C是A3C的同步版本，也让「实现细节」成为一个被认真研究的问题。

方法

仓库首页的描述是「高质量的强化学习算法实现」。项目通过Hacker News的发布记录可以看到，第一篇公告《OpenAI Baselines: DQN》发布于2017年5月，后续的《OpenAI Baselines: ACKTR and A2C》发布于2017年8月。

A2C（Advantage Actor-Critic）是A3C的同步变体：不再让各线程异步地更新共享参数，而是让多个环境副本同步地走完n步，收集到一起，用一次批量更新，这样更适合GPU，实践中效果不差于异步版本。Baselines的实现里还包含向量化环境封装和观测、奖励的归一化等工程细节，后来的研究（见PPO的实现细节之争）发现这些细节对最终成绩影响很大。
