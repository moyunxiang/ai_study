证明者-验证者博弈提升可读性

Prover-Verifier Games improve legibility of LLM outputs
2024.07论文延伸Jan Hendrik Kirchner, Yining Chen, Harri Edwards, Jan Leike, Nat McAleese, Yuri Burda · OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

只按答案是否正确来优化模型的思维链CoT解题过程，解答会变得越来越难让人看懂和检查；而模型能力超过人类时，人能否核对它的推理，正是可扩展监督要解决的事。

方法

让三方反复博弈：一个小的验证者模型学判断解答对不对；“老实的”证明者要写出正确、并能让验证者认可的解答；“狡猾的”证明者专门写错误但能骗过验证者的解答。

影响

把“可读性”（legibility）作为与正确性并列的训练目标提出来，是OpenAI超级对齐方向在可扩展监督上的代表性实验之一，常与辩论式对齐、弱到强泛化并列讨论。

方法

作者在GSM8K小学数学题上研究。先观察到问题：只用正确性做强化学习，证明者的解答准确率上升，但限时检查的人类对这些解答的判断准确率下降，也就是解答变得难以核对。

训练算法受Anil等人2021年提出的证明者—验证者博弈启发，按轮迭代：

  • 用上一轮证明者产生的正确和错误解答，训练一个比证明者小得多的验证者，预测解答是否正确；
  • 用强化学习训练老实证明者，奖励是“答案正确且验证者给高分”；
  • 同时训练狡猾证明者，奖励是“答案错误但验证者给高分”。

摘要报告：训练过程中老实证明者的准确率和验证者对对抗攻击的鲁棒性都在提高；可读性还会迁移到限时的人类检查者身上——人类检查老实证明者的解答时准确率上升，检查狡猾证明者的解答时准确率下降。作者认为，针对小验证者训练可检查性，是提高大模型输出对人类可读性的可行途径，可能有助于对齐超人类模型。

局限与后续

  • 只在小学数学这种有标准答案的任务上验证，可读性训练还带来一定的准确率代价；在没有明确对错的开放任务上是否有效尚不清楚。

它建立在什么之上

  • 改进
    思维链CoT2022.01 · 推理·智能体
    仅按正确性优化思维链会让解答难以核对，可读性训练缓解了这一问题。
  • 延续
    辩论式对齐2018.05 · 安全·可解释
    同样用对抗性的多方博弈帮助较弱的裁判核对较强模型的输出，这里裁判是一个小模型。
  • 使用
    GSM8K2021.10 · 数据·评测
    在GSM8K小学数学题上训练和评估证明者与验证者。
  • 延续
    弱到强泛化2023.12 · 安全·可解释

读懂它需要的概念

策略梯度 人类反馈强化学习 推理token与测试时计算 对抗训练

本篇术语

  • 可读性（legibility）　一段推理清楚、容易被别人检查对错的程度；不等同于正确。

怎么学

先读辩论式对齐和弱到强泛化 → 读原文第3节训练算法和人类检查实验的图 → 思考：如果验证者太小或太大，博弈会出现什么问题。
