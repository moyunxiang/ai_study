层次编码器对话HRED

Building End-To-End Dialogue Systems Using Generative Hierarchical Neural Network Models
2015.07论文延伸AAAI 2016Serban, Sordoni, Bengio, Courville, Pineau · 蒙特利尔大学 / 麦吉尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

一句话进一句话出的Seq2Seq看不到更早的对话轮次，多轮对话容易前后脱节。

方法

在词级RNN之上再加一个句子级RNN，逐轮汇总对话历史，作为解码器的上下文，形成层次编码器-解码器。

影响

成为多轮神经对话模型的常用骨架，也引出了对话中的变分与隐变量模型。

方法

HRED把对话看作「句子序列」，每个句子又是「词序列」。第一层RNN（编码器）把每句话读成一个向量；第二层RNN（上下文RNN）按轮次读这些句向量，状态里累积整个对话历史；解码器RNN以这个上下文状态为条件逐词生成下一句。这样历史长度只增加上下文RNN的步数，而不是把所有词拼成一个超长序列。

论文还发现，用较大的问答语料先预训练、再用预训练词向量初始化，能明显提升对话模型，并讨论了这类生成模型的局限。

局限与后续

  • 生成的回复仍偏泛化、缺少多样性，因为目标仍是最大似然。
    后来针对它的工作　对话多样性MMI目标
  • 上下文向量是单一的确定状态，难以表达同一上文下回答的多种可能。
    本站还没有记录针对它的后续工作（不代表没有人解决）
