梯度提升机GBM

Greedy Function Approximation: A Gradient Boosting Machine
2001论文重要Annals of Statistics 29(5), 2001Jerome H. Friedman · Stanford University待核对
DOI ↗ESL第10章（提升与加法树） ↗在交互版中打开（演化树、学习进度）

问题

AdaBoost效果很好，但它是为二分类和指数损失量身定做的，换成回归、绝对误差或多分类就不知道该怎么“提升”，也说不清它到底在优化什么。

方法

把提升看成在函数空间里做梯度下降：每一轮算出损失对当前预测值的负梯度，用一棵小回归树去拟合它，再乘一个小步长加进模型。任何可微损失都能这样提升。

影响

给出了一套适用于任意损失的统一提升框架（GBM/TreeBoost），成为XGBoost、LightGBM等工具的算法基础，至今是表格数据上精度最高的方法家族之一。

背景

AdaBoost与集成学习按顺序训练一串弱分类器，每轮加大前一轮分错样本的权重，最后加权投票，在很多数据上比单个模型准得多。随后Friedman、Hastie和Tibshirani指出AdaBoost等价于在指数损失下逐步拟合一个加法模型，但这个视角仍局限在特定损失上。实际问题却五花八门：房价回归要平方误差，有离群点的数据要绝对误差或Huber损失，多分类要对数似然。每换一种损失就要重新推一套算法，很不方便。

方法

把模型写成很多棵小树之和：F_M(x) = F_0(x) + Σ_m ν·h_m(x)。关键观察是：要让损失L(y, F(x))变小，最直接的方向就是它对F(x)的负梯度。于是每一轮：

  • 对每个训练样本算“伪残差”r_i = −∂L(y_i, F(x_i)) / ∂F(x_i)；
  • 用一棵小回归树h_m去拟合这些伪残差（树只负责找“往哪个方向改”）；
  • 在每个叶子上再单独做一次一维搜索，找出让损失最小的输出值；
  • 乘上收缩系数ν（学习率，小于1）后加进模型。

例子：平方损失L = (y − F)²/2时，负梯度就是y − F，即普通残差，算法退化为“反复拟合残差”。绝对误差的负梯度是sign(y − F)，只看方向不看大小，所以对离群点不敏感。

这与参数空间里的梯度下降完全对应，只是每一步沿“一棵树能表示的方向”走。论文还给出解释工具：按各特征在所有树切分中带来的改进累加得到相对重要性，以及偏依赖图。

结果

论文给出了平方误差、最小绝对偏差、Huber损失回归和多分类逻辑似然四种具体算法，并把收缩系数作为主要的正则化手段来讨论：步长越小、需要的树越多，但泛化通常越好。摘要称梯度提升树对“不太干净的数据”尤其稳健、有竞争力。

后来的发展

梯度提升树在2000年代成为工业界排序、点击率预估和风控的标准工具。2016年XGBoost加入二阶近似、正则项和并行化，使它在Kaggle等竞赛的表格任务中长期占优。“用一个弱学习器拟合负梯度”的思路后来也被用到排序学习和生存分析等场景。

局限与后续

  • 每一轮都依赖上一轮的结果，只能顺序训练，原始实现在百万级以上样本上很慢。

  • 只用一阶梯度，也没有对树的复杂度加显式正则，需要靠收缩系数、树深和轮数手工控制过拟合。
    后来针对它的工作　XGBoost
  • 没有对缺失值和稀疏特征的专门处理。

它建立在什么之上

  • 使用
    决策树CART1984 · 基础
    每一轮用一棵CART回归树拟合伪残差，并在叶子上单独求最优输出。
  • 竞争
    随机森林2001 · 基础
    同年的另一种树集成：随机森林并行随机化以降方差，梯度提升顺序纠错以降偏差；精度上后者经XGBoost调优后通常更高。
  • 延续
    随机梯度下降1951 · 基础
    把梯度下降从参数空间搬到函数空间，每一步的方向由一棵树近似。
  • 延续
    弱可学习性与Boosting1990 · 基础
    延续“弱学习器组合成强学习器”的思路，但从PAC理论转向数值优化的解释。
  • 改进
    AdaBoost与集成学习1997 · 基础
    把只适用于指数损失和分类的AdaBoost推广为任意可微损失下的函数空间梯度下降。

后来的相关工作

  • 改进
    AlexNet2012.09 · 视觉
    和所有树模型一样不学特征，面对图像、语音等原始信号无能为力。
  • 改进
    XGBoost2016.03 · 基础
    沿用逐棵拟合损失梯度的框架，加入二阶导和对树复杂度的显式正则，并解决了原实现顺序慢、不支持稀疏和缺失值的问题。
  • 延续
    LightGBM2017.12 · 基础
    完全沿用GBDT的「每轮拟合负梯度」框架，只改变建树时用哪些样本和特征来估计分裂增益。
  • 延续
    CatBoost2017.06 · 基础
    在梯度提升框架上修正预测偏移问题。

读懂它需要的概念

决策树 集成学习 梯度下降 损失函数 偏差-方差权衡

本篇术语

  • 伪残差　损失函数对当前预测值的负梯度。平方损失下它就是真实值减预测值。
  • 收缩（shrinkage）　每棵新树的输出乘一个小于1的系数再加入模型，相当于学习率，步子小一些，需要更多树但泛化更好。
  • 偏依赖图　固定其他特征的分布，只改变一个特征的取值，看模型平均输出如何变化，用来解释特征的作用。

怎么学

先读决策树与梯度下降，再读AdaBoost与集成学习理解“顺序纠错”。然后看ESL第10章或原文第1–5节（算法和收缩），推导平方损失和绝对误差下的伪残差。动手：用numpy和sklearn的DecisionTreeRegressor写一个50行的梯度提升回归，再与sklearn的GradientBoostingRegressor对比。
