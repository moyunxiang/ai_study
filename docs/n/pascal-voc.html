PASCAL VOC

The PASCAL Visual Object Classes (VOC) Challenge
2005数据集延伸Mark Everingham, Luc Van Gool, Chris Williams, John Winn, Andrew Zisserman · PASCAL网络待核对
官网 ↗在交互版中打开（演化树、学习进度）

问题

物体识别研究没有公共的评测，各组各用各的图片和指标，论文里的数字互相不可比。

方法

每年发布一套带统一标注和评测脚本的图片，开放挑战赛，让各队提交结果并公开比较。

影响

它成为2005到2012年间物体检测、分类、分割的核心基准，也是R-CNN等深度检测方法最早报告成绩的数据集。

方法

PASCAL VOC（Visual Object Classes）项目提供标准化的图像数据集、访问数据和标注的通用工具，以及评测方法，并从2005年到2012年每年举办挑战赛评估物体类别识别的性能；挑战结束后，评测服务器仍然开放。2010至2012年的数据还设有排行榜，后来又加入了显著性检验，看不同提交之间的差异是否可靠。2015年的回顾论文总结了2008至2012年的经验。

它的设计让后来的基准有所依照：每年的测试集标签不公开、提交结果由服务器评分，以防研究者在测试集上调参；检测任务的评分用平均精度（AP）。这套做法被MS COCO和ImageNet的挑战赛直接沿用。

R-CNN等早期深度检测器在VOC上取得突破，之后VOC的规模与类别数（相对后来的数据集）就显得太小，让位给MS COCO。

局限与后续

  • 类别数很少、图像相对简单，性能很快饱和，难以区分最新方法的差距。

  • 数据集本身带有收集偏差，在VOC上训练的模型换到其他数据集会明显变差。

它建立在什么之上

  • 改进
    MNIST1998 · 数据·评测
    只有居中、无背景的单个灰度数字，没有真实场景中的光照、遮挡、背景杂乱和类别多样性。
  • 改进
    Caltech-101/2562004.06 · 数据·评测
    Caltech-101物体居中、背景整洁；VOC改用复杂场景中的真实照片，并要求给出物体位置。

后来的相关工作

  • 延续
    ImageNet2009.06 · 数据·评测 已核对
    PASCAL VOC只有20类；ImageNet把类别扩展到上万个。据ILSVRC综述，ILSVRC沿用了PASCAL VOC“公开数据集+年度竞赛与研讨会”的形式，维基百科称它源于与PASCAL VOC团队的合作。
  • 使用
    可变形部件模型DPM2008.06 · 视觉
    在PASCAL VOC 2006/2007上评测，证明部件模型在真实难基准上确实有效。
  • 延续
    ILSVRC挑战赛2010 · 数据·评测
    与PASCAL VOC合办前三届，把它的20类比赛扩大到1000类和上百万张图。
  • 使用
    数据集偏差2011.06 · 数据·评测
    以PASCAL VOC为主要比较对象之一，发现它是泛化最好的数据集之一。
  • 使用
    KITTI2012.06 · 数据·评测
    检测评测沿用PASCAL的50%重叠规则和平均精确率，并加上朝向相似度扩展到3D。
  • 延续
    RTE文本蕴含挑战2005 · 数据·评测
    同属PASCAL网络的挑战赛模式：公开数据、统一评测、年度竞赛，只是任务从图像换成文本。
  • 延续
    MS COCO2014.05 · 数据·评测
    沿用VOC的挑战赛评测模式，但把图片换成复杂日常场景，并把标注提升到实例分割。
  • 使用
    LSUN场景与物体库2015.06 · 数据·评测
    20个物体类与PASCAL VOC相同，并在VOC 2012上验证预训练效果。
  • 延续
    Cityscapes2016.04 · 数据·评测
    PASCAL VOC 的分割图像来自日常场景，本文改为专门的城市街景。
