Mish激活函数

Mish: A Self Regularized Non-Monotonic Activation Function
2019.08论文延伸BMVC 2020Diganta Misra · 独立研究者（Landskape）待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

ReLU在负半轴梯度恒为0，Swish等平滑激活虽然更好，但在检测、分类等任务上仍有提升空间，选择哪个激活函数主要靠试。

方法

提出平滑、非单调、下有界上无界的激活函数 f(x) = x·tanh(softplus(x))，形状与Swish相近但在负区保留更多信息。

影响

被YOLOv4的骨干网络采用而广为人知，PyTorch加入了nn.Mish，成为常用激活函数之一。

方法

Mish定义为 f(x) = x·tanh(ln(1 + eˣ))，其中 ln(1+eˣ) 是softplus。它有四个性质：x很大时近似x（上无界，避免饱和）；x很负时趋于0（下有界，起到正则作用）；在x≈−0.31附近有一个小的负值极小点（非单调，负输入也能传一点梯度）；处处光滑可导。这些和Swish/SiLU（x·sigmoid(x)）很像，作者把两者归为同一族，并从一阶导数的形状解释它为什么像一个正则器、有助于优化。

摘要报告：在保持其他结构和超参数不变的条件下，Mish在MS-COCO检测上让CSP-DarkNet-53骨干的YOLOv4比Leaky ReLU的AP50平均高2.1%，在ImageNet-1k上让ResNet-50的Top-1比ReLU高约1%。它比ReLU多算一次指数、对数和tanh，速度慢一些。

局限与后续

  • 计算比ReLU贵，部署时常要专门的融合内核；提升幅度依任务而异。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 在Transformer类大模型里主流仍是GELU与SwiGLU，Mish没有成为默认选择。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    ImageNet分类实验以ResNet-50为对象；检测实验则在后来发表的YOLOv4（2020）上补做，YOLOv4也采用了Mish。
  • 竞争
    ReLU2010 · 基础
    ImageNet上ResNet-50的对照对象。
  • 竞争
    GELU2016.06 · 基础
    同为平滑、非单调的ReLU替代品。
  • 延续
    Swish/SiLU2017.10 · 基础
    与Swish同属自门控平滑激活，把sigmoid门换成tanh(softplus)。
