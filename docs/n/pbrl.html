PBRL悲观自举离线RL

Pessimistic Bootstrapping for Uncertainty-Driven Offline Reinforcement Learning
2022.02论文延伸ICLR 2022Chenjia Bai, Lingxiao Wang, Zhuoran Yang, Zhihong Deng, Animesh Garg, Peng Liu, Zhaoran Wang · 哈工大 / Northwestern / Princeton / Toronto待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL的主流做法要么压低分布外动作的Q值，要么约束策略靠近行为策略，都会妨碍价值函数在数据外的泛化，也说不清楚哪些数据算“分布外”。

方法

完全靠不确定性做悲观：训练一组自举Q网络，用它们之间的分歧当作不确定性，在TD目标里减去与不确定性成正比的惩罚；再专门采样分布外动作施加更强惩罚。

影响

把线性MDP里“悲观值迭代”的理论思想落到深度离线RL上，与EDAC一起代表“基于不确定性、无显式策略约束”的路线。

方法

理论上，离线RL的悲观原则（见PEVI悲观值迭代）是：在估计价值时减去一个不确定性项，数据覆盖少的地方减得多。PBRL（Pessimistic Bootstrapping for offline RL）把这个原则用深度网络实现：

  • 训练K个独立初始化的Q网络（类似Bootstrapped DQN），它们在数据覆盖充分的地方意见一致，在数据稀少处分歧大，用标准差 U(s, a) = Std_k Q_k(s, a) 作为不确定性；
  • 对数据内转移，TD目标变成 y = r + γ(Q_k(s′, a′) − β_in·U(s′, a′))；
  • 为了直接约束分布外区域，再从当前策略采样分布外动作 a_ood，让它们的Q值回归到 Q_k(s, a_ood) − β_ood·U(s, a_ood)，并让β_ood随训练逐渐减小。

这样不需要估计行为策略，也没有显式的策略约束。作者证明在线性MDP里这种自举分歧与LSVI式的不确定性量化相当，因此给出了理论依据。摘要称在D4RL上优于当时的最好算法。

局限与后续

  • 需要维护一组Q网络并额外采样分布外动作，计算开销比单网络方法大。

它建立在什么之上

  • 使用

    CQL压低所有分布外动作；PBRL按不确定性大小有区别地惩罚。

    PEVI悲观值迭代2020.12 · RL
    把线性MDP里减去不确定性项的悲观值迭代推广到深度网络。

    EDAC/SAC-N集成离线RL2021.10 · RL
    EDAC靠大集成取最小值隐式惩罚；PBRL显式减去标准差惩罚并额外采样分布外动作。
