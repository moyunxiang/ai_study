MLE-bench

MLE-bench: Evaluating Machine Learning Agents on Machine Learning Engineering
2024.10数据集延伸ICLR 2025Chan, Chowdhury, Jaffe, Aung, Sherburn, Mays, Starace, Liu et al. · OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

现有智能体评测很少考察机器学习工程本身：训练模型、准备数据、做实验。

方法

从Kaggle挑出75个机器学习竞赛，用公开排行榜建立人类基线，用奖牌门槛衡量智能体。

影响

首次把「AI做机器学习工程」量化：o1-preview加AIDE脚手架在16.9%的竞赛中至少达到铜牌水平。

方法

MLE-bench选取75个与机器学习工程相关的Kaggle数据竞赛竞赛，任务包括训练模型、预处理数据、跑实验。每个竞赛的人类基线来自Kaggle公开排行榜，智能体得分换算成奖牌等级。

作者用开源智能体脚手架评测多个前沿模型，最好的组合是OpenAI的o1-preview加AIDE脚手架，在16.9%的竞赛中至少达到铜牌水平。论文还研究了资源扩展（更多尝试次数、更长时间）对成绩的影响，以及预训练数据污染的影响，并开源了代码。它延续SWE-bench的思路，把评测从修Bug推向机器学习研发，后来的RE-Bench和PaperBench沿着这条线继续。

局限与后续

  • 题目来自公开竞赛，可能已在模型训练数据里；Kaggle铜牌只是低门槛，不等于真实研究能力。
