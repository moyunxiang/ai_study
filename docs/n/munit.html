MUNIT多模态翻译

Multimodal Unsupervised Image-to-Image Translation
2018.04论文延伸ECCV 2018Xun Huang, Ming-Yu Liu, Serge Belongie, Jan Kautz · 康奈尔大学 / NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

无配对的图像翻译（如CycleGAN）把转换当成一对一的确定映射：一张猫的照片只能变成一种狗，而真实情况是同一张图在目标域里可以有许多种合理样子。

方法

假设图像可以拆成跨域共享的“内容码”和各域特有的“风格码”；翻译时保留原图的内容码，再从目标域随机采样一个风格码，用AdaIN任意风格迁移把风格注入解码器，就能得到多种不同输出。

影响

“内容/风格解耦+AdaIN注入风格”的结构成为多模态图像翻译的标准设计，影响了后续的DRIT、StarGAN v2与FUNIT等工作，也和StyleGAN同样体现了用AdaIN控制风格的思路。

方法

每个域有一个自编码器，编码器分成两支：内容编码器输出一个保留空间结构的特征图（内容码c），风格编码器输出一个低维向量（风格码s）。解码器用残差块处理内容码，再用一个多层感知机把风格码变成AdaIN任意风格迁移的缩放和偏移参数，注入每一层，把内容“画成”某种风格。

要把图像x₁从域1翻到域2：取x₁的内容码c₁，从域2的风格先验（标准高斯）里随机采一个s₂，用域2的解码器生成G₂(c₁, s₂)。每采一个不同的s₂就得到一种不同的结果；也可以从一张参考图里编码出风格码，实现“按示例换风格”。

训练损失包括：每个域内的图像重建损失；隐码重建损失（翻译出的图再编码回去，内容码要等于c₁、风格码要等于s₂），它取代了图像级的循环一致损失；以及让翻译结果在目标域里看起来真实的对抗损失。论文在边缘图↔鞋包、猫↔狗、夏↔冬等任务上，与此前方法比较了质量和多样性。

局限与后续

  • 每对域要单独训练一组编码器和解码器，扩展到很多域时不如单模型方案方便。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 内容码只是假设跨域共享，在形状差别大的域（如猫和狗的整体轮廓）之间转换时结构常常保留不好。

读懂它需要的概念

对抗训练 自编码器 潜空间 归一化层 高斯分布

本篇术语

  • 多模态翻译　同一张输入图可以翻译成目标域里许多种不同但都合理的结果，“多模态”指输出分布有多个峰。
  • 风格码　一个低维向量，描述颜色、纹理等域内可变的外观因素，与描述结构的内容码分开。

怎么学

先读AdaIN和CycleGAN → 读本文第3节的模型图和三类损失 → 在边缘图到鞋子任务上固定内容、换风格码观察输出。
