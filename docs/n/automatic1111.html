AUTOMATIC1111 WebUI

2022.08系统延伸AUTOMATIC1111（匿名开发者）及社区 · 开源项目待核对
GitHub ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

Stable Diffusion开源刚开源时只能通过命令行或Colab笔记本使用，普通用户难以上手。

方法

用Gradio做成网页界面，把文生图、图生图、修补、放大、嵌入训练等功能集成在一起，并开放插件。

影响

成为本地运行Stable Diffusion最流行的界面，插件生态使LoRA、ControlNet等新技术一出现就能被大众使用。

方法

据维基百科，AUTOMATIC1111 Stable Diffusion Web UI于2022年8月22日发布到GitHub，即Stable Diffusion发布一个月后。按项目README，它提供txt2img和img2img、局部重绘与外延绘制、用括号语法调节词权重、批量与X/Y/Z参数对比图、文本反演训练、人脸修复与多种放大器、生成参数写入PNG元数据以便复现，并支持4GB显存的显卡。

后续通过扩展机制，社区把ControlNet、LoRA微调扩散模型等都做成插件。2023年起，节点式界面ComfyUI节点工作流成为另一个主要选择。
