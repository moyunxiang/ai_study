《动手学深度学习》

Dive into Deep Learning
2019思想延伸Aston Zhang、Zachary Lipton、Mu Li、Alex Smola 等待核对
Dive into Deep Learning ↗在交互版中打开（演化树、学习进度）

问题

深度学习教材要么偏理论、没有代码，要么只教调用框架，缺少把原理、代码和讨论放在一起的开放教材。

方法

《动手学深度学习》是一本开源交互式教材，每一章同时包含数学讲解、可运行代码和论坛讨论。

影响

成为中文和英文世界最常用的深度学习入门教材之一，被大量高校课程采用。

方法

据官网，这本书把数学、代码和讨论合在一起，代码有PyTorch、NumPy/MXNet、JAX和TensorFlow多个版本。官网称它被70个国家的500所大学采用，剑桥大学出版社将出版英文纸质版，中文版则是国内最大线上书店的畅销书。

内容由浅入深：先讲线性回归和反向传播，再到卷积网络、循环网络、注意力和Transformer，并逐步加入了强化学习、高斯过程和超参数优化等主题。读者可以直接在笔记本里修改并运行每一段代码。

后来的发展

它与斯坦福CS231n、吴恩达公开课与Coursera一起成为自学深度学习的三条主要路径，并在大模型时代继续更新，加入了视觉Transformer和大规模预训练等章节。

局限与后续

  • 教材更新速度赶不上大模型时代，近年的后训练、推理模型和智能体等主题覆盖有限。
