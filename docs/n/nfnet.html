NFNet无归一化网络

High-Performance Large-Scale Image Recognition Without Normalization
2021.02论文延伸ICML 2021Andrew Brock, Soham De, Samuel L. Smith, Karen Simonyan · DeepMind待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

Batch Normalization依赖批大小、让样本之间相互影响，带来许多麻烦；Fixup无归一化初始化等工作已能不用归一化训练深层ResNet，但精度比不上最好的BN网络，而且在大学习率或强数据增强下容易不稳定。

方法

提出自适应梯度裁剪（AGC）：按“梯度范数与参数范数之比”逐单元裁剪梯度，压住无归一化网络在大学习率下的不稳定；再配合缩放权重标准化和精心设计的结构，得到一族无归一化的NFNet。

影响

首次让无归一化的图像分类网络在ImageNet上达到当时最好精度、且训练快于EfficientNet，有力回应了“没有BN就训不好”的看法；AGC也被后来的一些大模型训练当作稳定化手段借鉴。

方法

去掉BN后，残差网络的激活尺度会随深度增长。作者沿用同组此前的做法：每个残差分支写成 h_{i+1} = h_i + α·f_i(h_i/β_i)，β_i是按理论推算的输入标准差，α是控制残差累加速度的小常数，并对卷积权重做缩放的权重标准化WS，使各层激活在初始化时保持合适的尺度。

仅靠这些，网络在大批量、大学习率和强数据增强下仍会发散。核心改进是AGC：对每个输出单元，计算梯度范数与对应权重范数之比 ‖G_i‖/‖W_i‖，超过阈值λ就把梯度按比例缩小。它的直觉是：一步更新不应该把权重改变超过其自身大小的一定比例。与梯度裁剪按全局梯度范数裁剪不同，AGC是逐单元、相对于参数大小的。

摘要报告：较小的NFNet与EfficientNet-B7在ImageNet上测试精度相当，而训练快最多8.7倍；最大的模型达到86.5%的top-1精度，创当时新高；在3亿张有标注图像上预训练后再在ImageNet上微调时，NFNet明显好于带BN的对应模型，最好达到89.2%。

局限与后续

  • 需要按网络结构推算缩放常数，并额外调AGC阈值，换一种结构就要重新推导；训练稳定性依赖强正则化和精心的超参数组合。

    梯度裁剪2012.11 · 基础
    把按全局范数裁剪梯度改为按每个单元的梯度与参数范数之比自适应裁剪。
  • 改进
    Fixup无归一化初始化2019.01 · 基础
    此前的无归一化ResNet精度不及最好的BN网络、大学习率下不稳定；NFNet用AGC解决了不稳定并追上精度。
  • 使用
    权重标准化WS2019.03 · 基础

读懂它需要的概念

归一化层 残差连接 梯度裁剪 参数初始化 范数与距离

本篇术语

  • 自适应梯度裁剪　按每个单元“梯度大小相对于权重大小”的比例来决定是否裁剪，权重越小允许的更新越小。

怎么学

先读Fixup无归一化初始化和梯度裁剪；读论文第3节AGC的定义与消融；在一个去掉BN的ResNet上分别用全局梯度裁剪与AGC训练，用较大学习率观察哪个不发散。
