《Perceptrons》与XOR问题

Perceptrons: An Introduction to Computational Geometry
1969思想重要MIT Press 1969Marvin Minsky, Seymour Papert · MIT待核对
Wikipedia: Perceptrons (book) ↗MIT Press（1988扩充版） ↗在交互版中打开（演化树、学习进度）

问题

1960年代的感知机被媒体和发明者描绘得几乎无所不能，但它到底能算什么、不能算什么，没有人做过严格的数学分析。

方法

把感知机形式化为“一层局部特征 + 一个线性阈值输出”，用几何与代数证明：在每个特征只看输入一小块的限制下，奇偶性、图形连通性这类需要全局信息的判断做不到，或者所需代价随输入规模增长。

影响

第一次把神经网络的能力边界变成定理，XOR成为“单层网络不行”的标志性例子；它也被普遍认为加速了神经网络研究经费的退潮，直到1980年代多层网络和反向传播复兴。

背景

感知机在1958年发布后备受关注。它有一条漂亮的收敛定理：只要任务能被它的参数表达，有限次修正就一定能学会。媒体报道和Rosenblatt本人的说法让人相信神经网络很快就能看懂图像、下棋。与此同时，达特茅斯会议之后兴起的符号主义路线与神经网络路线在争夺经费、人才和稀缺的计算资源。

Minsky和Papert都在MIT，属于符号主义一方（Minsky与Rosenblatt是中学校友，两人在会议上争论激烈，私交却不坏）。Papert 1963年到MIT后，两人决定为感知机的局限写一份理论分析，本以为很快能完成，结果解决中途冒出来的数学问题花了六年。

方法

研究对象。书中的“感知机”是Rosenblatt模型的抽象版本：一张“视网膜”（二值像素网格），上面有一层固定的特征检测器φ_i，每个只看视网膜的一部分；输出单元把这些特征加权求和，超过阈值就输出1：

ψ(X) = 1 当且仅当 Σ_i w_i·φ_i(X) > θ

只有输出层的权重w_i是可学的。一个特征最多连接的像素数叫这个感知机的阶（order）。

XOR：单个线性单元的极限。最简单的例子是两个输入的异或：(0,0)→0、(1,1)→0、(0,1)→1、(1,0)→1。在平面上，两个正例和两个负例分别在正方形的两条对角线上，不存在一条直线把它们分开，所以没有任何w₁x₁ + w₂x₂ > θ能实现它（见多层感知机）。加一个“x₁ AND x₂”的特征就能解决——但这要求某个特征同时看到两个输入。

奇偶性与连通性：局部特征的极限。把XOR推广到n个像素，就是判断“亮着的像素数是奇数还是偶数”。书中证明，要计算奇偶性，至少有一个特征必须连接全部n个像素；判断一个图形是否连通，所需的阶也随视网膜尺寸增长。也就是说，只靠“很多局部小检测器 + 一个线性组合”，这类全局性质算不出来，或代价随规模爆炸。

它没有证明的事。多层的阈值网络能算任何布尔函数，这一点从M-P神经元起就是已知的，书里也提到。书的结论针对的是带局部性限制、只有一层可学权重的结构；但书末对多层网络的前景表达了悲观的猜测，认为没有理由相信推广会有出路。

后来的发展

书出版后，神经网络研究的经费和关注度大幅下降，常被视为第一次AI寒冬的成因之一（这一因果关系至今有争议：也有人认为退潮主要因为感知机本身的进展停滞和当时的算力限制）。Minsky同年获得图灵奖（Minsky获图灵奖）。

书里留下的真正问题——多层网络中间层的权重怎么学——在1986年由反向传播给出了实用的答案，用一个隐藏层就能学会XOR；《并行分布式处理》丛书则直接回应了这本书的批评。1988年的扩充版加了序言和后记讨论这场复兴，但没有新的科学结果；2017年重印版由Léon Bottou作序，从深度学习的角度重新评价了它。今天它的“阶”和局部性分析，在研究卷积网络感受野和Transformer能否计算奇偶性等问题时仍被引用。

容易误解的地方

  • 常见说法“这本书证明了神经网络连XOR都做不到”是不准确的。单个线性单元做不到XOR是显而易见的事实；书的核心定理是关于局部特征的阶，并且作者知道多层网络能计算任何布尔函数。
  • 真正卡住当时研究的不是“多层网络不能表达”，而是“没有好方法训练多层网络的中间层”。

局限与后续

  • 分析只针对一层可学权重、特征固定的结构，对多层网络只给出了悲观的猜测，没有分析怎样训练中间层。

  • 多层网络到底能表达多少函数，书中没有回答。

它建立在什么之上

  • 竞争
    达特茅斯会议1956.06 · 事件
    作者是达特茅斯之后符号主义路线的核心人物，这本书也是两条路线争夺资源的一部分。
  • 延续
    感知机1958 · 基础
    对感知机做了第一次严格的能力分析：证明单层、局部特征的感知机算不了奇偶性、判断不了连通性，把它的收敛定理放进了“能表达什么”的边界之内。
  • 使用
    M-P神经元1943 · 基础
    借用M-P阈值单元的形式化；书中也承认，按M-P的结论，多层阈值网络可以计算任何布尔函数。
  • 竞争
    ADALINE与LMS1960 · 基础
    同属1960年代的线性阈值学习器；ADALINE用最小均方误差训练，同样只能学单层权重，同样受线性可分性的限制。

后来的相关工作

  • 改进
    反向传播1986 · 基础 已核对
    Minsky和Papert指出单层网络算不了XOR且不知如何训练多层网络；反向传播给出了训练隐藏层的通用方法。
  • 改进
    反向模式自动微分1970 · 系统·效率
    《Perceptrons》之后多层网络缺少可行的训练方法；反向模式提供了所需的高效求梯度工具，只是要到1980年代才被用上。
  • 竞争
    VC维与一致收敛1971 · 基础
    两者都在问“一类模型的能力边界在哪”：Minsky和Papert问能否表达某个函数，VC理论问从有限样本能否可靠地学会。
  • 延续
    第一次AI寒冬1973 · 事件
    《Perceptrons》揭示单层网络的局限，而多层网络无法训练，神经网络路线的经费随之枯竭。
  • 改进
    Neocognitron1980 · 视觉
    书中提出的局部性困境（局部特征算不出全局性质）没有给出建设性方案；后来是“局部连接 + 多层堆叠”让感受野逐层扩大，才把局部和全局结合起来。
  • 改进
    《并行分布式处理》1986 · 基础
    用带隐藏单元的多层网络加反向传播，回应了《Perceptrons》指出的单层网络算不了XOR、奇偶性等问题。
  • 改进
    卷积网络识别邮编1989 · 视觉
    书中提出的局部性困境（局部特征算不出全局性质）没有给出建设性方案；后来是“局部连接 + 多层堆叠”让感受野逐层扩大，才把局部和全局结合起来。
  • 改进
    万能近似定理1989 · 基础
    《Perceptrons》指出单层感知机表示能力有限（如XOR）；本文证明只加一层隐藏层，表示能力就不再受限。
  • 延续
    Minsky获图灵奖1969 · 事件
    同年他与Papert出版《Perceptrons》，其结论影响了此后十余年神经网络研究。
  • 改进
    Werbos博士论文1974 · 基础
    分析只针对一层可学权重、特征固定的结构，对多层网络只给出了悲观的猜测，没有分析怎样训练中间层。
  • 改进
    Jordan循环网络1986.05 · 基础
    单层感知机和普通前馈网络没有时间维度，这里通过输出反馈使网络能处理序列。

读懂它需要的概念

神经元与激活函数 多层感知机 命题逻辑、谓词逻辑与符号推理 内积与余弦相似度

本篇术语

  • 线性可分　存在一个超平面能把正例和负例完全分到两侧。单层感知机只能学会线性可分的问题。
  • 感知机的阶　书中定义的复杂度：所有特征检测器中，连接输入像素最多的那个所连的像素数。阶越高，需要的“全局”信息越多。
  • 奇偶性谓词　判断二值输入里1的个数是奇数还是偶数。两个输入时就是XOR。

怎么学

先理解感知机的学习规则。然后在纸上画出XOR的四个点，确认无法用一条直线分开；再手工构造一个两层网络（隐藏层两个单元分别算OR和NAND，输出层算AND）实现XOR。之后读维基百科“Perceptrons (book)”中“The XOR affair”一节，理解围绕这本书的争议。
