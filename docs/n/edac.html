EDAC/SAC-N集成离线RL

Uncertainty-Based Offline Reinforcement Learning with Diversified Q-Ensemble
2021.10论文延伸NeurIPS 2021Gaon An, Seungyong Moon, Jang-Hyun Kim, Hyun Oh Song · 首尔大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

离线RL主流做法要么估计行为策略再加约束，要么专门采样分布外动作来压低Q值，这些步骤本身就不容易做准，而且容易把策略压得离数据太近。

方法

发现只要把SAC的Q网络数量加到几十个、目标取它们的最小值（记作SAC-N），就能自动压低不确定性大的分布外动作的Q值；再加一项让各Q网络梯度彼此分散的正则，把所需网络数降到十分之一左右（EDAC）。

影响

SAC-N和EDAC成了「基于不确定性」一类离线RL的代表基线，CORL、OfflineRL-Kit等库都收录，后续的RORL、PBRL等常拿它们比较。

方法

在线RL里常用的“截断双Q”（取两个Q估计的最小值）本来是为了对付高估。论文观察到：如果把Q网络增加到N个、目标取N个里的最小值 y = r + γ (min_j Q_j(s′, a′) − α log π(a′|s′))，那么在数据覆盖到的动作上各网络意见一致，最小值和均值差不多；在数据没见过的动作上各网络分歧很大，最小值就会被拉得很低。这样不需要估计行为策略、也不需要专门生成分布外动作，就自动形成了与不确定性成正比的惩罚。这个直接把SAC的评论家数加大的做法叫SAC-N，论文在D4RL上用N从10到500不等。

N太大计算代价高。论文分析发现，若各Q网络对动作的梯度方向很相似，分布外动作上的分歧就不够大，需要更多网络才能起作用。于是EDAC加了一项多样化正则：最小化不同Q网络关于动作的梯度两两之间的余弦相似度，迫使它们在数据外“意见不同”。摘要称这样把所需的网络数降到朴素集成的约十分之一，并在所考察的大多数D4RL任务上取得当时最好成绩。

局限与后续

  • 需要几十个Q网络并行训练，显存和算力开销远大于单策略约束方法，在大网络或图像输入上不容易扩展。
    后来针对它的工作　ReBRAC重访极简离线RL
  • 惩罚强度靠网络数N间接控制，不同数据集上最合适的N相差很大，仍要逐个调。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    SAC2018.01 · RL
    直接在SAC上把评论家数从2个加到N个，目标取最小值，就是SAC-N。
  • 改进
    BEAR自举误差约束2019.06 · RL
    BEAR需要估计行为策略并做分布约束，EDAC完全不估计数据分布。
  • 使用
    D4RL离线RL基准2020.04 · RL
    在D4RL的MuJoCo和Adroit数据集上评测。
  • 竞争
    离线强化学习CQL2020.06 · RL
    CQL要显式采样分布外动作并压低其Q值；EDAC改用集成分歧隐式惩罚，不需要采样。
  • 竞争
    REDQ随机集成双Q2021.01 · RL
    REDQ在在线RL里用大集成取子集最小值提高样本效率，EDAC把类似的集成取小用于离线下的保守估计。
  • 改进
    UWAC不确定性加权2021.05 · RL
    MC Dropout给出的不确定性往往偏小且校准不佳，在高维连续动作下对分布外区域的识别不够可靠。

后来的相关工作

  • 竞争
    PBRL悲观自举离线RL2022.02 · RL
    EDAC靠大集成取最小值隐式惩罚；PBRL显式减去标准差惩罚并额外采样分布外动作。
  • 竞争
    ReBRAC重访极简离线RL2023.05 · RL
    EDAC靠几十个Q网络的集成做保守估计；ReBRAC不用集成，在多数任务上接近或超过它，开销小得多。

读懂它需要的概念

离线强化学习 Actor-Critic与优势函数 集成学习 分布偏移

本篇术语

  • SAC-N　把SAC的两个Q网络换成N个、目标取最小值的离线RL基线。
  • 分布外动作（OOD）　数据集中这个状态下从没出现过的动作，网络在它上面的Q值没有数据约束。

怎么学

先读离线强化学习CQL和TD3的截断双Q；读原文第3–4节看N增大时分布外动作Q值的变化和梯度多样化正则；用CORL里的SAC-N在halfcheetah-medium上试N=2、10、50的差别。
