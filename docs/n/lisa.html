LISA推理分割

LISA: Reasoning Segmentation via Large Language Model
2023.08论文延伸CVPR 2024Xin Lai, Zhuotao Tian, Yukang Chen, Yanwei Li, Yuhui Yuan, Shu Liu, Jiaya Jia · CUHK / 微软亚研等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统分割需要事先给定类别或明确指令，不能理解“图里哪个东西最适合保存食物”这种隐含意图。

方法

提出“推理分割”任务，并让多模态大模型输出一个特殊的<SEG>词元，其隐藏状态直接解码成分割掩码。

影响

把多模态大模型的语言推理与像素级输出连起来，催生一批“用语言指令做分割”的工作。

方法

推理分割的任务是：给定复杂、隐含的文字查询，输出对应物体的分割掩码。LISA在多模态大模型（LLaVA式）的词表里新增一个<SEG>词元。回答时，当模型生成<SEG>，就取它最后一层的隐藏向量，经小的投影后，作为提示送入分割解码器（采用Segment Anything的解码器），由后者生成掩码，称为“embedding-as-mask”。

论文还建立了包含一千多条图像-指令-掩码样本的评测集。作者称，只用不含推理的分割数据训练就具备零样本推理分割能力，再用239条推理分割样本微调还能进一步提升。

局限与后续

  • 每次只输出少量掩码，复杂场景下多目标、多轮分割能力有限。
