LayerDiffuse透明图层生成

Transparent Image Layer Diffusion using Latent Transparency
2024.02论文延伸SIGGRAPH 2024Lvmin Zhang, Maneesh Agrawala · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文生图模型只能生成不透明的RGB图，设计师要透明背景的素材只能先生成再抠图，边缘和半透明部分（头发、玻璃）效果很差。

方法

学习一个“潜在透明度”：把alpha通道编码成预训练潜空间里的一个小偏移，尽量不改变原有潜分布，这样任何潜扩散模型微调后都能直接生成透明图或多个透明图层。

影响

97%的情况下用户更喜欢它原生生成的透明内容而非先生成再抠图，成为ComfyUI等工具里生成透明素材的常用插件。

方法

如果直接给VAE加一个alpha通道，潜空间的分布会变，大模型原有的画质就毁了。LayerDiffuse的做法是：训练一个小编码器把透明度信息变成潜空间里的偏移量，加到原图的潜变量上，并约束这个偏移尽量小，使加了透明度的潜变量仍落在原模型熟悉的分布里；再训练一个解码器从潜变量中还原RGBA。随后用这种调整过的潜空间微调扩散模型，它就学会生成“带透明度”的潜变量。

训练数据是用人机协作流程收集的100万对透明图层。同一框架还能做前景条件生成背景、背景条件生成前景、联合生成多个图层，并能与ControlNet等控制方式结合。

局限与后续

  • 图层数量和图层之间的遮挡关系仍需人工规划，复杂多层合成时各层光照与透视不一定一致。
