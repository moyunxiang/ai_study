EvoLM全流程训练动态

EvoLM: In Search of Lost Language Model Training Dynamics
2025.06论文延伸NeurIPS 2025 OralZhenting Qi, Fan Nie, Alexandre Alahi, James Zou, Himabindu Lakkaraju, Yilun Du, Eric Xing, Sham Kakade, Hanlin Zhang · 哈佛大学、斯坦福大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

如今的语言模型要经过预训练、续训、SFT、RL多个阶段，各阶段设计选择对最终能力的影响很难单独评估，公开模型又只给最终权重。

方法

从头训练100多个1B和4B模型，系统改变每一阶段的数据量和配置，在同一套评测下观察能力怎样随阶段演化。

影响

给出了“预训练和后训练都有收益递减”“续训是连接预训练与后训练的关键”等可复现结论，并开放全部模型、数据和流程。

背景

Pythia为预训练阶段提供了可分析的模型套件，但后来模型的能力越来越依赖后训练：Tülu 3开放后训练这类工作公开了SFT和RL配方，却只在某一个基座上做。开发者想知道“多加预训练token还是多做RL”“领域续训会不会把通用能力忘掉”，缺少在同一条件下跨阶段的对照。

方法

EvoLM在1B和4B两个规模上，从头预训练不同token数的模型（覆盖从Chinchilla最优到明显过训练），再在其上分别做不同强度的领域续训（如数学）、不同数据量和轮数的指令微调与对话模板，最后做不同步数的强化学习。所有模型统一评测上游的语言建模损失和下游的解题能力，并区分领域内与领域外泛化。这样就能画出“某一阶段的投入 → 最终能力”的曲线，看到收益在哪里饱和、哪些组合会相互抵消。

结果

摘要列出的主要结论：过度的预训练和后训练都出现收益递减；领域续训会造成遗忘，需要专门的缓解做法；续训在连接预训练和后训练之间起关键作用；SFT与RL的配置之间存在多种复杂权衡。作者开放了全部预训练与后训练模型、各阶段训练数据和完整的训练评测流程。

后来的发展

它是少数把“预训练到RL”整条链路放在一起做对照实验的开放研究，入选NeurIPS 2025口头报告，可作为研究训练阶段分工的公共试验台。

局限与后续

  • 规模只到4B，结论能否外推到百亿以上的前沿模型和更长的RL训练尚不确定。

它建立在什么之上

  • 使用
    DeepSeek-R12025.01 · 推理·智能体
    后训练阶段采用面向推理的强化学习，研究其与预训练投入的关系。
  • 使用
    Chinchilla2022.03 · LLM
    以算力最优token数为参照，研究过训练带来的收益递减。
  • 延续
    Pythia2023.04 · LLM
    把可分析的开放模型套件从预训练阶段扩展到续训、SFT和RL全流程。
  • 延续
    Tülu 3开放后训练2024.11 · LLM
    Tülu 3公开了后训练配方，EvoLM在多个基座上系统比较后训练投入。

读懂它需要的概念

预训练与微调 幂律与规模定律 指令微调与对话模板 持续学习与灾难性遗忘 泛化与过拟合

怎么学

先读Pythia了解模型套件的用法；读EvoLM各阶段结论的小节；动手：下载其中两个不同预训练token数的基座，用同一SFT数据微调，比较领域外任务的差异。
