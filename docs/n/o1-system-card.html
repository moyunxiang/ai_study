OpenAI o1 System Card

问题

OpenAI o1推理模型用大规模强化学习训练模型先写长思维链再作答。推理能力变强既可能让模型更好地理解安全规则，也可能带来新的风险，例如更强的危险能力或在思维链中出现欺骗，需要一份系统的安全评估。

方法

在发布前对o1和o1-mini做全面的安全测试：标准的有害内容与越狱评测、外部红队、按OpenAI准备度框架对网络安全、生物化学、说服力和模型自主性等风险类别打分，并检查思维链是否存在欺骗。

影响

成为推理模型时代安全报告的范本之一，较完整地展示了思维链既能用于安全（审慎对齐），又需要被监控；其中的外部评估结果也是后来关于模型图谋的讨论的重要来源。

方法

按摘要，o1系列用大规模强化学习训练，在回答前先进行链式推理。这让模型在面对可能不安全的提示时，可以在上下文中对照OpenAI的安全政策进行推理，即审慎对齐。系统卡称，这使它在生成违法建议、选择刻板回答、被已知越狱攻破等风险基准上达到了当时的最好水平。

报告的主要内容：

  • 安全评测：不允许内容、越狱鲁棒性、过度拒绝、幻觉、偏见等，与GPT-4o等此前模型对比。
  • 外部红队：邀请外部专家和机构测试，例如上下文中的图谋的研究方Apollo Research评估了模型在给定目标下暗中违背开发者意图的倾向，METR评估了自主能力。
  • 思维链欺骗监控：用一个监控模型检查思维链中是否存在有意误导用户的推理，报告了被标记的比例和类型。
  • 准备度框架评估：在网络安全、化学生物、说服、模型自主性四类风险上给出“低/中/高/严重”的风险等级，并据此决定能否部署。

摘要的总结是：训练模型先推理再回答有可能带来显著收益，但也因能力增强而增加潜在风险，需要稳健的对齐方法、大量压力测试和细致的风险管理。

局限与后续

  • 评测由开发方主导，思维链对外不完全公开，外部研究者难以独立核实；思维链监控依赖思维链忠实反映模型推理，这一前提本身尚未被证实。
