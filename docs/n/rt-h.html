RT-H动作层级

RT-H: Action Hierarchies Using Language
2024.03论文延伸Belkhale, Ding, Xiao, Sermanet, Vuong, Tompson, Chebotar, Dwibedi, Sadigh · Google DeepMind / Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

任务越多样（如“拿可乐”和“倒杯子”），语言条件策略越难在任务间共享数据，需要更多示范。

方法

在高层任务和低层动作之间插入一层“语言动作”（如“手臂向前移动”），先预测这层描述再预测动作。

影响

迫使策略学到各任务共有的低层运动结构，并允许人在语言层面纠正机器人。

方法

RT-H建立在RT-2与VLA之上，把策略拆成两步：先根据任务描述和图像预测一句细粒度的运动描述（语言动作，如“move arm forward”），再根据这句话和图像预测机器人动作。两步用同一个视觉语言模型完成。

作者的观点是，语言动作把“看似不同的任务”映射到相同的低层动作词汇上，从而让数据在更多任务之间共享；运行时人还可以直接用语言纠正中间的动作描述，纠正后的数据又可以回流训练。

后来的发展

它提出的语言作为中间层思想，与Figure Helix的双系统和Gemini Robotics中的具身推理链相通，影响后来VLA中引入中间推理步骤的做法。
