RL²元强化学习

RL$^2$: Fast Reinforcement Learning via Slow Reinforcement Learning
2016.11论文重要arXiv 2016（ICLR 2017投稿）Duan, Schulman, Chen, Bartlett, Sutskever, Abbeel · UC Berkeley / OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度RL学一个新任务要几万局试错，动物却几次尝试就能学会；人手设计的“快速”学习算法（如老虎机算法）又只适用于特定的问题类别。

方法

不去设计快速学习算法，而是把它学出来：让一个循环网络在一组随机生成的任务上反复训练，它的权重用慢速RL更新，隐状态跨回合保留，在新任务里靠隐状态本身完成“快速学习”。

影响

确立了“上下文中的强化学习”（in-context RL）这一思路：学习过程本身由网络的前向计算实现，后来的算法蒸馏与上下文RL、AdA人类时间尺度适应直至大模型的上下文学习讨论都以它为起点之一。

背景

到2016年，DQN（Nature版）学一款游戏要几千万帧，每个任务都从零开始。人类玩新游戏几分钟就能上手，因为我们带着大量关于世界的先验，并且会有策略地试探。另一边，强化学习理论里早有针对特定问题的“快速”算法：多臂老虎机有Gittins指数、UCB1、Thompson采样的复兴，小型MDP有后验采样（PSRL），它们在探索与利用之间（见探索与利用）做得接近最优，但都是人针对一类问题手工推导的。

同一年，监督学习领域出现了“学会学习”的元学习工作（见元学习），如匹配网络与小样本学习用少量样本识别新类别。问题是：能不能把这种思路推广到需要自己探索的强化学习？

方法

把任务分布当作训练集。先定义一族MDP（例如“臂数为k、每臂中奖概率随机的老虎机”或“随机生成的迷宫”）。每次训练采样一个MDP，让智能体在其中连续玩n个回合，这n个回合合称一次“试验”（trial）。目标是最大化整个试验的总回报，而不是单个回合的回报。

网络结构。策略是一个GRU循环网络（见循环网络与隐状态），每步输入(当前观测, 上一步动作, 上一步奖励, 回合是否结束)，输出动作分布。关键在于：隐状态在同一试验的多个回合之间不清零，只在换到新的MDP时才重置。于是网络可以在隐状态里记下“哪个臂好像更好”“目标在迷宫哪里”。

两层学习。外层的“慢”RL用TRPO（配GAE式的优势估计）在大量MDP上更新网络权重；内层的“快”RL没有任何梯度更新——它就是网络在新MDP里的前向运算，由隐状态的变化完成。因为目标是整个试验的回报，网络被迫学会先花几次尝试去探索、再转向利用，相当于自己学出了一个探索-利用策略。

结果

在随机生成的多臂老虎机上（k取5、10、50，n取10、100、500），RL²的累计回报几乎与Gittins指数、UCB1、Thompson采样这些专门设计的算法一样好。在随机表格MDP上，回合数少（n=10）时它明显优于PSRL等方法，但n增大到100时优势反转，作者认为是外层RL难以优化更长的试验。在ViZDoom中的视觉迷宫导航上，智能体在第一回合探索找到目标后，第二回合的路径明显变短，并能部分推广到更大的9×9迷宫；但它偶尔会“忘掉”目标位置而重新探索。

后来的发展

DeepMind几乎同时发表了思路相同的“Learning to reinforcement learn”。几个月后MAML元学习提出了另一条路线：不靠循环网络记忆，而是学一个好的初始参数、在新任务上做几步梯度下降。基于记忆的路线后来通过算法蒸馏与上下文RL（用Transformer模仿整个学习过程）和AdA人类时间尺度适应（在开放式任务空间中做到人类时间尺度的适应）延续；DiscoRL：元学习发现RL算法则把“学出RL算法”推进到让元学习直接发现新的更新规则。

局限与后续

  • 外层用on-policy的TRPO优化很长的试验，回合数一多就学不好，在表格MDP上n增大时反被手工算法超过。

  • 只能在训练分布内的任务上快速学习，换到分布外的任务（如更大的迷宫）适应能力明显下降。
    后来针对它的工作　AdA人类时间尺度适应
  • 快速学习的全部信息塞在一个固定大小的GRU隐状态里，长时间后会遗忘，迷宫里偶尔忘记目标位置。

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    依靠门控循环网络的隐状态跨回合记忆信息；本文实际采用LSTM的简化变体GRU。
  • 竞争
    Gittins指数1979 · RL
    在老虎机上与Gittins指数等手工推导的近最优算法比较，学出来的算法表现几乎相当。
  • 使用
    TRPO2015.02 · RL
    外层的慢速RL算法是TRPO，因为它表现稳健、调参少。
  • 延续
    A3C2016.02 · RL
    把A3C时代成熟的深度策略梯度训练用作外层的“慢”学习器（本文实际用的是TRPO；同期DeepMind的同类工作用A3C），由它学出内层的“快”学习算法。
  • 延续
    匹配网络与小样本学习2016.06 · 基础
    把监督学习中“端到端学会学习”的元学习思路推广到需要自己探索的强化学习。

读懂它需要的概念

马尔可夫决策过程 探索与利用 循环网络与隐状态 元学习 策略梯度 奖励、回报与折扣

本篇术语

  • 试验（trial）　在同一个随机采样的任务上连续进行的n个回合。网络的隐状态在一次试验内保留，换任务才重置。
  • 上下文强化学习　不更新网络权重，仅靠网络在不断增长的交互历史上的前向计算，就在新任务中表现越来越好。

怎么学

先补元学习和循环网络与隐状态，并理解多臂老虎机上的UCB和Thompson采样。读原文第2节（问题设定与图1）和3.1节老虎机实验。动手：在随机伯努利老虎机分布上用PPO训练一个GRU策略，输入上一步的动作和奖励，观察它学会“先试几个臂再锁定”的行为。
