机器遗忘

Machine Unlearning
2019.12论文延伸IEEE S&P 2021Lucas Bourtoule, Varun Chandrasekaran, Christopher Choquette-Choo, Hengrui Jia, Adelin Travers, Baiwu Zhang, David Lie, Nicolas Papernot · 多伦多大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用户要求删除数据时，若模型已经用这些数据训练，朴素的做法是从头重训，代价极高；而模型还可能记住并泄露这些数据（见成员推断攻击）。

方法

提出SISA训练：把数据切成互不重叠的分片，每片训练一个子模型再做集成，并在每片内再分阶段保存检查点，删除一条数据时只需重训它所在的那一小部分。

影响

定义了「精确遗忘」问题的基本框架，之后有大量近似遗忘和大模型遗忘的工作。

方法

SISA是Sharded、Isolated、Sliced、Aggregated的缩写。数据分到多个分片，每个分片独立训练一个子模型，预测时聚合所有子模型；每个分片内部再切成片、按顺序训练并存下中间检查点。要删除某条数据，只需找到它所在的分片和切片，从之前的检查点开始重训，其他分片不动。

论文报告：在Purchase数据集上遗忘时间比从头重训快4.63倍，在SVHN上2.45倍；在ImageNet这样复杂的任务上是1.36倍，结合迁移学习后准确率略有下降。

局限与后续

  • 分片会损失模型精度，且对大型语言模型的预训练规模不现实；遗忘效果也难以验证。
