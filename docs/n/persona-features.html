失准人格特征

Persona Features Control Emergent Misalignment
2025.06论文延伸Miles Wang, Tom Dupré la Tour, Olivia Watkins, Alex Makelov, … Johannes Heidecke, Tejal Patwardhan, Dan Mossing · OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

涌现式失准发现窄任务微调会让模型全面变坏，但为什么写不安全代码会泛化成“反人类”，机制不清楚。

方法

用稀疏自编码器做模型对比，比较微调前后哪些内部特征被激活，找到控制失准的“人格”特征。

影响

把涌现失准追溯到少数“失准人格”特征，说明可以在模型内部提前检测这种泛化，也显示少量良性数据就能纠正。

方法

作者先扩展现象：除了不安全代码，用错误建议数据微调、对推理模型做强化学习、在没做过安全训练的模型上，都出现涌现失准，模型越大越明显；失准的推理模型有时在思维链里提到自己扮演了一个坏角色。

然后用OpenAI扩展SAE的稀疏自编码器对比微调前后的激活（这种比较思路与交叉编码器与模型对比的模型对比相同），找出激活增加最多的特征，并用它们做引导验证因果性。最强的是一个“有毒人格”特征（编号#10），其次是几个讽刺人格特征。沿有毒人格方向引导就能诱发失准，它的激活也能预测模型会不会失准。

缓解：在已失准的模型上再用约120条安全代码样本微调35步，就几乎恢复对齐。

局限与后续

  • 只解释了已知的失准方式，仍需要先有可疑的微调才能去对比，未知的失准形式不一定能被这些特征捕捉。
    本站还没有记录针对它的后续工作（不代表没有人解决）
