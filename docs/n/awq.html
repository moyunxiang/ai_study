AWQ激活感知量化

AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration
2023.06论文延伸MLSys 2024Ji Lin, Jiaming Tang, Haotian Tang, Shang Yang, Wei-Ming Chen, Wei-Chen Wang, Guangxuan Xiao, Xingyu Dang, Chuang Gan, Song Han · MIT / SJTU / NVIDIA / UMass待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GPTQ训练后量化靠重建误差补偿，容易对校准集过拟合；权重等量化时一小部分重要通道的误差占了主要影响。

方法

根据激活的大小找出约1%的重要权重通道，先放大它们再量化，等价于保护这些通道，同时全部仍用低比特整数。

影响

在不依赖反向传播和重建的前提下做到4位量化，并带来本地设备上的实际加速。

方法

关键观察：权重的重要性由对应的激活决定，而不是权重本身大小；保护1%的重要权重就能显著降低量化误差。直接保留成FP16会让数据格式混乱，AWQ改为在量化前给这些通道乘以一个缩放因子s（相应地激活除以s，数学上等价），使其相对量化步长更大、误差更小，缩放因子通过在激活统计上搜索得到。它配套提供TinyChat推理框架，摘要称在桌面和移动GPU上比Hugging Face的FP16实现快3倍以上，并使700亿参数的Llama-2能部署到移动GPU。思路与SmoothQuant的等价缩放相近。

局限与后续

  • 只量化权重，到3位以下精度仍会下降。
    后来针对它的工作　1.58比特模型BitNet
  • 依赖校准集的激活统计，对分布外数据的稳健性有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）

    8位只能把显存减半，175B模型仍要约175GB；更激进的4位、3位量化在这种方法下会严重掉点。

    最初的4位量化只是按块取整，低比特时质量损失明显，不如利用激活或二阶信息的量化方法。

    GPTQ训练后量化2022.10 · 系统·效率
