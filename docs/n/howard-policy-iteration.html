Howard策略迭代

Dynamic Programming and Markov Processes
1960思想延伸Dynamic Programming and Markov Processes, MIT Press 1960Ronald A. Howard · MIT待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

Bellman的价值迭代收敛慢，且没有直接给出一个好策略的搜索方式。

方法

交替做两步：给定策略求出它的价值（策略评估），再对每个状态改成贴着价值最高动作的新策略（策略改进），反复直到不变。

影响

给出强化学习里“评估再改进”的标准框架，几乎所有算法（含actor-critic）都是它的采样或近似版本。

方法

Howard把马尔可夫过程与动态规划结合起来。策略迭代从任意一个策略开始：第一步评估，求解该策略下每个状态的价值，这是一个线性方程组；第二步改进，对每个状态选能最大化“即时奖励加后续价值”的动作，得到的新策略不会比旧策略差。有限MDP里，这个过程在有限步后停在最优策略，常常只要很少几轮。

它和动态规划与Bellman方程的价值迭代的区别是：价值迭代每次只做一步备份，策略迭代每轮都把当前策略评估到底。

后来的发展

Actor-Critic（ASE/ACE）把评估和改进拆成两个网络同时更新；最小二乘TD（LSTD）直接解评估这一步的最小二乘；保守策略迭代CPI在近似情形下给出改进保证。

局限与后续

  • 评估一步需要解大规模线性方程组，状态多时代价很高。
    后来针对它的工作　最小二乘TD（LSTD）
  • 需要已知转移模型，且近似下的改进可能不再单调。
    后来针对它的工作　保守策略迭代CPI Q-learning

它建立在什么之上

  • 延续
    动态规划与Bellman方程1957 · RL
    在Bellman方程之上增加“评估策略再改进策略”的迭代结构。

后来的相关工作

  • 延续
    Dyna：学习与规划合一1990 · RL
    Dyna-PI是策略迭代的增量、采样式近似：评估和改进交替进行，但不需要已知模型。
  • 竞争
    Q-learning1992 · RL
    策略迭代先完整评估再改进，需要模型；Q学习把评估和改进揉进每一步的增量更新，属于异步、无模型的动态规划。
  • 延续
    POMDP规划1998 · RL
    把MDP的价值迭代与策略迭代推广到信念空间；最优策略仍然由价值函数决定，只是状态换成了概率分布。
  • 延续
    Options时间抽象框架1999 · RL
    中断定理是策略改进定理在半马尔可夫option上的推广。
  • 延续
    自然策略梯度2001 · RL
    证明自然梯度方向趋向一步贪心策略改进，把梯度法与策略迭代联系起来，同时保住了梯度法不退化的优点。
  • 使用
    Watkins博士论文1989 · RL
    沿用“评估价值再改进策略”的结构，但用采样代替模型。
  • 延续
    Puterman《马尔可夫决策过程》1994.04 · RL
    系统整理并推广了Howard的策略迭代，加入修正策略迭代和平均回报下的版本。
  • 改进
    最小二乘TD（LSTD）1996 · RL
    评估一步需要解大规模线性方程组，状态多时代价很高。
  • 竞争
    约束MDP（CMDP）1999 · RL
    普通MDP可用策略迭代得到确定性最优策略；CMDP一般需要随机策略，主要靠线性规划或对偶方法求解。
  • 改进
    保守策略迭代CPI2002 · RL
    需要已知转移模型，且近似下的改进可能不再单调。
  • 使用
    最小二乘策略迭代LSPI2003.12 · RL
    整体框架就是近似版的策略迭代：评估一步用最小二乘，改进一步取贪心。
  • 延续
    李雅普诺夫安全RL2018.05 · RL
    把策略迭代改造成在李雅普诺夫约束下的安全策略迭代。
