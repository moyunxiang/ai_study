tinygrad

2020.10系统延伸tiny corp待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

主流框架代码量巨大，想自己接入一种新加速器或读懂框架全貌都很困难。

方法

做一个极小的深度学习栈：只需支持约25个低层算子即可接入新硬件，惰性求值把多步运算融合成一个核。

影响

成为最容易读完的完整训练框架，也是新硬件后端的试验田。

方法

tinygrad的README称它介于PyTorch和micrograd之间，由tiny corp维护。它包含带自动求导的张量库、把核融合并下译的中间表示与编译器、JIT与图执行，以及nn、优化器、数据集模块。

两点设计最有特色。其一是惰性求值：张量运算先记成图，最终再融合成少量内核，README以一个矩阵乘例子说明被融合成一个内核。其二是极小算子集：新增一个加速器后端只需实现约25个低层算子。后端列表包括OpenCL、CPU、Metal、CUDA、AMD、NV、QCOM和WebGPU。

局限与后续

  • 功能和性能与PyTorch相比仍有差距，大规模分布式训练支持有限。
