图灵：可计算数

On Computable Numbers, with an Application to the Entscheidungsproblem
1936论文重要Proceedings of the London Mathematical Society, 1937Alan Turing · 剑桥大学国王学院待核对
DOI（原文） ↗Wikipedia：Turing's proof ↗Wikipedia：Turing machine ↗在交互版中打开（演化树、学习进度）

问题

希尔伯特问：有没有一个机械的方法，能对任何数学命题判定它能否被证明？可当时“机械的方法”本身没有精确定义，无从回答。

方法

用一台只会读写纸带、按有限规则表动作的抽象机器来定义“可计算”，再证明不存在能判定任意机器行为的机器，从而否定了判定问题。

影响

给“算法”和“计算机”下了数学定义，提出能模拟任何机器的通用机；此后一切关于“机器能不能思考”的讨论都以它为起点。

背景

1928年希尔伯特提出“判定问题”（Entscheidungsproblem）：能否找到一个通用的机械程序，输入任意一条一阶逻辑公式，有限步内给出“可证”或“不可证”。哥德尔1931年的不完备定理已经动摇了希尔伯特的计划，但判定问题仍悬而未决，难点在于“机械程序”是个直觉概念——不先说清什么叫机械地计算，就没法证明某件事不能被机械地计算。

同一时期，普林斯顿的Alonzo Church用λ演算给出了另一种定义，并先于图灵证明了判定问题无解（Church定理）。图灵的路线完全不同：他从“一个人拿着纸笔做计算时到底在做什么”出发。

方法

图灵机（图灵自己叫a-machine，自动机）。一条无限长、划分成格子的纸带，每格写一个来自有限字母表的符号；一个读写头停在某一格上；机器处于有限个状态之一。每一步，它根据“当前状态+读到的符号”查一张有限的规则表，决定写什么符号、向左或向右移一格、进入哪个新状态，或停机。例如一台给二进制数加1的机器只需要几条规则：从最右一位开始，读到1就写0并左移（进位），读到0或空格就写1并停机。

图灵论证：人用纸笔按规则做的任何计算，都能被这样一台机器完成。

通用机。规则表本身也能编码成纸带上的一串符号。图灵构造了一台通用机U：把任意机器M的编码和M的输入一起写在纸带上，U就能逐步模拟M。这就是“程序也是数据”的思想。

不可判定性。既然机器可以编码成数字，就能用对角线论证：假设存在一台机器能判定任意机器是否会陷入“循环”（今天称为停机问题），就能构造出一台与它的判定结果相反的机器，得出矛盾。再把判定问题归约到这个问题上，就证明了希尔伯特要的通用判定程序不存在。

后来的发展

Church在书评里把这种机器称为“图灵机”。“任何算法都能用图灵机实现”（Church–图灵论题）成为计算机科学的基本假设。通用机的“程序存储在内存里”思路在冯·诺依曼架构的EDVAC设计中落地为真实计算机。

对AI而言，这篇论文给出了一个基本前提：如果思维是某种按规则进行的符号操作，原则上就能被一台通用机执行。M-P神经元把神经元网络与图灵机的计算能力联系起来；图灵本人1950年在图灵测试里直接问“机器能思考吗”；逻辑理论家和达特茅斯会议则把这个前提变成了研究纲领。反过来，论文证明的不可判定性也一直是讨论机器能力上限时被反复引用的结论。

容易误解的地方

  • 图灵机不是一台实际造出来的机器，而是一个数学模型；它的纸带无限长，真实计算机只有有限内存。
  • 判定问题首先由Church证明无解，图灵是独立给出的第二个证明；图灵的贡献在于机器模型更直观、并提出了通用机。
  • “停机问题”这个名字不是图灵起的，他证明的是等价的“循环机”判定问题。

局限与后续

  • 只是一个抽象模型，纸带无限、速度不计，没有给出如何用电子元件造出一台实际可用的通用计算机。

读懂它需要的概念

命题逻辑、谓词逻辑与符号推理 时间与空间复杂度

本篇术语

  • 判定问题　希尔伯特1928年提出：是否存在一个机械程序，能对任意逻辑公式判定它是否可证。图灵和Church证明答案是否定的。
  • 通用图灵机　一台能读入其他任意图灵机的编码并模拟它运行的图灵机，相当于“能运行任何程序的计算机”。
  • 对角线论证　康托尔发明的证明方法：假设能列出全部对象，再构造一个与列表里每一项都至少有一处不同的新对象，从而得出矛盾。

怎么学

先补命题逻辑、谓词逻辑与符号推理。读Wikipedia的Turing machine词条，自己手写一台二进制加1或判断回文的图灵机规则表并用几十行Python模拟它；再读Turing's proof词条理解对角线论证，最后读Charles Petzold《图灵的秘密》逐段注释的原文。
