DETR

End-to-End Object Detection with Transformers
2020.05论文重要ECCV 2020Nicolas Carion, Francisco Massa, Gabriel Synnaeve, Nicolas Usunier, Alexander Kirillov, Sergey Zagoruyko · Facebook AI待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

主流检测器靠大量手工部件：预先铺设成千上万个锚框、按IoU规则分配正负样本、最后用非极大值抑制删除重复框，流程复杂且每个部件都要调参。

方法

把检测直接看成“预测一个集合”：Transformer解码器用100个可学习的查询向量并行输出100个预测，训练时用匈牙利算法把预测和真实物体一一配对，重复预测自然受罚，不再需要锚框和NMS。

影响

第一个端到端、没有锚框和NMS的检测器，精度与精调的Faster R-CNN持平；“对象查询 + 二分图匹配”成为之后检测、分割、开放词表检测乃至SAM 3的基础框架。

背景

到2020年，Faster R-CNN、Focal Loss与RetinaNet这类检测器（见分类、检测、分割）已经很准，但它们并不直接输出“图里有哪些物体”。它们先在图上铺满锚框（见锚框与非极大值抑制），对每个锚框判断是否有物体、需要怎样微调；训练时用IoU阈值规定哪些锚框算正样本；推理时同一个物体会被许多相邻锚框重复检出，只能事后用非极大值抑制（NMS）按分数删掉重叠框。

这些部件编码了大量人工先验，锚框尺寸、IoU阈值、NMS阈值都要按数据集调；NMS还不可微，模型无法在训练中学会“别重复”。论文的问题是：能不能像机器翻译直接输出一句话那样，让网络直接输出一个物体集合？

方法

结构。ResNet-50骨干把图像变成1/32分辨率的特征图，压成2048→256维后展平成一串“图像token”，加上二维正弦位置编码，送进6层Transformer编码器做全局自注意力。解码器有N = 100个可学习的向量，称为对象查询；它们通过自注意力互相交流（避免重复），通过交叉注意力从图像特征里取信息，6层后每个查询经一个小前馈网络输出一个类别（含“无物体”类∅）和一个框（中心、宽、高的归一化坐标）。100个预测是并行产生的，不是逐个生成。

集合损失。一张图可能只有5个物体，却有100个预测。先在所有“预测—真值”配对中找总代价最小的一一对应：

σ̂ = argmin_σ Σᵢ L_match(yᵢ, ŷ_σ(i))

代价由类别概率和框的差距（L1距离加广义IoU）组成，用匈牙利算法在多项式时间内求解。配上的预测按真值计算分类和框回归损失，没配上的95个预测都被要求输出“无物体”。由于每个真值只认一个预测，两个查询抢同一个物体时总有一个受罚，模型自己学会不重复，NMS因此多余。每层解码器后都加辅助损失。

结果

COCO验证集上，ResNet-50版DETR（约4100万参数）AP 42.0，与同样参数量、加强训练的Faster R-CNN-FPN（42.0）持平，速度也相近（28对26帧每秒）。分大小看差异明显：大物体AP 61.1，比Faster R-CNN高7.8；小物体AP 20.5，低5.5。去掉编码器，AP下降3.9，大物体下降6.0，说明全局自注意力对分开大物体很重要。加一个掩码头后可直接做全景分割。代价是训练很慢：基线在16块V100上训练300轮要3天，最终结果训了500轮，而Faster R-CNN通常只需几十轮。

后来的发展

DETR的两个明显缺陷——收敛慢、小物体差——半年后被Deformable DETR用稀疏的可变形注意力和多尺度特征解决，DINO（检测）进一步加入去噪训练把COCO精度推到新高，RT-DETR实时DETR做到实时。“查询 + 二分图匹配”被推广到分割（MaskFormer、Mask2Former通用分割）、图文检测（MDETR、OWL-ViT、Grounding DINO）、自动驾驶感知（BEVFormer），SAM 3概念分割的检测器也基于DETR。YOLOv10免NMS借用一对一匹配的思路去掉了YOLO的NMS。

容易误解的地方

  • DETR并没有在所有指标上超过Faster R-CNN：它强在大物体，弱在小物体，总AP打平。
  • “端到端”不代表训练简单：匈牙利匹配在训练初期很不稳定，同一个查询在相邻两轮可能被分配给不同物体，这是收敛慢的主要原因之一。

读懂它需要的概念

自注意力与多头注意力 编码器-解码器 分类、检测、分割 锚框与非极大值抑制 IoU与mAP 位置编码

本篇术语

  • 对象查询（object query）　解码器的N个可学习输入向量，每个最终输出一个预测（某个物体或“无物体”），相当于N个检测“槽位”。
  • 二分图匹配 / 匈牙利算法　在预测集合与真值集合之间找总代价最小的一对一配对的经典算法，复杂度为多项式级。
  • 广义IoU（GIoU）　IoU的推广，两框不相交时仍能根据距离给出有意义的梯度，常用作框回归损失。

怎么学

先懂自注意力与多头注意力、编码器-解码器和锚框与非极大值抑制。读原文第3.1节（集合损失）和附录里约50行的PyTorch推理代码。动手：用scipy.optimize.linear_sum_assignment写一个匈牙利匹配损失，再加载官方预训练DETR，可视化100个查询的预测框分布。
