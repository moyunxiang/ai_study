多智能体Transformer MAT

Multi-Agent Reinforcement Learning is a Sequence Modeling Problem
2022.05论文延伸NeurIPS 2022Muning Wen, Jakub Grudzien Kuba, Runji Lin, Weinan Zhang, Jun Wang, Ying Wen, Yaodong Yang · 上海交通大学 / 牛津大学 / 中科院自动化所 / 伦敦大学学院 / 北京大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

合作多智能体的联合动作空间随人数指数增长；已有方法要么各自独立决策难以配合，要么像HAPPO那样逐个更新、计算慢。

方法

把“每个智能体依次选动作”写成序列生成：编码器读入所有智能体的观测，解码器像语言模型一样一个接一个地输出各智能体的动作。

影响

把Transformer与在线MARL结合起来，成为合作MARL的强基线之一，并引出Sable等更可扩展的序列模型方法。

方法

MAT基于HATRPO/HAPPO的多智能体优势分解：联合优势等于各智能体在前面队友动作条件下优势之和，所以联合策略可以拆成“第1个智能体选动作→第2个看着第1个的动作再选→……”。这正好对应Transformer的编码器-解码器：编码器对所有智能体的观测做自注意力，输出每个智能体的表示并用贝尔曼误差训练价值估计；解码器用带掩码的自注意力，第m个智能体只能看到前m−1个的动作，自回归地输出动作，用PPO式截断目标在线训练。与只拟合离线数据的Decision Transformer不同，MAT是在环境里在线试错学的。作者称这样把联合动作搜索从“相乘”变成“相加”，复杂度对智能体数是线性的。

在星际SMAC上，MAT在3s5z vs 3s6z取得96.5%胜率（MAPPO 84.3%）；少样本迁移到新地图时，只用10%新数据，27m vs 30m上71.2%对MAPPO的26.8%。

局限与后续

  • 注意力的显存随智能体数和序列长度快速增长，上千个智能体时放不进单卡。

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    编码器-解码器结构与掩码自注意力。
  • 竞争
    Decision Transformer2021.06 · RL
    都把决策写成序列建模；DT只拟合离线轨迹，MAT在线on-policy训练且序列维度是智能体而非时间。
  • 竞争
    MAPPO2021.03 · RL
    主要比较基线；MAT在多数SMAC难图和少样本迁移上更强。
  • 改进
    HATRPO/HAPPO2021.09 · RL
    直接利用HAPPO的优势分解引理，把顺序更新改造成自回归的动作生成。

后来的相关工作

  • 改进
    Sable千智能体序列模型2024.10 · RL
    MAT显存随智能体数快速增长、没有时间记忆；Sable用保留机制同时解决这两点。
