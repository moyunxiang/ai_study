MAAC注意力评论家

Actor-Attention-Critic for Multi-Agent Reinforcement Learning
2018.10论文延伸ICML 2019Shariq Iqbal, Fei Sha · 南加州大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

MADDPG给每个智能体一个看全局的集中式评论家，输入是所有智能体观测与动作的拼接；智能体一多，输入维度线性膨胀，而且大部分信息与当前智能体无关。

方法

集中式评论家里加一层注意力：每个智能体在估计自己的Q值时，用查询-键匹配从其他智能体的编码里挑出相关的信息加权求和，注意力参数在所有评论家之间共享。

影响

把注意力机制引入CTDE（集中训练、分散执行）的评论家设计，成为多智能体actor-critic的常用基线，也说明了“选择性地看同伴”比简单拼接或取平均更能扩展。

背景

多智能体策略梯度的主流框架是CTDE：训练时评论家可以看所有人的信息，执行时每个智能体只靠自己的观测行动。MADDPG给每个智能体单独一个评论家，输入所有人观测动作的拼接；COMA反事实策略梯度用一个共享评论家和反事实基线解决信用分配。两者都有同一个问题：智能体越多，评论家的输入越长，学习越慢，而且一个智能体通常只需要关心少数几个相关的同伴。

方法

MAAC先把每个智能体的观测和动作编码成 e_j = g_j(o_j, a_j)。智能体i的评论家写成 Q_i(o, a) = f_i(e_i, x_i)，其中 x_i = Σ_{j≠i} α_{ij} · v_j 是其他智能体信息的加权和：值向量 v_j = h(V·e_j)，权重 α_{ij} ∝ exp(e_j^T W_k^T W_q e_i)，即用i的查询去匹配j的键，再做softmax（与Transformer的注意力同一形式）。W_q、W_k、V 在所有智能体的评论家之间共享，因此参数量不随智能体数平方增长，可以用多个注意力头。

训练框架是多智能体版的SAC（最大熵actor-critic）；策略梯度里用的优势函数借鉴COMA反事实策略梯度的反事实基线：固定其他智能体动作，对自己的动作求期望得到基线，从而判断“我这一步的动作到底有没有贡献”。该方法不要求全局状态、不限制动作空间类型，合作、各自奖励乃至对抗设定都能用。

结果

摘要称，与当时的方法相比，注意力机制让在复杂多智能体环境里的学习更有效、更可扩展。按原文正文的通行描述，在合作寻宝、漫游车-塔等需要选择性关注队友的任务上，智能体数增加时MAAC相对MADDPG、COMA反事实策略梯度的优势更明显。

后来的发展

此后多智能体评论家和值分解网络里普遍用注意力或图结构建模智能体之间的关系，QPLEX对偶值分解用注意力计算混合权重，多智能体Transformer MAT则把整个联合策略建成Transformer序列模型。

读懂它需要的概念

Actor-Critic与优势函数 注意力机制 Softmax与logits 策略梯度 信用分配

本篇术语

  • CTDE　集中训练、分散执行：训练时允许使用全局信息（如所有人的观测和动作），执行时每个智能体只用自己的观测决策。
  • 反事实基线　固定其他智能体的动作，把自己的动作换成所有可能动作求期望，作为比较基准，用来判断自己动作的贡献。

怎么学

先读MADDPG和COMA反事实策略梯度理解CTDE与反事实基线；再读原文第4节评论家结构，对照Transformer的注意力公式；可以在多智能体粒子环境里比较拼接式评论家和注意力评论家随智能体数增加的表现。
