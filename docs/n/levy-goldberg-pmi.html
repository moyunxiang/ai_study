word2vec即隐式矩阵分解

Neural Word Embedding as Implicit Matrix Factorization
2014.12论文延伸NeurIPS 2014Omer Levy, Yoav Goldberg · Bar-Ilan University待核对
NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

Skip-gram负采样这类神经词嵌入效果很好，但人们不清楚它到底在优化什么，似乎与传统基于计数的方法截然不同。

方法

证明skip-gram负采样的训练目标等价于隐式分解一个词与上下文的移位PMI矩阵，把神经词嵌入与经典矩阵分解联系起来。

影响

揭开词向量的“黑箱”，表明神经嵌入与基于计数的方法本质相通，并启发了对超参数和矩阵分解的重新审视（与GloVe同时期）。

方法

论文分析skip-gram负采样的目标。设词w与上下文c在语料中共现的统计量构成矩阵；若负样本个数为k，则训练达到最优时，词向量与上下文向量的内积w·c收敛到共现词对的点互信息（见互信息与词语搭配）减去log k：w·c = PMI(w, c) − log k。

这意味着skip-gram负采样在隐式地分解一个“移位的PMI矩阵”，只是用随机梯度下降而不是显式奇异值分解（见特征分解与奇异值分解）。作者据此直接对这个移位PMI矩阵做SVD，也得到了不错的嵌入，并在词相似度和类比任务上与神经方法有竞争力。

这条结论把word2vec与潜在语义分析LSA一类的基于计数的方法放在了同一个框架里。

局限与后续

  • 结论是对优化目标的分析，并没有解释为什么这样的向量空间会出现类比等线性结构。

读懂它需要的概念

互信息 特征分解与奇异值分解 嵌入向量 低秩近似

本篇术语

  • 点互信息（PMI）　衡量两个词共现程度高于随机预期多少的指标：对数的P(w,c)比P(w)P(c)。

怎么学

先读Skip-gram负采样；在小语料上自己计算移位PMI矩阵并做SVD，再与word2vec训练的向量比较相似度结果。
