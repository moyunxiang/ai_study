Element AI的兴衰

2016.10事件延伸Jean-François Gagné, Yoshua Bengio, Nicolas Chapados, Anne Martel, Philippe Beaudoin, Jean-Sébastien Cournoyer · 蒙特利尔待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

AlexNet之后谷歌、Facebook等大公司把深度学习研究者成批挖走，加拿大培养的人才大量流向美国；学术界想找一条既留住人、又能把研究变成产品的路。

方法

2016年10月Bengio与创业者在蒙特利尔创办Element AI，定位为给企业提供AI解决方案的“深度学习孵化器”，2017年拿到1.02亿美元A轮，想以本地公司的形式留住蒙特利尔的深度学习人才。

影响

它曾是加拿大最受瞩目的AI创业公司，但始终没找到可规模化的产品，2020年11月以约2.3亿美元卖给ServiceNow，创始人的价值大部分被抹去，成为“学术明星+巨额融资≠可持续商业”的常被引用的例子。

方法

Element AI于2016年10月由Jean-François Gagné与后来获图灵奖的Yoshua Bengio（见Hinton、LeCun、Bengio获图灵奖）等人共同创办，蒙特利尔风投Real Ventures的Cournoyer也是联合创始人。当时蒙特利尔是Bengio实验室所在地，是CIFAR资助下的深度学习小圈子那批深度学习研究者的重镇之一。

经过：

  • 2017年初收购开源机器学习数据库MLDB.ai的整个团队；随后由Data Collective和微软风投领投，从美国投资者那里拿到1.02亿美元A轮。
  • 2018年12月获加拿大政府最多500万加元贷款，目标是创造900个就业岗位；与国际特赦组织合作分析推特上针对女性政治人物和记者的网络暴力。
  • 2019年9月才推出第一个独立产品——保险核保辅助软件Underwriting Partner，12月推出面向制造业的数据管理平台。
  • 2020年11月30日，ServiceNow宣布收购，据报道公司当时资金将尽，售价约2.3亿美元，2021年1月完成交割。

它的经历和谷歌拍得Hinton团队、谷歌收购DeepMind形成对照：那两次是大公司直接买走研究团队；Element AI试图在本地自建公司留住人才，最后仍被美国公司收购。

局限与后续

  • 把咨询式的定制项目当作主要业务，难以形成可复制的产品；研究人才密集但客户收入跟不上，资金耗尽后只能出售。
