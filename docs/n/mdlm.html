掩码扩散语言模型MDLM

Simple and Effective Masked Diffusion Language Models
2024.06论文延伸NeurIPS 2024Subham Sekhar Sahoo, Marianne Arriola, Yair Schiff 等 · 康奈尔大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

扩散模型在图像上很成功，但在语言建模上，离散扩散比自回归模型差一大截，困惑度差距明显。

方法

证明简单的掩码离散扩散只要训练配方得当就比以前认为的强，并推导出一个简化的目标：它其实是若干种经典掩码语言模型损失的加权混合。

影响

让扩散语言模型的困惑度接近自回归模型，是后来LLaDA等大规模扩散语言模型的直接基础。

方法

做法是：前向过程把句子里的词逐步随机替换成一个特殊的[MASK]；反向模型（一个类似BERT的仅编码器网络）学习把被遮的词还原。作者推导出一个经过Rao-Blackwell化的简化目标，形式上就是不同遮挡比例下的掩码语言模型损失的混合，训练非常像BERT，但有了可以采样生成的理论基础。

在语言建模基准上，用现代工程手段训练的一系列掩码扩散模型在扩散模型中取得新的最好成绩，并接近自回归模型的困惑度。它的采样器还支持用半自回归的方式生成任意长度的文本。

局限与后续

  • 困惑度仍然略逊于同规模的自回归模型，且论文规模较小，没有证明能扩展到大模型。
    后来针对它的工作　LLaDA大语言扩散模型
  • 固定长度的并行去噪，难以像自回归那样自然地生成可变长度文本，需要半自回归等补丁。
    后来针对它的工作　块扩散BD3-LM

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    模型结构是类BERT的仅编码器网络，目标退化为不同遮挡率下的掩码语言建模。
  • 延续
    离散扩散语言模型SEDD2023.10 · LLM
    同为离散扩散语言模型；MDLM把目标简化为掩码语言模型损失的混合，并用更好的训练配方追上大部分差距。
  • 改进
    Levenshtein Transformer2019.05 · LLM
    需要从自回归教师模型做知识蒸馏才能达到可比的翻译质量，迭代轮数和三个分类器的误差会累积，在开放式长文本生成上没有验证。
  • 改进
    GLAT一瞥Transformer2020.08 · LLM
    一次并行输出后无法再修改错误，生成文本较长或任务更开放（如对话、摘要）时质量下降明显，后来的离散扩散模型改用多步去噪。
  • 改进
    多项式扩散与Argmax流2021.02 · 生成
    在文本上的似然和样本质量仍明显落后于自回归模型。
  • 改进
    离散扩散D3PM2021.07 · LLM
    文本质量仍不如自回归语言模型，大词表下的转移矩阵设计和采样效率都是难点。
  • 改进
    VQ-Diffusion离散扩散2021.11 · 生成
    均匀替换噪声使训练更难，后来的研究发现纯掩码（吸收态）转移往往更简单有效。
  • 改进
    Diffusion-LM2022.05 · LLM
    需要很多步迭代去噪，生成速度远慢于自回归，无条件文本质量也不如强自回归模型。
  • 改进
    DiffuSeq2022.10 · LLM
    采样需要很多去噪步，比自回归慢很多；质量与最强的预训练自回归模型相比仍无明显优势。
  • 改进
    SSD-LM单纯形块扩散2022.10 · LLM
    在V维词表空间上做多步扩散，计算量很大，生成比自回归模型慢得多；后来的掩码离散扩散直接在离散token上加噪，训练和采样都更高效。
  • 改进
    连续扩散CDCD2022.11 · LLM
    连续嵌入空间和离散词之间始终有一道鸿沟，需要额外的分类头来弥合，训练也更复杂。
  • 改进
    Plaid似然扩散LM2023.05 · LLM
    1B参数的Plaid仍在似然上只是刚超过一个124M的自回归小模型，与同算力的自回归模型相比效率明显偏低。

读懂它需要的概念

扩散：前向加噪与反向去噪 掩码建模 语言模型 困惑度 变分推断与ELBO

本篇术语

  • 离散扩散　把「加噪」从加高斯噪声换成对词做随机替换或遮挡，反向过程则学习还原。

怎么学

先会掩码建模和扩散：前向加噪与反向去噪；读原文第3节的目标推导；作者页面有代码、博客和视频教程，建议先看视频再看公式。
