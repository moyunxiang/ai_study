FAST角点

Machine Learning for High-Speed Corner Detection
2006.05论文延伸ECCV 2006Edward Rosten, Tom Drummond · 剑桥大学待核对
DOI ↗TPAMI扩展版 ↗在交互版中打开（演化树、学习进度）

问题

实时跟踪和SLAM每帧都要找特征点，SIFT特征的检测和Harris角点都太慢，跑不满视频帧率。

方法

只比较候选点周围一圈16个像素的亮度，若有一段连续像素都明显更亮或更暗就判为角点，并用决策树学出最快的比较顺序。

影响

检测只占实时视频处理时间的一小部分，成为实时视觉SLAM与ORB特征特征的检测部件。

方法

FAST的判断规则叫“分段测试”：以候选像素p为圆心、半径3画一个16像素的圆，设阈值t；若圆上有n个连续像素都比p亮t以上，或都比p暗t以上，就认为p是角点。大部分非角点只需看少数几个像素就能被排除，所以非常快。作者进一步用机器学习（决策树）从训练图像里学出先比哪个像素、后比哪个像素的最优顺序，把检测器编译成一串if判断，再加一步非极大值抑制去掉挤在一起的点。

论文摘要报告：它处理实时PAL视频只用不到7%的处理时间，而Harris需要120%、SIFT的检测阶段需要300%，都跑不满帧率；在三维场景下比较不同视角的重复检测率时，它的表现也优于已有检测子。2008年TPAMI扩展版《Faster and Better》把检测器推广为可按重复率优化的形式。

后来的发展

FAST本身不给方向和尺度，也不带描述子；ORB特征给它补上方向和图像金字塔，再配BRIEF描述子，成为ORB-SLAM等系统的标准特征。

局限与后续

  • 没有尺度和方向信息，也不提供描述子，单独用无法跨视角、跨尺度匹配。
    后来针对它的工作　ORB特征
  • 只比较亮度，对噪声敏感，阈值t需要人工调。
    后来针对它的工作　SuperPoint

它建立在什么之上

  • 竞争
    SIFT特征1999 · 视觉
    SIFT检测子追求尺度不变与描述能力，FAST放弃这些换取实时速度。
  • 改进
    Harris角点1988 · 视觉
    Harris要算梯度和结构张量，太慢；FAST只做像素比较，速度提高一个数量级以上。
  • 改进
    Shi–Tomasi角点1994.06 · 视觉
    需要计算每个像素的特征值，对实时系统仍偏慢。
  • 竞争
    SURF2006.05 · 视觉
    同年的SURF用积分图加速SIFT式检测，仍比FAST慢；FAST走的是只做像素比较的极简路线。

后来的相关工作

  • 改进
    ORB特征2011.11 · 视觉
    没有尺度和方向信息，也不提供描述子，单独用无法跨视角、跨尺度匹配。
  • 改进
    SuperPoint2017.12 · 视觉
    只比较亮度，对噪声敏感，阈值t需要人工调。

读懂它需要的概念

图像作为张量 决策树 特征与表示学习 吞吐、延迟与批处理

本篇术语

  • 非极大值抑制　在一小片区域里只保留响应最强的那个点，去掉挤在一起的重复检测。

怎么学

先看Harris角点的思路，再读FAST论文第2–3节的分段测试和决策树；用OpenCV的FastFeatureDetector调阈值看检测点数量和速度的变化。
