QANet

QANet: Combining Local Convolution with Global Self-Attention for Reading Comprehension
2018.04论文延伸ICLR 2018Adams Wei Yu, David Dohan, Minh-Thang Luong, Rui Zhao, Kai Chen, Mohammad Norouzi, Quoc V. Le · 卡内基梅隆大学 / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BiDAF等阅读理解模型都靠RNN加注意力，RNN必须逐词串行计算，训练和推理都慢，也就难以用更多数据训练。

方法

编码器完全去掉循环网络：用卷积捕捉局部词间关系、用自注意力捕捉全局关系，速度提升数倍；省下的算力用来训练用回译生成的改写数据。

影响

在SQuAD上训练快3–13倍、推理快4–9倍且精度相当，加上回译增强的单模型F1达84.6，高于当时已发表的81.8；它是Transformer式结构进入阅读理解的代表，也普及了用回译做文本数据增强。

方法

BiDAF双向注意力流式模型的流程是：词向量→LSTM编码文章和问题→文章-问题双向注意力→LSTM建模→预测答案起止位置。QANet保留了这个流程和BiDAF的上下文-问题注意力层，但把所有LSTM换成同一种编码块：若干层深度可分离卷积（只看邻近几个词，捕捉短语级局部特征）+一层多头自注意力与多头注意力（任意两个词直接交互，捕捉全局关系）+前馈层，每个子层都带层归一化和残差连接，并加位置编码。这与Transformer的编码器类似，只是多了卷积子层。没有循环，所有位置可以并行计算。

数据增强：用英法两个方向的神经翻译模型对训练文章做回译（英→法→英），得到意思相同、措辞不同的改写句，并相应调整答案位置，扩充训练集。

摘要报告：在SQuAD上训练快3到13倍、推理快4到9倍，精度与循环模型相当；加入回译增强数据后，单模型测试集F1为84.6，明显高于当时已发表的最好成绩81.8。

局限与后续

  • 仍需从头在SQuAD上训练任务专用模型，几个月后BERT类预训练模型微调就大幅超过了它。
    后来针对它的工作　BERT
  • 自注意力的计算与文章长度平方成正比，长文档阅读理解仍需截断或分段。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    编码块中的多头自注意力、位置编码、残差与层归一化沿用Transformer。
  • 使用
    回译2015.11 · NLP
    借用翻译中的回译思路，经英→法→英改写训练文章做数据增强。
  • 使用
    SQuAD2016.06 · 数据·评测
    在SQuAD上训练与评测，报告速度与F1。
  • 改进
    BiDAF双向注意力流2016.11 · NLP
    保留BiDAF的整体流程与上下文-问题注意力，但用卷积+自注意力替换LSTM，解决RNN串行计算慢的问题。
  • 使用
    Xception2016.10 · 视觉
    编码块中的卷积是深度可分离卷积，参数和计算量比普通卷积少。

读懂它需要的概念

卷积层、池化与感受野 自注意力与多头注意力 Transformer层的结构 残差连接 数据增强 准确率、精确率、召回率与F1

本篇术语

  • 深度可分离卷积　先对每个通道单独做空间卷积，再用1×1卷积混合通道，比普通卷积省参数和计算。
  • 抽取式阅读理解　答案是原文中的一段连续文字，模型只需预测这段文字的起点和终点。

怎么学

先读BiDAF双向注意力流与Transformer的讲解 → 读原文第2节编码块结构与第3节数据增强 → 动手：在SQuAD的子集上比较LSTM编码器与卷积+自注意力编码器的每轮训练时间和F1。
