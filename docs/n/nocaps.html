nocaps

nocaps: novel object captioning at scale
2018.12数据集延伸ICCV 2019Agrawal, Desai, Wang, Chen, Jain, Johnson, Batra, Parikh, Lee, Anderson · Georgia Tech / Facebook AI / Oregon State 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图像描述模型只能描述训练配对数据里见过的有限物体，一旦画面中出现 COCO 之外的物体，就只会乱编或用别的词替代。

方法

构建首个大规模『新物体描述』基准：测试图取自 Open Images，训练只给 COCO 的图文对加上 Open Images 的图像级标签与检测框，考察模型能否借用检测数据描述没有配对文字的物体。

影响

推动了用额外视觉数据扩展描述词汇的方法，也成为后来大规模图文预训练模型的零样本评测基准。

方法

nocaps 含15,100张来自 Open Images 验证与测试集的图片，共有166,100条人工写的描述。训练数据只有 MS COCO 的图文对，加上 Open Images 的图像级标签和检测框。

Open Images 比 COCO 的类别多得多，因此测试图里有近400个物体类别在训练描述里完全没出现或极少出现（nocaps 的由来）。模型只能靠物体检测数据学到这些词，再把它们放进句子。评测使用 CIDEr 等指标，并按见过/没见过的类别分成域内、近域和域外三类（分类方式记忆，未核对）。

局限与后续

  • 评测仍依赖参考描述的词面指标（如CIDEr），对不同表述的合理描述不够公平。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 训练数据仍被限定为 COCO 加检测标注，没有让模型接触海量的网络图文，后来的图文预训练模型绕开了此限制。

它建立在什么之上

  • 延续
    MS COCO2014.05 · 数据·评测
    COCO 的词汇有限，nocaps 测试在 COCO 训练条件下对未见类别的描述。
  • 使用
    CIDEr2014.11 · 数据·评测
    使用 CIDEr 等指标评价描述。
  • 改进
    Neural Baby Talk2018.03 · 多模态
    槽位内容受限于检测器的类别表，检测器不认识或漏检的物体就无法被正确写进描述。
  • 使用
    Open Images2018.11 · 数据·评测
    测试图和额外训练信号都来自 Open Images。
