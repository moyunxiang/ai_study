EDM设计空间

Elucidating the Design Space of Diffusion-Based Generative Models
2022.06论文重要NeurIPS 2022Tero Karras, Miika Aittala, Timo Aila, Samuli Laine · NVIDIA待核对
arXiv ↗官方代码 NVlabs/edm ↗在交互版中打开（演化树、学习进度）

问题

DDPM、DDIM、Score SDE各有一套记号和理论，设计选择互相缠在一起，没人说得清哪个改动真正有用，采样又要上百上千步。

方法

把所有扩散模型拆成几个可独立选择的部件（噪声尺度、采样器、网络输入输出缩放、训练噪声分布），逐一做实验，给出一套简单的最优配方。

影响

CIFAR-10上35次网络调用就达到FID 1.79，“EDM配方”成为之后几年训练和采样扩散模型的默认参考，一致性模型等工作都建在它上面。

背景

到2022年，扩散模型已经有好几套说法：DDPM是离散的马尔可夫链，Score SDE统一框架是连续时间的随机微分方程，DDIM是一个确定性的采样过程，改进DDPM和扩散超越GAN又各自加了技巧。每篇论文都把“噪声怎么加、网络预测什么、损失怎么加权、采样怎么走”一揽子打包，看起来这些选择都由理论推出、彼此不可分。结果是：想改进其中一处，很难判断该改哪里；采样也普遍需要几百上千步。

方法

作者先把所有方法统一写成一个“概率流ODE”：数据被加上标准差为σ的高斯噪声，去噪就是让σ从大到小走，

dx/dt = −σ̇(t)·σ(t)·∇ₓ log p(x; σ(t))

其中∇ₓ log p是分数（见分数函数与分数匹配），由一个去噪网络D(x; σ)估计：∇ₓ log p ≈ (D(x; σ) − x)/σ²。在这个框架下，各家方法只是在几个独立的旋钮上做了不同选择。他们给出的推荐：

噪声调度：直接令σ(t) = t，不再额外缩放x。这样ODE的轨迹接近直线，用大步长走误差小。

采样器：用二阶的Heun方法代替一阶欧拉法：先按当前斜率走一步，在新位置再算一次斜率，取两者平均重新走。每步多一次网络调用，但同样精度下步数少很多。时间步不均匀分布，σ_i = (σ_max^(1/ρ) + i/(N−1)·(σ_min^(1/ρ) − σ_max^(1/ρ)))^ρ，取ρ=7、σ从80降到0.002，即在低噪声处走得更密。18步Heun共35次网络调用。

网络的预处理（preconditioning）：网络F不直接输出去噪结果，而是

D(x; σ) = c_skip(σ)·x + c_out(σ)·F(c_in(σ)·x; c_noise(σ))

其中σ_data=0.5，c_skip = σ_data²/(σ²+σ_data²)，c_out = σ·σ_data/√(σ²+σ_data²)，c_in = 1/√(σ²+σ_data²)，c_noise = ¼·ln σ。作用是让网络的输入和要学的目标在任何噪声水平下都保持单位方差：噪声小时主要靠跳连直接输出x，噪声大时主要靠网络预测。

训练：训练时的噪声水平按ln σ ~ N(−1.2, 1.2²)采样，把算力集中在中等噪声（太小的噪声去不去都一样，太大的噪声什么也学不到），损失权重取λ(σ) = (σ²+σ_data²)/(σ·σ_data)²。

结果

CIFAR-10上类别条件FID 1.79、无条件FID 1.97，均为当时最好，每张图只要35次网络调用。只换采样器，不重新训练，一个已有的ImageNet-64模型FID就从2.07降到1.55；按新配方重新训练后达到1.36。

后来的发展

EDM的记号（σ参数化、预处理系数、对数正态噪声分布）成了后续研究的通用语言：一致性模型、分布匹配蒸馏DMD、连续时间一致性模型sCM都以它为基线和框架；同一团队的EDM2训练动力学继续研究大网络的训练动力学，自引导Autoguidance改进引导；JiT像素空间x预测等工作仍沿用它的设计。工业界的Stable Diffusion系列和许多开源训练库都内置了EDM采样器和Karras噪声表。之后Flow Matching与整流Rectified Flow用直线插值给出了另一种同样简洁的统一表述，大模型训练更多转向后者。

容易误解的地方

  • EDM的贡献不是新模型结构，而是把已有方法的选择拆开、各自调到最好。很多改进只换采样器就能拿到，不必重训。
  • Heun“步数少”要按网络调用次数算：18步实际是35次调用。

局限与后续

  • 仍需要几十次网络调用才能出一张好图，离一步生成还很远。

读懂它需要的概念

扩散：前向加噪与反向去噪 分数函数与分数匹配 常微分方程与随机微分方程 噪声调度与采样步数 高斯分布 生成质量指标：IS与FID

本篇术语

  • Heun方法　二阶的ODE数值解法：先按起点斜率试走一步，再在终点算一次斜率，用两个斜率的平均重新走。
  • 预处理系数　把网络输入、输出按噪声水平缩放的几个系数，保证网络在任何噪声下面对的都是数值大小相近的任务。
  • NFE　生成一张图需要调用神经网络的次数，比“步数”更准确地衡量采样成本。

怎么学

先读DDPM和Score SDE统一框架，补常微分方程与随机微分方程和分数函数与分数匹配。读原文第2节和表1（各方法在统一框架下的对照），然后第3节采样器、第5节预处理与训练。动手：读NVlabs/edm仓库里约50行的edm_sampler函数，在二维玩具数据上分别用欧拉法和Heun法采样，比较相同网络调用次数下的样本质量。
