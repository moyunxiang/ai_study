SIF加权平均句向量

A Simple but Tough-to-Beat Baseline for Sentence Embeddings
2017.04论文延伸ICLR 2017Sanjeev Arora, Yingyu Liang, Tengyu Ma · 普林斯顿大学待核对
ML Anthology ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

Skip-Thought等用复杂神经网络训练的句向量代价高，而Wieting等已发现在迁移场景下它们反被简单方法超过；但那些简单方法仍要用PPDB这类大规模标注数据重新训练词向量。

方法

完全无监督的句向量：用现成的词向量，对句中每个词按a/(a + p(w))加权平均（p(w)是词频，越常见的词权重越小），再对所有句向量求出第一主成分并把它从每个句向量中减去。

影响

在文本相似度任务上让加权平均比普通平均提升约10%–30%，并超过包括RNN、LSTM在内的有监督方法；作者建议把它作为今后必须打败的基线，此后句向量论文普遍报告与SIF的比较。

方法

做法分两步。第一步加权平均：v_s = (1/|s|)·Σ_w∈s [a/(a + p(w))]·v_w，其中p(w)是词在大语料中的频率，a是一个很小的常数。像the、and这类高频词权重接近0，低频的实义词权重接近1，作用和IDF与TF-IDF的逆文档频率相似。第二步去公共成分：把一批句向量排成矩阵，用奇异值分解（特征分解与奇异值分解）求第一主成分u，再令v_s ← v_s − u·uᵀ·v_s。直观上，所有句子的平均向量里都混着一个与语法、常用词相关的公共方向，去掉它之后句子之间的差异更多反映语义。

理论：作者在自己此前提出的潜变量生成模型（每个词由一个缓慢游走的「语篇向量」生成）上加了两个平滑项：一项允许词不依赖语境随机出现，另一项让and、not这类词在所有语境下都有较高概率。在这个模型下对语篇向量做最大似然估计，结果恰好就是上面的加权平均再去掉公共成分。

摘要报告：输入可以是在维基百科等无标注语料上用常用方法训练的词向量（如GloVe）；这种加权使文本相似度任务提升约10%–30%，并超过包括RNN、LSTM在内的复杂有监督方法，还能进一步改进Wieting等的词向量。

它建立在什么之上

  • 延续
    IDF与TF-IDF1972.01 · NLP
    按词频给词降权的思路与IDF相同，SIF给出了一个基于生成模型的加权公式。
  • 使用
    GloVe2014.10 · NLP
    以GloVe等现成的无监督词向量作为输入。
  • 竞争
    Skip-Thought句向量2015.06 · NLP
    Skip-Thought用编码器-解码器在大语料上训练句向量；SIF无需任何训练，在文本相似度任务上效果更好。
  • 竞争
    DAN深度平均网络2015.07 · NLP
    DAN用有监督的多层网络处理词向量平均，SIF则完全无监督，只靠加权和去主成分。
  • 改进
    PARAGRAM改写句向量2015.11 · NLP
    Wieting等的平均模型要用PPDB改写数据重新训练词向量；SIF完全无监督，用现成词向量加权平均即可达到并改进其效果。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

嵌入向量 特征分解与奇异值分解 降维与PCA 隐变量模型 最大似然估计

本篇术语

  • 公共成分去除　用一批句向量的第一主成分代表所有句子共有的方向，把它投影掉，使句向量之间的差别更多反映语义。

怎么学

先读GloVe和IDF与TF-IDF的讲解 → 读原文第3节生成模型与第4节算法1 → 动手：在STS基准上比较普通平均、只加权、加权并去主成分三种句向量的相关系数。
