LRV负样本指令去幻觉

Mitigating Hallucination in Large Multi-Modal Models via Robust Instruction Tuning
2023.06论文延伸ICLR 2024Fuxiao Liu, Kevin Lin, Linjie Li, Jianfeng Wang, Yaser Yacoob, Lijuan Wang · 马里兰大学 / 微软待核对
arXiv ↗代码与数据 ↗在交互版中打开（演化树、学习进度）

问题

早期视觉指令数据几乎全是“正样本”，模型被训练成对任何问题都顺着答，问到图里不存在的东西也会编出描述。

方法

用GPT-4生成40万条覆盖16类任务的视觉指令，其中专门加入三种层次的“负样本指令”（问不存在的物体、错说存在物体的属性、错引知识），教模型学会说“没有”。

影响

揭示当时的LMM在负样本指令下幻觉严重；在它上面微调MiniGPT-4和mPLUG-Owl能明显减少幻觉，并提出用GPT-4打分的评测法GAVIE。

方法

LLaVA、MiniGPT-4等模型的指令数据里，几乎每条问题都对应图里真实存在的内容。模型因此学到一种偏好：只要被问，就给出肯定而详细的回答。用户一问“图中那只猫在干什么”，即使没有猫，模型也会认真描述一只猫。

LRV-Instruction的做法是有意加入负样本指令。数据由GPT-4根据图像的稠密标注生成，共40万条，覆盖16种视觉语言任务，回答是开放式的。负样本分三个层次：

  • 不存在物体操纵：问图里根本没有的物体；
  • 存在物体操纵：物体存在，但问题里给了错误属性或关系；
  • 知识操纵：在问题里塞进错误的背景知识。

作者还提出GAVIE，让GPT-4像人类专家一样，根据图像标注给模型回答的准确性和相关性打分，不需要人工写标准答案。

实验发现现有LMM对后两种负样本尤其容易产生幻觉；在LRV-Instruction上微调MiniGPT-4和mPLUG-Owl后，幻觉减少，几个公开数据集上的成绩也有提升；正负样本比例均衡时模型最稳健。

局限与后续

  • 指令和评测都依赖GPT-4，数据会继承GPT-4的错误，GAVIE打分也带有评委模型的偏差。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只通过监督数据纠偏，没有对模型输出给出偏好或奖励信号，细粒度的幻觉仍会残留。

读懂它需要的概念

幻觉 指令微调与对话模板 基准、排行榜与SOTA 语言模型

本篇术语

  • 负样本指令（negative instruction）　问题本身包含错误前提（不存在的物体、错误属性或知识），正确的回答应当指出前提不成立，而不是顺着回答。

怎么学

先读LLaVA理解视觉指令数据怎么生成，再看LRV论文里三种负样本的示例表，用发布的数据挑几条负样本去测一个开源VLM。
