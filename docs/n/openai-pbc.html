OpenAI重组为公益公司

2025.10事件重要OpenAI（Sam Altman、董事会主席Bret Taylor） · Microsoft · 加州与特拉华州总检察长待核对
Microsoft官方博客：合作的新篇章 ↗CNBC报道（2025-10-28） ↗Wikipedia: OpenAI（公司结构） ↗在交互版中打开（演化树、学习进度）

问题

OpenAI的商业部门是非营利组织控制下的“利润封顶”公司，投资人回报有上限、股权结构复杂，无法像普通公司那样募集千亿美元级资金，也走不通上市。

方法

2025年10月28日完成资本重组：营利部门改为公益公司OpenAI Group PBC，非营利母体更名OpenAI基金会，持股26%并任免全部董事；微软持股约27%。

影响

OpenAI变成可以正常发股融资、准备上市的公司，同时重写了与微软的合作条款，为之后1220亿美元融资和IPO申请铺平了道路。

背景

OpenAI成立时是纯非营利研究机构。2019年为了融资，它设立了“利润封顶”的营利子公司：投资者回报最多为投资额的100倍，超出部分归非营利组织，随后接受了微软10亿美元投资（OpenAI转型与微软10亿美元投资）。

这个结构有两个问题。一是非营利董事会对商业公司有最终控制权，2023年的OpenAI董事会风波风波中，非营利董事会可以绕过投资人直接解雇CEO。二是投资者回报有上限、股权层层嵌套，难以吸引需要千亿美元级资金的算力扩张（见循环融资：芯片商与OpenAI）。

2024年12月OpenAI提出方案：营利部门转为特拉华州公益公司、取消利润上限、脱离非营利组织控制。前员工、公民团体联名致信加州和特拉华州总检察长反对，马斯克也提起诉讼。2025年5月OpenAI让步，宣布非营利组织保留控制权。

方法

最终方案（2025年10月28日宣布，已获两州总检察长批准）：

  • 两层结构：非营利组织更名为OpenAI基金会；营利部门改为OpenAI Group PBC。基金会任命并可随时罢免PBC的全部董事，以此保留控制权。
  • 股权：基金会持股26%（CNBC称当时价值约1300亿美元），微软约27%（约1350亿美元），员工与其他投资者约47%。利润上限取消。基金会首期承诺投入250亿美元，用于健康研究和AI韧性。
  • 公益公司（PBC）：仍是营利公司，可以发股、上市，但章程写明公益使命，董事在决策时须兼顾使命与股东利益。

与微软的新协议同时签署，要点包括：OpenAI宣布实现AGI后须由独立专家组核验；微软对模型和产品的知识产权延长到2032年；OpenAI追加采购2500亿美元Azure服务，但微软不再享有算力供应的优先购买权；OpenAI可以发布达到要求的开放权重模型，并可通过任何云向美国国家安全客户提供API。

结果

按当时5000亿美元的估值，OpenAI成为可正常股权融资的公司。软银在重组前已批准对OpenAI剩余的225亿美元投资。2026年3月OpenAI完成1220亿美元融资、估值8520亿美元（OpenAI 1220亿美元融资）；6月向美国证交会提交上市申请，9月Altman称IPO推迟到2027年。马斯克修改诉讼请求、要求撤销重组，2026年5月陪审团以超过诉讼时效为由判其败诉（马斯克诉OpenAI案败诉）。

后来的发展

这次重组确定了前沿实验室的标准形态：营利公司在名义上服从某种使命约束（Anthropic成立从一开始就是公益公司），但资本结构与普通科技公司无异。它也改写了AI行业最重要的一组合作关系：微软从独家算力供应商变为大股东之一，OpenAI则可以同时向Oracle、AMD、博通等采购算力。

至于基金会能否真正约束商业公司，争议没有结束：据维基百科，到2026年4月，基金会董事会与PBC董事会的成员几乎完全重叠。

容易误解的地方

  • “公益公司”不是非营利组织。PBC是营利公司，可以分红、上市，只是法律允许并要求董事在股东回报之外考虑公益目标。
  • 2025年5月的让步之后，非营利组织并没有失去控制权；变化在于取消了利润上限、把营利部门改成普通股权结构。
  • 微软约27%的股份是“按转换后完全稀释”口径计算的，包含员工、投资人和基金会在内的全部股东。

本篇术语

  • 公益公司（PBC）　美国部分州的一种公司形式：本质是营利公司，但章程中写明公益目的，董事须在股东利益与公益目标之间平衡。
  • 资本重组　改变一家公司的股权和债务结构，如把不同类别的权益统一转换为普通股，常是大规模融资或上市的前置步骤。
  • 利润封顶　OpenAI 2019年的设计：投资者回报最多为投资额的100倍，超出部分归非营利组织。
