R-CNN

Rich Feature Hierarchies for Accurate Object Detection and Semantic Segmentation
2013.11论文重要CVPR 2014Ross Girshick, Jeff Donahue, Trevor Darrell, Jitendra Malik · UC Berkeley待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

PASCAL VOC检测精度几年来停在DPM的约33% mAP；AlexNet的分类突破能否用到检测上并不清楚，而且检测的标注数据只有几千张，训练大网络会过拟合。

方法

先用选择性搜索生成约2000个候选框，把每个框缩放成227×227送进ImageNet预训练、再在检测数据上微调的卷积网络提特征，最后用每类一个线性SVM打分，并回归修正框的位置。

影响

VOC 2010上mAP从DPM的33.4%跳到53.7%，确立了“候选区域＋CNN特征”和“ImageNet预训练＋目标任务微调”两个范式，开启了深度目标检测。

背景

目标检测要输出“每个物体是什么、在哪里”。2008–2012年的最强方法是可变形部件模型DPM：在图像金字塔上滑动HOG模板。到2012年，PASCAL VOC上的进展已经很慢，最好的系统靠把多种低层特征和上下文拼成复杂的集成。

AlexNet刚在ImageNet分类上大幅领先，问题是怎么用到检测上。有两个障碍：一是检测要在一张图里的成千上万个位置判断，直接用CNN滑窗太贵（同期的OverFeat正是这么做的）；二是VOC只有几千张带框的训练图，从头训练一个6000万参数的网络必然过拟合。

方法

R-CNN（Regions with CNN features）分四步：

1. 候选区域。用选择性搜索根据颜色、纹理相似性把超像素逐步合并，每张图得到约2000个与类别无关的候选框。这把“在所有位置、所有尺度上找”变成“只看2000个可能有物体的框”。 2. 提特征。不管候选框是什么形状，都连同周围16像素的上下文一起直接拉伸成227×227，送进AlexNet，取最后一个全连接层的4096维向量作为特征。 3. 分类。每个类别训练一个线性支持向量机，对2000×4096的特征矩阵打分，然后做非极大值抑制（见锚框与非极大值抑制）去掉重叠的框。 4. 框回归。用一个线性回归，根据特征预测候选框中心和宽高该怎么平移、缩放，修正定位误差——误差分析显示定位不准是主要错误来源。

预训练加微调是另一个关键：网络先在ImageNet分类上训练，再把最后的1000类输出换成21类（20类加背景），用与真值框IoU≥0.5的候选框作为正例继续训练（见预训练与微调）。微调让VOC 2007的mAP提升了8个百分点。训练SVM时则把IoU<0.3的框当负例，并用可变形部件模型DPM沿用的难负样本挖掘。

结果

PASCAL VOC 2010：mAP 53.7%（加框回归），而DPM为33.4%，用同样候选框加空间金字塔词袋的方法为35.1%。VOC 2012：53.3%，比此前最好结果相对提升30%以上。ILSVRC 2013的200类检测：31.4%，此前最好的OverFeat为24.3%。代价是速度：每张图提候选框和特征需要13秒（GPU）或53秒（CPU）。

后来的发展

R-CNN之后两年内出现了一条直接的改进链：SPPnet让整张图只过一次卷积，Fast R-CNN把分类和框回归合进网络一次训练，Faster R-CNN用网络自己生成候选框，再到Mask R-CNN加上实例分割。这一“两阶段检测器”家族统治检测直到DETR等新范式出现。

“在大数据集上预训练、在小数据集上微调”的做法与同期的DeCAF通用深度特征一起，成为几乎所有视觉任务的默认流程，直到自监督和多模态预训练接棒。

局限与后续

  • 每个候选框都要单独过一遍CNN，2000个框大量重复计算，一张图要13秒（GPU）。
    后来针对它的工作　SPPnet Fast R-CNN
  • 训练分三段：先微调CNN，再把特征写到硬盘训练SVM，最后单独训练框回归，流程繁琐、占几百GB磁盘，各段目标也不一致。
    后来针对它的工作　Fast R-CNN
  • 候选框依赖选择性搜索这种外部、不可学习的算法，每张图还要再花约2秒，召回率也限制了上限。
    后来针对它的工作　Faster R-CNN YOLO
  • 把任意形状的框硬拉伸成227×227，物体被扭曲变形，影响特征质量。
    后来针对它的工作　SPPnet Fast R-CNN

它建立在什么之上

  • 使用
    AlexNet2012.09 · 视觉 待核对
    以ImageNet预训练的AlexNet作为特征提取器，再在检测数据上微调。
  • 改进
    可变形部件模型DPM2008.06 · 视觉
    DPM的HOG模板在VOC上停在约33% mAP；用CNN特征把VOC 2010的mAP提到53.7%。
  • 改进
    Viola–Jones人脸检测2001 · 视觉
    特征和级联结构都靠手工设计和启发式，换成其他物体需要重新大量调整。
  • 改进
    HOG与手工特征时代2005 · 视觉
    用ImageNet上学到的4096维CNN特征取代手工设计的HOG梯度特征。
  • 改进
    空间金字塔匹配2006.06 · 视觉
    位置信息只是粗网格，物体位置和大小稍有变化就不匹配。
  • 使用
    选择性搜索2013 · 视觉
    用选择性搜索每张图生成约2000个候选区域，避免对所有位置滑窗。
  • 改进
    DeCAF通用深度特征2013.10 · 视觉
    DeCAF证明了AlexNet中间层特征可以直接迁移；R-CNN进一步在目标任务上微调，并用到需要定位的检测上。
  • 竞争
    OverFeat2013.12 · 视觉
    同期用CNN做检测的另一条路：OverFeat在多尺度上滑窗；R-CNN只看候选区域，在ILSVRC 2013检测上以31.4%对24.3%胜出。

读懂它需要的概念

分类、检测、分割 IoU与mAP 锚框与非极大值抑制 预训练与微调 迁移学习 卷积层、池化与感受野

本篇术语

  • 候选区域　由与类别无关的算法预先生成的、可能包含物体的框，检测器只需判断这些框而不是所有位置。
  • 框回归　从候选框的特征预测一个修正量（中心平移和宽高缩放比例），让框更贴合物体。
  • mAP　平均精度均值：对每个类别算出预测框按置信度排序后的精度—召回曲线下面积，再对所有类别求平均。

怎么学

先读IoU与mAP和锚框与非极大值抑制，弄懂检测是怎么评分的。读原文第2节（系统三模块）和附录C（框回归公式）。动手：用OpenCV自带的选择性搜索在一张图上生成候选框并画出来，再用torchvision预训练的分类网络对每个框分类，体会这种做法有多慢。
