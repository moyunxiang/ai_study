Network In Network

Network In Network
2013.12论文延伸ICLR 2014Min Lin, Qiang Chen, Shuicheng Yan · National University of Singapore待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

卷积层用线性滤波加非线性，表达力有限，而末端的全连接层参数巨大又容易过拟合。

方法

在卷积窗口里放一个小的多层感知机来代替线性滤波，并在输出端用全局平均池化代替全连接层。

影响

「1×1卷积」和「全局平均池化」两个设计被GoogLeNet / Inception、ResNet等后来的网络普遍采用。

方法

卷积层的每个滤波器在感受野内只是线性的，Lin等把它换成一个小的多层感知机，在图像上滑动（见多层感知机）。这个小感知机实现成跟在普通卷积之后的一或多层1×1卷积，就是对每个位置的通道向量做一次全连接，因此能混合各通道的信息并增加非线性。

分类端，他们把最后一层卷积的每个特征图对应一个类，对该特征图取全局平均得到分数，直接送给softmax，不再有全连接层。这样没有额外参数，更不容易过拟合，而且每个特征图可以解释为对应类的置信图。摘要称在CIFAR-10和CIFAR-100上取得当时最好的分类结果，在SVHN和MNIST上也有合理成绩。

局限与后续

  • 论文只在小图像数据集（CIFAR、SVHN、MNIST）上验证，没有给出ImageNet级别的结果。
    后来针对它的工作　GoogLeNet / Inception ResNet
  • 全局平均池化丢弃了空间位置信息，对需要定位的任务需要另外处理。
    后来针对它的工作　全卷积网络FCN

读懂它需要的概念

卷积层、池化与感受野 多层感知机 神经元与激活函数 正则化与权重衰减

本篇术语

  • 全局平均池化　对每个特征图的所有位置取平均，一个特征图变成一个数。
  • 1×1卷积　窗口大小为1×1的卷积，对每个位置的各通道做线性组合，用来改变通道数。

怎么学

学卷积层、池化与感受野，再用PyTorch写一个带1×1卷积和全局平均池化的小网络，数一下参数量。
