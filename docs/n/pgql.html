PGQL策略梯度+Q学习

Combining policy gradient and Q-learning
2016.11论文延伸ICLR 2017Brendan O'Donoghue, Rémi Munos, Koray Kavukcuoglu, Volodymyr Mnih · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

A3C这类在线策略梯度方法只能用当前策略刚采到的数据，每条经验用一次就扔；Q学习能反复利用回放池，却和策略梯度是两套互不相干的算法。

方法

证明带熵正则的策略梯度在不动点处，策略的对数概率（动作偏好）与Q值只差一个与状态有关的量：Q̃(s,a) = α(log π(a|s) + H(π(·|s))) + V(s)。于是可以从策略里“读出”Q值，再对它做Q学习更新，用回放数据改进同一个策略。

影响

揭示了“熵正则策略梯度 ≈ 优势函数学习”的等价关系，是软Q学习、PCL、SAC等最大熵RL把策略与价值统一起来的理论来源之一；PGQL本身在Atari全集上超过A3C和Q学习。

背景

A3C用多个并行actor做在线的优势演员—评论家更新，加熵正则防止策略过早变成确定性的；它稳定、通用，但样本只能用一次。DQN（Nature版）靠经验回放大幅提高了数据利用率，但只学Q值，策略是贪心导出的。很多人尝试把两者结合（例如ACER用重要性采样修正回放数据），但需要处理离策略修正的方差。作者从另一个角度切入：熵正则策略梯度的最优解本身就隐含了一个Q函数。

方法

带熵正则的策略梯度目标是 J(π) = E[Σ r] + α Σ_s H(π(·|s))。作者证明，它的不动点满足

π(a|s) = exp( (Q^π(s,a) − V(s)) / α )，

即策略是Q值的Boltzmann分布。反过来，任意策略都可以诱导一个估计

Q̃(s,a) = α ( log π(a|s) + H(π(·|s)) ) + V(s)。

PGQL的更新由两部分组成：

  • 在线部分：在当前采样数据上做普通的熵正则演员—评论家（A3C式）更新；
  • 离线部分：从回放池采样转移，把上式中的 Q̃ 当作Q函数，做Q学习的Bellman误差更新 (r + γ max_a′ Q̃(s′,a′) − Q̃(s,a))²，梯度通过 log π 和V回传到同一套网络。

两部分加权相加。作者还证明了更一般的等价性：动作价值拟合方法与演员—评论家算法可以互相转化，正则化策略梯度可以解释为优势函数学习。

结果

摘要称，数值例子显示PGQL的数据效率和稳定性都有提升；在完整的Atari游戏集上，PGQL的表现超过了异步优势演员—评论家（A3C）和Q学习。

后来的发展

同一时期的软Q学习（能量策略）与PCL路径一致性学习从最大熵RL出发得到了相近的“策略与软Q值互相决定”的关系；后来的SAC把这条思路用于连续控制并成为主流算法。PGQL中“正则化策略梯度等价于优势学习”的结论也常在策略优化理论中被引用。

局限与后续

  • 等价关系只在不动点处严格成立，训练中途从策略读出的Q值可能很不准，Q学习更新会把误差传回策略。

读懂它需要的概念

策略梯度 Actor-Critic与优势函数 信息量与熵 Bellman方程 Softmax与logits

本篇术语

  • 熵正则化　在目标中加上策略熵，鼓励策略保持一定随机性，避免过早收敛到确定性动作。
  • Boltzmann策略　按 exp(Q/α) 的比例选择动作的随机策略，α越小越接近贪心。

怎么学

先熟悉A3C和Softmax与logits；读原文第3节不动点推导；在一个小型网格世界中验证：训练熵正则策略后，用公式读出的Q值与真实Q值是否接近。
