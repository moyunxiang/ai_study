SEVIR风暴影像数据集

SEVIR: A Storm Event Imagery Dataset for Deep Learning Applications in Radar and Satellite Meteorology
2020.12数据集延伸NeurIPS 2020Mark Veillette, Siddharth Samsi, Christopher Mattioli · MIT林肯实验室待核对
NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

公开的GOES卫星和NEXRAD雷达数据量巨大、难处理，妨碍了降水临近预报等深度学习研究。

方法

把多传感器时空对齐的风暴事件整理成一个带基线与指标的数据集。

影响

成为降水临近预报和合成雷达等任务常用的公开数据集之一（二级解释）。

背景

背景：雷达与卫星数据按传感器分散在不同格式里，研究者要花大量时间对齐，才能训练临近预报等深度学习模型。

方法

做法：SEVIR包含超过10000个天气事件，每个事件是384 km乘384 km、跨4小时的图像序列，数据来自五种类型：GOES-16成像仪的三个通道、NEXRAD垂直积分液态水等。数据集经过标注、整理和时空对齐，并附带深度学习基线实现和评价指标。

后来的发展

NowcastNet、DGMR雷达降水生成预报这类临近预报工作面向的是同一类雷达数据（二级解释，未核对）。
