WSD统一评测框架

Word Sense Disambiguation: A Unified Evaluation Framework and Empirical Comparison
2017.04数据集延伸EACL 2017Alessandro Raganato, Jose Camacho-Collados, Roberto Navigli · 罗马大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

词义消歧有十多年的Senseval/SemEval评测，但各测试集使用不同版本的WordNet、不同格式，训练语料也各不相同，系统之间的比较常常不公平、不可复现。

方法

把常用的训练语料（SemCor、OMSTI）和五个全词消歧测试集统一转换到WordNet 3.0和同一种格式，在同一设置下重新评测一批知识型和有监督系统。

影响

这个框架成为此后神经词义消歧（GlossBERT、EWISER、ESCHER等）的标准评测基准，「ALL」合并测试集上的F1成为该方向最常报告的数字；论文的结论也纠正了一些流行看法。

背景

词义消歧（WSD）要判断一个多义词在句子里取的是词典中的哪个义项，例如bank是「银行」还是「河岸」。Lesk词义消歧用词典释义重叠，Yarowsky自举词义消歧用自举学习；Senseval / SemEval系列评测从1998年起提供标准数据，WordNet是主要的义项清单。但不同届评测用的WordNet版本不同（1.7、2.1、3.0），同一个义项在不同版本里编号不同；有的系统在SemCor上训练，有的用更大的自动标注语料OMSTI，比较时常常不是同一回事。

方法

统一数据。 训练语料：SemCor（人工标注义项的Brown语料子集）和OMSTI（基于平行语料自动获得的大规模标注）。测试集：Senseval-2、Senseval-3、SemEval-2007第17项、SemEval-2013第12项、SemEval-2015第13项，全部映射到WordNet 3.0，转成统一的XML格式，并把五个集合合并成一个「ALL」测试集。

统一评测。 在同一设置下运行两类系统：

  • 知识型：只用WordNet等词汇资源，如扩展Lesk、基于图随机游走的UKB、Babelfy；
  • 有监督：在SemCor或SemCor+OMSTI上训练的IMS（用局部上下文特征的线性SVM）、IMS加词向量特征、context2vec、基于LSTM的模型等。

同时报告最常见义项（MFS）基线：总是选训练数据中该词最常出现的义项。

结果

摘要称：有监督系统明显优于知识型方法；在有监督系统中，基于传统局部特征的线性分类器（IMS）仍是难以超越的强基线，而利用无标注数据的神经方法表现出潜力。

后来的发展

后续WSD论文几乎都在这一框架的五个测试集和ALL上报告F1。基于BERT的GlossBERT（2019）、利用WordNet关系图的EWISER（2020）等先后在其上超过了IMS和MFS基线，有工作宣称在ALL上接近或超过估计的人类标注一致性上限。框架也使「罕见义项」「训练中未见的词」等细分分析成为可能。

局限与后续

  • 测试集都基于WordNet的细粒度义项，有些义项区分连人类标注者都难以一致，F1的天花板本身就不高。

本篇术语

  • 词义消歧（WSD）　判断多义词在具体上下文中取词典里的哪个义项。
  • 全词消歧（all-words）　要求为文本中所有实词都给出义项，而不是只针对少数几个目标词。
  • 最常见义项基线（MFS）　总是选该词在训练语料中最常见的义项，是WSD里很难超越的简单基线。

怎么学

先读Lesk词义消歧和WordNet → 读原文第2–3节的数据统一过程和第4节的比较结果 → 动手：下载框架数据，实现MFS基线和一个用BERT表示做最近邻的消歧器，在ALL上对比F1。
