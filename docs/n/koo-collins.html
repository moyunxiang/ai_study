三阶依存分析

Efficient Third-Order Dependency Parsers
2010.07论文延伸ACL 2010Terry Koo, Michael Collins · MIT CSAIL待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

图依存分析把整棵树的得分拆成小“部件”之和：部件越大（同时看几条依存弧），特征越丰富，但动态规划算法越慢；当时最强的二阶分析器已要 O(n⁴) 时间，只能看两条弧的组合。

方法

设计新的动态规划算法，让打分部件包含三条依存弧——同时看到中心词的祖父、兄弟与孙子关系（“祖孙兄弟”与“三兄弟”部件），而时间复杂度仍保持在 O(n⁴)、空间 O(n³)。

影响

在Penn Treebank上把无标记依存准确率推到93.04%，是神经方法出现前图依存分析的最好成绩之一；“更高阶部件加专门的动态规划”成为高阶依存分析的标准路线，后来也被用作神经分析器的结构化解码。

背景

Eisner依存分析算法（1996）给出了 O(n³) 的一阶投射依存分析算法：每条弧单独打分。MSTParser与MIRA（2005）用MIRA训练一阶模型，McDonald与Pereira（2006）加入相邻兄弟弧的二阶部件，Carreras（2007）又加入祖孙关系，后者需要 O(n⁴) 时间、O(n³) 空间。部件更大意味着能捕捉“这个动词已经有了一个宾语，不太会有第二个”之类的约束，但每加一阶，朴素的动态规划复杂度都会再乘一个n。

方法

依存树的得分写成部件得分之和 score(y) = Σ_{p∈parts(y)} w·f(p)。论文定义两类三阶部件：

  • grand-sibling：祖父g、中心词h、以及h的两个相邻修饰词（兄弟）m与s，即同时包含 g→h、h→m、h→s 三条弧；
  • tri-sibling：中心词h与它同一侧依次相邻的三个修饰词。

关键在于把Eisner算法中的“完整跨度”和“不完整跨度”两类图表项扩展为带祖父信息的“g-跨度”：每个跨度除了记录两端，还记住其中心词的父亲是谁。作者证明，在这种图表结构下，所有三阶部件都能在合并跨度时被计算，总体时间仍为 O(n⁴)、空间 O(n³)，与Carreras的二阶模型相同。

权重用平均感知机训练；为加速，还先用一阶模型对边做边缘概率剪枝，只保留可能的弧。

结果

在Penn WSJ Treebank上无标记依存准确率（UAS）达到93.04%，在捷克语Prague Dependency Treebank上达到87.38%（原文摘要），均优于此前的二阶模型。

后来的发展

此后Koo等人用对偶分解把高阶部件推广到非投射树，Zhang与McDonald等用立方剪枝支持任意高阶特征；而丰富非局部特征转移式分析（2011）则在转移式分析中用丰富的非局部特征达到同等水平。神经时代，神经网络依存分析与双仿射依存分析用学到的表示代替高阶手工特征，一阶双仿射模型已经超过三阶的特征模型；但二阶、三阶的结构化解码仍被一些神经分析器用于进一步提升。

局限与后续

  • O(n⁴) 时间对长句仍很慢，实际需要用低阶模型先剪枝。

读懂它需要的概念

动态规划 图、树与搜索 时间与空间复杂度 特征与表示学习

本篇术语

  • 部件（factor）　依存树中被一起打分的一小组弧，一阶是单条弧，二阶加兄弟或祖孙，三阶同时看三条弧。
  • 投射树　把依存弧画在句子上方时没有交叉的树。
  • UAS　无标记依存准确率：每个词的中心词预测正确的比例，不考虑关系标签。

怎么学

先读Eisner依存分析算法的跨度式动态规划 → 读本文第3–4节g-跨度与合并规则 → 动手：实现一阶Eisner算法，再尝试把相邻兄弟部件加进去，比较复杂度。
