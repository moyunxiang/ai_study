REDQ随机集成双Q

Randomized Ensembled Double Q-Learning: Learning Fast Without a Model
2021.01论文延伸ICLR 2021Xinyue Chen, Che Wang, Zijian Zhou, Keith Ross · 纽约大学上海 / 纽约大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

在MuJoCo连续控制上，MBPO这类基于模型的方法靠每采一步数据就更新很多次（高UTD比）获得远高于无模型方法的样本效率；无模型方法一提高更新次数，Q值高估就失控。

方法

用一组Q网络（如10个），每次算目标时随机抽两个取最小值，再配合远大于1的更新-数据比，让无模型的SAC也能「多更新、少采样」。

影响

说明高样本效率不一定要学环境模型，高UTD+集成成为后来DroQ、样本高效连续控制研究反复比较的基线。

方法

UTD比（update-to-data ratio）指每与环境交互一步，对网络做多少次梯度更新。SAC默认是1；把它提到20，Q网络在同一批数据上反复拟合，过估计偏差会累积得很快。

REDQ在SAC上改三处：一是UTD比远大于1（文中主要用20）；二是维护N个Q网络的集成（默认N=10），各自独立初始化、都用同一批数据训练；三是计算TD目标时，从N个Q里随机抽M个（默认M=2）取最小值，这是TD3双Q截断的推广，随机子集让目标的偏差可以通过M来调节。策略更新则用全部N个Q的平均。

摘要称，REDQ在MuJoCo上的表现与当时最强的基于模型的算法相当甚至更好，参数更少、运行时间更短；作者称它是第一个在连续动作上成功使用UTD≫1的无模型深度RL算法。文中还分析了各方法Q估计偏差的均值和方差，说明随机子集取最小能把偏差控制在接近零的水平。

  • 10个Q网络、每步20次更新，计算量比SAC高一个数量级，墙钟时间仍然可观。

读懂它需要的概念

时序差分与自举 Actor-Critic与优势函数 集成学习 on-policy与off-policy

本篇术语

  • UTD比　update-to-data ratio，每收集一步新数据对网络做多少次梯度更新；越高越省样本，但越容易过拟合和高估。

怎么学

先读TD3和SAC；读原文第3节算法和第4节偏差分析；在SAC实现上把Q网络改成集成并调高UTD，比较Q估计偏差曲线。
