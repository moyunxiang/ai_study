BEiT

BEiT: BERT Pre-Training of Image Transformers
2021.06论文重要ICLR 2022Hangbo Bao, Li Dong, Songhao Piao, Furu Wei · Microsoft Research / Harbin Institute of Technology待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

BERT的掩码预测在语言上极其成功，但图像没有现成的“词表”：直接让模型补全被遮住的像素，它只学会了平滑插值，ViT论文的尝试比有监督预训练低4%。

方法

先用DALL·E的离散变分自编码器把每个16×16图像块变成8192个“视觉词”中的一个；遮住约40%的图像块，让ViT根据剩余部分预测被遮位置的视觉词编号，就像BERT预测被遮的单词。

影响

第一个让掩码图像建模在微调精度上超过有监督预训练和对比学习的方法，开启了视觉的“BERT式预训练”路线，几个月后MAE把它简化并做大。

背景

BERT的预训练任务很简单：随机遮住15%的词，让模型根据上下文猜出它们（见掩码建模）。语言天然是离散的，猜词就是在几万个词里做分类。图像是连续的像素，Vision Transformer论文尝试让模型直接预测被遮块的平均颜色，ViT-B只到79.9%，比有监督预训练低4%。原因是：直接回归像素时，模型可以靠相邻像素的短程相关性“抄近道”，把精力花在高频细节上，学不到语义。

同期的自监督主流是对比学习和DINO式的自蒸馏，它们依赖精心设计的数据增强。另一条生成式路线Image GPT对像素做自回归预测，需要数十亿参数才有不错的效果。

方法

两种视图。一张224×224的图既被切成14×14 = 196个图像块（ViT的输入），又被一个图像分词器变成14×14个离散的视觉token。分词器直接借用DALL·E训练好的离散变分自编码器（dVAE），词表大小8192（见向量量化与离散token）。

掩码图像建模（MIM）。随机遮住约40%的图像块（最多75块），被遮的位置换成一个可学习的[MASK]向量，连同可见块一起送进ViT编码器。每个被遮位置的输出接一个softmax分类头，预测它原本的视觉token是8192个中的哪一个，损失是交叉熵。因为目标是离散编号而不是像素值，模型无需关心纹理细节，只需判断“这里大概是哪种视觉内容”。

块状遮挡。不是随机挑零散的块，而是一次遮住一片相邻的矩形区域，否则模型可以从四周像素轻易插值出来。消融显示块状遮挡对分割尤其有用。

预训练后丢掉分类头，在下游任务上整体微调。

结果

只用ImageNet-1k、不用标签预训练，BEiT-B微调后达到83.2%，比相同设置从头训练的DeiT-B（81.8%）高1.4；BEiT-L达到86.3%，超过在ImageNet-22k上有监督预训练的ViT-L（85.2%）。ADE20K语义分割mIoU 45.6，高于有监督预训练（45.3）和DINO（44.1）。消融中把预测视觉token改成直接回归像素，结果甚至不如从头训练，说明离散视觉token是关键。弱点是线性评估：BEiT-B只有56.7%，远低于DINO-B的78.2%。

后来的发展

BEiT之后掩码图像建模迅速成为视觉自监督的主流。五个月后掩码自编码器MAE证明根本不需要分词器：直接回归像素也行，关键是遮住75%并让编码器只处理可见块，既更简单也更快。iBOT把DINO的自蒸馏和掩码预测合在一起；data2vec把预测目标换成教师网络的特征，统一了视觉、语音和文本；EVA用CLIP特征作为重建目标，把ViT做到10亿参数级别；BEiT-3进一步把同一思路扩展到图文多模态。

容易误解的地方

  • BEiT的分词器不是自己训练的，而是OpenAI为DALL·E训练好的dVAE，它在大量外部图片上训练过，所以“只用ImageNet”并不完全准确。
  • 掩码建模学到的特征需要微调才好用，线性评估远不如对比学习和DINO；只看线性评估会严重低估它。

局限与后续

  • 依赖一个预先训练好的离散分词器（DALL·E的dVAE），增加了一个额外阶段和外部依赖。
    后来针对它的工作　掩码自编码器MAE
  • 编码器要处理包括[MASK]在内的全部196个位置，预训练计算量与不遮挡时相当。
    后来针对它的工作　掩码自编码器MAE
  • 冻结特征的线性评估很弱（BEiT-B 56.7%），不适合直接拿特征做检索或零样本迁移。
    后来针对它的工作　iBOT DINOv2
  • dVAE视觉token主要编码低层外观，作为预测目标语义不够强。
    后来针对它的工作　EVA data2vec

    ViT的掩码块预测自监督比有监督低4%；BEiT改为预测离散视觉token，微调精度超过有监督预训练。
  • 延续
    BERT2018.10 · LLM
    把BERT的掩码语言建模搬到图像：遮住图像块，预测其离散视觉token。
  • 改进
    DeiT2020.12 · 视觉
    以从头训练的DeiT-B（81.8%）为基线，同一架构经BEiT预训练后提升到83.2%。
  • 使用
    DALL·E2021.01 · 生成
    直接使用DALL·E训练好的dVAE作为图像分词器，词表8192。
  • 竞争
    DINO2021.04 · 视觉
    同期的判别式自监督路线；BEiT微调和分割更好，DINO的线性评估远强于BEiT。
  • 竞争
    Image GPT2020.06 · 生成
    同为生成式预训练；iGPT对像素自回归且需数十亿参数，BEiT用掩码预测视觉token，86M参数的模型就能微调出更好的结果。

读懂它需要的概念

掩码建模 向量量化与离散token 自监督学习 图像块与视觉token 预训练与微调 交叉熵

本篇术语

  • 视觉token　图像分词器把一块图像映射成的离散编号，类比文本里的词。BEiT中每个16×16块对应8192个编号之一。
  • 掩码图像建模（MIM）　遮住部分图像块，让模型根据可见部分恢复被遮内容（像素、视觉token或特征）的自监督任务。
  • 块状遮挡　每次遮住一片相邻的矩形图像块，而不是零散的单块，防止模型靠邻近像素插值作弊。

怎么学

先读BERT的掩码语言建模和向量量化与离散token。读原文第2节（图像分词器、掩码图像建模、块状遮挡的算法1）和表4的消融。动手：用DALL·E开源的dVAE把一张图编码成14×14的token网格再解码回来，观察它保留了什么、丢了什么。
