保形预测

Algorithmic Learning in a Random World
2005思想延伸Springer 2005（专著）Vladimir Vovk, Alex Gammerman, Glenn Shafer待核对
Springer（DOI） ↗Angelopoulos & Bates：A Gentle Introduction to Conformal Prediction ↗Wikipedia：Conformal prediction ↗在交互版中打开（演化树、学习进度）

问题

模型给出的置信度常常不准，高风险场景需要“真值有90%概率落在这个区间里”这样有严格保证的不确定性，却不想对数据分布或模型做假设。

方法

在一份校准集上计算“不一致分数”，取其分位数作为阈值，输出所有分数低于阈值的候选，构成预测集或预测区间。

影响

成为给任意黑箱模型加上有限样本覆盖率保证的标准工具，近年在深度学习、LLM和医学预测中被大量使用。

方法

Gammerman、Vovk与Vapnik在1998年以直推学习的形式提出保形预测，次年Saunders等给出今天常用的p值版本，Vovk、Gammerman与Shafer在2005年的专著中系统化；2002年提出的归纳式（分割）版本让它可以套在任意训练好的模型上。

分割保形预测的做法：把数据分成训练集和校准集，模型只训练一次；为每个校准样本算一个不一致分数，例如回归里的 |y − ŷ|，分类里的 1 − p(真实类)；取这些分数的约(1−α)分位数q。对新输入，输出所有不一致分数不超过q的候选——回归里就是区间 ŷ ± q。只要数据满足可交换性（比独立同分布更弱的假设），真值落在输出里的概率至少为1−α，这一保证与模型好坏无关；模型越好，区间越窄。

它的保证是对全体数据平均意义上的覆盖（边际覆盖），不保证每一类输入都达标；分布偏移会破坏可交换性，保证随之失效。

局限与后续

  • 只保证边际覆盖率，对某些子群体或困难输入，实际覆盖率可能明显低于标称值。

它建立在什么之上

  • 使用
    支持向量机1995 · 基础
    早期保形预测出自Vapnik一派的直推学习研究，常以支持向量机等模型的输出构造不一致分数。
  • 延续
    交叉验证1974 · 基础
    同样靠留出数据评估模型，但不是用来选模型，而是用校准集的误差分布直接给出带保证的预测区间。
  • 竞争
    贝叶斯神经网络1992 · 基础
    贝叶斯方法的不确定性依赖先验和模型设定是否正确；保形预测不对分布做假设，只要可交换就有覆盖率保证。

读懂它需要的概念

随机变量与概率分布 训练集、验证集与测试集 模型校准 分布偏移

本篇术语

  • 不一致分数　衡量一个候选答案与模型预测有多不符的数，越大越不像真值，例如预测值与候选值之差的绝对值。
  • 可交换性　把样本顺序任意打乱，联合分布不变；独立同分布的数据一定满足。

怎么学

先补训练集、验证集与测试集和模型校准；读Angelopoulos与Bates教程第1节；用任意回归模型在留出集上实现分割保形预测，检查测试集上90%区间的实际覆盖率。
