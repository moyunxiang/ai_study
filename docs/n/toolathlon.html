The Tool Decathlon: Benchmarking Language Agents for Diverse, Realistic, and Long-Horizon Task Execution

问题

工具调用基准多是单一领域、简化环境或模拟接口，测不出智能体在多个真实软件之间协作完成长流程工作的能力。

方法

基于MCP服务器接入32个真实软件、604个工具，用来自真实软件的初始状态（几十个学生的课程、真实财务表格）构造108个跨应用任务，每题用专门脚本严格验证结果。

影响

成为2025年底至2026年模型卡里常见的智能体工具调用指标；发布时最好的Claude-4.5-Sonnet成功率仅38.6%。

方法

Toolathlon覆盖日常软件（Google Calendar、Notion）到专业软件（WooCommerce、Kubernetes、BigQuery），工具大多来自作者修订或自己实现的模型上下文协议MCP服务器。与以往只保证接口真实的基准不同，它给出真实而多样的环境初始状态，例如一门有几十个学生的Canvas课程、一份真实的财务电子表格，任务要求跨多个应用协作，平均约20轮交互。

每个任务都有专门的评估脚本检查最终环境状态，不依赖LLM裁判。发布时最好的Claude-4.5-Sonnet成功率38.6%、平均调用工具20.2轮，最好的开源权重模型DeepSeek-V3.2-Exp为20.1%。

局限与后续

  • 只有108个任务，单个分数的统计误差不小；环境搭建复杂，复现和维护成本高。
