DigiRL设备控制RL

DigiRL: Training In-The-Wild Device-Control Agents with Autonomous Reinforcement Learning
2024.06论文延伸NeurIPS 2024Hao Bai, Yifei Zhou, Mert Cemri, Jiayi Pan, Alane Suhr, Sergey Levine, Aviral Kumar · UC伯克利 / UIUC / Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉语言模型的训练数据里几乎没有“做决策”的数据；只用人类演示做监督微调的手机智能体，一遇到真实设备上的弹窗、加载延迟、网页变化就不知所措。

方法

在可并行的真实安卓环境里自主强化学习：先用离线RL从已有数据初始化，再转到在线RL边操作边学，用一个视觉语言模型自动判断任务是否完成。

影响

在Android-in-the-Wild上把1.3B模型的成功率从17.7%提升到67.2%，说明对GUI智能体来说，在真实环境里自己试错比模仿静态演示有效得多。

方法

静态演示的问题在于真实设备是随机且不断变化的：同一个操作，这次弹出广告，下次网页改版。只模仿演示的模型没见过这些情况，一旦偏离演示轨迹就无法恢复。

DigiRL的组成：

  • 环境：一套可扩展、可并行的安卓模拟器集群，智能体看截图、输出点击和输入动作；用一个视觉语言模型（基于Gemini）作为评估器，自动判断每条轨迹是否完成了任务，给出二值奖励；
  • 两阶段训练：先在已有的交互数据上做离线RL初始化，再在环境里做离线到在线的RL；
  • 算法：优势加权回归式的策略更新（参考AWR优势加权回归），优势估计考虑了环境的随机性，同时用一个自动课程挑选最能提供学习信号的任务。

在Android-in-the-Wild（AitW）任务上，1.3B的视觉语言模型经过DigiRL训练，成功率从监督微调的17.7%提高到67.2%，远超用GPT-4V驱动的AppAgent手机智能体（8.3%）和用AitW数据训练的CogAgent等先前方法。

局限与后续

  • 任务主要来自AitW中的网页购物和通用指令，与复杂的多应用、长流程手机任务相比仍偏简单。

怎么学

先读ArCHer分层多轮RL和AppAgent手机智能体 → 读原文第4节环境与评估器、第5节算法 → 动手：在安卓模拟器上写一个随机点击的智能体，统计弹窗等意外情况出现的频率，体会静态演示覆盖不到的情况。
