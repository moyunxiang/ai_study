Halide：算法与调度分离

Halide: A Language and Compiler for Optimizing Parallelism, Locality, and Recomputation in Image Processing Pipelines
2013.06论文延伸PLDI 2013Jonathan Ragan-Kelley, Connelly Barnes, Andrew Adams, Sylvain Paris, Frédo Durand, Saman Amarasinghe · MIT / Adobe / Google待核对
ACM DOI ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

图像处理流水线要同时优化并行、局部性（缓存命中）和重复计算三者，手写优化代码往往几百行，且换一台机器就要重写。

方法

把算法（每个像素怎么算）和调度（以什么顺序、怎样分块并行计算）分成两部分写，改调度不会改变结果。

影响

这种「算法与调度分离」的设计思想后来被深度学习编译器TVM等直接继承。

方法

Halide是嵌入C++的领域专用语言（官网说明目标平台包括多种CPU架构和CUDA、OpenCL、Metal等GPU接口）。程序员先用函数式的方式写出算法，如 blur(x, y) = (in(x−1, y) + in(x, y) + in(x+1, y)) / 3；再单独写调度，说明这个函数是否分块（tile）、是否并行、是否向量化、与上一个阶段融合还是缓存其结果。同一个算法换一套调度，就能得到针对不同硬件的高速实现，而且保证结果一致。

论文在多个图像处理任务上，代码量远少于手写实现，并取得相近或更好的速度。后来TVM深度学习编译器把同样的分离用到了神经网络算子上。
