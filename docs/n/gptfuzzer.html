GPTFuzzer越狱模糊测试

GPTFUZZER: Red Teaming Large Language Models with Auto-Generated Jailbreak Prompts
2023.09论文延伸USENIX Security 2024Jiahao Yu, Xingwei Lin, Zheng Yu, Xinyu Xing · 西北大学（美国）/ 蚂蚁集团待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

越狱模板（如DAN）大多靠人手工编写，数量有限、更新慢，很难对大模型做大规模的安全测试。

方法

借鉴软件安全里的AFL模糊测试：以人写的越狱模板为种子，不断选种、变异出新模板，用一个判断模型自动判定越狱是否成功，保留有效的继续变异。

影响

把模糊测试引入大模型红队，成为自动化越狱生成的常用基线，被HarmBench等越狱评测和后续自动红队方法拿来对比。

方法

三个组件。种子选择：从当前模板池中挑下一个要变异的模板，作者用类蒙特卡洛树搜索的策略，在“挑已知有效的”和“尝试新的”之间取平衡。变异算子：让一个大模型对模板做改写，例如生成风格相似的新模板、把两个模板交叉拼接、扩写、缩短、改写句子，保持越狱意图不变。判断模型：一个微调过的RoBERTa分类器，判断目标模型的回答是否真的给出了有害内容。

流程。每轮把变异出的模板套上有害问题发给目标模型，判断成功就把模板加入种子池。整个过程只需要黑盒访问目标模型。

结果。作者在多个商业和开源大模型上评测。即使初始种子模板效果不好，GPTFuzz也能生成攻击成功率很高的模板，对ChatGPT和Llama-2等模型的成功率超过90%，效果优于人写的模板。

局限与后续

  • 依赖人写模板作为起点，生成的模板与种子风格相近；判断模型会误判，模板也容易被针对性的防御识别。
