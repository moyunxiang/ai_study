Neural Baby Talk

问题

神经网络生成的图像描述读起来通顺，却常常说出图里没有的东西，因为它很大程度上在背训练集里的语言搭配；老式“模板+检测器填空”的方法有依据但很生硬。

方法

先生成一个带空槽的句子模板，每个槽明确绑定到检测器找到的某个图像区域，再用该区域的检测类别去填槽，整个过程端到端可微。

影响

把“描述要落到检测到的物体上”做成了可训练的框架，在常规描述和新物体描述上都达到当时最好，是视觉落地（grounded）描述方向的常用对照。

方法

此前的图像描述分两派。经典的模板方法（作者称为baby talk）先用检测器找出物体，再往固定句式里填词，句子总能对上图像但很呆板；视觉注意力、自底向上注意力这类神经方法直接逐词生成，流畅度高，却容易受语言先验影响——训练集里“餐桌”常和“披萨”一起出现，模型就可能在没有披萨的图上也写出披萨。

Neural Baby Talk把两者结合：解码器每一步决定输出的是普通文本词还是一个视觉词槽。如果是槽，就用注意力在检测器给出的候选区域里选一个，槽的内容由该区域的检测类别决定，并进一步细化单复数和细粒度类别（例如把“狗”细化为某个品种）。这样，句子里的名词都能指回图中具体的框，而连接词和句式仍由语言模型生成。

摘要报告，在COCO和Flickr30k的标准描述与新物体描述任务上都达到当时最好；当训练与测试的场景组合分布不同时（也就是语言先验不再可靠时），它的优势更明显。

读懂它需要的概念

注意力机制 循环网络与隐状态 分类、检测、分割 解码：贪心、束搜索、温度与top-p 语言模型

本篇术语

  • 视觉词槽（visual word / slot）　句子模板中的一个空位，绑定到图中某个检测框，最终由该框的物体类别来填写。
  • 新物体描述（novel object captioning）　测试图中出现训练描述里从没出现过的物体类别，考察模型能否借助检测器把它说出来。

怎么学

先理解视觉注意力的注意力解码和Faster R-CNN的检测输出，再读NBT第3节解码器如何在文本词和视觉词之间切换。
