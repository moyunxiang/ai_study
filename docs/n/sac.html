SAC

Soft Actor-Critic: Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor
2018.01论文延伸ICML 2018Haarnoja, Zhou, Abbeel, Levine · UC Berkeley待核对
arXiv ↗SAC v2（含自动温度） ↗在交互版中打开（演化树、学习进度）

问题

深度RL样本效率差、对超参数很脆弱。DDPG这类离策略确定性方法训练不稳，同策略的PPO又太费样本。

方法

在最大熵RL框架下做离策略actor-critic：策略不仅要最大化回报，还要最大化自身的熵，用随机策略保持探索并稳住训练。

影响

成为连续控制最常用的离策略基线之一，后续MBPO、图像增强DrQ、离线强化学习CQL等都以它为底座。

方法

目标函数里在每步奖励上加一项策略熵：J = Σ E[r(s,a) + α·H(π(·|s))]，α控制「尽量随机」的力度。直观地说：完成任务的同时尽量多保留可选的动作，不过早收敛到单一做法。

实现上它是一个actor-critic（见Actor-Critic与优势函数）：Q网络用Bellman方程的软版本（目标里包含熵项）做离策略学习，经验放在on-policy与off-policy意义下的重放池里反复使用；策略输出高斯分布，用重参数化技巧直接对Q值求梯度来更新。论文用两个Q网络取较小者缓解过估计。摘要称它在连续控制基准上超过此前的同策略和离策略方法，并且在不同随机种子之间表现非常相近。

局限与后续

  • 温度α需要手调，不同任务最优值不同。

  • 以高斯策略为主，对动作空间离散或多峰分布的情形不自然。

它建立在什么之上

  • 改进
    PPO2017.07 · RL 已核对
    on-policy，每批数据用几轮就丢，样本效率远低于离策略方法，真实机器人上难以直接训练。
  • 改进
    REINFORCE策略梯度1992 · RL 已核对
    随机策略可能过早收敛到确定性的次优动作而不再探索。
  • 改进
    TRPO2015.02 · RL 已核对
    同一批样本只能用一次（on-policy），样本效率低。
  • 改进
    确定性策略梯度DPG2014.06 · RL
    确定性策略自身不探索，只能靠人为加噪声，噪声大小难调，在稀疏奖励任务上很弱。
  • 延续
    DQN（Nature版）2015.02 · RL
    把DQN的经验回放与目标网络思路带入连续动作的actor-critic。
  • 改进
    广义优势估计GAE2015.06 · RL
    仍是on-policy方法，数据用一次就扔，双足行走要相当于1–2周真实时间的模拟经验。
  • 改进
    直升机特技飞行RL2003 · 具身·世界模型
    需要人类飞行员先演示足够的数据。
  • 改进
    Expected SARSA2009.03 · RL
    需要对下一状态的所有动作求期望，动作空间很大或连续时不能直接使用。
  • 改进
    DDPG2015.09 · RL
    DDPG的确定性策略训练脆弱、依赖精细调参；SAC用随机策略加熵正则让训练更稳。
  • 改进
    Q-Prop控制变量策略梯度2016.11 · RL
    仍以TRPO为主体，每次更新需要新采样的同策略批次，样本效率不及纯离策略方法。
  • 改进
    PCL路径一致性学习2017.02 · RL
    温度τ和路径长度d需要调节，实验主要在算法类小任务和简单控制任务上，在大规模连续控制上没有成为主流。
  • 改进
    软Q学习（能量策略）2017.02 · RL
    SVGD采样网络和重要性采样估计软值都很复杂，训练不稳定、实现门槛高。
  • 改进
    ACKTR2017.08 · RL
    仍是同策略方法，样本效率比不上离策略的actor-critic。
  • 改进
    D4PG分布式确定性策略梯度2018.04 · RL
    依赖大规模并行采集，墙钟效率高但样本效率并不突出。
