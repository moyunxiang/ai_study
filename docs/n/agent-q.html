Agent Q搜索加DPO

Agent Q: Advanced Reasoning and Learning for Autonomous AI Agents
2024.08论文延伸Pranav Putta, Edmund Mills, Naman Garg, Sumeet Motwani, Chelsea Finn, Divyansh Garg, Rafael Rafailov · MultiOn / 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

网页智能体只靠模仿专家演示来微调，一旦走偏就会错上加错（复合误差），而且演示数据里几乎没有探索和失败的经验。

方法

让智能体在网页上用带自我评价的蒙特卡洛树搜索探索多条路径，把搜索得到的好坏动作对用离策略的DPO反复微调模型，使它同时从成功和失败的轨迹中学习。

影响

在真实订餐网站上把Llama-3 70B的零样本成功率从18.6%提升到81.7%，展示了“搜索+偏好优化”训练网页智能体的潜力，常被后续网页智能体RL工作引用。

方法

Agent Q把三样东西组合在一起：

  • 引导式MCTS：智能体在网页环境里每一步可以尝试多个动作，用蒙特卡洛树搜索UCT展开搜索树，向成功率高的分支倾斜，探索出比单条演示更丰富的轨迹；
  • 自我批评：在每个节点上，让模型自己评价各候选动作的好坏，给搜索提供中间步骤的价值信号，弥补网页任务奖励稀疏的问题；
  • 迭代的离策略DPO：把搜索树中同一状态下“好动作”与“差动作”配成偏好对，用DPO直接偏好优化的离策略变体微调模型；再用新模型搜索、再微调，反复迭代。这样失败的分支也成了有用的训练信号。

在WebShop模拟网购环境中，它持续优于行为克隆和强化微调基线；配合在线搜索时超过人类平均水平。在真实的订餐预订场景里，只用一天收集的数据，就把Llama-3 70B的零样本成功率从18.6%提高到81.7%（相对提升340%），再加在线搜索可达95.4%。

局限与后续

  • 在真实网站上做树搜索需要反复回退和尝试，很多操作（下单、付款）不可逆，搜索只能在可重置的环境或模拟中安全进行。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 中间步骤的价值来自模型自我评价，评价出错会把搜索和偏好数据一起带偏。
    本站还没有记录针对它的后续工作（不代表没有人解决）
