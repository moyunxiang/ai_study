BPE压缩算法

A New Algorithm for Data Compression
1994.02论文延伸C Users Journal 1994-02Philip Gage待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

需要一种简单、无损、解压很快的数据压缩方法。

方法

反复找出数据里最常相邻出现的一对字节，用一个没用过的字节替代它，并记录替换表。

影响

二十年后被Sennrich改造成子词切分（BPE子词切分），成为GPT系列等绝大多数大语言模型的分词基础。

方法

算法很简单：每一轮，扫描数据，统计所有相邻字节对出现的次数；取出现最多的那一对（比如“th”），用一个数据中从未出现过的字节（比如0xFF）替换整个数据里的这一对，并在一张表里记下“0xFF = th”；重复，直到没有出现次数超过阈值的对，或者没有未用的字节为止。

解压时按表倒着展开即可，速度很快，所以Gage把它当作一种压缩方法发表在《C Users Journal》1994年2月号上。

它在NLP里没有立刻引起注意；2015年Sennrich等人把相同的合并流程用在字符序列上，每次合并最高频的相邻符号对，得到一个可控大小的子词词表，才变成了NLP的标准做法。

局限与后续

  • 作为压缩算法，压缩率不如同时期的LZ类和霍夫曼方法，也只能处理字节级数据。
