Actor-Critic（ASE/ACE）

Neuronlike Adaptive Elements That Can Solve Difficult Learning Control Problems
1983论文主干IEEE Transactions on Systems, Man, and Cybernetics 1983Andrew G. Barto, Richard S. Sutton, Charles W. Anderson · 马萨诸塞大学阿默斯特分校来源已核对
论文PDF（Sutton主页） ↗Sutton & Barto教材第二版 ↗在交互版中打开（演化树、学习进度）

问题

倒立摆只在杆倒下的那一刻给出“失败”信号，平时毫无反馈；之前的BOXES只在失败时学习，越学越少失败、也就越学越慢。

方法

拆成两个类神经元单元：评论家（ACE）学习预测每个状态离失败有多近，并把“预测值的变化”作为每一步的内部奖惩发给行动者（ASE）；行动者据此调整各状态下向左推还是向右推的概率。

影响

把“价值预测 + 用预测误差训练策略”的actor-critic结构做成了可运行的学习系统；它的内部奖励公式就是后来的TD误差，A3C、PPO、SAC和RLHF里“策略网络＋价值网络”的组合采用的是同样的分工。

背景

上世纪70年代末，用自适应元件做控制的研究大多需要“教师”：每一步都告诉系统正确的输出应该是多少，这就是监督学习。可很多控制问题没有教师，只有很晚才到、很稀少的好坏评价。

典型例子是倒立摆：小车在长4.8米的轨道上，车上铰着一根杆，控制器每0.02秒只能选择向左或向右推车。系统不知道运动方程，唯一的反馈是杆偏离竖直超过12°、或小车撞到轨道端点时的一个“失败”信号（r = −1），其余时刻r = 0。几百步之前的哪个动作该为这次失败负责？这就是信用分配问题的提出提出的时间上的信用分配难题。

论文拿来对比的此前方案是BOXES倒立摆控制：把四维状态（小车位置、速度、杆角、角速度）切成若干“盒子”，每个盒子记住自己选过的动作，并按失败前坚持了多久来更新。它的问题在于只在失败时学习：系统越好，失败越少，学到的东西也越少。Samuel跳棋程序和Rescorla–Wagner条件反射模型则提示了另一条思路：让系统学会预测，再用预测本身当奖励。

方法

系统由两个类神经元单元组成，输入都是一个“解码器”：把状态落到3×3×6×3 = 162个盒子之一，输出一个只有一位为1的162维向量x。

评论家ACE（见Actor-Critic与优势函数）。对当前盒子给出一个预测值p(t) = Σ vᵢ·xᵢ(t)，含义是“从这里出发最终会得到多少强化”（越负越接近失败）。它向行动者发出的不是原始的r，而是内部强化：

r̂(t) = r(t) + γ·p(t) − p(t−1)

其中γ = 0.95是折扣因子。权重按vᵢ ← vᵢ + β·r̂(t)·x̄ᵢ(t)更新，x̄ᵢ是输入的指数衰减痕迹。这条规则让p(t−1)去逼近r(t) + γ·p(t)，即用下一步的预测修正上一步的预测——这正是后来的时序差分与自举。

举个例子：小车从一个安全的盒子（p ≈ 0）进入一个经常导致失败的盒子（p = −0.6），此时并未失败，r = 0，但r̂ = 0 + 0.95×(−0.6) − 0 = −0.57，行动者立刻受到惩罚。预测值的下降本身就成了惩罚，反馈从“几百步后一次”变成“每一步都有”。

行动者ASE。输出y(t) = f[Σ wᵢ·xᵢ(t) + noise(t)]，f是阈值函数，大于0向右推、否则向左推；高斯噪声让它在权重为0时随机试探。权重按wᵢ ← wᵢ + α·r̂(t)·eᵢ(t)更新，其中资格迹eᵢ(t+1) = δ·eᵢ(t) + (1−δ)·y(t)·xᵢ(t)记录了“最近在盒子i里做过什么动作”。这样一次奖惩会按时间远近分摊给之前访问过的盒子和当时选的动作。资格迹的想法来自Klopf享乐神经元假说。

两条更新规则形式几乎一样，区别只在于：行动者的迹带上了自己选的动作y，评论家的迹不管动作。

结果

在相同的仿真倒立摆上与作者重新实现的BOXES比较，每种方法跑10次，每次最多100次试验或50万个时间步（约2.8小时模拟时间）。ASE/ACE几乎所有运行都在100次失败之前就撞到了50万步的上限，即学会了长时间平衡；BOXES只有1次做到。参数为α = 1000, β = 0.5, δ = 0.9, γ = 0.95, λ = 0.8，作者称除一组极端值外没有调过参数。

关键的消融：去掉评论家、只用ASE直接接收失败信号，表现比BOXES还差。作者明确把性能归功于ACE在每一步都提供强化。

后来的发展

Sutton把评论家的预测规则单独拿出来，在1988年的时序差分学习里给出一般形式和分析；ACE的r̂就是TD误差。后来多巴胺与TD误差报告中脑多巴胺神经元的放电规律与这个量相似。行动者一侧则沿着REINFORCE策略梯度和策略梯度定理被严格化为策略梯度，后者证明了带函数近似的actor-critic在理论上成立。

深度强化学习中许多常用算法采用这个结构：A3C、PPO、SAC都由一个策略网络和一个价值网络组成；InstructGPT与RLHF用PPO训练语言模型时，价值网络就是评论家。2024年的GRPO则反过来去掉了评论家，用同一问题的多个回答的平均分代替，以省下一个与策略同样大的模型。

容易误解的地方

  • 这里的评论家学的是状态价值（每个盒子一个数），不是动作价值Q；它的输出是“预测的变化量”，不是预测本身。
  • ASE的更新是启发式的，与后来严格推导的策略梯度相近但不等同；论文没有收敛证明。
  • 162个盒子是人为设计的固定划分，系统并没有学习状态表示。

  • 延续
    Samuel跳棋程序1959 · RL 已核对
    继承Samuel“用后来的评估修正先前评估”的想法，并把它写成一条简单的类神经元更新规则。
  • 延续
    ADALINE与LMS1960 · 基础 已核对
    论文指出评论家的权重更新与ADALINE/LMS规则密切相关，只是回归目标换成了下一步的预测。
  • 改进
    信用分配问题的提出1961 · RL 已核对
    给Minsky提出的时间信用分配问题一个可运行的答案：资格迹分摊奖惩，评论家提供中间奖励。
  • 改进
    BOXES倒立摆控制1968 · RL 已核对
    BOXES只在失败时学习；评论家把预测值的变化变成每一步的奖惩，学习不再随失败变少而停滞。
  • 使用
    Klopf享乐神经元假说1972 · RL 已核对
    行动者的资格迹和“神经元追求强化”的设定直接取自Klopf的享乐神经元理论。
  • 延续
    Rescorla–Wagner条件反射模型1972 · RL 已核对
    评论家沿用“按预测误差更新”的思路，但把误差定义在相邻时间步之间，从而能处理信号与奖励之间的延迟。

读懂它需要的概念

本篇术语

  • 资格迹　给每个输入（这里是每个盒子）记一个随时间衰减的标记，记录它最近被用过多少、当时选了什么动作；奖惩到来时按这个标记分摊。
  • 内部强化　评论家发给行动者的奖惩信号，等于真实奖励加上新状态的预测值、再减去旧状态的预测值。
  • 倒立摆（cart-pole）　在可左右移动的小车上竖一根铰接的杆，靠推车保持杆不倒。至今仍是强化学习最常用的入门测试任务之一。

怎么学

先补时序差分与自举和Actor-Critic与优势函数。读原文第V–VIII节（BOXES、ASE、ACE三部分）和第IX节的实验。然后在Gymnasium的CartPole上自己实现：把状态离散成162格，按文中公式写出ASE和ACE，对比“只用失败信号”和“用内部强化”两种设置的学习曲线；最后对照Sutton & Barto教材第13章的现代actor-critic写法。
