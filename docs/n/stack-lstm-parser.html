Stack-LSTM依存分析

Transition-Based Dependency Parsing with Stack Long Short-Term Memory
2015.05论文延伸ACL 2015Chris Dyer, Miguel Ballesteros, Wang Ling, Austin Matthews, Noah A. Smith · 卡内基梅隆大学、庞培法布拉大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Chen和Manning的神经转移式分析器只从栈顶和缓冲区开头取固定的几个词作特征，看不到整个栈里已经建好的子树、整条缓冲区和全部历史动作，分析器状态的大部分信息被丢掉了。

方法

设计一种栈LSTM：它像普通栈一样支持常数时间的压入和弹出，同时用LSTM为栈的当前内容维护一个连续向量。用三个栈LSTM分别表示缓冲区、栈（其中元素是递归组合出的子树向量）和动作历史，据此预测下一个转移动作。

影响

在英文斯坦福依存和中文宾州树库上都明显超过Chen-Manning神经分析器；栈LSTM后来被用于循环神经网络文法RNNG、转移式命名实体识别等结构化预测任务。

方法

转移式依存分析式的转移系统用一个栈和一个缓冲区，靠SHIFT、REDUCE-LEFT、REDUCE-RIGHT三类动作逐步建出依存树。神经网络依存分析用前馈网络对栈顶几个词的特征打分，效果和速度都好，但特征窗口是固定的。

栈LSTM：在普通LSTM上加一个「栈指针」。压入一个元素时，从指针所指的位置出发计算新的隐状态并把指针移过去；弹出时只把指针移回上一个位置，不需要重新计算。这样任何时刻，指针处的隐状态就是对栈中全部内容的摘要。

分析器状态由三个栈LSTM组成：缓冲区（尚未处理的词，提供无限远的前瞻）、栈（部分建好的子树）、动作历史。三者的摘要向量拼接后经一层网络，softmax预测下一个动作。当REDUCE把一个修饰词挂到中心词上时，用一个组合函数c = tanh(U·[h; d; r] + e)把中心词h、修饰词d和依存关系r合成一个新的子树向量压回栈上，因此栈中元素包含了子树的内部结构。词的输入表示由学习的词向量、预训练词向量和词性向量拼接而成。

测试集结果：英文（斯坦福依存）UAS 93.1、LAS 90.9，Chen和Manning为91.8、89.6；中文（CTB5）UAS 87.2、LAS 85.7，对方为83.9、82.4。消融显示子树组合比只用中心词好，英文上去掉预测词性几乎没有损失；集束搜索带来的提升不超过0.3个百分点，所以用贪心解码即可。

本篇术语

  • 转移式分析　维护栈和缓冲区，每一步选一个动作（移入下一个词，或在栈顶两个元素间建一条依存弧），动作序列决定整棵树。
  • UAS/LAS　依存分析的指标：UAS是中心词预测正确的词所占比例，LAS还要求依存关系标签也正确。

怎么学

先读转移式依存分析和神经网络依存分析的讲解 → 读原文第2节栈LSTM和第3节分析器状态 → 动手：实现一个支持push和pop的栈LSTM，在一个小依存树库上训练转移式分析器，对比只用栈顶两个元素特征时的UAS。
