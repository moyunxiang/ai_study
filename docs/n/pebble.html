PEBBLE偏好强化学习

PEBBLE: Feedback-Efficient Interactive Reinforcement Learning via Relabeling Experience and Unsupervised Pre-training
2021.06论文延伸ICML 2021Kimin Lee, Laura Smith, Pieter Abbeel · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

从人类偏好学习奖励证明了用人对两段行为的偏好训练奖励模型是可行的，但它基于on-policy算法，需要大量的人类比较；人工反馈很贵，这种方法难以扩展到更复杂的任务。

方法

两处改进提高反馈效率：一是改用离策略的SAC，每当奖励模型更新时，把回放池里所有旧经验用新奖励重新标注，旧数据不浪费；二是在开始询问人之前，先用无监督探索（最大化状态熵）预训练智能体，让最初几次比较就能看到多样的行为。

影响

把偏好学习的反馈需求降到能用于移动和机械臂操作等更复杂任务的水平，成为“基于偏好的RL”（PbRL）方向的标准基线和代码框架，后续大量反馈高效的偏好学习方法都与它比较。

背景

很多任务的奖励难以手写：比如让机器人做后空翻，或者让它按人的偏好完成动作。从人类偏好学习奖励的方案是让人观看两段短视频片段、选择更好的一个，用这些比较训练奖励模型，再用RL优化。它用的是A2C/TRPO等on-policy算法：奖励模型一变，以前收集的数据就作废，因此需要不断产生新数据、不断请人比较。T-REX排序奖励外推用离线的排序示范学奖励，但需要事先有排好序的示范。

方法

PEBBLE（unsupervised PrE-training and preference-Based learning via relaBeLing Experience）有三个部分。

无监督预训练：一开始没有任何反馈，智能体用内在奖励探索，内在奖励是状态熵的粒子估计——状态与其在回放池中第k近邻的距离 r_int(s) = log(c + ‖s − s^{kNN}‖)，距离越大说明越新奇。这样回放池里会有多样的行为，第一批供人比较的片段就更有信息量。

偏好奖励学习：从回放池抽两段片段 σ⁰、σ¹ 给人（或模拟的“教师”）比较，用与从人类偏好学习奖励相同的Bradley-Terry模型训练奖励网络：P(σ¹ ≻ σ⁰) = exp Σ r̂(s,a)∈σ¹ / (exp Σ r̂∈σ⁰ + exp Σ r̂∈σ¹)，以交叉熵为损失。挑选哪两段询问时，可以优先选奖励模型集成分歧大或预测熵大的片段对。

重新标注与离策略学习：每次奖励模型更新后，把回放池中所有转移的奖励用新模型重算，然后用SAC继续训练。这样所有历史数据都能用上，大大减少了需要的交互和反馈。

结果

摘要称，该方法能学会比以往人在回路方法更复杂的任务，包括多种移动和机器人操作技能；还表明它能利用实时的人类反馈有效防止奖励被钻空子，并学会用标准奖励函数难以描述的新行为。

后来的发展

PEBBLE之后，偏好RL的研究多在它的框架上改进：更好的查询选择、半监督地利用未标注片段、数据增强等；Preference Transformer等工作改用序列模型建模偏好。人类偏好学奖励的思路在大语言模型的RLHF中被大规模使用。

局限与后续

  • 实验中的“人类”大多是用真实奖励模拟的理想教师，真实人类反馈有噪声、标准不一致，效果可能明显下降。

它建立在什么之上

  • 竞争
    随机网络蒸馏RND2018.10 · RL
    预训练阶段同样用内在奖励鼓励探索；PEBBLE选用基于k近邻的状态熵估计而不是预测误差。
  • 改进
    从人类偏好学习奖励2017.06 · RL
    原方法基于on-policy算法、反馈需求大；PEBBLE用重新标注加离策略学习和无监督预训练，大幅减少所需的偏好询问。
  • 使用
    SAC2018.01 · RL
    用SAC做离策略学习，奖励模型更新后重算回放池中所有转移的奖励。
  • 延续
    T-REX排序奖励外推2019.04 · RL
    同样用成对比较的Bradley-Terry损失学奖励，但改为在线主动向教师询问片段偏好，而不是依赖离线排序示范。

读懂它需要的概念

奖励设计与奖励投机 人类反馈强化学习 on-policy与off-policy 探索与利用 交叉熵

本篇术语

  • 重新标注（relabeling）　奖励模型更新后，用新模型重新计算回放池中旧经验的奖励，使旧数据可以继续用于离策略学习。
  • 状态熵最大化　鼓励智能体访问的状态分布尽可能分散的无监督目标；用k近邻距离近似熵，距离已访问状态越远奖励越大。

怎么学

先读从人类偏好学习奖励；读原文第4节三个部件，特别是重新标注的实现；用官方代码（B-Pref）在一个DeepMind Control任务上比较有无无监督预训练时达到同样性能所需的偏好询问数。
