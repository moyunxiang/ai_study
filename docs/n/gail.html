GAIL

Generative Adversarial Imitation Learning
2016.06论文重要NIPS 2016Jonathan Ho, Stefano Ermon · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

只有专家示范、没有奖励时，行为克隆数据少就会误差累积；逆强化学习先反推奖励再跑一遍完整RL，嵌套两层循环，在高维任务上又慢又难。

方法

证明“先逆强化学习再强化学习”等价于让策略的状态-动作分布逼近专家的分布，于是用GAN式的判别器区分专家与策略的(s,a)，把判别器输出当奖励，用TRPO更新策略。

影响

第一次让模仿学习在三维人形行走等高维连续控制任务上接近专家水平，“对抗式模仿”成为一条主线，后来的对抗运动先验AMP等角色动画方法直接继承了它。

背景

模仿学习（见模仿学习与行为克隆）有两条老路。行为克隆：把专家的(状态, 动作)当作监督学习的样本直接拟合，ALVINN端到端驾驶就是这样学开车的。问题是策略只要偏离专家走过的状态一点，就会进入没见过的状态、犯更大的错，误差逐步累积；DAgger能缓解，但要求能随时向专家提问。逆强化学习（逆强化学习IRL）：先找一个让专家显得最优的代价函数，再用RL求解它；最大熵逆强化学习让这条路更稳健，但每更新一次代价函数都要在内层把RL跑到收敛，代价巨大。学徒学习一类方法虽能直接给出策略，却只能用线性的代价函数类，表达力有限。

方法

理论上的化简。定义策略π的“占用度量”ρ_π(s,a)：按π行动时，以折扣加权统计每个状态-动作对出现的频率。论文证明：带凸正则ψ的最大因果熵IRL，后面再接RL，结果等价于直接求解

min_π −H(π) + ψ*(ρ_π − ρ_E)

也就是在保持策略熵的同时，让策略的占用度量在某种距离下接近专家的ρ_E。不同的ψ对应不同的模仿算法；选取一种特定的ψ，这个距离恰好是（相差常数的）Jensen–Shannon散度——也就是生成对抗网络GAN在优化的东西。

算法。像GAN一样设两个网络（见对抗训练）：判别器D(s,a)学着区分一个(s,a)来自当前策略还是来自专家；策略则要“骗过”判别器。目标是

max_D E_π[log D(s,a)] + E_专家[log(1 − D(s,a))]

每轮先用当前策略在环境里采样轨迹，用梯度更新D；然后把log D(s,a)当作代价（越像策略生成的越贵），用TRPO走一步策略更新。TRPO限制每步策略变化的幅度，防止判别器噪声把策略带偏。整个过程不需要显式求出代价函数，也不需要内层RL循环。

结果

在9个物理控制任务上测试，从倒立摆、Acrobot、山地车到MuJoCo中的三维人形行走。专家由在真实奖励上训练的TRPO生成，每条示范约50步。与行为克隆、特征期望匹配（FEM）和博弈论学徒学习（GTAL）相比，GAIL在经典控制任务上始终最好；在更难的MuJoCo任务上提升明显，在各种示范数量下几乎都达到专家水平的70%以上。例外是Reacher任务，行为克隆反而更省数据。

后来的发展

GAIL把模仿学习从“先学奖励”转向“直接匹配分布”。机器人与角色动画领域随后出现了一串对抗式方法：DeepMimic的后续对抗运动先验AMP用类似GAIL的判别器作为“动作风格”奖励，ASE技能嵌入再加入技能嵌入。另一方面，后来大规模机器人学习（BC-Z、Diffusion Policy）又回到了有大量数据时更简单稳定的行为克隆。

局限与后续

  • 依赖on-policy的TRPO，每次更新都要与环境大量交互，论文自己承认它在环境交互上的样本效率不高，远不如不需要交互的行为克隆。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 对抗训练继承了GAN的不稳定和对超参数敏感的问题，判别器过强时策略得不到有用的梯度。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 判别器只是区分“像不像专家”，并不给出一个可迁移、可解释的奖励函数，换个环境动力学就要重新训练。

它建立在什么之上

  • 使用
    生成对抗网络GAN2014.06 · 生成
    把判别器-生成器的对抗训练搬到状态-动作对上，策略扮演生成器。
  • 延续
    逆强化学习IRL2000 · RL
    把IRL重新解释为占用度量匹配的对偶问题，统一了多种已有的模仿学习算法。
  • 竞争
    DAgger2010.11 · RL
    DAgger靠随时询问专家修正行为克隆的误差累积；GAIL不需要专家在线参与，只用固定的示范数据。
  • 竞争
    学徒学习2004 · RL
    FEM与GTAL同样直接输出策略，但代价函数只能是线性或凸组合类；GAIL用神经网络判别器，在高维任务上明显胜出。
  • 改进
    最大熵逆强化学习2008 · RL
    证明最大因果熵IRL加RL等价于占用度量匹配，绕开了“每次更新代价都要在内层跑完一遍RL”的昂贵循环。
  • 使用
    TRPO2015.02 · RL
    策略更新使用TRPO，靠信赖域约束抵御判别器奖励的噪声。

后来的相关工作

  • 竞争
    DeepMimic2018.04 · 具身·世界模型
    GAIL用判别器隐式地衡量与示范的相似度；DeepMimic用显式的逐帧跟踪奖励，换来接近动作捕捉的质量和后空翻等高动态技能，后来的AMP又回到对抗式思路以去掉逐帧对齐。
  • 延续
    AIRL对抗逆强化学习2017.10 · RL
    沿用GAIL的对抗框架，但约束判别器形式，使其能同时恢复奖励函数。
  • 竞争
    BCO从观测行为克隆2018.05 · RL
    GAIL需要专家动作或大量交互；BCO只用状态示范，并且在拿到示范后学得更快。
  • 延续
    GAIfO从观察中对抗模仿2018.07 · RL
    沿用GAIL的对抗式模仿，把判别器的输入从状态—动作对改为状态—下一状态对，去掉对专家动作的需求。
  • 竞争
    T-REX排序奖励外推2019.04 · RL
    GAIL匹配示范的状态-动作分布，学到的最多与示范相当；T-REX的目标是超越示范。
  • 竞争
    SQIL软Q模仿2019.05 · RL
    同样借助RL做长程模仿；GAIL学对抗式奖励，SQIL用固定常数奖励，结果相当但简单得多。
  • 延续
    f-MAX散度最小化模仿2019.11 · RL
    把GAIL解释为f-MAX在JS散度下的特例。
  • 改进
    ValueDICE离策略模仿2019.12 · RL
    GAIL估计分布比需要on-policy数据；ValueDICE把目标改写成完全离策略的形式，并去掉了单独的RL步骤。
  • 改进
    PWIL最优传输模仿2020.06 · RL
    GAIL需要对抗训练的判别器、不稳定；PWIL用最优传输的原始形式离线给出奖励，无需判别器。
  • 使用
    对抗运动先验AMP2021.04 · 具身·世界模型
    借用GAIL的对抗模仿框架，把判别器作为动作先验。
  • 改进
    IQ-Learn逆软Q模仿2021.06 · RL
    去掉GAIL中奖励与策略的对抗优化，改为单个Q函数上的非对抗目标。

读懂它需要的概念

模仿学习与行为克隆 对抗训练 策略梯度 马尔可夫决策过程 信息量与熵 KL散度

本篇术语

  • 占用度量　按某策略长期行动时，各个(状态, 动作)对被访问的折扣加权频率。两个策略的占用度量相同，它们的行为就完全一样。
  • 复合误差（协变量偏移）　行为克隆的策略稍有偏差就会走到专家没去过的状态，在那里误差更大，越走越偏。
  • Jensen–Shannon散度　衡量两个分布差异的一种对称距离；GAN的最优判别器损失与它只差一个常数。

怎么学

先补模仿学习与行为克隆、对抗训练，并读懂TRPO或PPO其中一个。读原文第3节的命题3.2和第5节算法1，证明部分可以先跳过。动手：用PPO代替TRPO，在Gymnasium的HalfCheetah上用几条专家轨迹实现GAIL，和直接行为克隆比较。
