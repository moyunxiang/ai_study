GPT-4.1百万上下文

Introducing GPT-4.1 in the API
2025.04模型延伸OpenAI待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

GPT-4o上下文只有128K，写代码和照指令办事不够稳；GPT-4.5又大又贵，开发者缺一个便宜、长上下文、听话的API模型。

方法

只面向API推出GPT-4.1、mini、nano三档，专门针对编码、指令遵循和长上下文优化，上下文扩到100万token。

影响

OpenAI首个百万上下文模型系列，价格低于GPT-4o，并直接导致GPT-4.5预览版在API中下线。

方法

2025年初OpenAI的产品线里，GPT-4o全模态实时模型是主力但上下文只有128K，GPT-4.5规模大、成本高。2025年4月14日，OpenAI在API中发布GPT-4.1、GPT-4.1 mini和GPT-4.1 nano三个非推理模型，知识截止2024年6月，三档都支持100万token上下文。

官方给出的数字：SWE-bench Verified 54.6%（GPT-4o为33.2%），多轮指令遵循基准MultiChallenge 38.3%（比GPT-4o高10.5个百分点），IFEval 87.4%，长视频理解Video-MME（无字幕长视频）72.0%。定价为每百万token输入2美元、输出8美元，mini和nano更便宜，nano为0.1/0.4美元。

OpenAI同时宣布，由于GPT-4.1在多数能力上与GPT-4.5预览版相当或更好、成本和延迟低得多，GPT-4.5预览版将于2025年7月14日在API中停用。几个月后GPT-5发布，把推理与非推理模型合并到一个系统里。

局限与后续

  • 百万上下文能装下但不等于用得好，长输入下的检索和推理质量仍随长度下降（Chroma的上下文腐烂Context Rot报告把GPT-4.1列入测试）。
