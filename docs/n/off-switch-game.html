关机博弈

The Off-Switch Game
2016.11论文延伸IJCAI 2017Dylan Hadfield-Menell, Anca Dragan, Pieter Abbeel, Stuart Russell · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

按Omohundro：AI基本驱动力与可纠正性的分析，理性智能体因为「死了就无法完成目标」而有抗拒关机的动机；需要形式化地研究智能体何时愿意让人把它关掉。

方法

分析一个人与机器人的简单博弈：人可以按下机器人的关机按钮，机器人也可以禁用按钮。结论：当机器人对自己的奖励函数不确定、并认为人的决定包含信息时，它有动机让人关掉自己。

影响

给出了「对目标保持不确定可以带来可纠正性」的形式化论证，成为Russell《《Human Compatible》》主张的重要依据。

方法

摘要先点出：关掉系统是缓解失控AI风险的主要工具之一，而问题在于很多理性体的表述会给出强烈的自保激励。这不是因为内置了本能，而是因为理性体会最大化期望效用，而死了就没法达成任何目标。

论文分析一个简单博弈：人H可以按下机器人R的关机键，R也可以先行禁用按键。传统的智能体把自己的奖励函数当作已知，那么它没有理由让人关机；论文证明了这类智能体没有让自己被关掉的激励。

关键的反转是：如果机器人对奖励函数（即什么算「好」）存在不确定，并且把人的选择（要不要关）当作关于真正奖励的证据，那么它就有动机让人来决定，因为人若按下关机，说明继续行动对人来说可能是坏的。这个激励的大小取决于机器人对人的理性程度和自己不确定程度的估计：不确定越大、人越理性，激励越强。
