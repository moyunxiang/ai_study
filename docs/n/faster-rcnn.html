Faster R-CNN

Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks
2015.06论文重要NeurIPS 2015Shaoqing Ren（任少卿）, Kaiming He（何恺明）, Ross Girshick, Jian Sun（孙剑） · 微软亚洲研究院 / 微软研究院待核对
arXiv ↗代码（Python版） ↗在交互版中打开（演化树、学习进度）

问题

Fast R-CNN的检测网络只要零点几秒，但候选框仍由CPU上的选择性搜索生成，每张图约2秒，成了整个系统最慢的一环；而且候选框算法是手工设计的，不能随网络一起变好。

方法

在检测网络共享的卷积特征图上加一个小的区域候选网络（RPN）：在每个位置放9个不同大小和长宽比的“锚框”，预测每个锚框是不是物体以及该如何修正，候选框几乎不花额外时间。

影响

第一个真正端到端、全部由神经网络完成的检测器，用VGG-16时整个系统每秒5帧且精度更高；锚框和RPN成为此后多年检测、实例分割的标准部件，是ILSVRC和COCO 2015多个赛道冠军方案的基础。

背景

从R-CNN到Fast R-CNN，检测网络本身已经快了两百多倍。但两者都依赖外部的候选框算法：选择性搜索根据颜色、纹理贪心地合并超像素，在CPU上每张图约2秒；较快的EdgeBoxes也要0.2秒，和检测网络本身一样久。

更根本的问题是：候选框算法是手工设计的低层规则，它看不到卷积网络学到的语义特征，网络再强，候选框的质量也不会提高。既然检测网络已经算出了整张图的卷积特征，能不能直接用这些特征来提议“哪里可能有物体”？

方法

区域候选网络（RPN）。在共享卷积特征图（VGG-16最后一个卷积层，相对原图下采样16倍）上，用一个3×3的小窗口滑动。每个位置输出一个特征向量，再接两个1×1卷积：

  • 分类分支：对k个锚框各给出“是物体／不是物体”的分数；
  • 回归分支：对k个锚框各给出4个修正量（中心平移、宽高缩放）。

锚框。每个位置预设k＝9个参考框：3种面积（128²、256²、512²像素）×3种长宽比（1:2、1:1、2:1）。网络不直接预测框的绝对坐标，而是预测相对于锚框的偏移量——这样同一个卷积核只需学会“把一个128×128的方框修成什么样”，处理多尺度物体时不必构建图像金字塔。一张约1000×600的图上，特征图约60×40个位置，共约2万个锚框。

训练RPN。与某个真值框IoU最高、或IoU大于0.7的锚框记为正例，与所有真值框IoU都小于0.3的为负例，其余忽略（见IoU与mAP）。每张图采样256个锚框，正负尽量各半。损失＝分类的对数损失＋正例上的平滑L1回归损失。

与Fast R-CNN合并。RPN产生的框经非极大值抑制后取前300个，交给Fast R-CNN的RoI池化和分类/回归头。为了让两者共享卷积层，论文用了“四步交替训练”：先训RPN，再用它的框训Fast R-CNN，然后固定共享层分别微调两者的独有层。后来的实现改为把两个损失直接相加一起训练。

结果

VGG-16、PASCAL VOC 2007测试集：选择性搜索＋Fast R-CNN mAP 66.9%，RPN＋Fast R-CNN（共享特征）69.9%；用VOC 2007＋2012训练达到73.2%。VOC 2012测试集70.4%。速度（K40 GPU）：选择性搜索方案每张图1830毫秒（其中候选框1510毫秒），RPN方案共198毫秒（候选框仅10毫秒），即每秒5帧；用更小的ZF网络可达每秒17帧。COCO test-dev：mAP@0.5为42.7%，mAP@[0.5,0.95]为21.9%。

后来的发展

Faster R-CNN定义了“两阶段检测器”：第一阶段RPN粗筛候选框，第二阶段对每个候选框精细分类和回归。特征金字塔FPN在其上加多尺度特征金字塔，Mask R-CNN加掩码分支做实例分割，Cascade R-CNN串联多级检测头提高定位精度，这一家族主导了2016–2019年的COCO榜单。锚框的思想也被SSD、YOLOv2 / YOLO9000、Focal Loss与RetinaNet等单阶段检测器采用。

2019年以后，FCOS无锚框检测等无锚框方法和DETR的集合预测开始去掉锚框和非极大值抑制这些手工设计，但RPN的“在特征图上密集预测”仍是许多检测器的基础。

容易误解的地方

  • 锚框不是网络预测出来的，而是固定的参考框；网络预测的是相对于锚框的偏移。
  • RPN的分类只分“物体／背景”，具体类别由第二阶段决定。
  • 每秒5帧是用VGG-16的结果，仍不算实时；同期的YOLO才以实时为首要目标。

局限与后续

  • 两阶段流程每秒只有5帧左右（VGG-16），达不到视频实时检测的要求。
    后来针对它的工作　SSD YOLOv2 / YOLO9000
  • 只在单一尺度（下采样16倍）的特征图上放锚框，小物体检测效果差。
    后来针对它的工作　特征金字塔FPN
  • 锚框的尺度、长宽比、正负样本的IoU阈值、非极大值抑制都是手工设定的超参数，换数据集要重新调。
    后来针对它的工作　FCOS无锚框检测 DETR
  • RoI池化的坐标取整让特征与物体位置错位，不适合需要像素级精度的实例分割。
    后来针对它的工作　Mask R-CNN

读懂它需要的概念

卷积层、池化与感受野 IoU与mAP 锚框与非极大值抑制 损失函数 分类、检测、分割 预训练与微调

本篇术语

  • 锚框　在特征图每个位置预先放置的一组固定大小和长宽比的参考框，检测器预测的是相对于它们的偏移和是否含物体。
  • 区域候选网络（RPN）　一个小的全卷积网络，在共享特征图上滑动，为每个锚框输出“物体性”分数和框修正，用来代替手工的候选框算法。
  • 两阶段检测器　先生成少量候选框，再对每个候选框分类和精修的检测器；对应的单阶段检测器一次性直接输出最终框。

怎么学

先读Fast R-CNN，再补锚框与非极大值抑制。读原文第3.1节（RPN与锚框）和第3.2节（训练方式）。动手：用torchvision的fasterrcnn_resnet50_fpn在几张图上推理；然后自己写代码在一张特征图上生成9种锚框，并按IoU 0.7/0.3规则给它们分配正负标签，画出来看看。
