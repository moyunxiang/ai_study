参数高效微调的统一视角

Towards a Unified View of Parameter-Efficient Transfer Learning
2021.10论文延伸ICLR 2022Junxian He, Chunting Zhou, Xuezhe Ma, Taylor Berg-Kirkpatrick, Graham Neubig · 卡内基梅隆大学, 南加州大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

Adapter、前缀微调、LoRA等参数高效方法各自有效，但看起来形式完全不同，大家不清楚它们成功的关键是什么、彼此是什么关系，也就不知道该怎么组合或改进。

方法

把这些方法都改写成“对预训练模型某处隐藏状态加一个修改量Δh”，按修改量的函数形式、插入方式（串行/并行）、修改的位置（注意力/前馈层）和组合方式几个维度来比较，再按最优组合拼出新方法。

影响

成为参数高效微调最常被引用的分析框架之一，提出的并行适配器与MAM Adapter让后来的研究常把LoRA、Adapter、前缀看成同一家族的变体。

方法

Adapter在层与层之间串行插入小瓶颈网络，Prefix / Prompt Tuning在注意力里加可训练的Key/Value，LoRA给权重加低秩增量。作者推导出：前缀微调对注意力输出的作用，可以写成原输出与一个由前缀决定的项的加权和，形式上很像一个并行接在注意力旁边的适配器；LoRA则是并行加在权重矩阵上的线性修改。于是三者都可以表示为h ← h + s·Δh，区别只在于：

  • 函数形式：Δh是线性的（LoRA）、带非线性的瓶颈网络（Adapter），还是注意力式的加权（前缀）；
  • 插入方式：串行接在子层之后，还是与子层并行；
  • 修改位置：作用在注意力子层还是前馈子层；
  • 组合函数：直接相加、带缩放系数，还是门控加权。

在翻译、摘要、语言理解和文本分类上的系统实验得出几条经验：并行插入优于串行；修改前馈层更适合参数预算较多的情况，修改注意力在预算极小时更划算。据此组合出MAM Adapter（在注意力上用前缀微调、在前馈层上用缩放的并行适配器），以更少的可训练参数在四类任务上都达到与全量微调相当的结果（摘要所述）。

局限与后续

  • 实验主要在编码器—解码器和编码器模型上做，可训练参数比例仍是百分之几；后来的十亿级解码器LLM上，简单的LoRA因为可合并、无推理开销而成为事实标准，MAM这类组合方法用得不多。
