VIC变分内在控制

Variational Intrinsic Control
2016.11论文延伸ICLR 2017 WorkshopKarol Gregor, Danilo Jimenez Rezende, Daan Wierstra · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

没有外部奖励时，智能体该学些什么？分层RL里的“选项”通常要人手工设计子目标，无法自动发现一个环境里有哪些可控的行为。

方法

让智能体学一组选项Ω，目标是最大化选项与其终止状态之间的互信息 I(Ω; s_f | s_0)：不同选项应可靠地到达不同状态。用一个推断网络从终止状态猜选项，猜得准就给奖励。

影响

第一次把“用互信息无监督地发现技能”写成可扩展的RL算法，DIAYN、DADS等技能发现方法都沿用这一目标，它也给出了可计算的赋权（empowerment）估计。

背景

Options时间抽象框架框架把“可以持续多步的子策略”作为动作，但选项从哪里来一直是难题，多数工作依赖人工设定的子目标或瓶颈状态。另一条线索是赋权：一个状态的赋权定义为智能体动作与未来状态之间的最大互信息，衡量“在这里我能影响多少结果”，以往只能在小型离散环境里精确计算。作者把二者联系起来：一组好的选项，就是让终止状态最能被选项决定的那组。

方法

从起始状态 s_0 出发，先从先验 p(Ω|s_0) 采样一个选项Ω，按条件策略 π(a|s,Ω) 执行直到终止于 s_f。目标是

I(Ω; s_f | s_0) = H(Ω|s_0) − H(Ω|s_f, s_0)

第一项要求选项多样，第二项要求从终点能认出是哪个选项。后者不可直接计算，作者用一个推断网络 q(Ω|s_0, s_f) 给出变分下界：

I ≥ E[ log q(Ω|s_0,s_f) − log p(Ω|s_0) ]

这个量就作为回合末的内在奖励，用策略梯度同时优化策略和选项先验，推断网络则用最大似然训练。论文给了两个版本：一个显式学习选项嵌入空间与先验；另一个把选项隐式地表示为策略循环网络的状态，选项数量不必事先固定。最大化后的互信息值本身就是该状态赋权的一个估计。

结果

摘要称算法能很好地与函数近似结合，并在一系列任务上展示了适用性；原文实验以网格世界和简单的三维导航环境为主，展示学出的选项会分散地到达不同区域。

后来的发展

DIAYN无奖励技能发现把VIC的“终止状态”换成路径上每个状态并固定选项先验，训练更稳定，成为最常用的版本；DADS可预测技能发现把目标改成“技能的结果可预测”，URLB无监督RL基准则把这类互信息技能发现归为一大类方法。

读懂它需要的概念

互信息 信息量与熵 变分推断与ELBO 策略梯度 无监督学习

本篇术语

  • 赋权（empowerment）　一个状态下智能体的动作与未来状态之间可达到的最大互信息，大致衡量“在这里能控制多少种不同结果”。
  • 技能发现　不给任务奖励，让智能体自己学出一组彼此不同、可复用的子策略（技能）。

怎么学

先补互信息和变分下界；读原文第2节的目标推导和两种算法；在四房间网格世界里实现显式选项版本，画出每个选项的终止状态分布，再与DIAYN比较。
