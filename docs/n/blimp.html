BLiMP语法最小对立对

BLiMP: The Benchmark of Linguistic Minimal Pairs for English
2019.12数据集延伸TACL 2020Alex Warstadt, Alicia Parrish, Haokun Liu, Anhad Mohananey, Wei Peng, Sheng-Fu Wang, Samuel R. Bowman · 纽约大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

语言模型的困惑度只给一个总分，看不出它到底掌握了哪些语法规则，比如主谓一致、否定极性词、从句里能不能提取成分。

方法

用专家写的语法模板自动生成大量“最小对立对”：两句只差一处，一句合语法、一句不合，看语言模型是否给合语法的那句更高概率。

影响

成为检验语言模型语法知识的标准探针，被纳入lm-evaluation-harness，也是小规模语言模型（如BabyLM挑战）的主要评测之一。

方法

最小对立对。例如“这些猫在睡觉”与“这些猫在睡觉着”这类只差一个词的句子对。英文里典型的是“The cats annoy Tim”对“The cats annoys Tim”。BLiMP不让模型做选择题，而是直接比较语言模型给两句话的整句概率：合语法的那句概率更高就算对，所以任何能算句子概率的模型都能测，不需要微调。

规模与覆盖。共67个子数据集，每个1000对，按句法、形态、语义分成十几类现象，如论元结构、照应一致、填充词-空位依存、量词分布、否定极性词、提取孤岛等。数据由专家写的小语法自动生成，人类对标签的总体一致率为96.4%。

发现。作者测了n-gram、LSTM和Transformer-XL、GPT-2。摘要称，模型对形态上的对立（如一致）判断可靠，但在量词和否定极性词的语义限制、提取孤岛等细微句法现象上表现吃力。

后来的发展

BLiMP常和其他句法探针一起用来比较不同规模、不同训练数据量的模型学到了多少语法，也被移植出中文、荷兰语等多语言版本。

局限与后续

  • 句子由模板生成，词汇和句式偏简单、有时语义别扭；按整句概率比较也会受句子长度和词频影响，不完全等于语法判断。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    GPT-22019.02 · LLM
    GPT-2是被测的主要Transformer语言模型之一。
  • 竞争
    Penn Treebank1993 · 数据·评测
    树库靠人工标注句法结构来教模型语法，BLiMP反过来只用句子概率检验模型是否已经隐式学会了语法。
  • 竞争
    GLUE / SuperGLUE2018.04 · 数据·评测
    GLUE里的CoLA也测语法可接受性，但需要训练分类器；BLiMP不需微调，直接比较语言模型概率。
  • 使用
    Transformer-XL2019.01 · LLM
    与GPT-2一起作为被测的Transformer语言模型。

本篇术语

  • 最小对立对　只差一处的两句话，一句合语法一句不合，用来精确定位模型掌握了哪条语法规则。
  • 否定极性词　只能出现在否定或疑问语境里的词，如英语的ever、any，“I have ever been there”就不合语法。
