WebVoyager真实网站任务

WebVoyager: Building an End-to-End Web Agent with Large Multimodal Models
2024.01数据集延伸ACL 2024Hongliang He, Wenlin Yao, Kaixin Ma, Wenhao Yu, Yong Dai, Hongming Zhang, Zhenzhong Lan, Dong Yu · 腾讯AI Lab / 浙江大学 / 西湖大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

已有网页智能体大多只处理一种输入（HTML文本），而且只在简化的模拟网站或静态网页快照上评测，和在真实网站上完成任务差距很大。

方法

做一个看截图、操作真实网站的多模态端到端网页智能体，并从15个热门真实网站收集任务构成基准，用GPT-4V自动判断开放式任务是否完成。

影响

把网页智能体评测从模拟站点和静态快照搬到在线的真实网站，并示范用多模态模型当裁判自动判定开放式任务；自动评测与人工判断一致率85.3%。

方法

智能体。WebVoyager以大型多模态模型（GPT-4V）为核心，每一步接收当前网页的截图（以及必要的文本信息），决定下一步动作——点击、输入、滚动、返回、跳转到搜索引擎或给出答案，直接在真实网站上执行，直到完成用户指令。

基准。与WebArena自建的可复现网站、Mind2Web的静态网页快照不同，作者从15个热门真实网站（如购物、地图、航班、菜谱、学术检索类网站）收集任务，要求智能体在线完成。由于真实网站上的任务是开放式的，答案不唯一，作者提出用GPT-4V查看智能体的操作轨迹截图和最终回答，自动判断任务是否成功。

结果。据摘要，WebVoyager在该基准上任务成功率59.1%，明显高于GPT-4（All Tools）和只用文本的WebVoyager版本；自动评测与人工判断的一致率为85.3%。

局限与后续

  • 真实网站内容随时间变化，同一任务的答案和难度会漂移，不同时间测得的分数难以严格比较。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 成功与否由GPT-4V判断，本身有约15%与人工不一致。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    GPT-4V2023.09 · 多模态
    既用GPT-4V作为智能体的核心模型，也用它自动判断任务是否完成。
  • 改进
    Mind2Web2023.06 · 数据·评测
    Mind2Web在静态网页快照上离线评测，WebVoyager改为在线执行完整任务。
  • 竞争
    WebArena2023.07 · 数据·评测
    WebArena自建可复现的网站环境，WebVoyager直接在真实网站上评测，更真实但不易复现。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

怎么学

先读WebArena和Mind2Web了解网页智能体评测的两种做法。读WebVoyager原文的动作空间和自动评测部分；动手用一个多模态模型加浏览器自动化库，在一个真实网站上完成一条查询任务，并让另一个模型看截图判断是否成功。
