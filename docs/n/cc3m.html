Conceptual Captions

Conceptual Captions: A Cleaned, Hypernymed, Image Alt-text Dataset For Automatic Image Captioning
2018.07数据集延伸ACL 2018Sharma, Ding, Goodman, Soricut · Google AI待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

COCO 等图像描述数据集靠人工逐张写描述，规模和风格都有限，难以训练覆盖面更广的图像描述模型。

方法

从数十亿网页里抽取图片的 alt 文本，经过过滤并把专有名词等替换为上位词（如『演员』），得到比 COCO 大一个数量级的图文对。

影响

开启了用网页图文对做视觉-语言预训练的路线，ViLBERT、UNITER 等模型和 LiT 等工作都用 CC3M 或其扩展版本。

方法

论文称，Conceptual Captions 的图片数量比 MS-COCO 多一个数量级，图像与描述风格更多样。数据来自从数十亿网页里抽取出来的图片与 alt 文本；这些原始文本很噪，所以经过一条过滤与清洗流水线，并做『上位词化』：把具体人名、地名等替换成更泛的概念，使描述更适合训练。

作者也在这份数据上评测了多种模型，发现用 Inception-ResNetv2 提取图像特征、再用 Transformer 建模序列的组合表现最好。后来 CLIP、ALIGN 把规模放大到上亿、十亿级别的图文对，沿用的就是这种『从网页自动取数据』的思路。

局限与后续

它建立在什么之上

  • 竞争
    Common Crawl与网络规模文本2008 · 数据·评测
    同样从网络爬取数据，但 CC3M 是针对图文对做了清洗的专用数据集。
  • 改进
    Flickr30k2014.02 · 数据·评测
    图片规模只有3万多张，且偏向人物活动，难以覆盖更广泛的场景。
  • 改进
    MS COCO2014.05 · 数据·评测
    COCO 人工描述规模和多样性有限，CC3M 用网页 alt 文本自动获得大一个数量级的图文对。
  • 改进
    YFCC100M2015.03 · 数据·评测
    用户标签噪声大、语言杂乱，不是精心标注的描述，直接监督效果有限。
