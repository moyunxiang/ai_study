Skip-Thought句向量

Skip-Thought Vectors
2015.06论文延伸NeurIPS 2015Ryan Kiros, Yukun Zhu, Ruslan Salakhutdinov, Richard Zemel, Antonio Torralba, Raquel Urtasun, Sanja Fidler · University of Toronto / MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

词向量已有通用版本，但句子没有现成的通用向量；监督的句子表示又依赖特定任务的标注数据。

方法

利用书籍文本中句子的连续性：训练一个编码器，让它的句向量能让解码器还原出前一句和后一句。

影响

给出第一个流行的无监督通用句子编码器，其“用相邻上下文做自监督”的思路影响了后续句向量和预训练目标。

方法

在连续的书籍文本上，把中间句子s_i用RNN编码器压成一个向量，再用两个RNN解码器分别生成s_{i-1}和s_{i+1}。这等于把word2vec的skip-gram“用词预测邻居词”提升到句子层面，所以叫skip-thought。

训练后丢掉解码器，只保留编码器当作通用特征提取器。因为训练词表有限，论文又提出一种简单的词表扩展方法：在预训练词向量与模型词向量之间学一个线性映射，使词表可扩大到一百万词。

评测方式是冻结向量、只在上面训练线性模型，覆盖语义相关度、复述检测、图文排序、问题类型分类和四个情感与主观性数据集共8项任务，论文称取得稳健的表现。

局限与后续

  • 训练需要在长篇连续文本上跑很久，句子级的生成目标代价高，而且向量在需要精细语义的任务上不如后来的监督方法。
    后来针对它的工作　InferSent Sentence-BERT
  • 编码器是单向或双向RNN，难以并行，且表示不随任务微调。
    后来针对它的工作　BERT

它建立在什么之上

  • 延续
    word2vec2013.01 · NLP
    把skip-gram“预测邻居词”的思路提升到“预测邻居句”。
  • 改进
    Skip-gram负采样2013.10 · NLP
    短语靠共现计数和人工阈值预先合并，只能覆盖常见的固定搭配，句子、段落等更长文本的表示仍无从谈起。
  • 使用
    RNN编码器-解码器与GRU2014.06 · NLP
    用RNN（GRU）编码器-解码器结构，只是把目标换成相邻句子。
  • 改进
    doc2vec段落向量2014.05 · NLP
    没有利用句子之间的连续性，也不是为迁移到多种下游任务设计的通用编码器。

后来的相关工作

  • 使用
    Layer Normalization2016.07 · 基础 已核对
    以Skip-Thought句向量为实验对象（原模型要训练好几天才有像样的结果），显示LN能加快训练，1M步后下游任务效果也更好。
  • 改进
    BERT2018.10 · LLM
    编码器是单向或双向RNN，难以并行，且表示不随任务微调。
  • 竞争
    序列预训练（Dai & Le）2015.11 · NLP
    同年用无标注文本学句子编码器的另一条路：Skip-Thought预测相邻句子并冻结编码器当特征，本文复述本句并对整个网络微调。
  • 竞争
    Sentence-BERT2019.08 · NLP
    Skip-Thought通过预测相邻句子无监督学句向量；论文对比显示基于BERT微调的SBERT在语义相似度上明显更好。
  • 竞争
    InferSent2017.05 · NLP
    同样追求通用句向量，但改用监督NLI信号取代无监督的上下句预测。

读懂它需要的概念

嵌入向量 自监督学习 编码器-解码器

本篇术语

  • 句子编码器　把任意长度的句子映射为一个固定维度向量的模型，向量可直接喂给下游分类器。

怎么学

先会RNN编码器-解码器与GRU的编码器-解码器；读原文第2节；用公开的skip-thought向量在一个情感数据集上训练逻辑回归。
