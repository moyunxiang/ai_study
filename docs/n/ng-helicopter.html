直升机特技飞行RL

Autonomous Helicopter Flight via Reinforcement Learning
2003论文延伸NIPS 2003Andrew Ng, H. Jin Kim, Michael Jordan, Shankar Sastry · Stanford / UC Berkeley待核对
参考页面 ↗在交互版中打开（演化树、学习进度）

问题

无人直升机的动力学非线性强、不稳定，人工调参的控制器难以做特技飞行，真机上随便试错又会坠毁。

方法

先让人飞，用飞行数据学出直升机的动力学模型，再在这个模型的仿真里用强化学习搜索策略，最后放到真机上。

影响

强化学习第一次在真实、复杂、不稳定的机器人上成功，显示了“学模型加在模型里搜索策略”的路线。

方法

本篇的原文与数字未能在本次会话核对，只写定性内容。

做法分三步：第一步，由人类飞行员操控，记录直升机状态与操纵量；第二步，用这些数据拟合一个动力学模型；第三步，在模型里用强化学习（策略搜索）找到一个控制策略，再放回真机飞行。因为学习发生在模型里，真机不必承担大量试错的坠机风险。这条“先学模型再规划”的路线属于基于模型的强化学习。

  • 策略的质量受限于学到的模型；模型不准的地方，策略在真机上会出问题。
