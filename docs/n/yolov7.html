YOLOv7

YOLOv7: Trainable bag-of-freebies sets new state-of-the-art for real-time object detectors
2022.07论文延伸CVPR 2023Chien-Yao Wang, Alexey Bochkovskiy, Hong-Yuan Mark Liao · Academia Sinica待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

实时检测器的精度提升大多靠加大模型，作者想在不增加推理成本的前提下，仅靠训练策略的改进提升精度。

方法

提出一组「可训练的免费礼包」：只在训练阶段增加开销的结构与标签分配策略，推理时可合并或丢弃，从而同时提升速度与精度。

影响

在发表时刻于5到160 FPS范围内速度精度全面领先，是YOLO系列里偏工程优化的一代，也引发了关于版本命名的争论。

方法

论文延续YOLOv4的「bag-of-freebies」思路，核心是训练时的优化而非推理时的新模块。

  • 重参数化模块：训练时用多分支结构增强表示，推理时把分支合并成单个卷积，不增加推理开销；并研究了这类模块如何与带残差的网络兼容。
  • 由粗到细的标签分配：检测头分为主头和辅助头，辅助头用较宽松的标签监督、主头用更严格的监督，引导训练。
  • 复合缩放：同时按比例缩放深度与宽度，使不同规模的模型保持结构合理。

模型只在MS COCO上从头训练，不用其他数据集或预训练权重。

结果

摘要称YOLOv7在30 FPS以上的GPU（V100）实时检测器中精度最高，为56.8% AP；YOLOv7-E6为56 FPS、55.9% AP，速度比Swin-L Cascade-Mask R-CNN快509%、AP高2%，比ConvNeXt-XL Cascade-Mask R-CNN快551%、AP高0.7%。

后来的发展

之后的实时检测一方面沿着卷积路线继续优化至YOLOv10免NMS，另一方面RT-DETR实时DETR证明端到端Transformer检测器也能达到实时。

  • 重参数化　训练时用多分支结构，训练后通过数学等价变换合并成单分支，使推理更快。
