POPE物体幻觉

Evaluating Object Hallucination in Large Vision-Language Models
2023.05数据集延伸EMNLP 2023Li, Du, Zhou, Wang, Zhao, Wen · 中国人民大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LLaVA这类多模态大模型常常说出图片里根本没有的物体，但缺少稳定、可重复的方法来衡量这种幻觉。

方法

把评估改成是非题：直接问「图里有X吗？」，用图片里真实存在和不存在的物体各问一遍，按答对的比例打分。

影响

成为多模态大模型物体幻觉最常用的评测之一，后续大量减缓幻觉的方法都报告POPE成绩。

方法

此前评估图像描述里的物体幻觉多用CHAIR这类指标，需要把生成的句子里的物体词抽出来和标注比对，结果受句子长短和措辞影响很大。POPE（Polling-based Object Probing Evaluation）改成轮询式的是非提问：基于MS COCO的物体标注，对每张图问「Is there a X in the image?」。存在的物体作为正例；不存在的物体作为负例，负例的选法有三种：随机选、选全数据集里最常出现的物体、选与图中物体经常同时出现的物体。后两种更难，因为模型容易因为共现习惯而误答「有」。

作者评测了当时的多个多模态模型，发现它们在较难的负例设置下更容易幻觉。由于问题格式固定、答案只有是或否，评测稳定、便宜，也不依赖外部语言模型打分。

局限与后续

  • 只测物体是否存在，不覆盖属性、数量、位置、关系等其他类型的幻觉。
