4D高斯泼溅

4D Gaussian Splatting for Real-Time Dynamic Scene Rendering
2023.10论文延伸CVPR 2024Guanjun Wu, Taoran Yi, Jiemin Fang, Lingxi Xie, Xiaopeng Zhang, Wei Wei, Wenyu Liu, Qi Tian, Xinggang Wang · 华中科技大学 / 华为待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

3D高斯泼溅只能表示静止场景；动态场景若对每一帧单独训练一套高斯，存储和训练开销都随帧数线性增长，运动建模也不连贯。

方法

只保留一组规范空间里的3D高斯，再用4D神经体素编码加一个轻量MLP，预测每个高斯在任意时刻的形变。

影响

在800×800分辨率下达到实时渲染，是把高斯泼溅从静态扩展到动态场景的代表做法之一。

方法

4D-GS用一套整体表示描述整段动态场景，而不是逐帧套用3D-GS。它包含两部分：一组3D高斯（位置、形状、颜色、不透明度）和一个4D神经体素。体素的编码方式受HexPlane启发，把四维的（x, y, z, t）空间分解成若干张二维特征平面，再把平面特征合起来，为每个高斯在某个时刻提供一个特征向量，避免了存储完整4D体素的开销。

拿到这个特征后，一个轻量的MLP解码出该高斯在这个时间点的形变（位置、旋转、缩放的变化），变形后的高斯再用与3D-GS相同的可微分泼溅光栅化渲染。因此高斯数量不随帧数增长，训练和存储都更省。

摘要称，在RTX 3090上以800×800分辨率实时渲染达到82 FPS，同时质量与此前最好方法相当或更好。

局限与后续

  • 依赖初始相机位姿和点云，对大幅度或拓扑变化的运动（物体出现、消失）建模能力有限。
