Pixel Reasoner像素推理

Pixel Reasoner: Incentivizing Pixel-Space Reasoning with Curiosity-Driven Reinforcement Learning
2025.05论文延伸Haozhe Wang, Alex Su, Weiming Ren, Fangzhen Lin, Wenhu Chen · 香港科技大学 / 滑铁卢大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多模态推理模型的思维链只在文字里进行，看一眼图就开始“想”，遇到信息密集的图片或长视频时，没法回头放大细节或挑出关键帧。

方法

给VLM配上放大（zoom-in）、选帧（select-frame）等视觉操作，让推理过程可以在像素空间里取证；先用合成轨迹做指令微调教会它用这些操作，再用带“好奇心”奖励的强化学习鼓励它真的去用。

影响

7B模型在V* bench得84%、TallyQA-Complex得74%、InfographicsVQA得84%，作者称是当时开源模型的最高成绩；“好奇心奖励防止模型回避视觉操作”的做法被后续“用图像思考”类工作参考。

方法

用图像思考展示了推理模型可以在思考中反复裁剪、放大图片。开源界要复现这件事，难点不在定义操作，而在训练：模型一开始用视觉操作的能力很弱，用了反而容易出错；强化学习时它会发现“只在文字里推理”更稳，于是干脆不用新操作。

Pixel Reasoner分两阶段训练：

  • 指令微调：合成一批带视觉操作的推理轨迹（何时放大哪一块、何时选哪一帧），让模型先熟悉这些操作的格式和用途，其中也包括操作后发现选错、再自我纠正的轨迹。
  • 强化学习：除了答案对错的奖励，再加一项好奇心驱动的奖励，在模型使用像素空间操作的比例过低时给予额外激励，平衡像素空间推理与文字推理之间的探索，防止它退回纯文字推理。

有了这些操作，模型可以主动在信息丰富的图片或视频里收集证据，而不是一次性看完就靠猜。

局限与后续

  • 可用的视觉操作只有放大和选帧几种，无法做画辅助线、测量、调用外部工具等更复杂的视觉动作。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 好奇心奖励的阈值和系数需要手工设定，设得不好会让模型为了拿奖励而无意义地调用操作。

读懂它需要的概念

推理token与测试时计算 策略梯度 奖励设计与奖励投机 探索与利用 指令微调与对话模板

本篇术语

  • 像素空间推理（pixel-space reasoning）　推理过程中不只生成文字，还会调用放大、裁剪、选帧等操作直接查看图像局部，把看到的新视觉证据加入思考。
  • 好奇心奖励（curiosity reward）　强化学习里额外给“尝试新行为”的奖励，这里用来鼓励模型使用它还不擅长的视觉操作。

怎么学

先读用图像思考和DeepEyes图像思考RL，再看Pixel Reasoner论文关于“学习陷阱”和好奇心奖励的一节，比较它与DeepEyes在训练流程上的差别。
