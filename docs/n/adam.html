Adam

Adam: A Method for Stochastic Optimization
2014.12论文主干ICLR 2015Diederik P. Kingma, Jimmy Lei Ba · 阿姆斯特丹大学 / 多伦多大学来源已核对
arXiv ↗Sebastian Ruder：梯度下降优化算法概览 ↗在交互版中打开（演化树、学习进度）

问题

SGD对所有参数用同一个学习率，而不同参数的梯度尺度可以差几个数量级；AdaGrad的学习率会单调衰减到零，RMSProp没有论文也没有偏差修正。

方法

对每个参数同时维护梯度的滑动平均（一阶矩，相当于动量）和梯度平方的滑动平均（二阶矩），用前者除以后者的平方根作为更新量，并修正两者在训练初期偏向零的问题。

影响

论文称其超参数含义直观、通常只需少量调整；此后成为深度学习最常用的默认优化器之一，Transformer、GPT、BERT都用它（或其改进版AdamW）训练。

背景

训练神经网络的基本方法是随机梯度下降：θ ← θ − α·g，所有参数共用一个学习率α（见学习率与学习率调度）。问题是不同参数的梯度大小差别极大：词嵌入里罕见词的梯度大部分时间是0，偶尔才有一次；某些层的梯度又一直很大。一个α对一部分参数太大、对另一部分又太小，换个模型就要重新调。

2014年前已有几条思路，各解决一半。动量法把历史梯度累积起来，减少来回震荡，但不解决尺度问题。AdaGrad给每个参数一个自己的学习率：除以该参数历史梯度平方和的平方根，梯度一直很大的参数步子自动变小，稀疏特征的步子相对变大。但它累加的是全部历史，分母只增不减，训练久了学习率趋近于零，对需要长时间训练的非凸网络不合适。RMSProp把累加改成指数滑动平均，解决了这一点，但它只出现在Hinton的课程幻灯片里，没有论文，也没处理训练初期的估计偏差。

方法

对每个参数，每步拿到梯度g_t后（全部按元素计算）：

m_t = β₁·m_{t−1} + (1−β₁)·g_t（一阶矩：梯度的滑动平均，起动量作用） v_t = β₂·v_{t−1} + (1−β₂)·g_t²（二阶矩：梯度平方的滑动平均，衡量这个参数梯度的典型大小） m̂_t = m_t / (1−β₁ᵗ)，v̂_t = v_t / (1−β₂ᵗ)（偏差修正） θ_t = θ_{t−1} − α · m̂_t / (√v̂_t + ε)

论文推荐的默认值是 α = 0.001, β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸。

为什么要偏差修正。m和v都从0开始。第1步时 m₁ = 0.1g，v₁ = 0.001g²，不修正的话 m₁/√v₁ ≈ 0.1/0.0316 ≈ 3.16，第一步就迈出3倍多的α，而且β₂越接近1偏得越厉害。除以 1−β₁ᵗ 和 1−β₂ᵗ 之后，第1步恰好得到 m̂/√v̂ = g/|g|，步长就是α。随着t增大，修正因子趋近1，自动失效。

它为什么好用。更新量是“平均梯度除以梯度的典型大小”，量纲被消掉了：把损失乘以100，梯度乘100，更新量不变。每步的实际步长大致不超过α，相当于给每个参数一个以α为半径的“信任区域”，所以α的含义直观、好设。梯度方向前后一致时 m̂/√v̂ 接近±1，步子接近α；梯度忽正忽负（噪声大）时m̂被平均掉，步子自动变小。

论文还给出了在线凸优化框架下 O(√T) 的regret界，并提出用无穷范数代替二阶矩的变体AdaMax。

结果

论文的实验都不大，但覆盖了当时的典型场景：MNIST上的L2正则逻辑回归；用最常见的1万个词做词袋特征的IMDB影评分类（稀疏特征，Adam与擅长稀疏梯度的AdaGrad一样快）；带dropout的多层感知机；CIFAR-10上的卷积网络；以及变分自编码器（变分自编码器VAE），用来说明β₂接近1时不做偏差修正，训练初期会不稳定甚至发散。在这些任务上，Adam的收敛速度与各自最强的对手持平或更快，而且不需要为每个任务单独换方法。

后来的发展

Adam迅速成为默认选择：Transformer用Adam加warmup学习率调度训练，GPT-1、BERT延续了这个组合。之后的改进大多针对它的具体缺陷：AdamW指出在Adam里L2正则与权重衰减并不等价，把权重衰减从梯度里拆出来，之后被许多大语言模型采用；Adafactor压缩二阶矩的显存；LAMB针对超大批量训练；Lion只保留一个动量状态；Muon优化器对矩阵参数做整体正交化，被一些团队尝试用于大模型预训练。

在图像分类上，带动量的SGD训练出的卷积网络（如ResNet）泛化常被报告比Adam好（AdamW论文的动机之一就是让Adam在图像分类上能与之竞争），所以视觉领域长期两者并用。

容易误解的地方

  • 在Adam里往损失上加L2正则，并不等于权重衰减：L2的梯度也会被 √v̂ 缩放，梯度大的参数几乎没被正则。这正是AdamW要解决的问题。
  • 论文的收敛证明后来被指出有错误，存在Adam不收敛的简单凸问题反例；实践中这很少成为障碍。
  • ε不只是防止除零：大模型或低精度训练里它的取值会影响稳定性。
  • “Adam不用调学习率”是夸张说法，α和warmup对大模型依然关键。

局限与后续

  • 与L2正则耦合：权重衰减项被自适应分母缩放，正则效果变弱，图像分类上泛化常不如SGD加动量。
    后来针对它的工作　AdamW
  • 每个参数要额外存m和v两份状态，优化器显存是参数量的两倍，模型很大时成为负担。
    后来针对它的工作　Adafactor Lion
  • 按坐标独立缩放（对角预条件），忽略了权重矩阵内部参数之间的相关结构。
    后来针对它的工作　Shampoo Muon优化器
  • 批量增大到上万时，相同的超参数下训练变差，难以利用大规模数据并行。
    后来针对它的工作　LAMB
  • 训练初期二阶矩估计不准，深层Transformer仍需要学习率warmup才能稳定。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    变分自编码器VAE2013.12 · 生成 已核对
    第6.4节用变分自编码器（与Kingma和Welling 2013相同的结构）做实验，说明β₂接近1时不做偏差修正训练初期会不稳定。
  • 使用
    动量法1964 · 基础 已核对
    一阶矩m就是动量的指数平均形式，用来平滑梯度方向。
  • 延续
    RMSProp2012 · 基础 已核对
    二阶矩部分就是RMSProp，Adam在其上加了动量形式的一阶矩和偏差修正，并给出了正式的论文与分析。
  • 延续
    随机梯度下降1951 · 基础 已核对
    仍是一阶随机梯度方法，只是给每个参数自动配一个随梯度尺度变化的学习率。
  • 竞争
    自然梯度1998 · 基础 已核对
    论文指出二阶矩是对Fisher信息矩阵对角线的近似，Adam用它的平方根倒数做预条件，比标准自然梯度的调整更保守。
  • 改进
    AdaGrad2011 · 基础 已核对
    论文说Adam的设计是结合AdaGrad（擅长稀疏梯度）和RMSProp（擅长非平稳目标）的优点，并说明AdaGrad相当于β₁=0、β₂无限接近1且学习率按1/√t退火的Adam特例；与AdaGrad累加全部历史不同，Adam用指数滑动平均只看近期梯度。
  • 改进
    反向传播1986 · 基础 待核对
    学习率、动量等超参数全靠手调，不同层的梯度大小相差悬殊，训练慢且不稳定。
  • 改进
    Nesterov加速梯度1983 · 基础
    加速的保证只对光滑凸函数成立，神经网络是非凸、随机梯度的场景，理论不直接适用。
  • 改进
    L-BFGS1989 · 基础
    依赖精确的线搜索和稳定的梯度，在随机小批量、非凸的深度网络训练中表现不稳。
  • 改进
    Hessian-free优化2010.06 · 基础
    每次更新需要几十次CG迭代，每次迭代要对大批量数据算一次H·v，相比一阶方法每步代价高得多，不容易扩展到超大模型。
  • 改进
    动量与初始化的重要性2013.06 · 基础
    动量与初始化的调度需要大量人工调参，对不同架构不通用。

  • 改进

  • 竞争

  • 使用

  • 使用

读懂它需要的概念

梯度下降 随机梯度下降与小批量 学习率与学习率调度 动量 自适应学习率优化器 期望与方差

本篇术语

  • 一阶矩 / 二阶矩　随机变量的期望和平方的期望。Adam里指梯度和梯度平方的滑动平均，前者给方向，后者给尺度。
  • 偏差修正　滑动平均从0开始，前几步会系统性偏小；除以 1−βᵗ 把它放大回无偏的估计。
  • regret　在线学习中的指标：算法每一步的损失与事后看来最好的固定参数之间的差距之和。O(√T)表示平均差距随步数趋于0。

怎么学

先补动量和自适应学习率优化器，理解指数滑动平均。读原文第2节（算法，只有一页）和第3节（偏差修正），第4节的收敛证明可以跳过。动手：用NumPy在一个两个方向曲率相差100倍的二次函数上分别跑SGD、动量、RMSProp和Adam，画出轨迹；再把偏差修正去掉、β₂设为0.9999，看看前几十步发生了什么。
