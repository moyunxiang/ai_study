想象增强智能体I2A

Imagination-Augmented Agents for Deep Reinforcement Learning
2017.07论文延伸NIPS 2017Théophane Weber, Sébastien Racanière, David P. Reichert, Lars Buesing, Arthur Guez, Danilo J. Rezende, Adrià Puigdomènech Badia, Oriol Vinyals et al. · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多数基于模型的RL规定了模型该怎么用（比如在模型里做搜索或展开），一旦学到的模型不准，规划结果就会被误差带偏；无模型方法又不能利用对环境的预测。

方法

不规定如何用模型，而是让策略网络自己学会「解读」模型的预测：用学到的环境模型想象几条未来轨迹，编码后作为额外输入交给无模型的策略网络。

影响

代表了「把学到的模型当作信息来源而非规划器」的一种思路，和MuZero等「只学对决策有用的模型」的路线一起推动了学习式规划的研究。

方法

I2A由两条路径组成。无模型路径就是一个普通的A3C式卷积策略网络。想象路径先用一个预训练的环境模型（输入当前画面和动作，预测下一帧画面和奖励），从当前状态出发、按一个简单的展开策略连续想象若干步，得到一条想象中的轨迹；对每个可能的首个动作各想象一条。每条想象轨迹被一个循环网络从后往前读一遍，编码成一个向量。

所有想象轨迹的编码和无模型路径的特征拼接在一起，交给最终的策略和价值输出层，整体用A3C训练。网络可以学会在模型可靠时多依赖想象，在模型出错时少依赖，因为它从未被要求「相信」想象。

摘要称，与若干基线相比，I2A在数据效率、性能以及对模型误设的鲁棒性上都有改进；论文的主要实验在推箱子（Sokoban）这类需要提前规划的益智游戏上进行。

局限与后续

  • 环境模型要逐像素预测下一帧画面，训练成本高，且这些像素细节大多与决策无关。
    后来针对它的工作　MuZero
  • 每一步都要为每个动作展开想象轨迹，计算开销随动作数和展开深度线性增长。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    Dyna：学习与规划合一1990 · RL
    Dyna用模型生成数据来训练价值函数；I2A把模型的想象作为策略网络的输入，由网络自己决定如何使用。
  • 竞争
    PILCO2011 · RL
    PILCO在学到的模型里直接优化策略，模型不准时会被误差带偏；I2A不完全信任模型，只把它的预测当作参考信息。
  • 使用
    A3C2016.02 · RL
    整体用A3C训练，无模型路径就是A3C式的策略网络。

本篇术语

  • 想象（imagination）　用学到的环境模型模拟「如果这样做接下来会怎样」，而不在真实环境中执行。
