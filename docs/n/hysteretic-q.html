滞后Q学习

Hysteretic Q-learning: an algorithm for Decentralized Reinforcement Learning in Cooperative Multi-Agent Teams
2007.10论文延伸IROS 2007Laetitia Matignon, Guillaume J. Laurent, Nadine Le Fort-Piat · FEMTO-ST / Université de Franche-Comté待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

合作多智能体里如果每个智能体各自独立做Q学习，队友的探索动作会让一个本来很好的动作偶尔得到很差的回报，于是智能体错误地低估它，最终大家都退回保守、不协作的动作。

方法

滞后Q学习：Q值往上更新时用正常学习率，往下更新时用小得多的学习率——对坏消息“反应迟钝”，从而不轻易因为队友的探索失误而放弃好的协作动作。

影响

成为去中心化合作MARL的经典简单基线，与宽容学习（lenient learning）一起被用来对付“相对过度泛化”，后来也被搬到深度多智能体RL（如Dec-HDRQN）中。

方法

在独立Q学习多智能体设定下，每个智能体i只维护自己的 Q_i(s, a_i)，把队友当作环境的一部分。TD误差为 δ = r + γ max_a′ Q_i(s′, a′) − Q_i(s, a_i)。滞后Q学习的更新是：

Q_i(s, a_i) ← Q_i(s, a_i) + α·δ， 若 δ ≥ 0 Q_i(s, a_i) ← Q_i(s, a_i) + β·δ， 若 δ < 0， 且 β < α

直观解释：在合作博弈里，同一个动作有时得到低回报，往往不是因为动作本身差，而是队友在那一刻做了探索性或不协调的动作。对正误差正常学习、对负误差缓慢学习，相当于让每个智能体对自己动作的价值保持“乐观”，近似估计“在队友配合得好时能得到的回报”。β=α时退化为普通独立Q学习；β=0时变成只升不降的分布式Q学习（distributed Q-learning）的乐观更新，后者在随机环境中会被噪声误导，滞后Q学习用一个小的非零β在两者之间折中。

作者在若干经典的合作矩阵博弈（如攀登博弈）和多机器人协作任务上表明，滞后Q学习比独立Q学习更常收敛到最优的联合动作。

局限与后续

  • 在奖励本身随机性很大的环境中，对负误差反应迟钝会让智能体高估运气好时的回报，β的取值难以兼顾。

时序差分与自举 学习率与学习率调度 信用分配 博弈论基础与纳什均衡

本篇术语

  • 攀登博弈（climbing game）　经典合作矩阵博弈：最优联合动作回报最高，但一方偏离就会受重罚，独立学习者容易退到安全但次优的动作。

怎么学

先懂表格Q学习和独立Q学习；在攀登博弈上分别跑β=α、β=0.1α、β=0三种设置，比较收敛到最优联合动作的比例。
