ANYmal Parkour跑酷导航

ANYmal Parkour: Learning Agile Navigation for Quadrupedal Robots
2023.06论文延伸Science Robotics 2024David Hoeller, Nikita Rudin, Dhionis Sako, Marco Hutter · 苏黎世联邦理工学院（ETH Zurich）、NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

四足机器人做跑酷式敏捷导航很难：动作剧烈、身体各部位都可能接触障碍，传感器视野又有限，以往方法需要专家示范、离线规划或事先知道地形。

方法

完全靠学习：先分别训练行走、跳跃、攀爬、下蹲等技能，再训练一个高层导航策略选择和调用这些技能，并训练感知模块从遮挡、噪声大的数据中重建障碍。

影响

全部模块只在仿真中训练，真机上以最高约2米每秒连续越过高难障碍，展示了分层强化学习加感知重建在野外级跑酷上的可行性。

方法

卡在哪：ANYmal野外感知行走让ANYmal能在野外稳健行走，四足跑酷、Extreme Parkour四足极限跑酷让小型四足学会跑酷动作，但把多种技能组合起来、在陌生场景里自己规划路线穿越连续障碍，仍需要人工示范或事先建好地形图。

做法：分三部分。技能层：在Isaac Gym大规模并行仿真式的大规模并行仿真里用强化学习分别训练行走、跳上、爬下、蹲下钻过等运动技能。导航层：训练一个高层策略，在地形上选择调用哪个技能并给出目标，由于分层设计，导航策略“知道”每个技能能做什么，会根据场景调整行为。感知层：训练一个网络从高度遮挡、带噪的深度数据中重建障碍物，为上两层提供场景理解。与以往方法相比，它不需要专家示范、离线计算、环境先验，也不显式建模接触。

结果：所有模块只用仿真数据训练，真机实验中ANYmal以最高约2米每秒的速度连续越过多个高难障碍。
