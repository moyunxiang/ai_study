MPNet掩码排列预训练

MPNet: Masked and Permuted Pre-training for Language Understanding
2020.04论文延伸NeurIPS 2020Kaitao Song, Xu Tan, Tao Qin, Jianfeng Lu, Tie-Yan Liu · 南京理工大学、微软亚洲研究院待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

BERT的掩码语言模型独立预测各个被遮的词，忽略它们之间的依赖；XLNet的排列语言模型考虑了依赖，但预测时看不到后面待预测词的位置，预训练与微调时“看到的句子长度”不一致。

方法

结合两者：用排列语言模型的方式按顺序预测被遮的词以利用依赖，同时把所有待预测词的位置信息（不含内容）作为辅助输入，让模型始终“看到”完整句子的长度和位置。

影响

在同等设置下超过BERT、XLNet、RoBERTa；其基础模型后来被Sentence-Transformers微调成all-mpnet-base-v2，长期是最常用的英文句向量模型之一。

方法

背景：BERT随机遮住约15%的词，各个被遮词独立地被预测——如果遮住“New”和“York”，模型不能利用“前一个是New”来预测York。XLNet改用排列语言建模：随机打乱预测顺序，按这个顺序自回归地预测，从而建模被预测词之间的依赖；但在预测前几个词时，模型并不知道后面还有几个待预测位置，相当于看到的是一个残缺的句子，而微调时输入总是完整的，造成位置上的不一致。

MPNet的做法：把句子打乱成一个排列，前面一部分是可见词，后面是待预测词。预测时像XLNet那样按顺序生成，后面的词能看到前面已经预测出的词（利用依赖）；同时，在可见内容之外，额外插入所有待预测位置的位置嵌入加[MASK]占位，于是模型在每一步都知道整句有多长、哪些位置还空着，缓解了预训练与微调的差异。实现上沿用XLNet的双流注意力。

作者在超过160GB文本上预训练，在GLUE、SQuAD等任务上微调，摘要称在相同模型设置下大幅超过单纯的MLM和PLM，并优于BERT、XLNet、RoBERTa。

局限与后续

  • 仍属于编码器式的判别型预训练，双流注意力实现复杂、训练开销高于普通MLM；随着生成式大模型成为主流，这类针对理解任务的目标改进很快不再是研究重点。

它建立在什么之上

  • 改进
    BERT2018.10 · LLM
    BERT独立预测各个被遮词，MPNet用排列顺序预测利用被预测词之间的依赖。
  • 竞争
    RoBERTa2019.07 · LLM
    在同等模型规模和训练设置下与RoBERTa对比，摘要称更好。
  • 改进
    XLNet2019.06 · LLM
    XLNet预测时看不到完整句子的位置信息，MPNet把待预测位置的位置嵌入作为辅助输入。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

掩码建模 自回归生成 位置编码 预训练与微调 自注意力与多头注意力

本篇术语

  • 排列语言模型（PLM）　把一句话的词随机排一个顺序，按这个顺序一个接一个地预测，从而在不改变原句的前提下看到双向上下文。

怎么学

先读BERT的掩码语言模型和XLNet的排列语言模型与双流注意力；读本文第2节对两者缺点的分析示意图；之后看Sentence-Transformers如何在MPNet上微调句向量模型。
