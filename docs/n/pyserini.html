Pyserini检索工具包

Pyserini: An Easy-to-Use Python Toolkit to Support Replicable IR Research with Sparse and Dense Representations
2021.02系统延伸SIGIR 2021Jimmy Lin, Xueguang Ma, Sheng-Chieh Lin, Jheng-Hong Yang, Ronak Pradeep, Rodrigo Nogueira · 滑铁卢大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

神经检索研究用Python和PyTorch，而可复现的BM25基线在Java的Anserini里；稠密检索（DPR等）又各有各的代码和索引，想在同一套数据上公平比较稀疏、稠密和混合检索很麻烦。

方法

做一个标准的Python包：通过Anserini调用Lucene做稀疏检索，通过Faiss做稠密向量检索，并支持两者加权融合的混合检索；同时附带常用测试集的查询、相关性标注、预建索引和评测脚本，pip install 后几行代码就能复现基线。

影响

Pyserini成为多阶段排序研究中第一阶段检索的常用工具，MS MARCO、BEIR、Mr. TyDi等基准的BM25和稠密检索基线大量直接引用它的数字。

背景

Anserini可复现检索解决了Lucene上的稀疏检索可复现问题，但深度学习研究者习惯在Python中工作。2020年稠密检索DPR、ColBERT后期交互等稠密检索方法兴起，用Transformer把查询和段落编码成向量做最近邻搜索；这些方法与BM25各有优势，常需要混合使用，但缺少统一、可复现的实验平台。

方法

稀疏检索：通过Python调用Anserini/Lucene，支持BM25、查询扩展，以及DeepImpact、uniCOIL这类「学习到的稀疏表示」。

稠密检索：读取用Transformer编码器离线编码好的段落向量，放进Faiss索引（精确内积或近似搜索），查询时在线编码后检索最近邻。

混合检索：对同一查询分别取稀疏与稠密的候选列表，按归一化后的分数加权融合：

s_hybrid(d) = α · s_sparse(d) + s_dense(d)

可复现性：为MS MARCO passage/document、Natural Questions、TriviaQA等提供预建好的索引和编码向量的下载，以及与TREC官方工具一致的评测脚本，并像Anserini一样维护回归测试。

结果

摘要称论文概述了工具包功能，并在两个常用排序任务（MS MARCO段落与文档检索）上给出实验结果展示其有效性；具体数字未核对。

后来的发展

Pyserini之后，滑铁卢团队陆续加入多语言检索（Mr. TyDi、MIRACL）、BEIR零样本检索和大模型重排序的复现脚本；它与Faiss一起成为检索增强生成研究中搭建第一阶段检索器的常见选择。

局限与后续

  • 面向离线实验，预建索引和Faiss内存索引不适合直接作为大规模在线服务。

读懂它需要的概念

检索与向量数据库 嵌入向量 内积与余弦相似度 基准、排行榜与SOTA

本篇术语

  • 稀疏检索与稠密检索　稀疏检索用词项的倒排索引匹配（如BM25），稠密检索把查询和文档编码成连续向量后找最近邻；前者精确匹配词，后者能匹配语义。
  • 多阶段排序　先用便宜的检索器从海量文档中召回几百上千篇候选，再用更贵的模型（如BERT交叉编码器）重排序。

怎么学

先了解BM25、稠密检索DPR和Faiss → 读原文第2–3节 → 动手：pip install pyserini，在MS MARCO passage上分别跑BM25、DPR和混合检索，比较Recall@1000与MRR@10。
