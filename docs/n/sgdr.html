余弦退火SGDR

SGDR: Stochastic Gradient Descent with Warm Restarts
2016.08论文重要ICLR 2017Ilya Loshchilov, Frank Hutter · University of Freiburg待核对
arXiv ↗代码 loshchil/SGDR ↗PyTorch文档 CosineAnnealingWarmRestarts ↗在交互版中打开（演化树、学习进度）

问题

训练深度网络时学习率通常按人工定好的轮次“阶梯式”下降，什么时候降、降多少全凭经验，而且要等到训练快结束时模型才好用。

方法

让学习率在每个周期内沿半个余弦曲线从最大值平滑降到接近0，周期结束就“热重启”回到最大值，并让周期长度逐次翻倍。

影响

余弦退火从此成为最常用的学习率调度之一，去掉重启的单周期版本被ImageNet训练和GPT-3、Chinchilla等大语言模型广泛采用。

背景

随机梯度下降加动量法是2016年训练图像网络的主力，学习率（见学习率与学习率调度）怎么随训练变化对结果影响很大。当时的标准做法是阶梯衰减，例如Wide ResNet在CIFAR上用初始学习率0.1，第60、120、160轮各乘0.2，总共200轮。这有两个问题：几个下降点要人工试，换个预算就得重调；而且在第一次大幅降学习率之前，模型的测试误差一直很高——如果中途想停下来用，得到的是很差的模型（论文称之为“随时性能”差）。

作者来自无梯度优化（如进化策略CMA-ES）领域，那里常用“重启”来跳出局部区域、改善随时性能。他们想把这个思路搬到SGD上。

方法

把训练分成若干个周期。在第i个周期内，学习率按余弦从η_max降到η_min：

η_t = η_min + ½(η_max − η_min)(1 + cos(π·T_cur / T_i))

T_cur是从上次重启起已经过了多少轮（每个小批量都更新，可以取0.1、0.2这样的小数），T_i是这个周期的长度。开始时cos 0 = 1，学习率等于η_max；走到周期末cos π = −1，学习率降到η_min。曲线前段和末段都很平，中间下降最快：先用大步长探索，再用小步长细调。

热重启：周期结束后把学习率直接拉回η_max，但参数不重置，从当前位置继续——所以叫“热”重启。大学习率会把模型暂时推离当前极小值，可能落到更好的区域。

周期翻倍：T_i = T_0 · T_mult^i。例如T_0 = 10, T_mult = 2时，周期依次是10、20、40、80轮，在第10、30、70、150轮结束处各得到一个学习率降到底、可以直接拿来用的模型。

每次重启前的模型还可以存下来做集成（快照集成，Huang等人受本文arXiv初版启发提出），不增加训练成本。

结果

CIFAR上WRN-28-10（3650万参数），5次运行的中位测试误差：按原文复现的阶梯调度在CIFAR-10/100上为4.13%/20.21%（初始学习率0.05），SGDR（T_0=10, T_mult=2）为4.03%/19.58%。论文称达到相当或更好的结果所需轮数少2到4倍。网络加宽到WRN-28-20后，单模型CIFAR-100误差降到18.70%。用16次运行、每次取3个快照做集成，误差为3.14%（CIFAR-10）和16.21%（CIFAR-100），是当时的最好结果。另在EEG脑电数据和下采样到32×32的ImageNet上也验证了优势。

后来的发展

实践中被保留下来的主要是“余弦退火”本身：只跑一个周期、从最大值平滑降到接近0，不再重启。它成为图像分类训练的默认调度之一，大语言模型也普遍采用：GPT-3先线性预热、再用余弦把学习率在2600亿token内降到最大值的10%；Chinchilla的附录专门研究了余弦周期长度，结论是周期应与实际训练的token数匹配（在约D个token内衰减10倍），周期设得过长会让模型训练不足。开头的线性预热则来自学习率预热与大批量SGD一类工作。同组作者随后的AdamW把权重衰减与Adam解耦，并给出带热重启的AdamWR。随机权重平均SWA利用周期性学习率在多个解之间取平均。2024年的Schedule-Free优化则试图彻底去掉“必须事先知道总步数”的调度。

局限与后续

  • 余弦曲线需要事先确定周期长度；单周期用法等于必须提前知道总训练步数，中途想延长训练就得重来。
    后来针对它的工作　Schedule-Free优化
  • 每次重启后误差会暂时明显变差，重启的收益在后来的大规模训练中并不稳定，实际多数人只用不重启的单周期版本。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只在SGD加动量上验证，与Adam等自适应优化器、以及其中的权重衰减如何配合没有研究。
    后来针对它的工作　AdamW
  • 从最大学习率直接开始，没有预热；批量很大时一开始就用大学习率会训练发散。
    后来针对它的工作　学习率预热与大批量SGD

读懂它需要的概念

学习率与学习率调度 随机梯度下降与小批量 动量 损失曲面、局部极小与鞍点 集成学习

本篇术语

  • 热重启（warm restart）　把学习率突然调回较大值，但保留当前参数继续训练；与之相对的“冷重启”是从新的随机初始化重新训练。
  • 随时性能（anytime performance）　训练在任意时刻被打断时，手上模型的好坏。阶梯衰减在最后一次降学习率前一直很差，SGDR每个周期末都有一个可用的好模型。
  • 快照集成　把同一次训练中不同时刻（如每次重启前）的模型存下来，测试时对它们的预测取平均，得到不额外花训练成本的集成。

怎么学

先理解学习率与学习率调度调度为什么重要，然后读原文第3节（式5只有一行）和图1，看几种调度曲线的形状。动手：在CIFAR-10上训练同一个ResNet，分别用阶梯衰减、单周期余弦、带重启的余弦，记录每一轮的测试误差，比较最终精度和“中途停下”时的精度。
