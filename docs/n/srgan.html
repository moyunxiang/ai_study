SRGAN

Photo-Realistic Single Image Super-Resolution Using a Generative Adversarial Network
2016.09论文延伸CVPR 2017Ledig, Theis, Huszár, Caballero, Cunningham, Acosta, Aitken, Tejani, Totz, Wang, Shi · Twitter待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

最小化均方误差的超分辨率虽然PSNR高，但4倍放大时缺少高频纹理，看起来模糊。

方法

把生成对抗网络用于超分辨率：生成器输出高分辨图，判别器分辨真假，再加基于VGG特征的内容损失。

影响

第一个能在4倍放大下生成照片级真实纹理的框架，把「感知质量」而不是PSNR作为目标。

方法

生成器是深度残差网络，判别器负责区分生成图和真实高分辨率图。损失由两部分组成：对抗损失把输出推向自然图像的分布；内容损失则像感知损失那样比较预训练VGG特征，而不是逐像素比较。这与均方误差目标形成对比：MSE会把多种可能的细节平均成模糊的一团。

论文称，在大量用户打分（MOS）实验中，SRGAN的得分更接近原始高分辨率图，而不是任何其他最好方法；但按PSNR衡量并不占优势。

局限与后续

  • GAN训练不稳定，会生成看似合理、实际并不存在的伪细节，不适合需要保真的场景。
    后来针对它的工作　ESRGAN SR3扩散超分辨率
  • PSNR等指标不能反映感知质量，评估困难。
    本站还没有记录针对它的后续工作（不代表没有人解决）
