SAE扩展到生产模型

Scaling Monosemanticity: Extracting Interpretable Features from Claude 3 Sonnet
2024.05论文延伸Transformer Circuits Thread 2024-05-21Adly Templeton, Tom Conerly, Jonathan Marcus, Jack Lindsey, Trenton Bricken, Chris Olah, Tom Henighan 等 · Anthropic待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

稀疏自编码器与单义特征只在一层的小Transformer上证明了SAE能找到单义特征，大家担心它无法扩展到真实的前沿模型。

方法

在生产模型Claude 3 Sonnet的中间层训练大规模SAE，得到抽象、多语言、多模态的特征，并展示操控这些特征能改变模型行为。

影响

证明SAE能扩展到前沿模型，并以“金门大桥Claude”这类演示让可解释性第一次吸引公众关注。

方法

Anthropic在2023年10月的小模型工作之后，把重点放在扩展上。这篇文章对当时生产中的Claude 3 Sonnet（3.0版，2024年3月4日发布）的中间层激活训练稀疏自编码器，提取到大量高度抽象的特征，如著名人物、国家与城市、代码里的类型签名。许多特征是多语言的（不同语言里同一概念都会激活），也是多模态的（文字和图像里的同一概念都会激活）。

论文特别强调安全相关的特征，比如与代码漏洞、后门有关的特征。他们还表明，这些特征不只是“响应”概念，还会因果地驱动行为：人为放大或抑制某个特征，模型的输出会随之改变。

局限与后续

  • SAE只能解释模型激活的一部分，重建有误差，训练全套特征的成本很高。

  • 找到了特征并不等于能据此可靠地检测或纠正危险行为。
