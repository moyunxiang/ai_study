Rapidus：日本直攻2nm

2022.08事件延伸Rapidus株式会社（丰田、索尼、NTT、软银、电装、铠侠、NEC、三菱UFJ银行出资）· 日本经济产业省支持 · 与IBM、imec合作待核对
维基百科 ↗Rapidus官网 ↗在交互版中打开（演化树、学习进度）

问题

日本半导体在1980年代曾占全球约一半份额，到2019年降到约一成；最先进的逻辑制程只剩台积电、三星、Intel三家，日本完全没有能制造先进逻辑芯片的工厂。

方法

由政府牵头、八家日本大企业出资成立一家新代工厂，跳过中间几代工艺，直接从IBM引进2nm纳米片GAA晶体管技术，在北海道千岁建厂，目标2027年量产。

影响

是日本重返先进逻辑制造的国家级尝试，也是台积电、三星之外少数瞄准2nm的新玩家；2025年做出了第一批2nm原型芯片，但能否按期量产、找到客户还没有定论。

方法

维基百科记载，Rapidus于2022年8月10日由丰田、索尼、NTT、软银、电装、铠侠、NEC和三菱UFJ银行八家公司以合计73亿日元成立，预计十年内还需约360亿美元投资；首任领导人是前东京电子负责人东哲郎和前西部数据日本子公司负责人小池淳义。背景是2022年5月日美首脑会谈后两国加强半导体合作，经产省同时设立了下一代半导体研究机构LSTC。

技术路线是直接跳到2nm：2022年12月，IBM与Rapidus宣布合作，由Rapidus在日本工厂生产IBM 2021年公布的纳米片GAA晶体管，官方称性能比当时市面上的7nm芯片高最多45%、能耗低75%；同月也与比利时研究机构imec签署合作备忘录。2023年2月选定新千岁机场附近的千岁市建厂，9月开工，ASML在当地设立技术支持办公室。

政府补贴逐年加码：2023年4月追加2600亿日元，2025财年拨款8025亿日元（约54亿美元）。2025年4月1日试产线开始测试，7月18日展示了第一批2nm原型芯片的300mm晶圆，报道的晶体管密度为每平方毫米2.37亿个。

局限与后续

  • 缺乏大规模制造先进逻辑芯片的经验和稳定客户，所需资金高度依赖政府补贴；2027年量产目标和良率能否达成尚不确定。

它建立在什么之上

  • 竞争
    美国CHIPS法案2022.08 · 硬件
    与美国CHIPS法案、欧盟芯片法案同期，日本选择直接出资扶持一家国家级新代工厂。
  • 使用
    EUV光刻进入量产2019 · 硬件
    2nm制造依赖ASML的EUV光刻机，ASML在千岁设立了技术支持团队。
  • 延续
    三星3nm GAA2022.06 · 硬件
    同样采用环栅（GAA）纳米片晶体管，只是技术来自IBM的2nm研究。

读懂它需要的概念

晶体管、制程与摩尔定律 芯片供应链：设计、代工、封装、内存

本篇术语

  • GAA（环栅）晶体管　栅极从四面包住导电沟道的晶体管结构，比FinFET更能控制漏电，是2nm以下制程的主流选择。
  • 试产线　正式量产前用来调试工艺、做原型芯片的小规模生产线。

怎么学

先读FinFET三维晶体管和三星3nm GAA理解晶体管结构的演进，再对比台积电N2纳米片与本节点：一个是代工龙头按部就班推进，一个是新公司跳代追赶，想一想后者最难的是什么。
