Kaldi子采样TDNN

A time delay neural network architecture for efficient modeling of long temporal contexts
2015.09论文延伸Interspeech 2015Vijayaditya Peddinti, Daniel Povey, Sanjeev Khudanpur · 约翰斯·霍普金斯大学待核对
ISCA Archive ↗TDNN-F (Interspeech 2018) ↗在交互版中打开（演化树、学习进度）

问题

前馈DNN声学模型只能看一个固定的小窗口；LSTM能看长上下文，但训练和解码慢、难并行。

方法

重新启用1989年的时延神经网络思想：每层只在少数几个时间偏移上拼接下一层的输出（层层扩大感受野），并对时间做子采样，只计算真正需要的帧。

影响

这种「子采样TDNN」成为Kaldi的标准声学模型，配合链式模型（LF-MMI）和后来的TDNN-F，在2016–2020年是工业界和学术界混合识别系统的主力结构。

方法

时延神经网络TDNN最早由Waibel等人在1989年提出，用来做音素识别：每层对前一层在若干相邻时刻的输出做同样的变换，相当于沿时间方向的一维卷积。在CD-DNN-HMM时代，大家改用普通前馈网络看一个固定窗口（比如前后各5帧），想看更长上下文就只能把窗口加宽，参数随之暴涨。

Peddinti等人的做法是：底层只看相邻几帧，越往上层拼接的时间偏移越大（例如{−1,0,1}、{−3,3}、{−7,2}这样不对称的组合），整个网络的感受野可以覆盖几百毫秒；同时做子采样——高层只在少数时刻计算，不必为每一帧都算一遍，因为相邻帧的高层表示高度相关。这让训练速度接近前馈DNN，而建模能力接近循环网络。

论文在多个大词汇量任务上报告比DNN基线有相对错误率下降（具体数字未核对）。它被并入Kaldi，随后与无词图MMI链式模型链式训练一起成为Kaldi的默认配方。2018年Povey等人又提出TDNN-F：把每层权重矩阵分解为两个低秩因子，其中一个被约束为半正交，在参数更少的情况下进一步降低错误率，成为Kaldi后期的标准结构。x-vector说话人嵌入说话人嵌入也采用了这种TDNN。

它建立在什么之上

  • 延续
    时延神经网络TDNN1989.03 · 语音
    沿用1989年TDNN的时间偏移拼接思想，加入层间不同偏移和子采样，使之能用于大词汇量识别。
  • 改进
    CD-DNN-HMM2011.08 · 语音
    前馈DNN上下文窗口固定且加宽代价大；TDNN用层级偏移以较少参数覆盖长上下文。
  • 使用
    Kaldi2011.12 · 语音
    在Kaldi中实现，成为其默认的nnet3声学模型结构。
  • 改进
    动态差分特征Δ1986.02 · 语音
    差分窗口长度是固定的手工选择，只能捕捉几十毫秒范围内的局部变化。
  • 竞争
    大规模LSTM声学模型2014.02 · 语音
    LSTM声学模型同样建模长上下文，但难并行；TDNN以前馈结构达到相近效果、速度快得多。
