YOLOv10免NMS

YOLOv10: Real-Time End-to-End Object Detection
2024.05论文延伸NeurIPS 2024Ao Wang, Hui Chen, Lihao Liu, Kai Chen, Zijia Lin, Jungong Han, Guiguang Ding · 清华大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

YOLO系列推理后必须做非极大值抑制（NMS）去重，它拖慢延迟、无法端到端部署，网络各部分的设计也有冗余。

方法

训练时同时用一对多和一对一两个检测头（一致的双重分配），推理只用一对一头，从而不需要NMS；再从效率和精度两头系统地精简模块。

影响

让YOLO也变成端到端检测器，把DETR一路“去掉后处理”的思想带进了实时检测的主流工程路线。

方法

传统YOLO对一个目标会预测很多个重叠框，训练时一个目标对应多个正样本（一对多分配），这样监督信号丰富，但推理时必须用NMS把重复框删掉。DETR一类模型用一对一匹配，天然不需要NMS，但训练收敛慢。

YOLOv10同时挂两个头：一对多头提供丰富监督，一对一头学习只输出一个框，并通过让两个头的匹配度量保持一致，使一对一头得到一对多头那样的好监督。推理时丢掉一对多头和NMS。除此之外，作者对骨干、下采样、卷积核等部件逐个检查，去除计算冗余，做出不同规模的模型。摘要称它在多种规模上取得更好的精度与效率折中。

局限与后续

  • 一对一头仍需要额外的训练分支和匹配设计，小目标、密集场景下去掉NMS的效果依赖数据。

本篇术语

  • NMS　非极大值抑制：把同一目标上多个重叠的预测框，只保留得分最高的一个。

怎么学

先弄清NMS做了什么（按置信度排序、删除高IoU重叠框），再读论文的双重分配一节；用官方仓库在COCO小子集上对比开关NMS的延迟。
