Image GPT

Generative Pretraining from Pixels
2020.06论文延伸ICML 2020Chen, Radford, Child, Wu, Jun, Dhariwal, Luan, Sutskever · OpenAI待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

自监督预训练在语言中大获成功，在图像上则靠对比学习等专门设计的方法，没人证明同样的「预测下一个」能行。

方法

把图像拉成像素序列，直接用GPT-2的结构做自回归预测，不加入任何二维结构的先验。

影响

证明了生成式的下一个像素预测也能学到强的图像表示，为后来统一的多模态序列建模铺路。

方法

做法是把低分辨率图像（如32×32、48×48）的像素展平为一维序列，经颜色聚类压缩为较小的词表，再训练一个与GPT-2同结构的Transformer，逐个预测下一个像素（见自回归生成），不使用任何卷积或二维位置先验。预训练完成后，取中间层的特征，用线性分类器探测（线性探针），或整体微调来分类。

摘要给出：在低分辨率ImageNet上无标签预训练后，CIFAR-10线性探针准确率96.3%，超过有监督的Wide ResNet；全部微调为99.0%，与最好的有监督预训练模型相当；若把像素换成VQVAE编码，ImageNet线性探针的top-1为69.0%，与自监督基准具竞争力。

局限与后续

  • 注意力的代价随序列长度平方增长，只能用很低的分辨率（序列长度几千），无法直接做大图。
    后来针对它的工作　VQGAN 潜空间扩散LDM
  • 线性探针结果在最好的层而非最后一层，效率不如对比类自监督方法。
    后来针对它的工作　掩码自编码器MAE BEiT

它建立在什么之上

  • 使用
    GPT-22019.02 · LLM
    直接采用GPT-2的结构和预测目标。
  • 延续
    PixelRNN / PixelCNN2016.01 · 生成
    沿用逐像素自回归的思路，但把网络换成Transformer，并将重点放在表示学习。
  • 改进
    PixelCNN++2017.01 · 生成
    采样仍必须逐像素串行，大图非常慢。

后来的相关工作

  • 竞争
    Vision Transformer2020.10 · 视觉 已核对
    iGPT先降低分辨率和颜色空间再对像素序列做Transformer（ViT引用其ImageNet最高72%）；ViT以16×16的块为单位，序列短得多，可以在正常分辨率下训练。
  • 延续
    DALL·E2021.01 · 生成 待核对
    Image GPT逐像素生成，序列太长只能做低分辨率；DALL·E在压缩后的离散码上建模，并加入文本条件。
  • 改进
    潜空间扩散LDM2021.12 · 生成
    注意力的代价随序列长度平方增长，只能用很低的分辨率（序列长度几千），无法直接做大图。
  • 竞争
    BEiT2021.06 · 视觉
    同为生成式预训练；iGPT对像素自回归且需数十亿参数，BEiT用掩码预测视觉token，86M参数的模型就能微调出更好的结果。
  • 改进
    掩码自编码器MAE2021.11 · 视觉
    线性探针结果在最好的层而非最后一层，效率不如对比类自监督方法。
  • 改进
    VQGAN2020.12 · 生成
    注意力的代价随序列长度平方增长，只能用很低的分辨率（序列长度几千），无法直接做大图。
