LongRoPE

LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens
2024.02论文延伸ICML 2024Yiran Ding, Li Lyna Zhang, Chengruidong Zhang 等 · Microsoft Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

把旋转位置编码RoPE模型的窗口拉长，需要微调很长的文本，而长文本稀缺、微调昂贵，当时窗口大多停在约128K。

方法

用搜索找出RoPE各维度、各位置的非均匀缩放系数，再分阶段微调，把窗口推到2048K个token。

影响

说明预训练模型只靠改动位置编码加极少的微调，就能把窗口放大数十倍，且基本保住短文本性能。

方法

位置插值扩上下文和YaRN把长位置按统一比例压缩回训练过的范围。LongRoPE发现这种压缩应该是非均匀的：RoPE不同维度的频率不同、序列开头的若干token也该区别对待。于是用一个高效搜索为每个维度找出缩放系数，作为微调前更好的初始化；不微调时就能实现8倍的窗口扩展。

第二步是渐进扩展：先微调到256K长度，再在已扩展的模型上做第二次位置插值，得到2048K窗口，微调只需约1K步（训练长度256K以内）。最后在8K长度上重新调整系数，找回短文本性能。

实验在LLaMA2和Mistral上，模型结构只改了位置编码部分，可以复用已有优化。

局限与后续

  • 2048K窗口是外推出来的，在这么长的输入上真正能用多少信息（而不只是困惑度不爆）需要另外检验。
    后来针对它的工作　RULER长上下文
  • 每个模型都要单独搜索系数，并且长窗口下短文本性能需要额外再校准。

它建立在什么之上

  • 使用
    旋转位置编码RoPE2021.04 · LLM
    整个方法只修改RoPE的频率缩放，不改模型其余部分。
  • 延续
    位置插值扩上下文2023.06 · LLM
    在线性位置插值的基础上，引入非均匀性和渐进式扩展。
  • 延续
    YaRN2023.08 · LLM
    同样改RoPE插值，但把统一缩放换成按维度搜索的非均匀缩放。
  • 改进
    外接kNN记忆2022.03 · LLM
    每个检索步骤要在大规模向量库里查找，推理变慢，现代长上下文模型更多靠扩展上下文窗口。
  • 改进
    循环记忆Transformer2022.07 · LLM
    在真实大模型和极长文档上的验证有限，主流方案转向直接扩展上下文窗口。
  • 改进
    无位置编码NoPE2023.05 · LLM
    主要研究的是外推，没有给出在实际大模型里能直接用的方案；业界主流仍是RoPE加缩放。
  • 改进
    Claude 2与100K上下文2023.07 · LLM
    长上下文并不等于能可靠利用：对埋在中间的信息召回不稳定，且长输入的推理成本很高。
  • 改进
    Llama 2 Long长上下文续训2023.09 · LLM
    只做到32K上下文，而且在迷失在中间揭示的“中间信息利用不足”这类问题上没有专门解决。
  • 改进
    LongLoRA高效长上下文微调2023.09 · LLM
    训练时的分组局部注意力与推理时的全注意力并不一致，在需要大范围精确检索的长文本任务上，这种近似训练的效果受质疑；后来更多做法是直接配合FlashAttention做全注意力续训或改进位置编码。
  • 改进
    Kimi长文本对话2023.10 · LLM
    长上下文的价值取决于模型是否真能利用中间信息，早期版本对长文中间内容的召回并不稳定。
  • 改进
    Mistral 7B2023.10 · LLM
    滑动窗口使超长依赖只能通过多层间接传递，长上下文检索能力受限。

怎么学

先读旋转位置编码RoPE与位置插值扩上下文；然后读原文第3节的非均匀性分析和搜索流程；动手：用不同的插值比例，观察长输入上困惑度的变化。
