PEARL离策略元RL

Efficient Off-Policy Meta-Reinforcement Learning via Probabilistic Context Variables
2019.03论文延伸ICML 2019Kate Rakelly, Aurick Zhou, Deirdre Quillen, Chelsea Finn, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

元强化学习（RL²元强化学习、MAML元学习式方法）希望智能体凭少量经验就适应新任务，但已有方法依赖同策略数据，元训练本身需要海量样本；也缺少在新任务上推理不确定性的机制，稀疏奖励下适应困难。

方法

把「推断现在是哪个任务」与「控制」拆开：用一个概率编码器从少量经验推断任务的隐变量z的后验，策略和Q函数以z为条件，用离策略的SAC训练；适应时从后验采样z来做结构化探索。

影响

摘要称样本效率比已有方法高20–100倍，成为离策略元RL的标准基线，「任务推断+条件策略」的结构被后来的上下文式元RL广泛采用。

方法

PEARL（Probabilistic Embeddings for Actor-critic RL）假设每个任务对应一个隐变量z（比如机器人要走向的目标方向）。

任务推断：给定在当前任务中收集到的一小批转移（上下文c），编码器对每条转移给出一个高斯因子，相乘得到 q(z|c)——这是一个与转移顺序无关的后验，摘要称之为对隐任务变量的在线概率滤波。

控制：策略 π(a|s,z) 和Q函数 Q(s,a,z) 都以z为条件，用SAC在回放缓冲区上离策略训练；编码器的梯度来自Q函数的贝尔曼误差，并加上一个让后验接近先验的信息瓶颈项。

适应新任务：开始时从先验采样z，按对应策略行动一个回合；用收集到的经验更新后验，再采样新的z。这就是摘要说的后验采样：先按「可能的任务」去试，随证据积累逐渐确定，实现结构化的探索。摘要称，在多个元RL基准上，PEARL的元训练样本效率比已有算法高20–100倍，渐近性能也更好。

读懂它需要的概念

元学习 隐变量模型 变分推断与ELBO Actor-Critic与优势函数 on-policy与off-policy

本篇术语

  • 元强化学习　在许多相关任务上训练，使智能体在遇到新任务时只需少量经验就能学会。
  • 上下文（context）　当前任务中已经收集到的少量转移，用来推断这是哪个任务。

怎么学

先读RL²元强化学习和SAC；读原文第4节编码器与训练目标；在HalfCheetah目标速度任务上运行官方实现，观察适应过程中后验的收缩。
