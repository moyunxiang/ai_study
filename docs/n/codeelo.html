CodeElo与Codeforces评分

CodeElo: Benchmarking Competition-level Code Generation of LLMs with Human-comparable Elo Ratings
2025.01数据集延伸Shanghaoran Quan, Jiaxi Yang, Bowen Yu, Bo Zheng, Dayiheng Liu, An Yang, Xuancheng Ren, Bofei Gao et al. · 阿里巴巴Qwen团队待核对
arXiv ↗项目主页与排行榜 ↗数据（Hugging Face） ↗在交互版中打开（演化树、学习进度）

问题

o1、o3、DeepSeek-R1都报Codeforces评分，但各家自己模拟比赛、规则不公开；离线代码基准又缺隐藏测试、不支持特殊评测器，分数无法与人类选手对齐。

方法

把模型代码用机器人直接提交到Codeforces官方评测，按真实比赛排名反推每场的Elo分，得到与人类选手可比、方差更小的评分。

影响

给开源界提供了一套可复现的Codeforces评分口径；发布时o1-mini约1578分、QwQ-32B-Preview约1261分，其余多数模型落在人类最低四分之一。

背景

Codeforces是最大的算法竞赛平台之一，每个选手有一个Elo式的评分。AlphaCode（2022）在模拟的Codeforces比赛中平均排在前54.3%，之后“Codeforces评分/百分位”成了衡量竞赛编程能力的常用说法：OpenAI o1推理模型发布页称o1达到1673分（第89百分位）、专门强化编程的版本达到1807分；DeepSeek-R1模型卡报告R1为2029分（第96.3百分位）。但这些数字都来自各家内部的模拟流程，提交次数、题目范围、算分方法各不相同。

方法

题目。从Codeforces收集2024年5月4日到11月4日的54场比赛、共387道题（作者观察到多数模型连Div. 1最简单的题都做不出，测试以Div. 2–4和Div. 1+2为主，其中Div. 2有33场），每题带比赛分区、难度分和算法标签。

判题。不在本地跑测试，而是用机器人把模型代码直接提交到平台，由官方评测：隐藏测试完整、执行环境与人类一致，也支持约30%没有唯一正确输出、需要特殊评测器（special judge）的题。每题最多提交8次。

算分。把模型放进当场人类选手的排名里，按Elo公式 m = Σ 1/(1+10^((r−r_i)/400)) 解出让期望名次等于实际名次的评分r；每场单独算再平均，作者称这样比平台的累积算法方差更小。

结果

评测了30个开源模型和3个闭源模型。o1-mini得1578分，超过近90%的人类参赛者；QwQ-32B-Preview得1261分，约在第60百分位。其余多数模型连最简单的题都难以通过，落在人类最低25%以内。模型擅长数学和实现类题目，在动态规划和树上明显吃力；多数模型用C++比用Python得分更高。

后来的发展

CodeElo的Codeforces评分被后续开源推理模型拿来和人类选手对比，与持续收新题的LiveCodeBench、由奥赛奖牌得主分析失败原因的LiveCodeBench Pro形成互补。另一条路线是直接参加真实赛事：推理模型参赛IOI在IOI 2024现场参赛，ICPC总决赛金牌水平在ICPC世界总决赛同场作答。

容易误解的地方

  • 不同报告里的“Codeforces评分”口径不同：OpenAI允许每题10次提交且按自己的模拟规则，CodeElo每题最多8次并逐场独立算分，数字不能直接比较。
  • 评分反映的是在这批比赛题上的排名位置，不等于选手在限时、单次提交压力下的真实成绩。

局限与后续

  • 依赖向Codeforces官方平台提交，评测能否复现取决于平台是否允许这种自动提交，且只覆盖当时最近半年的比赛。

它建立在什么之上

  • 延续
    OpenAI o1推理模型2024.09 · 推理·智能体
    o1发布页报告了Codeforces评分但流程不公开，CodeElo给出公开可复现的同类评分，o1-mini在其中得1578分。
  • 延续
    AlphaCode2022.02 · 推理·智能体
    AlphaCode用模拟的Codeforces比赛给出人类百分位排名；CodeElo把这种做法标准化，直接提交到官方评测并给出可比的Elo分。
  • 改进
    LiveCodeBench2024.03 · 数据·评测
    作者指出LiveCodeBench等基准缺少隐藏测试、不支持特殊评测器、执行环境不一致；官方平台评测把这三点一并解决。
  • 使用
    QwQ开源推理模型2024.11 · 推理·智能体
    以QwQ-32B-Preview作为开源推理模型代表，得1261分，作者据此认为加长思维链是提升竞赛编程的有效方向。
  • 改进
    推理模型参赛IOI2025.02 · 推理·智能体
    o3的IOI成绩是赛后按同样规则补测的结果，不是现场参赛；Codeforces评分来自OpenAI自己的模拟比赛，外部难以复现。

读懂它需要的概念

基准、排行榜与SOTA Elo评分与两两比较 数据泄漏与基准污染 推理token与测试时计算

本篇术语

  • 特殊评测器（special judge）　当一道题有多个正确输出时，用一段专门的检查程序判断答案是否合法，而不是逐字比对标准输出。
  • Div. 1–4　Codeforces按难度把比赛分成四个分区，Div. 1最难、只对高分选手计分，Div. 4最容易；另有Div. 1+2合场和全球赛。

怎么学

先读Elo评分与两两比较，理解评分如何由对手评分和名次决定。读原文第3节（题目收集、提交方式、Elo计算）和表3。动手：取一场你参加过或看过的Codeforces比赛的排行榜，给定一个名次，用文中的公式二分求出对应评分。
