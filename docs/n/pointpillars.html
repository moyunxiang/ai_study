PointPillars

PointPillars: Fast Encoders for Object Detection from Point Clouds
2018.12论文延伸CVPR 2019Alex H. Lang, Sourabh Vora, Holger Caesar, Lubing Zhou, Jiong Yang, Oscar Beijbom · nuTonomy / Aptiv待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

点云检测要么用固定编码器（快但不准），要么用学习的编码器（准但慢），3D卷积尤其耗时。

方法

把点云组织成竖直的柱子（pillar），用PointNet学每根柱子的特征，拼成伪图像后用普通2D卷积检测。

影响

在精度和速度上同时大幅超过之前的编码器，成为自动驾驶点云检测最常用的基线之一。

方法

做法是把x-y平面划成网格，每个格子对应一根没有高度分割的竖直柱子。柱子里的点用一个简化的PointNet提取特征，再按位置散布回网格，得到一张通道很多的伪图像。因为不再有3D卷积，后面可以直接接标准2D卷积主干和类似SSD的检测头，实现快速推理。

相对VoxelNet点云检测的主要差别是：它去掉了高度方向的体素和3D卷积，用速度换来了可部署性。论文称只用激光雷达就在KITTI的3D和鸟瞰图基准上超过此前方法，含融合方法。

局限与后续

  • 柱子只在平面上划分，丢失高度方向的细结构，小物体和远处物体表现受限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 仍依赖带锚框的检测头，对任意朝向的物体不够自然。
