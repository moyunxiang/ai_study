Genesis物理引擎

Genesis: A Generative and Universal Physics Engine for Robotics and Beyond
2024.12系统延伸Genesis团队（学术项目，后获Genesis AI支持）待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

机器人仿真器分散：刚体、软体、流体各用一套工具，易用性和速度也难兼得，限制了机器人学习需要的大规模并行数据生成。

方法

一个Python原生、GPU加速的统一仿真平台，把多种物理求解器和渲染放在同一个场景里，并计划加入生成式数据能力。

影响

提供了开源的、易上手的GPU仿真替代方案，与MuJoCo、Isaac等并存，面向机器人学习和物理AI。

方法

Genesis在2024年12月作为学术项目公开（项目README称其自2024年12月起；骨架里的论文标题为愿景性描述，本次未找到对应的arXiv论文）。官方当前仓库把它描述为一个物理AI的仿真平台，由统一多物理引擎、光真实感渲染器和跨平台编译器加上Python接口构成，物理引擎整合刚体、有限元、物质点法、粒子（PBD/SPH）等求解器，共享一个场景和状态。

它的卖点是易用与可扩展：能解析URDF、MJCF、USD等资产，支持并行和异构环境，并可从笔记本扩展到数据中心GPU。它延续MuJoCo物理仿真和Isaac Gym大规模并行仿真的路线，目标是为机器人学习提供更广的物理类型，今天已由Genesis AI公司支持开发。

局限与后续

  • 发布时宣称的速度和生成式能力，缺少经过同行评审的系统性基准验证。

  • 竞争
    MuJoCo物理仿真2012 · 具身·世界模型
    同属通用机器人物理仿真器；MuJoCo以精确的刚体接触见长，Genesis强调多物理统一与Python易用。
  • 竞争
    Isaac Gym大规模并行仿真2021.08 · 具身·世界模型
    同样追求GPU并行仿真，Genesis强调开源易用且覆盖更多物理类型。
  • 改进
    Orbit / Isaac Lab2023.01 · 具身·世界模型
    依赖NVIDIA GPU和Isaac Sim，安装和算力门槛高。
