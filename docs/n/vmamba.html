VMamba视觉状态空间

VMamba: Visual State Space Model
2024.01论文延伸NeurIPS 2024Yue Liu, Yunjie Tian, Yuzhong Zhao, Hongtian Yu, Lingxi Xie, Yaowei Wang, Qixiang Ye, Jianbin Jiao, Yunfan Liu · 中国科学院大学 / 华为 / 鹏城实验室待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

ViT的自注意力计算量随图像token数平方增长；Mamba能线性建模序列，但它是一维、有先后顺序的，而图像是二维、没有天然顺序的。

方法

提出二维选择性扫描SS2D：把图像特征沿四条路线（行正向、行反向、列正向、列反向）展开成序列分别做选择性扫描，再合并，让每个位置都能汇集各方向的上下文。

影响

得到线性复杂度的视觉骨干VMamba，在分类、检测、分割上表现良好，输入分辨率变大时的效率优势明显。

方法

Mamba状态空间模型用输入相关的选择性状态空间模型处理序列，计算量与长度成线性，在语言上能与Transformer相比。把它用到视觉上的难点是：选择性扫描只能按一维顺序从前往后累积信息，而图像没有天然顺序，一个像素只能“看到”扫描顺序在它之前的像素。

VMamba的核心是视觉状态空间块（VSS块）中的二维选择性扫描模块SS2D：把二维特征图按四条路线展开成四个一维序列——从左上到右下逐行、反向逐行、逐列、反向逐列——每个序列分别用选择性扫描处理，再把四个结果折回二维并相加。这样每个位置都能综合来自各个方向的信息，弥合了一维扫描与二维数据之间的差距。在VSS块基础上搭成分层的VMamba网络，并通过一系列结构和实现上的改进加速。

摘要称VMamba在多种视觉感知任务上表现有前景，随输入尺寸扩大时效率优于已有基准模型。同月的Vision Mamba采用双向扫描，是另一条把Mamba用于视觉的路线。

局限与后续

  • 多方向扫描需要专门的CUDA扫描算子，实际吞吐常不如同精度的卷积网络或用FlashAttention优化的ViT。
