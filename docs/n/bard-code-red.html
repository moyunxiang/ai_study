谷歌“红色警报”与Bard

2023.02事件延伸Sundar Pichai、Sergey Brin、Larry Page · Google待核对
Forbes：How ChatGPT Suddenly Became Google's Code Red（网站首页，未取得具体文章链接） ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT发布发布后用户开始用对话机器人代替搜索，直接威胁谷歌的核心业务；谷歌虽然有LaMDA和PaLM，却一直没有向公众发布。

方法

据报道谷歌管理层宣布内部「红色警报」，创始人佩奇和布林回来参与，并在2023年2月仓促发布聊天机器人Bard。

影响

谷歌从技术领先者变成追赶者，随后合并Brain与DeepMind（Brain与DeepMind合并）并推出Gemini（Gemini 1.0）。

方法

Forbes在2023年1月23日报道ChatGPT如何让谷歌进入「code red」，创始人佩奇和布林重新参与；Business Insider在2月12日报道布林申请访问谷歌代码。Bard在2月6日前后宣布（Mashable 2月6日、WEF 2月8日），Business Insider 2月10日报道员工批评CEO的发布方式；Bard在3月21日起开放候补名单（Mashable）。

报道称Bard发布材料中的一个错误回答使母公司股价下挫，市值一度蒸发约千亿美元（remio的标题称这是一次$100B的code red），这一数字未在本次会话中核对原始来源。Pichai在2023年4月澄清了「红色警报」的说法（Observer）。

后来的发展

事件说明大公司的内部顾虑（品牌风险、与搜索广告的冲突）在新技术面前也可能变成负担。此后谷歌调整组织与节奏，把对话产品并入Gemini体系。
