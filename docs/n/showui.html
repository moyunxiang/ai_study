ShowUI轻量GUI模型

ShowUI: One Vision-Language-Action Model for GUI Visual Agent
2024.11论文延伸CVPR 2025Kevin Qinghong Lin, Linjie Li, Difei Gao, Zhengyuan Yang, Shiwei Wu, Zechen Bai, Weixian Lei, Lijuan Wang, Mike Zheng Shou · 新加坡国立大学Show Lab / 微软待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

多数GUI智能体靠闭源模型读HTML或可访问性树这类文字信息，不能像人一样直接看屏幕；而截图分辨率高、视觉词元太多，训练和推理都很贵。

方法

做一个只看截图的轻量视觉—语言—动作模型：按界面结构合并重复的视觉词元来省算力，把多步操作的截图与动作交错成一条序列训练，并精挑少量高质量数据。

影响

2B模型只用25.6万条数据就在零样本截图定位上达到75.1%，说明小模型加界面专用设计也能做好GUI视觉智能体，成为开源GUI定位的常用基线。

方法

ShowUI基于开源视觉语言模型（Qwen2-VL-2B），有三处针对界面的设计：

  • 按界面引导的视觉词元选择：截图里大片同色背景、空白区域的图块几乎一样。模型把截图看成一张图，相邻且颜色相同的图块连成一个连通块，每块只保留少数代表词元参与自注意力计算。训练时可减少33%的冗余视觉词元，速度提升1.4倍；
  • 视觉—语言—动作交错流：把多步导航中的历史截图和动作交错排成一条序列，模型能记住之前做过什么；对定位类数据，则在同一张截图上配多组“问题—动作”一起训练，提高效率；
  • 小而精的数据：精心整理网页、手机、桌面的指令与定位数据，并对不同类型的数据重采样，缓解类型严重不均衡。

结果：2B模型、25.6万条数据，零样本截图定位准确率75.1%；在网页Mind2Web、手机AITW、在线MiniWob等导航环境上的实验也显示了有效性。它延续了SeeClick GUI定位“只看截图做定位”的路线。

局限与后续

  • 2B模型的规划和长程推理能力有限，复杂多步任务仍需更大的模型或额外的规划器。
