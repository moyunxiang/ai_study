集成光子张量核

Parallel convolutional processing using an integrated photonic tensor core
2020.02论文延伸Nature 2021Johannes Feldmann, Nathan Youngblood, Maxim Karpov, Helge Gehring, Xuan Li, Manuel Le Gallo, Tobias J. Kippenberg, Harish Bhaskaran, Wolfram H. P. Pernice et al. · 明斯特大学 / 牛津大学 / EPFL / IBM苏黎世等待核对
arXiv ↗Nature ↗在交互版中打开（演化树、学习进度）

问题

电子芯片做卷积受时钟频率和数据搬运限制；此前的光子神经网络用干涉仪网格做矩阵乘，难以同时处理多路数据，权重也要靠持续供电的调制器维持。

方法

在硅基光子芯片上把权重写进相变材料存储单元，用芯片上产生的光频梳提供几十个波长，让多路输入在不同颜色的光上同时通过同一组权重，一次完成多个卷积。

影响

展示了光子“存内计算”加波长并行做卷积的可行性，被引两千余次，是光计算方向被引最多的工作之一；也和光子处理器跑通ResNet/BERT等后续工作一起让光子AI芯片进入工程讨论。

方法

核心是两个部件。一是相变材料（PCM）存储单元：把一小段相变材料放在波导上，它处于晶态还是非晶态决定了光的透过率，于是权重就“存”在透过率里，不需要持续供电维持——这是光学版的存内计算。二是光频梳：一个芯片级微环谐振器产生的孤子光频梳，一次给出许多等间距的波长。不同的输入向量调制在不同波长上，同时穿过同一组PCM权重矩阵，探测器测出的光强就是乘加结果；多个波长并行，就是多个卷积同时进行。

arXiv摘要称，这是一个“光学版ASIC”式的专用集成光子张量核，运算速度达到每秒万亿次乘加（TMAC/s）量级；计算被归结为测量可重构、非谐振无源器件的光透过率，带宽超过14GHz，只受调制器和光电探测器速度的限制。作者用它做卷积处理，并认为结合微梳的混合集成、超低损耗氮化硅波导和高速片上探测器，有望实现全CMOS晶圆级集成。

局限与后续

  • 只做了推理阶段的固定权重卷积，PCM改写权重慢、精度只有几位；激光器、调制器、探测器和模数转换的外围开销没有计入，系统级能效仍待证明。

本篇术语

  • 相变材料（PCM）　可以在晶态和非晶态之间切换的材料，两种状态的光学和电学性质不同，可用来存储数据。
  • 光频梳　一束光里包含许多等间距的频率（颜色），像梳子的齿，每个齿可以单独承载一路数据。

怎么学

先读光子神经网络了解光学矩阵乘的基本原理，再读本文的器件示意图，弄清每个波长对应哪一路输入；想一想：为什么波长并行能让同一组权重同时服务多个输入。
