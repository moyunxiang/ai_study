《并行分布式处理》

Parallel Distributed Processing: Explorations in the Microstructure of Cognition
1986思想重要MIT Press 1986（两卷本）David E. Rumelhart, James L. McClelland 与 PDP研究小组（含Geoffrey Hinton、Ronald Williams、Paul Smolensky等） · 加州大学圣地亚哥分校 / 卡内基梅隆大学待核对
第2章：PDP的一般框架（Stanford PDF） ↗第1章：PDP的魅力（Stanford PDF） ↗Wikipedia: Connectionism ↗在交互版中打开（演化树、学习进度）

问题

符号AI认为智能就是按显式规则操作符号；神经网络被《Perceptrons》打入冷宫，没人知道多层网络怎么学，也没有一个统一的理论框架。

方法

提出“并行分布式处理”框架：知识不写成规则，而是分布地存放在大量简单单元之间的连接强度里，学习就是根据局部信息调整这些连接；并在书中给出了训练隐藏层的反向传播算法。

影响

成为联结主义复兴的宣言和教科书，把反向传播、玻尔兹曼机、分布式表示带给整整一代研究者；“神经网络”从此重新成为一个研究领域。

背景

1980年代初，认知科学和AI的主流是符号主义：思维被看作按规则操作符号的过程，学习就是归纳出显式的规则（见物理符号系统假说）。神经网络在《Perceptrons》与XOR问题之后基本被放弃，理由是单层网络能力有限、多层网络又没有训练方法。

几条新线索在同一时期出现：Hopfield网络用能量函数说明一群简单单元能涌现出联想记忆；玻尔兹曼机给出了带隐藏单元的随机网络的学习规则；Rumelhart、Hinton和Williams找到了用梯度训练多层网络的办法。圣地亚哥的一批心理学家、计算机科学家和神经科学家想把这些零散结果组织成一套关于认知的统一理论。

方法

核心主张。第1章指出，大脑的神经元很慢，如果认知是一步步串行执行的规则，时间根本不够；人在约束更多时反而更快，说明大量约束是并行满足的。知识不在某条规则里，而是分布在整个网络的连接权重中；网络的行为可以“看起来像在遵守规则”，但其实没有规则被显式写下。

统一框架。第2章把所有模型拆成八个组成部分：一组处理单元；激活状态；每个单元的输出函数；连接模式（权重矩阵W）；把输入汇总的传播规则（通常是加权和net_i = Σ_j w_ij·o_j）；激活规则；修改连接的学习规则；系统所处的环境。感知机、Hopfield网络、玻尔兹曼机、竞争学习等都成了这个框架的特例。

学习算法。第一卷第8章（Rumelhart、Hinton、Williams）详细推导并实验了反向传播，展示隐藏单元能学出XOR、奇偶校验、对称性检测等问题所需的内部表示；书中还收录了玻尔兹曼机、竞争学习等其他学习规则。

心理学模型。第二卷用这些网络去模拟具体的认知现象，最有名的是英语动词过去式学习模型：网络没有被告知“加-ed”的规则，却在学习过程中先过度使用规则（说出goed），再学会不规则形式，与儿童的发展过程相似。

结果

这是一部两卷本论文集：第一卷《基础》讲框架与学习算法，第二卷《心理与生物模型》讲在语言、记忆、感知上的应用。反向传播那一章位于第一卷第318–362页，后来被单独大量引用。书的影响主要体现在它让分散在各处的结果有了共同语言，并迅速成为这一领域的入门读物。

后来的发展

第二年NIPS（NeurIPS）首届会议召开，联结主义有了自己的会议。批评也随之而来：1988年联结主义的系统性之争认为联结主义网络缺乏系统性和组合性，要么不足以解释思维，要么只是符号系统的一种实现，这场争论至今在大模型时代仍在延续。技术上，书中的框架直接引出了处理时间序列的Elman循环网络、用于手写识别的卷积网络识别邮编等工作。多层网络真正大规模奏效要等到二十多年后的深度信念网络和AlexNet。

容易误解的地方

  • 反向传播并不是这本书首次提出的：Linnainmaa的反向模式自动微分和Werbos博士论文更早；这本书和同年的Nature短文让它被广泛使用。
  • PDP首先是一套认知科学理论，目标是解释人的心理现象，而不只是做一个好用的分类器。

局限与后续

  • 书中的网络都只有一两个隐藏层、几十到几百个单元，当时的数据和算力不足以训练更深更大的网络。
    后来针对它的工作　深度信念网络 AlexNet
  • 大多数模型处理的是静态输入，对语言、语音这类随时间展开的序列缺少自然的处理方式。
    后来针对它的工作　Elman循环网络 LSTM
  • 没有回答符号主义的核心质疑：分布式表示如何系统地组合出新结构（系统性、组合性）。

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    第一卷第8章给出了反向传播的完整推导和实验，是同年Nature短文的长版本。
  • 改进
    《Perceptrons》与XOR问题1969 · 基础
    用带隐藏单元的多层网络加反向传播，回应了《Perceptrons》指出的单层网络算不了XOR、奇偶性等问题。
  • 改进
    德雷福斯的哲学批判1972 · 事件
    只指出符号方法的局限，没有给出实现“直觉式会做”的具体计算机制。
  • 改进
    第一次AI寒冬1973 · 事件
    神经网络研究在经费断绝中停滞，多层网络如何训练的问题悬而未决。
  • 竞争
    物理符号系统假说1976.03 · 事件
    物理符号系统假说认为智能就是符号操作；PDP主张知识分布在连接权重里，规则只是网络行为的近似描述。
  • 延续
    Hopfield网络1982 · 基础
    把Hopfield网络的能量与约束满足观点纳入统一框架，作为并行约束满足的典型例子。
  • 使用
    Hebb学习律1949 · 基础
    书中把Hebb规则作为最简单的局部学习规则来介绍，作为更复杂学习规则的起点。
  • 改进
    《计算机与人脑》1958 · 事件
    书是未完成的推测性论述，没有给出可检验的大脑计算模型，只是提出了比较的维度。
  • 改进
    Newell与Simon获图灵奖1975 · 事件
    他们把人的思维类比符号处理，但对大脑是否真如此运作没有神经层面的证据，联结主义提出了替代方案。
  • 使用
    玻尔兹曼机1985 · 基础
    收录玻尔兹曼机作为带隐藏单元的随机网络的学习规则，与反向传播并列为两种训练隐藏单元的方法。

读懂它需要的概念

神经元与激活函数 多层感知机 反向传播 特征与表示学习 命题逻辑、谓词逻辑与符号推理

本篇术语

  • 联结主义　认为认知来自大量简单单元之间的连接与相互作用，而不是来自对符号的显式规则操作的观点。
  • 分布式表示　一个概念由许多单元的共同激活模式表示，而每个单元也参与表示许多概念；与“一个单元对应一个概念”的局部表示相对。

怎么学

先补多层感知机和反向传播。读第1章（为什么要并行分布式处理）和第2章前半部分（八个组成部分），再读第一卷第8章反向传播的XOR与对称性实验。动手：按第2章的框架用NumPy实现一个通用的“单元 + 权重矩阵 + 激活规则 + 学习规则”模拟器，分别配置成感知机和两层反向传播网络，比较它们在XOR上的表现。
