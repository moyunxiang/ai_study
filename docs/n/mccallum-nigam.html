朴素贝叶斯两种事件模型

A Comparison of Event Models for Naive Bayes Text Classification
1998.07论文延伸AAAI-98文本分类学习研讨会Andrew McCallum, Kamal Nigam · 卡内基梅隆大学、Justsystem匹兹堡研究中心待核对
PDF（AAAI） ↗在交互版中打开（演化树、学习进度）

问题

朴素贝叶斯是文本分类最常用的方法，但文献里其实混着两种不同的概率模型：一种只看词“出现与否”（多元伯努利），一种看词“出现几次”（多项式），大家常常不加区分，也不清楚哪种更好。

方法

把两种“事件模型”的生成假设、参数估计和分类公式写清楚，并在五个文本语料上、在不同词表大小下系统比较它们的分类表现。

影响

结论清晰：词表小时伯努利模型尚可，词表大时多项式模型更好，平均错误率比伯努利模型低27%。多项式朴素贝叶斯此后成为文本分类的默认朴素贝叶斯，scikit-learn等工具里的MultinomialNB与BernoulliNB就对应这两种模型。

背景

朴素贝叶斯分类假设在给定类别时各特征相互独立，用贝叶斯公式求类别后验，计算极快，在垃圾邮件过滤、新闻分类中广泛使用。文本可以表示成二值的词出现向量（一张贝叶斯网络与概率图模型，词之间无依赖），也可以表示成词频计数（相当于每个类别一个一元语言模型）。Larkey与Croft、Koller与Sahami等用前者，Lewis与Gale、Mitchell的教材用后者，概念上的差别常被忽视。

方法

多元伯努利模型：文档是词表上V个二值变量，每个词要么出现要么不出现，

P(d | c) = Π_{t=1}^{V} [ B_t · P(w_t|c) + (1 − B_t) · (1 − P(w_t|c)) ]

B_t表示词t是否出现。注意没出现的词也参与计算（贡献 1 − P(w_t|c)），而词出现多少次被忽略。

多项式模型：文档是一串从类别的词分布中独立抽取的词，

P(d | c) ∝ Π_{t=1}^{V} P(w_t|c)^{N_t}

N_t是词t在文档中出现的次数，没出现的词不贡献任何因子。参数用带拉普拉斯平滑的计数估计：P(w_t|c) = (1 + Σ_{d∈c} N_{t,d}) / (V + Σ_s Σ_{d∈c} N_{s,d})。

分类时取 argmax_c P(c) P(d|c)。作者在Yahoo科学分类、Industry Sector、20 Newsgroups、WebKB、Reuters五个语料上，用按互信息选出的不同大小词表做比较。

结果

实验显示：多元伯努利模型在小词表时表现不错，但在大词表时多项式模型通常更好，在任意词表大小下平均比伯努利模型的错误率低27%（论文摘要）。

后来的发展

这篇论文让“文本分类用多项式朴素贝叶斯”成为共识，并成为教材（如Manning等《信息检索导论》第13章）讲朴素贝叶斯的标准参照。同一作者随后用EM把多项式朴素贝叶斯扩展到半监督文本分类。之后的研究指出朴素贝叶斯在概率校准、词频突发性上的缺陷，并与SVM文本分类、NBSVM强基线等判别式方法比较；机器学习情感分类等情感分类工作也把它作为基线。

局限与后续

  • 两种模型都假设词与词条件独立，忽略词序和词共现，同一个词的重复出现也被当作独立事件（实际文本中词具有突发性）。
    后来针对它的工作　NBSVM强基线 fastText文本分类
  • 生成式模型的分类精度通常不如同期的判别式方法（如SVM），输出的后验概率也严重失准。

读懂它需要的概念

条件概率与贝叶斯公式 伯努利、二项、类别与多项分布 最大似然估计 准确率、精确率、召回率与F1 语言模型

本篇术语

  • 事件模型　朴素贝叶斯对“一篇文档是怎样生成的”的具体假设：按词是否出现，还是按词一个个抽取。
  • 拉普拉斯平滑　给每个计数加1，避免没见过的词让概率变成0。

怎么学

先学贝叶斯公式与朴素贝叶斯分类 → 读论文第2节两种模型的推导 → 动手：用scikit-learn的BernoulliNB和MultinomialNB在20 Newsgroups上，分别用1000、10000、全部词表训练，画出准确率随词表大小的变化。
