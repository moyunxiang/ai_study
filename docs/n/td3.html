TD3

Addressing Function Approximation Error in Actor-Critic Methods
2018.02论文重要ICML 2018Scott Fujimoto, Herke van Hoof, David Meger · 麦吉尔大学 / 阿姆斯特丹大学待核对
arXiv ↗作者代码 ↗Spinning Up讲解 ↗在交互版中打开（演化树、学习进度）

问题

连续控制的主力算法DDPG很不稳定：critic系统性地高估Q值，actor又专门去追这些被高估的动作，误差越滚越大，换个随机种子结果就差很多。

方法

三处小改动：训练两个critic、目标取较小者（截断双Q）；actor和目标网络比critic更新得慢（延迟更新）；算目标时给目标动作加小噪声（目标策略平滑）。

影响

在MuJoCo各任务上大幅超过DDPG，实现简单，与SAC并列成为连续控制和离线RL的标准基线，BCQ、TD3+BC等直接在它上面构建。

背景

DDPG把DQN的经验回放和目标网络搬到连续动作上：critic学Q(s,a)，actorμ(s)沿∇_a Q的方向调整动作（即确定性策略梯度DPG）。它在MuJoCo机器人模拟上能学会走路，但出了名的脆弱。

离散动作里早已知道Q学习会高估：目标r + γ max_a Q(s',a)中的max会挑中被噪声偶然抬高的动作，于是有了Double Q-learning和Double DQN。这篇论文先证明，在actor-critic里同样存在高估——actor本身就是在找“Q最大的动作”，相当于一个隐式的max。而且Double DQN那种“用在线网络选动作、目标网络估值”的解法在这里不管用：actor变化很慢，在线网络和目标网络太像，两次估计并不独立。

方法

截断双Q。同时训练两个critic Q_θ1、Q_θ2，共享一个目标：

y = r + γ · min(Q'_θ1(s', ã), Q'_θ2(s', ã))

取两者中较小的值。宁可低估也不高估——低估的动作不会被actor刻意追逐，所以误差不会积累放大。

目标策略平滑。目标动作ã = μ'(s') + ε，噪声ε取幅度被截断在一个小范围内的高斯噪声。含义是“相近的动作应该有相近的价值”，防止critic在某个尖锐的动作点上出现虚假高峰、被actor钻空子，效果类似SARSA式的期望更新。

延迟策略更新。critic每更新2次，actor和目标网络才更新1次。先让价值估计稳定下来，再用它指导策略，减少“用错误的Q去更新策略、再产生更错的Q”的循环。

其余与DDPG相同：经验回放（见on-policy与off-policy）、软更新的目标网络、探索时给动作加高斯噪声。

结果

在OpenAI Gym的7个MuJoCo任务上训练100万步、各跑10个种子，TD3在大多数任务上取得最高的平均最大回报：HalfCheetah约9637（原版DDPG约3306），Ant约4372（DDPG约1005），Walker2d约4683。对比的还有PPO、TRPO、ACKTR和早期版本的SAC。消融实验显示，单独加入某一项改动多数情况下提升有限，组合起来才明显变好，完整算法在多数任务上最好；延迟更新还让actor只训练一半次数，缩短了训练时间。

后来的发展

TD3成为连续控制的两大默认off-policy算法之一（另一个是SAC，SAC后续版本也采用了双critic取最小）。同一作者在其上做了离线RL的BCQ批量约束Q学习和TD3+BC极简离线RL；“取多个Q的最小值来压制高估”也成了离线RL和许多后续算法的标配。

容易误解的地方

  • 取最小值会带来低估偏差，论文认为低估比高估危害小，但并非没有代价。
  • TD3是确定性策略，探索完全靠人为加噪声，噪声大小需要调。

局限与后续

  • 确定性策略加固定高斯噪声的探索方式很原始，在稀疏奖励任务上几乎无能为力。

    确定性策略梯度DPG2014.06 · RL
    actor仍按确定性策略梯度∇_a Q · ∇_θ μ更新。
  • 改进
    Double DQN2015.09 · RL
    证明Double DQN的修正在actor-critic里因在线网络与目标网络过于相似而失效，并给出替代方案。
  • 延续
    Double Q-learning2010 · RL
    沿用“两个独立估计器互相纠偏”的思想，但改成取两者最小值，以适应actor-critic中两个估计不够独立的情况。
  • 改进
    DDPG2015.09 · RL
    指出DDPG的critic系统性高估且误差会被actor放大，用截断双Q、延迟更新和目标平滑三处修改解决其不稳定问题。
  • 竞争
    SAC2018.01 · RL
    同期的另一条连续控制路线：SAC用随机策略加熵正则来探索，TD3用确定性策略加噪声；两者表现接近，至今并列为标准基线。

读懂它需要的概念

Actor-Critic与优势函数 时序差分与自举 on-policy与off-policy 策略与价值函数 Bellman方程

本篇术语

  • 高估偏差　对带噪声的估计取最大值，结果平均会偏高。Q学习的目标里有max，因此会系统性地高估动作价值。
  • 目标网络　参数缓慢跟随主网络的一份拷贝，专门用来计算训练目标，避免“自己追自己”导致的不稳定。

怎么学

先读DDPG和Double Q-learning的讲解，补Actor-Critic与优势函数。读原文第4节（高估的证明与截断双Q）和第5节（方差与目标平滑）。作者的PyTorch实现只有一两百行，对照算法1逐行读，然后在Gym的HalfCheetah上分别去掉三项改动，复现消融结果。
