Project Rainier：50万Trainium2

2025.10事件延伸AWS；Anthropic待核对
Data Center Dynamics报道 ↗在交互版中打开（演化树、学习进度）

问题

Anthropic的训练需求远超单一云租用，需要一个专为它定制的大规模Trainium集群。

方法

AWS在美国印第安纳建数据中心，激活近50万颗Trainium2芯片的Project Rainier，主要供Anthropic训练和服务Claude。

影响

它是自研训练芯片首次被一家前沿实验室大规模采用的案例，证明NVIDIA之外存在可行的路线。

方法

2025年10月29日CNBC报道Amazon在印第安纳开设一座约110亿美元的AI数据中心；10月30日DCD报道AWS激活Project Rainier，规模接近50万颗Trainium2芯片（AWS称）。该集群主要用于Anthropic。

Trainium2是AWS在AWS Inferentia与Trainium之后推出的训练芯片，Rainier是把它们连成超大集群的第一次。它与云厂商自研AI芯片趋势一致：云厂商以自研芯片降低成本，而前沿实验室通过同时使用多家云与芯片（TPU、Trainium、GPU）分散供应风险。

后续Trainium3见Trainium3：首颗3nm。

局限与后续

  • Trainium的软件栈和生态不如CUDA成熟，迁移模型需要大量工程投入。
