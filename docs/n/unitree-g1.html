低价人形机器人Unitree G1

2024.05硬件延伸宇树科技（Unitree Robotics）待核对
官方页面 ↗在交互版中打开（演化树、学习进度）

问题

人形机器人整机价格动辄数十万美元以上，高校和小团队难以买到用于研究的平台。

方法

2024年5月宇树发布G1人形机器人，起售价约1.6万美元，面向科研和教育，开放二次开发。

影响

把人形机器人整机价格拉到研究者可负担的范围，成为大量人形学习论文的实机平台。

方法

根据2024年5月的媒体报道（The Robot Report、New Atlas等），宇树发布了G1，标价约1.6万美元。后来The Verge（2024年8月19日）称这款机器人需要用户自己教会它做事，说明它定位为可开发平台而非开箱即用的家用机器人。

宇树官方页面（2026年查看）写明G1的关节电机为23至43个（随配置而异），页面现标价为13.5K美元起，与发布时的1.6万美元不同。

后来的发展

价格门槛的降低使ExBody全身表现控制、HumanPlus一类人形学习研究更容易在真机上复现，也促使其他厂商推出低价人形。

局限与后续

  • 低价硬件的力矩、续航和可靠性有限，难以做重载的真实工作。
