Codex CLI

GitHub ↗在交互版中打开（演化树、学习进度）

问题

OpenAI的编码智能体此前只有网页和API形态，而开发者更习惯在自己的终端和本地代码库里工作，Claude Code与终端编码智能体已经证明了这个形态。

方法

开源的本地命令行编码智能体：在用户电脑上运行，读代码、改文件、执行命令。

影响

让OpenAI的模型进入终端智能体赛道，后来扩展到IDE插件、桌面应用和云端Codex。

方法

Codex CLI是OpenAI的编码智能体，运行在本地电脑上，用户在终端输入codex即可开始，代码在GitHub的openai/codex仓库公开。README还说明了它的几个入口：在VS Code、Cursor、Windsurf这样的编辑器里作为插件使用；有桌面应用；也有云端的Codex Web，在chatgpt.com/codex使用。安装可以通过npm或Homebrew，也有独立安装脚本。

它与Claude Code与终端编码智能体同属终端智能体：本地沙箱中读写文件、运行命令并迭代修复，用户可以逐步批准。它与o3/o4-mini工具内推理一同被登记为2025年4月的发布（具体发布日期未核对）。

后来的发展

它与云端的云端异步编码智能体、后来的Codex app多智能体指挥台一起构成OpenAI的编码产品线；终端智能体已成为各家模型公司的标配形态，类似的还有Gemini CLI。
