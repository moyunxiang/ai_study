LoRA微调扩散模型

2022.12系统延伸Simo Ryu（cloneofsimo）及Hugging Face社区 · 开源项目待核对
cloneofsimo/lora ↗Hugging Face博客 ↗在交互版中打开（演化树、学习进度）

问题

DreamBooth与个性化要微调整个模型，每个主体存几GB的检查点，社区无法方便地分享与组合。

方法

把LoRA的低秩增量应用到Stable Diffusion的注意力层，只训练并保存很小的低秩矩阵，推理时加到原权重上。

影响

文件小到几MB，可随意分享、叠加和调节强度，使LoRA成为Stable Diffusion社区共享画风和角色的主要形式。

方法

原理与语言模型里的LoRA相同：冻结原权重W0，只训练低秩矩阵的乘积ΔW，使最终权重为W = W0 + α·ΔW，α是融合系数。cloneofsimo/lora项目把它用在Stable Diffusion开源的注意力层上；其README称训练速度约为DreamBooth的2倍，产出文件只有1~6MB，可与diffusers兼容，还支持把多个LoRA相加。

Hugging Face在2023年1月26日的博客里介绍了在diffusers里用LoRA微调Stable Diffusion，使这一做法进入主流工具链。AUTOMATIC1111 WebUI等界面随后支持直接加载LoRA文件，并用<lora:name:权重>之类的语法调节强度，于是社区出现了成千上万的画风和角色LoRA。

局限与后续

  • LoRA本身只调节注意力层，对很复杂的主体或风格的表达力不如全量微调。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 多个LoRA叠加会互相干扰，缺少原则性的组合方法。
