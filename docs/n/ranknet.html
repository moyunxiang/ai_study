RankNet排序学习

Learning to Rank using Gradient Descent
2005.08论文延伸ICML 2005Chris Burges, Tal Shaked, Erin Renshaw, Ari Lazier, Matt Deeds, Nicole Hamilton, Greg Hullender · Microsoft Research待核对
Microsoft Research ↗在交互版中打开（演化树、学习进度）

问题

搜索排序要综合几十上百个特征，手调权重难以为继；以往的机器学习方法把它当分类或回归，目标和“排对顺序”并不一致。

方法

在成对的文档上训练：让神经网络给两个文档打分，用两者分数差的sigmoid表示“A应排在B前面”的概率，以交叉熵为损失，用梯度下降学习。

影响

开启了现代“学习排序”（learning to rank）路线，是后来LambdaRank和LambdaMART的出发点，也是DSSM深度语义匹配的训练目标来源之一。

方法

对同一个查询，取一对文档A和B，其中人工判断A更相关。模型是一个神经网络，输入文档的特征向量，输出一个实数分数。令P(A排在B前) = sigmoid(s_A − s_B)，真实标签是1，损失就是这个概率的交叉熵（见交叉熵）。因为损失只依赖分数之差，网络对所有文档共享同一个打分函数，训练用反向传播加梯度下降。

这样不必给每个文档标一个绝对的相关度分数，只需要“谁比谁更相关”的成对比较，标注更容易，也直接对应排序目标。推断时对每个文档单独打分，再按分数排序。

局限与后续

  • 成对损失平等对待所有文档对，但用户只关心排在最前面的几条；损失与NDCG等排序评测指标不一致。

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    用反向传播训练打分网络，损失由成对概率导出。
  • 改进
    BM251994 · NLP
    BM25这样的检索分数可以作为特征之一，RankNet学习如何组合多个这样的特征。
  • 改进
    Ranking SVM点击学排序2002.07 · NLP
    成对约束的数量随候选数平方增长，大规模训练开销高。

后来的相关工作

  • 改进
    LambdaRank与LambdaMART2010.06 · NLP
    RankNet优化的成对错误数与NDCG不一致、对头部错误不敏感，lambda梯度按名次重要性加权解决了这一点。
  • 竞争
    点击数据的位置偏差2005.08 · NLP
    同年的RankNet用人工标注的相关性等级训练排序；这里研究如何用廉价但有偏的点击代替人工标注。
  • 延续
    ListNet列表式排序2007.06 · NLP
    同样用神经网络打分、梯度下降训练，但把成对的交叉熵损失推广为整个列表上的交叉熵。
  • 延续
    DSSM深度语义匹配2013.10 · NLP
    沿用成对/列表式的排序训练思想，用点击数据训练深度表示。
  • 使用
    RankGPT大模型重排序2023.04 · 推理·智能体
    蒸馏学生时用的成对排序损失。

读懂它需要的概念

交叉熵 反向传播 监督学习 随机梯度下降与小批量

本篇术语

  • 学习排序　用机器学习训练一个打分函数，使一个查询下的文档能按相关度正确排序。

怎么学

先会logistic回归和交叉熵；推导为什么成对损失只依赖分数差；用PyTorch在合成数据上实现RankNet。
