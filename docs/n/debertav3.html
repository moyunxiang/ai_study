DeBERTaV3

DeBERTaV3: Improving DeBERTa using ELECTRA-Style Pre-Training with Gradient-Disentangled Embedding Sharing
2021.11论文延伸ICLR 2023Pengcheng He, Jianfeng Gao, Weizhu Chen · 微软待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

ELECTRA的替换词检测比掩码语言模型更省样本，但它的生成器和判别器共享词嵌入时，两者的损失把嵌入往相反方向拉（“拔河”），拖慢训练、损害效果。

方法

在DeBERTa上改用替换词检测预训练，并提出梯度解耦嵌入共享：判别器复用生成器的嵌入，但判别器的梯度只更新一个额外的残差嵌入，不回传到共享部分。

影响

成为BERT类编码器在自然语言理解任务上长期最强的开源基线之一，直到ModernBERT等新一代编码器出现前，分类、抽取类比赛和工业系统常用它。

方法

ELECTRA替换词检测的做法是：一个小生成器先把句子里被遮住的词填成看起来合理的词，再让判别器判断每个位置的词是原词还是被替换过的。ELECTRA让生成器和判别器共享词嵌入，作者分析发现，生成器希望语义相近的词嵌入靠近（便于猜词），判别器却需要把它们区分开（便于识别替换），两个梯度互相拉扯。

梯度解耦嵌入共享（GDES）：判别器的嵌入等于生成器嵌入加一个残差项 E_D = sg(E_G) + E_Δ，sg表示停止梯度。生成器照常更新 E_G，判别器的梯度只更新 E_Δ。这样既保留共享带来的样本效率，又消除拔河。模型主体仍用DeBERTa解耦注意力的解耦注意力。

结果：在与DeBERTa相同的预训练设置下，DeBERTaV3 Large在GLUE八个任务上平均91.37%，比DeBERTa高1.37个点、比ELECTRA高1.91个点；多语言版mDeBERTa Base在XNLI零样本跨语言上达到79.8%，比XLM-R Base高3.6个点。
