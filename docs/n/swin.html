Swin Transformer

Swin Transformer: Hierarchical Vision Transformer using Shifted Windows
2021.03论文延伸ICCV 2021Ze Liu, Yutong Lin, Yue Cao, Han Hu, Yixuan Wei, Zheng Zhang, Stephen Lin, Baining Guo · Microsoft Research Asia来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Vision Transformer的全局注意力成本随图像面积平方增长，且只有单一尺度，难以直接用于高分辨率的检测和分割。

方法

把注意力限制在不重叠的局部窗口内，并在相邻层把窗口错开移位以便跨窗口交流，同时分层降低分辨率。

影响

在COCO检测和ADE20K分割上大幅超过此前最好的结果（box AP +2.7、mIoU +3.2），显示视觉Transformer可以作为检测、分割的通用骨干。

方法

Swin先把图切成4×4像素的小块（比ViT的16×16细得多），结构分四个阶段，每个阶段开头把相邻2×2个块的特征拼起来合并成一个，分辨率减半、通道翻倍，形成像卷积网络那样的层级特征图。每个阶段里自注意力只在7×7个块的不重叠窗口内计算：全局注意力的计算量随块数平方增长，窗口注意力则随图像面积线性增长。窗口之间如何交流？相邻两层交替使用规则窗口和整体平移⌊M/2⌋个块（M为窗口边长）后的窗口，这样上一层相邻窗口的内容会落到同一个新窗口里。实现上用“循环移位+掩码”保持窗口数量不变，比朴素的滑动窗口快约4倍。注意力里还加了相对位置偏置。训练沿用DeiT的大部分增强和正则化。

论文报告：ImageNet-1K top-1 87.3%（Swin-L，先在ImageNet-22K预训练、384分辨率）；只用ImageNet-1K训练的Swin-T为81.3%，DeiT-S为79.8%；COCO test-dev 58.7 box AP、51.1 mask AP（Swin-L配HTC++）；ADE20K 53.5 mIoU（Swin-L配UperNet）。

后来的发展

ConvNeXt为检验是否真是注意力带来的优势，把ResNet按Swin的设计现代化；ViTDet朴素ViT检测则表明朴素ViT加简单改动也够用。

局限与后续

  • 移位窗口的实现需要循环移位与掩码，较复杂，且窗口大小固定限制了全局建模。
    后来针对它的工作　ViTDet朴素ViT检测
  • 层级设计依赖大量卷积式先验，是否纯属Transformer的优势存疑。
    后来针对它的工作　ConvNeXt

它建立在什么之上

  • 延续
    Vision Transformer2020.10 · 视觉 已核对
    把全局注意力改为窗口注意力，并加入层级结构，使计算量线性于图像大小；论文把ViT单一分辨率、计算量平方增长列为不适合做稠密任务骨干的原因。
  • 使用
    DeiT2020.12 · 视觉 已核对
    ImageNet-1K训练设置主要沿用DeiT，包含其大部分增强和正则化策略（去掉了重复增强和EMA），并以DeiT为主要对比。
  • 改进
    Non-local网络2017.11 · 视觉
    对所有位置两两计算，复杂度随位置数的平方增长，高分辨率特征图上开销很大。
  • 改进
    PVT金字塔ViT2021.02 · 视觉
    空间缩减注意力仍是全局的，计算量随分辨率增长较快，高分辨率输入下开销大。

后来的相关工作

  • 竞争
    ConvNeXt2022.01 · 视觉 已核对
    用纯卷积复现Swin的精度，说明性能差距主要来自设计和训练配方而非注意力。
  • 改进
    ViTDet朴素ViT检测2022.03 · 视觉 已核对
    移位窗口的实现需要循环移位与掩码，较复杂，且窗口大小固定限制了全局建模。
  • 使用
    Mask2Former通用分割2021.12 · 视觉
    最好的结果使用Swin-L骨干。
  • 使用
    Florence2021.11 · 多模态
    采用Swin类层级Transformer作视觉骨干。
  • 使用
    Donut无OCR文档理解2021.11 · 多模态
