对偶学习翻译

Dual Learning for Machine Translation
2016.11论文延伸NeurIPS 2016Yingce Xia, Di He, Tao Qin, Liwei Wang, Nenghai Yu, Tie-Yan Liu, Wei-Ying Ma · 中国科学技术大学、北京大学、微软亚洲研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经机器翻译要几千万个双语句对才能训好，人工标注平行语料极其昂贵；已有的单语数据用法（训练语言模型融合进解码、回译生成伪数据）都只是间接利用单语语料。

方法

利用「每个翻译任务都有一个对偶任务」：英译法和法译英构成一个闭环。把两个翻译模型看作两个智能体做通信游戏：一个把单语句子译过去，另一个再译回来；用译文在目标语言模型下的似然和回译重建原句的概率作为奖励，用策略梯度同时更新两个模型。

影响

在英法互译上，只用10%的双语数据做热启动、其余靠单语数据，法译英就达到了用全部双语数据训练的NMT的水平；对偶学习随后被推广到图像生成、问答生成等成对任务，并与迭代回译一起成为无监督与半监督翻译的重要思路。

方法

设定。有两种语言A、B的大量单语语料，少量双语语料，两个翻译模型P(·|s; Θ_AB)和P(·|s; Θ_BA)（都是带注意力的编码器-解码器，用少量双语数据热启动），以及两个用单语语料训练好的语言模型LM_A、LM_B。

一局游戏（从A语言的句子s开始）：模型AB用集束搜索生成K个中间译文s_mid,k；对每个译文计算两种奖励：语言模型奖励r₁ = LM_B(s_mid)，衡量译文像不像自然的B语言；通信（重建）奖励r₂ = log P(s | s_mid; Θ_BA)，衡量能否从译文还原出原句。总奖励r = α·r₁ + (1−α)·r₂。按策略梯度定理，∇_Θ_AB E[r] = E[r·∇_Θ_AB log P(s_mid | s; Θ_AB)]，∇_Θ_BA E[r] = E[(1−α)·∇_Θ_BA log P(s | s_mid; Θ_BA)]，期望用K个集束结果的平均来估计。然后从B语言的句子开始再玩一局，两个方向轮流进行。由于奖励不需要人工标注，单语数据就能产生训练信号。

和回译的区别。回译把反向模型生成的伪平行数据固定下来当监督数据，反向模型本身不更新；对偶学习让两个方向在同一个闭环里互相提供反馈、同时改进。

结果。在英法互译上，dual-NMT明显优于只用双语数据的基线和用伪双语数据的方法；仅用10%双语数据热启动时，法译英达到了全量双语数据训练的NMT的精度。

局限与后续

  • 仍然需要一定量的双语数据做热启动，从完全随机的模型出发，奖励信号太弱，游戏无法启动。
    后来针对它的工作　无监督神经机器翻译 无监督NMT（Artetxe）
  • 策略梯度的方差大，每个句子都要集束搜索并前向计算两个模型和语言模型，训练代价很高。

读懂它需要的概念

编码器-解码器 策略梯度 语言模型 奖励、回报与折扣 半监督学习与伪标签 自编码器

本篇术语

  • 对偶任务　输入输出互换的一对任务，例如英译法与法译英；两者合起来可以形成「做一遍再还原」的闭环。
  • 热启动　先用少量带标注的数据把模型训到一个可用的起点，再用其他方法继续训练。

怎么学

先读回译的讲解和策略梯度 → 读原文第3节对偶学习算法（算法1与公式6、7） → 动手：用两个小的双向翻译模型在少量平行数据上热启动，再用单语句子按「译过去再译回来」的重建概率做几轮策略梯度更新，观察BLEU变化。
