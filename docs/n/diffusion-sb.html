扩散薛定谔桥DSB

Diffusion Schrödinger Bridge with Applications to Score-Based Generative Modeling
2021.06论文延伸NeurIPS 2021Valentin De Bortoli, James Thornton, Jeremy Heng, Arnaud Doucet · 牛津大学 / ESSEC待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Score SDE统一框架式扩散模型要求前向加噪跑得足够久，终点才近似标准高斯；时间短了，生成的起点分布就对不上，而且只能在“数据↔高斯”之间搭桥。

方法

把生成建模写成薛定谔桥问题：在路径空间上找一个熵正则的最优传输，使扩散过程在有限时间内恰好把数据分布送到先验分布；用分数模型近似迭代比例拟合（IPF），交替训练前向和反向过程。

影响

把扩散模型和最优传输、薛定谔桥理论接起来，开启了“任意两个分布之间搭桥”的一系列工作（如I²SB、扩散桥图像翻译），也是理解流匹配与整流流的理论背景之一。

方法

薛定谔桥问题问的是：给定起点分布（数据）和终点分布（先验），在所有连接它们的随机过程中，找一个最接近某个参考扩散（如布朗运动）的过程，接近程度用路径上的KL散度衡量。它等价于路径空间上的熵正则最优传输与Wasserstein距离，经典解法是迭代比例拟合（IPF）：轮流固定一端，只调整过程使另一端的边缘分布对上。

扩散薛定谔桥（DSB）把IPF的每一步都变成一次分数模型训练：

  • 第1轮：从数据出发跑前向SDE，训练网络学习反向过程的漂移，这恰好就是Score SDE统一框架的做法，只是允许较短的时间区间。
  • 第2轮：从先验出发用刚学到的反向过程采样，再训练一个新的前向过程，使其终点更贴近先验。
  • 如此交替，每轮都缩小前向终点与先验、反向终点与数据之间的偏差。

论文给出了收敛性分析，并在二维玩具分布、MNIST、CelebA上做了生成实验；它还指出DSB可以看作Sinkhorn算法在连续状态空间上的对应物，可当作通用的计算最优传输工具。

局限与后续

  • 需要多轮交替训练前向和反向网络，每轮都要模拟整条轨迹，训练成本远高于普通扩散模型，在大规模图像上难以使用。

读懂它需要的概念

常微分方程与随机微分方程 分数函数与分数匹配 最优传输与Wasserstein距离 KL散度 扩散：前向加噪与反向去噪

本篇术语

  • 薛定谔桥　在给定起点和终点分布的所有随机过程中，与参考扩散最接近的那一个；可看作带熵正则的最优传输。
  • 迭代比例拟合IPF　轮流修正联合分布使其分别满足两个边缘约束的经典算法，离散情形就是Sinkhorn算法。

怎么学

先读Score SDE和熵正则最优传输（Sinkhorn） → 读本文第3节IPF与DSB的对应 → 在二维两月形分布与高斯之间实现一次DSB。
