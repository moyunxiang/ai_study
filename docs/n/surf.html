SURF

SURF: Speeded Up Robust Features
2006.05论文延伸ECCV 2006Herbert Bay, Tinne Tuytelaars, Luc Van Gool · ETH Zurich / KU Leuven待核对
Crossref (CVIU版) ↗在交互版中打开（演化树、学习进度）

问题

SIFT特征效果好，但计算慢，用在实时和大规模场景里吃不消。

方法

用积分图像和方框滤波近似二阶高斯导数来找特征点，描述子用小波响应并缩短到64维，在保持相近鲁棒性的前提下大幅加速。

影响

成为SIFT最主要的快速替代品，之后的ORB特征等又把代价进一步降低。

方法

关键是把Hessian矩阵行列式作为特征点的响应，但不对图像做高斯滤波再求导，而是用方框滤波近似，借助积分图像使任何尺寸的方框滤波花费都一样，所以多尺度检测时不用缩小图像，只需放大滤波器。描述子基于特征点周围区域内Haar小波的响应，按4×4个子区域统计，得到64维向量，比SIFT的128维更短、匹配更快。

它沿用了SIFT的流程（尺度空间检测、方向分配、描述子），用的是同样的设计思想，换成了更便宜的计算。

局限与后续

  • 描述子仍是浮点向量，存储和匹配开销比二进制描述子大。
    后来针对它的工作　ORB特征
  • 有专利限制，使得它在开源项目里使用受限。
    后来针对它的工作　ORB特征
