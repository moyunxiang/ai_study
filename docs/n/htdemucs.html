HT Demucs音乐分离

Hybrid Transformers for Music Source Separation
2022.11论文延伸ICASSP 2023Simon Rouard, Francisco Massa, Alexandre Défossez · Meta AI待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

音乐分离（把一首歌拆成人声、鼓、贝斯、其他）的卷积网络只看局部声学特征，不清楚整首歌的长程上下文是否有用。

方法

在时域与频域双分支的Hybrid Demucs U-Net最内层，换上一个跨域Transformer：每个域内部做自注意力，两个域之间做交叉注意力。

影响

HT Demucs（Demucs v4）在加额外训练数据时刷新了MUSDB的分离纪录，开源后成为音乐人声伴奏分离最常用的工具之一，也是许多音乐数据处理流程（如为歌曲生成准备分轨）的标准环节。

方法

Demucs音乐分离直接在波形上用U-Net式（见U-Net）卷积编码器-解码器分离音乐，后续的Hybrid Demucs又并联了一条在频谱上工作的分支，两条分支在最深处汇合，被称为双U-Net。卷积的感受野有限，一个问题自然出现：分离时是否需要整首歌范围的上下文，比如副歌重复出现的旋律？

HT Demucs（Hybrid Transformer Demucs）保留两条分支的外层卷积，把最内层替换成跨域Transformer编码器：时域分支和频域分支的特征序列各自做自注意力（见自注意力与多头注意力），并在两个域之间做交叉注意力，交换信息后再各自解码，最终把两条分支的输出相加得到每个音源的波形。为了看更长的片段，作者还用稀疏注意力核扩大感受野，并对每个音源单独微调。

摘要报告：只用MUSDB训练时它表现不佳（Transformer需要更多数据）；加入800首额外训练歌曲后，比同样数据训练的Hybrid Demucs提高0.45 dB SDR；配合稀疏注意力和逐音源微调，在MUSDB上达到当时最好的9.20 dB SDR。

局限与后续

  • Transformer需要大量额外的分轨训练数据，只用公开的MUSDB时反而不如纯卷积模型，而带分轨的商业音乐数据很难获得。

  • SDR（信号失真比）　衡量分离出的音源与真实音源有多接近的指标，单位dB，越高越好。
