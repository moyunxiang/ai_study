TiTok一维分词器

An Image is Worth 32 Tokens for Reconstruction and Generation
2024.06论文延伸NeurIPS 2024Qihang Yu, Mark Weber, Xueqing Deng, Xiaohui Shen, Daniel Cremers, Liang-Chieh Chen · ByteDance / TUM待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统图像分词器把图切成二维网格，相邻区域冗余大，需要几百到上千个token。

方法

用Transformer把图像压成一维的token序列，不再受二维网格约束。

影响

256x256图像可压到仅32个离散token，生成更快。

方法

类似VQGAN的方法把图像切成固定下采样率的二维网格，每格一个token，一幅256x256x3的图要256或1024个token。TiTok（Transformer-based 1-Dimensional Tokenizer）用Vision Transformer式的编码器与解码器，把图像压进一个一维的潜序列，序列长度可以自由选择，一幅256x256x3的图最少只要32个离散token。

论文称，在同样的生成框架下，TiTok在ImageNet上的gFID为1.97，优于MaskGIT基线；因为token少，生成速度远快于二维网格的方法。

后来的发展

一维分词思路被后续的高压缩视觉分词器采用，并与自回归和掩码生成结合。

局限与后续

  • 极度压缩下丢细节，重建质量取决于编码器容量。

它建立在什么之上

  • 使用
    Vision Transformer2020.10 · 视觉
    用ViT式Transformer做编码与解码。
  • 改进
    VQGAN2020.12 · 生成
    解决二维网格分词冗余、token数过多的问题。
  • 改进
    SEED视觉分词器2023.07 · 多模态
    词表较小的离散词元重建质量有限，生成图像细节不如扩散模型。
  • 改进
    有限标量量化FSQ2023.09 · 生成
    只是量化方式的替换，并不改善分词器的压缩效率本身。
  • 改进
    MAGVIT-v2与LFQ分词器2023.10 · 生成
    离散化仍会损失细节，重建质量受分词器上限约束。
  • 改进
    VideoPoet2023.12 · 生成
    离散分词会损失画面细节，质量受分词器限制。
  • 改进
    LlamaGen2024.06 · 生成
    离散分词器限制了画质上限。
