MDETR

MDETR -- Modulated Detection for End-to-End Multi-Modal Understanding
2021.04论文延伸ICCV 2021Kamath, Singh, LeCun, Synnaeve, Misra, Carion · NYU / FAIR待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多模态系统把预训练检测器当黑箱，词表固定，学不到自由文本里长尾的视觉概念，检测与下游任务也是分开训练的。

方法

以DETR为基础，把文本和图像特征在早期融合，让检测器直接根据一句话输出对应的物体框，并让框与文字短语对齐。

影响

首个端到端的文字条件检测器，直接影响后来的GLIP、Grounding DINO。

方法

MDETR在DETR的结构上做改造：用文字编码器（RoBERTa）和卷积网络分别提取文本与图像特征，拼在一起送入Transformer编码器，使两种信息从一开始就充分交互，解码器的物体查询再预测框，并预测每个框对应文字里的哪些词。训练使用两项损失：软标记预测（框与短语的对齐）和文本-查询的对比对齐。

预训练数据是从现有的、带短语-物体对齐标注的多模态数据集里挖出的130万对图文。摘要称在此之后微调到多个任务，包括短语定位、指代表达理解和视觉问答，并在这些任务上取得有竞争力的成绩，还能在少量样本下识别长尾类别。

局限与后续

  • 预训练依赖有框标注的少量数据，未用上海量网络图文。
    后来针对它的工作　GLIP
  • Transformer检测器训练收敛慢，对大图计算开销大。
    后来针对它的工作　Grounding DINO

它建立在什么之上

  • 使用
    RoBERTa2019.07 · LLM
    用RoBERTa作文字编码器。
  • 延续
    DETR2020.05 · 视觉
    在DETR上加入文本输入，使检测变成文字条件。
  • 改进
    指代表达理解2015.11 · 多模态
    每个区域独立评分，无法与语言做深度交互。
  • 改进
    MAttNet2018.01 · 多模态
    依赖预先提取的候选区域，检测漏掉的物体无法恢复。

后来的相关工作

  • 延续
    Grounding DINO2023.03 · 多模态
    MDETR最早用文字调制DETR做端到端定位；Grounding DINO把这一思路做到更强的检测器和更大规模的数据上。
  • 延续
    GLIP2021.12 · 多模态
    沿用文字条件检测的思路，扩大到2700万条数据并统一检测与定位。
