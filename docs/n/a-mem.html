A-MEM卡片盒记忆

A-MEM: Agentic Memory for LLM Agents
2025.02论文延伸NeurIPS 2025Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang · 罗格斯大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

智能体的长期记忆系统大多只是「存进去、按相似度取出来」，记忆之间没有组织，结构和操作也是写死的，难以适应不同任务。

方法

仿照卡片盒笔记法：每条新记忆由LLM写成带关键词、标签和上下文描述的笔记，自动与相关旧笔记建立链接，并可以反过来更新旧笔记的描述，让记忆网络不断演化。

影响

在长对话记忆基准LoCoMo上，多类问题明显好于MemGPT、MemoryBank等基线，每次提问只用约1200个词元，比把全部历史塞进上下文少85%以上；成为智能体记忆研究中常用的对照方法。

方法

写入：每当有新的交互，LLM为它生成一张笔记：原始内容、时间戳、关键词、标签、一句上下文描述，以及由这些拼起来算出的向量。

建链接：用向量找出最相近的10条旧笔记作初筛，再交给LLM判断哪些真正相关、要不要连起来——向量负责快，LLM负责判断「为什么相关」。

记忆演化：对每条相近的旧笔记，LLM结合新笔记决定是否改写它的上下文描述和标签。例如先记了「用户在学钢琴」，后来又记「用户报名了音乐学院」，旧笔记的描述会被更新以反映这层关系。

检索：提问时用同样的编码器找出最相近的若干条笔记放进提示。

结果：在LoCoMo（7512个问答，长对话平均约9千词元）上，用GPT-4o-mini时时间类问题F1为45.85、对照的全上下文方法为18.41；在Qwen2.5-1.5B这样的小模型上多跳问题F1大约翻倍。但在对抗类问题上低于全上下文方法。消融显示链接和演化两个模块都有贡献。

局限与后续

  • 每写入一条记忆都要多次调用LLM来生成属性、判断链接和改写旧笔记，写入成本高，记忆质量也依赖所用LLM的能力。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 改写旧笔记会丢失原来的表述，记忆出错后很难追溯和纠正。
    本站还没有记录针对它的后续工作（不代表没有人解决）
