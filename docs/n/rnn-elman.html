Elman循环网络

Finding Structure in Time
1990论文重要Cognitive Science 1990Jeffrey L. Elman · 加州大学圣地亚哥分校待核对
Cognitive Science（DOI） ↗Wikipedia: Recurrent neural network（Elman网络一节） ↗在交互版中打开（演化树、学习进度）

问题

前馈网络只能吃固定长度的输入，处理序列时只好把时间摊成空间：开一个固定宽度的窗口，窗口外的历史全部丢失，同一个模式挪一个位置就认不出来。

方法

给网络加一组“上下文单元”，每一步把隐藏层的激活原样复制过去，下一步再和新输入一起送回隐藏层；用普通反向传播训练网络预测下一个输入，让记忆在隐状态里自己形成。

影响

定义了最简单的循环神经网络（简单循环网络，SRN），并证明只靠“预测下一个”就能学出词类等语言结构；后来的RNN语言模型和LSTM都沿着这个结构展开。

背景

反向传播让多层网络能学了，但输入必须是固定长度的向量。语言、语音都是随时间展开的，当时的通行做法是把时间“空间化”：取最近若干个时刻的输入拼成一个大向量（时延神经网络TDNN就是一种滑动窗口）。问题是：窗口长度必须事先定死；同一个模式出现在窗口的不同位置，对网络来说是完全不同的输入。

1986年Jordan提出把网络的输出反馈回来作为下一时刻的输入。Elman的问题是：能不能让时间只通过它对处理过程的影响隐式地表示出来，而不是摊在空间上？

方法

结构。输入层、隐藏层、输出层之外，再加一组和隐藏层同样大小的上下文单元。每一步结束时，隐藏层的激活以固定权重1.0复制到上下文单元；下一步，隐藏层同时接收新输入和上下文单元。写成公式（见循环网络与隐状态）：

h_t = σ(W·x_t + U·h_(t−1) + b) y_t = σ(V·h_t + c)

复制连接不训练，可训练的是W、U、V。于是h_t在原则上依赖全部历史。

训练。把上下文单元当作额外的输入，用标准反向传播训练，误差只往回传一步，不展开到更早的时刻。

任务：预测下一个。不需要人工标注，序列本身就是答案。例如“时间XOR”：比特串每三个一组，第三位是前两位的异或。网络只有在第三位才可能预测对，前两位是随机的——训练后网络的预测误差恰好在这些可预测的位置上降下来，说明它学会了利用前文。

词序实验。用一个小词表生成简单句子，把每个词编码成互不相关的独热向量（见独热编码与词表），连成长串让网络逐词预测下一个词。训练后对每个词的隐藏层平均激活做层次聚类，看网络把哪些词当成同类。

结果

论文报告的模拟从简单的时间XOR一直做到为词发现句法和语义特征。词序实验的聚类树显示，网络从未被告知任何语法，却按词的句法、语义类别把它们分了组（最常被引用的是名词与动词自然分开），这些类别完全来自词在序列中出现的位置和搭配。同一个词在不同上下文中的隐状态略有不同，论文借此讨论了type/token的区分。

后来的发展

Elman网络成了“简单循环网络”的代名词，也是今天所有RNN教科书里的第一个模型。同年的随时间反向传播BPTT给出了沿时间完整展开求梯度的方法，取代了只回传一步的训练。但很快梯度消失问题指出，用梯度下降学长距离依赖本身就很难，这直接引出了LSTM。二十年后RNN语言模型把同样的结构用到真实语料的语言模型上，再到word2vec，“从上下文学词的表示”在大规模数据上兑现。

容易误解的地方

  • Elman网络与Jordan网络的区别：Elman把隐藏层反馈回来，Jordan把输出层反馈回来。
  • 论文里的训练只回传一步，并不是现在通用的BPTT；现代框架训练“Elman式RNN”时用的是完整或截断的BPTT。
  • 词类聚类是对隐藏层表示做的事后分析，网络本身没有输出任何“类别”。

局限与后续

  • 误差只回传一步，网络很难学到相隔多步的依赖。
    后来针对它的工作　随时间反向传播BPTT
  • 即使沿时间完整求梯度，梯度也会随步数指数衰减或爆炸，长距离依赖依然学不会。
    后来针对它的工作　LSTM 梯度裁剪
  • 只在几十个词的人造小语法上验证，离真实语料的语言建模还很远。
    后来针对它的工作　RNN语言模型
  • 每一步都要等上一步算完，序列内部无法并行，长序列训练很慢。
    后来针对它的工作　Transformer

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    把上下文单元当作额外输入，直接用标准反向传播训练循环网络。
  • 延续
    Harris分布假说1954 · NLP
    网络只从词的上下文搭配就学出了名词、动词等类别，是分布假说的一个神经网络实证。
  • 竞争
    Hopfield网络1982 · 基础
    两者都有循环连接，但Hopfield网络的目标是收敛到固定的记忆，Elman网络的目标是随输入不断变化、记住刚发生过的事。
  • 改进
    《并行分布式处理》1986 · 基础
    PDP框架下的网络大多处理静态输入，Elman把它扩展到随时间展开的序列和语言。
  • 竞争
    时延神经网络TDNN1989.03 · 语音
    时延网络用固定宽度的时间窗口把时间摊成空间；Elman网络用循环隐状态隐式表示任意长的历史，后者成为序列建模的主流。
  • 改进
    Jordan循环网络1986.05 · 基础
    反馈的只是上一时刻的输出，记忆内容受限于输出的形式，也难以保存很久以前的信息。

后来的相关工作

  • 改进
    LSTM1997 · 基础 已核对
    论文实验中Elman网络在嵌入式Reber文法上成功率为0，LSTM几乎每次成功，长间隔任务上差距更大。
  • 改进
    Transformer2017.06 · LLM
    每一步都要等上一步算完，序列内部无法并行，长序列训练很慢。
  • 延续
    梯度消失问题1994 · 基础
    解释了Elman式循环网络为什么学不会长距离依赖：问题不在网络结构的表达力，而在梯度下降训练本身。
  • 竞争
    LSTM遗忘门1999.09 · 基础
    在原版嵌入式Reber文法上，Elman网络在超过20万次序列呈现后仍学不会，而LSTM全部学会；连续版本里此类网络未被纳入比较。
  • 使用
    RNN语言模型2010.09 · NLP
    网络就是Elman的简单循环网络：上一步隐层拷贝回来与当前输入拼接。
  • 改进
    梯度裁剪2012.11 · 基础
    让普通tanh循环网络的训练稳定下来，不必换成更复杂的结构或二阶优化。
  • 竞争
    神经常微分方程2018.06 · 基础
    处理不规则采样的时间序列时，RNN要把时间离散成格子，潜变量ODE可在任意时刻求值，在螺旋数据上外推更好。
  • 改进
    随时间反向传播BPTT1990 · 基础
    误差只回传一步，网络很难学到相隔多步的依赖。
  • 延续
    快速权重1992 · 基础
    在循环网络的隐状态之外增加可快速改写的权重矩阵作为额外的记忆。
  • 延续
    双向RNN1997 · 基础
    在单向循环网络之外再加一条反向的循环链，使每个位置同时获得左右上下文。
  • 延续
    图神经网络GNN2009.01 · 基础
    RNN沿时间链复用同一个状态更新函数；GNN把链换成任意图结构，对邻居聚合后更新状态。
  • 延续
    课程学习2009.06 · 基础
    Elman在1993年的“从小处开始”实验已经发现，循环网络先学简单句子再学复杂句子更容易成功；课程学习把这个观察推广成一般的训练策略并给出持续法的解释。
  • 竞争
    LSSL线性状态空间层2021.10 · 基础
    同样是带状态的递推模型，但LSSL的线性结构可展开成卷积并行训练。
  • 延续
    线性循环单元LRU2023.03 · 基础
    以普通循环网络为起点，通过去掉非线性和重新参数化让它重新可用于长序列。

读懂它需要的概念

循环网络与隐状态 反向传播 多层感知机 独热编码与词表 语言模型

本篇术语

  • 上下文单元　保存上一时刻隐藏层激活副本的单元，下一时刻作为额外输入送回隐藏层，相当于网络的短期记忆。
  • 简单循环网络（SRN）　Elman网络和Jordan网络的统称：只有一个隐藏层，通过固定的复制连接引入循环。
  • 层次聚类　把最相似的两个点（或簇）反复合并，得到一棵树状图，用来观察网络把哪些词归为一类。

怎么学

先补循环网络与隐状态和语言模型。读原文的引言、时间XOR和词序预测两节，配合Wikipedia的公式。动手：用PyTorch写一个隐藏层几十维的Elman网络，在自己生成的“名词 动词 名词”小句子上训练预测下一个词，然后对隐藏层做PCA或层次聚类，看名词和动词能否自动分开。
