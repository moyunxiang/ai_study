FireAct智能体微调

FireAct: Toward Language Agent Fine-tuning
2023.10论文延伸Baian Chen, Chang Shu, Ehsan Shareghi, Nigel Collier, Karthik Narasimhan, Shunyu Yao · System2 Research / 剑桥大学 / 莫纳什大学 / 普林斯顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

当时的语言智能体几乎都靠给现成大模型写少样本提示来驱动，提示又长又脆弱，小模型更是基本用不起来；“直接微调模型来当智能体”这条路很少有人系统研究。

方法

在“调用谷歌搜索回答问题”的设定下，用GPT-4生成的智能体轨迹去微调较小的模型，并把多种任务、多种提示方法产生的轨迹混在一起训练。

影响

用系统实验说明微调能稳定提升语言智能体，例如500条GPT-4轨迹就让Llama2-7B在HotpotQA上提升77%，是“智能体微调”路线的早期代表。

方法

作者是ReAct的原班人马之一。实验设定是多跳问答：智能体可以调用谷歌搜索API，按“思考—搜索—观察—再思考—作答”的格式工作。他们比较了不同的底座模型、不同的提示方法（ReAct、思维链CoT、Reflexion等）、不同的微调数据和问答任务（以HotpotQA多跳问答为主）。

核心发现是：微调底座模型后，智能体表现一致提升。例如，只用GPT-4生成的500条智能体轨迹微调Llama 2-7B，HotpotQA上的表现提升77%。

在此基础上提出FireAct：不只用一种任务、一种提示方法的轨迹，而是把来自多个任务、多种提示方法的轨迹混合起来做微调。这样训练出的模型能根据问题难度灵活选择“直接答”“一步步想”还是“搜索多次”，数据越多样，智能体越好。论文还讨论了规模效应、对噪声搜索结果的鲁棒性、泛化到新任务、推理效率与成本等，作为后续智能体微调研究的实验设计参照。
