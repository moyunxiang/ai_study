反向模式自动微分

The Representation of the Cumulative Rounding Error of an Algorithm as a Taylor Expansion of the Local Rounding Errors
1970论文重要赫尔辛基大学硕士论文（芬兰语）1970；英文期刊版 BIT 1976Seppo Linnainmaa · 赫尔辛基大学待核对

问题

前向自动微分每次只能求出对一个输入的导数；一个函数有n个输入，要得到完整梯度就得把整个计算重复n遍。

方法

先正向算一遍并记下所有中间结果，再从输出往回走，用链式法则把“输出对每个中间量的导数”一步步传回输入，一次反向扫描就得到全部偏导。

影响

求完整梯度的代价与输入个数无关，只是计算函数本身的常数倍。今天所有深度学习框架里的反向传播都是这个方法。

背景

要优化或分析一个程序算出来的函数，就需要它的导数。当时常见的办法有两种：手推公式（易错，函数一大就推不动）和有限差分（每个输入扰动一次，既慢又有截断误差）。Wengert列表与前向自动微分提出把计算拆成一串只含一个基本运算的步骤，沿着这串步骤同时传播数值和导数，这就是前向模式自动微分（见自动微分与计算图）。

前向模式的问题在于方向：它一次只跟踪“所有中间量对某一个输入的导数”。函数有n个输入、1个输出时，要得到梯度就得跑n遍。Linnainmaa当时研究的是数值分析问题：一个算法的最终舍入误差，怎样表示为每一步局部舍入误差的加权和——这里的权重恰好就是最终结果对每个中间量的偏导数，而中间量有成千上万个，逐个前向求是不可接受的。

方法

核心观察：链式法则（链式法则）既可以从输入往输出乘，也可以从输出往输入乘。反向模式分两遍：

  • 正向遍：按顺序执行计算，把每个中间变量的值存下来。
  • 反向遍：给每个中间量v配一个“伴随量”v̄ = ∂y/∂v。从输出开始令ȳ = 1，倒序访问每一步；若某步是w = g(u, v)，就把w̄·∂g/∂u累加到ū、把w̄·∂g/∂v累加到v̄。

例子：y = x₁·x₂ + sin(x₁)。正向得到v₃ = x₁·x₂、v₄ = sin(x₁)、y = v₃ + v₄。反向：ȳ = 1，于是v̄₃ = 1、v̄₄ = 1；再由v₃得x̄₂ = v̄₃·x₁、x̄₁ += v̄₃·x₂，由v₄得x̄₁ += v̄₄·cos(x₁)。一次反向扫描同时得到∂y/∂x₁ = x₂ + cos(x₁)和∂y/∂x₂ = x₁。

反向遍里每个基本运算只被访问一次、只做几次乘加，所以总代价与正向计算同一量级，与输入个数n无关。论文附有实现这一过程的FORTRAN程序，处理的是任意的、可能稀疏连接的计算图，而不限于逐层的矩阵结构。

后来的发展

这项工作在数值分析圈子里流传，神经网络研究者长期不知道它。Werbos博士论文在1974年博士论文里独立提出用类似方法训练网络，Speelpenning梯度代码生成在1980年写出了自动生成梯度代码的程序，1986年反向传播让它在神经网络界普及——反向传播本质上就是反向模式自动微分用在“标量损失对百万个参数”的场景。

后来的框架只是把它工程化：Theano与自动微分和TensorFlow先建静态计算图再反向求导，Chainer与Define-by-Run、autograd：给NumPy求导和PyTorch在运行时记录“磁带”再倒放。

容易误解的地方

  • 反向模式适合“输入多、输出少”（如标量损失对大量参数）；输入少、输出多时前向模式更省，两者不是谁取代谁。
  • 它不是符号求导：不产生导数的表达式，只在一个具体输入点上算出导数的数值。
  • 省下的是计算时间，代价是要保存正向遍的全部中间值，显存往往才是瓶颈。

局限与后续

  • 写成芬兰语硕士论文、动机是舍入误差分析，没有和神经网络或优化联系起来，此后十几年神经网络界并不知道这一方法。
    后来针对它的工作　Werbos博士论文 反向传播
  • 反向遍需要正向遍的全部中间值，存储量随计算步数线性增长，深而长的计算会被内存卡住。

读懂它需要的概念

本篇术语

  • 前向模式 / 反向模式　自动微分的两种传播方向。前向模式一遍求出所有量对一个输入的导数；反向模式一遍求出一个输出对所有量的导数。
  • 伴随量（adjoint）　反向模式中每个中间变量附带的数，等于最终输出对该变量的偏导数，在深度学习里通常就叫这个变量的“梯度”。

怎么学

先复习链式法则，在纸上把上面x₁·x₂ + sin(x₁)的例子正向、反向各算一遍。然后读Griewank的短文《Who invented the reverse mode of differentiation?》了解来龙去脉。动手：用Python写一个不到100行的标量自动微分类（每个节点记住父节点和局部导数，backward时倒序拓扑遍历），这就是Karpathy的micrograd。
