Flickr30k

From image descriptions to visual denotations: New similarity metrics for semantic inference over event descriptions
2014.02数据集延伸Peter Young, Alice Lai, Micah Hodosh, Julia Hockenmaier · University of Illinois Urbana-Champaign待核对
项目主页 ↗在交互版中打开（演化树、学习进度）

问题

图像描述和图文匹配缺少规模足够、描述足够多样的人工标注数据。

方法

收集3万多张Flickr上的人物活动照片，请众包工人为每张写多条描述，作为图文检索和图像描述的基准。

影响

它与MS COCO一起成为早期图像描述和图文检索的标准基准，也常被视觉-语言预训练工作用作评测。

方法

Flickr30k来自TACL 2014的论文《从图像描述到视觉外延》。据项目主页，该语料含158,915条众包标注的描述和31,783张图片，是作者此前Flickr 8k数据集的扩展，图片集中在人们的日常活动和事件上。每张图片有多条独立写成的描述，因此同一幅图的不同说法可以相互对照。

论文的原目标不是图像描述，而是研究「视觉外延」：一个短语的外延是它所描述的图片集合，据此可以定义新的语义相似度，并构建一张「外延图」，实验表明它在语义推断任务上不弱于基于词语共现的分布式相似度。语料随后被图像描述（图像描述Show and Tell等）和图文检索任务广泛采用。

描述由众包标注Mechanical Turk的工人撰写。
