Flickr8k图像描述

Framing Image Description as a Ranking Task: Data, Models and Evaluation Metrics
2013.08数据集延伸JAIR 2013Micah Hodosh, Peter Young, Julia Hockenmaier · 伊利诺伊大学厄巴纳-香槟分校待核对
JAIR ↗在交互版中打开（演化树、学习进度）

问题

早期图像描述研究各用各的小数据，生成的句子很难自动评分：BLEU、ROUGE等指标与人的判断是否一致并不清楚，不同系统也无法公平比较。

方法

把“给图配一句话”改写成排序任务：从一池候选描述里为图片排出最合适的一句（或反过来按句子找图），并发布8,000张图、每张配5句人工描述的基准。

影响

与随后更大的Flickr30k一起，成为图像描述与图文检索早期的标准评测；论文对自动指标的分析也提醒后来者：n元组重叠指标不一定可靠。

方法

论文的出发点是：句子生成式的图像描述难以评分，但“检索”有成熟的评测方法。于是把图像描述定义为一个排序问题——给定一张图，对一池候选句子按相关程度排序；给定一句话，对一池图片排序（基于句子的图像搜索）。

数据。8,000张来自Flickr的日常场景照片，每张配5句不同的人工描述，描述清楚地交代了图中主要的人、物和事件。描述通过众包（众包标注Mechanical Turk）收集。论文还提出一套低成本、大规模收集人工相关性判断的方法，用来标注“哪句话描述了哪张图”。

系统与指标分析。作者给出几种只需很少监督的特征就能表现不错的系统，发现每张图有多条描述、并同时利用词序（句法）和语义特征都很重要。他们还深入比较了人工评价与自动指标：考虑整个排序列表的指标（如召回率@K）比只看单个回答的指标稳健得多；对生成式描述，BLEU、ROUGE这类基于n元组重叠的指标与人工判断的一致性值得怀疑。
