LinkBERT文档链接预训练

LinkBERT: Pretraining Language Models with Document Links
2022.03论文延伸ACL 2022Michihiro Yasunaga, Jure Leskovec, Percy Liang · 斯坦福大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

BERT一类预训练每次只看单篇文档里的连续文本，学不到跨文档的知识；可很多问题（多跳问答）需要把分散在不同文档里的事实连起来，而网页的超链接、论文的引用恰恰标出了这种跨文档关系。

方法

把语料看成以超链接或引用为边的文档图，构造输入时把有链接关系的两段文本放进同一个上下文窗口；除掩码语言模型外，再加一个新任务“文档关系预测”：判断第二段是同一文档的下一段、随机文档，还是被链接的文档。

影响

简单地改变“哪些文本放在一起训练”，就让模型在多跳推理和少样本问答上明显变强（HotpotQA、TriviaQA约+5个点），生物医学版BioLinkBERT在BioASQ和USMLE上约+7个点，刷新了多项BioNLP纪录。

背景

BERT的预训练输入是同一文档的连续片段，下一句预测（NSP）也只在单文档内判断。REALM等检索增强模型在推理时检索其他文档，但预训练本身仍不建模文档间关系。生物医学领域的PubMedBERT从头领域预训练在PubMed摘要上从头预训练，同样一次只看一篇。而维基百科有大量超链接，PubMed论文有引用链接，这些链接往往连接了相互补充的知识，例如一篇讲“潮汐”，被链接的一篇讲“月球引力”。

方法

文档图：把语料中每篇文档当作节点，超链接（维基百科）或引用（PubMed）当作边。

构造输入：每个训练样本由两段文本A、B组成，放在同一个上下文里。B有三种来源，各占约三分之一：

  • 连续：B是A在同一文档里的下一段；
  • 随机：B来自一篇随机文档；
  • 链接：B来自与A所在文档有链接关系的文档。

两个目标：

  • 掩码语言模型：在A、B中随机遮词并预测，由于两段同在上下文中，模型可以借助被链接文档的信息来填空，从而学会跨文档的知识关联；
  • 文档关系预测（DRP）：用[CLS]表示对B属于“连续/随机/链接”三类做分类，迫使模型理解两段文本之间的关系。

两个领域：在带超链接的维基百科上预训练通用版LinkBERT，在带引用链接的PubMed上预训练BioLinkBERT，规模与BERT、PubMedBERT对应，便于直接对比。

结果

通用领域：LinkBERT在多种下游任务上超过BERT，在多跳推理和少样本问答上尤其明显，HotpotQA和TriviaQA绝对提升约5个点。生物医学领域：BioLinkBERT在多项BioNLP任务上刷新纪录，BioASQ和USMLE绝对提升约7个点。

后来的发展

同组随后的DRAGON把文本与知识图谱联合预训练，延续了“把结构化关系放进预训练”的思路；“把相关文档拼进同一上下文”的数据组织方式也在后来的大模型预训练中出现（例如按相关性而不是随机拼接文档以训练长上下文）。

它建立在什么之上

  • 延续
    BERT2018.10 · LLM
    保留掩码语言模型，把单文档输入扩展为链接文档对，并用文档关系预测替换下一句预测。
  • 竞争
    REALM2020.02 · 推理·智能体
    REALM在推理时检索文档来补充知识，LinkBERT在预训练时就把链接文档放进上下文。
  • 使用
    HotpotQA多跳问答2018.09 · 数据·评测
    多跳问答HotpotQA是主要评测之一，提升约5个点。
  • 延续
    PubMedBERT从头领域预训练2020.07 · LLM
    BioLinkBERT在同样的PubMed语料上加入引用链接，超过PubMedBERT等生物医学模型。
  • 使用
    MedQA医师执照考试题2020.09 · 数据·评测
    生物医学版在USMLE题目（MedQA）上提升约7个点。

读懂它需要的概念

掩码建模 预训练与微调 图、树与搜索 特殊token 准确率、精确率、召回率与F1

本篇术语

  • 多跳推理　回答一个问题需要依次用到两条或更多事实，而这些事实分布在不同的文档里。
  • 文档关系预测　LinkBERT新增的预训练任务：判断两段文本是同一文档的上下文、随机配对，还是有超链接或引用关系。

怎么学

先读BERT的预训练输入与下一句预测；读本文第3节输入构造和文档关系预测；动手：从维基百科抽取若干带超链接的段落对，构造三类样本，看一个现成BERT在文档关系分类上能做到多少。
