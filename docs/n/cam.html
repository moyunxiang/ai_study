CAM类激活图

Learning Deep Features for Discriminative Localization
2015.12论文延伸CVPR 2016Bolei Zhou, Aditya Khosla, Agata Lapedriza, Aude Oliva, Antonio Torralba · MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

分类网络只给出“这是狗”，看不出它依据图里哪块区域判断；梯度梯度显著图噪点多、难以解读。

方法

让网络最后用全局平均池化接一层线性分类器，把该类别的权重乘回最后一层特征图再相加，就得到一张显示“哪里像这个类”的热力图。

影响

把“类激活热力图”变成解释CNN的标准做法，Grad-CAM与显著图随后把它推广到任意结构的网络。

方法

关键是全局平均池化（GAP，来自Network In Network）：最后一个卷积层输出K张特征图f_k(x,y)，对每张图求空间平均得到K个数，再用一层线性层算类别c的分数 S_c = Σ_k w_k^c · mean(f_k)。因为求平均和加权求和可以交换顺序，同一组权重直接作用在每个空间位置上，就得到类激活图 M_c(x,y) = Σ_k w_k^c f_k(x,y)，上采样到原图大小即可看出模型在看哪里。

作者发现，这样只用图像级类别标签训练的网络，本身就能定位物体：在ILSVRC 2014的目标定位上，top-5错误率37.1%，接近用框标注全监督训练的CNN的34.2%。

局限是网络必须改成“卷积+GAP+线性层”的结构并重新训练。Grad-CAM与显著图用梯度代替这组权重，去掉了结构限制；而显著图的合理性检验后来提醒，这类热力图是否真实反映模型依据需要另行检验。

局限与后续

  • 只适用于最后是GAP加单层线性分类器的网络，其他结构要改网络并重训，可能损失精度。

    利用Network In Network提出的全局平均池化，使分类权重能映射回空间位置。

    同为解释“看哪里”，梯度显著图逐像素、噪声大，CAM给出平滑的区域级热力图。
  • 使用
    GoogLeNet / Inception2014.09 · 视觉
    实验中把GoogLeNet等网络改成GAP结构来生成类激活图。

读懂它需要的概念

卷积层、池化与感受野 特征与表示学习 Softmax与logits 分类、检测、分割

本篇术语

  • 全局平均池化　把每张特征图的所有位置取平均，压成一个数；常用来代替全连接层。
  • 弱监督定位　训练时只有“图里有什么”的标签，没有框，却要求模型指出物体在哪。

怎么学

先懂卷积特征图和池化 → 读原文第2节的推导 → 用预训练ResNet（它本身就以GAP结尾）在几张图上画出CAM。
