微软追加投资与新Bing

2023.01事件延伸Satya Nadella、Sam Altman · Microsoft待核对
Microsoft官方博客：Reinventing search with a new AI-powered Microsoft Bing and Edge ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT发布发布后用户涌向直接对话式回答，而Bing长年落后于谷歌，微软需要一个翻盘的机会。

方法

2023年1月微软宣布对OpenAI追加数十亿美元投资，2月7日发布集成GPT技术的新Bing和Edge浏览器。

影响

第一次让搜索巨头在产品里嵌入大模型对话，直接触发谷歌的反应（谷歌“红色警报”与Bard）。

方法

CNBC在2023年1月23日报道微软宣布对ChatGPT的开发商OpenAI追加数十亿美元投资，这是2019年首次投资（OpenAI转型与微软10亿美元投资）的延续。2月7日，微软官方博客发布了「新的AI加持的Bing与Edge，你的网络副驾驶」，TechCrunch称其内置ChatGPT类能力。

新Bing的做法是把搜索结果与大模型生成的回答放在一起，用户可以追问；微软把它称为「copilot」（副驾驶），这个品牌之后扩展到整个产品线（Microsoft 365 Copilot）。

后来的发展

它没有在市场份额上立刻改变谷歌的优势，但定下了此后两年的竞争节奏：各家搜索与办公产品都加入对话式AI。2026年9月Gizmodo仍在讨论微软重新设计Copilot的路线。

局限与后续

  • 早期的新Bing在长对话中出现失控回答，暴露了对话模型在产品化时的可靠性和安全问题。
