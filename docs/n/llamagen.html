LlamaGen

Autoregressive Model Beats Diffusion: Llama for Scalable Image Generation
2024.06论文延伸Peize Sun, Yi Jiang, Shoufa Chen, Shilong Zhang, Bingyue Peng, Ping Luo, Zehuan Yuan · 香港大学 / 字节跳动待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

没有视觉归纳偏置的普通自回归模型，能否在图像生成上追平扩散模型仍无定论。

方法

直接用Llama架构做下一token预测，只改分词器、规模和数据。

影响

证明纯粹的LLM式模型加好的分词器就能超过LDM和DiT，并可直接使用LLM推理框架加速。

方法

LlamaGen不对图像做特殊的结构设计，只做三件事。其一，重新审视图像分词器，得到下采样率16、ImageNet上重建rFID 0.94、码本使用率97%的分词器（见VQGAN）。其二，训练参数从111M到3.1B的类别条件生成模型（骨架是LLaMA），在ImageNet 256x256上FID 2.18，论文称优于LDM、DiT等。其三，训练一个775M的文生图模型，分两阶段在LAION-COCO和高美学质量图上训练。

作者还验证了LLM服务框架可以直接优化推理，提速326%到414%。

后来的发展

它和视觉自回归VAR、TiTok一维分词器一起证明了自回归在图像生成上的竞争力，随后Emu3纯下一词预测等把同一思路扩展到统一的多模态模型。
