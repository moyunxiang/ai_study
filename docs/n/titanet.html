TitaNet说话人嵌入

TitaNet: Neural Model for speaker representation with 1D Depth-wise separable convolutions and global context
2021.10论文延伸ICASSP 2022Nithin Rao Koluguri, Taejin Park, Boris Ginsburg · NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

ECAPA-TDNN等说话人嵌入模型效果好但参数较多；做说话人日志时要对大量短片段反复提取嵌入，需要又准又可伸缩的模型。

方法

用一维深度可分离卷积加带全局上下文的通道注意力（SE）堆成编码器，再用基于注意力的统计池化把任意长度的语音压成固定长度的说话人向量。

影响

TitaNet成为NVIDIA NeMo里默认的说话人嵌入模型，广泛用于NeMo的说话人验证和说话人日志流程；只有600万参数的小版本在日志任务上也接近最好结果。

方法

说话人识别的主流做法是：用神经网络把一段语音映射成一个固定长度的向量（说话人嵌入），同一个人的向量彼此接近。x-vector说话人嵌入用时延网络做到这一点，ECAPA-TDNN又加入通道注意力和多层特征聚合，成为2020年后的强基线。

TitaNet沿用NVIDIA识别模型QuartzNet（见Jasper与QuartzNet）的骨架：编码器由多个块组成，每块里是一维深度可分离卷积（先逐通道卷积、再1×1卷积混合通道，比普通卷积省参数），配合带全局上下文的Squeeze-and-Excitation层（见SENet通道注意力）——先对整段时间求平均得到全局信息，再据此给每个通道一个权重。编码器输出经过基于通道注意力的统计池化：按注意力权重计算每个通道在时间上的加权均值和标准差，拼成一个向量，再经线性层得到固定长度的嵌入（论文称t-vector），用角度间隔类损失训练。

摘要报告：在VoxCeleb1测试列表上等错误率0.68%；在说话人日志上AMI-MixHeadset、AMI-Lapel和CH109的日志错误率分别为1.73%、1.99%和1.11%；只有600万参数的TitaNet-S在日志任务上接近最好结果。

局限与后续

  • 作为先切段、再提取嵌入、再聚类的级联日志流程的一环，处理不了多人同时说话的重叠片段，需要与端到端日志模型配合。

它建立在什么之上

  • 延续
    x-vector说话人嵌入2018.04 · 语音
    延续把整段语音池化为固定长度嵌入的x-vector范式。
  • 使用
    SENet通道注意力2017.09 · 视觉
    每个块使用带全局上下文的Squeeze-and-Excitation通道注意力。
  • 延续
    Jasper与QuartzNet2019.04 · 语音
    编码器沿用QuartzNet（Jasper的轻量版）的一维深度可分离卷积块结构。
  • 竞争
    ECAPA-TDNN2020.05 · 语音
    同为说话人嵌入模型并都用SE通道注意力和注意力统计池化；TitaNet改用深度可分离卷积，参数更省、尺寸可伸缩。

  • 等错误率（EER）　说话人验证中把误接受率与误拒绝率调到相等时的错误率，越低越好。
  • 日志错误率（DER）　说话人日志中漏检、误检和说话人混淆时长之和占总时长的比例。
