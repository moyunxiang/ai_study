TETRIS：3D内存上的加速器

TETRIS: Scalable and Efficient Neural Network Acceleration with 3D Memory
2017.04论文延伸ASPLOS 2017Mingyu Gao, Jing Pu, Xuan Yang, Mark Horowitz, Christos Kozyrakis · 斯坦福大学待核对
ACM DOI（SIGPLAN Notices版） ↗在交互版中打开（演化树、学习进度）

问题

神经网络加速器越做越大，片上SRAM缓冲和片外DRAM通道的成本和能耗跟着暴涨，内存系统成了扩展的瓶颈。

方法

把加速器放进3D堆叠内存（如HMC混合存储立方体）的逻辑层：既然3D内存带宽高、能耗低，就少用芯片面积做SRAM缓冲、多放计算单元，并把一部分计算挪到DRAM存储体旁边。

影响

是用3D堆叠内存做神经网络近存加速的代表工作，说明了“高带宽内存改变加速器设计平衡”这一点，后来的HBM-PIM存内处理内存等商用近存方案沿着同一方向。

方法

论文的第一个论点是“重新平衡”：传统加速器为了少访问昂贵的片外DRAM，要花大量面积做片上SRAM缓冲。3D堆叠内存的带宽高、每比特能耗低，于是可以反过来——用更多面积放处理单元、只留小SRAM缓冲，靠3D内存及时供数。

第二，把部分神经网络计算挪到DRAM存储体附近（近存计算），进一步降低带宽压力、提高性能和能效。第三，作者发现，虽然SRAM缓冲变小了，3D内存的存在反而让数据流调度更简单，他们给出一种解析式调度方法，效率与穷举搜索得到的调度相当。最后，提出一种混合划分方法，把神经网络计算并行到多个加速器（多个内存立方体）上。

摘要报告，相对使用传统低功耗DRAM内存系统的神经网络加速器，TETRIS性能提升4.1倍、能耗降低1.5倍。

局限与后续

  • 依赖在内存堆栈逻辑层放计算单元，而HMC这类产品后来停产，逻辑层面积和散热也限制了能放多少计算。

本篇术语

  • 近存计算　把计算单元放在存储器内部或紧挨着存储器的地方，减少数据长距离搬运。
  • 存储体（bank）　DRAM芯片内部可以独立工作的一块存储阵列，一颗芯片有多个。
