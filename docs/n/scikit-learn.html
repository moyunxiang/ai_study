scikit-learn

Scikit-learn: Machine Learning in Python
2010.02系统重要首个公开版本2010-02-01；论文 JMLR 2011Fabian Pedregosa, Gaël Varoquaux, Alexandre Gramfort, Vincent Michel, Bertrand Thirion, Olivier Grisel, Mathieu Blondel, Peter Prettenhofer et al. · INRIA Saclay等（项目起源于David Cournapeau的GSoC项目）待核对
JMLR 2011论文 ↗API设计论文（arXiv 1309.0238） ↗官方用户指南 ↗在交互版中打开（演化树、学习进度）

问题

2010年前后，用SVM、随机森林这类经典算法要么写R、MATLAB，要么拼凑各自接口不同的C/C++库；Python里已有的机器学习包要么慢、要么依赖复杂、要么许可证限制商用。

方法

在NumPy/SciPy之上，用同一套极简接口（fit / predict / transform）实现几十种经典算法，性能关键处调用编译代码，BSD许可证允许商用，并配上详尽文档。

影响

把“训练一个分类器”降到三行代码，成为数据科学入门和工业界表格数据建模的默认工具；它的估计器接口被后来大量库模仿。

背景

到2010年，支持向量机、随机森林、k-means聚类等方法已经成熟，但普通工程师和其他学科的研究者很难用上。Java世界有Weka，统计学界用R语言，C/C++有LIBSVM这样的专用库，各自的数据格式和调用方式都不同。Python凭借NumPy与SciPy和SciPy正成为科学计算语言，但已有的Python机器学习包要么纯Python实现太慢，要么依赖R、Shogun等外部系统难以安装，要么是GPL许可证，企业不敢用。

方法

论文强调的设计原则是“少而精”：

  • 统一的估计器接口：任何模型都是一个对象，fit(X, y)训练，监督模型用predict(X)预测，降维、标准化这类变换器用transform(X)。接口靠约定而不是继承，外部代码只要实现这几个方法就能接进来。
  • 数据就是NumPy数组：X是样本×特征的矩阵，不另造数据容器，能直接和其他科学计算库互通。
  • 可组合：Pipeline把多个变换器和一个估计器串成一个新估计器（例如先PCA降维再SVM分类）；GridSearchCV把任意估计器包起来，用交叉验证在参数网格上搜索最优超参数（见超参数与调参、训练集、验证集与测试集），自己也表现为一个估计器，可以嵌套使用。
  • 性能：主体用Python写，热点用Cython编译，SVM和线性模型直接绑定LIBSVM和LibLinear。

一个完整例子只要几行：clf = make_pipeline(StandardScaler(), SVC()); clf.fit(X_train, y_train); clf.score(X_test, y_test)。

结果

论文在Madelon数据集（4400个样本、500个特征）上对比了几个Python机器学习库，scikit-learn的SVM分类用时5.2秒，是对比中最快的。原因之一是它的libsvm绑定避免了内存复制，开销比原版libsvm的Python绑定少最多40%。0.8版测试覆盖率为81%，附约300页用户指南和60多个示例。

后来的发展

scikit-learn成了Python数据科学栈的标准组件，和IPython / Jupyter Notebook、pandas一起构成数据分析的日常环境，Kaggle数据竞赛竞赛中大量的特征工程和基线模型都用它完成。它的fit/predict约定被XGBoost等库提供兼容接口，也影响了后来深度学习高层API（如Keras的model.fit）的设计。但它刻意不做深度学习和GPU，神经网络很快交给了Theano与自动微分、TensorFlow和PyTorch。

容易误解的地方

  • scikit-learn面向中等规模数据：所有数据通常要能放进单机内存，不适合几亿样本的训练。
  • 在交叉验证之外先用全量数据做标准化或特征选择会造成信息泄漏，正确做法是把预处理放进Pipeline。

局限与后续

读懂它需要的概念

监督学习 训练集、验证集与测试集 超参数与调参 准确率、精确率、召回率与F1 向量、矩阵与张量

本篇术语

  • 估计器（estimator）　scikit-learn里所有能从数据学习的对象的统称，必有fit方法；分类器、回归器、聚类器、降维器都是估计器。
  • 交叉验证　把训练数据分成k份，轮流用其中一份验证、其余训练，取平均成绩来估计泛化性能，常用于选超参数。
  • Cython　一种语法接近Python、可编译成C的语言，用来给Python程序的热点循环提速或绑定C库。

怎么学

先补训练集、验证集与测试集和超参数与调参。跟着官方教程用iris或digits数据集训练一个分类器，然后把StandardScaler、PCA和SVC串进Pipeline，用GridSearchCV搜索参数。最后读API设计论文（arXiv 1309.0238）第2节，理解为什么接口这样设计。
