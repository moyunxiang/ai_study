Ferret-UI手机界面理解

Ferret-UI: Grounded Mobile UI Understanding with Multimodal LLMs
2024.04论文延伸ECCV 2024Keen You, Haotian Zhang, Eldon Schoop, Floris Weers, Amanda Swearngin, Jeffrey Nichols, Yinfei Yang, Zhe Gan · Apple待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通用多模态大模型看自然照片还行，看手机截图却常常认不清小图标、读不准小字，也说不出某个按钮在哪里，难以支撑界面操作智能体。

方法

在支持指代和定位的多模态模型Ferret基础上，把细长的手机截图切成两半分别放大编码，并用大量基础与高级界面任务数据做指令微调。

影响

是较早专门针对手机界面理解训练的多模态模型，提出的“按长宽比切图放大”和基础/高级界面任务的划分被后来的GUI定位模型和评测反复参考。

方法

手机截图和自然图像很不一样：画面又高又窄，关键目标（图标、文字、开关）又小又密。直接缩放到固定分辨率送进模型，细节就丢了。

Ferret-UI在Ferret（能用框和点来指代、定位区域的多模态模型）的基础上做了两件事：

  • 任意分辨率切图：按截图的长宽比把它切成两张子图——竖屏横着切、横屏竖着切——两张子图分别编码后再送进语言模型，相当于把细节放大一倍；
  • 界面专用训练数据：从大量界面中构造基础任务，如图标识别、找文字、列出所有控件，每条样本都带区域标注，便于学会精确的指代和定位；再整理高级任务，如详细描述界面、关于感知与交互的对话、推断某个页面的功能，用来练推理能力。

训练后，Ferret-UI能较好地理解界面并执行开放式的界面指令；作者还建立了覆盖上述全部任务的评测集，报告它不仅超过大多数开源的界面多模态模型，而且在全部基础界面任务上超过GPT-4V。
