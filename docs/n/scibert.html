SciBERT科学文献预训练

SciBERT: A Pretrained Language Model for Scientific Text
2019.03论文延伸EMNLP 2019Iz Beltagy, Kyle Lo, Arman Cohan · Allen Institute for AI待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

科学领域的NLP任务（实体识别、关系抽取、论文句子分类）标注数据少且贵；通用BERT在维基百科和图书上预训练，对论文里的专业术语和行文不熟。

方法

在大规模科学论文全文上从头预训练BERT，并用这批语料重新构建一个科学领域的WordPiece词表（SciVocab），再在各项科学NLP任务上微调。

影响

是领域专用BERT的代表之一，与同期的BioBERT一起确立了“在领域语料上再预训练”这一做法，长期是科学文献信息抽取的常用基线。

方法

背景：BERT证明了“先在大规模无标注文本上预训练、再在小标注集上微调”的有效性，但它的语料和词表都来自通用领域；科学文本里有大量通用词表切得很碎的术语，例如化学名、基因名。

SciBERT的做法很直接：用Semantic Scholar收录的论文全文作为语料（以生物医学为主，也有计算机科学），在上面预训练BERT-Base；同时用SentencePiece在这批语料上构建新的大小相近的词表SciVocab，作者统计它与BERT原词表的重合不到一半。实验比较了“沿用BERT权重继续预训练、用原词表”和“从头训练、用SciVocab”等几种组合。

评测覆盖序列标注、句子分类和依存句法分析，数据集来自生物医学、计算机科学等多个科学领域。摘要称相对BERT有统计显著的提升，并在其中若干任务上取得当时最好的结果。

局限与后续

  • 只做了BERT-Base规模的编码器，领域覆盖以生物医学为主；后来通用大模型在足够规模下也能处理科学文本，领域专用小模型的优势在很多任务上缩小。

本篇术语

  • 领域预训练　用某个专业领域的大量无标注文本（论文、病历、代码等）预训练或继续预训练模型，让它熟悉该领域的用词和表达。

怎么学

先读BERT；读本文语料构成、SciVocab与原词表的对比，以及“继续预训练与从头训练”的消融表；之后读领域与任务自适应预训练看领域和任务自适应预训练的系统比较。
