jieba结巴分词

2012.09系统延伸fxsjy（Sun Junyi）及开源社区待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

中文句子里词与词之间没有空格，做任何统计或检索之前都得先切词，而学术系统大多难装难用。

方法

用前缀词典生成所有可能切分的有向无环图，动态规划选词频概率最大的路径，词典外的新词再交给字级HMM加Viterbi识别。

影响

成为Python里最常用的中文分词库，大量中文文本挖掘、搜索和课程作业的第一步就是import jieba。

方法

中文分词的难点是同一串汉字有多种切法（「结婚的和尚未结婚的」）。jieba的做法分两层。第一层查词典：用前缀词典扫描句子，把所有在词典里出现过的词都标出来，构成一张有向无环图（DAG），每条边是一个候选词；再用动态规划在图上找一条路径，使各词词频概率的乘积最大，这就是「精确模式」的切分。第二层处理未登录词：词典里没有的人名、新词，交给一个基于汉字成词能力的隐马尔可夫模型，把每个字标成词首、词中、词尾或单字，用Viterbi算法解码，这正是中文分词即字标注提出的「分词即字标注」思路。

除精确模式外，它还提供全模式（列出所有可能成词的词，不消歧）、搜索引擎模式（对长词再切以提高召回）和基于PaddlePaddle双向GRU的paddle模式，并附带词性标注与关键词提取（IDF与TF-IDF和TextRank两种）。它的定位是开箱即用而非最高精度：用户可以加载自定义词典来适应领域词汇。

局限与后续

  • 以词典和词频为主，切分精度依赖词典覆盖，遇到领域新词、网络用语和歧义结构容易切错，精度低于神经序列标注模型。

读懂它需要的概念

分词与token 隐马尔可夫模型 动态规划 n-gram与平滑

本篇术语

  • 未登录词　词典里没有收录的词，比如新出现的人名、网络用语，分词时最容易出错。
  • 前缀词典　把词典里每个词的所有前缀都存起来，扫描句子时能快速判断从某个字开始的哪些片段可能成词。

怎么学

先理解n-gram和HMM，再读jieba README里的算法一节；动手用jieba.cut对比精确模式和全模式的输出，再加一个自定义词典看结果如何变化。
