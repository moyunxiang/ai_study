特征金字塔FPN

Feature Pyramid Networks for Object Detection
2016.12论文重要CVPR 2017Tsung-Yi Lin, Piotr Dollár, Ross Girshick, Kaiming He, Bharath Hariharan, Serge Belongie · Facebook AI Research / Cornell待核对
arXiv ↗Detectron2（含FPN实现） ↗在交互版中打开（演化树、学习进度）

问题

同一张图里物体有大有小。卷积网络深层语义强但分辨率低，小物体在里面只剩一两个像素；把图缩放成多份再分别算又慢好几倍。

方法

复用骨干网络本来就有的多尺度特征图，加一条自顶向下的通路：把深层的强语义特征逐级放大，与同尺寸的浅层特征相加，得到每一层都语义强的特征金字塔。

影响

几乎零额外开销地显著提升小物体检测，此后Mask R-CNN、RetinaNet以及大多数检测和分割系统都把FPN当作标准“颈部”。

背景

检测的难点之一是尺度：一张街景里既有占半张图的公交车，也有只有十几个像素的路人。手工特征时代的标准做法是图像金字塔：把图片缩放成多种尺寸，每种都单独提特征、单独检测。换成深度网络后这样做代价太高——论文引用的数据是推理时间会增加到约4倍，而且显存不够在图像金字塔上端到端训练。

所以Faster R-CNN只在骨干网络最后一层（步长16或32）的单张特征图上检测，小物体在这里已经被下采样得几乎看不见。SSD尝试在网络中不同深度的多张特征图上分别预测，但为了避开语义太弱的浅层，它从较高层才开始取特征，等于放弃了分辨率最高的那几层，小物体照样吃亏。问题可以概括为：浅层分辨率高但“看不懂”，深层“看得懂”但分辨率低，能不能两样都要？

方法

以ResNet为骨干，取它四个阶段的输出C2、C3、C4、C5，相对输入的步长分别是4、8、16、32像素。这是自底向上的路径，就是普通的前向计算。

自顶向下路径加横向连接：先对C5做一个1×1卷积得到P5；然后把P5用最近邻插值放大2倍，与C4经过1×1卷积（把通道数统一成256）后的结果逐元素相加，得到P4；依此类推得到P3、P2。每个相加结果再过一个3×3卷积，消除上采样带来的锯齿。这样P2的分辨率和C2一样高，但它混入了从C5一路传下来的高层语义。所有层通道数都固定为256，因此后面的检测头可以在各层之间共享参数。

怎么用：区域建议网络（RPN）在P2到P6每层上滑动同一个小头，每层只负责一种尺寸的锚框（面积从32²到512²，见锚框与非极大值抑制），共15种锚框。第二阶段则按候选框大小选层：k = ⌊4 + log₂(√(w·h)/224)⌋，框越小就去越精细的层上取特征。

结果

在COCO上，以ResNet为骨干的单尺度Faster R-CNN做基线：FPN让候选框的平均召回率提高8.0个点，检测AP（COCO标准）提高2.3个点、PASCAL标准AP提高3.8个点。单模型在test-dev上AP达到36.2，超过2016年冠军G-RMI的35.7，而且没有用多尺度测试等技巧。共享特征后ResNet-50版本每张图推理0.148秒（单块M40 GPU），比单尺度基线的0.32秒还快。消融实验显示去掉自顶向下连接或去掉横向连接都会明显变差。

后来的发展

FPN很快成为检测和分割网络的默认“颈部”（骨干和预测头之间的部分）：几个月后的Mask R-CNN和Focal Loss与RetinaNet都直接建立在它上面，后来的FCOS无锚框检测、EfficientDet（BiFPN，双向加权融合）、全景分割相关模型也沿用多层金字塔。Transformer时代，PVT金字塔ViT、Swin Transformer专门把ViT改造成能输出多尺度特征的形式，就是为了接上FPN；ViTDet朴素ViT检测则发现普通ViT只用最后一层特征简单造一个金字塔也够用，说明金字塔的关键在于多尺度预测，而不一定是自顶向下融合。

容易误解的地方

  • FPN本身不是检测器，是一种通用的特征组织方式，可以接在Faster R-CNN、RetinaNet、Mask R-CNN等任何框架上。
  • 和U-Net的区别：U-Net也有自顶向下加跳跃连接，但只在最精细的一层上做预测；FPN在每一层都独立预测，相当于网络内部的图像金字塔。

局限与后续

  • 信息只沿自顶向下一个方向、用简单相加融合，浅层的精确定位信息到达高层的路径很长。
    后来针对它的工作　EfficientDet
  • 物体分到哪一层靠人工规则（锚框尺寸、按框面积算层号），而且仍依赖锚框和非极大值抑制等手工组件。
    后来针对它的工作　FCOS无锚框检测 DETR
  • 在两阶段检测器上验证；单阶段密集检测器即使用了FPN，精度仍明显落后两阶段方法。
    后来针对它的工作　Focal Loss与RetinaNet

    U-Net2015.05 · 视觉
    同样是自顶向下加跳跃连接的结构，但U-Net只在最细一层预测，FPN在每层独立预测。
  • 改进
    Faster R-CNN2015.06 · 视觉
    把Faster R-CNN的RPN和检测头从单张特征图搬到多层金字塔上，框架本身几乎不改。
  • 使用
    MS COCO2014.05 · 数据·评测
    在COCO上评测，AP、小物体AP等指标都按COCO标准报告。
  • 延续
    SPPnet2014.06 · 视觉
    SPPnet证明可以在单尺度特征图上做区域检测，但多尺度仍更准；FPN在网络内部造出多尺度，免去图像金字塔。
  • 改进
    SSD2015.12 · 视觉
    SSD多层预测但不用高分辨率浅层、浅层语义也弱；FPN用自顶向下通路给高分辨率层补上语义，小物体检测明显变好。
  • 改进
    R-FCN检测2016.05 · 视觉
    只在单一尺度特征图上检测，小物体效果不好。

读懂它需要的概念

卷积层、池化与感受野 分类、检测、分割 锚框与非极大值抑制 IoU与mAP 残差连接

本篇术语

  • 特征金字塔　同一张图在多个分辨率上的特征图，大物体在粗的层上检测，小物体在细的层上检测。
  • 横向连接　把骨干网络同尺寸的浅层特征经1×1卷积后，与上一级放大后的深层特征逐元素相加。
  • 颈部（neck）　检测网络中位于骨干网络和预测头之间、负责融合多尺度特征的部分，FPN是最典型的颈部。
