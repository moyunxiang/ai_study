Quick-Thoughts判别式句向量

An efficient framework for learning sentence representations
2018.03论文延伸ICLR 2018Lajanugen Logeswaran, Honglak Lee · 密歇根大学、Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Skip-Thought让编码器生成前后句的每一个词来学习句向量，生成目标要建模大量与语义无关的表层细节，训练极慢（数周）。

方法

把“生成上下文句”改成“分辨上下文句”：给定一句话，从一批候选句中挑出真正与它相邻的那一句，只需比较句向量的内积，是一个分类问题。

影响

在多项下游任务上超过此前的无监督和有监督句表示方法，同时训练时间缩短一个数量级；这种“正确邻句对比批内其他句子”的目标，是后来对比学习句向量（如SimCSE）的先声。

背景

Skip-Thought句向量（2015）借分布假说的思路：意思相近的句子出现在相似的上下文中，于是训练编码器—解码器根据当前句生成前后句。FastSent与无监督句向量比较（2016）用词袋预测相邻句中的词以加速，但丢失了词序。InferSent（2017）改用有标注的自然语言推理数据训练，效果好但依赖人工标注。另一方面，word2vec的负采样、噪声对比估计NCE等都说明：把预测问题改成区分真伪样本，可以大幅减少计算。

方法

两个编码器f和g（结构相同、参数分开，均为GRU）分别把句子编码为向量。对一句话s和一个候选集S_cand（其中包含s真正的前后句，其余为同一批次中的其他句子），定义

p(s_cand | s, S_cand) = exp(f(s)·g(s_cand)) / Σ_{s'∈S_cand} exp(f(s)·g(s'))

训练目标是最大化真实上下文句的对数概率。打分函数刻意选得极简（内积），迫使语义信息必须进入句向量本身，而不能靠复杂的分类器补偿。训练好后把f(s)与g(s)拼接作为句子表示。

因为不需要逐词解码，每个训练步只做编码和一个批内矩阵乘法，可在大规模无标注书籍语料上快速训练。

结果

论文报告，在情感、主观性、问题分类、复述识别、语义相关度等多项下游任务上，该方法的句表示优于当时最好的无监督与有监督表示学习方法，且训练时间加速一个数量级（原文摘要）。

后来的发展

Quick-Thoughts的批内对比目标与同年的对比预测编码CPC思路相近，之后被大量句向量和检索模型沿用：Sentence-BERT的多负例训练、SimCSE对比句向量的批内对比学习、稠密检索中的批内负例，都可以看作这一思路的延续。不过在预训练语言模型出现后，基于BERT的句向量很快超越了这些从头训练的RNN编码器。

本篇术语

  • 批内负例　把同一训练批次里其他样本当作负例，不需要额外采样，计算上只是一次矩阵乘法。
  • 判别式目标　训练模型区分正确答案与干扰项，而不是逐词生成正确答案。

怎么学

先读Skip-Thought句向量 → 读本文第3节目标函数 → 动手：用BookCorpus的小子集，以句子与其后一句为正例、批内其余句为负例，训练一个小GRU编码器，再在SST-2上用逻辑回归评测句向量。
