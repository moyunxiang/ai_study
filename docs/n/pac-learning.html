PAC学习

A Theory of the Learnable
1984论文重要Communications of the ACM 1984（初版见STOC 1984）Leslie G. Valiant · 哈佛大学待核对
CACM（DOI） ↗Wikipedia: PAC learning ↗在交互版中打开（演化树、学习进度）

问题

“机器学会了”没有严格定义：从有限样本归纳出规则，总有可能碰巧错；也没人说得清学一个概念需要多少样本、多少计算。

方法

把学习定义成：对任意数据分布，用多项式数量的样本和多项式时间，以至少1−δ的概率输出一个错误率不超过ε的假设——“大概率、近似正确”。

影响

让“可学习性”成为可以证明的计算机科学问题，奠定计算学习理论；直接引出Boosting，Valiant因此获2010年度图灵奖。

背景

1980年代初的AI主流是专家系统的商业化：知识由专家口述、工程师手写成规则，写规则本身成了瓶颈。另一边，统计学家早有VC维与一致收敛这样的一致收敛理论，回答“样本够多时经验误差接近真实误差”，但不关心算法要算多久。

Valiant的出发点是类比图灵：可计算数：可计算性理论之所以能建立，是因为先有了“机械计算”的精确模型。学习也需要一个精确模型，才能回答哪些东西学得会、哪些学不会。难点在于，从有限样本归纳规则在逻辑上永远不可靠——几个例子不能唯一确定一条规则。

方法

学习协议。原文里学习者可以调用两个例程：EXAMPLES按某个未知但固定的分布D给出一个正例；ORACLE对给定输入回答“是不是这个概念”。概念用布尔表达式表示。

定义（现在通行的写法）。对任意目标概念c和任意分布D，以及任意0 < ε, δ < 1，学习算法读入从D抽取的m个带标签样本，输出假设h，使得

P[ error_D(h) ≤ ε ] ≥ 1 − δ

且样本数m和运行时间都是1/ε、1/δ和问题规模的多项式。ε管“近似正确”，δ管“大概率”。“对任意分布”意味着不对数据做任何假设。

为什么有限样本就够。设假设集合H有限。一个真实错误率超过ε的坏假设，在m个独立样本上全部答对的概率至多(1−ε)ᵐ ≤ e^(−εm)；对H里所有坏假设取并集，只要

m ≥ (1/ε)·(ln|H| + ln(1/δ))

任何与全部样本一致的假设就满足要求。例如|H| = 2²⁰、ε = 0.05、δ = 0.01，约370个样本就够。

原文的正面例子：k-CNF。目标是若干个“最多k个变量的或”再取“与”。算法从所有可能的短子句出发，每看到一个正例，就删掉被它违反的子句。剩下的表达式不会把反例误判成正例，只会在一小部分正例上说“否”，而这一部分可以通过多看样本压到任意小。

结果

论文证明k-CNF等几类有实际意义的命题概念可以只用多项式个正例高效学到，并给出了样本数上界L(h, S) ≤ 2h(S + logₑh)。同时它用密码学论证指出：如果存在安全的单向函数，那么一般布尔电路这样的大类是学不会的——学习的上限由计算复杂性决定，而不只是数据量。

后来的发展

后续工作证明，在一定正则条件下，一个概念类可PAC学习当且仅当它的VC维有限，把这一框架与VC维与一致收敛统一起来。Valiant在文中留下的“弱学习能否变成强学习”问题，被弱可学习性与Boosting给出肯定回答，进而发展成AdaBoost与集成学习；最大间隔分类器与支持向量机的泛化分析也在这套语言里进行；强化学习里的E3与PAC探索理论把它推广到探索问题。2011年Valiant获图灵奖（Valiant获图灵奖）。

深度学习兴起后，这套最坏情况的界对“参数比样本多得多却仍能泛化”的网络几乎给不出有用的数字，见重新思考泛化。

容易误解的地方

  • PAC的“对任意分布”是最坏情况保证，给出的样本数通常极其保守，不能拿来估算实际需要多少数据。
  • PAC可学习不等于有好算法：样本够了，找一致假设仍可能是NP难的。
  • 原始定义假设标签无噪声、目标概念就在假设集合里；处理噪声和模型错设需要后来的“不可知”PAC。

    Valiant明确以可计算性理论为范本：先给学习一个精确的计算模型，再讨论什么可学、什么不可学。

    VC理论回答样本够不够，PAC在此之上加入“计算要在多项式时间内完成”的要求；后来证明两者在样本复杂度上等价。

读懂它需要的概念

随机变量与概率分布 泛化与过拟合 监督学习 时间与空间复杂度 命题逻辑、谓词逻辑与符号推理

本篇术语

  • 假设空间　学习算法可能输出的所有候选规则组成的集合，记作H。集合越大越可能包含正确答案，但也越需要更多样本才能排除错的。
  • 样本复杂度　达到给定精度ε和置信度1−δ所需的最少样本数。
  • k-CNF　合取范式：若干子句的“与”，每个子句是最多k个变量（或其否定）的“或”。

怎么学

先补随机变量与概率分布和泛化与过拟合。读原文第1、2节（协议与定义）和k-CNF一节；再看Wikipedia条目的定义部分。动手：自己推导一遍有限假设空间的样本数公式，然后写程序在随机生成的3-CNF上跑删子句算法，画出错误率随样本数下降的曲线，和公式给出的上界对比。
