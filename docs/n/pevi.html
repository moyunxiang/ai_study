PEVI悲观值迭代

Is Pessimism Provably Efficient for Offline RL?
2020.12论文延伸ICML 2021Ying Jin, Zhuoran Yang, Zhaoran Wang · 斯坦福大学 / 普林斯顿大学 / 西北大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL的经验方法（BCQ批量约束Q学习、离线强化学习CQL）都在用某种“悲观”，但理论分析大多假设数据集充分覆盖所有状态-动作（集中系数有界），而这恰恰是离线RL最不能保证的；不假设充分覆盖时，什么样的算法是可证明高效的？

方法

悲观值迭代（PEVI）：把在线探索中鼓励去不确定处的乐观奖励“翻转符号”，变成惩罚——在值迭代的每一步减去一个不确定性量化项 Γ_h(s,a)，数据覆盖越少的地方价值被压得越低。

影响

在不假设数据充分覆盖的情况下给出了数据依赖的次优性上界，并在线性MDP上证明与信息论下界只差维度和时域的乘性因子，即“悲观既可证明高效，又是极小极大最优的”，为离线RL的悲观原则提供了理论基础。

背景

在线RL理论用乐观原则（UCBVI极小极大遗憾界、LSVI-UCB线性MDP）：对不确定的地方高估价值，以便去探索。离线RL不能再探索，如果仍然高估，策略就会被推向数据从未覆盖的动作，这正是经验上离线RL崩溃的原因。以往离线理论（如拟合Q迭代的分析）通常假设数据分布对所有策略都有界的集中系数，这在实践中几乎不成立；Wang等人的下界（离线RL线性下界）更显示，即便线性可实现、数据对特征有良好覆盖，离线策略评估也可能需要指数多样本。

方法

PEVI与在线的LSVI-UCB结构相同，只改一个符号。从最后一步往前，对每个h：

Q̂_h(s,a) = min( 𝔹̂_h V̂_{h+1}(s,a) − Γ_h(s,a), H − h + 1 )^+，V̂_h(s) = ⟨Q̂_h(s,·), π̂_h(·|s)⟩，π̂_h = argmax Q̂_h

其中 𝔹̂_h V̂_{h+1} 是从离线数据估计的Bellman备份，Γ_h 是一个不确定性量化器，要求满足 |𝔹̂_h V − 𝔹_h V| ≤ Γ_h（以高概率）。在线性MDP中取 Γ_h(s,a) = β·√(φ(s,a)^T Λ_h⁻¹ φ(s,a))，正好是LSVI-UCB线性MDP奖励项的相反数。

主定理给出的次优性上界是数据依赖的：SubOpt(π̂) ≤ 2 Σ_h E_{π*}[ Γ_h(s_h, a_h) ]——只取决于数据在最优策略会经过的状态-动作上覆盖得怎么样，而不需要数据覆盖所有策略。作者还指出，悲观消除了一种由数据集中覆盖稀少、与最优策略无关的“无关轨迹”引起的“虚假相关”。

结果

摘要称，在不假设数据充分覆盖的前提下，为一般MDP建立了PEVI次优性的数据依赖上界；在线性MDP中，它与信息论下界只差维度和时域的乘性因子，即悲观不仅可证明高效，而且极小极大最优；学到的策略是给定数据下所有策略中的“尽力而为”。

后来的发展

PEVI与同期的单策略集中性分析（如“悲观的故事”系列）一起，确立了“离线RL只需覆盖最优策略”的理论范式；此后的离线RL理论大多沿用“下置信界+单策略覆盖”的框架，并推广到一般函数类与离线到在线的设定。

本篇术语

  • 悲观原则　面对不确定性时故意低估价值，只信任数据充分支持的结论；是在线探索中乐观原则的反面。
  • 集中系数　衡量数据分布对某个策略所访问分布的覆盖程度的比值上界；理论上越小，用离线数据评估该策略越容易。

怎么学

先读LSVI-UCB线性MDP理解乐观值迭代；读原文第3节PEVI的定义和第4节数据依赖上界；在一个表格MDP上用只覆盖部分状态的离线数据，比较普通值迭代与PEVI的策略质量。
