L-BFGS

On the Limited Memory BFGS Method for Large Scale Optimization
1989论文延伸Mathematical Programming 1989Dong Liu, Jorge Nocedal · 西北大学待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

牛顿类方法收敛快但需要存储和求逆n×n的Hessian矩阵，参数一多就不可能。

方法

只保留最近m次迭代的参数变化和梯度变化，用它们隐式地构造Hessian逆的近似，内存只需O(mn)。

影响

成为中等规模凸优化与经典机器学习（逻辑回归、CRF）里最常用的优化器之一。

方法

BFGS是一种拟牛顿法：不直接算二阶导数，而是用相邻两步的参数差s和梯度差y来更新对Hessian逆的近似，从而得到比梯度下降更好的搜索方向。但存储完整的近似矩阵要n²内存。

L-BFGS只保留最近m组(s, y)对（m通常取几到几十），用一个“双循环”递推直接算出方向，不显式形成矩阵。它配合线搜索使用，在凸问题上收敛很快，是训练逻辑回归、条件随机场的常用方法。在深度学习里，小批量带来的噪声破坏了线搜索与曲率估计，所以主流用随机梯度下降的变体。

局限与后续

  • 依赖精确的线搜索和稳定的梯度，在随机小批量、非凸的深度网络训练中表现不稳。
