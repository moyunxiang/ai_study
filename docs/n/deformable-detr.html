Deformable DETR

Deformable DETR: Deformable Transformers for End-to-End Object Detection
2020.10论文延伸ICLR 2021Zhu, Su, Lu, Li, Wang, Dai · SenseTime / USTC / CUHK待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DETR用全局注意力看整张特征图，收敛极慢，需要几百个epoch，并且因为计算量大只能用低分辨率特征，小物体效果差。

方法

让每个查询只关注参考点周围少数几个可学习的采样点，用可变形注意力替代全局注意力，并自然地接入多尺度特征。

影响

收敛快约10倍，小物体更好，成为后续DETR系检测器的共同基础模块。

方法

DETR的编码器和解码器里，每个位置都要和整张特征图的所有位置算注意力，计算量随图像面积平方增长，而且训练初期注意力权重近乎均匀，要很久才学会聚焦。Deformable DETR借用可变形卷积的思想：每个查询先预测几个相对参考点的偏移量，只在这几个采样点上取特征并加权；采样位置和权重都由网络学出，复杂度随像素数线性增长。因为每个查询只看少数点，它可以直接把多个尺度的特征图一起放进来，不必另造金字塔。

论文称在COCO上优于DETR（尤其是小物体），训练轮数少10倍（摘要）。

后来的发展

DINO（检测）、RT-DETR实时DETR等后续检测器都在Deformable DETR的结构上改进；可变形注意力后来也用于视觉大模型的骨干。

局限与后续

  • 仍需要大量解码器层和查询的训练技巧，收敛速度与卷积检测器相比仍不占绝对优势。
    后来针对它的工作　DINO（检测）
  • 可变形采样的内存访问不规则，实现和硬件效率不如规整的稠密算子。
    后来针对它的工作　RT-DETR实时DETR

读懂它需要的概念

自注意力与多头注意力 编码器-解码器 稀疏注意力与高效注意力 锚框与非极大值抑制 分类、检测、分割

怎么学

先读稀疏注意力与高效注意力与DETR，再读原文第4节可变形注意力公式，对照官方实现里的MSDeformAttn。
