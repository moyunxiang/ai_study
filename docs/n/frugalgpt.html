模型路由与级联

FrugalGPT: How to Use Large Language Models While Reducing Cost and Improving Performance
2023.05论文延伸TMLR 2024Lingjiao Chen, Matei Zaharia, James Zou · Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

不同LLM的API价格相差约两个数量级，但应用常常对所有问题都调用最贵的模型。

方法

用三类策略省钱：缩短提示、缓存近似问题、以及按问题难度在多个模型之间路由或级联，便宜模型答不好时才升级。

影响

明确提出“按问题挑模型”的成本-质量优化思路，被后来的路由器和级联系统沿用。

方法

论文把调用多个LLM API看作一个优化问题：给定预算，如何选模型使精度最高。其中的LLM级联先让便宜模型回答，用一个小的打分模型判断答案可信度，不够高才交给更贵的模型。摘要称API费用可相差约100倍，FrugalGPT可在匹配GPT-4性能的同时最多节省98%成本，或在相同成本下比GPT-4准确率高4%。

结果

评估在多个公开数据集和多家厂商的API上进行；官方摘要称，同等成本下准确率比GPT-4高4%，或在持平准确率时节省最多98%费用。这些是作者自己的实验结论，具体数据集明细本节未逐项核实。
