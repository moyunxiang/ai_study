LMDeploy与TurboMind

2023.06系统延伸上海人工智能实验室InternLM团队待核对
GitHub ↗TurboMind论文 ↗在交互版中打开（演化树、学习进度）

问题

国产开源大模型与多模态模型快速增多，需要一个既能压缩量化、又能高吞吐部署的工具链，并支持国产加速卡。

方法

提供压缩、部署、服务一体的工具包，包含两套推理引擎：C++/CUDA写的高性能TurboMind引擎，以及便于扩展新模型的PyTorch引擎。

影响

与vLLM、SGLang并列为国内最常用的开源推理框架之一，也是InternLM、InternVL等模型的官方部署方案，并支持华为昇腾等平台。

方法

LMDeploy仓库创建于2023年6月，定位是“压缩、部署和服务大模型的工具包”。它有两个后端：TurboMind源自NVIDIA FasterTransformer的思路，用C++/CUDA实现持续批处理、分块KV缓存、权重与KV缓存量化，追求极致性能；PyTorch引擎用Python实现，接入新模型更容易，也是它支持昇腾等非NVIDIA硬件的主要途径。上层提供离线批量推理接口和兼容OpenAI的API服务。

README中的更新记录显示：2024年起PyTorch引擎引入CUDA Graph、支持华为昇腾；2025年集成FlashMLA、DeepGEMM、DeepEP等DeepSeek开源组件，并支持与Mooncake结合的预填充—解码分离部署；TurboMind支持MXFP4等格式。其TurboMind混合精度推理论文已被EuroSys 2027接收。

局限与后续

  • 两套引擎的模型与功能支持范围不完全相同，选择和维护成本较高。

读懂它需要的概念

KV缓存 量化 吞吐、延迟与批处理

怎么学

先了解vLLM与PagedAttention的分页KV缓存和连续批处理；读LMDeploy文档的快速开始；动手分别用TurboMind与PyTorch引擎部署同一模型，比较吞吐。
