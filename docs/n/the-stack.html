The Stack开放代码语料

The Stack: 3 TB of permissively licensed source code
2022.11数据集延伸Denis Kocetkov, Raymond Li, Loubna Ben Allal, Jia Li, Chenghao Mou, Carlos Muñoz Ferrandis, Yacine Jernite, Margaret Mitchell et al. · BigCode（Hugging Face、ServiceNow等）待核对
arXiv ↗数据集 ↗在交互版中打开（演化树、学习进度）

问题

Codex等代码模型的训练数据不公开，来源和授权都说不清；开源社区想训练代码大模型，却没有一份规模够大、授权清楚的源代码语料。

方法

从GitHub收集30种编程语言共3.1TB、只保留宽松开源许可证的源代码，公开发布，并配上数据治理办法：开发者可以查询自己的代码是否在内并申请移除。

影响

成为BigCode项目SantaCoder、StarCoder系列的训练语料，也让“授权清楚、可退出”的数据治理方式成为开放代码语料的参照。

方法

Codex和GitHub Copilot证明了在海量代码上训练语言模型的价值，但训练数据是闭源的，代码作者既不知道自己的代码被用了，也无法拒绝。The Pile与开放预训练语料等开放语料里的代码部分又规模有限。

做法。BigCode团队抓取GitHub公开仓库，识别每个仓库的许可证，只保留MIT、Apache等宽松许可证下的文件，得到30种语言、3.1TB的数据集；再做近似去重。论文同时公布数据治理方案：提供名为“Am I in The Stack”的查询工具，开发者可以按流程申请把自己的代码移出数据集。

实验。作者在不同的Python子集上训练3.5亿参数的解码器，在HumanEval和MBPP上测试，发现两点：近似去重在所有实验中都显著提升效果；只用宽松许可证的数据，就能达到此前报告的同规模模型在HumanEval和MBPP上的成绩。

读懂它需要的概念

语言模型 预训练与微调 基准、排行榜与SOTA

本篇术语

  • 宽松许可证　MIT、Apache 2.0、BSD等开源许可证，允许他人自由使用、修改和再分发代码，限制很少。
  • 近似去重　不只删完全相同的文件，也删内容高度相似的文件（如复制后小改的代码），常用MinHash等算法实现。

怎么学

先了解代码模型如何用HumanEval评测。读原文关于许可证识别、去重和数据治理的章节；动手用datasets库加载The Stack里某一种语言的小子集，统计文件长度和重复率。
