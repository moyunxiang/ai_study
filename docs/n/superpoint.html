SuperPoint

SuperPoint: Self-Supervised Interest Point Detection and Description
2017.12论文延伸CVPRW 2018DeTone, Malisiewicz, Rabinovich · Magic Leap待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统角点与特征点（Harris、SIFT）靠手工规则，神经网络方案又缺少关键点位置的真值标注。

方法

先在合成几何图形上训练一个基础检测器，再用「单应变换自适应」在真实图像上自我标注，同时输出特征点位置和描述子。

影响

成为深度学习局部特征的代表，被SuperGlue等匹配与SLAM系统沿用。

方法

网络是全卷积的，一次前向就在整图上同时给出每个位置的特征点概率和对应的描述向量。训练分三步：先在人工合成、角点位置明确的几何图形（线条、方块等）上训练初始检测器；再对真实的无标注图像做随机单应变换（一种平面透视变换），在变换后的多个版本上分别跑检测器，把结果映射回原图叠加，得到更稳定、更丰富的伪标签，这就是Homographic Adaptation；最后用这些伪标签训练最终的检测器与描述子。

论文在HPatches上的单应估计结果好于LIFT、SIFT和ORB。

局限与后续

  • 描述子只以局部外观为依据，在光照、视角剧烈变化时匹配仍会失败，需要后续更强的匹配器。
    后来针对它的工作　SuperGlue
  • 自监督的伪标签仍受初始合成数据分布限制。
    后来针对它的工作　R2D2

它建立在什么之上

  • 竞争
    SIFT特征1999 · 视觉
    同样要产生关键点和描述子，但用网络一次完成，并在单应估计上优于SIFT。
  • 改进
    Harris角点1988 · 视觉
    用学习到的检测器替代手工的角点响应函数，提高重复检测率。
  • 改进
    MSER稳定区域2002.09 · 视觉
    只给出区域本身，还需要配合SIFT等描述子才能匹配，深度学习时代被学习式检测子和描述子取代。
  • 改进
    FAST角点2006.05 · 视觉
    只比较亮度，对噪声敏感，阈值t需要人工调。
  • 改进
    BRIEF二进制描述子2010.09 · 视觉
    随机采样的像素对之间相关性高、区分度有限，在重复纹理下容易误匹配。
  • 改进
    ORB特征2011.11 · 视觉
    旋转和轻度尺度变化可以处理，但在大的视角变化、模糊下，匹配的可靠性不及SIFT。
