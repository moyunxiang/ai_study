Sutton与Barto获图灵奖

2025.03事件延伸2024 ACM A.M. Turing Award（2025-03公布）ACM（获奖者：Andrew Barto、Richard Sutton） · ACM待核对
NSF新闻 ↗在交互版中打开（演化树、学习进度）

问题

强化学习长期被当作小众方向，其基础理论和算法的价值并未被计算机科学主流充分承认。

方法

ACM把2024年度图灵奖授予Andrew Barto与Richard Sutton，表彰他们对强化学习的奠基性贡献。

影响

标志着强化学习作为AI核心方向被计算机科学界的最高荣誉认可。

方法

2025年3月5日前后多家机构和媒体（美国国家科学基金会、麻省大学阿默斯特分校、纽约时报等）报道，Barto与Sutton获得2024年度图灵奖，NSF的标题称其「对强化学习的开创性贡献」（groundbreaking contributions to reinforcement learning）。

两人合著《Reinforcement Learning: An Introduction》（见《Reinforcement Learning: An Introduction》），该书是几乎所有强化学习课程的标准教材；Sutton的时序差分学习（见时序差分学习）等工作构成了现代深度RL的基础。奖金金额等细节本条目未核对，不引用。

  • 奖项认可的是奠基性工作，现代RL在大模型后训练中的作用之争仍在继续。
