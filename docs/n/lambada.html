LAMBADA末词预测

The LAMBADA dataset: Word prediction requiring a broad discourse context
2016.06数据集延伸ACL 2016Denis Paperno, Germán Kruszewski, Angeliki Lazaridou, Quan Ngoc Pham, Raffaella Bernardi, Sandro Pezzelle, Marco Baroni, Gemma Boleda et al. · 特伦托大学 / 阿姆斯特丹大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语言模型的困惑度主要奖励猜对局部搭配，测不出模型是否记住并理解了好几句之前的上下文。

方法

从小说中筛出一批段落：人读完整段能猜出最后一个词，只看最后一句却猜不出；模型必须利用更大范围的语篇信息才能答对。

影响

发布时所有被测语言模型准确率都不到1%；它后来成为GPT-2、GPT-3等大模型零样本评测的固定项目，GPT-3少样本达到86.4%。

方法

段落取自BooksCorpus里的未出版小说。每个样本由上下文（平均4.6句、至少凑够50个词）和目标句组成，任务是猜目标句的最后一个词。

两步过滤。先用四个语言模型（一个预训练RNN，以及在BooksCorpus上训练的4-gram、RNN和前馈网络）剔除那些靠局部上下文就容易猜中的段落；再在众包平台上分三步人工筛选：第一位、第二位标注者看完整段都猜对，然后让更多人只看目标句来猜，最多10人都猜不中才保留。

最终得到10,022段，开发集4,869段、测试集5,153段，来自互不重叠的小说；另提供2,662部小说、2.03亿词的同领域训练文本。作者还从同一批小说中随机抽取5千段不经过滤的段落作为对照集。

结果

在LAMBADA上，n-gram、RNN、LSTM、记忆网络的准确率都在1%以下（LSTM为0）；随机从段落里挑一个大写词反而有7.3%。同样的模型在未过滤的对照集上表现正常（LSTM 21.9%），说明难点确实来自需要长距离语篇信息。

四年后，GPT-3报告零样本76.2%、少样本86.4%，此前最好成绩为68.0%。

后来的发展

LAMBADA从“刁难语言模型”的测试，变成了衡量预训练语言模型规模效应的常用指标：GPT-3论文表中此前最好的困惑度8.63即出自GPT-2；GPT-3改用填空格式的少样本提示，比自己的零样本成绩又高出约10个百分点，并且这种提示只对大模型有效，对最小的模型反而降低了近20%。

局限与后续

  • 只考一个词，且很多目标词已在上下文中出现过（约84%），模型可以靠“从前文里挑一个词”的复制策略拿分，不完全等于理解剧情。

  • 段落取自BooksCorpus，而BooksCorpus被广泛用于预训练，后来的模型可能在训练中见过同一批小说。

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    以LSTM等当时最强的语言模型作为基线，它们在LAMBADA上准确率为0。
  • 改进
    困惑度Perplexity1977 · 数据·评测
    困惑度主要反映局部预测；LAMBADA过滤掉局部可猜的样本，用末词准确率专门考长距离语篇理解。
  • 使用
    记忆网络2014.10 · NLP
    测试了记忆网络这类带长期记忆的模型，同样不到1%；作者推测长期记忆加推理是解题关键。
  • 使用
    BooksCorpus2015.06 · 数据·评测
    段落和配套训练文本全部取自BooksCorpus的未出版小说，以减少外部知识的帮助。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

语言模型 困惑度 n-gram与平滑 循环网络与隐状态 基准、排行榜与SOTA

本篇术语

  • 末词预测（cloze）　把一段文字的最后一个词挖掉让模型填回，只有完全猜中才算对。

怎么学

先读困惑度，理解为什么低困惑度不代表理解长上下文。读原文第3节的过滤流程和表1。动手：用一个开源小模型在LAMBADA测试集上算末词准确率，再统计目标词是否出现在上下文中，比较两类样本的准确率。
