Ultralytics YOLO系列

2020.06模型延伸Glenn Jocher 等 · Ultralytics待核对
GitHub ↗Ultralytics文档 ↗在交互版中打开（演化树、学习进度）

问题

原版YOLO的实现是C语言的darknet，难以安装、修改和部署，研究者想在PyTorch里训练和导出检测器很不方便。

方法

Ultralytics用PyTorch重写YOLO并持续发布YOLOv5及之后的版本，提供n/s/m/l/x多个尺寸、一键训练与导出的工程化工具链。

影响

让实时检测成为开箱即用的软件，YOLO从论文系列变成最广泛使用的检测软件生态之一。

方法

YOLOv5的GitHub仓库于2020年5月27日公开，6月发布v1.0：基于PyTorch，按复合缩放给出s、m、l、x四个尺寸。v1.0发布说明里列出的COCO val AP为36.6（s）到48.4（x），V100上单图延迟2.1到6.1毫秒（官方自报，为官方称）。它同时带来训练、验证、推理和导出的统一命令行，后来的版本把这套接口扩展到分类、分割、姿态等任务，并改用无anchor的检测头（官方文档称YOLOv5u采用了YOLOv8引入的anchor-free split head）。

该系列没有配套的正式论文，这是学术界的主要争议点：速度精度对比出自官方自测，与YOLOv4等工作的可比性存疑。

后来的发展

该仓库成为工业界部署检测模型的默认选择之一，其接口也被后续版本延续。

局限与后续

  • 没有同行评审的论文，官方给出的基准难以被独立复现和比较。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 仍然需要NMS后处理，推理延迟含后处理时间。

读懂它需要的概念

锚框与非极大值抑制 分类、检测、分割 参数量、计算量与显存 基准、排行榜与SOTA IoU与mAP

怎么学

先读锚框与非极大值抑制，然后跟着官方文档用自己的数据训练一个yolov5s，再导出成ONNX观察部署流程。
