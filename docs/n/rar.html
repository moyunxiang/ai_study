RAR随机顺序自回归

Randomized Autoregressive Visual Generation
2024.11论文延伸Qihang Yu, Ju He, Xueqing Deng, Xiaohui Shen, Liang-Chieh Chen · 字节跳动待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

图像自回归模型照搬语言模型按光栅顺序（从左上到右下）逐个预测token，每个token只能看到“上方和左边”，而图像本身是双向相关的，所以效果不如掩码生成和扩散模型。

方法

训练时以概率r把token序列随机打乱成别的分解顺序（加上目标位置的编码），r从1线性退火到0；模型先学会各种顺序下的预测、看到双向上下文，最后回到标准光栅顺序。

影响

在完全保留标准“下一个token预测”框架、可直接复用语言模型基础设施的前提下，ImageNet 256上FID达到1.48，超过当时的自回归、掩码和扩散方法。

方法

自回归模型把图像的联合概率分解成p(x) = Π p(x_i | x_<i)，分解顺序是人为选的。光栅顺序下，第i个token看不到它右边和下方的内容，这对语言自然，对图像却是限制。

RAR的做法很简单：训练每一步以概率r把序列随机排列成另一个顺序，再按新顺序做下一个token预测。为了让模型知道下一个要预测的是图上哪个位置，在输入里加上“目标位置嵌入”。r在训练开始时为1（完全随机顺序），随训练线性降到0（只用光栅顺序），作者称之为排列退火。这样模型实际上在最大化“所有分解顺序上的期望似然”，学会利用双向上下文；而训练结束时又收敛到固定的光栅顺序，推理时完全是标准自回归，可以用KV缓存等语言模型工具。

论文在ImageNet 256×256上报告FID 1.48，超过此前最好的自回归模型（如LlamaGen），也超过主流的扩散模型和MaskGIT并行掩码生成式掩码Transformer。

局限与后续

  • 仍是逐个token串行生成，256分辨率下也要几百步，推理速度不如下一尺度预测或少步扩散。

  • 分解顺序　把联合概率拆成一连串条件概率时，先生成哪个变量、后生成哪个变量的顺序。
