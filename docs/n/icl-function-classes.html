上下文学习函数类

What Can Transformers Learn In-Context? A Case Study of Simple Function Classes
2022.08论文延伸NeurIPS 2022Shivam Garg, Dimitris Tsipras, Percy Liang, Gregory Valiant · Stanford / UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GPT-3的上下文学习能力来自何处、能学会哪类任务，在真实大模型上太复杂，难以研究清楚。

方法

换成干净的玩具问题：从头训练Transformer，让它在提示里看到一组(x, f(x))样本后预测新输入的f值，f来自线性函数等函数类。

影响

把上下文学习变成可控的实验对象，催生了大量关于Transformer能否在上下文中实现梯度下降或其他学习算法的研究。

方法

背景：ICL即隐式贝叶斯推断用理论解释上下文学习，但缺乏直接的实验验证。

做法：作者设定一个明确的问题：给定函数类（线性函数、稀疏线性函数、两层神经网络、决策树等），训练时每个序列随机采样一个函数f和一组输入，序列是x1, f(x1), x2, f(x2)……，让Transformer预测下一个f值。训练完后，用新的函数测试，看它能不能只靠提示中的样例学会。

结果：标准Transformer可以从头训练出上下文学习线性函数的能力，性能与最优的最小二乘估计相当，并且在两种分布偏移下仍然成立。
