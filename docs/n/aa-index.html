Artificial Analysis智能指数

2024.01系统重要Artificial Analysis（独立模型评测公司）待核对
方法说明 ↗v5公告 ↗在交互版中打开（演化树、学习进度）

问题

厂商各自挑基准、用各自的提示和设置报分，数字之间无法直接比较；用户想知道“哪个模型更聪明、多贵、多快”时缺少一个第三方统一口径。

方法

由第三方用同一套提示和评分流程重跑一组基准，加权平均成一个智能指数，并同时公布价格、输出速度等指标；基准饱和就换掉，版本号随之升级。

影响

2025–2026年新模型发布时最常被引用的第三方综合分之一，开源模型“登顶AA榜”常成为新闻；它的换题历史本身就是一份基准饱和记录。

背景

到2023年，比较大模型主要靠三类东西：学术套件HELM、开源模型的Open LLM Leaderboard、人投票的Chatbot Arena。前两者偏学术、更新慢，后者反映的是聊天偏好而不是解题能力。厂商在技术报告里自报的分数又用了不同的提示、采样次数和评分脚本，同一个MMLU能差出好几个点。Artificial Analysis在2024年1月推出智能指数的第一版，定位是第三方、持续更新、同时给出能力和成本的统一口径。

方法

做法很直接：对每个模型用同样的提示模板、同样的评分器跑一组公开或私有的评测，多数按pass@1计分，部分评测重复多次取平均，再按权重合成一个0–100的分数。

指数的关键在于持续换题。官方版本记录显示：v1.x从2024年1月用到2025年2月；v2.1（2025年8月）加入IFBench和AIME 2025、去掉MATH-500和AIME 2024；v3.0（2025年9月）加入Terminal-Bench Hard和τ²-Bench Telecom等智能体任务；v4.0（2026年1月）去掉已饱和的MMLU-Pro、LiveCodeBench和AIME 2025，加入GDPval-AA、AA-Omniscience和CritPt，并改为按类别加权。当前v5.0.1分知识工作、编程、科学、通用四类，各占25%，包括AA-Briefcase、Terminal-Bench 4.0、CritPt v2、AA-Omniscience、HLE-Diamond等9项评测；官方称v5中60%的权重来自私有测试集或不公开答案的评测，以降低污染。部分评测（如GDPval-AA、AA-Briefcase）用多模型裁判两两比较再拟合Elo或Bradley-Terry分数。

结果

官方方法页称v5是自2026年1月v4以来最大的一次升级；同时推出用项目反应理论联合估计模型能力和题目难度的Progress Index。Hacker News上关于新模型“在AA指数上得多少分”的帖子在2026年多次获得数百赞。

后来的发展

它和Epoch能力指数ECI、LMArena公司化一起构成2025年后最常被引用的三类第三方榜：AA偏可复现的自动评测加成本，ECI偏跨基准统计拟合，竞技场偏人类偏好。几乎每次换版都是在承认某些考卷已经饱和或被污染，这让它的版本记录成了观察MMLU、AIME、LiveCodeBench等基准走向饱和的窗口。

读懂它需要的概念

基准、排行榜与SOTA 数据泄漏与基准污染 Elo评分与两两比较 方差、种子与统计显著性

本篇术语

  • pass@1　每题只取模型的一次回答判对错，多次重复时对各次结果取平均。
  • 项目反应理论　心理测量学方法，把每道题的难度和每个答题者的能力放进同一个统计模型里一起估计。
