DAPO

DAPO: An Open-Source LLM Reinforcement Learning System at Scale
2025.03论文重要Qiying Yu, Zheng Zhang, Ruofei Zhu, Yufeng Yuan et al. · 字节跳动Seed / 清华AIR待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

DeepSeek-R1公布了思路却省略了关键训练细节，社区照着用GRPO在Qwen2.5-32B上复现，AIME只有30分，远低于R1报告的47分，训练还会熵坍缩、不稳定。

方法

诊断出朴素GRPO的四个毛病并逐一修补：上下裁剪分开设、动态过滤无梯度的样本组、按token而非按样本平均损失、对超长回答做软惩罚；并完整开源代码和数据。

影响

用一半训练步数在同一底座上拿到AIME 50分，成为开源大规模推理RL最常用的基线配方之一，Clip-Higher和动态采样被后续工作广泛沿用。

背景

DeepSeek-R1证明了对基础模型做大规模可验证奖励的强化学习能激发长推理，它用的算法是GRPO：每道题采样一组回答，用组内奖励的标准化值作为优势，再套用PPO的裁剪目标。但论文没有给出足够的工程细节。DAPO团队在Qwen2.5-32B基础模型上用朴素GRPO训练，AIME 2024只得30分，而R1论文报告同一底座的RL结果为47分。他们观察到三类问题：熵坍缩（模型很快变得确定，同一题的多个回答几乎一模一样，失去探索）、奖励噪声、训练不稳定。

方法

DAPO在GRPO基础上去掉了KL惩罚项（长推理训练中模型本就该远离初始分布），并加入四项修改。

1. Clip-Higher（解耦裁剪）。PPO式目标对概率比r = π_新/π_旧裁剪到[1−ε, 1+ε]，通常ε=0.2。问题在于上界对低概率token特别苛刻：旧概率0.01的token一次最多涨到0.012，旧概率0.9的上限却是1.08，等于不受约束。于是“冷门但可能有用”的推理路径几乎无法被强化，熵迅速下降。DAPO把上下界分开，取ε_low=0.2、ε_high=0.28，给低概率token更多上升空间。

2. 动态采样。如果一组16个回答全对或全错，组内标准化后优势全为0，这组样本不产生任何梯度，却仍占着批次。DAPO持续过采样，丢掉这类组，直到批次里填满对错混合的组。

3. token级损失。GRPO先在每个回答内部对token平均、再在回答之间平均，于是长回答里每个token的权重更小，冗长、重复、胡言乱语的长回答得不到足够惩罚。DAPO改为对整个批次的全部token直接平均。

4. 超长奖励整形。超过长度上限被截断的回答原来直接判0分，可它的推理也许是对的，这给训练带来噪声。DAPO先把截断样本从损失中屏蔽，再改用软惩罚：最大长度16384 token之外设4096 token的缓冲区，越过上限越多，扣分越多。

此外，团队整理了DAPO-Math-17K数据集：1.7万道题，答案都改写成整数，便于规则判分。训练基于verl / HybridFlow RL训练框架框架。

结果

Qwen2.5-32B基础模型上，AIME 2024（32次平均）逐项累加的结果为：朴素GRPO 30 → 加超长过滤36 → 加Clip-Higher 38 → 加软超长惩罚41 → 加token级损失42 → 加动态采样50，超过DeepSeek-R1-Zero-Qwen-32B的47分，且只用了约一半的训练步数。论文还观察到，让熵保持缓慢上升有利于成绩提升。

后来的发展

DAPO与稍后的Dr. GRPO与R1-Zero再审视一起，把“GRPO要怎么改才能稳定训练长推理”变成公开知识。Clip-Higher和动态采样成为后续开源推理RL的常见组件；RL中的熵坍缩进一步分析了熵坍缩的成因，GSPO序列级优化把重要性比率从token级改为序列级以稳定混合专家模型训练，RL算力扩展规律在大规模实验中比较了这些设计的扩展性。

读懂它需要的概念

策略梯度 重要性采样 信息量与熵 KL散度 奖励设计与奖励投机

本篇术语

  • 熵坍缩　强化学习训练中策略的输出熵迅速下降，模型对同一题总给出几乎相同的回答，探索停止，成绩停滞。
  • 裁剪（clip）　PPO为防止一次更新太猛，把新旧策略的概率比限制在1附近的一个区间内，超出区间的部分不再提供梯度。

怎么学

先读PPO的裁剪目标和GRPO的组内优势。然后读DAPO论文第3节的四个小节，每节都配有训练曲线，对照表1的逐项提升。动手：在一个小模型的GRPO实现里分别打开Clip-Higher和动态采样，记录熵曲线和正确率的变化。
