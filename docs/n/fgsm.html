FGSM与线性解释

Explaining and Harnessing Adversarial Examples
2014.12论文重要ICLR 2015Ian Goodfellow, Jonathon Shlens, Christian Szegedy · Google待核对
arXiv ↗PyTorch官方FGSM教程 ↗在交互版中打开（演化树、学习进度）

问题

对抗样本发现了对抗样本，但用L-BFGS逐张求解很慢，也没人说得清它为什么存在；流行的猜测是深度网络“太非线性”或过拟合。

方法

指出原因恰恰相反：网络太线性。高维输入上每维改一点点，沿权重符号方向累加起来就是大变化。由此得到一步生成法：沿损失对输入梯度的符号走ε。

影响

对抗样本从此可以廉价批量生成，对抗训练变得可行；FGSM成为攻防研究最基本的基线，“线性解释”也成为讨论对抗脆弱性的出发点。

背景

对抗样本一年前报告：对任何一张图，都能找到人眼看不出差别、网络却分错的版本，而且这种扰动能骗过别的网络。但它用带约束的L-BFGS为每张图单独做迭代优化，代价很高；用对抗样本做训练只在小网络上试过。

更重要的是没有解释。当时流行的猜测是：深度网络高度非线性，在训练数据之间的空白区域里决策面弯得厉害，出现了一些“口袋”；或者是模型平均不够、正则化不够导致的过拟合。如果真是这样，对抗样本应该是某个模型偶然的毛病，很难解释为什么它们能在不同结构、不同训练集的模型之间迁移。

方法

线性解释。先看最简单的线性模型wᵀx。给输入加扰动η，输出变为wᵀx + wᵀη。如果限制每个像素最多改ε（即‖η‖∞ ≤ ε，见范数与距离），让输出变化最大的扰动是η = ε·sign(w)，输出增加ε·Σ|wᵢ|，大约是ε·m·n（m是权重的平均大小，n是维数）。

关键在于：ε不随维数变，输出变化却随n线性增长。一张MNIST图有784个像素，一张ImageNet图有十几万个，每个像素改一个8位量化级以下的量，加起来足以翻转判断。作者把这叫做“意外的隐写术”。

深度网络为什么也适用？因为ReLU、LSTM、maxout这些组件被刻意设计成分段线性或工作在近线性区间，正是为了好优化。线性带来了易训练，也带来了脆弱。

快速梯度符号法（FGSM）。把损失函数J在当前输入处线性化，最大化损失的L∞约束扰动是

x̃ = x + ε · sign(∇ₓ J(θ, x, y))

只需一次反向传播（见反向传播）。著名的例子是对GoogLeNet / Inception：一张以57.7%置信度判为“熊猫”的图，加上ε = 0.007（相当于8位图像的最小一级）的符号扰动后，被以99.3%置信度判为“长臂猿”。

对抗训练。把FGSM放进损失里，每一步都针对当前模型重新生成对抗样本：

J̃ = α·J(θ, x, y) + (1 − α)·J(θ, x + ε·sign(∇ₓJ), y)，论文取α = 0.5。

结果

在MNIST上取ε = 0.25，FGSM让浅层softmax分类器的错误率达到99.9%（平均置信度79.3%），让maxout网络错分89.4%（平均置信度97.6%）；在CIFAR-10上取ε = 0.1，卷积maxout网络错误率87.15%。

对抗训练让带dropout的maxout网络在MNIST正常测试集上的错误率从0.94%降到0.84%，调整后的模型平均做到0.782%；对FGSM对抗样本的错误率从89.4%降到17.9%。但被骗时模型依然很自信，错分样本的平均置信度是81.4%。论文还发现浅层RBF网络对这类扰动天然更不敏感，代价是泛化能力差。

后来的发展

FGSM成为几乎所有对抗鲁棒性论文的基线攻击和教学第一例。它的局限也很快暴露：只走一步太弱，用FGSM训练出来的模型可以“记住”这一种攻击。C&W攻击用更强的优化攻击击穿了一批防御；PGD对抗训练把FGSM改成多步迭代并投影回ε球，再用它做对抗训练，成为至今最主要的经验防御。梯度混淆的虚假安全进一步说明，很多看似挡住FGSM的防御只是把梯度弄乱了。

“线性导致脆弱”的解释后来被修正和补充：对抗样本是特征不是bug认为对抗扰动利用的是数据中真实存在、对预测有用但人类察觉不到的特征。符号梯度的思路也在别处出现，比如对大模型的对抗攻击自动化越狱攻击GCG同样从输入梯度出发。

容易误解的地方

  • FGSM生成的不是“最小”扰动，而是在固定ε下沿一阶近似损失增长最快的方向，往往离真正的最坏情况还差得远。
  • 能挡住FGSM不代表模型鲁棒。单步攻击很容易被梯度遮蔽类防御骗过，评估防御时必须用多步、自适应的攻击。
  • 对抗训练在这篇里是作为正则化器出现的，提升干净准确率只有零点几个百分点；它的主要价值后来被证明在鲁棒性上，而且鲁棒性和干净准确率之间常有取舍。

局限与后续

  • 单步攻击太弱，用FGSM做对抗训练的模型对多步迭代攻击仍然很脆弱，鲁棒性被高估。

读懂它需要的概念

导数、偏导与梯度 反向传播 范数与距离 内积与余弦相似度 损失函数 正则化与权重衰减

本篇术语

  • L∞约束　规定每个像素的改动绝对值都不超过ε，即最大的那一维也不超过ε。FGSM和后来的PGD都在这个约束下攻击。
  • 对抗训练　训练时不断针对当前模型生成对抗样本，并要求模型在这些样本上也分对，相当于让模型在一个小邻域里最坏情况下也表现好。
  • 梯度遮蔽　防御方法让梯度变得无用（为零、随机或不连续），使基于梯度的攻击失效，但模型并没有真正变鲁棒，换一种攻击就会被击穿。

怎么学

先弄懂导数、偏导与梯度和范数与距离里的L∞范数，再读原文第3、4节的线性论证，自己用一个线性模型推一遍ε·Σ|wᵢ|。然后跑PyTorch官方FGSM教程，在MNIST上画出准确率随ε下降的曲线；最后对比读PGD对抗训练，看多步攻击为什么更强。
