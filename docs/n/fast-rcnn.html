Fast R-CNN

Fast R-CNN
2015.04论文重要ICCV 2015Ross Girshick · Microsoft Research待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

R-CNN对每个候选框单独跑一遍CNN，用VGG16检测一张图要47秒；训练分三段，还要把特征写到硬盘，占几百GB。SPPnet共享了卷积计算，但训练仍是多阶段的，而且无法微调共享层之下的卷积层。

方法

整张图只过一次卷积，用RoI池化从共享特征图上为每个候选框抠出固定大小（7×7）的特征，再用一个网络同时输出类别和框修正，一个多任务损失端到端训练。

影响

用VGG16时训练比R-CNN快9倍、测试快213倍，精度还更高；“共享特征＋RoI池化＋多任务头”成为两阶段检测器的标准结构。

背景

R-CNN把检测精度大幅提高，但它的三个缺点很明显（论文原话总结）：

  • 训练是多阶段的：先微调CNN，再训练每类的SVM，最后训练框回归；
  • 训练费时费空间：用VGG16在VOC 2007的5000张图上提特征要2.5个GPU天，特征要占几百GB硬盘；
  • 检测慢：每个候选框都要单独过一遍网络，一张图47秒。

SPPnet的改进是：整张图只算一次卷积特征图，再在特征图上对每个候选框做空间金字塔池化，得到定长向量。这样测试快了很多，但它的训练仍是R-CNN式的三段流程，而且由于实现方式，微调时无法更新池化层之前的卷积层，限制了精度。

方法

整体流程。输入一张图和它的约2000个候选框（仍由选择性搜索生成）。整张图过一遍VGG的卷积层得到特征图；每个候选框投影到特征图上，经RoI池化变成7×7的固定大小特征，再过两个全连接层，最后分成两个并列的输出头：

  • 分类头：对K+1类（K个物体类加背景）做Softmax与logits；
  • 回归头：为每一类输出4个框修正量。

RoI池化。把候选框在特征图上对应的区域等分成7×7个格子，每格取最大值。无论候选框多大、长宽比如何，输出都是7×7×通道数，可以接全连接层。它就是只有一层的空间金字塔池化，而且能把梯度反传回卷积层。

多任务损失。L = L_cls(p, u) + λ·[u ≥ 1]·L_loc(tᵘ, v)。L_cls是真实类别u的对数损失；L_loc只对非背景框计算，用平滑L1：误差小于1时为0.5x²，否则为|x| − 0.5，比R-CNN用的L2损失对离群值更不敏感。分类和定位一起训练，不再需要SVM。

分层采样。每个小批量只取2张图、每张图取64个候选框（共128个）。同一张图的候选框共享卷积计算，所以训练效率比“128个框来自128张图”高得多。

截断SVD加速。检测时全连接层占了约45%的时间，用截断奇异值分解把大矩阵拆成两个小矩阵（见低秩近似），速度再提升且精度几乎不变。

结果

VGG16、VOC 2007测试集：Fast R-CNN mAP 66.9%，R-CNN 66.0%，SPPnet 63.1%。训练时间从R-CNN的84小时降到9.5小时（9倍）；检测从47秒降到约0.32秒/图（不含候选框生成，加截断SVD后为R-CNN的213倍）。比SPPnet训练快2.7倍、测试快约10倍。VOC 2012上mAP 65.7%（加额外数据68.4%），为当时最佳。实验还表明，微调卷积层能把mAP从61.4%提到66.9%，说明SPPnet不能微调卷积层是精度瓶颈之一。

后来的发展

两个月后，Faster R-CNN把候选框生成也变成网络的一部分，构成完整的端到端检测器。RoI池化被Mask R-CNN改进为没有取整误差的RoIAlign；平滑L1损失和“分类＋回归”双头结构被几乎所有后续检测器沿用，包括SSD、Focal Loss与RetinaNet等单阶段方法。

读懂它需要的概念

卷积层、池化与感受野 IoU与mAP 锚框与非极大值抑制 损失函数 预训练与微调 低秩近似

本篇术语

  • RoI池化　把特征图上任意大小的一块区域等分成固定的H×W个格子，每格取最大值，从而得到固定尺寸的特征。RoI指感兴趣区域。
  • 平滑L1损失　误差小时像平方损失（处处可导、靠近0时梯度变小），误差大时像绝对值损失（梯度不会因离群值而爆炸）。
  • 多任务损失　把几个任务（这里是分类和框回归）的损失加权相加，用同一个网络同时优化。

怎么学

先读R-CNN，理解它的三段式流程为什么慢。读原文第2节（RoI池化、多任务损失、分层采样）。动手：用torchvision.ops.roi_pool在一张特征图上对几个不同大小的框做池化，确认输出形状一致；再读torchvision的Faster R-CNN代码中RoIHeads部分，找到分类头和回归头。
