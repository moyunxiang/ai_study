Extropic热力学采样芯片

An efficient probabilistic hardware architecture for diffusion-like models
2025.10论文延伸arXiv 2025Andraž Jelinčič, Owen Lockwood, Akhil Garlapati, Peter Schillinger, Isaac Chuang, Guillaume Verdon, Trevor McCourt · Extropic待核对
arXiv ↗arXiv HTML全文 ↗在交互版中打开（演化树、学习进度）

问题

GPU用确定性的浮点运算去模拟随机采样，扩散模型生成一张图要做大量矩阵乘法，能耗很高；以往的随机计算硬件要么模型太弱，要么器件太奇特无法量产。

方法

用普通晶体管的热噪声直接产生随机比特，在芯片上实现稀疏的玻尔兹曼机做吉布斯采样，再把多个这样的能量模型串成去噪步骤（DTM）。

影响

论文称系统级分析显示，在简单图像基准上能以约万分之一的能耗达到GPU的水平；配合X0原型芯片发布，“热力学计算”成为2025年底被热议的非冯·诺依曼路线。

方法

论文v1于2025年10月28日提交arXiv，Extropic同期发布X0测试芯片和XTR-0桌面开发平台。核心有两层：

  • 硬件层：每个节点是一个二值随机变量，由工作在亚阈值区的晶体管利用散粒噪声实现，输出为1的概率是输入电压的sigmoid函数。节点排成稀疏、只与邻居相连的网格，构成玻尔兹曼机；网格是二部图，一半节点可以同时更新，从而高速做吉布斯采样。
  • 模型层：单个基于能量的学习模型难以同时做到表达力强和采样混合快，论文提出去噪热力学模型（DTM）：仿照DDPM，把生成拆成多步去噪，每一步只需一个较简单、易采样的能量模型。

实验在二值化Fashion-MNIST上用FID评估。约1万倍的节能是基于随机数发生器实测与工艺仿真建立的能耗模型推算的，DTM本身在经典计算机上仿真运行，并非在流片芯片上实测。

局限与后续

  • 节能结论来自能耗模型推算和仿真，最大的DTM只有约5万个节点，只在二值化的小图像上验证，CIFAR-10上的尝试作者自称是初步的。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只适用于能写成能量模型采样的任务，与当前以Transformer为主的大模型如何结合尚不清楚；作者全部来自Extropic。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    DDPM2020.06 · 生成
    借用扩散模型“多步去噪”的结构，把每一步换成硬件上的能量模型。
  • 使用
    玻尔兹曼机1985 · 基础
    芯片上直接实现稀疏连接的玻尔兹曼机，用物理噪声完成吉布斯采样。
  • 改进
    基于能量的学习2006 · 基础
    用分步去噪缓解单一能量模型表达力与采样混合速度难以兼得的问题。
  • 竞争
    模拟存内计算芯片2023.08 · 硬件
    同为利用物理过程计算的非数字路线，一个做乘加，一个直接做采样。

读懂它需要的概念

能量模型与玻尔兹曼分布 蒙特卡洛采样 扩散：前向加噪与反向去噪 马尔可夫性与马尔可夫链

怎么学

先补能量模型与玻尔兹曼分布和蒙特卡洛采样理解吉布斯采样，再读arXiv论文第2–3节的DTM定义，注意区分实测数据和推算数据。
