CoVe上下文词向量

Learned in Translation: Contextualized Word Vectors
2017.08论文延伸NeurIPS 2017McCann, Bradbury, Xiong, Socher · Salesforce Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

当时NLP通常只预训练最底层的词向量，深层网络仍从随机初始化开始，不像视觉有ImageNet预训练。

方法

用机器翻译训练出的LSTM编码器给每个词输出带上下文的向量（CoVe），拼在GloVe词向量后面供下游模型使用。

影响

首次证明上下文相关的表示可迁移到多种任务，直接启发ELMo。

方法

先在带Luong注意力的seq2seq翻译模型上训练一个两层BiLSTM编码器，之后冻结它。对下游任务，每个词的输入变成[GloVe(w); CoVe(w)]，其中CoVe是编码器对该词的输出，包含上下文信息（比如区分一词多义）。摘要称在情感分析（SST、IMDb）、问题分类（TREC）、蕴含（SNLI）和问答（SQuAD）上，加入CoVe比只用词向量和字符向量都有提升，并在细粒度情感分析和蕴含上达到当时最佳。

局限与后续

  • 受限于翻译数据的规模，需要带标注的平行语料作预训练。
    后来针对它的工作　ELMo
  • 预训练任务是翻译，表示只含与翻译相关的信息。
    后来针对它的工作　BERT

它建立在什么之上

  • 改进
    word2vec2013.01 · NLP 已核对
    每个词只有一个固定向量，“bank”是银行还是河岸、“苹果”是水果还是公司都无法区分。
  • 延续
    GloVe2014.10 · NLP
    在静态GloVe向量上拼接上下文向量，使同一词在不同句子里表示不同。
  • 使用
    Luong注意力2015.08 · NLP
    用带Luong注意力的seq2seq翻译模型作为预训练来源。

后来的相关工作

  • 延续
    ELMo2018.02 · LLM 已核对
    同样做上下文词向量，但用无需平行语料的语言模型代替翻译编码器，并混合所有层而非只用顶层。
  • 改进
    BERT2018.10 · LLM
    预训练任务是翻译，表示只含与翻译相关的信息。
  • 竞争
    ULMFiT2018.01 · LLM
    CoVe把翻译模型的编码器当固定特征；ULMFiT整体微调语言模型，在IMDb上错误率从8.2%降到4.6%。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测
    CoVe是论文评测的另一种预训练表示基线，GLUE上效果不如ELMo。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
