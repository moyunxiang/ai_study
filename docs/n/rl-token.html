RL Token：VLA在线RL

RL Token: Bootstrapping Online RL with Vision-Language-Action Models
2026.04论文延伸arXiv 2026Charles Xu, Jost Tobias Springenberg, Michael Equi, Ali Amin, Adnan Esmail, Sergey Levine, Liyiming Ke · Physical Intelligence待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

VLA开箱即能做很多操作，但要达到真实任务需要的精度和速度还得用RL微调；直接对几十亿参数的VLA做在线RL又太慢、太费真机样本。

方法

让VLA额外输出一个压缩的“RL token”作状态表示，冻结VLA，只在其上训练小型actor-critic头，修正VLA给出的参考动作块。

影响

在拧螺丝、扎带、充电器插入、网线插入四个真机任务上，几分钟到几小时练习后，最难阶段速度最高提升约3倍，部分任务超过人类遥操作速度。

方法

卡在哪：π*0.6与RECAP里描述的π0.6等VLA已有很强的通用能力，但在插网线、拧螺丝这类精细接触任务上不够快也不够稳。HIL-SERL人在回路RL这类真机RL方法样本高效，但用的是小网络、单步动作，在长时序稀疏奖励任务上学不动；对整个VLA做RL又过于笨重。

做法：第一步，在VLA最后一层的token嵌入后接一个小编码器Transformer，并加入一个可学习的 <rl> 嵌入，该位置的输出就是RL token；再用一个解码器只凭这个token自回归重建VLA的嵌入，用平方误差训练。这个瓶颈迫使RL token保留与任务相关的预训练知识。之后VLA和编码器都冻结。第二步，在RL token、本体状态之上训练TD3式的off-policy actor-critic：评论家看RL token、本体状态和动作块；演员额外接收VLA给出的参考动作块ã，输出修正后的动作。演员目标是 max Q(s,a) − β‖a − ã‖²，即在提高价值的同时别离VLA太远；训练时还以50%概率把参考动作置零，防止演员只会照抄。RL动作块长10步（VLA是50步），在50Hz下控制14维动作。

结果：每个任务约15分钟到5小时真机数据（400–1000个回合）。拧螺丝的关键阶段成功率从20%提到65%、速度最高3倍；网线插入在保持成功率的同时完成步数减半，一半RL回合的关键阶段比所有遥操作示范都快。对比中HIL-SERL学不动，DAgger成功率持平但速度受限于人类示范，DSRL成功率持平但提速明显更小。

它建立在什么之上

  • 竞争
    DAgger2010.11 · RL
    DAgger靠人类纠正数据改进，成功率与RLT持平但速度被人类示范限制；RL能超过示范者速度。
  • 使用
    TD32018.02 · RL
    actor-critic头采用TD3式的双Q取最小值和延迟演员更新。
  • 使用
    π*0.6与RECAP2025.11 · 具身·世界模型
    以π0.6 VLA为基座；π*0.6用离线优势条件化改进策略，RL Token改为在冻结的π0.6上接小头做在线RL。
  • 改进
    HIL-SERL人在回路RL2024.10 · 具身·世界模型
    HIL-SERL的小网络单步策略在长时序稀疏奖励任务上学不动；RLT借VLA表示和参考动作块解决了样本效率问题。

读懂它需要的概念

VLA与WAM的基本结构 Actor-Critic与优势函数 on-policy与off-policy 动作表示：离散token、连续动作与动作块 自编码器 正则化与权重衰减

本篇术语

  • RL token　从VLA内部表示中压缩出来的一个向量，作为小型RL网络的输入状态，既保留预训练知识又足够小，便于快速学习。
  • 参考动作锚定　在RL目标里加一项惩罚，让学到的动作不偏离VLA原本给出的动作太远，防止RL把策略带崩。

怎么学

先读HIL-SERL人在回路RL了解真机off-policy RL，复习TD3；再读原文第3节RL token的编码-解码训练和actor目标，看网线插入任务的消融。
