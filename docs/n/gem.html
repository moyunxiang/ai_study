GEM梯度情景记忆

Gradient Episodic Memory for Continual Learning
2017.06论文延伸NeurIPS 2017David Lopez-Paz, Marc'Aurelio Ranzato · Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

持续学习方法大多只报告最终的平均准确率，看不出它们是在旧任务上遗忘了还是在新任务上学得慢；而且已有方法只想着“不遗忘”，没有考虑新知识反过来帮助旧任务。

方法

先定义一套评测指标（平均准确率、后向迁移、前向迁移）；再提出GEM：为每个旧任务保存少量样本作为情景记忆，学新样本时如果梯度会让任何旧任务的记忆损失上升，就把梯度投影到不伤害它们的最近方向。

影响

后向/前向迁移指标成为持续学习论文的标准报告项；GEM和随后的A-GEM是基于记忆约束梯度方向这一类方法的代表。

方法

设定是模型一次看一个样本、只看一遍，任务一个接一个到来。评测上，作者构造矩阵R，R_{i,j}是学完第i个任务后在第j个任务上的测试准确率，据此定义：平均准确率；后向迁移BWT（学了后面的任务，前面任务的准确率平均变了多少，负值即遗忘）；前向迁移FWT（学前面的任务对还没学的任务有多大帮助）。

GEM为每个旧任务k存一小块记忆M_k。学新样本时算出梯度g，同时算出每块记忆上的梯度g_k。约束是⟨g, g_k⟩ ≥ 0对所有k成立，也就是这一步不会让任何旧任务的记忆损失变大。若g违反约束，就求解一个小的二次规划，找到满足所有约束、离g最近的梯度g̃，用它更新。这样记忆既用于防止遗忘，也允许正向的后向迁移。摘要报告：在MNIST变体和CIFAR-100上，GEM相比当时最好的方法表现更强。

局限与后续

  • 每一步都要在所有旧任务的记忆上算梯度并解二次规划，任务数多时代价很高。
