Microsoft Maia 200

2026.01硬件延伸Microsoft待核对
Microsoft官方博客 ↗在交互版中打开（演化树、学习进度）

问题

Microsoft的第一代Maia 100没能大规模取代GPU，推理成本仍主要流向NVIDIA。

方法

Maia 200是为推理设计的3nm加速器，配216GB HBM3e和272MB片上SRAM，原生FP8/FP4。

影响

它是Microsoft首个声称在部分指标上超过同代云厂商自研芯片的加速器，用于服务GPT-5.2等模型。

方法

2026年1月26日Microsoft宣布Maia 200。官方称：基于台积电3nm工艺，带原生FP8/FP4张量核心，216GB HBM3e、带宽7TB/s，272MB片上SRAM；FP4性能是第三代Amazon Trainium的3倍，FP8性能高于Google第七代TPU；相比当前机群中最新的硬件，每美元性能高30%。它将服务包括OpenAI最新GPT-5.2在内的多个模型，并用于Microsoft Foundry和Microsoft 365 Copilot。

它属于云厂商自研AI芯片趋势，并使用与台积电N3同级的3nm工艺。注意：以上对比均为厂商自称，没有独立评测。2026年10月Microsoft又宣布把Maia扩展到多吉瓦部署，并展示多芯粒的Maia 300（SiliconANGLE、CNBC标题）。
