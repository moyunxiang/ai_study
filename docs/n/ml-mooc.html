吴恩达公开课与Coursera

2011.10事件延伸Andrew Ng · Stanford，后为Coursera待核对
Coursera ↗在交互版中打开（演化树、学习进度）

问题

机器学习的好课程只对少数名校学生开放，其他人只能自己啃论文和教材。

方法

2011年秋天Andrew Ng和Daphne Koller把斯坦福的课程放到线上免费开放，随后在2012年创办Coursera，机器学习课成为它的代表课程。

影响

让数以万计甚至更多的人通过网络系统学习机器学习，成为深度学习热潮前后补充人才的重要来源。

方法

据Wikipedia，Ng和Koller在2011年秋季开始在线开设斯坦福课程，随后离开斯坦福创办Coursera（2012年创办）；最早提供内容的大学是普林斯顿、斯坦福、密歇根和宾夕法尼亚。机器学习课程的内容在支持向量机、反向传播等传统方法的基础上，面向有一定编程基础的初学者。具体选课人数没有核对，因此不写。

它开创的“把顶级教授的课搬上线”的模式，后来延伸到斯坦福CS231n公开讲义、fast.ai等课程和3Blue1Brown神经网络系列等科普视频，构成了这个站点读者的主要自学路径。
