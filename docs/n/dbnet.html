DBNet可微二值化

Real-time Scene Text Detection with Differentiable Binarization
2019.11论文延伸AAAI 2020Minghui Liao, Zhaoyi Wan, Cong Yao, Kai Chen, Xiang Bai · 华中科技大学 / 旷视 / 上海交通大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

弯曲文字用分割做检测最准，但要把概率图二值化成文字区域，固定阈值的后处理既复杂又不能训练，拖慢速度。

方法

让网络在预测文字概率图之外再预测一张阈值图，用一个可求导的近似阶跃函数做二值化，把阈值也交给训练学习。

影响

以很轻的骨干就能又快又准地检测任意形状文字，被PaddleOCR等工业OCR系统采用为默认检测器。

方法

DBNet是一个分割网络：骨干加特征金字塔，输出与图像同尺寸（下采样后）的两张图——概率图P（每个像素属于文字的概率）和阈值图T。普通做法是“P大于固定阈值就算文字”，这个硬阈值不可导。本文改成可微二值化：B = 1 / (1 + e^(−k(P − T)))，k取较大值（如50），使它接近阶跃函数又处处可导。这样阈值随位置变化、可以学习，文字边界处的阈值更高，相邻文字更容易被分开。训练时概率图、阈值图和近似二值图三者都有监督；推理时只需概率图配一个简单的框生成步骤，后处理很省。

摘要报告在五个基准上同时取得精度和速度的领先结果；用ResNet-18骨干，在MSRA-TD500上F值82.8、速度62帧每秒。

局限与后续

  • 只负责找文字区域，识别还要接一个单独的识别模型，两阶段误差会叠加。
    后来针对它的工作　PaddleOCR / PP-OCR
  • 对极小或排得很密的文字，收缩后的文字核可能粘连或丢失。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    特征金字塔FPN2016.12 · 视觉
    用特征金字塔融合多尺度特征得到高分辨率概率图。
  • 使用
    全卷积网络FCN2014.11 · 视觉
    本质上是FCN式的逐像素分割网络，把文字检测转成预测文字概率图。
  • 使用
    可变形卷积2017.03 · 视觉
    骨干中加入可变形卷积，以适应长宽比变化大的文字。
  • 竞争
    EAST文字检测2017.04 · 视觉
    EAST直接回归四边形，难以处理弯曲文字；DBNet走分割路线，可以检测任意形状。
  • 改进
    CRAFT字符级文字检测2019.04 · 视觉
    靠后处理把字符连成单词，字符间距大或字符粘连时容易切错；推理也比分割式检测器慢。

读懂它需要的概念

本篇术语

  • 二值化　把0到1之间的概率图按阈值变成只有0和1的图，1表示属于文字。

怎么学

先了解语义分割与FPN，再读DBNet第3节的可微二值化公式；用PaddleOCR的DB检测模型跑几张街景照片，查看概率图与阈值图。
