实例归一化InstanceNorm

Instance Normalization: The Missing Ingredient for Fast Stylization
2016.07论文延伸Dmitry Ulyanov, Andrea Vedaldi, Victor Lempitsky · Skoltech / University of Oxford待核对
arXiv ↗扩展版 arXiv:1701.02096 ↗在交互版中打开（演化树、学习进度）

问题

用前馈网络做快速风格迁移（一次前向就出图）比逐图优化快得多，但画质明显不如神经风格迁移的迭代优化结果。

方法

把风格化网络里的Batch Normalization换成实例归一化：对每张图、每个通道单独减均值除标准差，并且在测试时也这样做。

影响

一个很小的改动让前馈风格迁移的质量大幅提升；实例归一化随后成为风格迁移、CycleGAN等图像翻译网络的标准部件，也是AdaIN任意风格迁移和StyleGAN风格注入的起点。

方法

感知损失和Ulyanov等人此前的纹理网络都训练一个生成网络：输入内容图，输出风格化后的图，训练时用Gatys式的风格损失监督。它们沿用了批归一化，即在一个小批量里统计每个通道的均值和方差。

作者的观察是：风格化结果本不应依赖内容图的对比度，而批归一化把整批图混在一起统计，单张图的对比度信息会残留到输出里。改为实例归一化后，对单张图x的第c个通道，在其所有空间位置上计算均值μ和方差σ²，输出(x−μ)/√(σ²+ε)再乘以可学习的缩放、加偏移。这相当于网络里自带一个“去掉对比度”的操作。关键是训练和测试都用当前这张图的统计量，而不是像批归一化那样在测试时换成整个训练集的滑动平均。

论文展示，同一架构只做这一处替换，风格化图像的质量就明显改善，可以用来训练实时生成的高性能网络。

局限与后续

  • 一个网络仍只能学一种（或固定几种）风格，换风格要重新训练。
    后来针对它的工作　AdaIN任意风格迁移
  • 逐图逐通道归一化会抹掉特征的绝对幅度信息，后来在StyleGAN2里被指出会造成水滴状伪影。
    后来针对它的工作　StyleGAN2

它建立在什么之上

  • 延续
    Batch Normalization2015.02 · 基础
    保留归一化加仿射变换的形式，但把统计范围从一个批次缩小到单张图的单个通道。
  • 使用
    神经风格迁移2015.08 · 生成
    训练目标仍是Gatys式的Gram矩阵风格损失加内容损失。
  • 使用
    CNN纹理合成2015.05 · 生成
    所改进的纹理网络就是要前馈地逼近Gatys纹理合成的结果。
  • 改进
    感知损失2016.03 · 视觉
    改善前馈风格迁移网络画质不如迭代优化的问题。

后来的相关工作

  • 改进
    StyleGAN22019.12 · 生成
    逐图逐通道归一化会抹掉特征的绝对幅度信息，后来在StyleGAN2里被指出会造成水滴状伪影。
  • 延续
    AdaIN任意风格迁移2017.03 · 生成
    把实例归一化中固定可学习的缩放和偏移，换成由风格图特征统计量动态给出。

本篇术语

  • 前馈风格迁移　先训练一个网络，之后对任意内容图只需一次前向计算就输出风格化结果，而不是每张图都迭代优化。

怎么学

先弄懂批归一化在训练和测试时的差别 → 读这篇只有几页的短文 → 在一个风格迁移代码里把BatchNorm2d换成InstanceNorm2d对比效果。
