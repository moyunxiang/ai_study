YOLOv9

YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information
2024.02论文延伸ECCV 2024Chien-Yao Wang, I-Hau Yeh, Hong-Yuan Mark Liao · 中研院资讯所待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

数据经过层层卷积会丢掉信息（信息瓶颈），轻量检测器尤其如此，导致算损失时依据的特征已不完整，梯度也就不可靠。

方法

训练时加一条可逆的辅助分支，保证损失能看到完整的输入信息，从而给主干提供可靠梯度（PGI）；推理时把辅助分支去掉，不增加开销。

影响

与新的GELAN骨干一起，在只用普通卷积的情况下超过同期基于深度可分离卷积的实时检测器，成为YOLOv7团队的下一代YOLO。

方法

YOLOv9有两个部件。

  • PGI（可编程梯度信息）：作者从信息瓶颈的角度论证，深层网络的特征会逐层丢失与目标相关的信息。PGI在训练时附加一条“辅助可逆分支”，它能保留输入的完整信息，并把由此计算的梯度送回主干；另有多级辅助信息，让不同大小目标的预测头都得到合适的梯度。推理时辅助分支整个拿掉，所以部署成本不变。
  • GELAN：把YOLOv7的ELAN层聚合结构推广为“广义”版本，各分支内部可以换成任意计算块，并按梯度路径规划设计，在参数量、计算量和精度间取平衡。

摘要报告：GELAN只用普通卷积就比基于深度可分离卷积的先进方法参数利用率更高；PGI适用于从轻量到大型的各种模型，使从零训练的模型超过用大数据集预训练的先进模型，结果在MS COCO目标检测上验证。

本篇术语

  • 可逆函数　输出能完整反推出输入的变换，经过它不会丢失信息。
  • 辅助分支　只在训练时存在、帮主干获得更好梯度的额外网络部分，推理时删除。

怎么学

先了解YOLO基本结构和YOLOv7的ELAN，再读YOLOv9第3–4节的PGI与GELAN；运行官方代码对比带与不带PGI训练的小模型精度。
