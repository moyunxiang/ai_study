软件3.0

Software Is Changing (Again)
2025.06思想延伸Andrej Karpathy · Y Combinator AI Startup School主题演讲待核对
Hugging Face博客：What's Software 3.0?（演讲摘要） ↗Latent Space：Andrej Karpathy on Software 3.0（含逐字稿） ↗在交互版中打开（演化树、学习进度）

问题

大模型出现后，“写程序”的含义在变：越来越多的功能不是写代码、也不是训练网络，而是用自然语言提示模型完成。原有的“软件2.0”框架没有覆盖这种做法。

方法

Karpathy把软件分成三代：1.0是人手写代码，2.0是训练神经网络的权重，3.0是用自然语言提示大模型；并把今天的LLM比作1960年代的分时操作系统，主张做“部分自主”的产品而不是全自动智能体。

影响

“软件3.0”和“钢铁侠战衣而非钢铁侠机器人”成为2025年讨论AI编程和智能体产品形态时的高频说法。

方法

2025年6月17日，Karpathy在旧金山YC的AI Startup School上演讲，题为《Software Is Changing (Again)》。它是他2017年软件2.0一文的更新：

  • 三代软件：1.0写代码，2.0训练神经网络，3.0“用自然语言提示LLM”，提示词本身就是程序。
  • LLM像操作系统：今天的大模型贵而集中在云端，用户通过分时方式共享，像1960年代的计算机，人们只是“瘦客户端”。
  • “人的精灵”：他把LLM称作会出错的“人的精灵”（people spirits），知识超人，但会幻觉、没有长期记忆。
  • 部分自主：与其追求全自动，不如像钢铁侠战衣那样放大人的能力，让“AI生成—人快速验证”的循环尽量快，并以Cursor这类工具为例。

演讲与年初的Vibe Coding一说相互呼应，前者讲新的编程范式，后者讲个人怎样用它写程序。

局限与后续

  • 这是类比和观点而不是可检验的论断：LLM像操作系统、提示词就是程序，都没有给出可以衡量的标准。

  • 延续
