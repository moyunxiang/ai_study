CTC

Connectionist Temporal Classification: Labelling Unsegmented Sequence Data with Recurrent Neural Networks
2006论文重要ICML 2006Alex Graves, Santiago Fernández, Faustino Gomez, Jürgen Schmidhuber · IDSIA（瑞士）待核对
论文（ACM） ↗论文PDF ↗Distill：Sequence Modeling with CTC ↗在交互版中打开（演化树、学习进度）

问题

用神经网络识别语音，训练时需要知道每一帧对应哪个音素；这种逐帧标签只能靠人工切分或另一个HMM系统强制对齐得到，输出也要靠HMM后处理才能变成音素串。

方法

让网络每帧输出“某个标签或空白”的概率，规定“合并重复、删掉空白”就得到最终序列，把所有能归并成正确答案的对齐路径的概率加起来作为目标，用前向-后向动态规划高效计算并求梯度。

影响

第一次让循环网络只用“这句话是什么”的标注就能直接训练成识别器，不需要逐帧对齐和HMM。它是端到端语音识别的起点之一，至今仍是识别、手写识别、语音自监督微调中最常用的损失函数之一。

背景

2006年的语音识别主流是HMM统计语音识别加高斯混合。混合NN/HMM已经证明神经网络打分更好，但网络只是HMM的一个部件：训练前先用HMM做强制对齐，给每一帧打上音素标签，网络按逐帧分类来学；识别时网络的输出还要交给HMM解码。网络学的目标（每帧分类对不对）和真正关心的目标（整句音素串对不对）并不一致，性能也受限于做对齐的那个HMM。

LSTM和双向RNN已经能很好地利用长上下文。问题是：输入几百帧、输出几十个音素，长度不等、对应关系未知（见输入输出不等长时的对齐），能不能直接用音素串这一级的标注训练网络？

方法

输出层。设标签表有K个音素，网络每帧输出一个K+1维的Softmax与logits分布，多出来的一类是“空白”（blank，记为-），意思是“这一帧不输出新标签”。T帧输入就得到T个分布。

路径与归并。每帧挑一个符号，得到一条长度为T的路径π。规定归并函数B：先合并相邻的重复符号，再删去所有空白。例如B(aa-abb) = aab，B(-a--b-) = ab。空白的作用是区分“同一个音拉长”和“连续两个相同的音”：aa归并成a，a-a才是aa。

目标函数。假设给定输入时各帧输出相互独立，一条路径的概率是各帧概率之积；标签序列l的概率是所有能归并成它的路径之和：

p(l | x) = Σ_{π: B(π)=l} Π_t y^t_{π_t}

训练目标是最小化−ln p(l | x)。这里不需要知道哪个音素在哪一帧——所有合法对齐都被一起考虑了。

前向-后向。路径数随T指数增长，不能枚举。在标签序列的首尾和每两个标签之间插入空白，得到长度2|l|+1的扩展序列，然后像HMM的前向算法一样逐帧递推α_t(s)：时刻t走到扩展序列第s个位置的所有路径前缀的总概率。允许的跳转只有三种：留在原地、前进一格、跳过一个空白（两个相邻标签不同时）。再算后向变量β_t(s)，两者相乘就得到每帧每个符号的后验占用，进而得到对网络输出的梯度，用随时间反向传播BPTT反传。总计算量与T·|l|成正比（见动态规划）。

解码。最简单的是“最优路径”：每帧取概率最大的符号再归并。论文还提出了一种前缀搜索，在空白概率很高的位置把输出切成小段分别搜索，结果略好。

结果

在TIMIT音素识别（61个音素，4620句训练、1680句测试）上，输入是每10毫秒一帧的12个MFCC加对数能量及其一阶差分共26维，网络是每个方向100个单元的双向LSTM，约11.5万个权重。标签错误率：上下文无关HMM 38.85%，上下文相关HMM 35.21%，同样网络结构的BLSTM/HMM混合33.84%，加权误差的混合系统31.57%，CTC最优路径解码31.47%，CTC前缀搜索30.51%（5次运行平均）。HMM基线用HTK工具包训练（据论文表1）。

后来的发展

CTC最初并非主流：大词表任务上CD-DNN-HMM等混合系统更强。转折来自规模：深层双向LSTM识别用深层双向LSTM加CTC刷新了TIMIT结果，Deep Speech端到端识别和Deep Speech 2用CTC在大规模数据上做字符级端到端识别；Graves本人的RNN-Transducer则针对CTC输出相互独立的缺陷加了预测网络。

今天CTC仍被大量使用：wav2vec 2.0、HuBERT等自监督模型微调时的标准损失，ESPnet、WeNet中与注意力解码器联合训练，手写识别和OCR也常用它。

容易误解的地方

  • CTC假设给定输入后各帧输出相互独立，所以它自身是一个很弱的语言模型；实际系统通常要配外部语言模型（常用WFST或束搜索融合）才能拿到好的词错误率。
  • CTC要求输出长度不超过输入帧数（遇到连续相同标签还要多留一帧放空白），对语音没问题，但不能直接用于输出比输入长的任务。
  • 训练好的CTC网络输出非常“尖”：绝大多数帧都是空白，标签只在少数帧上以尖峰出现，因此不能直接把它当作精确的时间对齐。

局限与后续

  • 各帧输出条件独立，模型内部无法利用已输出的标签，必须依赖外部语言模型才能纠正同音、拼写类错误。
    后来针对它的工作　RNN-Transducer Listen, Attend and Spell
  • 只在TIMIT这样的小规模朗读语音音素识别上验证，在大词表、大数据的单词或字符级识别上能否胜过混合系统尚不清楚。
    后来针对它的工作　深层双向LSTM识别 Deep Speech 2
  • 用的是双向LSTM，必须等整句结束才能输出，无法流式识别。
    后来针对它的工作　RNN-Transducer 端侧流式RNN-T
  • 输出呈尖峰状、主要是空白，标签出现的时刻与真实发音位置有偏移，不适合需要精确时间戳的应用。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    LSTM1997 · 基础 待核对
    网络是带遗忘门和窥视孔连接的双向LSTM，负责在长上下文中给每帧打分。
  • 使用
    Baum-Welch算法1970 · 语音
    目标函数的计算借用了HMM的前向-后向递推，只是状态换成了插入空白后的标签序列。
  • 改进
    HMM统计语音识别1976 · 语音
    不再需要HMM提供逐帧对齐和后处理解码，网络直接从未切分的语音学会输出音素串。
  • 改进
    时延神经网络TDNN1989.03 · 语音
    只能对人工截好、以元音起点为中心的固定长度片段做分类，不能直接处理连续语音中音素的切分和整句识别。
  • 使用
    TIMIT语音语料1990 · 数据·评测
    所有实验在TIMIT音素识别上进行，与HMM及混合系统比较。
  • 改进
    混合NN/HMM1994 · 语音
    混合系统按另一个系统给的逐帧标签训练，目标与整句识别错误不一致；CTC直接最大化正确标签序列的概率，在同样的BLSTM结构上错误率更低。
  • 改进
    LSTM遗忘门1999.09 · 基础
    只在人工合成的文法和时序分类任务上验证，网络只有4个记忆块、几百个权重，能否用于真实语音、语言数据尚不清楚。
  • 改进
    WFST解码器2002.01 · 语音
    声学模型、词典和语言模型仍是分别训练的，构图只是把它们组合起来，没有联合优化识别错误率。
  • 使用
    双向RNN1997 · 基础
    前后两个方向的循环层让每帧的输出同时看到过去和未来的语音。

读懂它需要的概念

循环网络与隐状态 Softmax与logits 动态规划 输入输出不等长时的对齐 隐马尔可夫模型 交叉熵

本篇术语

  • 空白符（blank）　CTC额外加的一个输出类别，表示“这一帧不输出标签”，也用来分隔相邻的相同标签。
  • 归并函数B　把逐帧路径变成最终标签序列的规则：先合并相邻重复符号，再删去空白。
  • 标签错误率（LER）　预测标签序列与正确序列之间的编辑距离除以正确序列长度，音素识别中也叫音素错误率。

怎么学

先补动态规划、隐马尔可夫模型的前向算法和输入输出不等长时的对齐。然后读Distill的CTC文章，再读原论文第3–4节的前向-后向推导。动手：用numpy手写一个CTC前向算法，对一个5帧、2个标签的小例子枚举所有路径验证结果，再与PyTorch的nn.CTCLoss对比。
