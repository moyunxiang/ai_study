SGLD随机梯度朗之万

Bayesian Learning via Stochastic Gradient Langevin Dynamics
2011.06论文延伸ICML 2011Max Welling, Yee Whye Teh · 加州大学欧文分校、伦敦大学学院Gatsby单元待核对
论文PDF ↗在交互版中打开（演化树、学习进度）

问题

贝叶斯方法要从参数后验分布里采样，传统Metropolis采样与MCMC每一步都要在全部数据上算一遍，数据量一大就跑不动；而随机梯度下降能处理大数据，却只给出一个点估计，没有不确定性。

方法

在小批量随机梯度下降的每一步里，加入方差与步长相当的高斯噪声，并让步长逐渐衰减到零：早期它像普通的优化，后期它的轨迹就变成从后验分布里取出的样本。

影响

开创了“随机梯度MCMC”这一类方法，让贝叶斯采样能扩展到大数据和神经网络；后续的随机梯度HMC等方法都在它的框架上发展，也被用作贝叶斯深度学习中的基线。它与后来扩散模型里的朗之万采样共享同一个更新公式。

方法

朗之万动力学是一种MCMC：参数沿着对数后验的梯度方向走一步，再加一点高斯噪声，Δθ = (ε/2)·∇log p(θ|数据) + η，其中 η ~ N(0, ε)。步长足够小时，参数的分布会收敛到后验 p(θ|数据)。但算 ∇log p(θ|数据) = ∇log p(θ) + Σ_{i=1}^{N} ∇log p(x_i|θ) 需要遍历全部N个样本。

SGLD把这个梯度换成小批量估计：随机取n个样本，用 (N/n)·Σ_{小批量} ∇log p(x_i|θ) 代替全量求和，再加上先验梯度和注入噪声；同时让步长 ε_t 按照随机逼近的条件（Σ ε_t = ∞，Σ ε_t² < ∞）衰减。作者的论证是：步长大时，小批量梯度的随机噪声远大于注入的噪声，算法表现得像随机梯度下降，快速走向后验的高概率区；步长变小后，注入噪声（方差为ε）主导了小批量噪声（方差约为ε²），算法就变成真正的朗之万采样，此时连Metropolis接受/拒绝步骤都可以省掉。于是同一个算法在“优化”和“采样”之间平滑过渡，最终把轨迹上的点（按步长加权）当作后验样本使用。

作者在混合高斯、逻辑回归和独立成分分析等模型上展示了这一方法。

局限与后续

  • 步长衰减到零时混合非常慢，实际使用固定小步长又会让样本分布带有偏差，样本之间相关性也高。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 在高维神经网络后验上，朗之万一步一步的随机游走探索效率低，难以覆盖多个模态。

它建立在什么之上

  • 延续
    随机梯度下降1951 · 基础
    在随机梯度下降的更新上注入高斯噪声并配合步长衰减，把优化变成采样。
  • 改进
    Metropolis采样与MCMC1953 · 基础
    用小批量梯度代替全数据梯度，解决MCMC无法扩展到大数据的问题。
  • 使用
    贝叶斯神经网络1992 · 基础
    为神经网络等大模型的贝叶斯后验推断提供可扩展的采样手段。
  • 竞争
    变分推断1999 · 基础
    两条近似后验的路线：变分推断优化一个近似分布，SGLD直接产生（近似的）后验样本。

读懂它需要的概念

MCMC与朗之万动力学 先验、后验与贝叶斯推断 随机梯度下降与小批量 高斯分布 马尔可夫性与马尔可夫链

本篇术语

  • 朗之万动力学　沿对数概率的梯度走一步再加高斯噪声的随机过程，长期运行后其位置服从目标分布。

怎么学

先学MCMC与朗之万动力学和贝叶斯后验；用NumPy在二维混合高斯后验上分别跑全梯度朗之万和SGLD，把样本画成散点和真实密度对比；再在逻辑回归上把SGLD样本的预测平均和普通SGD比较校准度。
