URIAL免微调对齐

The Unlocking Spell on Base LLMs: Rethinking Alignment via In-Context Learning
2023.12论文延伸ICLR 2024Bill Yuchen Lin, Abhilasha Ravichander, Ximing Lu, Nouha Dziri, Melanie Sclar, Khyathi Chandu, Chandra Bhagavatula, Yejin Choi · AI2、华盛顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LIMA发现1000条示例做SFT就能得到不错的对齐效果，提出“对齐只是表面的”假说，但没有直接证据说明对齐微调到底改变了基座模型的什么。

方法

逐个词元比较基座模型和对齐后模型的输出分布，发现绝大多数位置两者给出的首选词相同，差别集中在语气、过渡语、免责声明这类风格词元上；据此提出URIAL：不做任何微调，只用一个系统提示加三个固定的风格示例，靠上下文学习让基座模型像助手一样回答。

影响

为“表面对齐假说”提供了直接的词元级证据，并用实验说明强基座模型只靠精心设计的上下文示例就能接近SFT或SFT+RLHF的效果，成为讨论“对齐学到了什么”时常被引用的基线。

背景

常规对齐流程是在基座模型上做指令微调（SFT），再做InstructGPT与RLHF式的RLHF。LIMA少即是多只用1000条精选示例做SFT就得到不错的助手，提出表面对齐假说：模型的知识和能力几乎全在预训练中获得，对齐只是教它用哪种格式和风格与人交流。但这只是从结果反推，没有观察对齐前后模型内部到底变了什么。

方法

词元分布偏移分析：让对齐后的模型（如Llama 2-chat）生成回答，在每个位置，把同样的前缀喂给对应的基座模型，看对齐模型选中的词在基座模型的预测里排第几。排第1记为“未偏移”，排第2–3记为“轻微偏移”，更靠后记为“偏移”。结果大多数位置未偏移；偏移的位置集中在风格类词元：开头的寒暄、“然而”“此外”之类的过渡词、安全免责声明等，而承载知识的内容词基本不变。并且随着回答往后，偏移越来越少，说明基座模型一旦被引上正确的格式，就能自己写下去。

URIAL：既然变化主要是风格，就用上下文学习与提示代替微调。提示由三部分组成：一段说明助手应当有用、诚实、无害的系统提示；三个固定的问答示例，示例的回答按统一风格写成（先复述问题、分点作答、结尾给总结或提醒）；然后是用户问题。所有问题共用同一组示例，不做检索、不更新参数。

评测：作者构建了JUST-EVAL-INSTRUCT，从多个来源收集约1000条指令，用GPT-4按有用性、清晰度、事实性、深度、吸引力、安全等多个维度打分并给出解释。

结果

摘要称，用URIAL的基座模型可以达到甚至超过用SFT或SFT+RLHF对齐的同一模型；通过策略性的提示和上下文学习，免微调与基于微调的对齐方法之间的差距可以大幅缩小。

后来的发展

URIAL常被用作“对齐到底需要多少训练”的对照基线；词元分布偏移的分析方法被后续研究对齐前后差异、以及设计只改少数词元的轻量对齐与解码时对齐的工作沿用。

局限与后续

  • 效果依赖基座模型足够强，三个示例占用上千词元的上下文；多轮对话、复杂安全场景和需要拒答的情形下，与真正微调过的模型仍有差距。

读懂它需要的概念

上下文学习与提示 指令微调与对话模板 人类反馈强化学习 解码：贪心、束搜索、温度与top-p 语言模型

本篇术语

  • 表面对齐假说　认为模型的知识和能力来自预训练，对齐只教会它与人交流时该用的格式和风格。
  • 词元分布偏移　在同一前缀下，对齐后模型选中的词在基座模型预测中的排名变化；排名不变说明这一位置对齐没有带来改变。
  • 基座模型　只做过预训练、没有经过指令微调和RLHF的模型，擅长续写但不会按指令回答。

怎么学

先读LIMA少即是多；读本文第2节词元分布偏移分析和第3节URIAL提示；动手：拿一个开源基座模型和它的chat版本，统计一段回答中两者首选词相同的位置占比，再用三个示例写一个URIAL提示试试效果。
