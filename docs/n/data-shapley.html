Data Shapley数据估值

Data Shapley: Equitable Valuation of Data for Machine Learning
2019.04论文延伸ICML 2019Amirata Ghorbani, James Zou · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

数据成了驱动预测的“燃料”，但一条训练数据到底值多少、该怎样公平地衡量每条数据的贡献，没有原则性的答案。

方法

把训练样本看作合作博弈的参与者、模型性能看作收益，用博弈论中的Shapley值给每条数据估价，并用蒙特卡洛和梯度方法高效近似。

影响

开创了“数据估值”这一研究方向，此后的KNN-Shapley、Beta Shapley、Data Banzhaf等方法都以它为起点，也用于数据清洗和数据定价讨论。

方法

Shapley值。在合作博弈里，Shapley值把总收益按每个参与者的平均边际贡献分配：考虑所有参与者加入的排列顺序，计算某个参与者加入时带来的收益增量，再取平均。用到数据上，φ_i = 平均over所有子集S [V(S∪{i}) − V(S)]（按Shapley权重加权），其中V(S)是只用子集S训练出的模型的测试性能。它唯一地满足几条公平估值的自然性质：没贡献的数据价值为零、贡献相同的数据价值相同、价值可加。

怎么算。精确计算要训练指数多个模型，作者提出截断蒙特卡洛（随机抽排列、性能不再变化时提前停止）和基于梯度的近似，使神经网络等复杂模型在大数据集上也可估算。

结果。在生物医学、图像和合成数据上的实验表明，Data Shapley比常用的留一法和杠杆分数更能揭示哪些数据有价值；Shapley值低的数据往往是离群点和错误标注；Shapley值高的数据能提示应该再采集什么样的数据。

局限与后续

  • 即使用近似算法，也要训练大量模型，计算成本很高；估出的价值依赖于选定的学习算法和性能指标，换一个模型价值就会变。

本篇术语

  • Shapley值　合作博弈中按每个参与者在所有加入顺序下的平均边际贡献来分配总收益的方法，满足对称、零贡献者得零等公平性质。
  • 数据估值　量化每条训练数据对模型性能的贡献，用于清洗数据、定价或决定该采集什么数据。
