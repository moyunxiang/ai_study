Wan 2.2 MoE开源视频

2025.07模型延伸2025-07 开源发布Wan团队 · 阿里巴巴通义待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

Wan 2.1之后，大模型容量扩大意味着推理算力同步上升，且电影级美学与复杂运动仍不足。

方法

在视频扩散中引入专家混合（MoE）：按去噪时间步分配不同专家，总容量变大而单步计算量不变；同时加入带光影构图标签的美学数据。

影响

官方称训练数据比Wan2.1多65.6%图像与83.2%视频，并开源可在消费级显卡上跑720P、24fps的5B混合文/图生视频模型。

方法

据官方README，Wan2.2是对基础视频模型的重大升级，核心有四点。

1. MoE架构：把去噪过程按时间步分给专门的专家模型（早期噪声大时与后期细化时用不同专家），整体容量扩大而每步计算成本保持不变（见混合专家）。官方发布的A14B模型即以此命名。 2. 电影级美学：训练时加入带光照、构图、对比度、色调等细致标签的美学数据，便于控制风格。 3. 复杂运动：相对Wan2.1，训练数据多65.6%的图像、多83.2%的视频。 4. 高效混合TI2V：开源5B模型，配压缩比16×16×4的Wan2.2-VAE，同时支持文生视频与图生视频，720P、24fps，可在消费级显卡运行。

推理代码与权重于2025年7月28日放出（README记录），之后追加了音频驱动的S2V与角色动画Animate模型。

后来的发展

Wan 2.2把MoE带进视频扩散，也让开源视频模型保持与闭源模型的差距较小。

局限与后续

  • 两个专家各有独立权重，显存占用比单模型大。
