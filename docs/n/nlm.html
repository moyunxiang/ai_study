非局部均值去噪

A Non-Local Algorithm for Image Denoising
2005.06论文延伸CVPR 2005Antoni Buades, Bartomeu Coll, Jean-Michel Morel · 巴利阿里群岛大学 / 法国卡尚高等师范学院待核对
DOI ↗IPOL讲解与在线演示 ↗在交互版中打开（演化树、学习进度）

问题

当时的去噪方法（高斯平滑、各向异性扩散、双边滤波、小波阈值）都只用像素周围的局部信息，在去掉噪声的同时会把边缘和细纹理一并抹掉。

方法

利用自然图像的“自相似性”：同一张图里很多地方会出现长得很像的小块。去噪一个像素时，用全图（或一个大搜索窗）里与它周围小块相似的那些像素做加权平均，越像权重越大。

影响

把“图像块自相似”确立为图像复原的核心先验，直接催生了BM3D去噪等块匹配方法；“非局部”这个说法后来还被Non-local网络网络借进了深度学习。

方法

设图像为v，要估计像素i的干净值。普通滤波只平均i附近的像素；非局部均值改为在一个较大的搜索窗口内，对每个候选像素j计算两个小块（例如7×7）之间的距离：d(i,j) = ‖v(N_i) − v(N_j)‖²，其中N_i表示以i为中心的小块。权重随距离指数衰减：w(i,j) = exp(−d(i,j)/h²) / Z(i)，Z为归一化常数，h控制平滑程度。最终 NL(v)(i) = Σ_j w(i,j)·v(j)。

直观地说：一面砖墙上，每块砖的边缘都会在别处重复出现，NLM会找到这些“同类的砖缝”一起平均，噪声相互抵消而边缘保留。比较的是整块的相似度而不是单个像素值，所以对噪声更鲁棒。代价是计算量大：每个像素都要和搜索窗内所有位置比较小块。作者在论文中还提出了“方法噪声”（原图减去去噪结果）的评估方式：好的去噪方法剩下的应该只像纯噪声，不该看到图像结构。

后来的发展

BM3D去噪把相似块堆成三维组、在变换域里联合滤波，成为此后十年的去噪标杆；自相似性先验也进入了超分辨率和修补。深度学习时代的DnCNN去噪等转向从数据中学先验，但Non-local网络网络和注意力机制本质上同样是按相似度加权平均。

局限与后续

  • 每个像素都要在搜索窗内比较大量小块，计算很慢，原始版本难以实时。

读懂它需要的概念

图像作为张量 卷积运算 高斯分布 期望与方差

本篇术语

  • 自相似性　自然图像中相同或相似的局部图案会在图里多处重复出现的性质。
  • 方法噪声　原始含噪图减去去噪结果得到的差，理想情况下应该看起来只是随机噪声。

怎么学

先实现一个3×3高斯平滑看边缘如何被抹掉，再按公式实现非局部均值（小图上即可）；最后用OpenCV的fastNlMeansDenoising对比，并画出两者的方法噪声。
