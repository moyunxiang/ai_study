价值预测网络VPN

Value Prediction Network
2017.07论文延伸NeurIPS 2017Junhyuk Oh, Satinder Singh, Honglak Lee · 密歇根大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的RL通常要学一个预测未来观测的模型，在随机、视觉复杂的环境里很难学准；Predictron只做价值预测，没有动作，不能用来选择动作。

方法

学一个以动作（option）为条件的抽象动力学模型：抽象状态不重建观测，只被训练来预测未来的奖励、折扣和价值，再在这个抽象模型里做短程前瞻搜索来选动作。

影响

把无模型和基于模型的方法合进一个网络，是MuZero「只预测与规划有关的量」思路的直接前身之一。

方法

VPN有四个模块：编码器把观测变成抽象状态；价值模块从抽象状态估计价值；结果模块给出执行某个option后的奖励和折扣；转移模块给出下一抽象状态。这些都是神经网络，训练时用真实轨迹上的多步TD目标：从一个状态出发，按真实执行的动作在抽象模型里展开k步，让每一步预测的奖励、折扣和价值都与真实数据和n步回报对上，称为k步预测训练。模型从不需要重建像素。

决策时，从当前抽象状态出发对每个动作展开d步的树搜索，按预测的奖励和价值回溯出各动作的Q值，再选最优。摘要称，在需要仔细规划、但难以学出准确观测预测模型的随机环境里，VPN同时优于无模型和基于模型的基线；在若干Atari游戏上，即使只做很短的前瞻，也超过了DQN（Nature版）。

它建立在什么之上

  • 延续
    Dyna：学习与规划合一1990 · RL
    延续学模型加规划的路线，但模型只预测奖励与价值而非观测。
  • 使用
    Options时间抽象框架1999 · RL
    模型以option（可持续多步的动作）为条件进行预测。
  • 竞争
    DQN（Nature版）2015.02 · RL
    以DQN为无模型基线，在若干Atari游戏上用短程前瞻超过它。
  • 改进
    Predictron2016.12 · RL
    把只做价值预测的抽象模型推广到以动作为条件，能用来规划和控制。

后来的相关工作

  • 改进
    MuZero2019.11 · RL
    前瞻搜索是对所有动作穷举展开的浅层树，深度一大计算量指数增长。
  • 竞争
    TreeQN可微树规划2017.10 · RL
    同样在抽象状态空间里预测奖励与价值做前瞻；TreeQN把整棵树做成可微的价值网络端到端训练，Atari上比VPN更好。

读懂它需要的概念

基于模型的强化学习 时序差分与自举 博弈树搜索：minimax与MCTS 策略与价值函数

本篇术语

  • option　可以持续多个时间步的「宏动作」，有自己的执行策略和终止条件；最简单的option就是普通的单步动作。

怎么学

先读Predictron和DQN（Nature版）；读原文第3节结构与k步训练；对照MuZero的三函数结构看两者的差别。
