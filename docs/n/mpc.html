模型预测控制MPC

Dynamic Matrix Control—A Computer Control Algorithm
1980思想主干Joint Automatic Control Conference 1980Charles R. Cutler, B. L. Ramaker · Shell Oil（DMC）；同期Richalet等人（法国，IDCOM/MPHC）来源已核对
Rawlings, Mayne & Diehl《Model Predictive Control》（免费教材） ↗Wikipedia: Model predictive control ↗在交互版中打开（演化树、学习进度）

问题

炼油厂这类多变量过程，阀门开度、温度上下限都有硬约束，PID只看当前误差、不会提前动作，LQR又不能处理约束。

方法

每个控制周期用模型预测未来一段时间的输出，在线解一个带约束的优化问题，求出未来一串控制量，只执行第一步，下一周期用新测量重新算（滚动时域）。

影响

1980年代起在化工厂和炼油厂广泛使用，后来进入机器人与自动驾驶；“学一个模型 + 在线规划”的深度学习路线（Visual Foresight、PlaNet、TD-MPC）都采用了MPC式的滚动规划。

背景

1970年代的工业控制主要靠PID控制：把测量值和设定值的误差按比例、积分、微分加权后调节执行器。一个回路管一个变量还行，但炼油装置里几十个变量相互耦合：加大一个阀门，三个温度、两个压力都会跟着变；而且很多量有硬上下限，比如阀门开度不能超过100%、反应器温度不能越过安全线。PID既不能提前看到未来，也不知道约束在哪。

理论上更优的LQR最优控制给出了多变量的最优反馈，但它假设没有约束，并且需要准确的状态空间模型。工厂工程师手里往往只有做阶跃实验得到的经验曲线，而不是一套微分方程。

思想本身更早就有：Rawlings等人的教材指出，Propoi在1963年就提出了用线性规划处理带约束线性系统的类似方法，Lee与Markus在1967年的书里也描述过“测状态、快速算开环最优控制、只用前一小段、再重测重算”的做法。缺的是能在工厂里落地的算法。教材的说法是：1978年Richalet等人提倡把它用于过程控制，引发了一波关注；随后包括1980年Shell的Cutler与Ramaker发表的动态矩阵控制（DMC）在内的一系列论文，使它在过程控制工业中普及。

方法

滚动时域（receding horizon，见规划与模型预测控制）。在时刻t：

  • 用模型预测未来P步的输出；
  • 求未来M步的控制增量，使代价最小：J = Σ (r_i − y_i)² + λ·Σ Δu_i²，即跟踪设定值r，同时别让执行器动作太猛；
  • 满足约束：u_min ≤ u ≤ u_max，y_min ≤ y ≤ y_max；
  • 只执行第一步Δu_1，到t+1时用新的测量重来一遍。

为什么只执行一步？因为模型有误差、扰动随时会来，每步重算等于不断用现实纠正预测，这就把一个开环优化变成了闭环反馈。

DMC的模型：阶跃响应。DMC不要求写微分方程，只要做实验：把输入突然加一个单位，记录输出在之后各步上升了多少，得到系数a_1, a_2, …。线性叠加后，未来输出 = 不再动作时的“自由响应” + 动态矩阵A × 未来的控制增量：y = y_free + A·Δu，A由这些系数排成下三角矩阵，故名“动态矩阵”。无约束时解是一个最小二乘：Δu = (AᵀA + λI)⁻¹Aᵀ(r − y_free)。

一个小例子。加热炉温度：阶跃响应系数是0.2、0.5、0.8（加热功率加1个单位，1、2、3步后温度分别升0.2、0.5、0.8度）。目标100度，若不动作未来三步都停在80度，误差都是20。只优化一步增量、λ=0时，Δu = (0.2+0.5+0.8)×20 / (0.2²+0.5²+0.8²) = 30/0.93 ≈ 32。若执行器每步最多只能加20，就必须把约束放进优化，而不是事后截断；1986年García与Morshedi把这一步写成二次规划（QDMC），此后带约束的二次规划成为线性MPC的常见形式。

状态从哪来。模型需要当前状态作为起点，测不全时通常用卡尔曼滤波估计。

结果

MPC是一类方法而不是一个基准结果。Rawlings、Mayne与Diehl的教材总结：Richalet等人（1978）和Cutler与Ramaker（1980）之后的一系列论文让它在过程控制工业中站稳，成为处理带硬约束控制问题最有用的现代控制方法，应用数以千计。维基百科称它自1980年代起用于化工厂和炼油厂。据维基百科，1970年代末到80年代初DMC成为Shell内部控制复杂过程的标准方法；Cutler于1984年创办DMC公司，1996年将其卖给Aspen Technology。

后来的发展

早期工业MPC并不保证闭环稳定：优化有限时域代价不一定稳定。1980年代末到1990年代，学界用终端代价和终端约束补上了稳定性理论，非线性MPC随后发展起来。

在机器人和学习领域，MPC是“有模型就能规划”的通用框架。四足和人形机器人的步态控制中也常见MPC；深度学习之后，人们把手工模型换成学出来的模型：Visual Foresight用视频预测模型做MPC推物体，PETS概率集成模型和PlaNet用学到的动力学配合交叉熵方法采样规划，TD-MPC、TD-MPC2用学到的价值函数补上短时域之外的回报，DINO-WM和导航世界模型NWM在预训练视觉特征或视频生成模型里做MPC。MuZero的树搜索也可以看作离散动作下的同类思想。

容易误解的地方

  • MPC不是一个具体算法，而是“预测—优化—只执行第一步—重来”的框架；DMC、GPC、非线性MPC、基于采样的MPPI都是它的实现。
  • 每步解出的是开环计划，但因为每步都重算，整体是闭环控制；把它和一次性离线规划混为一谈是常见误解。
  • MPC的效果几乎完全取决于模型精度。模型错了，优化得越精细，偏得越远。

局限与后续

  • 需要准确的预测模型；DMC的线性阶跃响应只适合近似线性的慢过程，接触、摩擦、图像输入这类问题写不出模型。
    后来针对它的工作　Visual Foresight PETS概率集成模型 PlaNet
  • 每个控制周期都要在线解一次优化，炼油厂几分钟一次没问题，腿式机器人要在毫秒内算完，非线性问题更难实时。
    后来针对它的工作　TD-MPC
  • 只看有限时域，时域外的后果被忽略，容易短视；有限时域优化也不自动保证闭环稳定。
    后来针对它的工作　TD-MPC
  • 代价函数和约束要人来设计，复杂任务（如“把桌子收拾干净”）很难写成二次代价。
    后来针对它的工作　DINO-WM

它建立在什么之上

  • 使用
    卡尔曼滤波1960 · 具身·世界模型 已核对
    状态空间形式的MPC每步需要当前状态作为预测起点，状态测不全时常用卡尔曼滤波及其变体估计（Rawlings等人的教材用专门一章讲MPC中的状态估计，含EKF和UKF）。
  • 改进
    PID控制1922 · 具身·世界模型 已核对
    PID只看当前误差、不会提前动作、难以处理多变量耦合和硬约束；MPC用模型预测和约束优化改进了这三点。
  • 竞争
    动态规划与Bellman方程1957 · RL 已核对
    动态规划离线算出对所有状态都适用的最优策略，维数一高就算不动；MPC只对当前状态在线求一条最优开环轨迹，对确定性问题两者结果相同。
  • 改进
    LQR最优控制1960 · 具身·世界模型 待核对
    LQR是无约束、无限时域的二次最优控制；MPC改成有限时域并在线滚动求解，从而能把执行器和安全约束放进优化。

读懂它需要的概念

规划与模型预测控制 控制回路与控制频率 状态、观测与动作 线性回归 凸函数与凸优化 动态规划

本篇术语

  • 滚动时域　每次只规划未来固定长度的一段，执行第一步后窗口整体往前挪一步再重新规划，像开车时始终只看前方几十米。
  • 阶跃响应　把输入突然调高一个单位后，输出随时间变化的曲线。DMC直接用这条曲线上的采样值当模型。
  • 硬约束　任何时候都不能违反的限制，比如阀门开度在0到100%之间。与之相对的软约束只是在代价里加惩罚。
  • 二次规划（QP）　目标是二次函数、约束是线性不等式的优化问题，是凸的，有成熟快速的求解器，线性MPC每一步解的就是它。

怎么学

先补控制回路与控制频率、线性回归（最小二乘）和凸函数与凸优化。读Rawlings等人教材第1章和第2章开头，理解有限时域优化与滚动执行；维基百科的MPC条目有一段简明原理介绍。动手：用Python和cvxpy为一个二阶质量—弹簧系统写线性MPC，加上力的上下限，对比无约束LQR被截断后的表现；再把模型故意改错10%，观察每步重算如何把误差拉回来。
