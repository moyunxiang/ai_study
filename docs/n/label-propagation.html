标签传播（调和函数）

Semi-Supervised Learning Using Gaussian Fields and Harmonic Functions
2003.08论文延伸ICML 2003Xiaojin Zhu, Zoubin Ghahramani, John Lafferty · 卡内基梅隆大学待核对
AAAI论文页 ↗在交互版中打开（演化树、学习进度）

问题

只有少数样本带标签时，怎样利用“相似的样本应该同类”这个直觉，把标签可靠地扩散到大量无标签样本上，而不只是在标注点附近画边界。

方法

把所有样本（有标签和无标签）连成一张按相似度加权的图，要求每个无标签点的预测等于邻居预测的加权平均（调和函数），标签就沿着图从已知点流向未知点，答案可以用矩阵运算一次解出。

影响

成为图半监督学习的经典方法，与“标签传播”“图拉普拉斯正则”一起构成2000年代半监督学习的主线之一；后来图卷积网络的半监督节点分类正是在这类图上的问题设定里提出的。

方法

构图：每个样本是一个顶点，任意两点之间的边权 w_ij 随距离增大而减小（例如高斯核 exp(−‖x_i−x_j‖²/σ²)）。在这张图上定义一个实值函数f，标注点的f固定为它的标签（如0或1），无标签点的f待求。目标是让f在图上尽量平滑，即最小化能量 E(f) = ½ Σ_ij w_ij (f_i − f_j)²。

这个能量最小的解满足“调和性质”：每个无标签点的值恰好是邻居值按边权的加权平均。写成矩阵形式，用图拉普拉斯 L = D − W 分块，无标签部分的解是 f_u = (D_uu − W_uu)⁻¹ W_ul f_l，一次线性方程组就能求出；也可以反复让每个点取邻居平均来迭代逼近，这就是“标签传播”。f还有直观的随机游走解释：从一个无标签点出发在图上随机走，先撞到正类标注点的概率就是 f；也可以看成电路里各点的电压。

论文页摘要报告：作者把问题写成图上的高斯随机场，讨论了如何结合类别先验和有监督分类器的预测，并提出用熵最小化学习边权参数、做特征选择；在合成数据、手写数字分类和文本分类上取得了不错的实验结果。

局限与后续

  • 需要先构造整张相似度图并解线性方程组，样本多到百万级时内存和计算都难以承受。

本篇术语

  • 图拉普拉斯　由图的度矩阵D减去邻接矩阵W得到的矩阵 L = D − W，fᵀLf 衡量函数f在图上相邻点之间变化有多大。
  • 调和函数　图上每个点的值都等于邻居值加权平均的函数，相当于“没有局部高峰低谷”的最平滑插值。

怎么学

先复习矩阵求逆和马尔可夫性与马尔可夫链；在“双月牙”玩具数据上每类只标一个点，用k近邻构图后迭代做邻居平均，看标签如何沿着月牙扩散；再和直接用这两个点训练的线性分类器对比。scikit-learn里有现成的LabelPropagation可对照。
