ICLR与OpenReview

2013.05事件延伸Yann LeCun、Yoshua Bengio（创办者）· 美国亚利桑那州（首届）待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

表示学习与深度学习社区被NIPS等会议的审稿体系压着，评审周期长且不透明。

方法

2013年创办ICLR，采用开放评审（基于LeCun提出的模型），论文和评审意见公开挂在OpenReview上。

影响

它在短短几年内成为机器学习三大会议之一，其公开评审成为论文评审改革的样板。

方法

据Wikipedia，ICLR通常在每年4月下旬或5月初举行，与NeurIPS、ICML并列为机器学习与AI研究最具影响和声誉的三大会议之一；会议包括特邀报告以及口头和海报论文；自2013年创办起就使用基于LeCun提出模型的开放同行评审，由LeCun和Bengio在2012年创办。

它与arXiv与预印本文化的预印本文化一起，形成“论文先挂网、评审公开”的新习惯，也是NIPS（NeurIPS）首届会议一脉之外深度学习社区自己的会场。

局限与后续

  • 公开评审也带来评审质量下降和审稿人负担的问题，近年投稿量暴增。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    NIPS（NeurIPS）首届会议1987.11 · 事件
    深度学习社区在主流机器学习会议之外另立会议，强调表示学习与开放评审。
  • 改进
    AAAI首届年会1980.08 · 事件
    会议长期以符号AI和经典规划推理为主，2010年代后被机器学习顶会在影响力上超过。
  • 改进
    CVPR首届会议1983 · 事件
    规模膨胀使评审质量参差，口头报告比例极低，论文大多在arXiv先发而非首次在会上亮相。
  • 使用
    arXiv与预印本文化1991.08 · 事件
    会议鼓励先挂arXiv，和OpenReview一起构成开放的学术流程。
