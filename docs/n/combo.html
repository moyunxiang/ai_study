COMBO保守模型离线优化

COMBO: Conservative Offline Model-Based Policy Optimization
2021.02论文延伸NeurIPS 2021Tianhe Yu, Aviral Kumar, Rafael Rafailov, Aravind Rajeswaran, Sergey Levine, Chelsea Finn · 斯坦福大学 / UC Berkeley / Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的离线RL（MOPO模型离线优化、MOReL悲观模型离线RL）靠模型集成的不确定性估计来实现悲观，但深度网络的不确定性估计在复杂任务（尤其是图像输入）上往往不可靠，惩罚时有时无。

方法

不估计不确定性：用学到的模型生成短轨迹扩充数据，再像离线强化学习CQL那样在Q学习里加一个正则项——压低模型生成的（可能在数据之外的）状态-动作的Q值、抬高真实数据中状态-动作的Q值，从而得到保守的价值估计。

影响

把无模型的保守Q学习与基于模型的数据扩充结合起来，给出比CQL更紧的价值下界和离线策略改进保证，是基于模型的离线RL里常用的强基线，在图像输入任务上也能工作。

背景

离线RL的“悲观”可以有两种实现。基于模型的一派（MOPO模型离线优化按不确定性减奖励、MOReL悲观模型离线RL对未知区域截断）需要可靠的不确定性估计，而神经网络集成的分歧并不总是对应真实的模型误差。无模型的一派以离线强化学习CQL为代表：直接在Q学习目标里压低策略动作的Q值、抬高数据动作的Q值，不需要不确定性估计，但只能利用数据中的状态，泛化有限。COMBO想把两者的优点结合起来。

方法

先用离线数据训练一个动力学模型 T̂(s'|s,a)（与MBPO相同，从数据状态出发做短步数的模型展开）。Q函数的训练数据是真实数据D与模型展开数据的混合 d_f = f·D + (1−f)·d_model。损失是：

min_Q β · ( E_{(s,a)∼ρ}[Q(s,a)] − E_{(s,a)∼D}[Q(s,a)] ) + ½ · E_{(s,a,s')∼d_f}[ (Q(s,a) − 𝔅̂^π Q(s,a))² ]

第一项是保守正则：ρ是当前策略在学到的模型中产生的状态-动作分布，这些点可能在数据支撑之外，于是被压低；真实数据点被抬高。第二项是普通的Bellman误差。策略按actor-critic方式最大化这个保守Q值。

理论上作者证明，COMBO学到的价值是真实策略价值的下界，在一定条件下比CQL的下界更紧；同时满足离线设定下的策略改进保证。

结果

摘要称，COMBO在广泛研究的离线RL基准上（包括基于图像的任务）一致地与以往无模型和基于模型的离线方法表现相当或更好。

后来的发展

COMBO说明保守性可以不依赖不确定性估计来实现，后来的基于模型离线方法常在“如何构造被惩罚的分布ρ”上做文章；而无模型方法这边，隐式Q学习IQL等不查询数据外动作的方法以更简单的实现成为主流基线。

局限与后续

  • 仍需训练动力学模型并做模型展开，计算开销大；模型误差大时，展开数据本身会把错误带进Q学习。

它建立在什么之上

  • 使用
    MBPO2019.06 · RL
    沿用从数据状态出发做短步模型展开来扩充训练数据的做法。
  • 改进
    MOPO模型离线优化2020.05 · RL
    MOPO需要不可靠的集成不确定性来惩罚奖励；COMBO改用价值正则化，不需要显式不确定性估计。
  • 改进
    MOReL悲观模型离线RL2020.05 · RL
    MOReL同样依赖集成分歧检测未知区域；COMBO避开了这一依赖。
  • 延续
    离线强化学习CQL2020.06 · RL
    把CQL的保守正则推广到模型生成的状态-动作上，得到更紧的价值下界。

后来的相关工作

  • 竞争
    RAMBO对抗模型离线RL2022.04 · RL
    COMBO在模型数据上做CQL式保守正则；RAMBO在模型本身上施加对抗。

本篇术语

  • 保守价值估计　故意让学到的Q值偏低（至少不高于真实值），使策略不会被虚高的、数据外动作的价值吸引。
  • 模型展开　从真实状态出发，用学到的动力学模型往前模拟几步，生成额外的训练样本。
