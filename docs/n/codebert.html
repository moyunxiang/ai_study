CodeBERT

CodeBERT: A Pre-Trained Model for Programming and Natural Languages
2020.02论文延伸EMNLP Findings 2020Zhangyin Feng, Daya Guo, Duyu Tang, Nan Duan, Ming Zhou 等 · 哈尔滨工业大学 / 中山大学 / 微软亚洲研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

代码搜索、生成注释等任务既涉及自然语言又涉及编程语言，通用的文本预训练模型不懂代码结构。

方法

在自然语言与代码配对的数据（以及只有代码的数据）上，预训练一个Transformer编码器，目标包括掩码预测与「替换词检测」。

影响

第一个面向编程语言和自然语言的大规模双模态预训练模型，在代码搜索和代码注释生成上达到当时最优。

方法

CodeBERT沿用RoBERTa的架构，训练数据有两类：双模态数据（一段函数代码配它的文字说明），以及单模态数据（只有代码或只有文字）。训练目标是把两种信息混在一起的：遮词预测，加上替换词检测——一个小的生成器把部分词替换成貌似合理的别的词，主模型要判断每个词是否被替换，这比单纯预测遮住的词利用了所有位置的信号。

微调后用于自然语言搜代码、为代码生成文档两个任务，摘要称都取得当时的最优成绩。作者还构建了一个自然语言-代码的探测数据集，在固定参数的零样本设定下，CodeBERT也优于此前的预训练模型。

局限与后续

  • 只学了代码的文本形态，没有显式利用语法树和数据流等程序结构。
    后来针对它的工作　CodeT5
  • 只有编码器，擅长理解和检索，不能直接补全或生成整段代码。
    后来针对它的工作　Codex

  • 替换词检测　让一个小模型替换文本中的部分词，主模型判断每个位置的词是否被替换，需要对所有位置都做判断。
