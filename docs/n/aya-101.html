Aya 101多语言指令模型

Aya Model: An Instruction Finetuned Open-Access Multilingual Language Model
2024.02论文延伸ACL 2024Ahmet Üstün, Viraat Aryabumi, Zheng-Xin Yong, Wei-Yin Ko, Daniel D'souza, Gbemileke Onilude, Neel Bhandari, Shivalika Singh et al. · Cohere For AI及全球开放科学合作者待核对
arXiv ↗模型 ↗在交互版中打开（演化树、学习进度）

问题

大模型的进展集中在少数数据丰富的语言上，世界上大多数语言（尤其是低资源语言）的用户用不上能听懂指令的模型；已有的多语言指令模型如mT0、BLOOMZ覆盖的语言也只有约46种。

方法

以mT5为基座，在覆盖101种语言（一半以上为低资源语言）的大规模指令数据上微调，得到一个能用101种语言遵循指令的生成模型，并建立覆盖99种语言的评测体系。

影响

在多数任务上超过mT0和BLOOMZ，同时覆盖两倍的语言数；模型和指令数据全部开源，是2024年多语言、低资源语言指令模型的代表性开放工作。

方法

背景：BLOOMZ/mT0与xP3（含mT0）用多语言任务集合xP3做指令微调，覆盖46种语言；它们的基座分别是BLOOM和mT5。更多语言缺少高质量的指令数据，评测也基本只有翻译成各语言的少量基准。

数据：作者组合了几类多语言指令数据：

  • 由全球志愿者用母语撰写和标注的指令数据（Aya Dataset）；
  • 把现有英文指令数据集模板化或机器翻译成大量语言（Aya Collection的一部分）；
  • xP3x等现有多语言任务集合；
  • 合成数据。

并系统研究了不同来源的最优混合比例和数据剪枝（去掉低质量样本）对效果的影响。

模型：以13B参数的mT5-XXL（编码器—解码器）为基座做指令微调，得到Aya 101，支持101种语言，其中超过50%属于低资源语言。

评测：作者扩展了多语言评测，覆盖99种语言，包括判别类任务（如XNLI、XCOPA）、生成类任务、人工评测，以及由大模型模拟的胜率，既测完全留出的任务，也测分布内表现。他们还评估了模型的毒性、偏见与安全性。

结果（摘要）：Aya在多数任务上超过mT0和BLOOMZ，同时覆盖的语言数是它们的两倍。指令数据和模型全部开源。

后来的发展

Aya 101之后，Cohere For AI推出了以“深度换广度”的Aya 23和后续Aya Expanse等模型；Aya Dataset成为低资源语言指令数据的重要来源。

局限与后续

  • 基座mT5是2020年的编码器—解码器模型，开放式生成和对话能力明显弱于同期基于新一代解码器模型的系统。
    后来针对它的工作　Aya 23深度换广度
  • 很多语言的数据来自机器翻译，翻译腔和文化不贴合的问题难以避免；评测也部分依赖翻译后的基准。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 延续

  • 使用
    mT52020.10 · LLM
    以13B的mT5-XXL作为基座模型。
  • 改进
    BLOOMZ/mT0与xP32022.11 · LLM
    BLOOMZ和mT0只覆盖46种语言，Aya把指令微调扩展到101种语言，并在多数任务上超过它们。

  • 改进
    Aya 23深度换广度2024.05 · LLM

读懂它需要的概念

指令微调与对话模板 编码器-解码器 分词与token 迁移学习 基准、排行榜与SOTA

本篇术语

  • 低资源语言　可用于训练的数字化文本和标注数据很少的语言，例如许多非洲和南亚语言。
  • 数据剪枝　按质量或重复度删掉一部分训练数据，有时能在数据更少的情况下得到更好的模型。

怎么学

先读BLOOMZ/mT0与xP3了解多语言指令微调；读本文第2节数据来源与混合比例、第4节多语言评测；动手：用Aya 101分别以英语和一种低资源语言提出同一个问题，比较回答质量。
