GQA

GQA: A New Dataset for Real-World Visual Reasoning and Compositional Question Answering
2019.02数据集延伸CVPR 2019Hudson, Manning · Stanford待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

VQA v2 仍有问题偏置，CLEVR 又过于合成，缺少一个既用真实图像、又能系统检验组合推理与一致性的基准。

方法

用 Visual Genome 的场景图作为图结构，通过问题引擎自动生成带功能程序的问题，并通过平滑技术控制答案分布，另设一致性、可落地性、合理性等评测指标。

影响

成为真实图像上的组合式视觉推理基准，神经模块网络、视觉-语言预训练模型常在它上面汇报成绩。

方法

GQA 沿用 CLEVR 的做法：问题由程序生成，每一个问题都附一个功能程序，说明推理步骤；但图像换成真实图片，场景结构来自 Visual Genome 的场景图。论文称问题引擎生成了2200万个需要推理的问题。

他们提出可调的平滑技术来缓解问题偏置，并设计了新的评测指标，考察一致性（相关问题的回答是否相容）、可落地性和合理性。论文报告：一个只看问题的 LSTM 得到42.1%，强的 VQA 模型达到54.1%，人类为89.3%，说明有很大的提升空间。相对于 VQA v2，它更强调推理的结构。

局限与后续

  • 问题由模板生成，语言多样性不如人工写的问题，模型可能学到模板规律。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 场景图本身有噪声，部分自动生成问题的答案可能不唯一。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    VQA2015.05 · 数据·评测
    存在强烈的语言先验，只看问题不看图就能答对近一半，模型可以靠猜而不必理解图像。
  • 使用
    Visual Genome2016.02 · 数据·评测
    用 Visual Genome 的场景图自动生成问题。
  • 改进
    CLEVR2016.12 · 数据·评测
    把 CLEVR 的程序化诊断思路搬到真实图像。
  • 竞争
    VQA v22016.12 · 数据·评测
    VQA v2 通过平衡图片对抗偏置，GQA 通过可控答案分布和程序化问题。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
