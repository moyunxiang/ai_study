Focal Loss与RetinaNet

Focal Loss for Dense Object Detection
2017.08论文重要ICCV 2017Tsung-Yi Lin, Priya Goyal, Ross Girshick, Kaiming He, Piotr Dollár · Facebook AI Research待核对
arXiv ↗Detectron代码 ↗在交互版中打开（演化树、学习进度）

问题

单阶段检测器（SSD、YOLO）快但一直不如两阶段的Faster R-CNN准。原因说不清，大家以为是结构不够好。

方法

指出真正原因是正负样本极度不平衡：每张图约10万个候选框，绝大多数是一眼就能认出的背景。焦点损失给交叉熵乘上(1−p)^γ，把容易样本的损失压到几乎为零。

影响

单阶段检测器第一次在精度上超过所有两阶段方法；焦点损失成为检测、分割中处理类别不平衡的通用工具，后来的FCOS、Deformable DETR、SAM都在用。

背景

检测器分两类。两阶段的Faster R-CNN先用区域建议网络从几十万个位置里挑出一两千个可能有物体的框，再精细分类；第二阶段训练时还按正负1:3的比例采样。单阶段的SSD和YOLO直接在密集的网格上对每个位置、每种尺寸的锚框（见锚框与非极大值抑制）同时分类和回归，省掉一个阶段所以更快，但精度一直落后。

论文的诊断是：单阶段检测器每张图要评估约10万个锚框，其中前景与背景之比可达1:1000。这些背景大多是天空、地面这类容易负样本，每个的损失很小，但数量太多，加起来仍主导了总损失和梯度，真正难分的样本反而学不到。SSD用的难例挖掘（只保留损失最大的负样本）是一个补丁，但它直接丢掉大量样本，效果有限。

方法

焦点损失（Focal Loss）。二分类交叉熵（见交叉熵）可以写成CE = −log(p_t)，p_t是模型给正确类别的概率。焦点损失加一个调制因子：

FL(p_t) = −α_t · (1 − p_t)^γ · log(p_t)

γ取2时，一个已经分得很好的样本（p_t = 0.9）损失乘上(0.1)² = 0.01，比交叉熵小100倍；而一个分错的样本（p_t = 0.1）只乘上0.81，几乎不变。于是总损失自动集中到难样本上，不需要任何采样，10万个锚框全部参与训练。α = 0.25是正负类的平衡权重。

初始化技巧。如果最后一层按常规初始化，开始时每个锚框都输出约0.5的前景概率，海量背景会产生巨大损失让训练发散。作者把分类层偏置设为让初始前景概率约0.01，训练就稳定了。

RetinaNet。为了验证损失函数，作者搭了一个刻意简单的检测器：ResNet骨干加特征金字塔FPN，P3到P7每层每个位置放9个锚框（3种尺寸×3种长宽比），接两个并行的小全卷积子网络，一个分类、一个回归框，所有层共享参数。

结果

同一个ResNet-50网络，用平衡交叉熵最多只有31.1 AP，换成焦点损失提高约2.9 AP；在ResNet-101上焦点损失得到36.0 AP，最好的难例挖掘配置只有32.8 AP。最终的ResNet-101-FPN模型在COCO test-dev上AP 39.1，比最接近的单阶段方法DSSD（33.2）高5.9，比最好的两阶段Faster R-CNN变体高2.3；换ResNeXt骨干达到40.8。600像素输入时，RetinaNet-101与同骨干的FPN Faster R-CNN精度相当，每张图122毫秒对172毫秒（M40 GPU）。

后来的发展

焦点损失远远超出了这一个检测器：FCOS无锚框检测、CenterNet等无锚框检测器用它或它的变体做分类，Deformable DETR把DETR的分类损失换成焦点损失，Segment Anything训练掩码时用焦点损失与dice损失按20:1组合。RetinaNet本身成为单阶段检测的标准基线，“骨干+FPN+共享检测头”的模板被EfficientDet和后来的YOLO系列沿用。

容易误解的地方

  • 焦点损失解决的是容易样本太多，不是简单的类别数量不平衡；只按类别频率加权（α）不区分难易，效果差得多。
  • 论文的核心发现是诊断：单阶段落后主要因为训练时的不平衡，而不是结构本身的表达能力。RetinaNet的结构故意做得平淡，就是为了证明这一点。

局限与后续

  • 仍依赖人工设计的锚框（尺寸、比例、IoU阈值），每个位置9个锚框也带来大量冗余计算。
    后来针对它的工作　FCOS无锚框检测 CenterNet
  • 输出仍要经过非极大值抑制去重，不是端到端的检测。
    后来针对它的工作　DETR YOLOv10免NMS
  • 最好的配置每秒约5帧，远达不到YOLO那样的实时速度。
    后来针对它的工作　EfficientDet RT-DETR实时DETR

读懂它需要的概念

交叉熵 锚框与非极大值抑制 IoU与mAP 分类、检测、分割 卷积层、池化与感受野 参数初始化

本篇术语

  • 单阶段 / 两阶段检测器　两阶段先选出少量候选框再细分类；单阶段在所有密集位置上一次性分类和回归，更快但更受背景样本干扰。
  • 容易负样本　模型已能很有把握判为背景的锚框，单个损失很小，但数量极多时会淹没有用的梯度。
  • 难例挖掘（OHEM）　训练时只挑损失最大的样本组成小批量，其余丢弃。焦点损失用连续的降权替代了这种硬性筛选。

怎么学

先弄懂交叉熵和锚框。读原文第3节（焦点损失的推导，带图1的曲线）和第5.1节的消融表。动手：在Python里画出γ=0、1、2、5时FL随p_t变化的曲线，再在一个前景只占1%的玩具二分类数据上分别用CE和FL训练逻辑回归，比较召回率。
