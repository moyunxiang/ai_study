欧盟GPAI行为准则

The General-Purpose AI Code of Practice
2025.07事件延伸欧盟人工智能办公室与独立专家 · 欧盟委员会待核对
欧盟委员会 ↗在交互版中打开（演化树、学习进度）

问题

欧盟AI法案对通用模型提供者有义务，但细则缺失，企业不知道怎样才算合规。

方法

由独立专家经多方参与起草自愿性行为准则，分透明度、版权、安全与保障三章，签署者可借此证明合规。

影响

成为AI法案对通用AI模型义务落地的第一份实操文件，主要实验室几乎都签署。

方法

该准则于2025年7月10日发布。三章分别是：透明度，提供模型文档表，帮助提供者满足AI法案的透明度义务；版权，说明如何落实遵守欧盟版权法的政策；安全与保障，描述管理最先进模型系统性风险的最佳实践，只适用于少数提供者。

它是自愿的，供应商填写签署表发给AI办公室即可。官方页面列出的签署者包括Amazon、Anthropic、Google、IBM、Microsoft、Mistral AI和OpenAI等；xAI只签了安全与保障一章，须以其他方式证明透明度与版权合规。欧盟委员会和AI委员会已确认它是证明遵守AI法案的适当方式，签署可减少行政负担、增加法律确定性。

局限与后续

  • 准则为自愿性质，具体处罚和执法强度要看AI办公室后续执法。
    后来针对它的工作　欧盟AI法“数字综合”修订
  • 系统性风险章节的条款较宽泛，不同公司可能做出差异很大的解释。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 改进
    欧盟《人工智能法案》2024.03 · 安全·可解释

  • 改进
    OpenAI准备度框架2023.12 · 安全·可解释
    这类框架由企业自我治理，缺乏外部强制力。
