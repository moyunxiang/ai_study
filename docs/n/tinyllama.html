TinyLlama 1.1B

TinyLlama: An Open-Source Small Language Model
2024.01论文延伸Peiyuan Zhang, Guangtao Zeng, Tianduo Wang, Wei Lu · 新加坡科技设计大学StatNLP待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

按Chinchilla规则，1B左右的小模型只需几百亿词元就“训练够了”；但小模型继续多训练到底还能提升多少，几乎没人用公开资源认真试过。

方法

沿用Llama 2的架构和分词器，用FlashAttention、Lit-GPT等开源社区的优化，把一个1.1B模型在约1万亿词元上训练约3个epoch（总共约3万亿词元），并公开全部检查点和代码。

影响

以学术团队的资源证明了“小模型大量过度训练”仍持续有效，在多项下游任务上明显超过同尺寸开源模型，成为2024年端侧、投机解码草稿模型和小模型研究最常用的开源基座之一。

方法

背景：Chinchilla给出的算力最优点约为每个参数20个词元，1.1B模型约需220亿词元。但LLaMA、Llama 2的经验表明，小模型训练远超这个数时仍在变好，而推理成本只与模型大小有关。社区想知道：对1B级模型，这条路能走多远？

架构：完全沿用Llama 2的结构和分词器：22层、RMSNorm预归一化、SwiGLU前馈层、RoPE位置编码，以及分组查询注意力（GQA）以减少推理时的KV缓存。这样它可以直接放进为Llama生态开发的各种工具里。

数据与训练：预训练语料约1万亿词元，由自然语言数据（SlimPajama）和代码数据（StarCoder训练集）按约7:3混合，训练约3个epoch。

效率优化：利用开源社区的成果提高训练吞吐，包括FlashAttention-2、融合的层归一化和SwiGLU算子、Lit-GPT训练框架、全分片数据并行（FSDP）等，在16块A100上完成训练。

结果（摘要）：尽管规模很小，TinyLlama在一系列下游任务上表现出色，显著超过同等规模的现有开源语言模型（如OPT-1.3B、Pythia-1.4B）。作者公开了训练过程中的中间检查点和全部代码。

后来的发展

TinyLlama被大量用作投机解码的草稿模型、端侧部署的实验对象和教学项目；后续的SmolLM、Qwen小模型等把小模型过度训练推到了更大的词元数。

读懂它需要的概念

本篇术语

  • 分组查询注意力（GQA）　多个查询头共享同一组键和值头，在几乎不损失效果的情况下大幅减少推理时需要缓存的键值。
  • 投机解码草稿模型　用一个小而快的模型先猜出几个词，再让大模型一次性验证，从而加速大模型生成；小模型就是草稿模型。

怎么学

先读Chinchilla和Llama 2的架构部分；读本文第2节训练设置和第3节随训练词元的性能曲线；动手：下载TinyLlama不同阶段的检查点，在同一组常识题上评测，画出准确率随训练词元的变化。
