Cartographer实时回环激光SLAM

Real-time loop closure in 2D LIDAR SLAM
2016.05系统延伸ICRA 2016Wolfgang Hess, Damon Kohler, Holger Rapp, Daniel Andor · Google待核对
ICRA 2016 ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

用激光雷达给大楼画平面图时，单靠逐帧匹配会累积漂移，地图越画越歪；必须做回环检测修正，但在大场景里实时搜索回环的计算量太大。

方法

把连续几帧扫描拼成局部“子图”，后台把新扫描与所有子图做匹配来找回环，用分支定界加速搜索，再用图优化（稀疏位姿调整）统一修正所有位姿。

影响

Google开源的Cartographer成为二维/三维激光SLAM最常用的工程系统之一，提供ROS集成，在机器人社区被广泛使用。

方法

二维激光SLAM的基本流程是把每一帧激光扫描和已有地图对齐，求出机器人当前的位置，再把这帧加进地图（基于占据栅格地图）。问题是每次对齐都有小误差，走一圈回到起点时，地图上的起点和终点对不上。解决办法是回环检测：认出“这里我来过”，加一个约束把误差分摊回整条轨迹。但场景越大，候选位置越多，实时搜索很难。

Cartographer分两层。局部SLAM：每帧扫描与当前正在构建的子图（若干连续扫描组成的一小块占据栅格地图）做匹配插入，子图在短时间内足够精确。全局SLAM：后台不断把新扫描与所有已完成的子图尝试匹配；为了快，它用分支定界在多分辨率地图上搜索——先在粗分辨率上排除不可能的大片区域，只在有希望的区域细化，从而保证找到最优匹配的同时把计算量降到实时可行。找到的回环作为约束加入位姿图，再用稀疏位姿调整（一种非线性最小二乘优化）求解所有子图和扫描的位姿。

论文展示了在大型建筑中实时构建二维地图并闭合回环，精度与当时的方法相当；系统同年作为开源项目发布并提供ROS集成，后来也支持三维激光。

读懂它需要的概念

图、树与搜索 梯度下降 随机变量与概率分布 博弈树搜索：minimax与MCTS

本篇术语

  • 回环检测　识别机器人回到了曾经到过的地方，并据此加约束修正累积的定位误差。
  • 分支定界　一种搜索技巧：先用上界快速排除整块不可能的候选，只在有希望的分支里继续细分，保证找到最优解。
  • 位姿图优化　把各时刻的机器人位姿当作图的节点、相对测量当作边，求一组最符合所有测量的位姿。

怎么学

先理解占据栅格与扫描匹配，再读论文第4–5节子图与分支定界；可在ROS中运行Cartographer的官方示例数据包。
