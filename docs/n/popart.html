PopArt自适应目标归一化

Learning values across many orders of magnitude
2016.02论文延伸NeurIPS 2016Hado van Hasselt, Arthur Guez, Matteo Hessel, Volodymyr Mnih, David Silver · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经网络对要拟合的目标的尺度很敏感。DQN（Nature版）为了用同一套超参玩几十个Atari游戏，把所有奖励裁剪到[−1, 1]；可这样一来，吃一个小豆子和打掉一个大BOSS在智能体看来一样重要，行为会和真实目标不同。

方法

PopArt：对价值网络的回归目标做自适应归一化（持续估计目标的均值和标准差），并在更新统计量的同时反向修正网络最后一层的权重，让未归一化的输出保持不变。

影响

使去掉奖励裁剪成为可能，后来成为多任务RL的标准组件：IMPALA与V-trace的多任务版本、V-MPO同策略MPO等都用PopArt平衡不同游戏之间相差几个数量级的回报尺度。

方法

设网络输出归一化后的值 ŷ = W·h + b，真实尺度上的预测是 f(x) = σ·ŷ + μ，其中μ、σ是对回归目标（如TD目标）均值和标准差的滑动估计。训练时网络拟合的是归一化后的目标 (y − μ)/σ，梯度尺度因此大致恒定，不受某个游戏回报是1还是10000的影响。

问题在于：μ、σ一变，同一个网络的真实尺度输出也会跟着变，等于凭空改变了已经学到的价值。PopArt的名字就来自它的两半：

  • ART（Adaptively Rescaling Targets）：自适应地更新μ、σ；
  • POP（Preserving Outputs Precisely）：每次把μ、σ更新为μ'、σ'时，同时把最后一层改成 W' = σW/σ'、b' = (σb + μ − μ')/σ'，使得 σ'·(W'h + b') + μ' = σ·(Wh + b) + μ 对所有输入都精确成立。

这样统计量可以随时调整，而网络已经学到的函数一点不变。摘要称，在Atari上用自适应归一化可以去掉奖励裁剪这一领域特定的启发式，整体性能不下降；作者还展示了去掉裁剪后某些游戏中行为在质上的变化。

后来的发展

PopArt的主要用武之地后来转到了多任务RL：同时学几十个Atari游戏或DMLab关卡时，各游戏回报的尺度可以相差几个数量级，不做归一化，回报大的游戏会主导梯度，回报小的游戏几乎学不到东西。DeepMind把PopArt与IMPALA与V-trace结合，对每个任务分别维护一套均值和标准差，让一个智能体在所有任务上都能学习；V-MPO同策略MPO、Muesli策略优化等后续的大规模智能体也沿用了这种按任务归一化回报的做法。在单任务里，人们更常用的仍是奖励裁剪或对回报做简单缩放。

局限与后续

  • 只归一化了目标的整体尺度，奖励稀疏程度和时间尺度的差异仍会影响学习。

本篇术语

  • 奖励裁剪　把每一步奖励截断到固定区间（如[−1,1]），统一尺度但丢失了奖励大小的信息。
  • 目标归一化　回归时先把目标减均值除标准差，再让网络去拟合，保持梯度尺度稳定。

怎么学

先读DQN（Nature版）的奖励裁剪部分；读原文第2节POP的推导；在一个回报尺度会突然变大的回归任务上，对比直接回归、只做ART和完整PopArt三种做法。
