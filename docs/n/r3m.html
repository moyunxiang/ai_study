R3M机器人视觉表示

R3M: A Universal Visual Representation for Robot Manipulation
2022.03论文重要CoRL 2022Suraj Nair, Aravind Rajeswaran, Vikash Kumar, Chelsea Finn, Abhinav Gupta · 斯坦福大学 / Meta AI待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

机器人策略的视觉部分通常从零训练或用ImageNet、CLIP的通用特征；机器人数据太少，从零学不好，而通用特征并不是为“看懂操作过程”设计的。

方法

用Ego4D里海量第一人称的人类日常视频预训练一个ResNet视觉编码器，目标三合一：时间上相近的帧表示相近、画面变化要与旁白文字对得上、表示尽量稀疏，之后冻结它给机器人策略当“眼睛”。

影响

在12个仿真操作任务上，比从零训练成功率高20%以上、比CLIP和MoCo高10%以上，真机20条示范就能学会家务任务；开启了“用人类视频给机器人预训练视觉表示”这条研究线。

背景

模仿学习的策略要从相机图像里提取有用信息。机器人数据往往只有几十到几百条示范，如果视觉编码器从零训练，很容易过拟合到训练场景的背景、光照上。常见的替代办法是借用通用的预训练模型：ImageNet上监督训练的ResNet、MoCo这样的自监督模型、或者CLIP。但它们学的是“这张图里有什么”，对于操作最关键的东西——物体在被怎么移动、手和物体怎么接触、任务进展到哪一步——并没有特别关注。

2021年的Ego4D提供了大量第一人称视角的人类日常视频，很多是做饭、收拾这类手部操作，并配有“正在做什么”的旁白。问题是怎样从中学出对机器人有用的表示。

方法

编码器 F_φ 是一个ResNet-50，把一帧图像变成向量 z。训练目标由三部分加权求和：

时间对比学习（见对比学习）。从同一段视频里取三帧 I_i, I_j, I_k（时间顺序 i<j<k），要求 z_i 与较近的 z_j 的相似度，高于与较远的 z_k、以及与其他视频帧的相似度，用InfoNCE损失训练。这迫使表示捕捉手和物体状态这类随时间变化的东西，而非不变的背景。

视频—语言对齐。一个打分网络 G_θ(z_0, z_i, l) 输入起始帧、后续某帧和旁白句子 l（用DistilBERT编码），输出“从起始画面到这一帧，是否在完成这句话描述的事”。训练要求分数随视频进行而上升，且配对正确的句子分数更高。这让表示关注与任务语义相关的变化。

稀疏惩罚。对 z 加L1和L2正则（见正则化与权重衰减），鼓励紧凑、只保留少数关键特征，以减少对无关细节的过拟合。

下游使用。训练好后冻结编码器，机器人策略只训练一个小的MLP，把R3M特征和本体状态映射成动作，用少量示范做行为克隆。

结果

在Adroit、Franka-Kitchen、Meta-World三个仿真基准的12个任务上，只给少量示范，R3M比从零训练的成功率高20%以上，比CLIP、ImageNet监督特征和MoCo等表示高10%以上。消融显示三项目标都有用。真机上，Franka Panda机械臂在一个杂乱的真实公寓环境里，每个任务只用20条示范就学会了多种操作。

后来的发展

R3M开启了“用人类视频预训练机器人视觉表示”这条路线：VIP价值隐式预训练把同样的Ego4D数据改用价值函数的形式预训练。后来的研究进一步不满足于只学表示，而是直接从人类和机器人视频中学预测和动作：GR-1视频预训练策略、Video Prediction Policy用视频生成预训练整个策略，EgoMimic把人类第一人称视频与机器人数据联合训练。

局限与后续

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    视觉编码器是ResNet-50，并开放了ResNet-18/34版本。
  • 竞争
    CLIP2021.01 · 多模态
    CLIP用网络图文学通用语义；R3M用人类操作视频学时间动态，在机器人少样本模仿上高出10%以上。
  • 竞争
    MoCo2019.11 · 视觉
    MoCo在ImageNet上做图像级对比学习；R3M改为视频帧之间的时间对比，更关注操作过程中的变化。
  • 使用
    DistilBERT2019.10 · 系统·效率
    用DistilBERT编码Ego4D的旁白句子，用于视频—语言对齐目标。
  • 使用
    Ego4D2021.10 · 数据·评测
    预训练数据完全来自Ego4D的第一人称人类日常视频及其文字旁白。

读懂它需要的概念

对比学习 自监督学习 迁移学习 模仿学习与行为克隆 正则化与权重衰减

本篇术语

  • 时间对比学习　把同一视频里时间上相近的帧当作正样本、相隔较远或来自别的视频的帧当作负样本来训练表示，让表示随任务进展平滑变化。
  • 冻结表示　预训练好的编码器参数在下游训练中不再更新，只训练后面的小网络；省数据、省算力，也避免小数据把预训练特征破坏掉。
  • 第一人称视频　由头戴相机拍摄、从拍摄者自己眼睛视角看到的视频，画面里常能看到自己的手在操作物体。
