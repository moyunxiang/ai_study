DMCNN事件抽取

Event Extraction via Dynamic Multi-Pooling Convolutional Neural Networks
2015.07论文延伸ACL 2015Yubo Chen, Liheng Xu, Kang Liu, Daojian Zeng, Jun Zhao · 中国科学院自动化研究所待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

事件抽取要找出句子里的事件触发词（「被捕」表示逮捕事件）和事件论元（谁被捕、在哪里），以往方法依赖词性、依存、实体类型等复杂的人工特征和外部NLP工具，错误层层传递；而一句话里常有多个事件，普通的最大池化会把它们的信息混在一起。

方法

用卷积网络自动学习词汇和句子级特征，并提出动态多池化：根据当前候选触发词和候选论元的位置，把卷积特征图切成几段，每段分别做最大池化，从而保留与这对候选相关的关键信息。

影响

DMCNN是神经事件抽取的代表性早期工作，在ACE 2005上超过了特征工程方法；「按位置分段池化」的做法与同组的PCNN关系抽取一起被广泛沿用。

背景

事件抽取的标准评测是ACE 2005：33种事件类型（攻击、逮捕、选举……），任务分两阶段：触发词分类（找出表示事件的词并定类型）和论元分类（对每个实体判断它在事件中的角色，如施事、受害者、地点）。此前最好的系统（如Li等2013的结构化感知机联合模型）依赖大量人工特征。TextCNN句子分类、从零开始的神经NLP表明卷积网络能自动学习句子特征，但标准最大池化只保留整句最强的一个特征，一句话含多个事件时，与当前触发词或论元无关的信息会占据主导。

方法

输入表示：每个词由三部分拼接——预训练词向量（word2vec）、与候选触发词的相对位置向量、与候选论元的相对位置向量（论元阶段）、以及事件类型嵌入。

词汇级特征：候选词及其左右邻词的词向量。

句子级特征：在整句上做卷积，得到每个位置的特征 c_i。动态多池化：在论元分类中，以候选触发词和候选论元的位置把句子切成三段，每段内分别取最大值：

p_j = max_{i∈段j} c_i，j = 1, 2, 3

三个结果拼接成句子级特征；触发词分类时按触发词位置切成两段。

分类：词汇级与句子级特征拼接后经softmax，分别预测触发词类型或论元角色。两个阶段使用相同结构、各自训练。

结果

论文在ACE 2005上报告：DMCNN在触发词分类和论元分类上都优于当时基于人工特征的最好方法；具体F1数字未核对。

后来的发展

此后的事件抽取用双向RNN联合建模触发词和论元（JRNN）、图卷积利用依存树、BERT等预训练模型，以及把事件抽取改写为问答或生成（如Text2Event、DEGREE）；MAVEN等更大规模的事件检测数据集也相继出现。分段池化的思想在关系抽取的PCNN远程监督关系抽取中同期出现，两者常被一起引用。

本篇术语

  • 事件抽取　从文本中找出发生了什么事件（触发词及事件类型）以及事件的参与者、时间、地点等论元。
  • 触发词（trigger）　最能表明某个事件发生的词，例如「袭击」「当选」「辞职」。

怎么学

先了解TextCNN句子分类的卷积句子分类 → 读原文第3节动态多池化 → 动手：在一个公开的事件检测数据（如MAVEN）上实现触发词分类，比较普通最大池化与按触发词位置分两段池化的F1。
