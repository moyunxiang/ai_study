Cambricon神经网络指令集

Cambricon: An Instruction Set Architecture for Neural Networks
2016.06论文延伸ISCA 2016Shaoli Liu, Zidong Du, Jinhua Tao, Dong Han, Tao Luo, Yuan Xie, Yunji Chen, Tianshi Chen · 中科院计算所 / UCSB等待核对
IEEE DOI ↗在交互版中打开（演化树、学习进度）

问题

早期神经网络加速器的指令直接对应“一层”甚至“一整个网络”，容易实现，但网络结构一变就不支持，缺乏通用性。

方法

不再按层设计指令，而是分析大量神经网络算法后，提出一套面向神经网络的精简load-store指令集，包含标量、向量、矩阵、逻辑、数据传输和控制指令，用通用的小指令组合出各种网络。

影响

第一批为神经网络专门设计指令集架构的工作之一，成为寒武纪公司后续处理器的基础，也说明了专用加速器同样需要IBM System/360：兼容的计算机家族式“架构与实现分离”的接口。

方法

论文摘要先指出问题：已有的加速器只面向少数计算模式相近的网络，它们的指令是复杂的、直接对应高层功能块（如一层或整个网络）的控制信号，一旦遇到新的网络结构就无能为力。

Cambricon借鉴通用处理器里RISC精简指令集的思路：基于对现有神经网络技术的全面分析，定义一套load-store架构的指令集，数据只能通过专门的加载、存储指令在内存和片上暂存器之间移动，计算指令则分为标量、向量、矩阵、逻辑几类，再加上控制流指令。一层全连接可以写成“矩阵乘向量 + 向量加 + 激活函数”几条指令，卷积、池化、循环网络也都能由这些基本指令组合出来。

为了配合大块数据运算，它用片上暂存存储器代替传统的向量寄存器堆，矩阵和向量指令直接对暂存器里的大块数据操作。摘要称，在10种有代表性且各不相同的神经网络技术上评估，Cambricon显示出很强的表达能力。

局限与后续

  • 论文时期的设计主要面向推理和较小的网络，没有覆盖训练和后来规模大得多的Transformer模型对内存带宽的需求。
    本站还没有记录针对它的后续工作（不代表没有人解决）

矩阵乘法与线性变换 CPU、GPU与并行计算 多层感知机

本篇术语

  • load-store架构　只有专门的加载、存储指令可以访问内存，运算指令只处理寄存器或片上存储里的数据。
  • 代码密度　完成同样功能所需的指令数量或程序大小，越小说明指令表达能力越强。

怎么学

先读DianNao神经网络加速器理解早期加速器的结构，再读RISC精简指令集；然后对照本文的指令表，试着用矩阵乘向量、向量加、激活三类指令写出一个两层MLP的前向计算。
