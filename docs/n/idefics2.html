Idefics2设计选择

What matters when building vision-language models?
2024.05论文延伸NeurIPS 2024Hugo Laurençon, Léo Tronchon, Matthieu Cord, Victor Sanh · Hugging Face待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉语言模型的很多设计决定缺少依据，难以判断哪些选择真正带来提升。

方法

围绕预训练模型、架构、数据和训练方法做大量实验，并据此构建80亿参数的Idefics2，基于SigLIP与Mistral-7B。

影响

以8B规模取得同尺寸最佳，常常追平大4倍的模型，并开放模型和训练数据集，成为透明的开源配方。

方法

Idefics2把SigLIP视觉塔与Mistral 7B语言模型相连，沿用Flamingo一脉的交错图文数据设计。论文的价值在于逐项实验的结论，例如视觉塔、语言骨干、连接方式（如用查询向量压缩视觉词元）、图像分辨率处理和训练数据的选择，对性能各自的影响。

论文称，Idefics2在多个多模态基准上达到同规模最佳，经常与大它四倍的模型相当；基座、指令和对话版本连同训练用数据集一起发布。

局限与后续

  • 公开数据质量参差，文档和长文本场景仍然较弱。
