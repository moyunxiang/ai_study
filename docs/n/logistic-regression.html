逻辑回归

The Regression Analysis of Binary Sequences
1958论文重要Journal of the Royal Statistical Society B 1958David R. Cox · Birkbeck College, London待核对
DOI ↗Wikipedia: Logistic regression ↗在交互版中打开（演化树、学习进度）

问题

结果只有“是/否”两种（病人是否康复、零件是否失效），普通线性回归会预测出小于0或大于1的“概率”，也没有合理的误差模型。

方法

不直接回归概率，而是回归概率的对数几率：log(p/(1−p)) = β·x，再用sigmoid函数把线性得分压回(0,1)，用最大似然估计系数。

影响

成为二分类的标准统计模型；在机器学习里，它就是“一个sigmoid神经元加交叉熵损失”，今天每个分类网络的最后一层仍是它（多类时为softmax）。

背景

很多实际问题的结果是二值的：一种药剂量下虫子死没死、一位病人治疗后好没好。研究者想知道各个因素（剂量、年龄、体重）怎样影响“发生”的概率。

直接用线性回归p = β·x有两个毛病。一是右边可以取任意实数，预测出的“概率”会跑到0到1之外；二是二值结果的方差随p变化（p(1−p)），违背了最小二乘“误差方差恒定”的假设。

当时已有两条线索：19世纪Verhulst为人口增长提出的logistic曲线，以及1944年Berkson提出的“logit”。Cox这篇1958年的论文把对二值序列的回归分析系统化了：怎样设定模型、怎样估计、怎样检验。

方法

模型。对输入x，先算线性得分z = β₀ + β₁x₁ + … + β_dx_d，再用logistic函数（即sigmoid，见逻辑回归）把它变成概率：

p(y=1 | x) = σ(z) = 1 / (1 + e^(−z))

反过来写就是log(p/(1−p)) = z：模型假设对数几率是输入的线性函数。系数β_j的含义很直观——x_j增加1，几率p/(1−p)乘以e^(β_j)。

估计。用最大似然（见最大似然估计）。对n个样本，对数似然为

ℓ(β) = Σ [ y_i log p_i + (1 − y_i) log(1 − p_i) ]

取负号就是今天的二元交叉熵损失。它对β是凹函数，没有坏的局部最优，梯度形式非常简洁：∂ℓ/∂β = Σ (y_i − p_i)·x_i——预测与真实之差乘以输入，与感知机的更新规则形状几乎一样，只是把0/1的硬判断换成了连续概率。统计学里通常用牛顿法（迭代重加权最小二乘）几步就收敛。

例子。若某个模型z = −4 + 2x，那么x = 2时z = 0，概率正好0.5；x = 3时z = 2，概率约0.88。x每加1，几率乘以e² ≈ 7.4。

后来的发展

逻辑回归是统计学中广义线性模型的一员，也是机器学习里最常用的基线分类器。多类推广（multinomial logit，即softmax回归）在1960年代出现；在NLP中它以“最大熵模型”的名字被广泛使用（最大熵模型），条件随机场（条件随机场）则把它推广到整条序列的结构化输出。

对神经网络而言，逻辑回归就是一个用sigmoid激活、用交叉熵训练的神经元。多层网络（反向传播）可以看作在逻辑回归前面加上若干层可学习的特征变换；今天的图像分类网络和大语言模型，最后一层依然是一个Softmax与logits回归——只是它的输入特征不再由人设计，而是由前面的网络学出来。

容易误解的地方

  • 名字叫“回归”，用途是分类：它回归的是对数几率，再用阈值（通常0.5）做判断。
  • 如果训练数据线性可分，最大似然会让系数趋向无穷大，必须加正则化（见岭回归与L2正则）。

局限与后续

  • 决策边界是输入空间中的一个超平面，像XOR这样不能被一条直线分开的问题它学不会，除非人工构造交叉特征。
    后来针对它的工作　核技巧与最优间隔分类器 支持向量机 反向传播
  • 效果完全取决于人设计的输入特征；面对图像、语音这样的原始信号，线性模型几乎无能为力。
    后来针对它的工作　反向传播 LeNet与卷积网络 AlexNet
  • 数据线性可分时最大似然估计不存在（系数发散），特征多、样本少时容易过拟合。
    后来针对它的工作　岭回归与L2正则 Lasso与L1稀疏

读懂它需要的概念

线性回归 逻辑回归 最大似然估计 交叉熵 导数、偏导与梯度

本篇术语

  • 几率与对数几率　几率odds是p/(1−p)，例如概率0.8对应几率4（发生的可能是不发生的4倍）。对数几率logit是它的自然对数，取值范围是整个实数轴。
  • 广义线性模型　一类统计模型：输入的线性组合通过一个“连接函数”与输出的期望相联系。线性回归、逻辑回归、泊松回归都是它的特例。

怎么学

先补最大似然估计和交叉熵。然后用numpy从零实现：生成两团二维高斯点，写出交叉熵损失和梯度，用梯度下降训练，画出决策直线；再把数据换成XOR形状，观察它失败，并尝试加入x₁·x₂特征后成功。最后对照scikit-learn的LogisticRegression验证结果。
