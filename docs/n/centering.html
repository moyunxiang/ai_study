中心理论

Centering: A Framework for Modeling the Local Coherence of Discourse
1995.06论文延伸Computational Linguistics 1995Barbara J. Grosz, Aravind K. Joshi, Scott Weinstein · 哈佛大学、宾夕法尼亚大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

为什么有的段落读起来顺畅、有的别扭？说话人什么时候用代词、什么时候重复名字？语篇的「局部连贯」缺少一个能用来计算的理论。

方法

每句话都有一个「回指中心」，即它承接上一句最突出的那个实体；连贯的语篇倾向于保持中心不变，并且用代词指称中心。用几条规则和几种中心转移类型刻画这种偏好。

影响

中心理论成为计算语篇学的基础理论之一，直接催生了BFP代词消解算法，也启发了后来基于实体的连贯性模型（如Barzilay与Lapata的实体网格），在文本生成和摘要连贯性评估中被反复使用。

背景

Grosz与Sidner（1986）把语篇结构分为语言结构、意图结构和注意状态三层，其中注意状态描述「此刻大家在关注哪些实体」。修辞结构理论RST刻画的是句子之间的修辞关系，属于全局结构；而代词选择、指称连贯这类现象发生在相邻几句之间。Grosz、Joshi和Weinstein在1983年就提出了中心的初步想法，这篇1995年的论文给出了经过修订和扩充的完整版本（初稿已在学界流传多年）。

方法

对语篇中的每个话语（大致是一个小句）U_n，定义：

  • 前瞻中心 Cf(U_n)：U_n中提到的所有实体，按突出程度排序，通常主语 > 宾语 > 其他；
  • 回指中心 Cb(U_n)：Cf(U_{n−1})中排位最高、且在U_n中再次出现的那个实体——它是U_n「承接」上一句的东西；
  • 优先中心 Cp(U_n)：Cf(U_n)中排第一的实体，是下一句最可能承接的对象。

规则1（代词规则）：如果Cf(U_{n−1})中有某个实体在U_n里用代词表达，那么Cb(U_n)也必须用代词表达。

规则2（转移偏好）：相邻话语之间的中心转移按连贯程度排序：延续（Cb不变，且它仍是优先中心）优于保持（Cb不变，但已不是优先中心）优于转换（Cb改变）。

例：「约翰去了商店。他买了钢琴。他很高兴。」——Cb一直是约翰并且用代词，属于连续的「延续」，读起来最顺。若第三句改成「钢琴很贵」，Cb转移，读者需要额外的推理负担。理论预测：转移越少、中心越常用代词，语篇越连贯，理解成本越低。

后来的发展

Brennan、Friedman与Pollard（1987）据中心理论设计了BFP代词消解算法，常与Lappin-Leass代词消解和Hobbs指代消解算法并列比较。Poesio等人用语料系统检验了中心理论的各种参数设定。Barzilay与Lapata（2008）的实体网格把「实体在相邻句子中的语法角色变化」做成可学习的特征，用于连贯性评估和句子排序，被视为中心理论的统计化版本。

它建立在什么之上

  • 延续
    Hobbs指代消解算法1978 · NLP
    Hobbs从句法角度给出代词搜索算法，中心理论从注意状态角度解释为什么某个实体会被代词指回。
  • 改进
    话语表示理论DRT1981 · NLP
    可及性只给出代词「能指向谁」的约束，在多个可及候选中「实际指向谁」仍需要显著度、常识等其他知识。
  • 竞争
    修辞结构理论RST1988 · NLP
    RST刻画句子之间的修辞关系和全局树结构，中心理论只刻画实体层面的局部连贯，二者关注语篇的不同层面。
  • 竞争
    Lappin-Leass代词消解1994.12 · NLP
    两者都用「实体的突出程度」解释代词选择；中心理论给出离散的转移规则，Lappin-Leass给出连续的数值显著度。

读懂它需要的概念

命题逻辑、谓词逻辑与符号推理

本篇术语

  • 回指中心（Cb）　当前句承接上一句的那个最突出的实体，每句最多一个。
  • 前瞻中心（Cf）　当前句提到的所有实体，按语法角色等因素排出的突出度序列。
  • 局部连贯　相邻几句之间读起来是否衔接顺畅，主要取决于它们谈论的实体如何延续。

怎么学
