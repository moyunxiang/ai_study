ReMDM重掩码采样

Remasking Discrete Diffusion Models with Inference-Time Scaling
2025.03论文延伸NeurIPS 2025Guanghan Wang, Yair Schiff, Subham Sekhar Sahoo, Volodymyr Kuleshov · 康奈尔大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

扩散模型的一大卖点是反复修正，但掩码离散扩散（MDLM等）里一个token一旦被解码出来就固定不变，即使它是错的也无法再改；多给采样步数，质量也很快饱和。

方法

从一个带自定义“重掩码”反向过程的离散扩散模型推导出新的采样器：每一步不仅把一些[MASK]解码成词，也以概率σ_t把已经解码的词重新变回[MASK]，让模型有机会改正。它直接用于已训练好的掩码扩散模型，不需要重新训练。

影响

让掩码扩散模型第一次有了“步数越多、质量越好”的推理时计算扩展：步数足够时生成文本质量接近自回归模型，算力受限时也更能保持质量；重掩码思路随后在扩散语言模型的采样研究中被广泛跟进。

方法

背景：掩码扩散语言模型MDLM、MD4简化掩码扩散、离散扩散语言模型SEDD等掩码（吸收态）离散扩散模型的前向过程逐步把token换成[MASK]，q(z_t | x) = Cat(α_t x + (1−α_t) m)，α_t从1降到0。标准的反向过程中，若 z_t ≠ m（已解码），则 z_s = z_t 保持不变——这正是“不能修改”的来源。

ReMDM反向过程：作者构造了一族与原前向边缘分布一致的反向过程，引入重掩码概率σ_t：

  • 若 z_t ≠ m：q_σ(z_s | z_t, x) = Cat((1−σ_t)·x + σ_t·m)，即以概率σ_t把已解码的词重新掩掉；
  • 若 z_t = m：解码为x与保持掩码的概率相应调整，使得边缘分布 q(z_s|x) 不变。

σ_t=0时退化为MDLM原来的采样器。由于该过程的负ELBO与MDLM只差一个与σ有关的加权，预训练好的掩码扩散模型可以直接用作其去噪网络x_θ，无需重训。作者给出几种σ_t的调度方式：常数上限、随时间变化的退火调度，以及按模型置信度决定哪些词更该被重掩码（低置信度的先掩）。

结果：摘要称增加采样步数时，ReMDM生成的自然语言质量逐步接近自回归模型；算力有限时也比原采样器更好地保持质量。它同样提升了离散化图像的掩码扩散模型的样本质量；在分子设计等科学任务中，ReMDM便于做扩散引导，在可控性上优于经典的掩码扩散和均匀噪声扩散。

局限与后续

  • 重掩码引入额外的超参数（σ_t上限、调度、开始重掩码的时刻），最优设置依任务和步数而变，缺少统一的选择准则。

读懂它需要的概念

扩散：前向加噪与反向去噪 掩码建模 变分推断与ELBO 马尔可夫性与马尔可夫链 解码：贪心、束搜索、温度与top-p

本篇术语

  • 吸收态（absorbing state）　离散扩散中的[MASK]状态：前向过程中token一旦变成[MASK]就一直保持，反向过程从全[MASK]开始逐步还原。
  • 推理时计算扩展　不改模型参数，只增加生成时的计算（步数、采样次数），换取更好的输出质量。
