YouTube REINFORCE推荐

Top-K Off-Policy Correction for a REINFORCE Recommender System
2018.12论文延伸WSDM 2019Chen, Beutel, Covington, Jain, Belletti, Chi · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

工业推荐系统的候选物品有几百万个，用户数十亿，数据又是旧版推荐器产生的日志，带有选择偏差；一次还要推荐多个物品。

方法

把推荐当作序列决策，用REINFORCE策略梯度策略梯度训练，并加上离策略修正和针对「一次推荐K个」的top-K修正。

影响

是策略梯度方法在大规模线上推荐的早期落地案例，论文称在YouTube线上实验中见效。

方法

每次用户交互看作一步：状态是用户历史，动作是推荐哪个物品（动作空间达百万量级），奖励来自点击、观看时长等隐式反馈。训练数据来自多个旧策略的日志，所以梯度要乘上重要性权重π(a|s)/β(a|s)做离策略修正（见重要性采样），其中β是用神经网络另外估计的日志行为策略。

又因为一次展示K个物品，朴素做法会让相似的物品重复出现；论文推导出一个top-K修正项，使得学习目标考虑到整个列表中至少有一个被点击的概率。此外论文展示了探索的价值。论文用模拟和多次线上实验验证。具体提升幅度这里没有核实，故不引用。

局限与后续

  • 重要性权重方差大，需要截断，带来偏差。

  • 奖励只是点击等短期信号，对用户长期满意度的优化并不直接。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    REINFORCE策略梯度1992 · RL
    核心是在百万动作空间上扩展REINFORCE。
  • 改进
    Netflix Prize2006.10 · 数据·评测
    优化的是显式星级评分的RMSE，而真实推荐更关心排序、点击、观看等隐式反馈和长期满意度。
  • 改进
    LinUCB上下文老虎机2010.02 · RL
    每次只看单次点击这一步奖励，不考虑推荐对用户之后是否回访、观看多久等长期影响。
