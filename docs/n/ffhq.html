FFHQ高清人脸库

Flickr-Faces-HQ Dataset (FFHQ)
2018.12数据集延伸随StyleGAN论文发布（arXiv 2018，CVPR 2019）Tero Karras, Samuli Laine, Timo Aila · NVIDIA待核对
官方仓库 ↗StyleGAN论文（附录A） ↗在交互版中打开（演化树、学习进度）

问题

高分辨率人脸生成当时主要用名人照片做成的CelebA-HQ，年龄、种族和背景的变化有限，生成模型学不到人脸的多样性。

方法

从Flickr爬取宽松许可的人像照，用人脸关键点自动对齐裁成1024×1024，再自动过滤加人工剔除雕像、画作和翻拍照片，得到7万张。

影响

自StyleGAN起成为高分辨率人脸生成的默认基准，StyleGAN2、EG3D三维感知GAN、NVAE层级VAE、R3GAN现代GAN基线等都报告FFHQ上的FID。

方法

据StyleGAN论文附录A和官方仓库，FFHQ（Flickr-Faces-HQ）共70,000张1024×1024的PNG人脸图，只收集了宽松许可（知识共享、公有领域、美国政府作品）的Flickr照片，用dlib的68个人脸关键点自动对齐和裁剪；先用自动过滤器筛选，再由众包标注Mechanical Turk工人剔除偶尔出现的雕像、画作和照片翻拍。论文称它在年龄、种族和背景上的变化远多于CelebA-HQ（渐进式增长GAN从CelebA制作的高清版），眼镜、墨镜、帽子等配饰也覆盖得更好。仓库建议前60,000张作训练、后10,000张作验证，并提供128×128缩略图和未裁剪的原图。

StyleGAN在FFHQ上的FID为4.40（不用截断技巧、5万张样本），StyleGAN2降到2.84。

容易误解的地方

  • 论文里的FID通常是在1024×1024全分辨率、5万张样本、不用截断技巧时算的；不同分辨率版本（如256×256）的数字不可直接比较。
  • 不同论文对“训练集”的用法不一，有的用全部7万张，有的只用前6万张。

局限与后续

  • 图片来自Flickr，官方明说继承了该网站的各种偏差；照片里是真人，虽为宽松许可，但涉及隐私，官方提供了按Flickr用户名查询和申请删除的途径。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 数据集本身以CC BY-NC-SA 4.0发布，限非商业使用，并要求不得用于开发或改进人脸识别技术。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    渐进式增长GAN2017.10 · 生成
    PGGAN制作了1024分辨率的CelebA-HQ，FFHQ沿用同样的1024×1024对齐人脸格式，扩大规模与多样性。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测
    自动过滤后由众包工人剔除雕像、画作和翻拍照片。
  • 改进
    CelebA2014.11 · 数据·评测
    CelebA及其高清版CelebA-HQ多样性不足，FFHQ在年龄、种族、背景和配饰上覆盖更广。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

生成质量指标：IS与FID 图像作为张量 训练集、验证集与测试集

本篇术语

  • 人脸对齐　先检测眼睛、鼻子、嘴角等关键点，再旋转缩放裁剪，让所有图里五官大致落在同一位置，方便生成模型学习。
  • FFHQ 256 / 1024　同一数据集缩放到不同分辨率的版本；扩散和自回归模型常用256×256，GAN论文多用1024×1024。

怎么学

先读生成质量指标：IS与FID和StyleGAN讲解；动手：下载128×128缩略图版本，用一个小型生成模型训练，算一下与真实图片的FID；再读仓库里的许可与隐私说明。
