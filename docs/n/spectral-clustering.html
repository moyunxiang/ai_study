谱聚类NJW

On Spectral Clustering: Analysis and an algorithm
2001.12论文延伸NIPS 2001Andrew Y. Ng, Michael I. Jordan, Yair Weiss · 加州大学伯克利分校、耶路撒冷希伯来大学待核对
NeurIPS论文页 ↗在交互版中打开（演化树、学习进度）

问题

k-means聚类假设每一簇是围绕中心的凸团，遇到环形、月牙形这类弯曲的簇就分错；当时已有不少用矩阵特征向量做聚类的算法，但用法各不相同，而且大多没有证明能得到合理的聚类。

方法

先按两两相似度建一个亲和矩阵，取其归一化版本的前k个特征向量，把每个点映射成这k维空间里的一行并归一化长度，再在这个新空间里跑k-means；并用矩阵扰动理论分析算法何时有效。

影响

NJW算法成为谱聚类最常用的标准版本，被写进各类机器学习教材和scikit-learn；“先做谱嵌入再聚类”的思路也连接了图划分、流形学习与后来的图神经网络中关于图拉普拉斯的大量工作。

方法

算法只有几步，论文强调用几行Matlab就能实现：

  • 对n个点计算亲和矩阵 A_ij = exp(−‖s_i − s_j‖² / 2σ²)，对角线置0；
  • 令D为A每行之和构成的对角矩阵，构造归一化矩阵 L = D^(−1/2) A D^(−1/2)；
  • 取L最大的k个特征向量排成n×k矩阵X，把X的每一行归一化为单位长度得到Y；
  • 把Y的每一行当作一个k维点，用k-means分成k类，原始点i归入第i行所属的类。

直观解释：如果数据恰好分成k个彼此不相连的簇，A就是分块对角的，前k个特征向量各自只在一个簇上非零，归一化后同一簇的点会落在k维空间的同一个点上，任何聚类方法都能轻松分开。真实数据的簇之间有少量弱连接，相当于对理想情况加了一个小扰动；作者用矩阵扰动理论给出条件：簇内连接足够紧、簇间连接足够弱时，Y的各行仍会紧紧聚在k个相互正交的方向附近。

论文页摘要报告：作者给出这一简单算法，用矩阵扰动理论分析它，给出可预期它表现良好的条件，并在若干有挑战性的聚类问题上展示了令人满意的结果。

局限与后续

  • 需要存储n×n的亲和矩阵并做特征分解，样本数到十万级以上时计算和内存都难以承受。

本篇术语

  • 亲和矩阵　n×n矩阵，第(i, j)个元素表示样本i和j有多相似，越近数值越大。

怎么学

先复习特征分解和k-means聚类；在scikit-learn的“双环”数据上分别跑k-means与按本文步骤手写的谱聚类，画出聚类结果；再改变σ，观察结果如何变化。
