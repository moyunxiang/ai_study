梯度TD（GTD/TDC）

Fast Gradient-Descent Methods for Temporal-Difference Learning with Linear Function Approximation
2009论文延伸ICML 2009Sutton, Maei, Precup, Bhatnagar, Silver, Szepesvári, Wiewiora · University of Alberta / McGill / IISc待核对
论文PDF ↗在交互版中打开（演化树、学习进度）

问题

Baird反例与发散问题表明离策略学习加线性函数近似加自举会发散；要有一个既收敛又不太慢的TD算法。

方法

把TD学习当作对一个目标函数做真正的随机梯度下降，推导出GTD2和TDC两个算法，既能离策略训练，又保证收敛。

影响

第一批在离策略与线性函数近似下保证收敛的TD方法，对后来的离策略评估、Emphatic TD与致命三元组的研究有影响。

方法

论文说明，Sutton、Szepesvári与Maei（2009）刚提出的GTD是第一个与线性函数近似和离策略训练都兼容、且复杂度只与特征数线性相关的TD算法，但收敛很慢，实用价值存疑。本文提出两个收敛更快的新算法。

GTD2：使用不同的目标函数，推导和收敛证明与GTD类似，收敛明显更快，但仍慢于传统TD。TDC（线性TD加梯度修正）：更新规则与传统TD相同，只多了一个初始为零的修正项。论文称在小的测试问题和一个有一百万个特征的计算机围棋应用上，TDC的学习速度与传统TD相当；它看起来能在只使计算量翻倍的代价下，把线性TD扩展到离策略学习。

局限与后续

  • 只在线性函数近似下有保证；与非线性的深度网络结合时仍然没有收敛保证。
    后来针对它的工作　致命三元组
  • 需要同时维护第二组权重与额外步长，调参比普通TD更麻烦。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    时序差分学习1988 · RL
    与非线性函数近似或离策略数据结合时可能发散，论文没有讨论。
  • 改进
    Q-learning1992 · RL
    收敛只对表格成立；换成线性或神经网络近似后可能发散。
  • 改进
    TD-Gammon1995 · RL
    非线性神经网络下的TD学习没有收敛保证，为什么在这里有效缺乏理论解释。
  • 改进
    SARSA1994 · RL
    在非线性函数近似下没有收敛保证。
  • 改进
    Baird反例与发散问题1995 · RL
    对Baird反例所示的离策略线性TD发散问题给出收敛的算法。
  • 改进
    最小二乘TD（LSTD）1996 · RL
    每次更新的代价与特征数的平方成正比，特征很多时不可行。
  • 延续
    线性TD收敛性分析1997 · RL
    把线性TD收敛性的分析推广到离策略的设置。

后来的相关工作

  • 使用
    确定性策略梯度DPG2014.06 · RL
    COPDAC-GQ用梯度TD式的critic，保证离策略+线性近似下的收敛。
  • 竞争
    强调TD（Emphatic TD）2015.03 · RL
    两者都让线性离策略TD稳定且每步线性计算；梯度TD需要第二组参数，强调TD只需一组参数一个步长。
  • 改进
    致命三元组2018.12 · RL
    只在线性函数近似下有保证；与非线性的深度网络结合时仍然没有收敛保证。

读懂它需要的概念

时序差分与自举 梯度下降 on-policy与off-policy Bellman方程 向量、矩阵与张量

怎么学

先学时序差分与自举和on-policy与off-policy，再在Baird反例上分别跑普通TD和TDC，观察发散与收敛。
