ROVER系统融合

A post-processing system to yield reduced word error rates: Recognizer Output Voting Error Reduction (ROVER)
1997论文延伸IEEE ASRU 1997Jonathan G. Fiscus · NIST待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

DARPA评测里各家识别系统犯的错并不完全相同，但每个系统只交出一份转写，没有办法把它们各自的长处合起来。

方法

把多个系统输出的词序列用动态规划对齐成一张「词转移网络」，在每个对齐位置上投票（可结合置信度）选出最终的词。

影响

ROVER成为语音识别评测和工业系统里最常用的多系统融合方法，后来几乎每届评测的冠军系统都用某种形式的系统融合。

方法

在DARPA共同评测范式的共同评测里，NIST手上有许多参赛系统对同一批录音的转写结果。Fiscus观察到，不同系统的错误位置往往不重合，如果能在词的层面「少数服从多数」，整体错误率就可能低于其中最好的单个系统。

ROVER分两步。第一步对齐：先拿一个系统的输出作为骨架，依次把其他系统的词序列用编辑距离式的动态规划（见动态规划）对齐进来，得到一张词转移网络（WTN）：每个位置上是若干候选词，可能包括「空」（表示有的系统在这里没有输出词）。第二步投票：在每个位置上给候选词打分，最简单是数票数，也可以把各系统给出的词置信度加权进去，用一个参数在「票数」和「置信度」之间折中，取分最高的词作为输出。

这种做法不需要改动任何一个识别系统内部，只处理最终文字，所以可以融合结构完全不同的系统。之后出现了在词图层面融合的confusion network combination等改进，但ROVER因为简单通用，一直沿用到神经网络时代，比如融合多个端到端模型的输出。原文的具体降错幅度未核对，此处不写数字。

  • 只看各系统的1-best文字，丢掉了词图里的其他候选，融合时可用的信息有限。

读懂它需要的概念

动态规划 词错误率 集成学习 输入输出不等长时的对齐

本篇术语

  • 系统融合　把多个独立训练的识别系统的输出合并，得到比任何单个系统都好的结果。
  • 词转移网络（WTN）　对齐后每个位置有若干候选词的线性网络，投票就在每个位置上进行。
