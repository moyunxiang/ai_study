API-Bank工具调用评测

API-Bank: A Comprehensive Benchmark for Tool-Augmented LLMs
2023.04数据集延伸EMNLP 2023Minghao Li, Yingxiu Zhao, Bowen Yu, Feifan Song, Hangyu Li, Haiyang Yu, Zhoujun Li, Fei Huang, Yongbin Li · 阿里巴巴达摩院 / 北京航空航天大学 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型可以调用外部工具来增强能力，但三个问题没有答案：现有模型用工具到底多有效、怎样提升用工具的能力、还有哪些障碍。

方法

搭建一个可实际运行的API评测系统，人工标注多轮工具使用对话来考模型的规划、检索和调用能力，同时构造大规模训练集训练工具增强模型。

影响

是最早一批系统评测大模型工具调用的基准之一，和ToolBench、BFCL一起常被工具学习论文作为评测集。

方法

评测系统。实现了73个可运行的API工具（如查天气、订会议室、记日程、搜索），人工标注了314段工具使用对话，共753次API调用。评测分三个层次：直接调用（给定要用的API）、检索加调用（模型先从工具库里找合适的API）、规划加检索加调用（模型自己决定分几步、用哪些工具）。

训练集与Lynx。从1,000个不同领域的2,138个API出发，构造了1,888段工具使用对话作为训练数据，用它从Alpaca与廉价指令微调初始化训练出工具增强模型Lynx。

结果。摘要称，GPT-3.5比GPT-3用工具的能力有所提升，GPT-4在规划上表现突出，但都还有很大提升空间。Lynx的工具使用能力比Alpaca高26分以上，接近GPT-3.5。作者还做了错误分析，总结了工具使用中的主要障碍。

局限与后续

  • API数量和对话规模较小，工具多为模拟实现；评测侧重单次对话内的调用格式，难以反映真实复杂工作流。
