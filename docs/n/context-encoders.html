Context Encoders图像修补

Context Encoders: Feature Learning by Inpainting
2016.04论文延伸CVPR 2016Pathak, Krähenbühl, Donahue, Darrell, Efros · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自监督预测任务多是分类式的，没有让网络真正生成图像内容；传统图像修补也缺少语义理解。

方法

挖掉图像中间一块，让编码器-解码器网络依据周围内容生成缺失部分，并加上对抗损失使结果更清晰。

影响

同时是早期的语义图像修补方法和自监督预训练方法，把GAN引入了图像条件生成。

方法

网络是一个自编码器式的编码器-解码器：输入是被挖去一块的图像，输出是缺失的那块。论文试了两种损失：只用逐像素重建损失时，结果模糊，因为缺失内容往往有多种合理答案，网络只能给出平均；再加上对抗损失（生成对抗网络GAN的判别器）后，输出明显更清晰，因为判别器逼它选择一种逼真的答案。

论文称这样学到的特征不仅包含外观，也包含语义，用作分类、检测和分割的预训练，并可单独用于语义修补，或作为非参数方法的初始化。

局限与后续

  • 生成的块边缘常有伪影，分辨率低，不能处理任意形状的缺失区域。
