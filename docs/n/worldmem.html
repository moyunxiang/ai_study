WorldMem记忆世界模型

WorldMem: Long-term Consistent World Simulation with Memory
2025.04论文延伸arXiv 2025Zeqi Xiao, Yushi Lan, Yifan Zhou, Wenqi Ouyang, Shuai Yang, Yanhong Zeng, Xingang Pan · 南洋理工大学S-Lab等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视频世界模型只能看最近几十帧，玩家转一圈再回头，原来的房子就变了样，长时间探索时三维空间前后对不上。

方法

给世界模型配一个记忆库：存下历史帧及其相机位姿和时间戳，生成新帧时用记忆注意力检索相关的旧帧，让看过的场景能被还原。

影响

把“世界模型要有长期记忆”变成一个明确的问题和可比较的做法，后续交互式世界模型普遍把记忆模块当作标配来讨论。

方法

卡在哪：Genie 2、Oasis可玩世界模型、GameNGen这类交互式视频世界模型按自回归方式一帧帧往后生成，每次只能把有限长度的历史帧放进上下文。超出窗口的内容就被“忘掉”：在Minecraft里走远再走回来，同一个位置会长出不同的地形。这对用世界模型做训练环境或规划是硬伤，因为环境自己前后矛盾。

做法：WorldMem在Diffusion Forcing式的视频扩散骨干上加一个记忆库，每个条目是一帧画面加上它的状态——相机位姿和时间戳。生成新帧时，先按位姿和时间的相关程度从库里挑出若干帧，再通过专门的记忆注意力把它们作为条件，让模型“参考”当时看到的样子来画当前视角。因为状态里带着时间戳，模型还能区分“过去这里是这样”和“现在这里已经变了”，从而表示世界随时间的变化（比如作物长大）。

结果：在用MineDojo搭的Minecraft基准上，超出上下文窗口后再回到旧场景，纯Diffusion Forcing基线的PSNR只有18.04，WorldMem为25.32（LPIPS从0.4376降到0.1429）；在真实房屋视频RealEstate10K上转一圈回到原视角，PSNR从基线的8.4提到20.2。

局限与后续

  • 记忆库随探索时间线性增长，检索和注意力开销也随之上升，几小时级的长时探索还没有验证。

  • 检索依赖准确的相机位姿；真实场景里位姿要另行估计，估错就会取回错误的记忆。

读懂它需要的概念

世界模型 扩散：前向加噪与反向去噪 注意力机制 相机模型与多视图几何 自回归生成

本篇术语

  • 记忆注意力（memory attention）　生成当前帧时，让模型用注意力去看从记忆库里取回的旧帧及其位姿，相当于翻看相册再作画。
