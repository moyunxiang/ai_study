CKY句法分析算法

Recognition and Parsing of Context-Free Languages in Time n^3
1967论文延伸Information and Control 1967Daniel H. Younger（并有Cocke、Kasami独立提出） · Cornell / IBM / 空军剑桥研究实验室待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

上下文无关文法的句法分析如果用回溯搜索，句子稍长就会指数级变慢。

方法

把文法化成乔姆斯基范式，再用动态规划填一张「每个片段能由哪些非终结符推出」的表，复杂度降到句长的三次方。

影响

成为后来所有概率句法分析（概率上下文无关文法PCFG、Collins词汇化句法分析器）的基础算法，也是学习动态规划的经典例子。

方法

输入一个长为n的句子和一套乔姆斯基范式的文法（每条规则只有A→BC或A→a两种形式）。算法建一张三角表：T[i][j]记录从第i个词开始、长为j的片段可由哪些非终结符推出。

长度为1的片段直接查词典规则。更长的片段则枚举所有切分点k，如果左半段能推出B、右半段能推出C，且文法里有A→BC，就把A填进T[i][j]。最后只要起始符号S在整句对应的格子里，句子就合乎文法；回溯记录就能还原出语法树。

总时间是O(n³·|G|)。Younger在1967年发表，Cocke和Kasami也在差不多同时独立得到同样的算法，所以通称CKY或CYK。

局限与后续

  • 只能处理乔姆斯基范式的文法，且只判断合不合文法，对句子的多种歧义结构没有“哪个更可能”的排序。
    后来针对它的工作　概率上下文无关文法PCFG
  • 三次方复杂度对长句仍然偏慢。
    后来针对它的工作　Earley句法分析算法 转移式依存分析

它建立在什么之上

  • 使用
    乔姆斯基层级1956 · NLP
    解决的正是上下文无关文法这一层的句子识别问题。
  • 改进
    生成语法1957 · NLP
    转换规则表达力极强，但给定一句话反推它由哪些转换得到很难计算，早期很难直接做成高效的自动句法分析器。

后来的相关工作

  • 使用
    Collins词汇化句法分析器1997.07 · NLP
    用CKY式的动态规划图表分析器搜索概率最大的句法树。
  • 使用
    层次短语翻译Hiero2005.06 · NLP
    解码器就是带束剪枝的CKY图分析，对源句自底向上分析的同时组装目标译文。
  • 竞争
    Earley句法分析算法1970.02 · NLP
    同为O(n³)的通用分析算法：CKY要求范式、表格化；Earley不要范式、只展开可达状态，二者在统计句法分析中各有使用。
  • 改进
    概率上下文无关文法PCFG1979 · NLP
    把CKY中的“可推出”换成概率最大化，用同一张动态规划表求最优分析。
  • 改进
    转移式依存分析2003 · NLP
    三次方复杂度对长句仍然偏慢。
