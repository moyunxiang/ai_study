NMT继续训练领域适应

Stanford neural machine translation systems for spoken language domains
2015.12论文延伸IWSLT 2015（评测系统）Minh-Thang Luong, Christopher D. Manning · 斯坦福大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

神经机器翻译需要大量平行语料，但具体应用领域（如TED演讲这类口语）往往只有十几二十万句；只用领域内数据训练不够，只用大规模新闻、议会语料训练又不对路。

方法

先在大规模通用领域语料上训练好一个带注意力的NMT模型，再用少量领域内数据接着训练几轮——即后来通称的“继续训练/微调”式领域适应。

影响

在IWSLT 2015口语翻译评测中，用这种简单办法取得了明显收益，成为NMT领域适应最常用的基线做法，“先通用预训练、再领域微调”的范式后来推广到几乎所有神经NLP任务。

背景

统计翻译时代的领域适应有一整套方法：混合多个领域的翻译表和语言模型、按与领域的相似度挑选数据、给不同语料加权等。2015年的神经翻译（Seq2Seq、注意力机制、Luong注意力）刚刚在WMT大数据集上追上统计系统，但大家担心它在小数据上不行：神经网络参数多，领域内的十几万句话根本不够训练。

方法

斯坦福团队参加IWSLT 2015评测（翻译TED演讲字幕），做法很直接：

1. 在WMT提供的大规模英德通用语料（新闻、议会记录等）上训练一个多层LSTM加注意力的NMT模型； 2. 把这个模型作为初始化，只用IWSLT提供的TED领域数据继续训练若干个周期，学习率较小，使模型适应口语风格和TED常见词汇； 3. 解码时集成多个模型。

对于数据较少的英越方向，他们直接在领域内小数据上训练NMT，考察神经翻译在低资源条件下的表现。整个方法没有新的模型结构，关键是训练流程：先通用、再领域。

结果

论文报告，适应后的英德系统比未适应的通用系统BLEU有明显提升，并在评测中取得有竞争力的名次；英越方向的小数据NMT也表现不错（原文为扫描版，具体分数未能核对，此处不写数字）。

后来的发展

这篇系统报告常被引作NMT“继续训练”式领域适应的出处；之后的研究在此基础上处理它带来的问题，例如微调后在通用领域上性能下降（灾难性遗忘），提出混合微调、正则化、数据选择等方法。随后的多语言NMT与零样本翻译等工作也常把“先大数据预训练、再小数据微调”作为标准流程，这与预训练语言模型的范式一致。

局限与后续

  • 微调后模型在原通用领域上的翻译质量会下降（灾难性遗忘），需要另外的手段兼顾多个领域。

读懂它需要的概念

迁移学习 预训练与微调 编码器-解码器 注意力机制 分布偏移

本篇术语

  • 领域适应　让在一种数据分布（如新闻）上训练的模型在另一种分布（如口语演讲）上也表现好。
  • 继续训练　用已经训练好的模型作初始化，在新数据上接着训练，也就是微调。

怎么学

先读Luong注意力 → 读本报告的系统描述 → 动手：用一个公开的英德翻译模型，在几千句TED字幕上微调一个周期，比较微调前后在TED测试集和新闻测试集上的BLEU。
