QRNN准循环网络

Quasi-Recurrent Neural Networks
2016.11论文延伸ICLR 2017James Bradbury, Stephen Merity, Caiming Xiong, Richard Socher · Salesforce Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RNN每个时间步都要等上一个时间步的输出，无法在时间维上并行，长序列上又慢又难扩展。

方法

把重计算全部交给可在时间维并行的卷积层，只保留一个极简的、逐通道的循环池化函数（没有可训练的循环权重矩阵）来混合时间信息。

影响

在Transformer普及前是“又快又准的RNN替代品”之一，被用于语言模型与机器翻译加速；它“门由并行算出、循环只做逐元素更新”的设计，与后来的SRU、线性RNN和Mamba状态空间模型一类模型思路相通。

方法

LSTM的门依赖上一步的隐状态h_{t−1}，所以必须按时间顺序算。QRNN把门的计算改成只依赖输入：对输入序列做一维因果卷积（窗口宽度k，只看当前和过去k−1个位置），一次性并行算出所有时间步的候选值z、遗忘门f和输出门o。

然后做“循环池化”，例如fo-pooling：c_t = f_t ⊙ c_{t−1} + (1 − f_t) ⊙ z_t，h_t = o_t ⊙ c_t。这一步虽然仍要顺序做，但只是逐元素乘加、各通道相互独立，非常便宜，可以在通道维上并行。没有任何可训练的循环权重矩阵。

摘要报告：堆叠的QRNN在相同隐层大小下比堆叠LSTM预测精度更好，训练和测试速度最多快16倍；在语言建模、情感分类和字符级神经机器翻译上验证了这些优势。

局限与后续

  • 时间信息只靠窗口很短的卷积和逐元素循环混合，表达力弱于完整LSTM与注意力，长程依赖仍有限。
    后来针对它的工作　Transformer
  • 循环池化部分仍需顺序扫描，序列极长时仍有瓶颈。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    LSTM1997 · 基础
    保留LSTM式的门控记忆，但门由卷积并行算出，去掉了循环权重。
  • 使用
    WaveNet2016.09 · 语音
    借用因果卷积，只看当前与过去的位置。
  • 改进
    梯度消失问题1994 · 基础
    逐元素的遗忘门让梯度沿时间传播更顺畅，同时提高并行度。
  • 竞争
    ByteNet卷积翻译2016.10 · NLP
    同期用卷积做序列建模的路线，ByteNet完全不用循环。

后来的相关工作

  • 改进
    Transformer2017.06 · LLM
    时间信息只靠窗口很短的卷积和逐元素循环混合，表达力弱于完整LSTM与注意力，长程依赖仍有限。
  • 延续
    minGRU与minLSTM2024.10 · 基础
    与QRNN一样让门只依赖输入以获得并行性，并进一步用前缀扫描在时间维上并行。

读懂它需要的概念

循环网络与隐状态 门控机制 卷积运算 语言模型

怎么学

先懂LSTM的门控；读论文第2节的卷积层与三种池化（f/fo/ifo）；动手用PyTorch实现fo-pooling，与LSTM在字符级语言模型上比较速度。
