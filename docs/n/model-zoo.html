Caffe Model Zoo

2014系统延伸Caffe社区 · Berkeley Vision and Learning Center待核对
Caffe官网（Model Zoo） ↗在交互版中打开（演化树、学习进度）

问题

训练一个ImageNet规模的网络要几天到几周的GPU时间，多数人没有条件，也无法复现别人的结果。

方法

约定统一的权重文件格式，把各研究组训练好的模型集中放在一个可下载的清单里，别人可以直接拿来微调。

影响

推动了「下载预训练模型再微调」的做法成为标准，后来各框架的模型库和Hugging Face Hub延续了这个模式。

方法

Caffe Model Zoo是Caffe社区维护的预训练模型清单：每个条目包含网络定义（prototxt）、权重文件、训练数据说明和许可，使用者下载后即可对新任务做微调。它既包括Caffe参考版的AlexNet，也包括VGG、GoogLeNet等著名结构的移植版本。

这件事看似琐碎，却改变了研究方式：不再每人从零训练，而是共享权重，结合迁移学习在小数据集上取得好结果。模型分享和复现从此成为深度学习社区的常规。

局限与后续

  • 不同框架权重格式互不通用，模型从一个框架迁到另一个要手工转换。
    后来针对它的工作　ONNX模型交换格式
  • 分散在各处的链接，缺少统一的托管、版本和评测。
    后来针对它的工作　Hugging Face Hub与Datasets

它建立在什么之上

  • 使用
    AlexNet2012.09 · 视觉
    参考模型就是AlexNet的复现版本，用于微调。
  • 延续
    Caffe2013.12 · 系统·效率
    在Caffe之上建立了共享预训练权重的约定与清单。

后来的相关工作

  • 改进
    Hugging Face Hub与Datasets2020 · 系统·效率
    Model Zoo只是一份分散链接的列表；Hub把权重放进带版本、卡片和统一接口的仓库，任何人都能直接上传和加载。
  • 改进
    ONNX模型交换格式2017.09 · 系统·效率
    不同框架权重格式互不通用，模型从一个框架迁到另一个要手工转换。

读懂它需要的概念

迁移学习 预训练与微调

怎么学

用任一框架下载一个预训练的ResNet，替换最后一层，在小数据集上微调。
