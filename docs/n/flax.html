Flax（JAX神经网络库）

2020.01系统延伸Google Brain与JAX团队待核对
GitHub ↗文档 ↗在交互版中打开（演化树、学习进度）

问题

JAX只提供可组合的函数变换（求导、编译、向量化），要求函数是纯函数；写神经网络时，参数、批归一化统计量、随机数种子这些状态该放哪、怎么初始化，需要一套约定。

方法

在JAX之上提供层的定义方式：模型描述与参数分开存放，参数和其他可变状态作为显式的嵌套字典在函数间传递，从而能直接套用jit、grad、vmap、pmap等变换。

影响

成为谷歌内外用JAX做研究的主力神经网络库之一，大量TPU上的大模型研究代码和Hugging Face的JAX版模型都基于它；2024年推出的NNX改用Python对象语义。

方法

JAX的哲学是“NumPy加上函数变换”：grad(f) 得到梯度函数，jit(f) 交给XLA编译器编译，vmap/pmap 做向量化和多设备并行。这些变换要求f是没有副作用的纯函数，而面向对象的PyTorch式写法把参数藏在模块对象里，与之冲突。

Flax（2020年由Google Brain工程师与JAX团队开发，GitHub仓库建于2020年1月）的Linen接口用这样的约定解决：一个模块只描述计算结构，model.init(rng, x) 返回参数树（嵌套字典），model.apply(params, x) 是参数与输入的纯函数；批归一化统计量、缓存等放在单独的“变量集合”里显式传入传出，随机数种子也显式管理。这样整段训练步可以直接 jit，多卡训练直接 pmap。优化器后来交给配套的Optax库。

2024年发布的Flax NNX在此基础上加入对Python引用语义的一等支持，模型可以写成普通可变对象，降低了上手难度，README称它由Linen演化而来。

局限与后续

  • Linen的init/apply分离和显式状态传递对习惯PyTorch的用户门槛较高，调试和查看中间状态不直观。

它建立在什么之上

  • 使用
    Google TPU2016.05 · 硬件
    借助JAX与XLA，Flax模型主要在TPU上大规模训练。
  • 竞争
    PyTorch2017.01 · 系统·效率
    PyTorch把参数藏在可变模块对象里；Flax Linen坚持参数与计算分离的函数式风格，NNX后来向对象语义靠拢。
  • 使用
    JAX2018.12 · 系统·效率
    构建在JAX的函数变换之上，参数树可直接被grad、jit、pmap处理。
