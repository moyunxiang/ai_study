Dueling DQN

Dueling Network Architectures for Deep Reinforcement Learning
2015.11论文延伸ICML 2016Wang, Schaul, Hessel, van Hasselt, Lanctot, de Freitas · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DQN的网络对每个动作各输出一个Q值，很多状态下各动作的价值几乎相同，网络却要把每个动作都单独学一遍。

方法

把网络末端拆成两路：一路估计状态价值V(s)，一路估计每个动作的优势A(s,a)，再合成Q，不需要改动底层的RL算法。

影响

几乎不增加成本就在Atari上提升了DQN系列，后来成为Rainbow等算法的标准组件。

方法

网络前面的卷积层共用，后面接两个全连接分支：价值流输出一个标量V(s)，优势流输出每个动作一个A(s,a)。合成时 Q(s,a) = V(s) + A(s,a) − 平均A。减去平均值是为了解决「V和A怎么分」的不唯一性，否则网络可以把任意常数在两路之间挪来挪去。

好处是：每次更新Q值，价值流都会被训练到，所以即便某个动作从没被选过，状态价值也在学习；在许多动作价值相近的状态里，网络只需学好V就够了。摘要称这种结构在动作价值相近时策略评估更好，并使智能体在Arcade学习环境ALE的Atari 2600上超过当时最优水平。它可以和Double DQN、优先经验回放叠加使用。

局限与后续

  • 动作数很少时V/A分解的收益有限，主要在动作多且价值接近的游戏里有用。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 仍然是对每个动作输出一个值的离散动作结构，不能处理连续动作。
    后来针对它的工作　DDPG

它建立在什么之上

  • 延续
    DQN（Nature版）2015.02 · RL
    保持DQN的训练流程不变，只改网络结构。
  • 竞争
    Double DQN2015.09 · RL
    同期针对DQN的不同毛病：Double DQN修正过高估计，Dueling改进表示；两者互补，后来被合并进Rainbow。

后来的相关工作

  • 使用
    Rainbow2017.10 · RL
    网络头用Dueling结构，价值流和优势流都输出分布的logits；消融显示其整体贡献不明显。
  • 改进
    DDPG2015.09 · RL
    仍然是对每个动作输出一个值的离散动作结构，不能处理连续动作。
