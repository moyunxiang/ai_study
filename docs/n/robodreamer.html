RoboDreamer组合世界模型

RoboDreamer: Learning Compositional World Models for Robot Imagination
2024.04论文延伸arXiv 2024Siyuan Zhou, Yilun Du, Jiaben Chen, Yandong Li, Dit-Yan Yeung, Chuang Gan待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文本生成视频的机器人规划器只会画训练时见过的指令；换一个没见过的“物体+动作+位置”组合，生成的视频计划就不对。

方法

用句法分析把指令拆成动作短语和空间关系短语，每个短语各自给出一个扩散得分，推理时把得分加权相加，相当于把各部分的分布相乘，拼出新组合的视频。

影响

RT-1数据的人工评测中，未见指令的视频正确率81.3%（AVDC为46.9%）；RLBench平均成功率49.3%，高于UniPi的41.0%；还能加目标图或草图作条件。

方法

卡在哪：UniPi视频即策略、AVDC无动作视频把“视频生成”当成规划：给一句指令画出机器人完成任务的视频，再用逆动力学模型（从相邻两帧反推动作的小网络）转成动作。但它们把整句指令当一个条件，训练里没见过的组合（比如把见过的物体放到见过的另一个位置）就画不出来。

做法：RoboDreamer利用语言本身的组合性。先用现成的成分句法分析器加规则，把“把水瓶放进下层抽屉”拆成动作短语“放水瓶”和空间关系短语“进下层抽屉”。每个短语单独作为视频扩散模型的条件，得到各自的去噪方向；推理时取“无条件得分 + Σ w·(条件得分 − 无条件得分)”，这和无分类器引导CFG的形式一样，含义是把各部分的条件分布相乘（见条件生成与引导）。训练时随机只给一部分短语，让每个短语单独也能指导生成。同样的办法还能把目标图、草图当成额外的组合项。底层沿用AVDC与Imagen式的级联扩散，文本用冻结的T5编码，分辨率从64逐级放大到256。

结果：人工评测视频是否正确完成指令，已见/未见指令上分别为90.1%/81.3%，AVDC为63.1%/46.9%，不做句法拆分的版本为85.5%/68.8%。加入目标图后人工评分升到95.8%。在RLBench仿真里闭环重规划执行，平均成功率49.3%，UniPi视频即策略为41.0%。

读懂它需要的概念

扩散：前向加噪与反向去噪 条件生成与引导 世界模型 规划与模型预测控制 语言模型 状态、观测与动作

本篇术语

  • 成分句法分析　把句子切成嵌套的短语结构，例如区分出动词短语和介词短语；RoboDreamer用它把指令拆成可单独建模的部件。
  • 组合泛化　训练时见过各个零件，测试时能处理这些零件的新组合，例如见过“拿杯子”和“放到左边”，就能做“把杯子放到左边”。
