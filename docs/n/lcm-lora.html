LCM-LoRA即插即用加速

LCM-LoRA: A Universal Stable-Diffusion Acceleration Module
2023.11论文延伸Simian Luo, Yiqin Tan, Suraj Patil, Daniel Gu, Patrick von Platen, Apolinário Passos, Longbo Huang, Jian Li et al. · 清华大学 / Hugging Face待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

潜空间一致性模型LCM要对每个基础模型做全参数蒸馏才能少步出图，而社区里有成千上万个微调过的SD模型和风格LoRA，不可能逐个重新蒸馏，大模型（SDXL）的全量蒸馏还很耗显存。

方法

把潜空间一致性蒸馏改用LoRA来做，只训练一组低秩参数；然后发现这组参数可以当作通用的“加速模块”，直接插到别的SD微调模型或风格LoRA上，无需再训练就能4步左右出图。

影响

使少步生成在Stable Diffusion社区里变成“加一个LoRA文件”的操作，被diffusers、ComfyUI等工具直接支持；也让“加速能力和风格能力可以分别做成LoRA再相加”这一思路流行起来。

方法

LCM的做法是：以预训练潜扩散模型为教师，在概率流ODE轨迹上做一致性蒸馏（见一致性模型），让学生从轨迹上任一点一步跳到终点，于是2–4步就能出图。论文摘要称LCM蒸馏只需约32个A100 GPU小时。

LCM-LoRA的两点贡献：

  • 用LoRA做蒸馏：冻结原模型，只在注意力等层上训练低秩增量ΔW = BA（见参数高效微调）。这样蒸馏SD-V1.5、SSD-1B、SDXL时显存占用显著降低，画质反而更好。
  • 当作通用加速器：把蒸馏得到的ΔW_LCM直接加到其他由同一基础模型微调来的权重上，或与风格LoRA的ΔW_style线性相加，W = W_0 + λ_1ΔW_style + λ_2ΔW_LCM，模型就同时具备该风格和少步生成能力。作者把它类比为一个“可插拔的神经PF-ODE求解器”，与DDIM、DPM-Solver这类数值求解器相对。

局限与后续

  • 2–4步画质与原模型多步结果仍有差距，细节偏软，且不太适配大的CFG系数。

读懂它需要的概念

参数高效微调 知识蒸馏 少步采样与扩散蒸馏 潜空间 低秩近似

本篇术语

  • 一致性蒸馏　训练学生网络，使它从同一条ODE轨迹上任意两点出发都映射到同一个终点，从而一步或几步完成采样。

怎么学

先读一致性模型与LCM → 读这篇短报告的LoRA组合公式 → 在diffusers里给一个社区风格模型加载LCM-LoRA，用4步采样对比效果。
