DSO直接稀疏里程计

Direct Sparse Odometry
2016.07论文延伸IEEE TPAMI 2018Jakob Engel, Vladlen Koltun, Daniel Cremers · 慕尼黑工业大学 / 英特尔实验室待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

视觉里程计分两派：ORB-SLAM这类特征点法依赖关键点检测与描述子，在弱纹理处缺少特征；LSD-SLAM直接法这类直接法直接用像素亮度，但半稠密地使用像素、加平滑先验，难以对所有参数做一致的联合优化。

方法

直接法与稀疏采样结合：从图像中所有有亮度梯度的区域均匀采样少量像素，直接最小化光度误差，并在一个滑动窗口内对相机位姿、像素逆深度和光度参数做完整的联合优化；同时对曝光时间、镜头暗角和相机响应做光度标定。

影响

摘要称在数小时视频的三个数据集上，跟踪精度和鲁棒性都明显超过当时最好的直接法与间接法，成为直接法视觉里程计的代表，衍生出双目、视觉惯性和带回环的多个版本。

方法

直接、稀疏：DSO不提取特征点，而是在每个关键帧里按梯度大小、在网格中均匀地挑选约两千个像素（可以在边缘上，也可以在白墙上缓慢变化的亮度处），每个像素用参考帧中的逆深度表示几何。误差是该像素周围一小块在另一帧中的亮度差，经Huber鲁棒核加权。

完整的光度模型：真实相机的亮度会随自动曝光、镜头暗角（边缘变暗）和非线性响应曲线变化，直接比较亮度会出错。DSO把曝光时间、暗角和响应函数事先标定好，并为每帧估计一个仿射亮度变换 I′ = e^a·I + b，把它们放进误差模型里。

滑动窗口联合优化：维护约7个关键帧，把这些帧的位姿、光度参数和所有点的逆深度一起用高斯-牛顿优化——相当于在小窗口里做光度版的光束平差综述。旧帧移出窗口时用边缘化（Schur补）保留其信息。由于去掉了半稠密方法中常用的平滑先验、改为均匀采样，问题保持稀疏，能实时求解。DSO只做里程计，没有回环检测和全局重定位。

后来的发展

后续有双目版Stereo DSO、视觉惯性版VI-DSO和带回环的LDSO；直接法的光度误差思想也被DROID-SLAM等学习式SLAM和可微渲染式SLAM继承。

读懂它需要的概念

相机模型与多视图几何 雅可比矩阵与海森矩阵 梯度下降 图像作为张量

本篇术语

  • 直接法　不提取特征点，直接用像素亮度差作为误差来估计相机运动和场景深度。
  • 逆深度　用深度的倒数1/d表示点的远近，对远处点和刚初始化的点数值上更稳定。

怎么学

先读LSD-SLAM了解直接法，再读DSO论文第2、3节光度模型与滑动窗口优化；用TUM monoVO数据集运行官方代码，并对比关掉光度标定后的漂移。
