DIV2K超分辨率数据集

NTIRE 2017 Challenge on Single Image Super-Resolution: Dataset and Study
2017.07数据集延伸CVPR Workshops 2017（NTIRE）Eirikur Agustsson, Radu Timofte · 苏黎世联邦理工学院计算机视觉实验室待核对
CVF / DOI ↗数据集主页 ↗在交互版中打开（演化树、学习进度）

问题

图像超分辨率（把低分辨率图放大并补出细节）多年用Set5、Set14、BSD100这类只有几张到几百张的小图集训练和测试，深度模型越做越大，训练数据跟不上，测试图分辨率也偏低。

方法

为NTIRE 2017超分辨率挑战赛收集1000张内容多样的2K分辨率高清图，划分为800张训练、100张验证、100张测试，并为2倍、3倍、4倍缩小给出对应的低分辨率版本。

影响

成为深度超分辨率模型的标准训练集，EDSR之后的大多数超分辨率论文都在DIV2K上训练，再到Set5、Urban100等测试集上报告PSNR和SSIM。

方法

从SRCNN超分辨率开始，超分辨率转向深度学习，但训练数据仍是零星的小图集，测试图片也大多低于百万像素。为了举办CVPR 2017的NTIRE单图超分辨率挑战赛，作者从网上收集了一批高质量、内容多样（人物、自然、建筑、物品等）的2K分辨率RGB图像，即DIV2K（DIVerse 2K）。

划分。训练集800张高清图，提供与之对应的2倍、3倍、4倍下采样的低分辨率图；验证集100张，比赛期间先只公开低分辨率图供参赛者在线获取反馈；测试集另有100张。低分辨率图有两种退化方式：标准的双三次下采样，以及参赛者事先不知道的“未知”退化，后者更接近真实相机。论文还在这些数据上比较了多种已有方法，研究评测指标与数据规模的影响。挑战赛的冠军方法即EDSR超分辨率。

局限与后续

  • 低分辨率图主要由人工下采样合成，与真实相机拍到的模糊、噪声、压缩退化不同，在DIV2K上训练的模型面对真实低质照片效果会明显变差。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    SRCNN超分辨率2014.09 · 视觉
    SRCNN一代深度超分模型只能用几十到几百张小图训练，DIV2K提供了规模更大、分辨率更高的训练数据。
  • 延续
    SRGAN2016.09 · 视觉
    SRGAN等方法揭示了PSNR与感知质量的分歧，DIV2K的挑战赛同时研究了评测指标问题。
  • 使用
    EDSR超分辨率2017.07 · 视觉
    EDSR是NTIRE 2017挑战赛的获胜方法，训练于DIV2K，两者同期发布。

读懂它需要的概念

图像作为张量 基准、排行榜与SOTA 训练集、验证集与测试集

本篇术语

  • PSNR / SSIM　超分辨率最常用的两种客观指标：PSNR按像素误差计算（单位dB，越高越好），SSIM比较局部亮度、对比度和结构的相似程度（0到1）。

怎么学

先了解图像下采样和PSNR的计算。读论文对数据收集与划分的说明；动手把DIV2K的一张图按4倍双三次缩小再放大，和用一个预训练的EDSR放大的结果分别算PSNR。
