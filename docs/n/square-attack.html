Square Attack黑盒攻击

Square Attack: a query-efficient black-box adversarial attack via random search
2019.11论文延伸ECCV 2020Maksym Andriushchenko, Francesco Croce, Nicolas Flammarion, Matthias Hein · 洛桑联邦理工学院 / 图宾根大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

黑盒攻击只能看模型输出，靠估计梯度的方法查询次数多，而且会被梯度掩蔽类防御误导，难以可靠地评估鲁棒性。

方法

完全不估计梯度，用随机搜索：每次在随机位置改动一个正方形区域的像素，只要让模型的损失变大就保留，否则丢弃。

影响

成为最常用的分数型黑盒攻击之一，被收进AutoAttack评测组合，专门用来识破依赖梯度掩蔽的虚假防御。

方法

做法。攻击者每次查询能拿到模型的输出分数。从一个初始扰动出发，每一轮在图像上随机选一个正方形区域（大小随迭代逐渐缩小），在这个区域内把扰动改成可行集合边界上的新值，例如在ℓ∞约束下直接取±ε。查询模型：如果损失增大就接受这次改动，否则撤回。因为更新总在可行集合边界附近，每一步的改动都“用足”了预算。

为什么不怕梯度掩蔽。方法不用局部梯度信息，所以那些让梯度失效、看起来很鲁棒的防御对它不起作用。

结果。摘要称，Square Attack比当时最好的方法查询效率显著更高、成功率更高，尤其在非定向设定下。在ImageNet上，对多种深度网络的平均查询效率比此前最好的ℓ∞黑盒攻击提高至少1.8倍、最多3倍。虽是黑盒攻击，它在标准基准上的成功率甚至能超过基于梯度的白盒攻击。

局限与后续

  • 需要模型返回分数（而非只返回标签）；在高分辨率图像上仍需要数百到数千次查询。
