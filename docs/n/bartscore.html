BARTScore生成式指标

BARTScore: Evaluating Generated Text as Text Generation
2021.06论文延伸NeurIPS 2021Weizhe Yuan, Graham Neubig, Pengfei Liu · 卡内基梅隆大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

生成文本的自动指标大多是“比相似度”，一种指标很难同时衡量流畅性、事实性、信息量等不同方面，也不能直接利用预训练生成模型学到的知识。

方法

把评测本身看成一个生成问题：用预训练的BART计算“从源文本或参考生成这段输出”的对数概率，生成得越顺，说明输出越好。

影响

开启了“用生成模型的条件概率打分”这一路线，GPTScore等后续指标沿用了同一思路，BARTScore本身也成为摘要和翻译评测的常用对照。

方法

核心公式。给定条件文本x（源文档或参考答案）和待评文本y，分数是 BARTScore = Σ_t w_t · log p(y_t | y_<t, x; θ)，即预训练BART在已知x时逐词生成y的加权对数概率。

换个方向就换个维度。从源文本到输出（s→h）的概率反映忠实度和事实性；从参考到输出、从输出到参考的概率分别近似精确率和召回率；两者平均近似F值。这样一个模型通过改变输入输出方向，就能测多个方面。

增强。还可以在摘要或复述数据上微调BART，或在输入前后加提示词（如“换句话说”）来调整打分。

结果。作者在16个数据集、7个评测维度上测试，摘要称BARTScore在大多数设定上超过已有的顶尖指标。

  • 竞争
    BERTScore2019.04 · 数据·评测

  • 使用
    BART2019.10 · LLM
    直接用预训练的BART序列到序列模型计算条件对数概率。
  • 使用
    SummEval摘要指标重评2020.07 · 数据·评测
    在SummEval等带人工评分的数据上检验与人类判断的相关性。

后来的相关工作

  • 竞争
    UniEval多维度评估器2022.10 · 数据·评测
    BARTScore用生成概率、改变方向来测不同维度，UniEval用不同问题来测不同维度。
  • 延续
    GPTScore大模型概率打分2023.02 · 数据·评测
    同一团队的思路延续：BARTScore用BART的生成概率，GPTScore换成带评测指令的大语言模型。
  • 改进
    G-Eval大模型评分2023.03 · 数据·评测
    分数依赖BART自身的偏好，倾向于给常见、流畅的措辞高分，对长文本和与预训练分布差别大的领域可靠性下降。
