指令微调FLAN

Finetuned Language Models Are Zero-Shot Learners
2021.09论文延伸ICLR 2022Jason Wei, Maarten Bosma, Vincent Y. Zhao, Kelvin Guu, Adams Wei Yu, Brian Lester, Nan Du, Andrew M. Dai, Quoc V. Le · Google Research来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

预训练模型零样本做任务的能力远不如少样本，用户必须自己写示例才能让它理解要做什么。

方法

把60多个NLP数据集用自然语言指令模板改写，混在一起微调一个137B的预训练模型（LaMDA-PT），得到FLAN，再到没见过的任务类型上零样本测试。

影响

用“指令微调”这个名字系统检验了这种做法：在25个数据集中的20个上零样本超过GPT-3的零样本，在6个数据集上大幅超过GPT-3的少样本。之后的Flan-T5与指令规模化在它的基础上扩大了任务数和模型规模。

方法

背景：GPT-3的零样本表现比少样本差很多。Natural Instructions已经尝试在带指令的任务上微调，但用的是1.4亿参数的BART、看的是少样本；同一时期的T0多任务提示训练在11B的T5上做了类似的事。

做法：作者取一个137B参数、只做过语言模型预训练的模型LaMDA-PT，把62个公开NLP数据集（翻译、问答、推理等，分成12个任务簇）各自写成多种自然语言指令模板，对整个混合数据做微调。评估时按任务簇划分，微调时完全不见某一簇（比如自然语言推理），再零样本测这一簇。

结果：FLAN在评估的25个数据集中有20个零样本超过175B GPT-3的零样本，并在ANLI、RTE、BoolQ、AI2-ARC、OpenbookQA和StoryCloze上大幅超过GPT-3的少样本。消融显示：微调的任务簇越多，没见过的任务上越好；指令微调的好处只在足够大的模型上出现，8B及更小的模型反而在没见过的任务上变差；去掉指令、只给输入输出或只写数据集名，效果明显更差。对本来就是“续写句子”形式的任务（如常识推理、指代消解），指令微调帮助不大，7个这类任务中只有3个超过未微调的模型。

局限与后续

  • 需要人工为每个数据集手写指令模板，任务多样性受限于已有学术数据集，与真实用户请求分布有差距。
    后来针对它的工作　Self-Instruct InstructGPT与RLHF
  • 只验证了单轮、传统NLP任务，没有涉及开放式对话和人类偏好。
    后来针对它的工作　InstructGPT与RLHF

它建立在什么之上

  • 延续
    T52019.10 · LLM 已核对
    论文把T5代表的“预训练—在单个任务上微调”和GPT-3式的提示放在一起对比，指令微调结合两者：同样在有标注数据上微调，但把许多任务写成自然语言指令混在一起训练，目标是零样本做没见过的任务。
  • 竞争
    Natural Instructions2021.04 · LLM 已核对
    同一时期用指令提升跨任务泛化的工作：Natural Instructions在1.4亿参数的BART上看少样本，FLAN在137B模型上看零样本，并按任务簇严格留出评估。

后来的相关工作

  • 竞争
    InstructGPT与RLHF2022.03 · LLM 已核对
    同期的指令微调路线，用改写的公开NLP数据集；在API用户提示上，FLAN微调的GPT-3胜率29.8%，远低于InstructGPT的73.4%。
  • 竞争
    Self-Instruct2022.12 · LLM 已核对
    FLAN把现成学术数据集改写成指令模板；Self-Instruct认为这类人写的指令数据在数量和多样性上受限，改由模型自己生成指令。论文没有直接用FLAN数据做对照。
  • 竞争
    T0多任务提示训练2021.10 · LLM
    几周前的FLAN用137B的解码器模型做了同样的事；T0只有11B，在多个留出任务上与FLAN相当或更好，并且全部公开。
  • 使用
    涌现能力2022.06 · LLM
    指令微调在8B及以下模型上有害、到约千亿参数才有益，被列为涌现实例。
  • 延续
    Flan-T5与指令规模化2022.10 · LLM
    沿用FLAN的指令微调，任务从62个扩到1836个，模型扩到540B，并加入思维链和少样本格式。
  • 使用
    Med-PaLM2022.12 · 科学
    Flan-PaLM来自指令微调，是Med-PaLM的起点。
  • 竞争
    Alpaca与廉价指令微调2023.03 · LLM
    同为指令微调，但Flan用人工整理的学术任务集合，Alpaca用大模型合成数据
  • 使用
    InstructBLIP2023.05 · 多模态
    沿用FLAN式把多个数据集改写成指令格式的做法。
