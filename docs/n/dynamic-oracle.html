动态预言训练依存分析

A Dynamic Oracle for Arc-Eager Dependency Parsing
2012.12论文延伸COLING 2012Yoav Goldberg, Joakim Nivre · 乌普萨拉大学等待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

转移式依存分析器训练时只看到「每一步都走对」的标准状态，测试时一旦走错一步，就进入从没见过的状态，后面错误层层累积。

方法

给出一个对任意状态都适用的「动态预言」：即使已经走错、标准树已不可达，它也能告诉你接下来哪些动作能得到仍可达的最好的树；训练时故意按模型自己的预测走，让模型学会从错误中恢复。

影响

在多种语言上稳定提升贪心转移式分析器的精度且不增加解析时间，「动态预言+探索训练」很快成为转移式分析器（包括神经版本）的标准训练方式。

背景

转移式依存分析这类转移式分析器从左到右读句子，维护一个栈和一个缓冲区，每一步选一个动作（arc-eager体系里是移进SHIFT、左弧LEFT-ARC、右弧RIGHT-ARC、归约REDUCE），O(n)时间就能分析完一句话。训练时需要一个预言（oracle）：给定标准树，告诉分类器每个状态下正确的动作。传统做法是静态预言：从标准树推出一条固定的标准动作序列，只在这条序列经过的状态上训练。问题在于测试时分类器一旦犯错，它面对的状态就不在训练分布里，它没学过此时该怎么做——这和模仿学习里的「分布偏移」是同一个问题。

方法

论文为arc-eager体系定义了一个动态预言：对任意合法状态c和动作t，定义代价 cost(t; c) = 执行t之后，从新状态出发再也无法得到的标准弧的数量减去在c时已经无法得到的数量。代价为0的动作都是「最优动作」，可能不止一个（静态预言只给一个）。

关键性质是arc-eager体系满足弧可分解：一组标准弧只要两两都还能同时得到，它们整体就能同时得到，所以每个动作的代价只需逐条检查它会让哪些弧失效，计算很便宜，作者证明了这个预言是正确的。

训练用在线感知机加探索：在每个状态，如果模型预测的动作不是最优动作，就朝得分最高的最优动作更新权重；然后以一定概率按模型自己预测的（可能是错误的）动作前进，而不是强制走回标准路径。这样模型会见到大量「已经犯过错」的状态，并学到在这些状态下如何把损失降到最小。

结果

摘要称，用这个预言训练的贪心arc-eager分析器在多种语言上都比静态预言训练的版本更准确，解析速度不变。

后来的发展

Goldberg与Nivre在2013年TACL上把动态预言推广到arc-standard、arc-hybrid等更多转移体系；神经转移式分析器（如Stack-LSTM依存分析的后续版本、BiLSTM特征依存分析）普遍采用带探索的动态预言训练。它把句法分析和DAgger、SEARN搜索式结构预测等「学习纠错」的模仿学习思想连接了起来。

本篇术语

  • 转移式分析　用栈和缓冲区逐词处理句子，每一步从少数几个动作中选一个，最终动作序列确定一棵依存树。
  • 预言（oracle）　训练时提供「正确动作」的程序；静态预言只给标准路径上的答案，动态预言对任意状态都给出最优动作集合。
  • 弧可分解　若一组标准弧两两兼容，则它们整体也能同时达到；有这一性质时动作代价很容易计算。

怎么学

先读转移式依存分析理解arc-eager的四个动作 → 读原文第3节代价定义与第4节带探索的训练算法 → 动手：在一个小依存树库上实现静态与动态预言两种训练，比较测试集上的附着准确率。
