NVIDIA NeMo工具包

NeMo: a toolkit for building AI applications using Neural Modules
2019.09系统延伸Oleksii Kuchaiev, Jason Li, Huyen Nguyen, Oleksii Hrinchuk, Ryan Leary, Boris Ginsburg, Samuel Kriman, Stanislav Beliaev et al. · NVIDIA待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

神经语音识别和语言模型都由编码器、解码器、损失函数等部件拼成，但各家代码耦合在一起，换一个部件或做分布式、混合精度训练都很费事。

方法

把网络拆成带类型的「神经模块」，每个模块声明输入输出的语义类型，像搭积木一样组合，并内置分布式和混合精度训练与预训练模型集合。

影响

NeMo成为NVIDIA语音（以及后来大模型）工作的统一框架，QuartzNet、Citrinet、TitaNet、Canary、Parakeet、TDT等模型都在其中发布。

方法

2019年前后，Kaldi统治着传统的混合识别流程，ESPnet是端到端研究的主要工具，但用户想复用一个声学编码器去接不同的解码器、或者把识别模型接进语言模型，往往要改大量代码。NVIDIA当时刚发布卷积识别模型Jasper与QuartzNet，需要一个能在自家GPU上高效训练、方便组合的框架。

NeMo（Neural Modules）的核心概念是神经模块：数据层、编码器、解码器、语言模型、损失函数等都是一个模块，输入输出带有「神经类型」（例如「梅尔频谱，形状为批×通道×时间」），连接时框架会检查类型是否匹配，防止把不兼容的张量接在一起。工具包提供识别和自然语言处理的预置模块集合，内置多GPU分布式训练（见分布式训练：数据并行与模型并行）和混合精度（见浮点精度：FP32、FP16、BF16、INT8）。它构建在PyTorch之上（摘要称框架无关，早期也考虑过别的后端）。

此后NeMo逐渐发展为NVIDIA语音、TTS、说话人和大模型训练的统一代码库：说话人模型TitaNet、多语言识别与翻译Canary与Parakeet、快速转导器TDT都随它开源。

本篇术语

  • 神经类型　NeMo给模块输入输出标注的语义类型（含张量含义与维度），连接时用来检查是否兼容。
  • 混合精度训练　用16位浮点做大部分计算、关键部分保留32位，以减少显存并加速训练。
