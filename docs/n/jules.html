Jules异步编码智能体

Jules: Google’s autonomous AI coding agent
2025.05系统延伸Google Labs（产品负责人Kathy Korevec等）待核对
官方博客 ↗在交互版中打开（演化树、学习进度）

问题

Copilot式的补全和IDE里的对话助手需要开发者盯着、一步步确认；把修bug、写测试、升级依赖这类完整任务整个交出去、让智能体在后台自己干完，还缺少直接接入代码仓库的产品。

方法

做一个异步的编码智能体：把用户的GitHub仓库克隆进一台谷歌云上的隔离虚拟机，用Gemini 2.5 Pro理解整个项目，先给出计划供用户审阅修改，再在后台执行，完成后交回推理过程和代码改动（diff），由用户决定是否合并。

影响

2024年12月在Google Labs首次亮相，2025年5月20日开放公测、面向所有Gemini可用地区且无需排队；与同月发布的OpenAI云端Codex一起，标志“在云端虚拟机里异步完成整项任务”的编码智能体成为各大厂的主流产品形态。

背景

GitHub Copilot开启了AI辅助编程，Cursor AI编辑器、Claude Code与终端编码智能体把智能体放进编辑器和终端，Devin则展示了在自己的环境里独立完成任务的“AI软件工程师”。但前两者需要开发者在本地陪着，后者是封闭的付费服务。谷歌的思路是：任务直接从GitHub发起，在云端并行跑，人只在开头审计划、结尾审代码。

方法

工作流程：连接GitHub并选择分支 → 用自然语言描述任务 → Jules读取整个代码库后给出执行计划 → 用户批准或修改计划 → Jules在云端虚拟机里修改代码、运行命令 → 完成后展示计划、推理和diff，用户可继续反馈或直接提交为拉取请求。

主要特点（官方列举）：

  • 在真实代码库上工作，获取项目的完整上下文；
  • 任务在云虚拟机中运行，可同时处理多个请求；
  • 改动前展示计划和推理过程，执行前、中、后都可以修改计划；
  • 直接集成在GitHub工作流中；
  • 能生成近期提交的“音频更新日志”；
  • 默认私有，不用用户的私有代码训练，数据隔离在执行环境中。

典型任务：写测试、开发新功能、修bug、升级依赖版本（官方演示把一个代码库升级到新版Node.js）。

定价：公测期间免费但有用量限制，官方表示之后会引入付费。

后来的发展

云端异步编码智能体迅速成为标配：OpenAI的云端异步编码智能体、GitHub的Copilot编码智能体、Anthropic的网页版Claude Code等形态相近；“开发者同时向多个智能体派任务、再统一审查拉取请求”的工作方式因此流行。谷歌之后又推出了命令行的Gemini CLI。

局限与后续

  • 异步执行意味着用户要等任务结束才能看到结果，计划一开始就理解错时，返工成本比交互式工具高。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 需要把代码交给谷歌云执行，对私有或受监管的代码库存在合规顾虑；公测阶段还有用量限制。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 官方公告没有给出在SWE-bench等公开基准上的成绩，能力只能凭使用体验判断。

本篇术语

  • 异步编码智能体　提交任务后无需守着，智能体在后台独立完成，结束后通知用户审查结果。
  • diff　代码改动前后的逐行差异，审查代码时看的就是它。

怎么学

先了解Devin和云端异步编码智能体 → 读官方博客的功能列表和使用步骤 → 动手：给一个小仓库提交“为某个函数补单元测试”的任务，审阅它给出的计划，再比较最终diff与计划是否一致。
