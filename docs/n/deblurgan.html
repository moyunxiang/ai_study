DeblurGAN对抗去模糊

DeblurGAN: Blind Motion Deblurring Using Conditional Adversarial Networks
2017.11论文延伸CVPR 2018Orest Kupyn, Volodymyr Budzan, Mykola Mykhailych, Dmytro Mishkin, Jiri Matas · 乌克兰天主教大学 / 布拉格捷克理工大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

运动模糊的“盲去模糊”要同时猜出模糊核和清晰图，传统方法先估核再反卷积，慢且对复杂的非均匀模糊失效；用像素误差训练的网络又容易输出偏平滑、细节不足的结果。

方法

把去模糊当成条件图像翻译：生成器直接把模糊图变成清晰图，不估计模糊核；用条件GAN（WGAN-GP）的对抗损失加上基于VGG特征的内容损失训练，让结果既像原图又有真实细节。还提出一种用随机轨迹合成运动模糊的数据增强方法。

影响

成为学习式去模糊的常用基线，并开创了用下游任务（模糊图上的目标检测）评估复原效果的做法；后续的DeblurGAN-v2进一步加入特征金字塔和轻量骨干。

方法

生成器是带残差块的全卷积网络，输入模糊图，学习输出“清晰图减模糊图”的残差；判别器是只看局部图像块真假的PatchGAN（同pix2pix条件图像翻译）。损失由两部分组成：

  • 对抗损失：用WGAN-GP梯度惩罚的形式，训练比原始GAN稳定；
  • 内容损失：比较生成图与真值在VGG某一层特征上的差（即感知损失），而不是直接比像素，避免平均化造成的模糊。

数据方面，除了GoPro数据集（高速相机连续帧平均得到的真实模糊），论文提出用随机相机运动轨迹生成模糊核、合成运动模糊图像，用于扩充训练数据。

摘要称DeblurGAN在结构相似度（SSIM）和视觉效果上都达到当时最好，比最接近的竞争方法DeepDeblur快5倍；还在真实问题上评估：对去模糊前后的图像跑目标检测，看检测效果改善了多少。

读懂它需要的概念

生成建模的目标 对抗训练 卷积层、池化与感受野 图像作为张量

本篇术语

  • 盲去模糊　不知道图像是被什么样的模糊核弄糊的，只拿到模糊图，就要恢复清晰图。

怎么学

先读pix2pix理解条件GAN做图像翻译，再读本文第3节的损失设计和第4节的合成模糊方法；用GoPro数据集跑一遍预训练模型，并在去模糊前后跑一个现成检测器对比。
