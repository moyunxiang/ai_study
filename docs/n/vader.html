VADER规则情感分析

VADER: A Parsimonious Rule-Based Model for Sentiment Analysis of Social Media Text
2014.05论文延伸ICWSM 2014C. J. Hutto, Eric Gilbert · 佐治亚理工学院待核对
DOI ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

推特这类社交媒体文本短、口语化，满是表情符号、缩写、全大写和感叹号；通用情感词典不认识这些表达，训练机器学习模型又缺标注数据，换个领域还要重训。

方法

人工构建一部针对社交媒体的情感词典（每个词或表情由多名标注者给出−4到+4的强度），再加上五条从语料中归纳出的语法启发式规则（感叹号、全大写、程度副词、but转折、否定），给每句话算出一个归一化的综合情感分。

影响

VADER不需要训练、开箱即用，NLTK把它内置为情感分析模块，在社交媒体分析、金融舆情和计算社会科学中被大量使用，至今仍是规则式情感分析的默认选择。

背景

情感分析主要有两类方法：机器学习情感分类那样在标注数据上训练分类器，以及基于词典的方法（LIWC心理语言词典、General Inquirer、评论观点挖掘与摘要的观点词表）。前者依赖领域内标注数据，后者的词典多为正式书面语编制，只给极性不给强度，也不认识「:)」「lol」「sooo good」。

方法

词典。 以LIWC、ANEW、General Inquirer等已有词表为基础，补充大量社交媒体常见的表情符号（:-)）、俚语缩写（LOL、WTF）和网络用语，得到约7500个候选条目；每个条目由10名经过筛选的众包标注者打−4（极负）到+4（极正）的分，取平均作为情感强度，剔除分歧太大或接近中性的条目。

五条启发式规则（从人工分析推文归纳并经实验验证）：

1. 感叹号增加情感强度（「好！！！」比「好」更强）； 2. 全大写的情感词强度增加； 3. 程度副词（extremely、slightly）放大或减弱后面的情感词； 4. 转折词but：but之前的情感减弱、之后的增强； 5. 否定：情感词前三个词内出现not等否定词时把极性翻转并打折。

打分。 把句中各词调整后的分数求和 s，再归一化到[−1,1]：

compound = s / √(s² + α)，α取15

同时输出积极、消极、中性三部分的比例。

结果

摘要报告：在社交媒体文本上，VADER的F1为0.96，超过单个人工标注者的0.84；在四个领域的对比中，它总体上优于LIWC、General Inquirer、SentiWordNet等七种词典基线和朴素贝叶斯、最大熵、SVM等机器学习方法，并能较好地推广到其他领域。

后来的发展

NLTK的 SentimentIntensityAnalyzer 就是VADER，这让它成为入门课程和数据分析中最常用的情感分析工具之一。预训练模型（如在推特上训练的RoBERTa情感模型）在准确率上早已超过它，但VADER因零成本、可解释、速度快，仍常被用作基线和大规模舆情分析的第一步。

局限与后续

  • 规则只覆盖五种现象，反讽、比较句、长距离的否定和需要常识的情感都处理不了。

它建立在什么之上

  • 竞争
    机器学习情感分类2002.07 · NLP
    机器学习情感分类需要领域标注数据，VADER无需训练；论文比较中在社交媒体文本上更优。
  • 竞争
    Turney无监督情感分类2002.07 · NLP
    Turney从语料自动推断词语情感倾向，VADER用众包人工标注词语强度。
  • 延续
    评论观点挖掘与摘要2004.08 · NLP
    延续以情感词表判断文本极性的路线，增加强度分和上下文规则。
  • 改进
    LIWC心理语言词典2009.12 · NLP
    LIWC逐词计数、不处理否定与程度，VADER加入强度分与五条语法规则，并补充表情和网络用语。

读懂它需要的概念

特征与表示学习 准确率、精确率、召回率与F1

本篇术语

  • 情感强度（valence）　一个词或句子情感的方向和强弱，VADER中用−4到+4（词）和−1到1（句）的连续分数表示。
  • compound分数　VADER对整句给出的归一化综合情感分，通常以≥0.05为积极、≤−0.05为消极。
