FAST动作分词与π0-FAST

FAST: Efficient Action Tokenization for Vision-Language-Action Models
2025.01论文重要Karl Pertsch, Kyle Stachowicz, Brian Ichter, Danny Driess, Suraj Nair, Quan Vuong, Oier Mees, Chelsea Finn, Sergey Levine · Physical Intelligence、UC Berkeley、Stanford待核对
arXiv ↗openpi（含π0-FAST权重） ↗在交互版中打开（演化树、学习进度）

问题

自回归VLA把每一步、每一维动作各切成一个token；控制频率一高，相邻token几乎一样，模型只要“照抄上一个”损失就很低，结果什么也学不会，在50Hz叠衣服这类任务上完全失败。

方法

借用JPEG的思路压缩动作：对1秒的动作块逐维做离散余弦变换（DCT），把系数缩放取整后大部分变成0，再用BPE把整数序列压成少量token，让每个token都携带真正的新信息。

影响

让自回归VLA第一次能做高频灵巧任务：π0-FAST在叠衣服、收拾餐桌等任务上追平流匹配版π0，训练快至多5倍；FAST+分词器在100万条轨迹上训练，可作为通用的动作分词器直接调用。

背景

RT-2与VLA和OpenVLA的做法是：动作的每一维在每个时间步各离散成256档中的一档，变成一个token。对5Hz、单步预测的任务这还行。但π0这类模型需要一次预测1秒的动作块：50Hz的双臂叠衣任务有14维，1秒就是50×14 = 700个token。

更根本的问题在训练信号。自回归模型学的是“给定前面的token，下一个是什么”。机器人动作很平滑，频率越高，相邻两步越接近——下一个token几乎等于上一个，所含的新信息趋近于零。模型很快学会“复制上一步”这种捷径，损失看起来很低，实际什么规律都没学到。论文用一个插值玩具任务验证：采样率升高后，逐步离散化的模型误差急剧上升，最终退化为照抄。

于是当时大家倾向于用扩散或流匹配输出连续动作（如π0），但这类模型训练更慢，也不能直接沿用语言模型的离散token训练方式。

方法

FAST（Frequency-space Action Sequence Tokenization）分四步：

1. 归一化：每维动作按训练数据的分位数缩放到[-1, 1]。 2. DCT：对每一维的H步动作序列单独做离散余弦变换，把“随时间的数值”变成“不同频率成分的强度”。平滑的轨迹能量集中在少数低频系数上，就像JPEG压缩照片一样。 3. 缩放取整：系数乘以一个缩放因子（默认10）后取整，不重要的高频系数变成0，矩阵变得很稀疏。缩放因子决定压缩率和精度之间的取舍。 4. BPE：把系数矩阵展平成一维整数序列，所有维度的低频系数排在前面，再训练一个BPE子词切分分词器（词表1024）做无损压缩，把大量0和常见组合合并成少数token。

解码时反向操作即可还原连续动作。先生成低频系数相当于先确定轨迹的大致形状，再补细节，使生成更稳定。生成的token覆盖VLM词表中最少用的那部分token，用普通的下一个token预测训练。

FAST+：在100万条真实机器人轨迹上训练的通用BPE词表，覆盖单臂、双臂、移动机器人和不同控制频率，可作为现成的黑盒分词器。

结果

压缩率（1秒动作块）：BridgeV2（7维、5Hz）从35个token降到20；DROID（15Hz）105→29；收拾餐桌（20Hz）140→28；叠T恤（14维、50Hz）700→53，压缩13.2倍。无论频率高低，FAST大约都用每条臂30个token，说明它抓住的是动作本身的复杂度。

策略效果：在6个真机任务和LIBERO上，压缩类分词（FAST、FSQ）都远好于逐步离散化，FAST在灵巧真机任务上又好于需要额外训练网络的FSQ；去掉BPE步骤性能下降，但仍好于朴素离散化。把OpenVLA的分词换成FAST+后，它也能学会高频的叠T恤任务。

π0-FAST：基于PaliGemma-3B，在约1万小时数据上训练，性能与流匹配版π0相当，达到同等表现所需训练计算少至多5倍；在DROID上训练出的策略可在新环境中零样本执行语言指令，这是此前DROID上训练的模型都没有展示过的。

后来的发展

FAST成为离散动作表示的常用方案，并直接用在知识隔离VLA和π0.5的训练里：VLM骨干用FAST token做快速、稳定的预训练，推理时再交给流匹配动作专家输出连续动作，兼得两者的优点。π0-FAST和FAST+分词器随openpi开源，π0-FAST-DROID也成为常用的开源通用策略。

容易误解的地方

  • FAST不是神经网络学出来的分词器：DCT和取整是固定公式，只有BPE词表需要从数据里统计，几乎不需要调参。
  • 压缩是有损的（取整丢掉了小系数），缩放因子太小会让还原的动作不够精确。
  • 它让自回归VLA训练更快，但推理反而更慢：每块要逐个解码30–60个token。

局限与后续

  • 自回归解码慢：π0-FAST在4090上每个动作块约需750毫秒，而流匹配版π0约100毫秒，不适合需要快速反应的场景。

读懂它需要的概念

分词与token 傅里叶变换与频域 自回归生成 动作表示：离散token、连续动作与动作块 VLA与WAM的基本结构 信息量与熵

本篇术语

  • 离散余弦变换（DCT）　把一段信号分解成不同频率余弦波的加权和，得到每个频率的系数。平滑信号的大部分能量集中在少数低频系数上，因此很适合压缩，JPEG就用它压缩图像。
  • FSQ（有限标量量化）　一种比VQ-VAE更简单的离散化方法：把编码器输出的每一维直接取整到少数几个固定值，不需要学习码本。
  • π0-FAST　与π0同一骨干、同一数据，但用FAST token自回归地输出动作，而不是用流匹配。

怎么学

先补傅里叶变换与频域和分词与token，理解为什么平滑信号在频域里是稀疏的。读原文第IV节（插值玩具实验，解释为什么高频下逐步离散化会失败）和第V节算法1。动手：取一段机械臂关节轨迹，用scipy做DCT、乘10取整，看看有多少系数变成0，再反变换比较误差；然后用openpi里的FAST分词器对比token数量。
