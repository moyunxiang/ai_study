离线RL的瓶颈在哪

Is Value Learning Really the Main Bottleneck in Offline RL?
2024.06论文延伸NeurIPS 2024Seohong Park, Kevin Frans, Sergey Levine, Aviral Kumar · UC Berkeley, Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL理论上能用价值函数从低质量数据中学得比模仿更好，实际却常常不如行为克隆。人们通常把原因归于价值函数学不好，但这一判断很少被系统检验。

方法

把离线RL拆成三个部分——价值学习、从价值中提取策略、策略在测试状态上的泛化——分别控制变量做大规模实证研究，看究竟哪一步才是主要瓶颈。

影响

得出两个反直觉的结论：策略提取方法的选择往往比价值学习目标更影响性能与可扩展性（AWR式加权BC不如DDPG+BC式的行为约束策略梯度）；测试时访问训练数据支撑之外的状态造成的泛化误差，常常是比价值函数更大的障碍。

背景

离线RL算法众多：离线强化学习CQL、隐式Q学习IQL等改进价值学习，AWR优势加权回归、TD3+BC极简离线RL等代表不同的策略提取方式。社区讨论多集中在“如何学到不高估的价值函数”，并以D4RL上的分数比较算法。但当数据规模变大、质量变化时，离线RL的提升常常不明显，甚至不如简单的行为克隆。作者想弄清：给定一个足够好的价值函数，算法是否真的把它用好了？瓶颈到底在哪里？

方法

作者设计了一组对照实验：

  • 价值学习：比较IQL式期望分位数回归、SARSA式在数据策略上的评估以及CRL式对比价值等目标；
  • 策略提取：比较优势加权回归 max E[exp(A/β) log π(a|s)]（AWR）、DDPG+BC式的行为约束策略梯度 max E[Q(s,π(s))] − α·E[‖π(s) − a‖²]，以及基于采样的动作选择；
  • 策略泛化：区分训练状态与测试时实际访问的状态，测量策略在后者上的误差。

实验在多种任务和数据规模上进行，并单独增大价值网络或策略网络的数据量，观察哪一部分的数据扩展更能提升性能。作者还提出两种简单的测试时改进：用在测试状态上的价值梯度对策略做少量在线修正，或用OOD感知的数据增强来提升策略的泛化。

结果

摘要称：第一，策略提取算法的选择显著影响离线RL的性能与可扩展性，往往比价值学习目标影响更大；例如常见的价值加权行为克隆目标（如AWR）没有充分利用学到的价值函数，换成行为约束的策略梯度目标（如DDPG+BC）常能带来显著的性能与扩展性提升。第二，阻碍离线RL性能提升的一大障碍，往往是策略在训练数据支撑之外的测试状态上泛化不完美，而不是价值函数本身。

后来的发展

这篇分析改变了离线RL的实践习惯：后续工作更常用行为约束的策略梯度提取策略，更关注测试时状态分布与策略泛化；它也与同组的OGBench离线目标RL基准相互配合，后者提供了检验这些结论所需的更难、更大规模的任务。

本篇术语

  • 策略提取　已经学到价值函数后，如何从中得到一个可执行的策略，例如加权模仿或直接沿价值梯度更新策略。
  • 测试时状态分布　部署策略时实际访问到的状态，可能与训练数据覆盖的状态不同，策略在那里的误差决定了最终表现。

怎么学

先熟悉AWR优势加权回归与TD3+BC极简离线RL两种策略提取方式；读原文第4节策略提取比较与第5节泛化分析；在一个D4RL任务上固定IQL价值函数，分别用AWR与DDPG+BC提取策略，比较回报。
