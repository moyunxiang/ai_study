Detic两万类检测

Detecting Twenty-thousand Classes using Image-level Supervision
2022.01论文延伸ECCV 2022Xingyi Zhou, Rohit Girdhar, Armand Joulin, Philipp Krähenbühl, Ishan Misra · Meta AI / 得克萨斯大学奥斯汀分校待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

检测数据集标框很贵，类别数有限（COCO 80类、LVIS 1200类）；分类数据集类别多得多，却没有框。

方法

直接用图像分类数据训练检测器的分类头：把图像级标签赋给面积最大的候选框，不需要复杂的“标签分配给哪个框”的方案；分类器权重用CLIP的文本嵌入。

影响

第一次用ImageNet全部两万一千类训练检测器，且无需微调就能泛化到新数据集；开放词表LVIS上新类别提升8.3 mAP。

方法

开放词表检测要识别训练时没标过框的类别。ViLD开放词表检测等方法从CLIP蒸馏知识，弱监督方法则用模型预测去决定图像级标签该分给哪个框，这类分配方案复杂又容易出错。

Detic（Detector with image classes）的想法很直接：检测器的分类和定位可以分开学。有框的检测数据照常训练全部；只有图像级标签的分类数据（如ImageNet-21K）只训练分类头——把整张图的类别标签赋给区域提议网络输出的面积最大的那个候选框，只计算分类损失。分类器权重换成CLIP对类别名的文本嵌入，所以测试时换一组类别名就能检测新类别。因为不依赖模型预测做分配，实现简单，可用于各种检测架构和骨干。

摘要报告：开放词表LVIS上，所有类别提升2.4 mAP，新类别提升8.3 mAP；标准LVIS上所有类别达到41.7 mAP，只看稀有类也是41.7 mAP，缩小了少样本类别的差距。作者首次用ImageNet全部两万一千个类别训练检测器，并显示无需微调即可泛化到新数据集。
