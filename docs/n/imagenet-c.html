ImageNet-C

Benchmarking Neural Network Robustness to Common Corruptions and Perturbations
2019.03数据集延伸ICLR 2019Hendrycks, Dietterich · Oregon State University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

对抗鲁棒性研究关注最坏情况的微小扰动，但真实世界里更常见的是噪声、模糊、天气等普通损坏，分类器在这些上的表现没有标准评测。

方法

给 ImageNet 验证图加上多种常见损坏（并分严重程度），构建 ImageNet-C；另有 ImageNet-P 评测对常见扰动的稳定性。

影响

成为评测分布偏移鲁棒性的标准基准，之后 ImageNet-A、ImageNet-R 等一系列鲁棒性数据集沿用了这条路线。

方法

ImageNet-C 把标准 ImageNet 验证图施加多类常见的损坏，如噪声、模糊、天气和数码处理，每类设有不同严重程度，用分类器在这些图上的错误率衡量鲁棒性。ImageNet-P 则测量对常见微小扰动的预测稳定性。

论文有一个出乎意料的发现：从 AlexNet 到 ResNet，相对的损坏鲁棒性几乎没有变好，也就是说准确率大幅提高并没有带来对损坏的抵抗力。他们还找到了一些改善方式，甚至发现一个被绕过的对抗防御方法能显著提升对常见扰动的鲁棒性。这与 对抗样本 关注最坏情形的角度互补。

局限与后续

  • 损坏是人工合成的，真实世界的分布偏移更复杂，通过合成基准不代表真实鲁棒。
