SimVLM

SimVLM: Simple Visual Language Model Pretraining with Weak Supervision
2021.08论文延伸ICLR 2022Wang, Yu, Yu, Dai, Tsvetkov, Cao · Google / CMU待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视觉语言预训练依赖干净的图文标注与区域标签，并叠加多个数据集专用损失，训练过程复杂且难扩展。

方法

只用一个前缀语言建模目标，把图像patch与文字前缀作为输入，让模型续写剩余文字，用大规模弱监督网络数据训练。

影响

把视觉语言预训练简化为一个生成目标，并证明规模足够时无需任务专用设计，直接影响CoCa、PaLI。

方法

输入是图像patch的特征，加上一段文字的前半，模型（编码器-解码器Transformer）的任务是生成后半。这就是前缀语言建模（PrefixLM）：前缀部分可以双向可见，后面的部分自回归预测。图像的patch特征来自一个小的卷积层加Transformer，不需要检测器和框标注。

训练数据使用大规模的弱监督网络图文，不做清洗，也没有区域标签。摘要称，该方法不使用额外数据或任务专用设计，就明显超过先前预训练方法，在多个视觉语言任务上取得新的最好成绩，同时具备零样本迁移能力。

局限与后续

  • 纯生成目标缺少图文对比学习，检索与表示质量不如对比模型。

它建立在什么之上

  • 使用
    T52019.10 · LLM
    借用T5式编码器-解码器与前缀语言建模思路。
  • 改进
    M²网状记忆描述2019.12 · 多模态
    只在COCO这类人工标注的描述数据上训练，没有借助大规模网络图文数据，开放域物体描述能力有限。
  • 改进
    VinVL2021.01 · 多模态
    两阶段流程仍要先跑一个大检测器抽特征，推理慢，检测器与融合模型无法联合训练，且依赖带框标注的数据。
  • 延续
    ALIGN2021.02 · 多模态
    同样依赖大规模弱标注网络数据，但用生成目标替换对比目标。
  • 改进
    ALBEF2021.07 · 多模态
    只能做理解任务，不能直接生成文字。
