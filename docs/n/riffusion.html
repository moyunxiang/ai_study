Riffusion频谱图作曲

Riffusion - Stable diffusion for real-time music generation
2022.12系统延伸Seth Forsgren, Hayk Martiros待核对
GitHub ↗模型 ↗在交互版中打开（演化树、学习进度）

问题

2022年文生图扩散模型已经很强，但文字生成音乐的模型还很少、门槛很高。

方法

把音乐片段画成频谱图图像，直接微调Stable Diffusion去生成“音乐的图片”，再把生成的频谱图转回音频；配合提示词插值和图像条件做实时、可连续变化的音乐。

影响

2022年12月上线后在Hacker News上获得2400多分，让很多人第一次听到“用画图模型作曲”，后来发展为同名的音乐生成产品。

方法

频谱图把声音表示成一张图：横轴是时间，纵轴是频率，亮度是能量。Riffusion把几秒钟的音乐片段转成固定大小的梅尔频谱图图像，配上文字描述，在此数据上微调Stable Diffusion开源，于是输入“爵士萨克斯”之类的提示词就能生成对应的频谱图。频谱图只记录幅度、丢掉了相位，转回音频时用Griffin-Lim等方法估计相位。

为了生成连续不断的音乐，它在相邻片段之间对提示词嵌入和初始噪声做插值，并以前一段的频谱图为图像条件做图生图（与SDEdit相同的加噪再去噪思路），让音乐平滑过渡。项目开源了推理管线、频谱图与音频的互转工具、交互应用和模型权重。

局限与后续

  • 每段只有几秒，结构感和长时连贯性差；从幅度谱估计相位带来明显的音质损失。
