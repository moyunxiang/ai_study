Agent Laboratory

Agent Laboratory: Using LLM Agents as Research Assistants
2025.01论文延伸arXiv 2025Schmidgall, Su, Wang, Sun, Wu, Yu, Liu, Moor, Liu, Barsoum · 约翰斯·霍普金斯大学 / AMD待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

此前的自动科研系统要么几乎不要人参与、质量难控，要么只覆盖研究流程的一小段，成本也高。

方法

给定人类提出的研究想法，让LLM智能体依次完成文献综述、实验和报告撰写三个阶段，每个阶段允许人类反馈。

影响

证明人工反馈能显著提升自动科研的质量，同时降低成本，是开源的自动研究助手框架。

方法

背景：AI Scientist强调端到端全自动。Agent Laboratory改为“人机协作”：用户提供研究想法，系统依次经历文献综述、实验、报告撰写，产出代码仓库和研究报告，用户在各阶段给指导。

据论文摘要：作者用多种大模型部署系统，邀请研究者填写问卷评估质量并在过程中给反馈，再评估最终论文。结论：用o1-preview驱动的版本产出最好；生成的机器学习代码相比已有方法能达到最先进水平；在每个阶段加入人类反馈会明显提升整体质量；与先前自主研究方法相比成本降低84%。

局限与后续

  • 评估主要靠少数研究者的主观评分，课题限于机器学习实验，缺少外部可复现的评测标准。
