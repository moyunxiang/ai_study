OAIF在线AI反馈

Direct Language Model Alignment from Online AI Feedback
2024.02论文延伸Shangmin Guo, Biao Zhang, Tianlin Liu, Tianqi Liu, Misha Khalman, Felipe Llinares, Alexandre Ramé, Thomas Mesnard et al. · Google DeepMind、爱丁堡大学、巴塞尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DPO这类直接偏好对齐方法用的偏好数据是训练前一次性收集的，训练中从不更新；数据里的回答还常常来自另一个模型。随着被训练的模型不断变化，训练不可避免地是离线、离策略的。

方法

把在线反馈加回直接偏好对齐：每一轮训练从当前模型采样两个回答，让一个LLM作为标注者判断哪个更好，立刻用这对偏好做DPO等更新。

影响

方法极其简单，但在多个任务的人工评测中超过离线DPO和RLHF，有力支持了“在线、同策略的偏好数据是关键”这一观点，成为在线DPO类方法的代表。

方法

背景：DPO直接偏好优化、IPO与ΨPO框架、SLiC-HF序列似然校准被统称为直接偏好对齐（DAP）方法：不训练奖励模型、不做RL，直接在偏好对上优化策略，比InstructGPT与RLHF式RLHF简单稳定。但它们有两个隐患：

  • 离线：偏好数据集事先收集好，训练中不更新；
  • 离策略：数据中的回答往往由另一个模型（甚至人）生成，而被训练的模型在训练中不断变化，二者分布越来越不一致。RSO统计拒绝采样已经指出偏好对的采样分布会影响估计质量。

相比之下，RLHF始终用当前策略采样，是在线、同策略的。

OAIF：每个训练步：

  • 从当前模型π_θ对提示x采样两个回答y₁、y₂；
  • 用一个LLM标注者（例如更大的PaLM 2模型），通过提示让它判断哪个回答更好，得到偏好（y⁺, y⁻）；
  • 立即用这对偏好按DPO（或IPO、SLiC）的损失更新π_θ。

这样，偏好数据始终来自当前模型的分布，反馈是在线的；而且不需要单独训练奖励模型，LLM标注者直接给出成对比较，这与RLAIF用AI反馈代替人类反馈的思路一致。

结果（摘要）：尽管简单，在多个任务的人工评测中OAIF超过离线的DAP方法和RLHF。另外，OAIF的反馈很容易控制：只要修改给LLM标注者的指令（例如“更偏好简短的回答”），就能引导模型往相应方向对齐。

后来的发展

“在线采样+AI裁判+DPO”的组合被许多开源后训练流程采用（迭代DPO、在线DPO等），也为Self-Rewarding等“模型自己当裁判”的工作提供了对照。

局限与后续

  • 依赖一个更强的LLM作为标注者，对齐上限和偏差都受这个标注者影响，每步还要调用它，标注成本随训练步数线性增长。

  • LLM标注者本身有偏好偏差（如偏爱更长的回答），在线反馈会把这些偏差持续放大。

  • 使用
    RLAIF2023.09 · LLM
    用LLM代替人类给出成对偏好，属于AI反馈。
  • 延续
    RSO统计拒绝采样2023.09 · LLM
    RSO指出偏好对应来自（近似）最优策略，OAIF进一步做到每步都从当前策略在线采样。
  • 使用
    IPO与ΨPO框架2023.10 · LLM

读懂它需要的概念

人类反馈强化学习 on-policy与off-policy 解码：贪心、束搜索、温度与top-p KL散度

本篇术语

  • 直接偏好对齐（DAP）　不训练奖励模型、不用强化学习，直接用偏好对构造损失来优化模型的一类方法，DPO是代表。
  • 同策略（on-policy）　用于训练的数据由当前正在训练的模型自己生成。

怎么学

先读DPO直接偏好优化和RLAIF；读本文第3节OAIF算法和第4节与离线DPO、RLHF的对比；动手：用一个小模型采样两个回答，用更大的开源模型按提示判断优劣，循环几百步做在线DPO，与在固定偏好集上做DPO比较胜率。
