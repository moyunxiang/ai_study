混合专家MoE

Adaptive Mixtures of Local Experts
1991论文延伸Neural Computation 1991Robert Jacobs, Michael Jordan, Steven Nowlan, Geoffrey Hinton · 麻省理工学院 / 多伦多大学待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

一个网络同时处理多种不同的子任务时，各部分互相干扰，学习慢，而且难以让不同部分各司其职。

方法

多个专家网络加一个门控网络：门控根据输入决定每个专家的权重，整个系统一起训练，专家自动分工到不同的区域。

影响

是稀疏专家模型的源头，三十年后被用来在不成比例地增加计算的前提下扩大大语言模型。

方法

系统包含若干个专家网络，各自对输入给出输出，以及一个门控网络，它输出一组和为1的权重（用Softmax与logits），最终输出是专家输出的加权和y = Σ g_i(x) · y_i(x)。

训练目标把专家当作竞争：误差用每个专家各自的误差按门控权重混合，使得对某个输入表现好的专家，会得到更大的门控权重和更多的学习机会，渐渐分化出各自负责的区域。可以用反向传播或EM算法训练。后来的稀疏门控MoE层只激活得分最高的少数专家，使参数量大增而每个词的计算量不变，见混合专家。

局限与后续

  • 门控可能总是偏向少数几个专家，其余专家得不到训练；每个输入要运行所有专家，计算量随专家数增长。
    后来针对它的工作　稀疏门控MoE层 稀疏MoE大模型

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    专家和门控网络都用反向传播联合训练。
  • 使用
    EM算法1977 · 基础
    可以用EM算法把专家的责任分配视为隐变量来训练。
