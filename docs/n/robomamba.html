RoboMamba高效VLA

RoboMamba: Efficient Vision-Language-Action Model for Robotic Reasoning and Manipulation
2024.06论文延伸arXiv 2024Jiaming Liu, Mengzhen Liu, Zhenyu Wang, Pengju An, Xiaoqi Li, Kaichen Zhou, Senqiao Yang, Renrui Zhang, Yandong Guo, Shanghang Zhang待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

VLA在复杂任务上的推理能力有限，微调和推理开销又很大。

方法

以Mamba状态空间模型为主干，用协同训练对齐视觉与语言，再接一个简单的策略头预测SE(3)位姿。

影响

只微调约0.1%的参数就能学会操作技能，作者称推理速度约为现有VLA的3倍。

方法

卡在哪：基于LLaVA、RT-2与VLA式Transformer的VLA，注意力开销大，且推理能力有限。

做法：RoboMamba用Mamba状态空间模型（状态空间模型与线性RNN）代替Transformer做语言主干，通过协同训练把视觉token与语言嵌入对齐，使它具备通用和机器人推理能力。然后加一个简单的策略头，直接预测末端执行器的SE(3)位姿（三维位置与朝向）。

结果：论文报告在通用与机器人推理基准上表现强，学习操作技能只需微调约0.1%的参数，推理约3倍快于现有VLA。

局限与后续

  • Mamba主干生态远不如Transformer成熟，后续主流VLA仍多用Transformer。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 位姿预测适合规划类动作，高频连续控制未在摘要中说明。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    LLaVA2023.04 · 多模态
    沿用视觉特征对齐语言模型的范式，换成状态空间主干。
  • 竞争
    RT-2与VLA2023.07 · 具身·世界模型
    同样是视觉语言动作模型，RoboMamba强调效率。
  • 使用
    Mamba状态空间模型2023.12 · 基础
    以Mamba作为语言主干，获得线性复杂度。
