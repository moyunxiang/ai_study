Weka

WEKA: A Machine Learning Workbench
1994系统延伸Geoffrey Holmes, Andrew Donkin, Ian H. Witten · University of Waikato待核对
维基百科 ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

机器学习算法散落在各研究者的代码里，数据格式各异，想比较几种分类器要自己拼接大量粘合代码。

方法

做一个统一的工作台：同一数据格式，同一套接口，图形界面里点几下就能比较多种学习算法。

影响

成为二十年里数据挖掘教学和快速对比实验的标准工具，也塑造了「调用一个统一接口的算法库」的使用习惯。

方法

Weka由新西兰怀卡托大学开发，集成了决策树、规则、贝叶斯、聚类、关联规则等大量算法和数据预处理工具，并配有图形界面（Explorer）和命令行。所有算法读取同一种数据文件格式，因此「换一个分类器再跑一遍」只需要换一个选项，十折交叉验证等评估流程也内置在工具里。

对读者最直接的价值是：它让不懂编程的人也能完成一次完整的建模与评估，教材《Data Mining》（Witten等）长期以它为配套工具。这种统一接口的思路后来在scikit-learn中以Python形式延续。

局限与后续

  • 主要把整个数据集读进内存，面向表格数据和中小规模问题，不适合深度学习和大数据。
    后来针对它的工作　scikit-learn Spark
  • 基于Java的图形工作台，难以嵌入Python为主的科研流程。
    后来针对它的工作　scikit-learn

它建立在什么之上

  • 竞争
    MATLAB1984 · 系统·效率
    都是让研究者快速做实验的环境：MATLAB提供通用矩阵工具，Weka提供现成的机器学习算法与流程。

后来的相关工作

  • 竞争
    scikit-learn2010.02 · 系统·效率
    两者都是通用机器学习工具箱；Weka基于Java并以图形界面为主，scikit-learn以Python库形式嵌入编程工作流，后来在研究和工业界更普及。
  • 改进
    Spark2010.06 · 系统·效率

怎么学

安装Weka，用自带的iris数据集比较决策树和朴素贝叶斯，再用scikit-learn复现。
