SIFT特征

Object Recognition from Local Scale-Invariant Features
1999论文重要ICCV 1999David G. Lowe · 不列颠哥伦比亚大学（UBC）待核对
ICCV 1999（DOI） ↗PDF（作者主页） ↗IJCV 2004完整版 ↗在交互版中打开（演化树、学习进度）

问题

要在杂乱、被遮挡的照片里认出一个物体，需要能在两张图之间可靠对上的局部特征；当时的角点特征一缩放就对不上，对视角、光照也很敏感。

方法

在多尺度的高斯差分金字塔里找极值点作为关键点，按关键点自己的尺度和主方向截取局部区域，用梯度方向直方图描述它，从而对缩放、旋转不变，对光照和视角变化部分不变。

影响

SIFT成为此后十多年图像匹配、全景拼接、三维重建、物体检索的通用特征，视觉词袋、HOG、SfM系统都建立在它之上。

背景

1990年代，物体识别的一条主流思路是比较整张图的外观（如特征脸Eigenfaces），一有遮挡、背景一变就失效。另一条思路是找局部特征点再匹配，常用Harris角点角点：它对平移、旋转稳定，但只在一个固定尺度上检测——同一个物体拍近一点、拍远一点，检测到的点就不再是同一批，周围窗口的内容也对不上。

Lowe想要的特征要满足两点：物体缩放、旋转、轻微换视角或光照变化后，大部分特征仍能在另一张图里找到对应；每个特征又足够独特，能在大库里用最近邻直接查到。

方法

SIFT（尺度不变特征变换）分两步：先检测关键点，再描述它。

检测：在尺度空间里找极值。把图像用不同宽度σ的高斯分布模糊，得到一串越来越模糊的图；相邻两张相减就是高斯差分（DoG），它近似于Marr《视觉》里用来找边缘的高斯拉普拉斯。每一层模糊完后再缩小图像，组成金字塔。一个像素如果比它在同层和上下两层的邻居都大或都小，就是一个关键点，它所在的层就是它的“特征尺度”。同一个斑点放大两倍，会在大一档的尺度上被检测到——这就是尺度不变的来源。

定方向。统计关键点周围像素的梯度方向，取最强的方向作为主方向。之后的描述都相对于这个方向计算，于是对旋转不变。

描述。以关键点为中心、按其尺度截取一块区域，切成4×4个小格，每格统计8个方向的梯度直方图。梯度的位置被有意“模糊”到邻近格子里，这样小的变形和视角变化不会让描述子剧变（作者称模仿了复杂细胞，见视觉皮层感受野）。1999年版在两个尺度上取样，共8×4×4＋8×2×2＝160维；2004年的期刊版简化为4×4×8＝128维，成为标准。

匹配与识别。新图的每个特征在库里找最近邻；2004年版提出比值检验：最近邻距离小于次近邻距离的0.8倍才算匹配。再用霍夫变换投票，把对同一物体位姿意见一致的匹配聚在一起，至少3个一致就做最小二乘求位姿确认。

结果

1999年论文：每张图约产生1000个特征，提取不到1秒；在杂乱、部分遮挡的场景中识别物体总耗时不到2秒。图像旋转15度、缩放0.9倍并拉伸后，78%的特征仍能在预测位置找到匹配。2004年期刊版报告：0.8的比值阈值能剔除90%的错误匹配，同时丢掉的正确匹配不到5%。

后来的发展

SIFT很快成为视觉的“通用零件”：视觉词袋把它量化成视觉单词做检索，HOG与手工特征时代借用了它的梯度方向直方图，Photo Tourism和一天建成罗马用它匹配成千上万张网络照片重建三维，COLMAP至今默认用它。SURF和ORB特征主要是为了更快而做的近似或替代。

在识别任务上，2012年后它被卷积网络学到的特征取代；在匹配与三维重建上它坚持得更久，直到SuperPoint、LoFTR等学习型方法在弱纹理、大视角下明显更好。

容易误解的地方

  • “尺度不变”指能在不同尺度上检测到同一个点并按该尺度归一化，不是说描述子对任何形变都不变；视角变化超过几十度，匹配率会明显下降。
  • 最常被引用的128维描述子和0.8比值检验来自2004年的IJCV期刊版，不是1999年的会议版。

局限与后续

  • 特征是手工设计的，只描述局部纹理，不包含“这是什么类别”的语义；拿它做类别识别还要再加量化、编码和分类器。
    后来针对它的工作　视觉词袋 空间金字塔匹配 AlexNet
  • 构建高斯金字塔和128维描述子计算量大，每张图要接近1秒，难以满足视频和移动设备的实时需求。
    后来针对它的工作　SURF ORB特征
  • 在弱纹理（白墙）、重复纹理、大视角或昼夜光照变化下，检测不到足够的稳定点或匹配大量出错。

它建立在什么之上

  • 使用
    Marr《视觉》1982 · 视觉
    检测器用的高斯差分是Marr–Hildreth高斯拉普拉斯的高效近似，多尺度的思路也来自那一脉的尺度空间理论。
  • 使用
    视觉皮层感受野1959 · 视觉
    描述子把梯度位置在邻近格子间模糊，作者明确说这是模仿复杂细胞对小位移不敏感的特性。
  • 改进
    Roberts积木世界1963 · 视觉
    只在背景干净、物体形状预先已知的积木世界里成立，对纹理、曲面和自然场景无能为力。
  • 改进
    Canny边缘检测1986.11 · 视觉
    高斯平滑的尺度要手动选，一个尺度难同时适应不同粗细的边缘。
  • 改进
    Harris角点1988 · 视觉
    Harris角点只在固定尺度上检测，物体一缩放就对不上；SIFT在尺度空间里找极值并按特征尺度描述，解决了缩放问题。
  • 竞争
    特征脸Eigenfaces1991 · 视觉
    特征脸代表“比较整张图外观”的全局路线，遇到遮挡和背景变化就失效；SIFT的局部特征路线在杂乱场景中更稳，此后十多年占据主流。

读懂它需要的概念

卷积运算 高斯分布 导数、偏导与梯度 范数与距离 k近邻 图像作为张量

本篇术语

  • 尺度空间　把同一张图用越来越宽的高斯核模糊，得到一串从精细到粗糙的版本，用来在不同尺度上寻找结构。
  • 高斯差分（DoG）　两张模糊程度相邻的图相减，突出与该尺度相当大小的斑点和边缘，是高斯拉普拉斯的廉价近似。
  • 比值检验　只有当最近邻明显比次近邻更近（距离比小于0.8）时才接受匹配，用来排除在重复纹理上模棱两可的错误匹配。

怎么学

先补卷积运算与高斯分布，理解高斯模糊和图像梯度。读2004年IJCV版第3–6节（比会议版清楚得多）。动手：用OpenCV的SIFT在两张不同角度拍的同一物体照片上提取特征，做比值检验匹配，再用RANSAC估计单应矩阵把两图拼起来；把比值阈值从0.6调到0.9，看正确匹配和错误匹配的变化。
