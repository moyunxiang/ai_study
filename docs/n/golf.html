Bellman Eluder维度与GOLF

Bellman Eluder Dimension: New Rich Classes of RL Problems, and Sample-Efficient Algorithms
2021.02论文延伸NeurIPS 2021Chi Jin, Qinghua Liu, Sobhan Miryoosefi · Princeton待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RL理论里有好几套“可高效学习”的结构假设——表格MDP、线性MDP、低Bellman秩、低Eluder维度——各有各的算法和分析，彼此不能互相覆盖，人们想找到更小、更统一的结构条件。

方法

提出新的复杂度度量Bellman Eluder（BE）维度，证明低BE维度的问题类包含上述几乎所有已知可解类；并设计基于优化的算法GOLF、重新分析OLIVE，证明二者在低BE维度问题上样本复杂度只依赖BE维度而与状态动作数无关。

影响

BE维度和GOLF成为函数近似RL理论的核心工具之一，后续的DEC、广义Eluder系数等统一框架都以它为比较或推广对象。

方法

函数近似RL的基本问题：给定一个函数类F（候选的Q函数），在什么条件下只需与“F的复杂度”多项式相关的样本就能学到近似最优策略？

Bellman Eluder维度：考虑贝尔曼残差 (f − T f)(s, a) 构成的函数类，在某个分布族上度量它的Eluder维度与后验采样。直观上，它衡量“即使前面的若干次观测都显示贝尔曼误差很小，下一次仍可能出现大误差”的最长链有多长。作者证明低BE维度涵盖：表格MDP、线性MDP（见LSVI-UCB线性MDP）、反应式POMDP、低Bellman秩问题（见Bellman秩与OLIVE）以及低Eluder维度问题。

GOLF（Global Optimism based on Local Fitting）：维护一个置信集合，里面是在历史数据上贝尔曼误差（用平方损失衡量）都不大的函数：

C_t = { f ∈ F : L_D(f_h, f_(h+1)) ≤ min_g L_D(g, f_(h+1)) + β，对所有步h }

每轮从置信集中选初始价值最大的函数（全局乐观），按它的贪心策略采集一条轨迹，加入数据后更新置信集。

作者证明GOLF与OLIVE在低BE维度问题上的样本复杂度和遗憾都是所有相关参数（维度、视界、函数类的覆盖数）的多项式，且与状态和动作空间大小无关；在多个已知子类上，这些结果与已有最好结果持平或更好。

局限与后续

  • GOLF每轮要在函数类上做带约束的全局优化，一般情况下计算不可行，只是统计意义上的算法。

本篇术语

  • Bellman Eluder维度　衡量贝尔曼残差函数类“难以通过已有数据预测”的程度的复杂度度量，越小越容易学。
  • 置信集合　与历史数据相容（误差不超过阈值）的所有候选函数的集合。
