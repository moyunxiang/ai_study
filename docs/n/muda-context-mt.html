MuDA篇章翻译评测

When Does Translation Require Context? A Data-driven, Multilingual Exploration
2021.09论文延伸ACL 2023（获奖论文）Patrick Fernandes, Kayo Yin, Emmy Liu, André F. T. Martins, Graham Neubig · 卡内基梅隆大学、里斯本高等理工学院、加州大学伯克利分校待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

很多翻译错误只有看前文才能避免（代词该用哪个性别、正式还是非正式称呼、省略的动词），但常用的BLEU、COMET几乎测不出这些，已有的篇章翻译评测只挑了几种现象、也不成体系。

方法

用「条件交叉互信息」逐词量化：加上前文后，模型对这个目标词的预测改变了多少。把高度依赖上下文的词归纳成几类篇章现象，写成可自动标注任意语料的标注器（MuDA基准），再分别统计翻译系统在这些词上的准确率。

影响

MuDA给14个语言对提供了系统的篇章现象评测，发现主流上下文感知翻译模型只比逐句翻译略好；论文获ACL 2023的奖项，常被用来评估大模型做文档级翻译的能力。

背景

谷歌神经机器翻译以来的机器翻译基本按句子逐句翻译。篇章级翻译研究给模型加入前几句作为上下文，但整体BLEU只涨一点点，很难判断模型是否真的用到了上下文。已有的对比测试集（如针对英语代词的测试）只覆盖少数现象，且需要人工构造，难以推广到其他语言。

方法

量化上下文的作用。 对目标句的每个词 y_i，比较带上下文 C 和不带上下文时模型给它的概率，定义逐点条件交叉互信息：

P-CXMI(y_i) = log P(y_i | x, y_<i, C) − log P(y_i | x, y_<i)

值越大，说明这个词越需要上下文才能翻对。作者在多个语言对上统计P-CXMI高的词，人工归纳出五类现象：代词（如英语it译成有性别的法语il/elle）、正式程度（德语du/Sie、日语敬语）、词汇一致性（同一术语前后译法一致）、省略（目标语需要补出被省略的成分）、动词形式（时态在篇章中需一致）。

MuDA标注器。 为每类现象写基于词性、指代、对齐等信息的规则标注器，可以在任意平行语料上自动找出需要上下文的词；评测时只在这些词上计算翻译是否正确。

结果

摘要报告：确认了以往研究过的现象确实困难，并发现了以往没有关注的现象；常见的上下文感知翻译模型相比不看上下文的模型只有很小的提升，说明它们没有有效处理这些歧义；发布了14个语言对的代码和数据。

后来的发展

MuDA被用于比较商业翻译系统和大语言模型的篇章翻译能力，后续研究报告大模型在正式程度、代词等现象上明显好于逐句NMT。P-CXMI这种「量化上下文贡献」的度量也被用来分析其他生成任务中模型对上下文的依赖。

读懂它需要的概念

互信息 文本生成的自动指标 编码器-解码器 上下文窗口

本篇术语

  • 篇章级（文档级）机器翻译　翻译时考虑前后句子，以正确处理代词、称呼、术语一致性等跨句现象。
  • P-CXMI　逐点条件交叉互信息：某个目标词在加入上下文后对数概率的变化量，用来衡量它对上下文的依赖程度。

怎么学

先了解Transformer翻译模型和互信息 → 读原文第3节P-CXMI和第4节五类现象 → 动手：用MuDA标注一段英法平行文本，找出代词与正式程度相关的词，再比较逐句翻译和整段交给大模型翻译的准确率。
