Diffusion-QL扩散策略

Diffusion Policies as an Expressive Policy Class for Offline Reinforcement Learning
2022.08论文延伸ICLR 2023Zhendong Wang, Jonathan J Hunt, Mingyuan Zhou · 德克萨斯大学奥斯汀分校 / Twitter待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离线RL的策略约束方法（TD3+BC极简离线RL、BRAC行为正则化等）大多用单峰高斯策略，表达能力有限：当数据由几种截然不同的行为混合而成时，高斯策略要么平均成一个糟糕的动作，要么约束不住，导致明显次优。

方法

直接用条件扩散模型（DDPM式的去噪过程）表示策略 π(a|s)；训练损失是扩散模型的去噪行为克隆损失，再加一项让生成的动作Q值最大的项，于是策略在“像数据”和“回报高”之间取折中。

影响

首批把扩散模型用作离线RL策略类的工作之一，在D4RL上取得当时的最好成绩，开启了“扩散/流策略+Q学习”的一系列后续工作（IDQL隐式扩散Q学习、一致性策略、流匹配Q学习等）。

背景

离线RL需要防止策略选数据中没出现过的动作，常见办法是让策略贴近行为策略，例如在目标里加行为克隆项（TD3+BC极简离线RL）或散度惩罚（BRAC行为正则化）。这些方法默认策略是一个高斯分布，均值由网络给出。但真实数据集常由多个策略或多种技能混合采集，在同一状态下的动作分布是多峰的；用高斯去拟合，均值会落在几个峰之间——一个数据里从没出现过、可能很差的动作。与此同时，扩散模型在图像生成中证明了对复杂多峰分布的建模能力，Diffuser扩散规划也已把它用到轨迹规划上。

方法

策略是一个以状态为条件的扩散模型：从高斯噪声 a_N ∼ N(0, I) 出发，经过N步去噪 a_{i−1} = (a_i − β_i/√(1−ᾱ_i)·ε_θ(a_i, s, i))/√α_i + σ_i z 得到动作 a_0。训练损失有两项：

L(θ) = E_{i,ε,(s,a)∼D} ‖ε − ε_θ(√ᾱ_i·a + √(1−ᾱ_i)·ε, s, i)‖² − α · E_{s∼D, a_0∼π_θ} [Q_φ(s, a_0)]

第一项是标准的去噪损失，等价于在数据动作上做行为克隆，起到约束作用；第二项通过整条去噪链反向传播，把生成的动作往Q值高的方向推。α按Q值的平均绝对值归一化，以适应不同任务的奖励尺度。Q函数用双Q网络和普通TD学习，目标中的下一步动作由扩散策略采样。为了训练和推理不太慢，去噪步数取得很少。

结果

摘要称，扩散策略的表达能力，以及在扩散模型内部把行为克隆与策略改进耦合在一起，这两点共同带来了很好的表现；在行为策略多峰的二维老虎机例子中优于以往方法，并在大多数D4RL基准任务上达到最先进水平。

后来的发展

此后离线RL里出现了大量扩散/流策略方法：IDQL隐式扩散Q学习把扩散行为模型与隐式Q学习IQL的critic结合，用重要性采样挑动作而不是通过去噪链反向传播；也有工作用一致性模型或流匹配减少采样步数。扩散策略同时在机器人模仿学习中大放异彩（Diffusion Policy）。

局限与后续

  • Q值梯度要穿过整条去噪链反向传播，训练和推理都比高斯策略慢得多，步数一多就难以训练。
    后来针对它的工作　IDQL隐式扩散Q学习
  • Q学习的目标仍要从策略采样下一步动作，会在数据外动作上外推，对α的选择比较敏感。
    后来针对它的工作　IDQL隐式扩散Q学习

它建立在什么之上

  • 使用
    DDPM2020.06 · 生成
    策略就是一个以状态为条件的DDPM式扩散模型。
  • 竞争
    BRAC行为正则化2019.11 · RL
    BRAC用显式散度把高斯策略拉向行为策略；Diffusion-QL用表达力更强的生成模型隐式实现约束。
  • 改进
    PLAS潜在动作空间策略2020.11 · RL
    策略能达到的动作完全取决于VAE的表达能力，VAE对多峰或复杂动作分布拟合不好时，好动作可能根本解码不出来。
  • 改进
    TD3+BC极简离线RL2021.06 · RL
    TD3+BC用高斯策略加行为克隆项，难以拟合多峰数据；Diffusion-QL把行为克隆项换成扩散模型的去噪损失。
  • 延续
    Diffuser扩散规划2022.05 · RL
    Diffuser用扩散模型生成整条轨迹做规划；Diffusion-QL只用扩散模型表示单步策略，并配合Q学习。

后来的相关工作

  • 改进
    IDQL隐式扩散Q学习2023.04 · RL
    Diffusion-QL要通过去噪链反向传播Q梯度，训练慢且敏感；IDQL的扩散模型只做行为克隆，用critic权重在采样后重选动作。
  • 改进
    FQL流Q学习2025.02 · RL
    Diffusion-QL要对整条去噪链反传Q梯度；FQL改为只训练一步策略，避免递归反传。

读懂它需要的概念

离线强化学习 扩散：前向加噪与反向去噪 Actor-Critic与优势函数 模仿学习与行为克隆 噪声调度与采样步数

本篇术语

  • 多峰分布　有多个高概率区域的分布，例如在同一路口有人左转有人右转；单个高斯只有一个峰，拟合时会落在中间。
  • 扩散策略　用扩散模型表示的策略：从噪声出发，经过若干步以状态为条件的去噪，生成一个动作。

怎么学

先学DDPM的去噪训练和采样；读原文第3节目标函数和第4节二维老虎机例子；在一个D4RL任务上把TD3+BC的高斯策略换成小型扩散策略，比较在混合质量数据集上的表现。
