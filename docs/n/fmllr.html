fMLLR约束线性变换

Maximum likelihood linear transformations for HMM-based speech recognition
1998.04论文延伸Computer Speech & Language 1998Mark J. F. Gales · 剑桥大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

MLLR只变换高斯均值，方差不跟着变；而且每个高斯类都要单独做变换，用在说话人自适应训练里计算很重。

方法

让均值和方差共用同一个线性变换（约束MLLR），数学上等价于直接对输入特征做一次线性变换，于是自适应可以变成「先变换特征、再用原模型打分」。

影响

约束MLLR（CMLLR，常称fMLLR）成了GMM-HMM说话人自适应和自适应训练的标准工具；深度学习初期，fMLLR变换后的特征也是DNN声学模型的常用输入。

方法

MLLR说话人自适应用仿射变换 μ' = Aμ + b 调整高斯均值，方差保持不变。Gales这篇长文系统整理了线性变换自适应的几种形式，其中最常被用到的是约束形式：均值和协方差用同一个矩阵变换，μ' = Aμ + b，Σ' = AΣAᵀ。可以证明这时计算似然等价于把每帧特征 x 变换成 x' = A⁻¹(x − b)，再在原模型下打分（另加一个雅可比行列式项）。所以实际系统里直接估一个特征变换 W，常写成 x' = Wx + b，名字也就叫feature-space MLLR（fMLLR）。

变换用最大似然准则（见最大似然估计）按行迭代估计，只需新说话人十几秒到几十秒的语音。因为变换作用在特征上，同一个说话人只需变换一次特征，后面所有高斯都不用改，这使SAT说话人自适应训练的训练成本大幅下降：每个训练说话人的特征先各自规整，再训练一个规范模型。

后来Kaldi的标准GMM流程里，LDA+MLLT之后接SAT+fMLLR是通用配方；深度网络声学模型刚兴起时，很多系统把fMLLR规整后的特征作为网络输入以获得额外收益。以上与工具包的关系为一般了解。
