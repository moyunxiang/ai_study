EDA文本数据增强

EDA: Easy Data Augmentation Techniques for Boosting Performance on Text Classification Tasks
2019.01论文延伸EMNLP-IJCNLP 2019Jason Wei, Kai Zou · Protago Labs、达特茅斯学院、乔治城大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

图像领域翻转、裁剪就能扩充数据，文本却很难做数据增强：改一个词可能改变句意；回译、生成式改写又要额外训练翻译或语言模型，小团队用不起。

方法

只用四个不需要任何模型的简单操作：同义词替换（用WordNet换掉n个非停用词）、随机插入（在随机位置插入某个词的同义词）、随机交换（随机交换两个词的位置）、随机删除（以概率p删掉每个词），对每条训练句子生成若干变体。

影响

EDA因为简单、几乎零成本，成为文本分类小数据场景下最常用的增强基线，后续的文本增强综述和方法几乎都拿它对比。

背景

在计算机视觉里，数据增强是标准做法，AlexNet就靠随机裁剪和翻转减轻过拟合。NLP中已有的增强方法包括回译（先译成外语再译回来）、用语言模型预测替换词、按同义词典替换，但前两种需要训练好的模型、计算开销大，系统性的比较也很少。对只有几百条标注样本的文本分类任务，过拟合尤其严重。

方法

对一条长度为 l 的句子，按增强强度参数 α 计算要改动的词数 n = α·l，然后随机选择以下操作之一：

  • SR 同义词替换：随机选 n 个非停用词，各自换成WordNet里的一个随机同义词；
  • RI 随机插入：随机找一个非停用词的同义词，插到句中随机位置，重复 n 次；
  • RS 随机交换：随机挑两个词交换位置，重复 n 次；
  • RD 随机删除：每个词以概率 p = α 被删除。

每条原句生成 n_aug 条增强句（训练集越小，生成越多），与原句一起训练。例如「这部电影的剧情非常精彩」经SR可能变成「这部影片的剧情非常出色」。作者在五个分类任务（SST-2、CR、SUBJ、TREC、PC）上，用RNN和TextCNN句子分类两类模型做了系统实验和消融，并给出 α 与 n_aug 的推荐取值。

结果

摘要报告：在五个文本分类任务上，EDA对卷积和循环网络都有提升，在小数据集上效果尤其明显；平均而言，只用50%训练数据加EDA，就能达到用全部数据正常训练的准确率。

后来的发展

EDA之后出现了基于预训练语言模型的上下文替换、UDA（用回译做一致性正则）、AEDA（只插标点）等方法。预训练模型普及后，研究发现EDA对BERT等大模型的提升明显变小，甚至可能有害；但在资源受限、无法调用大模型的场景下，它仍常被当作第一步尝试。

局限与后续

  • 替换、插入和删除可能改变句子的标签（例如删掉「不」会让否定句变成肯定句）。

它建立在什么之上

  • 延续
    AlexNet2012.09 · 视觉
    把视觉中「对输入做随机扰动以扩充数据、减轻过拟合」的数据增强思路搬到文本分类。
  • 使用
    TextCNN句子分类2014.08 · NLP
    用TextCNN和RNN作为被增强训练的分类模型。
  • 竞争
    回译2015.11 · NLP
    回译需要训练好的翻译模型来生成改写句，EDA只用规则操作，几乎零成本。
  • 使用
    WordNet1995 · 数据·评测
    同义词替换和随机插入都从WordNet查同义词。

读懂它需要的概念

数据增强 正则化与权重衰减 监督学习 训练集、验证集与测试集

本篇术语

  • 文本数据增强　对已有的训练句子做改写、替换、扰动，生成新的带标签样本，以扩大训练集、减轻过拟合。
  • 停用词　「的」「了」「the」「is」这类出现极频繁、单独几乎不携带内容的词，很多文本处理会把它们排除在外。

怎么学

先了解数据增强 → 读原文第2节四个操作和第4节消融 → 动手：在一个只有500条样本的情感分类数据上，对比加不加EDA训练的TextCNN准确率，再换成BERT看提升是否还在。
