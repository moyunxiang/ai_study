叠加假说

Toy Models of Superposition
2022.09论文重要Transformer Circuits Thread 2022Nelson Elhage, Tristan Hume, Catherine Olsson, Nicholas Schiefer, Tom Henighan, Roger Grosse, Martin Wattenberg, Chris Olah et al. · Anthropic / Harvard待核对
原文 ↗arXiv ↗在交互版中打开（演化树、学习进度）

问题

机制可解释性希望一个神经元对应一个可理解的特征，但实际上很多神经元是多义的，在大语言模型里干净的神经元甚至很少见。为什么会这样，一直没人说清楚。

方法

用只有几个维度的玩具模型证明：当特征很稀疏时，网络会把比维度数更多的特征以“几乎正交”的方向叠放在同一组神经元里，代价是一点干扰；多义神经元就是这种叠加的副产品。

影响

把多义性从“恼人的例外”变成了可以研究的现象，并指出了出路：在模型激活上找一组过完备的特征基。这直接导向了一年后用稀疏自编码器提取单义特征的工作。

背景

Circuits与机制可解释性在图像网络里找到了很多含义清楚的神经元，但也发现了多义神经元，并猜测网络是把多个特征“叠加”在一起以节省神经元。Transformer电路的数学框架把同样的方法搬到语言模型上之后，问题更严重了：注意力头还算好读，MLP层的神经元大多对一堆毫不相干的东西都有反应，按神经元去读电路几乎走不通。

要继续推进，必须先回答：神经元什么时候会与特征对齐，什么时候不会？在真实模型里直接研究太复杂，因为我们根本不知道“真正的特征”是什么。这篇文章的做法是造一个知道答案的小模型。

方法

线性表示假设。特征对应激活空间中的方向：若特征f₁、f₂取值x₁、x₂，表示就是x₁W₁ + x₂W₂ + …。一个d维空间只能放d个互相正交的方向，但在高维空间里，可以放下多得多的“几乎正交”（夹角接近90度）的方向。

玩具模型。输入x有n个特征，每个特征以概率S为0（S叫稀疏度），否则在[0, 1]上均匀取值；每个特征还有一个重要性Iᵢ。模型把n维输入压到m维（m < n）再还原：

h = W·x，x′ = ReLU(Wᵀh + b)，损失L = Σᵢ Iᵢ·(xᵢ − x′ᵢ)²

作为对照，把ReLU去掉就是线性模型。

关键观察。在n = 20、m = 5的实验里：

  • 线性模型只学最重要的5个特征，彼此正交，其余丢掉——和主成分分析PCA一样。
  • ReLU模型在特征稠密时也一样；但随着特征变稀疏，它开始把更多特征塞进5个维度，先把不太重要的特征排成“对跖对”（一个特征的方向正好是另一个的反方向），然后扩展到三角形、五边形、四面体等几何结构。

为什么ReLU有用。两个特征共用方向时，一个激活会让另一个也“看起来”有一点激活，这是干扰。如果特征很稀疏，两个同时出现的概率很低；而ReLU能把小的负干扰截成0。于是“多表示几个特征”的收益超过了偶尔干扰的代价。

相变。作者用“每个特征占几个维度”D* = m / ‖W‖²_F来度量，发现它会“粘”在1和1/2这样的值上，并在稀疏度和重要性变化时出现突变式的转换，像物理中的相变。

特权基。如果在隐藏层上加ReLU，神经元方向变得特殊，特征会更倾向于对齐到单个神经元；但在叠加下，仍会出现同时承载多个特征的多义神经元。文章还展示了一些计算（如求绝对值）可以直接在叠加状态下完成。

结果

玩具模型中观察到：叠加是真实存在的现象；单义和多义神经元都能形成；至少有些计算可以在叠加状态下进行；特征是否以叠加方式存储由相变决定；叠加会把特征组织成对跖对、三角形、五边形、四面体等均匀多面体结构。作者还给出与对抗样本的初步联系：没有叠加时，第一个特征的端到端权重是(1, 0, 0, …)；有叠加时变成(1, ε, −ε, ε, …)，这些ε正是攻击者可以利用的干扰通道。

后来的发展

文章最后列出三条出路：训练没有叠加的模型；在有叠加的模型上找一组过完备的特征基（字典学习）；或两者结合。第二条很快被走通：稀疏自编码器解释LLM和稀疏自编码器与单义特征在2023年用稀疏自编码器从语言模型激活中分解出数千到数万个比神经元更单义的特征，SAE扩展到生产模型进一步扩展到Claude 3 Sonnet。之后的Transcoders、归因图与《大模型的生物学》都建立在“特征在叠加中、需要先分解”这一前提上。

第一条也有人尝试，例如权重稀疏Transformer直接训练权重稀疏的模型，让电路更容易读。“特征是方向”的线性表示假设也支撑了激活引导、拒答方向等直接在激活上做干预的方法。

容易误解的地方

  • 这篇文章只在玩具模型里证明了叠加，真实大模型中是否同样如此是推断，作者自己写明“非常不清楚该如何推广到真实网络”。
  • 叠加不等于多义神经元。叠加是特征比维度多；多义神经元是叠加在有特权基的层里的一种表现。没有特权基的表示（如残差流）也可以有叠加，但谈不上“某个神经元多义”。
  • “几乎正交”的方向在高维空间中可以多到指数级，这是叠加能工作的数学原因，但每多塞一个特征都会增加干扰。

本篇术语

  • 叠加　模型用m维空间表示多于m个特征，让它们的方向彼此几乎正交，并容忍少量相互干扰。
  • 特权基　某一层的坐标轴（即各个神经元）因为逐元素的非线性（如ReLU）而具有特殊意义，特征有动力对齐到这些轴上。残差流就没有特权基。
  • 过完备基　方向数多于空间维数的一组向量。用它来描述激活，就能让每个方向对应一个特征，即使这些方向不能两两正交。
  • 对跖对　两个特征的表示方向正好相反，可以共用一个维度；由于稀疏特征很少同时出现、ReLU又能截掉负值，这样几乎没有损失。
