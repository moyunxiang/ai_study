卡尔曼滤波

A New Approach to Linear Filtering and Prediction Problems
1960论文主干Journal of Basic Engineering 82(1), 1960R. E. Kalman · Research Institute for Advanced Study（RIAS，巴尔的摩）来源已核对
DOI ↗Wikipedia: Kalman filter ↗Kalman and Bayesian Filters in Python ↗在交互版中打开（演化树、学习进度）

问题

从带噪声的测量里实时估计一个运动系统的真实状态，当时的Wiener滤波要解积分方程、假设统计平稳，难以在计算机上实现。

方法

把系统写成状态空间模型，用“预测—校正”两步递推：先按动力学推一步，再用新测量按不确定性加权修正，只需保存当前估计和协方差。

影响

广泛用于导航、制导与机器人状态估计：早期实现进入阿波罗导航计算机，后来成为SLAM、传感器融合和定位中的常用基础方法。

背景

很多工程问题都是：系统在动，但我们看不清它。雷达给出的飞行器位置每次都有误差，陀螺仪会漂移，船的速度没法直接量。要控制它，先得从一串有噪声的测量里估计出它此刻的真实状态。

此前的标准答案是Wiener滤波（维纳在维纳《控制论》同一时期建立的最优滤波理论）：把信号和噪声都看作随机过程，求一个线性系统，让输出与真实信号的均方误差最小。Kalman在论文开头列出了这套方法的毛病：最优滤波器由冲激响应给出，很难照着造出来；数值求解很繁琐、不适合机器计算，问题一复杂就更糟；非平稳信号、记忆长度会增长的滤波器这类推广，每种都要重新推导；数学推导不透明，基本假设藏在里面看不清。

1950年代末正是数字计算机开始上飞行器的时候，大家需要一个能在小计算机上逐步更新的算法，而不是一个要离线求解的积分方程。

方法

状态空间模型。Kalman不再在频域里描述信号，而是用一阶差分方程描述系统的“状态”如何随时间变化，以及测量如何由状态产生。用今天的通用记号：

x_k = F·x_{k−1} + w_k（状态转移，w是过程噪声，协方差Q） z_k = H·x_k + v_k（观测，v是测量噪声，协方差R）

两步递推。滤波器只维护两样东西：当前估计x̂和它的误差协方差P（见协方差矩阵），每来一个测量就做一轮：

  • 预测：x̂⁻ = F·x̂，P⁻ = F·P·Fᵀ + Q。按动力学往前推一步，不确定性随之变大。
  • 校正：K = P⁻Hᵀ(H·P⁻·Hᵀ + R)⁻¹，x̂ = x̂⁻ + K·(z − H·x̂⁻)，P = (I − K·H)·P⁻。用测量与预测之差去修正，修正幅度由卡尔曼增益K决定。

一个数字例子。估计一辆小车的位置。预测说在10米处，方差4；传感器读到12米，方差1。一维时K = 4/(4+1) = 0.8，新估计是10 + 0.8×(12−10) = 11.6米，方差降到(1−0.8)×4 = 0.8，比两者中任何一个都小。谁更可信就更听谁的，这就是K的含义。

为什么是最优的。论文从条件期望和正交投影出发：最优估计就是真实状态在已有测量张成的空间上的投影，计算只需要一阶、二阶统计量（均值和协方差）。在噪声为高斯时，它就是贝叶斯后验的精确计算（见条件概率与贝叶斯公式、高斯分布）；即使不是高斯，它也是均方误差最小的线性估计。协方差满足一个非线性的递推方程（今天叫Riccati方程），解出它就直接得到滤波器系数。论文还证明这个滤波问题与无噪声的调节器控制问题互为对偶。

结果

这是一篇理论论文，没有基准测试。它的检验来自工程：论文用新方法重新求解了两个已知的经典问题，确认并推广了原有结果。Kalman1960年访问NASA艾姆斯研究中心时，Stanley Schmidt看出它可用于阿波罗计划的轨道估计，并把它拆成测量之间的预测和测量到来时的更新两部分、推广到非线性情形（后来叫扩展卡尔曼滤波EKF），最终进入阿波罗导航计算机。据维基百科引述，那台计算机只有2k字的磁芯内存、时钟频率不到100kHz，这正说明递推形式的价值：每步只做几次小矩阵运算。之后它被用于航天飞机、潜艇导航和巡航导弹。

后来的发展

在机器人里，它是状态估计最常见的起点。1986年的SLAM的概率框架用均值和协方差表示空间关系的不确定性，随后Smith、Self与Cheeseman用EKF同时估计机器人位姿和路标位置，FastSLAM论文称这是SLAM的主导方法；模型预测控制MPC这类控制器通常用它先估出状态再做优化；它表达不了的多峰分布、以及EKF难以处理的大规模地图，后来常用粒子滤波来处理，如蒙特卡洛定位和FastSLAM，这些后来被系统整理进《概率机器人》。今天的手机定位、无人机飞控、自动驾驶里GPS与惯性测量的融合，核心仍是卡尔曼滤波或其变体。

在机器学习里，它是连续状态、高斯噪声版本的隐马尔可夫模型，类似的预测—校正结构也出现在学出来的世界模型中，PlaNet的潜在状态模型可以看作用神经网络学出的类似结构。线性状态空间的递推思想在S4结构化状态空间、Mamba状态空间模型这类序列模型中以另一种形式重现。

容易误解的地方

  • 常说卡尔曼滤波“必须假设高斯噪声”，这不准确。高斯时它是最优估计；非高斯时它仍是最优的线性估计，只是可能有更好的非线性方法。
  • 它不是Kalman一人凭空发明的：Swerling（1958）和更早的Thiele有类似算法，Stratonovich发表过更一般的非线性滤波，连续时间版本是1961年与Bucy合写的。
  • Q和R要人来设，设错了滤波器会过度相信模型或过度相信传感器，实际工程里调这两个矩阵往往最费时间。

它建立在什么之上

  • 改进
    维纳《控制论》1948 · 事件 已核对
    针对维纳一派的Wiener滤波（论文引用的是维纳1949年的平稳时间序列外推与平滑理论）：论文开头列出Wiener方法的四条局限，改用状态空间和递推算法，同一套解法适用于平稳与非平稳情形。
  • 延续
    LQR最优控制1960 · 具身·世界模型 已核对
    论文指出滤波问题是作者此前已解决的无噪声最优调节器问题的对偶（引用的是Kalman 1958–1959年的调节器工作），两者的数学背景相同；后来的LQG就是把两者组合起来。
  • 竞争
    随机梯度下降1951 · 基础 待核对
    Robbins–Monro随机逼近同样从噪声数据中递推估计未知量，但只追踪一个点估计；卡尔曼滤波额外显式维护误差协方差，并利用动力学模型做预测。
  • 竞争
    ADALINE与LMS1960 · 基础 待核对
    同年的另一种递推滤波：LMS不需要系统模型、靠梯度慢慢调权重；卡尔曼滤波需要已知模型和噪声统计，但每步都给出最优估计和不确定性。

读懂它需要的概念

向量、矩阵与张量 高斯分布 条件概率与贝叶斯公式 期望与方差 协方差矩阵 隐马尔可夫模型 状态、观测与动作

本篇术语

  • 状态空间模型　用一组“状态”变量（如位置、速度）描述系统，并写出状态如何一步步演化、测量如何由状态产生。今天控制、机器人和不少序列模型都用这种写法。
  • 卡尔曼增益K　决定新测量对估计修正多少的权重。预测越不确定、传感器越准，K越大，越相信测量。
  • 过程噪声Q / 测量噪声R　Q描述模型预测本身有多不准（比如路面颠簸），R描述传感器有多不准。两者都要人来给定。
  • 扩展卡尔曼滤波EKF　把非线性模型在当前估计附近做一阶泰勒展开再套用卡尔曼公式，由NASA的Schmidt等人为阿波罗计划发展出来。

怎么学

先补高斯分布、协方差矩阵和条件概率与贝叶斯公式，确认理解两个高斯相乘仍是高斯。然后读Labbe的《Kalman and Bayesian Filters in Python》前几章，从一维例子推到矩阵形式；原论文可以只看引言（Wiener方法的四条缺陷）和第5、6节的模型设定。动手：用NumPy写一个跟踪匀速小车的二维卡尔曼滤波器，改变Q和R，观察估计曲线如何在“跟得紧”与“很平滑”之间变化。
