旋转位置编码RoPE

RoFormer: Enhanced Transformer with Rotary Position Embedding
2021.04论文重要Jianlin Su（苏剑林）, Yu Lu, Shengfeng Pan, Ahmed Murtadha, Bo Wen, Yunfeng Liu · 追一科技待核对
arXiv ↗EleutherAI博客：Rotary Embeddings ↗在交互版中打开（演化树、学习进度）

问题

绝对位置编码加在输入上，不直接表达“两个词相距多远”；相对位置编码要改注意力矩阵、额外加偏置项，实现复杂且与一些高效注意力不兼容。

方法

把查询和键向量的每两维看成一个平面上的点，按词的位置m旋转角度mθ。两个旋转后向量的内积只取决于位置差，于是用“绝对位置的写法”得到了“相对位置的效果”。

影响

实现只需几行、不加参数，被GPT-J、PaLM、LLaMA等几乎所有主流大模型采用；后来的长上下文扩展方法（位置插值、YaRN）也都建立在它上面。

背景

自注意力本身不知道词序（见位置编码）。Transformer的做法是把正弦位置向量加到词向量上；BERT和GPT-2改成可学习的绝对位置向量。两者的共同问题是：注意力分数q·k展开后，位置信息与内容信息搅在一起，模型只能间接推断两个词的相对距离；可学习的位置向量还无法用于比训练时更长的位置。

相对位置表示、T5和DeBERTa解耦注意力改在注意力分数上直接加入相对距离的偏置或嵌入，效果更好，但需要构造一个n×n的相对位置项，代码更复杂，也和Performer核近似注意力这类不显式算n×n矩阵的线性注意力不兼容。作者想要一种方法：像绝对位置一样只作用在每个向量自己身上，却让内积自动只依赖相对位置。

方法

二维情形。设第m个位置的查询向量是二维的q = (q₁, q₂)，把它看成复数q₁ + i·q₂，乘上e^{i·mθ}，相当于在平面上逆时针旋转角度mθ。键向量在位置n同样旋转nθ。两个复数的内积（取实部）是

Re[ q·e^{imθ} · conj(k·e^{inθ}) ] = Re[ q·conj(k)·e^{i(m−n)θ} ]

结果只包含m−n，与m、n各自是多少无关。比如位置3和位置5的一对词，与位置103和位置105的一对词，只要内容相同，注意力分数就相同。

推广到d维。把d维向量两两分组成d/2个平面，第i组用不同的频率θ_i = 10000^(−2i/d)旋转（与原始正弦编码的频率相同）。低维的组转得快，捕捉近距离的细节；高维的组转得慢，能区分很远的距离。实现上不需要真的构造旋转矩阵，只要

RoPE(x, m) = x ⊙ cos(mθ) + rotate_half(x) ⊙ sin(mθ)

其中rotate_half把每对(x₁, x₂)换成(−x₂, x₁)。只对Q和K做，不对V做，不增加任何参数。

性质。论文证明这种频率设置使内积的上界随相对距离增大而衰减（远处的词默认关注少一些）；由于只作用在单个向量上，它也能直接用于线性注意力。

结果

论文本身的实验规模不大：WMT14英德翻译BLEU 27.5，对比原始Transformer-base的27.3；在约34GB中文语料上预训练RoFormer，在长文本法律案例匹配CAIL2019-SCM上，输入截断到512时与基线相当，放宽到1024时测试准确率69.79%，比WoBERT高约1.5个百分点。作者也承认没有从理论上解释为什么它比其他位置编码收敛更快。

它被大量采用主要是因为实践：方法最早在作者的中文博客上发布，EleutherAI在多种规模的模型上复现，得到稳定的收益，并用于GPT-J-6B。

后来的发展

此后的开源与闭源主流大模型几乎都用RoPE：GPT-J-6B、PaLM、LLaMA及其后代。它的旋转形式也让“扩上下文”有了清晰的操作手柄：位置插值扩上下文把位置下标按比例压缩，使长序列的旋转角度落回训练范围；YaRN对不同频率的维度区别对待。同一时期的ALiBi线性偏置位置走了另一条路——不改Q、K，直接给分数加距离惩罚，外推更好但在大模型上不如RoPE普及。

容易误解的地方

  • RoPE并不能自动外推到更长的序列。训练长度之外的位置会产生没见过的旋转角度，困惑度会迅速变差，需要位置插值等方法配合。
  • 它是乘在Q和K上的，不是加在输入词向量上的；V不旋转。

局限与后续

  • 直接用于比训练时更长的序列时效果迅速变差，长度外推能力不足。

它建立在什么之上

  • 改进
    Transformer2017.06 · LLM 已核对
    替代原始Transformer加在输入上的正弦绝对位置编码，使注意力分数直接只依赖相对位置。
  • 竞争
    T52019.10 · LLM
    T5用按距离分桶的可学习标量偏置表示相对位置，RoPE则不需要额外参数。
  • 竞争
    DeBERTa解耦注意力2020.06 · LLM
    DeBERTa把内容和相对位置拆成多项分别算分数；RoPE用旋转把位置融进Q、K本身，计算更省，后来在生成式大模型中胜出。
  • 改进
    相对位置表示2018.03 · LLM
    同样实现相对位置，但不需要构造n×n的相对位置嵌入，实现更简单，也能用于线性注意力。
  • 延续
    Performer核近似注意力2020.09 · LLM
    论文专门说明RoPE可以与Performer式的线性注意力结合，而加性相对位置编码做不到。

读懂它需要的概念

位置编码 自注意力与多头注意力 内积与余弦相似度 矩阵乘法与线性变换

本篇术语

  • 旋转位置编码（RoPE）　按位置把Q、K向量的每对维度旋转一个角度。两个向量各自转过的角度之差就是它们的相对距离，所以内积只依赖相对位置。
  • 长度外推　模型在推理时处理比训练时更长的输入，并保持效果。

怎么学

先复习复数乘法等于旋转、以及位置编码里的正弦编码。读原文第3.2节（式12–16的推导）和图1。最直观的练习：用numpy取两个二维向量，分别按位置(3,5)和(103,105)旋转后算内积，验证结果相同；再在nanoGPT里把可学习位置嵌入换成RoPE。
