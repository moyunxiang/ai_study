岭回归与L2正则

Ridge Regression: Biased Estimation for Nonorthogonal Problems
1970论文延伸Technometrics 1970Arthur Hoerl, Robert Kennard · 特拉华大学 / 杜邦待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

线性回归的特征高度相关时，XᵀX接近奇异，最小二乘解方差极大，系数忽正忽负、对数据微小变化极其敏感。

方法

在最小二乘目标上加一项λ‖w‖²，用一点偏差换取大幅降低的方差。

影响

L2正则成为防止过拟合的标准手段，在神经网络里以权重衰减的形式沿用至今。

方法

岭回归求解的是min ‖y − Xw‖² + λ‖w‖²，闭式解为w = (XᵀX + λI)⁻¹ Xᵀy。给矩阵对角线加上λ，保证它可逆且条件数变好。

这是偏差-方差权衡权衡的经典例子：解不再是无偏的，但方差变小，在样本少或特征相关时测试误差常常更低。λ越大，权重被压得越小；λ=0就是普通最小二乘。从贝叶斯角度看，等价于给权重加了零均值高斯先验（见先验、后验与贝叶斯推断）。λ需要靠交叉验证选。

局限与后续

  • λ要靠人工或交叉验证挑选，且所有特征被同等地压缩，不会把无用特征的系数置零。
