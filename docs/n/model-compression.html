模型压缩（Buciluă等）

Model Compression
2006.08论文延伸KDD 2006Cristian Buciluă, Rich Caruana, Alexandru Niculescu-Mizil · Cornell University待核对
ACM DOI ↗在交互版中打开（演化树、学习进度）

问题

准确率最高的模型往往是几百个模型组成的集成，太大太慢，难以放进手机或实时系统。

方法

用大集成给大量无标签（或合成）数据打标签，再让一个小的神经网络去模仿这些标签。

影响

第一次系统地证明小模型可以通过模仿大模型而获得接近大模型的精度，这就是后来知识蒸馏的起点。

方法

做法分三步：先训练一个强大的集成（如AdaBoost与集成学习或袋装的上百个模型）；再生成很大一批输入样本，因为原训练集太小，作者设计了一种合成数据的方法；最后用集成对这些样本的输出作为标签，训练一个小神经网络回归这些输出。因为教师能为任意多的数据贴标签，小网络可以见到远多于原始训练集的样本，从而学到集成的决策边界。

这篇的贡献是思路：模型的知识可以从「它对很多输入的输出」中提取出来，而不依赖它的内部结构。2015年的知识蒸馏把这个想法推广到用软概率和温度系数。

局限与后续

  • 依赖生成大量合成输入，在图像、文本等高维数据上难以做好。
    后来针对它的工作　知识蒸馏
  • 只让学生拟合教师的最终输出，没有利用教师中间层的表示。
    后来针对它的工作　FitNets中间层蒸馏
