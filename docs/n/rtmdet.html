RTMDet实时检测

RTMDet: An Empirical Study of Designing Real-Time Object Detectors
2022.12论文延伸Chengqi Lyu, Wenwei Zhang, Haian Huang, Yue Zhou, Yudong Wang, Yanyi Liu, Shilong Zhang, Kai Chen · 上海人工智能实验室 / OpenMMLab待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

想要一个超过YOLO系列、又能方便扩展到实例分割和旋转框检测的实时检测器，同时把各种设计选择的影响讲清楚。

方法

用大核逐通道卷积组成的基本块搭建容量匹配的骨干和颈部（CSPNeXt），在动态标签分配的匹配代价里引入软标签，并配合更好的训练技巧。

影响

在3090上以300多FPS达到COCO 52.8% AP，超过主流工业检测器，并在实时实例分割和旋转检测上取得最好结果；后成为RTMPose等工作的基础。

方法

实时检测领域以YOLO系列为主（YOLOX无锚框YOLO、YOLOv6工业检测、YOLOv7），各家改动很多，但哪些设计真正起作用并不总是清楚，而且多数模型只做矩形框检测。

RTMDet是一篇“实证研究”：系统比较各种设计后给出一套配置。结构上，作者认为骨干和颈部的容量应该匹配，两者都由同一种基本块构成——在CSPNet跨阶段局部网络式的结构中使用5×5的大核逐通道卷积，扩大感受野（骨干称为CSPNeXt）。标签分配沿用动态分配（类似SimOTA），但在计算预测框与真值的匹配代价时用软标签（以IoU作为分类目标的软化值），使匹配更准确。再加上更强的数据增强等训练技巧。同一框架只需换检测头，就能做实例分割（RTMDet-Ins）和旋转框检测（RTMDet-R）。

摘要报告RTMDet在COCO上达到52.8% AP，在NVIDIA 3090上300+ FPS，超过当时主流工业检测器；在tiny到extra-large各规模上取得最好的参数-精度权衡，并在实时实例分割和旋转目标检测上刷新纪录。
