GPT-4o原生图像生成

Introducing 4o Image Generation
2025.03模型重要OpenAI待核对
OpenAI发布公告 ↗系统卡附录 ↗在交互版中打开（演化树、学习进度）

问题

DALL·E 3等扩散模型是独立于聊天模型的“外挂”：画不准图中文字，五到八个以上物体就开始混乱，也无法在多轮对话中基于上一张图精确修改。

方法

把图像生成直接做进全模态的GPT-4o内部，作为自回归模型的原生能力，在图文联合分布上训练并大量后训练，让模型用自己的世界知识和对话上下文来画图。

影响

图中文字、复杂指令和多轮编辑首次变得可靠，上线后的“吉卜力风”热潮让ChatGPT用户量暴涨，也让“理解与生成统一”的原生多模态模型成为各家主攻方向。

背景

到2024年，DALL·E 3与重写描述、Midjourney V5、FLUX.1的画质已经很高，但都是专门的扩散模型，语言模型只负责把提示词改写一遍再交给它们。这种分离带来几个问题：模型不真正“懂”自己在画什么，图中文字常常拼错；物体一多，属性就绑错；用户说“把刚才那张图的猫换成狗”，模型只能重新生成，人物和构图都会变。

研究界已经在尝试统一：Chameleon早期融合、Emu3纯下一词预测用同一个自回归Transformer同时生成文本和图像token，Transfusion在一个模型里结合语言建模和扩散。但这些开源模型的画质还远不及专门的扩散模型。2024年5月发布的GPT-4o全模态实时模型号称“全模态”，当时演示过原生出图，但这一能力直到2025年3月才开放。

方法

OpenAI没有公布技术细节，公开信息只有几点：

  • 原生内嵌：系统卡写明，与以扩散模型运作的DALL·E不同，4o图像生成是一个原生嵌入ChatGPT的自回归模型，“深植于全模态GPT-4o的架构之中”。也就是说，图像和文字由同一个模型在同一上下文中产生（见自回归生成）。
  • 训练数据：在网络图像与文本的联合分布上训练，不仅学习图像与语言的关系，也学习图像与图像之间的关系，再配合“激进的”后训练。
  • 能力来源：因为同一个模型既理解对话又生成图像，它可以直接利用语言模型的世界知识、聊天上下文和用户上传的图片（上下文学习），在多轮对话中保持角色和画面一致。

官方展示的重点能力是：准确渲染文字（菜单、海报、信息图）、遵循复杂指令、多轮修改、以上传图片为参考进行变换。

结果

官方称，其他系统处理约5到8个物体就会出错，GPT-4o能处理10到20个不同物体并正确绑定属性和关系。2025年3月25日在ChatGPT中上线，随后以“吉卜力风格”头像为代表的使用热潮爆发，据媒体报道新增用户一度达到一小时一百万。4月23日以gpt-image-1的名义开放API。

后来的发展

它把文生图的竞争焦点从“画得美”转向“画得对、能改”。谷歌在2025年8月推出Gemini 2.5 Flash Image（Gemini 2.5 Flash Image），主打多轮编辑中的角色一致性，随后是Nano Banana Pro；开源方面，BAGEL统一预训练、HunyuanImage 3.0、Qwen-Image等也走向理解生成一体化或强文字渲染。OpenAI后来推出GPT Image 2思考式出图，进一步让模型在出图前先进行推理。

它同时引发了新的争议：大量模仿吉卜力等工作室风格的图片让版权与风格保护问题再次升温；照片级真实感也加剧了伪造风险，系统卡称所有生成图都附带C2PA来源元数据。

容易误解的地方

  • “自回归”只是系统卡的一句描述，OpenAI没有说明图像token如何表示、是否还有扩散解码器等细节，外界的架构推测都不是官方信息。
  • “10到20个物体”是官方宣称，没有公开的评测基准支持。

局限与后续

读懂它需要的概念

自回归生成 分词与token 上下文学习与提示 扩散：前向加噪与反向去噪 人类反馈强化学习

本篇术语

  • 原生图像生成　由同一个多模态大模型直接产生图像，而不是让语言模型调用另一个独立的图像生成模型。
  • C2PA　一种内容来源与真实性的行业标准，把“由谁、用什么工具生成”的信息以可验证的元数据附在文件里。

怎么学

先读DALL·E 3与重写描述了解“外挂式”文生图的局限，再读Chameleon早期融合和Transfusion理解统一模型的两种做法。阅读官方公告中的示例（文字渲染、多轮编辑），对照系统卡附录了解其风险评估。动手：用开源的BAGEL统一预训练或Janus-Pro做多轮图像编辑，体会原生多模态模型和扩散模型在一致性上的差别。
