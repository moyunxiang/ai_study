NumPy与SciPy

Array programming with NumPy

arXiv（Array programming with NumPy） ↗SciPy 1.0论文（Nature Methods 2020） ↗NumPy官方入门 ↗在交互版中打开（演化树、学习进度）

问题

Python写起来快但做数值计算极慢：每个数都是独立对象，逐元素循环要解释执行；而MATLAB是闭源商业软件，Python社区的两个数组库Numeric和Numarray又互不兼容。

方法

提供一个统一的多维数组类型ndarray：数据是一整块连续内存，所有运算以“整个数组”为单位交给C循环或BLAS执行，配合广播规则和视图，让Python代码像写数学公式一样操作矩阵。

影响

成为Python科学计算的公共底座；scikit-learn、pandas、Theano、PyTorch、JAX的数组接口都照着它设计，“NumPy式API”成了数组库事实上的标准。

背景

1990年代到2000年代初，做数值计算的研究者多用MATLAB或Fortran/C。Python语法友好、库多，但原生的列表里每个元素都是带类型信息的独立对象，for循环每一步都要解释执行，算一百万个数的加法要比C慢上很多。

1995年起Python社区出现了数组库Numeric，后来又有面向大数组的Numarray，两者接口不兼容，社区分裂；建在它们上面的科学计算库SciPy（2001年首次发布）也左右为难。2005年Travis Oliphant把Numarray的特性并入Numeric、大幅重写，形成NumPy，2006年发布1.0，统一了这个局面。

方法

NumPy的核心是ndarray：一块连续的原始内存，加上描述如何解读它的元数据——元素类型（dtype，如float32）、形状（shape）和步长（strides，沿每个维度走一步要跳过多少字节）。

  • 向量化：c = a + b不是Python循环，而是一次调用编译好的C循环；矩阵乘法a @ b进一步交给BLAS线性代数接口，线性代数交给LAPACK。
  • 视图而非复制：一个3×4的float64数组步长是(32, 8)字节；转置只需把步长改成(8, 32)，切片a[:, ::2]只改起点和步长，都不复制数据。
  • 广播：形状不同的数组按规则自动对齐——从最后一维往前比，长度相等或其中一个为1即可。形状(3, 1)加(1, 4)得到(3, 4)，就像把列向量和行向量各自复制展开，但实际并不分配那份内存。例如对一批数据减去每列均值：X - X.mean(axis=0)。
  • C接口：其他库可以直接拿到ndarray的内存指针，在C/Fortran里处理后交还，不必复制。

SciPy建在NumPy之上，提供优化、积分、插值、稀疏矩阵、信号处理、统计等算法。

结果

据SciPy 1.0论文，SciPy自2001年发布以来有600多位代码贡献者、超过10万个依赖它的代码仓库；NumPy论文举例说，它是引力波探测和第一张黑洞照片背后软件栈的一部分。

后来的发展

NumPy成了Python数据科学栈的最底层：scikit-learn的输入输出都是ndarray，IPython / Jupyter Notebook让人能交互地操作它；Theano与自动微分把NumPy式表达式编译到GPU，autograd：给NumPy求导直接给NumPy代码求导，它的作者随后做了JAX（jax.numpy几乎照搬NumPy接口）；PyTorch的Tensor在接口上也大量模仿NumPy。2020年的论文指出，NumPy越来越多地扮演这些新数组库之间“互操作层”的角色。

容易误解的地方

  • 向量化快是因为循环挪到了C里；如果在NumPy数组上写Python for循环逐元素访问，速度并不比原生列表好多少。
  • 切片返回视图，修改切片会改动原数组；需要独立副本时要显式copy()。
  • a * b是逐元素乘，矩阵乘法要用a @ b。

局限与后续

读懂它需要的概念

向量、矩阵与张量 矩阵乘法与线性变换 时间与空间复杂度 显存、内存带宽与“内存墙” CPU、GPU与并行计算

本篇术语

  • 向量化　把对每个元素的循环写成对整个数组的一次运算，让循环在编译好的底层代码里执行。
  • 广播（broadcasting）　形状不同的数组做运算时，按规则把长度为1的维度虚拟扩展成对方的长度，不实际复制数据。
  • 步长（strides）　沿数组每个维度前进一个元素时，在内存里要跳过的字节数。改变步长就能得到转置、切片等视图。

怎么学

跟着官方入门文档过一遍创建数组、切片、广播。动手：用纯Python列表和NumPy分别实现两个100万元素数组的加法并计时；再不用任何循环，只用广播写出一批点之间的两两距离矩阵。最后打印一个数组及其转置的.strides，理解视图。
