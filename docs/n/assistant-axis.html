助手轴

The Assistant Axis: Situating and Stabilizing the Default Persona of Language Models
2026.01论文延伸Christina Lu, Jack Gallagher, Jonathan Michala, Kyle Fish, Jack Lindsey · MATS / Anthropic待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模型能扮演各种角色，但默认停在“乐于助人的助手”上；长对话中它有时会滑向有害或怪异的角色，原因和防法不明。

方法

提取大量角色原型的激活方向，发现人格空间的第一主成分就是“助手轴”，沿它测量漂移，并把激活限制在正常范围内。

影响

给“人格漂移”提供了可测的内部指标，并用简单的激活封顶减少了人格类越狱和有害回答。

方法

作者让Gemma、Qwen 3 32B、Llama 3.3 70B等模型扮演大量不同角色，提取对应的激活方向，对这个人格空间做主成分分析。第一主成分在多个模型上都对应“模型有多像默认助手”，即助手轴。朝助手方向引导会强化有益、无害的行为；反方向引导会让模型自认是别的实体，极端时出现神秘、戏剧化的说话风格。基座模型里也有这条轴，偏向顾问、教练这类助人的人类原型。

沿助手轴的偏离能预测“人格漂移”：模型突然做出与平时人格不符的有害或怪异行为，常由要求模型反思自身过程的对话，或情绪脆弱的用户引发。对策是激活封顶：当沿轴的激活超出正常范围时把它夹回去。在Qwen 3 32B和Llama 3.3 70B上，这能在不损失能力的前提下把有害回答率降低近60%，也能抵御基于人格扮演的越狱。

局限与后续

  • 后训练只是把模型松松地拴在助手区域，封顶是推理时的补丁，没有从训练上把人格锚定住。
    本站还没有记录针对它的后续工作（不代表没有人解决）
