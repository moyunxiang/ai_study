Operator与浏览器智能体

Introducing Operator
2025.01系统延伸官方公告 2025-01-23OpenAI · OpenAI待核对
OpenAI公告（存档） ↗在交互版中打开（演化树、学习进度）

问题

大多数网站没有API，让AI替人办事就得像人一样看屏幕、点鼠标，而此前这类能力只是研究演示。

方法

OpenAI推出Operator：由CUA模型驱动，用自己的浏览器看页面、点击、输入、滚动，替用户完成网页任务。

影响

第一个面向普通用户的浏览器智能体产品，半年后并入ChatGPT的agent模式。

方法

Operator于2025年1月23日作为研究预览发布，面向美国的Pro用户。它由Computer-Using Agent（CUA）驱动：官方称CUA把GPT-4o的视觉能力与通过强化学习得到的推理结合起来，被训练去操作图形界面（按钮、菜单、文本框）。Operator通过截图「看」，用鼠标键盘的各种动作「操作」浏览器，不需要为每个网站做API对接；遇到困难或犯错时它会自己纠错或请用户接管。

官方在WebArena和WebVoyager两个浏览器基准上给出了评测结果（具体数字未在此核对）。2025年7月17日官方更新：Operator已并入ChatGPT，成为「agent模式」，独立的Operator网站随后下线（ChatGPT agent）。

后来的发展

Operator与Anthropic的Computer Use、谷歌的Project Mariner构成第一批商业化的电脑使用智能体，使「让AI替你用网站」成为主流产品形态。

局限与后续

  • 研究预览阶段能力有限，购物、付款等敏感操作需要用户确认。
    后来针对它的工作　ChatGPT agent
  • 在复杂的真实网站上成功率仍明显低于人，且慢。
    后来针对它的工作　OSWorld-Verified

后来的相关工作

  • 使用
    Responses API与Agents SDK2025.03 · 推理·智能体
    API中的电脑操作工具就是Operator背后的CUA模型，首次开放给开发者。
  • 延续
    ChatGPT agent2025.07 · 推理·智能体
    继承Operator的图形界面操作能力（CUA），并补上分析和长文写作，发布后Operator被下线。
  • 延续
    AI浏览器Comet与Atlas2025.07 · 推理·智能体

  • 改进
