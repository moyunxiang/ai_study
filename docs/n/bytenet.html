ByteNet卷积翻译

Neural Machine Translation in Linear Time
2016.10论文延伸arXiv 2016Kalchbrenner, Espeholt, Simonyan, van den Oord, Graves, Kavukcuoglu · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

RNN式Seq2Seq翻译训练和解码都要按词顺序，耗时随句长增长，且很难并行。

方法

全卷积的编码器-解码器：解码器叠在编码器上并保持时间分辨率，用膨胀卷积扩大感受野，计算时间随序列长度线性增长。

影响

证明纯卷积也能做翻译，为后续卷积Seq2Seq和Transformer的非循环路线提供了先例。

方法

ByteNet由两个一维卷积网络叠成：编码器读源序列，解码器是因果（只看已生成部分）的卷积网络，叠在编码器输出之上；源与目标长度不同时，解码器按源长度动态展开，并保持时间分辨率不变。借鉴WaveNet，层与层之间用膨胀（dilated）卷积，感受野随层数指数增长，所以长距离依赖不必逐步传递。输入输出直接用字符，因此不用分词。

摘要称其计算时间与序列长度线性相关，并称在字符级语言建模上取得最佳，在WMT英德字符到字符翻译上超过基于循环网络加注意力、计算量随长度平方增长的同类模型。

局限与后续

  • 字符级输入使序列很长，且精度未超过同期的词/子词注意力模型。
