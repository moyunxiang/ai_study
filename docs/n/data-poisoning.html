数据投毒攻击

Poisoning Attacks against Support Vector Machines
2012.06论文延伸ICML 2012Battista Biggio, Blaine Nelson, Pavel Laskov · 卡利亚里大学 / 图宾根大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

机器学习默认训练数据来自自然、无恶意的分布；在安全场景里攻击者可以往训练集里塞样本，没有人量化过这会把模型害到什么程度。

方法

针对支持向量机设计投毒攻击：用梯度上升找到一个注入点，使训练后的SVM在验证集上误差最大；并通过SVM最优解的性质算出梯度，可用于核SVM。

影响

确立了「训练时投毒」这一类攻击，后来的BadNets后门攻击后门和网络规模数据投毒沿着这条线发展。

方法

论文的威胁模型是：攻击者能向训练集里加入少量精心构造的点。作者的做法是把攻击当作一个优化问题：选一个攻击点x_c，使重新训练后的SVM在验证数据上的损失最大。

难点是SVM的解依赖训练数据，攻击点对解的影响需要微分。他们利用SVM最优解满足的KKT条件，推导出解随攻击点变化的方向，进而得到损失对攻击点的梯度，然后做梯度上升，不断移动攻击点。这套推导可以核化，所以即使是非线性核，攻击点也可以在输入空间里构造。

实验表明，一个精心放置的点就能显著提高SVM的测试误差（摘要称「increases the SVM's test error」，具体数字未在摘要中给出，此处不写）。要点在于：攻击者对学习算法的内部有一定了解（白盒假设）。

局限与后续

  • 攻击需要知道学习算法和训练数据的一部分，且推导依赖SVM的特殊结构，难以直接用于深度网络。
