无归一化Transformer DyT

Transformers without Normalization
2025.03论文延伸CVPR 2025Jiachen Zhu, Xinlei Chen, Kaiming He, Yann LeCun, Zhuang Liu · Meta FAIR / NYU / MIT / Princeton待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

归一化层（Layer Normalization等）在现代网络中被视为必不可少，但它们需要统计量计算，带来额外开销。

方法

用逐元素的tanh(αx)（Dynamic Tanh，DyT）直接替换Transformer里的归一化层。

影响

表明Transformer不一定需要归一化，为简化架构提供了新的选择。

方法

作者观察到Transformer里LayerNorm的输入输出映射常常呈类似tanh的S形曲线：中间近似线性，极端值被压缩。于是提出DyT：DyT(x) = tanh(αx)，其中α是可学习的标量，不需要计算均值与方差。

摘要称，把DyT作为归一化层的替代放进Transformer，效果能匹配或超过带归一化的版本，且多数情况不用调超参，覆盖识别到生成、监督到自监督、视觉到语言模型等多种设置。这对“归一化层不可或缺”的传统观点提出了挑战。

局限与后续

  • 主要在Transformer上验证，对BatchNorm为主的卷积网络和更大规模语言模型的结果有限。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 对α的初始化有一定敏感性，LLM里需要额外调整。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    Batch Normalization2015.02 · 基础 待核对
    同批样本互相耦合，多卡训练要同步统计量，也给推理和对比学习等场景带来额外麻烦。
  • 改进
    Layer Normalization2016.07 · 基础 待核对
    LayerNorm需要统计均值与方差；DyT用逐元素tanh取而代之，保留其压缩极端值的作用。
  • 延续
    Transformer2017.06 · LLM
    简化Transformer的子层，去掉归一化层。
  • 改进
    RMSNorm2019.10 · 基础
    每层仍要对每个token做一次求和归约，算子受内存带宽限制；部分RMSNorm的理论加速在实测中没有兑现。
  • 改进
    Pre-LN Transformer2020.02 · LLM
    每个子层前都要做一次归一化，增加计算和访存，归一化本身是否必要没有讨论。
  • 改进
    BN为何有效之争2018.05 · 基础
    论文只给出平滑性的实证与部分理论，并未完整解释为何平滑性带来泛化提升，也未说明Layer Normalization等其他归一化是否同理。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

怎么学

先复习Layer Normalization和归一化层；读原文第3节的观察与第4节的DyT定义；把一个小ViT或GPT里的LayerNorm换成DyT并比较训练曲线。
