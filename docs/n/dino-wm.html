DINO-WM

DINO-WM: World Models on Pre-trained Visual Features enable Zero-shot Planning
2024.11论文延伸Gaoyue Zhou, Hengkai Pan, Yann LeCun, Lerrel Pinto · NYU、Meta待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

世界模型多数针对单个任务、依赖在线策略学习，或要重建像素，既昂贵又难以用于零样本规划。

方法

在预训练的DINOv2图像块特征空间里预测未来特征，而不重建画面，再通过对动作序列做优化来规划到达目标。

影响

展示了无需奖励和专家演示、仅靠离线数据训练的世界模型，也能在多个环境中零样本规划，并启发了基于JEPA思想的世界模型。

方法

DINO-WM（DINO World Model）的做法是：用冻结的DINOv2提取图像的空间块特征，然后学习一个模型，输入当前特征和动作，预测下一步的块特征，而不去生成像素（避免了重建带来的开销）。因为不重建画面，它可以直接用离线收集的行为轨迹训练，无需奖励、专家演示或在线交互。

规划时把目标图像也编码成目标特征，然后用模型预测控制MPC式的方法，优化动作序列使模型预测的终态特征接近目标特征。论文称在六个环境中实现了零样本的行为求解，覆盖导航、操作等任务，并且比此前的世界模型方法更好。

局限与后续

  • 需要在动作序列上做迭代优化，规划速度较慢，且特征空间预测依赖冻结编码器的质量。
    后来针对它的工作　V-JEPA 2
  • 环境主要是简单仿真，复杂真实场景的验证有限。
    后来针对它的工作　LeJEPA V-JEPA 2
