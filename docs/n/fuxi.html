伏羲天气

FuXi: A cascade machine learning forecasting system for 15-day global weather forecast
2023.06论文延伸arXiv 2023Chen, Zhong, Zhang, Cheng, Xu, Qi, Li · 复旦大学 / 上海人工智能实验室 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

盘古天气等AI天气模型在10天内已超过ECMWF的高分辨率预报，但自回归逐步外推时误差不断累积，15天预报赶不上集合平均。

方法

把预报分成短、中、长三段，各自单独训练一个模型再级联，使每个模型只负责自己擅长的预报时效。

影响

成为第一个在15天全球预报上达到ECMWF集合平均水平的机器学习系统，说明级联能缓解长时效误差累积。

方法

背景：此前的AI天气模型（FourCastNet、盘古天气、GraphCast与AI天气预报）都是把6小时预报反复喂回模型自身来外推，每一步的小误差会越滚越大，短时效最优的模型到了第10到15天并不最优。论文指出，用单个模型同时兼顾短和长时效是不够的。

FuXi的做法：用欧洲中期天气预报中心（ECMWF）的ERA5再分析资料中39年的数据训练，输出分辨率0.25度、时间间隔6小时的全球预报，共15天。为减少误差累积，模型按预报时效分成几段，每段使用针对该时效微调的模型，前一段的输出作为后一段的起点，这就是“级联”。模型把全球多层气象变量当作一张多通道的“图像”来处理，用自注意力与多头注意力类结构学习变量之间的关系。

局限与后续

  • 相邻级联段之间的衔接仍会引入误差，且预报是确定性的，不给出不确定性。

  • 训练和评测都依赖ERA5再分析资料，真实业务中的初值误差没有被充分检验。
    后来针对它的工作　ECMWF AIFS业务化

读懂它需要的概念

自注意力与多头注意力 自回归生成 泛化与过拟合 基准、排行榜与SOTA

怎么学

先理解自回归外推为什么会累积误差；读论文的方法部分看三段模型如何划分和衔接；用WeatherBench 2比较各模型在不同预报时效的RMSE曲线。
