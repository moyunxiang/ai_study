LLM.int8()与离群特征

LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale
2022.08论文重要NeurIPS 2022Tim Dettmers, Mike Lewis, Younes Belkada, Luke Zettlemoyer · 华盛顿大学 / Meta AI / Hugging Face待核对
arXiv ↗bitsandbytes ↗Hugging Face博客：8-bit矩阵乘 ↗在交互版中打开（演化树、学习进度）

问题

1750亿参数的模型用16位存储要350GB显存；把权重直接压到8位整数，在小模型上可行，但模型一过约67亿参数，准确率就突然崩溃，原因不明。

方法

找到原因：大模型的隐藏状态里出现少数数值巨大的“离群特征”维度。把这几个维度留在16位计算，其余99.9%以上的数值用8位整数乘，就能做到零精度损失。

影响

第一次让175B级别的模型以8位加载而不掉点，显存减半；集成进Hugging Face后，用一个参数就能8位加载大模型，也为后来的4比特量化和QLoRA打下基础。

背景

量化的基本做法是：把一个张量按它的最大绝对值缩放到[−127, 127]，四舍五入存成INT8（absmax量化），计算时再乘回缩放系数。这样权重显存减半，在几亿参数的BERT上效果很好（剪枝与量化压缩等更早的工作已在CNN上压缩过权重）。

但放到OPT-175B、BLOOM这类开放的大模型上，当时最好的8位方法在参数量达到约6.7B时准确率突然大幅下滑。显存问题又恰恰在大模型上最迫切：175B模型的16位权重就要350GB，要好几张80GB的A100才放得下。

方法

第一步：向量级量化。不是整个矩阵共用一个缩放系数，而是矩阵乘X·W中X的每一行、W的每一列各有自己的系数，结果再用两者的外积还原。论文表明，仅靠这一步可以在2.7B以内的模型上保持精度。

第二步：发现离群特征。作者分析隐藏状态后发现，模型变大后，某几个固定的特征维度会出现幅度极大的值（比其他维度大3到20倍，而其余维度通常在[−3.5, 3.5]之间）。在约6.7B处出现“相变”：所有层、约75%的token位置都受到影响；6.7B模型每个序列有约15万个离群值，却只集中在全模型的6个特征维度上。用absmax量化时，这几个大数把缩放系数撑得很大，其余正常数值都被压成0附近的几个整数，精度就毁了。

第三步：混合精度分解。把输入X中任何值的绝对值超过阈值α = 6的那几列（以及W对应的行）挑出来，用FP16做矩阵乘；其余部分用向量级INT8乘，两部分结果相加。被留在16位的只是极少数维度，超过99.9%的乘法仍在8位进行。

结果

在125M到175B的OPT系列上，LLM.int8()的C4困惑度和零样本准确率与16位基线一致，而此前的8位方法在6.7B以上明显退化。显存减半后，OPT-175B或BLOOM-176B可以放进一台配消费级GPU的服务器。速度方面，论文坦言主要收益是省显存：对6.7B以下的模型，量化和分解的开销会让推理变慢；对175B规模的大矩阵乘，INT8约快一倍。

后来的发展

方法通过bitsandbytes库集成进Hugging Face Transformers，加载时加一个参数即可8位运行，开源社区第一次能在少量GPU上跑百亿级模型。离群特征的发现影响更大：SmoothQuant把激活中的离群值“迁移”到权重上，让权重和激活都能用INT8并真正提速；GPTQ训练后量化、AWQ激活感知量化把权重压到4位；同一作者的QLoRA用4位基座加LoRA实现单卡微调65B模型。

容易误解的地方

  • LLM.int8()主要省显存，不是加速方法；小模型上它比FP16还慢。
  • 离群值出现在激活（隐藏状态）的特定维度上，而不是权重里，所以无法在离线压缩权重时一劳永逸地处理掉。
  • 论文说的“相变”在按参数量画图时很陡，但按困惑度画图时是渐进的指数变化。

局限与后续

  • 混合精度分解有额外开销，6.7B以下的模型推理比FP16还慢，没有真正利用INT8的计算吞吐。

读懂它需要的概念

量化 浮点精度：FP32、FP16、BF16、INT8 矩阵乘法与线性变换 Transformer层的结构 参数量、计算量与显存

本篇术语

  • 离群特征（outlier features）　隐藏状态中少数几个固定维度上数值远大于其他维度的现象，在大模型的几乎所有层和大多数token上同时出现。
  • absmax量化　用张量的最大绝对值做缩放，把数值线性映射到[−127, 127]再取整。一个异常大的数就会让其余数的精度变差。
  • 混合精度分解　把矩阵乘拆成两部分：含离群值的少数维度用16位算，其余用8位算，最后相加。

怎么学

先弄清浮点精度：FP32、FP16、BF16、INT8和量化里absmax量化的计算。然后读论文第3节（向量级量化与混合精度分解）和第4节（离群特征的分析，看图3、图4）。动手：在NumPy里构造一个有一列特别大的矩阵，比较整体absmax量化、逐行量化、把大列单独留在浮点三种方案的矩阵乘误差；再用transformers的8位加载跑一个OPT模型对比显存。
