问题

聊天助手的记忆只是被动保存零散事实，越攒越杂，也不会主动归纳，无法真正理解用户的长期偏好。

方法

仿照睡眠中整理记忆的过程，在后台定期回顾和整理对话，提炼更稳定、更有用的记忆。

影响

把记忆从“记录”推进到“整理”，也让这项功能扩展到更多用户。
