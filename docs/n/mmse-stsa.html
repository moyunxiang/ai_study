MMSE谱幅度估计降噪

Speech enhancement using a minimum-mean square error short-time spectral amplitude estimator
1984.12论文延伸IEEE TASSP 1984Yariv Ephraim, David Malah · 以色列理工学院待核对
IEEE ↗对数谱版 (1985) ↗在交互版中打开（演化树、学习进度）

问题

谱减法从带噪频谱里直接减去估计的噪声，结果常出现负值和随机的残留尖峰，听起来像断断续续的「音乐噪声」。

方法

把降噪当成统计估计问题：假设语音和噪声的频谱分量都是高斯随机变量，推导出在最小均方误差意义下最优的频谱幅度估计，增益由「先验信噪比」平滑决定。

影响

Ephraim-Malah估计器及其配套的「决策导向」先验信噪比估计成为经典统计降噪的标准方法，手机通话、助听器里的传统降噪模块大多建立在它和它的对数谱版本之上。

方法

谱减法语音降噪的思路很直接：在每个频点上，用带噪语音的功率减去估计的噪声功率。但噪声功率只是平均值，具体某一帧可能偏大或偏小，减完后会留下随机分布的孤立峰，形成刺耳的音乐噪声。

Ephraim和Malah把每一帧短时傅里叶变换（见傅里叶变换与频域）的每个频点看作：带噪观测Y = 语音S + 噪声N，假设S和N的复数分量都服从零均值高斯分布分布且相互独立。在这个模型下，他们推导出使 E[(|S| − |Ŝ|)²] 最小的幅度估计 |Ŝ| = G·|Y|，增益G是两个量的函数：后验信噪比（当前帧带噪功率与噪声功率之比）和先验信噪比（干净语音功率与噪声功率之比）。先验信噪比无法直接观测，他们提出决策导向估计：用上一帧已增强的语音功率和当前帧的后验信噪比加权平均。这种平滑让增益不会逐帧剧烈跳变，从而大大减少了音乐噪声。相位直接沿用带噪语音的相位。

1985年他们又给出最小化对数谱误差的版本（log-MMSE），更符合人耳对响度的对数感知。这一系列方法一直是统计降噪的基线，深度学习降噪（如RNNoise实时降噪、DCCRN复数网络降噪）的论文常用它作对比。

  • 音乐噪声　降噪后在时频图上随机出现的孤立残留峰，听起来像细碎的音调声，比原来的噪声更刺耳。
