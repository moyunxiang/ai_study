Introducing Aardvark: OpenAI’s agentic security researcher
2025.10系统延伸OpenAI待核对
OpenAI官方（HN收录） ↗The Hacker News报道 ↗在交互版中打开（演化树、学习进度）

问题

安全团队被海量代码和不断出现的漏洞淹没，传统扫描工具只能匹配已知模式，难以判断一个缺陷是否真能被利用。

方法

用GPT-5驱动一个代码安全智能体：建威胁模型、盯提交、在沙箱里验证可利用性，再用Codex生成补丁供人审阅。

影响

展示了智能体可以承担“发现、验证、修复”的完整安全研究流程，是AI用于防御安全的一个官方样板。

方法

OpenAI在2025年10月30日宣布Aardvark，称为“智能体式安全研究员”，当时为私测。据The Hacker News报道，它由GPT-5驱动，持续分析源代码仓库，找漏洞、评估可利用性、排序严重程度并提出补丁。流程是：先分析整个项目，生成它认为最能代表项目安全目标与设计的威胁模型；再扫描历史找已有问题，并检查新的提交；发现疑似缺陷后，在隔离沙箱里尝试触发以确认可被利用；最后用云端异步编码智能体里的Codex生成补丁，交由人审核。

私测阶段意味着没有公开的独立评测数字；报道中官方在基准仓库上的检出率等数字我没有逐项核实，故不引用。

局限与后续

  • 私测阶段缺少独立评测，误报率和对未知漏洞的真实发现能力不明。
