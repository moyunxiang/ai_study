Arcade学习环境ALE

The Arcade Learning Environment: An Evaluation Platform for General Agents
2012.07数据集重要JAIR 2013Bellemare, Naddaf, Veness, Bowling · 阿尔伯塔大学待核对
arXiv ↗JAIR ↗ALE代码 ↗在交互版中打开（演化树、学习进度）

问题

强化学习论文各自在自己设计的小任务上做实验，算法往往为某个任务手工调特征，没有一个统一、多样又公开的平台来衡量“通用”智能体。

方法

把Atari 2600模拟器包装成标准接口：同一个智能体只看屏幕像素和分数、用同一组18个摇杆动作，在几十款风格迥异的游戏上评测，并配上分数归一化方法。

影响

成为深度强化学习十年的主战场：DQN、DQN（Nature版）、Rainbow、Agent57、MuZero都以它为主要成绩单。

背景

2012年前后，强化学习的实验大多在网格世界、倒立摆、山地车这类玩具任务上做，每篇论文用自己的环境、自己的特征和评测方式，数字之间无法比较。更深的问题是：算法常常靠研究者为单个任务手工设计特征才能工作，看不出它有多“通用”。计算机视觉已经有了ImageNet这样的公共基准，强化学习还没有。

方法

ALE基于开源的Atari 2600模拟器Stella。这台1977年的游戏机屏幕是160×210像素、128色，内存只有128字节，手柄组合出18个离散动作。ALE把每款游戏都变成同一个接口：每一帧给智能体屏幕图像（或内存内容），智能体选一个动作，环境返回分数变化作为奖励（见奖励、回报与折扣），游戏结束即一个回合结束。模拟器实时是每秒60帧，满速可达每秒约6000帧，足够做大量试错。

作者还给出一套评测方法：先在5款“训练游戏”上调参，再在随机挑出的50款“测试游戏”上原样运行，防止针对性调参；由于各游戏分数量级差别巨大，提出了几种归一化方式（相对随机策略、相对一组简单基线策略的分数区间），再取平均值或中位数汇总。

结果

论文在55款游戏上跑了两类基线：一类是线性函数近似的SARSA（λ），配5种手工特征（Basic、BASS、DISCO、LSH和直接读内存）；另一类是能读取模拟器状态反复试演的规划方法，包括宽度优先搜索和蒙特卡洛树搜索UCT（UCT）。学习型智能体在55款中的40款上超过简单基线，其中BASS特征整体最好；可以“作弊”式试演的搜索方法则在49款上胜过所有学习方法，例如Asterix上UCT得290700分，最好的学习方法只有987分。搜索也没赢的4款是Freeway、Private Eye、Montezuma's Revenge和Venture，都是奖励稀疏、需要长远规划的游戏。

后来的发展

一年后DQN用一个卷积网络直接从ALE像素学习，DQN（Nature版）扩展到49款游戏，“人类归一化分数”从此成为标准指标。OpenAI Gym把ALE收进统一的Python接口，之后的值函数路线几乎全部在它上面比较。论文点名的Montezuma's Revenge成了探索问题的代名词，催生了随机网络蒸馏RND、Go-Explore等工作。后来研究者又在它上面发展出小数据量版本（SimPLe与Atari 100k的Atari 100k）和更严格的统计评测（统计悬崖边的深度RL评测）。

容易误解的地方

  • ALE本身是确定性的：同样的动作序列总得到同样的结果，智能体可能只是背下一条通关路线，而不是学会了应对。后来的版本加入了“粘滞动作”（随机重复上一个动作）来注入随机性。
  • 论文里的搜索方法能直接复制模拟器状态做试演，这在真实世界不可能，不能与只看像素的学习方法直接比较。

局限与后续

  • 环境完全确定，开局固定，智能体可以记住一条动作序列而不必真正理解画面，评测高估了泛化能力。

读懂它需要的概念

马尔可夫决策过程 奖励、回报与折扣 状态、观测与动作 探索与利用 基准、排行榜与SOTA

本篇术语

  • 归一化分数　把每款游戏的原始分数换算到可比较的尺度，例如（智能体分−随机策略分）/（参照分−随机策略分），这样才能对几十款游戏取平均。
  • 稀疏奖励　绝大多数时刻奖励都是0，只有完成一长串正确动作后才得分；随机乱按几乎永远拿不到第一个奖励。

怎么学

先补马尔可夫决策过程和奖励、回报与折扣。读论文第2节（平台设计）和第4节（评测方法）。然后装上gymnasium和ale-py，用随机策略玩几款游戏，打印观测的形状和每步奖励，体会为什么Montezuma's Revenge难。
