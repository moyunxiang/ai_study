torchvision视觉库

2017.01系统延伸PyTorch团队（Meta）及社区待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

做视觉实验时，每个人都要自己写数据集读取、图像增强和标准模型（ResNet、VGG等），实现细节不一，结果难以复现和比较。

方法

作为PyTorch的官方视觉配套库，统一提供常用数据集的加载器、图像变换（数据增强）流水线，以及带预训练权重的标准模型和视觉算子。

影响

几乎所有基于PyTorch的视觉教程和论文代码都依赖它；torchvision.models.resnet50(weights=...) 一类调用成了加载预训练骨干网络的标准写法。

方法

torchvision的GitHub仓库创建于2016年11月，与PyTorch同期出现，描述是“计算机视觉专用的数据集、变换和模型”。主要模块：datasets——MNIST、CIFAR、ImageNet、COCO、VOC等数据集的统一读取接口，配合PyTorch的DataLoader使用；transforms——裁剪、翻转、缩放、颜色抖动、归一化以及AutoAugment、RandAugment等增强，新版v2接口可同时变换图像、边界框和掩码；models——分类（AlexNet、VGG、ResNet、MobileNet、EfficientNet、ViT等）、检测（Faster R-CNN、RetinaNet等）、分割和视频模型，附带ImageNet等数据上的预训练权重；ops——非极大值抑制、RoIAlign、可变形卷积等检测常用算子的高效实现；io——图像与视频的编解码。

它的API设计影响了后来的torchaudio、torchtext等领域库，也与timm视觉模型库等第三方模型库互补。

局限与后续

  • 模型库更新较慢，最新的骨干网络与训练配方往往先出现在timm等第三方库中。

怎么学

先了解PyTorch的Dataset与DataLoader；读torchvision文档的transforms与models页面；动手加载ImageNet预训练的ResNet-50，在一个小数据集上微调。
