GPT-Neo

GPT-Neo: Large Scale Autoregressive Language Modeling with Mesh-Tensorflow
2021.03模型延伸开源发布 2021Sid Black, Leo Gao, Phil Wang, Connor Leahy, Stella Biderman · EleutherAI待核对
GitHub ↗Zenodo引用 ↗Hugging Face ↗在交互版中打开（演化树、学习进度）

问题

GPT-3只通过付费API提供，权重不公开，研究者没有一个可以下载、微调和拆开研究的GPT-3式模型。

方法

EleutherAI用Mesh-TensorFlow在TPU上实现GPT-3式解码器，在自建的The Pile语料上训练，公开1.3B和2.7B两个尺寸的权重。

影响

社区复现GPT-3路线的起点：仓库自测中2.7B版在LAMBADA上超过GPT-2 1.5B约11个百分点，随后的GPT-J-6B与GPT-NeoX-20B沿同一路线继续放大。

方法

GPT-Neo既是一个代码库，也是用它训练出的一组模型。代码库基于Mesh-TensorFlow张量切分实现模型并行与数据并行，目标是训练GPT-3式的自回归解码器（见自回归生成），官方支持TPU，并提供局部注意力、线性注意力、混合专家、轴向位置嵌入等可选组件。

2021年3月21日，EleutherAI发布两个在The Pile与开放预训练语料上训练的预训练模型，参数量为13亿和27亿，推荐通过Hugging Face Transformers直接加载。

仓库给出的评测：GPT-Neo 2.7B在LAMBADA上准确率62.22%、困惑度5.626，GPT-2 1.5B为51.21%、10.634，GPT-3 Ada为51.60%；Wikitext困惑度11.39，GPT-2 1.5B为17.48。仓库自己注明，部分GPT-2、GPT-3的数字与原论文报告的不一致。

2021年8月起这个代码库不再维护，面向GPU的工作转到GPT-NeoX-20B仓库。
