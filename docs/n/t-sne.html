t-SNE

Visualizing Data using t-SNE
2008.11论文延伸JMLR 2008Laurens van der Maaten, Geoffrey Hinton · Tilburg University / University of Toronto待核对
JMLR ↗Distill: How to Use t-SNE Effectively ↗在交互版中打开（演化树、学习进度）

问题

把高维数据压到二维观察时，流形学习Isomap/LLE类方法常把点挤成一团，看不出多个类簇的结构。

方法

在高维中用高斯衡量点对相似度，在低维中改用重尾的t分布，然后让两边的相似度分布尽量一致，重尾使得簇与簇之间能拉开距离。

影响

成为最常用的高维数据可视化方法，看词向量、图像特征、神经元激活时几乎人人都用，也带来大量对其图的误读。

方法

它是Stochastic Neighbor Embedding（SNE）的改进。

第一步，在高维空间对每个点i，用高斯核给其他点分配被选为邻居的概率p(j|i)，高斯的宽度由“困惑度”（有效邻居数）这一超参数决定，再对称化为pᵢⱼ。第二步，在低维（二维或三维）为每个点随机放一个位置，用自由度为1的t分布计算低维相似度qᵢⱼ ∝ (1 + ‖yᵢ − yⱼ‖²)⁻¹。第三步，最小化两个分布间的KL散度（见KL散度）KL(P‖Q)，用梯度下降移动低维点。

两个关键设计：低维用重尾的t分布，使中等距离的点之间的“排斥”比高斯强，缓解了“拥挤问题”（高维里很多近邻在低维放不下，被挤到中心）；对称化的相似度也使优化更容易。摘要称它比已有方法更能同时展示多个尺度上的结构。

局限与后续

  • 每次要计算所有点对的相似度，复杂度平方级，数据量大时很慢，且结果依赖随机初始化和困惑度。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 簇的大小、簇之间的距离在图上并不可靠，只有局部邻居关系可信；也没有可用于新样本的显式映射。
