W2NER词对关系统一NER

Unified Named Entity Recognition as Word-Word Relation Classification
2021.12论文延伸AAAI 2022Jingye Li, Hao Fei, Jiang Liu, Shengqiong Wu, Meishan Zhang, Chong Teng, Donghong Ji, Fei Li · 武汉大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

命名实体有三种形态：平面、嵌套（实体套实体）和非连续（如“肌肉疼痛和疲劳”中的“肌肉疲劳”由不相邻的片段组成）。片段式方法只关注边界，生成式方法有暴露偏差，很难用一个模型同时处理三种情况。

方法

把统一NER改写为“词与词之间的关系分类”：在句子所有词对组成的二维网格上，预测两类关系——相邻词同属一个实体（NNW，下一相邻词）和某个词是实体的尾、另一个词是其首且实体类型为某类（THW-类型）；由这些关系就能解码出任意形态的实体。

影响

在14个广泛使用的平面、嵌套、非连续NER基准（8个英文、6个中文）上都超过了当时的最好方法，成为统一NER的代表性方法与常用基线。

背景

BiLSTM-CRF序列标注只能处理平面实体；MRC-NER阅读理解式实体识别通过分类型提问处理嵌套实体，但不能处理非连续实体，且类型多时推理慢；片段枚举方法要遍历大量候选片段；生成式（Seq2Seq）方法可以输出任意结构，但存在暴露偏差和解码顺序问题。依存分析中的双仿射依存分析表明，在词对网格上打分可以高效表示句中的结构关系。

方法

关系定义：对句中任意两个词(x_i, x_j)，标注其关系：

  • NNW（Next-Neighboring-Word）：x_j 是 x_i 在同一个实体中的下一个词（可以不相邻，从而表示非连续实体）；
  • THW-类型（Tail-Head-Word）：x_i 是某实体的尾词、x_j 是该实体的首词，且实体类型为指定类型；
  • 否则为“无关系”。

于是一个实体对应网格上一条由NNW连起来的路径，加上一条从尾指回首的THW边。

模型：BERT加BiLSTM得到词表示；构造词对网格表示，融合距离嵌入和区域嵌入（网格上三角/下三角）；用多粒度空洞二维卷积在网格上提取相邻词对之间的交互；最后用“协同预测器”（双仿射分类器与多层感知机预测结果相加）为每个词对预测关系。解码时沿NNW边找出所有路径，并用THW边确认首尾与类型，得到全部实体。

结果

在14个基准数据集（8个英文、6个中文）上，覆盖平面、嵌套和非连续三类NER，W2NER都超过了当时表现最好的基线，推进了统一NER的最好水平（arXiv摘要）。

后来的发展

W2NER之后，网格式的统一抽取被推广到方面级情感三元组、事件抽取等任务；同期的UIE通用信息抽取则走生成路线，用统一的文本到结构生成覆盖多种信息抽取任务。大模型时代，基于提示的生成式抽取成为常见做法，但在精度和速度要求高的场景中，W2NER这类判别式统一模型仍常被使用。

局限与后续

  • 词对网格的大小随句长平方增长，长文档上的计算和显存开销大。

本篇术语

  • 非连续实体　由文本中不相邻的几个片段共同组成的实体，常见于医学文本，如“左腿和右腿疼痛”中的“左腿疼痛”。
  • 词对网格　句子中所有词两两组成的n×n表格，每个格子表示一对词之间的关系。
  • 空洞卷积　卷积核的采样点之间留出间隔，在不增加参数的情况下扩大感受野。

怎么学

先读MRC-NER阅读理解式实体识别与双仿射依存分析 → 读本文第3节关系定义和解码 → 动手：对“我肌肉疼痛和疲劳”这句话手工画出词对网格上的NNW与THW关系，再按解码规则还原出全部实体。
