SambaY门控记忆共享

Decoder-Hybrid-Decoder Architecture for Efficient Reasoning with Long Generation
2025.07论文延伸NeurIPS 2025Liliang Ren, Congcong Chen, Haoran Xu, Young Jin Kim, Adam Atkinson, Zheng Zhan, Jiankai Sun, Baolin Peng 等 · 微软待核对
arXiv ↗代码ArchScale ↗在交互版中打开（演化树、学习进度）

问题

推理模型要生成很长的思维链，解码阶段成本高；YOCO、Samba等高效架构还没有利用“SSM层之间共享表示”来进一步省内存和计算。

方法

提出门控记忆单元GMU，在YOCO式的交叉解码器里复用自解码器（基于Samba）某层SSM的记忆读出，用逐元素门控代替一部分交叉注意力。

影响

SambaY的不可约损失明显低于强YOCO基线；加上差分注意力的Phi-4-mini-flash-reasoning在32K长生成下解码吞吐最高提升10倍，推理成绩还超过Phi-4-mini-reasoning。

背景

YOCO只缓存一次把模型分成自解码器和交叉解码器，只缓存一份全局KV；Samba混合SSM把Mamba和滑动窗口注意力混合，预填充是线性复杂度。但推理模型的瓶颈在长输出的解码：即使只有一份KV缓存，交叉解码器每层的交叉注意力仍要读整个缓存。

方法

门控记忆单元（GMU）：取自解码器中某个SSM层的记忆读出 m（相当于它对当前token汇总的上下文信息），在交叉解码器的层里用当前隐藏状态 x 产生门控，做逐元素组合：

y = W_out · ( m ⊙ σ(W_in · x) )

这样一部分交叉解码器层不再做交叉注意力，而是直接复用SSM的读出状态，计算和内存访问都与上下文长度无关。SambaY的结构是：以Samba（Mamba加滑动窗口注意力）为自解码器，交叉解码器里交替使用交叉注意力层和GMU层。由于SSM本身携带位置信息，模型不再需要显式的位置编码。论文还用大规模的规模化实验比较不可约损失（拟合规模定律后的渐近损失），并在最大模型上加入差分注意力的差分注意力得到Phi-4-mini-flash-reasoning。

结果

摘要报告：SambaY显著提升解码效率，保持线性的预填充复杂度，增强长上下文表现，且无需显式位置编码；规模化实验显示其不可约损失明显低于强YOCO基线；Phi4-mini-Flash-Reasoning在不使用任何强化学习的情况下，在Math500、AIME24/25、GPQA Diamond上明显优于Phi4-mini-Reasoning，在vLLM下对2K提示、32K生成长度的解码吞吐最高提升10倍。

后来的发展

它把“跨层共享缓存”从KV推广到SSM状态，是为长思维链推理专门设计架构的代表工作之一；训练代码库ArchScale以开源数据开放。

局限与后续

  • 公开模型只有约38亿参数级别的Phi-4-mini规模，更大规模的效果依赖规模定律外推。
