神经风格迁移

A Neural Algorithm of Artistic Style
2015.08论文重要arXiv 2015（扩展版发表于CVPR 2016，题为Image Style Transfer Using Convolutional Neural Networks）Leon A. Gatys, Alexander S. Ecker, Matthias Bethge · University of Tübingen待核对
arXiv ↗PyTorch官方教程：Neural Transfer ↗在交互版中打开（演化树、学习进度）

问题

让计算机把一张照片画成某位画家的风格，以往只能针对特定纹理手工设计算法，没有办法把一幅画的“内容”和“风格”分开来描述。

方法

用训练好的VGG网络当“眼睛”：深层特征代表内容，各层特征之间的相关矩阵（Gram矩阵）代表风格；从白噪声出发，用梯度下降修改图像本身，使它同时匹配照片的内容特征和画作的风格统计。

影响

第一次展示了分类网络的特征可以拿来做艺术创作，引发风格迁移研究热潮和一批爆红的手机应用，Gram矩阵与“特征空间损失”成为图像生成与超分辨率的常用工具。

背景

到2015年，AlexNet和VGG这类卷积网络在ImageNet分类上已经很强，卷积网络可视化等工作也通过可视化说明：浅层卷积核响应边缘和颜色，深层响应物体部件和整体形状。但这些网络基本只被当作分类器来用。

另一方面，“非真实感渲染”和纹理合成是图形学的老问题。传统方法要么在像素层面拼贴纹理块，要么针对某一种笔触手工设计规则，没有一个统一的办法去刻画“梵高的画是什么风格”，更不能把任意一幅画的风格搬到任意一张照片上。同一组作者稍早已经发现，卷积特征之间的相关性能很好地描述纹理。

方法

用VGG-19当特征提取器。只用它的16个卷积层和5个池化层，不用全连接层，并把最大池化换成平均池化（作者发现梯度更顺、结果更好看）。网络参数全程固定，不做任何训练。

内容表示。把照片p和待生成图像x都送进网络，取某一深层（如conv4_2）的特征图F和P，内容损失就是两者的平方误差：

L_content = ½ Σ_ij (F_ij − P_ij)²

深层特征只保留了“哪里有什么东西”，丢掉了精确的像素细节，所以匹配它等于保留布局而允许笔触变化。

风格表示：Gram矩阵。对某一层的N个特征图（每个拉平成长度M的向量），计算两两内积：

G_ij = Σ_k F_ik · F_jk

它记录“哪些特征倾向于在同一处同时出现”（例如蓝色与漩涡状笔触总是一起出现），但把位置信息全部求和掉了。在conv1_1到conv5_1共5层上匹配画作a的Gram矩阵，就得到从细笔触到大色块的多尺度风格损失L_style。

合成。总损失L = α·L_content + β·L_style，α/β取1×10⁻³或1×10⁻⁴（比值越小风格越重）。从一张白噪声图像出发，用反向传播求损失对像素的梯度并迭代更新图像——优化的对象是图像，而不是网络。

结果

论文展示了同一张图宾根内卡河畔照片分别迁移成透纳《米诺陶号的沉船》、梵高《星夜》、蒙克《呐喊》、毕加索与康定斯基作品风格的效果，并系统演示了改变α/β比值、改变匹配层数时结果如何在“像照片”和“像画”之间变化。这是一篇定性展示为主的论文，没有定量指标。

后来的发展

这项方法每生成一张图都要做几百次迭代优化，很慢。2016年感知损失训练一个前馈网络一次性完成某一种风格的迁移，速度快了约三个数量级，并把“在VGG特征空间算损失”的思想推广到超分辨率。后来的自适应实例归一化（AdaIN）把风格解释为特征图的均值与方差，可以一个网络迁移任意风格——StyleGAN的“风格调制”正是借用了这一机制。Gram矩阵也被用来分析CNN的纹理偏置：ImageNet训练的CNN更依赖纹理而非形状。2016年前后Prisma等风格滤镜手机应用随之流行。今天艺术风格化主要由文生图扩散模型完成，但“特征空间损失”仍是图像重建与超分训练的标准组件。

容易误解的地方

  • 这里没有训练任何网络：VGG是现成的，被优化的是图像的像素。很多初学者把它误解为“训练了一个风格迁移模型”。
  • Gram矩阵丢掉了空间位置，所以它只能迁移局部纹理和色彩统计，无法迁移画家对构图、透视、人物比例的处理。

局限与后续

  • 每张图都要从头做数百次迭代优化，在GPU上也要数十秒到数分钟，无法实时使用。
    后来针对它的工作　感知损失
  • Gram矩阵只捕捉局部纹理统计，不理解画面的语义与构图，常把笔触错误地涂到人脸等关键区域。
    后来针对它的工作　Stable Diffusion开源 ControlNet
  • 依赖ImageNet分类网络的特征，“内容”与“风格”的划分是经验性的，没有理论保证。

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    把损失对输入像素求梯度，用反向传播直接优化图像而非网络参数。
  • 使用
    ImageNet2009.06 · 数据·评测
    所用特征来自在ImageNet上训练的分类网络，风格迁移效果依赖这些特征的通用性。
  • 使用
    VGG2014.09 · 视觉
    以固定的VGG-19卷积层作为内容与风格的特征提取器。
  • 延续
    卷积网络可视化2013.11 · 视觉
    延续可视化工作“深层特征编码物体、浅层编码纹理”的观察，把它从理解网络变成了生成图像的工具。

读懂它需要的概念

卷积层、池化与感受野 特征与表示学习 内积与余弦相似度 损失函数 梯度下降 图像作为张量

本篇术语

  • Gram矩阵　一层中所有特征图两两做内积得到的矩阵，记录哪些特征经常同时出现，丢掉了位置信息，被用作纹理和风格的描述。
  • 特征空间损失　不在像素上比较两张图，而是把它们送进预训练网络，比较中间层特征的差异。也称感知损失。

怎么学

先补卷积层、池化与感受野和特征与表示学习，知道CNN各层学到什么。原文只有十几页，重点读方法部分的三个公式和图2。然后跟着PyTorch官方的Neural Transfer教程，用不到一百行代码复现，并尝试改α/β比值、改匹配的层。
