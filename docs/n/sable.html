Sable千智能体序列模型

Sable: a Performant, Efficient and Scalable Sequence Model for MARL
2024.10论文延伸Omayma Mahjoub, Sasha Abramowitz, Ruan de Kock, Wiem Khlifi, Simon du Toit, Jemma Daniel, Louay Ben Nessir, Louise Beyers et al. · InstaDeep待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

序列模型方法MAT在合作MARL上很强，但注意力的显存随智能体数快速增长，上千个智能体就放不进显卡，而且没有跨时间步的记忆。

方法

把MAT里的注意力换成RetNet的“保留”机制：既能像循环网络一样逐步更新隐状态、带上长时记忆，又能按块并行训练，显存随智能体数线性增长。

影响

展示了序列模型路线的合作MARL可以扩展到上千个智能体且显存线性增长，是“大规模MARL”这一话题里有代表性的新方法。

方法

Sable沿用多智能体Transformer MAT的编码器-解码器框架：编码器在每个时间步对所有智能体的观测做全量“自保留”，解码器自回归地逐个输出智能体动作。区别在于把注意力换成RetNet的保留机制：它有一个跨时间步传递的隐状态（回合结束时清零），因此能记住过去；训练时把整段轨迹切成块并行处理，并修改衰减矩阵防止信息越过回合边界。智能体特别多时，编码器可以改为按智能体维度切块，进一步限制显存。

实验覆盖RWARE、MABrax、SMAX、Connector、LBF、MPE六个环境共45个任务，Sable在其中34个排第一（只有MABrax不占优）。作者另做了Neom环境测试规模：在1024个智能体时MAT超出80GB显存无法运行，Sable仍能稳定训练；其显存随智能体数线性增长，与IPPO相当，作者报告512个智能体时吞吐量最高约为MAT的6.5倍。

局限与后续

  • 千智能体的结论来自作者自建的Neom环境，任务相对简单，真实大规模协作场景还缺少验证。

它建立在什么之上

  • 竞争
    MAPPO2021.03 · RL
    主要基线之一。
  • 改进
    HATRPO/HAPPO2021.09 · RL
    顺序更新使每轮训练时间随智能体数线性增加，大团队下计算开销明显。
  • 改进
    多智能体Transformer MAT2022.05 · RL
    MAT显存随智能体数快速增长、没有时间记忆；Sable用保留机制同时解决这两点。
  • 使用
    RetNet2023.07 · LLM
    把RetNet的保留机制改造到多智能体、跨回合的RL设定。
  • 使用
    JaxMARL2023.11 · RL
    评测环境之一SMAX是JaxMARL提出的JAX版星际多智能体环境。
