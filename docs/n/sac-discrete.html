离散动作SAC

Soft Actor-Critic for Discrete Action Settings
2019.10论文延伸Petros Christodoulou · 伦敦帝国理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

SAC是连续控制上的强算法，但它的策略更新依赖对连续动作重参数化采样，不能直接用在Atari这类离散动作环境上。

方法

利用离散动作可以穷举的特点：策略直接输出每个动作的概率，评论家输出每个动作的Q值，期望和熵都按概率精确求和，不再需要采样和重参数化。

影响

成为离散动作最大熵RL的标准写法（SAC-Discrete），Tianshou、TorchRL等库都内置，也是很多需要离散动作的应用里的默认off-policy演员-评论家。

方法

SAC的目标是在回报之外最大化策略熵：J(π) = E[Σ r_t + α·H(π(·|s_t))]。连续动作下，策略是高斯分布，期望要靠采样估计，策略梯度靠重参数化技巧反传。离散动作没有重参数化可用，但动作只有有限个，可以全部列出来。论文据此改了三处：

  • 评论家输出一个向量 Q(s, ·)，每个元素对应一个动作，像DQN（Nature版）那样；
  • 软价值按策略概率精确求期望：V(s) = π(·|s)ᵀ [Q(s, ·) − α log π(·|s)]，TD目标用它而不用采样；
  • 策略损失也精确求和：J_π = E_s[ π(·|s)ᵀ (α log π(·|s) − Q(s, ·)) ]，直接对概率向量求导，不需要重参数化；温度α的自动调节同样按精确的熵计算，目标熵取一个与动作数有关的值。

其余沿用SAC：两个Q网络取较小值、目标网络软更新。摘要称即使不调超参数，它在所选的Atari游戏上也能与调过参的无模型最好方法竞争。

局限与后续

  • 后来的复现发现，在不少Atari游戏上自动温度调节会让熵过早塌缩或Q值不稳，表现不如Rainbow一类值方法，需要额外的稳定技巧。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 动作数很大（成千上万）时，每步都要对全部动作求和，计算量随动作数线性增长。
