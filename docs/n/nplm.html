神经概率语言模型

A Neural Probabilistic Language Model
2003.02论文主干JMLR 2003Yoshua Bengio, Réjean Ducharme, Pascal Vincent, Christian Jauvin · 蒙特利尔大学来源已核对
JMLR论文 ↗PDF ↗Revisiting Simple NPLMs（2021年复现） ↗在交互版中打开（演化树、学习进度）

问题

n-gram语言模型把每个词当成互不相关的符号，只能数训练语料里出现过的短词串；没见过的组合只能靠平滑硬分概率，“猫在卧室里走”学到的东西帮不了“狗在房间里跑”。

方法

给每个词学一个几十维的实数向量，把前几个词的向量拼起来送进一个神经网络，输出下一个词的概率分布；词向量和网络一起用最大似然训练，意思相近的词自动得到相近的向量。

影响

在百万词级的Brown语料和千万词级的AP新闻语料上显示，神经网络语言模型能明显胜过当时最好的n-gram（Brown上最好的n-gram困惑度比它高约24%）；“查表得到词向量→神经网络→softmax输出下一个词”的结构被之后的神经语言模型普遍沿用，今天大模型的第一层仍是词嵌入查找表。

背景

语言模型要估计一句话的概率，按链式法则拆成“给定前文，下一个词是什么”的连乘。1990年代的标准做法是n-gram与平滑：只看前面n−1个词，用语料里的出现次数估计条件概率，再用n-gram平滑里的各种平滑技巧给没出现过的组合分一点概率。

它卡在维度灾难上。论文开头算了一笔账：词表10万、连续10个词的联合分布，自由参数多达10⁵⁰ − 1个。任何语料都只能覆盖其中极小一部分，所以n-gram实际只能用到3、4个词的上下文，更长的组合几乎全是没见过的。

更根本的是，n-gram里“cat”和“dog”是两个毫无关系的编号（独热编码与词表）。训练集里有“The cat is walking in the bedroom”，对估计“A dog was running in a room”毫无帮助，尽管人一眼就看出两句结构相同、用词相近。Brown聚类一类的“类别n-gram”尝试把词先聚成几百个类来共享统计，但一个词只能属于一个类，相似度是非黑即白的。

方法

两步拆分。把条件概率P(w_t | w_{t−n+1}, …, w_{t−1})拆成两部分：

  • 一张查找表C：词表里每个词i对应一个m维实数向量C(i)，整张表是一个|V| × m的参数矩阵（这就是后来所说的嵌入向量），所有位置共用同一张表。
  • 一个函数g：把前n−1个词的向量拼成一个长向量x = (C(w_{t−1}), …, C(w_{t−n+1}))，算出下一个词在整个词表上的分布。

网络结构。论文的公式(1)：

y = b + W·x + U·tanh(d + H·x)

tanh隐层有h个单元，W·x是可选的从词向量直连输出的线性项。y有|V|维，每一维是一个词的未归一化对数概率，过Softmax与logits得到P(w_t = i | 前文) = e^{y_i} / Σ_j e^{y_j}。

训练。目标是训练语料上的平均对数似然（最大似然估计）加权重衰减，用随机梯度上升，梯度经反向传播一直传到查找表C。于是词向量不是事先设计的，而是为了“更好地预测下一个词”被逼出来的：如果cat和dog后面常跟相同的词，把它们的向量放近就能同时降低两处的损失。一句见过的句子由此能把概率“分”给一大批由相近词组成的没见过的句子。

代价在输出层。n-gram查一个概率只要读一个计数；这里每预测一个词都要对全部|V|个词算y_i再归一化，参数量主项是|V|·(n·m + h)。论文估算，在AP新闻的设置下约99.7%的计算花在输出层的加权求和上。作者为此写了在64个CPU（32台双CPU机器）集群上按输出单元切分参数的并行算法，通信开销约占总时间的1/15。

结果

Brown语料（约118万词，训练80万词，词表16,383）：验证集上最好的网络（与三元模型混合）测试困惑度252，最好的n-gram（500类的类别回退模型）312，比网络高约24%；常用的删除插值三元模型336，比网络高33%。上下文从2个词增加到4个词时网络继续变好，n-gram不再变好。

AP新闻语料（训练约1400万词，词表17,964）：网络与三元模型混合后测试困惑度109，最好的5阶Kneser-Ney模型117，比网络高约8%。但只训练了5轮，用40个CPU花了大约三周。

论文还发现把网络输出与插值三元模型各取一半平均总能再降困惑度，说明两者犯错的地方不同。

后来的发展

之后十年里，不少工作针对它留下的两个问题（作者在第5节和结论里自己也把提速和扩大上下文列为下一步）。一是太慢：层次softmax语言模型把输出层改成二叉树，对数双线性语言模型去掉非线性隐层，噪声对比估计NCE和后来Skip-gram负采样的负采样避免对整个词表归一化。二是上下文固定：RNN语言模型用循环网络让上下文长度不受窗口限制。

同时，人们发现那张查找表本身比语言模型更有用。从零开始的神经NLP把预训练的词向量拿去做词性标注、命名实体识别；word2vec干脆扔掉隐层，专门快速训练词向量。

今天的GPT-3等大模型仍是这套结构：token查表得到向量→深层网络→softmax预测下一个token，用交叉熵训练。被替换的是中间的网络（从两层MLP换成Transformer）和输入单位（从整词换成BPE子词切分子词）。

容易误解的地方

  • 词向量不是这篇最早提出的：分布式表示的想法来自1980年代联结主义（Hinton 1986等），这篇的贡献是把它和概率语言模型结合起来，并在真实语料上大规模训练成功。
  • 论文报的最好结果大多是“网络+三元模型”混合后的数字，纯网络单独用时优势小一些。
  • 它是前馈网络，看的仍是固定窗口（实验里最多5个词）；“神经语言模型能看很长的上下文”是后来RNN和Transformer才做到的。

它建立在什么之上

  • 使用
    反向传播1986 · 基础 已核对
    用反向传播把预测误差一直传到输入的词向量查找表，词向量和网络权重一起训练。
  • 改进
    Brown聚类1992 · NLP 已核对
    类别n-gram把词硬性聚成几百类来共享统计，NPLM改成连续向量，相似度有了程度之分；Brown语料上最好的类别模型（500类）困惑度比它高约24%。
  • 使用
    Brown语料库1961 · 数据·评测 已核对
    主实验在Brown语料上做，前80万词训练、20万词验证、其余测试。
  • 竞争
    n-gram平滑1996 · NLP 已核对
    同样是为了给没见过的词组合合理的概率：平滑靠回退到更短的n-gram，NPLM靠词向量的相似度；实验直接对比了Kneser-Ney等最强平滑模型。
  • 改进
    香农：语言的统计模型1948 · NLP 待核对
    香农开创的n-gram统计语言模型把词当孤立符号、无法在相似词之间泛化，这篇用连续词向量让没见过的词串也能借用相似句子的统计。
  • 改进
    乔姆斯基层级1956 · NLP
    把统计模型等同于原始频率计数，忽略了能泛化到未见组合的概率模型，结论对后来的平滑和神经语言模型不成立。
  • 改进
    Kneser-Ney平滑1995.05 · NLP
    仍是按词形计数：「狗」和「猫」的统计互不相通，没见过的组合只能靠低阶分布兜底，无法利用词之间的相似性。

后来的相关工作

  • 改进
    word2vec2013.01 · NLP 已核对
    论文把前馈NNLM的计算量拆开，指出主要耗在非线性隐层上；去掉隐层后，在同样数据上CBOW和Skip-gram的类比准确率都高于NNLM，在60亿词上NNLM（100维）用14天×180核达到50.8%，Skip-gram（1000维）用2.5天×125核达到65.6%。
  • 改进
    从零开始的神经NLP2011 · NLP 已核对
    NPLM要对整个词表做softmax归一化、也没检验词向量的用途；这里改用排序损失免去归一化，并证明预训练词向量能提升四项标注任务。
  • 改进
    BPE子词切分2015.08 · NLP 已核对
    以整词为单位，低频词被合并成一个“未知词”符号，没见过的词和词形变化都没有向量。
  • 改进
    fastText2016.07 · NLP 已核对
    以整词为单位，低频词被合并成一个“未知词”符号，没见过的词和词形变化都没有向量。

  • 改进

  • 改进

读懂它需要的概念

语言模型 n-gram与平滑 困惑度 独热编码与词表 嵌入向量 Softmax与logits 最大似然估计 反向传播

本篇术语

  • 分布式表示　用一个多维实数向量表示一个对象，每一维都参与表示很多对象，每个对象也由很多维共同刻画；与“一个词占一个独立编号”的独热表示相对。
  • 类别n-gram　先把词聚成若干类（如几百类），再在类别序列上数n-gram，用类别统计帮助估计低频词的概率。
  • 直连　论文中从拼接的词向量直接线性连到输出层的那条通路（公式里的W·x），绕过tanh隐层。

怎么学

先补n-gram与平滑、困惑度、Softmax与logits和嵌入向量。读原文第1节的维度灾难论证和“cat/dog”例子、第2节的公式(1)和图1、第4节的表1。动手：在一个几十万词的语料上用PyTorch写一个窗口为4的NPLM（嵌入层+一个tanh隐层+softmax），与一个加平滑的三元模型比较验证集困惑度，再看训练后cat、dog等词的最近邻。
