HunyuanImage 3.0

HunyuanImage 3.0 Technical Report
2025.09论文延伸arXiv 2025Tencent Hunyuan Foundation Model Team · 腾讯混元待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

开源图像模型大多是纯扩散模型，理解与生成分离，缺少统一、能做思考式生成的大规模开源基座。

方法

原生多模态：在一个自回归框架里统一理解与生成，MoE架构总计超过80B参数、每个token激活13B，并加入原生思维链。

影响

官方称是迄今最大、最强的开源图像生成模型，代码与权重公开。

方法

HunyuanImage 3.0是原生多模态模型，用自回归框架同时做理解与生成，仅图像生成模块开放。摘要列出关键成分：精心的数据整理、先进的架构设计、原生思维链（Chain-of-Thoughts）方案、渐进式预训练、大力度的后训练，以及高效的训练推理基础设施。

模型是混合专家结构：总参数超过80B，每个token推理时激活13B。其思路接近Transfusion（在同一个模型里同时做文本的下一token预测与图像生成），而不是把扩散模型与语言模型拆开。作者称人工与自动评测的文图对齐与视觉质量都能与此前最先进的模型相当。

后来的发展

它是2025年下半年开源图像模型向「大参数、原生多模态、会思考」演进的代表，对比之下Z-Image走了小而快的路线。

局限与后续
