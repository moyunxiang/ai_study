PageRank与Google搜索

The Anatomy of a Large-Scale Hypertextual Web Search Engine
1998.04论文延伸WWW7 / Computer Networks and ISDN Systems 1998-04Sergey Brin, Lawrence Page · Stanford University待核对
Crossref DOI ↗在交互版中打开（演化树、学习进度）

问题

早期网页搜索主要靠词匹配，网络又大、垃圾页面多，排序结果质量差。

方法

把网页之间的链接看成投票：被重要页面链接的页面更重要，用迭代计算每个页面的重要度，再与文本匹配结合排序。

影响

是Google搜索的核心，也是图上随机游走和TextRank等“重要性传播”算法的原型。

方法

论文描述了Google原型系统。核心是PageRank：一个页面的得分由指向它的页面贡献，每个页面把自己的得分平均分给它链接到的页面。公式：PR(A) = (1−d) + d·Σ PR(Tᵢ)/C(Tᵢ)，其中Tᵢ是指向A的页面，C(Tᵢ)是Tᵢ的出链数，d是阻尼系数，论文中取0.85。

直觉是“随机冲浪者”：一个人随机点链接，偶尔以概率1−d随机跳到任意页面。PageRank就是这个随机游走的稳态分布，用幂迭代求解，几十轮就可收敛。

系统还利用链接的锚文本（链接上的文字）来描述被链接的页面，并且和词匹配的结果结合。它说明了：网页文本之外的“结构信息”对相关性判断非常有用。

它建立在什么之上

  • 延续
    向量空间模型1975.11 · NLP
    在文本向量匹配之外，加入链接结构给出与查询无关的页面重要度。
  • 改进
    TREC文本检索评测1992.11 · 数据·评测
    早期文档集是新闻和期刊文本，没有网页的超链接结构和噪声，与网络搜索的真实环境有差距。
  • 改进
    BM251994 · NLP
    只能用于文本本身，链接、点击等文档以外的信号无法融入公式。

后来的相关工作

  • 改进
    BERT2018.10 · LLM
    对链接农场等作弊手段敏感，且对所有查询给同一个全局重要度，不能反映用户意图。
  • 延续
    Google知识图谱2012.05 · NLP
    PageRank给网页排序但把查询当字符串；知识图谱在链接排序之外加入实体理解，直接回答“是什么”。
  • 使用
    TextRank2004.07 · NLP
    把PageRank的链接分析原样搬到词和句子构成的图上。
