Runway Praxis-1

Introducing Praxis-1
2026.09模型延伸Runway待核对
Runway研究页 ↗The Robot Report ↗在交互版中打开（演化树、学习进度）

问题

机器人策略依赖昂贵的遥操作视频预训练，而且多数商用机器人模型闭源，开发者无法在自己的硬件上微调。

方法

把Runway视频生成模型的大规模视频预训练用到机器人控制：27B参数的混合专家扩散Transformer同时预测视频和动作，权重以Apache 2.0开放。

影响

又一家视频生成公司转向世界动作模型；官方称网页视频与遥操作视频预训练效果相当，开放权重后在RoboLab-120上为排名最高的世界动作模型。

方法

Runway在2026年9月发布研究文章，把Praxis-1定位为面向多种机器人形态的开放权重世界动作模型，建立在与其通用世界模型相同的大规模视频预训练之上（Runway Gen-3 Alpha以来的视频生成积累）。文章的一个核心实验是：从头训练时，用网页视频和用遥操作机器人视频预训练，微调后的放置误差分别为16.1厘米和16.0厘米，差异不显著；并称策略性能随第三人称视频规模提升。首批合作方是Noble Machines（双臂）、Standard Bots（6自由度机械臂）和Ultra（移动底盘）。

11月11日正式开放：据The Robot Report，模型是27B参数的混合专家扩散Transformer，联合预测视频和动作；权重、推理和微调代码以Apache 2.0发布，支持LeRobot。RoboLab-120上成功率46.2%（FLUX 3 Action 42.9%、Cosmos3 Nano 36.8%、π0.5 28.0%），总榜第五；在未见过的RT-1机器人上微调后SimplerEnv成功率80.0%。

  • 研究文章没有公开架构细节和训练数据构成，核心数字来自官方与媒体转述。
