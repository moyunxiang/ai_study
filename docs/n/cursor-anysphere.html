2025.11系统延伸Michael Truell等 · Anysphere待核对
Cursor官网 ↗在交互版中打开（演化树、学习进度）

问题

GitHub Copilot之后，开发者想要能理解整个代码库、能直接改多个文件的AI编辑器。

方法

Cursor是基于VS Code的AI编辑器，接入多个前沿模型，支持代码库级对话和智能体式修改，靠口碑增长而不是销售。

影响

它成为增长最快的AI应用之一，估值在两年内从几亿美元升到数百亿美元。

背景

Cursor由Anysphere开发，它把代码补全、对话和多文件修改放在同一个编辑器中，开发者可以在界面上选择不同厂商的模型，这使它不依赖单一模型的表现。

方法
