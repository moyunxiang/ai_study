LaBSE

Language-agnostic BERT Sentence Embedding
2020.07论文延伸ACL 2022Fangxiaoyu Feng, Yinfei Yang, Daniel Cer, Naveen Arivazhagan, Wei Wang · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LASER多语言句向量用BiLSTM训练多语言句向量，没有用上BERT式预训练，并且需要大量平行语料。

方法

在预训练多语言BERT上，用翻译排序的双编码器目标加附加间隔softmax训练句向量，再结合MLM和TLM预训练。

影响

在112种语言的Tatoeba检索上显著超过LASER，并可用于挖掘平行语料训练翻译模型。

方法

LaBSE（Language-agnostic BERT Sentence Embedding）系统比较了学习单语和跨语句向量的几种方法并把最好的组合起来：掩码语言建模（MLM）、翻译语言建模（TLM，来自跨语言预训练XLM）、双编码器翻译排序，以及附加间隔softmax。核心是翻译排序：一个批次里有若干对互译句子，对每个源句，要让它的译文在批内所有候选中得分最高，其余句子作为负例，这属于对比学习；附加间隔使正例要比负例高出一个固定间隔。编码器用类似Sentence-BERT的方式产出句向量。

论文称，引入预训练的多语言语言模型可把所需平行数据减少80%。在Tatoeba的112种语言双语文本检索中准确率达83.7%，而LASER多语言句向量的结果为65.5%（论文引用Artetxe和Schwenk 2019b）。用该模型从CommonCrawl挖出的平行数据训练出的中英、英德翻译模型效果有竞争力。模型公开了109种以上语言版本。

局限与后续

  • 对低资源语言和语义相近但不互译的句子，对齐质量仍不如高资源语言，训练仍依赖平行语料。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    以多语言BERT式预训练模型作为编码器初始化。
  • 延续
    Sentence-BERT2019.08 · NLP
    把句向量的双编码器训练方式推广到跨语言设定。
  • 改进
    LASER多语言句向量2018.12 · NLP
    用预训练Transformer取代BiLSTM，在Tatoeba检索上从65.5%提高到83.7%。

本篇术语

  • 附加间隔softmax　给正确样本的得分减去一个固定值再做softmax，迫使正负例拉开距离。

怎么学

先读Sentence-BERT和LASER，再读本文翻译排序损失一节；动手用公开的LaBSE模型比较中英句子的相似度。
