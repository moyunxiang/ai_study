ESP游戏：用游戏做标注

Labeling Images with a Computer Game
2004.04论文延伸Luis von Ahn, Laura Dabbish · Carnegie Mellon University待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

给网上海量图片打文字标签，对计算机很难，雇人标注成本太高。

方法

做成一个双人网页游戏：两个陌生玩家同时看同一张图，各自输入描述词，输入相同的词就得分，这个词就成了图片的标签。

影响

它证明人们愿意免费做标注，开启「带目的的游戏」和众包标注的路线，对后来的ImageNet式大规模标注有直接启发。

方法

ESP游戏由von Ahn构想，2003年上线，2004年发表论文。规则是：系统随机配对两个互不相识的玩家，给他们同一张图片，各自输入觉得能描述它的词，一旦两人输入了同一个词，就得分并换下一张图。因为两人无法交流，唯一合理的策略就是写出图片里最明显的内容，所以两人一致的词往往就是可靠的标签。同一张图被多次玩过后，已经得到的标签会被设为「禁用词」，逼迫玩家写出更新的词。

论文称，一对玩家平均每分钟产生3.89±0.69个标签；据此估算，5000人持续游戏，约31天可以为谷歌索引的4.25亿张图片各打一个标签。自2003年10月上线到2008年5月，共收集了3600万个标签。谷歌后来买下授权，推出自己的版本。

这种让人在玩的过程中完成计算机做不好的任务的思路，被称为人类计算（human computation）。

局限与后续

  • 标签偏向图片里最显眼的物体，细节、抽象概念和同一词的多个意思都难以覆盖。

  • 竞争
    ImageNet2009.06 · 数据·评测 已核对
    同样用众人之力给图片打标签：论文指出ESP游戏的标签不区分词义、大部分数据未公开，ImageNet则以WordNet同义词集从构造上避免了歧义。
  • 竞争
    LabelMe标注工具2005 · 数据·评测
    同样想用大众的劳动做图像标注：ESP用游戏激励、只给图片级标签，LabelMe用开放工具、给物体级轮廓。
