Qwen-Audio系列

Qwen-Audio: Advancing Universal Audio Understanding via Unified Large-Scale Audio-Language Models
2023.11论文延伸arXiv 2023Yunfei Chu, Jin Xu, Xiaohuan Zhou, Qian Yang, Shiliang Zhang, Zhijie Yan, Chang Zhou, Jingren Zhou · 阿里巴巴通义待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

缺少能处理多种音频类型和多种任务的预训练音频模型；直接混合训练时，不同数据集的文本标签格式、粒度、语言各不相同，彼此干扰。

方法

把音频语言预训练规模扩到30多个任务和多种音频（语音、自然声、音乐、歌曲），并用层级标签序列作为解码器的条件，共享与特定标签分别负责共享知识和避免干扰。

影响

形成开源的通用音频理解基座，后续的指令版本Qwen-Audio-Chat和Qwen2-Audio沿用这一路线，成为中文社区常用的音频语言模型。

方法

Qwen-Audio由音频编码器（初始化自Whisper）和大语言模型（参考Qwen-VL的思路，用Qwen-7B）组成。核心设计是多任务训练框架：每条训练样本在文本前面带一串层级标签，如“是否带转写”“音频语言”“任务类型”“时间戳要求”等，标签告诉解码器要做什么。相同的标签共享知识，不同的标签区分任务，这样把30多个任务的数据放在一起训练也不会因为输出格式不同而互相干扰（论文摘要称之为一对多干扰）。

预训练后再做指令微调得到对话版本，用于音频问答和多轮交互。摘要称模型在各类基准上无需任务特定微调就取得了不错的表现。

局限与后续

  • 输出只能是文字，不会直接生成语音，和用户交流仍是一问一答。

  • 长音频、多说话人和细粒度时间定位能力有限。

它建立在什么之上

  • 使用

  • 改进
    WavLM2021.10 · 语音
    仍是只处理语音的编码器，要接到LLM上做对话还需要额外的适配模块。
  • 改进
    BEATs2022.12 · 语音
    音频编码器仍是独立预训练，需要额外的对齐才能接入LLM。
  • 延续
    Qwen-VL2023.08 · 多模态
    沿用Qwen-VL的多模态预训练和指令微调套路，从视觉扩展到音频。
  • 竞争
    SALMONN2023.10 · 语音
    同期的通用音频理解大模型，Qwen-Audio用层级标签处理任务冲突，SALMONN用激活调优。
