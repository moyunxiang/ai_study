AdaIN任意风格迁移

Arbitrary Style Transfer in Real-time with Adaptive Instance Normalization
2017.03论文延伸ICCV 2017Xun Huang, Serge Belongie · Cornell University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经风格迁移能用任意风格但要逐图迭代优化，很慢；前馈风格迁移网络很快，却只能用训练时固定的一种或几种风格。

方法

把风格看作特征图每个通道的均值和标准差：先对内容特征做实例归一化，再换成风格图特征的均值和标准差，一个无参数的层就完成了风格注入。

影响

论文称首次实现了实时的任意风格迁移；“用另一路信号给出归一化的缩放和偏移”这一做法被StyleGAN直接采用，成为生成网络注入条件的常用方式。

方法

实例归一化InstanceNorm的研究提示：特征图各通道的均值和方差这类统计量就承载了大部分“风格”。AdaIN据此设计了一个没有可学习参数的层：

AdaIN(x, y) = σ(y)·(x − μ(x))/σ(x) + μ(y)

其中x是内容图的特征，y是风格图的特征，μ、σ在每个通道的空间维度上计算。先把内容特征的统计“洗掉”，再套上风格特征的统计。

整个网络是编码器—AdaIN—解码器：编码器用固定的VGG前几层，分别提取内容图和风格图的特征，经AdaIN对齐统计后，交给训练好的解码器还原成图像。训练损失是内容损失（输出特征与AdaIN结果的距离）加风格损失（各层特征均值、标准差与风格图的差异）。因为风格只以统计量形式进入，测试时可以换上训练中从未见过的风格图；在AdaIN输出与原内容特征之间插值，还能调节风格强度、混合多种风格。

局限与后续

  • 只匹配一阶、二阶通道统计，复杂的笔触和局部结构迁移得不够细，效果通常不如逐图优化。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 逐通道归一化会抹掉特征幅度，被StyleGAN沿用后造成水滴状伪影。
    后来针对它的工作　StyleGAN2

它建立在什么之上

  • 使用
    VGG2014.09 · 视觉
    固定的VGG-19前几层作为编码器，也用于计算内容与风格损失。
  • 改进
    神经风格迁移2015.08 · 生成
    保留任意风格的能力，同时把逐图迭代优化变为一次前向计算。
  • 延续
    实例归一化InstanceNorm2016.07 · 生成
    把实例归一化中固定可学习的缩放和偏移，换成由风格图特征统计量动态给出。

后来的相关工作

  • 改进
    StyleGAN22019.12 · 生成
    逐通道归一化会抹掉特征幅度，被StyleGAN沿用后造成水滴状伪影。
  • 使用
    MUNIT多模态翻译2018.04 · 生成
    用AdaIN把风格码注入解码器，第一作者与AdaIN相同。

怎么学

先读实例归一化 → 读本文第4–5节的AdaIN层和网络结构 → 写一个十几行的AdaIN函数，在两张图的VGG特征上试试。
