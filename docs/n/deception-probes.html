线性探针检测欺骗

Detecting Strategic Deception Using Linear Probes
2025.02论文延伸Nicholas Goldowsky-Dill, Bilal Chughtai, Stefan Heimersheim, Marius Hobbhahn · Apollo Research待核对
arXiv ↗探针输出示例 ↗在交互版中打开（演化树、学习进度）

问题

图谋的模型可能输出看似无害、内部却另有打算，只看输出的监控不够；在模型内部读出“它在撒谎”能否在真实场景中可靠工作？

方法

用简单的诚实/欺骗对照数据训练线性探针，读取Llama-3.3-70B的激活，检验它能否泛化到内幕交易隐瞒、故意压分等真实欺骗场景。

影响

表明白盒探针能高精度区分诚实与欺骗回答，推动“激活探针”成为前沿实验室安全监控的组成部分，但也说明它还不足以当作可靠防线。

方法

做法沿用表示工程RepE：让模型在“请诚实回答”和“请撒谎”两种指令下回答同一批事实，取中间层激活训练一个逻辑回归探针（另一种训练集是简单的角色扮演场景）。然后在训练时从没见过的场景里测试：模型为完成目标隐瞒内幕交易、在安全评测中故意表现差（对应破坏能力评测与评测中故意藏拙研究的行为）等。

在这些评测集上，探针区分诚实与欺骗回答的AUROC在0.96到0.999之间；把阈值设成在无关聊天数据上只有1%误报时，能抓到95%–99%的欺骗回答。作者的结论是：白盒探针有希望用于未来的监控系统，但目前的性能还不足以作为抵御欺骗的稳健防线。

局限与后续
