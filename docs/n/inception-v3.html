Inception v3

Rethinking the Inception Architecture for Computer Vision
2015.12论文延伸CVPR 2016Szegedy, Vanhoucke, Ioffe, Shlens, Wojna · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GoogLeNet结构复杂，如何在增大模型时又不浪费计算量缺少指导原则。

方法

提出若干设计原则：把大卷积分解成小卷积（5×5换成两个3×3，n×n换成1×n加n×1），并加入标签平滑等强正则。

影响

在约5亿次乘加、不到2500万参数下达到5.6%的top-5错误率；标签平滑成为通用技巧。

方法

核心是卷积分解。一个5×5卷积的视野可以由两个叠放的3×3卷积得到，参数从25降到18；再进一步，3×3可以拆成1×3和3×1。这些分解在不损失表达能力的前提下省计算，所省下的计算可以用来加宽加深网络。

论文还提出带辅助分类器的作用其实更像正则，并引入标签平滑：把one-hot标签改成略平滑的分布，减轻过拟合。同时在网络里使用了Batch Normalization。论文称单模型单帧评测达到top-1错误21.2%、top-5错误5.6%，计算量为5亿次乘加、不到2500万参数；4个模型集成加多裁剪评测的top-5错误为3.5%（验证集）。
