mBART多语言去噪预训练

Multilingual Denoising Pre-training for Neural Machine Translation
2020.01论文延伸TACL 2020Yinhan Liu, Jiatao Gu, Naman Goyal, Xian Li, Sergey Edunov, Marjan Ghazvininejad, Mike Lewis, Luke Zettlemoyer · Facebook AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

此前的多语言预训练要么只预训练编码器（如XLM），要么只重建句子的一部分（如MASS），翻译模型的编码器—解码器无法整体从预训练中受益，低资源语言对尤其吃亏。

方法

把BART的去噪目标搬到多语言：在多种语言的单语语料上，把整段文本打乱、遮盖，再让完整的编码器—解码器还原原文，然后直接拿去微调翻译。

影响

成为多语言seq2seq预训练的常用起点，低资源和无监督翻译显著受益；mBART-50等后续版本被大量翻译与跨语言生成工作当作基线。

方法

BART的预训练是“加噪声再还原”：把句子打乱顺序、把连续片段替换成一个[MASK]，让编码器读入破损文本、解码器写出原文。mBART用同样的目标，在从Common Crawl抽取的25种语言单语语料（mBART-25）上训练一个12层编码器加12层解码器的Transformer，每段输入末尾附一个语言标记，让解码器知道该写哪种语言。

与跨语言预训练XLM只预训练编码器、MASS只让解码器重建被遮住的片段不同，mBART预训练的是完整的序列到序列模型，因此可以不加任何任务特定改动，直接微调成句子级或文档级翻译模型，也能用于无监督翻译。

作者报告：加mBART初始化后，除了资源最丰富的语言对，几乎所有设定都有提升，低资源翻译最多提升12个BLEU，文档级和无监督翻译多个模型提升超过5个BLEU；对预训练中没出现过的语言对也能迁移。

局限与后续

  • 在资源最丰富的语言对上预训练几乎没有收益；覆盖语言只有25种，语言之间争夺模型容量的问题在更多语言时会更严重。

它建立在什么之上

  • 改进
    跨语言预训练XLM2019.01 · LLM
    XLM只预训练编码器，翻译的解码器仍需从头学；mBART预训练完整的编码器—解码器。
  • 竞争
    MASS2019.05 · LLM
    MASS也预训练seq2seq，但只重建被遮住的片段；mBART还原整段文本。
  • 延续
    BART2019.10 · LLM
    直接沿用BART的文本打乱和片段遮盖目标，推广到多语言语料。

怎么学

先读BART的去噪目标；读本文预训练设置和低资源翻译、无监督翻译的结果表；动手：用Hugging Face上的mBART-50在一个小语种平行语料上微调，对比随机初始化的BLEU。
