Gorila分布式DQN

Massively Parallel Methods for Deep Reinforcement Learning
2015.07论文延伸ICML 2015 Deep Learning WorkshopNair, Srinivasan, Blackwell, ..., Legg, Mnih et al. · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

DQN（Nature版）在单机上训练一个Atari游戏要很多天，深度RL的实验周期太长。

方法

把DQN拆成并行的执行者、并行的学习者、分布式的参数服务器和分布式的经验回放库，大规模并行训练。

影响

首次展示深度RL可以大规模分布式训练，开启了Ape-X、IMPALA与V-trace这类「很多actor加一个learner」的架构。

方法

Gorila（General Reinforcement Learning Architecture）有四个组成部分：许多并行的actor在各自的环境副本里按当前网络玩游戏、产生经验；许多并行的learner从存储的经验里取样本训练（沿用经验回放）；用分布式方式保存网络参数；经验也存在分布式的回放库里。actor和learner各自异步地读写参数，不必互相等待。

论文用它实现了DQN，在Arcade学习环境ALE的49个Atari游戏上用同一组超参数测试。摘要称在49个游戏中有41个超过非分布式DQN，且在多数游戏上把达到该成绩所需的墙钟时间缩短了一个数量级。

局限与后续

  • 需要成百上千个CPU/GPU级别的计算资源，一般实验室用不起。
    后来针对它的工作　IMPALA与V-trace Ape-X
  • 异步更新带来的参数过期会让学习变得不稳定，算法本身并没有变得更聪明。
    后来针对它的工作　IMPALA与V-trace

它建立在什么之上

  • 延续
    DQN2013.12 · RL
    把单机DQN的训练过程拆分并行化。
  • 使用
    经验回放1992 · RL
    分布式的回放库保存所有actor产生的经验，learner从中采样。

后来的相关工作

  • 改进
    IMPALA与V-trace2018.02 · RL
    同样是采样与学习分离的分布式架构，但面向actor-critic、在GPU上批量学习，规模和效率更高。
  • 延续
    Ape-X2018.03 · RL
    Gorila已有分布式DQN，Ape-X改用集中的优先回放加单个learner，更有效率。
