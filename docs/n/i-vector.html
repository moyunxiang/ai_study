i-vector说话人识别

Front-End Factor Analysis for Speaker Verification
2011.05论文延伸IEEE TASLP 19(4) 2011Najim Dehak, Patrick Kenny, Réda Dehak, Pierre Dumouchel, Pierre Ouellet · CRIM / ETS待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

GMM-UBM说话人确认的说话人表示是几万维的均值超向量，里面混着说话人、信道和内容的变化，之前的联合因子分析需要分别建模说话人与信道。

方法

把说话人与信道合在一个低维总变化空间里，每段语音用这个空间里的一个几百维向量（i-vector）表示，再用简单的分类器比较。

影响

i-vector成为2011到2018年说话人识别的事实标准，把「语音转成定长向量」的思路固定下来。

背景

说话人确认和聚类需要对不同长度的语音给出可比较的定长表示。联合因子分析（JFA）分别学习说话人子空间和信道子空间，复杂而且二者并不能完全分开。

方法

做法是假设某段语音的GMM均值超向量M可以写成M = m + T·w：m是UBM的均值超向量，T是一个低秩的总变化矩阵（见低秩近似），w是服从标准正态先验的低维隐变量，它的后验均值就是i-vector（见隐变量模型）。T用EM算法从大量数据估计（见EM算法）。得到的向量先做线性判别分析（LDA）去掉信道方向，再做长度归一化，最后用余弦距离或概率线性判别分析（PLDA）打分。整个流程把「说话人加信道」压进一个几百维向量，后续分类用简单的线性方法即可。

后来的发展

i-vector也被用作声学模型的说话人自适应输入。它在2018年后被深度网络嵌入x-vector说话人嵌入和ECAPA-TDNN取代。

局限与后续

  • i-vector由无监督的因子分析得到，不直接优化区分说话人，短语音下估计不稳定。
    后来针对它的工作　x-vector说话人嵌入 ECAPA-TDNN
  • 依赖UBM的高斯统计量，整个流水线是多个独立训练的模块。
    后来针对它的工作　x-vector说话人嵌入

它建立在什么之上

  • 改进
    MAP说话人自适应1994.04 · 语音
    每个说话人都要单独存一套完整模型参数，说话人多时存储和管理成本高。
  • 改进
    MLLR说话人自适应1995.04 · 语音
    线性假设有限，对大幅度的说话人差异（比如儿童与成年人）适应能力不足。
  • 改进
    SAT说话人自适应训练1996.10 · 语音
    只用线性变换描述说话人差异，表达能力有限；深度网络时代改为把说话人信息作为输入向量（如i-vector）喂给网络。
  • 改进
    fMLLR约束线性变换1998.04 · 语音
    整个说话人只用一个（或少数几个）全局线性变换，无法刻画非线性的嗓音差异。
  • 改进
    GMM-UBM说话人确认2000.01 · 语音
    在UBM均值超向量基础上学习低维总变化空间，把变长语音映射成定长向量。

后来的相关工作

  • 改进
    x-vector说话人嵌入2018.04 · 语音
    i-vector的无监督提取器无法从扩增数据中获益；有监督训练的x-vector能，于是在两个测试集上都超过了它。
  • 使用
    i-vector说话人自适应2013.12 · 语音
    直接使用说话人识别中的i-vector作为说话人与信道的表示。
  • 竞争
    d-vector说话人嵌入2014.05 · 语音
    i-vector用GMM和因子分析得到说话人向量，d-vector用DNN隐层激活；论文发现两者融合效果更好。
  • 竞争
    VoxCeleb说话人库2017.06 · 数据·评测
    两篇论文都以i-vector加PLDA为传统基线，用VoxCeleb训练的卷积网络在等错误率上明显更低。
  • 竞争
    GE2E说话人嵌入2017.10 · 语音
    i-vector用因子分析得到说话人向量；GE2E用端到端训练的神经网络嵌入替代。
  • 改进
    ECAPA-TDNN2020.05 · 语音
    i-vector由无监督的因子分析得到，不直接优化区分说话人，短语音下估计不稳定。
