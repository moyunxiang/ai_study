Core ML

2017.06系统延伸Apple待核对
iOS 11发布信息 ↗在交互版中打开（演化树、学习进度）

问题

在手机上运行训练好的神经网络，开发者要自己把模型转换并手写调用GPU/CPU的底层代码，既慢又难维护。

方法

Apple提供统一的设备端推理框架：开发者把训练好的模型转换为Core ML格式，系统自动调度到CPU、GPU或后来的神经引擎上运行。

影响

让图像识别、语音等模型在iPhone上本地运行成为普通应用的常规功能，数据不必上传云端。

方法

Core ML随iOS 11于2017年6月的WWDC上宣布（iOS 11的宣布日期为2017年6月5日，正式发布为9月19日）。它定位于设备端推理：模型在训练端用Caffe等框架完成，再经转换工具变为Core ML模型文件，应用里用统一接口加载预测。系统负责选用最合适的计算单元。

它同期面向的是MobileNet这类专为手机设计的轻量网络。注意它只做推理，不做训练。

局限与后续

  • 早期只支持推理，且依赖转换工具，新算子支持滞后。
