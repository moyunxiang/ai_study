CodeGen

CodeGen: An Open Large Language Model for Code with Multi-Turn Program Synthesis
2022.03论文延伸ICLR 2023Erik Nijkamp, Bo Pang, Hiroaki Hayashi, Lifu Tu, Huan Wang, Yingbo Zhou, Silvio Savarese, Caiming Xiong · Salesforce Research待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

Codex这类强力的代码生成模型不开放，训练资源和数据也让研究者难以复现。

方法

训练并开源最多16.1B参数的CodeGen系列和训练库JAXFORMER，并提出多轮程序合成的设定和基准MTPB。

影响

当时最强的开放代码模型之一，在HumanEval上的零样本Python生成能力与此前最佳相当，并推广了把程序拆成多轮提示的用法。

方法

背景：Codex证明了大模型能写代码，但闭源。作者在自然语言和编程语言混合数据上训练一族模型，最大16.1B参数，并发布权重和JAXFORMER训练库。

除了常规的单轮生成，论文研究多轮程序合成：把一个程序的需求拆成几段子问题，依次作为多个提示给模型，每轮在前面已生成代码的基础上继续。为此构建了开放基准Multi-Turn Programming Benchmark（MTPB），共115组问题。

结果：在HumanEval零样本Python生成上，CodeGen与当时最好的方法相当；在MTPB上，同样意图以多轮方式给出，合成效果明显好于一次性给出。

局限与后续

  • 评测仍以单元测试通过率的HumanEval为主，对真实仓库级任务能力不清楚。
    后来针对它的工作　SWE-bench Code Llama
  • 训练数据的许可和安全问题没有解决，模型会输出含漏洞或来源不明的代码。
    后来针对它的工作　StarCoder
