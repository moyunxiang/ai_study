EG3D三维感知GAN

Efficient Geometry-aware 3D Generative Adversarial Networks
2021.12论文延伸CVPR 2022Chan, Lin, Chan, Nagano, Pan, De Mello, Gallo, Guibas, Tremblay, Khamis, Karras, Wetzstein · NVIDIA / Stanford待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

只用单视角照片训练3D感知的GAN，要么体渲染太贵导致分辨率低，要么靠2D上采样近似而破坏多视角一致。

方法

提出三平面（tri-plane）混合显式-隐式表示：用StyleGAN2生成三张特征平面，在其上采样特征再小网络解码并体渲染。

影响

实时生成高分辨率、多视角一致的图像和3D几何，成为之后3D头像、可控人脸3D生成的常用基础结构。

方法

思路是把“生成特征”和“神经渲染”解耦。一个现成的2D卷积生成器（StyleGAN2）输出三张轴对齐的特征平面（XY、XZ、YZ）；对空间中任意3D点，把它投影到三张平面上取特征并相加，再由一个很小的MLP解码成颜色和密度，按NeRF的体渲染（见体渲染）得到低分辨率图像，最后用2D超分辨率网络放大到最终分辨率。

由于特征由2D卷积生成，表达力强且高效，体渲染只需在低分辨率上做。训练只用单视角照片和相机位姿，判别器看图与相机参数。论文在FFHQ和AFHQ猫上取得当时最好的3D感知合成效果，并能提取出高质量几何。

局限与后续

  • 放大步骤的2D超分网络仍会带来轻微的多视角不一致。
