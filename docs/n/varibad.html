VariBAD贝叶斯自适应

VariBAD: A Very Good Method for Bayes-Adaptive Deep RL via Meta-Learning
2019.10论文延伸ICLR 2020Luisa Zintgraf, Kyriacos Shiarlis, Maximilian Igl, Sebastian Schulze, Yarin Gal, Katja Hofmann, Shimon Whiteson · 牛津大学 / 微软研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

在未知环境里，贝叶斯最优策略会根据自己对环境的不确定程度决定是探索还是利用，但精确计算它只在极小的问题上可行；RL²元强化学习隐式地学，PEARL离策略元RL用后验采样，都不是直接对不确定性做决策。

方法

用变分自编码器从过去的轨迹推断任务的隐变量后验分布，把后验的均值和方差一起输入策略，让策略显式地根据「我还有多不确定」来行动；用元学习在一批任务上训练。

影响

成为元强化学习中「近似贝叶斯自适应」路线的代表方法和常用基线，后续的元探索研究普遍与它比较。

方法

贝叶斯自适应MDP（BAMDP）把智能体对环境的信念也当作状态的一部分：最优策略会主动去做能减少不确定性的事。VariBAD用三部分近似它：

  • 编码器：一个循环网络，读入到当前为止的状态、动作、奖励序列，输出任务隐变量m的近似后验 q(m | τ:t)（高斯分布的均值和方差）；
  • 解码器：给定m，预测未来的奖励和状态转移，用来训练编码器，目标是变分下界（ELBO），而且要求在每个时刻的后验都能重建整段轨迹的过去和未来；
  • 策略：输入当前状态和后验参数（均值、方差），用普通RL算法（如PPO）训练。

因为策略看到的是整个后验而不是一次采样，它能根据不确定度决定是去试探还是直接利用。摘要称：在网格世界里，VariBAD表现出随任务不确定度变化的结构化在线探索；在元RL常用的MuJoCo任务上，它在线回报高于已有方法。

局限与后续

  • 解码器要重建奖励和转移，在高维观测下难以训练；而且只学到在训练任务分布内的近似贝叶斯行为。

读懂它需要的概念

元学习 变分推断与ELBO 隐变量模型 探索与利用 条件概率与贝叶斯公式

本篇术语

  • 贝叶斯最优策略　在对环境只有先验信念时，平均意义上回报最高的策略；它会在探索获得信息和利用已知之间做最优取舍。
  • BAMDP　贝叶斯自适应MDP：把对环境的信念并入状态后得到的MDP，在其中求最优就得到贝叶斯最优策略。
