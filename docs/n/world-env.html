World-Env: Leveraging World Model as a Virtual Environment for VLA Post-Training
2025.09论文延伸arXiv 2025Junjin Xiao, Yandan Yang, Xinyuan Chang, Ronghan Chen, Feng Xiong, Mu Xu, Wei-Shi Zheng, Qing Zhang · 中山大学、阿里巴巴高德待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

示范很少时VLA模仿学习效果差；RL后训练能补，但真实环境不能随便重置，工业场景里一次失败可能无法复原；VLA还不知道何时任务已完成，会多做多余动作。

方法

用视频世界模型代替物理交互当虚拟环境，再用视觉语言模型做“即时反思器”：持续给出成功概率作奖励，并在概率超过阈值时判定任务结束。

影响

在LIBERO每个任务只有5条示范的设置下，把OpenVLA-OFT的四套件平均成功率从74.85%提到79.6%，物体套件提升12.4个百分点。

方法

卡在哪：SimpleVLA-RL这类在线RL需要能反复重置的仿真器，真实场景做不到；另外VLA通常跑满固定步数，任务完成了还在动，反而可能把成功的状态弄乱。

做法：World-Env由两部分组成。世界模拟器基于EVAC框架的扩散式动作条件视频模型：把要执行的动作和由正运动学算出的下一时刻机械臂状态渲染成一张“动作图”，与历史画面一起作为像素级条件，预测下一帧。训练数据除了LIBERO的人类成功示范，还加入OpenVLA-OFT在动作上加拉普拉斯噪声后自主跑出的轨迹，其中包含失败，使模拟器也能逼真地生成失败过程。即时反思器用冻结的LLaVA加一个训练出的奖励头：取32帧画面问“视频是否完成了任务”，经sigmoid输出0到1之间的连续分数，用逐帧成功标签的二元交叉熵训练；分数超过0.5就终止，并在终止时给出奖励。策略训练用LOOP算法，即RLOO回归REINFORCE式留一法基线配合PPO裁剪目标（ε=0.1），每轮8条rollout；视觉语言主干用秩32的LoRA，动作头和尺度头全量训练。

结果：每任务5条示范时，OpenVLA-OFT监督微调四套件平均74.85%，加World-Env后79.6%，其中Goal 84.0→86.4、Object 74.2→86.6、Spatial 84.2→87.6、Long 57.0→57.8。去掉仿真器提供的真实终止信号后，World-Env平均74.9%，OpenVLA-OFT只有63.05%，说明自动判断结束本身就很有用。

  • 使用
    LIBERO2023.06 · 具身·世界模型

  • 使用
    RLOO回归REINFORCE2024.02 · LLM

  • 使用
    OpenVLA-OFT2025.02 · 具身·世界模型
    以OpenVLA-OFT为待后训练的策略，并用它自主采集带失败的轨迹训练世界模型。
  • 竞争
    SimpleVLA-RL2025.09 · 具身·世界模型
    SimpleVLA-RL在物理仿真器中做在线RL；World-Env用学到的视频世界模型代替仿真器，并自带终止判断。
