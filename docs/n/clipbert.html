ClipBERT

Less is More: ClipBERT for Video-and-Language Learning via Sparse Sampling
2021.02论文延伸CVPR 2021Lei, Li, Zhou, Gan, Berg, Bansal, Liu · UNC / 微软待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视频语言任务依赖离线提取的稠密视频特征，这些特征与目标任务无关，又太大，使得端到端微调几乎不可行。

方法

每个训练步只随机采样一到几段短视频片段，并用可训练的2D卷积和Transformer端到端学习，以稀疏采样替代稠密特征。

影响

让视频语言模型端到端训练变得可行，并发现稀疏采样往往足够。

方法

ClipBERT的核心是稀疏采样：训练时，每个视频只取一个或几个短片段（原文用少量帧），把每段送入可训练的CNN，得到视觉特征，再与文字一起进入Transformer做融合。推理时则多取几个片段，对预测取平均。这样每一步的计算量与视频长度无关，可以像图像模型一样反向传播到视觉编码器。

作者还用图像加文字数据（如COCO和Visual Genome）初始化，使模型先具备图文能力再迁移到视频。摘要称，该方法在视频问答和文本到视频检索等任务上，相比用离线稠密特征的模型更好，且训练更省。
