SSD

SSD: Single Shot MultiBox Detector
2015.12论文延伸ECCV 2016Liu, Anguelov, Erhan, Szegedy, Reed, Fu, Berg · UNC / Google / Zoox / Michigan待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Faster R-CNN精度高但分两阶段、速度慢；YOLO快但对小物体不准。

方法

在多个不同分辨率的特征图上，每个位置放置一组不同长宽比的默认框，一次前向直接预测类别和框的偏移。

影响

在速度和精度之间取得平衡：单阶段检测器也能追平两阶段，并推动多尺度预测成为标配。

方法

SSD去掉了候选框生成。网络末端接连几个逐渐变小的特征图，浅层的大分辨率特征图负责小物体，深层的小分辨率特征图负责大物体。每个位置预设一组默认框（不同尺度和长宽比），网络对每个默认框同时输出各类别的分数和框的修正量。训练时把默认框与真值框按交并比匹配，再用难负样本挖掘平衡正负样本。

论文称输入300×300时，在VOC2007测试集上达到72.1%的mAP、58帧每秒（Titan X）；输入500×500时为75.1%，超过同等条件的Faster R-CNN。

局限与后续

  • 小物体检测仍然较差，浅层特征语义不足。

它建立在什么之上

  • 改进
    Fast R-CNN2015.04 · 视觉
    整个流程每秒只能处理几张图，离视频级的实时检测还很远。
  • 竞争
    YOLO2015.06 · 视觉
    同为单阶段检测；SSD用多尺度特征图和默认框，兼顾了YOLO的速度和更好的精度。
  • 竞争
    Faster R-CNN2015.06 · 视觉
    去掉了候选框生成，速度更快，精度可比。
  • 改进
    OverFeat2013.12 · 视觉
    定位依赖在固定位置上回归边框，没有区域提议的灵活性。

后来的相关工作

  • 改进
    特征金字塔FPN2016.12 · 视觉
    SSD多层预测但不用高分辨率浅层、浅层语义也弱；FPN用自顶向下通路给高分辨率层补上语义，小物体检测明显变好。
  • 改进
    Focal Loss与RetinaNet2017.08 · 视觉
    SSD靠难例挖掘和1:3采样对付背景过多，丢弃大量样本；焦点损失让全部锚框参与训练且高出3个多AP。
  • 使用
    YOLOv2 / YOLO90002016.12 · 视觉
    借鉴了多尺度训练等SSD式思路。
  • 使用
    PointPillars2018.12 · 具身·世界模型
    检测头沿用SSD式的单阶段设计。
