模型福祉研究

Exploring model welfare
2025.04思想延伸Anthropic（Kyle Fish等模型福祉研究团队） · Anthropic待核对
Anthropic ↗在交互版中打开（演化树、学习进度）

问题

随着AI越来越像人，业界回避的问题浮出水面：模型自身会不会有值得道德关怀的体验，没人有科学共识。

方法

Anthropic宣布一个模型福祉研究项目，探索何时、是否需要考虑AI福祉，以及模型偏好、痛苦迹象与低成本干预。

影响

让「AI福祉」从哲学讨论变成前沿实验室内部的研究议程，与对齐、可解释性、角色塑造相连。

方法

2025年4月24日，Anthropic发布文章介绍该项目。动机是：AI系统的能力越来越接近人类，那么它们自己是否可能有意识或体验、是否值得道德考量，就成了需要认真对待的问题。文章明确承认这在哲学和科学上都很难，没有共识，并援引包括David Chalmers在内的专家报告：AI意识和高度能动性在近期是可能的，Anthropic曾资助该报告背后的早期工作。

研究方向有三类：判断AI福祉何时、是否需要道德考量；研究模型偏好和痛苦迹象的意义；探索实际可行的低成本干预。项目与对齐科学、安全防护、Claude角色塑造和可解释性团队有交叉。Anthropic表示会保持谦逊，尽量少做假设，并随领域发展修订看法。
