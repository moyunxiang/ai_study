Mini-Omni

Mini-Omni: Language Models Can Hear, Talk While Thinking in Streaming
2024.08论文延伸arXiv 2024Xie, Wu · 清华大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

学术界的语音对话模型依赖外挂TTS，说话前要先等文本生成完，延迟高，没有开源的端到端实时方案。

方法

让语言模型在生成文本的同时并行生成语音token（文本引导的语音生成），并用批并行推理提升质量，称为Any Model Can Talk训练法。

影响

论文称是首个完全端到端、开源的实时语音交互模型，并发布了VoiceAssistant-400K数据集。

方法

Mini-Omni在一个现成语言模型上加语音能力：模型每一步同时输出文本token和语音token，让它「边想边说」（talk while thinking），用文本推理的结果指引语音的内容。语音token用音频codec离散化（见声码器与音频编解码），输入端用Whisper的编码器听音频。

训练分阶段：先让模型学会听和说，再逐步混合，使原有语言能力退化很小，这套办法被称作Any Model Can Talk，可套用到其他语言模型。推理时再用批并行策略提升语音质量。数据方面发布了VoiceAssistant-400K。它是对GPT-4o全模态实时模型实时语音交互的开源追赶。
