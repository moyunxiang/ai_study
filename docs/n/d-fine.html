D-FINE

D-FINE: Redefine Regression Task in DETRs as Fine-grained Distribution Refinement
2024.10论文延伸Yansong Peng, Hebei Li, Peixi Wu, Yueyi Zhang, Xiaoyan Sun, Feng Wu · 中国科学技术大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

实时DETR检测器直接回归框的四个坐标，定位精度受限，而且深层解码器学到的精确定位无法回传给浅层。

方法

把框回归改成对每条边偏移量的概率分布做逐层细化，并让最深层的精细分布通过自蒸馏教给浅层。

影响

在T4 GPU实时速度下把COCO精度推到新高，与后续的DEIM一起成为2025年实时检测的主要基线，RF-DETR等工作都以它为对照。

方法

DETR式检测器的解码器有多层，每层都输出一组框，后一层在前一层基础上修正。D-FINE认为直接预测固定坐标太粗：坐标值本身没有表达“这条边大概在哪、有多确定”。

它有两个部件。一是细粒度分布细化（FDR）：每条边（上下左右）不再输出一个数，而是输出一组离散偏移量上的概率分布，每层解码器在上一层分布的基础上做残差式细化，最终位置取分布的期望。二是全局最优定位自蒸馏（GO-LSD）：把最后一层细化好的分布当作老师，用知识蒸馏的方式监督浅层的分布，浅层学好后深层只需修正更小的残差。此外还对计算密集的模块做了轻量化。

摘要报告D-FINE-L/X在COCO上达到54.0%/55.8% AP，T4上分别124/78 FPS；先在Objects365上预训练后为57.1%/59.3% AP。把FDR和GO-LSD装到其他DETR上可提升最多5.3% AP，额外参数和训练成本几乎为零。

读懂它需要的概念

本篇术语

  • 边界框回归　预测物体外接矩形的位置，通常是中心点加宽高或四条边到参考点的距离。
  • 自蒸馏　老师和学生是同一个网络的不同部分（这里是深层教浅层），不需要另外训练一个老师模型。
