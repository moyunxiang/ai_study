ICL即梯度下降

Transformers learn in-context by gradient descent
2022.12论文重要ICML 2023Johannes von Oswald, Eyvind Niklasson, Ettore Randazzo, João Sacramento, Alexander Mordvintsev, Andrey Zhmoginov, Max Vladymyrov · Google Research / ETH Zürich待核对
arXiv ↗后续质疑：Do pretrained Transformers Learn In-Context by Gradient Descent? ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

大模型看几个例子就能做新任务（上下文学习），但权重没有更新，它到底在前向计算里做了什么，没有机制层面的解释。

方法

构造证明：一层线性自注意力恰好能实现“在上下文例子上对线性回归做一步梯度下降”；再实验表明，在回归任务上训练出来的Transformer，权重确实收敛到这个构造。

影响

给“上下文学习是一种在前向计算中运行的学习算法”提供了可检验的机制模型，成为上下文学习理论研究的常用出发点；但它能多大程度解释真实大模型，至今有争议。

背景

GPT-3展示了上下文学习与提示：提示里放几个输入输出例子，模型不更新参数也能照着做。这像是一种学习，但学习发生在哪里？

2022年有两条线索。上下文学习函数类发现，专门在“给若干(x, y)对、预测新x的y”上训练的Transformer，做线性回归的误差能接近最小二乘法，但没说它内部怎么算。归纳头与ICL在真实语言模型里找到了“复制前文模式”的注意力头，却解释不了回归这类需要计算的任务。另一方面，线性注意力早已指出：去掉softmax的注意力等价于一个随输入不断累加的“快速权重”矩阵。这篇论文把这几件事连了起来。

方法

梯度下降可以写成“改数据”。设线性模型y = W·x，损失L = (1/2N)·Σ‖W·xᵢ − yᵢ‖²。从W₀ = 0出发走一步梯度下降，权重变化为

ΔW = −η·∇L = (η/N)·Σ yᵢ·xᵢᵀ

于是对测试点的预测是ŷ = ΔW·x_test = (η/N)·Σ yᵢ·(xᵢᵀ·x_test)。

这正是线性注意力。把每个例子拼成一个token eᵢ = (xᵢ, yᵢ)，测试点是(x_test, 0)。如果让键和查询取出x部分、值取出y部分，去掉softmax的注意力输出就是Σ vᵢ·(kᵢᵀ·q) = Σ yᵢ·(xᵢᵀ·x_test)，与上式只差一个系数η/N。论文的命题1给出了具体的W_K, W_Q, W_V, P矩阵，使一层线性自注意力对所有token的更新，与“对数据做一步梯度下降后的变化”完全一致；学习率η被吸收进权重里，相当于跨任务元学习出来的（见元学习）。

多层。把K层堆起来，就对应K步梯度下降。

结果

在随机生成的线性回归任务上训练单层线性自注意力模型，它的损失与调好学习率的一步梯度下降几乎重合，两者给出的预测和隐含的权重的余弦相似度接近1，换成训练时没见过的输入尺度也一致（5个随机种子）。多层模型比同样步数的普通梯度下降更好，但与作者提出的变体GD++吻合：每步先把输入变换为(I − γ·X·Xᵀ)·x，相当于做了一次曲率校正。在非线性回归上，带MLP的Transformer先学出特征，再在特征上做梯度下降。

后来的发展

同期的ICL学的是什么算法和ICL即隐式元优化从不同角度提出了相近的主张，三篇合在一起，使“上下文学习＝隐式优化”成为一个主流的理论视角，也让学到的优化器与内对齐这个原本偏思辨的安全概念有了具体实例。2023年10月Shen等人在LLaMA-7B上直接比较上下文学习与真正的梯度微调，发现两者在不同数据集、模型和示例数量下表现并不一致，结论是二者等价仍只是一个开放假设。这个对应关系目前主要在受控的回归任务里成立。

容易误解的地方

  • 结论是在“线性注意力＋把x和y拼进同一个token”的人造设定下得到的。真实大模型用softmax注意力，例子以普通文本分散在很多token中，不能直接推出“GPT在做梯度下降”。
  • “等价”指输出相同，构造并不唯一：只要P·W_V和W_K·W_Q的乘积对上即可，所以比较训练出的权重时要先消除缩放差异。

局限与后续

  • 只在线性自注意力、人造线性回归任务上严格成立；带softmax、在自然语言上训练的大模型是否仍按梯度下降做上下文学习，没有直接证据。

读懂它需要的概念

上下文学习与提示 梯度下降 线性回归 自注意力与多头注意力 稀疏注意力与高效注意力 元学习

本篇术语

  • 线性自注意力（LSA）　去掉softmax、直接用键和查询的内积作为权重的注意力。它的输出可以写成一个由历史(键, 值)外积累加而成的矩阵乘以查询。
  • mesa优化器　被训练出来的模型自身在前向计算中又执行了一个优化过程。外层训练是“基础优化”，模型内部的这个过程叫mesa优化。
  • GD++　本文提出的梯度下降变体：每步先用(I − γXXᵀ)变换输入数据再做梯度步，相当于近似的曲率（二阶）校正，多层Transformer的行为与它吻合。

怎么学

先确认会线性回归的梯度推导和自注意力与多头注意力的矩阵写法。读论文第2节，自己在纸上验证：W₀=0时一步梯度下降的预测等于Σ yᵢ(xᵢᵀx_test)，再把它对上线性注意力的公式。然后跑官方代码里的单层实验，看训练出的权重与构造的对比图。
