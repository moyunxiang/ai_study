Uni-Mol

Uni-Mol: A Universal 3D Molecular Representation Learning Framework
2022.09论文延伸Gengmo Zhou, Zhifeng Gao, Qiankun Ding, Hang Zheng, Hongteng Xu, Zhewei Wei, Linfeng Zhang, Guolin Ke待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

分子表示学习多基于一维序列或二维图，没有利用三维构象，且缺少三维的大规模预训练。

方法

在大量分子三维构象上做类似BERT的预训练：遮盖原子并恢复，同时恢复坐标。

影响

提供了可迁移到性质预测和构象生成的三维分子预训练骨干。

方法

Uni-Mol以Transformer为骨干，输入原子类型与原子间距离，在大规模分子构象上预训练：遮盖部分原子类型要求恢复，并对加噪的坐标要求还原；另有一个以蛋白口袋为对象的预训练分支。预训练后在分子性质预测、构象生成等下游任务上微调。

后来的发展

常作为三维分子预训练的基线。读这一篇时，可以把上面列出的前驱工作放在一起对照，看同一个问题的做法是怎样一步步演变的，以及它没解决的部分后来由谁接手。

它建立在什么之上

  • 延续
    BERT2018.10 · LLM
    把遮盖预测的预训练范式用到三维分子。
  • 竞争
    SchNet2017.06 · 科学
    SchNet从头训练的三维分子网络，Uni-Mol强调大规模预训练。
  • 改进
    GROVER分子图预训练2020.06 · 科学
    仍是二维图表示，未利用三维构象。
  • 改进
    ChemBERTa2020.10 · 科学
    SMILES是线性字符串，同一分子可以有多种写法，且丢失三维构象信息，这限制了序列模型的表示能力。
  • 竞争
    E(n)等变图网络EGNN2021.02 · 基础
    等变图网络靠结构设计保持几何对称，Uni-Mol靠数据增强与预训练。
