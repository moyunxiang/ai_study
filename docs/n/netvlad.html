NetVLAD地点识别

NetVLAD: CNN architecture for weakly supervised place recognition
2015.11论文延伸CVPR 2016Relja Arandjelović, Petr Gronat, Akihiko Torii, Tomas Pajdla, Josef Sivic · INRIA / 东京工业大学 / 捷克理工大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大规模视觉地点识别要快速认出一张照片拍摄于何处，传统的VLAD等表示不可学习，现成CNN特征又不是为这个任务训练的。

方法

把图像检索中常用的VLAD聚合做成可微的NetVLAD层，接在CNN后端到端训练；用街景时光机中同一地点不同时期的照片，以弱监督排序损失学习参数。

影响

在两个地点识别基准上大幅超过手工和现成CNN描述子，NetVLAD成为视觉定位和SLAM回环检测中最常用的全局描述子之一。

方法

VLAD（局部聚合描述子向量，Jégou等2010年提出）是图像检索的经典表示：先用k-means得到K个视觉词中心，把图中每个局部描述子（如SIFT特征）分配给最近的中心，累加它与中心的残差，得到K×D维向量再归一化。它与视觉词袋的视觉词袋、Fisher向量同属手工设计的聚合编码，硬分配不可导，无法和特征一起学习。

NetVLAD把硬分配换成软分配：每个局部特征以softmax权重 a_k(x) = softmax(w_kᵀx + b_k) 分配给各中心，残差按权重累加，于是整个层可微，能接在任意CNN的卷积特征后用反向传播训练。训练数据来自谷歌街景时光机：同一地点不同时间拍的照片，只知道大致GPS位置、不知道哪张真正对应，因此作者设计了弱监督的三元组排序损失，要求查询与最近的潜在正样本的距离小于与所有负样本的距离。

摘要称该结构在两个有挑战的地点识别基准上显著超过非学习的表示和现成CNN描述子，并在标准图像检索基准上改进了紧凑表示的最好结果。

局限与后续

  • 全局描述子对大视角变化和季节、昼夜等外观剧变仍敏感，常需再用局部特征匹配重排序。
