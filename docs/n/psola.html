PSOLA基音同步叠加

Pitch-synchronous waveform processing techniques for text-to-speech synthesis using diphones
1989.09论文延伸Eurospeech 1989；Speech Communication 1990Francis Charpentier, Eric Moulines · 法国国家电信研究中心CNET待核对
ISCA Archive ↗期刊版DOI ↗在交互版中打开（演化树、学习进度）

问题

双音子拼接合成把录好的真人语音片段接起来，音质比共振峰合成器自然，但要让同一片段配合新句子的语调和节奏，就必须改它的音高和时长，而当时的方法一改就明显失真。

方法

按基音周期把语音切成一个个重叠的短片段（每段以一个声门脉冲为中心、加窗），通过改变片段之间的间距来改音高、通过重复或删掉片段来改时长，再叠加回去。

影响

基音同步叠加（PSOLA，尤其是时域版TD-PSOLA）成为1990年代拼接合成的标准韵律修改方法，被大量商用和开源合成系统采用，直到单元选择和统计参数合成普及。

方法

Klatt共振峰合成器这类共振峰合成器用规则驱动的滤波器产生语音，可懂度高但听起来像机器。另一条路是拼接：录下一个人说的所有「双音子」（从一个音素中间到下一个音素中间的过渡段），合成时按文本把它们接起来。难点在于录音里的片段有自己的音高和长度，而新句子需要不同的语调。基于线性预测编码LPC的方法可以分开改激励和声道，但会带来嗡嗡的合成感。

PSOLA利用了浊音的周期性。先在录音里标出每个基音周期的位置（大致对应声门每次闭合的时刻），以每个标记为中心取一个约两个周期长的窗（如汉宁窗），得到一串互相重叠的短时信号。要升高音高，就把这些短时信号排得更密再叠加；要降低音高，就排得更疏。要拉长时长，就重复其中一些短时信号；要缩短就跳过一些。因为每个短时信号本身保留了原来的频谱包络（即声道形状），改变间距只改变基频，不改变音色（见傅里叶变换与频域）。时域版本几乎只需要加法，计算量极小。

论文还讨论了频域等其他变体（未逐项核对）。PSOLA让双音子合成在1990年代可以用较少的存储得到较自然的语音；之后单元选择拼接合成改为从大语料里直接挑选韵律合适的片段，尽量少做修改，以减少PSOLA带来的失真。

局限与后续

它建立在什么之上

  • 延续
    Dudley声码器与Voder1939.10 · 语音
    同属「把语音拆成激励（音高）与声道（音色）分别处理」的思路，但PSOLA不做参数化，直接操作波形片段。
  • 竞争
    线性预测编码LPC1971.08 · 语音
    基于LPC的方法通过改激励来改音高，音质偏机械；PSOLA直接在时域波形上重排片段，音质更自然。
  • 竞争
    Klatt共振峰合成器1980.03 · 语音
    共振峰合成用规则生成全部声音；PSOLA服务的拼接合成使用真人录音片段。

本篇术语

  • 双音子　从一个音素的中间到下一个音素中间的语音片段，包含了两个音之间的过渡。
  • 基音周期　浊音中声带每振动一次的时间，倒数就是基频（音高）。
  • 韵律　语音的音高起伏、时长和响度变化，决定了一句话的语调和节奏。
