FAST-LIO激光惯性滤波

FAST-LIO: A Fast, Robust LiDAR-inertial Odometry Package by Tightly-Coupled Iterated Kalman Filter
2020.10论文延伸IEEE RA-L 2021Wei Xu, Fu Zhang · 香港大学待核对
arXiv ↗FAST-LIO2（arXiv） ↗在交互版中打开（演化树、学习进度）

问题

激光-惯性融合在快速运动、噪声大或场景退化时容易失效；而用卡尔曼滤波融合上千个激光点时，增益计算量随测量维度增长，机载电脑算不动。

方法

用紧耦合的迭代扩展卡尔曼滤波融合激光特征点和IMU，并推导出一个计算量只随状态维度而非测量维度增长的卡尔曼增益公式。

影响

在四旋翼机载电脑上25毫秒内完成一次融合；后续FAST-LIO2去掉特征提取、直接配准原始点，并用增量k-d树维护地图，成为激光SLAM最常用的开源方案之一。

方法

LIO-SAM激光惯性里程计走的是因子图平滑路线，精度高但计算重；FAST-LIO选择滤波路线，在卡尔曼滤波的框架里做迭代扩展卡尔曼滤波：每来一帧扫描，用IMU传播状态，再用激光特征点到地图平面/边缘的距离作为观测，多次迭代线性化直到收敛。难点在于一帧有上千个有效观测，标准卡尔曼增益要对“测量维度×测量维度”的矩阵求逆；作者给出一个等价的新公式，求逆只涉及状态维度，计算量大幅下降。

摘要报告在四旋翼的机载电脑上，一帧融合超过1200个有效特征点，完整的一次迭代滤波步骤在25毫秒内完成。2021年的FAST-LIO2进一步直接把原始点配准到地图，不再手工提取特征，因而能适配不同扫描方式的新型激光雷达；地图用增量k-d树（ikd-Tree）维护，支持插入、删除和动态再平衡。

局限与后续
