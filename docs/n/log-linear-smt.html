对数线性翻译模型

Discriminative Training and Maximum Entropy Models for Statistical Machine Translation
2002.07论文延伸ACL 2002Franz Josef Och, Hermann Ney · RWTH Aachen University待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

统计翻译沿用噪声信道公式，只能把翻译模型和语言模型按固定方式相乘，想加入新的信息（词典、句长、短语对齐特征）都很别扭。

方法

把翻译看作对任意多个特征函数的对数线性组合，用最大熵训练权重，噪声信道只是其中一个特例。

影响

成为之后所有短语式和层次式统计机器翻译的统一框架，也催生了直接优化BLEU的参数调优（最小错误率训练MERT）。

方法

噪声信道模型把P(e|f)写成翻译模型P(f|e)乘以语言模型P(e)，两个部分各一个概率、权重固定为1。论文把它推广为：P(e|f) ∝ exp(Σ λ_m · h_m(e, f))，每个h_m是一个特征函数（可以是翻译模型对数概率、语言模型对数概率、词典得分、句子长度惩罚、短语对齐得分等），λ_m是对应权重。

这是最大熵模型在翻译上的直接应用：用最大熵原理估计权重，训练数据是源语言句子和它们的参考译文。新的信息源只需要写成一个新特征函数加进来，不必改动整个概率推导。

论文还说明，用这种判别式训练方式可以直接针对翻译质量的评测指标来调权重，而不是只最大化似然。

局限与后续

  • 特征权重虽然能调，但目标函数与BLEU这类评测指标不一致，需要专门的优化算法。
    后来针对它的工作　最小错误率训练MERT
  • 特征函数仍然要人手设计，翻译核心仍是词和短语对齐表。
    后来针对它的工作　注意力机制

它建立在什么之上

  • 延续
    IBM统计翻译模型1993 · NLP
    IBM模型的噪声信道公式成为特例，翻译与语言模型只是众多特征中的两个。
  • 改进
    噪声信道翻译模型1990.06 · NLP
    只有语言模型和翻译模型两个因子，无法加入其他有用的信息，也无法直接按翻译质量调参。
  • 使用
    最大熵模型1996 · NLP
    用最大熵（对数线性）模型组合多个特征，把最大熵建模从分类搬到整句翻译。

后来的相关工作

  • 改进
    注意力机制2014.09 · NLP
    特征函数仍然要人手设计，翻译核心仍是词和短语对齐表。
  • 使用
    GIZA++与对齐模型比较2003 · NLP
    Model 6沿用同一作者在翻译模型里采用的对数线性组合思路，把两个对齐模型的概率加权相乘。
  • 延续
    短语统计机器翻译2003.05 · NLP
    论文本身仍用噪声信道加长度因子；短语翻译概率、词汇权重、调序惩罚随后作为特征放进Och的对数线性框架，成为Pharaoh/Moses的标准形态。
  • 改进
    最小错误率训练MERT2003.07 · NLP
    对数线性模型的特征权重原来用最大互信息训练，与翻译质量关系松散，MERT改为直接最小化开发集上的评测错误。
  • 使用
    RNN编码器-解码器与GRU2014.06 · NLP
    神经网络给出的短语分数作为对数线性模型的一个新特征，与原有特征一起加权。
  • 使用
    词汇化调序模型2004.05 · NLP
    方向概率作为对数线性模型里的一个特征，与翻译概率、语言模型一起加权。
  • 使用
    最小贝叶斯风险解码MBR2004.05 · NLP
    候选的后验概率来自对数线性翻译模型的打分。
  • 使用
    Pharaoh短语解码器2004.09 · NLP
    译文得分是多种特征的对数线性组合，权重可以按开发集调整。
  • 延续
    PRO排序式调参2011.07 · NLP
    仍在对数线性翻译模型的框架内，只改变权重的学习方式。
  • 使用
    RNN中文诗歌生成2014.10 · NLP
    解码时把神经模型得分与翻译概率、n-gram特征在对数线性框架里组合。

读懂它需要的概念

语言模型 最大似然估计 逻辑回归 噪声信道与词对齐

本篇术语

  • 特征函数　输入一对源句和译句，输出一个数的函数，用来衡量某个翻译质量方面，如语言模型得分或长度比。
  • 对数线性模型　概率与各特征的加权和的指数成正比，形式与softmax回归相同。

怎么学

先会逻辑回归与softmax；读原文模型一节，理解为什么噪声信道是对数线性模型的特例；之后读短语统计机器翻译看它在短语翻译里怎么用。
