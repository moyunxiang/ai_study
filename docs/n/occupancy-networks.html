占据网络

Occupancy Networks: Learning 3D Reconstruction in Function Space
2018.12论文延伸CVPR 2019Mescheder, Oechsle, Niemeyer, Nowozin, Geiger · MPI-IS / Tübingen待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

3D重建用体素、点云或网格表示几何，要么分辨率受显存限制，要么拓扑固定。

方法

用一个神经网络表示一个3D点是在物体内部的概率，把表面看作分类器的决策边界。

影响

开启了用坐标MLP表示形状的隐式表示路线，与DeepSDF一起影响了NeRF。

方法

网络的输入是一个3D坐标和一个条件向量（来自图像、点云或体素的编码），输出是该点被物体占据的概率，在0.5处的等值面即物体表面。因为输出的是连续函数，可以在任意分辨率上查询，不需要预先划分网格，内存占用与分辨率无关。

训练时随机采样大量空间点，用二分类交叉熵监督。提取表面时可在空间里按网格查询，再用Marching Cubes等算法抽取网格。论文在单图、含噪点云、粗体素三种输入的重建任务上验证。
