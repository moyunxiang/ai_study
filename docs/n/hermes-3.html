Nous Hermes 3

Hermes 3 Technical Report
2024.08论文延伸arXiv 2024Ryan Teknium, Jeffrey Quesnelle, Chen Guang · Nous Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

主流指令模型的对齐带有厂商的价值取向和频繁拒答，用户难以通过系统提示精确控制模型行为；开放社区需要一个“中立对齐”的通用助手。

方法

在Llama 3.1基座上用大规模合成数据做指令微调，强调严格遵循系统提示、角色扮演、工具调用和结构化输出，对齐尽量保持中立。

影响

最大的Hermes 3 405B在多项公开基准上达到开放权重模型的最好水平；Hermes系列是社区微调模型中下载和使用最多的家族之一。

背景

Nous Research的Hermes系列从2023年起在Llama 2、Mistral 7B上做社区微调，OpenHermes 2.5等一度是开源SFT模型的标杆（Starling-7B与Nectar的博客里也把它列为最强SFT基线之一）。Llama 3.1 405B开放405B基座后，社区第一次可以在前沿规模的开放模型上自己做完整的后训练。

方法

Hermes 3以Llama 3.1的8B、70B、405B基座为起点。训练数据以合成数据为主，覆盖通用指令、推理与数学、代码、角色扮演、长对话、工具调用与检索增强等；作者强调模型应该对系统提示高度敏感，用户指定什么角色和规则就照做，而不是附加固定的价值判断，论文称之为“中立对齐”。训练流程以监督微调为主，并辅以偏好优化；模型还支持函数调用、结构化输出（JSON）和内部独白式的推理标签等能力。

结果

摘要称Hermes 3是具备强推理和创作能力的中立对齐通用指令与工具使用模型，其最大版本Hermes 3 405B在若干公开基准上达到开放权重模型中的最好成绩。

后来的发展

它代表了社区微调路线在前沿规模上的一次实践，也引发了关于“中立对齐”与安全拒答之间权衡的讨论；后续Nous Research继续推出Hermes 4等版本。

怎么学

先读Llama 3.1 405B；读Hermes 3报告的数据构成和中立对齐一节；动手：用不同系统提示让Hermes 3 8B扮演不同角色，观察遵循程度。
