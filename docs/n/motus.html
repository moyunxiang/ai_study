Motus潜动作世界模型

Motus: A Unified Latent Action World Model
2025.12论文延伸arXiv 2025Hongzhe Bi, Hengkai Tan, Shenghao Xie, Zeyuan Wang 等（16位）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

理解、世界建模、控制各自用独立模型，阻碍了统一多模态生成能力，也难以利用大规模异构数据。

方法

用三专家的混合Transformer（理解、视频生成、动作），配合UniDiffuser式调度，一个模型可在世界模型、VLA、逆动力学、视频生成、视频动作联合预测模式间切换；用光流学习潜动作。

影响

摘要称仿真中比X-VLA高15%、比π0.5高45%，真实场景提升11到48%。

方法

UWM统一世界模型把视频与动作扩散耦合，Motus继续统一。核心有三点：Mixture-of-Transformer，让理解、视频生成、动作三类专家共享注意力；UniDiffuser式调度，通过对不同模态采不同噪声水平，使同一网络既能做条件生成也能做逆动力学；光流潜动作，从光流中提取像素级的「delta action」，使没有动作标签的视频也能做大规模动作预训练。训练分三阶段，并用六层数据金字塔组织从网络视频到机器人轨迹的数据。设计与Genie用潜动作学交互环境的想法相通。
