最大熵逆强化学习

Maximum Entropy Inverse Reinforcement Learning
2008论文延伸AAAI 2008Ziebart, Maas, Bagnell, Dey · Carnegie Mellon University待核对
CMU RI页面 ↗在交互版中打开（演化树、学习进度）

问题

学徒学习里许多奖励都能解释同一批演示，歧义严重；专家演示往往也不是严格最优的。

方法

用最大熵原理：在匹配专家特征期望的所有轨迹分布里，选熵最大的那个，轨迹出现的概率与其累计奖励的指数成正比。

影响

给IRL一个良好定义的概率模型，并可用梯度训练，成为后来深度IRL、GAIL、RLHF中奖励模型的概率基础。

方法

约束是：学到的轨迹分布，其特征期望要等于专家演示的特征期望。在这个约束下取最大熵，结果是 P(τ) ∝ exp(wᵀφ(τ))：累计奖励越高的轨迹概率越大，奖励相同的轨迹概率相同，没有额外偏好，歧义因此被消除。训练就是对 w 做梯度上升以最大化专家轨迹的似然，梯度等于「专家的特征期望 − 当前模型下的特征期望」，后者用动态规划（前后向算法）计算。

摘要称该方法给出一个全局归一化的决策分布，保持与已有方法相同的性能保证，并用于真实的路径导航建模。

局限与后续

  • 每一步梯度都要在当前奖励下做一次软最优规划，大状态空间代价很高，并且要已知环境动力学。
    后来针对它的工作　GAIL
  • 奖励仍假设为已知特征的线性组合。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    逆强化学习IRL2000 · RL
    把IRL写成概率模型上的最大似然问题。
  • 改进
    学徒学习2004 · RL
    把「多种奖励同样解释演示」的歧义，通过最大熵原则消除，并容忍次优演示。

后来的相关工作

  • 改进
    GAIL2016.06 · RL
    证明最大因果熵IRL加RL等价于占用度量匹配，绕开了“每次更新代价都要在内层跑完一遍RL”的昂贵循环。
  • 延续
    引导代价学习GCL2016.03 · RL
    保留最大熵IRL的概率模型，用样本估计配分函数，并把线性代价换成神经网络。
  • 使用
    软Q学习（能量策略）2017.02 · RL
    沿用最大熵框架下策略呈玻尔兹曼分布的形式，把它从逆RL用到正向控制。
  • 使用
    AIRL对抗逆强化学习2017.10 · RL
    判别器的最优解对应最大熵IRL意义下的奖励与优势。
  • 竞争
    T-REX排序奖励外推2019.04 · RL
    最大熵IRL让示范在玻尔兹曼分布下最可能；T-REX只要求更好的轨迹累计奖励更高。
  • 延续
    f-MAX散度最小化模仿2019.11 · RL
    延续最大熵IRL把模仿写成分布匹配的思路，统一到f-散度框架中。
  • 延续
    ValueDICE离策略模仿2019.12 · RL
    同属分布匹配视角下的模仿/逆RL，但不再显式恢复奖励。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

信息量与熵 最大似然估计 模仿学习与行为克隆 动态规划 奖励设计与奖励投机

怎么学
