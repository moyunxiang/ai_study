自然梯度

Natural Gradient Works Efficiently in Learning
1998论文延伸Neural Computation 1998Shun-ichi Amari · RIKEN Brain Science Institute待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

普通梯度下降隐含地认为参数空间是平坦的欧氏空间，但同样大小的参数改变对模型输出分布的影响差别很大，导致训练慢、容易被平台困住。

方法

把模型看作概率分布构成的流形，用Fisher信息矩阵定义这个空间的距离，沿着“分布空间里最陡”的方向走，即把梯度左乘Fisher矩阵的逆。

影响

给二阶优化提供了信息几何的原理，之后的Hessian-free、K-FAC、Shampoo等方法都可以看作对自然梯度的近似或类比。

方法

设模型输出分布为p(y|x;θ)。普通梯度下降更新θ ← θ − η∇L，它用的是参数的欧氏距离。Amari指出，真正有意义的距离是两个分布之间的差异（KL散度，见KL散度），其二阶近似由Fisher信息矩阵F给出。

在这个由F定义的黎曼度量下，最陡下降方向是F⁻¹∇L，称为自然梯度，更新为θ ← θ − η F⁻¹ ∇L。它对参数的重新参数化不敏感：同一个模型换一种写法，自然梯度走出的分布轨迹不变。

论文针对神经网络学习（尤其是存在平台期的多层感知机）说明，自然梯度在统计意义上接近Fisher有效，并有机会缓解平台。同时作者提出可以在线估计F⁻¹的自适应算法，避免每步重新求逆。

局限与后续

  • Fisher矩阵有参数个数平方那么大，对数百万参数的网络无法存储也无法求逆。
    后来针对它的工作　K-FAC Shampoo
  • 精确的Fisher需要对输出分布求期望，估计它本身带噪声、计算量大，论文只给出小网络的演示。
    后来针对它的工作　Hessian-free优化 K-FAC

后来的相关工作

  • 竞争
    Adam2014.12 · 基础 已核对
    论文指出二阶矩是对Fisher信息矩阵对角线的近似，Adam用它的平方根倒数做预条件，比标准自然梯度的调整更保守。
  • 使用
    自然策略梯度2001 · RL
    把Amari为概率模型提出的Fisher信息度量搬到策略上，并按状态访问分布加权。
  • 使用
    EWC弹性权重巩固2016.12 · 基础
    借用自然梯度中的Fisher信息矩阵来度量每个参数对旧任务的敏感程度。
  • 延续
    CMA-ES进化策略2001.06 · 基础
    后来的分析表明CMA-ES的均值与协方差更新近似是对采样分布参数的自然梯度下降，与自然进化策略相通。
  • 使用
    Hessian-free优化2010.06 · 基础
    用高斯-牛顿近似（与Fisher矩阵紧密相关）作曲率矩阵，在每步用CG求近似自然梯度方向。
  • 使用
    随机变分推断SVI2012.06 · 基础
    每一步沿ELBO的自然梯度方向更新，在共轭模型里这一步形式非常简单。
  • 竞争
    高维优化的鞍点问题2014.06 · 基础

读懂它需要的概念

梯度下降 KL散度 雅可比矩阵与海森矩阵 最大似然估计 随机梯度下降与小批量

本篇术语

  • Fisher信息矩阵　对数似然梯度的协方差，衡量改变某个参数会让模型输出分布变化多大，也是KL散度的局部二阶近似。

怎么学

先学KL散度和雅可比矩阵与海森矩阵，再读论文前几节的核心推导。之后读K-FAC看如何把它变得可算。动手：在一个两参数的逻辑回归上对比梯度下降与自然梯度的轨迹。
