黑箱变分推断BBVI

Black Box Variational Inference
2013.12论文延伸AISTATS 2014Rajesh Ranganath, Sean Gerrish, David M. Blei · 普林斯顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

给每个新的概率模型推导变分推断算法都需要大量针对模型的数学推导，非共轭模型更是难以下手，研究者很难快速尝试不同模型。

方法

只要求能对联合概率取对数、能从变分分布抽样并对其对数密度求导，就用蒙特卡洛样本估计ELBO的梯度并做随机优化；再配上Rao-Blackwell化和控制变量降低梯度方差。

影响

让变分推断变成几乎与模型无关的“黑箱”工具，与同期的重参数化梯度一起构成了概率编程（如Edward、Pyro）里自动变分推断的基础。

方法

ELBO是L(λ) = E_q[log p(x,z) − log q(z;λ)]。关键恒等式是∇_λ L = E_q[∇_λ log q(z;λ) · (log p(x,z) − log q(z;λ))]，右边只需要从q里抽样、计算模型的对数联合概率和q的得分函数，完全不用对模型求导或推导期望的闭式解。于是可以抽S个样本求平均，得到梯度的无偏估计，再用随机优化更新变分参数λ。

朴素估计的方差很大，作者提出几种不依赖模型推导的降方差手段：按平均场分解做Rao-Blackwell化，每个变分因子只用与它相关的项；用得分函数本身作控制变量。摘要报告：与对应的黑箱采样方法相比，它更快达到更好的预测似然，并用它快速构建和比较了纵向医疗数据上的若干模型。

局限与后续

  • 得分函数梯度即使降方差后方差仍较大，收敛慢；对连续隐变量，重参数化梯度通常方差小得多。
