SQuAD

SQuAD: 100,000+ Questions for Machine Comprehension of Text
2016.06数据集重要EMNLP 2016Pranav Rajpurkar, Jian Zhang, Konstantin Lopyrev, Percy Liang · 斯坦福大学待核对
arXiv 1606.05250 ↗SQuAD官网与排行榜 ↗在交互版中打开（演化树、学习进度）

问题

阅读理解数据要么由人精心编写但只有几百篇（如MCTest），要么由程序自动生成完形填空题，规模大但题目不自然、难度偏低。

方法

从维基百科挑出536篇高质量文章，请众包工作者针对每个段落提问，并在原文中划出答案片段；共得到10万多个问答对，答案必须是原文中的一段连续文字，便于自动评分。

影响

SQuAD成为神经阅读理解的标准考场，排行榜上的竞争催生了Match-LSTM、BiDAF、DrQA等模型；2018年BERT在上面超过人类基准，它也因此成了预训练语言模型必报的任务。

背景

让机器“读一段文字再回答问题”是检验语言理解的直观方式，但缺好数据。MCTest由人写了660个小故事、每篇4道选择题，质量高但只有约2600道题，训练不了神经网络。另一类是自动构造：CNN/Daily Mail数据集把新闻要点句中的实体挖空让模型填（注意力阅读器与CNN/DM用的就是它），bAbI用程序生成简单的合成故事。它们规模可以很大，但题目不像人会问的问题，后续分析发现很多题只需很浅的推理。

作者想要两者兼得：问题是人写的、自然多样，规模又足以训练神经网络，同时答案能自动客观地评分。

方法

选文章。用维基百科内部的PageRank排名取前1万篇英文文章，从中随机抽取536篇（见维基百科语料），切成23,215个段落，按文章划分为训练80%、开发10%、测试10%。

众包提问。通过Daemo平台（后台是众包标注Mechanical Turk）招募美国和加拿大、历史通过率高的工作者，时薪9美元，每个段落约花4分钟，针对内容提出并回答最多5个问题。答案必须在段落中划出一段连续的文字。界面上禁止复制粘贴，并提示用自己的话提问，避免问题照抄原文。

多答案。开发集和测试集的每个问题再请至少两位工作者独立划出答案，用于评分和估计人类水平。

评测。两种指标，都先去掉标点和冠词：精确匹配EM（预测与任一标准答案完全相同的比例）；F1（把预测和答案当作词袋，计算词重叠的F1，取与各标准答案中的最大值再平均）。

分析。答案中名词短语约32%，人名、地点、日期、数字等实体合计约一半；大多数问题与答案所在句子之间存在同义替换或句法变换。

结果

最终共107,785个问答对。滑动窗口匹配基线的F1约20%；作者构造的逻辑回归模型使用了词汇、依存句法路径等大量特征，测试集EM 40.4%、F1 51.0%；人类在测试集上EM 77.0%、F1 86.8%。逻辑回归能以79.3%的准确率选中答案所在的句子，难点主要在于找准句中的片段；问题与答案句的句法差异越大，模型表现越差，而人基本不受影响，说明数据集确实考察了改写和句法变化。

后来的发展

SQuAD发布后的两年里，排行榜几乎每月刷新：Match-LSTM与答案指针、BiDAF双向注意力流把注意力用于在段落中定位答案，DrQA开放域问答把它与维基百科检索结合做开放域问答。2018年BERT在SQuAD v1.1测试集上F1达到93.2，超过了人类基准。与此同时它的缺陷也被揭示：Jia和Liang在段落末尾插入一句干扰句，16个已发表模型的平均F1就从75%跌到36%；由于每题都保证有答案，模型从不需要说“不知道”。于是有了加入5万多个无答案问题的SQuAD 2.0，以及取材于真实搜索的MS MARCO、Natural Questions，多跳推理的HotpotQA多跳问答，对话式的CoQA对话问答。

容易误解的地方

  • “超过人类”是指超过论文里由众包工作者测出的人类基准，而人类分数被同一问题的多个答案划法不一致压低了，并不代表模型阅读理解能力超过人。
  • 提问者是看着段落写问题的，问题与原文用词高度重叠，这让基于词匹配的捷径格外有效。

局限与后续

  • 每个问题都保证在段落中有答案，模型只需挑出最像的一段文字，从不需要判断“文中没有答案”。
    后来针对它的工作　SQuAD 2.0
  • 问题是看着段落写的，与原文措辞高度重合；在段落中插入一句无关的相似句，模型就大面积失败。
    后来针对它的工作　Natural Questions 对抗式NLI
  • 答案限定为一个段落里的连续片段，不考察跨段落、多步推理，也不考察需要生成或计算的答案。
    后来针对它的工作　HotpotQA多跳问答 DROP数值推理
  • 只给定单个段落，不涉及从大量文档中先找到相关内容的检索问题。
    后来针对它的工作　DrQA开放域问答 MS MARCO

它建立在什么之上

  • 改进
    注意力阅读器与CNN/DM2015.06 · NLP
    CNN/Daily Mail这类自动挖空的完形填空题不自然、推理浅；SQuAD用人写的问题取代了它，同时保持了足够大的规模。
  • 使用
    维基百科语料2001.01 · 数据·评测
    从PageRank最高的1万篇英文维基百科文章中抽取536篇作为阅读材料。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测
    通过以亚马逊众包为后台的Daemo平台招募工作者提问和划答案。
  • 改进
    bAbI2015.02 · 数据·评测
    bAbI是程序生成的合成故事，SQuAD改用真实百科文本和人写问题，考察真实语言中的改写与句法变化。
  • 改进
    端到端记忆网络2015.03 · NLP
    记忆按句子独立编码、位置信息处理粗糙，只在合成问答和小规模语言建模上验证，真实阅读理解上还差得远。

后来的相关工作

  • 使用
    BERT2018.10 · LLM 已核对
    抽取式问答基准，用起点/终点两个向量直接从原文中标出答案。
  • 使用
    ELMo2018.02 · LLM 已核对
    在SQuAD等六个基准上验证，问答任务提升最大。
  • 改进
    MS MARCO2016.11 · 数据·评测
    SQuAD的问题是看着段落写的、保证有答案；MS MARCO改用真实用户查询，允许无答案，并要求从多个网页段落中综合答案。
  • 使用
    BiDAF双向注意力流2016.11 · NLP
    主要在SQuAD上评测，输出层专门为“预测答案片段起止位置”设计。
  • 使用
    DrQA开放域问答2017.03 · NLP
    用SQuAD训练阅读器，并把SQuAD开发集的问题拿掉段落，改成全维基百科上的开放域问答评测。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测
    QNLI任务由SQuAD改造：判断上下文中的某个句子是否包含问题的答案。
  • 使用
    语言模型即知识库2019.09 · LLM
    从SQuAD开发集挑出305个与上下文无关、答案为单词的问题，改写成完形填空句。
  • 使用
    Match-LSTM与答案指针2016.08 · NLP
    以SQuAD为训练和评测数据。
  • 改进
    RACE考试阅读理解2017.04 · 数据·评测
    SQuAD的答案都是原文片段、多数题靠匹配可答；RACE用教师出的四选一题，选项不一定出现在原文，推理题比例约59%对SQuAD的20.5%。
  • 改进
    TriviaQA2017.05 · 数据·评测
    SQuAD 的问题写自段落、词面重合过高，TriviaQA 的问题独立写成、证据独立收集，难度更接近真实。
  • 竞争
    AI2 ARC科学题2018.03 · 数据·评测
    SQuAD 的答案就在文本里，ARC 要求外部知识与推理，针对 SQuAD 式基准过于容易的问题。
  • 延续
    SQuAD 2.02018.06 · 数据·评测
    在 SQuAD 1.1 上加入无法回答的问题，要求模型能弃权。
  • 延续
    CoQA对话问答2018.08 · 数据·评测
    把 SQuAD 的单轮问答扩展为多轮对话，加入指代与上下文依赖。
  • 延续
    HotpotQA多跳问答2018.09 · 数据·评测
    把 SQuAD 的单段抽取扩展为多文档、多跳推理，并增加句子级证据。
  • 改进
    Natural Questions2019.01 · 数据·评测
    SQuAD 的问题是读着段落写的，NQ 改用真实搜索查询，避免与证据词面过度重合。
  • 改进
    DROP数值推理2019.03 · 数据·评测
    SQuAD 只需要抽取一段文字，DROP 要求对段落内容做离散运算。
  • 延续
    PubMedQA生物医学问答2019.09 · 数据·评测
    同属给定段落的阅读理解，但答案不是从原文抽取片段，而要根据摘要中的数据推断出是、否或也许。
  • 改进
    对抗式NLI2019.10 · 数据·评测
    问题是看着段落写的，与原文措辞高度重合；在段落中插入一句无关的相似句，模型就大面积失败。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

监督学习 准确率、精确率、召回率与F1 注意力机制 嵌入向量 基准、排行榜与SOTA

本篇术语

  • 抽取式问答　答案必须是给定文本中的一段原文，模型只需预测这段文字的起点和终点位置。
  • EM与F1　EM要求预测与标准答案一字不差；F1把两者看成词的集合，按重叠词计算精确率和召回率的调和平均，允许部分正确。

怎么学

先补注意力机制和准确率、精确率、召回率与F1。读原文第3节（数据收集）和第6节（评测与人类表现）。动手：用Hugging Face加载SQuAD，微调一个小型BERT预测答案的起止位置，算出EM和F1；再手工在几个段落末尾加一句与问题相似的干扰句，观察模型是否被误导。
