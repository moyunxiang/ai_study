Beyond Ten Turns: Unlocking Long-Horizon Agentic Search with Large-Scale Asynchronous RL
2025.08论文延伸Jiaxuan Gao, Wei Fu, Minyang Xie, Shusheng Xu, Chuyi He, Zhiyu Mei, Banghua Zhu, Yi Wu · 清华大学交叉信息研究院 / 蚂蚁集团 / 华盛顿大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

用强化学习训练搜索智能体的开源工作（如Search-R1）通常把每条轨迹限制在10轮以内：批量生成时，一条特别长的轨迹会让整批等待、GPU空转；而且训练用的HotpotQA这类数据又旧又简单，激发不出复杂的搜索策略。

方法

基于AReaL做全异步RL训练，把轨迹执行和模型更新解耦，长轨迹不再拖住训练，于是可以放宽到每条128轮；再用一个LLM智能体自动合成难题：从种子问题出发，反复“注入”外部事实增加复杂度、或“模糊”关键信息增加不确定性，并多阶段验证。

影响

训练中智能体的工具调用超过100轮、生成超过40万词元；QwQ-32B智能体经RL后在xBench和GAIA上Avg@4分别为51.1和58.7，超过同规模开源智能体；模型、数据和代码全部开源，成为长程搜索智能体RL的常用基线与训练框架。

背景

Search-R1证明了用结果奖励的RL能教模型调用搜索引擎，DeepResearcher真实网络RL、WebDancer信息检索智能体、WebSailor高不确定性检索把训练搬到真实网络并合成更难的数据。但学术界的训练系统多为同步批量生成，轮数一放开，少数长轨迹就让效率崩溃。AReaL异步RL训练提出的异步RL训练系统为此提供了基础。

方法

智能体设计：工具只有搜索引擎和网页浏览器（读网页时由模型自己总结），不依赖外部更强的LLM。两种设置：从Qwen2.5-7B/14B基础模型直接RL；以及微调一个基于大推理模型QwQ-32B的提示式智能体。

全异步RL：生成端的每条轨迹独立运行，随时把完成的轨迹送去训练；训练端更新后把新权重推给生成端，正在跑的轨迹不必等整批结束。这样单条轨迹可以有128轮的上限，而训练吞吐不受最长轨迹拖累。

问答合成智能体：从一个种子问答出发，智能体迭代地做两种修改：

  • 注入：查找与问题实体相关的外部事实加进问题，例如把“某部电影的导演是谁”改成“某年获某奖、改编自某小说的电影的导演是谁”，需要多跳检索；
  • 模糊：把问题里的具体信息改得含糊（如具体年份改成“二十世纪初”），增加不确定性。

每次修改后都检查问题是否仍有唯一答案、是否足够难（例如强模型不搜索就答不出）。从1.4万个种子生成了13.4万个高质量问答，其中2.56万个必须借助外部工具才能解。

结果：RL使QwQ-32B智能体在GAIA、xBench、Frames上分别提高15.0、22.4、15.6分；只用本地知识库训练的7B/14B模型也能迁移到真实网络搜索。

后来的发展

长轨迹、全异步、自动合成难题成为2025年下半年开源搜索与深度研究智能体训练的共同配方，与Kimi-Researcher端到端RL、通义DeepResearch的做法相互印证。

本篇术语

  • 全异步RL　生成轨迹和更新模型同时进行、互不等待；代价是部分轨迹由稍旧的模型版本生成。
  • Avg@4　每道题独立跑4次，取平均正确率，用来减小单次运行的随机波动。
