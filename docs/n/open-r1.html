Open-R1与R1复现潮

2025.01系统延伸Hugging Face · Hugging Face待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

DeepSeek-R1公开了结果和技术报告，但没有公开训练数据和完整训练代码，外界无法复现。

方法

Hugging Face发起完全开放的R1复现：按技术报告分步重现蒸馏、纯RL和多阶段训练，并公开数据与代码。

影响

带动了2025年初一波R1复现，并留下了公开的推理数据集和训练脚本。

方法

项目自称是「DeepSeek-R1的完全开放复现」，按技术报告分成三步：第一步，从R1蒸馏高质量语料，复现R1-Distill模型；第二步，复现DeepSeek用来得到R1-Zero的纯RL流程，需要整理大规模数学、推理和代码数据；第三步，证明可以通过多阶段训练从基座走到RL调优。

代码仓库提供grpo.py（用GRPO训练）、sft.py（监督微调）和用于生成合成数据的generate.py。第一步在2025年5月26日宣布完成，发布了Mixture-of-Thoughts数据集：35万条经验证的、从R1蒸馏的推理轨迹，覆盖数学、代码和科学。项目如今已不再维护，训练部分由TRL库承接。

后来的发展

它与DAPO等开源RL方案一起，使「训练一个推理模型」从大厂独有变成社区可做的事；训练代码并入TRL后，GRPO成为开源工具链的标准部件。

局限与后续
