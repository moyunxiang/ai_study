OpenAI Realtime API

2024.10系统延伸OpenAI待核对
HN讨论 ↗OpenAI 2025音频模型公告 ↗在交互版中打开（演化树、学习进度）

问题

开发者要做语音助手，必须自己串联识别、LLM、合成三个模型，延迟高，也难处理打断。

方法

提供一个按流式连接的API，直接以语音输入输出，由GPT-4o全模态实时模型在一个模型内处理，并支持被打断。

影响

第一次让开发者能用一个API构建低延迟的语音到语音应用，催生大量语音代理产品和相关基础设施。

方法

OpenAI在2024年10月初宣布Realtime API（HN聚合的当日消息日期为2024-10-01，原始来源为社交媒体转载；OpenAI官方页面当时无法抓取，细节未逐条核对）。它让应用通过持久连接发送音频，由GPT-4o类模型直接生成语音回复，无需把语音先转文字再合成，从而降低延迟、保留语气，并能处理用户打断。

据OpenAI 2025年3月20日的公告页，2025年8月28日该API正式发布（GA）。此后它成为语音代理开发的常用接口，LiveKit等第三方也快速提供了配套工具。

局限与后续

  • 底层仍是回合制模型，依靠静音检测判断说话是否结束，会在停顿时被误判打断；长对话的成本较高。
