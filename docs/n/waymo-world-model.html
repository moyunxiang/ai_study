The Waymo World Model: A New Frontier For Autonomous Driving Simulation
2026.02模型延伸官方博客 2026-02Chiyu Max Jiang, Xander Masotto, Bo Sun 等 · Waymo待核对
官方页面 ↗在交互版中打开（演化树、学习进度）

问题

自动驾驶模拟器若只用自家路测数据训练，就学不到从未遇到过的罕见场景，也难以同时产出相机和激光雷达数据。

方法

以DeepMind的通用世界模型Genie 3为底座，针对驾驶做专门后训练，把2D视频中的世界知识迁移到Waymo传感器套件的3D激光雷达输出，生成相机加激光雷达的多传感器仿真。

影响

官方称可以用语言提示、驾驶输入和场景布局来改变仿真，并模拟龙卷风、大象等极罕见事件。

方法

博客发布于2026年2月6日，称Waymo Driver已完成近2亿英里完全自动驾驶，并在虚拟世界里跑数十亿英里。世界模型是其「三大安全支柱」之一仿真的核心。

与GAIA-2这类只从自家驾驶视频训练的模型相比，Waymo World Model借助Genie 3在海量多样视频上预训练得到的世界知识，因此能探索车队从未观测到的情形。它的输出是高保真的多传感器数据，包括相机和激光雷达，用于测试Waymo Driver在边缘场景下的反应。可控性包括语言提示、驾驶输入和场景布局三种。

它建立在什么之上

  • 改进
    Tesla FSD v12端到端2024.03 · 具身·世界模型 已核对
    模仿人类驾驶只能学到数据里出现过的行为，罕见危险场景样本极少，长尾问题依然存在。
  • 改进
    CARLA驾驶仿真器2017.11 · 具身·世界模型
    首版只有两座总长约4公里的小城镇，场景单一；其他车辆和行人的行为由简单规则控制，远不如真实交通多样。
  • 改进
    Waymo EMMA2024.10 · 具身·世界模型
    主要做开环评测；闭环评测需要逼真且昂贵的传感器仿真。
  • 延续
    Genie 32025.08 · 具身·世界模型
    以Genie 3为底座，加入驾驶专用后训练和激光雷达输出。
  • 改进
    Waymo全无人驾驶开放运营2020.10 · 具身·世界模型
    只在已绘制高精地图的有限区域运营，扩展到新城市较慢。
  • 改进
    Vista驾驶世界模型2024.05 · 具身·世界模型
    生成的视频仍是视觉层面的预测，缺少对3D几何和物理的显式建模。
  • 竞争
    GAIA-22025.03 · 具身·世界模型
    同为驾驶生成式世界模型；Waymo借助通用世界模型的知识，GAIA-2则从驾驶数据专门训练。
  • 改进
    Tesla Robotaxi上线2025.06 · 具身·世界模型
    纯视觉端到端路线在安全性上缺少公开、可比的统计，监管和事故调查仍在进行。
  • 改进
    Alpamayo-R1驾驶VLA2025.10 · 具身·世界模型
    额外的推理生成增加延迟与算力，长尾场景的覆盖仍受数据限制。
