DianNao神经网络加速器

DianNao: A Small-Footprint High-Throughput Accelerator for Ubiquitous Machine-Learning
2014.03论文重要ASPLOS 2014陈天石、杜子东、孙凝晖、王佳、吴承勇、陈云霁、Olivier Temam · 中国科学院计算技术研究所 / Inria待核对
ACM（DOI） ↗原文PDF（存档） ↗在交互版中打开（演化树、学习进度）

问题

早期神经网络加速器只优化乘加运算、几乎不管内存，而新的卷积网络和深度网络动辄上百万参数，数据搬运会吃掉专用硬件的全部优势。

方法

从内存出发设计加速器：把每层计算切成小块，配三块专用片上缓冲区分别存输入、输出和权重，用16位定点乘法器加加法树组成流水线，并按分块方式调度DMA读写主存。

影响

在3mm²的面积里做到452 GOP/s、比2GHz的SIMD处理器快约118倍，此后出现了一系列DianNao家族设计和大量深度学习加速器研究，团队还据此创办了寒武纪。

背景

2011年的暗硅研究指出，受功耗限制，芯片上的晶体管不能同时全部通电，与其继续堆通用核心，不如加上效率高得多的专用加速器。同时，卷积网络和深度网络迅速成为识别等任务上最好的方法，而它们的核心计算种类很少，正适合做专用硬件。

更早的神经网络芯片（如贝尔实验室ANNA芯片）和当时多数加速器论文都只专注把乘加做快，要么忽略内存传输，要么简单地用DMA把计算单元接到内存上。作者认为网络变大以后会出现“Amdahl定律效应”（Amdahl定律）：计算再快，总时间和能耗也会被内存传输卡住，即内存墙。

方法

分块。全连接层要对Nn个输出神经元、每个Ni个输入做乘加，卷积层还要在二维特征图上滑动。作者先分析这些循环的数据复用方式，把它们按Ti个输入、Tn个输出切块，使每块需要的数据刚好放进片上缓冲区，从而大幅降低对主存的带宽需求。

三块专用缓冲区。NBin存输入神经元，NBout存输出神经元的部分和，SB存权重。三者分开，各配一个DMA，宽度按计算单元一次要读的数据量定制，比通用缓存省掉了标签比较和多路组相联的开销。片上RAM总共只有44KB。

神经功能单元（NFU）。分三级流水：第一级是Tn×Ti个乘法器（作者取Tn=Ti=16，即256个），第二级是加法树把乘积求和，第三级用16段分段线性函数近似sigmoid等激活函数。每个周期完成496次16位定点运算。

16位定点。作者在UCI数据集和MNIST上验证，16位定点与32位浮点精度相当；而16位定点乘法器的面积约为32位浮点乘法器的1/6、功耗约1/7。

结果

在台积电65nm工艺上完成布局布线：每1.02ns完成496次16位定点运算，即452 GOP/s；面积3.02mm²，功耗485mW（不含主存）。在近期网络中最大的10个层上，比2GHz、128位SIMD处理器平均快117.87倍，计入主存访问后能耗低21.08倍。作者指出，这个能效比此前报告的几百倍小一个数量级，因为别人没算主存访问；现在能耗主要花在读写主存上。

后来的发展

这篇论文之后，同一团队又做了面向大规模网络的DaDianNao等后续设计，统称DianNao家族；2016年团队成立寒武纪成立（寒武纪）把这条技术路线商品化；此后手机芯片里也出现了专用的神经网络单元（手机NPU：麒麟970与A11）。

学术界随即掀起深度学习加速器研究：Eyeriss数据流加速器系统研究片上数据复用的“数据流”，EIE稀疏推理引擎加速剪枝压缩后的稀疏网络并与DaDianNao比较。工业界方面，谷歌的Google TPU论文把DianNao系列列为主要相关工作，用脉动阵列做成了数据中心规模的推理芯片。

它建立在什么之上

  • 使用
    Amdahl定律1967.04 · 硬件
    论文用Amdahl定律说明：只加速计算而不管内存传输，加速比和能效会被传输部分封顶。
  • 改进
    Dennard缩放定律1974.10 · 硬件
    缩放红利失效后，芯片上更多的晶体管不能同时全速运行，通用处理器的能效进步大幅放缓。
  • 竞争
    脉动阵列1982.01 · 硬件
    同是为矩阵类运算做专用硬件，DianNao用乘法器阵列加加法树，后来的TPU选择让数据在阵列中逐拍流动的脉动结构；两种数据通路至今都在使用。
  • 改进
    内存墙1995.03 · 硬件
    把内存当作一等设计目标，用分块和三块专用缓冲区减少主存访问，在加速器层面应对内存墙。
  • 改进
    RISC精简指令集1980.10 · 硬件
    通用标量处理器的指令流水线对深度学习中的大规模张量运算仍然效率太低，需要专用硬件。
  • 延续
    贝尔实验室ANNA芯片1992 · 硬件
    早期神经网络芯片主要优化运算本身；DianNao面对的是大得多的现代网络，把重心转到内存与数据复用。
  • 改进
    暗硅2011.06 · 硬件
    暗硅研究指出通用多核到头、应转向专用加速器，但没说做什么；DianNao给出了神经网络这一具体答案。

后来的相关工作

  • 竞争
    Google TPU2016.05 · 硬件 已核对
    论文在相关工作中讨论了DianNao系列：它们靠小规模乘加阵列和尽量把权重留在片上来减少访存，TPU则用65536个乘加单元的大阵列加片外权重内存，面向数据中心真实负载。
  • 改进
    TPU v2/v3与TPU Pod2017.05 · 硬件
    只做推理，不支持训练；作者把在硬件上实现训练列为未来工作。
  • 延续
    DaDianNao机器学习超算2014.12 · 硬件
    同一团队的下一篇，从单芯片加速器扩展到多芯片“机器学习超级计算机”。
  • 改进
    ShiDianNao传感器旁的CNN加速器2015.06 · 硬件
    DianNao的能效仍受DRAM访问限制；ShiDianNao把权重放进SRAM、把加速器放到传感器旁，消除了DRAM访问。
  • 竞争
    EIE稀疏推理引擎2016.02 · 硬件
    DianNao系列处理稠密网络，EIE处理稀疏压缩网络，并与DaDianNao比较。
  • 延续
    寒武纪成立2016.03 · 硬件
    把DianNao系列的学术加速器架构产品化，成立公司并走IP授权加自研芯片的路线。
  • 改进
    Eyeriss数据流加速器2016.06 · 硬件
    在DianNao用专用单元加速神经网络的基础上，系统地讨论片上数据复用与数据流。
  • 改进
    Cambricon神经网络指令集2016.06 · 硬件
    DianNao系列的指令对应固定的高层功能块，灵活性不足；Cambricon用精简的通用指令集让同一硬件支持多种网络。
  • 竞争
    PRIME：ReRAM主存内计算2016.06 · 硬件
    以DianNao一类数字神经处理单元为对照基线，展示存内计算的潜在优势。
  • 使用
    手机NPU：麒麟970与A112017.09 · 硬件
    把学术上的神经网络专用加速器架构落地为手机SoC的一个模块。

读懂它需要的概念

晶体管、制程与摩尔定律 显存、内存带宽与“内存墙” 卷积层、池化与感受野 多层感知机 量化 浮点精度：FP32、FP16、BF16、INT8

本篇术语

  • GOP/s　每秒十亿次运算。这里的运算是16位定点的乘法或加法，不是浮点运算，所以不能直接和GPU的GFLOPS比较。
  • 定点数　小数点位置固定的整数表示，比如16位里留若干位表示小数。运算电路比浮点简单得多，但能表示的数值范围有限。
  • 加法树　把很多个乘积两两相加、逐层合并的加法器结构，16个数相加只需4级，适合做内积。

怎么学

先读卷积层、池化与感受野、显存、内存带宽与“内存墙”和量化。然后读原文第3节（各类层的分块与带宽需求，图5–8的循环代码）和第5节（加速器结构，图11）。动手：用Python写出全连接层的分块循环，统计不同Ti、Tn下需要从主存读多少字节，画出带宽需求随块大小的变化；再读Eyeriss数据流加速器和Google TPU，比较三者怎样复用数据。
