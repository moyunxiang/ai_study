R1-Searcher搜索RL

R1-Searcher: Incentivizing the Search Capability in LLMs via Reinforcement Learning
2025.03论文延伸Huatong Song, Jinhao Jiang, Yingqian Min, Jie Chen, Zhipeng Chen, Wayne Xin Zhao, Lei Fang, Ji-Rong Wen · 中国人民大学高瓴人工智能学院 / 九章云极DataCanvas待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

R1式推理模型只靠参数里的知识，遇到时效性强或知识密集的问题容易答错编造；让模型在推理中调用搜索，以往要靠提示词或蒸馏数据冷启动。

方法

完全用结果奖励的强化学习、分两个阶段：先只奖励“会按格式发起检索”，再奖励答案F1，让模型自己学会何时检索、检索什么；检索回来的文字不参与梯度。

影响

与同月的Search-R1一起，说明不需要过程奖励和冷启动蒸馏，只用RL就能教会7B/8B模型在推理中使用搜索，并能迁移到真实网页搜索。

方法

DeepSeek-R1证明结果奖励的RL能教会模型长推理；Search-o1让推理模型在思考中途调用搜索，但只靠提示。R1-Searcher直接用RL训练这种行为。

两阶段奖励。第一阶段只给检索奖励（至少发起一次检索得0.5）和格式奖励，不看答案对错，先让模型学会用规定标签发出查询；第二阶段去掉检索奖励，改为按答案F1给分，格式错误罚−2。

算法。主算法是改造过的REINFORCE++：生成过程中遇到查询就调用检索器，把文档插回上下文；计算损失时屏蔽这些外部文档的token。论文也对比了GRPO：GRPO生成更长、检索更多，域外泛化更好；REINFORCE++在域内更好。

训练与评测。底座为Qwen-2.5-7B-Base和Llama-3.1-8B-Instruct，从HotpotQA和2WikiMultiHopQA中按难度选出约8000道题训练；在这两个数据集及域外的Musique、Bamboogle上评测。官方称Llama版在HotpotQA上比基于GPT-4o-mini的ReARTeR高48.2%（LLM评判）。换成Google在线搜索后，Qwen版在Bamboogle上比本地检索版高18.2%，比32B的Search-o1高11.4%。

局限与后续

  • 训练只用维基百科本地检索和两个多跳问答集，约8000道题，短答案问答以外的开放研究任务没有涉及。
