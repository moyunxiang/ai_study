稀疏采样在线规划

A Sparse Sampling Algorithm for Near-Optimal Planning in Large Markov Decision Processes
2002.11论文延伸Machine Learning 2002（会议版IJCAI 1999）Michael Kearns, Yishay Mansour, Andrew Y. Ng · AT&T实验室 / 特拉维夫大学 / UC伯克利待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

动态规划的计算量与状态数成正比；状态空间巨大甚至无限时（比如只有一个能「给定状态和动作就采样下一状态」的模拟器），值迭代和策略迭代都无从下手。

方法

稀疏采样：在当前状态向前构造一棵有限深度的前瞻树，每个节点对每个动作只从模拟器里采样C个后继状态，用这些样本的平均做贝尔曼备份；证明选出的动作是近似最优的，而且每步计算量与状态空间大小完全无关。

影响

它是「在线规划的代价可以与状态数无关」这一结论的代表性结果，奠定了基于模拟器的蒙特卡洛规划的理论基础；后来的UCT（蒙特卡洛树搜索UCT）正是为了避免它对每个动作都均匀采样、深度指数爆炸的问题而提出的。

方法

设有一个生成模型：输入(s, a)，返回一个按真实转移概率采样的下一状态和奖励。要在当前状态s₀选动作时，稀疏采样递归地估计：

  • 深度为0时，Q̂₀(s,a) = 0；
  • 深度为h时，对每个动作a从模拟器采样C个后继 s'_1, …, s'_C，令 Q̂_h(s,a) = (1/C) Σ_j [r_j + γ max_a' Q̂_{h−1}(s'_j, a')]。

最后在根节点选 argmax_a Q̂_H(s₀, a)。整棵树有 (|A|·C)^H 个节点。

论文的主要定理：对任意ε>0，只要取深度 H = O(log(1/ε)/(1−γ)) 级别（足以让折扣后被截断的尾巴可以忽略），并让每个动作的采样数C足够大（只依赖ε、γ、最大奖励和动作数），所得策略就是ε-最优的；关键是C和H都不依赖状态数，因为每次只在样本上做备份，用集中不等式控制每层平均值与真实期望的偏差，再沿树向上累积误差。

这说明大规模甚至无限状态的MDP在原则上也能高效地在线规划，前提是能调用模拟器。不过C和H在理论上的数值往往大得不可接受，整棵树的规模对深度是指数的。

局限与后续

  • 每个节点对所有动作均匀采样，树大小随深度指数增长，理论上需要的样本数在实践中大到无法使用。

它建立在什么之上

  • 延续
    动态规划与Bellman方程1957 · RL
    把贝尔曼备份中的期望换成从模拟器采样的平均，在有限深度的前瞻树上近似求解。
  • 竞争
    Alpha-Beta剪枝分析1975 · RL
    博弈树搜索在确定性游戏中展开前瞻树；稀疏采样把前瞻树推广到随机转移的MDP，并给出近似最优保证。
  • 延续
    E3与PAC探索理论1998 · RL
    同一作者群的PAC式分析：E3处理学习中的探索，稀疏采样处理已有模拟器时的规划复杂度。

读懂它需要的概念

马尔可夫决策过程 Bellman方程 蒙特卡洛采样 博弈树搜索：minimax与MCTS 时间与空间复杂度

本篇术语

  • 生成模型（模拟器）　可以对任意状态-动作对采样下一状态和奖励，但不必给出完整的转移概率表。
  • 在线规划　每到一个状态才临时向前搜索，只为当前这一步选动作，而不是事先算出所有状态的策略。

怎么学

先学值迭代和蒙特卡洛估计；读论文第3节算法和主定理的陈述；在一个随机网格世界上实现深度3、C=5的稀疏采样，再与相同模拟次数的UCT比较选动作的质量。
