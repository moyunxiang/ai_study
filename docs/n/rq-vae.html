RQ-VAE残差量化

Autoregressive Image Generation using Residual Quantization
2022.03论文延伸CVPR 2022Doyup Lee, Chiheon Kim, Saehoon Kim, Minsu Cho, Wook-Shin Han · Kakao Brain / 浦项科技大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自回归图像生成要先用VQ-VAE/VQGAN把图像变成离散码序列；序列越短，Transformer越省算力，但在码本大小固定时，把图压得更小就会丢细节，短序列和高保真难以兼得。

方法

残差量化：每个位置不只用一个码，而是先量化一次，再对剩下的误差继续量化，叠D层码，逐层逼近原特征；生成时用RQ-Transformer在每个位置一次预测一整叠码。

影响

论文称能把256×256图像表示成8×8的码图而仍保持高保真，采样也比此前自回归模型快得多；残差量化后来被广泛用于图像分词器和音频编解码器的多层码设计。

方法

RQ-VAE：编码器把图像变成一张低分辨率特征图。对每个位置的特征向量z，先在码本里找最近的码k₁，得到残差r₁ = z − e(k₁)；再对r₁找最近的码k₂，得到r₂，如此重复D次。最终用e(k₁)+…+e(k_D)近似z。由于每一层都在修正上一层的误差，同一个码本反复使用就能得到很精细的近似，相当于用D个码的组合表达一个向量。于是可以把空间分辨率压得更低（256×256→8×8），序列长度大幅缩短。

RQ-Transformer：要生成的是一个8×8×D的码栈。它分两级：空间Transformer按光栅顺序处理各位置，输出每个位置的上下文向量；深度Transformer以这个向量为起点，在该位置内部依次预测k₁到k_D。这样长序列的注意力只发生在64个位置之间，计算成本明显降低。

论文在无条件和类别条件、文本条件的图像生成基准上报告优于此前的自回归模型，并且采样速度显著更快。

    VQGAN2020.12 · 生成
    VQGAN要用较长的码序列才能保真，RQ-VAE在更短的序列上达到高保真。
