AlphaCode

Competition-Level Code Generation with AlphaCode
2022.02论文延伸Science 2022Yujia Li, David Choi, Junyoung Chung, Nate Kushman, Julian Schrittwieser, Rémi Leblond, Tom Eccles, James Keeling et al. · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大模型只能写简单函数，面对需要算法思考的竞赛题基本不行。

方法

先用大量采样生成海量候选程序，再按样例过滤并聚类，从中挑出少数提交。

影响

第一个在真实编程竞赛中达到中游水平的AI系统，证明「大量采样加筛选」可以弥补单次生成的不足。

方法

AlphaCode用Transformer编码器-解码器，先在GitHub代码上预训练，再在自建的竞赛题数据集上微调。推理时对每道题采样海量程序，运行题目给的样例输入，丢掉输出不对的；剩下的程序再按它们在模型生成的新输入上的输出行为聚类，从每个簇取代表提交。

摘要称在Codeforces近期比赛的模拟评测中，平均排名在参赛人数超过5000的比赛里位于前54.3%。作者认为三点关键：干净的数据集、高效可采样的大模型、大规模采样。

后来的发展

这种「多采样、验证、选择」的套路后来出现在测试时算力扩展研究中（如重复采样的扩展律），也影响了AlphaCodium流程工程这类代码流程工程。
