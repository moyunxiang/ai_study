OCRNet物体上下文分割

Object-Contextual Representations for Semantic Segmentation
2019.09论文延伸ECCV 2020Yuhui Yuan, Xiaokang Chen, Xilin Chen, Jingdong Wang · 微软亚洲研究院 / 中科院计算所待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

语义分割要靠上下文判断一个像素是什么，但PSPNet的金字塔池化和Non-local网络式注意力汇集的是“周围所有像素”，其中混着大量别的物体的信息。

方法

一个像素的标签就是它所属物体的类别，所以应该用“物体”来做上下文：先粗分出每一类的物体区域，把区域内像素特征平均成区域表示，再按像素与各区域的相似度加权汇总，拼回像素特征。

影响

OCR模块简单、可以接在任意骨干后面，“HRNet+OCR”在Cityscapes等基准上长期是强基线；论文后来把这种像素-区域注意力改写成Transformer编码器-解码器的形式。

方法

OCR模块分三步：

  • 软物体区域：在骨干特征上接一个辅助分割头，输出K张（K=类别数）粗分割图，用真值监督；
  • 区域表示：对第k张软区域图，用它当权重把所有像素特征加权平均，得到第k类物体的一个向量 f_k；
  • 物体上下文：对每个像素i，算它与各区域表示的相似度并做Softmax与logits得到权重 w_ik，物体上下文 y_i = Σ_k w_ik · φ(f_k)；最后把 y_i 与原像素特征拼接，再预测最终类别。

与Non-local网络让每个像素看所有像素不同，这里每个像素只看K个区域向量，计算量从“像素×像素”降到“像素×类别”，而且汇集的是同类物体的信息。论文在HRNet和ResNet骨干上做实验，摘要报告在Cityscapes、ADE20K、LIP、PASCAL-Context和COCO-Stuff上都有竞争力，“HRNet + OCR + SegFix”提交时在Cityscapes排行榜第一。

之后的MaskFormer、Mask2Former通用分割把“用少量类别或物体向量去与像素交互”做成了基于查询的掩码分类，OCR可以看成这条路线的前身之一。

它建立在什么之上

  • 改进
    RefineNet多路径细化2016.11 · 视觉
    上下文只靠局部池化链来汇集，对整张图级别的全局关系建模有限。
  • 改进
    PSPNet2016.12 · 视觉
    金字塔池化按固定窗口汇集上下文，混入别的物体；OCR改为按所属物体区域汇集。
  • 竞争
    DeepLabv3与ASPP2017.06 · 视觉
    DeepLabv3用ASPP的多空洞率卷积获取多尺度上下文；OCR用物体区域表示，两者在Cityscapes等基准上长期并列比较。
  • 延续
    Non-local网络2017.11 · 视觉
    同样是注意力式上下文聚合，但把“像素对像素”换成“像素对物体区域”，更省也更有针对性。
  • 使用
    HRNet2019.02 · 视觉
    主要实验以HRNet为骨干，HRNet+OCR成为常用组合。

读懂它需要的概念

分类、检测、分割 卷积层、池化与感受野 注意力机制 Softmax与logits IoU与mAP

本篇术语

  • 软物体区域　每一类一张、取值在0到1之间的粗分割图，表示每个像素属于这一类物体的程度。

怎么学

先理解Non-local注意力的计算方式，再读本文第3节的三步公式；可在mmsegmentation里对比OCRNet与PSPNet的配置和精度。
