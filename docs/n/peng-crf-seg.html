CRF中文分词与新词发现

Chinese Segmentation and New Word Detection using Conditional Random Fields
2004.08论文延伸COLING 2004Fuchun Peng, Fangfang Feng, Andrew McCallum · 马萨诸塞大学阿默斯特分校待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

中文分词靠词典最大匹配会在歧义和未登录词（人名、新造词、专业术语）上出错；字标注式的最大熵方法逐字独立决策，标签之间不能全局协调，词典知识也难以灵活加入。

方法

把分词当作序列标注，用线性链条件随机场对整句的“词开始/非开始”标签做全局建模，特征同时包括字、字的组合和各种领域词典；再用CRF给出的置信度从切分结果中发现新词，加入词典后迭代。

影响

这是最早把CRF用于中文分词的工作之一，在SIGHAN 2003首届分词评测的多个语料上取得有竞争力的结果；“CRF+字特征+词典特征”随后成为中文分词的主流做法，直到神经方法出现。

背景

中文书面语没有空格，分词是几乎所有中文处理的第一步。中文分词即字标注（Xue，2003）把分词改写为给每个字打位置标签（词首、词中、词尾、单字词），用最大熵分类器逐字判断。条件随机场（2001）能在整个序列上做全局归一化，避免标签偏置问题；它已在英语命名实体识别、浅层句法分析中表现出色。

方法

标注方式：对每个汉字预测二值标签——它是否是一个词的开始（START/NONSTART）。线性链CRF定义

P(y | x) = (1/Z(x)) · exp( Σ_t Σ_k λ_k f_k(y_{t−1}, y_t, x, t) )

特征f包括：当前字及前后各两个字、相邻字的组合（如 C_{−1}C_0）、字是否属于数字/字母/标点等类别，以及词典特征——当前字开始或结束于某个词典中的词（作者使用多个词典，包括通用词表、人名地名表、从训练语料学到的词表），这些词典特征让模型能灵活结合外部知识。

新词发现：CRF能给出每个切分边界的边缘概率。在大量未标注文本上切分后，挑出模型置信度高、但不在词典中的字串作为候选新词，加入词典再重新训练，提升对未登录词的召回。

结果

在近期一次综合性中文分词评测（SIGHAN 2003首届评测）所用的四个数据集上，系统取得了当时最好水平；概率式的新词发现进一步提升了性能（原文摘要）。具体F值未在此引用。

后来的发展

SIGHAN 2005第二届分词评测中，多数领先系统采用了CRF与字标注；CRF++等工具让这一做法普及，LTP哈工大语言技术平台、Stanford中文分词器等工具包也用CRF分词。神经时代，BiLSTM-CRF与Lattice LSTM中文NER等模型延续了“字级标注+词典信息”的思路，pkuseg多领域中文分词等工具则关注多领域分词。

局限与后续

  • 依赖人工设计的字窗口和词典特征，跨领域时（如从新闻到医学）效果明显下降。

本篇术语

  • 未登录词　不在分词词典里的词，如新出现的人名、网络用语、专业术语，是中文分词错误的主要来源。
  • 字标注　把分词转换成给每个汉字打标签（如是否为词首），再按标签把字串切成词。
  • SIGHAN分词评测　ACL中文处理特别兴趣小组组织的国际中文分词评测，2003年首届，提供多个语料的标准评测。

怎么学

先读条件随机场和中文分词即字标注 → 读论文第2–3节特征与新词发现 → 动手：用sklearn-crfsuite在人民日报或PKU语料上训练一个字级CRF分词器，比较加入词典特征前后在未登录词上的召回率。
