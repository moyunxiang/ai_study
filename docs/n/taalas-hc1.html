Taalas HC1：模型固化芯片

The Path to Ubiquitous AI
2026.02硬件延伸Ljubisa Bajic 等 · Taalas待核对
Taalas官方博客 ↗CNX Software报道 ↗在交互版中打开（演化树、学习进度）

问题

GPU推理每生成一个token都要从HBM读一遍权重，单用户速度被内存带宽卡住，还要背负HBM、先进封装和液冷的成本。

方法

把某一个模型的权重直接做进芯片的金属层，存储与计算合一，芯片只跑这一个模型，但不再需要HBM。

影响

第一款芯片HC1把Llama 3.1 8B固化进硅片，官方称单用户每秒约1.7万token，在社区引发“专用到单个模型的芯片是否值得”的大讨论。

方法

Taalas成立约两年半后，于2026年2月发布HC1（官方博客署名Ljubisa Bajic）。芯片用台积电6nm，约530亿晶体管、815mm²，把Llama 3.1 405B的8B版本以只读形式固化在芯片里，存储密度官方称达到DRAM级别。第一代用自定义的3位基础数据类型，混合3位和6位参数，官方承认相对GPU有一定质量损失；第二代HC2改用标准4位浮点格式。

官方称：单用户每秒约1.7万token，比当前最好方案快近10倍，制造成本低20倍，功耗低10倍；从拿到一个新模型到做成芯片只需两个月。团队24人，第一款产品花了3000万美元（总融资超过2亿美元）。

这条路线把Etched Sohu专用ASIC“只为Transformer设计芯片”的专用化推到极致：芯片不再是通用的计算设备，而是某一个模型的物理实现。社区讨论的焦点是，模型几个月就换代一次，专用芯片的两个月流片周期能否跟上。

局限与后续

  • 一块芯片只能跑一个固定模型，模型更新换代后硬件就过时，激进量化也带来质量损失。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 8B规模的模型可以单芯片放下，前沿规模的模型需要多芯片，HC2能否兑现尚待验证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    Llama 3.1 405B2024.07 · LLM
    第一款芯片固化的就是Llama 3.1 8B。
  • 竞争
    Groq LPU与推理专用芯片2024.02 · 硬件
    都追求极低延迟的单用户推理，Groq保持可编程、用大量SRAM，Taalas干脆把权重做成只读硬件。
  • 延续
    Etched Sohu专用ASIC2024.06 · 硬件
    Etched把芯片专用到Transformer架构，Taalas更进一步专用到某一个具体模型的权重。
  • 竞争
    Cerebras推理服务2024.08 · 硬件
    官方以Cerebras为主要对比对象，称速度快约10倍。

读懂它需要的概念

显存、内存带宽与“内存墙” 量化 吞吐、延迟与批处理

怎么学
