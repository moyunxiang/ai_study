Dia对话语音生成

2025.04模型延伸Nari Labs待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

一般TTS一次只合成一个说话人的一句话，要做多人对话或播客，得逐句合成再拼接，轮换和语气都不自然。

方法

1.6B参数的模型直接从带[S1]、[S2]说话人标记的完整对话脚本一次生成整段对话，并能生成笑声、咳嗽、清嗓等非语言声音，可用参考音频控制情绪和音色。

影响

开源后很快获得近2万星，官方以ElevenLabs Studio和Sesame CSM-1B作对比；2025年11月推出Dia2。

方法

Dia的输入是一段对话脚本，用[S1]、[S2]交替标记两位说话人，可以插入（laughs）、（coughs）等非语言标签。模型一次性生成整段多人对话的音频token，再解码成波形，因此说话人之间的衔接、抢话和语气呼应都在一个生成过程里完成。用户可以给一段参考音频及其文字，以此控制情绪、语气或克隆音色。官方给出的使用建议包括：输入长度适中（对应约5到20秒音频），非语言标签少用，说话人标记必须交替出现。模型目前只支持英文，权重发布在Hugging Face，并已进入Hugging Face Transformers。

局限与后续

  • 只支持英文；输入过短或过长都会导致不自然；未指定参考音频时每次生成的音色不固定。
