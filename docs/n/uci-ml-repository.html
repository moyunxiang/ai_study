UCI机器学习库

The UCI Machine Learning Repository

问题

1980年代的机器学习论文各用各的小数据集，别人拿不到同样的数据，新算法到底比旧算法好多少很难比较。

方法

在加州大学尔湾分校建一个公开的数据集档案：研究者把数据捐出来，统一存档、写好说明，任何人都能下载同一份数据复现和比较。

影响

官方称它被全球学生、教师和研究者当作机器学习数据集的主要来源；例如随机森林原论文在13个UCI数据集上做比较，Mixup也报告了UCI数据上的结果。

方法

据官方关于页面，这个库于1987年由UCI的博士生David Aha以FTP档案的形式创建，此后一直被学生、教师和研究者当作机器学习数据集的主要来源；网站现行版本于2023年上线，由几位称作“librarian”的管理员维护，官方建议的引用为Markelle Kelly、Rachel Longjohn、Kolby Nottingham的“The UCI Machine Learning Repository”。截至本次查看，首页称维护着690个数据集。

每个数据集有一页说明：来源与捐赠者、样本数、特征类型、任务（分类、回归、聚类等）、缺失值情况和推荐引用。最出名的例子是Iris鸢尾花数据：R. A. Fisher 1936年的150个样本、3类各50个、4个以厘米计的花萼花瓣测量值，1988年6月入库，官方称它是已知最早用于评估分类方法的数据集之一。另一个常用的是Adult：48,842条记录，由Barry Becker从1994年美国人口普查数据库抽取，任务是预测年收入是否超过5万美元，含种族、性别、年龄等人口属性，后来也常被拿来研究算法公平性。

容易误解的地方

  • “在若干UCI数据集上更好”这种结论高度依赖挑了哪些数据集；多数数据集只有几百到几万个样本，差异常常落在统计误差之内。
  • 不少老数据集含缺失值、重复样本或敏感属性，使用前要读它的说明页。

局限与后续

  • 数据集多是小规模的表格数据，没有统一的训练/测试划分，论文之间的结果往往不可直接比较；深度学习兴起后，图像、语音、文本的大规模基准转向ImageNet等专门数据集。

读懂它需要的概念

监督学习 训练集、验证集与测试集 基准、排行榜与SOTA 决策树

本篇术语

  • 表格数据　像电子表格一样，每行一个样本、每列一个特征（年龄、收入、测量值等）的数据，是UCI库里最常见的形式。
  • Iris / Adult　UCI里最常被用作教学和实验的两个数据集：Iris是150朵鸢尾花的4项测量与3个品种；Adult是由人口普查记录预测收入是否超过5万美元。

怎么学

先读训练集、验证集与测试集；动手：在官网下载Iris和Adult，用scikit-learn分别训练决策树和k近邻，做5折交叉验证，看看两个数据集上结果的波动有多大。
