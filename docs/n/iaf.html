逆自回归流IAF

Improving Variational Inference with Inverse Autoregressive Flow
2016.06论文延伸NeurIPS 2016Kingma, Salimans, Jozefowicz, Chen, Sutskever, Welling · OpenAI / Amsterdam待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

变分自编码器VAE的后验常假设为对角高斯，过于简单；标准化流里已有的流在高维隐空间中计算代价太大。

方法

用自回归网络构造一个流：每个隐变量的新值由前面维度的函数缩放平移，雅可比为三角阵，高维下仍高效。

影响

让VAE的后验可以灵活到与自回归模型竞争，同时采样快得多，成为NVAE层级VAE等模型的标准部件。

方法

流的变换形式为 z' = μ(z_<i) + σ(z_<i) ⊙ z，其中每一维i的μ、σ只依赖输入z的前面维度，由MADE这类自回归网络一次前向算出。因此雅可比是三角阵，对数行列式就是 −Σ log σ_i，计算量与维度线性相关；多层堆叠后，后验分布越来越灵活。

它是自回归模型的「逆」：自回归做密度估计时能快速算概率、慢速采样；IAF反过来，给定噪声并行地快速得到样本，而对任意外部数据点求密度则较慢。这恰好适合变分推断：我们要在从q采样的点上算密度，而不是对外部数据点。

论文称IAF显著优于对角高斯后验，并且带IAF的新型VAE在自然图像对数似然上可与神经自回归模型竞争，同时合成快得多。

局限与后续

  • 采样快但对任意给定数据点评估密度慢，不适合直接当作数据密度模型。

它建立在什么之上

  • 改进
    变分自编码器VAE2013.12 · 生成 已核对
    近似后验限定为对角高斯，表达力有限，变分下界与真实似然之间存在明显差距。
  • 延续
    标准化流2015.05 · 生成
    把流的变换改成自回归形式，使其可扩展到高维隐空间。
  • 改进
    神经自回归NADE2011.04 · 生成
    生成样本时要按顺序一个变量一个变量采样，D很大时很慢，也难处理图像这类带空间结构的数据。
  • 改进
    随机反向传播DLGM2014.01 · 生成
    下界只用单个后验样本估计，对复杂后验的刻画有限，后验被假设为对角高斯。
  • 使用
    MADE2015.02 · 生成
    用MADE一次前向得到每一维的缩放和平移。
  • 改进
    重要性加权IWAE2015.09 · 生成
    k个样本的代价是k倍，且当k很大时识别网络的梯度信号变弱。

后来的相关工作

  • 改进
    DDPM2020.06 · 生成
    隐变量仍受限于VAE框架，样本往往模糊。
  • 改进
    Glow2018.07 · 生成
    采样快但对任意给定数据点评估密度慢，不适合直接当作数据密度模型。
  • 使用
    NVAE层级VAE2020.07 · 生成
    借用IAF思想的自回归流来提升后验灵活性，并沿用其层级后验的做法。
