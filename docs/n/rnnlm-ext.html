RNNLM扩展与类分解

Extensions of recurrent neural network language model
2011.05论文延伸ICASSP 2011Tomas Mikolov, Stefan Kombrink, Lukáš Burget, Jan Černocký, Sanjeev Khudanpur · 布尔诺理工大学、约翰斯·霍普金斯大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

2010年的RNN语言模型困惑度明显低于n-gram，但输出层要对整个词表（几万到几十万词）算softmax，训练和测试都很慢，只能在小语料上训练，难以进入实际的语音识别系统。

方法

把输出层分解成两步：先预测下一个词属于哪个词类，再只在这个类内部预测具体的词；同时用按时间截断的反向传播训练，并组合多个RNN模型。

影响

让RNN语言模型的训练速度提高一个数量级以上，配套发布的RNNLM工具包成为2011–2014年神经语言模型实验和语音识别重打分的常用工具，类分解思路也被后来的层次softmax类方法沿用。

背景

RNN语言模型（2010）用一个循环隐层把全部历史压成向量，再在输出层预测下一个词的分布。困难在于输出层：隐层维度H、词表V时，每预测一个词要做 H×V 次乘加，V在几万以上时，这一项远大于隐层本身的计算。神经概率语言模型同样被这个瓶颈卡住；层次softmax语言模型用二叉树把复杂度降到 log V，但树的构造较复杂、效果对树结构敏感。

方法

核心改动是按词类分解输出概率：先把词按频率分到C个类（按累计词频把词表切成大致等概率的几段，高频词各占小类，低频词合进大类），然后

p(w_t | h_t) = p(c(w_t) | h_t) · p(w_t | c(w_t), h_t)

第一项是对C个类的softmax，第二项只对该类内的词做softmax。每步计算量从 H×V 降到约 H×(C + V/C)，C取 √V 量级时最省。

训练上，论文比较了只回传一步的简单反向传播与随时间反向传播BPTT（随时间反向传播，回传若干步后截断），说明后者能学到更长的依赖、困惑度更低；还讨论了把多个不同初始化的RNN模型线性插值，以及和n-gram模型插值，以进一步降低困惑度和识别词错率。

结果

论文在Penn Treebank语料上报告困惑度，在语音识别任务上报告重打分后的词错率；主要结论是类分解带来大幅加速而困惑度只略有上升，BPTT与模型组合都能降低困惑度（具体数字未能核对原文，此处不写）。

后来的发展

这篇论文和随后公开的RNNLM工具包让循环网络语言模型从实验室走向大规模实验：Mikolov随后在语音识别和机器翻译重打分中用它取得收益，word2vec的工程实现也沿用了他在这里积累的高效训练经验。词类分解输出层后来被LSTM语言模型等工作直接采用，并演化出自适应softmax这类按词频分簇、适配GPU的输出层。

局限与后续

  • 普通RNN用截断BPTT训练仍会遇到梯度消失，实际能利用的历史只有十几个词。

    后来针对它的工作　自适应softmax NCE训练语言模型

它建立在什么之上

  • 延续
    Brown聚类1992 · NLP
    沿用“先预测词类再预测词”的类语言模型思想，但词类按词频简单切分，而非Brown式的互信息聚类。
  • 改进
    RNN语言模型2010.09 · NLP
    解决RNN语言模型输出层对整个词表做softmax太慢的问题，使它能在更大语料上训练。
  • 使用
    随时间反向传播BPTT1990 · 基础
    用截断的随时间反向传播训练循环隐层，并与一步反向传播比较。
  • 竞争
    层次softmax语言模型2005 · NLP
    同样把输出层分解来省计算：层次softmax用二叉树做log V次判别，这里只用一层词类、实现简单。

读懂它需要的概念

语言模型 循环网络与隐状态 Softmax与logits 反向传播 困惑度 时间与空间复杂度

本篇术语

  • 类分解softmax　先在少数几个词类上做softmax，再在选中的类内部做softmax，两者相乘得到词的概率。
  • 截断BPTT　反向传播只沿时间往回传固定步数，用来控制计算量和梯度爆炸。

怎么学

先读RNN语言模型了解基本结构 → 读本文的类分解与BPTT两节 → 动手：在PyTorch里实现一个带两级softmax的小RNN语言模型，比较V=5万时与完整softmax的每步耗时。
