Transformers.js浏览器推理

2023.02系统延伸Joshua Lochner（Xenova）· Hugging Face待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

想在网页里直接调用语音识别、文本分类、嵌入等模型时，通常要搭一个后端服务器；把模型放到浏览器本地运行，又缺少像Python transformers那样好用的接口。

方法

把Python transformers的pipeline接口原样搬到JavaScript：模型先转成ONNX，在浏览器或Node.js里用ONNX Runtime Web（WASM或WebGPU）执行，无需服务器。

影响

成为在网页端运行开源模型最常用的库之一，Hugging Face Hub上有大量为它转换好的ONNX模型；它让隐私敏感或离线的前端应用可以直接在本地推理。

方法

Transformers.js仓库创建于2023年2月，描述是“为网页提供最先进的机器学习，在浏览器中直接运行Transformers，无需服务器”。用法与Python版几乎一致：const pipe = await pipeline('sentiment-analysis')，然后对文本调用即可；也提供AutoTokenizer、AutoModel等底层接口。

实现上，模型先用Optimum等工具导出为ONNX模型交换格式格式（常同时提供量化版本以减小下载体积），由ONNX Runtime Web在浏览器中执行：默认用WebAssembly在CPU上计算，支持的浏览器上可切换到WebGPU后端利用显卡。分词器、前后处理也都用JavaScript重新实现，以保证与Python版输出一致。覆盖的任务包括文本分类、命名实体、翻译、摘要、语音识别（Whisper）、图像分类与分割、嵌入等。

局限与后续

  • 受浏览器内存与下载体积限制，主要适合小模型；大语言模型在浏览器里通常要靠WebLLM这类专门方案。
    本站还没有记录针对它的后续工作（不代表没有人解决）
