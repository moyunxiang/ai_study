AgentTuning/AgentLM

AgentTuning: Enabling Generalized Agent Abilities for LLMs
2023.10论文延伸Aohan Zeng, Mingdao Liu, Rui Lu, Bowen Wang, Xiao Liu, Yuxiao Dong, Jie Tang · 清华大学 / 智谱AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

开源大模型当智能体用时远不如ChatGPT和GPT-4；已有方法多是为特定任务设计提示，很少有人研究怎样提升模型本身的智能体能力，又不损害它的通用能力。

方法

构造一份覆盖多种智能体任务的高质量交互轨迹数据集AgentInstruct，与通用领域的指令数据按比例混合，对Llama 2做指令微调，得到AgentLM。

影响

AgentLM-70B在未见过的智能体任务上接近GPT-3.5，“智能体数据+通用数据混合微调”成为后来开源智能体模型训练的常见做法。

方法

智能体任务里，模型要充当中央控制器，负责规划、记忆和使用工具。作者的思路是直接把这些能力训进模型：

  • AgentInstruct数据：在操作系统、数据库、知识图谱、网购、家务、网页浏览等六类任务上，用GPT-4按ReAct式格式（思考—行动—观察）生成交互轨迹，只保留成功完成任务的那些，得到一份规模不大但质量高的数据集；
  • 混合指令微调：把AgentInstruct与通用领域的开源指令数据（如ShareGPT对话）按一定比例混合，微调Llama 2系列，得到AgentLM-7B/13B/70B。

混合的目的是防止“只学智能体数据导致通用能力下降”。评测用的是同组的AgentBench中训练时未见过的任务，以及MMLU、GSM8K等通用基准。结果显示，AgentTuning在提升智能体能力的同时基本不损失通用能力；AgentLM-70B在未见过的智能体任务上与GPT-3.5-turbo相当。

局限与后续

  • 轨迹都来自GPT-4的成功示范，属于模仿学习；没有利用失败轨迹，也无法超越教师的策略。

  • 智能体数据中格式遵循和推理能力纠缠在一起，模型容易学到格式而推理没跟上，并带来幻觉式的动作。

读懂它需要的概念

指令微调与对话模板 模仿学习与行为克隆 智能体循环 泛化与过拟合

怎么学

先读AgentBench和FireAct智能体微调 → 读原文第2节数据构造和第3节混合比例的消融 → 动手：用少量智能体轨迹和通用对话数据按不同比例微调小模型，比较它在智能体任务和通用问答上的得失。
