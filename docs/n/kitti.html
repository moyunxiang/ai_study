KITTI

Are we ready for Autonomous Driving? The KITTI Vision Benchmark Suite
2012.06数据集重要CVPR 2012Andreas Geiger, Philip Lenz, Raquel Urtasun · 卡尔斯鲁厄理工学院（KIT）、丰田芝加哥技术研究院（TTIC）待核对
论文PDF ↗KITTI官网与排行榜 ↗在交互版中打开（演化树、学习进度）

问题

立体匹配、光流、视觉里程计等任务的标准数据集多在实验室里拍摄，场景简单；在这些基准上排名靠前的方法，放到真实道路上表现如何没人知道。

方法

把相机、激光雷达和高精度GPS/惯导装在一辆旅行车上，开遍城市、乡村和高速，用激光点云和定位系统自动生成稠密的真值，同时发布立体、光流、里程计和3D物体检测四个基准与在线排行榜。

影响

KITTI成为自动驾驶感知研究的第一个通用基准，3D检测、单目深度、视觉里程计等方向此后多年都以它的排行榜为准，也引出了后来更大的nuScenes、Waymo Open等数据集。

背景

DARPA无人车挑战赛和DARPA城市挑战赛让自动驾驶从实验室走上真实道路，但当时的无人车主要靠激光雷达和地图，视觉算法在机器人里用得很少。作者认为一个重要原因是缺少贴近真实场景、要求苛刻的视觉基准：立体匹配和光流的标准测试集Middlebury是在实验室里拍的少量图片，纹理丰富、视差范围小；视觉SLAM数据集则大多没有统一的评测指标和高精度轨迹真值。检测方面只有PASCAL VOC用的是真实场景照片，但它没有3D信息。

方法

采集平台。一辆旅行车上装了两台彩色、两台灰度PointGrey相机（10Hz，1392×512像素），一台Velodyne HDL-64E激光雷达（10Hz，64线，测距100米，每秒超过100万个3D点），以及带RTK差分校正的GPS/惯导系统OXTS RT 3003（开阔地带定位误差小于5厘米）。所有传感器之间都做了精确标定和时间同步，在卡尔斯鲁厄的城区、乡村和高速公路上采集。

自动生成真值。立体匹配和光流的真值来自激光点云：用ICP把目标帧前后各5帧的激光扫描配准累积，投影到图像上，再人工去掉窗户、栅栏等有歧义的区域，由相机标定直接算出视差；把3D点投影到下一帧即得光流。最终约一半像素有真值。视觉里程计的真值轨迹来自GPS/惯导。

3D物体标注。不靠众包，而是由专门的标注员直接在激光点云里给汽车、货车、卡车、行人、骑车人、电车等画3D框，再投影回图像。检测沿用PASCAL的2D框重叠50%的规则，并提出平均朝向相似度（AOS），同时评价检测和朝向估计。

评测方式。测试集真值不公开，提供在线评测服务器和公开排行榜。

结果

四个基准合计：389对立体与光流图像对，22段立体视频序列、总长39.2公里、约4.1万帧的视觉里程计数据，以及超过20万个3D物体标注，单张图中最多可见15辆车和30个行人。2012年4月的立体匹配排行榜上，最好的方法PCBP在非遮挡区域的错误像素比例为4.72%，最差的超过30%，误差普遍高于在Middlebury上报告的数字。在Middlebury上排名靠前的方法，例如引导代价体滤波和逐像素图割，在KITTI上表现特别差，作者认为是因为Middlebury纹理丰富、视差范围小，而真实道路上有大片弱纹理、反光和大视差。

后来的发展

KITTI的3D检测榜成了激光雷达和多传感器检测的主战场，也带动了单目深度估计（自监督单目深度就在它上面训练和评测）、ORB-SLAM等视觉SLAM的比较。它证明了“用更精确的传感器自动产生真值”是构建大规模视觉基准的可行方法。之后的Cityscapes提供50个城市的语义分割标注，nuScenes和Waymo Open Dataset提供360度多传感器、夜间雨天和多得多的场景，逐渐取代它成为新的主流；面向驾驶决策闭环评测的，则是CARLA驾驶仿真器这类仿真平台。

容易误解的地方

  • KITTI主要在一座德国城市及周边、光照较好的条件下采集，在它上面排名靠前不代表能处理夜间、雨雪或其他国家的道路。
  • 3D检测分“简单、中等、困难”三档，各论文常只报中等档，比较时需要对齐。

局限与后续

  • 只在一个城市周边采集，并去掉了光照不佳的场景，天气和场景多样性有限，3D检测的训练数据规模也不大。
    后来针对它的工作　Cityscapes nuScenes Waymo Open Dataset
  • 相机只朝向前方，没有360度环视，无法评测完整的周边感知。
    后来针对它的工作　nuScenes Waymo Open Dataset
  • 只评测感知和定位，不评测驾驶决策本身，在KITTI上感知更准并不等于车开得更好。

它建立在什么之上

  • 延续
    DARPA无人车挑战赛2005.10 · 具身·世界模型
    沿着无人车挑战赛开启的道路自动驾驶方向，为其中的视觉感知部分建立公开、统一的基准。
  • 延续
    DARPA城市挑战赛2007.11 · 具身·世界模型
    城市挑战赛把无人车带进城市道路，KITTI在真实城区和高速上采集，针对的正是这类场景的视觉问题。
  • 使用
    PASCAL VOC2005 · 数据·评测
    检测评测沿用PASCAL的50%重叠规则和平均精确率，并加上朝向相似度扩展到3D。
  • 改进
    PTAM2007.11 · 视觉
    PTAM等视觉SLAM方法缺少室外大尺度、带高精度真值轨迹的统一评测，KITTI提供了39.2公里的里程计基准。

后来的相关工作

  • 改进
    CARLA驾驶仿真器2017.11 · 具身·世界模型
    只评测感知和定位，不评测驾驶决策本身，在KITTI上感知更准并不等于车开得更好。
  • 竞争

    同年发布的深度数据：NYU是室内Kinect近距离深度，KITTI是室外车载激光雷达远距离深度，后来常被成对用作单目深度估计的两个基准。
  • 使用

    在KITTI基准上评测。
  • 改进

读懂它需要的概念

相机模型与多视图几何 三维表示：体素、点云、网格、隐式场 IoU与mAP 基准、排行榜与SOTA 分类、检测、分割

本篇术语

  • 立体匹配　从左右两台相机的图像中找出同一点的对应位置，水平位移（视差）越大说明物体越近，从而恢复深度。
  • 光流　相邻两帧图像中每个像素的运动位移，用来估计场景中物体和相机的运动。
  • 视觉里程计　只用相机图像连续估计车辆自身的位置和朝向变化，误差会随距离累积。

怎么学

先补相机模型与多视图几何和IoU与mAP。读原文第2节（传感器、标定与真值生成）。然后下载KITTI的一小段原始数据，用官方开发包把激光点云投影到相机图像上画出来，直观理解“激光点云给出深度真值”是怎么回事。
