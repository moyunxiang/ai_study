VirTex文本监督预训练

VirTex: Learning Visual Representations from Textual Annotations
2020.06论文延伸CVPR 2021Karan Desai, Justin Johnson · University of Michigan待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

视觉骨干网络通常靠ImageNet的类别标签预训练，一张图只给一个词，信息稀疏，需要上百万张标注图。

方法

改用图像描述来监督：从零训练一个卷积网络，让它的特征能支撑一个Transformer解码器生成这张图的描述，再把卷积网络拿去做下游任务。

影响

证明自然语言是比类别标签更“密”的监督信号，是CLIP之前用文字训练视觉表示的代表工作之一，常被当作CLIP的前驱提及。

方法

2020年前后，视觉任务的标准起点是在ImageNet上用类别标签预训练的ResNet；SimCLR、MoCo等自监督方法则试图完全不用标签。VirTex走第三条路：一句描述里包含物体、属性、动作和关系，比一个类别词携带的信息多得多，也许能用更少的图片学到同样好的特征。

做法是把预训练与微调里的预训练任务换成图像描述。视觉部分是一个从随机初始化开始训练的ResNet，把图像变成一组空间特征；文字部分是Transformer解码器，在视觉特征上做交叉注意力，逐词预测描述，论文同时训练从左到右和从右到左两个方向的解码器。数据只用MS COCO的描述标注，规模约十万张图。预训练结束后扔掉文字解码器，只保留ResNet，迁移到图像分类、目标检测和实例分割。

摘要报告，在所有下游任务上VirTex的特征都能达到或超过在ImageNet上（有监督或自监督）预训练的特征，而使用的图片数量最多少十倍。几个月后CLIP把“用文字监督视觉”扩大到4亿图文对，并把生成描述换成对比学习，论文中说明这样训练效率更高。

局限与后续

  • 只在约十万张人工标注描述的COCO图上训练，没有利用网络上海量、带噪声的图文对，规模难以扩大。

  • 逐词生成描述的预训练目标计算贵、收敛慢，学到的特征也不能直接做零样本分类。

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    视觉骨干是从零训练的ResNet，预训练后迁移到下游任务。
  • 使用
    Transformer2017.06 · LLM
    用Transformer解码器在视觉特征上生成描述，作为预训练任务。
  • 竞争
    SimCLR2020.02 · 视觉
    同期用无标签图像做对比自监督预训练；VirTex主张少量带文字的图像更省数据，两者都与ImageNet有监督预训练比较。
  • 使用
    MS COCO2014.05 · 数据·评测
    唯一的预训练数据来源是COCO的图像描述标注。

  • 迁移评测　预训练完成后冻结或微调骨干网络，看它在分类、检测等别的任务上表现如何，用来衡量学到的特征好不好。
