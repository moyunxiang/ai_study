RoBERTa

RoBERTa: A Robustly Optimized BERT Pretraining Approach
2019.07论文重要Yinhan Liu, Myle Ott, Naman Goyal, Jingfei Du, Mandar Joshi, Danqi Chen, Omer Levy, Mike Lewis et al. · Facebook AI / 华盛顿大学来源已核对
arXiv ↗fairseq代码与模型 ↗在交互版中打开（演化树、学习进度）

问题

BERT之后新方法层出不穷，但各家数据量、训练时长、超参数都不同，说不清提升究竟来自新方法还是只是训练得更多。

方法

不改模型结构，只认真复现并调整BERT的训练：去掉下一句预测、改为动态掩码、用更大的批次、10倍的数据、更长的训练。

影响

论文称结构不变的BERT经过充分训练就能追平或超过此后发表的所有模型，BERT明显训练不足；RoBERTa之后常被用作编码器的对比基线。

背景

BERT发表后不到一年，XLNet等新模型纷纷声称超过它，并把提升归功于新的预训练目标或结构。但比较并不公平：XLNet用的预训练数据是BERT的近10倍，批次和步数也不同。预训练一次成本很高，很少有人做系统的对照实验，社区并不知道BERT本身的潜力在哪里。

方法

作者用同一套代码逐项改动BERT的训练方式，每次只变一个因素，看下游效果。

动态掩码。原版BERT在数据预处理时就决定好遮哪些词，为了多样性把数据复制10份、各遮一次，40轮训练里每种遮法要重复4次。RoBERTa改为每次喂给模型时现场随机选掩码位置，效果相当或略好，也更省事。

去掉NSP。对比四种输入构造后发现，直接用一篇或多篇文档里连续的整句填满512个token、不做下一句预测，效果持平或略好。

大批次。批大小从256个序列提高到8000个，配合调整后的学习率，在相同计算量下困惑度和下游效果都更好，也更易并行。

更多数据、更久训练。在原有的书籍+维基（16GB）之外，新收集了CC-News（2016年9月到2019年2月的6300万篇英文新闻）等，共160GB；训练步数从10万逐步加到50万。

分词。改用GPT-2的字节级BPE子词切分，词表5万，无需任何预处理也不会出现未知词。

结果

数据从16GB增到160GB、步数从10万到30万再到50万，下游指标持续上升，没有饱和迹象。最终模型在GLUE开发集上与当时同样使用大量数据的XLNet持平或更好，在GLUE公开排行榜上得到88.5分，与XLNet报告的88.4持平，并在9个任务中的4个（MNLI、QNLI、RTE、STS-B）上刷新最好结果；RACE上取得最好结果，SQuAD 1.1开发集追平XLNet、2.0开发集略超XLNet。训练使用1024块V100，以混合精度训练。

后来的发展

RoBERTa提醒社区：比较预训练方法时要控制数据量和训练量，之后不少新方法会在相近的数据和计算下与它比较。XLM-R把类似的配方扩展到100种语言，DeBERTa解耦注意力、CodeBERT、Longformer滑窗注意力在它的基础上继续改。去掉NSP、动态掩码、大批次这些做法被不少后来的编码器采用。

局限与后续

  • 仍是掩码语言模型，每个序列只从被遮住的15%位置学习，计算利用率低。
    后来针对它的工作　ELECTRA替换词检测
  • 靠堆数据和算力取胜，单次预训练需要上千块GPU，小团队难以复现。
    后来针对它的工作　ELECTRA替换词检测
  • 只有英文，对其他语言没有直接帮助。
    后来针对它的工作　XLM-R
  • 仍是只有编码器的结构，无法直接生成文本。
    后来针对它的工作　BART T5

它建立在什么之上

  • 改进
    BERT2018.10 · LLM 已核对
    针对BERT训练不足：结构和目标不变，只靠更多数据、更长训练、更大批次、去掉NSP，实验显示各项下游指标都提高。
  • 使用
    GPT-22019.02 · LLM 已核对
    采用GPT-2的字节级BPE词表。
  • 使用
    GLUE / SuperGLUE2018.04 · 数据·评测 已核对
    以GLUE、SQuAD、RACE为主要评测，GLUE排行榜88.5分。
  • 使用
    Common Crawl与网络规模文本2008 · 数据·评测 已核对
    新语料CC-News取自Common Crawl的新闻部分。
  • 竞争
    XLNet2019.06 · LLM 已核对
    XLNet把提升归于新的排列语言模型目标；RoBERTa在可比数据下用原版MLM追平它，说明数据与训练量是主因。
  • 改进
    ULMFiT2018.01 · LLM
    预训练语料只有1亿词的维基百科，远未用上网络规模的文本。

后来的相关工作

  • 使用
    LoRA2021.06 · 系统·效率 已核对
    在RoBERTa和DeBERTa上用GLUE验证方法对理解类任务同样有效。
  • 竞争
    T52019.10 · LLM 已核对
    同一时期两项重新审视预训练选择的工作：RoBERTa只调BERT的训练配方，T5在统一的文本到文本框架下逐项比较目标、结构、数据和规模。T5论文把RoBERTa列为SuperGLUE此前的最好结果（84.6）。
  • 使用
    XLM-R2019.11 · LLM 已核对
    照搬RoBERTa的训练配方（大批量、长训练、只做掩码预测），把它从英语推广到100种语言。
  • 竞争
    ELECTRA替换词检测2020.03 · LLM 已核对
    RoBERTa靠更多数据和算力提升BERT；ELECTRA靠更好的预训练任务，用不到1/4算力达到同等水平。
  • 改进
    BART2019.10 · LLM 已核对
    仍是只有编码器的结构，无法直接生成文本。
  • 竞争
    ALBERT参数共享2019.09 · LLM
    同期都指出NSP有问题：RoBERTa直接去掉，ALBERT改成更难的句序预测。
  • 延续
    DeBERTa解耦注意力2020.06 · LLM
    在RoBERTa的训练配方上改注意力和解码层，用一半数据取得更好成绩。
  • 使用
    OPT-175B2022.05 · LLM
    预训练语料包含RoBERTa用过的图书、故事和新闻数据。
  • 使用
    CodeBERT2020.02 · LLM
    以RoBERTa作为结构与训练配方的基础。
  • 使用
    Longformer滑窗注意力2020.04 · LLM
    以RoBERTa的参数为起点继续预训练，并与之比较。
  • 使用
    MDETR2021.04 · 多模态
    用RoBERTa作文字编码器。

本篇术语

  • 动态掩码　每次把样本送进模型时重新随机选要遮住的位置，而不是在预处理时一次定死。
  • CC-News　作者从Common Crawl新闻数据中整理的英文新闻语料，6300万篇。

怎么学

先读懂BERT。读RoBERTa第4节，每个小节就是一个单因素实验，注意表格里控制了哪些变量。动手：用Hugging Face加载roberta-base与bert-base，在同一个分类任务上用相同超参数微调对比。
