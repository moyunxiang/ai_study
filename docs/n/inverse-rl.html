逆强化学习IRL

Algorithms for Inverse Reinforcement Learning
2000论文重要ICML 2000Andrew Y. Ng, Stuart Russell · 加州大学伯克利分校待核对
论文PDF（Ng主页） ↗Wikipedia：Inverse RL ↗在交互版中打开（演化树、学习进度）

问题

强化学习默认奖励函数是已知的，但“开好车”这样的任务很难写出奖励；研究动物和人类行为时，奖励更是要去测量的未知量。能看到专家怎么做，却不知道他在优化什么。

方法

把问题反过来：给定环境模型和专家的（最优）策略，求出能让这个策略成为最优的奖励函数。先刻画所有这样的奖励构成的集合，再用线性规划挑出一个最能把专家策略和其他策略区分开、又尽量简单的奖励。

影响

首次给出逆强化学习的形式化定义和可计算算法，开启了从示范中学奖励的路线：学徒学习、最大熵IRL、GAIL，以及从人类偏好学奖励模型的RLHF都沿着这条思路。

背景

前一年同一团队的基于势函数的奖励塑形研究了“改哪些奖励不会改变最优策略”。Russell在1998年提出了反方向的问题：观察一个智能体在各种情况下的行为，能否推断它在优化什么奖励？

论文给出两个动机。一是科学：RL被用作动物学习的模型（例如蜜蜂觅食、多巴胺与TD误差这类工作），但这些模型都假设奖励已知；蜜蜂到底如何权衡花蜜、飞行距离、风险，事先无从知道。二是工程：想让机器“开好车”，写不出奖励，但能拿到专家的示范。当时的模仿学习（如ALVINN端到端驾驶、机器人示教学习）直接学“状态→动作”的映射；作者认为奖励才是对任务最简洁、最可迁移的描述。

方法

有限状态、已知策略。设专家在每个状态都选动作a₁，转移矩阵为P_a，折扣γ。由动态规划与Bellman方程方程，V^π = (I − γP_{a₁})⁻¹R。a₁处处最优，当且仅当对每个其他动作a：

(P_{a₁} − P_a)(I − γP_{a₁})⁻¹ R ⪰ 0（定理3）

这刻画了所有可行的奖励R。问题马上出现：退化——R = 0（或任何常数）永远满足条件，因为奖励处处相同时任何策略都是最优的；而且通常还有无数个解。

挑一个合理的解：作者提出两条启发式，并写成线性规划：（1）让专家动作比次优动作的价值差距尽量大（类似最大间隔）；（2）加一个−λ‖R‖₁惩罚，偏好大部分状态奖励为0的简单奖励。

大状态空间：把奖励写成特征的线性组合R(s) = Σ αᵢφᵢ(s)，只在采样的状态上施加约束。

只有轨迹、没有完整策略：用蒙特卡洛轨迹估计每个特征的折扣累计值，于是任意α下专家的价值都能线性算出。算法迭代：从一个随机策略开始，求一个让专家价值超过已有策略的α，再在这个奖励下求最优策略、加入集合，反复进行。

结果

5×5网格（30%概率随机走，右上角奖励1）：不加惩罚时恢复出大致结构但“凹凸不平”，λ取在相变点下方时几乎等于真实奖励。山地车（连续状态）：用26个高斯基函数表示奖励，基本恢复了“每步−1”的结构；把真实奖励改为“停在谷底附近得1”后，也恢复了主要结构，只在右端有个伪影。连续版网格上的轨迹版算法同样找到了右上角的奖励区域。

后来的发展

学徒学习（Abbeel & Ng 2004）指出不必恢复“真”奖励，只要让学徒的特征期望与专家相同；直升机特技飞行RL用这类方法学会了直升机特技飞行；最大熵逆强化学习用最大熵原理给出处理次优、带噪示范的概率解法；GAIL跳过显式奖励，用判别器直接对齐行为分布。从人类比较中学奖励的从人类偏好学习奖励、InstructGPT与RLHF的奖励模型，也是“奖励要从人那里学来”这一思想的延续。

容易误解的地方

  • IRL的结果本质上不唯一：同一行为可由许多奖励解释，算法给出的只是按启发式挑出的一个。
  • 原始算法假设专家完全最优，示范里的失误会被当成“专家就是想这样”。

局限与后续

  • 退化问题没有根本解决：很多奖励（包括全零）都能解释同一行为，只能靠最大间隔和L1惩罚这类启发式挑一个。
    后来针对它的工作　学徒学习 最大熵逆强化学习
  • 假设示范是最优的，无法合理处理人类示范中常见的噪声和次优行为。
    后来针对它的工作　最大熵逆强化学习
  • 需要已知环境模型或反复求解最优策略的内循环，计算昂贵，只在小网格和山地车上演示。
    后来针对它的工作　GAIL
  • 奖励被限定为人工选定特征的线性组合，表达能力有限。
    后来针对它的工作　GAIL 从人类偏好学习奖励

它建立在什么之上

  • 延续
    多巴胺与TD误差1997.03 · RL
    用RL解释动物行为的工作假设奖励已知；IRL把奖励本身变成要从行为中测量的对象。
  • 延续
    基于势函数的奖励塑形1999 · RL
    塑形研究“哪些奖励给出同一最优策略”；IRL直面同一个不可辨识性，并把它变成从行为反推奖励的问题。
  • 使用
    动态规划与Bellman方程1957 · RL
    可行奖励集合的刻画直接由Bellman方程和最优性条件推出。
  • 竞争
    ALVINN端到端驾驶1989 · 具身·世界模型
    ALVINN式模仿学习直接拟合状态到动作的映射；IRL主张先恢复奖励，认为它比策略更简洁、更能迁移到新环境。
  • 竞争
    机器人示教学习1997 · 具身·世界模型
    机器人示教学习同样从示范出发，但学的是动作或轨迹本身；IRL学的是示范背后的目标。

读懂它需要的概念

马尔可夫决策过程 Bellman方程 策略与价值函数 模仿学习与行为克隆 线性回归 奖励设计与奖励投机

本篇术语

  • 逆强化学习（IRL）　已知环境和专家行为，反推专家在优化的奖励函数；与普通RL（已知奖励求最优行为）方向相反。
  • 退化　许多不同的奖励函数都能让同一个策略成为最优，最极端的是处处为0的奖励。
  • 线性规划　在线性不等式约束下最大化线性目标的优化问题，有高效的通用求解器。

怎么学

先懂Bellman方程和模仿学习与行为克隆。读原文第3节（定理3与线性规划）和第6节实验。动手：在5×5网格上用scipy的linprog实现第3.2节的算法，对比λ=0与较大λ时恢复出的奖励热图；然后读学徒学习和最大熵逆强化学习。
