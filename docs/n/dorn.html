DORN序数回归深度

Deep Ordinal Regression Network for Monocular Depth Estimation
2018.06论文延伸CVPR 2018Huan Fu, Mingming Gong, Chaohui Wang, Kayhan Batmanghelich, Dacheng Tao · 悉尼大学 / 匹兹堡大学 / 卡内基梅隆大学 等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

监督式单目深度一般当作回归问题、最小化均方误差，收敛慢、容易陷入不理想的解；网络里反复池化又让特征图分辨率太低。

方法

把连续深度按“越远间隔越大”的方式切成若干段，把深度预测改成有序的分类（序数回归）；网络用空洞卷积和多尺度并行结构，避免不必要的池化。

影响

在KITTI、NYU Depth v2等四个基准上取得当时最好结果并赢得2018年Robust Vision Challenge，“把深度离散成区间来预测”的思路被AdaBins自适应区间等后续工作沿用。

方法

间隔递增离散化（SID）：把深度范围 [α, β] 在对数空间均匀切成K段，近处的区间窄、远处的区间宽。这符合实际需求——10米处差1米无所谓，1米处差1米就是大错。

序数回归：深度区间是有顺序的，不能当成互不相关的类别。DORN对每个像素输出K个二分类：“深度是否大于第k个阈值？”。训练时对每个阈值做二元交叉熵，推理时数一数有多少个“是”，就得到落在第几个区间，再取区间中心作为深度。这样既利用了分类训练稳定、收敛快的好处，又保留了“3号区间比8号区间更接近4号”的顺序信息。

网络结构：在骨干网络后用类似DeepLabv3与ASPP的空洞卷积多分支（加一路全图特征）并行提取多尺度上下文，代替反复池化再用跳跃连接或多层反卷积恢复分辨率的做法。

摘要称该方法精度明显更高、收敛更快，在KITTI、ScanNet、Make3D和NYU Depth v2四个基准上取得当时最好结果，并获得Robust Vision Challenge 2018第一名。

后来的发展

离散化思路被AdaBins自适应区间推进为“每张图自适应地决定区间”，又被ZoeDepth的度量区间模块沿用；随着DPT稠密预测ViT、MiDaS混合数据集深度等跨数据集训练模型出现，单数据集监督式深度逐渐退出主流。

局限与后续

  • 区间是固定的，所有图都用同一套划分；室内和室外深度分布差别很大，固定区间浪费精度，输出也有明显的台阶感。

本篇术语

  • 序数回归　预测有顺序的等级（如1–5星），常拆成一组“是否大于第k级”的二分类，兼顾分类和顺序信息。
  • 间隔递增离散化　在对数尺度上均匀切分深度范围，近处切得细、远处切得粗。

怎么学

先理解普通回归与分类损失的区别，再读DORN第3节SID与序数损失；自己实现一次对数空间离散化，比较均匀切分与SID在近处的分辨率差别。
