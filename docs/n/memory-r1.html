Memory-R1记忆管理RL

Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning
2025.08论文延伸Sikuan Yan, Xiufeng Yang, Zuchao Huang, Ercong Nie, Zifeng Ding, Zonggen Li, Xiaowen Ma, Jinhe Bi et al. · 慕尼黑大学 / 慕尼黑工业大学 / 剑桥大学 / 香港大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

给LLM加外部记忆库的做法多是静态规则：什么时候存、改、删全凭提示词和启发式，模型并没有学会怎样管理记忆才能在以后答对问题。

方法

用两个经强化学习训练的智能体：记忆管理者对每条新信息选择增、改、删或不动；回答者从检索到的记忆里筛出有用条目再作答；两者都只用最终答案是否正确作为奖励。

影响

把R1式结果奖励强化学习用到智能体的记忆管理上，只用152道训练题就在长对话记忆基准上超过Mem0等基于规则的记忆系统。

方法

MemGPT、Mem0长期记忆、A-MEM卡片盒记忆等系统由LLM按提示决定记忆的增删改，没有针对“以后能否答对”优化。论文的例子：用户先说领养了狗Buddy，后来又说领养了Scout；普通管理者删掉第一条、加上第二条，丢了信息；训练后的管理者用一次UPDATE把两条狗合并记下。

记忆管理者。每轮对话抽出新事实，与检索到的旧记忆对比，输出ADD、UPDATE、DELETE或NOOP之一。它的奖励来自下游：执行操作后，用更新过的记忆库让回答者答题，答案与标准答案精确匹配即得分。

回答者。对每个问题先检索约60条候选记忆，学会只挑出相关条目（记忆蒸馏），再推理作答，同样用精确匹配奖励。

训练与结果。两者分别用PPO或GRPO训练，底座为LLaMA-3.1-8B-Instruct和Qwen-2.5的3B、7B、14B，训练数据只有LoCoMo里的152道问答。在LoCoMo上，LLaMA-3.1-8B的GRPO版本相对最强基线MemoryOS，F1提升约28.5%、LLM评判分提升约30.2%；不再训练就能迁移到MSC和LongMemEval两个基准。

局限与后续

  • 奖励依赖带标准答案的问答，只能在LoCoMo这类有现成问题的对话记忆基准上训练，真实用户场景里没有现成奖励。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 记忆仍是扁平的文本条目和四种固定操作，没有处理层次化组织、时间推理或多模态记忆。

    A-MEM卡片盒记忆2025.02 · 推理·智能体

    Mem0长期记忆2025.04 · 推理·智能体
    Mem0用提示让LLM决定增删改记忆；Memory-R1保留同样的四种操作，但用答题正确率做奖励训练这一决策，在LoCoMo上超过Mem0。
