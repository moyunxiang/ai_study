SR3扩散超分辨率

Image Super-Resolution via Iterative Refinement
2021.04论文延伸TPAMI 2022Saharia, Ho, Chan, Salimans, Fleet, Norouzi · Google Research待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

超分辨率常用回归或GAN，回归给出模糊结果，GAN则训练不稳且易模式缺失。

方法

把DDPM改成条件生成：从纯噪声开始，以低分辨率图为条件，用U-Net反复去噪细化出高分辨率图。

影响

首次证明扩散模型在超分辨率上可超过GAN，并展示了级联扩散生成大图的路线。

方法

SR3训练一个以低分辨率图像（先放大到目标尺寸）为条件的去噪U-Net（见U-Net）：输入是加噪的高分辨率图、低分辨率图拼接和噪声水平，输出预测的噪声。训练与DDPM相同。推断时从纯高斯噪声开始，迭代细化多步，得到的是满足条件的一个采样，而非唯一的回归值，因此可以生成清晰且多样的细节。

摘要给出：在CelebA-HQ 8倍超分的人类评估中，SR3的欺骗率（让人把输出误认为真图）接近50%，而GAN不超过34%；在级联生成中，把无条件或类条件模型与SR3串联，ImageNet上取得竞争力的FID 11.3。

局限与后续

  • 每张图需要几十到上百步的迭代去噪，推断比一次前向的GAN慢几个数量级。

它建立在什么之上

  • 延续
    DDPM2020.06 · 生成
    把DDPM改成以低分辨率图为条件的条件生成，用于超分辨率。
  • 使用
    U-Net2015.05 · 视觉
    去噪网络采用U-Net。
  • 改进
    SRGAN2016.09 · 视觉
    GAN训练不稳定，会生成看似合理、实际并不存在的伪细节，不适合需要保真的场景。

后来的相关工作

  • 改进
    潜空间扩散LDM2021.12 · 生成
    每个放大倍率需要单独训练模型，高分辨率仍直接在像素空间运行，代价大。
  • 使用
    级联扩散2021.05 · 生成
    每一级超分模型就是SR3式的条件扩散模型，并加入条件增强防止误差累积。
  • 改进
    一致性模型2023.03 · 生成
    每张图需要几十到上百步的迭代去噪，推断比一次前向的GAN慢几个数量级。
