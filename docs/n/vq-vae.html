VQ-VAE

Neural Discrete Representation Learning
2017.11论文重要NeurIPS 2017Aaron van den Oord, Oriol Vinyals, Koray Kavukcuoglu · DeepMind待核对
arXiv ↗DeepMind Sonnet中的VQ-VAE示例 ↗在交互版中打开（演化树、学习进度）

问题

VAE的隐变量是连续高斯，配上强大的自回归解码器时常被完全忽略（后验坍塌）；而语言、音素、物体类别等很多信息本质上是离散的，连续隐变量也不便交给自回归模型建模。

方法

让编码器的输出去查一本可学习的“码本”，替换成最近的那个码向量，于是每张图被压成一格格离散编号；用直通估计把梯度绕过不可导的查表；最后再用PixelCNN等自回归模型学习这些编号的分布。

影响

确立了“先把图像、音频压成离散token，再用自回归或掩码模型生成token”的两阶段范式，DALL·E、VQGAN、音频编解码器和后来的图像token化都由此而来。

背景

变分自编码器VAE把数据编码成连续的高斯隐变量。为了让样本更清晰，人们给它配上很强的解码器，例如PixelRNN / PixelCNN这类逐像素自回归模型。问题是：解码器强到不看隐变量也能把图生成得不错时，优化会让编码器输出直接退化成先验，KL项变成0，隐变量不携带任何信息，这就是后验坍塌（后验坍塌与KL退火）。

另一方面，自回归模型（PixelRNN / PixelCNN、WaveNet）在像素或音频采样点上直接建模，能生成很好的局部细节，但要花大量容量在难以察觉的噪声上，序列也极长：一张128×128的彩色图就是近5万个数。如果能先把数据压成短得多的离散符号序列，再在上面训练自回归模型，就像语言模型处理单词一样，会高效得多。问题是离散变量无法直接求梯度。

方法

码本与量化（见向量量化与离散token）。准备一个含K个向量的码本（图像实验K=512）。编码器把图像变成一张特征图，特征图上每个位置的向量z_e都去码本里找L2距离最近的码向量e_k，用它替换z_e后交给解码器。一张128×128×3的ImageNet图像就被压成32×32个编号，每个编号取值0到511。

梯度怎么过去（见离散变量的梯度：直通估计与Gumbel-Softmax）。“找最近邻”不可导。做法是直通估计：反向传播时，把解码器输入处的梯度原样复制给编码器输出，假装量化这一步是恒等映射。

三项损失：

L = −log p(x | z_q) + ‖sg[z_e] − e‖² + β‖z_e − sg[e]‖²

sg表示停止梯度。第一项是重建；第二项把码向量拉向编码器输出（只更新码本）；第三项是承诺损失，让编码器输出不要离选中的码向量太远、不要来回跳（只更新编码器），β=0.25，作者报告0.1到2.0之间结果都稳健。附录还给出用指数滑动平均更新码本的替代方案。

两阶段生成。第一阶段训练好VQ-VAE后，把训练集全部编码成编号网格；第二阶段在这些编号上训练一个自回归先验（图像用PixelCNN，音频用WaveNet）。生成时先由先验逐个采样编号，再交给解码器一次性还原成图像。

结果

CIFAR-10上VQ-VAE的对数似然下界为每维4.67比特，接近连续VAE的4.51，优于VIMCO的5.14——这是离散隐变量模型首次接近连续模型。ImageNet上把128×128×3图像压到32×32×1、K=512的离散码，比特数约减少42.6倍，重建仍保留了主要结构。语音上，在VCTK数据集上无监督学到的离散码与音素对应，按41类映射准确率为49.3%（随机为7.2%）；解码时替换说话人编号即可做声音转换。论文还在DeepMind Lab上做了以动作为条件的视频生成。作者指出即使配上强大的PixelCNN解码器，VQ-VAE也没有出现后验坍塌。

后来的发展

2019年VQ-VAE-2用多层级码本加更强的先验，大幅提升了生成质量。2020年VQGAN给它加上对抗损失和感知损失，让每个码承载更多细节，并用Transformer建模码序列；DALL·E用它的变体（离散VAE）把图像变成token，与文本token一起交给GPT式模型。同样的思想在音频上演变为神经音频编解码器、EnCodec等神经编解码器，成为VALL-E、AudioLM等语音生成模型的基础；Jukebox用它生成音乐。码本利用率低的问题后来由有限标量量化FSQ、MAGVIT-v2与LFQ分词器的无码本量化缓解。今天的潜空间扩散模型多用连续隐变量，但离散token路线在自回归多模态模型中仍是主流之一。

    它是有偏的启发式估计，没有理论保证梯度方向正确；对多层离散化的深网络，误差会累积，训练可能不稳定。

读懂它需要的概念

自编码器 向量量化与离散token 离散变量的梯度：直通估计与Gumbel-Softmax 隐变量模型 自回归生成 变分推断与ELBO

本篇术语

  • 码本（codebook）　一组可学习的向量，相当于离散“词表”。编码器输出被替换成码本中最近的向量，于是数据被表示为一串编号。
  • 直通估计（straight-through）　前向用不可导的离散操作，反向时把梯度原样传过去，当作这个操作是恒等函数。
  • 承诺损失　惩罚编码器输出离所选码向量太远，防止编码器输出无限增长或在码之间频繁跳动。

怎么学

先读变分自编码器VAE，补向量量化与离散token与离散变量的梯度：直通估计与Gumbel-Softmax中的直通估计。原文第3节只有两页，重点是公式(3)中三项损失各自更新哪部分参数。动手：在CIFAR-10上实现VQ-VAE，统计训练过程中码本有多少个码真正被用到，再尝试用指数滑动平均更新码本对比利用率。
