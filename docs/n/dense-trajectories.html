稠密轨迹

Action Recognition by Dense Trajectories
2011.06论文延伸CVPR 2011Heng Wang, Alexander Kläser, Cordelia Schmid, Cheng-Lin Liu · 中国科学院自动化研究所 / INRIA待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

早期视频动作识别靠KLT跟踪或SIFT匹配得到特征轨迹，轨迹数量少、质量差，遇到快速不规则运动容易断。

方法

在每帧上稠密采样点，沿稠密光流场把它们连成轨迹，再在轨迹周围算HOG、HOF和新的运动边界直方图MBH，用词袋模型分类。

影响

成为深度学习之前动作识别的最强手工特征；改进版iDT直到2015年前后仍是深度视频模型的对照和融合对象。

方法

做法分三步。第一，在多个尺度上按网格稠密采样特征点，去掉纹理太弱的点；第二，用稠密光流（论文采用Farnebäck算法）把每个点逐帧往后推，形成固定长度（如15帧）的轨迹，漂移过大的轨迹丢弃；第三，在轨迹经过的时空管道里计算描述子：外观用HOG与手工特征时代，运动用光流方向直方图HOF，以及本文提出的MBH——对光流的水平、竖直分量各自求梯度再做直方图。MBH只看运动的“边界”，相机整体平移造成的均匀光流被抵消，因而对镜头运动更稳。最后像视觉词袋那样把描述子量化成视觉词，统计词袋直方图，用SVM分类。

摘要报告它在KTH、YouTube、Hollywood2、UCF Sports四个难度不同的数据集上都明显超过当时最好的方法，MBH在不受控的真实视频上一致优于其他描述子。

后来的发展

2013年Wang与Schmid的改进版iDT进一步估计并补偿相机运动、改用Fisher向量编码。双流网络等早期深度模型都把iDT当作主要对照，并常与之融合提分；C3D三维卷积、I3D与Kinetics之后才被逐渐取代。

读懂它需要的概念

图像作为张量 特征与表示学习 聚类 核技巧与间隔 分类、检测、分割

本篇术语

  • 光流　相邻两帧之间每个像素移动的方向和距离，可以看成一张二维位移场。
  • MBH　运动边界直方图：对光流场本身再求梯度并统计方向，突出运动物体的边缘，抵消相机平移。

怎么学

先理解HOG和视觉词袋，再读原文第2–3节的轨迹提取与MBH；之后对照Wang与Schmid 2013年的iDT论文看相机运动补偿。
