RESCAL张量分解

A Three-Way Model for Collective Learning on Multi-Relational Data
2011.06论文延伸ICML 2011Maximilian Nickel, Volker Tresp, Hans-Peter Kriegel · 慕尼黑大学、西门子待核对
ICML ↗在交互版中打开（演化树、学习进度）

问题

知识库里的事实是多种关系交织的三元组，要预测缺失的事实（链接预测）或判断两个名字是否指同一实体，需要利用跨关系、跨实体的间接信息；已有的张量分解方法做不到这种「集体学习」。

方法

把知识库写成一个「实体×实体×关系」的三阶0/1张量，每种关系的切片分解为 X_k ≈ A R_k Aᵀ：所有关系共享同一个实体向量矩阵A，每种关系有一个小的交互矩阵R_k，用交替最小二乘高效求解。

影响

RESCAL是知识图谱嵌入的奠基模型之一，「实体是向量、关系是双线性变换」的形式被DistMult、ComplEx等直接继承，也是TransE等平移模型的主要对照对象。

背景

Freebase、YAGO知识库、DBpedia等知识库在2007年前后出现，它们由大量（主语，关系，宾语）三元组构成，且普遍不完整。统计关系学习希望从已有事实中推断新事实。矩阵分解在推荐系统中（Netflix Prize）证明了低秩隐因子能很好地补全稀疏的用户-物品矩阵，潜在语义分析LSA也用低秩分解捕捉词与文档的潜在语义。但知识库有多种关系，对每种关系单独分解矩阵，就无法让一种关系里的信息帮助另一种关系。

方法

张量表示。 n个实体、m种关系，构造张量 X ∈ {0,1}^{n×n×m}：X_ijk = 1 当且仅当事实（实体i，关系k，实体j）成立。

分解。 对第k个切片 X_k ≈ A R_k Aᵀ，其中 A ∈ R^{n×r} 的第i行是实体i的r维隐向量，R_k ∈ R^{r×r} 刻画在关系k下各隐维度之间如何相互作用。于是三元组得分 score(i, k, j) = a_iᵀ R_k a_j，这是一个双线性函数；R_k不对称，因此能区分主语和宾语的方向。

为什么能集体学习。 实体i无论作为主语还是宾语、出现在哪种关系中，都使用同一个向量a_i。论文的例子：要预测某位美国副总统所属的政党，可以经由「他与哪位总统搭档」「那位总统属于哪个党」把信息传过来；独立的矩阵分解或把主宾语用不同向量的张量分解（如Tucker、PARAFAC的常见用法）做不到。

优化。 最小化 Σ_k ‖X_k − A R_k Aᵀ‖² + 正则项，用交替最小二乘：固定A时R_k有闭式解，固定所有R_k时A也可以闭式更新，计算复杂度对实体数是线性的，能处理较大的数据。

结果

摘要称：在一个新数据集和一个常用的实体消解数据集上的实验验证了集体学习能力，在常用基准数据集上效果优于或持平于当时的关系学习方法，并且计算比它们快（论文中使用Kinships、UMLS、Nations等数据，具体数字未逐项核对）。

后来的发展

Nickel等在2012年把RESCAL扩展到YAGO全库的规模。为了减少参数，DistMult（2014）把R_k限制为对角矩阵，ComplEx（2016）用复数对角矩阵恢复对非对称关系的建模；TransE知识图谱嵌入（2013）走另一条路，把关系看成向量空间中的平移；RotatE旋转嵌入（2019）则把关系看成复平面上的旋转。RESCAL本身在适当调参和正则化后，后续复现研究中仍表现出很强的竞争力。

局限与后续

它建立在什么之上

  • 延续
    潜在语义分析LSA1990.09 · NLP
    LSA对词-文档矩阵做低秩分解，RESCAL把低秩隐因子推广到多关系的三阶张量。
  • 延续
    Netflix Prize2006.10 · 数据·评测
    借鉴推荐系统中用隐因子分解补全稀疏矩阵的做法，用于补全知识库中的缺失事实。
  • 改进
    Freebase2007.03 · NLP
    面向Freebase这类大规模但不完整的多关系知识库，提供可扩展的缺失事实推断方法。

后来的相关工作

  • 改进
    TransE知识图谱嵌入2013.12 · NLP
    每种关系一个r×r的满矩阵，参数量随隐维度平方增长，关系很多时容易过拟合。
  • 竞争
    TransH超平面平移嵌入2014.07 · NLP
    RESCAL用关系矩阵能表达复杂映射但参数多；TransH以接近TransE的参数量取得折中。
  • 改进
    RotatE旋转嵌入2019.02 · NLP
    RESCAL给每个关系一个完整矩阵，参数多且不显式区分关系模式；RotatE每个关系只用一组相位，并能解释对称、互逆与组合。

读懂它需要的概念

特征分解与奇异值分解 低秩近似 向量、矩阵与张量 正则化与权重衰减 嵌入向量

本篇术语

  • 链接预测　给定知识图谱中的部分事实，预测缺失的（主语，关系，宾语）三元组。
  • 三阶张量　可以看成一叠矩阵的三维数组，这里每一层对应一种关系。
  • 交替最小二乘　轮流固定一部分参数、对另一部分求最小二乘闭式解，反复迭代的优化方法。

怎么学

先复习矩阵分解与SVD → 读原文第3节模型和第4节ALS更新公式 → 动手：在UMLS或Kinships小数据集上用numpy实现RESCAL-ALS，计算链接预测的AUC，并与把每种关系单独做矩阵分解的结果对比。
