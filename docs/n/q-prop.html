Q-Prop控制变量策略梯度

Q-Prop: Sample-Efficient Policy Gradient with An Off-Policy Critic
2016.11论文延伸ICLR 2017Shixiang Gu, Timothy Lillicrap, Zoubin Ghahramani, Richard E. Turner, Sergey Levine · 剑桥大学 / DeepMind / Google Brain / UC伯克利待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

同策略的批量策略梯度（TRPO+广义优势估计GAE）稳定但方差大，要很大的批次、很多样本；离策略的DDPG省样本但有偏，对超参很敏感、容易发散。两条路线的优点很难兼得。

方法

Q-Prop用一个离策略训练的评论家Q_w作为策略梯度的控制变量：把Q_w在当前策略均值动作处做一阶泰勒展开，解析地算出它对应的那部分梯度（类似DDPG），剩下的残差再用同策略的蒙特卡洛估计，从而在不引入偏差的前提下降低方差。

影响

把「控制变量」的统计学工具系统地带进深度策略梯度，开启了一批同策略/离策略混合方法（IPG、动作相关基线等）的讨论；后来关于这些基线到底降了多少方差的争论也由此而来。

方法

策略梯度的标准估计是 ∇J = E[∇log π(a|s) · Â(s,a)]，方差主要来自Â。控制变量的思想是：减去一个与它相关、但期望可以解析算出的量，再把这个期望加回来，估计仍然无偏，方差却可能小很多。

Q-Prop选的控制变量是评论家Q_w在 ā = μ_θ(s)（策略的均值动作）处的一阶泰勒展开：Q̄(s,a) = Q_w(s,ā) + ∇_a Q_w(s,ā)·(a − ā)。对这个线性函数，策略梯度的期望部分可以解析求出，结果正是一个DDPG式的确定性梯度项 E_s[∇_a Q_w(s,ā) ∇_θ μ_θ(s)]。于是 ∇J ≈ E[∇log π(a|s)·(Â(s,a) − η·Ā(s,a))] + η·E_s[∇_a Q_w(s,ā) ∇_θ μ_θ(s)]， 其中Ā是泰勒展开对应的优势，Â用同策略样本和广义优势估计GAE估计。评论家Q_w用回放缓冲区里的离策略数据训练，提高了数据利用率。

系数η决定用多少控制变量。作者从控制变量理论推出两个变体：保守版只在Â与Ā正相关时启用（η=1，否则0），激进版在负相关时用η=−1。摘要称，保守Q-Prop在MuJoCo任务上比TRPO+GAE样本效率显著更高，又比DDPG更稳定。

后来的发展

Q-Prop之后，「用动作相关的控制变量给策略梯度降方差」成了一个小方向：同一作者的插值策略梯度（IPG）在同策略与离策略梯度之间插值，另有工作用Stein恒等式构造更一般的动作相关基线。2018年Tucker等人的分析指出，在常见基准上这类基线实际降低的方差比预想的小，部分报告的收益可能来自实现细节，这场讨论也是深度RL复现性争论的一部分。今天主流做法仍是同策略用PPO加GAE、离策略用SAC，Q-Prop主要作为思想来源被引用。

  • 控制变量　从估计量中减去一个期望已知、且与之相关的量再加回期望，保持无偏而降低方差的统计技巧。
