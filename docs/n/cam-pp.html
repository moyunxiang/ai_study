CAM++高效说话人验证

CAM++: A Fast and Efficient Network for Speaker Verification Using Context-Aware Masking
2023.03论文延伸Interspeech 2023Hui Wang, Siqi Zheng, Yafeng Chen, Luyao Cheng, Qian Chen · 阿里巴巴达摩院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

ECAPA-TDNN说话人验证效果最好，但计算复杂、推理慢，不适合对速度和算力有要求的场景。

方法

以密集连接的TDNN为骨干，加入上下文感知掩码和多粒度池化，在不同层次上捕捉上下文信息。

影响

在保持ECAPA-TDNN水平的同时计算量和推理时间大幅降低，被收入达摩院3D-Speaker工具包，成为中文声纹识别和说话人日志的常用模型。

方法

CAM++的骨干是密集连接的时延神经网络（D-TDNN）：每一层都接收前面所有层的输出，参数复用率高、网络更窄。在每个D-TDNN层里加入上下文感知掩码：先在不同粒度上（整句级和片段级）对特征做池化得到上下文向量，再据此生成一个注意力掩码，突出与说话人相关的帧、抑制噪声和无关信息。前端还加了一个轻量的二维卷积模块，捕捉频率方向上的局部细节。在VoxCeleb和CN-Celeb两个公开基准上，CAM++取得了比ECAPA-TDNN更低或相当的错误率，计算量和推理时间明显更低。

局限与后续

  • 针对干净或中等噪声的单人语音，在多人重叠和远场强混响下仍需配合分离和增强。
