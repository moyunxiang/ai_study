ERNIE 3.0

ERNIE 3.0: Large-scale Knowledge Enhanced Pre-training for Language Understanding and Generation
2021.07论文延伸arXiv 2021Yu Sun, Shuohuan Wang, Shikun Feng, Siyu Ding et al. · Baidu待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

GPT-3、T5这类大模型只用纯文本训练，没有显式融入知识，而且自回归训练在下游理解任务上微调效果偏弱。

方法

提出统一框架：共享的通用网络加任务专用网络，既有自回归也有自编码分支，并在纯文本之外加入大规模知识图谱数据。

影响

在中文NLP任务上拿到强结果，是百度文心系列的基础模型，也是早期中文大模型的代表。

方法

背景：百度ERNIE系列已经尝试把实体、短语等知识融入预训练。GPT-3、T5让参数规模成为主要手段，但百度认为纯文本训练缺少语言学和世界知识，且纯自回归模型对理解类任务不理想。

做法：ERNIE 3.0把自回归网络和自编码网络融合到一个框架里，让同一个模型既能做理解也能做生成，并支持零样本、少样本和微调三种使用方式。训练规模为100亿参数，语料4TB，由纯文本和大规模知识图谱组成。

结果：摘要称在54个中文NLP任务上超过当时最先进模型，其英文版在2021年7月3日的SuperGLUE榜单上排名第一，超过人类基线0.8分。

局限与后续

  • 100亿参数的规模明显小于同期GPT-3级别模型，后来的ERNIE 3.0 Titan才扩到更大规模。
    后来针对它的工作　GLM-130B
  • 知识图谱对效果的贡献缺少独立的大规模验证，后续模型主要靠扩大纯文本规模取胜。
    后来针对它的工作　Chinchilla

它建立在什么之上

  • 竞争
    T52019.10 · LLM
    T5用统一的文本到文本框架，ERNIE 3.0用共享加任务专用网络，走不同的统一路线。
  • 延续
    百度ERNIE2019.04 · LLM
    在ERNIE的知识增强思路上扩展到百亿参数并统一理解与生成。

后来的相关工作

  • 改进
    Chinchilla2022.03 · LLM
    知识图谱对效果的贡献缺少独立的大规模验证，后续模型主要靠扩大纯文本规模取胜。
  • 改进
