最小割主观句情感分类

A Sentimental Education: Sentiment Analysis Using Subjectivity Summarization Based on Minimum Cuts
2004.07论文延伸ACL 2004Bo Pang（庞博）, Lillian Lee · 康奈尔大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

影评的情感分类里，评论常常大段复述剧情（“反派一路追杀主角……”），这些客观句里的情感词会误导分类器；而判断一句话是否主观，又应当参考相邻句子——主观句往往成片出现。

方法

先从评论中抽出主观句、丢掉客观句，再只对主观部分做极性分类；抽主观句时，把每个句子的主观概率和“相邻句应该同类”的约束一起写成图上的最小割问题，用多项式时间的最大流算法求全局最优划分。

影响

只用主观句摘要就能保持甚至提高极性分类精度；“先做主观性过滤、再做极性分类”的流水线和最小割建模句间约束的方法被大量后续工作采用，论文发布的主观性数据集与2000篇影评极性数据集v2.0成为情感分析的经典基准。

背景

机器学习情感分类（Pang、Lee与Vaithyanathan，2002）证明朴素贝叶斯、最大熵、SVM等机器学习方法可以做影评正负分类，但准确率明显低于主题分类，原因之一是评论中混杂大量客观描述。Wiebe等人的研究已提出区分主观与客观句；但逐句独立分类忽视了句子之间的连贯性。图割在计算机视觉中已被用于图像分割，可以把“每个点的独立偏好”与“相邻点应当一致”的约束统一优化。同年稍晚，评论观点挖掘与摘要则从另一个角度做细粒度的评论属性观点挖掘。

方法

两阶段流程：主观性检测器从文档中选出主观句（构成“主观性摘要”），再交给标准的极性分类器（朴素贝叶斯或SVM）判断正负。

最小割建模：对一篇文档的n个句子构造图：源点s代表“主观”，汇点t代表“客观”。

  • 每个句子x_i连边 s→x_i，容量为 ind_1(x_i)（独立分类器给出的主观概率），连边 x_i→t，容量为 ind_2(x_i) = 1 − ind_1(x_i)；
  • 每对句子 x_i、x_j 之间连边，容量为关联分数 assoc(x_i, x_j)，随两句距离增大而减小（如距离超过阈值T时为0）。

把句子划分为主观集合C₁与客观集合C₂的代价为

cost = Σ_{x∈C₁} ind_2(x) + Σ_{x∈C₂} ind_1(x) + Σ_{x_i∈C₁, x_k∈C₂} assoc(x_i, x_k)

即违背单句偏好的代价加上把相邻句分到不同类的代价。最小化它恰好是s-t最小割，可用最大流算法在多项式时间内精确求解。

主观句分类器在作者构造的主观性数据集上训练：5000句来自影评网站的评论摘要片段（主观），5000句来自IMDb的剧情简介（客观）。

结果

在2000篇影评的极性数据上，只用主观性摘要做极性分类，准确率与使用全文相当或更好（使用朴素贝叶斯时有显著提升），而摘要只保留了原文的一部分句子；加入最小割的句间约束比逐句独立判断主观性效果更好（原文结论，具体百分比未在此引用）。

后来的发展

这篇论文发布的主观性数据集（SUBJ）和极性数据集v2.0被TextCNN句子分类、NBSVM强基线等句子分类工作反复使用，SUBJ至今仍是SentEval的任务之一。最小割/图划分的思路后来被用于结合跨句、跨文档的约束（如同一作者、同一议题的立场分类）。Pang与Lee在2008年写成的综述观点挖掘与情感分析综述系统总结了这一领域。

本篇术语

  • 主观性　句子表达的是个人观点、评价，还是客观事实描述。
  • 最小割　把图的节点分成分别含源点和汇点的两部分，使被切断的边容量之和最小；它等于最大流，可在多项式时间内求出。

怎么学

先读机器学习情感分类 → 读本文第2节图构造 → 动手：用networkx对一篇评论的十几个句子构造s-t图，用逻辑回归给出主观概率、按句距设关联权重，求最小割得到主观句集合。
