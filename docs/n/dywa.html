DyWA

DyWA: Dynamics-adaptive World Action Model for Generalizable Non-prehensile Manipulation
2025.03论文延伸Jiangran Lyu, Ziming Li, Xuesong Shi, Chaoyi Xu, Yizhou Wang, He Wang · 北京大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

非抓取操作（推、滑、翻转物体）依赖多视角相机和精确位姿追踪，且难以适应物体质量、桌面摩擦等动力学变化。

方法

让策略联合预测未来状态，并根据历史轨迹推断动力学，统一几何、状态、物理和动作的建模。

影响

在部分可观测条件下提高非抓取操作的泛化，把世界-动作联合建模带到真实机器人操作。

方法

DyWA（Dynamics-adaptive World Action Model）受JOWA世界-动作模型等世界-动作模型启发，不只学「在当前状态下该做什么」，还同时学「做了这个动作之后未来状态会怎样」。它的输入包括历史轨迹，模型借此隐式推断物体质量、摩擦等动力学参数，再据此调整动作。

这样即便只有部分观测，也能做出适应不同物理条件的策略。论文称与基线相比成功率有明显提升（具体幅度在摘要中被截断，本次未核实具体数字），并在真机上验证了对不同物体质量和桌面摩擦的泛化。
