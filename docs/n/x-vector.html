x-vector说话人嵌入

X-Vectors: Robust DNN Embeddings for Speaker Recognition
2018.04论文重要ICASSP 2018David Snyder, Daniel Garcia-Romero, Gregory Sell, Daniel Povey, Sanjeev Khudanpur · 约翰斯·霍普金斯大学待核对
IEEE ↗PDF ↗在交互版中打开（演化树、学习进度）

问题

说话人识别的主流i-vector是无监督的统计模型，多给带噪数据也学不到更多；早期神经网络嵌入又需要大量带说话人标签的数据，数据不够时打不过i-vector。

方法

用时延神经网络逐帧提特征，统计池化层把整段语音的均值和标准差拼起来，再训练网络分类说话人，取中间层作为固定长度的“x-vector”；用加噪和混响把训练数据扩增几倍。

影响

在野外视频和粤语电话两个测试集上都超过i-vector，x-vector加PLDA成为2018年后说话人识别和说话人日志的标准方案，被Kaldi等工具广泛采用。

背景

说话人识别要回答“这两段语音是不是同一个人说的”。2011年起的标准做法是i-vector说话人识别：先用大量语音训练一个通用背景GMM（见GMM-UBM说话人确认），把每段语音相对它的偏移压缩成一个几百维的向量，再用PLDA（概率线性判别分析）给两条向量打相似度分。i-vector的提取器是无监督训练的，不用说话人标签，但也正因如此，往训练数据里加更多带噪样本对它帮助不大。

另一种思路是直接训练神经网络区分说话人，取中间层作为嵌入。作者团队2017年已经做过这样的嵌入，并发现它比i-vector更能利用大规模训练数据，但带说话人标签的数据难以大量收集。这篇论文的问题是：能不能用便宜的数据扩增来弥补标注数据的不足？

方法

网络结构。输入是24维滤波器组特征，帧长25ms。前五层是帧级的时延神经网络TDNN：每层把下层在几个相邻时刻的输出拼起来，例如第三层看下层的t−3、t、t+3三个时刻，层层叠加后第三层已经覆盖15帧的上下文。

统计池化。不管一段语音有多少帧T，都把第五层的全部T个1500维输出求均值和标准差，拼成一个3000维向量——变长输入由此变成定长。之后是两个段级全连接层（各512维）和Softmax与logits输出层，训练目标是把训练集里的N个说话人分对。

取嵌入。训练完后丢掉softmax层，取第一个段级层（segment6）在非线性之前的512维输出作为x-vector（见嵌入向量）。不计丢掉的层，网络约420万参数。两条x-vector经过降维、长度归一化后，仍然交给PLDA打分。

数据扩增（见数据增强）。每条训练录音再生成几个副本：叠加3到7人的人声（嘈杂人群）、叠加音乐、每秒叠加一段噪声，或者与房间冲激响应卷积模拟混响，噪声来自MUSAN数据集。

结果

评测用两个集合：Speakers in the Wild（英语网络视频，含噪声和混响）和NIST SRE16粤语电话语音，指标是等错误率EER。不做扩增时，x-vector在SITW上略逊于i-vector（9.40%对9.29%），在粤语上更好（8.00%对9.23%）。对提取器和PLDA都做扩增后，x-vector在SITW上为6.00%、粤语5.86%，而声学i-vector为8.04%、8.95%：扩增对i-vector提取器作用不稳定，对x-vector网络帮助很大。再加入VoxCeleb训练数据，x-vector在SITW上降到4.16%，同条件下i-vector为7.45%。

后来的发展

x-vector加PLDA迅速成为说话人确认、说话人日志（pyannote.audio）和语种识别的默认方案。之后的改进集中在网络本身：ECAPA-TDNN加入通道注意力、多层特征聚合和注意力统计池化，在VoxCeleb上进一步降低错误率；WavLM等自监督模型的特征也被用作x-vector网络的输入。说话人嵌入还成为多说话人TTS和声音克隆（如YourTTS）中表示“谁在说话”的条件向量。

本篇术语

  • 统计池化　把变长序列在时间维上求均值和标准差并拼接，得到一个与长度无关的定长向量，从“逐帧特征”过渡到“整段特征”。
  • PLDA　概率线性判别分析。把嵌入分解为“说话人成分”和“其他变化”，据此计算两个嵌入来自同一说话人的似然比，作为打分器。
  • 等错误率（EER）　调节判定阈值，使误接受率和误拒绝率相等时的错误率。越低越好。
