ESIM自然语言推理

Enhanced LSTM for Natural Language Inference
2016.09论文延伸ACL 2017Chen, Zhu, Ling, Wei, Jiang, Inkpen · 中科大 / 国家研究委员会（加拿大）等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

自然语言推理的前沿模型结构越来越复杂（树结构等），不清楚简单的顺序模型到底差多少。

方法

精心设计的链式LSTM：先用BiLSTM编码，再做注意力对齐、局部推理增强（拼接、相减、相乘）、再用BiLSTM组合，最后池化分类。

影响

以简洁架构在SNLI上达到当时最佳，成为后续句对匹配模型的常用基线。

方法

ESIM分三步。输入编码：前提和假设各过一个BiLSTM。局部推理：用可分解注意力式的软对齐得到对方的加权表示，再把原向量a、对齐向量ã、差a−ã、积a⊙ã拼接，增强对差异的感知。推理组合：再过一个BiLSTM，经平均和最大池化后分类。论文还加入Tree-LSTM做句法信息，可以进一步提升。

摘要称在SNLI上达到88.6%准确率，并证明精心设计的链式LSTM可以优于之前复杂的结构。
