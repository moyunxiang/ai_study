树备份与离策略资格迹

Eligibility Traces for Off-Policy Policy Evaluation
2000.06论文延伸ICML 2000Doina Precup, Richard S. Sutton, Satinder Singh · 马萨诸塞大学阿默斯特分校 / AT&T实验室待核对
UMass存档 ↗在交互版中打开（演化树、学习进度）

问题

离策略评估：用行为策略b收集的数据，估计另一个目标策略π的价值。多步TD与资格迹在同策略下很好用，但离策略时，Q-learning式的多步版本（Watkins的Q(λ)）一遇到非贪心动作就得切断资格迹，学得很慢；简单乘重要性权重又会让方差爆炸。

方法

系统研究带资格迹的离策略评估，提出并比较几种算法：逐决策重要性采样的TD(λ)变体，以及树备份（Tree Backup）——每一步都按目标策略的概率对所有动作求期望，只沿实际走的那个动作继续往后看，因此根本不需要重要性权重。

影响

这篇论文是离策略多步学习的起点：树备份算法进入了Sutton与Barto教材，Retrace离策略修正把树备份和重要性采样的优点结合起来，Q(σ)多步统一算法把树备份与Sarsa统一成一个连续谱。

方法

多步TD的目标把未来几步的奖励和估值串起来。离策略时问题在于：数据里实际走的是b选的动作，而我们关心π下的回报。

重要性采样方法：每一步给后续的修正乘上比值 ρ_t = π(a_t|s_t) / b(a_t|s_t)。它是无偏的，但多步连乘后方差可能极大。论文讨论了按每次决策加权的几种资格迹版本，并证明了它们在表格情形下的收敛性。

树备份：在状态s_{t+1}，把目标写成「对没走的动作直接用当前估值按π的概率加权，只对实际走的a_{t+1}继续向后展开」： G_t = r_{t+1} + γ Σ_{a ≠ a_{t+1}} π(a|s_{t+1}) Q(s_{t+1},a) + γ π(a_{t+1}|s_{t+1}) G_{t+1}。 展开后，第k步之后的部分被乘上 Π π(a_i|s_i)——也就是目标策略的概率，而不是π/b的比值。因为这些概率都不超过1，方差始终有界，也完全不需要知道行为策略b。代价是：当π对实际动作给的概率很小时，迹衰减得很快，多步回报的好处就用不上了（π是贪心策略时它退化成类似Watkins Q(λ)的行为）。

作者在小型马尔可夫链上的实验比较了这些算法的偏差与方差特性。

局限与后续

  • 当目标策略与行为策略差别大时，树备份的迹衰减很快，几乎退化为一步更新，无法利用长回报。

  • 收敛性分析限于表格情形，与线性或非线性函数近似结合时可能发散。
    后来针对它的工作　梯度TD（GTD/TDC） 强调TD（Emphatic TD）

读懂它需要的概念

时序差分与自举 on-policy与off-policy 重要性采样 Bellman方程

本篇术语

  • 离策略评估　用一个策略收集的数据，估计另一个策略的价值。
  • 资格迹　对过去访问过的状态-动作按时间衰减地记账，使当前的TD误差也能更新更早的估值。
  • 重要性采样比　目标策略与行为策略选同一动作的概率之比，用来把行为策略下的回报改写成目标策略下的期望。

怎么学

先学时序差分学习的资格迹和重要性采样；读Sutton与Barto第二版第7.5节树备份；在一个小随机游走上分别用重要性采样和树备份做离策略评估，比较方差。
