ALFWorld文字家务环境

ALFWorld: Aligning Text and Embodied Environments for Interactive Learning
2020.10数据集延伸ICLR 2021Mohit Shridhar, Xingdi Yuan, Marc-Alexandre Côté, Yonatan Bisk, Adam Trischler, Matthew Hausknecht · 华盛顿大学 / 微软研究院 / 卡内基梅隆大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

具身智能体既要能抽象地规划（“先洗苹果再放进冰箱”），又要在具体的视觉场景里执行；已有工作没有一套基础设施能让智能体先在文字世界里学抽象策略，再迁移到视觉环境中执行。

方法

把ALFRED的家务任务一一对应到TextWorld文字游戏里，智能体在纯文字环境中学高层策略，再把同样的目标放到ALFRED的三维视觉环境中执行；并给出模块化智能体BUTLER。

影响

它的文字版家务任务后来成为大模型智能体最常用的测试环境之一，ReAct、Reflexion等工作都在ALFWorld上报告成功率。

方法

问题。人接到“把洗过的苹果放进厨房冰箱”这样的请求时，不用动手就能在脑子里排出动作序列，看到具体厨房后再调整。ALFRED具身指令基准提供了带三维视觉的家务指令任务，但直接在视觉环境里从零学习，智能体既要理解语言又要学规划和导航，样本效率很低。

ALFWorld怎么做。作者为ALFRED中的每个场景生成对应的文字游戏：环境用文字描述房间和物体（“你在厨房，看到一个台面1、一个冰箱1……”），智能体输入“去台面1”“拿起苹果1”“用水槽清洗苹果1”之类的文字命令，任务包括拾取放置、清洗、加热、冷却、检查物体等六类。智能体先在这个TextWorld式文字环境里学抽象策略，再在视觉环境中执行同一目标。

BUTLER。作者提出模块化智能体BUTLER：文字策略用模仿学习（DAgger式）训练，再接一个把高层文字命令落到视觉动作的执行器。实验显示，先在文字世界学抽象知识，比只在视觉环境里训练泛化更好。

局限与后续

  • 文字版环境的命令空间固定、反馈简单，后来的大模型很容易在其上取得高成功率，区分度下降；文字到视觉的执行仍依赖专门的检测与导航模块。

读懂它需要的概念

状态、观测与动作 模仿学习与行为克隆 智能体循环

本篇术语

  • 文字游戏环境　用文字描述场景、用文字命令行动的交互环境，像早期的文字冒险游戏。

怎么学

先读ALFRED具身指令基准了解原始任务。读ALFWorld原文第3节的环境设计；动手装好ALFWorld文字环境，用一个大模型按ReAct格式完成两三个家务任务。
