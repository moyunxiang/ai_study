ALVINN端到端驾驶

ALVINN: An Autonomous Land Vehicle in a Neural Network
1989论文延伸Dean Pomerleau · 卡内基梅隆大学待核对
NavLab维基（含ALVINN） ↗在交互版中打开（演化树、学习进度）

问题

自动驾驶系统靠人手写规则去识别道路，换一种路面就失效。

方法

训练一个小型三层神经网络，输入摄像头图像，直接输出方向盘转角，训练数据来自人类驾驶。

影响

第一个用神经网络直接从图像输出驾驶控制的系统，是端到端驾驶的鼻祖。

方法

据维基百科，ALVINN开发于1988年，1989年2月训练出第一个版本，是一个由反向传播（反向传播）训练的三层前馈网络，结构为1217-29-46个神经元，共36627个权重。输入来自摄像头和激光测距仪，输出是45个转向角单元加一个反馈单元。

训练方式是看人开：在约1200张模拟道路图像上训练40轮，对没见过的模拟图像，转角误差在两个单位之内的准确率达90%。上路后，在Navlab 1上以0.5米每秒沿400米的林间小路行驶，天气不同也可以。为了让网络见过偏离路中央的情形，把真实图像左右平移五档，一个样本扩成11个。1989年6月，团队发现可以边开边在线训练。

后来的发展

DAgger正是针对它的误差累积问题提出的；2016年端到端自动驾驶用卷积网络重新实现，条件模仿学习驾驶再加上导航指令。

局限与后续

  • 网络很小，只会沿一种路面行驶，不能处理路口和复杂交通。

  • 使用

  • 使用
    CMU NavLab1986 · 具身·世界模型
    在Navlab 1上训练和测试。
  • 改进
    Dickmanns视觉高速驾驶1987 · 具身·世界模型
    依赖手工设计的道路模型和特征提取，换到没有清晰车道线的路面就不灵。

后来的相关工作

  • 延续
    Tesla FSD v12端到端2024.03 · 具身·世界模型 待核对
    35年前ALVINN已用神经网络从图像直接输出方向盘角度；v12是同一思路在数据和算力上的放大。
  • 竞争
    逆强化学习IRL2000 · RL
    ALVINN式模仿学习直接拟合状态到动作的映射；IRL主张先恢复奖励，认为它比策略更简洁、更能迁移到新环境。
  • 延续
    DARPA无人车挑战赛2005.10 · 具身·世界模型
    Stanley的视觉模块明确建立在Pomerleau以来的道路识别研究上，但不再离线训练，而是用激光自动标注、在线适应当前路面。
  • 改进
    DAgger2010.11 · RL
    ALVINN式行为克隆只学专家状态，偏离后不会纠正；DAgger让专家在学生实际到达的状态上补标，误差从随T²增长降到随T增长。
  • 延续
    机器人示教学习1997 · 具身·世界模型
    沿着“从人类演示学控制”的思路，从驾驶推广到机械臂操作。
  • 延续
    端到端自动驾驶2016.04 · 具身·世界模型
    同样是摄像头图像到方向盘转角的端到端模仿，ALVINN用小型全连接网络，这里换成深度卷积网络并在真实道路上验证。
  • 改进
    条件模仿学习驾驶2017.10 · 具身·世界模型
    网络很小，只会沿一种路面行驶，不能处理路口和复杂交通。
