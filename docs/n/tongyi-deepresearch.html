Tongyi DeepResearch Technical Report

arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度研究智能体多是闭源产品，开源方案靠拼接流程或昂贵的人工标注，长程信息检索的训练方法不透明。

方法

专为长程信息检索设计，用端到端训练（智能体式中期训练加智能体式后训练）和全自动的数据合成管线，不依赖人工标注。

影响

开源了模型、框架和完整方案，用305亿参数、每token只激活33亿的MoE模型在多个深度研究基准上取得最好成绩。

方法

Tongyi DeepResearch是一个面向长时程信息检索任务的智能体模型。它的训练分两段：智能体式中期训练，让模型在预训练之后先适应智能体的行为模式；智能体式后训练，则通过强化学习提升。支撑这两段的是一条全自动、可扩展的数据合成管线，不需要昂贵的人工标注；并为每个阶段定制了环境，使交互稳定一致。

模型总参数305亿，每个token只激活33亿。技术报告称它在Humanity's Last Exam、BrowseComp、BrowseComp-ZH、WebWalkerQA、xbench-DeepSearch、FRAMES等基准上达到当前最优（官方自述）。它延续了Search-R1用强化学习训练搜索行为的思路，并补上了合成数据与中期训练这一环。
