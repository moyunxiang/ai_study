RLOO回归REINFORCE

Back to Basics: Revisiting REINFORCE Style Optimization for Learning from Human Feedback in LLMs
2024.02论文延伸ACL 2024Arash Ahmadian, Chris Cremer, Matthias Gallé, Marzieh Fadaee, Julia Kreutzer, Olivier Pietquin, Ahmet Üstün, Sara Hooker · Cohere For AI、Cohere待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

PPO被当作RLHF中强化学习部分的标准方法，但它要额外训练价值网络、调很多超参数，计算贵且不稳定；DPO等“免RL”方法又放弃了在线采样的好处。

方法

回到更简单的REINFORCE：把整段回答当作一个动作，不要价值网络和裁剪；对每个提示采样k个回答，用其余k−1个回答的平均奖励作为基线来降低方差（RLOO）。

影响

论证了PPO的许多组件在RLHF里并不必要，RLOO进入TRL等常用库，和同月提出的GRPO一样用“同一提示多次采样互为基线”的办法替代价值网络。

方法

背景：InstructGPT与RLHF用PPO做RLHF。PPO是为游戏、机器人等长序列、高方差的深度强化学习设计的，需要价值网络估计每一步的优势，并用裁剪限制更新幅度。作者认为语言模型的情形不同：从一个已经很好的预训练加SFT模型出发，策略本身方差不大，奖励只在整段回答结束时给出一次。

他们因此回到REINFORCE策略梯度式的策略梯度：把生成整段回答看成一个动作，梯度为 (R(y) − b) · ∇ log π(y|x)，b是降低方差的基线。RLOO的做法是对每个提示采样k个回答y₁…y_k，第i个回答的基线取其余k−1个回答的平均奖励 b_i = (1/(k−1)) Σ_{j≠i} R(y_j)，不需要任何学出来的价值函数。作者还系统检查了PPO各组件的作用，例如把每个token当动作、用价值网络估计优势、裁剪比率等，发现它们在RLHF设定下多半可以去掉。

摘要报告：去掉PPO中不必要的部分后，更简单的REINFORCE式变体效果超过PPO，也超过DPO、RAFT等新近提出的“免RL”方法，以较低成本保留了在线RL的好处。

局限与后续

  • 每个提示要采样k个回答才能构造基线，生成开销随k线性增长；实验以单轮对话和摘要类偏好任务为主，对长链推理、多轮交互等奖励更稀疏的任务是否同样不需要价值网络没有验证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 改进
    PPO2017.07 · RL
    PPO需要价值网络和大量超参数，作者论证这些组件在RLHF中多半不必要，RLOO更省且效果更好。
  • 改进
    InstructGPT与RLHF2022.03 · LLM
    InstructGPT确立的PPO-RLHF流程计算昂贵，本文给出更简单的在线RL替代。
  • 竞争
    DPO直接偏好优化2023.05 · LLM
    DPO放弃在线RL，RLOO坚持在线采样，摘要称效果超过DPO。
  • 延续
    REINFORCE策略梯度1992 · RL
    直接使用REINFORCE策略梯度，用留一法多样本基线降低方差。
  • 改进
    RRHF排序对齐2023.04 · LLM
    效果受限于候选回答的质量：如果k个回答都不好，排序损失只能在差的里面挑相对好的，摘要明确指出性能与采样质量高度相关；离线排序也没有在线采样那样持续探索新回答。
  • 改进
    RLHF的秘密与PPO-max2023.07 · LLM
    仍保留PPO的价值网络与复杂流程，显存和实现负担没有减少。
  • 竞争
    GRPO2024.02 · 推理·智能体
    同月提出的GRPO也用同一提示的多个采样做基线、去掉价值网络，但用组内标准化和PPO式裁剪。

读懂它需要的概念

人类反馈强化学习 策略梯度 期望与方差 Actor-Critic与优势函数 蒙特卡洛采样

本篇术语

  • 基线（baseline）　策略梯度中从奖励里减去的一个参考值，不改变梯度的期望，但能大幅降低方差。
  • 留一法基线　同一提示采样k个回答时，给每个回答用另外k−1个回答的平均奖励作基线。

怎么学

先补REINFORCE策略梯度的策略梯度推导和基线的作用；读本文第3节逐项检查PPO组件的实验和RLOO的定义；动手：用TRL的RLOOTrainer和PPOTrainer在同一奖励模型上训练小模型，比较奖励曲线和显存占用。
