图核网络

Neural Operator: Graph Kernel Network for Partial Differential Equations
2020.03论文延伸ICLR 2020 Workshop on Integration of Deep Neural Models and Differential EquationsZongyi Li, Nikola Kovachki, Kamyar Azizzadenesheli, Burigede Liu, Kaushik Bhattacharya, Andrew Stuart, Anima Anandkumar · Caltech待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经网络通常学习有限维向量之间的映射；PDE的输入输出是函数（无穷维），网络换一种网格分辨率就要重训。

方法

把神经网络推广为学习无穷维函数空间之间的算子：用一个核积分算子加非线性层叠起来，核积分用图网络的消息传递计算，使同一组参数能跨不同离散化使用。

影响

提出了神经算子（Neural Operator）的框架，是傅里叶神经算子FNO以及此后一系列算子学习方法的前身。

方法

层的形式是：新函数在每个点的取值，由旧函数的线性变换加上对邻域内旧函数值按可学习的核做积分得到，再过一个非线性激活。这个核积分在离散网格上用图网络的消息传递近似计算，核本身是由网络参数化的函数，输入是两点的位置和函数值。因为参数描述的是函数空间之间的映射，而不是某个固定网格上的向量，所以同一组参数可以用于不同分辨率和不同离散方式（如有限差分或有限元）。

摘要称实验证实该方法具有这些性质，并与当时最先进的求解器相比有竞争力。

后来的发展

随后作者把核积分换成傅里叶空间里的乘法，得到更快的傅里叶神经算子FNO；图核路线本身则演化出处理不规则几何的Geo-FNO不规则几何、GNOT算子Transformer等工作。

局限与后续

  • 图上的核积分需要对所有邻居求和，计算和显存代价高，难以扩展到大规模网格。
