数据受限的规模定律

Scaling Data-Constrained Language Models
2023.05论文延伸NeurIPS 2023Muennighoff, Rush, Barak, Le Scao, Piktus, Tazi, Pyysalo, Wolf, Raffel · Hugging Face / Harvard 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

规模定律假设数据取之不尽，但互联网上的高质量文本有限；数据不够时，反复训练同一批数据（多个epoch）到底有多大价值？

方法

在数据受限条件下做大量实验，改变数据重复次数和算力预算，并提出一个把重复数据价值递减考虑进去的计算最优规模定律。

影响

定量回答了「重复数据还有没有用」：约4个epoch几乎等价于新数据，之后收益迅速衰减。

方法

实验规模最高到900B训练token、90亿参数。固定算力预算，对比在唯一数据与重复数据上训练的效果。核心发现是：重复使用数据最多约4个epoch时，损失与使用全新数据相比变化可以忽略；但重复更多后，增加算力的价值最终衰减到零。

基于此作者修改Chinchilla的规模定律：不是简单地把重复数据当新数据，而是给重复出现的token和多余的参数引入「衰减的有效价值」，据此给出数据受限时参数与数据的最优分配，并经实验验证。此外还尝试了其他补救办法，例如用代码数据补足、放宽数据过滤。

对读者来说，结论是：当高质量文本用完时，不要盲目增大模型，也不要无限重复数据。

结果

摘要：最高900B训练token、9B参数模型的大量实验；最多4个epoch的重复与新数据损失几乎无差别，更多重复后算力价值衰减至零。

后来的发展

此后「数据墙」成为大模型讨论的焦点，催生了合成数据、更大规模的网页过滤数据集（见FineWeb / FineWeb-Edu、DCLM）以及对模型坍缩风险的研究（见模型坍缩）。
