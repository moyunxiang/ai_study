Weyn数据驱动天气预报

Can Machines Learn to Predict Weather? Using Deep Learning to Predict Gridded 500-hPa Geopotential Height From Historical Weather Data
2019.08论文延伸JAMES 2019Jonathan Weyn, Dale Durran, Rich Caruana · 华盛顿大学、微软待核对
JAMES ↗在交互版中打开（演化树、学习进度）

问题

数值天气预报靠物理方程，没有人确认过纯数据驱动的神经网络能否做全球预报。

方法

训练卷积神经网络，只用历史天气数据预报北半球网格上的500 hPa位势高度，不显式使用物理过程。

影响

早期的数据驱动全球预报尝试，之后发展为FourCastNet、GraphCast与AI天气预报等模型。

方法

做法：用深度卷积网络在北半球网格上预测一到两个基本气象场。摘要称，预报时效到三天时仅预测500 hPa位势高度的CNN就明显优于持续性、气候态和基于动力学的正压涡度模型，但打不过业务化的全物理模型；加入700到300 hPa厚度可略有改进；最好的模型能生成14天时效的逼真大气状态。

后来的发展

立方球面CNN天气预报在其基础上改进，WeatherBench等给出统一评测。

局限与后续

  • 摘要明确说简单模型不如业务化全物理预报。
