RAP推理即规划

Reasoning with Language Model is Planning with World Model
2023.05论文延伸EMNLP 2023Shibo Hao, Yi Gu, Haodi Ma, Joshua Jiahua Hong, Zhen Wang, Daisy Zhe Wang, Zhiting Hu · UCSD / Florida待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

思维链是顺着一条路径一直写下去，模型没有对世界状态的内部模型，不能预判后果、回头尝试别的路。

方法

让同一个语言模型既当「世界模型」预测状态，又当「推理者」选动作，并用蒙特卡洛树搜索探索。

影响

把推理明确表述为规划问题，将树搜索引入语言模型推理。

方法

RAP全称Reasoning via Planning。设定上，状态是当前已知的世界信息（如积木块的位置、已求出的中间量），动作是下一步要做的事。同一个模型被提示用于两个角色：给定状态和动作，预测下一个状态（世界模型）；给定状态，提出可能的动作并给出奖励估计（推理者）。再用蒙特卡洛树搜索UCT在这个由模型想象出的搜索树上平衡探索与利用，选出收益最高的推理路径。

摘要称在计划生成、数学推理和逻辑推理任务上，RAP优于多种思维链基线。

后来的发展

与思维树并列成为早期的搜索式推理；LATS智能体树搜索进一步结合环境反馈；2024年起的推理模型则把搜索训练进模型本身（如OpenAI o1推理模型）。

局限与后续

  • 每一步都要多次调用模型来模拟和评估，推理成本高出思维链几个数量级。

    后来针对它的工作　LATS智能体树搜索
