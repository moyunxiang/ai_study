张正友标定法

A Flexible New Technique for Camera Calibration
2000论文延伸IEEE TPAMI 2000Zhengyou Zhang（张正友） · 微软研究院待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

要从图像做测量或三维重建，必须先知道相机内参（焦距、主点、畸变）；传统标定需要精密加工的三维标定物，而自标定方法又不够稳定可靠。

方法

只用一块打印出来的平面棋盘格，从几个不同角度各拍一张：每张图给出平面到图像的单应矩阵，每个单应矩阵对内参提供两个约束，三张以上就能线性解出内参，再用最大似然非线性优化统一精化（含镜头畸变）。

影响

让相机标定变成人人能做的事，成为事实上的标准方法：OpenCV的calibrateCamera和MATLAB标定工具箱都基于它，几乎所有视觉、机器人、AR系统的标定流程都从拍棋盘格开始。

方法

把棋盘格所在平面设为世界坐标的 Z=0 平面，平面上的点 (X, Y) 与图像点之间就是一个3×3的单应矩阵H：s·[u, v, 1]ᵀ = K·[r₁ r₂ t]·[X, Y, 1]ᵀ，其中K是内参矩阵，r₁、r₂是旋转矩阵的前两列，t是平移。

  • 估计单应：每张图里检测到的角点与已知的棋盘坐标对应，用线性方法（加非线性精化）求出H。
  • 线性求内参：记 H = [h₁ h₂ h₃] = λK[r₁ r₂ t]。因为r₁、r₂是正交的单位向量，得到两个约束：h₁ᵀ K⁻ᵀK⁻¹ h₂ = 0 和 h₁ᵀ K⁻ᵀK⁻¹ h₁ = h₂ᵀ K⁻ᵀK⁻¹ h₂。令 B = K⁻ᵀK⁻¹（对称，6个未知数），每张图给2个线性方程，3张以上就能用SVD解出B，再分解出K；随后每张图的外参（R、t）也能直接算出。
  • 最大似然精化：以线性解为初值，对所有图像的所有角点最小化重投影误差，同时估计径向畸变系数，用Levenberg–Marquardt求解——这一步与光束平差综述的思想相同。

这种方法介于需要三维标定物的摄影测量标定和完全不用标定物的自标定之间，只需要平面图案，可以手持相机或移动平面拍摄，无需知道运动。

局限与后续

  • 依赖角点检测的精度和足够多不同姿态的图像，标定板几乎平行于成像面时约束退化。

读懂它需要的概念

相机模型与多视图几何 特征分解与奇异值分解 向量、矩阵与张量 最大似然估计

本篇术语

  • 单应矩阵　描述一个平面在两张图（或平面与图像）之间如何对应的3×3矩阵，平面上的点经它变换得到图像上的点。
  • 径向畸变　镜头使离画面中心越远的直线越弯（桶形或枕形），需要用几个系数建模并校正。

怎么学

先复习针孔相机模型和齐次坐标，再读论文第2、3节约束推导；打印一张棋盘格，用手机从十几个角度拍照，用OpenCV的findChessboardCorners和calibrateCamera标定，查看重投影误差和去畸变效果。
