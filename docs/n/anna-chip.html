贝尔实验室ANNA芯片

Application of the ANNA Neural Network Chip to High-Speed Character Recognition
1992论文延伸IEEE Transactions on Neural Networks，1992年5月Eduard Säckinger, Bernhard Boser, Jane Bromley, Yann LeCun, Lawrence Jackel · AT&T Bell Labs待核对
来源 ↗在交互版中打开（演化树、学习进度）

问题

卷积网络识别手写字符效果很好，但在通用处理器上太慢，达不到邮件分拣、支票识别所需的实时速度。

方法

贝尔实验室做了一块专为神经网络设计的ANNA芯片（模拟与数字混合），用它高速运行手写字符识别的卷积网络。

影响

它是最早把卷积网络放在专用芯片上实际识别字符的工作之一，说明神经网络加速器可以面向真实应用。

方法

论文《Application of the ANNA Neural Network Chip to High-Speed Character Recognition》发表在1992年5月的IEEE Transactions on Neural Networks，作者有Säckinger、Boser、Bromley、LeCun、Jackel。同一组人1991年在IJCNN上先发过《An analog neural network processor and its application to high-speed character recognition》。

ANNA是一块神经网络专用芯片，目标是高速字符识别，应用于LeCun等人的卷积网络（见LeNet与卷积网络）。它把神经网络里最耗时的乘加运算交给芯片完成，主机只负责数据搬运和结果处理，从而达到通用处理器达不到的速度。具体的芯片规格、速度数字本页未核对，不写具体数字。

这类工作是此后专用神经网络加速器路线的早期例子，与Intel ETANN模拟神经芯片同属一代模拟或混合信号神经网络芯片，但最终主流深度学习走向GPU而不是定制模拟芯片。

局限与后续

  • 模拟或混合信号电路难以随网络结构变化灵活编程，一块芯片只适合一种网络。
    后来针对它的工作　GPU上的卷积网络 Google TPU
  • 精度和规模有限，无法承担后来数百万参数的深度卷积网络。
    后来针对它的工作　AlexNet
