Helmholtz机与wake-sleep

The Helmholtz Machine
1995论文延伸Neural Computation 1995Dayan, Hinton, Neal, Zemel · Toronto / Gatsby / MIT待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

想让网络学会一个生成数据的隐变量模型，但给定一张图后推断它的隐变量要对指数多种组合求和，无法精确计算。

方法

同时训练两个网络：自上而下的生成网络产生数据，自下而上的识别网络近似推断隐变量，两者用wake-sleep算法互相教对方。

影响

首次把「生成网络加近似推断网络」这套结构定型，是后来变分自编码器VAE中编码器与解码器的直接前身。

方法

Helmholtz机有两套权重。识别网络把输入（比如一张二值图）一层层向上映射成隐变量的取值分布，生成网络则从最高层隐变量出发向下逐层采样出数据。两者都是随机二值单元的网络。

wake-sleep算法分两个阶段。清醒（wake）阶段：用识别网络对真实数据推断出一组隐变量，再调整生成网络的权重，使它更可能生成这份数据。睡眠（sleep）阶段：让生成网络自己「做梦」，采样出隐变量和对应的假数据，再调整识别网络，使它能从假数据里还原出当初的隐变量。两个阶段都只需要局部的、类似反向传播之前的简单更新规则，不必穿过随机采样求梯度。

它背后的目标是最小化一个自由能（变分下界，见变分推断与ELBO），但睡眠阶段实际优化的是反向的KL，所以并不严格最大化下界，这也是它的主要缺陷。

局限与后续

  • 睡眠阶段优化的不是真正的变分下界，识别网络的目标与生成网络的目标不一致，训练不保证收敛到好的模型。
    后来针对它的工作　随机反向传播DLGM 变分自编码器VAE
  • 随机二值单元无法直接用反向传播，只能靠粗糙的局部规则，难以扩展到大模型和连续数据。
    后来针对它的工作　变分自编码器VAE 随机反向传播DLGM

它建立在什么之上

  • 竞争
    反向传播1986 · 基础
    用局部的wake/sleep规则代替端到端反向传播，因为随机单元当时无法求导。
  • 竞争
    玻尔兹曼机1985 · 基础
    同样是带隐变量的概率网络，但玻尔兹曼机靠耗时的采样学习，Helmholtz机用识别网络一次前向给出近似后验。

后来的相关工作

  • 改进
    变分自编码器VAE2013.12 · 生成 已核对
    同样用识别网络近似后验。论文指出wake-sleep需要同时优化两个目标函数；AEVB让两个网络联合优化同一个下界，在MNIST和Frey Face实验中下界收敛更快、最终更高。
  • 改进
    随机反向传播DLGM2014.01 · 生成
    Helmholtz机的wake-sleep没有统一目标，这里用变分下界加随机反向传播统一训练识别和生成网络。
