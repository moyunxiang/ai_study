TextCNN句子分类

Convolutional Neural Networks for Sentence Classification
2014.08论文重要EMNLP 2014Yoon Kim · 纽约大学待核对
arXiv ↗ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

句子分类当时有两类方法：词袋加朴素贝叶斯/SVM不看词序；递归张量网络等结构化模型要先做句法分析、实现复杂、训练慢。人们不清楚一个简单的神经网络加上预训练词向量能做到多好。

方法

把句子的word2vec词向量排成一个矩阵，用宽度为3、4、5个词的卷积核各100个在上面滑动，每个卷积核对整句取最大值，拼起来后加dropout接softmax分类。词向量可以固定，也可以随任务微调。

影响

一个几乎不调参的单层卷积网络在7个基准中的4个上刷新最好成绩，证明预训练词向量是通用的特征提取器、微调还能再提高。TextCNN由此成为文本分类的标准基线，“用预训练向量初始化再微调”的做法也被普遍采用。

背景

2014年的句子分类（影评情感、主观性、问题类型等）有两条路。一条是机器学习情感分类以来的词袋特征加朴素贝叶斯或SVM，Wang和Manning的NBSVM已经调得很强，但看不到词序和否定。另一条是结构化神经网络，如递归张量网络与情感树库沿句法树递归组合，需要外部句法分析器、实现复杂。

从零开始的神经NLP早已证明“词向量+卷积+对整句取最大值”能做序列标注，word2vec又在1000亿词的Google新闻上发布了300维预训练向量。那么，把现成的词向量接一个最简单的卷积网络，用在句子分类上会怎样？

方法

输入。长度为n的句子表示为n个300维word2vec向量依次排成的矩阵，不足的句子补零。

卷积。一个卷积核w ∈ R^{h×k}覆盖h个相邻词，在每个窗口上算一个特征c_i = f(w · x_{i:i+h−1} + b)，f是ReLU；沿句子滑动得到一条特征图c = [c_1, …, c_{n−h+1}]（见卷积层、池化与感受野）。宽度h取3、4、5，每种100个卷积核，相当于学习300个“3到5个词的短语探测器”。

最大池化。每条特征图只取最大值ĉ = max(c)，表示“这个短语模式在句中任意位置出现的最强程度”。这样不论句子多长，都得到一个300维的定长向量，也自然地处理了变长输入。

分类与正则化。300维向量经dropout（丢弃率0.5，见Dropout）后接全连接softmax层；另外把每个权重向量的L2范数限制在3以内。小批量50，所有超参数只在SST-2验证集上做过一次网格搜索，然后用于全部数据集。

四个变体：词向量随机初始化（rand）、用word2vec初始化且固定（static）、初始化后随任务微调（non-static）、以及同时保留固定和可微调两份向量作为两个“通道”（multichannel）。

结果

7个数据集上（准确率，%）：

  • 影评MR：随机初始化76.1，固定向量81.0，微调81.5；此前最强的NBSVM为79.4。
  • 情感树库五分类SST-1：微调版48.0，RNTN为45.7；二分类SST-2：双通道88.1，RNTN为85.4。
  • 主观性Subj 93.4、问题分类TREC 93.6、商品评论CR 85.0、观点极性MPQA 89.6。

共在4个任务上超过此前最好结果。仅换用预训练词向量就带来大幅提升，例如MR上从76.1到81.0。微调后的向量更贴近任务：在word2vec中与bad最相似的是good（两者句法上几乎等价），在SST-2上微调后变成terrible、horrible。dropout稳定带来2%到4%的相对提升；换用Collobert等人的词向量效果明显差于word2vec。

后来的发展

TextCNN成为文本分类的默认基线之一，被大量工业系统采用。随后字符级CNN文本分类把输入从词换成字符，字符感知语言模型把字符卷积用于语言模型，fastText证明更简单的词袋平均加子词在许多分类任务上也能接近它。

“预训练词向量当通用特征、再针对任务微调”这一发现，是从词向量迁移走向整个网络迁移的中间一步：ULMFiT、ELMo、GPT-1和BERT把预训练从输入层扩展到整个模型，在同样的SST等基准上又把成绩提高了一大截。

它建立在什么之上

  • 使用
    LeNet与卷积网络1998 · 视觉
    卷积核共享权重、在输入上滑动提取局部特征的思想来自图像卷积网络，这里把一维卷积用在词序列上。
  • 使用
    word2vec2013.01 · NLP
    输入层直接使用在1000亿词Google新闻上训练的300维word2vec公开向量，实验表明这是性能提升的主要来源。
  • 改进
    机器学习情感分类2002.07 · NLP
    词袋加朴素贝叶斯/SVM路线的最强变体NBSVM在影评MR上为79.4%，TextCNN达到81.5%。
  • 延续
    从零开始的神经NLP2011 · NLP
    沿用“词向量查表+卷积+对整句取最大值”的结构，从序列标注搬到句子分类，并加入多种窗口宽度和dropout。
  • 使用
    Dropout2012.07 · 基础
    在倒数第二层用丢弃率0.5的dropout，作者称这稳定带来2%到4%的相对提升。
  • 改进
    递归张量网络与情感树库2013.10 · NLP
    RNTN需要句法分析树和复杂的张量组合；单层卷积网络不用任何句法信息，在SST-1和SST-2上都超过了它。
  • 改进
    SVM文本分类1998 · NLP
    线性SVM只看词的出现，不理解词序和语义，对同义表达和长距离依赖无能为力。
  • 改进
    NBSVM强基线2012.07 · NLP
    仍是词袋加二元组，无法表示长距离的否定、转折和组合语义。
  • 改进
    DCNN动态卷积句子模型2014.04 · NLP
    结构比单层卷积复杂得多，超参数和实现细节多，而同年更简单的单层CNN配预训练词向量效果相当，实践中后者更常用。

读懂它需要的概念

嵌入向量 卷积层、池化与感受野 Dropout Softmax与logits 预训练与微调 准确率、精确率、召回率与F1

本篇术语

  • 最大池化（max-over-time）　对一条特征图在整个句子长度上取最大值，只保留最强的响应，从而把变长句子变成定长向量。
  • 通道　借用图像RGB通道的说法：同一句子准备两套词向量（一套固定、一套可微调），卷积核同时作用在两套上再相加。
  • 微调词向量　用预训练向量初始化嵌入层，再在具体任务上随其他参数一起更新，使向量更适合该任务。

怎么学

先补卷积层、池化与感受野、嵌入向量和Dropout，读过word2vec。原文只有6页，读第2节（模型）、第3节（数据与超参数）和表2、表3。动手：在SST-2上用PyTorch实现TextCNN，分别跑rand、static、non-static三种设置，复现“预训练词向量带来大幅提升”，并查看微调前后good、bad的最近邻。
