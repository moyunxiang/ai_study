测试集污染检测

Proving Test Set Contamination in Black Box Language Models
2023.10论文重要Yonatan Oren, Nicole Meister, Niladri Chatterji, Faisal Ladhak, Tatsunori B. Hashimoto · 斯坦福大学 / 哥伦比亚大学待核对
arXiv ↗代码（GitHub） ↗在交互版中打开（演化树、学习进度）

问题

大模型的预训练语料不公开，外人无法查它是否见过某个基准的测试题；以往的污染检查要么需要训练数据，要么只是启发式猜测，给不出可信的证据。

方法

利用“数据集中样本的顺序本来无关紧要”这一点：没见过测试集的模型对原始顺序和打乱顺序应给出相近的概率；若原始顺序的概率显著更高，就说明模型背过这份文件。

影响

第一次给出只需查询对数概率、带有严格假阳性率保证的污染检测方法，把“测试集泄漏”从怀疑变成可以统计检验的问题。

背景

大模型在越来越多基准上得高分，同时有人怀疑这些基准早已混进了从网上爬来的训练语料（见数据泄漏与基准污染）。GPT-3论文曾在自己的训练数据里搜索与测试题的13-gram重叠来估计污染，网络语料文档化：C4审计也在C4语料里找到了其他基准的样本。但这些方法都要求能访问训练语料，The Pile与开放预训练语料这类公开语料可以查，闭源模型的语料却完全看不到。

另一类做法是看模型能否补全测试题、或者看它在测试题上的损失是否异常低，但这些都没有统计保证，很难区分“背过”和“题目本身简单”。

方法

可交换性。很多基准的样本是独立收集、顺序随意的，任意打乱都同样合理，统计上叫可交换。如果模型从没见过这份测试文件，它对“原始顺序拼起来的整份文件”和“打乱后的文件”给出的概率在分布上应该一样。但语言模型会记住训练时看到的顺序，所以若测试集文件被原样放进过训练数据，原始顺序的对数概率会明显高于大多数打乱版本。

置换检验。把测试集按原始顺序拼接，计算对数概率log p(X_原序)；再随机打乱很多次，算出log p(X_打乱)的分布。原序的值在这个分布里排得越靠前，p值越小。由于打乱顺序在“没见过”的假设下概率相同，这个检验的假阳性率有严格保证。

分片检验。整份文件太长、打乱次数有限时检验力不足，作者把数据集切成多个小片，在每片内各做一次比较，再把各片的结果合并成一个统计量。这样能并行计算，在p值很小时检验力也大幅提高。整个过程只需要模型对文本的对数概率，不需要权重或训练数据。

结果

作者训练了一个14亿参数的模型，训练语料是维基百科加上一批已知的测试集（重复1到100次插入，总共202亿token）作为阳性对照。只有1000个样本的测试集，即使在语料中只出现两次，有时也能被检测出来；出现10次以上时p值小到接近浮点精度极限。

审计公开模型：在LLaMA2-7B、Mistral-7B、Pythia-1.4B、GPT-2 XL、BioMedLM上测试了8个基准，除Mistral在ARC-Easy上p=0.001外，没有发现原样污染的证据；MMLU汇总后LLaMA2与Mistral的p值较小，与Meta自报的轻度MMLU污染一致。在7B模型上，用50个分片、每片250次打乱检验65个文件不到24小时。

后来的发展

这种基于排列的检测思路为“没有训练数据也能审计模型”提供了范例，但它只能抓住按原顺序原样出现的污染。对于改写、翻译或打乱后混入训练数据的题目，后来的做法是重新出一份同分布的新题来对比：GSM1k污染复查照GSM8K的风格重写了1000道题，发现部分模型在新题上明显掉分；LiveBench和MathArena竞赛数学则持续用模型发布后才出现的新题，让污染无从发生。

容易误解的地方

  • 检验没有发现污染，不代表模型没见过这些题：如果训练数据里的题目被打乱、改写或只出现一次，检验可能无力察觉。
  • 若基准文件本身不可交换（例如按编号或难度排序、含重复样本），会产生假阳性，作者在审计前做了启发式过滤。

局限与后续

  • 只能检测测试集按原始顺序原样出现在训练数据中的情况，对改写、打乱或零散混入的污染不敏感。

读懂它需要的概念

数据泄漏与基准污染 语言模型 方差、种子与统计显著性 随机变量与概率分布 困惑度

本篇术语

  • 可交换　一组数据的任意重新排列在统计上与原排列同样可能出现。独立收集、顺序随意的测试样本通常满足这一点。
  • 置换检验　在“顺序无关”的假设下，把数据打乱很多次构造统计量的分布，看原始数据的统计量落在分布的哪里，从而得到p值。

怎么学

先懂数据泄漏与基准污染和方差、种子与统计显著性。读原文第3节（置换检验与分片检验）和第4节的表1。动手：用GPT-2对一份小测试集算原序与100次打乱的总对数概率，再把这份测试集重复10次微调GPT-2，重新检验，观察p值的变化。
