Set Transformer

Set Transformer: A Framework for Attention-based Permutation-Invariant Neural Networks
2018.10论文延伸ICML 2019Juho Lee, Yoonho Lee, Jungtaek Kim, Adam R. Kosiorek, Seungjin Choi, Yee Whye Teh · 牛津大学 / 浦项工科大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Deep Sets对集合里的每个元素独立编码再求和，满足置换不变，却建模不了元素之间的相互作用；直接用自注意力又是元素数的平方开销。

方法

用注意力搭建集合的编码器和解码器：编码器用自注意力建模元素间的交互；再借稀疏高斯过程的“诱导点”思想，引入少量可学习的诱导向量，把复杂度从平方降到线性。

影响

成为处理集合、点集和多实例输入的标准注意力架构之一，诱导点式的“用少量潜变量做交叉注意力”也是后来Perceiver等架构的同类做法。

方法

集合输入的要求是：打乱元素顺序，输出不变（置换不变），或输出跟着同样地打乱（置换等变）。不带位置编码的自注意力天然是置换等变的，所以作者用Transformer的多头注意力搭了几个模块：MAB是普通的注意力块；SAB对集合做自注意力，让每个元素看到所有其他元素；ISAB先让m个可学习的诱导向量对集合做注意力，汇总成m个“摘要”，再让集合元素对这些摘要做注意力，复杂度从n²降到n·m。

编码器由SAB或ISAB堆叠而成，得到每个元素的上下文表示。解码器用PMA做汇聚：让k个可学习的种子向量对编码结果做注意力，得到k个输出（k=1时就是一个集合级别的向量），这比Deep Sets中简单的求和或取平均更灵活。

摘要以多实例学习、三维形状识别、小样本图像分类作为“输入是集合”的典型任务，并称该模型在理论上性质良好，在一系列集合结构数据的任务上达到了当时最好的表现。

局限与后续

  • 诱导点个数m是固定的超参数，集合很大或结构很复杂时，少量诱导点可能成为信息瓶颈。

读懂它需要的概念

自注意力与多头注意力 注意力机制 不变性与等变性 归纳偏置

本篇术语

  • 置换不变　无论输入元素以什么顺序排列，输出都相同。
  • 诱导点　少量可学习的向量，代替全部元素充当“中转站”，把两两交互的计算量从平方降到线性。

怎么学

先读Deep Sets和Transformer的多头注意力，再读原文第3节的MAB/SAB/ISAB/PMA定义；动手用PyTorch实现ISAB，在“求一组数的最大值”这样的玩具任务上和Deep Sets对比。
