字符级CNN文本分类

Character-level Convolutional Networks for Text Classification
2015.09论文延伸NeurIPS 2015Zhang, Zhao, LeCun · 纽约大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文本分类默认先分词再用词向量，遇到未登录词、拼写错误和不同语言就很脆弱。

方法

把文本当作字符序列，用深层一维卷积层、池化与感受野直接分类，不需要词、语法或语义的先验知识。

影响

在大规模数据上证明纯字符CNN可以和词袋、n-gram、词CNN、RNN竞争，是后来字符/字节级模型的先声。

方法

输入是固定长度的字符序列，每个字符用one-hot向量表示（字母表很小），后面接多层一维卷积和池化，再接全连接层输出类别。因为没有词表，拼写错误和新词天然兼容，也可以不加修改地用于不同语言。

论文还专门构建了多个大规模文本分类数据集（以百万级样本规模为特点）来验证，并与词袋、n-gram及TF-IDF变体、基于词的ConvNet和RNN对比，得出结论：字符级ConvNet在足够大的数据集上可达到最先进或具竞争力的结果。

局限与后续

  • 需要大量训练数据，小数据集上不如词级模型。
    后来针对它的工作　ULMFiT
  • 层数深、序列长，计算开销大。
