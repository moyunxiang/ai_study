VAE-GAN

Autoencoding beyond pixels using a learned similarity metric
2015.12论文延伸ICML 2016Anders Boesen Lindbo Larsen, Søren Kaae Sønderby, Hugo Larochelle, Ole Winther · 丹麦技术大学 / 哥本哈根大学 / Twitter待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

变分自编码器VAE用逐像素误差衡量重建好坏，图像平移一点就被重罚，于是模型宁可输出模糊的平均图；生成对抗网络GAN图像锐利却没有编码器。

方法

把VAE的解码器同时当作GAN的生成器，用GAN判别器中间层的特征距离代替像素误差来衡量重建，让“像不像”由学到的特征决定。

影响

较早把VAE与GAN合成一个模型，让重建图更清晰并得到可做向量运算的隐空间；“用网络特征而非像素算重建损失”的思想后来在VQGAN等视觉分词器里成为标配。

方法

VAE的损失是重建误差加KL项（见变分推断与ELBO）。若重建误差取像素空间的平方误差，就等于假设图像每个像素独立地服从高斯分布：一张整体右移两个像素的脸，像素误差会很大，尽管人眼看来几乎一样。为了降低这类惩罚，模型倾向输出模糊结果。

VAE-GAN把三部分连成一个网络：编码器把图像映到隐变量z；解码器（也是GAN生成器）把z还原成图像；判别器区分真图、重建图和从先验采样生成的图。关键改动是重建项：不再比较像素，而是比较原图和重建图在判别器第l层的特征，L_rec = ‖Dis_l(x) − Dis_l(x̃)‖²。判别器为了分辨真假而学到的特征对平移等小变化不敏感，于是成了一个“学出来的相似度度量”。三个部分分别用不同的损失组合更新。

作者在人脸数据上显示，重建与生成图的视觉保真度高于用逐元素误差训练的VAE，并且学到的隐空间里可以通过简单加减修改“戴眼镜”等高层属性。

局限与后续

  • 引入GAN的对抗训练后也带来不稳定和需要仔细平衡多项损失的问题，难以放大到复杂的自然图像。
