线性探针

Understanding intermediate layers using linear classifier probes
2016.10论文延伸ICLR 2017 WorkshopGuillaume Alain, Yoshua Bengio · 蒙特利尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度网络被视为黑箱；人们不知道每一层的特征对分类到底有多大用处，也没有一种与模型自身训练无关的观察手段。

方法

在网络的每一层中间特征上训练一个独立的线性分类器（探针），用其准确率衡量该层特征与目标任务的相关程度。

影响

「线性探针」成为分析神经网络表示的基本工具，从视觉扩展到BERTology，也是后来无监督发现潜在知识CCS、表示工程RepE的出发点。

方法

做法很简单：固定已训练好的网络，在某一层的输出上训练一个线性分类器去预测标签，探针的训练与原网络完全独立，不影响原网络。把这个操作在每一层都做一遍，就能画出一条「特征对分类的有用程度随深度变化」的曲线。

作者把方法用在Inception v3和ResNet-50上，据摘要，实验观察到特征的线性可分性随深度单调增加，也就是越深的层，线性分类器越容易把类别分开。他们还用探针来诊断模型，例如发现某些层之间存在训练问题。

关键点是选线性分类器：它足够简单，不会自己学出太多东西，因此探针的好成绩可以认为是特征本身已经包含了信息；这一点后来引发了争论，因为复杂探针也许是在自己做学习（见探针的对照任务）。

局限与后续

  • 探针高分只说明信息「可被线性读出」，不说明模型自己真的用了这些信息。
