无监督NMT（Artetxe）

Unsupervised Neural Machine Translation
2017.10论文延伸ICLR 2018Mikel Artetxe, Gorka Labaka, Eneko Agirre, Kyunghyun Cho · 巴斯克大学 / 纽约大学待核对
arXiv ↗代码 UNdreaMT ↗在交互版中打开（演化树、学习进度）

问题

绝大多数语言对（例如巴斯克语与其他语言）没有大规模平行语料，此前的半监督、枢轴翻译仍需要一定的跨语言信号。

方法

只用两种语言各自的单语语料：先用无监督方法得到跨语言词向量并固定，作为共享编码器的输入；每种语言一个解码器，交替做去噪自编码和即时回译来训练。

影响

与Lample等同月发表的工作一起证明完全不用平行句也能训练神经翻译，「去噪+迭代回译」成为无监督与低资源翻译的标准配方。

方法

模型是一个略作修改的注意力编码器-解码器（注意力机制）：两种语言共用一个编码器，编码器的输入是固定不更新的跨语言词向量——它们由单语Skip-gram负采样词向量经无监督映射对齐得到，因此「猫」和「cat」从一开始就在同一空间里相近。两种语言各有一个解码器。

训练交替进行两件事。去噪：把L1句子打乱局部词序后送入共享编码器，让L1解码器还原原句；加噪是为了防止模型学成简单的逐词复制。即时回译（回译）：用当前模型把L1句子译成L2，再把这句伪L2送入编码器，让L1解码器恢复原句，反方向同理。共享编码器加固定的跨语言词向量，使模型学到与语言无关的句子表示，两种语言的解码器就能互相「接力」。

摘要报告：完全无监督时在WMT 2014法英和德英上分别得到15.56和10.21 BLEU；再加10万句平行语料，提高到21.81和15.24。同一时期无监督神经机器翻译（Lample等）用共享编码器和解码器加对抗训练，得到相近结论，两者常被一起引用。

局限与后续

  • BLEU远低于有监督系统，且在语言差异大、单语语料领域不一致时，初始的跨语言词向量映射容易失败，整个训练随之崩溃。

  • 词向量固定不更新，模型容量受限；后续工作发现结合短语表或预训练能大幅提升。

读懂它需要的概念

编码器-解码器 注意力机制 嵌入向量 自编码器 无监督学习

本篇术语

  • 跨语言词向量　把两种语言的词映射到同一个向量空间，使互为翻译的词彼此靠近。
  • 去噪自编码　给输入加噪声（如打乱词序）再让模型还原原句，迫使模型学习句子结构而非逐字复制。

怎么学

先读回译和无平行语料的词翻译MUSE的讲解 → 读原文第3节的模型结构与训练流程 → 动手：用开源代码在小规模英法单语语料上训练几轮，观察去噪与回译损失和BLEU的变化。
