Mamba状态空间模型

Mamba: Linear-Time Sequence Modeling with Selective State Spaces
2023.12论文延伸COLM 2024Albert Gu, Tri Dao · CMU / Princeton待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

此前的亚二次模型（线性注意力、S4结构化状态空间等）与注意力相比在语言上较弱，原因是参数不随输入变化，无法按内容选择记住或忘记什么。

方法

让状态空间模型的参数成为输入的函数（选择性），并用硬件感知的并行扫描算法保持线性时间。

影响

成为首个在语言上可与同规模Transformer竞争的线性时间主干，掀起状态空间与混合架构的研究浪潮。

方法

S4的状态矩阵对所有输入相同，因此能用卷积高效计算，但也不能区分重要与无关的词。Mamba让步长Δ、B、C等参数由当前输入算出，于是模型能在每个token处决定是写入状态还是忽略。

这样就不能再用卷积，作者设计了硬件感知的并行扫描，在GPU的高速存储里完成递推，并把选择性SSM整合进一个不含注意力甚至不含MLP块的简化网络。摘要称：推理吞吐是Transformer的5倍，随序列长度线性增长，在百万长度上仍有提升；语言上Mamba-3B优于同规模Transformer，与两倍大小的Transformer相当；并在音频、基因组上也达到先进水平。

局限与后续

  • 固定大小的状态在需要精确检索的任务上仍弱于注意力，实践中常与注意力混合。
    后来针对它的工作　Jamba混合架构 Gated DeltaNet
  • 选择性扫描依赖定制CUDA内核，难以用矩阵乘法加速器高效实现。
    后来针对它的工作　Mamba-2与状态空间对偶

它建立在什么之上

  • 竞争
    LSTM1997 · 基础
    同为递归模型，Mamba的状态更新近似线性、可并行扫描，扩展性更好。
  • 竞争
    Transformer2017.06 · LLM
    以线性时间和恒定状态挑战注意力主干。
  • 改进
    LSTM遗忘门1999.09 · 基础
    每一步都依赖上一步，序列内部无法并行；整段历史压进固定大小的状态，遗忘门只能整体衰减，不能精确改写某一条记忆。
  • 延续
    S4结构化状态空间2021.10 · 基础
    把S4的输入无关参数改为输入依赖，换取内容选择能力，同时放弃卷积形式。
  • 改进
    Universal Transformer2018.07 · LLM
    自适应停止让不同位置的计算量不一，难以高效批处理，实际训练和推理的硬件利用率不如固定层数。
  • 改进
    线性注意力2020.06 · 基础
    核特征映射近似不了softmax的“尖锐”选择，检索类任务上明显弱于标准注意力。
  • 改进
    HiPPO2020.08 · 基础
    矩阵A和B固定，不依赖输入内容，无法按内容选择记住什么。
  • 改进
    Performer核近似注意力2020.09 · LLM
    精确注意力在优化的内核下已经足够快，近似方法在大模型中很少被采用。
  • 改进
    Hyena长卷积算子2023.02 · 基础
    门控只依赖当前位置的投影，对需要按内容检索的任务仍弱于注意力；论文的对比规模不大，在更大规模上是否持平未被证明。
  • 改进
    RWKV2023.05 · 基础
    早期版本的衰减与状态更新不依赖输入内容，表达力有限。
  • 改进
    RetNet2023.07 · LLM
    论文实验规模最大到数十亿参数，没有在前沿规模上与Transformer正面对比；长上下文的精确回忆能力通常弱于全注意力。

后来的相关工作

  • 改进
    Gated DeltaNet2024.12 · 基础
    固定大小的状态在需要精确检索的任务上仍弱于注意力，实践中常与注意力混合。
  • 竞争
    MiniMax-01闪电注意力2025.01 · LLM
    同为用固定大小状态替代KV缓存的线性复杂度序列模型；论文测试中纯线性模型都在检索上不足，因此采用混合结构。
  • 使用
    Vision Mamba2024.01 · 视觉
    用选择性状态空间模型作为主体序列算子。
  • 使用
    Jamba混合架构2024.03 · LLM
    把Mamba层作为主体，用选择性状态空间模型以线性成本处理长序列。
  • 延续
    Mamba-2与状态空间对偶2024.05 · 基础
    在Mamba基础上简化SSM矩阵并改为矩阵乘主导的算法，速度提升。

读懂它需要的概念

循环网络与隐状态 门控机制 常微分方程与随机微分方程 吞吐、延迟与批处理 KV缓存 显存、内存带宽与“内存墙”

怎么学

先学S4结构化状态空间和HiPPO；读原文第3节的选择机制与算法2；运行官方mamba_ssm的小模型，对比不同序列长度下的显存与速度。
