LSD Lipschitz技能发现

Lipschitz-constrained Unsupervised Skill Discovery
2022.02论文延伸ICLR 2022Seohong Park, Jongwook Choi, Jaekyeom Kim, Honglak Lee, Gunhee Kim · 首尔大学 / 密歇根大学 / LG AI Research待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

基于互信息的技能发现（DIAYN、DADS等）只要求技能之间可区分，状态上一点小差别就足够区分，因此偏好静止或移动很小的技能，对下游任务用处不大。

方法

把状态映射到一个满足Lipschitz约束的表示空间——表示里的距离不超过状态空间里的距离——再让技能z沿表示空间的方向z尽量走远；这样“区分技能”必须靠真实地移动很远（LSD）。

影响

距离最大化式技能发现的开端，后续的CSD、METRA都是同一组作者在它上面的推进，其学到的表示还能零样本用于目标跟随。

方法

LSD（Lipschitz-constrained Skill Discovery）学一个表示函数 φ: S → Z 和以技能 z ∈ Z 为条件的策略。目标是：

max E[(φ(s_T) − φ(s_0))ᵀ z] s.t. ‖φ(x) − φ(y)‖ ≤ ‖x − y‖ 对所有状态x, y

约束是1-Lipschitz条件，用谱归一化实现。读法：策略要让表示在z方向上走得尽量远；但因为表示的变化不能超过状态本身的变化，表示上走远就意味着在状态空间里真的走远。而互信息目标没有这个约束，只要编码器把很小的状态差别放大，技能就能被区分，所以会学出“原地小动作”。

实现上把目标拆成每一步的奖励 r_t = (φ(s_(t+1)) − φ(s_t))ᵀ z，用SAC训练策略。

作者还指出，学到的φ可以零样本做目标跟随：给定目标状态g，令 z = φ(g) − φ(s) 并归一化，策略就会朝目标前进，无需额外训练或复杂规划。在多个MuJoCo运动和操作环境上，摘要称LSD在技能多样性、状态空间覆盖和7个下游任务（包括在Humanoid上依次跟随多个目标）上都超过以往方法。

局限与后续

  • Lipschitz约束用的是状态空间的欧氏距离，在像素观测下欧氏距离没有意义，方法难以直接用于图像输入。
    后来针对它的工作　METRA度量感知技能
  • 只追求“走得远”，容易学出简单的移动技能，而忽略难以控制但有用的行为（如操作物体）。
    后来针对它的工作　CSD可控性感知技能
