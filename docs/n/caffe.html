Caffe

Caffe: Convolutional Architecture for Fast Feature Embedding
2013.12系统重要开源发布2013年12月；论文 ACM Multimedia 2014贾扬清（Yangqing Jia）, Evan Shelhamer, Jeff Donahue, Sergey Karayev, Jonathan Long, Ross Girshick, Sergio Guadarrama, Trevor Darrell · 加州大学伯克利分校BVLC待核对
arXiv ↗GitHub：BVLC/caffe ↗在交互版中打开（演化树、学习进度）

问题

AlexNet之后人人都想用卷积网络，但能高效训练它的代码要么是作者个人的CUDA代码，要么需要自己用Theano搭，复现一个ImageNet模型门槛很高。

方法

用C++/CUDA写一套高速的卷积网络库：网络结构写在纯文本配置文件里，不用写代码；CPU和GPU一键切换；同时发布训练好的参考模型（如AlexNet）供直接下载使用。

影响

2014—2016年计算机视觉研究和工业部署的主力框架，R-CNN、FCN等大量视觉工作用它实现；“下载预训练模型再微调”的习惯从它的Model Zoo开始普及。

背景

AlexNet在2012年证明了GPU训练的大卷积网络在ImageNet上的威力，但其cuda-convnet代码面向特定实验，扩展不便。当时的选择大致是：Theano与自动微分灵活但要自己从数学表达式搭网络、编译慢；Torch7需要写Lua；其他工具要么没有GPU支持、要么不开源。视觉研究者想要的是一个“像搭积木一样”组网、又足够快、能直接部署进C++产品的工具。Caffe的直接前身是同组的DeCAF通用深度特征——一个用预训练卷积网络提取通用特征的Python工具，但它速度不够快。

方法

网络即配置。模型用Google Protocol Buffer格式的文本文件（.prototxt）描述，每层写明类型、输入输出和参数，例如一个卷积层要写明类型Convolution、输入blob（data）、输出blob（conv1）、卷积核大小和输出通道数。网络可以是任意有向无环图。训练超参数写在另一个solver文件里，改结构不需要重新编译。

Blob与Layer。数据统一存成四维数组blob（批大小×通道×高×宽），blob在CPU和GPU内存之间按需自动同步。每个层实现前向和反向两个函数；Solver驱动SGD训练。

卷积变矩阵乘。卷积层先用im2col把输入中每个卷积窗口展开成一列，再调用一次BLAS线性代数接口的GEMM完成卷积。以LeNet第一层为例：28×28的单通道输入、5×5卷积核，输出24×24，于是展开成25×576的矩阵，与20×25的权重相乘就得到20个通道的输出。这样卷积的速度直接受益于高度优化的矩阵乘法库，GPU上用cuBLAS（见CUDA）。

参考模型。发布训练好的AlexNet和R-CNN检测模型，用户可以直接拿来提特征或微调。

结果

论文称在单块K40或Titan GPU上每天能处理超过4000万张图片（约2.5毫秒一张），并认为它可能是当时最快的卷积网络实现。公开发布后前六个月就被伯克利和其他大学的大量研究项目使用，还用微调把网络扩展到完整ImageNet的1万个类别。

后来的发展

Caffe让卷积网络在视觉圈普及：R-CNN、全卷积网络FCN等基于它实现，Caffe Model Zoo让社区共享预训练模型，cuDNN发布后很快被集成进来加速卷积。它的“层”抽象和配置文件式定义被许多后来的推理引擎沿用。

局限也很明显：加新层要写C++和CUDA，循环网络支持差，多机训练困难。Caffe在2018年停止支持，研究界早已转向TensorFlow和PyTorch。

容易误解的地方

  • Caffe的代码是BSD许可证，但论文明确说明发布的参考模型仅限学术和非商业用途，并不是BSD。
  • 配置文件方便的是“组合已有的层”；需要新运算时仍要自己写C++/CUDA的前向和反向函数。

局限与后续

  • 网络必须用配置文件描述成固定的层图，循环网络、动态结构和新运算很难表达，研究灵活性差。
    后来针对它的工作　PyTorch TensorFlow
  • 主要面向单机，多机分布式训练支持弱，难以训练更大的模型。
    后来针对它的工作　TensorFlow
  • im2col把输入展开会成倍增加显存占用，卷积性能受限于通用矩阵乘法。
    后来针对它的工作　cuDNN

读懂它需要的概念

卷积层、池化与感受野 图像作为张量 反向传播 随机梯度下降与小批量 矩阵乘法与线性变换 CPU、GPU与并行计算

本篇术语

  • im2col　把图像中每个卷积窗口覆盖的像素展开成矩阵的一列，使卷积可以用一次大矩阵乘法完成，代价是数据被重复存储。
  • Protocol Buffer（prototxt）　Google的一种结构化数据描述格式。Caffe用它的文本形式描述网络结构和训练参数，也用二进制形式存储模型权重。
  • 微调（fine-tuning）　拿在大数据集上训练好的模型作为起点，在新任务的数据上继续训练，通常只需少量数据和时间。

怎么学

先补卷积层、池化与感受野和矩阵乘法与线性变换。读论文第2、3节了解Blob/Layer/Solver。动手：用NumPy写一个im2col，把一个小卷积改写成矩阵乘法，与直接循环的结果对比是否一致；再打开Caffe仓库examples/mnist下的LeNet配置文件，逐层对照理解。
