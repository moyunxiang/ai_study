《多视图几何》

Multiple View Geometry in Computer Vision
2000思想延伸Book 2000Richard Hartley, Andrew Zisserman · Cambridge University Press待核对
出版社页面 ↗在交互版中打开（演化树、学习进度）

问题

多幅图像之间的几何关系（相机模型、对极几何、三维重建）散落在摄影测量和视觉论文里，没有统一的数学框架。

方法

用射影几何的统一语言，把相机矩阵、基础矩阵、三焦点张量、自标定和光束平差整理成一本系统教材。

影响

成为三维视觉和SLAM领域的标准参考书，后来的COLMAP、ORB-SLAM等系统都在使用其中的算法。

方法

这本书用齐次坐标和射影变换表示点、线和相机：一个三维点X投影到图像上是x = P X，P是3×4的相机矩阵。书中给出两幅图之间的对极约束x′ᵀ F x = 0，F是3×3的基础矩阵，已知足够多的对应点就可以估计F，进而恢复相机的相对姿态和三维点（见相机模型与多视图几何）。

估计时对错误匹配用RANSAC做稳健处理，最后用光束平差联合优化所有相机和三维点。书的价值在于给出了推导、数值稳定的算法（如归一化八点法）和各种退化情形的讨论。
