UCB1

Finite-time Analysis of the Multiarmed Bandit Problem
2002论文重要Machine Learning 47, 2002Peter Auer, Nicolò Cesa-Bianchi, Paul Fischer · 格拉茨工业大学 / 米兰大学 / 多特蒙德大学待核对
Springer ↗论文PDF（Cesa-Bianchi主页） ↗Wikipedia：Multi-armed bandit ↗在交互版中打开（演化树、学习进度）

问题

多臂老虎机里，Lai和Robbins已证明遗憾至少按ln n增长，也给出了渐近达到这一下界的策略；但那些策略的指标很难计算、只在n趋于无穷时才有保证，还要假设奖励分布属于特定的参数族。

方法

一个几行就能写完的规则：每台机器先拉一次，之后总拉“平均奖励 + √(2 ln n / n_j)”最大的那台。只要奖励在[0,1]之间，不管分布是什么，在任何有限的n上遗憾都不超过O(ln n)的显式上界。

影响

“对不确定性保持乐观”的置信上界原则从此成为探索的标准做法：直接催生了围棋里的UCT/蒙特卡洛树搜索、AlphaGo的PUCT选择规则，以及推荐系统里的LinUCB。

背景

多臂老虎机问题把问题表述为：K台老虎机，每台的奖励分布未知，每次只能拉一台，想让n次的总奖励最大。代价用遗憾衡量：如果一直拉最好的那台能多拿多少（见探索与利用）。

Lai–Robbins遗憾下界（1985）证明了任何策略拉一台次优机器的期望次数至少约为ln n / D(p_j‖p*)，D是该机器与最优机器奖励分布的KL散度，并构造了渐近达到它的策略。问题在于其“置信上界”指标依赖整段奖励历史，计算困难，而且只在渐近意义下成立。Agrawal（1995）把指标简化为总奖励的简单函数，但保证仍然是渐近的。实践中大家用的是ε-贪心这类启发式，参数靠调。

方法

UCB1：先把每台机器各拉一次；之后每一轮，对每台机器j计算

x̄_j + √(2 ln n / n_j)

x̄_j是它目前的平均奖励，n_j是它被拉过的次数，n是总轮数，拉这个值最大的那台。第二项是由Hoeffding不等式得到的置信区间半宽：拉得越少，区间越宽，越值得一试。随着n增长，所有机器的加成都缓慢变大，所以被冷落太久的机器总会被重新试一次。

例子：两台机器共拉了100次，A拉了80次、平均0.6，B拉了20次、平均0.5。2 ln 100 ≈ 9.21，A的指标0.6 + √(9.21/80) ≈ 0.94，B的指标0.5 + √(9.21/20) ≈ 1.18，于是下一次拉B——它虽然均值低，但还不够确定。

定理1：奖励在[0,1]内的任意分布下，对任意n，期望遗憾不超过

8 Σ_{i: μ_i<μ*} (ln n / Δ_i) + (1 + π²/3) Σ_j Δ_j

Δ_i = μ* − μ_i是第i台与最优机器的差距。差距越小的机器越难分辨，所以对遗憾贡献越大。论文还给出了常数更接近最优的UCB2、按1/n衰减探索率并有同样对数保证的ε_n-贪心，以及正态奖励下的变体。

结果

在2臂和10臂伯努利老虎机上各跑10万轮、取100次平均：调好参数的ε_n-贪心几乎总是最好，但参数稍偏性能就迅速变差，且在次优机器很多、差别较大时吃亏；用样本方差收紧置信项的UCB1-TUNED多数情况下与调好的ε_n-贪心相当，对方差不敏感，但作者无法证明它的遗憾界；UCB2与UCB1-TUNED相近，略差。

后来的发展

蒙特卡洛树搜索UCT（UCT）把UCB1用在博弈树的每个节点上，决定往哪个分支多模拟，随后有了MoGo和强得多的围棋程序；AlphaGo、AlphaZero的PUCT公式是它的变体。LinUCB上下文老虎机把置信上界推广到带特征的上下文老虎机，用于新闻推荐；UCRL2遗憾界把乐观原则推广到完整的MDP。Thompson采样的复兴是同一问题上随后复兴的贝叶斯路线。

容易误解的地方

  • “乐观”不是说高估更好，而是对还没看清楚的选项按其可能达到的上限来对待，于是要么发现它确实好，要么很快排除它。
  • 定理1是有限时间界，但常数8较松；它并不意味着UCB1在实践中总比调好的ε-贪心好。

局限与后续

  • 常数较松，UCB1实际表现不如调过参数的方法；表现更好的UCB1-TUNED却没有理论保证。

读懂它需要的概念

探索与利用 期望与方差 随机变量与概率分布 时间与空间复杂度

本篇术语

  • 遗憾　若始终选最优选项能得到的期望总奖励，减去实际策略得到的期望总奖励。对数遗憾意味着犯错次数增长得极慢。
  • Hoeffding不等式　有界随机变量的样本均值偏离真实均值超过某个量的概率随样本数指数下降；UCB1的加成项由它推出。
  • 置信上界（UCB）　根据目前数据，某选项的真实均值“最高可能是多少”。按置信上界选择，就是对不确定的选项保持乐观。

怎么学

先懂探索与利用和期望与方差。读原文第1–2节（问题与定理1）和第4节实验，定理1的证明在第3节，约两页。动手：模拟原文表中的2臂（0.9/0.6、0.9/0.8）和10臂伯努利老虎机，比较UCB1、ε-贪心和Thompson采样的累计遗憾曲线（用对数横轴）。
