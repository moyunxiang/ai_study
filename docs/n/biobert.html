BioBERT生物医学预训练

BioBERT: a pre-trained biomedical language representation model for biomedical text mining
2019.01论文延伸Bioinformatics 2020Jinhyuk Lee, Wonjin Yoon, Sungdong Kim, Donghyeon Kim, Sunkyu Kim, Chan Ho So, Jaewoo Kang · 高丽大学、Clova AI（NAVER）待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

BERT在通用语料（维基百科和图书）上预训练，直接用到生物医学文献时，大量专业词汇和表达方式与通用语料分布不同，效果并不理想。

方法

以BERT的权重为起点，在PubMed摘要和PMC全文这些大规模生物医学语料上继续做BERT式预训练，再在各个生物医学任务上微调；结构与BERT完全相同。

影响

最早、也是被引用最多的领域专用BERT之一，在生物医学命名实体识别、关系抽取和问答上明显超过BERT与此前方法，开启了SciBERT、ClinicalBERT、PubMedBERT等一系列领域预训练模型。

方法

背景：BERT（2018年10月）的预训练语料是英文维基百科和BooksCorpus。生物医学文献里充满基因、蛋白、药物、疾病名称和长串的专业复合词，词频分布与通用文本差异很大，此前的生物医学NLP多用在领域语料上训练的word2vec类词向量加任务专用网络。

做法：BioBERT不改结构、也不改词表，直接用BERT-Base的权重和WordPiece词表初始化，在PubMed摘要（约45亿词）和PMC全文（约135亿词）上继续做掩码语言模型和下一句预测的预训练（语料规模为一般了解）。之后像BERT一样，加一个很薄的任务头在各个下游数据集上微调。由于沿用BERT词表，生物医学专有名词常被切成多个子词，但子词组合仍能表示它们。

结果：摘要称，在三个代表性的生物医学文本挖掘任务上，BioBERT显著超过此前最好的方法：生物医学命名实体识别F1提升0.62%，生物医学关系抽取F1提升2.80%，生物医学问答MRR提升12.24%；而直接使用通用BERT只能与此前最好方法持平。作者分析认为，在生物医学语料上预训练帮助BERT理解复杂的生物医学文本。预训练权重和微调代码均公开。

局限与后续

  • 沿用通用领域的WordPiece词表，大量生物医学术语被切得很碎；后续工作用领域语料重建词表并从头预训练，效果更好。

读懂它需要的概念

预训练与微调 掩码建模 迁移学习 分词与token 准确率、精确率、召回率与F1

本篇术语

  • 命名实体识别（NER）　从文本中找出并标注人名、地名或基因、疾病等特定类别的词组。
  • MRR（平均倒数排名）　问答评测指标：对每个问题看正确答案排在第几位，取倒数后求平均，越接近1越好。

怎么学

先读BERT；读原文第2节预训练语料与设置和第4节三类任务的结果表；动手：用BioBERT和BERT-Base分别在一个公开的生物医学NER数据集上微调，比较F1和专业词的切分情况。
