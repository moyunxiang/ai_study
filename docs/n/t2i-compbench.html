T2I-CompBench

T2I-CompBench: A Comprehensive Benchmark for Open-world Compositional Text-to-image Generation
2023.07数据集延伸NeurIPS 2023Kaiyi Huang, Kaiyue Sun, Enze Xie, Zhenguo Li, Xihui Liu 等 · 香港大学 / 华为诺亚方舟实验室待核对
arXiv（现为++版） ↗在交互版中打开（演化树、学习进度）

问题

文生图模型常常画错物体的属性搭配和位置关系（红色的方块配蓝色的球却画反了），而已有指标只看整体质量，测不出这类组合错误。

方法

构建专门考察组合能力的提示词集：属性绑定、物体关系、复杂组合，并为各类设计对应的自动评测指标。

影响

成为评测文生图组合能力的常用基准，推动了针对属性绑定和空间关系的改进工作。

方法

T2I-CompBench把「组合式生成」拆成几类分别测试：属性绑定（颜色、形状、纹理应绑在正确物体上）、物体之间的空间与非空间关系、以及更复杂的混合提示。每类都有专门的评测方式，借助检测模型、视觉问答模型（如BLIP）和多模态大模型来判断生成图是否满足提示，而不是只算整体相似度。

论文在发布时评测了当时的Stable Diffusion开源等开源模型，并提出了无需重新训练的改进办法。arXiv页面现已更新为T2I-CompBench++版本：含8000条组合提示，分属性绑定、物体关系、生成计数和复杂组合四大类、八个子类，新增3D空间关系与计数，并增加用GPT-4V等多模态大模型当评测者，评测了包括FLUX.1、SD3、DALL-E 3在内的11个模型。需要注意这里描述的是更新后版本的内容，原始版本的提示数量与细分类别以论文为准。

局限与后续

  • 自动评测依赖检测或视觉问答模型，这些评测者自己会出错，计数和三维关系尤其不准。
    后来针对它的工作　GenEval
  • 提示词是模板化的，与真实用户的长而复杂的描述有差距。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    FID与Inception Score2017.06 · 数据·评测
    完全不衡量条件生成是否符合输入，文生图时无法判断图片与文字描述是否一致。
  • 使用
    Stable Diffusion开源2022.08 · 生成
    以其为主要被测对象，揭示其属性绑定和关系错误。
  • 使用
    BLIP2022.01 · 多模态
    用BLIP等视觉问答模型作为属性和关系的自动判官。
  • 改进
    Pick-a-Pic / PickScore2023.05 · 数据·评测
    一个标量分数不能区分构图、清晰度、文图一致性等具体维度，也无法说明错在哪里。
  • 改进
    HPS v2人类偏好分2023.06 · 数据·评测
    偏好仍是对整张图的整体判断，难以拆解出结构错误、数量错误等具体失败模式。

后来的相关工作

  • 改进
    GenEval2023.10 · 数据·评测
    自动评测依赖检测或视觉问答模型，这些评测者自己会出错，计数和三维关系尤其不准。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

基准、排行榜与SOTA 分类、检测、分割 准确率、精确率、召回率与F1

怎么学

先了解FID与CLIPScore的局限 → 读原文各类提示与评测指标的定义 → 用官方脚本评测一个自己的模型并看失败案例。
