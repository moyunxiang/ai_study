HATRPO/HAPPO

Trust Region Policy Optimisation in Multi-Agent Reinforcement Learning
2021.09论文延伸Jakub Grudzien Kuba, Ruiqing Chen, Muning Wen, Ying Wen, Fanglei Sun, Jun Wang, Yaodong Yang · 牛津大学 / 上海科技大学 / 上海交通大学 / 伦敦大学学院 / 北京大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

把TRPO/PPO直接用到多智能体时，各智能体同时更新可能方向互相冲突，单调改进的保证失效；MAPPO等又依赖参数共享，不适合角色不同的异构团队。

方法

证明联合优势可以按顺序拆成每个智能体在前面队友已更新基础上的优势之和，于是让智能体按随机顺序逐个做信赖域更新。

影响

给合作MARL带来了有单调改进理论保证的信赖域方法，不需参数共享；它的优势分解引理直接催生了多智能体Transformer（MAT）。

方法

核心是多智能体优势分解引理：对任意一组智能体i₁…iₘ，A^{i₁:ₘ}(s,a^{i₁:ₘ}) = Σⱼ A^{iⱼ}(s,a^{i₁:ⱼ₋₁},a^{iⱼ})。意思是团队的联合优势，等于第一个智能体的优势，加上“在第一个已选定动作的条件下”第二个的优势，依此类推。

据此设计顺序更新：每轮随机抽一个排列，智能体逐个更新；第m个智能体优化的替代目标会考虑前m−1个已经更新过的策略，并加一个KL惩罚。作者证明这样联合策略单调改进，随机顺序还有助于收敛到纳什均衡。HATRPO用KL约束（同TRPO），HAPPO把约束换成PPO式的截断目标，只需一阶优化。各智能体不必共享参数，论文还给出例子说明强制参数共享可能离最优很远。

在多智能体MuJoCo（如把一个Ant或HalfCheetah的各条腿交给不同智能体控制）和星际SMAC上测试：MuJoCo各任务中HATRPO与HAPPO均超过IPPO、MAPPO和MADDPG，且智能体越多差距越大；SMAC上多数方法都接近100%胜率，作者认为它已难以区分算法。

局限与后续

  • 顺序更新使每轮训练时间随智能体数线性增加，大团队下计算开销明显。

它建立在什么之上

  • 延续
    PPO2017.07 · RL
    HAPPO用PPO式的截断替代目标实现顺序更新。
  • 改进
    平均场多智能体RL2018.02 · RL
    假设邻居同质、可互换且只有平均效应重要，智能体角色差异大或需要精细分工时近似失效。
  • 延续
    TRPO2015.02 · RL
    把信赖域的单调改进理论从单智能体推广到多智能体联合策略。
  • 使用
    星际多智能体挑战SMAC2019.02 · RL
    评测平台之一，作者也指出它已接近饱和。
  • 改进
    MAPPO2021.03 · RL
    MAPPO依赖参数共享、同时更新且无单调改进保证；HAPPO用顺序更新给出保证并支持异构智能体。

策略梯度 Actor-Critic与优势函数 KL散度 博弈论基础与纳什均衡

怎么学

先学TRPO与PPO；读原文的优势分解引理和顺序更新算法部分，再读多智能体Transformer MAT看它如何把同一引理变成自回归Transformer。
