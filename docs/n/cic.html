CIC对比内在控制

CIC: Contrastive Intrinsic Control for Unsupervised Skill Discovery
2022.02论文延伸Michael Laskin, Hao Liu, Xue Bin Peng, Denis Yarats, Aravind Rajeswaran, Pieter Abbeel · UC Berkeley / NYU / Meta AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

无监督技能发现方法（DIAYN、APS等）用一个判别器从状态猜技能，技能空间一大判别器就学不好，学出的技能多样性有限，在URLB上不如纯探索方法。

方法

把技能与“状态转移”（s, s′）之间的互信息分开优化：用对比学习（类似CPC/InfoNCE）让转移嵌入与技能向量对齐，用转移嵌入上的粒子熵作为内在奖励鼓励多样性（CIC）。

影响

在URLB上大幅领先此前的技能发现方法，成为无监督RL预训练的强基线；METRA等后来的技能发现工作都把它列入对比。

方法

目标仍是最大化技能z与行为之间的互信息，但CIC用转移 τ = (s, s′) 而不是单个状态，并按 I(τ; z) = H(τ) − H(τ | z) 拆开：

  • −H(τ | z)（技能可区分）：用对比学习的下界。给一批 (τ_i, z_i)，让查询网络 g_q(τ_i) 与键网络 g_k(z_i) 的内积在配对时大、不配对时小，损失是InfoNCE形式：

L = −log [ exp(g_q(τ_i)ᵀg_k(z_i)/T) / Σ_j exp(g_q(τ_i)ᵀg_k(z_j)/T) ]

这比训练一个直接输出技能的判别器容易扩展到高维技能；

  • H(τ)（行为多样）：在学到的转移嵌入空间里用k近邻粒子熵估计，作为RL的内在奖励，与APT主动预训练的做法相同。

预训练阶段智能体（DDPG底座）在无奖励的环境中最大化这个内在奖励；下游阶段给出外部奖励，选择一个技能后短时间微调。作者在URLB上评测：先进行长时间无奖励预训练，再进行短时间的下游适应。摘要称CIC在适应效率上大幅提升，比此前的无监督技能发现方法高1.79倍，比次优的探索算法高1.18倍。

局限与后续

  • 下游适应时要先在多个技能中搜索最合适的一个，技能数多时选择成本高，且选到的技能未必对齐任务。
