Project Genie

Project Genie: Experimenting with infinite, interactive worlds
2026.01系统延伸Google DeepMind待核对
Google博客 ↗在交互版中打开（演化树、学习进度）

问题

Genie 3在2025年8月只以研究预览形式展示，普通用户无法亲手生成和探索交互世界。

方法

做成网页应用：用文字和图片“勾勒”世界并用Nano Banana Pro预览，再由Genie 3随用户移动实时生成前方画面，支持改编他人的世界。

影响

第一个面向付费消费者的实时交互世界模型产品，让“世界模型”从论文概念进入大众讨论。

方法

2026年1月29日，Google DeepMind以“实验性研究原型”的名义推出Project Genie，底层是Genie 3，同时用到Nano Banana Pro和Gemini。功能分三块：世界勾勒（用文字和图片描述环境，先用Nano Banana Pro生成预览，选第一或第三人称视角）、世界探索（用户移动时Genie 3实时生成前方路径，可调整镜头）、世界改编（在别人的提示上二次创作，浏览画廊，下载探索视频）。

首批只对美国18岁以上的Google AI Ultra订阅用户开放，每次生成限60秒。官方列出的局限包括：世界不一定逼真、不一定遵守提示和物理规律，角色控制延迟较高，Genie 3发布时演示的“可提示事件”（探索中途用文字改变世界）尚未加入。
