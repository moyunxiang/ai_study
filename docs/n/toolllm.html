ToolLLM与ToolBench

ToolLLM: Facilitating Large Language Models to Master 16000+ Real-world APIs
2023.07论文延伸ICLR 2024Yujia Qin, Shihao Liang, Yining Ye, Kunlun Zhu, Lan Yan, Yaxi Lu, Yankai Lin, Xin Cong, Xiangru Tang 等 · 清华大学 / 人民大学 / 耶鲁 / 腾讯 / Zhihu待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

开源模型（如LLaMA）在指令微调里几乎没学过工具使用，面对真实世界的API远不如ChatGPT；已有数据集也只覆盖少数API。

方法

用ChatGPT自动构造包含16,464个真实RESTful API的指令数据集ToolBench，并提出深度优先搜索决策树让模型回溯改正调用路径，再微调LLaMA。

影响

给开源模型提供了大规模、可复现的工具使用训练和评测数据，是后来许多工具调用模型的数据基础。

方法

ToolBench的构造分三步：从RapidAPI Hub收集16,464个真实API（49个类别）；让ChatGPT生成涉及单个或多个API的指令；再让ChatGPT为每条指令搜索出一条有效的API调用链。关键改进是深度优先搜索决策树（DFSDT）：ReAct式的链条走错一步就只能失败，DFSDT允许模型在多条推理路径中评估、放弃死路并回溯，扩大搜索空间，这与思维树的思路相通。论文还提出自动评测器ToolEval。

用ToolBench微调LLaMA得到ToolLLaMA，论文称它在执行复杂指令和泛化到没见过的API上表现出色，并与ChatGPT相当。它把Gorilla API调用的“教模型写API调用”扩展到了多API、多步骤。

局限与后续

  • 训练数据由ChatGPT生成和标注，错误会被继承，部分指令和调用链质量有噪声。
