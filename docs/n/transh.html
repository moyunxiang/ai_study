TransH超平面平移嵌入

Knowledge Graph Embedding by Translating on Hyperplanes
2014.07论文延伸AAAI 2014Zhen Wang, Jianwen Zhang, Jianlin Feng, Zheng Chen · 中山大学、微软亚洲研究院待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

TransE把关系看作头实体向量到尾实体向量的平移 h + r ≈ t，简单高效，但处理不了一对多、多对一、多对多和自反关系：如果“导演—执导—电影”中一个导演有多部电影，TransE会把这些电影的向量挤成同一个点。

方法

让每个关系拥有一个超平面：先把头尾实体投影到该关系的超平面上，再在超平面内做平移。同一个实体在不同关系下的投影不同，于是多部电影只需在“执导”超平面上的投影重合，本身仍可不同。

影响

以几乎与TransE相同的参数量和计算代价，在WordNet和Freebase上的链接预测、三元组分类和事实抽取任务中显著优于TransE；它与同期的TransR、TransD等组成了“Trans系列”平移式知识图谱嵌入，其伯努利负采样技巧也被广泛沿用。

背景

TransE知识图谱嵌入（2013）用 ‖h + r − t‖ 衡量三元组 (h, r, t) 是否成立，参数少、易扩展，是知识图谱补全的强基线。但当 (h, r, t₁) 和 (h, r, t₂) 同时成立时，最优解要求 t₁ ≈ t₂；自反关系则要求 r ≈ 0。更复杂的模型（如RESCAL张量分解的双线性矩阵、神经张量网络）能表达这些映射属性，但参数多、效率低。

方法

每个关系r有两个向量：超平面的法向量 w_r（单位长度）和超平面上的平移向量 d_r。实体投影为

h⊥ = h − w_rᵀh · w_r，t⊥ = t − w_rᵀt · w_r

打分函数为 f_r(h, t) = ‖h⊥ + d_r − t⊥‖²₂，越小越可能成立。训练用基于间隔的排序损失：L = Σ max(0, f_r(h,t) + γ − f_r(h′,t′))，(h′, r, t′) 是负例，并约束实体向量范数不超过1、d_r 位于超平面内。

负采样技巧：随机替换头或尾实体造负例时，可能恰好造出一个真实但未被收录的三元组（假负例）。对一对多关系，替换头实体更不容易造出假负例。作者统计每个关系平均每个头对应多少尾（tph）和每个尾对应多少头（hpt），以概率 tph/(tph+hpt) 替换头实体、否则替换尾实体，称为“bern”采样。

结果

在WordNet与Freebase的标准数据上，TransH在链接预测、三元组分类和事实抽取三项任务中相对TransE有显著提升，同时保持了相近的可扩展性；bern负采样对TransE和TransH都有帮助（原文摘要）。

后来的发展

TransH之后，TransR关系空间嵌入（2015）把实体投影到关系专属的空间，TransD、TranSparse等进一步细化投影方式；双线性的DistMult双线性嵌入、ComplEx复数嵌入和旋转式的RotatE旋转嵌入则从另一角度解决复杂关系建模。bern负采样成为平移式嵌入的标准训练配置。

读懂它需要的概念

嵌入向量 向量、矩阵与张量 范数与距离 损失函数 随机梯度下降与小批量

本篇术语

  • 链接预测　给定三元组中的两项（如头实体和关系），预测缺失的另一项。
  • 一对多关系　一个头实体对应多个尾实体的关系，如一位导演执导多部电影。
  • 假负例　随机替换得到、被当作错误的三元组，其实在现实中成立，只是知识图谱里没收录。

怎么学

先读TransE知识图谱嵌入 → 读本文第3节投影与负采样 → 动手：用PyKEEN在FB15k-237上分别训练TransE和TransH，比较两者在一对多关系上的Hits@10。
