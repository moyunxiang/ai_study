Google Brain猫脸实验

Building High-level Features Using Large Scale Unsupervised Learning
2011.12论文重要ICML 2012（arXiv 2011年12月）Quoc V. Le, Marc'Aurelio Ranzato, Rajat Monga, Matthieu Devin, Kai Chen, Greg S. Corrado, Jeff Dean, Andrew Y. Ng · Google / 斯坦福大学待核对
arXiv ↗Google官方博客（2012-06-26） ↗在交互版中打开（演化树、学习进度）

问题

无监督学习只能学到边缘、角点这类低层特征；要得到“人脸”这样的高层概念检测器，大家都认为必须有标注数据，而当时的网络也只有几百万个连接。

方法

在1000台机器、16000个CPU核心上，用1000万张YouTube截图训练一个10亿连接的9层稀疏自编码器，三天后网络里自己出现了对人脸、猫脸和人体有选择性反应的神经元。

影响

证明了把模型和数据放大，无监督学习也能得到高层概念，“猫脸神经元”让深度学习进入大众视野；同时它也显示出CPU集群的代价太高，促使后来改用GPU集群。

背景

2006年以后，深度自编码器和稀疏编码等无监督方法可以从图像里学到像视觉皮层V1简单细胞那样的边缘检测器，但这些模型都很浅、很小，只能学到低层特征。此前用卷积深度信念网络学出人脸检测器的工作，训练图是对齐过的单类图像，相当于暗中提供了监督。

当时多数网络只有100万到1000万个连接，处理的多是32×32的小图。GPU训练深度网络已证明更大的模型需要更多算力，吴恩达所在的Google Brain成立项目则想利用谷歌的数据中心，看看把规模再放大100倍会发生什么。

方法

数据：从1000万个YouTube视频中各取一帧，得到1000万张200×200的彩色图，不带任何标签。

模型：一个9层的稀疏深度自编码器，由同一种三层结构重复三次组成：局部感受野（每个特征只连接下一层的一小块区域）、L2池化（对相邻特征取平方和再开方，获得对小形变的不变性）、局部对比度归一化。与卷积网络不同，这里的局部连接不共享权重，每个位置有自己的参数，所以总共约10亿个连接。训练目标是让网络能从压缩后的表示重建输入，同时让表示尽量稀疏。

训练系统：模型并行与数据并行结合。一个模型副本被切开放到169台机器上（每台16个CPU核心），多个副本各自读不同数据，通过参数服务器做异步随机梯度下降，总共用1000台机器、16000个核心训练三天。管理这些通信的软件框架叫DistBelief（见DistBelief与Downpour SGD）。

结果

测试集有37000张图，其中13026张是来自LFW人脸库的人脸，其余是从ImageNet随机抽取的干扰图。网络中最好的一个神经元识别人脸的准确率为81.7%，而全部猜“不是人脸”也有64.8%；单层网络最好的神经元只有71%。同样方法找到的猫脸神经元准确率74.8%，人体神经元76.7%。这个人脸检测器对平移、缩放和平面外旋转都较稳健。

用学到的特征再做有监督训练，在约2万类的ImageNet上达到15.8%的准确率（正文为2.2万类），比此前最好的9.3%相对提高70%。

后来的发展

谷歌在2012年6月26日发布官方博客介绍这项工作，“猫脸神经元”随后被媒体广泛报道。训练它的DistBelief系统后来发展为TensorFlow。

但三个月后，AlexNet在两块GPU上用有监督的卷积网络在ImageNet上取得大幅领先，无监督预训练这条路线很快让位于有监督训练。成本问题也很快被回答：2013年斯坦福的COTS HPC：GPU集群复现猫脸用3台GPU服务器在几天内训练了同样10亿参数规模的网络。“从无标注数据学高层特征”的目标后来由自监督学习（SimCLR、掩码自编码器MAE、DINOv2）重新实现。

    稀疏编码1996.06 · 基础
    论文明确受稀疏编码启发，用稀疏约束学习特征，但把浅层模型扩展成9层，从而学到高层概念而不只是边缘。
  • 延续
    深度自编码器2006 · 基础
    沿用深度自编码器“压缩再重建”的无监督目标，把规模从几百万参数放大到10亿连接、输入放大到200×200的图像。

读懂它需要的概念

自编码器 无监督学习 随机梯度下降与小批量 分布式训练：数据并行与模型并行 卷积层、池化与感受野 特征与表示学习

本篇术语

  • 局部感受野　每个神经元只看输入的一小块区域，而不是整张图，这样参数少、计算可以按区域分到不同机器上。
  • 模型并行　把一个模型的不同部分放到不同机器上，各自计算并交换边界上的数据；与之相对的数据并行是每台机器放完整模型、各算一部分数据。
  • 异步SGD　多个模型副本各自计算梯度并随时发给参数服务器，不等别人；速度快，但每个副本拿到的参数可能已经过时。

怎么学

先读自编码器和分布式训练：数据并行与模型并行。然后读原文第3节（架构与并行方式）、第4节（人脸神经元的测试方法）和表1、表2。动手：用PyTorch在MNIST或小图像集上训练一个稀疏自编码器，找出对某一类数字反应最强的隐藏单元，计算它当作分类器时的准确率，并与“全猜负类”的基线比较。
