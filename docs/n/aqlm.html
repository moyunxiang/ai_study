AQLM加性量化

Extreme Compression of Large Language Models via Additive Quantization
2024.01论文延伸ICML 2024Vage Egiazarian, Andrei Panferov, Denis Kuznedelev, Elias Frantar, Artem Babenko, Dan Alistarh · Yandex, 奥地利科学技术研究所等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

GPTQ、AWQ在4比特上已接近无损，但压到每参数2–3比特时，逐个标量四舍五入的量化误差急剧增大，模型质量大幅下降。

方法

借用信息检索里的加性量化：把一组权重（如8个）当作一个向量，用几个码本里各选一个码字相加来表示它，只存码字编号；码本按校准数据学习，并在每个Transformer块内联合优化。

影响

把2比特LLM量化的精度推到新的水平，与QuIP#一起代表“向量量化”路线，被Hugging Face Transformers和vLLM等支持，成为极低比特量化的常用基线。

方法

GPTQ训练后量化等方法属于标量量化：每个权重独立地映射到少数几个格点之一。比特数一低，格点太稀，误差就大。向量量化把若干个权重合成一个向量一起编码，可以更好地贴合权重的实际分布。

AQLM采用多码本的加性量化（AQ）：把每一行权重切成长度为g（如8）的小组，每组向量用M个码本中各选一个码字相加来近似，w ≈ C₁[i₁] + C₂[i₂] + … + C_M[i_M]，只需存储M个编号。例如g=8、一个16比特编号的码本，就相当于每个参数2比特。两点改进使它适合LLM：一是输入自适应——优化目标不是让权重本身接近，而是让该层在校准数据上的输出接近原来（与GPTQ训练后量化相同的层输出误差），用束搜索选码字、再更新码本；二是块内联合微调——量化完一个Transformer块后，把块内所有码本和缩放参数一起微调，让整块输出接近原模型。

摘要称：AQLM是压到每参数3比特以下时，首个在精度—模型大小上达到帕累托最优的方案，在2比特区间显著优于已知方法；同时提供GPU和CPU上的快速生成内核，速度可达到或超过优化过的FP16实现，而内存占用小得多。

局限与后续

  • 量化过程需要大量校准优化，比GPTQ慢得多；查码本解码的推理内核在大批量时难以达到标量量化的吞吐。
