Pre-LN Transformer

On Layer Normalization in the Transformer Architecture
2020.02论文重要ICML 2020Xiong, Yang, He, Zheng, Zheng, Xing, Zhang, Lan et al. · 微软研究院 / 北京大学 / 中科院计算所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

原版Transformer必须先用几千步把学习率从0慢慢升上去（warmup），否则训练直接失败；warmup步数还很敏感，调它费时费钱，没人说得清为什么非要它。

方法

用平均场理论分析初始化时的梯度：LayerNorm放在残差相加之后（Post-LN）时，靠近输出层的梯度很大；把LayerNorm挪进残差分支、放在子层之前（Pre-LN），梯度随层数缩小、处处平稳，于是可以去掉warmup。

影响

给“为什么要warmup”和“为什么Pre-LN好训”提供了第一个理论解释；Pre-LN此后成为GPT系列、LLaMA等几乎所有大语言模型的默认结构。

背景

原版Transformer的每个子层写成x_{l+1} = LN(x_l + F(x_l))：先把子层输出F与输入相加（残差连接，来自ResNet），再做Layer Normalization。这种写法叫Post-LN。

它有个麻烦：用Adam训练时，学习率必须从接近0开始，在几千步内线性升到峰值（warmup，见学习率与学习率调度），否则训练会发散。作者在IWSLT14德英翻译上复现：不用warmup，BLEU只有8.45；用4000步warmup可达约34；warmup只用500步、峰值学习率1e-3时只有2.77。warmup既拖慢训练，又多了一个敏感的超参数，在BERT这样昂贵的训练上尤其难调。

当时已有人提出把LayerNorm挪到前面（GPT-2、稀疏注意力等已采用），也有人认为warmup的作用是缓解Adam早期二阶矩估计方差过大，但都没有说清楚根本原因。

方法

两种写法。

Post-LN：x_{l+1} = LN(x_l + F(x_l))

Pre-LN：x_{l+1} = x_l + F(LN(x_l))，并在最后一层之后、输出之前再加一个LN。

区别在于：Pre-LN里，从输入到输出有一条完全不经过LN的“直通”残差路径，每层只是往上加一点东西；Post-LN里，每一层的输出都要被LN重新缩放一次。

理论分析。作者假设参数按高斯分布初始化，用平均场近似估计隐状态的范数，再推出最后一层前馈网络权重的梯度大小（定理1，d为隐藏维度，L为层数）：

  • Post-LN：‖∂L/∂W‖ ≤ O(d·√(ln d))，与层数无关，靠近输出的层梯度很大；
  • Pre-LN：‖∂L/∂W‖ ≤ O(d·√(ln d / L))，层数越多，梯度越小。

直观地说，Pre-LN中第l层的隐状态范数随l增长，经过LN时梯度会被这个范数除一下，越深的层分到的梯度越温和。Post-LN在初始化时输出端梯度过大，一上来就用大学习率，参数更新会过猛——warmup正是在绕开这一点。

推论。既然Pre-LN初始化时梯度本来就平稳，就应该可以不要warmup，直接用大学习率开训。

结果

在IWSLT14德英、WMT14英德翻译和BERT预训练上，Pre-LN去掉warmup后都能达到与带warmup的Post-LN相当的最终效果，而且收敛更快：IWSLT14上Pre-LN第9个检查点的效果约等于Post-LN的第15个。BERT预训练中，Post-LN在50万步时验证损失为1.69，Pre-LN（无warmup）更早达到同样水平，论文估算约40%的提速；在MRPC、RTE下游任务上同样更早达到相近的分数。作者还发现Post-LN用SGD时也离不开warmup，说明warmup的必要性不只来自Adam。

后来的发展

Pre-LN成为大模型的默认写法：GPT-3沿用了GPT-2的这一结构，LLaMA用的是Pre-LN配RMSNorm。今天的大语言模型基本都是“残差直通、归一化放在子层之前”。

但“完全不用warmup”并没有被普遍采纳——大模型训练至今仍会保留一段短warmup，因为规模上去后还有别的不稳定来源。另外，后续研究发现Pre-LN在很深时，靠后的层对输出的贡献越来越小，充分调好的Post-LN最终效果有时反而略好，围绕两者折中的改进一直在继续。

容易误解的地方

  • Pre-LN不是这篇论文发明的，GPT-2等已在使用；本文的贡献是解释它为什么好训，以及证明可以去掉warmup。
  • 理论只分析了初始化那一刻的梯度，不保证整个训练过程都稳定。

局限与后续

  • 理论只覆盖初始化时的梯度大小，训练中后期的不稳定（大模型常见的损失突刺）不在解释范围内，大规模训练实际上仍要保留warmup。

  • Pre-LN很深时隐状态范数不断累积，靠后的层贡献越来越小，充分调参的Post-LN最终效果有时更好，深度与最终质量的取舍没有解决。

它建立在什么之上

    解释并消除了原版Post-LN Transformer对学习率warmup的依赖。
  • 改进
    Layer Normalization2016.07 · 基础 已核对
    不改LayerNorm本身，研究它在残差结构中的位置如何决定梯度大小。
  • 使用
    Adam2014.12 · 基础
    主要实验用Adam；并说明warmup的必要性不只来自Adam，用SGD训练Post-LN同样离不开它。
  • 使用
    ResNet2015.12 · 视觉
    Pre-LN保留一条不被归一化打断的残差直通路径，与ResNet恒等映射的思路一致。
  • 使用
    BERT2018.10 · LLM
    以BERT预训练为最重要的验证场景，Pre-LN无warmup约提速40%。
  • 延续
    GPT-22019.02 · LLM
    GPT-2已把LN移到子层之前；本文从理论上说明这样做为什么更好训，并进一步去掉warmup。
  • 改进
    梯度裁剪2012.11 · 基础
    裁剪治标不治本：大模型训练中的损失尖峰往往源于数值和架构问题，仅靠裁剪挡不住。
  • 改进
    学习率预热与大批量SGD2017.06 · 基础
    warmup是经验技巧，为什么需要、需要多长没有理论解释，只能靠试。
  • 改进
    RMSNorm2019.10 · 基础
    只回答了怎么归一化，没回答放在哪里：放在残差之后的Post-LN结构在深层Transformer上仍依赖学习率预热、容易发散。
  • 改进
    深层Transformer与DLCL2019.06 · LLM
    实验只在机器翻译的编码器上加深，解码器仍为6层，对语言模型这类纯解码器结构没有验证。

读懂它需要的概念

归一化层 残差连接 Transformer层的结构 学习率与学习率调度 梯度消失与梯度爆炸 自适应学习率优化器

本篇术语

  • Post-LN / Pre-LN　LayerNorm放在残差相加之后（原版Transformer）还是放在每个子层的输入端（残差分支内部）。
  • 平均场理论　把网络宽度看作很大，用随机初始化下各量的期望和集中性来近似分析信号与梯度大小的方法。
  • warmup　训练开头若干步把学习率从接近0线性升到峰值，避免一开始更新过猛。

怎么学

先懂残差连接、归一化层和学习率与学习率调度调度。读原文第3节（warmup实验，图2）和第4节开头的图1与定理1的结论，证明细节可以先跳过。动手：在nanoGPT里把LN挪到残差相加之后改成Post-LN，分别在有无warmup、两种学习率下各训练几百步，对比损失曲线和各层梯度范数。
