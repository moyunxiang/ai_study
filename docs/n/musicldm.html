MusicLDM节拍同步增强

MusicLDM: Enhancing Novelty in Text-to-Music Generation Using Beat-Synchronous Mixup Strategies
2023.08论文延伸ICASSP 2024Ke Chen, Yusong Wu, Haohe Liu, Marianna Nezhurina, Taylor Berg-Kirkpatrick, Shlomo Dubnov · 加州大学圣地亚哥分校、蒙特利尔大学、萨里大学、LAION待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

扩散模型能做文生图、文生音频，但音乐有特殊的难处：可用的音乐数据少，生成结果又容易贴近训练曲目，带来版权和抄袭风险。

方法

把Stable Diffusion和AudioLDM的结构迁移到音乐，在音乐数据上重新训练CLAP和HiFi-GAN；再借助节拍跟踪做两种「节拍同步mixup」数据增强，让模型在训练曲目之间插值，生成更新颖的音乐。

影响

给出了一个开源的潜空间扩散文生音乐基线，并把「生成结果离训练数据有多近」作为文生音乐的评测问题提了出来，设计了基于CLAP分数的新指标。

方法

AudioLDM在潜空间扩散LDM的框架上做文生音频：用CLAP音频-文本对比把文本和音频映射到同一空间作条件，在VAE的潜空间里做扩散，再用HiFi-GAN把梅尔谱变回波形。MusicLDM先把这一套搬到音乐领域：用音乐数据重新训练CLAP和HiFi-GAN。

关键的新东西是节拍同步mixup。普通的Mixup把两个训练样本按比例线性混合；但两段节奏不一致的音乐混在一起会变成噪声。作者先用节拍跟踪模型估计每段音乐的速度和小节位置，只挑速度相近的样本、对齐节拍后再混：

  • 节拍同步音频mixup：直接在波形上把对齐后的两段音乐混合。
  • 节拍同步潜空间mixup：在VAE潜空间里对两段的latent做插值。

这样模型学到的是训练数据「凸包」内部的新组合，而不是记住某一首。作者还设计了几种基于CLAP分数的指标，衡量生成音乐与训练集的相似度。摘要报告：MusicLDM和节拍同步mixup同时提高了生成音乐的质量、新颖性和文本-音乐对应程度。

本篇术语

  • 节拍跟踪　自动估计一段音乐的速度（每分钟多少拍）和每一拍、每一小节出现的时间点。
  • 凸包　一组点所有加权平均能到达的区域；在训练样本之间插值得到的新样本都落在这个区域内。
