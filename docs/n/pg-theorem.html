策略梯度定理

Policy Gradient Methods for Reinforcement Learning with Function Approximation
1999论文主干NIPS 1999Richard S. Sutton, David McAllester, Satinder Singh, Yishay Mansour · AT&T实验室来源已核对
NeurIPS论文 ↗Sutton & Barto教材第13章 ↗Lilian Weng：Policy Gradient Algorithms ↗在交互版中打开（演化树、学习进度）

问题

一用函数近似，Q学习、Sarsa、动态规划都被构造出不收敛的例子：价值上一点微小变化就会让贪心策略突然换动作。REINFORCE虽有无偏梯度但慢得难以使用，actor-critic快却没有任何理论保证。

方法

证明期望回报对策略参数的梯度可以写成Σ_s d^π(s) Σ_a ∇π(a|s) Q^π(s,a)，其中不含“策略变化如何改变状态分布”这一项，因此能直接从采样中估计；再证明用满足“相容”条件的近似价值函数代替Q，梯度依然精确，进而证明一种actor-critic式策略迭代收敛到局部最优。

影响

给策略梯度和actor-critic打下了理论地基：优势函数A = Q − V作为评论家目标、任意状态基线不改变梯度，这两条之后被TRPO、PPO、A3C和GAE等方法普遍采用；用RL训练大语言模型时估计的也是同一个梯度。

背景

1990年代中期，强化学习要处理大问题就必须用函数近似（神经网络、线性特征），而主流做法是只近似价值函数，再取贪心策略。问题随之暴露：Baird反例与发散问题和Gordon、Tsitsiklis–Van Roy等人构造了简单的MDP和简单的近似器，使Q-learning、SARSA和动态规划都无法收敛到任何策略。根源之一是贪心策略不连续——某个动作的估值高出一点点，策略就整个切换过去。

另一条路是直接参数化策略、沿期望回报的梯度走。REINFORCE策略梯度证明了用实际回报就能得到无偏梯度，但方差大、学得极慢；Actor-Critic（ASE/ACE）用学到的价值来降低方差，实践上快得多，可没人能证明它在函数近似下是对的——用一个有误差的评论家，梯度还准吗？

方法

设策略为π(a|s; θ)，目标ρ(θ)是从起点出发的期望折扣回报（或长期平均奖励）。

定理1（策略梯度定理）（见策略梯度）：

∂ρ/∂θ = Σ_s d^π(s) Σ_a ∂π(a|s)/∂θ · Q^π(s,a)

d^π(s)是按策略π访问各状态的（折扣）频率。关键在于式中没有∂d^π/∂θ：改变策略会改变访问哪些状态，但这一影响不需要计算。所以只要按π采样状态，Σ_a ∇π·Q就是梯度的无偏估计。把Q换成实际回报R_t，就得到REINFORCE。

定理2（带函数近似的策略梯度）：用f_w(s,a)近似Q^π，若（a）f_w已经按均方误差训练到局部最优，（b）满足相容条件∂f_w/∂w = ∂π/∂θ · 1/π，则把定理1里的Q^π换成f_w，梯度完全不变。直观上，评论家的误差恰好与策略的梯度方向正交，不会把梯度带偏。

优势与基线：对线性-softmax策略，相容的f_w在每个状态里均值为0，所以它近似的其实是优势函数A^π(s,a) = Q^π(s,a) − V^π(s)（见Actor-Critic与优势函数）。更一般地，往f_w里加任意只依赖状态的v(s)都不改变梯度，因为Σ_a ∂π/∂θ = 0——这就是REINFORCE策略梯度里基线的严格版本，只影响方差。

一个小例子：某状态有左右两个动作，softmax策略当前各0.5，Q(左) = 1，Q(右) = 3。对左动作logit的偏导：∂π左/∂θ左 = 0.25，∂π右/∂θ左 = −0.25，梯度分量为0.25×1 − 0.25×3 = −0.5；对右动作logit为+0.5，于是右动作概率上升。若减去基线v = 2，算得0.25×(−1) − 0.25×1 = −0.5，结果相同，但每个样本的数值变小了，方差随之下降。

定理3：评论家满足相容条件并每轮拟合到位、策略按上式更新、步长满足α_k → 0且Σα_k = ∞，则∂ρ/∂θ → 0，即这种带函数近似的策略迭代收敛到局部最优。证明借用《Neuro-Dynamic Programming》中随机梯度法的收敛命题。

结果

这是一篇纯理论论文，没有实验。作者指出Konda与Tsitsiklis独立得到了非常相似的结果；平均奖励情形下的梯度表达式Marbach与Tsitsiklis（1998）已讨论过，本文推广到起始状态情形并给出更简短的证明。

后来的发展

这条定理把策略梯度从“一个能用的技巧”变成可以推导新算法的框架。自然策略梯度指出普通梯度依赖参数化方式，改用自然梯度；保守策略迭代CPI和TRPO进一步约束每步策略变化；PPO把它简化成可大规模使用的剪切目标。另一个方向，确定性策略梯度DPG推出了确定性策略的梯度定理，导向DDPG和TD3；A3C、广义优势估计GAE把“评论家估计优势、行动者沿梯度走”做成了深度RL中常用的形式。InstructGPT与RLHF的RLHF和GRPO训练推理模型，仍是在估计同一个梯度，只是基线的取法不同。

容易误解的地方

  • 定理1的梯度是精确的，但“精确”指期望；单个样本的估计方差可能极大，这正是基线和评论家的用处。
  • 相容条件非常苛刻（评论家须在策略的特征上线性）；今天的深度actor-critic基本都不满足它，因此不享有定理3的收敛保证。
  • 评论家学的是优势（各动作的相对好坏），而不是Q的绝对值。

它建立在什么之上

  • 改进
    Actor-Critic（ASE/ACE）1983 · RL 已核对
    actor-critic此前没有函数近似下的理论；论文指出其结果提示了证明这类方法收敛的途径，并作为第一步证明：相容条件下评论家不带偏梯度，一种带函数近似的策略迭代收敛到局部最优。
  • 延续
    REINFORCE策略梯度1992 · RL 已核对
    把REINFORCE的似然比梯度推广到多步MDP的一般形式，并说明用回报代替Q时就退化为REINFORCE。
  • 竞争
    Q-learning1992 · RL 已核对
    价值方法用贪心策略，天然确定且不连续；策略梯度直接学随机策略，参数的小变化只引起策略和状态分布的小变化。
  • 改进
    Baird反例与发散问题1995 · RL 已核对
    价值函数方法在函数近似下可能发散或振荡；直接对策略做梯度上升，参数小变化只引起策略小变化，绕开了这一问题。
  • 使用
    《Neuro-Dynamic Programming》1996 · RL 已核对
    定理3的收敛证明直接调用Bertsekas–Tsitsiklis书中关于随机梯度法的命题3.5。

读懂它需要的概念

马尔可夫决策过程 策略与价值函数 策略梯度 Actor-Critic与优势函数 Softmax与logits 期望与方差 导数、偏导与梯度

本篇术语

  • 状态访问分布d^π　按策略π一直行动时，各状态被访问的长期频率（折扣情形下按γ的幂加权）。策略梯度定理的期望就是在这个分布下取的。
  • 相容函数近似　评论家的梯度等于策略对数概率的梯度：∇_w f_w = ∇_θ ln π。满足它时，用评论家代替真实Q不会让策略梯度产生偏差。
  • 优势函数　A(s,a) = Q(s,a) − V(s)：在状态s选a比按策略平均水平好多少。只表达动作间的相对好坏。

怎么学

先确认会Softmax与logits的求导、策略梯度和REINFORCE策略梯度。读原文第1节（定理1）和第3节（优势与基线），附录证明值得逐行推一遍；再读Sutton & Barto教材13.2–13.5节。动手：在CartPole上依次实现REINFORCE、带价值基线的REINFORCE、单步actor-critic，比较三者回报曲线的方差和学习速度。
