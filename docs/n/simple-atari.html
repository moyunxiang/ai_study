SimPLe与Atari 100k

Model-Based Reinforcement Learning for Atari
2019.03论文延伸ICLR 2020Kaiser, Babaeizadeh, Milos, Osinski, Campbell, Czechowski, Erhan, Finn, Kozakowski, Levine et al. · Google Brain, UC Berkeley 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

无模型RL玩Atari要几千万帧，远多于人类；基于模型的方法在像素观测下一直没打败它们。

方法

学一个视频预测模型当模拟器，策略主要在模型想象出的轨迹里训练（SimPLe），每轮只用少量真实交互更新模型。

影响

定义了Atari 100k（10万步交互，约两小时真实游戏）这一样本效率评测，后来被BBF、EfficientZero等沿用。

方法

循环是：智能体与真实环境交互少量步，用这些数据训练视频预测模型（预测下一帧和奖励），再让策略在模型里展开想象轨迹，用PPO训练；然后回到真实环境收集新数据，重复。论文比较了多种模型结构，提出了一种效果最好的新结构。

评测限定为10万次智能体与环境的交互（对应两小时实时游戏）。摘要称在大多数游戏里，SimPLe在这个低数据设定下优于当时最强的无模型方法，在部分游戏中领先超过一个数量级。

局限与后续

  • 视频预测误差会在想象轨迹里累积，在需要精细像素细节的游戏里失败。
    后来针对它的工作　Dreamer EfficientZero
  • 渐近性能不如无模型方法，只在少数据时占优。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    DQN2013.12 · RL 已核对
    需要1000万帧（约46小时实时游戏）才学会一款游戏，远比人类慢；ε-贪心在奖励稀疏的游戏里几乎找不到奖励。
  • 延续
    World Models2018.03 · 具身·世界模型 已核对
    沿用在学到的模型里训练策略的思路，但改为迭代采集数据并在Atari上规模化。
  • 使用
    PPO2017.07 · RL
    策略在想象轨迹里用PPO训练。
  • 改进
    DQN（Nature版）2015.02 · RL
    每款游戏要5000万帧（约38天游戏时间），且每款单独训练，数据效率和跨游戏迁移都很差。
  • 改进
    Rainbow2017.10 · RL
    每款游戏训练2亿帧、在单GPU上约10天，样本效率和计算成本都很高。

后来的相关工作

  • 竞争
    MuZero2019.11 · RL 已核对
    同为Atari上的基于模型方法：SimPLe预测像素画面、面向10万步的小数据设置，MuZero只学价值等价的隐状态模型、用大得多的数据；论文称MuZero在所有游戏上都超过SimPLe，但两者数据量不在一个量级。
  • 改进
    Dreamer2019.12 · 具身·世界模型
    视频预测误差会在想象轨迹里累积，在需要精细像素细节的游戏里失败。
  • 改进
    EfficientZero2021.10 · RL
    在SimPLe提出的Atari 100k基准上，首次把平均成绩推到人类之上。
  • 使用
    SPR自预测表示2020.07 · RL
    评测采用SimPLe提出的Atari 100k设定。
  • 竞争
    IRIS2022.09 · 具身·世界模型
    同样追求Atari 100k的样本效率，SimPLe用视频预测模型，IRIS用离散令牌加Transformer，得分更高。
