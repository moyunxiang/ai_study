DARPA共同评测范式

1987事件延伸DARPA（美国国防高级研究计划局）、NIST及各参评实验室待核对
NIST语音评测归档 ↗在交互版中打开（演化树、学习进度）

问题

各实验室用自己的数据和指标，宣称的准确率无法互相比较，也难以判断某个方法是否真的更好。

方法

由资助方统一发布训练集和测试集，各队同时提交结果，由第三方按固定指标打分，然后公开比较、交流方法。

影响

它让「共享数据加统一打分」成为语音和语言技术的研究范式，今天的基准榜单都继承自这套做法。

背景

1970年代的ARPA语音理解计划各系统使用不同任务，结果无法横向比较。1980年代中后期，DARPA重启语音识别计划，吸取这一教训。

方法

评测的做法是：官方发布一套标准语料（如1000词左右的Resource Management任务），划定训练与测试划分；参评单位在规定期限内对未公开的测试集解码并提交；NIST按统一的词错误率（见词错误率）打分，之后开会公布并讨论各队做法。此后任务逐年升级：从受控朗读到华尔街日报新闻朗读，再到Switchboard电话语料的电话对话。统一的数据也让HMM统计语音识别路线中的各种改进（语言模型、区分性训练、说话人适应）能被量化地比较，进展因此变快。

后来的发展

这套评测文化被NIST、后来的语音和NLP评测（如TREC、MT评测）以及ImageNet式的竞赛广泛继承，是现代基准、排行榜与SOTA驱动研究的起点。

局限与后续

  • 一个固定测试集被反复使用，容易让方法针对它过度调参，成绩未必能推广到别的数据。

它建立在什么之上

  • 改进
    ARPA IPTO与Licklider1962.10 · 事件
    经费依赖少数项目经理的个人眼光、缺少明确的任务指标，一旦国会要求军事相关性，基础AI研究就首当其冲被削减。
  • 改进
    ARPA语音理解计划1971 · 语音
    延续ARPA对语音技术的资助，但改为统一语料和统一打分的可比较评测。
  • 改进
    第一次AI寒冬1973 · 事件
    领域缺乏公认的评测基准，资助方只能凭演示和承诺判断进展，导致承诺不断加码。
  • 使用
    HMM统计语音识别1976 · 语音
    评测的参赛系统几乎都基于HMM统计路线，评测使其改进可被量化。
  • 改进
    第二次AI寒冬1987 · 事件
    领域缺少统一的评测基准，资助方和企业无法客观判断进展，只能凭演示和承诺决策。
  • 改进
    Baker的DRAGON系统1975.02 · 语音
    统一网络里的各部分概率都要靠数据估计，缺少大规模标注语料时难以训练。
  • 改进
    Hearsay-II黑板架构1980.06 · 语音
    知识源与调度策略全靠人工设计，难以扩展，换一个任务要大量重写。

后来的相关工作

  • 延续
    DARPA共同任务框架1987 · 数据·评测
    两者描述同一段历史：darpa-eval侧重语音评测的流程，本节点侧重它作为一种跨领域研究方法论的推广。
  • 使用
    CMU SPHINX1988 · 语音
    以DARPA发布的约1000词资源管理任务为测试平台，在统一测试集上报告词准确率。
  • 使用
    HTK工具包1989 · 语音
    以ARPA华尔街日报评测为主战场，在统一测试集上与各实验室比较。
  • 使用
    TIMIT语音语料1990 · 数据·评测
    TIMIT由NIST校验和发行，纳入DARPA语音评测体系，测试划分固定、结果可以横向比较。
  • 使用
    Switchboard电话语料1992.03 · 数据·评测
    测试集由NIST保管，用统一的词错误率在年度评测中比较各参赛系统。
  • 使用
    “每开除一个语言学家”1988 · 语音
    口号的底气来自统一评测中统计系统持续取得更低的错误率。
  • 改进
    对话语音识别达到人类水平2016.10 · 语音
    任务逐年更接近自然口语，但与真实使用环境（噪声、口音、远场）仍有距离。
