BEVFormer: Learning Bird's-Eye-View Representation from Multi-Camera Images via Spatiotemporal Transformers
2022.03论文重要ECCV 2022Zhiqi Li, Wenhai Wang, Hongyang Li, Enze Xie, Chonghao Sima, Tong Lu, Qiao Yu, Jifeng Dai · 南京大学 / 上海人工智能实验室 / 香港大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

纯视觉的3D检测要么逐相机检测再拼接，要么像Lift-Splat那样先估深度再投影，深度估不准就全盘出错；单帧方法还测不准车速，被遮挡的物体也容易丢。

方法

在俯视图上铺一张200×200的可学习查询网格，每个查询按自己的三维位置投影到各相机图像里，用可变形注意力取特征；再用另一层注意力读取上一时刻的BEV特征，融合时间信息。

影响

nuScenes测试集NDS达到56.9%，比之前最好的纯视觉方法高9分、接近激光雷达方法；把Tesla在发布会上展示的“查询式BEV+时序”做成了公开方法，成为纯视觉BEV感知的代表性基线。

背景

Lift-Splat-Shoot给出了一种把多相机图像变成鸟瞰图（BEV）的方法：先给每个像素预测深度分布，再把特征投到三维、压成俯视图。它的弱点是一切都建立在深度估计之上，而单目深度本来就很难估准。另一条路是DETR风格的检测：DETR3D用一组可学习的三维物体查询，投影到图像上取特征直接回归三维框，不需要深度，但只有稀疏的物体，没有能同时服务检测和地图分割的稠密BEV特征。

此外多数方法只看当前一帧，判断不了前车在加速还是刹车，也容易漏掉被挡住的行人。2021年Tesla HydraNet与BEV在发布会上展示了用注意力把多相机融合到俯视空间、并加入时序队列的思路，但没有公开细节。

方法

BEV查询。在自车周围±51.2米的范围内铺一张200×200的网格，每格约0.5米，每格放一个可学习的256维查询向量 Q_p，负责“这块地面上有什么”。编码器有6层，每层依次做两件事：

时间自注意力。保留上一时刻的BEV特征 B_{t−1}，先按自车的运动把它平移旋转对齐到当前坐标系（同一格对应同一块真实地面），再让当前查询通过注意力去读取它。这样历史信息一帧帧循环传下来，速度和被遮挡物体就有了线索。

空间交叉注意力。每个查询代表的是一根竖直的“柱子”：在这一格上预设若干个不同高度的三维参考点，用相机内外参把它们投影到各个相机图像上（见相机模型与多视图几何）。只有能看到这些点的相机才参与计算；在投影点附近，用Deformable DETR的可变形注意力只采样少数几个位置的特征并加权求和（见注意力机制）。这样不用显式估深度，也比全局注意力省算力。

任务头。得到的BEV特征 B_t 一方面接一个改造过的Deformable DETR检测头，直接输出三维框和速度、无需NMS；另一方面接分割头，输出车道、可行驶区域等地图元素。

结果

在nuScenes测试集上，纯视觉方法NDS达到56.9%，比此前最好的DETR3D（47.9%）高9.0分，与当时一些激光雷达方法相当；地图分割中最难的车道线比Lift-Splat高5分以上。加入时序后，速度估计更准，低可见度物体的召回率也提高。

后来的发展

BEVFormer与Lift-Splat-Shoot一起成为纯视觉BEV感知的两大基线。它的BEV特征直接被UniAD端到端规划用作端到端驾驶系统的底座，把检测、跟踪、建图、预测和规划串在一起。BEV之后，业界又把俯视平面扩展为三维占用栅格（Tesla占用网络、OccWorld占用世界模型）。

读懂它需要的概念

注意力机制 自注意力与多头注意力 相机模型与多视图几何 分类、检测、分割 IoU与mAP

本篇术语

  • NDS（nuScenes检测分数）　nuScenes的综合指标，由平均精度mAP与位置、尺寸、朝向、速度、属性五项误差加权合成，取值0–1，越高越好。
  • 可变形注意力　不让每个查询和所有位置计算注意力，而是在一个参考点周围学出少数几个采样偏移，只在这些点上取特征加权求和。
  • 自车运动对齐　车在移动，上一帧的俯视图要按自车的平移和旋转变换到当前坐标系，才能和当前帧逐格对应。

怎么学

先读DETR和Lift-Splat-Shoot → 读原文第3节（BEV查询、空间交叉注意力、时间自注意力）和图2 → 动手：用开源代码在nuScenes mini上推理，把BEV特征和检测框可视化，观察去掉时间注意力后速度误差的变化。
