随机先验函数

Randomized Prior Functions for Deep Reinforcement Learning
2018.06论文延伸NeurIPS 2018Ian Osband, John Aslanides, Albin Cassirer · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用网络集成估计不确定性来探索时，自助采样（bootstrap）只能反映“已观测数据”带来的不确定性；在完全没有数据的区域，各成员可能给出一样的值，探索失去动力。

方法

给集成里每个成员加一个随机初始化、永不训练的“先验网络”，成员的输出是 Q_k = f_θk + β·p_k。只训练 f_θk 去拟合数据，于是在有数据处各成员趋于一致，在没数据处保留各自先验带来的分歧。

影响

成为深度RL里实现“近似后验采样”最常用的做法之一，后来不少集成探索、不确定性估计和离线RL方法都沿用了随机先验网络。

背景

RLSVI随机化价值函数表明，从价值函数的后验里采样再贪心行动，可以实现有方向的深度探索；Bootstrapped DQN用多头网络和数据重采样在深度网络上近似这种后验。但作者指出，bootstrap只对数据做扰动：如果某个区域从没被访问，所有成员在那里的输出只取决于初始化和泛化，并不能可靠地表达“我不知道”。贝叶斯推断里，这部分不确定性来自先验，而普通集成没有显式的先验。

方法

维护K个成员。第k个成员的Q函数是

Q_k(s,a) = f(s,a; θ_k) + β · p_k(s,a)

其中 p_k 是随机初始化后冻结的网络，β控制先验的尺度。训练时只更新 θ_k，损失是普通的TD误差（可配合bootstrap掩码）：(Q_k(s,a) − r − γ max_a′ Q_k^target(s′,a′))²。每个回合随机挑一个成员，整回合按它贪心行动，这就是对后验的近似Thompson采样。

作者证明，在线性高斯模型下，“对先验样本加上扰动数据后求最小二乘解”恰好得到精确的后验样本，这给加法先验提供了理论依据。直观地说：在数据充分的地方，f_θk 会学会抵消 p_k 的差异；在没有数据的地方，各成员的差异原样保留，驱使智能体去那里看一看。

结果

摘要称，作者证明了这一方法在线性表示下是高效的，用非线性表示的简单例子说明了它的作用，并表明它比以前的尝试更好地扩展到大规模问题。原文实验包括需要长程探索的“深海”（Deep Sea）类问题，β取0时的纯bootstrap集成明显失败。

后来的发展

随机先验网络很快被吸收进集成方法的标准配方：后来的集成Q学习、离线RL里的集成悲观估计、基于集成的不确定性奖励等都常带上它。它也与随机网络蒸馏RND有亲缘：两者都用一个冻结的随机网络作为“参照”，RND用预测误差当新颖度，随机先验用它当先验差异。

读懂它需要的概念

探索与利用 集成学习 先验、后验与贝叶斯推断 时序差分与自举 高斯分布

本篇术语

  • 先验网络（prior network）　随机初始化后不再训练的网络，加在可训练网络的输出上，代表“看到数据之前”的信念。
  • 认知不确定性　因为数据不足而产生的不确定性，多收集数据就能减少；探索要找的正是这种不确定性。

怎么学

先理解Bootstrapped DQN的多头集成；读原文第2节关于bootstrap缺少先验的反例和第3节线性高斯情形的证明；在一维回归上画出带先验与不带先验的集成在无数据区域的分歧，再在长链环境上比较探索效果。
