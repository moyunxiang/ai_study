LOAM激光里程计与建图

LOAM: Lidar Odometry and Mapping in Real-time
2014.07论文延伸RSS 2014Ji Zhang, Sanjiv Singh · 卡内基梅隆大学机器人研究所待核对
RSS 2014 ↗在交互版中打开（演化树、学习进度）

问题

激光雷达边运动边扫描，一帧点云里的点是在不同时刻、不同位置测到的，会产生运动畸变；同时要做高频定位和精确建图，计算量难以兼顾。

方法

把问题拆成两个以不同频率运行的算法：高频的里程计只用少量特征点粗略估计运动并校正畸变，低频的建图再把点云精细地配准到全局地图上。

影响

成为三维激光SLAM最有影响的框架之一，长期位居KITTI里程计榜前列，LeGO-LOAM、LIO-SAM等大量后续激光（惯性）SLAM系统都在它的基础上发展。

方法

SLAM（同时定位与建图）在SLAM的概率框架和FastSLAM时代多用二维激光或稀疏路标。三维多线激光雷达普及后，一个难点是：雷达在机器人移动中逐线扫描，一帧点云跨越约0.1秒，期间机器人已经移动，直接把它当作“同一时刻的快照”去配准会产生畸变和累积误差；而对每帧几万个点做精细配准又太慢。

LOAM的做法有两个要点。特征提取：按每个点与邻近点的局部曲率，把点分成“边缘点”（曲率大，如墙角、柱子）和“平面点”（曲率小，如墙面、地面），只保留少量最显著的特征点。两级估计：里程计以约10Hz运行，把当前帧的边缘点匹配到上一帧的边缘线、平面点匹配到上一帧的平面上，最小化点到线、点到面的距离，求出运动并据此校正这一帧的畸变；建图以约1Hz运行，把校正后的点云与累积的全局地图做更精细的匹配，修正里程计的漂移。两者的输出合起来，同时得到高频的位姿和高精度的地图。

LOAM不依赖惯性测量单元或GPS也能达到很低的漂移，在KITTI等室外数据集上取得了很高的精度，其后来的期刊版本和开源实现被广泛采用。

局限与后续

  • 没有回环检测，长距离运行后漂移只能靠局部建图修正，无法全局一致地消除。
    后来针对它的工作　Cartographer实时回环激光SLAM
  • 在长走廊、空旷场地等几何特征退化的场景中容易失效，也没有与惯性测量紧耦合。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    SLAM的概率框架1986 · 具身·世界模型
    在SLAM框架下用三维激光点云做实时里程计与建图。
  • 延续
    DARPA城市挑战赛2007.11 · 具身·世界模型
    城市挑战赛让多线激光雷达在无人车上普及，LOAM处理的正是这类三维激光数据。
  • 竞争
    PTAM2007.11 · 视觉
    PTAM在视觉SLAM中把跟踪和建图分成两个线程；LOAM在激光SLAM中把高频里程计和低频建图分开，思路相近、传感器不同。

后来的相关工作

  • 改进
    Cartographer实时回环激光SLAM2016.05 · 具身·世界模型
    LOAM这类里程计式方法没有回环检测，Cartographer通过子图匹配与位姿图优化实时闭合回环。
  • 延续
    LIO-SAM激光惯性里程计2020.07 · 具身·世界模型

    FAST-LIO激光惯性滤波2020.10 · 具身·世界模型

读懂它需要的概念

相机模型与多视图几何 三维表示：体素、点云、网格、隐式场 梯度下降 随机变量与概率分布

本篇术语

  • 运动畸变　传感器在采集一帧数据的过程中自身在移动，导致同一帧里不同点的坐标系不一致。
  • 点云配准　求一个旋转加平移，让两帧点云（或点云与地图）尽可能重合，从而得出传感器的相对运动。

怎么学

先了解ICP点云配准，再读LOAM论文的特征提取与两级估计部分；开源的A-LOAM代码更易读，可在KITTI数据上运行。
