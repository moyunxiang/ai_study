PARAGRAM改写句向量

Towards Universal Paraphrastic Sentence Embeddings
2015.11论文延伸ICLR 2016John Wieting, Mohit Bansal, Kevin Gimpel, Karen Livescu · 芝加哥丰田技术研究所待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大家想要一种通用的句向量：意思相近的句子余弦相似度高，并且能迁移到各种领域；当时的趋势是用越来越复杂的组合模型（递归网络、LSTM），但它们在训练领域之外表现如何，没有系统比较。

方法

用释义数据库PPDB里三百多万对带噪声的同义短语作监督，以带间隔的铰链损失训练六种组合结构（从词向量平均到LSTM），让同义短语的向量更接近、和批内挑出的负例更远，然后在22个不同领域的语义相似度数据集上比较。

影响

在训练分布之外，最简单的词向量平均模型平均比最好的LSTM高16.5个皮尔逊相关点，比直接平均GloVe高17.1点；它说明「好的句向量来自好的词向量加简单组合」，直接引出了SIF等无监督加权平均方法，也让「平均词向量」成为句向量研究中必比的基线。

方法

训练数据与目标。PPDB的XL部分含3,033,753对互为改写的短语⟨x₁, x₂⟩。对每对，从当前小批量中挑出与x₁最相似但不是它改写的短语t₁作负例（MAX策略；MIX策略则一半用MAX一半随机），目标为max(0, δ − cos(g(x₁), g(x₂)) + cos(g(x₁), g(t₁))) + max(0, δ − cos(g(x₁), g(x₂)) + cos(g(x₂), g(t₂)))，再加上对组合参数的L2正则和把词向量拉回初始值的正则。g是句子编码函数，δ是间隔。

六种组合结构：①词向量平均（没有额外参数，只学词向量本身，即PARAGRAM-PHRASE）；②平均后接一层线性变换；③平均后接深层网络（类似DAN深度平均网络）；④普通RNN；⑤带恒等初始化的RNN；⑥LSTM。词向量从此前在PPDB上训练的PARAGRAM-SL999初始化，超参数（正则强度、间隔、优化器等）在两个人工打分的短语对数据集上调。

结果。在与训练数据同分布的测试上LSTM最好；但在2012–2015年SemEval语义相似度任务的22个数据集（新闻、论坛、图片与视频描述等）上，平均模型平均比最好的LSTM高16.5（皮尔逊r×100），比平均GloVe高17.1、比平均PARAGRAM-SL999高12.8，并且在其中4个数据集上与专门为该任务调过的系统并列或更好。在有监督的SICK相似度与蕴含任务上平均模型也优于LSTM，但在斯坦福情感树库上LSTM更强并创下新纪录。

局限与后续

  • 需要PPDB这样的大规模改写监督数据来重新训练词向量，换语言或领域时不一定有这样的资源。
    后来针对它的工作　SIF加权平均句向量
  • 平均模型忽略词序，在情感分类这类依赖组合与否定的任务上明显不如LSTM。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    GloVe2014.10 · NLP
    直接平均GloVe向量是基线，在22个相似度数据集上平均低17.1点。
  • 延续
    Retrofitting词向量改装2014.11 · NLP
    同样利用PPDB这类语义资源改进词向量，但目标是让平均后的句向量反映改写关系。
  • 竞争
    Tree-LSTM2015.02 · NLP
    LSTM类组合模型在训练分布内最好，但跨领域时远不如平均。
  • 竞争
    Skip-Thought句向量2015.06 · NLP
    Skip-Thought用大语料上的编码器-解码器学通用句向量；本文用改写监督加简单平均，在语义相似度上更好。
  • 延续
    DAN深度平均网络2015.07 · NLP
    深度平均网络是被比较的结构之一；本文进一步发现连深层网络都不加、只学词向量的平均在跨领域时最好。

后来的相关工作

  • 改进
    SIF加权平均句向量2017.04 · NLP
    Wieting等的平均模型要用PPDB改写数据重新训练词向量；SIF完全无监督，用现成词向量加权平均即可达到并改进其效果。

读懂它需要的概念

嵌入向量 损失函数 内积与余弦相似度 循环网络与隐状态 分布偏移 对比学习

本篇术语

  • PPDB　释义数据库，从双语平行语料中自动抽取的数以百万计的同义短语对，带噪声。
  • 铰链损失　要求正例的得分至少比负例高出一个间隔δ，否则按差距受罚；已满足时损失为0。
  • 域外泛化　模型在与训练数据来源、风格不同的数据上的表现。

怎么学

先读DAN深度平均网络和Skip-Thought句向量的讲解 → 读原文第3节模型与训练目标、第4节22个数据集的结果表 → 动手：下载PARAGRAM-PHRASE-XXL词向量，在STS基准上比较它的平均与GloVe平均的相关系数。
