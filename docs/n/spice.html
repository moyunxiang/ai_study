SPICE场景图描述指标

SPICE: Semantic Propositional Image Caption Evaluation
2016.07论文延伸ECCV 2016Peter Anderson, Basura Fernando, Mark Johnson, Stephen Gould · 澳大利亚国立大学 / 麦考瑞大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图像描述的自动指标（BLEU、METEOR、CIDEr）主要看n-gram重合，而n-gram重合既不是判断描述好坏的必要条件，也不是充分条件，系统级排名常与人类判断不一致。

方法

把候选描述和参考描述都解析成场景图（物体、属性、关系），再把场景图拆成一组语义命题，在命题层面算F值，得到指标SPICE。

影响

成为COCO图像描述评测里与CIDEr并列报告的标准指标，也开了“先解析语义结构再比较”的评测思路。

方法

背景。MS COCO图像描述任务里，模型生成一句话描述图片，再和人写的几句参考描述比较。BLEU、METEOR、CIDEr都基于n-gram：一句“一个年轻女孩站在网球场上”和参考句“一个打网球的女孩”词面重合很少，却可能都是好描述；反过来，两句话共享“站在……上”这类短语，意思却可能完全不同。2015年COCO挑战赛中，这些指标给出的排名与人类评审不一致。

做法。SPICE用依存句法分析把每句描述转成场景图：节点是物体（女孩、球场），附着属性（年轻），边是关系（站在……上）。场景图再拆成命题元组，例如（女孩）、（女孩，年轻）、（女孩，站在，球场）。候选描述和所有参考描述的命题集合做匹配（借助WordNet同义词），算精确率和召回率，取F1作为得分。

结果。摘要报告，在COCO上SPICE与人类判断的系统级相关系数为0.88，CIDEr为0.43，METEOR为0.53。因为分数可以按命题类型拆开，SPICE还能回答“哪个模型更懂颜色”“模型会不会数数”这类问题。

局限与后续

  • 完全依赖句法解析器把句子转成场景图，解析错误直接变成打分错误；它也不看句子是否通顺，语法很差的描述也可能高分。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    METEOR2005.06 · 数据·评测
    METEOR用同义词和词干放宽匹配，仍在词面层面；SPICE匹配的是解析出的物体、属性和关系。
  • 使用
    MS COCO2014.05 · 数据·评测
    在COCO图像描述的人工评审数据上验证与人类判断的相关性。
  • 改进
    CIDEr2014.11 · 数据·评测
    CIDEr等n-gram指标在COCO上的系统级排名与人类判断相关性只有0.43，SPICE改在语义命题层面比较，提高到0.88。
  • 竞争
    Visual Genome2016.02 · 数据·评测
    Visual Genome为图像人工标注场景图，SPICE则从描述文本自动解析出场景图，两者使用同一种物体—属性—关系表示。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

文本生成的自动指标 准确率、精确率、召回率与F1 图、树与搜索

本篇术语

  • 场景图　用图表示一个场景：节点是物体，节点上挂属性，边表示物体之间的关系，例如（女孩）—站在→（球场）。
  • 系统级相关性　先用指标和人类分别给每个系统打总分，再看两组总分的相关系数，衡量指标能否排对系统的先后。

怎么学

先了解CIDEr和BLEU怎么算；读SPICE原文中句子到场景图的例子图和COCO相关性表；动手用pycocoevalcap对同一张图的几句不同描述分别算CIDEr和SPICE，比较差异。
