CosFace余弦间隔

CosFace: Large Margin Cosine Loss for Deep Face Recognition
2018.01论文延伸CVPR 2018Hao Wang, Yitong Wang, Zheng Zhou, Xing Ji, Dihong Gong, Jingchao Zhou, Zhifeng Li, Wei Liu · 腾讯AI Lab待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人脸识别要求同一人的特征挤在一起、不同人的特征分得很开，普通softmax损失做不到；SphereFace角度间隔在角度上乘一个间隔（A-Softmax）有效，但乘性间隔让损失很难优化，需要各种技巧才能训练收敛。

方法

把特征和分类权重都做L2归一化，只保留夹角的余弦；然后在目标类的余弦上直接减去一个固定间隔m，要求“正确类的余弦减去m后仍然最大”，在角度空间里拉开决策边界。

影响

加性余弦间隔形式简单、训练稳定，与同期的ArcFace（加性角度间隔）一起成为人脸识别的标准损失，后来也被用于说话人识别、行人重识别等度量学习任务。

方法

softmax分类的logit是 W_j·x = ‖W_j‖‖x‖cos θ_j。CosFace先把权重归一化为单位长度、把特征归一化后放大到固定长度s，于是logit只取决于夹角：s·cos θ_j。这一步去掉了特征长度带来的变化，让判别完全发生在角度上。

然后对真实类别y减去间隔m：

L = −log( e^{s(cos θ_y − m)} / ( e^{s(cos θ_y − m)} + Σ_{j≠y} e^{s·cos θ_j} ) )

含义是：训练时要求正确类的余弦比其他类至少高m，测试时不再减m，于是不同类之间在余弦空间里留出一条宽度为m的“缓冲带”，类内更紧、类间更开。论文从几何上分析了s和m的取值范围（s需要足够大，类别越多需要越大）。

摘要称在MegaFace、YouTube Faces（YTF）和LFW这些最常用的公开人脸识别数据集上取得当时最好结果。

局限与后续

  • 间隔m对所有样本相同，对噪声标签、低质量人脸和长尾身份不够鲁棒。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 在余弦上加间隔，与角度不是线性关系，几何解释不如在角度上直接加间隔直观。

它建立在什么之上

  • 竞争
    FaceNet与三元组损失2015.03 · 视觉
    FaceNet用三元组损失直接学度量，需要难样本挖掘；CosFace用带间隔的分类损失，训练更简单、效果更好。
  • 改进
    SphereFace角度间隔2017.04 · 视觉
    SphereFace的乘性角度间隔难以优化；CosFace改为在余弦上加性地减去间隔，训练更稳定。
  • 竞争
    ArcFace2018.01 · 视觉
    同月发布：CosFace在余弦上减间隔，ArcFace在角度上加间隔，两者效果接近，ArcFace后来更常用。

读懂它需要的概念

Softmax与logits 交叉熵 范数与距离 嵌入向量

本篇术语

  • 加性余弦间隔　在正确类别的余弦相似度上减去一个常数m，迫使模型把正确类与其他类拉开至少m。

怎么学

先弄懂softmax分类与特征归一化，再读本文第3节的损失推导与s、m取值分析；在一个小人脸数据集上分别用softmax和CosFace训练，用t-SNE画出特征分布对比。
