BART

BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension
2019.10论文延伸ACL 2020Mike Lewis, Yinhan Liu, Naman Goyal, Marjan Ghazvininejad, Abdelrahman Mohamed, Omer Levy, Ves Stoyanov, Luke Zettlemoyer · Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BERT（只有编码器）和GPT-2（只有解码器）各擅长一半任务，而摘要、翻译、对话这类生成任务需要完整的编码器-解码器。

方法

用标准Transformer编码器-解码器做去噪自编码：先用各种方式破坏输入文本，再让解码器还原出原文。

影响

在摘要、对话和问答生成上取得当时最佳，「文本去噪式的编码器-解码器预训练」成为生成任务的常见起点。

方法

BART的结构就是原版的Transformer编码器-解码器：编码器双向读入被破坏的文本，解码器从左到右自回归地生成原文。它可以看成BERT的双向编码器加GPT的单向解码器的结合。

关键在于破坏文本的方式：可以遮单个词、删词、打乱句子顺序、旋转文档，或者把一整段文字替换成一个遮罩符号。作者比较后发现，把句子打乱顺序并且用「片段填充」（一段文字换成单个遮罩）的效果最好。

摘要称，BART在GLUE和SQuAD上与RoBERTa相当，并在摘要、对话、问答生成任务上取得新最佳，ROUGE最多提升6；用于机器翻译时，只对目标语言做预训练，相对反向翻译系统提升1.1 BLEU。

局限与后续

  • 需要整套编码器-解码器，参数量和推理成本比同等的纯解码器模型高。

  • 仍需要为每个任务做监督微调，不能靠提示零样本完成。
    后来针对它的工作　GPT-3

它建立在什么之上

  • 延续
    BERT2018.10 · LLM 已核对
    用同样的去噪思想，但扩展到编码器-解码器并允许多种破坏方式。
  • 改进
    RoBERTa2019.07 · LLM 已核对
    仍是只有编码器的结构，无法直接生成文本。
  • 使用
    GPT-22019.02 · LLM
    解码器部分是GPT式的从左到右自回归生成。
  • 改进
    指针-生成器摘要2017.04 · NLP
    模型过度依赖复制：35%的输出句子整句抄原文，生成新n-gram的比例远低于人写摘要，抽象程度有限。
  • 竞争
    MASS2019.05 · LLM
    MASS同期也做编码器-解码器的掩码预训练，但只遮一段；BART支持更多种破坏方式。
  • 改进
    SpanBERT2019.07 · LLM
    只改善编码器式理解任务，不能用于生成。
  • 改进
    BertSum预训练摘要2019.08 · NLP
    生成式模型的解码器没有预训练，需要专门的学习率技巧来平衡；编码器和解码器一起预训练的模型随后表现更好。
