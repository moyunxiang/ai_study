LongMemEval长期记忆

LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory
2024.10数据集延伸ICLR 2025Di Wu, Hongwei Wang, Wenhao Yu, Yuwei Zhang, Kai-Wei Chang, Dong Yu · 加州大学洛杉矶分校 / 腾讯AI Lab待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

聊天助手开始加入记忆功能来记录用户的历史对话，但它们在长期、持续的交互中到底能记住什么、会在哪里出错，缺少系统的测试。

方法

定义聊天助手长期记忆的五种核心能力，围绕它们精心编写500道题，并把题目嵌入长度可自由扩展的用户-助手聊天历史中。

影响

与LoCoMo一起成为长期记忆系统最常用的两个基准，Zep、Mem0等记忆产品和大量记忆架构论文都报告LongMemEval分数。

方法

五种能力。信息抽取（记住用户某次提到的细节）、跨会话推理（把多次会话的信息合起来）、时间推理（理解事情发生的先后和时间点）、知识更新（用户信息变了要用新的）、拒答（没聊过的事情要说不知道）。

数据。500道人工精心整理的问题，每道题的证据分散嵌入在一段用户与助手的聊天历史里，历史中还混有大量无关会话，长度可以自由扩展，例如标准设定约11.5万词元，更长的版本达到数百次会话。

发现。摘要称，商业聊天助手和长上下文模型在持续交互中记住信息的准确率下降约30%。作者提出一个统一框架，把长期记忆设计拆成索引、检索、读取三个阶段，并据此给出几项优化：按会话拆分记忆粒度、用抽取出的事实扩展索引键、按时间范围改写查询，实验表明这些改进显著提升了记忆召回和下游问答。

局限与后续

  • 聊天历史部分由模型合成，用户行为比真实使用简单；题目以英文为主，只覆盖单个用户与助手的记忆。
    本站还没有记录针对它的后续工作（不代表没有人解决）

    像大海捞针一样把证据藏在长历史里，但证据是自然对话，并要求跨会话推理和更新。

    LoCoMo超长对话记忆2024.02 · 数据·评测
    LoCoMo测两个虚拟人物之间的长对话记忆，LongMemEval专测用户与聊天助手之间的长期记忆，并细分五种能力。
