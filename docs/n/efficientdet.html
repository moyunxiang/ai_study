EfficientDet

EfficientDet: Scalable and Efficient Object Detection
2019.11论文延伸CVPR 2020Tan, Pang, Le · Google Research, Brain Team待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

检测器越做越大，不同工作各自堆参数，没有一套能随算力预算平滑缩放、又省算力的设计。

方法

提出加权双向特征金字塔BiFPN和把分辨率、深度、宽度（骨干、特征网络、预测头）一起放缩的复合缩放，得到D0到D7一族检测器。

影响

把EfficientNet的缩放思想带进检测，给出效率最好的一族单阶段检测器，BiFPN被后续工作广泛借用。

方法

特征金字塔FPN用自顶向下的路径融合多尺度特征，但各层同权相加。EfficientDet的BiFPN有两处改动：加入自底向上的路径形成双向融合，并给每条输入边一个可学习的权重，让网络自己决定哪个尺度更重要。第二个点是复合缩放，沿用EfficientNet的思路，用一个系数同时放大骨干、BiFPN、预测头和输入分辨率，而不是只放大其中一个。检测头沿用Focal Loss与RetinaNet式的单阶段密集预测。

论文报告最大的EfficientDet-D7单模型单尺度在COCO test-dev上55.1 AP，77M参数、410B FLOPs，比此前检测器小4到9倍、FLOPs少13到42倍（摘要）。

后来的发展

BiFPN成为许多检测器的可选颈部，复合缩放思想影响了后续YOLOv4类检测器的族化设计，但后来的主流转向Transformer检测器。
