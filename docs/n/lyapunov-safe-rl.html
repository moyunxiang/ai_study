李雅普诺夫安全RL

A Lyapunov-based Approach to Safe Reinforcement Learning
2018.05论文延伸NeurIPS 2018Yinlam Chow, Ofir Nachum, Edgar Duenez-Guzman, Mohammad Ghavamzadeh · DeepMind / Google Brain / Facebook AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

拉格朗日法只在收敛后满足约束，训练中会反复违规；而机器人这类系统在训练期间也不能做出不可挽回的危险动作。

方法

借用控制论里的李雅普诺夫函数：构造一个函数，使得只要每一步的策略都满足一组关于它的局部线性约束，整条轨迹的累计代价就一定不超过阈值；再把动态规划和RL算法改造成在这组约束下更新。

影响

把李雅普诺夫稳定性思想系统地引入CMDP，是“训练全程安全”路线的代表，后来的李雅普诺夫策略梯度和基于控制屏障函数的安全RL都沿用这一思路。

方法

在约束MDP（CMDP）里，约束是全局的：E[Σ γ^t c_t] ≤ d。全局约束难以在每一步更新时直接检查。论文定义了一类李雅普诺夫函数 L(s)：它在初始状态的值不超过阈值d，并且对某个已知满足约束的基准策略 π_B 满足 T_(π_B, c)[L](s) ≤ L(s)，其中 T_(π, c)[L](s) = Σ_a π(a|s)[c(s, a) + γ Σ_s′ P(s′|s, a) L(s′)] 是代价的贝尔曼算子。

关键结论：任何满足同样局部不等式 T_(π, c)[L](s) ≤ L(s)（对每个状态）的策略π，其累计代价都不超过d。这样一个全局约束就变成了每个状态上关于π的线性约束。作者还给出了一种构造L的方法：在基准策略的代价价值上加一个辅助项，尽量放宽可行策略集合。

据此，可以把策略迭代、值迭代改造成“安全版本”：每一步改进时在满足李雅普诺夫约束的策略集合里找最好的（一个小线性规划）。深度RL里，论文给出了安全的DQN与DPI变体，把这组约束用于动作选择。摘要称在安全基准任务上，它在约束满足与性能的平衡上明显优于已有基线。
