RCAN通道注意力超分

Image Super-Resolution Using Very Deep Residual Channel Attention Networks
2018.07论文延伸ECCV 2018Yulun Zhang, Kunpeng Li, Kai Li, Lichen Wang, Bineng Zhong, Yun Fu · 美国东北大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

超分网络越深效果越好，但EDSR超分辨率之后再加深就难以训练；而且低分辨率输入里大量是低频信息，网络对所有通道一视同仁，表达能力被浪费。

方法

用“残差里套残差”（RIR）结构搭出400多层的超深网络：多级长、短跳跃连接让低频信息直接绕过去，主干只学高频；每个残差块里加通道注意力，按通道间的关系自适应地重新加权特征。

影响

把SENet通道注意力式通道注意力引入超分辨率，成为2018–2021年超分领域最常被比较的PSNR导向强基线之一，此后的注意力式复原网络大多以它为对照。

方法

残差里套残差（RIR）：整个网络由若干个“残差组”串联，每个残差组外面有一条长跳跃连接；组内又由若干个残差块组成，每个块有自己的短跳跃连接；整个主干外面还有一条最长的跳跃连接。这样，输入里平滑的低频成分可以沿着多级捷径直接传到输出，主网络只需专注学边缘、纹理这类高频细节，训练也更稳定。论文采用10个残差组、每组20个残差块，总深度超过400层。

通道注意力：每个残差块末尾，对每个通道做全局平均池化得到一个数，经过“压缩再展开”的两层小网络和sigmoid，得到每个通道的权重，再乘回原特征——与SENet通道注意力的挤压-激励相同。它让网络自动强调对重建高频细节更有用的通道。

摘要称，大量实验表明RCAN在精度和视觉效果上都优于当时最先进的方法。

后来的发展

通道注意力和RIR结构被许多后续复原网络借用；2021年起SwinIR图像复原、Restormer复原Transformer等基于Transformer的方法在PSNR上超过RCAN，NAFNet则把通道注意力简化到更轻的形式。

读懂它需要的概念

卷积层、池化与感受野 残差连接 注意力机制 图像作为张量 损失函数

本篇术语

  • 通道注意力　为每个特征通道算一个0到1的权重并乘回去，让网络强调有用的通道、抑制无用的通道。
  • 低频与高频信息　低频是图像中缓慢变化的部分（大块颜色），高频是快速变化的部分（边缘、纹理），超分主要难在恢复高频。

怎么学

先读SENet理解挤压-激励模块、读EDSR理解超分残差块，再读RCAN第3节RIR结构；用官方代码对比去掉通道注意力后在Set5上的PSNR。
