CMOS互补逻辑

Nanowatt Logic Using Field-Effect Metal-Oxide Semiconductor Triodes
1963.02论文延伸ISSCC 1963F. M. Wanlass, C. T. Sah · Fairchild待核对
来源 ↗在交互版中打开（演化树、学习进度）

问题

NMOS或双极逻辑门在不翻转时也持续耗电，晶体管越多，发热越成为瓶颈。

方法

把互补的P型和N型MOS管成对串接：一个导通时另一个截止，静态时几乎没有电流，只在翻转的瞬间耗电。

影响

CMOS后来成为几乎所有数字芯片（包括CPU、GPU、AI加速器）的基本电路形式，是摩尔定律能延续数十年的前提之一。

方法

1963年Wanlass与Sah在ISSCC发表《Nanowatt Logic Using Field-Effect Metal-Oxide Semiconductor Triodes》，提出互补MOS逻辑。

以反相器为例：输入为低电平时，P管导通、N管截止，输出被拉高；输入为高电平时，N管导通、P管截止，输出被拉低。两只管子在稳定状态下总有一只截止，所以电源到地之间没有通路，静态功耗只剩极小的漏电流。只有在电平翻转的瞬间，两只管子短暂同时导通并给负载电容充放电，才耗电，动态功耗大致为P = α·C·V²·f。

这个特性让芯片可以把成千上万个门集成在一起而不被静态功耗烧坏。Dennard缩放定律提出的按比例缩小规则，正是建立在CMOS之上：晶体管缩小后电压和电容同比降低，功率密度保持不变。

  • 动态功耗随频率和翻转数增长，Dennard缩放失效后（见Dennard缩放终结与并行转向）功率密度重新成为瓶颈。
