Phi-4

Phi-4 Technical Report
2024.12论文延伸arXiv 2024Marah Abdin, Jyoti Aneja, Harkirat Behl, Sébastien Bubeck 等 · Microsoft Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

前几代Phi本质上在蒸馏教师模型（GPT-4），学生很难超过教师。

方法

把合成数据贯穿预训练全程，改进数据生成与课程安排，并创新后训练方案，14B参数。

影响

报告称在以STEM问答为主的能力上超过了它的教师模型GPT-4，说明方法不止是蒸馏。

方法

phi-4有140亿参数，架构与Phi-3几乎一样，改变集中在数据和训练方法：在预训练的各个阶段有策略地加入合成数据，而不是以网页和代码等自然数据为主；同时调整训练课程，并在后训练阶段引入新的技巧。

官方称，以往的Phi系列大多是在蒸馏教师（GPT-4），而phi-4在STEM问答上大幅超过教师，说明数据生成和后训练能带来超出蒸馏的收益；尤其在推理类基准上表现突出。

局限与后续

  • 依赖强模型生成的合成数据，对事实性知识类任务帮助有限，也可能继承教师的错误。

本篇术语

  • Phi-4-mini / Phi-4-multimodal　2025年3月的技术报告：Phi-4-mini是38亿参数的语言模型，词表扩到20万并用GQA，官方称在数学和编程推理上可比两倍大的模型；Phi-4-multimodal在它之上用LoRA适配器和模态路由接入图像与语音输入。
  • Phi-4-reasoning　2025年4月30日的技术报告：在精选的“可教”提示和由o3-mini生成的推理示范上对140亿参数的Phi-4做监督微调，得到推理模型；再加一小段结果奖励强化学习得到Phi-4-reasoning-plus。

怎么学

读原文第2节（合成数据）与第4节（后训练）；动手：设计一个让强模型生成数学练习题并自动校验答案的小流程。
