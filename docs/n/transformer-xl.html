Transformer-XL

Transformer-XL: Attentive Language Models Beyond a Fixed-Length Context
2019.01论文延伸ACL 2019Zihang Dai, Zhilin Yang, Yiming Yang, Jaime Carbonell, Quoc V. Le, Ruslan Salakhutdinov · 卡内基梅隆大学 / Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Transformer语言模型把长文本切成固定长度的片段分别处理，片段之间信息完全不通，既看不到片段外的上下文，开头几个词也几乎没有上文。

方法

处理新片段时，把上一个片段算出的隐状态缓存下来当作额外的上文，并改用相对位置编码，使缓存的状态可以复用。

影响

让Transformer能利用超过训练长度的上文，成为XLNet、压缩记忆Transformer的基础，其相对位置思路影响了后续位置编码。

方法

固定长度片段训练有两个后果：片段边界处的词没有上文（作者称之为上下文碎片化），模型能用的依赖长度也不超过片段长度。

Transformer-XL的做法是片段级循环：处理第t个片段时，把第t−1个片段每一层的隐状态缓存起来（不再反向传播梯度），让第t个片段的注意力同时看到自己和缓存。第t+1个片段看到的缓存里又包含了更早的信息，所以有效上文可以随层数一层层延长。

缓存的状态里已经加过绝对位置编码，不同片段的位置会重复冲突，所以作者改用相对位置编码：注意力分数里只出现词与词的相对距离，不再出现绝对位置。

官方摘要称：学到的依赖比RNN长80%、比原始Transformer长450%；评估时最多快1800多倍；在enwiki8上达到0.99 bpc，WikiText-103上困惑度18.3。

局限与后续

  • 缓存只是把上一个片段原样保留，旧片段越多内存越大，更早的信息只能被丢弃。
    后来针对它的工作　压缩记忆Transformer
  • 注意力仍然是对缓存内全部位置计算，长度一大成本依然随长度增长。
    后来针对它的工作　Longformer滑窗注意力 FlashAttention

它建立在什么之上

  • 延续
    Transformer2017.06 · LLM 已核对
    在Transformer上加入跨片段的状态缓存和相对位置编码，突破固定长度上下文。
  • 改进
    探索语言模型的极限2016.02 · NLP
    10亿词基准的句子是打乱的，模型只能看到单句上下文，学不到跨句、篇章级的依赖。
  • 改进
    AWD-LSTM2017.08 · NLP
    加一个不需训练的缓存就能降低6–11个困惑度，说明LSTM记不住几百个词之前出现过的内容，长程依赖仍弱。
  • 改进
    门控卷积语言模型GLU2016.12 · NLP
    上下文长度固定，无法像RNN那样原则上处理无限历史。

后来的相关工作

  • 使用
    Conformer2020.05 · 语音 已核对
    自注意力采用Transformer-XL的相对正弦位置编码，消融显示去掉它错误率明显上升。
  • 竞争
    ALiBi线性偏置位置2021.08 · LLM
    Transformer-XL靠缓存上一段的隐状态延长上下文；ALiBi在WikiText-103上用更长的训练长度（3072）超过了它的困惑度。
  • 使用
    Gopher2021.12 · LLM
    采用其相对位置编码，以便在比训练更长的文档上评估。
  • 改进
    FlashAttention2022.05 · 系统·效率
    注意力仍然是对缓存内全部位置计算，长度一大成本依然随长度增长。
  • 竞争
    位置插值扩上下文2023.06 · LLM
    Transformer-XL用循环记忆跨段传递信息，需要改结构；位置插值保留原结构，直接看到完整的长窗口。
  • 使用
    XLNet2019.06 · LLM
    沿用Transformer-XL的片段循环与相对位置编码，使其可处理更长上文。
  • 延续
    压缩记忆Transformer2019.11 · LLM
    在Transformer-XL的片段记忆之外再加一层压缩记忆，保留更久的历史。
  • 改进
    Longformer滑窗注意力2020.04 · LLM
    注意力仍然是对缓存内全部位置计算，长度一大成本依然随长度增长。
  • 延续
    外接kNN记忆2022.03 · LLM
    把Transformer-XL的短期缓存换成可检索的大规模外部记忆。
  • 延续

读懂它需要的概念

自注意力与多头注意力 上下文窗口 位置编码 循环网络与隐状态 语言模型 困惑度

本篇术语

  • 上下文碎片化　把长文本硬切成固定长度片段后，每个片段开头的词看不到前文，边界处的预测变差。

怎么学

先理解上下文窗口和位置编码；读原文第3节的片段循环和相对位置公式；对照相对位置表示看两者相对位置写法的差异。
