QuAC对话式问答

QuAC: Question Answering in Context
2018.08数据集延伸EMNLP 2018Eunsol Choi, He He, Mohit Iyyer, Mark Yatskar, Wen-tau Yih, Yejin Choi, Percy Liang, Luke Zettlemoyer · 艾伦人工智能研究所 / 华盛顿大学 / 斯坦福大学 / 马萨诸塞大学阿默斯特分校待核对
arXiv ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

SQuAD等阅读理解是一问一答，问题彼此独立、多由看过文章的人写；真实的求知对话里，后一个问题依赖前面的对话，还常常开放、没有答案。

方法

让两名众包者对话：学生看不到一篇隐藏的维基百科文章，只能连续自由提问以尽量多了解它；老师看得到文章，用文中的短片段作答，共收集1.4万段对话、10万个问题。

影响

与同期的CoQA并列为对话式问答的两大基准，推动了把对话历史建模进阅读理解模型的研究。

方法

背景。SQuAD和SQuAD 2.0的问题相互独立。同期的CoQA对话问答也做多轮问答，但提问者能看到文章，问题偏向从文中找事实。QuAC强调“信息不对称”：提问者真的不知道文章内容。

数据怎么收。学生只知道文章所在维基页面的标题和章节名，要通过一连串自由提问尽量多了解这一节内容；老师看着全文，只能用文中的连续片段回答，或回答“无法回答”，并给出提示，例如“可以继续问”。这样产生的问题常常更开放，有些在文中找不到答案，有些只有放在对话上下文里才有意义，比如“他后来怎么样了”。

规模与基线。共约1.4万段对话、10万个问题。作者扩展了当时最强的阅读理解架构以建模对话上下文，但最好的模型仍比人类低20个F1。

局限与后续

  • 答案必须是文中的连续片段，开放式问题的评分只能靠片段重合；标注者之间对“答多长”分歧大，人类上限本身不高。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    SQuAD2016.06 · 数据·评测
    把抽取式阅读理解扩展为依赖对话历史的多轮问答。
  • 延续
    SQuAD 2.02018.06 · 数据·评测
    延续SQuAD 2.0引入的无法回答问题，并让它在对话中自然出现。
  • 竞争
    CoQA对话问答2018.08 · 数据·评测
    同期的对话式问答数据集；CoQA提问者能看到文章，QuAC刻意让提问者看不到。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

本篇术语

  • 信息不对称　对话一方掌握信息、另一方不掌握，提问者只能靠提问来了解，问题因此更自然、更开放。

怎么学

先读SQuAD和CoQA对话问答。读QuAC原文第2节的收集界面说明和问题类型分析；动手统计几段对话里有多少问题必须结合上文才能理解。
