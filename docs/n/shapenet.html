ShapeNet

ShapeNet: An Information-Rich 3D Model Repository
2015.12数据集延伸arXiv 技术报告 2015Chang, Funkhouser, Guibas, Hanrahan, Huang, Li 等 · Stanford / Princeton / TTIC待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图像有了 ImageNet，3D 形状却没有统一的大规模、带语义标注的模型库，各家用的小数据集互不相通，数据驱动的 3D 学习无从谈起。

方法

收集大规模 3D CAD 模型，按 WordNet 的类别体系组织，并给模型配上对齐朝向、部件、对称面、物理尺寸、关键词等标注。

影响

成为 3D 形状识别、重建、生成的标准数据来源（常用其中带类别的子集），许多点云、体素、NeRF 前身工作都在它上面训练评测。

方法

ShapeNet 是一个『标注丰富的 3D CAD 模型仓库』。技术报告发布时，它索引了超过300万个模型，其中22万个被归入3135个类别（WordNet 的同义词集 synset），仿照 ImageNet 用 WordNet 组织类别的做法。

每个模型不仅有类别，还尽量提供一致的刚性对齐（所有椅子朝向一致）、部件分割、双边对称面、真实物理尺寸和关键词，并通过网页界面供浏览。后来常用的子集（如 ShapeNetCore）只取其中已清洗、带类别的一部分。这些统一的坐标和标注让研究者能比较不同的 3D 表示方法，例如 PointNet 就在它上面评测。

局限与后续

  • 模型多是干净的人工建模CAD，没有真实扫描的噪声、遮挡和纹理，在它上面训练的方法迁移到真实传感器数据时效果下降。
    后来针对它的工作　nuScenes
  • 绝大多数模型没有被分类，部件等细标注也只覆盖其中一部分。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    ImageNet2009.06 · 数据·评测
    沿用 ImageNet 『大规模数据加统一类别体系』的思路，但对象从2D图片换成3D模型。
  • 使用
    WordNet1995 · 数据·评测
    用 WordNet 同义词集作为类别体系，使 3D 类别能与 ImageNet 对齐。

后来的相关工作

  • 使用
    PointNet2016.12 · 视觉
    部件分割在ShapeNet的16类、约1.7万个形状上评测。
  • 使用
    FlyingThings3D合成光流2015.12 · 数据·评测
    FlyingThings3D里飞行的物体取自ShapeNet的三维模型。
  • 使用
    ScanNet2017.02 · 数据·评测
    用ShapeNet的CAD模型做模型检索与对齐任务。
  • 改进
    nuScenes2019.03 · 数据·评测
    模型多是干净的人工建模CAD，没有真实扫描的噪声、遮挡和纹理，在它上面训练的方法迁移到真实传感器数据时效果下降。
  • 使用
    SAPIEN铰接物体仿真2020.03 · 具身·世界模型
    铰接物体数据集建立在ShapeNet/PartNet的三维模型之上。
  • 使用
    pixelNeRF少视角NeRF2020.12 · 视觉
    主要在ShapeNet物体上训练和评测单图新视角合成。
  • 改进
    CO3D真实物体多视图2021.09 · 数据·评测
    ShapeNet是合成CAD模型，CO3D提供规模相当的真实多视图照片。
  • 延续
    Objaverse2022.12 · 数据·评测
    ShapeNet只有数万个、少量类别的模型；Objaverse把规模提高一个数量级以上并附文字描述。

读懂它需要的概念

三维表示：体素、点云、网格、隐式场 监督学习 分类、检测、分割

怎么学

先了解三维表示：体素、点云、网格、隐式场（网格、体素、点云） → 读技术报告第1、3节了解结构 → 下载 ShapeNetCore 的一个类别看看模型。
