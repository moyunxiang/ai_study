AlexNet

ImageNet Classification with Deep Convolutional Neural Networks
2012.09论文主干NeurIPS 2012Alex Krizhevsky, Ilya Sutskever, Geoffrey E. Hinton · 多伦多大学来源已核对
NeurIPS 2012 ↗PDF ↗CS231n：卷积网络讲义 ↗在交互版中打开（演化树、学习进度）

问题

2012年以前，图像识别靠手工特征（SIFT、HOG）加编码再接SVM，ImageNet千类识别的top-5错误率停在25%以上；卷积网络主要在MNIST这类小图上表现突出，用到大规模高分辨率自然图像上，计算代价高得难以承受，参数多了又容易过拟合。

方法

把LeNet式的卷积网络放大到8层、6000万参数，用ReLU加快训练、用Dropout和数据增强抑制过拟合，在两块GTX 580 GPU上用120万张ImageNet图片训练5–6天。

影响

ILSVRC-2012的top-5错误率15.3%，第二名26.2%，差距超过10个百分点。此后历届ILSVRC分类冠军都是卷积网络，用GPU训练深度网络成为视觉研究的主流做法。

背景

2010–2011年的ILSVRC挑战赛挑战赛要在1000个类别、约120万张训练图上做分类。当时的冠军方案是一条很长的手工流水线：在图上密集提取SIFT特征等局部特征，用Fisher向量或稀疏编码把它们汇总成一个长向量，再训练线性支持向量机，最后把多个这样的系统平均。每一步都要专家调。

卷积网络（LeNet与卷积网络）在手写数字上早就很好，但要用到224×224的彩色自然图像上，有三个现实障碍：

  • 算力：网络大一百倍，CPU上要训几个月；
  • 数据：参数几千万，小数据集上必然过拟合——直到ImageNet才有了百万级标注；
  • 训练技巧：tanh/sigmoid激活在深网络里饱和、梯度变小，训练极慢。

论文的引言把卷积网络的优势归结为它对图像做了“强而大体正确的假设”：图像统计在各处相同（平移不变），像素之间的依赖是局部的。所以它比同样大小的全连接网络连接和参数少得多、好训练。这篇论文同时应对了上面三个障碍。

方法

结构。5个卷积层＋3个全连接层，最后接1000路Softmax与logits。输入224×224×3；第一层用96个11×11的卷积核、步长4，之后的卷积核依次是5×5和3×3；第1、2、5层卷积后接最大池化；全连接层各4096个单元。共约6000万参数、65万个神经元。作者发现去掉任何一个中间卷积层，top-1性能会掉约2%，说明深度是重要的。

ReLU。激活函数用ReLU：f(x) = max(0, x)。它在正区间不饱和，梯度恒为1。在CIFAR-10上，4层卷积网络用ReLU达到25%训练错误率的速度是tanh的6倍。

两块GPU。一块GTX 580：AlexNet的显卡只有3GB显存，装不下整个网络。作者用CUDA手写了高效的卷积实现，把每层的卷积核对半分到两块GPU上，只在某些层交换数据。这就是早期的“模型并行”。

抑制过拟合。

  • 数据增强（见数据增强）：从256×256的图里随机裁224×224的块并随机水平翻转，相当于把训练集扩大2048倍；再按RGB主成分随机扰动颜色。测试时取四角加中心共5块及其翻转，10个预测取平均。
  • Dropout：前两个全连接层每个神经元以0.5的概率被置零，迫使网络不依赖某几个特定神经元。没有它，网络严重过拟合。

其他细节。局部响应归一化（LRN）使top-5错误降1.2%；重叠池化（3×3窗口、步长2）再降0.3%。训练用带动量的SGD：批大小128、动量0.9、权重衰减0.0005，验证错误不降时把学习率除以10，共约90轮。

结果

ILSVRC-2010测试集：top-1 37.5%、top-5 17.0%；当年比赛的最好结果是47.1%和28.2%（稀疏编码方案），之后发表的最好结果为45.7%和25.7%（Fisher向量）。

ILSVRC-2012：单个网络验证集top-5为18.2%；5个网络平均16.4%；再加上两个先在更大的ImageNet全集上预训练的网络，7个平均得到测试集15.3%。第二名用多种Fisher向量特征加分类器，为26.2%。

训练在两块GTX 580 3GB上花了5–6天。

后来的发展

AlexNet之后，ILSVRC分类的冠军都是卷积网络：卷积网络可视化调整了第一层，VGG统一用3×3卷积把深度推到16–19层，GoogLeNet / Inception用Inception模块，ResNet用残差连接把深度推到152层，2015年top-5降到约3.6%。DeCAF通用深度特征发现AlexNet中间层的特征可以直接迁移到其他任务，“ImageNet预训练＋微调”成为视觉的默认做法，R-CNN借此把检测精度大幅提升。

工程上，之后的深度学习训练普遍使用GPU，Caffe等早期框架都提供了它的复现。今天回看，后来的网络大多不再沿用的有：LRN（之后多用Batch Normalization）、11×11大卷积核（改为小卷积核堆叠）、巨大的全连接层（改为全局平均池化）、手工两卡切分（改为框架自动的数据并行）。保留下来的是ReLU、Dropout、数据增强、GPU训练和“大数据＋大模型＋端到端”的整套思路。

容易误解的地方

  • AlexNet的结构与LeNet相比并无本质创新，真正的变化是规模（数据、参数、算力）和几个让大网络能训起来的技巧。
  • 15.3%是7个网络集成、并用了额外预训练数据的结果；单个网络约18%。
  • 两块GPU的切分是显存不够的权宜之计（论文说单块GTX 580只有3GB显存，限制了网络大小），不是有意设计的“分组卷积”。

它建立在什么之上

  • 改进
    反向传播1986 · 基础 已核对
    需要大量计算，在1980年代的CPU上只能训练几百到几千个权重的小网络。
  • 延续
    LeNet与卷积网络1998 · 视觉 已核对
    结构仍是卷积—池化—全连接，但输入从32×32灰度图变成224×224彩色图，参数从6万变成6000万。论文引用的是LeCun等1990年的手写数字网络及后来的卷积网络工作，参考文献里没有这篇1998年论文。
  • 使用
    CUDA2006.11 · 硬件 已核对
    用CUDA手写高效卷积实现，才能在几天内训完。
  • 使用
    ImageNet2009.06 · 数据·评测 已核对
    论文称ImageNet这样的新数据集有足够多的标注样本（约120万张训练图），可以训练这种规模的网络而不严重过拟合。
  • 使用
    ReLU2010 · 基础 已核对
    用不饱和的ReLU代替tanh，在CIFAR-10上达到同等训练错误快6倍。
  • 使用
    GTX 580：AlexNet的显卡2010.11 · 硬件 已核对
    两块3GB的GTX 580，显存限制直接决定了网络被切成两半的结构。
  • 使用
    Dropout2012.07 · 基础 已核对
    在前两个全连接层以0.5的概率丢弃神经元，是抑制过拟合的关键手段。
  • 竞争
    Fisher向量2010.09 · 视觉 已核对
    两条路线的正面比较：ILSVRC-2010此前最好的公开结果和ILSVRC-2012第二名都是Fisher向量加手工特征（top-5分别为25.7%和26.2%），AlexNet用端到端学到的特征做到17.0%和15.3%；之后ILSVRC的主要参赛方案转向卷积网络。
  • 改进
    达特茅斯会议1956.06 · 事件 待核对
    神经元网络如何“形成概念”没有可用的学习算法，多层网络无法训练。
  • 改进
    深度信念网络2006 · 基础 待核对
    训练流程繁琐：逐层预训练加上下算法微调，MNIST上要训练约一周，且对比散度给出的是有偏梯度。
  • 改进
    支持向量机1995 · 基础 待核对
    核函数和其参数要人工挑选，模型本身不学习特征，在图像、语音这类原始输入上依赖手工特征。
  • 延续
    GPU多列卷积网络2012.02 · 视觉 待核对
    论文引用Cireşan等的多列深度网络（MNIST错误率低于0.3%）作为小数据集上的代表成绩，并说自己的双GPU结构与Cireşan等的“列式”卷积网络有些相似；AlexNet在百万张、千类的自然图像上用GPU训练卷积网络。
  • 改进
    逻辑回归1958 · 基础
    效果完全取决于人设计的输入特征；面对图像、语音这样的原始信号，线性模型几乎无能为力。
  • 改进
    ARPA IPTO与Licklider1962.10 · 事件
    分时系统改善了上机条件，但当时的算力和内存仍远远不够支撑视觉、语言等任务所需的规模。
  • 改进
    物理符号系统假说1976.03 · 事件

  • 改进
    Neocognitron1980 · 视觉

  • 改进
    第二次AI寒冬1987 · 事件
    手写规则的知识工程无法规模化，寒冬后很长一段时间里，AI缺少一种能从大量数据中自动获取知识的通用方法。
  • 改进
    NIPS（NeurIPS）首届会议1987.11 · 事件

  • 改进
    卷积网络识别邮编1989 · 视觉
    数据只有几千张、网络只有约1万个参数，训练却要3天，这样的算力无法扩展到自然图像和上千类别。
  • 改进
    偏差-方差权衡1992 · 基础
    实验规模很小（每个训练集200个样本、最多24个隐藏单元），大数据下方差问题有多严重没有检验。
  • 改进
    SIFT特征1999 · 视觉
    特征是手工设计的，只描述局部纹理，不包含“这是什么类别”的语义；拿它做类别识别还要再加量化、编码和分类器。
  • 改进
    OpenCV视觉库2000.06 · 系统·效率
    收录的是手工设计的流水线，每一步都要调阈值和参数，在复杂真实场景里的识别精度有明显上限。
  • 改进
    梯度提升机GBM2001 · 基础
    和所有树模型一样不学特征，面对图像、语音等原始信号无能为力。
  • 改进
    随机森林2001 · 基础
    只能在给定的特征上切分，不会从像素、波形、文字这类原始输入中学出特征，在感知任务上远不如深度网络。
  • 改进
    GPU训练深度网络2009.06 · 硬件
    只用一块1GB显存的GPU，模型大小被显存卡住，没有给出多GPU或多机扩展的方法。
  • 改进
    Google Brain猫脸实验2011.12 · 硬件
    局部连接不共享权重，参数量巨大但利用率低；同期的有监督卷积网络用少得多的参数取得了好得多的识别结果。
  • 改进
    视觉皮层感受野1959 · 视觉
    只是单个神经元的描述性发现，没有给出可计算的学习规则，人们不知道这样的分层特征如何通过训练得到。
  • 改进
    MIT夏季视觉项目1966.07 · 视觉
    低估了问题：真实图像里的光照、遮挡、视角变化使得简单的分割加识别流水线根本不可行。
  • 改进
    莫拉维克悖论1988 · 事件
    只是描述性的经验观察，没有给出可检验的定量定义，进化论的解释也是推测。
  • 改进
    贝尔实验室ANNA芯片1992 · 硬件

  • 改进
    HMAX与最大池化1999.11 · 视觉
    模板是手工设定或从图像随机采样的，不是通过端到端误差反向传播学习的。
  • 改进
    LIBSVM2001 · 系统·效率
    核SVM的训练时间和内存随样本数增长很快（需要处理核矩阵），难以扩展到数百万样本。
  • 改进
    HOG与手工特征时代2005 · 视觉

  • 改进
    空间金字塔匹配2006.06 · 视觉

  • 改进

读懂它需要的概念

卷积层、池化与感受野 神经元与激活函数 Softmax与logits 随机梯度下降与小批量 Dropout 数据增强 Top-1与Top-5错误率 CPU、GPU与并行计算

本篇术语

  • top-5错误率　模型给出概率最高的5个类别，如果正确答案不在其中就算错。ImageNet有很多相近类别（上百种狗），所以用它作为主要指标。
  • 局部响应归一化（LRN）　让一个位置上的激活值除以相邻几个通道激活值的平方和，模仿神经元之间的侧抑制。后来的网络大多不再使用它。
  • 重叠池化　池化窗口（3×3）大于步长（2），相邻窗口有重叠。AlexNet用它略微降低了错误率。
  • 模型并行　把同一个网络的不同部分放在不同GPU上计算，用于单卡显存装不下模型的情况。

怎么学

先补卷积层、池化与感受野、神经元与激活函数和Dropout，能自己算出一层卷积的输出尺寸和参数量。读原文第3节（ReLU、多GPU、LRN、重叠池化）和第4节（数据增强与Dropout），对照图2画出每一层的形状。动手：用PyTorch的torchvision.models.alexnet在一个小数据集（如Imagenette）上训练，分别去掉ReLU（换tanh）、去掉Dropout、去掉数据增强，比较训练曲线与验证准确率。
