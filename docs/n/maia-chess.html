Maia类人象棋

Aligning Superhuman AI with Human Behavior: Chess as a Model System
2020.06论文延伸KDD 2020Reid McIlroy-Young, Siddhartha Sen, Jon Kleinberg, Ashton Anderson · 多伦多大学 / 微软研究院 / 康奈尔大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

国际象棋引擎早已远超人类，但它们下棋的方式和人不同：拿来预测「一个具体水平的人这一步会怎么走」时很不准，人也难以从中学习或与之协作。

方法

把AlphaZero式的网络改成在海量在线人类对局上做监督学习，并按棋手等级分档训练，目标不是赢棋，而是准确预测某个水平的人会走哪一步。

影响

Maia把「建模人的决策」而不是「超越人」作为棋类AI的目标，开出了与人类对齐、个性化棋手建模的一条研究线，模型也在Lichess上作为可对弈的机器人供人使用。

方法

在线棋站上有数以亿计的对局，记录了各个水平的棋手在每一个局面下实际走了什么。作者先测试现成引擎：把Stockfish和一个开源的AlphaZero实现当成「人类走法预测器」，发现它们预测人类走法的准确率并不高，而且不会随棋手水平变化而合理变化——它们总是倾向于走最强的那步。

Maia沿用AlphaZero的残差卷积网络结构，但不做自我对弈强化学习，而是直接用人类对局做监督学习：输入局面，输出人类下一步走法的概率分布。关键是按等级分分档：每个分数段单独训练一个模型，于是每个模型都学到了那个水平的人常见的走法和常犯的错误。摘要称，Maia预测人类走法的准确率远高于现有引擎，并且对某个特定水平棋手的预测准确率在对应分档的模型上达到最高，这种「可调」正是它的设计目标。作者还训练了一个深度网络专门预测人类下一步会不会犯大错，显著好于有竞争力的基线。

局限与后续

  • 按等级分分档只刻画了群体平均风格，不能区分同一水平里不同个人的习惯。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只预测单步走法，不做搜索，无法回答人在长计划上的思考方式；方法也只在象棋这种数据极丰富的领域验证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    AlphaGo2016.01 · RL
    AlphaGo第一阶段也在人类棋谱上训练走法预测网络，Maia把这一步单独拿出来并按水平细分。
  • 延续
    AlphaZero2017.12 · RL
    沿用AlphaZero式的网络结构和走法表示，但目标从最强改为最像人，训练从自我对弈改为人类数据监督学习。
  • 竞争
    深蓝战胜卡斯帕罗夫1997.05 · RL
    以深蓝为代表的引擎追求击败人类，Maia追求准确模仿人类，代表两种不同的棋类AI目标。

本篇术语

  • 走法预测准确率　模型给出概率最高的那步与人类实际走的那步相同的比例。

怎么学

先读AlphaZero的网络部分；读原文第3–4节引擎与Maia的对比；在Lichess公开对局里取某一分数段的数据，训练一个小走法预测网络，看准确率随分数段怎样变化。
