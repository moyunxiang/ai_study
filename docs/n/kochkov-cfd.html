机器学习加速CFD

Machine learning accelerated computational fluid dynamics
2021.01论文延伸PNAS 2021；arXiv 2021Kochkov, Smith, Alieva, Wang, Brenner, Hoyer待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

求解纳维-斯托克斯方程要解析最小尺度的流动，成本极高；纯黑箱的机器学习替代又不稳定、泛化差。

方法

保留传统数值求解器的结构，用端到端训练的神经网络改进求解器内部的近似，在粗网格上得到准确结果。

影响

在二维湍流上达到细8到10倍分辨率基线求解器的精度，计算加速40到80倍，并能泛化到训练外的强迫项和雷诺数。

方法

思路是把神经网络嵌进数值求解器里，而不是整个替换：求解器仍按物理方程推进，网络只负责修正粗网格上对导数、对流通量等的近似误差，并通过可微的求解器端到端训练。

摘要报告：对直接数值模拟和大涡模拟两种情形，结果与每个空间维度分辨率细8到10倍的基线求解器一样准，对应40到80倍的计算加速；长时间模拟保持稳定，并可泛化到训练时没见过的强迫函数和雷诺数，这点不同于黑箱方法。

后来的发展

它代表了学习修正数值求解器的路线，与图网络物理模拟器GNS这类完全学习的模拟器、傅里叶神经算子FNO这类算子学习路线并存，也影响了NeuralGCM混合气候模型的混合建模做法。
