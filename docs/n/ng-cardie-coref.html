Ng-Cardie共指消解改进

Improving Machine Learning Approaches to Coreference Resolution
2002.07论文延伸ACL 2002Vincent Ng, Claire Cardie · 康奈尔大学待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

Soon等（2001）把名词短语共指消解变成“两个名词短语是否指同一实体”的二分类，再用简单的就近原则把配对合成实体链；它只有12个浅层特征，学习框架中的若干设计也未经推敲。

方法

从两方面改进：一是学习框架本身——改变训练样例的构造方式和把配对判断合成实体的聚类规则（改为选置信度最高的先行语）；二是把特征集大幅扩充到五十多个，加入更丰富的语言学知识。

影响

在MUC-6和MUC-7共指数据上取得当时最好的结果（F值70.4和63.4），使“提及对分类加聚类”的框架连同其扩充特征集成为此后近十年统计共指消解的标准基线。

背景

共指消解要找出文中哪些名词短语指同一个实体（“奥巴马”“他”“总统”）。早期方法如Lappin-Leass代词消解、中心理论主要处理代词，依靠手写规则。机器学习指代消解（2001）首次给出一个效果可比规则系统的端到端机器学习方案：对每对提及用决策树判断是否共指，测试时对每个提及向前找最近的、被判为共指的提及作为先行语。

方法

学习框架的改动：

  • 训练样例构造：Soon等以“最近的先行语”构造正例；Ng与Cardie对非代词的提及改用最近的非代词先行语构造正例，因为代词先行语携带的信息很少。
  • 聚类规则：测试时不再选“最近的被判为共指的提及”，而是在前文所有候选中选分类置信度最高的那个（best-first），减少被一个就近的错误判断带偏。
  • 还调整了字符串匹配特征的计算方式，并尝试对决策树规则做人工筛选。

特征扩充：在Soon等的12个特征（距离、字符串匹配、性别、数、是否专有名词、是否同位语等）基础上加到53个，新增词汇特征（如中心词匹配、别名）、语法特征（句法角色、是否为限定性名词短语、是否内嵌）、语义特征（WordNet类别是否兼容、上下位关系）以及位置特征等。

分类器使用C4.5决策树与RIPPER规则学习。

结果

在MUC-6和MUC-7共指评测数据上分别取得70.4和63.4的F值，为当时已知的最好结果；提升来自学习框架的改动和更丰富的语言学特征两方面（原文摘要）。作者也发现，单纯加入大量特征会让精确率下降，需要人工挑选（凭一般了解）。

后来的发展

提及对加聚类的框架此后被不断改进：实体—提及模型、排序模型（mention-ranking）、整数线性规划聚类等；Stanford的多遍筛共指消解（2010）用规则式多遍筛反超了很多学习系统；伯克利浅层特征共指（2013）用少量简单特征的排序模型重新取得最好成绩；端到端神经指代消解（2017）则用端到端神经网络同时学提及检测和共指。

本篇术语

  • 提及（mention）　文中指向某个实体的名词短语或代词，如“奥巴马”“他”。
  • 先行语　一个提及在前文中所指的那个更早出现的提及。
  • MUC　1990年代的消息理解会议评测，MUC-6和MUC-7包含了最早的标准共指评测数据和指标。
