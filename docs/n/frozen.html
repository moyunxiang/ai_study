Frozen冻结LM读图

Multimodal Few-Shot Learning with Frozen Language Models
2021.06论文延伸NeurIPS 2021Tsimpoukelli, Menick, Cabi, Eslami, Vinyals, Hill · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

大语言模型能靠几个示例学新任务，但视觉语言模型要么从头训练，要么要为每个任务微调，没有这种少样本能力。

方法

冻结一个预训练语言模型，只训练一个视觉编码器，把每张图变成一小串连续向量，作为前缀放在文字前面，让语言模型照常续写。

影响

第一次展示冻结的大语言模型加视觉前缀即可做多模态少样本学习，直接启发Flamingo、BLIP-2。

方法

做法分两步。第一步：用图文配对数据训练视觉编码器，把一张图编码成若干个连续的嵌入向量（作为前缀，思想与Prefix / Prompt Tuning相近），送给一个参数完全冻结的语言模型，让它写出对应的描述。梯度只更新视觉编码器，语言模型不动。

第二步，由于语言模型能处理任意序列，推理时可以把多个图像嵌入和文字交错排列，如「图1，这是一只dax；图2，这是……」，模型便能依据上下文示例（上下文学习与提示）完成任务。摘要称它能快速学会新物体的名字、做视觉问答和用外部知识，且只用少量示例，说明语言模型的少样本能力可以转移到多模态。

局限与后续

  • 只学到简单的少样本能力，规模较小，对复杂推理仍弱。
    后来针对它的工作　Flamingo
  • 每张图的前缀向量个数固定，且与文字之间只靠输入端对接。
    后来针对它的工作　BLIP-2
