北京智源研究院成立

2018.11事件延伸北京智源人工智能研究院 · 创始院长张宏江待核对
Wikipedia ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

2017年中国发布新一代AI发展规划后，地方政府要把国家战略落到具体机构上；高校和企业各做各的，缺少一个面向长期基础研究、又能把学界和企业拉到一起的平台。

方法

2018年11月在北京市支持下成立北京智源人工智能研究院（BAAI），以非营利研究机构的形式联合高校、研究所和头部AI公司，做基础研究、开源模型与工具，并办年度智源大会。

影响

它是中国大模型早期最活跃的公共机构之一：悟道系列、FlagAI工具链、BGE中文嵌入模型和Emu3多模态模型都出自这里；2025年3月被美国商务部列入实体清单，成为中美AI对抗的一个具体例子。

方法

智源研究院于2018年11月成立，创始人张宏江，总部在北京五道口，2023年约100名员工。据Wikipedia，它的创始成员包括主要AI公司、大学和研究所，宗旨是促进学界与产业合作、培养顶尖人才、聚焦AI基础的长期研究。

主要产出：

  • 悟道（WuDao）：多模态预训练大模型，悟道2.0号称1.75万亿参数，用4.9TB图文数据训练，当时被拿来与GPT-3比较；但参数量并不能直接说明质量。
  • FlagAI：开源的大模型训练与推理工具包，是Linux基金会的孵化项目。
  • 九鼎算力平台：截至2022年9月提供约1000P算力，支持多种AI芯片架构。
  • BGE嵌入模型中文嵌入模型系列和Emu3纯下一词预测纯下一词预测的多模态模型。
  • 线虫C. elegans神经系统与身体的数字仿真（MetaWorm/BAAIWorm）。

智源每年举办智源大会，邀请海内外研究者讨论AI前沿。它是中国新一代AI发展规划之后地方政府建设新型研发机构的代表，2023年的中国“百模大战”中也有它的身影。2025年3月，美国商务部以涉嫌为军事用途开发技术为由将其列入实体清单。

局限与后续

  • 非营利研究院的预算和算力远小于头部互联网公司，在百模大战后大模型主战场转向企业，研究院更多转向开源工具、嵌入模型和评测；被列入实体清单后获取海外芯片与合作也更难。

它建立在什么之上

  • 延续
    OpenAI成立2015.12 · 事件
    以非营利研究机构的形式做前沿AI研究，组织形态与早期OpenAI相似，但由地方政府支持。
  • 延续
    中国新一代AI发展规划2017.07 · 事件
    2017年国家规划要求建设AI创新平台，智源是北京市落实这一规划的代表机构。
  • 竞争
    加拿大AI战略与Vector/Mila2017.03 · 事件
    同样是政府出资建设AI研究所来聚集人才，加拿大依托Vector/Mila等大学研究所，智源以独立非营利研究院形式联合企业。
