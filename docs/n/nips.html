NIPS（NeurIPS）首届会议

1987.11事件重要NIPS 1987，美国丹佛Ed Posner（首任大会主席）、Yaser Abu-Mostafa（程序主席）、Terrence Sejnowski 等 · 加州理工 / 贝尔实验室发起待核对
Wikipedia：NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

1980年代中期神经网络重新受到关注，但研究者散落在物理、神经科学、工程、心理学各处；主流AI会议以符号方法为中心，没有一个开放的场所让研究生物和人工神经网络的人交流。

方法

在加州理工和贝尔实验室主办的邀请制Snowbird神经网络会议基础上，1986年提议创办一个开放的跨学科年会，1987年在丹佛举行首届神经信息处理系统大会（NIPS），讨论从工程应用到大脑建模的一切神经网络研究。

影响

成为联结主义和后来机器学习、统计学习、深度学习的主场；论文集从1987年的90篇增长到2024年的约4,500篇，今天与ICML、ICLR并列为机器学习三大顶会，2018年更名为NeurIPS。

背景

1969年《Perceptrons》与XOR问题之后，神经网络研究在主流AI中边缘化了十多年。转机出现在1980年代：1982年物理学家Hopfield提出Hopfield网络网络，把神经网络与统计物理的能量函数联系起来，吸引了一批物理学家进入；1986年《并行分布式处理》两卷本和反向传播论文表明多层网络可以训练，联结主义迅速升温。

这批人的背景极其多样：物理学家、神经生理学家、电子工程师、心理学家、计算机科学家。当时AI的主要会议IJCAI首届会议和AAAI首届年会以符号方法和专家系统为主；1980年代初出现的机器学习研讨会（ICML的起点的前身）也以符号学习为主。加州理工和贝尔实验室每年在犹他州Snowbird举办一个只限受邀者的“计算用神经网络”会议，但规模小、不开放。

方法

1986年的Snowbird会议上，与会者提议另办一个开放的、跨学科的会议，作为Snowbird的补充，面向研究生物神经网络和人工神经网络的所有人。

1987年，首届NIPS在丹佛举行，由信息论学者Ed Posner任大会主席、学习理论学者Yaser Abu-Mostafa任程序主席，首届由IEEE赞助。早期会议的论文范围很广，从纯工程问题，到把计算模型当作理解生物神经系统的工具。会后在附近滑雪场开研讨会的传统一直保留到2013年会议规模超出滑雪场容量为止。

首届论文集由美国物理联合会（AIP）以《Neural Information Processing Systems》为名出版，物理学出版社出版论文集这件事本身就反映了当时这一领域与物理学的渊源。此后由Posner建立的NIPS基金会主办，论文集改称《Advances in Neural Information Processing Systems》，先后由Morgan Kaufmann、MIT Press、Curran Associates出版。Posner 1993年去世后，Sejnowski一直担任基金会主席。

结果

按papers.nips.cc上的论文列表，1987年收录90篇，2000年152篇，2012年370篇，2017年679篇，2024年约4,500篇。会址1987—2000年一直在丹佛，2001—2010年在温哥华，此后在欧美加多地轮换。

后来的发展

随着时间推移，生物神经系统与人工系统两条研究线逐渐分开，NIPS的论文变成以机器学习、AI和统计为主。1990年代后期神经网络本身一度失宠，NIPS上的主角换成了支持向量机、核方法和贝叶斯方法，会名里的“Neural”几乎成了历史遗留。2012年AlexNet之后深度学习回归，NIPS又成为它的主战场，生成对抗网络GAN、Transformer等都发表在这里。

2014年NIPS做了一个著名实验：把10%的投稿复制一份，交给另一组审稿人独立评审，发现录用决定有相当大的随机性；2021年重复实验，23%的重复投稿得到了不同的录用结论。规模爆炸给审稿带来的压力，也促成了ICLR与OpenReview采用OpenReview公开评审的探索。2018年11月，因“NIPS”缩写被批评带有性别歧视联想，理事会将其更名为NeurIPS。

局限与后续

  • 早期神经网络受限于数据和算力，只能在小问题上演示，1990年代后期在会上被SVM、核方法压过。
    后来针对它的工作　深度信念网络 AlexNet
  • 会议规模扩张后同行评审一致性差，2014年和2021年的重复评审实验都显示录用结论有很大随机性。
    后来针对它的工作　ICLR与OpenReview
  • 生物神经科学与人工神经网络两条线逐渐分道扬镳，最初“用计算理解大脑”的跨学科目标被边缘化。

  • 使用
    反向传播1986 · 基础
    反向传播让多层网络可训练，是早期NIPS论文最常用的工具。
  • 使用
    Hopfield网络1982 · 基础
    Hopfield网络把大批物理学家带进神经网络研究，NIPS的发起方加州理工正是Hopfield所在地，首届论文集也由物理学出版社出版。
  • 延续
    《并行分布式处理》1986 · 基础
    PDP两卷本引发的联结主义复兴需要一个专属会场，NIPS就是它的制度化。
  • 竞争
    IJCAI首届会议1969.05 · 事件
    IJCAI与AAAI以符号AI为主，NIPS则面向神经网络和统计学习，两个社群长期分立，后来NIPS的影响力反超。
  • 竞争
    ICML的起点1980 · 事件
    同一时期的机器学习会议起初偏重符号学习，NIPS偏重神经与统计方法，后来两者主题逐渐趋同。
  • 改进
    AAAI首届年会1980.08 · 事件
    会议长期以符号AI和经典规划推理为主，2010年代后被机器学习顶会在影响力上超过。

本篇术语

  • Snowbird会议　加州理工与贝尔实验室在犹他州Snowbird举办的邀请制“计算用神经网络”年会，是NIPS的前身。
  • 联结主义　认为智能来自大量简单单元（神经元）之间连接权重的并行计算，与以显式符号和规则为核心的符号主义相对。

怎么学

打开papers.nips.cc，浏览1987年的论文目录，看看当时的题目有多少与生物神经系统有关；再看2012年和2017年的目录，体会研究重心的转移。可以挑AlexNet或Transformer的NIPS原文读一读，熟悉顶会论文的格式。
