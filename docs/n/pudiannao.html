PuDianNao通用机器学习加速器

PuDianNao: A Polyvalent Machine Learning Accelerator
2015.03论文延伸ASPLOS 2015Daofu Liu, Tianshi Chen, Shaoli Liu, Jinhong Zhou, Shengyuan Zhou, Olivier Temam, Xiaobing Feng, Xuehai Zhou, Yunji Chen · 中科院计算所 / 中国科学技术大学 / Inria待核对
ACM DOI ↗在交互版中打开（演化树、学习进度）

问题

DianNao神经网络加速器和DaDianNao机器学习超算只加速神经网络，但实际应用里k近邻、SVM、决策树等经典机器学习方法同样常用；为单一算法定制的加速器一换算法就用不上。

方法

分析七种代表性机器学习算法的计算原语和数据局部性，找出它们共有的运算（距离计算、点积、计数、排序等），设计一个能同时支持这七种算法的加速器。

影响

DianNao系列里专攻“通用机器学习”的一篇，说明专用加速器也可以覆盖一族算法而不是一个；后来寒武纪的指令集路线延续了这种追求一定通用性的思路。

方法

论文的出发点是机器学习里的“没有免费午餐”：在一个数据集上好用的方法，换个数据集可能很差，用户也可能干脆换一种方法。所以一颗只认神经网络的加速器，很可能因为任务改变而闲置。

PuDianNao覆盖七种方法：k均值、k近邻、朴素贝叶斯、支持向量机、线性回归、分类树和深度神经网络。作者逐一拆解它们的计算原语——例如k近邻和k均值的主体是向量距离，SVM和线性回归是点积，朴素贝叶斯和分类树需要计数与比较——以及数据被重复使用的模式，再据此设计功能单元和片上缓冲，让不同算法共享同一套硬件。

摘要给出的数字：65nm工艺下面积3.51平方毫米，峰值1056 GOP/s，功耗仅596毫瓦；与28nm工艺的NVIDIA K20M GPU相比，速度约为其1.20倍，而功耗只有不到1瓦（GPU为百瓦级）。

局限与后续

  • 七种算法是事先挑定的，新的模型结构（例如后来的注意力网络）仍需要改硬件；通用性与效率之间的取舍没有被根本解决。
