神经命名实体识别

Neural Architectures for Named Entity Recognition
2016.03论文重要NAACL 2016Guillaume Lample, Miguel Ballesteros, Sandeep Subramanian, Kazuya Kawakami, Chris Dyer · 卡内基梅隆大学等待核对
arXiv ↗ACL Anthology ↗LSTM-CRF代码 ↗在交互版中打开（演化树、学习进度）

问题

命名实体识别的最好系统依赖大量手工特征（前后缀、大小写规则）和地名人名词典，每换一种语言都要重做；标注数据又很少，纯数据驱动的模型很难学好罕见词。

方法

每个词的表示由两部分拼成：从无标注语料预训练的词向量，加上用双向LSTM读该词字符得到的拼写向量；句子层面用双向LSTM读上下文，顶上接CRF联合解码整条标签序列。

影响

不用任何词典和语言专属特征，在英、德、荷、西四种语言上达到或接近最好结果；“字符BiLSTM + 词向量 + BiLSTM-CRF”成为2016–2018年序列标注的标准模板，ELMo和BERT出现前几乎所有NER系统都以它为基线。

背景

命名实体识别（NER）要在句子里找出人名、地名、机构名等，并标出类型。标注通常用IOB格式：每个词标为B-PER（人名开头）、I-PER（人名内部）或O（不是实体）等。

2016年前的强系统，如基于条件随机场或感知机的模型，靠人工设计的特征：词是否首字母大写、有什么后缀、是否出现在地名词典里。这些特征强依赖语言，德语名词都大写，英语的规则就不管用。从零开始的神经NLP和BiLSTM-CRF序列标注已经用神经网络学上下文特征，但最好的版本仍要加拼写特征和词典。另一个难点是数据量：CoNLL-2003命名实体这类标注集规模很小，大量人名、地名在训练集里只出现一两次，甚至没出现过，单独为每个词学一个向量根本学不好。

方法

词的表示 = 词向量 ⊕ 字符向量。

  • 词向量：在大规模无标注语料上用skip-n-gram（word2vec的变体）预训练，再微调。
  • 字符向量：把“Mars”拆成M、a、r、s，用一个正向和一个反向LSTM各读一遍，拼接两者的最终状态。作者的理由是：正向LSTM的末状态偏向记住后缀，反向偏向记住前缀，而前缀、后缀和词干携带的信息不同，比位置无关的卷积更合适。
  • 在拼好的向量上加dropout（丢弃率0.5），否则模型会只依赖预训练词向量，忽略字符信息。

句子层：BiLSTM-CRF。双向LSTM读整句，为每个位置输出对每个标签的分数P_i,y。CRF层再学一个标签转移矩阵A，整条标签序列的得分是

s(X, y) = Σ_i A_(y_i, y_(i+1)) + Σ_i P_(i, y_i)

训练时最大化正确序列在所有可能序列中的Softmax与logits概率，测试时用维特比算法（动态规划）找得分最高的序列。转移矩阵会学到“I-PER不能跟在B-LOC后面”这类约束，这是逐词独立分类做不到的。

论文还提出另一种转移式模型Stack-LSTM，用类似依存分析（转移式依存分析）的移进-归约动作直接切分实体块。

结果

CoNLL-2003英语测试集F1（见准确率、精确率、召回率与F1）：LSTM-CRF为90.94，去掉字符向量为90.20，Stack-LSTM为90.33；当时使用外部词典或额外标注数据的最好系统为91.2。德语78.76、荷兰语81.74、西班牙语85.75，均超过此前所有方法，包括使用外部资源的系统。消融显示各部分对英语F1的贡献：预训练词向量+7.31，CRF层+1.79，dropout+1.17，字符向量约+0.74。

后来的发展

这套结构很快成为标准做法，Ma和Hovy同年提出用字符CNN替代字符LSTM的同类模型。ELMo在同一类BiLSTM-CRF上换入上下文化的预训练向量，BERT则直接在预训练Transformer上逐词分类，在CoNLL-2003上进一步刷新纪录。CRF层在BERT之后常被省略，因为强编码器已经能隐式学到标签之间的约束；字符级建模则被子词切分（BPE子词切分、WordPiece）取代。

读懂它需要的概念

循环网络与隐状态 嵌入向量 概率图模型 动态规划 准确率、精确率、召回率与F1 Dropout

本篇术语

  • 命名实体识别（NER）　在文本中找出人名、地名、机构名等专有名称，并标出它们的类型。
  • IOB标注　把实体识别变成逐词打标签：B表示实体开头，I表示实体内部，O表示不属于实体。
  • 维特比算法　在所有可能的标签序列里找总分最高的一条的动态规划算法，复杂度与句长成正比、与标签数平方成正比。

怎么学

先补循环网络与隐状态、概率图模型和动态规划，读过条件随机场和BiLSTM-CRF序列标注。读原文第2节（CRF打分和归一化公式）和第4.1节（字符模型），再看表5的消融。动手：用PyTorch实现BiLSTM-CRF，自己写前向算法和维特比解码，在CoNLL-2003上训练，再分别去掉字符向量和CRF层看F1变化。
