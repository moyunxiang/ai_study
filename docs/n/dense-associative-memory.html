稠密联想记忆

Dense Associative Memory for Pattern Recognition
2016.06论文延伸NIPS 2016Dmitry Krotov, John J. Hopfield · 普林斯顿高等研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

经典Hopfield网络网络能存的模式数只有神经元数的约0.14倍，多存一点就互相干扰、取不回来；作为模式识别模型也很难和深度学习里的前馈网络对上号。

方法

把Hopfield能量函数里神经元与记忆之间的二次相互作用换成更高次（如n次多项式或指数）的“陡峭”函数，记忆之间的干扰急剧变小，能存的模式数远超神经元数；并指出这种记忆与单隐层前馈网络是对偶的。

影响

开启了“现代Hopfield网络”这条线：后来现代Hopfield网络把交互函数取成指数，得到与Transformer注意力等价的更新规则；Krotov与Hopfield此后继续以这一框架研究能量模型与深度网络的联系。

方法

经典Hopfield网络的能量可以写成 E = −Σ_μ (ξ_μ · σ)²（σ是神经元状态，ξ_μ是第μ个存储模式），即每个记忆与当前状态重叠度的平方之和。重叠度的二次函数比较“平缓”，许多记忆的贡献叠在一起会产生大量串扰。

稠密联想记忆把平方换成更一般的函数F：E = −Σ_μ F(ξ_μ · σ)，例如 F(x) = xⁿ（n>2的整流多项式）。当n变大时，F变得很陡，状态只有在非常接近某个记忆时才会感受到它的强烈吸引，离得远的记忆几乎不起作用，于是串扰被压低，存储容量随n大幅增长，能够可靠存取远多于神经元数的模式。n较小时网络按“特征匹配”方式识别模式，n很大时退化为“原型”方式（直接找最像的那个记忆）。

作者提出的对偶是：这样的记忆网络在一次更新中，等价于一个单隐层前馈网络——可见层神经元的活动传到隐层，隐层的激活函数正对应F的导数。于是 F(x)=x² 对应线性/逻辑函数，常用的ReLU对应 x³ 等情形，更高次的整流多项式则对应深度学习中还没用过的激活函数。摘要报告：作者用逻辑门XOR和MNIST手写数字识别两个例子展示了稠密记忆的效用。

局限与后续

  • 多项式交互函数的容量随n增长但仍是多项式级；后来把F取成指数函数才得到随维度指数增长的容量，并与注意力机制对应起来。
    后来针对它的工作　现代Hopfield网络
  • 实验只在XOR和MNIST等小任务上，作为实际的识别模型与当时的深度网络相比没有优势。

读懂它需要的概念

能量模型与玻尔兹曼分布 神经元与激活函数 多层感知机 内积与余弦相似度

本篇术语

  • 联想记忆　给出一个残缺或带噪声的输入，网络自动回到与之最接近的已存模式，就像看到半张脸想起整个人。
  • 串扰　存储的多个记忆在能量函数里互相叠加干扰，使网络落到错误的记忆或混合状态。

怎么学

先读Hopfield网络理解能量下降和存储容量；用NumPy分别实现n=2与n=3、4的稠密联想记忆，在随机二值模式上逐步增加存储模式数，画出正确取回率随模式数的变化；再读现代Hopfield网络看指数版本。
