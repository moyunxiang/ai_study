深度信念网络

A Fast Learning Algorithm for Deep Belief Nets
2006论文主干Neural Computation 2006Geoffrey Hinton, Simon Osindero, Yee-Whye Teh · 多伦多大学 / 新加坡国立大学来源已核对
Neural Computation ↗作者PDF ↗在交互版中打开（演化树、学习进度）

问题

多隐层网络用反向传播从随机初始化训练，层数一多就训不动；多层有向概率网络又因“解释消除”而几乎无法推断，深层模型整体陷入停滞。

方法

把深层网络拆成一摞受限玻尔兹曼机，用对比散度一层一层地无监督预训练，每层把下一层的输出当作数据，最后再整体微调。

影响

在不利用图像先验的MNIST任务上，三个隐层的生成模型（1.25%）好于当时报告的SVM（1.4%）和反向传播网络（1.51%）；“先逐层预训练、再微调”成为2006–2011年前后训练深层网络的常用做法。

背景

2006年前后，神经网络处于低谷。反向传播理论上能训任意深的网络，但实践中从随机权重出发，隐层一多，误差信号传到底层就几乎消失（见梯度消失问题），深网络往往还不如浅网络。机器学习的主流是支持向量机这类凸优化方法：有全局最优解，不用调网络结构。

另一条路是把网络看成概率生成模型（有向信念网络，见贝叶斯网络与概率图模型）。它的难点在推断：看到一张图片后，要算出隐变量的后验分布。多个隐藏原因共同解释同一个观测时会互相“抢功”——确认了一个原因，另一个原因的概率就下降，这叫解释消除（explaining away）。它让同层隐变量在后验中彼此耦合，层数越多越算不动，只能用很慢的MCMC或很粗的变分近似。

玻尔兹曼机是无向的能量模型，学习规则漂亮，但每次更新都要跑马尔可夫链到平衡，太慢。Hinton在2002年提出的对比散度让受限玻尔兹曼机变得可训，这篇论文的问题是：能不能用它把深层网络一层层地搭起来？

方法

受限玻尔兹曼机（RBM）。一层可见单元v、一层隐单元h，只有层间连接、层内没有连接（见能量模型与玻尔兹曼分布）。能量为 E(v,h) = −Σ b_i v_i − Σ c_j h_j − Σ v_i w_ij h_j。因为层内无连接，给定v时各隐单元相互独立：p(h_j=1 | v) = σ(c_j + Σ_i v_i w_ij)，推断只要一次矩阵乘法，解释消除的问题在单层内不存在。

对比散度训练。把一张图片放到v上，采样h，再由h重建v′、再算h′，权重按 Δw_ij = ε(⟨v_i h_j⟩_数据 − ⟨v_i h_j⟩_重建) 更新：让真实数据的能量变低，让模型自己“幻想”出来的重建能量变高。

逐层贪心预训练。先在像素上训第一个RBM；训好后冻结，把它的隐层激活当作新的“数据”，再训第二个RBM，依此类推。论文用“互补先验”说明：一个权重绑定的无限深有向网络恰好等价于一个RBM，其先验正好抵消解释消除；在一定条件下，每加一层都不会降低数据对数似然的变分下界。直观说，每层只需解决一个浅层问题，就把深层网络放到了一个好的起点。

整体结构与微调。MNIST模型是784个像素 → 500 → 500 → 2000个单元，顶部两层（500与2000，再加10个标签单元）构成无向的联想记忆，下面各层是有向的生成连接，共约170万个权重。预训练后用“上下算法”（对比版的wake-sleep）整体微调300轮。分类时把图片自下而上传到顶层，看哪个标签单元与之能量最低；也可以从顶层出发向下采样，“想象”出数字图片。

结果

MNIST官方测试集错误率1.25%，优于当时最好的反向传播网络（1.5%）和不用领域技巧的SVM（1.4%）。这个模型不用卷积、不用数据增强，是一个同时建模图片和标签的生成模型。代价是训练很慢：每层预训练30轮，在一台3GHz Xeon上用Matlab每层要几个小时；再加上上下算法微调，总共约一周。作者自己也说这个模型“在很多方面受限”：只适合能把像素值当作概率的图像，没有系统处理感知不变性的办法，假设已经分割好，微调算法也太慢。

后来的发展

同年Hinton与Salakhutdinov在Science上用同样的RBM预训练做出了深度自编码器，两篇常被认为让深层网络重新受到关注。预训练很快进入语音：DBN音素识别在TIMIT上用DBN做声学模型，随后发展成深度网络声学模型；按2015年Nature综述《Deep Learning》的说法，到2012年这类系统已被多个主要语音团队开发，并部署在Android手机上。

但几年之内，人们发现真正的瓶颈是优化而不是“需要无监督预训练”。ReLU、更好的初始化（Xavier初始化）、Dropout加上GPU和大量标注数据，让AlexNet在2012年直接用纯监督反向传播训练深层卷积网络；Nature综述《Deep Learning》写道，深度学习复兴之后，人们发现预训练阶段只在小数据集上才需要。今天RBM和DBN已很少用于主流模型；“先在无标注数据上预训练、再微调”这个思路则以完全不同的形式出现在BERT和GPT-1等工作中。

容易误解的地方

  • DBN不等于“很多层的RBM直接堆起来”。只有顶部两层是无向的，下面各层是有向生成连接；用于分类时人们常把它展开成普通前馈网络再用反向传播微调，那已是另一个模型。
  • 逐层预训练的作用后来被理解为一种好的初始化和正则化，而不是深层网络的必要条件。
  • 1.25%在今天看不算好（卷积网络早已低于0.5%），它的意义在于证明深层网络可以被有效训练。

读懂它需要的概念

能量模型与玻尔兹曼分布 隐变量模型 多层感知机 反向传播 蒙特卡洛采样 条件概率与贝叶斯公式 预训练与微调

本篇术语

  • 受限玻尔兹曼机（RBM）　一层可见单元、一层隐单元、只有层间连接的能量模型。层内无连接，所以给定一层时另一层的单元相互独立，采样和推断都很快。
  • 解释消除　多个隐藏原因都能解释同一个观测时，确认其中一个会降低其他原因的后验概率，导致隐变量在后验里互相耦合、难以推断。
  • 逐层贪心预训练　每次只训练一层，训好后固定，把它的输出当作下一层的训练数据；全部训完再整体微调。
  • wake-sleep算法　训练生成模型的一种两阶段方法：一阶段用识别权重自下而上推断、更新生成权重，另一阶段从模型采样、更新识别权重。

怎么学

先补能量模型与玻尔兹曼分布、隐变量模型和蒙特卡洛采样中的吉布斯采样。读原文第3节（RBM与对比散度）和第4节（贪心算法），第6节看实验即可，第2节的互补先验可以先略过。动手：用NumPy写一个RBM，在MNIST上用CD-1训练，可视化第一层权重（会看到笔画状的特征），再叠第二层，把两层展开成前馈网络做分类微调，与随机初始化对比。
