HAC多层后见分层RL

Learning Multi-Level Hierarchies with Hindsight
2017.12论文延伸ICLR 2019Andrew Levy, George Konidaris, Robert Platt, Kate Saenko · 布朗大学 / 东北大学 / 波士顿大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

分层RL想同时训练多层策略：上层给子目标、下层去实现；但下层策略在不断变化，上层看到的“给出子目标后会发生什么”也随之变化，相当于在一个非平稳的环境里学习，多层并行训练很不稳定。

方法

让每一层都假装下层已经是最优的来训练：用后见经验回放HER式的后见之明重标注，把上层发出的子目标改写成下层实际到达的状态，于是上层的经验看起来就像来自一个完美执行的下层；再配合“子目标测试”惩罚下层确实到不了的子目标。

影响

首次在连续状态和动作空间里成功地并行学习三层层次结构，并与同期的HIRO离策略分层RL一起成为目标条件分层RL的代表方法和常用基线。

背景

分层RL的思想可以追溯到封建式分层RL和Options时间抽象框架：把长任务拆成子目标，上层在更粗的时间尺度上决策。深度RL时代的h-DQN分层DQN、FeUdal Networks做了尝试，但多层联合训练时，下层策略一变，上层同一个子目标动作带来的结果就变了，上层的经验回放很快过时。几个月后发表的HIRO离策略分层RL则用离策略修正（重新挑选与下层行为一致的子目标）处理同一问题。

方法

HAC是一个k层的目标条件策略层次。第i层策略 π_i(s, g_i) 输出一个子目标 g_{i−1}（对最底层则输出原始动作），下层最多用H步去达到它。每层都用目标条件的离策略算法（DDPG配合通用值函数近似UVFA式的目标输入）训练，奖励是稀疏的“到达目标为0、否则为−1”。三种转移让各层独立学习：

后见动作转移：上层的经验里，把它当时发出的子目标替换成下层H步后实际到达的状态，这样这条经验就像是在一个最优下层下产生的，上层的转移函数变得平稳。

后见目标转移：与后见经验回放HER相同，把整段经验的目标替换成之后实际到达的状态，缓解稀疏奖励。

子目标测试转移：以一定概率让下层不加探索噪声地执行上层的子目标；如果下层没有到达，就给上层一个大的惩罚（−H），让上层学会只提出下层力所能及的子目标。

结果

摘要称，在网格世界和模拟机器人领域，HAC相对非分层和其他分层方法显著加快了学习；它是第一个在连续状态和动作空间任务中成功并行学习三层层次结构的框架。

后来的发展

HAC与HIRO离策略分层RL把“子目标即状态”和后见重标注确立为目标条件分层RL的标准组件；后来的离线分层方法（如HIQL）把同样的结构用于离线目标条件RL。

它建立在什么之上

  • 延续
    后见经验回放HER2017.07 · RL
    把后见重标注从“替换目标”推广到“替换上层发出的子目标动作”，使多层并行训练变得平稳。
  • 使用
    通用值函数近似UVFA2015.07 · RL
    每一层都是以目标为额外输入的价值函数与策略。
  • 使用
    DDPG2015.09 · RL
    各层在连续动作上用DDPG训练。
  • 改进
    FeUdal Networks2017.03 · RL
    以往的多层方法联合训练不稳定；HAC通过假设下层最优让各层独立学习，可扩展到三层。

本篇术语

  • 子目标　上层策略给下层设定的中间目标，通常是一个希望在若干步内到达的状态。
  • 后见之明重标注　事后把经验里的目标改成实际达到的结果，使原本失败的经验变成“成功达到另一个目标”的有用数据。

怎么学

先读后见经验回放HER，再对照稍后的HIRO离策略分层RL；读原文第4节三种转移的定义；用官方代码在一个连续导航任务上比较一层、两层、三层的学习速度。
