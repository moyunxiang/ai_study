IVR隐式价值正则（SQL/EQL）

Offline RL with No OOD Actions: In-Sample Learning via Implicit Value Regularization
2023.03论文延伸ICLR 2023Haoran Xu, Li Jiang, Jianxiong Li, Zhuoran Yang, Zhaoran Wang, Victor Wai Kin Chan, Xianyuan Zhan · 清华大学AIR / Yale / Northwestern待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

IQL这类“只用数据内样本”的离线方法效果好，但它为什么能处理分布偏移、和CQL这类显式正则有什么关系，一直没有说清楚。

方法

把数据内学习统一解释为“隐式价值正则”（IVR）：在行为正则化的目标下，最优价值可以只用数据内的动作写出来；选不同的正则函数就得到不同算法，提出稀疏Q学习SQL和指数Q学习EQL。

影响

给IQL、XQL等数据内方法提供了统一的理论视角，SQL/EQL也成为离线RL对比表里常见的条目。

方法

离线RL的一种标准写法是“行为正则化的策略优化”：最大化 E[Q(s, a)] − α·D_f(π ‖ μ)，其中μ是行为策略、D_f 是某个f散度。论文推导出，在这个目标下最优策略和最优价值都有闭式，而且价值的更新只需要用数据里出现过的 (s, a)：

min_V E_(s,a)∼D [ g(Q(s, a) − V(s)) ]

具体的函数g由所选的散度决定。散度取KL时，最优策略是 π ∝ μ·exp(A/α)，对应的价值损失就是指数形式——作者称为EQL（指数Q学习），它与XQL极值Q学习的Gumbel回归在形式上相近。散度取一种使策略稀疏的形式时，得到SQL（稀疏Q学习）：最优策略会把优势为负的动作概率直接置零，只在好动作上分配概率。

这样一来，隐式Q学习IQL的期望分位数回归也可以看成这个框架下的一种特例式近似，都是“隐式”地施加了价值正则，而不用像离线强化学习CQL那样查询分布外动作。摘要称与IQL相比，SQL/EQL在学价值函数时引入稀疏性，在噪声数据下更稳健；在小数据量时也优于CQL。

局限与后续

  • 正则强度α需要按数据集调整，太大退化为行为克隆，太小价值又不稳。

读懂它需要的概念

离线强化学习 KL散度 Bellman方程 分布偏移

本篇术语

  • 数据内学习（in-sample learning）　训练价值和策略时只用数据集里出现过的状态-动作对，不去评估没见过的动作。
  • f散度　衡量两个分布差异的一类指标，KL散度是其中最常见的一个。
