DeepLabv3+

Encoder-Decoder with Atrous Separable Convolution for Semantic Image Segmentation
2018.02论文延伸ECCV 2018Chen, Zhu, Papandreou, Schroff, Adam · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

空洞空间金字塔池化（ASPP）能抓多尺度上下文但边界模糊，编码器-解码器能恢复边界却缺少多尺度上下文。

方法

在DeepLabv3后面加一个轻量解码器，用浅层特征细化边界，并把深度可分离卷积用到ASPP与解码器中。

影响

成为语义分割十年里最常用的基线之一，在PASCAL VOC 2012上取得89.0%。

方法

DeepLabv3用不同空洞率的卷积（见DeepLab空洞卷积）并行采样，得到多尺度上下文，但输出特征图只有输入的1/16，边界粗糙。DeepLabv3+保留它作为编码器，把输出上采样4倍后，与骨干网络浅层的高分辨率特征拼接，再过几层卷积做细化，最后再上采样得到预测。

作者还把Xception作为骨干，并把深度可分离卷积应用到ASPP和解码器里，降低计算量。论文报告在PASCAL VOC 2012和Cityscapes测试集上，无需后处理即取得89.0%和82.1%。

局限与后续

  • 语义分割仍然只有类别，无法区分同类的不同个体。
    后来针对它的工作　全景分割
  • 卷积感受野限制了全局上下文，大场景下依赖空洞卷积间接获取。
    后来针对它的工作　Mask2Former通用分割

它建立在什么之上

  • 改进
    DeepLab空洞卷积2014.12 · 视觉
    沿用空洞卷积与ASPP，补上解码器模块。
  • 改进
    全连接CRF2011.12 · 视觉
    需要迭代滤波，额外增加推断时间；网络本身的边缘能力变强后其增益逐渐变小。
  • 改进
    DeconvNet反卷积分割2015.05 · 视觉
    对每个候选框单独跑一遍分割网络，推理很慢，而且要靠和FCN集成才拿到最好成绩。
  • 使用
    Xception2016.10 · 视觉
    用修改版Xception作为主干。
  • 改进
    RefineNet多路径细化2016.11 · 视觉
    每一级都有完整的细化模块，解码器本身很重，速度不适合实时场景。
  • 竞争
    PSPNet2016.12 · 视觉
    PSPNet用金字塔池化聚合上下文，DeepLab用多空洞率卷积，思路相近而实现不同。
  • 改进
    DeepLabv3与ASPP2017.06 · 视觉
    输出只在1/8或1/16分辨率上预测再直接上采样，物体边界和细小结构仍然粗糙。
