线性倒立摆LIPM

The 3D Linear Inverted Pendulum Mode: A Simple Modeling for a Biped Walking Pattern Generation
2001.10论文延伸IROS 2001Shuuji Kajita, Fumio Kanehiro, Kenji Kaneko, Kazuhito Yokoi, Hirohisa Hirukawa · 日本产业技术综合研究所（AIST）待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

双足机器人的全身动力学非线性、自由度多，实时生成满足平衡的步行模式很难算。

方法

把机器人简化成质量集中在质心、腿无质量的倒立摆，并约束质心在一个平面上运动，使动力学变成两个解耦的线性方程，可以解析地生成步行模式。

影响

三维线性倒立摆模式成为双足步态生成的基础模型，Kajita后来的ZMP预观控制、捕获点等方法都建立在它之上。

方法

人走路时身体重心起伏不大，像一根倒立的摆在支撑脚上方摆动。Kajita等人把双足机器人简化为线性倒立摆：全部质量集中在质心，腿是无质量的伸缩杆，并约束质心只在一个（可以倾斜的）平面上运动。在这个约束下，质心在x、y两个水平方向的运动变成两条解耦的线性微分方程 ẍ = (g/z_c)·x（z_c为质心高度），可以写出解析解。步态生成于是变得简单：给定落脚点序列，就能解析算出质心轨迹，再用逆运动学得到各关节角。论文用这个模型生成了三维的双足行走模式。

局限与后续

  • 忽略腿的质量、躯干转动和角动量，跑跳等高动态动作不适用。
