PSRO博弈论元求解

A Unified Game-Theoretic Approach to Multiagent Reinforcement Learning
2017.11论文重要NeurIPS 2017Lanctot, Zambaldi, Gruslys, Lazaridou, Tuyls, Pérolat, Silver, Graepel · DeepMind待核对
arXiv ↗ar5iv全文 ↗在交互版中打开（演化树、学习进度）

问题

多智能体里各自独立训练的智能体会“过拟合”到训练时的对手，换一个同样水平的搭档或对手就表现大跌；已有的博弈论求解方法又难以接上深度RL。

方法

维护一个不断扩大的策略种群：每轮用博弈论“元求解器”算出对手种群的混合分布，再用深度RL训练一个对这个混合的最佳响应，加入种群，循环往复。

影响

给“自我对弈、虚拟对弈、双重预言机”等方法一个统一框架，成为后来AlphaStar联赛训练等种群式多智能体训练的理论底座。

背景

最简单的多智能体强化学习是独立Q学习多智能体式的独立学习（InRL）：每个智能体把别人都当作环境的一部分来学。问题是对手也在变，环境不再是固定的马尔可夫决策过程；更隐蔽的是，学到的策略会紧紧贴合训练时那几个对手的习惯。

博弈论早有对策：求纳什均衡，或者像虚拟对弈（fictitious play，神经虚拟自我对弈NFSP是它的神经网络版本）那样，对“历史上所有对手策略的平均”做最佳响应。但这些方法要么只能处理小矩阵博弈，要么只对某一种特定的混合方式成立。

方法

过拟合有多严重：JPC矩阵。用同一配置独立跑N次实验，第i次的玩家1和第j次的玩家2组队或对战，得到N×N的回报矩阵。对角线是“一起训练过的搭档”，非对角线是“陌生搭档”。两者差得越多，说明越过拟合。

PSRO（策略空间响应预言机）。维护每个玩家的策略集合，循环：

  • 让集合里的策略两两（或多方）对战，估计一个“元博弈”的收益表——每个策略就是元博弈中的一个“纯策略”。
  • 元求解器在这个小收益表上算出每个玩家的混合分布σ（可以是纳什均衡、均匀分布、复制者动态等）。
  • 对每个玩家，固定对手按σ混合抽取策略，用深度RL训练一个新策略作为近似最佳响应（论文称之为“预言机”）。
  • 把新策略加进集合，重复。

元求解器取不同的选择，就退化成不同的旧方法：只对最新的对手响应是迭代最佳响应（即朴素自我对弈），对历史均匀混合响应是虚拟对弈，用纳什均衡就是双重预言机（double oracle）。

DCH。为了能并行，论文还给了一个近似版：多个进程分别负责不同“层级”的响应，彼此异步读取对方的最新策略和元策略，元求解器在线更新，不必存完整收益表。

结果

在部分可观测的网格世界激光枪战（Laser Tag）small4地图上，独立学习的对角线平均回报20.15、陌生搭档只有5.71，JPC相对损失0.717；换成DCH后降到0.150。在Leduc扑克上，PSRO/DCH得到的策略可利用度（离纳什均衡多远）随迭代持续下降，与神经虚拟自我对弈NFSP同一量级，后期NFSP略低。

后来的发展

“种群+元求解器+RL最佳响应”成了多智能体训练的通用模板：AlphaStar的联赛训练用优先虚拟自我对弈在种群中挑对手，后续还出现了α-Rank元求解器、并行化的Pipeline PSRO等改进。DeepNash陆军棋则走了另一条路——不维护种群，直接让单一策略的学习动力学收敛到纳什均衡。

局限与后续

  • 每一轮都要从头训练一个完整的深度RL最佳响应，迭代次数一多，总算力随种群线性甚至更快增长。

  • 元博弈收益表需要所有策略两两对战来估计，大小随种群规模平方（多人时指数）增长。

  • 在多人、一般和博弈中纳什均衡不唯一、也不一定是好目标，用什么元求解器没有定论。

它建立在什么之上

  • 竞争
    反事实遗憾最小化CFR2007 · RL
    CFR在扑克上靠遗憾最小化逼近纳什均衡、需要遍历博弈树；PSRO只需能采样对局和训练RL，适用面更广但精度不如CFR。
  • 改进
    MADDPG2017.06 · RL
    只在简单的二维粒子世界验证，竞争场景中策略集成只是缓解对手过拟合，并不保证收敛到均衡。
  • 使用
    纳什均衡1950 · RL
    元求解器可以在元博弈收益表上求纳什均衡，此时PSRO就是双重预言机；评价指标NashConv也以纳什均衡为参照。
  • 改进
    独立Q学习多智能体1993 · RL
    用JPC量化了独立学习对训练对手的过拟合，并用对种群混合做最佳响应的方式把这种过拟合显著降低。
  • 改进
    马尔可夫博弈1994 · RL
    在马尔可夫博弈这一多智能体框架下，把博弈论求解与深度RL结合起来。
  • 延续
    神经虚拟自我对弈NFSP2016.03 · RL
    NFSP是神经网络版的虚拟对弈；PSRO把虚拟对弈当作元求解器取“历史均匀混合”时的特例，推广成可换元求解器的框架。

后来的相关工作

  • 竞争
    DeepNash陆军棋2022.06 · RL
    PSRO维护策略种群并用元求解器求均衡；DeepNash只训练单一策略，通过改造学习动力学直接收敛到均衡。
  • 使用
    AlphaStar2019.10 · RL
    联赛训练借鉴博弈论的元策略求解思路。

读懂它需要的概念

博弈论基础与纳什均衡 自我对弈 策略与价值函数 马尔可夫决策过程

本篇术语

  • 最佳响应　对手策略固定时，能让自己收益最大的策略。用RL训练近似最佳响应，就是把固定对手当成环境来学。
  • 元博弈　把种群里的每个完整策略当成一个“招式”，对战结果当收益，构成的一个小矩阵博弈。
  • 可利用度　对手针对你的策略做最佳响应时能多赢多少；为0就是纳什均衡。

怎么学

先补博弈论基础与纳什均衡和自我对弈。读原文第3节（PSRO与DCH）和算法1。动手：在石头剪刀布或Kuhn扑克上实现PSRO，把元求解器分别换成“只打最新对手”“均匀混合”“纳什”，比较可利用度曲线。OpenSpiel库里有现成实现可对照。
