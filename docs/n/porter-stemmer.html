Porter词干提取

An Algorithm for Suffix Stripping
1980论文延伸Program 1980Martin F. Porter · 剑桥大学待核对
作者主页 ↗在交互版中打开（演化树、学习进度）

问题

检索时“connect、connected、connecting”被当成不同的词，查询和文档因词形不同而匹配不上。

方法

用几步按顺序执行的后缀剥离规则，把英语单词的变形还原成同一个词干，不需要词典。

影响

成为信息检索里最常用的词干提取器，在很多搜索引擎和NLP工具中使用了几十年。

方法

Porter词干提取器是一组规则，分五步依次去后缀。每条规则的形式是：如果词以某个后缀结尾，并且剩下的词干满足某个条件，就把后缀替换成另一个。

条件用“词干的测度m”来表示。把单词写成辅音和元音的交替序列，m是其中“元音+辅音”组合的个数。例如tree的m是0，trouble的m是1。规则里常写“当m>1时才去掉-ement”，这样replacement会变成replac，而cement不会被削成c。

例如第一步把sses变成ss，ies变成i，去掉-ing和-ed；后几步处理-ational→-ate、-ness、-ful 等。它的结果不一定是真正的单词（比如happy→happi），但只要同一类词得到同一个词干，用于检索就够了。
