HMC混合存储立方体

Hybrid Memory Cube New DRAM Architecture Increases Density and Performance
2011.08硬件延伸Hot Chips 23（2011）/ VLSI 2012Micron · Samsung · HMC联盟（论文作者Joe Jeddeloh, Brent Keeth · Micron）待核对
VLSI 2012论文DOI ↗维基百科 ↗在交互版中打开（演化树、学习进度）

问题

DDR3这类平面DRAM靠宽并行总线和处理器相连，带宽提升受引脚数和信号完整性限制，内存墙越来越严重。

方法

用硅通孔（TSV）把4–8层DRAM芯片垂直堆在一块逻辑芯片上，内存控制器放进底层逻辑芯片，对外用高速串行链路与处理器通信。

影响

是3D堆叠DRAM最早的商用尝试之一，用在富士通SPARC64 XIfx超算处理器上；但它在市场上输给了同为TSV堆叠、走宽并行接口的HBM高带宽内存，2018年被Micron放弃。

方法

维基百科记载，HMC由Samsung与Micron在2011年共同开发，Micron当年9月公布。在2011年的Hot Chips 23上公布的第一代演示样品由4层50nm DRAM芯片和1层90nm逻辑芯片组成，容量512MB，在1.2V下功耗11W。它的关键设计是：用DRAM与Intel 1103芯片之间的硅通孔和微凸点做垂直连接，把原本放在处理器里的内存控制器移到堆栈底部的逻辑芯片上，处理器只需通过几条高速串行（SerDes）链路发送读写请求。Micron起初称速度可比DDR3高15倍。

HMC 1.0规范于2013年4月发布，HMC 2规范于2014年11月18日发布；按规范，4链路的立方体带宽可达240GB/s，8链路可达320GB/s。第一款使用HMC的处理器是富士通SPARC64 XIfx，用于2015年推出的PRIMEHPC FX100超算。2018年8月，Micron宣布转向GDDR6和HBM，HMC因未获市场采用而停产。

局限与后续

  • 串行链路的功耗和延迟较高，且标准由少数厂商主导、成本高，GPU厂商选择了与处理器做2.5D封装、走宽并行接口的HBM。

本篇术语

  • 硅通孔（TSV）　在硅芯片上垂直打穿的导电通道，让上下堆叠的芯片可以直接相连。

怎么学

先读内存墙，再对比本节点与HBM高带宽内存：两者都用TSV堆叠DRAM，区别在于对外接口（串行链路对宽并行总线）和封装方式，想一想为什么GPU选择了HBM。
