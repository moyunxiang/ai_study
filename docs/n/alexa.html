Amazon Echo与Alexa

2014.11系统延伸Amazon（Lab126）待核对
Amazon Echo（Wikipedia） ↗CNBC 2014-11-06报道 ↗在交互版中打开（演化树、学习进度）

问题

手机上的语音助手需要拿起手机按键唤醒，在厨房或客厅这类离麦克风较远的环境里并不好用。

方法

做一个专用的智能音箱，用远场麦克风阵列和唤醒词随时听用户说话，把识别与理解放在云端。

影响

Echo开创了智能音箱品类，把语音助手推进家庭，并催生了技能（skill）这种第三方语音应用生态。

背景

Siri与语音助手证明了语音助手可行，但它依附于手机。深度网络声学模型（见深度网络声学模型）让识别在较远距离、有噪声的环境下也足够可用。

方法

2014年11月6日，Amazon宣布了Echo（CNBC报道），Wikipedia记载Echo由Amazon的Lab126自2010年左右开始研发，最初只面向Prime会员或需邀请购买，2015年中期才在美国广泛销售。设备内置多麦克风阵列，通过波束成形和噪声抑制听清远处的声音；本地只做唤醒词检测，唤醒后把语音送到云端的Alexa服务做识别和理解，再把结果以语音返回。第三方开发者可以通过Alexa Skills Kit为它添加功能。

后来的发展

智能音箱之后，Google Home等跟进；2020年代，语音助手向由大语言模型驱动的对话型助手演进，见OpenAI Realtime API。
