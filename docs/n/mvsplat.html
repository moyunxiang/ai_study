MVSplat代价体高斯

MVSplat: Efficient 3D Gaussian Splatting from Sparse Multi-View Images
2024.03论文延伸ECCV 2024Yuedong Chen, Haofei Xu, Chuanxia Zheng, Bohan Zhuang, Marc Pollefeys, Andreas Geiger, Tat-Jen Cham, Jianfei Cai · 莫纳什大学 / 苏黎世联邦理工 / 图宾根大学 等待核对

问题

pixelSplat前馈高斯能从两张图前馈预测三维高斯，但它靠网络从单张图特征里猜每个高斯的深度分布，几何不准、模型大，换个数据集泛化也差。

方法

把多视图立体（MVS）里的代价体搬进来：沿若干候选深度平面把另一视图的特征扭过来，算跨视图特征相似度，相似度最高的深度就是可靠的几何线索；用它定位高斯中心，其余高斯参数一起学，只用渲染图像的光度误差监督。

影响

MVSplat表明显式的跨视图几何匹配是前馈高斯重建的关键，以更小的模型、更快的速度超过pixelSplat，成为稀疏视图前馈3DGS的常用基线，后续DepthSplat、AnySplat前馈高斯等都与之比较。

方法

输入两张（或几张）带相机位姿的图像：

  • 用CNN加跨视图Transformer提取每张图的特征。
  • 平面扫描代价体：对参考视图，在近远范围内取D个深度候选；对每个候选深度，用相机参数把另一视图的特征扭到参考视图，与参考特征做点积，得到一个 H×W×D 的代价体。某像素在正确深度上，两视图看到的是同一个三维点，相似度最高。
  • 用一个U-Net细化代价体，softmax后得到每个像素的深度；把像素按深度反投影成三维点，作为高斯的中心。
  • 同一网络再预测每个高斯的不透明度、协方差和颜色（球谐系数），所有视图的高斯合在一起，用3D高斯泼溅的光栅化渲染新视角。

训练只用渲染图与真实图的光度损失，不需要深度真值。摘要称在RealEstate10K和ACID两个大规模基准上取得最好结果和最快的前馈推理速度（22 fps）；与pixelSplat相比，参数少10倍、推理快2倍以上，外观和几何质量更高，跨数据集泛化更好。

后来的发展

代价体＋高斯的组合被后续前馈重建广泛采用；同组的DepthSplat把单目深度先验与多视图匹配结合。再往后AnySplat前馈高斯等方法去掉了对输入位姿的依赖，与VGGT这类直接回归相机和几何的模型合流。

读懂它需要的概念

三维表示：体素、点云、网格、隐式场 相机模型与多视图几何 Softmax与logits 自注意力与多头注意力 编码器-解码器

本篇术语

  • 代价体　对每个像素、每个候选深度记录两视图特征的匹配程度，形成一个三维的数组，用来找最可能的深度。
  • 平面扫描　假设场景位于一系列平行的深度平面上，逐个平面把另一视图扭过来比较。
