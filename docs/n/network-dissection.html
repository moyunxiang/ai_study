网络解剖

Network Dissection: Quantifying Interpretability of Deep Visual Representations
2017.04论文延伸CVPR 2017David Bau, Bolei Zhou, Aditya Khosla, Aude Oliva, Antonio Torralba · MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

人们常说卷积网络里的某些单元「检测」了某个概念，但这是靠少数样例目测得到的印象，没有量化度量，也不清楚这种语义是否只是巧合。

方法

建立带像素级概念标注的数据集（Broden），对每个隐藏单元计算它的激活区域与每个概念标注的重合度，把最匹配的概念作为该单元的标签，并以此量化网络的可解释性。

影响

把「这个神经元是干什么的」变成可量化、可对比的指标，是后来神经元级可解释性（包括用LLM解释神经元）的方法先驱。

方法

框架分三步。第一，收集一个包含多种视觉概念的数据集，涵盖物体、部件、场景、纹理、材质、颜色，每张图都有这些概念的像素级标注。第二，把图像输入待测网络，对每个卷积层的每个单元，取它的激活图，与每个概念的标注区域比较，重合度高就说明该单元与这个概念对齐。第三，把重合度最高的概念作为该单元的标签，把有语义的单元数量当作整个层的可解释性得分。

作者用它检验一个假设：单元的可解释性是否等价于随机的线性组合。结果（据摘要）用来比较不同网络和不同训练任务（有监督与自监督）、训练过程中的变化、不同初始化、正则化等对可解释性的影响。这些比较表明，可解释性是网络的一个可以测量、会随训练选择变化的性质。

局限是只能识别数据集里有标注的概念，对没有标注的概念视而不见。

局限与后续

  • 只能发现数据集里已标注的概念，网络学到的未标注特征看不到。
