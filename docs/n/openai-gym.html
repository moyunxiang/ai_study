OpenAI Gym

OpenAI Gym
2016.06系统延伸Brockman, Cheung, Pettersson, Schneider, Schulman, Tang, Zaremba · OpenAI待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

每个RL论文都有自己的环境与接口，实验难以复现、算法难以公平比较。

方法

提供一组统一接口的基准环境，核心就是 reset() 与 step(action)，再配一个让人上传和比较成绩的网站。

影响

成为此后RL研究事实上的环境标准接口，后继者Gymnasium继续沿用。

方法

Gym是一个RL研究工具包：包含一批不断增加的基准问题（经典控制、Atari、机器人等），它们暴露同一个接口。使用者拿到一个环境对象后，reset() 返回初始观测，step(action) 返回新观测、奖励、是否结束及附加信息。这样同一个算法可以不改代码就跑在许多环境上，不同论文之间可以对比。

白皮书还讨论了设计决定，比如把环境和智能体分开，不规定智能体的实现；并配有网站供人分享结果与比较算法（该榜单后来被停用）。Gym之后，DeepMind Control Suite、NetHack学习环境等基准也采用类似的接口风格。

局限与后续

  • 每个环境各自处理随机种子、版本和渲染细节，历史上出现过因版本差异而不可复现的问题。
    后来针对它的工作　Gymnasium
  • 接口是单智能体的，多智能体、向量化环境需要另外的扩展。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

怎么学

装好gym，按文档跑一遍CartPole，用随机策略和手写策略各玩一次，再自己实现一个简单的 step/reset 环境。
