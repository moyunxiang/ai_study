DnCNN去噪

Beyond a Gaussian Denoiser: Residual Learning of Deep CNN for Image Denoising
2016.08论文延伸TIP 2017Zhang, Zuo, Chen, Meng, Zhang · 哈尔滨工业大学 / 香港理工大学 / 西安交通大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

早期的判别式去噪模型对每个噪声强度单独训练，盲去噪效果差，网络也不深。

方法

让网络预测噪声本身（残差学习），再用带噪图减去它，配合批归一化训练较深的卷积网络。

影响

成为学习式去噪的标准基线；一个模型可同时处理未知噪声强度、超分辨率和JPEG去块。

方法

输入是带噪图像，网络（一串卷积、批归一化、ReLU）输出的不是干净图，而是噪声图，干净图由输入减去预测的噪声得到。作者认为预测噪声比预测干净图更易学：噪声的分布简单，而且残差学习与批归一化结合能加速训练并提高精度。这借鉴了ResNet的残差思想，对手的传统方法如BM3D去噪则基于图块的非局部相似性。

论文称同一个DnCNN模型可以处理噪声强度未知的盲高斯去噪，还可以同时处理一般的去噪、单图超分辨率与JPEG去块。

局限与后续

  • 对真实相机噪声（不是高斯噪声）泛化差。

它建立在什么之上

  • 使用
    ResNet2015.12 · 视觉
    借用残差学习，让网络输出噪声而非干净图。
  • 改进
    非局部均值去噪2005.06 · 视觉
    只做加权平均，相似块不多（细小、独特结构）时去噪效果有限，PSNR明显低于后来的协同滤波和学习方法。
  • 改进
    BM3D去噪2007.08 · 视觉
    用学习到的深度网络，在去噪质量上超过手工设计的BM3D。
