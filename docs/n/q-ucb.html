Q学习的UCB遗憾界

Is Q-learning Provably Efficient?
2018.07论文延伸NeurIPS 2018Chi Jin, Zeyuan Allen-Zhu, Sebastien Bubeck, Michael I. Jordan · UC Berkeley / 微软研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

实践中最流行的是无模型方法（Q-learning及其深度版本），但经验上它们似乎比基于模型的方法需要更多样本；“无模型算法能不能做到样本高效”，即使在有限状态动作的情形也没有理论答案——此前的无模型分析要么需要模拟器，要么遗憾不是 √T 量级。

方法

给Q学习加上UCB式的探索奖励，并精心选择学习率 α_t = (H+1)/(H+t)（t是该状态-动作被访问的次数）。这个学习率让最近的样本权重更大，避免早期不准确的估计长期拖累，从而得到与基于模型方法几乎同阶的遗憾。

影响

第一次在不借助模拟器的前提下证明无模型算法也有 √T 遗憾：Õ(√(H³SAT))，与基于模型方法的最优界只差一个√H因子，回答了“Q学习是否可证明高效”这一基本问题。

背景

在表格有限时域MDP中，基于模型的方法（如UCBVI极小极大遗憾界）先估计转移概率，再在估计的模型上做乐观规划，已经接近最优遗憾 Õ(√(HSAT))。但它们要存储 S²A 规模的转移表，计算也重。无模型的Q学习只存 SA 规模的Q表，每一步只做一次更新，但经典分析（如E3与PAC探索理论、R-max乐观探索的PAC框架下的无模型变体）给出的样本复杂度要差得多，或者需要能从任意状态采样的“模拟器”。学习率怎么选是关键障碍：常用的 1/t 学习率等于对所有历史样本平均，早期来自不准确价值估计的目标值会被同等对待，误差积累后可能随时域指数级放大。

方法

算法很简单：对每个时间步h维护一张表 Q_h(s,a)，初始化为H（最乐观）。在状态 s_h 选 a_h = argmax_a Q_h(s_h, a)，观察 r_h 和 s_{h+1} 后更新：

Q_h(s,a) ← (1 − α_t)·Q_h(s,a) + α_t·[ r_h + V_{h+1}(s_{h+1}) + b_t ]，V_{h+1}(s') = min(H, max_a Q_{h+1}(s', a))

其中t是 (s,a) 在第h步被访问的次数，学习率 α_t = (H+1)/(H+t)，Hoeffding型奖励 b_t = c·√(H³·ι / t)（ι是对数因子）。

这个学习率使第i次样本在最终估计中的权重大致集中在最近的约 t/H 次样本上，于是早期误差被快速“遗忘”，误差在H步之间的传播只放大常数倍而不是指数倍。按原文正文，用上述Hoeffding型奖励时遗憾为 Õ(√(H⁴SAT))；换成利用经验方差的Bernstein型奖励后，改进为摘要中的 Õ(√(H³SAT))。

结果

摘要称，在分幕式MDP中，带UCB探索的Q学习遗憾为 Õ(√(H³SAT))，与任何基于模型方法可达到的最优遗憾只差一个√H因子；据作者所知，这是第一个不需要模拟器就在无模型设定下建立 √T 遗憾的分析。

后来的发展

这篇工作把“学习率设计”带进了RL理论，此后的无模型方法（如带参考-优势分解的Q学习）进一步把遗憾做到最优；同一作者团队随后在LSVI-UCB线性MDP中把乐观值迭代推广到线性函数近似。

读懂它需要的概念

本篇术语

  • 无模型（model-free）　不显式估计环境的转移概率，直接学价值或策略的方法，例如Q学习。
  • 模拟器（generative model）　理论分析中的一种假设：可以从任意指定的状态-动作直接采样下一状态；在线学习中通常没有这种能力。
