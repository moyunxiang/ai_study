CTC-注意力联合训练

Joint CTC-Attention based End-to-End Speech Recognition using Multi-task Learning
2016.09论文延伸arXiv 2016Suyoun Kim, Takaaki Hori, Shinji Watanabe · 卡内基梅隆大学 / 三菱电机研究实验室（MERL）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

注意力编码器-解码器识别模型太灵活：没有从左到右的单调约束，在噪声环境下和长输入上容易对齐出错，训练初期也很难收敛。

方法

在注意力模型的共享编码器上再接一个CTC输出层，两个损失加权相加一起训练，用CTC的单调对齐约束去「拉住」注意力。

影响

CTC与注意力联合训练（以及后来的联合解码）成为ESPnet、WeNet等开源工具的默认配方，今天很多注意力和Conformer识别模型仍带一个辅助CTC分支。

方法

端到端识别有两条主要路线：CTC假设各帧输出相互独立，并强制从左到右的单调对齐；注意力模型（Listen, Attend and Spell、注意力语音识别）在生成每个字时都能参考之前生成的字，没有独立性假设，通常更准，但它的对齐完全靠注意力权重自由学出来，长句和噪声下容易跳读、重复或提前结束。

论文的做法是多任务学习：编码器（多层双向LSTM）由两个分支共享，一个是注意力解码器，一个是CTC输出层，总损失为 L = λ·L_CTC + (1−λ)·L_attention，λ在0到1之间。CTC分支的前向后向计算只允许单调对齐，等于给共享编码器加了一个对齐方面的正则，注意力因此更快学到合理的对齐。摘要称，在WSJ和CHiME-4任务上，联合模型比单独的CTC和单独的注意力基线字符错误率相对降低5.4%–14.6%。

局限与后续

  • 注意力解码器要等整句音频输入完才能开始输出，不适合边说边出字的流式识别。
    后来针对它的工作　端侧流式RNN-T WeNet
  • 论文只在训练阶段联合，解码时仍主要依赖注意力分支，对齐错误在推理时并没有被完全杜绝。
    后来针对它的工作　ESPnet

读懂它需要的概念

编码器-解码器 注意力机制 输入输出不等长时的对齐 端到端学习 循环网络与隐状态

本篇术语

  • 多任务学习　一个共享的网络同时为几个相关目标训练，各目标的损失加权相加，互相起到正则作用。
  • 单调对齐　输出的第k个字对应的音频位置不早于第k−1个字，就像从左往右读，不会跳回去。
