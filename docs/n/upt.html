UPT通用物理Transformer

Universal Physics Transformers: A Framework For Efficiently Scaling Neural Operators
2024.02论文延伸Benedikt Alkin, Andreas Fürst, Simon Schmid, Lukas Gruber, Markus Holzleitner, Johannes Brandstetter待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

拉格朗日仿真多用图网络、欧拉仿真多用网格模型，各应用各设计架构，难以统一规模化。

方法

把不同网格或粒子表示统一压缩到一个潜在空间里推进，再解码到任意查询点。

影响

为一套架构覆盖多种仿真数据和更高效的规模化提供了框架。

方法

UPT用编码器把规则网格、不规则网格或粒子这些输入压缩为紧凑的潜在表示，在潜在空间中用Transformer推进动力学，再通过解码器在任意位置查询输出，因此不必在全分辨率上做昂贵计算。摘要称它可统一处理多种仿真数据并高效扩展。

后来的发展

作为物理代理模型规模化路线的代表，常与DPOT PDE预训练、Poseidon PDE基础模型一起被提及。

局限与后续

  • 在更大规模、多物理场预训练上的效果仍待检验。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 竞争

  • 竞争

  • 延续

    同样用Transformer做算子学习，UPT强调统一表示与潜在空间推进。
