SimCLR

A Simple Framework for Contrastive Learning of Visual Representations
2020.02论文重要ICML 2020Ting Chen, Simon Kornblith, Mohammad Norouzi, Geoffrey Hinton · Google Research (Brain)待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

对比自监督学习越做越复杂：要特殊网络结构、记忆库或动量队列，到底哪个部件真正起作用并不清楚。

方法

去掉所有花样，只留“同图两种增强互为正样本、同批其他图为负样本”。系统消融后发现三件事最关键：裁剪加强颜色扰动的组合、一个用完就扔的非线性投影头、很大的批次和长训练。

影响

线性评估比此前最好结果相对提升7%，加宽的ResNet-50达到有监督ResNet-50的水平；它确立的增强配方和投影头成为后来自监督方法的默认组件，图文对比学习CLIP也直接借用。

背景

对比学习在2019年已经很有效，但各家方法差别很大：对比预测编码CPC要把图像切块、用自回归网络预测相邻块；实例判别InstDisc要维护全数据集的记忆库；三个月前的MoCo用队列加动量编码器。每篇都同时改了很多东西，读者很难判断效果究竟来自损失函数、网络结构，还是数据增强。

SimCLR的出发点是做减法：用最朴素的设置，把每个部件单独拿出来消融。

方法

流程。一个批次取N张图，每张做两次随机增强，得到2N个视图。每个视图过编码器f（ResNet-50）得到表示h，再过一个两层MLP投影头g得到128维的z。同一张图的两个视图互为正样本，批内其余2(N−1)个视图都是负样本，不另外采样也不存记忆库。

损失NT-Xent（归一化、带温度的交叉熵）：

ℓ(i,j) = −log [ exp(sim(zᵢ,zⱼ)/τ) / Σ_{k≠i} exp(sim(zᵢ,z_k)/τ) ]

sim是余弦相似度。批次8192时，每个正样本对有16382个负样本。大批次用LARS优化器稳定训练，在128核TPU v3上训练ResNet-50（批4096、100轮）约1.5小时。

三个发现：

  • 增强的组合比单个增强重要。只用随机裁剪时，同一张图的两块颜色分布几乎相同，网络靠颜色直方图就能“作弊”；加上强颜色扰动才逼它学形状和语义。监督学习用不上的强颜色增强，对比学习却很需要。
  • 非线性投影头。损失算在z = g(h)上，下游任务却用h。非线性头比线性头高约3%、比不用头高10%以上。原因是z被训练得对增强不变，会丢掉颜色、朝向等信息，h保留得更多。
  • 批次越大、训练越久越好，这一点比监督学习更明显。

结果

ImageNet线性评估：标准ResNet-50为69.3%，加宽4倍的ResNet-50（3.75亿参数）为76.5%，与有监督的标准ResNet-50持平，比此前最好的方法相对提升7%。只用1%的ImageNet标签微调，top-5准确率85.8%，超过用全部标签训练的AlexNet。迁移到12个自然图像分类数据集，微调后在10个上不差于或优于有监督预训练的基线。

后来的发展

SimCLR的配方很快被所有人吸收：MoCo v2加上投影头和强增强后不再需要大批次；BYOL、SwAV、SimSiam、Barlow Twins沿用同样的双视图增强。投影头成为自监督的标准部件。CLIP的图文对比损失与NT-Xent形式相同，只是把“两种增强”换成“图片和它的文字描述”，ConVIRT图文对比、ALIGN也一样。此后视觉自监督的主流转向不需要负样本的自蒸馏（DINO）和掩码重建（掩码自编码器MAE）。

容易误解的地方

  • 摘要说“达到有监督ResNet-50的水平”，用的是宽4倍、参数多十几倍的网络；同尺寸ResNet-50是69.3%，与有监督的76.5%仍有差距。
  • 训练完后投影头直接丢掉，下游用的是投影头之前的特征，这一点常被忽略。

局限与后续

  • 负样本只来自同一批次，效果依赖4096–8192的超大批次和TPU集群，普通实验室难以复现。
    后来针对它的工作　BYOL SimSiam
  • 同尺寸ResNet-50的线性评估仍比有监督训练低约7个点。
    后来针对它的工作　BYOL DINO
  • 依赖人工设计的增强组合，换到医学、遥感等颜色本身有意义的领域时增强可能抹掉关键信息。
    后来针对它的工作　掩码自编码器MAE DINOv2

它建立在什么之上

  • 改进
    AlexNet2012.09 · 视觉 待核对
    依赖120万张人工标注图片；类别越多、领域越专，标注成本越难承受。
  • 使用
    ResNet2015.12 · 视觉
    编码器为ResNet-50及其2倍、4倍加宽版本。
  • 改进
    Google Brain猫脸实验2011.12 · 硬件
    无监督特征在ImageNet上的识别准确率只有15.8%，离实用很远；靠重建目标学到的特征不如后来的自监督方法。
  • 改进
    Nature综述《Deep Learning》2015.05 · 基础
    主要成功都来自需要大量标注的监督学习；作者预期无监督学习会更重要，但当时没有可行的大规模方法。
  • 竞争
    MoCo2019.11 · 视觉
    MoCo用队列和动量编码器提供负样本，SimCLR直接用超大批次；随后MoCo v2吸收了SimCLR的投影头和增强，两条路线合流。
  • 改进
    对比损失2006 · 基础
    一次只比较一对，没有利用批内大量其他样本作为负例，规模化时效率低。
  • 改进
    噪声对比估计NCE2010.05 · 基础
    效果依赖噪声分布的选择，噪声与数据差异太大时分类太容易、梯度信息少。
  • 改进
    表示学习综述2012.06 · 基础
    综述时期的主流方法仍是逐层无监督预训练，对“好表示”缺少可量化的评价标准，只能靠下游任务间接衡量。
  • 改进
    Exemplar CNN2014.06 · 视觉

  • 改进

读懂它需要的概念

对比学习 自监督学习 数据增强 内积与余弦相似度 Softmax与logits 批大小、步数与轮数

本篇术语

  • NT-Xent　归一化、带温度系数的交叉熵损失，即InfoNCE在“批内其他样本都是负样本”时的写法。
  • 投影头　接在编码器后面的小MLP，只在计算对比损失时使用，训练完丢弃，下游用它之前的特征。
  • LARS　按每层参数和梯度的范数比例单独缩放学习率的优化器，用来稳定超大批次训练。

怎么学

先懂对比学习和数据增强。读原文第2节的算法1（损失的完整写法）和第3、4节的消融图（增强组合矩阵、投影头对比）。动手：在CIFAR-10上用ResNet-18实现SimCLR，分别去掉颜色扰动和投影头，各训练几十轮，比较线性评估精度。
