安全层动作修正

Safe Exploration in Continuous Action Spaces
2018.01论文延伸Gal Dalal, Krishnamurthy Dvijotham, Matej Vecerik, Todd Hester, Cosmin Paduraru, Yuval Tassa · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

把RL部署到数据中心冷却、机器人这类物理系统上时，有些约束（温度、关节极限）在学习过程中一次都不能违反，而奖励塑形和期望约束都做不到“从不违反”。

方法

在策略输出后面加一个“安全层”：用历史数据学一个代价随动作线性变化的近似模型，每一步求一个最小修改动作的二次规划，使下一步代价不超限；这个问题有闭式解。

影响

“安全层/动作投影”式安全RL的代表做法，与Shielding一起被安全RL综述作为“动作修正”类方法的起点，后来的安全滤波器、控制屏障函数结合RL的工作常引用它。

方法

设每个约束是一个逐步代价 c_i(s, a)，要求每一步 c_i(s′) ≤ C_i。安全层的关键假设是：物理系统的动力学通常是光滑的，下一步代价可以对动作做一阶近似：

c_i(s′) ≈ c_i(s) + g_i(s; w_i)^T a

其中 g_i 是一个用历史轨迹（由任意行为策略产生的动作）离线训练的小网络。有了这个线性模型，每一步把策略给出的动作 μ(s) 修正为离它最近的安全动作：

a* = argmin_a ½‖a − μ(s)‖² s.t. c_i(s) + g_i(s)^T a ≤ C_i

当同一时刻最多只有一个约束处于临界时，这个二次规划有闭式解：a* = μ(s) − λ_i* g_i(s)，其中 λ_i* = max(0, (g_i^T μ(s) + c_i(s) − C_i) / (g_i^T g_i))。也就是说，动作只在快要违规时沿着代价增长最快的方向被往回推，推多少恰好让约束取等号。

安全层是可微的，可以直接接在DDPG这类策略后面一起训练。摘要称在新构造的几个物理环境上，该方法在学习过程中保持零约束违反，而奖励塑形做不到。

局限与后续

  • 线性化只对一步之后的代价有效，无法预见多步之后才会发生的违规；动力学剧烈变化时线性模型失效。
    后来针对它的工作　Recovery RL恢复策略
  • 闭式解假设同时最多只有一个约束激活，多约束同时临界时只能近似。

怎么学

先补拉格朗日乘子、约束优化与对偶；读原文第4节的闭式解推导；在一个带速度上限的点质量环境里实现安全层，对比加与不加时的违规次数。
