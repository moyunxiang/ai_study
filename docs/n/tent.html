TENT测试时熵最小化

Tent: Fully Test-time Adaptation by Entropy Minimization
2020.06论文延伸ICLR 2021Dequan Wang, Evan Shelhamer, Shaoteng Liu, Bruno Olshausen, Trevor Darrell · UC Berkeley 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

测试时训练需要在训练阶段加自监督分支；如果手里只有一个训好的模型和测试数据，没有训练数据也不能改训练过程，怎么适应分布偏移？

方法

测试时最小化模型自身预测的熵，让它对测试数据更自信，只更新归一化层的统计量和逐通道仿射参数。

影响

确立“完全测试时适应”设定和最常用的基线，此后大量TTA方法都在它上面改进。

方法

设定是“完全测试时适应”：只有已训练好的模型参数和无标签测试数据，既没有训练数据，也不改训练流程。Tent的目标函数是预测分布的熵 H(ŷ) = −Σ p(c) log p(c)——预测越集中熵越低。直觉是：在偏移数据上，模型预测越不确定，错误率通常越高，所以压低熵能把模型往更可靠的方向推。

为保证稳定和高效，Tent不动大部分权重，只做两件事：用当前测试批次重新估计Batch Normalization的均值方差；用熵的梯度更新每个通道的缩放和平移参数。每来一个批次在线更新一次。

摘要报告：在加了腐蚀的ImageNet和CIFAR-10/100上降低了泛化误差，在ImageNet-C上达到新的最好错误率；还能处理无源域适应（SVHN到MNIST等数字识别、GTA到Cityscapes的语义分割、VisDA-C），且只需一个轮次的测试时优化，不改动训练。相比测试时训练TTT（分布偏移），它可以直接套在现成模型上。

局限与后续

  • 依赖批归一化和足够大的测试批次，小批次或非i.i.d.的测试流上统计量估计不准。

  • 长时间在线最小化熵可能让模型越来越自信地犯错，甚至坍缩到少数类别。

它建立在什么之上

  • 使用
    Batch Normalization2015.02 · 基础
    以批归一化层为适应对象：重估统计量并只更新其逐通道仿射参数。
  • 使用
    ImageNet-C2019.03 · 数据·评测
    在ImageNet-C上报告当时最好的腐蚀鲁棒错误率。
  • 改进
    测试时训练TTT（分布偏移）2019.09 · 基础
    TTT必须在训练时加自监督分支；Tent只用测试数据和熵目标，不改训练过程，可直接适配现成模型。

读懂它需要的概念

信息量与熵 分布偏移 归一化层 Softmax与logits

怎么学

先补信息量与熵和归一化层；读论文第3节方法；拿一个预训练ResNet在CIFAR-10-C上实现Tent，比较只重估BN统计量与再更新仿射参数的差别。
