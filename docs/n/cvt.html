CvT卷积视觉Transformer

CvT: Introducing Convolutions to Vision Transformers
2021.03论文延伸ICCV 2021Haiping Wu, Bin Xiao, Noel Codella, Mengchen Liu, Xiyang Dai, Lu Yuan, Lei Zhang · 微软 / 麦吉尔大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

Vision Transformer把图像切成不重叠的图块后就只靠注意力，丢掉了卷积对平移、缩放等的天然适应性，在中等规模数据上不如ResNet；而且依赖位置编码，换输入分辨率时很麻烦。

方法

把卷积放回Transformer的两个地方：每个阶段开头用一个带步长的卷积生成token（卷积token嵌入），形成像CNN那样逐级缩小分辨率的层级结构；注意力里的Q、K、V也不用线性层，而用深度可分离卷积投影得到。

影响

CvT是2021年“卷积＋Transformer混合骨干”的代表之一，用更少参数和计算超过同期ViT和ResNet；它“卷积可以替代位置编码”的发现被后续很多混合架构采用。

方法

CvT分三个阶段，每个阶段由两部分组成：

  • 卷积token嵌入：把上一阶段输出的token重排成二维特征图，用一个带重叠、带步长的卷积（第一阶段是7×7、步长4）生成新的token图。这样每过一个阶段，token数变少、维度变宽，与CNN的金字塔结构类似；重叠卷积也让局部空间信息自然进入token。
  • 卷积Transformer块：自注意力需要的Q、K、V原本由线性投影得到，CvT先把token还原成二维，用3×3深度可分离卷积做投影再展平。K和V的投影还可以带步长2，把键值token数降为1/4，显著减少注意力计算，精度几乎不降。

由于卷积已经编码了相对位置，CvT可以完全去掉位置编码。

摘要称CvT在ImageNet-1k上以更少的参数和FLOPs超过其他视觉Transformer和ResNet；在更大数据集（ImageNet-22k）上预训练再迁移时优势仍然保持，CvT-W24在ImageNet-1k验证集上达到87.7% top-1；并且位置编码可以安全移除，简化了高分辨率任务的设计。

后来的发展

CvT与PVT金字塔ViT、Swin Transformer、CoAtNet一起说明层级结构和卷积式局部性对视觉Transformer很有帮助，后续混合骨干（MaxViT等）延续了这一路线；2022年ConvNeXt则从另一个方向证明，现代化的纯卷积网络也能达到同样水平。

局限与后续

它建立在什么之上

  • 改进
    Vision Transformer2020.10 · 视觉
    ViT缺少卷积的局部归纳偏置且依赖位置编码；CvT用卷积嵌入和卷积投影补上，并去掉位置编码。
  • 延续
    DeiT2020.12 · 视觉
    沿用DeiT一类在ImageNet-1k上训练视觉Transformer的设置，与其直接比较参数量与精度。
  • 使用
    MobileNet2017.04 · 视觉
    Q、K、V投影使用MobileNet式的深度可分离卷积，计算量小。
  • 竞争
    PVT金字塔ViT2021.02 · 视觉
    同期都做层级式视觉Transformer并给键值降采样；PVT用不重叠图块和线性降维，CvT用重叠卷积。

读懂它需要的概念

自注意力与多头注意力 卷积层、池化与感受野 图像块与视觉token 位置编码 归纳偏置

本篇术语

  • 深度可分离卷积　先对每个通道单独做空间卷积，再用1×1卷积混合通道，计算量远小于普通卷积。

怎么学

先读懂ViT和Swin的层级结构，再读CvT第3节的两个卷积组件和去掉位置编码的消融；用timm加载CvT-13，换不同输入分辨率推理，体会无位置编码的好处。
