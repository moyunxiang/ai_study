存储超级周期与内存短缺

2025.10事件重要2025年第四季度起三星、SK海力士、美光等存储厂商 · AI数据中心客户待核对
三星：与OpenAI的战略合作（900,000片晶圆/月） ↗Tom’s Hardware：服务器DRAM涨价最高50% ↗美光：退出Crucial消费业务 ↗在交互版中打开（演化树、学习进度）

问题

AI加速器每代都要更多HBM，HBM又比普通DRAM占用多得多的晶圆；存储厂把产能转向AI后，普通内存供不应求。

方法

这不是一项发明，而是一次供需冲击：OpenAI一家就预计最多需要每月90万片DRAM晶圆，存储厂与AI客户签长约锁定产能，价格由客户竞价决定。

影响

存储从周期性的低利润行业变成AI产业链里最紧的一环：服务器内存涨价、厂商退出消费市场、手机和电脑涨价，内存成本也推高了云厂商的资本开支。

背景

大模型推理受显存带宽限制（见显存、内存带宽与“内存墙”），所以每一代加速器都在加HBM：H100是80GB，Blackwell与整机柜液冷单卡近200GB，Vera Rubin NVL72上到288GB的HBM4：2048位接口。HBM是把多层DRAM芯片垂直堆叠、用硅通孔连接的内存（见HBM高带宽内存），同样容量下比普通DRAM消耗更多晶圆，良率也更低。

全球DRAM产能集中在三星、SK海力士和美光三家，新建晶圆厂需要数年。2025年下半年，Stargate扩至约7GW等吉瓦级园区的规划在短时间内叠加，内存需求的增长速度远超扩产速度。

方法

冲击在几周内集中显现：

长约锁产能。2025年10月1日，三星与OpenAI签署意向书，成为Stargate的战略内存伙伴；三星公告称，OpenAI的内存需求预计最高达每月90万片DRAM晶圆。SK海力士同日也与OpenAI达成类似合作。

挤出普通内存。据Tom’s Hardware 2025年10月引用DigiTimes，存储厂把先进制程产能转向AI用的产品后，连普通的DDR5服务器内存也供不应求：美国和中国的大型云厂商即使同意第四季度合约价最高上涨50%（原本预算约30%），也只能拿到订单量的约70%；三星把服务器内存合约价上调最多50%、服务器SSD上调最多35%。

退出消费市场。2025年12月3日美光宣布退出Crucial消费品牌业务，到2026年2月停止向零售渠道供货，理由是AI驱动的数据中心需求激增，要把供给留给更大、增长更快的客户。

结果

短缺在2026年蔓延到终端：据Tom’s Hardware 2026年9月的报道标题，笔记本用DDR5价格12个月上涨约6倍，德国厂商Schenker上调笔记本价格并预计短缺将持续到2027年；Fairphone称内存已占其产品物料成本的60%。云厂商也付出代价：据CNBC，微软2026年4月预计的约1900亿美元资本开支中，约250亿来自内存等零部件涨价（见云厂商资本开支竞赛）。

存储厂利润暴增：据2026年10月的报道标题，SK海力士第三季度营业利润率创下约80%的纪录，称DRAM和HBM产能实际上已售罄至2029年，并宣布向股东返还750亿美元。

后来的发展

内存成为继GPU（H100短缺与GPU配给）、封装（CoWoS产能危机）、电力（电网排队与现场燃气发电）之后AI算力的又一个瓶颈，也是投资市场最敏感的环节：2026年7月韩国存储股与中国科创板AI股的急跌（韩股与科创板AI崩跌）即与此相关。它推动了几条技术方向：用更宽的HBM4接口而非更高频率换带宽，用CXL内存互连等技术扩展内存池，以及用量化、KV缓存压缩（见KV缓存）减少每个token需要的内存。中国则因HBM与设备出口管制被迫自研HBM（昇腾950PR与自研HBM）。

容易误解的地方

  • “90万片晶圆/月”是OpenAI预计的最高需求，不是已签的订单量。
  • 短缺主要集中在DRAM和HBM；同一时期的消费级NAND闪存价格走势并不完全一致，不能把所有存储芯片一概而论。

显存、内存带宽与“内存墙” 芯片供应链：设计、代工、封装、内存 KV缓存 训练与推理的算力差别

本篇术语

  • DRAM与NAND　DRAM是断电即失、速度快的内存，用于显存和主存；NAND是断电保存数据的闪存，用于SSD。HBM属于DRAM。
  • 合约价与现货价　大客户按季度与存储厂谈定的价格叫合约价；在市场上随时买卖的价格叫现货价，波动更剧烈。
  • 长约（LTA）　长期供货协议，客户承诺未来数年的采购量，换取有保障的产能。

怎么学
