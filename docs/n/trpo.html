TRPO

Trust Region Policy Optimization
2015.02论文延伸ICML 2015Schulman, Levine, Moritz, Jordan, Abbeel · UC Berkeley来源已核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

策略梯度的步长很难选：太小学得慢，太大一步更新就可能把策略毁掉，性能崩塌后很难恢复。

方法

每次更新时限制新旧策略之间的KL散度不超过一个小常数（信任域），在这个约束下最大化代理目标。理论版本（以最大KL作惩罚项）可证明单调改进，实际算法是它的近似。

影响

让神经网络策略能稳定地训练出游泳、跳跃、行走等控制任务，是后来PPO的直接前身。

方法

此前的自然策略梯度用Fisher信息矩阵修正梯度方向，保守策略迭代CPI则证明了「小步更新能保证改进」，但都难以用于大型神经网络。TRPO把两者的思路合起来：先写出新策略回报的一个局部近似（代理目标）：旧策略回报加上一项用旧策略采样、按新旧概率比重加权的优势（见重要性采样、Actor-Critic与优势函数），并证明它减去一个与最大KL成正比的惩罚项后，就是新策略回报的下界；再要求新旧策略的平均KL散度不超过δ，在此约束下最大化这个代理目标。

论文给出的原始理论用的是最大KL，实际算法改用平均KL以便估计。求解时用共轭梯度法近似解自然梯度方向，避免显式求逆Fisher矩阵，再沿该方向做线搜索，直到约束被满足且代理目标确实上升。摘要称，尽管实现中做了若干偏离理论的近似，TRPO仍倾向于单调改进，且几乎不用调超参数，并在机器人游泳、跳跃、行走和用屏幕图像玩Atari上验证。

局限与后续

  • 每次更新要做共轭梯度和线搜索，实现复杂，也不方便与共享参数的网络、dropout等结构配合。
    后来针对它的工作　PPO
  • 同一批样本只能用一次（on-policy），样本效率低。
    后来针对它的工作　ACER SAC

它建立在什么之上

  • 改进
    策略梯度定理1999 · RL 已核对
    普通梯度依赖参数化方式，步长难以确定，只保证收敛到局部最优且要求步长逐渐趋于0，实践中收敛很慢。
  • 改进
    自然策略梯度2001 · RL 已核对
    把自然梯度推广为带KL约束的优化，并给出可用于神经网络的近似求解。
  • 使用
    保守策略迭代CPI2002 · RL 已核对
    沿用CPI「保守更新可保证改进」的理论思路，但把混合策略换成任意参数化策略加KL约束。
  • 改进
    REINFORCE策略梯度1992 · RL 待核对
    针对朴素策略梯度步长难选、更新不稳定的问题，用KL信任域控制每步更新幅度；论文实验中直接对比的是固定惩罚系数的自然梯度，并未直接引用REINFORCE。
  • 改进
    GPOMDP无限时域策略梯度2001 · RL
    按普通梯度方向更新，对策略参数化方式敏感，步长难选。

读懂它需要的概念

怎么学

先读策略梯度，再读原文第2–5节理解代理目标与KL约束；然后看PPO如何把约束换成裁剪，对比两者代码量。

核对了什么
  • 5位作者Schulman、Levine、Moritz、Jordan、Abbeel，均为UC Berkeley EECS
  • Proceedings of the 31st ICML, Lille, 2015
  • 理论界用总变差距离导出、再换成最大KL的惩罚形式；实际算法“heuristic approximation which considers the average KL divergence”
  • “We use the conjugate gradient algorithm followed by a line search”；线搜索按指数缩小步长直到目标改进
  • single path与vine两种采样方式；vine需要把系统重置到任意状态
  • 实验：游泳、跳跃、行走（MuJoCo），以及与DQN论文相同的7款Atari游戏
  • 摘要：尽管做了偏离理论的近似，TRPO倾向于单调改进，且几乎不用调超参数
  • Kakade & Langford的保守策略迭代给出了改进下界；自然策略梯度是该信任域更新在线性化目标、二次化KL约束下的特例
