Non-local网络

Non-local Neural Networks
2017.11论文延伸CVPR 2018Wang, Girshick, Gupta, He · CMU / Facebook AI Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

卷积和循环都只处理一个局部邻域，远处位置要靠堆很多层才能互相影响，视频里尤其浪费。

方法

提出非局部操作：一个位置的输出是所有位置特征的加权和，可作为通用模块插入任意网络。

影响

把自注意力式的全局建模带进视觉，是从CNN走向ViT的重要中间步骤。

方法

思想来自经典图像去噪方法non-local means。对特征图上每个位置i，计算它和所有位置j的相似度f(x_i, x_j)，归一化后对各位置的变换特征g(x_j)加权求和，再经过一个线性层并与输入相加（残差形式），这样模块可以插入已训练的网络而不破坏其初值。取点积加softmax的形式时，它就是自注意力与多头注意力的视觉版本。

论文把它放进I3D与Kinetics式的视频网络，让任意两帧、任意两处的位置直接交互；在Kinetics和Charades上达到或超过当时的冠军方案，在COCO上也提升了检测、分割与姿态估计。

局限与后续

  • 对所有位置两两计算，复杂度随位置数的平方增长，高分辨率特征图上开销很大。
    后来针对它的工作　Swin Transformer
  • 只是插在CNN里的附加模块，网络主体仍由卷积构成。
    后来针对它的工作　Vision Transformer

它建立在什么之上

  • 改进
    ResNet2015.12 · 视觉 已核对
    卷积只看局部邻域，要靠堆很多层才能让远处的像素交换信息，缺少显式的全局建模。
  • 使用
    Transformer2017.06 · LLM
    其点积加softmax形式与Transformer的自注意力相通，论文明确讨论了这一联系。
  • 改进
    DenseNet2016.08 · 视觉
    仍是纯卷积结构，每层只看局部邻域，长距离依赖要靠堆叠很多层间接获得。
  • 改进
    I3D与Kinetics2017.05 · 视觉
    把非局部块加入I3D类视频网络，建立跨帧的长程联系。
  • 改进
    SENet通道注意力2017.09 · 视觉
    只在通道维度做重新加权，没有建模空间位置之间的关系。

后来的相关工作

  • 竞争
    Vision Transformer2020.10 · 视觉 已核对
    两种引入注意力的路线：Non-local把自注意力当作插进卷积网络的模块（ViT引言把它列为“注意力与卷积网络结合”的例子）；ViT去掉卷积主干，只用标准Transformer。
  • 使用
    SlowFast2018.12 · 视觉
    可在SlowFast的残差块中插入非局部模块以增强长程依赖。
  • 改进
    Swin Transformer2021.03 · 视觉
    对所有位置两两计算，复杂度随位置数的平方增长，高分辨率特征图上开销很大。
