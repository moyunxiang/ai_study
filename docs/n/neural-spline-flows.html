神经样条流NSF

Neural Spline Flows
2019.06论文延伸NeurIPS 2019Conor Durkan, Artur Bekasov, Iain Murray, George Papamakarios · 爱丁堡大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

可逆流与流匹配的耦合层和自回归层里，每个维度上的可逆变换多是仿射变换（乘一个数再加一个数），单层表达力弱，只能靠堆很多层来拟合复杂分布。

方法

把逐维的仿射变换换成单调的有理二次样条：在一个区间上分成K段，每段用一个有理二次函数，由神经网络输出各段的宽度、高度和节点导数，既灵活又能解析求逆、算雅可比。

影响

样条耦合层成为标准化流的常用模块，被nflows等开源库实现，并广泛用于密度估计、变分推断和科学计算中的模拟推断。

方法

以耦合层为例：把输入x分成两半，前一半原样保留，另一半的每个维度都经过一个一元可逆函数，函数参数由前一半经神经网络算出。标准化流RealNVP、Glow里这个一元函数是仿射的y = a·x + b，形状过于简单。

神经样条流把它换成单调有理二次样条：在区间[−B, B]上设K+1个节点，神经网络输出每段的宽度、高度（经softmax保证加起来等于区间长度）和每个节点处的导数（经softplus保证为正）。每一段内部用两个二次多项式之比来插值，这种形式保证单调递增，因而可逆；求逆只需解一个二次方程，有闭式解；每一维的导数也能直接算出，于是整层的对数雅可比行列式就是各维导数的对数之和。区间外则用恒等映射。

同样的样条也能用在自回归流（参数由MADE式网络给出）里。论文在表格密度估计、变分自编码器的后验和图像生成上，报告了比仿射版本更好的似然，或用更少的层达到相近效果。

  • 标准化流整体在高分辨率图像生成上的样本质量仍明显落后于GAN和扩散模型，样条层没有改变这一点。

读懂它需要的概念

可逆流与流匹配 雅可比矩阵与海森矩阵 最大似然估计 随机变量与概率分布

本篇术语

  • 有理二次样条　把区间分段，每段用两个二次多项式之比来插值的曲线；可以构造成严格单调，因此可逆。

怎么学

先读RealNVP的耦合层和变量替换公式 → 读本文第3节样条参数化与求逆 → 用nflows库在二维玩具分布上比较仿射流和样条流。
