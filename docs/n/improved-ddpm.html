改进DDPM

Improved Denoising Diffusion Probabilistic Models
2021.02论文重要ICML 2021Alex Nichol, Prafulla Dhariwal · OpenAI待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

DDPM样本质量好，但对数似然不如自回归模型；反向过程的方差被固定，采样必须跑满1000步；线性噪声调度在低分辨率图像上过早把信息破坏殆尽。

方法

让网络同时学习反向过程的方差（在两个理论边界之间插值），用“简单损失＋少量变分下界”的混合目标训练，并改用余弦噪声调度，使似然更高、少步采样也能保持质量。

影响

扩散模型的似然首次与自回归模型相当，50到100步即可生成高质量样本，并在ImageNet 64×64上以更高召回率超过BigGAN；学习方差与余弦调度被ADM、GLIDE、DALL·E 2等后续模型直接沿用。

背景

DDPM用1000步、固定方差σ_t² = β_t、线性噪声调度和不加权的L_simple损失，在CIFAR-10和LSUN上得到了与GAN相当的样本。但还有几处明显的不足：

  • 似然：CIFAR-10上每维3.75比特，不如自回归模型，扩散模型是否能覆盖整个数据分布受到质疑。
  • 速度：方差固定意味着采样器离开1000步的设定就明显变差。同期的DDIM提出了确定性的少步采样，但那是另一种采样过程。
  • 调度：线性调度下，后段很多步的图像已经几乎是纯噪声，对低分辨率图像尤其浪费。

还有一个问题没人系统研究过：扩散模型在ImageNet这种多样化数据上表现如何，又如何随规模变化？

方法

学习方差。DDPM论文发现，固定的方差取β_t（上界）或后验方差β̃_t（下界）时样本质量差不多。作者让网络额外输出一个向量v，在对数空间里于两者之间插值：

Σ_θ = exp(v·log β_t + (1−v)·log β̃_t)

这样网络只需输出0到1附近的插值系数，比直接预测方差稳定得多。

混合目标。L_simple不含方差，无法训练它；直接优化完整的变分下界L_vlb又噪声很大、难训练。于是两者相加：L_hybrid = L_simple + λ·L_vlb，λ=0.001，并让L_vlb只更新方差、不影响均值。若只追求似然，作者还提出按各时间步损失的大小对t做重要性采样，降低L_vlb的梯度噪声。

余弦噪声调度（见噪声调度与采样步数）：

ᾱ_t = f(t)/f(0)， f(t) = cos²(((t/T + s)/(1 + s))·π/2)，s=0.008

ᾱ_t在中段近似线性下降，而在两端变化平缓，信息被破坏得更均匀，不会在前一半步数就把图像淹没。

少步采样。有了学到的方差，可以把1000步的时间序列等间隔抽取成更短的子序列，并按相应公式重新计算β，直接用更少的步数采样。

结果

似然：CIFAR-10上只用L_vlb训练达到每维2.94比特，ImageNet 64×64达到3.53比特，与当时的自回归模型相当。混合目标在ImageNet 64×64上FID为19.2，远好于纯L_vlb的40.1。采样：50次前向就能得到不错的样本，约100步时接近满步数的FID；少于50步时DDIM更好，50步以上则本方法更好。在类别条件ImageNet 64×64上，大模型FID为2.92、召回率0.71，而BigGAN-deep为FID 4.06、召回率0.59，说明扩散模型覆盖的模式更多（精确率0.82略低于BigGAN的0.86）。作者还观察到FID随训练计算量大致呈幂律下降。

后来的发展

同一作者几个月后发表的扩散超越GAN在本文的模型基础上改进网络结构并加入分类器引导，在ImageNet上全面超过BigGAN；GLIDE与DALL·E 2也沿用了学习方差和余弦调度。变分扩散模型VDM从变分角度进一步提升了似然，并让噪声调度本身可学习；EDM设计空间则重新梳理了调度与采样器的选择。2023年噪声调度缺陷与零终端SNR进一步指出，Stable Diffusion等模型常用的噪声调度在最后一步并未真正到达纯噪声，导致训练与推理不一致，说明噪声调度的选择仍有讲究。

读懂它需要的概念

扩散：前向加噪与反向去噪 噪声调度与采样步数 变分推断与ELBO 重要性采样 高斯分布 生成质量指标：IS与FID

本篇术语

  • β̃_t（后验方差）　已知原图x₀时，从x_t回到x_{t−1}这一步的真实方差，比β_t略小。DDPM的方差上下界就是β_t和β̃_t。
  • 召回率（生成模型）　真实数据中有多大比例能被生成样本“覆盖到”，用来衡量多样性与模式覆盖；精确率衡量生成样本有多少落在真实数据分布内。

怎么学

先彻底读懂DDPM的推导，尤其是后验均值与方差。原文第3节（学习方差、余弦调度）和第4节（少步采样）是重点，图5对比了线性与余弦调度下的加噪过程。动手：在自己实现的DDPM中把线性调度换成余弦调度，并在CIFAR-10上比较25、50、100步采样时的样本质量。
