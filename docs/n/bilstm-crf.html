BiLSTM-CRF序列标注

Bidirectional LSTM-CRF Models for Sequence Tagging
2015.08论文延伸arXiv 2015Huang, Xu, Yu · 百度待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

序列标注（词性、分块、命名实体）既需要左右两侧上下文，又需要标签之间的搭配约束。

方法

用双向LSTM提取每个词的上下文特征，上面接一个条件随机场层，对整条标签序列联合打分。

影响

成为之后多年命名实体识别和序列标注的标准架构。

方法

双向LSTM各向前、向后读一遍句子，把两个方向的隐状态拼起来，使每个词都同时看到前后文。仅用它逐词分类的话，标签之间互不知晓，可能出现「I-PER」直接接「B-LOC」这类不合法组合。因此在输出层加上CRF：除了每个词对各标签的得分，还学习标签到标签的转移分数，训练时优化整条序列的概率，解码用动态规划的Viterbi算法找最优标签序列。

论文称这是首个把BI-LSTM-CRF用在NLP标准序列标注数据上的工作，在词性标注、分块和命名实体识别上达到或接近当时最佳，且对词向量的依赖较小。

局限与后续

  • 需要手工设计的词形特征仍有帮助，字符级信息尚未纳入。
    后来针对它的工作　神经命名实体识别
  • LSTM逐步读入，训练和推理难以并行。
    后来针对它的工作　Transformer

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    用双向LSTM编码上下文。
  • 改进
    HMM词性标注1988 · NLP
    只看相邻两个词性，无法利用更远的上下文。
  • 使用
    条件随机场2001 · NLP
    输出层用CRF对标签序列联合建模，学习标签转移分数。
  • 改进
    结构化感知机2002.07 · NLP
    特征仍要人工设计成模板（前后词、后缀、标签二元组等），模型本身不学表示，换任务就要重新做特征工程。
  • 竞争
    从零开始的神经NLP2011 · NLP
    同样做端到端标注，但Collobert用窗口加卷积、不使用循环结构。
  • 改进
    中文分词即字标注2003 · NLP
    逐字独立预测标签，没有显式保证标签序列合法（如词尾后不能直接接词中），需要后处理或序列模型。
  • 改进
    jieba结巴分词2012.09 · NLP
    以词典和词频为主，切分精度依赖词典覆盖，遇到领域新词、网络用语和歧义结构容易切错，精度低于神经序列标注模型。

后来的相关工作

  • 改进
    Transformer2017.06 · LLM
    LSTM逐步读入，训练和推理难以并行。
  • 改进
    神经命名实体识别2016.03 · NLP
    沿用BiLSTM-CRF的句子层结构，但去掉手工拼写特征和词典，改用从字符学出的词表示。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

循环网络与隐状态 嵌入向量 动态规划 准确率、精确率、召回率与F1

怎么学

先读条件随机场的转移分数与Viterbi，再读原文第3节，动手用PyTorch写BiLSTM加CRF层做NER。
