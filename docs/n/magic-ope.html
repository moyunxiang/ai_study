WDR与MAGIC离策略评估

Data-Efficient Off-Policy Policy Evaluation for Reinforcement Learning
2016.04论文延伸ICML 2016Philip S. Thomas, Emma Brunskill · Carnegie Mellon University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

在医疗、教育、推荐等场景，上线一个坏策略代价很大，需要先用历史数据（由别的策略产生）估计新策略的表现。重要性采样估计无偏但方差巨大，基于模型的估计方差小却可能严重有偏。

方法

两点改进：（1）把Jiang与Li的双重稳健（DR）估计器推广为加权双重稳健（WDR），用加权重要性采样降低方差；（2）提出MAGIC，对“前j步用重要性采样、之后用模型”这一族估计器按估计的均方误差最优地混合。

影响

在多个领域把离策略评估的均方误差降低了几个数量级，WDR与MAGIC成为离策略评估（OPE）的经典基线，后续OPE基准与新估计器几乎都与它们比较。

背景

离策略评估要用行为策略β产生的轨迹，估计目标策略π的期望回报。经典做法是逐步重要性采样（参见树备份与离策略资格迹等Precup的工作）：用累乘的比率 ρ_t = Π π(a_i|s_i)/β(a_i|s_i) 给回报加权，无偏但方差随时程指数增长；加权重要性采样（WIS）把权重归一化，方差小但有偏。基于模型的方法（直接估计MDP再算π的价值）方差小但可能有大偏差。双重稳健策略评估在老虎机里把两者结合，Jiang与Li（2015）把双重稳健估计推广到序列决策。

方法

WDR：双重稳健估计以模型给出的价值 q̂, v̂ 作为控制变量：

DR = Σ_t γ^t [ w_t r_t − ( w_t q̂(s_t,a_t) − w_{t−1} v̂(s_t) ) ]

其中 w_t 是到t为止的累积重要性权重。WDR把 w_t 换成在全部n条轨迹上归一化的权重 w_t^i / Σ_j w_t^j，牺牲一点偏差（渐近一致）换取大幅降低的方差。

MAGIC（Model And Guided Importance sampling Combining）：定义一族“部分重要性采样”估计器 g^{(j)}——前j步用WDR式的重要性采样，第j步之后直接用模型的价值估计。j=0是纯模型，j=∞是纯WDR。MAGIC用自助法估计这些估计器的偏差，用样本协方差估计它们的方差，然后求一个权重向量x，使组合估计 xᵀg 的估计均方误差最小。数据少或模型好时偏向模型，数据多时偏向重要性采样。

结果

摘要称：作者给出了一种新方法，从可能由不同策略产生的历史数据预测强化学习策略的表现；实验表明该算法给出的估计常常比已有方法的均方误差低几个数量级，更有效地利用了可用数据；新估计器基于两个进展：对Jiang与Li（2015）双重稳健估计器的扩展，以及一种在基于模型的估计与基于重要性采样的估计之间混合的新方法。

后来的发展

WDR与MAGIC是离策略评估文献中最常见的基线之一；之后出现了基于拟合Q评估的估计（FQE拟合Q评估）、基于分布校正比的DICE系列（DualDICE分布修正估计等）以及边际化重要性采样，以绕开长时程累乘权重的方差问题。

局限与后续

  • 仍依赖逐步累乘的重要性权重，时程很长或策略差异很大时方差依旧很高。
    后来针对它的工作　DualDICE分布修正估计
  • 需要知道行为策略的动作概率；只有日志数据、没有记录行为概率时无法直接使用。
    后来针对它的工作　FQE拟合Q评估

读懂它需要的概念

重要性采样 偏差-方差权衡 蒙特卡洛采样 策略与价值函数 on-policy与off-policy

本篇术语

  • 离策略评估（OPE）　不实际运行目标策略，只用其他策略收集的历史数据估计目标策略的期望回报。
  • 双重稳健估计　同时用模型预测和重要性加权的估计器：只要两者之一准确，结果就无偏（或一致）。

怎么学

先补重要性采样和双重稳健策略评估；读原文第3节WDR与第4节MAGIC的混合方法；在一个小网格世界上比较IS、WIS、WDR与MAGIC在不同数据量下的均方误差。
