YOLOv6工业检测

YOLOv6: A Single-Stage Object Detection Framework for Industrial Applications
2022.09论文延伸Chuyi Li, Lulu Li, Hongliang Jiang, Kaiheng Weng, Yifei Geng, Liang Li, Zaidan Ke, Xiaolin Wei et al. · 美团待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

工业部署要在各种硬件上同时兼顾速度和精度，还要能量化，现有YOLO在重参数化结构下量化掉点明显。

方法

汇集近年网络设计、训练策略、测试技巧、量化与优化方法，构建一组从N到L、可直接部署的检测网络，经YOLO原作者许可命名为YOLOv6。

影响

YOLOv6-N在T4上以1234 FPS达到35.9% AP，YOLOv6-S以495 FPS达到43.5% AP，超过同规模的YOLOv5-S、YOLOX-S和PPYOLOE-S。

方法

YOLOX无锚框YOLO、PP-YOLOE等在YOLOv4之后继续推高实时检测的精度，但工业落地还关心不同硬件上的实际吞吐、TensorRT部署和INT8量化。

YOLOv6是美团视觉团队的技术报告。骨干和颈部采用基于RepVGG重参数化式结构重参数化的设计（EfficientRep骨干、Rep-PAN颈部）：训练时多分支、推理时合并成单路3×3卷积，适合GPU；检测头为解耦头并采用无锚框方案；标签分配使用任务对齐学习（TAL），并用自蒸馏、更长训练等策略提精度。针对重参数化网络难以量化的问题，报告还给出了量化感知训练和面向量化的重参数化改进。

摘要报告：在COCO上，YOLOv6-N在NVIDIA Tesla T4上以1234 FPS达到35.9% AP；YOLOv6-S以495 FPS达到43.5% AP，超过同规模的YOLOv5-S、YOLOX-S和PPYOLOE-S；量化版YOLOv6-S以869 FPS达到43.3% AP；YOLOv6-M/L分别为49.5%和52.3% AP。
