Tandem神经网络特征

Tandem connectionist feature extraction for conventional HMM systems
2000.06论文延伸ICASSP 2000Hynek Hermansky, Daniel P. W. Ellis, Sanjay Sharma · 俄勒冈研究生院 / 国际计算机科学研究所（ICSI）待核对
IEEE DOI ↗在交互版中打开（演化树、学习进度）

问题

神经网络擅长区分音素，GMM-HMM工具链成熟、能用全部现成的训练和自适应技术，但混合NN/HMM要求整套换成神经网络，两边的好处很难兼得。

方法

让神经网络只当特征提取器：先训练它输出音素后验概率，把这些概率取对数、去相关后当作新的特征，再交给常规训练的GMM-HMM去建模。

影响

这种「网络出特征、GMM做建模」的串联做法在2000年代广泛使用，后来演化为瓶颈特征（取网络中间一个窄层的输出），是深度学习全面接管声学模型之前的过渡路线。

方法

常规的HMM统计语音识别系统用高斯混合模型描述去相关后的声学特征（如感知线性预测PLP）；混合系统则用判别式训练的神经网络直接估计音素的后验概率（见判别模型与生成模型）。两种做法各有长处。

Tandem（串联）把两者接起来：第一步，训练一个多层感知机（见多层感知机），输入是若干帧声学特征，输出是各个音素的后验概率；第二步，把网络输出（去掉最后的softmax非线性或取对数）再经过主成分分析去相关，变成一组新的特征向量；第三步，用这组特征按常规流程训练GMM-HMM。这样神经网络带来的区分能力被保留下来，而GMM一侧的上下文相关建模、自适应等成熟技术一样能用。摘要称，在多条件Aurora带噪连续数字任务上，词错误率相对降低35%以上。

局限与后续

  • 网络与GMM分两阶段各自训练，网络并不是为最终识别准确率优化的，两部分无法联合调整。
    后来针对它的工作　深度网络声学模型
  • 实验主要在小词表的带噪数字任务上，大词汇量任务上的收益需要另行验证。
    后来针对它的工作　CD-DNN-HMM

读懂它需要的概念

多层感知机 Softmax与logits 隐马尔可夫模型 降维与PCA 判别模型与生成模型

本篇术语

  • 音素后验概率　给定一小段声音，网络估计它属于每个音素的概率，所有音素的概率加起来为1。
  • 瓶颈特征　Tandem的后续变体：在网络中间放一层很窄的隐藏层，取这一层的输出作为特征。
