LSTM

Long Short-Term Memory
1997论文主干Neural Computation 1997Sepp Hochreiter, Jürgen Schmidhuber · 慕尼黑工业大学 / IDSIA（瑞士卢加诺）来源已核对
Neural Computation（DOI） ↗原文PDF（CMU课程页） ↗Colah: Understanding LSTM Networks ↗在交互版中打开（演化树、学习进度）

问题

循环网络反向传回去的误差每走一步就乘一次小于1（或大于1）的因子，隔十几步就消失或爆炸，所以学不会输入与输出相隔很远的依赖。

方法

在网络里放一个“记忆单元”，它的状态只做加法、自连接权重恒为1，误差沿它可以原样传过任意多步（恒定误差传送带）；再用可学习的乘法门决定什么时候写入、什么时候读出。

影响

在人工构造的任务上让梯度训练的循环网络跨越了上千步的间隔（论文称此前的循环网络算法都解不了这类任务）；加上遗忘门等改进后，2010年代被广泛用于语音识别、机器翻译和语言建模，2017年后这些任务的主流模型多数转向Transformer。

背景

1990年代，训练循环网络的标准方法是随时间反向传播BPTT（沿时间展开再反向传播）或实时循环学习（RTRL）。Elman循环网络这类网络在相隔几步的依赖上表现不错，但相隔一远就失效。

原因已被分析清楚。Hochreiter在1991年的硕士论文中、梯度消失问题在1994年分别证明：误差信号从第t步传到第t−q步，要连乘q个“激活函数导数 × 循环权重”的因子。因子普遍小于1时信号指数衰减（梯度消失），大于1时指数膨胀，权重来回振荡（梯度爆炸）。比如每步因子0.9，传100步后只剩约十万分之三。

当时提出的绕路办法——模拟退火、随机搜索、时间常数网络、序列分块压缩——要么慢，要么只对有局部规律的序列有效。问题是：能不能设计一种结构，让误差在需要的地方既不衰减也不爆炸？

方法

第一步：恒定误差传送带（CEC）。对一个只连自己的单元j，误差每回传一步乘以f′(net_j)·w_jj。要让它恒等于1，最简单的办法是激活函数取恒等f(x) = x、自连接权重固定为w_jj = 1.0。于是单元的状态原样保持，误差也原样回传，多少步都不衰减。

第二步：加门。光有CEC不行：同一个输入权重既要负责“这时写进去”，又要负责“别的时候别乱写”，两种要求互相冲突（输入权重冲突）；输出端同理。解决办法是加两个乘法门，取值在0到1之间、由当前输入和网络状态决定：

  • 输入门i_t：决定当前候选内容写入多少；
  • 输出门o_t：决定记忆内容读出多少给网络其他部分。

1997年版的记忆单元：

c_t = c_(t−1) + i_t ⊙ g_t h_t = o_t ⊙ h(c_t)

其中g_t是由输入算出的候选内容，i_t = σ(W_i·[x_t, h_(t−1)] + b_i)，o_t同理，σ是sigmoid（见门控机制）。关键在第一行：∂c_t/∂c_(t−1) = 1，记忆沿时间只做加法，这就是梯度不消失的原因。

直观例子。任务：序列第1个符号是x或y，之后是1000个随机干扰符号，最后要求输出第1个符号。LSTM学会在看到x/y时打开输入门写入，之后关闭输入门让干扰符号进不来，最后打开输出门读出。中间1000步，记忆单元的值和误差都原封不动。

训练。用RTRL的一个变体，并在误差要离开记忆单元时截断梯度，只让它沿CEC长距离流动。这样每个时间步、每个权重的计算量是O(1)，在时间和空间上都是局部的。

今天用的版本多了一个遗忘门（1999–2000年Gers等人加入）：c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t，让网络能主动清空不再需要的记忆，并改用完整BPTT训练。

结果

全部实验都用人工构造的序列。嵌入式Reber文法：Elman网络成功率为0，循环级联相关约50%，RTRL只有部分成功；LSTM在150次试验中只失败2次，最快约8440个训练序列就学会。超长间隔（任务2c）：最短间隔1000步以上、中间插入1000种随机干扰符号，论文称此前没有循环网络算法能解，LSTM平均约4.9万个训练序列学会。加法问题：序列长度1000时，要把相隔至少500步的两个实数相加，在2560条测试序列上只错1条。作者同时坦白：Bengio等人的二序列问题太简单，随机猜权重比LSTM还快；强延迟的XOR这类不可分解任务，截断梯度的LSTM学不会。

后来的发展

LSTM在发表后近十年并不流行。转折来自几步改进：遗忘门让它能处理没有明确边界的长数据流；完整BPTT训练和CTC让它能直接在未对齐的语音上训练；深层双向LSTM识别用深层双向LSTM在TIMIT上刷新纪录；大规模LSTM声学模型把它推进大规模语音识别。2014年Seq2Seq用两个LSTM做机器翻译，加上注意力机制后成为谷歌神经机器翻译的骨干；语言模型方面有AWD-LSTM、ELMo。RNN编码器-解码器与GRU提出的GRU是它的简化版。之后的Highway网络网络也用门控单元来调节信息在层间的流动。

2017年Transformer以可并行训练为主要卖点出现，之后翻译和语言模型的主流多数转向它。近年的线性循环模型（Mamba状态空间模型、Gated DeltaNet）和Hochreiter本人的xLSTM又把“带门控的循环记忆”带回大模型架构讨论。

容易误解的地方

  • 1997年的原始LSTM没有遗忘门。今天教科书里带f_t的版本是1999–2000年后的改进；原版需要在每个序列开始时手动把状态清零。
  • LSTM缓解的是梯度消失；梯度爆炸在CEC之外仍可能发生，实际训练通常仍要梯度裁剪。
  • “长短期记忆”指的是能维持很久的短期记忆（激活值），不是长期记忆（权重）。

局限与后续

  • 没有遗忘门，记忆单元只能累加，面对没有分段的连续数据流时状态会无限增长，必须人为在序列边界清零。

它建立在什么之上

  • 使用
    反向传播1986 · 基础 已核对
    整体仍是梯度下降训练，只是通过结构设计让误差能在时间上走得更远。
  • 竞争
    HMM统计语音识别1976 · 语音 已核对
    当时序列建模尤其是语音的主流是隐马尔可夫模型；论文第6.2节特别指出LSTM不像HMM那样需要事先选定有限个状态。之后LSTM结合CTC等方法进入语音识别，与HMM声学模型竞争。
  • 改进
    Elman循环网络1990 · 基础 已核对
    论文实验中Elman网络在嵌入式Reber文法上成功率为0，LSTM几乎每次成功，长间隔任务上差距更大。
  • 改进
    梯度消失问题1994 · 基础 已核对
    用导数恒为1的线性自连接记忆单元，让误差沿时间原样回传，绕开了梯度连乘衰减。
  • 使用
    随时间反向传播BPTT1990 · 基础 待核对
    用截断的梯度计算（RTRL变体，与截断BPTT类似）训练，只让误差沿记忆单元长距离传播；后来改用完整BPTT。
  • 竞争
    快速权重1992 · 基础 待核对
    同一实验室的另一种记忆方案：用一个网络快速改写另一个网络的权重来存短期信息；LSTM把记忆放在门控的激活值里。
  • 改进
    香农：语言的统计模型1948 · NLP
    只看前面n−1个符号，超出窗口的句法和语义依赖完全丢失；香农自己也说再往高阶做，所需的统计“工作量变得巨大”。
  • 改进
    Hopfield网络1982 · 基础
    动力学只收敛到固定点，不能处理或生成随时间变化的序列。
  • 改进
    《并行分布式处理》1986 · 基础
    大多数模型处理的是静态输入，对语言、语音这类随时间展开的序列缺少自然的处理方式。

    Jordan循环网络1986.05 · 基础
    反馈的只是上一时刻的输出，记忆内容受限于输出的形式，也难以保存很久以前的信息。

读懂它需要的概念

循环网络与隐状态 梯度消失与梯度爆炸 反向传播 链式法则 门控机制 神经元与激活函数

本篇术语

  • 恒定误差传送带（CEC）　记忆单元里自连接权重固定为1的线性通路，状态和误差都能沿它原样传过任意多步。
  • 记忆块　共享同一对输入门和输出门的若干记忆单元，原文用它来更省参数地存储分布式信息。
  • 遗忘门　后来加入的第三个门，乘在旧状态上，取0时清空记忆、取1时完整保留，让网络能自己决定何时忘记。
  • 嵌入式Reber文法　一个人工的有限状态文法，序列开头和结尾的符号必须一致、中间夹着一段子串，用来测试网络能否记住跨越中间部分的信息。

怎么学

先补循环网络与隐状态、梯度消失与梯度爆炸和门控机制。读Colah的图解文章建立直觉，再读原文第3.2节（为什么需要CEC）、第4节（结构）和第5.4节（加法问题）。动手：用PyTorch从零写一个LSTM单元（先不加遗忘门，再加上），在“记住第一个符号、隔T步后输出”的任务上和普通RNN对比，T取10、100、500，观察谁先学不会；然后跑通《RNN不可思议的有效性》的字符级语言模型。
