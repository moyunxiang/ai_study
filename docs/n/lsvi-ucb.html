LSVI-UCB线性MDP

Provably Efficient Reinforcement Learning with Linear Function Approximation
2019.07论文延伸COLT 2020Chi Jin, Zhuoran Yang, Zhaoran Wang, Michael I. Jordan · UC Berkeley / 普林斯顿大学 / 西北大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

表格探索理论（UCBVI极小极大遗憾界、Q学习的UCB遗憾界）的遗憾都随状态数S增长，而实际问题的状态数是天文数字，必须用函数近似；可即便在动力学和奖励都是线性的最基本设定下，也没有既多项式时间又多项式样本、且不需要模拟器的可证明算法。

方法

在“线性MDP”假设下（转移和奖励对一个已知特征 φ(s,a) 线性），把经典的最小二乘值迭代（LSVI）改成乐观版本：每一步用岭回归拟合Q函数，再加上一个与特征在已见数据上的不确定性成正比的奖励 β·‖φ(s,a)‖_{Λ⁻¹}，形同把LinUCB上下文老虎机搬进多步决策。

影响

给出了线性函数近似下第一个多项式时间、多项式样本的可证明RL算法，遗憾 Õ(√(d³H³T)) 与状态数和动作数无关；线性MDP与LSVI-UCB成为此后函数近似RL理论（包括离线RL的PEVI悲观值迭代）的基础设定和标准算法。

背景

函数近似引入了统计和计算两方面的难题：表格方法靠对每个状态-动作计数来构造置信区间，状态无穷多时这条路走不通。线性老虎机（LinUCB上下文老虎机、OFUL线性老虎机）已经展示了在线性模型下如何用“特征方向上的不确定性”替代计数，但多步决策中误差会通过Bellman备份逐步传播，而且拟合目标本身依赖于后续步骤的估计，线性老虎机的分析不能直接套用。

方法

线性MDP假设：存在已知特征 φ(s,a) ∈ ℝ^d，使得 P_h(s'|s,a) = ⟨φ(s,a), μ_h(s')⟩、r_h(s,a) = ⟨φ(s,a), θ_h⟩。在这个假设下，任何策略的Q函数都对φ线性。

算法：每一局开始时，从最后一步往前，对每个h用之前所有局的数据做岭回归：

Λ_h = Σ_τ φ(s_h^τ, a_h^τ) φ(s_h^τ, a_h^τ)^T + λI w_h = Λ_h⁻¹ Σ_τ φ(s_h^τ, a_h^τ) · [ r_h^τ + max_a Q_{h+1}(s_{h+1}^τ, a) ]

然后令 Q_h(s,a) = min( ⟨w_h, φ(s,a)⟩ + β·√(φ(s,a)^T Λ_h⁻¹ φ(s,a)), H )，并在这一局按Q贪心行动。奖励项 ‖φ‖_{Λ⁻¹} 衡量特征φ所在方向上已有数据的多少：方向上数据越多，这一项越小。

分析的难点是回归目标里的 max_a Q_{h+1} 本身依赖数据，作者用对Q函数类做覆盖数论证来控制这一依赖，从而选出 β = Õ(dH)。

结果

摘要称，乐观的LSVI达到 Õ(√(d³H³T)) 遗憾，d是特征维度，H是每局长度，T是总步数；这一遗憾与状态数和动作数无关，是该线性设定下第一个兼具多项式运行时间和多项式样本复杂度、且无需模拟器或额外假设的可证明RL算法。

后来的发展

此后的线性函数近似理论大多以线性MDP或其变体为起点，改进d和H的依赖、扩展到一般函数类（Bellman秩、Eluder维度等）；把奖励项变号用作惩罚，就得到离线RL中的悲观值迭代PEVI悲观值迭代。

局限与后续

  • 线性MDP要求转移对已知特征精确线性，这个假设很强，实际问题里几乎不成立，误设时保证会退化。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 遗憾对d的依赖是d^{3/2}，比下界的d多一个√d；每步要对所有动作计算奖励并做回归，大动作空间下计算量大。

读懂它需要的概念

探索与利用 线性回归 马尔可夫决策过程 正则化与权重衰减 时间与空间复杂度

本篇术语

  • 线性MDP　一种结构假设：转移概率和奖励都可以写成已知特征φ(s,a)与未知参数的内积，从而所有Q函数都对φ线性。
  • 岭回归　带L2正则的最小二乘回归，解为 (ΦᵀΦ + λI)⁻¹Φᵀy；正则项保证矩阵可逆。

怎么学

先学LinUCB上下文老虎机的置信椭球；读原文第3节算法和第4节主要定理，跳过覆盖数的技术细节；在一个用one-hot特征表示的小MDP上实现LSVI-UCB（此时退化为表格情形），与UCBVI极小极大遗憾界对比。
