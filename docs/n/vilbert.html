ViLBERT

ViLBERT: Pretraining Task-Agnostic Visiolinguistic Representations for Vision-and-Language Tasks
2019.08论文延伸NeurIPS 2019Lu, Batra, Parikh, Lee · 佐治亚理工 / FAIR待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

每个视觉语言任务都从头训练专用模型，没有像语言领域那样可迁移的通用预训练表示。

方法

把BERT扩成两条流，图像一条、文字一条，之间用共注意力层交换信息，在Conceptual Captions上预训练，再用小改动迁移到多个任务。

影响

证明了预训练加微调的范式可用于视觉语言，并在四项任务上都刷新当时最好成绩。

方法

ViLBERT有两条并行的Transformer流：文字流是普通的BERT，视觉流读取Faster R-CNN检测出的区域特征。关键是共注意力层：在这些层里，视觉流的查询去注意文字流的键值，文字流的查询去注意视觉流的键值，从而图像区域和词互相读取，但两条流的深度和宽度可以不同。

预训练用自动收集的 Conceptual Captions 数据集，设置两个代理任务：遮住部分词或区域后预测它们，以及判断图文是否匹配。预训练完成后，只给基础结构加很小的任务层，就能迁移到视觉问答、视觉常识推理、指代表达和基于文字的图像检索。摘要称在四个任务上都达到当时最好，并强调这是从为每个任务单独设计模型转向学习通用表示。

它建立在什么之上

  • 延续
    BERT2018.10 · LLM
    把BERT扩成图文两条流，并加入共注意力。
  • 使用
    Faster R-CNN2015.06 · 视觉
    使用检测出的区域特征作为视觉输入。
  • 使用
    自底向上注意力2017.07 · 多模态
    使用其区域特征提取流程。
  • 改进
    图文联合嵌入VSE2014.11 · 多模态
    嵌入由整图向量得到，无法细致对齐图像区域和词。
  • 改进
    双线性池化MCB2016.06 · 多模态
    随机投影后的融合向量维度很高，参数和显存开销大。
  • 改进
    MAttNet2018.01 · 多模态
    三个固定模块不能覆盖任意复杂的语言。
