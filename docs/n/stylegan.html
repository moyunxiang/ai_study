StyleGAN

A Style-Based Generator Architecture for Generative Adversarial Networks
2018.12论文重要CVPR 2019Tero Karras, Samuli Laine, Timo Aila · NVIDIA待核对
arXiv ↗官方代码与FFHQ数据集 ↗在交互版中打开（演化树、学习进度）

问题

ProGAN已能生成1024×1024人脸，但生成器像个黑箱：隐向量直接从输入层灌进去，姿态、发型、肤色、雀斑等属性纠缠在一起，无法分别控制，也说不清网络如何组织这些信息。

方法

借鉴风格迁移重新设计生成器：先用8层MLP把噪声z映射成中间向量w，再通过AdaIN在每个分辨率层分别注入w作为“风格”，另给每层加随机噪声负责发丝等随机细节，输入改为一个学到的常数。

影响

生成的人脸逼真到普通人难辨真伪，出现了“这个人不存在”式的展示网站；粗、中、细三级风格可分别控制，W空间成为GAN图像编辑与反演研究的基础；同时发布的FFHQ成为人脸生成标准数据集。

背景

渐进式增长GAN通过渐进式增长把GAN推到了1024×1024，但生成器结构仍沿用DCGAN以来的传统设计：随机向量z从第一层输入，经过一层层卷积放大成图像。z必须服从固定的高斯分布，而训练数据中各属性的组合并不均匀（比如长发男性很少），网络为了把均匀的z空间“扭”成不均匀的数据分布，只能让各属性纠缠在一起：沿z的某个方向走，可能同时改变了性别、年龄和背景。

另一方面，风格迁移领域发现，用AdaIN（自适应实例归一化）调整特征图的均值和方差，就能控制图像的“风格”（参见神经风格迁移中Gram矩阵统计量的思想）。

方法

映射网络。z（512维）先经过一个8层MLP得到w（也是512维）。w不必服从高斯分布，可以“自由弯曲”以匹配数据中属性的真实分布，因而更容易解耦。

AdaIN注入风格。合成网络从一个学到的4×4×512常数张量开始（不再从z输入），每个卷积层之后，用w经仿射变换得到每个通道的缩放y_s和偏移y_b：

AdaIN(x_i, y) = y_{s,i} · (x_i − μ(x_i)) / σ(x_i) + y_{b,i}

即先把每个特征图归一化，再用风格设定它的均值和方差。每个分辨率层的风格都单独来自w，于是低分辨率层（4²–8²）控制姿态、脸型，中间层控制五官与发型，高分辨率层控制配色和微观纹理。

噪声输入。每层加一张单通道高斯噪声图，并学习各通道的缩放。头发具体落在哪、雀斑和毛孔的位置这类随机细节由噪声负责，不必消耗w的容量。

风格混合正则。训练时部分图像用两个w：在某个随机层之前用w₁，之后用w₂，阻止网络假设相邻层风格相关。生成时可以把A的姿态与B的配色组合。

截断技巧。把w向平均脸拉近：w' = w̄ + ψ(w − w̄)，ψ<1时牺牲多样性换取质量（论文中的FID都不用截断计算）。

结果

在逐步消融中（表1），FFHQ上的FID从ProGAN基线的8.04依次降为：调参与双线性采样5.25、加映射网络与风格4.85、去掉传统输入4.88、加噪声4.42、加风格混合4.40；CelebA-HQ上从7.79降到5.06左右。论文提出感知路径长度和线性可分性两个解耦指标，用来说明W空间比Z空间更解耦。新数据集FFHQ含7万张来自Flickr的1024×1024人脸，比CelebA-HQ在年龄、种族、配饰上更多样。训练在一台8块Tesla V100的DGX-1上约需一周。

后来的发展

StyleGAN2发现AdaIN会产生“水滴”状伪影、渐进式增长会让细节粘在固定位置，于是改为权重调制和不增长的跳连结构；StyleGAN2-ADA小数据训练用自适应数据增强让它在几千张图上也能训练；StyleGAN3无混叠解决了纹理随坐标“粘住”的混叠问题。W空间被广泛用于真实图像反演与编辑，DragGAN拖拽编辑在它之上实现拖拽式编辑，EG3D三维感知GAN把它扩展为三维感知生成。逼真人脸的大量生成也加剧了Deepfake出现相关的担忧。扩散模型兴起后，StyleGAN在通用文生图上被取代，但在人脸等单领域、需要实时生成或可控编辑的场景仍被使用；GigaGAN尝试把这一架构扩展到文生图。

读懂它需要的概念

对抗训练 潜空间 归一化层 多层感知机 卷积层、池化与感受野 生成质量指标：IS与FID

本篇术语

  • AdaIN　自适应实例归一化：先把每个特征图归一化到零均值单位方差，再用外部给定的缩放与偏移重新设定均值和方差。
  • W空间　映射网络输出的中间隐空间。比原始的高斯噪声空间更解耦，常用于图像编辑和把真实照片反演进GAN。
  • 截断技巧　把隐向量向平均值拉近，样本更稳定好看，但多样性下降。

怎么学

先读渐进式增长GAN，补归一化层和潜空间。原文第2节（生成器结构）和图1、图3（风格混合）最重要，第4节讲两个解耦指标。动手：下载官方预训练FFHQ模型，在两个w之间做风格混合，分别交换粗、中、细层，观察各控制什么；再试不同ψ的截断效果。
