TANGO文生音频

Text-to-Audio Generation using Instruction-Tuned LLM and Latent Diffusion Model
2023.04论文延伸ACM MM 2023Deepanway Ghosal, Navonil Majumder, Ambuj Mehrish, Soujanya Poria · 新加坡科技设计大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

文生音频模型的文本编码器要么是专门联合训练的文本-音频编码器（如CLAP），要么是普通的T5，对复杂描述（先后顺序、多个声源）理解不足，而且训练数据规模很大。

方法

直接拿经过指令微调的大语言模型Flan-T5作为冻结的文本编码器，接一个潜在扩散模型生成音频；训练时按声压级来混合两段音频做数据增强。

影响

TANGO用小得多的数据量在AudioCaps上超过AudioLDM的大多数指标，说明文本编码器的语言理解能力是文生音频的关键因素，后续多个文生音频模型都改用大语言模型类的文本编码器。

方法

AudioLDM用CLAP音频-文本对比的文本嵌入作为扩散模型的条件，其他工作如AudioGen用T5编码文字。TANGO的出发点是：经过指令微调的Flan-T5与指令规模化在零样本和少样本任务上理解能力更强，也许能更好地读懂「一只狗叫了几声，接着有汽车驶过」这类描述。

结构上，文本先经冻结的Flan-T5编码成一串向量；一个UNet结构的潜在扩散模型（见潜空间扩散LDM与扩散：前向加噪与反向去噪）通过交叉注意力读取这些向量，在梅尔频谱的VAE潜空间中去噪，最后由声码器还原成波形。只训练扩散模型，文本编码器保持不动。数据增强方面，以往做法是随机混合两段音频并拼接描述；TANGO按两段音频的声压级来决定混合比例，避免一段声音把另一段完全盖住。

摘要报告：在AudioCaps测试集上，TANGO在大多数指标上优于当时最好的AudioLDM、其余指标相当，而它的扩散模型训练数据小63倍，文本编码器保持冻结。同组后来又推出了用偏好优化微调的版本（未核对）。

局限与后续

  • 只在AudioCaps这类规模有限的数据上训练，对音乐和语音的生成能力弱，覆盖的声音种类有限。
    后来针对它的工作　AudioLDM 2 Stable Audio Open
  • 扩散模型需要多步去噪，生成速度慢，片段长度也受限。
