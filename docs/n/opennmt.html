OpenNMT

OpenNMT: Open-Source Toolkit for Neural Machine Translation
2017.01系统延伸Klein, Kim, Deng, Senellart, Rush · Harvard NLP / SYSTRAN待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经机器翻译的代码多是研究者各自的实验脚本，难复现、难扩展，工业界难以直接采用。

方法

发布开源NMT工具包，强调效率、模块化和可扩展性，并附详细的教学文档。

影响

成为NMT研究和部署中广泛使用的开源基础，降低了入门和复现门槛。

方法

OpenNMT由哈佛NLP组与SYSTRAN合作开发，它把Seq2Seq、Luong注意力式注意力、多层LSTM、双向编码器等做成可配置模块，提供训练、翻译、数据预处理的完整流水线，并强调在合理硬件上能训练出有竞争力的模型。论文摘要称工具包支持模型结构、特征表示和输入模态（如图像、语音）的研究，同时保持有竞争力的性能和合理的训练开销，并附有说明底层技术的教学文档。

对读者最直接的价值是：想亲手跑一个神经翻译系统，可以先读它的教程再看源码。
