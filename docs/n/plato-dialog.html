PLATO对话预训练

PLATO: Pre-trained Dialogue Generation Model with Discrete Latent Variable
2019.10论文延伸ACL 2020Siqi Bao, Huang He, Fan Wang, Hua Wu, Haifeng Wang · 百度待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

对话回复是「一对多」的：同一句「今天好累」可以回安慰、回建议、回追问。直接用最大似然训练的生成模型会把这些可能性平均掉，倾向于输出「哈哈」「我也是」这类空洞回复。

方法

给对话预训练加入一个离散隐变量 z（K个取值，代表不同的「回复意图」）：模型先根据上下文和回复推断 z（隐动作识别），再以上下文和 z 为条件生成回复；两个任务共享一个统一的Transformer，靠灵活的注意力掩码同时实现双向理解和单向生成。

影响

PLATO系列（PLATO、PLATO-2、PLATO-XL）是中英文开放域对话预训练的代表模型之一，百度据此做了小度等产品中的闲聊能力；「用离散隐变量建模一对多」是对话生成中常被引用的做法。

背景

DialoGPT在Reddit对话上继续训练GPT-2，BlenderBot开放域对话把规模推到更大，但它们都只学 P(回复 | 上下文) 的单一分布。早期研究用连续隐变量的变分自编码器VAE（如CVAE）建模回复多样性，但连续隐变量在强解码器下容易被忽略（后验坍塌），而且难以解释。UniLM展示了一个Transformer可以通过不同的注意力掩码同时做理解和生成。

方法

输入：上下文、回复和隐变量 z 的嵌入拼在一起，再加上角色嵌入（谁在说话）和轮次嵌入。

注意力掩码：上下文内部双向可见；回复只能看见上下文、z 和自己左边的词（单向）。

三个训练任务（共享参数）：

1. 隐动作识别：输入上下文和回复，在[M]位置预测 z 的后验 q(z | c, r)，z 取K个离散值之一（论文中K=20），用Gumbel-Softmax使采样可导； 2. 回复生成：给定上下文和采样的 z，自回归生成回复，损失为 −log p(r | c, z)，并加一个词袋损失让 z 对回复内容有足够预测力； 3. 训练时两者交替进行。

推理：对每个可能的 z 各生成一个候选回复，再用一个打分模型（评估回复与上下文的连贯性）挑出最好的。

预训练语料来自Reddit和Twitter的大规模对话，并从BERT初始化。

结果

摘要称：在闲聊（Persona-Chat）、知识对话和对话式问答三个公开数据集上的综合实验验证了框架的有效性和优越性。具体数字未核对。

后来的发展

PLATO-2（2020）用课程学习先训一对一再训一对多，扩到16亿参数；PLATO-XL（2021）把对话模型推到110亿参数，中英文都有。ChatGPT出现后通用指令模型接管了闲聊场景，但「离散隐变量表示回复意图、生成多个候选再重排」的思路仍出现在可控对话和多样性生成研究中。

读懂它需要的概念

隐变量模型 离散变量的梯度：直通估计与Gumbel-Softmax 预训练与微调 自注意力与多头注意力 自回归生成

本篇术语

  • 一对多映射　同一段对话上下文可以有很多种合理回复，生成模型需要表示这种多样性，而不是只学一个平均答案。
  • 隐动作识别　PLATO中根据上下文和真实回复推断离散隐变量取值的任务，相当于判断这句回复属于哪一种「回复方式」。

怎么学

先了解DialoGPT和离散变量的梯度：直通估计与Gumbel-Softmax → 读原文第3节三个任务和注意力掩码 → 动手：用开源的PLATO-2中文或英文模型，对同一句话分别指定不同的隐变量取值生成回复，观察差异。
