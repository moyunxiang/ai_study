StarCoder2与Stack v2

StarCoder 2 and The Stack v2: The Next Generation
2024.02论文延伸arXiv 2024Anton Lozhkov, Raymond Li, Loubna Ben Allal 等 · BigCode / Hugging Face / ServiceNow 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

第一代StarCoder的训练数据规模有限，且代码来源与许可的透明度需要继续提高。

方法

与Software Heritage合作构建The Stack v2（覆盖619种语言，数据量是前代的约4倍），训练3B、7B、15B三个模型。

影响

在开源、可追溯数据的前提下，15B模型追平甚至超过更大的CodeLlama-34B。

方法

The Stack v2建立在Software Heritage的源代码归档上，除了仓库代码，还加入GitHub拉取请求、Kaggle笔记本和代码文档等高质量来源，覆盖619种编程语言，训练集比第一代大约4倍。作者公开了数据对应的SWHID（持久标识符），方便追溯来源和让作者退出。

训练了3B、7B、15B三个模型，token数为3.3到4.3万亿。摘要称StarCoder2-3B在多数基准上超过同规模代码模型，也超过StarCoderBase-15B；15B模型匹配或超过CodeLlama-34B。在高资源语言的代码补全上，DeepSeekCoder-33B最好，但StarCoder2-15B在数学与代码推理及一些低资源语言上更强。权重以OpenRAIL许可发布。

局限与后续

  • 依然在函数级补全基准上评测为主，仓库级、多文件任务能力有限。
    后来针对它的工作　Qwen2.5-Coder
  • 开放数据带来许可和版权争议，退出机制只覆盖作者主动申请的情况。
    本站还没有记录针对它的后续工作（不代表没有人解决）
