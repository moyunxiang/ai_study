PGD对抗训练

Towards Deep Learning Models Resistant to Adversarial Attacks
2017.06论文重要ICLR 2018Aleksander Madry, Aleksandar Makelov, Ludwig Schmidt, Dimitris Tsipras, Adrian Vladu · MIT待核对
arXiv ↗MNIST挑战赛 ↗CIFAR10挑战赛 ↗在交互版中打开（演化树、学习进度）

问题

2014–2017年提出的对抗防御一个接一个被更强的攻击击穿；用FGSM与线性解释做的对抗训练只能防住FGSM本身，大家连“鲁棒”应该怎么定义、怎么检验都没有共识。

方法

把鲁棒性写成一个最小最大问题：内层找邻域内让损失最大的扰动，外层训练模型让这个最坏损失最小；内层用多步投影梯度下降（PGD）尽量解准，再在这些最坏样本上训练。

影响

PGD成了评估防御的标准攻击，PGD对抗训练成了此后多年最可靠的经验防御，它的最小最大表述也成为鲁棒性研究的通用语言。

背景

对抗样本发现深度网络可以被不可察觉的扰动骗过之后，防御方法层出不穷：蒸馏防御、输入变换、检测器……但C&W攻击用更强的优化攻击击穿了其中许多。FGSM与线性解释提出的对抗训练用一步梯度符号生成训练样本，结果模型学会了专门对付这一种弱攻击，换成多步攻击仍然脆弱。

根本问题是没有清晰的目标：“防住攻击”到底是防住哪些攻击？防御者每次只针对已知攻击打补丁，攻击者换个方法就能绕过。这篇论文要回答的是：能否给鲁棒性一个精确的定义，并找到一种在这个定义下有原则的训练方法。

方法

最小最大表述。设S是允许的扰动集合，这里取每个像素改动不超过ε的L∞球。鲁棒训练的目标是

min_θ E_(x,y)[ max_{δ∈S} L(θ, x + δ, y) ]

内层的max是攻击者：在邻域里找让损失最大的扰动；外层的min是防御者：调整参数θ，让最坏情况下的损失也小。这个表述把以前各种攻击和防御都统一起来——FGSM就是只走一步去近似内层max。

PGD攻击。内层用多步迭代：从x附近的一个随机点出发，每一步沿损失梯度的符号走一小步α，再投影回允许的邻域内（超出ε的部分截掉）：

x_{t+1} = Π_{x+S}( x_t + α·sign(∇ₓ L(θ, x_t, y)) )

作者做了大量随机重启实验，发现PGD找到的局部最大值的损失值高度集中、彼此相近，说明一阶方法虽然解不出全局最优，但能可靠地找到“差不多最坏”的点。于是他们把PGD定位为“一阶攻击者”的代表：能防住PGD，就有理由认为能防住所有只用梯度信息的攻击。

训练。每个小批量先用PGD为每个样本找到最坏扰动，再在这些样本上做一步梯度下降。根据Danskin定理，内层最大值处的梯度就是外层问题的下降方向。MNIST上用40步、步长0.01、ε = 0.3；CIFAR10上用7步、步长2、ε = 8（像素按0–255计）。

模型容量。实验发现，要抵御强攻击，网络需要比只做正常分类大得多的容量；CIFAR10上用了宽度放大10倍的ResNet。

结果

MNIST（ε = 0.3）：正常训练的网络干净准确率99.2%，遇到FGSM降到6.4%。PGD对抗训练后，干净准确率98.8%，面对最强的白盒攻击（100步、20次随机重启的PGD）仍有89.3%，黑盒攻击下在95%以上。

CIFAR10（ε = 8）：干净准确率87.3%，面对20步PGD白盒攻击仍有45.8%，用C&W攻击损失的攻击下为46.8%。作者把两个模型连同代码公开为挑战赛，邀请任何人来攻击，以便更准确地评估它们的鲁棒性。

后来的发展

PGD对抗训练是为数不多经受住时间考验的经验防御。2018年梯度混淆的虚假安全审查了ICLR 2018收录的9个白盒防御，发现其中7个依赖梯度混淆，6个被完全绕过；PGD对抗训练不依赖这种技巧，成为此后评估新防御时必须比较的基线。之后的工作在此基础上改进训练目标和效率，也用它研究鲁棒性与准确率的取舍。

它还带来了新的认识：对抗样本是特征不是bug用PGD训练出的鲁棒模型说明，对抗脆弱性来自模型依赖了数据中人类看不见的“非鲁棒特征”。另一方面，它只能给出经验上的鲁棒性，随机平滑认证鲁棒性等方法则转向可证明的保证。在大语言模型上，“用最强攻击来训练”的思路延续到针对越狱攻击的防御中，而熔断器：表示重定向等工作则尝试绕开对抗训练、直接改写有害表示。

容易误解的地方

  • “能防住PGD”是经验结论，不是证明。论文自己就发现，在L2攻击下MNIST模型学到的阈值滤波器会遮蔽梯度，PGD高估了它的鲁棒性。
  • 鲁棒性只针对训练时设定的扰动类型和大小：L∞、ε = 8训练的模型，对旋转、贴片或更大的ε没有保证。
  • CIFAR10上鲁棒准确率不到一半，而干净准确率也从正常训练的水平降到87.3%，鲁棒性是有代价的。

读懂它需要的概念

对抗训练 梯度下降 范数与距离 损失函数 随机梯度下降与小批量 参数量、计算量与显存

本篇术语

  • 投影梯度下降（PGD）　每走一步梯度后，把结果投影回允许的集合（这里是以原图为中心、半径ε的L∞球），保证扰动始终合法的迭代优化方法。
  • 白盒 / 黑盒攻击　白盒攻击者知道模型全部参数、能求梯度；黑盒攻击者只能用别的模型生成对抗样本再迁移过来，或只能查询输出。
  • Danskin定理　优化理论中的结论：对max函数求梯度，可以在取到最大值的点处对原函数求梯度。它为“先找最坏样本、再在它上面求梯度”提供了依据。

怎么学

先读FGSM与线性解释，理解单步攻击。然后读本文第2节的最小最大表述和第3节的随机重启实验。动手：在MNIST上实现PGD攻击，比较FGSM与PGD在正常模型上的成功率；再做一遍PGD对抗训练，观察干净准确率和鲁棒准确率的变化。
