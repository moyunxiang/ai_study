H-Net动态分块

Dynamic Chunking for End-to-End Hierarchical Sequence Modeling
2025.07论文延伸arXiv 2025Sukjun Hwang, Brandon Wang, Albert Gu · Carnegie Mellon University / Cartesia AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

语言模型仍依赖分词器这个手工预处理步骤，它不随任务学习，对中文、代码、DNA等分词规则弱的数据尤其差。

方法

让模型直接读字节，由网络自己学习在哪里切块（动态分块），逐级压缩成高层表示，再还原回字节，整体端到端训练。

影响

第一次让无分词器的字节级模型在计算量和数据量匹配时超过BPE词元的Transformer。

方法

分词与token（如BPE子词切分）把文字切成固定词表里的片段，是语言模型里少数没有被学习的环节。字节潜变量BLT已经用熵来切字节块，但切块规则仍是启发式的。

H-Net把整个“分词器—语言模型—反分词器”流程换成一个层次化网络：底层的小编码器处理字节，一个动态分块模块根据相邻向量的相似度判断此处是否是边界，只把边界处的向量送到中层，中层的主网络在更短的序列上计算，再由解码器上采样回字节。切块和网络其余部分一起端到端训练。底层大量使用Mamba-2与状态空间对偶这类状态空间层处理长字节序列。

摘要称：计算量和数据量匹配时，单层级的字节级H-Net超过基于BPE的强Transformer；多层级后在数据扩展上更好，可匹配两倍大小的词元Transformer。在中文、代码和DNA上优势更大，DNA上数据效率约提高4倍。

局限与后续

  • 字节序列远长于词元序列，训练和推理的工程实现比标准Transformer复杂。

  • 实验主要是英文预训练和中小规模，更大规模下的收益尚无定论。

它建立在什么之上

  • 改进
    CANINE字符级编码器2021.03 · LLM
    只做了编码器，不能直接用于生成；下采样倍数固定为4，不随文本内容自适应，后来的字节级生成模型改为动态或按熵分块。
  • 使用
    Mamba-2与状态空间对偶2024.05 · 基础
    在字节级的高分辨率层用状态空间层，避免注意力在长字节序列上的平方开销。
  • 改进
    字节潜变量BLT2024.12 · LLM
    把BLT里依赖熵阈值的切块，换成与网络联合训练、可学习的动态分块。
  • 改进
    SuperBPE超词切分2025.03 · NLP
    仍是基于频率的静态切分，无法根据上下文动态决定切多大的块。
