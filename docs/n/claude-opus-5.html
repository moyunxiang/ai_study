Claude Opus 5

Introducing Claude Opus 5

官方公告 ↗在交互版中打开（演化树、学习进度）

问题

Opus级模型成本高，日常使用时用户常在“够强但太贵”和“便宜但不够强”之间取舍。

方法

Opus 5以与前代Opus 4.8相同的价格给出大幅提升的性能，接近Claude Fable 5的前沿智能而价格只有一半，并通过effort设置调节智能与token消耗。

影响

官方称在Frontier-Bench和GDPval-AA上达到最优，成为Claude Max的默认模型。

方法

2026年7月24日，Anthropic发布Claude Opus 5。官方称它是一个“有思考、主动”的模型，接近Claude Fable 5的前沿智能，价格只有一半；在Frontier-Bench、GDPval-AA等编码和知识工作评测上是新的最优，但在网络安全任务上仍落后于Mythos 5。它是Claude Max的新默认模型，也是Claude Pro里最强的模型。

与前代Opus 4.8相比，价格不变、性能大幅提高。官方称：在Frontier-Bench v0.1上超过所有其他模型，表现是Opus 4.8的两倍多且单任务成本更低；在CursorBench 3.2上，最高努力档的得分与Fable 5峰值相差不到0.5%，成本只有一半；在检验新问题求解的ARC-AGI 3上，得分是第二名的三倍；在计算机使用基准OSWorld 2.0上以略多于三分之一的成本超过Fable 5的最好成绩。用户可用effort设置，在智能和省token之间取舍。以上均为官方自述。
