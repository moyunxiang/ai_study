标准化流

Variational Inference with Normalizing Flows
2015.05论文重要ICML 2015Danilo Jimenez Rezende, Shakir Mohamed · Google DeepMind待核对
arXiv ↗Papamakarios et al.：Normalizing Flows综述 ↗Lilian Weng：Flow-based Deep Generative Models ↗在交互版中打开（演化树、学习进度）

问题

VAE的近似后验被限定为对角高斯，真实后验往往是多峰、弯曲的，近似得不准就会让变分下界与真实似然之间留下很大差距。

方法

从一个简单高斯出发，连续施加K个可逆变换，用变量替换公式精确追踪每一步的密度变化，得到一个任意复杂、但仍能采样和计算密度的后验分布。

影响

确立了“标准化流”这个名字和用可逆变换链构造分布的框架，引出IAF、RealNVP、Glow等一整类流模型，并延续到今天的连续流与流匹配。

背景

变分自编码器VAE用编码器输出一个对角高斯q(z|x)来近似真实后验p(z|x)。对角高斯意味着各维度独立、只有一个峰。可是真实后验常常是弯曲的、多峰的：比如一张模糊的“1/7”图像，后验应该在“1”和“7”两处各有一个峰。用单峰高斯去近似，ELBO与真实对数似然之间的差距（就是那个KL项）就降不下来，作者认为这正是变分推断效果常常不如MCMC的主要原因。

此前的改进办法要么只加一点相关性（全协方差高斯），要么用混合分布，但计算代价高、表达力仍有限。同期的NICE可逆耦合层已经用可逆耦合层构造了能精确算似然的生成模型，但它是用在数据空间上，而不是用来改进变分后验。

方法

变量替换公式（见可逆流与流匹配）。如果z' = f(z)是一个光滑可逆函数，那么

q(z') = q(z) · |det ∂f/∂z|⁻¹

直观地说：变换把某个区域拉大了，概率质量不变，密度就要相应变小，拉伸倍数就是雅可比行列式（见雅可比矩阵与海森矩阵）。连续做K次变换，对数密度只是逐项相加：

ln q_K(z_K) = ln q₀(z₀) − Σ_k ln|det ∂f_k/∂z_{k−1}|

“流”指概率密度沿着这串变换流动，“标准化”指它始终保持积分为1。

行列式要便宜。一般D维矩阵的行列式要O(D³)计算。论文设计了两种行列式只需O(D)的变换：

  • 平面流：f(z) = z + u·h(wᵀz + b)，h是tanh之类的非线性。它沿着一个超平面的法向把空间压缩或拉伸。雅可比行列式是|1 + uᵀψ(z)|，其中ψ(z) = h'(wᵀz + b)·w。
  • 径向流：围绕某个参考点z₀把空间径向收缩或扩张。

用于VAE。编码器除了输出μ、σ，还输出这K个变换的参数。采样时先按重参数化得到z₀，再依次经过K个变换得到z_K；ELBO中多出来的就是各步对数行列式之和，仍然可以用反向传播优化。

论文还指出，当K趋于无穷、每步无限小时，朗之万动力学和哈密顿蒙特卡洛也可以看作一种流，而且其极限分布就是真实后验——这把变分推断与MCMC联系了起来。

结果

在二值化MNIST上（40维隐变量），对角高斯后验的DLGM负对数似然上界为89.9，加入K=10、20、40、80个平面流后依次降到87.5、86.5、85.7、85.1，流越长越好；同样长度下用NICE式变换为88.6到87.2，不如平面流。在二维的非高斯玩具分布上，平面流用少得多的参数就能达到与NICE相近的拟合效果。CIFAR-10小图块上同样观察到流越长似然越好。

后来的发展

很快出现了更强的流：逆自回归流IAF用自回归结构让每一层都能表达更复杂的依赖，更适合高维隐变量；标准化流RealNVP与Glow把可逆耦合层直接用在图像像素上，得到能精确算似然、一步采样的图像生成模型；FFJORD连续标准化流把离散的K步变成连续时间的常微分方程。2022年的Flow Matching与整流Rectified Flow沿用“从高斯连续变形到数据”的思想，但换了一种不需要计算行列式的训练方式，成为Stable Diffusion 3、FLUX等模型的训练框架。

局限与后续

  • 平面流和径向流每一层只能做很简单的形变，高维隐空间里需要堆非常多层才有明显效果。
    后来针对它的工作　逆自回归流IAF
  • 论文只把流用于改进变分后验，没有用它直接为高维图像建模并精确计算似然。
    后来针对它的工作　标准化流RealNVP Glow
  • 平面流没有解析逆变换，只能单向计算密度，不能从数据反推隐变量。
    后来针对它的工作　标准化流RealNVP
  • 为了保证行列式便宜，变换的形式受到严格限制，表达力与计算代价之间的取舍始终存在。
    后来针对它的工作　FFJORD连续标准化流 Flow Matching

读懂它需要的概念

变分推断与ELBO 重参数化技巧 雅可比矩阵与海森矩阵 可逆流与流匹配 高斯分布 隐变量模型

本篇术语

  • 变量替换公式　随机变量经可逆变换后，新密度等于旧密度除以变换的雅可比行列式的绝对值。
  • 平面流　f(z) = z + u·h(wᵀz + b)：沿着一个方向推挤空间的一层简单可逆变换，行列式只需O(D)计算。

怎么学

先复习雅可比矩阵与海森矩阵中的行列式与一维变量替换（p_y(y) = p_x(x)/|dy/dx|），并读懂变分自编码器VAE。然后读原文第3节（流的定义、平面流和径向流）和第4节（用于推断）。动手：用PyTorch实现平面流，在二维平面上把标准高斯拟合到论文图3那种环形或双峰能量函数，观察K=2、8、32时的差别。
