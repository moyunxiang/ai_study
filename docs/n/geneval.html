GenEval

GenEval: An Object-Focused Framework for Evaluating Text-to-Image Alignment
2023.10数据集延伸NeurIPS 2023Dhruba Ghosh, Hannaneh Hajishirzi, Ludwig Schmidt · 华盛顿大学 / Allen AI待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

FID与CLIPScore只给整体分，看不出文生图模型是否画对了物体个数、位置和颜色，人工评测又太贵。

方法

用现成的目标检测等判别模型检查生成图里的物体是否共现、位置、数量与颜色是否符合提示，自动给出实例级评分。

影响

成为评测文生图对齐能力的常用自动基准，SD3等后续模型的报告里常用它的分数。

方法

GenEval是以物体为单位的评测框架：对每条提示（如「两只狗和一个蓝色的长椅」），它先让被测模型生成图像，再用目标检测模型找出图中的物体，检查是否出现了要求的物体、数量对不对、相对位置对不对；必要时再接别的判别模型（如颜色分类）验证颜色等属性。

作者发现这种自动判断与人类评判一致度高，并用它评测了多个开源文生图模型：近期模型在这些任务上进步明显，但在空间关系和属性绑定等复杂能力上仍不足。它与T2I-CompBench目标相近，方法更偏向用检测器直接核对，参照的是FID与Inception Score和CLIPScore只能给整体分的不足；被测模型以Stable Diffusion开源系为主。

局限与后续

  • 只覆盖物体、数量、位置、颜色等简单可检测属性，无法评测风格、文字渲染、抽象概念和细致细节。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 准确度受检测模型限制，漏检或误检会直接变成对被测模型的错误评价，模型进步后分数容易饱和。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    FID与Inception Score2017.06 · 数据·评测
    弥补FID只能衡量整体分布质量、无法做实例级检查的缺陷。
  • 使用
    Mask2Former通用分割2021.12 · 视觉
    评测流水线依赖目标检测与分割类判别模型来核对物体。
  • 使用
    Stable Diffusion开源2022.08 · 生成
    以Stable Diffusion系模型为评测对象，揭示其物体和关系错误。
  • 改进
    Pick-a-Pic / PickScore2023.05 · 数据·评测
    一个标量分数不能区分构图、清晰度、文图一致性等具体维度，也无法说明错在哪里。
  • 改进
    HPS v2人类偏好分2023.06 · 数据·评测
    偏好仍是对整张图的整体判断，难以拆解出结构错误、数量错误等具体失败模式。
  • 改进
    T2I-CompBench2023.07 · 数据·评测
    自动评测依赖检测或视觉问答模型，这些评测者自己会出错，计数和三维关系尤其不准。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
