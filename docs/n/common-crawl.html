Common Crawl与网络规模文本

2008数据集延伸Gil Elbaz · Common Crawl Foundation待核对
Wikipedia ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

只有谷歌等少数公司能抓取并保存整个网络，研究者和创业团队拿不到网页规模的数据。

方法

一家非营利组织定期抓取网页，把存档免费放在云上，任何人都可以下载或在云上直接处理。

影响

它成为GPT-3、LLaMA等几乎所有大模型预训练语料的主要原料，C4、RefinedWeb、FineWeb都是从它过滤出来的。

方法

Common Crawl由Gil Elbaz创立，是一家501(c)(3)非营利机构，2007年成立并开始存档网页，2011年起公开发布抓取结果。据维基百科，到2015年存档里已有18亿网页；数据在亚马逊云上免费访问，用户只需承担存储和计算费用。其初衷是降低研究者和公司对谷歌的依赖。

在2020年代之前，主要使用者是研究者和一些创业公司；此后AI公司开始用它训练大语言模型。原始抓取质量参差，含大量重复、模板化页面和垃圾内容，所以后来的大模型语料项目都在它之上做过滤与去重：C4语料用启发式规则清洗，CCNet按语言和质量打分，RefinedWeb、FineWeb / FineWeb-Edu进一步改进。

它也引发争议：据维基百科引述，2025年11月《大西洋月刊》的调查称Common Crawl曾在是否遵守付费墙、是否响应出版商删除请求上误导出版商。这是一家媒体的调查结论，Common Crawl一方的说法本次未核对。

局限与后续

  • 原始网页质量低、重复多，直接训练效果差，必须自行过滤去重。

它建立在什么之上

  • 改进
    Brown语料库1961 · 数据·评测
    规模只有约100万词，且只有1961年的美式书面英语，不含口语、网络文本，也不覆盖其他语言。
  • 改进
    维基百科语料2001.01 · 数据·评测
    内容覆盖和质量不均衡，少数语言和冷门话题的条目稀少，学到的知识也带有编辑群体的偏向。
  • 改进
    English Gigaword2003 · 数据·评测
    只有新闻文体，且受授权限制，难以反映口语、小说、网页等其他文本。
  • 改进
    Europarl平行语料2005.09 · 数据·评测
    全是议会辩论，语体和主题偏窄，训练出的系统换到新闻、口语、技术文档时质量大降。
  • 延续
    Google Web 1T 5-gram2006.08 · 数据·评测
    Web 1T只公布n-gram计数；Common Crawl公开网页原文，可训练任何类型的模型。
