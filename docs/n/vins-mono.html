VINS-Mono视觉惯性

VINS-Mono: A Robust and Versatile Monocular Visual-Inertial State Estimator
2017.08论文延伸IEEE T-RO 2018Tong Qin, Peiliang Li, Shaojie Shen · 香港科技大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

纯单目SLAM（如ORB-SLAM）无法知道真实尺度，快速运动时还容易跟丢；加一个便宜的惯性测量单元（IMU）能补上尺度和姿态，但IMU和相机怎么初始化、外参怎么标、怎样高精度又实时地融合，都很难做稳。

方法

做一个完整的单目视觉-惯性系统：先用一套稳健的初始化流程把视觉的无尺度结构和IMU预积分对齐，求出尺度、重力和速度；再用滑动窗口里的紧耦合非线性优化同时优化IMU和特征观测；加上回环检测、重定位和4自由度位姿图优化保证全局一致。

影响

开源后成为无人机、AR和机器人上最常用的视觉惯性里程计之一，“一个相机加一个IMU”的方案被大量后续系统和产品沿用；后来扩展为支持双目和GPS的VINS-Fusion。

方法

系统分为几个模块：

  • 前端：跟踪角点特征（KLT光流），同时对两帧之间的高频IMU读数做预积分——把这段时间的加速度和角速度积成一个相对运动量，之后优化时状态变了也不用从头重积分；
  • 初始化：先只用视觉做一个小规模、无尺度的运动恢复结构，再把它和IMU预积分对齐，解出尺度、重力方向、速度和陀螺仪偏置；初始化失败可以自动重来（故障恢复）；
  • 紧耦合滑动窗口优化：在最近若干个关键帧组成的窗口里，把IMU残差、视觉重投影残差和边缘化留下的先验一起做非线性最小二乘（与光束平差综述同一类问题），窗口外的旧帧被边缘化掉以保持实时；
  • 回环与位姿图：用词袋检测回到旧地点，先做轻量的重定位，再做位姿图优化。因为IMU让重力方向可观测，俯仰和横滚是确定的，位姿图只需优化x、y、z和偏航角这4个自由度。

摘要称在公开数据集和真实实验中与当时最好的方法比较，还在微型飞行器上做了机载闭环自主飞行，并移植到了iOS。

局限与后续

  • 只支持单目+IMU，地图只有一张，跟丢后无法与之前的地图合并；在长时间纯旋转或匀速运动时尺度仍可能不可观测。

它建立在什么之上

  • 竞争
    卡尔曼滤波1960 · 具身·世界模型
    另一类视觉惯性方法（如MSCKF）用卡尔曼滤波递推融合；VINS-Mono选择基于优化的方法，精度更高、计算更重。
  • 改进
    ORB-SLAM2015.02 · 视觉
    单目视觉SLAM没有真实尺度、快速运动易丢；VINS-Mono引入IMU紧耦合，给出度量尺度并提高鲁棒性。
  • 使用
    Lucas–Kanade光流1981.08 · 视觉
    前端用KLT光流跟踪角点特征。
  • 使用
    光束平差综述2000 · 视觉
    滑动窗口内的联合非线性最小二乘与光束平差同属一类问题，额外加入IMU残差。
  • 改进
    MSCKF视觉惯性滤波2007.04 · 具身·世界模型
    作为滤波方法，线性化误差一旦进入就无法修正，长时间运行会有一致性问题和漂移，也没有回环。

后来的相关工作

  • 延续
    LIO-SAM激光惯性里程计2020.07 · 具身·世界模型
    借鉴视觉-惯性紧耦合与IMU预积分的思路，把视觉换成激光雷达。
  • 改进
    ORB-SLAM3视觉惯性多地图2020.07 · 视觉
    VINS-Mono是单地图、以滑动窗口为主的视觉惯性系统，跟丢后无法复用旧地图；ORB-SLAM3用多地图合并复用全部历史，精度高2到5倍。
  • 改进
    DROID-SLAM2021.08 · 视觉

读懂它需要的概念

相机模型与多视图几何 梯度下降 自由度、运动学与本体感知 随机变量与概率分布

本篇术语

  • IMU预积分　把两帧图像之间的多个IMU读数预先积成一个相对位移和旋转，优化时状态改变也不必重新积分。
  • 边缘化　把滑出窗口的旧状态从优化里消去，但保留它们对剩余状态的约束，作为先验项。

怎么学

先学单目SLAM的基本流程和光束平差，再读本文第4节IMU预积分和第5节初始化；用开源代码在EuRoC数据集上跑一次，画出估计轨迹和真值对比。
