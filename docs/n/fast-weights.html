快速权重

Learning to Control Fast-Weight Memories: An Alternative to Dynamic Recurrent Networks
1992论文延伸Neural Computation 1992Jürgen Schmidhuber · 慕尼黑工业大学待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

Elman循环网络一类网络靠隐状态记住过去，而隐状态的容量小，增大隐状态时参数要平方增长。

方法

让一个慢网络输出“快权重”的修改量，快网络的权重随输入序列被改写，把这些权重本身当作短期记忆。

影响

它是线性注意力的早期形态，三十年后被指出与Transformer里的注意力数学上等价。

方法

系统有两个网络：慢网络通过普通梯度下降缓慢学习；它的输出是快网络权重的更新量，这些权重在每个时间步通过外积ΔW = a · bᵀ快速改写，快网络用当前的W处理输入。

于是记忆被存在一个矩阵里，容量与矩阵大小而不是隐状态大小有关，用外积写入、用矩阵乘法读出，有点像Hebb学习律式的联想存储。这个模型与后来的线性注意力的“键-值外积累积”写入方式本质相同。

  • 以当时的算力很难训练，没有得到大规模验证。
