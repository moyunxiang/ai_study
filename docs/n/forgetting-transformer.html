遗忘Transformer FoX

Forgetting Transformer: Softmax Attention with a Forget Gate
2025.03论文延伸ICLR 2025Zhixuan Lin, Evgenii Nikishin, Xu Owen He, Aaron Courville · Mila、蒙特利尔大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

LSTM、Mamba、GLA等循环模型都靠遗忘门决定“多快忘掉旧信息”，这是它们的关键部件；Transformer没有显式循环形式，似乎无法直接装上遗忘门，只能靠位置编码间接表达远近。

方法

把遗忘门写成对未归一化注意力分数的、依赖数据的衰减：每个位置算一个遗忘门 f_t = σ(w·x_t + b)，从位置j到i的分数加上 Σ_{l=j+1..i} log f_l，越远、门越小的位置被压得越低，仍然是softmax注意力。

影响

FoX在长上下文语言建模、长度外推和短上下文下游任务上都超过标准Transformer，不需要任何位置编码，且兼容FlashAttention；它把循环模型的遗忘门思想带回了softmax注意力，是2025年“注意力与循环融合”路线中被频繁比较的基线之一。

方法

背景：门控线性注意力（门控线性注意力GLA）、Mamba-2与状态空间对偶、Gated DeltaNet都依赖随数据变化的遗忘门来控制记忆衰减；ALiBi线性偏置位置则用一个与位置距离成正比的固定偏置让远处的注意力变弱，但它与内容无关。

遗忘注意力：对每个时刻t计算标量遗忘门 f_t = σ(w_fᵀ x_t + b_f) ∈ (0,1)（每个头一个）。令 F_ij = Π_{l=j+1}^{i} f_l，注意力改为

o_i = Σ_j F_ij · exp(q_iᵀk_j) v_j / Σ_j F_ij · exp(q_iᵀk_j)

等价地，在对数域里给分数加偏置 D_ij = Σ_{l=j+1}^{i} log f_l，即 softmax(QKᵀ + D)。D可以用前缀和一次算出，作为加到注意力分数上的偏置矩阵，所以能直接放进FlashAttention-2这类分块实现。若所有f都等于同一个常数，它就退化成ALiBi式的线性距离衰减；f依赖内容时，模型可以在某些位置“清空记忆”，在另一些位置长期保留。

作者还提出“Pro”块设计，把循环模型中常见的组件（如输出门、QK归一化、短卷积）加入，发现它同时提升FoX和Transformer。

结果：摘要称FoX在长上下文语言建模、长度外推和短上下文下游任务上优于Transformer，在长上下文下游任务上与Transformer相当，不需要位置编码；大海捞针等分析显示它保留了Transformer相对Mamba-2、HGRN2、DeltaNet等循环模型在长上下文上的优势。

局限与后续

  • 仍是完整的softmax注意力，计算随长度平方增长、需要完整KV缓存，遗忘门本身并不降低推理开销（作者后续工作才研究按遗忘门裁剪KV）。
    本站还没有记录针对它的后续工作（不代表没有人解决）

读懂它需要的概念

自注意力与多头注意力 门控机制 位置编码 循环网络与隐状态 Softmax与logits

本篇术语

  • 遗忘门（forget gate）　循环网络里一个0到1之间的系数，乘在旧状态上，决定保留多少过去的信息。
  • 长度外推　模型在比训练时更长的序列上仍能正常工作的能力。

怎么学

先补门控机制和ALiBi线性偏置位置；读原文第2节从遗忘门推出对数偏置的推导；动手：在小GPT里去掉RoPE，加上 D = cumsum(log f) 形式的偏置，训练后在2倍训练长度上比较困惑度。
