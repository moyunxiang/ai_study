BM25

Some Simple Effective Approximations to the 2-Poisson Model for Probabilistic Weighted Retrieval
1994论文重要SIGIR 1994，pp. 232–241Stephen E. Robertson, Steve Walker · 伦敦城市大学（Okapi项目）待核对
DOI ↗Robertson & Zaragoza 2009：The Probabilistic Relevance Framework: BM25 and Beyond ↗Wikipedia: Okapi BM25 ↗在交互版中打开（演化树、学习进度）

问题

TF-IDF是经验公式：词出现20次的得分是出现1次的20倍，长文档天然占便宜。概率检索模型有理论，但在大规模TREC评测上用不好词频和文档长度。

方法

从“词频由文档是否真正讲这个主题决定”的双泊松模型出发，不去估计它那些估不出来的参数，而是模仿它的形状：词频的贡献先快后慢、趋于饱和，并按文档长度相对平均长度做软归一化。

影响

得到一个只有两个参数（k₁和b）的打分公式，三十年来一直是关键词检索的默认算法和最难打败的基线；今天RAG系统里的关键词召回通道大多还是它。

背景

检索打分有两条路线。向量空间模型用TF-IDF向量的余弦，效果好但没有理论解释。概率路线从朴素贝叶斯分类（Maron与Kuhns的概率索引）发展到Robertson与Spärck Jones 1976年的相关性权重：给定一个词在相关文档和不相关文档中出现的概率，就能推出它该加多少分；在没有任何相关性信息时，这个权重退化成与IDF与TF-IDF几乎相同的 log((N−n+0.5)/(n+0.5))。但它只看词“有没有出现”，不用词频。

1992年起的TREC文本检索评测提供了上百万篇、长短悬殊的新闻和政府文档，词频和文档长度的影响一下子变得很大。Harter提出过一个能解释词频的双泊松模型，可它的参数（两个泊松均值和混合比例）在实际中无从估计。

方法

精英度（eliteness）。设想每篇文档对每个词有一个看不见的二值属性：这篇文档是否真正“讲”这个词代表的主题。讲这个主题的文档里，词频服从均值较大的泊松分布；不讲的，服从均值较小的泊松分布——两个泊松混合，故称双泊松。相关性只通过精英度影响词频。

看形状，不算参数。把这个模型代入相关性权重，得到的公式很复杂，但它的性质很清楚：词频为0时贡献为0；随词频单调上升；但有上限，上限就是“已经确定这篇是精英文档”时的权重。于是用一个最简单的同形状函数代替：

tf / (k₁ + tf)

k₁控制饱和快慢。例如k₁=1.2时，词频1、2、10对应的值约为0.45、0.63、0.89——出现第二次还有明显加分，出现第十次就几乎不加了。

文档长度。长文档词频高，可能是作者啰嗦（应按长度打折），也可能是内容多（不该打折）。折中的做法是软归一化：B = (1−b) + b·dl/avdl，dl是文档长度，avdl是平均长度，b=1完全按长度归一化，b=0不归一化。

完整公式。对查询中每个词求和：

score = Σ IDF(t) · tf·(k₁+1) / (tf + k₁·B)

分子的 (k₁+1) 不影响排序，只是让词频为1时得分与原权重一致。IDF部分在没有相关性信息时用 log((N−n+0.5)/(n+0.5))。“BM”是best matching（最佳匹配）的缩写，Okapi是最早使用它的检索系统的名字。

结果

原始论文的SIGIR版本本次未能打开，具体TREC数字未核对。根据Robertson与Zaragoza 2009年的综述：模型本身不告诉你k₁和b该取多少，大量实验表明 1.2 < k₁ < 2、0.5 < b < 0.8 在多数情况下效果不错，但最优值依赖文档和查询类型；查询内词频的饱和项和额外的整篇长度修正后来被证明不重要而被去掉。

后来的发展

BM25很快成为检索系统的标准打分函数，Lemur、Terrier、Xapian等开源引擎都实现了它，后来又扩展出处理标题、正文等多个字段的BM25F。在机器学习时代，它通常作为一个特征被RankNet排序学习等排序学习模型使用；IBM Watson赢得Jeopardy!的候选段落检索、DrQA开放域问答的文档检索也以它或TF-IDF为基础。

神经检索兴起后，BM25反而成了必须报告的基线：稠密检索DPR需要证明自己比它好，BEIR零样本检索却显示在跨领域零样本检索上，很多稠密检索模型不如BM25。SPLADE学习式稀疏检索把它的“稀疏词权重”交给BERT来学；上下文检索等RAG实践则把BM25和向量检索的结果合并。

容易误解的地方

  • BM25不是从双泊松模型严格推导出来的，而是用一个形状相似的简单函数去近似，作者自己称之为“简单有效的近似”。
  • 公式有很多变体（是否带k₁+1、IDF是否加1防负数、是否保留k₃查询词频项），不同工具包的得分不能直接比较。
  • 它和TF-IDF一样是词袋模型：词序、短语、同义词一概不管。

局限与后续

  • 仍然只认字面相同的词，查询与文档用词不同（同义词、改写）就检索不到。

    向量空间模型1975.11 · NLP
    同样给文档打分排序：向量空间模型靠几何直觉，BM25从相关概率出发，在TREC上逐渐成为更强的方案。
  • 使用
    TREC文本检索评测1992.11 · 数据·评测
    在TREC的大规模、长度差异巨大的文档集上开发和调参，正是这些数据暴露了词频与长度的问题。

    朴素贝叶斯分类1961 · 基础

本篇术语

  • 双泊松模型（2-Poisson）　假设词频来自两个泊松分布的混合：讲这个主题的文档里词出现得多，不讲的文档里只是偶然出现。
  • 词频饱和　同一个词多次出现带来的加分递减并趋于上限。避免一篇文档靠重复关键词刷高得分。
  • 软长度归一化　按文档长度相对平均长度的比例对词频打折，打折力度由b在0到1之间调节。

怎么学

先读Robertson与Zaragoza 2009年综述的第3.4–3.5节（精英度、饱和、长度归一化和参数取值），比读原文更清楚。动手：用Python实现BM25，在一个小型问答语料上与TF-IDF余弦比较前10条结果；再画出k₁=0.5、1.2、3时 tf/(k₁+tf) 的曲线，体会饱和的含义；最后用rank_bm25或Pyserini跑一个MS MARCO子集。
