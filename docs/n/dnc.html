可微神经计算机DNC

Hybrid Computing Using a Neural Network with Dynamic External Memory
2016.10论文延伸Nature 538, 2016Alex Graves, Greg Wayne, Malcolm Reynolds, Tim Harley, Ivo Danihelka, Agnieszka Grabska-Barwińska, Sergio Gómez Colmenarejo, Edward Grefenstette et al. · DeepMind待核对
Nature ↗开放获取版本（牛津大学存档） ↗在交互版中打开（演化树、学习进度）

问题

神经网络擅长感知和序列学习，却难以表示变量和数据结构、也难以长时间存储数据；神经图灵机加了外部记忆，但写入时可能覆盖仍有用的内容，也无法按写入顺序回溯。

方法

在神经图灵机的基础上，用一个控制器网络读写外部记忆矩阵，并加入动态的空间分配（记录哪些格子空闲）和时间链接（记录写入先后顺序），全部可微、端到端训练。

影响

把“可微的读写记忆”推进到能在图上找最短路径、推断家族关系的程度，是记忆增强神经网络这条路线最有代表性的工作。

方法

DNC由一个控制器（通常是LSTM）和一块N×W的外部记忆矩阵组成，好比计算机的CPU和内存。每一步，控制器输出一组“接口向量”，决定从哪里读、往哪里写、写什么。所有寻址都是软的：读写头对每个记忆格子给一个权重，读出的是加权平均，因此整个系统可以用梯度训练。

寻址有三种机制。一是按内容寻址：拿一个查询向量和每个格子算余弦相似度，与神经图灵机相同。二是动态分配：维护每个格子的“使用率”，写入时优先挑没用过或已被释放的格子，避免覆盖还要用的内容。三是时间链接矩阵：记录“格子i是在格子j之后写入的”，读的时候可以沿写入顺序向前或向后走，按顺序回放存进去的序列。

Nature摘要报告：用监督学习训练时，DNC能回答模拟自然语言推理的合成问题，能学会在随机生成的图上找指定两点间的最短路径、推断缺失的边，并推广到伦敦地铁网络和家族树这样的具体图；用强化学习训练时，能完成目标由符号序列给出的积木移动谜题。

局限与后续

  • 软寻址要对所有记忆格子计算权重，记忆一大就慢；训练不稳定、调参困难，任务大多停留在合成数据上。

  • 软寻址　不是选中某一个记忆格子，而是对所有格子给出一个权重分布，读写都按权重加权进行，因此可微。
