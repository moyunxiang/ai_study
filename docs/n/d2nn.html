衍射深度神经网络D2NN

All-Optical Machine Learning Using Diffractive Deep Neural Networks
2018.04论文延伸Science 2018Xing Lin, Yair Rivenson, Nezih T. Yardimci, Muhammed Veli, Mona Jarrahi, Aydogan Ozcan · UCLA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

电子芯片做神经网络推理要消耗电能、受时钟频率限制；光子神经网络用集成光路做矩阵乘法，但规模受芯片上光学元件数量限制。

方法

把一叠被动的衍射薄片当作网络的“层”：每片上每个点的厚度决定它怎样改变透过光的相位，用深度学习在电脑上训练这些厚度，再3D打印出来，光穿过它就完成计算。

影响

让“衍射光学神经网络”成为一个活跃的研究方向，此后出现了大量用衍射层做分类、成像和光计算的工作，也是光计算讨论里最常被引用的样例之一。

方法

光在自由空间传播时，从前一片的每个点发出的次级波会叠加到下一片的每个点上，这天然是一种“全连接”；每片上的点相当于神经元，它透过的光的相位（和振幅）就是可调的权重。作者在电脑里用衍射光学的物理模型模拟光的传播，用反向传播对每个点的参数做梯度下降；训练完后把这些层用3D打印做成实物，按设计的间距摆放。

摘要报告，他们在太赫兹波段做了实验：3D打印的D2NN学会了手写数字分类，也学会了实现成像透镜的功能。衍射层本身是被动元件，除照明光源外不耗电，计算以光速完成，作者设想它可用于全光图像分析、特征检测和新型相机。需要注意，这样的网络一旦打印就固定了，而且主要是线性的光学变换。

局限与后续

  • 层是被动、固定的，训练完不能再改，换任务就要重新制造；缺少光学非线性，表达能力受限。

读懂它需要的概念

多层感知机 导数、偏导与梯度 矩阵乘法与线性变换

本篇术语

  • 衍射　光遇到障碍或小孔时向各个方向散开、相互叠加的现象；D2NN利用这种叠加让每层的每个点都影响下一层的所有点。

怎么学

先回顾多层感知机里全连接层的含义，再读论文摘要和主图，想一想“每个点的厚度”如何对应“权重”；可对比光子神经网络的片上光路方案。
