多智能体竞争涌现复杂性

Emergent Complexity via Multi-Agent Competition
2017.10论文延伸ICLR 2018Trapit Bansal, Jakub Pachocki, Szymon Sidor, Ilya Sutskever, Igor Mordatch · OpenAI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

单智能体RL学到的行为大致和环境一样复杂；要得到复杂的能力，似乎就得手工搭一个复杂的环境和一套循序渐进的课程。

方法

在简单的三维物理竞技场里让两个智能体用自我对弈互相竞争：对手的水平随自己一起提高，天然构成一套难度刚好的课程，于是简单环境里也能长出复杂的身体技能。

影响

让「多智能体竞争产生自动课程」成为一个明确的说法，OpenAI后来的捉迷藏中的涌现工具使用沿着同一思路把它推到了工具使用。

方法

作者在MuJoCo物理模拟里做了几个双人竞技环境，例如两个人形机器人在圆台上相扑、一方射门一方守门、一方要跑过对方而另一方要拦住。规则很简单，奖励基本只有输赢。

训练用PPO做自我对弈：两个智能体都在学，任何一方变强，另一方面对的难度就随之上升。论文强调这种环境的两个性质：一是行为可以远比环境复杂；二是自带课程——对任何技能水平，一个满是同等水平对手的环境恰好难度合适。为了让这个过程启动起来，训练初期加了鼓励站立、移动的稠密奖励再逐步退火到只看输赢；对手也不总是用最新版本，而是从自己过去的版本里随机抽，避免两个智能体陷入只针对彼此当前弱点的循环。

摘要称，智能体学会了奔跑、阻挡、下蹲、擒抱、假动作欺骗对手，以及用手脚踢球和防守等多种技能，而环境本身相当简单。

局限与后续

  • 自我对弈可能陷入循环或只学会针对特定对手的策略，学到的技能是否泛化到别的对手没有系统评估。

读懂它需要的概念

自我对弈 策略梯度 奖励设计与奖励投机 状态、观测与动作

本篇术语

  • 自动课程（autocurriculum）　训练任务的难度不是人安排的，而是随着智能体和对手的共同进步自动提高。

怎么学

先了解PPO和自我对弈；读原文第2–3节环境与训练细节；看项目视频，对照文中的对手采样策略想一想为什么只和最新版本对打会出问题。
