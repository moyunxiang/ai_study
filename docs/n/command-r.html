Cohere Command R/R+

Command R: RAG at Production Scale
2024.03模型延伸Cohere待核对
官方博客 ↗Hugging Face ↗在交互版中打开（演化树、学习进度）

问题

企业用大模型主要做检索增强问答和调用内部工具，但通用聊天模型在长文档引用、给出处和工具调用上不可靠，前沿闭源模型又贵。

方法

专门为RAG和工具调用优化一个中等规模模型：长上下文、带引用的回答、多步工具使用，并把权重开放给研究使用。

影响

350亿参数的Command R和1040亿参数的Command R+是2024年上半年最强的开放权重模型之一，带动了“为RAG专门训练模型”的做法。

背景

检索增强生成RAG把检索到的文档塞进上下文让模型据此回答，但通用模型常常不按文档回答、编造引用；Toolformer之后，工具调用也成了企业场景的刚需。2024年初开源社区最强的是Llama 2和Mixtral 8x7B，它们没有针对这两类能力专门训练。

方法

Command R于2024年3月11日发布，Command R+于4月初发布。Cohere在公告中把它定位为“面向生产规模RAG”的模型，主要特点是：128K token的长上下文；回答时给出指向检索文档片段的引用（grounded generation），便于核查；支持单步和多步工具调用；覆盖十种左右的主要商业语言。模型以API提供，同时在Hugging Face上以CC BY-NC 4.0许可开放权重，供研究和非商业使用。

结果

Hugging Face模型元数据显示，Command R约350亿参数（34.98B），Command R+约1040亿参数（103.8B），许可均为CC BY-NC 4.0。基准成绩以官方自报为主，Command R+发布后曾在Chatbot Arena上排在开放权重模型前列。

后来的发展

2025年的后继型号Command A延续了“面向企业RAG与智能体”的定位；它的多语言路线与Cohere的Aya 23深度换广度、Aya Expanse多语言模型相互借鉴。
