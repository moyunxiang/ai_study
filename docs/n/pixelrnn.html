PixelRNN / PixelCNN

Pixel Recurrent Neural Networks
2016.01论文延伸ICML 2016van den Oord, Kalchbrenner, Kavukcuoglu · Google DeepMind待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

神经自回归NADE类自回归模型只在小的二值图上试过，如何对真实彩色图像的像素做精确似然建模并生成清晰的样本不清楚。

方法

把图像当作像素序列，按从左到右、从上到下的顺序，用LSTM或掩码卷积逐个预测像素的离散取值分布。

影响

确立了图像自回归模型路线，PixelCNN成为后续VQ-VAE、VQGAN等先验模型的基础。

方法

图像的联合概率被拆成 p(x) = Π p(x_i | x_<i)，像素按行扫描排序，每个像素的R、G、B三个通道也依次预测，每个通道值是0到255的256类分类，用softmax输出，因此直接对离散像素值建模，不需要连续化。

论文提出了几种网络：Row LSTM、对角线BiLSTM用两维循环层捕获上文，并用残差连接加深；更快的PixelCNN则用「掩码卷积」，卷积核里把当前及之后位置的权重置零，训练时所有位置可并行。训练目标就是精确的对数似然，所以不同模型可以直接比较。

摘要称在自然图像上取得显著优于当时水平的似然，并给出ImageNet基准，样本「清晰、多样、全局连贯」。

局限与后续

  • 生成时必须一个像素一个像素串行采样，生成一张图要几万到几十万步，极慢。
    后来针对它的工作　VQ-VAE-2 MaskGIT并行掩码生成
  • PixelCNN的掩码卷积有盲点，感受野看不到上方右侧的像素，训练速度快但似然不如PixelRNN。
    后来针对它的工作　PixelCNN++

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    Row LSTM与对角线BiLSTM用二维循环层捕获像素上文。
  • 改进
    神经自回归NADE2011.04 · 生成
    把NADE的自回归思路从小的二值向量推到真实彩色图像，并改用深度循环和卷积结构。
  • 改进
    MADE2015.02 · 生成
    对顺序敏感，且全连接结构不利用图像的空间局部性。

后来的相关工作

  • 延续
    WaveNet2016.09 · 语音 已核对
    把PixelCNN逐像素自回归、用掩码卷积并行训练、门控激活、离散softmax输出的做法从二维图像搬到一维音频。
  • 使用
    VQ-VAE2017.11 · 生成
    第二阶段用PixelCNN在离散编号网格上建模先验，生成时逐个采样编号。
  • 改进
    MaskGIT并行掩码生成2022.02 · 生成
    生成时必须一个像素一个像素串行采样，生成一张图要几万到几十万步，极慢。
  • 延续
    PixelCNN++2017.01 · 生成
    对PixelCNN做工程性改进，提高似然并加速训练。
  • 使用
    VQ-VAE-22019.06 · 生成
    先验采用PixelCNN式的自回归模型。
  • 延续
    Image GPT2020.06 · 生成
    沿用逐像素自回归的思路，但把网络换成Transformer，并将重点放在表示学习。
