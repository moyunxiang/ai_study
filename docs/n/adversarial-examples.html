对抗样本

Intriguing Properties of Neural Networks
2013.12论文重要ICLR 2014Christian Szegedy, Wojciech Zaremba, Ilya Sutskever, Joan Bruna, Dumitru Erhan, Ian Goodfellow, Rob Fergus · Google / NYU / Université de Montréal待核对
arXiv ↗Distill：对抗样本的图解讨论 ↗在交互版中打开（演化树、学习进度）

问题

AlexNet之后深度网络在图像识别上接近人类，大家默认它学到的映射是平滑的：图片稍微改一点，判断不会变。没人系统检查过这一点。

方法

把“找到离原图最近、却被分错的图”写成一个优化问题，用梯度去解，结果每一张图都能找到人眼看不出差别、网络却分错的版本，而且这些扰动能骗过别的网络。

影响

揭示了深度网络在最坏情况下极其脆弱，开启了对抗攻击与防御这一整个研究方向，也让“模型安全”第一次成为深度学习的正式问题。

背景

2012年AlexNet在ImageNet上大幅领先之后，深度卷积网络迅速成为视觉和语音的主流。人们评价模型只看测试集准确率：从同一分布随机抽的图片，分对多少。隐含的假设是，网络学到的输入到输出的映射在局部是平滑的——一张猫的照片加一点人眼看不出的变化，网络当然还认为它是猫。

这个假设从未被认真检验过。同年9月，测试时规避攻击已经在SVM和浅层网络上展示了用梯度构造“逃避检测”的样本，但那是针对垃圾邮件、恶意软件这类安全场景；对刚刚赢下ImageNet的深度网络，没人知道它在最坏情况下会怎样。

这篇论文原本是在研究网络的可解释性，报告了两个“反直觉的性质”，其中第二个就是对抗样本。

方法

性质一：单个神经元不比随机方向更有意义。作者找出让某个高层神经元激活最大的图片，再找出让一个随机方向（多个神经元的随机线性组合）激活最大的图片，发现两组图片看起来都有清楚的语义共性。结论是：语义信息存在于整个激活空间里，而不是对齐到单个神经元上。

性质二：对抗样本。给定分类器f、图片x（像素值在[0, 1]）和一个错误的目标类别l，求一个最小的扰动r：

最小化 ‖r‖₂，使得 f(x + r) = l，且 x + r ∈ [0, 1]^m

直接求解很难，作者改成带惩罚项的形式最小化 c·|r| + loss_f(x + r, l)，用带边界约束的L-BFGS（一种利用梯度的拟牛顿优化法）求解，并对c做线搜索，找到仍能让网络输出l的最小扰动。这里的梯度是对输入像素求的，而不是对网络参数——网络固定不动，改的是图片（见反向传播）。

迁移实验。在MNIST上用不同层数、不同正则化、甚至在不相交的两半训练集上分别训练多个网络，把为其中一个网络构造的对抗样本喂给其他网络，看错误率。

结果

在作者测试的所有网络（MNIST上的全连接网络、QuocNet、AlexNet）上，每一个样本都能找到视觉上几乎无法区分、却被分错的版本。图5中为AlexNet构造的对抗样本全部被判为“鸵鸟”，64个样本的平均失真只有0.0065（像素值范围0到1）。

MNIST上为一个网络构造的对抗样本，喂给结构不同或用另一半数据训练的网络，错误率从个位数到87%不等（表2）；而幅度比这些对抗扰动还大的随机高斯噪声（标准差0.1）造成的错误率在0%到18%之间，多数模型不到10%。初步实验还显示，把对抗样本混进训练集，能让一个100-100-10的全连接网络在MNIST上测试误差降到1.2%以下。

后来的发展

一年后FGSM与线性解释给出了“网络太线性”的解释和一步就能生成对抗样本的快速方法，攻防研究从此爆发：物理世界中的对抗样本证明打印出来拍照仍然有效，C&W攻击把攻击做得更强，PGD对抗训练把防御写成鲁棒优化，随机平滑认证鲁棒性给出可证明的鲁棒性。对抗样本是特征不是bug则提出对抗扰动利用的是数据中真实存在、但人类看不到的特征。

2023年自动化越狱攻击GCG把同样的思路用到大语言模型上：对输入token做梯度引导的搜索，找到能让对齐模型越狱的后缀。论文的第一个性质则在十年后的叠加假说研究中被重新提起——语义方向不对齐到单个神经元，正是后来稀疏自编码器要解决的问题。

容易误解的地方

  • 对抗样本不是因为模型“过拟合”。论文本身就发现扰动能跨模型、跨训练集迁移，后来的研究普遍认为它与高维空间中的近似线性行为和数据中的非鲁棒特征有关。
  • “人眼看不出”是相对于像素范数说的。对抗扰动是专门构造的最坏方向，同样大小的随机噪声几乎不影响分类。

读懂它需要的概念

反向传播 导数、偏导与梯度 范数与距离 卷积层、池化与感受野 泛化与过拟合 图像作为张量

本篇术语

  • 对抗样本　对正常输入做专门构造的微小修改后得到的输入，人类看不出区别，模型却给出错误且往往很自信的判断。
  • L-BFGS　一种利用梯度、并用最近几步的梯度变化近似二阶信息的优化算法；带边界约束的版本可以保证像素值始终留在合法范围内。
  • 迁移性　为一个模型构造的对抗样本对另一个独立训练的模型也有效。这使得攻击者不需要拿到目标模型的参数（黑盒攻击）。
