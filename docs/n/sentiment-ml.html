机器学习情感分类

Thumbs up? Sentiment Classification using Machine Learning Techniques
2002.07论文重要EMNLP 2002，pp. 79–86Bo Pang, Lillian Lee, Shivakumar Vaithyanathan · 康奈尔大学 / IBM Almaden研究中心待核对
ACL Anthology ↗PDF ↗Cornell电影评论数据集（polarity dataset） ↗在交互版中打开（演化树、学习进度）

问题

文本分类一直按“主题”分（体育还是政治），而判断一篇评论是褒是贬，靠的常常是语气和措辞；当时的情感分析多依赖人工整理的褒贬词表，效果如何、能否直接用机器学习，都没有系统的答案。

方法

把影评的褒贬当作一种二分类“主题”，用星级评分自动生成标签，直接套用朴素贝叶斯、最大熵、SVM三种标准文本分类器，比较不同特征（单词、双词、词性、位置）的效果。

影响

把情感分析确立为机器学习问题，并公开了第一个广泛使用的情感分类数据集；它发现的“特征是否出现比出现几次更有用”“褒贬分类比主题分类难”成为后续研究的出发点。

背景

2000年前后，网上出现了大量带星级评分的影评和商品评论，企业想知道用户怎么评价产品。早期做法是找出褒义词和贬义词再计数，或用语言学规则判断形容词的倾向。

与此同时，文本主题分类已经很成熟：朴素贝叶斯分类简单有效，SVM文本分类表明SVM在主题分类上通常最好，最大熵模型也被用于文本分类，且在主题分类上能达到90%以上的准确率。问题是：情感能不能像主题一样，只靠词袋特征和标准分类器就分得出来？

方法

数据。从IMDb存档的rec.arts.movies.reviews新闻组收集影评，只保留作者给出星级或数字评分的，自动换算成正面、负面（和中性）；为避免少数高产影评人主导，每位作者每个类别少于20篇。实验用700篇正面、700篇负面，三折交叉验证。

人工基线。让两位研究生分别写出他们认为最能表达褒贬的词（如dazzling、brilliant对suck、terrible），按“文中哪类词多”分类，准确率只有58%和64%；作者看过语料统计后再挑14个词，提到69%。有些有效的词并不直观（如“still”和问号“?”）。

特征。每篇文档表示为特征向量：单词（出现至少4次的16165个）、双词、带词性的单词、单词在文章前/中/后部的位置、只用形容词等。对否定做了一个简单处理：在not、isn't等词后、到下一个标点前的每个词加前缀NOT_，使“good”和“NOT_good”成为不同特征。

三种分类器。朴素贝叶斯（假设特征条件独立，按频率估计概率）、最大熵（对数线性模型，不做独立假设）、SVM（找出间隔最大的分割超平面，见核技巧与间隔）。

结果

全部方法都明显超过人工词表基线。最好结果是SVM加单词“是否出现”特征：82.9%。几个发现：

  • 用“是否出现”代替“出现次数”后，SVM从72.8%升到82.9%，朴素贝叶斯从78.7%升到81.0%，与主题分类中的经验相反。
  • 加双词、词性或位置信息都没有带来稳定提升；只用形容词反而更差（SVM 75.1%）。
  • 情感分类比主题分类难得多。作者分析发现常见的“预期落空”式写法：前面列举演员、剧情多么好，最后一句“但它撑不住”；或者通篇骂烂片，结尾却说“但我爱它”。词袋分类器会被大量反向词误导。

后来的发展

Pang与Lee公开的影评数据集成为情感分析的标准基准，此后的工作沿两条线推进：一是语言结构，递归张量网络与情感树库构建了按句法树逐短语标注的情感树库，专门处理否定和转折这类“整体不等于部分之和”的现象；二是表示学习，TextCNN句子分类用卷积网络和预训练词向量做句子分类，情感神经元发现在评论上训练的语言模型里会自发出现一个情感神经元，ULMFiT和BERT的预训练-微调把IMDb等情感任务的错误率进一步大幅降低。情感二分类（SST-2）后来被收入GLUE / SuperGLUE，成为检验语言理解的入门任务。

容易误解的地方

  • 82.9%是在电影评论这一领域、正负各半的平衡数据上得到的，换到商品评论或社交媒体文本需要重新训练。
  • 论文的结论是“词是否出现比次数更有用”，这是针对其设置的经验观察，作者推测与情感和主题的表达方式不同有关，并未证明。
  • NOT_标记只是粗糙地处理否定，无法处理“not only good but great”之类的情况。

局限与后续

  • 词袋特征无法理解转折和整体语气：“预期落空”式评论中大量反向词会误导分类器。
    后来针对它的工作　递归张量网络与情感树库 BERT
  • 否定只靠在否定词后加NOT_前缀，作用范围和组合语义（“不算太差”）都处理不了。
    后来针对它的工作　递归张量网络与情感树库
  • 只有1400篇训练文档、只做正负二分类，没有程度、方面（演技好但剧情差）等更细的情感信息。
    后来针对它的工作　递归张量网络与情感树库
  • 每个领域都需要带标签的数据，模型在其他领域的评论上效果会下降。

读懂它需要的概念

监督学习 条件概率与贝叶斯公式 逻辑回归 核技巧与间隔 独热编码与词表 准确率、精确率、召回率与F1 训练集、验证集与测试集

本篇术语

  • 情感分类（sentiment classification）　判断一段文本表达的是正面还是负面评价，也叫观点挖掘或极性分类。
  • 交叉验证　把数据分成k份，轮流用一份测试、其余训练，取平均成绩。数据少时用来得到更稳定的估计。
  • 否定标记　在否定词后到下一个标点之间的词前加NOT_前缀，让模型能区分“good”和“not good”。

怎么学

先补监督学习和准确率、精确率、召回率与F1。读原文第4节（人工词表基线）、第6节（结果表）和第7节（“预期落空”分析），只有几页。动手：下载康奈尔影评极性数据，用scikit-learn分别以词频和二值特征训练朴素贝叶斯、逻辑回归和线性SVM，复现“二值优于词频”的现象；再挑几篇分错的评论看看是不是转折造成的。
