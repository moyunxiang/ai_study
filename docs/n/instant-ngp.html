Instant-NGP

Instant Neural Graphics Primitives with a Multiresolution Hash Encoding
2022.01论文重要SIGGRAPH 2022（ACM Transactions on Graphics）Thomas Müller, Alex Evans, Christoph Schied, Alexander Keller · NVIDIA待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

NeRF用一个大MLP表示整个场景，每个采样点都要跑完8层网络，一个场景要训练一两天，渲染也很慢。

方法

把场景信息主要存在一张可训练的多分辨率哈希表里：查询点按16个分辨率各取周围格点的特征向量插值后拼起来，只需再过一个很小的MLP；整套流程用手写的融合CUDA内核实现。

影响

NeRF类模型的训练从小时级降到秒到分钟级，1080p渲染只需几十毫秒；“多分辨率特征网格 + 小网络”成为神经场的默认编码方式，也让NeRF第一次能在交互中实时看到训练过程。

背景

NeRF把一个场景存在一个8层、每层256通道的MLP权重里，输入坐标先经过正弦位置编码。问题在于：每个采样点都要完整地跑一遍大网络，一条光线上百个点，一张图几十万条光线，在一块V100上训练一个场景要1–2天，渲染一帧也要数十秒。

另一条路线是显式网格：把特征直接存在三维体素格点上，查询时插值，计算极快，但稠密网格的内存随分辨率立方增长，要表现精细细节就存不下；稀疏八叉树等结构则需要训练中不断调整，实现复杂、难以在GPU上高效并行。

方法

多分辨率网格。设L = 16层网格，分辨率从最粗的16按几何级数增长到最细的512至52万（视任务而定）。查询一个点x时，在每一层找到包住它的那个格子，取格子2^d个顶点（三维时8个）上存的特征向量，按距离做线性插值，得到这一层的F = 2维特征；16层拼起来是32维，再连同观察方向送入一个只有一两个隐藏层、宽64的小MLP。

用哈希表代替稠密网格。粗层格点少，每个格点在表里独占一项；细层格点数远超表的容量T（2¹⁴到2²⁴项），就用空间哈希把格点坐标映射到表中位置：

h(x) = (x₁·π₁ ⊕ x₂·π₂ ⊕ x₃·π₃) mod T

π是大素数，⊕是按位异或。不同格点会撞到同一项（哈希冲突），但论文不做任何冲突处理：真正有物体表面的格点梯度大，会主导该项的取值；空旷区域的格点贡献小；而粗层不冲突，加上小MLP，网络能自己分辨冲突。表的参数量固定为T·L·F，与场景分辨率无关。

工程。整个MLP在一个融合的CUDA内核里计算，中间结果留在片上缓存；用占据网格跳过空旷区域的采样。

结果

在NeRF合成数据集上，训练5秒到15秒就与原版NeRF和NSVF（需训练数小时）的PSNR相当，1到5分钟与mip-NeRF相当；5分钟时8个场景平均PSNR 33.18，高于mip-NeRF的33.09和NeRF的31.01。把哈希编码换回NeRF的频率编码、其余实现不变，同等质量要慢20–60倍，说明提速主要来自编码而非工程。论文还在千兆像素图像拟合、有符号距离场等任务上展示了同样的加速，所有结果在单块RTX 3090上得到。

后来的发展

哈希网格编码迅速成为神经场的标准组件：nerfstudio等框架的默认NeRF模型、大量动态场景和大场景重建工作都采用它，Zip-NeRF把它与Mip-NeRF的抗锯齿结合。它把NeRF的训练时间降到了“可交互”的量级，但渲染仍需沿光线采样。一年后3D高斯泼溅换成显式的三维高斯与光栅化，渲染达到实时，在应用中逐渐取代了基于光线采样的NeRF；不过“多分辨率哈希特征”也被用到3D生成和机器人场景表示中。

容易误解的地方

  • 提速来自“大部分容量放进查表、网络变得很小”，并不是换了更快的GPU；论文用对照实验把编码的贡献单独量化成20–60倍。
  • 哈希冲突在表容量不足时会表现为细小的噪点状伪影；增大T能缓解但会增加显存。

局限与后续

  • 渲染仍要沿每条光线采样并查询网络，复杂大场景难以稳定达到实时帧率。

读懂它需要的概念

多层感知机 体渲染 三维表示：体素、点云、网格、隐式场 显存、内存带宽与“内存墙” 位置编码

本篇术语

  • 神经图形基元　用神经网络表示的图形对象，如图像、有符号距离场、辐射场，输入坐标、输出颜色或距离等。
  • 空间哈希　把整数格点坐标通过乘大素数再异或、取模的方式映射到固定大小数组中的位置。
  • 哈希冲突　两个不同格点被映射到哈希表的同一项。Instant-NGP不显式解决冲突，让梯度和小网络自行消解。

怎么学

先读NeRF，理解为什么大MLP慢。读原文第3节（多分辨率哈希编码，图3和公式2–4），再看第5.4节的NeRF实验表。动手：用tiny-cuda-nn或纯PyTorch实现一个二维哈希网格去拟合一张高分辨率照片，对比只用正弦位置编码的MLP的收敛速度。
