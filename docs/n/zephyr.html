Zephyr蒸馏对齐

Zephyr: Direct Distillation of LM Alignment
2023.10论文延伸Tunstall, Beeching, Lambert, Rajani, Rasul, Belkada, von Werra, Fourrier et al. · Hugging Face待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通过蒸馏监督微调（dSFT）得到的小模型任务准确率高，但对自然提示反应不好，没有与用户意图对齐。

方法

从教师模型排序过的输出出发，用AI反馈偏好数据做蒸馏式的直接偏好优化（dDPO），得到对齐的小聊天模型。

影响

证明只要几小时训练、无需人工标注，就能让7B模型在聊天基准上超过更大的RLHF模型。

方法

流程分三步。第一步，用大模型生成的指令对话数据做蒸馏监督微调，基础模型是Mistral 7B。第二步，收集AI反馈的偏好数据：对每个提示，让几个模型回答，再让教师模型（GPT-4）给回答排序，取最好和较差的组成偏好对。第三步，在偏好对上用DPO直接偏好优化直接优化模型，不训练奖励模型，也不需要在微调期间额外采样，因此训练只需几个小时。

结果模型Zephyr-7B在7B规模的聊天基准上达到当时最优；在MT-Bench上超过Llama2-Chat-70B，后者是当时最强的开放RLHF模型。整个过程没有任何人工标注。

结果

摘要：Zephyr-7B在7B规模的聊天基准上达到最优，MT-Bench上超过Llama2-Chat-70B；训练只需数小时。

后来的发展

Zephyr的配方（dSFT加dDPO，加UltraFeedback数据）成为开源社区对齐的参考流程，也被Hugging Face的alignment-handbook收录。

局限与后续

  • 偏好数据由GPT-4标注，教师偏差被继承；MT-Bench评测本身也由GPT-4评分，存在偏向。

  • DPO对偏好数据过拟合的风险未解决，训练过久会出现性能下降。

它建立在什么之上

  • 改进
    Self-Instruct2022.12 · LLM 已核对
    只做了监督微调，没有用偏好数据或强化学习进一步对齐，与InstructGPT仍有差距。
  • 使用
    DPO直接偏好优化2023.05 · LLM
    用DPO直接在AI偏好对上优化，不训练奖励模型
  • 改进
    Llama 22023.07 · LLM
    RLHF流程昂贵复杂：需要140多万条人工偏好、两个奖励模型和多轮PPO，社区难以复现。
  • 改进
    模仿闭源模型的假象2023.05 · LLM
    评测的模仿数据来源是ChatGPT，且是当时较弱的基础模型，结论对更强的基础模型和更精细的蒸馏是否成立未知。
  • 改进
    Orca解释蒸馏2023.06 · LLM
    效果依赖GPT-4和ChatGPT的大量调用，成本高，且受到使用条款约束；性能上限仍受教师约束。
  • 延续
    RLAIF2023.09 · LLM
    用AI反馈偏好数据，并蒸馏到小模型
  • 使用
    Mistral 7B2023.10 · LLM
    以Mistral 7B为基础模型

后来的相关工作

  • 改进
    IPO与ΨPO框架2023.10 · LLM
    偏好数据由GPT-4标注，教师偏差被继承；MT-Bench评测本身也由GPT-4评分，存在偏向。
  • 延续
    Tülu 2开放后训练2023.11 · LLM
    Zephyr在7B上用UltraFeedback做DPO，Tulu 2把同一配方放大到70B并与更强的SFT数据组合。
  • 竞争
    Starling-7B与Nectar2023.11 · LLM
    Zephyr用DPO离线对齐，Starling用奖励模型加在线RL，MT-Bench更高。
  • 竞争
    SPIN自我对弈微调2024.01 · LLM
    从Zephyr的SFT模型出发，与用GPT-4偏好数据做DPO的Zephyr比较，摘要称可以超过。
