DeepNash陆军棋

Mastering the Game of Stratego with Model-Free Multiagent Reinforcement Learning
2022.06论文重要arXiv 2022；Science 2022Julien Perolat, Bart de Vylder, Daniel Hennes, Eugene Tarassov, Florian Strub et al., Karl Tuyls · DeepMind待核对
arXiv ↗ar5iv全文 ↗DeepMind博客 ↗在交互版中打开（演化树、学习进度）

问题

陆军棋（Stratego）的博弈树约10⁵³⁵个节点，比围棋大10¹⁷⁵倍，开局还要在10⁶⁶种布阵里选择，而且看不到对方棋子是什么——围棋的树搜索和扑克的博弈树求解都用不上。

方法

不做搜索，只用无模型的自我对弈强化学习，但改造学习动力学：在奖励中加入“偏离参考策略”的正则项，使自我对弈收敛到一个不动点，再用它当新的参考策略，反复迭代，最终逼近纳什均衡而不是来回打转。

影响

在Gravon在线平台上对人类专家胜率84%，进入2022年度和历史排行前三，对现有陆军棋AI胜率超过97%；首次在这个规模的不完全信息博弈上，用不依赖搜索的方法达到人类专家水平。

背景

陆军棋是两人对战的棋盘游戏：每方40个棋子，开局时自行布置且背面朝向对手，只有交战时才亮出身份。这意味着两个难点同时存在：博弈树巨大（约10⁵³⁵，围棋约10³⁶⁰，无限注德扑约10¹⁶⁴），以及不完全信息——每方开局就有约10⁶⁶种布阵，对手的每颗棋子都是未知的，诈唬和隐藏身份是核心策略。

已有方法都不合适。AlphaZero式的树搜索依赖完美信息，局面价值不能脱离信念单独评估。扑克AI（Libratus、Pluribus多人扑克）在反事实遗憾最小化CFR上做子博弈求解，需要枚举对手可能的私有信息，扑克只有约1000种手牌组合，陆军棋却有天文数字的布阵，无法枚举。而朴素的自我对弈（见自我对弈）在不完全信息博弈中常常会“绕圈”：A克制B、B克制C、C又克制A，策略在纳什均衡附近循环而不收敛。

方法

核心算法：正则化纳什动力学（R-NaD），三步循环：

  • 奖励变换：给定一个参考（正则化）策略π_reg，把每个玩家的奖励改成r − η·log(π/π_reg)，再加上对手偏离π_reg程度的相应项。直观上，偏离参考策略要付出代价，这让原本会绕圈的博弈变得“好收敛”。
  • 动力学：在变换后的博弈中运行自我对弈学习（类似复制者动态），这个系统有唯一不动点π_fix，并可用一个李雅普诺夫函数（KL散度形式，见KL散度）证明一定收敛到它。
  • 更新：π_fix还不是原博弈的均衡；把它设为新的π_reg，重复上述过程。论文给出的理论结果是，这一串不动点收敛到原博弈的纳什均衡。

深度化。DeepNash用一个深度网络同时输出布阵策略和走子策略，输入是己方棋子、已暴露的对方棋子和历史信息；用自我对弈数据按R-NaD的变换奖励训练，策略更新采用一种基于优势、与复制者动态对应的形式（见Actor-Critic与优势函数）。训练后期对动作概率做阈值化与离散化微调，测试时再过滤掉概率极低的动作和明显失误；全程不做任何搜索。

结果

对已有的陆军棋程序（如Probe、Master of the Flag等）胜率超过97%。2022年4月初在Gravon在线平台上用两周与人类顶尖玩家进行了50场排位赛，赢下42场（84%），在当年和历史排行榜上都进入前三。论文还展示了DeepNash学到的人类式策略：诈唬（用小子冒充大子吓退对手）、在已知物力领先时冒险、故意不暴露关键棋子等，且布阵具有随机性、难以被预测。

后来的发展

R-NaD展示了“改造学习动力学”这条不同于“树搜索”和“博弈树求解”的第三条路线。之后Student of Games把搜索和学习统一到完美与不完全信息博弈中；2026年的Ataraxos陆军棋超越人类则在陆军棋上进一步超越顶尖人类，标志着这一博弈被彻底攻克。

容易误解的地方

  • “不用搜索”不等于不需要大量计算：自我对弈训练本身规模很大。
  • 84%胜率与“前三”是在在线平台对专家玩家的成绩，不等于击败了世界冠军。

局限与后续

  • 完全不做实时搜索，在对局关键时刻无法像人类那样针对当前局面深入计算，仍会出现被高手利用的失误。
    后来针对它的工作　Ataraxos陆军棋超越人类
  • 只达到“进入排行前三”的专家水平，没有在正式比赛中击败世界最强的人类棋手。
    后来针对它的工作　Ataraxos陆军棋超越人类
  • R-NaD的收敛保证是在两人零和博弈中证明的，对多人或一般和博弈不直接适用。

它建立在什么之上

  • 竞争
    反事实遗憾最小化CFR2007 · RL
    CFR类方法需要遍历或枚举对手私有信息，陆军棋的布阵空间太大；DeepNash改用无模型自我对弈加正则化动力学。
  • 竞争
    PSRO博弈论元求解2017.11 · RL
    PSRO维护策略种群并用元求解器求均衡；DeepNash只训练单一策略，通过改造学习动力学直接收敛到均衡。
  • 竞争
    AlphaZero2017.12 · RL
    AlphaZero依赖完美信息下的树搜索；DeepNash证明在不完全信息巨型博弈中，不做搜索的RL也能达到专家水平。
  • 改进
    Pluribus多人扑克2019.07 · RL
    Pluribus依赖手工抽象和枚举手牌的搜索，无法扩展到陆军棋的10⁶⁶种布阵；DeepNash用端到端学习解决了这一规模问题。
  • 使用
    纳什均衡1950 · RL
    训练目标是两人零和博弈的近似纳什均衡，并通过正则化动力学保证收敛而不是绕圈。

读懂它需要的概念

博弈论基础与纳什均衡 自我对弈 策略梯度 Actor-Critic与优势函数 KL散度

本篇术语

  • 陆军棋（Stratego）　两人对弈的棋盘游戏，每方40子，身份对对手隐藏，目标是夺取对方军旗或使其无子可动。
  • 李雅普诺夫函数　一个随系统演化只减不增的“能量”函数，找到它就能证明系统会收敛到某个稳定点。
  • 复制者动态　演化博弈论中的动力学：表现比平均好的策略，其概率按比例增加。

怎么学

先补博弈论基础与纳什均衡，读反事实遗憾最小化CFR和PSRO博弈论元求解的讲解了解其他求均衡的路线。读原文第2节，先看R-NaD在“匹配硬币”小游戏上的图示，理解为什么普通学习会绕圈、正则化后为何收敛。动手：在石头剪刀布上分别实现普通的复制者动态和加了熵/KL正则的版本，画出策略轨迹对比。
