ClipCap前缀描述

ClipCap: CLIP Prefix for Image Captioning
2021.11论文延伸Ron Mokady, Amir Hertz, Amit H. Bermano · 特拉维夫大学待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

图像描述模型通常要在大规模图文数据上做专门的视觉语言预训练，或依赖目标检测特征，训练重、流程复杂。

方法

把CLIP的图像嵌入经过一个小映射网络变成一串“前缀”向量，接在GPT-2的输入前面，让语言模型接着写出描述；甚至可以冻结CLIP和GPT-2，只训练映射网络。

影响

在Conceptual Captions和nocaps上与当时最好方法相当，却更简单、更快、更轻；“冻结视觉编码器+冻结语言模型+只训一个映射层”的做法预示了后来多模态大模型的标准接法。

方法

此前的强描述模型，如自底向上注意力、OSCAR，要么依赖离线检测器提的区域特征，要么在大量图文对上做专门预训练。ClipCap的出发点是：CLIP的图像嵌入本身就是和文字一起训练出来的，语义很丰富；GPT-2本身就会写流畅的句子。把两者接上，可能只需要很少的训练。

做法：CLIP图像编码器把一张图压成一个向量，再用一个映射网络把它变成k个与GPT-2词嵌入同维度的向量，作为“前缀”放在句子前面（思路与Prefix / Prompt Tuning的连续前缀相同）。之后GPT-2按普通的语言建模方式，根据前缀逐词生成描述，用描述的交叉熵训练。

论文给了两种版本：映射网络用MLP，同时微调GPT-2；或者映射网络用Transformer，CLIP与GPT-2都冻结、只训映射网络。后者可训练参数少得多，效果依然不错。两者都不需要额外标注或预训练，在Conceptual Captions和nocaps上达到与最好方法相当的结果。

读懂它需要的概念

嵌入向量 语言模型 自回归生成 迁移学习 多层感知机

本篇术语

  • 前缀（prefix）　放在语言模型输入最前面的一串连续向量，它们不对应任何真实词，但能引导模型接下来生成什么内容。

怎么学

先读CLIP和Prefix / Prompt Tuning的讲解，再读ClipCap论文第3节的两种映射网络，用开源代码在COCO上训练一个只训映射层的版本，比较生成的描述。
