后验采样RL（PSRL）

(More) Efficient Reinforcement Learning via Posterior Sampling
2013.06论文延伸NeurIPS 2013Ian Osband, Daniel Russo, Benjamin Van Roy · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

有理论保证的高效探索算法（R-max乐观探索、UCRL2遗憾界）几乎都靠「面对不确定性保持乐观」，需要为每个状态-动作构造置信区间，算法复杂、计算昂贵，也难以加入先验知识。

方法

把Thompson采样的复兴推广到MDP：每局开始时从对MDP的后验分布中采样一个MDP，这一局就按这个样本的最优策略行动，局末用观测更新后验。

影响

给出第一批非乐观式算法的遗憾界之一，让后验采样成为RL探索理论的主要路线之一，后来的随机价值函数、Bootstrapped DQN等深度探索方法都从它出发。

方法

PSRL（Posterior Sampling for Reinforcement Learning）在已知长度τ的若干局（episode）里重复：

  • 局首：从当前对转移概率和奖励的后验分布里抽一个MDP样本M_k；
  • 求解M_k的最优策略π_k（已知模型时用动态规划即可）；
  • 整局按π_k行动；
  • 局末：用这一局观测到的转移和奖励更新后验（例如对转移用狄利克雷先验，对奖励用共轭先验）。

直觉是：没怎么试过的状态-动作后验很宽，被采样到「看起来很好」的概率不小，于是自然会被探索；试多了后验变窄，就不再浪费尝试。它只需要一次采样和一次规划，不必构造复杂的置信集，先验知识也可以自然地放进先验分布。摘要称，作者证明了期望遗憾为 Õ(τS√(AT))（T为总时间，S、A为状态数和动作数），这是首批不基于乐观的算法遗憾界之一，并接近当时任何RL算法的最好结果；模拟实验中PSRL明显优于具有类似遗憾界的已有算法。

局限与后续

  • 需要在状态和动作都可枚举的表格MDP上维护后验并精确规划，无法直接用于大规模问题。
    后来针对它的工作　Bootstrapped DQN
  • 遗憾界是对先验求期望的贝叶斯遗憾，不是对最坏情况的频率派保证。
    本站还没有记录针对它的后续工作（不代表没有人解决）

  • 竞争
    R-max乐观探索2002.10 · RL
    同为有理论保证的高效探索，R-max用乐观初始化，PSRL用随机化的后验样本。
  • 竞争
    UCRL2遗憾界2008 · RL
    UCRL2靠置信区间上的乐观规划；PSRL靠后验采样，遗憾界接近而计算更简单，实验中表现更好。
  • 延续
    Thompson采样的复兴2011 · RL
    把老虎机里的Thompson采样推广到有状态转移的MDP。

读懂它需要的概念

马尔可夫决策过程 探索与利用 条件概率与贝叶斯公式 动态规划

本篇术语

  • 遗憾　智能体实际获得的累计回报与一直按最优策略行动能获得的回报之差；遗憾增长得越慢，学得越高效。
  • 后验采样　根据当前对未知量的后验分布随机抽一个可能的取值，并当作真实值去行动。

怎么学

先学Thompson采样的复兴和UCRL2遗憾界；读原文第3节算法和第4节遗憾分析的思路；在RiverSwim这类小MDP上实现PSRL，与ε-贪心Q学习比较遗憾曲线。
