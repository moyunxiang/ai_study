PointNet

PointNet: Deep Learning on Point Sets for 3D Classification and Segmentation
2016.12论文重要CVPR 2017Charles R. Qi, Hao Su, Kaichun Mo, Leonidas J. Guibas · Stanford University待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

激光雷达和深度相机给出的是一堆无序的三维点。卷积只能吃规整网格，大家只好先转成体素或多视角图片，数据量暴涨、细节丢失。

方法

每个点用同一个小MLP独立编码，再对所有点做逐维最大池化。最大值与点的顺序无关，网络因此天然对点的排列不敏感，可以直接吃原始点云。

影响

第一个直接处理原始点云的通用深度网络，结构极简、计算量小，成为三维分类、分割、检测里点云骨干的起点，PointNet++等后续工作都由它展开。

背景

三维数据有几种存法（见三维表示：体素、点云、网格、隐式场）：体素网格、网格面片、多视角图片、点云。传感器（激光雷达、深度相机）直接给出的是点云——几千到几十万个(x, y, z)坐标，没有固定顺序，也不在规整网格上。

2016年前后，深度学习处理三维数据的办法是绕开点云：VoxNet等方法把空间切成小立方体（体素）后做三维卷积，内存随分辨率的立方增长，只能用32³这样的粗网格；多视角方法把物体渲染成十几张图片后用图像CNN，精度高但计算重。直接把点当成一个序列喂给网络也不行：同一个物体的1024个点有1024!种排法，网络输出却必须完全相同。问题是要设计一个对输入顺序天生不敏感的网络。

方法

对称函数。如果g(x₁,…,xₙ)无论怎样打乱输入都输出一样的结果，就叫对称函数，加法、取最大值都是。PointNet把整个网络写成

f({x₁,…,xₙ}) ≈ γ( MAX_i h(x_i) )

其中h是所有点共享的同一个多层感知机（多层感知机），把每个点的3维坐标映射成1024维特征；MAX在每一维上分别取所有点中的最大值，得到一个1024维的全局特征；γ是最后的几层全连接，输出类别。因为MAX不管点的顺序，整个网络对排列不变。论文证明：只要中间维度足够大，这种结构可以任意逼近任何连续的集合函数。

分割：把全局特征拼回每个点自己的特征上，再用MLP给每个点分类，这样每个点既知道自己在哪，也知道整体是什么。

对齐网络T-Net：一个小PointNet预测一个3×3矩阵，先把输入点云旋转到规范姿态；特征层再加一个64×64的变换，配一个让它接近正交矩阵的正则项。

关键点：真正决定全局特征的只是在某一维上取到最大值的那些点（最多1024个），论文称为临界点集，可视化后大致是物体的骨架。删掉其余的点，输出完全不变，这解释了它对缺点和噪声的鲁棒性。

结果

ModelNet40（40类、12311个CAD模型、每个物体采样1024点）上总体准确率89.2%，与3D卷积方法Subvolume持平、高于VoxNet的85.9%，但仍低于多视角的MVCNN（90.1%）。计算量方面，论文给出的每样本FLOPs比MVCNN少约141倍、比Subvolume少约8倍，参数量比MVCNN少约17倍。ShapeNet部件分割mIoU 83.7%。消融实验中最大池化明显优于平均池化和注意力加权求和，也远好于在排序或乱序点上用MLP、RNN。

后来的发展

PointNet的缺陷是每个点被独立处理，只在最后一步汇总，看不到局部邻域。半年后同一作者的PointNet++在不同半径的局部邻域里递归地套用PointNet，补上了局部结构。此后点云网络分化出图卷积、稀疏卷积、点云Transformer等路线，直到Point Transformer V3。“共享MLP + 对称池化”的思路也被用于集合数据的一般理论（与Deep Sets同时期），并被激光雷达检测、机器人抓取等系统当作点云编码器。

容易误解的地方

  • 排列不变不等于旋转不变。PointNet靠T-Net和训练时绕竖直轴的随机旋转来应对姿态变化，任意三维旋转下性能仍会下降。
  • 最大池化只看每一维的最大值，局部的几何关系（相邻点的距离、曲率）没有被显式建模，这是它在复杂场景上弱的主因。

局限与后续

  • 每个点独立编码后一步全局汇总，不建模局部邻域，细粒度几何和复杂场景表现差。
    后来针对它的工作　PointNet++ Point Transformer V3
  • 在单个物体（1024–4096点）上验证，大规模室外激光雷达点云需要切块处理，效率和精度都不够。
    后来针对它的工作　Point Transformer V3
  • 对任意三维旋转不具有不变性，依赖T-Net和数据增强。

读懂它需要的概念

多层感知机 三维表示：体素、点云、网格、隐式场 不变性与等变性 分类、检测、分割 IoU与mAP

本篇术语

  • 点云　一组三维坐标点（可附带颜色、强度），没有固定顺序和网格结构，激光雷达和深度相机的原始输出就是点云。
  • 对称函数　输入任意打乱后输出不变的函数，例如求和、取最大值。PointNet用逐维最大值实现排列不变。
  • 临界点集　在全局特征某一维上取到最大值的那些点。全局特征只由它们决定，删掉其他点输出不变。

怎么学

先确认理解多层感知机和不变性与等变性里“不变性”的含义。读原文第4.2节（三个模块）和图2结构图，再看第5.3节的临界点可视化。动手：用PyTorch写一个只有共享MLP和最大池化的PointNet，在ModelNet40上跑分类，然后把输入点的顺序打乱，验证输出完全一致。
