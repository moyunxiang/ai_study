RMA快速运动适应

RMA: Rapid Motor Adaptation for Legged Robots
2021.07论文重要RSS 2021Ashish Kumar, Zipeng Fu, Deepak Pathak, Jitendra Malik · UC Berkeley / CMU / Facebook AI Research待核对
arXiv ↗项目主页（含视频） ↗在交互版中打开（演化树、学习进度）

问题

仿真训练的足式策略到了真实世界，地面软硬、摩擦、负重、电机磨损都在变；域随机化只能学一个对所有情况都凑合的保守策略，前作还依赖人工设计的足端轨迹和电机模型。

方法

把“环境长什么样”压成一个低维隐向量：仿真里用真实环境参数算出它来训练基础策略，再训练一个适应模块，只看最近0.5秒的状态和动作历史就推断出这个向量，真机上实时更新。

影响

一台低成本的Unitree A1不经任何真机微调，就能在沙地、泥地、草丛、碎石和楼梯上行走并在不到一秒内适应变化；“历史推断隐环境因子”成为足式sim2real的通用组件。

背景

足式机器人强化学习和ANYmal复杂地形行走证明了仿真里训练的策略能上真机，但都依赖一些领域知识：精心辨识的执行器模型、预先设计的足端轨迹生成器。而且真实世界一直在变：从水泥地走到沙地，背上多了几公斤东西，电机用久了变弱。

域随机化与Sim2Real的思路是让策略在训练时见过足够多的变化，于是对所有情况都鲁棒。代价是策略不知道自己当下处在哪种情况，只能取一个折中、偏保守的行为。人走路不是这样：一脚踩进沙里，下一步立刻会调整。更理想的是在线适应：先判断“现在的地面和身体是什么状态”，再据此调整动作。

方法

第一阶段：带“作弊信息”的基础策略。在RaiSim仿真里随机生成分形起伏地形，并随机化质量、重心、摩擦、电机强度等17个环境参数，记为 e_t。一个编码器 μ 把它压成低维的“外部因子”向量 z_t = μ(e_t)。基础策略 a_t = π(x_t, a_{t−1}, z_t) 输入当前30维本体状态（12个关节角、12个关节速度、机身横滚和俯仰、4个足底接触）、上一步动作和 z_t，输出12个关节的目标角度。μ 和 π 一起用PPO训练。奖励借鉴生物能量学，惩罚做功和能耗，不需要参考步态或轨迹生成器。

第二阶段：学会从历史推断环境。真机上测不到 e_t。但环境参数会体现在“我下达的动作”和“身体实际怎么动”的差别里。适应模块 φ 输入最近 k=50 步（0.5秒）的状态和动作，用一维卷积网络输出估计值 ẑ_t，用监督学习让它逼近 z_t；训练数据由策略在仿真里自己走出来。

部署。基础策略100 Hz运行，适应模块10 Hz异步运行，随时更新 ẑ_t。这让它能在A1有限的机载算力上跑起来。

结果

同一个策略，不做仿真校准也不做真机微调。论文报告在沙地、泥地、徒步小道、高草丛和土堆上所有试验都没有失败；沿徒步小道下台阶成功率70%，走过水泥堆和鹅卵石堆80%。在记忆泡沫床垫等软地面上成功率100%，A1出厂控制器则在不平的泡沫上走不过去。负重实验中，A1自重12千克，出厂控制器在负重8千克时开始变差，RMA的表现更好。

后来的发展

“基础策略+历史适应模块”的两阶段结构，被四足跑酷（四足跑酷）、人形机器人行走（人形机器人RL行走）等后续工作广泛采用或改写；也有工作把它推广到机械手和无人机。它与ANYmal复杂地形行走的教师—学生蒸馏一起，构成了今天足式机器人sim2real的两种标准写法。

  • 使用
    PPO2017.07 · RL
    基础策略和环境编码器一起用PPO训练。
  • 延续
    域随机化与Sim2Real2017.03 · 具身·世界模型
    不再只求对所有随机化环境都鲁棒，而是显式推断当前处在哪种环境，从“鲁棒”走向“适应”。
  • 改进
    足式机器人强化学习2019.01 · 具身·世界模型
    去掉了前作依赖的人工执行器模型和足端轨迹生成器，并加入在线适应，使策略能在部署时随环境变化调整。
  • 竞争
    ANYmal复杂地形行走2020.10 · 具身·世界模型
    同样先用特权信息训练、再迁移到只用本体感觉的策略；RMA只让学生估计低维环境向量而不模仿整个动作，并且不依赖轨迹生成器。
  • 改进
    MIT Cheetah 3凸MPC2018.10 · 具身·世界模型
    依赖人为设定的步态时序和平坦或已知地形，在复杂地形上不如后来的强化学习策略鲁棒。

本篇术语

  • 外部因子（extrinsics）　RMA里对“机器人所处环境”的低维隐向量编码，由摩擦、负重、地形等参数压缩而来，策略据此调整动作。
  • 在线适应　部署过程中根据最近的经验不断调整行为，而不是带着一组固定参数去应对所有情况。
  • Unitree A1　宇树科技出品的低成本小型四足机器人，自重约12千克，2020年代初被学术界大量使用。

怎么学

先补PPO与domain randomization → 读原文第III节（RMA两阶段训练）和图1 → 动手：在开源的legged_gym里给机器人加上随机负重，比较只用随机化和加上历史适应模块两种策略的表现。
