MLC LLM与WebLLM

2023.04系统延伸2023MLC团队 · MLC AI待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

大模型推理多依赖NVIDIA GPU上的专用库，想在手机、浏览器或各种显卡上跑需要逐平台手写内核。

方法

基于TVM深度学习编译器系列的机器学习编译器，把模型一次编译到CUDA、Vulkan、Metal、OpenCL、WebGPU等后端，并提供统一的引擎和OpenAI兼容接口。

影响

让同一个大模型能在浏览器、手机和不同厂商GPU上本地运行。

方法

MLC LLM自称是面向大语言模型的机器学习编译器和高性能部署引擎，目标是让人们在各种设备上原生构建、优化和运行模型。README列出的后端包括：Linux/Windows上的AMD、NVIDIA、Intel GPU（Vulkan、ROCm或CUDA），macOS和iOS的Metal，浏览器的WebGPU与WASM，Android的OpenCL（Adreno和Mali）。运行时叫MLCEngine，提供REST、Python、JavaScript、iOS、Android接口，且兼容OpenAI API。README引用TVM、TensorIR和MetaSchedule论文作为其底层技术；WebLLM是其相关的浏览器端项目。首发日期以骨架为准，未单独核实。

局限与后续

  • 编译一个新模型和新后端需要较多适配工作，易受上游编译器变动影响。
