LightGCN图推荐

LightGCN: Simplifying and Powering Graph Convolution Network for Recommendation
2020.02论文延伸SIGIR 2020Xiangnan He, Kuan Deng, Xiang Wang, Yan Li, Yongdong Zhang, Meng Wang · 中国科学技术大学、新加坡国立大学、快手、合肥工业大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图卷积网络已成为协同过滤推荐的最好方法，但它照搬了为节点分类设计的特征变换和非线性激活，没人认真检验这些部件在推荐里是否有用。

方法

消融发现特征变换和非线性激活对协同过滤几乎没贡献，反而让训练更难；于是只保留邻域聚合：用户和物品嵌入在交互图上线性传播，各层结果加权求和作为最终嵌入。

影响

成为图推荐领域引用最多的基线之一，说明在推荐任务上更简单的GNN往往更好。

方法

推荐数据可以看成一张用户—物品二部图，有交互就连边。此前的NGCF在每层做“邻居聚合 + 权重矩阵变换 + 非线性”。LightGCN把后两者都去掉，每层只做对称归一化的邻居求和：

e_u^{(k+1)} = Σ_{i∈N(u)} e_i^{(k)} / √(|N(u)|·|N(i)|)，物品侧同理。

唯一可训练的参数是第0层的用户和物品嵌入。K层传播后，把各层嵌入加权求和（默认取平均）e_u = Σ_k α_k e_u^{(k)}，层组合既缓解了过平滑，也相当于自带了跨层的残差。预测分数是用户与物品最终嵌入的内积，用BPR成对排序损失训练。作者还分析了它与简化图卷积SGC、APPNP先预测后传播等简化GNN的联系。摘要报告它比NGCF更简洁、更易训练、效果明显更好。

局限与后续

  • 只用交互图，不利用用户和物品的属性特征；冷启动的新用户、新物品没有可传播的连接。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    图卷积网络2016.09 · 基础
    保留GCN的归一化邻域聚合，去掉特征变换与非线性。
  • 竞争
    低秩矩阵补全2008.05 · 基础
    矩阵分解式协同过滤的图视角推广：0层LightGCN就是嵌入内积的矩阵分解。
  • 改进
    GCN过平滑2018.01 · 基础
    用各层嵌入加权求和缓解多层传播的过平滑。
  • 延续
    简化图卷积SGC2019.02 · 基础
    与SGC同样去掉非线性，进一步在推荐场景中去掉了特征变换矩阵。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

图、树与搜索 图神经网络与消息传递 嵌入向量 内积与余弦相似度

怎么学

先了解协同过滤与矩阵分解；读论文第3节的传播式与层组合；动手用PyG的LightGCN在MovieLens上训练，比较1到4层的Recall@20。
