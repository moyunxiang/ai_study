LSUN场景与物体库

LSUN: Construction of a Large-scale Image Dataset using Deep Learning with Humans in the Loop
2015.06数据集延伸arXiv 2015Fisher Yu, Ari Seff, Yinda Zhang, Shuran Song, Thomas Funkhouser, Jianxiong Xiao · Princeton University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

深度网络越来越大，人工标注的数据集却跟不上；全靠人一张张标，几百万张图的成本太高。

方法

让人只标一小部分，用这部分训练分类器给其余图片打分，把高置信的直接定为正例或负例，中间不确定的留到下一轮，如此迭代，人力放大约40倍。

影响

它的10个场景类和20个物体类各有上百万张图；卧室、教堂、猫、汽车等单类子集后来成为GAN和扩散模型最常用的无条件生成基准。

方法

据论文，每个类别先用谷歌图片搜索收集上千万到上亿张候选图，过滤掉短边小于256像素的。每轮从未标注池里随机抽4万张，由众包标注Mechanical Turk工人标注（每张两人；每个任务含55张已知答案的质控图），用于训练和标定分类器：前几轮用AlexNet特征加两层MLP，后面换成微调的GoogLeNet / Inception。按标注的测试部分设两条阈值：高于正阈值的图里95%是真正例，低于负阈值的部分只漏掉1%的正例；两条阈值之间的图进入下一轮。

最终下载了10亿多张图，得到20个物体类（与PASCAL VOC相同的20类）共5900万张、10个场景类（取自SUN与Places场景库的SUN类别）共1000万张已标注图像，人工只看了不到总量的1/40。

结果

据论文，用专家抽检得到的平均精度约为90%，但不同类别差异较大。在Places测试集上，加入LSUN训练使场景分类错误率从28.6%降到22.2%；在PASCAL VOC 2012分类上，用LSUN预训练比ImageNet预训练更好（AlexNet 0.87对0.80，VGG 0.88对0.82）。

在生成模型里，它主要以单类子集出现：渐进式增长GAN在LSUN的各个类别上分别训练了模型；StyleGAN报告的FID为卧室2.65（256×256）、汽车3.27、猫8.53，DDPM等扩散模型也沿用卧室和教堂子集。

局限与后续

  • 标签有一成左右噪声，主要来自玩具、电脑渲染图、拼贴和修图；初始图片池没有去重。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 单类子集内容高度同质（如卧室全是室内照），生成模型在上面的FID只能说明单一领域的拟合能力，不反映多类别、可控的生成。

它建立在什么之上

  • 使用
    PASCAL VOC2005 · 数据·评测
    20个物体类与PASCAL VOC相同，并在VOC 2012上验证预训练效果。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测
    人工标注由众包工人完成，配有内嵌质控图和准确率门槛。
  • 延续
    SUN与Places场景库2010.06 · 数据·评测
    场景类别取自SUN数据库，但每类规模扩大到约百万张。
  • 使用
    GoogLeNet / Inception2014.09 · 视觉
    迭代后期用微调的GoogLeNet给未标注图片打分，决定哪些自动接收。

读懂它需要的概念

监督学习 准确率、精确率、召回率与F1 迁移学习 生成质量指标：IS与FID

本篇术语

  • 人在回路标注　人和模型交替工作：人标一小批，模型学了以后自动处理有把握的部分，只把没把握的交回给人。
  • LSUN Bedroom / Church / Cat / Car　LSUN里单个类别的子集（卧室、教堂、猫、汽车等），生成模型论文常把它们缩放到256×256等分辨率，各训练一个无条件生成模型并报告FID。

怎么学

先读FID与Inception Score和StyleGAN讲解；动手：从LSUN卧室子集取几千张图，用一个小的生成模型训练并计算FID，体会单一场景的数据为什么容易得到低FID。
