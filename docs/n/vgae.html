变分图自编码器VGAE

Variational Graph Auto-Encoders
2016.11论文延伸NIPS 2016 Bayesian Deep Learning WorkshopThomas N. Kipf, Max Welling · 阿姆斯特丹大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

图上的无监督学习和链接预测（猜哪两个节点之间缺了一条边）当时多用DeepWalk图嵌入这类随机游走嵌入或矩阵分解，很难利用节点自带的特征。

方法

把变分自编码器VAE搬到图上：用图卷积网络做编码器，为每个节点输出一个高斯隐变量；解码器只用两个节点隐向量的内积来预测它们之间有没有边。

影响

成为图自编码器和链接预测最常用的基线，GAE/VGAE的“GCN编码+内积解码”结构被大量后续的图生成、图对比学习和推荐系统工作沿用。

方法

输入是无向图的邻接矩阵A和节点特征矩阵X。编码器是两层图卷积网络：第一层得到共享的隐层表示，第二层分别输出每个节点隐变量的均值μ和对数方差logσ，再用重参数化技巧采样 z_i = μ_i + σ_i ⊙ ε。

解码器非常简单：节点i和j之间有边的概率为 p(A_ij=1) = sigmoid(z_iᵀ z_j)，即隐向量越接近，越可能相连。训练目标是VAE的变分推断与ELBO：重构邻接矩阵的对数似然，减去每个节点后验与标准正态先验之间的KL散度。去掉随机性、只用均值的版本叫图自编码器（GAE）。

摘要报告：在引文网络的链接预测任务上，VGAE取得有竞争力的结果；与多数已有的图无监督学习和链接预测方法不同，它能自然地利用节点特征，这在多个基准数据集上显著提升了预测性能。

局限与后续

  • 内积解码器只能表达对称、“相似即相连”的关系，难以刻画有向边或“不同类节点才相连”的异配结构；重构整个邻接矩阵的代价随节点数平方增长。
