SAT证明布尔毕达哥拉斯三元组

Solving and Verifying the Boolean Pythagorean Triples Problem via Cube-and-Conquer
2016.05论文延伸SAT 2016Marijn Heule, Oliver Kullmann, Victor Marek待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

能否把自然数分成两部分，使得两部分都不含毕达哥拉斯三元组a²+b²=c²？这是拉姆齐理论中的悬而未决问题。

方法

把问题编码成布尔可满足性（SAT）问题，用Cube-and-Conquer把它切成大量子问题并行求解，同时输出可独立检验的证明。

影响

当时数学中最大的证明之一，展示SAT求解器可以解决人类数学家无法手工处理的问题。

方法

结论是：不存在这样的划分，无论怎样二分，总有一部分含有毕达哥拉斯三元组。

方法是Cube-and-Conquer：先用look-ahead求解器把问题切成许多“方块”（cube）子问题，再让CDCL求解器逐个求解。据摘要，计算在800个核的集群上运行约2天，生成的DRAT证明接近200太字节，作者从中提取出68吉字节的压缩证书，供别人重构并验证。
