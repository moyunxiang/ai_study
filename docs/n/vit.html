Vision Transformer

An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale
2020.10论文主干ICLR 2021Alexey Dosovitskiy, Lucas Beyer, Alexander Kolesnikov, Dirk Weissenborn, Xiaohua Zhai, Thomas Unterthiner, Mostafa Dehghani, Matthias Minderer et al. · Google Research, Brain Team来源已核对
arXiv ↗官方代码（big_vision / vision_transformer） ↗timm中的ViT实现 ↗在交互版中打开（演化树、学习进度）

问题

Transformer已统治自然语言处理，但视觉仍以卷积网络为主；注意力只被当作CNN的附加模块，而对每个像素做自注意力计算量又太大。

方法

把图像切成16×16像素的小块，每块线性映射成一个向量，当作一个“词”，整串送进几乎不加修改的标准Transformer编码器做分类。

影响

在足够大的数据上预训练后，纯Transformer与当时最强的卷积网络相当或更好，预训练算力更少；之后CLIP、MAE、DINO、SAM、DiT和许多多模态大模型的视觉部分都采用了ViT结构。

背景

从AlexNet到ResNet，卷积网络（见卷积层、池化与感受野）统治视觉近十年。卷积有两个内置假设（归纳偏置）：局部性——一个像素只和邻近像素直接相关；平移等变——同一个卷积核在图上每个位置共用，猫在左上角和右下角用同样的方式识别。这些假设让CNN在中等规模数据上很省样本。

同期在语言领域，Transformer靠自注意力和大规模预训练（BERT、GPT-3）一路做大，模型越大越好。视觉界也尝试引入注意力：Non-local网络在CNN里插入自注意力模块，另一些工作用局部窗口注意力替换卷积，但整体仍是CNN的骨架，而且论文指出，这些专用的注意力模式需要复杂的工程才能在硬件加速器上高效运行。直接对像素做自注意力也不现实：224×224的图有约5万个像素，自注意力的计算量随序列长度平方增长。同年的Image GPT先降低分辨率和颜色空间、再对像素做Transformer，ImageNet上最高72%。

此时大规模图像识别的最好成绩仍属于卷积网络：BiT大规模迁移（大规模迁移的ResNet）和Noisy Student自训练（半监督的EfficientNet）。问题是：能不能像NLP一样，用一个几乎不改的标准Transformer直接处理图像？

方法

切块变成token（见图像块与视觉token）。一张224×224×3的图切成16×16像素的小块，共(224/16)² = 196块。每块展平成16×16×3 = 768个数，再乘一个可学习矩阵映射成D维向量（ViT-Base中D = 768）。这一步等价于一个核大小和步长都是16的卷积。196个patch向量就是196个“词”。

位置编码与分类token。自注意力本身不分先后，所以给每个位置加一个可学习的位置向量（见位置编码）；作者试过显式的二维位置编码，没有明显收益，于是用最简单的一维版本。仿照BERT，在序列最前面加一个可学习的[class] token，它最终的输出作为整张图的表示，接一个小分类头。

编码器。之后就是标准的Transformer编码器（见Transformer层的结构）：每层是LayerNorm → 多头自注意力 → 残差，再LayerNorm → 两层MLP（GELU）→ 残差。三种规模：

  • ViT-Base：12层、宽768、12头，8600万参数
  • ViT-Large：24层、宽1024、16头，3.07亿参数
  • ViT-Huge：32层、宽1280、16头，6.32亿参数

名字里的“/16”“/14”是块的边长。块越小序列越长，计算越重：ViT-H/14在224分辨率下有256个token。

训练。先在大数据集上有监督预训练：ImageNet-1k（130万张）、ImageNet-21k（1400万张、2.1万类）或Google内部的JFT-300M（3.03亿张、1.8万类），用Adam、批大小4096、权重衰减0.1。再在下游任务上微调，微调时常换更高分辨率：块大小不变，序列变长，预训练的位置编码按二维位置插值到新网格上。

与CNN相比，ViT只在“切块”和“微调时插值位置编码”两处用到图像的二维结构，其余空间关系全部从数据中学。论文的说法是：CNN的每一层都内置了局部性、二维邻域结构和平移等变；ViT里只有逐个token计算的MLP层是局部、平移等变的，自注意力层是全局的。

结果

数据量决定胜负。只在ImageNet-1k上训练、正则化不强时，ViT比同等大小的ResNet低几个百分点（附录表5中只用ImageNet的ViT-B/16为77.9%）；在ImageNet上预训练时ViT-Large甚至不如ViT-Base。换成ImageNet-21k两者相当，到JFT-300M时大模型的优势才完全显现。在JFT的子集上对比：数据为900万张时ViT-B/32远不如ResNet-50，9000万张以上反超。

最好的模型ViT-H/14（JFT预训练）在ImageNet上准确率88.55%，ImageNet-ReaL 90.72%，CIFAR-100 94.55%，19项任务的VTAB 77.63%，均超过BiT-L（ResNet152x4，ImageNet 87.54%）并与Noisy Student（88.4%）相当。预训练算力：ViT-H/14约2.5千TPUv3核·天，而BiT-L为9.9千、Noisy Student为12.3千。用公开的ImageNet-21k预训练的ViT-L/16也表现良好，8核TPUv3约30天可以训完。论文还初步尝试了BERT式的掩码块预测自监督，ViT-B/16达到79.9%，比从头训练高2%，但仍比有监督预训练低4%。

后来的发展

ViT之后，大量视觉研究改用Transformer骨干。两个月后DeiT显示只用ImageNet-1k加强数据增强和蒸馏也能训好ViT；Swin Transformer、PVT金字塔ViT把它改造成多尺度、局部窗口的结构，用于检测和分割；BEiT、掩码自编码器MAE沿着论文结尾提出的自监督方向，用掩码预训练取得了好于从头有监督训练的结果，DINO、DINOv2用自蒸馏学到通用特征。CLIP的图像编码器有ViT版本，此后许多多模态大模型（如LLaVA）以CLIP或SigLIP的ViT作为视觉编码器；Segment Anything的图像编码器是MAE预训练的ViT；图像生成领域Diffusion Transformer把扩散模型的骨干也换成了ViT。

卷积网络一侧也有回应：ConvNeXt按视觉Transformer的设计逐步改造ResNet，显示纯卷积网络仍有竞争力。之后的视觉Transformer相对原论文的变化主要在：用自监督或图文对比代替有监督预训练、支持可变分辨率（NaViT任意分辨率）、加入寄存器token（ViT需要寄存器）；编码器主体结构变化不大。

容易误解的地方

  • “一张图值16×16个词”并不是说一张图有16×16个词，而是每个词对应一块16×16像素。224分辨率下是14×14 = 196个词。
  • ViT胜过CNN的前提是大规模预训练。论文明确报告：只用ImageNet时它不如ResNet。“Transformer比CNN强”是有数据量条件的。
  • 分块嵌入层本质上就是一个步长等于核大小的卷积，所以ViT并非完全没有卷积，只是不再堆叠卷积。

它建立在什么之上

  • 竞争
    ResNet2015.12 · 视觉 已核对
    与卷积网络正面对比：小数据上ResNet更好，数据到9000万张以上ViT反超，并且预训练算力更少。
  • 改进
    Transformer2017.06 · LLM 已核对
    几乎原样使用Transformer编码器，把图像块当成词，显示它在视觉上同样可以随数据和模型规模扩展。
  • 使用
    BERT2018.10 · LLM 已核对
    借用BERT的[class] token汇总整张图，并照搬“大规模预训练 + 微调”的范式；还试了BERT式的掩码块预测。
  • 使用
    JFT-300M2017.07 · 数据·评测 已核对
    最好的结果依赖JFT-300M上的有监督预训练，数据规模是ViT胜出的关键。
  • 竞争
    Non-local网络2017.11 · 视觉 已核对
    两种引入注意力的路线：Non-local把自注意力当作插进卷积网络的模块（ViT引言把它列为“注意力与卷积网络结合”的例子）；ViT去掉卷积主干，只用标准Transformer。
  • 竞争
    Noisy Student自训练2019.11 · 视觉 已核对
    当时ImageNet最高分的EfficientNet半监督方法；ViT-H/14精度相当，预训练算力约为其五分之一。
  • 竞争
    BiT大规模迁移2019.12 · 视觉 已核对
    同一团队的大规模迁移ResNet是主要对手。论文称在同样的JFT-300M上预训练，ViT-L/16在所有任务上超过BiT-L，预训练算力约为其1/14（0.68k对9.9k TPUv3核·天）；但表2中两者ReaL同为90.54、VTAB为76.28对76.29，这两项实际持平。
  • 竞争
    Image GPT2020.06 · 生成 已核对
    iGPT先降低分辨率和颜色空间再对像素序列做Transformer（ViT引用其ImageNet最高72%）；ViT以16×16的块为单位，序列短得多，可以在正常分辨率下训练。
  • 改进
    DenseNet2016.08 · 视觉
    仍是纯卷积结构，每层只看局部邻域，长距离依赖要靠堆叠很多层间接获得。
  • 改进
    SENet通道注意力2017.09 · 视觉
    只在通道维度做重新加权，没有建模空间位置之间的关系。

读懂它需要的概念

自注意力与多头注意力 Transformer层的结构 图像块与视觉token 位置编码 归纳偏置 预训练与微调 卷积层、池化与感受野

本篇术语

  • patch embedding　把每个图像块展平后乘以同一个矩阵，得到一个向量，作为Transformer的输入token。
  • [class] token　额外加在序列最前面的可学习向量，经过各层注意力汇集全图信息，最终用来做分类。
  • ViT-B/16　ViT的命名方式：B/L/H表示Base、Large、Huge三种规模，斜杠后的数字是块的边长（像素）。
  • TPUv3核·天　论文衡量训练算力的单位：使用的TPU v3核数乘以训练天数。

怎么学

先确认会自注意力与多头注意力和Transformer层的结构，最好已读懂Transformer。读原文第3.1节（只有一页的模型描述和公式1–4）、第4.4节（数据规模实验，图3、图4）。然后读timm的vision_transformer.py，或照Andrej Karpathy式的极简写法自己写一个ViT：PatchEmbed → 加位置编码和cls token → N个编码器层 → 分类头。在CIFAR-10上从头训练，再加载ImageNet-21k预训练权重微调，对比两者，体会数据规模和预训练的作用。

  • 3.1节原话：CNN每一层都内置局部性、二维邻域结构和平移等变；ViT只有MLP层是局部且平移等变的，自注意力层是全局的；二维邻域结构只在切块和微调时调整位置编码两处使用，块之间的空间关系要从头学
  • 引言：在ImageNet这类中等规模数据上不加强正则时，比同等大小的ResNet低几个百分点；“大规模训练胜过归纳偏置”
  • 表1：Base 12层/768/12头/86M，Large 24层/1024/16头/307M，Huge 32层/1280/16头/632M
  • 二维位置编码没有明显收益（附录D.4中1D与2D几乎相同）；微调时对预训练位置编码做二维插值
  • Adam（β1=0.9、β2=0.999）、批4096、权重衰减0.1；ImageNet 1.3M张1k类、ImageNet-21k 14M张21k类、JFT 303M张18k类
  • 表2：ViT-H/14为88.55/90.72/94.55/77.63、2.5k TPUv3核·天；ViT-L/16为87.76/90.54/93.90/76.28、0.68k；BiT-L为87.54/90.54/93.51/76.29、9.9k；Noisy Student 88.4、12.3k
  • ViT-L/16用ImageNet-21k预训练可在8核TPUv3上约30天训完
  • 在ImageNet上预训练时ViT-Large不如ViT-Base；JFT的9M/30M/90M子集上，ViT-B/32在9M上远差于ResNet50、90M以上更好
  • 附录表5：只用ImageNet的ViT-B/16为77.9%
  • 4.6节掩码块预测：ViT-B/16 79.9%，比从头训练高2%，比有监督预训练低4%
  • 相关工作：iGPT降低分辨率和颜色空间、ImageNet最高72%；引言引用Wang et al. 2018（Non-local）作为注意力与CNN结合的例子；专用注意力模式需要复杂工程才能在硬件加速器上高效运行
  • 结论列出的挑战：用于检测和分割、自监督与大规模有监督预训练之间仍有很大差距、继续扩大规模
