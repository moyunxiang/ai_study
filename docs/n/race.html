RACE考试阅读理解

RACE: Large-scale ReAding Comprehension Dataset From Examinations
2017.04数据集延伸EMNLP 2017Guokun Lai, Qizhe Xie, Hanxiao Liu, Yiming Yang, Eduard Hovy · 卡内基梅隆大学语言技术研究所待核对
arXiv ↗数据下载 ↗在交互版中打开（演化树、学习进度）

问题

SQuAD、CNN/Daily Mail等阅读理解数据的答案直接从原文抽取或靠自动挖空生成，多数题靠词语匹配就能答，模型分数很快逼近人类，却不说明真的读懂了。

方法

直接收集中国初高中英语考试的阅读理解题：近2.8万篇文章、近10万道由英语教师出的四选一题，答案选项不一定在原文中出现，需要推理的题比例远高于已有数据。

影响

发布时最好模型只有44.1%，人类上限约95%；随后GPT-1、ALBERT、DeBERTa、Megatron-LM等预训练模型都把它列为主要评测，是BERT时代考“长文推理阅读”的常用考题。

方法

来源。题目取自面向12–18岁中国学生的英语考试，按难度分成RACE-M（初中，12–15岁）和RACE-H（高中，15–18岁）。每篇文章配若干道四选一题，题目和选项由英语教师编写，形式有问句也有填空句。两部分各留5%作开发集、5%作测试集：RACE共27,933篇文章、97,687道题，其中测试集1,407篇、4,934题。高中部分文章平均353词，明显长于初中的231词。

推理比例。作者从测试集各抽50篇（500题）请Amazon众包工人作答并标注题型，分为词语匹配、改写、单句推理、多句推理和无法回答五类。RACE中59.2%的题属于单句或多句推理，而CNN、SQuAD、NewsQA分别只有21%、20.5%、33.9%；纯词语匹配题只占15.8%。推理题又细分为细节推理、全文理解、概括、作者态度和常识推理等。

人类上限。众包工人在RACE-M上85%、RACE-H上70%，作者认为部分工人不够认真，于是人工检查题目是否有唯一正确答案，得到有效题比例94.5%，作为人类上限。

结果

在全集上，滑动窗口匹配算法为32.2%，Stanford Attentive Reader为43.3%，Gated-Attention Reader为44.1%，众包工人73.3%，上限94.5%。之后的预训练模型迅速拉近差距：ALBERT参数共享的摘要称在RACE上刷新最好成绩，DeBERTa解耦注意力的摘要报告比RoBERTa-Large从83.2%提高到86.8%。

后来的发展

RACE和SQuAD、GLUE / SuperGLUE一起，构成2018–2020年预训练语言模型论文的固定评测组合：GPT-1、RoBERTa、ALBERT参数共享、Megatron-LM模型并行、DeBERTa解耦注意力都报告了它的分数。到2020年，面向医学考试的MedQA医师执照考试题在引言里已把RACE列为预训练模型接近做满的数据集之一。分数超过90%以后，大模型评测的重心转向MMLU这类多学科考试。

局限与后续

  • 题目来自公开流传的中国英语考试资料，网页语料里可能含有原题与答案，大模型的高分难以排除记忆。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 四选一形式的随机基线有25%，干扰项由人编写，模型可能利用选项本身的措辞规律而不读文章。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    注意力阅读器与CNN/DM2015.06 · NLP
    注意力阅读器带来的CNN/Daily Mail是自动挖空生成的完形题，噪声大、人类上限也受限；RACE改用教师出的考试题。同类注意力阅读器在CNN上约74%，在RACE上只有43%左右。
  • 改进
    SQuAD2016.06 · 数据·评测
    SQuAD的答案都是原文片段、多数题靠匹配可答；RACE用教师出的四选一题，选项不一定出现在原文，推理题比例约59%对SQuAD的20.5%。

后来的相关工作

  • 竞争
    MedQA医师执照考试题2020.09 · 数据·评测
    论文引言把RACE等给定文章的阅读理解列为预训练模型已接近做满的任务，MedQA不提供文章、要求自己检索证据。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

基准、排行榜与SOTA 注意力机制 准确率、精确率、召回率与F1 预训练与微调

本篇术语

  • RACE-M / RACE-H　RACE的初中部分（27,933篇里的约7,100篇）和高中部分；高中部分文章更长、词汇量更大，模型分数也明显更低。
  • 人类上限（ceiling performance）　作者人工核查后认为有唯一正确答案的题目比例（94.5%），代表理想读者能达到的最高准确率。

怎么学

先读SQuAD了解抽取式阅读理解的局限。读原文第3节（题型标注与表4的推理比例）和表5。动手：从RACE-H测试集里随机挑20道题，自己判断每道属于匹配、改写还是推理，再用一个预训练模型做四选一，看它在推理题上错得多不多。
