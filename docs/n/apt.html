APT主动预训练

Behavior From the Void: Unsupervised Active Pre-Training
2021.03论文延伸NeurIPS 2021Hao Liu, Pieter Abbeel · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

想在没有奖励的环境里先预训练智能体，常见目标是最大化访问状态的熵，但在图像观测下需要估计高维密度，几乎做不到。

方法

在学到的低维表示空间里，用粒子式的k近邻距离来估计状态熵：每个状态离它的第k个近邻越远，说明这里越稀疏、越新，就给越高的内在奖励。无须建密度模型。

影响

让“最大化状态熵”的无监督预训练在像素输入下可行，成为无监督RL基准URLB里的核心基线，后续的ProtoRL、CIC等都沿用了k近邻熵奖励。

背景

视觉和语言领域已经证明“先在无标签数据上预训练、再在下游任务上微调”很有效；强化学习的对应做法是先在无奖励环境里探索、学行为和表示，再接上任务奖励。一个自然的无监督目标是让访问的状态分布熵尽可能大（覆盖尽可能多的状态），但熵需要密度，在高维图像上估计密度又难又慢；随机网络蒸馏RND、计数这类新颖度奖励则不直接对应熵。

方法

APT分两部分同时训练。

表示：用对比学习（与CURL对比表征RL、SimCLR类似）把图像观测编码成低维向量 z = f(s)。

奖励：对一批 z 用粒子式（非参数）熵估计器。熵 H(z) 可以用每个样本到其第k个近邻的距离来近似：Ĥ ∝ Σ_i log ‖z_i − z_i^{(k)}‖。于是给每个状态的内在奖励设为

r(s) = log( c + (1/k) Σ_{j∈kNN(z)} ‖z − z_j‖ )

c是防止取对数爆掉的常数。离已访问状态越远，奖励越高。策略用离策略演员—评论家算法在这一奖励上训练；预训练结束后，换上任务奖励继续微调。整个过程不需要密度模型，也不需要预测下一状态。

结果

摘要称：先进行长时间的无监督预训练再给任务奖励，在Atari上APT在12个游戏上达到人类水平，并与标准的全监督RL算法相比很有竞争力；在DMControl上，APT在渐近性能和数据效率上都超过所有基线，并显著改善了从零训练极难的任务。

后来的发展

k近邻熵奖励后来被大量无监督RL工作采用：同组随后的URLB无监督RL基准把APT列为“基于数据”的代表方法，ProtoRL用原型网络加快近邻计算，CIC把它与对比技能学习结合。它也让“RL预训练—微调”这一设定成为一条独立的研究线。

局限与后续

  • k近邻只在一个批次或回放池样本里计算，熵估计有偏，且随表示的变化而漂移，奖励不平稳。

读懂它需要的概念

信息量与熵 k近邻 对比学习 探索与利用 预训练与微调

本篇术语

  • 粒子式熵估计　不估计概率密度，而是用样本之间的距离来近似熵：样本彼此离得越远，分布越分散，熵越大。
  • 无监督RL预训练　先在没有任务奖励的环境中用内在奖励训练智能体，再接上任务奖励微调，类似视觉和语言里的预训练。

怎么学

先补信息量与熵和k近邻；读原文第3节熵估计与奖励的推导；用URLB的开源代码在一个DMC任务上跑APT预训练加微调，与从零训练比较曲线。
