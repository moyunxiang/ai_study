引导策略搜索GPS

Guided Policy Search
2013.06论文重要ICML 2013Sergey Levine, Vladlen Koltun · Stanford University待核对
PMLR论文 ↗项目页与视频 ↗在交互版中打开（演化树、学习进度）

问题

用策略梯度直接训练有几百上千个参数的神经网络控制器，需要海量试验，而且很容易卡在差的局部最优，比如让机器人一直摔倒。

方法

先用轨迹优化（DDP）算出几条高回报的动作轨迹作为“引导样本”，再用带正则的重要性采样把这些样本纳入策略优化，让网络向好轨迹靠拢，而不是盲目探索。

影响

把“轨迹优化当老师、神经网络当学生”变成一种可行的强化学习方法，为两年后直接从图像训练机械臂策略的端到端视觉运动学习打下基础。

背景

强化学习里的直接策略搜索（见策略梯度）在机器人上很受欢迎，因为它能扩展到高维动作。但当时的成功几乎都依赖专门设计的策略形式，比如只跟踪一条轨迹的控制器（如动态运动基元DMP），这限制了能学到的行为：一个只会沿固定轨迹走的策略，没法根据当前状态选择不同的走法。

如果改用通用的神经网络策略，REINFORCE策略梯度式的似然比梯度每一步都需要用当前策略重新采样，并且极易陷入局部最优——一个网络很快学会“原地摔倒”就停在那里。另一边，轨迹优化方法（如微分动态规划DDP，它是LQR最优控制在非线性系统上的推广）在已知模型时能快速找到一条好轨迹，但得到的是一个只在这条轨迹附近有效、随时间变化的控制器，不能泛化到新情况。

方法

第一步：生成引导样本。用DDP（可以从一段示范动作初始化，比如人类跑步的动作捕捉）解出一条高回报轨迹和它附近的线性反馈控制器。作者把DDP改成从“高回报轨迹的分布”中采样，即一个以最优轨迹为中心的高斯分布，从中采出一批样本，它们集中在好的区域，但彼此有差异。

第二步：重要性采样的策略优化。策略的期望回报用已有样本估计：对每条样本轨迹ζᵢ按πθ(ζᵢ) / q(ζᵢ)加权（q是样本实际来自的分布，见重要性采样），这样就能用不是当前策略采出的样本（包括引导样本）计算目标。为防止权重退化——所有样本概率都很低、只有最好的一个略高——目标里加了一项w_r · log Z(θ)的正则（Z是权重的归一化项），迫使策略至少让部分样本有较高概率。因为不必每步重新采样，可以用二阶的拟牛顿法连续优化许多步。

循环。每轮加入当前策略的新样本，若策略难以跟上，再用DDP生成适应当前策略的新引导样本。策略是一个单隐层神经网络，输出加高斯噪声。

结果

在平面游泳、单腿跳、双足行走三个仿真任务上（时域500步，50个隐藏单元，最多1256个参数），引导策略搜索能学会，而去掉引导样本的变体和几种已有方法大多失败。泛化测试中，训练在平地走4米再爬10度斜坡的策略，在斜坡位置随机改变的测试地形上仍能走完，而直接执行DDP控制器会摔倒。最后用200个隐藏单元的网络学会了63维状态的三维人形机器人跑步，在四种随机坡度的测试地形上都成功，步态保留了动作捕捉的自然外观。

后来的发展

这篇的核心思路“用局部轨迹优化给全局神经网络策略提供监督”很快被推进：作者随后用从真实样本拟合的局部线性模型替代已知动力学，并在2015年的端到端视觉运动策略中用它直接从摄像头图像训练机械臂拧瓶盖、挂衣架等真实任务。此后，大规模并行仿真中的PPO（如几分钟学会走路）和从人类示范学习的方法（如Diffusion Policy）成为主流，但“教师—学生”蒸馏结构在足式机器人强化学习里仍然常见。

局限与后续

  • DDP需要已知、可微的动力学模型，实验全部在仿真中完成；真实机器人的模型往往拿不到。
    后来针对它的工作　端到端视觉运动策略
  • 策略输入是完整的仿真状态（关节角、速度等），没有处理相机图像这类高维、部分可观测的输入。
    后来针对它的工作　端到端视觉运动策略
  • 重要性权重在长时域上会严重退化，样本复用受限；网络只有几百到几千个参数，规模远小于后来的深度策略。
    后来针对它的工作　几分钟学会走路

它建立在什么之上

  • 改进
    REINFORCE策略梯度1992 · RL
    似然比策略梯度需要每步在线重新采样且易陷局部最优；GPS用重要性采样复用离策略样本，并用DDP样本把搜索引向高回报区域。
  • 改进
    《概率机器人》2005.08 · 具身·世界模型
    POMDP规划在状态稍多时就无法精确求解，书中的决策部分在实际机器人上很少能直接使用，操作任务几乎没有涉及。
  • 竞争
    DAgger2010.11 · RL
    两者都把“专家”转成可泛化的策略；DAgger需要能随时查询的专家做监督，GPS的专家是可以按需重新求解的轨迹优化器。
  • 使用
    LQR最优控制1960 · 具身·世界模型
    引导样本来自DDP，即在轨迹附近反复线性化动力学、二次化代价后求解LQR式的局部反馈控制器。
  • 改进
    直升机特技飞行RL2003 · 具身·世界模型
    策略的质量受限于学到的模型；模型不准的地方，策略在真机上会出问题。
  • 改进
    iLQR迭代线性二次调节2004 · 具身·世界模型
    只能找到局部最优，依赖初始轨迹，并且需要准确、可求导的动力学模型。
  • 竞争
    PILCO2011 · RL
    同属利用模型的策略搜索：PILCO学习高斯过程模型、数据效率高但策略很小；GPS借助轨迹优化引导，能训练有上千参数的神经网络策略。

读懂它需要的概念

策略梯度 重要性采样 多层感知机 马尔可夫决策过程 规划与模型预测控制

本篇术语

  • 轨迹优化　给定动力学模型和代价，直接优化一整条状态—动作序列使总代价最小。只对一个起点、一条轨迹有效。
  • 微分动态规划DDP　一种轨迹优化算法：在当前轨迹附近对动力学做线性化、对代价做二次近似，用LQR求出更好的轨迹和局部反馈增益，反复迭代。
  • 引导样本　不是由当前策略、而是由轨迹优化器产生的高回报样本，用来告诉策略“好的行为长什么样”。

怎么学

先补策略梯度和重要性采样，并理解LQR最优控制。读论文第2节（重要性采样目标）和第4节（DDP引导样本），对照项目页视频看三个平面任务。动手：在Gymnasium的倒立摆上用iLQR求一条轨迹，再用监督学习让一个小MLP拟合这条轨迹上的动作，对比它与iLQR控制器在不同初始状态下的表现。
