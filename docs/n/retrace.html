Retrace离策略修正

Safe and Efficient Off-Policy Reinforcement Learning
2016.06论文延伸NeurIPS 2016Munos, Stepleton, Harutyunyan, Bellemare · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

离策略学习要用旧策略采集的数据，但重要性采样修正的方差可能极大；而简单地截断又会引入偏差，甚至不再保证收敛。

方法

把多种基于回报的离策略算法写成统一形式，提出Retrace(λ)：把每一步的重要性比率截断到最多1，既低方差又安全，还能充分利用接近同策略的数据。

影响

成为深度RL里标准的多步离策略修正，被ACER、IMPALA与V-trace（V-trace的思路）等采用。

方法

多步回报（时序差分与自举里的n步、λ回报）比一步TD更快传播奖励，但数据来自行为策略μ，目标是学习策略π，两者不同就必须修正。完整的重要性采样把每步的比率 π(a|s)/μ(a|s) 连乘，方差随步数爆炸；Tree-backup干脆不用比率，在数据接近同策略时又浪费数据。

Retrace(λ)用 c = λ·min(1, π/μ) 作为每一步的跟踪系数：比率大于1时截断为1，保证方差有界；小于1时按比例缩小，在行为策略远离目标策略时自动切断很远的未来。论文证明了对应的算子是收缩映射，并称这是第一个不需要GLIE假设（无限探索下贪心）就几乎必然收敛到Q*的基于回报的离策略控制算法，作为推论还证明了Watkins Q(λ)的收敛，这是1989年以来的未解问题。论文在Atari上展示了好处。

局限与后续

  • 每一步都要读到行为策略当时的概率μ，回放里必须存下来；行为策略与目标策略差别很大时，截断使多步回报很快退化成一步。
    后来针对它的工作　IMPALA与V-trace
  • 理论保证限于表格或带收缩性质的情形，与深度网络近似结合时仍无保证。

它建立在什么之上

  • 使用
    时序差分学习1988 · RL
    基于TD(λ)的资格迹思想构造多步目标。
  • 延续
    Q-learning1992 · RL
    把Q学习的一步离策略更新推广成带截断重要性采样的多步更新。
  • 改进
    经验回放1992 · RL
    只敢回放与当前策略一致的动作，大量旧经验被丢弃；用神经网络时回放离策略数据容易带偏价值估计。
