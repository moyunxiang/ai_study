Luma Dream Machine

2024.06模型延伸Luma AI（Luma Labs）待核对
维基百科 ↗Luma官网 ↗在交互版中打开（演化树、学习进度）

问题

Sora只发布了演示，普通用户在2024年上半年还用不上高质量的文生视频模型。

方法

直接向公众开放文字与图片生成视频的模型。

影响

在Sora之后几个月内，让高质量视频生成面向所有人开放，引发社交媒体上的二次创作热潮。

方法

Dream Machine由旧金山的Luma Labs制作，此前该公司做过3D模型生成器Genie。据维基百科，它于2024年6月12日向公众开放，公司在X上发布了示例。上线不久用户就拿Midjourney生成的图片做成视频，把名画和网络梗图做成动态画面。

它能根据文字或静态图片生成视频。维基百科也提到评论者批评其对训练数据缺乏透明度。官方没有公开模型架构，所以技术细节不详。

后来的发展

它与可灵Kling、Runway Gen-3 Alpha同在2024年6月前后公开，标志文生视频进入多家竞争。
