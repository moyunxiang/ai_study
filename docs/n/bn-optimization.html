BN为何有效之争

How Does Batch Normalization Help Optimization? (No, It Is Not About Internal Covariate Shift)
2018.05论文延伸NeurIPS 2018Shibani Santurkar, Dimitris Tsipras, Andrew Ilyas, Aleksander Madry · MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

Batch Normalization为什么有效？流行解释是它减小了层输入分布的变化（内部协变量偏移），但这从未被严格检验。

方法

设计实验检验该解释：证明分布稳定与BatchNorm的收益关系不大，真正起作用的是它让损失曲面更平滑。

影响

把对BatchNorm的解释从“稳定分布”改写为“平滑优化地形”，影响后续对各种归一化层的理论分析。

方法

论文做了对照实验：在BatchNorm之后故意加入随时间变化的随机噪声，使层输入分布反而更不稳定，训练速度仍与普通BatchNorm相近。这说明内部协变量偏移并不是收益的来源。

作者转而测量优化地形：在梯度方向上走不同步长时，损失与梯度的变化。结论是BatchNorm使损失和梯度的Lipschitz性质更好，也就是曲面更平滑、梯度更可预测，所以可以使用更大的学习率并更快收敛。摘要中的结论是：BatchNorm的根本作用是让优化地形显著变平滑。

局限与后续

  • 论文只给出平滑性的实证与部分理论，并未完整解释为何平滑性带来泛化提升，也未说明Layer Normalization等其他归一化是否同理。
