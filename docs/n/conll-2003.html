CoNLL-2003命名实体

Introduction to the CoNLL-2003 Shared Task: Language-Independent Named Entity Recognition
2003.06数据集重要CoNLL 2003（HLT-NAACL 2003同期）Erik F. Tjong Kim Sang, Fien De Meulder · 安特卫普大学CNTS待核对
arXiv cs/0306050 ↗ACL Anthology W03-0419 ↗在交互版中打开（演化树、学习进度）

问题

命名实体识别的公开评测基本只有英语的MUC，数据少、获取受限，也无法检验一个学习方法换到别的语言是否还管用。

方法

用同一套标注规范和评测方式，同时发布英语（路透社新闻）和德语（法兰克福评论报）的人名、地名、机构名、其他专名标注数据，外加大量未标注文本，比较各种机器学习方法。

影响

CoNLL-2003英语数据成了命名实体识别的标准基准，从最大熵、CRF到BiLSTM-CRF和BERT，二十年里几乎所有序列标注模型都在上面报告F1。

背景

命名实体识别（NER）就是在文本里找出人名、地名、机构名等专有名称并判断类别，例如“[ORG U.N.] official [PER Ekeus] heads for [LOC Baghdad].”。它是信息抽取的基础步骤，MUC信息抽取评测的MUC-6、MUC-7评测已经让英语系统能在同一批数据上比较。

但MUC的数据规模有限，系统也大多依赖手写规则和人工整理的名录。2000年前后，Nymble命名实体识别式的HMM、最大熵模型、条件随机场等统计学习方法兴起，研究者想知道：一个从数据中学习的方法，能否不改设计就用到不同语言上？CoNLL-2002先做了西班牙语和荷兰语，2003年换成英语和德语，并特别鼓励使用未标注数据。

方法

数据。英语取自路透社语料（1996年8月到1997年8月的新闻），德语取自《法兰克福评论报》。每种语言都有训练集、开发集、测试集，以及一大份未标注文本（英语1700万词、德语1400万词）。英语训练集946篇文章、约1.5万句、20万词；测试集231篇、约3700句、4.6万词。测试集的新闻时间晚于训练集，避免系统针对同一批事件调参。

标注。四类实体：人名PER、地名LOC、机构名ORG、其他专名MISC（如国籍形容词、事件名）。数据每行一个词，依次是词、词性、组块标记、实体标记，实体用IOB格式：I-ORG表示在机构名内部，B-表示紧挨着同类实体的另一个实体的开头，O表示不属于实体。

评测。只有边界和类别都与标准答案完全一致才算对，按实体计算精确率、召回率和它们的调和平均F1（见准确率、精确率、召回率与F1），并用自助重采样估计显著性。

结果

共16个系统参赛，基线（只认训练集中类别唯一的短语）英语测试集F1为59.61。最好的是Florian等人的分类器组合，英语F1 88.76、德语72.41；它与Chieu和Ng的最大熵系统差异在统计上不显著。最常用的学习方法是最大熵（5个系统），4个系统用了神经网络类方法（其中Hammerton已经用了LSTM），CRF只有McCallum和Li一个系统使用。16个队中11个用了人工整理的名录，使用未标注数据的系统提升约5%。德语普遍比英语难得多（一个常见解释是德语所有名词都首字母大写，大写不再是专名的强线索）。

后来的发展

CoNLL-2003英语数据很快成为NER的默认考场。从零开始的神经NLP在它上面证明神经网络不靠手工特征也能接近最好系统；神经命名实体识别的BiLSTM-CRF把字符级表示加了进来；之后ELMo、BERT等预训练模型的论文都把它列为必报任务。它的IOB列格式也成了序列标注数据的通用格式。后来的OntoNotes提供了更多实体类型和体裁，多语言的XTREME跨语言基准把NER扩到几十种语言，但CoNLL-2003英语F1至今仍是最常被引用的NER数字。

容易误解的地方

  • 报告CoNLL-2003成绩时要说明是否把开发集并入训练，这一做法会让F1提高一些，不同论文之间不可直接比较。
  • 数据来自1996–1997年的路透社新闻，测试集中很多实体在训练集中出现过，高F1部分来自“记住”实体名，而不完全是识别新实体的能力。

局限与后续

它建立在什么之上

  • 使用
    Penn Treebank1993 · 数据·评测
    英语数据的词性和组块标记由MBT标注器自动给出，用的是宾州树库风格的标记（如NNP），供参赛系统当特征。
  • 使用
    最大熵模型1996 · NLP
    最大熵是参赛系统最常用的学习方法，Chieu和Ng的最大熵系统名列前茅。
  • 使用
    条件随机场2001 · NLP
    McCallum和Li首次在这一共享任务上用条件随机场做NER（F1 84.04）；CRF随后成为神经网络之前序列标注的主流模型。
  • 延续
    MUC信息抽取评测1987 · 数据·评测
    延续MUC的命名实体任务，但改成多语言、统一的列格式，并面向机器学习方法而不是手写规则。
  • 延续
    Nymble命名实体识别1997 · NLP
    Nymble把NER变成从标注数据学习的HMM序列标注问题，CoNLL-2003为这类方法提供了多语言的统一比较场地。

后来的相关工作

  • 改进

读懂它需要的概念

监督学习 准确率、精确率、召回率与F1 训练集、验证集与测试集 基准、排行榜与SOTA 隐马尔可夫模型

本篇术语

  • 命名实体识别（NER）　在文本中找出人名、地名、机构名等专有名称的边界，并判断其类别。
  • IOB标注　把找实体变成给每个词贴标签：I表示在某类实体内部，B表示同类实体紧挨时第二个实体的开头，O表示不属于任何实体。
  • 名录（gazetteer）　人工整理的已知人名、地名、机构名列表，系统可以查表作为特征。

怎么学

先补准确率、精确率、召回率与F1。读原文第2节，弄懂数据格式和实体级F1的算法；然后用Hugging Face datasets加载conll2003，先写一个“查训练集词典”的基线，再微调一个小的BERT，对比两者的F1，并看看错误主要出在哪类实体上。
