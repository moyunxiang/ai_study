CNN关系分类与位置嵌入

Relation Classification via Convolutional Deep Neural Network
2014.08论文延伸COLING 2014Daojian Zeng（曾道建）, Kang Liu（刘康）, Siwei Lai（来斯惟）, Guangyou Zhou（周光有）, Jun Zhao（赵军）· 中国科学院自动化研究所待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

关系分类（判断句中两个名词之间是“因果”“部分—整体”等哪种关系）的主流方法依赖人工特征和核函数，特征来自词性标注、句法分析、WordNet等现成工具，工具的错误会层层传递，而且特征工程很费力。

方法

直接以词为输入，不做复杂预处理：用预训练词向量表示每个词，抽取两个目标名词附近的词汇级特征，再用卷积网络学习句子级特征；关键是给每个词加上“它距离两个目标名词各有多远”的位置特征，让卷积知道关系的两端在哪里。

影响

在SemEval-2010 Task 8关系分类上超过了当时依赖大量人工特征的最好方法，是最早的深度学习关系抽取工作之一；它提出的位置特征（位置嵌入）几乎被此后所有神经关系抽取模型沿用，同组的PCNN进一步把它用于远程监督关系抽取。

背景

关系分类的经典做法是用SVM配合大量特征（词、词性、依存路径、WordNet上位词等）或树核，SemEval-2010 Task 8提供了9类有向关系加“其他”的标准评测。从零开始的神经NLP（2011）表明卷积网络加词向量可以替代人工特征做多种序列标注任务；Socher等的递归神经网络也被用于关系分类，但依赖句法树。

方法

词汇级特征：两个目标名词e1、e2的词向量、它们左右相邻词的词向量，以及它们在WordNet中的上位词，拼接成一个向量。

句子级特征：

  • 每个词的表示由两部分拼接：一是以该词为中心的窗口内词向量（词特征）；二是位置特征——该词到e1和到e2的相对距离 (d_1, d_2)，每个距离值映射为一个可学习的低维向量。例如在“The [kitchen] is the last renovated part of the [house]”中，“part”到kitchen的距离为5、到house的距离为−3。
  • 对整句做卷积（线性变换），再在句子长度上做最大池化，得到定长的句子特征，经一层非线性变换。

词汇级与句子级特征拼接后接softmax分类器，输出关系类别（含方向）。整个模型端到端训练，词向量用预训练结果初始化。

结果

在SemEval-2010 Task 8数据上，该方法的宏平均F1超过了此前基于SVM与大量人工特征的最好系统；消融实验显示位置特征和WordNet上位词都带来明显提升（结论按一般了解写，具体F1未在此引用）。

后来的发展

位置嵌入成为神经关系抽取的标准输入。同组2015年的PCNN远程监督关系抽取把句子按两个实体分为三段做分段池化，并结合多示例学习用于远程监督关系抽取；随后的注意力、选择性注意力关系抽取以及基于预训练模型的MTB关系表示预训练、PURE流水线实体关系抽取等，都在相同的SemEval/TACRED类数据上与它比较。

局限与后续

  • 卷积只覆盖局部窗口，最大池化丢掉了结构信息，对两实体相距很远的长句建模能力有限。
    后来针对它的工作　PCNN远程监督关系抽取
  • 需要大量人工标注的句子级关系数据，难以扩展到成百上千种关系。
    后来针对它的工作　PCNN远程监督关系抽取 MTB关系表示预训练

读懂它需要的概念

卷积层、池化与感受野 嵌入向量 Softmax与logits 特征与表示学习 准确率、精确率、召回率与F1

本篇术语

  • 关系分类　给定句子和其中标出的两个实体，判断它们之间属于预定义的哪一种语义关系。
  • 位置特征　每个词到两个目标实体的相对距离，映射成可学习的向量，告诉模型关系的两端在哪里。

怎么学

先读从零开始的神经NLP与TextCNN句子分类 → 读本文第3节两类特征 → 动手：在SemEval-2010 Task 8上实现带位置嵌入的单层CNN，比较去掉位置嵌入后F1的下降。
