S5简化状态空间层

Simplified State Space Layers for Sequence Modeling
2022.08论文延伸ICLR 2023Jimmy T. H. Smith, Andrew Warrington, Scott W. Linderman · 斯坦福大学待核对
arXiv ↗官方代码 ↗在交互版中打开（演化树、学习进度）

问题

S4结构化状态空间效果好但实现复杂：每层由很多个独立的单输入单输出（SISO）状态空间模型组成，训练时要靠频域卷积核和复杂的数学技巧来算，难以理解和修改。

方法

把一层里的许多SISO小系统换成一个多输入多输出（MIMO）的状态空间系统，用对角化的状态矩阵，并直接在时间域用并行扫描（parallel scan）算递推，不再需要卷积核。

影响

S5证明了“对角线性递推加并行扫描”就足以达到S4的效果和效率，这条更简单的路线直接影响了后来的线性循环单元LRU和Mamba状态空间模型（Mamba用硬件感知的并行扫描实现选择性递推）。

方法

S4的一层对输入的H个通道各配一个N维的SISO状态空间模型，共H个互不相干的小系统，再用线性层混合通道；训练时把每个系统展开成长卷积核，用FFT计算。S5改为：整层只有一个状态维度为P的MIMO系统，x_k = Ā x_{k−1} + B̄ u_k，y_k = C x_k + D u_k，其中u和y都是H维向量，B̄是P×H、C是H×P的矩阵。

关键在于把Ā设为对角矩阵（用HiPPO-N矩阵的特征分解初始化，这一点建立在作者对S5与S4关系的推导上）。对角的线性递推可以写成满足结合律的运算，于是长度为L的序列能用并行扫描在 O(log L) 的并行深度内算完，而不必像RNN那样一步一步算。每个时间步的步长Δ也可以不同，便于处理不规则采样的时间序列。由于不再需要卷积核，实现大大简化，且计算效率与S4相当。

摘要报告：S5在多个长程序列建模任务上取得最好结果，在LRA长序列基准上平均得分87.4%，在其中最难的Path-X任务上达到98.5%。

局限与后续

  • 仍是线性时不变系统，参数不随输入变化，在需要按内容选择性记忆的语言建模任务上落后于注意力。

读懂它需要的概念

状态空间模型与线性RNN 循环网络与隐状态 特征分解与奇异值分解 时间与空间复杂度

本篇术语

  • 并行扫描　对满足结合律的累积运算（如前缀和）做树状并行计算，长度为L的序列只需约log L轮。
  • MIMO与SISO　多输入多输出与单输入单输出：前者一个系统同时处理所有通道，后者每个通道一个独立的小系统。

怎么学

先读S4结构化状态空间和对角状态空间S4D/DSS；用JAX的associative_scan实现一个对角线性递推，验证与for循环结果一致并比较速度；再读S5论文第3节它与S4的关系。
