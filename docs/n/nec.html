NEC神经情景控制

Neural Episodic Control
2017.03论文延伸ICML 2017Alexander Pritzel, Benigno Uria, Sriram Srinivasan, Adrià Puigdomènech, Oriol Vinyals, Demis Hassabis, Daan Wierstra, Charles Blundell · DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

MFEC用固定的状态嵌入做情景记忆，学得快但上限低；DQN能学好表示但很慢。想要既快又能学表示。

方法

每个动作配一个可微的键值记忆（DND）：键是卷积网络学出的状态嵌入，值是快速更新的Q估计；查询时按核函数加权相邻条目，嵌入网络再用梯度慢慢学。

影响

“半表格”价值表示的代表工作，表明情景记忆可以和深度表示学习结合；其可微记忆和快速写入的思想被NGU等工作的情景新颖性模块继承。

方法

NEC（Neural Episodic Control）由三部分组成：

  • 嵌入网络：卷积网络把画面映射为键向量 h = f(s)，用梯度训练，变化较慢；
  • 可微神经字典（DND）：每个动作a一张表，存若干 (h_i, Q_i) 对。查询时找p个最近邻，按核函数 k(h, h_i) = 1/(‖h − h_i‖² + δ) 归一化加权：Q(s, a) = Σ_i w_i Q_i。整个读取过程可微，梯度能传回嵌入网络和被读到的值；
  • 快速写入：每一步用N步Q学习目标 Q^(N)(s_t, a) = Σ_(j<N) γ^j r_(t+j) + γ^N max_a′ Q(s_(t+N), a′) 作为新值：若键已存在（找到完全匹配），用类似表格Q学习的方式以较大学习率更新 Q_i ← Q_i + α(Q^(N) − Q_i)；否则直接追加新条目。

与MFEC无模型情景控制相比，嵌入是学出来的、值是TD目标而不是“最好的一次”；与DQN（Nature版）相比，价值可以在一次经历后就大幅更新，不必等网络慢慢拟合。摘要称在广泛的环境上，NEC比当时最好的通用深度RL智能体学得明显更快。

局限与后续

  • 最近邻查询和巨大的记忆表带来很高的内存和计算开销，难以扩展到长时间训练。

读懂它需要的概念

策略与价值函数 时序差分与自举 k近邻 嵌入向量

本篇术语

  • 可微神经字典（DND）　一张键值表，读取是对最近邻的加权平均，整个过程可以求梯度。
  • 半表格表示　价值存在表里且可以快速改写，但查表用的键由神经网络学出。

怎么学

先读MFEC无模型情景控制；读NEC原文第2–3节的DND读写公式；用小规模Atari游戏比较NEC与DQN前1000万帧的学习曲线。
