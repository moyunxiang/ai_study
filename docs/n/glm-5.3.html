GLM-5.2/5.3

GLM-5.3
2026.08模型延伸智谱（Z.ai）待核对
Hugging Face模型卡 ↗GLM-5.2模型卡 ↗在交互版中打开（演化树、学习进度）

问题

开放权重模型在复杂编码和长时程任务上与闭源前沿模型仍有差距；同时，后训练放大的能力里可能包括意料之外的危险能力（如网络攻击）。

方法

基座与GLM-5.2完全相同，所有提升都来自扩大后训练，重点是复杂编码与长时程任务。

影响

官方称是编码能力最强的开放权重模型，在自家Z.ai Code Bench上比GLM-5.2提升50%；网络安全能力意外快速增长，在CyberGym漏洞发现上达到最好。

背景

智谱在2026年4月发布GLM-5.1长时程智能体，6月发布GLM-5.2，8月发布GLM-5.3。同期Kimi K3、DeepSeek-V4百万上下文等开放模型都在长时程编码上激烈竞争，前沿闭源模型的系统卡也开始专门评估网络攻击能力。

方法

据官方模型卡，GLM-5.3与GLM-5.2使用同一个基座模型，所有提升都来自后训练：扩大面向复杂编码和长时程任务的强化学习与数据。官方特别说明，随着后训练规模扩大，模型的网络安全能力增长得比预期更快：在漏洞利用链越靠后的环节提升越大，在漏洞利用（exploitation）基准上比GLM-5.2高出一倍以上。同代还发布了较小的GLM-5.3-Flash。

结果

官方模型卡报告：Z.ai Code Bench上比GLM-5.2提升50%；Terminal Bench 3.0从4.6升到28.3，DeepSWE从46.2升到66.9，NL2Repo从48.9升到58.0；在Terminal Bench 3.0和Agents' Last Exam等公开基准上为开源最好；CyberGym漏洞发现达到最好。对比表中闭源的GPT-5.6 Sol、Claude Fable 5在多数编码指标上仍更高。

后来的发展

它是“只扩后训练就能显著提升智能体能力”的又一个例子，也让开放权重模型的网络攻击能力成为安全讨论的话题。
