Dify LLM应用平台

2023.04系统延伸LangGenius（Dify团队）待核对
GitHub ↗文档 ↗在交互版中打开（演化树、学习进度）

问题

企业想做知识库问答、客服机器人这类LLM应用，但用LangChain写代码门槛高；模型接入、知识库、提示调试、日志监控也都要自己从头搭。

方法

做一个可自托管的开源平台，在可视化画布上拖拽搭建工作流，把RAG管线、智能体、模型管理和可观测性做成现成模块，搭好后直接发布成应用或API。

影响

成为GitHub上星标最多的开源LLM应用平台之一（约16万星），在国内外被大量企业用来搭建内部知识库和智能体应用，是“低代码智能体平台”这一类工具的代表。

方法

Dify的GitHub仓库创建于2023-04。按README的说法，它把几类功能放在同一个界面里：

  • 工作流：在可视化画布上用节点搭建流程——调用模型、检索知识库、条件分支、循环、调用工具、执行代码——并可单步测试；
  • RAG管线：上传文档后自动切块、生成嵌入、建索引，在应用里直接做检索增强（原理见检索增强生成RAG）；
  • 智能体：基于函数调用或ReAct式循环的智能体，可挂接内置工具和自定义工具；
  • 模型管理：统一接入各家商用模型和自托管的开源模型；
  • 可观测性：记录每次调用的输入输出、耗时和费用，接入外部追踪工具。

部署上可以用Docker Compose在自己的服务器上一键起全套服务，也有官方云版。和LangChain、LlamaIndex这类代码库相比，Dify面向的是更少写代码、更多靠配置的产品和业务人员；搭好的应用可以发布成网页、嵌入组件或后端API。

局限与后续

  • 可视化工作流适合结构固定的流程，遇到需要模型自主多步决策的开放任务时，表达能力和调试能力不如直接写代码的框架。

    LlamaIndex2022.11 · 推理·智能体
