COLMAP

Structure-from-Motion Revisited
2016.06系统重要CVPR 2016Johannes L. Schönberger, Jan-Michael Frahm · 北卡罗来纳大学教堂山分校 / 苏黎世联邦理工待核对
CVPR 2016论文 ↗代码（GitHub） ↗官方文档与教程 ↗在交互版中打开（演化树、学习进度）

问题

从网上一堆无序照片恢复相机位姿和三维结构的增量式SfM已经能处理上百万张图，但仍常常漏掉大量本该能注册的照片、因误匹配而重建出断裂或扭曲的模型，而且最好的系统要么闭源、要么很慢。

方法

在增量式SfM的每个环节做针对性改进：多模型几何验证、偏向均匀分布观测的下一视角选择、递归RANSAC三角化、反复的光束法平差—重新三角化—离群点过滤，以及合并冗余视图加速BA；并完整开源。

影响

在17个互联网照片数据集上注册的图像和重建的点都明显多于Bundler、VisualSFM等系统，速度是Bundler的50倍以上；COLMAP随即成为三维重建的事实标准工具，NeRF、3D高斯泼溅几乎都用它求相机位姿。

背景

运动恢复结构（SfM）要从多张照片中同时求出每张照片的相机位置、朝向、焦距和场景的三维点。Photo Tourism及其开源实现Bundler、以及一天建成罗马把它推广到上万到上百万张网络照片，主流是增量式流程：

1. 对每张图提取SIFT特征特征并两两匹配； 2. 用RANSAC估计两图间的几何关系（基础矩阵等，见《多视图几何》），剔除误匹配，得到“场景图”； 3. 从一对好的图像开始重建，逐张加入新图（由已知三维点求新相机位姿），三角化出新的点，再做光束法平差（BA）整体优化。

问题在于，网络照片质量参差：带水印、时间戳、相框的图会产生假匹配；对称建筑会让不同的面互相混淆；一张图注册错了，误差会不断累积，模型断成几块或漂移。当时常用的VisualSFM闭源，Bundler开源但慢。

方法

论文针对增量式流程中的五个环节分别改进：

  • 场景图增强。对每对图像同时估计基础矩阵、单应矩阵和本质矩阵，根据哪个模型支持的内点多判断这对图是一般场景、纯旋转全景还是平面；能自动识别由水印、时间戳、相框造成的假匹配并剔除。
  • 下一最佳视角选择。选下一张要加入的图时，不只看它能看到多少已重建的点，还看这些点在图像上分布是否均匀（用多分辨率网格打分）。分布均匀的图求位姿更稳。
  • 鲁棒三角化。一个三维点被很多图看到时，其中可能混入错误的观测。用RANSAC从所有观测中递归地选出一致的子集来三角化，得到更长、更可靠的特征轨迹，速度比穷举法快10–40倍。
  • BA与重新三角化循环。每次BA后，过滤重投影误差大的观测，对之前失败的点重新三角化，再BA，如此迭代，抑制漂移。
  • 冗余视图挖掘。对大量高度重叠的照片，把彼此冗余的图像分组参数化，减少BA要解的规模。

系统以COLMAP为名开源，之后又加入了生成稠密点云的多视图立体（MVS）模块。

结果

在17个共144,953张互联网照片的数据集上与Bundler、VisualSFM（增量式）和DISCO、Theia（全局式）比较：所有数据集上重建的完整度（注册图像数、三维点数）都明显最好，越大的数据集优势越明显。速度比VisualSFM略慢，但比Bundler快50倍以上。在有真值的Quad数据集上，相机位置误差为0.85米，好于DISCO的1.16米、Bundler的1.01米和VisualSFM的0.89米。在Rome数据集上从7.5万张中注册了2.1万张。

后来的发展

COLMAP很快成为学术界和工业界最常用的SfM/MVS工具：MVSNet等学习型多视图立体方法用它生成训练和测试所需的相机参数；NeRF和3D高斯泼溅的标准流程第一步就是“用COLMAP求相机位姿”，没有它这些方法几乎无法用在真实照片上。

它的弱点——慢、依赖手工特征、在弱纹理和视角少时失败——推动了新一代方法：SuperPoint、SuperGlue、LoFTR替换特征和匹配环节；DUSt3R、MASt3R、VGGT用一个前馈网络直接从几张图预测相机和三维点，在少视角场景下明显更稳。

容易误解的地方

  • COLMAP的SfM输出的是稀疏点云和相机参数；稠密重建要再运行它的MVS模块，时间往往长得多。
  • 单目照片的SfM结果没有真实尺度，坐标系的单位是任意的，除非额外提供GPS或已知尺寸。

局限与后续

  • 增量式流程逐张注册、反复BA，对数万张图要跑数小时到数天，难以并行，也不适合需要即时结果的应用。

读懂它需要的概念

相机模型与多视图几何 三维表示：体素、点云、网格、隐式场 图、树与搜索 梯度下降 k近邻

本篇术语

  • 运动恢复结构（SfM）　从同一场景的多张照片中同时估计每张照片的相机参数和场景的三维点。
  • 增量式SfM　从两张图开始，每次加入一张新图并扩展三维点，再整体优化，逐步长出整个模型。与之相对的全局式SfM一次性求所有相机位姿。
  • 三角化　已知两台以上相机的位姿和同一点在各图中的位置，求这个点的三维坐标。
  • 多视图立体（MVS）　在相机位姿已知的前提下，为图像中的每个像素估计深度，生成稠密的点云或网格。

怎么学

先补相机模型与多视图几何（针孔模型、对极几何）。读原文第2节（增量式SfM的标准流程，图2）和第4节各项改进。动手：用手机绕一个物体拍40张照片，用COLMAP的图形界面自动重建，观察稀疏点云和相机轨迹；再把结果导入一个3D高斯泼溅实现训练，体会COLMAP在新视角合成流程中的作用。
