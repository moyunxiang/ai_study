Grok 3

Grok 3 Beta — The Age of Reasoning Agents

官方公告 ↗在交互版中打开（演化树、学习进度）

问题

xAI此前发布的是开放权重的Grok-1和后续的闭源版本，规模与推理能力都落后于OpenAI、Google等前沿模型。

方法

在Colossus超级集群上以约10倍于此前最先进模型的算力训练Grok 3，并用大规模强化学习训练可「思考」的推理版本。

影响

官方称其在数学、代码和聊天偏好评测上达到领先，推动算力规模竞赛。

方法

官方公告（2025-02-19）称，Grok 3在xAI的Colossus超级集群上训练，算力是此前最先进模型的10倍。同时发布了两个测试版推理模型Grok 3（Think）和Grok 3 mini（Think），用大规模强化学习训练，能花几秒到几分钟思考、回溯纠错、尝试多种思路。

官方给出的成绩（均为厂商自报）：聊天竞技场Elo 1402；Grok 3（Think）在2025年AIME上93.3%（最高测试时算力，cons@64）、GPQA 84.6%、LiveCodeBench 79.4%；mini在AIME 2024上95.8%。公告同时说两个模型仍在训练中。

局限与后续

  • 所有数字都是厂商自报，且是在最高测试时算力设置下取得的，缺乏独立复现；模型尚在训练中。
    后来针对它的工作　Grok 4
  • 推理链的可靠性与幻觉问题仍然存在。
