CheXNet

CheXNet: Radiologist-Level Pneumonia Detection on Chest X-Rays with Deep Learning
2017.11论文重要arXiv 2017Rajpurkar, Irvin, Zhu, Yang, Mehta, Duan, Ding, Bagul et al. · Stanford ML Group待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

胸片读片耗时且依赖放射科医生，而公开的大规模胸片数据集刚出现，还没有人证明深度网络能在肺炎检测上追上医生。

方法

在10万余张胸片的ChestX-ray14上微调121层的DenseNet，输出14种病变的概率；再请4位放射科医生标注一个测试集，直接比较模型与医生。

影响

成为医学影像“超过医生”这类宣称的代表，也引出了关于数据泄漏、标签噪声和比较方式的长期讨论，推动了更严格的数据集（如CheXpert）和评测。

背景

2017年，皮肤癌皮肤科医生级分类和糖尿病视网膜病变深度学习已经表明深度卷积网络能在皮肤和眼底图像上达到专家水平。胸部X光是最常做的影像检查之一，肺炎是常见又会致命的病，但读片需要放射科医生，很多地区缺少这类人手。美国国立卫生研究院（NIH）此前公开了ChestX-ray14数据集，含超过10万张正位胸片和14类病变标签，这些标签是从放射报告中用文本挖掘自动抽取的，而不是医生逐张标注的。

方法

模型。CheXNet是一个121层的DenseNet（见DenseNet：每一层都接收前面所有层的特征，缓解深层网络的梯度消失）。它在ImageNet预训练的权重上微调（见迁移学习），输入胸片，最后一层输出14个sigmoid，每个对应一种病变的概率。损失是各类别的二元交叉熵（见交叉熵）。

对照实验。作者找了4位学院派放射科医生，在一批测试胸片上独立标注肺炎是否存在。比较的方式是F1分数：先用模型对每个医生算一次F1（把其他三人的多数意见当作参照），再看模型与这些医生的平均水平。

可解释性。用类激活图（CAM）把对预测贡献大的区域标成热力图，叠加在胸片上，让医生看到模型“看”到了哪里。

结果

摘要给出的结论是：在作者组织的测试集上，CheXNet在F1指标上超过了放射科医生的平均水平；同一模型扩展到全部14类病变后，在ChestX-ray14的所有14类上取得当时最好的结果。需要注意，这里的“超过”指一个特定测试集和一个特定的F1定义。

后来的发展

这篇预印本迅速传播，也引发了批评：训练标签来自自动抽取的报告，同一病人的多张胸片可能同时出现在训练和测试集，医生只看正位片而临床读片通常结合侧位片和病史。此后斯坦福组发布了标签更干净的CheXpert，各类胸片AI开始被用于临床研究。从方法上它没有新的结构，价值主要在于数据加迁移学习加严格的人机对照这套范式。

容易误解的地方

  • 在一个测试集上F1超过医生，不等于在真实临床流程中比医生更好；医生没有病史，也只看一张图。
  • ChestX-ray14的标签由自然语言处理从报告抽取，本身含噪声，所以测试集需要另外请医生标注。

读懂它需要的概念

卷积层、池化与感受野 迁移学习 交叉熵 准确率、精确率、召回率与F1 残差连接

本篇术语

  • F1分数　精确率和召回率的调和平均，F1 = 2PR/(P+R)，用来在漏诊和误诊之间取一个综合指标。
  • 类激活图（CAM）　把最后一个卷积层的特征按分类权重加权，得到一张热力图，指出图像中对该类别预测最有贡献的区域。

怎么学

先学准确率、精确率、召回率与F1和迁移学习。读原文了解数据、模型和与放射科医生对比的方法部分，再读后来对其数据质量的批评。动手：在公开胸片数据集上用ImageNet预训练的DenseNet做微调，按病人而不是按图片划分训练和测试集。
