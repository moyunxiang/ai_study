MADDPG

Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments
2017.06论文重要NIPS 2017Lowe, Wu, Tamar, Harb, Abbeel, Mordatch · OpenAI / 麦吉尔大学 / UC Berkeley待核对
arXiv ↗多智能体粒子环境代码 ↗在交互版中打开（演化树、学习进度）

问题

多个智能体同时学习时，别人的策略一直在变，单个智能体眼中的环境不再稳定：Q-learning的经验很快过时，策略梯度的方差随智能体数量急剧增大，需要协作或沟通的任务几乎学不会。

方法

“集中训练、分散执行”：训练时每个智能体的critic能看到所有智能体的观测和动作，环境因此重新变得稳定；执行时每个actor只用自己的观测。

影响

成为合作、竞争、混合场景通用的多智能体深度RL基线，“集中式critic”的思路被QMIX值分解、MAPPO等后续方法普遍采用。

背景

多智能体强化学习的经典框架是马尔可夫博弈：多个智能体在同一环境中各自行动、各拿奖励。最直接的做法是独立Q学习多智能体——每个智能体把其他人当成环境的一部分，各学各的。问题是其他人也在学习：昨天“走左边安全”的经验，今天对手换了策略就不再成立，环境对每个智能体都是非平稳的，经验回放里存的旧经验也会误导学习。

策略梯度同样吃亏：一个智能体的回报还取决于所有其他人的随机动作，论文构造了一个例子说明，梯度方向正确的概率随智能体数量指数下降。到2017年，深度RL在单智能体上已经很成熟（DQN（Nature版）、DDPG），多智能体上却缺少一个在合作、竞争两类场景都能用的通用方法。

方法

MADDPG以DDPG为基础（actor输出确定性动作，critic估计Q值，见Actor-Critic与优势函数），做了一处关键修改：

集中式critic。第i个智能体的critic输入的是全局信息x（所有智能体的观测）以及所有智能体的动作：Qᵢ(x, a₁, …, a_N)。一旦知道了每个人做了什么，环境的转移就不再依赖“别人用的是哪个策略”，对critic来说环境又是平稳的了。actor只用自己的观测oᵢ，按确定性策略梯度DPG的公式沿∇_{aᵢ} Qᵢ更新。训练完以后critic被丢掉，执行时完全分散，不需要通信或看到别人的信息。每个智能体有自己的critic，所以各自的奖励可以不同——合作、竞争、混合都能处理。

推断他人策略。如果训练时也拿不到别人的策略，每个智能体可以在线学一个近似模型来预测他人的动作，再用于计算critic的目标。

策略集成。在竞争场景中，智能体容易过拟合到对手当前的策略。于是让每个智能体维护K个子策略，每局随机选一个执行，并对整个集合优化，迫使它学会应对各种对手。

结果

在OpenAI的二维多智能体粒子环境中测试了合作沟通、合作导航、追捕、物理欺骗、保持距离、隐蔽通信等场景。合作沟通任务里，“说话者”看得到目标颜色却不能动，“听者”能动却不知道目标；DQN、Actor-Critic、TRPO的一阶实现和DDPG全都失败——听者学会无视说话者、径直走到所有地标中间。MADDPG则可靠地学会了沟通，训练25000回合后听者84.0%的情况下能到达目标。物理欺骗任务（两个合作者要掩护真正的目标不被对手识破）中，L=2时MADDPG合作者约94%的时间能成功欺骗对手。直接对抗时MADDPG总胜过DDPG，策略集成又胜过单一策略。

后来的发展

同期还有用单一集中式critic做反事实信用分配的COMA。“集中训练、分散执行”此后成为合作多智能体RL的默认范式：QMIX值分解把全局Q值分解为各智能体Q值的单调组合，星际多智能体挑战SMAC提供了标准测试平台，MAPPO表明用集中式价值函数的PPO在这些基准上同样很强。论文配套的粒子环境也成为多智能体研究最常用的小型测试场。

局限与后续

  • 集中式critic的输入随智能体数量线性增长，智能体一多就难以训练，论文自己列为主要缺点。
    后来针对它的工作　QMIX值分解 MAPPO
  • 合作任务里所有人共享一个团队奖励时，critic无法告诉每个智能体它自己的贡献有多大，信用分配仍然困难。
    后来针对它的工作　QMIX值分解
  • 只在简单的二维粒子世界验证，竞争场景中策略集成只是缓解对手过拟合，并不保证收敛到均衡。
    后来针对它的工作　PSRO博弈论元求解 AlphaStar

它建立在什么之上

  • 使用
    经验回放1992 · RL
    沿用DDPG的离策略回放；由于critic看到了所有人的动作，旧经验不再因他人策略变化而失效。
  • 使用
    确定性策略梯度DPG2014.06 · RL
    actor按确定性策略梯度沿critic对自身动作的梯度更新。
  • 改进
    独立Q学习多智能体1993 · RL
    独立学习者把其他智能体当作环境，环境因而非平稳；集中式critic显式输入他人的动作，恢复了平稳性。
  • 延续
    马尔可夫博弈1994 · RL
    在马尔可夫博弈框架下，为合作、竞争和混合动机的深度多智能体学习给出一个通用算法。
  • 延续
    DDPG2015.09 · RL
    每个智能体都是一个DDPG式actor-critic，只是critic的输入扩展为所有智能体的观测和动作。

  • 改进
    群体系统的深度RL2018.07 · RL

读懂它需要的概念

Actor-Critic与优势函数 策略梯度 博弈论基础与纳什均衡 on-policy与off-policy 信用分配 马尔可夫决策过程

本篇术语

  • 非平稳性　从单个智能体的角度看，环境的转移和奖励规律在随时间变化，因为其他智能体也在学习、改变策略。
  • 集中训练、分散执行　训练时可以使用全局信息（所有人的观测和动作），部署时每个智能体只依据自己的局部观测行动。
  • 策略集成　每个智能体同时训练多个子策略、每局随机选一个，使对手无法只针对其中某一个，学到的策略更稳健。
