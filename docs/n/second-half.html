姚顺雨《AI的下半场》

The Second Half
2025.04思想延伸姚顺雨（Shunyu Yao） · 个人博客待核对
The Second Half（2025-04-10） ↗在交互版中打开（演化树、学习进度）

问题

过去十几年AI研究的主要玩法是提出新方法、在基准上刷分；可到2025年，推理模型一出来就能横扫几乎所有新基准，刷分越来越没有信息量，而AI对真实经济的影响却远小于它的考试成绩。

方法

作者主张AI已进入“下半场”：一套通用配方（大规模语言预训练提供先验、把推理当作动作、再做强化学习）已经能通吃各种任务，研究重心应从“解决问题”转向“定义问题”，也就是设计更接近真实世界的评测。

影响

这篇博客在中英文社区被大量转发，“下半场”成为讨论“评测与环境比算法更重要”“AI为什么还没改变经济”时最常用的说法之一。

方法

文章写于2025年4月10日。作者把强化学习拆成三个部分：算法、环境、先验，并说事后看来最重要的可能是先验——大规模语言预训练提供了通用知识，而把“推理”当作一种不改变外部世界、却能帮助决策的动作，让智能体可以泛化，他自己的总结是“语言通过智能体中的推理来泛化”。他以自己早期的文字游戏智能体CALM为例：没有这种先验时，一个游戏要上百万步RL，且无法迁移到新游戏。

“上半场”的成功者靠提出Transformer这类通用方法，基准只是把现成的人类任务改成考卷；配方成熟之后（OpenAI o1推理模型、DeepSeek-R1），增量方法很快被通用模型超越，新基准也很快被解掉。

他把核心矛盾称为“效用问题”：AI已在棋类、考试、IMO与IOI上达到顶尖，但世界没有因此明显改变。原因是评测设定与现实不同，例如评测假设智能体独立完成任务，而现实工作需要和人持续交互；评测假设任务彼此独立同分布，而现实中人会在同一个代码库里越做越熟。所以下半场要质疑评测设定本身，造出需要新方法的问题。

局限与后续

  • 文章指出了评测与现实的差距，但没有给出可操作的新评测标准，怎样衡量“真实效用”仍是开放问题。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • “通用配方已能通吃”的判断建立在可验证奖励任务（数学、代码）的成功上，在难以验证结果的开放任务上是否成立尚无定论。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    ReAct2022.10 · 推理·智能体
    作者是ReAct的作者，文中“把推理当作动作”的核心论点正是ReAct思路的总结和推广。
  • 竞争
    SWE-bench2023.10 · 数据·评测
    文中批评的正是这类“把现成任务改成考卷、假设独立完成”的评测设定，主张设计更贴近真实工作的评测。
  • 使用
    OpenAI o1推理模型2024.09 · 推理·智能体
    以o1式推理模型为证据，说明“预训练先验+推理+RL”的配方已经跑通。
  • 使用
    DeepSeek-R12025.01 · 推理·智能体
    开源推理模型的复现进一步说明配方已经标准化，算法本身不再是瓶颈。
