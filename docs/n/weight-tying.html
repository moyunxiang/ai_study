输入输出嵌入共享

Using the Output Embedding to Improve Language Models
2016.08论文延伸EACL 2017Press, Wolf · Tel Aviv University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

神经语言模型有一个输入词嵌入矩阵和一个输出投影矩阵，各占词表大小×维度个参数，既浪费又分别训练。

方法

观察到输出矩阵本身就是一种合格的词嵌入，建议让输入嵌入与输出嵌入共用同一个矩阵。

影响

以几乎零成本减少参数并降低困惑度，成为语言模型和翻译模型的常规做法，今天大量Transformer语言模型仍沿用。

方法

语言模型最后一层把隐状态映射到词表大小的向量，再softmax，这个投影矩阵的每一行对应一个词，其实就是该词的“输出嵌入”。作者先证明这个输出嵌入的词相似度质量并不比输入嵌入差，于是提出权重共享：令输出矩阵等于输入嵌入矩阵（转置），减少一个与词表大小成正比的参数块。他们还分析了更新规则：共享后的嵌入随训练的演化更接近原来的输出嵌入，而不是输入嵌入，因为输出层每一步会对所有词给出梯度。

摘要称，该方法在多种神经网络语言模型上显著降低困惑度，并可把神经翻译模型的体积缩小到不到一半而不损害性能。

局限与后续

  • 只在输入输出共用同一词表时才直接适用；共享迫使同一矩阵同时服务于“读入”和“预测”，在某些模型里可能限制两者的专门化。
    本站还没有记录针对它的后续工作（不代表没有人解决）
