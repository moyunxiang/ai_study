SuperGlue

SuperGlue: Learning Feature Matching with Graph Neural Networks
2019.11论文延伸CVPR 2020Sarlin, DeTone, Malisiewicz, Rabinovich · ETH Zurich / Magic Leap待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

两张图的局部特征匹配靠最近邻加手写规则（比值测试、RANSAC）过滤，对视角和光照剧变很脆弱，且不会主动拒绝不可匹配的点。

方法

用注意力图神经网络让两张图的所有特征点互相“看”，再用可微最优传输求出匹配，同时允许点被标成无匹配。

影响

首个端到端学习的特征匹配器，成为SLAM和三维重建里取代最近邻匹配的新基线。

方法

输入是SuperPoint等检测器给出的两组关键点及其描述子。SuperGlue先用一个MLP把位置编码进描述子，再用带自注意力（同一图内）和交叉注意力（两图之间）的图神经网络（见图注意力网络GAT和Transformer）交替更新，使每个点的表示同时包含本图上下文和另一张图的信息。随后计算所有点对的匹配得分，加一个“垃圾桶”行列表示不匹配，用可微的Sinkhorn算法（最优传输，见最优传输与Wasserstein距离）得到软分配。整套网络用真实匹配监督、端到端训练。

论文称在室内外的位姿估计上超过其他学习方法，在现代GPU上可实时匹配（摘要）。

后来的发展

之后出现了更快的匹配器和无检测器的LoFTR，SuperGlue的“注意力加最优传输”范式被广泛沿用。

局限与后续

  • 需要依赖前置的关键点检测器，在低纹理区域检测不到可重复的点。
    后来针对它的工作　LoFTR
  • 全连接注意力的开销随点数平方增长，点数多时很慢。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    自注意力与交叉注意力直接来自Transformer。
  • 改进
    SIFT特征1999 · 视觉
    在弱纹理（白墙）、重复纹理、大视角或昼夜光照变化下，检测不到足够的稳定点或匹配大量出错。
  • 改进
    COLMAP2016.06 · 视觉
    依赖SIFT等手工特征和匹配，在弱纹理、重复纹理、光照差异大或视角很少（两三张图）时无法注册或重建失败。
  • 使用
    图注意力网络GAT2017.10 · 基础
    把关键点视为图的节点，用注意力在图上传递消息。
  • 改进
    《多视图几何》2000 · 视觉
    以经典的几何方法为主，对低纹理、重复结构、大量遮挡的场景依赖手工特征匹配，容易失败。
  • 改进
    ORB特征2011.11 · 视觉
    旋转和轻度尺度变化可以处理，但在大的视角变化、模糊下，匹配的可靠性不及SIFT。
  • 使用
    SuperPoint2017.12 · 视觉
    以SuperPoint的关键点和描述子作为输入。

后来的相关工作

  • 改进
    LoFTR2021.04 · 视觉
    去掉对关键点检测器的依赖，用稠密粗匹配加精细化，使低纹理区域也能匹配。
  • 改进
    LightGlue2023.06 · 视觉
    解决SuperGlue速度慢、显存大、难训练的问题。
