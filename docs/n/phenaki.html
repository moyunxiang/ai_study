Phenaki变长视频

Phenaki: Variable Length Video Generation From Open Domain Textual Description
2022.10论文延伸ICLR 2023Villegas, Babaeizadeh, Kindermans, Moraldo, Zhang, Saffar, Castro, Kunze, Erhan · Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

视频生成面临计算量大、文本-视频数据少，且视频长度不固定。

方法

用时间上带因果注意力的分词器把视频压成离散token，再用双向掩码Transformer以文字为条件并行生成这些token。

影响

第一篇研究以随时间变化的提示序列（像一个故事）生成任意长度视频的论文。

方法

视频分词器：一个编码器-解码器，把视频压成少量离散token；它在时间维度用因果注意力，因此既能编码一张图（一帧），也能编码任意长度的视频，每个视频的token数比逐帧编码更少，而时空一致性更好。

生成器：与MaskGIT并行掩码生成相同的双向掩码Transformer，以预先算好的文本token为条件，多轮并行填出视频token，再由解码器还原成视频。训练时大量图文对和较少的视频文本对联合使用，使模型泛化到视频数据集里没有的内容。生成长视频时，用上一段的最后几帧token作为条件、配以新的提示，一段一段延续。

局限与后续

  • 长视频靠逐段接续生成，误差会累积，镜头间的连贯性有限。

它建立在什么之上

  • 使用
    MaskGIT并行掩码生成2022.02 · 生成
    生成器是MaskGIT式的掩码双向Transformer，并行解码视频token。
  • 使用
    VQGAN2020.12 · 生成
    视频分词器沿用VQGAN式的离散编码与对抗训练思路。
  • 改进
    CogVideo2022.05 · 生成
    自回归逐token生成，生成长视频极慢，序列长度也限制了时长和分辨率。
  • 改进
    Imagen Video2022.10 · 生成
    片段仍只有几秒，长程叙事和一致性没有解决。
