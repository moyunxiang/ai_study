信息导向采样IDS

Learning to Optimize via Information-Directed Sampling
2014.03论文延伸NeurIPS 2014；Operations Research 2018Daniel Russo, Benjamin Van Roy · Stanford University待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

UCB和Thompson采样只会去试“可能是最优”的动作；有时一个明知不是最优的动作能提供大量信息（比如一次就能揭示哪只臂最好），这两类方法却永远不选它，在这类问题上会非常低效。

方法

每一步按“信息比”选择动作的分布：最小化 Δ(π)² / g(π)，分子是期望的单步遗憾，分母是这一步观测带来的关于最优动作的信息增益（互信息）。愿意付一点遗憾去换大量信息。

影响

给出一个直接以信息为中心的探索原则和一般性的遗憾界，信息比随后成为分析Thompson采样的标准工具，也被推广到部分监督、RL和深度RL中的信息导向探索。

背景

UCB1与Thompson采样的复兴都可以归为“只在可能最优的动作之间探索”。作者在Eluder维度与后验采样的工作里已经给出了这类方法的一般贝叶斯遗憾界。但当动作之间共享信息结构时，它们会显得笨拙：例如有一个“探测”动作，自己奖励很低，却能直接告诉你哪只臂最好；又如线性老虎机里某些方向的信息只能靠非最优动作获得。这类问题里，乐观或后验采样的遗憾可以比最优策略大得多。

方法

设 A* 是未知的最优动作，π 是本步选择动作的分布。定义

  • 期望单步遗憾 Δ_t(π) = E[ R(A*) − R(A) ]，A按π选取；
  • 信息增益 g_t(π) = I_t( A* ; (A, Y_A) )，即这一步观测Y能让关于“哪个动作最优”的不确定性降低多少。

信息导向采样（IDS）选择

π_t = argmin_π Δ_t(π)² / g_t(π)

作者证明最优解总能在最多两个动作上取支撑，所以计算上只需搜索动作对及其混合比例。对任意在每步都满足信息比 Γ_t ≤ Γ 的算法，有通用的界

E[Regret(T)] ≤ √( Γ · H(A*) · T )

其中 H(A*) 是最优动作先验分布的熵。IDS直接最小化信息比，自然满足这个界。

结果

摘要称，作者为IDS建立了适用于非常一般的模型类、并随最优动作分布的熵而缩放的期望遗憾界；用简单的解析例子说明IDS能利用其他方法无法充分利用的信息，从而带来显著的性能提升；在伯努利、高斯和线性老虎机问题上，模拟结果达到了当时最好水平。

后来的发展

信息比这一工具后来被广泛用于分析Thompson采样（作者自己的后续工作即用它给出了更紧的界），也被推广到部分监督问题、多步RL中的信息导向探索，以及用集成近似后验的深度RL版本（如信息导向的DQN变体）。

局限与后续

  • 需要计算关于最优动作的互信息，只有在共轭模型或可以精确采样后验时可行，复杂模型下计算昂贵。

它建立在什么之上

  • 竞争
    UCB12002 · RL
    UCB以乐观主义平衡探索与利用，IDS以遗憾与信息增益之比平衡二者。
  • 改进
    Thompson采样的复兴2011 · RL
    Thompson采样只选可能最优的动作，在“探测动作”这类问题上低效；IDS可以主动选择非最优但信息量大的动作。
  • 竞争
    OFUL线性老虎机2011.12 · RL
    在线性老虎机上与乐观类算法对比，IDS利用动作之间共享的信息取得更低遗憾。
  • 延续
    Eluder维度与后验采样2013.01 · RL
    同一作者从后验采样的一般遗憾界出发，转向直接以信息增益为中心的算法与分析。

读懂它需要的概念

探索与利用 互信息 信息量与熵 条件概率与贝叶斯公式 期望与方差

本篇术语

  • 信息比（information ratio）　单步期望遗憾的平方除以这一步获得的信息量；它小，说明每付出一点遗憾就换来了很多信息。
  • 探测动作　本身奖励不高、却能揭示其他动作好坏的动作；乐观类方法往往从不选它。

怎么学

先熟悉Thompson采样的复兴和互信息；读原文第4节信息比与遗憾界的推导、第6节的探测动作例子；实现一个带“揭示动作”的老虎机，比较IDS与Thompson采样的遗憾曲线。
