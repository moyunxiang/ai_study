条件随机场

Conditional Random Fields: Probabilistic Models for Segmenting and Labeling Sequence Data
2001论文重要ICML 2001John Lafferty, Andrew McCallum, Fernando Pereira · 卡内基梅隆大学 / WhizBang! Labs / 宾夕法尼亚大学待核对
论文PDF（哥伦比亚大学课程镜像） ↗Sutton & McCallum：An Introduction to Conditional Random Fields ↗Wikipedia: Conditional random field ↗在交互版中打开（演化树、学习进度）

问题

序列标注里，HMM是生成式模型，很难加入“首字母大写”“以-ing结尾”这类重叠特征；MEMM能加特征，但每一步在局部归一化，会出现“标签偏置”：后继选择少的状态几乎无视观测。

方法

不再为每一步单独归一化，而是为整个标签序列定义一个对数线性分数，只在全体可能序列上归一化一次：p(y|x) = exp(Σ 特征权重) / Z(x)，用前向-后向算法高效计算Z(x)和梯度。

影响

成为2000年代序列标注（分词、词性、命名实体、信息抽取）的标准模型；神经网络时代又作为BiLSTM等编码器上面的输出层继续使用。

背景

序列标注要给一串观测（词）配一串标签（词性、实体类型）。HMM词性标注那样的HMM对“词和标签”的联合概率建模，必须假设每个词只依赖当前标签，所以很难同时使用大小写、后缀、前后词这类相互重叠的特征。

最大熵模型的对数线性模型可以随意加特征。最大熵马尔可夫模型MEMM把它串成序列：每个状态用一个最大熵分类器给出“下一个状态”的条件分布。但正因为每个状态的出边概率要归一化到1，从某个状态流出的概率总量是固定的，观测只能决定“怎么分”，不能决定“分多少”。只有一条出边的状态会把全部概率传下去，不管观测是什么——这就是标签偏置。

方法

标签偏置的例子。一个识别rib和rob的有限状态机：开头看到r，两条路径各分一半；接下来不论看到i还是o，每条路径上的状态都只有一条出边，只能把概率原样传下去。结果哪个词在训练集里稍多一点，就永远赢，观测被忽略。

线性链CRF。对输入x和整个标签序列y定义

p(y | x) = (1/Z(x)) · exp( Σ_t Σ_k λ_k f_k(y_{t−1}, y_t, x, t) )

特征f可以是“当前标签是名词且当前词以-tion结尾”“前一个标签是限定词且当前标签是名词”等任意函数，且可以看整句的任何位置。关键在Z(x)：它是对所有可能标签序列的指数分数求和，而不是每一步各自归一化。于是一个位置的强证据可以压过其他位置，标签偏置随之消失。

计算。标签序列的数量随长度指数增长，但分数可以按相邻标签分解，所以Z(x)和每个位置的边缘概率可以用前向-后向（动态规划）在 O(长度 × 标签数²) 内算出；预测时用Viterbi找最优序列。

训练。最大化条件对数似然，它是参数的凹函数，有唯一全局最优。论文给出两种迭代尺度算法，每一轮都需对每个训练句做一次前向-后向。

结果

合成数据上，按rib/rob结构生成的带噪数据，CRF错误率4.6%，MEMM为42%。在Penn Treebank 45类词性标注上（110万词语料一半训练一半测试），只用词-标签和标签-标签特征时：HMM 5.69%，MEMM 6.37%，CRF 5.55%；加入大小写、连字符、后缀等拼写特征后，MEMM降到4.81%，CRF降到4.27%，未登录词错误率从HMM的45.99%降到23.76%。训练很慢：从零初始化2000轮仍未收敛，用MEMM参数初始化后需1000轮。

后来的发展

CRF迅速成为信息抽取和序列标注的主力：CoNLL-2003命名实体命名实体评测、中文分词即字标注中的中文分词都大量使用它。结构化感知机提出了更简单、更快的训练方式，在同类任务上效果相当。

神经网络出现后，人们保留了CRF的“整句归一化 + 标签转移”部分，用网络自动学出的特征替代手写特征：从零开始的神经NLP的句子级训练、BiLSTM-CRF序列标注和神经命名实体识别都是“神经编码器 + CRF输出层”。预训练模型（BERT）普及后，逐位置softmax往往已足够，CRF层的增益变小，但在需要严格标签约束的场景仍在使用。

容易误解的地方

  • 标签偏置不是“所有判别模型”的问题，而是逐状态局部归一化带来的问题；CRF也是判别模型，但做全局归一化。
  • 论文实验里HMM在不加特征时反而比MEMM好，CRF的优势主要体现在能和MEMM一样加特征、又没有标签偏置。
  • CRF的训练和推断都要前向-后向或Viterbi，标签数多（如几百类）时计算量是标签数的平方。

局限与后续

  • 训练要对每个句子反复做前向-后向，迭代尺度法收敛很慢，论文中需上千轮迭代。

  • 特征仍需人工设计（后缀、大小写、词典等），换任务、换语言就要重新做特征工程。
    后来针对它的工作　从零开始的神经NLP BiLSTM-CRF序列标注 神经命名实体识别
  • 线性链只建模相邻标签之间的依赖，更远的标签约束要用高阶CRF，计算量随阶数指数增长。

它建立在什么之上

  • 改进
    HMM词性标注1988 · NLP
    HMM式生成模型难以加入重叠特征；CRF作为条件模型可使用任意观测特征，词性标注未登录词错误率大幅下降。
  • 使用
    Penn Treebank1993 · 数据·评测
    在Penn Treebank的45类词性标注上与HMM、MEMM对比。
  • 延续
    最大熵模型1996 · NLP
    把最大熵/对数线性模型从单个决策推广到整个序列，特征与权重的形式完全相同。
  • 使用
    Viterbi算法1967.04 · 语音
    预测时沿用Viterbi动态规划寻找得分最高的标签序列，训练用同类的前向-后向算法。
  • 竞争
    贝叶斯网络与概率图模型1988 · 基础
    HMM、MEMM是有向图模型；CRF是无向图（马尔可夫随机场）模型，只对条件分布建模，从而避开了有向模型的局部归一化。
  • 改进
    Brill转换式标注器1992 · NLP
    训练时要把每条候选规则在全语料上试一遍，速度慢，规则间有顺序依赖，难以融入概率不确定性。
  • 改进
    Nymble命名实体识别1997 · NLP
    生成式HMM难以同时利用词形、前后缀、词表等大量重叠特征。
  • 改进
    最大熵马尔可夫模型MEMM2000 · NLP
    MEMM逐状态归一化导致标签偏置；CRF改为在整个标签序列上归一化，合成数据上错误率从42%降到4.6%。

后来的相关工作

  • 改进
    BERT2018.10 · LLM
    线性链只建模相邻标签之间的依赖，更远的标签约束要用高阶CRF，计算量随阶数指数增长。
  • 竞争
    结构化感知机2002.07 · NLP
    CRF对全局序列做概率归一化，需要前向-后向求和；感知机只需要argmax，后来两者在实践中长期并存。
  • 使用
    CoNLL-2003命名实体2003.06 · 数据·评测
    McCallum和Li首次在这一共享任务上用条件随机场做NER（F1 84.04）；CRF随后成为神经网络之前序列标注的主流模型。
  • 使用
    从零开始的神经NLP2011 · NLP
    在神经网络打分之上加标签转移矩阵、用句子级似然训练，相当于以神经特征为输入的条件随机场。
  • 使用
    DeepLab空洞卷积2014.12 · 视觉
    用全连接CRF作后处理，把网络的粗糙概率图按颜色和位置相似性贴合到物体边界。
  • 使用
    神经命名实体识别2016.03 · NLP
    顶层用线性链CRF对整条标签序列联合打分，消融中贡献1.79 F1。
  • 使用
    BiLSTM-CRF序列标注2015.08 · NLP
    输出层用CRF对标签序列联合建模，学习标签转移分数。
  • 使用
    SyntaxNet全局归一化2016.03 · NLP
    借用CRF的全局归一化思想解决标签偏置。

读懂它需要的概念

概率图模型 逻辑回归 动态规划 隐马尔可夫模型 最大似然估计 判别模型与生成模型 凸函数与凸优化

本篇术语

  • 标签偏置（label bias）　局部归一化的序列模型中，后继状态少的状态会把概率几乎原样传下去，导致观测对路径选择几乎不起作用。
  • 全局归一化　只在“所有可能的完整标签序列”上做一次归一化，而不是每一步分别归一化，使各位置的证据可以互相权衡。
  • 前向-后向算法　利用分数可按相邻位置分解的性质，用动态规划求所有路径分数之和以及每个位置取各标签的边缘概率。

怎么学

先补隐马尔可夫模型、逻辑回归和概率图模型。读原文第2节（rib/rob的标签偏置例子）和第3节（CRF定义），再读Sutton与McCallum的教程第2–4章看前向-后向的推导。动手：用sklearn-crfsuite在CoNLL-2003上做命名实体识别，先只用词本身作特征，再加入大小写、后缀、前后词，观察F1的变化。
