DistilBERT

DistilBERT, a Distilled Version of BERT: Smaller, Faster, Cheaper and Lighter
2019.10论文延伸NeurIPS 2019 EMC² WorkshopVictor Sanh, Lysandre Debut, Julien Chaumond, Thomas Wolf · Hugging Face待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

BERT推理慢、占内存，在边缘设备和高并发服务上成本高。

方法

在预训练阶段做蒸馏：学生取BERT的一半层数，用语言建模、蒸馏和余弦距离三种损失训练。

影响

得到小40%、快60%、保留97%能力的通用小BERT，广泛用于实际部署。

方法

DistilBERT的学生模型结构与BERT相同，只是层数减半，用教师的权重间隔初始化。训练损失由三部分组成：掩码语言建模损失、与教师输出分布的蒸馏损失（见知识蒸馏）、学生与教师隐藏向量之间的余弦距离。

与TinyBERT不同，它只在预训练阶段蒸馏，之后像BERT一样微调。摘要称它比BERT小40%，保留97%的语言理解能力，快60%，并在手机上做了概念验证。Hugging Face把它放进自己的库，使其成为很多项目的默认轻量选择。

局限与后续

  • 层数减半，需要更强能力的任务上有明显下降。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM 已核对
    以BERT为教师，学生取一半层数。
  • 延续
    知识蒸馏2015.03 · 系统·效率
    把Hinton式蒸馏用在BERT预训练阶段。
  • 改进
    FitNets中间层蒸馏2014.12 · 系统·效率
    只在小数据集（CIFAR等）上验证，大数据集和Transformer上的效果当时未知。
  • 竞争
    TinyBERT2019.09 · 系统·效率
    同月出现的另一种BERT蒸馏：DistilBERT只在预训练做输出与隐藏向量蒸馏，TinyBERT逐层对齐且两阶段蒸馏，但训练更复杂。

    同样做任务无关的BERT蒸馏，但去掉了对隐层维度和层数的硬对齐要求。
