Rahimi“炼金术”演讲

Reflections on Random Kitchen Sinks
2017.12事件延伸NIPS 2017 时间检验奖演讲Ali Rahimi, Ben Recht · Google / UC Berkeley待核对
演讲文字稿（arg min博客） ↗在交互版中打开（演化树、学习进度）

问题

深度学习在2017年前后效果惊人，但很多常用技巧为什么有效没人说得清，领域里弥漫着一种自我庆祝的气氛。

方法

Rahimi在NIPS 2017领取时间检验奖时说“机器学习已经变成了炼金术”：能用，但缺乏理解；他以Batch Norm为例，呼吁回到严谨、可验证的知识。

影响

这段演讲在会场内外引发了关于深度学习严谨性的公开争论，随后催生了对机器学习论文写作和实证方法的一系列反思。

方法

2017年12月，Rahimi与Recht凭2007年的论文《Random Features for Large-scale Kernel Machines》获得NIPS时间检验奖。演讲前半段讲这篇论文的来历：2006年深度学习刚在NIPS引起注意，两人想找一种在大数据上训练核支持向量机的简单办法，用随机特征近似核函数。

后半段转向批评。Rahimi说空气中有一种自我庆祝的感觉，并提出另一个比喻：“机器学习已经变成了炼金术。”他承认炼金术并不坏，也确实产出了成果，做照片分享服务用它没问题，但“我们现在构建的系统在管理医疗和公民辩论”。他以Batch Normalization为例：它能加速梯度下降、已成为基础操作、效果极好，“但我们对它几乎一无所知”，连“内部协变量偏移”到底是什么都说不清。他希望系统建立在“严谨、可靠、可验证的知识”之上，甚至说怀念当年NIPS的“严谨警察”。

按一般了解，LeCun随后公开反驳，认为在理论跟上之前先让方法工作起来正是科学和工程的常态；这场争论在社区里持续了很久。演讲稿发布在Recht的博客上，日期是2017年12月5日。
