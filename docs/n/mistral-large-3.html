Mistral 3

Introducing Mistral 3
2025.12模型延伸2025-12-02 发布Mistral AI待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

Mistral自Mixtral之后未再发布开源MoE，开源前沿模型的话语权被中国实验室的大型MoE占据。

方法

发布Mistral 3系列：Mistral Large 3是总参数675B、激活参数41B的稀疏MoE，另有14B、8B、3B的小型稠密Ministral模型，全部Apache 2.0。

影响

欧洲实验室重回开源大型MoE，在3000块H200上从零训练，LMArena开源非推理模型排第2。

方法

2025年12月2日，Mistral发布Mistral 3。系列包含三个小型稠密模型（14B、8B、3B）和旗舰Mistral Large 3，后者是稀疏混合专家，总参数675B、激活参数41B，使用3000块英伟达H200从零训练。官方称这是Mistral自Mixtral系列之后第一个MoE模型，所有模型采用Apache 2.0许可。

官方称后训练后它与最好的开源指令微调模型持平，并具备图像理解和非中英文的多语言对话优势，在LMArena的开源非推理模型榜上排第2、开源总榜第6。同时发布了NVFP4格式检查点，可在单个8×A100或8×H100节点上用vLLM运行。官方说推理版本即将推出。

局限与后续

  • 官方公告时还没有推理版本，在数学和长链推理任务上落后于同期推理模型。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 总参数675B，需要整节点GPU才能部署，对个人开发者门槛仍高。
    本站还没有记录针对它的后续工作（不代表没有人解决）
