知识蒸馏

Distilling the Knowledge in a Neural Network
2015.03论文重要arXiv 2015Geoffrey Hinton, Oriol Vinyals, Jeff Dean · Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

多个大模型的集成或一个强正则化的大网络效果最好，但部署时太慢太贵；直接训练一个小模型，效果又明显差。

方法

让小模型（学生）去拟合大模型（教师）在较高“温度”下输出的整个概率分布（软目标），而不只是正确答案的标签，从而学到教师对“哪些错误答案更像”的判断。

影响

“蒸馏”成为把大模型能力压缩进小模型的标准方法：从DistilBERT、DeiT到今天用大模型输出训练小语言模型，都是它的后代。

背景

2015年，提升精度最可靠的办法是训练多个模型取平均（集成），或者训练一个用Dropout强力正则化的大网络。但语音识别、图像分类这类服务要同时响应海量请求，集成十个模型意味着十倍的推理成本。

模型压缩（Buciluă等）（Buciluă、Caruana等，2006）已经证明可以让一个小模型去模仿集成模型的输出，把知识“压缩”进去；Caruana等后来的做法是让小模型直接回归大模型softmax之前的logit。这篇论文要回答的是：这种迁移的本质是什么，怎样做最好。

方法

关键观察：训练好的模型不仅给出正确类别的概率，还给所有错误类别分配了概率，而这些小概率的相对大小包含大量信息。一张“2”的图片，可能被认为像“3”的概率是10⁻⁶、像“7”的概率是10⁻⁹——这说明了数据的相似结构，但数值太小，在交叉熵里几乎不起作用。

温度softmax（见Softmax与logits）：qᵢ = exp(zᵢ/T) / Σⱼ exp(zⱼ/T)。T=1是普通softmax；T越大分布越平。举例：一个十分类模型的logit是（10, 4, 3, 0, …, 0），T=1时概率约为（0.996, 0.0025, 0.0009, …），次要类别几乎看不见；T=5时变成（0.40, 0.12, 0.10, 0.054, …），“像3还是像7”的差别就显现出来了。

训练学生：在一个迁移集上，用教师在高温T下的输出作为软目标，学生在同一个T下计算softmax并最小化两者的交叉熵（见交叉熵）；同时再加一项以真实标签为目标、T=1的普通交叉熵，权重较小。软目标的梯度量级按1/T²缩小，所以要乘以T²保持两项比例。训练完后学生用T=1推理。

论文还证明：当T远大于logit的数值时，蒸馏等价于让学生的logit去拟合教师的logit，Caruana的做法是它的一个特例。

专家模型：对1亿张图、1.5万类的内部数据集JFT，训练一个通用模型加若干只区分易混类别的专家模型，专家可以并行训练。

一个惊人的实验：迁移集里去掉所有“3”，学生从没见过3，调好偏置后仍能认对98.6%的测试集“3”——知识全部来自教师对其他数字的软目标。

结果

MNIST：两层1200单元、带dropout的大网络错67个；两层800单元、无正则的小网络错146个；同样的小网络只加上拟合大网络T=20软目标的任务，错74个。

语音识别（约8500万参数的声学模型，约2000小时数据）：单模型帧准确率58.9%、词错误率10.9%；10个模型的集成为61.1%和10.7%；蒸馏出的单模型为60.8%和10.7%，集成带来的帧准确率提升超过80%被转移到了单个模型。只用3%的训练数据时，硬标签训练过拟合到44.5%，软目标训练达到57.0%。JFT上加61个专家模型，测试准确率从25.0%升到26.1%。

后来的发展

蒸馏很快成为通用工具：几乎同时的FitNets中间层蒸馏把匹配对象扩展到中间层特征，DistilBERT、TinyBERT、MiniLM把BERT压到更小，DeiT用卷积网络教师帮ViT在较少数据上训好，Noisy Student自训练把“教师生成软标签”用于自训练。大模型时代，“蒸馏”含义扩大为用强模型生成的数据训练弱模型：Alpaca与廉价指令微调、Vicuna与ShareGPT、Orca解释蒸馏用GPT的输出做指令微调，DeepSeek-R1把长推理能力蒸馏进小模型，Gemma 2用大模型的概率分布训练小模型。围绕用他人模型输出蒸馏的合规争议也随之而来（中美“蒸馏攻击”指控）。

容易误解的地方

  • 蒸馏的主要收益来自软目标里“错误类别的相对概率”，所以教师过于自信（输出接近one-hot）时效果有限，需要升温。
  • 温度不是越高越好：论文发现学生很小（每层30个单元）时，2.5到4的中等温度明显更好。
  • 原论文中的专家模型部分并没有被蒸馏回单个模型，它展示的是另一种并行训练集成的方法。

局限与后续

  • 只匹配最终输出的概率分布，教师中间层表示里的知识没有利用，学生和教师差距大时迁移有限。
    后来针对它的工作　TinyBERT MiniLM
  • 需要先训练好一个昂贵的教师模型，并在迁移集上反复运行它来产生软目标，训练总成本增加。
    后来针对它的工作　DistilBERT
  • 论文只在分类任务上验证，如何对生成式的序列模型做蒸馏（每一步都是一个分布）没有讨论。
    后来针对它的工作　Gemma 2 DeepSeek-R1
  • 为什么学生能从软目标学到额外的泛化能力，缺乏理论解释。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 改进
    Netflix Prize2006.10 · 数据·评测
    最终获胜的是数百个模型的集成，额外精度不值得工程成本，Netflix没有部署大奖方案。
  • 使用
    Dropout2012.07 · 基础
    MNIST上的教师是用dropout强正则化的大网络，论文把dropout看作共享权重的指数级集成，蒸馏正是把这种集成压缩进小网络。
  • 使用
    DistBelief与Downpour SGD2012.12 · 系统·效率
    JFT的基线模型和专家模型都在参数服务器加多副本异步SGD的DistBelief式基础设施上训练。
  • 延续
    模型压缩（Buciluă等）2006.08 · 系统·效率
    延续Buciluă等让小模型模仿集成模型的思路，用温度softmax把它推广，并证明匹配logit是其高温极限下的特例。
  • 竞争
    FitNets中间层蒸馏2014.12 · 系统·效率
    FitNets几乎同时提出、并以Hinton的软目标思想为基础，额外让学生匹配教师的中间层特征，用来训练更深更窄的学生网络。

读懂它需要的概念

Softmax与logits 交叉熵 KL散度 知识蒸馏 正则化与权重衰减 泛化与过拟合

本篇术语

  • 软目标（soft targets）　教师模型输出的完整概率分布，相对于只有正确类别为1的硬标签而言，包含各类别之间的相似信息。
  • 温度T　softmax里logit的除数。T越大，分布越平，小概率的类别之间的差别越容易被学生学到。
  • 暗知识（dark knowledge）　Hinton对软目标中错误类别相对概率所含信息的称呼。

怎么学

先确认会Softmax与logits和KL散度，手算一遍上面T=1和T=5的例子。读原文第2节（含梯度推导）和第3节MNIST实验。动手：在MNIST上训一个大MLP作教师，再分别用硬标签和T=4的软目标训练一个每层只有30个单元的学生，比较测试错误数；再试试从迁移集中去掉数字3会怎样。
