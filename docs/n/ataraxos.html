Ataraxos陆军棋超越人类

Scalable Decision-Making for Games of Imperfect Information
2026.09论文重要Nature 2026Samuel Sokota, Eugene Vinitsky, Hengyuan Hu, Zhiyuan Fan, J. Zico Kolter, Gabriele Farina · Carnegie Mellon University / NYU / Stanford / MIT待核对
Nature ↗DOI ↗在交互版中打开（演化树、学习进度）

问题

陆军棋的隐藏信息太多（布阵组合超过10³³种），扑克AI那套基于公共信息的博弈变换无法枚举；DeepNash花了数百万美元算力也只到专家水平、不做搜索，在世界锦标赛上输给了大多数顶尖选手。

方法

自我对弈时让正则化强度和策略更新幅度一起随训练衰减，压住不完全信息下的循环震荡；再训练一个信念网络采样“对方棋子可能是什么”，测试时在这些样本上推演，对当前一步再做一次同样的更新。

影响

20局对阵四届世界冠军Pim Niemeijer取得15胜1负4平，是陆军棋史上第一次超越人类最强者；训练只用16块H100一周、成本不到8000美元，同一套方法还在Barrage陆军棋、Hanabi、斗地主上取得最佳成绩。

背景

在不完全信息博弈里，一步棋的价值不只取决于之后怎么下，还取决于自己过去本来会怎么下——因为对手会据此推断你的隐藏信息。扑克AI（Libratus、ReBeL）用基于公共信息的变换处理它，代价随隐藏信息量增长：德州扑克只有1326种手牌，陆军棋的布阵则超过10³³种。

DeepNash陆军棋因此放弃搜索，只靠正则化自我对弈（R-NaD）；据本文作者了解，它用1024个TPU节点训练了两三个月、约55亿局。它2022年在线上平台胜率84%，但作者指出当时平台对手远非顶尖；2023年世锦赛展示中它19胜9负，输给了包括Pim在内的大多数高排名选手。

方法

两个互相耦合的自我对弈过程（见自我对弈），都用Transformer：布阵网络学习怎么摆40个棋子，走子网络学习怎么走；布阵过程提供开局，对局结果同时用来更新两者。

动态阻尼。不完全信息下朴素自我对弈会绕圈或发散（见博弈论基础与纳什均衡）。Ataraxos在损失中加正则项——走子网络是朝“随机挑一个可动棋子、再随机走一步”这一均匀策略的反向KL惩罚（见KL散度），布阵网络是最大熵项——并控制每次更新的幅度（PPO式比率裁剪、梯度裁剪、学习率等）。关键是两者协调：早期正则强、步子大，后期正则弱、步子小，都按幂律退火。退火太慢学不会，太快则熵塌缩、容易被针对。

信念网络与测试时搜索。用自我对弈数据训练信念网络，根据己方可见信息自回归地预测对方每个隐藏棋子的类型（自我对弈中真值已知）。每走一步前，从信念网络采样若干种可能的完整局面；对每个候选走法做限深推演并用价值网络估值；再把这些估值当作自我对弈数据，对当前这一步做一次表格式的磁镜像下降更新，从更新后的策略中采样走法。

结果

对Pim Niemeijer（4次世界冠军、排名第一超过600周）的20局系列赛历时3周，15胜1负4平，有效胜率85%；2025年世锦赛展示中40局38胜2负。训练用约1.6亿局、500亿条样本，作者估算算力约为DeepNash的1/500、对局数约1/30。其他游戏：Barrage陆军棋赢下对世界前四中三位选手的四个50局系列；Hanabi 2到5人变体均取得统计显著的新最佳；斗地主上显著击败PerfectDou和DouZero斗地主。

后来的发展

论文发表于2026年9月，影响尚待观察。它主张AlphaZero式的“自我对弈RL+测试时搜索”配方可以推广到隐藏信息极多的博弈，前提是有快速准确的模拟器（作者为此写了每秒数百万次状态更新的CUDA模拟器）。

容易误解的地方

  • 人机对局不是独立同分布的：Pim可以在20局中不断适应，而Ataraxos策略固定；论文报告的p值是在独立同分布假设下的参考值。
  • 测试时搜索只模仿一次更新步，和AlphaZero那种可以无限加深的树搜索不同。

  • 使用

  • 竞争
    反事实遗憾最小化CFR2007 · RL

本篇术语

  • 不完全信息博弈　玩家看不到全部局面的博弈，如扑克的底牌、陆军棋背面朝外的棋子；需要推断对手的隐藏信息并防止自己被推断。
  • 信念网络　根据己方能看到的信息，输出对手隐藏信息（这里是每个棋子的兵种）的概率分布，并可从中采样。
  • 磁镜像下降　Sokota等人提出的一种带正则的策略更新方法，每步既朝高价值动作移动，又被拉向一个参考策略，用于让博弈中的学习稳定收敛。
  • 有效胜率　把平局算半场胜利后的胜率，15胜1负4平即(15+2)/20=85%。

怎么学

先读DeepNash陆军棋了解陆军棋和R-NaD，再读ReBeL理解扑克AI如何在公共信念上搜索、为什么它在陆军棋上不可行。然后读Nature原文的“Overview of Ataraxos”和Methods中“Dynamically damped self-play”“Test-time search via update equivalence”两节。动手：在OpenSpiel的Kuhn扑克上实现带KL正则的自我对弈，比较正则系数固定与按幂律退火时策略是否绕圈。
