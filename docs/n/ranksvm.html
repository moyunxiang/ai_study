Ranking SVM点击学排序

Optimizing search engines using clickthrough data
2002.07论文延伸KDD 2002Thorsten Joachims · 康奈尔大学待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

要用机器学习调出好的检索排序函数，需要专家对大量查询-文档对做相关性标注，成本极高，难以随用户和时间不断更新。

方法

从搜索日志里的点击行为推出相对偏好：用户跳过前面的结果、点了后面的，就说明后者比前者更相关；再把「学排序」转化为在成对偏好约束上训练的支持向量机。

影响

确立了「成对（pairwise）学习排序」这一主要范式，Ranking SVM成为此后十年LETOR等基准上的标准基线；「用点击作隐式反馈」也开启了搜索日志学习与点击偏差研究。

背景

早期的检索排序函数（向量空间模型、BM25）由少数几个参数决定，靠人工调参。要综合几十种信号（文本相似度、链接、URL特征等），就需要从数据中学习。传统做法要求专家为查询-文档对标注相关性，这对每个新领域、每批新用户都要重做。Rocchio相关反馈相关反馈利用用户对单次结果的显式反馈，但用户很少愿意显式打分。与此同时，搜索引擎的日志里免费记录着海量点击。

方法

从点击中提取偏好。 点击不能直接当作「绝对相关」：排在第一的结果因为位置靠前被点的概率天然更高。Joachims只从点击中提取相对判断：如果用户看到排名1、2、3的结果，跳过1和2、点击了3，就推断「3 优于 1」和「3 优于 2」（被点击的文档优于排在它前面却没被点的文档）。这样位置偏差被大部分抵消。

成对排序SVM。 设Φ(q, d)是查询q和文档d的特征向量，排序函数是线性打分 f(q, d) = w·Φ(q, d)。每条偏好 d_i ≻ d_j 给出一个约束 w·Φ(q, d_i) > w·Φ(q, d_j)。允许违反并最大化间隔，得到优化问题：min ½‖w‖² + C Σ ξ_ij，约束 w·( Φ(q, d_i) − Φ(q, d_j) ) ≥ 1 − ξ_ij，ξ_ij ≥ 0。注意它等价于在差向量 Φ(q, d_i) − Φ(q, d_j) 上训练一个二分类支持向量机，所以可以直接用现成的SVM求解器（作者自己的SVMlight）。

实验系统。 作者搭了一个元搜索引擎，把几个商业搜索引擎的结果合并展示给用户，收集点击，学习各种特征（如某结果在各引擎中的排名、URL和摘要中是否含查询词）的权重。

结果

摘要称，实验表明这种方法能够有效地从点击数据中学出检索函数；原文的在线对比实验中，学到的排序函数相对所组合的商业引擎更受用户偏好（具体数字未核对）。

后来的发展

几年内出现了RankBoost、RankNet排序学习等其他成对方法，以及把成对改为列表的ListNet列表式排序；Joachims本人此后研究点击的位置偏差和交错实验（interleaving），发展出无偏学习排序。Ranking SVM作为基线一直出现在学习排序和推荐系统文献中。

读懂它需要的概念

核技巧与间隔 损失函数 监督学习 特征与表示学习 检索与向量数据库

本篇术语

  • 学习排序（learning to rank）　用机器学习从数据中学出一个给文档打分、按分数排序的函数。
  • 成对方法　训练样本是「文档A应排在文档B前面」这样的偏好对，而不是每篇文档的绝对相关度。
  • 隐式反馈　从用户的自然行为（点击、停留时间）推断偏好，而不是请用户明确打分。

怎么学

先懂支持向量机的软间隔形式 → 读原文第3节从点击提取偏好、第4节Ranking SVM → 动手：用LETOR或MSLR数据，把成对差向量喂给sklearn的线性SVM，与逐点回归比较NDCG。
