智能体的“致命三要素”

The lethal trifecta for AI agents: private data, untrusted content, and external communication
2025.06思想延伸Simon Willison · 个人博客待核对
Simon Willison ↗在交互版中打开（演化树、学习进度）

问题

智能体接入工具后常被提示注入攻击窃取数据，业界缺少一个简单规则来判断什么组合是危险的。

方法

提出「致命三要素」：同时拥有私有数据访问、接触不可信内容、对外通信能力，三者合一就能被诱导泄露数据。

影响

给开发者和用户一个可操作的判断标准，推动「避免三要素同时出现」成为智能体设计的经验法则。

方法

2025年6月16日，Simon Willison在博客提出该概念。逻辑是：LLM无法可靠区分运营者的指令与混入处理内容里的指令，所以网页或邮件里的恶意文字能够改变智能体行为。当同一个智能体既能读私有数据（如邮件）、又会读不可信内容（如网页）、还能向外发请求时，攻击者就能让它把私有数据发出去。

文章指出，厂商可以修补自己产品里的具体漏洞，却无法保护用户把不同来源的工具拼在一起的情形；模型上下文协议MCP让混搭工具变得容易，三要素可能在用户不知不觉时形成。声称拦截95%攻击的护栏产品在网络安全里等于不及格。最稳妥的办法是彻底避免三要素组合。
