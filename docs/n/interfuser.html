InterFuser可解释融合驾驶

Safety-Enhanced Autonomous Driving Using Interpretable Sensor Fusion Transformer
2022.07论文延伸CoRL 2022Hao Shao, Letian Wang, RuoBing Chen, Hongsheng Li, Yu Liu · 商汤、香港中文大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

端到端驾驶模型对突然出现的未知物体等罕见复杂场景很脆弱，而且是黑箱，出了事故也查不出原因。

方法

用Transformer融合多视角相机和激光雷达，同时输出可解释的中间结果（周围物体的占用图、交通信号状态），再用它们把规划出的动作约束在安全范围内。

影响

在CARLA公开排行榜上排名第一；“端到端模型也输出可解释中间表示并用作安全约束”的做法被后续驾驶系统广泛借鉴。

方法

TransFuser证明了用Transformer融合相机和激光雷达能提升端到端驾驶，但它的输出只有路点，无法检查模型“看到了什么”。InterFuser在融合多模态、多视角传感器信息后，除了预测未来路点，还输出一组可解释的中间特征：自车周围物体的占用与未来位置图、红绿灯和停车标志的状态等。控制器不直接照搬网络预测的路点，而是利用这些中间结果把动作约束在“安全集合”里，例如前方占用图显示有障碍就减速。这样既提高了对罕见对抗事件的检测能力，也让失败原因可以追查。论文在CARLA驾驶仿真器基准上做了大量实验，模型超过此前方法，在CARLA公开排行榜上排名第一。
