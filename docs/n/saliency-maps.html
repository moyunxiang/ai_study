梯度显著图

Deep Inside Convolutional Networks: Visualising Image Classification Models and Saliency Maps
2013.12论文延伸ICLR 2014 WorkshopKaren Simonyan, Andrea Vedaldi, Andrew Zisserman · 牛津大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

卷积网络分类很准，却是黑箱：人们不知道网络是看图像的哪些部分作出判断的。

方法

计算类别得分对输入像素的梯度，梯度绝对值大的像素就是对该类别最敏感的像素，得到显著图；另外还可以通过梯度上升生成使某类得分最大的图像。

影响

最早、最简单的梯度归因方法，后续积分梯度、Grad-CAM与显著图等都是对它的改进。

方法

论文提出两种基于梯度的可视化。第一种：用梯度上升在输入空间里合成一张使某个类别得分最大的图像，直观展示网络心中「这个类」的样子。第二种：给定一张图像和一个类别，计算该类的未归一化得分S_c对输入图像I的偏导∂S_c/∂I。偏导绝对值大，说明稍微改变这个像素就会明显影响该类得分，所以对多个颜色通道取最大值后画成热图，就是显著图。

作者展示，这个显著图可以不经任何额外训练，只靠分类网络就大致圈出物体位置，用作弱监督分割（用一个简单的前景、背景分割算法初始化）。他们还证明，这种梯度方法与卷积网络可视化的反卷积网络可视化在本质上是一回事，差别只是对ReLU的处理。

这种方法简单，但得到的图往往有噪点，也不一定反映网络真正「依据」了什么。

局限与后续

  • 梯度图噪声大，并且梯度只反映局部敏感度，不等于像素对结果的贡献。
    后来针对它的工作　积分梯度 Grad-CAM与显著图
  • 后来发现显著图可能与模型参数基本无关，难以判断可信度。
    后来针对它的工作　显著图的合理性检验

后来的相关工作

  • 竞争
    对抗样本2013.12 · 安全·可解释
    同月发表，同样对输入像素求梯度：显著图用它解释网络看哪里，这篇用它寻找让网络犯错的最坏方向。
  • 竞争
    LIME2016.02 · 安全·可解释
    显著图需要模型可微并读取梯度；LIME只调用模型的输入输出，适用于任意分类器，代价是需要大量采样。
  • 竞争
    Circuits与机制可解释性2020.03 · 安全·可解释
    显著图等归因方法只看输入对输出的影响；机制可解释性主张打开模型、读懂中间计算，两条路线此后并行发展。
  • 竞争
    CAM类激活图2015.12 · 安全·可解释
    同为解释“看哪里”，梯度显著图逐像素、噪声大，CAM给出平滑的区域级热力图。
  • 延续
    Grad-CAM与显著图2016.10 · 安全·可解释
    把输入像素梯度换成对最后卷积层特征图的梯度，得到更平滑、类别区分更强的热图
  • 改进
    积分梯度2017.03 · 安全·可解释
    梯度显著图在饱和区域的梯度接近零而漏掉重要特征；积分梯度沿路径积分，满足敏感性公理
  • 竞争
    影响函数与数据归因2017.03 · 安全·可解释
    显著图回答“看了输入哪里”，影响函数回答“从哪些训练数据学来”。
  • 改进
    DeepLIFT参考差分归因2017.04 · 安全·可解释
    梯度在饱和区为零会漏掉重要特征，DeepLIFT改用相对参考的激活差来分配贡献。
  • 改进
    SmoothGrad平滑梯度2017.06 · 安全·可解释
    原始梯度显著图噪点多，SmoothGrad在加噪的邻域内平均梯度，使图像更清晰。
  • 改进
    TCAV概念激活向量2017.11 · 安全·可解释
    梯度显著图只指出像素重要，TCAV把重要性表达为高层概念对预测的敏感度
  • 竞争
    特征可视化2017.11 · 安全·可解释
    梯度显著图解释一张具体图片里哪些像素重要，本文则生成神经元偏好的原型图像。
  • 改进
    显著图的合理性检验2018.10 · 安全·可解释
    梯度显著图一类方法缺少可靠的验证手段；本文提供了随机化检验。
