漂移模型Drifting

Generative Modeling via Drifting
2026.02论文延伸NeurIPS 2026（oral）Mingyang Deng, He Li, Tianhong Li, Yilun Du, Kaiming He · MIT / 哈佛大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

扩散和流模型把“噪声到数据”的推前映射拆成推理时的许多小步，所以生成慢；一步方法大多还要蒸馏或复杂的自洽约束。

方法

把“分布逐步演化”挪到训练时：定义一个漂移场，样本被真实数据吸引、被其他生成样本排斥，两分布相等时漂移为零；网络每次更新就朝漂移后的位置回归。

影响

一步生成在ImageNet 256上潜空间FID 1.54、像素空间1.61，超过此前所有一步方法，与多步模型相当。

方法

生成建模可以看成学一个映射f，使噪声经f推前后的分布等于数据分布。DDPM、Flow Matching是在推理时一步步推；Drifting Models注意到训练本身就是迭代过程，每次更新f，生成分布q都在变，于是让分布在训练时演化，推理只需一次前向。

驱动演化的是漂移场 V(x) = V⁺(x) − V⁻(x)：V⁺是按核函数加权的、指向真实样本的位移平均（吸引），V⁻是指向同批其他生成样本的位移平均（排斥）。q=p时二者抵消，V=0。损失为 ‖f(ε) − stopgrad(f(ε)+V(f(ε)))‖²，即让输出朝漂移后的位置移动。V在预训练特征空间（默认是在潜变量上训练的掩码自编码器MAE式编码器）里计算，作者说没有特征编码器在ImageNet上训不起来。

论文报告，L/2模型一步FID 1.54（潜空间）、L/16像素模型1.61；B/2仅1.33亿参数就与此前XL级一步模型相当。它与MeanFlow一步生成、生成对抗网络GAN同属“一步推前”，但既无判别器也无ODE。

局限与后续

  • 理论上只证明了“两分布相等则漂移为零”，反过来“漂移为零则分布相等”的条件仍不清楚。

  • 强依赖预训练特征编码器，核函数在样本相距很远时会变平；文生图与视频尚未验证。

它建立在什么之上

  • 竞争
    生成对抗网络GAN2014.06 · 生成
    同样是一次前向的推前生成器，但不训练判别器，而用吸引-排斥的核均值场直接给出移动方向。
  • 使用
    掩码自编码器MAE2021.11 · 视觉
    漂移场在MAE式自监督编码器的特征空间中计算，特征质量决定效果。
  • 使用
    Diffusion Transformer2022.12 · 生成
    生成器采用带adaLN-zero条件的DiT结构。
  • 改进
    归纳矩匹配IMM2025.03 · 生成
    1步质量明显不如8步，真正的一步高质量生成仍要靠后来的方法。
  • 竞争
    MeanFlow一步生成2025.05 · 生成
    同为从零训练的一步生成：MeanFlow学平均速度场，漂移模型完全去掉ODE，在训练时演化分布；论文中一步FID更低。
