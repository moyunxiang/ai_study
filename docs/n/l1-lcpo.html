L1思考长度控制

L1: Controlling How Long A Reasoning Model Thinks With Reinforcement Learning
2025.03论文延伸COLM 2025Pranjal Aggarwal, Sean Welleck · 卡内基梅隆大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

推理模型想得越久往往越准，但想多久没法控制：同一道题可能写几百词元也可能写一万，用户无法按预算换取准确率；s1的「预算强制」靠硬截断或硬续写，效果损失大。

方法

在提示里写明「思考N个词元」，用强化学习同时奖励答对和长度贴近N：奖励 = 答对与否 − α·|N − 实际长度|，让模型学会按指定预算思考。

影响

1.5B的L1能按预算平滑地在成本与准确率之间取舍，在数学题上比s1高最多20个百分点；还发现压到很短时仍保留推理模式的「短推理模型」，在同等长度下超过GPT-4o。

方法

基座是DeepScaleR-1.5B-Preview（由DeepSeek-R1蒸馏出的1.5B模型再经RL训练），训练数据约4万道数学题。每道题在提示末尾加一句「Think for N tokens.」，N在100到4000之间随机抽。

LCPO（长度控制策略优化）用GRPO训练，奖励有两种：

  • L1-Exact：r = 𝟙[答对] − α·|N − n_y|，α = 0.0003，偏离目标长度越多扣分越多，要求长度尽量精确；
  • L1-Max：r = 𝟙[答对] · clip(α·(N − n_y) + 0.5, 0, 1)，只要求不超过N，越省越好，但前提是答对。

结果：在512到3600词元的几档预算下，L1的准确率随预算平滑上升；与s1与预算强制用截断和插入「Wait」强制长度的做法相比，同预算下在数学题上最多高出20个百分点（短预算时相对提升100%以上）。作者还发现，把预算压到几百词元时模型仍会写出自我检查等推理模式，称为短推理模型（SRM）：1.5B的L1-Max在约800个词元时平均准确率略高于输出长度相近的GPT-4o全模态实时模型。

局限与后续

  • 长度目标需要用户在提示里显式给出，模型不会自己判断一道题该想多久。
