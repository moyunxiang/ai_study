ChatGPT agent

Introducing ChatGPT agent
2025.07系统重要OpenAI待核对
官方公告（存档） ↗System Card ↗在交互版中打开（演化树、学习进度）

问题

Operator会点网页但不擅长分析写报告，Deep Research会查资料写报告却不能登录、不能在网页上操作，用户得自己判断该用哪个。

方法

把两者合成一个模型和一台虚拟电脑：图形浏览器、文本浏览器、终端、API和连接器都放进同一个工具箱，由模型自己挑工具，一路做完任务。

影响

ChatGPT第一次能在网上替用户执行操作；“一个通用智能体加一台云端电脑”成为聊天产品的标准形态，Operator随后下线。

背景

2025年上半年，OpenAI有两个分开的智能体产品。Operator与浏览器智能体（1月）用CUA模型看截图、点鼠标，能在网页上订餐、填表，但写不出深入的分析；Deep Research（2月）能连续搜索几十轮、写出带引用的长报告，却只能读公开网页，不能点按钮、不能访问需要登录的内容。官方说，用户在Operator里提的很多请求其实更适合Deep Research。真实任务往往两者都要：比如“分析三家竞品并做成幻灯片”，既要查资料、又要登录网站、还要跑代码处理数据。

方法

2025年7月17日，OpenAI在ChatGPT里加入“agent mode”。核心是一个统一训练的模型在一台自己的虚拟电脑上工作，工具箱包括：

  • 图形浏览器：像Operator一样看截图、点击、输入，用于为人设计的网页；
  • 文本浏览器：像Deep Research一样快速读大量网页文字；
  • 终端：下载文件、运行代码、生成表格和幻灯片；
  • API与连接器：直接读Gmail、GitHub、日历等。

据发布直播，OpenAI用强化学习训练它在这些工具间切换：专门构造必须用到全部工具的难题，让模型不仅学会用工具，还学会“什么时候该用哪个工具”。同一台虚拟机保存任务上下文，模型可以用文本浏览器找到文件、在终端里处理、再用图形浏览器查看结果。这就是智能体循环的扩展版：每一步不只决定“做什么”，还决定“用哪种工具做”。

人随时可以插话改需求、接管浏览器（登录时由用户亲自输入密码，模型看不到），做购买等有后果的操作前模型必须请求确认，发邮件等关键任务要在“观看模式”下进行，银行转账直接拒绝。

结果

官方称：Humanity's Last Exam（Humanity's Last Exam）单次通过率41.6%，最多8次并行、按模型自报信心挑一个则为44.4%；FrontierMath借助终端达到27.4%；BrowseComp达到68.9%，比Deep Research高17.4个百分点；SpreadsheetBench直接编辑表格45.5%，对照的Excel Copilot为20.0%；WebArena上超过驱动Operator的CUA。在内部的经济价值知识工作评测中，约一半任务的产出被专家评为不差于人类。Pro用户每月400条消息，其他付费用户40条。

后来的发展

发布同时宣布Operator几周后下线，Deep Research保留为一个选项。OpenAI也首次把它按准备度框架（OpenAI准备度框架）视为生物化学“高能力”模型并启用相应防护。第三方实测（Timothy B. Lee）显示它比Operator进步明显：16项购物清单抄对并加入购物车15项（Operator只放进13项），但仍会漏项，还会被过于敏感的安全监控挡在登录页外，可靠性不足以托付重要任务。

容易误解的地方

  • ChatGPT agent不是把两个产品界面拼起来，而是一个同时学会了点网页和做研究的模型；但原版Deep Research仍可单独选用，默认报告更详细。
  • 41.6%等成绩是“驱动agent的模型”在带工具设定下的结果，不能直接与不带工具的模型分数比较。

局限与后续

  • 智能体能读到连接器里的私人数据并在已登录网站上行动，网页中隐藏的恶意指令（提示注入）可能诱导它泄露数据或误操作，官方承认整体风险更高。

读懂它需要的概念

智能体循环 工具调用 提示注入 推理token与测试时计算

本篇术语

  • 接管模式（takeover）　用户直接操作智能体正在使用的远程浏览器，例如亲自输入密码登录，然后把控制权交还给模型；这段输入不会被模型看到。
  • 连接器（connector）　经用户授权后，让ChatGPT通过接口读取Gmail、GitHub、日历等第三方应用数据的插件。

怎么学

先读Operator与浏览器智能体和Deep Research两个节点，理解两种智能体各自擅长什么。然后读官方公告的“A natural evolution”和“Novel capabilities, novel risks”两节，再翻System Card看提示注入和确认机制的评测。动手：把同一个任务（如比价并整理表格）分别描述成“需要点网页”和“只需读网页”两种做法，体会工具选择为什么重要。
