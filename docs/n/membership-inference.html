成员推断攻击

Membership Inference Attacks against Machine Learning Models
2016.10论文延伸IEEE S&P 2017Reza Shokri, Marco Stronati, Congzheng Song, Vitaly Shmatikov · Cornell Tech待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

模型是否「记住」了某条训练数据，没有可操作的度量；人们不知道对着黑箱模型，能不能判断某个具体个人的记录是否在训练集里。

方法

训练若干「影子模型」模仿目标模型，再训练一个攻击模型，根据模型对一条记录的输出区分「在训练集里」与「不在」。

影响

成为隐私攻击的标准测试：判断模型是否泄露训练数据，从LLM提取训练数据等后续攻击和机器遗忘的评估都使用它。

方法

攻击者只能黑盒访问模型：给一条记录，得到模型的预测向量。目标是判断这条记录是否在目标模型的训练集里。

方法是对抗性地使用机器学习本身：攻击者先造出若干「影子模型」，用与目标模型相同的服务（如Google、Amazon的机器学习即服务）和与目标数据分布相似的数据训练它们。因为攻击者自己知道影子模型的训练集，就能得到大量标注好「在训练集 / 不在训练集」的输出样本。然后在这些样本上训练一个二分类的攻击模型：模型对训练过的记录和没训练过的记录，输出的置信度分布不同（过拟合越严重差异越大），攻击模型据此判断。

论文用真实的医院出院数据集等做了评估，结果表明（摘要）这些商用服务训练出的模型会泄露训练记录的信息。成员身份本身可能是敏感信息，例如某人的记录出现在某种疾病的数据集里。

局限与后续

  • 攻击效果与过拟合高度相关，对泛化好的模型较弱；同时需要有与训练数据分布相近的数据。

  • 论文只给出攻击，缺少有保证的防御；有效防御后来主要是差分隐私。
