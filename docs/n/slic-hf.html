SLiC-HF序列似然校准

SLiC-HF: Sequence Likelihood Calibration with Human Feedback
2023.05论文延伸Yao Zhao, Rishabh Joshi, Tianqi Liu, Misha Khalman, Mohammad Saleh, Peter J. Liu · Google DeepMind、Google Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用人类反馈对齐语言模型通常走RLHF：先训奖励模型，再用PPO在线采样优化，实现复杂、难调、算力开销大。

方法

把序列似然校准（SLiC）用到人类偏好上：直接用排序损失让模型给“被偏好回答”的序列似然高出“不被偏好回答”一个间隔，再加一项正则防止偏离SFT模型，不需要在线强化学习。

影响

与约两周后公开的DPO一起，代表了“不用强化学习、直接在偏好对上做离线优化”的路线，后来的IPO、RSO等工作常把它当作对照。

方法

背景：人类反馈学摘要和InstructGPT与RLHF用PPO做RLHF，需要同时维护策略、价值、奖励和参考四个模型，并在训练中不断采样新回答。作者此前提出的SLiC（序列似然校准）发现，按最大似然训练的生成模型给出的序列概率排序并不总与质量一致，可以用一个校准损失来纠正。

SLiC-HF把这个思路搬到人类偏好上。对一条输入x，取一对回答：人类更偏好的y⁺和较差的y⁻，损失是 max(0, δ − log P(y⁺|x) + log P(y⁻|x)) 加上一项正则（在SFT数据上的交叉熵），δ是希望拉开的间隔。偏好对可以有两种来源：直接用已有的人类偏好数据；或者先训一个排序模型，再用它给SFT模型自己采样出的多个回答排序配对。作者还强调，偏好数据可以来自另一个模型的输出，相当于离线、异策略的数据。

实验在TL;DR摘要任务上进行，摘要称SLiC-HF明显超过SFT基线，与过去工作中PPO实现的RLHF相比有竞争力，而实现更简单、调参更容易、实际计算更省。

局限与后续

  • 使用hinge式间隔损失和单独的正则项，没有像DPO那样从KL约束的RL目标推导出来，理论性质不清楚；实验也只在摘要任务上做，没有在通用对话助手上验证。

  • 竞争
    PPO2017.07 · RL

  • 改进
    InstructGPT与RLHF2022.03 · LLM
    InstructGPT式的PPO-RLHF实现复杂、开销大，SLiC-HF用离线排序损失直接在偏好对上训练。
  • 竞争
    DPO直接偏好优化2023.05 · LLM
    约两周后公开的离线偏好优化方法，DPO从带KL约束的RL目标推出对数几率损失，SLiC-HF用间隔排序损失加SFT正则。
  • 使用
    人类反馈学摘要2020.09 · LLM
    使用同一个TL;DR摘要任务和人类偏好数据作为主要实验平台。

读懂它需要的概念

人类反馈强化学习 损失函数 语言模型 on-policy与off-policy 正则化与权重衰减

本篇术语

  • 序列似然校准　调整模型给整段输出序列的概率，使概率高低与输出质量的好坏一致。
  • hinge损失　只在两者差距小于某个间隔时才产生损失，差距足够大后损失为零。

怎么学

先读人类反馈学摘要了解TL;DR上的RLHF设定和DPO直接偏好优化的推导；读本文损失函数和两种偏好对构造方式的对比；动手：在一个偏好数据集上分别用hinge损失和DPO损失训练小模型，比较胜率与KL偏离。
