基础模型工具学习综述

Tool Learning with Foundation Models
2023.04论文延伸ACM Computing SurveysYujia Qin, Shengding Hu, Yankai Lin, Weize Chen, Ning Ding, Ganqu Cui, Zheni Zeng, Yufei Huang et al. · 清华大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

2023年初，让大模型调用搜索、计算器、各种API的工作突然变多，但大家各用各的说法和做法，缺少一个统一的问题框架来讨论“模型怎样学会用工具”。

方法

系统梳理工具学习：区分“用工具增强模型”和“让模型面向工具操作”两类研究，提出一个从理解指令、分解任务、动态调整计划到选择并调用工具的通用框架。

影响

成为“tool learning（工具学习）”这一说法最常被引用的综述之一，作者团队随后做出ToolLLM与ToolBench，这套框架成了后续工具调用研究的常用参照。

方法

综述先从认知科学讲起：人类之所以强，是因为会造工具、用工具；基础模型出现后，AI系统也有可能把“专用工具的精确”和“大模型的通用理解”结合起来。

作者把已有工作分成两类：

  • 工具增强学习：工具是模型的辅助，用来补足模型的短板，比如检索补知识（见WebGPT）、计算器补算术、代码解释器补精确执行；
  • 面向工具的学习：模型的目标是操作工具本身，比如按指令控制网页、软件、机器人，由模型充当控制器。

在此基础上提出一个通用工具学习框架：模型先理解用户指令，把复杂任务分解成若干子任务，在执行过程中通过推理动态调整计划，并为每个子任务选择合适的工具完成。论文还讨论了怎样训练模型使用工具（从演示中学、从反馈中学）、怎样让模型在没见过的工具上泛化，以及安全、可信、工具创造等开放问题。由于此前缺少系统的工具学习评测，作者用18个代表性工具做实验，展示了当时基础模型熟练使用工具的潜力。它整理的脉络把MRKL系统、Toolformer、ReAct等工作放进了同一张图里。
