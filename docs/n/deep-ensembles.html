深度集成

Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles
2016.12论文延伸NeurIPS 2017Lakshminarayanan, Pritzel, Blundell · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

贝叶斯神经网络能给出不确定性，但需要改训练流程、计算贵、超参数多，实际难以推广。

方法

直接训练若干个随机初始化的普通网络（再配合恰当的评分规则和可选对抗训练），把它们的预测平均，用分歧度当作不确定性。

影响

成为深度学习不确定性估计中最强的、最容易复现的基线，常常优于近似贝叶斯方法。

方法

做法是：独立训练M个同结构的网络，只让它们的随机初始化与数据顺序不同；对回归，每个网络输出均值和方差，并用高斯负对数似然训练，对分类则直接用交叉熵。预测时把M个网络的输出混合，均值为平均，方差由各网络方差的平均加上各均值的离散程度给出，所以模型间的分歧越大，不确定性越高。作者还加入对抗样本训练来平滑预测。

摘要称在分类与回归基准上，该方法给出的不确定性估计与近似贝叶斯网络相当或更好，在分布外样本上表现出更高的不确定性，并在ImageNet上验证了可扩展性。它与Bagging的区别是不对数据重采样，实践中随机初始化已足够带来多样性。

局限与后续

  • 推理和存储成本是单个模型的M倍，对大模型很难承受；各成员互相独立，没有显式保证多样性，也缺乏严格的贝叶斯解释。

它建立在什么之上

  • 竞争
    贝叶斯神经网络1992 · 基础
    作为不依赖贝叶斯推断的非贝叶斯替代方案，达到相当或更好的不确定性
  • 改进
    高斯过程回归1995 · 基础
    求逆需要O(n³)时间和O(n²)内存，数据超过几万点就不可行。
  • 延续
    Bagging1996 · 基础
    沿用集成的思想，但不重采样数据，只靠随机初始化和数据顺序产生差异
  • 改进
    SGLD随机梯度朗之万2011.06 · 基础
    在高维神经网络后验上，朗之万一步一步的随机游走探索效率低，难以覆盖多个模态。
  • 改进
    Bayes by Backprop2015.05 · 基础
    参数量翻倍，且平均场高斯后验假设权重之间相互独立，往往低估不确定性，在大网络上效果不如简单的集成方法。
  • 竞争
    MC Dropout不确定性2015.06 · 基础
    同样想得到不确定性；MC Dropout是单模型多次采样，集成是训练多个模型，后者通常质量更好但更贵

后来的相关工作

  • 竞争
    快照集成2017.04 · 基础
    深度集成独立训练多个网络，多样性更好但训练成本是M倍；快照集成用一次训练的预算换取较低的多样性。
  • 竞争
    神经网络校准2017.06 · 基础
    同期另一条获得可靠不确定性的路线；集成需要训练多个模型，温度缩放只在已训好的模型上加一个参数
  • 改进
    模式连通性2018.02 · 基础
    把集成的训练成本压缩到约一次训练，用一条山谷里的多个点代替多次独立训练
  • 改进
    随机权重平均SWA2018.03 · 基础
    推理和存储成本是单个模型的M倍，对大模型很难承受；各成员互相独立，没有显式保证多样性，也缺乏严格的贝叶斯解释。
  • 竞争
    Laplace Redux拉普拉斯近似2021.06 · 基础
    深度集成需要训多个网络；拉普拉斯近似只在一个训练好的网络上事后计算，实验中性能相当而代价更低。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。
