在线LDA随机变分推断

Online Learning for Latent Dirichlet Allocation
2010.12论文延伸NeurIPS 2010Matthew D. Hoffman, David M. Blei, Francis Bach · 普林斯顿大学、INRIA待核对
NeurIPS论文页 ↗在交互版中打开（演化树、学习进度）

问题

批量变分推断和Gibbs采样每次迭代都要扫一遍全部文档，面对几百万篇维基百科文章或持续到达的新闻流，训练一个主题模型要很久，甚至根本装不下。

方法

把LDA的变分推断改写成随机优化：每次只读一小批文档，求出它们的局部变分参数，再沿“自然梯度”方向用逐渐减小的步长更新全局的主题参数，可以证明收敛到变分目标的局部最优。

影响

单遍扫描就在330万篇维基百科文章上拟合出100个主题，质量与批量变分推断相当甚至更好、耗时只是零头；这一算法成为gensim、scikit-learn中LDA的默认实现，并被推广为通用的随机变分推断（SVI）。

背景

LDA主题模型原论文用批量变分EM：E步为每篇文档优化局部变分参数（主题比例γ与词的主题分配φ），M步用所有文档的统计量更新全局的主题—词参数λ。LDA折叠Gibbs采样实现更简单，但同样需要反复遍历整个语料。到2010年，可用的文本规模（整个维基百科、新闻流）已经远远超出这些批量方法的承受能力。随机梯度下降在大规模机器学习中早已证明有效，但如何把它用于贝叶斯后验推断还不清楚。

方法

全局变分参数λ（每个主题对词表的狄利克雷参数）的批量更新是：λ = η + Σ_d (文档d的期望词—主题计数)。在线算法的第t步：

1. 从语料中取一篇（或一小批）文档d； 2. 固定λ，像批量算法的E步一样迭代求出该文档的局部参数γ_d与φ_d； 3. 假装整个语料由D篇与d相同的文档组成，计算中间估计 λ̃ = η + D · (文档d的期望计数)； 4. 用步长 ρ_t = (τ_0 + t)^{−κ} 混合：λ ← (1 − ρ_t) λ + ρ_t λ̃。

作者证明，λ̃ − λ 正是变分目标对λ的自然梯度的一个无偏随机估计，因此这实际上是随机自然梯度上升；当 κ ∈ (0.5, 1] 时满足Robbins-Monro条件，算法收敛到变分目标的局部最优。小批量与参数τ_0、κ控制早期更新的权重和遗忘速度。

结果

作者用单遍扫描在330万篇维基百科文章上拟合了100个主题的模型；在多个语料上，在线LDA找到的主题模型与批量变分推断一样好或更好（以留出困惑度衡量），而用时只是后者的一小部分（NeurIPS论文页摘要）。

后来的发展

Hoffman、Blei等人在2013年把这一思路推广为随机变分推断SVI随机变分推断，适用于一大类条件共轭的概率模型，包括HDP层次狄利克雷过程。在线LDA被gensim的LdaModel与scikit-learn的LatentDirichletAllocation直接实现，是工业界训练大规模主题模型最常见的方式；随机变分推断也成为后来变分自编码器等深度生成模型训练的思想来源之一。

局限与后续

  • 仍只收敛到局部最优，结果对步长参数τ_0、κ和小批量大小敏感。

它建立在什么之上

  • 使用
    随机梯度下降1951 · 基础
    沿用随机近似的步长条件（Robbins-Monro）保证收敛。
  • 延续
    变分推断1999 · 基础
    把批量变分推断改造为随机自然梯度优化。
  • 改进
    LDA主题模型2003 · NLP
    解决LDA批量推断无法扩展到海量和流式文档的问题。
  • 竞争
    LDA折叠Gibbs采样2004.04 · NLP
    Gibbs采样每轮要遍历所有词；在线变分推断单遍即可，更适合超大语料。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

Beta分布、狄利克雷分布与共轭先验 变分推断与ELBO 随机梯度下降与小批量 学习率与学习率调度 隐变量模型 费舍尔信息与Cramér–Rao下界

本篇术语

  • 自然梯度　按参数空间中概率分布的几何（费舍尔信息）修正过的梯度，对变分参数而言更新更稳定。
  • 全局与局部变分参数　全局参数是所有文档共享的主题词分布，局部参数是每篇文档自己的主题比例和词的主题分配。
  • Robbins-Monro条件　步长之和发散而步长平方和收敛，保证随机近似算法收敛。

怎么学

先学LDA主题模型的变分推断 → 读论文第2–3节在线算法与收敛性 → 动手：用gensim的LdaModel在维基百科的一个子集上以不同的chunksize和decay参数训练，比较留出困惑度和耗时。
