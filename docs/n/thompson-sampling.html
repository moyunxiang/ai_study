Thompson采样的复兴

An Empirical Evaluation of Thompson Sampling
2011论文延伸NIPS 2011Chapelle, Li · Yahoo! Research待核对
NeurIPS ↗在交互版中打开（演化树、学习进度）

问题

多臂老虎机问题里的Thompson采样（1933）是最古老的探索方法之一，但当时文献里很少用，人们更多使用UCB类方法。

方法

在模拟和真实数据上做经验评估，说明Thompson采样表现很有竞争力且极易实现。

影响

让Thompson采样重新进入主流，之后成为在线推荐、广告和后验采样RL的常用基线。

方法

算法非常简单：为每个臂（或每个选项）维护奖励概率的后验分布，每一轮从每个臂的后验里各采一个样本，选取样本最大的那个臂，观察奖励后更新这个臂的后验。后验越不确定的臂越有可能采到大样本，探索自然发生；后验越窄越会被利用。

论文摘要称，作者在模拟与真实数据上做了经验结果，表明它很有竞争力，并因为容易实现，主张它应当成为标准基线。我只核对了摘要，没有逐项核对具体实验数字，所以这里不引用数字。

它建立在什么之上

  • 改进
    UCB12002 · RL
    常数较松，UCB1实际表现不如调过参数的方法；表现更好的UCB1-TUNED却没有理论保证。
  • 竞争
    LinUCB上下文老虎机2010.02 · RL
    同期的上下文老虎机主流是LinUCB的置信上界法；Thompson采样用后验采样取代置信上界，实验上常常更好。
  • 延续
    多臂老虎机问题1952 · RL
    在老虎机问题上重新验证并推广了Thompson的原始思想。

后来的相关工作

  • 使用
    Bootstrapped DQN2016.02 · RL
    每回合随机挑一个头整回合执行，是Thompson采样在深度Q网络上的近似。
  • 改进
    伪计数探索2016.06 · RL
    需要能处理的后验分布；在复杂模型（如深度网络）里后验难以精确求得。
  • 使用
    PEARL离策略元RL2019.03 · RL
    适应时从任务后验采样再行动，是后验采样（Thompson采样）思想的应用。
