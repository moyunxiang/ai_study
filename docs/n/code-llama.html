Code Llama

Code Llama: Open Foundation Models for Code
2023.08论文重要arXiv 2023Baptiste Rozière, Jonas Gehring, Fabian Gloeckle, Sten Sootla, Itai Gat, Xiaoqing Ellen Tan, Yossi Adi, Jingyu Liu et al. · Meta待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

开放代码模型（StarCoder等）在HumanEval上只有三成左右，与GPT-4的67%差距巨大；上下文多为8K以内，放不下多个源文件；从头训练一个大代码模型代价高昂。

方法

不从头训练，而是从通用的Llama 2出发，在5000亿token以代码为主的数据上继续训练，再分别加上中间填充、16K长上下文微调（调大RoPE基频）、Python专精和指令微调，得到一个系列。

影响

开放代码模型的HumanEval首次超过50%（后来的70B指令版达67.8%），7B的Python版就超过通用的Llama 2 70B；“通用基座＋代码继续预训练＋长上下文微调”成为之后代码模型的标准配方。

背景

Codex本身就是在GPT-3上继续用代码训练得到的，说明通用语言知识对写代码有帮助。开源一侧，StarCoder从头在1万亿token的代码上训练，HumanEval 33.6%；通用的Llama 2 70B只有30.5%。闭源的GPT-4为67.0%。

实际的编程助手还需要两种能力：一是在编辑器里根据光标前后的代码补全中间（中间填充FIM）；二是看到足够多的上下文，比如整个文件甚至多个文件。Llama 2只有4096个token，而一个中等规模的源文件就可能超过这个长度。

方法

分阶段专精，全部从Llama 2权重初始化：

1. 代码继续预训练：7B/13B/34B在5000亿个token上训练（论文后续版本加入的70B为1万亿），数据以近似去重的公开代码为主，另有8%与代码相关的自然语言（如问答讨论），再混入少量普通文本以保留语言能力。7B、13B、70B同时以中间填充FIM目标训练：一部分样本把代码切成前缀、中间、后缀，按“前缀-后缀-中间”或“后缀-前缀-中间”的顺序排列，让模型学会补中间。

2. 长上下文微调：在16,384长度的序列上继续训练，并把旋转位置编码RoPE的基频θ从10,000调到1,000,000。基频越大，每个维度旋转得越慢，同样的角度范围能覆盖更长的距离。模型在推理时可以稳定处理到约10万个token。

3. Python专精：再用1000亿个Python为主的token训练，得到Code Llama - Python。

4. 指令微调：除Llama 2的指令数据外，用自举方式造代码数据（见Self-Instruct）：让Llama 2 70B出6.2万道面试风格的题目，去重后约5.2万道；每题让Code Llama 7B写单元测试和10个解答，运行测试，保留第一个通过的解答，最终约1.4万组“题目-测试-解答”。这里用执行反馈代替了昂贵的人工标注。

结果

HumanEval pass@1（贪心解码）：Code Llama 34B为48.8%，Python版34B为53.7%，最初发布中最好；论文v3加入的Code Llama - Instruct 70B达67.8%，与GPT-4报告的67.0%持平。MBPP最高约65%。Code Llama - Python 7B（HumanEval 38.4%）超过Llama 2 70B（30.5%）。在多语言代码评测MultiPL-E上所有尺寸都超过此前公开模型。长上下文方面，困惑度在10万token以内持续下降，在一个仿照迷失在中间设计的代码检索任务中，模型在训练长度16K以内表现良好，超过16K后准确率下降。

后来的发展

Code Llama以与Llama 2相同的许可证发布，允许商用，成为2023年下半年开源编程助手的主要底座。“调大RoPE基频”与YaRN等插值方法一起，成为后来扩展上下文时常用的两类手段。此后DeepSeek-Coder、StarCoder2与Stack v2和Qwen2.5-Coder继续抬高开放代码模型的水平，评测重心也从函数级小题转向SWE-bench这类真实仓库任务。

容易误解的地方

  • 基频调大不是免费的：论文报告长上下文微调后，模型在短序列代码基准上略有下降，需要在长短之间权衡。
  • 最受关注的67.8%来自2024年1月加入的70B指令版，2023年8月首发时最好成绩是34B的50%出头。

局限与后续

  • 评测以HumanEval和MBPP这类独立函数题为主，不能反映修改真实仓库、跨文件调试的能力。

读懂它需要的概念

预训练与微调 位置编码 上下文窗口 指令微调与对话模板 基准、排行榜与SOTA 分词与token

本篇术语

  • 继续预训练　在已训练好的通用模型上，用某一领域的大量无标注数据接着做预训练，让它专精该领域，成本远低于从头训练。
  • RoPE基频　RoPE中决定各维度旋转速度的常数（原始为10,000）。调大后所有维度转得更慢，模型能区分的距离更长。
  • 执行反馈　把模型写的代码真正运行一遍，用是否通过测试来判断好坏，而不依赖人工评判。

怎么学

先读旋转位置编码RoPE和中间填充FIM。读Code Llama论文第2节（四个训练阶段，尤其2.4长上下文和2.5自举指令数据）和表2。动手：取一个开源代码模型，写一个函数前后文用FIM格式让它补中间；再复现自举流程的缩小版——让模型出10道题、写测试和解答，用Python执行筛选。
