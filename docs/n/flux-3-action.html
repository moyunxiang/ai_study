FLUX 3 Action

FLUX 3 Action
2026.09模型延伸Black Forest Labs待核对
官方页面 ↗VentureBeat报道 ↗在交互版中打开（演化树、学习进度）

问题

开源世界动作模型参数大、推理慢，最好的开源模型Cosmos 3 Nano有16B参数，难以在机器人端侧实时运行。

方法

从以视频为主预训练的多模态FLUX 3骨干派生出7B的世界动作模型，同时预测未来视频和32步动作块，并做引导蒸馏和单步蒸馏提速。

影响

图像生成公司跨界做机器人：官方称以不到一半参数在RoboLab-120上超过Cosmos 3 Nano，权重开放并接入LeRobot。

方法

FLUX 3是Black Forest Labs在2026年推出的多模态生成骨干（延续FLUX.2），训练token中视频占95%以上。FLUX 3 Action在此基础上做“动作中期训练”：混入游戏数据（占21.85%）、第一视角手势数据、手持夹爪数据和14种机器人形态的遥操作数据，再在DROID上微调。输入是文字指令、多路相机画面和机器人状态，输出是未来视频帧和动作块（每次32个动作，15赫兹，约2.13秒），视频和动作在同一模型里联合预测，属于DreamZero与世界动作模型WAM开创的世界动作模型路线。

官方报告：RoboLab-120基准上引导蒸馏版成功率约42.2%，Cosmos 3的Nano版（16B）36.8%，π0.5为28.0%；单步蒸馏版单块延迟约32毫秒。合作方在Franka机械臂上做10个DROID任务各3次，FLUX 3 Action成功28次（93.3%），Cosmos 3 Nano 90.0%，DreamZero 66.7%，π0.5 43.3%。官方页面正文和表格里有几处数字不一致（42.2%与42.92%）。
