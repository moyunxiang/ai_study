微软收购Nuance

2021.04事件延伸微软、Nuance · Microsoft待核对
Nuance Communications（维基百科） ↗在交互版中打开（演化树、学习进度）

问题

微软要在医疗这一语音与文档需求大的行业里扩大AI业务，需要成熟的临床语音识别产品和客户基础。

方法

2021年4月，微软宣布以约197亿美元（含债务）全现金收购语音识别公司Nuance，2022年3月完成。

影响

这笔收购把语音识别从历史上的独立公司并入云与医疗AI业务。

方法

Nuance是老牌的语音技术公司，前身可追溯到SRI国际的STAR实验室（1994年分拆）和ScanSoft，2005年二者合并。据维基百科，微软在2021年4月宣布收购，价格为每股56美元，含债务总计197亿美元，全现金，2022年3月完成。

历史上Nuance的语音识别技术是许多产品的幕后引擎，早期的语音助手（见Siri与语音助手）就曾依赖它的技术；其识别方法随着深度网络声学模型一起升级为深度神经网络。微软看重的是它的临床对话记录产品。

后来的发展

收购后微软把Nuance的临床语音功能放进自己的医疗云，并在2023年把GPT-4用于临床文档（Microsoft 365 Copilot一类的产品化路线）。这笔交易也象征独立语音公司被大模型时代的平台公司吸收。
