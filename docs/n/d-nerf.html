D-NeRF动态辐射场

D-NeRF: Neural Radiance Fields for Dynamic Scenes
2020.11论文延伸CVPR 2021Albert Pumarola, Enric Corona, Gerard Pons-Moll, Francesc Moreno-Noguer · 加泰罗尼亚理工大学 / 马普所待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

NeRF只适用于静态场景：同一空间位置必须在不同图像中看起来一样，物体一动就无法重建。

方法

把时间作为额外输入，学习两个映射：一个把某时刻的点变形回统一的规范空间，另一个在规范空间里表示场景的密度和颜色。

影响

只用一台绕场景移动的相机，就能重建刚性、关节和非刚性运动的物体，并同时控制视角和时间渲染新图像，成为动态NeRF的代表基线。

方法

NeRF用一个网络把空间位置和视角方向映射为体密度和颜色，前提是场景不变。对于运动物体，同一个三维点在不同时刻对应不同内容，多视角约束失效。

D-NeRF把学习分成两部分，都用全连接网络实现并同时训练：变形网络输入点坐标x和时间t，输出位移Δx，把该时刻的点映射到规范空间（约定t=0时的形态）中的对应位置；规范网络在规范空间里像普通NeRF一样，输出密度和与视角相关的颜色。渲染某一时刻、某一视角的图像时，沿射线采样的每个点先经变形网络变回规范空间再查询。训练数据只来自单台绕场景移动的相机，每个时刻只有一个视角。

训练好后，可以分别控制相机视角和时间变量来渲染新图像，也就控制了物体的运动。作者在包含刚性、关节和非刚性运动物体的场景上展示了效果。
