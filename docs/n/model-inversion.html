模型反演攻击

Model Inversion Attacks that Exploit Confidence Information and Basic Countermeasures
2015.10论文延伸ACM CCS 2015Matt Fredrikson, Somesh Jha, Thomas Ristenpart · 卡内基梅隆大学 / 威斯康星大学 / 康奈尔科技校区待核对
论文PDF ↗在交互版中打开（演化树、学习进度）

问题

机器学习即服务让人们能向模型查询预测结果，而模型常同时返回置信度；这些置信度是否泄露训练数据里个人的敏感信息，没有被系统研究过。

方法

利用返回的置信度，反过来推断输入：给定一个人的名字和对人脸识别网络的访问，用梯度方法恢复出可辨认的人脸图像。

影响

表明模型的输出会泄露训练数据的信息，开启了此后成员推断攻击、模型窃取、从LLM提取训练数据等一系列隐私攻击研究。

方法

论文把「模型反演攻击」推广到利用置信度的场景。在两个场景下做了深入实验：一是用在机器学习即服务上的决策树，根据生活方式调查，估计受访者是否承认自己对伴侣不忠；二是人脸识别神经网络，在只知道某人名字并能查询模型的情况下，恢复出能被人辨认的该人的面部图像。

做法大意是：把「找一个输入，使模型对目标类别的置信度最高」当作优化问题，用梯度下降从随机或平均图像出发逐步优化，得到的图像会像训练集里那个人。

作者还尝试了两种对策：一种是隐私感知的决策树训练（CART的简单变体），另一种是只返回取整后的置信度。据摘要，这类攻击可以在效用损失可以忽略的情况下被避免，也就是说，简单的防护措施是有效的。

局限与后续

  • 攻击效果依赖模型返回完整置信度；防护方法只在特定模型上做了试验，没有普适的隐私保证。

  • 恢复出的图像是否等同于「训练集中的真实样本」存在争议，只能说明模型对这个类别学到了什么。
