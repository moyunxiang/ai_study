IRASim机器人动作世界模型

IRASim: Learning Interactive Real-Robot Action Simulators
2024.06论文延伸ICCV 2025Fangqi Zhu, Hongtao Wu, Song Guo, Yuxiao Liu, Chilam Cheang, Tao Kong · 字节跳动、香港科技大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用视频生成模型当机器人的世界模型时，生成的画面往往和每一步动作对不齐，夹爪和物体的精细接触细节也画不准。

方法

训练一个扩散Transformer，以历史画面和机器人动作轨迹为条件生成未来视频，并在每个Transformer块里加一个逐帧的动作条件模块，让每一帧都和对应的动作严格对齐。

影响

把动作条件视频模型做到了能看清夹爪与物体接触的精度，并展示了它可用于策略评测和测试时规划。

方法

UniSim等工作展示了用视频生成模型模拟“机器人做了这个动作之后画面会怎样”，但它们通常把整段动作当作一个整体条件，忽略了动作与帧的一一对应，结果是机械臂动作和画面对不上。IRASim基于Diffusion Transformer（扩散Transformer），输入历史观测和一段动作轨迹，生成未来的视频；关键改动是在每个Transformer块里加入帧级的动作条件模块，把第t步动作专门注入第t帧，显式强化动作与帧的对齐。

摘要列出四点结果：生成视频的质量超过所有基线，并随模型规模和计算量有效提升；用IRASim评测策略，结果与用真值仿真器评测高度相关，有望加速真机策略评测；用IRASim做基于模型的规划（测试时扩展）能显著提升策略表现，Push-T基准上的IoU从0.637提升到0.961；还可以用键盘或VR手柄直接操控数据集里的虚拟机械臂。

局限与后续

  • 生成视频的速度远慢于物理仿真，用来做规划或大规模评测的计算成本高。
