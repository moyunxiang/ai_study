Contriever无监督检索

Unsupervised Dense Information Retrieval with Contrastive Learning
2021.12论文延伸TMLR 2022Gautier Izacard, Mathilde Caron, Lucas Hosseini, Sebastian Riedel, Piotr Bojanowski, Armand Joulin, Edouard Grave · Meta AI / UCL / Inria待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

稠密检索器需要大量标注才能训好，换到没有标注的新领域时，甚至不如BM25。

方法

不用任何标注，在无标签文本上用对比学习预训练检索器：同一文档里随机裁出的两段互为正例，其余为负例。

影响

首次让纯无监督稠密检索在多数数据集上超过BM25，并成为后续检索预训练的常用起点。

方法

沿用稠密检索DPR的双编码器，但正例不再是标注的问答对，而是从同一文档中随机裁剪出的两个片段（类似视觉里的MoCo对同一图像做两次裁剪）；负例来自批内其他文档，并借鉴MoCo维护一个动量编码器和大规模负样本队列。

摘要称在BEIR基准上，无监督模型的Recall@100在15个数据集中的11个上超过BM25；若再用少量领域内数据或MS MARCO微调，还会更好，并能做多语言和跨语言检索。

后来的发展

Atlas检索增强少样本用它作检索器；HyDE假设文档检索用它把假设文档编码成向量；之后的E5文本嵌入、BGE嵌入模型等嵌入模型沿用大规模弱监督对比预训练。

局限与后续

  • 无监督模型在需要精确匹配稀有词的场景仍可能输给BM25。

    后来针对它的工作　E5文本嵌入 BGE嵌入模型

它建立在什么之上

  • 延续
    稠密检索DPR2020.04 · 推理·智能体 已核对
    保留双编码器，但去掉对标注问答对的依赖，改用无监督对比预训练。
  • 改进
    BM251994 · NLP
    仍然只认字面相同的词，查询与文档用词不同（同义词、改写）就检索不到。
  • 改进
    FAISS向量检索2017.02 · 推理·智能体
    它只负责“在向量里找近邻”，检索质量完全取决于向量本身是否表达了语义；当时还没有好用的文本检索向量。
  • 改进
    Sentence-BERT2019.08 · NLP
    需要NLI这类人工标注的句对来微调，没有标注数据的领域和语言难以训练。
  • 使用
    MoCo2019.11 · 视觉
    借用MoCo的动量编码器与负样本队列来训练检索器。
  • 改进
    ColBERT后期交互2020.04 · 推理·智能体
    训练只用MS MARCO上BM25挖出的负例，跨领域、跨语言的效果没有验证。
  • 改进
    BERT重排序2019.01 · 推理·智能体
    需要大量相关性标注（如MS MARCO）微调，换领域效果不稳。
  • 改进
    BEIR零样本检索2021.04 · 数据·评测
    稠密检索在新领域上不如BM25的问题，在论文中只是被揭示，没有给出解决办法。
  • 改进
    SPLADE学习式稀疏检索2021.07 · 推理·智能体
    训练依赖MS MARCO类标注，换领域泛化有限。
