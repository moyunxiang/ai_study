手机NPU：麒麟970与A11

2017.09硬件延伸华为 · 苹果 · 寒武纪待核对
维基百科：Apple A11 ↗在交互版中打开（演化树、学习进度）

问题

手机上做人脸识别、拍照增强等推理，用CPU太慢太耗电，用GPU又占用图形资源，端侧需要常驻的低功耗推理单元。

方法

2017年9月前后，华为麒麟970集成专用神经网络处理单元（NPU），苹果A11 Bionic集成Neural Engine，把神经网络推理做成手机SoC里的固定模块。

影响

‘手机SoC里必有一块NPU’从此成为行业标配，此后的Apple M1与统一内存、Copilot+ PC与NPU都把NPU带到了电脑上。

方法

按维基百科，苹果A11 Bionic用于2017年9月12日发布的iPhone 8和iPhone X，由TSMC制造，是六核CPU。同一时期，华为麒麟970也在2017年下半年发布，其NPU据称采用寒武纪成立的IP（这两款芯片的NPU算力数字本次未核对，因此不写）。

共同的设计要点是：神经网络推理主要是大量低精度乘加，用专用的乘加阵列加片上缓存，比通用CPU核更省电；它们服务于固定的应用，如Face ID、拍照场景识别，而不是训练。这一做法直接继承了DianNao神经网络加速器一类学术加速器的思路。

后来的发展

之后每一代手机芯片都在加大NPU的算力；2020年的Apple M1与统一内存把同样的Neural Engine放进了笔记本和台式机芯片。

局限与后续

  • 端侧NPU的算力和内存带宽很小，只能运行小模型，大模型要放在云端。

  • 各厂商NPU各用各的软件接口，开发者要分别适配。
