Retrofitting词向量改装

Retrofitting Word Vectors to Semantic Lexicons
2014.11论文延伸NAACL 2015Manaal Faruqui, Jesse Dodge, Sujay K. Jauhar, Chris Dyer, Eduard Hovy, Noah A. Smith · 卡内基梅隆大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

从大语料共现统计学到的词向量包含很多语义信息，却完全没有用到WordNet、FrameNet、PPDB这些人工整理的语义词典；此前把词典信息融入词向量的方法要改动特定模型的训练过程。

方法

把词典看作一张图（相关的词之间连边），在训练好的词向量上做一步后处理：让每个词的新向量既接近它原来的向量，又接近图上邻居的新向量，用简单的迭代平均求解，适用于任何来源的词向量。

影响

在多种语言、多种词向量和多项词汇语义任务上都有提升，10万词的图只要约5秒；之后专门把词向量往语义约束上拉的「后处理专门化」一类方法（如counter-fitting、ConceptNet Numberbatch）都由此出发。

方法

word2vec、GloVe等方法只看语料中的共现，因此反义词（热/冷常出现在相同上下文）往往很接近，而同义词如果用法不同又可能离得远。WordNet、FrameNet和释义库PPDB里明确记录了哪些词是同义或相关的。

改装的做法：设原始向量为q̂_i，图的边集为E，求新向量Q使目标Ψ(Q) = Σ_i [ α_i‖q_i − q̂_i‖² + Σ_(i,j)∈E β_ij‖q_i − q_j‖² ]最小，第一项让新向量不要离原始向量太远，第二项让相连的词彼此靠近。目标是凸的，可以逐个词用闭式更新q_i = (Σ_j β_ij q_j + α_i q̂_i) / (Σ_j β_ij + α_i)，即「邻居新向量与自己原向量的加权平均」，实践中迭代10次就收敛。论文把α都设为1、β设为该词度数的倒数。

实验对GloVe、skip-gram、全局上下文向量和多语言向量分别用PPDB、WordNet同义词、WordNet全部关系和FrameNet改装，在词相似度、同义词选择、类比和情感分析等任务上比较。总体上PPDB带来提升的次数最多，WordNet全部关系紧随其后，FrameNet较弱；句法类比任务几乎没有提升，作者认为原因是改装加入的是语义信息。整个过程在10万词、300维的图上约5秒。

局限与后续

  • 只能拉近相关词，无法把反义词推开；同义与相关不加区分，相似度任务上的提升有限。
