SqueezeNet小模型

SqueezeNet: AlexNet-level accuracy with 50x fewer parameters and <0.5MB model size
2016.02论文延伸Forrest N. Iandola, Song Han, Matthew W. Moskewicz, Khalid Ashraf, William J. Dally, Kurt Keutzer · 加州大学伯克利分校 / 斯坦福大学 / DeepScale待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

2015年前后的卷积网络研究几乎只追求精度。AlexNet有约6000万参数、模型两百多MB，分布式训练时通信量大，往汽车或嵌入式设备上下发和部署都很吃力。

方法

换个目标：在保持AlexNet级精度的前提下尽量减少参数。主要手段是大量用1×1卷积代替3×3卷积、先用1×1“挤压”层减少输入通道再“扩展”，并把下采样推迟到网络后部。

影响

SqueezeNet以少50倍的参数达到AlexNet级的ImageNet精度，再配合压缩可小到0.5MB以内，是最早专门为小模型设计的卷积架构之一，引出了之后MobileNet、ShuffleNet等轻量网络的研究潮流。

方法

作者给出三条设计策略：

  • 用1×1卷积替换3×3卷积：1×1卷积的参数是3×3的1/9。
  • 减少送进3×3卷积的输入通道数：3×3层的参数量 = 输入通道 × 输出通道 × 9，输入通道少了参数就少。
  • 推迟下采样：让前面的层保持较大的特征图，作者认为这样在参数受限时有助于精度。

前两条落实为Fire模块：先是一个只有1×1卷积的“squeeze”层，把通道数压下来；接着是“expand”层，由一组1×1卷积和一组3×3卷积并联，输出拼接在一起。squeeze层的通道数小于expand层，起到瓶颈作用。整个SqueezeNet由一个普通卷积层、8个Fire模块和最后一个卷积层组成，最后用全局平均池化代替全连接层（借鉴Network In Network），全连接层原本占了AlexNet大部分参数。

摘要称SqueezeNet在ImageNet上以少50倍的参数达到AlexNet级精度；再用剪枝与量化压缩等模型压缩技术，可以压到不到0.5MB，比AlexNet小510倍。作者还指出小模型的三个好处：分布式训练通信更少、向汽车等终端下发模型带宽更低、更容易部署到FPGA等内存有限的硬件上。

后来的发展

SqueezeNet把“参数效率”变成了架构设计的显式目标。之后的MobileNet用深度可分离卷积、ShuffleNet用分组卷积和通道洗牌，在计算量（而不仅是参数量）上进一步优化，成为移动端的主流选择。

局限与后续

  • 只压缩参数量，没有减少计算量和延迟，在手机上的实际速度并不比AlexNet快多少。

读懂它需要的概念

卷积层、池化与感受野 参数量、计算量与显存 图像作为张量 量化

本篇术语

  • 1×1卷积　只在每个像素位置混合通道、不看邻域的卷积，常用来改变通道数。

怎么学

先会算一个卷积层的参数量，再读SqueezeNet第3节的三条策略和Fire模块；用torchvision加载SqueezeNet和AlexNet，打印两者的参数量和模型文件大小做对比。
