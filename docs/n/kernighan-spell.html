噪声信道拼写纠错

A Spelling Correction Program Based on a Noisy Channel Model
1990.08论文延伸COLING 1990Mark D. Kernighan, Kenneth W. Church, William A. Gale · AT&T贝尔实验室待核对
ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

Unix的spell之类拼写检查器只会指出「这个词不在词典里」，至于该改成哪个词，靠手写规则列出所有编辑距离为1的候选，无法判断哪个候选最可能。

方法

把拼写错误看成一个噪声信道：作者想写正确词 c，经过「手误」变成了错词 t。纠错就是找 ĉ = argmax_c P(c)·P(t|c)：P(c) 来自语料中词的频率，P(t|c) 来自从真实错误中统计出的四张「混淆矩阵」（删除、插入、替换、相邻换位）。

影响

这是把噪声信道模型用于拼写纠错的代表性工作，SLP等教材讲拼写纠错时都以它为例；其「语言模型先验 × 错误模型似然」的框架一直沿用到神经时代。

背景

1960年代Damerau统计发现，八成以上的拼写错误是单个字母的删除、插入、替换或相邻两个字母换位。早期纠错程序据此对非词错误生成所有一步编辑可达的词典词作为候选，但遇到多个候选（acress可以是actress、across、acres……）只能随意排序。同时期，IBM的噪声信道翻译模型把翻译也写成噪声信道问题，贝叶斯式的「先验×信道」思路开始在语言处理里流行。

方法

候选生成。 对一个不在词典里的词 t，找出所有经过一次删除、插入、替换或相邻换位能得到 t 的词典词 c。

打分。 按贝叶斯公式

ĉ = argmax_c P(c) · P(t | c)

  • 先验 P(c)：词 c 在大语料（美联社新闻）中的频率，加了平滑处理没见过的词；
  • 信道模型 P(t | c)：只看那一步编辑。例如若 c 到 t 是把字母x替换成y，则 P(t|c) = sub[x,y] / count[y]，sub[x,y] 是在真实错误语料中把y误打成x的次数。删除、插入、换位各有一张类似的混淆矩阵，它们的条目由错误数据用迭代重估的办法统计。

程序最后给出排好序的候选并附上概率，供用户确认。

结果

具体数字未核对。论文用美联社新闻中的错误样例评测，把系统选择与人工判断比较；教材常以acress为例说明该方法能按概率排出actress、cress、caress、access、across、acres等候选。

后来的发展

SLP第三版仍用这个模型讲拼写纠错与编辑距离。后续改进包括Brill & Moore（2000）允许任意子串替换的错误模型、用上下文n-gram语言模型处理「真词错误」（把their写成there），再到神经网络和预训练模型做的检测-纠正框架（如中文里的Soft-Masked BERT中文纠错），基本都保留了「错误模型+语言模型」两部分。
