MBPO

When to Trust Your Model: Model-Based Policy Optimization
2019.06论文延伸NeurIPS 2019Janner, Fu, Zhang, Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

基于模型的方法用模型生成数据能省样本，但模型有误差，长轨迹上误差累积，常使最终性能不如无模型方法。

方法

只用模型从真实数据状态出发做很短的分支展开（几步），再用SAC训练，兼得样本效率和渐近性能。

影响

成为连续控制中最常用的基于模型的基线之一。

方法

论文先给出一个带单调改进保证的理论分析：它的结论过于悲观，说明用模型数据永远不如真实数据。再引入对模型泛化误差的经验估计，说明在模型误差较小的范围内使用模型是合理的，从而推出：从真实回放缓冲里取出的状态出发，只用模型向前展开k步（k很小），把这些短轨迹放入训练池，用SAC做策略更新。

摘要称它在样本效率上超过先前的基于模型方法，渐近性能与最好的无模型方法相当，并能扩展到让其他基于模型方法完全失败的长时域。

局限与后续

  • 展开步数k需要手选，不同任务最优值不一样。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 只在低维状态的连续控制上验证，高维像素观测没有解决。

它建立在什么之上

  • 改进
    PPO2017.07 · RL 已核对
    on-policy，每批数据用几轮就丢，样本效率远低于离策略方法，真实机器人上难以直接训练。
  • 改进
    World Models2018.03 · 具身·世界模型 已核对
    控制器会钻世界模型的漏洞（比如梦里怪物不开火），必须手动调温度τ来平衡真实性与可利用性。
  • 改进
    Dyna：学习与规划合一1990 · RL
    是Dyna思想在深度网络下的现代版本：用模型生成的经验训练策略。
  • 改进
    PILCO2011 · RL
    假设动力学平滑、状态分布能用高斯近似，对接触等不连续动力学不合适。
  • 改进
    随机价值梯度SVG2015.10 · RL
    模型展开步数越多，梯度方差和模型偏差越难控制，SVG(∞)在复杂任务上不稳定。
  • 使用
    SAC2018.01 · RL
    底层策略学习用SAC。
  • 改进
    ME-TRPO模型集成2018.02 · RL
    在模型里想象长轨迹，误差随步数累积，渐近性能仍明显落后于无模型方法。
  • 延续
    PETS概率集成模型2018.05 · RL
    沿用PETS的概率集成模型，但把模型用于生成短轨迹训练策略而非在线规划。
  • 改进
    STEVE集成价值扩展2018.07 · RL
    需要同时训练模型、奖励和Q函数三组集成，计算和实现开销都比无模型方法大得多。

后来的相关工作

  • 改进
    Dreamer2019.12 · 具身·世界模型
    只在低维状态的连续控制上验证，高维像素观测没有解决。
  • 延续
    MBRL目标错配2020.02 · RL
    针对MBPO等主流MBRL共享的“先按似然学模型再使用”的框架，指出其根本限制。
  • 延续
    MOPO模型离线优化2020.05 · RL
    沿用MBPO的短程模型展开加SAC训练，在奖励里加入不确定度惩罚以适应离线设定。
  • 延续
    MOReL悲观模型离线RL2020.05 · RL
    沿用学动力学模型、在模型中优化策略的框架，并加入悲观性以适应离线设定。
  • 竞争
    REDQ随机集成双Q2021.01 · RL
    MBPO靠学到的模型实现高UTD；REDQ证明不学模型也能达到相近的样本效率。
  • 使用
    COMBO保守模型离线优化2021.02 · RL
    沿用从数据状态出发做短步模型展开来扩充训练数据的做法。
  • 使用
    RAMBO对抗模型离线RL2022.04 · RL
    沿用MBPO用模型生成短虚拟轨迹训练SAC的框架。
  • 使用
    iVideoGPT交互视频世界模型2024.05 · 具身·世界模型
    把预训练后微调的模型当作MBPO的环境模型，用想象轨迹扩充DrQ-v2的训练数据。
  • 延续
    VLA-MBPO2026.03 · 具身·世界模型
    沿用MBPO从真实状态出发做短分支想象的思路，扩展到动作块级别和像素级多视角世界模型。
