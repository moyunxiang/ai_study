Visual Genome

Visual Genome: Connecting Language and Vision Using Crowdsourced Dense Image Annotations
2016.02数据集延伸IJCV 2017 / arXiv 2016Krishna, Zhu, Groth, Johnson, Hata, Kravitz, Chen, Kalantidis, Li, Shamma, Bernstein, Fei-Fei · Stanford 等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

ImageNet 和 COCO 教会模型『认出物体』，但描述图像、回答问题需要理解物体之间的关系，现有数据缺少对关系的密集标注。

方法

众包标注每张图中的区域描述、物体、属性、物体间关系和问答，并把它们组织成场景图（scene graph）。

影响

给视觉问答、场景图生成和视觉-语言预训练提供了关系与区域级的监督，后续 GQA、许多多模态模型都用它做数据来源。

方法

Visual Genome 的出发点是：回答『这个人骑着什么交通工具？』既要识别人和车，也要知道 riding(man, carriage)、pulling(horse, carriage) 这样的关系。为此它在每张图上用众包收集多层标注：区域描述（一句话描述图中某个区域）、物体及其边界框、属性、物体之间的关系，以及问答对，并把物体名称、关系、属性映射到 WordNet，使标注可以统一。

场景图是一种用节点表示物体、用边表示关系的结构化描述。它让模型的训练信号从『整张图一句话』变成『每个物体、每条关系都有标注』，GQA 就用它自动生成了大量需要推理的问题。

局限与后续

  • 众包标注的关系和属性词汇杂乱、长尾严重，同一概念有大量不同说法，需要后续清洗。
    后来针对它的工作　GQA
  • 标注的是静态的图像，对于需要常识或知识的问题并不够。
    本站还没有记录针对它的后续工作（不代表没有人解决）
