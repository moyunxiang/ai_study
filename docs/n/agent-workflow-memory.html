AWM工作流记忆

Agent Workflow Memory
2024.09论文延伸ICML 2025Zora Zhiruo Wang, Jiayuan Mao, Daniel Fried, Graham Neubig · 卡内基梅隆大学 / MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

网页智能体做长程任务时步骤又多又复杂，每个任务都从头摸索；而人会把以前做过的事总结成可复用的套路，下次直接照着做。

方法

从过往经验中归纳出常用的“工作流”（去掉具体值、保留步骤骨架的例行程序），存进记忆，按需挑选相关的工作流放进提示，指导后续操作。

影响

在Mind2Web和WebArena上分别带来24.6%和51.1%的相对成功率提升，把“记忆存技能套路而不是存原始轨迹”的思路带进网页智能体，是智能体程序性记忆的代表工作之一。

方法

AWM的核心是工作流归纳：给定一些成功完成的任务轨迹，让LLM把其中反复出现的子流程抽象出来。比如“在购物网站搜索某商品并加入购物车”，会被写成一段带占位符的步骤序列：点击搜索框、输入{商品名}、点击第一个结果、点击加入购物车。具体的商品名被替换成变量，只保留可迁移的骨架。

归纳出的工作流存进智能体的记忆。之后遇到新任务时，把相关的工作流放进提示，智能体照着套路行动，必要时再调整。两种用法：

  • 离线：先从训练样本里归纳好工作流，测试时直接用；
  • 在线：没有训练数据，智能体每完成一个测试任务、经自我评估判为成功，就从中归纳新的工作流加入记忆，边做边学。

实验在Mind2Web和WebArena两个网页导航基准上进行，合计覆盖200多个领域的1000多个任务。AWM把基线的相对成功率分别提升24.6%和51.1%，并减少了在WebArena上成功完成任务所需的步数；在跨任务、跨网站、跨领域的评测中，在线AWM随训练与测试分布差距变大，领先基线8.9到14.0个百分点。它延续了Voyager存技能代码、ExpeL经验学习智能体存经验规则的思路，把记忆的单位换成了可复用的操作流程。
