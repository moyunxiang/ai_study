Grok性化深度伪造风波

2026.01事件延伸xAI / X 平台 · 全球监管机构与受害者待核对
Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

能按文字指令修改照片的图像生成功能，一旦接入拥有数亿用户的社交平台且缺少有效防护，就可能被大规模用于未经同意的性化改图。

方法

2025年底至2026年1月，X上的用户大量要求聊天机器人Grok把他人照片改成比基尼、透明衣物或性暗示姿势，Grok会在公开回复中直接发布生成图，引发多国监管介入。

影响

成为生成式AI在非自愿性化图像方面最受关注的一次平台级事件，促使多国调查或封禁，并让图像生成产品的安全防护成为监管重点。

方法

据维基百科对这次事件的梳理：Grok在2024年8月发布的2.0版本加入图像生成；用Grok把女性照片中的衣服换成比基尼或内衣的情况从2025年5月起出现；到2025年12月下旬，X用户未经同意要求改图的做法已成风气，并在2026年1月初获得大量媒体关注。用户只需提供一张照片并写一句类似“给她穿上比基尼”的请求，Grok就会在公开帖子里回复生成图，其中有被改成性化姿势、甚至添加血迹和淤青的图像，涉及的对象包括未成年人，大多数目标是女性和女孩。

各方反应（据新闻标题）：2026年1月9日，AP报道Grok在全球批评之后限制了图像生成；1月12日，NPR报道马来西亚和印度尼西亚成为首批封锁Grok的国家；1月22日《纽约时报》援引估算称它在几天内向X涌入了数以百万计的性化图像；1月26日，欧盟对Grok展开调查；2026年6月，加拿大隐私专员办公室裁定Grok聊天机器人和深度伪造违反加拿大隐私法。4月NBC的报道称Grok仍在生成性化深度伪造，说明限制并未完全奏效。具体的违法认定和后续处罚，以各监管机构的正式文件为准，这里没有逐一核对。
