Agent S

Agent S: An Open Agentic Framework that Uses Computers Like a Human
2024.10论文延伸Saaket Agashe, Jiuzhou Han, Shuyu Gan, Jiachen Yang, Ang Li, Xin Eric Wang · Simular Research待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

用多模态大模型操作电脑界面有三个难点：不了解具体软件的知识、长任务难以规划、界面五花八门不统一。

方法

经验增强的分层规划：向外检索网络知识、向内检索过往经验，并设计专门的智能体-电脑接口(ACI)，让模型更好地观察和控制界面。

影响

在OSWorld上刷新当时最好成绩，是早期开源电脑智能体框架的代表。

方法

Agent S用一个管理者模块把任务拆成子任务，再由执行者模块逐个完成，这就是「分层规划」。规划时有两类检索：外部知识来自联网搜索（比如某个软件怎么导出PDF），内部经验来自记忆库，里面存着过去完成任务的完整轨迹和子任务经验总结，遇到相似任务时直接参考。

另一半贡献是Agent-Computer Interface：它不是让模型直接输出像素坐标，而是给界面元素提供带标注的观察，并把动作限制为一组定义良好的原语，让模型的推理和控制更稳定（思路类似SWE-agent对命令行做的ACI）。论文报告在OSWorld上比基线高9.37个百分点（相对提升83.6%），并在新发布的WindowsAgentArena上也有效。

后来的发展

它的框架思想被后续版本延续，也被Browser Use等开源项目借鉴；随后Computer Use与Operator与浏览器智能体把电脑操作能力放进了模型本身。

局限与后续

  • 每一步依赖外部搜索和多个模块调用，延迟和成本较高。
