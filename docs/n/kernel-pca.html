核主成分分析

Nonlinear Component Analysis as a Kernel Eigenvalue Problem
1998.07论文延伸Neural Computation 10(5), 1998Bernhard Schölkopf, Alexander Smola, Klaus-Robert Müller · GMD FIRST（柏林）等待核对
Neural Computation（DOI） ↗Wikipedia: Kernel principal component analysis ↗在交互版中打开（演化树、学习进度）

问题

主成分分析PCA只能找线性的主方向，数据如果沿着弯曲的结构分布（比如同心圆），线性投影分不开、压不好。

方法

借核技巧与最优间隔分类器：先想象把数据映射到一个很高维的特征空间，在那里做PCA；整个计算只需要样本两两之间的核函数值，最后变成一个n×n核矩阵的特征值问题。

影响

把核方法从分类推广到无监督降维，是“任何只依赖内积的线性算法都能核化”这一思路的代表作，也是后来流形学习方法常被比较的对象。

方法

PCA求的是协方差矩阵的特征向量。设有映射φ把输入x送到高维特征空间，在那里的协方差矩阵是 C = (1/n) Σ φ(x_i) φ(x_i)ᵀ。直接计算不可行，因为特征空间可能有几百万维甚至无穷维，例如论文举的例子是16×16图像中所有五个像素乘积构成的空间。

作者的观察是：C的特征向量一定落在φ(x₁)…φ(x_n)张成的子空间里，可以写成 v = Σ α_i φ(x_i)。代入特征方程后，只剩下核矩阵 K_ij = k(x_i, x_j) = φ(x_i)·φ(x_j)，问题化为 n λ α = K α，即n×n矩阵K的特征值问题（还要对K做中心化）。新样本在第k个主成分上的投影同样只需要它与训练样本的核值：Σ α_i^k k(x_i, x)。核可以选多项式核、高斯核等，不同的核对应不同的非线性特征。

论文给出推导，并在模式识别任务上用多项式核提取的非线性主成分作为特征做实验。

局限与后续

  • 需要存储并分解n×n的核矩阵，样本数一大，内存和计算（约n³）都无法承受。
