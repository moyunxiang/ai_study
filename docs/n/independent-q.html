独立Q学习多智能体

Multi-Agent Reinforcement Learning: Independent vs. Cooperative Agents
1993论文延伸ICML 1993Ming Tan · GTE Laboratories待核对
ICML 1993（网站首页，未取得具体文章链接） ↗在交互版中打开（演化树、学习进度）

问题

多个智能体要在同一环境里合作，直接套用单智能体强化学习是否可行，各自学和共同学有多大差别。

方法

让每个智能体独立运行自己的Q学习，把别的智能体当作环境的一部分，并比较共享感知、共享策略、共享经验三种合作方式。

影响

多智能体强化学习的基线方法，今天仍然是最常见的对照（IQL）。

方法

实验场景是猎人追捕猎物：多个猎人各自用Q-learning学习如何追赶，并与独立学习的方式对比。比较了几种合作：互相告诉对方当前所见（共享感知）、共享学到的策略、共享学习过的经验片段。结论是合作通常能学得更快、效果更好，但代价是通信与协调的开销。

独立Q学习实现简单、能扩展到很多个体，是多智能体的最简基线，它的缺点在于：别的智能体也在学习，环境对每个个体来说在不断变化，不再是固定的MDP。

后来的发展

MADDPG用集中训练解决这个非平稳问题，QMIX值分解在合作任务里把联合价值分解开。

局限与后续

  • 别的智能体在学习，环境对单个智能体是非平稳的，Q学习的收敛保证失效。

它建立在什么之上

  • 使用
    Q-learning1992 · RL
    每个智能体独立运行一份Q学习。

后来的相关工作

  • 改进
    MADDPG2017.06 · RL
    独立学习者把其他智能体当作环境，环境因而非平稳；集中式critic显式输入他人的动作，恢复了平稳性。
  • 改进
    PSRO博弈论元求解2017.11 · RL
    用JPC量化了独立学习对训练对手的过拟合，并用对种群混合做最佳响应的方式把这种过拟合显著降低。
  • 改进
    QMIX值分解2018.03 · RL
    独立Q学习不稳定、无法分配团队奖励；QMIX通过混合网络集中训练，用团队TD误差把功劳回传给每个智能体。
  • 改进
    WoLF可变学习率2002.04 · RL
    独立Q学习只学确定性策略，在只有混合均衡的博弈里震荡；WoLF-PHC学混合策略并用可变学习率促成收敛。
  • 延续
    DIAL/RIAL学习通信2016.05 · RL
    RIAL就是在独立Q学习上把消息也当动作；DIAL则让梯度跨智能体流动，突破了“各学各的”。
  • 改进
    CommNet可微通信2016.05 · RL
    独立学习的智能体互相看不到对方状态；CommNet让每个智能体每层都收到同伴隐状态的平均，从而能协调动作。
  • 延续
    序贯社会困境SSD2017.02 · RL
    沿用独立学习的设定，但把关注点从“能否学好”转向“学出的行为是合作还是冲突”。
  • 改进
    COMA反事实策略梯度2017.05 · RL
    独立学习者把队友当环境噪声；COMA用集中式评论家和反事实基线给出每个智能体自己的学习信号。
  • 改进
    VDN值分解网络2017.06 · RL
    独立Q学习受虚假奖励困扰；VDN用可加分解让每个智能体的Q值只为团队奖励中可归于自己的部分负责。
  • 改进
    LOLA对手学习感知2017.09 · RL
    独立学习把对手当静态环境，在社会困境里学成双输；LOLA把对手的学习纳入考虑，学出合作。
  • 使用
    MAgent百万智能体平台2017.12 · RL
    大量智能体各自做Q学习、共享参数，本质上是规模化的独立学习者。
  • 延续
    QTRAN变换分解2019.05 · RL
    执行时仍然是每个智能体按自己的Q值独立贪心，但训练时用联合Q值保证这种独立执行不失最优。
  • 延续
    Other-Play零样本协作2020.03 · RL
    合作多智能体学习中各自训练的智能体会形成各自的约定，Other-Play针对的就是这一问题在零样本场景下的版本。
  • 延续
    IPPO独立PPO2020.11 · RL
    沿用独立学习的思路，但把独立的Q学习换成独立的PPO，避开了回放数据过时的问题。
  • 改进
    MAPPO2021.03 · RL
    只在很小的网格世界里验证。
