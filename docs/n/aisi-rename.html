AISI从Safety转向Security

2025.02事件延伸英国科学、创新与技术部 · AI Security Institute待核对
维基百科 ↗在交互版中打开（演化树、学习进度）

问题

英国AI安全研究所2023年底成立，职责是评测前沿模型的安全；到2025年，政府更强调国家安全和经济增长。

方法

2025年2月研究所更名为AI安全保障研究所（AI Security Institute），重心转向网络、犯罪、化学生物等“安全”（security）风险，淡化偏见、言论自由等议题。

影响

成为各国同类机构从“safety”转向“security”的标志，美国对应机构也改名为CAISI。

方法

据维基百科，2025年英国的AI Safety Institute被改名为AI Security Institute，美国的对应机构改为Center for AI Standards and Innovation（CAISI）。Google News上有Americans for Responsible Innovation于2025年2月13日的报道，标题为“UK Renames AI Institute Following Paris Summit”，说明改名紧随巴黎AI行动峰会。

改名反映的是关注重点的变化：由广义的模型安全，转向对国家安全有直接意义的风险。研究所仍继续开发并开源评测工具，如Inspect评测框架。具体新职责清单和官方声明措辞，本次未能核对一手文件。

局限与后续

  • “security”框架下，偏见、社会影响等议题不再是重点，对这类风险的评测责任由谁承担没有明确。
