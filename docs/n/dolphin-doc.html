Dolphin先分析后解析

Dolphin: Document Image Parsing via Heterogeneous Anchor Prompting
2025.05论文延伸ACL 2025Hao Feng, Shu Wei, Xiang Fei, Wei Shi, Yingdong Han, Lei Liao, Jinghui Lu, Can Huang et al. · 字节跳动待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

文档图像里段落、图、公式、表格交织；拼装专家模型的方案集成开销大，直接逐页自回归生成整页内容的方案又慢，还会破坏版面结构。

方法

先分析后解析：第一阶段按阅读顺序生成版面元素序列；第二阶段把每个元素作为锚点，配上该元素类型的专用提示，并行地解析各元素内容。

影响

在常用和自建基准上的页面级、元素级解析任务中都达到最好，并因并行解析而效率更高。

方法

文档解析要把一页PDF或扫描件转成结构化文本。MinerU文档解析等流水线方案先做版面检测，再把不同元素交给不同的专家模型（OCR、公式识别、表格识别）；Nougat学术文档、GOT-OCR 2.0式的端到端模型则一口气生成整页内容，页面一长就慢，且容易打乱结构。

Dolphin（Document Image Parsing via Heterogeneous Anchor Prompting）用同一个视觉-语言模型分两步完成。第一步“分析”：输入整页图像，模型按阅读顺序输出版面元素的序列，每个元素带类型（文本段落、表格、公式、图等）和位置框。第二步“解析”：把这些异构元素作为锚点，裁出对应区域，并为每类元素配一个任务专用的提示（如“把表格解析成HTML”“识别公式为LaTeX”），交回同一个模型并行生成各元素的内容，最后按阅读顺序拼回整页。为训练它，作者构建了超过3000万样本的大规模数据集，覆盖多种粒度的解析任务。

摘要称Dolphin在常用基准和自建基准上，在多种页面级与元素级设置中都取得最好成绩，并兼顾效率。
