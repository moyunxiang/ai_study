SuperMimic可微世界模型

SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model
2026.10论文延伸CoRL 2026Qiayuan Liao, Yiyang Shao, Junfeng Long, Kevin Zakka, Roberto Horowitz, Pieter Abbeel, Koushil Sreenath · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

跟踪大规模人类动作数据训练人形全身控制，要么把一堆单动作专家蒸馏到一起（有损），要么用集群级算力硬训一个策略，成本极高。

方法

从普通刚体仿真器的日志里拟合一个所有动作共享的可微世界模型，策略在模型里做短程想象，对整段想象轨迹做时间反向传播得到解析梯度。

影响

单卡3小时超过需128卡训练7天的SOTA动作跟踪器，GPU小时减少1000倍以上，真机迁移到Unitree G1；据报道获CoRL 2026最佳论文奖。

方法

通用人形全身控制的主流做法，是让一个策略在仿真里跟踪数十万段人类动作（DeepMimic的思路做大），例如SONIC大规模动作跟踪用大规模集群训练。这些方法是无模型强化学习，样本效率低。

SuperMimic的做法类似Dreamer：交替进行“仿真器采数据 → 拟合世界模型 → 改进策略”。不同在于世界模型是对刚体仿真器动力学的可微近似，策略通过冻结的世界模型做短程想象，再沿时间反向传播，直接得到动作对回报的解析梯度，不用策略梯度估计。论文报告：单GPU训练3小时，回报超过一个在128块GPU上训练7天的SOTA跟踪基线；在129514段基准动作中只失败25段（基线179段），两块GPU训练9.8小时后零失败；动作数据从1小时扩到264小时，世界模型预测误差保持稳定。策略可迁移到真机Unitree G1，完成多种杂技动作。

局限与后续

  • 与SONIC的比较在硬件和数据上并不完全对等（使用约265小时动作数据，SONIC约611小时）。

它建立在什么之上

  • 延续
    DeepMimic2018.04 · 具身·世界模型
    任务仍是跟踪人类参考动作，训练方式从无模型RL换成基于模型的解析梯度。
  • 延续
    Dreamer2019.12 · 具身·世界模型
    沿用在学到的模型里想象并反向传播价值的思路，用到人形全身控制上。
  • 竞争
    BeyondMimic2025.08 · 具身·世界模型
    同一实验室同一问题的不同方案：BeyondMimic走动作跟踪加引导扩散，SuperMimic走可微世界模型。
  • 改进
    SONIC大规模动作跟踪2025.11 · 具身·世界模型
    SONIC靠集群级算力训练通用动作跟踪，SuperMimic用可微世界模型把算力降低三个数量级。
