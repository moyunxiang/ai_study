ZSON零样本物体导航

ZSON: Zero-Shot Object-Goal Navigation using Multimodal Goal Embeddings
2022.06论文延伸NeurIPS 2022Arjun Majumdar, Gunjan Aggarwal, Bhavika Devnani, Judy Hoffman, Dhruv Batra · 佐治亚理工学院、Meta AI待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

物体目标导航通常要有该任务的奖励或示范，而且只能找训练时固定的几十类物体，没法说“找浴室的水槽”这种开放描述。

方法

不用任何物体导航的奖励或示范：在图像目标导航任务上训练，但把目标图片编码进CLIP的多模态语义空间；测试时把文字目标投影到同一空间，就能找任意语言描述的物体。

影响

在Gibson、HM3D、MP3D三个物体导航数据集上，比已有零样本方法的成功率绝对提升4.2%–20.0%，为开放词汇物体导航提供了可扩展的训练方式。

方法

ObjectNav物体目标导航定义的物体导航任务依赖标注好的物体类别，CoW零样本物体导航用现成的视觉语言模型做零样本探索，但不学习导航策略。ZSON的思路是借CLIP把“图像目标”和“语言目标”放进同一个语义空间：先在无标注的三维扫描场景（如HM3D具身导航场景）中大规模训练图像目标导航——给一张在某处拍的照片，让智能体找到拍摄位置——但目标照片不是直接给像素，而是用CLIP的图像编码器编码成语义向量，于是训练的其实是“语义目标导航”。测试时，把“sink”“bathroom sink”这样的自由文本用CLIP的文本编码器投影到同一空间作为目标，智能体就能去找对应物体。整个过程不需要任何物体导航的奖励或示范。

局限与后续

  • 语义嵌入来自CLIP的整图表示，对小物体和细粒度区分较弱，到达目标后的停止判断也不够准。
