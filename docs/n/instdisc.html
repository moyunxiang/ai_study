实例判别InstDisc

Unsupervised Feature Learning via Non-Parametric Instance Discrimination
2018.05论文延伸CVPR 2018Wu, Xiong, Yu, Lin · UC Berkeley / ICSI / CUHK待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

监督学习的特征能反映类别间的视觉相似性，但没有标签时怎么得到类似的特征不清楚。

方法

把每一张图像当作自己的一个类，用非参数的softmax和噪声对比估计，让网络区分各个实例。

影响

提出实例判别这一思路和memory bank，直接引出MoCo、SimCLR等对比学习方法。

方法

想法是：既然监督分类器会把相似类别的图片靠得更近，那就让网络去区分每一张图。若有一百万张图就是一百万个类，普通softmax的权重矩阵放不下，所以作者用非参数形式：为每张图在一个memory bank里存一个128维特征，分类时直接拿当前特征与bank中所有特征算相似度，再做softmax。

分母要对所有一百万项求和，代价太高，于是用噪声对比估计NCE（噪声对比估计）把它近似成只对一部分负样本计算。训练后，用最近邻检索即可做分类。论文称每张图128维特征，百万张图只需约600MB存储。

局限与后续

  • memory bank里的特征是几轮之前的旧特征，与当前网络不一致，训练信号滞后。
    后来针对它的工作　MoCo
  • 负样本只来自bank的一个随机子集，规模与新旧程度难以兼顾。
    后来针对它的工作　SimCLR
