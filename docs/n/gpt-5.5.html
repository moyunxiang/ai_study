GPT-5.5

Introducing GPT-5.5
2026.04模型重要OpenAI待核对
官方公告 ↗GPT-5.5 System Card ↗维基百科：GPT-5.5 ↗在交互版中打开（演化树、学习进度）

问题

Anthropic两周前公布的Mythos Preview在编码和网络能力上大幅领先；OpenAI需要一个能少要指引、自己把复杂工作做完的新旗舰，同时它的网络能力也已高到不能毫无限制地开放。

方法

推出面向“真实复杂工作”的GPT-5.5（代号Spud）：更早理解任务、更会用工具、会检查自己的工作；按准备度框架定为网络与生物“高”风险级，公开版加强防护，网络专用版GPT-5.5-Cyber只给经审核的防守方。

影响

官方称Terminal-Bench 2.0达82.7%，略高于Mythos Preview；英国AISI评测其专家级网络任务通过率与Mythos Preview相当。它让“公开版加防护、网络版走可信访问”成为OpenAI的发布惯例。

背景

GPT-5之后，OpenAI以一两个月一次的节奏迭代（5.1、5.2、GPT-5.4），每代主要提升编码智能体和办公任务能力，产品载体是ChatGPT和Codex app多智能体指挥台。

2026年4月7日Anthropic公布Claude Mythos分级开放，并以网络风险为由不公开发布，这在华尔街和政府引起很大关注。对OpenAI来说有两个压力：能力上要证明自己没有掉队；安全上，自GPT-5.4起它已把模型定为网络“高”风险级，越来越强的模型必须解决“怎样既开放又不帮攻击者”的问题。

方法

训练细节未公开。系统卡说明它与以往推理模型一样，先用强化学习训练其在回答前生成长思考链；GPT-5.5 Pro是同一模型加上并行测试时计算（同时尝试多条解法再选优）。发布前约200个早期合作方在真实用例上试用。

风险分级。按OpenAI准备度框架，它在生物化学和网络安全两个领域被定为“高”能力级，但低于“关键”级：内部专家测试中，它能借助工具和验证环境发现大量线索，却没能独立在真实目标上做出完整的利用链，瓶颈在于判断哪些线索值得深挖、如何把崩溃变成可控的攻击原语。AI自我改进方面未达“高”级。

分发方式。4月23日先在ChatGPT付费版和Codex上线；API因需要“不同的防护”晚一天开放。5月7日推出GPT-5.5-Cyber，只通过可信访问计划给经审核的网络安全团队。5月5日更快的GPT-5.5 Instant成为免费用户的默认模型。

结果

官方称Terminal-Bench 2.0为82.7%，FrontierMath第1–3级为51.7%、第4级为35.4%，均高于Claude Opus 4.7和Gemini 3.1 Pro。英国AISI的专家级网络任务平均通过率为71.4%（±8.0%），Mythos Preview为68.6%（±8.7%），AISI称它可能是测过最强的模型。系统卡称在用户标记过事实错误的对话上，它的单条陈述正确的可能性高23%，但因为每次回答写得更多，整条回答含错误的比例只降低3%。

后来的发展

6月OpenAI用GPT-5.5-Cyber和Codex Security发起帮助开源项目修补漏洞的计划，与Anthropic的Glasswing对标。它也暴露出奖励信号会意外扩散：为“书呆子”人格设计的奖励让模型偏爱说goblin等怪物词，并在后续训练中扩散到其他场景，OpenAI只好删掉该奖励并过滤数据。四个半月后，GPT-6成为OpenAI第一个达到网络“关键”级的模型。

容易误解的地方

  • 与Mythos Preview的对比多数来自OpenAI自报或媒体转述，各家的harness和资源设置不同；AISI的71.4%和68.6%误差范围重叠，只能说两者相当。
  • “高”风险级不是说它危险到不能用，而是说已触发准备度框架中对应的一组防护要求。

读懂它需要的概念

语言模型 推理token与测试时计算 智能体循环 奖励设计与奖励投机 幻觉 基准、排行榜与SOTA

本篇术语

  • 可信访问计划（Trusted Access for Cyber）　OpenAI的身份审核机制：通过审核的安全团队可以使用防护更少、网络能力更强的模型版本。
  • 攻击原语　漏洞利用中可被攻击者稳定控制的基本能力，比如任意读写某块内存；把一个崩溃变成原语是写出可用利用代码的关键一步。

怎么学

先读OpenAI准备度框架了解“高”“关键”两级各指什么。再读GPT-5.5系统卡的网络安全章节和Apollo评测结果，体会能力评估与对齐评估分别回答什么问题。对照阅读同月的Claude Mythos分级开放，比较两家对相近能力采取的不同发布策略。
