UniZero Transformer潜在规划

UniZero: Generalized and Efficient Planning with Scalable Latent World Models
2024.06论文延伸Yuan Pu, Yazhe Niu, Zhenjie Yang, Jiyuan Ren, Hongsheng Li, Yu Liu · 上海人工智能实验室 / 商汤 / 港中文待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

MuZero式方法的潜在模型只看当前一帧编码的状态，靠循环展开做规划，难以处理需要长期记忆的任务，也不容易在多任务、异构场景下扩展。

方法

用Transformer做世界模型：把过去的潜在状态和动作作为序列输入，同时预测下一个潜在状态、奖励、策略和价值，在共享的潜在空间里联合优化长时程世界模型和策略，再在其中做MCTS规划（UniZero）。

影响

把MuZero系从“单帧+循环动力学”推进到“Transformer世界模型+序列历史”，是2024年以来该路线扩展到长记忆和多任务的代表工作之一，集成在LightZero库中。

方法

MuZero的结构是：表示网络把当前观测编码成潜在状态，动力学网络 s_(k+1) = g(s_k, a_k) 一步步展开，预测网络给出策略与价值；规划只依赖当前一帧的编码。作者分析指出，这种设计把历史信息全部压在循环展开里，在需要记住很久以前信息的任务里表现差，而且潜在表示与决策目标之间的耦合方式限制了扩展。

UniZero的改动：

  • Transformer潜在世界模型：把历史上的 (z_1, a_1, z_2, a_2, …, z_t) 作为序列输入一个因果Transformer，在每个位置预测下一个潜在状态、即时奖励以及当前的策略和价值。潜在状态的学习目标是与目标编码器对下一帧观测的编码一致（自监督一致性）；
  • 联合优化：世界模型的预测损失与策略、价值损失在同一个潜在空间里一起训练，作者称这使长时程世界模型与策略能够联合优化；
  • 规划：在这个以历史为条件的潜在模型中做MCTS，搜索时用KV缓存复用已有的上下文。

摘要称UniZero在需要长期记忆的基准上明显超过现有基线；在Atari多任务学习实验中表现出更好的扩展性；在标准单任务的Atari和DMControl上与当前最好方法持平甚至更好。

  • 使用
    Transformer2017.06 · LLM

  • 改进
    MuZero2019.11 · RL
    MuZero只用当前帧编码与循环动力学，长期记忆差；UniZero以历史序列为条件做潜在规划。
  • 延续
    EfficientZero2021.10 · RL
    沿用EfficientZero的自监督一致性损失来学潜在状态。

    TWM Transformer世界模型2023.03 · 具身·世界模型

  • 使用
    LightZero MCTS基准库2023.10 · RL
    在LightZero框架中实现和评测。
