Adadelta

ADADELTA: An Adaptive Learning Rate Method
2012.12论文延伸Matthew D. Zeiler · 纽约大学 / Google待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

AdaGrad把历史梯度平方一直累加，学习率只降不升，训练到后期几乎停滞；而且它和SGD一样需要手动挑一个全局学习率。

方法

只累积最近一段时间的梯度平方（指数滑动平均），并用“最近参数更新量的均方根”代替全局学习率，使更新量与参数有相同的“单位”。

影响

与RMSProp同期提出了用指数滑动平均替代AdaGrad累加的做法，是Adam之前常用的自适应优化器之一，至今仍在主流框架中保留。

方法

AdaGrad给每个参数的学习率除以该参数历史梯度平方和的平方根，梯度大的参数步子小、梯度小的步子大，但分母只增不减，学习率最终趋于0。Adadelta做了两处修改。

第一，用指数滑动平均代替累加：E[g²]_t = ρ·E[g²]_{t−1} + (1−ρ)·g_t²，ρ如0.95，于是分母只反映最近的梯度大小，学习率不会单调衰减到0。第二，作者注意到SGD、动量和AdaGrad的更新量“单位”与参数本身不一致（如果参数有某种单位，梯度的单位是它的倒数），而牛顿法这类二阶方法的更新量单位是对的。受此启发，他用另一个滑动平均 E[Δx²] 记录最近的更新量大小，令更新为 Δx_t = −(RMS[Δx]_{t−1} / RMS[g]_t) · g_t，其中 RMS[z] = √(E[z²] + ε)。这样就不再需要全局学习率。

摘要称，该方法只使用一阶信息，比普通SGD多出的计算很少，不需要手动调学习率，对噪声梯度、不同的模型结构、数据模态和超参数选择都比较稳健；作者在单机的MNIST分类和一个分布式集群上的大规模语音数据集上展示了效果。

本篇术语

  • 指数滑动平均　新值 = ρ×旧值 + (1−ρ)×当前观测，越早的观测权重衰减越多，只反映最近的情况。
