Fashion-MNIST

Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning Algorithms
2017.08数据集延伸arXiv 2017Han Xiao, Kashif Rasul, Roland Vollgraf · Zalando Research待核对
arXiv ↗官方仓库 ↗在交互版中打开（演化树、学习进度）

问题

手写数字MNIST上卷积网络已能做到99.7%，太容易、用得太滥，也不像现代视觉任务，但大量代码和教程又都按它的格式写死了。

方法

用电商Zalando的7万张商品图，做成与MNIST完全同格式的28×28灰度图、10类、6万训练加1万测试，换个文件就能直接替换MNIST。

影响

成为入门教程和小规模算法实验里最常用的MNIST替代品，torchvision、Keras等框架都内置了它。

方法

据论文和官方仓库，Fashion-MNIST来自Zalando网站上的商品图片，共70,000张、10个类别、每类7,000张：T恤/上衣、裤子、套头衫、连衣裙、外套、凉鞋、衬衫、运动鞋、包、短靴。每张原图经过一条固定的转换流程：转成PNG、裁掉与角落像素颜色相近的边、把长边缩到28像素、用高斯算子锐化、把短边补到28像素并居中、反转明暗，最后转成8位灰度。

作者的出发点写在仓库里：MNIST太容易（卷积网络可达99.7%）、被用得太多，也代表不了现代视觉任务；但很多代码只认MNIST的格式。所以Fashion-MNIST刻意保持同样的图像尺寸、文件格式和6万/1万的训练测试划分，作为“直接替换”的基准。论文用scikit-learn里的多种经典分类器做了基线，每个重复5次取平均，表中最好的是RBF核的支持向量机，测试准确率0.897。仓库另列了社区提交的结果（维护者注明未逐一复测），多数卷积网络在0.90–0.96之间，明显低于它们在MNIST上的成绩。

容易误解的地方

  • 它只是比MNIST难一些，类别少、图像小，在它上面领先不能说明方法在真实视觉任务上也领先。
  • 仓库里的社区结果没有统一复测，引用时应说明来源。

局限与后续

  • 图像只有28×28灰度、10类且都是白底居中的商品照，衬衫与T恤、套头衫与外套等类别容易混淆，但离真实场景的识别难度仍很远。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    支持向量机1995 · 基础
    论文用scikit-learn的经典分类器做基线，RBF核SVM在表中最好。
  • 改进
    MNIST1998 · 数据·评测
    MNIST太容易且被过度使用，Fashion-MNIST保持同样格式和划分但换成更难的服装图片，可直接替换。

读懂它需要的概念

图像作为张量 监督学习 训练集、验证集与测试集

本篇术语

  • drop-in replacement（直接替换）　与原数据集文件格式、尺寸和划分完全一致，只改数据路径、不改代码就能换用。

怎么学

先读MNIST讲解；动手：用torchvision加载FashionMNIST，同一个小卷积网络分别在MNIST和Fashion-MNIST上训练，比较准确率，再看混淆矩阵里哪几类最容易搞错。
