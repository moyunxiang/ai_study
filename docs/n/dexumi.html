DexUMI人手外骨骼采集

DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation
2025.05系统延伸CoRL 2025Mengda Xu, Han Zhang, Yifan Hou, Zhenjia Xu, Linxi Fan, Manuela Veloso, Shuran Song · 斯坦福大学、哥伦比亚大学、NVIDIA等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

用人手采集灵巧操作数据最自然，但人手与机器手在运动学和外观上都有差距：人能做的动作机器手未必能做，视频里出现的是人手而不是机器手。

方法

硬件上用可穿戴手部外骨骼弥合运动学差距（采集时有直接触觉反馈，并把人手动作约束到机器手可行范围），软件上用高保真的机器手图像修补替换视频里的人手，弥合视觉差距。

影响

在两种不同的灵巧机器手平台上做了全面的真实实验，平均任务成功率86%，把UMI式便携采集推广到了灵巧手。

方法

UMI手持夹爪采集用手持夹爪让人在野外采集夹爪操作数据，DexCap便携手部动捕用动捕手套采集人手动作，但两者都不能直接给多指机器手用：动捕记录的人手动作常常超出机器手关节范围，图像里的人手外观与机器手不同，训练出的视觉策略部署时看到的是机器手。DexUMI做两项适配：硬件适配是一个按目标机器手设计的可穿戴外骨骼，人戴着它操作，手指运动被限制在机器手可行的空间内，同时手指直接接触物体，保留触觉反馈；软件适配是在采集的视频中把人手和外骨骼抠掉，用高保真修补换成机器手的图像，使训练数据和部署时的观测一致。论文在两种灵巧机器手硬件上进行了全面的真实实验，平均任务成功率86%。
