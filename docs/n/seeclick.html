SeeClick GUI定位

SeeClick: Harnessing GUI Grounding for Advanced Visual GUI Agents
2024.01论文延伸ACL 2024Kanzhi Cheng, Qiushi Sun, Yougang Chu, Fangzhi Xu, Yantao Li, Jianbing Zhang, Zhiyong Wu · 南京大学 / 上海AI Lab待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

视觉GUI智能体只靠截图，但模型很难根据指令准确指出屏幕上某个元素在哪里（GUI落地），这是性能瓶颈。

方法

专门为GUI落地做预训练，并自动构造落地数据，同时发布覆盖手机、桌面、网页的ScreenSpot基准。

影响

确立了“先练好点哪里，再谈完成任务”的路线，ScreenSpot成为GUI落地的常用基准。

方法

SeeClick基于Qwen-VL（具备把文字对应到图像位置的能力），再用大量“指令对应屏幕位置”的数据继续预训练。训练数据自动构造：从网页的HTML中抽取可点击元素及其文字、位置，以及手机界面里的控件信息，生成“点击某按钮”这类样本。同时提出ScreenSpot，第一个覆盖移动端、桌面和网页的真实GUI落地基准。

摘要称预训练后SeeClick在ScreenSpot上相比各种基线显著提升，并且在三个常用的GUI智能体基准上，落地能力的提高与下游任务表现正相关。这直接回应了SeeAct指出的“落地难”问题，与CogAgent一样只靠截图而不依赖HTML。
