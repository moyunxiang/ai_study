实时动态规划RTDP

Learning to Act Using Real-Time Dynamic Programming
1995.01论文延伸Artificial Intelligence 1995Andrew G. Barto, Steven J. Bradtke, Satinder P. Singh · 马萨诸塞大学阿默斯特分校待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

经典动态规划（值迭代、策略迭代）每一轮都要扫遍所有状态；状态空间一大，哪怕模型已知也算不动，而且大量算力花在智能体根本到不了的状态上。

方法

实时动态规划RTDP：让智能体一边行动一边做Bellman备份，只更新它实际访问到的状态；把动态规划、启发式搜索和强化学习放进同一个异步DP的框架里讨论。

影响

这篇长文把TD学习、Q-learning与动态规划的关系讲清楚了，RTDP本身成了规划领域（尤其随机最短路问题）的经典算法，后来的LRTDP等变体都从它出发。

方法

动态规划的核心操作是Bellman备份：用后继状态的估值更新当前状态，V(s) ← min_a Σ_s' P(s'|s,a)[c(s,a,s') + V(s')]（这里按随机最短路的代价写法）。值迭代按固定顺序把所有状态都备份一遍再重复。

异步DP的观察是：备份顺序可以任意，只要每个状态被无限次备份，值函数仍会收敛。RTDP就利用这一点：智能体从起点出发，在当前状态s做一次（或几次）Bellman备份，然后按当前估值贪心地选动作、走到下一个状态，再在那里备份，如此循环，一局一局重复。这样算力集中在从起点出发真正会经过的状态上。

论文给出的结论是：在随机最短路问题里，如果初始估值是乐观的（不高估代价），RTDP在相关状态上收敛到最优，无需遍历所有状态——这和人工智能里Korf的LRTA*启发式搜索是同一个思想在随机情形下的推广。论文还把不知道模型时的版本（自适应RTDP，边学模型边做RTDP）与Q-learning等直接方法放在一起比较，用赛车轨迹问题做实验，并系统梳理了RL算法如何看作异步、基于采样的动态规划。

本篇术语

  • 异步动态规划　不要求每轮扫遍所有状态，按任意顺序更新单个状态的估值，只要每个状态被无限次更新就仍然收敛。
  • 随机最短路问题　从起点出发、以最小期望代价到达目标集合的MDP，许多规划和导航问题都能写成这种形式。

怎么学

先学值迭代；读原文中RTDP算法和赛车轨迹实验部分；在一个网格迷宫上分别实现值迭代和RTDP，统计两者各做了多少次备份。
