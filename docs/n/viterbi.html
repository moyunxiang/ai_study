Viterbi算法

Error Bounds for Convolutional Codes and an Asymptotically Optimum Decoding Algorithm
1967.04论文延伸IEEE Trans. Information Theory 1967Andrew J. Viterbi · UCLA待核对
DOI ↗在交互版中打开（演化树、学习进度）

问题

卷积码的接收端要从带噪声的符号流里找出最可能的发送序列，可能的序列数随长度指数增长，穷举不可行。

方法

按时间一步步推进，在每个状态上只保留到达该状态的最优路径（幸存路径），其余全部丢弃，计算量随序列长度线性增长。

影响

它成了所有HMM解码器的核心：给定一串声学观测，高效求出最可能的音素或词序列。

背景

1960年代的通信系统需要在噪声中还原卷积码。序列有N步、每步S个状态时，所有路径共有S的N次方条，没法逐条打分。

方法

核心是动态规划（见动态规划）。设δ_t(j)为「走到第t步、停在状态j」的最优路径得分，则

δ_t(j) = max_i [δ_{t-1}(i) + log a_ij] + log b_j(o_t)

同时记下每个状态是从哪个前驱来的，走到末尾后沿记录回溯，就得到全局最优路径。只要某条路径在t时刻落在状态j，它之后的最优延续只取决于j，与它怎么来的无关（马尔可夫性，见马尔可夫性与马尔可夫链），所以每个状态保留一条就够。复杂度是O(N·S²)，不再指数增长。

论文本身的主题是卷积码的误码界和这种渐近最优的译码器；语音界后来把同一个算法用在HMM统计语音识别的隐马尔可夫模型（见隐马尔可夫模型）上，Rabiner的HMM教程把它列为HMM的三个基本问题之一。

后来的发展

大词汇量识别里状态图极大，实际系统在Viterbi上再加束搜索（每步只留得分接近最优的状态），并用WFST解码器把声学、词典和语言模型合成一张图来搜索。

局限与后续
