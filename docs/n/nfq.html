神经拟合Q迭代NFQ

Neural Fitted Q Iteration – First Experiences with a Data Efficient Neural Reinforcement Learning Method
2005论文延伸ECML 2005Riedmiller · University of Osnabrück待核对
Springer ↗在交互版中打开（演化树、学习进度）

问题

在线地用神经网络做Q学习，每个样本只更新一次，既浪费数据又不稳定。

方法

保存所有经历过的转移，每一轮把全部数据当作一个批量回归问题，用RPROP这类批量优化器重新训练多层感知机来拟合Bellman目标。

影响

最早展示用神经网络做数据高效RL的方法之一，是DQN的前身思路：存储并复用经验，用网络拟合Q。

方法

NFQ是拟合Q迭代FQI的神经网络版本：智能体不停与环境交互并存下 (s, a, r, s′)，每隔一段时间用全部存下的数据训练一次网络。每次训练里的目标由上一轮网络计算：目标 = r + γ·min/max Q_旧(s′, ·)，然后做若干轮批量监督学习（作者用的是对步长不敏感的RPROP），而不是每个样本做一次SGD更新。

摘要称，这种存储并复用转移经验的无模型、基于神经网络的方法在三个基准问题上，只需与被控对象交互相当少的次数就能生成高质量的控制策略。

局限与后续

  • 每一轮要在全部数据上重新训练网络，数据一多计算代价很大，难以扩展到图像输入。
    后来针对它的工作　DQN
  • 神经网络与自举结合仍可能不稳定，早期只靠小网络和手工状态特征。
    后来针对它的工作　DQN

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    用批量反向传播（RPROP优化）训练Q网络。
  • 改进
    拟合Q迭代FQI2005 · RL
    把树集成回归器换成多层感知机，把拟合Q迭代带进神经网络。

后来的相关工作

  • 改进
    DQN2013.12 · RL 已核对
    NFQ每轮要在全部数据上重新训练网络，无法扩展；DQN改为从回放池抽小批量做SGD，能用大网络处理海量画面。

读懂它需要的概念

反向传播 时序差分与自举 Bellman方程 监督学习

怎么学

先学拟合Q迭代FQI，再把回归器换成小的MLP，在CartPole上跑一遍，并对比DQN里逐小批量更新的做法。
