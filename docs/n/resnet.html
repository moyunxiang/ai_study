ResNet

Deep Residual Learning for Image Recognition
2015.12论文主干CVPR 2016Kaiming He（何恺明）, Xiangyu Zhang（张祥雨）, Shaoqing Ren（任少卿）, Jian Sun（孙剑） · 微软亚洲研究院来源已核对
arXiv ↗后续：Identity Mappings in Deep Residual Networks ↗D2L：残差网络 ↗在交互版中打开（演化树、学习进度）

问题

网络超过二十层后，再加层不但测试误差变大，连训练误差也变大——这不是过拟合，而是更深的网络反而更难优化，深度红利到VGG的19层就吃不下去了。

方法

让每几层只学习“在输入基础上要改多少”：输出写成F(x) + x，x经一条恒等捷径直接加到输出上。如果某几层没用，只要把F推到0就退化成恒等映射，加深至少不会变差。

影响

训练出152层的ImageNet网络，集成模型top-5错误率3.57%，赢得ILSVRC 2015分类以及ImageNet检测、定位和COCO检测、分割共五项第一；之后Transformer、扩散模型的U-Net等大量网络都采用了残差连接。

背景

VGG证明了更深的网络更好，但VGG-19之后，单纯继续堆层出现了反常现象。作者用同样设计规则搭了一个20层和一个56层的“普通网络”（plain net），在CIFAR-10上，56层网络的训练误差和测试误差都高于20层。

这有些奇怪：理论上，深网络至少可以把多出来的层设成恒等映射，从而复制浅网络的结果，训练误差不该更高。作者称之为退化问题。它也不是经典的梯度消失（梯度消失问题）：网络里用了Batch Normalization，作者检查发现前向信号和反向梯度的幅度都正常。合理的推断是：用多层非线性层去逼近一个恒等映射，对SGD来说本身就很难。

同年的Highway网络网络借鉴LSTM的门控，用一个可学的门在“变换”和“原样通过”之间加权，已经能训练上百层的网络，但ResNet论文指出，它还没有显示出极深（如上百层）带来的精度收益。

方法

残差学习。设某几层要学的目标映射是H(x)。不直接学H，而是让这几层学残差F(x) = H(x) − x，输出写成

y = F(x, {Wᵢ}) + x

加号那条路叫捷径连接（见残差连接），它不含参数、不需要计算。直观理解：如果最优映射接近恒等，学“把F压到0”比用一堆非线性层凑出恒等容易得多；即便不是恒等，以恒等为参照学一个小的修正量也更容易。反向传播时，∂y/∂x = ∂F/∂x + 1，那个“+1”让梯度可以不经衰减地直接传回浅层。

基本块。ResNet-18/34用两个3×3卷积组成一个残差块，每个卷积后接BN和ReLU，相加之后再过ReLU。下采样时通道翻倍，捷径的维度对不上，就用1×1卷积投影或补零。

瓶颈块。ResNet-50/101/152把每个块换成“1×1降维 → 3×3 → 1×1升维”三层（如256→64→64→256通道），让3×3卷积在低维上算，层数加倍而计算量增加不多。ResNet-152的计算量为113亿次乘加，低于VGG-16/19（VGG-19为196亿）。

训练。沿用He初始化与PReLU的初始化，SGD批大小256、动量0.9、权重衰减10⁻⁴、学习率从0.1开始，误差停滞时除以10；不用Dropout。

结果

这组对比里退化现象消失。ImageNet验证集top-1错误率（10-crop）：普通网络18层27.94%、34层28.54%（更深反而更差）；残差网络18层27.88%、34层25.03%（更深明显更好）。

更深更好。单模型ResNet-152的top-1为19.38%、top-5为4.49%，比此前所有单模型都好；6个不同深度模型的集成在测试集上top-5错误率3.57%，获ILSVRC 2015分类第一。

迁移。把Faster R-CNN的主干从VGG-16换成ResNet-101，COCO检测指标相对提升28%。在CIFAR-10上训练了110层（错误率6.43%）和1202层的网络，1202层仍能优化到很低的训练误差，但测试误差7.93%，比110层差，作者认为是在小数据集上过拟合。

后来的发展

残差连接是这篇论文影响最广的部分。Transformer的每个子层都包了一层残差加LayerNorm，并在论文中引用了ResNet；扩散模型的U-Net、AlphaFold 2的主干和今天的大语言模型也都使用残差连接。

在视觉里，ResNet-50此后多年是最常用的骨干和对比基准之一：特征金字塔FPN、Mask R-CNN、MoCo、SimCLR都以它为默认网络。直接的变体有：预激活ResNet把BN和ReLU移到卷积前面，使恒等路径完全“干净”，训出1001层；Wide ResNet发现变宽比变深更划算；ResNeXt用分组卷积；DenseNet把相加换成拼接。理论上，神经常微分方程把残差块看成常微分方程的欧拉离散。2022年的ConvNeXt按视觉Transformer的设计逐步改造ResNet，论文报告它的ImageNet精度与Vision Transformer系的Swin相当，并在COCO检测和ADE20K分割上超过Swin。

容易误解的地方

  • 残差连接针对的主要是“退化”（深网络难优化），论文明确说它不是靠解决梯度消失起作用的——用了BN的普通深网络梯度并没有消失。
  • 残差块输出是F(x)+x，相加要求两者形状一致；维度变化处的捷径需要投影，不再是纯恒等。
  • 原版ResNet在相加之后还有一个ReLU，恒等路径并不完全“干净”，这正是预激活ResNet要改的地方。

它建立在什么之上

  • 改进
    AlexNet2012.09 · 视觉 已核对
    只有8层，再加深就难以训练；11×11大卷积核、LRN等设计靠经验拼凑，缺少统一原则。
  • 使用
    Batch Normalization2015.02 · 基础 已核对
    每个卷积后都接BN，保证前向和反向信号的幅度正常，使退化问题能与梯度消失区分开。
  • 改进
    梯度消失问题1994 · 基础 已核对
    论文认为退化问题“不太可能由梯度消失引起”：用了BN的普通网络前向信号方差不为零、反向梯度幅度正常；它把“深网络难优化”从梯度消失中区分出来，单独作为要处理的问题。
  • 改进
    VGG2014.09 · 视觉 已核对
    VGG式的普通网络加深到二三十层后出现退化；残差连接让深度继续带来收益，152层的计算量仍低于VGG。
  • 竞争
    Highway网络2015.05 · 基础 已核对
    同一时期针对“很深的网络难训练”的另一条路线：Highway用依赖数据的门控决定“变换”与“直通”的比例；ResNet用无参数的恒等捷径直接相加。ResNet论文把Highway列为同期工作，并称它还没有显示出极深带来的精度收益。
  • 使用
    Faster R-CNN2015.06 · 视觉 已核对
    把Faster R-CNN的主干换成ResNet-101，COCO检测相对提升28%，赢得COCO 2015检测与分割。
  • 竞争
    GoogLeNet / Inception2014.09 · 视觉 已核对
    ILSVRC 2014冠军，靠多分支的Inception模块在固定计算量下加宽加深；ResNet论文把它列为主要对比（单模型top-5 7.89%、集成6.66%，ResNet分别为4.49%和3.57%），并在相关工作里提到Inception层含有一条捷径分支。
  • 使用
    He初始化与PReLU2015.02 · 基础 已核对
    用何恺明等人为ReLU网络推导的初始化方法从头训练所有网络。
  • 改进
    反向传播1986 · 基础 待核对
    层数一多，误差信号每经过一层都要乘上S形函数的导数（最大0.25），传到底层时几乎为0，深层网络训不动。
  • 改进
    深度信念网络2006 · 基础 待核对
    没有说清深层网络难训的真正原因；后来发现靠合适的激活函数、初始化和归一化就能直接训练深网络，无需预训练。
  • 改进
    Xavier初始化2010 · 基础
    只缓解了初始阶段的信号尺度，深度再增加（几十到上百层）时仍然难以训练。
  • 改进
    GPU多列卷积网络2012.02 · 视觉
    多个网络集成使推理成本成倍增加。
  • 改进
    Network In Network2013.12 · 视觉
    论文只在小图像数据集（CIFAR、SVHN、MNIST）上验证，没有给出ImageNet级别的结果。

本篇术语

  • 退化问题　网络加深后训练误差反而升高的现象。它不是过拟合（训练误差也变差），而是深网络更难被优化。
  • 捷径连接　跳过若干层、把输入直接加到这些层输出上的连接。ResNet中多为不含参数的恒等映射。
  • 瓶颈块　1×1卷积先把通道降下来，在低维上做3×3卷积，再用1×1卷积升回去，用于在深网络中节省计算。
