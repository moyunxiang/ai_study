xFormers内存高效注意力

2021.10系统延伸Meta AI（FAIR）待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

Transformer研究里新的注意力变体和组件层出不穷，主流框架来不及提供高效实现；自己写又慢又费显存。

方法

提供一组可自由组合、与具体领域无关的Transformer构件，其中最常用的是内存高效的注意力算子，让研究者不写底层内核也能用上快且省显存的实现。

影响

它的memory_efficient_attention在2022–2023年被Stable Diffusion WebUI等扩散模型工具广泛使用（“--xformers”选项），大幅降低了生成图片所需的显存。

方法

xFormers仓库创建于2021年10月，定位是“加速Transformer研究的工具箱”，README列出三点：可定制、无需样板代码的独立构件，适用于视觉、NLP等各领域；研究优先，包含主流库中尚未提供的前沿组件；以效率为先，组件尽可能快、省显存。

其中影响最大的是memory_efficient_attention：它与FlashAttention思路相同，按块计算注意力并用在线softmax合并结果，不在显存中存放完整的n×n注意力矩阵，因而显存随序列长度线性增长；它还支持多种注意力偏置（如因果掩码、分块对角掩码，便于把不同长度的序列拼成一批）。早期版本自带CUTLASS与Triton写的内核；README目前说明它是纯Python包，要求PyTorch 2.10以上，注意力内核来自MSLK包，并可选用FlashAttention 3。

局限与后续

  • PyTorch 2.0起内置了scaled_dot_product_attention（包含FlashAttention与内存高效两种后端），xFormers作为独立依赖的必要性下降。

  • 竞争
    高效长序列注意力2020.01 · LLM
    早期高效注意力多改变注意力的数学形式（如Reformer的哈希注意力），xFormers的内存高效注意力保持精确结果、只改计算方式；后期它也直接调用FlashAttention内核。

怎么学
