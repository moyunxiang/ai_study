PLAS潜在动作空间策略

PLAS: Latent Action Space for Offline Reinforcement Learning
2020.11论文延伸CoRL 2020Wenxuan Zhou, Sujay Bajracharya, David Held · CMU待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

离线RL要让策略只选数据支撑集内的动作，BCQ、BEAR等方法用显式约束或扰动来实现，约束强弱不好把握。

方法

先用条件VAE学会“数据里的动作长什么样”，再让策略在VAE的潜在空间里输出潜变量，经解码器变成动作；这样输出的动作天然落在数据分布附近。

影响

成为“隐式约束/潜在动作空间”一类离线RL的代表，d3rlpy等库内置；后来用扩散、流模型表示行为分布的离线方法都可看作同一思路的延续。

方法

BCQ批量约束Q学习用一个生成模型产生“像数据的动作”，再加一个小扰动网络去改进；扰动多大是个超参数。PLAS（Policy in the Latent Action Space）换了一种做法：

1. 先在离线数据上训练一个条件变分自编码器VAE：编码器把 (s, a) 压成潜变量z，解码器从 (s, z) 还原动作。 2. 策略不直接输出动作，而是输出潜变量 z = π(s)，并把z限制在先验分布概率较高的区域（如截断在一个范围内）。 3. 执行时 a = Decoder(s, π(s))。由于解码器只学过数据里的动作，它在高概率潜变量上解码出来的动作都在数据支撑集内。 4. 评论家照常用TD3式的双Q学习，策略在潜在空间里做确定性策略梯度最大化Q。

约束不再写在损失里，而是被“动作空间的重新参数化”隐式实现。作者在D4RL连续控制任务和一个真实机器人布料操作任务上评测，摘要称在不同类型的数据集上表现稳定，超过带显式约束的离线方法。

局限与后续

  • 策略能达到的动作完全取决于VAE的表达能力，VAE对多峰或复杂动作分布拟合不好时，好动作可能根本解码不出来。
    后来针对它的工作　Diffusion-QL扩散策略
  • 需要先训VAE再训策略，两阶段的效果受VAE质量和潜变量截断范围影响。
    本站还没有记录针对它的后续工作（不代表没有人解决）
