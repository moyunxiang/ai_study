LSQ可学习步长量化

Learned Step Size Quantization
2019.02论文延伸ICLR 2020Steven K. Esser, Jeffrey L. McKinstry, Deepika Bablani, Rathinakumar Appuswamy, Dharmendra S. Modha · IBM研究院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

低比特量化感知训练里，量化步长（每个整数等级代表多大的实数）多半靠统计或手工设定，权重和激活降到2–4比特时，这个步长选得好不好直接决定精度。

方法

把每层权重和激活量化器的步长s当作网络参数，推导出损失对s的梯度并按参数量和位宽给它乘一个缩放系数，让s和权重一起训练。

影响

成为量化感知训练最常用的强基线之一，只需对训练代码做很小的改动；后续的低比特QAT方法普遍以它为起点或对照。

方法

量化器把实数v映射成 v̂ = round(clip(v / s, −Q_N, Q_P)) × s，其中Q_N、Q_P由位宽决定（如3比特无符号激活为0到7）。PACT可学习截断激活量化学习的是截断阈值，步长随之间接确定；LSQ直接学习步长s本身。

关键在于s的梯度。取整不可导，LSQ同样借助直通估计器STE，但保留了取整带来的影响：在截断范围内，∂v̂/∂s = −v/s + round(v/s)，越靠近两个量化等级的分界处，梯度越大；超出范围时梯度为 −Q_N 或 Q_P。作者还发现，s的梯度量级与权重梯度相差悬殊，于是给它乘上 g = 1/√(N·Q_P)（N为该层权重或特征的个数），使步长与权重的更新速度相称。s的初值用 2⟨|v|⟩/√Q_P 估计。

摘要报告：在ImageNet上，多种架构的权重与激活量化到2、3、4比特时，取得了当时最高的精度；3比特模型可以达到全精度基线的精度。
