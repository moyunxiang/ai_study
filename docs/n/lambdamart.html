LambdaRank与LambdaMART

From RankNet to LambdaRank to LambdaMART: An Overview
2010.06论文重要Microsoft Research技术报告 MSR-TR-2010-82Christopher J. C. Burges · 微软研究院待核对
技术报告PDF ↗LambdaRank（NIPS 2006） ↗Wikipedia：Learning to rank ↗在交互版中打开（演化树、学习进度）

问题

搜索排序的好坏用NDCG这类只看名次的指标衡量，它对模型参数不可导；RankNet优化的成对错误数与NDCG并不一致，排在第1位和第50位的错误被同等对待。

方法

不去写出那个不可导的损失，而是直接规定梯度：在RankNet的成对梯度上乘以「交换这两篇文档会让NDCG变化多少」；再把这种梯度（lambda）交给梯度提升树去拟合，就是LambdaMART。

影响

LambdaMART成为工业界排序学习的主力，2010年雅虎排序学习挑战赛第一赛道的冠军方案是LambdaMART集成；今天LightGBM、XGBoost里的lambdarank目标就是它。

背景

2000年代的网页搜索已经不再只用BM25一个分数，而是把BM25、PageRank、点击率等几百个特征交给机器学习模型排序，即「排序学习」。RankNet排序学习（2005）是其中的代表：对同一查询下的每一对文档，用神经网络打分，再用交叉熵让「更相关的那篇分更高」。

问题在于评价指标。搜索看的是NDCG（归一化折损累计增益）：排在越前面的位置权重越大，前几名排错的代价远大于后面。NDCG只取决于名次，名次随分数跳变，对参数几乎处处梯度为0，没法直接优化；而RankNet数的是错误对的个数，模型可能为了修正第50名附近的一堆小错误，牺牲第1名。

方法

LambdaRank（Burges等，NIPS 2006）的观察是：梯度下降真正需要的只是梯度，不需要损失函数本身。对一对文档i（更相关）和j，RankNet给出的梯度大小是σ / (1 + exp(σ(s_i − s_j)))；LambdaRank把它乘以交换i、j两篇文档后NDCG变化的绝对值：

λ_ij = −σ / (1 + exp(σ(s_i − s_j))) · |ΔNDCG_ij|

每篇文档把它和所有其他文档配对得到的λ相加，就得到这篇文档分数该往上推还是往下拉、推多大力。牵涉到前几名的交换|ΔNDCG|大，梯度也大，模型于是优先把头部排对。后来的实验与分析表明，这样定义的梯度确实在直接提升NDCG。

LambdaMART（Wu、Burges、Svore、Gao，2008年技术报告）把模型从神经网络换成MART，即梯度提升机GBM回归树：每一轮把λ当作要拟合的「伪残差」，长一棵新的回归树加到模型上，并用牛顿法步长给叶子节点赋值。树模型擅长处理量纲各异的手工特征，训练也快。Burges这份2010年报告把散落在多篇论文和报告里的三者推导整理成一篇完整说明。

结果

据报告摘要，LambdaMART排序器的集成赢得了2010年雅虎排序学习挑战赛（Yahoo! Learning to Rank Challenge）第一赛道；报告本身是综述性的推导说明，不报告新的实验数字。

后来的发展

LambdaMART此后十年都是排序学习的标准强基线，开源实现进入RankLib、XGBoost和LightGBM（目标函数名就叫lambdarank）。神经检索兴起后，BERT重排序等BERT重排序模型在效果上超过了基于手工特征的LambdaMART，但在要融合大量异构特征的工业排序里，梯度提升树配lambda梯度仍很常见。「不写损失、直接定义与指标对齐的梯度」这个想法也被借到推荐系统等其他排序任务。

容易误解的地方

  • LambdaRank、LambdaMART分别在2006年和2008年提出，本节点挂在2010年的综述报告上，是因为它第一次把三者完整地写在一起，后来被广泛引用。
  • λ梯度并不对应一个事先写好的损失函数；后来有工作（如LambdaLoss）才给出它对应的概率框架。

局限与后续

  • 仍然依赖人工设计的几百个特征（BM25分、PageRank、点击统计），模型本身不理解查询和文档的文字含义。

  • 训练需要大量人工标注的分级相关性，标注昂贵；直接用点击日志又会带入位置偏差。

读懂它需要的概念

梯度下降 损失函数 决策树 集成学习 检索与向量数据库 准确率、精确率、召回率与F1

本篇术语

  • NDCG　归一化折损累计增益：按名次给相关文档打折计分（第k位乘以1/log₂(k+1)），再除以理想排序的得分，取值0到1。
  • 排序学习　Learning to Rank：用机器学习把多个相关性特征组合成一个排序分数，按成对、按列表等方式训练。
  • MART　Multiple Additive Regression Trees，即梯度提升回归树：每一轮拟合当前梯度，逐棵累加小树。

怎么学

先复习梯度提升树和交叉熵 → 读Burges报告第1–5节（RankNet → LambdaRank → LambdaMART的推导）→ 动手：用LightGBM的lambdarank目标在MSLR-WEB10K或任一小型排序数据上训练，并与按单一BM25分排序比较NDCG@10。
