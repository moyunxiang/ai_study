影响函数与数据归因

Understanding Black-box Predictions via Influence Functions
2017.03论文延伸ICML 2017Pang Wei Koh, Percy Liang · 斯坦福大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

LIME、梯度显著图这类方法解释的是“输入的哪部分重要”，回答不了“是哪些训练样本让模型学成这样”。

方法

借用稳健统计里的影响函数，近似估计“把某个训练样本的权重调大一点或删掉，测试预测会怎么变”，而不必真的重训模型。

影响

开创了用影响函数做训练数据归因的路线，用来找错误标注、调试模型、构造投毒样本，后来被扩展到大语言模型。

方法

最直接的问法是：删掉训练样本z重新训练，测试点上的损失变了多少？对每个样本都重训显然做不到。影响函数给出一阶近似：把z的权重增加一个很小的ε，最优参数的变化约为 −H⁻¹ ∇L(z, θ)，其中H是训练损失在最优点的海森矩阵（雅可比矩阵与海森矩阵）。再用链式法则，z对测试点z_test损失的影响为 I(z, z_test) = −∇L(z_test)ᵀ H⁻¹ ∇L(z)。

难点是海森矩阵太大没法求逆。作者只需要梯度和“海森矩阵乘向量”这两种运算，用共轭梯度或随机近似去求 H⁻¹v，使方法能用到现代模型上。理论要求损失凸且可微，但实验表明在非凸、不可微的神经网络上近似仍然有用。

作者在线性模型和卷积网络上展示了四种用途：理解模型行为、调试模型、发现数据集里的标注错误，以及构造肉眼看不出差别的训练集攻击，这一点把它和数据投毒攻击联系了起来。

局限与后续

  • 依赖凸性和最优点附近的局部近似，在深层网络上估计值可能很不准，计算量也随参数规模迅速增大。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 竞争
    LIME2016.02 · 安全·可解释
    LIME用输入特征解释单个预测，影响函数把预测追溯到训练样本。
  • 延续
    数据投毒攻击2012.06 · 安全·可解释
    用影响函数找出最能改变预测的训练点，构造难以察觉的训练集攻击。
  • 竞争
    梯度显著图2013.12 · 安全·可解释
    显著图回答“看了输入哪里”，影响函数回答“从哪些训练数据学来”。

读懂它需要的概念

雅可比矩阵与海森矩阵 泰勒展开 损失函数 凸函数与凸优化 导数、偏导与梯度

本篇术语

  • 海森矩阵乘向量　不显式构造海森矩阵，只计算它与某个向量的乘积，代价约等于两次求梯度。

怎么学

先复习泰勒展开与海森矩阵 → 读原文第2–3节推导和高效计算 → 在逻辑回归上实现影响函数，与真正删样本重训的结果对比。
