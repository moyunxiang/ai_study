Bark文本提示音频生成

2023.04模型延伸Suno待核对
GitHub ↗在交互版中打开（演化树、学习进度）

问题

开源TTS大多只能把文字读出来，做不出笑声、叹气、音乐、背景声这类非语言声音，也很难跨语言自然发音。

方法

做一个GPT式的全生成文本到音频模型：沿用AudioLM、VALL-E的分层token思路，用EnCodec量化的音频表示，直接从文本生成语音乃至其他声音。

影响

开源后很快成为最受欢迎的TTS仓库之一（约3.9万星），能生成多语言语音和笑声、音乐等，2023-05改为MIT许可可商用，并被Coqui TTS集成。

方法

Bark由Suno开发，README称它是“全生成式”的文本到音频模型而非传统TTS。结构上它参照AudioLM和VALL-E：先用一个Transformer从文本生成语义token，再用后续模型依次生成粗粒度和细粒度的声学token，这些声学token来自EnCodec的量化表示，最后由EnCodec解码器还原波形。因为是纯生成模型，它不仅能说多种语言，还能在文本里用提示标记生成笑声、叹息、清嗓、背景噪声，甚至简单的音乐和音效；也可以用预设的语音提示控制音色和语气。2023-05的更新带来GPU上2倍、CPU上10倍的提速，并提供更小的版本。

局限与后续

  • 作为研究性的全生成模型，输出可能偏离提示，长文本需分段生成；官方不支持任意声音的克隆。
