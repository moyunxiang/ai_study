OpenWebMath数学网页

OpenWebMath: An Open Dataset of High-Quality Mathematical Web Text
2023.10数据集延伸ICLR 2024Keiran Paster, Marco Dos Santos, Zhangir Azerbayev, Jimmy Ba · 多伦多大学 / 剑桥大学 / 普林斯顿大学待核对
arXiv ↗Hugging Face数据集 ↗在交互版中打开（演化树、学习进度）

问题

Minerva等工作表明在大量数学网页和论文上继续训练能显著提升推理，但已知的开源网络语料在预处理时都会破坏数学公式，研究者拿不到可用的大规模数学网络文本。

方法

专门从Common Crawl中找出数学网页，设计保留LaTeX和公式内容的HTML文本抽取方法，去除页面模板，再做质量过滤和去重，得到147亿token的OpenWebMath。

影响

成为开源数学大模型的标准预训练数据之一，Llemma的Proof-Pile-2、DeepSeekMath等后续数学语料都以它为组成部分或对照。

方法

问题。Common Crawl与网络规模文本里有大量数学论坛、讲义和问答页面，但C4语料、RefinedWeb等通用语料在把HTML转成纯文本时，会把MathJax、图片形式或标签里的公式丢掉或打乱，数学内容基本不可用。闭源的Minerva用了这类数据，开源社区却没有对应的东西。

怎么做。先用分类器和关键词从Common Crawl中挑出可能含数学的网页；再针对各种公式渲染方式（MathJax、KaTeX、图片的替代文字等）写专门的抽取规则，把公式还原成LaTeX；然后去掉导航栏、广告等模板文字，用数学质量分类器和困惑度过滤低质量页面，最后做去重。

结果。最终得到147亿token的数学网页文本。作者用它训练14亿参数的模型做小规模实验：只用147亿token的OpenWebMath训练，效果超过用20多倍通用语言数据训练的模型。

局限与后续

  • 质量过滤依赖分类器，对非英语和非常规排版的数学内容覆盖不足；语料里可能混入常见数学基准的题目，带来污染风险。

读懂它需要的概念

语言模型 分词与token 预训练与微调 困惑度

本篇术语

  • LaTeX　写数学公式最常用的排版语言，例如 \frac{a}{b} 表示分数。
  • 页面模板文字　网页上与正文无关的重复部分，如导航菜单、页脚和广告。

怎么学

先读RefinedWeb了解网页语料的清洗流程。读OpenWebMath原文第3节的公式抽取部分；动手从一个数学问答网页的HTML里分别用普通抽取工具和保留公式的方法提取文本，比较结果。
