物理信息神经网络PINN

Physics Informed Deep Learning (Part I): Data-driven Solutions of Nonlinear Partial Differential Equations
2017.11论文延伸arXiv 2017（Part I）Raissi, Perdikaris, Karniadakis · 布朗大学 / 宾夕法尼亚大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统数值方法求解偏微分方程要划网格、离散化；纯数据驱动的神经网络又需要大量数据且不遵守物理定律。

方法

把偏微分方程本身写进损失函数：网络输入时空坐标、输出解，用自动微分算出方程残差并要求它趋近于零。

影响

开启了「物理信息机器学习」这一方向，此后算子学习、科学计算中的神经网络大量沿用这一思路。

方法

设偏微分方程为 u_t + N[u] = 0。PINN用一个神经网络 u(t, x) 表示解，输入是时间和位置。关键是自动微分与计算图：它不仅能对网络参数求导，也能对输入坐标求导，因此 u_t、u_xx 等偏导数可以精确算出，不必差分。

损失由两项相加：一项是网络在已知数据点（初始条件、边界条件或少量观测）上与真值的误差；另一项是在区域内大量随机取的配点上，方程残差 u_t + N[u] 的平方。训练就是用梯度下降同时压低两项。论文分连续时间和离散时间两类算法，并区分两种问题：已知方程求解，以及从数据中反推方程里的未知系数。

好处是不需要网格，解是可微的函数，数据很少时物理约束起到正则作用。论文在Burgers方程、Schrödinger方程等经典方程上演示了求解。

局限与后续

  • 方程残差作为软约束与数据项竞争，权重难调；对激波、多尺度、长时间演化等问题训练常常很慢或不收敛。
    后来针对它的工作　傅里叶神经算子FNO
  • 每换一组参数或初始条件就要重新训练一个网络，不能一次学出整个解算子。
    后来针对它的工作　DeepONet算子学习 傅里叶神经算子FNO

  • 使用
    反向传播1986 · 基础
    依靠反向传播和自动微分，既训练网络，也计算解对输入坐标的偏导数。

后来的相关工作

  • 延续
    DeepONet算子学习2019.10 · 科学
    PINN每个问题学一个解；DeepONet学的是从条件到解的算子，换条件不必重训。
  • 改进
    傅里叶神经算子FNO2020.10 · 科学
    PINN每个问题都要重新训练；FNO学一整族方程的解算子，对新条件只需一次前向。
  • 竞争
    FourCastNet2022.02 · 科学
    PINN靠把物理方程写进损失函数；FourCastNet完全靠数据，不显式使用方程。
  • 延续
    NeuralGCM混合气候模型2023.11 · 科学
    同属把物理知识放进学习的路线，但NeuralGCM保留完整的数值求解器而不是把方程写进损失。
  • 竞争
    The Well物理仿真数据集2024.11 · 科学
    PINN用方程约束，The Well提供的是数据驱动路线所需的大规模模拟数据。

读懂它需要的概念

怎么学

先会自动微分和梯度下降；读原文第1部分的连续时间模型和Burgers方程示例，然后用PyTorch在一维Burgers方程上自己实现一遍。
