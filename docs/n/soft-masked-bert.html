Soft-Masked BERT中文纠错

Spelling Error Correction with Soft-Masked BERT
2020.05论文延伸ACL 2020Shaohua Zhang, Haoran Huang, Jicong Liu, Hang Li · 字节跳动AI Lab、复旦大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

中文拼写纠错（找出并改正错别字）的最好方法是在每个位置用BERT从候选字里选一个，但BERT的掩码语言模型预训练只让它预测被[MASK]的位置，不擅长判断「这个位置的字是不是错了」。

方法

先用一个双向GRU检测网络估计每个字出错的概率 p_i，再把该位置的输入表示按 p_i 与[MASK]向量做加权混合（软掩码），送进BERT纠正网络预测正确的字。越可能错的字越接近被遮住，BERT就越会认真去「填空」。

影响

这种「检测+纠正」两段、用软掩码连接的结构成为中文拼写纠错的常用基线，之后的SpellGCN、PLOME等方法常与它比较。

背景

中文没有空格、错别字多是音近字（「在/再」）和形近字（「己/已」），输入法和OCR都会产生。2019年前后的做法是把BERT当成每个位置的分类器：输入整句，在每个位置输出一个字，与原字不同就是纠正。但BERT预训练时只有15%的位置被遮住或替换，大多数位置它都倾向「照抄原字」，因此常常检测不出错误。

方法

模型由两部分串联：

检测网络：字向量 e_i 输入双向GRU，输出每个位置是错字的概率 p_i。

软掩码：把送入纠正网络的输入改成

e'_i = p_i · e_mask + (1 − p_i) · e_i

其中 e_mask 是[MASK]的向量。检测网络认为错得越确定，输入越接近[MASK]；认为没错，就基本保留原字。

纠正网络：一个BERT，接在 e'_i 后面，最后一层再加上原字向量的残差，经softmax在全字表上预测每个位置的正确字。

训练的总损失是两部分的加权和 L = λ·L_correct + (1 − λ)·L_detect，两个网络端到端联合训练。训练数据除公开标注集外，还用同音、近形字替换的方法从大量文本中自动生成了错句。

结果

摘要称在两个数据集上的表现显著优于包括只用BERT的方法在内的基线。具体数字未核对。

后来的发展

此后的中文拼写纠错工作沿着两条路改进：把字音和字形信息显式加进模型（SpellGCN用图卷积建模混淆集，PLOME等在预训练中加入拼音与笔画），以及把检测和纠正更紧地融合。软掩码这种「用检测概率调节输入」的思路也被用到其他「先检测后纠正」的任务。

本篇术语

  • 中文拼写纠错（CSC）　找出中文句子里的错别字并替换为正确的字，常用SIGHAN系列数据集评测，分检测和纠正两个层面计分。
  • 混淆集　每个字可能被误写成的字的集合，通常由音近字和形近字组成，用来生成训练数据或限制候选。

怎么学

先读BERT的掩码语言模型 → 读原文第3节软掩码公式与第4节数据构造 → 动手：用一个中文BERT直接做逐字纠错，再加一个简单的检测头实现软掩码，对比检测召回率。
