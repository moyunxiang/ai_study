DQN

Playing Atari with Deep Reinforcement Learning
2013.12论文主干NIPS 2013 Deep Learning WorkshopMnih, Kavukcuoglu, Silver, Graves, Antonoglou, Wierstra, Riedmiller · DeepMind来源已核对
arXiv ↗Nature版（2015） ↗Spinning Up：Q-learning系 ↗在交互版中打开（演化树、学习进度）

问题

Q-learning配上神经网络这类非线性函数近似，训练常常发散；以前成功的强化学习应用大多靠手工设计的特征，论文称此前没有深度学习模型能用强化学习直接从原始像素学会控制策略。

方法

用卷积网络直接把4帧游戏画面映射成每个动作的Q值，用经验回放打乱样本相关性，用固定一轮的旧参数算目标，再用小批量SGD训练。

影响

同一个网络、几乎同一组超参数，只看像素就在7款Atari游戏中的3款超过人类专家，常被视为深度强化学习兴起的起点。

背景

强化学习的目标是让智能体通过试错学会在环境中拿到尽量多的累计奖励（见奖励、回报与折扣）。Q-learning是最经典的做法：学一个函数Q(s,a)，表示在状态s做动作a之后能拿到的期望回报，然后每步选Q最大的动作。状态少时可以用一张表存Q值；但一帧Atari画面有160×210个像素，状态数天文数字，必须用函数近似。

问题在于，用神经网络近似Q值一直很不稳定。理论上，离策略学习+函数近似+自举（用自己的估计当目标）这三者凑在一起就可能发散，Baird反例与发散问题给出了线性情形下的反例。实践中，TD-Gammon在双陆棋上成功过，但论文指出，把同样方法用到国际象棋、围棋和跳棋上的早期尝试不太成功。神经拟合Q迭代NFQ用多层网络做批量Q迭代，能在小控制问题上工作，但每轮都要在全部数据上重训，难以扩展到大网络和海量画面。

另一边，2012年的AlexNet刚证明了卷积网络能从原始像素学出好特征。Arcade学习环境ALE则提供了几十款Atari游戏的统一接口。问题是：能不能把两者接起来，让一个网络只看画面和分数，学会玩游戏？

方法

网络。每帧画面转灰度、缩到84×84，把最近4帧叠成一个84×84×4的输入（单帧看不出球往哪飞）。网络是两层卷积（16个8×8卷积核步长4，32个4×4卷积核步长2，见卷积层、池化与感受野）加一个256单元的全连接层，输出层每个合法动作一个数，即该动作的Q值。一次前向就得到所有动作的Q值，选最大的即可。

目标与损失。根据Bellman方程，最优Q值应满足Q(s,a) = E[r + γ·maxₐ' Q(s',a')]。于是把右边当作“标签”，用均方误差训练：

L(θ) = E[(y − Q(s,a;θ))²]，y = r + γ·maxₐ' Q(s',a';θ_旧)

这正是时序差分与自举的平方。论文强调计算目标y时用的是上一轮迭代的参数，并在这一轮优化中保持不变，让“标签”不要随每一步梯度更新而漂移。

经验回放（来自经验回放）。智能体每走一步，就把(s, a, r, s')存进一个容量100万帧的回放池；训练时从池里随机抽32条做一个小批量。这有两个作用：相邻帧高度相关，随机抽样打破了这种相关性，更接近监督学习要求的独立同分布；每条经验可以被反复利用多次，提高了数据效率。因为训练用的数据来自旧策略，所以算法必须是离策略的（见on-policy与off-policy），Q-learning恰好满足。

其他细节。探索用ε-贪心：以ε的概率随机按键，ε在前100万帧内从1线性降到0.1（见探索与利用）。每4帧才决策一次、其间重复上一个动作，省下计算；只有Space Invaders用3帧（4帧时激光闪烁看不见），这是各游戏之间唯一不同的超参数。各游戏分数尺度差别大，训练时把正奖励一律记为+1、负奖励记为−1，这样同一学习率能通用于所有游戏。优化器是RMSProp，共训练1000万帧。

结果

在7款游戏（Beam Rider、Breakout、Enduro、Pong、Q*bert、Seaquest、Space Invaders）上，网络结构和学习算法不变（超参数只有Space Invaders的跳帧数不同），其中6款超过此前所有方法（包括使用手工特征的Arcade学习环境ALE基线），并在Breakout、Enduro和Pong上超过人类专家。例如Breakout平均168分，人类专家31分；Pong平均20分（满分21），人类−3分。人类分数是一位专家玩家每款游戏玩约两小时后的中位数。Q*bert、Seaquest、Space Invaders离人类水平还差很远，论文的解释是这几款需要跨越较长时间尺度的策略。训练中没有观察到发散，论文据此称该方法虽无理论收敛保证，却能稳定地训练大网络。

后来的发展

这篇工作坊论文发表约一个月后，Google收购了DeepMind（谷歌收购DeepMind）。2015年的DQN（Nature版）加入了周期同步的独立目标网络，扩展到49款游戏，并成为后续一切改进的基准。此后几年的很多工作都在改进它的某个部件：Double DQN修高估，优先经验回放改回放的抽样方式，Dueling DQN改网络结构，分布式RL C51把Q值换成分布，Rainbow把这些合在一起。DDPG把同样的套路搬到连续动作，A3C则尝试用并行代替回放池。AlphaGo也出自同一团队，把深度网络带进了围棋。

今天，“回放池+目标网络+TD损失”仍是多数离策略值函数类深度RL算法（包括SAC、TD3）的共同骨架。

容易误解的地方

  • 这一版没有独立的目标网络：论文只说目标用上一轮迭代的参数。“每隔C步把网络整体复制一份当目标”是2015年Nature版加上的。
  • 经验回放不是这篇发明的，而是Lin在1992年提出的；这篇把它用在深度网络+Q-learning上，并论证它能平均行为分布、避免振荡或发散（这一版没有做去掉回放的对照实验）。
  • “超过人类”只指7款中的3款，而且是单个专家玩家的分数；其余游戏差距很大。

读懂它需要的概念

马尔可夫决策过程 策略与价值函数 Bellman方程 时序差分与自举 探索与利用 on-policy与off-policy 卷积层、池化与感受野 随机梯度下降与小批量

本篇术语

  • Q值　在状态s下先做动作a、之后一直按当前策略行动，能拿到的期望折扣回报。知道了Q值，选Q最大的动作就是贪心策略。
  • ε-贪心　以概率ε随机选动作（探索），否则选当前Q值最大的动作（利用）。
  • 帧跳过　每隔k帧才让网络决策一次，中间几帧重复上一个动作，用更少的计算玩完同样长的游戏。
  • 奖励裁剪　把正奖励统一记为+1、负奖励记为−1。代价是智能体分不清大奖励和小奖励。

怎么学

先补马尔可夫决策过程、Bellman方程和时序差分与自举，在网格世界上写一个表格Q-learning。然后读原文第4节（Deep Reinforcement Learning）和算法1。动手：用PyTorch在CartPole上写一个带回放池的DQN，再换成Pong的像素输入，对比加不加回放池的训练曲线。CleanRL的dqn_atari.py是很好的单文件参考。
