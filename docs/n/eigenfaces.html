特征脸Eigenfaces

Eigenfaces for Recognition
1991论文延伸J. Cognitive Neuroscience 1991Matthew Turk, Alex Pentland · MIT Media Lab待核对
Crossref ↗在交互版中打开（演化树、学习进度）

问题

人脸识别依赖手工量取眼鼻嘴的位置和距离，对表情和光照敏感，自动化程度低。

方法

把每张脸看成一个高维向量，对一批人脸做PCA，得到少数几个主成分「特征脸」，用一张脸在这些主成分上的坐标来表示和比较。

影响

第一个能实时运行的自动人脸识别系统，让「用统计方法从整张图学表示」成为人脸识别的主流，之后的DeepFace仍沿着同一个目标。

方法

把每张对齐好的人脸灰度图展平成长向量，求所有人脸的平均脸，再对去均值的数据做PCA（见主成分分析PCA），取方差最大的若干个特征向量。这些特征向量还原成图像就像鬼影一样的人脸，因此叫特征脸。

任何一张脸都可以近似写成平均脸加上若干特征脸的线性组合，组合系数是一个很短的向量。识别时，把新脸投影到这个「脸空间」，在系数空间里找最近的已知人，距离太远则说明这不是一张脸或不在库里。

局限与后续

  • PCA只保留整体方差，光照、姿态、表情的变化往往比不同人之间的差异还大，换个光照识别率就大幅下降。
    后来针对它的工作　DeepFace FaceNet与三元组损失
  • 必须先把人脸对齐、裁剪到统一大小，对真实场景的遮挡很脆弱。
    后来针对它的工作　DeepFace

它建立在什么之上

  • 使用
    主成分分析PCA1901 · 基础
    直接把PCA用于人脸图像向量，得到特征脸。

后来的相关工作

  • 竞争
    SIFT特征1999 · 视觉
    特征脸代表“比较整张图外观”的全局路线，遇到遮挡和背景变化就失效；SIFT的局部特征路线在杂乱场景中更稳，此后十多年占据主流。
  • 改进
    FaceNet与三元组损失2015.03 · 视觉
    PCA只保留整体方差，光照、姿态、表情的变化往往比不同人之间的差异还大，换个光照识别率就大幅下降。
  • 改进
    DeepFace2014.06 · 视觉
    用深度非线性表示取代PCA线性表示，克服光照、姿态变化下的性能下降。

读懂它需要的概念

降维与PCA 特征分解与奇异值分解 向量、矩阵与张量 k近邻

本篇术语

  • 特征脸　对人脸图像做PCA得到的主成分，每一个都像一张模糊的人脸图。

怎么学

学降维与PCA，然后用scikit-learn在公开人脸数据集上做PCA并显示前几个特征脸。
