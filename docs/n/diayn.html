DIAYN无奖励技能发现

Diversity is All You Need: Learning Skills without a Reward Function
2018.02论文延伸ICLR 2019Eysenbach, Gupta, Ibarz, Levine · UC Berkeley, Google Brain待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

没有奖励函数时，智能体怎么自己学到有用的行为？此前的内在动机方法多是追求新奇，难以得到可复用的技能。

方法

让每个技能z对应一类独特的状态：最大化技能与所访问状态之间的互信息，同时用最大熵策略保证行为多样。

影响

开启了「无奖励预训练技能」一路，预训练技能可作为下游任务的初始化或分层RL的积木。

方法

设一个离散的技能变量z。训练一个判别器q(z|s)去根据当前状态猜是哪个技能；策略得到的奖励是log q(z|s) − log p(z)：如果判别器能从状态认出技能，说明这个技能走到了与众不同的地方，奖励就高。这等价于最大化技能和状态的互信息（见互信息），再加上SAC式的熵项，保证每个技能内部也尽量随机。

全程不用任务奖励。论文在模拟机器人上观察到行走、跳跃等技能自发出现；在若干基准中，有的技能不看真实奖励就解出了任务；预训练技能还能当作参数初始化，或被高层策略组合去解决稀疏奖励的复杂任务。

局限与后续

  • 技能数量要预先指定，且判别器只能区分「状态可分」的技能，不保证技能对人有意义。

  • 技能是否对下游任务有用依赖状态空间的选择，没有统一保证。

后来的相关工作

    借用技能潜变量，让多个子策略分别覆盖状态空间不同区域。

    DADS可预测技能发现2019.07 · RL

    MAVEN协同探索2019.10 · RL
    用变分下界最大化隐变量与轨迹的互信息，让不同的z对应可区分的行为，做法与DIAYN相同。
  • 延续
    ROMA涌现角色MARL2020.03 · RL
    借鉴用互信息让潜变量（技能/角色）可从行为中识别的思路。
  • 竞争
    APT主动预训练2021.03 · RL
    同为无奖励预训练：DIAYN学互相可区分的技能，APT追求状态覆盖。
  • 改进
    APS后继特征主动预训练2021.08 · RL

  • 使用
    URLB无监督RL基准2021.10 · RL
    把DIAYN作为“能力型”技能发现的代表实现进基准。

    CIC对比内在控制2022.02 · RL
    DIAYN用判别器直接猜技能，技能空间大时难学；CIC改用对比学习的互信息下界。

    LSD Lipschitz技能发现2022.02 · RL
    DIAYN的互信息目标偏好静止技能；LSD的Lipschitz约束迫使技能产生大的状态变化。

    CSD可控性感知技能2023.02 · RL
    互信息技能方法偏好简单技能；CSD通过距离动态变化持续激励更难的技能。
  • 改进
    METRA度量感知技能2023.10 · RL
    DIAYN的互信息技能没有探索动力；METRA要求技能在时间距离意义上走远，强制覆盖。
