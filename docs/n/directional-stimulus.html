定向刺激提示DSP

Guiding Large Language Models via Directional Stimulus Prompting
2023.02论文延伸NeurIPS 2023Zekun Li, Baolin Peng, Pengcheng He, Michel Galley, Jianfeng Gao, Xifeng Yan · UC圣塔芭芭拉 / 微软研究院待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

ChatGPT这类黑盒LLM只能通过API调用，无法微调；想让它在某个任务上更贴合要求（如摘要必须覆盖关键点），只能靠一条对所有输入都相同的手写提示。

方法

训练一个小的策略模型（Flan-T5、T5），为每个输入生成一条专属的“方向刺激”——关键词、对话行为或推理触发语，拼进提示里引导大模型；小模型先监督微调，再用大模型输出的得分做强化学习。

影响

只调小模型就能改善冻结的大模型：MultiWOZ上只用80段对话，ChatGPT的综合得分从68.4提到96.7（提升41.4%），展示了“小模型给大模型写提示”的路线。

方法

以新闻摘要为例：直接让ChatGPT写摘要，常常漏掉参考摘要里的要点。DSP让一个小模型先读文章，输出几个关键词（用分号隔开），提示变成“请根据文章写摘要，并包含这些关键词：……”。关键词就是方向刺激：它不替大模型写答案，只指个方向。在任务型对话里，刺激是对话行为标签，如“[hotel] [inform] choice type”；在数学推理里，刺激是为每道题挑选的触发语，如“一步一步想”的各种变体。

训练分两步。先监督微调：摘要任务用TextRank从文章抽关键词，只保留出现在参考摘要里的，作为小模型的学习目标。再用强化学习：把冻结的大模型连同评分当作环境，用PPO的NLPO变体优化小模型，奖励分别是ROUGE、BLEU或答案是否正确，并加KL惩罚防止偏离太远。

结果：CNN/DailyMail摘要上ChatGPT的ROUGE、BLEU等指标有一到两分的提升；InstructGPT零样本推理在MultiArith上从自动提示工程APE提示的81.6%提到84.0%，AQuA从34.3%提到38.6%。强化学习这一步不可少：只做监督微调时，MultiArith上只有75.2%，反而不如人写的提示，说明让小模型直接从大模型的反馈中学习“哪种提示对它最管用”才是关键。

局限与后续

  • 每个任务都要人工设计刺激的形式（关键词、对话行为、触发语），还需要标注数据或可自动计算的奖励，换任务就要重新设计、重新训练。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 强化学习阶段每一步都要调用大模型生成输出再打分，API成本高；小模型能力有限，复杂任务上给出的提示信息量不大。

它建立在什么之上

  • 使用
    PPO2017.07 · RL
    用PPO的NLPO变体，以冻结大模型输出的得分为奖励优化策略模型，并加入自适应KL惩罚。
  • 使用
    ChatGPT发布2022.11 · LLM
    以ChatGPT、Codex和InstructGPT作为只能通过API调用的黑盒大模型，参数完全不动。
  • 延续
    零样本思维链2022.05 · 推理·智能体
    把固定的“一步一步想”换成由策略模型为每道题挑选的触发语。
  • 使用
    Flan-T5与指令规模化2022.10 · LLM
    用Flan-T5-Large和T5-Base作为可训练的策略模型，为每个输入生成方向刺激。
  • 竞争
    自动提示工程APE2022.11 · 推理·智能体
    APE为整个任务搜一条通用指令；DSP为每个输入单独生成提示，推理实验中超过了APE找到的提示。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

读懂它需要的概念

策略梯度 人类反馈强化学习 预训练与微调 上下文学习与提示 文本生成的自动指标

本篇术语

  • 方向刺激　由小模型为每个输入生成、拼进提示里的提示信息，如关键词，只引导方向而不直接给出答案。
  • 策略模型　强化学习里负责做决策的模型，这里指那个负责生成方向刺激的小T5。

怎么学

先补人类反馈强化学习和PPO的基本流程 → 读原文第2节框架图和第3节摘要、对话实验 → 动手：用TextRank给几篇新闻抽关键词，比较让LLM带关键词与不带关键词写出的摘要的ROUGE。
