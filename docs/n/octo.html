Octo

Octo: An Open-Source Generalist Robot Policy
2024.05论文延伸Octo Model Team（Ghosh, Walke, Pertsch, Black, Mees, Dasari, Hejna等） · UC Berkeley / Stanford / CMU / Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

通用机器人策略需要处理不同的传感器和动作空间，并能高效微调到新机器人，但此前的大模型多为闭源。

方法

在Open X-Embodiment的80万条轨迹上训练一个Transformer策略，用扩散头输出动作，支持语言或目标图像指令，并能灵活微调。

影响

成为首批开放权重和代码的通用机器人策略，为社区提供可微调的起点。

方法

Octo的输入是任务（语言指令或目标图像）、若干相机图像和历史观测，经过Transformer骨干得到读出向量，再由一个扩散动作头（见Diffusion Policy）输出一段动作序列。设计上它把不同传感器和机器人动作空间的差异放在可替换的输入分词器和输出头里，使微调到新观测或新动作时只需新增少数模块。

预训练使用Open X-Embodiment中的80万条轨迹，摘要称这是当时最大的机器人操作数据集；微调只需很少的域内数据。

后来的发展

它给后来的OpenVLA、π0提供了开放通用策略的对照与基线，也被SIMPLER仿真评测等评测工具当作标准评测对象。

局限与后续

  • 模型较小，零样本能力有限，微调后才有较好表现。
