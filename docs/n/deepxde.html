DeepXDE库

DeepXDE: A deep learning library for solving differential equations
2019.07系统延伸Lu, Meng, Mao, Karniadakis待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

物理信息神经网络（PINN）刚出现时，每个问题都要自己写代码，也缺少与有限元等传统方法的系统对比。

方法

给出PINN的统一综述和一个Python库DeepXDE，用户按数学形式写方程、边界和初值条件即可求解正问题和反问题，并提出残差自适应加密（RAR）。

影响

成为PINN最常用的开源工具，也是教学和入门的标准入口。

方法

PINN把偏微分方程写进损失函数：网络输出作为解，通过自动微分算出方程残差，再与边界、初值条件的误差一起最小化。DeepXDE把这一过程封装起来：支持用构造实体几何描述复杂区域，支持积分微分方程、分数阶方程和随机PDE，并让反问题（已知部分测量去反推参数）和正问题用几乎相同的代码写出。

论文还提出残差自适应加密（residual-based adaptive refinement，RAR）：在残差大的地方加采样点，提高训练效率；并用五个例子展示用法，同时与标准有限元方法做了教学性比较。

后来的发展

它让物理信息神经网络PINN从一个想法变成可复用的软件，是PINN入门和教学中最常见的开源实现；与它对照的算子学习路线见DeepONet算子学习和傅里叶神经算子FNO。

局限与后续

  • PINN训练对损失权重、采样点敏感，复杂或刚性方程容易训练失败。
