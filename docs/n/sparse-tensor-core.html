2:4结构化稀疏Tensor Core

Accelerating Sparse Deep Neural Networks
2021.04论文延伸arXiv 2021Asit Mishra, Jorge Albericio Latorre, Jeff Pool, Darko Stosic, Dusan Stosic, Ganesh Venkatesh, Chong Yu, Paulius Micikevicius · NVIDIA待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

剪枝研究追求很高的稀疏度，但不规则的零分布让矩阵硬件很难真正提速，高稀疏度下精度也难以在各类模型上普遍保持。

方法

只要求一种规整的稀疏：每连续4个权重里恰好2个为零（2:4）。硬件只存非零值和2位索引，Tensor Core据此跳过一半乘法，吞吐翻倍。

影响

让稀疏在主流GPU上成为可直接使用的硬件特性，从A100起延续到之后几代NVIDIA GPU，也让“N:M稀疏”成为剪枝研究的一个常用设定。

方法

SCNN稀疏卷积加速器、EIE稀疏推理引擎一类研究加速器追求任意位置的零，代价是复杂的索引和负载不均。NVIDIA在A100的Ampere架构里换了一个思路：牺牲一些灵活性，换取硬件实现的简单。2:4模式规定权重矩阵每一行里每4个相邻元素至多2个非零，于是压缩后数据量减半，每个非零值只需2位元数据说明它在4个位置中的哪一个；Sparse Tensor Core读到元数据后，从激活中挑出对应的两个数相乘，跳过另外两个，因此在同样的时间里完成两倍的有效运算。

论文同时给出一套简单的训练流程：先正常训练稠密网络，再在每组4个权重里剪掉绝对值最小的2个，然后用原来的超参数重新训练一轮让精度恢复。作者在视觉、检测、翻译、语言模型等多种任务和模型上验证，摘要称这套流程能在满足2:4约束的同时保持精度。

局限与后续

  • 50%稀疏度是固定的，想利用更高的稀疏度拿不到更多加速；而且只对权重稀疏有效，不利用激活的动态稀疏。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 实际端到端加速常低于理论的2倍，因为只有矩阵乘法部分受益，且需要重新训练。
    本站还没有记录针对它的后续工作（不代表没有人解决）

本篇术语

  • 结构化稀疏　零值按固定规律分布（如每4个里2个为零），硬件可以按规律跳过，比任意位置的零更容易加速。
