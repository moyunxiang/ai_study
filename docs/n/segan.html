SEGAN语音增强

SEGAN: Speech Enhancement Generative Adversarial Network
2017.03论文延伸Pascual, Bonafonte, Serrà · UPC / Telefónica Research待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统语音增强（降噪）多在频谱上做，依赖一阶统计假设，只能应对有限的噪声类型。

方法

用生成对抗网络在原始波形上做端到端语音增强：生成器接收带噪波形，输出干净波形，判别器分辨真假。

影响

最早把GAN用到波形级语音增强的工作之一，之后波形域降噪与声码器GAN（如MelGAN）沿用了这一思路。

方法

当时主流降噪方法先把音频变成频谱，再估计每个频率上该保留多少（掩码或谱减），这类方法依赖对噪声的统计假设，换一种噪声就失效；深度网络虽能学更复杂的映射，但多数仍在频谱域工作。

SEGAN直接在波形上做事：生成器是一个全卷积的编码器-解码器，带跳连，输入带噪波形，输出增强后的波形；判别器同时看带噪波形和候选波形，判断后者是真实干净语音还是生成的（对抗训练，见生成对抗网络GAN）。整个模型端到端训练，不需要手工特征。

摘要写明：一个模型里同时放入28个说话人、40种噪声条件、共享参数，并在没见过的2个说话人、20种其他噪声条件的测试集上评估，客观与主观指标都证实可行。

局限与后续

  • 音质提升有限，GAN训练不稳定，生成波形时会引入听感上的伪影。
