吴恩达机器学习公开课

2011.10思想延伸Stanford在线课程 2011年秋；Coursera 2012年起Andrew Ng · Stanford University（后转至Coursera）待核对
Andrew Ng（维基百科） ↗Coursera ↗在交互版中打开（演化树、学习进度）

问题

机器学习入门材料大多是研究生课程和论文，普通工程师和学生很难系统入门，没有面向大众的完整、免费课程。

方法

把斯坦福的机器学习课程做成面向全世界的在线课：短视频讲解、测验和用Octave做的编程作业，从线性回归一直讲到神经网络。

影响

成为入门机器学习最著名的课程，学习者规模远超线下课堂，也是MOOC平台Coursera成立的起点，并培养了一代从业者。

背景

2011年秋，Stanford把包括机器学习在内的几门计算机课程免费放到网上，据维基百科，Andrew Ng和Daphne Koller在2011年秋开始在线提供斯坦福课程，随后离开斯坦福创办Coursera（2012年成立）。

方法

它是一门课，不是论文。内容主线是经典监督学习：线性回归与梯度下降、逻辑回归与正则化、神经网络与反向传播（见反向传播）、支持向量机（见支持向量机），之后讲无监督学习（k-means、PCA）、异常检测、推荐系统和大规模机器学习。讲解的重点是直觉加实用建议，例如怎样用学习曲线判断高偏差还是高方差，如何设计训练、验证、测试划分。

课程用Octave做编程作业，让学习者亲手实现梯度下降和反向传播，而不是调库。（具体课时、学习人数等数字本次会话未核对，故不引用。）

后来的发展

维基百科称Ng通过在线课程教过的学生超过800万。后续他又推出了深度学习系列课程，影响延续至今；这一课程让“先打好基础再动手实现”成为许多人进入机器学习的标准路径。

读懂它需要的概念

线性回归 梯度下降 逻辑回归 多层感知机 泛化与过拟合

怎么学

如果你还没系统学过机器学习，这是最友好的起点：先看线性回归与逻辑回归两周，再做反向传播作业。学完后可读《统计学习基础》ESL补统计理论，再读《深度学习》花书进入深度学习。
