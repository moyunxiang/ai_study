缓存语言模型

A Cache-Based Natural Language Model for Speech Recognition
1990.06论文延伸IEEE TPAMI 1990Roland Kuhn, Renato De Mori · 麦吉尔大学待核对
DOI ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

n-gram语言模型的概率是在整个训练语料上数出来的固定值，看不到「这篇文章刚才提过什么词」：一个词在文中出现过一次，接下来再出现的可能性会大增，但n-gram模型无法利用这种短期波动。

方法

在三元语法式的马尔可夫模型之外加一个「缓存」：记录最近出现过的词及其频率，用缓存里的频率估计一个随文本变化的分布，再和静态模型的概率插值。

影响

缓存模型成为语言模型自适应的经典做法，在语音识别中长期沿用；它指出的「近期出现的词更可能再出现」，后来被神经缓存语言模型和指针机制以连续向量的形式重新实现。

方法

n-gram平滑一类的n-gram模型只看前面一两个词，概率表在训练后固定不变。Kuhn和De Mori观察到文本中词的使用有很强的局部性：一篇讲股票的文章里，「股价」一旦出现，后面多半还会出现。

他们的模型由两部分组成：一个基于词性的三元马尔可夫成分（先预测下一个词的词性，再预测这个词性下的具体词），以及一个缓存成分，为每个词性维护最近若干个词的频率表。最终概率是两者的加权插值，缓存成分随着读入文本不断更新，因此模型在一篇文档内部会逐渐适应它的用词。

论文的应用场景是语音识别：识别器要在多种把声学输入切分成词串的候选之间选择，语言模型给出的先验越准，错误越少。后续工作把缓存推广到不分词性的一元缓存、带衰减的缓存和主题缓存，神经缓存语言模型则把缓存里存的东西换成了RNN的隐状态。

局限与后续

  • 缓存只记录词频，不区分词出现时的上下文，对「同一个词在不同语境下」无法区别对待。

本篇术语

  • 语言模型自适应　让语言模型的概率随当前文档、话题或说话人而调整，而不是对所有文本都用同一套固定概率。
  • 插值　把两个模型给出的概率按权重相加，如P = λ·P_cache + (1−λ)·P_ngram。

怎么学

先读n-gram与平滑和n-gram平滑 → 读维基百科「Cache language model」条目了解变体 → 动手：在一个新闻语料上给三元模型加一个最近500词的一元缓存，调插值权重，比较困惑度。
