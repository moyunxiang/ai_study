折扣CFR（DCFR）

Solving Imperfect-Information Games via Discounted Regret Minimization
2018.09论文延伸AAAI 2019Noam Brown, Tuomas Sandholm · 卡内基梅隆大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

CFR+是求解大型不完全信息博弈最快的算法，长期没有别的算法能稳定超过它；但它和剪枝、采样等加速技巧不兼容，早期迭代里的糟糕遗憾值也会拖慢收敛。

方法

给不同迭代的遗憾值打折：越早的迭代权重越小，正负遗憾可以用不同的折扣；输出策略时也对迭代加权平均。

影响

其中的Discounted CFR（DCFR）在所有测试博弈里都超过CFR+，成为后来扑克求解器和Deep CFR类方法常用的默认变体。

方法

反事实遗憾最小化CFR在每个信息集上累计每个动作的「反事实遗憾」（如果当时一直选这个动作会多赚多少），再按正遗憾的比例决定下一轮策略，最终输出所有迭代策略的平均。问题是：早期迭代的策略很差，留下的大额遗憾要很久才被冲淡。

本文系统试了几类改动：按迭代次数给累计遗憾打折（有时对正、负遗憾用不同折扣）、用不同方式给迭代加权求平均策略、换用非标准的遗憾最小化器、利用「乐观遗憾匹配」。DCFR是其中代表：在第t轮，把累计的正遗憾乘以 t^α/(t^α+1)，负遗憾乘以 t^β/(t^β+1)，平均策略的贡献乘以 (t/(t+1))^γ，文中推荐 α=1.5、β=0、γ=2。

摘要称，其中一个变体在所有测试博弈（包括大规模的真实场景）里都超过了CFR+；并且与CFR+不同，许多新变体能与现代剪枝技术兼容，其中一个还能与博弈树采样兼容。

局限与后续

  • 折扣参数是手工挑选的，在不同博弈里最优取值不同，缺少自适应的选择方法。

它建立在什么之上

  • 延续
    反事实遗憾最小化CFR2007 · RL
    保留反事实遗憾的框架，只改变各次迭代遗憾和策略的加权方式。
  • 延续
    蒙特卡洛CFR（MCCFR）2009.12 · RL
    其中一个变体能与博弈树采样结合，延续蒙特卡洛CFR的方向。
  • 改进
    CFR+2014.07 · RL
    在所有测试博弈中收敛更快，并且能与CFR+不兼容的剪枝技术一起用。

后来的相关工作

  • 改进
    Deep CFR2018.11 · RL
    仍需遍历或采样整棵博弈树，规模大到无法存表时要配合抽象或神经网络近似。
  • 竞争
    预测版CFR+2020.07 · RL
    DCFR靠折扣早期遗憾加速；PCFR+靠对下一轮收益的预测加速，在多数非扑克博弈上更快，在部分扑克上不如DCFR。
