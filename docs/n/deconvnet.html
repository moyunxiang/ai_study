DeconvNet反卷积分割

Learning Deconvolution Network for Semantic Segmentation
2015.05论文延伸ICCV 2015Hyeonwoo Noh, Seunghoon Hong, Bohyung Han · 浦项工科大学（POSTECH）待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

全卷积网络FCN只用一层双线性上采样把粗糙的得分图放大回原图，物体细节和边界丢失严重；感受野固定，过大或过小的物体容易被切碎或漏掉。

方法

在VGG-16卷积部分后面接一个镜像对称、同样深的“反卷积网络”：用记住最大值位置的反池化层和可学习的反卷积层一级级恢复分辨率，并对每个候选框分别预测掩码再合并。

影响

把语义分割做成对称的编码器-解码器结构，和同期的U-Net、后来的SegNet一起确立了“逐级上采样恢复细节”的解码器设计。

方法

FCN的问题是解码太浅：最后的特征图只有原图的1/32大小，一次放大32倍，边界自然模糊。DeconvNet把解码部分也做深：编码器是VGG的13个卷积层，解码器是与之镜像的一串反池化和反卷积层。

反池化的做法是：编码器每次做最大池化时记下每个窗口里最大值来自哪个位置（“开关”），解码时把值放回那个位置、其余填0，于是物体的空间结构被原样还原；随后的反卷积层（转置卷积）把稀疏的图填密。这样网络逐级从7×7恢复到原分辨率。

为了照顾不同大小的物体，论文不是整图推理，而是对每张图先取约几十个物体候选框，每个框缩放到固定大小单独分割，再把所有结果合起来。摘要报告在PASCAL VOC 2012上与FCN集成后达到72.5%，是当时不用外部数据的方法里最好的。

后来SegNet沿用“记住池化位置”的反池化但去掉了候选框，DeepLabv3+等则改用轻量解码器加空洞卷积，逐框推理的做法没有流传下来。

局限与后续

  • 对每个候选框单独跑一遍分割网络，推理很慢，而且要靠和FCN集成才拿到最好成绩。
    后来针对它的工作　SegNet DeepLabv3+
  • 解码器参数量与编码器一样大，训练要分两阶段、依赖批归一化才能收敛。
    后来针对它的工作　DeepLabv3+

它建立在什么之上

  • 使用
    VGG2014.09 · 视觉
    编码器直接取VGG-16的13个卷积层，解码器与之镜像对称。
  • 竞争
    U-Net2015.05 · 视觉
    同年的U-Net用跳连把编码器特征直接拼到解码器；DeconvNet不用跳连，只靠池化位置还原结构，后来跳连路线更普及。
  • 延续
    卷积网络可视化2013.11 · 视觉
    反池化时记录最大值位置的“开关”做法来自卷积网络可视化工作，这里把它变成可训练的解码器。
  • 改进
    全卷积网络FCN2014.11 · 视觉
    FCN一次32倍上采样导致边界粗糙；DeconvNet用深层反池化加反卷积逐级恢复细节。

读懂它需要的概念

分类、检测、分割 卷积层、池化与感受野 编码器-解码器 IoU与mAP

本篇术语

  • 反池化（unpooling）　最大池化的近似逆操作：把值放回池化时记下的最大值位置，其余位置填0。
  • 反卷积（转置卷积）　把卷积的输入输出关系倒过来用，让特征图变大的一种可学习上采样层。

怎么学

先看FCN的上采样方式，再读本文第3节的反池化与反卷积示意图；用PyTorch的MaxPool2d(return_indices=True)和MaxUnpool2d试一次池化再还原。
