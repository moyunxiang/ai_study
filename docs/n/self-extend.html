SelfExtend免训练扩上下文

LLM Maybe LongLM: Self-Extend LLM Context Window Without Tuning
2024.01论文延伸ICML 2024Hongye Jin, Xiaotian Han, Jingfeng Yang, Zhimeng Jiang, Zirui Liu, Chia-Yuan Chang, Huiyuan Chen, Xia Hu · 德州农工大学、莱斯大学等待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

用RoPE训练的LLM一旦输入超过训练长度，就会遇到没见过的相对位置，输出迅速崩坏；位置插值、YaRN等方法仍需要一段长文本微调。

方法

推理时把远处token的相对位置做整除压缩（分组注意力），近处仍用原始位置（邻域注意力），让模型看到的相对位置始终落在训练范围内，完全不需要微调。

影响

给出一个几行代码、零训练的上下文扩展办法，常作为免训练长上下文方法的基线，被llama.cpp等推理框架实现。

方法

背景：旋转位置编码RoPE把位置信息编码进查询和键的旋转角度里，注意力分数只依赖相对距离。作者认为LLM失败于长输入的主要原因是遇到了训练时从没见过的大相对距离（分布外位置），而不是模型本身缺乏处理长文本的能力。位置插值扩上下文把所有位置按比例压缩来解决，但压缩会让近处的细粒度位置变模糊，所以需要再微调。

SelfExtend在推理时把注意力分两层：对距离在邻域窗口W以内的token，用原始相对位置，保证局部语序精确；对更远的token，把位置整除一个分组大小G（p′ = ⌊p / G⌋），相当于把G个相邻位置当成同一个位置，再整体平移使两段衔接起来。这样，最远的相对距离被压缩到约 W + (L − W)/G，只要不超过训练长度就不会出现分布外位置。两种注意力都直接用原模型的权重计算，按距离拼接成最终的注意力矩阵。

摘要称只需少量代码修改，在多个长文本基准上有效扩展了现有LLM的上下文窗口。

局限与后续

  • 远处位置被整除后，同一组内的token顺序信息丢失，需要精确定位远处细节的任务会受影响；而且推理时要算两套注意力，与FlashAttention等融合内核的配合需要额外实现。

本篇术语

  • 分组注意力　把远处token的位置整除分组大小G，G个相邻位置共用一个位置编号，从而压缩最大相对距离。

怎么学

先读旋转位置编码RoPE和位置插值扩上下文；读本文关于分布外位置的论证和两层注意力的示意图；动手：在一个4k上下文的开源模型上实现整除位置映射，测8k到16k长文本的passkey检索。
