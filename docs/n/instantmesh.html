InstantMesh单图生网格

InstantMesh: Efficient 3D Mesh Generation from a Single Image with Sparse-view Large Reconstruction Models
2024.04论文延伸Jiale Xu, Weihao Cheng, Yiming Gao, Xintao Wang, Shenghua Gao, Ying Shan · 腾讯ARC Lab / 上海科技大学待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

单图生成三维时，大重建模型LRM式前馈重建输出三平面加体渲染，要再提取网格、几何偏软；体渲染训练又贵，难以利用深度、法线等几何监督。

方法

把现成的多视图扩散模型（Zero123++多视图基座）与基于LRM结构的稀疏视图重建模型串起来，并在重建器末端接入可微的等值面提取模块，直接在网格表示上优化，用深度和法线做额外监督。

影响

论文称10秒内即可从一张图生成多样的三维资产，并开源了全部代码、权重和演示，成为2024年图生3D最常用的开源流水线和基线之一。

方法

InstantMesh分两段：

  • 多视图生成：输入一张物体图片，用Zero123++多视图基座生成固定相机位姿下的6张多视图图像，并对白色背景做处理。
  • 稀疏视图重建：一个沿用大重建模型LRM结构的Transformer重建器，以这6张图为输入，输出三平面特征。与原版LRM不同，训练分两阶段：先像LRM一样用体渲染（NeRF式）训练；再把表示切换为网格——用可微的等值面提取模块（FlexiCubes）从三平面解码出的有符号距离场里直接提出三角网格，再用可微光栅化渲染图像、深度和法线，与真值比较。

直接在网格上优化有两个好处：光栅化比体渲染省算力，训练可以用更高分辨率的监督；同时深度和法线这类几何监督可以直接加上，得到更光滑、更准确的表面。最终模型一次前向就输出可用的带颜色网格。论文在公开数据集上与同期图生3D方法比较，报告在定性和定量指标上都明显领先。

局限与后续

  • 质量受上游多视图扩散一致性的限制，背面和细小结构常出错，纹理也只是逐顶点颜色而非高分辨率贴图。

读懂它需要的概念

三维表示：体素、点云、网格、隐式场 相机模型与多视图几何 体渲染 Transformer层的结构 扩散：前向加噪与反向去噪

本篇术语

  • 稀疏视图重建　只用少数几个视角（如6张）的图像恢复出完整三维物体，而不是像传统多视图重建那样用几十上百张照片。

怎么学

先读LRM和Zero123++ → 读本文第3节两阶段训练与等值面提取 → 用开源代码从一张图生成网格并检查法线质量。
