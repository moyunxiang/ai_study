Pharaoh短语解码器

Pharaoh: A Beam Search Decoder for Phrase-Based Statistical Machine Translation Models
2004.09系统延伸AMTA 2004Philipp Koehn · 麻省理工学院待核对
Springer ↗在交互版中打开（演化树、学习进度）

问题

短语统计翻译模型已经提出，但要把它真正用起来，需要一个能在指数多的切分、翻译和调序组合里快速找出高分译文的解码器，当时没有公开可用的高效实现。

方法

Pharaoh实现了短语翻译的集束搜索：从左到右逐步生成译文，每步选一段尚未翻译的源语言短语加上它的一个译法，把覆盖了同样多源词的假设放进同一个栈里按得分加未来代价剪枝，并能输出词图供重打分。

影响

作为免费提供的短语翻译解码器，被大量研究组用作实验基线；它的栈解码算法、未来代价估计和词图输出直接被开源工具包Moses继承。

方法

短语统计机器翻译把翻译看成：把源句切成若干短语，每个短语换成目标语言短语，再调整顺序；得分由对数线性翻译模型式的若干特征加权组合，包括短语翻译概率、语言模型、调序惩罚和长度惩罚。可能的组合数随句长指数增长，必须靠启发式搜索。

Pharaoh的解码过程：一个假设记录已经覆盖了哪些源词、已生成的译文和当前得分。每次扩展从未覆盖的源词里选一段连续短语，加上短语表里的一个译法。所有覆盖了k个源词的假设放进第k个栈，每个栈只保留得分最高的若干个（集束搜索），并合并最后几个目标词相同、覆盖相同的假设（这是动态规划式的重组）。只比当前得分会偏向先翻译容易的部分，所以每个假设还要加上对剩余源词的未来代价估计。搜索完成后可以输出译文的格子（词图）或n-best列表，供最小错误率训练MERT调参或更复杂的模型重打分。

摘要称它是一个免费提供的短语翻译解码器，实现了带词图生成和外部组件XML标注的高效动态规划搜索算法。

读懂它需要的概念

动态规划 解码：贪心、束搜索、温度与top-p 语言模型 噪声信道与词对齐 时间与空间复杂度

本篇术语

  • 栈解码　按已翻译的源词数把部分译文假设分组，每组只保留得分最高的若干个，逐组向后扩展。
  • 未来代价　对尚未翻译的源词部分预估一个最低代价，加到当前得分上，使覆盖不同部分的假设能公平比较。

怎么学

先读短语统计机器翻译的讲解 → 读Koehn《Statistical Machine Translation》教材第6章「解码」 → 动手：用Moses在一个小的平行语料上训练短语表，调大调小栈大小，观察BLEU和解码时间的变化。
