《深度学习》花书

Deep Learning
2016.11思想重要MIT Press 2016Ian Goodfellow, Yoshua Bengio, Aaron Courville · Google Brain / OpenAI / 蒙特利尔大学待核对
官方网站（全书免费在线阅读） ↗MIT Press ↗中文版翻译项目 ↗在交互版中打开（演化树、学习进度）

问题

深度学习爆发后，知识散落在论文、课程讲义和博客里；已有的机器学习教材（ESL、PRML）几乎不讲卷积网络、正则化技巧、优化细节这些深度学习的实际做法。

方法

写一本从数学基础一路讲到研究前沿的系统教材：先补线性代数、概率、数值计算和机器学习基础，再讲现代深度网络的实践，最后讲表示学习、概率模型和深度生成模型。

影响

第一本全面的深度学习教科书，全书在线免费阅读，成为全球课程和自学的标准参考；中文版因封面被称为“花书”，是很多中文读者的入门读物。

背景

到2016年，深度学习已经在视觉、语音、翻译上全面领先，大量工程师和学生想入门，但能用的材料很零散：Nature综述《Deep Learning》只有9页，斯坦福CS231n等课程聚焦视觉，经典教材《统计学习基础》ESL、《模式识别与机器学习》写于深度学习复兴之前，对Dropout、Batch Normalization、卷积网络、LSTM这些当时的标准工具着墨很少。另一方面，很多实用技巧（初始化、学习率、调试方法）只存在于研究者的经验中，从未被系统整理。作者中Bengio是神经网络领域的长期研究者，Goodfellow是生成对抗网络GAN的提出者，Courville长期研究概率模型，三人都出自蒙特利尔大学的研究组。

方法

全书约800页、20章，分三部分：

  • 第一部分 应用数学与机器学习基础（第2–5章）：线性代数、概率与信息论、数值计算（上溢下溢、梯度方法、约束优化）、机器学习基础（容量、过拟合、偏差-方差权衡、最大似然、贝叶斯统计）。目标是让只学过大学数学的读者补齐前置知识。
  • 第二部分 现代实用深度网络（第6–12章）：前馈网络与反向传播、深度学习的正则化（权重衰减、数据增强、提前停止、dropout、对抗训练）、训练深度模型的优化（SGD、动量、自适应学习率、批归一化、初始化）、卷积网络、循环与递归网络（含LSTM、梯度裁剪），以及“实践方法论”和应用（视觉、语音、NLP）。这是全书最常被阅读的部分。
  • 第三部分 深度学习研究（第13–20章）：线性因子模型、自编码器、表示学习、结构化概率模型、蒙特卡洛方法、配分函数、近似推断、深度生成模型（玻尔兹曼机、变分自编码器VAE、GAN等）。

书中统一了数学记号，网站另提供各章讲座幻灯片和练习。出于与出版社的合同，网站只提供HTML版，不提供PDF。

结果

MIT Press于2016年11月出版（电子版11月10日、精装版11月18日），约800页，含66幅彩色和100幅黑白插图。在线版在出版前就已完整公开并保持免费；人民邮电出版社购买了中文版权，中文版由社区协作翻译、校对后出版。

后来的发展

这本书确立了“深度学习课程”的标准大纲：许多大学课程的前置数学、正则化、优化、卷积、循环网络这一顺序都与它相近，它的记号也被大量论文和讲义沿用。它的局限是写作时间：成书时还没有Transformer，因此对注意力只有简短介绍，对BERT、GPT-3式大规模预训练、扩散模型都没有涉及；全书偏重理论和概念，没有配套代码。后来的《动手学深度学习》用可运行的代码讲同样的内容并持续更新到Transformer和大模型，Karpathy《Zero to Hero》等视频课程则从零手写代码讲到GPT。

    Batch Normalization2015.02 · 基础
    第8章在优化部分讲解批归一化，把它列为训练深度模型的标准工具。
  • 使用
    Dropout2012.07 · 基础
    第7章把dropout作为深度学习正则化的核心方法之一，详细讲解其集成解释和实现。
  • 延续
    Nature综述《Deep Learning》2015.05 · 基础
    把Nature综述9页的主线扩展成约800页的系统教材，从数学基础一直讲到研究前沿。
  • 改进
    《统计学习基础》ESL2001 · 基础
    沿用统计学习的基本概念（容量、偏差-方差、正则化），但把重点从线性模型和核方法转到深度表示学习。
  • 竞争
    《模式识别与机器学习》2006 · 基础
    PRML以贝叶斯视角统一传统机器学习，神经网络只占一章；本书以深度网络为中心，成为新一代的标准教材。
  • 改进
    吴恩达机器学习公开课2011.10 · 基础
    内容止于传统机器学习与浅层神经网络，不含卷积、循环网络和Transformer。

读懂它需要的概念

向量、矩阵与张量 随机变量与概率分布 导数、偏导与梯度 最大似然估计 泛化与过拟合 反向传播

本篇术语

  • 花书　中文读者对本书中文版的昵称，来自其色彩斑斓的封面图案。
  • 配分函数　概率模型中把未归一化的概率变成合法分布所需的归一化常数，通常是对所有可能状态求和，难以直接计算。

怎么学

不必从头读到尾。数学基础薄弱的读者先读第2–5章；想快速上手的读者重点读第6–9章和第11章“实践方法论”；对生成模型感兴趣再读第14章和第20章。搭配《动手学深度学习》或PyTorch教程动手实现每章的模型，读到第10章后转去学习Transformer补上书中缺失的部分。
