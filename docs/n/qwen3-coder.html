Qwen3-Coder

Qwen3-Coder: Agentic Coding in the World
2025.07模型延伸Qwen团队 · 阿里巴巴待核对
官方博客 ↗Qwen Code ↗在交互版中打开（演化树、学习进度）

问题

开源代码模型能补全和写函数，但在要读仓库、调工具、多轮修改的智能体式编程上与闭源模型差距大。

方法

480B总参、35B激活的MoE代码模型，7.5T token预训练（七成是代码），再用大规模执行反馈RL和2万个并行环境的长程智能体RL后训练。

影响

发布时开源模型中SWE-bench Verified成绩最好的一档，配套开源命令行工具Qwen Code，带动开源模型进入编码智能体场景。

方法

Qwen2.5-Coder已经是强力开源代码模型，但主要面向补全和单轮生成。2025年7月22日发布的Qwen3-Coder基于Qwen3混合思考的MoE架构，旗舰版Qwen3-Coder-480B-A35B-Instruct总参480B、每个token激活35B，原生上下文256K，用YaRN可外推到100万token，以便一次读入整个代码仓库。

预训练用7.5T token，其中代码占70%。后训练有两部分：一是代码RL，在大量真实编程任务上按执行结果给奖励，并自动扩充测试用例；二是长程智能体RL，让模型在多轮中调用工具、与环境交互，团队在阿里云上搭建了可同时运行2万个独立环境的系统来做这件事。官方称它在不使用测试时扩展的情况下，取得了开源模型中最好的SWE-bench Verified成绩。

同时开源的Qwen Code是从Gemini CLI改出来的命令行编码工具，针对Qwen3-Coder调整了提示和函数调用。
