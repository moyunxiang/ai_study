伪计数探索

Unifying Count-Based Exploration and Intrinsic Motivation
2016.06论文延伸NeurIPS 2016Bellemare, Srinivasan, Ostrovski, Schaul, Saxton, Munos · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

表格RL里按访问次数给奖励（访问越少越新奇）很有效，但Atari里状态是像素，几乎不会精确重复，计数永远是0或1。

方法

用一个密度模型估计观测的概率，从模型在一次访问前后概率变化推出「伪计数」，再把伪计数转成内在奖励。

影响

第一次在像素输入的Atari上让计数式探索奏效，在DQN几乎学不会的Montezuma's Revenge上取得明显进展。

方法

思路是：如果一个状态被访问过N次，那么再看到它时，密度模型给它的概率会按 ρ = N/n 上升。反过来，从模型在看到某观测x前后的概率 ρ(x) 与 ρ′(x)，就能解出伪计数 N̂ = ρ(1−ρ′)/(ρ′−ρ)。这样任何能给出概率的模型（论文用的是对像素做的简单密度模型）都能产生计数，并且相似的画面共享计数，能泛化。

伪计数 N̂ 被转成内在奖励，大致与 1/√N̂ 成正比，加到游戏本身的奖励上给DQN类智能体。摘要称这在多个难探索的Atari游戏上显著改进了探索，包括出了名困难的Montezuma's Revenge。

局限与后续

  • 伪计数依赖密度模型的质量，用像素级模型得到的新奇性有时并不对应有意义的游戏进展。

它建立在什么之上

  • 改进
    Q-learning1992 · RL
    要求每对状态动作被无限次尝试，但没有说如何高效探索，大状态空间里学得很慢。
  • 延续
    DQN（Nature版）2015.02 · RL
    在DQN上叠加探索奖励，解决其ε贪心探索无法应对稀疏奖励的问题。
  • 使用
    Schmidhuber人工好奇心1991 · RL
    沿用内在动机思想：把新奇性作为额外奖励。
  • 改进
    E3与PAC探索理论1998 · RL
    算法与界限的多项式很大，实际效率低，不能直接用于大状态空间。
  • 改进
    UCRL2遗憾界2008 · RL
    只适用于小规模的表格MDP，不能直接处理深度RL中的函数近似。
  • 改进
    Thompson采样的复兴2011 · RL
    需要能处理的后验分布；在复杂模型（如深度网络）里后验难以精确求得。

后来的相关工作

  • 竞争
    好奇心模块ICM2017.05 · RL
    同为解决稀疏奖励的内在动机：伪计数奖励“没去过的状态”，ICM奖励“预测不准的转移”，后者对高维像素更自然。
  • 竞争
    后见经验回放HER2017.07 · RL
    同为解决稀疏奖励：计数探索鼓励去新状态，HER改写学习目标；在机械臂任务上前者几乎无效。
  • 竞争
    随机网络蒸馏RND2018.10 · RL
    伪计数用密度模型估计访问次数；RND用蒸馏误差隐式地起到计数作用，实现更简单、在Montezuma上分数更高。
  • 改进
    Go-Explore2019.01 · RL
    指出伪计数等内在奖励方法会“脱离”已发现的前沿，用显式档案代替会被消耗的内在奖励。
  • 竞争
    捉迷藏中的涌现工具使用2019.09 · RL
    论文把基于计数的内在动机作为对照：在同一环境中它产生的物体交互远少于竞争，迁移测试也略差。
  • 改进
    Agent572020.03 · RL
    仍然解决不了最稀疏的游戏，需要探索更长的动作序列。
