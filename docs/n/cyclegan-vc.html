CycleGAN-VC非平行变声

Parallel-Data-Free Voice Conversion Using Cycle-Consistent Adversarial Networks
2017.11论文延伸EUSIPCO 2018Takuhiro Kaneko, Hirokazu Kameoka · NTT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

传统语音转换（把A的声音变成B的声音、内容不变）需要两人朗读同一批句子的平行数据，并逐帧对齐后学习映射；统计模型的输出还会被过度平滑，听起来发闷。

方法

借用图像领域的CycleGAN：同时学习A→B和B→A两个映射，用对抗损失让转换结果像目标说话人，用循环一致性损失（转过去再转回来要还原）保证内容不变，从而只需两人各自的非平行录音。

影响

CycleGAN-VC开启了无平行数据语音转换的GAN路线，后续CycleGAN-VC2/VC3、StarGAN-VC等都在它的基础上改进，是自编码器类方法（如AutoVC）流行之前的主要基线。

方法

此前主流的语音转换基于高斯混合模型（GMM）：先用动态时间规整DTW把两个人朗读同一句话的特征逐帧对齐，再学习从A的特征到B的特征的映射。收集平行数据成本高，而且GMM按均值回归，输出的频谱参数被过度平滑。

CycleGAN-VC把图像翻译方法CycleGAN搬到语音特征序列上（输入是梅尔倒谱等声学特征，再由声码器合成）。它训练两个生成器G_A→B、G_B→A和两个判别器（见生成对抗网络GAN）。损失有三项：对抗损失让G_A→B的输出骗过B的判别器，因而具有B的声音特点，也缓解了过度平滑；循环一致性损失 ‖G_B→A(G_A→B(x)) − x‖ 保证转换没有丢掉语言内容；恒等映射损失要求把B的语音输入G_A→B时尽量不变，帮助保持语言信息。生成器使用门控卷积（与门控卷积语言模型GLU的门控线性单元相同），能捕捉特征的时间结构。

摘要报告：客观指标上，转换后的特征序列在全局方差和调制谱上接近自然语音；主观评测中，它的质量与一个在更有利条件下（使用平行数据、且数据量为两倍）训练的GMM方法相当。

局限与后续

  • 每一对说话人都要单独训练一个模型，无法转换到训练时没见过的说话人。

  • 使用
    生成对抗网络GAN2014.06 · 生成
    用对抗训练让转换结果具有目标说话人的分布特点，缓解统计方法的过度平滑。
  • 改进
    动态时间规整DTW1978.02 · 语音
    传统方法要靠DTW对齐平行语句；CycleGAN-VC不需要平行数据和对齐。
  • 使用
    CycleGAN2017.03 · 生成
    直接把CycleGAN的双向映射和循环一致性损失用到语音特征序列上。
  • 使用
    门控卷积语言模型GLU2016.12 · NLP
    生成器采用门控线性单元的一维卷积结构。

读懂它需要的概念

对抗训练 卷积层、池化与感受野 门控机制 波形、频谱与梅尔谱 声码器与音频编解码

本篇术语

  • 语音转换（VC）　保持说话内容不变，把一个人的声音变成另一个人的声音。
  • 非平行数据　两个说话人的录音内容各不相同，无法逐句对应。
  • 过度平滑　统计模型输出接近平均值，频谱细节被抹平，合成声音发闷、不自然。
