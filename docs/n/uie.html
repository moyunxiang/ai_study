UIE通用信息抽取

Unified Structure Generation for Universal Information Extraction
2022.03论文延伸ACL 2022Yaojie Lu（陆垚杰）, Qing Liu, Dai Dai, Xinyan Xiao, Hongyu Lin, Xianpei Han（韩先培）, Le Sun（孙乐）, Hua Wu（吴华）· 中国科学院软件研究所、百度待核对
arXiv ↗ACL Anthology ↗在交互版中打开（演化树、学习进度）

问题

实体识别、关系抽取、事件抽取、情感抽取各有不同的目标结构（片段、三元组、事件框架、方面—观点对）和不同的模式（类型集合），每个任务甚至每个数据集都要专门设计模型，知识无法在任务之间共享，低资源场景尤其吃亏。

方法

把所有信息抽取任务统一为“文本到结构”的生成：用一种结构化抽取语言（SEL）把任何抽取结果写成统一的括号结构，再用“结构化模式提示”（SSI）在输入前告诉模型这次要抽哪些类型；在大规模异构数据上预训练一个T5式的文本到结构模型。

影响

一个模型在实体、关系、事件、情感4类任务、13个数据集上，在有监督、低资源和少样本设定下都取得当时最好结果；UIE（及百度PaddleNLP中的中文UIE）被大量用于工业界的通用抽取，也成为大模型时代“指令式信息抽取”的直接前身。

背景

信息抽取长期按任务分治：序列标注做NER（BiLSTM-CRF序列标注）、PURE流水线实体关系抽取这类流水线做实体关系、专门的事件抽取模型等。MRC-NER阅读理解式实体识别用问答形式统一平面与嵌套NER，W2NER词对关系统一NER用词对网格统一多种NER，但都局限于单一任务。T5表明一切NLP任务都可以写成文本到文本，生成式方法开始被用于抽取，但输出格式各不相同。

方法

结构化抽取语言（SEL）：任何抽取结果都由“定位片段 + 关联关系”组成，写成嵌套括号：

((人物: 史蒂夫·乔布斯 (工作于: 苹果)) (组织机构: 苹果))

实体是 (类型: 片段)，关系与事件论元作为内层的 (关系名: 片段) 挂在头实体或触发词下。这样实体、关系、事件和情感的输出共享同一种语法。

结构化模式提示（SSI）：在输入文本前加上本次要抽取的模式，例如 [spot] 人物 [spot] 组织机构 [asso] 工作于 [text] 原文…，其中[spot]列出要定位的类型，[asso]列出要关联的关系或角色。模型据此“按需”生成对应结构，同一个模型可以服务不同任务和类型集合。

预训练：在T5基础上，用三类数据预训练：维基百科与Wikidata远程对齐得到的文本—结构平行数据（学习文本到结构的映射），只有结构的数据（学习SEL语法，类似结构语言模型），只有文本的数据（保留语言能力，用掩码片段预测）。预训练时还加入“拒绝”机制：在SSI中混入文本里不存在的类型，训练模型对其生成空结果，减少幻觉式抽取。下游任务只需用对应的SSI微调。

结果

UIE在4类信息抽取任务（实体、关系、事件、情感）的13个数据集上，在有监督、低资源和少样本各种设定下都取得最好成绩（arXiv摘要），验证了统一建模的有效性、通用性和可迁移性。

后来的发展

UIE之后，InstructUIE、USM、基于大模型的指令式抽取（如用GPT类模型配合模式描述做零样本抽取）都延续了“统一结构表示加模式提示”的思路；百度的中文UIE模型因开箱可用而在工业界广泛使用。大模型时代，信息抽取越来越多地被当作带约束的生成任务处理，UIE是这一转变的代表节点。

它建立在什么之上

  • 使用
    T52019.10 · LLM
    以T5式的编码器—解码器为基础，把抽取写成文本到结构的生成。
  • 延续
    MRC-NER阅读理解式实体识别2019.10 · NLP
    MRC-NER用问题告诉模型抽哪种类型；UIE的结构化模式提示把这一思想推广到关系、事件、情感等所有抽取任务。
  • 改进
    PURE流水线实体关系抽取2020.10 · NLP
    PURE等方法为每个抽取任务设计专门的流水线；UIE用统一的结构语言和模式提示让一个模型覆盖多种任务。
  • 竞争
    W2NER词对关系统一NER2021.12 · NLP
    W2NER在判别式框架内统一各类NER；UIE走生成路线，统一的范围扩大到多种抽取任务。

读懂它需要的概念

编码器-解码器 预训练与微调 自回归生成 特殊token 零样本与少样本

本篇术语

  • 结构化抽取语言　UIE定义的一种括号式线性化格式，把实体、关系、事件等不同抽取结果写成统一的文本。
  • 模式提示　放在输入前面、列出本次要抽取的实体类型和关系类型的提示，相当于告诉模型“抽什么”。
  • 远程监督对齐　把知识库中的三元组自动对齐到提到相关实体的句子，得到大量带噪声的文本—结构训练数据。

怎么学

先读T5了解文本到文本框架，再读MRC-NER阅读理解式实体识别 → 读本文第3节SEL与SSI、第4节预训练 → 动手：用PaddleNLP中的UIE，对一段新闻分别给出“人物/组织/工作于”和“事件类型/时间/地点”两套模式，观察同一模型的不同输出。
