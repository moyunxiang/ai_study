Stanza多语言工具包

Stanza: A Python Natural Language Processing Toolkit for Many Human Languages
2020.03系统延伸ACL 2020 系统演示Peng Qi, Yuhao Zhang, Yuhui Zhang, Jason Bolton, Christopher D. Manning · 斯坦福大学待核对
arXiv ↗官网 ↗在交互版中打开（演化树、学习进度）

问题

CoreNLP等成熟工具包基于Java和手工特征，只对少数几种语言提供高质量模型；研究者想对几十种语言做分词、词性、依存分析，往往要拼凑多个不兼容的工具。

方法

用同一套与语言无关的全神经网络流水线，从字符级分词一直做到依存分析和命名实体识别，在Universal Dependencies等112个数据集上分别训练，覆盖66种语言，并提供Python接口和调用CoreNLP的桥接。

影响

成为多语言句法分析最常用的开源工具之一，在多数语言上达到有竞争力的效果；它让「对任意语言快速得到UD风格的分析」变成一行Python代码，被语言学研究和跨语言NLP广泛采用。

背景

Stanford CoreNLP（2014）把词性、句法、NER、共指等模块集成在一起，是英语NLP的标准工具，但以Java为主、多数模块只支持英语和少数大语种。Universal Dependencies为一百多种语言提供了统一标注体系的树库，CoNLL 2017/2018共享任务促成了从原始文本到依存树的多语言端到端系统，斯坦福团队的系统在2018年的评测中名列前茅。spaCy提供工业级的Python工具，但语言覆盖有限。

方法

流水线由几个神经模块串联而成，每个模块对所有语言使用同一结构、各自在对应数据上训练：

  • 分词与断句：把文本看成字符序列，用字符级双向LSTM加卷积同时预测每个字符是否为词尾、句尾；
  • 多词词元展开：处理法语「du」= de + le这类一个书写词对应多个句法词的情况，结合词典和字符级seq2seq；
  • 词形还原：先查训练集构建的词典，查不到再用字符级seq2seq生成词元；
  • 词性与形态特征：双向LSTM编码后，用双仿射分类器同时预测通用词性、语言特定词性和形态特征；
  • 依存分析：采用与双仿射依存分析相同思路的双仿射图式分析器，并加入词序与距离特征；
  • 命名实体识别：用字符级语言模型的上下文表示（与Flair上下文字符串嵌入思路相同）加BiLSTM-CRF。

另外提供一个Python客户端，可以启动并调用Java版CoreNLP服务器，使用共指消解、关系抽取等Stanza本身没有的功能。

结果

摘要称：Stanza在112个数据集（包括Universal Dependencies树库和其他多语言语料）上训练，同一套神经结构在所有被测语言上都取得有竞争力的表现，支持66种语言（论文中与UDPipe、spaCy等工具比较，具体分数未逐项核对）。

后来的发展

Stanza此后持续扩充语言和模型，增加了生物医学与临床模型、基于Transformer的模块以及成分句法分析。它与spaCy、UDPipe一起构成多语言NLP预处理的主要选择；在大模型时代，它仍常被用来为语言学分析、数据清洗和评测生成可靠的句法标注。

读懂它需要的概念

分词与token 循环网络与隐状态 编码器-解码器 预训练与微调

本篇术语

  • 多词词元（multi-word token）　书写上是一个词、句法上是多个词的形式，如西班牙语dámelo = da + me + lo。
  • 词形还原（lemmatization）　把词的屈折形式还原成词典形式，如went → go。
  • NLP流水线　把分词、词性、句法等步骤依次串联，每步的输出作为下一步的输入。

怎么学

先了解Universal Dependencies的标注体系 → 读原文第2节的系统设计 → 动手：pip安装stanza，对中文、英文和一门你不熟悉的语言各跑一段文本，查看分词、词性和依存结果。
