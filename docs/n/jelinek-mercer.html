Jelinek-Mercer插值平滑

Interpolated estimation of Markov source parameters from sparse data
1980论文延伸Pattern Recognition in Practice（研讨会文集）1980Frederick Jelinek, Robert L. Mercer · IBM T.J. Watson研究中心待核对
CiNii记录 ↗在交互版中打开（演化树、学习进度）

问题

三元语法语言模型在语音识别中效果最好，但训练语料中绝大多数三元组只出现过一两次或从未出现，直接用相对频率估计会把大量合理的词序列概率估成0；二元、一元模型估计更稳定却丢掉了上下文。

方法

把三元、二元、一元的频率估计线性混合：p(w|u,v) = λ₃ f(w|u,v) + λ₂ f(w|v) + λ₁ f(w)，混合权重λ不手工设定，而是在留出的数据上用EM算法估计（“删除插值”），并允许按历史出现次数分组使用不同的λ。

影响

插值平滑成为n-gram语言模型最基本的平滑方法之一，IBM语音识别系统长期使用；它和Katz回退并列为两大平滑范式，此后的Kneser-Ney等方法常以插值形式实现，检索中的语言模型方法也直接沿用了“Jelinek-Mercer平滑”这一名称。

背景

IBM的统计语音识别组在1970年代把语音识别看作噪声信道问题，HMM统计语音识别负责声学部分，语言部分用三元语法。香农：语言的统计模型早已提出用n元频率近似语言，Good-Turing估计给出了估计未见事件总概率的方法，但如何在不同阶的估计之间取舍还没有好的方案。

方法

插值形式：对历史(u, v)和下一个词w，

p̂(w | u, v) = λ₃(u,v) · f(w | u, v) + λ₂(u,v) · f(w | v) + λ₁(u,v) · f(w)，其中 λ₁ + λ₂ + λ₃ = 1

f是在训练语料上的相对频率。直观上，历史(u, v)出现得越多，三元估计越可信，λ₃应越大；出现得少就更多依赖低阶估计。

权重估计（删除插值）：λ不能在同一份训练数据上估，否则三元频率总是“最准”、λ₃会趋于1。做法是留出一部分数据（或轮流删除一部分数据做交叉估计），把插值看成一个隐变量混合模型——每个词“由哪一阶模型生成”是隐变量——用EM算法迭代：E步计算每个留出词由各阶模型生成的后验，M步把后验平均作为新的λ。

参数分组：为每个历史单独估λ太稀疏，于是按历史的出现次数把历史分到若干“桶”中，同一个桶共享一组λ。

结果

论文以IBM语音识别任务说明了插值估计相对单一阶估计的优势（原始文集难以获取，具体数字未核对，此处不写）。

后来的发展

Jelinek-Mercer插值与Katz回退语言模型回退一起构成n-gram平滑的两大基本形式；n-gram平滑（Chen与Goodman）的系统比较把它作为基线之一，并说明插值版的Kneser-Ney平滑效果最好。在信息检索中，语言模型检索（查询似然）与检索语言模型的平滑把文档模型与语料背景模型的线性混合直接称为Jelinek-Mercer平滑。混合权重用EM在留出数据上估计的做法也被广泛用于模型插值与集成。

局限与后续

  • 低阶分布直接用普通的相对频率，没有考虑一个词能接在多少种不同上下文后面，这会高估某些只在固定搭配中出现的词。
    后来针对它的工作　Kneser-Ney平滑
  • 插值权重按历史计数分组估计，粒度粗，需要额外的留出数据。
    后来针对它的工作　n-gram平滑

读懂它需要的概念

n-gram与平滑 语言模型 EM算法 最大似然估计 随机变量与概率分布

本篇术语

  • 插值　把几个不同的概率估计按权重相加，权重之和为1。
  • 删除插值　轮流删除一部分训练数据作为留出集来估计插值权重，再把结果合并，避免在同一份数据上过拟合。

怎么学

先学n-gram的极大似然估计 → 读Jurafsky与Martin教材n-gram平滑一节的插值部分 → 动手：在一份小语料上实现三元插值模型，用EM在留出集上估计λ，比较与只用三元、只用二元模型的困惑度。
