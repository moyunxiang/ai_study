WIDER FACE人脸检测

WIDER FACE: A Face Detection Benchmark
2015.11数据集延伸CVPR 2016Shuo Yang, Ping Luo, Chen Change Loy, Xiaoou Tang · 香港中文大学待核对
arXiv ↗项目页 ↗在交互版中打开（演化树、学习进度）

问题

人脸检测在已有基准上的成绩已经很高，但这些基准规模小、人脸大多清晰正面，和真实照片里又小、又侧、又被遮挡的人脸差距很大。

方法

收集一个比已有人脸检测数据集大10倍的数据集，标注人脸框以及遮挡、姿态、事件类别等属性，并专门让尺度、姿态、遮挡的变化非常大。

影响

成为深度学习时代人脸检测的标准基准，MTCNN之后的人脸检测器几乎都按它的Easy / Medium / Hard三档子集报告成绩。

方法

从Viola–Jones人脸检测开始，人脸检测一直是视觉研究最多的任务之一，进展很大程度上靠公开基准推动。作者认为当时的基准与真实需求之间有落差：图中人脸偏大、偏正，算法在上面的高分会高估真实表现。

数据。WIDER FACE的规模是已有人脸检测数据集的10倍，图片按事件类别（如游行、会议、运动等场景）组织；每张脸标了边界框，以及遮挡、姿态等属性。数据刻意保留了大量极小、严重遮挡和大角度侧脸的样本。

评测与发现。作者用几种有代表性的检测系统做了基准测试，展示了在难样本上的明显差距；证明WIDER FACE也是有效的训练数据；提出了一种处理大尺度变化的方案，并分析了常见的失败案例。

局限与后续

  • 只标注人脸框和若干属性，没有关键点等更细的标注；最难一档的极小人脸在标注上也存在歧义。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 延续
    Viola–Jones人脸检测2001 · 视觉
    Viola–Jones以来的人脸检测进展依赖基准，WIDER FACE把考题换成更难、更大的真实场景。
  • 延续
    PASCAL VOC2005 · 数据·评测
    沿用通用目标检测基准的边界框标注和平均精度评测方式，专门用于人脸。
  • 竞争
    LFW人脸库2007.10 · 数据·评测
    LFW考的是人脸识别（是不是同一个人），WIDER FACE考的是在整张照片中找出所有人脸。

读懂它需要的概念

怎么学

先了解目标检测的边界框和平均精度。读原文的数据集构建与基准实验部分；动手下载验证集，用一个开源人脸检测器在Easy/Medium/Hard三档上分别算AP，看小脸上掉多少。
