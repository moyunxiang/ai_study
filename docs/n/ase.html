ASE技能嵌入

ASE: Large-Scale Reusable Adversarial Skill Embeddings for Physically Simulated Characters
2022.05论文延伸SIGGRAPH 2022Peng, Guo, Halper, Levine, Fidler · UC Berkeley / NVIDIA / Univ. of Toronto待核对
原文 ↗在交互版中打开（演化树、学习进度）

问题

物理角色的控制策略通常每个任务都从零训练，缺乏像人类那样可复用的通用运动技能库。

方法

结合对抗模仿和无监督强化学习，从大规模动作数据中学出一个技能嵌入空间，让高层只需选择潜在技能就能控制角色。

影响

让物理角色像“预训练加微调”一样复用技能，为后来人形机器人的通用动作先验提供了思路。

方法

ASE沿用对抗运动先验AMP的对抗式风格奖励来保证动作自然，同时引入一个潜变量z来表示不同技能：低层策略根据z产生不同风格的动作，一个互信息（见互信息）类的无监督目标要求不同的z能产生可区分的行为，防止策略只学一种动作。训练完成后得到一个技能嵌入空间和一个低层控制器。

之后每遇到一个新任务，只需训练一个小的高层策略来选择z，而不是重新训练整个控制器。论文称这种方式既能让动作逼真，又给下游任务提供了易控制的表示。

局限与后续

  • 技能嵌入的覆盖受限于训练动作数据，需要的算力和数据都较大。
