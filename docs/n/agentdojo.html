AgentDojo注入评测

AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents
2024.06数据集延伸NeurIPS 2024（Datasets and Benchmarks）Edoardo Debenedetti, Jie Zhang, Mislav Balunović, Luca Beurer-Kellner, Marc Fischer, Florian Tramèr · ETH Zürich / Invariant Labs待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

间接提示注入已被演示，但缺少能衡量智能体在真实任务中被劫持的难易、并可随攻防演进而扩展的评测。

方法

做成可扩展的动态环境：用97个真实任务和629个安全测试用例，评估智能体在工具返回不可信数据时被攻击的情况，并可加入新攻击和新防御。

影响

成为提示注入防御的通用试验场，后来的CaMeL：从设计上防注入等工作都以它来报告结果。

方法

AgentDojo不是一份静态的题库，而是一个环境：智能体需要调用工具完成任务，如管理邮箱、操作网银、订旅行（见工具调用与智能体循环），而工具返回的内容里可能夹带攻击者写的指令（见提示注入）。

评测同时测两件事：智能体在没有攻击时能完成多少任务（效用），以及攻击者的目标有多少被达成（安全）。环境里有97个任务、629个安全测试用例，并收录了文献中的多种攻击与防御，研究者可以自己再加任务、防御和自适应攻击。作者发现它对双方都有挑战：最先进的LLM即使没有攻击也完成不了许多任务，而现有的提示注入攻击也能在一部分任务上得手（具体比例请看原文）。

局限与后续

  • 动态环境依赖手写的任务和规则，覆盖面有限，防御在这里的得分未必能推广到真实系统。
