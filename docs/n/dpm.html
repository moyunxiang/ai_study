可变形部件模型DPM

A Discriminatively Trained, Multiscale, Deformable Part Model
2008.06论文重要CVPR 2008Pedro Felzenszwalb, David McAllester, Deva Ramanan · 芝加哥大学 / TTI-Chicago / UC Irvine待核对
CVPR 2008（DOI） ↗PDF ↗在交互版中打开（演化树、学习进度）

问题

HOG加线性SVM的刚性模板只能描述一个固定姿态，人一抬手、马一转身，模板就对不上；可变形部件模型概念上更好，却从没在PASCAL这种难基准上赢过。

方法

一个粗分辨率的整体模板加几个高分辨率的部件模板，每个部件可以在预期位置附近移动、按偏离程度付代价；部件位置作为隐变量，用隐变量SVM和难负样本挖掘来训练。

影响

在PASCAL VOC 2006行人检测上把AP从0.16翻倍到0.34，2007年20类中10类第一；此后到2012年，DPM及其变体一直是目标检测的最强方法。

背景

目标检测要在图里框出所有的人、车、马。2005年的HOG与手工特征时代给出了标准做法：把一个固定大小的窗口在图像金字塔上逐位置滑动，每个窗口提取HOG特征，用线性支持向量机判断是不是人。这是一个刚性模板：它只记得“人大致长这样”，对站姿、手臂位置、视角的变化只能靠模板本身变模糊来容忍。

“物体由可以相对移动的部件组成”（脸＝眼睛＋鼻子＋嘴，位置有弹性）是很早就有的想法，但在PASCAL VOC这样真实而杂乱的数据集上，这类模型反而经常输给更简单的刚性模板或词袋模型。难点在训练：数据只标了整个物体的框，没标部件在哪里。

方法

模型。一个物体模型由三部分组成：

  • 根滤波器：覆盖整个物体的粗分辨率HOG模板，相当于Dalal–Triggs的检测器；
  • 若干部件滤波器（每类6个）：在两倍分辨率上描述细节，比如人的头、肩、腿；
  • 空间模型：每个部件有一个相对根的“锚点”，偏离锚点(dx, dy)要付二次形式的代价，例如a·(dx, dy) + b·(dx², dy²)。

打分。窗口的得分＝根滤波器得分＋Σ各部件“在最佳位置的滤波器得分 − 移动代价”。每个部件都独立在附近搜索最佳位置，这一步用广义距离变换可以在线性时间内对所有位置算完，所以每张图约2秒。

训练：隐变量SVM。训练图只标了物体框，部件位置（以及根滤波器的精确位置和尺度）是不知道的隐变量z。得分写成f(x) = max_z β·Φ(x, z)。作者交替做两步：固定模型，为每个正样本找出得分最高的隐变量；固定隐变量，问题就变成普通的凸SVM。论文证明了这个问题是“半凸”的，因此交替优化是合理的。

难负样本挖掘。背景窗口有几十亿个，不可能全放进训练。做法是先随便取一些负样本训练，再用当前模型扫描背景图，把被误判为物体的“难”负样本加进来重训，如此反复。

结果

PASCAL VOC 2006行人：2006年竞赛最好的刚性HOG模板AP为0.16，此前最好结果0.19；只用根滤波器0.18，加入隐变量训练后0.24，再加部件0.34，是之前最好结果的两倍；只用部件不用根为0.29。VOC 2007的20类中，10类第一、6类第二。

后来的发展

DPM及其改进版（混合多个视角的组件、级联加速、加上下文）在此后几年的PASCAL VOC检测中一直处于领先。难负样本挖掘和“检测＝滑窗/候选框＋打分＋非极大值抑制”的框架被深度检测器继承；2013年的R-CNN用卷积网络特征替换HOG，在VOC上大幅超过DPM，手工特征检测的时代结束。后来有人指出DPM本身可以写成一种卷积网络。

容易误解的地方

  • DPM的“可变形”是部件在锚点附近平移，部件模板本身不形变。
  • 训练只需要整个物体的框，部件是自动学出来的，不需要人工标注部件。

局限与后续

  • 特征仍是手工设计的HOG，只描述局部梯度形状，类别区分能力有限，2010年前后VOC上的检测精度进展明显放缓。
    后来针对它的工作　R-CNN
  • 每类要单独训练一个模型、每张图约2秒，在图像金字塔上做滑窗，类别一多就很慢。
    后来针对它的工作　Fast R-CNN YOLO
  • 隐变量SVM是非凸的，结果依赖部件初始化等启发式，部件数量和形状也是固定的，难以表达更复杂的结构。
    后来针对它的工作　R-CNN

它建立在什么之上

  • 延续
    支持向量机1995 · 基础
    把线性SVM推广为隐变量SVM，使部件位置这种没有标注的变量也能参与最大间隔训练。
  • 竞争
    Viola–Jones人脸检测2001 · 视觉
    Viola–Jones用刚性的级联分类器快速检测正脸；DPM用可变形部件处理姿态多变的通用类别，代价是速度慢得多。
  • 延续
    HOG与手工特征时代2005 · 视觉
    根滤波器就是Dalal–Triggs的HOG刚性模板；DPM在它之上加了高分辨率部件和可变形的空间模型。
  • 使用
    PASCAL VOC2005 · 数据·评测
    在PASCAL VOC 2006/2007上评测，证明部件模型在真实难基准上确实有效。

后来的相关工作

  • 改进
    R-CNN2013.11 · 视觉
    DPM的HOG模板在VOC上停在约33% mAP；用CNN特征把VOC 2010的mAP提到53.7%。
  • 改进
    Fast R-CNN2015.04 · 视觉
    每类要单独训练一个模型、每张图约2秒，在图像金字塔上做滑窗，类别一多就很慢。
  • 改进
    YOLO2015.06 · 视觉
    此前唯一能实时的是GPU版DPM（26.1% mAP），YOLO在实时速度下达到63.4%。
  • 使用
    MPII人体姿态2014.06 · 数据·评测
    作为基线评测的FMP属于可变形部件模型一类的“部件+形变”方法，论文用它和图结构模型分析姿态估计的失败模式。

读懂它需要的概念

分类、检测、分割 核技巧与间隔 隐变量模型 IoU与mAP 锚框与非极大值抑制

本篇术语

  • 滑动窗口　把一个固定大小的框在图像的每个位置、每个尺度上移动，逐个判断框里是不是目标。
  • 隐变量SVM　得分取所有可能隐变量（如部件位置）中的最大值；训练时交替“为正样本选最佳隐变量”和“训练普通SVM”。
  • 难负样本挖掘　反复用当前模型扫描背景，把被误判的背景窗口加入训练集，让模型重点学习最容易混淆的负例。

怎么学

先确认会核技巧与间隔里的最大间隔思想，再看HOG与手工特征时代的特征是怎么算的。读原文第2节（模型）和第3节（隐变量SVM、难负样本），看图1和图4的模型可视化。动手：用scikit-image提取HOG，在一个小行人数据集上训练线性SVM滑窗检测器，然后体会它对姿态变化的不足。
