双块注意力DCA

Training-Free Long-Context Scaling of Large Language Models
2024.02论文延伸ICML 2024Chenxin An, Fei Huang, Jun Zhang, Shansan Gong, Xipeng Qiu, Chang Zhou, Lingpeng Kong · 香港大学、阿里巴巴、复旦大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

模型输入一旦超过预训练长度，RoPE遇到训练中没见过的相对距离，效果就急剧变差；用长文本继续训练（位置插值、YaRN等）对70B级模型代价很高。

方法

免训练地把长序列切成不超过预训练长度的块，重新安排位置下标：块内用原始相对位置，跨块时把查询和键的位置重映射，使任意两个token之间的相对距离都落在模型训练中见过的范围内。

影响

让Llama2 70B不经继续训练就支持10万token以上的上下文；DCA后来被Qwen2和Qwen2.5-1M用于推理时的长度外推，是免训练长上下文扩展的常用方法之一。

方法

背景：旋转位置编码RoPE把位置编码写进q、k的旋转角度，注意力只依赖相对距离 i − j。预训练长度为L时，模型只见过 0 ≤ i − j < L 的距离；推理时若出现更大的距离，注意力分数就落入分布外。位置插值扩上下文和YaRN通过压缩位置并少量续训解决，SelfExtend免训练扩上下文则在推理时把远距离位置做整除合并。

DCA把注意力拆成三种情况，每种都保证相对距离不超过L：

  • 块内注意力（intra-chunk）：序列切成长度为s（s < L）的块，同一块内的token用块内下标 i mod s 计算相对位置，等同于原模型。
  • 块间注意力（inter-chunk）：查询与之前各块的键相互作用时，把查询的位置固定设为一个较大的常数（接近L−1），键用块内下标，因此距离在 [0, L) 内，同时保持“查询在键之后”的顺序。
  • 相邻块注意力（successive-chunk）：相邻两块之间对查询位置做特殊处理，保留局部的精确相对距离，避免块边界处出现跳变。

三部分的注意力分数在softmax前拼接，整体仍是一次标准的注意力，因此可以和FlashAttention结合，实现上只需改变传入的位置下标。

结果：摘要称DCA让Llama 2 70B在不继续训练的情况下支持超过10万token的上下文；在实际长上下文任务上与经过微调的模型相当甚至更好；免训练的70B模型达到gpt-3.5-16k表现的94%。

它建立在什么之上

  • 改进
    旋转位置编码RoPE2021.04 · LLM
    RoPE在超出训练长度的相对距离上失效，DCA通过重映射位置下标让所有距离都落在训练范围内。
  • 使用
    FlashAttention2022.05 · 系统·效率
    三部分注意力只改变位置下标，可直接用FlashAttention计算。
  • 竞争
    位置插值扩上下文2023.06 · LLM
    位置插值压缩位置并续训，DCA完全免训练。
  • 使用
    Llama 22023.07 · LLM
    主要在Llama2 7B到70B上验证。
  • 竞争
    SelfExtend免训练扩上下文2024.01 · LLM
    SelfExtend用整除合并远处位置，DCA按块重排下标并单独处理相邻块，同为推理时免训练扩展。

读懂它需要的概念

位置编码 上下文窗口 自注意力与多头注意力 KV缓存

本篇术语

  • 长度外推　模型在比训练时更长的输入上仍然正常工作的能力。
  • 免训练（training-free）　只在推理时修改计算方式，不更新任何模型参数。
