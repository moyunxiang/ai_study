AWR优势加权回归

Advantage-Weighted Regression: Simple and Scalable Off-Policy Reinforcement Learning
2019.10论文延伸Xue Bin Peng, Aviral Kumar, Grace Zhang, Sergey Levine · UC Berkeley待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

主流离策略深度RL算法（SAC、TD3）要同时训练互相依赖的actor和critic，超参数敏感、实现复杂；简单稳定的监督学习式算法又通常只能用on-policy数据。

方法

把RL拆成两个普通的回归问题：先回归一个价值函数，再对数据中的动作做加权最大似然——权重是优势的指数 exp(A/β)，比平均更好的动作被模仿得更多。两步都是收敛的监督学习，可以直接用回放池里的离策略数据。

影响

“优势加权回归”成为离线RL里从价值函数提取策略的标准方式之一，AWAC优势加权、CRR评论家正则化回归、隐式Q学习IQL等方法都用了这种指数加权的策略更新。

背景

早在2007年，奖励加权回归（RWR）就提出过用“回报加权的行为克隆”来做策略改进，但只适用于on-policy数据。深度RL的离策略算法样本效率高，但critic与actor之间的耦合使训练不稳定，复现困难（《Deep RL that Matters》复现性批评）。作者希望得到一个只调用标准监督学习、却能利用经验回放的简单算法。

方法

AWR从一个约束的策略改进问题出发：在不偏离数据采样策略 μ 太远（KL约束）的前提下最大化期望改进。这个问题的解析解是 π*(a|s) ∝ μ(a|s) · exp(A^μ(s,a) / β)，其中 A^μ = Q^μ − V^μ 是优势，β是温度。把它投影到参数化策略上，就得到一个加权最大似然目标：

π ← argmax_π E_{(s,a)∼D} [ log π(a|s) · exp( (R_{s,a} − V(s)) / β ) ]

每轮迭代两步：（1）用数据中的回报（论文用TD(λ)回报）回归价值函数 V(s)；（2）用上式对回放池中的动作做加权行为克隆，回报高于价值估计的动作权重大。权重会截断到一个上限以防数值爆炸。作者还分析了混合多个历史策略的回放数据时这一目标的含义。

结果

摘要称，AWR在一组标准OpenAI Gym任务上与多个成熟的最先进RL算法表现相当；只用静态数据、不再与环境交互时，它比大多数离策略算法学到的策略更好；并在高度复杂的模拟角色连续控制任务上展示了效果。

后来的发展

AWR把“用优势的指数给行为克隆加权”带入深度离线RL：AWAC优势加权把其中的蒙特卡洛价值换成Q函数，CRR评论家正则化回归系统比较了不同的权重函数，隐式Q学习IQL用期望分位数回归学价值函数后同样用AWR提取策略。后来IDQL隐式扩散Q学习指出，用AWR拟合单峰高斯策略会丢掉隐式策略的多峰结构。

局限与后续

  • 价值函数用蒙特卡洛或TD(λ)回报回归的是数据混合策略的价值，而不是当前策略的价值，离线时改进幅度有限。
    后来针对它的工作　AWAC优势加权 隐式Q学习IQL
  • 加权最大似然拟合的是单峰高斯策略，数据里动作分布多峰时会把几种动作平均成一个不好的动作。
    后来针对它的工作　IDQL隐式扩散Q学习

  • 使用
    时序差分学习1988 · RL
    价值函数回归的目标是TD(λ)回报，来自时序差分学习的多步回报。
  • 改进
    《Deep RL that Matters》复现性批评2017.09 · RL
    针对深度RL实现复杂、对超参数敏感的问题，只用收敛的监督学习损失构建算法。
  • 竞争
    SAC2018.01 · RL
    SAC靠actor-critic联合优化取得高样本效率；AWR只用两个回归步骤，更简单稳定，性能相当。
  • 延续
    MPO2018.06 · RL
    与MPO同样从KL约束下的策略改进得到“按指数优势重加权”的非参数策略，再投影到参数化策略。

读懂它需要的概念

策略与价值函数 KL散度 最大似然估计 模仿学习与行为克隆 on-policy与off-policy

本篇术语

  • 优势（advantage）　某个动作的价值比该状态的平均价值高多少：A(s,a) = Q(s,a) − V(s)，正值表示比平均好。
  • 加权行为克隆　模仿数据中的动作，但每个样本乘一个权重；权重大的动作被模仿得更多。

怎么学

先复习模仿学习与行为克隆和优势函数；读原文第3节从KL约束问题推导出指数权重的过程；在一个连续控制任务上实现AWR的两个回归步骤，试不同温度β看对性能的影响。
