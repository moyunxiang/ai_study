百度深度学习研究院

2013.01事件延伸Kai Yu、Robin Li · 百度待核对
WIRED报道 ↗在交互版中打开（演化树、学习进度）

问题

谷歌在2011至2013年建立深度学习团队后，中国的搜索公司担心在语音、图像上落后。

方法

2013年初百度成立深度学习研究院，随后在硅谷设立实验室（2013年4月WIRED以“中国的谷歌”报道），成为中国企业最早的深度学习研究机构。

影响

引发了中国互联网公司的深度学习人才争夺，后来演变为百度研究院和硅谷AI实验室，吸引了吴恩达等人。

方法

我只核对到WIRED在2013年4月12日发表过一篇标题为“‘Chinese Google’ Opens Artificial-Intelligence Lab in Silicon Valley”的报道，另有The Next Web 2014年8月的报道讲百度用深度学习改进手机应用。研究院的负责人、具体成立日期和规模没有核对，因此不写具体内容。

这件事发生在Google Brain成立与谷歌拍得Hinton团队收购之后，是对谷歌动作的回应，也是中国公司在AlexNet之后系统性投入深度学习的开始。

局限与后续

  • 早期研究院的目标更偏产品，缺乏稳定的长期基础研究文化。
