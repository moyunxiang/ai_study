Machine Bias
2016.05思想重要Julia Angwin, Jeff Larson, Surya Mattu, Lauren Kirchner · ProPublica待核对
ProPublica原文 ↗数据分析方法说明 ↗数据与代码 ↗在交互版中打开（演化树、学习进度）

问题

美国法院越来越多地用商业软件给被告打“再犯风险分”，用于保释和量刑，但算法不公开，没人用真实结果检验过它对不同族裔是否同样准确。

方法

调查记者拿到佛罗里达州布劳沃德县七千多名被捕者的COMPAS风险分，追踪两年内谁真的再次被捕，按族裔分别统计算法的两类错误。

影响

第一次用公开数据把“算法偏见”做成可复查的证据，直接引出“公平的几种定义不能同时满足”的理论结果，使算法公平成为机器学习的正式研究方向。

背景

2010年代，美国司法系统广泛采用“风险评估”工具：被告入狱登记时回答一份问卷，软件据此给出未来再犯罪的风险等级，法官在定保释金、决定缓刑甚至量刑时参考。报道发表时，亚利桑那、威斯康星等9个州在量刑阶段把这类评分交给法官。最常用的产品之一是Northpointe公司的COMPAS，它根据137个问题（来自被告回答或犯罪记录）打分，问题里不包括种族，但计算方法是商业机密。

2014年时任美国司法部长霍尔德就公开担心这类评分会把不公平带进法庭，要求美国量刑委员会研究，但这项研究并没有启动。工具的开发方用自己的验证研究证明“有效”，外部没人用独立数据检验过。

方法

数据。ProPublica通过公开记录申请拿到布劳沃德县2013–2014年被捕者的COMPAS评分（方法说明中共分析了一万多名被告，正文报道称七千多人），再与此后两年的犯罪记录逐人匹配。“两年内是否被指控新罪”正是COMPAS开发方自己用的标准。

检验什么。对二分类器有两类错误（见准确率、精确率、召回率与F1）：

  • 假阳性：被评为较高风险，实际没有再犯。
  • 假阴性：被评为较低风险，实际再犯了。

记者按黑人和白人被告分别计算这两个比例。

控制其他因素。为了排除“黑人被告前科更多”这类解释，团队用逻辑回归把风险分（低 vs 中高）对种族、年龄、性别、犯罪史、罪名等级和实际是否再犯同时回归，看种族本身的系数；并像Northpointe的验证研究一样用Cox比例风险模型检验整体预测力。全部数据和代码公开在GitHub上。

结果

整体准确率。被评为可能再犯的人中，61%在两年内因任何罪名再次被捕，记者形容为“比抛硬币好一点”；预测暴力犯罪时，被判为高风险的人只有20%真的实施了暴力犯罪。

错误分布不同。黑人被告中，被评为较高风险但没有再犯的比例是44.9%，白人是23.5%；被评为较低风险却再犯的比例，白人47.7%，黑人28.0%。也就是说，两组的总体准确率接近，但黑人更容易被错判为危险，白人更容易被错判为安全。

控制变量后。在控制犯罪史、实际再犯、年龄和性别之后，黑人被告被评为暴力再犯较高风险的可能性仍高77%，被评为任何再犯较高风险的可能性高45%。

Northpointe在给ProPublica的信中否认这些结论、批评其方法；它随后的回应是，评分对不同族裔同样准确地预测了再犯，即同一风险分对应的实际再犯率相近。

后来的发展

这场争论的核心在几个月内被理论界说清：公平性不可兼得证明，当两个群体的基础再犯率不同时，“同一分数代表同样的再犯概率”（校准，Northpointe的标准）和“两组的假阳性、假阴性率相等”（ProPublica的标准）不可能同时成立，除非预测完美。几乎同时，机会均等把“各组错误率相等”形式化为一个可以直接施加到任意分类器上的约束。ProPublica公开的COMPAS数据集随后成为算法公平研究中最常用的基准之一。

此后对其他系统的独立审计接连出现，如Gender Shades与算法公平对商业人脸识别的检测、亚马逊招聘AI的性别偏见被曝光的招聘模型歧视，模型卡则主张模型发布时按人群分组报告性能。别再解释黑盒以COMPAS为例主张：高风险决策应使用透明的简单模型，而不是不公开的黑箱。

容易误解的地方

  • ProPublica并没有证明COMPAS“整体准确率对黑人更低”，两组的总体准确率大致相同；差别在于错误的方向。
  • Northpointe和ProPublica用的是两种不同的公平定义，二者在基础率不同时数学上互相冲突。这是这篇报道真正留给学界的问题，而不是简单的谁对谁错。
  • 种族不在问卷里不等于算法与种族无关：犯罪史、家庭成员是否坐牢等问题本身就与种族相关，这类变量常被称为代理变量。

局限与后续

  • 报道揭示了矛盾却没有给出“公平”该如何定义；它的标准与开发方的校准标准互相冲突，当时没人知道两者能否兼得。

本篇术语

  • COMPAS　Northpointe公司（2017年合并为equivant）的刑事风险评估软件，用137个问题给被告打再犯风险分，在美国多个州被法院使用。
  • 假阳性率 / 假阴性率　在实际没有再犯的人中被错判为高风险的比例 / 在实际再犯的人中被错判为低风险的比例。ProPublica比较的就是这两个比例在不同族裔间是否相等。
  • 校准　同一个风险分对应的实际再犯率在各群体间相同，例如所有评为7分的人，不论族裔，都有大约同样比例真的再犯。
