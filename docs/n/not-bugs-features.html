对抗样本是特征不是bug

Adversarial Examples Are Not Bugs, They Are Features
2019.05论文延伸NeurIPS 2019Andrew Ilyas, Shibani Santurkar, Dimitris Tsipras, Logan Engstrom, Brandon Tran, Aleksander Madry · MIT待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

对抗样本为什么存在？一种看法是它们是模型的缺陷（bug），是网络的怪异行为。

方法

提出对抗样本来自「非鲁棒特征」：数据中确实能预测标签、但脆弱且人看不懂的模式，模型只是在忠实地利用它们。

影响

把对抗鲁棒性从「修补模型」重新定位为「数据里有什么特征」，影响了后续对鲁棒性与可解释性关系的研究。

方法

作者把特征分成鲁棒特征（扰动后仍有预测力）与非鲁棒特征（有预测力但容易被小扰动翻转）。他们的思路是：既然模型会利用非鲁棒特征，那么分类器被攻击就是特征本身的性质，而不是训练出了错。

论文在理论框架下论证这类特征在标准数据集中广泛存在，并用一个简单设定把观察到的现象联系到人所定义的鲁棒性与数据几何结构之间的不一致。这与PGD对抗训练一致：对抗训练迫使模型只用鲁棒特征，因此得到的梯度和表征更容易被人理解。

局限与后续

  • 论文并未给出让模型自动只用鲁棒特征的低成本方法；鲁棒特征的定义依赖选定的扰动范围。
    本站还没有记录针对它的后续工作（不代表没有人解决）
