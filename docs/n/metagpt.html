MetaGPT

MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework
2023.08论文延伸ICLR 2024Sirui Hong, Mingchen Zhuge, Jiaqi Chen, Xiawu Zheng, Yuheng Cheng, Ceyao Zhang, Jinlin Wang, Zili Wang 等 · DeepWisdom / KAUST / 厦门大学等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

让多个LLM自由聊天协作，复杂任务里一个智能体的幻觉会被下一个当真并层层放大，结果前后不一致。

方法

把人类团队的标准作业流程（SOP）写进提示，让产品经理、架构师、工程师等角色按流水线产出结构化文档，并在中间环节互相检查。

影响

把“让智能体按组织流程交接结构化产物”变成多智能体写代码的主流做法之一。

方法

MetaGPT的核心是把SOP编码进提示序列。每个角色有固定职责和输出格式：产品经理写需求文档，架构师写系统设计和接口，项目经理拆任务，工程师写代码，测试员验证。交接的是结构化的文档和图（如接口定义），而不是闲聊，下游角色可以据此检查上游的输出是否合理，从而截断“级联幻觉”。流水线式分工使一个复杂任务拆成多个子任务。

与同期的ChatDev相比，它强调结构化中间产物，而ChatDev强调聊天。摘要称在协作式软件工程基准上，它比此前基于聊天的多智能体系统生成的方案更连贯。
