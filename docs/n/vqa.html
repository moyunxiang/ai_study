VQA

VQA: Visual Question Answering
2015.05数据集重要ICCV 2015Stanislaw Antol, Aishwarya Agrawal, Jiasen Lu, Margaret Mitchell, Dhruv Batra, C. Lawrence Zitnick, Devi Parikh · 弗吉尼亚理工、微软研究院待核对
arXiv 1505.00468 ↗VQA官网 ↗在交互版中打开（演化树、学习进度）

问题

图像描述模型能生成像样的句子，但一句笼统的描述（“一个人站在街上”）说明不了模型看懂了多少；而且描述好坏很难自动评判。

方法

给一张图和一个关于它的自由提问（“这个人穿的鞋是什么颜色？”），要求给出简短答案；每个问题收集10个人的答案，按“至少3人给出相同答案即满分”自动打分。

影响

VQA成为视觉-语言理解的核心基准，催生了注意力、双线性融合、区域特征、视觉-语言预训练等一系列模型；它暴露的“只看问题就能答”的语言先验问题也成为多模态评测的长期议题。

背景

2014–2015年，图像描述Show and Tell等模型把CNN图像特征接到LSTM上生成图片描述，效果惊人。但描述任务有两个问题：一是模型可以只说出最显眼的物体就得到不错的描述，不需要理解细节；二是评价靠BLEU这类和参考句比对的指标，与人的判断相关性有限。

问答提供了更精确的考法：问题可以指向图中任意细节——背景里的东西、物体的数量、人物的动作、场景的用途，有的还需要常识；而答案往往只有一两个词，可以自动比对。此前已有的视觉问答数据集只有一两千张图、问题由模板生成或范围很窄，作者要做一个开放、规模大的版本。

方法

图像。真实图片来自MS COCO，共204,721张；另做了5万张用剪贴画拼成的抽象场景，让研究者可以抛开底层视觉识别，只研究推理。

提问。在众包标注Mechanical Turk上，要求工作者针对图片提出一个“能难倒一个聪明机器人”、必须看图才能回答的问题。每张图由3位不同的工作者各提一个问题。

回答。每个问题再请10位不同的工作者作答，回答要简短。真实图片部分共614,163个问题、约798万个答案。

评测。开放式回答用一个简单公式：

准确率 = min(给出该答案的人数 / 3, 1)

也就是说，只要10个人里有至少3人给出和模型一样的答案就算全对，只有1人给出则得1/3分。比较前统一转小写、数字转成阿拉伯数字、去掉冠词等。另设多项选择版本，每题18个候选答案。

基线。把问题编码（词袋或LSTM）与图像编码（VGG的特征）合并后送进分类器，在最常见的1000个答案中挑一个。

结果

在测试开发集上，总是回答“yes”的基线准确率为29.66%；只看问题、完全不看图的LSTM已达48.76%；最好的模型（两层LSTM问题编码加归一化的VGG图像特征）为57.75%，在标准测试集上为58.16%。让人在看图的条件下作答，准确率为83.30%。只看问题就能拿到约49%，说明大量问题的答案可以从问题本身猜出来，例如问“有没有……”时答“yes”更常见（问题中约58.8%的答案是yes）。

后来的发展

此后几年，VQA是视觉-语言模型的主战场：堆叠注意力SAN让模型按问题多次关注图像区域，神经模块网络把问题拆成可组合的模块，双线性池化MCB用双线性池化融合两种模态，自底向上注意力改用检测器给出的物体区域特征并赢得2017年VQA挑战赛，ViLBERT、LXMERT则开启了视觉-语言预训练。VQA也被纳入Flamingo、BLIP-2、LLaVA等多模态大模型的标准评测。

针对它暴露的语言先验问题，VQA v2为每个问题配上一对相似但答案不同的图片来平衡数据；CLEVR和GQA专门考组合推理，TextVQA考图中文字的阅读。

容易误解的地方

  • VQA准确率不是简单的“对或错”：与3个以上人的答案一致才是满分，部分匹配会拿部分分数。
  • 作者2016年的分析论文发现，模型常常听了半句问题就下结论，换一张图也不改答案；高分不一定说明模型在看图。
  • 人类83%左右的上限也说明，相当一部分问题本身就有歧义或主观性。

局限与后续

  • 存在强烈的语言先验，只看问题不看图就能答对近一半，模型可以靠猜而不必理解图像。
    后来针对它的工作　VQA v2 GQA
  • 问题大多只需识别单个物体或属性，很少考察多步、组合式的推理，也无法诊断模型具体错在哪一步。
    后来针对它的工作　CLEVR GQA
  • 很少有需要阅读图中文字的问题，而这恰是视障用户等真实场景中最常见的需求之一。
    后来针对它的工作　TextVQA
  • 按字符串精确匹配打分，同义词、单复数等不同说法会被判错，生成式大模型的长回答尤其难以公平评估。
    本站还没有记录针对它的后续工作（不代表没有人解决）

它建立在什么之上

  • 使用
    LSTM1997 · 基础
    基线用一层或两层LSTM把问题编码成向量。
  • 使用
    VGG2014.09 · 视觉
    基线模型用VGG网络最后一层隐藏特征作为图像表示。
  • 使用
    众包标注Mechanical Turk2005.11 · 数据·评测
    问题和每题10个答案都通过亚马逊众包收集，评测公式也建立在这10个人的答案分布上。
  • 使用
    MS COCO2014.05 · 数据·评测
    真实图片部分全部取自MS COCO，利用它场景复杂、每图多物体的特点来提出多样的问题。
  • 改进
    图像描述Show and Tell2014.11 · 多模态
    图像描述可以只说笼统的话、又难以自动评分；问答能针对任意细节考察，答案短，可自动比对。

读懂它需要的概念

卷积层、池化与感受野 循环网络与隐状态 嵌入向量 准确率、精确率、召回率与F1 基准、排行榜与SOTA

本篇术语

  • 语言先验　答案在问题条件下的统计偏好，例如“天空是什么颜色”大概率答“蓝色”；模型可以靠它答对而不看图。
  • 开放式与多项选择　开放式要求自己给出答案；多项选择则从给定的18个候选中挑一个，更容易评分也更容易。

怎么学

先补卷积层、池化与感受野、循环网络与隐状态和嵌入向量。读原文第3节（数据收集）和第5节（基线与结果表）。动手：从VQA v2中取一小部分数据，先实现“只看问题”的基线（问题词袋+逻辑回归），再加上预训练CNN的图像特征，比较加图之后提升了多少。
