低秩矩阵补全

Exact Matrix Completion via Convex Optimization
2008.05论文延伸Foundations of Computational Mathematics 2009Emmanuel J. Candès, Benjamin Recht · 加州理工学院待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

推荐系统里的评分矩阵只观测到极少数条目（Netflix Prize就是典型），要猜出其余条目。直接找“与观测一致的最低秩矩阵”是NP难的组合问题，也不清楚观测到多少条目才够。

方法

把“秩最小”换成它的凸替代——核范数（奇异值之和）最小，并证明：对大多数低秩矩阵，只要随机观测到约 C·n^1.2·r·log n 个条目，这个凸优化就能以高概率精确恢复整个矩阵。

影响

把压缩感知“稀疏向量可由少量测量恢复”的思想推广到低秩矩阵，奠定了矩阵补全与低秩恢复的理论基础，是推荐系统、协同过滤和低秩建模的常引理论文献。

方法

设n×n矩阵M的秩为r，远小于n。我们随机看到其中m个条目，希望补全其余部分。自然的做法是在所有与观测一致的矩阵中找秩最低的，但秩函数不连续、不凸，求解是组合爆炸的。

作者的类比来自Lasso与L1稀疏与压缩感知：向量的非零个数（L0）难以优化，就用L1范数代替；矩阵的秩等于非零奇异值的个数，就用奇异值之和——核范数 ‖X‖* = Σσ_i(X)——代替。于是问题变成凸优化：在 X_ij = M_ij（对所有观测位置）的约束下最小化 ‖X‖*，可以用半定规划求解。

主定理：若观测条目数满足 m ≥ C·n^1.2·r·log n（C为常数），则对大多数秩为r的矩阵，核范数最小化以很高概率恰好恢复M；把指数1.2换成1.25则对所有秩都成立。这里“大多数”对应一个不相干性条件：矩阵的奇异向量不能集中在少数几行几列，否则没被看到的那一行根本无从猜起。

这一结果说明，补全一个n×n的低秩矩阵只需要远少于n²个观测，后续工作把所需条目数改进到接近 n·r·log n 的量级，并发展出更快的交替最小化等非凸算法。

局限与后续

  • 半定规划求解代价高，矩阵稍大就无法直接用通用求解器；而且要求观测位置均匀随机，真实推荐数据的缺失并不随机。

读懂它需要的概念

特征分解与奇异值分解 低秩近似 凸函数与凸优化 范数与距离 正则化与权重衰减

本篇术语

  • 核范数　矩阵所有奇异值之和，是秩函数最紧的凸替代；最小化它会让很多奇异值变成0，从而得到低秩解。
  • 不相干性　矩阵的信息要均匀分布在各行各列上；如果某一行的信息完全藏在没观测到的条目里，任何方法都补不出来。

怎么学

先补特征分解与奇异值分解和Lasso与L1稀疏的L1松弛思想；读论文第1节问题陈述与主定理；用numpy生成一个100×100、秩为3的矩阵，随机保留30%条目，用奇异值软阈值迭代补全并看误差。
