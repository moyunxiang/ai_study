GR00T N1

GR00T N1: An Open Foundation Model for Generalist Humanoid Robots
2025.03论文重要NVIDIA（Johan Bjorck, Fernando Castañeda, Nikita Cherniadev, Xingye Da等，arXiv作者列表按姓氏字母排序；附录列出的研究负责人为Linxi “Jim” Fan、Yuke Zhu）来源已核对
arXiv ↗GitHub: Isaac-GR00T ↗在交互版中打开（演化树、学习进度）

问题

人形机器人的真机数据极其昂贵，各家只能在自己的“数据孤岛”上训练；而π0这类通用VLA既不开源训练数据，也没有专门处理人形双臂灵巧手的形态差异。

方法

沿用“VLM理解+流匹配DiT出动作”的双系统结构，把训练数据组织成金字塔：底层是网络数据和人类视频，中层是仿真和视频生成模型合成的轨迹，顶层是少量真机遥操作；无动作的数据用潜动作或逆动力学模型补标签。

影响

NVIDIA开源的人形机器人基础模型（2.2B），论文称模型权重、训练数据和仿真基准都已公开；实验显示用视频生成模型把88小时真机数据扩增到827小时后，仿真和真机成功率都有提升。

背景

π0确立了“预训练VLM+连续动作专家”的VLA结构，Figure Helix也提出了类似的“慢思考+快执行”双系统设计。但人形机器人有两个特殊困难：一是形态多——单臂、双臂、带灵巧手、带腰和头的人形，状态和动作维度各不相同；二是数据少——人形真机遥操作极其耗时，各公司的数据互不共享，形成“数据孤岛”。

NVIDIA手里有另外两类资源：大规模仿真数据生成工具（GR00T N1的仿真任务建在RoboCasa框架上，用DexMimicGen合成轨迹），以及图生视频模型。问题是能否把仿真轨迹、生成的视频、人类视频和真机数据放进同一个模型一起训练。

方法

System 2（视觉-语言）：NVIDIA Eagle-2 VLM，输入图像和指令，在L40上约10Hz运行。实验发现用语言模型中间层（第12层）而非最后一层的特征，推理更快、策略成功率也更高。

System 1（动作）：一个用流匹配训练的扩散Transformer（Diffusion Transformer），以带噪声的动作块和本体状态为输入，通过交叉注意力读取VLM特征，输出去噪后的动作，最高可达120Hz闭环控制。每种机器人形态各有一个小MLP做状态和动作的编码/解码，主体共享。整个模型2.2B参数（VLM占1.34B），在L40上生成16步动作块需63.9毫秒。两个系统端到端联合训练。

数据金字塔：

  • 底层：VLM预训练用的网络图文数据和开源人类第一视角视频；
  • 中层：用DexMimicGen（MimicGen数据扩增的灵巧双臂扩展）从少量人类示范自动生成仿真轨迹，11小时生成78万条，相当于6500小时人工示范；用视频生成模型（LoRA微调的Wan2.1图生视频14B等）根据真机首帧和新的语言指令生成“反事实”的机器人视频，把88小时真机数据扩增到827小时；
  • 顶层：Fourier GR-1人形等真机遥操作数据。

给无动作数据贴标签：在所有视频上训练一个VQ-VAE潜动作模型，把相邻画面的变化编码成潜动作，作为一种虚拟的“潜动作形态”参与训练；或者用训练好的逆动力学模型推断伪动作。

预训练约用5万H100 GPU小时。

结果

仿真基准（每任务100条示范后训练）：RoboCasa、DexMimicGen双臂灵巧、GR-1人形三组任务平均成功率45.0%，Diffusion Policy为33.4%、BC-Transformer为26.4%，在GR-1任务上领先17个百分点以上。真机GR-1人形（抓放、开关物体、工业装配、双臂协作等）：比Diffusion Policy在10%数据和全部数据下分别高32.4和30.4个百分点；只用10%数据的GR00T N1只比用全部数据的Diffusion Policy低3.8个百分点。加入视频生成的神经轨迹后，RoboCasa在30/100/300条示范下平均提升4.2/8.8/6.8个百分点，真机8个任务平均提升5.8个百分点。

后来的发展

GR00T N1之后NVIDIA持续迭代（N1.5、GR00T N2），并推出专门用世界模型生成训练数据的DreamGen / GR00T Dreams。“合成数据+真机数据的金字塔”和“用潜动作给无标注视频贴标签”之后在不少人形VLA工作中出现；NVIDIA在2026年3月的新闻稿中称多家人形机器人公司正在采用GR00T N系列模型。

容易误解的地方

  • 双系统并不是两个独立训练的模型，System 1和System 2是联合端到端训练的；“10Hz/120Hz”指两部分的运行频率可以不同。
  • 视频生成的“神经轨迹”本身没有动作，必须靠潜动作或逆动力学模型补标签，标签质量受这些模型限制。

读懂它需要的概念

VLA与WAM的基本结构 可逆流与流匹配 动作表示：离散token、连续动作与动作块 仿真到现实的差距 向量量化与离散token 自由度、运动学与本体感知 模仿学习与行为克隆

本篇术语

  • 数据金字塔　按数据量和与真机的接近程度分层组织训练数据：最多最杂的网络和人类视频在底部，仿真与生成数据在中间，最少但最贴近目标机器人的真机数据在顶部。
  • 神经轨迹（neural trajectories）　用视频生成模型“想象”出来的机器人执行视频，再通过潜动作或逆动力学模型补上动作标签，用作合成训练数据。
  • System 1 / System 2　借用心理学“快思考/慢思考”的说法：System 2是较慢的视觉-语言理解模块，System 1是快速生成运动指令的动作模块。

怎么学

先读π0理解VLM+流匹配动作专家，再读Genie的潜动作部分和MimicGen数据扩增。读原文第2节（结构与数据金字塔）、第4.4节的表2、表3和神经轨迹的消融。动手：用Isaac-GR00T仓库在官方仿真任务上用30、100条示范分别后训练，复现“数据越少，预训练优势越大”的趋势。
