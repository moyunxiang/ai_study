卷积网络识别邮编

Backpropagation Applied to Handwritten Zip Code Recognition
1989论文重要Neural Computation 1989Yann LeCun, Bernhard Boser, John Denker, Donnie Henderson, Richard Howard, Wayne Hubbard, Lawrence Jackel · AT&T贝尔实验室待核对
Neural Computation ↗Karpathy：33年前的深度网络（复现） ↗复现代码 lecun1989-repro ↗在交互版中打开（演化树、学习进度）

问题

美国邮政每天要读大量手写邮编，传统做法先手工设计特征再分类；新认知机有卷积式结构，却没有办法用分类误差去训练整个网络。

方法

把局部感受野和权重共享直接写进网络结构，然后用反向传播从原始像素到类别一次训练所有层，让特征提取器自己学出来。

影响

第一次在真实商业数据上用反向传播端到端训练卷积网络，5%左右的测试错误率证明“结构约束＋梯度学习”可行，这就是卷积网络的诞生。

背景

1980年代末，反向传播已经能训练多层网络，但把一张16×16的图直接接全连接网络，参数多、数据少，很容易过拟合（见泛化与过拟合）；而且平移一下就要重新学。Neocognitron用权重共享解决了平移问题，但它的特征是用赢者通吃规则自组织出来的，没有用“分类对不对”来指导每一层。

这篇论文的数据是美国邮政提供的、真实信件上的手写邮编数字，形态、笔画粗细都很杂乱。问题是：能不能既保留卷积式的结构先验，又用反向传播把整个网络一起训好？

方法

输入是切割好、缩放到16×16的单个数字灰度图，输出10个单元，对应0–9。中间三个隐藏层H1、H2、H3：

  • H1、H2是卷积层（见卷积层、池化与感受野）：每个单元只看上一层5×5的一小块，同一张特征图里所有单元共享同一组权重，相当于拿同一个5×5模板在图上滑动；滑动步长为2，因此每过一层特征图边长减半，起到下采样的作用。网络最多只有12个通道。H1到H2之间的连接是人为挑选的稀疏连接。
  • H3是全连接层，再接输出层。

权重共享是关键：一个5×5卷积核只有25个权重加1个偏置，却在整张图上复用。整个网络约1000个神经元、9760个参数，前向一次约6.4万次乘加。若用同样规模的全连接网络，参数量会多出一个数量级以上。

训练用反向传播计算所有权重的梯度——共享的权重只需把各个位置的梯度加起来。激活函数是tanh，损失是让输出逼近+1（正确类）和−1（其他类）的均方误差，每次只用一个样本更新（见随机梯度下降与小批量），论文还用了对角近似海森矩阵的牛顿法调节步长。

结果

训练集7291张、测试集2007张。训练23遍、共约16.8万次样本呈现，在一台SUN-4/260工作站上训练了3天。测试错误率5.0%（2007张中错102张），训练错误率0.14%。

2022年Karpathy用PyTorch复现，在笔记本CPU上约90秒训完，得到相近结果（测试错误约4.1%）；他再换上交叉熵、AdamW、数据增强、Dropout和ReLU，测试错误降到约1.6%——说明主要差距来自后来30年的训练技巧，而不是结构本身。

后来的发展

这个网络随后在贝尔实验室演变为LeNet与卷积网络：加上专门的下采样层、更深的结构，以及把切割和识别合在一起训练的图变换网络，最终部署到银行支票读取系统。权重共享的卷积层、逐层下采样、端到端反向传播这三样，二十多年后在AlexNet里原样出现，只是网络大了几千倍、换了ReLU和GPU。

容易误解的地方

  • 人们常把“LeNet”专指1998年的LeNet-5，这篇1989年的网络是它的前身，结构不同（用步长2的卷积下采样，没有单独的池化层）。
  • 数字的定位和切割不是这个网络做的，它只识别已经切好的单个数字。

局限与后续

  • 输入必须是已经定位、切割并归一化好的单个数字，整条邮编的分割要依赖另一套系统，切错了网络也无能为力。
    后来针对它的工作　LeNet与卷积网络
  • 数据只有几千张、网络只有约1万个参数，训练却要3天，这样的算力无法扩展到自然图像和上千类别。
    后来针对它的工作　GPU上的卷积网络 AlexNet
  • tanh加均方误差的组合容易饱和、梯度小，H1到H2的稀疏连接也靠人工挑选，训练配方远非最优。

它建立在什么之上

  • 使用
    反向传播1986 · 基础
    用反向传播计算所有层的梯度；共享权重的梯度是它在各个位置梯度之和。
  • 改进
    《Perceptrons》与XOR问题1969 · 基础
    书中提出的局部性困境（局部特征算不出全局性质）没有给出建设性方案；后来是“局部连接 + 多层堆叠”让感受野逐层扩大，才把局部和全局结合起来。
  • 改进
    Neocognitron1980 · 视觉
    保留了局部感受野与权重共享的结构，但用全局的分类误差和反向传播取代赢者通吃的自组织学习，每层特征都为分类服务。
  • 竞争
    时延神经网络TDNN1989.03 · 语音
    同年把权重共享用在语音的时间轴上；两者是同一思想在一维和二维上的平行实践，后来都归入卷积网络。
  • 使用
    随机梯度下降1951 · 基础
    每看一个样本就更新一次参数，共约16.8万次更新。

读懂它需要的概念

卷积层、池化与感受野 反向传播 随机梯度下降与小批量 神经元与激活函数 损失函数 归纳偏置

本篇术语

  • 权重共享　同一张特征图上所有位置使用同一组权重。好处是参数大大减少，而且图案出现在哪里都能被同一个检测器认出来。
  • 步长　卷积模板每次滑动的像素数。步长为2时输出的长和宽都约为输入的一半，起到下采样作用。

怎么学

先弄懂卷积层、池化与感受野和反向传播，尤其是“共享权重的梯度等于各位置梯度之和”。然后读Karpathy的复现博客，打开lecun1989-repro的代码，把网络结构对照博客逐层画出来。动手：先跑原始配方，再逐个加入交叉熵、Adam、平移增强、ReLU，观察每一步测试错误的变化。
