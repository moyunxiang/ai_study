IP-Adapter图像提示

IP-Adapter: Text Compatible Image Prompt Adapter for Text-to-Image Diffusion Models
2023.08论文延伸Hu Ye, Jun Zhang, Sibo Liu, Xiao Han, Wei Yang · Tencent AI Lab待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

只用文字描述很难精确说明想要的画面，而直接微调模型来接受图像提示又贵又不兼容别的工具。

方法

冻结扩散模型，只增加一路专门处理图像特征的解耦交叉注意力，约22M参数。

影响

让「用一张图当提示词」成为即插即用的标配，可与文字和ControlNet同时使用。

方法

图像提示的思路是：用CLIP图像编码器把参考图提取成特征，再让扩散模型去注意这些特征。已有做法是把图像特征和文字特征混进同一个交叉注意力，要微调整个模型。IP-Adapter的关键是解耦交叉注意力：在U-Net原有的文字交叉注意力旁边，另加一套独立的、只处理图像特征的交叉注意力层，二者输出相加。训练时只训练新增部分。

论文称仅22M参数的适配器就能达到与全量微调的图像提示模型相当甚至更好的效果。因为原模型被冻结，它可以直接用于同一基础模型微调出的其他模型，也能和ControlNet、T2I-Adapter等结构控制工具一起使用，还能与文字提示组合成多模态提示。

后来的发展

它成为Stable Diffusion开源生态里做风格迁移和保持人物相似的基础组件，后续的人物保持与视频生成方法常借用它。

局限与后续
