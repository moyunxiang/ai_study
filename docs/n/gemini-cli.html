Gemini CLI

Gemini CLI: your open-source AI agent
2025.06系统延伸Taylor Mullen, Ryan J. Salva · Google待核对
Google官方公告 ↗在交互版中打开（演化树、学习进度）

问题

终端里的编码智能体当时主要是Claude Code和Codex CLI，而且需要付费或自备API额度，开发者很难免费试用。

方法

推出开源的命令行智能体，个人Google账号即可免费调用Gemini 2.5 Pro，并和VS Code里的Gemini Code Assist共享技术。

影响

让终端智能体成为各大厂的标配形态，也用免费额度抬高了竞争门槛。

方法

Google在2025年6月25日发布Gemini CLI，官方称它是开源的AI智能体，把Gemini直接带进开发者的终端。它不只写代码，也可用于内容生成、问题求解、深度研究和任务管理。使用方式有三种：用个人Google账号登录免费使用Gemini 2.5 Pro，或用Google AI Studio、Vertex AI的密钥获得更高额度。

因为开源，开发者可以查看并贡献代码；官方称它与Gemini Code Assist共用技术，因此终端和VS Code里的体验一致。它的出现使Claude Code与终端编码智能体与Codex CLI所代表的“终端里的智能体”成了三家共同的产品形态，后来AGENTS.md也把它列为支持的工具之一。

局限与后续

  • 终端智能体的权限、沙箱和提示注入风险仍要使用者自己把关。
