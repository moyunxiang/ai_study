Open-Reasoner-Zero开源零RL

Open-Reasoner-Zero: An Open Source Approach to Scaling Up Reinforcement Learning on the Base Model
2025.03论文延伸Jingcheng Hu, Yinmin Zhang, Qi Han, Daxin Jiang, Xiangyu Zhang, Heung-Yeung Shum · 阶跃星辰 / 清华大学待核对
arXiv ↗GitHub ↗在交互版中打开（演化树、学习进度）

问题

DeepSeek-R1-Zero说明直接在基座模型上做大规模RL就能长出长推理，但训练代码和数据没有公开；大家也不确定GRPO、KL约束、格式奖励这些设计是否必需。

方法

用最朴素的配置复现：原版PPO加GAE（λ=1、γ=1）、只看答案对不对的0/1奖励、不加KL正则，配上几万道精选题，在同一基座Qwen2.5-32B上训练并完整开源。

影响

在AIME2024、MATH500和GPQA Diamond上超过同基座的DeepSeek-R1-Zero-Qwen-32B，训练步数只要其约十分之一；代码、数据和权重全部公开，成为「零RL」复现的常用参照。

方法

「零RL」指不做监督微调，直接对基座模型做强化学习。Open-Reasoner-Zero刻意把配置做到最简：

  • 算法：原版PPO，优势用广义优势估计GAE估计，取 λ = 1, γ = 1（相当于用整条回答的最终奖励减去价值估计），没有KL惩罚项；
  • 奖励：只抽取回答中 <answer> 标签里的内容与参考答案比对，一致得1、否则得0，不像DeepSeek-R1那样另加格式奖励；
  • 数据：从AIME（2023年及以前）、MATH、NuminaMath、Tulu3 MATH、OpenR1-Math-220k和AoPS论坛收集并清洗出几万道数学与通用推理题，另用程序合成逻辑谜题等。

在Qwen2.5-32B基座上，训练过程中准确率和回答长度一起稳定增长，复现了R1-Zero的「越训越长」现象。分析显示，学到的价值函数（critic）能识别并压低重复啰嗦的回答模式，使优势估计更稳，这是作者选择PPO而非GRPO的理由之一。与同期的DAPO、Dr. GRPO与R1-Zero再审视一起，说明R1-Zero式训练的关键在于数据和稳定性，而不是复杂的技巧。

局限与后续

  • 需要训练一个与策略同规模的价值模型，资源开销高于无critic的GRPO类方法。
    本站还没有记录针对它的后续工作（不代表没有人解决）
  • 实验集中在Qwen2.5系列基座上，而Qwen基座本身已有较强推理和自我反思倾向，结论能否推广到其他模型家族需要另外验证。

怎么学

先读DeepSeek-R1和PPO → 读原文第2节「最简配方」和第3.2节消融 → 动手：在小模型上分别用λ=0.95和λ=1的GAE跑数学题RL，比较训练稳定性和回答长度。
