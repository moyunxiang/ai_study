MCAN协同注意力

Deep Modular Co-Attention Networks for Visual Question Answering
2019.06论文延伸CVPR 2019Zhou Yu, Jun Yu, Yuhao Cui, Dacheng Tao, Qi Tian · 杭州电子科技大学等待核对
arXiv ↗代码 ↗在交互版中打开（演化树、学习进度）

问题

视觉问答要把问题里的关键词和图里的关键物体对上，但当时的协同注意力模型都很浅，叠深了几乎不涨分。

方法

把自注意力和“问题引导图像”的引导注意力组合成一个模块化协同注意力层，像Transformer一样层层堆叠。

影响

在VQA-v2上以单模型70.63%刷新纪录，成为BERT式视觉语言预训练普及前最常用的VQA强基线和代码库之一。

方法

2019年的视觉问答（VQA）主流做法是：用自底向上注意力提取图中几十个物体区域的特征，再让问题去“注意”这些区域。所谓协同注意力，是让问题的词和图像区域互相找对应。问题在于当时这类模型只有一两层，作者指出深层的协同注意力模型相比浅层几乎没有提升。

MCAN借用了Transformer的两种注意力单元：自注意力（SA，问题词之间、区域之间各自建模关系）和引导注意力（GA，以问题特征为查询去关注图像区域）。一个模块化协同注意力（MCA）层由“问题SA + 图像SA + 问题引导图像的GA”组成，多层级联加深；论文比较了逐层堆叠和编码器-解码器两种级联方式。最后把问题和图像特征各自汇总、融合后做答案分类。

摘要报告，最佳单模型在VQA v2的test-dev上达到70.63%总体准确率，明显超过此前最好方法。它的代码库后来也被很多VQA工作当作基线框架使用。

它建立在什么之上

  • 使用
    Transformer2017.06 · LLM
    协同注意力层直接由Transformer式的多头自注意力与交叉注意力单元拼装。
  • 使用
    自底向上注意力2017.07 · 多模态
    以BUTD的Faster R-CNN区域特征作为图像输入。
  • 改进
    堆叠注意力SAN2015.11 · 多模态
    把SAN一类只有一两层的浅层问题→图像注意力推进到可有效加深的协同注意力。
  • 改进
    HieCoAtt协同注意力2016.05 · 多模态
    图像与问题之间只用一次线性亲和矩阵交互，多模态融合较浅，层数加深后难有收益。
  • 使用
    VQA v22016.12 · 数据·评测
    主要在VQA-v2上训练与评测。

读懂它需要的概念

注意力机制 自注意力与多头注意力 Transformer层的结构 分类、检测、分割

本篇术语

  • 协同注意力（co-attention）　同时让问题关注图像、图像关注问题（或问题引导图像），在两种模态之间建立双向对应的注意力机制。

怎么学

先读懂自底向上注意力的区域特征和Transformer的注意力，再看MCAN原文第3节MCA层的结构图，对照代码跑一次VQA-v2小规模训练。
