指针-生成器摘要

Get To The Point: Summarization with Pointer-Generator Networks
2017.04论文重要ACL 2017Abigail See, Peter J. Liu, Christopher D. Manning · 斯坦福大学、Google Brain待核对
arXiv ↗ACL Anthology ↗作者博客讲解 ↗在交互版中打开（演化树、学习进度）

问题

用Seq2Seq做生成式摘要，多句摘要里常把人名、比分抄错，词表外的词只能输出UNK，还会反复生成同一句话。

方法

每一步算一个0到1之间的“生成概率”p_gen，用它把“从词表生成一个词”和“沿注意力从原文复制一个词”两种分布加权混合；再记录各原文位置累计被关注了多少（覆盖向量），对重复关注同一处加以惩罚。

影响

在CNN/Daily Mail上比此前生成式摘要模型高约4个ROUGE点，几乎消除了重复；“复制+生成”混合分布和覆盖损失成为预训练模型之前神经摘要的标准组件。论文也坦白指出模型仍以抄句子为主，未超过“取前三句”基线。

背景

摘要分两类：抽取式从原文挑句子拼起来，语法和事实都有保障，但不能改写；生成式像人一样重新组织语言。神经生成式摘要用带注意力的神经网络为单句生成标题，Nallapati等人随后把注意力阅读器与CNN/DM的CNN/Daily Mail新闻语料改成多句摘要数据集（平均781词的文章对应约3.75句、56词的摘要）。

但在长文档、多句摘要上，Seq2Seq加注意力机制的基线问题很多：比分“2-0”这类词表外的词变成UNK；即使在词表内，罕见的人名也常被换成一个常见名字；生成到后面会一遍遍重复同一句话。

方法

指针-生成器。解码第t步时，注意力分布aᵗ给出原文每个位置的权重，上下文向量为h*_t。计算

p_gen = σ(w_hᵀ·h*_t + w_sᵀ·s_t + w_xᵀ·x_t + b)

（s_t是解码器状态，x_t是当前输入词），然后在“词表 ∪ 本文出现的所有词”这个扩展词表上得到最终分布：

P(w) = p_gen · P_vocab(w) + (1 − p_gen) · Σ_{i: w_i = w} a_iᵗ

如果w是词表外的词，第一项为0，但只要它在原文出现过，就能靠第二项被复制出来。这和指针网络“输出指向输入位置”的思想一致，区别是这里用一个软开关同时保留了生成能力。

覆盖机制。借用覆盖机制的想法，维护覆盖向量cᵗ = Σ_{t'<t} a^{t'}，即每个原文位置至今累计得到的注意力，并把它作为注意力打分的额外输入。另加覆盖损失：

covloss_t = Σ_i min(a_iᵗ, c_iᵗ)

只惩罚“这一步又关注了已经关注过的位置”，而不像翻译那样要求每个词都被覆盖，因为摘要本来就不该覆盖全文。

训练细节。文章截断到400词，词表5万；先训练指针-生成器，最后只加约3000步覆盖损失（λ=1）微调，从一开始就加反而干扰主任务。

结果

CNN/Daily Mail测试集ROUGE-1/2/L（见文本生成的自动指标）：Seq2Seq+注意力基线31.33 / 11.81 / 28.83；加指针36.44 / 15.66 / 33.42；再加覆盖39.53 / 17.28 / 36.38，比此前最好的生成式模型（35.46 / 13.30 / 32.65，匿名化数据）高约4个点。但简单取文章前三句的lead-3基线为40.34 / 17.70 / 36.57，仍略高于本文模型。指针与覆盖只增加了极少参数（基线约2150万参数）。分析显示，最终模型有35%的情况整句照抄原文，人写的摘要只有1.3%；测试时p_gen平均只有0.17，模型主要在复制。

后来的发展

复制机制与覆盖损失被广泛用于摘要、对话、数据到文本生成等任务。论文暴露的问题，即ROUGE偏爱抽取、模型过度抄写、lead-3难以超越，推动了后续研究：BART和PEGASUS摘要预训练用预训练的Transformer编码器-解码器大幅提升生成式摘要；人类反馈学摘要直接用人类偏好代替ROUGE作为训练目标。大模型时代不再需要显式的指针结构，注意力本身就能完成复制，但“生成内容与原文事实不符”（幻觉）仍是摘要的核心难题。

读懂它需要的概念

编码器-解码器 注意力机制 Softmax与logits 随机变量与概率分布 文本生成的自动指标 解码：贪心、束搜索、温度与top-p

本篇术语

  • 生成式摘要 / 抽取式摘要　抽取式从原文挑选句子拼成摘要；生成式像人一样用自己的话重写，可以出现原文没有的词。
  • ROUGE　摘要的自动评价指标，计算生成摘要与人写参考摘要之间单词（ROUGE-1）、二元组（ROUGE-2）或最长公共子序列（ROUGE-L）的重合程度。
  • lead-3　直接取新闻前三句作为摘要的基线。新闻通常把最重要的信息放在开头，所以这个基线非常强。

怎么学

先补注意力机制和文本生成的自动指标，读过Seq2Seq和指针网络。读原文第2节的公式(8)–(13)，再看第7节对“模型到底有多抽象”的分析。作者博客有清晰的图解。动手：在一个小的Seq2Seq摘要模型上加入p_gen混合分布，比较加入前后人名、数字被抄错的次数；再加覆盖损失，统计重复三元组的比例。
