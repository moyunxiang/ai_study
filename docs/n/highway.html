Highway网络

Highway Networks
2015.05论文重要ICML 2015 Deep Learning Workshop；完整版NIPS 2015Rupesh Kumar Srivastava, Klaus Greff, Jürgen Schmidhuber · IDSIA待核对
arXiv ↗完整版 Training Very Deep Networks ↗在交互版中打开（演化树、学习进度）

问题

网络越深越难训：即便用了方差保持的初始化，几十层的普通网络用SGD也训不下去，只能靠分阶段训练或在中间层加辅助损失。

方法

借用LSTM的门：每层输出 = 变换后的结果×门T + 原输入×(1−T)。门关上时这一层就是恒等映射，信息和梯度可以沿“高速公路”无衰减地穿过很多层。

影响

第一次用普通SGD直接训练上百层的前馈网络。半年后ResNet把门去掉、只留恒等捷径，成为深度网络的标准结构。

背景

到2015年，ImageNet上的进步大多来自更深的网络（VGG、GoogLeNet / Inception），理论上深网络也能比浅网络更高效地表示某些函数。但多加几层并不简单：普通网络超过一二十层后，训练误差本身就降不下去。当时的对策都很曲折——专门的初始化（Xavier初始化、He初始化与PReLU），先训浅网络再加深，或者像GoogLeNet那样在中间层挂辅助分类器、像FitNets那样用老师网络的中间输出做提示。作者注意到，循环网络里同样的问题早已由LSTM的门控解决：门控让信息沿时间几乎无衰减地传很远（见梯度消失问题）。

方法

普通层是y = H(x)。Highway层多一个“变换门”T(x) = σ(W_T·x + b_T)：

y = H(x)·T(x) + x·(1 − T(x))

逐元素相乘。T接近0时y ≈ x，这一层直接把输入搬运过去，雅可比矩阵接近单位矩阵，梯度原样回传；T接近1时就是普通层。网络可以按样本、按单元自己决定每层“改多少、留多少”。论文一般形式里还有单独的携带门C，为简单起见取C = 1 − T。

关键的初始化：把门的偏置b_T设成负数（如−1、−3），让网络在开始时偏向“搬运”，深层网络一开始就近似浅网络，梯度通畅；这一招直接借自LSTM遗忘门的偏置初始化。好处是它与H用什么激活、权重怎么初始化无关。

输入输出维度必须相同，需要改变维度时插入一个普通层。卷积版的H和T都是卷积。

结果

MNIST上比较10、20、50、100层：普通网络（用He初始化、各自随机搜索40组超参数）层数一多训练误差明显变差；Highway网络几乎不受深度影响，100层的最终训练误差比10层的好约一个数量级，作者还开始训练一个900层的网络且未见优化困难。CIFAR-10上，19层、约230万参数的Highway网络直接反向传播训练就达到92.24%，好于需要老师网络两阶段训练的FitNet（91.61%）。

后来的发展

2015年12月的ResNet相当于把门固定为“恒等+残差相加”：y = x + F(x)，没有额外参数，在ImageNet上训到152层并夺冠，此后残差连接取代了Highway成为默认做法，Transformer的每个子层也包着残差。Highway的门控思想则留在了LSTM、GRU以及后来的门控线性单元中。2024年的超连接重新回到“可学习地混合捷径与变换”的思路。

局限与后续

  • 门T需要和H一样多的参数与计算，每层成本约翻倍。
    后来针对它的工作　ResNet
  • 门可能学会关闭捷径，信息通路并非始终畅通；在ImageNet这样的大规模任务上没有验证几百层网络的效果。
    后来针对它的工作　ResNet
  • 深度带来的表示收益并不清楚：很多层可能学成近似恒等，存在冗余。
    后来针对它的工作　随机深度

它建立在什么之上

  • 延续
    LSTM1997 · 基础
    把LSTM沿时间传递信息的门控和遗忘门负偏置初始化，搬到前馈网络的深度方向上。
  • 改进
    梯度消失问题1994 · 基础
    门关闭时层的雅可比接近单位矩阵，梯度可跨越上百层不衰减，解决了深层前馈网络的梯度消失。
  • 竞争
    Xavier初始化2010 · 基础
    初始化方案依赖激活函数的具体形式；Highway的负偏置初始化与H的形式无关。
  • 竞争
    GoogLeNet / Inception2014.09 · 视觉
    GoogLeNet靠中间层的辅助损失帮助梯度传递；Highway用结构上的捷径直接解决，不需要额外损失。
  • 改进
    He初始化与PReLU2015.02 · 基础
    实验表明即便用He初始化，普通网络到50、100层仍难以优化，而Highway网络不受深度影响。

后来的相关工作

  • 竞争
    ResNet2015.12 · 视觉 已核对
    同一时期针对“很深的网络难训练”的另一条路线：Highway用依赖数据的门控决定“变换”与“直通”的比例；ResNet用无参数的恒等捷径直接相加。ResNet论文把Highway列为同期工作，并称它还没有显示出极深带来的精度收益。
  • 使用
    BiDAF双向注意力流2016.11 · NLP
    字符向量与词向量拼接后经过两层Highway网络。
  • 竞争
    随机深度2016.03 · 基础
    同样想让极深网络好训练，Highway靠学出的门，随机深度靠随机丢层
  • 延续
    超连接2024.09 · 基础
    与Highway一样让层间连接可学习，但Highway是门控一条流，超连接是多条流的混合。

读懂它需要的概念

多层感知机 门控机制 梯度消失与梯度爆炸 残差连接 参数初始化

本篇术语

  • 变换门 / 携带门　变换门T决定输出中有多少来自本层的变换H(x)，携带门C决定有多少直接来自输入x；本文取C=1−T。
  • FitNets　2014年的一种训练细深网络的方法：先训一个浅而宽的老师网络，再用老师中间层的输出作为“提示”训练学生网络。

怎么学

先弄懂LSTM的遗忘门和门控机制，再读原文第2节（式3–5和2.2节的偏置初始化，只有两页）。然后读ResNet，比较y = H·T + x·(1−T)与y = x + F(x)的差别。动手：在MNIST上搭50层的普通MLP和Highway MLP，记录训练损失曲线和各层梯度范数。
