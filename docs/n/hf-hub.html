Hugging Face Hub与Datasets

2020系统重要Datasets论文：EMNLP 2021 DemoHugging Face团队（Lhoest, Wolf, Chaumond, von Platen et al.） · Hugging Face待核对
Hugging Face Hub ↗Datasets论文（arXiv） ↗Hub文档 ↗在交互版中打开（演化树、学习进度）

问题

预训练模型和数据集散落在各个论文的网盘、GitHub和个人主页上，格式各异、没有版本和说明，复现一篇论文常常先卡在“找到并读进同一份数据和权重”。

方法

做一个像GitHub一样、基于git的公共仓库平台：每个模型、数据集都是一个带版本、说明卡片和统一加载接口的仓库，一行代码就能下载使用。

影响

成为开源AI事实上的发布渠道：新开源模型几乎都首发在Hub上，llama.cpp、vLLM、MLX等工具都直接从Hub拉取权重。

背景

Caffe Model Zoo让人第一次能下载别人训练好的CNN，但它只是Caffe项目里的一份列表，权重放在各自的链接上。到了BERT之后的预训练时代，模型变体爆炸式增长：同一个BERT有不同语言、大小、下游任务的微调版。Hugging Face Transformers统一了加载代码，却仍需要一个地方存放成千上万份权重。

数据也是同样的问题。NLP研究要在几十个基准上评测，每个数据集有自己的下载脚本、文件格式和切分方式，大语料又大到放不进内存。

方法

Hub：每个模型、数据集、演示应用（Spaces）都是一个git仓库，大文件用git-lfs存储，因此天然有版本历史、分支和提交记录。仓库首页是一份模型卡/数据卡（Markdown加元数据），写明来源、用途、许可证和局限。任何库都可以用from_pretrained('用户名/模型名')这样的统一接口按名字下载。

Datasets库（2020年开始开发）：load_dataset('名字')从Hub取得数据，按数据集自带的构建脚本转换成有类型的表格。底层用Apache Arrow列式存储并做内存映射，数据留在磁盘上、按需读取，所以在内存很小的机器上也能处理大语料；放不下磁盘的数据集还可以用流式模式边下载边处理。

结果

Datasets论文（2021年9月）称，开发一年后库里已有650多个数据集、250多位贡献者。本次核对时，Hub模型页显示约325万个模型，数据集页显示约114万个数据集。

后来的发展

开源大模型时代的分发几乎都经过它：LLaMA之后的各类微调版、GGUF与k-quants量化版、Stable Diffusion开源的LoRA微调扩散模型都在Hub上流通；Hugging Face PEFT库、Diffusers、Hugging Face LeRobot等库都以它为存储后端；Open LLM Leaderboard也建在它上面。2026年2月llama.cpp背后的公司加入Hugging Face（ggml.ai加入Hugging Face）。据路透社、CNBC等报道，2026年8月NVIDIA同意以约129亿美元收购Hugging Face，美国司法部已就此展开问询，交易尚待监管审批。

它建立在什么之上

  • 使用
    BERT2018.10 · LLM
    Hub最早的大量内容是BERT及其各语言、各任务的微调变体，正是这类变体爆炸让集中托管变得必要。
  • 延续
    Hugging Face Transformers2018.11 · 系统·效率
    Transformers库统一了模型加载代码，Hub为它提供按名字下载的权重存储，两者合起来才让“一行代码用上别人的模型”成立。
  • 竞争
    Kaggle数据竞赛2010.04 · 事件
    Kaggle以竞赛为中心托管数据集；Hub以模型和数据仓库本身为中心，并与训练库直接打通，后来成为开源模型的主要分发处。
  • 改进
    Caffe Model Zoo2014 · 系统·效率
    Model Zoo只是一份分散链接的列表；Hub把权重放进带版本、卡片和统一接口的仓库，任何人都能直接上传和加载。
  • 改进
    Papers with Code与SOTA榜2018.07 · 数据·评测
    站点已不再以原形态运行，历史榜单的维护和存档依赖其他平台。

读懂它需要的概念

预训练与微调 迁移学习 训练集、验证集与测试集 基准、排行榜与SOTA

本篇术语

  • 模型卡（model card）　模型仓库首页的说明文档，记录训练数据、用途、评测结果、许可证和已知局限。数据集对应的叫数据卡。
  • git-lfs　git的大文件扩展：仓库里只存一个指针，真正的几GB权重文件放在单独的存储里，按需下载。
  • 内存映射　让程序像访问内存一样访问磁盘文件，操作系统只在用到某部分时才把它读进来，因此能处理比内存还大的数据。

怎么学

注册Hub账号，用huggingface_hub和datasets库下载一个小模型和一个数据集（比如GLUE里的SST-2），看它们在本地缓存成什么文件。然后读Datasets论文第3节（Arrow与内存映射）。最后把自己微调的一个小模型连同模型卡上传成仓库，体会版本和卡片的作用。
