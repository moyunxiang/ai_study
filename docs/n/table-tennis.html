乒乓球机器人

Achieving Human Level Competitive Robot Table Tennis
2024.08论文延伸D'Ambrosio, Abeyruwan, Graesser, Iscen, Ben Amor, Bewley等（共27位） · Google DeepMind待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

乒乓球要求毫秒级反应、高速运动和对不同对手的适应，此前学习型机器人没有达到过人类业余水平。

方法

用分层策略：低层技能控制器加描述其能力的技能说明，高层控制器挑选技能；用从真实世界迭代定义的任务分布实现零样本sim2real，并在比赛中实时适应对手。

影响

首个达到业余人类水平的竞技乒乓球学习型机器人。

方法

系统分为低层和高层。低层是多个擅长不同击球类型的技能控制器，每个都附有“技能说明”记录它能处理的来球范围，帮助弥合仿真和真机的差距；高层控制器根据来球和对手情况，从中选出合适的技能。

训练用仿真加零样本迁移（见域随机化与Sim2Real），任务分布通过与真实世界迭代对齐来确定，并自动形成课程；比赛中还会实时调整对未见过对手的策略。

结果

论文评估了29场机器人对人类比赛，机器人赢了13场（45%）；对手均为未见过的人，从初学者到锦标赛水平。机器人对初学者全胜（100%），对中级选手胜率55%，对最高水平选手全败。

后来的发展

结果说明学习型系统可以在快速物理交互里达到业余水平，和Swift无人机竞速一起代表竞技机器人学习的进展。
