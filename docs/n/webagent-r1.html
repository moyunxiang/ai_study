WebAgent-R1多轮网页RL

WebAgent-R1: Training Web Agents via End-to-End Multi-Turn Reinforcement Learning
2025.05论文延伸Zhepei Wei, Wenlin Yao, Yao Liu, Weizhi Zhang, Qin Lu, Liang Qiu, Changlong Yu, Puyang Xu et al. · 亚马逊 / 弗吉尼亚大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

R1式的强化学习在单轮数学题上效果很好，但网页任务要跨很多步、面对动态变化的页面，怎样把这种简单的结果奖励RL直接用在多轮网页智能体上还没有清楚的做法。

方法

做一个端到端的多轮RL框架：智能体直接在网页环境里在线交互，异步地生成大量轨迹，只按任务成功与否给二值奖励来训练。

影响

在WebArena-Lite上让3B、8B开源模型超过o3等闭源模型，并用对比实验说明行为克隆预热和“先思考再操作”的提示对多轮网页RL很关键。

方法

与WebRL自演化课程网页RL需要训练专门的结果奖励模型和课程生成器不同，WebAgent-R1尽量简单：

  • 智能体每一步看当前网页，先写思考再输出一个操作（点击、输入、跳转等），环境执行后返回新页面；
  • 训练时异步地并行生成大量多样的轨迹，任务完成就给1、否则给0，没有中间奖励；
  • 优化采用把GRPO推广到多轮交互的组相对策略优化，整条轨迹共享一个结果奖励。

在WebArena的精简版WebArena-Lite上，Qwen-2.5-3B的成功率从6.1%提升到33.9%，Llama-3.1-8B从8.5%提升到44.8%，超过此前的最好方法以及OpenAI o3等强闭源模型。分析部分有两点结论：一是“先思考再操作”的提示格式明显有帮助，增加交互步数也能起到测试时扩展的作用；二是作者比较了两种初始化——不做预热直接RL的WebAgent-R1-Zero效果差很多，从长思维链模型出发的WebAgent-R1-CoT也不一定更好，说明先用行为克隆打底这一步很重要。

局限与后续

  • 只有任务成功与否的二值奖励，长任务里每一步的信用分配仍很粗；失败轨迹中做对的部分得不到奖励。

怎么学

先读DeepSeek-R1和WebRL自演化课程网页RL → 读原文第3节框架与第5节初始化策略的对比 → 动手：在一个小网页任务上对比“直接操作”和“先写一句思考再操作”两种提示的成功率。
