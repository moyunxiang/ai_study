Transcoders

Transcoders Find Interpretable LLM Feature Circuits
2024.06论文延伸NeurIPS 2024Jacob Dunefsky, Philippe Chlenski, Neel Nanda待核对
论文 ↗在交互版中打开（演化树、学习进度）

问题

用SAE分析MLP层很麻烦：SAE特征是许多带非线性的神经元的线性组合，做电路分析不是图过大，就是分不清局部与全局行为。

方法

训练transcoder去逼近MLP层本身（输入进去、输出出来），用更宽的稀疏层取代稠密层，使电路能直接用权重分析。

影响

给穿过MLP的电路分析提供了干净的工具，后来被用作归因图和跨层转码器的基础。

方法

SAE的任务是重建某处的激活；transcoder的任务则不同，它要重建的是一个MLP子层的输入到输出的映射：用一个更宽但稀疏激活的MLP去近似原本稠密激活的MLP。这样，每个transcoder特征都有明确的输入权重和输出权重，一条电路连线的强度就可以直接由权重相乘算出，并自然分解成两项：随输入变化的项和不随输入变化的项。

作者在120M、410M和1.4B参数的语言模型上训练了transcoder，称它们在稀疏度、忠实度和人的可解释性上至少不输SAE；还用它们解释了GPT-2 small里的“大于”（greater-than）电路，得到了新的发现。

局限与后续

  • transcoder只替换MLP，注意力部分仍需另外处理，且近似存在误差。
