TD-MPC2

TD-MPC2: Scalable, Robust World Models for Continuous Control
2023.10论文重要ICLR 2024Nicklas Hansen, Hao Su, Xiaolong Wang · UC San Diego待核对
arXiv ↗项目主页（代码与300+模型） ↗arXiv HTML全文 ↗在交互版中打开（演化树、学习进度）

问题

TD-MPC在单个连续控制任务上很强，但每个任务要单独调参，把模型和数据放大后效果反而下降，还会因梯度爆炸发散，做不成一个通吃多任务的大模型。

方法

保留“不重建观测的隐空间世界模型+短时域规划+终端价值”的框架，改掉一批不稳的设计：SimNorm归一化隐状态、奖励和价值改成分类式回归、5个Q函数集成、可学习任务嵌入和动作维度掩码。

影响

一套超参数在4个领域104个连续控制任务上胜过SAC、DreamerV3和TD-MPC；单个3.17亿参数的世界模型学会80个任务，且性能随参数量持续上升。

背景

TD-MPC走的是MuZero式的“价值等价”路线：世界模型不预测画面，只在隐空间里预测奖励和价值，然后用规划与模型预测控制在模型里试很多条动作序列、执行最好那条的第一步。它比无模型的SAC更省样本，但每个任务要单独调参，有时梯度爆炸而发散，模型做大或混入多任务数据后效果反而变差。

同期“一个模型做很多控制任务”的尝试（如Gato、RT-1）都靠模仿专家示范；作者想用强化学习从质量参差的数据里学出能放大的多任务世界模型。

方法

五个部件，都是带Layer Normalization的小MLP，并都以任务嵌入e为条件：编码器z = h(s, e)、隐空间动力学z′ = d(z, a, e)、奖励r̂ = R(z, a, e)、终端价值q̂ = Q(z, a, e)、策略先验â = p(z, e)。

模型训练。从回放池取长为H的轨迹，在隐空间连续展开，三项损失相加：预测的下一隐状态对齐编码器对真实下一观测的编码（停止梯度，类似BYOL的联合嵌入预测，不解码画面）；奖励预测；价值预测，目标是TD目标q_t = r_t + γ·Q̄(z′_t, p(z′_t))（见时序差分与自举）。不同任务的奖励尺度差别巨大，所以奖励和价值都在对数变换后的空间里离散成若干桶，用交叉熵做分类（思路来自分布式RL C51和DreamerV3）。

稳定性改动。SimNorm：把隐向量切成若干组，每组做一次Softmax与logits，让隐状态落在单纯形上，防止梯度爆炸；用5个Q函数，每次随机取两个的最小值做目标，抑制高估。策略先验是最大熵策略（同SAC），熵系数按滑动统计自动调。

规划。每步用MPPI采样一批长H的动作序列（部分来自策略先验），在模型里算“H步奖励+终端价值”，迭代更新高斯分布，只执行第一个动作。

多任务。输入输出补零到最大维度并掩掉无效动作维，不同身体的任务就能放进同一个模型。

结果

单任务：在DMControl、Meta-World、ManiSkill2、MyoSuite共104个任务上，用同一套超参数总体优于SAC、DreamerV3和原版TD-MPC（后者偶尔梯度发散）；默认模型只有500万参数，DreamerV3约2000万。多任务：在由240个单任务智能体回放数据组成的5.45亿条转移上训练1M到317M五种规模，在80任务集上归一化得分从16.0升到70.6，最大模型在单块RTX 3090上约需33 GPU天，且未见饱和。70任务预训练的19M模型微调到新任务，2万步内得分约为从零训练的2倍。

后来的发展

TD-MPC2公开了300多个模型检查点，成为连续控制中常用的基于模型基线。它和SimBa、价值型RL的可预测扩展、1000层网络的自监督RL一起代表“让RL网络像监督学习一样放大”的一系列工作，归一化和分类式价值回归（另见用分类训练价值函数）是其中反复出现的配方。

容易误解的地方

  • 它的“世界模型”不能生成画面，只能在隐空间里预测奖励和价值，和DreamerV3、视频世界模型不是一类东西。
  • 80任务的多任务模型是离线学自已有智能体的回放数据，不是从零在线探索80个任务。

它建立在什么之上

  • 使用
    分布式RL C512017.07 · RL
    沿用把回报离散成若干桶、用交叉熵训练的做法，使奖励尺度相差悬殊的任务能共用一套超参数。
  • 改进
    EfficientZero2021.10 · RL
    只适用于离散动作，无法直接用于连续控制。
  • 竞争
    Gato2022.05 · RL
    Gato靠模仿大量专家示范做多任务；TD-MPC2用强化学习从混合质量的回放数据中学出多任务世界模型，不要求专家数据。
  • 竞争
    DreamerV32023.01 · 具身·世界模型
    二者都追求一套超参数通吃；DreamerV3重建观测并在想象中训练策略，TD-MPC2不解码观测、靠在线规划，在难的连续控制任务上明显更好，离散任务则仍是DreamerV3的强项。
  • 竞争
    SAC2018.01 · RL
    SAC是主要的无模型基线且需逐任务调参；TD-MPC2在104个任务上总体更省样本，并借用了SAC的最大熵策略作为规划的先验。
  • 使用
    BYOL2020.06 · 视觉
    隐状态预测用BYOL式的联合嵌入目标：预测值对齐停止梯度后的目标编码，从而无需解码观测。
  • 改进
    TD-MPC2022.03 · RL
    修正TD-MPC的梯度爆炸和超参数敏感，让它从单任务、逐任务调参变成一套超参数、可放大到3亿参数的多任务模型。

读懂它需要的概念

基于模型的强化学习 规划与模型预测控制 时序差分与自举 Actor-Critic与优势函数 世界模型 交叉熵 归一化层

本篇术语

  • 隐式世界模型　不生成未来观测、只在网络内部的隐向量上预测下一状态、奖励和价值的环境模型。
  • MPPI　模型预测路径积分：每步随机采样很多条动作序列，按模型预测的回报加权平均来更新动作分布，只执行第一步，下一步重新规划。
  • SimNorm　把隐向量分成若干组、每组做softmax，使每组都是一个概率向量；数值有界，防止训练中梯度爆炸。
  • 动作掩码　不同机器人动作维数不同，统一补零到最大维度后，把当前任务不存在的维度屏蔽，不参与预测和采样。

怎么学

先读TD-MPC和规划与模型预测控制，理解“模型里试动作序列、执行第一步”。再读原文第3节（五个部件、式3–6）和附录A的改动清单，以及第4节的规模表。动手：用官方代码在DMControl的一个简单任务上跑5M模型，再把SimNorm关掉，对比训练曲线的稳定性。
