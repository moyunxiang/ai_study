Devin

Introducing Devin, the first AI software engineer
2024.03事件延伸官方公告 2024-03-12Cognition AI待核对
官方公告 ↗在交互版中打开（演化树、学习进度）

问题

AutoGPT式的自主智能体在真实软件任务上不可靠；SWE-bench上此前最好的结果也只能解决很小一部分GitHub issue。

方法

Cognition发布号称“第一个AI软件工程师”的Devin：在沙箱里配备命令行、代码编辑器和浏览器，长时间自主规划并完成工程任务。

影响

引发“AI软件工程师”热潮，也促使学界做出开源复现（如OpenHands）和更严格的评测。

方法

官方公告（2024年3月12日）称Devin能规划并执行需要数千个决策的复杂工程任务，在沙箱计算环境里使用shell、代码编辑器和浏览器，能向用户实时汇报进度、接受反馈。示例包括：读一篇博客后学会用不熟悉的技术、端到端搭建并部署网站、定位并修复代码库中的bug、微调模型、解决开源仓库的GitHub issue，以及在Upwork上接真实任务。

关键数字：在SWE-bench上，官方称Devin在随机抽取的25%子集上不借助任何提示，端到端解决了13.86%的issue，而此前最好为1.96%；即使告诉模型要改哪些文件，此前最好也只有4.80%。这些是公司的自我宣称，官方当时表示会稍后发布详细技术报告。此后社区对演示的真实性有过争议，本次未核实。
