独立成分分析ICA

Independent Component Analysis, A New Concept?
1994.04论文重要Signal Processing 36(3), 1994Pierre Comon · Thomson-Sintra（法国）待核对
Signal Processing（DOI） ↗Wikipedia: Independent component analysis ↗Hyvärinen & Oja 2000教程（FastICA） ↗在交互版中打开（演化树、学习进度）

问题

多个信号源被线性混在一起（比如鸡尾酒会上几个麦克风同时录到几个人说话），只拿到混合后的信号，能否把各个源分离出来？主成分分析PCA只能让分量互不相关，分不开它们。

方法

寻找一个线性变换，使变换后的各分量在统计上尽量相互独立（而不只是不相关），用基于互信息的对比函数来度量独立程度。

影响

把“独立成分分析”定义成一个有明确目标和可辨识性结论的问题，成为盲源分离、脑电/功能磁共振信号去噪和特征学习的标准工具。

背景

1980年代中期，Hérault与Jutten在研究神经网络模型时提出了一种分离线性混合信号的自适应算法，这就是“盲源分离”问题：观测 x = A·s，源信号s和混合矩阵A都未知，要从x恢复s。“盲”指既不知道源长什么样，也不知道怎么混的。

最直接的想法是主成分分析PCA或白化：把数据转到一组互不相关、方差为1的坐标上。但不相关只约束了二阶统计量（协方差），任何一个旋转都能保持它，所以PCA只能把问题化简到“还差一个未知旋转”，分不开源信号。缺的是比二阶更高的统计信息。

方法

Comon这篇论文给ICA下了明确的定义：给定观测向量x，寻找线性变换W，使 y = W·x 的各分量尽可能相互独立。论文证明了可辨识性：只要源信号中至多一个是高斯分布，W就能在“各分量的缩放和排列顺序”之外被唯一确定。高斯源不行的原因是：多个独立高斯变量的任意旋转仍然独立，信息不足以定出旋转。

独立程度用对比函数来度量，最自然的是各分量之间的互信息（为0当且仅当相互独立）。互信息难以直接计算，Comon用高阶累积量（如四阶累积量，与峰度有关）对其做近似，并给出先白化、再逐对旋转来优化对比函数的实际算法。直观地说，由中心极限定理，混合信号比单个源更接近高斯，所以“让输出尽量不像高斯”就是在把源分开。

后来的发展

随后几年出现了两个最常用的算法：Bell与Sejnowski在1995年从信息最大化（infomax）出发推出了神经网络式的ICA学习规则；Hyvärinen与Oja提出的FastICA用定点迭代最大化非高斯性，计算快，成为脑电、功能磁共振等数据分析软件里的默认选择。

ICA也进入了表示学习：对自然图像小块做ICA，得到的基函数是局部的、带方向的边缘检测器，与稀疏编码的结论一致，都被用来解释视觉皮层简单细胞的感受野。非线性ICA的可辨识性问题，后来成为解耦表示学习和因果表示学习的理论起点。

本篇术语

  • 盲源分离　只观测到多个源信号的混合，在不知道源和混合方式的情况下把源恢复出来。
  • 白化　对数据做线性变换，使各维互不相关且方差为1。
  • 峰度　四阶统计量，衡量分布相对高斯是“尖峰厚尾”还是“平顶”；高斯分布的超额峰度为0。

怎么学

先复习主成分分析PCA与白化，再读Hyvärinen与Oja 2000年的教程前五节；用scikit-learn的FastICA把两段混合后的音频（或正弦波与方波）分离开，并和PCA的结果对比。
