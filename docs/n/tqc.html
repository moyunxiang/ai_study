TQC截断分位数评论家

Controlling Overestimation Bias with Truncated Mixture of Continuous Distributional Quantile Critics
2020.05论文延伸ICML 2020Arsenii Kuznetsov, Pavel Shvechikov, Alexander Grishin, Dmitry Vetrov · Samsung AI Center / HSE待核对
arXiv ↗SB3-Contrib实现 ↗在交互版中打开（演化树、学习进度）

问题

连续控制的离策略演员-评论家会高估Q值；TD3那样取两个评论家的最小值只能粗粒度地压低估计，压多压少没法细调。

方法

让每个评论家输出回报分布的一组分位数，把多个评论家的分位数混在一起排序，丢掉最大的那几个再算目标，丢多少就控制压低多少。

影响

成为SAC之后MuJoCo连续控制上被反复比较的强基线，SB3-Contrib和TorchRL都内置了它，常与REDQ、DroQ等高更新比方法一起对比。

方法

离策略方法的目标里有一个对动作的“取大”操作，估计噪声会被系统性地放大成高估。TD3的办法是训两个Q网络、取较小的那个，但“两个里取小”这个力度是固定的。

TQC把三件事合在一起。第一是分布式评论家：沿用分位数回归QR-DQN的分位数表示，每个评论家对状态-动作输出M个分位数原子，表示回报分布而不是一个均值。第二是集成：训练N个这样的评论家（论文默认N=5、M=25）。第三是截断：计算目标时把N个评论家在下一状态的N×M个原子合在一起排序，只保留最小的kN个，丢掉每个评论家平均d=M−k个最大的原子，用剩下的原子构造分位数回归的目标：

Z_target = { r + γ (z_(i)(s′, a′) − α log π(a′|s′)) : i = 1…kN }

其中 z_(i) 是排序后的第i小原子，熵项沿用SAC。丢弃数d是一个连续可调的旋钮：d越大越保守，论文在不同环境上用不同的d。策略更新照SAC，最大化所有原子均值减去熵惩罚。

摘要称TQC在当时的连续控制基准所有环境上超过此前最好结果，在最难的Humanoid上提升约25%。

局限与后续

  • 每个环境最好的丢弃数d不同，需要按环境调，换一个新任务没有现成的取值规则。

读懂它需要的概念

Actor-Critic与优势函数 Bellman方程 on-policy与off-policy 集成学习

本篇术语

  • 分位数原子　用若干个等概率的点来表示一个分布，每个点是某个分位数位置上的取值。
  • 截断　排序后丢掉最大的一部分原子，只用较小的那部分做学习目标，从而压低高估。

怎么学

先读TD3理解双Q取小，再读分位数回归QR-DQN的分位数回归；读原文第3节的截断目标公式；用SB3-Contrib的TQC在Humanoid上和SAC对比，并调整丢弃数观察回报曲线。
