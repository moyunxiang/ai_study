OK-VQA外部知识问答

OK-VQA: A Visual Question Answering Benchmark Requiring External Knowledge
2019.05数据集延伸CVPR 2019Kenneth Marino, Mohammad Rastegari, Ali Farhadi, Roozbeh Mottaghi · 艾伦人工智能研究所（AI2）/ 卡内基梅隆大学 / 华盛顿大学待核对
arXiv ↗项目主页 ↗在交互版中打开（演化树、学习进度）

问题

VQA里的问题大多是数一数、什么颜色、有没有某物，答案就在图里；考不到“看懂图之后还要调用世界知识”的能力。

方法

只收集光看图答不出来、必须借助外部知识的问题，例如看到一座教堂问“这里的人信什么教”，共14,055题，按十类知识标注。

影响

成为知识型视觉问答的常用基准；后来Flamingo等多模态大模型把它列为评测项目之一，检验语言模型里存的知识能否用于看图答题。

方法

图片取自MS COCO，沿用其训练/验证划分作为本数据集的训练/测试集。第一轮请众包者看图写一个需要外部知识才能回答的问题，后续轮次为每题收集答案，为压低答案偏差，同一个最常见答案超过5题时就删掉多余的题，并删去标注者答案没有共识的题，最终训练9,009题、测试5,046题，共14,055题、14,031张图。

作者另请五位众包者给每题标知识类别，共十类：交通工具、品牌与产品、物品材料与服饰、体育娱乐、烹饪食物、地理历史语言文化、人与日常生活、动植物、科学技术、天气气候，外加“其他”。

作者还给了一个简单的知识检索基线ArticleNet：根据问题和图中物体去维基百科检索文章，再在文章里找答案。

结果

当时最强的VQA模型在OK-VQA上成绩大幅下滑：MUTAN为26.41%、BAN为25.17%，只用问题不看图的基线也有14.93%；把ArticleNet与MUTAN结合只提高到27.84%，说明简单检索远不够。

后来的发展

OK-VQA引出了“检索外部知识再回答”的一系列视觉问答方法，也被Flamingo选为开发阶段使用的5个基准之一；Flamingo为此专门把训练图片与OK-VQA的训练、验证、测试图片做了去重。同一团队后来又推出要求常识推理、不能直接查知识库作答的A-OKVQA（2022）。

局限与后续

  • 测试集只有约5千题，而且为了压低答案偏差人为把答案分布拉平，题目分布与真实用户的提问分布不同。

它建立在什么之上

  • 延续
    VQA2015.05 · 数据·评测
    沿用VQA的看图开放问答形式，但只保留答案不在图中、需要外部知识的问题。
  • 使用
    MS COCO2014.05 · 数据·评测
    图片全部取自COCO，沿用其训练和验证划分。
  • 竞争
    VQA v22016.12 · 数据·评测
    VQA v2通过成对图片压低语言偏差，考的仍是图内信息；OK-VQA换了方向，考图外知识。

这些关系由AI模型整理。“改进”指后来的工作针对它的某个问题做了改进，不代表问题已经解决；“竞争”指同一问题的不同路线，不代表谁取代了谁。标有“已核对”的对照过原始来源，其余未逐条核对。

本篇术语

  • 知识型视觉问答　回答需要图像之外的事实或常识，例如品牌产地、动物习性、历史背景，模型必须从参数记忆或外部知识库里调用。
  • A-OKVQA　2022年发布的后续数据集，约2.5万题，强调问题一般不能靠直接查询知识库回答，而要结合常识推理。

怎么学

先读VQA理解VQA的计分方式。读原文第3节的收集流程和表2。动手：从测试集抽20题，先只看问题猜答案，再看图作答，体会哪些题真正需要图像、哪些主要靠知识。
