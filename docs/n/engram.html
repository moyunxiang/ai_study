Engram条件记忆

Conditional Memory via Scalable Lookup: A New Axis of Sparsity for Large Language Models

问题

MoE靠条件计算扩大容量，但Transformer没有原生的“查知识”原语，静态知识和固定搭配也要靠前几层的计算去重建。

方法

提出条件记忆这一新的稀疏轴：Engram模块把经典的N-gram嵌入现代化，用确定性哈希寻址做O(1)查表，再与隐状态融合。

影响

给出一条MoE之外的稀疏性路径，并通过U形缩放律指导计算与记忆的容量分配。

方法

DeepSeekMoE细粒度专家一类MoE把“多算”做成稀疏：每个token只激活少数专家。Engram补上另一个维度：把“记住”做成稀疏。

Engram是接在主干网络上的模块：它根据当前token及其前面的几个token（N-gram）查一张很大的嵌入表，得到静态记忆向量，再与动态的隐状态融合。因为地址由输入token确定、不依赖网络计算，查表是O(1)的，而且可以把巨大的嵌入表放到主机内存，推理开销很小（以上均出自官方README对论文的概述）。

论文的主张：在参数量和FLOPs都相同的约束下，Engram-27B在知识、推理、代码和数学上持续优于MoE基线；在“神经计算（MoE）”和“静态记忆（Engram）”之间分配容量时，存在U形的缩放规律；分析表明Engram让前几层不必再重建静态模式，可能把有效深度留给复杂推理。
