MeCab日语形态分析

Applying Conditional Random Fields to Japanese Morphological Analysis
2004.07论文延伸EMNLP 2004Taku Kudo, Kaoru Yamamoto, Yuji Matsumoto · 奈良先端科学技术大学院大学待核对
ACL Anthology ↗MeCab ↗在交互版中打开（演化树、学习进度）

问题

日语和中文一样不用空格分词，还要同时确定每个词的词性和活用形；当时的日语形态分析器（如ChaSen）用隐马尔可夫模型，难以利用重叠的丰富特征，而最大熵马尔可夫模型又有标签偏置问题，会偏向切成长词或短词。

方法

先用词典把句子所有可能的切分与词性组合列成一张词格（lattice），再在词格上训练一个条件随机场：对整条路径做全局归一化，可以随意使用词形、词性层级、字符类型等重叠特征，又不受标签偏置影响；解码用维特比找最高分路径。

影响

论文的方法实现为MeCab，成为日语最常用的形态分析器，被几乎所有日语NLP工具、搜索引擎和日语BERT的预处理使用；「词典+词格+CRF」的方案也影响了中文和韩语分词器的设计。

背景

条件随机场（2001）在英语序列标注上证明能解决最大熵马尔可夫模型MEMM的标签偏置问题，但英语的词已经切好、每个位置的标签数固定。日语分词中，不同切分方式产生长度不同的词序列，不能直接套用线性链CRF。此前的ChaSen用HMM在词格上解码，参数只能是词性转移和词的发射概率。

方法

词格构建：用系统词典（如IPADIC）在句子的每个字符位置查出所有以它开头的词条，每个词条带词性、活用等信息，这些候选词构成一张从句首到句尾的有向无环图，每条从头到尾的路径就是一种分词+词性标注结果。

CRF打分：一条路径 y = (w_1, t_1), …, (w_n, t_n) 的得分是所有特征的加权和：

P(y | x) = exp( Σ_i Σ_k λ_k f_k(y_{i−1}, y_i, x) ) / Z(x)

其中特征包括词本身、各层级词性（大类、细类）、字符类型（汉字、平假名、片假名）及其两两组合；Z(x) 是对词格中所有路径求和，用前向-后向算法在词格上高效计算。

训练：最大化训练语料上正确路径的条件对数似然，加L1或L2正则，用L-BFGS优化。作者分析了L1/L2正则的差别，并指出CRF避免了MEMM偏向「切得更少（长词）」的标签偏置。

解码：维特比算法在词格上找得分最高的路径。

结果

论文在京都大学语料和RWCP语料上与HMM、MEMM方法比较，报告CRF的分词与词性标注F值更高；具体数字未核对。

后来的发展

MeCab因为速度快、词典可替换（IPADIC、UniDic、mecab-ipadic-NEologd），成为日语处理的事实标准；Sudachi、Juman++等后来的分析器也采用词格+统计模型的框架。CRF在词格上的用法也影响了中文分词器和Kudo本人后来的CRF++、SentencePiece等工具。

本篇术语

  • 词格（lattice）　把一句话所有可能的切分与标注候选画成有向无环图，每条从头到尾的路径对应一种分析结果。
  • 形态素解析　日语NLP中的术语，指把句子切分成最小的有意义单位（形态素）并标注词性和活用形。
