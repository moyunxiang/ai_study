LangChain

LangChain
2022.10系统延伸开源项目 2022-10Harrison Chase · LangChain（开源项目）待核对
GitHub ↗维基百科 ↗在交互版中打开（演化树、学习进度）

问题

2022年下半年大模型API可用后，每个开发者都在重复写提示拼接、调用外部工具、保存对话历史这些胶水代码。

方法

开源一个把提示模板、模型、检索、工具和记忆组合成「链」和「代理」的框架。

影响

成为最早、也是用得最广的大模型应用框架之一，把RAG和代理的做法变成可复用的模块。

方法

LangChain由Harrison Chase于2022年10月作为开源项目发布，当时他在Robust Intelligence工作（据维基百科）。核心抽象是把一次应用拆成可组合的组件：提示模板、模型调用、文档加载与向量检索、对话记忆，以及让模型选择工具的代理，早期的代理实现直接参考了ReAct的「思考、行动、观察」循环。

2023年4月它成立公司并获得融资，同年引入声明式的LangChain Expression Language，2024年2月发布LangSmith观测平台（据维基百科）。

后来的发展

之后出现了LlamaIndex、LangGraph图式编排、DSPy等更专注于检索、图状工作流或自动优化的框架；也有人批评它抽象层过多，但它确立了「编排层」这个概念。

后来的相关工作

  • 竞争
    模型上下文协议MCP2024.11 · 推理·智能体 待核对
    LangChain在库层面封装工具，工具与应用同进程、同语言；MCP把工具拆成独立进程，用协议通信，任何语言写的服务器都能接。
  • 改进
    函数调用成为标准接口2023.06 · 推理·智能体 待核对
    LangChain等框架原本要用输出解析器把模型文本转成调用；函数调用把这一步移进模型和API，框架可以直接使用它。
  • 竞争
    AutoGPT与自主智能体热潮2023.03 · 推理·智能体
    LangChain提供让开发者组装智能体的组件，流程由人设计；AutoGPT是开箱即用的完全自主程序，流程由模型自己决定。
  • 竞争
    ChatGPT插件2023.03 · 推理·智能体
    LangChain在应用外部用代码把模型和工具串起来，开发者完全掌控；插件则由OpenAI在产品内部统一托管。
  • 改进
    DSPy2023.10 · 推理·智能体
    LangChain式流水线依赖手写提示模板，换模型就要重调；DSPy用签名和编译器自动生成各步提示。
  • 竞争
    SGLang与RadixAttention2023.12 · 系统·效率
    LangChain等框架只在应用层编排调用，看不到底层缓存；SGLang把前端语言与推理运行时一起设计，从而能复用KV、并行分支。
  • 改进
    LangGraph图式编排2024.01 · 推理·智能体
    在LangChain链式调用的基础上加入循环和状态。
