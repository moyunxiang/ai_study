ComfyUI节点工作流

2023.01系统延伸comfyanonymous · 开源项目（后成立Comfy Org）待核对
GitHub ↗Wikipedia ↗在交互版中打开（演化树、学习进度）

问题

AUTOMATIC1111 WebUI把流程固定在表单式界面里，想自由组合多个模型、LoRA、ControlNet时很不灵活，也难以复现与分享完整流程。

方法

用节点图界面：每个加载模型、采样、控制和后处理步骤是一个节点，用户把它们连成工作流，保存为文件即可分享。

影响

成为最灵活的本地扩散模型前端，新模型发布后常常最先被它支持，并可被调用为API接入生产管线。

方法

据维基百科，ComfyUI于2023年1月发布在GitHub，创作者comfyanonymous的主要目标是改进已有软件的界面设计；2024年6月前后，Comfy Org成立并接手。

按官方README，它的核心是一个可视化节点图：用户把图像、视频、音频、3D等流程搭成可重复使用的工作流，并可通过本地API集成到应用里；执行端支持异步排队、只重算被改动的部分子图、显存与内存的智能管理、模型卸载以及量化模型，据称最低4GB显存加8GB内存也能运行大模型。节点式设计也使ControlNet、LoRA微调扩散模型、IP-Adapter图像提示等可控生成技术可以自由串联。

局限与后续

  • 节点图对新手门槛高，复杂工作流难以理解和调试，节点插件生态存在版本冲突和安全风险。

  • 工作流依赖大量第三方自定义节点，可复现性取决于节点版本。

它建立在什么之上

  • 使用
    Stable Diffusion开源2022.08 · 生成

  • 竞争

读懂它需要的概念

扩散：前向加噪与反向去噪 潜空间 参数高效微调 CPU、GPU与并行计算 显存、内存带宽与“内存墙”

怎么学

安装后先跑默认工作流，再把ControlNet节点接进去，导出工作流文件。
