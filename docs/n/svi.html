随机变分推断SVI

Stochastic Variational Inference
2012.06论文延伸JMLR 2013Matthew D. Hoffman, David M. Blei, Chong Wang, John Paisley · 普林斯顿大学、哥伦比亚大学等待核对
arXiv ↗在交互版中打开（演化树、学习进度）

问题

经典的变分推断每一轮都要遍历全部数据更新每个样本的局部变分参数后，才能更新一次全局参数，数据一到百万级就跑不动。

方法

把全局变分参数的更新写成随机优化：每次只抽一个或一小批文档，算出它们的局部变分参数，据此构造全局参数自然梯度的无偏噪声估计，用递减步长更新。

影响

让主题模型等复杂贝叶斯模型第一次能处理数百万篇文档，“小批量+随机梯度”从此成为变分推断的默认做法，并延伸到高斯过程、VAE等深度概率模型。

方法

模型里有两类隐变量：所有数据共享的全局变量β（如主题），以及每个数据点自己的局部变量z_i（如一篇文档的主题比例）。在条件共轭的模型族里，全局变分参数λ的最优值可以写成“先验参数+所有数据点的充分统计量之和”。SVI的做法是：随机抽一个数据点，先优化它的局部参数，然后假装整个数据集都是这个点重复n次，算出一个中间的全局参数λ̂，再按λ ← (1−ρ_t)λ + ρ_t λ̂更新。作者证明这一步正好是沿ELBO自然梯度方向的随机梯度步，步长满足Robbins–Monro条件时收敛。

摘要报告：在潜在狄利克雷分配和层次狄利克雷过程主题模型上，用SVI分析了Nature的30万篇、纽约时报的180万篇和维基百科的380万篇文章；SVI能处理这样的规模，并优于只能用其中一小部分数据的传统变分推断。

局限与后续

  • 推导依赖条件共轭的模型结构，换一个非共轭模型就要重新推导更新式。

它建立在什么之上

  • 使用
    随机梯度下降1951 · 基础
    把全局变分参数的更新变成Robbins–Monro式的随机优化。
  • 使用
    自然梯度1998 · 基础
    每一步沿ELBO的自然梯度方向更新，在共轭模型里这一步形式非常简单。
  • 改进
    变分推断1999 · 基础
    解决经典变分推断每轮都要遍历全部数据、无法扩展到大数据的问题。
  • 使用
    LDA主题模型2003 · NLP
    主要实验对象是LDA主题模型及其非参数扩展。
  • 改进
    LDA折叠Gibbs采样2004.04 · NLP
    每轮要扫描语料中的每一个词，语料达到百万文档时速度很慢，难以处理流式到达的数据。
  • 改进
    动态主题模型DTM2006.06 · NLP
    非共轭的变分推断复杂、计算量大，难以扩展到很大的语料和词表。
