Transformer与大语言模型

一个只做“预测下一个词”的模型，放大到什么程度、怎么训练，才能变成通用的智能底座？

整张图的主干。Transformer → 预训练+微调 → 规模定律与少样本 → 指令对齐与ChatGPT → 开源生态、长上下文与前沿模型竞赛，外加扩散语言模型这条非自回归支线。

从“语言与NLP（前Transformer）”分出：Transformer完全用注意力取代循环，训练更容易并行、更好放大，之后NLP的主干逐步转向它。
