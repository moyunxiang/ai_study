推理、检索与智能体

模型已经会说话了——怎样让它想得更深、查得到事实、并且能自己动手把事做完？

围绕大模型“怎么用”的一整条线：检索增强、思维链、工具调用、推理模型与面向推理的强化学习、编码智能体、协议与多智能体。这是2024年之后最热的方向。

从“Transformer与大语言模型”分出：模型本身不够用时，给它外挂检索、草稿纸和工具；之前的向量检索是这条线的前史。
