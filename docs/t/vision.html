计算机视觉

怎样从像素里学到通用的视觉表示——先是识别，然后是定位、分割、三维？

深度学习革命的起点。手工特征 → AlexNet → 越来越深的卷积网络 → 检测与分割 → 自监督预训练 → ViT把视觉并入Transformer → SAM、DINOv2这类视觉基础模型与三维重建。

从“机器学习与深度学习基础”分出：视觉先有几十年的手工特征与几何方法；LeNet一系把反向传播和卷积结合，视觉接上神经网络，2012年AlexNet后多数工作转向深度网络。
