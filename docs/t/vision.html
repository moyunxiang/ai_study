计算机视觉

怎样从像素里学到通用的视觉表示——先是识别，然后是定位、分割、三维？

深度学习革命的起点。手工特征 → AlexNet → 越来越深的卷积网络 → 检测与分割 → 自监督预训练 → ViT把视觉并入Transformer → SAM、DINOv2这类视觉基础模型与三维重建。

从“机器学习与深度学习基础”分出：视觉先有几十年的手工特征与几何方法；LeNet一系把反向传播和卷积结合，视觉接上神经网络，2012年AlexNet后多数工作转向深度网络。

卷积骨干网络

1959–2023 · 37个节点

怎样设计并训练一个通用的卷积网络，把图像特征提取做深、做准、做快。

  • 1959视觉皮层感受野没人知道大脑皮层里的神经元到底对图像里的什么东西起反应，用均匀的光斑刺激视觉皮层几乎得不到稳定响应。
  • 1980Neocognitron感知机一类的模型把整张图连到一层神经元上，同一个字母平移几个像素就成了完全不同的输入，识别不出来。
  • 1989卷积网络识别邮编美国邮政每天要读大量手写邮编，传统做法先手工设计特征再分类；新认知机有卷积式结构，却没有办法用分类误差去训练整个网络。
  • 1998LeNet与卷积网络文字识别系统由人工设计的特征提取器、分割规则和分类器拼成，每一块单独调，换一种字体或书写风格就要重写一大段。
  • 1999.11HMAX与最大池化视觉皮层能识别物体，且对位置和大小的变化不敏感，但缺少一个能实际计算的模型解释这是怎么做到的。
  • 2012.02GPU多列卷积网络卷积网络在MNIST之外的图像任务上一直被SVM加手工特征压着，深层网络的训练又太慢。

  • 2013.10DeCAF通用深度特征深度网络在ImageNet上很强，但换到别的任务时，数据少，没有人确定学到的表示是否可以直接拿来用。
  • 2013.11卷积网络可视化的成绩很好，但没人知道每一层在学什么，为什么有效，如何改进，调参基本靠猜。
  • 2013.12Network In Network卷积层用线性滤波加非线性，表达力有限，而末端的全连接层参数巨大又容易过拟合。
  • 2014.09VGGAlexNet之后大家都在调卷积核大小、步长、宽度，结构五花八门，没人系统回答过“网络更深是否就更好、该怎么加深”。
  • 2014.09GoogLeNet / Inception提高精度的办法是加深加宽网络，但参数和计算量随之暴涨，容易过拟合。
  • 2015.06空间变换网络STNCNN靠池化只获得很有限的平移不变性，对旋转、缩放、扭曲不鲁棒。

  • 2016.03预激活ResNetResNet的残差块在相加之后还有ReLU，信号经过一个个块时会被改变，超深的网络难训练。

  • 2016.08DenseNetResNet把很多层做深了，但随机深度等实验表明，深ResNet里很多层可以随机丢掉而几乎不影响结果——层与层之间存在大量冗余，参数利用率…
  • 2016.10XceptionInception模块把「找跨通道相关」和「找空间相关」混在一起做，它们是否应该分开不清楚。
  • 2016.11ResNeXt提高网络精度只有加深和加宽两条路，Inception的多分支结构需要为每个分支手工设计。
  • 2017.03可变形卷积标准卷积的采样位置是固定的规则网格，难以适应物体的形变和尺度变化。
  • 2017.04MobileNetResNet、VGG这类网络参数和计算量太大，手机和嵌入式设备跑不动。
  • 2017.07ShuffleNetMobileNet把大部分计算量集中到了1×1逐点卷积上，在更小的预算（几十MFLOPs）下，它仍然成为瓶颈。
  • 2017.07NASNet在大数据集上直接做神经架构搜索，代价高到不实用，且找出的结构没法迁移。
  • 2017.08Cutout网络在CIFAR这类小数据集上容易过拟合，而常见的dropout对卷积层作用有限。
  • 2017.09SENet通道注意力卷积同时混合空间与通道信息，但对「哪些通道此刻更重要」没有显式的建模。
  • 2018.01MobileNetV2MobileNet的结构对低维特征做ReLU会损失信息，而且没有残差连接，网络很难做深。
  • 2018.05AutoAugment数据增强策略（翻转、裁剪、颜色等）全靠人工设计，且不同数据集的最佳选择不同。
  • 2018.11重新思考ImageNet预训练「先在ImageNet上预训练再微调」是视觉的默认做法，人们很少检验它到底必不必要。
  • 2019.05CutMixCutout遮掉的区域是纯黑像素，丢了信息，训练效率低；Mixup整张叠加又让图像不自然。
  • 2019.05EfficientNet放大网络时，只加深、只加宽或只加大输入分辨率往往很快饱和，三者各调各的缺少规律。
  • 2019.09RandAugment这类自动数据增强要先在小模型、小数据集上花大量算力搜索策略，再搬到目标任务，既贵又无法随模型大小调整增强强度。
  • 2019.11Noisy Student自训练即使有完整的ImageNet标签，大量无标注图片也没被用上；以往自训练的学生不比老师强，增益有限。
  • 2019.12BiT大规模迁移迁移学习在视觉里还没有统一配方：各家预训练规模不同、微调超参逐任务手调，小数据集的迁移效果不稳定。
  • 2020.03RegNet设计空间网络结构设计要么靠人凭经验，要么靠神经架构搜索，只得到个别网络，很难总结可迁移的设计规律。
  • 2022.01ConvNeXt这样的分层Transformer在检测、分割上超过CNN，但不清楚优势来自注意力本身，还是来自训练配方和层级设计等其他改动。
  • 2023.01ConvNeXt V2原为有监督训练设计，直接套用的掩码自监督预训练，效果反而不好。

手工特征

1963–2013 · 18个节点

深度学习之前，靠人设计的边缘、角点、梯度直方图等特征来识别图像。

  • 1963Roberts积木世界早期的图像处理只能做二维模式匹配，机器并不能从一张照片理解里面物体的三维形状。
  • 1966.07MIT夏季视觉项目1960年代中期人们以为让机器「看懂」图像不过是个工程问题，可以安排给暑期学生在几周内完成。
  • 1982Marr《视觉》1960–70年代的视觉程序只能在积木世界里跑，大家写了很多技巧，却说不清“看”到底要算什么、每个模块的输入输出是什么。
  • 1986.11Canny边缘检测边缘检测方法很多都是经验性的，没有一个明确的「什么叫好的边缘检测」的标准，结果常常断断续续、一条边出现多个响应。
  • 1988Harris角点跟踪和匹配需要图像里「容易被认出的点」，边缘上的点沿边缘滑动时看起来都一样，不适合当特征。
  • 1991特征脸Eigenfaces人脸识别依赖手工量取眼鼻嘴的位置和距离，对表情和光照敏感，自动化程度低。
  • 1997.06归一化割把图像分成有意义的区域时，常用的最小割准则倾向于切出很小的孤立碎片，而不是整块的物体或区域。
  • 1999SIFT特征要在杂乱、被遮挡的照片里认出一个物体，需要能在两张图之间可靠对上的局部特征；当时的角点特征一缩放就对不上，对视角、光照也很敏感。
  • 2001Viola–Jones人脸检测人脸检测需要在图像的每个位置和尺度上滑动窗口判断，传统分类器太慢，无法实时运行。
  • 2003.10视觉词袋在整部电影里找出某个物体出现的所有镜头，需要逐帧比对，对大规模视频的计算量无法接受。
  • 2005HOG与手工特征时代行人检测要在姿态、衣着、光照变化很大的情况下判断窗口里是不是人，当时的特征对光照变化和局部形变不够稳健。
  • 2006.05SURF效果好，但计算慢，用在实时和大规模场景里吃不消。
  • 2006.06空间金字塔匹配式的词袋完全丢掉了特征的空间位置，场景分类里「天空在上、草地在下」这种布局信息被浪费。
  • 2007.09Tesseract OCR开源世界缺少一个质量可用的OCR引擎，文字识别要么是昂贵的商业软件，要么准确率很低。
  • 2008.06可变形部件模型DPMHOG加线性SVM的刚性模板只能描述一个固定姿态，人一抬手、马一转身，模板就对不上；可变形部件模型概念上更好，却从没在PASCAL这种难基…
  • 2010.09Fisher向量词袋模型用硬分配和一阶统计（只数每个词出现几次），丢失了描述子在簇内的分布信息，要得到好精度需要很大的词表。
  • 2011.11ORB特征和精度好，但计算慢、描述子占内存，而且当时还有专利顾虑，难以放进手机和嵌入式设备。
  • 2013选择性搜索滑动窗口要对每个位置和尺度都跑分类器，物体检测太慢，要用的分类器越强越贵。

多视图几何与重建

1981–2025 · 27个节点

从多张照片恢复相机位置和场景三维结构，从几何流水线走向前馈网络。

  • 1981.06RANSAC拟合直线、变换矩阵时，只要有少量错误匹配（离群点），最小二乘就会被带偏，而真实数据里离群点很常见。

  • 2017.12SuperPoint传统角点与特征点（Harris、SIFT）靠手工规则，神经网络方案又缺少关键点位置的真值标注。
  • 2018.04MVSNet传统多视图立体靠手工匹配代价和优化，对弱纹理、反光区域易失败，且深度学习缺少能处理任意视图数的端到端方案。
  • 2019.11SuperGlue两张图的局部特征匹配靠最近邻加手写规则（比值测试、RANSAC）过滤，对视角和光照剧变很脆弱，且不会主动拒绝不可匹配的点。
  • 2021.04LoFTR仍要先在两张图里各自检测关键点；在低纹理区域（白墙、地板）检测器找不到可重复的点，匹配就无从谈起。
  • 2022.10CroCo跨视图补全一类的掩码图像建模擅长分类、检测等语义任务，但对深度估计、光流这类需要几何理解的底层任务帮助有限，因为单张图里被遮住的内容无法被精确推断。
  • 2023.06LightGlue匹配精度高，但计算和显存开销大、训练困难，难以用于对延迟敏感的三维重建与定位。
  • 2023.12DUSt3R传统多视图重建要先标定相机、估计位姿，再三角化匹配点，由匹配加光束法平差等多阶段流水线组成，复杂且对无标定图片脆弱。

  • 2025.09MapAnything度量重建前馈三维重建模型各自只做一类任务（只有图像、或已知内参等），无法灵活利用手头已有的几何信息，也难以统一度量尺度。
