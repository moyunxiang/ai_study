# 设计备选

线上现版之外的十一套设计原型：八套以一张大图为主（年轮、地铁、大树、星图、河流、弧线、气泡、谱系），三套以文字为主（手册、长卷、分栏）。每套都是单独写的页面结构和交互，不是在线上样式上换颜色；它们读的是 `docs/data/` 里线上同一份数据。

另有八套“线上现版换风格”（水墨、圆角、终端、书卷、展厅、海报、站牌、图纸）：页面结构和功能就是现版，只多加载一份 `skins/<名字>.css`。

还有七套“线上现版换颜色”（蓝、靛、紫、青、琥珀、玫红、石墨）：版式、字体和现版完全一样，只换底色、文字色和强调色，深色、浅色、跟随系统三档都有。

线上：<https://moyunxiang.com/ai_study/lab/>（总览页；各页面带 `noindex`，不进站点地图，线上现版的页面里没有入口）。

    python3 scripts/style_lab.py              # 本地预览：http://127.0.0.1:8793/lab/
    python3 scripts/style_lab.py --publish    # 把这里要发布的部分复制到 docs/lab/（改完原型后要重跑，再提交）

页面底部有一条切换条：上一套、下一套、下拉里挑一套（也可以按 Alt+[ 和 Alt+]，或 Alt+1…9）。在某个节点或概念的页面上切换，会带着同一个节点到另一套设计里。

| 目录 | 名字 | 是什么 |
|---|---|---|
| （无） | 线上现版 | 顶部导航、一页一页地翻、横向的演化树 |
| `atlas/` | 年轮 | 整个网站是一张可拖动缩放的图：圆心是1943年，越往外越新，十六条分支各占一个扇区；讲解从侧边滑出，路线、分支、年代、概念都是在图上点亮一部分 |
| `metro/` | 地铁 | 地铁线路图：时间从左到右，每条主题线是一条线，同一分支的线同色并排；节点是站，线从哪一站分出来就在那里拐45度接出去，跨分支的汇流是虚线；路线是一条黑底黄芯的行程 |
| `tree/` | 大树 | 一棵从1943年往上长的树：越高越新，主题线是枝、从母枝上分出来，节点是叶子、主干节点是果子；根窄冠宽。目录和讲解都在左边一栏，树一直在右边 |
| `galaxy/` | 星图 | 没有时间轴：位置由关系决定，有关系的节点靠近，同一分支聚成星云；星越大后续工作越多、越亮越新。底下的时间条可以拖和播放，看星空怎么长出来。只有深色。坐标由 `galaxy/layout.mjs` 预先算好存在 `layout.json`，改了数据后要重算 |
| `river/` | 河流 | 往下滚的长图（SVG，不用画布）：十六条河道的宽度是各分支每年节点数的占比，节点是河道里的点；顶上一条细带显示当前这一年各河道的名字；右边一栏是目录和讲解 |
| `arcs/` | 弧线 | 所有节点按时间排在一条横轴上：轴上面每条关系是一道弧（颜色跟较早那一头的分支），轴下面每个节点是一个点，同一段时间的点往下堆，堆的高度就是那段时间的工作量。图贴在页面顶部，目录和讲解在下面跟着页面滚。跟随系统明暗 |
| `bubbles/` | 气泡 | 一层套一层的圈：六个大方向里是十六条分支，分支里是主题线，主题线里每个圆点是一个节点（最早的在圆心，越新越靠外）。点一个圈放大进去，放大以后点圆点看讲解；没有时间轴。跟随系统明暗 |
| `lineage/` | 谱系 | 不用画布，方框和连线：看一个节点时它在正中，左边两代是来源、右边两代是后续，点别的方框就以它为中心重画；分支页画主题线从哪条线分出来，首页画十六条分支的分叉关系，路线是一串带编号的方框。图在上，讲解在下。跟随系统明暗 |
| `handbook/` | 手册 | 三栏文档站：左边是整棵树的目录，中间读正文，右边是本页目录和前驱后续；另有一张年份×方向的年表 |
| `scroll/` | 长卷 | 一页到底的编年史：从1943年往下滚到今天，点一条就在原地展开讲解；左边一根时间尺，路线是在长卷上点亮几站 |
| `columns/` | 分栏 | 分栏浏览器：方向、年代、路线、概念、我的五种看法共用一套栏，一栏一栏往右展开，最右是讲解；方向键可用 |

`shared/core.js` 是共用的数据层（节点、关系、正文、概念、路线、搜索、学习状态），`shared/base.css` 只有重置和机制图的样式。后做的七套（地铁、大树、星图、河流、弧线、气泡、谱系）还共用 `shared/browse.js`（各种列表有哪些条目、该点亮哪些节点、地址怎么对应到状态）；其中五套画布的（地铁、大树、星图、弧线、气泡）共用 `shared/stage.js`（拖动、缩放、点选、标签避让）。这两个文件只管数据和手势，画什么、界面怎么摆都在各自目录里。

## 原型做到了哪里

每套都有：首页、节点讲解（三句话、正文、机制图、局限、前驱和后续）、概念、分支和主题线、年代、入门路线和十个研究专题、搜索、学习状态和收藏。

每套都还没有：笔记、从零读到某个节点的路线、两个节点对比、统计、机构、指南、静态页和SEO。弧线、气泡、谱系、手册、分栏跟随系统的明暗，年轮、地铁、大树、河流只有浅色，长卷和星图只有深色。

参考过的做法：OneZoom（可缩放的生命之树）、Beck式地铁图的横竖斜线、Paperscape（按引用关系排的arXiv星图，大小表示被引、亮度表示新旧）、Histomap和ThemeRiver（宽度表示占比的河流图）；第四批又参考了Chris Harrison的圣经互引弧线图（一条轴、每条引用一道弧）、Histography（每个事件一个点、按时间往上堆）、嵌套圆的层级图（circle packing，点一个圈放大进去）、Citeology和Connected Papers（以一篇论文为中心，画它的上下几代）、Litmaps（横轴是年份的引用图）。只借了表达方式，没有用它们的代码或素材。

## 选定之后

把选中的设计做成线上实现（`docs/assets/app.js` 和 `style.css`），补齐上面缺的功能和另一种明暗，保住现有地址；重拍 `docs/design/` 的截图、更新 `docs/design.html`；跑搜索回归和三内核浏览器回归后再提交。

## 线上现版换颜色

`skins/tint-<名字>.css` 由 `scripts/lab_tints.py` 生成，不要手改：

```
python3 scripts/lab_tints.py          # 重新生成七套
python3 scripts/lab_tints.py --check  # 只打印对比度
```

做法是读现版 `docs/assets/style.css` 里深色和浅色两组颜色变量，在 OKLCH 里只转色相：亮度不动，彩度按比例放大或缩小（超出 sRGB 时只降彩度）。所以每套的明暗层次和对比度跟现版基本一致。蓝、靛、紫、玫红四套把深色下的强调色压暗了一点，换来更饱和的颜色；石墨把彩度几乎去掉，强调色是白（浅色下是黑）。

不动的东西：十六条分支各自的颜色（按色相算），以及“已读 / 解决 / 使用”这类有固定含义的红、绿、蓝。

要加一套或者调一套，改脚本开头的 `TINTS`，再在 `styles.json` 里加一条 `"skin": "tint-<名字>"`、`"kind": "色"` 的条目。页面的生成方式和下面的换风格一样。

## 线上现版换风格

`skins/` 里每个 CSS 是叠在线上 `docs/assets/style.css` 之上的一套样式，不改页面结构和脚本。`styles.json` 里带 `"skin"` 的条目会生成一个页面 `/lab/v1-<名字>/`：它是 `docs/index.html` 的副本，资源和数据请求指回站点根目录，再多加载这份 CSS（本地预览时现做，`--publish` 时写成文件）。现版改了 `index.html` 之后要重新 `--publish`。

| 名字 | 样子 |
|---|---|
| 水墨 `ink` | 宣纸底、墨色字、一方朱砂印，楷体标题、宋体正文，分支颜色压成灰调 |
| 圆角 `candy` | 学习应用的样子：圆体字、大圆角、有厚度的按钮和卡片、淡彩色块 |
| 终端 `terminal` | 琥珀色荧光屏的老终端：全等宽字、虚线框、提示符、扫描线（深色） |
| 书卷 `book` | 一本排过版的书：宋体、黑白、双线、窄栏 |
| 展厅 `gallery` | 极简白：整屏居中、大留白，几乎不用线 |
| 海报 `poster` | 超大字、粗黑边、硬阴影、大色块 |
| 站牌 `transit` | 地铁标识系统：黑色顶栏加黄线、粗黑体、实色线路牌 |
| 图纸 `blueprint` | 工程蓝图：蓝底网格、等宽字、方框和编号（深色） |

这些换风格的页面只覆盖交互版（`index.html`）；不带脚本也能读的静态页（`n/*.html` 等）仍是现版样式。
