# 配色备选

线上现版只换颜色的备选。版式、字体、功能和现版完全一样，只换底色、文字色、线条色和强调色；现版自己的页面、样式和脚本都没有改。

预览只有一个页面 `/lab/`：它就是现版，页面底部多一排色块，点一下原地换色，不跳页，停在哪个页面、滚到哪儿都不变。色块条上还有深色 / 浅色 / 跟随系统的切换。选中的配色记在本机，也写进地址的 `?c=<名字>`。快捷键：Alt+[ 上一套，Alt+] 下一套。

```
python3 scripts/style_lab.py            # 本地预览 http://127.0.0.1:8793/lab/
python3 scripts/lab_colors.py           # 重新生成全部配色（并打印对比度）
python3 scripts/lab_colors.py --check   # 只打印对比度
python3 scripts/style_lab.py --publish  # 生成 docs/lab/
```

## 文件

- `colors/<名字>.css`、`colors.json`：由 `scripts/lab_colors.py` 生成，不要手改。要加、要调，改脚本开头的 `SCHEMES` 或 `TINTS` 再重跑。
- `bar.js`：底部的色块条。
- `/lab/` 的页面由 `scripts/style_lab.py` 从 `docs/index.html` 生成：资源和数据请求指回上一级的站点根目录，多加载一份配色样式表和色块条，带 `noindex`。现版改了 `index.html` 之后要重新发布。

## 两类配色

**照着真实网站和公开配色方案的思路定的（12套）。** 每套只给出深色、浅色各一组“纸、字、强调色”，其余中间色按现版的明暗层次在纸和字之间取。这一类去掉了现版的发光和首页标题后面的光晕。

| 名字 | 样子 | 参考 |
|---|---|---|
| 黑白 `mono` | 纯黑纯白，不用任何彩色 | 极简的开发者工具站 |
| 素绿 `green` | 白纸黑字，只留一点深绿 | 长文阅读站 |
| 报纸 `news` | 新闻纸的米白、黑字、一处红 | 报纸和新闻周刊的网站 |
| 粉纸 `salmon` | 三文鱼粉的纸色，青绿的链接 | 财经报纸的网站 |
| 百科 `wiki` | 纯白、深灰字、链接蓝 | 百科网站 |
| 代码 `code` | 冷白和冷黑、细灰线、标准的蓝 | 代码托管网站的设计规范 |
| 笔记 `note` | 暖灰的字和线，一点不抢眼的蓝 | 笔记应用 |
| 朱墨 `zhumo` | 宣纸、墨色、朱砂 | 书画和线装书 |
| 青花 `qinghua` | 白底钴蓝；深色下是整页钴蓝底配白字 | 青花瓷 |
| 日晒 `solar` | 米黄的纸、青灰的字，深色下是墨青底 | Solarized配色方案 |
| 复古 `gruv` | 发黄的暖色 | Gruvbox配色方案 |
| 北欧 `nord` | 偏蓝的冷灰 | Nord配色方案 |

只借了颜色的思路，没有用这些网站的代码、字体、标志或素材。颜色值是按这些公开的设计规范和配色方案写的，写的时候没有逐个去它们的网站上重新核对；强调色对底色的对比度不到4.5时脚本会自动调深或调亮，所以个别值和来源不完全一样（脚本输出里会标“调过”）。

**现版转色相（7套）：蓝、靛、紫、青、琥珀、玫红、石墨。** 把现版的颜色在OKLCH里整体转一个色相，亮度不动，发光保留。结构上和现版是同一个配方（带色的深底加一个亮的强调色）。

两类都不动的：十六条分支各自的颜色（按色相算），以及“已读 / 解决 / 使用”这类有固定含义的红、绿、蓝。

## 没覆盖的

不带脚本也能读的静态页（`n/*.html` 等）仍是现版的颜色。选定一套之后，要把它的两组变量写回 `docs/assets/style.css`，静态页才会一起变。
