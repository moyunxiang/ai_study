# —— 对已有节点的连接与修正建议 ——
# PARENT backprop <- werbos, Werbos 1974年博士论文首次提出用反向模式求导训练多层网络
# PARENT svm <- kernel-trick, Cortes&Vapnik 1995直接建立在Boser等1992的核化最优间隔分类器上
# PARENT svm <- vc-dimension, SVM的理论动机是VC维与结构风险最小化
# PARENT adaboost <- boosting-weak, AdaBoost是Schapire 1990 boosting构造的实用化
# PARENT resnet <- highway, 残差连接是Highway网络去掉门控后的特例
# PARENT adamw <- weight-decay, AdamW的核心论点就是区分权重衰减与L2正则
# PARENT adam <- rmsprop, Adam = RMSProp的二阶矩估计 + 动量
# PARENT adam <- momentum, 同上
# PARENT gcn <- chebnet, GCN是ChebNet的一阶近似
# PARENT mamba <- s4, Mamba是在S4上加入输入依赖的选择机制
# PARENT double-descent <- interpolation-regime, Belkin等2018首先提出双下降曲线
# PARENT dbn <- contrastive-divergence, DBN的逐层RBM训练使用对比散度
# PARENT deep-autoencoder <- pca, 该文的核心对比对象就是PCA降维
# PARENT score-matching <- score-matching-hyvarinen, Song&Ermon直接使用Hyvärinen的分数匹配目标
# PARENT vae <- variational-inference, VAE是摊销化的变分推断
# PARENT cpc <- nce, InfoNCE损失由NCE推广而来
# PARENT word2vec <- nce, 负采样是NCE的简化
# PARENT switch-transformer <- moe-1991, 混合专家思想的源头
# PARENT lottery-ticket <- deep-compression, 彩票假说的出发点是剪枝后的稀疏子网络，而非Dropout
# PARENT graphcast <- mpnn, GraphCast是编码-处理-解码式的消息传递图网络
# SUGGEST llm: Sparsely-Gated MoE（Outrageously Large Neural Networks: The Sparsely-Gated Mixture-of-Experts Layer）, 2017-01, 现代MoE大模型的直接起点，llm骨架只有2021年的switch-transformer
# SUGGEST llm: Pre-LN Transformer（On Layer Normalization in the Transformer Architecture）, 2020-02, 解释了为何几乎所有LLM改用Pre-LN与去掉warmup依赖
# SUGGEST llm: 线性注意力混合架构（Qwen3-Next / Kimi Linear）, 2025-09/2025-10, Gated DeltaNet类层与全注意力3:1混合成为开源模型的一条主流架构路线
# SUGGEST sys: Optimal Brain Damage, 1989, 基于二阶信息剪枝的源头，deep-compression与lottery-ticket的上游
