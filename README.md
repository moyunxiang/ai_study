# AI脉络

把AI的发展画成一棵按时间生长的树：<https://moyunxiang.com/ai_study/>

从1943年的M-P神经元到今天，按“6个大方向 › 16条分支 › 190条主题线 › 约3000个节点”四层组织（树干是学习方法；大枝是语言与推理、感知与生成、决策与真实世界；土壤是数据、系统与算力；环境是社会）。节点包括论文、模型、系统、芯片、数据集和关键事件。每个节点讲清楚三件事：当时卡在哪、它怎么解决、它留下了什么问题以及后来谁解决了。节点之间用“解决 / 延续 / 使用 / 竞争”四种边连起来。另有206个基础概念词条，面向只有基本编程和大一数学基础的读者。

## 功能

- 使用指南（`#/guide`）：三种读法、节点页怎么读、图例
- 全景树（`#/map`）：总览里一行是一条分支，画出它从哪条分支分叉、每年的工作量和主干节点；点分支名展开成主题线，点节点看讲解和连接；可切横向/竖向，可只看某个节点的来龙去脉
- 分支页（`#/tracks`）：大方向 › 分支 › 主题线的层级总览；每条分支有自己的树
- 时代页、节点讲解页、概念词条
- 学习路线（69个主干节点）、任意节点的“从零读懂”学习链、任意两个节点之间的演进路径
- 开放问题：还没有后续工作解决的遗留问题
- 搜索（标题、作者、摘要、讲解全文、概念与术语）
- 学习进度、收藏、笔记、自测卡片（只存在浏览器本地，可导出导入）

## 目录

```
data/tracks.json, eras.json     分支与时代
data/tree.json                  6个大方向、分支之间的分叉关系、跨分支汇流
data/threads/<track>.json       每条分支的主题线，以及每个节点属于哪条
data/skeleton/*.txt             节点登记表：id | date | tier | kind | title | full | parents
data/content/<track>/<id>.json  每个节点的讲解
data/concepts.txt, concepts/    基础概念登记与词条
guide/                          内容规范
scripts/build.py                校验并生成 docs/data/
docs/                           静态站点（GitHub Pages从这里发布，无构建步骤）
```

## 本地运行

```
python3 scripts/build.py --check --stats   # 只校验
python3 scripts/build.py                   # 生成 docs/data/
python3 -m http.server 8791 -d docs        # 打开 http://127.0.0.1:8791/
```

## 关于内容

讲解由AI模型撰写，写作时要求对照论文原文或官方页面核对数字和日期，每个节点页底部列出核对所用的出处。仍然可能有错，引用前请以原文为准。发现错误欢迎提issue。
